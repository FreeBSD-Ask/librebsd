### M-6（B 级·依裁定修订）卷 29 章序重组（不拆卷、不并卷）

**卷 29（BSD 分支的安全工程，16 章 143 节）**现章序为：形成史(1) → 模型群(2) → 现代缓解(3) → 共同基础(4) → FreeBSD(5) → NetBSD(6) → OpenBSD(7) → **最小权限与主动防御(8)** → DragonFly(9) → 机制比较(10) → 网络密码(11) → 供应链(12) → 漏洞类型(13) → 漏洞事件(14) → 路线比较(15) → 方法(16)。**第 8 章夹在 OpenBSD 与 DragonFly 两支之间**，切断分支块；第 11／12 章（机制深化）与第 2／3 章（模型机制）亦分置。建议按层序重排：**形成史 → 共同基础与机制群（模型／缓解／最小权限／网络密码／供应链）→ 四分支持论（F／N／O／D）→ 机制与路线比较 → 漏洞类型与事件响应 → 方法与史料**。此为**章内重组**，不动卷界，锚点变更限于卷内。

**拆分／合并路线：依主理人裁定（2026-09-27）关闭**——**大卷不因体量本身而被拆分**，**不考虑合并小卷**。故本项仅保留上列的**章内重组**：不动卷界、不动卷数，锚点变更限于卷 29 卷内。前稿曾列“拆卷 29（安全机制史＋漏洞史）”“合并卷 5＋6”“卷 43 并入他卷”等选项，**一并撤销，不再作为建议**；体量差（卷 13 的 162 节等）**按史料驱动的既成事实保留**，不作均衡干预。
