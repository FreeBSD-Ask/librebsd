# 100.13.1 chflags 权限绕过与 OpenSSH agent 转发漏洞——权限层与加密协议层漏洞

  **要点**：FreeBSD-SA-99:01.chflags（1999 年 9 月 4 日）记录 BSD File Flags 权限检查缺陷——**chflags(1)** 的权限检查存在漏洞，本地用户可绕过文件标志保护修改受保护文件，受影响版本为 FreeBSD 3.2 及更早版本，公告原文未引用 CVE 编号；FreeBSD-SA-01:01.openssh（2001 年 1 月 15 日）记录恶意 SSH 服务器可利用 OpenSSH agent 转发与 X11 转发漏洞攻击客户端——导致客户端用户权限被窃取，受影响版本为 FreeBSD 4.2-RELEASE（含 OpenSSH 2.3.0），该漏洞被编号为 CVE-2001-0144；FreeBSD-SA-00:21.ssh（2000 年 6 月 7 日）记录 ports collection 中 ssh 软件包端口 722 配置问题可能导致未授权访问；上述漏洞覆盖权限层（chflags 文件标志绕过）与加密协议层（OpenSSH agent/X11 转发），反映 FreeBSD 3.x 至 4.x 过渡期权限模型与加密服务基线的缺陷——chflags 为 4.4BSD 继承的文件标志机制，OpenSSH 为 3.x 时期新引入的加密服务，二者分别代表继承漏洞面与新引入漏洞面
  
**史料**：FreeBSD-SA-99:01.chflags 公告（freebsd.org/security/advisories/FreeBSD-SA-99:01.chflags.asc）、FreeBSD-SA-01:01.openssh 公告（CVE-2001-0144）、FreeBSD-SA-00:21.ssh 公告、CVE-2001-0144 NVD 条目 ［A］
  
**史观**：密码学与信息安全：chflags 权限绕过为 4.4BSD 继承漏洞面的延续，OpenSSH agent 转发漏洞为新引入组件漏洞面的代表；技术路线分化：FreeBSD 3.x 引入 OpenSSH 作为加密服务，与同期 OpenBSD 2.6（1999 年 12 月首次发布 OpenSSH）形成路径交叉
  
**辨析**：chflags 权限绕过的精确触发路径须对照 FreeBSD-SA-99:01.chflags 公告原文与 **chflags(2)** 手册页核实——公告仅称 “权限检查缺陷”，未详细说明绕过路径；CVE-2001-0144 的 CVSS 评分须对照 NVD 条目核实——版本周期文件未提取 CVSS 评分，史家不得臆造评分值；FreeBSD-SA-01:01.openssh 影响 FreeBSD 4.2-RELEASE，超出 FreeBSD 3.x 版本周期（1998-10 至 2000-03），但 OpenSSH 在 3.x 时期引入故归入本章叙事，史家须在叙事中明确版本归属；【0 信任原则·CVE 编号时序】CVE-2001-0144 编号年份为 2001 年，但 OpenSSH agent 转发漏洞的发现与披露可能早于 2001 年，史家须区分 “CVE 编号年份” 与 “漏洞披露年份”
