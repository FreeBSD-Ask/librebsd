# 100.3.3 与日志文件系统的路线分野

  **要点**：soft updates 与日志文件系统 (ext3 journaling、ReiserFS、JFS) 走不同路线，前者跟踪依赖顺序写入，后者先写日志再写数据；Linux/Solaris 选择日志，FreeBSD 选择 soft updates，这一分化持续至 ZFS(2005) 引入
  
**史料**：McKusick 与 Linux 社区关于 journaling vs soft updates 的辩论、BSDCon 文件系统讨论 ［B］
  
**史观**：技术路线分化，soft updates 与 journaling 是文件系统一致性的两条路线
  
**辨析**：两条路线的优劣比较需结合具体负载，不存在绝对优劣
  
**文献**：McKusick “Soft Updates vs Journaling”(BSDCon 2000)；ext3 设计文档；ReiserFS 论文 ［B］
