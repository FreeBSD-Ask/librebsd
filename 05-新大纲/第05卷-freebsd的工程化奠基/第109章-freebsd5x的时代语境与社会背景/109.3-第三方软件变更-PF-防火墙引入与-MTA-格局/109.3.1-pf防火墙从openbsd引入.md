# 109.3.1 PF 防火墙从 OpenBSD 引入

  **要点**：FreeBSD 5.3-RELEASE（2004 年 11 月，release/5.3.0 tag 为 2004-11-04，发布日区分见辨析段）正式从 OpenBSD 导入 PF（Packet Filter）防火墙，作为 IPFilter 的替代选择。PF 由 Daniel Hartmeier（丹尼尔·哈特迈尔） 为 OpenBSD 设计，随 OpenBSD 3.0（2001 年 12 月 1 日）首次发布，其设计动机源于 IPFilter 许可证争议——2000 年 Darren Reed（达伦·里德） 修改 IPFilter 许可证条款，导致 OpenBSD 将其从源码树移除，Hartmeier 从头编写 PF 作为替代。PF 支持状态检测（stateful inspection）、NAT/NAPT、ALTQ 流量整形、pfsync 状态同步、authpf 用户认证等特性，FreeBSD 移植由 Max Laier 主导完成，将 PF 从 OpenBSD 的 pf(4) 源码适配到 FreeBSD 内核（导入提交的哈希与时间戳移见史料与文献字段）。FreeBSD 5.3 同时保留 IPFilter 与 PF，用户可选其一作为防火墙；PF 在后续版本中性能和功能持续改进，逐步成为 FreeBSD 社区首选防火墙。IPFilter 最终在 FreeBSD 10.0（2014 年 1 月 20 日）从 base system 移除，PF 延续至今作为 FreeBSD 的三款内置防火墙之一（PF、IPFW、IPFilter 共存至 10.0）。
  
**史料**：FreeBSD 5.3-RELEASE Announcement（release/5.3.0 tagger_date = 2004-11-04T19:12:42Z，明确 PF 导入）、OpenBSD 3.0 Release Notes（2001.12.1，PF 首次发布）、Daniel Hartmeier BSDCon 2002 论文 “The Design and Implementation of the OpenBSD Packet Filter (PF)”、Max Laier PF 移植提交记录（freebsd.duckdb freebsd-src 仓库 commits 表 commit_hash = 32b30983561ed562aa495d8e124488ab94b332aa，committer_date = 2004-06-16T23:03:14Z，author = Max Laier，message_subject = “Import pf from OpenBSD 3.5 (OPENBSD_3_5_BASE)”）；freebsd.duckdb freebsd-src 仓库 tags 表 release/5.3.0 的 tagger_date = 2004-11-04T19:12:42Z（target_commit_hash = f8d4987d7271c1003cce92715022709505f995c7） ［A］
  
**史观**：总纲第 4 条——分离聚合是永恒规律：PF 从 OpenBSD 到 FreeBSD 的移植是 BSD 家族内部代码共享的典型案例——OpenBSD 因许可证问题移除 IPFilter 后编写 PF，FreeBSD 因 PF 的技术优势将其移植，两个 BSD 项目在防火墙领域的代码流动体现了 BSD 社区 “择优而用” 的务实传统；总纲第 13 条——法律与道德是利益分配：IPFilter 许可证争议是 PF 诞生的直接催化剂，也是 BSD 社区对许可证问题敏感的早期例证
  
**辨析**：经 freebsd.duckdb tags 表验证，5.3-RELEASE 的 tagger_date 为 2004-11-04T19:12:42Z（非旧叙事 2004.11.6，误差 2 天，可能为公告日期与 tag 日期差异）；经 freebsd.duckdb commits 表验证，PF 导入 commit 为 2004-06-16T23:03:14Z Max Laier “Import pf from OpenBSD 3.5 (OPENBSD_3_5_BASE)”（早于 5.3-RELEASE 约 4.5 个月，属 5.3-CURRENT 开发周期）；需区分 PF 的 “创建” 与 “引入 FreeBSD” 两个时间点——PF 创建于 OpenBSD（2001），FreeBSD 在 5.3（2004）引入，引入时已非 PF 首个版本；FreeBSD 的 PF 移植与 OpenBSD 主线的 PF 在后续发展中逐步分化——OpenBSD 持续改进 PF（如 4.1 引入 pfsync 改进、4.3 引入 address pool 等），FreeBSD 的 PF 在 5.3 后也经历了多 CPU 性能优化（10.x 细粒度锁定）、VIMAGE 支持等差异化改进，但 FreeBSD 的 PF 版本长期落后于 OpenBSD 最新版本；部分资料称 “FreeBSD 5.3 用 PF 取代 IPFilter”——经 Release Notes 核实，5.3 是同时提供 PF 和 IPFilter，而非替代，IPFilter 保留至 10.0 才移除
