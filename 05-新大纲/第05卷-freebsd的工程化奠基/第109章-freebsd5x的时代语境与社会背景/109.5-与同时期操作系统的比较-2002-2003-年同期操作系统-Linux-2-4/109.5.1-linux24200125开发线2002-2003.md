# 109.5.1 Linux 2.4（2001）/ 2.5 开发线（2002-2003）

  **要点**：Linux 2.4（2001.1）是稳定的服务器内核，2.5 开发线（2002-2003）引入 O(1) 调度器、抢占式内核、反向映射 VM 等，演进为 2.6（2003.12）；2002-2003 年 Linux 在内核可扩展性上快速进步，而 FreeBSD 5.x 的 SMPng（细粒度 SMP）仍在整合期，性能与稳定性波动较大，社区出现 “5.x 不如 4.x 快” 的批评。
  
**史料**：Linux 2.4/2.6 发布说明（2001/2003）；2.5 变更日志（O(1) 调度器等）［B］；FreeBSD 5.x 性能讨论邮件列表 ［C］
  
**史观**：总纲第 5 条——没有必然性，只有偶然性：SMP 现代化不存在必然的单一路径——FreeBSD 5.x 的长期阵痛与 Linux 2.5→2.6 的相对平滑，均系各自人力分布与架构债务等偶然条件的产物（原挂“总纲第 25 条——终结与延续”，基线第 25 条为“逻辑是形式主义而非世界本身的结构”，按权威表改挂——2026-09-12 整改）。
  
**辨析**：将 5.x 早期性能问题等同于 “FreeBSD 衰落” 是片面——5.x 的架构债务清理为 6.x/7.x 的性能回升奠定基础；Linux 2.5 同样经历开发期不稳定。
  
**文献**：Torvalds L. Linux 2.6 ChangeLog [EB/OL]. 2003；McKusick M K, Neville-Neil G. The Design and Implementation of the FreeBSD Operating System [M]. Addison-Wesley, 2004. ［B］
