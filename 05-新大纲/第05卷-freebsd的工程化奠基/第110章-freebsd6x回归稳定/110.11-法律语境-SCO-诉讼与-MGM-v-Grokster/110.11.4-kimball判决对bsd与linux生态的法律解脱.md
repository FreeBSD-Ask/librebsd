# 110.11.4 Kimball 判决对 BSD 与 Linux 生态的法律解脱

  **要点**：Kimball 判决对 BSD 与 Linux 生态的法律解脱：（1）解除 Linux 版权威胁；（2）BSD 因 USL v. BSDi 已有先例；（3）企业重新放心使用开源。
  
**史料**：USL v. BSDi 和解文件（L3 官方文档）；企业采购数据（L4 事后统计）
  
**史观**：总纲第 13 条——法律与道德是利益分配：USL v. BSDi 先例已一次性分配了 BSD 侧的版权利益，Kimball 判决改变的只是 Linux 侧的利益格局
  
**辨析**：BSD 对 Kimball 判决的“受益”是间接的——其法律确定性早已由 USL v. BSDi 和解与 4.4BSD-Lite 授权安排建立，判决消除的是 Linux 侧的版权威胁；企业因此重估“UNIX 系开源”的整体风险，属市场信心层面的传导效应而非 BSD 法律权利的变化。
