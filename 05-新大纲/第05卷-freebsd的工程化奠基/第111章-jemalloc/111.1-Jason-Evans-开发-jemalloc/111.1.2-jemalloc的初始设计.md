# 111.1.2 jemalloc 的初始设计

  **要点**：jemalloc 初始设计目标：（1）减少碎片；（2）多线程扩展性；（3）可预测性能。核心设计为 arena 分配架构（每线程或每 CPU 一个 arena）与 extent 分级策略。
  
**史料**：Evans BSDCan 2006 jemalloc 演讲、jemalloc 源码 ［A］
  
**史观**：专题语（不设总纲条号）——抽象克制与工程取舍：arena 分级以克制的形式化设计换取可预测性能
  
**辨析**：设计是否受 Hoard 影响，需查 Evans 引用
  
**文献**：Evans, J. A Scalable Concurrent malloc(3) Implementation for FreeBSD BSDCan 2006 Proceedings，**<https://www.bsdcan.org/2006/papers/jemalloc.pdf>**；Berger, E. D. et al. Hoard: A Scalable Memory Allocator for Multithreaded Applications ACM SIGPLAN Notices 35(11), 2000, pp. 117-128 ［B］
