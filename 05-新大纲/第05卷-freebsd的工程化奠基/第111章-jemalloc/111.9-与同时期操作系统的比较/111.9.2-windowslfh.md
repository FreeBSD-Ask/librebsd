# 111.9.2 Windows LFH

**要点**：Windows LFH（Low Fragmentation Heap，Vista 引入 2006）是 Microsoft 对碎片问题的回应；与 jemalloc 路线不同（LFH 修改现有 heap，jemalloc 完全重写）。

**史观**：总纲第 4 条——分离聚合是永恒规律：LFH 改造现有堆与 jemalloc 另起炉灶，是同一碎片问题在不同谱系内分化出的两条路线

**辨析**：LFH 与 jemalloc 的优劣缺少同条件公开基准——LFH 以降低碎片为目标、jemalloc 以多核扩展为目标，设计目标不同使结论不可直接互换，须分场景测试。
