# 111.9.1 Linux ptmalloc 与 Solaris libumem

**要点**：Linux ptmalloc（基于 Wolfram Gloger 的 ptmalloc2）与 Solaris libumem（主要实现者 Mike Shapiro，其 slab 与 vmem 机制思想源自 Jeff Bonwick（杰夫·邦威克））是同期主流分配器；ptmalloc 多线程扩展性弱，libumem 性能优秀但仅限 Solaris 平台。 [存疑脚注] libumem 的用户态实现主要由 Mike Shapiro 完成，Bonwick 系 slab 分配器（USENIX 1994）与 magazines/vmem 机制（USENIX 2001）的原创者，实现者与思想源头的归属以一手文献为准。

**史料**：glibc 源码树 malloc.c（ptmalloc2 实现与注释）；OpenSolaris usr/src/lib/libumem 源码与 man 3 libumem 手册页［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档〕

**史观**：总纲第 8 条——本体论上各方平等：各操作系统的分配器路线互为参照系，不以单一生态的市场地位预设优劣

**辨析**：jemalloc 与二者优劣须以基准测试回答——据 Evans（BSDCan 2006），jemalloc 的多线程扩展性优于 ptmalloc 的 per-thread arena 设计，与 libumem 同属 slab 系但缺少同环境对照数据，架构推断不能替代实测。
