# 111.3.1 FreeBSD 7.0 默认集成

  **要点**：FreeBSD 7.0(2008.2.24，release/7.0.0 tagger_date = 2008-02-24T05:45:17Z，tagger = cvs2svn) 将 jemalloc 集成为默认 libc 内存分配器，替代 phk malloc；理由是多线程性能优势与碎片减少；jemalloc 集成工作早至 2006 年 5 月已在 7-CURRENT 中进行（Bruce A. Mah 2006-05-22 commit “New release notes: ipfwpcap(8), jemalloc” 已将 jemalloc 列入 7.0 release notes），2008 年 2 月 24 日随 7.0-RELEASE 正式发布；2012-04-17 Jason Evans 再次 import jemalloc 3.0.0 dev 分支至 contrib/jemalloc 并重新集成至 libc（commit_hash = a4bd5210d5e680818a9319a76ebf71caef95bcd3），代码自 2010 年 3 月从 lib/libc/stdlib/malloc.c 分叉
  
**史料**：FreeBSD 7.0 Release Notes、commit log；freebsd.duckdb freebsd-src 仓库 tags 表 release/7.0.0 的 tagger_date = 2008-02-24T05:45:17Z（target_commit_hash = ba209d619d07461cc752dcdd596ab0d9b50e847a）；freebsd.duckdb freebsd-src 仓库 commits 表 Bruce A. Mah 2006-05-22 commit “New release notes: ipfwpcap(8), jemalloc”（committer_date = 2006-05-22T20:18:04Z）；freebsd.duckdb freebsd-src 仓库 commits 表 Jason Evans 2012-04-17 import jemalloc commit（commit_hash = a4bd5210d5e680818a9319a76ebf71caef95bcd3，committer_date = 2012-04-17T07:22:14Z）；freebsd.duckdb freebsd-src 仓库 contributors 表 Jason Evans 共 317 commits，首次 commit 1999-05-07，末次 2019-11-11 ［A］
  
**史观**：BSD 与 UNIX 谱系的连续性
  
**辨析**：经 bsd_commits.duckdb tags 表验证，7.0-RELEASE 的 tagger_date 为 2008-02-24T05:45:17Z（非旧叙事 2008.2.27，误差 3 天，可能为公告日期与 tag 日期差异）；jemalloc 在 7-CURRENT 开发周期（早至 2006-05-22）已集成，但正式发布为 7.0-RELEASE；2012 年 jemalloc 3.0.0 import 是代码重组（lib/libc/stdlib/malloc.c → contrib/jemalloc），并非首次集成；是否真比 phk malloc 优，需查基准测试
