# 115.5.2 新栈的设计与效应

  **要点**：新 USB 栈的设计：(1) 模块化驱动；(2) USB 2.0（EHCI/OHCI/UHCI）全量支持，USB 3.0 xHCI 系后续版本（FreeBSD 12.0 合入 base）；(3) 改善设备兼容性；(4) 性能提升
  
**史料**：commit log、Release Notes ［A］
  
**史观**：专题语（不设总纲条号）：模块化增加灵活但增加复杂度
  
**辨析**：性能提升幅度，需查基准测试——PODCAST_REVIEW 块载实测：大容量存储新栈与 Linux 相当、旧栈落后约 2-5%；USB Ethernet 凭 IO 向量突破中断率瓶颈；正式撰写仍须对照基准测试
  
**文献**：FreeBSD 8.0 src/sys/dev/usb/ commit log；Selasky, H. P. EuroBSDCon 2009 USB talk；FreeBSD 8.0-RELEASE Release Notes ［A］
