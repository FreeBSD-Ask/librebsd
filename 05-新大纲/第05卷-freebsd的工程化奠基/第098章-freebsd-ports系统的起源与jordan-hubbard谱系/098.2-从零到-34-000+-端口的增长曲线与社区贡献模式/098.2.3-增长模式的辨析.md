# 098.2.3 增长模式的辨析

  **要点**：Ports 指数增长背后存在质量问题，部分 port 因 upstream 消失或缺乏维护而 broken，2005 年引入 expire-ok 机制自动清理长期 broken 的 port，反映“增长 vs 质量”的张力
  
**史料**：freebsd-ports 邮件列表关于 broken port 清理的讨论、Ports Quarterly Report 中 broken 统计、expire-ok 机制 commit log ［A］
  
**史观**：形式主义膨胀〔订正注：原误挂总纲第 3 条，权威 3=不存在进步只有权力再分配，去号〕，Port 数量的形式主义增长可能掩盖质量衰退
  
**辨析**：broken port 的定义标准在不同时期不同，1998 年与 2008 年的 broken 判定阈值存在差异
  
**文献**：Ports Quarterly Report；freebsd-ports 邮件列表；expire-ok 机制文档 ［A］
