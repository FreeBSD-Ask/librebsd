# 098.2.2 社区贡献模式

  **要点**：Ports 社区贡献模式以 maintainer 制度为核心，每个 port 由 1-3 名 maintainer 维护，无 maintainer 的 port 由 ports-secteam 集体维护，新 port 通过 submit PR 提交，committer 评审后导入，形成约 500 名活跃 maintainer 与 100 名 committer 的贡献金字塔
  
**史料**：freebsd-ports 邮件列表、GNATS/Bugzilla PR 数据库、Maintainers Guide 各版本、Ports Committer 指南 ［A］
