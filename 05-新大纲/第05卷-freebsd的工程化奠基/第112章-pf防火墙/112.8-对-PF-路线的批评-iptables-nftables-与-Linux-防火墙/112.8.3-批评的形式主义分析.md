# 112.8.3 批评的形式主义分析

**要点**：批评形式主义分析：(1) 工程否定是否公平（技术 vs 非技术因素）；(2) 边缘化是否可逆；(3) 批评是否促进 PF 改进

**史料**：邮件、博客 ［C］

**史观**：形式主义膨胀与抽象克制

**辨析**：批评效果，需查 PF 是否因批评而改进跨平台能力

**文献**：freebsd-pf mailing list PF criticism response (2005-2010)；netfilter-devel mailing list nftables justification (2012-2014)；LWN.net PF vs nftables discussion (2014) ［A］
