# 112.3.2 开源合规质疑的爆发

**要点**：OpenBSD 团队（Theo de Raadt（西奥·德·若特） 等）于 2001 年公开质疑 IPFilter 许可证合规性，认为修改后的措辞不符合 OpenBSD 的许可证政策；OpenBSD 3.0（2001.12）移除 IPFilter 并以 PF 替代
