# 112.0.8 核心内容

### 史观映射

> PF 从 OpenBSD 流入 FreeBSD，再流入全 BSD 生态——代码不在乎项目的旗帜，只在乎许可证是否允许、接口是否兼容。这种跨项目流动是 BSD 生态独有的共享性，但共享性不等于话语权：Adam 与 Tablo 的论文证明 iptables 在大多数场景下过滤速度快于 PF，Linux netfilter 社区宁可自建 nftables 也不移植 PF，Red Hat 的博客列举 iptables 的架构局限时对 PF 只字未提——“我们不采用你的方案”比“你的方案不好”是更彻底的否定

### 辨析（2026-08-14 双库核查）

- “PF 从 OpenBSD 流入 FreeBSD”经邮件列表库验证：freebsd 列表 2003 年已有 pf4freebsd port 与 OpenBSD pf 移植记录（MAIL_MINE 线索：2003 ports/52121《pf4freebsd port OpenBSD's pf ported》），与章节索引 102.1 记“2004 年移植”大体一致。
- “Adam 与 Tablo 论文证明 iptables 过滤速度快于 PF”（Massimiliano Adamo 与 Mauro Tablo，USENIX login）经两库检索未获直接验证，保留原述并标注待外部核验。
- “Darren Reed（达伦·里德） 修改 IPFilter 许可证措辞”经邮件列表库验证 Darren Reed 于 FreeBSD 列表活跃（<darrenr@freebsd.org>，2016/2018 邮件），但 2001 年许可证争议原文两库无法直接验证，保留原述。
