# 097.3.3 Ports 社区贡献模式

  **要点**：Ports 采用 maintainer 字段标识每个 port 的维护者，社区通过 send-pr 工具提交 port 新增与更新请求，committer 评审后提交至 CVS，形成 “维护者-评审者-提交者” 三级贡献链，这一模式延续至今
  
**史料**：freebsd-ports 邮件列表 1995-1998 年 PR 流程记录、send-pr(1) 手册页、Maintainer's Guide 早期版本 ［A］
  
**史观**：社区治理，Ports 的 maintainer 制度是 FreeBSD 社区从精英评审向分布式维护演化的早期实验
  
**辨析**：早期 maintainer 字段是否强制要求存在争议，1996 年前后才形成 “无 maintainer 的 port 视为孤儿” 的规范
  
**文献**：FreeBSD Porter's Handbook 中 “Maintaining a Port” 章节；Hubbard “The Ports Collection”(Daemon News 1997)；freebsd-ports 邮件列表 FAQ ［A］
