# 097.11.3 syslogd/master.passwd/procfs 漏洞与 MFC 安全回溯模型——服务层与权限层中低风险漏洞群

  **要点**：FreeBSD-SA-96:08.syslog（1996 年 4 月 21 日）记录 **syslogd(8)** 守护进程漏洞可能导致系统日志服务异常，受影响版本为 FreeBSD 2.0、2.0.5；1997 年 2 月 8 日 John Polstra 提交 commit `f5491fc795b1f44ac01ab139a3fd53ffc6070457`（"Security fix. Strip the encrypted passwords out of the master.passwd diff output"——从 master.passwd diff 输出中剥离加密密码，防止密码泄漏）；1997 年 8 月 25 日 Guido van Rooij 提交 commit `83dea3e840ff107d01337374c6547e99294d1967`（“MFC: procfs security patch. 2.1's not dead! Long live 2.1 ;-”——procfs 安全补丁 MFC 回溯至 2.1 分支，commit subject 中的感叹反映 2.1 分支仍被维护的事实）；1996 年 4 月 26 日 Joerg Wunsch 提交 commit `711e38f8ed0a78cbe86f57d7a59d31eebb7d67c3`（"/etc/skeykeys was basically suffering from the same vulnerability as any non-shadowed /etc/passwd"——S/Key 密钥文件存在与非影子 /etc/passwd 相同的漏洞）；上述漏洞覆盖日志服务（syslogd）、密码文件（master.passwd）、进程文件系统（procfs）、认证密钥（skeykeys）四类组件，属于中低风险级别，通过 MFC（Merge From Current）机制从 -current 分支回溯至 2.1/2.2 稳定分支
  
**史料**：FreeBSD-SA-96:08.syslog 公告、freebsd.duckdb freebsd-src 仓库 security fix commit 记录（John Polstra 1997-02-08、Guido van Rooij 1997-08-25、Joerg Wunsch 1996-04-26）［A］
  
**史观**：密码学与信息安全：syslogd/master.passwd/procfs/skeykeys 漏洞群覆盖服务层与权限层，反映 FreeBSD 2.x 安全基线的多层缺陷；组织结构塑造技术路径：MFC 回溯机制是 FreeBSD 2.x 安全响应的工程基础
  
**辨析**：syslogd 漏洞的具体机制须对照 FreeBSD-SA-96:08.syslog 公告原文核实——公告仅称 “可能导致系统日志服务异常”，未详细说明触发路径；master.passwd diff 密码剥离修复的上下文须对照 John Polstra 1997-02-08 commit diff 核实——该修复针对 master.passwd 变更输出中加密密码的泄漏风险；procfs 安全补丁的具体内容须对照 Guido van Rooij 1997-08-25 commit diff 核实——commit subject 仅称 “procfs security patch” 未说明漏洞机制；【0 信任原则·MFC 回溯的时序】MFC commit 的 author_date 为 MFC 操作时间而非原始修复时间，原始修复须在 -current 分支中查找对应 commit，史家须区分 “原始修复时间” 与 “MFC 回溯时间” 两个时点；【0 信任原则·commit subject 信息量限制】部分 commit subject（如 “YAMFC (security enhancements)”、“YAMFC (security fixes and buffer overruns)”）仅标注为 YAMFC（Yet Another MFC）附带安全修复，未说明具体漏洞机制，史家须对照 commit diff 核实
