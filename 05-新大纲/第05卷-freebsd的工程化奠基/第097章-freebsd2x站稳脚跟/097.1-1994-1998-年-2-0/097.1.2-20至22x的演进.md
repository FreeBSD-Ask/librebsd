# 097.1.2 2.0 至 2.2.x 的演进

  **要点**：2.1(1996.1.1)、2.1.5(1996.10.6)、2.1.7(1997.3.11)、2.2.0(1997.3.17)、2.2.x 系列延续至 1999.1.21（2.2.8-RELEASE），期间逐步引入 sendfile、dummynet、IPFW 第二代规则语法，并稳定了 SCSI 子系统与 PCI 总线支持，是 FreeBSD 从研究性系统转向生产级系统的关键演进期

  FreeBSD 2.x 版本发布时间线（freebsd.duckdb `tags` 表验证）：

**史料**：FreeBSD 2.1/2.1.5/2.1.7/2.2 Release Notes、CVS 仓库 releng/2.1 与 releng/2.2 分支、freebsd-stable 邮件列表 1995-1998 年归档；freebsd.duckdb `tags` 表 `release/2.0.5` tagger_date = 1995-06-10T19:44:55Z、`release/2.1.0`/`release/2.1.0_cvs` tagger_date = 1996-01-01T11:01:15Z、`release/2.1.5` tagger_date = 1996-10-06T07:58:04Z、`release/2.1.7` tagger_date = 1997-03-11T00:08:01Z、`release/2.2.0` tagger_date = 1997-03-17T04:05:04Z、`release/2.2.5` tagger_date = 1997-10-21T01:56:05Z、`release/2.2.8` tagger_date = 1999-01-21T00:55:30Z ［A］
  
**史观**：终结与延续，2.2.x 既是 2.x 系列的终结，也是 3.x SMP 时代的铺垫，releng 分支机制在此期间成型并延续至今
  
**辨析**：经 freebsd.duckdb `tags` 表验证，2.1.0 实际 tagger_date = 1996-01-01（非旧叙事 ~~“1995.11”~~），2.1.5 实际 tagger_date = 1996-10-06（非 ~~“1996.7”~~），2.1.7 实际 tagger_date = 1997-03-11（非 ~~“1996.11”~~），原大纲日期有误已修正；2.2.0-RELEASE 实际为 1997-03-17 而非笼统 “1997.3”，2.2.8-RELEASE 为 1999-01-21，2.2 系列官方支持终止期应以此为准；2.1 与 2.1.5 之间关系仍需查 Release Engineering 文档以判定 “维护版” 与 “独立版” 性质；经邮件列表库+参考文献库交叉验证（fact-check 2026-08-14），2.2.8-RELEASE 实际公告/发布日为 1998-11-29/30，而非本章表中 1999-01-21——证据：邮件列表库 freebsd-announce Jordan K. Hubbard（乔丹·哈伯德） 公告“2.2.8-RELEASE is now available”Message-ID <26003.912469008@zippy.cdrom.com>（1998-12-01T07:36:48+08:00，即 1998-11-30 UTC）；参考文献库 FreeBSD 官方 Timeline（reference_id=1049，fact_id=6613）“FreeBSD 2.2.8-RELEASE arrived November 29, 1998”。tags 表 `release/2.2.8` tagger_date=1999-01-21 与公告日相差约两个月，疑为 2.2 分支最终关停/再打 tag 所致，正文引用时应以 1998-11-29 为准
