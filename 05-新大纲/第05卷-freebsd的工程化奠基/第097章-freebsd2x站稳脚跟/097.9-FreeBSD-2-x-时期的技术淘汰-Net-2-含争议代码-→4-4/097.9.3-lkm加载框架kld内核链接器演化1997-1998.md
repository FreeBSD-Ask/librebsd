# 097.9.3 LKM 加载框架 → KLD 内核链接器演化（1997-1998）

  **要点**：FreeBSD 2.0-2.1 时期沿用 4.4BSD-Lite 的 LKM（Loadable Kernel Modules）框架，允许内核在运行时加载模块；LKM 框架设计原始，缺少依赖管理、符号解析、自动加载机制，加载模块需手动配置；为支持 DEC Alpha 平台移植（1997 年 5 月 Jordan Hubbard 呼吁志愿者，Doug Rabson（道格·拉布森） 自愿承担），Doug Rabson 设计新的 KLD（Kernel Linker）框架取代 LKM；KLD 引入自动符号解析、模块依赖跟踪、/boot/loader 预加载能力；KLD 在 FreeBSD 3.0-RELEASE（1998.10）成为默认内核模块框架，但开发始于 2.x 末期（1997.5）；KLD 为后续 5.x 时期内核模块化（如 devfs、**mac(4)**）奠定基础
  
**史料**：Doug Rabson “Early FreeBSD Ports”（FreeBSD Foundation 2023）；FreeBSD 3.0-RELEASE Release Notes；Doug Rabson 在 freebsd-hackers 与 freebsd-alpha 邮件列表 1997-1998 年关于 KLD 设计的讨论；freebsd.duckdb `commits` 表 KLD 首次 commit：author = Doug Rabson，author_date = 1997-05-07T16:05:47Z，commit_hash = cea6c86c11f5264ab880e5d253986982d5644dd0，message = "This is the kernel linker. To use it, you will first need to apply the patches in freefall:/home/dfr/ld.diffs to your ld sources and set BINFORMAT to aoutkld when linking the kernel."；同日 commit e8ec170c35c23c431330deb927b92c79be223350 添加 syscalls，commit a79fe60755523cab06086c7a032a326f247b7424 添加 utilities ［A］
  
**史观**：边缘者贡献：Doug Rabson 作为 Alpha 移植驱动者，其 KLD 设计影响后续整个 FreeBSD 内核模块化方向；技术选择的代价：KLD 引入付出向后不兼容代价（LKM 模块需重写为 KLD），但获得更强的模块管理能力
  
**辨析**：经 freebsd.duckdb `commits` 表验证〔订正注：2026-09-14 原 bsd_commits.duckdb 系旧名/异名，统一为 freebsd.duckdb〕，KLD 首次合入主干时间为 1997-05-07（commit cea6c86c11f5264ab880e5d253986982d5644dd0），早于 Doug Rabson 自述的 “late 1997”，可见原型在 1997 年春季已就绪；自 1997-05-07 至 3.0-RELEASE（1998.10）的 17 个月为 LKM 与 KLD 共存期，3.0-RELEASE 后 KLD 成为默认；KLD 与 Linux kernel modules 的设计差异需对照源码核验，KLD 强调符号自动解析与依赖跟踪，Linux 模块框架在 2.4 时期（2001）才引入类似依赖管理
