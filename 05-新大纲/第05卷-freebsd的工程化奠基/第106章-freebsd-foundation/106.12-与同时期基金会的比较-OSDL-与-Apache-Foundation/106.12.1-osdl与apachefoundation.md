# 106.12.1 OSDL 与 Apache Foundation

  **要点**：OSDL(Open Source Development Labs, 2000) 与 Apache Software Foundation(1999) 是同期开源基金会，二者治理路径不同：OSDL 以企业成员为主，Apache 以个人成员为主；FreeBSD Foundation 选择个人主导路径
  
**史料**：OSDL 历史文档、Apache Foundation By-Laws、Linux Foundation 历史 (2007 OSDL+FSG 合并) ［A］
  
**史观**：总纲第 4 条——分离聚合是永恒规律，BSD 与 UNIX 谱系的连续性与 Apache 路径的相似性（原挂第 7 条系自撰名目，按赓续谱系论旨改挂第 4 条）
  
**辨析**：FreeBSD Foundation 选择是否真受 Apache 影响，需查早期邮件
  
**文献**：Apache Foundation By-Laws；OSDL 文档 ［A］
