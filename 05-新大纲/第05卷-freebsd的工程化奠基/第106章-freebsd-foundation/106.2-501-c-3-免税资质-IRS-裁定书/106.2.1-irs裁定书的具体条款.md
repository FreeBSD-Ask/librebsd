# 106.2.1 IRS 裁定书的具体条款

  **要点**：IRS 于 2000.12.7 签发 Determination Letter 授予 FreeBSD Foundation 501(c)(3) 公共慈善实体身份 (509(a)(1))，条款要求基金会遵守：(1) 仅用于免税目的；(2) 不参与政治竞选；(3) 无私人利益分配；(4) 解散时资产转交同类组织
  
**史料**：IRS Determination Letter 全文、Form 1023 申请材料、Foundation 501(c)(3) 资格公开文件［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档〕
  
**史观**：BSD 与 UNIX 谱系的连续性，501(c)(3) 身份使基金会可比拟其他开源基金会
  
**辨析**：501(c)(3) 与 509(a)(1) 的区别需准确表述，前者是免税类别后者是公共慈善子类
