# 116.1.2 技术路线分化比较

  **要点**：虚拟化路线分化：(1) FreeBSD jails（轻量容器）+ XEN domU（半虚拟化）+ VNET（网络虚拟化）；(2) Linux KVM（全虚拟化）+ Xen（半虚拟化）+ LXC（容器）；(3) Solaris Zones（容器）+ Crossbow（网络虚拟化）；(4) Windows Hyper-V（全虚拟化）

  2009-2011 年同期操作系统虚拟化路线对照：

  | 操作系统 | 容器技术 | 半虚拟化 | 全虚拟化 | 网络虚拟化 | 路线特征 |
| ------ | ------ | ------ | ------ | -------- | ------ |
| FreeBSD 8.x | jails（2000） | XEN domU | 无 | VNET | 轻量容器 + 半虚拟化，无 dom0 |
| Linux 2.6.30-3.0 | LXC/cgroups | Xen | KVM（2007） | veth/netns | 多路线并行，KVM 主导 |
| Solaris 11 Express | Zones（2004） | 无 | 无 | Crossbow | 容器成熟，与网络虚拟化集成 |
| Windows Server 2008 R2 | 无 | 无 | Hyper-V R2 | 无 | Type-1 hypervisor 主导 |
