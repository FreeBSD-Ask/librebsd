# 104.1.4 设计史料辨析

  **要点**：kqueue 设计史料的争议点包括：(1) Lemon 是否独立于 Banga 的 /dev/poll 工作；(2) 设计灵感是否部分来自 Solaris /dev/poll；(3) commit 时间与 BSDCon 论文时间的先后
  
**史料**：FreeBSD svn r61973(2000.7.5) commit、BSDCon 2000 论文 (2000.10)、Banga /dev/poll(1998) ［A］；freebsd.duckdb 查询 L2.2.1.sys_kern 显示：freebsd-src sys/kern/ 年度 commit 量——1999 年 2,506 条/130 文件、2000 年 2,154 条/143 文件、2001 年 2,182 条/148 文件、2002 年 3,495 条/164 文件，kqueue 引入的 2000 年 sys/kern commit 量（2,154 条）较 1999 年（2,506 条）略有下降，反映 kqueue 作为单个特性未显著改变 sys/kern 整体 commit 规模；freebsd.duckdb 数据库交叉印证——统计结论 C-03 freebsd-src 仓库总 commit 数 444,203 条（`SELECT COUNT(*) FROM commits WHERE repo_name='freebsd-src'`），kqueue 首次 commit（2000-04-16）至 4.1 发布（2000-07-26 公告）期间约 3 个月的 commit 分布为此累计量的早期段；统计结论 C-12 freebsd-src 变点检测 1999-08（Pettitt 与 BUISHAND 双检验一致 p < 0.001），距 2020-01 SVN-to-Git 迁移 245 个月，判定为非迁移伪变点，1999-08 距 kqueue 首次 commit（2000-04-16）约 8 个月，变点反映 kqueue 开发期所属的 3.x 维护期向 4.x 黄金时期切换的工程节律结构性转变，为 kqueue 的孕育与发布提供了 commit 时序上的工程背景；Python 脚本 `script/phase2_inferential.py` Task 6（Pettitt 自实现 + BUISHAND R 自实现），查询日期 2026-07-27 ［B］
  
**史观**：0 信任原则，对一手 commit 与论文仍需交叉验证时间线；统计结论印证——C-12 变点 1999-08 距 kqueue 首次 commit 约 8 个月，与项目史观总纲第 25 条 “分离聚合是永恒规律” 映射：3.x 维护期的终结（分离）与 4.x 黄金时期的兴起（聚合）在 commit 时序上形成可检测的变点，kqueue 作为 4.1 标志性特性的诞生嵌入这一工程节律切换，统计变点检测为史观中的 “分离聚合” 提供量化印证
  
**辨析**：Lemon 论文致谢未提 Banga，但 **kqueue(2)** 手册页 “SEE ALSO” 列了 Banga 论文，二者关系需谨慎定性；freebsd.duckdb 查询 L2.3.1.kqueue（kqueue 特性引入到稳定周期前 20 条 commit）在已读取的中观模式挖掘报告中未找到对应数据段落，kqueue 特性的 commit 级稳定周期数据存疑，待后续直接查询数据库补充；39.1.1 节已通过 commits 表直接查询获取 kqueue 首次 commit（2000-04-16）数据，部分弥补 L2.3.1.kqueue 查询缺失；【0 信任原则·SVN-to-Git 迁移】L2.2.1.sys_kern 数据基于 2020 年 SVN-to-Git 迁移后的仓库，sys/kern 路径匹配 sys/kern% 可能漏掉重命名后的文件，须与 SVN 时代邮件列表存档交叉验证；**统计局限性标注**——统计显著 ≠ 实际显著，C-12 变点 p < 0.001 仅反映 commit 时序存在结构性断点，不等于 kqueue 的诞生 “导致” 了变点，变点为工程节律切换的统计表征而非 kqueue 工程因果；C-12 双检验一致性（Pettitt 与 BUISHAND）降低单一方法偏差但不可消除方法学局限；变点距 2020-01 SVN-to-Git 迁移 245 个月，已排除迁移伪变点假设，但 1999-08 仍可能受 Y2K 准备期、互联网泡沫期 ISP 需求激增等同期外部因素干扰，单一归因于 3.x/4.x 转型存在简化风险；C-03 freebsd-src 444,203 commits 为全周期（1993-2026）累计，非 kqueue 开发期单段统计，跨时期引用时须注意；0 信任原则适用——`freebsd.duckdb` kqueue 开发期（2000）commit 数据完整但 2008 CVS→SVN 与 2020 SVN→Git 两次迁移可能引入日期偏差与作者归属错误，须与 SVN 时代邮件列表存档交叉验证；多重比较风险——本卷 16 章跨章引用 C-03 与 C-12 时存在多重比较风险，已在辨析字段标注
