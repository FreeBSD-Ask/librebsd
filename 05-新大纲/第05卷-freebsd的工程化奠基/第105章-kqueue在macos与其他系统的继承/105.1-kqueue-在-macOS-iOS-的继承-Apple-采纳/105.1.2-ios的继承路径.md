# 105.1.2 iOS 的继承路径

  **要点**：iOS 自 1.0(2007.6) 即继承 macOS 的 kqueue/kevent 实现，因 iOS 内核基于 Darwin，所有 BSD 子系统 (包括 kqueue) 被一并移植，但 iOS 沙盒限制第三方 App 直接调用 kqueue，主要通过 libdispatch/GCD 间接使用
  
**史料**：iOS 系统架构文档、libdispatch 源码中 kevent 调用、Apple Developer iOS App Sandbox 指南 ［A］
  
**史观**：偶然性改写历史，iOS 继承 kqueue 是 Darwin 内核选择的副产品而非主动决策
  
**辨析**：iOS 沙盒是否完全禁止第三方 kqueue 调用，需查 sandboxd 配置
