  **要点**：边缘者史料的疑点：(1) 边缘贡献者是否被 commit log 充分记录；(2) 测试用例贡献者是否应计入设计贡献；(3) kqueue 移植到其他 BSD 的贡献者归属
  
**史料**：FreeBSD commit log 中的 contributors 列表、NetBSD/DragonFly 移植 commit ［A］
  
**史观**：0 信任原则，commit log 不一定能反映全部贡献
  
**辨析**：测试用例贡献者是否计入，需查 FreeBSD 项目贡献认定规范
