# 105.6.1 select/poll 与 kqueue 的比较

  **要点**：2000 年前后 select/poll 与 kqueue 的比较维度：(1) 复杂度 O(N) vs O(1)；(2) FD_SETSIZE 限制 vs 无限制；(3) 状态保持 vs 每次注册；(4) filter 抽象 vs 原始 fd
  
**史料**：Lemon BSDCon 2000 论文对比表、Stevens《UNIX Network Programming》第 6 章、FreeBSD kqueue(2) 手册页 ［A］
  
**史观**：实践先于理论，kqueue 的 stateful 设计源于实际 Web 服务器场景
  
**辨析**：Lemon 论文的 select/poll 测试是否在同一硬件上，需查测试环境
