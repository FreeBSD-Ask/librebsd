# 105.6.2 IOCP 与 /dev/poll 的比较

  **要点**：Windows IOCP(1995 NT 3.5) 采用线程池 + 完成端口模型，Solaris /dev/poll(1998)在内核维护就绪列表，二者均为 kqueue 的同期竞争者；IOCP 走异步 IO 路线，/dev/poll 与 kqueue 走同步事件通知路线
  
**史料**：Windows NT IOCP 文档、Banga /dev/poll 论文、Lemon BSDCon 2000 论文对比 ［B］
  
**史观**：BSD 与 UNIX 谱系的连续性，/dev/poll 与 kqueue 同属 UNIX 谱系但路线分野
  
**辨析**：IOCP 与 kqueue 是否可比，需区分异步 IO 与事件通知两个不同模型
  
**文献**：MSDN IOCP 文档；Banga USENIX 1998 ［B］
