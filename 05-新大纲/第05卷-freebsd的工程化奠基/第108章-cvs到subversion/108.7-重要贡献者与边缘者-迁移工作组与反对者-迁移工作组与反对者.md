## 108.7.2 反对者与边缘者

  **要点**：反对者主要来自坚持 Git/Mercurial 的开发者与坚持 CVS 的保守派：前者主张 Git 已成熟应一步到位；后者担忧 SVN 学习成本；边缘者包括 ports 子系统的镜像维护者（ports 在迁移后单独处理）
  
**史料**：邮件、社区讨论［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ [已尝试：FreeBSD SVN migration opponents、freebsd-hackers VCS debate 2008 关键词搜索，freebsd-hackers 与 freebsd-arch 邮件列表存档确认存在但具体反对者名单须逐帖核查，无法在本次复核中确证。]
  
**史观**：话语权与边缘者，反对者话语权与核心团队对比
  
**辨析**：反对者是否被边缘化在 freebsd.duckdb 中无直接证据（邮件是否被忽视不反映在 commit 中），须依赖 freebsd-hackers 与 freebsd-arch 邮件列表 2008 年讨论的回复与引用关系交叉验证
  
**文献**：freebsd-hackers mailing list migration working group (2008)；freebsd-ports mailing list SVN migration (2008)；Wemm, P. SVN migration team (2008) ［A］

## 108.7.4 边缘者史料辨析

  **要点**：边缘者史料疑点：(1) csup（C 语言 cvsup 替代品）开发者；(2) svnup 开发者归属；(3) 文档团队具体成员；(4) 镜像站点协调者
  
**史料**：commit log、邮件 ［A］
  
**史观**：0 信任原则
  
**辨析**：csup 与 svnup 开发者归属在 freebsd.duckdb 中可部分验证——csup 作为 C 语言 cvsup 替代品，其开发者可通过 freebsd-src 仓库 commit 的 message_subject 与 author 字段核查；svnup 开发者归属在 commit 中无直接证据；文档团队具体成员与镜像站点协调者在 commit 中部分可见但角色归属须依赖 freebsd-doc 邮件列表与 freebsd-mirrors 邮件列表交叉验证
  
**文献**：freebsd-hackers mailing list 2008-2010 SVN migration archives；Wemm, P. SVN migration report (2008)；freebsd-doc mailing list documentation migration (2008-2009) ［A］
