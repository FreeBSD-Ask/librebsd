# 103.7.11 总纲22知识注定过时OpenBSD以约350行的doas取代基本系统中滞留多年的

- 总纲22 知识注定过时：OpenBSD 以约 350 行的 doas 取代基本系统中滞留多年的 sudo（旧版约一万行），把 LDAP 等扩展特性连同 sudo 一并降级至 ports；主持人指出基本系统中冻结的软件版本注定落后于上游演进，与其反复审计膨胀的新代码不如重写最小必需实现，man 手册仅一页半与三个命令行旗标即构成“足够好”的边界。承认 base 内知识必然过时、把演化自由让渡给包管理体系，是“知识注定过时”命题的一次工程化演练。（BSD Now EP99，[610.64-681.16]，L2）
- 总纲10 动手者创造历史：SmallWall 的谱系由动手者而非明星人物书写：Lee Sharp 自述当年受教于 monoWall 周边的实践者——Chris 后执掌 pfSense 与 BSD Perimeter，写文档者独立门户，做网络架构者遍及全球——如今他刻意降低开发门槛、把工具与文档摆出来，请有想法的人跳进来，以日常劳动的传递续写项目，而非依赖英雄叙事。 [存疑脚注] 转写将相关人名误作 Michael Adema、Escozia、Jonathan DeGraves 等，准确拼写待核（BSD Now EP97，[1986.33-2023.69]，L1）
- 总纲5 没有必然性，只有偶然性：项目的存在本身即偶然性的产物：没有那份宣布停更的邮件便没有 SmallWall，Lee Sharp 强调少数人 “had the same idea at the same time”（1078.33-1083.33），复活不是历史必然，而是几个用户在同一周内的应急反应；其早期声势亦系于 Slashdot 曝光这类无法规划的事件。（BSD Now EP97，[1031.14-1090.33]，L1）
- 总纲5 没有必然性，只有偶然性：Maxwell 与 NetBSD 的终身结缘并无必然性可言：他自述“我碰巧进入一份对 NetBSD 已有兴趣的工作”（1425.70-1433.73），入职首项任务恰是把 NetBSD 从 0.8 升到 0.9，一次寻常的工作分配把人送进尚处早期的社区并塑造其后数十年职业轨迹；技术史中的个人分岔多由此类偶然事件促成，而非任何先验规划。（BSD Now EP73，[1411.60-1437.82]，L1）
- 总纲10 动手者创造历史：本期技术史细节全由一线动手者承载：KMS/DRM 代码合入 head 依赖 Adrian Chadd 等测试者排障，USB 大容量存储驱动提交留言“先中止各条管道，再释放传输，否则小丑会撞上你”（5055.30-5061.98）记录了一处释放顺序的教训，Dru Lavigne 全职撰写 FreeNAS 文档，Maxwell 自陈其仓库痕迹多为零散 bug 修复与 pkgsrc 小项——BSD 的历史由这类无名修补累积而成。（BSD Now EP73，[5027.40-5073.98]，L3） [订正：原 否则 panic 会找上你，2026-09-30 SenseAudio 重转核对]
- 总纲5 没有必然性，只有偶然性：同一虚拟化机制在作者意图（网络仿真实验台）与社区接收（jail 虚拟主机扩展）之间发生意义转移：技术物的历史角色由使用者群体的偶然需求重新定义，而非由设计初衷单方面决定。（BSDTalk EP130，[156.27-208.36]，L1）
- 总纲4 分离聚合是永恒规律：jail 生态从单一 IP 隔离到多实例网络栈的演进，是同一隔离理念在网络维度上的再分离与再聚合：容器与虚拟网络栈作为可组合的分离单元，经由 NetGraph 拓扑再行聚合，呈现 OS 级虚拟化技术的循环构造而非单向进步。（BSDTalk EP130，[578.73-700.55]，L1）
- 总纲3 不存在进步，只有权力再分配：受访者以亲历者身份描述 FreeBSD 治理：每两年由拥有仓库写权限的提交者选举九人组成 core team，其职能是协调方向、仲裁争论与授予写权限，而非自上而下规定路线，他本人曾任两届；以定期改选的委员会替代单一个人权威，使项目权力以制度化节奏反复再分配，并降低对单个个体倦怠或离场的依赖。（The Changelog EP574，[3971.06-4040.29]，L1）
- 总纲5 没有必然性，只有偶然性：受访者提醒，世纪初 BSD 系统管理员的“硬核”光环与 Linux 的“玩具”标签是可反转的历史建构：当年 BSD 文档反而更完善、托管业务首选 BSD，其后 Linux 经 IBM 数十亿美元投入与对 Red Hat 的收购而成熟，两阵营声望结构在二十年间整体倒置；这一位序变动由诉讼、资本与生态事件等偶然条件叠加而成，并非技术优劣的必然。他另以“Unix 不阻止你做蠢事，因为那也会阻止你做聪明事”概括无护栏设计的代价。（The Changelog EP574，[4680.24]，L2）
- 总纲10 动手者创造历史：Bastille 的模板改进、ZFS 支持与克隆功能均出自社区提交而非作者一人，作者自述不知道如何在非开放环境中构建软件，把开源协作视为其开发能力的构成条件； jails 生态由一代代动手者接续经营，而作者将模板集中化为类似 ports tree 的单一仓库的构想，亦是让后来者更易上手的动手者伦理。（YouTube EPIOUr7Is5FSU，[3312.24-3353.36]，L1）[订正：原“jails 生态由 ezjail、iocage、Bastille 等一代代动手者接续经营”→“jails 生态由一代代动手者接续经营”（转写未提及 ezjail、iocage，仅言曾试用多种其他 jail 管理器而未具名）；另去除重复前缀“动手者创造历史：”] [订正：“模板集中化为类似 ports tree 的单一仓库”之构想出自模板路线图段 [2313.7-2354.4]，不在所引区间内，内容复核]
- 总纲10 动手者创造历史：教程以“保持简单、使用默认工具、跟随 Handbook 亲手搭建”为路径，把 jails 的可用性交付给普通用户的亲手实践而非重型框架依赖，延续了 FreeBSD 社区以手册与动手操作传承工程知识的传统。（YouTube EPvVpd34bWCJA，[45.6-75.6]，L2）
