# 103.7.5 独立开发者以告别GPL为题撰文论证copyleft在云软件SaaS时代已失去实际

- 独立开发者以“告别 GPL”为题撰文，论证 copyleft 在云软件（SaaS）时代已失去实际效用：其仅存的用武之地是 MongoDB、Elastic 等商业厂商对抗云巨头的业务动机，而 FSF 在 Stallman 复职风波后既无应对云软件威胁的方案，也持续重复数十年前的论调，作者因此主张改用 MIT、BSD、Apache 2.0 等宽松许可证，并把精力转向反垄断、可持续商业模式与用户利益优先的监管。（BSD Now EP402，[282.18-516.52]，L2）
- AWS 工程师 Samuel Karp 开源 RunJ，一个面向 FreeBSD Jails 的实验性 OCI 兼容容器运行时；因 runc 与 containerd 现有 shim 深度假设 Linux 内核接口（cgroups、namespaces），作者选择从零实现而非移植，并附带自写 containerd shim，为 OCI 镜像生态进入 FreeBSD 打开通道，随后即有社区志愿者将其导入 ports。（BSD Now EP402，[716.66-918.42]，L2）
- 前微软 Xenix 团队成员回顾 1980-1989 年 Xenix 史：Xenix 为 AT&T Unix 的移植打包版本，1980 年 8 月 25 日经《Computerworld》公告上市、单套定价 2000 至 9000 美元；微软持有商标与 Unix 母许可证并向各 OEM 再授权，1983 年为 IBM PC AT（代号 Salmon）完成移植，后因放弃零售市场而与 Santa Cruz Operation（SCO）达成打包、销售与支持协议，1989 年团队解散。（BSD Now EP402，[919.42-1253.24]，L2）
- FreeBSD 开发者 Warner Losh 更新 QEMU bsd-user 用户态模拟分支：为摆脱数千补丁 rebase 的僵局，他将基于 3.1 的 bsd-user 目录直接并入 QEMU 6.0 并设 Blitz（快速可用）与 Kaizen（持续缩减 diff、先保 x86）双分支，与上游达成原则上每月合并的协议，目标是恢复以用户态模拟加速 FreeBSD 跨架构包构建的能力。（BSD Now EP402，[1254.24-1524.86]，L1）

- 随机数生成器更新：FreeBSD 11 起默认采用 Ferguson 与 Schneier 设计的 Fortuna（熵积累进多池并据此重播种）；2019 年 Ferguson 发表 Windows 10 随机数生成器设计白皮书，社区据此实现 FenestrasX——每 CPU 一个生成器构成树、消除多核读锁竞争，小请求从缓冲服务并在用后安全擦除，集成进 arc4random，已在 -current 但默认关闭，需自定义内核 RANDOM_FENESTRASX 并重建。（BSD Now EP388，[593.74-739.5]，L2）
- PF 与路由查找的性能优化：Christoph 用 HWPMC 工具定位到 PF 对每包、每字节做 64 位计数导致多核 cache 抖动，将计数器替换为内核 counter 框架，并把 PF 规则的用户态配置结构与内核评估结构解耦；Alexander（melifaro）引入 FIB lookup 框架，可按路由数量在 Bsearch4、Radix4 lockless 与 DPDK 的 LPM4 之间动态选择，8 条路由时 Bsearch 达约 6900 万 pps，70 万条全量路由时 LPM 达约 4600 万 pps。（BSD Now EP388，[745.82-955.22]，L2）
