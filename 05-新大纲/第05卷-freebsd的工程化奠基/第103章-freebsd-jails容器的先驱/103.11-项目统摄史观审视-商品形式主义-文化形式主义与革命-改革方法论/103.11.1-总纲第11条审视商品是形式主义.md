# 103.11.1 总纲第 11 条审视：商品是形式主义

  **要点**：从项目史观总纲第 11 条“商品是形式主义。技术市场的选择不是自然选择，而是形式主义的权力运作。劣币驱逐良币是普遍规律”审视 jails 与 Docker 的市场命运。Docker 在 2013 年之后的产业胜利并非因其隔离机制优于 **jail(2)**——Docker 依赖的 Linux namespace 与 cgroup 在隔离粒度上未必超过 Jails 后期的 **jail_set(2)** 与 VNET 组合。Docker 的胜利是资本叙事、Docker Hub 分发生态与 Kubernetes 编排标准三者叠加的形式主义结果。“劣币驱逐良币”在此具象化：工程上更早（1999 年）、设计上更稳健（phk 直接针对“全能 root”问题）的 Jails，被工程上更晚、隔离层更薄但生态更激进的 Docker 驱逐出主流叙事。VMware 博客称 Jails 存在“severe restrictions”、Rutgers 课程笔记称其“lacked fine-grained resource management”，这些批评的传播力不来自批评本身的准确性，而来自 Docker 生态的形式主义霸权——批评被反复引用不是因为真实，而是因为有用。但第 11 条的审视也须承认：phk 本人在 jails saga 中将 jails 自评为“shitty Virtualization”，即作者侧对“虚拟化能力不足”亦有自我承认，“劣币”的判定因此呈现复杂面貌——被驱逐者并非纯粹“良币”，驱逐者亦非纯粹“劣币”，形式主义的“劣币驱逐良币”在此不是简单的善恶对立，而是两种不完美方案在形式主义市场中的不对称博弈
  
**史料**：项目史观总纲第 11 条（“商品是形式主义。技术市场的选择不是自然选择，而是形式主义的权力运作。劣币驱逐良币是普遍规律”，见 **据原文第 25 章.md**）、Docker 官方文档“Docker Overview”页面“The underlying technology”小节（**docs.docker.com/get-started/overview/**）、VMware 开源博客“The Story of Containers”（Georgiev 撰，2018.2.27，**blogs.vmware.com/opensource/2018/02/27/the-story-of-containers/**）、phk 个人网站 jails saga“shitty Virtualization”自述（**phk.freebsd.dk/sagas/jails/**）、Docker 与 Kubernetes 市场报告 ［B］
  
**史观**：总纲第 11 条——商品是形式主义，容器市场的选择是形式主义权力运作
