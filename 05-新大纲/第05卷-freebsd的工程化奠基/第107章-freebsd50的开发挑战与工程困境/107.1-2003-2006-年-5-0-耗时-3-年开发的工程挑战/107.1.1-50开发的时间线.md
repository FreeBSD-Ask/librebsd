# 107.1.1 5.0 开发的时间线

  **要点**：FreeBSD 5.0 开发时间线：2000.3 启动 5-CURRENT 分支，2002.4 首个 5.0-DP1 开发者预览，2002.10 5.0-DP2，2003.1.16 5.0-RELEASE 正式发布（release/5.0.0 tagger_date = 2003-01-16T16:56:23Z），从 4.0(2000.3.20) 到 5.0 历时近 3 年

  FreeBSD 5.x 系列版本发布时间线（freebsd.duckdb `tags` 表验证）：

  | 版本 | 发布时间 | tag | tagger_date | 主要特性/定位 |
| -- | ------ |---| --------- | ----------- |
| 5.0 | 2003-01-16 | `release/5.0.0` | 2003-01-16T16:56:23Z | SMPng、GEOM、ULE（默认禁用）、MAC、Technology Release |
| 5.1 | 2003-06-09 | —— | —— | ULE 首次引入、UFS2 默认 |
| 5.2 | 2004-01 | —— | —— | 稳定性改进 |
| 5.3 | 2004-11-04 | `release/5.3.0` | 2004-11-04T19:12:42Z | 首个 5-STABLE 分支、Production Release |
| 5.4 | 2005-05 | —— | —— | 5-STABLE 维护 |
| 5.5 | 2006-05 | —— | —— | 5.x 系列终结版 |

**史料**：FreeBSD 5.0 Release Notes、freebsd-current 邮件 2000-2003、SVN commit log；freebsd.duckdb freebsd-src 仓库 tags 表 release/5.0.0 的 tagger_date = 2003-01-16T16:56:23Z（target_commit_hash = 47227ef0ef663b7abb81ab5a60a450da9a93d24b），release/5.0.0_cvs 同日创建，证明 5.0-RELEASE 的 tag 时间确凿；freebsd.duckdb 查询 L1.1.1 显示：freebsd-src 仓库年度 commit 量在 5.x 转型期呈先升后降趋势——2002 年 19,824 条（占 4 大 BSD src 合计 22.63%）、2003 年 15,654 条（占 20.40%），5.0-RELEASE 发布后 commit 量下降反映转型期开发节奏放缓；freebsd.duckdb 查询 L1.4.1 显示：freebsd-src release tag 间隔在 5.x 期紊乱——release/4.7.0（2002-10-08）至 release/5.0.0（2003-01-16）间隔约 100 天，但 5.x 系列 release 间隔因转型困难而拉长（5.0 至 5.3 间隔近 22 个月），与 4.x 稳定的 4-6 个月 release 周期形成鲜明对照；freebsd.duckdb 查询 L3.4.1.top10 显示：freebsd-src 等 4 大 BSD src 仓库 top 10 贡献者集中度在 5.x 转型期——2002 年 25.00%、2003 年 20.50%、2004 年 19.69%、2005 年 25.02%、2006 年 22.08%，2005 年集中度回升至 25.02% 反映 5.x 转型困难期核心开发者承担更多工作量 ［A］
  
**史观**：专题语（不设总纲条号）——实践先于理论，3 年延期源于 SMPng 工程挑战而非计划
  
**辨析**：经 freebsd.duckdb tags 表验证，5.0-RELEASE 的 tagger_date 为 2003-01-16（非旧叙事 2003.1.19，误差 3 天，可能为公告日期与 tag 日期差异），5.0 开发起始日期存在 2000.3 与 2000.1 两种说法，需查 SVN；0 信任原则适用说明：L1.1.1 年度 commit 量基于 author_date 聚合，FreeBSD SVN-to-Git 2020 迁移可能引入日期偏差但 author_date 应保持一致；commit 量下降（2002→2003）不等于开发停滞，可能反映 SMPng 细粒度锁改造使单个 commit 涉及更多文件与审查周期；L3.4.1.top10 集中度基于 4 大 BSD src 合计（freebsd-src + openbsd-src + netbsd-src + dragonfly-src），freebsd-src 单仓库集中度可能更高；bus factor 低不等于风险高，须结合关键子系统（SMPng、GEOM、ULE）贡献集中度综合判断；L1.4.1 release tag 间隔数据中部分 tag 为 svn2git 重构时打的标签，非原始发布时间，须排除 _cvs 后缀 tag
