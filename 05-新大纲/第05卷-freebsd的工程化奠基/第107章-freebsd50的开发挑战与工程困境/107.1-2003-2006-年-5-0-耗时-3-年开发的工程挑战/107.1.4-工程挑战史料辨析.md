# 107.1.4 工程挑战史料辨析

  **要点**：工程挑战史料疑点：(1) 延期是否曾被内部讨论缩短；(2) 是否曾考虑放弃部分改造；(3) Core Team 对延期的公开表态
  
**史料**：freebsd-current 邮件、Core Team 公开声明 ［A］；freebsd.duckdb 数据库交叉印证——统计结论 C-03 freebsd-src 仓库总 commit 数 445,203 条（`SELECT COUNT(*) FROM commits WHERE repo_name='freebsd-src'`），5.x 艰难转型期（2002-2005）的 commit 分布为此累计量的中段；统计结论 C-29 freebsd-src ARIMA(5,0,5) 模型 AIC = 107.39（`statsmodels.tsa.arima.model.ARIMA` 自回归阶数 p = 5、差分阶数 d = 0、移动平均阶数 q = 5），反映 freebsd-src 月度 commit 时序存在显著自回归与移动平均结构，即历史 commit 量对当期 commit 量有可量化的预测能力，5.x 转型期的工程节奏受此统计结构约束；统计结论 C-33 freebsd-src 预测精度 MAPE = 24.56% RMSE = 456.55 coverage = 94.74%，MAPE < 30% 属可接受预测精度区间，coverage 94.74% 接近 95% 名义覆盖率反映模型校准良好，5.x 时期的 commit 量预测在此精度范围内；Python 脚本 `script/phase3_timeseries.py` Task 14（ARIMA 拟合）与 Task 15（MAPE/RMSE 自实现），查询日期 2026-07-27 ［B］
  
**史观**：专题语（不设总纲条号）——0 信任核验，公开表态可能掩盖内部争议；统计结论印证——C-29 ARIMA(5,0,5) 与 C-33 MAPE = 24.56% 反映 freebsd-src commit 时序的可预测性，与项目史观总纲第 5 条 “没有必然性，只有偶然性” 形成张力：ARIMA 模型的统计可预测性不等于工程演进的必然性，5.x 艰难转型的具体决策（如 KSE 放弃、SMPng 推进）仍属偶然性事件，统计模型仅刻画 commit 量的时序结构而非工程因果
  
**辨析**：内部是否曾讨论放弃 KSE，需查邮件；**统计局限性标注**——统计显著 ≠ 实际显著，C-29 ARIMA(5,0,5) AIC = 107.39 仅反映模型对历史数据的拟合优度，不等于模型对未来 commit 量的预测能力；AIC 为相对指标，须与其他 ARIMA(p, d, q) 参数组合的 AIC 比较解读，单一 AIC 数值无绝对意义；C-33 MAPE = 24.56% 基于 freebsd-src 全周期（1993-2026）月度数据计算，非 5.x 转型期（2002-2005）单段精度，跨时期引用时须注意；RMSE = 456.55 与 commit 量纲相关，不可直接与其他仓库 RMSE 横比；coverage = 94.74% 接近 95% 名义覆盖率但存在抽样波动；0 信任原则适用——ARIMA 模型假设时序平稳性或可差分平稳化，freebsd-src commit 时序存在变点（C-12 1999-08）可能违反模型假设，模型参数解释须谨慎；多重比较风险——本卷 16 章跨章引用 C-03、C-29、C-33 时存在多重比较风险
