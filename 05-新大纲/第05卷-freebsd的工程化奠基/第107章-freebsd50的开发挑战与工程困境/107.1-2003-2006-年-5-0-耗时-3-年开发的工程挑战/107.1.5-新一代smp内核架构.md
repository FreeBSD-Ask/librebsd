# 107.1.5 新一代 SMP 内核架构

  **要点**：SMPng(SMP Next Generation) 由 John Baldwin（约翰·鲍德温） 等主导，目标是用细粒度锁替代 Giant Lock，支持多核 CPU 并行执行内核代码；架构包括 **mutex(2)**、**sx(9)**、**condvar(9)**、**witness(4)** 调试框架
  
**史料**：Baldwin BSDCon 2001 SMPng 演讲、FreeBSD mutex(9) 手册页、witness(4) 手册页 ［A］
  
**史观**：专题语（不设总纲条号）——BSD 与 UNIX 谱系的连续性，SMPng 延续 4.4BSD SMP 工作
  
**辨析**：SMPng 设计是否受 Solaris 细粒度锁影响，需查 Baldwin 演讲
  
**文献**：Baldwin BSDCon 2001 演讲；mutex(9) 手册页 ［A］
