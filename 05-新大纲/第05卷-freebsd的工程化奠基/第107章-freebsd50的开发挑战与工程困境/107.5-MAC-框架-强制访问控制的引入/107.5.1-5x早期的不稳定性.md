# 107.5.1 5.x 早期的不稳定性

  **要点**：5.x 早期 (5.0/5.1/5.2) 存在明显不稳定性：内核 panic、SMP 性能倒退、设备驱动不兼容；FreeBSD 5.0-RELEASE 发布说明已明确标注 “Technology Release” 而非 Production Release
  
**史料**：FreeBSD 5.0/5.1/5.2 Release Notes、FreeBSD 邮件列表 bug 报告 ［A］
  
**史观**：技术债务与代码考古，5.x 早期不稳定是 SMPng 转型代价
  
**辨析**：早期版本稳定性评价需以原始 release notes 与邮件列表报告为准
  
**文献**：FreeBSD Release Notes（5.0/5.1/5.2/5.3/5.4/5.5）；FreeBSD 邮件列表 2003-2004 bug 报告与稳定性讨论；FreeBSD 官方公告 2003-2004 安全性与稳定性公告；SMPng 设计文档（FreeBSD 内部 Wiki） ［A］
