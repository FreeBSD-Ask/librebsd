# 107.5.3 M: N 模型的理论优势

  **要点**：KSE(Kernel Scheduled Entities)M: N 线程模型由 Daniel Eischen 与 Julian Elischer 设计，理论优势：(1) 用户态调度减少内核切换；(2) 内核线程数可控；(3) 适合高并发线程应用
  
**史料**：Eischen/Elischer BSDCon 2001 KSE 演讲、kse(9) 手册页 ［A］
  
**史观**：实践先于理论，理论优势未在实践实现
  
**辨析**：M: N 理论是否真有优势，需查 Solaris 历史
  
**文献**：Eischen 演讲；kse(9) 手册页 ［A］
