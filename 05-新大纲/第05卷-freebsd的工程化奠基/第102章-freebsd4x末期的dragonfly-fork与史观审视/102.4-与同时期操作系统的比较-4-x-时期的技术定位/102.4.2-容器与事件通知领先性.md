# 102.4.2 容器与事件通知领先性

  **要点**：FreeBSD 4.x 在容器 (Jails 2000) 与事件通知 (kqueue 2000) 上领先 Linux 3-7 年，Linux cgroups(2007)/LXC(2008) 与 epoll(2002) 均晚于 FreeBSD；这一领先未转化为市场优势
  
**史料**：Jails/kqueue commit log、Linux cgroups/epoll 文档、容器技术史论文 ［A］
  
**史观**：偶然性改写历史，Jails 领先但未获市场认可
  
**辨析**：领先是否 “应” 转化为市场优势存在争议，市场受非技术因素影响
