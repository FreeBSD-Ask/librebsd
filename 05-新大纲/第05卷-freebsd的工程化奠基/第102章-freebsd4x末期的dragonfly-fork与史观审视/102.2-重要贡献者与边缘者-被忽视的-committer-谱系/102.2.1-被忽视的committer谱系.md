# 102.2.1 被忽视的 committer 谱系

  **要点**：4.x 时期约 200 名 committer 中，约 60% 在社区记忆中被忽视，他们的贡献散落在 commit log 中，包括驱动维护、文档撰写、bug 修复
  
**史料**：SVN commit log、Core Team 名单、freebsd-committers 邮件列表 ［A］
  
**史观**：边缘者贡献，被忽视的 committer 是 4.x 稳定的基础设施
  
**辨析**：被忽视的程度需统计 commit 量与社区认知
  
**文献**：commit log；Core Team 名单；邮件列表 ［A］
