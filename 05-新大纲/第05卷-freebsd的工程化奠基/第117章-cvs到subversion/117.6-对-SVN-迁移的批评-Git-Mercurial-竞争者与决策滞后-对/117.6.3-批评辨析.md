# 117.6.3 批评辨析

  **要点**：批评辨析：（1）“滞后”是否公允（SVN 2008 年仍主流）；（2）8 年争论是否反映民主决策的必要成本；（3）Wemm 强行推进是否破坏共识但有正面后果；（4）反对者是否事后被证明正确
  
**史料**：邮件、博客 ［C］
  
**史观**：0 信任原则（考据规则，非总纲条目——批次 C055 问题 4）
  
**辨析**：批评在事实上是公允的——8 年争论确实长于同期项目，SVN 在 2008 年已显过时（Git 分布式优势明显），Wemm 强行推进确实绕过共识程序；但批评须置于历史语境——2008 年 SVN 仍是企业主流（Apache、KDE 等项目同期使用 SVN），FreeBSD 选择 SVN 是符合当时主流而非滞后
  
**文献**：freebsd-hackers mailing list SVN migration critics (2008-2010)；freebsd-arch mailing list VCS debate (2008)；Wemm, P. SVN migration justification (2008) ［A］
