# 117.2.1 cvsup 到 svnup 的技术更替

  **要点**：cvsup（John Polstra 用 Modula-3 编写的 CVSup 工具，1998）被 svnup 替代；cvsup 基于 pull 模型与 Zlib 压缩，svnup 基于 SVN 协议；cvsup 的 Modula-3 依赖长期是构建痛点
  
**史料**：cvsup 文档、svnup 文档、freebsd-hackers 邮件 ［A］
  
**史观**：BSD 与 UNIX 谱系的连续性，工具更替延续 BSD 工具传统
  
**辨析**：更替在事实上是必要的——cvsup 的 Modula-3 依赖是 FreeBSD ports 树长期构建痛点，Modula-3 编译器在 FreeBSD 上的维护已停滞；svnup 消除 Modula-3 依赖简化构建的工具链；性能比较数据在 freebsd.duckdb 中不可得，须依赖 freebsd-hackers 邮件列表与性能测试报告交叉验证
