# 117.7.3 边缘贡献者辨析

  **要点**：边缘贡献者辨析：(1) ports 镜像维护者在迁移中的角色；(2) 文档团队对迁移手册的更新；(3) 镜像站点管理员的协调；(4) 第三方工具（csup、svnup）开发者
  
**史料**：邮件、commit log ［A］
  
**史观**：边缘者的作用
  
**辨析**：边缘者贡献在 freebsd.duckdb 中部分可得——ports 镜像维护者的 commit 反映在 freebsd-ports 仓库，文档团队的 commit 反映在 freebsd-doc 仓库，但镜像站点管理员的协调工作在 commit 中不可见，须依赖 freebsd-mirrors 邮件列表与 Foundation 年度报告交叉验证
  
**文献**：freebsd-hackers mailing list 2008-2010 archives；freebsd-ports mailing list SVN migration (2008)；FreeBSD Committer's Guide ［A］
