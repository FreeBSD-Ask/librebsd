# 117.3.1 CVS 时代的补丁文化

  **要点**：CVS 时代 FreeBSD 社区采用补丁文化：开发者通过 diff/patch 提交补丁，由 committer 审核提交；补丁文化强调社区参与，边缘者可通过补丁贡献
  
**史料**：freebsd-hackers 邮件、补丁提交记录 ［A］
  
**史观**：边缘者的作用，补丁文化允许边缘者参与
  
**辨析**：补丁文化与中央仓库文化无绝对优劣但有不同后果——补丁文化降低参与门槛但增加 committer 审核负担，中央仓库文化提升提交效率但提高边缘者参与门槛；freebsd.duckdb contributors 表显示 freebsd-src 仓库 commit 数量在 2008 年前后未发生突变（月度 commit 数 644-1430 区间波动），说明模式变化对总提交量的影响有限，但对贡献者结构的影响须依赖邮件列表讨论交叉验证
  
**文献**：freebsd-hackers mailing list patch culture (2000-2008)；freebsd-committers mailing list commit statistics；McKusick, M. K. FreeBSD committer model in Open Sources (O'Reilly, 1999) ［A］
