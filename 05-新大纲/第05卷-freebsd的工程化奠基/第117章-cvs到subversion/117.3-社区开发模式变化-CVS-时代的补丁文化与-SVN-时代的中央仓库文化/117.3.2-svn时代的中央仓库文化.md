# 117.3.2 SVN 时代的中央仓库文化

  **要点**：SVN 时代 FreeBSD 社区转向中央仓库文化：committer 直接提交，分支管理更规范；但边缘者参与门槛提高，补丁提交减少
  
**史料**：commit log、邮件 ［A］
  
**史观**：话语权与边缘者，中央仓库文化可能削弱边缘者参与
  
**辨析**：文化变化影响在 freebsd.duckdb 中可通过 contributors 表首末活动时间间接验证——2008 年后新进入 committer 的首条 commit 时间分布须依赖 contributors 表逐人核查，但 “边缘者参与门槛提高” 的主观感受在 commit 中不可见，须依赖 freebsd-hackers 邮件列表与 freebsd-advocacy 讨论交叉验证
  
**文献**：freebsd-hackers mailing list SVN commit culture (2008-2010)；freebsd-committers mailing list；FreeBSD Committer's Guide (freebsd.org) ［A］
