# 101.5.1 Yahoo! 的 FreeBSD 部署

  **要点**：Yahoo! 在 1998-2000 年大规模部署 FreeBSD 支撑其 Web 服务，是 FreeBSD 商业验证的标志性事件；Yahoo! 工程团队 (如 Jeremy Zawodny) 积极回馈 FreeBSD 性能改进
  
**史料**：Yahoo! 工程博客、BSDCon 2000 Yahoo! 演讲、Jeremy Zawodny 个人博客 ［C］
  
**史观**：企业研究双重性，Yahoo! 部署兼具商业需求与工程研究
  
**辨析**：Yahoo! 部署规模存在 “数千台” 与 “上万台” 两种说法，需查 Yahoo! 内部报告
  
**文献**：Yahoo! BSDCon 演讲；Zawodny 博客；BSDCon 2000 论文 ［B］
