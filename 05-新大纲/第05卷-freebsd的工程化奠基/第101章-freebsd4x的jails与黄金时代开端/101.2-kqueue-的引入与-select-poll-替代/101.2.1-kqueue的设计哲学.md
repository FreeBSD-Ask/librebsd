# 101.2.1 kqueue 的设计哲学

  **要点**：kqueue 由 Jonathan Lemon 设计，2000 年引入 FreeBSD 4.1，采用统一 filter 接口替代 select/poll 的分散 API，支持文件、套接字、信号、定时器、进程等多种事件源，设计哲学是 “消解复杂性”
  
**史料**：kqueue(2) 手册页、Lemon 的 kqueue 论文 (BSDCon 2000)、SVN commit log ［A］
  
**史观**：总纲第 2 条——实践先于理论，kqueue 源于 select/poll 性能瓶颈的实践
  
**辨析**：kqueue 引入版本存在 4.0 与 4.1 争议，需查 commit log
  
**文献**：Lemon “Kqueue: A Generic and Scalable Event Notification Facility”(BSDCon 2000)；kqueue(2) 手册页 ［A］
