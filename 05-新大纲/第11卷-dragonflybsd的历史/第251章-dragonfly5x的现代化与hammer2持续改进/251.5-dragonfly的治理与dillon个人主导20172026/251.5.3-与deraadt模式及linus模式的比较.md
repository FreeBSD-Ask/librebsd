# 251.5.3 与 de Raadt 模式及 Linus 模式的比较

**要点**：openbsd.duckdb 显示 2017-2026 年间三个个人主导项目的 commit 量对照——OpenBSD（openbsd-src）年均约 5700 条、Linux（linux-stable，仅 stable 分支）年均 commit 量缺位〔存疑：仅 stable 分支口径，未经复核〕、DragonFly（dragonfly-src）年均约 1300 条。三种个人主导模式对照如下：

| 维度 | OpenBSD（de Raadt） | Linux（Linus） | DragonFly（Dillon） |
|---|---|---|---|
| 年均 commit 量 | 约 5700 条 | —〔存疑：stable 分支口径未复核〕 | 约 1300 条 |
| 公开讨论机制 | misc@ 邮件列表 | LKML | kernel@ 邮件列表 |
| Foundation 法律实体 | 有（**openbsdfoundation.org**） | 有（**linuxfoundation.org**） | 无（**dragonflybsd.org/foundation/** 404） |
| 公开审议机制 | 有 | 有 | 无 |

三种个人主导模式的治理基础设施差异显著——OpenBSD de Raadt 主导但有 misc@ 邮件列表公开讨论机制与 OpenBSD Foundation 法律实体（**openbsdfoundation.org**）；Linux Linus 主导但有 LKML 公开讨论机制与 Linux Foundation 法律实体；DragonFly Dillon 主导无公开审议机制与 Foundation 法律实体（**dragonflybsd.org/foundation/** 404）
**史料**：openbsd.duckdb commits 表三仓库 2017-2026 年对照（openbsd-src/dragonfly-src；linux-stable 须单独核验）；openbsdfoundation.org 年报；linuxfoundation.org 年报；dragonflybsd.org/foundation/ HTTP 404；OpenBSD misc@/Linux LKML/DragonFly kernel@ 邮件列表档案

**史观**：专题语：dragonfly.duckdb 数据显示三种个人主导模式的治理基础设施差异塑造三个项目的不同文化——OpenBSD 有 Foundation 但 de Raadt 主导技术决策，DragonFly 无 Foundation 且 Dillon 主导全部决策；总纲第 8 条——本体论上各方平等：dragonfly.duckdb 显示 OpenBSD 年均 commit 量约为 DragonFly 的 4.4 倍，反映 Foundation 法律实体与公开讨论机制对社区动员能力的支撑作用

**辨析**：dragonfly.duckdb 显示 OpenBSD 与 DragonFly 都是小项目，但 OpenBSD 的巴士因子略高（de Raadt 之外有更多核心 committer 如 tb@、kettenis@、deraadt@）；Linux Linus 主导但 Linux 内核有数千名 committer，巴士因子远高于 OpenBSD 与 DragonFly；三人治理风格的差异需结合项目规模辨析
