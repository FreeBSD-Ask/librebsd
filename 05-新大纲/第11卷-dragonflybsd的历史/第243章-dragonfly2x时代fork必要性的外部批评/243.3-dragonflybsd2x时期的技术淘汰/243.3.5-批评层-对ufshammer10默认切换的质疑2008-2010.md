# 243.3.5 批评层——对 UFS→HAMMER 1.0 默认切换的质疑（2008-2010）

**要点**：DragonFly 2.0（**2008.7.20**）将默认文件系统从 UFS 切换为 HAMMER 1.0 的决策面临三类批评。其一，“成熟度不足”批评——HAMMER 1.0 仅经 1 年密集开发（2007-2008 年 1,213 条 commit），dragonfly.duckdb dragonfly-src 仓库 `sys/vfs/hammer*` 路径 2007 年 commit 仅 181 条（设计阶段），2008 年激增至 1,213 条（工程爆发），但相比 UFS 数十年部署历史（源自 4.2BSD Fast File System 经 CSRG/McKusick 持续维护）与 ZFS 企业级团队开发（Sun Microsystems），HAMMER 1.0 的成熟度不足以承担默认文件系统职责。其二，“巴士因子风险”批评——dragonfly.duckdb dragonfly-src 仓库 contributors 表显示 HAMMER 设计主要由 Dillon 个人完成（2008 年 Dillon 个人占比仍居主导），HAMMER 作为默认文件系统后 Dillon 个人风险即项目风险，与 FreeBSD UFS 由 McKusick 及多位 committer 共同维护、OpenBSD FFS 由 de Raadt 与多位开发者审计的多元维护形成对照。其三，“用户迁移成本”批评——UFS 用户需迁移至 HAMMER 1.0，而 HAMMER 1.0 的功能集较小（无 ZFS 的 send/receive、无 ZFS 的 pool 管理），迁移后的功能损失需用户承担；FreeBSD 8.x 同期采取保守策略——UFS 仍为默认，ZFS 作为可选，让用户按需选择，避免强制迁移

**史料**：DragonFly 2.0 release notes（**2008.7.20** HAMMER 默认切换）；dragonfly.duckdb dragonfly-src 仓库 `sys/vfs/hammer*` 路径 commit 演化（2007 年 181 条、2008 年 1,213 条、2009 年 282 条）；dragonfly.duckdb dragonfly-src 仓库 contributors 表（2008 年 bus factor：top10 占 91.56%、Dillon 个人占比）；FreeBSD 8.0 release notes（UFS 默认、ZFS 可选）；HAMMER 设计文档 v1 ［A］

**史观**：总纲第 8 条——本体论上各方平等：UFS、HAMMER、ZFS 三种文件系统在本体论上地位相等，“成熟度”与“功能集”的差异是经验事实而非本体论等级；总纲第 17 条——软件工程：HAMMER 1.0 默认切换体现“先设计 → 实验引入 → 默认切换”的工程节奏，但批评者质疑该节奏过快

**辨析**：考据过程留痕——【查证来源】HAMMER 1.0 默认切换经 DragonFly 2.0 release notes 一手核验，dragonfly.duckdb dragonfly-src 仓库 tags 表无 v2.0 系列 tag，2.0 发布日期 **2008.7.20** 须与 Dillon 在 kernel@ 邮件列表的 2.0 RELEASED 公告交叉验证；HAMMER 路径 commit 统计以 `sys/vfs/hammer*` 路径匹配，可能遗漏散落在其他路径的相关 commit（如文档、测试、工具）；【交叉验证方法】HAMMER 1.0 与 UFS/ZFS 的成熟度对比以 dragonfly.duckdb commit 量与部署历史为依据，但 commit 量不等于质量——2008 年 HAMMER 路径 1,213 条 commit 含大量基础工作，并非全部用于核心功能完善；UFS 的“数十年部署历史”以 4.2BSD FFS（1983）为起点，须经 McKusick 相关论文与 FreeBSD release notes 交叉验证；【0 信任原则·Dillon 自述考据】Dillon 在 HAMMER 设计文档中关于“轻量级写时复制”优于 ZFS 的表述属当事人自辩，须以独立第三方 benchmark 交叉验证，不得仅凭 Dillon 单方面陈述采信；【存疑判定依据】HAMMER 1.0 在 2.x 周期的实际部署规模无权威统计，dragonfly.duckdb 显示 2.x 周期 HAMMER 相关 commit 以功能完善为主而非安全修复，但部署规模有限可能导致漏洞未充分暴露 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］
