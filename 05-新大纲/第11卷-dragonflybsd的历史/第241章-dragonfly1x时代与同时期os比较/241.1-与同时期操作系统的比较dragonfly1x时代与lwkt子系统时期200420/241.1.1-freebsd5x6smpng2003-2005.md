# 241.1.1 FreeBSD 5.x/6（SMPng，2003-2005）

**要点**：FreeBSD 在 DragonFly 1.x 同期为 5.x（2003-2005）/6.0（2005），以 SMPng（细粒度锁）重构内核并发；与 DragonFly 1.x 的 LWKT（轻量内核线程）对照——二者同源于 4.4BSD，DragonFly 放弃 SMPng 的锁路线、改用消息传递/LWKT，体现 fork 后的并发哲学分野。

**史料**：FreeBSD 5.x/6 SMPng 史料（含 Baldwin 2002 SMPng 实现文档、FreeBSD 5.0/5.1/5.2/5.3/6.0 Release Notes）；DragonFly 1.x LWKT 史料；dragonfly.duckdb dragonfly-src 仓库 commits 表与 commit_files 表（路径 `03-原始史料库/01-代码仓库史料/05-DragonFlyBSD/db/duckdb/〔原引 01-数据库本体 路径断链，订正〕`，含 LWKT 首引 commit `8ad65e080342` 2003-06-20、token 机制 1.10 引入 2007.8.6、2003-2008 年 LWKT 路径 commit 演化）；DragonFly BSD 邮件列表存档（**DragonFly 邮件列表**（<https://www.dragonflybsd.org/mailinglists/>），含 kernel@、users@ 2003-2008 年间 LWKT/SMPng 讨论档案）；DragonFly BSD Release Notes（<https://www.dragonflybsd.org/releases/>，**1.0-1.12> 版本序列）；Dillon fork 公告（<https://lists.freebsd.org/pipermail/freebsd-current/2003-July/006889.html>，**2003-07-16，“too> heavily mutexed” 表述）；HAMMER 设计 PDF（<https://www.dragonflybsd.org/hammer/hammer.pdf>，**Dillon> 2008 完整设计文档，B+Tree 写时复制哲学，为 LWKT 工程哲学在文件系统层面的延续）[三角验证：dragonfly.duckdb 代码层 + 邮件列表言论层 + Release Notes 官方层三类来源互参] ［A］**

**史观**：总纲第 4 条——分离聚合是永恒规律：DragonFly 自 FreeBSD 5.x fork（2003），LWKT 与 SMPng 是 fork 后并发路线分化。

**辨析**：LWKT 的消息传递 vs SMPng 的锁，是两种 SMP 哲学，非技术优劣。具体争议点：1) 版本号核验——DragonFly 1.0 发布日期（**2004.7.12**）经 kernel@ 邮件公告（**lists.dragonflybsd.org/pipermail/kernel/2004-July/212809.html**）与 dragonfly.duckdb dragonfly-src tags 表交叉验证，部分二手来源误载为 2005.3，已修正；2) LWKT 首引时间——dragonfly.duckdb 显示 LWKT 首引 commit `8ad65e080342`（2003-06-20T02:09:59Z）距 fork 首 commit `984263bcb83a`（2003-06-17T02:57:24Z）仅 2 天 19 小时 36 分钟，反映 Dillon 在 fork 前已完成 LWKT 设计，但 commit 量不等于设计完成度；3) SMPng 与 LWKT 性能对比缺乏权威第三方基准 [存疑脚注：LWKT 与 SMPng 性能对比缺乏权威第三方基准，本节不臆造具体性能数字]〔DX-1592／id1660〕。0 信任原则应用维度：author 字段可伪造（dragonfly.duckdb author_email 须与 committer 字段交叉验证）、tagger_date 与实际发布日期可能偏差（须与 Release Notes 互参）、关键词匹配局限（sys/sys/lwkt*与 sys/kern/lwkt* 路径匹配可能遗漏散落在 sys/platform/ 下的 IPI 实现）。考据记录归档至 `d:\librebsd\03-原始史料库\06-考据记录\20260730_jianyi缺口补全考据.md` 8g 节。
