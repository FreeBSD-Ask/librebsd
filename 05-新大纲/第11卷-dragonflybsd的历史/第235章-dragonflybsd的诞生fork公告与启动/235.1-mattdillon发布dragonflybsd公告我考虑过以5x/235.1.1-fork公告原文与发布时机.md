# 235.1.1 Fork 公告原文与发布时机

**要点**：2003 年 7 月 16 日（太平洋夏令时 Wed Jul 16 12:41:34 PDT 2003）Matt Dillon 在 freebsd-current 邮件列表发布标题为 “Annoucning DragonFly BSD!”（原文拼写如此）的 fork 公告，宣告从 FreeBSD 4.8-RELEASE 分叉。公告选在 FreeBSD 5.x SMPng 重构引发性能争议的高峰期。经 dragonfly.duckdb 验证，dragonfly-src 仓库中 Dillon 的首条 commit（`40292e35c603f70be70f9b04c9c49d82e1e6b6ba`）的 author_date 为 2003-07-01T00:19:36Z，commit message 为 "Sync userland up with the kernel. This primarily adjusts ps, etc to handle information stored in the thread structure."，证明 fork 后代码工作实际始于 2003 年 7 月 1 日，比 7 月 16 日的公开公告早 15 天；dragonflybsd.org/history 官方页面将 fork 时间表述为 “June of 2003” 指项目酝酿期或代码准备期，与公告日期不矛盾。**统计结论 C-19**——推断性统计.md Task 8 SubTask 8.2 配对 Wilcoxon 符号秩检验显示，Matt Dillon fork DragonFly BSD 事件（2003-07）前后各 6 个月 freebsd-src 月度 commit 量存在统计显著差异，前窗（2003-01 至 2003-06）均值 1434.83 高于后窗（2003-08 至 2004-01）均值 1183.33，检验统计量 W = 1.0，p = 0.0464（α = 0.05），效应量 r = 0.8131 属大效应（r > 0.5），统计上拒绝 H₀，即 fork 事件后 FreeBSD 短期 commit 量显著下降，量化印证 Dillon 作为 FreeBSD 核心开发者离开对 FreeBSD commit 流量的短期冲击；**统计结论 C-27**——推断性统计.md Task 10 Bootstrap 重抽样（B = 2000）显示 dragonfly-src 贡献者 Gini 系数观测值 0.8972，Bootstrap 均值 0.8905，95% CI [0.8517, 0.9187]，CI 宽度 0.0670，反映 dragonfly-src 贡献高度集中于少数开发者（201 位贡献者），Gini 系数在 BSD 4 项目 src 仓库中仅次于 freebsd-src（0.9188），印证 fork 初期 Dillon 个人主导的治理结构特征。fork 事件三时间点对照如下：

**史观**：技术路线分化：4.x 派与 5.x 派在锁粒度路线上的分化；统计结论 C-19 印证——fork 事件前后 freebsd-src 月度 commit 量统计显著下降（W = 1.0, p = 0.0464, r = 0.8131），反映 Dillon 作为 FreeBSD 核心开发者离开短期内带走了部分 commit 流量，是 “分离” 在 commit 流量层面的量化呈现；统计结论 C-27 印证——dragonfly-src Gini 0.8972 反映 fork 后 DragonFly 贡献高度集中，与 Dillon 个人主导模式互证；统计结论 C-06 印证——dragonfly-src 全时段 49,280 commits 反映 fork 后 DragonFly 工程规模远小于 FreeBSD 主线

**辨析**：原大纲中 “7.23 与 7.27 两种说法” 经核对 freebsd.org 邮件列表归档原始时间戳后确认为误传，实际公告日期为 7 月 16 日；经 dragonfly.duckdb 验证，dragonfly-src 仓库首条 commit（author_date = 2003-07-01T00:19:36Z，message = “Sync userland up with the kernel...”）证明代码工作实际始于 7 月 1 日，比公开公告早 15 天，这与 Dillon 在公告中提及 “我已开始代码工作” 的表述一致；dragonflybsd.org/history 官方页面写 “June of 2003” 指项目酝酿期而非公告日期，contributors 表中 Matt Dillon 的 first_commit_date = 2003-06-17T02:57:24Z 可解释 “June of 2003” 说法的来源——此为仓库迁移保留的更早 commit 记录；三个时间点（6 月酝酿期、7 月 1 日代码开始、7 月 16 日公开公告）经 commit 数据库与邮件列表交叉验证后明确区分，存疑已解决。经 2026-08-15 邮件列表库双库核查，fork 公告邮件标题 Annoucning DragonFly BSD! 在 dragonfly kernel@ 列表交叉存档（Message-ID <200307162042.h6GKge0T094438@apollo.backplane.com>），Dillon 同日自称 I stupidly misspelled announcing，公告日期 2003-07-16 获证；【0 信任原则·commit 量不等于质量】L2.1 查询显示 fork 后 6 个月 dragonfly-src 月均 158.8 条 commit 远低于 freebsd-src 月均 1174.2 条，但 commit 量仅反映开发活跃度，须结合 commit 规模（additions/deletions）与 message 质量综合判断——DragonFly 早期 commit 多为 LWKT 子系统从零构建的大型 commit，单条 commit 影响力高于 FreeBSD 同期维护性 commit；事件影响评估须结合 commit message 主题词与文件路径交叉验证；【统计显著 ≠ 实际显著·C-19 局限】Wilcoxon 检验仅表明 fork 事件前后 commit 量差异的统计显著性，不证明 fork 事件本身导致差异，须结合邮件列表存档、核心开发者访谈等史实证据交叉验证；【样本量极小】C-19 配对样本仅 6 对（N = 6），p 值与 Z 统计量基于正态近似，小样本下可能不准确；【p 值临界】C-19 p = 0.0464 接近 α = 0.05，若做 Bonferroni 校正（2 事件比较，α'= 0.025），则不拒绝 H₀，结论稳健性较弱；【混淆变量未控制】fork 事件前后的 commit 量变化可能受其他因素影响（如 release 周期、季节性、其他核心开发者变动），Wilcoxon 检验不控制混淆变量；【多重比较风险】C-19 与 C-27 同源 dragonfly.duckdb dragonfly-src 仓库，跨章引用时存在多重比较风险；【Bootstrap CI 假设】C-27 Bootstrap 假设样本对总体有代表性，dragonfly-src 201 位贡献者是否代表 BSD 项目总体须辨析；freebsd-src 与 dragonfly-src 的 Bootstrap CI 略重叠，二者贡献集中度差异不显著
