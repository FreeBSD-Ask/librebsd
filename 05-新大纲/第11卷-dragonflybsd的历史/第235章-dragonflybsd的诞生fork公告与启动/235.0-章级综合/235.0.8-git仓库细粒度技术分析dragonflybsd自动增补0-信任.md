- **TLS/加密**（安全，2003–2026）：传输加密：OpenSSL→LibreSSL（OpenBSD 2014 分叉）
- **性能优化**（性能，2003–2026）：持续性能工程：内核网络/存储/调度微优化
- **HAMMER**（存储，2009–2026）：DragonFly 独有 CoW 文件系统（2007），HAMMER2（2018）
- **TCP/IP**（网络，2003–2026）：TCP 拥塞控制演进：Reno→NewReno→CUBIC，BSD 与 Linux 并行
- **Clang/LLVM**（工具链，2008–2026）：C 编译器栈：FreeBSD 2012 用 Clang 取代 GCC（许可证原因）
- **SMP/多核**（进程/并行，2003–2026）：对称多处理与内核并行化（自旋锁→睡眠锁→无锁结构）
- **内存管理**（内存管理，2003–2026）：虚拟内存、slab 分配、大页/HugeTLB 透明大页
- **许可/治理**（治理，2003–2026）：许可证与治理：BSD 许可宽松，Linux GPL；基金会治理（FreeBSD/NetBSD/OpenBSD 基金会）
- **无线**（网络，2004–2026）：802.11 无线栈：FreeBSD 用 net80211，Linux 用 mac80211/cfg80211
- **GPU/DRM**（硬件支持，2003–2026）：显卡驱动：Linux DRM 2010s 成熟，FreeBSD 借 LinuxKPI 移植 DRM
- **ARM**（硬件支持，2008–2026）：ARM64 支持：Linux 2012 官方；FreeBSD 2016 起
- **OpenSSH**（安全，2003–2025）：安全远程登录套件（OpenBSD 1999 开发）
- **USB**（硬件支持，2003–2026）：USB 栈：FreeBSD usb4bsd 重写，Linux 成熟
- **UFS/FFS**（存储，2003–2026）：伯克利快速文件系统（1984），soft updates（1998）
- **Jails**（容器隔离，2003–2026）：FreeBSD 进程隔离容器（2000），chroot 的强安全超集
- **调度器**（进程/并行，2003–2026）：任务调度策略：FreeBSD ULE、Linux CFS/EEVDF、NetBSD sched_4BSD
- **IPFW**（网络，2003–2026）：FreeBSD 传统包过滤（1994），与 dummynet 流量整形结合
- **kqueue**（可观测性，2003–2025）：BSD 事件通知机制（FreeBSD 2000），与 epoll 对位
