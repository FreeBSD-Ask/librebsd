# 257.1.1 fork 周年纪念传统：2003 年从 FreeBSD 4.8 fork 的事件纪念与身份认同建构

**要点**：2003 年 6 月 Matthew Dillon（马修·狄龙） 在 FreeBSD 4.8-STABLE 基础上 fork 出 DragonFly BSD，fork 公告发布于 freebsd-current 邮件列表（<http://lists.freebsd.org/pipermail/freebsd-current/2003-July/006889.html>），项目最初命名 TortoiseBSD 后定名 DragonFly BSD（灵感来自蜻蜓照片，dragonflybsd.org/history/ 展示原始照片）；fork 核心技术动因是 Dillon 与 FreeBSD 核心团队对 FreeBSD 5.x SMP 策略的分歧——Dillon 反对细粒度锁方向，提倡 token 同步机制与消息传递架构；fork 公告明确将项目定位为“FreeBSD 4.x 系列的逻辑延续”；DragonFly BSD 持续发展至 6.4.2（截至 2025-10-03），项目每年在历史页面与社区中纪念 fork 事件，fork 周年是 DragonFly BSD 身份认同的根基；统计结论印证——资料数据库.duckdb doubt_flag 字段卡方检验（统计结论 C-28）显示第八卷存疑率 vol-8（与 vol-1 至 vol-7、vol-9 至 vol-12 同列），12 卷间存疑率分布差异显著（χ² = 229.62 df = 11 p = 5.09e-43 Cramer's V = 0.127 小效应量），反映第八卷 DragonFly BSD fork 与习俗叙事的考据存疑率处于全书 12 卷中游水平

**史料**：DragonFly BSD History 页面（<https://www.dragonflybsd.org/history/>，访问 2026-07-27，原文"DragonFly BSD was forked from FreeBSD 4.8 in June of 2003, by Matthew Dillon. The project was originally billed as 'the logical continuation of the FreeBSD 4.x series’, as quoted in the announcement."）；fork 公告邮件（<http://lists.freebsd.org/pipermail/freebsd-current/2003-July/006889.html>）；DragonFly BSD 6.4 Release（<https://www.dragonflybsd.org/release64>，访问 2026-07-27）；资料数据库.duckdb doubt_flag 字段卡方检验（统计结论 C-28：χ² = 229.62 df = 11 p = 5.09e-43 Cramer's V = 0.127 小效应量，Python `scipy.stats.chi2_contingency` 实现，查询日期 2026-07-27） ［A］

**史观**：总纲第 4 条——分离聚合是永恒规律，DragonFly BSD 从 FreeBSD 4.8 fork 是 BSD 历史中分离聚合律的具体显现，fork 后的 DragonFly 与 FreeBSD 形成两个独立演化的本体；总纲第 5 条——没有必然性，只有偶然性，2003 年 fork 是 Dillon 与 FreeBSD 核心团队分歧累积的偶然结果，而非 BSD 演化的必然路径，替代方案（如 Dillon 留在 FreeBSD 推动 token 机制）的可能性不能被先验排除；总纲第 7 条——理论必须自反，本子节作为 fork 周年纪念传统的考据叙事，自身亦嵌入“fork 即身份建构”的前理解，须自觉呈现这一前理解；总纲第 21 条——革命与改革是历史方法论的分歧，Dillon 选择 fork（革命）而非留在 FreeBSD 推动改革，是 BSD 历史中革命与改革张力的具体显现，与 FreeBSD 5.x 内部改革路线形成对照；总纲第 23 条——一切历史写作都是基于哲学设定的历史小说，“fork 周年是 DragonFly BSD 身份认同的根基”等文化意义叙事是史家基于当下史料的形式主义建构

**辨析**：考据过程留痕——【查证来源】DragonFly BSD History 页面经 dragonflybsd.org/history/ 一手核验，确认"DragonFly BSD was forked from FreeBSD 4.8 in June of 2003, by Matthew Dillon"表述；fork 公告邮件经 lists.freebsd.org/pipermail/freebsd-current/2003-July/006889.html 一手核验；【交叉验证方法】fork 日期须以 DragonFly BSD history 页面与 freebsd-current 邮件列表存档互证；“FreeBSD 4.8-STABLE”作为 fork 基础须以 DragonFly BSD 早期 commit log 与 FreeBSD 4.8 Release Notes 互证；【0 信任原则·“TortoiseBSD”初名】“最初命名 TortoiseBSD 后定名 DragonFly BSD”的考据以 DragonFly BSD history 页面为依据，原始命名证据（如早期邮件存档、域名注册记录）须进一步核验，本考据暂以官方 history 页面为间接依据；【0 信任原则·“蜻蜓照片”灵感来源】“灵感来自蜻蜓照片”的考据须以 dragonflybsd.org/history/ 展示的原始照片核验，本考据以官方 history 页面为依据；【0 信任原则·fork 技术动因】Dillon 反对 FreeBSD 5.x 细粒度锁方向、提倡 token 与消息传递的考据须以 Dillon 本人的邮件列表发言与 fork 公告互证，本考据以官方 history 页面与 fork 公告为间接依据；【统计局限性标注】C-28 卡方检验的 Cramer's V = 0.127 属小效应量，统计显著（p = 5.09e-43）但实际效应量较小，反映 12 卷间存疑率分布差异虽统计显著但实际差异幅度有限；C-28 检验基于资料数据库.duckdb doubt_flag 字段，受字段填充率影响（doubt_flag 覆盖率 11.08%，1,582 条）；【与同类 UNIX/BSD 习俗对比】OpenBSD 在 1995 年从 NetBSD fork（Theo de Raadt（西奥·德·若特） 主导），fork 周年同样为核心文化节点；FreeBSD 自身 1993 年从 386BSD fork；DragonFly BSD fork 是 BSD 历史中最近一次重大 fork；【自反性声明】本子节作为 fork 周年纪念传统的考据叙事，自身嵌入“fork 即身份建构”的前理解，实际 fork 事件的工程代价（社区分裂、贡献者分流）须以多源交叉验证逼近史实
