# 237.4.5 HAMMER2IsNowTheDefaultFileSystemForDrago

### 新闻条目 1

- **新闻标题（中英）**：HAMMER2 Is Now The Default File-System For DragonFlyBSD（HAMMER2 现成为 DragonFlyBSD 默认文件系统）
- **新闻来源**：Phoronix + Michael Larabel + 2019-06-17 + URL **<https://www.phoronix.com/news/DragonFlyBSD-HAMMER2-Default>**（经 WebFetch 抓取可访问，访问日期 2026-07-27）
- **新闻摘要**：Phoronix 报道 HAMMER2 在作为 DragonFlyBSD 实验性选项超过五年后，成为该 FreeBSD 衍生项目的新默认文件系统。报道指出："After being an experimental option in DragonFlyBSD for more than the past half-decade, HAMMER2 is the new default file-system of this FreeBSD derivative." 并引用 gitweb.dragonflybsd.org 提交记录（commit `a49112761c919d42d405ec10252eb0553662c824`）证实切换发生在 2019-06-16 当日。HAMMER1 文件系统仍保留可用。该决策体现了 Dillon 作为单一技术决策核心对项目方向的塑造——HAMMER2 自 2017 年 5.0 首次可启动到 2019 年 5.6 成为默认，完全由 Dillon 主导设计与推进。
- **与本章主题的关联说明**：本章关注 DragonFly BSD 治理中的技术决策机制，HAMMER2 成为默认文件系统是项目 “创始人主导技术路线” 治理模式的典型例证——重大技术决策由 Dillon 个人推动，无公开的核心团队投票或社区评议程序，与 FreeBSD Core Team 选举治理、OpenBSD Foundation 理事会治理形成对比。
