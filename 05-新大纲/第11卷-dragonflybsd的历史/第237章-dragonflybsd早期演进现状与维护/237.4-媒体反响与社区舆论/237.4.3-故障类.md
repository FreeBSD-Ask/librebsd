### 新闻条目 2

- **新闻标题（中英）**：DragonFlyBSD 6.0 Has Been Released（DragonFlyBSD 6.0 已发布）
- **新闻来源**：Phoronix + Michael Larabel + 2021-05-10 + URL **<https://www.phoronix.com/news/DragonFlyBSD-6.0-Released>**（经 WebFetch 抓取可访问，访问日期 2026-07-27）
- **新闻摘要**：Phoronix 报道 DragonFlyBSD 6.0 正式发布。报道开头："DragonFlyBSD 6.0 has officially launched today as the newest version of this popular BSD operating system. Following the recent launches of FreeBSD 13.0 and OpenBSD 6.9, DragonFlyBSD 6.0 has made it out as the latest version of this BSD operating system forked long ago from FreeBSD." 报道详列 6.0 主要变更，包括改进内存分页、AMDSMN 驱动从 FreeBSD 移植、更好的 EFI 帧缓存支持、Meltdown 漏洞 Intel 处理器启动检测、HAMMER2 多卷初始支持、TMPFS 性能提升、新的非 GPL EXT2/3/4 文件系统驱动、GCC 8 默认编译器等。报道未提及具体发布工程师姓名，但提供了 DragonFlyBSD 在 BSD 生态中与 FreeBSD 13.0、OpenBSD 6.9 同期发布的时序定位。
- **与本章主题的关联说明**：本章关注 DragonFly BSD 治理结构的对外呈现方式，Phoronix 报道反映 DragonFly 项目对外发布通过英文技术媒体（Phoronix）公告的常规渠道，体现了项目 “小团队依赖外部媒体放大声量” 的治理传播模式。
- **与官方史料的交叉验证结论**：与 DragonFly 6.0 release 页面（URL `https://www.dragonflybsd.org/release60/`，发布日期 2021-05-10）完全一致；dragonfly.duckdb dragonfly-src 仓库 tags 表 v6.0.0 tagger_date = `2021-05-09T16:42:54-04:00` 与 Phoronix 报道日期 2021-05-10 相差 1 天（时区差异）；Phoronix 所列 EXT2/3/4 新驱动、AMDSMN 移植、HAMMER2 多卷支持等变更与 release notes 一致；Phoronix 作为商业广告支持的英文技术媒体，其报道须警惕赞助商关系带来的偏向（如对 AMD 相关特性的突出）。
