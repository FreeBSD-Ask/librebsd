# 237.3.3 与 OpenBSD-NetBSD 分裂后关系的比较

**要点**：OpenBSD 1996 年从 NetBSD fork 后两者关系长期紧张，但 2007 年 NetBSD Foundation 与 OpenBSD Foundation 均注册成立后关系逐步缓和，至 2015 年后两项目在 LibreSSL/portable 代码共享等议题上出现协作。DragonFly-FreeBSD 关系至 2026 年仍未出现类似缓和迹象——dragonfly.duckdb 显示 2010 年后 DragonFly 与 FreeBSD 内核代码共享停止，userland 共享亦逐步减少

**史料**：dragonfly.duckdb dragonfly-src/freebsd-src/netbsd-src/openbsd-src 仓库 commits 表（按年统计对照）；OpenBSD Foundation 2007 年注册记录（openbsdfoundation.org/）；NetBSD Foundation 2007 年重组记录（netbsd.org/foundation/）；DragonFly 无 Foundation 注册记录（dragonflybsd.org/foundation/ 404）〔L1 代码/构建产物/L3 官方文档与公告〕

**史观**：终结与延续：fork 后关系的长期演变——OpenBSD-NetBSD 关系在 11 年后（1996-2007）随双方 Foundation 同步注册而缓和，DragonFly-FreeBSD 关系在 23 年后（2003-2026）仍未缓和，差异的原因在于 OpenBSD/NetBSD 双方均有 Foundation 法律实体作为对话渠道，DragonFly-FreeBSD 双方仅剩邮件列表与个人互动
