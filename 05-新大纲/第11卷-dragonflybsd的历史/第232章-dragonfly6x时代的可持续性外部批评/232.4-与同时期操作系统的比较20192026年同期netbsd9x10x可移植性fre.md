# 232.4 与同时期操作系统的比较：2019-2026 年同期 NetBSD 9.x-10.x（可移植性）、FreeBSD 13.x-15.x（Clang/LLVM/OpenZFS/bhyve）、OpenBSD 6.x-7.x（pledge/unveil/LibreSSL）、Linux 5.x-6.x（cgroups/Docker/Kubernetes）——DragonFly 以“HAMMER 2 与 LWKT”为定位

## 232.4.1 NetBSD 可移植性的对照

**要点**：netbsd.duckdb 显示 NetBSD 2024 年 commit 量 5985 条、2025 年 4708 条、2026 年截至 7 月 3247 条，远高于 dragonfly.duckdb 所示 DragonFly 同期（277/561/906 条）。NetBSD 9.x-10.x 时期（2019-2026）持续推进可移植性，支持数十种硬件架构；DragonFly 则专注于 x86-64 平台（2014 年 v4.0 系列弃用 i386 后），与 NetBSD 的多平台策略形成对照

**史料**：netbsd.duckdb commits 表（NetBSD 2024-2026 年 commit 量：5985/4708/3247）；dragonfly.duckdb commits 表（DragonFly 同期：277/561/906）；NetBSD 9.x/10.x release notes；NetBSD 支持架构列表（netbsd.org/ports/）；DragonFly 平台支持说明（dragonflybsd.org/docs/hardware/）〔L1 代码/构建产物/L3 官方文档与公告〕

**史观**：总纲第 4 条——分离聚合是永恒规律：netbsd.duckdb 与 dragonfly.duckdb 数据显示 NetBSD 选择“广度”路线（多架构支持），DragonFly 选择“深度”路线（x86-64 专注）——NetBSD 2024 年 commit 量是 DragonFly 的 21.6 倍，多平台策略需要更多维护资源

**辨析**：可移植性与轻量级内核并非完全对立——但 dragonfly.duckdb 显示 DragonFly 2014 年弃用 i386 后专注 x86-64，NetBSD 同期维护 50+ 端口，分化加剧；NetBSD 多平台策略的可持续性须以 Foundation 资金支撑核验

**文献**：netbsd.duckdb／dragonfly.duckdb commits 表（NetBSD/DragonFly 2024-2026 年对照）；NetBSD 9.x/10.x release notes [EB/OL]. netbsd.org/releases/；NetBSD Ports [EB/OL]. netbsd.org/ports/；DragonFly hardware support [EB/OL]. dragonflybsd.org/docs/hardware/ ［A］

## 232.4.2 FreeBSD 现代化的技术进展

**要点**：freebsd.duckdb 显示 FreeBSD 2024 年 commit 量 14541 条、2025 年 15598 条、2026 年截至 7 月 9041 条，远高于 DragonFly 同期。FreeBSD 13.x-15.x 时期（2019-2026）引入对 64-bit ARM 的 Tier-1 支持、改进 bhyve、引入 Kunai 实验性调度器、改进 OpenZFS 集成等；DragonFly 同期主要推进 HAMMER 2 与 LWKT 维护（dragonfly.duckdb 显示 HAMMER 2 关键词 commit 2024 年 16 条、2025 年 27 条、2026 年 11 条），技术广度不及 FreeBSD

**史料**：freebsd.duckdb commits 表（FreeBSD 2024-2026 年 commit 量：14541/15598/9041）；dragonfly.duckdb commits 表（DragonFly 同期：277/561/906）；dragonfly.duckdb dragonfly-src 仓库 commits 表（HAMMER2 关键词 commit 按年：2024 = 16、2025 = 27、2026 = 11）；FreeBSD 13.x/14.x/15.x release notes；DragonFly 5.x/6.x release notes〔L1 代码/构建产物/L3 官方文档与公告〕

**史观**：总纲第 4 条——分离聚合是永恒规律：freebsd.duckdb 与 dragonfly.duckdb 数据显示 FreeBSD 与 DragonFly 在技术广度上的分化持续加深——FreeBSD 2024 年 commit 量是 DragonFly 的 52.5 倍，FreeBSD Core Team 集体审议机制支持 GEOM/ZFS/bhyve 等大型子系统的多贡献者协作，DragonFly Dillon 个人主导模式下的子系统开发受限于创始人精力

**辨析**：技术比较须结合项目目标——openzfs.duckdb 显示 commit 量差距显著，但 FreeBSD 追求主流服务器市场（Tier-1 ARM64、bhyve、Kunai 调度器），DragonFly 追求轻量级内核哲学（LWKT/HAMMER/vkernel），无简单优劣关系；vkernel 在 v6.0 起失功能并非 vkernel 整体移除，而是 MAP_VPAGETABLE 支持移除（commit `4d4f84f5f26bf5e9fe4d0761b34a5f1a3784a16f`）所致，恢复工单 issue #3389 已于 2025-12 启动、目标 v6.6；该事件须经 **UPDATING** “从 6.0 升级” 段与 issue #3389 交叉印证；HAMMER 与 ZFS 设计哲学差异（B+Tree vs merkle tree）须经 sys/vfs/hammer2/ 与 OpenZFS 源码逐文件对比核验 [存疑脚注：vkernel 失功能事件（MAP_VPAGETABLE 支持移除 commit 4d4f84f5、恢复工单 issue #3389）须经 DragonFly 官方 UPDATING 与 issue #3389 交叉印证；HAMMER 与 ZFS 设计哲学差异须经源码逐文件对比核验，本轮考据未联网核验]；commit 量比较须以各自仓库 committer 字段交叉验证，v6.2.1/v6.4.0 tagger（分别为 Sherrill 与 Huete Jimenez）须与 Release Notes 互参，关键词匹配局限须以 commit_files 表细分核验

## 232.4.3 OpenBSD 安全文化的对照

**要点**：openbsd.duckdb 显示 OpenBSD 2024 年 commit 量 6512 条、2025 年 5330 条、2026 年截至 7 月 3205 条，远高于 DragonFly 同期。OpenBSD 6.x-7.x 时期（2019-2026）持续安全审计与 pledge/unveil 改进、LibreSSL 持续维护；DragonFly 同期在安全方面投入较少（dragonfly.duckdb 显示 v6.0 起 MAP_VPAGETABLE 支持移除致 vkernel 失功能后无系统性安全机制创新），主要专注于 HAMMER 2 与维护

**史料**：openbsd.duckdb 与 dragonfly.duckdb commits 表对照（OpenBSD 2024-2026 年 commit 量：6512/5330/3205；DragonFly 同期：277/561/906）；OpenBSD 6.x/7.x release notes；DragonFly 5.x/6.x release notes〔L1 代码/构建产物/L3 官方文档与公告〕

**史观**：总纲第 4 条——分离聚合是永恒规律：openbsd.duckdb 与 dragonfly.duckdb 数据显示 OpenBSD 选择“安全优先”路线（pledge/unveil/LibreSSL），DragonFly 选择“架构优先”路线（LWKT/HAMMER/vkernel）——OpenBSD 2024 年 commit 量是 DragonFly 的 23.5 倍，安全细分市场为 OpenBSD 提供了稳定的贡献者群体与 Foundation 资金支撑

**辨析**：DragonFly 并非完全忽视安全——dragonfly.duckdb 显示 DragonFly 在 6.x 时期有安全相关 commit，但未进行 OpenBSD 式的系统性安全机制创新；OpenBSD 的安全细分市场（pledge/unveil/LibreSSL）为项目提供了可持续性支撑，DragonFly 的 LWKT/HAMMER 创新未获业界主流采纳，缺乏细分市场支撑

**文献**：openbsd.duckdb／dragonfly.duckdb commits 表（OpenBSD/DragonFly 2024-2026 年对照）；OpenBSD 6.x/7.x release notes [EB/OL]. openbsd.org/；DragonFly 5.x/6.x release notes [EB/OL]. dragonflybsd.org/release/ ［A］
