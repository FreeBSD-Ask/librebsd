# 245.3.3 HAMMER 2 与 OpenZFS/btrfs 的比较

**要点**：dragonfly.duckdb 显示 dragonfly-src 仓库 HAMMER2 关键词 commit 2014 年 48 条、2015 年 86 条；freebsd-src 仓库 OpenZFS 关键词 commit 2014 年 0 条、2015 年 3 条——DragonFly 在 HAMMER 2 上的自研投入远超 FreeBSD 在 OpenZFS 上的整合投入。HAMMER 2 与 OpenZFS 相比——内存占用更小（64MB 即可运行 vs 256MB ARC 基线）、设计更轻量，但功能集与生态较弱；与 btrfs 相比——成熟度更高、稳定性更好，但社区支持与工具链较弱

**史料**：dragonfly.duckdb dragonfly-src 仓库 commits 表 HAMMER2 关键词按年：2014 = 48、2015 = 86；freebsd.duckdb freebsd-src 仓库 commits 表 OpenZFS 关键词按年：2014 = 0、2015 = 3；HAMMER 2、OpenZFS、btrfs 的技术比较文献；各文件系统的性能 benchmark；用户邮件列表讨论

**史观**：技术路线分化：openzfs.duckdb 数据显示 HAMMER 2、OpenZFS、btrfs 是文件系统技术路线分化的典型——HAMMER 2 自研轻量级（2014-2015 年 134 条 HAMMER2 commit），OpenZFS 跨平台整合（FreeBSD 2014-2015 年仅 3 条 OpenZFS commit），btrfs Linux 主流生态
