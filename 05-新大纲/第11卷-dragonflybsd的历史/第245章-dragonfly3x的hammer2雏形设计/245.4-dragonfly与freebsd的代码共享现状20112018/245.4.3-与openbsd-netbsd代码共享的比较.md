# 245.4.3 与 OpenBSD-NetBSD 代码共享的比较

**要点**：bsd_commits.duckdb 显示 2011-2015 年间四仓库 commit 量对照——openbsd-src 年均约 8074 条、netbsd-src 年均约 20618 条、freebsd-src 年均约 13745 条、dragonfly-src 年均约 2684 条。OpenBSD 与 NetBSD 自 1995 年 fork 后共享代码迅速减少，至 2011-2015 年间几乎完全独立；DragonFly 与 FreeBSD 的代码共享演化与之类似，但 DragonFly fork 起点更晚（2003），独立过程更长——bsd_commits.duckdb 显示 dragonfly-src 仓库 MFC commit 2015 年仍 18 条，反映 DragonFly-FreeBSD 代码共享未完全归零

**史料**：dragonfly.duckdb commits 表四仓库 2011-2015 年对照；OpenBSD 与 NetBSD 源码 diff 分析；DragonFly 与 FreeBSD 源码 diff 分析；dragonfly.duckdb dragonfly-src 仓库 commits 表 MFC 关键词 2015 年 18 条〔L1 代码/构建产物/L5 二手研究〕

**史观**：总纲第 4 条——分离与聚合：dragonfly.duckdb 数据显示 BSD 阵营内部多次 fork 后的代码共享演化都遵循分离聚合律——OpenBSD-NetBSD 因 1995 年个人冲突（de Raadt 与 NetBSD 核心团队）迅速独立，DragonFly-FreeBSD 因 2003 年技术分歧（LWKT vs 细粒度锁）缓慢独立，独立速度差异源于 fork 动机的不同
