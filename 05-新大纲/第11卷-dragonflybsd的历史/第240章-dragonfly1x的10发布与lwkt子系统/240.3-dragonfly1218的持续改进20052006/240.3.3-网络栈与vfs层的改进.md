# 240.3.3 网络栈与 VFS 层的改进

**要点**：DragonFly 1.6（2006-07-24）改进网络栈——基于 LWKT 的每 CPU 网络栈线程；1.8（2007-01-30）改进 VFS 层——基于 LWKT 的 VFS 操作消息传递；改进让网络栈与 VFS 层充分利用 LWKT 的多核扩展性

**辨析**：每 CPU 网络栈线程的具体实现需对照源码核验；VFS 层消息传递的性能影响需考据
