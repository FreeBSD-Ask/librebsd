# 240.5.3 与 OpenBSD-NetBSD 分裂后关系的比较

**要点**：OpenBSD 1995 年从 NetBSD fork 后，二者长期保持完全独立的代码库与社区；DragonFly 与 FreeBSD 4.x 的关系演变与之类似，但 DragonFly fork 起点更高（继承自成熟的 4.x），初期共享代码更多

**史料**：OpenBSD fork 历史（1995 年 de Raadt 从 NetBSD fork 公告与邮件列表记录）；NetBSD 与 OpenBSD 早期共享代码记录（netbsd-src 与 openbsd-src 仓库 commit 历史）；DragonFly 与 FreeBSD 4.x 共享代码记录（dragonfly-src 首 commit `984263bcb83a` “Initial import from FreeBSD RELENG_4” 2003-06-17）；dragonfly.duckdb dragonfly-src/netbsd-src/openbsd-src 仓库 commits 表与 commit_files 表（路径 `d:\librebsd\03-原始史料库\01-代码仓库史料\01-数据库本体\`）；DragonFly BSD 邮件列表存档（**<https://www.dragonflybsd.org/mailinglists/**）；DragonFly> BSD Release Notes（**<https://www.dragonflybsd.org/releases/**）；Dillon> fork 公告（**<https://lists.freebsd.org/pipermail/freebsd-current/2003-July/006889.html**）；HAMMER> 设计 PDF（**<https://www.dragonflybsd.org/hammer/hammer.pdf**）[三角验证：openbsd.duckdb> + 邮件列表 + Release Notes] ［A］

**史观**：总纲第 4 条——分离与聚合：BSD 阵营内部的多次 fork（386BSD→FreeBSD/NetBSD、NetBSD→OpenBSD、FreeBSD→DragonFly）都是分离聚合律的体现

**辨析**：每次 fork 的分离速度不同——OpenBSD-NetBSD 因 de Raadt 与 NetBSD Core 的个人冲突而迅速完全分离，DragonFly-FreeBSD 因 Dillon 仍保留部分合作而缓慢分离
