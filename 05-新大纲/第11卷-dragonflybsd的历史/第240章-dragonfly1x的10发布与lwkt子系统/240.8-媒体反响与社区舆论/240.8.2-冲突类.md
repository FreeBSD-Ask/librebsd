# 240.8.2 冲突类

### 新闻条目 1

- **新闻标题（中英）**：Annoucning DragonFly BSD!（公告 DragonFly BSD！，原拼写为 “Annoucning”）
- **新闻来源**：FreeBSD 邮件列表 + Matthew Dillon（马修·狄龙） + 2003-07-16 12:41:34 PDT + URL **<https://lists.freebsd.org/pipermail/freebsd-current/2003-July/006889.html>**（经 WebFetch 抓取可访问，访问日期 2026-07-27）
- **新闻摘要**：Matthew Dillon 在 freebsd-current 邮件列表中正式宣布 fork FreeBSD 4.x，命名为 DragonFly BSD。公告称 “take over development of the 4.x tree”、“move kernel development along an entirely new path towards SMP”，并解释 fork 4.x 而非 5.x 的原因：“it is simply too heavily mutexed, it was actually faster to start with 4.x and move forward rather then to start with 5.x and move backwards”。
- **与本章主题的关联说明**：本章主题为 DragonFly BSD 的诞生与 Matt Dillon fork FreeBSD 冲突事件，该公告是 fork 事件的一手史料，但其在新闻媒体上的传播与社区反响构成二手史料层。
- **与官方史料的交叉验证结论**：与 DragonFly BSD 官方历史页面 **<https://www.dragonflybsd.org/history/>**（标注 “Last edited Thu Jan 17 13:32:06 2019”，访问日期 2026-07-27）“DragonFly BSD was forked from FreeBSD 4.8 in June of 2003” 一致；dragonfly.duckdb dragonfly-src 首 commit `984263bcb83a` 时间戳 `2003-06-17T02:57:24Z` 与公告日期形成 “6 月准备、7 月公开” 的工程时间序列。

### 新闻条目 2

- **新闻标题（中英）**：Flame Wars, Forks and Freedom（火焰战争、fork 与自由）
- **新闻来源**：OSNews + Vinayak Hegde + 2005-01-24 + URL **<https://www.osnews.com/story/9501/flame-wars-forks-and-freedom/>**（经 WebFetch 抓取可访问，访问日期 2026-07-27）
- **新闻摘要**：该社论将 DragonFlyBSD fork 列为 “对项目技术方向不满” 型 fork 的典型案例，称 “FreeBSD 4.x had scalability problems and could not make optimum use of multi-processor machines... The programmers who are working on Dragonfly BSD were not happy with the way this technical problem was solved and forked the project forming DragonflyBSD”，并将 DragonFlyBSD 定位为 “focused on providing Single System Image (SSI) Clustering”。
- **与本章主题的关联说明**：本章关注 fork 冲突事件报道，该社论是 OSNews 早期对 fork 起因的概括性叙述，反映了 2005 年社区对 fork 事件的解读。
- **与官方史料的交叉验证结论**：与公告邮件所述 “too heavily mutexed” 的判断一致，但 OSNews 将 fork 主因归结为 SMP 可扩展性问题，与公告中 “4.x 路线延续 + SMP 新路径” 双重动机的表述略有简化 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］：fork 动机是单纯 SMP 路线分歧，还是同时包含 4.x 维护承诺，须对照 Dillon 后续邮件与 FreeBSD 5.x SMPng 设计文档加以辨析。

### 新闻条目 3

- **新闻标题（中英）**：GoBSD Preview1 Release Available（GoBSD Preview1 发布版可用）
- **新闻来源**：OSNews + Max（投稿人） + 2004-11-25 + URL **<https://www.osnews.com/story/8990/gobsd-preview1-release-available/>**（经 WebFetch 抓取可访问，访问日期 2026-07-27）
- **新闻摘要**：GoBSD 作为 DragonFlyBSD 的 “distro”（发行版）发布 Preview1，URL `http://gobsd.com/node/1` 与 `http://gobsd.com/node/128`。评论区有用户支持此分工：“allow the dragonfly developers go about their core aims of developing the dragonfly kernel... this was in fact the raison d'etre of dragonfly”，亦有用户担忧 “with all these repackaging and forking going on” 加剧 BSD 碎片化。
- **与本章主题的关联说明**：本章关注 fork 后衍生发行版的早期生态，GoBSD 与 FireFlyBSD 共同构成 DragonFly BSD 早期商业/社区衍生发行版的第一波。
- **与官方史料的交叉验证结论**：GoBSD 站点 gobsd.com 在 2026-07-27 已失效，互联网档案馆存档覆盖度待补全 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］；与 DragonFly BSD 官方历史页面 “adoption of the pkgsrc framework” 形成对照——DragonFly BSD 主项目采用 pkgsrc 而非自建发行版，GoBSD 等社区发行版填补了用户态打包工具的空缺。
