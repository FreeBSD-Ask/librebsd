# 249.1.3 传统老 GPU 驱动 → 清理移除（DragonFly 4.0，2014.10-2014.11）

**要点**：bsd_commits.duckdb 显示 **v4.0.0** 系列（2014-10-25 v4.0.0rc1 至 2014-11-23 v4.0.0）开发周期内 `sys/dev/drm/` 目录 commit 集中——2014-10-23 `ftigeot@wolfpond.org` 提交 'drm: Drop drm1 drivers’ 是传统老 GPU 驱动清理的标志性 commit：
    > drm: Drop drm1 drivers
    bsd_commits.duckdb 显示 2014-2015 年间 `sys/dev/drm/` 目录共 507 个 distinct commit（2014 = 197、2015 = 310），反映 v4.0 系列发布后 DRM 工作持续——传统老 GPU 驱动（早期 Intel i810/i830 系列、ATI Rage128/Radeon 旧系列、Matrox、3dfx Voodoo 等）在 v4.0 系列被清理移除。bsd_commits.duckdb 关键词搜索显示 2014-2015 年 DRM 驱动相关 commit 按驱动分布如下：

    | i915 | 146 | Intel 集成显卡（主要工作） |

    | mga | 1 | Matrox 显卡（已基本移除） |
    反映 i915 与 radeon 是 DRM 移植的主要工作，i810/mga 等老驱动已基本移除
