# 239.2.4 userland 分化对用户迁移的效应及与其他 BSD 的对比

**要点**：userland 分化使 DragonFly 与 FreeBSD 之间的用户迁移成本增加——dragonfly.duckdb 显示两仓库 userland 目录 2010-2026 年间独立演进，用户迁移须重新学习命令行为与配置文件格式。但差异小于 FreeBSD 与 OpenBSD 之间的差异（OpenBSD 移除 config 语法、独立维护 openssl 替代品 LibreSSL 等），DragonFly 与 FreeBSD 因 fork 起源接近（2003 年自 4.8 fork）userland 差异相对较小

**史料**：dragonfly.duckdb dragonfly-src/freebsd-src/openbsd-src 仓库 commit_files 表（userland 目录文件变更对照）；dragonfly.duckdb dragonfly-src 仓库 commits 表（DMA 引入与 sendmail 移除 commit 序列）；用户迁移讨论（lists.dragonflybsd.org 与 lists.freebsd.org 邮件列表存档）〔L1 代码/构建产物/L3 官方文档与公告/L4 当事人邮件〕

**史观**：总纲第 4 条——分离聚合是永恒规律：分化对用户粘性的影响——userland 分化增加用户迁移成本，反过来强化项目用户粘性（DragonFly 用户因不熟悉 FreeBSD userland 而不愿迁移、FreeBSD 用户同理），形成“分化-粘性-进一步分化”的正反馈循环；dragonfly.duckdb 显示两仓库 2010 年后无回移 commit，反映分化已不可逆

**辨析**：迁移成本是主观感受，须基于多案例归纳——dragonfly.duckdb 不直接提供迁移成本数据，正式撰写时须以 lists.dragonflybsd.org 与 lists.freebsd.org 邮件列表中用户迁移讨论案例统计核验；DragonFly 与 FreeBSD userland 差异“小于 FreeBSD 与 OpenBSD”的判断须以同口径 userland 目录文件 diff 量化核验 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］，不得仅凭直觉判断
