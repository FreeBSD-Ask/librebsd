**要点**：dragonfly.duckdb 显示 DragonFly v6.2.1 tagger_date = 2022-01-09T19:51:15-05:00（Justin C. Sherrill（贾斯廷·C·谢里尔） tagger）、v6.2.2 tagger_date = 2022-06-09T22:18:03-04:00，v6.2 系列在 2022 年发布。DragonFly 6.2 系列 tag 字段如下：

    | tag | tagger_date | tagger |
    |---|---|---|
    | v6.2.1 | 2022-01-09T19:51:15-05:00 | Justin C. Sherrill |
    | v6.2.2 | 2022-06-09T22:18:03-04:00 | Justin C. Sherrill |
    v6.2 系列引入 GPU 改进，包括对 Linux DRM 的持续同步、对 Intel/AMD 新 GPU 的支持、对 Vulkan/Mesa 的兼容性改进
**史料**：dragonfly.duckdb dragonfly-src 仓库 tags 表 v6.2.1 = 2022-01-09、v6.2.2 = 2022-06-09（tagger = Justin C. Sherrill）；DragonFly 6.2 release notes（dragonflybsd.org/release/）；kernel@ 邮件列表中 GPU 讨论；DragonFly commit log GPU 改进相关 commit

**史观**：硬件与软件辩证：2022 年 Intel/AMD 新 GPU 硬件普及推动 DragonFly 在 GPU 支持上的持续投入——dragonfly.duckdb 显示 v6.2 系列（2022-01 至 2022-06）期间 GPU 相关 commit 集中在 sys/dev/drm/ 目录，反映 GPU 硬件迭代与 DragonFly 驱动同步的工程节奏

**辨析**：GPU 支持与 Linux DRM 同步强相关——DragonFly 从 Linux DRM 移植驱动，存在版本滞后；dragonfly.duckdb 显示 sys/dev/drm/ 目录的 commit 多为 Linux DRM 回移，DragonFly 自研 GPU 驱动贡献有限；Linux DRM 版本与 DragonFly 回移版本的对应关系须经 commit_files 表 sys/dev/drm/ 路径与 Linux 内核 DRM 子系统版本 tag 交叉核验 [存疑脚注：DragonFly 从 Linux DRM 回移的具体版本对应关系须经 sys/dev/drm/ 目录 commit 与 Linux 内核 DRM 版本 tag 交叉核验，本轮考据未联网核验]。0 信任原则应用维度：author 字段可伪造（DRM 移植 commit 作者归属须与 committer 字段交叉验证，Tigeot 作为 DRM 移植主要贡献者须与 <ftigeot@wolfpond.org> 邮箱核验）、tagger_date 与实际发布日期可能偏差（v6.2.1/v6.2.2 tagger 均为 Sherrill，须与 Release Notes 互参）、关键词匹配局限（GPU 相关 commit 可能以 i915/radeon 等具体驱动名为关键词而未提及 DRM，须以 commit_files 表细分核验）。考据留痕至 `03-原始史料库/06-考据记录/20260730_jianyi缺口补全考据.md` 8ai 节
