# 236.5.2 隐喻在社区中的传播与引用

**要点**：比萨饼隐喻被广泛引用以说明 BSD 频繁分裂的特性，成为 BSD 社区自我调侃的经典话语。Linux 社区也常引用此隐喻以对比 Linux 内核的统一性。dragonfly.duckdb 显示 DragonFly fork（2003-06-17）后该隐喻在 dragonfly.kernel 邮件列表与 Slashdot DragonFly 讨论帖中多次出现

**史料**：Slashdot、Reddit r/BSD、Hacker News 等社区讨论；dragonfly.duckdb dragonfly-src 仓库 commits 表 commit message 中偶有引用（如 2003-2006 年间 Dillon 或其他 committer 在 commit message 中提及）；技术博客引用记录〔L1 代码/构建产物/L2 即时通讯记录/L4 事后叙述〕

**史观**：总纲第 4 条——分离与聚合：隐喻反映 BSD 分裂与 Linux 聚合的对比——dragonfly.duckdb 显示 BSD 家族 1993-2003 年间产生 3 次内核 fork（NetBSD、OpenBSD、DragonFly），Linux 内核同期无成功 fork，比萨饼隐喻在 2003 年 DragonFly fork 后传播达到高峰

**辨析**：隐喻的传播中措辞有多种变体——“10 个 BSD 开发者” 或 “3 个 BSD 开发者”、“比萨饼” 或 “蛋糕”、“开发者死了” 或 “开发者打起来” 等变体并存，反映社区传说的口头传统特征；正式撰写时须记录所有已知变体，不得仅引用单一版本
