# 347.7.3 校园社会文化新闻类

### 新闻条目 1

- **新闻标题（中英）**：AsiaBSDCon — BSD Conference in Tokyo, Japan / AsiaBSDCon——日本东京 BSD 会议
- **新闻来源**：AsiaBSDCon 官方 + URL `<https://www.asiabsdcon.org/`>
- **新闻摘要**：AsiaBSDCon 是面向基于 BSD 系统用户与开发者的技术会议，涵盖 FreeBSD、NetBSD、OpenBSD、DragonFlyBSD、Darwin 与 Mac OS X。大会主席为 Hiroki Sato（FreeBSD 项目，东京工业大学）；程序委员会包括 George V. Neville-Neil（乔治·V·内维尔-尼尔）、Hidetoshi Shimokawa、Masanobu Saitoh、Henning Brauer（亨宁·布劳尔）、Li-Wen Hsu（许立文）、Allan Jude（艾伦·裘德）。AsiaBSDCon 由 Japan NetBSD Users' Group 与 BSD Research 联合主办。
- **与本章主题的关联说明**：这是 AsiaBSDCon 作为亚太 BSD 会议代表的官方信息，是本章 “亚太 BSD 会议” 与 “日本 BSD 社区组织” 小节的核心一手史料。
- **与官方史料的交叉验证结论**：`asiabsdcon.org` 为 AsiaBSDCon 官方域名，Hiroki Sato、Li-Wen Hsu、Allan Jude 等程序委员会成员与 FreeBSD Core Team/Foundation 理事身份一致（参见第十二卷第014章交叉验证）。
