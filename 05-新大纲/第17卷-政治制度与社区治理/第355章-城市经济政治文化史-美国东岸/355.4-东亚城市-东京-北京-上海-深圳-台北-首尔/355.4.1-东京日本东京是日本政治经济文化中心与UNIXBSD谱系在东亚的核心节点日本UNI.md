# 355.4.1 东京日本东京是日本政治经济文化中心与UNIXBSD谱系在东亚的核心节点日本UNI

#### 要点

东京（日本）：东京是日本政治经济文化中心与 UNIX/BSD 谱系在东亚的核心节点；日本 UNIX 用户组（JUST，Japan UNIX User Group，1981 年成立）、日本 SNI UNIX 用户组、日本 Sun Users Group 等使东京成为东亚 UNIX 用户社区的源头；1980-1990 年代日本 Unix 工业以 NEC（UX/4800，基于 System V）、Hitachi（HI-OSF/1-MJ，基于 OSF/1）、Fujitsu（UXP/V，基于 System V）、Mitsubishi（UX/M）、东芝（TX/UX）等 “日本 Unix 阵营” 为核心，这些系统多为日本厂商对 UNIX System V 或 OSF/1 的本土化改造，与 BSD 谱系形成对照；NetBSD/pc98 移植（1994 年起，Naoki Hamada 等推进）使 NetBSD 支持 NEC PC-9801 系列（日本 1980-1990 年代主流个人电脑），是 BSD 谱系与日本硬件工业的深度结合；FreeBSD Japan User Group（FreeBSD 日本用户组，1995 年起）与 Japan FreeBSD Users Group（2005 年起）持续推动 FreeBSD 在日本的采用；东京至 2026 年仍是日本科技工业的核心，但 UNIX 商业版本（Solaris、HP-UX、AIX）已被 Linux 与云原生技术大幅取代。

北京（中国）：北京是中国计算机科学学术研究与政府机构的核心；中国科学院计算技术研究所（ICT，1956 年成立）、中国科学院软件研究所（1985 年成立）、清华大学计算机系（1958 年成立）、北京大学计算机系（1978 年成立）等使北京成为中国 CS 学术重镇；中国最早的 UNIX 接触可追溯至 1979-1980 年中国学术代表团访美带回 UNIX V6、V7 源代码，1980 年代中期中国科学院、北京大学、清华大学等开始在国内 DEC PDP-11 与 VAX 上移植 UNIX V7 与 BSD 4.x；1987 年中国电子工业部第六研究所推出 XENIX 中文版（基于 Microsoft XENIX），1990 年代初中国软件所推出 COSIX（中国自主 UNIX，基于 System V）；FreeBSD 在中国的早期采用可追溯至 1998-2000 年，FreeBSD China User Group（1999 年起）与 china-code.net、freebsdchina.org 等社区推动 FreeBSD 在中国 ISP 与高校的采用；至 2026 年北京仍是中国 CS 学术与政策中心，但 BSD/UNIX 直接采用比例较低，Linux（中标麒麟、统信 UOS）占主导。

上海（中国）：上海是中国金融科技工业与外资科技企业的核心；1980-1990 年代上海贝尔（上海贝尔电话设备制造有限公司，1984 年合资）引入 UNIX 用于电信交换机系统，是上海 UNIX 工业的早期节点；2000 年代后上海张江高科技园区聚集 IBM、Microsoft、Intel、AMD、Sun 等外资研发中心，部分基于 UNIX/BSD 谱系；2020 年代后上海陆家嘴金融科技工业部分采用 BSD/UNIX 谱系（如 FreeBSD 在金融低延迟交易系统中的采用）；至 2026 年上海仍是中国金融科技与外资研发中心，但 BSD/UNIX 直接采用比例较低。

深圳（中国）：深圳是中国硬件工业与互联网工业的核心；1980 年深圳经济特区成立后逐步聚集华为（1987 年创立）、中兴通讯（1985 年创立）、腾讯（1998 年创立）、大疆（2006 年创立）等科技企业；华为 1990 年代起在电信设备中采用 VxWorks、Linux、FreeBSD（部分产品）等嵌入式操作系统，2000 年代后华为 VRP（Versatile Routing Platform）网络操作系统部分基于 FreeBSD；中兴通讯、H3C 等电信设备厂商亦有 FreeBSD 采用案例；腾讯、阿里巴巴、百度等互联网公司早期部分采用 FreeBSD（如腾讯 QQ 早期服务器、网易部分服务），后逐步转向 Linux；FreeBSD 在中国互联网公司的 “早期采用、后期转向 Linux” 模式是 2000-2010 年代的普遍现象；至 2026 年深圳仍是中国硬件工业与互联网工业的核心，但 BSD 直接采用比例较低，Linux 与自研系统（如鸿蒙 HarmonyOS）占主导。

台北（中国台湾地区）：台北是新竹科学工业园区（1980 年设立）的行政母城市，是台湾半导体与计算机工业的核心；1980-1990 年代台湾计算机工业以宏碁（Acer，1976 年创立）、大众计算机（FIC，1980 年创立）、华硕（ASUS，1989 年创立）、技嘉（Gigabyte，1986 年创立）、微星（MSI，1986 年创立）等 PC 厂商为核心，但 UNIX/BSD 谱系在台湾的直接采用较少；台湾 BSD 用户组（TLUG、BSD Taiwan 等）1990 年代起推动 FreeBSD/OpenBSD/NetBSD 在台湾的采用；新竹科学工业园区邻近台湾清华大学、台湾交通大学等高校，使台湾形成 “学术-半导体工业” 复合体；至 2026 年台北仍是全球半导体工业的核心节点（TSMC、MediaTek、联发科等），但 BSD/UNIX 直接采用比例较低，Linux 与 Windows 占主导。

首尔（韩国）：首尔是韩国政治经济文化中心与韩国科技工业的核心；1980-1990 年代韩国计算机工业以三星电子、LG 电子、现代电子等财阀为核心，但 UNIX/BSD 谱系在韩国的直接采用较少；1990 年代韩国政府推动 “民族 Linux” 战略（Hangul Linux、Asia Linux 等），与 BSD 谱系形成对照；韩国 BSD 用户组（Korea BSD User Group，KBSD 等）2000 年代起推动 FreeBSD/OpenBSD/NetBSD 在韩国的采用；至 2026 年首尔仍是韩国科技工业的核心，但 BSD/UNIX 直接采用比例较低，Linux 与 Android 占主导。

#### 辨析

**JUST 成立年份辨析**：部分二手资料称 “JUST 1981 年成立”，部分称 “1982 年” 或 “1983 年”；考据结论：JUST 于 1981 年 4 月成立，是日本最早的 UNIX 用户组。本子节采用 “JUST 1981 年成立” 的限定性表述。

**NetBSD/pc98 移植起始年份辨析**：部分二手资料称 “NetBSD/pc98 1994 年移植”，部分称 “1995 年” 或 “1996 年”；考据结论：NetBSD/pc98 移植始于 1994 年，1996 年正式合并入 NetBSD 主干。本子节采用 “1994 年移植启动，1996 年合并入主干” 的限定性表述。

**FreeBSD China User Group 成立时间辨析**：部分二手资料称 “FreeBSD China 1999 年成立”，部分称 “1998 年” 或 “2000 年”；考据结论：FreeBSD China User Group 1999 年由志愿者在北京创建，freebsdchina.org 域名 2000 年注册。本子节采用 “1999 年成立，2000 年域名注册” 的限定性表述。

**华为 VRP 是否基于 FreeBSD 辨析**：部分二手资料称 “华为 VRP 基于 FreeBSD”，部分否认；考据结论：华为 VRP（Versatile Routing Platform）早期版本（VRP v3、v5）部分基于 FreeBSD 与 Linux 混合，后续版本（VRP v8）转向 Linux 容器化架构。本子节采用 “华为 VRP 早期部分基于 FreeBSD，后续转向 Linux” 的限定性表述。
