# 348.3.4 史料辨析：媒体报道与公众认知调查

  **要点**：媒体报道与公众认知调查的史料辨析须包括——媒体报道的代表性（主流媒体 vs 技术媒体 vs 自媒体）、公众认知调查的方法论（问卷调查 vs 焦点小组 vs 社区讨论分析）、媒体报道与公众认知的相互作用；用户文章关于公众认知的论述须按 0 信任原则考据
  **史料**：媒体报道档案；公众认知调查；用户文章 ［C］
  **史观**：史学方法论，媒体报道与公众认知调查的多重交叉验证是史学方法的体现
  **辨析**：媒体报道的代表性须考察；公众认知调查的方法论须明确；用户文章的论断须考据
  **文献**：媒体报道档案；公众认知调查；用户文章 ［C］
