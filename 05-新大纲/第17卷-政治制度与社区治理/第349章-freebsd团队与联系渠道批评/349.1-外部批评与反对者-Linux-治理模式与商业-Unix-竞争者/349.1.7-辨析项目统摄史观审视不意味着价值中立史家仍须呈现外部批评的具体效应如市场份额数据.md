# 349.1.7 辨析项目统摄史观审视不意味着价值中立史家仍须呈现外部批评的具体效应如市场份额数据

  **辨析**：项目统摄史观审视不意味着价值中立——史家仍须呈现外部批评的具体效应（如市场份额数据、技术引入时间线、committer 数量趋势、工业部署案例），但不得以“Linux 优于 BSD”或“BSD 优于 Linux”的前理解预先判定；【0 信任原则·本体论平等的非相对主义】本体论平等不意味着所有立场无差别，而是意味着差异是一刻状态的不同而非本体等级的高下——BSD license 与 GPL 在本体论上地位相等不意味着二者在实践效应上无差异，FSF 推荐 Apache 2.0 而非 BSD license 是实践性偏好而非本体等级判断；【0 信任原则·本体论平等与考据验证的区分】本体论平等是史观预设而非考据结论——史家仍须以多源交叉验证逼近史实，本体论平等不豁免考据义务；【0 信任原则·叙事权力的自觉】本节作为项目统摄史观审视，自身亦嵌入项目统摄史观的前理解，须自觉呈现这一前理解而非伪装中立；【0 信任原则·辩证链的非终结性】辩证链四层（批评-反批评-再批评-合图）不是史家认识的终结而是阶段性综合——合图本身嵌入特定前理解，随 BSD 与 Linux 生态演进须重新展开；【0 信任原则·对称呈现的限度】本节试图使外部批评各阵营与 BSD 阵营论点对称呈现，但“对称”本身是史家的形式主义建构——史料的不对称性（Linux 社区批评叙事丰富、BSD 阵营回应叙事相对稀缺，特别是 freebsd-advocacy 邮件列表在 2022-2024 年近乎停滞）使绝对对称不可能，史家须自觉呈现这一限度；【0 信任原则·历史小说性的非虚无主义】总纲第 23 条“一切历史写作都是基于哲学设定的历史小说”不意味着历史写作无意义，而是意味着史家须自觉呈现自身的哲学设定，使叙事在知晓设定的前提下具有有限的合理性与可验证性——本节的辩证链补足与考据留痕即是这一非虚无主义解读的具体实践
