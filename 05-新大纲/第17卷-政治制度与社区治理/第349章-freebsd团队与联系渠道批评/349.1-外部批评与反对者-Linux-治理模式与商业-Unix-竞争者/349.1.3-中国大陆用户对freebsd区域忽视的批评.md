# 349.1.3 中国大陆用户对 FreeBSD 区域忽视的批评

  **要点**：中国大陆 FreeBSD 用户对 FreeBSD Foundation 区域忽视的批评包括——无官方镜像站、无中文文档支持、无中国大陆社区投入、无中国大陆 committer 培养；批评主要见于中文技术社区（如 freebsdchina.org 历史存档、知乎、V2EX、中文 BSD 邮件列表）；参见相关章节 Linux 中文社区对 BSD 的批评部分；中国大陆用户的批评须辩证看待——部分批评成立（如镜像站缺位），部分批评是中文社区自身问题的外部归因
  **史料**：freebsdchina.org 历史存档；知乎/V2EX 中文 BSD 讨论档案；中文 BSD 邮件列表；参见相关章节中文 BSD 社区部分史料 ［A］
  **史观**：历史解释学与权力，中国大陆用户批评是地缘权力运作的话语呈现；法哲学与政治历史哲学，区域忽视批评涉及政治与法律的交织
  **辨析**：中国大陆用户批评的具体来源须考据；批评的成立性须逐一分析；中文社区自身问题的归因须谨慎
  **文献**：freebsdchina.org 存档；知乎/V2EX 档案；中文 BSD 邮件列表 ［A］
