# 353.1.3 总纲第 13、19、21 条的最终综合审视：BSD 治理批评三重张力的收束

  **要点**：综合项目史观总纲第 13 条（许可证哲学）、第 19 条（解释学循环与权力知识共谋）、第 21 条（革命与改革）三个视角，BSD 治理批评的最终综合审视揭示三重张力的收束——其一，总纲第 13 条的最终审视：BSD 治理批评的历史演变与未来展望皆是利益分配的话语呈现——CSRG 精英主导传统、FreeBSD Core Team 选举权限制（active committer 门槛）、OpenBSD BDFL 模式（de Raadt 个人主导）、NetBSD Foundation 执行委员会制、BSD license 与 GPL 差异（消极自由 vs 积极自由）、2026 FreeBSD 新章程任期限制皆是利益分配机制的具体显现；这些利益分配机制在本体论上地位相等（总纲第 8 条），无道德高下之分——BSD license 允许商业公司免费使用代码是消极自由的利益分配，GPL 强制衍生作品开源是积极自由的利益分配，二者皆是合法的自由软件许可证（FSF 官方将 BSD 系许可证列为“GPL-Compatible Free Software Licenses”，经 <https://www.gnu.org/licenses/license-list.en.html> 一手核验）；其二，总纲第 19 条的最终审视：BSD 治理批评的叙事建构受前理解差异制约——BSD 阵营以“工程传统”“治理独立性”为前理解，Linux 阵营以“治理现代化”“市场份额”为前理解，中国大陆用户以“区域重视”为前理解，商业 Unix 阵营以“商业支持”为前理解，学术研究者以“文明层积”为前理解，五者难以通约；权力与知识在 BSD 治理批评的叙事建构中共谋——“BSD is dying”叙事的传播渠道非对称性（Linux 阵营多渠道 vs BSD 阵营 freebsd-advocacy 邮件列表 2022-2024 年共 7 条消息，经 <https://lists.freebsd.org/archives/freebsd-advocacy/> 一手核验）、daemon 版权私有化使文化叙事权集中于 McKusick 个人、Core Team 决策过程的“闭门会议”传统、OpenBSD“政治最小化”原则排除治理民主讨论，皆是权力知识共谋的具体显现；其三，总纲第 21 条的最终审视：BSD 治理批评的核心张力是“革命性”治理重构与“改革性”渐进调整的方法论分歧——Linux 治理模式经历了多次革命性重构（1991 年 Linus Torvalds 个人发起 Linux 内核、2000 年 OSDL 由 IBM、HP、Intel 等企业创立、2007 年 1 月 22 日 OSDL 与 Free Standards Group 合并成立 Linux Foundation、2014 年后 CNCF、Kubernetes、Hyperledger 等多项目托管扩展），每次重构都是治理结构的根本性变革；BSD 治理模式则是渐进改革——FreeBSD Core Team 2000 年章程沿用 26 年至 2026 年才通过新章程，新章程拟 2028 年生效，过渡期长达 2 年，改革幅度仅限于任期限制与年度选举，未触及核心团队制本身；OpenBSD 自 1995 年至今 31 年治理结构基本未变，仍由 Theo de Raadt 个人主导；NetBSD Foundation 自 2003 年成立 <core@NetBSD.org> 等执行委员会后治理结构基本稳定；“改革的困难远高于革命”在 FreeBSD 2026 新章程的延迟生效（2028 年）中具体显现，“破山中贼易，破心中贼难”在 committer 群体与 Core Team 成员对治理惯性的内化中具体显现；其四，三重张力的收束：许可证哲学维度的“消极自由 vs 积极自由”张力、解释学循环维度的“前理解差异”张力、革命与改革维度的“改革性 vs 革命性”张力是 BSD 治理批评的结构性矛盾，不可能通过单次审视完全消除——BSD license 的宽松性是 BSD 阵营有意识的哲学选择，GPL 的 copyleft 亦是 GPL 阵营有意识的哲学选择，二者的差异是“心中贼”而非“山中贼”；前理解差异使分歧不可避免，史家的叙事重构须面对既有前理解的惯性阻力；“改革性”与“革命性”是历史方法论的不同而非本体等级的高下，BSD“改革性”治理传统的延续与 Linux“革命性”治理传统的重构在本体论上地位相等；其五，本审视作为历史小说的自觉（总纲第 23 条）：本节作为 BSD 治理批评三重张力收束的审视，本身是基于项目统摄史观设定的历史小说——“三重张力”的归纳是史家的形式主义建构，实际治理批评过程是多重张力交织的复杂形态，史家须自觉呈现这一建构而非伪装客观中立的旁观者
  **史料**：项目史观总纲第 13、19、21、8、23 条原文（据原文第 25 章，第 13 条“法律与道德是利益分配，社区治理亦是形式主义的政治产物”，第 19 条“前理解的差异使分歧不可避免，权力与知识在历史书写中共谋”，第 21 条“革命与改革是历史方法论的分歧，Linux 靠革命，BSD 靠改革，改革的困难远高于革命，破山中贼易，破心中贼难”，第 8 条“本体论上各方平等”，第 23 条“一切历史写作都是基于哲学设定的历史小说”）；FreeBSD Core Bylaws 2000.8.28 版与 2026.5.27 新版（<https://www.freebsd.org/internal/bylaws/>，作为治理改革具体实践的证据）；FreeBSD BSD Daemon 版权页面（<https://www.freebsd.org/copyright/daemon/>，作为文化符号私有化的证据）；OpenBSD Project Goals（<https://www.openbsd.org/goals.html>，作为“政治最小化”原则的证据）；FSF 官方许可证列表（<https://www.gnu.org/licenses/license-list.en.html>，作为 BSD license 与 GPL 本体论平等的权威参照）；freebsd-advocacy 邮件列表存档（<https://lists.freebsd.org/archives/freebsd-advocacy/>，2022-2024 年共 7 条消息，作为 BSD 阵营话语权争夺正式渠道近乎停滞的证据）；Linux Foundation 合并档案（2007-01-22，作为 Linux 治理革命性重构的证据）；FreeBSD Core Team Activity Reports（Core.10 回顾 2020-07-27，作为“小圈子循环”现象的证据）；第 15.1-20.20〔存疑：旧卷章节号体系残留，现行对应节号待核〕 节史料综合；参见相关章节 BSD 治理改革与 Linux 治理重构部分史料 ［A］
  **史观**：总纲第 13 条——法律与道德是利益分配，BSD 治理批评的叙事建构皆是利益分配的话语呈现；总纲第 19 条——解释学循环是历史认识的根本条件（原“解释学循环与权力知识共谋”系名目变体，正名），BSD 治理批评的叙事建构受前理解差异制约，话语权争夺的非对称性是权力知识共谋的具体显现；总纲第 21 条——革命与改革，BSD 治理批评叙事的“改革性”与 Linux“革命性”是历史方法论的不同，“改革的困难远高于革命”“破山中贼易，破心中贼难”在 BSD 治理改革中具体显现；总纲第 8 条——本体论上各方平等，BSD 治理模式与 Linux 治理模式、BSD license 与 GPL、改革性与革命性在本体论上地位相等；总纲第 23 条——一切历史写作都是基于哲学设定的历史小说，本节作为 BSD 治理批评三重张力收束的审视本身是历史小说，史家须自觉呈现自身的哲学设定
  **辨析**：考据过程留痕——【查证来源】合图层史料综合第 15.1-20.20〔存疑：旧卷章节号体系残留，现行对应节号待核〕 节所有引用的一手与二手史料，包括 FreeBSD Core Bylaws 2000.8.28 版与 2026.5.27 新版（经 <https://www.freebsd.org/internal/bylaws/> 一手核验）、FreeBSD BSD Daemon 版权页面（经 <https://www.freebsd.org/copyright/daemon/> 一手核验）、OpenBSD Project Goals（经 <https://www.openbsd.org/goals.html> 一手核验）、FSF 官方许可证列表（经 <https://www.gnu.org/licenses/license-list.en.html> 一手核验）、freebsd-advocacy 邮件列表存档（经 <https://lists.freebsd.org/archives/freebsd-advocacy/> 一手核验，2022-2024 年共 7 条消息）、Linux Foundation 合并档案（2007-01-22）、FreeBSD Core Team Activity Reports（Core.10 回顾 2020-07-27）；【交叉验证方法】“三重张力收束”的关键论断须以三重交叉验证——其一，许可证哲学维度须以 BSD daemon 版权私有化（McKusick 个人持有）、FreeBSD Core Team 选举权限制（active committer 门槛）、OpenBSD de Raadt 个人主导、BSD license 与 GPL 差异四个案例互证，确认“利益分配”是各案例的共同结构；其二，解释学循环维度须以 BSD 阵营、Linux 阵营、中国大陆用户、商业 Unix 阵营、学术研究者五方的前理解差异互证，确认“前理解差异使分歧不可避免”；其三，革命与改革维度须以 FreeBSD Core Bylaws 演化（2000 旧章程沿用 26 年至 2026 新章程）与 Linux Foundation 治理重构（1991 个人发起 → 2007 Linux Foundation → 2014 后多项目托管）的时间线互证，确认“改革性”与“革命性”是历史方法论的不同；【0 信任原则·“三重张力”归纳的形式主义建构】“三重张力”（许可证哲学、解释学循环、革命与改革）的归纳是史家的形式主义建构——实际治理批评过程是多重张力交织的复杂形态，如 daemon 版权私有化既是许可证哲学维度的利益分配，也是解释学循环维度的话语权非对称性，亦是革命与改革维度的“改革性”传统延续，三者难以完全分离；【0 信任原则·合图的非终结性】合图并非辩证链的终结而是阶段性综合，随 BSD 与 Linux 生态演进（如 2028 年 FreeBSD 新章程生效、OpenBSD 传承规划公开、Linux Foundation 治理调整、GPL 阵营新动态）须重新展开；【0 信任原则·合图的非折中主义】合图不是“BSD 在治理改革上合理、在治理批评上不合理”的简单分类，而是揭示“消极自由”与“积极自由”、“前理解差异”与“话语权非对称性”、“改革性”与“革命性”的张力——BSD 以积极自由、话语权非对称性、革命性换取消极自由、前理解差异、改革性是结构性选择而非道德缺陷，但这一选择的代价须被自觉呈现；【0 信任原则·本体论平等与考据验证的区分】本体论平等是史观预设而非考据结论——史家仍须以多源交叉验证逼近史实，本体论平等不豁免考据义务；【0 信任原则·争议不可调和性的非虚无主义】“争议不可完全调和性”不意味着审视无意义，而是意味着审视须自觉呈现争议的结构性矛盾，使读者在知晓矛盾的前提下评估叙事的合理性与局限性——本节的最终综合审视与考据留痕即是这一非虚无主义解读的具体实践；【0 信任原则·叙事权力的自觉】本节作为最终综合审视，自身亦嵌入项目统摄史观的前理解，须自觉呈现这一前理解而非伪装中立；【0 信任原则·对称呈现的限度】本节试图使各阵营论点对称呈现，但“对称”本身是史家的形式主义建构——史料的不对称性（Linux 阵营叙事丰富、BSD 阵营叙事相对稀缺，特别是 freebsd-advocacy 邮件列表在 2022-2024 年近乎停滞）使绝对对称不可能，史家须自觉呈现这一限度
