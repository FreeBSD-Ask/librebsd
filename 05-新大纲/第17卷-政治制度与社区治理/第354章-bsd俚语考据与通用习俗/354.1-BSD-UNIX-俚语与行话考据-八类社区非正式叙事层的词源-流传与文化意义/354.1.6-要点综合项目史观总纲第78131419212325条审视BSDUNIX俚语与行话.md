# 354.1.6 要点综合项目史观总纲第78131419212325条审视BSDUNIX俚语与行话

  **要点**：综合项目史观总纲第 7、8、13、14、19、21、23、25 条审视，BSD/UNIX 俚语与行话的八类词条（BSD 专属、UNIX 通用、黑客文化通用、BSD/Linux 论战、版本号、工具与命令、文件系统、文化梗）呈现五重结构——其一，词源层积的史观审视（总纲第 7、25 条）：daemon 从 Maxwell's Demon（1867 物理思想实验）→ CTSS DAEMON 程序（1960s MIT 计算领域引入）→ BSD Daemon 吉祥物（1988 Lasseter 绘制）的跨域迁移，hacker 从 MIT TMRC 1960 年代“用巧妙方法解决问题的人”到 1990 年代“恶意入侵者”的语义漂变，皆是词源层积的典型呈现，“终结中的延续”在 daemon 守护神意涵被基督教化覆盖但未消亡中得到体现；其二，本体论平等审视（总纲第 8 条）：BSD 专属俚语与 UNIX 通用俚语与黑客文化通用俚语在本体论上地位相等，BSD license 与 GPL、master 与 main 分支名称、BSD“改革性”与 Linux“革命性”在本体论上地位相等，无道德高下之分；其三，利益分配审视（总纲第 13 条）：BSD Daemon 版权由 McKusick 个人持有是文化符号私有化的利益分配，commit bit 三类分权是子树治理权限的利益分配，NetBSD tainted code 政策是代码来源可追溯性的利益分配，RTFM 与 PEBKAC 等技术支持黑话是“将故障归因于用户而非系统”的利益分配，hacker 与 cracker 的区分是 1980 年代黑客社区为维护“黑客”正面形象而进行的利益分配；其四，解释学循环与权力知识共谋审视（总纲第 19 条）：“BSD is dying”梗的传播渠道非对称性（Linux 阵营多渠道 vs BSD 阵营 `freebsd-advocacy` 邮件列表 2022-2024 年共 7 条消息，经 `lists.freebsd.org/archives/freebsd-advocacy/` 一手核验）是权力知识共谋的具体显现，UNIX 通用俚语是 UNIX 文化话语权的具体显现，掌握俚语即掌握社区身份认同的话语权；其五，历史小说性审视（总纲第 23 条）：本节作为 BSD/UNIX 俚语与行话的综合审视，本身是基于项目统摄史观设定的历史小说——“八类俚语”的归纳是史家的形式主义建构，实际俚语生态是多重文化层交织的复杂形态，史家须自觉呈现这一建构而非伪装客观中立的旁观者
  **史料**：项目史观总纲第 7、8、13、14、19、21、23、25 条原文（据原文第 25 章，第 7 条“文化历史哲学”，第 8 条“本体论上各方平等”，第 13 条“法律与道德是利益分配〔原后半句“社区治理亦是形式主义的政治产物”系增衍，已删〕”，第 14 条“社区与文明历史哲学”，第 19 条“前理解的差异使分歧不可避免，权力与知识在历史书写中共谋”，第 21 条“革命与改革是历史方法论的分歧，Linux 靠革命，BSD 靠改革”，第 23 条“一切历史写作都是基于哲学设定的历史小说”，第 25 条“终结中的延续”）；Jargon File 4.4.7 版本（`catb.org/jargon/`，八类俚语词条综合，经一手核验）；Marshall Kirk McKusick 个人站点 beastie 页（`mckusick.com/beastie/`，BSD Daemon 版权与命名说明，经一手核验）；FreeBSD Committer's Guide（`docs.freebsd.org/en/articles/committers-guide/`，commit bit 三类分权与分支约定，经一手核验）；NetBSD Commit Guidelines（互联网档案馆 2024 年存档版本，tainted code 政策原文，经一手核验）；`freebsd-advocacy` 邮件列表存档（`lists.freebsd.org/archives/freebsd-advocacy/`，2022-2024 年共 7 条消息，作为 BSD 阵营话语权争夺正式渠道近乎停滞的证据，经一手核验）；第 22.22.1-22.22.5〔待核实节号〕 节史料综合；参见相关章节 BSD 文化溯源与治理批评部分史料 ［A］
  **史观**：专题语（不设总纲条号）——文化历史哲学（原挂总纲第 7 条系自创名目，删条号），BSD/UNIX 俚语的词源层积是 BSD/UNIX 文化历史哲学的微观显现；总纲第 8 条——本体论上各方平等，八类俚语在本体论上地位相等，BSD 阵营与 Linux 阵营、BSD license 与 GPL、master 与 main 在本体论上地位相等；总纲第 13 条——法律与道德是利益分配，BSD Daemon 版权私有化、commit bit 三类分权、NetBSD tainted code 政策、RTFM/PEBKAC 技术支持黑话、hacker/cracker 区分皆是利益分配机制的具体显现；总纲第 15 条——文化即形式主义（原“社区与文明历史哲学”系自创名目，按文化论旨改挂，存疑），跨文化翻译中的语义错位是文明接触带的典型现象；总纲第 19 条——解释学循环是历史认识的根本条件（原“解释学循环与权力知识共谋”系增衍名目，正名），BSD/UNIX 俚语的叙事建构受前理解差异制约，“BSD is dying”梗的传播渠道非对称性是权力知识共谋的具体显现；总纲第 21 条——革命与改革，BSD“改革性”俚语传统（如 MFC 约定沿用 26 年）与 Linux“革命性”俚语重构（如 master 替换为 main）在本体论上地位相等；总纲第 23 条——一切历史写作都是基于哲学设定的历史小说，本节作为 BSD/UNIX 俚语综合审视本身是历史小说，史家须自觉呈现自身的哲学设定；总纲第 4 条——分离聚合是永恒规律（原“终结中的延续”系自创名目，按族例改挂），daemon 守护神意涵被基督教化覆盖但未消亡，是“终结中的延续”在词源层面的典型呈现
