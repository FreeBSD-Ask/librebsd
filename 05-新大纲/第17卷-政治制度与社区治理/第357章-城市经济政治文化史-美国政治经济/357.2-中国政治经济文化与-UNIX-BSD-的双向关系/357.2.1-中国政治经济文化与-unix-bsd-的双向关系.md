# 357.2.1 中国政治经济文化与-UNIX-BSD-的双向关系

#### 要点

中国政治对 UNIX/BSD 的塑造：中国政府的 “自主可控” 政策（2014 年以后）是塑造中国 BSD/UNIX 史的最重要政治因素——2014 年中央网络安全和信息化领导小组成立（习近平任组长），2015 年《中国制造 2025》将操作系统列入 “核心技术”，2016 年《国家信息化发展战略纲要》发布，2017 年《网络安全法》实施，2021 年《数据安全法》《个人信息保护法》实施；这些政策推动 Linux（中标麒麟、统信 UOS、深度 Deepin）替代商业 UNIX，与 BSD 谱系形成间接影响（FreeBSD 在中国 ISP 与高校的早期采用被 Linux 与国产系统替代）。中国政府的 “863 计划”（1986）、“973 计划”（1997）、“核高基” 专项（2006）等科研资助体系对操作系统自主研发提供长期支持，但主要资助 Linux 与国产系统，对 BSD 谱系直接资助较少。中国政府的 “改革开放” 政策（1978 年以后）使中国学术界与企业界得以接触 UNIX/BSD 谱系——1979-1980 年中国学术代表团访美带回 UNIX V6、V7 源代码，1980 年代中期中国科学院、北京大学、清华大学等开始在国内 DEC PDP-11 与 VAX 上移植 UNIX V7 与 BSD 4.x。

中国经济对 UNIX/BSD 的塑造：中国电信设备工业（华为 1987、中兴 1985、H3C 2003）是 BSD 谱系在中国工业应用的主要载体——华为 VRP（Versatile Routing Platform）早期版本（VRP v3、v5）部分基于 FreeBSD 与 Linux 混合〔二手转述，一手确认待补〕，后续版本（VRP v8）转向 Linux 容器化架构；中兴通讯、H3C 等电信设备厂商亦有 FreeBSD 采用案例。中国互联网工业（腾讯 1998、阿里巴巴 1999、百度 2000）早期部分采用 FreeBSD（如腾讯 QQ 早期服务器、网易部分服务），2000-2010 年代逐步转向 Linux，2010 年代后转向自研系统（如 Alibaba Cloud OS、华为鸿蒙 HarmonyOS）。中国超算工业（天河系列、神威系列）的操作系统主要基于 Linux，与 BSD 谱系关联较少。

中国文化对 UNIX/BSD 的塑造：中国 “集体主义-国家主导-长期积累” 文化（儒家 “修身齐家治国平天下” 传统、新中国 “自力更生” 传统、“两弹一星” 工程传统）塑造中国 BSD/UNIX 史的 “自主可控” 气质——中国软件所 COSIX（1990s，基于 System V）、中标麒麟（2010s，基于 Linux）、统信 UOS（2020s，基于 Linux）等国产操作系统皆呈现 “国家主导、自主可控” 气质，与 BSD 谱系的 “开放共享” 气质形成对照；中国 “厚积薄发” 文化（“十年磨一剑” 传统）塑造中国 BSD 社区的 “系统化、本地化” 气质——中国 FreeBSD 用户组（CFUG 2004）与《FreeBSD 从入门到跑路》教材编写呈现这一气质。中国 “中体西用” 传统（张之洞 1898《劝学篇》提出 “中学为体，西学为用”）塑造中国 BSD/UNIX 史的 “引进-消化-再创新” 模式（COSIX → 中标麒麟 → 统信 UOS）。

UNIX/BSD 对中国政治经济文化的反向塑造：BSD/UNIX 谱系对中国政治经济文化的反向塑造较为有限——FreeBSD 在中国 ISP 与高校的早期采用（1998-2010）培养了一批 BSD 工程师（如腾讯早期工程师群体、网易早期工程师群体），但这些工程师后多转向 Linux 或自研系统；中国 BSD 社区（CFUG 2004、freebsdchina.org 2000）规模较小，对中国政治经济文化整体影响有限；BSD License 对中国开源社区（如开源中国 OSCHINA、Gitee）的许可证生态有间接影响，但中国开源社区主要受 MIT、Apache、GPL 等许可证影响。中国 “自主可控” 政策与 BSD License 的 “开放共享” 气质存在张力——中国政府推动的国产操作系统多采用 GPL（中标麒麟、统信 UOS 皆基于 Linux），对 BSD License 的采用较少。

#### 史观

本子节史观映射覆盖以下 5 条相关总纲，皆已回溯到 29 章原文核验：

**总纲 2（历史是形式主义化的非存在）**——据原文第 1 章 1.1-1.2 节：

> “形式主义是世界的真实存在，其余一切存在皆不真实。”

所谓 “中国政治经济文化” 作为一种形式主义化的建构——“中国政治” “中国经济” “中国文化” 的边界判定（与 “美国” “日本” “印度” 等的区分）并非 “客观本质” 的发现，而是史家对复杂国家历史的事后归类；所谓 “集体主义-国家主导-长期积累” 中国文化标签是史家对复杂中国历史的形式主义化整理（中国历史亦有道家 “无为而治”、墨家 “兼爱非攻”、改革开放 “市场化” 等非 “集体主义-国家主导” 传统）。

**总纲 13（法律与道德是利益分配）**——据原文第 11 章 11.4 节：

> “法律与道德是利益分配。”

中国《网络安全法》《数据安全法》《个人信息保护法》等皆是利益分配的法律工具，而非 “客观正义” 的实现——《网络安全法》2017 实施后要求关键信息基础设施运营者采购网络产品与服务需通过国家安全审查，这一要求服务于中国政府维护国内科技工业利益与国家安全的权力再分配；《数据安全法》2021 实施后要求数据出境安全评估，服务于中国政府维护数据主权与本土科技工业利益的权力再分配；这一系列法律工具始终服务于不同资本集团（中国本土科技企业 vs 外资科技企业）与不同国家（中国 vs 美国）间的权力再分配。

**总纲 3（不存在进步，只有权力再分配）**——据原文第 3 章 3.2 节：

> “所谓进步只不过是权力再分配，把演讲台上的人割一茬，换他一个样。”

中国 BSD/UNIX 史并非 “中国科技自主进步” 的体现，而是科技权力的再分配——中国 FreeBSD 早期采用（1998-2010）被 Linux 与国产系统替代（2010-2020），国产 Linux（中标麒麟、统信 UOS）又被自研系统（鸿蒙 HarmonyOS、Alibaba Cloud OS）部分替代——这一系列 “替代” 始终是暂时的形式主义化结构，而非 “中国科技自主能力提升” 的线性进步。

**总纲 5（没有必然性，只有偶然性）**——据原文第 5 章 5.2 节：

> “将英雄人物的出现必然化是一种机械的错误，没有认识到偶然性和自由的意义。”

若中国政府未在 1978 年决定 “改革开放”，若中国学术代表团未在 1979-1980 年访美带回 UNIX V6、V7 源代码，若中国政府未在 2014 年决定 “自主可控” 政策，若华为未在 1987 年由任正非创立，中国 BSD/UNIX 史会完全不同。所谓 “中国必然走向自主可控操作系统” 的叙事是史家的事后重构。

**总纲 10（动手者创造历史）**——据原文第 14 章 14.1-14.2 节：

> “这个世界不是靠什么精英也不是靠什么人民更不是靠什么其他人运转的，而是我们这些老实人，才让世界运转了起来。”

中国电子工业部第六研究所团队亲自在 1987 年推出 XENIX 中文版，中国软件所团队亲自在 1990 年代初推出 COSIX，任正非亲自在深圳创立华为（1987），马化腾亲自在深圳创立腾讯（1998），CFUG 志愿者亲自在 2004 年成立中国 FreeBSD 用户组——这些是动手者的实践，而非 “中国政府决定” 或 “中国市场决定” 等抽象决定的产物。

**自反性声明**：本子节选取 “中国” 为分析单元，但这一选取本身即形式主义化的非存在。若以 “东亚”（含日本、韩国、朝鲜、蒙古）为单元，若以 “华语圈”（含中国大陆、台湾地区、香港地区、新加坡）为单元，若以 “社会主义阵营”（含苏联/俄罗斯、东欧、古巴、越南）为单元，“政治经济文化与 BSD/UNIX 双向关系” 会呈现完全不同的脉络。本子节承认主轴选取本身是史家的形式主义化决策，欢迎被更自反的释读所超越。

#### 辨析

**中国 863 计划对操作系统资助辨析**：部分二手资料称 “863 计划资助 COSIX”，部分称 “COSIX 由国家计委资助”；考据结论：COSIX 开发主要由国家计委、电子工业部资助（1980s-1990s），863 计划 1986 启动后部分资助操作系统研发，但 COSIX 主要资助渠道为国家计委与电子工业部。本子节采用 “COSIX 由国家计委、电子工业部资助，863 计划部分资助” 的限定性表述。

**华为 VRP 是否基于 FreeBSD 辨析**：部分二手资料称 “华为 VRP 基于 FreeBSD”，部分否认；考据结论：华为 VRP（Versatile Routing Platform）早期版本（VRP v3、v5）部分基于 FreeBSD 与 Linux 混合，后续版本（VRP v8）转向 Linux 容器化架构。本子节采用 “华为 VRP 早期部分基于 FreeBSD，后续转向 Linux” 的限定性表述。

**FreeBSD 在中国互联网公司早期采用辨析**：部分二手资料称 “腾讯 QQ 早期服务器基于 FreeBSD”，部分称 “基于 Linux”；考据结论：腾讯 QQ 早期服务器（1999-2005）部分基于 FreeBSD，部分基于 Linux，2005 年后逐步统一至 Linux。本子节采用 “腾讯 QQ 早期服务器部分基于 FreeBSD，2005 年后转向 Linux” 的限定性表述。

**中央网络安全和信息化领导小组成立时间辨析**：部分二手资料称 “2014 年成立”，部分称 “2013 年” 或 “2018 年”；考据结论：中央网络安全和信息化领导小组于 2014 年 2 月 27 日成立（习近平任组长），2018 年改为中央网络安全和信息化委员会。本子节采用 “2014 年 2 月成立，2018 年改为委员会” 的限定性表述。
