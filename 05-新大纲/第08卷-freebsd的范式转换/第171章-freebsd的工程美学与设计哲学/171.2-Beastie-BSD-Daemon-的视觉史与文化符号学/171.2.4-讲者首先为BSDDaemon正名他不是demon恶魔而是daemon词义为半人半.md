# 171.2.4 讲者首先为BSDDaemon正名他不是demon恶魔而是daemon词义为半人半

- 讲者首先为 BSD Daemon 正名：他不是 demon（恶魔）而是 daemon，词义为半人半神的良善守护精灵、站在人的一边。这个形象从未有过正式名字，社区不断为它起名——早年甚至有一件 T 恤依讲者高中时期一位讨厌同学的玩笑把它标作 Chuck the demon；日后通行的 Beastie 之名，讲者翻查笔记仍无法确定命名者，只能承认不可考。已知最早的 daemon 图像出自 Mike O'Brien 委托的一幅画，讲者曾向 O'Brien 借四件特制 T 恤之一拍照后归还，原作留存于一家家庭印刷店，店主歇业后由 DEC 的 Armando Stettner 取去用于 PDP-11 Unix 的宣传；1985 年 6 月 USENIX 十周年纪念 T 恤复制该图像时抹去了艺术家签名——艺术品被使用时爱被抹去署名，成为贯穿全讲反复出现的母题。（YouTube EP7d7fwAE-2Aw，[44.9-286.0]，L1）[订正：原“讲者曾借原作拍照”→“讲者曾向 O'Brien 借四件特制 T 恤之一拍照后归还”，内容复核：新转写载借拍对象系袖口下摆缀花边的四件特制 T 恤之一（[228.2-236.9]），原作始终留存于家庭印花店（[234.1-243.7]）]
- 第一幅 John Lasseter daemon 源于一段偶然的职业史：Lasseter 时为迪士尼顶级动画师——他向听者解释迪士尼画师的三个层级，顶层画师只画间隔一帧的关键帧，其下是补足中间帧的画师与上色师——依例休半年带薪假，选择去 Lucasfilm 参与动画师工作站项目，为计算机图形工程师补上动画师真正需要的界面视角。返回迪士尼后他力推动画计算机化遭拒——迪士尼自恃全手工品质、称任何人都能买计算机——遂辞职重回 Lucasfilm；彼时 CSRG 正收尾 4.2BSD，同在 Lucasfilm 的 Sam Leffler 牵线，并出示早期 daemon 图请他参照，为 BSD 手册封面绘成第一幅黑白 daemon。因当时须持 AT&T 许可证方可持有 Unix，手册由 USENIX 代印以确保仅售予持证者；画中发光球上印有 Unix TM 字样，日后成为争议点，后续版本的光球上再无任何文字。（YouTube EP7d7fwAE-2Aw，[286.0-603.4]，L1）[订正：原“讲者拿早期 daemon 图请他参照”→“由 Sam 出示早期 daemon 图请他参照”，内容复核：新转写载系当时已在 Lucasfilm 的 Sam 向 Lasseter 出示旧 daemon 图并称“我们需要类似这样的图”（[529.4-546.9]），非讲者亲自出示]
- 第二幅 daemon 与 BSD 教科书出版史交织：CSRG 自 1983 年起就想写 BSD 教科书，Addison-Wesley 要求先获 AT&T 授权，而 AT&T 刚关停逐行注释 Unix 源码的 John Lions 之书——讲者承认在代码尚无版权保护、全凭商业秘密维系的年代，那并非无理——于是要求教科书写完再送审，合作就此搁浅。1986 年 Maurice Bach 的书出版且只记载到函数级接口，讲者据此说服出版社：本书绝不会涉及那样的细节深度，两年后 1988 年 4.3BSD 教科书出版，附有答问集并译成日语，讲者特别称赞在场监督翻译的译者。封面彩图是 Lasseter 已在 Pixar 时应 Sam Leffler 之请所绘：从垃圾桶抽出蓝色纸板、拿粉笔在约二十分钟内画成，迪士尼画风肉眼可辨；出版社先以严肃教科书不登卡通为由拒绝，被作者援引作者权利坚持收录，该书卖出五万册创纪录，内布拉斯加州学区一度以封面有恶魔为由拒其入馆。第三幅为 4.4BSD 教科书封面而作，讲者要求比前两幅更富动感；Lasseter 正忙于《玩具总动员》收尾，讲者以巧克力疏通其秘书才推动进度，画师铺纸研墨后自陈五年未动笔恐已生疏，随即在十分钟内完成；出版社又以发光球看起来太像精子细胞为由，把光球从封面与封底一并移除，只留签名。（YouTube EP7d7fwAE-2Aw，[871.0-1947.5]，L1）
- 讲者以亲历者身份补全 Net/2 重写运动的内幕：Net/2 最初只含 TCP/IP 代码与工具，社区不断要求更多，Keith Bostic 便在 USENIX 会议上以“让你的名字亮起来”号召重写 AT&T 的工具与库；投稿大多业余，Bostic 几乎从头重写却不署己名，一律保留贡献者姓名。内核侧由 Mike Karels 与讲者负责且进度滞后，被 Bostic 以“库与工具已过半，内核如何了”当面催问后，二人依其建议从 32V 原始源码出发，先用 C 美化器统一格式、为每一行建立数据库，再与自家内核逐行比对，忽略花括号独占一行之类的排版差异，连续数行相同即视为需要重写——例如把按进程 ID 的线性查找改为哈希查找，既清除 AT&T 代码又顺带更快。清理到最后仅剩六个文件存在显著匹配，Mike Karels 主张发布完整系统只会招来更多法律红旗，不如宣布内核不完整、只发布可发布部分，六个文件以模板存根形式放入——是为 Networking Release 2；定价一千美元，原本预计售出三份即会被放上网免费传播，实际售出约千份、入账约百万美元——买主看重的是加州大学那张自由再分发许可的纸，甚至嘱咐不必寄磁带。（YouTube EP7d7fwAE-2Aw，[1988.6-2243.1]，L1）[订正：原 [1994.279-2243.119] → [1988.6-2243.1]，原[起]越过本条首句——Net/2 最初只含 TCP/IP 代码与工具实出 [1988.6-1999.8] the release of the net 2 version of BSD we had done that one which was just the TCP IP code，原锚起点 1994.3 截于该行句中，内容复核]
- USL 诉讼的亲历叙述补足正史细节：BSDi 创办后即被 AT&T 一方起诉，一审抗辩指出余下六个文件系洁净室重写、完全干净，法官已倾向驳回；原告遂转而追加起诉加州大学，大学立即停止分发——但这无关紧要，拷贝早已散布四方——继而质疑自己不从中获利、为何要出钱辩护。辩护经费正来自 Net/2 销售所得的约百万美元；面对对方的世界级专家证人，加州大学无力聘请对等的专家，讲者便自任专家证人（其细节他留作另讲）。诉讼期间讲者委托一位从未画过此类题材的肖像画家朋友创作反抗 T 恤：一幅 daemon 把被谑称为死星的 AT&T 新标志扣进篮筐，另一幅 daemon 脚踩 Birkenstock 凉鞋立于地球之上以矛刺穿死星。Dennis Ritchie 为此亲自来电：他理解并支持讲者的立场，但所用的标志属于 AT&T 而非起诉方 USL，恳请改用 USL 标志——讲者重印了 USL 标志版本，并至今珍藏一张 Ritchie 购买 T 恤而未兑现的支票。 [存疑脚注] 转写把扣篮 T 恤下方铭文记作 net2 USL Z，具体文字与史实铭文写法待与实物照片核证（YouTube EP7d7fwAE-2Aw，[2243.1-2434.7]，L1）
- daemon 图像的扩散与退场同样由当事人勾勒：Walnut Creek 时期流行的恶魔推着 CD 前行的 T 恤是 FreeBSD 常见形象，但 FreeBSD 最早的 T 恤只是在 daemon 前方添上 Free 字样；早期 NetBSD 与 OpenBSD 也曾沿用 daemon，FreeBSD Foundation 亦用过穿西装的 daemon 形象；此后各发行版与基金会相继弃用——因为恶魔形象在世界部分地区的公众观感不佳——转而启用各自的标志。法律一端，Lasseter 以雇用作品条款把画作著作权转让给讲者个人，转让书由讲者签署、Lasseter 会签，1988 年经版权局登记；经人提醒三十五年续展期已至，讲者正在办理续展。（YouTube EP7d7fwAE-2Aw，[2439.3-2531.4]，L1）[订正：原“把三幅画著作权转让给讲者个人并罕见地在画面正面签名”→“把画作著作权转让给讲者个人，转让书由讲者签署、Lasseter 会签”，内容复核：新转写仅载单一转让书、未言明涵盖三幅（[2504.2-2520.3]）；“罕见地在画面正面签名”实为肖像画家朋友之事（[2424.6-2445.1]），Lasseter 签名上 4.4 书封面系因其已成名人（[1797.0-1807.1]）]
- McKusick 强调 BSD 图像人物系 daemon 而非 demon：后者指邪恶精灵，前者承希腊词义的半人半神之中介性存在，故有“做软件至少需要半个神站在你这边”的自况；daemon 从未被项目正式命名，社区不断起名，有人提议 Chuck，但因 Chuck 系演讲人高中时令其头疼之人而被否决（一件 Chuck the Demon 衬衫设计被否决，演讲人自述持有唯一一件），最终定名 Beastie，起名者经翻检笔记与邮件未能查明；NetBSD 与 OpenBSD 早期沿用该形象，FreeBSD Foundation 曾推出西装版本，其后各项目与基金会均因 daemon 在部分文化语境中被视为邪恶精灵、公关不佳而弃用，改换独立标志。[订正：原“某衬衫上出现的 Chuck 之名只是设计被否决的玩笑，起名者已不可考”→新转写证实 Chuck 提议因演讲人高中阴影被否决，起名者不可考系指 Beastie 之定名者]（YouTube EPF9mtbe9vw90，[47.52-112.64]，L1）
- 图像谱系可分三代：最早版本出自 Phil Foglio 手笔，系其为酬谢受过锁匠训练的 Michael O'Brien 开启公寓内置保险箱而作，画面配 PDP-11（当时运行 Unix 的机型），USENIX 于 1985 年 6 月十周年纪念印制 T 恤复用该图时抹去了艺术家签名，这一抹签现象在其后历次授权使用中反复重演；John Lasseter 应 Sam Leffler 之请为 4.2BSD 手册绘制黑白版，又以垃圾桶拾得的蓝色纸板与粉笔在约二十分钟内绘出 4.3 教科书彩色版（署名 Lasseter 88），第三版为 4.4BSD 书而作、姿态更具动感；Addison-Wesley 一度以“严肃计算机科学教科书”为由拒绝卡通封面，经作者坚持方得采用，而发光球体则因被认为形似精子从 4.4 书封面删除。（YouTube EPF9mtbe9vw90，[521.68-548.72]，L1）
- Lasseter 的经历链与 BSD 出版物时间线交织：他原为 Walt Disney 顶级动画师，享六个月带薪学术休假赴 Lucasfilm 参与动画师工作站项目，以其审美判断弥补计算机图形团队对用户界面的一无所知；休假结束返 Disney 倡导电脑动画遭拒（Disney 以手工品质为招牌不肯让渡业务），遂去职重回 Lucasfilm；Lucasfilm 将计算机部门拆分为 Pixar 后，Steve Jobs 促成与 Disney 的五部片约（Disney 全额出资并取九成收益），Lasseter 执导首部作品 Toy Story；恰在 CSRG 收尾 4.2BSD 之际，离开 BSD 转赴 Lucasfilm 的 Sam Leffler 请他为手册封面作画，由此诞生第一版黑白 daemon。[订正：原“六个月停薪留职式学术休假”→“六个月带薪学术休假”，内容复核：新转写载 sabbatical 为“you're still paid”的六个月带薪休假（[363.0-377.6]）]（YouTube EPF9mtbe9vw90，[300.64-497.52]，L1）
- 4.3BSD 教科书出版历经十年波折：CSRG 自 1983 年起计划著书，Addison-Wesley 要求先获 AT&T 许可，AT&T 以当时代码属商业秘密（早于代码版权时代）为由搁置，John Lions 逐行注释 Unix 源码之书即因同一逻辑被封禁；1986 年 Bach 书以接口级描述出版后，CSRG 援引先例说服出版社，1988 年 4.3BSD 书问世并售出五万册创当时纪录，衍生习题册与日语译本（演讲现场观众 Hiroki 曾参与监督翻译）；内布拉斯加州学区图书馆仅因封面上的魔鬼形象拒绝收录该书而未翻阅内文。（YouTube EPF9mtbe9vw90，[867.92-1056.0]，L1）
- Networking Release 2 的重写与随后的诉讼构成连续链条：Keith Bostic 在 USENIX 会议上以“让你的名字出现在灯光下”动员社区重写工具与库，对收到的众多业余水平稿件基本从头重写却不署己名，理由是“把功劳归于他人能成就无尽善举，而且人们会因此去找那个人”；Mike Karels 与 McKusick 负责内核，将 32V 原始源码经 C beautifier 规范化建立逐行数据库与本方内核比对，连续四行以上匹配即触发重写（如把进程查找由线性搜索改为哈希查找，既清除 AT&T 代码又改进性能），最终仅约六个文件存在显著匹配，Karels 建议以“不完整内核”名义仅放入调用模板后发行；预期售出三份的 net/2 实际约千人各付一千美元购买授权文书（部分人不要磁带只要那张可自由再分发的纸），收入约百万美元；BSDI 随之成立并在第一审以六文件出自洁室、其余代码持有加州大学自由再分发授权书抗辩，法官拟驳回后 AT&T 转而起诉加州大学，Dennis Ritchie 私下劝 McKusick 将 T 恤上的 AT&T 死星标志换为 USL 标志，诉讼后期因经费所限 McKusick 自任专家证人。（YouTube EPF9mtbe9vw90，[2015.52-2231.52]，L1）

**史观**：
