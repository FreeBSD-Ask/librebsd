# 172.1.2 CSRG 传统的延续：Bostic、Karels、Leffler 等人的科学精神

**要点**：CSRG（Computer Systems Research Group）的科学精神通过代码和文化传承给了 FreeBSD：(1) **Keith Bostic（基思·博斯蒂克）**——CSRG 核心成员，主导了 Net/2 重写（1991 年为应对 USL 诉讼，带领团队重写了所有 AT&T 代码）、nvi 编辑器（原 vi 许可证问题的重写版）、Berkeley DB 等项目；Bostic 的工作体现了 “为了自由重写一切” 的决心；(2) **Mike Karels**——CSRG 技术领导（1983 年后与 McKusick 共同领导），4.2BSD/4.3BSD 主要架构师之一，后加入 BSDi；Karels 以对代码质量的苛刻要求和细致的代码审查著称；(3) **Sam Leffler**——4.2BSD 技术主管（1982-1983），TCP/IP 栈实现的主要作者之一；1983 年离开 CSRG 加入 Lucasfilm（John Lasseter 正是通过 Leffler 的关系为 4.3BSD 画了 daemon！），后创立 Silicon Graphics 的 BSD 部门，再后创建 Whistle Communications（嵌入式 BSD 产品）；Leffler 是典型的 “从学术到工业” 的桥梁人物；(4) **CSRG 的同行评审传统**——在互联网时代之前，CSRG 就已经在实施类似现代 code review 的实践——所有代码提交都要经过 Karels 或 McKusick 的审查；(5) **可重复实验精神**——CSRG 发布的不仅是代码，还有完整的文档、论文和设计说明（如 4.3BSD 设计书），使得其他人可以理解、复现、改进他们的工作

**史料**：McKusick, M. K. (1999). *Twenty Years of Berkeley Unix*. in Open Sources; Salus, P. H. (1994). *A Quarter Century of UNIX*. Addison-Wesley; Leffler, S. J., McKusick, M. K., Karels, M. J., & Quarterman, J. S. (1989). *The Design and Implementation of the 4.3BSD UNIX Operating System*. Addison-Wesley; Bostic, K. (1990s). *Net/2 Source Tree Release Notes*. CSRG, UC Berkeley ［B］

**史观**：终结与延续：CSRG 的科学精神没有随 CSRG 1995 年解散而消失——它通过 FreeBSD、NetBSD、OpenBSD、Darwin 等后代项目延续至今；FreeBSD 的 code review 流程、release engineering 纪律、文档传统都是 CSRG 精神的直接继承者

**辨析**：需要区分 “CSRG 神话” 与历史真实——CSRG 不是完美的理想国，他们也有代码 bug、内部政治、截止日期压力、人为错误；但他们确实建立了一套在当时非常先进的工程实践，为后来的开源运动提供了参考模型
