# 185.7.3 冲突类

### 新闻条目 4

- **新闻标题（中英）**：“Debian kFreeBSD 是玩具操作系统”——Poettering 访谈言论引发 BSD 社区论战（“Debian kFreeBSD Is a Toy OS”: Poettering Interview Remarks Ignite BSD Community Feud）
- **新闻来源**：LinuxFR.org 访谈（2011-07-05）+ LWN.net 转述 + Slashdot + <https://linuxfr.org/news/un-entretien-avec-lennart-poettering> + <https://lwn.net/Articles/450299/> + <https://lists.freebsd.org/pipermail/freebsd-questions/2011-July/232025.html> + <https://bsd.slashdot.org/story/11/07/16/0020243/Lennart-Poettering-BSD-Isnt-Relevant-Anymore>
- **新闻摘要**：2011 年 7 月 LinuxFR.org 刊出 Poettering 访谈，他称“Debian kFreeBSD is a toy OS”（玩具操作系统），并表示认为对 BSD 的支持正拖累大量自由软件开发、若由他主掌 Debian 将专注保持其“职业相关性”。Slashdot 以“Lennart Poettering: BSD Isn't Relevant Anymore”为题转载引爆论战，freebsd-questions 等邮件列表随即掀起 BSD 社区的长篇回应。
- **与本章主题的关联说明**：本章记述 systemd 的诞生扩散与哲学分野，此次访谈言论是 systemd 争议中直接波及 BSD 社区的标志性冲突节点，与本卷“多方平等”的问题意识直接相关。
- **与官方史料的交叉验证结论**：LinuxFR 访谈原文、LWN 报道、Slashdot 转载与 freebsd-questions 邮件列表线程多源交叉验证：言论文本与时间（2011-07）一致。

### 新闻条目 5

- **新闻标题（中英）**：Debian“init system coupling”一般决议未获通过，Devuan 分叉宣告（Debian General Resolution on Init System Coupling Fails; Devuan Fork Announced）
- **新闻来源**：Debian 投票页 + SoylentNews + Linux Pro Magazine + <https://www.debian.org/vote/2014/vote_003.en.html> + <https://soylentnews.org/article.pl?sid=14/11/19/0826247> + <https://www.linuxpromagazine.com/content/download/104082/807948/version/1/file/026-027_Distro_Walk_Devuan.pdf>
- **新闻摘要**：2014 年 11 月，由 Ian Jackson 发起的“init system coupling”一般决议投票未获通过（多数意见认为决议无必要）；围绕 systemd 争议，Joey Hess、Russ Allbery、Ian Jackson、Tollef Fog Heen 等 Debian 开发者与技术委员会成员先后辞职并公开说明压力；2014 年 11 月 24 日 Devuan 分叉宣告，目标是不受“systemd 同质化与锁定”影响。
- **与本章主题的关联说明**：本章 170.4 记述 Unix 哲学争议在发行版采纳层面的展开，Debian 决议、辞职潮与分叉宣告是 systemd 争议强度最高的冲突节点。
- **与官方史料的交叉验证结论**：Debian 官方投票记录、SoylentNews 报道与 Linux Pro Magazine Devuan 专文多源交叉验证：决议结果与分叉日期（2014-11-24）一致。
