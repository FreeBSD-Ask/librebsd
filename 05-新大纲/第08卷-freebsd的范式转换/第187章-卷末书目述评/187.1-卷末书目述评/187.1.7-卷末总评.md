# 187.1.7 卷末总评

本卷史料基础以 **freebsd.duckdb** 数据库、FreeBSD 官方发布公告与 Release Notes、邮件列表存档为三大支柱，覆盖代码、文档、社区三维度；二手研究以 Losh 的 Git 迁移博客、Poettering 的 systemd 设计文档、de Raadt 的 BSD 阵营声明、Spafford 与 Eichin 的 Morris 蠕虫分析报告为骨干。主要缺口：Core Team 内部决策记录未公开、当代史料时间距离不足、systemd 跨阵营辩论档案分散、量化数据分析不足。未来方向包括 Core Team 成员口述史、当代史料的定期修订、跨阵营辩论档案系统整理、工程演化量化数据库建设。
