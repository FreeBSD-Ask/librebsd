# 187.1.6 文献清单

> 以下保留评注式书目的三个子节（一手史料、二手研究、工具书与参考），作为本综述的文献支撑。

### 一手史料

FreeBSD Project. FreeBSD 15.0-RELEASE Announcement [EB/OL]. [2026-07-31]. <https://www.freebsd.org/releases/15.0R/announce/>.

> FreeBSD 15.0-RELEASE 公告，记录 FreeBSD 15.x 分支的技术特性与架构变更。15.0 是本卷时间范围内的首个主要版本，须与 **freebsd.duckdb** freebsd-src 仓库 release/15.0.0 tag 交叉验证。须注意 15.0 的具体发布日期与技术特性清单以官方公告为准，本卷引用时须注明访问日期。

FreeBSD Project. FreeBSD 16.x-CURRENT Development Branch [EB/OL]. [2026-07-31]. <https://cgit.freebsd.org/src/log/branches/branch>.

> FreeBSD 16.x-CURRENT 开发分支的 Git 仓库，记录 16.x 分支的当前开发状态与版本定位。16.x-CURRENT 作为开发分支，其版本定位与发布节奏的官方陈述须与 Git 仓库分支状态、Core Team 公开声明交叉验证。

FreeBSD Project. FreeBSD Security Advisories [EB/OL]. (1999-2026)[2026-07-31]. <https://www.freebsd.org/security/advisories/>.

> FreeBSD 官方安全公告档案，覆盖本卷所述各版本周期安全响应事件。公告与 **freebsd.duckdb** security fix commit 记录、NVD CVE 条目交叉验证，是本卷第 156、157 章安全史叙事的一手权威来源。

BSD 仓库分析数据库（**bsd_commits.db**）. 23 个 BSD 与跨项目仓库结构化 commit 元数据 SQLite 数据库（v3 扩展版）[DB/OL]. (2026-07-22)[2026-07-22]. **原材料/研究/bsd 仓库分析/bsd_commits.db**.

> 本项目自建的 BSD 仓库 commit 元数据库，是本卷量化考据的核心数字史料。Git 迁移的关键 commit、Rust 集成实验性 commit、FreeBSD 15.0 与 16.x-CURRENT 的 tag 与分支元数据、systemd 相关讨论的 commit 引用等关键事件均经数据库直接验证。须注意 Git 迁移前的 Subversion 历史（2008-2020）与 Git 迁移后的历史（2020 起）在数据库中以统一 schema 整合，但两段历史的元数据字段存在差异。

FreeBSD Foundation. Annual Reports 2010-2026 [R]. Boulder: FreeBSD Foundation, 2011-2026.

> FreeBSD Foundation 年度报告档案，记录 Foundation 自 2010 年以来的财务状况、资助项目、社区活动。2020 年代 Rust 集成实验性资助、Git 迁移工程资助、15.x/16.x 开发支持等资助策略的一手来源。

### 二手研究

Losh W. FreeBSD Subversion to Git Migration: Why?[EB/OL]. (2020-09)[2026-07-31]. <https://bsdimp.blogspot.com/>.

> Warner Losh（沃纳·洛什） 系统阐述 Git 迁移原因的博客文章，回应社区常见疑问，是本卷第181章“从 Subversion 到 Git 的迁移历程”的核心一手来源。Losh 作为 Git 迁移工程的核心参与者，其陈述带有当事人倾向，正文引用时须与 Git 迁移 RFC 讨论存档、Core Team 官方陈述交叉验证。

Poettering L. systemd for Administrators [EB/OL]. (2010-2026)[2026-07-31]. <https://0pointer.de/blog/projects/systemd.html>.

> Lennart Poettering 的 systemd 设计博客系列，系统阐述 systemd 的设计动机、架构选择、服务管理、依赖关系处理、并行启动、cgroup 集成、journald 日志结构化等核心机制。是本卷第182章“systemd 的诞生扩散与工程架构”的核心一手来源，须与 BSD 阵营对 systemd 的批评性评论互参以平衡跨阵营视角。

Poettering L. The Biggest Myths [EB/OL]. (2013)[2026-07-31]. <http://0pointer.de/blog/projects/the-biggest-myths.html>.

> Poettering 2013 年发表的 systemd 神话辟谣文章，回应 BSD 阵营与 Linux 老用户对 systemd 的常见批评。是本卷第183章“systemd 与 BSD init 的哲学合图层”跨阵营辩论的核心一手来源，须与 de Raadt 等 BSD 阵营核心开发者的公开陈述互参。

de Raadt T. Slashdot OpenBSD Interviews [EB/OL]. (1998-2026)[2026-07-31]. <https://bsd.slashdot.org/>.

> Slashdot BSD 频道历年的 de Raadt 在线社区访谈，含其对 systemd、BSD init 哲学、Rust 集成等议题的公开陈述。de Raadt 作为 OpenBSD 创始人与 BSD 许可证哲学的坚定捍卫者，其陈述带有 BSD 阵营立场，是本卷第 167、168 章 systemd 与 BSD init 哲学分野叙事的当事人外部视角，正文引用时须与 Poettering 的 systemd 设计文档互参。

McKusick M K, Neville-Neil G V, Watson R N M. The Design and Implementation of the FreeBSD Operating System, 2nd Edition [M]. 2nd ed. Boston: Addison-Wesley Professional, 2014. ISBN: 978-0-321-96897-5.

> FreeBSD 操作系统设计与实现第二版，虽出版于 2014 年，但其对 BSD 工程传统、安全模型、系统初始化的章节陈述是本卷第 153、156、157、168 章工程美学与安全史叙事的核心二手来源。

Spafford E H. The Internet Worm Program: An Analysis [R]. West Lafayette: Purdue University, 1988.

> Eugene H. Spafford 1988 年发表的 Morris 蠕虫分析报告，是本卷第171章“计算机安全史的早期 UNIX 安全与 Morris 蠕虫”的核心一手学术来源。该报告系统分析 Morris 蠕虫的传播机制、利用漏洞（sendmail、finger、rsh）、影响范围，是早期 UNIX 安全史的奠基性文献。

Eichin M W, Rochlis J A. With Microscope and Tweezers: The Worm from MIT's Perspective [R]. Cambridge: MIT, 1989.

> Eichin 与 Rochlis 1989 年发表的 MIT 视角 Morris 蠕虫分析报告，与 Spafford 报告互为补充，是本卷第171章早期 UNIX 安全史的核心一手学术来源。两份报告的交叉印证可降低单一视角的偏差风险。

Cantrill B. Observability with DTrace [J/OL]. ACM Queue, (2017)[2026-07-31]. <https://queue.acm.org/detail.cfm?id=3160812>.

> Bryan Cantrill（布莱恩·坎特里尔） 在 ACM Queue 发表的 DTrace 观测性专栏文章，Cantrill 作为 DTrace 原作者与 Solaris/illumos 工程传统的核心人物。是本卷第166章“FreeBSD 的工程美学与设计哲学”的当事人外部视角，可与 McKusick 的 BSD 工程传统陈述互参。

Davis B. FreeBSD 15.x CHERI [C/OL]. papers.freebsd.org 2024 年论文索引。(2024)[2026-07-31]. <https://papers.freebsd.org/2024/davis-cheri/>.

> Brooks Davis 在 papers.freebsd.org 2024 年发表的 FreeBSD 15.x CHERI 硬件能力架构现代化技术论文。是本卷第174章“FreeBSD 15.0 发布与技术特性”的当事人技术陈述来源，须与 CHERI 学术谱系研究文献交叉验证。
