# 175.5.13 JannHorn指出OpenBSD已使用MAP_STACK标志内核定期检查用户态

Jann Horn 指出 OpenBSD 已使用 MAP_STACK 标志：内核定期检查用户态栈指针是否落在 MAP_STACK 区域，否则杀掉进程；Ts'o 由此发问 Linux 是否应照做，认为即使只在系统调用入口检查成本也低且能有效防御各类 ROP 技术；Horn 随后表示并不看好仅在系统调用入口做检查——攻击者一旦能执行系统调用，把 ROP 栈搬到合法栈上并不困难；Kees Cook 则认为该机制仍有价值，具备对用户态栈用法异常行为的声明与强制检查作用，虽不纯粹作为 ROP 防御。以上为邮件列表当事人一手自述，属过程性证据，不得单独引为定论。
