# 182.1.3 OpenSSL、OpenZFS 与存储栈更新

**要点**：FreeBSD 16.0-CURRENT 将包含更新版本的 OpenSSL 和 OpenZFS；FreeBSD 15.0 已包含 OpenZFS 2.3.x 系列，16.x 预计跟进 OpenZFS 2.4 或更新版本；ZFS block cloning（块克隆）功能在 15.x 周期已引入并持续稳定化；OpenSSL 版本持续跟进上游 LTS 版本，同时可能包含 FreeBSD 特定的安全加固和性能优化；pkgbase（将 base 系统拆分为 pkg 包）项目持续推进，2026Q1 状态报告有“More robust pkgbase conversion”专门条目

**史料**：FreeBSD 15.0/15.1-RELEASE Release Notes（OpenZFS、OpenSSL 版本）、FreeBSD 2026Q1 Status Report（More robust pkgbase conversion 条目）、OpenZFS 官方发布说明、OpenSSL 官方安全公告和发布说明、FreeBSD src main 分支 cvs/svn/git 提交历史（存储栈相关更新） ［A］

**史观**：总纲第 15 条——文化即形式主义〔存疑：原挂总纲第 19 条系伪标签，依核查报告改挂第 15 条，语境适配未经总纲原文逐字复核〕：OpenZFS 持续作为 FreeBSD 旗舰级存储功能，其版本跟进速度反映了 FreeBSD 与 ZFS 开源社区的紧密协作关系；pkgbase 项目则是 FreeBSD 软件包管理现代化的关键一步，将 base 系统与 ports 系统统一在 pkg 软件包管理框架下

**辨析**：OpenSSL 和 OpenZFS 在 16-CURRENT 中的具体版本号须以实际 RELEASE 时的版本为准；OpenZFS 2.4/2.5 的新特性（如更高效的块克隆、性能优化、新功能）在 16-CURRENT 中的合入状态须对照 git 提交记录核实；Bcachefs 等新文件系统的移植截至 2026 年 7 月主要是社区讨论或外部实验，尚未进入 base system 的明确计划
