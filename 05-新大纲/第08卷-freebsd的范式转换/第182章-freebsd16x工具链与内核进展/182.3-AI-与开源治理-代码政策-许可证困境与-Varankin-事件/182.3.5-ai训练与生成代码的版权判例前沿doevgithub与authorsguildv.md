# 182.3.5 AI 训练与生成代码的版权判例前沿：Doe v. GitHub 与 Authors Guild v. Google

**要点**：AI 时代开源代码版权争议的两起代表性判例为：(1) **Doe v. GitHub, Inc.**（No. 4:22-cv-06823-JST, N.D. Cal.）——2022 年 11 月 3 日匿名开发者（J. Doe 1/2）对 GitHub、Microsoft、OpenAI 提起集体诉讼，指控 GitHub Copilot 与 OpenAI Codex 以 GitHub 开源仓库代码训练模型、并在输出时剥离版权声明与许可证信息，违反 DMCA §1202（版权管理信息）、开源许可证（MIT/GPL/Apache/BSD 等）与 GitHub 服务条款；2023 年 6 月地区法院（Jon Tigar 法官）驳回 22 项诉因中约 20 项（多数以偏见驳回），保留开源许可证违约与合同违约等少量诉因；2024 年 7 月 5 日 Tigar 法官再驳 DMCA §1202(b) 等诉因（认为 Copilot 输出与训练源码非逐字相同，§1202(b) 不适用），案件剩余诉因有限并进入上诉程序；(2) **Authors Guild v. Google, Inc.**（804 F.3d 202, 2d Cir. 2015）——2015 年 10 月 16 日第二巡回上诉法院认定 Google Books 大规模图书扫描（含 snippet view 片段显示）构成合理使用（fair use），理由是转换性使用（transformative use）、展示功能与搜索功能区分、市场替代有限；该判决是“大规模复制训练/索引数据集”合理使用论的核心先例，被 AI 版权辩论双方分别援引

**史料**：Doe v. GitHub, Inc., No. 4:22-cv-06823-JST（N.D. Cal. 2022）案件 docket 与 2024-07-05 驳回令（courtlistener.com/justia.com）；The Register. Judge dismisses DMCA copyright claim in GitHub Copilot suit（2024-07-08）；Lexology. Insights from the Pending Copilot Class Action Lawsuit；Authors Guild, Inc. v. Google, Inc., 804 F.3d 202 (2d Cir. 2015) 判决书全文；Conventus Law. US – Ruling on Motion to Dismiss Sheds Light on IP Issues in AI（2023） ［A］

**史观**：总纲第 13 条——法律与道德是利益分配：Doe v. GitHub 与 Authors Guild v. Google 共同揭示 AI 训练数据版权问题的两难结构——Authors Guild 确立了“大规模扫描索引数据”的合理使用先例（有利于 AI 训练），Doe v. GitHub 则暴露“模型输出剥离许可证信息”对开源署名义务的系统性冲击（有利于要求 AI 输出合规）；BSD 许可证在两端都处境微妙：其“保留版权声明”义务是唯一实质性约束，但 AI 输出无法稳定携带版权声明，使 BSDL 的署名机制在 AI 时代面临技术性失效

**辨析**：须严格区分两案效力——Authors Guild v. Google 是第二巡回上诉法院的终局判决（合理使用认定），构成有约束力的巡回先例；Doe v. GitHub 截至 2026 年 7 月仍处诉讼进程中（多数诉因被驳回但部分上诉未决），其 DMCA 主张被驳回不意味着“AI 训练开源代码合法”的终局结论；另须注意两案的复制形态差异——Google Books 是“批量扫描+片段展示”，Copilot 是“模型学习+按需生成”，前者是索引型复制、后者是生成型复制，司法对待二者的合理使用分析路径不同；案件名更正：2022 年 Copilot 诉讼原告采用匿名身份，正确的案件名为 Doe v. GitHub, Inc. 而非部分文献误写的 “Smith v. GitHub” ［A］

Judge dismisses DMCA copyright claim in GitHub Copilot suit（2024-07-08）；Conventus Law. US – Ruling on Motion to Dismiss Sheds Light on IP Issues in AI ［A］
