# 183.3.6 总纲第 19 条审视——解释学循环与权力知识共谋

**要点**：dialog 移除的叙事印证“权力与知识在历史书写中共谋——什么被记录、什么被遗忘，本身就是权力行使”。在 FreeBSD 官方叙事中，bsddialog 作为“BSD 自己的 dialog”被记录为工程成就（3,123 commits、5 年开发周期、BSD-2-Clause 许可证），但 GNU dialog 在 FreeBSD base system 中存在 20 余年的历史被遗忘——`gnu/` 目录的物理移除是“记忆抹除”的形式化表达，将 GNU 工具谱系对 FreeBSD 早期发展的贡献从源码树中抹去。**FSF 官方许可证评论页面作为 GPL 阵营长期立场声明在 FreeBSD 官方叙事中被边缘化**——FSF 将 FreeBSD 许可证归类为“松散的、纵容型、非 copyleft 的自由软件许可证，兼容 GNU GPL”，同时“更推荐 Apache 2.0 许可证”，这一立场在 FreeBSD 社区的主流叙事中几乎不被引用，是“被遗忘”的典型案例：GPL 阵营对 BSD 路径的学理评价被遮蔽，仅剩“工程成就”的一面被记录。FreeBSD Licensing Policy 作为“权力-知识”共谋的文本——偏好 BSD-2-Clause 不是中立的技术规范，而是项目治理权力的形式化，将“商业友好”的市场诉求转化为“工程原则”的技术规范。解释学循环体现在“前理解的差异使分歧不可避免”——BSD 阵营的前理解（许可证一致性是工程原则）与 GPL 阵营的前理解（copyleft 是开源伦理）使双方对 dialog 移除的评价分歧不可避免，任一方都无法说服对方，因为分歧根植于前理解而非论证。本节叙事本身亦是史家前理解的产物——史家以项目史观总纲第 19 条为前理解审视 dialog 移除，所得结论受这一前理解塑造，无法声称“客观中立”。<des@FreeBSD.org>（Dag-Erling Smørgrav）于 2026-06-30 18:56:52 UTC 统一提交三个 ports（devel/libfigpar、devel/libdpv、sysutils/dpv）的行为，在 FreeBSD 官方叙事中被记录为“兼容性承诺”，但在权力-知识共谋视角下，这一行为亦是将“GPL 软件退出 base”的形式化完成——ports 化延续既是兼容性承诺，也是 base 纯洁化的工程收尾，二者在同一行为中并存，叙事选择哪个面向本身就是权力行使。

**史料**：项目史观总纲第 19 条原文（据原文第 25 章 第 23 行：“19. **解释学循环是历史认识的根本条件**。前理解的差异使分歧不可避免。权力与知识在历史书写中共谋——什么被记录、什么被遗忘，本身就是权力行使。”）；FreeBSD Licensing Policy（docs.freebsd.org/en/articles/license-guide/，作为“权力-知识”共谋文本，第 2.1 节 Guiding Principles BSD-2-Clause 偏好条款）；**FSF 官方许可证评论页面**（gnu.org/licenses/license-list.html#FreeBSD，2026-07-23 一手核验，作为 GPL 阵营长期立场声明在 FreeBSD 官方叙事中被边缘化的“被遗忘”案例——FSF“更推荐 Apache 2.0”立场在 FreeBSD 社区主流叙事中几乎不被引用，印证“什么被记录、什么被遗忘，本身就是权力行使”）；FreeBSD FreshPorts 三个 ports（devel/libfigpar、devel/libdpv、sysutils/dpv，2026-06-30 由 <des@FreeBSD.org> 统一提交，commit hash 分别为 `10594b0593a388b5567116403b93906c11bdcd17`、`f6a8a826d2ad17621de59a0306918be614be3284`、`278661a01cd42045e11ffaec7b22e3e6c1fab571`）；FreeBSD src repository cgit 提交历史（`gnu/` 目录移除记录，须以 cgit.freebsd.org/src/ 实时源码为准）；bsddialog 项目页面（gitlab.com/alfix/bsddialog，被记录为“BSD 自己的 dialog”）；GNU dialog 在 FreeBSD base system 中的历史贡献记录（须从 FreeBSD 早期 release notes 与 CVS 历史中考据）

**史观**：总纲第 19 条——解释学循环与权力知识共谋：dialog 移除印证“什么被记录、什么被遗忘，本身就是权力行使”——bsddialog 的工程成就被记录，GNU dialog 在 base 中的 20 余年历史被遗忘，`gnu/` 目录的物理移除是记忆抹除的形式化表达；FreeBSD Licensing Policy 作为“权力-知识”共谋文本，将商业友好诉求形式化为项目身份认同的技术规范
