# 183.3.5 总纲第 11 条审视——商品是形式主义

**要点**：dialog 移除与 GPL 代码清零作为“技术市场的选择”，印证“商品是形式主义”——BSD 许可证纯洁化不是自然选择，而是形式主义的权力运作。base system 移除 GPL 组件是“劣币驱逐良币”规律的逆向案例——BSD 阵营将 BSD 许可证建构为“良币”（商业友好、无义务使用），将 GPL 许可证建构为“劣币”（copyleft 义务、商业不友好），但“良劣”标签本身是形式主义建构，非技术优越性的客观量度。FreeBSD Licensing Policy 偏好 BSD-2-Clause 是“技术市场选择不是自然选择”的典型——市场（商业厂商赞助 FreeBSD Foundation）通过许可证偏好这一形式化机制，将商业友好诉求转化为项目身份认同的技术规范。Ports 中保留 GNU dialog（misc/dialog port）与 lang/gcc port 体现“商品形式主义”的双层架构——base system 作为“纯 BSD 商品”在市场叙事中获得品牌溢价，Ports 作为“多元商品货架”容纳 GPL 软件维持功能可用性，二者在分层架构中各司其职，但分层本身是形式主义的市场策略而非中立的技术决策。iXsystems TrueNAS、Netgate pfSense 等基于 FreeBSD base system 的商业产品受益于 BSD 许可证的无义务特性——base system 保持 BSD 许可证是这些商业产品商业模式的前提条件，“许可证纯洁化”的工程叙事服务于“商品形式主义”的市场逻辑。

**史料**：项目史观总纲第 11 条原文（据原文第 25 章 第 15 行：“11. **商品是形式主义**。技术市场的选择不是自然选择，而是形式主义的权力运作。劣币驱逐良币是普遍规律。”）；FreeBSD Licensing Policy（docs.freebsd.org/en/articles/license-guide/，BSD-2-Clause 偏好条款）；FreeBSD Foundation 2024 Annual Report（freebsdfoundation.org/our-donors/，企业赞助者名单含 iXsystems、Netgate、Juniper、Apple 等）；FreeBSD Ports 中 GNU 软件列表（misc/dialog port、lang/gcc port，freshports.org 一手核验）；iXsystems TrueNAS 与 Netgate pfSense 商业产品页面（基于 FreeBSD base system 的闭源/商业衍生产品）

**史观**：总纲第 11 条——商品是形式主义：dialog 移除印证“技术市场的选择不是自然选择，而是形式主义的权力运作”——BSD 许可证纯洁化作为“商品形式主义”的市场策略，将商业友好诉求形式化为项目身份认同的技术规范，base/ports 分层架构是商品形式主义的双层货架而非中立的技术决策
