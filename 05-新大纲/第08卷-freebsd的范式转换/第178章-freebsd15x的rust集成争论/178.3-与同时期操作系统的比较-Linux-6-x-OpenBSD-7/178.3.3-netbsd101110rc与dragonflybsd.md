# 178.3.3 NetBSD 10.1/11.0 RC 与 DragonFly BSD

**要点**：同期（2025-2026）其他 BSD：**NetBSD 10.1**（2024.12.16 发布，现行稳定版）持续支持众多平台（理论上 NetBSD 支持最多硬件平台），2024.5 发布 AI 生成代码禁令（tainted code 政策）；**NetBSD 11.0** 截至 2026 年 7 月 19 日仍处于 RC6 阶段（2026.7.13 发布第六个候选版本），尚未正式发布；**DragonFly BSD** 6.4+ 持续发展 HAMMER2 文件系统、轻量级虚拟化、性能优化，但其核心团队规模极小（主要是 Matt Dillon 等少数开发者），硬件支持有限；**illumos**（OpenSolaris 后继者）持续在 ZFS 存储、服务器领域发展但生态规模较小

**史料**：NetBSD 10.1 Release Announcement（2024.12.16）；NetBSD 11.0 RC 公告（2026.7）；DragonFly BSD 6.4 Release Notes；illumos 项目文档；**netbsd.duckdb** `netbsd-src` 仓库数据库查询——无 release tag，仅有 `origin/netbsd-11` 分支用于 11.0 开发，与 NetBSD 主仓（CVS）的 release tag 机制不同；NetBSD 10.1/11.0 RC 日期仍须以 NetBSD 官方公告（netbsd.org/releases/）为权威来源；**dragonfly.duckdb** `dragonfly-src` 仓库 release tag 数据库验证——`v6.4.0` tagger_date = 2022-12-30T17:41:38+01:00（CET 时区），tagger_name = Antonio Huete Jimenez（安东尼奥·韦特·希门尼斯），tag_type = annotated；`v6.4.1` tagger_date = 2025-04-29T16:03:04-04:00（EDT），tagger_name = Justin C. Sherrill（贾斯廷·C·谢里尔）；`v6.4.2` tagger_date = 2025-05-09T13:44:10-04:00（EDT），tagger_name = Justin C. Sherrill；DragonFly 6.4 系列持续维护至 2025.5（v6.4.2），但 6.5 及之后版本截至 2026.7 暂无新 tag ［A］

**史观**：总纲第 4 条——分离聚合是永恒规律（原“技术路线分化”系伪名目，按族例改挂）：五大 BSD（FreeBSD、OpenBSD、NetBSD、DragonFly、Darwin/macOS）在 2020 年代的分化比历史上任何时期都明显：FreeBSD 走 “通用服务器、Linux 生态兼容、企业用户” 路线；OpenBSD 走 “安全审计、极简主义、透明性” 路线；NetBSD 走 “跨平台移植、学术性、代码清洁” 路线；DragonFly 走 “高性能 SMP、HAMMER2、Matthew Dillon（马修·狄龙） 个人愿景” 路线；Darwin/macOS 走 “Apple 生态、商业闭源驱动、Mach 微内核” 路线；每条路线都有其忠实用户与生态位

**辨析**：NetBSD 的平台支持数量常被引用但需客观看待——NetBSD 确实支持最多平台（50+），但许多平台属于 Tier II/III 支持（不提供 RELEASE 镜像、无二进制包、不保证稳定性），真正具有生产级支持的平台数量少于 FreeBSD；DragonFly BSD 单线程性能与 HAMMER2 文件系统在特定工作负载下有优势，但硬件支持（特别是 GPU、WiFi、新外设）远弱于 FreeBSD。**数据库验证结论**：① NetBSD：经 netbsd.duckdb `netbsd-src` 仓库查询未得 release tag，仅得 `origin/netbsd-11` 分支用于 11.0 开发，无法用 tag tagger_date 验证 NetBSD 10.1 发布日期；考据审慎提示：NetBSD 主仓为 CVS（部分组件如 pkgsrc 已迁 Mercurial），GitHub 镜像可能未导入 CVS release tag，NetBSD 10.1 发布日期仍采信官方公告 2024-12-16 作为权威来源；NetBSD 11.0 RC6 阶段经 `origin/netbsd-11` 分支存在性确认，符合 11.0 开发中状态。② DragonFly BSD：`v6.4.0` tagger_date = 2022-12-30T17:41:38+01:00 与 DragonFly BSD 官方 6.4 Release Notes 公告日期（2022-12）一致，偏差 0 日（同月发布）；`v6.4.1` 与 `v6.4.2` 分别为 2025-04-29 与 2025-05-09，反映 DragonFly 在 2025 年 4-5 月仍有维护版本发布，但 6.5 截至查询时（2026-07-21）无新 tag，可能已进入低活跃维护状态；DragonFly 6.4 系列 tagger 从 Antonio Huete Jimenez（6.4.0）切换至 Justin C. Sherrill（6.4.1/6.4.2），反映 DragonFly 发布工程团队人事变动
