# 184.6.4 贡献者考据与史料存疑

**要点**：Git 迁移贡献者考据的主要存疑事项：(1) **完整贡献者名单**——Git 工作组没有官方发布完整的“感谢名单”，部分贡献者（如早期测试者、文档编辑者、镜像维护者）的完整名单难以考证；(2) **具体决策归因**——某些技术决策（如 main 分支命名、转换工具选择）是集体讨论的结果，难以归因到单一个人；(3) **CVS→SVN 迁移细节**——2008 年的迁移文档和讨论存档不如 Git 迁移完整，部分细节（如精确的迁移完成日期）难以精确考证；(4) **NetBSD 迁移最终状态**——NetBSD 2025 年 1 月宣布的 Mercurial+Git 双轨方案仍在实施中，最终形态尚未确定；(5) **committer 退役原因**——个别老 committer 在 Git 迁移前后减少活动或退役，真实原因（Git 不适应、时间精力、其他原因）无法从公开记录确认

**史料**：freebsd-committers 邮件列表欢迎/退役公告；src/conf/COMMITTERS 文件历史；私人博客和社交媒体的零星记述 ［A］

**史观**：历史考据（专题语，不设总纲条号；原挂“总纲第 3 条——形式主义膨胀”系伪标签名目，权威第 3 条为“不存在进步，只有权力再分配”，依核查报告订正）：历史考据的边界就是史料的边界——对于没有可靠史料支撑的细节，史学家应当诚实地存疑，而不是用推测填补空白；不完整的真相好过编造的完整

**辨析**：存疑事项不是缺陷而是诚实的表现——历史书写不可能还原所有细节，承认未知比强行编造更符合学术规范；本章对关键日期、核心成员、主要事件的考据已有至少两个独立来源交叉验证，可以保证基本史实的准确性

**文献**：FreeBSD Project. src/conf/COMMITTERS file (historical versions via Git); freebsd-committers mailing list archives (2019-2021); Wayback Machine. *FreeBSD developer blogs and personal sites*. ［A］
