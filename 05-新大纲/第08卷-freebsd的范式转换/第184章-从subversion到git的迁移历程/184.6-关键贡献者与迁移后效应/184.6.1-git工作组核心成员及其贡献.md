# 184.6.1 Git 工作组核心成员及其贡献

**要点**：Git 迁移的成功归功于 Git 工作组和社区贡献者的集体努力，核心成员的主要贡献经多源交叉验证如下：(1) **Ed Maste（埃德·马斯特）（emaste@）**——工作组主席，整体协调、基金会对接、对外沟通、EuroBSDCon/BSDCan 演讲分享进展；(2) **Ulrich Spörlein（uqs@）**——SVN→Git 转换技术负责人，编写转换规则、调试转换工具、执行最终转换、验证历史完整性；(3) **Li-Wen Hsu（许立文）（lwhsu@）**——基础设施负责人，Git 仓库部署、镜像同步、权限配置、CI/CD 集成，执行了三大仓库的最终切换操作；(4) **Warner Losh（沃纳·洛什）（imp@）**——文档和培训负责人，编写 Git Primer、发送迁移预告邮件、组织 committer 培训、撰写博客文章解答社区疑问；(5) **Glen Barber（格伦·巴伯）（gjb@）**——发布工程对接，确保迁移不影响 13.0 发布、调整 releng 分支流程、doc 仓库构建系统切换；(6) **Baptiste Daroussin（巴蒂斯特·达鲁桑）（bapt@）**——ports 仓库迁移负责人，处理 ports 仓库特有的规模和结构问题；FreeBSD 基金会提供资金支持，使部分工作组成员能够投入专职时间

**史料**：freebsd-git 邮件列表发帖统计和分工记录；Git 工作组会议纪要；BSDCan/EuroBSDCon 演讲者名单；FreeBSD Foundation 资助名单 ［A］

**史观**：软件工程（专题语，不设总纲条号；原挂“总纲第 17 条”系伪标签，权威第 17 条为“证明世界先于解释和改造世界”，依核查报告订正）：大规模基础设施迁移是系统工程，成功依赖于明确的角色分工、周密的计划、充分的测试和团队协作；Git 工作组展示了开源项目如何以志愿者为主完成专业级的工程任务

**辨析**：贡献归属需避免“英雄史观”——Git 迁移不是某一个人的功劳，而是数十名 committer 参与测试、反馈问题、编写文档、适配工具的集体成果；核心成员的协调工作固然重要，但没有更广泛社区的参与不可能成功
