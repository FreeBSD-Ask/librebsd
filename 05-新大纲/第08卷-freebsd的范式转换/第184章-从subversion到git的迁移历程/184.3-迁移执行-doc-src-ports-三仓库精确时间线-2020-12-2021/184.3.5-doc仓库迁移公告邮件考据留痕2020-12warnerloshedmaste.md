# 184.3.5 doc 仓库迁移公告邮件考据留痕（2020-12 Warner Losh + Ed Maste）

**要点**：FreeBSD-doc Subversion to Git 迁移公告邮件经 freebsd-announce 邮件列表存档一手核验，发信人为 Warner Losh 与 Ed Maste（代表 git conversion working group），邮件正文明确"We will begin the migration sometime on December 5th and hope to be completed by December 8th"——这一时间表与 66.3.1 节中考据的 doc 仓库迁移关键时间线（12 月 5 日构建切换、12 月 8 日 SVN 关闭）完全一致，可作为迁移时间表的二手印证；邮件存档 mailman 页面显示 12 月邮件跨度 2020-12-01 20:45:49 UTC 至 2020-12-14 22:18:42 UTC，未在邮件正文内嵌具体日期戳，但邮件正文明确迁移时间表；**重要说明**：本公告仅为 doc 仓库迁移公告——src 仓库的 SVN-to-Git 迁移公告未在 freebsd-announce 2020-12 与 2021-01 存档中找到，可能在 freebsd-src 或 freebsd-git 邮件列表发布，需后续单独考据

**史料**：freebsd-announce 邮件列表 mailman 存档（<https://lists.freebsd.org/pipermail/freebsd-announce/2020-December/002002.html>，访问 2026-07-23）；迁移计划文档 <https://github.com/bsdimp/freebsd-git-docs/blob/main/doc-cutover-schedule.md>（Warner Losh 维护）；历史归档邮件列表 <https://lists.freebsd.org/pipermail/freebsd-git/>（freebsd-git 邮件列表完整存档） ［A］

**史观**：迁移公告邮件由 Warner Losh 与 Ed Maste 代表 git conversion working group 集体名义发信，而非个人名义——这一发信方式体现 Git 工作组的“集体责任”治理模式，工作组决策以集体名义对外公告，避免将基础设施变更归因于个人〔订正注：原挂“总纲第 23 条——社区治理”系伪标签，权威表第 23 条为“一切历史写作都是基于哲学设定的历史小说”，依核查报告去条号留中性论旨〕
