# 179.3.1 **ftpd(8)** 在 15.0 从 base system 移除与 ftp/freebsd-ftpd port 接续

**要点**：FreeBSD 15.0-RELEASE 将传统 **ftpd(8)** 守护进程从基本系统中移除，commit 259bb93b80c0 由 Lexi Winter（<ivy@FreeBSD.org>）于 2025.9.29 起草、2025.10.1 合入 stable/15 分支，Phabricator 评审编号 D52739，由 Colin Percival（cperciva@）批准；该删除在更早版本中已标为 deprecated 并预告 15.0 移除；接续路径为 ftp/freebsd-ftpd port，PAM 服务 ftp(d) 保留以供其他 FTP 守护进程使用；/etc/inetd.conf 中条目相应改为指向 /usr/local 路径；ObsoleteFiles.inc 列出 usr/libexec/ftpd、etc/rc.d/ftpd、share/man/man5/ftpchroot.5.gz、share/man/man8/ftpd.8.gz 等删除条目，但配置文件保留以便用户迁移至 port；共删除 6972 行、38 个文件

**史观**：总纲第 13 条——法律与道德是利益分配：ftpd 移除是 BSD 项目持续剥离非核心网络服务的具体显现，与 14.x telnetd 移除、13.x ip6fw 移除构成同一长期工程脉络——base 仅保留必要组件，传统服务交由 Ports 系统维护；专题语（不设条号）：通过 ObsoleteFiles 机制平滑过渡，体现 “为正确性减负” 原则（本节两处原伪标签“总纲第 24 条——许可证／总纲第 17 条——软件工程”已按权威表分别订正为总纲 13／不设条号专题语）

**辨析**：ftpd 与 telnetd 在 14.x/15.x 期间相继移除体现 BSD 项目对 “上古网络服务” 的批量清理态度；但须严格区分 “ftpd 从 base 移除” 与 “ftpd 工具消失” 两类事实——前者为 15.0 实际事件，后者并未发生，ftp/freebsd-ftpd port 仍持续维护；FreeBSD FTP 客户端 **ftp(1)**（基于 tnftp）继续保留在 base 中；移除决策源于 FTP 协议本身在公网环境下明文传输凭据的安全性问题与 base 维护成本，并非 ftpd 代码本身存在漏洞
