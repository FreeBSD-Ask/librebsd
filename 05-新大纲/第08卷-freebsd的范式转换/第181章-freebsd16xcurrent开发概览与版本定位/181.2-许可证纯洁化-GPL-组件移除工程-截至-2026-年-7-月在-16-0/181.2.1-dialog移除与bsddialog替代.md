# 181.2.1 dialog 移除与 bsddialog 替代

**要点**：截至 2026 年 7 月，GNU dialog 已在 16.0-CURRENT（main）分支中被移除，bsddialog 作为 BSD-2-Clause 许可的替代方案已在 FreeBSD 14.0 之后逐步进入 base system〔订正注：经核验 14.0/15.0 Release Notes 均未提及 bsddialog，原“14.0 首次引入 base system”表述修正〕，安装器约在 2022 年前后已迁移至 bsddialog；dpv 作为源码树中最后一个 dialog 消费者在移除前已超过 2 年未纳入构建流程；该移除工作标志着 FreeBSD 基本系统 GPL 许可组件清除工程的重要里程碑，截至 2026 年 7 月 16.0-CURRENT 分支 base system 不再包含 GPL 许可软件（需以 cgit.freebsd.org 源码最终状态为准）

**史料**：IT 之家 2026 年 7 月 18 日报道“4 年成功收尾：FreeBSD 基本系统现已不再包含 GPL 许可的软件”（援引 Linuxiac 2026 年 7 月 17 日报道）、FreeBSD src repository cgit 提交记录（cgit.freebsd.org/src/，截至 2026 年 7 月）、bsddialog 1.x 版本系列（Alfonso S. Siciliano 开发，BSD-2-Clause 许可，gitlab.com/alfix/bsddialog）、FreeBSD 14.0-RELEASE Release Notes（首次引入 bsddialog）、FreeBSD 14.0（2023 年 11 月）bsddialog 引入提交；**freebsd.duckdb** `tags` 表验证——`release/14.0.0` tagger_date = 2023-11-17T18:23:38-05:00（Glen Barber）证实 14.0 引入 bsddialog 的时间基线；**16.0 tag 查询**：经 `freebsd.duckdb` 查询未得 `release/16.0.0` tag（截至 2026-07-21 查询时），符合 16.0-CURRENT 仍处于开发中、dialog 移除工作尚未进入 RELEASE 阶段的客观状态 ［A］

**史观**：许可证〔订正注：原误挂总纲第 24 条，权威 24=美是消解性的体验，许可证论旨非总纲条目，去号〕：dialog 的移除是 FreeBSD 基本系统许可证纯洁化进程中的关键节点，从 GCC 到 Clang、从 GNU binutils 到 LLVM 工具链、从 GNU grep 到 bsdgrep、从 GNU patch 到 BSD patch、从 GNU diff/diff3 到 BSD diff，这一持续十余年的迁移工程在 dialog 移除后实现了 base system 层面的 GPL 清零

**辨析**：必须明确——该移除是在 16.0-CURRENT 分支中完成，而非已发布的 RELEASE 版本；截至 2026 年 7 月 19 日，FreeBSD 15.1（最新 RELEASE）的 base system 仍可能包含 dialog（需对照 15.1 releng 分支源码确认）；“base system 无 GPL”不等于“FreeBSD 无 GPL”——Ports 集合仍包含数千个 GPL 许可软件（如 GCC、Emacs、Bash 等），且将继续提供；bsddialog 与 GNU dialog 功能并非完全等价，部分高级特性和.dialogrc 配置支持可能存在差异。**数据库验证结论**：经 `freebsd.duckdb` 查询未得 `release/16.0.0` tag，证实 16.0 尚未进入 RELEASE 阶段，dialog 移除工作截至 2026-07-21 仍处于 CURRENT 分支状态，须以未来 16.0-RELEASE 公告与 tag tagger_date 作为最终确认依据；0 信任原则提示：dialog 移除的 commit hash 须以 cgit.freebsd.org/src/ 实时源码为准，本节不引用具体 commit hash 因 16.0-CURRENT 仍在活跃开发中，commit 历史可能调整
