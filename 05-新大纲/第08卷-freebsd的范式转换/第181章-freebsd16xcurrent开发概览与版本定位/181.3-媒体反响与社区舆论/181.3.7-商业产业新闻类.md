# 181.3.7 商业产业新闻类

### 新闻条目 5

- **新闻标题（中英）**：FreeBSD 实习生致力于将 AMD ROCm 移植到 BSD 世界（FreeBSD Intern Working On Porting AMD ROCm To The BSD World）
- **新闻来源**：Phoronix + Michael Larabel + 2026-07-16 + <https://www.phoronix.com/news/FreeBSD-Intern-AMD-ROCm> + <https://web.archive.org/web/2026/https://www.phoronix.com/news/FreeBSD-Intern-AMD-ROCm>
- **新闻摘要**：2026 年 7 月 16 日 Phoronix 报道 FreeBSD Foundation 实习生正在将 AMD ROCm 计算栈移植到 FreeBSD。ROCm 是 AMD 的 GPU 计算栈，移植到 FreeBSD 将使 BSD 平台支持 GPU 计算。这是 FreeBSD 16.x-CURRENT 在 GPU 计算方向的关键进展。
- **与本章主题的关联说明**：本章记述 FreeBSD 16.x-CURRENT 的 GPU 计算支持进展，AMD ROCm 移植是 16.x 在 GPU 计算方向的代表性工程。
- **与官方史料的交叉验证结论**：FreeBSD Foundation 官方公告与 Phoronix 报道交叉验证。
