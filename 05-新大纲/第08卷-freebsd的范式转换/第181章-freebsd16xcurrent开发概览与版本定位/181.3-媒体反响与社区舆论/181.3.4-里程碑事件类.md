# 181.3.4 里程碑事件类

### 新闻条目 3

- **新闻标题（中英）**：FreeBSD 16 从基本系统中退役最后的 GPL 代码（FreeBSD 16 Retires The Last Of Its GPL Code From Its Base System）
- **新闻来源**：Phoronix + Michael Larabel + 2026-07-15 + <https://www.phoronix.com/news/FreeBSD-16-Goes-GPL-Free> + <https://web.archive.org/web/2026/https://www.phoronix.com/news/FreeBSD-16-Goes-GPL-Free>
- **新闻摘要**：2026 年 7 月 15 日 Phoronix 报道 FreeBSD 16-CURRENT 已从基本系统中移除最后的 GPL 许可组件：`diff3`（替换为 OpenBSD 的 BSD 版实现）与 GNU `dialog`（替换为 `bsddialog`，安装程序已于约 4 年前迁移，`dpv` 作为最后一个使用者在弃用逾两年后一并移除），同步删除 `dpv`、`libdpv`、`libfigpar` 并退役源码树中的 `gnu/` 目录。FreeBSD 16.0 预定 2027 年 12 月发布，届时基本系统将不含 GPL 代码；Ports 中的数千个 GPL 应用不受影响。工具链去 GPL 化可上溯至 2010 年代初的 Clang 迁移与 2012 年 GNU `patch` 替换等节点（存疑：起算年份与迁移节点口径不一，待考）。
- **与本章主题的关联说明**：本章记述 FreeBSD 16.x-CURRENT 中 `gnu/` 目录退役的里程碑，这是 FreeBSD 许可证纯洁化工程的最终完成节点。
- **与官方史料的交叉验证结论**：Phoronix 报道与 OpenNet（2026-07-15）、FOSS Force（2026-07-15）及 FreeBSD 源码审查记录多源交叉验证：一致（移除组件清单、`gnu/` 目录退役与 FreeBSD 16.0 预定时间以官方审查记录为准）。

### 新闻条目 4

- **新闻标题（中英）**：FreeBSD 开发新的 NTSYNC 驱动用于加速 Windows NT 同步原语（FreeBSD Developing New NTSYNC Driver For Accelerating Windows NT Sync Primitives）
- **新闻来源**：Phoronix + Michael Larabel + 2026-07-27 + <https://www.phoronix.com/news/FreeBSD-Q2-2026> + <https://web.archive.org/web/2026/https://www.phoronix.com/news/FreeBSD-Q2-2026>
- **新闻摘要**：2026 年 7 月 27 日 FreeBSD 项目发布 Q2-2026 状态报告，其中包含新的 NTSYNC 驱动开发，用于加速 Windows NT 同步原语。这一驱动将提升 FreeBSD 上运行 Windows 应用的性能。同期报告还包含 AMD ROCm 移植等多项现代化改进。
- **与本章主题的关联说明**：本章记述 FreeBSD 16.x-CURRENT 的现代化进展，NTSYNC 驱动是 16.x 在 Windows 兼容性方向的关键改进。
- **与官方史料的交叉验证结论**：FreeBSD Q2-2026 状态报告（2026-07-27）与 Phoronix 报道交叉验证。
