# 392.0.11 邮件列表史学观点（2026-08-28 深度蒸馏 · v2-hist）

<!-- MAIL_INSIGHT: <no-id-netbsd-advocacy-aa084fc6a66d20ad> -->
**观点**：2013 年 1 月，netbsd-advocacy 出现征集帖“20 significant events in NetBSD history?”：发起者计划撰写 NetBSD 20 周年纪念文，向列表征集“any events that you think are noteworthy”，并自述“I have already done many interviews about NetBSD's early history and have compiled a start of a list toward a longer work”。
**邮件来源**：发件人字段空缺（正文署名链接指向 reedmedia.net），netbsd-advocacy，2013-01-19，Message-ID: `<no-id-netbsd-advocacy-aa084fc6a66d20ad>`
**史学意义**：本条补存该征集帖的标准存档 ID：它揭示社区自我史学的完整生产管线——口述访谈（many interviews）→ 事件清单（compiled a start of a list）→ 众包补充（suggesting any events）→ 纪念文章，且明言这是“toward a longer work”的阶段成果。未来 BSD 史书写的真正竞争者不是学者的专著，而是这条社区流水线的产出，史家的存档与考据工作须以该管线为对象并与之对话。
<!-- /MAIL_INSIGHT -->

<!-- MAIL_INSIGHT: 199605120721.JAA29151@allegro.lemis.de -->
**观点**：1996 年 5 月，J. Wunsch 与 Greg Lehey 在 freebsd-chat 就 daemon 故事“Pity that it didn‘t make it into Salus’ book”与“It‘s made it into the new edition of ’Installing FreeBSD'”往复，同帖还考证了早期 Unix 的 daemon 名单：“only init, update, and cron have already been there in V7?”“And the swapper.”
**邮件来源**：Greg Lehey，freebsd-chat，1996-05-12，Message-ID: `199605120721.JAA29151@allegro.lemis.de`
**史学意义**：本条为本章补全该帖的另一半价值：同一封邮件里，权威史书的覆盖缺口（Salus 未收）与史料的实际栖身地（安装手册新版）被同时指出，且顺手完成了 V7 daemon 清单的微型考据（init、update、cron，Lehey 补 swapper）。未来书写的方向已含在这封 1996 年的邮件里：史料的补全不发生在史书之内，而发生在技术文档、邮件往复与当事人的随手考据之中，未来史家的基本功是从这些非史书载体中打捞史实。
<!-- /MAIL_INSIGHT -->

<!-- MAIL_INSIGHT: <no-id-tech-misc-5f1cbc641a0fdd72> -->
**观点**：2024 年 5 月，NetBSD 开发者 Brett Lymn 在 tech-misc 就 curses 源流作谱系直述：“The NetBSD curses is the original BSD curses with updates and enhancements”，并说明其目标是完整实现 Open Group SUSv2 curses 规范的全部函数调用。
**邮件来源**：Brett Lymn，tech-misc（NetBSD 列表），2024-05-30，Message-ID: `<no-id-tech-misc-5f1cbc641a0fdd72>`
**史学意义**：距 4BSD curses 诞生四十余年后，谱系仍由当事人以一句话直述并附规范性目标——活态传承的口述谱系与标准文档在 2024 年仍在同帖并行。它为“未来书写方向”提供最直接的注脚：代码谱系的第一手陈述者正在老去，未来 BSD 史的一部分任务是在这批直述尚可核验时，将其与源码演进史交叉锚定，使口述谱系降维成可检验的版本序列。
