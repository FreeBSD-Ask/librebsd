# 213.3.3 Linux 2.4（2001）

**要点**：Linux 2.4（2001）在 OpenBSD 2.x 同期以稳定化、多架构与企业采用见长；与 OpenBSD 2.x 的安全审计文化对照——Linux 2.4 的社区规模驱动快速迭代，安全修复依赖分散维护，OpenBSD 2.x 以集中代码审计建立安全声誉。

**史料**：Linux 2.4 发布说明（2001）［B］

**史观**：总纲第 8 条——本体论上各方平等：Linux 社区规模模式 vs OpenBSD 集中审计模式在 2000-2004 形成安全文化对照。

**辨析**：Linux 2.4 的安全靠社区响应，OpenBSD 2.x 靠主动审计，二者路径不同。

**文献**：Linux Kernel. 2.4 Release Notes [EB/OL]. ［B］
