# 213.3.4 Windows 2000/XP（2000-2001）

**要点**：Microsoft 在 OpenBSD 2.x 同期发布 Windows 2000（2000）与 XP（2001），以商业桌面/企业市场主导；与 OpenBSD 2.x 的开源安全审计对照——Windows 闭源使安全依赖微软响应，OpenBSD 2.x 以开源可审计建立“默认安全”声誉。

**史料**：Microsoft Windows 2000/XP 发布史 ［B］

**史观**：总纲第 8 条——本体论上各方平等：闭源安全响应 vs 开源代码审计在 2000-2004 形成对照。

**辨析**：Windows 2000/XP 的安全事件（如冲击波，2003-08 爆发，处本节 2000-2004 窗口末端）凸显闭源响应劣势，OpenBSD 2.x 以审计预防。
