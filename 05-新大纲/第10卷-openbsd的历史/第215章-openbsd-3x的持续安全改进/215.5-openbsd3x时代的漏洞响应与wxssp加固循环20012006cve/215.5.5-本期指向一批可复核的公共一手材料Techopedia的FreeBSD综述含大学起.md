# 215.5.5 本期指向一批可复核的公共一手材料Techopedia的FreeBSD综述含大学起

- 本期指向一批可复核的公共一手材料：Techopedia 的 FreeBSD 综述（含大学起源、AT&T 纠葛、1990 年代拨号 ISP 时期的支配地位、PS3/PS4 与 Netflix、WhatsApp 用例，并链接 Jordan Hubbard 在 MeetBSD 与 EuroBSDCon 的 SlideShare 演讲）（2044.96-2178.50）；NYCBUG 公开视频：John Baldwin 讲 FreeBSD 的 NUMA 支持、Ingo Schwarze 讲 Mandoc 六年间从零重建并成为各 BSD 标准文档工具链（3593.96-3689.50）；OpenBSD 5.7 CD 套装将 base 与 packages 的签名印于盘面（3520.26-3584.70）；FreeBSD/ARM 原生构建的 SVN 提交（2504.00-2606.16）与 OpenBSD disklabel 模板的 Undeadly 文章及手册页节选（2343.80-2474.12）。（BSD Now EP89，[2044.96-2178.50]，L2）

**史观**：

- 总纲10 动手者创造历史：Larkin 的整段自述是“动手者创造历史”的范本：安全机制的落地不是宣言而是逐页的体力活——在 QEMU 中逐项核对内核各区域的页权限、拆分 hibernate 唤醒代码与栈共用的页面、AMD64 内核 W^X 耗时约两个月而 i386 复活 PAE 耗时约两倍（1166.14-1185.56、1450.06-1459.82）；他形容自己当初“被塞给一个半成品补丁，让它能跑起来再回来汇报”（843.40-849.54），工程的推进系于具体的人与具体的机器。（BSD Now EP89，[1166.14-1459.82]，L1）
- 总纲3 不存在进步，只有权力再分配：从 2001/2002 年引入到 2015 年“我们仍在改进它”（961.62-968.14），从永远修不完的 suspend/resume 机器世代（879.00-905.98）到攻击与防御围绕页权限的持续博弈，本访谈呈现的安全史不是线性进步史，而是防线与绕过之间无终点的再分配过程；Larkin 反复强调 W^X 并非万灵药，正是否认“问题已被永久解决”这一叙事。（BSD Now EP89，[957.74-975.98]，L1）
- 总纲4 分离聚合是永恒规律：本期新闻呈现 BSD 生态的分离聚合循环：BitRig 自 OpenBSD 分叉并披露与上游在 base 系统与开发模式上的差异（457.14-525.68）；Hardened BSD 自 FreeBSD 分叉、以“特性成熟后推回主线”为目标，主持人将其类比 TrustedBSD 时代 Robert Watson 的独立仓库模式（594.18-610.44）；OPNsense 则发布以 Hardened BSD 为底座的实验构建，形成防火墙发行版与安全 fork 的重新聚合（527.10-654.70）——分叉不是决裂，而是实验与再整合的环节。（BSD Now EP89，[457.14-654.70]，L2）
