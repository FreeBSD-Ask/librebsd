# 215.4.2 FreeBSD x86 性能的对照

**要点**：FreeBSD 1996-2004 年间专注 x86 性能与稳定性，引入 SMPng（5.x 时代）、softdep、ULE 调度器雏形；FreeBSD x86 性能领先于 OpenBSD，但 OpenBSD 安全特性领先；FreeBSD 与 OpenBSD 在用户群上分化——FreeBSD 服务于 ISP/CDN，OpenBSD 服务于安全敏感场景

**史料**：FreeBSD 2.x-4.x Release Notes；OpenBSD Release Notes；BSD 基准测试对比〔L3 官方文档与公告/L5 二手研究〕

**史观**：总纲第 8 条——本体论上各方平等：FreeBSD 以 x86 性能见长、OpenBSD 以安全审计立身，两种工程取向在存在论上并无高下——性能与安全是不同部署场景下的不同“善”，比较框架本身即预设了评价者的立场。

**辨析**：FreeBSD 与 OpenBSD 的“性能差距”在不同硬件与负载上差异较大——需对照基准测试核验；两项目的用户群分化缺乏权威统计

**文献**：FreeBSD/OpenBSD Release Notes；BSD 基准测试对比
