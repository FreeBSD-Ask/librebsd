# 212.5.3 再回应——批评方对 OpenBSD 反批评的再回应与许可证纯洁化争议深化

**要点**：针对 OpenBSD 阵营在 212.5.2 节提出的四条反批评论证（许可证权利合法行使、许可证递进限制实证、GPL 违规技术困境、社区需求驱动），批评方（Ylönen 阵营及其同情者）的再回应沿三条线索展开，并与许可证纯洁化争议深化交织——（0）再回应总纲：Ylönen 阵营可论证 OpenBSD 阵营的四条反批评均以“自由许可”为单一预设，但 SSH 1.2.12 的自由许可是 Ylönen 在 1995 年尚未决定商业化时的临时状态，而非 Ylönen 对“软件自由”价值观的承诺——以“自由许可”对抗“商业许可”是将作者的“未决状态”重构为“价值观承诺”，这一重构使 OpenBSD 阵营占据道德高地的论证基础本身值得审视；Ylönen 阵营亦可再回应“GPL 违规”论点——GPL 违规的判定权在 GPL 许可证持有者（FSF 与 libgmp 作者 T. Granlund）而非 OpenBSD 阵营，OpenBSD 阵营以“GPL violation”论证 fork 正当性存在法律越位风险，且“移除 GPL 组件”与“指控 Ylönen 的 SSH 1.2.13+ 为 GPL 违规”是两个不同层面，前者是技术必要、后者是法律判断，两者不得混淆；OpenSSH fork 后的“许可证纯洁化”（license purification）工作——de Raadt 移除非可移植代码、Provos 赴加拿大移除加密与 GPL 组件（libgmp）、Friedl 替换 SSH 1.3 协议为 1.5、Beck 处理 Makefile 避开 RSA 专利——在再回应层引发三重争议——（1）“纯洁化”叙事的道德预判：“cleaning up the license mess”（清理许可证混乱）与“purification”（纯洁化）措辞隐含道德预判——将 Ylönen 的 SSH 1.2.12 定位为“混乱”（mess）与“不纯”（impure），将 OpenBSD 的工作定位为“清理”（cleaning up）与“纯洁化”（purification），这一叙事框架使 Ylönen 的原创贡献在“纯洁化”过程中被重构为“需要被清理的遗留物”；但 SSH 1.2.12 是 Ylönen 的原创作品，其许可证组合（Ylönen 自有许可 + GPL'd libgmp）是当时的合法状态，“混乱”是 OpenBSD 阵营的事后定性而非客观事实；（2）GPL 组件移除的动机辨析：Provos 移除 libgmp（GPL 组件）被叙述为“纯洁化”，但移除 GPL 组件的动机可能混合了法律约束（美国密码出口管制要求 Provos 赴加拿大工作）与许可证意识形态（使 OpenSSH 可在 BSD 许可下发布，避免 GPL 传染）——若动机主要是法律约束，则“纯洁化”是法律驱动的技术必要；若动机主要是许可证意识形态，则“纯洁化”是 BSD 阵营对 GPL 的意识形态排斥；两类动机须经 Provos 赴加拿大的具体工作记录与 OpenBSD misc@ 邮件列表讨论交叉验证；（3）“纯洁化”与文化挪用的类比：OpenSSH 的“纯洁化”叙事与“重写即归属”模式（参见相关章节）存在结构相似性——OpenBSD 重写 SSH 1.2.12 的 GPL 组件与非可移植代码后，OpenSSH 以“纯洁化版本”自我定位，Ylönen 的原创贡献在“纯洁化”叙事中被弱化为“需要被清理的起点”，这一弱化与文化挪用中“重写即归属”的结构相似但非同一——OpenSSH 官方历史确实承认"OpenSSH is a derivative of the original free ssh 1.2.12 release from Tatu Ylönen“与”Parts of OpenSSH still bear Tatu's license"，归属承认的存在使“纯洁化”不同于完全的文化挪用

**史料**：OpenSSH 项目历史页面（记载“cleaning up the license mess”、“removing non-portabilities”、“removed the remaining cryptographic and GPL'd components”、Provos 赴加拿大工作）；OpenSSH LICENCE 文件（记载“Parts of OpenSSH still bear Tatu's license”与各组件许可证组合）；参见 OpenSSH 专章许可证纯洁化记录；参见“重写即归属”模式相关章节；OpenBSD misc@ 邮件列表 1999-2000 年关于许可证纯洁化工作的讨论存档；美国密码出口管制（BXA/EAR）文档 ［A］

**史观**：总纲第 15 条——文化即形式主义：SSH 文化（Ylönen 的原创 SSH 文化）在“纯洁化”叙事的形式主义化过程中被遮蔽与重构——Ylönen 的 SSH 1.2.12 被重构为“许可证混乱的起点”，OpenBSD 的“纯洁化”工作被重构为“清理与解放”，传统在重构中被遮蔽；总纲第 19 条——解释学循环是历史认识的根本条件：“什么被记录、什么被遗忘”——OpenSSH 官方历史记录了“纯洁化”工作的细节（de Raadt、Provos、Friedl、Beck 各自贡献），但对 Ylönen 原创贡献的记录仅以“derivative of the original free ssh 1.2.12 release”一笔带过，这一“记录与遗忘”的分配本身就是权力行使

**辨析**：许可证纯洁化争议的辨析须区分三个维度并以三段式呈现——【查证来源】（1）OpenSSH 官方历史页面（<https://www.openssh.com/history.html>）经 2026-07-23 WebFetch 一手核验，确认“cleaning up the license mess”“removing non-portabilities”“removed the remaining cryptographic and GPL'd components”等措辞均原文存在；（2）openbsd.duckdb openbsd-src 仓库 commits 表验证 Provos 移除 libgmp 的完整时间线：fork 启动（commit `84959968510b`，1999-09-26）→libgmp→SSL bignum 转换启动（commit `76c6bcb9f8b9`，1999-09-28T04:45:35Z，subject 原文"convert all uses of gmp to SSL bignum convert all used of rsa to SSL rsa functions"）→GPL 组件持续移除（commit `d9d42abc7ed4`，2000-12-11T02:22:53Z，subject“another piece of GPL software gone”）→libgmp 完全移除（commit `84174f65ff52`，2000-12-12T00:46:49Z，subject“gmp gone”；commit `348a6efc411d`，2000-12-15T01:58:27Z，subject“more cleanup. remove last vestiges of gmp”）——Provos 的 libgmp 移除工作历时 14 个月（1999-09-28 至 2000-12-15），证明“纯洁化”是长期系统工程而非单点修复；【交叉验证方法】（1）法律维度：OpenBSD 移除 GPL 组件与非可移植代码在法律层面完全正当——BSD 许可证允许修改与再分发，“纯洁化”是合法行使许可权利；openbsd.duckdb 显示的 Provos 持续 14 个月的 libgmp 移除工作（1999-09-28 至 2000-12-15）证明 OpenBSD 阵营以技术必要而非意识形态排斥为驱动，但“法律正当”不等于“叙事公正”——“纯洁化”叙事将 Ylönen 的原创贡献重构为“需要被清理的遗留物”在法律上正当但在叙事上须对称呈现，须经 SSH 1.2.12 原始 LICENSE 文件、OpenSSH LICENCE 文件、SSH Communications Security 历年许可证文件三方比对核实；（2）技术维度：de Raadt 移除非可移植代码以“简化源码便于安全审计”（OpenSSH 官方历史原文"simpler source code, so that security holes and other issues could be spotted easier"）是技术驱动的正当工作，Beck 处理 Makefile 避开 RSA 专利是法律约束驱动的技术必要——openbsd.duckdb 显示 Beck 在 1999.09-2000.12 期间共 40 条 ssh 相关 commit 涉及 Makefile、OpenSSL、RSA 专利规避，二者与“许可证意识形态”无关；（3）叙事维度：“纯洁化”措辞隐含的道德预判须经 Ylönen 阵营的对称呈现后方可评估——Ylönen 阵营可论证 SSH 1.2.12 的许可证组合（自有许可 + GPL'd libgmp）是当时的合法状态，“混乱”是 OpenBSD 阵营的事后定性而非客观事实；三个维度须分层处理，不得以法律维度的正当性替代叙事维度的对称呈现；【0 信任原则·多源交叉验证不可靠性规则】OpenSSH 官方历史是 OpenBSD 阵营的单方面叙事，其“cleaning up the license mess”措辞须经 SSH Communications Security 官方声明与 comp.security.ssh Usenet 存档交叉验证后方可采信为“社区共识”；【存疑判定依据】（1）“纯洁化”动机的法律约束 vs 意识形态辨析边界：Provos 移除 libgmp 的动机可能混合了法律约束（美国密码出口管制要求 Provos 赴加拿大工作）与许可证意识形态（使 OpenSSH 可在 BSD 许可下发布，避免 GPL 传染）——openbsd.duckdb 的 commit subject（“convert all
