# 212.3.3 OpenSSH 的全球部署与效应

**要点**：OpenSSH 自 1999 年起迅速成为 Unix 生态标准 SSH 实现，部署于 Linux 几乎所有发行版、FreeBSD/NetBSD/macOS/Solaris 等；OpenSSH 部署规模至 2020 年代为 **千万至亿级服务器**（2026-08-04 联网复核修正：Zondex 全球扫描约 1.22 亿 SSH 主机、Bitsight 2024 Q1 约 3,830 万 SSH 服务器其中约 2,600 万运行 OpenSSH（约 70%）；“数亿台”为过高估计）；OpenSSH 的成功让 OpenBSD 项目获得间接名声，但商业回报有限

**史料**：Zondex OpenSSH 部署统计（zondex.io/product/OpenSSH，约 1.22 亿主机）；Bitsight 2024 Q1 全球扫描分析（bitsighttech.com/blog/xz-apocalypse-almost-was，约 3,830 万 SSH 服务器/约 2,600 万 OpenSSH）；各 OS 发行版 OpenSSH 包信息；Rapid7 NICER 2020 全网扫描（Sonar，OpenSSH 占 SSH 服务 92.238%，ref2510）；OpenBSD Foundation 年度报告 ［B］

**史观**：总纲第 3 条——不存在进步只有权力再分配：OpenSSH 商业公司（如 Cisco、Apple、IBM）获利但 OpenBSD 项目未获对应回报

**辨析**：OpenSSH 部署规模（2026-08-04 联网复核后修正）——【0 信任原则·扫描统计的口径差异】Zondex（2026 年数据，端口 22/2222 等扫描）统计约 1.22 亿 SSH 主机、Bitsight（2024 Q1，三个月扫描）统计约 3,830 万 SSH 服务器（其中约 70% 即 2,600 万运行 OpenSSH、24% 为 dropbear）、Rapid7 NICER 2020 全网 IPv4 普查（Sonar）则显示 OpenSSH 占 SSH 服务 92.238%（15,747,821/约 1,708 万，ref2510）、TUM 2014 抽样约 65%——单一扫描口径下 OpenSSH 占 SSH 服务比例在 65%–92% 区间波动，Bitsight 70% 系其 2024 Q1 单窗口 IPv4 探测之比，不宜作为通用市占率；社区文章（vivianvoss.net）称“3,200 万互联网服务器”——三源量级一致（千万级），但口径差异显著（Zondex 含全端口+IPv4/IPv6 全量扫描、Bitsight 为三个月窗口的 IPv4 探测、社区数字可能只计端口 22）；“数亿台服务器”系过高估计，须修正为“千万至亿级”；Debian Popcon（约 30 万自愿上报主机样本）仅反映 Debian 子样本安装比例，无法外推全球；【存疑判定依据】OpenSSH 官方未发布权威部署统计，“数亿台”（>1 亿）表述失实，实测量级为 2,600 万-1.22 亿（OpenSSH 具体约 2,600 万，SSH 总协议主机约 1.22 亿）；具体数字随扫描时间窗与方法论波动，正文采用量级表述“千万至亿级”并附三源；OpenBSD 项目从 OpenSSH 获得的具体回报（捐赠、赞助）需考据
