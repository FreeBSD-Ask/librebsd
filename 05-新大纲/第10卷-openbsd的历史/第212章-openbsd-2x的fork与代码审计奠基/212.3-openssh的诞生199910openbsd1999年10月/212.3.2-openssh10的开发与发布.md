# 212.3.2 OpenSSH 1.0 的开发与发布

**要点**：OpenSSH 1.0（1999.10）由 OpenBSD 团队开发，基于 SSH 1.2.12 源码并加入大量审计修复；OpenSSH 1.0 仅支持 SSH 协议 1；OpenSSH 2.1.0（2000 年）支持 SSH 协议 2；OpenBSD 团队与 OpenSSH 可移植版（Portable OpenSSH）团队协作扩展至非 OpenBSD 平台

**史料**：OpenSSH 1.0/2.1.0 Release Notes；OpenBSD CVS commit log；OpenSSH 邮件列表 ［A］

**史观**：总纲第 10 条——动手者创造历史：OpenBSD 作为边缘项目通过 OpenSSH 贡献全球基础设施

**辨析**：OpenSSH 1.0 与 2.1.0 的具体发布日期在不同来源中存在差异——需对照 OpenBSD 官方公告核验；Portable OpenSSH 的独立团队与 OpenBSD OpenSSH 的协作模式需考据
