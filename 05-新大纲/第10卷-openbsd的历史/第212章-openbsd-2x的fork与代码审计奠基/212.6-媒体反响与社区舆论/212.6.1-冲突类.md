# 212.6.1 冲突类


> 本子节汇总与本章主题相关的新闻报道与社区舆论，本子节原声明按七类组织，实际现载类目以各节小标题为准（冲突类等已载类目；其余类目暂缺待补）。所有新闻条目遵循 0 信任原则，须与官方史料交叉验证后方可采信。

### 新闻条目 1

- **新闻标题（中英）**：OpenBSD Jumpstart 历史页（“Forked from NetBSD. Theo de Raadt（西奥·德·若特） is the founder and leader of the OpenBSD project. The first OpenBSD release 1.1/CVS appeared on October 18, 1995”）
- **新闻来源**：openbsdjumpstart.org + 无署名作者 + 持续更新 + URL: <https://www.openbsdjumpstart.org/> + 〔存档链接待补，原“存档 URL: 待补”占位已标注〕
- **新闻摘要**：OpenBSD Jumpstart 教学站点明确记载 OpenBSD 1995 年 10 月 18 日 CVS 仓库建立、早期 1.1 快照口径；首版正式发行按本章 193.1 考据脚注为 1.2（1996-07-01）〔两说已按考据脚注统一，避免仓库日期与发行日期混同〕、Theo de Raadt 为创始人兼领导者、fork 自 NetBSD 三个核心史实。该站点为社区维护的 OpenBSD 入门教学资源，常被引用为 OpenBSD 起源时点的二手参考。
- **与本章主题的关联说明**：本章叙述 OpenBSD 起源，该页明确点出三个关键史实（1995-10-18、fork 自 NetBSD、Theo 创始），与官方 FAQ 一致，可作为本章叙事的辅助印证史料。
- **与官方史料的交叉验证结论**：openbsdjumpstart.org 表述与 OpenBSD FAQ 1（"The first OpenBSD release 1.1/CVS appeared on October 18, 1995"）、OpenBSD 邮件列表 Adam Glass（亚当·格拉斯） 1994-12-23 通知（NetBSD Core Team 移除 de Raadt）一致；OpenBSD 1.1 早期版本号在官方 changelog 中以 plus20.html “Changes made between birth and OpenBSD 2.0” 涵盖。一致采纳。

### 新闻条目 2

- **新闻标题（中英）**：OpenBSD Journal 2000 年 3 月报道 “OpenSSH 1.2.3 is out”
- **新闻来源**：undeadly.org + James Phillips（Dengue）+ 2000-03-06 + URL: <https://undeadly.org/cgi?action=article;sid=20000306225318> + 〔存档链接待补，原“存档 URL: 待补”占位已标注〕
- **新闻摘要**：undeadly.org 报道 OpenSSH 1.2.3 发布，OpenSSH 是 OpenBSD 项目从 1999 年起 fork 自 OSSH 的 SSH 实现，本章起源期 OpenBSD 项目已奠定 “衍生子项目” 模式。该报道反映了 OpenBSD 起源期结束后衍生 OpenSSH 子项目的早期状态。
- **与本章主题的关联说明**：本章叙述 OpenBSD 起源（1996），OpenSSH 1999 年 fork 是 OpenBSD 起源期结束后第一个重大衍生子项目，可作为本章 “OpenBSD 安全文化奠基催生 OpenSSH” 叙事的延伸史料。
- **与官方史料的交叉验证结论**：undeadly.org 报道与 OpenBSD 官方 OpenSSH 历史页面（www.openssh.com/history.html）一致；OpenSSH 1.2.3 发布日期 2000-03-06 与 OpenBSD release 时间线（OpenBSD 2.6 1999-12 与 OpenBSD 2.7 2000-06 之间）一致。一致采纳。
