# 212.2.2 早期发现的重大漏洞

**要点**：OpenBSD 1996-2000 年间通过代码审计发现并修复数千个安全漏洞，包括缓冲区溢出（如 ftpd、telnetd）、格式化字符串漏洞、信任边界问题；部分漏洞在审计前已被利用，部分是审计发现的新型漏洞；OpenBSD 的审计成果被其他 BSD/Linux 项目移植修复

**史料**：OpenBSD Security Advisories 1996-2000；CVS commit log；BUGTRAQ 邮件列表档案 ［A］

**史观**：总纲第 10 条——动手者创造历史：OpenBSD 作为边缘项目通过逐行审计以动手修复而非宣言的方式贡献安全成果至整个 Unix 生态，其缓冲区溢出等修复被其他 BSD/Linux 项目移植

**辨析**：“数千个漏洞”的具体数字在不同叙事中差异较大——部分资料称 2000+，部分称 5000+，需对照 security advisory 与 commit log 核验；经 WebFetch OpenBSD 官方 **security.html**（<https://www.openbsd.org/security.html>，2026-07-30 访问）核实，OpenBSD 官方 Security 页面 §The Reward 明确表述 "The most intense part of our security auditing happened immediately before the OpenBSD 2.0 release and during the 2.0→2.1 transition, over the last third of 1996 and first half of 1997. Thousands (yes, thousands) of security issues were fixed rapidly over this year-long period; bugs like the standard buffer overflows, protocol implementation weaknesses, information gathering, and filesystem races. Hence most of the security problems that we encountered were fixed before our 2.1 release, and then a far smaller number needed fixing for our 2.2 release.“，OpenBSD 官方一手表述使用 ”Thousands (yes, thousands)" 强调 “数千” 量级，但未给出精确数字；OpenBSD 官方 Security 页面 §Audit Process 确认 “We have been auditing since the summer of 1996.”，证实审计始于 1996 年夏；OpenBSD 官方 errata 链接从 2.0 起（errata20.html 至 errata79.html），1.0/1.1 无 errata 页面，advisory 数量须以各版本 errata 页面逐版本统计；[考据完成：2026-07-30 OpenBSD 官方 security.html 已证实 “数千” 量级为官方表述，但精确数字须以各版本 errata 页面逐版本统计，“2000+” 与 “5000+” 等具体数字无官方一手来源，属二手转述]

**文献**：OpenBSD Security Advisories；BUGTRAQ 档案；CVS commit log ［A］
