# 212.2.4 要点OpenBSD审计记录与漏洞修复commit是研究审计文化的核心史料comm

**要点**：OpenBSD 审计记录与漏洞修复 commit 是研究审计文化的核心史料；commit log 中的“audit”与“fix”标签标识审计工作；security advisory 与 commit 的对应关系是考据关键；考据需对照 CVS commit log 与 advisory 数据库

**史料**：OpenBSD CVS commit log；OpenBSD Security Advisories 数据库；BUGTRAQ 档案 ［A］

**史观**：总纲第 9 条——经验优先：审计记录与 commit 的考据须多源交叉——部分 commit 在迁移过程中可能丢失 audit 标签，结论须以 commit log、security advisory 与 errata 相互印证而非单源推断

**辨析**：审计 commit 与一般 commit 的区分需考据——OpenBSD commit log 中部分 commit 未明确标注 audit，需对照 advisory 推断
