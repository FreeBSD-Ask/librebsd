# 218.2.1 Heartbleed 漏洞的效应

**要点**：2014 年 4 月 7 日 Heartbleed 漏洞（CVE-2014-0160）披露，OpenSSL TLS heartbeat 扩展存在缓冲区越界读取缺陷，攻击者可读取服务器内存中的私钥与会话令牌，影响全球 HTTPS 服务；OpenBSD 社区在 misc@ 邮件列表讨论 OpenSSL 代码质量问题（包括未使用的 dead code、维护混乱），形成对 OpenSSL“维护失败”的共识；openbsd.duckdb 显示 2014-04-07 djm commit af0b15b8442f"cherrypick fix for CVE-2014-0160 ‘heartbleed’ vulnerability from OpenSSL git"为 OpenBSD 对 Heartbleed 的即时响应

**史料**：CVE-2014-0160 详情（<https://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2014-0160>）；Heartbleed 官网（<http://heartbleed.com/>）；openbsd.duckdb openbsd-src 仓库 commit af0b15b8442f（2014-04-07 djm“cherrypick fix for CVE-2014-0160”）；OpenBSD misc@ 关于 Heartbleed 的讨论（<https://marc.info/?laccopenbsd-misc>）〔L1 代码/构建产物/L2 即时通讯记录/L3 官方文档与公告〕

**史观**：密码学：Heartbleed 暴露密码学库的工程质量问题——OpenSSL 作为全球 HTTPS 基础设施的核心组件，其代码质量（dead code、维护混乱）与安全关键性不匹配，这一矛盾催生 LibreSSL fork

**辨析**：Heartbleed 的责任归属在不同叙事中存在分歧——部分归咎 OpenSSL 项目（代码质量差、维护流程不透明），部分归咎使用方未及时更新；漏洞的实际影响范围无权威统计 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］
