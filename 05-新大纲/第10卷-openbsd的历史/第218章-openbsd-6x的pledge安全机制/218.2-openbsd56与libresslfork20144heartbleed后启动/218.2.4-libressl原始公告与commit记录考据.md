# 218.2.4 LibreSSL 原始公告与 commit 记录考据

**要点**：LibreSSL fork 的原始公告与 openbsd.duckdb commit log 是研究 fork 过程的核心史料；openbsd.duckdb 显示 LibreSSL 相关 commit 自 2014-04-07 起（djm Heartbleed fix），2014-04-13 起 miod 导入 OpenSSL 1.0.1g，2014-04-14 起 beck 移除引擎、jsing 应用 KNF，2014-07-12 jsing 提交 libressl 库初始版本；fork 过程的完整时间线以 commit log 与邮件列表档案交叉验证为准

**史料**：openbsd.duckdb openbsd-src 仓库 LibreSSL 相关 commit（2014-04-07 起 djm、miod、beck、jsing 等）；LibreSSL 官方公告（<https://www.libressl.org/>）；misc@、tech@ 邮件列表中关于 fork 的讨论（<https://marc.info/?laccopenbsd-misc>、<https://marc.info/?laccopenbsd-tech）>

**史观**：0 信任原则：LibreSSL 考据是 0 信任原则在 fork 史研究中的实践——fork 公告的文本须与 commit log 交叉验证，仅凭公告文本无法确认 fork 的实际代码变更范围与时间线

**辨析**：fork 公告的具体内容以 LibreSSL 官方网站原始公告为准——转载或二手报道可能简化 fork 动机与过程；commit log 中的清理工作量以 openbsd.duckdb openbsd-src 仓库 2014-04 至 2014-11 期间 lib/libressl/ 与 lib/libssl/ 路径下的 commit 计数为准
