# 218.1.1 **pledge(2)** 的设计与实现

**要点**：**pledge(2)** 的前身是 tame(2) 子系统，由 de Raadt 于 2015-07-19 commit `586b470f3a48` 引入（"tame(2) is a subsystem which restricts programs into a ‘reduced feature operating model’"）；2015-10-09 de Raadt commit `350b464c5787` 将 tame() 重命名为 pledge()（"Rename tame() to pledge(). This fairly interface has evolved to be more strict than anticipated"）；pledge 在 OpenBSD 5.8（2015-10-29 发布）中存在但被禁用——2015-10-12 schwarze commit `cfe38e1d85ad` 明确记载“pledge wasn't called pledge in 5.8, and it was disabled”；pledge 在 OpenBSD 5.9（2016-03-29 发布）中正式启用；pledge 让进程自愿放弃特定权限（如网络、文件系统访问），进程在程序启动时调用 `pledge("stdio rpath", NULL)` 即可限制权限

  **pledge/tame 演进关键 commit 时间线**：

  | 日期 | commit hash | 作者 | 说明 |
  | --- | --- | --- | --- |
  | 2015-07-19 | `586b470f3a48` | deraadt | tame(2) 引入——restricts programs into a ‘reduced feature operating model’ |
  | 2015-10-09 | `350b464c5787` | deraadt | 将 tame() 重命名为 pledge() |

**史料**：openbsd.duckdb openbsd-src 仓库 commit `586b470f3a48`（2015-07-19 deraadt “tame(2) is a subsystem...”）、commit `350b464c5787`（2015-10-09 deraadt “Rename tame() to pledge()”）、commit `cfe38e1d85ad`（2015-10-12 schwarze“pledge wasn't called pledge in 5.8, and it was disabled”）；OpenBSD 5.9 Release Notes pledge 部分；**pledge(2)** 手册页（<https://man.openbsd.org/pledge.2>）〔L1 代码/构建产物/L3 官方文档与公告〕

**史观**：总纲第 17 条——软件工程：pledge 是“最小权限”原则的系统调用化实现——进程自愿声明所需权限子集，内核据此拒绝越权系统调用，这一设计将安全约束从外部沙箱转移至程序自身声明，是软件工程中“白名单优先于黑名单”原则在操作系统接口层的实践

**辨析**：[2026-08-15 邮件列表库验证通过]：2015-10 openbsd-tech/openbsd-bugs 多条邮件确认 pledge 在 2015 年 10 月已进入广泛测试阶段（2015-10-30 “syscall 96 in top(1) on renice”、2015-10-31 “pledge(2) and pselect(2)”、2015-10-09 Kevin Reay 提及“new pledge syscall”），与 5.8 开发周期时间线一致；pledge 的引入版本在不同叙事中存在分歧——部分资料称 5.9 正式引入，部分称 5.8 已有雏形；经 openbsd.duckdb 核查，tame() 于 2015-07-19 引入（5.8 开发周期），2015-10-09 重命名为 pledge()，但在 5.8 中被禁用（schwarze commit cfe38e1d85ad 明确记载），5.9 正式启用；原大纲称“5.4 引入 pledge 雏形”系误记——5.4（2014）时 tame/pledge 均不存在，tame 的最早 commit 为 2015-07-19
