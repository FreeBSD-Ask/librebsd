# 218.3.3 与 Linux namespaces/Solaris zones 的比较

**要点**：Linux namespaces 提供进程隔离（mount、PID、network 等），Solaris zones 提供系统级容器隔离；OpenBSD pledge+unveil 是进程级权限限制，不提供完整隔离；三者设计目标不同——namespaces/zones 是容器化（隔离整个运行环境），pledge/unveil 是权限沙箱（限制单个进程的权限），二者非互斥但解决不同层面的问题

**史料**：Linux namespaces 文档（<https://man7.org/linux/man-pages/man7/namespaces.7.html>）；Solaris zones 设计文档；OpenBSD pledge/unveil 文档（<https://man.openbsd.org/pledge.2>、<https://man.openbsd.org/unveil.2）〔L3> 官方文档与公告〕

**史观**：总纲第 7 条——技术选择即政治选择：三项目选择不同的隔离机制是各自对“安全与隔离粒度权衡”的不同政治回应——Linux 以“资源隔离优先”为预设选择 namespaces，Solaris 以“系统级隔离优先”为预设选择 zones，OpenBSD 以“进程级权限限制优先”为预设选择 pledge/unveil

**辨析**：三者的隔离强度对比——设计目标不同难以直接比较，namespaces/zones 提供容器级隔离（适用于多租户场景），pledge/unveil 提供进程级权限限制（适用于单进程硬化）；Solaris zones 的实际部署规模以 Oracle Solaris 官方数据为准 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］
