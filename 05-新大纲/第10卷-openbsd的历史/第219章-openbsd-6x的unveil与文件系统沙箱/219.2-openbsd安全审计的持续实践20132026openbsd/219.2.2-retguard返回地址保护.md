# 219.2.2 RETGUARD 返回地址保护

**要点**：RETGUARD 是 OpenBSD 6.4（2018-10-25 发布）引入的返回地址保护机制——在每个函数 prologue/epilogue 中插入随机 canary，防止 ROP（Return-Oriented Programming）攻击；RETGUARD 由 Todd Mortimer（托德·莫蒂默） 设计实现——openbsd.duckdb 显示 RETGUARD 首次 commit 为 2018-06-06T00:14:29Z mortimer commit `e688c2b0648a` "Add RETGUARD to clang for amd64. This security mechanism uses per-function rando..."；RETGUARD 覆盖 amd64 与 arm64 架构；RETGUARD 与 KARL 配合，形成编译时与运行时双重防护

**辨析**：RETGUARD 与 LLVM CFI、Microsoft CFG（Control Flow Guard）的对比以各自设计文档为准——三者设计目标与覆盖范围不同，RETGUARD 以 per-function 随机 canary 防护返回地址，LLVM CFI 以控制流完整性图防护间接调用，Microsoft CFG 以目标地址验证防护间接调用；RETGUARD 的性能开销以 OpenBSD Release Notes 与 tech@ 邮件列表讨论为准 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］
