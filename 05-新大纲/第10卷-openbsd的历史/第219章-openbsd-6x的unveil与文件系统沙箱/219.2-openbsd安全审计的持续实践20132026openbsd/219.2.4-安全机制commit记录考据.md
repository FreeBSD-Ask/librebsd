# 219.2.4 安全机制 commit 记录考据

**要点**：KARL、RETGUARD 等安全机制的 openbsd.duckdb commit log 与设计文档是研究 OpenBSD 安全审计实践的核心史料；特性引入时间与实现细节以 commit log、邮件列表、设计文档交叉验证为准

**史料**：openbsd.duckdb openbsd-src 仓库安全机制相关 commit（RETGUARD commit e688c2b0648a 等）；OpenBSD Security Advisories（<https://www.openbsd.org/security.html>）；tech@ 邮件列表安全讨论（<https://marc.info/?laccopenbsd-tech>）

**史观**：0 信任原则：安全机制考据是 0 信任原则在安全史研究中的实践——commit log 中的安全机制相关 commit 须以 message_subject 与 file_path 交叉筛选，部分机制在不同版本中演进，仅凭 message_subject 关键字可能遗漏

**辨析**：commit log 中的安全机制相关 commit 以 message_subject 含机制名（如“retguard”、“KARL”）或 file_path 含机制相关文件为筛选条件；设计文档的完整性以 OpenBSD 官方文档为准——部分安全机制的设计文档散见于 tech@ 邮件列表讨论而非独立文档【代码级证据·openbsd.duckdb openbsd-src 仓库】StackGhost 首次引入 commit 为 `da7128b1dcf0`（2002-02-20T22:28:21Z deraadt，message "frantzen's stackghost code.  wcookie is set at 0 right now, until debugger suppo..."），2004-05-23 deraadt commit `c2669961ad3e` 回顾“Three years ago, Mike Frantzen invented StackGhost”，sparc64 StackGhost 支持由 kettenis 于 2005-03-29 commit `62d8eb4962d0` 引入；RETGUARD 首次引入 commit 为 `e688c2b0648a`（2018-06-06T00:14:29Z mortimer，message "Add RETGUARD to clang for amd64.
