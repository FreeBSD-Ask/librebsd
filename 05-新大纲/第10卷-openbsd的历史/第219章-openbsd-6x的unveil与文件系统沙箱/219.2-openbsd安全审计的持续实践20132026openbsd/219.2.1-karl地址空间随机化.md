# 219.2.1 KARL 地址空间随机化

**要点**：KARL（Kernel Address Space Layout Randomization）是 OpenBSD 5.0（2011-11 发布）引入的内核地址空间随机化机制，由 Mike Belopuhov（迈克·别洛普霍夫） 等实现；KARL 在每次系统启动时随机化内核与内核模块的加载地址，提升内核漏洞利用难度；OpenBSD 是 BSD 世界中最早实现完整 KARL 的项目

**史料**：OpenBSD 5.0 Release Notes KARL 部分（<https://www.openbsd.org/50.html>）；Belopuhov 在 tech@ 关于 KARL 的讨论（<https://marc.info/?laccopenbsd-tech>）；openbsd.duckdb openbsd-src 仓库 KARL 相关 commit ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］〔L1 代码/构建产物/L2 即时通讯记录/L3 官方文档与公告〕

**史观**：密码学：KARL 是 OpenBSD 对安全机制的持续探索——通过随机化对抗代码重用攻击，将地址随机化从用户态（ASLR）扩展至内核态（KARL）

**辨析**：KARL 的引入版本以 OpenBSD 5.0 Release Notes 为准——部分资料称 5.0，部分称更早；KARL 与 Linux KASLR 的关系以各自设计文档为准——二者功能类似但实现路径不同，KARL 在每次启动时随机化，Linux KASLR 的随机化粒度与启动方式相关
