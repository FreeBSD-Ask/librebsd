# 225.11.3 里程碑事件类

### 新闻条目 1

- **新闻标题（中英）**：OpenSSH 2.1.0 随 OpenBSD 2.7 发布，引入 SSH 2 协议支持（OpenSSH 2.1.0 shipped with OpenBSD 2.7, with SSH 2 protocol support）
- **新闻来源**：OpenSSH 官方项目历史 + 2000-06-15 + URL: <https://www.openssh.com/history.html>
- **新闻摘要**：OpenSSH 项目历史官方叙述：OpenBSD 2.6 发布后，Markus Friedl 着手 SSH 2 协议支持，数月努力后将 OpenSSH 改造为单一软件同时支持 SSH 1 与 SSH 2 协议。OpenSSH 2.1.0 于 2000-06 随 OpenBSD 2.7（2000-06-15 发布）发布（OpenSSH 官方历史页将该版本叙述为 “OpenSSH 2.0”，OpenBSD 2.7 发行说明所列为 OpenSSH 2.1；portable 版本序列 1.2.x 之后为 2.1.0，从无 2.0 版本号）。Niels Provos 与 Theo de Raadt 进行代码审查，Bob Beck 负责更新外部 SSL 库。OpenSSH 2.1.0 是 OpenSSH 从单一协议走向多协议支持的关键节点，奠定了 OpenSSH 作为 SSH 协议完整实现的基础。
- **与本章主题的关联说明**：本章叙述 OpenSSH（1999-2026），2000-06-15 OpenSSH 2.0 引入 SSH 2 协议是本章 “OpenSSH 协议完备化” 叙事的核心节点。
- **与官方史料的交叉验证结论**：openssh.com/history.html 项目官方叙述与 OpenBSD 2.7 发行说明（<https://www.openbsd.org/27.html>）一致；OpenSSH 2.1.0 与 OpenBSD 2.7（2000-06-15）的对应关系经发行说明所列组件（OpenSSH 2.1，支持 SSH1 与 SSH2）互证。一致采纳。

### 新闻条目 2

- **新闻标题（中英）**：SFTP 服务端支持随 OpenSSH 2.3.0 发布（SFTP server-side support released in OpenSSH 2.3.0）
- **新闻来源**：OpenSSH 官方项目历史 + 2000-11 + URL: <https://www.openssh.com/history.html>
- **新闻摘要**：OpenSSH 项目历史官方叙述：SFTP 子协议的服务端支持由 Markus Friedl 编写，于 2000-11 在 OpenSSH 2.3.0 发布。随后 Damien Miller 开始 sftp 客户端的工作，于 OpenSSH 2.5.0 首次发布。同期 Niels Provos 编写 scanssh 工具（monkey.org/~provos/scanssh/）扫描 SSH 服务器版本，用于监控企业网络中部署的 SSH 服务器并统计 SSH 协议与软件版本分布。OpenSSH 2.3.0 是 OpenSSH 从远程登录工具走向完整 SSH 协议套件（含文件传输）的关键节点。
- **与本章主题的关联说明**：本章叙述 OpenSSH（1999-2026），2000-11 OpenSSH 2.3.0 引入 SFTP 服务端是本章 “OpenSSH 功能完备化” 叙事的核心节点，使 OpenSSH 成为 SSH 协议的完整实现。
- **与官方史料的交叉验证结论**：openssh.com/history.html 项目官方叙述与 OpenSSH 2.3.0 release notes（openssh.com/txt/release-2.3.0）互证；与 scanssh 工具页面互证。一致采纳。

### 新闻条目 3

- **新闻标题（中英）**：OpenSSH 6.8 Released（OpenSSH 6.8 发布）
- **新闻来源**：undeadly.org + pitrh（Peter Hessler）署名 + 2015-03-20 + URL: <https://undeadly.org/cgi?action=article;sid=20150320130957>
- **新闻摘要**：undeadly.org 2015-03-20 报道 OpenSSH 6.8 发布，将随 OpenBSD 5.7（2015-05-01）发布。OpenSSH 6.8 是一次主版本升级，含大量内部重构（refactoring）与新特性：默认指纹算法从 MD5 切换到 SHA256 并改用 base64 格式、实验性主机密钥轮换支持（UpdateHostkeys 选项）、HostbasedKeyType/HostbasedAcceptedKeyTypes/PubkeyAcceptedKeyTypes 选项、ed25519 主机认证、sshd 对已用公钥的拒识（要求 AuthenticationMethods = publickey, publickey 使用两把不同公钥）、KRL 不再需要 OpenSSL 支持、sshd_config 中 UseDNS 默认改为 no（潜在向后不兼容）。Portable OpenSSH 新增 --without-openssl 与 --without-ssh1 配置选项。OpenSSH 6.8 团队署名：Markus Friedl、Niels Provos、Theo de Raadt、Kevin Steves、Damien Miller、Darren Tucker、Jason McIntyre、Tim Rice、Ben Lindstrom。
- **与本章主题的关联说明**：本章叙述 OpenSSH（1999-2026），2015-03-20 OpenSSH 6.8 是本章 “OpenSSH 现代化” 叙事的典型节点，体现从 MD5 到 SHA256 的指纹现代化与代码库重构。
- **与官方史料的交叉验证结论**：undeadly.org 报道与 OpenSSH 6.8 release notes（openssh.com/txt/release-6.8）完全一致；与 OpenBSD 5.7（2015-05-01）changelog 中 OpenSSH 6.8 条目互证；与 Slashdot 2015-03-20 报道形成媒体反映链。一致采纳。

### 新闻条目 4

- **新闻标题（中英）**：Microsoft Announces Support for SSH（Microsoft 宣布支持 SSH）
- **新闻来源**：undeadly.org + tbert 署名 + 2015-06-03 + URL: <https://undeadly.org/cgi?action=article;sid=20150603090420>
- **新闻摘要**：undeadly.org 2015-06-03 报道 Microsoft PowerShell 团队在其 MSDN 博客（blogs.msdn.com/b/looking_forward_microsoft__support_for_secure_shell_ssh1）宣布将支持并贡献于 OpenSSH 社区。PowerShell 团队声明：“PowerShell 团队将支持并贡献于 OpenSSH 社区——非常兴奋能与 OpenSSH 社区合作交付 PowerShell 与 Windows SSH 解决方案。” 团队处于早期规划阶段，未给出确切发布日期。这是 Microsoft 从 “Linux 是癌症”（Ballmer 时代）到 “Microsoft loves Linux”（Nadella 时代）的战略转折标志之一，也是 OpenSSH 从 BSD/UNIX/Linux 走向 Windows 生态的关键里程碑。评论中 Chas 呼吁使用最强加密算法并禁用不安全组件，引用 stribika.github.io 的 secure shell 指南；Blake 提出在 CPU 受限系统上使用 arcfour256 的需求，Chas 反驳引用 RFC 7465 与 RFC 7525 要求停止使用 RC4。
- **与本章主题的关联说明**：本章叙述 OpenSSH（1999-2026），2015-06-03 Microsoft 宣布支持 OpenSSH 是本章 “OpenSSH 跨平台普及” 叙事的核心里程碑节点，标志 OpenSSH 进入 Windows 主流生态。
- **与官方史料的交叉验证结论**：undeadly.org 报道与 Microsoft PowerShell 团队 MSDN 博客原文一致；与 2018 年秋季 Windows 10 与 Windows Server 2019 正式内置 OpenSSH 形成 “承诺 → 兑现” 时序链；与 OpenBSD Foundation 2015 募捐进度（评论中提及 47.5%）形成同期 OpenBSD 生态背景。一致采纳。
