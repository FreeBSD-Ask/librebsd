### 新闻条目 1

- **新闻标题（中英）**：The OpenBSD Foundation Announces First Platinum Donor: CII（OpenBSD Foundation 宣布首位 Platinum 捐赠者：CII）
- **新闻来源**：undeadly.org + pitrh（Peter Hessler）署名 + 2015-08-04 + URL: <https://undeadly.org/cgi?action=article;sid=20150804161939> + 存档 URL: 待补；Foundation 官方声明
- **新闻摘要**：undeadly.org 2015-08-04 报道 OpenBSD Foundation 宣布 Linux Foundation 的 Core Infrastructure Initiative（CII）成为首位 Platinum 级别捐赠者。Foundation 声明：“Linux Foundation 的 Core Infrastructure Initiative 向 Foundation 提供了重大财务捐赠。这是 CII 2014 年捐赠的重复，像第一次一样，被 Foundation 用于帮助覆盖 OpenBSD、OpenSSH 与相关项目的网络连接合约。” CII 是 Linux Foundation 在 Heartbleed（CVE-2014-0160，2014-04-07）后创建的关键开源基础设施资助计划——CII 资助 OpenBSD 体现 “FOSS 大生态对 OpenBSD 关键基础设施地位的认可”。评论中 brynet 注意到 2015 募捐目标仅差 $5,000 即可达成；Albert 批评 Foundation 财务透明度——“ 2014 预算 150K，2015 增长约 30% 至 200K，为什么？让我们看 Theo 和 Bob 的会计，100% 透明度会很好 ”。多名社区成员反驳：pb 指向 Foundation 的 Activities 页面；Anonymous Coward 指向 openbsdfoundation.org/financials/ 公开财务报告；Just Another OpenBSD User 指出 “ 作为加拿大注册非营利，依法须公开资金去向 ”；Thomas 反驳 “ 代码自由可用，所谓 commit 影响指控请提供证据 ”。Noryungi 总结：“ 每次 OpenBSD Foundation 宣布新赞助者，就有小 troll 钻出来胡说八道——问责在哪里（看 Foundation 网站）、钱去哪里（啤酒、烧烤、硬件——废话）、这些人会要求妥协（问 DARPA，对他们效果很好）。”
- **与本章主题的关联说明**：本章叙述 OpenBSD Foundation（2007-2026），2015-08-04 CII 成为首位 Platinum 捐赠者是本章 “Foundation 大额捐赠里程碑” 叙事的核心节点，体现 FOSS 大生态对 OpenBSD 关键基础设施地位的认可与对 Heartbleed 后开源资助的响应。
- **与官方史料的交叉验证结论**：undeadly.org 报道与 Foundation 官方声明（openbsdfoundation.org/contributors.html）一致；与 CII 2014 年首次捐赠形成 “重复捐赠” 时序链；与 openbsdfoundation.org/financials/ 公开财务记录互证。一致采纳。
