### 新闻条目 1

- **新闻标题（中英）**：Microsoft Now OpenBSD Foundation Gold Contributor（Microsoft 成为 OpenBSD Foundation Gold 捐赠者）
- **新闻来源**：undeadly.org + tbert 署名 + 2015-07-08 + URL: <https://undeadly.org/cgi?action=article;sid=20150708134520> + 存档 URL: 待补；Foundation 官方声明：openbsdfoundation.org/contributors.html
- **新闻摘要**：undeadly.org 2015-07-08 报道 Microsoft 在 2015-06-03 宣布支持 OpenSSH 后约一个月，成为 OpenBSD Foundation 历史上首位 Gold 级别捐赠者。Foundation 声明：“Microsoft 的重大财务捐赠是对 Foundation 支持 OpenSSH 项目角色的认可。这使 Microsoft 成为 OpenBSD Foundation 2015 募捐活动中首位 Gold 级别捐赠者。” undeadly.org 编辑 tbert 评论 “看到言语之后是行动，特别是对如此关键的软件，令人鼓舞”。这一事件标志 Microsoft 与 OpenBSD 的关系从 “敌人”（Ballmer 时代 “Linux 是癌症”、Microsoft vs FOSS 长期对立）到 “合作伙伴”（Nadella 时代 “Microsoft loves Linux”、采纳 OpenSSH 并资金支持 OpenBSD）的战略转折。评论中 Josh Grosse、Raymond Côté、Rick Hanson 等表示祝贺；Chas 推测 “OpenBSD 是 Azure 网络的基础”——［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］：Azure 网络栈是否使用 OpenBSD 技术须以 Microsoft 官方技术文档进一步核实；多条评论讨论 Microsoft 战略转变的可信度与动机。
- **与本章主题的关联说明**：本章叙述 OpenBSD Foundation（2007-2026），2015-07-08 Microsoft 成为 Gold 捐赠者是本章 “Foundation 企业捐赠里程碑” 叙事的核心节点，标志 OpenBSD Foundation 获得前 “敌人” 认可与资金支持。
- **与官方史料的交叉验证结论**：undeadly.org 报道与 Foundation 官方声明（openbsdfoundation.org/contributors.html）一致；与 undeadly.org 2015-06-03 Microsoft 宣布支持 OpenSSH 报道（详见第101章条目 7）形成 “承诺 → 兑现” 时序链；与 Microsoft 后续在 Windows 10/Server 2019 内置 OpenSSH 形成 “捐赠 → 集成” 长期链。一致采纳。
