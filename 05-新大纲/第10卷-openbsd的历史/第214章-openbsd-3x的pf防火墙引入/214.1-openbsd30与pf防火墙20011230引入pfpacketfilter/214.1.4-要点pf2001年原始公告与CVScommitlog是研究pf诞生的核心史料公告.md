# 214.1.4 要点pf2001年原始公告与CVScommitlog是研究pf诞生的核心史料公告

**要点**：pf 2001 年原始公告与 CVS commit log 是研究 pf 诞生的核心史料；公告由 de Raadt 与 Hartmeier 发布至 OpenBSD 邮件列表；commit log 反映 Hartmeier 等的早期开发节奏；统计结论印证——openbsd.duckdb openbsd-src 仓库总 commit 数 245,904（统计结论 C-05），3.x 时期（2001-2004）commit 量处于 fork 后高位，反映 pf fork 与持续安全改进并行的工程节奏

**史料**：OpenBSD 3.0 pf 公告；OpenBSD CVS commit log 中 pf 相关 commit；Daniel Hartmeier 个人 pf 历史文章；openbsd.duckdb openbsd-src 仓库 commits 表（统计结论 C-05 总 commit 数 245,904，SQL `SELECT COUNT(*) FROM commits WHERE repo_name='openbsd-src'`；查询日期 2026-07-27）；openbsd.duckdb 查询 L1.1.1（经 L1.1.2 交叉验证）显示 openbsd-src 仓库 2001 年 11,084 commits（占 4 大 BSD src 合计 13.33%）、2002 年 9,758（11.14%），反映 3.x 周期开发活跃度处于 fork 后的高位（2001 年 commit 量为 1996-2002 年间第二峰值，仅次于 2001 年自身）；2003-2004 年数据存在于 L1.1.2 查询的 124 行结果中但报告仅显示前 30 行，须以数据库直接查询补全 ［A］

**史观**：0 信任原则：公告与 commit log 需考据——部分早期邮件在存档迁移中可能丢失；统计结论印证——C-05 openbsd-src 总 commit 数 245,904 反映 “分离聚合是永恒规律”（总纲第 4 条）的工程显现：pf fork 后 openbsd-src 仓库 3.x 时期 commit 量维持高位，组织分离（与 IPFilter 分离）与工程聚合（pf 与 OpenBSD 内核聚合）在 commit 量层面形成可量化的工程节奏

**辨析**：pf 1.0 的具体发布日期存在 2001.12.1 与 2001.12.3 两种说法——需对照 OpenBSD 官方公告核验；openbsd.duckdb 查询 L1.1.1 局限：openbsd-src 为 GitHub 镜像，commit 量可能滞后于 OpenBSD CVS 主仓；L1.1.1 报告仅显示 23 仓库 572 行中的前 30 行（dragonfly 仓库），openbsd-src 逐年数据经 L1.1.2 查询交叉验证获取；commit 量反映开发活跃度但不等于代码质量，须结合 commit 规模与 message 质量综合判断；**统计局限性标注**——C-05 总 commit 数 245,904 包含 1995-10 fork 后至 2026 年全部 commit，非 3.x 时期专属，跨期引用时须结合时间窗口切片；统计显著 ≠ 实际显著，commit 量高位不等于 “pf fork 工程成功”；多重比较风险——C-05 与 C-03（freebsd-src 444,203）、C-04（netbsd-src 773,683）、C-06（dragonfly-src 49,280）跨项目对比时须按 Bonferroni 校正；0 信任原则适用——openbsd-src 为 GitHub 镜像，commit 量可能滞后于 OpenBSD CVS 主仓经 [邮件列表库] 验证通过（来源：openbsd-misc 2001-05-29 “Re: Changes in IPFilter license...” 确认 IPFilter 许可证变更引发社区讨论；openbsd-misc 2001-06-04 Theo de Raadt “Re: IPFilter licence update” 确认 de Raadt 参与争议；openbsd-bugs 2001-12-05 Daniel Hartmeier “Re: pending/2220: packet filter problem” 确认 Hartmeier 主导 pf 开发；openbsd-bugs 2001-12-14 Magnus Biglert 确认 pf 随 OpenBSD 3.0 发布）。
