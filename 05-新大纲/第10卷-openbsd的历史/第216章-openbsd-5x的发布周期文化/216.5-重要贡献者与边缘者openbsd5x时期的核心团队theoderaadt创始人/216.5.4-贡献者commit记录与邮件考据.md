# 216.5.4 贡献者 commit 记录与邮件考据

**要点**：OpenBSD 5.x 时期核心贡献者的 commit 记录与邮件列表发言是研究 OpenBSD 社区生态的核心史料；openbsd.duckdb openbsd-src 仓库 contributors 表提供了贡献者首末 commit 时间与 commit 数量的代码级证据

**史料**：openbsd.duckdb openbsd-src 仓库 contributors 表与 commits 表；misc@、tech@、source-changed@ 邮件列表档案（<https://marc.info/?l=openbsd-misc>、<https://marc.info/?l=openbsd-tech>、<https://marc.info/?l=openbsd-source-changed>）；OpenBSD hackathons 报告（<https://www.openbsd.org/hackathons.html>）［A］

**史观**：0 信任原则：贡献者考据是 0 信任原则在社区史研究中的应用——commit 记录的归属须以 commit_files 表交叉验证，仅凭 commit message 中的 author 字段无法确认实际代码变更者

**辨析**：commit 记录的归属以 openbsd.duckdb openbsd-src 仓库 commits 表 author_name 与 commit_files 表 file_path 交叉验证为准——部分 patch 由多人协作但仅一人 commit，commit_files 表可定位实际代码变更者；邮件列表档案的完整性以 marc.info 存档为准

**文献**：openbsd.duckdb openbsd-src 仓库 commits、commit_files、contributors 表；OpenBSD 邮件列表档案 [EB/OL]. <https://marc.info/>；OpenBSD hackathons 记录 [EB/OL]. <https://www.openbsd.org/hackathons.html> ［A］
