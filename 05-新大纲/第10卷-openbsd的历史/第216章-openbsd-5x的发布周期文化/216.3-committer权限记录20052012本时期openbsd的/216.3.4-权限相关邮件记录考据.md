# 216.3.4 权限相关邮件记录考据

**要点**：OpenBSD misc@、tech@ 邮件列表中关于权限授予、撤销、committer 行为规范的讨论是研究权限模型的核心史料；openbsd.duckdb openbsd-src 仓库 contributors 表提供了 committer 活跃度的代码级证据

**史料**：OpenBSD misc@、tech@ 邮件列表档案（<https://marc.info/?l=openbsd-misc>、<https://marc.info/?l=openbsd-tech>）；openbsd.duckdb openbsd-src 仓库 contributors 表；OpenBSD hackathons 中权限讨论记录（<https://www.openbsd.org/hackathons.html>）［A］

**史观**：0 信任原则：权限相关邮件考据是 0 信任原则在治理史研究中的应用——邮件列表中的权限讨论须与 contributors 表的 commit 活跃度交叉验证，仅凭邮件声明无法确认 committer 的实际活跃状态

**辨析**：邮件列表档案的完整性以 marc.info 存档为准——部分权限撤销讨论可能在私有列表进行，公开档案无法覆盖全部讨论；个别权限撤销事件的具体细节以多源交叉验证为准——邮件列表、hackathons 记录、contributors 表三者交叉
