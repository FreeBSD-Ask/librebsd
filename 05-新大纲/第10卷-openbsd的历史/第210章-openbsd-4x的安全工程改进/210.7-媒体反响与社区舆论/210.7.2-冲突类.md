# 210.7.2 冲突类

### 新闻条目 1

- **新闻标题（中英）**：OpenBSD has started a massive strip-down and cleanup of OpenSSL + One week of OpenSSL cleanup + It's Official: The OpenSSL Overhaul Is A Fork: Welcome LibreSSL in OpenBSD 5.6（OpenBSD 启动 OpenSSL 大规模清理 + 一周清理工作 + 官宣 LibreSSL fork）
- **新闻来源**：undeadly.org + 编辑署名 + 2014-04-15 / 2014-04-18 / 2014-04-23 + URL: <https://undeadly.org/cgi?action=article;sid=20140415093252> + <https://undeadly.org/cgi?action=article;sid=20140418063443> + <https://undeadly.org/cgi?action=article;sid=20140423045847>- **新闻摘要**：undeadly.org 系列报道追踪 LibreSSL fork 全过程：4 月 15 日 OpenBSD 项目启动 OpenSSL 大规模清理，删除无用户死代码、修正编译警告、整理文件结构；4 月 18 日一周清理工作总结；4 月 23 日官方宣布 fork，命名为 LibreSSL，将作为 OpenBSD 5.6（2014-11）默认 TLS 库。这是 OpenBSD 项目自 OpenSSH 1999 fork 后最重大的衍生子项目。
- **与本章主题的关联说明**：本章叙述 OpenBSD 5.x 时期，LibreSSL fork 2014-04-23 官宣是本章 “OpenBSD 5.x 子项目扩展” 叙事的关键里程碑，与 OpenSSH 1999 fork 形成历史呼应。
- **与官方史料的交叉验证结论**：undeadly.org 三篇系列报道与 OpenBSD <source-changes@openbsd.org> 邮件列表 2014-04 CVS commit 一致；LibreSSL fork commit 历史可查（OpenBSD CVS 2014-04-12 起大量 OpenSSL 相关 commit）；与 Bob Beck（LibreSSL 主要开发者）BSDCan 2014 演讲内容一致。一致采纳。

### 新闻条目 2

- **新闻标题（中英）**：OpenBSD 5.6 Released（OpenBSD 5.6 发布）+ OpenBSD Passes 300,000 Commits
- **新闻来源**：undeadly.org + 编辑署名 + 2014-11-01 / 2014-10-19 + URL: <https://undeadly.org/cgi?action=article;sid=20141101181155> + <https://undeadly.org/cgi?action=article;sid=20141019130102>- **新闻摘要**：undeadly.org 报道 OpenBSD 5.6 于 2014-11-01 正式发布，首次集成 LibreSSL 作为默认 TLS 库；同时报道 OpenBSD 项目 CVS commit 总数突破 30 万大关（2014-10-19）。OpenBSD 5.6 是 LibreSSL fork 后首个正式 release，标志 LibreSSL 进入稳定维护期。
- **与本章主题的关联说明**：本章叙述 OpenBSD 5.x 时期，OpenBSD 5.6 发布（含 LibreSSL 集成）是本章 “LibreSSL fork 落地” 叙事的收官节点；30 万 commits 里程碑是本章 “OpenBSD 工程量演化” 叙事的关键数据。
- **与官方史料的交叉验证结论**：undeadly.org 报道与 OpenBSD 5.6 changelog（plus56.html）一致；LibreSSL 集成与 OpenBSD 5.6 release notes 互证；30 万 commits 与 OpenBSD source-changes@ 邮件列表自动化邮件计数一致。一致采纳。
