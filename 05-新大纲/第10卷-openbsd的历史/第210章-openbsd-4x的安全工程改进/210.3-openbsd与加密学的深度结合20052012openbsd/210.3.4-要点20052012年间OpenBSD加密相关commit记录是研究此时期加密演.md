# 210.3.4 要点20052012年间OpenBSD加密相关commit记录是研究此时期加密演

**要点**：2005-2012 年间 OpenBSD 加密相关 commit 记录是研究此时期加密演进的核心史料——softraid 加密（2007-2008 tedu@、hshoexer@、jsing@）、IPSec 改进、TLS 库更新等；openbsd.duckdb openbsd-src 仓库保留完整 CVS 历史；交叉验证须对照 Release Notes、man page 与 commit log

**史料**：openbsd.duckdb openbsd-src 仓库 2005-2012 加密相关 commit（softraid、IPSec、SSL/TLS）；OpenBSD Release Notes；OpenBSD **softraid(4)**、**ipsec(4)**、**ssl(8)** 手册页历次版本 ［A］

**史观**：总纲第 9 条——经验优先〔存疑：原挂第 25 条“0 信任原则”系伪标签，按核查报告处方重挂待终核〕：commit 记录考据须以多维度交叉筛选——softraid 加密相关 commit 须以 file_path（sys/dev/softraid*.c）与 message_subject（含 “softraid” 与 “crypto”）双重筛选，仅凭 message_subject 关键字可能遗漏跨子系统 commit

**辨析**：softraid 加密的 commit 时间线以 openbsd.duckdb 为准——2007-11-27 tedu@ 拆分加密函数，2008-06-11 hshoexer@ 移植加密代码，2008-06-14 hshoexer@ 完整启用，时间线清晰；NRL IPSec 代码的具体改动记录以 commit log 的 message_body 中提及 NRL 的 commit 为索引
