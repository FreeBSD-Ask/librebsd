# 210.4.2 与 FreeBSD/NetBSD 发布周期的比较

**要点**：FreeBSD 在 4.x 之前采用 “准备好就发布” 模式，5.x/6.x 时期改为大约 18 个月周期（4.11 至 5.0 间隔 31 个月，5.5 至 6.0 间隔 19 个月），后逐步缩短至约 2 年；NetBSD 周期更长且不规律——1.0 至 2.0 间隔 8 年（1994-2001）；OpenBSD 的 6 个月周期在 BSD 世界中独一无二——可预测性成为 OpenBSD 的标志性特征

**史料**：FreeBSD Release Notes 各版本间隔时间（<https://www.freebsd.org/releases/>）；NetBSD Release Notes 各版本间隔时间（<https://www.netbsd.org/releases/>）；OpenBSD Release Notes（<https://www.openbsd.org/plus.html>）；freebsd.duckdb tags 表 freebsd-src release/4.11.0、release/5.0.0、release/6.0.0 tagger_date ［A］

**史观**：组织结构塑造技术路径：发布周期作为组织结构塑造了不同 BSD 项目的开发节奏——FreeBSD 的 18 个月周期适配其大规模贡献者群体与复杂特性集成，NetDB 的不规律周期反映其资源限制，OpenBSD 的 6 个月周期适配其小团队与稳定性优先导向

**辨析**：FreeBSD/NetBSD 的发布周期以各自 Release Notes 与 freebsd.duckdb tags 表的 tagger_date 交叉确认——freebsd.duckdb tags 表含 freebsd-src 仓库的 release tag（如 release/9.0.0 tagger_date = 2012-01-02T18:59:55Z），可精确核查 FreeBSD release 日期；FreeBSD 周期缩短的具体时间点以 FreeBSD 9.0（2012.1）后的 release 间隔为准——9.0 至 10.0 间隔 25 个月，10.0 至 11.0 间隔 35 个月，未显著缩短

**文献**：FreeBSD Release Notes [EB/OL]. <https://www.freebsd.org/releases/>；NetBSD Release Notes [EB/OL]. <https://www.netbsd.org/releases/>；freebsd.duckdb tags 表 freebsd-src release tag ［A］
