# 221.5.3 Schwarze/Lindqvist 的文档与网络贡献

**要点**：Ingo Schwarze 是 mandoc 的核心维护者——mandoc 被 FreeBSD/NetBSD/Linux 发行版采用，是 BSD 对 man 页面文化的贡献；Anton Lindqvist 是 OpenBSD 网络栈的长期贡献者；两人的贡献让 OpenBSD 在文档与网络基础设施中保持高质量

**史料**：OpenBSD CVS commit log 中 Schwarze 的 mandoc commit、Lindqvist 的网络栈 commit（<https://cvsweb.openbsd.org/>）；misc@、tech@ 邮件列表中两人的发言 ［A］

**史观**：边缘者贡献：Schwarze 与 Lindqvist 作为非显性贡献者，长期在文档（mandoc）与网络（网络栈）基础设施中贡献——mandoc 被多个 BSD 项目采纳但 Schwarze 的名字鲜为公众所知，是 “边缘者贡献至整个生态但不被主流叙事记录” 的典型

**辨析**：Schwarze 在 mandoc 中的具体贡献边界以 **openbsd.duckdb** openbsd-src 仓库 usr.bin/mandoc/ 路径下 Schwarze 的 commit 为准——Schwarze 自 2011 年起持续维护 mandoc；Lindqvist 在网络栈中的角色以 sys/net/ 路径下 Lindqvist 的 commit 为准——Lindqvist 负责网络栈部分子系统
