# 221.5.4 要点OpenBSD7x时期核心贡献者的commit记录与邮件列表发言是研究Ope

**要点**：OpenBSD 7.x 时期核心贡献者的 commit 记录与邮件列表发言是研究 OpenBSD 社区生态的核心史料；贡献的具体内容与时间以 CVS commit log、邮件列表档案、hackathons 记录交叉验证为准

**史料**：OpenBSD CVS commit log（<https://cvsweb.openbsd.org/>）；misc@、tech@、source-changed@ 邮件列表档案（<https://marc.info/?l=openbsd-misc>，tech@ 列表见 <https://marc.info/?l=openbsd-tech>）；OpenBSD hackathons 报告 ［A］

**史观**：0 信任原则：贡献者考据是 0 信任原则在社区史研究中的实践——commit 记录的归属可能简化（部分 patch 由多人协作但仅一人 commit），邮件列表档案可能不完整，二者交叉验证方可确认贡献的实际归属

**辨析**：commit 记录的归属以 **bsd_commits.duckdb** author_name 字段为准——部分 patch 由多人协作但仅 committer 一人出现在 author_name 字段，实际贡献者可能在 commit message 的 `from` 或 `ok` 行中署名；邮件列表档案的完整性以 marc.info 存档为准

**文献**：OpenBSD CVS 仓库 [EB/OL]. <https://cvsweb.openbsd.org/>；OpenBSD 邮件列表档案 [EB/OL]. <https://marc.info/?l=openbsd-misc>；OpenBSD hackathons 记录 ［A］
