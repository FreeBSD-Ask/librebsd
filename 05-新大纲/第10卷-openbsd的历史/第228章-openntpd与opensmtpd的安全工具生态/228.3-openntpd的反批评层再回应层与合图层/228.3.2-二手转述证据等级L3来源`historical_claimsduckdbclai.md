**要点**：

- Brauer 回溯 OpenNTPD 起于 2004 年的偶然组合：他为 OpenBGPD 写的进程间消息传递框架足够通用，而当时多数机器根本不运行 NTP 客户端、开机对时了事；原定分工是他人负责时间逻辑，结果无人履约，他只能自己补齐并发现精度尚可。项目由此确立“简单到人人都会开启”的使命，客户端优先、服务端随后补上，配置解析器最终只保留 `listen on`、`server`、`servers`、`sensor` 等约五个关键字，并刻意拒绝仅极少数人需要的小众特性——此类特性后来被指为 NTP 反射攻击的漏洞温床。（BSD Now EP76，[1154.82-1348.64]，L1）
- portable 版的兴衰成为项目生命线的缩影：早期由 Darren Tucker 维护，其因时间与资源耗尽而退出（“我想这就是所谓的生活”，1431.76）后，portable 停滞在 3.9 版近五年，错过后续精度改进；Brent Cook 在 portable LibreSSL 工作中被 Theo de Raadt 催促转向，约两天便让 OpenNTPD portable 重获可用。开发模式上，原生版坚持 OpenBSD API 纯净而不为可移植性妥协，portable 版以兼容层补齐其他系统缺失的函数，portable 侧的小修复亦持续回流原生版。（BSD Now EP76，[1395.22-1583.90]，L1）
- 本期新闻核实了 FreeBSD 11-CURRENT 的 24.6 天崩溃：2014 年 12 月 10 日至 2015 年 1 月 7 日间一项 timing bug 进入 head；裸机默认 kern.hz=1000 时 tick 计数于 24.6 天后触及 32 位溢出点、机器随即失灵，虚拟机默认 hz=100 则约可支撑十倍时长。根因被锁定为 Clang 3.5 升级对整数溢出未定义行为的优化假设，而内核恰恰依赖该行为；修复是加入专用编译旗标禁止该项优化，旗标在 Clang 与 GCC 下均生效。 [存疑脚注] 溢出整数的符号性（有符号/无符号）在转写中失真，未能确认（BSD Now EP76，[144.42-186.24]，L2）
- Ian Sutton 在 GSoC 期间为 OpenBSD 编写 systemd 四个非 init 组件的兼容包装器：GNOME 3 对 hostnamed、localed、timedated、logind 存在硬依赖，包装器经由 D-Bus 提供与 systemd 相同的接口使其透明可用；项目按操作系统无关设计，FreeBSD 提交者 Baptiste Daroussin 已着手移植，logind 因涉及 PAM 与 3D 加速设备权限传递而最为复杂，其余三个组件已基本成形。（BSD Now EP71，[879.16-934.98]，L1）
- 在 ISC NTPD 连串安全补丁与 NTP 反射攻击的背景下，长期无人维护的 portable OpenNTPD 由曾参与 LibreSSL 相关工作的 Brent Cook 等志愿者接手复活，产出 16 个补丁并重新发布至 GitHub 与 FreeBSD 包仓库，修复过程中还反哺了 OpenBSD 原生版代码。（BSD Now EP71，[602.16-686.20]，L2）
- pkg（pkgng）新增对 OS X 的支持并连发新版本，MacPorts 因 FreeBSD ports 树日益依赖 pkg 而考虑移植其完整功能，未来或为 Mac 引入二进制包；pkg 由此从 BSD 生态扩展为跨平台包管理方案，同期亦出现 Linux 移植迹象。（BSD Now EP71，[1842.70-1950.34]，L2）
