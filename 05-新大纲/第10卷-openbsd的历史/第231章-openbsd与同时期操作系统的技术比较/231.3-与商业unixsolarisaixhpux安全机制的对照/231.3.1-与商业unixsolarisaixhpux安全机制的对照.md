# 231.3.1 与商业unixsolarisaixhpux安全机制的对照

**要点**：Solaris 自 8（2000）起提供 RBAC（Role-Based Access Control），Solaris 10（2005-01）引入 Trusted Extensions 与 Zones；AIX 5L（2001）提供多级安全（MLS）与 Trusted Computing Base（TCB）评估；HP-UX 11i v2（2003）提供 Security Containment 与 Common Criteria EAL4+ 评估认证；三者均通过 Common Criteria 认证（多为 EAL4+）作为企业级安全的合规背书；OpenBSD 从未申请任何 Common Criteria 认证，纯走代码审计驱动的社区安全路线——OpenBSD 主页（<https://www.openbsd.org/>）自 2000 年起持续声明 "Only two remote holes in the default install, in a heck of a long time!"

**史料**：Solaris Trusted Extensions 文档（<https://docs.oracle.com/cd/E19253-01/>）与 Solaris 10 Release Notes；AIX Security Guide（<https://www.ibm.com/docs/en/aix/>）与 TCB 评估报告；HP-UX Security Features 白皮书（<https://docs.hp.com/>）；Common Criteria 评估证书数据库（<https://www.commoncriteriaportal.org/>）；OpenBSD 主页安全声明与 Security Advisories（<https://www.openbsd.org/security.html>）〔L3 官方文档与公告/L5 二手研究〕

**史观**：总纲第 7 条——技术选择即政治选择：商业认证驱动与社区审计驱动是两种不同政治选择——前者以 “通过合规审计为采购门槛” 为预设，后者以 “代码本身可审计为可信来源” 为预设；法律结构：Common Criteria 作为政府/企业采购的结构性准入，OpenBSD 无认证即被部分采购场景先验排除

**辨析**：商业 UNIX 持有 Common Criteria 认证与 OpenBSD 无认证的实际安全水平对比缺乏权威评估——认证仅证明通过评估流程，不保证实际漏洞率更低；Common Criteria EAL4+ 评估证书在 commoncriteriaportal.org 数据库中可查 Solaris 10（认证 ID CEMC/VS-0003/2005）、AIX 7.2（认证 ID CCEVS-VR-VID10750）等具体条目；OpenBSD “无认证” 路线在政府/金融采购场景中处于合规劣势——如美国联邦政府 FISMA 合规要求通常隐含 Common Criteria 认证

**文献**：Solaris 10 Trusted Extensions 文档 [EB/OL]. <https://docs.oracle.com/cd/E19253-01/>；AIX Security Guide [EB/OL]. <https://www.ibm.com/docs/en/aix/>；HP-UX Security Features [EB/OL]. <https://docs.hp.com/>；Common Criteria 证书数据库 [EB/OL]. <https://www.commoncriteriaportal.org/>；OpenBSD 安全声明 [EB/OL]. <https://www.openbsd.org/> ［A］

**商业 UNIX 安全机制与 OpenBSD 路线对比**：

| 系统 | 关键安全机制 | 引入版本 | Common Criteria 认证 | OpenBSD 对应路线 |
| --- | --- | --- | --- | --- |
| Solaris | RBAC、Trusted Extensions、Zones | Solaris 8（2000）/10（2005-01） | EAL4+ | 无对应，OpenBSD 走 jail(8) + pledge |
| AIX | MLS、Trusted Computing Base | AIX 5L（2001） | EAL4+ | 无对应 |
| HP-UX | Security Containment | HP-UX 11i v2（2003） | EAL4+ | 无对应 |
| OpenBSD | 代码审计、pledge/unveil | 自 1995-10-18 fork | 从未申请 | 纯社区审计驱动 |
