- **新闻标题（中英）**：OPNsense 项目官方自述——fork 自 pfSense 与 m0n0wall 的防火墙发行版（About OPNsense）
- **新闻来源**：opnsense.org 项目官方 + 2014 起 + URL: <https://opnsense.org/about/about-opnsense/>
- **新闻摘要**：opnsense.org 官方 “About OPNsense” 页面自述：OPNsense 是开源、易用、易构建的基于 FreeBSD 的防火墙与路由平台。OPNsense 于 2014 年作为 pfSense 与 m0n0wall 的 fork 启动，首个正式发布于 2015 年 1 月。项目由 Deciso B.V. 创立，核心团队由 Franco Fichtner、Ad Schellevis、Jos Schellevis 三人组成。OPNsense 采用 2-clause BSD 许可证，每两周发布安全更新，每年发布两个主版本。OPNsense 虽为 FreeBSD 衍生，但其 pf 防火墙技术源自 OpenBSD，是 OpenBSD 技术外溢的典型案例。项目使命是 “使 OPNsense 成为最广泛使用的开源安全平台”。

### 新闻条目 3

- **新闻标题（中英）**：amd64 Kernel W^X——OpenBSD 安全特性向衍生发行版的技术辐射（amd64 Kernel W^X）
- **新闻来源**：undeadly.org + 2015-01-14 + URL: <https://undeadly.org/cgi?action=article;sid=20150114144142>
- **新闻摘要**：undeadly.org 2015-01-14 报道 OpenBSD amd64 架构内核 W^X（写异或执行）特性进展。W^X 是 OpenBSD 安全文化的标志性技术，2003 年起在 OpenBSD 中全面启用。这一技术随后辐射到其他 BSD 衍生项目——HardenedBSD 实现 ASLR 时参考 OpenBSD 经验，Bitrig fork 时继承 W^X，甚至 Linux 与 FreeBSD 也受到 OpenBSD W^X 实践的影响。W^X 的扩散是 OpenBSD 技术外溢的典型案例，体现 OpenBSD “通过代码审计与默认安全影响整个开源生态” 的项目特质。
- **与本章主题的关联说明**：本章叙述 OpenBSD 衍生发行版（1996-2026），W^X 技术向衍生发行版的辐射是本章 “OpenBSD 安全技术外溢” 叙事的典型节点。
- **与官方史料的交叉验证结论**：undeadly.org 报道与 OpenBSD 官方文档（openbsd.org/papers/）中 W^X 相关论文一致；与 OpenBSD 3.3（2003）changelog 中 W^X 启用条目互证；与 HardenedBSD 文档中 ASLR 实现参考 OpenBSD 的表述一致。一致采纳。
