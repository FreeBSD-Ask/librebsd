# 211.5.3 file(1)/Perl/CGI 等用户态工具漏洞群（2007-2011）

**要点**：OpenBSD 4.x 时期用户态工具漏洞集中于文件类型识别、Perl 模块与 CGI 库——CVE-2007-1536 为 **file(1)** 命令可能的堆溢出，dim 于 2007-07-09 修复（commit `8743e97b9d3dde9bd38406e812f834a27aec68a8`），技术机制类型为缓冲区溢出，无 CVSS v3 评分，**file(1)** 是 OpenBSD 基本系统中用于文件类型识别的核心工具，其堆溢出可被构造的恶意文件触发；CVE-2009-1391 为 Compress:: Zlib 的 **inflate** 函数缓冲区溢出，martynas 于 2009-06-21 修复（commit `6a153ceef817f397206a456078e5183d146144e5`）；CVE-2009-3626 为 Perl **rehash** 代码拒绝服务，jasper 于 2009-11-03 从上游 git 应用修复（commit `d886bcfeff3966f63b8fdff847d1e46374e3863f`）；CVE-2010-1168 与 CVE-2010-1447 为 Perl Safe 模块认证绕过，millert 于 2010-06-28 更新至 Safe 2.2.7（commit `20a192e8b817ef070b3475cd87733fbcf9eff42d`）；CVE-2010-0405 为 Perl 整数溢出，millert 于 2010-09-24 应用修复（commit `f92bd99370f5e67d60423f05250846abbada03bb`）；CVE-2011-1487 为 Perl **ucfirst**/**uc**/**lc** 函数未设置 UTF-8 标志的认证绕过，bluhm 于 2011-04-18 修复（commit `fcc8ea346a2fc4e9d3b36e8758942be80da07b8f`）；CVE-2011-2939 为 Perl **decode_xs** 堆缓冲区溢出，jasper 于 2011-11-01 修复（commit `945a9a587895b1b0229296859cdf38ee3657a42c`）；此外 CGI 库的 `multipart_init` HTTP 头注入漏洞由 jasper 于 2010-12-06 修复（commit `743b3e5168623dc39935178ac2be27db9c00772c`，SA42443），并于 2011-01-06 更新至 CGI 3.51（commit `4f7cdc7caf61405a40c3c35caf79b21a25503b75`）。

**史观**：边缘者贡献：Perl 模块的安全维护由 millert、jasper、bluhm 等少数开发者承担，Perl 在 OpenBSD 基本系统中的维护成本与安全风险不成比例；形式主义化：**file(1)** 堆溢出在 malloc.c 随机化下的可利用性降低体现加固机制对具体漏洞的防御价值

**辨析**：CVE-2007-1536 的 **file(1)** 堆溢出具体触发条件须对照 file 上游安全公告核验——是否需要特定文件格式；Perl Safe 模块的 CVE-2010-1168/CVE-2010-1447 认证绕过具体为 Safe 2.2.6 还是更早版本的缺陷须考据；CVE-2011-2939 的 **decode_xs** 堆溢出是否影响 OpenBSD 默认配置须核验——Perl 是否默认启用 Encode 模块
