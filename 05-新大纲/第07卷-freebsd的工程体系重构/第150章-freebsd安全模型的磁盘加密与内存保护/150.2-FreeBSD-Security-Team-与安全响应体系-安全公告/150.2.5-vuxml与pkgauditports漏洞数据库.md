# 150.2.5 VuXML 与 pkg audit：ports 漏洞数据库

**要点**：FreeBSD VuXML（Vulnerability XML）是 FreeBSD Ports Collection 的软件漏洞数据库，记录 ports 中第三方软件的已知安全漏洞；VuXML 由 Jacques Vidrine 等人于 2003 年前后建立 [存疑精确建立年份]〔DX-0482／id484〕，以 XML 格式存储在 ports 树的 **security/vuxml** 中；每个 VuXML 条目包含：受影响软件名称、版本范围、漏洞描述、CVE 编号、修复建议或修复版本；**pkg-audit(8)** 命令（以及早期的 portaudit 工具）检查已安装的软件包是否存在已知漏洞，通过对比本地安装包数据库与 VuXML 数据库实现；VuXML 是社区维护的开放数据库，任何人都可以提交漏洞条目，经过 Security Team 或 ports committer 审核后提交；VuXML 只覆盖 ports 中的第三方软件，FreeBSD 基本系统漏洞通过 FreeBSD-SA/EN 公告处理，不在 VuXML 中

**史料**：VuXML 文档 vuxml.freebsd.org；**pkg-audit(8)**（pkg audit）手册页；FreeBSD ports 树 security/vuxml/ 目录；VuXML 建立历史（Jacques Vidrine 等早期贡献者邮件列表记录）；portaudit（pkg audit 的前身）历史 ［A］

**史观**：总纲第 13 条——法律与道德是利益分配：VuXML 是开源社区协作维护安全漏洞数据库的成功案例——与 NVD（National Vulnerability Database）等官方数据库不同，VuXML 专注于 FreeBSD ports 生态，条目更新速度通常快于通用漏洞数据库，因为 ports 维护者和用户直接提交漏洞信息；这种“社区维护、快速更新”的模式与 OSVDB（已关闭）、GitHub Advisory Database 等社区漏洞数据库模式类似

**辨析**：“VuXML 由 FreeBSD Security Team 维护”——不准确，VuXML 主要由 ports 社区和安全团队共同维护，ports committer 可以直接提交 VuXML 条目；“VuXML 包含 FreeBSD 基本系统漏洞”——不包含，基本系统漏洞通过 SA/EN 公告处理；“pkg audit 自动更新 VuXML 数据库”——需要定期运行 `pkg audit -F` 或通过 periodic 任务更新，与 freebsd-update 更新基本系统不同
