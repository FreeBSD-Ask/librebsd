# 150.2.2 安全公告体系：FreeBSD-SA 与 Errata Notice

**要点**：FreeBSD 安全公告分为两类：FreeBSD Security Advisories（FreeBSD-SA-XX: YY 格式）用于高危安全漏洞，FreeBSD Errata Notices（FreeBSD-EN-XX: YY 格式）用于非安全的错误修正和低影响安全问题；FreeBSD-SA 编号体系始于 FreeBSD 项目早期（约 1990 年代末 -2000 年代初），格式为 FreeBSD-SA-年份：序号（如 FreeBSD-SA-24:04.openssl）；每个 Security Advisory 包含：漏洞描述、受影响版本、影响评估、修复建议、补丁链接、CVE 编号（如适用）、发现者致谢；Errata Notice 的区分始于 2000 年代中期，将非安全关键的勘误与高危安全公告分离，避免用户对非安全更新产生安全恐慌；安全公告使用 Security Officer PGP 密钥签名，通过 freebsd-security-notifications@、freebsd-security@、freebsd-announce@ 邮件列表发布，存档于 security.freebsd.org/advisories/；CVE 编号协调——如果报告者已申请 CVE 则使用该编号，否则由 Security Team 从 FreeBSD 的 CVE 池中分配

**史观**：总纲第 15 条——文化即形式主义：FreeBSD 安全公告体系的规范化是漏洞响应成熟度的标志——从早期的临时邮件通知到 PGP 签名的正式公告，从 SA 与 EN 不区分到分类发布，反映了开源项目安全响应的制度化过程；这一制度化与 CVE 编号体系（1999 年启动）、协调披露（coordinated disclosure）规范的普及同步演进〔映射存疑，待主理人审定〕

**辨析**：“FreeBSD-SA 编号从 1993 年项目启动时就有”说法不准确——FreeBSD 1993 年发布时项目规模小、用户少，正式的 SA 编号体系是在 1990 年代末 -2000 年代初随着用户规模增长和互联网安全威胁加剧而建立的；早期公告的编号格式和发布流程与现代不同；“所有 FreeBSD-SA 都对应 CVE 编号”——早期 SA 可能没有 CVE 编号（CVE 体系 1999 年才启动且推广需要时间），现代 SA 通常有对应 CVE 编号
