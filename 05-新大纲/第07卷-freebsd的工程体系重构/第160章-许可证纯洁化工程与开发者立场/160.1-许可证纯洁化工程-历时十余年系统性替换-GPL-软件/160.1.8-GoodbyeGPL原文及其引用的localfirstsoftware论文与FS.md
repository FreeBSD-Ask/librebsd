# 160.1.8 GoodbyeGPL原文及其引用的localfirstsoftware论文与FS

- “Goodbye GPL”原文及其引用的 local-first software 论文与 FSF 事件背景，构成 2021 年许可证论辩的一手文本；主持人另指出 BSD 许可证简化史（广告条款废除）可作许可证演化的一手对照材料。（BSD Now EP402，[100.88-105.84]，L1）
- Samuel Karp 发布 RunJ 的自述博文，含其 OCI 技术监督委员会职位、六年 Linux 容器经验与从零实现动机，属当事人一手陈述。（BSD Now EP402，[716.66-754.02]，L1）
- Xenix 老兵以亲历者身份整理的 1980-1989 发布时间线与 OEM 关系回忆（含散伙饭上由资深同事协作整理的版本谱系），属微软 Unix 史稀缺的当事人一手口述。（BSD Now EP402，[949.5-1147.78]，L1）
- Warner Losh 关于 QEMU bsd-user 分支策略（Blitz/Kaizen）与上游化路线的第一手工程日志，含 35,000 行 diff 的处置决策。（BSD Now EP402，[1254.24-1503.42]，L1）
- Rob Pike 在邮件列表中亲述 UTF-8 发明场景：“1992 年 9 月前后某晚在新泽西一家餐馆的餐垫上当场设计”，直接反驳“IBM 设计、Plan 9 实现”的流传版本，并附当时字节编码取舍的讨论线索。（BSD Now EP402，[2214.04-2268.02]，L1）
- OpenBSD RISC-V 导入的 commit 消息（Dale Rahn）与 Undeadly 站点对其上游论文（Bamsch、He、Lee、Vagela 等）的致谢说明。（BSD Now EP402，[2276.04-2331.46]，L1）
- FreeBSD 2020 年第四季度状态报告原文，含各项目联系人清单与“如何开始贡献”的指引，是一手项目文献。（BSD Now EP388，[1411.58-1425.7]，L1）
- FenestrasX 实现的 commit 消息与 Ferguson 的 Windows 10 随机数生成器白皮书，构成随机数演进的当事人一手材料。（BSD Now EP388，[704.98-711.38]，L1）
- PFBadHost 的 Undeadly 文章及其十步安装指南（专用用户、doas 权限、pf.conf 表与规则、crontab），一手部署说明。（BSD Now EP388，[1551.88-1675.94]，L1）
- Brian Kernighan 的 CMU 访谈全文转写与视频链接，当事人一手口述。（BSD Now EP388，[2774.42-2789.82]，L1）
- 该期提及的一手线索包括：deadly.org（OpenBSD Journal 前身）多年间关于 PCC 的系列帖子；BSDTalk 在纽约 BSDCon 对 Anders 的现场采访（促成 PCC 资助链条）；DCBSDCon 上 Malt 项目的演示；FreeGeek Portland 的硬件捐赠；BSDfund.org 的信用卡注册渠道及 Drew Levine 维护的 BSD 活动日历。（BSDTalk EP175，[189.0-287.4]，L1）
- 本期为 FreeBSD 开发者 Joseph Koshy 的口述访谈（bsdtalk087，2006-12-10），提供其履历一手陈述：1994 年前后开始使用 FreeBSD 并加入邮件列表；1996 年提交一枚以太网驱动补丁、由 David Greenman 提交入库，此后陆续提交 CTM 相关补丁；由 PHK（Poul-Henning Kamp）推荐 commit bit，约 1998 年成为 committer；自 1994 年起 FreeBSD 一直是其工作与桌面主力系统。libelf 属其 PMC 性能测量工具工作的底层部分。（BSDTalk EP87，[427.06-474.34]，L1）

**史观**：

- 总纲13 法律与道德是利益分配：“告别 GPL”论断的核心是把许可证还原为利益分配装置：copyleft 的道德叙事在 MongoDB、Elastic 等厂商手中显形为阻止云厂商搭便车的商业工具，许可证之争的本质由此成为软件利益结构的再分配之争。（BSD Now EP402，[403.02-432.58]，L2）
- 总纲3 不存在进步，只有权力再分配：主持人以“不可能拿到一个不含 BSD 代码的专有 SDK”反驳 GPL 阵营的道德话语，指出宽松分发实际改变了软件权力的分布；两种许可证路线的消长并非技术进步，而是分发权力结构的再平衡。（BSD Now EP402，[623.42-669.34]，L2）
- 总纲5 没有必然性，只有偶然性：UTF-8 的诞生史是偶然性改写标准的典型案例：编码方案在餐馆餐垫上于一夜成形，一周内完成全系统实现，这一无预谋的偶然设计此后支撑起整个互联网的文本层。（BSD Now EP402，[2236.8-2268.02]，L1）
- 总纲10 动手者创造历史：Warner Losh 数年维护 bsd-user、自嘲“最后的孤注一掷”式目录拷贝并以 Blitz/Kaizen 分支推进上游化，展示了动手者叙事：决定 FreeBSD 交叉构建生态存续的不是路线图，而是个别工程师对数千补丁的持续清理。（BSD Now EP402，[1254.24-1335.08]，L1）
- 总纲1 一切真历史都是古代史：Xenix 回忆与散伙饭上的时间线考据表明，微软 Unix 史的书写必须回到“古代”档案与当事人记忆中重构；当下对 Xenix 的普遍误解正源于这段历史长期无人书写。（BSD Now EP402，[919.42-1232.8]，L2）
- 总纲13 法律与道德是利益分配：去 GPL 化并非单纯技术替换，而是以许可证为边界的利益与法律风险管理：每移除一个 GPL 组件，都减少一重分发上的法律不确定性，工程动作背后是利益分配结构的调整。（BSD Now EP388，[384.26-430.42]，L2）
- 总纲9 经验优先：PF 的性能问题不是凭理论推演发现的，而是用 HWPMC 实测到最长 cache miss 事件后定位：优化方向由可复测的经验数据而非抽象基准决定。（BSD Now EP388，[762.5-789.22]，L2）
- 总纲1 一切真历史都是古代史：ping 等词源在流传中被反向炮制出 Packet Internet Groper 一类的“合理”解释，回到 1800 年代拟声词与声呐回响的古代语源才能辨伪：命名的真相藏在历史而非后设逻辑中。（BSD Now EP388，[2483.94-2525.22]，L2）
- 总纲4 分离聚合是永恒规律：FenestrasX 直接借鉴微软 Windows 10 的随机数设计并融入 FreeBSD，展示设计思想在异质系统间的分离与再聚合，而非某一方的线性“进步”。（BSD Now EP388，[617.34-664.74]，L2）
- 总纲10 动手者创造历史：季度报告的价值在“联系人与求助事项”清单：贡献路径由具体的人和待办事项组成，社区史由这些无名动手者的可认领工作而非路线图推动。（BSD Now EP388，[1413.62-1430.38]，L2）
- 总纲10 动手者创造历史：Dexter 强调 BSD 开发多为志愿劳动、同时在公司内又具职业性质，资助机制的意义在于补足预算、期限与优先项目识别的正式化灰色地带，使实际动手的开发者获得资源而非只资助机构本身。（BSDTalk EP175，[517.6-555.2]，L1）
- 总纲4 分离聚合是永恒规律：Dexter 主张一切 BSD 皆可上溯至伯克利代码发布，各项目历经分化之后仍存在可独立维护的共同代码空间，PCC 即可同时服务各 BSD 项目乃至 Linux，体现分化后重新聚合的资金与代码双向流通观。（BSDTalk EP175，[665.7-698.2]，L1）
- 总纲5 没有必然性，只有偶然性：受访者的社区轨迹系于一次偶然的正反馈：1996 年那枚以太网驱动补丁被 David Greenman 提交入库后，他自述从此入迷，持续投递补丁直至获得 commit bit。长期贡献的起点并非规划，而是一枚补丁被承认的偶然事件。（BSDTalk EP87，[437.58-448.22]，L1）

**辨析**：

- “告别 GPL”文章的作者归属在转写中存在噪声：主持人将文章与 local-first software 论文作者（Kleppmann 等）并置转述，作者身份与论文关系须以原文署名核实。[存疑脚注] 转写将 Martin Kleppmann 读作文章作者，须核对原文署名 [存疑脚注] 文章作者身份与 local-first 论文作者关系系主持人转述，转写噪声明显，须以原文署名核实（BSD Now EP402，[322.02-349.9]，L4）
- Xenix 时间线作者自称 1986 年入职时为团队最资浅者，1986 年前的 OEM 关系其本人无亲历知识，时间线系资深同事协作成果；转写未署名，人物归属待考。[考据脚注] 时间线作者姓名在转写中缺失，须回溯原文核对 [存疑脚注] Xenix 时间线作者身份未署名，1986 年前内容系二手追述（BSD Now EP402，[949.5-962.14]，L4）
- 主持人“广告条款几乎已从所有软件中消失”的说法系概括性陈述：4-Clause BSD 广告条款于 1999 年由 UC Berkeley 正式废除，但“remnants 存在与否”无法在对话中核验。（BSD Now EP402，[585.46-592.34]，L2）
- OpenBSD RISC-V 初始支持的功劳归属存在两层：commit 落于 Dale Rahn，技术基础是 Bamsch 等人的移植论文；主持人的致谢转述对两代贡献的边界较模糊，引用时宜并置。（BSD Now EP402，[2284.52-2314.22]，L2）
- 转写把 Fortuna 的作者记作 Ferguson 与 Steier，应为 Ferguson 与 Schneier；FenestrasX 亦被转写为 Nestra/Fineser/finaster 等多种形态，引用须以论文与 commit 为准。[考据脚注] 人名与实现名以 Ferguson/Schneier 论文及 FreeBSD RANDOM_FENESTRASX commit 为准 [考据脚注] Fortuna 设计者为 Ferguson 与 Schneier，FenestrasX 拼写须以 commit 为准（BSD Now EP388，[604.26-627.14]，L4）
- FIB 路由优化的作者在转写中被读作 Alexander Trenenko，FreeBSD 中以 melifaro 为用户名的路由栈维护者实为 Alexander V. Chernikov，人名归属须核实。[存疑脚注] 作者姓名转写有误，须以 src 提交记录核实 [存疑脚注] FIB lookup 框架作者姓名转写存疑，须查 src 提交记录（BSD Now EP388，[843.02-847.54]，L4）
- PFBadHost 拦截 6.2 亿地址仅为示例环境数据，非该工具的普遍效果；黑名单式拦截的可绕过性与误杀风险在文中未展开，引用时不宜作安全结论。（BSD Now EP388，[1541.52-1549.56]，L2）
- 节目称 64 位 ARM 支持“相当好”并劝读者尝试，同时指出所引 ARM wiki 页面过时：官方文档与实际支持状态的落差本身构成待考据项。（BSD Now EP388，[2044.5-2060.9]，L2）
- Malt 项目在 DCBSDCon 获良好反响，据称 Henning Brauer 曾对 jail 拥护者回应称其更优；但此后无人接手协助，开发者 Kristaps 因另一项目的政治纠葛受挫，其所在学校拟将 Malt 申报欧盟资助，Malt 能否成为 BSD Fund 项目取决于社区技术与资金双重兴趣。 [存疑脚注] Malt 的技术性质仅凭本期转写无法确证；受访者口中的 Henning Brower 拼写存疑，通行拼写为 Henning Brauer。（BSDTalk EP175，[1059.2-1113.7]，L2）
- 许可证在此不是偏好而是工程约束：受访者明言希望工具进入 base system，而纳入 base 必须采用 BSD 许可，且愈彻底愈好。他进一步提出结构性主张——若要构建 BSD 许可的工具链，须以跨 BSD 的协作项目方式完成方能惠及所有项目，并欢迎 libelf 成熟后移植到其他 BSD。个体工程动机与跨项目公共品供给在其陈述中合为一体。（BSDTalk EP87，[312.78-324.7]，L1）
