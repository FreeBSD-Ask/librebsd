# 160.1.4 史料辨析

**要点**：许可证纯洁化工程的史料主要散落在各版本 Release Notes、Quarterly Status Reports、svn commit log 和邮件列表中，缺乏单一的官方文档完整叙述整个工程。这导致外部叙述常将整个工程简化为“GCC→Clang”单一事件，忽略了 bmake、mandoc、ELF Tool Chain、BSD sort/grep/patch、lld、lldb、libc++、Unbound、dialog 替换等十余个平行项目。部分工具替换的时间线和具体贡献者记录不完整，需通过 svn commit 历史逐步追溯。

**史料**：FreeBSD SVN/Git 提交历史（r246074 BSD patch、r253689 BSD patch 默认、r334391/r336901/r337057 lld bootstrap linker for amd64/i386/armv7、dialog 移除 2024 提交）、各版本 Release Notes、Quarterly Status Reports 2010-2024。 ［A］

**史观**：总纲第 10 条——动手者创造历史：大规模工程的历史往往被简化为关键节点的“里程碑叙事”，渐进过程中无数普通开发者的修补工作被遗忘。许可证纯洁化不是某次发布会宣布的革命，而是数千个 commit 逐步积累的结果。

**辨析**：dialog 作为“最后一个 GPL 组件”移除的具体时间点在中文媒体报道中存在差异（2024 年 7 月 Linuxiac 报道、FreeBSD 16-CURRENT 开发分支），需对照 FreeBSD Git 仓库精确核实 commit hash 和日期。

**文献**：Linuxiac. FreeBSD Base System Is Now GPL-Free [EB/OL]. linuxiac.com, 2024-07-17；FreeBSD Git repository. dialog removal commit [Z]. cgit.freebsd.org/src, 2024. ［A］
