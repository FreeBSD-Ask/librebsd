# 160.1.1 历时十余年的 GPL 软件替换工程

**要点**：Clang/LLVM 迁移仅是 FreeBSD 许可证纯洁化工程（License Purification）中最大的单一项目，整个替换工程历时十余年（约 2007-2024），覆盖基本系统中几乎所有 GNU 工具：① 编译器：GCC→Clang/LLVM（2009-2014 完成 i386/amd64）；②C++ 标准库：libstdc++→libc+++libcxxrt（David Chisnall（戴维·奇斯纳尔） 主导，9.1 可选，10.0 默认）；③ 链接器：GNU **ld(1)** → **lld(1)**（FreeBSD 12 成为 amd64/i386/armv7 bootstrap linker，后续版本全架构默认）；④ 调试器：GDB→LLDB（FreeBSD 12 将旧 **gdb(1)** 移至 `/usr/libexec/gdb` 仅供 **crashinfo(8)** 使用，交互式调试推荐 **lldb(1)** 或 ports/devel/gdb）；⑤ 二进制工具：GNU binutils（**ar(1)**/**as(1)**/**ld(1)**/**objdump(1)**/**ranlib(1)**/**nm(1)**/**readelf(1)**/**size(1)**/**strings(1)**/**strip(1)**）→ELF Tool Chain 项目（BSD 许可的 **ar(1)**/**ranlib(1)**/**readelf(1)**/**objdump(1)**/**nm(1)**/**size(1)**/**strings(1)**/**strip(1)**）+ LLVM 工具链；⑥ 构建工具：GNU make→bmake（从 NetBSD 移植，10.0 默认替换 **make(1)**）；⑦ 文本处理：GNU sort→BSD sort（2012 Q1 status report 报告 BSD-licensed sort 开发中，后导入 base）、GNU grep→BSD grep（约 FreeBSD 12/13 完成替换）、GNU diff→BSD diff、GNU patch→BSD patch（r246074 2013.1.29 导入，r253689 成为默认）；⑧ 手册页排版：**groff(1)**（GPL）→ **mandoc(1)**（mdocml）——由 OpenBSD Ingo Schwarze（英戈·施瓦茨） 开发的 BSD 许可手册页编译器；⑨DNS 服务器：BIND→Unbound（10.0 移除 BIND，导入 Unbound 作为本地缓存 DNS 解析器）；⑩ 软件包管理：pkg_install（BSD 许可但架构过时）→ **pkg(7)**（10.0 默认切换，非许可证驱动但同期完成）；⑪ 其他：GNU rcs 移除、GNU texinfo 替换、GNU dialog→BSD dialog（2024 年 FreeBSD 16-CURRENT 完成替换，最后一个 GPL 组件移除）。GPL 软件替换工程组件汇总见下表。

**史料**：FreeBSD 10.0 Announcement（明确列出 bmake 替换 GNU make、BIND 移除、pkg 默认）、FreeBSD Quarterly Status Report 2012 Q1（BSD-licensed sort 条目）、FreeBSD 12.0 Release Notes（lld bootstrap linker、GDB 移至 libexec、mandoc 更新至 1.14.4、LLVM/Clang/lld/lldb 更新至 6.0.1）、Pedro Giffuni 2013.1.29 freebsd-current [CFT] WITH_BSD_PATCH 邮件（r246074 提交，含 BSD patch 跨项目谱系）、2024 年 FreeBSD 16 dialog 移除提交记录和相关新闻报道；**freebsd.duckdb** L3.6.1 查询（含 license/copyright/patent/BSD 关键词的 commit 时间分布）——查询覆盖 22 个仓库（freebsd-src、freebsd-doc、freebsd-ports、openbsd-src、openbsd-ports、openbsd-www、netbsd-src、netbsd-pkgsrc、dragonfly-src、dragonfly-dports、dragonfly-docs、openzfs-zfs、trueos-src、ghostbsd-src、hardenedbsd-src、midnightbsd-src、truenas-middleware、opnsense-core、pfsense-src、linux-kernel、illumos-gate、xnu），匹配条件为 message_subject 或 message_body 含 ‘license’、‘copyright’、‘patent’、‘BSD’ 四关键词之一（LIKE 大小写不敏感）；查询结果摘要：共 35 行年度数据，本节（147.4）关注的 2010-2021 年窗口内数据如下：2010 年 18,614 license 相关 commits/729 贡献者、2011 年 15,237/746、2012 年 17,521/744、2013 年 21,962/714、2014 年 35,494/790、2015 年 49,311/807、2016 年 53,771/789（commit 量峰值）、2017 年 45,840/769、2018 年 49,511/838、2019 年 46,194/785、2020 年 40,723/716、2021 年 43,729/931（贡献者数峰值）；**关键趋势辨析**：2014 年 license 相关 commit 量从 21,962 骤增至 35,494（增幅 61.6%），与 FreeBSD 10.0-RELEASE（2014.1.20）Clang 成为默认编译器、BIND 移除、bmake 替换 GNU make 等大规模许可证纯洁化里程碑时间点吻合；2015-2016 年 commit 量持续攀升至 53,771 峰值，反映 CDDL 许可的 ZFS/DTrace 代码集成后许可证合规审查工作的高强度期；2021 年贡献者数达 931 峰值但 commit 量（43,729）低于 2016 年峰值，反映许可证工作从集中式大规模审查转向分布式持续维护；0 信任原则局限提示：(1) 关键词匹配可能误报——‘BSD’ 一词在 commit message 中可能出现在非许可证语境（如 BSD 会议、BSDCan、BSD 操作系统名称等），导致 license 相关 commit 量被高估；(2) LIKE 默认大小写不敏感，可能漏掉全大写 ‘BSD’ 等极端大小写情况，但实际影响较小；(3) 查询覆盖 22 个仓库，本节（147.4）关注的 freebsd-src 数据须从该数据中单独提取子集，跨仓库聚合数据不能直接等同于 FreeBSD base 系统的许可证纯洁化工作量；(4) 2010-2014 年间 FreeBSD 仍处于 SVN 时代，commit hash 经 2020 年 SVN-to-Git 迁移重算，message_subject 与 message_body 内容在迁移过程中应保持不变但须以原始 SVN 存档为权威 ［A］

**史观**：专题语（不设总纲条号）——许可证纯洁化工程：FreeBSD 的许可证纯洁化工程是开源历史上规模最大的系统性 GPL 代码替换运动。这不是单一决策的结果，而是持续十余年的“逐点清除”工程，每个 GNU 工具的替换都是独立的工程项目，有各自的时间表和贡献者。整个工程的核心理念是：基本系统（base system）应完全由 BSD 或 BSD 兼容许可证（如 MIT、ISC、Apache 2.0）的代码构成，将 GPL 代码驱逐出 base 到 ports 中（用户若需要可自行安装 ports/devel/gcc 等）。

**辨析**：原文件中提到的“BSDgrep 替代 GNUgrep”和“LibreSSL 替代 OpenSSL”需精确说明：BSD grep 替换 GNU grep 确实是许可证纯洁化一部分（约 FreeBSD 13 完成），但 LibreSSL 未在 FreeBSD base 中替换 OpenSSL——FreeBSD base 仍保留 OpenSSL（OpenSSL 许可证为 Apache-style 的 OpenSSL License，非 GPL），LibreSSL 仅在 ports 中提供；OpenBSD base 中完成了 OpenSSL→LibreSSL 的替换（2014 年）。
