# 162.3.1 Linux ABI 兼容层大改进：Debian/Ubuntu 用户态支持

**要点**：FreeBSD 13.x 期间 Linux ABI（Application Binary Interface）兼容层得到重大改进：(1) 从主要支持 CentOS 用户态扩展为支持基于 Debian/Ubuntu 的 Linux 用户态环境；(2) Linux syscall 数量持续增加，接近 Linux 5.x 内核系统调用集；(3) Linux 专有软件（如 Matlab、某些游戏、Oracle 数据库等）兼容性提升；(4) linuxlator 改进支持更多 Linux 特性（epoll、cgroups v2 部分支持等）；(5) debootstrap/pacstrap 等工具可用于在 FreeBSD 上构建 Linux 用户态环境；Linux ABI 兼容层允许 FreeBSD 在不使用虚拟化的情况下直接运行 Linux 二进制程序；在 BSD 家族中，FreeBSD 的 Linux 兼容层实现最为完备且持续演进——NetBSD 亦长期维护 **compat_linux(8)** Linux 模拟层（截至 NetBSD 11.0 仍在增强 Linux 系统调用支持），OpenBSD 则已在 6.3 版本（2018）正式将 **linux(4)** Linux 兼容子系统移出内核

**史料**：**linux(4)** 手册页；FreeBSD 13.x Release Notes“Linux Emulation”章节；freebsd-emulation@ 邮件列表；linuxulator commit 历史 〔L1 代码；L2 邮件；L3 官方文档〕

**史观**：总纲第 6 条——和解优于斗争：Linux ABI 兼容层体现了 FreeBSD 的实用主义哲学——不做宗教式的“Not Invented Here”排斥，而是承认 Linux 软件生态的主导地位，提供兼容层让用户能够运行需要的软件，同时保留 FreeBSD 内核和用户态的优势

**辨析**：Linux ABI 层不是“Linux 虚拟机”——它直接在 FreeBSD 内核上运行 Linux 二进制，没有硬件虚拟化开销，但也并非 100% 兼容；某些 Linux 特定内核功能、驱动、cgroups 深度依赖的程序可能无法正常运行；支持的 Linux 发行版版本有特定范围，不是所有 Debian/Ubuntu 版本都支持

**文献**：FreeBSD Project. **linux(4)** Manual Page; FreeBSD Project. *Linux Emulation* wiki page; freebsd-emulation mailing list; NetBSD Project. **compat_linux(8)** Manual Page and NetBSD 10.0/11.0 Release Notes; OpenBSD Project. OpenBSD 6.3 changelog (linux(4) removal). ［A］
