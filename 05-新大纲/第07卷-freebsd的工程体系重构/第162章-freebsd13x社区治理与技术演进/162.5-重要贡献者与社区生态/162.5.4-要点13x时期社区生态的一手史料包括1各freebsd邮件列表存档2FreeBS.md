# 162.5.4 要点13x时期社区生态的一手史料包括1各freebsd邮件列表存档2FreeBS

**要点**：13.x 时期社区生态的一手史料包括：(1) 各 freebsd-* 邮件列表存档；(2) FreeBSD 论坛（forums.freebsd.org）讨论；(3) IRC/Discord/Slack 等实时交流渠道（但这些通常不存档或难以检索）；(4) FreeBSD 周会（weekly status reports）；(5) 会议录像和幻灯片；社区文化在 Git 迁移后缓慢演进——更开放、对新贡献者更友好，但仍保留了 FreeBSD 特有的技术高标准和直接沟通风格

**史料**：FreeBSD Mailing List Archives; FreeBSD Forums; FreeBSD Weekly Status Reports; BSD Conference YouTube 频道录像 ［B］

**史观**：边缘者贡献：邮件列表和论坛中无数帮助新人、解答问题、报告 bug 的用户是社区的基石，他们的名字不会出现在 Release Notes 中，但他们构成了 FreeBSD 社区的真实面貌

**辨析**：IRC/Discord 等实时交流内容难以作为历史史料，因为通常不存档或检索困难；邮件列表和论坛是更可靠的历史记录来源
