# 162.7.2 riscv64sf（软浮点 RISC-V）退役与 riscv64 演进

**要点**：FreeBSD 13.0 移除了 riscv64sf（64 位 RISC-V 软浮点变体）架构支持，仅保留 riscv64（hard-float）作为 Tier-2 支持；riscv64 与 riscv64sf 最初由 Ruslan Bukin、Mitchell Horne（米切尔·霍恩） 等于 FreeBSD 12.0 时期移植；riscv64sf 退役原因：(1) RISC-V 规范明确 hard-float 为标准配置，软浮点仅用于早期 FPGA 原型和模拟器；(2) 主流 RISC-V 硬件（SiFive U74、Allwinner D1、StarFive JH7110 等）均使用 hard-float；(3) 维护两个 ABI 变体成本高于收益；(4) riscv64sf 实际用户基数极小；riscv64 在 13.x 期间持续改进，但仍保持 Tier-2 地位，13.x 发布 RISC-V 虚拟机镜像但不提供 RELEASE 级别的阻塞保证

**史料**：FreeBSD 13.0 Release Notes；RISC-V ISA 规范；freebsd-riscv@ 邮件列表 Ruslan Bukin、Mitchell Horne 等的帖子 ［A］

**史观**：BSD 与 UNIX 谱系的连续性：RISC-V 是开放指令集架构的新希望，FreeBSD 是较早支持 RISC-V 的通用操作系统之一；riscv64sf 的退役不是对 RISC-V 的放弃，而是聚焦资源支持标准硬件配置

**辨析**：RISC-V 在 13.x 时期仍为 Tier-2，不应被宣传为“全面支持”——riscv64 在 13.x 适合开发者和早期采用者，生产环境使用需谨慎；riscv64 升 Tier-1 是长期目标但未在 13.x 实现

**文献**：FreeBSD Project. (2021). *13.0 Release Notes*; RISC-V International. *RISC-V ISA Specifications*. riscv.org; Bukin, R., Horne, M. (2018-2024). freebsd-riscv mailing list. ［A］
