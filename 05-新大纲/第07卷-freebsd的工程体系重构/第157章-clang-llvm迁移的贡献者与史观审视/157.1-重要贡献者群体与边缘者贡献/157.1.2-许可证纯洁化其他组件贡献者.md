# 157.1.2 许可证纯洁化其他组件贡献者

**要点**：除编译器外的许可证纯洁化子项目各有其主要贡献者：①bmake——Simon J. Gerraty 等人从 NetBSD 移植，10.0 默认替换 GNU make；②BSD grep——主要由 Gábor Kövesdán（gabor@）等人开发（基于 TRE 正则表达式库）；③BSD sort——Q1 2012 status report 报告为 Tim Kientzle 等人开发（原文件未具体记载，待进一步核）；④BSD patch——Pedro Giffuni（pfg@）移植 OpenBSD 版本，r246074（2013.1.29）导入，r253689 成为默认；⑤mandoc——Ingo Schwarze（英戈·施瓦茨）（OpenBSD）开发，FreeBSD 逐步引入作为 groff 替代；⑥ELF Tool Chain——Kai Wang、Joseph Koshy（约瑟夫·科希） 等人开发的 BSD 许可 ELF 工具；⑦lld/lldb 集成——由 Dimitry Andric、Ed Maste（埃德·马斯特） 等人维护；⑧Unbound——替代 BIND 导入 base；⑨BSD dialog——2024 年完成替换（FreeBSD 15），具体提交者待查。FreeBSD Foundation 资助了多个上述项目（Growing Filesystems Online、auditdistd、NAND 等非工具链项目也获得资助，但工具链迁移同样受益于 Foundation 资助）。

**史料**：FreeBSD 10.0 Announcement（bmake/Unbound 替换）、Pedro Giffuni 2013 WITH_BSD_PATCH 邮件（r246074）、FreeBSD Quarterly Status Report 2012 Q1（BSD-licensed sort 条目）、FreeBSD Foundation 年度报告（历年资助项目清单）。 ［B］

**史观**：总纲第 10 条——动手者创造历史：每个 GNU 工具的替换都是一个独立的小型工程项目，由 1-2 名核心开发者主导，历经数年渐进完成。这些工具替换工作在 Release Notes 中仅占一行，但背后是数百个 commit 和数千小时的测试工作。

**辨析**：BSD sort 的主要开发者在 Q1 2012 status report 中未明确署名（仅列为项目条目），需对照 SVN 历史确认具体贡献者；BSD dialog 的替换提交者和精确 commit hash 需查阅 FreeBSD Git 仓库（2024 年移除）。
