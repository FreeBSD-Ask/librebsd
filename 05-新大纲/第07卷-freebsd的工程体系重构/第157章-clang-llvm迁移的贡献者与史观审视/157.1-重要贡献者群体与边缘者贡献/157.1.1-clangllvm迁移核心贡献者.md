# 157.1.1 Clang/LLVM 迁移核心贡献者

**要点**：FreeBSD Clang/LLVM 迁移由一批核心 committer 历时多年完成，按主要贡献领域划分：①Roman Divacky（rdivacky@）——先锋探索者，2009 年 2 月首次宣布 Clang 可编译启动 i386/amd64 FreeBSD 内核，是迁移可行性的证明者；②Brooks Davis（brooks@）——项目协调人，2012 年 11 月宣布 x86 默认切换 Clang，长期参与工具链和架构支持工作；③David Chisnall（戴维·奇斯纳尔）（theraven@）——C++ 栈负责人，主导 libc++/libcxxrt 引入和 xlocale 实现，解决 C++11 支持问题；注意其姓名为 David Chisnall，非 “Theresa Chisnall”（这是对 theraven 用户名的误读）；④Dimitry Andric（dim@）——版本维护者，承担了历年 LLVM/Clang 版本导入、ports 兼容性修复和大量 bug 修正工作，是持续时间最长的日常维护者；⑤Ed Schouten（ed@）——早期贡献者，参与 2010-2012 年 Clang 导入和 world/kernel 修复；⑥Andrew Turner（andrew@）——arm64/AArch64 移植负责人，使 FreeBSD 在 ARM64 时代获得 Tier 1 地位；⑦Warner Losh（沃纳·洛什）（imp@）——GCC 4.2.1 退休执行者，推动 sparc64/mips 等旧架构的工具链切换或废弃；⑧Pawel Worach——早期测试和补丁贡献者（2012 Q1 status report 列为联系人之一）；⑨FreeBSD Foundation——资助多个工具链迁移子项目（包括 lld 默认切换、arm64 移植等）。

**史料**：FreeBSD Quarterly Status Report 2012 Q1（Clang 条目列出联系人 Brooks Davis/David Chisnall/Dimitry Andric/Ed Schouten/Pawel Worach/Roman Divacky）、Roman Divacky 2009 内核公告、Brooks Davis 2012 默认切换邮件、Andrew Turner arm64 提交记录、Warner Losh GCC 退休邮件、FreeBSD Foundation 年度报告。 ［B］

**史观**：总纲第 10 条——动手者创造历史：编译器迁移是典型的 “基础设施工程”——没有耀眼的新功能发布，没有媒体关注，只有经年累月的 bug 修复和兼容性调整。Divacky（2009 年首告内核可启动时甚至不是全职 committer）、Andric（做了最多日常版本维护和 bug 修复的无名英雄）、Worach（测试和补丁贡献者）等人的工作往往不在聚光灯下，但他们是迁移真正的基石。

**辨析**：David Chisnall 的姓名错误——原文件和多个中文资料中出现的 “Theresa Chisnall” 是对其用户名 **theraven@** 的误读（theraven → “The Raven” → 误联想为女性名字 Theresa），其 AsiaBSDCon 2014 论文作者署名明确为 David Chisnall，此错误已修正。

**文献**：FreeBSD Quarterly Status Report 2012 Q1 [R]；Chisnall D. LLVM in the FreeBSD Toolchain [C]//AsiaBSDCon 2014（作者署名 David Chisnall）；Divacky R. 2009 kernel announcement [EB/OL]；Davis B. 2012 default announcement [EB/OL].
