# 157.2.1 dialog 作为最后 GPL 组件的移除过程

**要点**：dialog 是一种基于文本的用户界面库（用于 shell 脚本中的对话框），FreeBSD base 系统长期使用的 **dialog(1)** 是 GNU dialog（GPLv2 许可）。随着其他 GPL 组件逐一被替换，dialog 成为 FreeBSD base 中最后一个 GPL 许可的软件组件。2024 年 7 月，Linuxiac 等科技媒体报道 FreeBSD 16-CURRENT 开发分支正式移除了 GNU dialog，替换为 BSD 许可的实现（可能是基于 OpenBSD 或 NetBSD 的 BSD dialog 版本，或新项目）。这标志着从 2007 年 GCC 冻结开始的许可证纯洁化工程在代码层面最终完成——FreeBSD base 系统不再包含任何 GPL 许可的代码，全部由 BSD/MIT/ISC/Apache 2.0/CDDL 等宽容许可证或 FreeBSD 可接受的弱 copyleft 许可证（CDDL 文件级 copyleft 不传染）代码构成。

**史料**：Linuxiac 2024.7.17 报道 “FreeBSD Base System Is Now GPL-Free”、FreeBSD Git 仓库 dialog 移除 commit、多个中文科技媒体（搜狐、头条等）转载报道。 ［A］

**史观**：终结与延续：dialog 移除是一个时代的终结——从 1992/1993 年 FreeBSD 创立以来，GPL 代码（GCC、gdb、binutils、groff、make、dialog、grep、sort、patch、BIND、texinfo、rcs 等）一直是 FreeBSD base 的重要组成部分（CSRG 时代 BSD 即包含 GCC 和 GNU 工具）。2024 年 GPL 代码清零标志着 FreeBSD 彻底完成了从 “BSD + GNU 工具混合” 到 “纯 BSD 许可基本系统” 的身份转变。

**辨析**：dialog 移除的精确 commit hash 和日期需查阅 FreeBSD Git 仓库确认（中文媒体报道为 2024 年 7 月，FreeBSD 16-CURRENT 分支），替换为的 BSD dialog 具体来源（是新写的还是从 OpenBSD/NetBSD 移植）也需对照 commit 确认；CDDL 许可的 DTrace/ZFS/CTF 工具仍在 base 中，但 CDDL 是文件级 copyleft 不传染 BSD 代码，经法律审查可共存，因此不算 “GPL 代码”。
