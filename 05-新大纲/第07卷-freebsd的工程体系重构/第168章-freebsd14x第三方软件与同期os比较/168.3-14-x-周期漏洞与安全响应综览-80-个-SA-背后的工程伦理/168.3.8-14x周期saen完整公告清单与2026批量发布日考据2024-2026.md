# 168.3.8 14.x 周期 SA/EN 完整公告清单与 2026 批量发布日考据（2024-2026）

**要点**：14.x 周期共发布 **80 个 FreeBSD-SA 公告** 与 **54 个 FreeBSD-EN Errata 公告**，每条均通过 <https://www.freebsd.org/security/advisories/> 与 <https://www.freebsd.org/security/notices/> 双源交叉验证；2026 年 49 条 SA 的批量发布日呈现显著的“集群式披露”模式——9 个批量发布日（2026-01-27、02-10、02-24、03-26、04-21、04-29、05-20、06-09、06-30）覆盖全部 49 条 SA，反映 Security Team 内部“audit—修复—批量披露”的节奏化工作流；2026-06-09 单日发布 12 条 SA、2026-06-30 单日发布 14 条 SA——这两个批量披露日合计 26 条 SA 占全年 49 条的 53%，反映 Security Team 在 14.x 周期尾声（14.3 EOL 与 14.4 RELEASE 前后）的集中清算；2026-06-17 修订重发 FreeBSD-SA-26:26.ktls [REVISED]——原版 2026-06-09 发布，因发现勘误于 2026-06-17 修订重发，是 14.x 周期罕见的“勘误修订”案例；2024-2026 SA 修复 commit 的 tagger_date 普遍偏差 0-1 天（Philip Paeps 位于 UTC+8 时区），2026-06-30 一批 SA 由 Mark Johnston（UTC 时区）签名，公告与 tag 同日

**史料**：FreeBSD Security Advisories 完整列表 <https://www.freebsd.org/security/advisories/>（访问 2026-07-23，从 FreeBSD-SA-08:05.openssh 至 FreeBSD-SA-26:49.iconv）；FreeBSD Errata Notices 完整列表 <https://www.freebsd.org/security/notices/>（访问 2026-07-23，从 FreeBSD-EN-04:01.twe 至 FreeBSD-EN-26:17.rpcsec_tls）；freebsd-announce 邮件列表存档 2026-June/July <https://lists.freebsd.org/archives/freebsd-announce/2026-June/date.html>、<https://lists.freebsd.org/archives/freebsd-announce/2026-July/date.html；**freebsd.duckdb>** `tags` 表 SA patch release tag tagger_date 交叉验证——例如 `release/14.2.0-p1` tagger_date = 2025-01-30T13:56:24+08:00（Philip Paeps），`release/15.0.0-p2` tagger_date = 2026-01-28T08:53:31+08:00（Philip Paeps），`release/15.1.0-p1` tagger_date = 2026-06-30T17:35:24Z（Mark Johnston） ［A］

**史观**：专题语（不设总纲条号）——披露节奏与发布节奏协调：2026 年 49 条 SA 的“集群式披露”模式反映 FreeBSD Security Team 工作流的成熟——9 个批量发布日并非随意分布，而是与 14.4 RELEASE 周期（2026-03-10）、14.3 EOL（2026-06-30）、15.1 RELEASE（2026-06-16）等关键节点关联，体现“披露节奏与发布节奏协调”的工程伦理；2026-06-09 与 2026-06-30 两个高峰披露日分别对应 15.1 RELEASE 前一周与 14.3 EOL 当日，反映 Security Team 在版本切换节点集中清算已知漏洞；SA-26:26.ktls 的修订重发反映 Security Team 对公告准确性的负责态度——发现勘误后主动修订而非掩盖

**辨析**：**早期 SA 的考据盲点**：freebsd.org/security/advisories/ 页面仅列出从 FreeBSD-SA-08:05.openssh（2008-04-17）起的公告，1993-2007 年间的早期 SA-93: *至 SA-07:* 需查询互联网档案馆 freebsd.org/security/advisories/ 历史存档或 CVS 仓库历史〔存疑：1993-2007 早期 SA 存档可得性暂无一手来源印证，待互联网档案馆存档补全〕；**FreeBSD-EN-04 之前的 Errata 公告**：freebsd.org/security/notices/ 页面最早条目为 FreeBSD-EN-04:01.twe（2004-06-28），2004 年之前的 Errata 公告未在页面列出 ［ 存疑脚注：2004 年前 EN 待互联网档案馆存档补全 ］；**SA-26:26.ktls 修订重发的辨析**：原版 2026-06-09 发布，2026-06-17 修订重发——修订原因可能是受影响版本范围、CVE 编号或补丁细节的勘误，但具体修订内容未在邮件正文捕获，需后续查询修订版公告正文确证；**SA tagger_date 偏差规律**：Philip Paeps 位于 UTC+8 时区，公告 UTC 时间与 tagger 本地时间存在 0-1 天偏差；Mark Johnston 位于 UTC 时区，公告与 tag 同日——这一时区差异不构成考据问题，但需在偏差分析中考虑；**多源交叉验证不可靠性规则应用**：freebsd.org 公告页与 freebsd-announce 邮件列表均来自 FreeBSD 项目内部（同一作者群体），存在信息茧房风险，但 freebsd.duckdb 来自 cgit.freebsd.org git 仓库镜像独立抓取，独立性较高，三源一致可采信
