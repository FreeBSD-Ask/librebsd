# 166.1.3 14.3-RELEASE（2025.6.10）：WiFi 802.11ac、OCI Docker Hub 与 LLVM 19

**要点**：FreeBSD 14.3-RELEASE 于 **2025 年 6 月 10 日** 发布，是 stable/14 分支第四个版本，Release Engineer 为 Colin Percival；核心亮点：① **iwlwifi 驱动支持 802.11ac（WiFi 5）**——这是 FreeBSD WiFi 支持的重要里程碑，现代 Intel WiFi 芯片首次在 FreeBSD 上可用 802.11ac；② OCI 容器镜像正式发布至 Docker Hub 与 GitHub Container Registry；③ Clang/LLVM 升级至 19.1.7；④ OpenSSH 升级至 9.9p2；⑤ xz 升级至 5.8.1（xz-utils 后门事件后版本，5.6.x 系列含后门，FreeBSD 13.x/14.x 中未使用受影响版本但仍跟进更新）；⑥ expat 升级至 2.7.1；14.3 支持至 2026.6.30，14.2 EOL 为 2025.9.30；xz 后门事件（CVE-2024-3094，2024.3 发现）影响的是 xz 5.6.0-5.6.1，FreeBSD 14.x 使用较旧的 xz 版本，未受该后门直接影响

**史料**：FreeBSD 14.3-RELEASE Announcement（Date: June 10, 2025）；FreeBSD 14.3-RELEASE Release Notes；CVE-2024-3094 xz 后门事件分析；**freebsd.duckdb** `tags` 表 `freebsd-src` 仓库 release tag 数据库验证——`release/14.3.0` tagger_date = 2025-06-06T00:00:00Z（UTC 时区），tagger_name = Colin Percival，target_commit_hash = `8c9ce319fef765890ce518cab85d3a470b669849`，target_commit_date = 2025-06-06T00:00:00Z，tag_type = annotated，tag_message =“Tag 14.3-RELEASE from 8c9ce319fef7”（tag_message 字段被截断），与公开公告日期 2025-06-10 相差 4 日；target_commit_date 与 tagger_date 完全一致（均为 2025-06-06T00:00:00Z），延续 14.2 起的 UTC 标准化与 commit-tag 同步模式；14.3 为 Git 时代发布版本，tagger_date 使用 UTC 标准化时区标记 ［A］

**史观**：开源运动：xz 后门事件（2024.3）是开源供应链安全的标志性事件——长达数年的恶意代码植入活动几乎成功进入多个主要 Linux 发行版，最终因微软工程师的偶然性能测试发现异常而被揭露；FreeBSD 因使用 5.4.x 或更早版本的 xz 而未受影响，但此事件引发了整个开源社区对供应链安全的重新审视，FreeBSD 在 14.x 周期内也加强了对基本系统库更新的安全审计

**辨析**：802.11ac 支持在 14.3 中限于 iwlwifi 驱动（Intel 芯片），其他驱动（如 rtw89 Realtek）的 802.11ac 支持在 14.3 时仍不完善或未合并；WiFi 6（802.11ax）支持仍处于“初始”阶段，远未达到 Linux 成熟度；xz 后门版本范围需精确说明：xz 5.6.0 和 5.6.1 包含后门，FreeBSD 14.x 在 2024.3 前使用 5.4.x 或更早版本，未受影响。**数据库验证结论**：`release/14.3.0` tagger_date = 2025-06-06T00:00:00Z 早于公开公告日期 2025-06-10 共 4 日，与 14.x 系列的偏差范围（14.0 偏差 3 日、14.1 偏差 5 日、14.2 偏差 4 日、14.4 偏差 4 日）对比，14.3 的 4 日偏差属于正常范围；0 信任原则提示：14.3 为 Git 时代原生 tag，tagger_date 与 target_commit_date 均为原生 Git 元数据，可信度高；Colin Percival 同时为 tagger 与 14.3 Release Engineer Lead，身份一致性验证通过；**target_commit_date 与 tagger_date 完全一致** 延续 14.2 起的发布工程模式（commit-tag 同步创建、均使用 UTC 标记），反映 14.2-14.4 维护版本发布工程流程已完全标准化；**tag_message 截断现象**：tag_message 字段为“Tag 14.3-RELEASE from 8c9ce319fef7”（被截断），与 14.1/14.2 的完整 commit hash 引用格式不同，可能反映 tag 创建时的自动化脚本变更或字段长度限制
