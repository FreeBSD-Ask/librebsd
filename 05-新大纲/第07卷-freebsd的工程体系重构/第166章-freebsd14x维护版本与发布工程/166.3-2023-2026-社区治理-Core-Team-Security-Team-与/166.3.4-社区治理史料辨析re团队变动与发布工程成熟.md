# 166.3.4 社区治理史料辨析：re@ 团队变动与发布工程成熟

**要点**：FreeBSD Release Engineering Team（re@）在 14.x 周期内经历了值得注意的人事变动：14.0 时 Colin Percival 任 Lead，Glen Barber（格伦·巴伯） 任 Deputy Lead；Glen Barber（gjb@，长期担任发布工程师，负责 FreeBSD 10-13 多个版本的发布工程）在 14.0 后离开 re@ 团队；Mike Karels（mike@）接任 Deputy Lead，但不幸于 2024 年 10 月逝世，14.2 献词给他；Ed Maste（emaste@）随后接任 Deputy Lead 并任职至今；14.4 时 re@ 团队进一步变动——Konstantin Belousov（康斯坦丁·别洛乌索夫）（kib@）、John Hixson、Doug Rabson（道格·拉布森）、Mahdi Mokhtari 等离开，新增 Sergio Carlavilla Delgado、Jake Freeland、Craig Leres、Vladlen Popolitov、Lexi Winter、Alexander Ziaee 等新成员；Antoine Brodin 继续负责 Package Building；Colin Percival 自 13.x 起担任 re@ Lead，是 FreeBSD 历史上任职时间较长的发布工程负责人之一，14.x 稳定的 6 个月发布节奏体现了其领导下的工程成熟度

**史料**：FreeBSD 14.0-14.4 发布公告中的 re@ 名单；Glen Barber 离职邮件；Mike Karels 逝世公告与纪念文章［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］

**史观**：总纲第 4 条——分离聚合是永恒规律：Mike Karels 的逝世是 BSD 第一代开发者群体逐渐谢幕的标志——他是 CSRG 核心成员（《The Design and Implementation of the 4.3/4.4BSD Operating System》合著者），从 1980 年代 4.xBSD 到 2020 年代 FreeBSD 14.x，持续贡献 BSD 四十年；他在生命最后阶段仍担任 Deputy Release Engineer 参与 14.2 发布工作，这种 “代码即生命” 的精神是 BSD 社区最珍贵的遗产；发布工程团队的新老交替（Glen Barber 离开、新成员加入）也体现了社区延续性——re@ 作为制度化团队，个人离开不会导致发布流程中断

**辨析**：发布工程团队成员的增加（从 14.0 约 7-8 人到 14.4 约 11 人）反映了 FreeBSD 发布工程工作量的增长——支持架构增加、云镜像/OCI 镜像/VM 镜像等多种发布格式、安全补丁频率增加，都需要更多人力；Colin Percival 同时也是 FreeBSD 历史上的 Security Officer Emeritus、FreeBSD Update（**freebsd-update(8)**）作者、知名的安全研究者（他在 2005 年发现了著名的 AES cache timing 攻击）
