# 166.3.2 Security Officer 任期与安全团队演进

**要点**：截至 2026 年 7 月，FreeBSD Security Officer 为 **Gordon Tetlow（戈登·泰特洛）**（gordon@），Deputy Security Officer 为 Ed Maste（埃德·马斯特）（emaste@）；Security Officer Emeritus（荣誉安全官）包括 Xin Li（delphij@）与 Dag-Erling Smørgrav（des@）；安全团队其他成员包括 Allan Jude（艾伦·裘德）（Core Team Liaison）、Pierre Pronchery（皮埃尔·普龙谢里）、Mark Johnston（马克·约翰斯顿）、Mariusz Zaborski、Philip Paeps（菲利普·佩普斯） 等；Security Team 负责 base 系统安全漏洞处理，发布 Security Advisory（SA）与 Errata Notice（EN）；Ports Collection 安全问题由独立的 Ports Security Team 处理；Colin Percival 曾担任 Security Officer 多年（2005-2015 左右），后转任 Release Engineering Lead，Dag-Erling Smørgrav、Xin Li、Gordon Tetlow 先后接任 Security Officer

**史料**：FreeBSD Security Team 页面；Security Officer 交接历史邮件列表公告；安全团队成员名单 ［A］

**史观**：总纲第 4 条——分离聚合是永恒规律：FreeBSD Security Team 是开源项目中历史最悠久、最受尊敬的安全响应团队之一——自 1990 年代末成立以来，它建立了成熟的漏洞响应流程、PGP 签名公告制度、负责任披露规范；Security Officer 职位的平稳交接（Colin→des→delphij→Gordon）体现了项目治理的成熟度——安全团队的领导力不依赖于个人，而是制度化的团队能力

**辨析**：Security Officer 与 Release Engineering Lead 之间的协作关系紧密——安全补丁需要在所有支持的 release/STABLE 分支及时合并，这要求 re@ 与 secteam 密切协调；Dag-Erling Smørgrav（des@）作为 FreeBSD 历史上任职时间最长的 Security Officer 之一，在任期间建立了许多延续至今的安全响应规范；Xin Li（delphij@）在任期间处理了多项重大安全事件，同时兼任 Release Engineering Team Liaison
