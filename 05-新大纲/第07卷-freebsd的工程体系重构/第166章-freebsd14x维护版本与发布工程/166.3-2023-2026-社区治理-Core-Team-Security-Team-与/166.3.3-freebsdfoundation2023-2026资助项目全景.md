# 166.3.3 FreeBSD Foundation 2023-2026 资助项目全景

**要点**：FreeBSD Foundation（FreeBSD 基金会）是 501(c)(3) 非营利组织，为 FreeBSD 项目提供资金、法律与开发资源支持；2023-2026 年基金会资助的重点项目包括但不限于：① WiFi 驱动与 LinuxKPI 层改进（改善笔记本/桌面体验，资助金额约 75 万美元的多年项目）；② 64-bit time_t Y2038 修复（Ed Maste 主导）；③ WireGuard 驱动重写（John Baldwin（约翰·鲍德温） 团队，Netgate 配合赞助）；④ pkgbase 开发与成熟；⑤ bhyve 虚拟化改进（TPM/GPU passthrough、vCPU 扩展）；⑥ **makefs(8)** ZFS 支持；⑦ boottrace 启动跟踪框架；⑧ OpenZFS 持续集成与性能优化；⑨ 安全改进（PIE/ASLR、KASAN、安全审计）；⑩ LLVM/Clang 工具链跟进与优化；基金会同时资助开发者参加 BSDCan、EuroBSDCon、vDevCon 等会议，提供法律支持（如商标、许可证问题），并协调与商业公司的合作；主要赞助商包括 Netflix、Google、Microsoft、Amazon AWS、Netgate/iXsystems、Stormshield、Beckhoff Automation、Open Sats Initiative、Ampere Computing 等

**史料**：FreeBSD Foundation 2023、2024、2025 年度报告；Foundation 资助项目页面；季度/月度状态报告；赞助商名单 ［B］

**史观**：总纲第 13 条——法律与道德是利益分配：FreeBSD Foundation 在项目生态中扮演了独特的角色——它不是 Linux Foundation 那样庞大的行业协会，也不是单一公司控制的项目（如 Redis/MongoDB），而是一个相对小型、专注的非营利组织，2020 年代年度预算约数百万美元；Foundation 的存在解决了 BSD 许可证的一个结构性问题：BSD 许可证允许公司自由使用代码而不必回馈，基金会通过自愿赞助汇聚资源，资助那些商业公司不愿单独投入但对整个生态至关重要的基础工作（如 WiFi 驱动、Y2038 修复、安全改进）

**辨析**：FreeBSD Foundation 与 Core Team 的关系需厘清：Core Team 是项目的技术治理机构，由开发者选举产生；Foundation 是独立的非营利法人，由董事会管理，向项目提供资金与资源支持但不直接干预技术决策；两者之间有 Liaison 沟通机制，但保持组织独立；这一 “技术治理与资金支持分离” 的模式是 FreeBSD 项目结构的重要特征，避免了 “谁出钱谁决定技术路线” 的问题
