# 161.3.4 要点Git迁移的一手史料包括1FreeBSD基金会20192021年关于迁移的博

**要点**：Git 迁移的一手史料包括：(1) FreeBSD 基金会 2019-2021 年关于迁移的博客文章和公告；(2) freebsd-git 邮件列表存档；(3) Ed Maste、Glen Barber 等在会议上的演讲；(4) src 仓库中 Subversion→Git 转换的 commit 记录（注意：Git 转换保留了 svn 时代的作者信息和提交时间）；迁移过程中遇到的主要技术挑战包括：svn 到 Git 的作者映射、vendor branch 转换为 Git submodule、提交签名验证、大型仓库性能优化等

**史料**：<freebsd-git@freebsd.org> 邮件列表存档；git.freebsd.org 仓库统计；FreeBSD 基金会 2020-2021 年度报告中 Git 迁移相关章节 ［A］

**史观**：总纲第 3 条——形式主义膨胀：版本控制系统迁移本质上是开发基础设施的“形式化升级”——Git 本身是更强大、更形式化的版本控制工具，它强制实施更多工作流规则，这在提高协作效率的同时也增加了形式化负担

**辨析**：svn 仓库只读镜像的寿命——FreeBSD 项目承诺长期保留 svn 镜像供历史查询，但所有新开发必须在 Git 上进行；部分旧文档和教程仍引用 svn 命令，需注意更新

**文献**：FreeBSD Project. freebsd-git Mailing List Archives; FreeBSD Foundation. (2021). *2021 Annual Report* (Git Migration chapter). ［A］
