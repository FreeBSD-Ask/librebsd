# 161.1.1 13.0 发布语境与精确日期

**要点**：FreeBSD 13.0-RELEASE 于 2021 年 4 月 13 日由发布工程团队正式公告，Glen Barber（格伦·巴伯） 担任 13.0 发布工程师，这是 stable/13 分支的首个版本；13.0 发布前 8 天（2021 年 4 月 5 日）美国最高法院就 Google LLC v. Oracle America, Inc.（593 U.S. 1, Docket No. 18-956）作出 6-2 判决，认定 Google 对 Java API 的重新实现构成 fair use，这一判决对 BSD 社区重新实现 UNIX API 的长期实践具有重大法律意义；13.0 发布时全球仍处于 COVID-19 疫情期间，FreeBSD 开发者会议已全面转为线上，BSDCan 2020-2021 连续两年取消线下会议

**史料**：FreeBSD 13.0-RELEASE 官方公告（2021-04-13，freebsd.org/releases/13.0R/announce/）；Google LLC v. Oracle America, Inc. 593 U.S. 1 (2021) 判决书；FreeBSD 13.0 发布工程团队名单；BSDCan 2021 线上举办公告；**freebsd.duckdb** `tags` 表 `freebsd-src` 仓库 release tag 数据库验证——`release/13.0.0` tagger_date = 2021-04-09T14:52:16-04:00（EDT 时区），tagger_name = Glen Barber，target_commit_hash = `ea31abc261ffc01b6ff5671bffb15cf910a07f4b`，target_commit_date = 2021-04-08T20:14:30-04:00，tag_type = annotated，tag_message =“13.0-RELEASE: tag release/13.0.0”，与公开公告日期 2021-04-13 相差 4 日（即 tag 创建后约 4 日才正式发布，符合 FreeBSD 发布工程“tag 先行、公告随后”的标准节奏）；target_commit_date 与 tagger_date 相差约 1 日，反映 tag 指向 commit 与 tag 创建之间的时差极小；13.0 为 Git 时代发布版本（2021-04-06 Git 迁移完成后首个 RELEASE），tagger_date 保留原时区标记 -04:00（EDT）；**freebsd.duckdb** L1.1.1 查询（freebsd-src 仓库年度 commit 量时间序列）——查询结果摘要：ch62 关注的 13.x 时代（2021-2022）freebsd-src 仓库年度 commit 量数据如下：2021 年 17,116 author commits/13,768 committer commits/110,661 总计、2022 年 10,719 author commits/5,055 committer commits/89,213 总计；2021 年总 commit 量 110,661 发布前开发周期）及 COVID-19 疫情后社区节奏调整相关；0 信任原则局限提示：(1) 2021 年 commit 量仍部分受 SVN-to-Git 迁移后元数据回填影响，须结合 mailing list 与 release notes 综合判断；(2) 13.x 时代为 Git 时代（2020 年 12 月迁移后），commit hash 为 Git 原生 hash，author_date 与 committer_date 均为 Git 原生元数据，可信度较 SVN 时代高；(3) L1.1.1 查询覆盖 freebsd-src 单仓库，未含 ports/doc 等其他仓库；**freebsd.duckdb** L1.4.1 查询（4 大 BSD src release tag 发布间隔天数分布）——该查询覆盖 **史观**：项目统摄史观：2021 年 4 月是 FreeBSD 历史的关键一刻——Git 迁移完成（2021-04-06）、最高法院 API 版权判决（2021-04-05）、13.0 正式发布（2021-04-13），三件大事在八天内相继发生，共同标志着 FreeBSD 从 12.x 时代向 13.x 时代的过渡

**辨析**：[双库核查：2026-08-15] 13.0-RELEASE 发布日期（2021-04-13）经邮件列表库验证通过——Message-ID 20210413185035.34DD1202D@nucleus（2021-04-13T14:50:35-04:00），发件人 Glen Barber，主题 FreeBSD 13.0-RELEASE Now Available；13.0 发布日期存在 4 月 9 日（镜像开始构建）、4 月 13 日（官方公告）两种说法，经官方公告交叉验证，正式发布日期应为 **2021 年 4 月 13 日**，4 月 9 日是发布工程团队开始构建镜像、部分镜像提前上传至镜像站的日期，非正式发布日；Git 迁移完成日期为 2021 年 4 月 6 日（ch88 详述），距 13.0 发布仅一周。**数据库验证结论**：`release/13.0.0` tagger_date = 2021-04-09T14:52:16-04:00 早于公开公告日期 2021-04-13 共 4 日，与 12.x 系列的偏差范围（12.0 偏差 4 日、12.1 偏差 0 日、12.2 偏差 16 日、12.3 偏差 5 日、12.4 偏差 0 日）对比，13.0 的 4 日偏差属于正常范围（反映 tag 创建到正式公告间的镜像构建与发布准备时间）；0 信任原则提示：13.0 为 Git 时代原生 tag（非 SVN-to-Git 迁移回填），tagger_date 与 target_commit_date 均为原生 Git 元数据，可信度高；Glen Barber 同时为 tagger 与 13.0 Release Engineer Lead，身份一致性验证通过
