# 161.1.7 2024.3.5 FreeBSD 13.3——致敬 Glen Barber、Clang 17 与 NFS in vnet jail

**要点**：FreeBSD 13.3-RELEASE 于 **2024 年 3 月 5 日** 正式发布，Colin Percival 继续担任 Release Engineer Lead，这是 stable/13 分支的第四个版本；13.3 公告专门将此版本献给长期担任 Release Engineer Lead 的 **Glen Barber**，感谢他多年对发布工程的贡献；核心特性包括：(1) LLVM 和 Clang 编译器升级到 **17.0.6**（这是 13.x 系列中一次显著的工具链升级）；(2) OpenSSH 升级到 9.6p1；(3) Sendmail 升级到 8.18.1；(4) ZFS 升级到 OpenZFS 2.1.14；(5) 原生和 LinuxKPI WiFi 驱动进行大量稳定性修复；(6) **NFS 服务器现在可以在适当配置的 vnet jail 中运行**，增强了 jail 虚拟化场景的网络服务能力；13.3 公告中的致敬为对 Glen Barber 历史贡献的回顾性致谢

**史料**：FreeBSD 13.3-RELEASE 官方公告（2024-03-05，freebsd.org/releases/13.3R/announce/）；FreeBSD 13.3 Release Notes；公告中对 Glen Barber 的致敬章节；**freebsd.duckdb** `tags` 表 `freebsd-src` 仓库 release tag 数据库验证——`release/13.3.0` tagger_date = 2024-03-04T23:09:10-08:00（PST 时区），tagger_name = Colin Percival，target_commit_hash = `80d2b634ddf0b459910b54a04bc09f5cbc7185a7`，target_commit_date = 2024-03-01T11:00:16-08:00，tag_type = annotated，tag_message ="Tag 13.3-RELEASE from 80d2b634ddf0b459910b54a04bc09f5cbc7185a7"，与公开公告日期 2024-03-05 相差仅 1 日（与 13.2 并列 13.x 系列偏差最小）；target_commit_date 与 tagger_date 相差约 3 日，反映 tag 指向 commit 与 tag 创建之间的时差；13.3 为 Git 时代发布版本，tagger_date 保留原时区标记 -08:00（PST，Colin Percival 所在西海岸时区） ［A］

**史观**：社区治理：Glen Barber 在 13.x 时期完成 Release Engineer Lead 交接是 FreeBSD 发布工程团队新老交替的标志——他担任 Release Engineer Lead 多年，负责了从 10.x 到 13.1 的多个重要版本，其贡献对 FreeBSD 发布流程的规范化至关重要；开源项目的可持续性体现在有能力完成新老领导者的平稳交接

**辨析**：LLVM/Clang 从 13.0 的 11.0.1 升级到 13.3 的 17.0.6 是稳定分支中的一次大跨度工具链更新——这在 FreeBSD 稳定分支中并不常见，反映了 LLVM 项目快速迭代的现实以及 FreeBSD 对工具链安全修复和性能改进的需求；Sendmail 版本更新是 base 系统邮件传输代理的常规维护更新，**dma(8)** 仍未成为默认（默认仍为 sendmail）。**数据库验证结论**：`release/13.3.0` tagger_date = 2024-03-04T23:09:10-08:00 早于公开公告日期 2024-03-05 仅 1 日，与 13.2 并列 13.x 系列偏差最小（13.0 偏差 4 日、13.1 偏差 4 日、13.2 偏差 1 日、13.4 偏差 4 日）；0 信任原则提示：13.3 为 Git 时代原生 tag，tagger_date 与 target_commit_date 均为原生 Git 元数据，可信度高；**关键史实修正**：原大纲称“Glen Barber 在 13.3 后卸任 Release Engineering Lead，由 Colin Percival 接任”——经数据库验证，`release/13.2.0`（2023-04-10）的 tagger 已为 Colin Percival，**Colin Percival 实际从 13.2 起就接任 Release Engineer Lead**，而非原大纲所述的 13.3 后；13.3 公告中对 Glen Barber 的致敬应为对其历史贡献的回顾性致谢，而非卸任时的即时致敬；**Glen Barber 担任 Release Engineer Lead 的最后版本为 13.1**（2022-05-12），其卸任与 Colin Percival 接任发生在 13.1→13.2 之间（约 2022 年 5 月至 2023 年 4 月之间）
