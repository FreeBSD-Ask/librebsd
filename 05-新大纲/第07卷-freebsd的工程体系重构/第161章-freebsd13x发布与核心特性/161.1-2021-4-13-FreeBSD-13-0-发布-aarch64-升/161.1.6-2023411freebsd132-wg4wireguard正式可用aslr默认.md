# 161.1.6 2023.4.11 FreeBSD 13.2——**wg(4)** WireGuard 正式可用、ASLR 默认启用与 bhyve > 16 vCPU

**要点**：FreeBSD 13.2-RELEASE 于 **2023 年 4 月 11 日** 正式发布，Colin Percival 担任 13.2 Release Engineer（接替 Glen Barber），这是 stable/13 分支的第三个版本；13.2 是 13.x 系列最重要的功能更新版本，核心特性包括：(1) **** wg(4)**WireGuard 内核驱动正式可用**——这是 2020-2021 年争议后经过两年重构和审计的安全 VPN 驱动，标志着 WireGuard 事件的最终解决；(2) OpenSSH 升级到 9.3p1；(3) OpenSSL 升级到 1.1.1t；(4) ZFS 升级到 OpenZFS 2.1.9；(5) **bhyve  hypervisor 支持客户机超过 16 个 vCPU**，解除了先前的限制；(6) **ASLR（地址空间布局随机化）对 64 位可执行文件默认启用**，提升安全防护等级；(7) 引入 **** netlink(4)**** 内核网络配置协议（源自 Linux），提供更现代的网络配置接口；(8) UFS 文件系统在使用日志软更新（journaled soft updates）时支持快照；13.1 将在 13.2 发布后三个月（2023-07-31）EOL

**史料**：FreeBSD 13.2-RELEASE 官方公告（2023-04-11，freebsd.org/releases/13.2R/announce/）；FreeBSD 13.2 Release Notes“New Features”章节；**wg(4)**、**netlink(4)**、**bhyve(8)** 手册页；**freebsd.duckdb** `tags` 表 `freebsd-src` 仓库 release tag 数据库验证——`release/13.2.0` tagger_date = 2023-04-10T22:18:03-07:00（PDT 时区），tagger_name = Colin Percival，target_commit_hash = `525ecfdad597980ea4cd59238e24c8530dbcd31d`，target_commit_date = 2023-04-06T17:03:18-07:00，tag_type = annotated，tag_message ="Tag 13.2-RELEASE from 525ecfdad597980ea4cd59238e24c8530dbcd31d"，与公开公告日期 2023-04-11 相差仅 1 日（13.x 系列偏差最小，反映 13.2 发布工程节奏最为顺畅）；target_commit_date 与 tagger_date 相差约 4 日，反映 tag 指向 commit 与 tag 创建之间存在一定的延迟（4 日为 13.x 系列中 target_commit 与 tagger 时差最大者）；13.2 为 Git 时代发布版本，tagger_date 保留原时区标记 -07:00（PDT，Colin Percival 所在西海岸时区） ［A］
