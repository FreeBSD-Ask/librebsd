# 161.1.5 2022.5.16 FreeBSD 13.1——致敬 Bill Jolitz、FIDO/U2F 支持与 iwlwifi 引入

**要点**：FreeBSD 13.1-RELEASE 于 **2022 年 5 月 16 日** 由发布工程团队正式公告，Glen Barber 担任 13.1 Release Engineer（这是他最后一次担任 Release Engineer Lead）；13.1 是 stable/13 分支的第二个版本，核心特性包括：(1) OpenSSH 升级到 8.8p1，支持 FIDO/U2F 硬件认证密钥（ecdsa-sk、ed25519-sk 公钥类型）；(2) OpenSSL 升级到 1.1.1o；(3) ZFS 升级到 OpenZFS 2.1.4；(4) **ice(4)** 驱动更新到 1.34.2-k，添加固件日志和初始 DCB 支持；(5) 引入 **iwlwifi(4)** 驱动及 LinuxKPI 802.11 兼容层，补充 **iwm(4)** 以支持较新的 Intel WiFi 芯片；(6) EC2 镜像默认使用 UEFI 启动而非传统 BIOS；13.1 公告专门将此版本献给 386BSD 共同作者 **Bill Jolitz**——“We stand on the shoulders of giants”，Bill Jolitz 于 2022 年逝世；13.1 不包含 WireGuard **wg(4)** 驱动（重写工作仍在进行）

**史料**：FreeBSD 13.1-RELEASE 官方公告（2022-05-16，freebsd.org/releases/13.1R/announce/）；FreeBSD 13.1 Release Notes；13.1 公告中对 Bill Jolitz 的致敬章节；**iwlwifi(4)** 手册页；**freebsd.duckdb** `tags` 表 `freebsd-src` 仓库 release tag 数据库验证——`release/13.1.0` tagger_date = 2022-05-12T11:48:43-04:00（EDT 时区），tagger_name = Glen Barber，target_commit_hash = `fc952ac2212b121aa6eefc273f5960ec3e0a466d`，target_commit_date = 2022-05-11T19:59:24-04:00，tag_type = annotated，tag_message ="Tag 13.1-RELEASE from fc952ac2212b121aa6eefc273f5960ec3e0a466d"，与公开公告日期 2022-05-16 相差 4 日（即 tag 创建后约 4 日才正式发布，符合 FreeBSD 发布工程“tag 先行、公告随后”的标准节奏）；target_commit_date 与 tagger_date 相差约 16 小时，反映 tag 指向 commit 与 tag 创建之间的时差极小；13.1 为 Git 时代发布版本，tagger_date 保留原时区标记 -04:00（EDT） ［A］

**史观**：BSD 与 UNIX 谱系的连续性：对 Bill Jolitz 的致敬体现了 FreeBSD 社区对历史先驱的尊重——没有 386BSD 就没有 FreeBSD 1.0，当代开发者站在巨人肩膀上；FIDO/U2F 硬件认证支持是安全认证从软件密码向硬件令牌转型的体现，符合 2020 年代无密码认证趋势

**辨析**：**重要事实确认**：13.1 不包含 **wg(4)** WireGuard 驱动——原大纲或部分二手资料称“13.1 启用重构后 WireGuard”是错误的，经 13.1 官方 Release Notes 和公告交叉验证，**wg(4)** 未在 13.1 中提供；**iwlwifi(4)** 在 13.1 中是首次引入 base 系统，标志着 FreeBSD WiFi 驱动策略从“从零编写”转向“通过 LinuxKPI 移植成熟 Linux 驱动”的务实转变。**数据库验证结论**：`release/13.1.0` tagger_date = 2022-05-12T11:48:43-04:00 早于公开公告日期 2022-05-16 共 4 日，与 13.0 的 4 日偏差一致，反映 13.x 系列的发布工程节奏稳定；0 信任原则提示：13.1 为 Git 时代原生 tag，tagger_date 与 target_commit_date 均为原生 Git 元数据，可信度高；Glen Barber 同时为 tagger 与 13.1 Release Engineer Lead，身份一致性验证通过；**Glen Barber 担任 Release Engineer Lead 的最后版本应为 13.1 而非 13.2**——`release/13.2.0` 的 tagger 已切换为 Colin Percival，表明 Release Engineer Lead 交接发生在 13.1→13.2 之间
