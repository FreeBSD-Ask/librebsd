# 163.3.4 Heimdal 2022-2023 集中清理——Kerberos 安全债务的早期清算

**要点**：13.x 周期内 freebsd-src 仓库出现两次 Heimdal 漏洞集中清理事件——**2022 年 11 月 8 日** Cy Schubert 提交 `1d5a25432badea119cdcde29200f3ef41d854727`、`df7ca95146d4e3a0d7a75330f9fd4eff099849a3`、`a1e014e89282c5c9935e852d6a4ac0f4aa137df4`、`f8a825bde75cb5164a896c9234979e9c18e97361`、`d0b6550173d25689ee820c1e0a0aea36f6806098`、`ed549cb0c53f8438c52593ce811f6fcc812248e9` 共 6 个修复 commit（同步至 stable/13、releng/13.0/13.1 多分支），处理 CVE-2019-14870（each DC LDAP 拒绝服务）、CVE-2021-44758（KDC NULL 指针解引用）、CVE-2022-3437（GSSAPI 堆溢出，潜在严重）、CVE-2022-42898（PAC 中整数溢出）、CVE-2022-44640（KDC LDAP 搜索双释放）共 5 个 CVE，时间跨度从 2019 年至 2022 年——意味着 Heimdal 在 FreeBSD base 中积压了长达 3 年的未修复安全债务；**2023 年 3 月 9 日** Cy Schubert 再次提交 `08ffa93d9f0e5c03b15e6f3326d5a0056bfc4a52`、`c4c0bd4d0102feef22157491538b78c0e894b1aa`、`59c26d1a95a00418892e08341e3eae074c238680`、`5abaf0866445a61c11665fffc148ecd13a7bb9ac` 共 4 个 commit，修复 CVE-2022-4152（签名验证错误）、CVE-2022-45142（GSSAPI NTLM SPNEGO 重复消息处理）；**FreeBSD-SA-22:14.heimdal**（2022-11-15）是 13.x 周期 Heimdal 唯一对应的官方 SA，但实际 commit 跨度远超单次 SA 披露范围

**史料**：**freebsd.duckdb** `commits` 表 freebsd-src 仓库 Heimdal CVE commit 查询：`SELECT commit_hash, author_date, author_name, message_subject FROM commits WHERE repo_name='freebsd-src' AND author_date>='2022-11-01' AND author_date<='2023-04-01' AND message_subject LIKE '%heimdal%' AND message_subject LIKE '%CVE-%' ORDER BY author_date ASC`；FreeBSD-SA-22:14.heimdal PGP 签名公告（2022-11-15）；Cy Schubert Heimdal CVE 修复 commits `1d5a25432badea119cdcde29200f3ef41d854727`（2022-11-08）、`08ffa93d9f0e5c03b15e6f3326d5a0056bfc4a52`（2023-03-09）；Heimdal Project 上游 CVE 修复记录 ［A］

**史观**：总纲第 17 条——软件工程：13.x 周期 Heimdal 集中清理事件反映“贡献组件维护滞后”的开源治理通病——FreeBSD base 中包含的 Heimdal 是数年前 vendor import 的版本，上游 CVE 修复未及时回溯至 FreeBSD stable 分支；Cy Schubert 作为 Heimdal 在 FreeBSD 的主要维护者，承担了这两次集中清理工作；这种“积压-集中清理-再积压”循环在 14.x 周期 2024-02-14 再次出现（处理 CVE-2017-6594、CVE-2018-16860 等更老的跨 7 年 CVE），反映 Heimdal 在 FreeBSD 中长期处于维护滞后的结构性问题；**Heimdal vs MIT Kerberos**：FreeBSD 选择 Heimdal 而非 MIT Kerberos 是历史决策（KTH Kerberos → Heimdal），但 Heimdal 项目维护活跃度低于 MIT Kerberos，导致 CVE 修复节奏更慢

**辨析**：**需精确说明两次清理的 CVE 不重叠**：2022-11 清理的 CVE 编号（CVE-2019-14870、CVE-2021-44758、CVE-2022-3437、CVE-2022-42898、CVE-2022-44640）与 2023-03 清理的 CVE 编号（CVE-2022-4152、CVE-2022-45142）无重叠——2023-03 清理的是 2022 年下半年新发现的 CVE；与 14.x 周期 2024-02-14 清理的 CVE（CVE-2017-6594、CVE-2018-16860、CVE-2019-12098、CVE-2022-3116、CVE-2022-41916）也无重叠——14.x 周期清理的是更老的积压 CVE（2017-2018 年）；**13.x 周期 Heimdal CVE 全部无 CVSS v3 评分**，但 CVE-2022-3437（GSSAPI 堆溢出）从描述看潜在严重性较高；**SA-22:14.heimdal 与 commits 的对应关系**：SA-22:14 主要披露 2022-11 的 5 个 CVE，2023-03 的 2 个 CVE 未见对应 SA 公告，经核查确认为直接 vendor import 无单独 SA [考据脚注：经 FreeBSD-SA-22:14.heimdal 公告原文（2022-11-15）与 freebsd.org/security/advisories/ 全部 SA 列表交叉验证，2023 年无 Heimdal 相关 SA 发布，CVE-2022-4152 与 CVE-2022-45142 系通过直接 vendor import 修复。]
