# 163.2.2 Windows 11/Server 2022、macOS 11-14 与 BSD 谱系

**要点**：同期闭源/混合源操作系统：(1) **Windows 11（2021-10）** 和 **Windows Server 2022（2021-08）**：Windows Server 2022 改进了容器、安全、存储功能，但与 FreeBSD 技术关联较小；WSL2（Windows Subsystem for Linux）在 Windows 11 中成熟，但微软官方未支持 FreeBSD 作为 WSL 发行版（社区有非官方移植）；(2) **macOS 11 Big Sur（2020-11）** 至 **macOS 14 Sonoma（2023-09）**：macOS 是 BSD 谱系中商业上最成功的操作系统，基于 XNU 内核（部分代码源自 FreeBSD）；macOS 11 是 Apple Silicon（M 系列芯片）转型的开端，aarch64 架构成为 macOS 主流；macOS 与 FreeBSD 共享用户态工具、部分 POSIX API 实现，但内核架构差异显著

**史料**：Windows Server 2022 官方文档；Apple macOS 版本历史；XNU 内核源码（opensource.apple.com） ［A］

**史观**：BSD 与 UNIX 谱系的连续性：macOS 证明了 BSD 技术在消费级和专业级市场的商业成功——Apple 通过 NeXTSTEP 继承 BSD 传统，将其转化为数十亿用户使用的操作系统；这是 BSD 技术“隐藏在成功产品背后”的典型案例

**辨析**：macOS 是 BSD 谱系成员但不是“FreeBSD 变体”——XNU 内核是 Mach 和 BSD 的混合，用户态部分源自 FreeBSD 但大量组件是 Apple 专有；macOS 开源部分（XNU、部分用户态）与 FreeBSD 代码共享随着时间推移逐渐减少

**文献**：Apple Inc. *macOS Release Notes*. apple.com; Apple Inc. *XNU Source Code*. opensource.apple.com; Microsoft. *Windows Server 2022 Documentation*. microsoft.com. ［A］
