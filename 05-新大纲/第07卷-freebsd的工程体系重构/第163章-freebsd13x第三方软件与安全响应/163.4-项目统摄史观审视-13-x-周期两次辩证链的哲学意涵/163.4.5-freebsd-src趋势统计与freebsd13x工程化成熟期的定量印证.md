# 163.4.5 freebsd-src 趋势统计与 FreeBSD 13.x 工程化成熟期的定量印证

**要点**：**统计分析印证**——`freebsd.duckdb` freebsd-src 仓库 1993-2026 年 commit 月度量 Mann-Kendall 趋势检验结果为显著上升趋势（Sen's slope =+1.40/月，p < 0.001，95% CI [1.11, 1.69]）（统计结论 C-03）；Pettitt 与 BUISHAND R 双变点检验一致判定变点为 1999-08（p < 0.001，距 2020-01 SVN-to-Git 迁移 245 个月，判定非迁移伪变点）（统计结论 C-08、C-12）；ARIMA(5,0,5) 模型拟合 AIC = 107.39（统计结论 C-29），表明 freebsd-src commit 月度量可由 ARIMA 模型较好刻画；FreeBSD 13.x 系列（2021-2024）以 aarch64 升 Tier-1、Git 迁移完成（2021-04-06）、GCC 4.2.1 完全移除、WireGuard if_wg 争议、OpenZFS 合并等为特征，该时期 freebsd-src 趋势持续上升，未因 SVN-to-Git 迁移或 GCC 完全移除而中断 commit 增长趋势；变点 1999-08 距 2021-04 Git 迁移约 261 个月，进一步印证 Git 迁移未产生新的统计变点，统计结论支持 13.x 时期工程化成熟未对 freebsd-src 整体开发活跃度产生负面影响

**史料**：`freebsd.duckdb` `commits` 表 freebsd-src 仓库 commit 月度量；SQL 查询 `SELECT strftime('%Y-%m', committer_date) AS month, COUNT(*) AS commit_count FROM commits WHERE repo_name='freebsd-src' GROUP BY month ORDER BY month`；Python 脚本 `script/phase3_inferential_stats.py` Task 5-6（Mann-Kendall 趋势检验 + Pettitt/BUISHAND R 变点检验）；Python 脚本 `script/phase4_time_series.py` Task 14（ARIMA 建模）；统计结论编号 C-03、C-08、C-12、C-29；查询日期 2026-07-27 ［A］

**史观**：赓续而非断裂：freebsd-src 趋势检验显示 13.x 时期（2021-2024）SVN-to-Git 迁移与 GCC 完全移除前后 commit 量均呈上升趋势，未出现因开发基础设施迁移或工具链彻底替换导致的 “开发断裂”——统计数据印证 FreeBSD 在工程化成熟期赓续了 CSRG 未竟事业而非中断主线开发；软件工程：13.x 时期 Git 迁移完成与 GCC 移除是大型基础设施迁移的工程典范，freebsd-src 持续上升趋势为这一工程规律的统计印证；终结与延续：13.x 终结了 GCC 在 base 中的存在与 SVN 版本控制时代，开启了纯 Git 时代与新架构支持的新篇章，变点检验显示这一终结与延续未产生统计意义上的 “断裂点”

**辨析**：**统计局限性标注**——(1) 统计显著 ≠ 实际显著：Mann-Kendall 趋势检验 p < 0.001 表明 freebsd-src commit 量存在统计学显著上升趋势，但 13.x 时期 “工程化成熟” 的实际工程意义须结合 Git 迁移具体影响与 GCC 移除的具体代码量综合判断；(2) 变点归因存疑：1999-08 变点距 13.x 时期约 22 年，归因单一化风险高，变点本身与 13.x 时期工程事件无直接因果关系；(3) ARIMA 模型局限：ARIMA(5,0,5) AIC = 107.39 为 freebsd-src 整体 commit 序列拟合结果，未单独建模 13.x 时期 commit 子序列；(4) 多重比较风险：本结论与第五卷其他章节引用相同 freebsd-src 趋势统计存在多重比较风险，Bonferroni 校正后显著性可能降低；(5) Git 迁移影响：13.x 时期跨越 SVN-to-Git 迁移（2021-04），迁移后 commit 粒度可能因 Git 工作流变化而与 SVN 时代不同，趋势比较须谨慎
