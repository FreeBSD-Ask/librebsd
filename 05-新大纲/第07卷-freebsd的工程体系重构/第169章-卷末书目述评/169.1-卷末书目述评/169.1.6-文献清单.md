# 169.1.6 文献清单

> 以下保留原评注式书目的三个子节（一手史料、二手研究、工具书与参考），作为本综述的文献支撑。

### 一手史料

FreeBSD Project. FreeBSD 13.0-RELEASE Announcement [EB/OL]. (2021-04-13)[2026-07-23]. <https://www.freebsd.org/releases/13.0R/announce/>.

> FreeBSD 13.0-RELEASE 于 2021 年 4 月 13 日正式发布，arm64/AArch64 提升为 Tier 1 架构、合入 OpenZFS 2.0 代码库、为首个完全在 Git 工作流下发布的版本。13.0 是 FreeBSD 技术现代化中期阶段的首个主要版本，标志 GCC 从源码树完全移除与 Git 工作流全面启用，须与 **freebsd.duckdb** freebsd-src 仓库 **release/13.0.0** tag 交叉验证。

FreeBSD Project. FreeBSD 14.0-RELEASE Announcement [EB/OL]. (2023-11-20)[2026-07-23]. <https://www.freebsd.org/releases/14.0R/announce/>.

> FreeBSD 14.0-RELEASE 于 2023 年 11 月 20 日正式发布，登录管理器与桌面环境改进、Linuxulator 升级至 CentOS 7、bhyve 改进、首款在 AWS arm64 上正式发布的版本。14.0 是本卷时间范围的末版，标志 FreeBSD 中期现代化阶段的网络栈与虚拟化现代化成熟。

FreeBSD Project. FreeBSD Security Advisories [EB/OL]. (2014-2023)[2026-07-23]. <https://www.freebsd.org/security/advisories/>.

> FreeBSD 官方安全公告档案，覆盖 FreeBSD-SA-14:01 至 FreeBSD-SA-23:xx 等本卷所述各版本周期安全响应事件，包括 TCP SACK 漏洞（SACK 漏洞响应）等关键安全事件。公告与 **freebsd.duckdb** security fix commit 记录、NVD CVE 条目交叉验证，是本卷安全模型叙事的一手权威来源。

BSD 仓库分析数据库（**bsd_commits.db**）. 23 个 BSD 与跨项目仓库结构化 commit 元数据 SQLite 数据库（v3 扩展版）[DB/OL]. (2026-07-22)[2026-07-22]. **原材料/研究/bsd 仓库分析/bsd_commits.db**.

> 本项目自建的 BSD 仓库 commit 元数据库，是本卷量化考据的核心数字史料。Clang/LLVM 迁移 commit、GCC 完全移除 commit、TCP SACK 漏洞修复 commit、netmap/iflib 合入 commit 等关键事件均经数据库直接验证。

FreeBSD Foundation. Annual Reports 2014-2023 [R]. Boulder: FreeBSD Foundation, 2015-2024.

> 基金会年度报告，记载基金会资助项目清单、受赞助开发者名单、企业捐赠来源，是 Foundation 在 Clang/LLVM 迁移、arm64 移植等关键工程中的资助策略演化一手来源。

### 二手研究

Smørgrav D E. LLVM/Clang Migration Retrospective [EB/OL]. (2020)[2026-07-23]. <freebsd-arch@freebsd.org> mailing list archives.

> Dag-Erling Smørgrav 在 freebsd-arch 邮件列表中回顾 Clang/LLVM 迁移的个人回忆，记录 Foundation 资助、与 Apple/LLVM 社区协作、技术挑战与决策背景，是 Clang/LLVM 迁移叙事的核心一手来源。

McKusick M K, Neville-Neil G V, Watson R N M. The Design and Implementation of the FreeBSD Operating System, 2nd Edition [M]. 2nd ed. Boston: Addison-Wesley Professional, 2014. ISBN: 978-0-321-96897-5.

> FreeBSD 操作系统设计与实现第二版，覆盖 FreeBSD 10.x 之前内核架构，其中 UNIX DAC、MAC 框架、网络栈等核心子系统设计是本卷安全模型与网络栈章节的核心二手来源。

Lattner C, Adve V. LLVM: A Compilation Framework for Lifelong Program Analysis & Transformation [C]//Proceedings of the 2004 International Symposium on Code Generation and Optimization (CGO). San Jose: IEEE, 2004: 75-88.

> LLVM 原始论文，由 Chris Lattner 与 Vikram Adve 合著，奠定 LLVM 编译器框架基础，是本卷 Clang/LLVM 迁移章节的技术背景文献。

Losh W. FreeBSD Subversion to Git Migration: Why?[EB/OL]. (2020-09)[2026-07-23]. <https://bsdimp.blogspot.com/>.

> Warner Losh 系统阐述 Git 迁移原因的博客文章，回应社区常见疑问，是本卷 FreeBSD 13.0 Git 工作流启用章节的背景文献。

Watson R N M. How the FreeBSD Project Works [C]//Proceedings of AsiaBSDCon 2007. 东京：AsiaBSDCon, 2007 [2026-07-23]. <https://2007.asiabsdcon.org/papers/P08-paper.pdf>.

> Robert N. M. Watson（罗伯特·N·M·沃森） 在 AsiaBSDCon 2007 发表的 FreeBSD 项目工程治理结构论文，从 Cambridge 视角梳理 FreeBSD 安全子系统与项目治理，是本卷安全模型与社区治理章节的核心二手来源。

Stewart R. FreeBSD SCTP Implementation [C/OL]. papers.freebsd.org 2007 年论文索引。(2007)[2026-07-24]. <https://papers.freebsd.org/2007/stewart-sctp/>.

> Randall Stewart 在 papers.freebsd.org 2007 年发表的 FreeBSD SCTP 协议实现技术论文，是本卷网络栈章节的当事人技术陈述来源。

Belousov K. FreeBSD 11.x vmm [C/OL]. papers.freebsd.org 2017 年论文索引。(2017)[2026-07-24]. <https://papers.freebsd.org/2017/kib-vmm/>.

> Konstantin Belousov（康斯坦丁·别洛乌索夫） 在 papers.freebsd.org 2017 年发表的 FreeBSD 11.x vmm 内核虚拟化技术论文，是本卷 14.x 虚拟化现代化章节的背景文献。
