# 155.3.3 DPDK 与用户态高速包处理

**要点**：Intel DPDK（Data Plane Development Kit，2010 起）等用户态框架绕过内核协议栈实现线速转发，被 Linux 与部分 BSD 生态采用；FreeBSD 以 netmap 提供类似能力，二者竞争“内核旁路”高性能网络方案。

**史料**：Intel DPDK 发布文档（2010）；FreeBSD netmap 论文（2012）［B］

**史观**：总纲第 6 条——技术路线分化：DPDK 的“用户态轮询”与 netmap 的“内核映射 + 用户态”代表内核旁路的两类实现。

**辨析**：DPDK 生态更广（厂商驱动多），netmap 更轻量且与 FreeBSD 内核集成更紧；二者非互斥，可共存。

**文献**：Intel. DPDK Getting Started [Z]；Rizzo L. netmap [EB/OL]. ［B］
