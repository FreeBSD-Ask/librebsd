# 155.3.5 Windows 网络栈（Winsock / TCP/IP）

**要点**：Windows NT 网络栈基于 Winsock API 与分层服务提供者，企业特性成熟但与 UNIX 网络栈（socket/BPF）哲学不同；FreeBSD 的 Berkeley socket 是事实标准，Windows 通过兼容层（如 WSL 的 Linux socket）弥合差距。

**史料**：Microsoft Winsock/TCP-IP 文档 ［A］
    FreeBSD 社区论文：[FP-2019-013] Doubling FreeBSD request-response throughputs over TCP with PASTE（Michio Honda and Giuseppe Lettieri，2019）<https://papers.freebsd.org/2019/asiabsdcon/honda-paste/>

**史观**：技术路线分化：Berkeley socket（FreeBSD）与 Winsock（Windows）是两套网络 API 传统，WSL 的出现使 Linux/BSD socket 语义在 Windows 上可用。

**辨析**：Windows 网络栈性能与功能长期不弱，但其闭源与不同 API 传统使其与 BSD 网络生态协作需转换层。
