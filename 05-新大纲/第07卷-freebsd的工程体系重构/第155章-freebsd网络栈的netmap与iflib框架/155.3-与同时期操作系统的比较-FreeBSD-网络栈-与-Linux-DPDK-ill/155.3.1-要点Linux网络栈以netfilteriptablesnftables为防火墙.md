# 155.3.1 要点Linux网络栈以netfilteriptablesnftables为防火墙

**要点**：Linux 网络栈以 netfilter（iptables/nftables）为防火墙核心，2010 年代引入 eBPF 与 XDP（eXpress Data Path）实现内核可编程与极高吞吐；FreeBSD 的 ipfw/pf、netgraph 与 Linux netfilter 功能对应，而 eBPF/XDP 的高性能路径是 FreeBSD 当时相对薄弱的环节（FreeBSD 后来以 netmap、iflib 等填补）。

**史观**：技术路线分化：Linux 以 eBPF 通用可编程数据面、FreeBSD 以 netmap/专用框架追求高性能，是网络栈演进的两条路线。

**辨析**：eBPF 的“通用内核虚拟机”与 netmap 的“零拷贝用户态 IO”范式不同；将 XDP 等同于 netmap 会忽略架构差异。
