# 159.3.5 当今最佳寄存器分配器实现之一与各项性能数字1015倍编译加速1020%执行减速1

- “当今最佳寄存器分配器实现之一”与各项性能数字（10-15 倍编译加速、10-20% 执行减速、10 小时对 2 小时）均为当事人在自有机器上的单方陈述，未注明硬件配置与对比版本，亦无独立基准测试佐证。 [存疑脚注] 单方自评与自测数据，须以后续独立基准复核（BSDTalk EP131，[199.00-356.91]，L4）
- 转写讹误较多：Reggie 应为 Ragge（Anders Magnusson 昵称），wax port 应为 VAX port，Kanteria 应为 Caldera，NetPC 与 NetPistil 应为 NetBSD，DPL version 3 应为 GPLv3，for-close 与 three-close 应为 four-clause 与 three-clause，port loss 应为广告条款语境下的四条款表述。 [存疑脚注] 专名经上下文推断校正，无法逐词回溯录音原文（BSDTalk EP131，[36.95-529.94]，L4）
- 多处转写名物须校正后引用：公司名应作 Afilias（转写作 Affilius/affiliates），Kern Sibbald 误作 Ken Sebold，Google Summer of Code 讲者疑为 Leslie Hawthorne（误作 Ludley Hawthorne），X.Org 讲者转写 Matthew Herb 不可确证，ZFS 演讲者名不可辨；Afilias 数据规模与“无须持续调优”系当事人单方口述，无公开运维文档佐证，引用时应标注为受访者陈述。 [存疑脚注] 人名与赞助商辨识均属推断，Afilias 运维数据为单一来源（BSDTalk EP144，[756.80-788.44]，L4）
- 受访者对 CDDL 的专利条款作三层风险评估：顶层是两名贡献代码的开发者，中层是接受 CDDL 并对部分代码主张专利的厂商，底层是运行该厂商 OpenSolaris 的客户；一旦厂商起诉贡献者，贡献者有六十天通知期撤销其许可，厂商客户随即陷入危险；由此判断 CDDL 从 BSD 许可证立场并不友好，DTrace 不会进入 FreeBSD base 系统，只能作为后启用组件。 [存疑脚注] 对 CDDL 专利终止机制的六十天期限与后果系受访者口头解读，须对照 CDDL 原文条文核验（BSDTalk EP30，[1078.7-1156.1]，L1）
