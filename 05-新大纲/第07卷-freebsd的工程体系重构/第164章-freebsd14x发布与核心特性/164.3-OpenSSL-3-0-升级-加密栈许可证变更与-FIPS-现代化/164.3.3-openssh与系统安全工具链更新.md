# 164.3.3 OpenSSH 与系统安全工具链更新

**要点**：14.0 同时将 OpenSSH 更新至 **9.5p1**，重要变更包括：默认禁用 ssh-rsa SHA-1 公钥算法（SHA-1 密码学已不安全）、FIDO/U2F 硬件密钥支持（ecdsa-sk、ed25519-sk）、sshd_config 包含改进、sftp 服务器性能与安全增强；14.0 还包含多个安全加固：64 位平台默认 PIE+ASLR、Intel Alder Lake/Raptor Lake 混合架构页失效硬件 bug 修复（cde70e312c3f，FreeBSD Foundation 赞助）、libc stdio 缓冲区溢出修复（SA-23:15）、cap_net 权限修复（SA-23:16）；LLVM AddressSanitizer 可用于 amd64 内核（**kasan(9)**）

**史料**：FreeBSD 14.0 Release Notes Security Advisories 部分；OpenSSH 9.5 Release Notes；Intel Alder Lake page invalidation erratum 相关 commit；kasan(9) 手册页 ［A］

**史观**：开源运动：OpenSSH 版本的快速跟进（14.0: 9.5p1、14.1: 9.7p1、14.3: 9.9p2、14.4: 10.0p2 含后量子算法 mlkem768x25519-sha256 默认启用）反映了安全工具链在现代 OS 中的特殊地位——加密协议、SSH 版本、TLS 版本的跟进速度直接决定系统面对密码学攻击的防御能力，2020 年代后量子密码学（PQC）的快速标准化（NIST 2024 年发布首批后量子标准）推动各 OS 紧急跟进；14.4 默认启用混合后量子密钥交换是 FreeBSD 历史上首次在 SSH 中默认启用抗量子计算算法

**辨析**：OpenSSH 9.5 默认禁用 ssh-rsa 可能导致与老版本 SSH 客户端/服务器的连接问题——Release Notes 与 UPDATING 文件中有详细的兼容处理说明，用户仍可通过 HostKeyAlgorithms 配置手动启用 ssh-rsa 但不推荐；FIDO/U2F 支持需要 USB HID 设备与相应库，在 GENERIC 内核中已包含必要驱动但某些硬件可能需要额外固件
