# 164.4.3 **makefs(8)** ZFS 与安装镜像改进

**要点**：14.0 中的 **makefs(8)** 工具（来自 NetBSD 的文件系统镜像创建工具）支持创建可引导的 ZFS 镜像，这一改进使 FreeBSD 发布工程团队可以无需 root 权限构建 ZFS 格式的安装镜像、云镜像与虚拟机镜像；先前 ZFS 镜像构建需要 mdconfig 挂载与 zpool 操作，需要 root 权限且难以在容器化构建环境中运行；**makefs(8)** ZFS 支持由 Kyle Evans（kevans@）等开发，FreeBSD Foundation 赞助；14.0 安装程序（bsdinstall）的 ZFS 配置也有改进，支持更多高级 zpool 属性配置

**史料**：makefs(8) ZFS 支持 commit 系列（cgit.freebsd.org/src/ 2022-2023）；Kyle Evans makefs ZFS 演讲（BSDCan/vDevCon）；FreeBSD 14.0 Release Notes “makefs ZFS” 条目 ［A］

**史观**：软件工程：无需 root 的文件系统镜像构建是现代 CI/CD 与可重现构建（reproducible builds）的基础要求——先前需要 root 权限的构建流程不仅是安全风险，也难以在容器化、沙箱化的现代构建基础设施中运行；**makefs(8)** ZFS 支持看似不起眼的工程改进，实际上为 FreeBSD 发布工程的现代化与自动化奠定了基础

**辨析**：**makefs(8)** 最初由 NetBSD 的 Christos Zoulas（克里斯托斯·祖拉斯） 于 2000 年代初开发，FreeBSD 从 NetBSD 导入并持续扩展功能——这是 BSD 生态内代码共享的典型案例：各 BSD 项目既竞争又协作，工具链代码在不同 BSD 间自由流动；makefs ZFS 是 FreeBSD 主导开发的功能，已被回传到 NetBSD 吗？需核实 据 coscup (2019) 一手文献印证消解^doubt-resolved-526：此处事实待多源交叉验证 ］
