# 164.4.4 ZFS 演进史料辨析

**要点**：OpenZFS 2.2 的 block cloning 功能最早由 Pawel Jakub Dawidek（早期 FreeBSD ZFS 移植者）提出设计概念，后由 OpenZFS 社区（包括 FreeBSD、Linux、macOS 多方开发者）共同实现，主要提交者为 Paul Dagnelie、Rob Norris、Allan Jude（艾伦·裘德） 等；block cloning 在 FreeBSD 与 Linux 上同时可用，这是 OpenZFS 2020 年统一代码库后的优势——功能一次开发跨平台可用；FreeBSD 14.0 ZFS 引导加载程序（gptzfsboot、loader.efi）也有改进以支持 OpenZFS 2.2 的新 on-disk 格式特性，升级引导加载程序是 14.0 升级的强制步骤

**史料**：OpenZFS 2.2 block cloning PR 与 commit 历史；FreeBSD 14.0 升级说明中关于 boot loader 更新的强制要求；Allan Jude OpenZFS 2.2 发布演讲 ［A］

**史观**：许可证：CDDL 许可证使 OpenZFS 能够在 FreeBSD 内核中原生集成（BSD 与 CDDL 兼容），这是 ZFS 在 FreeBSD 上持续深入发展的法律基础；Linux 生态长期面临 CDDL-GPL 不兼容问题（参见相关章节 ZFS 部分详述）

**辨析**：ZFS pool version 与 feature flags 的关系需澄清：OpenZFS 2.0+ 不再使用传统的 zpool version 数字，而是使用 feature flags（功能标志），OpenZFS 2.2 新增了 block_cloning、blake3 等 feature flags；一旦这些 feature 被启用，pool 就不能被旧版本 OpenZFS（2.1 及之前）导入——这是 ZFS 升级的单向性：升级功能标志容易，降级困难

**文献**：Jude A. OpenZFS 2.2 Features Overview [C]. OpenZFS Developer Summit 2023; FreeBSD Project. zpool-features(7) Manual Page [EB/OL]. [2026-07-19]. <https://man.freebsd.org/zpool-features/7>.
