# 151.4.3 在线资源与社区文档

**要点**：FreeBSD 安全相关在线资源包括：FreeBSD Handbook 安全章节（docs.freebsd.org/en/books/handbook/security/）；FreeBSD Security Team 官方页面（freebsd.org/security/）；VuXML 漏洞数据库（vuxml.freebsd.org）；FreeBSD Wiki 安全相关页面；FreeBSD Foundation 博客安全相关文章（freebsdfoundation.org/blog/）；LWN.net 关于 FreeBSD 安全的报道（lwn.net）；CheriBSD 项目官方文档（cheribsd.com）；Capsicum 项目页面（capsicum-linux.org、cl.cam.ac.uk/research/security/capsicum/）；Poul-Henning Kamp（波尔-亨宁·坎普） 个人网站（phk.freebsd.dk）上的安全相关文章；Colin Percival 个人网站（daemonology.net）上的 freebsd-update 和 Security Officer 相关文章

**史料**：上述在线资源［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔内部交叉引用·无独立来源〕

**史观**：开源运动：在线资源和社区文档是开源项目历史的活档案——与传统软件项目的封闭文档不同，FreeBSD 的设计讨论、安全公告、开发日志大部分可公开访问，这是开源历史书写的独特优势；但在线资源面临链接失效问题，需利用互联网档案馆（Wayback Machine）保存历史版本

**辨析**：在线资源质量参差不齐——官方文档和核心开发者博客可信度高，第三方博客和论坛内容需交叉验证；部分旧链接可能已失效，需查询互联网档案馆获取历史存档

**文献**：FreeBSD Project. FreeBSD Handbook: Security. docs.freebsd.org; FreeBSD Project. FreeBSD Security Information. freebsd.org/security/; FreeBSD Foundation. Blog. freebsdfoundation.org/blog/; LWN.net. FreeBSD Security Coverage. lwn.net. ［B］
