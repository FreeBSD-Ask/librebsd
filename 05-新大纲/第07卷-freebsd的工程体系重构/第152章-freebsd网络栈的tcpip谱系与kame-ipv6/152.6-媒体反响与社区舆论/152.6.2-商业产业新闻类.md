# 152.6.2 商业产业新闻类

### 新闻条目 1

- **新闻标题（中英）**：Netflix 优化 FreeBSD 网络栈，使 AMD EPYC 性能翻倍（Netflix Optimized FreeBSD's Network Stack More Than Doubled AMD EPYC Performance）
- **新闻来源**：Phoronix（Michael Larabel），2019-11-04
- **URL**：**<https://www.phoronix.com/news/Netflix-NUMA-FreeBSD-Optimized>**
- **存档 URL**：**<https://web.archive.org/web/2019/https://www.phoronix.com/news/Netflix-NUMA-FreeBSD-Optimized>**
- **新闻摘要**：2019 年 11 月 Phoronix 报道 Netflix 通过优化 FreeBSD 网络栈在 NUMA 感知方面的实现，使 AMD EPYC 服务器性能提升超过一倍。Netflix 是 FreeBSD 网络栈在企业级生产环境中的主要商业用户之一 [存疑脚注] 原作“最大商业用户”缺乏量化依据（上游提交量、官方致谢口径未核），改限定表述，其优化贡献已回流到 FreeBSD 上游。
- **与本章主题的关联说明**：本章记述 FreeBSD 网络栈在现代数据中心场景的性能演进，Netflix NUMA 优化是 FreeBSD 网络栈在 2010s 末的关键工程突破。
- **与官方史料的交叉验证结论**：Netflix 技术博客（Jonathan Looney 等，BSDCan 2019 演讲）与 FreeBSD 13.0-RELEASE 发行说明可交叉验证；Phoronix 报道与 Netflix 官方技术发表一致。

### 新闻条目 2

- **新闻标题（中英）**：pfSense 2.3 发布，配备新 Web UI（pfSense 2.3 Released With New Web UI）
- **新闻来源**：Phoronix（Michael Larabel），2016-04-12
- **URL**：**<https://www.phoronix.com/news/pfSense-2.3-Released>**
- **存档 URL**：**<https://web.archive.org/web/2016/https://www.phoronix.com/news/pfSense-2.3-Released>**
- **新闻摘要**：2016 年 4 月 pfSense 2.3 发布，基于 FreeBSD 10.3-RELEASE（10.3-RELEASE 于同年 4 月 4 日发布），配备全新 Web UI。pfSense 是 FreeBSD 网络栈在防火墙/路由器场景的最重要衍生项目，其 2.3 版本的重大更新反映了 FreeBSD 网络栈在中小企业网络设备市场的持续的市场存在感。
- **与本章主题的关联说明**：本章记述 FreeBSD 网络栈在衍生项目中的应用，pfSense 是 FreeBSD 网络栈商业化的关键载体。
- **与官方史料的交叉验证结论**：pfSense 官方发布公告与 Phoronix 报道交叉验证，版本与发布时间一致。
