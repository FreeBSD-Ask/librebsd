# 321.4.206 〔USENIXSecurity23据频道标题标注〕在此观察之上先做两件逆向工程还

- 〔USENIX Security '23（据频道标题标注）〕在此观察之上先做两件逆向工程：还原 Intel 上指令预取器的工作方式，并“for the first time we show the replacement policy of the branch target buffer on various intel processors”〔05:55〕，还发现 Intel 的分支目标缓冲里实际有两种分支，称作 long branch 与 short branch。据此提出三种攻击：前两种把缓存攻击技术搬到分支预测器上，用 flush+reload 可学同一超平面内的预测器状态，用 prime+probe（转写作 prompt probe）可跨超平面获取；第三种是自驱逐，“a variant of evict time attack”，让受害者自己把自己的数据逐出〔06:23〕，用法与以往攻击完全不同，也是演讲重点。驱逐时延攻击原只需访问一大片内存逐出受害者的秘密相关数据，再测其执行时间即可推断秘密相关行为；防御手段是缓存着色，“assign different cache sets to different processes”〔07:39〕，攻击进程无法触达受害者的着色缓存，驱逐攻击就此失效。但受害者自己的内存仍可被访问并用于逐出自己——只是不会自动发生。于是作者“poison the branch predictor to tell the instruction prefetcher to actively fetch these memory addresses that will evict victim's data”〔08:31〕：执行一串首尾相接的分支指令，其目标地址又含另一分支，反复执行即完成投毒，待受害者运行时预测器便指示预取器去取那些会挤掉受害者秘密相关数据的地址；最后只差触发器，而“it can be any instruction because the instruction prefetcher does not care what it is prefetching”〔09:54〕，只要该指令在秘密数据被真正使用前被取到即可。至此秘密相关数据被受害者自己的访存逐出，攻击者只需测其执行时间——变长即说明数据被重新从内存取回。作者在 Linux 内核中运行的受保护 AES 上给出概念验证，“with less than twenty thousand traces we can successfully recover one key byte”〔10:43〕，而缓存已着色时驱逐时延攻击做不到；代码开源于 GitHub，他提到这是最后一天最后一场的收尾。（YouTube EPX2aNW6H75Bw，[351-702]，L1）
- 〔学术会议演讲（场合未明示）〕Chelsea Komlo 报告与 Nick Matthewson、Ian Goldberg 合作的 Walking Onions 工作，开场给出标题 "Walking Onions, Scaling Anonymity Networks While Protecting Users"〔00:16〕，以 Tor 为案例研究。Tor 的做法是所有客户端下载由目录权威签名的共识，它 "essentially the state of the network"〔00:33〕，列出每个中继与网络参数；客户端按带宽加权随机采样第一跳中继做密钥交换，再由第一跳转发请求去采样出的第二跳、第三跳，形成电路。演讲先说明 Tor "Tor favors security over scalability" 的取舍，代价是新中继不断加入使共识变大、客户端带宽开销随之上升。工作面向两类攻击：认知攻击，"users with different views in the network can be distinguished by their relay selection"〔01:47〕，Tor 靠所有客户端持有同一份最新共识抵御；路由捕获攻击，即攻击者影响用户的中继选择〔02:26〕，靠共识内携带的中继签名密钥链条抵御。贡献有三：把客户端带宽开销压到常数级，"we reduce client bandwidth overhead to constant size, even as new relays join the network"〔02:57〕；不破坏 Tor 既有安全模型，给出两个变体，后者 "has a slight weakening in forward secrecy, but only for the selection of relays in the path, not actually for content that is sent"〔03:22〕；并声称在如今 Tor 的规模下已有即时性能收益，部分设计可推广到 Tor 之外。演讲宣布按三问展开：中继信息如何表示才能支持 "oblivious selection of relays"〔03:54〕、如何据此选路建电路、如何更快建电路。第一项改造是沿用原有中继条目但追加两个值——目录权威计算的认证标签与一段索引区间，后者表示该中继在按带宽加权后的网络分布中的占位；所有 snip 连同另一个认证标签组成 n-dive，客户端只下载恒定大小的网络参数文档〔05:28〕，因此其负载不随新中继加入而增长。（YouTube EPX3wiFC0wncE，[8-352]，L1）
- 〔学术会议演讲（场合未明示）〕后半段先讲第一个变体 telescoping walking onions：客户端靠带外机制引导到第一跳，选第二跳时 "just samples some index completely at random within the distribution"〔06:13〕，第一跳在索引区间内找到对应 snip 并把 snip 连同回包返回，客户端据此做 "post hoc"〔06:38〕事后校验——确认自己采样的索引确实落在该中继区间内、且内容带权威认证标签；第三跳同理。要点是客户端 "doesn't need to know the full consensus, but it can still determine the relays for its path without influence by any intermediaries"〔07:17〕。第二个变体 single pass 更进一步：客户端连索引都不必自算，改用 VRF——"we actually use VRFs. So VRFs determine the second and third hop"〔07:34〕——由 VRF 决定第二、第三跳，客户端验证 VRF 证明与 snip 有效性即可。仿真以当今 Tor 规模 "about sixty-five thousand relays"〔08:49〕为参照：中继侧相对 Tor 现行洋葱路由省四到六倍带宽，网络扩到十倍规模时省二十到四十倍〔09:16〕；客户端侧省十到十五倍，十倍规模下省九十到一百五十倍〔09:44〕，规模越大收益复合放大。收尾给出结论：Tor 现设计使客户端开销随网络增长恶化；Walking Onions 去掉逐中继的带宽与存储开销，因为客户端不再本地维护共识、只维护恒定大小的网络参数文档并事后验证路径完整性〔10:36〕；对认知攻击与路由捕获攻击的保护并未丢失〔10:57〕。最后一句值得记下：Tor 项目 "has already begun the specification work to integrate walking onions into the Tor protocol"〔11:19〕。（YouTube EPX3wiFC0wncE，[352-695]，L1）

- 〔EuroS&P（推测）〕演讲者报告 ABY2——"improved mix protocol secure two-party computation"〔00:08〕——为与导师 Thomas Schneider（TU Darmstadt）以及 IIT Madras 的 Arpita Patra、Ajith Suresh 的联合工作。两方安全计算让互相不信任的两方在各自私有输入上算出联合函数而不泄露额外信息，示例是双方各有一盒钻石、只求同色数目。工作以 ABY 为基线：它假定半诚实安全、给出三种方案并在其间做转换〔01:09〕——算术份额（GMW）乘法廉价，布尔份额每个 AND 门都要一轮，Yao 加解密电路评 AND 门无需交互但 "communication overhead in Yao is more than Boolean GMW sharing"〔01:51〕。ABY2 的贡献清单很具体：设计新的算术与布尔份额方案及深度优化的布尔构造块〔02:19〕；提出至少 "two times better than A B Y" 的被动安全两方计算〔02:35〕；改用函数依赖的预处理，代价是需要提前知道待评估函数〔02:48〕；把两输入乘法推广为三、四输入乘法且在线通信仍只要两个值，并由此构造轮次与通信高效的电路如 EuAdders 与 AES Spikes〔03:13〕；提供比 ABY 更省的转换协议；面向隐私保护机器学习提供若干高效构造，并给出新的点积使在线通信与向量维度无关〔03:38〕。方案改造的入口是份额方案："For every value v we associate a random mask"〔04:24〕，取值为值加掩码，掩码值连同一份掩码份额明文交给双方、缺失的那份份额提供隐私——一方没有另一方的掩码份额，反之亦然；加法在 ABY2 中 "local"〔05:06〕，只需把对应份额相加、掩码份额也在本地算出。（YouTube EPX7IKSQyNEto，[8-357]，L1）
- 〔EuroS&P（推测）〕后半段落在乘法与工程收益上。乘法沿用掩码化思路：双方各持有掩码份额，只需额外获得两个交叉掩码份额即可本地算出结果的加性份额，最后把掩码值明文交换；关键改进是 "this approach requires a communication of just two values instead of four in the traditional A B Y approach"〔06:44〕——ABY 在线阶段每次乘法要四个值，ABY2 只要两个〔06:54〕，而预处理开销相同，差别仅在于 ABY2 是函数依赖、ABY 是函数无关。多输入推广后，"for four-input multiplication we just need two elements in online phase, but in ABY we need like twelve elements"〔07:21〕，这是文献中首次让在线通信与门扇入无关。转换协议同样优于 ABY〔07:45〕。最亮点是点积：ABY 需要与向量维度 D 成比例的四个值〔08:13〕，ABY2 只要两个值，是 "the first work to make the online cost independent of the feature size in this setting"〔08:19〕。基准测试在 Google Cloud 上做，涵盖最大池化、基于 AES Spikes 电路的 PSI、最小欧氏距离与生物特征匹配、隐私保护机器学习等场景〔08:38〕。与 SecML 相比，逻辑回归推理在 LAN 环境运行时间快约六倍、吞吐高约三十五倍，WAN 环境快约两倍、吞吐高约十一倍〔09:15〕；神经网络推理运行时间快约三倍、吞吐高约七百倍〔09:33〕，归因于 ABY2 的新点积〔09:54〕；神经网络训练吞吐快约三倍〔10:00〕，归功于新的 Softmax。总结四点：新的两方安全电路求值协议〔10:18〕；轮次与在线通信都更好的混合协议转换〔10:29〕；从两输入扩展到 n 输入且在线成本恒为 "only two rings"〔10:38〕（转写中的 rings 即环）；以及面向应用的构造块——新的标量积，以及轮次更省的 AND 组合、矩阵乘法、等值测试、比较与位提取〔10:48〕。（YouTube EPX7IKSQyNEto，[357-706]，L1）
