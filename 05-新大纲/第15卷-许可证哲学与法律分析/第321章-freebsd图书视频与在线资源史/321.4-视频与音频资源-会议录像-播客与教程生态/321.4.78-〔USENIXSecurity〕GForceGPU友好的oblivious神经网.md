- 〔FAST〕相变存储器（PCM）的性能测量。IBM Almaden 的 Hyojun Kim 报告对 Micron 2012 年 45nm PCM 原型 SSD（64GB）的测量研究，澄清写延迟（材料级 set 约 200ns、reset 脉冲 40ns，源于 2004 年 STMicroelectronics 论文）与写吞吐（芯片级受功耗预算限制，约 2.5MB/s）是不同层面的指标，研究者混用常得出 PCM 比闪存快千倍或仅 100MB/s 等误导性数字。团队修改 Red Hat Linux 内核与驱动以纳秒级捕获每次 I/O，实测 4KB 随机读平均 6.7µs（比 1.8TB eMMC 闪存 SSD 的 108µs 快 16 倍、500 万样本最大延迟低于 200µs），随机写平均 128.3µs（因无写缓冲而比闪存 SSD 慢 3.4 倍）。（YouTube EPCrCsEqT3BfI，[9.8-624.9]，L1）

- 〔会议不详〕为 BFT 状态机复制协议提供公平排序。报告指出经典 BFT 共识（如 PBFT）只保证输出全序，恶意 leader 可借交易排序牟利，引发 front-running、sandwich 等排序攻击，据估计参与者每月向以太坊验证者支付约 720 万美元以保交易顺序；ordered consensus（转写拼写的 Pompeii、Sermus）虽以服务观察决定排序，但观察本身偏向与多数节点低延迟相连的客户端，边际优势即可带来巨大收益并引发延迟军备竞赛。报告形式化定义了 bias、impartiality、ε-ordering quality 与 δ-ordering separation 等公平性概念，并给出公平与延迟的理论最优权衡曲线。（YouTube EPCrbY6Ujo2pI，[18.4-501.4]，L1）

- 〔USENIX Security〕压缩式 GC 引发的 use-after-free 缺陷检测。Theori 的 HyungSeok Han（合作者 Andrew Wesie、Brian Pak）报告：压缩式 GC 通过移动存活对象消除内存碎片，而未登记进地址表的 unrooted pointer 在对象被移动后成为悬挂指针，形成 use-after-compacting-GC bug，即 def-use-CGC-use 序列存在可行路径。Google V8 的 GC Mole 与 Mozilla SpiderMonkey 的 Root Analysis 等既有静态工具路径不敏感、依赖与目标紧耦合的启发式（维护非压缩 GC 函数列表、忽略 noGC 注解作用域）且不检查可行路径，可能漏报也易误报。（YouTube EPCtGPJW0gS7c，[7.8-354.6]，L1）

- 〔USENIX Security〕MBA-Blast：混合布尔-算术（MBA）混淆的化简。报告人 Binbin Liu（转写作 Ben Minio）介绍 MBA 表达式以位运算与算术运算的组合把 x+y 之类的简单表达式变成语义等价但难以理解的形式，被多个学术工具与工业项目（转写提到的 Pyomo、Gurobi、CPLEX 等求解器）嵌入采用，也用于 VMProtect 等虚拟化保护，而 Mathematica 内置求解器因不支持混合算子化简规则而失败，现有方案或性能代价大、或仅针对特定模式、或误报多。关键发现是现有 MBA 混淆设计隐含一比特与 n 比特空间之间的双向变换特征，可在搜索空间大幅缩小的一比特空间建立化简规则：两变量一比特表达式的 16 种真值均可表示为 x、y、x∧y 与常数的线性组合。（YouTube EPCzjgiVU5bII，[7.8-310.0]，L1）

- 〔OSDI〕VeriSMo：AMD 机密 VM 的形式化验证安全模块。在 AMD SEV-SNP（以及 Intel TDX、Arm CCA）等硬件特性使 hypervisor 不再可信后，代码完整性、运行时度量（虚拟 TPM）等安全特性须移入 VM 内安全模块：VeriSMo 是一个经形式化验证的 Rust VM 固件，运行于最高特权级并利用 VM 提供的特权级与 guest OS 隔离（仅共享内存加密密钥），为 guest OS 提供代码完整性、运行时度量与机密管理 API，并管理 RMP 逆向映射表、页表加密位与 vCPU 状态等敏感变更。报告指出这些硬件特性仍由软件控制、实现不当即致命，且现有开源 SVSM 均含大量 unsafe Rust 且从未被形式化验证。（YouTube EPD4o9WHeJlrc，[16.3-496.4]，L1）
