# 314.2.4 合图层：治理程序与许可证哲学的分层共存

**要点**：Committer’s Big List of Rules 的沉默反映分层设计——治理程序处理“谁有权提交”，许可证哲学通过社区讨论与工程实践处理“提交什么”。BSD 化工程未通过修订 committer 规则实现，而是通过构建 BSD 许可证替代品逐步完成，证明规则的程序中立未阻碍许可证纯化，反而为工程替代争取了时间——若规则在早期强制禁绝 GPL 代码，FreeBSD 将因缺乏可用编译器而无法发行。争议的启示在于：治理规则与许可证哲学运行在不同时间尺度——规则需稳定以维系社区信任，许可证哲学需演化以应对技术变迁，二者的分层共存是 BSD 社区治理的结构性特征。但分层共存亦属权力分配——“什么归规则、什么归工程”的界限是社区主流共识的产物，当共识变化时界限亦须重新协商。

**史料**：Committer’s Big List of Rules 修订历史（FreeBSD Committer’s Guide 第 20 章，docs.freebsd.org/en/articles/committers-guide/#rules）、BSD 化工程 commit log、Core Team 选举记录（freebsd.org/administration/）、FreeBSD Core Bylaws 2000.8.28 版第 1 条与第 5 条（"Active committers have made a commit to the tree in the last 12 months“；”Core members and committers may be ejected by a 2/3 vote of core"）［A］

**史观**：总纲第 4 条——分离聚合是永恒规律：治理程序与许可证哲学的分合循环

**辨析**：
    【查证来源】FreeBSD Committer’s Guide 第 20 章经 docs.freebsd.org/en/articles/committers-guide/#rules WebFetch 一手核验目录条目存在；FreeBSD Core Bylaws 2000.8.28 版经 freebsd.org/internal/bylaws/ WebFetch 一手核验，规定 active committer 12 个月门槛、Core 三分之二多数表决可驱逐 committer、规则修订须经 committers 三分之二多数且 50% active committers 投票；BSD 化工程 commit log 经 135.8 节史料交叉核验；Core Team 选举记录经 freebsd.org/administration/ 公开档案核验
    【交叉验证方法】四层交叉验证：（1）Committer’s Big List of Rules 章节存在的官方文档目录核验；（2）Core Bylaws 一手文本核验规则修订须 committers 三分之二多数，反映规则稳定性制度设计；（3）BSD 化工程时间线（2005 Clang 启动 → 2012 Clang 成为默认编译器 → 2014 LibreSSL fork → 2019 GCC 自 base 移除）［订正注：原稿 “2015 GCC 移除” 系时间线偏差——通行记载 base GCC 4.2.1 自 base 移除系 13-CURRENT（2019），2026-09-14 按核查报告订正，精确时点待以 Release Notes 一手复核］与规则修订记录对照，核验“工程替代优先于规则强制”的合图层论断；（4）Core Team 选举周期（每 2 年一次，2000 年首次）与 BSD 化关键节点对照，核验“治理规则与许可证哲学运行在不同时间尺度”的合图层论断；分层共存合图承认争议的部分不可调和性——分层界限是社区主流共识的产物，纯化派中的激进者仍可能持续不满
    【存疑判定依据】“分层共存是设计选择还是历史偶然”是本合图层的核心存疑点——规则的沉默可能仅是早期社区未预见许可证政治化的遗留，后被实用派赋予“分层治理”的正当性叙事，亦可能是有意识的分层设计，二者难以通过史料最终判定；“若规则在早期强制禁绝 GPL 代码，FreeBSD 将因缺乏可用编译器而无法发行”是反事实假设，无法经验验证，但工程史时间线（Clang 2005 启动 → 2012 默认 → 2014 GCC 移除）支持“工程替代品就绪是移除 GPL 代码的前置条件”的工程事实；合图层承认争议的部分不可调和性——纯化派中的激进者仍可能持续不满革命路径被搁置，故合图非强行归并而是分层共存下的动态张力 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］
