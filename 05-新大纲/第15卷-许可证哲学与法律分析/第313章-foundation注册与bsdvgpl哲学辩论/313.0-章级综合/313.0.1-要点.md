# 313.0.1 要点

- **Articles of Incorporation** 通过 **Colorado Secretary of State** 与 **Foundation** 官网双重披露，修订历史可从两地档案交叉核查。
- **IRS Determination Letter** 通过 **Foundation** 官网 PDF 与 **IRS EO BMF** 数据库双重披露，可对照核查。
- 各基金会治理结构史料通过 **By-Laws**、**IRS** 文件、年度报告等多源披露，需交叉核对。
- **Committer's Big List of Rules** 通过 **FreeBSD** 官网与 `freebsd-hackers` 邮件列表双重披露，修订历史可从两源档案交叉核查。
- **Core Team** 名单通过 **FreeBSD** 官网与 `freebsd-hackers` 邮件列表双重披露，历任名单可从两源档案交叉核查。
