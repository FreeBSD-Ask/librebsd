在 SCTP 修复的 git pull 讨论中，有读者（Jijo Chacko）问如何把 HTTP 流量迁到 SCTP：用户空间用 SCTP 的 BSD 风格套接口很容易，但若要写内核模块（如内核态 web 客户端/服务器），他在内核版 SCTP 接口里找不到与 NFS/RPC 所用 TCP、UDP 内核版 _sendmsg 相当的调用（原文："I am trying to develop a frame work, where i transport all HTTP traffic over SCTP. On user space, i can do this easily over SCTP, BSD-style sockets. If i am to write a kernel module(say in-kernel web client/server) using kernel version of SCTP interfaces, what are the available calls now supported ? I see in-kernel implementation like NFS/RPC make kernel version of UDP and TCP _sendmsg, i don't find similar interfaces for SCTP.."）。Vlad Yasevich 答复说不用另找：看 fs/dlm/lowcomms.c，在内核里创建套接口时用 IPPROTO_SCTP，即可沿用与 TCP/UDP 完全相同的调用（原文："Look at fs/dlm/lowcomms.c All you need to do is use IPPROTO_SCTP when creating a socket in the kernel and then I believe you can use all the same calls as TCP/UDP."）。即 BSD 风格套接口语义在内核态同样是可用的，只是提问者没有意识到 IPPROTO_SCTP 这一入口。
