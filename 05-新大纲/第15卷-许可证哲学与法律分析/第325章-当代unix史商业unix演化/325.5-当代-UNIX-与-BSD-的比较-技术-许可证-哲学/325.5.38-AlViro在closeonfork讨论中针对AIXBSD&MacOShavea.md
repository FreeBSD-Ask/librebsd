Matt Dillon 在 linux-mm 上提问：FreeBSD 会换出睡眠进程，是否会换出运行中的进程？并引到旧 BSD VM 系统的做法——他称其为硬交换（hard swapping）：当运行进程无法全部装入内存时，唯一的前进途径是循环把它们换过内存。Rik van Riel 回复 Linux 走另一条路——“swapout on next pagefault”，因为缺页时进程本就可被挂起，颠簸情形下应让每个进程在被换出前尽量多做进度，且不该为此复杂化 return to userspace 这类快路径代码。

关于 Unix 套接字文件描述符传递的 CMSG 长度语义之争，Steve Rago 指出 CMSG_LEN 与 CMSG_SPACE 源自已被 RFC 3542 取代的 RFC 2292，单条 cmsghdr 时到底需要多大缓冲标准未定；并称"Historically, BSD-based platforms never had these macros"；他认为 Linux 真正的问题在于 put_cmsg() 按 CMSG_LEN 计算长度，recvmsg() 却用 msg_sys.msg_control - cmsg_ptr 覆写 msg_controllen（该 msg_control 在 scm_detach_fds() 末尾被加了 CMSG_SPACE）、向应用返回错误值；本封作者 Andy Lutomirski 反驳该行为并不更令人意外，并以 CMSG_LEN=12、CMSG_SPACE=16 的三档占用举例。
