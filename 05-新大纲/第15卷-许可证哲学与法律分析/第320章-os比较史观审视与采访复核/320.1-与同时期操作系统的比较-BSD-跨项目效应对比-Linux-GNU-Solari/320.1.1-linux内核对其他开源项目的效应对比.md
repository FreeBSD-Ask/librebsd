# 320.1.1 Linux 内核对其他开源项目的效应对比

**要点**：Linux 内核作为 GPL 项目，其跨项目影响主要通过“内核模块 + 用户态工具”模式扩散——Linux 内核模块（如 eBPF、cgroups、namespaces）被其他开源项目采用；Linux 基金会托管项目（如 Kubernetes、Node.js）以宽松许可证发布；Linux 阵营的跨项目影响以“生态规模”见长，BSD 阵营以“许可证宽松性”见长；两者影响模式差异源于 GPL 与 BSD 许可证的法律结构

**史料**：Linux 内核源代码、Linux 基金会项目列表（linuxfoundation.org）、Kubernetes/Node.js 项目历史、GPL 与 BSD 许可证对比研究 ［A］

**史观**：许可证：GPL 与 BSD 的法律结构差异塑造不同跨项目影响模式；商业与社区的张力：Linux 生态规模优势 vs BSD 许可证宽松优势

**辨析**：Linux“生态规模”是否真大于 BSD 须量化对比；Linux 基金会托管项目是否真“Linux 内核影响”须辨析——这些项目多为独立运行于 Linux 但非内核衍生；GPL 与 BSD 影响模式的对比须避免简单化
