# 322.11.5 GPL 执行谱系对 BSD 史的整体意义

**要点**：GPL 执行判例谱系（Welte 2004 → BusyBox 2007-2013 → Wallace 2006 → Versata 2013-2015 → Hellwig 2015-2019 → SFC v. Vizio 2021-）对 BSD 史的整体意义有三：(1) 制度对照——GPL 靠“执行”维持 copyleft 闭环、产生大量判例与执法组织（SFLC/SFC/gpl-violations），BSD 许可证“无义务”设计使 BSD 几乎不产生许可诉讼（Jacobsen 案为唯一涉及 BSD 类条款的上诉判例，本卷 282.12）；(2) 生态影响——GPL 执行的合规成本（源码发布、合规官）推高企业使用 GPL 组件的成本，间接使 BSD 许可证（零义务）在嵌入式/商业场景更具吸引力；(3) 法律确定性——GPL 判例确认“附条件许可可执行”的普适原理，BSD 许可证的署名/免责条款（同为附条件）在此框架下亦获可执行性基础，BSD 社区因此受益于 GPL 执行带来的判例法外溢

**史料**：本小节所列全部判例与组织档案（SFLC/SFC/gpl-violations 官网）；Radcliffe M. Open Source Licensing 系列评论；Rosen L. Open Source Licensing（2005） ［A］

**史观**：总纲第 13 条法律与道德是利益分配——GPL 与 BSD 的执法不对称是两种自由哲学（copyleft 积极自由 vs 散逸消极自由）在制度层面的必然结果：copyleft 需要持续执行维持其“传染性”，BSD 无需执行维持其“开放性”；判例谱系是 GPL 哲学的制度化展开，而 BSD 哲学的“制度化”体现在许可证文本的极简与无讼状态——两种制度的演化路径互为镜像

**辨析**：须避免“BSD 无诉讼=BSD 更安全”的过度简化——BSD 少诉源于其许可证义务极少（可诉点少），但也意味着署名/免责条款的可执行性缺少直接判例支撑（Jacobsen 案的 Artistic License 类比仅为间接支持）；另须注意 GPL 执行组织的存在（SFC/SFLC）本身构成开源治理的重要机构史内容，与 BSD 基金会（本卷 283 章）的治理模式形成机构对照 ［A］
