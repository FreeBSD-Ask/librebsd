# 311.6.3 与其他开源基金会商标策略比较

**要点**：Linux 商标由 Linus Torvalds 个人持有（1997 年 Torvalds 诉 Della Croce 案和解后商标归属 Torvalds，此后设立 Linux Mark Institute 管理商标许可），Torvalds 授予 Linux Foundation 独占被许可人（exclusive licensee）地位，由基金会经由其管理的 Linux Mark Institute 向公众发放免费、永久、全球性的分许可；FreeBSD Foundation 直接持有 FreeBSD 商标并自行管理；Apache 软件基金会直接持有 Apache 商标。三者治理结构不同：Linux 为“个人持有＋基金会受托管理”，FreeBSD 与 Apache 为“基金会直接持有”。

| 基金会 | 商标 | 持有方式 |
| ------ | ---- | -------- |
| Linux Foundation | Linux | Linus Torvalds 个人持有，Linux Foundation 为独占被许可人，经 Linux Mark Institute 分许可管理 |
| **FreeBSD Foundation** | **FreeBSD** | 直接持有 |
| **Apache 软件基金会** | **Apache** | 直接持有 |

**史料**：Linux Foundation. The Linux Mark（商标分许可页）、Apache 软件基金会商标策略页、USPTO TSDR 检索记录 ［A］

**史观**：总纲第 13 条——法律与道德是利益分配：基金会商标治理差异

**辨析**：不同商标治理结构对项目发展的影响。个人持有＋机构受托模式（Linux）在创始人个人权利与机构执法能力之间形成制衡，1997 年 Della Croce 案后设立 Linux Mark Institute 即为防止商标旁落的产物；基金会直接持有模式（FreeBSD、Apache）把商标存续与基金会治理绑定，执法立场更易受社区舆论约束。比较时还须注意三者的注册类目与地域范围差异，不能以“谁持有”单一维度评判治理优劣。
