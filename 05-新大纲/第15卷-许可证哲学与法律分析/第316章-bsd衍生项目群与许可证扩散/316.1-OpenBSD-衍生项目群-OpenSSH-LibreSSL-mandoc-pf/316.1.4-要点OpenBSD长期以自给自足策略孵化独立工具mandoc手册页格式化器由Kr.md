# 316.1.4 要点OpenBSD长期以自给自足策略孵化独立工具mandoc手册页格式化器由Kr

**要点**：OpenBSD 长期以 “自给自足” 策略孵化独立工具：mandoc（手册页格式化器，由 Kristaps Dzonsons 与 Ingo Schwarze（英戈·施瓦茨） 开发，替代 groff，后被 Linux 发行版与 FreeBSD 采用）、signify（签名工具，由 Marc Espie（马克·埃斯皮） 与 Ted Unangst 开发，用于 OpenBSD 发布签名）、iked（IKEv2 守护进程，由 Reyk Flöter 开发）、bgpd（BGP 守护进程，由 Claudio Jeker（克劳迪奥·耶克尔） 开发，后被 OpenBGPD 独立项目化）、httpd（OpenBSD 自带 HTTP 服务器，基于 relayd 框架）、relayd、smtpd（由 Gilles Chehade、Jacek Masiulaniec、Charles Longeau 开发）、ntpd（由 Henning Brauer（亨宁·布劳尔） 开发）、snmpd、ldapd 等；这些工具均以 ISC 或 BSD 许可证发布，构成 OpenBSD 衍生项目群

**史料**：openbsd.org/innovations.html（OpenBSD 官方创新列表）、man.openbsd.org 各工具手册页、OpenBGPD 官网（openbgpd.org）、各工具源代码仓库 commit 历史 ［A］

**史观**：总纲第 8 条——社区文化即技术资产：OpenBSD “自给自足” 文化催生完整工具链；总纲第 7 条——BSD 与 UNIX 谱系的连续性：OpenBSD 工具群延续 UNIX “做一件事并做好” 哲学

**辨析**：各工具的作者归属须逐个对照 OpenBSD 源代码 commit 历史核实；“后被 Linux 发行版采用” 的范围须逐发行版核实（Alpine Linux、Void Linux 等采用 mandoc）；OpenBGPD 是否真独立项目化须查 openbgpd.org 治理结构

**文献**：OpenBSD innovations 官方列表；各工具手册页；OpenBGPD 官网 ［A］
