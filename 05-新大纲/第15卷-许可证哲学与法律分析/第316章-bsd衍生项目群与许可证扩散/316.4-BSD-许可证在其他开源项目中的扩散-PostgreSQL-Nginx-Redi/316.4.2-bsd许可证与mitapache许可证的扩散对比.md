# 316.4.2 BSD 许可证与 MIT/Apache 许可证的扩散对比

**要点**：BSD、MIT、Apache 2.0 三者构成 “宽松许可证” 主流；BSD 许可证在 1980-1990 年代 UNIX 生态中占主导，MIT 许可证在 X Window System 与现代 JavaScript 生态中扩散，Apache 2.0 在 2000 年代后随 Apache 软件基金会项目扩散；BSD 许可证的演化（4 条款 →3 条款 →2 条款）反映社区对广告条款的反对；BSD-2-Clause 成为现代 BSD 项目（FreeBSD、Nginx、Varnish 等）的主流选择

**史观**：法律结构：BSD/MIT/Apache 三者法律结构的差异塑造不同扩散模式；许可证：宽松许可证的扩散对比 GPL 的强制回馈

**辨析**：BSD 与 MIT 的法律差异极小（主要在条款表述），实际扩散差异源于项目选择而非许可证本身；Apache 2.0 的专利反制条款是 BSD/MIT 所无，须查 Apache 2.0 第 3 条原文
