# 316.2.1 Poul-Henning Kamp（波尔-亨宁·坎普） 与 Varnish Cache

**要点**：Varnish Cache 由 FreeBSD 核心开发者 Poul-Henning Kamp（phk）于 2006 年 2 月开始设计，2006 年 9 月发布 Varnish 1.0；项目由挪威报纸 Verdens Gang（VG）的 Anders Berg 发起并提供资金，由挪威开源咨询公司 Linpro（后改名 Redpill-Linpro）提供开发支持；Varnish 设计目标为替代 Squid 作为反向代理缓存，PHK 的核心设计决策是将缓存置换交给操作系统虚拟内存管理（而非应用层），以利用现代操作系统的页缓存与多级 CPU 缓存；Varnish 采用 BSD-2-Clause 许可证；2010 年 Varnish Software 从 Linpro 分拆独立商业化，Varnish Cache 开源项目保持独立；采用方包括 Wikipedia、Facebook、Twitter、Vimeo、Tumblr、The New York Times、The Guardian、The Hindu 等，BuiltWith 统计显示前 1 万网站中 13% 以上采用 Varnish〔原禁引来源（仅作考据留痕）·已改引官方主源 ref2514（PHK 一手设计笔记 varnish-cache.org/docs/7.5/phk/firstdesign.html，2006-02-02）〕

**史料**：info.varnish-software.com/blog/history-varnish-cache-10-years（2016.2.23）、varnish-software.com/varnish-history/、varnish-cache.org/docs/trunk/phk/firstdesign.html（PHK 设计笔记）、BuiltWith varnish 趋势统计 ［A］

**史观**：边缘者贡献：PHK 作为 FreeBSD 开发者主持非 BSD 项目，体现 BSD 开发者的跨项目影响力；商业与社区的张力：VG 商业需求驱动开源项目孵化

**辨析**：PHK 在 Varnish 中的角色须区分“首席架构师”与“主要开发者”——后期 Varnish Software 团队承担主要开发；“13% 采用率”统计需通过 BuiltWith 数据采集方法核实；Varnish 与 Squid 的性能对比须查独立基准测试
