# 316.5.3 BSD 开发者在 IETF 工作组中的角色

**要点**：BSD 开发者长期参与 IETF 工作组——BSD socket API 直接进入 POSIX 与 IETF 网络标准；Kirk McKusick、Poul-Henning Kamp（波尔-亨宁·坎普） 等长期参与 IETF 会议；Tom Jones（FreeBSD 提交者）与 Lars Eggert（FreeBSD 贡献者——曾为 FreeBSD 开发 DCTCP、PRR、NewCWV 等网络协议实现，后任 IETF 主席与 IRTF 主席）参与 IETF 治理；BSD 网络栈实现（如 TCP、IPsec、IPv6）是 IETF RFC 的参考实现之一；BSD 与 IETF 的双向影响构成网络协议演化的重要维度

**史料**：IETF 会议议程历年存档、IETF 工作组成员名单、BSD 网络栈 commit 历史、Jones 与 Eggert 个人主页 ［A］

**史观**：BSD 与 UNIX 谱系的连续性：BSD 与 IETF 协议演化相互塑造；边缘者贡献：BSD 开发者跨 IETF 与 BSD 两个领域

**辨析**：Jones 与 Eggert 在 IETF 的具体角色须查 IETF 工作组当前名单；BSD 网络栈作为“RFC 参考实现”须具体到 RFC 编号核实；McKusick 与 PHK 参与 IETF 的频率须查 IETF 会议出席记录
