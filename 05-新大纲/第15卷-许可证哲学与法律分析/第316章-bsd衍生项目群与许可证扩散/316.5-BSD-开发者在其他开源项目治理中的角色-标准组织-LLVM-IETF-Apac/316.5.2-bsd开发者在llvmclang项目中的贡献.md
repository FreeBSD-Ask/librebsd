# 316.5.2 BSD 开发者在 LLVM/Clang 项目中的贡献

**要点**：FreeBSD 项目是 LLVM/Clang 早期主要采用者与贡献者——2012 年 1 月 12 日 FreeBSD 9.0 起 Clang 3.0 作为 amd64 与 i386 的可选编译器随基本系统发布（先前叙事称“2011 年 FreeBSD 9.0 起 Clang 替代 GCC 作为默认编译器”有误，9.0 release notes 与 Roman Divacky 2011 BSD Day 演讲明确 Clang 在 9.0 中仅作可选编译器，能编译 world/kernel 但 GCC 仍为默认），2014 年 1 月 20 日 FreeBSD 10.0 起 Clang 正式替代 GCC 成为 x86 与 ARMv6+ 平台的默认系统编译器〔订正注：原误记 2014-01-31，FreeBSD 10.0-RELEASE 为 2014-01-20〕，libc++ 同步替代 libstdc++ 作为默认 C++ 标准库（参见相关章节）；GCC 在 GPLv3 转换后因下游消费者反对未能进入 FreeBSD 基本系统，长期停留在 4.2.1（最后 GPLv2 版本）；FreeBSD 开发者 Roman Divacky、Brooks Davis、Ed Maste（埃德·马斯特）、David Chisnall（戴维·奇斯纳尔） 等长期贡献 Clang/LLVM 上游；FreeBSD 基金会 曾赞助 LLVM 项目开发（如 ARM64 后端、MIPS 后端），FreeBSD 与 NetBSD 基金会 还联合资助 PathScale 开源 libcxxrt（C++ 运行时）；OpenBSD 与 NetBSD 后续也采用 Clang；BSD 项目对 LLVM 的贡献是 BSD 阵营“去 GPL 化”战略的关键组成部分

**史料**：llvm.org 发布历史、FreeBSD 9.0 release notes（2012-01-12）、FreeBSD 10.0 release notes（2014-01-20）、FreeBSD 基金会 2014 年 1 月刊 David Chisnall“Clang in 10”文章（freebsdfoundation.org/wp-content/uploads/2014/01/Clang-in-10.pdf）、Roman Divacky 2011 BSD Day 演讲“Clang/LLVM in FreeBSD”（people.freebsd.org/~pgj/bsd_day(2011)/原材料/13_rdivacky_clang.pdf）、David Chisnall AsiaBSDCon 2014“LLVM in the FreeBSD Toolchain”论文（cl.cam.ac.uk/research/security/ctsrd/pdfs/201403-asiabsdcon2014-llvmbsd.pdf）、FreeBSD 基金会年报赞助 LLVM 部分、FreeBSD src commit 历史 @llvm.org 邮箱统计 ［A］

**史观**：商业与社区的张力：BSD 项目资助 LLVM 以摆脱 GPL 依赖；BSD 与 UNIX 谱系的连续性：LLVM 成为 BSD 阵营默认编译器

**辨析**：FreeBSD 基金会 赞助 LLVM 的具体金额须查年报；BSD 开发者在 LLVM commit 中的占比须查 llvm-project 仓库 commit 统计；“去 GPL 化”战略参见相关章节，本节不重复；FreeBSD 9.0 中 Clang 的“可选”地位经核查由 Divacky 2011 演讲与 9.0 release notes 共同印证，先前叙事错误已修正
