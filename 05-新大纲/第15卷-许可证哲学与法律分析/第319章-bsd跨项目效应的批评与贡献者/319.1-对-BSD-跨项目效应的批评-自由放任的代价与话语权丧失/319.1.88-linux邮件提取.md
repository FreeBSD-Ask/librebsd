2003-07-03 2.7 研究议程讨论中，William Lee Irwin III 转引 Larry McVoy 的观点：思路是把状态存到更高层对象、按高层对象做更智能的分页决策；McVoy 自称 SunOS 出身，所指的"高层对象"即 vnode(inode) （原文，跨行折行："In my brain, since I'm a SunOS guy, that means that you store information in the vnode (inode) which reflects the status of all pages backed by this inode."）。本封作者自有段仅一句 "I believe people are already on file object local page replacement, though it's more in the planning than implementation phase." 需更正：该对照基线是 SunOS（Sun 系 vnode 语义），并非 BSD 血统系统，本封正文无任何 BSD 指称；本块可留作 Linux 按对象（inode/vnode）级分页决策的设计讨论留痕，但不得冠以 BSD 血统。
