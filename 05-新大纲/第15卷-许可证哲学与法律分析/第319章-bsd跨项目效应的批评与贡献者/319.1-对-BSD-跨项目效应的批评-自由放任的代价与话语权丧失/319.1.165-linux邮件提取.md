Mateusz Guzik 在 percpu 计数器分配的构想中提出分层架构——"backing percpu machinery"负责为缓存分配内存，"caching layer"负责向最终消费者发放内存，缓存若未发放出去则留存在 per-CPU 上，避免跨 CPU 争用；同时热插拔列表可承接所有已缓存与已发放对象。Mateusz Guzik 在早前同一线程往来中援引 FreeBSD 的 per-CPU 分配器作为参照："FreeBSD has a per-cpu allocator which pretends to be the same as the slab allocator, except handing out per-cpu bufs. So far it has sizes 4, 8, 16, 32 and 64 and you can act as if you are mallocing in that size. Scales perfectly fine of course since it caches objs per-CPU, but there is some waste and I have 0 idea how it compares to what Linux is doing on that front."——为 Mateusz 的方案提供了 BSD 侧的成熟先例。
