## 103.1 2.6.19-rc2-mm1

- 【Linux社区】Andrew Morton 发布 -mm 树 2.6.19-rc2-mm1；评语核心为新增 hwmon 与 i2c 两个 quilt 式树（Jean Delvare 维护），附 git 抓取/二分定位 boilerplate 与补丁清单，共 875 个补丁。 `<!-- ROW_MINE: linux-kernel-announce.messages.719974 -->`

## 103.2 2.6.26-rc5-mm3

- 【Linux社区】Andrew Morton 发布；说明此为 rc5-mm2 的修 bug 版且未重拉 git 树，目标是清掉低级 bug 以便开展认真 MM 测试；1390 个提交、967 个补丁文件，含 Rik 页回收工作新迭代（unevictable LRU）。 `<!-- ROW_MINE: linux-kernel-announce.messages.720052 -->`

## 103.3 2.6.14-mm2

- 【Linux社区】Andrew Morton 发布；评语核心：reiser4 以模块构建已坏需选 CONFIG_REISER4_FS=y、新增 git-cfq 树（Jens 的 CFQ I/O 调度器更新）、git-pcmcia 重新加入、git-audit 暂撤；共 610 个补丁。 `<!-- ROW_MINE: linux-kernel-announce.messages.720058 -->`

## 103.4 2.6.18-rc1-mm1

- 【Linux社区】Andrew Morton 发布；评语核心：给设备注册 API 加 __must_check 引出约 1500 个新警告（须全部修复）、swsusp 磁盘读写速度约翻倍、reiser4 编译坏、powerpc G5 疑似挂死；共 807 个补丁。 `<!-- ROW_MINE: linux-kernel-announce.messages.720101 -->`

## 103.5 2.6.17-rc4-mm1

- 【Linux社区】Andrew Morton 发布；自嘲“大量新 bug^H^H补丁”：新增 klibc（Peter Anvin）、用户态头文件清理与 hdrinstall（David Woodhouse）、cachefs 回归、新增 ecryptfs 文件系统、per-task delay accounting；共 992 个补丁。 `<!-- ROW_MINE: linux-kernel-announce.messages.720103 -->`

## 103.6 Linux 2.2.26 aka “2.2 is not dead” released

- 【Linux社区】Marc-Christian Petersen 发布 2.2.26 最终版并呼吁 2.2 用户升级；列安全修复清单：CAN-2004-0077 mremap/do_munmap、CAN-2003-0984 /dev/rtc 内存泄漏、CAN-2003-0244 网络栈 hashing 漏洞；致谢 Solar Designer，带 PGP 签名。 `<!-- ROW_MINE: linux-kernel-announce.messages.720105 -->`

## 103.7 2.6.23-rc6-mm1

- 【Linux社区】Andrew Morton 发布；评语核心：29MB 差异、花两天整理约 90 个修补补丁并直言“这已经行不通了”；已知问题为 Vaio 退出 X、挂起与恢复均挂死、网络大改致 b44 被禁用、IPC 大改待测；4641 个提交、1872 个补丁文件。 `<!-- ROW_MINE: linux-kernel-announce.messages.720118 -->`

## 103.8 Announce loop-AES-v2.0b file/swap crypto package

- 【Linux社区】Jari Ruusu 发布 loop-AES v2.0b 加密包；含实质变更清单：module-init-tools 命名变通、INITIALDELAY 选项、loop_info64 与 64 位 offset/sizelimit 支持、MD5 IV 多密钥操作、消除 highmem bouncing，并附 ciphers v2.0b 变更与 md5sum。 `<!-- ROW_MINE: linux-kernel-announce.messages.720125 -->`

## 103.9 Linux 2.6.13.1

- 【Linux社区】Chris Wright（-stable 团队）发布 2.6.13.1；附 diffstat（16 文件，85 增 77 删）与修复摘要：raw_sendmsg DoS（CAN-2005-2492）、32 位 sendmsg 漏洞（CAN-2005-2490）、libpcap/tcpdump 修复、cipher 边界检查、PCI ROM 映射等，并给出 2.6.13.y git 树。 `<!-- ROW_MINE: linux-kernel-announce.messages.720130 -->`
