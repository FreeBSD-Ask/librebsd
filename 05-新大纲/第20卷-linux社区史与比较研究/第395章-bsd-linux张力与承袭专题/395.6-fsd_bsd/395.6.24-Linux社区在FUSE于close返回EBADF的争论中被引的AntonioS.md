- 【Linux社区】在 FUSE 于 close() 返回 EBADF 的争论中，被引的 Antonio SJ Musumeci 指出 FUSE 是跨平台协议（Linux、FreeBSD、MacOS、Windows）（引语：“FUSE which is a cross platform (Linux, FreeBSD, MacOS, Windows) protocol.”），服务器返回错误时的行为已事实性地构成协议内容，Linux 若单方面改变会波及所有实现；发信人 The 8472 则要求 Linux 收紧自身 API 契约或补正文档。BSD 在此是 Linux 系统调用语义变更的外部约束，而非设计来源。`<!-- ROW_MINE: linux-fsdevel.messages.674723 -->`
- 【Linux社区】Linus Torvalds 裁定 O_DIRECTORY 与 O_CREAT 混用之乱，把 Linux 历史行为与两个 BSD 对照：FreeBSD 在目标是已存在目录时成功、仅在落到创建路径时返回 ENOENT（2015 年起如此），最接近 Linux 旧行为；NetBSD 直接返回 EINVAL，最为清晰（引语：“NetBSD just straight up returns EINVAL”，出自被引 Pedro Falcato 的罗列）；他还草拟 build_open_flags() 补丁，在 WILL_CREATE() 遇到 O_DIRECTORY 时返回 -EINVAL。BSD 两族的处理方式成为 Linux 语义取舍的判据。`<!-- ROW_MINE: linux-fsdevel.messages.675263 -->`
