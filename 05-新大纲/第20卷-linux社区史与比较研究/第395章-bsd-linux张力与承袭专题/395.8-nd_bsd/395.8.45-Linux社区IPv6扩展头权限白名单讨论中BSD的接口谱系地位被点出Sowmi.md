- 【Linux社区】SO_REUSEADDR 语义分歧被点名为 BSD 差异，线程标题即称 “SO_REUSEADDR behavior different from BSD”：发帖人报告 Linux 上第二个实例以 EADDRINUSE 失败，而 FreeBSD 5.1 能绑定成功，被引的 YOSHIFUJI 明确表态 “I hate BSD's behavior because it is asynmetry”，坚持该行为是有意为之，是 BSD socket 语义与 Linux 有意分岔的正面记录。`<!-- ROW_MINE: netdev.messages.8339938 -->`
- 【Linux社区】af_packet 直环访问补丁的评审中，BSD netmap 被当作对照方案：Borkmann 询问若采用 “use an e.g. netmap-alike Linux-own variant as a hw-neutral interface”，即不直接暴露硬件描述符格式的硬件中立接口，性能损失有多大，说明 BSD 系零拷贝接口设计已被拿来作为 Linux 网络接口设计的参考基线。`<!-- ROW_MINE: netdev.messages.8340298 -->`
