### 新闻条目 1

- **新闻标题（中英）**：FreeBSD Foundation Launches Alpha Omega Project to Reduce Exploitable Vulnerabilities / FreeBSD Foundation 启动 Alpha Omega 项目以减少可利用漏洞
- **新闻来源**：FreeBSD Foundation 官方网站 + URL `<https://freebsdfoundation.org/`> + 关联 URL `<https://alpha-omega.dev/`>
- **新闻摘要**：FreeBSD Foundation 启动为期 6 个月的 Alpha Omega 项目，关键目标是减少 FreeBSD 源代码中可利用漏洞的数量。该项目由 Alpha Omega 项目资助。
- **与本章主题的关联说明**：反映 2024 年前后 FreeBSD Foundation 对 SSDF（Secure Software Development Framework）合规要求的响应，是本章 “BSD 与 SSDF” 小节与 “FreeBSD Foundation 合规工程” 小节的衔接史料。
- **与官方史料的交叉验证结论**：FreeBSD Foundation 官方页面明确披露该项目存在与资助来源。Alpha Omega 是 Linux Foundation 旗下的开源安全项目，其资助 FreeBSD 反映跨基金会协作，与 OpenSSF（Open Source Security Foundation）2023-2024 年度报告可交叉验证。

## 里程碑事件类

### 新闻条目 1

- **新闻标题（中英）**：FreeBSD C99 & POSIX Conformance Project / FreeBSD C99 与 POSIX 合规项目
- **新闻来源**：FreeBSD Project 官方页面（Mike Barcroft 维护）+ 2002-04-10 最后更新 + URL `<https://people.freebsd.org/~mike/.c99/`> + 镜像 `<http://mirror.rootbsd.net/projects/c99/index.html`>
- **新闻摘要**：该项目目标是实现 ISO 9899:1999（C99）和 IEEE 1003.1-2001（POSIX）标准的全部要求，无法遵循的部分将在 **c99(7)** 或 **posix(7)** 手册页中记录。初始开发在 5.0-CURRENT 分支进行，并希望最终合并至 4-STABLE 分支。任务清单涵盖 `strerror_r()`、`tgamma()`、`imaxabs()`、`atoll()`、`strtoimax()`、`getgrgid_r()`、`getpwnam_r()` 等 C99/POSIX 函数实现，以及 `<stdint.h>`、`<inttypes.h>`、`<complex.h>`、`<fenv.h>` 等头文件合规化。
- **与本章主题的关联说明**：这是 FreeBSD 项目在 2001-2002 年期间对 POSIX/C99 标准合规化的系统性工程响应，反映 FreeBSD 早期主动遵循 IEEE 1003.1 与 ISO 9899 标准的历史脉络，是本章 “POSIX 标准” 小节的核心一手史料。
- **与官方史料的交叉验证结论**：页面位于 `freebsd.org` 官方域，由 Mike Barcroft（FreeBSD 提交者）维护，与 `freebsd-standards` 邮件列表存档可交叉验证。页面标注 “2002-04-10 最后更新”，对应 5.0-CURRENT 开发期（FreeBSD 5.0 于 2003-01-19 发布），时间线一致。

### 新闻条目 2

- **新闻标题（中英）**：POSIX Certification by IEEE and The Open Group / IEEE 与 The Open Group 的 POSIX 认证
- **新闻来源**：The Open Group 官方 POSIX 认证站点 + URL `<https://posix.opengroup.org/`> + 认证指南 `<https://posix.opengroup.org/certification_guide.html`>
- **新闻摘要**：POSIX™: Certified by IEEE and The Open Group 是自愿性认证程序，但供应商若要使用 POSIX™ 商标则必须通过认证。认证对任何满足合规要求的产品开放。Product Standards 提供认证、POSIX 标准与所需测试套件之间的映射。
- **与本章主题的关联说明**：揭示 FreeBSD 未申请 POSIX 商标认证的事实背景——FreeBSD 长期声明 “兼容 POSIX” 但未通过 The Open Group 的付费认证程序。这是 FreeBSD “事实合规而非认证合规” 模式的关键证据。
- **与官方史料的交叉验证结论**：The Open Group 是 POSIX 商标的法定持有方，其官方认证程序说明与 FreeBSD 手册页 **posix(7)** 中 “FreeBSD 力求遵循 IEEE Std 1003.1-2001 但未进行正式认证” 的声明互为印证。

- **新闻来源**：FreeBSD 官方文档 `<https://docs.freebsd.org/en/articles/bsdl-gpl/`> + FreeBSD 文档项目
- **新闻摘要**：该文档阐述 BSD 风格许可证的法律特征与历史脉络，涵盖 Very Brief Open Source History、Unix from a BSD Licensing Perspective、The Current State of FreeBSD and BSD Licenses、The origins of the GPL、The origins of Linux and the LGPL、Open Source licenses and the Orphaning Problem、GPL Advantages and Disadvantages、BSD Advantages、Specific Recommendations 等章节。
- **与本章主题的关联说明**：FreeBSD 官方对 BSD 许可证与 GPL 差异的法律立场陈述，是本章 “许可证标准遵守” 小节的核心一手史料，亦为第 140 章 “BSD 许可证与 GPL 论战” 提供官方视角基础。
- **与官方史料的交叉验证结论**：文档位于 `docs.freebsd.org` 官方域，属 FreeBSD 文档项目（FreeBSD Documentation Project）正式发布的文章，与 FreeBSD 许可证文本（BSD 2-Clause）及 SPDX 标识符 `BSD-2-Clause` 一致。

- **新闻标题（中英）**：FreeBSD Foundation About the Foundation / FreeBSD Foundation 关于基金会
- **新闻来源**：FreeBSD Foundation 官方网站 + URL `<https://freebsdfoundation.org/about-us/about-the-foundation/`>
- **新闻摘要**：FreeBSD Foundation 是美国 501(c)(3) 非营利组织，通过软件开发、基础设施改进、倡导、培训与社区参与支持 FreeBSD 项目。基金会作为项目的法定实体，管理合同、许可证与其他协议。核心价值包括创新、透明、专业、质量、可信。2025 年预算分配中超过 60% 用于软件开发。
