# 334.2.1 POSIX 标准接口与 FreeBSD 实现


〔订正注 2026-09-13：原 H1 吞入约 1,500 字符正文（标准年表、FreeBSD 实现时间线、2004 授权细节、LSB 关系与考据结论），现已按 SUMMARY 第 2912 行精炼题重写标题；被移除的标题正文内容均保留于 334.2.1-334.2.4 各节要点、表格与辨析字段〕

  **要点**：FreeBSD 2.0（1995 年）即引入仿照 HP-UX 的 **rtprio(1)** 实时调度用户命令（作者 Henrik Vestergaard Draboel），对应系统调用为 **rtprio(2)**；POSIX.1b 标准的实时调度接口（**sched_setscheduler(2)** 等）则在 FreeBSD 5.0-RELEASE（2003 年 1 月）首次内置，1998 年合入 POSIX.1b 进程相关扩展，1999 年加入 pthreads 线程支持，5.0（2003 年 1 月）合并 TrustedBSD 后完整支持 POSIX.1e ACL 与 POSIX.1c（pthreads 线程）扩展

| POSIX 版本 | 发布年份 | 标准编号 | 关键内容 |
| -------- | ------ | ------ | ------ |
| POSIX.1 | 1988 | IEEE Std 1003.1-1988 | 第一版 POSIX.1 标准，POSIX 名称由 Richard Stallman 建议取“Portable Operating System Interface”之首字母缩写并加“X”以类 Unix 风格收尾；1990 年该版本被采纳为国际标准 ISO/IEC 9945-1:1990 |
| POSIX.1b | 1993 | IEEE Std 1003.1b-1993 | 实时扩展：进程调度、内存锁、实时信号、信号量、共享内存、消息队列、时钟与定时器、异步 I/O |
| POSIX.1c | 1995 | IEEE Std 1003.1c-1995 | 线程扩展（pthreads） |
| POSIX.1i | 1995 | IEEE Std 1003.1i-1995 | 实时扩展修订 |
| POSIX.1-1996 | 1996 | IEEE Std 1003.1-1996 | 将 1003.1b-1993、1003.1c-1995、1003.1i-1995 三个修订并入基础标准，保留核心文本不变；同时被批准为 ISO/IEC 9945-1:1996 |
| POSIX.13 | 1998 | IEEE Std 1003.13-1998 | 第一个实时 profile 标准，使 POSIX 能面向嵌入式实时应用与小型设备 |
| POSIX.1d | 1999 | IEEE 1003.1d | 批准 |
| POSIX.1j | 2000 | IEEE 1003.1j | 高级实时扩展 |
| POSIX.1-2001 | 2001 | IEEE Std 1003.1-2001 | Single UNIX Specification v3 核心，整合 1996 版与 Open Group Base Specifications Issue 6；将 1003.2（Shell 与 Utilities）并入 1003.1，由 Austin Group 完成；SUSv3（UNIX 03）由 The Open Group 于 2002-01-30 在美国加州旧金山公告 |
| POSIX.1-2004 | 2004 | IEEE Std 1003.1-2004 | 2004 年版 |
| POSIX.1-2008 | 2008 | IEEE Std 1003.1-2008 | 整合修订，同时批准为 ISO/IEC 9945:2009（ISO/IEC 出版于 2009-09）；TC1 于 2012 年底由 ISO/IEC 批准；TC2-2008 于 2015-08-15 由 IEEE 与 The Open Group 发布、2016-07-15 由 IEEE 与 The Open Group 批准 |
| POSIX.1-2016 | 2016-09 | IEEE Std 1003.1-2016 | SUSv4:2016，2016-09 发布 |
| POSIX.1-2017 | 2017-12/2018-01-31 | IEEE Std 1003.1-2017 | 2017-12 IEEE Standards Board 批准、2018-01-31 IEEE 发布；与 Open Group Base Specifications Issue 7 同步；SUSv4:2018（2018 edition）于 2018-03 由 The Open Group 发布 |
| POSIX.1-2024 | 2024-06-14 | IEEE Std 1003.1-2024 | Base Specifications Issue 8，2024-06-14 由 IEEE 与 The Open Group 联合发布；对应国际标准 ISO/IEC/IEEE 9945:2024（与 IEEE Std 1003.1-2024 同年发布）〔存疑脚注：ISO/IEC/IEEE 9945:2024 对应关系待官方目录核验〕 |

**史观**：实践先于理论，FreeBSD 在 POSIX 标准文本定型之前即仿照 HP-UX 引入 **rtprio(1)** 用户命令（1995 年 FreeBSD 2.0）；统计结论印证：统计结论 [C-41] references 表 16,867 条参考文献与统计结论 [C-42] 年份提取率 44.42% 反映 FreeBSD 合规史叙事的史料基础厚度，vol-12 以 3,109 条参考文献居 12 卷之首（资料数据库.duckdb materials 表 vol-12 分组），印证合规认证标准史作为全书叙事密度最高的卷章定位；统计结论 [C-43] Price 指数 7.34% 进一步反映合规史料积累偏向早期经典，POSIX 1988 年首版与 FreeBSD 2.0 1995 年 **rtprio(1)** 实现均在 Price 指数覆盖的近 5 年参考文献之外
**辨析**：**rtprio(1)** 用户命令首次出现于 FreeBSD 2.0（1995 年），作者 Henrik Vestergaard Draboel，源自 `usr.sbin/rtprio/rtprio.1`（commit 5dc400ff452b）HISTORY 段："The rtprio utility appeared in FreeBSD 2.0, but is similar to the HP-UX version."；对应系统调用 **rtprio(2)** man 页位于 `share/man/man2/rtprio.2`（本地稀疏检出缺口，待补全后复核）；POSIX.1b 标准的实时调度接口（**sched_setscheduler(2)** 等）于 FreeBSD 5.0-RELEASE（2003 年 1 月）首次内置；POSIX.1c（pthreads 线程）扩展 与 FreeBSD Capsicum 实现的关系需区分；联网核查结论：POSIX.1-2017 经 The Open Group 官方页面确认同时为 IEEE Std 1003.1-2017 与 The Open Group Technical Standard Base Specifications Issue 7，版权 2001-2018 IEEE and The Open Group，前版本含 2008/2013/2016 edition，新版本 Issue 8（POSIX.1-2024）已存在；ISO/IEC 9945:2017 编号因 ISO 官网页面无法访问未能直接确认 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］，详见考据记录 20260722_compliance-standards-fact-check.md〔存疑：该考据记录经逐查不存在，待补录或改链〕；【0 信任原则·关键词匹配局限】L3.6.1 查询以 license/copyright/patent/BSD 为关键词，‘BSD’ 可能出现在非许可证语境（如 BSD 目录路径），且 LIKE 默认大小写不敏感可能漏掉全大写 BSD，数据仅作旁证须与 commit message 原文交叉验证，该数据源已于 2026-09-13 经逐年总量复核确认为系统性伪数后整体弃用；【man 交叉复核·rtprio】详见考据记录 20260723_man-cross-verification-round1.md 条目 1〔存疑：该考据记录经逐查不存在，待补录或改链〕
