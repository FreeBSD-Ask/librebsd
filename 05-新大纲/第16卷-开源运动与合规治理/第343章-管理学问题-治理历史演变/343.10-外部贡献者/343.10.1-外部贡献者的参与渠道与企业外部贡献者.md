# 343.10.1 外部贡献者的参与渠道与企业外部贡献者

**要点**：FreeBSD 外部贡献者指无 committer 权限但通过提交补丁、bug 报告、文档翻译参与项目的贡献者；外部贡献者的主要参与渠道包括 Bugzilla（后迁 GitHub Issues）、phabricator（代码审查，2020 年迁 Git 后逐步过渡到 GitHub PR）、邮件列表；企业外部贡献者（如 Netflix 工程师通过提交 kernel TLS offload 补丁、Juniper 工程师提交路由相关补丁）是 FreeBSD 高质量外部贡献的重要来源；外部贡献者转 committer 的 “mentor 担保” 机制是主要晋升路径但存在 mentor 数量瓶颈

**史料**：FreeBSD Bugzilla 与 GitHub Issues 统计、phabricator 审查记录、freebsd-hackers 外部贡献者讨论、Netflix/Juniper 工程博客［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］〔L2 即时通讯记录〕

**史观**：总纲第 10 条——边缘者贡献，外部贡献者是社区 “动手者” 的典型代表，其贡献长期被 committer 叙事遮蔽

**辨析**：外部贡献者的具体数量与贡献量需量化（以 Bugzilla/GitHub 统计为准）；企业外部贡献者与个人外部贡献者的动机差异需分析；mentor 瓶颈对外部贡献者转 committer 的具体影响需以 mentor 邮件列表讨论为据
