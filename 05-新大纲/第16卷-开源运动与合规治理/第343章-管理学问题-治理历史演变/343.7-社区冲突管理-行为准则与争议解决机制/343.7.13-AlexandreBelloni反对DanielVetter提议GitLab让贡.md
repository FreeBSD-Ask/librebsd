# 343.7.13 AlexandreBelloni反对DanielVetter提议GitLab让贡

2018-09-12 Alexandre Belloni 反对 Daniel Vetter 提议 GitLab 让贡献者参与更省事,认为小型子系统(如 RTC、codec、IIO、hwmon)贡献者多为一次性、非全职,无法承担初始设置成本;Vetter 主张 "makes the 90% so much easier",Belloni 则用 git shortlog 数据对比 RTC 与 DRM,指出 RTC 驱动一个补丁即可上线、后续补丁并非来自维护者,DRM 则依赖少数大公司团队。
