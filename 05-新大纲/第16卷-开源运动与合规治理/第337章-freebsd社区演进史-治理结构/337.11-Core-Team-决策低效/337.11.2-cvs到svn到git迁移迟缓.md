# 337.11.2 CVS 到 SVN 到 Git 迁移迟缓

  **要点**：FreeBSD 1993-2008 年使用 CVS，2008-2020 年使用 SVN，2020 年迁移至 Git，相比 Linux（2002 即采用 BitKeeper 后转 Git）迟缓约 8-15 年
  **史料**：FreeBSD 2008 SVN 迁移公告、2020 Git 迁移 freebsd-hackers 讨论、Linux BitKeeper 2002-2005 历史 ［A］
  **史观**：专题语（不设条号）：版本控制工具的采用速度受治理模式影响——FreeBSD 的 CVS→SVN→Git 三段迁移迟缓与 Linux 的快速切换形成治理结构对照（原挂“总纲第 19 条——信息技术工具采用速度受治理模式影响”，基线第 19 条为“解释学循环是历史认识的根本条件”，主题对不上基线，按 R2140 先例改不设条号专题语——2026-09-12 整改）
  **辨析**：FreeBSD 2008 年为何选 SVN 而非 Git 需查讨论；2020 年迁移是否因外部压力（如 GitHub 流行）需考据
  **文献**：FreeBSD SVN Migration Announcement 2008；FreeBSD Git Migration 2020 Documentation ［A］
