# 337.3.1 Committer 制度与权限模型


306.3 **committer 制度与文档贡献者**——参见相关章节 Committer's Big List of Rules

  **要点**：FreeBSD committer 制度赋予直接修改 src/ports/doc 仓库权限，新 committer 需现有 committer 提名并经 Core Team 批准
  **史料**：Committer's Guide 历年版本、FreeBSD src/ 仓库 access list、Core Team 提名公告 ［A］
  **史观**：专题语（不设条号）：committer 权限模型是社区治理的形式主义化呈现（原挂“总纲第 23 条——社区治理”非基线条名，按权威表改写）
  **辨析**：committer 提名是否需“投票”还是“共识”需查 Committer's Guide；权限分级（full/src only/ports only）的演变需追溯
  **文献**：FreeBSD Committer's Guide；FreeBSD src/ repository ACL ［A］
