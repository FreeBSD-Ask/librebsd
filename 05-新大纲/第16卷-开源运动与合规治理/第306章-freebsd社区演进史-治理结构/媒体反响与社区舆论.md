## 批评类

### 新闻条目 1

- **新闻标题（中英）**：The Linus Files, Part Two: Torvalds Says GPLv3 Backers Full of Hot Air / Linus 档案之二：Torvalds 称 GPLv3 支持者 “满嘴空话”
- **新闻来源**：InformationWeek + 发布日期 2006-09-21 + URL `<https://www.informationweek.com/it-sectors/the-linus-files-part-two-torvalds-says-gplv3-backers-full-of-hot-air-`>
- **新闻摘要**：Linus Torvalds 公开称 FSF 的 GPLv3 支持者为 “hypocrites”（伪君子），并称 FSF 领导层 “controlling”（控制欲强）、“condescending”（居高临下）、“full of hot air”（满嘴空话）。Torvalds 明确表示 Linux 内核将保持 GPLv2，不会迁移至 GPLv3，并对 GPLv3 的 anti-Tivoization 条款表示反对。
- **与本章主题的关联说明**：揭示 Linus Torvalds 在 GPL 内部分裂（GPLv2 vs GPLv3）中的立场，与 BSD 阵营对 FSF 控制欲的批评形成呼应，是本章 “H 类 Linus Torvalds 个人立场” 小节的关键史料。
- **与官方史料的交叉验证结论**：Torvalds 在 Linux 内核邮件列表（LKML）的多次发言与 InformationWeek 报道一致。Linux 内核主目录 `COPYING` 文件至今标注 “GPL-2.0 only WITH Linux-syscall-note”，与 Torvalds 立场一致。

## 冲突类

### 新闻条目 1

- **新闻标题（中英）**：Linux Leader Torvalds Blasts Free Software Movement / Linux 领袖 Torvalds 猛轰自由软件运动
- **新闻来源**：CRN（Channel Reseller News）+ 发布日期 2006-09-19 + URL `<https://www.crn.com/news/applications-os/191600924/linux-leader-torvalds-blasts-free-software-movement`>
- **新闻摘要**：在 FSF 发布 GPLv3 草案期间，Torvalds 再次公开批评 FSF，称其将 “自由软件” 与 “GPL 强制” 混为一谈。Torvalds 区分 “open source”（开源）与 “free software”（自由软件），明确自认开源派而非自由软件派，与 BSD 阵营立场更接近。
- **与本章主题的关联说明**：反映 Torvalds 在 GPL/BSD 论战中实际上偏向 BSD 阵营的 “实用主义开源” 立场，是本章 “开源运动内部分裂” 小节的关键史料。
- **与官方史料的交叉验证结论**：CRN 报道与 Torvalds 在 2006-2007 年 LKML 多次发言时间一致，与 Torvalds 自传《Just for Fun》及 2007 年 Linux Foundation 峰会发言互证。

## 里程碑事件类

### 新闻条目 1

- **新闻标题（中英）**：Eric Raymond talks about GPL and BSD licenses / Eric Raymond 谈 GPL 与 BSD 许可证
- **新闻来源**：OSNews + 作者 Eugenia Loli + 发布日期 2005-06-16 + URL `<https://www.osnews.com/story/10868/eric-raymond-talks-about-gpl-and-bsd-licenses/`> + 同步转载 Linux.com `<https://www.linux.com/news/eric-raymond-talks-about-gpl-and-bsd-licenses/`>
- **新闻摘要**：Eric Raymond 在 2005 年 FISL（Fórum Internacional de Software Livre，巴西阿雷格里港）会议上为开源模式辩护时称："Basically, we don‘t need GPL. It’s based on the belief that open source software is weak and needs to be protected. With it, we continue injuring ourselves, cutting ourselves from the economic benefits of BSD license."（基本上，我们不需要 GPL。它建立在开源软件弱小、需要保护的前提之上。沿用 GPL，我们等于持续自残，割裂与 BSD 许可证经济效益的联系。）
- **与本章主题的关联说明**：这是 OSI 联合创始人 Eric S. Raymond 在公开场合对 GPL 与 BSD 许可证之争的最直接表态，是本章 “H 类著名人物报道” 与 “BSD vs GPL 论战” 小节的标志性事件，体现开源阵营内部分歧。
- **与官方史料的交叉验证结论**：原始报道链接 `myfreebsd.com.br/static/raymond-20050604.html` 已失效，但 OSNews 与 Linux.com 双源互证，且 Raymond 本人博客 `esr.ibiblio.org` 多次重申相似立场，引文可信。

### 新闻条目 2

- **新闻标题（中英）**：FSF's Richard Stallman Calls LLVM a ‘Terrible Setback’ / FSF 的 Richard Stallman 称 LLVM 是 “可怕的倒退”
- **新闻来源**：Slashdot（news.slashdot.org）+ 发布日期 2014-01-24 + URL `<https://news.slashdot.org/story/14/01/24/1838241/fsfs-richard-stallman-calls-llvm-a-terrible-setback`>
- **新闻摘要**：Richard Stallman 在 GCC vs Clang/LLVM 邮件列表讨论中称 LLVM 是 “可怕的倒退”，因为 LLVM 采用 BSD 风格许可证而非 GPL。RMS 写道：“For GCC to be replaced by another technically superior compiler that defended freedom equally well would cause me some personal regret, but I could congratulate them and wish them well. But GCC to be replaced by a compiler that does not defend freedom well — that would be a terrible setback.”（GCC 被另一个技术上更好且同样捍卫自由的编译器取代，我会遗憾但可祝贺；但被一个不捍卫自由的编译器取代，则是可怕的倒退。）
- **与本章主题的关联说明**：这是 2014 年前后 FreeBSD 推进 Clang/LLVM 迁移以 “许可证纯洁化” 背景下，FSF 创始人对 BSD 风格许可证扩展的公开批评，反映 GPL 阵营对 BSD 许可证侵蚀 GCC 垄断地位的焦虑，是本章 “G 类 FSF 官方通讯” 与 “LLVM/Clang 许可证之争” 小节的关键史料。
- **与官方史料的交叉验证结论**：Stallman 的邮件原文存档于 GCC 邮件列表（`gcc.gnu.org/ml/gcc/`），Slashdot 报道与邮件列表原文一致。事件时间与 FreeBSD 10.0（2014-01-20 发布）弃 GCC 转 Clang 几乎同步，反映许可证论战与现实工程决策的耦合。

### 新闻条目 3

- **新闻标题（中英）**：The BSD License Problem / BSD 许可证问题
- **新闻来源**：GNU Project / Free Software Foundation 官方文档 + URL `<https://www.gnu.org/licenses/bsd.html`>
- **新闻摘要**：FSF 官方对 BSD 许可证的立场文档，指出 1999 年前 BSD 许可证含 “obnoxious BSD advertising clause”（令人不悦的 BSD 广告条款），要求所有广告材料必须承认 Berkeley 贡献。FSF 称该条款导致 “obnoxious BSD advertising clause” 问题，并推动 BSD 在 1999 年改为 2-Clause 形式以去除该条款。文档同时将 FreeBSD 许可证、Expat 许可证、X10/X11 许可证归为 “simple non-copyleft free software licenses”。
- **与本章主题的关联说明**：这是 FSF 对 BSD 许可证最系统性的官方立场陈述，揭示 FSF 承认 1999 年后 BSD 2-Clause 已是 “自由软件许可证”，但仍坚持 copyleft 优于 non-copyleft。是本章 “G 类 FSF 官方通讯” 小节的核心一手史料。
- **与官方史料的交叉验证结论**：文档位于 `gnu.org` 官方域，属 GNU Project 正式发布文档。1999 年 BSD 许可证从 4-Clause 改为 2-Clause 的事实与 FreeBSD 源码 commit log（1999-07-18 由 <ghost@FreeBSD.org> 提交）一致。

### 新闻条目 4

- **新闻标题（中英）**：Linus Torvalds on Why Open Source Solves the Biggest Problems / Linus Torvalds 谈开源为何能解决最大问题
- **新闻来源**：The New Stack + URL `<https://thenewstack.io/linus-torvalds-on-why-open-source-solves-the-biggest-problems/`>
- **新闻摘要**：Torvalds 回顾其在 1990 年代 “充满 flame wars” 的 BSD 与 GPL 许可证之争中选择 GPLv2 的决策过程，称此后数十年的变化均为 “incremental”（渐进式）。他承认当时 BSD 衍生源码虽存在但价格高昂（约 2 万美元），直到 Linux 发布后 386BSD 才免费开放。
- **与本章主题的关联说明**：Torvalds 对 BSD vs GPL 论战历史地位的回顾性陈述，提供 1990 年代早期 BSD 源码商业化壁垒的关键细节，是本章 “1990 年代 BSD vs GPL 论战背景” 小节的口述史料。
- **与官方史料的交叉验证结论**：386BSD 于 1992-02 发布免费版本，Linux 0.01 于 1991-09 发布，时间顺序与 Torvalds 陈述一致。“BSD 源码约 2 万美元” 指 1990 年代早期 BSD/OS（BSDi 商业产品）授权费，与 BSDi 1991 年价格表互证。
