**要点**：

- FreeBSD 发布新版行为准则，核心团队成员 Benno Rice 在访谈中说明：首个准则是在 gamergate 相关风波后的应激产物，新准则以 geek feminism 反骚扰政策为底本，采取报告驱动而非禁止模式，由 conduct@freebsd.org 的五人审查团队受理，重大处分须上报 core 团队并允许上诉。（BSD Now EP234，[1021.5-2144.3]，L1）
- Benno Rice 自述曾任职 Isilon（Dell EMC），后加入 iXsystems；其当前工作包括为 FreeBSD 安装镜像实现 hybrid boot，使单个镜像可同时作为 CD 与 USB 启动，方案源自对 GRUB hybrid boot 的反向工程。（BSD Now EP234，[2153.4-2241.3]，L1）
- iocage 教程演示其作为 jail 命令的替代管理 FreeBSD jail：激活后拉取 FreeBSD 11.1 镜像、创建带 IP 的 jail、经 loopback 接口与 PF NAT 联网，并可在 jail 内安装 Apache 或以前端 jail 反代到多个后端 jail。（BSD Now EP234，[525.3-757.7]，L2）
- Landon Fuller 自 2015 年起受 FreeBSD Foundation 赞助改进 Broadcom Wi-Fi 支持，2016 年初提交 BHND 驱动家族以统一 SSB 与 BCMA 总线接口，并完成将 BWN 软 MAC 驱动移植到 BHND、初步支持 BCM43224 与 BCM43225。（BSD Now EP234，[3511.3-3899.5]，L2）
- Lib Hijack 文章展示利用 FreeBSD 默认开启的非特权 ptrace 创建匿名内存映射、注入代码并劫持 PLT/GOT，称其绕过 wrapper 式 Capsicum，建议默认关闭 security.bsd.unprivileged_proc_debug 并实现 pax noexec。（BSD Now EP234，[2529.5-2872.4]，L2）
- 2016 年 FreeBSD 核心团队改选之际，澳大利亚开发者 Benno Rice（1994 至 1995 年间开始使用 FreeBSD，2000 年因架设新闻服务器与参与 PowerPC 移植获提交权，时任 EMC Isilon 操作系统与网络管理者）作为候选人系列首位受访者在访谈中诊断：项目内部氛围友善，对外却近乎封闭，非提交者找不到清晰的补丁提交与接纳路径，Bugzilla 中大量问题报告积压数年，正如其所言“每一个积压的报告都代表着一个我们失去的潜在贡献者”（791.44-797.35）；他主张统计非提交者代码占比并设定目标值，以量化指标倒逼贡献渠道改革。（BSD Now EP145，[767.2-816.4]，L1）[订正：原 [772.55-797.35]，2026-09-30 SenseAudio 重转核对]
- 在改革路径上，Benno Rice 借鉴 linux.conf.au 2016 上 Mozilla Rust 项目开发者 Emily Dunham 的新人引育实践（定期通讯致谢首次贡献者、公开可循的贡献路径），主张 FreeBSD 亟需一份得到“可见地执行”的行为准则（676.32-690.00），并强调“编码并非回馈项目的唯一方式”（612.08-623.40），运维、文档与测试自动化同样是项目承重结构；对于 GitHub，他的判断是“全有或全无 proposition”（1398.94-1407.82）——现状的半接入镜像只会让外部补丁继续沉没，若不采纳 GitHub，则必须让 Bugzilla 与 Phabricator 的整合达到等效的低摩擦体验。（BSD Now EP145，[522.2-1465.6]，L1）[订正：原 [524.67-1460.08]，2026-09-30 SenseAudio 重转核对]
- 本期转述 pkgsrc 第 50 版发行之际对核心开发者 Jörg Sonnenberger 的采访：这位数学背景出身、以兴趣驱动参与开源的开发者称 quarterly 季度分支正是他十余年前关注 pkgsrc 的起点，第四十个分支的通过既是个人里程碑，也令他在回望时“既自豪于已有的成就，也对随时间消逝的面孔与名字感到一丝伤感”（2534.54-2545.26）；他将 pkgsrc 的核心价值概括为在 NetBSD、SmartOS 及多种 Linux、Solaris 之间提供一套一致的软件包体系，当前工作聚焦 Clang 构建排错、恢复 pbulk 批量构建并降低主从构建机耦合，pkgsrcCon 2016 定于 7 月 1 日至 3 日在波兰克拉科夫举行。（BSD Now EP145，[2478.0-2688.1]，L2）[订正：原 [2481.47-2663.78]，2026-09-30 SenseAudio 重转核对]

**史观**：

- 总纲6 和解优于斗争：新版行为准则以报告驱动而非禁令的方式为多元背景参与者提供安全空间，把不同群体的共存置于社区治理核心，体现和解优于对抗的社区伦理。（BSD Now EP234，[1410.9-1449.2]，L1）
- 总纲10 动手者创造历史：Landon Fuller 多年默默推进 BHND 驱动并使其覆盖消费级 Broadcom 设备，Benno Rice 以反向工程实现 hybrid boot，均为动手者在系统基础设施上的真实积累。（BSD Now EP234，[3511.3-3899.5]，L2）
- 总纲10 动手者创造历史：Benno Rice 反复强调，维系 FreeBSD 的不只是提交代码的程序员：长期义务运维集群的 Glenn Barber、文档作者、测试体系的建设者同样是项目的生命线，项目甚至应考虑由基金会出资设立测试自动化岗位（655.64-665.74）——这一立场把“谁在创造历史”的追问从台前的明星提交者扩展到日常维持系统运转的动手者，与本书记录默默做事之人的取径一致。（BSD Now EP145，[604.7-679.5]，L1）[订正：原 [605.44-665.74]，2026-09-30 SenseAudio 重转核对]
- 总纲22 知识注定过时：Colin Percival 2007 年前后为 FreeBSD 重写并调优的 SHA-256 与 SHA-512 实现，到 2016 年因处理器微架构转向偏好访存指令而非大代码足迹而再度被重排提速：2008 年前的旧平台收益近零，2013 至 2015 年的平台则获得两成以上吞吐提升，Raspberry Pi 2 亦有 6% 至 8% 进益——曾被证明“当时最优”的代码终究随硬件土壤变迁而过时，优化不是一次性的抵达而是持续的再适配。（BSD Now EP145，[2344.52-2459.03]，L2）

**辨析**：

- [存疑脚注] 行为准则的起源、gamergate 关联与审查团队运作方式系 Benno Rice 受访者一方解释，须与 FreeBSD 官方文档及多方记录交叉核验。 [存疑脚注] CoC 起源与机制系受访者解释。（BSD Now EP234，[1300.0-2144.3]，L4）
- [考据脚注] BHND 驱动支持范围、提交时间与 BCM 芯片型号系博客转述，须以 FreeBSD 版本库与 FreeBSD Foundation 项目记录为准。 [考据脚注] BHND 细节系博客转述。（BSD Now EP234，[3511.3-3899.5]，L4）
- 针对 Reddit 传言“FreeBSD 计划彻底移除 ports、人人应改用 packages”，主持人给出澄清式辨析：ports 不会消失，packages 本就全部由 ports 构建而来，二者是同一分发体系的两种形态而非替代关系；项目鼓励默认选项即可满足的用户转向 packages，而 ports 至少会作为 packages 的构建框架长期存在，特殊配置需求者仍可自建 Poudriere 实例按需编译——这一表态为 2016 年前后 ports 与二进制包的路线之争划定了社区口径。（BSD Now EP145，[3052.6-3158.0]，L2）[订正：原 [3056.22-3128.42]，2026-09-30 SenseAudio 重转核对]
- 关于 jails 管理工具的选型，主持人 Allan Jude 以 iXsystems 管理层身份说明 Warden 已在其团队内部停止开发、由 iocage 接棒并吸收 ezjail 的 base jail 等特性，但工具格局并非非此即彼：iocage 深度依赖 ZFS 的数据集与克隆能力，UFS 用户只能选择 ezjail，CBSD 亦属可选项，手动管理随 rc 脚本与标签机制的改进而愈发可行——选型最终取决于文件系统与个人偏好，不存在唯一正解。（BSD Now EP145，[3129.05-3315.16]，L1）
