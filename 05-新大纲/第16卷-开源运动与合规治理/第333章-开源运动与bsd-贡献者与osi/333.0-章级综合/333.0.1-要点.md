# 333.0.1 要点

- BSD 社区在 OSI 中的代表：(1) BSD 社区未派遣代表长期参与 OSI 决策；(2) OSI 早期决策（OSD 制定）主要由 Perens、Raymond 等 Linux 阵营主导；(3) BSD 许可证在 OSD 制定中被作为 “原型” 引用但 BSD 社区未参与制定；(4) BSD 社区在 OSI 中代表性不足
- BSD 许可证在开源定义中的参与：(1) BSDL 作为 OSD 原型被引用；(2) Perens 在 OSD 制定中参考 BSDL；(3) BSD 社区未主动参与 OSD 起草；(4) OSD 部分条款（如无歧视、技术中立）与 BSDL 精神一致
- 被忽视的 BSD 开源运动推广者：(1) Kirk McKusick 长期教学与演讲推广 BSD；(2) Jordan Hubbard 早期 FreeBSD 推广；(3) Poul-Henning Kamp（波尔-亨宁·坎普） 在欧洲推广 BSD；(4) 各 BSD 会议组织者；这些推广者长期未被主流开源运动叙事记录
- 边缘贡献者史料疑点：(1) BSD 在 OSI 早期是否真有代表；(2) McKusick 在 Open Source 运动中的具体角色；(3) Hubbard 离开 FreeBSD 后是否仍推广 BSD；(4) Kamp 在欧洲 BSD 推广的具体贡献
- Linux 在开源运动中的主导地位：(1) Linus Torvalds 的 “独裁” 模式（最终决策权）成为开源运动典型；(2) Linux Foundation（2007 年由 OSDL 与 FSG 合并）是最大开源基金会，预算数亿美元；(3) Linux 是 OSI 与 Open Source 运动的旗舰项目；(4) Linux 在企业、云、移动（Android）三大市场主导
