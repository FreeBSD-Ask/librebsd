# 332.5.2 Open Source 去政治化对 BSD 的消解

  **要点**：Open Source 一词去政治化对 BSD 哲学的消解：(1) BSD 哲学强调 “代码在那里，拿走就好” 的低调；(2) Open Source 运动强调 “开放作为商业策略”；(3) BSD 低调哲学被 Open Source 话语淹没；(4) BSD 社区未主动表达自身哲学，导致被消解
