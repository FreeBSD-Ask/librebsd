# 332.3.3 FreeBSD 2021 年 Git 迁移与 GitHub 适应

  **要点**：FreeBSD 于 2020 年 12 月决定从 SVN 迁移至 Git，2021 年 1 月正式完成；官方仓库托管于 git.freebsd.org（自托管）与 GitHub 镜像（cgit 风格只读镜像）；FreeBSD 未采用 GitHub PR 作为主要贡献方式（仍通过 Phabricator/邮件提交），但 GitHub 镜像提升可见性
  **史料**：FreeBSD 2020.12 Git 迁移公告、GitHub 镜像说明；freebsd.duckdb freebsd-doc 仓库 2021-03 至 2021-06 间 GitHub 主题 commit 共 10 余条，反映 doc 仓库的 Git 迁移文档更新集中在 2021 年 3 月至 6 月：

  **史观**：偶然性改写历史，2020 年迁移是 FreeBSD 工具链关键转折
  **辨析**：FreeBSD 是否完全接受 GitHub PR，须查当前文档；freebsd.duckdb freebsd-doc 仓库的 Git 迁移主题 commit 显示原大纲 “2021 年 1 月正式完成” 叙事在 doc 仓库层面需修正——doc 仓库的 Git 迁移文档更新集中在 2021-03-16 至 2021-06-16，说明 doc 仓库的实际迁移完成时间在 2021 年 3 月中旬而非 1 月；2021-06-03 Warner Losh “how to merge a pull request from github” commit 证明 FreeBSD 在 2021 年 6 月已正式接受 GitHub PR，原大纲 “未采用 GitHub PR 作为主要贡献方式” 叙事需修正——FreeBSD 已在 2021 年 6 月将 GitHub PR 处理写入 Committers Guide；0 信任原则适用说明：commit message 仅反映 doc 仓库的文档更新，src/ports 仓库的实际 Git 迁移完成时间须另行查询；Warner Losh 为 2020-2021 年 FreeBSD Git 迁移的核心推动者，其 commit 集中反映迁移过程；FreeBSD SVN-to-Git 迁移自身的 commit 历史在 freebsd.duckdb 中完整保存——2020 年前的 SVN commit 与 2020 年后的 Git commit 均已统一存储；推论有效性边界：doc 仓库的迁移文档更新时间仅代表 doc 仓库层面，不能直接外推为 src/ports 仓库乃至项目整体的迁移完成时间，整体完成时间须以 src 仓库 commit 证据另行考据
