# 332.1.1 Apache 软件基金会 1999 年成立

  **要点**：Apache 软件基金会（ASF）于 1999 年 3 月成立，前身是 1995 年的 Apache Group（Brian Behlendorf（布莱恩·贝伦多夫）、Cliff Skolnick 等维护 NCSA HTTPd 衍生的 Apache 服务器）；ASF 组织模式借鉴 BSD 精英评审模式（committer、PMC、member 三层）；ASF 是除 FSF 与 OSI 外最具影响力的开源组织
  **史料**：ASF 1999 年成立公告、Apache Group 历史、Behlendorf 访谈 ［B］
  **史观**：BSD 与 UNIX 谱系的连续性，Apache 继承 BSD 开源传统
