# 331.2.4 Open Source 一词对 BSD 社区的冲击

  **要点**：Open Source 一词对 BSD 社区的冲击：(1) BSD 长期 “已开源” 但不在新话语中；(2) BSD 社区被动接受 Open Source 标签；(3) BSD 在新话语中被 Linux 抢占焦点；(4) BSD 社区未主动参与命名政治学，导致话语权丧失
  **史料**：BSD 邮件、社区讨论［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］
  **史观**：话语权与边缘者
  **辨析**：BSD 是否真被冲击，需独立判断
