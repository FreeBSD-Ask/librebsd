# 331.3.3 OSI 认证许可证体系与 BSD 变体

  **要点**：OSI 认证许可证体系涵盖 80 余种许可证，BSD 变体包括：(1) 两条款 BSD（FreeBSD 修订版）；(2) 三条款 BSD（BSD-New，含 no-endorsement 条款）；(3) 四条款 BSD（旧 BSD，含 advertising 条款，1999 年被 OSI 重新评估后仍认证）；OSI 认证允许 BSD 系代码在 Open Source 体系内流通
