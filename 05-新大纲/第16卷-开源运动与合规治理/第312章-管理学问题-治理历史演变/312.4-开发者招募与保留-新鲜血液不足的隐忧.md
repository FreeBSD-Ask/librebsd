# 312.4 开发者招募与保留——新鲜血液不足的隐忧

## 312.4.1 committer 招募瓶颈与 编程之夏 转化率

**要点**：FreeBSD committer 数量从 2000 年代高峰约 400 人逐步下降，新增 committer 速度低于退休速度（“18 个月不活跃自动退休” 条款）；mentor 制度（新 committer 须由现有 committer 担保）是招募机制核心，但 mentor 数量不足形成瓶颈；Google 编程之夏（编程之夏，2005 年起 FreeBSD 参与）是新鲜血液主要来源，但 编程之夏 贡献者转为长期 committer 的比例偏低；2020 年代 GitHub 迁移后 PR 流程简化，外部贡献者门槛降低但转 committer 路径仍受 mentor 瓶颈制约

**史料**：FreeBSD committers 列表、编程之夏 项目档案 2005-2025、freebsd-hackers 关于招募的讨论、GitHub PR 统计［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］〔L2 即时通讯记录〕

**史观**：边缘者贡献，新鲜血液不足反映社区对新人融入机制的不足
