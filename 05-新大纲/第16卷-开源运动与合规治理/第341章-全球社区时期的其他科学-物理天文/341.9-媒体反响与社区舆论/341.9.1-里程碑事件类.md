### 新闻条目 1

- **新闻标题（中英）**：ISO/IEC 27001:2022 Information security, cybersecurity and privacy protection — Information security management systems — Requirements / 信息安全、网络安全与隐私保护——信息安全管理体系——要求
- **新闻来源**：国际标准化组织（ISO）官方 + URL `<https://www.iso.org/standard/27001`>
- **新闻摘要**：ISO/IEC 27001:2022 于 2022-10 发布（Edition 3，参考编号 82875），是 ISO/IEC 27001 标准的第三版，取代 ISO/IEC 27001:2013。标准定义信息安全管理体系（ISMS）要求，为各类规模与行业的组织提供建立、实施、维护与持续改进 ISMS 的指导，遵循风险管理与运营卓越的最佳实践与原则。
- **与本章主题的关联说明**：这是 ISO/IEC 27001:2022 标准的官方发布页面，是本章 “J 类 ISO 官方文档” 与 “ISO 27001:2022 框架” 小节的核心一手史料。
- **与官方史料的交叉验证结论**：`iso.org` 为 ISO 官方域名，版本号（Edition 3）、发布时间（2022-10）、参考编号（82875）与 ISO Catalog 一致。

### 新闻条目 4

- **新闻标题（中英）**：Amazon AWS 喜获 ISO 27001 认证 / Amazon AWS Receives ISO 27001 Certification
- **新闻来源**：InfoQ 中国 2010-11-27 转载 AWS 官方博客 + URL `<https://www.infoq.cn/article/2010/11/aws-certification`>
- **新闻摘要**：2010-11 Amazon Web Services（AWS）被授予 ISO/IEC 27001 认证。认证含 3 阶段审计：阶段 1 审核 ISMS 规章制度；阶段 2 由独立审计员进行 ISO/IEC 27001 详细法规审计；阶段 3 维护阶段含周期性后续审核（通常每年一次）。AWS 同时实施 ISO/IEC 27002 指南，覆盖 EC2、S3、VPC 等服务。Salesforce.com 早于 AWS 获得该认证，微软亦积极推进 BPOS 的 ISO 27000 家族认证。
- **与本章主题的关联说明**：这是 AWS（BSD 商业下游代表，Netflix 等基于 FreeBSD 的服务部署于 AWS）获得 ISO 27001 认证的早期里程碑报道，是本章 “BSD 商业下游与 ISO 27001” 小节的关键一手史料。
