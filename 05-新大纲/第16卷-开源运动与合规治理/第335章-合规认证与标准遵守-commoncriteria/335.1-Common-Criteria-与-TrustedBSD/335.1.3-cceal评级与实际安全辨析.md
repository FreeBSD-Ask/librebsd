# 335.1.3 CC EAL 评级与实际安全辨析

  **要点**：CC EAL 评级衡量的是评估过程的严格程度而非产品本身的安全程度，FreeBSD 未通过 CC 认证但通过 TrustedBSD 工程实现实质安全功能
  **史料**：Common Criteria Evaluation Methodology、NIAP Protection Profiles 列表、TrustedBSD 文档［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］〔L3 官方文档与公告〕
  **史观**：形式主义膨胀，EAL 评级作为形式化认证与实际安全的差距
  **辨析**：EAL 4+ 与 EAL 5+ 的实际差异需查 Common Criteria 评估方法学；某些通过 EAL 4+ 的产品被发现严重漏洞（如 Juniper 2015 backdoor）说明 EAL 评级非安全保证
