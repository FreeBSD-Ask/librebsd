# 335.1.1 CC/EAL 标准体系与认证格局


103.7 **Common Criteria 与 TrustedBSD**———Common Criteria（CC，通用准则）是 ISO/IEC 15408 国际标准，1996 年 CC 2.0 草案发布（由美、加、英、法、荷五国联合制定），1999 年 12 月 ISO/IEC 15408:1999 正式发布，2005 年 ISO/IEC 15408:2005 发布，2017 年 ISO/IEC 15408:2017 发布（CC v3.1 r5）

  **要点**：Common Criteria（CC）是 ISO/IEC 15408 国际标准，EAL（Evaluation Assurance Level）1-7 评级衡量验证严格程度而非安全程度，FreeBSD 本身未通过 CC 认证

| CC 版本 | 发布年份 | ISO 编号 | 备注 |
| ----- | ------ | ------ | -- |
| CC 2.0 草案 | 1996 | - | 由美、加、英、法、荷五国联合制定 |
| CC v3.1 R5 | 2017-04（待确认） | ISO/IEC 15408:2017 | 历史版本，PDF 路径 CCv3.1R5-CCRA.pdf 返回 404 |
| CC: 2022 Release 1 | 2022 | - | 当前版本，配套 CEM: 2022 评估方法学 |

| Part 3 | Security assurance requirements |
| Part 4 | Framework for the specification of evaluation methods and activities |

| EAL 评级 | 含义 | FreeBSD 状态 |
| ------ | -- | ---------- |
| EAL 1-7 | 衡量验证严格程度而非安全程度 | FreeBSD 本身未通过 CC 认证 |
| CCRA | Common Criteria Recognition Arrangement，声明各版本间 EAL 评级等价 | - |

> EAL 评级衡量的是评估过程的严格程度而非产品本身的安全程度。
>
> ——Common Criteria 社区共识
