# 335.1.2 TrustedBSD 安全功能工程演进

  **要点**：TrustedBSD 子项目由 Robert Watson 等于 2000 年发起（2000-04-09 初始公告，trustedbsd.org 官网自述 Started in April 2000），引入 POSIX.1e ACL、Capability、Mandatory Access Control（MAC）框架，2003 年合入 FreeBSD 5.0[考据完成：2026-08-04 权威核验（trustedbsd.org 官网一手 ‘Started in April 2000’ + trustedbsd.net 新闻时间线 2000-04-]
  **史料**：TrustedBSD 项目主页存档、Watson 2001 USENIX 论文、FreeBSD 5.0 release notes ［A］
  **史观**：总纲第 9 条——企业研究的双重性，TrustedBSD 受 DARPA/NSA 资助又服务于开源社区；统计结论印证：统计结论 [E-21] NVD FreeBSD 相关 CVE 421 个（NVD keywordSearch 查询，2026-07-27 三次复查）、统计结论 [E-25] FreeBSD 官方安全公告 FreeBSD-SA 382 条（freebsd.org/security/advisories 官方存档）、统计结论 [E-26] FreeBSD CVE 平均 CVSS 6.24（NVD CVSS 严重程度分布）共同构成 FreeBSD 实质安全工程的量化基础，与 CC EAL 形式认证缺失形成对照——FreeBSD 未通过 CC 认证但以 382 条 SA 与 TrustedBSD MAC 框架实现 “实际遵守但未缴费认证” 的合规路径；freebsd.duckdb 查询显示 freebsd-src CVE commit 1791 条反映安全修复 commit 持续活跃
  **辨析**：TrustedBSD 是否完全合并入 FreeBSD 主线存在争议，部分组件（如 Audit）2003 年合并，其他组件（如 MLS policy）则未合入；TrustedBSD 与 SEBSD（Security-Enhanced BSD）的关系需厘清；【0 信任原则·CVE 数量不等于漏洞数量】统计结论 [E-21] NVD FreeBSD 421 个 CVE 受 NVD CPE 命名完整性影响（FreeBSD 版本命名在 NVD 中可能不完整），且 CVE 披露存在滞后与选择偏差，421 个 CVE 仅为 NVD 收录部分，不等于 FreeBSD 实际漏洞总量；【0 信任原则·SA 公告统计口径】统计结论 [E-25] 382 条 FreeBSD-SA 为官方存档计数，部分早期 SA 可能已归档或合并，数据须与 freebsd-security 邮件列表存档交叉验证；【0 信任原则·CVSS 跨版本不可直接比较】统计结论 [E-26] 平均 CVSS 6.24 含 CVSS v2 与 v3 混合评分，跨版本评分不可直接算术平均，该均值为近似指标；【统计显著 ≠ 实际显著】382 条 SA 与 421 个 CVE 的数量对比不直接等同于安全响应质量，须结合修复滞后时间、回溯补丁覆盖率等指标综合判断；详见外部基准-Academic-CVE.md 第 2 节与考据记录 20260727_第十二卷-统计学整合.md
  **文献**：Watson 2001"TrustedBSD: Adding Trusted Operating System Features to FreeBSD"USENIX；FreeBSD 5.0 Release Notes ［B］
