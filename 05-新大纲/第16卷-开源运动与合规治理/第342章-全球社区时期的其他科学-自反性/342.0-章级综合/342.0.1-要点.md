# 342.0.1 要点

- BSD 市场份额持续下滑的虚无主义意味须通过哲学分析明确；BSD 代码散逸而不回馈的散逸宿命须通过代码分发统计核查；BSD 项目可能的消亡作为虚无本体论的实例须通过哲学分析明确
- 虚无主义视角随 BSD 边缘化加剧而深化——从单纯的市场份额下滑分析转向虚无本体论的实例；演变须通过 BSD 史书写档案分析
- BSD 虚无主义与一般虚无主义的差异在于 BSD 虚无主义明确以技术史为实例；一般虚无主义多侧重存在或价值；比较须控制哲学框架与研究对象变量
- 虚无主义史料以 BSD 史书写档案、市场份额统计、哲学研究为主，缺乏系统性的学术研究；市场份额统计须警惕分类标准变化；哲学研究须警惕理论先行
- BSD 开发者 “动手者” 的存在主义含义须通过加缪 “推石上山的西西弗斯” 哲学分析明确；会者定离的存在主义时间性须通过社区变迁档案核查；BSD 开发者在 “无意义” 中坚持开发的存在主义姿态须通过开发者访谈与提交日志验证；“日复一日即是修行” 的加缪式反抗须通过哲学分析明确
