# 342.6.3 BSD 与 Linux 科学合规比较

  **要点**：BSD 与 Linux 科学合规的差异：BSD 许可证（BSD-2/3-Clause）仅要求保留版权与免责声明，合规重心在归属声明保留与免责条款传递；Linux 内核 GPLv2 要求衍生作品按 GPLv2 分发，合规重心还包括 copyleft 义务履行与源码提供。企业支持模式上，Linux 生态以厂商认证与合规服务体系为主，BSD 生态以基金会、社区文档与邮件列表协作为主
  **史料**：BSD-2-Clause 与 BSD-3-Clause 文本（Open Source Initiative <https://opensource.org/licenses/BSD-2-Clause>、<https://opensource.org/licenses/BSD-3-Clause>）；GNU GPLv2 文本（<https://www.gnu.org/licenses/old-licenses/gpl-2.0.html>）；Regulation (EU) 2016/679（EUR-Lex 32016R0679）［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］〔L3 官方文档与公告〕
  **史观**：总纲第 4 条——分离聚合是永恒规律：BSD 与 Linux 合规机制的分化与并行，是分离聚合规律在治理层面的体现
  **辨析**：“BSD 合规更侧重许可证合规”须通过具体案例验证；“Linux 合规更侧重企业合规支持”须通过厂商支持档案核查
