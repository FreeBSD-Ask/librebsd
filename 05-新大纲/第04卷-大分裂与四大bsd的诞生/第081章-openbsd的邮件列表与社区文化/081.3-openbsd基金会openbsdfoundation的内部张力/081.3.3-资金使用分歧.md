# 081.3.3 资金使用分歧

  **要点**：OpenBSD Foundation 与 de Raadt 在资金使用上存在分歧——Foundation 主张资金用于项目长期可持续发展，de Raadt 主张资金用于直接工程投入；分歧长期影响 Foundation 运作
  
**史料**：OpenBSD Foundation 董事会会议记录摘要、de Raadt 关于资金使用的公开声明［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档与公告〕
  
**史观**：总纲第 3 条——不存在进步，只有权力再分配（商业与社区的张力）：资金使用分歧反映商业逻辑与社区路线的张力
  
**辨析**：分歧的具体表现在不同叙事中略有差异——需对照 Foundation 决策记录核实
