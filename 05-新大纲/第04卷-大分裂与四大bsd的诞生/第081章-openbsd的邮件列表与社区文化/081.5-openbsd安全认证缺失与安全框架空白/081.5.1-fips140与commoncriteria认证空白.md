# 081.5.1 FIPS 140 与 Common Criteria 认证空白

  **要点**：经 NIST CMVP（Cryptographic Module Validation Program）数据库检索，OpenBSD 从未获得 FIPS 140-2/3 密码模块认证——对比之下，Canonical/Ubuntu 与 Red Hat 均有 FIPS 140-2/3 认证的 OpenSSL 与内核密码模块；Common Criteria 认证亦为空白。FIPS 140-2/3 认证对照如下：

| 项目 | FIPS 140-2/3 认证状态 | 证书示例 |
| -- | ------------------- | ------ |
| OpenBSD | **从未获得** | — |
| Ubuntu | 已获得 | Ubuntu 23.04 OpenSSL Cryptographic Module Cert. **#4292** |
| Red Hat | 已获得 | Red Hat Enterprise Linux 9 Kernel Cryptographic API Cert. **#4796** |
| OpenBSD Common Criteria | **空白** | — |
