# 081.1.2 misc@ 的欢迎仪式

  **要点**：<misc@openbsd.org> 邮件列表对新人提问有特定的 “欢迎仪式”——新人提问常被回应 “先读源码” 或 “this is stupid”；仪式既是 OpenBSD 精英主义的体现也是新人进入的障碍
  
**史料**：<misc@openbsd.org> 邮件列表历年存档、OpenBSD 官方 FAQ、新人经历访谈录 ［A］
  
**史观**：社区文化即技术资产：misc@ 的欢迎仪式是 OpenBSD 精英主义的具体仪式
  
**辨析**：欢迎仪式的正负评估在不同叙事中差异较大——部分视为必要筛选，部分视为不友好；需对照多方公开声明核实
  
**文献**：<misc@openbsd.org> 邮件列表历年存档；OpenBSD 官方 FAQ ［A］
