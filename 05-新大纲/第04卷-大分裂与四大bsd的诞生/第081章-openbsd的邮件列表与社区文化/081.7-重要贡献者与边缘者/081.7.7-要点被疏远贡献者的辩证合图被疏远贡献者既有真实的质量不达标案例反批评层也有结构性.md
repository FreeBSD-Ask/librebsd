# 081.7.7 要点被疏远贡献者的辩证合图被疏远贡献者既有真实的质量不达标案例反批评层也有结构性

  **要点**：被疏远贡献者的辩证合图——被疏远贡献者既有真实的质量不达标案例（反批评层）也有结构性排斥的受害者（批评层与再批评层），二者并非非此即彼；OpenBSD 的精英主义在特定规模（核心开发者约数十人）与特定目标（安全至上代码审计）下具有工程质量保障功能，但这一功能以部分贡献者的疏远为代价——精英主义的 “筛选” 与 “排斥” 是同一机制的不同命名；合图不寻求 “折中” 而寻求揭示精英主义的双重效应——它既是 OpenBSD 安全文化的工程基础（保证代码审计的高标准一致性）也是其人才流失的结构性根源（排斥潜在贡献者与多样性视角）；本体论上，被疏远贡献者与核心开发者在 OpenBSD 安全文化中的贡献地位相等——被疏远贡献者的边缘贡献（如被拒绝但技术正确的补丁、离开后的反思）亦是 OpenBSD 历史的组成部分，不应被排除在叙事之外
  
**史料**：被疏远贡献者案例综合研究、OpenBSD 贡献者流动统计（bsd_commits.duckdb contributors 表）、BSD 三项目（OpenBSD/FreeBSD/NetBSD）贡献者保留率对比、被疏远贡献者与核心开发者的对照访谈录 〔L1 代码/L4 事后叙述/L5 二手研究〕
  
**史观**：本体论上各方平等：被疏远贡献者与核心开发者在 OpenBSD 安全文化中的贡献在本体论上地位相等；动手者创造历史：被疏远贡献者的边缘贡献亦是 OpenBSD 历史的组成部分；解释学循环：被疏远贡献者叙事的评估受前理解差异制约，合图不寻求消除差异而寻求呈现差异
  
**辨析**：考据过程留痕——【查证来源】合图层的关键证据基于 OpenBSD security.html（<https://www.openbsd.org/security.html>，"Our security auditing team typically has between six and twelve members " 经一手核验）的代码审计团队规模、openbsd.duckdb openbsd-src contributors 表（403 名贡献者，deraadt 累计 27,181 commits）的量化证据、OpenBSD goals.html（“ Focus on being developer-oriented in all senses ”）的精英主义定位、OpenBSD KNF 代码风格文档（style.styles(9) 手册页）的质量标准定义；【交叉验证方法】精英主义的“ 质量保障 ”效应与“ 人才排斥 ”效应须以同一组 commit 历史证据同时呈现——openbsd.duckdb openbsd-src contributors 表中核心开发者（deraadt、Brauer、Beck、Friedl 等）的 commit 占比与边缘贡献者的 commit 占比对照，可量化呈现“ 核心圈 ”与“ 边缘圈 ”的工程贡献差距；被疏远贡献者案例与 OpenBSD 官方 errata 历年记录交叉验证，确认被拒绝补丁中是否存在后来被官方 errata 修复的同类问题——若存在，则“ 质量不达标 ”论证不成立；BSD 三项目（OpenBSD/FreeBSD/NetBSD）贡献者保留率对比须以三项目 contributors 表对照核验，OpenBSD 的精英主义是否导致更低的贡献者保留率须以量化数据而非主观印象判断；【存疑判定依据】合图并非辩证链的终结，随新被疏远贡献者自述的出现须重新展开；合图不寻求“ 折中 ”而寻求揭示精英主义的双重效应——“ 质量保障 ”与“ 人才排斥 ”是同一机制的共生效应，不可分割；“ 各打五十大板 ”的折中主义将精英主义的双重效应割裂为可分别评估的独立维度，违反结构性双重效应的本体；“ 质量 ”标准本身的结构性权力——谁定义质量（de Raadt 与核心开发者）、谁执行质量（代码审计团队 6-12 人）、谁被质量排斥（被疏远贡献者），本身就是权力行使；0 信任原则提示：合图层的史观审视本身嵌入项目统摄史观的前理解（总纲第 8 条本体论平等与第 19 条解释学循环），史家须自觉呈现这一前理解而非伪装中立；被疏远贡献者的边缘贡献（如被拒绝但技术正确的补丁、离开后的反思）在本体论上与核心开发者的贡献地位相等，但本体论平等不豁免考据义务——被拒绝补丁的“ 技术正确性 ” 仍须以源码 diff 与 errata 历史交叉验证，不得以本体论平等预先判定
  
**文献**：被疏远贡献者案例综合研究；openbsd.duckdb openbsd-src contributors 表；BSD 三项目贡献者保留率对比研究；被疏远贡献者与核心开发者对照访谈录；OpenBSD security.html [EB/OL]. <https://www.openbsd.org/security.html>；OpenBSD goals.html [EB/OL]. <https://www.openbsd.org/goals.html>；OpenBSD KNF 代码风格文档 style(9) ［A］
