# 081.2.8 BSDTaiwan报名人数预期80注册120余系主持人口述无官方书面数字复核存疑

- BSD Taiwan 报名人数（预期 80、注册 120 余）系主持人口述，无官方书面数字复核。 [存疑脚注] 报名数字系口述，须以会议官方记录核实（BSD Now EP221，[1772.4-1782.4]，L4）
- 转写将多个人名与机构名误转（如“Gambold”“Nanshiao”等），人物身份须核对会议议程。 [存疑脚注] 转写人名拼写不可靠（BSD Now EP221，[1146.76-1173.16]，L4）
- Superfish 事件展示了 SSL 拦截正当性边界由主体身份而非技术本身划定：预装自签根证书、在用户浏览器信任链内伪造站点证书并注入广告，在消费产品上属恶意行为；同样的中间人架构置于企业网络边缘并取得员工知情同意，则可能是合法的内容审查，relayd 的证书拼接功能正以企业部署为设计前提，并提醒各国对未告知监控的法律限制不同。 [存疑脚注] 转写将 Reyk Floeter 失真作“rake floiter”、OPNsense 失真作“OpenSense”、LibreSSL 失真作“Libra SSL”，引用时须以原始博文与发布公告为准。（BSD Now EP78，[649.11-838.61]，L2）
- PC-BSD 将默认防火墙由 PF 切向 IPFW 的决策链条中，主持人转述 Luigi Rizzo 曾重写 IPFW 使其大幅提速，并与 vimage jail 兼容性（PF 搭配 vimage 曾长期导致内核恐慌）、显式规则号、免重编译内核的模块化加载等理由并列；但“Luigi 重写 IPFW”所指的具体版本与年代在节目中未展开，且该说法仅系主持人单一回忆，引用前须回查 FreeBSD 源码提交记录与当时基准测试。 [存疑脚注] “Luigi 重写 IPFW”版本与年代未经节目中其他信息确证；转写亦存在人名与项目名失真，涉及专名处以 FreeBSD 源码与原始发布为准。（BSD Now EP78，[2884.13-2960.21]，L4）
- de Raadt 关于被 NetBSD 逐出与 OpenBSD 创立的叙述属当事人一方陈述，须与 Adam Glass 邮件原文、Core 团队决议等项目考据材料交叉验证。 [存疑脚注] 该叙述为争议事件的单方陈述，须与既有考据记录相互印证。（BSD Now EP6，[508.09-609.45]，L4）
- 关于 Calgary 为全球距 DNS 根服务器最远的 G20 地点、以及 de Raadt 筹建互联网交换中心的说法为主持人转述，具体数据未获权威来源核验。 [存疑脚注] Calgary 互联网交换中心与 DNS 延迟排名的具体数据属二手转述，须以原始邮件与测量资料核验。（BSD Now EP6，[2252.07-2323.19]，L4）
- 约九成八的 SSH 实现为 OpenSSH 且其余多为改名或混淆版本，系当事人无统计来源的口头估计，仅可作为生态集中度的印象性证据。[存疑脚注] 九成八占比为访谈口述估计，未经审计数据交叉验证。 [存疑脚注] OpenSSH 市场占比为当事人口头估计，无第三方统计佐证，引用时须标注为印象性判断（BSDTalk EP228，[432.11-448.88]，L4）
- GoDaddy 已支持 DS 记录与 IPv6 但 Dxtr 等注册商十年未跟进互联网标准，注册商技术能力与 DNSSEC 普及之间的瓶颈关系为当事人单方观察，缺 注册商市场份额数据支撑。[存疑脚注] 单一来源推断。 [存疑脚注] 注册商支持度的判断仅来自当事人个人转商经历，未与行业统计交叉验证（BSDTalk EP228，[1066.29-1116.19]，L4）
- 转写为自动语音识别产物，专名与人名多处误拼（如 LibreSSL 误作 Libra SSL、Sendmail 误作 Zenmail），段落时间戳乱序但文本完整；上一年度超支约两万美元、15 万美元筹款目标等财务数字目前仅见本人口述，须与 OpenBSD 基金会年度财务公告交叉验证后方可引为定论。 [存疑脚注] 财务数字与部分人名拼写仅出自单一口述来源，且 ASR 误拼降低了原文保真度（BSDTalk EP241，[781.86-829.16]，L4）
- 关于播客能否反哺代码与项目，两人判断影响至多间接（听众因而关注某事物），且 OpenBSD 本身受外部影响有限；对号召听众向 OpenBSD Foundation 捐款的效果，Joshua 仅表示“愿意相信有影响”，并无数据佐证。另“OpenBSD 网络慢”的外界印象与 Brandon 的使用经验相悖，双方均无基准测试支撑。[存疑脚注] 捐款带动效果与网络性能评价均系当事人主观判断，待财务数据与性能基准核实。 [存疑脚注] 播客对捐款与代码的间接影响、网络性能口碑之争均无量化证据，仅系当事人自评（BSDTalk EP263，[765.82-843.10]，L4）
- 新闻条目均系 TTS“节点”转述的二手通告，未附原文链接，断代与引用须回溯 NetBSD 官网公告、FreeBSD Foundation 更新原文与 Undeadly 报告；转写将布里斯班 hackathon 记作 A2K12，按 OpenBSD hackathon 命名惯例 2017 年活动疑为 a2k17，须以 Undeadly 原文核实；Ed Maste 之名转写为 Edmast；“获 David Gwynne 支持”的表述含混（资助方为 OpenBSD Foundation），所指待考。[存疑脚注] 以上细节均需以一手公告校正。 [存疑脚注] hackathon 代号、人名拼写与资助表述均系转写转述，未经一手来源核对（BSDTalk EP266，[80.16-122.22]，L4）
- 转写专名失真须回核音频：Spamdy/spam log D/BAMD 均应为 SpamD，Tai Samaka 应为 Ty Semaka，Plattongue Devils 应为 Plaid Tongued Devils，FBWM 应为 fvwm；“Diffsin TCP”与“Lowcore.S”疑为“diffs in tcp”与“locore.s”，无法确证；bigbutts@obtuse.com 轶事及所涉 BSD 期刊名称为受访者单方追述，期刊与色情站点放大链条须另行核实。 [存疑脚注] 发行歌曲参与人员姓名转写失真；TCP/locore.s 提交细节与 bigbutts 轶事的传播链均待音频与外部材料核实（BSDTalk EP68，[1304.22-1417.98]，L5）
