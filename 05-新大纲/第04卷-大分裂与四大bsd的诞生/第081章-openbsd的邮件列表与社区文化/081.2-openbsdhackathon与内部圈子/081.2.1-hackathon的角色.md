# 081.2.1 hackathon 的角色

  **要点**：OpenBSD hackathon（首次 **1999 年 6 月 Calgary**，此后命名为 c2k1、c2k2 等）是核心开发者线下聚会的关键事件——首次 hackathon 完成了 IPv6 与 IPSEC 栈的完整集成（业界首次）；hackathon 承担技术决策、代码审计、新人筛选等多重功能；角色是 OpenBSD 治理结构的关键环节；hackathon 无演讲、无固定日程，核心是同一房间内集中编写代码。hackathon 关键信息如下：

| 项目 | 内容 |
| -- | -- |
| 首次举办时间 | **1999 年 6 月** |
| 首次举办地点 | Calgary |
| 命名惯例 | c2k1、c2k2 等 |
| 一词首创者 | Theo de Raadt 或 Niels Provos（**1999 年**） |
| 首次 hackathon 工程产出 | IPv6 与 IPSEC 栈首次完整集成（业界首次） |
| 形式特征 | 无演讲、无固定日程，同一房间内集中编写代码 |
| 治理功能 | 技术决策、代码审计、新人筛选 |

**史料**：OpenBSD hackathon 历年记录（hackathons.html，1999 年至今）、核心开发者访谈录、OpenBSD 官方关于 hackathon 的声明 ［B］

**史观**：社区文化即技术资产：hackathon 是 OpenBSD 治理结构的关键资产
