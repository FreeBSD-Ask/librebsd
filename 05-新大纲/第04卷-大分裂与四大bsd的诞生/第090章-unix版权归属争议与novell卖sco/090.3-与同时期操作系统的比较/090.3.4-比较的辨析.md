# 090.3.4 比较的辨析

  **要点**：4.4BSD-Lite 与 Windows NT 3.5、Solaris 2.4、IBM OS/2 Warp 的比较辨析须区分 “技术架构”（微内核 vs 宏内核、SVR4 vs BSD、32 位抢占式多任务 vs 分时多任务）与 “市场定位”（企业 vs SPARC 工作站 vs 桌面 vs 服务器）——前者可技术对比，后者经各操作系统的发布档案与第三方市场份额统计（IDC、Gartner）场景化评估；单一维度的决定论（如仅以许可模式判断胜负）经 Windows NT 3.5 商业市场胜出但开源生态影响为零、4.4BSD-Lite 商业市场份额有限但开源生态影响深远的对照可证伪。1994 年同期操作系统对照如下：

| 操作系统 | 发布时间 | 技术架构 | 市场定位 | 许可模式 |
| ------ | ------ | ------ | ------ | ------ |
| 4.4BSD-Lite | **1994.6** | 宏内核 | 服务器 | BSD 开源 |
| Windows NT 3.5 | **1994 年** | 微内核 | 企业 | 专有 |
| Solaris 2.4 | **1994 年** | SVR4 | SPARC 工作站 | 专有 |
| IBM OS/2 Warp 3.0 | **1994 年** | 32 位抢占式多任务 | 桌面 | 专有 |

**辨析**：比较的解释力存在边界——部分学者过于强调单一维度（如许可模式），架构（微内核 vs 宏内核）、市场（企业 vs 桌面 vs 服务器）、生态（商业支持 vs 开源社区）多维因素须综合评估——Windows NT 3.5 在商业市场胜出但开源生态影响为零，4.4BSD-Lite 在商业市场份额有限但开源生态影响深远，二者经不同维度评估结论不同

### 史观映射

> Karels 的告别邮件发出去的那天，CSRG 不是终结了，而是散开了——代码、人、许可证，像一把沙子从指缝间漏下，每一粒都落在了不同的地方。4.4BSD-Lite 是这些沙粒中最干净的一把：不含 AT&T 代码，法律上无可争议，成为 FreeBSD、NetBSD、OpenBSD 三个项目共同的重建基础。CSRG 的解散不是历史的断裂，而是总纲第 4 条分离聚合是永恒规律的又一次展开：一个中心消失了，三个分支从它的遗产中各自生长。FreeBSD 基于 4.4BSD-Lite 的重建不是回归，而是聚合——旧代码在新手中获得了新的命运
