# 090.3.1 Windows NT 3.5 的比较

  **要点**：**1994 年** Windows NT 3.5 发布，定位企业市场，支持 x86、MIPS、Alpha 多架构（PowerPC 支持自 NT 3.51 起），提供 Win32 API；与 4.4BSD-Lite 相比，NT 3.5 商业支持完善但开源程度为零，技术架构（微内核 vs 宏内核）与许可模式（专有 vs 开源）形成鲜明对比
  
**史料**：Windows NT 3.5 Release 1994 微软公告；Windows NT 内核架构文档；4.4BSD-Lite Release Notes［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档与公告〕
  
**史观**：专题语（不设总纲条号）——技术选择即政治选择：NT 的微内核架构与 4.4BSD-Lite 的宏内核架构反映不同的技术政治选择
  
**辨析**：NT 3.5 与 4.4BSD-Lite 的比较须区分 “市场份额”（NT 3.5 经微软企业销售渠道在商业市场胜出）与 “技术影响”（4.4BSD-Lite 经 FreeBSD 2.0 1994.11.22、NetBSD 1.0 1994.10.26、OpenBSD 1995.10 fork 在开源生态影响深远）；技术影响的多维评估经 bsd_commits.duckdb 三大 fork 首条 commit 时间（FreeBSD 1993-06-12、NetBSD 1993-03-21、OpenBSD 1995-10-18）可量化——4.4BSD-Lite 代码遗产持续至 2026 年，NT 3.5 已被 NT 4.0/2000/XP/Server 2003 等后续版本取代
