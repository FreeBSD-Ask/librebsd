# 083.0.1 要点

- **1996 年** BSD 格局形成——FreeBSD、NetBSD、OpenBSD 三项目定位分化，共享 4.4BSD-Lite 遗产但走向不同方向；背景涉及 386BSD 中断、三项目创建与定位选择。三项目首条 commit 时间节点对照如下：
- FreeBSD 选择 x86 性能定位——聚焦 i386 平台性能优化与 Walnut Creek CDROM 商业绑定；定位选择决定 FreeBSD 后续发展路径
- NetBSD 选择可移植定位——聚焦多平台移植，扩展至 50+ 平台；定位选择决定 NetBSD 后续工程方向；freebsd.duckdb 统计结论 C-04 显示：netbsd-src 总 commit 数 774,061（SQL 查询 `SELECT COUNT(*) FROM commits WHERE repo_name='netbsd-src'`）〔订正注：原 773,683 系统计结论漂移，依核查报告按三库实测统一更新〕，为四 BSD 项目 src 仓库中累计 commit 量最高者——与 C-03 freebsd-src 总 commit 数 445,203、C-05 openbsd-src 总 commit 数 246,535 对照〔订正注：原 444,203/245,904 同上，C-03 差恰 1,000 疑位数误植〕，NetBSD 累计 commit 量约为 FreeBSD 的 1.74 倍、OpenBSD 的 3.15 倍，反映 NetBSD 在更多平台移植目标（50+ 平台）下的累计工程产出规模最大，可移植定位的工程代价体现为单平台深度优化 commit 的分散
- OpenBSD 选择安全定位——聚焦全代码审计与安全默认配置；定位选择决定 OpenBSD 后续工程方向。三项目定位分化对照如下：
