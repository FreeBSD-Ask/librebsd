# 083.5.4 排外性的比较分析

  **要点**：三项目排外性的比较分析——FreeBSD 封闭决策、OpenBSD 独裁式排外、NetBSD 社区萎缩；比较反映 BSD 阵营精英主义文化的多样性。三项目排外性对照如下：

| 项目 | 排外形态 | 典型证据 | 关键时点 |
| -- | ------ | ------ | ------ |
| FreeBSD | 封闭决策 | Jordan Hubbard 2001 年辞职信“核心团队实在太‘反应迟钝’了” | **2001 年** |
| FreeBSD | 信息不对称 | trasz@/Edward Tomasz Napierała 批评 Core Team“无视开发者社区”“假装民主” | **2025 年 12 月** |
| FreeBSD | 峰会邀请制 | jmmv 2013 EuroBSDCon 报道“invite-only events gather together FreeBSD committers” | **2013 年** |
| OpenBSD | 独裁式排外 | “与 Theo 意见不合就是与上帝不合”（LWN 2007 Jonathan Corbet 报道） | **2007 年** |
| OpenBSD | 新手敌意 | misc@ 邮件列表、IRC don’t ask to ask 文化 | 长期 |
| NetBSD | 社区萎缩 | BSDCan 2011 峰会仅 3 人到场 | **2011 年** |
| NetBSD | 工具排外 | pkgsrc 与 Ports 系统差异使转入者需重新学习 | 长期 |

**史料**：三项目邮件列表历年存档、开源社区排外性对比研究、BSDCan/EuroBSDCon 历年议题统计 ［A］

**史观**：社区文化即技术资产：排外性的比较反映 BSD 阵营精英主义文化的多样性

**辨析**：排外性的具体比较在不同叙事中略有差异——需对照多方公开声明核实

**文献**：三项目邮件列表存档；开源社区排外性对比研究 ［A］

**观点**：1996 年 9 月 4 日，Terry Lambert 在 freebsd-chat 的同一讨论串中进一步主张：“如果说有什么不同，OpenBSD 的精英主义态度比其他 BSD 还要严重——只要开始追问那些了不起的‘安全修复’究竟是什么，你就会发现它并不像名字所暗示的那么‘开放’”，并预言 OpenBSD 将不可避免地滑向势能最低的状态。
**邮件来源**：Terry Lambert，freebsd-chat，1996 年，Message-ID: `199609041726.KAA06713@phaeton.artisoft.com`
**史学意义**：这一早期批评把“排外”具体化为对安全信息获取路径的质询障碍，与 75.5.2 所引 LWN 2007 报道、misc@ 敌意叙事构成跨越十年的同题证据链，说明排外性批评在 OpenBSD 公开首年即已定型为可复用的论式。
