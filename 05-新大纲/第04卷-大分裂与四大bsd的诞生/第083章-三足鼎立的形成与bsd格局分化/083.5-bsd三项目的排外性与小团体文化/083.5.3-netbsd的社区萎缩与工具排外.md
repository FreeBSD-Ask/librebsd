# 083.5.3 NetBSD 的社区萎缩与工具排外

  **要点**：NetBSD 开发者社区极度萎缩——BSDCan 2011 峰会仅 3 人到场（jmmv 2013 EuroBSDCon 报道）；pkgsrc 与 Ports 系统差异使从 FreeBSD/Linux 转入者需重新学习，构成工具排外
  
**史料**：jmmv 2013 EuroBSDCon 报道、NetBSD 社区活跃度历年统计、pkgsrc 与 Ports 对比研究 ［C］
  
**史观**：社区文化即技术资产：社区萎缩与工具排外是 NetBSD 精英主义文化的负资产
  
**辨析**：社区萎缩的程度在不同叙事中略有差异——需对照 BSDCan 历年参与统计核实
  
**文献**：jmmv 2013 EuroBSDCon 报道；NetBSD 社区活跃度统计 ［C］
