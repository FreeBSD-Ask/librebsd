**史观**：总纲第 4 条——分离聚合是永恒规律：1996 年 BSD 格局是分离后产生的新聚合

**辨析**：格局形成的具体时点在不同叙事中略有差异——需对照三项目发布历史核实；netbsd.duckdb 中 NetBSD src 首条 commit（1992-07-13）为仓库初始化脚本，非实际源码导入，须区分“仓库初始化”与“项目实际启动”；OpenBSD src GitHub 镜像可能滞后于 CVS 主仓，commit 数统计仅供参考；【0 信任原则·commit 量不等于质量】L1.1.2 的 1995-1996 BSD src 比例反映开发活跃度分布但不等于项目质量，三足鼎立的“实力”评估须结合 commit message 主题词、release 稳定性与社区生态综合判断；【0 信任原则·CVS-to-Git 迁移风险】netbsd-src 与 openbsd-src 均为 CVS 主仓的 GitHub 镜像，CVS-to-Git 转换可能重写 author 字段或 commit_date，1995-1996 年 commit 量基线须与 NetBSD/OpenBSD 官方档案交叉验证；【0 信任原则·GitHub 镜像滞后】netbsd-src 与 openbsd-src 的 GitHub 镜像可能滞后于 CVS 主仓，1995-1996 年 commit 量比例的精度须以官方档案为准
