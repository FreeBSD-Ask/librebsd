# 088.3.4 三条总纲的合图——争议的不可调和性与和解路径

  **要点**：总纲第 13、19、21 条的合图显示，Linux vs BSD 争议的不可调和性源于三条总纲的交织——许可证哲学（第 13 条）的利益分配差异、解释学循环（第 19 条）的前理解差异、革命与改革（第 21 条）的方法论差异，三者共同构成争议的不可调和性；合图层指出和解路径——承认 BSD 与 Linux 各有其主体性，许可证哲学差异不得以道德判断简化，解释学循环差异不得以 “消除分歧” 回避，革命与改革差异不得以 “胜负” 衡量；和解不是 “消除争议” 而是 “在争议中呈现各主体性”

**辨析**：三条总纲的合图须区分 “不可调和性” 与 “和解路径”——不可调和性源于三条总纲的交织（许可证利益分配、解释学前理解、革命与改革方法论），三者共同构成争议的结构性张力；和解路径不是 “消除争议” 而是 “在争议中呈现各主体性”，承认 BSD 与 Linux 各有其评价标准与存在价值；【0 信任原则·不可调和性须考据】“不可调和性” 与 “和解路径” 的区分须经具体争议案例（如 sudo、jail、rc.d 等文化挪用案例）的考据验证，不得仅凭理论推演即断定；【0 信任原则·和解非折中】和解路径非 “双方都有道理” 的折中主义，而是基于一手档案与第三方数据的多因素叠加分析，合图须以考据为前提

**史家判断**（证据等级：L2，来源：`cross_indexes.duckdb.concept_history.21`）

虚拟内存：虚拟内存概念的演化: 思想萌芽：1950 年代 Güntsch 等提出以自动存储管理化解手工“覆盖”（overlay）编程负担。确立期：1959–1962 年英国曼彻斯特大学 Kilburn 团队在 Atlas 计算机上首次实现“单级存储”（后称虚拟内存），以磁鼓为辅助存储，硬件自动在主存与磁鼓间搬移代码数据从而取消人工覆盖，并配套产生 Atlas Supervisor；该成果获 IEEE 里程碑。产业化：1961 年 Burroughs 推出采用段式管理的首款商用虚拟内存系统。理论奠基：1962 年 Kilburn、Edwards、Lanigan、Sumner 发表《One-Level Storage System》
