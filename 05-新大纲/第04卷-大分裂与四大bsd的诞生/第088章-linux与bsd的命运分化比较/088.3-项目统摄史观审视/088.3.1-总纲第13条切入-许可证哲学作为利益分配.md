# 088.3.1 总纲第 13 条切入——许可证哲学作为利益分配

  **要点**：从总纲第 13 条（法律与道德是利益分配）切入，Linux vs BSD 许可证之争本质是利益分配问题——GPL 强制回馈条款将商业公司的衍生作品贡献强制回流公共池，形成 “贡献循环”；BSD 许可证允许商业公司自由使用、修改、再分发而不强制回馈，形成 “散逸效应”；两套许可证哲学背后的利益分配机制不同，不得以 “GPL 优于 BSD” 或 “BSD 优于 GPL” 的道德判断简化；FSF 与 Stallman 在 2000 年代多场公开演讲中将 BSD 描述为 “less free than GPL”，建构 “GPL 是严格 free software，BSD 是 permissive” 的阵营对立叙事，这一 “道德问题” 本质上是 FSF 阵营对 BSD 阵营的 “利益分配” 问题。GPL 与 BSD 利益分配机制对照如下：

| 维度 | GPL（Linux 内核） | BSD（FreeBSD/NetBSD/OpenBSD） |
| -- | --------------- | --------------------------- |
| 利益流向 | 公共池与贡献者 | 商业公司与最终用户 |
| 强制回馈 | 是——衍生作品须以 GPL 发布 | 否——允许 proprietary 衍生品 |
| 道德叙事 | “GPL 严格 free software” | “BSD permissive” |
| 利益分配本质 | 商业公司贡献强制回流 | 商业公司自由使用不回馈 |

**史料**：BSD 许可证原文（BSD 3-Clause **1990**）、GPL v2 许可证原文（**1991**）、GPL v3 许可证原文（**2007**）；Stallman 公开演讲存档（FSF 网站）；Torvalds 关于 GPL 的公开声明（lkml.org 邮件列表存档）；BSD 衍生产品统计（macOS、PlayStation、Netflix、Juniper、NetApp） ［A］

**史观**：总纲第 13 条——法律与道德是利益分配：GPL 与 BSD 许可证之争本质是利益分配问题，GPL 强制回馈条款将商业公司的衍生作品贡献强制回流公共池，BSD 许可证允许商业公司自由使用而不强制回馈，两套许可证哲学背后的利益分配机制不同；FSF 与 Stallman 建构的 “GPL 严格 free software，BSD permissive” 叙事本质上是 FSF 阵营对 BSD 阵营的 “利益分配” 问题

**辨析**：总纲第 13 条的切入须区分三个维度——法律维度（GPL 强制回馈条款与 BSD 散逸效应是法律结构差异）、道德维度（“GPL 优于 BSD” 或 “BSD 优于 GPL” 的道德判断是形式主义误读）、利益分配维度（GPL 与 BSD 背后的利益分配机制不同，GPL 利益流向公共池与贡献者，BSD 利益流向商业公司与最终用户）；【0 信任原则·道德判断考据】Stallman 公开演讲中 “BSD less free than GPL” 的表述须经 FSF 网站存档与 lkml.org 邮件列表存档交叉验证，不得仅凭道听途说即采信；【0 信任原则·利益分配非道德判断】GPL 与 BSD 的利益分配机制差异是法律结构差异，不得以 “GPL 更道德” 或 “BSD 更道德” 的道德判断简化——二者各有其哲学前提（GPL 以强制回馈保障公共池，BSD 以自由散逸承认人类有限性）

**文献**：BSD 与 GPL 许可证原文；Stallman 公开演讲存档；Torvalds 公开声明 ［A］
