# 092.2.2 NetBSD 与 OpenBSD 的地理分布

  **要点**：NetBSD 的地理分布——核心团队分散于美国（加州、马萨诸塞州）、欧洲（英国、德国）、日本等，反映 “可移植性至上” 的全球性；OpenBSD 1995 年代码层面 fork（deraadt 1995-10-18T08:37:01Z 首条 commit “initial import of NetBSD tree”，commit_hash `df930be708d50e9715f173caa26ffe1b7599b157`），1996 年公开发布 1.2 后以加拿大卡尔加里（de Raadt 居住地）为基地，地理上的 “边缘化” 反映 OpenBSD 与美国主流的分离
  
**史料**：NetBSD 核心团队地理分布档案；OpenBSD 卡尔加里基地档案；de Raadt 居住记录；openbsd.duckdb 数据库证据（2026-07-21 复核）：openbsd-src 首条 commit 由 deraadt 于 1995-10-18T08:37:01Z 提交（commit_hash `df930be708d50e9715f173caa26ffe1b7599b157`），证实 OpenBSD 代码层面 fork 在 1995 年 10 月，而非 1996 年；deraadt 在 netbsd-src 的最后一条 commit 为 1994-12-17T23:12:41Z（commit_hash `699d2a37b0e3c0c6ff29ea0d407c3feeba5642b4`），距 openbsd-src 首条 commit 约 304 天，反映从被逐到 fork 的地理迁移准备期 ［A］；openbsd.duckdb 查询 L3.3.1 显示：欧洲时区（+01:00 西欧、+02:00 中欧）合计 806,625 commits/32,668 位贡献者，反映欧洲为 BSD 社区第二大开发者来源地，支撑 NetBSD “可移植性至上” 的全球协作需求；东亚时区（+08:00 东亚）115,307 commits/3,406 位贡献者，反映东亚（特别是日本）BSD 开发者规模；openbsd.duckdb 查询 L3.3.2 显示：.ca（加拿大）ccTLD 有 2,395 commits/144 个邮箱，反映 OpenBSD 以加拿大卡尔加里为基地后加拿大开发者占比虽小但存在；.de（德国）112,451 commits/1,753 个邮箱、.uk（英国）30,913/387、.fr（法国）10,051/345 等欧洲 ccTLD 合计反映欧洲为 NetBSD 核心团队全球分布的主要组成部分；.jp（日本）6,471 commits/205 个邮箱反映日本 BSD 社区规模，与 NetBSD 在日本早期推广（日本 BSD 用户会）的历史叙事在数据上得到印证
  
**史观**：总纲第 5 条——没有必然性，只有偶然性。项目史观总纲第 5 章 5.1 节载 “世界上没有必然性，只有偶然性”——NetBSD 的全球分布与 OpenBSD 的加拿大基地并非 “组织结构必然塑造技术路径” 的规律展开，而是 de Raadt 1994.12 被逐后从美国迁至加拿大卡尔加里、NetBSD 核心团队全球分布等偶然条件组合的层叠；5.3 节 “记忆将许多偶然性认识为一种必然性” 警示事后叙事可能将此偶然组合回溯为 “地理边缘化决定 OpenBSD 安全独裁” 的必然规律
  
**辨析**：OpenBSD 的 “加拿大基地” 在不同叙事中差异较小，但须区分 “代码 fork 时间”（1995-10-18）与 “首个公开发布版本时间”（1.2, 1996.7）——前者是地理迁移的实际起点，后者是公开亮相的时间点；de Raadt 个人居住史经 netbsd.duckdb 间接印证——deraadt 在 netbsd-src 最后 commit 为 1994-12-17T23:12:41Z（commit_hash `699d2a37b0e3c0c6ff29ea0d407c3feeba5642b4`），openbsd-src 首条 commit 为 1995-10-18T08:37:01Z（commit_hash `df930be708d50e9715f173caa26ffe1b7599b157`），中间 304 天的 fork 准备周期与 “从美国迁至加拿大卡尔加里” 的地理迁移叙事在时间上吻合 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］；【0 信任原则·committer_date 可能被重写】L3.3.1 的欧洲与东亚时区数据基于 committer_date 字段，committer_date 可能被 GitHub 镜像同步重写，时区偏移不直接等于贡献者居住地，欧洲时区的高 commit 量可能包含非欧洲贡献者（如北美开发者配置中欧时区），须与 author_date 字段交叉验证；【0 信任原则·时区不直接等于地理位置】L3.3.1 的时区数据反映 commit_date 的时区设置而非 NetBSD 核心团队的实际地理分布，NetBSD “全球分布” 的叙事须以 Core Team 成员公开自述与基金会档案为准而非仅依赖时区统计；【0 信任原则·author 字段可伪造】L3.3.2 的 .ca/.de/.uk/.fr/.jp 等 ccTLD 数据基于 author_email 字段，git 的 author 字段可由提交者任意填写，ccTLD 不直接等于贡献者国籍，.ca 邮箱数（144）较小不意味着加拿大 BSD 开发者仅 144 人，可能多数加拿大开发者使用 .com 或 .org 邮箱；【0 信任原则·CVS-to-Git 迁移风险】netbsd-src 与 openbsd-src 均为 CVS 主仓的 GitHub 镜像，CVS-to-Git 转换可能重写 committer_date 或 author_email 字段，时区与 TLD 分布须与各项目官方档案交叉验证
