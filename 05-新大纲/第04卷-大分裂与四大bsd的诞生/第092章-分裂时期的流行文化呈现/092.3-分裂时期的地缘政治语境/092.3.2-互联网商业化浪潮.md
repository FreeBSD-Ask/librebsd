# 092.3.2 互联网商业化浪潮

  **要点**：**1993-1996 年** 互联网商业化浪潮对 BSD 社区地理扩张的塑造——NSFNET **1995 年** 商业化、Web 兴起、ISP 普及使 BSD 代码通过互联网全球扩散；BSD 在 Web 服务器（Apache 早期基于 FreeBSD）、ISP 基础设施中的广泛应用反映互联网商业化的塑造

**史观**：总纲第 15 条——文化即形式主义〔存疑：对位待主理人审定〕：互联网商业化通过商业需求推动 BSD 全球扩散，但亦带来商业-社区张力，Walnut Creek CDROM 等商业实体在 BSD 社区中产生隐形中心化（商业发行渠道的权威）；“假开源” 等不自反的形式主义化社区姿态须警惕，BSD 商业化与社区理想之间的张力须自反地审视而非简单二元对立
