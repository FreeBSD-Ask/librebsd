# 091.3.1 BSD Daemon 的文化意义


BSD 符号演变时间线如下：

| 时间 | 符号 | 项目 | 说明 |
| -- | -- | -- | -- |
| **1988 年** | BSD Daemon 原始画作 | CSRG 共享 | John Lasseter 创作（McKusick 委托并持有版权） |
| **1993.4** | — | NetBSD | NetBSD 0.8 发布（公告原件无 Daemon 标识记载〔存疑脚注：早期吉祥物使用起点待档案补证〕） |
| **1993.11.1** | — | FreeBSD | FreeBSD 1.0 发布（公告原件无 Beastie 图形使用记载〔存疑脚注：同上〕） |
| **1996.7** | 沿用 NetBSD 风格 | OpenBSD | OpenBSD 1.2 发布 |
| **2002.11** | Puffy（河豚）确认 | OpenBSD | OpenBSD 3.2 歌曲 “Goldflipper” |

  **要点**：BSD Daemon 由动画导演 John Lasseter 于 **1988 年** 受 Marshall Kirk McKusick 委托为 4.3BSD 教科书封面绘制（McKusick 持有版权，同年秋出版），作为 BSD 项目共享图腾，在分裂时期承载 CSRG 文化记忆；Daemon 形象（持三叉戟的小恶魔）象征 BSD 的技术精神与社区认同〔创作者归因经 2026-09-12 联网核验校正（McKusick 本人 BSDCan 2025 演讲与 FreeBSD Foundation 官方博客），原“McKusick 创作”说不确〕
  
**史料**：McKusick 1988 BSD Daemon 原始画作；BSD Daemon 历史档案；CSRG 文化档案 ［A］
  
**史观**：总纲第 15 条——文化即形式主义。项目史观总纲第 14 章 14.5 节载 “真正使项目得以成立的，不是代码，而是这些外围的形式主义的东西”——Daemon 作为社区图腾承载 BSD 文化记忆即形式主义建构的体现，14.5 节 “文档与代码的本体平等” 提示图腾符号与代码本身在本体论上地位相等（总纲第 8 条 “本体论上各方平等”）；14.6 节 “开源的形式主义” 批评 “假开源” 等不自反的形式主义化社区姿态，但 Daemon 作为自反地承认自身形式主义性质的社区图腾，并非项目统摄史观批评的对象
  
**辨析**：Daemon 的文化意义在不同叙事中差异较小，FreeBSD 2005 年发布 6.0 后逐步减少 Beastie 在官方宣传中的使用——因避免宗教敏感性（恶魔形象）的考量在社区讨论中出现，但 Beastie 未被完全弃用，FreeBSD Foundation logo 于 2013 年 redesign 后采用更抽象形态 [存疑脚注：2013 年 redesign 年份未获一手佐证，相关资料多记 Foundation 品牌更新为 2014 年前后，待官方新闻稿复核] ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］
