# 091.3.3 符号的形式主义化

  **要点**：**1992-1996 年** 间 BSD Daemon 从 CSRG 的随意图腾演变为三项目各自发展的符号谱系——FreeBSD 1.0（**1993.11.1**）与 NetBSD 0.8（**1993.4.19**〔存疑脚注：官方 formal-0.8 页作 19th April 1993，而 formal.html 历史表与 history 页作 20 Apr 1993，两口径并存〕）公告原件均未载吉祥物图形使用记载〔存疑脚注：两公告经 2026-09-12 取原件核验，早期公告与吉祥物官方化的关联系原稿想象性填充已删，实际使用起点待档案补证〕，OpenBSD 1.2（**1996.7**）发布后经 daemon 变体逐步转向 Puffy 河豚形象；符号的官方化过程与三项目的社区认同建构同步发生
  
**史料**：FreeBSD 1.0 RELEASE Announcement (1 Nov 1993)（原件核验：无 Beastie 使用记载）；NetBSD 0.8 Release Announcement (19 Apr 1993)（原件核验：无 Daemon 标识记载）；OpenBSD 标志演变档案；McKusick 1988 BSD Daemon 原始画作档案［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档与公告〕
  
**史观**：总纲第 15 条——文化即形式主义：符号（Daemon/Beastie/Puffy）作为形式要素与社区认同作为内容要素形成对应——FreeBSD 2005 年后逐步减少 Beastie 使用以避免宗教敏感性，OpenBSD 经 2.3-2.5 daemon 变体转向 Puffy 以强调安全文化的差异化身份〔Puffy 首登版本存疑待核〕，符号变迁与社区认同变迁同步
  
**辨析**：符号形式主义化的具体过程在不同叙事中差异较小，但 OpenBSD 转向 Puffy 的精确时间需对照 OpenBSD lyrics.html 与各版本歌曲档案核实——Puffy 母题在 OpenBSD 3.2（2002.11）歌曲 “Goldflipper” 中出现（官方所载），其成为吉祥物的时点早于 3.2〔存疑脚注：Puffy 首次登场的确切版本待核〕
