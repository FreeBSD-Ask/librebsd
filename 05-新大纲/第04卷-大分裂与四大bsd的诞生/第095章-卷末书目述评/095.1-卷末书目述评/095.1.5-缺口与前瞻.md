# 095.1.5 缺口与前瞻

本卷史料存在三类缺口，需在未来研究中补全。

档案缺口：其一，CSRG 内部邮件存档（伯克利 Bancroft 图书馆 CU-551 全宗）未公开数字化，这使 CSRG 在 USL 诉讼期间的具体决策过程、4.4BSD-Lite 代码清理工作的内部讨论、CSRG 解散前的交接细节等关键史实难以从内部视角重构。其二，NetBSD Core Team 内部邮件存档未公开，这使 de Raadt 被逐出 NetBSD Core Team 的具体决策过程与驱逐理由难以从内部视角重构，目前主要依赖 Glass 1994 年 12 月 23 日的单方面声明。其三，USL/Novell 一方的内部档案未公开，这使 USL 诉讼的战略意图与和解动机难以从对方视角重构，目前主要依赖 CSRG 一方叙述。其四，386BSD 无独立 git 仓库，下游 import commit 时间晚于原始发布约 9 至 12 个月，须与一手 Release Notes 交叉验证。未来方向为 Bancroft 实地查阅 CU-551 全宗、NetBSD Core Team 内部邮件存档发掘、USL/Novell 档案发掘。

方法论缺口：其一，缺乏 386BSD 0.1 与 FreeBSD 1.0 源码 diff 量化分析。386BSD 停滞责任的辨析目前依赖 Jolitz 夫妇自述与 FreeBSD Project 叙事的对立陈述，缺乏基于源码 diff 的代码层面量化比较。未来可借助 **netbsd.duckdb** 数据库进行源码 diff 量化分析，重构 386BSD 至 FreeBSD 1.0 的代码演化路径。其二，缺乏 4.4BSD-Lite 与 Net/2 源码 diff 量化分析。和解条款的执行结果（3 文件删除、约 70 文件添加版权声明）目前依赖 McKusick 1999 年当事人转述，缺乏基于源码 diff 的代码层面量化验证。其三，缺乏 de Raadt 在 netbsd-src 仓库提交历史的系统性量化分析。de Raadt 被逐出 NetBSD Core Team 的事件性质辨析目前依赖 Glass 声明与 OpenBSD FAQ 措辞差异，缺乏基于其提交历史量化分析的工程贡献规模评估。其四，BSDNow 播客与 BSDCan 演讲档案的具体期数待三次复查核实 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］。

史学缺口：其一，USL/Novell 一方视角的一手叙述稀缺。USL 诉讼的战略意图与和解动机目前主要通过 CSRG 一方叙述呈现，缺乏 USL/Novell 内部档案或 USL 核心成员的系统性口述史。其二，386BSD 阵营视角的一手叙述除 Chalmers 2000 年 Salon 专访外稀缺。Jolitz 夫妇作为 386BSD 开发者的视角主要通过 Salon 专访呈现，缺乏其他 386BSD 用户的佐证与 Jolitz 夫妇的系统性口述史。其三，NetBSD Core Team 除 Glass 与 de Raadt 之外的其他成员（Demetriou、Hannum）对此事件的公开陈述稀缺。其四，Karels 告别邮件精确日期未考证。多数来源仅标注 1995 年 6 月，无精确到日的一手记录 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］。未来研究方向：Bancroft 实地查阅 CU-551 CSRG 邮件存档，NetBSD Core Team 内部邮件存档发掘，USL/Novell 档案发掘，386BSD 0.1 与 FreeBSD 1.0 源码 diff 量化分析，4.4BSD-Lite 与 Net/2 源码 diff 量化分析，Karels 告别邮件精确日期考证，CSRG 口述史系统性整理与交叉索引。这些方向将有助于补全本卷史料的档案缺口、方法论缺口与史学缺口，使第四卷的叙事从对立叙事辨析转向档案证据、代码层面量化证据与当事人叙述的批判性互证。
