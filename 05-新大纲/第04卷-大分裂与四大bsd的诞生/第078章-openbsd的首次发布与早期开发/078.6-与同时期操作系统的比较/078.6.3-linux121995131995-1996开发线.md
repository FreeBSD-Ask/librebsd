# 078.6.3 Linux 1.2（1995）/ 1.3（1995-1996 开发线）

  **要点**：Linux 1.2（1995.3）是功能完整但规模尚小的 UNIX 内核，1.3 为开发主线（后演进为 2.0）；1995-1996 年 Linux 处于 “功能追赶” 阶段，社区以功能与移植为主，尚未形成系统性的安全审计文化。OpenBSD 的 proactive security 理念在 Linux 界当时几乎不存在，直到多年后 grsecurity/SELinux 才出现类似关注。
  
**史料**：Linux 1.2 发布说明（1995.3）；Torvalds 邮件列表公告 ［B］；Linux 1.3 变更日志 ［C］
  
**史观**：总纲第 4 条——分离聚合是永恒规律：Linux 的 “大规模协作功能开发” 与 OpenBSD 的 “小团队安全审计” 由同源开源运动分离后各自聚合，代表两种开源开发哲学，1995-1996 年二者安全成熟度差距显著。
  
**辨析**：Linux 当时并非 “不安全”——而是缺乏 OpenBSD 式的制度化安全流程；将 OpenBSD 视为对 Linux 的安全批判是事后视角，当时二者关注点本就不同。
  
**文献**：Torvalds L. Linux 1.2 Release Notes [Z]. 1995；Linus Torvalds et al. Linux Kernel Archives [EB/OL]. ［B］
