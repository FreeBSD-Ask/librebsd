# 078.6.1 NetBSD 1.1（1995）/ 1.2（1996-10-04）

  **要点**：NetBSD 1.1（1995.11）与 1.2（1996-10-04）延续 NetBSD 的 “极致可移植” 路线，支持从 VAX 到 ARM 的广泛平台；OpenBSD 正是由此派生——1995 年 10 月 Theo de Raadt（西奥·德·若特）因与 NetBSD 核心团队的治理分歧而分叉，OpenBSD 1.0（1996.7）基于 NetBSD 1.0 但重写了大量安全相关代码。二者共享 BSD 谱系，但在优先级上分道：NetBSD 重 “可移植”、OpenBSD 重 “安全”。
  
**史料**：NetBSD 1.1/1.2 发布说明；OpenBSD 1.0 公告（1996.7）与 de Raadt 分叉公开信 ［A］；NetBSD 邮件列表分叉讨论归档 ［B］；freebsd.duckdb 查询 L1.1.2 显示：1995 年 4 大 BSD src 仓库 commit 量相对比例为 netbsd-src = 12,163 commits（58.88%）、freebsd-src = 7,723 commits（37.39%）、openbsd-src = 770 commits（3.73%），反映 OpenBSD fork 当年（1995.10）commit 份额极低；1996 年比例变为 netbsd-src = 16,057 commits（54.91%）、freebsd-src = 7,948 commits（27.18%）、openbsd-src = 5,240 commits（17.92%），OpenBSD 份额增长约 4.8 倍，反映 OpenBSD 1.2 发布后逐步在 BSD 阵营中占据独立位置，但仍远低于 NetBSD 与 FreeBSD
  
**史观**：总纲第 7 条——BSD 谱系：OpenBSD 是 NetBSD 的直接派生，证明 BSD 许可证允许自由分叉以追求不同工程优先级；这一 fork 是 BSD 家族 “各自独立发展” 的典范。
  
**辨析**：OpenBSD 并非 “优于” NetBSD——二者目标不同；分叉源于治理与文化分歧而非技术优劣，OpenBSD 继承了 NetBSD 的代码基础与可移植框架；【0 信任原则·commit 量不等于质量】L1.1.2 的 1995-1996 BSD src 比例反映开发活跃度分布但不等于项目质量，OpenBSD 3.73%→17.92% 的份额增长须结合 commit message 主题词与安全审计记录综合判断；【0 信任原则·CVS-to-Git 迁移风险】netbsd-src 与 openbsd-src 均为 CVS 主仓的 GitHub 镜像，CVS-to-Git 转换可能重写 author 字段或 commit_date，1995-1996 年 commit 量基线须与 NetBSD/OpenBSD 官方档案交叉验证；【0 信任原则·GitHub 镜像滞后】netbsd-src 与 openbsd-src 的 GitHub 镜像可能滞后于 CVS 主仓，1995-1996 年 commit 量比例的精度须以官方档案为准；【勘误·经[邮件列表库]验证】本文要点原记 “1.2（1996.12）” 系日期误差，应修正为 **1996-10-04**：NetBSD 1.2 实际由 J.T. Conklin（<jtc@NetBSD.ORG>）于 1996-10-04 在 netbsd-announce 公告发布（Message-ID `no-id-netbsd-announce-199610-04-0000`，subject“Announcing the release of NetBSD 1.2.”）
