# 078.5.5 要点OpenBSD早期19962003技术淘汰具有安全驱动而非商业驱动的鲜明特征

  **要点**：OpenBSD 早期（1996-2003）技术淘汰具有 “安全驱动而非商业驱动” 的鲜明特征——淘汰决策主要基于安全论证而非市场份额或商业压力；这一特征使 OpenBSD 在 BSD 阵营中独树一帜，与 FreeBSD 的 “兼容优先” 形成对照；但需警惕将 OpenBSD 叙事为 “安全原教旨主义” 的回溯性建构——彼时 OpenBSD 的移除决策多基于具体工程权衡（如 telnetd 移除后 ssh 已成熟可用），而非抽象安全原则
  
**史料**：OpenBSD 1996-2003 年邮件列表存档、Theo de Raadt 公开演讲、OpenBSD Security FAQ ［A］
  
**史观**：总纲第 13 条——法律与道德是利益分配〔存疑：对位待主理人审定〕：安全驱动淘汰是 OpenBSD 工程文化的核心特征；总纲第 7 条——理论必须自反：避免将工程权衡叙事为抽象原则
  
**辨析**：OpenBSD 移除决策是否完全基于安全需考据——sendmail 退役亦涉及配置复杂度与维护成本；r-commands 退役虽然安全论证为主，但 SSH 已成熟亦是工程前提
  
**文献**：OpenBSD 邮件列表 1996-2003 存档；de Raadt 公开演讲；OpenBSD Security FAQ ［A］

### 史观映射

> 第 28 章体现项目统摄史观中 “偶然性改写历史” 与 “分离与聚合” 的双重运作——de Raadt 被 NetBSD Core Team 逐出是具体的个人决定，但直接催生 OpenBSD 这一 BSD 家族的安全堡垒；fork 是 “分离” 的极端形式，但分离后的 “聚合”（加密代码集成、代码审计文化建立）才是 OpenBSD 真正的创造性贡献；“安全至上” 作为差异化定位是 “技术选择即政治选择” 的典型——de Raadt 选择安全而非可移植性或性能，这一选择反映了 OpenBSD 对 BSD 哲学的不同理解；Core Team 的驱逐决议则体现了 “组织结构塑造技术路径”——NetBSD 的精英决策结构直接改变了 BSD 家族的格局（按：“偶然性改写历史”“分离与聚合” 分别对应总纲第 5 条 “没有必然性，只有偶然性” 与第 4 条 “分离聚合是永恒规律”；“技术选择即政治选择”“组织结构塑造技术路径” 为专题语，不设总纲条号〔待主理人审定〕）
