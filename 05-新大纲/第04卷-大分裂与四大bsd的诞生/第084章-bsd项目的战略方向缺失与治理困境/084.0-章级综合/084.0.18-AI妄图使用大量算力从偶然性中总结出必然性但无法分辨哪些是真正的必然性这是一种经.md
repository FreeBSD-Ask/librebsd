# 084.0.18 AI妄图使用大量算力从偶然性中总结出必然性但无法分辨哪些是真正的必然性这是一种经

AI 妄图使用大量算力从偶然性中总结出必然性，但无法分辨哪些是真正的必然性。这是一种经验主义实证主义。AI 就像会写八股文的学生，如果自己知道框架怎么搭建，他可以帮忙，但要写出好东西，自己完全不懂是困难的。AI 自己生成的文本的回归问题就像近亲繁殖一样。随着 AI 的发展，我们理应看到更多高质量的开源内容，但正好相反。
