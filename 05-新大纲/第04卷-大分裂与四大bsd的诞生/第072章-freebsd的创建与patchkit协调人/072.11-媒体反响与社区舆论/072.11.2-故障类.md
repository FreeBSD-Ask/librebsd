# 072.11.2 故障类

### 故障类-1

- **新闻标题（中英）**：FreeBSD 1.0 RELEASE now available（FreeBSD 1.0 正式版现已发布）
- **新闻来源**：comp.os.386bsd.announce Usenet newsgroup + Jordan K. Hubbard（乔丹·哈伯德） + 1993-11-01 + **<https://www.freebsd.org/releases/1.0/announce/>** + FreeBSD 官方归档（2021-02-21 由 Danilo G. Baio 最后修改）
- **新闻摘要**：Jordan K. Hubbard 在 Usenet 新闻组 comp.os.386bsd.announce 发布 FreeBSD 1.0 RELEASE 公告，明确标注"the first ‘official’ release of FreeBSD 1.0, no more greek letters"，列出动态缓冲区缓存机制、Linux 声卡驱动（Gravis UltraSound、SoundBlaster）、Mitsumi CDROM 接口、XFree86 2.0 syscons 支持等新增功能，明确致谢 Walnut Creek CDROM“持续的（迄今仍无利可图的）支持使这一切成为可能”（原文：“continuing thanks to Walnut Creek CDROM who’s ongoing (and, up to now, profitless) support has made this all possible”，中译为本文件责任）。公告落款为“The FreeBSD Team”，联系方式为 <freebsd-questions@freefall.cdrom.com>、<freebsd-bugs@freefall.cdrom.com>、<freebsd-hackers@freefall.cdrom.com>。
- **与本章主题的关联说明**：本章核心是 FreeBSD 1.0 发布里程碑，该 Usenet 公告是 FreeBSD 1.0 发布的唯一一手官方公告，构成本章时间线的锚点。公告中“no more greek letters”印证 FreeBSD 1.0 发布前存在 ALPHA、BETA、EPSILON 等希腊字母预发布版本的事实；公告中 freefall.cdrom.com 域名印证 Walnut Creek CDROM 为 FreeBSD 项目提供开发主机与互联网接入的事实。
- **与官方史料的交叉验证结论**：该公告本身即为 FreeBSD 项目官方史料，与 FreeBSD Handbook 1.3.1 节“第一个 CD-ROM（以及在整个互联网范围内发行的）发行版本是 FreeBSD 1.0，于 1993 年 10 月发布”的叙事基本一致，但 Handbook 中文译本标注“1993 年 10 月”与公告 Usenet Date 头“1 Nov 1993 16:12:20 -0800”存在月份差异——以 Usenet Date 头为准，FreeBSD 1.0 发布日期为 1993-11-01。
