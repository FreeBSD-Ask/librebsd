# 072.3.3 FreeBSD 1.0 的技术特性

**要点**：FreeBSD 1.0 基于 4.3BSD Net/2 + 386BSD 组件 + FSF 组件，支持 386/486 处理器、ISA 总线、SCSI/IDE 磁盘；引入 GCC、XFree86、TCP/IP 网络栈；Ports 软件包管理系统在 1.0 中是否存在 [考据完成：2026-08-17 FreeBSD 1.0（1993.11）不含 Ports；pkg_install 工具 1993-08-26 已提交，Ports 框架由 Jordan Hubbard 于 1994-08-21 首次提交]，由后续版本引入
  
**史料**：FreeBSD 1.0 原始公告、FreeBSD 1.0 Release Notes、FreeBSD Handbook 官方历史 ［A］
  
**史观**：硬件与软件辩证：FreeBSD 1.0 的硬件支持范围决定了其早期用户群
  
**辨析**：原始公告提及的特性包括动态缓冲区缓存、Linux 声音驱动（Gravis UltraSound/SoundBlaster）、Mitsumi CDROM 接口、更新的安装软盘、更安全的 ISA 设备探测、syscons 对 XFree86 2.0 的高级支持；~~原 “4.3BSD-Reno” 说法错误~~（Handbook 明确为 Net/2）；FreeBSD 1.0 不含 Ports，Ports 框架由 Jordan Hubbard 于 1994-08-21 首次提交，属后续版本引入（考据完成：2026-08-17）
  
**文献**：FreeBSD 1.0 RELEASE Announcement (1 Nov 1993)；FreeBSD Handbook “A Brief History of FreeBSD” ［B］
