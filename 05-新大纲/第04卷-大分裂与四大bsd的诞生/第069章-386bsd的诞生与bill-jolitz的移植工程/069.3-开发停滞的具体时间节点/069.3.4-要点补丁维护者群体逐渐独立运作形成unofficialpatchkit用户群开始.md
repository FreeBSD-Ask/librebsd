# 069.3.4 要点补丁维护者群体逐渐独立运作形成unofficialpatchkit用户群开始

  **要点**：补丁维护者群体逐渐独立运作，形成 unofficial patchkit；用户群开始流失至 Linux 与其他 BSD 雏形；386BSD 的滞后直接催生了 1993.6 FreeBSD 与 1993.4 NetBSD 的 fork
  
**史料**：comp.unix.386bsd 1993 年用户流失讨论、FreeBSD 1.0 公告、NetBSD 创建邮件［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］
  
**史观**：分离与聚合：停滞是分离的催化剂，社区在等待中分裂出新的项目
  
**辨析**：FreeBSD fork 的具体动机在不同叙事中权重不同——FreeBSD Project 强调 “社区驱动”，Jolitz 夫妇强调 “窃取用户群”，需对照原始邮件列表
