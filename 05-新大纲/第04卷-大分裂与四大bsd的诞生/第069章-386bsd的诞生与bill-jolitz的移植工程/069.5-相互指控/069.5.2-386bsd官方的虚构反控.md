# 069.5.2 386BSD 官方的虚构反控

  **要点**：Lynne Jolitz 在 386BSD.org 与相关文章中指控 FreeBSD 起源叙事存在严重偏差，称 FreeBSD 从 386BSD 分叉时未充分承认其代码继承关系；Bill Jolitz 也在多个场合表达类似立场
  
**史料**：386BSD.org 历史版本 archive.org 快照、Lynne Jolitz 在 2000 年 Salon 专访中的陈述、Jolitz 夫妇 “Operating System Source Code Secrets” 系列著作中的历史回顾 ［A］
  
**史观**：终结与延续：起源叙事的争夺是对历史定义权的争夺
  
**辨析**：双方叙事都存在选择性记忆——FreeBSD 强调 Jolitz 失职，Jolitz 强调 FreeBSD 窃取；需对照原始邮件列表与源码历史独立核验；原文献引用 “Lynne Jolitz ‘The Unknown History of FreeBSD’ Salon (1999)” 为错误信息——该文章不存在
  
**文献**：Chalmers, R. “The unknown hackers” Salon, 17 May 2000；386BSD.org 历史页面（Internet Archive 存档）；Jolitz & Jolitz “Operating System Source Code Secrets” 系列 ［A］
