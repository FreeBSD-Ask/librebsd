# 079.2.3 procfs 权限泄漏、rfork 系统调用缺陷与 tgetent/xterm 缓冲区溢出——OpenBSD 2.1/2.2 时期本地提权与内存破坏漏洞群

  **要点**：OpenBSD 2.1（1997 年 5 月发布）的 **procfs(5)** 文件系统挂载后进程内存映射对其他用户可读，本地用户可借由 `/proc/[pid]/mem` 读取其他用户进程内存实现信息泄漏；**rfork(2)** 系统调用作为 4.4BSD 进程创建原语（fork 的底层实现）存在文件描述符表与信号处理表共享逻辑缺陷，可被利用实现本地权限提升；**vacation(1)** 自动回复程序在处理邮件头字段时存在输入验证缺陷，可被构造邮件触发缓冲区溢出或命令注入；**lpd(8)** 行式打印守护进程在处理远程打印请求时缺乏输入验证与地址认证，远程攻击者可触发缓冲区溢出或未授权打印；**tgetent(3)** termcap 数据库读取函数在读取 termcap 条目至固定大小缓冲区时缺乏边界检查，构造超长条目可触发缓冲区溢出；OpenBSD 2.2（1997 年 10 月发布）的 **xterm(1)** 与 Xaw 库在处理 `inputMethod`、`preeditType`、`*Keymap` 资源时存在缓冲区溢出，内核 IP 源路由处理在 `net.inet.ip.forwarding` 启用且 `net.inet.ip.sourceroute` 禁用时的逻辑缺陷亦被识别；上述漏洞群覆盖本地提权（procfs/rfork）、远程内存破坏（lpd）、本地内存破坏（tgetent/xterm）与信息泄漏（procfs）四类技术机制，属于 OpenBSD 2.1/2.2 全代码审计向系统调用层与用户态工具深化的成果
  
**史料**：OpenBSD 2.1 errata 页面（openbsd.org/errata21.html）、OpenBSD 2.2 errata 页面（openbsd.org/errata22.html）、4.4BSD procfs 实现源码、XFree86 3.3.x 安全公告存档、OpenBSD CVS 历史系统调用层与用户态工具 commit 序列 ［A］
  
**史观**：procfs/rfork/tgetent/xterm 漏洞群体现全代码审计从网络服务层向系统调用层与用户态工具层的深化；总纲第 10 条——动手者创造历史：de Raadt 与早期开发者以逐行审计的工程实践识别 4.4BSD-Lite 遗留的深层漏洞
  
**辨析**：procfs 内存映射可读性的精确权限模型须对照 4.4BSD procfs 实现与 OpenBSD 2.1 源码核实；rfork 文件描述符表共享缺陷的具体触发路径须对照 **rfork(2)** 手册页与 OpenBSD CVS 历史 commit 核实；tgetent/xterm 缓冲区溢出的发现者与披露时点在 errata 原文中未注明，须对照 XFree86 安全公告与 termcap 库发布说明交叉验证；【0 信任原则·errata 无 CVE 引用】上述漏洞群在 OpenBSD 2.1/2.2 errata 中均未引用 CVE 编号，CVE 体系 1999 年方建立；【0 信任原则·漏洞群归类风险】将 procfs/rfork/tgetent/xterm/lpd/vacation 归类为 “本地提权与内存破坏漏洞群” 是史家的叙事组织，errata 原文按独立条目发布而非按技术机制分组，史家须在辨析中说明归类的叙事性质
