# 089.9.4 外部冲击类

### 新闻条目 1

- **新闻标题（中英）**：FreeBSD 2.0.5 ALPHA Release Notes — 4.4BSD-Lite transition context（FreeBSD 2.0.5 ALPHA 发行说明 —— 4.4BSD-Lite 过渡背景）
- **新闻来源**：FreeBSD Project 官方网站 + FreeBSD Project 集体署名 + 1995-06 + **<https://www.freebsd.org/releases/2.0.5R/notes.html>** + 访问日期 2026-07-27
- **新闻摘要**：FreeBSD 2.0.5 ALPHA 发行说明记载 FreeBSD 自 1.0 起近两年的过渡，明确陈述 4.4BSD-Lite 重构的法律意义：“Since our first release of FreeBSD 1.0 nearly two years ago, FreeBSD has changed almost entirely. A new port from the Berkeley 4.4 code base was done, which brought the legal status of the system out of the shadows with the blessing of Novell (the new owners of USL and UNIX).“发行说明同时记载 FreeBSD 2.0.5 的性能改进：”Since our release of FreeBSD 2.0 some 8 months ago, the performance, feature set, and stability of FreeBSD has improved dramatically. The largest change is a revamped VM system with a merged VM/file buffer cache that not only increases performance, but reduces FreeBSD's memory footprint, making a 4MB configuration a more acceptable minimum.”
- **与本章主题的关联说明**：本章 4.4BSD-Lite 发布事件须包含 FreeBSD 阵营对 4.4BSD-Lite 重构的工程层陈述，FreeBSD 2.0.5 ALPHA 发行说明是 FreeBSD 阵营对自身 4.4BSD-Lite 重构工程的当事人叙事，构成本章 FreeBSD 阵营工程层证据。发行说明中“out of the shadows with the blessing of Novell”陈述显示 FreeBSD 阵营将 4.4BSD-Lite 重构视为法律正名，与 McKusick 亲述的“Novell's ‘blessing’”陈述一致。
- **与官方史料的交叉验证结论**：发行说明关于“FreeBSD 1.0 至 2.0.5 近两年”的陈述与 FreeBSD 1.0 1993-11-01 发布、FreeBSD 2.0.5 1995-06 发布的时序一致；关于“4.4BSD-Lite 重构”的陈述与 FreeBSD Handbook 1.3.1 节“FreeBSD then set about the arduous task of literally re-inventing itself from a completely new and rather incomplete set of 4.4BSD-Lite bits”一致；关于“Novell 收购 USL 与 UNIX”的陈述与 McKusick 亲述“USL was bought from AT&T by Novell”一致。

**史家判断**（证据等级：L2，来源：`cross_indexes.duckdb.concept_history.21`）

虚拟内存：虚拟内存概念的演化: 思想萌芽：1950 年代 Güntsch 等提出以自动存储管理化解手工“覆盖”（overlay）编程负担。确立期：1959–1962 年英国曼彻斯特大学 Kilburn 团队在 Atlas 计算机上首次实现“单级存储”（后称虚拟内存），以磁鼓为辅助存储，硬件自动在主存与磁鼓间搬移代码数据从而取消人工覆盖，并配套产生 Atlas Supervisor；该成果获 IEEE 里程碑。产业化：1961 年 Burroughs 推出采用段式管理的首款商用虚拟内存系统。理论奠基：1962 年 Kilburn、Edwards、Lanigan、Sumner 发表《One-Level Storage System》
