# 089.4.3 文档史的形式主义分析

  **要点**：4.4BSD-Lite Release Notes 的文档史形式主义分析显示——文档作为 “形式” 承载技术 “内容”，但文档的形式（官方发布）与内容（实际代码）存在张力——部分文档内容可能滞后于代码变更；文档与代码的关系经 4.4BSD-Lite Release Notes 1994.6 技术变更列表与 4.4BSD-Lite 源码 diff 对照可量化
  
**史料**：4.4BSD-Lite Release Notes；4.4BSD-Lite 源码档案；CSRG 文档与代码 diff ［A］
  
**史观**：形式与内容：文档作为形式与代码作为内容存在张力，两者的关系经 4.4BSD-Lite Release Notes 1994.6 与 4.4BSD-Lite 源码档案对照可追溯——技术变更列表与源码 diff 高度一致，贡献者名单与 SCCS 元数据存在滞后
  
**辨析**：形式主义分析的边界——部分文档与代码高度一致（如 4.4BSD-Lite Release Notes 的技术变更列表与源码 diff 一致），部分存在滞后（如贡献者名单可能未记录最后时刻的补丁）；须逐项对照 Release Notes 与源码档案核实
  
**文献**：4.4BSD-Lite Release Notes 与源码 diff 分析 ［A］
