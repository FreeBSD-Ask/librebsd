# 089.3.4 要点解散的史料辨析须区分组织解散与技术终结前者有据可循CSRG19956Mike

  **要点**：解散的史料辨析须区分 “组织解散” 与 “技术终结”——前者有据可循（CSRG **1995.6** Mike Karels 告别邮件 “Berkeley CSRG is now disbanded”），后者经三大 fork 项目继承 4.4BSD-Lite2 代码延续（FreeBSD 2.0 **1994.11.22**、NetBSD 1.0 **1994.10.26**、OpenBSD **1995.10** fork）；组织与技术的平衡经 CSRG 解散（组织终结）与三大 fork 持续至 **2026 年**（技术延续）的对照可量化
  
**史料**：CSRG 解散档案；FreeBSD/NetBSD/OpenBSD 早期项目档案；BSD 技术传承分析［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档/L5 二手研究〕
  
**史观**：0 信任原则：解散史料（Karels 告别邮件 1995.6、McKusick 1999 Open Sources 当事人一手记载、CSRG 解散档案）须对照 FreeBSD/NetBSD/OpenBSD 早期项目档案交叉验证，不得因 “CSRG 解散” 而误认为 “BSD 终结”
  
**辨析**：解散的史料价值在 “组织解散” 维度有据可循（CSRG 1995.6 Karels 告别邮件），但在 “技术终结” 维度经 FreeBSD/NetBSD/OpenBSD 三大 fork 持续至 2026 年的客观事实可证伪——BSD 技术通过社区项目长期延续，组织解散与技术终结非同一维度

虚拟内存：虚拟内存概念的演化: 思想萌芽：1950 年代 Güntsch 等提出以自动存储管理化解手工“覆盖”（overlay）编程负担。确立期：1959–1962 年英国曼彻斯特大学 Kilburn 团队在 Atlas 计算机上首次实现“单级存储”（后称虚拟内存），以磁鼓为辅助存储，硬件自动在主存与磁鼓间搬移代码数据从而取消人工覆盖，并配套产生 Atlas Supervisor；该成果获 IEEE 里程碑。产业化：1961 年 Burroughs 推出采用段式管理的首款商用虚拟内存系统。理论奠基：1962 年 Kilburn、Edwards、Lanigan、Sumner 发表《One-Level Storage System》
