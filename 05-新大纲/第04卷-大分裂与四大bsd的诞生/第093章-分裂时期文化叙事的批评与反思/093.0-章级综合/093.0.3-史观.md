# 093.0.3 史观

- 总纲第 23 条——一切历史写作都是基于哲学设定的历史小说：分裂时期的文化叙事（三项目差异的浪漫化、冲突事件的选择性记忆）属历史写作，其哲学设定先于史料筛选，批评须先揭示叙事预设再核对史实
- 总纲第 15 条——文化即形式主义：三项目文化差异的标签化表述是叙事形式而非实质，须对照具体事件（386BSD patchkit 分裂、de Raadt 被逐、Jolitz 指控）验证，不得直接采信
- 总纲第 7 条——理论必须自反：对浪漫化与选择性记忆的批评自身亦须自反，须区分有据叙事与浪漫化叙事，不得因存在浪漫化而否定文化差异叙事的整体解释力
- 章级史观依《一刻哲学》25 条总纲权威表回填；子节史观见 86.9、86.10、86.11 各节史观字段
