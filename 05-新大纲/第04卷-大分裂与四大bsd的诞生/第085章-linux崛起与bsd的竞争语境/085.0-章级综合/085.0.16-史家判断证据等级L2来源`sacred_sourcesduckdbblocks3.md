将一切公理化在形式上似乎能消解理解问题，但会陷入解释学循环。我们本意是解决一个简单的操作问题，却演变为追问更底层的前提——这种因果倒退的唯一解决方式是回到起点。以往做法是：若读者不具备基本的前理解，便中断对话，而非无穷倒退。认为存在一种边界，这是实证主义科学中的一种典型思路。但那不是语言的边界，而是自身理论的边界。

我们往往预设了读者与作者享有相同的“前理解”与“前意识”。因此，随着讨论深入，分歧只会越来越多。史家书写历史时，同样预设了读者共享某些前理解——但这一预设本身就是形式主义。不同文化背景、不同技术背景、不同时代背景的读者，对同一史事的前理解截然不同。
