# 085.0.15 即使是复制粘贴如此简单的事情也罕有人去做他们的社区管理得也非常差只能容许一些所谓

即使是复制粘贴，如此简单的事情也罕有人去做。他们的社区管理得也非常差，只能容许一些所谓大佬在那里冒头，新人则得不到任何帮助，甚至连外网常说的 RTFM 都做不到，因为没有任何成体系的东西可读。甚至连一本入门手册都没写过，只是一直在搬运外网的文章。但这不是讽刺，因为无论要做些什么、写些什么，都会承担难以忍受的坏名声。这除了导致社区尽早解体外，没有别的好处。
