# 085.0.14 一切苦难都不值得被提倡那只是一种类似宗教救赎的神话叙事结构苦难并不会使人变得优秀

一切苦难都不值得被提倡，那只是一种类似宗教救赎的神话叙事结构。苦难并不会使人变得优秀，只会让人隐藏自己真实的主体性。在这种结构中，苦难被别有用心者包装成为通达幸福的必由之路。历经苦难的人，其主体性已被苦难所异化。凡是强调苦难的意义和推崇苦难本身者都有其潜在的龌龊目的。
