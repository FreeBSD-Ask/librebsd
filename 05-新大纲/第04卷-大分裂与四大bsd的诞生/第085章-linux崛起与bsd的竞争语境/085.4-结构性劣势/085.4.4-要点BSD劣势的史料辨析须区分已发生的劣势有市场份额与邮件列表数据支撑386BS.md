# 085.4.4 要点BSD劣势的史料辨析须区分已发生的劣势有市场份额与邮件列表数据支撑386BS

  **要点**：BSD 劣势的史料辨析须区分 “已发生的劣势”（有市场份额与邮件列表数据支撑——386BSD 1992.7 后维护停顿、FreeBSD/NetBSD 1993 年 fork 后 1994 年才完成 4.4BSD-Lite 迁移、Linux 内核贡献者 1995 年达约 200 人远超 BSD 三大分支总和）与 “被夸大的劣势”（包含部分 “BSD 已死” 叙事的情绪渲染——“BSD is dying” 梗将桌面市场份额下滑夸大为整体消亡）；两类叙事经 BSD 与 Linux 邮件列表活跃度对比、“BSD is dying” 梗的传播记录与市场份额第三方统计交叉验证后须分两层处理
  
**史料**：BSD 与 Linux 邮件列表活跃度对比；市场份额第三方统计；“BSD is dying” 梗的传播记录 ［A］
  
**史观**：本项目 0 信任考据纪律（去条号化：非总纲命题）：市场份额与活跃度数据须考据——第三方统计口径（Netcraft 按域名计数 vs W3Techs 按 Web 站点技术栈检测）与邮件列表采样方法（按发帖数 vs 按订阅数）须经原始数据来源交叉验证
  
**辨析**：BSD 劣势的 “已发生” 维度有据可循（386BSD 维护停顿、FreeBSD 1994.11.22 重建后仍需追赶 Linux 1.0 1994.3 的 8 个月窗口），但在 “被夸大” 维度须谨慎——FreeBSD 在服务器市场（Yahoo、Hotmail 后端 1990 年代后期使用 FreeBSD）、CDN（Netflix Open Connect CDN 项目约 2011-2012 年公开〔原“2007 年起”系将流媒体上线年与 CDN 项目年混并，已按时间线订正〕；FreeBSD 为 OpenConnect 载体之说成立）、嵌入式（Juniper JunOS、PlayStation）领域长期保持强势；“桌面市场劣势”（Linux 桌面发行版远超 BSD 桌面，2020 年代 Linux 桌面约 2% 而 BSD 桌面不足 0.1%）与 “整体生态劣势”（BSD 在特定领域持续深耕，非整体衰退）非同一维度，“BSD is dying” 叙事混淆了两个维度
  
**文献**：BSD 与 Linux 邮件列表活跃度对比研究；第三方市场份额统计 ［A］
