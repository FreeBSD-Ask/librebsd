# 085.7.11 Linus Torvalds 在 netdev 审议 __kernel_

**要点**：2019 年 6 月，Linus Torvalds 在 netdev 审议 __kernel_fsid_t 命名空间修复补丁时援引 statfs(2) 手册页：Linux 与 SunOS、HP-UX、4.4BSD 同有返回 fsid_t（struct { int val[2]; }）的 statfs(2)，FreeBSD 亦然仅头文件为 <sys/mount.h>，据此判定用户态按 val[] 访问的既有依赖不可破坏、补丁不可接受。

**史料**：**historical_claims.duckdb.claim.CL-RM-012794**（证据 `EV-RM-012794`，批次锚点 kw_batch_07_row17）；源邮件：Linus Torvalds. Re: [PATCH] uapi: avoid namespace conflict in linux/posix_types.h[EB/OL]. (2019-06-07). netdev 邮件列表. <CAHk-=wio1e4=WUUwmo-Ph55BEgH_X3oXzBpvPyLQg2TxzfGYuw@mail.gmail.com>

**史观**：总纲 8（本体论上各方平等）——Linux 与 SunOS、HP-UX、4.4BSD、FreeBSD 的 statfs(2) API 平行对照、不预设优劣；总纲 9（经验优先）——以 statfs(2) 手册页跨系统记载与用户态既有依赖为经验层证据
