# 085.8.3 外部冲击类

### 新闻条目 1

- **新闻标题（中英）**：FreeBSD 2.0.5 ALPHA Release Notes — 4.4BSD-Lite transition and performance（FreeBSD 2.0.5 ALPHA 发行说明 —— 4.4BSD-Lite 过渡与性能）
- **新闻来源**：FreeBSD Project 官方网站 + FreeBSD Project 集体署名 + 1995-06 + **<https://www.freebsd.org/releases/2.0.5R/notes.html>** + 访问日期 2026-07-27
- **新闻摘要**：FreeBSD 2.0.5 ALPHA 发行说明记载 FreeBSD 自 1.0 起近两年的过渡："Since our first release of FreeBSD 1.0 nearly two years ago, FreeBSD has changed almost entirely. A new port from the Berkeley 4.4 code base was done, which brought the legal status of the system out of the shadows with the blessing of Novell (the new owners of USL and UNIX).“发行说明同时记载 FreeBSD 2.0.5 的性能改进：”Since our release of FreeBSD 2.0 some 8 months ago, the performance, feature set, and stability of FreeBSD has improved dramatically. The largest change is a revamped VM system with a merged VM/file buffer cache that not only increases performance, but reduces FreeBSD's memory footprint, making a 4MB configuration a more acceptable minimum."
- **与本章主题的关联说明**：本章论战叙事须包含 1994-1995 年 FreeBSD 法律过渡与性能改进的背景，FreeBSD 2.0.5 ALPHA 发行说明是 FreeBSD 阵营对自身技术演进与法律过渡的当事人叙事，构成本章 FreeBSD 阵营“法律过渡后性能改进”立场锚点。发行说明中“out of the shadows with the blessing of Novell”陈述显示 FreeBSD 阵营将 4.4BSD-Lite 重构视为法律正名，与 Linux 阵营“从未受 USL 诉讼影响”形成对照。
- **与官方史料的交叉验证结论**：发行说明关于“FreeBSD 1.0 至 2.0.5 近两年”的陈述与 FreeBSD 1.0 1993-11-01 发布、FreeBSD 2.0.5 1995-06 发布的时序一致；关于“4.4BSD-Lite 重构”的陈述与 FreeBSD Handbook 1.3.1 节"FreeBSD then set about the arduous task of literally re-inventing itself from a completely new and rather incomplete set of 4.4BSD-Lite bits"一致；关于“Novell 收购 USL 与 UNIX”的陈述与 FreeBSD Handbook 1.3.1 节、Salon 2000-05-17 专访一致。
