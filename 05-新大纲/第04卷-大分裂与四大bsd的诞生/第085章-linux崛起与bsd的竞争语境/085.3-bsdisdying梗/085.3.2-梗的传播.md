# 085.3.2 梗的传播

  **要点**：梗在 2000 年代中期通过 Slashdot、Reddit、Digg、OSNews 等技术媒体快速扩散，每次 BSD 版本发布或社区事件都被附会为 “BSD is dying” 的新证据，形成自我强化的传播循环
  
**史料**：Slashdot BSD 标签页面存档；Reddit r/BSD r/BSDlinux 早期讨论；OSNews BSD 相关报道；Digg BSD 投稿 ［A］
  
**史观**：总纲第 4 条——分离聚合是永恒规律：梗的传播既是 BSD 社区聚合的纽带（集体自嘲），也是 BSD 与 Linux 阵营分离的边界标记
  
**辨析**：梗的传播机制在不同分析中有 “被动扩散” 与 “主动调侃” 两种解释——前者强调 Linux 社区的攻讦（Slashdot 评论中 Linux 用户对 BSD 帖子的踩踏式回应），后者强调 BSD 社区的自嘲（Daemon News 与 BSD Today 中 BSD 成员主动引用梗的反讽式文章）；两类叙事经 Slashdot BSD 标签页面与 Daemon News 邮件列表存档交叉验证后，发现并非对立——主动调侃在 1998-2001 年为主，被动扩散在 2002-2005 年 Reddit、Digg 兴起后增强
