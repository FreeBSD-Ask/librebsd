# 074.5.2 de Raadt 与 Demetriou/Hannum 的张力

  **要点**：de Raadt 直率作风与其他核心成员的矛盾在邮件列表上多次公开爆发；**1994 年 12 月**，de Raadt 被要求辞去 NetBSD 开发工作并被取消 CVS 仓库访问权限（被逐出 Core Team）；被逐后 de Raadt 于 **1995 年 10 月** 从 **NetBSD 1.0** fork 创立 OpenBSD 项目，第一个正式版本 **OpenBSD 1.2** 于 **1996 年 7 月** 发布，**OpenBSD 2.0** 于 **1996 年 10 月** 发布。de Raadt 离开 NetBSD 事件时间线如下：

| 事件 | 日期 | 备注 |
| -- | -- | -- |
| NetBSD 1.0 release tag | 1994-10-26 | de Raadt 仍为核心成员 |
| NetBSD 1.0 公告 | 1994-11-08 | Demetriou 发布 |
| de Raadt 末次 commit | 1994-12-17 | `699d2a37b0e3c0c6ff29ea0d407c3feeba5642b4` |
| 被逐出 Core Team | 1994 年 12 月 | 约在 1.0 发布后两个月 |
| OpenBSD fork | 1995-10 | 从 NetBSD 1.0 派生 |
| OpenBSD 1.2 发布 | 1996-07 | 继承 NetBSD 版本号体系 |
| OpenBSD 2.0 发布 | 1996-10 | — |

**史料**：OpenBSD 项目历史记载、de Raadt 个人自述、NetBSD Core Team 相关邮件（部分公开）、中文多方来源交叉验证（1994 年 12 月时间点）；netbsd.duckdb 查询 L2.1.Theo_de_Raadt_leaves_NetBSD 显示：以 1994-12-01 为事件日，netbsd-src 在 after 期间（1994-12-01 至 1995-05-31，6 个月）total_commits = 6,678、month_count = 6、avg_monthly = 1,113.0；查询仅返回 1 行（after 期间），before 期间（1994-06-01 至 1994-11-30）无数据返回，可能因 netbsd-src GitHub 镜像在 before 期间 commit 量统计缺失或查询参数边界问题，须与 NetBSD CVS 主仓档案交叉验证；deraadt 在 netbsd-src 末次 commit 为 1994-12-17T23:12:41Z（commit_hash `699d2a37b0e3c0c6ff29ea0d407c3feeba5642b4`），与被逐日期 1994.12.23 仅相差 6 天，为事件时间线提供客观印证 ［A］

**史观**：总纲第 4 条——分离聚合是永恒规律：技术社区的人际张力是项目分裂的直接诱因，分离后产生新聚合（OpenBSD）

**辨析**：de Raadt 被驱逐的具体决议文本未完整公开，Core Team 内部成员各执一词；驱逐发生于 NetBSD 1.0 发布（1994.10）后约两个月，而非 1996 年；OpenBSD 第一个版本号为 1.2（继承自 NetBSD 版本号体系）而非 1.0，反映了其从 NetBSD 派生的事实；【0 信任原则·commit 量不等于质量】L2.1.theo_fork 的 after 期间 commit 量（6,678 commits/6 个月）反映 NetBSD 在 de Raadt 离开后仍保持开发活跃度，但 commit 量不等于代码质量，须结合 commit message 主题词与文件路径交叉验证 de Raadt 离开对 NetBSD 技术方向的具体影响；【0 信任原则·before 期间数据缺失】查询仅返回 after 期间数据，before 期间无数据返回，无法直接对比 de Raadt 离开前后的 commit 量变化，事件影响评估须结合 NetBSD CVS 主仓档案补全 before 期间数据；【0 信任原则·GitHub 镜像滞后】netbsd-src 为 GitHub 镜像，commit 量可能滞后于主仓（CVS），L2.1.theo_fork 数据须以 NetBSD 官方档案为准
