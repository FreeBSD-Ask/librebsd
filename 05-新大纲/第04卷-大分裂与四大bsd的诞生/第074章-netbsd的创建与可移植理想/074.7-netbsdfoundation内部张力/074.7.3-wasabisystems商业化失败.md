# 074.7.3 Wasabi Systems 商业化失败

  **要点**：Wasabi Systems 作为 NetBSD 唯一规模化商业支持公司，**2000-2009 年** 间尝试商业化路径最终失败；商业化失败使 NetBSD 失去关键资金与工程来源，加剧 Foundation 内部张力。Wasabi Systems 商业化兴衰时间线如下：

| 事件 | 时间 | 备注 |
| -- | -- | -- |
| Wasabi Systems 成立 | 2000 年 | NetBSD 商业化支持 |
| 规模化商业赞助期 | 2000-2007 年 | 关键资金与工程来源 |
| 商业化路径受挫 | 2007-2009 年 | Linux 商业发行版挤压 |
| 公司终止运营 | 2009 年 | NetBSD 失去关键支持 |

**史料**：Wasabi Systems 公司公告、NetBSD Foundation 与 Wasabi 合作协议摘要、Jay Michaelson 公开访谈 ［B］

**史观**：商业与社区的张力：商业化失败使社区失去商业支持，影响长期工程投入

**辨析**：Wasabi 失败的责任归属存在争议——部分归因于 Linux 商业发行版挤压，部分归因于战略失误；需对照 Wasabi 公告与 Foundation 内部记录核实

**文献**：Wasabi Systems 公司公告；Michaelson“On Wasabi”访谈 ［B］
