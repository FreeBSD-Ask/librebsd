# 074.1.3 创建的具体时间线

  **要点**：**1993-03-21** NetBSD CVS 仓库建立；**1993-04-19** Chris Demetriou 在 comp.os.386bsd.announce 发布 **NetBSD 0.8**（原始公告日期为 April 19, 1993，官方发布历史页标记为 April 20, 1993）；**1993-08-23** **NetBSD 0.9** 发布；**1994-10-26** **NetBSD 1.0** 正式 release tag，**1994-11-08** Demetriou 发布官方公告；项目初期聚焦质量与稳定性，“可移植性至上”（架构独立性）的工程哲学逐步确立。NetBSD 早期时间线如下：

| -- | -- | -- |
| CVS 仓库建立 | 1993-03-21 | cgd `initial import of 386bsd-0.1 sources` |
| NetBSD 0.8 公告 | 1993-04-19 | comp.os.386bsd.announce，FTP 开放日 04-20 |
| NetBSD 0.9 发布 | 1993-08-23 | — |

**史料**：NetBSD 官方 Formal Releases 历史页（netbsd.org/releases/formal.html）、Demetriou 0.8 原始公告（19 Apr 1993）、Demetriou 1.0 原始公告（8 Nov 1994）；netbsd.duckdb 数据库证据——netbsd-src 中 cgd 1993-03-21T09:45:37Z “initial import of 386bsd-0.1 sources”（commit_hash `0d110d127c41d7aeb2b1bfdc71964c5a496eabf9`）证实 1993-03-21 为 NetBSD 项目代码 import 起点；<christos@NetBSD.org> 在 netbsd-src 首次 commit 为 1994-10-26T11:58:24Z，与 NetBSD 1.0 release tag 日期完全一致，末次 commit 为 2026-07-13T18:46:33Z，共 34026 个 commit，是 NetBSD 项目最长持续贡献者；deraadt（Theo de Raadt）在 netbsd-src 末次 commit 为 1994-12-17T23:12:41Z，与其被 NetBSD 核心团队撤销 commit bit 的时间吻合；freebsd.duckdb 统计结论 C-03 显示：freebsd-src 总 commit 数 444,203（统计档案生成时点快照值，2026-09-12 实查已增至 445,203；SQL 查询 `SELECT COUNT(*) FROM commits WHERE repo_name='freebsd-src'`），与 netbsd-src 总 commit 数 773,683（C-04，统计档案生成时点快照值，2026-09-12 实查已增至 774,061）对照——NetBSD 总 commit 量约为 FreeBSD 的 1.74 倍，反映 NetBSD 在更长的时间跨度（1993-2026）与更多平台移植目标下的累计 commit 量更高；freebsd.duckdb 数据局限性总述标注：freebsd-src 存在 1993-11-29 时间戳异常（疑 SVN-to-Git 迁移伪时间戳），此日期与 FreeBSD 1.0 FTP 公告日（1993-11-01）接近但非同日，须与 FreeBSD 官方公告交叉验证，不得直接作为 FreeBSD 1.0 发布日依据

**史观**：总纲第 5 条——没有必然性，只有偶然性：NetBSD 0.8（1993.4）早于 FreeBSD 1.0（1993.11）约 7 个月发布，两项目并行发展决定了 BSD 生态的分化格局；统计结论印证总纲第 15 条——文化即形式主义——C-03 freebsd-src 444,203 commits 与 C-04 netbsd-src 773,683 commits 的量级差异反映两项目工程组织模式的分化（NetBSD 多平台移植累计 commit 更多，FreeBSD 聚焦 x86/64 性能优化 commit 粒度可能更大），第 25 章分离聚合是永恒规律在 commit 量层面得到量化印证

**辨析**：NetBSD 0.8 发布日期——原始 Usenet 公告日期为 April 19, 1993（Date: 19 Apr 1993 20:06:49 -0700），官方发布历史页标记为 April 20, 1993（可能为 FTP 站点正式开放或公告传播日期）；~~1994.4 的说法为严重事实错误~~（将 0.8 发布时间延后一年）；netbsd.duckdb 验证结论——NetBSD 1.0 release tag 日期（1994-10-26）与 <christos@NetBSD.org> 首次 commit 日期完全一致，但 christos 1994-10-26 的 commit 是其个人首次提交，与 NetBSD 1.0 release tag 在同日并非偶然——christos 作为 NetBSD 长期贡献者于 NetBSD 1.0 发布日加入，可作为 NetBSD 1.0 发布日期的间接旁证；deraadt 在 netbsd-src 末次 commit 1994-12-17T23:12:41Z，证实大纲记载 “1994 年 12 月 Theo de Raadt 被 NetBSD 核心团队撤销 commit bit” 的时间点；【0 信任原则·SVN-to-Git 迁移风险】C-03 freebsd-src 1993-11-29 时间戳异常疑为 2020 年 SVN-to-Git 迁移引入的伪时间戳——FreeBSD 2020 年 SVN-to-Git 迁移可能重写部分早期 commit 的 committer_date 字段，1993-11-29 须与 FreeBSD 1.0 原始公告（1993-11-01）与 FreeBSD Handbook 官方历史交叉验证，不得直接作为 FreeBSD 1.0 发布日依据；【0 信任原则·commit 量不等于质量】C-03 freebsd-src 444,203 与 C-04 netbsd-src 773,683 的量级差异不等于两项目代码质量或工程效率的差异——commit 粒度（单次 commit 的 additions/deletions 规模）、提交习惯（小步提交 vs 大步提交）、迁移历史（CVS-to-Git 转换可能拆分或合并原 CVS commit）均影响 commit 总数，须结合 commit_files 表与 commit 规模综合判断；【0 信任原则·多重比较风险】C-03 与 C-04 跨章引用时存在多重比较风险，须按 Bonferroni 或 Benjamini-Hochberg 校正后解读
