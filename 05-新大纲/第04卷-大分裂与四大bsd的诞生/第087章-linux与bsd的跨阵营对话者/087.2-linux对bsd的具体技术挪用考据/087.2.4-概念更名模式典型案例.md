# 087.2.4 概念更名模式典型案例

  **要点**：概念更名模式指 Linux 端对 BSD 端既有概念进行重新命名，新名称更通俗化或更具商业品牌感，使概念源头在新的命名下被遮蔽；本目选取 BSD 案例 7（jail → container）、BSD 案例 13（rc.d → systemd unit）、BSD 案例 5（ports → package manager）、BSD 案例 58（devfs → devtmpfs）4 项典型案例
  
**史料**：BSD 案例 7——Poul-Henning Kamp（波尔-亨宁·坎普） 1999 年设计 **jail(2)** 并 commit 进 FreeBSD 主线，2000-03-14 随 FreeBSD 4.0-RELEASE 首次公开发布（“OS-level virtualization”概念原型），Linux 端 LXC 2008-08-06（IBM 主导）、Docker 2013-03-20（Solomon Hykes）、Podman 2018（Red Hat）均以“container”自我标榜，主流第三方源偶有“similar to FreeBSD jails”式比附一笔带过；BSD 案例 13——V7 Unix 1979-01 Ken Thompson 释出 **/etc/rc** 单文件脚本，4.4BSD-Lite 1994-06 释出基于目录的 **/etc/rc.d/** 框架，NetBSD 1.3 1998-01-04 Luke Mewburn（卢克·缪伯恩） 重构（引入 **rcorder(8)** 与 rc.subr 与 PROVIDE 与 REQUIRE 元数据），Lennart Poettering（伦纳特·珀特林） 2010-03-30 首次 commit systemd，将“init script”重新命名为“unit”（`.service`、`.socket`、`.target`、`.mount`、`.timer`、`.path`），Poettering 2010-04-30 博客明确承认借鉴 NetBSD rc.d 与 Mac OS X launchd，但 systemd 主流叙事以“现代 init 设计”自我标榜；BSD 案例 5——FreeBSD 1.0 1993-11 将 BSD `pkg_add` 与 `pkg_delete` 与 `pkg_info` 与 `pkg_create` 工具集纳入基本系统，并以“ports”作为用户态源码包管理框架（FreeBSD ports 系统定型于 1994 至 1995），Debian 0.91 1994-01 释出 dpkg、1998-03-31 apt 公开，Red Hat 1995 rpm 释出，Linux 端软件包管理器均以“package manager”自我标榜，将 BSD“ports”概念更名为“package manager”；BSD 案例 58——Dima Dorfman 设计的 devfs 以“内核动态维护设备节点”哲学取代传统静态 **/dev** 目录与用户态 `mknod` 命令，FreeBSD 5.0-RELEASE 2003-01-19 首次以默认文件系统形式引入，Kay Sievers 2009-04-30 向 LKML 提交 devtmpfs patch，Linux 2.6.32 2009-12 首次将 devtmpfs 合入主线，“devfs”概念在 Linux 端被更名为“devtmpfs”以与 systemd 与 udev 体系绑定 ［A］
  
**史观**：同 79.11.1 总述，总纲第 11 条——商品是形式主义：概念更名以更通俗或更具商业品牌感的新名称将 BSD 端既有概念重新封装为“开源软件商品”，遮蔽概念源头
  
**辨析**：概念更名模式的考据须警惕“功能差异即原创”的简化陷阱——更名后概念的功能可能确实有差异，但功能差异不等于哲学原创；“container 不等于 jail”的差异（cgroup 与 namespace 对 **jail(2)**）是工程实现差异，不是哲学原创；4 项案例的“先验存在”均经一手档案印证——PHK 1999 FreeBSD 主线 commit 与 FreeBSD 4.0-RELEASE 2000-03-14 公告双源印证 jail 起源、4.4BSD-Lite 1994-06 **/etc/rc.d/** 框架与 NetBSD 1.3 1998-01-04 **rcorder(8)** 印证 rc.d 起源、FreeBSD 1.0 1993-11 `pkg_add` 工具集印证 ports 起源、FreeBSD 5.0-RELEASE 2003-01-19 公告印证 devfs 起源；【0 信任原则】Poettering 2010-04-30 博客承认借鉴 NetBSD rc.d 是“和解”的碎片，但主流叙事的整体倾向仍以“现代 init 设计”自我标榜
