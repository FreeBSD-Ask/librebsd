# 67.3 NetBSD 0.8

## 67.3.1 NetBSD 0.8 的开发

  **要点**：1993 年 3 月 Chris Demetriou 等四人启动 NetBSD 项目，约一个月后即发布 NetBSD 0.8（1993 年 4 月 19 日公告）；0.8 以 386BSD 0.1 为基础，应用 0.2.2 patch kit，集成 Net/2 中缺失的程序，修复大量 bug 提升稳定性；此时 MI/MD 分层架构尚在雏形阶段
  
**史料**：Demetriou 0.8 原始公告（19 Apr 1993）、NetBSD 0.8 Installation Notes、NetBSD 邮件列表 1993 年早期讨论 ［A］
  
**史观**：软件工程：快速发布与迭代是开源项目早期发展的典型模式
  
**辨析**：NetBSD 0.8 从项目启动到发布仅约一个月，本质上是 386BSD 0.1 的集成补丁版本，而非全新开发的系统；0.8 的命名反映了其作为 386BSD 后继者的定位
  
**文献**：Demetriou C G. “So you say you want an interim release of 386bsd?” (NetBSD 0.8 Announcement, 19 Apr 1993)；NetBSD 0.8 Installation Notes［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］

## 67.3.3 NetBSD 0.8 的技术特性

  **要点**：NetBSD 0.8 基于 386BSD 0.1 + 0.2.2 patch kit + Net/2 组件；仅支持 i386 平台（ISA/EISA，支持 Adaptec 154x/1742、Bustec 742、Ultrastor 14f SCSI 控制器、WD/SMC/Novell NE/3COM 以太网等）；与 386BSD 0.1 100% 二进制兼容；提供 GCC 1.39、G++、BSD make、TCP/IP 等用户空间；安装方式支持 MS-DOS floppies、Tape、NFS、FTP
  
**史料**：NetBSD 0.8 Installation Notes（完整列出支持硬件、分发集合、系统需求）、NetBSD 0.8 源码树 ［A］
  
**史观**：硬件与软件辩证：单平台起步是项目早期资源约束下的现实选择
  
**辨析**：0.8 仅支持 i386 平台，不支持 hp300、sparc 等其他平台——hp300 支持在公告中被列为未来计划（"perhaps even going back to Net/2 in order to re-integrate support for other architectures, such as the Hewlett-Packard 9000/300 family"），多平台支持在后续版本中逐步实现；0.8 不基于 4.3BSD-Reno，也不基于 4.4BSD-Lite
  
**文献**：NetBSD 0.8 Installation Notes (19 Apr 1993)［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］

## 67.3.4 NetBSD 0.8 的反响

  **要点**：NetBSD 0.8 在 comp.unix.bsd 社区获得关注，被视为 386BSD 的更稳定替代分支；公告中明确表达了“escape from the political wars”与“regular releases”的社区治理诉求，吸引了对 386BSD 维护停滞不满的开发者
  
**史料**：comp.os.386bsd.announce 1993 年反馈、netbsd-users 邮件列表早期讨论、Demetriou 原始公告中的项目定位表述 ［A］
  
**史观**：开源运动：NetBSD 的诞生回应了社区对稳定维护与开放治理的需求
  
**辨析**：0.8 发布时多平台支持尚未实现，其吸引非 x86 用户是后续版本（0.9/1.0）的效应；用户反响规模需对照 Usenet 帖量核验
  
**文献**：Demetriou C G. NetBSD 0.8 Release Announcement (19 Apr 1993)［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］
