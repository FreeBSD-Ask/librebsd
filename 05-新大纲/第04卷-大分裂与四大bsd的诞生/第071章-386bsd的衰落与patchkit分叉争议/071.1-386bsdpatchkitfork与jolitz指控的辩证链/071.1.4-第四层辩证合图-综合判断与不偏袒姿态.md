# 071.1.4 第四层辩证：合图——综合判断与不偏袒姿态

  **要点**：综合四层辩证，386BSD patchkit fork 与 Jolitz 指控的争议不能简化为 “个人英雄主义 vs 社区协作” 或 “窃取 vs 自救” 的二元结构——双方叙事都存在选择性记忆。Jolitz 夫妇的 “质量把控” 自辩部分成立（USL 诉讼确为外部压力），但 “等待 4.4BSD-Lite” 自辩与 386BSD 1.0 实际基于 0.1 的事实存在内在矛盾，需承认自辩的不完全性。FreeBSD 阵营的 “被迫 fork” 叙事部分成立（补丁积压确为事实），但 “被迫” 一词遮蔽了 patchkit 群体在分歧出现时未充分协商即 fork 的主动选择，需承认 fork 是主动决策而非纯粹被动反应。真正的 “悲剧” 不是个人英雄主义或社区失责，而是 BSD 在 1992-1994 年的关键窗口期被多重偶然因素叠加消耗——Jolitz 个人精力有限、USL 诉讼法律风险、单一维护者模型的结构性脆弱、社区协作机制的不成熟，四者叠加使 386BSD 错失窗口，Linux 在此期间获得关键发展期（Linux 1.0 发布于 1994 年 3 月 14 日）。合图阶段须明确——本章不判定 Jolitz 与 fork 群体 “谁更正确”，而是呈现争议的辩证结构本身
  
**史料**：综合前三层辩证所引史料——386BSD 0.1/1.0 Release Notes、4.4BSD-Lite Release Notes、FreeBSD 1.0 RELEASE Announcement、NetBSD 0.8 Release Notes、Chalmers Salon 2000.5.17 专访、freebsd.duckdb 查询 L1.1.1 与 L1.4.1、comp.unix.bsd 1992-1994 年帖、Linux 1.0 Release Announcement（1994.3.14） ［A］
  
**史观**：第 8 条本体论上各方平等——Jolitz 夫妇与 patchkit 群体在本体论上地位相等，无谁更 “正统”，差异仅是一刻状态的不同；第 19 条解释学循环是历史认识的根本条件——双方叙事都基于前理解，分歧不可避免，权力与知识在历史书写中共谋——什么被记录、什么被遗忘本身就是权力行使；第 5 条没有必然性，只有偶然性——Jolitz 停滞、USL 诉讼、patchkit fork 都是偶然事件，没有必然性，但此偶然叠加使 BSD 错失窗口成为既成事实
  
**辨析**：考据过程留痕——【查证来源】合图层不引入新的事实考据，仅综合既有辩证，新事实考据分散于 64.1-64.14 各节；本节所引史料均为前三层辩证已核验的一手史料——386BSD 0.1/1.0 Release Notes、4.4BSD-Lite Release Notes、FreeBSD 1.0 RELEASE Announcement、NetBSD 0.8 Release Notes、Chalmers Salon 2000.5.17 专访、freebsd.duckdb 查询 L1.1.1 与 L1.4.1、comp.unix.bsd 1992-1994 年帖、Linux 1.0 Release Announcement（1994.3.14）；【交叉验证方法】合图层的事实判断（如 “386BSD 1.0 仍基于 0.1 而非 4.4BSD-Lite” “FreeBSD 在 USL 诉讼期间以约 2-6 个月周期持续发布” “Linux 1.0 发布于 1994 年 3 月 14 日”）均经前三层辩证交叉验证，本节不重复考据过程，仅综合事实判断；叙事层面（“被迫 fork” “窃取用户群” “个人英雄主义” 等价值判断）须呈现双方立场而不予判定，区分事实层面与叙事层面——事实层面以一手史料为准考据，叙事层面呈现双方主体性的呈现与冲突；【存疑判定依据】合图阶段不等于 “各打五十大板” 的折衷主义——须区分事实层面（代码继承、版本发布时间、commit 记录可量化考据）与叙事层面（“被迫 fork” “窃取用户群” “个人英雄主义” 等价值判断）；本节不引入新的事实考据，仅综合既有辩证；0 信任原则提示——合图本身亦是史家的形式主义化重构，承认自身局限，史家须自反——本节 “四者叠加使 386BSD 错失窗口” 的判断本身是事后视角的重构，当事人当时未必有 “窗口” 的自觉，“错失窗口” 是史家赋予历史的意义而非历史本身的意义；本事件的不可调和性源于前理解的根本差异——Jolitz 夫妇以 “386BSD 是我们的创造物” 为前理解，patchkit 群体以 “386BSD 已停滞需自救” 为前理解，两种前理解不可通约，争议的不可调和性是解释学循环的必然结果而非任何一方的过错
