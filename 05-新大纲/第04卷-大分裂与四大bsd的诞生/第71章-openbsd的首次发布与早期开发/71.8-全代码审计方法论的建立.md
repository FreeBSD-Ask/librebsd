## 71.8.4 审计方法论的意义

  **要点**：审计方法论的意义在于塑造 OpenBSD 安全至上的工程文化——方法论成为 OpenBSD 项目的标识，影响后续 BSD 与 Linux 项目的安全实践
  
**史料**：OpenBSD 官方 FAQ、BSD 与 Linux 安全实践对比研究、开源社区访谈录
  
**史观**：总纲第 15 条文化即形式主义：全代码审计传统作为 OpenBSD 的文化仪式塑造其安全至上的工程文化，并影响后续 BSD 与 Linux 项目
  
**辨析**：方法论的外部影响在不同叙事中评估不一——部分视为决定性，部分视为辅助性；需对照多 BSD/Linux 项目安全实践核实

- CSRG 遭入侵事件使其重新转向安全，此后 OpenBSD 建立全代码审计传统；审计后又认识到审计还不够，继而引入 ProPolice 等防护机制。（BSD Now EP6，[594.81-721.24]，L1）
