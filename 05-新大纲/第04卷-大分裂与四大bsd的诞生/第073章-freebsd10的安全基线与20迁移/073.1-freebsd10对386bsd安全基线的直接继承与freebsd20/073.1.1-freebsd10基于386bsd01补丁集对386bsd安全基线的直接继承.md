# 073.1.1 FreeBSD 1.0 基于 386BSD 0.1 补丁集对 386BSD 安全基线的直接继承

  **要点**：FreeBSD 1.0（1993-11-01）由 Nate Williams（内特·威廉姆斯）、Rod Grimes、Jordan Hubbard 等在 386BSD 0.1 补丁集基础上 fork 发布，同时继承 U.C. Berkeley 的 4.3BSD-Lite（“Net/2”）磁带——FreeBSD 1.0 的安全基线来自 Net/2（即 4.3BSD-Reno 网络栈）经 386BSD 0.1 移植至 80386 平台，未引入新的安全机制；继承的安全基线包括 root/超级用户二元特权模型、文件权限 rwx 三段式结构、setuid/setgid 机制、基于 DES 的 **crypt(3)** 密码散列、Net/2 密码文件布局（公开可读的 `/etc/passwd` 与仅 root 可读的 `/etc/master.passwd` 并存，pwd_mkdb(8) 生成的 `/etc/spwd.db`/`/etc/pwd.db` 双数据库实现口令分离——shadow 机制随 Net/2 继承而非 FreeBSD 新增）；FreeBSD 1.0 因基线较早未直接继承 securelevel（4.4BSD-Lite 才引入），securelevel 须通过 FreeBSD 2.0（1994-11-22）rebase 至 4.4BSD-Lite 后方能进入 FreeBSD；FreeBSD 1.0 的安全补丁维护从此由 FreeBSD Core Team 集体治理，脱离 386BSD 单人维护模式
  
**史料**：FreeBSD 1.0 Release Announcement (1 Nov 1993)（明确说明基于 U.C. Berkeley‘s 4.3BSD-Lite (’Net/2') tape distribution）；386BSD 0.1 Release Notes (14 July 1992)；`freebsd-hackers` 邮件列表存档（1993-1994）；FreeBSD Handbook “A Brief History of FreeBSD” ［A］
  
**史观**：总纲第 4 条——分离聚合是永恒规律：FreeBSD 1.0 fork 386BSD 是分离后产生的新聚合，安全补丁维护从 386BSD 单人模式转为 FreeBSD Core Team 集体治理；总纲第 4 条——分离聚合是永恒规律（BSD 反向影响线）：FreeBSD 1.0 直接继承 386BSD 安全基线，是 BSD UNIX 安全基因在 FreeBSD 分支得以延续的直接史源
  
**辨析**：FreeBSD 1.0 的安全基线继承须区分 “Net/2 基础” 与 “386BSD 0.1 补丁集基础”——FreeBSD 1.0 同时继承 Net/2 与 386BSD 0.1 补丁集，安全基线来自 Net/2（即 4.3BSD-Reno 网络栈）经 386BSD 0.1 移植至 80386 平台；FreeBSD 1.0 未继承 securelevel 的考据基于 4.4BSD SMM: 16《On the Security of UNIX》（securelevel 于 4.4BSD 引入）与 FreeBSD 1.0 源代码的对照，FreeBSD 1.0 源代码中未发现 securelevel 相关代码；FreeBSD 1.0 的安全补丁维护须区分 “代码继承”（来自 386BSD 0.1）与 “补丁维护”（fork 后由 FreeBSD Core Team 独立维护）
  
**文献**：FreeBSD 1.0 Release Announcement (1 Nov 1993)；386BSD 0.1 Release Notes (14 July 1992)；FreeBSD Handbook “A Brief History of FreeBSD”；4.4BSD SMM: 16《On the Security of UNIX》 ［A］
