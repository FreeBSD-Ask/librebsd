# 073.4.2 总纲第 8 条审视：本体论上各方平等

  **要点**：Jolitz 夫妇与 FreeBSD fork 群体在本体论上地位相等——不存在 “Jolitz 是正统、FreeBSD 是叛离” 或 “FreeBSD 是进步、Jolitz 是保守” 的本体论等级。Jolitz 夫妇作为 386BSD 的创建者，其坚持单一维护者决策与高质量门槛的工程哲学在本体论上与 FreeBSD Core Team 坚持集体治理与加快发布节奏的工程哲学平等——二者都是 BSD 工程传统的合理呈现，差异仅是一刻状态的不同。FreeBSD、NetBSD、OpenBSD、DragonFly BSD 在本体论上地位相等，386BSD 亦然——386BSD 不是 “失败的先驱”，FreeBSD 不是 “窃取者”，二者都是 BSD 在 386 平台的特定一刻状态。文档与代码本体平等——FreeBSD Handbook 与 386BSD Release Notes、freebsd-src 仓库 commit 历史与 386BSD 0.0/0.1 源码树，在本体论上地位相等，无谁更 “权威”。商业资源的不对等（Walnut Creek CDROM 为 FreeBSD 提供开发机器与高速互联网接入）不构成本体论上的等级差异——商业资源是经验层面的差异，不改变本体论平等。合图阶段的不偏袒姿态即源于此——史家无权在本体论上判定 Jolitz 与 FreeBSD fork 群体 “谁更正确”，只能呈现各方主体性的呈现与冲突，与第 25 章 25.16.2 审视保持对称
  
**史料**：综合 26.1-26.13 各节史料 ［A］
  
**史观**：本体论上各方平等；经验优先：优先呈现质朴的事实与当事人的直接经验，而非套用 “窃取” “自救” “个人英雄主义” 等复杂框架
  
**辨析**：本体论平等不等于事实层面无差异——commit 量、版本发布时间、代码继承比例、商业资源注入等事实层面仍须以一手史料为准考据；本体论平等审视的是各方主体的存在地位，而非其具体行为的后果；本节审视不否定 26.13 合图阶段的事实判断（如 “FreeBSD 1.0 基于 386BSD 0.1 + Net/2 + FSF 组件”），而是在史观层面呈现各方本体论平等。考据过程留痕——【查证来源】项目史观总纲第 8 条原文 “本体论上各方平等。FreeBSD、OpenBSD、NetBSD、DragonFly BSD 在本体论上地位相等，差异仅是一刻状态的不同。文档与代码本体平等” 经 据原文第 25 章 第 12 行 Read 一手核验；项目史观总纲第 9 条原文 “经验优先。优先呈现质朴的事实与当事人的直接经验，而非套用复杂框架” 经第 13 行 Read 一手核验；freebsd.duckdb freebsd-src 仓库首条 commit（commit_hash `9002c02abc587664acb357c6879d8ca08664dd0b`）经 SQL 查询一手核验——commit message “Initial import, 0.1 + pk 0.2.4-B1” 证明 FreeBSD 1.0 工程基础直接建立在 386BSD 0.1 + patchkit 0.2.4-Beta1 之上（事实层面），但不改变 Jolitz 夫妇与 FreeBSD fork 群体在本体论上地位相等（史观层面）；FreeBSD Handbook 与 386BSD Release Notes 在本体论上地位相等——文档本体平等；【交叉验证方法】总纲第 8 条原文与 FreeBSD/386BSD/NetBSD/OpenBSD/DragonFly BSD 各方本体论地位交叉验证——Jolitz 夫妇作为 386BSD 创建者的工程哲学（单一维护者决策、高质量门槛）与 FreeBSD Core Team 坚持集体治理与加快发布节奏的工程哲学在本体论上各自成立，差异仅是一刻状态的不同，史家不得以组织权威视角压制个人主体性，亦不得以个人英雄视角否定组织治理的正当性；与第 25 章 25.16.2 审视的呼应——两章审视共同呈现 fork 争议的完整本体论平等结构，避免单章偏颇；【存疑判定依据】本体论平等审视的是各方主体的存在地位，而非其具体行为的后果——commit 量、版本发布时间、代码继承比例、商业资源注入等事实层面仍须以一手史料为准考据，本节审视不否定 26.13 合图阶段的事实判断（如 “FreeBSD 1.0 基于 386BSD 0.1 + Net/2 + FSF 组件”），而是在史观层面呈现各方本体论平等；0 信任原则提示——本体论平等是哲学判断而非史实判断，史家不得以 “本体论平等” 即否定事实层面的差异考据，亦不得以 “事实层面差异” 即否定本体论平等；商业资源的不对等（Walnut Creek CDROM 为 FreeBSD 提供开发机器与高速互联网接入）是经验层面的差异，不改变本体论平等，但商业资源不对等对叙事权力的影响须在 26.14.3 解释学循环审视中具体呈现
