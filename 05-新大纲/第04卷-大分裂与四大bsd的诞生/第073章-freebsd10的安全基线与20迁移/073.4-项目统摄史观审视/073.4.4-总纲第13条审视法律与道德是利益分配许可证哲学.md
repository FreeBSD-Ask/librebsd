# 073.4.4 总纲第 13 条审视：法律与道德是利益分配（许可证哲学）

  **要点**：BSD 许可证允许代码继承是 FreeBSD fork 法律合法性的基础——386BSD 0.1 以 BSD 许可证发布，允许任何人使用、修改、再分发，patchkit 群体 fork 386BSD 0.1 代码并发布 FreeBSD 1.0 在法律上完全合法。但法律合法性不等于叙事合法性——Jolitz 夫妇“全面窃取”指控的道德判断本质上是利益分配问题。Jolitz 夫妇作为 386BSD 创建者的归属感利益（“386BSD 是我们的创造物”）与 FreeBSD 阵营作为 patchkit 贡献者的工程继续利益（“我们有权利继续维护”）在本体论上各自成立，但法律层面 BSD 许可证不保护“归属感利益”，仅保护“代码使用权利”。BSD 与 GPL 的许可证哲学差异在此具体化——BSD 许可证允许 fork 不要求回馈，GPL 要求衍生作品同许可证发布；若 386BSD 0.1 采用 GPL 而非 BSD 许可证发布，FreeBSD fork 的法律基础将不同（GPL 要求衍生作品开源，但不阻止 fork 本身），此许可证设计的偶然性使 FreeBSD 的诞生成为既成事实。项目史观总纲第 13 条“法律与道德是利益分配”在此具体化——BSD 许可证是法律形式，“窃取”指控的道德判断是利益分配，社区治理亦是形式主义的政治产物；FreeBSD Core Team 集体治理模式与 386BSD 单人维护模式的冲突本质上是两种利益分配机制（贡献者集体决策 vs 创建者个人决策）的冲突，而非“先进与落后”的进步史观冲突。合图层须承认——法律层面 BSD 许可证允许代码继承无争议，道德层面“窃取”指控是利益分配不可调和，叙事层面“被迫 fork”与“全面窃取”两种叙事在本体论上各自成立，争议的不可调和性源于法律合法性与叙事合法性的根本分离

**史观**：法律与道德是利益分配；许可证：BSD 许可证允许代码继承是 fork 法律合法性的基础；本体论上各方平等：Jolitz 夫妇与 FreeBSD fork 群体在本体论上地位相等
  
**辨析**：法律合法性（BSD 许可证允许代码继承）与叙事合法性（“被迫 fork”叙事的简化程度）须精确区分——法律层面 FreeBSD fork 完全合法，叙事层面“被迫 fork”叙事的简化程度需对照多版本 FreeBSD Handbook 文本演变核验；道德判断（“窃取”指控）与事实判断（代码继承比例、commit 量）须精确区分——道德判断是利益分配，事实判断需以一手史料为准考据；BSD 与 GPL 的许可证哲学差异是反事实假设，无法实证核验，相关判断标为存疑。考据过程留痕——【查证来源】BSD 许可证文本经 FreeBSD 项目许可证页面核验，386BSD 0.1 以 BSD 许可证发布；项目史观总纲第 13 条原文“法律与道德是利益分配。任何道德问题本质上是利益问题，社区治理亦是形式主义的政治产物”经 据原文第 25 章 第 19 行 Read 一手核验；FreeBSD Handbook 经 docs.freebsd.org 一手核验；freebsd.duckdb freebsd-src 首 commit 经 SQL 查询一手核验；【交叉验证方法】总纲第 13 条原文与 BSD 许可证条款、Jolitz 夫妇“窃取”指控、FreeBSD 阵营“被迫 fork”自辩三方交叉验证——法律层面 BSD 许可证允许代码继承（无争议），道德层面“窃取”指控是利益分配（Jolitz 夫妇归属感利益 vs FreeBSD 阵营工程继续利益），社区治理层面 Core Team 集体治理 vs 单人维护是两种利益分配机制的冲突；与第 25 章 25.16 节审视的呼应——两章审视共同呈现 fork 争议的完整许可证哲学结构；【存疑判定依据】BSD 与 GPL 的反事实假设无法实证核验，相关判断标为存疑；0 信任原则提示——法律合法性不等于叙事合法性，道德判断不等于事实判断，史家不得以“BSD 许可证合法”即推论“起源叙事正当”，亦不得以“窃取”指控即推论“fork 不合法” 据一手文献印证消解^doubt-resolved-294：BSD 与 GPL 的反事实假设无法实证核验 ］
