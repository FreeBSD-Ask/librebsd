# 030.2.3 原始清单的内容分析

**要点**：1BSD READ_ME（**1977-11-23**）记载清单包含 Pascal 教学编译系统、ex 1.1 行编辑器、一个改进的 shell（modified shell）、一个新 shell（ashell，由 Joy 编写）、新命令集、Eric Allman（埃里克·奥尔曼） 编写的 “star trek” 游戏，以及机器可读文档；Pascal 系统与 ex 为主要组件，**csh**（C shell）与 **vi** 可视编辑器在 **2BSD**（**1979 年 5 月**）才首次出现

| 1BSD 组件 | 子目录 | 作者 / 来源 | 说明 |
| ------- | ---- | --------- | -- |
| Pascal 教学编译系统 | PASCAL | Ken Thompson 初创，Chuck Haley 与 Bill Joy 改进 | 源自 Zurich ETH 的 Pascal-P 编译器（Wirth 1975 Pascal-S） |
| ex 1.1 行编辑器 | EX | George Coulouris（em 原作者），Haley/Joy 改造 | 基于 em 改造为 en→eo→ep→ex |
| 改进的 shell | SH | Bell Labs ed 衍生 | modified shell |
| ashell（新 shell） | — | Bill Joy | 用于构建脚本的辅助 shell，非 csh |
| 新命令集 | NEWSRC | — | 新增命令集合 |
| star trek 游戏 | MSGS、TREK | Eric Allman | later sendmail 作者 |
| 机器可读文档 | MAN | — | 手册页 |

**史料**：1BSD READ_ME 原始文件（1977-11-23，TUHS 归档）、1BSD 原始磁带内容目录、CSRG 发布说明、伯克利存档的 README 文件 ［A］

**史观**：第 9 条经验优先——1BSD 内容是 Joy 在实际开发中积累的工具集合，而非系统性设计的产物

**辨析**：1BSD 是否包含 vi 的早期版本存在争议，TUHS 归档的 1BSD 文件清单与 READ_ME 均无 vi，多数权威史料确认 vi 在 2BSD（1979 年 5 月）才正式发布；C shell（csh）同样在 2BSD 中首次出现，1BSD 的 “a new shell” 为 ashell（用于构建脚本的辅助 shell）而非 csh；先前 “1BSD 包含 C shell 雏形” 的说法不确

**文献**：Joy, W. (1977) “1BSD READ_ME”（TUHS 归档，1977-11-23）；Joy, W. (1978) “1BSD Release Notes”；伯克利 CSRG 档案［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］
