# 28.3 PDP-11 上的最后 BSD 版本——技术约束的极限

## 28.3.1 PDP-11 硬件的极限约束

**要点**：PDP-11 的 16 位地址空间（64KB）与有限内存（最大 4MB）成为 BSD 发展的硬件瓶颈，迫使 2BSD 在内核大小与功能取舍上做出严格妥协

**史料**：DEC PDP-11 硬件手册、2BSD 内核配置文档、伯克利 CSRG 性能测试报告 ［A］

**史观**：第 7 条硬件与软件辩证——PDP-11 的硬件极限直接塑造了 2BSD 的内核架构与功能边界

**辨析**：PDP-11/70 与 /45 的内存上限在不同 DEC 文档中表述不一，需核对硬件规格表；[2026-08-14 两库核查：PDP-11 16 位地址空间/64KB 寻址、最大 4MB 内存等硬件规格两库无条目，邮件库 freebsd 1994-/usenet 1981- 早于覆盖范围，两库无法验证，保留存疑]

**文献**：DEC (1976) “PDP-11/70 Processor Handbook”；伯克利 CSRG 技术报告 ［B］

## 28.3.2 2BSD 在 PDP-11 上的优化

**要点**：2BSD 针对 PDP-11 的内存限制进行内核覆盖（overlay）、代码紧凑化、可交换代码段等优化，使 BSD 能在有限的 PDP-11 资源下运行

**史料**：2BSD 内核源代码、覆盖技术文档、伯克利性能优化报告 ［A］

**史观**：第 7 条硬件与软件辩证——硬件限制催生的优化技术成为 BSD 工程传统的组成部分
