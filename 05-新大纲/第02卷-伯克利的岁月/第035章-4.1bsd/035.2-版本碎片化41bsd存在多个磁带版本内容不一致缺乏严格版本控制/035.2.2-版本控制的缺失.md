# 035.2.2 版本控制的缺失

**要点**：4.1BSD 时期 CSRG 尚未引入正式版本控制系统（如 CVS、RCS），依赖手工管理与磁带标签，导致版本追踪困难

**史料**：CSRG 版本管理备忘录、RCS/CVS 引入记录、BSD 源代码历史 ［A］

**史观**：第 17 条软件工程——版本控制的缺失是早期软件工程的普遍问题，CSRG 后期引入 CVS 改进

**辨析**：CSRG 引入 CVS 的具体时间在不同史料中不一致，需核对 CSRG 工具采用记录

**文献**：Rochkind, M. (19USA “The Source Code Control System”；CSRG CVS 采用档案 ［A］
