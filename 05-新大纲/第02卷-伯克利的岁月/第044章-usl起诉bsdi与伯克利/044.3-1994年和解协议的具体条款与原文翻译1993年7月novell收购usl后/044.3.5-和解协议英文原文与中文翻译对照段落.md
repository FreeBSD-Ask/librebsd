# 044.3.5 和解协议英文原文与中文翻译对照段落

**要点**：经 2026-07-28 三次联网核查 McKusick 1999《Twenty Years of Berkeley Unix》当事人一手叙述原文（oreilly.com/openbook/opensources/book/kirkmck.html）确认，和解协议核心条款的英文原文如下（含中文翻译对照）：

  | 英文原文（McKusick 1999） | 中文翻译 |
| ----------------------- | ------ |
| "With some further prodding by Ray Noorda on the USL side, many of the sticking points were removed and a settlement was finally reached in January 1994." | 在 Ray Noorda 对 USL 方面的进一步推动下，许多僵持点被移除，和解最终于 **1994 年 1 月** 达成。 |
| "The result was that three files were removed from the 18,000 that made up Networking Release 2, and a number of minor changes were made to other files." | 结果是从构成 Networking Release 2 的 18,000 个文件中删除了 3 个文件，并对其他文件进行了若干小修改。 |
| "In addition, the University agreed to add USL copyrights to about 70 files, although those files continued to be freely redistributed." | 此外，大学同意在约 70 个文件中添加 USL 版权声明，尽管这些文件仍可自由再分发。 |
| "The newly blessed release was called 4.4BSD-Lite and was released in June 1994 under terms identical to those used for the Networking releases." | 新获认可发布的版本被称为 4.4BSD-Lite，于 **1994 年 6 月** 在与 Networking releases 相同的条款下发布。 |
| "Specifically, the terms allow free redistribution in source and binary form subject only to the constraint that the University copyrights remain intact and that the University receive credit when others use the code." | 具体而言，条款允许以源代码与二进制形式自由再分发，唯一约束是大学版权声明须保持完整，且他人使用代码时须给予大学致谢。 |
| "Simultaneously, the complete system was released as 4.4BSD-Encumbered, which still required recipients to have a USL source license." | 同时，完整系统以 4.4BSD-Encumbered 形式发布，仍要求接收方持有 USL 源代码许可证。 |
| "The lawsuit settlement also stipulated that USL would not sue any organization using 4.4BSD-Lite as the base for their system." | 诉讼和解还规定，USL 不会起诉任何使用 4.4BSD-Lite 作为其系统基础的组织。 |
| "So, all the BSD groups that were doing releases at that time, BSDI, NetBSD, and FreeBSD, had to restart their code base with the 4.4BSD-Lite sources into which they then merged their enhancements and improvements." | 因此，当时所有发布 BSD 系统的小组——BSDI、NetBSD 与 FreeBSD——须以 4.4BSD-Lite 源代码重新启动其代码库，然后将各自的增强与改进合并进去。 |
| "While this reintegration caused a short-term delay in the development of the various BSD systems, it was a blessing in disguise since it forced all the divergent groups to resynchronize with the three years of development that had occurred at the CSRG since the release of Networking Release 2." | 虽然此重新整合导致各 BSD 系统的短期开发延迟，但这是因祸得福，因为它迫使所有分歧的小组与 CSRG 自 Networking Release 2 发布以来三年间发生的开发重新同步。 |

**史料**：McKusick 1999《Twenty Years of Berkeley Unix》当事人一手原文（oreilly.com/openbook/opensources/book/kirkmck.html，**2026-07-28** 访问）；Novell-UC Berkeley 和解协议（**1994.1**，部分保密）；4.4BSD-Lite Release Notes（**1994.6**）；FreeBSD 2.0 Release Notes（freebsd.org/releases/2.0/notes/，**1994-1995**） ［A］

**史观**：第 9 条经验优先——McKusick 作为 CSRG 核心成员直接参与和解谈判，其 1999 年当事人一手叙述是和解协议核心条款最权威的公开来源；和解协议原文受保密条款限制未完全公开，McKusick 回忆录公开的条款是研究者能获取的最完整一手叙述；第 2 条形式主义——和解协议的形式逻辑（3 删 70 改）吞并了诉讼的实质争议，极小范围的形式妥协结束了长达两年的法律冲突
