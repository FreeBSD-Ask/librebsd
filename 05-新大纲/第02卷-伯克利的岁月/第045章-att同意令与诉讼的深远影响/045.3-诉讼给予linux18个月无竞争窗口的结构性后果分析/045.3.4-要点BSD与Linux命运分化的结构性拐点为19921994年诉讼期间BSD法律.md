# 045.3.4 要点BSD与Linux命运分化的结构性拐点为19921994年诉讼期间BSD法律

**要点**：BSD 与 Linux 命运分化的结构性拐点为 1992-1994 年诉讼期间，BSD 法律不确定性使 Linux 抢占市场份额，1994 年和解后 BSD 路线恢复但市场份额难以夺回，1995-2000 年 Linux 在服务器市场超越 BSD，BSD 与 Linux 命运分化长期固化

**史料**：1992-2000 年 BSD 与 Linux 市场份额对比、Linux 1.0-2.4 Release Notes（1994-2001）、FreeBSD/NetBSD/OpenBSD Release Notes（1994-2001）［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档 + L5 研究报告〕

**史观**：第 5 条偶然性——1992-1994 年诉讼是命运分化的偶然拐点，但此拐点决定 BSD 与 Linux 长期格局

**辨析**：命运分化的 “结构性” 需核对，避免将短期市场份额等同于长期命运，BSD 在嵌入式与服务器市场仍保持影响力

**观点**：1992 年 12 月 20 日 Linus Torvalds 在 unix.bsd 回应“为何同时存在两个自由 UNIX 工程”时答称纯属巧合：他通过 DDJ 文章知道 386bsd，但它显然尚未就绪，只好自己动手；如果 386bsd 早一年就绪，他很可能根本不会启动 Linux 而直接使用 BSD——尽管他对最终结果非常满意；他还说明 Linux 并非 System V，只因 POSIX 接口偏向而显得更像 sysv。
**邮件来源**：Linus Torvalds，unix.bsd，1992-12-20，Message-ID: `1992Dec20.115036.7197@klaava.Helsinki.FI`
**史学意义**：诉讼窗口期 Linux 的结构性地位由其作者亲口定位——Linux 是 386BSD 技术就绪缺口中的替代品而非独立竞争路线的宣言；“若 386bsd 早一年就绪便不会有 Linux”的当事人反事实陈述，是评估 18 个月窗口效应最直接的一手证词。

**观点**：1992 年 8 月 17 日罗格斯大学的 Charles Hedrick 在 unix.bsd 评析 Linux 的许可结构：Linus 个人倾向 GPL 但内核代码标注 1991 年版权且其他条款可以协商，他并不反对商业发行；从未有过“全部 Linux 代码必须受 GPL 约束”的要求；函数库的若干部分取自 BSD、继续受 BSD 版权约束；内核之外无中央权威、无官方发行版，最接近 386BSD 完整发行物的东西由曼彻斯特计算联盟打包且并无官方地位。
**邮件来源**：Charles Hedrick，unix.bsd，1992-08-17，Message-ID: `Aug.16.20.35.57.1992.15736@athos.rutgers.edu`
**史学意义**：USL 诉讼高潮期，社区观察者已指出 Linux 对 BSD 库代码的实际依赖与松散版权结构——所谓“Linux 法律明确、BSD 受诉不确定”的简单对照，在 1992 年的现场认知中并不成立，18 个月窗口的法律不对称被当事人复杂化。
