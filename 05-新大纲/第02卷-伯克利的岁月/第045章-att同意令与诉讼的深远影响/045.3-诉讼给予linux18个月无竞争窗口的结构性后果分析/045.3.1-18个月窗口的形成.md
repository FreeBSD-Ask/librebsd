# 045.3.1 18 个月窗口的形成

**要点**：**1992.4-1994.1** 诉讼期间 BSD 路线法律不确定性高，386BSD 与 NetBSD 0.8 发展受阻、商业厂商谨慎采用 BSD、Linux 0.01-0.99（**1991.9-1994.3**）快速发展，18 个月窗口使 Linux 抢占 BSD 部分市场份额；统计结论 [C-41] references 表总数 16,867 条，[C-42] 年份提取率 44.42%（7,493/16,867），诉讼期间 1992-1994 年参考文献累计 1,564 条（20.87%），CSRG 时期（1969-1995）累计 1,879 条占比 25.08%——诉讼期间文献产出占 CSRG 时期约 83.23%（1,564/1,879），反映法律不确定性虽阻碍 BSD 代码发展但未中断学术研究文献产出

| 维度 | BSD 路线（1992.4-1994.1） | Linux 路线（1992.4-1994.1） |
| -- | ----------------------- | ------------------------- |
| 法律状态 | 受 USL 诉讼影响，法律不确定性高 | 无诉讼影响，法律明确（GPL） |
| 关键版本 | 386BSD 0.1（**1992.2**）、NetBSD 0.8（**1993.4**） | Linux 0.12（**1992.1**）、0.99（**1992.12**）、1.0（**1994.3**） |
| 商业采用 | 商业厂商谨慎采用 BSD | 商业厂商（如早期发行版）开始关注 Linux |
| 核心贡献者 | Bill Jolitz 维护中断、CSRG 转向 4.4BSD 开发 | Linus Torvalds、Alan Cox、Theodore Ts'o 等 |
| 市场份额 | 发展受阻，部分份额被 Linux 抢占 | 抢占 PC UNIX 市场份额约 30% |

**史观**：第 5 条偶然性——18 个月窗口是诉讼偶然事件造成的，但此偶然窗口决定 BSD 与 Linux 路线长期竞争格局；统计结论 [C-41] 印证——诉讼期间 1992-1994 年 references 表累计 1,564 条（20.87%），占 CSRG 时期（1,879 条）约 83.23%——法律不确定性未中断学术文献产出，与第 5 条 “偶然性” 形成量化印证（诉讼偶然事件影响代码发展但未阻断学术研究），但须遵循 0 信任原则——统计显著 ≠ 实际显著，文献累积量可能受同期操作系统研究整体扩张影响，不得单凭此数据推断诉讼对学术产出的净效应

**辨析**：18 个月窗口的 “具体时长” 需核对，部分史料称 18 个月，部分称 20 个月，需核对诉讼起止时间与 BSD/Linux 发展记录；统计局限性标注——references 表年份提取率仅 44.42%（7,493/16,867），超半数文献缺年份字段，1992-1994 年累计条数（1,564）受提取率限制存在低估偏差，CSRG 时期占比 25.08% 为提取年份后的子集统计，不得外推为全表结论
