# 037.2.3 Apple Lisa 的对比

**要点**：Apple Lisa 于 1983 年 1 月 19 日由 Apple 正式推出（per Computer History Museum"This Day in History: January 19, 1983 Apple Computer Introduces the Lisa“原文”Apple began developing the Lisa computer in 1978. It was to feature a graphical user interface (GUI) and use the Motorola 68000 CPU. It was also the first Apple product with an internal hard drive“；arstechnica 2023 报道”On its 40th anniversary"确认日期 1983-01-19），是全球首款集成 GUI 与鼠标的个人电脑；售价 \$9,995（per arstechnica 2023 报道原文"The Lisa's price was \$9,995, which would be nearly \$30,000 today"），硬件配置为 Motorola 68000 CPU、16 位寻址、内部硬盘；GUI 设计借鉴 Xerox PARC 的 Smalltalk 与 Alto（Steve Jobs 1979.12 访问 PARC），由 Bill Atkinson（QuickDraw 图形库）、Larry Tesler（来自 PARC，Lisa 用户界面）等人开发；因价格过高（约为 IBM PC \$1,565 的 6.4 倍）与第三方软件支持不足销量不佳，1985 年改名 Macintosh XL 降价销售，1986 年停产

**史观**：第 6 条技术路线分化——Lisa GUI 路线与 BSD CLI 路线是人机界面的分化

**辨析**：Lisa 与 Macintosh 的关系（Lisa 是否为 Macintosh 前身）在不同史料中表述不一——CHM 2023 原文“Apple's Macintosh line of computers today... owes its existence to its immediate predecessor at Apple, the Lisa. Without the Lisa, there would have been no Macintosh—at least in the form we have it today—and perhaps there would have been no Microsoft Windows either”确认 Lisa 为 Macintosh 直接前身；arstechnica 原文"It was the first personal computer with a graphical user interface (GUI)"与 m.baike.com“Lisa 是全球首款同时采用图形用户界面 (GUI) 和鼠标的个人电脑”表述一致，但需注意 Xerox Alto（1973 年研发、1981 年作为 Xerox 8010 Star 商品化 \$16,595 上市）才是更早的 GUI 商用工作站；Lisa 是“个人电脑”范畴的 GUI 首例，不应混淆为“GUI 史首例”
