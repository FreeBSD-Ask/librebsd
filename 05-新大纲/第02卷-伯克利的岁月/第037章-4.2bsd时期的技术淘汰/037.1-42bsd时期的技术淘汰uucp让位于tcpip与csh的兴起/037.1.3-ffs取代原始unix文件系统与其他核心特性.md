# 037.1.3 FFS 取代原始 UNIX 文件系统与其他核心特性

**要点**：4.2BSD（1983 年 8 月）引入 Fast File System（FFS，又称 Berkeley Fast File System，后称 UFS1），由 Marshall Kirk McKusick（马歇尔·柯克·麦库西克） 主导实现（论文作者为 McKusick/Joy/Leffler/Fabry 四人），取代 V7/3BSD 的原始 UNIX 文件系统（old file system）；原始 UNIX 文件系统采用 512 字节块、无柱面组、单间接块设计，磁盘寻道效率极差；FFS 引入柱面组（cylinder group）、4KB/8KB 大块、旋转优化、可配置碎片（fragment），McKusick 等 1984 ACM TOCS 论文原文记载吞吐量较原文件系统提升约 8-10 倍（不同基准测试下有差异）；FFS 原型于 1982 年 6 月集成入 4.1b，4.2BSD 正式发布，论文 1984 年 8 月发表于 ACM TOCS；其他 4.2BSD 核心特性还包括：磁盘配额（disc quotas，来自 Robert Elz/墨尔本大学，由 Leffler 集成）、可靠信号机制（new signal facilities，Leffler 实现）、重写独立 I/O 系统简化安装；符号链接（symbolic links）经 FreeBSD 官方手册页 symlink(2) 的 HISTORY 段确认首次出现于 4.2BSD（1983.8）［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］；sendmail（Eric Allman（埃里克·奥尔曼） 编写）随 4.2BSD 正式发布，取代 4BSD 中的 delivermail；BIND（Berkeley Internet Name Domain）早期版本（4.8.3 及之前）由 CSRG 维护随 4.2BSD 分发，由 Douglas Terry、Mark Painter、David Riggle、Songnian Zhou 四位研究生在 DARPA 资助下开发，Kevin Dunlap（DEC 借调）1985-1987 年重大重写，Paul Vixie 1985 年后才成为主要维护者（非 4.2BSD 时期）；NFS（Network File System）由 Sun 开发，BSD 版本在 4.3BSD-Reno（1990 年初）才由 Rick Macklem（圭尔夫大学）集成入 BSD，非 4.2BSD 特性；FFS 是 BSD 标准文件系统直至 4.2BSD→4.3BSD→4.4BSD 全过程，FreeBSD 中延续为 UFS1，直至 FreeBSD 5.0（2003 年 1 月）引入 UFS2（McKusick 与 Poul-Henning Kamp（波尔-亨宁·坎普） 共同设计）后逐步被取代（UFS1 仍保留兼容支持）；FFS 的设计思想直接影响后续 Linux ext2/ext3/ext4 等文件系统

**史料**：McKusick et al. 1984 ACM TOCS“A Fast File System for UNIX”论文（DOI: 10.1145/989.990，记载 8-10 倍性能提升）；McKusick 1999（记载 FFS 4.1b 1982.6 原型、Elz 磁盘配额、Leffler 实现信号设施、sendmail 取代 delivermail）；ISC 官方 BIND History（记载 BIND 最初四位研究生作者、4.8.3 及之前 CSRG 维护、Dunlap 1985-1987 重写、Vixie 后续维护）；Costales & Allman (1993) 《sendmail》（ISBN 1-56592-056-5）；4.2BSD FFS/网络源代码；Thompson 1978“UNIX Implementation”Bell Labs Tech. Journal ［A］

**史观**：实践先于理论：FFS 的设计源于实际磁盘性能优化需求而非文件系统理论；软件工程：FFS 的柱面组设计是软件工程针对硬件特性的典型优化

**辨析**：FFS 论文作者为四人合著（McKusick/Joy/Leffler/Fabry），非 McKusick 单人设计；FFS 原型集成于 4.1b（1982.6），正式随 4.2BSD（1983.8）发布，论文 1984 年 8 月发表于 ACM TOCS 期刊；FFS 与原始 UNIX 文件系统的关系并非完全取代，而是保留 inode 模型与目录结构，仅替换块分配策略；性能提升“约 8-10 倍”数据出自 McKusick 等 1984 论文原始基准测试，不同硬件配置下结果有差异；NFS 非 4.2BSD 特性，而是 4.3BSD-Reno（1990 初）引入；Paul Vixie 在 4.2BSD 时期（1983）尚未参与 BIND 维护，BIND 4.2BSD 版本由 CSRG 维护；LFS（Log-structured File System，Rosenblum & Ousterhout 1992）在 4.4BSD 中作为实验特性引入，未能取代 FFS；符号链接精确引入版本经 FreeBSD 官方手册页 symlink(2) 确认为 4.2BSD（详见上文考据脚注）——freebsd.duckdb 最早 commit 为 1993-06-12 by Rodney W. Grimes（罗德尼·W·格赖姆斯）（hash 9002c02abc587664acb357c6879d8ca08664dd0b），早于 4.2BSD 约 10 年，无符号链接首次引入的代码级证据，故以 FreeBSD 官方手册页 symlink(2) HISTORY 段为权威依据
