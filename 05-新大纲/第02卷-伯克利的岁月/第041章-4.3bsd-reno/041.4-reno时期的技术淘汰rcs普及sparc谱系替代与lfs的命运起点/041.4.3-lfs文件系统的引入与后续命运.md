# 041.4.3 LFS 文件系统的引入与后续命运

**要点**：**重大史实澄清**：LFS（Log-structured File System）**不在 4.3BSD-Reno 中**——Keith Bostic 1990.7.6 Reno 原始公告未提及 LFS；LFS 由 Margo Seltzer、Mendel Rosenblum（孟德尔·罗森布拉姆）、Carl Staelin 贡献（CSRG 贡献者名单明确列为 4.4BSD 贡献者），其设计基于 Rosenblum 与 Ousterhout（Sprite LFS）**1991 年** SIGOPS European Workshop 论文、**1992 年** ACM TOCS 正式发表的"The Design and Implementation of a Log-Structured File System"；**LFS 首次在 4.4BSD 中作为可选文件系统引入**（**1993 年** 4.4BSD-Encumbered、**1994 年** 4.4BSD-Lite），非 Reno 预览；LFS 把所有写操作以日志形式追加至磁盘，理论上提供顺序写性能优势，但面临清理（cleaning）开销、碎片化等工程挑战；4.4BSD-Lite（**1994 年**）后 LFS 逐步边缘化；FreeBSD 早期版本保留 LFS 支持但维护停滞，至 FreeBSD 5.x（**2003-2006 年**）已基本不可用；NetBSD 在 1990 年代维护 LFS 直至 NetBSD 7.0（**2015 年 10 月**）仍保留，但在 NetBSD 9.0（**2020 年 5 月**）后逐步弃用；BSD LFS 与 Sprite LFS（Ousterhout 组，**1989-1992 年**）设计有亲缘关系但实现独立，由 Margo Seltzer（Ousterhout 的博士生）主导 BSD LFS 实现

| 项目/版本 | LFS 支持状态 | 时间 | 说明 |
| ------- | ---------- | -- | -- |
| 4.3BSD-Reno | ❌ 不包含 | 1990.6 | Bostic 公告未提及 LFS |
| 4.4BSD-Encumbered | ✅ 首次引入 | 1993.6 | LFS 作为可选文件系统 |
| 4.4BSD-Lite | ✅ 保留 | 1994.3 | 4.4BSD-Lite 后逐步边缘化 |
| FreeBSD 早期版本 | ✅ 保留但维护停滞 | 1994 起 | — |
| FreeBSD 5.x | ⚠ 基本不可用 | 2003-2006 | 维护停滞导致 LFS 失效 |
| NetBSD 7.0 | ✅ 仍保留 | 2015.10 | 1990 年代起持续维护 |
| NetBSD 9.0 | ⚠ 逐步弃用 | 2020.5 | 后续版本逐步弃用 |
| Sprite LFS（Ousterhout 组） | — | 1989-1992 | BSD LFS 的姊妹项目，设计亲缘但实现独立 |

**史料**：Rosenblum & Ousterhout 1992 ACM TOCS"The Design and Implementation of a Log-Structured File System"论文（Vol. 10 No. 1 pp. 26-52，DOI: 10.1145/146941.128852）、4.4BSD LFS 源代码（非 Reno 源码）、CSRG 贡献者名单（netbsd.org/people/CSRG-contrib.html 明确列出“LFS: Margo Seltzer, Mendel Rosenblum, Carl Staelin”）、Seltzer et al. 1993 USENIX Winter“File System Logging vs. Clustering: A Performance Evaluation”论文对 LFS 性能的批评、McKusick et al. 1996《The Design and Implementation of the 4.4BSD Operating System》第 7 章文件系统部分确认 LFS 为 4.4BSD 特性 ［A］

**史观**：第 4 条分离聚合是永恒规律：LFS（日志结构）与 FFS/UFS（柱面组）形成 BSD 文件系统的两条路线，LFS 路线最终未能取代 FFS；LFS 的“统一日志”抽象在工程清理开销下暴露形式主义局限

**辨析**：LFS 是否真正“失败”需辨析——其在主线 BSD 中未能成为默认文件系统，但在 ZFS（Sun 2005 年）、WAFL（NetApp）等现代文件系统中以 copy-on-write、事务日志等变体形式延续思想；Reno 作为 test release 不包含 LFS 与新 VM 系统，这两个主要新组件均在 4.4BSD 中才集成，原文件称“4.3BSD-Reno 首次以预览形式引入 LFS”系事实错误——混淆了“开发时期归属”与“发布版本包含”；Margo Seltzer 为 Ousterhout 在 Berkeley 的博士生，BSD LFS 与 Sprite LFS 为姊妹项目关系
