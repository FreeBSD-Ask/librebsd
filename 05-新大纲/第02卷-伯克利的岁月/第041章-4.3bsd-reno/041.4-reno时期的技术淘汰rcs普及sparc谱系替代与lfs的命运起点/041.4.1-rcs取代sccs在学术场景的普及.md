# 041.4.1 RCS 取代 SCCS 在学术场景的普及

**要点**：RCS（Revision Control System）由 Walter F. Tichy 于 **1980 年** 在普渡大学（Purdue University）开始开发，**1982 年** 以 Purdue 技术报告形式公开发布首版（CSD-TR-357），**1985 年** 在 IEEE TSE 发表正式论文描述其设计；RCS 最初即为 UNIX 平台开发（非从其他系统移植），采用反向 delta 存储模型，取代 SCCS 在学术与小型项目场景的主导地位；但其单文件、无网络的局限使其在大型项目中被 **1986 年** Dick Grune 原型、**1989 年** Brian Berliner 重写的 CVS（Concurrent Versions System）逐步取代；4.3BSD-Reno（**1990 年 6 月**）发行时 CSRG 已使用 RCS 管理 BSD 源代码树（与 SCCS 并存），Git 对象存储采用自研 packfile delta 机制而非 RCS 文件格式，仅在 delta 存储思想层面与 RCS 同源；RCS 在 BSD base system 中保留 **rcs(1)**、**ci(1)**、**co(1)** 等命令直至 **2010 年代**，被 SVN 与 Git 完全取代后逐步边缘化 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］

| 版本控制系统 | 起源年份 | 作者/机构 | 关键特性 | 主要适用场景 |
| ---------- | ------ | ------- | ------ | ---------- |
| SCCS | 1972 | Marc Rochkind（Bell Labs） |  interleaved deltas，单文件 | 早期商业 UNIX |
| RCS | 1980/1982 | Walter F. Tichy（Purdue 大学） | 反向 delta，单文件 | 学术与小型项目 |
| CVS | 1986/1989 | Dick Grune 原型；Brian Berliner 重写 | 多文件、网络化、并发开发 | 大型协作项目 |
| SVN | 2000 | CollabNet | 集中式、CVS 改进版 | 企业集中式版本控制 |
| Git | 2005 | Linus Torvalds（Linux 社区） | 分布式、内容寻址、自研 packfile delta 机制（delta 存储思想与 RCS 同源） | 分布式协作开源与商业项目 |

**史料**：Tichy 1982 Purdue 大学技术报告"Design, Implementation, and Evaluation of a Revision Control System"、Tichy 1985 IEEE TSE“RCS—A System for Version Control”论文、Berliner 1989“CVS-II: Parallel Development Software”USENIX 春季会议论文、4.3BSD-Reno 源代码树中的 RCS 历史文件 ［A］

**史观**：RCS 的反向 delta 存储是软件工程对存储效率的典型优化；第 4 条分离聚合是永恒规律：RCS 从 SCCS 分离（单文件模型），与 CVS 聚合（多文件协同）

**辨析**：Tichy 1982 技术报告与 1985 IEEE TSE 论文在 RCS 设计描述上有差异，需对照原文核实；RCS 与 SCCS 的市场份额争议需区分学术与商业场景；4.3BSD-Reno 是否真正“采用 RCS”需考据——CSRG 在不同时期使用 SCCS/RCS/CVS 并存；原称“1985 年随 GNU 计划移植至 UNIX”系事实错误——RCS 由 Tichy 在 Purdue 独立开发、初始即为 UNIX 平台，GNU 项目后来维护 GNU RCS 分支但非起源；CSRG 何时开始使用 RCS 管理 BSD 源码树的精确时间——经 freebsd.duckdb 查询未得明确证据（查询条件：`SELECT * FROM commits WHERE message_subject LIKE '%RCS%' OR message_subject LIKE '%SCCS%' OR message_subject LIKE '%CVS%' OR message_subject LIKE '%revision control%'`，freebsd-src 仓库最早 commit 为 1993-06-12T14:49:13Z by Rodney W. Grimes（罗德尼·W·格赖姆斯），hash 9002c02abc587664acb357c6879d8ca08664dd0b，早于 4.3BSD-Reno 1990 年 6 月发布约 3 年，commit 历史中无 CSRG 采用 RCS 具体时间的代码级证据），暂保留存疑
