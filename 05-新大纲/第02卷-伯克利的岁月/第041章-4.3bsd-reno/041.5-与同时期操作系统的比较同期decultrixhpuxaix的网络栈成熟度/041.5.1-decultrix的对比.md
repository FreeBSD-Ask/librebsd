# 041.5.1 DEC Ultrix 的对比

**要点**：DEC Ultrix（1984-1995）基于 4.2BSD 与 4.3BSD，运行于 VAX 与 DECstation（MIPS）平台，网络栈直接源自 BSD，成熟度与 4.3BSD 相当，但 DEC 后期转向 OSF/1（1990），Ultrix 维护减弱，1995 年停止开发

**史料**：DEC Ultrix Release Notes（1984-1995）、DEC OSF/1 迁移指南、DEC 年报（1984-1995） ［B］

**史观**：第 11 条分离与聚合——Ultrix 与 BSD 主干既分离（厂商 fork）又聚合（直接基于 BSD 源代码），分离与聚合的辩证统一

**辨析**：Ultrix 与 BSD 源代码的具体关系需核对，部分史料称 Ultrix“直接基于 BSD”，部分称“基于 BSD 与 System V 混合”，需核对 DEC 内部开发记录

**文献**：DEC Ultrix Release Notes（1984-1995）；DEC 年报；Salus, P. (1994) “A Quarter Century of UNIX” ［B］
