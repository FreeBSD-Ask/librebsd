# 042.0.6 文章称cat的首版C实现迟至第七版UNIX才出现与4BSD标志集38年未变等细节

- 文章称 cat 的首版 C 实现“迟至第七版 UNIX 才出现”与“4BSD 标志集 38 年未变”等细节系二手转述，须与 TUHS 归档的早期 cat 源码逐版核对。 [存疑脚注] 各版本 cat 的实现时间线未经一手源码逐版核验。（BSD Now EP273，[1651.48-1800.70]，L4）
- de Raadt 对 X 安全团队协调不力的批评属当事人立场，其“提前一小时才通知”的表述须与 X 安全团队与 OpenBSD 的往来记录交叉核实。 [存疑脚注] 披露时间线仅来自 OpenBSD 一方叙述。（BSD Now EP273，[2430.02-2489.74]，L4）
- 转写中 Thompson 与 Ritchie 起家所用机器记作 PDP-8（新转写逐字证实演讲原话即为 PDP-8），与通行记载的 PDP-7 不符，疑为口误或转写之误；片首宣传片另称伯克利“最终发行版”年份为 1992 年，而通行纪年为 4.4BSD 于 1993 年发布、4.4BSD-Lite 于 1994 年发布，McKusick 所述或指代码清理完成之时点；两处纪年均属单一来源口述，引用前须另行核验。[订正：原存疑脚注“本流转写为多音轨交错合并”之转写缺陷经滚动重叠重建后已不存在，新转写为单轨顺排] [已核备注] 新转写已为单轨顺排；PDP-8 机型与 1992 年末版年份两处纪年仍系单一来源口述且与通行记载存在出入，未经与 McKusick 出版著作及 CSRG 发行记录交叉核对前不宜直接引用。（YouTube EPnwbqBdghh6E，[1931.0-1959.3]，L4）[订正：原“同段称伯克利最终发行版年份为 1992 年”不成立——PDP-8 原话位于第一讲正文，1992 年最终发行版陈述位于片首宣传片段 [94.9-103.0]，两处相隔逾 1800 秒，已改作“片首宣传片另称”；重锚 [1933.44-1946.549]→[1931.0-1959.3]，PDP-8 原话新转写逐字核符（“an old uh PDP eight”）]
- 和解条款的当事人口述版本与公开文本可互勘：条件包括在 70 个文件上补加 USL 版权声明（多为已被认定近乎公有领域的公共头文件）、删除三个文件并禁用 Net/2；McKusick 自述被删的 System V IPC、共享内存与信号量仿真实为有用代码，选择删除它们纯属让对方保留颜面——律师明言只需挑出任何三个文件以成全文义；此叙述提示和解的法律实质弱于其象征姿态，而 4.4BSD-Lite 正是以此法律清白版本的形式发行。（YouTube EPbVSXXeiFLgk，[2684.95-2774.58]，L1）
