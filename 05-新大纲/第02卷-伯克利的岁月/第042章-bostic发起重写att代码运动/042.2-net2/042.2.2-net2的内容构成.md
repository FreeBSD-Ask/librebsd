# 042.2.2 Net/2 的内容构成

**要点**：Net/2 内容包括 4.3BSD Reno 的大部分用户工具、库函数、内核源代码、网络栈、设备驱动框架、文档，McKusick 当事人原文确认约 **18,000 个文件**；代码行数无一手行数统计（McKusick 1999 仅确认文件数 18,000，无精确行数）［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］；Net/2 明确不包含 6 个仍有 AT&T 衍生争议的内核文件（由 Jolitz 后来补全），保留 4.3BSD Reno 的内核架构与功能

| Net/2 内容构成 | 来源 | 法律状态 | 备注 |
| ------------ | -- | ------ | -- |
| 用户工具（约 100+ 个） | 社区志愿者 clean room 重写 | BSD 许可证，完全自由 | 基于 McKusick 1999 当事人原文 |
| C 库函数（`libc` 等） | 社区志愿者重写 | BSD 许可证，完全自由 | — |
| 内核源代码 | CSRG 伯克利原创 + AT&T 衍生清理 | 大部分 BSD 许可证；6 个文件仍有争议 | Jolitz 后补全 6 个文件形成 386BSD |
| 网络栈 | 伯克利原创（Net/1 起即不含 AT&T 代码） | BSD 许可证，完全自由 | — |
| 设备驱动框架 | 伯克利原创 | BSD 许可证，完全自由 | — |
| 文档（手册页） | 社区志愿者重写 | BSD 许可证，完全自由 | — |

**史料**：Net/2 源代码清单、Net/2 与 4.3BSD Reno 源代码对比、CSRG 关于 Net/2 内容选择的备忘录、McKusick (1999) 一手叙述 ［A］

**史观**：总纲第 4 条分离聚合是永恒规律——Net/2 是将 BSD 代码从 AT&T 混合版权聚合体中分离出来，分离是为了聚合到完全自由 BSD 生态

**辨析**：Net/2 的代码行数“200 万行”说法无一手来源确认——McKusick 当事人原文仅确认“18,000 files”，代码行数需核对 Net/2 源代码磁带的精确统计；Net/2 并非“完全不含 AT&T 代码”的完整可运行系统——McKusick 原文明确记载"there were only six remaining kernel files that were still contaminated"，即发布时仍有 6 个内核文件缺失/有争议，Jolitz 在 6 个月内补全了这 6 个文件才形成可运行的 386BSD；经 freebsd.duckdb 查询未得明确证据（查询条件：`SELECT * FROM commits WHERE message_subject LIKE '%Net/2%' AND message_subject LIKE '%line%'`，freebsd-src 仓库中 Net/2 代码导入 commit 如 `9cad5725f1649589cbc90ecb989aadfd28f1b94b`（Garrett Wollman, 1993-11-07T22:54:51Z, “Added the netrmp protocol from the Net/2 tape”）未记载代码行数统计，无法对“200 万行”说法提供代码级证据），暂保留存疑

**文献**：Net/2 源代码（1991.6）；McKusick, M. K. (1999) “Twenty Years of Berkeley Unix”；Bostic, K. (1991) “Net/2 Release Notes” ［A］
