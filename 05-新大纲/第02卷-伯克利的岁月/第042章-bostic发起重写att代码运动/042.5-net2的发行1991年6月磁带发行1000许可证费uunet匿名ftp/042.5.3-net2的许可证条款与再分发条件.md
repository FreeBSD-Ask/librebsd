# 042.5.3 Net/2 的许可证条款与再分发条件

**要点**：Net/2 沿用 Net/1 的 BSD 许可证文本（McKusick 1999 原文“we decided to call the new release Networking Release 2 since we could just do a revision of the approved Networking Release 1 license agreement”），许可证条款包括：① 版权声明须在源文件中保持完整（“the copyright notices in the source file be left intact”）；② 使用 Net/2 代码的产品须在文档中说明包含加州大学及其贡献者的代码（“products that incorporated the code indicate in their documentation that the product contained code from the University of California and its contributors”）；③ 允许修改/不修改、源代码/二进制形式再发布（“A licensee could release the code modified or unmodified in source or binary form”）；④ 无版税、无会计要求（“with no accounting or royalties to Berkeley”）；⑤ 允许任何人从已获取副本者处免费复制（“anyone was free to get a copy from anyone who already had received it”）；此许可证条款成为后续 4.4BSD-Lite、FreeBSD、NetBSD、OpenBSD 等自由 BSD 项目许可证的基础，亦是 BSD 许可证与 GPL 的关键分野——BSD 许可证允许商业封闭再发布，GPL 则要求衍生作品必须开源

**史料**：Net/2 BSD 许可证原文（TUHS Net2 目录归档，tuhs.org/Archive/Distributions/UCB/Net2/）；McKusick 1999 一手原文；Net/1 BSD 许可证原文（TUHS net1.tar.gz 归档，tuhs.org/Archive/Distributions/UCB/net1.tar.gz） ［A］

**史观**：第 2 条历史是形式主义化的非存在——Net/2 许可证的形式逻辑（允许商业封闭再发布）吞并了自由软件的实质自由，与 GPL 的形式逻辑（强制开源）形成两种形式主义对立；第 9 条经验优先——Net/2 沿用 Net/1 许可证文本而非另起法律文本，是工程实践的路径依赖而非理论先行

**辨析**：Net/2 许可证与 Net/1 许可证的关系——McKusick 1999 原文明确“we could just do a revision of the approved Networking Release 1 license agreement”，即 Net/2 许可证是 Net/1 许可证的修订版而非全新法律文本，须区分“许可证文本修订”与“许可证条款实质变化”，实际条款实质与 Net/1 一致；Net/2 许可证与 4.4BSD-Lite 许可证的关系——4.4BSD-Lite 沿用 Net/2（即 Net/1 修订版）许可证条款，McKusick 1999 原文确认“4.4BSD-Lite ... was released in June 1994 under terms identical to those used for the Networking releases”，须区分“Net/2 许可证”与“4.4BSD-Lite 许可证”在条款上的一致性与在适用对象上的差异；［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 关于 Net/2 许可证文本的具体修订内容（相对于 Net/1 的差异），经 2026-07-28 三次联网核查 McKusick 1999 一手原文、TUHS Net2 目录归档、TUHS net1.tar.gz 归档三方一手来源，McKusick 1999 仅提及“revision”而未列出具体修订条款，TUHS Net2 目录归档的 net2.tar.gz 与 net1.tar.gz 包含许可证原文但需解压比对，此项工作超出免费公开来源范围，禁止以二手转述或模型记忆臆造修订内容
