# 040.10.2 VAX 单平台 → 多平台支持（VAX、Tahoe/CCI Power 6/32、Sun-3）的迁移（1988）

**要点**：4.1BSD/4.2BSD/4.3BSD（1981-1986）以 VAX-11/780 为唯一主要平台，BSD 内核与 VAX 硬件深度绑定（VAX 汇编、VAX 中断处理、VAX 内存管理单元）；4.3BSD-Tahoe（**1988.6**）首次支持多平台——VAX（DEC VAX-11/780、VAX-11/750、MicroVAX、新增 DEC 8250 BI-based CPU 与 KDB-50 BI 磁盘控制器支持，Chris Torek 贡献）、Tahoe（CCI Power 6/32、6/32SX，CCI Computer Consoles Inc. 公司 supermini 类 VAX 兼容超级小型机，亦被 Harris (HCX-7/HCX-9)、Unisys (7000/40)、ICL (Clan 7) 作为 OEM 转售，CCI 向 CSRG 提供了 Power 6/32 机器用于内核分离工作）、Sun-3（Sun Microsystems Sun-3 工作站，Motorola 68020）；注意：一手公告（Karels/McKusick/Bostic 1988 年 6 月）明确 Tahoe 工作主要目的为"The primary purpose of this release is to provide support for the“tahoe”processor"，但 **未明确说明系应 DARPA 要求**——相关章节原文中“Tahoe 平台支持是应 DARPA 要求支持 CCI Power 6 平台”系推断而非一手公告原文，伯克利 CSRG 1980-1988 年间受 DARPA 资助（DARPA funding 1988 终止），DARPA 对 BSD 路线有影响力但无具体合同条款证据显示“DARPA 要求支持 CCI Power 6/32”；4.3BSD-Tahoe 系 interim release 而非标准 Berkeley 发布（"This distribution is not a standard Berkeley release; it is an interim release intended for testing and evaluation rather than production use"），其正式地位与“标准 BSD 发布”有差异；多平台支持使 BSD 从“VAX 专属”转向“跨平台通用”，为后续 386BSD（1992）、NetBSD（1993，多平台支持）、FreeBSD（1993，386 平台）、OpenBSD（1995，多平台支持）奠定工程基础；VAX 单平台主导地位在 4.3BSD-Tahoe 中被“淘汰”为多平台并行支持，但 VAX 平台本身在 BSD 中持续到 4.4BSD-Lite（1995），1990 年代后 BSD 主平台转向 386、SPARC、Alpha、PowerPC

| 平台 | 厂商 | 4.3BSD-Tahoe 支持机型 | 关键贡献者 |
| -- | -- | ------------------- | -------- |
| VAX | DEC | VAX-11/780、VAX-11/750、MicroVAX、DEC 8250 BI-based CPU（+ KDB-50 BI 磁盘控制器） | Chris Torek |
| Tahoe | CCI | Power 6/32、6/32SX（+ OEM: Harris HCX-7/HCX-9、Unisys 7000/40、ICL Clan 7） | CSRG（CCI 提供机器） |
| Sun-3 | Sun Microsystems | Sun-3 工作站（Motorola 68020） | Sun 工程师 |

**史料**：4.3BSD-Tahoe Release Notes (1988.6)；CCI Power 6/32 硬件手册；Sun-3 硬件手册；4.3BSD-Tahoe `sys/tahoe/` 源代码；Karels, M., McKusick, K., Bostic, K. (1988-06) 4.3BSD-Tahoe 公告（tuhs.org/Usenet/comp.sys.tahoe/1988-June/000067.html 一手公告）；McKusick, K. (1999) “Twenty Years of Berkeley Unix” ［A］

**史观**：硬件与软件辩证——VAX 单平台深度绑定限制了 BSD 演化空间，多平台支持是软件工程对硬件多样性的回应；第 4 条分离与聚合——多平台支持使 BSD 从“VAX 硬件聚合”分离为“跨平台通用内核 + 各平台机器相关层”，分离与聚合辩证统一

**辨析**：VAX 单平台被“淘汰”为多平台支持而非被完全弃用，VAX 平台在 BSD 中持续到 4.4BSD-Lite（1995），须区分“主平台地位退场”（4.3BSD-Tahoe 后多平台并行）与“完全弃用”（4.4BSD-Lite 后 VAX 平台逐步停止）；CCI Power 6/32（Tahoe）平台支持的具体动机——McKusick 1999 记载 CCI 向 CSRG 提供了几台 Power 6/32 机器使 CSRG 得以完成 Bill Joy 早先开始的机器依赖分离工作，“应 DARPA 要求”系推断而非一手公告；4.3BSD-Tahoe 公告明确为 interim release 而非标准 Berkeley 发布，须区分“interim release”与“标准 release”；386BSD（1992）基于 Net/2 移植到 386 是 BSD 多平台支持的关键延续，但 386BSD 的工程基础可追溯至 4.3BSD-Tahoe 分离架构
