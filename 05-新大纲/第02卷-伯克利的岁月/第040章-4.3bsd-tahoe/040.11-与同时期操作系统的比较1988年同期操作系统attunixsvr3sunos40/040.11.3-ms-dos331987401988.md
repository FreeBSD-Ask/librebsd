# 040.11.3 MS-DOS 3.3（1987）/ 4.0（1988）

**要点**：MS-DOS 3.3（1987）完善了硬盘分区与网络支持，4.0（1988）引入 DOS Shell 图形外壳，仍是单用户、单任务操作系统；它与 4.3BSD-Tahoe 面向完全不同的市场（IBM PC 兼容机 vs VAX/多平台科研机），却在装机量上碾压所有 UNIX 变体，是 1980 年代末最普及的操作系统。

**史料**：Microsoft MS-DOS 3.3/4.0 用户手册（1987-1988）［A］；PC 兼容机市场销量统计（1988）［C］

**史观**：技术路线分化：MS-DOS 以极简单用户设计适配廉价硬件，与 BSD 的多用户研究路线形成极端对照；Tahoe 的多平台化努力（68030）也无法触及 DOS 的微机海量市场。

**辨析**：MS-DOS 与 BSD 无直接竞争——硬件平台（8088/286 vs VAX/68030）与用户群（家庭/办公 vs 科研/服务器）完全错位；DOS 的普及是 IBM PC 标准的结果，而非技术对标。

**文献**：Microsoft. MS-DOS User's Guide [Z]. 1988；Duncan R. The MS-DOS Encyclopedia [M]. Microsoft Press, 1988. ［B］
