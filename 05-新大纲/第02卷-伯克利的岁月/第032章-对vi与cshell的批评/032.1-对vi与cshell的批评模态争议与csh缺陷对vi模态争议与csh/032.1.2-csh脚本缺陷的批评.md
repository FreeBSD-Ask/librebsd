# 032.1.2 csh 脚本缺陷的批评

**要点**：csh 作为脚本语言存在变量作用域混乱、错误处理不足、语法不一致等缺陷，Tom Christiansen（汤姆·克里斯蒂安森） 1996 年发表 “Csh Programming Considered Harmful” 系统化批评

**史料**：Christiansen 的批评文章、csh 脚本 bug 报告、shell 比较论文 ［B］

**史观**：第 2 条实践先于理论——csh 的脚本缺陷源于其设计是为交互式而非脚本式使用，实践需求与设计目标的错位导致缺陷

**辨析**：csh 脚本缺陷的严重程度在不同使用场景下评价不一，需区分交互式与脚本式场景；[2026-08-14 两库核查：邮件库 usenet 1996 年 unix.bsd.misc 帖（Message-ID 4mkaj9$51s@uriah.heep.sax.de>#1/1，J Wunsch）出现 “csh programming considered harmful” 短语，佐证该批评 1996 年已在社区流传；参考文献库全文未命中 Christiansen 原文，其发表细节两库无法直接验证]
