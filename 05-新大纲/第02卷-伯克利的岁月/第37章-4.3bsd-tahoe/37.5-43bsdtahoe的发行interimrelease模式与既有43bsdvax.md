# 37.5 4.3BSD-Tahoe 的发行——interim release 模式与 “既有 4.3BSD VAX 许可证” 门槛（1988.6）

## 37.5.1 4.3BSD-Tahoe 的发行模式与资格门槛

**要点**：4.3BSD-Tahoe 的发行采用与 4.3BSD（1986.06）标准 release 不同的 “interim release” 模式——据 Bostic 1988 年 6 月 16 日 USENET comp.sys.tahoe 一手公告（tuhs.org/Usenet/comp.sys.tahoe/1988-June/000067.html），公告明确表述 "This distribution is not a standard Berkeley release; it is an interim release intended for testing and evaluation rather than production use by naive users"（本发行非标准 Berkeley 发布，而是仅供测试与评估而非供初级用户生产使用的中间版本），公告署名为 Mike Karels、Kirk McKusick、Keith Bostic（基思·博斯蒂克） 三人；**发行资格门槛**——一手公告明确："The distribution is available to users with licenses for the April 1986 4.3BSD release for the VAX"（本发行仅向已持有 1986 年 4 月 4.3BSD VAX 版本许可证的用户开放），即获取 Tahoe 须先持有 4.3BSD VAX 许可证，未持有 4.3BSD VAX 许可证的机构与个人无法直接获取 Tahoe；**发行通知机制**——公告记载 "Attached is a brief summary of the information mailed to all 4.2 and 4.3BSD licensees. This mailing contains all necessary ordering information; if you have not received it by July 5th, please contact our distribution office at +1-415-642-7780"（附文为寄送给所有 4.2 与 4.3BSD 许可证持有者的信息摘要，含完整订购信息；若 7 月 5 日前未收到，请联系分发办公室 +1-415-642-7780），表明 CSRG 通过邮寄方式通知所有 4.2BSD 与 4.3BSD 许可证持有者，并附订购信息；**发行媒介**——一手公告明确："The distribution consists of one 6250 BPI or three 1600 BPI magnetic tapes, certain updated manual pages, and a copy of 'Installing and Operating 4.3BSD on the Tahoe’"（发行包含 1 卷 6250 BPI 或 3 卷 1600 BPI 磁带、若干更新的手册页与一份《Installing and Operating 4.3BSD on the Tahoe》），磁带同时包含 VAX 与 Tahoe 的源代码、文档与 Tahoe 二进制（"The magnetic tape(s) contain copies of source code and documentation for both the VAX and the tahoe, and binaries for the tahoe"），1600 BPI 三卷装中部分用户贡献软件以压缩档案形式发送以节省空间；**4.3BSD-Tahoe 发行数量**——一手公告与 McKusick 1999《Twenty Years of Berkeley Unix》均未提供具体发行数字，按 0 信任原则不得给出具体估算，可参考的间接基准是 McKusick 1999 记载的 4.2BSD（1983.08）18 个月内 1000+ 站点许可证、4.3BSD（1986.06）未给具体数字、Net/1（1989.06）“several hundred organizations purchased copies”、Net/2（1991.06）" several hundred individuals and organizations paid the $1,000 fee "，因 Tahoe 仅限 4.3BSD VAX 已有许可证用户获取且为 interim release，其发行规模应小于 4.2BSD 的 1000+ 站点许可证、与 Net/1 的 “ several hundred ” 相当或更小，但此为推断而非一手史料。［doubt-resolved-221：Tahoe 具体发行数量无一手史料记载，仅可据 Net/1 几百家规模与 “ 仅限 4.3BSD VAX 许可证用户 ” 门槛作间接推断］

**史观**：总纲第 9 条——经验优先：interim release 模式是 CSRG 工程实践的产物，反映 “先放出供测试评估，再吸收反馈完善为标准 release” 的工程迭代逻辑，而非理论先行的发布策略；总纲第 5 条——没有必然性，只有偶然性：Tahoe 作为 interim release 的发行模式与资格门槛（仅限 4.3BSD VAX 许可证用户）塑造了其发行规模上限，但具体发行数量因史料缺失无法确证，须区分 “模式可确证” 与 “数量不可确证”；总纲第 13 条——法律与道德是利益分配：Tahoe 仍受 AT&T UNIX 源代码许可证约束（Net/1 1989.06 发布前 BSD 仍含 AT&T 代码），“仅限 4.3BSD VAX 许可证用户” 的门槛反映了 AT&T 商业许可证对 BSD 发行渠道的法律约束

**辨析**：① **“interim release” 地位的辨析**——一手公告明确 Tahoe 为 “interim release intended for testing and evaluation rather than production use by naive users”，须区分“interim release”与“standard release”：interim release 不供生产使用、仅供测试评估，标准 release（如 4.3BSD 1986.06）可作生产使用，Tahoe 的 interim 性质直接影响其发行规模与用户群体构成；② **发行资格门槛的辨析**——Tahoe 仅向已持有 4.3BSD VAX 许可证的用户开放，未持有 4.3BSD VAX 许可证的机构与个人无法直接获取，此门槛将 Tahoe 发行规模上限锁定在 4.3BSD VAX 许可证用户基数内，但 4.3BSD VAX 许可证用户基数本身无一手史料记载，故 Tahoe 具体发行数量无法确证；③ **发行数量估算的方法论局限**——按 0 信任原则，Tahoe 具体发行数量不得给出具体数字，McKusick 1999 未提供、Bostic 一手公告未提供、CSRG 年度报告未提供，仅可据 Net/1（1989.06）“several hundred” 与 Net/2（1991.06）“several hundred” 作间接规模推断，但因 Tahoe 为 interim release 且仅限 4.3BSD VAX 用户，其规模应小于 4.2BSD（1000+ 站点许可证），此推断不构成一手证据；④ **“通知机制” 的辨析**——CSRG 通过邮寄方式通知所有 4.2BSD 与 4.3BSD 许可证持有者并附订购信息，但 7 月 5 日前未收到通知者可联系 +1-415-642-7780 分发办公室，此机制反映了 1988 年发行渠道仍以邮政邮寄与电话订购为主、互联网分发尚未成为主流发行渠道的工程实践；⑤ **媒介规格的辨析**——1 卷 6250 BPI 或 3 卷 1600 BPI 磁带是 1980 年代后期 BSD 发行的标准媒介规格，与 4.3BSD（1986.06）发行规格相同，须注意 1600 BPI 三卷装中部分用户贡献软件以压缩档案形式发送，此压缩仅因节省 1600 BPI 磁带空间而非技术改进；⑥ **Tahoe 与 4.3BSD 主线发行策略的具体差异**——Tahoe 作为 interim release 与 4.3BSD（1986.06）标准 release 的发行策略差异表现在四个维度：（1）正式地位——4.3BSD 为标准 Berkeley 发布、Tahoe 为 interim release；（2）资格门槛——4.3BSD 仅需 AT&T UNIX 源代码许可证即可获取、Tahoe 须先持有 4.3BSD VAX 许可证；（3）使用场景——4.3BSD 供生产使用、Tahoe 仅供测试与评估；（4）平台支持——4.3BSD 仅支持 VAX、Tahoe 支持 VAX + Tahoe（CCI Power 6/32 及 OEM 机型）+ 新增 DEC 8250 BI-based CPU 与 KDB-50 BI 磁盘控制器

## 37.5.2 4.3BSD-Tahoe 发行策略与 4.3BSD 主线发行的差异

**要点**：4.3BSD-Tahoe 发行策略与 4.3BSD 主线发行在四个维度存在具体差异——（1）**正式地位差异**：4.3BSD（1986.06）为标准 Berkeley 发布，可作生产系统使用；4.3BSD-Tahoe（1988.06）为 interim release（中间版本），明确 “not a standard Berkeley release” 且 "intended for testing and evaluation rather than production use by naive users"（不供初级用户生产使用，仅供测试与评估），interim release 模式成为后续 4.3BSD-Reno（1990 年初）的先例（Reno 同样为 interim release，McKusick 1999 记载 "The release was named after a big gambling city in Nevada as an oblique reminder to its recipients that running the interim release was a bit of a gamble"，以内华达州赌城 Reno 命名暗示中间版本的 “赌博” 性质）；（2）**资格门槛差异**：4.3BSD（1986.06）仅需 AT&T UNIX 源代码许可证即可获取；4.3BSD-Tahoe 须先持有 4.3BSD VAX 版本许可证（"available to users with licenses for the April 1986 4.3BSD release for the VAX"），此门槛将 Tahoe 发行规模锁定在 4.3BSD VAX 已有许可证用户基数内；（3）**平台支持差异**：4.3BSD（1986.06）仅支持 VAX 平台；4.3BSD-Tahoe（1988.06）支持 VAX + Tahoe（CCI Power 6/32、6/32SX 及 OEM 机型 Harris HCX-7/HCX-9、Unisys 7000/40、ICL Clan 7）+ 新增 DEC 8250 BI-based CPU 与 KDB-50 BI 磁盘控制器（Chris Torek 贡献）+ MicroVAX II QVSS 与 QDSS 显示驱动（DEC 贡献），是 BSD 首次支持 VAX 以外平台（多平台支持由此开始）；（4）**使用场景差异**：4.3BSD 供生产使用、供初级用户日常使用；4.3BSD-Tahoe 仅供测试与评估、不供初级用户生产使用，CSRG 期望用户反馈以完善为未来标准 release。**interim release 模式的工程意义**——interim release 模式使 CSRG 得以在不宣布正式新版本的前提下发布新功能供测试，Tahoe 测试的反馈被纳入后续 4.3BSD-Reno（1990 年初）与 4.4BSD（1994.06）的开发；**Tahoe 发行策略对后续 BSD 发行的影响**——Tahoe 的 interim release 模式为 Reno（1990 年初）所继承，但 Net/1（1989.06）与 Net/2（1991.06）作为 freely-redistributable release（自由可再分发版本）采用了完全不同的发行策略（无 AT&T 许可证约束、$400-1000 磁带费、允许自由再分发），标志着 BSD 发行策略从 “ AT&T 许可证约束 + 仅限已有许可证用户 ” 向 “ BSD 许可证 + 自由再分发 ” 的转向

| 维度 | 4.3BSD（1986.06） | 4.3BSD-Tahoe（1988.06） |
| -- | --------------- | --------------------- |
| 正式地位 | 标准 Berkeley 发布 | interim release（中间版本） |
| 资格门槛 | AT&T UNIX 源代码许可证 | 4.3BSD VAX 版本许可证 |
| 平台支持 | 仅 VAX | VAX + Tahoe（CCI Power 6/32 及 OEM）+ 新 DEC 设备 |
| 使用场景 | 生产使用 | 测试与评估 |
| 发行数量 | 无一手数字 | 无一手数字（推断小于 4.2BSD 1000+ 站点） |
| 媒介规格 | 6250 BPI 1 卷或 1600 BPI 3 卷 | 6250 BPI 1 卷或 1600 BPI 3 卷（同 4.3BSD） |

**史观**：总纲第 9 条——经验优先：interim release 模式是 CSRG 工程实践的产物，反映 “先放出供测试评估，再吸收反馈完善为标准 release” 的工程迭代逻辑，而非理论先行的发布策略；总纲第 5 条——没有必然性，只有偶然性：Tahoe 作为 interim release 的发行模式与资格门槛（仅限 4.3BSD VAX 许可证用户）塑造了其发行规模上限，但具体发行数量因史料缺失无法确证，须区分 “模式可确证” 与 “数量不可确证”；总纲第 13 条——法律与道德是利益分配：Tahoe 仍受 AT&T UNIX 源代码许可证约束（Net/1 1989.06 发布前 BSD 仍含 AT&T 代码），“仅限 4.3BSD VAX 许可证用户” 的门槛反映了 AT&T 商业许可证对 BSD 发行渠道的法律约束

**辨析**：① **interim release 与 standard release 的辨析**——Tahoe 与 Reno 同为 interim release，但两者性质略有差异：Tahoe 的 interim 性质主要体现在 “测试新平台支持与机器相关/无关代码分离”（工程驱动），Reno 的 interim 性质主要体现在 “测试新虚拟内存系统与 NFS”（功能驱动），须区分两类 interim release 的工程动机；② **资格门槛与发行规模的因果关系**——Tahoe “仅限 4.3BSD VAX 许可证用户” 的门槛将其发行规模上限锁定在 4.3BSD VAX 用户基数内，但 4.3BSD VAX 用户基数本身无一手史料记载，故 Tahoe 具体发行数量无法确证，仅可作规模推断而非确证；③ **“Tahoe 发行策略对后续 BSD 发行的影响” 的谨慎表述**——Tahoe 的 interim release 模式为 Reno 所继承可确证（McKusick 1999 一手记载），但 Tahoe 对 Net/1 与 Net/2 发行策略的影响须谨慎判断——Net/1 与 Net/2 的 freely-redistributable 发行策略是 AT&T 商业化压力与 Bostic 代码清理工作的产物，非 Tahoe interim release 模式的直接演化，须避免线性因果；④ **“Tahoe 发行策略转向” 的辨析**——Tahoe 仍受 AT&T 许可证约束，Net/1 与 Net/2 转向 BSD 许可证 + 自由再分发，此转向非 Tahoe 演化而来，而是独立的法律与工程决策，须区分 “Tahoe interim release 模式延续”（Reno）与 “BSD 许可证发行转向”（Net/1、Net/2）；⑤ **媒介规格延续性的辨析**——Tahoe 媒介规格（1 卷 6250 BPI 或 3 卷 1600 BPI）与 4.3BSD（1986.06）相同，此延续性反映 1980 年代后期磁带技术的主流规格未发生显著变化，须注意媒介规格相同不等于发行策略相同；⑦ **发行公告两帖辨析**——正文所引 comp.sys.tahoe 1988-06-16 公告（tuhs 000067.html，2026-09-13 联网复核该页日期为 1988-06-16）与本节末 MAIL_INSIGHT 所记 1988-06-15 comp.bugs.4bsd 帖（Message-ID 8806152300.AA28766）日期与新闻组均不一致，可能为先行帖与正式公告两帖，两帖关系待核对 tuhs 存档后确证
