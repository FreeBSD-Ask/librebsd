# 039.8.1 4.3BSD 在 BSD 历史中的定位

**要点**：4.3BSD（**1986 年 6 月** 发布）在 BSD 历史中的定位为 BSD 商业主导期的终结与网络子系统长期影响的奠基——McKusick 1999 明确记载 "Although most of the vendors had started the switch back to System V, large parts of 4.3BSD were carried over into their systems, particularly the networking subsystem"（虽然大多数厂商已开始转回 System V，但 4.3BSD 的大部分被带入他们的系统，尤其是网络子系统），表明 4.3BSD 标志 BSD 作为独立商业操作系统主导地位的终结，但其网络子系统通过厂商集成延续影响；4.3BSD 是 CSRG 在 4.2BSD 性能批评后两年调优的成果，平息了 4.2BSD 以来的性能抱怨，但未引入重大新架构（虚拟内存重大改进推迟至 4.3BSD-Reno 1990）；4.3BSD-Tahoe（**1988 年 6 月** 发布）在 4.3BSD 基础上完成内核机器相关/机器无关代码拆分，为多架构移植奠定基础；4.3BSD-Reno（**1990 年初** 发布）引入 MACH 虚拟内存系统与 NFS 兼容实现，标志 BSD 向 4.4BSD 最后过渡的开始

| 4.3BSD 系列版本 | 发布时间 | 关键改进 | 历史定位 |
| ------------- | ------ | ------ | ------ |
| 4.3BSD | 1986.06 | 两年调优与网络代码精炼 | BSD 商业主导期终结 |
| 4.3BSD-Tahoe | 1988.06 | 内核机器相关/机器无关代码拆分，支持 CCI Power 6/32 | 多架构移植基础奠定 |
| 4.3BSD-Reno | 1990 年初 | MACH 虚拟内存系统，NFS 兼容实现 | 向 4.4BSD 最后过渡 |

**史料**：McKusick, M. K. (1999) “Twenty Years of Berkeley Unix” O'Reilly Open Sources 官方在线版（CSRG 核心成员当事人一手叙述，明确记载 4.3BSD 网络子系统被厂商集成入 System V、4.3BSD-Tahoe 内核拆分动机与结果、4.3BSD-Reno MACH 虚拟内存与 NFS 兼容实现三处关键叙述）；4.3BSD Release Notes (1986.06)；4.3BSD-Tahoe Release Notes (1988.06)；4.3BSD-Reno Release Notes (1990) ［A］

**史观**：第 3 条不存在进步，只有权力再分配——4.3BSD 标志 BSD 作为独立商业操作系统主导地位的终结，厂商转回 System V 系主导权再分配，而其网络子系统通过 System V 厂商集成延续影响；第 4 条分离聚合是永恒规律——4.3BSD 的网络子系统从 BSD 整体中分离出来，被聚合入 System V，分离与聚合的辩证统一在 4.3BSD 网络代码的厂商集成中具体化

**辨析**：① “BSD 商业主导期终结” 的表述须精确——BSD 并非在 4.3BSD 后立即退出商业市场，而是逐步被 System V 替代，4.3BSD 是此一过渡的关键节点而非绝对的终结点；② “大多数厂商转回 System V” 的叙事须区分 “完全切换” 与 “部分采纳”——厂商在 System V 基础上集成 BSD 网络代码而非完全切换回 System V，BSD 代码通过 “被集成” 而非 “作为主系统” 延续；③ 4.3BSD-Tahoe 的内核代码拆分虽为多架构移植奠定基础，但其直接动机是支持 CCI Power 6/32 硬件，多架构移植是副作用而非原计划目标；④ 4.3BSD-Reno 的 MACH 虚拟内存集成是 CSRG 选择 “寻找现有代码而非从头设计” 的工程实践体现，亦反映 CSRG 资源有限时的务实策略
