# 039.2.2 蠕虫利用的 BSD 漏洞

**要点**：Morris 蠕虫利用四个 BSD 漏洞：**sendmail(8)** 调试模式后门（DEBUG 命令允许远程执行任意命令，4.3BSD sendmail 默认开启 DEBUG 模式，具体版本号 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］）、**fingerd(8)** 缓冲区溢出（512 字节固定缓冲区被超长输入覆盖返回地址，arstechnica.com 2015-08-26 二手科技媒体叙述称“his exploit sent 537 bytes to fingerd”［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］）、**rshd(8)** 信任传递（rhosts 信任链跨主机传播）、密码字典攻击（获取的密码字典用于破解其他账户，含“guest”“manager”等常见弱密码），均为 4.3BSD 与早期 UNIX 共有漏洞

| 漏洞 | 类型 | 利用机制 | 修复方向 |
| -- | -- | ------ | ------ |
| **sendmail(8)** DEBUG 命令 | 调试模式后门 | SMTP `DEBUG` 命令远程调用解释器执行 shell 命令 | 默认禁用 DEBUG 模式 |
| **fingerd(8)** 缓冲区溢出 | stack smashing 早期实例 | 超长输入覆盖返回地址（512 字节固定缓冲区） | 改为动态分配 + 输入长度检查 |
| **rshd(8)** 信任传递 | 信任链跨主机传递 | `.rhosts` 信任链 A→B→C 跨主机扩散 | 禁止跨主机信任链、要求显式 `.rhosts` 声明 |
| 密码字典攻击 | 弱密码破解 | 利用“guest”“manager”等常见弱密码字典 | 引入密码强度策略与 shadow 密码 |
