# 034.3.1 VAX-11/780 硬件特性

**要点**：VAX-11/780 由 DEC 1977 年 10 月 25 日发布（DEC VAX-11/780 技术手册原文 “The VAX-11/780, introduced October 25, 1977”；retrocity.gr 希腊文史料原文 “ΣΑΝ ΣΗΜΕΡΑ 25 Οκτωβρίου 1977, η DEC παρουσιάζει...”），32 位地址空间、4GB 虚拟内存、硬件页表与 TLB 支持，是 3BSD 与 4.xBSD 的主要运行平台

| 硬件规格 | 参数 | 来源 |
| ------ | -- | -- |
| 发布日期 | 1977 年 10 月 25 日 | DEC VAX-11/780 Hardware Handbook；retrocity.gr 一手史料 |
| 架构 | 32 位虚拟地址扩展（VAX = Virtual Address eXtension） | DEC VAX Architecture Handbook Vol.1 (1977) |
| 虚拟地址空间 | 4 GB（32 位） | DEC VAX Architecture Handbook Vol.1 (1977) |
| 内存管理 | 硬件页表与 TLB（Translation Lookaside Buffer）支持 | DEC VAX-11/780 Hardware User's Guide (1979) |
| CPU 时钟周期 | 约 200 ns（对应约 5 MHz 时钟频率） | ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 须查阅 DEC EK-11780-UG-001 原始手册核实 |

**史料**：DEC VAX-11/780 技术手册、VAX 架构参考、DEC 销售档案、DEC VAX-11/780 Hardware Handbook、retrocity.gr 1977.10.25 史料 ［A］

**史观**：第 7 条硬件与软件辩证——VAX 的 32 位架构与硬件虚拟内存支持直接塑造了 BSD 的设计空间

**辨析**：VAX-11/780 的发布日期已确认为 1977 年 10 月 25 日（DEC VAX-11/780 Hardware Handbook 与 retrocity.gr 一手史料交叉印证），而非部分中文文献所记的 “1977 年”；同步宣布的 VAX/VMS V1.0 实际于 1978 年 2 月（HP 30 周年纪念原话 “February 1978—VMS v1.0 ships”）或 1978 年 8 月（HP OpenVMS 30th Anniversary Timeline 表格 “V1.0 / August 1978”）首次出货，宣布日与出货日须区分；CPU 时钟频率与最大物理内存的具体数值经 2026-07-29 联网核查未能从可访问的二手学术来源确证——Bitsavers 文档索引（bitsavers.org/pdf/dec/vax/780/、bitsavers.org/pdf/dec/vax/handbook/）确认 DEC 原始手册 PDF 存在但单文件 10-14 MB，WebFetch 无法完整解析；Hennessy & Patterson《Computer Architecture: A Quantitative Approach》附录 M 确认 VAX-11/780 名义 1 MIPS 与 Joel Emer 实测 0.5 MIPS 的事实，但未直接记载时钟频率与最大物理内存数值；网络流传 “5 MHz / 200 ns 时钟周期 / 8 MB 最大物理内存” 等说法未在可访问的权威一手来源中交叉印证，疑为对 DEC 原始手册的转引，须按 0 信任原则标注存疑，最终数值须查阅 DEC EK-11780-UG-001《VAX-11/780 Hardware User's Guide》(1979-02) 与 VAX Architecture Handbook Vol.1 (1977) 原始印刷版或 PDF 核实；VAX-11/780 CPU 为 KA780 模块（TTL 逻辑实现，非单芯片微处理器），Bitsavers KA780modules.txt 文件列出 M8232（CLK CPU CLOCK）等 30 余块模块，确认其为大板级 TTL 设计而非 VLSI 微处理器；freebsd.duckdb（freebsd-src 仓库最早 commit 为 1993-06-12T14:49:13Z by Rodney W. Grimes（罗德尼·W·格赖姆斯），hash 9002c02abc587664acb357c6879d8ca08664dd0b）远晚于 VAX-11/780 1977 年发布时间，无 VAX 硬件参数的代码级证据；[2026-08-14 两库核查：参考文献库 tech “VAX” 命中 reference_id=1546（Bell 1998），佐证 VAX 硬件谱系文献存在，但 CPU 时钟频率/最大内存等具体参数两库无条目，两库无法验证]
