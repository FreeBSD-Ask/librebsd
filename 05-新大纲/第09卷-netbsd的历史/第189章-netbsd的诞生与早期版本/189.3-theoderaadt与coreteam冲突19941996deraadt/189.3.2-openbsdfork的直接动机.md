# 189.3.2 OpenBSD fork 的直接动机

**要点**：1996 年 7 月 de Raadt fork OpenBSD（首个正式发行版 OpenBSD 1.2）的直接动机——撤权后无法继续贡献 NetBSD，de Raadt 决定 fork 创建专注于代码审计与安全的项目；OpenBSD 创建直接动机是“被边缘者另起炉灶”

**史料**：OpenBSD 创建公告 1996 年；de Raadt 公开演讲；OpenBSD 早期邮件存档；openbsd.duckdb openbsd-src 仓库 commits 表最早 commit 验证：1995-10-18T08:37:01Z（author = deraadt，commit df930be708d5），与“1995 年下半年开始筹备 fork”叙事吻合；当日 deraadt 在 openbsd-src 连续提交 10+ 条 commit（10:39、10:42、10:52、10:54、10:58、11:03、11:05、12:19、12:22 等），可视为 OpenBSD 仓库正式启动的代码级证据 ［A］

**史观**：边缘者贡献：de Raadt 作为被边缘者，通过 OpenBSD 创建获得新的贡献空间

**辨析**：OpenBSD 首次正式发布日期在不同叙事中差异较大——部分资料称 1996.5，部分称 1996.7，需对照 OpenBSD 官方 changelog（openbsd.org/plus.html 自 2.0 起列出，1.x 版本需对照早期 CVS 标签）核验。经 openbsd.duckdb openbsd-src 仓库 commits 表验证：openbsd-src 最早 commit 时间 1995-10-18T08:37:01Z（commit df930be708d5，author = deraadt），此时间与“OpenBSD 1.1 CVS 标签日期 1995.10.18”的叙事吻合，可解释为 1995.10.18 是 OpenBSD 仓库首条 commit 时间（即 fork 实际启动日），而非 OpenBSD 1.1 的发布日期；OpenBSD 1.1 是 fork 后首个公开版本，于 1996 年 1 月发布（依 OpenBSD 官方档案），OpenBSD 1.2 于 1996 年 7 月发布；故“1995.10.18”与“1996.7”分别对应 fork 启动与 1.2 正式发行两个不同时间点，二者非混用而是各自指代不同事件，存疑已部分解决；但 OpenBSD 1.1 的精确发布日期（1996.1 还是其他）仍需对照 OpenBSD 官方发布档案最终核验
