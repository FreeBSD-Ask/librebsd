**要点**：1993 年 NetBSD 分叉动机——386BSD 因 Jolitz 维护停顿无法支持新硬件与新功能，Chris Demetriou、Adam Glass、Charles Hannum 等伯克利学生决定 fork 创建 NetBSD，目标是延续 BSD 在多平台上的发展

**史料**：NetBSD 创建公告 1993.4；Demetriou/Glass/Hannum 早期邮件存档；386BSD 维护停滞记录；netbsd.duckdb netbsd-src 仓库最早 commit 时间为 1992-07-13（srcmastr/mrg 导入 CSRG 历史代码），Chris Demetriou（cgd）首批 commit 时间为 1993-03-21（共 18 条 commit 同一时间戳导入），Theo de Raadt（deraadt）首条 commit 时间为 1993-04-02T12:24:21Z（commit 355265a86628），与 NetBSD 1993.4 创建公告时间吻合；统计结论 [C-04]: netbsd-src 仓库总 commit 数 773,683（截至 2026-07-27 查询），为 4 大 BSD src 仓库中 commit 累计最高者；netbsd.duckdb 查询 L1.1.1 显示：netbsd-src 1993 年 commit_count=14,507，在 4 大 BSD src 仓库中占 94.35%（freebsd-src 同年仅 868 commit，占 5.65%），与“NetBSD 1993 年 fork 后早期开发强度远超 FreeBSD”叙事一致 ［A］

**史观**：总纲第 4 条——分离聚合是永恒规律：386BSD 停滞触发分离，NetBSD 创建体现分离与聚合的辩证

**辨析**：分叉动机在不同叙事中差异较大——部分归因于技术分歧，部分归因于个人冲突；需对照原始邮件存档核实。经 netbsd.duckdb netbsd-src 仓库 commits 表验证，Chris Demetriou（cgd）与 Theo de Raadt（deraadt）的首批 commit 时间戳（1993-03-21 与 1993-04-02）与 NetBSD 1993.4 创建公告时间高度吻合，可作为 fork 时间的代码级次权威证据；但需注意 netbsd-src 是 GitHub 镜像，主仓为 Mercurial（hg.NetBSD.org），2015 年 CVS→Mercurial、2018 年 Mercurial→Git 迁移可能引入时间戳偏差，故仍须与 NetBSD 官方公告交叉验证；L1.1.1 查询的 commit 量数据存在 GitHub 镜像滞后风险——netbsd-src GitHub 镜像同步可能滞后于 hg.NetBSD.org 主仓，1993 年 commit_count = 14,507 应与主仓 commit 量交叉验证

- [双库核查] NetBSD 1.0 发布公告经双库核查通过：netbsd-announce 邮件列表（跨 port-m68k/port-sparc 等列表）Chris Demetriou 公告（Message-ID `<no-id-port-m68k-5ded0af92ed2c634>`，1994 年）确认 1.0 发布，与 branches 表 `origin/netbsd-1-0` commit_date 1994-11-29 时序一致（参见考据记录 20260815_第09卷-netbsd的历史-mail-ref-db-factcheck.md §1）。
