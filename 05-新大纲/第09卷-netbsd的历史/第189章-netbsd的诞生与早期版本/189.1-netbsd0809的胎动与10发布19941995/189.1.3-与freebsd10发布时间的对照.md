# 189.1.3 与 FreeBSD 1.0 发布时间的对照

**要点**：NetBSD 1.0（1994.10.26）与 FreeBSD 1.0（1993.11.1）发布时间的对照——FreeBSD 1.0 早于 NetBSD 1.0 近 1 年发布；两项目虽同期发轫于 1993 年 4 月前后的 386BSD 分叉浪潮，但 NetBSD 1.0 因整合 4.4BSD-Lite 基础迁移工程而晚于 FreeBSD 1.0 发布；NetBSD 强调多平台可移植性，FreeBSD 强调 x86 性能优化；发布时间差异奠定两项目的差异化定位

**史料**：NetBSD 1.0 与 FreeBSD 1.0 Release Notes；两项目 1993-1994 年邮件列表对比；freebsd.duckdb freebsd-src 仓库 tags 表 release/1.0.0_cvs tagger_date = 1993-11-01T00:00:00-08:00（tagger = svn2git，2020 年 SVN-to-Git 迁移时重建的 tag，与 FreeBSD 官方公告 1.0 发布日期 1993.11.1 一致）；freebsd.duckdb netbsd-src 仓库 branches 表 origin/netbsd-1-0 commit_date = 1994-11-29T04:19:15Z（与 NetBSD 官方公告 1.0 发布日期 1994.10.26 时序一致）；freebsd.duckdb 查询 L1.1.2 显示：1993 年 4 大 BSD src 中 netbsd-src = 14,507（94.35%）vs freebsd-src = 868（5.65%），1994 年 netbsd-src = 17,726（80.78%）vs freebsd-src = 4,217（19.22%），反映 NetBSD 1.x 早期在 4 大 BSD 中长期保持 commit 量主导地位，直至 2003 年 dragonfly-src fork 后格局方逐步变化 ［A］

**史观**：技术选择即政治选择：NetBSD 与 FreeBSD 的发布时间差异反映不同技术政治选择

**辨析**：NetBSD 1.0 与 FreeBSD 1.0 的发布间隔约 12 个月（FreeBSD 1.0 于 **1993-11-01**，NetBSD 1.0 于 **1994-10-26**）；先前叙事中 ~~“1993.10.4 与 1993.11.1 同期发布”~~ 系误传，需对照 NetBSD 官方发布页面（**<https://www.netbsd.org/releases/formal.html>**）核验。经 freebsd.duckdb 验证：freebsd-src tags 表 `release/1.0.0_cvs` tagger_date = 1993-11-01（tagger = svn2git，2020 年 SVN-to-Git 迁移期 tag，须与 SVN 时代邮件列表存档交叉验证）；netbsd-src branches 表 `origin/netbsd-1-0` commit_date = 1994-11-29（与官方公告 1994.10.26 一致）；两者时间间隔约 12 个月，与官方公告吻合，~~1993.10.4 同期发布~~ 说法不正确，存疑已解决；L1.1.2 查询的 4 大 BSD src 比例数据须注意 openbsd-src/netbsd-src 为 GitHub 镜像，commit 量可能不完整，1993-1994 年 netbsd-src 94.35%/80.78% 的高占比应与 hg.NetBSD.org 主仓数据交叉验证，且 commit 量比例不等于技术影响力或市场占比
