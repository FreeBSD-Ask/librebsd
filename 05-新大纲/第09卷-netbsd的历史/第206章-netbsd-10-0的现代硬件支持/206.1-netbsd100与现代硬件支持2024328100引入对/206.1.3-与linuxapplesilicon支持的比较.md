# 206.1.3 与 Linux Apple Silicon 支持的比较

**要点**：Linux Apple Silicon 支持由 Asahi Linux 项目（Hector Martin 等）主导，2022 年起在 M1/M2 上获得可用桌面；NetBSD Apple Silicon 支持远落后 Linux，10.0 仅提供基础内核启动；FreeBSD arm64 自 2021 年起已可实验性引导 Apple M1/M2（支持度落后 Linux，但非“未支持”）；Linux 凭借社区规模与商业赞助（Asahi Linux 众筹）获得压倒性优势
