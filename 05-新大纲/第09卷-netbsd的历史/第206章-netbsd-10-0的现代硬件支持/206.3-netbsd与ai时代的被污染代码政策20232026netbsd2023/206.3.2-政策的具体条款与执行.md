# 206.3.2 政策的具体条款与执行

**要点**：tainted code 政策条款包括：AI 生成代码须明确标注来源、须由人类开发者逐行审查、不得直接粘贴；执行依赖 committer 自我声明与 peer review；政策未引入自动化检测工具（因 AI 检测技术不可靠）

**史料**：NetBSD tainted code 政策文档；tech-kern 邮件列表执行讨论；committer 自我声明样本 ［A］

**史观**：总纲第 17 条——形式与内容：政策作为“形式”（条款与流程）保障代码“内容”（人工审查的真实性）

**辨析**：政策执行的实际效果缺乏公开统计——需对照 commit log 中 AI 代码标注比例核验；“AI 生成代码”的定义（如完全 AI 生成 vs AI 辅助）在政策中可能存在模糊
