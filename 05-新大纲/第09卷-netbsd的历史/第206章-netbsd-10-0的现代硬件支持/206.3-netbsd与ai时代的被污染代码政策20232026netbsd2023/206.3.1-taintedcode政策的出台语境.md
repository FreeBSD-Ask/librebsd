# 206.3.1 tainted code 政策的出台语境

**要点**：NetBSD 2023 年率先明确将 AI 生成代码（如 GitHub Copilot、ChatGPT 生成的代码）定性为“被污染的代码”（tainted code），禁止直接合入主线；背景包括 GitHub Copilot 版权诉讼、Free Software Foundation 对 AI 代码的版权担忧；NetBSD Core Team 在 tech-kern 邮件列表发布政策讨论

**史料**：NetBSD Core Team 关于 tainted code 的公告；tech-kern 邮件列表讨论；GitHub Copilot 版权诉讼档案 ［A］

**史观**：总纲第 25 条——0 信任原则：tainted code 政策是 NetBSD 对 AI 时代“真实性困境”的哲学回应，体现 0 信任原则在代码层面的实践

**辨析**：tainted code 政策的具体条款（如“AI 生成代码须审查哪些方面”）在不同叙事中存在差异——需对照 Core Team 公告原文核验；政策出台的具体时间（2023 年中 vs 2023 年底）需考据

**文献**：NetBSD Core Team 公告；tech-kern 邮件列表；GitHub Copilot 版权诉讼档案 ［A］
