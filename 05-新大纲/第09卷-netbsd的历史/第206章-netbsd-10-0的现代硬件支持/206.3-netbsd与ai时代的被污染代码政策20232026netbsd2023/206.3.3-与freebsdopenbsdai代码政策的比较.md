# 206.3.3 与 FreeBSD/OpenBSD AI 代码政策的比较

**要点**：FreeBSD 2023-2026 年间对 AI 代码政策相对宽松，允许 AI 辅助但要求人类审查；OpenBSD 由 de Raadt 主导对 AI 代码持强烈怀疑态度，但未出台正式政策；NetBSD 是三大 BSD 中唯一明确出台 tainted code 政策的项目

**史料**：FreeBSD Committer's Guide 关于 AI 代码的章节；OpenBSD 邮件列表 de Raadt 关于 AI 的发言；NetBSD tainted code 政策 ［A］

**史观**：社区文化即技术资产：三大 BSD 对 AI 代码的不同态度反映各自社区文化——NetBSD 谨慎、FreeBSD 务实、OpenBSD 怀疑

**辨析**：FreeBSD 与 OpenBSD 的“AI 代码政策”在不同叙事中存在差异——部分资料称两者均无正式政策，部分称有非正式指导，需对照官方文档核验；OpenBSD de Raadt 的私人观点与 OpenBSD 官方立场需区分

**文献**：FreeBSD Committer's Guide；OpenBSD 邮件列表；NetBSD tainted code 政策 ［A］
