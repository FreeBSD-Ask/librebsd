# 194.5.2 OpenSSL 集成风险与嵌入式设备的加密栈困境（2001-2003）

**要点**：NetBSD 1.x 后期 OpenSSL 漏洞群对嵌入式设备构成特殊风险——NetBSD-SA2001-013（OpenSSL PRNG 实现弱点，熵池初始化不充分导致会话密钥可预测）、NetBSD-SA2002-009（CVE-2002-0655，OpenSSL ASN.1 解析器缓冲区溢出与 SSL v2 弱密钥协商）、NetBSD-SA2003-017（CVE-2003-0543/0544/0545，OpenSSL ASN.1 解析器双重释放与空指针解引用）；netbsd.duckdb 显示 itojun 主导 OpenSSL 安全升级（检索口径：commits 表 author 含 itojun、2002-07/08 时间窗、message 含 openssl），commit `1e8891b392f18bcded939ba980db7b7220adbb8a`（2002-07-30，“OpenSSL 0.9.6e. includes major security fixes”）、`042428eaf426e96fd227e8cf2f6b2456af1f6412`（2002-08-08，“openssl 0.9.6f, with security fixes”）；嵌入式设备因资源受限（CPU、内存、熵源）在 OpenSSL 升级中面临特殊困境——PRNG 熵源不足在嵌入式设备（无键盘、无鼠标、无磁盘 I/O）上更为严重，OpenSSL 0.9.6e 升级要求的内存与 CPU 开销对低端嵌入式设备构成压力

**史料**：NetBSD-SA2001-013 公告（OpenSSL PRNG）；NetBSD-SA2002-009 公告（CVE-2002-0655，OpenSSL ASN.1）；NetBSD-SA2003-017 公告（CVE-2003-0543/0544/0545，OpenSSL 双重释放）；netbsd.duckdb netbsd-src 仓库 itojun OpenSSL commit `1e8891b392f18bcded939ba980db7b7220adbb8a`（2002-07-30）、`042428eaf426e96fd227e8cf2f6b2456af1f6412`（2002-08-08） ［A］

**史观**：总纲第 17 条——软件工程：OpenSSL 在嵌入式场景下的 “熵源困境” 揭示 “通用加密栈” 与 “资源受限环境” 的工程张力——OpenSSL PRNG 设计假设桌面/服务器环境的丰富熵源（键盘、鼠标、磁盘 I/O），嵌入式设备缺乏这些熵源导致密钥可预测；总纲第 6 条——技术选择的代价：NetBSD 嵌入式市场定位使 OpenSSL 集成须在 “安全强度” 与 “资源开销” 之间权衡

**辨析**：OpenSSL PRNG 在嵌入式设备上的熵源不足问题是否在 NetBSD-SA2001-013 公告中被明确提及须对照公告原文核验——公告可能仅描述通用 PRNG 弱点而未专门讨论嵌入式场景；嵌入式设备的 OpenSSL 升级实际部署率须考据——厂商是否及时将 OpenSSL 0.9.6e/f 升级推送至终端设备须对照厂商固件更新历史核验；【0 信任原则·CVSS 评分缺失】CVE-2002-0655、CVE-2003-0543/0544/0545 均无 CVSS v3 评分，但 “ASN.1 解析器缓冲区溢出” 与 “双重释放” 的机制类型本身暗示较高风险

**文献**：NetBSD-SA2001-013、NetBSD-SA2002-009、NetBSD-SA2003-017 公告原文；netbsd.duckdb netbsd-src 仓库 itojun OpenSSL commit 记录 ［A］
