# 199.5.2 里程碑事件类

### 新闻条目 1

- **新闻标题（中英）**：NetBSD 9.0 released（NetBSD 9.0 发布）
- **新闻来源**：NetBSD 官方变更页 + 发布日期 2020-02-14 + URL `https://www.netbsd.org/changes/2020.html#netbsd-9-0-released` + 存档 URL `https://web.archive.org/web/2024/https://www.netbsd.org/changes/2020.html`
- **新闻摘要**：2020-02-14 NetBSD 9.0 正式发布，是 NetBSD 第十七个主要版本。NetBSD 9.0 引入了多项重要特性：改进的 SMP 性能、GPU 加速图形支持、新一代 USB 子系统、改进的网络栈、aarch64（ARM64）移植完善、Raspberry Pi 3 与 4 移植支持、改进的 ZFS 支持、JIT 编译器支持等。
- **与本章主题的关联说明**：直接对应本章 “NetBSD 9.x（2019-2021）” 主题的核心发布事件；aarch64 移植与 Raspberry Pi 4 支持是 9.0 时期最重要的工程里程碑。
- **与官方史料的交叉验证结论**：与 NetBSD 官方 releases 页面 `https://www.netbsd.org/releases/formal-9.0/` 一致；9.0 引入的特性列表与 NetBSD 9.0 release notes 完全吻合。

### 新闻条目 2

- **新闻标题（中英）**：NetBSD 9.1 released（NetBSD 9.1 发布）
- **新闻来源**：NetBSD 官方变更页 + 发布日期 2020-10-20 + URL `https://www.netbsd.org/changes/2020.html#NetBSD-9.1-released` + 存档 URL `https://web.archive.org/web/2024/https://www.netbsd.org/changes/2020.html`
- **新闻摘要**：2020-10-20 NetBSD 9.1 发布，作为 9.0 系列的第一个维护性更新。NetBSD 9.1 主要包含自 9.0 发布约 8 个月以来的安全修复与稳定性改进，与 NetBSD 9.0 完全兼容。
- **与本章主题的关联说明**：NetBSD 9.1 是 9.x 系列维护分支的典型案例；对应本章 “9.x（2019-2021）” 主题中维护性发布模式。
- **与官方史料的交叉验证结论**：与 NetBSD 官方 releases 页面 9.1 条目一致；发布日期与 NetBSD 邮件列表公告吻合。

### 新闻条目 3

- **新闻标题（中英）**：NetBSD 8.2 released（NetBSD 8.2 发布）
- **新闻来源**：NetBSD 官方变更页 + 发布日期 2020-04-02 + URL `https://www.netbsd.org/changes/2020.html#netbsd-8-2` + 存档 URL `https://web.archive.org/web/2024/https://www.netbsd.org/changes/2020.html`
- **新闻摘要**：2020-04-02 NetBSD 8.2 发布，作为 8.x 系列维护版本。NetBSD 8.2 包含从 9.0 开发分支回传的安全修复与稳定性改进。同日宣布 netbsd-7 分支延长支持三个月。
- **与本章主题的关联说明**：NetBSD 8.2 在 9.x 时期发布，反映 8.x 与 9.x 系列并行的长期支持模式；netbsd-7 分支延长支持反映 NetBSD 项目对旧分支的长期维护承诺。
- **与官方史料的交叉验证结论**：与 NetBSD 官方 releases 页面 8.2 条目一致；发布日期与 NetBSD 邮件列表公告吻合。

- **新闻来源**：NetBSD 官方变更页 + 发布日期 2020-02-13 + URL `https://www.netbsd.org/changes/2020.html#fundraising-2020` + 存档 URL `https://web.archive.org/web/2024/https://www.netbsd.org/changes/2020.html`
