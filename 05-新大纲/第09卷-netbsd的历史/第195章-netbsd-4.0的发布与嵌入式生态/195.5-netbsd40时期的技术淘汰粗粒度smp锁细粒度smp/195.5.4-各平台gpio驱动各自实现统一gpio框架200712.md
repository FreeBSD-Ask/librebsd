# 195.5.4 各平台 GPIO 驱动各自实现 → 统一 GPIO 框架（2007.12）

**要点**：NetBSD 3.x 及之前缺乏统一的 GPIO（General Purpose Input/Output）框架，各嵌入式平台 GPIO 驱动各自实现；NetBSD 4.0（2007.12）引入统一 GPIO 框架，提供 **gpio(4)** 设备接口与 **gpioctl(8)** 用户空间工具；GPIO 框架由 Marc Balmer 等开发者贡献；GPIO 框架使 NetBSD 在嵌入式设备（如 SoC 板卡）的 GPIO 控制标准化，简化嵌入式开发

**史料**：NetBSD 4.0 Release Notes GPIO 章节；**gpio(4)** 与 **gpioctl(8)** 手册页；Marc Balmer GPIO 框架 commit log；netbsd.duckdb netbsd-src 仓库 commits 表 GPIO 相关 commit 验证：christos 2007-01-06T00:58:04Z “PR/34682: Bucky Katz: Add support for the OMAP GPIO blocks.”（commit faa54b03a6a3，OMAP GPIO 块支持，早于 4.0 发布 2007.12.19 约 11 个月），christos 2007-01-06T16:08:54Z “Update the gpio code to the latest. From Bucky Katz”（commit ee28c46912e3，GPIO 代码更新）；此两 commit 由 christos 提交但署名 Bucky Katz 贡献，与 “GPIO 框架由 Marc Balmer 贡献” 叙事存在作者归属差异 ［A］

**史观**：总纲第 17 条——形式与内容：GPIO 框架作为 “形式” 统一了各平台 GPIO “内容”；技术选择的代价：GPIO 框架付出抽象层代价，但获得嵌入式开发简化

**辨析**：GPIO 框架的具体引入版本需考据——部分资料称 4.0，部分称 4.99.x（开发分支），需对照 Release Notes 与 commit log 核验；Marc Balmer 的具体贡献需对照 commit log 核验。经 netbsd.duckdb netbsd-src 仓库 commits 表验证：2007-01-06 christos 提交的 GPIO 相关 commit（OMAP GPIO 块支持、GPIO 代码更新）早于 4.0 发布日期 2007.12.19 约 11 个月，可视为 4.0 开发周期内 GPIO 框架演进的代码级证据；但 commit 署名贡献者为 Bucky Katz 而非 Marc Balmer，“GPIO 框架由 Marc Balmer 贡献” 叙事的作者归属需对照更多 commit 与邮件列表最终核验，存疑已部分解决（GPIO 框架在 4.0 周期内引入得到代码级确认，但作者归属待最终核验）
