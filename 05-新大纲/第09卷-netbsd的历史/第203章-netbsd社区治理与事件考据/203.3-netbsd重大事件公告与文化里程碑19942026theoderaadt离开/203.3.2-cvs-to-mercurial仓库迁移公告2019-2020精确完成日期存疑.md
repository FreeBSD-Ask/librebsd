# 203.3.2 CVS-to-Mercurial 仓库迁移公告（2019-2020，精确完成日期存疑）

**要点**：NetBSD 主仓库自 2019-2020 年间由 CVS 迁移至 Mercurial（位于 **<https://anonhg.netbsd.org/>**）——这一迁移是 NetBSD 基础设施现代化的关键事件，使 NetBSD 跟上现代分布式版本控制工具的步伐；但** 精确迁移完成日期未能从 netbsd-announce 邮件列表取得**——在 netbsd-announce 2019/02-2020/10 各月存档中未发现明确的“CVS-to-Mercurial 迁移完成公告”［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］；迁移公告可能发布于 tech-repository、source-changes 或 core 等其他邮件列表而非 netbsd-announce；netbsd.duckdb 的 tags 表不含 NetBSD 仓库 release tag，原因之一即为 NetBSD 主仓库已迁至 Mercurial，GitHub 镜像不携带 Mercurial 主仓的 release tag

**史料**：netbsd-announce 邮件列表 2019/02-2020/10 各月存档（逐月抓取，未发现迁移完成公告）；NetBSD-SA2024-002 PGP 原文（**<https://ftp.netbsd.org/pub/NetBSD/security/advisories/NetBSD-SA2024-002.txt.asc>**，2024-07-01，仍使用“cvs update -d -P”指令，提示文档可能未及时更新）；netbsd.duckdb tags 表查询结果（tags 表不含 netbsd-src/netbsd-pkgsrc，commits 表含 netbsd-src 773,687 条与 netbsd-pkgsrc 1,222,307 条）；考据记录 20260723_announcements-netbsd.md §C-5、§ 存疑判定依据-二 -3 ［A］

**史观**：形式与内容：版本控制系统作为 “形式”（开发工具框架）改变了开发 “内容”（协作方式）；CVS-to-Mercurial 迁移是 NetBSD 基础设施形式主义化的关键事件；商业与社区的张力：NetBSD 选择 Mercurial 而非 Git，与 FreeBSD（2020-12 SVN-to-Git）、DragonFly BSD（Git）、OpenBSD（CVS）形成对照，反映各 BSD 项目在版本控制工具选择上的分化

**辨析**：经考据记录 20260723_announcements-netbsd.md § 存疑判定依据-二 -3 验证：**精确迁移完成日期未能从 netbsd-announce 一手来源取得**——已尝试的查证路径包括 WebFetch 逐月抓取 netbsd-announce 2019/02、2019/05、2019/06、2019/07、2019/08、2019/10、2019/11、2019/12、2020/01、2020/02、2020/03、2020/04、2020/05、2020/06、2020/08、2020/10 月存档，均未发现明确的“CVS-to-Mercurial 迁移完成公告”；WebSearch 检索"NetBSD CVS Mercurial migration completed date 2020 announcement"未返回 NetBSD 官方结果；**未能覆盖的来源**——迁移公告可能发布于 tech-repository、source-changes、core 等其他邮件列表而非 netbsd-announce；亦可能通过 Repository 结构变化隐式完成而无单独公告 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］；**NetBSD-SA2024-002 PGP 原文的“cvs update”指令**——2024-07-01 发布的 SA 公告中仍使用“cvs update -d -P”指令，可能反映文档历史遗留未及时更新，而非实际仓库仍为 CVS；实际仓库状态须查 **<https://anonhg.netbsd.org/>** 确认；**与 FreeBSD SVN-to-Git 迁移（2020-12）的对比**——FreeBSD 迁移有明确公告与完整文档，NetBSD 迁移的公告可见度较低，反映两项目在基础设施变更的沟通透明度差异；**netbsd.duckdb 的影响**——NetBSD 主仓库迁至 Mercurial 导致 netbsd.duckdb 的 tags 表无法纳入 NetBSD release tag（GitHub 镜像不携带 Mercurial tag），NetBSD RELEASE 日期无法通过数据库 tag 交叉验证
