# 193.3.3 Linux 发行版包管理（RPM/DEB/APT，1994-2004）

**要点**：Linux 在 pkgsrc 同期发展出 RPM（Red Hat, 1995）、DEB/APT（Debian, 1993-1998）等二进制包管理系统，以 “预编译二进制 + 依赖解析” 为主；与 pkgsrc 的 “源码编译 + 跨平台” 形成对照——Linux 包管理强调分发便利，pkgsrc 强调可复现构建与可移植性。

**史料**：RPM/DEB/APT 历史文档 ［B］

**史观**：总纲第 8 条——本体论上各方平等：Linux 二进制包管理 vs BSD 源码 Ports 是两种分发哲学，反映生态差异。

**辨析**：pkgsrc 后期也支持二进制包（2001+），故 “源码 vs 二进制” 非绝对对立，而是起点差异。

**文献**：Red Hat. RPM History [EB/OL]；Debian. APT/DPKG Docs [EB/OL]. ［B］
