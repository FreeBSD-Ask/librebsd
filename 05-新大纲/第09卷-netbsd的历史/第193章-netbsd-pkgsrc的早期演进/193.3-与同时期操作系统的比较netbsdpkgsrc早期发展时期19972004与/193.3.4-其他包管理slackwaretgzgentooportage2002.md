# 193.3.4 其他包管理（Slackware tgz、Gentoo Portage 2002）

**要点**：同期还有 Slackware 的 tgz 简单打包（1993-）与 Gentoo Portage（2002，受 BSD Ports 启发以源码编译 + USE 标志著称）；Portage 明确受 pkgsrc/Ports 概念启发，体现 BSD 包管理思想向 Linux 的反向流动。

**史料**：Slackware/Gentoo 历史；Portage 受 Ports 启发记录 ［B］

**史观**：总纲第 4 条——分离聚合是永恒规律：Portage 受 BSD Ports 启发，是 BSD 包管理思想跨生态外溢的例证。

**辨析**：Portage 的 USE 标志与 pkgsrc 的 mk.conf 选项机制同源思路，但实现独立。
