# 193.4.2 IPsec/PPP 漏洞群与 NetBSD 2.x 网络栈安全（2006）

**要点**：NetBSD 2.x 后期网络栈漏洞集中在 IPsec 与 PPP 子系统——CVE-2006-0905（IPsec 重放序列号处理缺陷，攻击者可绕过重放保护伪造已接收的 IPsec 数据包，netbsd.duckdb 显示 rpaulo 2006-03-23 主仓 commit `51a2954a4da7db96e86a7364da01c209e7e16dcd`，riz 2006-03-28 至 03-30 多次 pullup 至 netbsd-2-0、netbsd-3 分支 commit `c047d4b2f8485ad052bb82cec4d05eccd893896c`、`db756ebe5a82afb9bf1342ac34145c28f330416a` 等，commit subject 明确引用 “FreeBSD SA-06:11 and CVE-2006-0905”，反映 NetBSD 与 FreeBSD 在 IPsec 实现上的代码共享与漏洞协同修复）；CVE-2006-4304（内核 PPP 代码缓冲区溢出，与 ISDN PPP 接口共享同一 PPP 实现，adrianp 2006-08-23 commit `3d8cbc06bac2eec7eff2e941a02d16f2b121c09e`，tron 同日多次 pullup commit `ee6be1e5c2479dfd8e97a410943129710a20ae66` 等）；此时期 NetBSD 网络栈与 FreeBSD、OpenBSD 存在代码共享，IPsec 实现源自 KAME 项目，PPP 实现的历史代码共享导致同源漏洞跨项目传播

**史料**：netbsd.duckdb netbsd-src 仓库 rpaulo commit `51a2954a4da7db96e86a7364da01c209e7e16dcd`（2006-03-23，CVE-2006-0905）；riz pullup commit `c047d4b2f8485ad052bb82cec4d05eccd893896c`（2006-03-28，CVE-2006-0905 netbsd-2-0 分支）；adrianp commit `3d8cbc06bac2eec7eff2e941a02d16f2b121c09e`（2006-08-23，CVE-2006-4304 PPP）；FreeBSD SA-06:11 公告原文 ［A］

**史观**：总纲第 15 条（文化即形式主义）：IPsec/PPP 漏洞群揭示 “代码共享双刃剑”——KAME IPsec 与历史 PPP 代码在 BSD 项目间的共享加速了功能传播，但也使同源漏洞跨项目扩散，FreeBSD SA-06:11 与 NetBSD CVE-2006-0905 修复的协同体现 BSD 家族的代码互鉴；总纲第 4 条（分离聚合是永恒规律）：NetBSD commit subject 显式引用 FreeBSD SA 编号反映 BSD 家族安全响应的协作传统

**辨析**：CVE-2006-0905 的 commit subject "FreeBSD SA-06:11 and CVE-2006-0905: update the replay sequence number" 表明 NetBSD 该漏洞修复直接借鉴 FreeBSD SA-06:11 公告，但两项目 IPsec 实现是否完全共享代码须对照源码 diff 核验——KAME 项目是 FreeBSD/NetBSD/OpenBSD IPsec 实现的共同源头，但各项目在 KAME 基础上的本地化修改可能使漏洞影响范围不同；CVE-2006-4304 的 PPP 漏洞涉及 ISDN PPP 接口，反映 NetBSD 在嵌入式与通信设备市场的 PPP/ISDN 代码维护压力；【0 信任原则·CVSS 评分缺失】两条 CVE 均无 CVSS v3 评分，但 “绕过重放保护” 与 “内核缓冲区溢出” 的机制类型本身暗示较高风险

**文献**：netbsd.duckdb netbsd-src 仓库 rpaulo、riz、adrianp、tron commit 记录；FreeBSD SA-06:11 公告；CVE-2006-0905、CVE-2006-4304 NVD 条目 ［A］
