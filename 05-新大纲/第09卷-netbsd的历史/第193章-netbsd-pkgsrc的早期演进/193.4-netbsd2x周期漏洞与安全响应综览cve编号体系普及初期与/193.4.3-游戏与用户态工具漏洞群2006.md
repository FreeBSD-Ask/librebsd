# 193.4.3 游戏与用户态工具漏洞群（2006）

**要点**：NetBSD 2.x 时期一批游戏与用户态工具漏洞被披露并修复——CVE-2006-1539（**tetris(6)** 游戏分数文件读取越界，drochner 2006-06-01 commit `3f13a4cf7b1bc96d4abe7fee82708310fd238bf7`，commit subject "Better check data read from tetris.scores before use as array indices"，tron 2006-06-08 多次 pullup 至稳定分支）；CVE-2006-1744（**sail(6)** 游戏缓冲区溢出，drochner 2006-04-20 commit `d8da09bdafc783cfa2e3861e01daf1c86b9ad07e`，commit subject “fix buffer overflow (CVE-2006-1744), from Debian”，snj 2006-04-25 至 04-26 多次 pullup）；这些漏洞虽影响有限（游戏程序通常不用于生产环境），但反映 NetBSD 2.x 时期对基本系统中所有 setuid/setgid 程序的系统性安全审计，与 OpenBSD 同期的全面代码审计文化形成呼应

**史料**：netbsd.duckdb netbsd-src 仓库 drochner commit `3f13a4cf7b1bc96d4abe7fee82708310fd238bf7`（2006-06-01，CVE-2006-1539 tetris）；drochner commit `d8da09bdafc783cfa2e3861e01daf1c86b9ad07e`（2006-04-20，CVE-2006-1744 sail）；tron pullup commit `fbaedb932b5f`（2006-06-08，**tetris(6)** netbsd-2-0 分支；原引哈希 `1b2544f35aaafffc0d442fa7a0c1e625b76fa7e6` 经 netbsd.duckdb 复查未命中，同日 tron **tetris(6)** pullup 实存 `fbaedb932b5f`、`543723af17ef`、`413774688d28` 等）；snj pullup commit `b6ebe409abdb3b9d1189aa467b125b5cdb2cdb9a`（2006-04-25，CVE-2006-1744 netbsd-2-0 分支） ［A］

**史观**：总纲第 15 条（文化即形式主义）：游戏程序漏洞的修复反映 NetBSD 安全审计的 “无死角” 原则——即使是低权限游戏程序也须遵循边界检查规范，此与项目统摄史观 “形式主义化” 在安全治理中的体现一致——将安全检查从 “高风险组件” 扩展至 “全部代码” 的形式主义化实践；总纲第 15 条（文化即形式主义）：NetBSD 对游戏程序漏洞的修复态度与 OpenBSD 的全面代码审计文化同源

**辨析**：CVE-2006-1744 的 commit subject “fix buffer overflow (CVE-2006-1744), from Debian” 表明 NetBSD 该修复借鉴自 Debian 项目，反映跨发行版安全协作——NetBSD 与 Debian 在用户态工具代码上存在共享（如 GNU 工具），同源漏洞须跨发行版协同修复；CVE-2006-1539 的 tetris 分数文件越界漏洞虽影响有限，但揭示 “信任本地文件内容” 的通用风险——任何读取用户可写文件的程序都须验证数据完整性；【0 信任原则·CVSS 评分缺失】两条 CVE 均无 CVSS v3 评分，但游戏程序漏洞的实际风险较低（通常无 setuid 权限）

**文献**：netbsd.duckdb netbsd-src 仓库 drochner、tron、snj commit 记录；CVE-2006-1539、CVE-2006-1744 NVD 条目 ［A］
