# 207.1.4 各项目发布数据与市场份额考据

**要点**：2010-2026 年间市场份额数据——Linux 服务器市场占有率约 70%-80%（云时代主导），FreeBSD 约 1%-2%，NetBSD 不足 0.1%，OpenBSD 不足 0.1%；BSD 整体在云时代被 Linux 进一步挤压

**史料**：Netcraft Web Server Survey 2010-2026；IDC 服务器操作系统市场报告；StatCounter 操作系统份额［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］〔L5 二手研究〕

**史观**：0 信任原则：市场份额数据需考据——Netcraft 基于 Web 服务器签名可能低估 BSD 部署

**辨析**：NetBSD 服务器市场份额“不足 0.1%”在不同调查中差异较大——需对照多源核验；BSD 在嵌入式市场的部署未被服务器市场报告统计
