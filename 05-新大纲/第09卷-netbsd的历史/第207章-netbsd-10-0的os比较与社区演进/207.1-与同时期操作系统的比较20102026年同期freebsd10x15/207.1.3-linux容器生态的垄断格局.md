# 207.1.3 Linux 容器生态的垄断格局

**要点**：Linux 3.x-6.x（2011-2026）凭借 cgroups、namespaces、Docker（2013）、Kubernetes（2014）主导云原生市场；NetBSD 缺乏原生容器能力（无 cgroups 等价物）被边缘化；pkgsrc 在 Docker 中的存在感微弱；FreeBSD 通过 jail 与 bhyve 部分应对，但仍不及 Linux

**史观**：商业与社区的张力：Linux 容器生态凭借商业赞助（Docker Inc.、Red Hat OpenShift）主导市场，BSD 整体被边缘化

**辨析**：FreeBSD jail 与 Linux 容器的“等价性”在不同叙事中存在分歧——jail 是 OS 级虚拟化，cgroups+namespaces 是轻量级虚拟化，技术路径不同；NetBSD 是否曾考虑实现 cgroups 等价物缺乏公开记录
