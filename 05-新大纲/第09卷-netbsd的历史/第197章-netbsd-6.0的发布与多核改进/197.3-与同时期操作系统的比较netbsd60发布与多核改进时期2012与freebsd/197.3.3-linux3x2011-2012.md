# 197.3.3 Linux 3.x（2011-2012）

**要点**：Linux 3.0（2011）至 3.x 在 NetBSD 6.0 同期强化调度器（CFS 演进）、Btrfs 与大内存支持；与 NetBSD 6.0 的 SMP 改进对照——Linux 借社区规模在特性广度上领先，NetBSD 6.0 以架构整洁与多平台平衡。

**史料**：Linux 3.x 发布说明 ［B］

**史观**：技术路线分化：Linux 单内核 + GPL 社区规模与 NetBSD 的 BSD 许可 + 多平台在 2012 形成能力落差。

**辨析**：Linux 3.x 的 SMP 成熟度高于 NetBSD 6.0，但后者在多平台一致性上具优势。

**文献**：Linux Kernel. 3.x Release Notes [EB/OL]. ［B］
