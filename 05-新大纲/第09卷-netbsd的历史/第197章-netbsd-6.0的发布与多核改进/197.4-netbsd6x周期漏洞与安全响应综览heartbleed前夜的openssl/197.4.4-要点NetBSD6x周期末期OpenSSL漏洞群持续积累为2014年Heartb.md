# 197.4.4 要点NetBSD6x周期末期OpenSSL漏洞群持续积累为2014年Heartb

**要点**：NetBSD 6.x 周期末期 OpenSSL 漏洞群持续积累，为 2014 年 Heartbleed（CVE-2014-0160）的爆发埋下伏笔——CVE-2013-0169（OpenSSL 1.0.1d 至 1.0.1e 升级中的多漏洞修复，christos 2013-02-12 commit `a79346cf8ad8cc6c7ff13916fedccb6b679da6ae`，commit subject “Changes between 1.0.1d and 1.0.1e [11 Feb 2013]”）、CVE-2014-0160（Heartbleed，OpenSSL TLS heartbeat 扩展内存泄露，ed81493569fefce792d08aa976144cfb15a2d23d，2014-04-08）、CVE-2014-0195/0221/0224/3470（OpenSSL 2014 年 6 月漏洞群，7f1933c65c30295bff0e9e49d9e9ec253f897c67，2014-06-05）、CVE-2014-0591（OpenSSL 拒绝服务，5c974b3074a13b17ebeed33fd00bad131991c6d8，2014-01-14）；Heartbleed（CVE-2014-0160）是 NetBSD 6.x 周期影响最广泛的漏洞——攻击者可利用 TLS heartbeat 扩展读取服务器进程内存（每次泄露最多 64KB），潜在泄露私钥、会话凭证、用户密码等敏感数据；NetBSD 的修复 commit `ed81493569fefce792d08aa976144cfb15a2d23d`（2014-04-08）在 Heartbleed 公开披露（2014-04-07）后 1 天完成，反映 NetBSD 对该漏洞的快速响应

**史料**：netbsd.duckdb netbsd-src 仓库 christos commit `a79346cf8ad8cc6c7ff13916fedccb6b679da6ae`（2013-02-12，CVE-2013-0169 OpenSSL 1.0.1e）；commit `ed81493569fefce792d08aa976144cfb15a2d23d`（2014-04-08，CVE-2014-0160 Heartbleed）；commit `7f1933c65c30295bff0e9e49d9e9ec253f897c67`（2014-06-05，CVE-2014-0195/0221/0224/3470 OpenSSL 群）；commit `5c974b3074a13b17ebeed33fd00bad131991c6d8`（2014-01-14，CVE-2014-0591）；Heartbleed 官方披露公告（heartbleed.com） ［A］

**史观**：总纲第 15 条（文化即形式主义）：Heartbleed 揭示“协议扩展实现缺陷”的工程风险——TLS heartbeat 扩展本为保活设计，但其实现中的长度检查缺失使攻击者可读取任意长度内存，此为“协议扩展作为攻击面”的典型范式；专题语（不设总纲条号）：Heartbleed 的广泛影响（影响约 17% 的 HTTPS 服务器）揭示“信任基础设施”的脆弱性——OpenSSL 作为全球 TLS 基础设施，其单点漏洞可影响整个互联网

**辨析**：NetBSD Heartbleed 修复 commit `ed81493569fefce792d08aa976144cfb15a2d23d` 的修复日期（2014-04-08）与 Heartbleed 公开披露日期（2014-04-07）相差 1 天，反映 NetBSD 的快速响应，但该修复是否同步至所有稳定分支（netbsd-6、netbsd-5）须对照 pullup commit 核验；CVE-2013-0169 的 commit subject“Changes between 1.0.1d and 1.0.1e [11 Feb 2013]”表明该 commit 为 OpenSSL 版本升级而非单独补丁，反映“依赖项漏洞通过升级修复”的实践；【0 信任原则·CVSS 评分缺失】全部 CVE 均无 CVSS v3 评分，但 Heartbleed 的实际影响已由历史证明为极高
