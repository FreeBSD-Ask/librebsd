# 192.1.5 要点19932004是BSD复兴与Linux崛起的重叠期NetBSD1x以多平台

**要点**：1993-2004 是 BSD 复兴与 Linux 崛起的重叠期：NetBSD 1.x 以多平台 + 社区治理（NetBSD Foundation 1995）立身，FreeBSD 以 x86 性能 + Ports 领先，OpenBSD 以安全分叉，Linux 以 GPL 社区规模爆发；四者在此期既竞争又互鉴，奠定 2000 年后开源格局。

**史料**：各系统 1993-2004 发布与治理史料 ［B］

**史观**：总纲第 4 条——分离聚合是永恒规律：NetBSD/FreeBSD/OpenBSD 同期并行演进，与 Linux 共同构成 UNIX/类 UNIX 生态的多元复兴。

**辨析**：将此期视为“BSD vs Linux”零和竞争是误读——代码互鉴（如 VM、网络栈）与社区流动持续发生。

**文献**：McKusick M K, Neville-Neil G. The Design and Implementation of the FreeBSD Operating System [M]. 2nd ed. Addison-Wesley, 2015. ［B］
