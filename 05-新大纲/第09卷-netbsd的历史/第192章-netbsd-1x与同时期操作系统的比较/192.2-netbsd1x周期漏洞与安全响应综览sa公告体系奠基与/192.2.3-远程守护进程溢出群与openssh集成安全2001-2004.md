# 192.2.3 远程守护进程溢出群与 OpenSSH 集成安全（2001-2004）

**要点**：NetBSD 1.x 后期远程守护进程缓冲区溢出是另一高发类别——NetBSD-SA2001-005（CVE-2001-0240，**ftpd(8)** 远程缓冲区溢出，匿名或认证用户可构造超长路径名触发溢出执行任意代码）、NetBSD-SA2001-018（CVE-2001-0670，**lpd(8)** 远程缓冲区溢出，攻击者可构造恶意打印作业请求获取 root 权限）、NetBSD-SA2001-012（**telnetd(8)** 选项协商缓冲区溢出）、NetBSD-SA2003-009（CVE-2003-0161，**sendmail(8)** prescan 地址解析器溢出）；OpenSSH 集成引入新型安全风险——NetBSD-SA2002-005（CVE-2001-1483，OpenSSH 协议版本 2 challenge-response 认证模块缺陷，远程攻击者可绕过认证以任意用户身份登录包括 root）、NetBSD-SA2001-003（SSH 守护进程漏洞与 **rnd(4)** 随机数设备默认配置熵源不足导致密钥可预测）；netbsd.duckdb 显示 itojun 2001-02-08 commit `7f8fa38080fdccd83f8a06e70b3a77abc8c2e435` 标注"authentication mistake in SSHv2 + pubkey, from markus. REBUILD AND RESTART SSHD NOW"，反映 OpenSSH 漏洞修复的紧迫性

**史料**：NetBSD-SA2001-005 公告（CVE-2001-0240，ftpd）；NetBSD-SA2001-018 公告（CVE-2001-0670，lpd）；NetBSD-SA2002-005 公告（CVE-2001-1483，OpenSSH challenge-response）；NetBSD-SA2003-009 公告（CVE-2003-0161，sendmail）；netbsd.duckdb netbsd-src 仓库 commit `7f8fa38080fdccd83f8a06e70b3a77abc8c2e435`（itojun，2001-02-08，SSHv2 pubkey 认证修复） ［A］

**史观**：软件工程：远程守护进程溢出群反映 1990 年代末 C 语言无边界检查的系统性风险在 BSD 基本系统中的集中爆发；法律结构：OpenSSH 的 BSD 许可证让 NetBSD 得以自由集成并快速响应安全漏洞，与 SSH 商业版的闭源形成对照

**辨析**：CVE-2001-0240（ftpd）与 CVE-2001-0670（lpd）均为远程 root 级溢出，但 NVD 未提供 CVSS v3 评分，不得臆造；NetBSD-SA2002-005 引用的 CVE-2001-1483 编号在 NVD 中对应 OpenSSH challenge-response 绕过，但该 CVE 的影响范围（仅 OpenSSH 2.x/3.x vs 所有 OpenSSH）需对照公告原文核验；commit `7f8fa38080fdccd83f8a06e70b3a77abc8c2e435` 的 commit subject 中“REBUILD AND RESTART SSHD NOW”反映当时安全修复的紧急程度，但该 commit 是否对应特定 CVE 编号须与 SA 公告交叉验证

**文献**：NetBSD-SA2001-005、NetBSD-SA2001-018、NetBSD-SA2002-005、NetBSD-SA2003-009 公告原文；netbsd.duckdb netbsd-src 仓库 itojun SSH 修复 commit ［A］
