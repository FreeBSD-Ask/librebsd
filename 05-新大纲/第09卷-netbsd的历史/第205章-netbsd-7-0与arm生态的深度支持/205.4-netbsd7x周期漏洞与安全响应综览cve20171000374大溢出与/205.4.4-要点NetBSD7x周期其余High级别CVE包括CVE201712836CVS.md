# 205.4.4 要点NetBSD7x周期其余High级别CVE包括CVE201712836CVS

**要点**：NetBSD 7.x 周期其余 High 级别 CVE 包括——CVE-2017-12836（CVSS v3 7.5 High，注入漏洞，commit `74e8c71cd1136230728133034816cf03b1f4af1f`，2017-08-22）、CVE-2018-5732（CVSS v3 7.5 High，ISC DHCP 缓冲区溢出，commit `097731dea099250bc460a975c393fc370c283a95`，2018-04-07）；CVE-2018-5732 影响 ISC DHCP 客户端与中继代理，攻击者可构造恶意 DHCP 响应触发缓冲区溢出，导致 DHCP 客户端崩溃或潜在代码执行——此漏洞对 NetBSD 嵌入式设备（依赖 DHCP 获取网络配置）构成特殊风险，嵌入式设备在不可信网络（如公共 Wi-Fi）中易受恶意 DHCP 服务器攻击；netbsd.duckdb 显示 CVE-2018-5732 与 CVE-2018-5733（Medium 5.9，ISC DHCP 拒绝服务）由同一 commit `097731dea099250bc460a975c393fc370c283a95` 修复，反映 “同组件多漏洞合并修复” 实践

**史料**：netbsd.duckdb netbsd-src 仓库 commit `74e8c71cd1136230728133034816cf03b1f4af1f`（2017-08-22，CVE-2017-12836 High 7.5）；commit `097731dea099250bc460a975c393fc370c283a95`（2018-04-07，CVE-2018-5732 High 7.5 与 CVE-2018-5733 Medium 5.9 ISC DHCP）；NVD CVE-2017-12836、CVE-2018-5732、CVE-2018-5733 条目 ［A］

**史观**：专题语（不设总纲条号）：CVE-2018-5732 的 ISC DHCP 缓冲区溢出揭示 “网络配置协议” 作为攻击面的工程风险——DHCP 协议设计假设可信网络环境，其实现中的缓冲区溢出可被恶意 DHCP 服务器利用攻击客户端，此为 “信任假设失效” 的典型范式；NetBSD 嵌入式设备依赖 DHCP 获取网络配置，使 DHCP 客户端漏洞对嵌入式场景构成特殊风险

**辨析**：CVE-2017-12836 的 “注入漏洞” 机制须对照 NVD 条目核验具体注入类型（SQL 注入、命令注入、代码注入等）——netbsd.duckdb 仅标注 “注入” 而未细分，须对照 NVD CWE 分类核验；核查留痕：该 CVE 与 NetBSD phnum/process64 ioctl 的栈碰撞问题相关（Qualys stack clash 系列），具体注入类型仍以 NVD 条目为准；CVE-2018-5732 与 CVE-2018-5733 由同一 commit 修复的论断须对照 commit subject 核验——该 commit 可能同时修复 ISC DHCP 的多个子漏洞；【0 信任原则·CVSS 评分核验】全部 CVSS v3 评分须以 NVD 官方条目为准

**文献**：netbsd.duckdb netbsd-src 仓库 commit `74e8c71cd1136230728133034816cf03b1f4af1f`、`097731dea099250bc460a975c393fc370c283a95`；NVD CVE-2017-12836、CVE-2018-5732、CVE-2018-5733 条目；ISC DHCP 安全公告 ［A］
