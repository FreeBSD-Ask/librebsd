# 205.3.1 FreeBSD 10.x/11（2015）


**2015 年同期操作系统 ARM 生态对照表**：

| 操作系统 | 版本（2015） | ARM 支持 | 重点关注 | 与 NetBSD 7.0 比较 |
| --- | --- | --- | --- | --- |
| NetBSD 7.0 | 7.0（**2015.9**） | Cortex-A15/A57 多核、RPI2 官方支持 | 平台广度与 SMP 提升 | — |
| FreeBSD | 10.1/10.2/11-CURRENT | ARMv7、Xilinx/ZedBoard | 服务器/嵌入式产品落地 | NetBSD 平台广度优，FreeBSD 产品落地优 |
| OpenBSD | 5.8（**2015.10**） | BeagleBone 等少数平台 | 安全与少数平台 | NetBSD ARM 平台数远多，OpenBSD 安全审计更严 |
| Linux | 4.0-4.x | ARM64、PREEMPT_RT、设备树统一 | 消费端 ARM 生态规模 | Linux 生态规模领先，NetBSD 架构一致性占优 |
| Windows 10 | 10（**2015**） | ARM 版本受限，x86 模拟 | 桌面/消费端 | 闭源限制定制，NetBSD 开源可定制 |

**要点**：FreeBSD 在 NetBSD 7.0 同期为 10.1/10.2/11-CURRENT（2015），以 ARM 支持（如 ARMv7、Xilinx/ZedBoard）、ZFS 与新网络栈见长；与 NetBSD 7.0 的 “ARM 深度支持 + 多核” 对照——FreeBSD 聚焦服务器/嵌入式产品落地，NetBSD 7.0 强调 ARM 平台广度与 SMP 提升。

**史料**：FreeBSD 10.x/11 发布说明（2015）；NetBSD 7.0 发布说明（2015.10）［A］

**史观**：BSD 谱系：FreeBSD 与 NetBSD 同期推进 ARM 与多核，体现家族并行创新。

**辨析**：NetBSD 7.0 的 ARM 支持广度（含 Raspberry Pi 等）与 FreeBSD 的嵌入式深度各有所长。

**文献**：FreeBSD. 10.x/11 Release Notes [EB/OL]；NetBSD. 7.0 Release Notes [EB/OL]. ［A］
