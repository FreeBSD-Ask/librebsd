# 205.3.3 Linux 4.x（2015）

**要点**：Linux 4.0（2015）在 NetBSD 7.0 同期以 ARM64 支持、实时性（PREEMPT_RT 进展）与设备树统一著称；与 NetBSD 7.0 的 ARM 深度支持对照——Linux 4.x 借 ARM 生态（树莓派、开发板）与社区规模在 ARM 消费端领先，NetBSD 7.0 在架构一致性与多平台代码复用上占优。

**史料**：Linux 4.x 发布说明（2015）［B］

**史观**：技术路线分化：Linux 4.x 的 ARM 生态规模与 NetBSD 7.0 的 ARM 深度形成落差。

**辨析**：ARM 生态份额由芯片厂支持主导，非内核技术优劣；NetBSD 7.0 在嵌入式教育利基有价值。

**文献**：Linux Kernel. 4.x Release Notes [EB/OL]. ［B］
