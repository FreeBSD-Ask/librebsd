# 205.3.2 OpenBSD 5.8（2015）

**要点**：OpenBSD 在 NetBSD 7.0 同期为 5.8（2015.10），以安全机制与 ARM 部分支持（如 BeagleBone）著称；与 NetBSD 7.0 的 “ARM 生态广度” 分野——OpenBSD 5.8 的 ARM 支持有限，专注安全与少数平台。

**史料**：OpenBSD 5.8 发布说明 ［A］

**史观**：BSD 谱系：OpenBSD 与 NetBSD 同期演进，安全 vs ARM 广度目标分化。

**辨析**：OpenBSD 5.8 的 ARM 平台数远少于 NetBSD 7.0，但每平台安全性审计更严。
