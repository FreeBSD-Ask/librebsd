# 205.3.5 同期 ARM 生态总览（2015）

**要点**：2015 年 ARM 成为操作系统竞争焦点：Linux 4.x 以生态规模领先，NetBSD 7.0 以平台广度与 SMP 提升立足，FreeBSD 10/11 在嵌入式产品落地，OpenBSD 5.8 安全利基，Windows 10 试探 ARM；NetBSD 7.0 以 “多核 + ARM 深度” 强化可移植哲学。

**史观**：BSD 谱系：NetBSD 7.0 与同族 BSD 在 ARM 时代并行创新。

**辨析**：ARM 竞争是生态（芯片/社区）竞争，内核技术各有侧重。

**文献**：NetBSD. 7.0 Release Notes [EB/OL]；ARM 生态史料。［B］
