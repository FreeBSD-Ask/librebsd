# 205.1.4 要点NetBSDARM平台commit记录是研究ARM移植演进的核心史料Jare

**要点**：NetBSD ARM 平台 commit 记录是研究 ARM 移植演进的核心史料；Jared McNeill、Ryo Shimizu 等是 ARM 移植主要贡献者；硬件文档考据需对照 ARM 架构参考手册与 SoC 厂商文档

**史料**：NetBSD CVS commit log 中 arm/evbarm 相关 commit；tech-port-arm 邮件列表；ARM Architecture Reference Manual ［A］

**史观**：0 信任原则（考据规则）：ARM 厂商文档中的 SoC 细节需对照实际硬件核验——部分厂商文档存在错误或遗漏

**辨析**：NetBSD ARM 平台支持列表在不同来源中可能略有出入——需对照 NetBSD/doc/PLATFORMS 文件核验；部分老 ARM 平台（如 StrongARM）是否仍在维护需考据
