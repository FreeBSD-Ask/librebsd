# 205.1.2 树莓派 RPI2/RPI3 的移植

  **RPI 移植最早 commit 原文**：

  > add support for rpi temperature sensor
  >
  > ——jmcneill (Jared McNeill), netbsd-src 仓库，commit `376e8f54a74c`, 2013-01-07T20:19:33Z

**要点**：NetBSD 7.0 引入对树莓派 RPI2（Cortex-A7）的官方支持，7.1 引入 RPI3（Cortex-A53 64 位）支持（RPI3 版本归属 7.1/8.0 存在叙事分歧，见辨析）；树莓派移植由 Jared McNeill 等推动；移植让 NetBSD 在嵌入式爱好者社区获得显著曝光

**史料**：NetBSD/evbarm 树莓派移植文档；Jared McNeill 邮件列表帖；CVS commit log；netbsd.duckdb netbsd-src 仓库 commits 表 RPI 相关 commit 验证（2013-2016）：jmcneill（Jared McNeill）2013-01-07T20:19:33Z “add support for rpi temperature sensor”（commit 376e8f54a74c，RPI 温度传感器支持，最早 RPI commit 之一）；jmcneill 2013-01-07T22:32:24Z " Add support for rpi cpu frequency scaling through machdep.cpu.frequency.* sysctl "（commit 254e99495965，RPI CPU 频率缩放）；jmcneill 2013-01-09T00:24:54Z “ genfb support for rpi ”（commit 180616cfd89e，RPI 帧缓冲支持）；skrll（Nick Hudson）2013-01-09T22:23:44Z " Provide dotg(4) - a driver for the Synposys DesignWare OTG USB IP found in the R..."（commit 0b453b8d4b3d，RPI USB OTG 驱动 dotg(4)）；skrll 2013-01-10T13:38:37Z “ Create a plcom0 device node for RaspberryPI ”（commit 5c014ba1cfaf，RaspberryPI 串口设备节点）；netbsd.duckdb netbsd-src 仓库 branches 表验证：origin/netbsd-7-0 branch commit_date = 2020-05-07T12:03:47Z（commit f76d427f5b4c，远晚于 7.0 发布 2015.9 约 4 年 8 个月），origin/netbsd-7-1 branch commit_date = 2020-05-07T12:07:13Z（commit 327ce71f43e8，远晚于 7.1 发布 2016.10 约 3 年 7 个月），两 branch commit_date 均为分支末次维护更新时间非发布时间 ［A］

**史观**：总纲第 10 条（动手者创造历史）：McNeill 作为嵌入式边缘贡献者，推动 NetBSD 在树莓派社区的普及

**辨析**：NetBSD 树莓派支持的实际可用性（性能、外设支持）需对照社区测试报告核验。经 netbsd.duckdb netbsd-src 仓库 commits 表验证：RPI 移植工作最早可追溯至 2013-01-07（jmcneill 提交温度传感器、CPU 频率缩放、帧缓冲支持），远早于 7.0 发布 2015.9 约 2 年 8 个月，反映 RPI 移植在 7.0 开发周期内已持续进行约 2 年 8 个月才随 7.0 正式发布；skrll（Nick Hudson）于 2013-01-09/10 提供 USB OTG 驱动 dotg(4) 与串口设备节点，是 RPI 移植的另一关键贡献者，原叙事中 “由 Jared McNeill 等推动” 中的 “等” 应明确包含 skrll；RPI3 64 位支持的具体版本（7.1 或 8.0）在不同叙事中存在分歧，仍需对照 NetBSD 官方 Release Notes 核验；7.0/7.1 发布日期仍须以 NetBSD 官方公告为准
