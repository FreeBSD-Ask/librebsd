# 205.2.2 旧 ARM 单核 → ARM 多核支持改进（2015）

**要点**：NetBSD 7.0（**2015.10**）改进 ARM 多核支持，支持 Cortex-A15/A57 等多核 SoC；~~引入 big.LITTLE 架构支持~~（存疑待考据【考据完成：2026-08-02 经项目数据库（netbsd.duckdb/netbsd.duckdb netbsd-src 仓库 commits 表）精确查询核验，结果详见本子节史料/辨析字段；相关声明未获代码级确认，维持存疑，特性是否引入留待官方 Release Notes 复核】，详见 76.1.1 辨析）；ARM SMP 调度器优化；7.0 引入对树莓派 RPI2（Cortex-A7）的官方支持，7.1 引入 RPI3（Cortex-A53 64 位）；树莓派移植由 Jared McNeill 推动，移植让 NetBSD 在嵌入式爱好者社区获得显著曝光

**史料**：NetBSD 7.0 Release Notes ARM 部分；tech-port-arm 邮件列表；CVS commit log 中 evbarm 相关 commit；netbsd.duckdb netbsd-src 仓库 branches 表验证：origin/netbsd-7-0 branch commit_date = 2020-05-07T12:03:47Z（commit f76d427f5b4c，远晚于 7.0 发布 2015.10 约 4 年 7 个月，属分支末次维护更新时间，非发布时间），origin/netbsd-7-1 branch commit_date = 2020-05-07T12:07:13Z（commit 327ce71f43e8，远晚于 7.1 发布 2016.10 约 3 年 7 个月），两 branch commit_date 均为分支末次维护更新时间非发布时间，与 6.x 系列模式一致；netbsd.duckdb netbsd-src 仓库 commits 表 aarch64 验证：joerg 2013-02-04 引入 LLVM/Clang AArch64 后端（commit 96fc3e30a7c3），matt 2013-10-29 添加 AARCH64 定义（commit f4eee7a46719），matt 2014-01-29 添加 latent AArch64 支持后又于同日删除（commit 25b6650f1bb1 与 8e5b387ff0e4），反映 7.0 时期 aarch64 在主分支处于反复状态；netbsd.duckdb 查询 L1.1.1 显示：netbsd-src 2013 年 commit_count = 19,460，2014 年 = 20,949（较 2013 年增长 7.6%），2015 年 = 17,365（7.0 发布年，较 2014 年下降 17.1%），2014 年 commit 量增长反映 7.0 开发中段 ARM 多核移植与 aarch64 准备的工程投入，2015 年发布年 commit 量下降反映进入发布收尾阶段；netbsd.duckdb 查询 L2.3.1.arm 显示：netbsd-src 2013 年 ARM 相关 commit = 854（开发峰值），2014 年 = 670，2015 年 = 464（7.0 发布年），2013 年 ARM commit 峰值与 aarch64 后端首次引入时序吻合，反映 2013 年是 ARM 生态深度支持的核心开发年，2015 年发布年 ARM commit 量下降反映 ARM 移植已趋稳定；统计结论 [C-04]: netbsd-src 仓库总 commit 数 773,683（截至 2026-07-27 查询），为 4 大 BSD src 仓库中 commit 累计最高者，本章时期（2013-2015）的 commit 活动构成此总量的后段；统计结论 [C-13]: netbsd-src 月度 commit 量 Pettitt 检验变点为 2012-04、BUISHAND R 检验变点为 2011-09（10,000 次 Monte Carlo），两检验变点均早于本章时期（2013-2015）约 1-2 年，反映本章时期处于 netbsd-src 长期下降趋势变点后的延续阶段，CVS 迁移至 Mercurial 的过渡期影响已基本消化；统计结论 [C-30]: netbsd-src ARIMA(2,1,4) 模型 AIC=−79.34（4 BSD 项目 src 仓库中最低，反映 netbsd-src 月度序列经一阶差分后模型拟合优度最佳），本章时期（2013-2015）的 commit 量数据纳入 ARIMA 建模样本；统计结论 [C-34]: netbsd-src ARIMA 模型预测 MAPE=25.65%、RMSE=109.44、coverage=94.74%，MAPE 在 4 BSD 项目中处于中等水平（低于 openbsd-src 45.21% 与 dragonfly-src 70.88%，略高于 freebsd-src 24.56%），反映 netbsd-src 月度序列的可预测性较好但本章时期 ARM 移植高峰带来的 commit 量波动可能贡献了部分预测误差 ［A］

**史观**：总纲第 5 条——偶然性：树莓派的爆发是偶然事件，NetBSD 抓住机会投入 ARM 多核支持改写自身在嵌入式市场的地位；社区与文明历史哲学：嵌入式爱好者社区的参与体现社区文明的扩展

**辨析**：NetBSD ARM 多核支持与 Linux ARM 多核支持的成熟度对比缺乏权威基准——需对照同硬件测试核验。经 netbsd.duckdb netbsd-src 仓库 commits 表验证：aarch64 后端于 2013.2.4 由 joerg 首次引入，AARCH64 定义于 2013.10.29 由 matt 添加，latent AArch64 支持于 2014.1.29 由 matt 添加后同日删除，反映 7.0 时期 aarch64 支持在主分支尚未稳定；big.LITTLE 在 NetBSD 中的具体实现细节需考据——经 netbsd.duckdb netbsd-src 仓库 commits 表查询 `message_subject LIKE '%big.LITTLE%' OR '%big_little%' OR '%biglittle%'` 未找到与 ARM big.LITTLE 架构直接相关的 commit（搜索结果均为 big/little endian 大小端处理），原叙事中 “7.0 引入 big.LITTLE 架构支持” 声明暂未得到代码级确认，存疑待考据【考据完成：2026-08-02 经项目数据库（netbsd.duckdb/netbsd.duckdb netbsd-src 仓库 commits 表）精确查询核验，结果详见本子节史料/辨析字段；相关声明未获代码级确认，维持存疑，特性是否引入留待官方 Release Notes 复核】；RPI3 64 位支持的具体版本（7.1 或 8.0）在不同叙事中存在分歧，仍需对照 NetBSD 官方 Release Notes 核验；7.0/7.1 发布日期仍须以 NetBSD 官方公告为准。L1.1.1 查询的 commit 量数据存在 GitHub 镜像滞后风险——netbsd-src 为 GitHub 镜像（主仓为 Mercurial **hg.NetBSD.org**），2013-2015 年 commit 量可能不完整；L2.3.1.arm 查询基于 message_subject LIKE '%ARM%’ 匹配，854/670/464 这组数字是 ARM 相关 commit 的下限，实际涉及 ARM 多核支持改进的 commit 可能更多（如 subject 中含 “evbarm” “Cortex” “Raspberry Pi” “aarch64” “SMP” 但未含 “ARM” 的 commit 未被统计）；2013 年 ARM commit 峰值（854）与 aarch64 后端首次引入时序吻合，但 commit 量峰值不等于技术成熟度峰值，2015 年发布年 commit 量下降可能反映 ARM 移植已进入稳定维护而非开发衰退
