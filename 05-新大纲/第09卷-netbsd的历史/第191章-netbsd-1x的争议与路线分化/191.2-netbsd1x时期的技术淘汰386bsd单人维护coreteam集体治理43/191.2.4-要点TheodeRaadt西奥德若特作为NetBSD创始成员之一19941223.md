# 191.2.4 要点TheodeRaadt西奥德若特作为NetBSD创始成员之一19941223

**要点**：Theo de Raadt（西奥·德·若特） 作为 NetBSD 创始成员之一，1994.12.23 被 Core Team 以“沟通风格问题”为由通过投票撤销 commit 权限；de Raadt 此后无法继续贡献 NetBSD，1995 年下半年开始筹备 fork，1996 年 7 月正式发布 OpenBSD 1.2（首个正式发行版）；OpenBSD 从 NetBSD 1.0 代码基础 fork，专注于代码审计与安全；fork 使 BSD 生态从 NetBSD/FreeBSD 两强格局演变为三足鼎立；从单一项目到独立 fork 的“淘汰”是社区治理失败的产物，亦是 BSD 多元化的契机

**史料**：de Raadt 撤权事件邮件存档（core 与 tech 邮件列表）；NetBSD Core Team 1994.12.23 决议记录；OpenBSD 创建公告（1996 年）；de Raadt 公开演讲与回应；OpenBSD 官方 changelog（openbsd.org/plus.html）；netbsd.duckdb netbsd-src 仓库 commits 表 deraadt 活动验证（首条 1993-04-02 commit 355265a86628，末条 1994-12-17 commit 699d2a37b0e3，共 2757 条 commit，末条早于 1994.12.23 决议 6 天）；openbsd.duckdb openbsd-src 仓库 commits 表最早 commit 1995-10-18T08:37:01Z（commit df930be708d5，author = deraadt），当日 deraadt 连续提交 10+ 条 commit（10:39、10:42、10:52、10:54、10:58、11:03、11:05、12:19、12:22 等），可视为 OpenBSD 仓库正式启动的代码级证据 ［A］

**史观**：总纲第 4 条——分离聚合是永恒规律：撤权事件触发分离，OpenBSD 创建体现分离与聚合的辩证；边缘者贡献：de Raadt 作为被边缘者通过 OpenBSD 获得新的贡献空间；0 信任原则：fork 叙事需考据，撤权原因在不同叙事中差异较大

**辨析**：撤权的具体原因在不同叙事中差异较大——部分归因于沟通风格，部分归因于技术分歧，部分归因于项目治理分歧；OpenBSD 首次正式发布日期在不同叙事中存在分歧——部分早期资料误作 1996.5，部分资料区分 OpenBSD 1.1 CVS 标签（1995.10.18）与 OpenBSD 1.2 首次正式发行（1996.7），需对照 OpenBSD 官方档案进一步核验。经 openbsd.duckdb openbsd-src 仓库 commits 表验证：1995.10.18 实为 openbsd-src 仓库首条 commit 时间（即 fork 实际启动日），与 OpenBSD 1.1 CVS 标签日期 1995.10.18 的叙事吻合，但此非 OpenBSD 1.1 发布日期；OpenBSD 1.1 是 fork 后首个公开版本（依 OpenBSD 官方档案，1996 年 1 月发布），OpenBSD 1.2 于 1996 年 7 月发布；故“1995.10.18”对应 fork 启动，“1996.1”对应 1.1 发布，“1996.7”对应 1.2 发布，三者各自指代不同事件，非混用；deraadt 在 netbsd-src 末条 commit 1994-12-17 与 1994.12.23 决议日期吻合（差 6 天），deraadt 在 openbsd-src 首条 commit 1995-10-18 与“1995 年下半年开始筹备 fork”叙事吻合，存疑已解决；但撤权原因的“沟通风格/技术分歧/治理分歧”三分法仍需对照原始邮件存档最终核验；OpenBSD 与 NetBSD 1.0 的代码 diff 需考据
