# 200.5.1 里程碑事件类


> 本子节汇总与本章主题相关的新闻报道与社区舆论，现按“里程碑事件类 / 官方制度文献”两类组织；批评类 / 故障类 / 冲突类 / 外部冲击类 / 校园社会文化新闻类五类暂无条目，待回填。所有新闻条目遵循 0 信任原则，须与官方史料交叉验证后方可采信。

### 新闻条目 1

- **新闻标题（中英）**：NetBSD Commit Guidelines — Do not commit tainted code to the repository（NetBSD 提交指南 — 不得向代码库提交受污染的代码）
- **新闻来源**：NetBSD 官方开发者文档 + 2024-05 修订 + URL `https://www.netbsd.org/developers/commit-guidelines.html` + 存档 URL `https://web.archive.org/web/2024/https://www.netbsd.org/developers/commit-guidelines.html`
- **新闻摘要**：2024-05 NetBSD Foundation 修订 Commit Guidelines（提交指南）第 2 条，明确规定 “不得向代码库提交 tainted code（受污染的代码）”。修订条款明确写道："Code generated by a large language model or similar technology, such as GitHub/Microsoft‘s Copilot, OpenAI’s ChatGPT, or Facebook/Meta's Code Llama, is presumed to be tainted code, and must not be committed without prior written approval by core."（由大语言模型或类似技术——如 GitHub/Microsoft Copilot、OpenAI ChatGPT、Facebook/Meta Code Llama——生成的代码被推定为受污染的代码，未经核心团队事先书面批准不得提交。）该政策首次在 BSD 项目中明确将 AI 生成代码归类为 “tainted code”。
- **与本章主题的关联说明**：直接对应本章 “NetBSD Foundation 治理” 主题中 2024-05 Tainted Code 政策争议的核心事件；“tainted code” 术语选择极具象征意义，反映 NetBSD Foundation 对代码来源纯洁性的严格立场，体现 BSD 项目对许可证合规与代码溯源的传统坚持。
- **与官方史料的交叉验证结论**：本身即为 NetBSD 官方 Commit Guidelines 一手史料，与 NetBSD Foundation 董事会决议记录、`netbsd-announce` 邮件列表公告一致；与同期 Gentoo 理事会 2024-04-14 投票禁止 AI 代码、QEMU 2023-11 起禁止 AI 代码的政策形成对照。

### 新闻条目 2

- **新闻标题（中英）**：类 Unix 开源操作系统 NetBSD 禁止提交由 AI 生成的代码（NetBSD Bans AI-Generated Code Commits）
- **新闻来源**：IT 之家（企鹅号，腾讯云开发者社区转载）+ 发布日期 2024-05-17 + URL `https://cloud.tencent.com.cn/developer/news/1400568` + 存档 URL `https://web.archive.org/web/2024/https://cloud.tencent.com.cn/developer/news/1400568`
- **新闻摘要**：2024-05-17 IT 之家报道 NetBSD Foundation 新开发政策：由大语言模型或类似技术（如 ChatGPT、GitHub Copilot）生成的代码将被假定为受到污染（即版权不明，不符合 NetBSD 的许可目标），从而不能被提交给 NetBSD。报道引用 NetBSD 提交指南原文，强调 “不要将受污染的代码提交到代码库”。报道指出 NetBSD 是免费、快速、安全且高度可移植的类 Unix 开源操作系统。
- **与本章主题的关联说明**：IT 之家的中文媒体报道是 Tainted Code 政策争议在国内 BSD 社区传播的主要节点；反映国内技术媒体对 NetBSD 治理决策的关注程度。
- **与官方史料的交叉验证结论**：报道内容与 NetBSD 官方 Commit Guidelines 一字不差对照一致；“版权不明，不符合 NetBSD 的许可目标” 表述准确转述了官方立场；报道日期 2024-05-17 与官方修订时间窗吻合。一手英文来源为条目 1 所引官方 Commit Guidelines 页（唯一一手），本条与条目 3、条目 4 系传播链记录（中文转载/汇总）。

### 新闻条目 3

- **新闻标题（中英）**：NetBSD 禁止 AI 生成代码（NetBSD Bans AI-Generated Code）
- **新闻来源**：搜狐号 “科技问题新制造” + 发布日期 2024-05-18 + URL `https://m.sohu.com/a/779654378_121124365/` + 存档 URL `https://web.archive.org/web/2024/https://m.sohu.com/a/779654378_121124365/`
- **新闻摘要**：2024-05-18 搜狐号 “科技问题新制造” 报道 NetBSD 禁止使用 ChatGPT、CoPilot 等 AI 工具生成代码。报道详细引用 NetBSD Commit Guidelines：“如果代码非开发者本人编写，那么需要仔细检查代码的许可证是否允许导入到 NetBSD 的源代码库，允许自由分发。开发者需要联络原代码的作者，确保他们是代码的唯一作者，并验证确保没有拷贝其它代码。由 GitHub/Microsoft Copilot, OpenAI ChatGPT 或 Facebook/Meta Code Llama 等大模型生成的代码被认为很可能拷贝自不同许可证授权的代码，BSD 要求未经核心团队批准不得递交这些 AI 工具生成的代码。”
- **与本章主题的关联说明**：搜狐号报道补充了 IT 之家报道未尽的细节，明确解释 “为何 AI 生成代码被视为 tainted code”——因 AI 模型可能拷贝不同许可证授权的代码，存在许可证污染风险；这一表述为理解 NetBSD Foundation 治理决策动机提供重要背景。
- **与官方史料的交叉验证结论**：报道引用的 Commit Guidelines 内容与官方页面一字不差；对 “为何视为 tainted code” 的解释与 NetBSD Foundation 一贯的许可证纯洁性立场一致；报道日期 2024-05-18 紧随官方修订与 IT 之家报道。

### 新闻条目 4

- **新闻标题（中英）**：Debian 要全体投票：以后还能不能用 AI 写代码（Debian to Vote on Whether AI-Generated Code is Allowed）
- **新闻来源**：今日头条 + 发布日期 2024 年 + URL `http://m.toutiao.com/group/7666635832400347654/` + 存档 URL `https://web.archive.org/web/2024/http://m.toutiao.com/group/7666635832400347654/`
- **新闻摘要**：今日头条报道 Debian 就 AI 生成代码问题进行全体投票的讨论。报道梳理了 2024 年各开源项目的 AI 代码政策时间线：NetBSD 在 2024 年 5 月修改守则时用了 “tainted code（被污染的代码）” 这一传神术语，未经 core 书面批准不得提交；Gentoo 理事会 2024-04-14 投票禁止 AI 代码，理由为版权、质量、伦理三件套；QEMU 从 2023 年 11 月起即禁止 AI 代码。报道将 NetBSD 的 Tainted Code 政策置于 2023-2024 年开源项目 AI 代码政策浪潮中考察。
- **与本章主题的关联说明**：跨项目比较视角是理解 NetBSD Foundation 2024-05 Tainted Code 政策历史地位的关键史料；反映 NetBSD 在开源生态 AI 伦理治理浪潮中并非孤立事件，而是与 Gentoo、QEMU、Debian 形成政策共振。
- **与官方史料的交叉验证结论**：报道所引 NetBSD 2024-05 修订时间、Gentoo 2024-04-14 投票时间、QEMU 2023-11 起禁止时间均与各项目官方记录一致；“tainted code” 术语与 NetBSD 官方 Commit Guidelines 一致；Debian 投票事件与 Debian 项目邮件列表存档一致。

### 新闻条目 6

- **新闻标题（中英）**：NetBSD Foundation Resolutions（NetBSD Foundation 决议集）
- **新闻来源**：NetBSD Foundation 官方 + 持续维护 + URL `https://www.netbsd.org/foundation/#resolutions` + 存档 URL `https://web.archive.org/web/2024/https://www.netbsd.org/foundation/`
- **新闻摘要**：NetBSD Foundation 自 2003 年起通过多项关键决议：2003-01-14 同时成立 administration-exec、communication-exec、finance-exec、membership-exec、technical-exec 五个执行委员会（前三者于 2008-03 解散，2017-02-15 通过书面决议重新确认解散）；2003-09-23 成立 <core@NetBSD.org>（核心团队，即 Tainted Code 政策中的 “core” 决策机构）；2003-12-02 成立 <pkgsrc-pmc@NetBSD.org>（pkgsrc 项目管理委员会）；2004-10-06 成立 <www-pmc@NetBSD.org>（网站项目管理委员会）；2016-08-10 成立 <concom@NetBSD.org>（会议委员会，2017-11-08 修订）。Foundation 还制定了 Donation Policy（2003-07-15）、New NetBSD developer application procedure、Reimbursement Policy（2018-05-02）等政策文件。
- **与本章主题的关联说明**：决议集梳理 NetBSD Foundation 自 2003 年起的治理结构演进；<core@NetBSD.org>（核心团队）的 2003-09-23 成立决议是理解 2024-05 Tainted Code 政策 “prior written approval by core” 条款的治理源头；pkgsrc-pmc、www-pmc、concom 等项目管理委员会的成立反映 Foundation 的分权化治理演进。
- **与官方史料的交叉验证结论**：本身即为 NetBSD Foundation 官方决议一手史料；与 NetBSD Foundation 章程条款、董事会会议记录一致；与各执行委员会邮件列表存档（如 <core@NetBSD.org> 邮件列表）一致。
