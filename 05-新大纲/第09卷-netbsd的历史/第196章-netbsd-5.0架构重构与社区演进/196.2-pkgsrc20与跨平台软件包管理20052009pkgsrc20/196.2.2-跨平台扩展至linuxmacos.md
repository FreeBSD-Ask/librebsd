# 196.2.2 跨平台扩展至 Linux/macOS

**要点**：pkgsrc 2005-2009 年间扩展至 Linux（特别是 Slackware、Gentoo 等发行版）、macOS（通过 bootstrap）、Solaris、IRIX、AIX 等平台；pkgsrc 在 macOS 上的成功催生 MacPorts（2007）等项目借鉴其设计；跨平台能力使 pkgsrc 成为“系统无关的软件包管理框架”

**史料**：pkgsrc/doc/PLATFORMS 文件历年版本；macOS 上 pkgsrc bootstrap 文档；MacPorts 设计文档与 pkgsrc 对比［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］〔L1 代码/构建产物/L3 官方文档与公告〕

**史观**：总纲第 2 条——分离与聚合：pkgsrc 与 NetBSD 内核的“分离”换来与多平台的“聚合”，体现了 BSD 哲学的“工具独立于系统”理念

**辨析**：MacPorts 是否直接基于 pkgsrc 存在叙事分歧——MacPorts 早期文档称借鉴 FreeBSD Ports，但部分技术细节与 pkgsrc 高度相似，需对照早期 MacPorts 源码核验；pkgsrc 在 Linux 上的实际用户数缺乏权威统计
