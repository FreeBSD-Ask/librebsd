# 196.6.2 Sonnenberger 的 pkgsrc 维护

**要点**：Joerg Sonnenberger 作为 pkgsrc 长期维护者在 2005-2009 年间提交数千次 commit，是 pkgsrc 跨平台扩展的核心推动者；Sonnenberger 还参与 NetBSD 内核开发，特别是文件系统与构建系统改进；其工作风格以“严格技术标准”著称

**史料**：pkgsrc CVS commit log 中 joerg 的提交记录；tech-pkg 邮件列表讨论；Sonnenberger 的 BSDCan 演讲 ［A］

**史观**：边缘者贡献：Sonnenberger 作为德国开发者，是 NetBSD 欧洲边缘者贡献的代表

**辨析**：Sonnenberger 的具体 commit 数量在不同统计工具中差异较大——需对照 CVS 与 Git 镜像核验；其工作风格在社区中存在争议，部分 committer 称其“过于严格”，需对照邮件列表讨论核验
