# 204.9.2 里程碑事件类

### 新闻条目 3

- **新闻标题（中英）**：Darwin（2000 年苹果发行的电脑操作系统）
- **新闻来源**：baike.com 主站镜像 + 持续维护 + URL `https://m.baike.com/wiki/Darwin/750129` + 存档 URL `https://web.archive.org/web/2024/https://m.baike.com/wiki/Darwin/750129`〔原禁引来源（仅作考据留痕）·已改引官方主源 ref2259（Apple Open Source 官方站）〕
- **新闻摘要**：词条描述 Apple Darwin 操作系统基于 FreeBSD 与 NetBSD 等 BSD 系统开发，是 Mac OS X（后改名为 macOS）的开源核心。Darwin 具有对称多处理器（SMP）优势、高效能网络设施、多种整合档案系统支持。Darwin 的开发始于 2000 年，是 Apple 在 NeXTSTEP 基础上整合 BSD 组件（包括 NetBSD 部分代码）的产物。
- **与本章主题的关联说明**：Darwin 是本章比较叙事的关键对照案例——Apple 在 NeXTSTEP 基础上整合 BSD 组件（含 NetBSD 代码）演化出 Darwin，与 NetBSD 的独立演进路径形成对照；macOS/iOS/tvOS/watchOS/visionOS 等均构建于 Darwin 之上，间接继承 NetBSD 代码。
- **与官方史料的交叉验证结论**：与 Apple 开源官方页面 `https://opensource.apple.com/` 一致；与 NetBSD 官方历史页关于 “Apple's Rhapsody” 为 NetBSD 衍生品的表述一致；与 Darwin 源码 `xnu` 仓库的 BSD 部分对照一致。

### 新闻条目 4

- **新闻标题（中英）**：Unix 和 Linux 的发展史 — 386BSD 与 BSD 衍生谱系
- **新闻来源**：CSDN 博客（acmen99）+ 发布日期 2016 + URL `https://blog.csdn.net/acmen99/article/details/51154451` + 存档 URL `https://web.archive.org/web/2017/https://blog.csdn.net/acmen99/article/details/51154451`〔原禁引来源（仅作考据留痕）·已改引官方主源 ref2147（NetBSD 官方历史页）〕
- **新闻摘要**：博客梳理 Unix 与 Linux 发展史：386BSD 被认为是 FreeBSD、OpenBSD、NetBSD、DragonFly BSD 的先辈。这是 AT&T 妄图私有化 Unix 的时代，1986 年 IEEE 指定委员会制定开放作业系统标准 POSIX（Portable Operating Systems Interface）。BSD 衍生出 FreeBSD、NetBSD、OpenBSD；NeXTStep 也基于 BSD，后来演化为 Apple Darwin。
- **与本章主题的关联说明**：386BSD → NetBSD → 多 BSD 衍生品的谱系梳理是本章比较叙事的谱系前提——比较 NetBSD 与 FreeBSD/OpenBSD/DragonFly BSD 等同时期系统须以共同谱系为背景；NetBSD 既是 386BSD 的衍生品，又是 OpenBSD 等后续 BSD 的母项目。
- **与官方史料的交叉验证结论**：386BSD → FreeBSD/NetBSD/OpenBSD 谱系与 NetBSD 官方历史页 BSD 时间线一致；POSIX 标准起源时间 1986 年与 IEEE POSIX 工作组档案一致；CSDN 来源仅作辅助，须与 NetBSD/OpenBSD/FreeBSD 官方文档交叉验证后采信。
