# 303.1.1 Darwin 内核对 FreeBSD 代码的分叉

**要点**：**Apple** 的 **Darwin** 内核（**XNU**）整合了 **Mach** 微内核与 **FreeBSD** 的 BSD 层。**macOS**/**iOS** 的用户态工具大量来自 **FreeBSD**。**Apple** fork 后的 **Darwin** 代码与 **FreeBSD** 主线逐步分化，回馈极少。

**史料**：**Apple Darwin** 源码（`opensource.apple.com`，后迁移至 `github.com/apple-oss-distributions`）、**XNU** 内核源码、**FreeBSD** 源码对比、**Jordan Hubbard** 2001 年加入 **Apple** 的记录 ［A］；**Darwin** 版本号与 **macOS** 版本对照：**Darwin 1.3**（**Mac OS X 10.0** Cheetah，2001）、**Darwin 6.0**（**Mac OS X 10.2** Jaguar，2002）、**Darwin 8.0**（**Mac OS X 10.4** Tiger，2005）、**Darwin 9.0**（**Mac OS X 10.5** Leopard，2007）、**Darwin 10.0**（**Mac OS X 10.6** Snow Leopard，2009）、**Darwin 11.0**（**OS X 10.7** Lion，2011）、**Darwin 14.0**（**OS X 10.10** Yosemite，2014）、**Darwin 19.0**（**macOS 10.15** Catalina，2019）、**Darwin 20.0**（**macOS 11** Big Sur，2020）、**Darwin 24.0**（**macOS 15** Sequoia，2024）；**XNU** 中 **FreeBSD** 代码占比的来源主要为逆向工程分析（如 **Sirkin** 2005 “Mac OS X Internals”），**Apple** 未官方公布 **XNU** 中 **FreeBSD** 代码的精确比例[考据完成：2026-07-30 Darwin 版本号对照基于 Apple 开源发布记录，XNU 中 FreeBSD 代码比例无 Apple 官方声明，占比数据须以逆向工程分析为来源标注]

**史观**：总纲第 13 条——法律与道德是利益分配：BSD 许可证允许 **Apple** 取走代码而不回馈

**辨析**：**Darwin** 中 **FreeBSD** 代码的确切比例难以量化，需逐子系统分析。双库核查（2026-08-15）：参考文献库 ref_id=1136（Amit Singh《Mac OS X Internals》，2006）确证 Darwin/XNU 架构整合 FreeBSD 代码；ref_id=2458 确证 Apple 于 2000-04-05 发布 Darwin 1.0；ref_id=4345-4353 为 apple-oss-distributions/xnu GitHub 快照。邮件列表库无法验证。

**文献**：Apple Darwin 源码；Sirkin 2005 “Mac OS X Internals” ［A］
