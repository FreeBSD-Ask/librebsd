# 298.5.11 教材辨析

**要点**：教材辨析：(1) 是否过于偏重文件系统（McKusick 专长）；(2) 是否忽略网络栈细节；(3) 是否及时反映 ZFS 集成；(4) 与 Tanenbaum《Modern Operating Systems》的对比

**史料**：教材、评论 ［B］

**史观**：0 信任原则

**辨析**：教材平衡性偏重文件系统（McKusick 专长），网络栈与安全框架覆盖相对薄弱；与 Tanenbaum《Modern Operating Systems》的通用覆盖相比，McKusick 教材在 BSD 子系统深度上更强但广度上较窄

**文献**：Tanenbaum. Modern Operating Systems[M]. 年份不详；作者不详. 教材评论[EB/OL]. 年份不详 ［B］
