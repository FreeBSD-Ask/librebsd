# 298.3.1 Yahoo!/Hotmail 大规模部署


商业部署案例与回馈形态对照：

| 部署方 | 部署时期 | 应用场景 | FreeBSD 使用范围 | 回馈形态 |
| --- | --- | --- | --- | --- |
| Yahoo! | 1996 年起 | 前端服务 | FreeBSD + Apache（数千台服务器） | 工程反馈（具体回馈须依赖 Yahoo! 工程博客交叉验证） |
| Hotmail | 1997 年前 | Web 邮件 | FreeBSD + Solaris | Microsoft 收购后迁移至 Windows，无回馈 |
| Netflix | 2012 年起 | Open Connect CDN | 底层操作系统 | RACK/TLP、KTLS 等网络栈优化回馈 freebsd-src 上游 |
| WhatsApp | 2009 年起 | 服务器架构 | 依赖 FreeBSD | Jan Koum 2014-11 捐赠 $1,000,000 至 Foundation |
| Juniper | 1990 年代末 | Junos 控制平面 | Junos 基于 FreeBSD | 工程师参与社区提交 patch（具体名单须按 @juniper.net 邮箱域名细分查询） |
| NetApp | 1990 年代起 | ONTAP 基底 | ONTAP 基于 FreeBSD | 文件系统相关工作参与 |

**要点**：Yahoo! 是 FreeBSD 早期（1996 年起）最大的商业部署案例之一，整个前端服务运行于 FreeBSD + Apache；Hotmail 1997 年被 Microsoft 收购前运行于 FreeBSD + Solaris，Microsoft 收购后将其迁移至 Windows 以证明 Windows 服务器能力；Yahoo! 部署规模数千台服务器，是 FreeBSD 在互联网泡沫期的主要商业证明

**史料**：Yahoo! 工程博客、David Filo 关于 FreeBSD 的早期评论、Hotmail 迁移案例研究 ［C］

**史观**：总纲第 5 条——没有必然性，只有偶然性：Microsoft 收购 Hotmail 后强制迁移反映商业策略凌驾技术最优

**辨析**：Hotmail 迁移时间线在 freebsd.duckdb 中无直接证据（Hotmail 非 FreeBSD 项目仓库）；Yahoo! 部署规模数字须依赖 Yahoo! 工程博客与新闻报道多源交叉验证
