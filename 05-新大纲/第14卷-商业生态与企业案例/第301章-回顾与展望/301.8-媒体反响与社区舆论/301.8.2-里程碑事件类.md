# 301.8.2 里程碑事件类

### 新闻条目 1

- **新闻标题（中英）**：FreeBSD Handbook 历史章节——Walnut Creek CDROM 的支持
- **新闻来源**：FreeBSD 项目官方文档 + FreeBSD 文档项目 + 持续维护 + URL <https://docs.freebsd.org/en/books/handbook/eresources/> + 存档 URL <https://web.archive.org/web/2026/https://docs.freebsd.org/en/books/handbook/eresources/> ；另见 <https://docs-archive.freebsd.org/doc/6.4-RELEASE/usr/share/doc/zh_CN/books/handbook/history.html>
- **新闻摘要**：FreeBSD 官方 Handbook 记载，FreeBSD 小组为给上网不方便的用户提供发行渠道，开始与 Walnut Creek CDROM 发行商联系。Walnut Creek CDROM 不仅支持发行 FreeBSD 光盘版的想法，还为该计划提供了所需的计算机和高速网络接入。Walnut Creek CDROM 多年来使用 FreeBSD 支撑最繁忙的 Internet FTP 服务器 `ftp.cdrom.com`，该服务器能支持超过 6000 个并发连接。
- **与本章主题的关联说明**：此为 FreeBSD 项目官方对 Walnut Creek CDROM 早期商业支持的权威记载，是 BSDi 收购 Walnut Creek CDROM 事件前因后果的关键背景史料。
- **与官方史料的交叉验证结论**：此为 FreeBSD 项目官方文档一手史料。`ftp.cdrom.com` 的并发连接数可与 FreeBSD Status Reports 历史归档交叉验证。
