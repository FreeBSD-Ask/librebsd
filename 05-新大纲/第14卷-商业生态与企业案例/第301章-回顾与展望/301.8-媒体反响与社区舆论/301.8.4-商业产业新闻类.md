# 301.8.4 商业产业新闻类

### 新闻条目 1

- **新闻标题（中英）**：FreeBSD 商业供应商目录中的 BSDi 历史遗迹
- **新闻来源**：FreeBSD 项目官网 + Sergio Carlavilla Delgado + 最后修改日期 2026-05-16 + URL <https://www.freebsd.org/commercial/> + 存档 URL <https://web.archive.org/web/2026/https://www.freebsd.org/commercial/>
- **新闻摘要**：FreeBSD 官方商业供应商目录页面当前版本（2026-05-16）已不再列出 BSDi 与 Wind River BSD/OS 产品线，反映 BSDi/Wind River BSD 商业路线已退出 FreeBSD 商业生态。目录当前活跃的咨询供应商包括 Klara Systems、iXsystems 等继承 BSD 商业传统的公司。
- **与本章主题的关联说明**：BSDi 与 Wind River BSD/OS 产品线在 FreeBSD 商业目录中的缺席，从反面印证了其商业路线的终结。
- **与官方史料的交叉验证结论**：此为 FreeBSD 项目官方一手史料。iXsystems 出现在当前目录中，与 iXsystems 收购 BSDi 部分资产的历史一致。
