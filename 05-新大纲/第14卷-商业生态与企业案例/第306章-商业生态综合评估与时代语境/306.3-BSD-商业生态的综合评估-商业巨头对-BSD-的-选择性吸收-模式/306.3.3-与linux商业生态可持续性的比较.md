# 306.3.3 与 Linux 商业生态可持续性的比较

**要点**：**Linux** 商业生态通过 **Red Hat**、**Canonical**、**SUSE** 形成完整商业闭环，**BSD** 商业生态缺乏类似闭环，可持续性存疑。

  | 维度 | **Linux** 商业生态 | **BSD** 商业生态 |
  |---|---|---|
  | 商业闭环 | **Red Hat**/**Canonical**/**SUSE** | 缺乏 |
  | 企业回馈 | 强制/自愿回馈 | 选择性吸收 |
**史料**：**Red Hat** 2018 年报、**Canonical** 2018 年报、**SUSE** 2018 年报、**FreeBSD Foundation** 年报 ［B］

**史观**：商业形态分化：**Linux** 商业闭环 vs **BSD** 商业碎片化

**辨析**：**BSD** 商业生态是否可能通过新商业模式形成闭环

**文献**：各公司年报；FreeBSD Foundation Annual Report ［B］
