# 306.3.1 商业巨头选择性吸收模式的评估

**要点**：**Apple**、**Sony**、**Juniper**、**NetApp** 等商业巨头采用选择性吸收模式，使用 **BSD** 代码但回馈有限，形成 **BSD** 商业生态的主导形态。

**史料**：**FreeBSD** 源码 `commit` 记录、各公司开源项目页面 ［A］
    FreeBSD 社区论文：[FP-2018-002] Flexible Disk Use in OpenZFS（Matt Ahrens，2018）<https://papers.freebsd.org/2018/bsdcan/ahrens-flexible_disk_use_in_openzfs/>
**史观**：总纲第 13 条——法律与道德是利益分配：**BSDL** 允许不回馈

**辨析**：选择性吸收模式是否反映 **BSDL** 的设计意图或漏洞

**文献**：FreeBSD 源码仓库；各公司开源项目页面 ［A］
