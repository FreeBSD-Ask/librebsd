# 299.2.2 经济教育模式横向比较

**要点**：经济教育模式横向比较：(1) Linux 教育以 Red Hat 认证（RHCE）、企业培训、FSF 倡导为主；(2) Windows 教育以 Microsoft 认证（MSCE）为主；(3) Solaris 教育以 Sun 认证为主；(4) FreeBSD 教育以“源代码开放 + 教材经典 + 会议传播”为特征；Linux 商业化教育更普及，BSD 学术化教育更深度

**史观**：总纲第 4 条——分离聚合是永恒规律，BSD 教育模式延续学术传统

**辨析**：BSD 教育在商业化教育市场被边缘化——Red Hat RHCE、Microsoft MCSE 等商业认证占据主流，BSD 无对应商业认证体系；但 BSD 在学术教育（高校操作系统课程、研究生系统研究）中仍保持地位，McKusick 教材作为权威参考
