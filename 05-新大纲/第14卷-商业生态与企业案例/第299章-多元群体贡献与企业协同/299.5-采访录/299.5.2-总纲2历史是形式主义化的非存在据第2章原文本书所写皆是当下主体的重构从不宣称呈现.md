# 299.5.2 总纲2历史是形式主义化的非存在据第2章原文本书所写皆是当下主体的重构从不宣称呈现

- 总纲 2“历史是形式主义化的非存在”——据第 2 章原文“本书所写皆是当下主体的重构，从不宣称呈现历史本身”，麦库西克在 bsdtalk 018 中对 McKusick & Associates 提供 FreeBSD 培训课程经济模式的陈述，并非对客观培训过程的复述，而是麦库西克作为 McKusick & Associates 创始人在当下对既往培训实践的形式主义化重组。其“CSRG 时期知识传承转化为商业培训的路径，以及 FreeBSD 内核设计课程对开发者社区的贡献”的因果链，本身是当下主体赋予既往事件的形式主义化叙事。
- 总纲 4“分离聚合是永恒规律”——据第 4 章原文“UNIX 与 BSD、BSD 各分支之间的分合循环，是历史的根本结构”，CSRG 知识在 CSRG 1995 年解散后分离，在 FreeBSD 培训中聚合为商业模式，是 BSD 谱系内部知识传统的分离聚合循环。但聚合形态已非 CSRG 时期的复刻——McKusick & Associates 的商业培训以课程付费模式重新锚定 CSRG 知识传承，构成新的工程实体，而非 CSRG 时期“师徒制学术传承”的复刻。
- 总纲 5“没有必然性，只有偶然性”——据第 5 章原文“每一个关键人物、每一次 fork、每一个技术决定，都是不可替代的偶然”，培训课程经济模式的形成由若干偶然决策交汇促成——CSRG 知识商业化的时机是偶然，FreeBSD 内核设计课程的开发时点亦是偶然。麦库西克作为 McKusick & Associates 创始人的介入本身构成不可替代的偶然。培训课程经济模式不可被读为“CSRG 知识必然商业化”的目的论——替代品的无限性不能否定事物的独特价值，但 McKusick & Associates 的商业模式亦不能反向论证其必然性。
- 总纲 10“动手者创造历史”——据第 14 章 14.2 节“真正推动 BSD 的是‘Get your hands dirty’（动手去做）的人，而非旁观者”，麦库西克从 CSRG 到 FreeBSD 培训的持续知识传承，体现动手者的形态。但 14.1 节“决定世界的并非某个阶级，也不是什么经济”提示：不可将麦库西克的“持续传承”简化为“独立英雄”叙事——培训课程依赖 CSRG 时期的知识积淀基础、FreeBSD 内核设计课程的工程内容，以及 bsdtalk 等播客的形式主义化传播机制，“动手者”的认定与影响本身嵌入社区形式主义化条件。
- 总纲 11“商品是形式主义”——据第 11 章原文“技术市场的选择不是自然选择，而是形式主义的权力运作。劣币驱逐良币是普遍规律”，McKusick & Associates 的商业培训是技术市场的形式主义权力运作——CSRG 知识的商业化使内核设计课程成为可交易的商品，其市场定位由 FreeBSD 开发者社区的需求形式主义化决定。但须警惕“劣币驱逐良币”——商业培训的存在可能挤压志愿者社区对培训依赖度的独立评估，使“付费培训”成为开发者社区知识获取的默认路径。
- 总纲 19“解释学循环是历史认识的根本条件”——据第 19 章原文“前理解的差异使分歧不可避免”，麦库西克作为 McKusick & Associates 创始人对培训课程价值的视角，与志愿者社区对培训依赖度的视角构成不同的前理解。二者在培训课程价值的判断上可能存在分歧——麦库西克倾向强调商业培训对知识传承的系统化价值，志愿者社区倾向强调志愿维护者的非商业化知识传递价值，这种分歧本身是历史认识的根本条件，而非可被消除的误差。

**要点**：

- Sangoma 公司沿革：约二十年历史的硬件厂商，起家于 V.35、RS-232 等数据协议接口卡；约在访谈前五年随 VoIP 技术兴起转型生产 T1 数字卡与模拟卡，凭多年硬件经验在 Asterisk 社区获得口碑。（BSDTalk EP150，[203.38-249.94]，L1）
- Feldman 在 Sangoma 任软件项目负责人约十年，FreeBSD 驱动支持是其入职后的第一个项目；随 VoIP 发展 Linux 成为公司商业主线并占据其工作时间，但作为 FreeBSD 长期支持者，他仍以工作时间之外的努力将公司全线硬件持续推向 FreeBSD，自称视这些驱动如自己的孩子。（BSDTalk EP150，[181.18-293.70]，L1）
- 支持形态超出驱动层：公司对全部卡型支持 FreeBSD，用户致电支持可直达设计并开发该卡驱动的工程师；公司近期宣布全线硬件终身保修；面向爱好者提供廉价入门产品，如单 T1 口基础卡与可直连电话线路、允许外接普通电话的模拟卡，便于以 Asterisk 实验 VoIP。（BSDTalk EP150，[293.70-360.30]，L1）
- 上游化目标：当时正与社区推动 wanpipe 驱动进入 FreeBSD 基本系统树，希望借此引发 FreeBSD 用户对 Asterisk、SS7 协议与 VoIP 应用的兴趣，比照 Linux 社区已有的同类生态，并期待 FreeBSD 有朝一日能在桌面操作系统市场与对手竞争。（BSDTalk EP150，[446.22-496.46]，L1）
- Kaliski 早年任职于初创期的 RSA Data Security，VeriSign 即自 RSA 分拆而来；EMC 收购 RSA 后他随迁 EMC，约两年前回任 VeriSign 出任 CTO，负责公司长期技术愿景，并称与运营全球分布式基础设施多年的团队共事是其职务的兴奋点。（BSDTalk EP230，[122.27-147.24]，L1）
- VeriSign 以 SSL 证书业务为起点，收购 Network Solutions 后开始运营域名注册局，尤其承担 .com 与 .net 等注册局；历经多年公司变动后业务重新聚焦注册局，并在该全球分布式平台上叠加新的连接类产品与服务。（BSDTalk EP230，[148.08-184.58]，L1）

- 首届 vBSDcon 定于 2013 年 10 月 25 至 27 日在弗吉尼亚州 Herndon 的 Hyatt Dulles 举行，周五欢迎晚宴加周六周日两日单轨议程；Kaliski 阐明 VeriSign 采用业界轮值承办模式，自视为众多受益于 FreeBSD 的公司之一并期望他企业接力承办，同时已向 FreeBSD 基金会捐款，并持续征集志愿者参与组织。（BSDTalk EP230，[307.37-423.47]，L1）

- Google 开源释出分两类：API 示例以 BSD、GPL、Apache 等多许可发布；独立工具则依兼容性选型，如 Google Talk 语音组件 libjingle 经 Java 规范提案开放信令规范并以 BSD 与 GPL 发布，malloc 性能工具与 sparse hash table 实现均取 BSD 许可；DiBona 称 BSD 许可为全球第二大流行许可，企业借此确保释出代码可被最广泛使用。（BSDTalk EP41，[437.28-533.18]，L1）

**史观**：

- 总纲10 动手者创造历史：Feldman 的自述显示，商业公司对 FreeBSD 的支持并非市场决策而是动手者的个人劳动维系：在 Linux 主导商业需求的格局下，工程师以业余时间把全线硬件驱动推向 FreeBSD，默默投入的个体劳动构成企业与 BSD 社区之间的实际纽带。（BSDTalk EP150，[420.12-436.06]，L1）
- 总纲8 本体论上各方平等：Kaliski 表达的企业架构观将 Linux 与 BSD 置于对等地位：不为任一生态单独绑定，而是以组件独立与构建多样性消解对单一系统的依赖，任一生态的进展皆可为己所用；企业技术选型中各方平等、无单一正统的姿态由此成为风控原则。（BSDTalk EP230，[251.37-278.26]，L1）
- 总纲4 分离聚合是永恒规律：VeriSign 的公司史呈现为一系列分离与聚合：自 RSA 分拆而生，吸收 Network Solutions 而扩张，随 EMC 收购 RSA 而易主，最终剥离证书业务重聚于注册局；企业形态在分合往复中重定边界，而非沿单一方向演进。（BSDTalk EP230，[122.27-184.58]，L1）
- 总纲11 商品是形式主义：闭源商业软件把 FreeBSD 纳入支持矩阵、厂商因同行进入市场而跟进投资、社区以展位与客户曝光回报厂商——BSD 生态的扩张经由商品兼容性与商业模仿链完成，开源平台的价值以商品形式得到确认。（BSDTalk EP258，[230.74-255.88]，L1）
- 总纲3 不存在进步，只有权力再分配：DiBona 解释平台支持优先级时直言：个体开发者对平台重要性的自我认同无法改变企业按聚合用户量分配工程资源的逻辑，被支持与否是资源权力的再分配结果而非技术优劣的裁决；被冷落平台的出路在于代码开源后由社区自行移植。（BSDTalk EP41，[688.02-723.94]，L1）

**辨析**：
