# 302.11.3 数字鸿沟的正义辨析

**要点**：数字鸿沟在 BSD 社区引发正义问题——发达国家开发者主导 BSD 发展，发展中国家开发者处于边缘，需通过正义原则评估（存疑：主导与边缘化的国别分布无统计数据支撑，待考）。

**史观**：总纲第 8 条——本体论上各方平等：数字鸿沟的正义辨析

**辨析**：BSD 社区是否需主动纠正数字鸿沟——正方诉诸各方平等的参与前提，主张社区应补贴国际参与；反方主张社区自治不宜承担社会工程职能；考据点在于区分社区自发的技术扩散与有意识的资源再分配，两者效果须分别评估。
