# 302.0.1 要点

- 加州大学伯克利分校 **Evans Hall** 是 **CSRG**（Computer Systems Research Group）所在地，1970-1995 年间 BSD 在此诞生，1995 年 **CSRG** 解散后遗址仅存铭牌与档案。
- 伯克利校园内 **Soda Hall**（计算机系新楼，1994 年启用）替代 **Evans Hall** 成为计算机系主楼，BSD 历史地标从 Evans 转向 Soda，但 **CSRG** 时期的物理痕迹逐渐消失。
- 伯克利作为 BSD 发源地被全球 Unix 社区视为文化原乡，但 CSRG 1995 年解散后这一地位逐渐淡化，需通过史学方法还原其文化意义。
- 伯克利 BSD 遗址史料分散在 UC Berkeley 档案、CSRG 文件、个人收藏中，需多源交叉核对。
- 北美 BSD 发展以学术驱动为主（伯克利 CSRG、剑桥 CHERI），欧洲学术与商业并重（剑桥、NetApp 英国），亚洲商业驱动（日本 Sony、Juniper 韩国），其他地区社区驱动。
