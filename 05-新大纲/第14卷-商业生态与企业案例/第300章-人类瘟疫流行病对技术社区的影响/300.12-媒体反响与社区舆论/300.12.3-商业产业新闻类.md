# 300.12.3 商业产业新闻类

### 新闻条目 1

- **新闻标题（中英）**：FreeBSD 商业供应商目录（Commercial Vendors）
- **新闻来源**：FreeBSD 项目官网 + Sergio Carlavilla Delgado + 最后修改日期 2026-05-16 + URL <https://www.freebsd.org/commercial/> + 存档 URL <https://web.archive.org/web/2026/https://www.freebsd.org/commercial/>
- **新闻摘要**：FreeBSD 官方维护的商业供应商目录页面，将商业生态分为咨询服务（Consulting Services）、硬件供应商（Hardware Vendors）、互联网服务提供商（Internet Service Providers）、软件供应商（Software Vendors）四大类别。页面明确声明 “列入名单不意味着 FreeBSD 项目背书其产品或服务”。
- **与本章主题的关联说明**：此为 FreeBSD 项目官方对自身商业生态的权威分类，是 BSD 商业生态总论的一手史料，反映 FreeBSD 项目对商业生态的自我认知与边界划定。
- **与官方史料的交叉验证结论**：此页面本身即为 FreeBSD 项目官方一手史料，无需二次交叉验证。页面最后修改者 Sergio Carlavilla Delgado 为 FreeBSD 文档项目提交者。

### 新闻条目 2

- **新闻标题（中英）**：FreeBSD Foundation 终端用户故事集（End User Stories）
- **新闻来源**：FreeBSD Foundation 官网 + 无具体作者（机构发布）+ 持续更新 + URL <https://freebsdfoundation.org/end-user-stories/> + 存档 URL <https://web.archive.org/web/2026/https://freebsdfoundation.org/end-user-stories/>
- **新闻摘要**：FreeBSD Foundation 官方维护的终端用户案例库，收录 NYI、Sheridan Computers、Beckhoff、RG Nets、NetApp、Metify、Cloudnium、Antithesis、E-Card、Netflix 等多个商业用户的案例研究。页面含商业用户证言集，包括 NetApp（Matt Hambrick，ONTAP Engineering Director）、Netflix（David Fullagar，Content Delivery Architecture Director）、WhatsApp（Jan Koum（简·库姆），CEO）、Microsoft、NGINX、Mellanox、Stormshield、Verisign、Netgate、Chelsio、ScaleEngine 等公司高管的亲口证言。
- **与本章主题的关联说明**：这是 FreeBSD Foundation 对 BSD 商业生态最系统的官方汇总，覆盖存储、流媒体、即时通讯、网络设备、防火墙、虚拟化等多个产业领域，是 BSD 商业生态总论的核心一手史料。
- **与官方史料的交叉验证结论**：此为 FreeBSD Foundation 官方一手史料。证言中各公司高管姓名与职务可与 LinkedIn 等职业社交网络交叉验证。Jan Koum 为 WhatsApp 联合创始人兼 CEO 的身份与公开工商记录一致。
