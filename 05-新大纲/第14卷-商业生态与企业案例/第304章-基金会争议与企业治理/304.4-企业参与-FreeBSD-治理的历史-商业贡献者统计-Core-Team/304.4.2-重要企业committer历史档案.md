# 304.4.2 重要企业 committer 历史档案

**要点**：基于 133.12.7 节核验的 freebsd.duckdb 查询结论，**freebsd-src** 仓库中企业 committer 的 commit 分布为：**iXsystems** 530 commit（最高，反映 iXsystems 作为 FreeBSD 下游 TrueNAS 开发商的长期投入）、**Netflix** 64 commit（集中在 **kTLS**/`sendfile` 优化，由 **Jonathan Looney**、**Drew Gallatin** 推送）、**Juniper** 28 commit（集中在 **Broadcom** **ARM64** SoC 支持）、**NetApp** 11 commit（**ONTAP** 相关改进）、**Apple** 6 commit（**Darwin** 回馈极少，印证 144.1 节“Apple 的无薪员工”批评）；合计 642 commit，企业 commit 占比 0.1445%（基于 9 个邮箱域名）；按时间分布，L3.2.1 报告显示 2005 年 153 commit、2015 年 3,391 commit、2020 年 3,820 commit，企业 commit 量随时间增长但总占比仍低于 1.3%。

**史料**：freebsd.duckdb 查询（`script/query_ch133_enterprise_commits.py`，查询时间 2026-07-23，已在 133.12.7 节核验）；L3.2.1 查询报告；**FreeBSD** git 仓库 commit 记录中 `@ixsystems.com`、`@netflix.com`、`@juniper.net`、`@netapp.com`、`@apple.com` 邮箱统计 ［A］

**史观**：总纲第 11 条——商品是形式主义，企业 commit 的分布反映商业资源向特定技术方向的倾斜（**Netflix** 倾向 CDN 优化、**Juniper** 倾向网络硬件支持、**iXsystems** 倾向存储与虚拟化）；总纲第 9 条——经验优先，优先呈现 commit 统计这一质朴事实而非套用理论框架
