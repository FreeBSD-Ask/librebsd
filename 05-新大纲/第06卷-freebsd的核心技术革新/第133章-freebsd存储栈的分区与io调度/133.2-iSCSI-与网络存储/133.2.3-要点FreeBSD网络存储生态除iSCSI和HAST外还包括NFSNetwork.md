# 133.2.3 要点FreeBSD网络存储生态除iSCSI和HAST外还包括NFSNetwork

**要点**：FreeBSD 网络存储生态除 iSCSI 和 HAST 外，还包括：NFS（Network File System）作为最古老的分布式文件系统协议在 FreeBSD 中有完整的客户端/服务器实现（NFSv2/v3/v4，详见 085.4.4 节）；**ggate(8)**（GEOM Gate）允许用户态程序通过网络导出块设备，是 HAST 和其他用户态 GEOM 模块的基础；**nfsv4(4)** 新客户端/服务器在 FreeBSD 9.0 引入（实验性 NFSv4 更早）后持续改进，支持 pNFS 部分特性；SMB/CIFS 客户端和服务器通过 ports 中的 samba 提供，内核态 **smbfs(5)** 支持 SMB 挂载；FreeBSD 还支持 AFS、Ceph 等分布式文件系统通过 FUSE 或 ports 提供

**史料**：**ggate(4)**, **nfs(5)** 手册页；FreeBSD Handbook 网络文件系统章节；FreeBSD 各版本 Release Notes NFS 改进记录；Samba 项目官方文档 ［A］

**史观**：总纲第 13 条——法律与道德是利益分配：FreeBSD 网络存储生态的特点是 “提供核心机制，具体方案由用户选择”——内核只提供 GEOM、NFS、iSCSI、ggate 等基础机制，不强制用户使用特定的高可用或分布式存储方案，与 ZFS 这样的 “一体化” 方案形成互补

**辨析**：FreeBSD 基本系统不包含 Ceph、Gluster 等分布式存储，这些都通过 ports/pkg 提供；这与 Linux 发行版将客户端/服务器全部打包入默认安装不同，体现了 FreeBSD “基本系统最小化、附加软件通过 ports” 的设计哲学；**ggate(8)** 是一个常被忽视但技术上很优雅的设计——它允许用户态进程实现 GEOM provider，这使得 HAST 等网络块设备可以在用户态处理网络协议而不需要全部在内核实现

**文献**：FreeBSD Project. **ggate(4)**, **ggated(8)** Manual Pages; FreeBSD Project. *FreeBSD Handbook - Network Filesystems*. docs.freebsd.org. ［B］
