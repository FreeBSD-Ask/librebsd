# 138.6.2 里程碑事件类

### 新闻条目 1

- **新闻标题（中英）**：FreeBSD 10.0 终于发布了（FreeBSD 10.0 Has Finally Been Released）
- **新闻来源**：Phoronix + Michael Larabel + 2014-01-20 + <https://www.phoronix.com/news/MTU3NzM> + <https://web.archive.org/web/2014/https://www.phoronix.com/news/MTU3NzM>
- **新闻摘要**：2014 年 1 月 20 日 FreeBSD 10.0-RELEASE 正式发布，是 10.x 系列的首个稳定版本，也是 FreeBSD 历史上最具里程碑意义的版本之一。10.0 的关键新特性包括：Clang 替代 GCC 成为默认编译器、bhyve 原生虚拟化、Radeon KMS 图形驱动、ZFS 改进、ARM Raspberry Pi 支持、Hyper-V 虚拟化集成。Phoronix 报道强调“Finally”（终于），反映了 10.0 经历多次 RC 延迟后的发布。
- **与本章主题的关联说明**：本章记述 FreeBSD 10.x 大整合时代的开端，10.0-RELEASE 是 Clang 迁移、bhyve 虚拟化、KMS 图形驱动等多项技术整合的里程碑。
- **与官方史料的交叉验证结论**：FreeBSD 10.0-RELEASE 发行说明（2014-01-20）与 Phoronix 报道交叉验证，新特性列表与发布日期一致。

- **新闻来源**：Phoronix + Michael Larabel + 2014-01-05 + <https://www.phoronix.com/news/MTU2MDQ> + <https://web.archive.org/web/2014/https://www.phoronix.com/news/MTU2MDQ>

- **与本章主题的关联说明**：本章记述 FreeBSD 10.x 大整合的技术广度，Phoronix“10 大特性”是 10.x 整合范围的代表性总结。
- **与官方史料的交叉验证结论**：FreeBSD 10.0-RELEASE 发行说明与 Phoronix 报道交叉验证，特性列表一致。
