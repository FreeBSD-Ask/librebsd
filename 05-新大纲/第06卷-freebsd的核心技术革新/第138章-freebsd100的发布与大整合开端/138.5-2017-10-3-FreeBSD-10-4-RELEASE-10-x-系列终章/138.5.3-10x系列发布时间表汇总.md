# 138.5.3 10.x 系列发布时间表汇总

**要点**：FreeBSD 10.x 系列五个 RELEASE 版本精确发布日期与支持周期。Release Engineering Team 主要变动：10.0 时期 Release Engineering Lead 为 Ken Smith（kensmith@），10.1 起 Lead 交棒给 Glen Barber（格伦·巴伯）（gjb@），Glen Barber 担任 10.1-10.4 四个版本的 RE Lead；Security Officer 在 10.0 时期为 Dag-Erling Smørgrav（des@），Colin Percival（cperciva@）时已转任 Security Officer Emeritus 荣誉身份但仍参与安全咨询，Xin Li（delphij@）在 10.1 起加入 Security Team。

  **FreeBSD 10.x 系列 RELEASE 版本发布日期与支持周期表**：

  | 版本 | 公告日期 | 支持截止日期 | 标注 |
  | --- | --- | --- | --- |
  | 10.0-RELEASE | 2014-01-20 | 2015-02（10.1 发布后一个月） | —— |
  | 10.1-RELEASE | 2014-11-14 | 2017-01-01 | 作为 old stable 分支延长支持 |
  | 10.2-RELEASE | 2015-08-13 | 2016-12-31 | —— |
  | 10.3-RELEASE | 2016-04-04 | 2018-04-01 | —— |
  | 10.4-RELEASE | 2017-10-03 | 2018-10-31 | stable/10 EOL |

**史料**：FreeBSD 10.0-10.4 各版本 Announcement（发布日期、支持截止日期、Release Team 名单）、FreeBSD Security Officer 页面历史。［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档〕

**史观**：总纲第 8 条——本体论上各方平等：Release Engineering Lead 从 Ken Smith 到 Glen Barber 的交棒是 FreeBSD 项目治理代际传承的典型案例，前任与继任者作为平等参与者通过实践协作完成角色更替。Ken Smith 是 2000 年代 FreeBSD 发布工程的核心人物，Glen Barber 从 10.0 Release Engineer 做起最终接任 Lead，这种 “在实践中培养接班人” 的模式保证了项目连续性。

**辨析**：10.1 支持周期标注为至 2017.1.1（超过 2 年），长于常规 RELEASE 支持周期——这是因为 10.1 被选为 “extended support” 稳定版本供长期部署用户使用，类似 Linux 发行版的 LTS 点版本概念。Colin Percival 作为 Security Officer Emeritus 仍在 10.x 时期参与安全工作但日常 Security Officer 职责由 Dag-Erling Smørgrav 与 Xin Li 承担。
