# 138.2.1 发布与主要特性概览

**要点**：FreeBSD 10.1-RELEASE 于 2014 年 11 月 14 日发布，是 stable/10 分支的第二个版本，Release Engineering Lead 从 Ken Smith 交棒给 Glen Barber（格伦·巴伯）（gjb@），10.1 的 Release Engineer 即为 Glen Barber 本人。此版本新增支持 armv6 架构（10.0 仅支持 amd64/i386/ia64/powerpc/powerpc64/sparc64）。主要亮点特性：**vt(4)** 新控制台驱动（Newcons）从 -CURRENT 合并；**bhyve(4)** 新增 i386 客户机支持与 ZFS 引导支持；amd64 加入初始 UEFI 引导支持（由 FreeBSD Foundation 赞助开发）；**autofs(5)** 自动挂载工具加入；**geli(8)** 支持启动时缓存密码短语；UDP-Lite（RFC 3828）支持加入 IPv4/IPv6 协议栈；OpenSSH 更新至 6.6p1，默认生成 ED25519 主机密钥；Unbound 更新至 1.4.22；**pkg(8)** 更新至 1.3.8；支持生命周期至 2017 年 1 月 1 日。10.1 首次提供 UEFI 可引导镜像（amd64）以及 QCOW2/VHD/VMDK 格式的预构建虚拟机镜像，并提供 Amazon EC2 与 Microsoft Azure 官方云镜像〔存疑：原稿称“首次登陆”，10.1 公告仅列镜像链接，EC2 官方镜像早于 10.1，Azure 首发与否另考〕。

**史料**：FreeBSD 10.1-RELEASE Announcement（2014-11-14，明确发布日期、Release Team 名单中 Glen Barber 已成为 Lead、Xin Li（delphij@）与 Dag-Erling Smørgrav（des@）为 Security Officer、支持截止日期 2017-01-01、新增 UEFI 镜像与云镜像）、FreeBSD 10.1-RELEASE Release Notes（Kernel Changes 中 r262861 vt(4) 导入、r271135 UEFI 引导支持、r267399 bhyve i386 客户机支持）。［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档〕

**史观**：总纲第 13 条——法律与道德是利益分配〔存疑：原挂“第 22 条——开源运动”系伪标签，权威表第 22 条为“知识注定过时”，按云时代商业利益合作语义暂挂第 13 条〕：10.1 提供官方云镜像（EC2、Azure）标志着 FreeBSD 从“传统服务器/桌面 OS”向“云时代基础设施 OS”的转型开端。Microsoft 在 10.x 时期与 FreeBSD 项目密切合作开发 Hyper-V 集成驱动，这是 Microsoft 对开源态度转变在 FreeBSD 生态中的早期体现。

**辨析**：原文件与部分资料称“**vt(4)** 在 10.1 默认启用替换 syscons”——经 Release Notes 核实，10.1 中 **vt(4)** 已合并但需通过 `kern.vty=vt` loader 变量手动启用，**syscons(4)** 仍为默认控制台；**vt(4)** 成为默认发生在更晚版本（FreeBSD 11.0）。UEFI 引导在 10.1 标注为“initial support”（初始支持），功能不完备，仅提供独立的 UEFI 镜像文件，自动安装不支持 UEFI 上的 Root-on-ZFS（至 10.3 才支持）。
