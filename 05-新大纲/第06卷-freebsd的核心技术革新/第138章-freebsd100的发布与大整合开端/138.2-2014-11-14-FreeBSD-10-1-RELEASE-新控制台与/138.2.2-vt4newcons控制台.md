# 138.2.2 **vt(4)** Newcons 控制台

**要点**：**vt(4)**（又称 Newcons）是 FreeBSD 新一代虚拟控制台驱动，旨在替换自 BSD 时代沿用的 **syscons(4)**。**vt(4)** 项目起源于 2000 年代后期，主要开发者包括 Ed Schouten（ed@）、Ed Maste（埃德·马斯特）（emaste@）、Aleksandr Rybalko（ray@）等人（据 **vt(4)** 手册页 AUTHORS 段），FreeBSD Foundation 赞助了部分开发工作（r271128 性能合并标注“Sponsored by The FreeBSD Foundation”），手册页由 Warren Block（wblock@）撰写；**vt(4)** 首次出现于 FreeBSD 9.3（据 HISTORY 段），后合并入 stable/10。**vt(4)** 在 10.1 合并入 stable/10（r262861），核心特性：支持 KMS（Kernel Mode Setting）驱动，可与 **drm2(4)** Radeon/Intel GPU 驱动配合实现高分辨率控制台；支持 Unicode/UTF-8 终端；更好的多显示器支持；与 Xorg 图形系统更平滑的切换。在 10.1 中启用 **vt(4)** 需在 **loader.conf(5)** 中设置 `kern.vty=vt` 或在 loader 提示符下输入；powerpc64 GENERIC64 内核已默认启用 **vt(4)** 用于 Sony PlayStation 3 支持（r271111）。使用 ATI Radeon 显卡配合 **vt(4)** 需要 x11-servers/xorg-server 1.12.4_8 或更新版本。

**史料**：FreeBSD 10.1-RELEASE Release Notes（Kernel Changes vt(4) 章节、Boot Loader Changes 章节）、vt(4) 手册页、Ed Schouten 历年 Newcons 设计文档与邮件列表公告、svn commit r262861（vt(4) merge from -CURRENT）、r271128（vt(4) performance enhancements，Sponsored by FreeBSD Foundation）。 ［A］

**史观**：专题语（不设总纲条号；原挂“第 17 条——软件工程”系伪标签，权威表第 17 条为“证明世界先于解释和改造世界”）：**syscons(4)** 作为 1980 年代设计的控制台驱动，无法支持现代显卡的 KMS 模式切换与高分辨率显示，**vt(4)** 替换是 FreeBSD 桌面与图形支持现代化的必要基础工程。这一替换历时近十年（从项目启动到默认启用），体现了 BSD 项目在核心基础设施替换上的极度审慎。

**辨析**：Newcons 项目名称常被误写为“newcons”或“NewCons”——正式驱动名为 **vt(4)**，“Newcons”是开发期间的项目代号；部分资料称 **vt(4)** 支持 Intel KMS 驱动——10.1 中 drm/i915 驱动已加入硬件上下文支持（r271816）可配合 Mesa 9.2+，但 **vt(4)** 与 Intel KMS 的集成稳定性在 10.x 时期不如 Radeon，至 11/12 才成熟。
