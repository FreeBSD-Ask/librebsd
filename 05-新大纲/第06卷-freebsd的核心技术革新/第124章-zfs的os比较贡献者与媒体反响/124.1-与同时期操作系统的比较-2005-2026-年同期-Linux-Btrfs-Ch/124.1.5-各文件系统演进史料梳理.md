# 124.1.5 各文件系统演进史料梳理

**要点**：各文件系统关键史实汇总与交叉验证见下表，覆盖 ZFS、Btrfs、ext4、XFS、HAMMER/HAMMER2、ReFS、APFS 共 8 个 2005-2026 年间主流文件系统的启动时间、主要里程碑与当前状态。

| 文件系统 | 启动/首发 | 主要里程碑 | 当前状态 |
| --- | --- | --- | --- |
| ZFS | 2001 年（Bonwick/Ahrens，Sun） | 2005 年 11 月开源至 OpenSolaris；2007 年 Pawel Dawidek 移植到 FreeBSD；2010 年 Oracle 收购 Sun 后社区 fork 至 illumos；2013 年 OpenZFS 正式成立；2020 年 OpenZFS 2.0 统一代码库 | 跨平台统一（FreeBSD/Linux/macOS） |
| Btrfs | 2007 年（Chris Mason，Oracle） | 2009 年 Linux 2.6.29 合入主线；2019 年 Red Hat 从 RHEL 8 移除 | Linux 主线（openSUSE 默认） |
| ext4 | 2008 年稳定（Theodore Ts'o） | 2008 年 Linux 2.6.28 稳定 | 多数 Linux 发行版默认 |
| XFS | 1994 年（SGI IRIX 首发） | 2001 年 Linux 移植；Red Hat 主导维护 | RHEL 7+ 默认 |
| HAMMER | 2008 年（Matthew Dillon） | DragonFly BSD 2.0 引入 | DragonFly BSD |
| HAMMER2 | 2018 年默认（Matthew Dillon 完全重写） | DragonFly BSD 5.2 默认 | DragonFly BSD 默认 |
| ReFS | 2012 年（Microsoft） | Windows Server 2012 首发 | Windows Server |
| APFS | 2017 年（Apple） | macOS 10.13 默认（SSD） | macOS/iOS 默认 |

**史料**：各操作系统 Release Notes；各文件系统官方文档；USENIX/FAST 论文 ［D］

**史观**：形式主义膨胀：文件系统发展史的形式化记录（版本号、发布日期、commit hash）是历史书写的基础，没有精确的时间锚点，技术叙事就会退化为模糊的技术传奇

**辨析**：需注意各文件系统“稳定”的定义差异——ext4 在 2008 年即被标记为 stable 并被发行版大量采用；Btrfs 虽合入主线但 RAID 5/6 长期不稳定；ZFS 在 Solaris 中 2006 年即被视为 production ready，在 FreeBSD 中 7.0 标记为 experimental、8.0 production ready；HAMMER 在 DragonFly 2.4（2009 年）后才稳定

**文献**：USENIX Conference on File and Storage Technologies (FAST) Proceedings [C/OL]. 获取路径：<https://www.usenix.org/conferences/byname/925> [访问日期 2026-07-30]; 各文件系统项目官方文档。［D］
