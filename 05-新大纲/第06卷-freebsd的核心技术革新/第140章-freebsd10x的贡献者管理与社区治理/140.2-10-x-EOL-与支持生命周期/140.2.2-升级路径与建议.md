# 140.2.2 升级路径与建议

**要点**：10.x 用户升级路径：**freebsd-update(8)** 二进制升级支持从 10.x 到 11.x 升级，再升级到 12.x（跨大版本直接升级可能不支持，需逐大版本升级）。ZFS Boot Environment（BE）支持使升级风险可控——升级前创建 BE，失败可回滚。10.x 时期 freebsd-update 已成熟但仍建议在升级前阅读目标版本 Errata 与 Release Notes。对于使用 ports 编译软件的用户，大版本升级后建议重新安装所有 ports 包以确保 ABI 兼容性（pkg bootstrap + pkg upgrade 可处理二进制包）。

**史料**：FreeBSD Handbook 升级章节、freebsd-update(8) 手册页、11.x/12.x Release Notes 升级说明。 ［A］

**史观**：总纲第 9 条——经验优先：**freebsd-update(8)** 由 Colin Percival 开发（原挂“总纲第 17 条——软件工程”，基线第 17 条为“证明世界先于解释和改造世界”，按权威表改挂——批次 C164 问题 2），是 FreeBSD 相比其他 BSD 发行版（OpenBSD/NetBSD 长期缺乏官方二进制升级工具）在工程成熟度上的重要优势。ZFS Boot Environment 集成（**bectl(8)** 在 12.x 引入，但 beadm 在 10.x 已可用）进一步降低了升级风险。

**辨析**：跨大版本直接升级（如 10.4→12.0）在 freebsd-update 中可能不被支持或风险较高，建议逐版本升级；大版本间 ABI 可能变化（如 10→11 某些 syscall 号变化），因此 ports 软件通常需要重新编译或更新二进制包。

**文献**：FreeBSD Handbook. Updating FreeBSD [Z].；Colin Percival. freebsd-update: Binary Updates for FreeBSD [C]//BSDCan 2005.
