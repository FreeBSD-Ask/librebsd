# 140.3.3 sendmail 与 DMA 的地位

**要点**：FreeBSD 10.x 全系列中 sendmail 仍为默认 MTA（版本更新至 8.14.9），DMA（DragonFly Mail Agent）在 10.x 时期不在 base 中。DMA 来自 DragonFly BSD 项目，由 Matthias Schmidt 开发，是一款轻量级 MTA 专为桌面/客户端系统设计。DMA 成为 FreeBSD 默认 MTA 发生在 FreeBSD 14.0（2023 年 11 月 20 日）。详细分析见 59.7.3〔待核实节号〕 节。

**史料**：详见 59.7.3〔待核实节号〕 节史料与文献［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔内部交叉引用·无独立来源〕

**史观**：技术债务：sendmail 是 1980 年代的 MTA，配置文件语法复杂、安全性历史上问题较多，从讨论替换到实际替换历时近十年

**辨析**：原文件称 “10.0 默认 MTA 为 dma”——经官方 Announcement 三源交叉核实，此说法为关键事实错误，dma 在 10.x 全系列中不在 base 中
