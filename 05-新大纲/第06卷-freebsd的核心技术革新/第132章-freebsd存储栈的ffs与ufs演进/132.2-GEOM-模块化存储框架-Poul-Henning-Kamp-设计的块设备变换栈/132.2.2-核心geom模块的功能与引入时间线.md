# 132.2.2 核心 GEOM 模块的功能与引入时间线

**要点**：GEOM 标准模块可分为几类：RAID 类包括 **gmirror(8)**（RAID1 镜像，FreeBSD 5.x 引入）、**gstripe(8)**（RAID0 条带）、**graid3(8)**（RAID3 专用奇偶校验）、**gconcat(8)**（JBOD 磁盘串联）、**graid(8)**（BIOS/固件软 RAID 支持）；加密类包括 **gbde(8)**（phk 设计的 GBDE，FreeBSD 5.0 引入，四道加密屏障）、**geli(8)**（Pawel Dawidek 设计，FreeBSD 6.0 引入，支持 HMAC 认证加密，推荐使用）、**gshsec(8)**（共享密钥加密）；分区与标签类包括 **gpart(8)**（GPT/MBR/APM/VTOC8/BSD disklabel 分区，FreeBSD 7.x 引入，替代老的 fdisk/bsdlabel）、**glabel(8)**（文件系统标签与 UFS ID 标签）；工具与调试类包括 **gnop(8)**（透明透传，用于调试和测试）、**gzero(8)**（零设备，写丢弃读返回零）、**geom_nop(4)** 等；虚拟设备类包括 **md(4)**/**mdconfig(8)**（内存盘与 vnode 盘，FreeBSD 5.0 前已存在但通过 GEOM 重构）、**ggate(8)**（用户态 GEOM 网关，允许用户态程序导出块设备）、**geom_virstor(8)**（虚拟大小超限，即精简置备）、**geom_mountver(8)**（挂载验证，防止脏设备挂载）、**geom_multipath(8)**（多路径 I/O）

**史观**：开源运动：GEOM 模块生态是开源协作的典型——phk 提供了框架，核心模块由不同开发者贡献：Pawel Dawidek 写了 geli 和 ggate，Lukas Ertl 写了 gvinum，其他开发者贡献了各自需要的模块；但这种分散贡献也导致了文档不完整、部分模块维护不足的问题——graid3、gshsec、geom_virstor 等模块实际生产使用较少

**辨析**：需纠正一个常见误解：“gvinum 是 GEOM 模块”——**geom_vinum(4)** 确实是 GEOM 封装，但 Vinum 卷管理器本身是 Greg Lehey 在 FreeBSD 3.x 时代（1998-1999 年）设计的，早于 GEOM，GEOM 化是后续封装（数据库验证 gvinum 用户态工具首次合入时间为 2004-06-12，由 Lukas Ertl 提交，处于 FreeBSD 5.x 时代，比 Vinum 本身晚约 5-6 年）；**ccd(4)**（Concatenated Disk Driver）是 FreeBSD 2.x 时代的 RAID0 实现，早于 GEOM，现在通过 **geom_ccd(4)** 封装但已不推荐使用；geom_raid5 曾存在但从未正式进入 FreeBSD 主线，因为 ZFS 的 RAID-Z 提供了更优方案；**gjournal(8)**（GEOM 日志，FreeBSD 7.0 引入）是块级日志，与 SUJ 的文件系统级日志不同
