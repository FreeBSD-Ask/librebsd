# 126.0.7 核心要点

Yutaro Hayakawa 提出面向 FreeBSD 的 eBPF 实现，其中 eBPF 可被用作动态追踪的后端，功能类似 DTrace（Yutaro Hayakawa, 2018）。

Mateusz Piotrowski 基准测试比较了 DTrace（FreeBSD）与 eBPF（Linux）的性能开销，指出二者服务于同一可观测性生态位，为跨系统追踪工具的性能特征提供了数据点（Mateusz Piotrowski, 2024）。
