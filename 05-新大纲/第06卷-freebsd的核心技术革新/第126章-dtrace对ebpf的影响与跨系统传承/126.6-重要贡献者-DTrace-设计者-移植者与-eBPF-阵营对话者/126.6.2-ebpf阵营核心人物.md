# 126.6.2 eBPF 阵营核心人物

**要点**：eBPF 生态的核心贡献者：(1) Alexei Starovoitov——eBPF 设计者，俄罗斯/美国工程师，最初在 PLUMgrid 工作，将经典 BPF 扩展为通用内核虚拟机，2014 年 eBPF 补丁合入 Linux 主线；(2) Daniel Borkmann——eBPF 核心共同维护者，Cilium/Isovalent 公司（后被 Cisco 收购），与 Starovoitov 合作扩展 eBPF 到网络和追踪领域；(3) Brendan Gregg——从 DTrace 阵营转向 eBPF 开发，创作 BCC 工具集多个工具、bpftrace 贡献者，著《BPF Performance Tools》；(4) Alastair Robertson——bpftrace 创建者；(5) Thomas Graf 等 Cilium 团队成员——推动 eBPF 在网络和云原生领域的应用

**史料**：Linux 内核源码 MAINTAINERS 文件（eBPF 维护者记录）；Starovoitov 和 Borkmann 的 LKML 补丁提交历史；Gregg《BPF Performance Tools》致谢章节；Cilium 项目文档（cilium.io）；bpftrace GitHub 贡献者记录 ［A］

**史观**：总纲第 10 条——动手者创造历史：eBPF 的成功同样是多人协作的成果——Starovoitov 提供核心虚拟机设计，Borkmann 提供网络和验证器改进，Gregg 提供工具和用户体验，Cilium 团队提供云原生场景落地

**辨析**：Alexei Starovoitov 的 eBPF 工作最初是为了改进 Linux 网络包过滤性能（classic BPF 已用于 tcpdump/libpcap），追踪功能是后续扩展的方向——eBPF 不是为了“做 Linux 版 DTrace”而设计的，尽管它最终在追踪领域被定位为 DTrace 的对应物；Starovoitov 后来加入 Meta（Facebook），继续从事 eBPF 和内核开发
