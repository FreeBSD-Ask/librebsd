# 126.3.4 可观测性竞争史料梳理

**要点**：DTrace 与 eBPF 竞争时期的一手史料包括：Brendan Gregg 博客的持续记录（2014-2025 年）；Linux 内核邮件列表中 eBPF 相关的补丁和讨论；FreeBSD 邮件列表中 DTrace 维护和改进的讨论；各类会议（USENIX LISA、BSDCan、eBPF Summit）的演讲视频和论文；DTrace 和 eBPF 相关书籍（Gregg/Mauro 2011、Gregg 2019）

**史料**：Brendan Gregg brendangregg.com 博客完整存档；USENIX、BSDCan、eBPF Summit 等会议论文集和视频存档；LKML 和 FreeBSD 邮件列表存档；相关书籍 ［A］

**史观**：总纲第 3 条——形式主义膨胀：技术竞争的历史书写往往由胜出者主导——eBPF 作为当前（2026 年）的技术热点，其叙事框架容易将 DTrace 简化为“先驱”或“被取代者”；但 DTrace 在 BSD/macOS/illumos 生态中仍在活跃使用和维护，并未“死亡”

**辨析**：Oracle 在 2010 年代后期向 eBPF 靠拢（Oracle Linux 同时支持 DTrace 和 eBPF）确实在工程话语权上标志着 DTrace 不再是 Oracle 的可观测性战略重心，但 Oracle 同时继续维护 Solaris DTrace 和 Oracle Linux DTrace；Cantrill 离开 Oracle 后（2010 年加入 Joyent，2019 年联合创立 Oxide Computer）继续在公开场合讨论 DTrace 及其对行业的影响，但他的工作重心转向云计算硬件（Oxide Computer 做云服务器）

**文献**：Gregg, B. brendangregg.com; Cantrill, B. dtrace.org/blogs/bmc/ (post-Oracle posts); eBPF Summit proceedings (2020-2025); USENIX LISA proceedings ［B］
