# 136.2.1 总纲第 13 条审视——法律与道德是利益分配

**要点**：总纲第 13 条断言 “法律与道德是利益分配。任何道德问题本质上是利益问题，社区治理亦是形式主义的政治产物”。以此审视 BSD patch 替代 GNU patch 争议，可见双方道德话语（FSF 的 “保护自由” 与 BSD 阵营的 “真正的自由”）实质是不同利益群体的政治表达。FSF 的 copyleft 保护用户免于工具被专有锁定（用户利益），BSD 宽容许可保护商业开发者任意处置代码与免受 GPLv3 法律义务约束（开发者与商业参与者利益），两者均非道德绝对而系利益取向。**patch(1)** 作为基础工具，其许可证争议的结构与 GCC→Clang 迁移（详见第063章 58.4.7）同构——选择性地将 “避免 GPLv3 法律风险” 工程化，却接受同样含专利报复条款的 Apache 2.0（LLVM 现用许可证），这一选择性揭示 “纯洁化” 话语并非中立的工程评估，而是特定利益群体（免受 GPLv3 约束的商业参与者）风险偏好的形式主义包装。但 BSD patch 争议的特殊性在于：**patch(1)** 是小工具，其许可证纯洁化的工程收益极小（不像 GCC→Clang 有 C++11 支持的工程必要性），故利益分配的底色更清晰——BSD patch 替换几乎纯系许可证驱动，工程必要性遮蔽论在此更为有力。道德话语的层叠遮蔽了利益分配的底层结构，史家的任务不是裁决哪方 “更道德”，而是还原道德话语背后的利益地理。

**史观**：总纲第 13 条——法律与道德是利益分配：许可证争议的法律文本（GPLv3 §5/§6/§11）与道德话语（“自由” “纯洁”）均为利益分配的形式主义工具。BSD patch 替换中，“接受” BSD 许可版本与 “驱逐” GPLv3 增强版本的边界划定本身反映 FreeBSD 商业生态的利益取舍——BSD 许可不威胁专利组合与商业分发自由，GPLv3 §11 威胁专利组合，故 “反 GPLv3” 非 “意识形态反 copyleft” 而是 “利益反专利风险与商业义务”。
