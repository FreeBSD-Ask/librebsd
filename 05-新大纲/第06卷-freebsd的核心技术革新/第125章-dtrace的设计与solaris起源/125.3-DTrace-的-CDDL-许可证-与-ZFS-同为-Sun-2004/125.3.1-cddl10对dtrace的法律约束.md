# 125.3.1 CDDL 1.0 对 DTrace 的法律约束

**要点**：DTrace 源码由 Sun Microsystems 于 2005 年随 OpenSolaris 以 CDDL 1.0 许可证发布；CDDL 1.0 基于 MPL 1.1，采用文件级 copyleft——所有源自 OpenSolaris 的 DTrace 源文件必须保持 CDDL 许可，但 CDDL 文件可与 BSD 许可证文件聚合分发；CDDL §3.1 授予"perpetual, worldwide, non-exclusive, no-charge, royalty-free, irrevocable"版权与专利许可；§3.2 分发义务——CDDL 覆盖文件的修改版也必须以 CDDL 发布；§3.5 明确允许与其他许可证的代码聚合分发；CDDL 对 DTrace 的约束与对 ZFS 的约束完全相同（CDDL 条款本身统一）

**史料**：CDDL 1.0 官方文本（opensource.org/licenses/CDDL-1.0）；OSI 2005 年 1 月 CDDL 审批公告；FreeBSD src/sys/cddl/ 目录结构（CDDL contrib 代码与 BSD compat 代码分离）；Oracle 2017 年 8 月 GPLv2+ 重新许可公告（Mark J. Wielaard 博客 2018-02-14） ［A］

**史观**：许可证：CDDL 文件级 copyleft 的法律结构决定了 DTrace 的跨平台流动边界：FreeBSD/macOS/NetBSD/Windows 可合法包含 DTrace（因 CDDL 与 BSD/类 BSD 许可证兼容），Linux 则因 CDDL 与 GPLv2 作品级 copyleft 冲突，无法将 DTrace 直接合入主线内核（Oracle Linux DTrace 采用内核模块方式分发）

**辨析**：CDDL 对 DTrace 的约束与 ZFS 完全相同——二者均源自 OpenSolaris，使用同一 CDDL 许可证文本；2017 年 8 月 Oracle 将 DTrace 内核代码以 GPLv2+ 许可发布（用户态为 GPLv2+UPL），这一许可变更仅适用于 Oracle 随后发布的 Linux DTrace 代码，OpenSolaris/illumos 分支的 DTrace 代码仍为 CDDL；FreeBSD 中的 DTrace 代码源自 OpenSolaris CDDL 分支，仍保持 CDDL 许可
