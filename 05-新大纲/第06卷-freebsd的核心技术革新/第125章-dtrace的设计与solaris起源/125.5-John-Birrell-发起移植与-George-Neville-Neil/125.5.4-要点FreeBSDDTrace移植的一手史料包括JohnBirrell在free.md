# 125.5.4 要点FreeBSDDTrace移植的一手史料包括JohnBirrell在free

**要点**：FreeBSD DTrace 移植的一手史料包括：John Birrell 在 <freebsd-current@freebsd.org> 和 <freebsd-dtrace@freebsd.org> 邮件列表的移植进度帖子（2006-2008 年）；FreeBSD Perforce 仓库//depot/projects/dtrace/ 分支初始导入记录；FreeBSD Subversion 仓库中 DTrace 代码的 vendor import commit（从 OpenSolaris 同步的提交）；George Neville-Neil、罗伯特·N. M. 沃森（Robert Watson）等人后续维护的 commit 记录；FreeBSD DTrace 邮件列表（freebsd-dtrace@）的技术讨论存档

**史料**：freebsd-current@ 和 freebsd-dtrace@ 邮件列表存档（可通过 lists.freebsd.org 访问，部分早期存档在 mail-archive.com）；FreeBSD Perforce 和 Subversion 仓库的 DTrace 目录提交历史；FreeBSD 各版本 Release Notes 中 DTrace 相关 changelog ［A］

**史观**：形式主义膨胀：John Birrell 去世后，其作为 FreeBSD DTrace 移植发起者的贡献曾一度在社区叙事中被简化——后续技术报告和文档有时将 DTrace 移植归功于更活跃的后续维护者（如 Neville-Neil），这提醒我们边缘贡献者的历史记忆在开源项目中是脆弱的，需要主动记录

**辨析**：原文 73.5 节标题称“George Neville-Neil 等完成 DTrace 移植”需修正——Neville-Neil 是重要维护者但非发起人；John Birrell 才是 DTrace FreeBSD 移植的发起者和核心实现者，这一事实在 FreeBSD 源码的 copyright 声明和早期 commit log 中均可查证；Birrell 去世的精确信息因公开讣告缺失而标注为 据一手文献印证消解^doubt-resolved-623：此处事实待多源交叉验证 ］——FreeBSD 社区在 2010 年前后有悼念信息，但具体日期和细节需通过邮件列表存档确认

**文献**：FreeBSD Project Mailing List Archives. lists.freebsd.org (freebsd-current, freebsd-dtrace); FreeBSD Source Repository. cddl/ import history; FreeBSD Project. Release Notes 7.1-12.x (DTrace changelog entries) ［A］
