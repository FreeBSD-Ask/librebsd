# 130.6.1 bhyve 的主要商业用户场景

**要点**：FreeNAS（后更名为 TrueNAS CORE）是 bhyve 最知名的商业部署场景，由 iXsystems 开发与维护；FreeNAS 是基于 FreeBSD 的开源网络附加存储（NAS）操作系统，从 FreeNAS 9.x 版本开始集成 bhyve 虚拟化功能，允许用户在存储设备上同时运行虚拟机；TrueNAS CORE（FreeNAS 的继承者）继续基于 FreeBSD 与 bhyve 提供 VM 功能；bhyve 在 TrueNAS/FreeNAS 中与 ZFS 深度集成，支持 ZFS 卷作为 VM 磁盘、ZFS 快照作为 VM 检查点、ZFS send/recv 用于 VM 迁移；iXsystems 工程团队对 bhyve 做出了大量功能贡献与 bug 修复，回馈上游 FreeBSD；iXsystems 于 2017 年 2 月在 FreeNAS 中正式引入 VM 功能，bhyve 随 FreeNAS 11.0 官方可用，至 2018 年 3 月已累计报告 244 个 bhyve 相关 bug（其中 VNC 相关 21 个），FreeNAS 累计下载超 1000 万次、活跃用户超 20 万（Araujo, 2018）

**史观**：商业形态分化：bhyve 的商业采用高度集中于存储设备厂商（NetApp 内部使用、iXsystems TrueNAS/FreeNAS），这与 bhyve 起源于 NetApp 的背景直接相关；存储厂商选择 bhyve 而非 KVM 的原因包括：FreeBSD ZFS 集成成熟度、BSD 许可证允许专有产品集成、bhyve 代码简洁易于定制

**辨析**：需纠正原文中关于 TrueNAS 转向 Linux 的叙述——TrueNAS 存在两个并行版本：TrueNAS CORE（基于 FreeBSD + bhyve）与 TrueNAS SCALE（基于 Debian Linux + KVM/QEMU），两个版本并行开发维护，CORE 并未被放弃或 “转向 Linux”；TrueNAS SCALE 从 2020 年开始开发，作为面向超融合基础设施（HCI）的独立版本，并非 CORE 的替代品；iXsystems 对 FreeBSD 与 bhyve 的工程投入确实因 SCALE 开发资源分流而受到影响，但声称 “TrueNAS 放弃 FreeBSD” 是不准确的，需要区分两个版本线；bhyve 并非 TrueNAS/FreeNAS 的唯一虚拟化选项，早期 FreeNAS 也支持通过 Jail 进行 OS-level 虚拟化，bhyve 提供的是 full machine 虚拟化
