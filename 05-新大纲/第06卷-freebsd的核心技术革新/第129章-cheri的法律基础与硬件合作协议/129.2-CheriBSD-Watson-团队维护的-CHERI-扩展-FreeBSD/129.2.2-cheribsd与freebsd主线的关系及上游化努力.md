# 129.2.2 CheriBSD 与 FreeBSD 主线的关系及上游化努力

**要点**：CheriBSD 是 FreeBSD 的一个 fork（分支）而非 FreeBSD 基本系统的一部分——截至 2025 年，FreeBSD 主线（main 分支）不包含 CHERI 硬件支持；CheriBSD 与 FreeBSD 主线保持定期同步（通常基于 FreeBSD -CURRENT 或 -STABLE 分支进行开发），CheriBSD 团队持续将与 CHERI 无关的通用改进向上游 FreeBSD 提交；CheriBSD 维护者（包括 Brooks Davis、Edward Tomasz Napierala、John Baldwin（约翰·鲍德温）、Jessica Clarke 等 FreeBSD committers）本身就是 FreeBSD 社区的活跃贡献者，许多 CheriBSD 中的通用改进（如 RISC-V 架构支持完善、链接器改进、bhyve 增强等）已进入 FreeBSD 主线；但 CHERI 硬件支持本身（能力感知的内核、CheriABI 等）因需要相应硬件才能测试且涉及大量 ABI 变更，短期内不太可能合入 FreeBSD 主线

**史观**：边缘者贡献：CheriBSD 作为 FreeBSD 研究分支的模式类似于 BSD 历史上的诸多研究分支（如 BSD/OS、BSD/386 是商业化分支）——研究分支承担高风险新特性的早期探索，成熟后部分成果反馈主线；这一模式与 FreeBSD 本身从 386BSD 分支发展而来的历史形成呼应，体现了 BSD 生态中分支实验与主线稳定的动态平衡

**辨析**：原大纲称“CHERI FreeBSD 移植——Watson 团队维护的 CHERI FreeBSD 分支，作为研究原型长期运行”——“移植”表述不完全准确，CheriBSD 不是简单的“移植”，而是在 FreeBSD 基础上添加深度 CHERI 支持（内核、用户态、ABI、工具链）的扩展分支；CheriBSD 也不仅仅是“研究原型”——截至 2025 年，CheriBSD 已能运行完整 KDE 桌面环境、支持 bhyve 虚拟化（CHERI 感知的 bhyve，可运行 CHERI-aware guest OS）、提供 10,000+ 预编译 CheriABI 软件包，在 Morello 板上可作为日常使用系统进行研究和开发
