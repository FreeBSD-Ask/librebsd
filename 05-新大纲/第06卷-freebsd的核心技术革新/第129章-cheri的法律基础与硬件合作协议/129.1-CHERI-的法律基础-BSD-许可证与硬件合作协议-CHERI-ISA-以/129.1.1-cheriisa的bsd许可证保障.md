# 129.1.1 CHERI ISA 的 BSD 许可证保障

**要点**：CHERI 指令集架构（ISA）规范由剑桥大学和 SRI International 以 BSD 风格的开放许可证发布，允许学术研究、商业实现和开源项目自由使用 CHERI 架构思想；这一许可策略覆盖 CHERI-MIPS、CHERI-RISC-V、CHERI-AArch64（Morello）的 ISA 规范文档、硬件 RTL 代码（CHERI-Piccolo/CHERI-Flute/CHERI-Toooba 等开源 RISC-V 核心在 GitHub 以 BSD 许可发布）、CheriBSD 操作系统（BSD 许可）；CHERI ISA 开放许可的直接成果包括：Codasip 2023 年发布首个商业 CHERI-RISC-V 处理器 IP 核（X730，2024 年正式发布）、Microsoft CHERIoT 嵌入式 CHERI-RISC-V 方案（2023 年 MICRO 论文）、lowRISC Sonata FPGA 开发板（开源硬件）、Google 作为创始成员加入 CHERI Alliance（2024 年 11 月）

**史料**：CHERI 官方网站 cheri-cpu.org（含 ISA 规范和许可信息）；CTSRD-CHERI GitHub 组织 github.com/CTSRD-CHERI（含 CHERI-RISC-V 开源核心、CheriBSD、工具链）；CHERI Alliance 成立公告（2024-11-13 Electronics Weekly）；Codasip 2023/2024 CHERI RISC-V 公告；Microsoft CHERIoT 2023 MICRO 论文 ［B］

**史观**：总纲第 8 条——本体论上各方平等〔存疑：原挂“第 20 条——基础科学”系伪标签，权威表第 20 条为“历史地理塑造思想土壤”，待主理人审定〕：CHERI ISA 的开放许可策略体现了安全基础设施研究的“公共产品”逻辑——内存安全漏洞是全行业共同面对的危机（Microsoft/Google 均报告 70% 漏洞为内存安全问题），以开放规范发布 CHERI 使所有芯片厂商和操作系统开发者都能参与实现和改进，这与 RISC-V 的开放 ISA 策略精神一致；Arm Morello 原型板的专有硬件与 CHERI ISA 的开放规范之间的张力（参见 52.8.2）正是“开放标准 + 商业实现”模式的典型表现

**辨析**：CHERI 不同组件的许可证状态需区分：(1) CHERI ISA 规范本身——BSD 风格开放许可；(2) CHERI 开源硬件实现（Piccolo/Flute/Toooba 在 GitHub）——BSD 许可；(3) CheriBSD 软件——BSD 许可；(4) ARM Morello SoC 和开发板硬件设计——ARM 专有，需要商业许可或通过 DSbD 计划获取；(5) CHERIoT（Microsoft 主导的嵌入式 CHERI-RISC-V）——开源但部分组件许可条款需查阅具体仓库 ［据 03-15 (2024) 一手文献印证消解 doubt-resolved-641：此处事实待多源交叉验证］
