# 129.3.3 CHERI-RISC-V 标准化进程与开源生态

**要点**：CHERI-RISC-V 是 CHERI 架构向开放 RISC-V 指令集的移植，由剑桥大学和 SRI International 主导开发，是 CHERI 走向完全开放生态的关键路径；CHERI-RISC-V 的 ISA 扩展规范已提交至 RISC-V 国际基金会进行标准化（RISC-V CHERI Ratification Plan），目标是成为 RISC-V 官方认可的能力架构扩展；CHERI-RISC-V 开源硬件实现包括：CHERI-Piccolo（3 级按序核心）、CHERI-Flute（6 级按序核心）、CHERI-Toooba（乱序核心），均以 BSD 许可在 GitHub 发布；商业 IP 方面，Codasip 于 2023 年发布首个商业 CHERI-RISC-V 处理器 IP 核（X730），2024 年 10 月宣布向 CHERI Alliance 捐赠 CHERI RISC-V SDK；lowRISC 主导的 Sonata FPGA 开发板（基于 CHERI-Flute）为开源 CHERI 硬件开发提供了 accessible 平台；Microsoft 主导的 CHERIoT（CHERI for IoT）项目是面向嵌入式微控制器的 CHERI-RISC-V 精简实现，2023 年 MICRO 论文发表完整技术方案

**史观**：总纲第 13 条——法律与道德是利益分配：CHERI-RISC-V 的标准化进程代表了硬件安全架构在开源时代的新路径——与 Intel iAPX 432（1980s 专有商业失败）、ARM Morello（半封闭研究原型）不同，CHERI-RISC-V 试图通过 RISC-V 开放标准生态实现 “开放 ISA 规范 + 开源参考实现 + 商业 IP 支持” 的三重协同；CHERI Alliance 于 2024 年 11 月正式成立（创始成员包括 Google、Microsoft、Arm、Codasip、lowRISC、剑桥大学、SRI International 等），其角色类似于 RISC-V International 之于 RISC-V，但 Alliance 不拥有 CHERI IP，而是协调产业推广
