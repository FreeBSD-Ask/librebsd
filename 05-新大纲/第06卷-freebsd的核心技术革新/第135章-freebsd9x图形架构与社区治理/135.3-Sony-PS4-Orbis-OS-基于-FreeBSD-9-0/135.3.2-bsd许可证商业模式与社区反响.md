# 135.3.2 BSD 许可证商业模式与社区反响

**要点**：FreeBSD 社区对 Sony 使用 FreeBSD 的态度总体积极——项目既未收到 Sony 的大规模代码贡献（除少量驱动补丁外），也未发起任何许可证合规争议；这种 “静默使用” 是 BSD 许可证的典型模式——商业公司可以自由使用而无需回馈，社区也不强求；FreeBSD Foundation 在 2013 年度报告中提及 PS4 作为 FreeBSD 生态影响力的例证，但未将其列为资金赞助商

**史料**：FreeBSD Foundation 2013 Annual Report、freebsd-announce/freebsd-hackers 邮件列表关于 PS4 的讨论、BSD 许可证商业案例分析 ［A］

**史观**：总纲第 22 条——开源运动：PS4 案例揭示了 BSD 模式与 GPL 模式的核心差异——GPL 通过 copyleft 强制回馈（“传染”），BSD 通过自由使用换取生态规模和商业采用；两种模式各有优劣：GPL 保证代码流动但可能吓退商业用户，BSD 吸引商业用户但回馈依赖自愿；PS4 与 Linksys WRT54G（Linux/GPL，强制公开源码后催生 OpenWRT）形成鲜明对照

**辨析**：Nintendo Switch 也使用基于 FreeBSD 的内核（XNU 变体？实际 Switch OS 基于 FreeBSD 网络栈和部分内核组件），但与 PS4 的纯 FreeBSD 基础不同；Microsoft Windows 10+ 在 TCP/IP 栈等组件上也参考了 BSD 代码
