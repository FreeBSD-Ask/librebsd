# 135.2.2 9.x 支持架构与状态

**要点**：9.0-RELEASE 支持架构：amd64、i386、ia64（Itanium）、powerpc、powerpc64、sparc64；9.1-RELEASE 初始仅发布 amd64、i386、powerpc64、sparc64（ia64/powerpc 因构建资源受限后补）；9.2/9.3 恢复支持 amd64、i386、ia64、powerpc、powerpc64、sparc64；FreeBSD/arm 在 9.x 时期持续改进但未列入 RELEASE Tier 1 架构；FreeBSD/mips 在 9.x 时期主要用于嵌入式场景，不发布标准安装镜像

**史料**：各版本 Release Announcement Availability 章节、FreeBSD 架构支持网页［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档〕

**史观**：技术路线分化：ia64（Itanium）在 9.x 之后逐步被放弃（10.x 后取消），armv6/armv7 从嵌入式实验品逐步上升为 10.x/11.x 正式支持架构——这一消长反映了 Itanium 架构商业失败与 ARM 移动/嵌入式崛起的产业格局变化

**辨析**：9.1 架构支持减少直接源于 2012 年入侵事件后包构建基础设施资源紧张，而非架构本身被弃用；Tier 1 vs Tier 2 架构在安全更新、预编译包、release engineering 支持级别上有明确区分
