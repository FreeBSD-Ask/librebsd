# 135.2.1 FreeBSD/powerpc 支持 Sony PlayStation 3

**要点**：9.0-RELEASE 中 FreeBSD/powerpc 支持 Sony PlayStation 3 主机的 OtherOS 功能（固件 3.15 及更早版本）；Nathan Whitehorn 是 PS3 支持的主要开发者，他同时也是 bsdinstall 作者和 powerpc64 release builder；Sony 于 2010-04-01 通过固件更新 3.21 移除 OtherOS 功能（2010-03-28/29 为公告日，2026-08-05 联网复核更正），因此该支持仅对未升级固件的旧款 PS3（“OtherOS 脂肪机”）有意义，PS3 Slim 出厂即无 OtherOS

**史料**：svn r217044（PS3 支持 commit）、FreeBSD 9.0 Release Notes、Nathan Whitehorn freebsd-powerpc 邮件列表公告、Sony PS3 OtherOS 移除诉讼相关报道 ［A］

**史观**：边缘者贡献：PS3 支持是 FreeBSD 支持游戏主机的罕见案例——它与 PS4 Orbis OS（见 79.12）形成有趣对照：前者是 hobbyist 级的非官方支持，后者是 Sony 官方基于 FreeBSD 的产品级派生；Sony 移除 OtherOS 的决定引发了集体诉讼，最终以赔偿和解告终

**辨析**：PS3 OtherOS 支持仅在 3.15 及更早固件有效，绝大多数 PS3 用户因在线游戏和 PSN 需求早已升级固件，因此该支持的实用价值有限，但作为 FreeBSD 支持非传统硬件平台的案例具有历史意义

SCEA，多案合并）→ 2011 部分驳回 → 2014 第九巡回上诉（11-18066，2014-01-06 部分恢复）→ **2017-09 初步批准和解 → 2018-06-08 最终批准**（此前大纲记录“2016 年和解”系简报错误，实际最终批准在 2018）；和解细节：**和解基金 $3,750,000，符合条件用户每人最高 $65，律师费 $1,250,000**；Sony **2010-04-01 固件 3.21 发布移除 OtherOS 功能**（2010-03-28/29 为公告日；此前 2009-04-01 固件 2.50 起支持安装 Linux/FreeBSD）。一手来源：起诉状/合并起诉/驳回令/初步批准令/最终批准令/终局判决（ref 2632-2637/2647） [考据完成：2026-08-05 经 7 份一手原件 + 联网复核核验]
