# 135.4.1 Security Officer 交接

**要点**：FreeBSD Security Officer 在 9.x 时期经历有序交接：9.0-RELEASE 时期 Security Officer 为 Colin Percival（cperciva@），他自 2005 年起担任此职并建立了 FreeBSD 安全响应体系；9.1-RELEASE 时期 Security Officer 为 Simon Nielsen（simon@），Colin Percival 卸任；9.2-RELEASE 时期 Dag-Erling Smørgrav（des@）担任 Security Officer，Simon Nielsen 与 Colin Percival 均转为 Security Officer Emeritus（荣誉安全官）；9.3-RELEASE 时期 Dag-Erling Smørgrav 继续担任 Security Officer，Xin Li（delphij@）加入 Security Team 并列名为 Security Officer。9.x 周期 Security Officer 交接序列汇总见下表。

| 版本 | Security Officer | Emeritus（荣誉安全官） | 备注 |
| --- | --- | --- | --- |
| 9.0 | Colin Percival（cperciva@） | —— | 自 2005 年任职，建立 FreeBSD 安全响应体系 |
| 9.1 | Simon Nielsen（simon@） | Colin Percival | Colin Percival 卸任，转向 Tarsnap 商业项目 |
| 9.2 | Dag-Erling Smørgrav（des@） | Simon Nielsen、Colin Percival | 采用 “Officer + Emeritus” 双轨制保留前任经验 |
| 9.3 | Dag-Erling Smørgrav（des@）+ Xin Li（delphij@） | Simon Nielsen、Colin Percival | delphij 加入 Security Team，与 2012 年入侵事件后团队扩充相关 |

**史料**：各版本 Release Announcement Acknowledgments 章节（明确列出 Security Officer 名单）、FreeBSD Security Team 页面历史［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档〕

**史观**：社区治理：Security Officer 是 FreeBSD 最关键的角色之一，掌握安全公告发布、漏洞协调、基础设施安全等核心权力；Colin Percival 长达 7 年（2005-2012）的任期塑造了 FreeBSD 安全响应的文化与流程，其继任者延续了严格、保守、透明的安全公告风格

**辨析**：Security Officer 交接在 9.x 密集发生（9.0 cperciva→9.1 simon→9.2 des，9.3 新增 delphij），部分源于 Colin Percival 在 Tarsnap 等商业项目上的精力分配，也与 2012 年入侵事件后安全团队扩充有关；从 9.2 开始采用 “Security Officer + Emeritus” 双轨制，保留前任经验；这种有序的权力交接是 FreeBSD 治理成熟的体现
