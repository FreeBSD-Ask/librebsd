# 135.6.3 功能差异与社区测试过程

**要点**：BSD patch 与 GNU patch 的功能差异：BSD patch 缺失 `-I` 与 `-S` 两个选项（pfg 在邮件中说明 "Both options seem to be obsolete and don't seem to be used in ports"），同时 GNU 与 BSD patch 已使用 `-I` 表示忽略空白字符；pfg 在邮件中呼吁 "please test extensively, report bugs, and submit patches. We would love to use the new patch by default in 10.0 but only testing will let us know when it's ready."；特别鸣谢 Christoph Mallon 移植 perforce diff 支持与 Gabor Kovesdan 完成导入；r253689 是真正使 BSD patch 成为默认的 commit

**史料**：pfg 2013.1.29 18:42 邮件原文（功能差异说明、测试呼吁、特别鸣谢）、FreeBSD 10.0 release notes、freebsd-current 邮件列表 2013.1-2014.9 BSD patch 测试反馈线程、PR 99173 评论历史（pfg 2014.9.19 关闭评论 "This was done in r253689 and preceding commits. BSD-licensed patch is shipping since FreeBSD 10."） ［A］

**史观**：总纲第 17 条——软件工程：BSD patch 引入作为可选构建选项而非立即默认，体现 FreeBSD 项目 “工程优先于意识形态” 的实用主义——即便有许可证纯洁化的法律动机，仍须通过社区测试验证功能等价性方可切换默认

**辨析**：`-I` 与 `-S` 选项的 “obsolete” 判断须对照 ports 集合实际使用情况核实——pfg 的判断基于 “don't seem to be used in ports” 的初步调查，但 “seem” 一词表明该判断存在不确定性；r253689 是真正使 BSD patch 成为默认的 commit，经 freebsd.duckdb freebsd-src 仓库 commits 表与 GitHub freebsd/freebsd-src 仓库一手核验，其提交日期为 **2013-07-26T21:25:18Z**（commit hash `21244d522787c25ce4187cbd9b523e266b6ca8c6`，作者 Pedro F. Giffuni，commit_subject “Make the BSD-licensed patch the default.”），diff 内容显示该 commit 将 `MK_BSD_PATCH` 默认值反转——原 `MK_BSD_PATCH=yes` 时 BSD patch 为 `patch`、GNU patch 为 `gnupatch`；新 `MK_GNU_PATCH=yes` 时 GNU patch 为 `patch`、BSD patch 为 `bsdpatch`，即 BSD patch 成为默认 `patch`，GNU patch 退为可选；pfg 2014.9.19 在 PR 99173 关闭评论 "This was done in r253689 and preceding commits. BSD-licensed patch is shipping since FreeBSD 10.“ 印证 r253689 在 FreeBSD 10.0-RELEASE（2014.1.20）发布前半年即完成；”shipping since FreeBSD 10“ 的表述须精确为 ”FreeBSD 10.0"（2014.1.20 发布）而非泛指 “FreeBSD 10.x 系列”
