# 135.9.2 Linux 3.x 系列与 systemd 兴起

**要点**：同期（2012-2014）Linux 发布 3.2-3.19 系列内核，EXT4 文件系统稳定成熟、btrfs 持续开发、systemd 引入引发发行版初始化系统大争议（2012-2014）、RHEL 6.3-6.4/CentOS 6 企业部署、Ubuntu 12.04 LTS/14.04 LTS、Docker 于 2013 年发布开启容器化时代；Windows Server 2012 于 2012 年 10 月发布引入 ReFS 和 Hyper-V 3.0；Solaris 11.1（2012）延续 Oracle Solaris 11 路线；OpenBSD 发布 5.1-5.6（2012-2014）持续安全加固；NetBSD 6.0（2012.10）引入 NPF 防火墙和模块化内核改进

**史料**：Linux 3.x kernel release notes、OpenBSD/NetBSD/DragonFly release announcements、Windows Server 2012 技术文档［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档〕

**史观**：总纲第 6 条——技术路线分化：2012-2014 年是操作系统生态关键分化期——Linux 走向 systemd/cgroups/容器化（“现代” 基础设施），FreeBSD 9.x 仍坚持传统 BSD init 和 jail 改进、但 10.x 将引入 bhyve 虚拟化；systemd 争议导致部分 Linux 用户转向 BSD，是 9.x 时期 FreeBSD 用户增长的因素之一

**辨析**：FreeBSD 9.x 在 “云原生” 浪潮中处于相对边缘位置——Docker 最初只支持 Linux，jail 虽成熟但缺乏 Docker 式生态；FreeBSD 在 10.x 后逐步追赶容器化趋势，但 Linux 在该领域的生态优势已确立
