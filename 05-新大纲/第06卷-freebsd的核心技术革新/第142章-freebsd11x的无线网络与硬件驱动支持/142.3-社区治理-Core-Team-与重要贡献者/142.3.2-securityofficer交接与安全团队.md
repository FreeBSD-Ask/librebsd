# 142.3.2 Security Officer 交接与安全团队

**要点**：FreeBSD Security Team 负责安全漏洞响应、安全公告发布、安全补丁维护。Colin Percival（cperciva@）自 2004 年起担任 Security Officer 长达约十年，是 FreeBSD 安全响应体系的建立者，卸任后保留 Security Officer Emeritus（荣誉安全官）称号。10.x-11.x 早期 Security Officer 为 Dag-Erling Smørgrav（des@）与 Xin Li（delphij@）。11.2-RELEASE（2018.6）Release Team 名单标志着正式交接：Xin Li 转为 Security Officer Emeritus，Gordon Tetlow（戈登·泰特洛）（gordon@）接任 Security Officer，Ed Maste（emaste@）任 Security Officer Deputy。Gordon Tetlow 长期参与 FreeBSD 安全工作与 portmgr 团队工作，其接任保证了安全团队的连续性。Security Team 其他成员包括 Remko Lodder（Security Team Liaison）、Gleb Smirnoff 等。安全团队的职责包括接收安全漏洞报告、评估严重性、协调补丁开发、发布 FreeBSD Security Advisory（SA）与 Errata Notice（EN）。

**史料**：FreeBSD 11.0-11.4 RELEASE Announcements 中 Release Team 名单（Security Officer 职务变化）、FreeBSD Security Team 页面历史、Colin Percival 关于 FreeBSD Security Officer 工作的文章。［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档；L5 二手研究〕

**史观**：社区治理（专题语，不设总纲条号；原挂“总纲第 23 条——社区治理”系伪标签，权威第 23 条为“一切历史写作都是基于哲学设定的历史小说”，依 2026-09-14 核查报告去条号留论旨）：安全团队的平稳交接是 FreeBSD 项目成熟度的体现——安全漏洞响应能力直接关系到操作系统的可信度，交接过程不能出现空档。Security Officer Emeritus 制度使经验丰富的前安全官能够继续以顾问身份参与，Dag-Erling Smørgrav、Xin Li、Colin Percival 等 Emeritus 成员在 11.x 时期仍参与安全问题处理。

**辨析**：Colin Percival 正式卸任 Security Officer 实际发生在 2010 年代初早于 11.x 时期，但他作为 Security Officer Emeritus 持续参与安全工作，11.2 Announcement 仍特别感谢他协助解决 EC2 问题——他的贡献贯穿 11.x 始终。Gordon Tetlow 在 11.2 正式接任 Security Officer 前已参与安全团队工作多年，属于内部晋升而非外部空降。
