# 142.3.1 2014/2016/2018 Core Team 选举

**要点**：FreeBSD Core Team（核心团队）是项目的最高治理机构，由活跃 committer 每两年选举产生。11.x 时期跨越三次 Core Team 选举：①2014 年选举——产生 2014-2016 届 Core Team；②2016 年选举——2016 年 5-6 月举行，产生 2016-2018 届 Core Team；③2018 年选举——2018 年举行，产生 2018-2020 届 Core Team。Core Team 职责包括：committer 权限的授予与撤销、项目方向决策、争端解决、与 FreeBSD Foundation 协调、新 Core Team 选举组织。2016/2018 届 Core Team 成员包括 George V. Neville-Neil（主席）、Benedict Reuschling（秘书）、Ed Maste（埃德·马斯特）、Gleb Smirnoff、John Baldwin（约翰·鲍德温）、Konstantin Belousov（康斯坦丁·别洛乌索夫）、Kris Moore（克里斯·摩尔）、Philip Paeps（菲利普·佩普斯）、Sean Chittenden 等（不同届次有变动）。11.x 时期没有公开的大规模 committer 权限撤销事件，社区治理相对平稳。

**史料**：FreeBSD Core Team 选举公告（freebsd-announce 邮件列表）、Core Team 页面各届成员名单、core-secretary 邮件列表归档。 ［A］

**史观**：社区治理（专题语，不设总纲条号；原挂“总纲第 23 条——社区治理”系伪标签，权威第 23 条为“一切历史写作都是基于哲学设定的历史小说”，依 2026-09-14 核查报告去条号留论旨）：FreeBSD Core Team 是“开发者自治”模式的典型——由活跃开发者选举产生核心团队，核心团队对开发者负责，没有单一企业或个人能控制项目。这种治理模式与 Linux 的“仁慈独裁者”（林纳斯·托瓦兹（Linus Torvalds）长期拥有最终决策权）模式形成对比。两年一次的定期选举保证了核心团队的新陈代谢。

**辨析**：2014-2018 年间 Core Team 没有公开撤销 committer 权限的案例——这一时期社区治理相对和谐，未发生像 2000 年代初（core 辞职风波）或 2020 年代初（WireGuard 争议）那样的重大治理冲突。committer 权限变动多为自然退役（committer 因个人原因申请退位）而非强制撤销。
