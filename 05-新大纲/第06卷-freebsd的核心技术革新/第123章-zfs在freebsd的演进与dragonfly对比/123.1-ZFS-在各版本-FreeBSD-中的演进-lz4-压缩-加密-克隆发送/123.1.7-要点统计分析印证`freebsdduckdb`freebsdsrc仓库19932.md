# 123.1.7 要点统计分析印证`freebsdduckdb`freebsdsrc仓库19932

**要点**：**统计分析印证**——`freebsd.duckdb` freebsd-src 仓库 1993-2026 年 commit 月度量 Mann-Kendall 趋势检验结果为显著上升趋势（Sen's slope =+1.40/月，p < 0.001，95% CI [1.11, 1.69]）（统计结论 C-03）；Pettitt 与 BUISHAND R 双变点检验一致判定 freebsd-src 变点为 1999-08（p < 0.001，距 2020-01 SVN-to-Git 迁移 245 个月，判定非迁移伪变点）（统计结论 C-08、C-12）；该变点早于 ZFS 主干导入 freebsd-src 仓库的 commit `f0a75d274af375d15b97b830966b99a02b7db911`（2007-04-06）约 8 年，反映 freebsd-src 在 ZFS 集成前已进入稳定上升通道；ZFS 集成后 freebsd-src 趋势持续上升，未因 CDDL-ZFS 引入而中断 commit 增长趋势，统计结论支持 CDDL-BSD 许可证兼容性未对 freebsd-src 整体开发活跃度产生负面影响（统计结论 C-03/C-08/C-12 系跨卷背景参考）

**史料**：`freebsd.duckdb` `commits` 表 freebsd-src 仓库 commit 月度量；SQL 查询 `SELECT strftime('%Y-%m', committer_date) AS month, COUNT(*) AS commit_count FROM commits WHERE repo_name='freebsd-src' GROUP BY month ORDER BY month`；推断性统计.md Task 5（Mann-Kendall 趋势检验）与 Task 6（Pettitt + BUISHAND R 变点检验；原引 `script/phase3_inferential_stats.py` 经实测不在库，以存档结论文件为准）；统计结论编号 C-03、C-08、C-12（跨卷背景参考）；查询日期 2026-07-27 ［A］

**史观**：总纲第 4 条——分离聚合是永恒规律：freebsd-src 趋势检验显示 ZFS 集成（2007-04）前后 commit 量均呈上升趋势，未出现因 CDDL 许可证引入导致的 “开发断裂”——统计数据印证 CDDL-BSD 许可证兼容性使 ZFS 得以聚合入 FreeBSD 主线、赓续 CSRG 未竟事业而非中断开发；总纲第 5 条——没有必然性，只有偶然性：变点 1999-08 早于 ZFS 集成约 8 年，反映 freebsd-src 上升趋势的根因在于 FreeBSD 3.x/4.x 时期的工程积累，而非 ZFS 集成驱动

**辨析**：**统计局限性标注**——(1) 统计显著 ≠ 实际显著：Mann-Kendall 趋势检验 p < 0.001 表明 freebsd-src commit 量存在统计学显著上升趋势，但 Sen's slope =+1.40/月 的实际工程意义须结合 FreeBSD 版本周期与 commit 粒度变化综合判断；(2) 变点归因存疑：1999-08 变点距 2020-01 SVN-to-Git 迁移 245 个月，虽判定非迁移伪变点，但 1999 年 FreeBSD 3.3-4.0 过渡期可能存在其他工程事件（如 CAM 子系统重构、SMPng 项目启动）共同贡献变点，单一归因存在简化风险；(3) 0 信任原则适用：commit 量统计不区分 ZFS 相关 commit 与其他子系统 commit，ZFS 作为 freebsd-src 子集其对整体趋势的贡献率未单独量化；(4) 多重比较风险：本结论与第五卷其他章节引用相同 freebsd-src 趋势统计存在多重比较风险，Bonferroni 校正后显著性可能降低；(5) SVN-to-Git 迁移影响：1993-2020 年 freebsd-src 数据经 SVN-to-Git 迁移重算，commit hash 与 author_date 由迁移脚本回填，可信度较高但非原始 Git 时代记录
