# 134.8.3 9.1 **netmap(4)** 高速包 I/O 框架

**要点**：9.1-RELEASE 引入 **netmap(4)** 框架，由 Luigi Rizzo 教授团队开发，提供用户态高性能包 I/O 能力，绕过内核网络栈开销，可实现线速包处理（10Gbps+）；netmap 是 FreeBSD 在软件定义网络（SDN）、网络功能虚拟化（NFV）和高速包处理领域的关键基础设施

**史料**：Luigi Rizzo 关于 netmap 的论文（USENIX ATC 2012）、svn commit log、FreeBSD 9.1 Release Notes、**netmap(4)** man page ［A］

**史观**：总纲第 10 条——动手者创造历史：netmap 源自 Luigi Rizzo 团队的学术研究项目（比萨大学），而非商业公司需求；研究者以亲手实现使成果在 FreeBSD 中落地并持续发展，体现了动手者对开源操作系统的直接塑造，与 Dummynet（Rizzo 早期作品）成为 FreeBSD 网络研究双璧

**辨析**：netmap 在 9.1 中仅支持部分网卡驱动（em/igb/ixgbe 等 Intel 网卡优先支持），覆盖范围在 10.x 及后续版本大幅扩展；9.1 时期 netmap 主要面向研究人员和网络设备开发者，普通用户感知度低

**文献**：Rizzo L. netmap: A Novel Framework for Fast Packet I/O [C]//Proceedings of the 2012 USENIX Annual Technical Conference. Boston, 2012；**netmap(4)** man page；FreeBSD 9.1-RELEASE Release Notes
