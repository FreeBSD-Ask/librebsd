# 134.6.2 9.2 中 ZFS TRIM 与 lz4 压缩

**要点**：9.2-RELEASE 官方公告明确列出两项 ZFS 新特性："The ZFS filesystem now supports TRIM when used on solid state drives“ 和 ”The ZFS filesystem now supports lz4 compression"——即 ZFS 正式支持 SSD TRIM 与 lz4 压缩算法；lz4 由 Pawel Dawidek（pjd@）等从 illumos 移植，相比 gzip 提供更高的压缩/解压吞吐量和合理的压缩比，成为 ZFS 推荐的实时压缩算法；10.0-RELEASE 公告也将 TRIM 和 lz4 列为新特性，这是面向从 8.x/9.0-9.1 升级用户的强调而非重复添加

**史料**：FreeBSD 9.2-RELEASE Announcement（官方明确列出 TRIM 与 lz4）、FreeBSD 10.0-RELEASE Announcement、Pawel Dawidek 关于 ZFS lz4 的 commit log 与邮件列表公告 ［A］

**史观**：专题语（不设总纲条号）——软件工程（原挂总纲第 17 条系伪名目，删条号）：lz4 的引入反映了 ZFS 压缩算法从 “高压缩比优先”（gzip）向 “性能优先透明压缩”（lz4）的范式转变；lz4 成为 FreeBSD ZFS 默认推荐压缩算法，与 Linux btrfs/zfs 同期采纳 lz4 一致

**辨析**：9.2 与 10.0 公告均提及 ZFS TRIM/lz4，原因是 10.0 是新的大版本分支（stable/10），其公告面向所有用户（包括从 8.x 升级或新安装 10.0 的用户）汇总新特性；9.2 的 TRIM/lz4 是 9-STABLE 分支中的引入，10.0 则是将这些特性带入 10-STABLE 分支；TRIM 在 9.2 中的具体支持范围（手动 `zpool trim` vs 自动 TRIM）需对照 release notes 进一步核实
