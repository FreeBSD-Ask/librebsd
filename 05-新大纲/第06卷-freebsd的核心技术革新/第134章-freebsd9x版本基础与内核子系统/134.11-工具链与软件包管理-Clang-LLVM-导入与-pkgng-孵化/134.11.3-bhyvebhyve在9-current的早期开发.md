# 134.11.3 bhyve（BHyVe）在 9-CURRENT 的早期开发

**要点**：bhyve（早期称 BHyVe，BSD Hypervisor）由 Peter Grehan（彼得·格雷汉）（grehan@）和 NetApp 赞助开发，在 9-CURRENT 分支中进行早期开发，但 **未包含在任何 9.x RELEASE 版本中**；bhyve 的核心组件（vmm.ko 内核模块、**bhyve(8)** 用户态工具）在 10.0-RELEASE（2014.1.20）正式发布并提供支持；9.x 时期 bhyve 仅在 -CURRENT 分支供开发者测试，不适合生产使用；10.0 同时引入 **virtio(4)** 半虚拟化驱动和 Hyper-V 原生 guest 支持

**史料**：FreeBSD 10.0-RELEASE Announcement（明确列出 "the addition of **bhyve(8)**, **virtio(4)**, and native paravirtualized drivers providing support for FreeBSD as a guest operating system on Microsoft Hyper-V"）、Peter Grehan bhyve 邮件列表讨论、svn commit log（vmm 模块导入时间） ［A］

**史观**：技术路线分化：bhyve 使 FreeBSD 成为第一个内置原生 Type-2 hypervisor 的主流 BSD 系统，与 Linux KVM 形成技术路线平行发展；NetApp 对 bhyve 开发的赞助体现了存储公司对 FreeBSD 虚拟化能力的商业需求

**辨析**：**重要事实纠正——bhyve 不在 9.x RELEASE 中**：原文件或某些材料可能因 bhyve 在 9-CURRENT 时期即开始开发而误将其归入 9.x 特性，但官方 release notes 和 announcement 明确 bhyve 是 10.0 引入的核心新特性；9.0-9.3 RELEASE 公告和 release notes 均未提及 bhyve；用户需注意区分-CURRENT 分支开发与-RELEASE 正式发布的区别

**文献**：FreeBSD 10.0-RELEASE Announcement [Z]. 2014-01-20；**bhyve(8)**、**vmm(4)** man pages；Grehan P. BHyVe: A BSD Hypervisor [C]//BSDCan 2011. Ottawa, 2011
