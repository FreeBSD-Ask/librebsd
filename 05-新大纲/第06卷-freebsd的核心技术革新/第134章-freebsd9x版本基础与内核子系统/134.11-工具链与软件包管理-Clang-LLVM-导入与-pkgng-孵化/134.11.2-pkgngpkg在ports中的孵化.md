# 134.11.2 pkgng（pkg）在 ports 中的孵化

**要点**：pkgng（下一代软件包管理，后称 **pkg(8)**）在 9.x 时期以 ports-mgmt/pkg port 形式存在于 ports 树中，Baptiste Daroussin（巴蒂斯特·达鲁桑）（bapt@）主导开发；9.x 全程 base 系统默认软件包管理仍是 pkg_install 工具集（**pkg_add(1)**、**pkg_delete(1)**、**pkg_info(1)** 等）；pkg 1.0 正式版于 2012 年 8 月发布；**10.0-RELEASE 才将** pkg(7)**作为默认软件包管理工具，pkg_add/pkg_delete 等被移除**；2012 年入侵事件后软件包构建基础设施重构加速了 pkgng 与签名软件包的部署

**史料**：pkgng 官方文档、Baptiste Daroussin pkgng 邮件列表公告、FreeBSD 10.0 Release Notes（明确 "**pkg(7)** is now the default package management utility. **pkg_add(1)**, **pkg_delete(1)**, and related tools have been removed."）、ports-mgmt/pkg port Makefile 历史 ［A］

**史观**：总纲第 17 条——软件工程：pkgng 是 FreeBSD 软件包管理从 “shell 脚本 + tarball”（pkg_install）向 “现代二进制软件包管理器”（pkg）的重构；它借鉴了 apt/yum 等 Linux 软件包管理器的特性（依赖解析、仓库签名、增量更新）但保持 BSD 实现；入侵事件中旧软件包基础设施暴露的安全缺陷直接加速了 pkgng 签名软件包功能的设计

**辨析**：pkgng 在 9.x ports 中可用但非默认——用户需通过 ports 安装 pkg 并使用 `pkg2ng` 转换旧数据库；9.x 时期不建议新手使用 pkgng，官方文档仍指导使用 pkg_add；原文件若将 pkg 描述为 9.x 默认则为错误

**文献**：FreeBSD 10.0-RELEASE Announcement [Z]. 2014-01-20；**pkg(7)**、**pkg-add(8)** man pages；pkgng GitHub 仓库历史提交 ［B］
