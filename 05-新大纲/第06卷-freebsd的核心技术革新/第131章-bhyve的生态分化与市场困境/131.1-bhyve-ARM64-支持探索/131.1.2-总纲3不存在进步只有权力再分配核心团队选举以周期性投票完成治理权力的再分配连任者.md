- 总纲3 不存在进步，只有权力再分配：核心团队选举以周期性投票完成治理权力的再分配：连任者与新入选者在同一票池中竞争，交接日期预先公告，权力的存续系于这套形式化程序而非个人威望；投票率低于往年的波动提示参与本身是偶然条件的产物，而非治理制度线性进步的证据。（BSD Now EP148，[157.32-286.22]，L2）
- 总纲10 动手者创造历史：机器人访谈呈现的是边缘实践者驱动的技术扩散：两名自称初学者依靠 IRC 中志愿开发者即时解答与 DTS/FDT 补丁进入基系统，进而反向要求项目补全嵌入式文档、构想设备类 SDK——技术演进由动手者推动，其真实需求构成项目改进的直接动力，而非自上而下的规划。 [订正：原 Bugzilla 报告与 DTS/FDT 补丁（新转写访谈段无 Bugzilla 提及），2026-09-30 SenseAudio 重转核对]（BSD Now EP148，[2682.06-3091.22]，L1）
- 总纲10 动手者创造历史：Zoulas 自述其 NetBSD 安全官身份并非任命所得，“人人都去做他们认为能帮上忙的事”（1438.96-1447.12）；blacklistd 亦非立项规划的产物，而是他面对自身服务器日志膨胀时的动手自救。项目角色与工具产出均生长于具体动手者在偶然遭遇中的自发行动，这一时期的 BSD 史应当由这些动手者的实践而非职位与蓝图来解释。（BSD Now EP87，[1438.96-1447.12]，L1）
- 总纲8 本体论上各方平等：主持人在访谈中主动检讨对 NetBSD 的覆盖不足，承诺“像对待其他 BSD 一样给他们公允的机会”（2249.26-2252.42），Zoulas 回应称包括自己在内的 NetBSD 社区成员“一直不太愿意接受访谈”（2275.50-2281.82）；同一期节目也为 MidnightBSD 这类小型衍生分支留出版面。各分支在本体论层面的平等呈现，在此是社区媒体的自觉实践而非修辞。（BSD Now EP87，[2246.30-2269.50]，L2）
- 总纲5 没有必然性，只有偶然性：bhyve 的诞生系于一连串偶然：Intel 在 2009 年 Nehalem 上引入 EPT 的硬件节点、NetApp 内部项目未达预期、公司恰选择捐赠而非封存，三者叠加才有 2011 年 FreeBSD 获赠这份代码；演讲人自己把时机称为 fortuitous——没有必然规律保证 FreeBSD 一定获得原生 hypervisor，历史进程由具体事件与偶然条件铺就。（YouTube EPkXi1xaUqr20，[289.28-357.68]，L1）

**辨析**：

- HAMMER 的伪文件系统命名被逐层拆解：@@ 前缀标记伪文件系统或快照，冒号前数字指示主从角色，冒号后为五位数编号；主持人辨析其与 ZFS 数据集概念的错位——HAMMER 以 localization 参数在单棵 B-tree 内切分数据，概念迁移到 ZFS 语汇反而引起混乱，且路径中的冒号会破坏 PATH 环境变量解析，邮件列表已有人提议改换分隔符或引入别名机制。（BSD Now EP148，[3515.45-3905.94]，L2）
- 可复现构建议题上，NetBSD 进度报告达 77.7%、内核已完全可复现，主持人援引该结果并称“所有 BSD 都应尝试做到这一点”（4727.46-4744.98），从安全审计与二进制可溯源出发论证其价值；同时发现 FreeBSD 当周结果异常（0/1 文件），推测是统计页归档故障而非能力缺失，Ed Maste 等人仍在推进。（BSD Now EP148，[4711.29-4783.06]，L2）
- 关于 file(1) 重写，Zoulas 给出当事人权衡：魔法规则集已支持递归引用，JPEG 等格式无固定偏移可循，多年累积使解析器能力与攻击面同步增长，“问题在于你想理解多少文件定义，与想要多安全之间如何取舍”（2424.66-2431.78）；他并提醒 file 程序与 libmagic 库早已分离，PHP、Apache 等软件直接复用该库，仅修固命令前端并不等于修复生态中的库本体。（BSD Now EP87，[2424.66-2457.66]，L1）
