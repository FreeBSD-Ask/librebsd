# 127.3.4 剑桥大学许可策略史料考证

**要点**：剑桥大学在安全研究领域长期采用 BSD 风格的开放许可策略，这一策略贯穿 Capsicum（2010）至 CHERI（2014+）系列项目：Capsicum 以 BSD 2-Clause 发布、CHERI ISA 规范以 BSD 风格许可证发布、CheriBSD 以 BSD 许可发布；这一策略的代表性先例包括 MIT Project Athena 的 X Window System（1984，MIT 许可）、剑桥大学在 TCP/IP 协议栈实现等方面的开放贡献；罗伯特·N. M. 沃森（Robert Watson）作为 FreeBSD committer 和 TrustedBSD 框架作者，对 BSD 许可证生态有深度参与，其主导的项目选择 BSD 许可具有一致性

**史料**：剑桥大学 Capsicum 项目首页许可声明；CHERI ISA 规范 cheri-cpu.org 许可页面；CheriBSD 源码仓库 LICENSE 文件；FreeBSD 源码 svn log 中 罗伯特·N. M. 沃森 (rwatson@) 的多年提交历史 ［A］
