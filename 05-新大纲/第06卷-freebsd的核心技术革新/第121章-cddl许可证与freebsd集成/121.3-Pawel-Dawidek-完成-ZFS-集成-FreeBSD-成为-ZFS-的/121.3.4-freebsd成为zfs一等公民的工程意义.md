# 121.3.4 FreeBSD 成为 ZFS 一等公民的工程意义

**要点**：FreeBSD 成为 ZFS “一等公民” 操作系统意味着 ZFS 不再是 Solaris 独有的功能，而是跨平台开源文件系统；FreeBSD 对 ZFS 的关键工程贡献包括：boot from ZFS 支持（FreeBSD 9.0，2012 年 1 月）、ZFS bootloader（gptzfsboot 引导程序）、ZFS 与 GEOM 框架的集成、ZFS 与 jail 的集成、lz4 压缩支持（从 illumos 同步）、TRIM/UNMAP 支持；FreeBSD 7.0（2008）ZFS 标记为 experimental；FreeBSD 8.0（2009）ZFS 升级为生产就绪；FreeBSD 9.0（2012）ZFS 根文件系统正式支持；FreeBSD 10.0（2014）ZFS 为推荐文件系统；基于 FreeBSD 的发行版将 ZFS 作为核心卖点：FreeNAS（2005 年由 Olivier Cochard-Labbé 创建，后由 iXsystems 接手更名为 TrueNAS CORE）、pfSense（防火墙发行版）、TrueOS（PC-BSD 后继）、GhostBSD 等；TrueNAS CORE（原 FreeNAS）成为全球部署最广泛的开源 ZFS 存储操作系统之一

**史观**：终结与延续：FreeBSD 成为 ZFS 一等公民是一个历史悖论——Sun 创造了 ZFS 但最终被 Oracle 收购并转向封闭；一个本非 BSD 世界创造的文件系统，最终在 BSD 生态中找到了最自由的发展空间；这印证了项目统摄史观中关于 “创造者不必然是继承者” 的洞见

**辨析**：macOS ZFS 移植历史需补充：Apple 曾在 Mac OS X 10.5 Leopard（2007 年 10 月）中包含只读 ZFS 支持，但在 Mac OS X 10.6 Snow Leopard（2009 年 8 月）中移除；Mac ZFS 社区在 2008-2012 年间维护了 MacZFS 项目，后发展为 OpenZFS on OS X（O3X）；Apple 最终于 2017 年发布自研 APFS 作为 HFS+ 的后继，彻底放弃了 ZFS 路线
