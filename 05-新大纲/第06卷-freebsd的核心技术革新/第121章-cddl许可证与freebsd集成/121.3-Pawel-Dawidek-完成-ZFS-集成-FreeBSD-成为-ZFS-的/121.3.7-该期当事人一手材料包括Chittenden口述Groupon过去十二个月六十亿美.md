- 该期当事人一手材料包括：Chittenden 口述 Groupon 过去十二个月六十亿美元订单与一点六亿访客的运营规模及 FreeBSD 迁移决策过程、BSDcan 2015 会场见闻（FreeBSD 上原生运行 CentOS 6 Docker 容器、CloudABI、iocage 等演示）、OpenZFS 欧洲第二届大会视频（Matt Ahrens 回顾 ZFS 历史、Oracle 收购与 illumos 诞生，2015 年 5 月巴黎）、Ingo Schwarze 撰写的以 AFL 模糊测试 mandoc 并分解四十五个 bug 的技术文章，以及 NetBSD 7.0 RC1 发布公告；另有 Facebook SSD 错误率白皮书作为转引材料被用于论证位翻转风险。（BSD Now EP95，[1218.16-1347.60]，L1）

**史观**：

- 总纲9 经验优先：全期论证结构以一线经验替代基准测试神话：不宣称 FreeBSD 更快，而以生产事故处置、延迟分位数测量、漏洞公告日四十分钟重编译 world 的响应能力等操作事实论证企业采用理由，体现正确性优先于速度的经验主义立场，拒绝对操作系统作抽象优劣排序。（BSD Now EP95，[1704.13-2028.82]，L1）
- 总纲10 动手者创造历史：嘉宾以运维者视角刻画范式变迁：引用 Randy Bias 的“命名宠物变牲畜”名言（2626.28-2635.47）概括数据中心从给服务器起名到编号批量管理之变，指出工具链（Consul 基于 Serf 的故障检测、Ansible 配置管理）使自愈发生在机器时间而非人类时间，关注单位从单台服务器变为整个数据中心；并以自身公司公开分享使用经验、呼吁打破企业只取不予的沉默趋势作结，把技术史的动力归于动手者与公开实践的累积而非厂商叙事。（BSD Now EP95，[2621.03-2754.08]，L1）
- 总纲10 动手者创造历史：该期堪称动手者史的范本：移植的成败不系于宣言或路线图，而系于个体连续十昼夜的编码、其后数月的打磨与多年近乎独自的维护——他自陈 FreeBSD 侧移植数年间几乎由其一人支撑、尽管 ZFS 本身绝非一人项目，并长期“等待他人加入”（1174.94-1193.82）；企业采用亦由工程师在生产环境中逐案促成。技术史在此呈现为具体劳动的累积，而非抽象进程的展开。（BSD Now EP62，[587.77-1193.82]，L1）
- 总纲5 偶然性优先：偶然性优先：受访者从 Linux 转向 FreeBSD 的经历表明，用户技术路线的分岔并非产品优劣理性权衡的产物，而是由一次偶发的社区人际干预决定——“有人过来说，不，这不是合适的操作系统，你该用这个”（2007-06-22，383.88-392.16），随后一张光盘改写了其此后七年的操作系统生涯；个体采用史由无数此类微小偶然累积而成，构成社区技术扩散的真实底层。（BSDTalk EP118，[380.92-392.16]，L1）
- 总纲10 动手者创造历史：动手者创造历史：EuroBSDCon 2007 的组织架构中没有职业会议经理人，只有 BSD 用户组前董事、既有 Linux 会议的志愿操办者与受同侪相邀而入的业余组织者；会议史的书写重心因此不在台前演讲的名家，而在敲定旅舍、预算与日程的台下之手——正是这些默默做事者把分散于欧洲各国的开发者维系为年度相聚的共同体。（BSDTalk EP118，[317.1-358.68]，L1）
- 总纲4 分离聚合是永恒规律：ZFS 谱系呈现典型的分离聚合循环：Sun 开源、Oracle 收购后闭源、Illumos 与 ZFS on Linux 分头演化为分离，OpenZFS 统一上游仓库是对分离的再聚合；当事人以同一份源码在 FreeBSD 与 Linux 上完全一致为聚合完成之标准，并称各系统仅需保留与各自内核对接的薄层。（YouTube EPhTbqEf9LRGE，[2066.159-2293.4]，L1）
