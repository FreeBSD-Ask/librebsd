# 130.2 11.1-11.4 RELEASE——次版本迭代与 11.x 系列演进

## 130.2.1 2017.7.26 FreeBSD 11.1-RELEASE——云平台深化

**要点**：FreeBSD 11.1-RELEASE 于 2017 年 7 月 26 日发布，是 stable/11 第二个版本，Release Engineering Lead 仍为 Glen Barber（格伦·巴伯）。核心更新：Clang/LLVM/LLD/LLDB/libc++ 全套升级至 4.0.0；**blacklistd(8)** 正式集成到 OpenSSH；新增 **zfsbootcfg(8)** 工具（提供 ZFS 引导一次性 boot.config 风格选项）与 **efivar(8)** 工具（UEFI 变量管理接口）；支持 Microsoft Hyper-V Generation 2 虚拟机（UEFI 引导、安全启动等第二代特性）；新增 **ena(4)** 驱动支持 Amazon EC2“下一代增强网络”（Elastic Network Adapter，100Gbps 级网络）；NFS 客户端支持 Amazon Elastic File System（EFS）；EFI 引导加载器新增 TFTP 远程文件访问（除 NFS 外）；ZFS 改进压缩数据缓存以提高缓存命中率与性能；多项构建可重现性（reproducible builds）改进。11.1 是首个正式登陆 Microsoft Azure Marketplace 的 FreeBSD 版本（10.x 时期仅在 VMDepot），Google Compute Engine、Amazon EC2、Vagrant 镜像继续提供。

## 130.2.4 2020.6.23 FreeBSD 11.4-RELEASE——11.x 终章与 Bruce Evans 纪念
