# 145.6.2 LLD 成为 amd64 默认链接器

**要点**：FreeBSD 12.0-RELEASE 将 LLD（LLVM Linker）设为 amd64 架构的默认系统链接器，替代 GNU ld（来自 GNU binutils）。LLD 是 LLVM 项目的子项目，由 Rui Ueyama 等开发，使用 Apache 2.0 with LLVM Exceptions 许可证，链接速度远快于 GNU ld（大型 C++ 项目可快 2-5 倍），且原生支持 LTO（Link Time Optimization）。12.0 中 LLD 为 amd64 默认链接器，i386 和 armv6/armv7 可选，arm64 也在 12.0 中默认使用 LLD。GNU ld 仍保留在 base 中用于其他架构（如 powerpc64、mips 等）。FreeBSD 13.0 将 LLD 设为所有架构的默认链接器。

**史料**：FreeBSD 12.0-RELEASE Release Notes（LLD 章节）、LLD 项目文档、commit r348182（LLD 默认） ［A］

**史观**：许可证：LLD 替换 GNU ld 是许可证纯洁化工程的又一关键步骤——GNU ld 使用 GPLv3 许可证，LLD 使用 Apache 2.0 with LLVM Exceptions，消除了 GPL 许可证约束；软件工程：LLD 的链接速度优势对大型 C++ 项目（如 LLVM/Clang 自身、Chromium、LibreOffice 等）的构建时间有显著改善，这也是 FreeBSD 自身构建系统受益的方向

**辨析**：LLD 在 12.0 中仅为 amd64 默认链接器，arm64 也默认使用 LLD，但 i386/armv7/powerpc 等仍默认使用 GNU ld；LLD 对所有架构的默认化发生在 13.0；GNU ld/GNU binutils 在 12.0 中仍保留在 base 中用于非 LLD 架构
