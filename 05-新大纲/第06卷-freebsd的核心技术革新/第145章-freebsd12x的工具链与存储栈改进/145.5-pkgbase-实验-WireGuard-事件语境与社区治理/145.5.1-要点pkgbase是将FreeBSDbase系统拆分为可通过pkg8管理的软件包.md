# 145.5.1 要点pkgbase是将FreeBSDbase系统拆分为可通过pkg8管理的软件包

**要点**：pkgbase 是将 FreeBSD base 系统拆分为可通过 **pkg(8)** 管理的软件包的实验性项目，主要由 Glen Barber（格伦·巴伯）（gjb@）与 Release Engineering Team 开发，在 12.x 时期引入实验性支持。传统上 FreeBSD base 系统通过 make buildworld/installworld 或 **freebsd-update(8)** 整体更新，pkgbase 目标是让 base 组件像 ports 编译的第三方软件一样可独立安装、更新、卸载。12.x 时期 pkgbase 处于“实验性技术预览”状态，提供基础包构建但不推荐生产使用。pkgbase 的长期目标是使系统更新更灵活（可只更新特定组件而不重启）、支持最小化系统安装（如仅安装内核+libc+SSH）。pkgbase 最终在 FreeBSD 14.x/15.x 逐步成熟。

**史料**：FreeBSD 12.0/13.0 Release Notes Packaging Changes 章节、Glen Barber pkgbase 邮件列表公告与开发更新、FreeBSD Quarterly Status Reports pkgbase 章节、pkgbase 构建脚本与 wiki 页面。 ［A］

**史观**：总纲第 17 条——软件工程：pkgbase 反映了 FreeBSD 从“monolithic base”向“packageable components”的工程范式迁移。类 Unix 操作系统长期以来将基本系统与第三方软件严格分离（base vs ports/pkg），这种分离保证了 base 的纯净与一致性但也限制了灵活性。pkgbase 试图在保持 base 质量标准的同时引入更现代的软件管理模型。

**辨析**：pkgbase 在 12.x 完全是实验性质，不适合生产环境；**freebsd-update(8)** 仍是 12.x 官方推荐的二进制更新工具；pkgbase 与传统 buildworld 并行存在而非替代。pkgbase 概念的最初发起者是 bapt@（Baptiste Daroussin），2015 年即已启动（Vadot, 2019），Glen Barber 与 Release Engineering Team 在 12.x 时期将其发展为实验性支持——早期目标包括对 RELEASE/STABLE/CURRENT 的二进制升级与无需 sendmail/工具链的细粒度安装。
