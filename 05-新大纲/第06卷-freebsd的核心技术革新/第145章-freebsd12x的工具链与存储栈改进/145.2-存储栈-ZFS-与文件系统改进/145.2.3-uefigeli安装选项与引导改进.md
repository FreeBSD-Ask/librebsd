# 145.2.3 UEFI+GELI 安装选项与引导改进

**要点**：FreeBSD 12.0 的 **bsdinstall(8)** 安装器新增 UEFI+GELI 作为官方安装选项（r338282，Klara Systems 赞助），允许在 UEFI 引导模式下使用 GELI 加密根文件系统。先前 UEFI+GELI 需要手动配置，12.0 起安装器原生支持此配置。Lua **loader(8)**（基于 Lua 的引导加载器）在 12.0 获得多项改进（“Various Lua **loader(8)** improvements”），是 FreeBSD 11.x 引入 Lua loader 替代 Forth loader 后的持续完善。12.x 时期 **loader.conf(5)** 配置、UEFI Secure Boot 支持、**zfsbootcfg(8)** 等引导工具持续改进。**vt(4)** 控制台在 12.0 获得性能优化，文本绘制速度提升 2-6 倍。

**史料**：FreeBSD 12.0-RELEASE Announcement（UEFI+GELI、Lua loader 改进、vt 性能提升）、**bsdinstall(8)**/**loader(8)**/**vt(4)** 手册页、commit r338282。 ［A］

**史观**：总纲第 15 条——文化即形式主义〔存疑：映射待主理人审定〕：UEFI+GELI 安装选项的加入是“加密即默认”理念在安装流程中的体现——全盘加密在笔记本电脑与移动设备场景下已成为最佳实践，安装器原生支持可避免用户手动配置出错。Lua loader 替代 Forth loader 则是用户可编程基础设施的现代化——Lua 比 Forth 更广为人知，降低了引导加载器脚本开发的门槛。

**辨析**：UEFI+GELI 在 12.0 为安装器支持新选项，但 GELI 加密本身自 FreeBSD 6.x 即已存在；BIOS 模式下 GELI 加密引导支持更早版本即已存在。GELI 加密启动引导代码（gptgeliboot 与 gptzfsboot 的 GELI 支持）由 Allan Jude（艾伦·裘德） 主导开发（Jude, 2016）：开发中 gptldr 引导代码的 16 位汇编 64KB 复制限制曾使加入 AES/SHA 实现的加密 ZFS 引导代码（超 90KB）无法装入，最终由 Colin Percival 在 EuroBSDCon 2015 开发者峰会后以可扩展的可变 32KB 块复制方案解决（Jude, 2016）。Lua loader 在 11.x 已引入，12.0 是改进而非首次引入。

**文献**：FreeBSD **bsdinstall(8)**/**loader(8)**/**geli(8)** Manual Pages [Z]；FreeBSD 12.0-RELEASE Announcement [Z]. 2018；commit r338282 [Z]. svn.freebsd.org；Jude A. Booting from Encrypted Disks on FreeBSD [C]//AsiaBSDCon 2016. Tokyo, 2016. ［A］

**要点**：

- FreeBSD 12.2 引入 special VDEV（metadata classes）：可把元数据（目录内容、时间戳、文件大小等）与可选的小数据块存入专用 SSD VDEV，数据块留在机械盘，从而加速 find、rsync 等元数据密集操作；使用时须镜像元数据 VDEV（丢失元数据则数据近乎无用），且加入既有池后仅新写入文件的元数据迁移过去，需以 send/receive 或等待数据自然修改来迁移。（BSD Now EP376，[569.22-679.88]，L2）
- 12.2 的已知问题：IPFW forward 规则向同一接口多 IP 转发时存在栈损坏导致的随机端口问题，修复将随 12.2-p1 发布；zfs receive 在期待删除旧快照时也有问题并将修复；BeagleBone 因 SD 卡 IO 异常缓慢而暂未提供 12.2 镜像；DVD 安装器内附带的 GDM 版本损坏，需在安装后从上游镜像升级。（BSD Now EP376，[686.3-800.7]，L2）
- 用户空间与基础设施改进：rc.conf 新增 linux_mounts_enable（依赖 linux_enable 挂载 Linux 专用文件系统）；cron 新增 -n 与 -q（成功时不发邮件、不记日志）；dd 新增 conv=fsync/fdatasync/sync 与 iflag=fullblock 等选项；fsck 支持 ms-dosfs；showmount 支持长选项；mountd 修正 map root/map all 的组列出；sesutil 新增面向人读的 show 子命令；jail 工具支持在 jail 内运行 Linux 程序；read 系统调用默认禁止读目录，可用 security.bsd.allow_read_dir 恢复。（BSD Now EP376，[84.16-477.1]，L2）[订正：原 map root/map all 的根目录列出、security.bsd.allow_readdir，2026-09-30 SenseAudio 重转核对]
- certctl 项目由 Alan Jude 发起：把 Mozilla CA 根证书包拆分为单个证书随系统分发，并允许管理员额外信任自签证书或显式不信任某些证书，满足企业在 SSL 拦截设备、管理系统中信任自有证书的需求，由 Kyle Evans 完成落地；virtio 块驱动新增 trim 支持，使 FreeBSD 作为 guest 删除数据时能向 hypervisor 释放空间，bhyve 侧 zvol 也能相应释放。（BSD Now EP376，[234.84-295.3]，L1）
- ZFS per-dataset kstats：kstat.zfs.<pool>.dataset 下按 object ID 为每个数据集提供读写次数与字节数，计数自重启或导入后从零累计，可定位哪个客户或虚拟机在制造磁盘负载；升级时还须更新池与池的 boot 部分。（BSD Now EP376，[485.72-554.12]，L1）
