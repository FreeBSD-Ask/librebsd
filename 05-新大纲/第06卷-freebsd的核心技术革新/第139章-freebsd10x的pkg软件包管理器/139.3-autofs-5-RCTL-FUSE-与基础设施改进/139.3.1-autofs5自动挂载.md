# 139.3.1 **autofs(5)** 自动挂载

**要点**：**autofs(5)**——FreeBSD 原生自动挂载设施——在 FreeBSD 10.1 正式加入 base（10.1 Release Notes 标注），由 Edward Tomasz Napierala（trasz@）主导开发。autofs 起源于 FreeBSD 2000 年代末期的 NFSv4 支持工作，设计参考了 Solaris/illumos autofs 与 Linux autofs，但为 BSD 许可的独立实现。**autofs(5)** 支持按需自动挂载文件系统（访问时挂载、空闲超时卸载），可与 NFS、SMB、CD9660、MSDOSFS、ZFS 等多种文件系统配合，替代了 10.x 之前使用的 **amd(8)**（automount daemon）。10.1 中 autofs 已功能完整但默认不启用，需配置 /etc/auto_master 与 autofs rc.d 服务。

**史料**：FreeBSD 10.1 Announcement（"The new filesystem automount facility, autofs(5), has been added"）、10.1 Release Notes、autofs(5)/automount(8)/automountd(8) 手册页、Edward Tomasz Napierala autofs 设计文档与提交记录、FreeBSD Quarterly Status Report 2014 Q3 autofs 条目。 ［A］

**史观**：专题语（不设总纲条号）——基础设施的现代化重写：**amd(8)** 作为 1990 年代的自动挂载守护进程，代码老旧且功能有限，**autofs(5)** 的重写使 FreeBSD 自动挂载功能达到与 Solaris/Linux 可比水平，对 NFSv4 与可移动介质支持至关重要。Edward Tomasz Napierala 是 FreeBSD 存储与文件系统领域多产贡献者，除 autofs 外还参与 iSCSI、NFSv4 ACL、CAM 等子系统开发。

**辨析**：部分资料称 autofs 在 10.0 引入——经官方 Announcement 核实 autofs 在 10.1（2014.11）才正式加入，10.0 中不包含；autofs 与 FreeBSD 7.x 时期引入的 autofs 同名但为完全重写的实现。
