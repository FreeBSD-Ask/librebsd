# 143.1.4 FreeBSD 内核本土代码审计——ptrace/shm/kldstat/ipsec/vt/elf/nfs 的信息泄露群

**要点**：11.x 周期 FreeBSD 内核本土代码（非贡献组件）共发布约 35 个 SA，其中信息泄露类占主导——**SA-17:08.ptrace**（**2017 年 11 月 15 日**）修复 CVE-2017-1086，由 Konstantin Belousov 提交 commit `799a19dd010b` "MFC r325567: Zero whole struct ptrace_lwpinfo to not leak kernel stack data"——通过 **ptrace(2)** 的 PT_LWPINFO 请求泄露内核栈数据；**SA-17:09.shm**（**2017 年 11 月 15 日**）修复 CVE-2017-1087，由 Gordon Tetlow 提交 commit `ae7f9f96b8cd` “Fix namespace issue in POSIX shm implementation for jails”——jail 环境中 POSIX 共享内存命名空间隔离缺陷；**SA-17:10.kldstat**（**2017 年 11 月 15 日**）修复 CVE-2017-1088，由 Gordon Tetlow 提交 commit `edb01d11f896` "Properly bzero kldstat structure to prevent kernel information leak"——**kldstat(2)** 系统调用泄露内核内存；**SA-18:01.ipsec** 与 **SA-18:05.ipsec**（**2018 年 3 月 7 日** 与 **2018 年 4 月 4 日**）修复 CVE-2018-6916 与 CVE-2018-6918——IPsec 验证与崩溃漏洞，由 Gordon Tetlow 提交；**SA-18:04.vt**（**2018 年 4 月 4 日**）修复 CVE-2018-6917，由 Gordon Tetlow 提交 commit `9f6fffc73127` “Limit glyph count in vtfont_load to avoid integer overflow”——**vt(4)** 控制台字体加载整数溢出导致内存泄露；**SA-18:06.debugreg**（**2018 年 5 月 8 日**）修复 CVE-2018-8897（前述 x86 debug register）；**SA-18:08.tcp**（**2018 年 8 月 6 日**）修复 CVE-2018-6922，由 Jonathan T. Looney 提交 commit `95a914f63168` “Address concerns about CPU usage while doing TCP reassembly”——TCP 重组 CPU 使用率 DoS；**SA-18:10.ip**（**2018 年 8 月 14 日**）修复 CVE-2018-6923，由 Jonathan T. Looney 提交一组共 12 个 commit 改进 IPv4/IPv6 分片重组性能与限制；**SA-18:12.elf**（**2018 年 9 月 12 日**）修复 CVE-2018-6924，由 Gordon Tetlow 提交 commit `c9e562b18868` "Correct ELF header parsing code to prevent invalid ELF sections from disclosing"——ELF 头解析缺陷；**SA-18:13.nfs**（**2018 年 11 月 27 日**）修复 CVE-2018-17157/17158/17159，由 Gordon Tetlow 提交 commit `795132c5e923` “Fix multiple vulnerabilities in NFS server code”——NFS 服务器多个漏洞；**SA-18:14.bhyve**（**2018 年 12 月 4 日**）修复 bhyve 漏洞；信息泄露类漏洞（ptrace/kldstat/vt/elf/ip）的共同特征是“内核未初始化内存通过系统调用返回用户空间”——这是 FreeBSD 内核代码审计的长期主题

**史料**：FreeBSD-SA-17:08.ptrace / SA-17:09.shm / SA-17:10.kldstat PGP 签名公告（2017-11-15）；FreeBSD-SA-18:01.ipsec / SA-18:05.ipsec / SA-18:04.vt / SA-18:08.tcp / SA-18:10.ip / SA-18:12.elf / SA-18:13.nfs PGP 签名公告；**freebsd.duckdb** `commits` 表 `freebsd-src` 仓库 11.x 内核信息泄露类修复 commit 查询：`SELECT commit_hash, author_date, author_name, message_subject FROM commits WHERE repo_name='freebsd-src' AND author_date>='2017-11-01' AND author_date<='2018-12-31' AND message_subject LIKE '%kernel%' AND message_subject LIKE '%leak%' ORDER BY author_date ASC`；Gordon Tetlow 在 2017-11-15 集中提交的 ptrace/shm/kldstat 修复 commits（`799a19dd010b`、`ae7f9f96b8cd`、`edb01d11f896` 等）；Jonathan T. Looney 在 2018-08-14 提交的 IPv4/IPv6 分片重组改进 commits 系列（`5d9bd4551811` 至 `deee6872d9cb` 共 12 条） ［A］

**史观**：总纲第 17 条——证明世界先于解释和改造世界：11.x 周期内核信息泄露类 SA 的集中爆发反映 FreeBSD Security Team 在 Gordon Tetlow 接任 Security Officer 后开展了系统性的“未初始化内存审计”——这类漏洞的技术机制相似（内核未将结构体完整清零，导致系统调用返回包含旧内核栈数据的字段），修复方式也相似（添加 `bzero`/`memset` 调用），表明审计是有针对性而非偶发；Gordon Tetlow 在 2017-11-15 同日发布 3 个 SA（SA-17:08/09/10）的“批量披露”模式，预示了 14.x 周期 Security Team 的“主动审计—批量披露”工作模式的雏形；Jonathan T. Looney 在 2018-08-14 提交的 12 个 IPv4/IPv6 分片重组改进 commits 则反映 11.x 周期对 IPv6 重组算法的工程级重构——这是 11.x 周期网络栈安全加固的代表性工作

**辨析**：**SA-17:08/09/10 三个 SA 同日发布的辨析**：2017-11-15 Gordon Tetlow 同日发布 ptrace/shm/kldstat 三个 SA——这不是巧合而是“批量披露”策略，三个漏洞属于同一审计主题（内核信息泄露）但影响不同子系统，分别发布 SA 而非合并发布符合 FreeBSD SA 的传统风格（一个 SA 一个 CVE 或一组紧密相关 CVE）；**SA-18:10.ip 与 CVE-2018-5391 的辨析**：CVE-2018-5391（FragmentSmack）是 Linux 内核漏洞，FreeBSD 不受影响——版本周期文件中 CVE-2018-5391 出现是因为 commit `fb3c158489bc` 等 FreeBSD pf 修复 commit 引用了 CVE-2018-5391 作为“相关 CVE”，但 FreeBSD 本身不是该 CVE 的受影响产品；SA-18:10.ip 修复的是 FreeBSD 自己的 IPv4/IPv6 分片重组算法 DoS（CVE-2018-6923），与 CVE-2018-5391 技术机制类似但代码独立；**SA-18:13.nfs 的 CVE 数量辨析**：SA-18:13.nfs 修复 CVE-2018-17157/17158/17159 共 3 个 CVE，但 commit `795132c5e923` 的 message_subject“Fix multiple vulnerabilities in NFS server code”未明确列出 CVE 数量——需通过 SA 公告正文确认具体 CVE 编号 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］
