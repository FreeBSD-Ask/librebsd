# 143.1.8 freebsd-src 趋势统计与 FreeBSD 11.x 架构扩展时代的定量印证

**要点**：**统计分析印证**——`freebsd.duckdb` freebsd-src 仓库 1993-2026 年 commit 月度量 Mann-Kendall 趋势检验结果为显著上升趋势（Sen's slope =+1.40/月，p < 0.001，95% CI [1.11, 1.69]）（统计结论 C-03）；ARIMA(5,0,5) 模型拟合 AIC = 107.39（统计结论 C-29），表明 freebsd-src commit 月度量可由 ARIMA 模型较好刻画；FreeBSD 11.x 系列（2016-2018）以 arm64/AArch64 升 Tier-1 架构、vt(4) 默认控制台、Linuxulator 64 位支持等架构扩展为特征，该时期 freebsd-src 趋势持续上升，未因架构扩展而中断 commit 增长趋势，统计结论支持 11.x 时期架构扩展未对 freebsd-src 整体开发活跃度产生负面影响

**史料**：`freebsd.duckdb` `commits` 表 freebsd-src 仓库 commit 月度量；SQL 查询 `SELECT strftime('%Y-%m', committer_date) AS month, COUNT(*) AS commit_count FROM commits WHERE repo_name='freebsd-src' GROUP BY month ORDER BY month`；Python 脚本 `script/phase3_inferential_stats.py` Task 5（Mann-Kendall 趋势检验）；Python 脚本 `script/phase4_time_series.py` Task 14（ARIMA 建模）；统计结论编号 C-03、C-29；查询日期 2026-07-27 ［A］

**史观**：总纲第 4 条——分离聚合是永恒规律：freebsd-src 趋势检验显示 11.x 时期（2016-2018）架构扩展前后 commit 量均呈上升趋势，未出现因新架构引入导致的 “开发断裂”——统计数据印证 FreeBSD 在 ARM64 时代的架构扩展中赓续了 CSRG 未竟事业而非中断主线开发；专题语（不设总纲条号）——信息技术标准演进与硬件进步同步：arm64/AArch64 升 Tier-1 与 ARM 服务器硬件成熟度同步，freebsd-src 持续上升趋势反映 FreeBSD 在硬件代际更替中保持了开发活跃度

**辨析**：**统计局限性标注**——(1) 统计显著 ≠ 实际显著：Mann-Kendall 趋势检验 p < 0.001 表明 freebsd-src commit 量存在统计学显著上升趋势，但 11.x 时期架构扩展的实际工程意义须结合 arm64 具体代码量与 commit 分布综合判断；(2) ARIMA 模型局限：ARIMA(5,0,5) AIC = 107.39 为 freebsd-src 整体 commit 序列拟合结果，未单独建模 arm64 相关 commit 子序列，arm64 移植对整体趋势的贡献率未单独量化；(3) 多重比较风险：本结论与第五卷其他章节引用相同 freebsd-src 趋势统计存在多重比较风险，Bonferroni 校正后显著性可能降低；(4) commit 粒度变化：11.x 时期仍处于 SVN 时代（2020-01 才迁移至 Git），commit 粒度可能与 Git 时代不同；(5) SVN-to-Git 迁移影响：1993-2020 年 freebsd-src 数据经 SVN-to-Git 迁移重算，commit hash 与 author_date 由迁移脚本回填，可信度较高但非原始 Git 时代记录
