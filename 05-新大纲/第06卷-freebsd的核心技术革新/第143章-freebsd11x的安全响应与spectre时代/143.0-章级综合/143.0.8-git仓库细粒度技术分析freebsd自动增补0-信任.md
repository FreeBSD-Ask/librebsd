- **IPsec**（安全/网络，1998–2026）：IP 安全协议（RFC 2401），内核加密隧道 替代：早期实现 → RFC 4301 标准
- **TLS/加密**（安全，1993–2026）：传输加密：OpenSSL→LibreSSL（OpenBSD 2014 分叉） 替代：OpenSSL → LibreSSL（OpenBSD）
- **ASLR**（安全，1999–2026）：地址空间布局随机化（2001 年由 Linux PaX 补丁首次实现；OpenBSD 3.4 于 2003 年默认启用，为首个默认开启 ASLR 的主流操作系统） 替代：固定地址 → ASLR → KASLR
- **OpenSSH**（安全，1995–2026）：安全远程登录套件（OpenBSD 1999 开发） 替代：telnet/rlogin → SSH → OpenSSH
