# 141.1.1 发布工程语境与核心特性

**要点**：FreeBSD 11.0-RELEASE 于 2016 年 10 月 10 日由 Release Engineering Team 正式发布，是 stable/11 分支首个版本，Release Engineering Lead 为 Glen Barber（格伦·巴伯）（gjb@），Marius Strobl 任 Deputy Lead。11.0 支持 amd64、i386、powerpc、powerpc64、sparc64、armv6、aarch64 共七种架构，正式移除 IA-64（Itanium）架构支持（commit `e7d939bda22b` “Remove ia64.”由 Marcel Moolenaar 于 2014-07-07T00:27:09Z 提交，11.0 生效；前置 commit `50f73640baa7` "Remove ia64 from the list of known architectures and add an entry to UPDATING."由 Marcel Moolenaar 于 2014-07-02T22:34:06Z 提交；Glen Barber 于 2014-07-08T14:42:44Z 提交 `d9fa41e1a175` “Document r268351, end of ia64 support.”在 relnotes 中正式记录此变更）。核心编译器升级至 Clang/LLVM 3.8.0（r296417，由 Steven Kreuzer 于 2016-04-21T14:20:45Z 在 `b8df8f9a8df79fe6282e4c0f0cdd5c6f7e267a91` "Document r296417, clang, llvm, etc. updated to upstream 3.8.0"中正式记录），OpenSSH 更新至 7.2p2（默认禁用 DSA 密钥生成、移除 SSH Protocol 1 支持）。献词页纪念五位逝去的社区成员：Stefan Farfeleder、Juergen Lock、Ben Perrault、Paul Schenkeveld、Volker Werth。11.0 发布时因最后时刻发现问题重建镜像，**uname(1)** 显示为 11.0-RELEASE-p1，从早期镜像升级的用户须立即应用补丁。

**史观**：总纲第 17 条——软件工程：11.0 是 10.x“大整合”之后的“架构扩展”版本，不再集中替换基础组件（编译器、软件包管理器等已在 10.x 完成更替），而是聚焦于新架构支持（arm64）、新功能引入（libxo、blacklistd）与基础设施完善（UEFI、bhyve 图形）。11.0 发布前的镜像重建事件体现了 FreeBSD 发布工程“质量优先于进度”的实践——tagger_date = 2016-09-23 与公开声明日期 2016-10-10 相差 17 日，是 11.x 系列中最大偏差，反映 11.0 因镜像重建导致公告延迟的历史事实。

**辨析**：原文件与部分中文资料误称“11.0 默认使用 Clang 4.0”——经 Release Notes（r296417）与 Announcement 交叉验证，11.0 携带 Clang 3.8.0；Clang 4.0.0 在 11.1-RELEASE（2017.7.26）才引入。原文件称“GCC 在 x86 默认不安装”——经核实，此变更实际在 FreeBSD 10.0 已完成（r255321，"On platforms where clang is the default compiler, don't build GCC or libstdc++ by default"），11.0 延续了这一策略而非首次引入；GCC 4.2.1 在 11.x 仍保留于 base 源码树用于 powerpc、powerpc64、sparc64、mips 等非 x86 架构。原文件称“11.0 引入 NetGPG/openrsync”——经 Release Notes 全文检索，11.0 未引入这两项：NetGPG 从未进入 FreeBSD base，openrsync 是 OpenBSD 6.4（2018.10）才发布且在更晚版本才考虑移植；11.0 引入的是从 NetBSD 移植的 **blacklistd(8)**/**libblacklist(3)**。**数据库验证结论**：`release/11.0.0` tagger_date = 2016-09-23T22:37:05Z 早于公开声明日期 2016-10-10 共 17 日，符合“tag 创建后等待公告”的 FreeBSD 发布流程；11.0 的 17 日偏差在 11.x 系列中最大，反映 11.0 因镜像重建导致公告延迟的历史；IA-64 实际移除 commit 为 `e7d939bda22b` “Remove ia64.”（Marcel Moolenaar 2014-07-07），原文件标注的“commit r268351，2014-07-13 提交”在日期上有偏差——实际 r268351 对应的 commit `e7d939bda22b` 提交日期为 2014-07-07 而非 2014-07-13，6 日偏差可能源于 SVN 时代 committer_date 与 author_date 差异或事后文档记录错误；0 信任原则提示：11.0 系列在 SVN 时代发布，commit hash 经 2020 年 SVN-to-Git 迁移重算，tagger_date 由迁移脚本根据原始 SVN 元数据回填，可信度较高；[考据完成：2026-08-15 复核查] 邮件列表库未检索到“FreeBSD 11.0-RELEASE Now Available”发布公告（检索词“11.0-RELEASE Now Available”“11.0-RELEASE”在 freebsd-announce 均未命中该公告），2016-10-10 发布日两库无法验证（仅见 2016-08-05 Glen Barber “OpenSSH DSA keys are deprecated in 12.0 and 11.0”预通知）
