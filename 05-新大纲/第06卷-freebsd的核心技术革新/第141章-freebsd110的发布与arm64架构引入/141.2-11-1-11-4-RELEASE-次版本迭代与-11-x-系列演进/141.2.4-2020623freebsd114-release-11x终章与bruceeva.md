# 141.2.4 2020.6.23 FreeBSD 11.4-RELEASE——11.x 终章与 Bruce Evans 纪念

**要点**：FreeBSD 11.4-RELEASE 于 2020 年 6 月 23 日发布，是 stable/11 分支第五个也是最后一个版本（“fifth and final release”）。核心更新：Clang/LLVM/LLD/LLDB/compiler-rt/libc++ 升级至 10.0.0；OpenSSL 1.0.2u（OpenSSL 1.0.2 系列最终版本）；Unbound 更新至 1.9.6；**pkg(8)** 更新至 1.13.2；新增 **certctl(8)** 证书管理工具（用于管理 TLS CA 证书黑名单/白名单）；支持 ZFS 书签（bookmark）重命名；新增 Kerberos GSS API 弱算法弃用警告（遵循 RFC 6649 与 RFC 8429）。11.4 献词页献给 Bruce Evans（bde@）——Bruce Evans 是 FreeBSD 项目早期最具影响力的核心开发者之一，自 386BSD 时代即参与项目，对内核、C 库、启动流程、GCC/Clang 支持、i386/amd64 架构优化等做出了不可磨灭的基础性贡献，以代码质量极高和代码审查严格著称，于 2019-2020 年间去世。11.4 发布后 stable/11 分支继续接收安全更新至 2021 年 9 月 30 日，11.3 支持至 2020.9.30。

**史料**：FreeBSD 11.4-RELEASE Announcement（2020-06-23，明确“fifth and final release”定位、献词给 Bruce Evans、certctl(8) 新工具、支持周期至 2021.9.30）、FreeBSD 11.4-RELEASE Release Notes（Clang 10.0.0 r365567、OpenSSL 1.0.2u、ZFS 书签重命名）、Bruce Evans commit 历史与纪念帖；**freebsd.duckdb** `tags` 表 `freebsd-src` 仓库 release tag 数据库验证——`release/11.4.0` tagger_date = 2020-06-16T13:59:51Z，tagger_name = Glen Barber，target_commit_hash = `8c639945a44588f6cfdddfb057bb5aad88735da0`，target_commit_date = 2020-06-12T11:44:30Z，tag_type = annotated，tag_message =“Tag releng/11.4@r362094 as release/11.4.0 (11.4-RELEASE).”，与公开声明日期 2020-06-23 相差 7 日（即 tag 创建后约 7 日才正式发布，反映 11.4 发布前可能有镜像构建或最终验证延迟）；**freebsd.duckdb** `commits` 表 `freebsd-src` 仓库查询 r365567（Clang 10.0.0 升级）关键字未找到对应 commit 记录，与 r333688（11.2 Clang 6.0.0 升级）同样未找到的情况一致，提示 SVN-to-Git 迁移时 Clang 升级相关 commits 的 SVN revision 编号普遍未被保留在新 commit message 中，原大纲中“Clang 10.0.0 r365567”的 SVN revision 标注无法通过 commits 表直接验证，需通过 release notes 文档记录作为辅助证据 ［A］

**史观**：总纲第 4 条——分离聚合是永恒规律（原“终结与延续”系伪名目，按族例改挂）：11.4 作为 11.x 系列终版延续了 FreeBSD 为逝去贡献者献词的传统（10.4 献给 Andrey A. Chernov、11.0 献给五位社区成员、11.4 献给 Bruce Evans）。Bruce Evans 代表了 FreeBSD“第一代黑客”群体——他们从 386BSD/4.4BSD-Lite 时代即开始雕琢系统，对代码质量有着近乎偏执的追求，这种文化基因深刻影响了 FreeBSD 后续的工程风格。11.x 系列支持周期（2016.10-2021.9）约五年，体现了 FreeBSD 对生产环境用户长期支持的承诺。

**辨析**：部分资料误称“11.4 是最后一个使用 GCC 4.2.1 的版本”——GCC 4.2.1 在 11.x 仍用于 powerpc/sparc64/mips 等非 x86 架构的构建，但 x86 早已默认 Clang；GCC 4.2.1 从 base 中完全移除发生在 FreeBSD 13.0 时期，非 11.4。11.4 携带的 OpenSSL 1.0.2u 是 OpenSSL 1.0.2 系列的最后版本（OpenSSL 1.0.2 在 2019 年底 EOL），FreeBSD 12.x/13.x 已迁移到 OpenSSL 1.1.x。**数据库验证结论**：`release/11.4.0` tagger_date = 2020-06-16T13:59:51Z 早于公开声明日期 2020-06-23 共 7 日，与 11.0 的 17 日偏差、11.1 的 5 日偏差、11.2 的 6 日偏差、11.3 的 1 日偏差对比，11.4 的 7 日偏差属于正常偏大范围（可能反映终版发布前的额外验证工作）；r365567（Clang 10.0.0 升级）在 commits 表中未找到对应记录，与 r333688（11.2 Clang 6.0.0 升级）同样未找到，但 r296417（11.0 Clang 3.8.0）与 r348241（11.3 Clang 8.0.0 相关）均找到了 MFC commits，提示 SVN-to-Git 迁移对不同 SVN revision 编号的保留程度不一致；0 信任原则提示：tagger_date 由迁移脚本根据原始 SVN 元数据回填，可信度较高；target_commit_date = 2020-06-12T11:44:30Z 早于 tagger_date 约 4 日，反映 tag 指向的 commit 与 tag 创建之间存在 SVN 操作延迟

**要点**：

- FreeBSD 11.2 于 2018 年 6 月 27 日发布，带来 ZFS 压缩发送/接收与设备移除、面向 Intel 集成显卡的 DRM Next Kmod、OpenSSH 7.5p1 与 OpenSSL 1.0.2o 更新、LLVM 6 工具链，以及 Chelsio、Mellanox、Intel IXL 等大量网卡驱动更新。（BSD Now EP252，[63.24-246.32]，L2）
- Robert Watson 在 2008 年的帖子中指出 XNU 并非微内核，但其源码树含约 2100 万行显式标记为 BSD 的代码（主要来自 FreeBSD 并经大量修改）、约 1600 万行 Mach 代码，另有 IOKit 设备驱动与 libkern 等 Apple 自有代码，从而反驳 macOS 只是带 Apple 图形界面的 FreeBSD 这一说法。（BSD Now EP252，[3217.08-3380.68]，L1）
- Dave 的 BSDCan 2018 报告记录 Ben O'Rice 的 systemd 悲剧主题演讲与 Kirk McKusick 的 FreeBSD 治理演进演讲，后者回顾从 Jordan、Phk、Rod Grimes 时代到 Watson 时代的核心团队更替，并讨论 committer 年龄结构与社区新鲜血液。（BSD Now EP252，[2747.78-3215.62]，L1）

**史料**：
