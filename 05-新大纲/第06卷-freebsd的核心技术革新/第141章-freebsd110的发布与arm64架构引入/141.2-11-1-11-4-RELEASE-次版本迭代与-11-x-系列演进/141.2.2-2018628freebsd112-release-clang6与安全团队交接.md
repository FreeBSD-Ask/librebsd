# 141.2.2 2018.6.28 FreeBSD 11.2-RELEASE——Clang 6 与安全团队交接

**要点**：FreeBSD 11.2-RELEASE 于 2018 年 6 月 28 日发布，stable/11 第三个版本。核心更新：Clang/LLVM/lldb/compiler-rt 升级至 6.0.0；OpenSSH 7.5p1；OpenSSL 1.0.2o；libxo 更新至 0.9.0；新增 **dwatch(1)** DTrace 监控工具、**efibootmgr(8)** UEFI 引导管理工具、**etdump(1)** is Torito 引导镜像查看工具；网络驱动更新：**cxgbe(4)** Chelsio T5/T6 改进、**ixl(4)** Intel XL710 更新、新增 **mlx5io(4)** Mellanox ConnectX-5、**ocs_fw(4)** Emulex 固件接口、**smartpqi(4)** Microsemi 智能存储控制器驱动。11.2 标志着 Security Officer 团队的重要交接：Release Team 名单中 Xin Li（delphij@）标注为“Security Officer Emeritus”（荣誉安全官），Gordon Tetlow（戈登·泰特洛）（gordon@）正式接任 Security Officer，Ed Maste（埃德·马斯特）（emaste@）任 Security Officer Deputy。Colin Percival（cperciva@）虽已卸任日常 Security Officer 职务多年（Security Officer Emeritus 身份），11.2 Announcement 仍特别感谢他协助解决 Amazon EC2 相关最后时刻问题。

**史料**：FreeBSD 11.2-RELEASE Announcement（2018-06-28，Release Team 名单明确 Security Officer 交接、感谢 Colin Percival）、FreeBSD 11.2-RELEASE Release Notes（Clang 6.0.0 r333688、新工具、新驱动）、FreeBSD Security Team 页面历史；**freebsd.duckdb** `tags` 表 `freebsd-src` 仓库 release tag 数据库验证——`release/11.2.0` tagger_date = 2018-06-22T20:27:40Z，tagger_name = Glen Barber，target_commit_hash = `617bf97c016b3bd3305cd606897ead7dcc7634a1`，target_commit_date = 2018-06-21T22:59:49Z，tag_type = annotated，tag_message =“Tag releng/11.2@r335510 as release/11.2.0 (11.2-RELEASE).”，与公开声明日期 2018-06-28 相差 6 日（即 tag 创建后约 6 日才正式发布，与 11.1 的 5 日偏差、11.3 的 1 日偏差、11.4 的 7 日偏差处于同一正常范围）；**freebsd.duckdb** `commits` 表 `freebsd-src` 仓库查询 r333688（Clang 6.0.0 升级）关键字未找到对应 commit 记录，提示该 SVN revision 编号在 2020 年 SVN-to-Git 迁移时未被保留在新 commit message 中，原大纲中“Clang 6.0.0 r333688”的 SVN revision 标注无法通过 commits 表直接验证，需通过 release notes 文档记录作为辅助证据 ［A］

**史观**：总纲第 8 条——本体论上各方平等（原“社区治理”挂第 23 条系伪名目，按交接程序论旨改挂）：Security Officer 从 Colin Percival→Dag-Erling Smørgrav/Xin Li→Gordon Tetlow 的交接体现了 FreeBSD 安全团队的代际传承。Colin Percival 自 2004 年起担任 Security Officer 长达十年，是 FreeBSD 安全响应体系的主要建立者；Gordon Tetlow 长期参与 FreeBSD 安全工作，其接任保证了安全响应的连续性。Security Officer Emeritus 头衔的设置使经验丰富的前安全官能够继续以顾问身份参与。

**辨析**：11.2 中 KDE 版本号标注为 4.14.3——这是 ports 中的版本而非 base 系统组件，FreeBSD base 始终不包含 KDE/GNOME 等桌面环境，桌面环境通过 ports/pkg 提供。11.2 发布时原计划 11.1 支持至 2018.9.30（11.2 发布后三个月）。**数据库验证结论**：`release/11.2.0` tagger_date = 2018-06-22T20:27:40Z 早于公开声明日期 2018-06-28 共 6 日，符合 FreeBSD 发布工程“tag 先行、公告随后”的标准节奏；r333688（Clang 6.0.0 升级）在 commits 表中未找到对应记录，与 r365567（11.4 Clang 10.0.0 升级）同样未找到的情况一致，可能与 SVN-to-Git 迁移时这些特定 revision 编号未被保留有关，但不影响 Clang 6.0.0 升级事实本身——可通过 release notes 与 LLVM 项目发布历史交叉验证；0 信任原则提示：tagger_date 由迁移脚本根据原始 SVN 元数据回填，可信度较高；r333688 编号缺失不等于 Clang 6.0.0 未升级，仅表示无法通过 commit hash 直接关联
