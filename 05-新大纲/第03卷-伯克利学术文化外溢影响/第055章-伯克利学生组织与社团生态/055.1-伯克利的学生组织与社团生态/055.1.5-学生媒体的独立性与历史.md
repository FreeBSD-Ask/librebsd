# 055.1.5 学生媒体的独立性与历史

  **要点**：（一）The Daily Californian：The Daily Californian 成立于 **1871 年**，原为 UC Berkeley 校园报纸，**1971 年** Daily Cal 从大学独立出来，成为独立报纸（学生运营但独立于大学治理），Daily Cal 是独立的非营利组织，编辑独立于大学行政；（二）KALX 电台：KALX 电台成立于 **1962 年**，FM 90.7，由 UC Berkeley 学生运营，KALX 持有 FCC 颁发的广播执照；（三）独立性章程：Daily Cal 与 KALX 的独立性章程与历史需后续抓取 Daily Cal 与 KALX 官方章程文件或 Bancroft Library 档案核实——2026-07-25 两个官方页面均抓取超时；（四）CSRG 时期的学生媒体：CSRG 时期（1978-1992）Daily Cal 与 KALX 对 CSRG 与 BSD 的报道需查阅 Daily Cal 与 KALX 历史档案核实；（五）独立性对 CSRG 的效应：Daily Cal 与 KALX 的独立性使学生对 CSRG 相关议题（如 DARPA 资助伦理、BSD 版权争议）的报道不受大学行政干预，但 CSRG 本身未见成为 Daily Cal 或 KALX 的主要报道焦点

**史观**：第 14 章社区与文明历史哲学——项目史观总纲第 14 章 “史学含义” 原文指出 “代码与文档在本体论上地位相等，当事人的邮件、commit message、会议记录，都是历史的一部分”，学生媒体（Daily Cal、KALX）作为学生 “动手” 的产物，其报道与广播是伯克利校园历史的 “文档” 组成部分——若 CSRG 时期 Daily Cal 或 KALX 曾报道 CSRG 与 BSD 相关议题，这些报道即为 CSRG 历史的 “文档” 证据；第 10 条动手者创造历史——项目史观总纲第 14 章 14.2 节原文指出 “真正推动 BSD 的是‘Get your hands dirty’（动手去做）的人，而非旁观者”，Daily Cal 1971 年从大学独立是学生 “动手者” 在具体条件中的行动产物——学生通过具体行动争取媒体独立，而非大学行政的顶层设计。此处 “动手者” 指 “没有多余形式主义的老实人”（第 14 章 14.1 节原文：“什么是老实人？没有多余形式主义的人就是老实人”），即主体性未被理论遮蔽者，非任何阶级或经济范畴——项目史观总纲第 14 章 14.1 节明确 “决定世界的并非某个阶级，也不是什么经济，而是我们这些老实人”。依第 29 章 29.5 节 “物质决定意识不是哲学发现，而是政治建构”，把 Daily Cal 的独立性还原为 “学生阶级斗争” 或 “学生媒体劳动者争取权益” 即落入项目统摄史观所批评的形式唯物主义。本释读自反地承认自身亦为形式主义化的非存在，非对项目统摄史观的客观正确解读；第 19 条解释学循环是历史认识的根本条件——本节将 “学生媒体独立性” 与 “CSRG 运作” 关联是史家的解释学循环，CSRG 成员本人是否将 Daily Cal 与 KALX 视为影响其研究的重要因素未见明确口述记录
