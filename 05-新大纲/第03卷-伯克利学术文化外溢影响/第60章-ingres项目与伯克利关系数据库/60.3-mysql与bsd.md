# 60.3 MySQL 与 BSD：开源数据库的 FreeBSD 生态——MySQL 1995 年 Monty Widenius 发布，MySQL 在 FreeBSD 上的部署与优化，MySQL AB 的商业化与 Sun/Oracle 收购，MySQL 与 FreeBSD Ports 的共生关系

## 60.3.1 MySQL 1995 年发布与早期架构

  **要点**：MySQL 1995 年由 Michael“Monty”Widenius、David Axmark 与 Allan Larsson 在瑞典创立 MySQL AB 并发布 MySQL，MySQL 早期架构包括：（1）基于 mSQL（Mini SQL，David Hughes 开发）的 API 兼容改进而非代码派生；（2）使用 ISAM（Indexed Sequential Access Method）存储引擎（后发展为 MyISAM）；（3）支持 SQL 查询但早期版本功能简化（无事务、无外键）；（4）MySQL 采用 GPL 与商业双许可证模式（2000 年 GPL 化后确立，创立初期并非 GPL）；MySQL 名称来源于 Widenius 的女儿 My；MySQL 的早期架构反映实用主义哲学（“快与简单”优先于“完整与严格”）

## 60.3.2 MySQL 在 FreeBSD 上的部署与优化

  **要点**：MySQL 在 FreeBSD 上的部署与优化：（1）MySQL 早期用户多运行于 FreeBSD（Yahoo! 1990 年代后期运行 MySQL on FreeBSD）；（2）FreeBSD 的网络栈性能（4.4BSD-Lite 衍生）使 MySQL 在 FreeBSD 上性能优秀；（3）MySQL 在 FreeBSD 上的线程模型优化（FreeBSD 的 LinuxThreads 兼容层）；（4）MySQL 在 FreeBSD 上的部署推动 FreeBSD Ports 系统（1994 年 Jordan Hubbard 创建）的 MySQL 移植

  | Yahoo! MySQL on FreeBSD 部署 | 内容 |
| -------------------------- | -- |
| 部署时期 | 1990 年代后期 |
| FreeBSD 版本 | FreeBSD 4.x 时代 |
| 部署性质 | 关键数据库平台 |
| 选择 FreeBSD 原因 | 4.4BSD-Lite 衍生 BSD 网络栈在并发连接数与吞吐量上优于 Linux |

  | MySQL FreeBSD 线程模型演进 | FreeBSD 版本 | 线程实现 | 兼容性 |
| ------------------------ | ---------- | ------ | ---- |
| FreeBSD 5.x 之前 | — | libc_r（M: N 模型） | 与 LinuxThreads 不兼容 |
| 编译选项 | — | `-DUSE_LINUX_THREADS` | 启用 LinuxThreads 兼容 |
| FreeBSD 7.x 起 | — | libthr（1:1 模型） | 原生兼容 |

**辨析**：Yahoo! ## 60.3.3 MySQL AB 的商业化与 Sun/Oracle 收购

  **要点**：MySQL AB 的商业化与 Sun/Oracle 收购：（1）MySQL AB 1995 年由 Widenius、Axmark 与 Allan Larsson 创立（瑞典），采用 GPL + 商业双许可证模式；（2）MySQL AB 2000 年代初获得风险投资（Benchmark Capital 等）；（3）Sun Microsystems 2008 年以约 10 亿美元收购 MySQL AB；（4）Oracle 2010 年完成对 Sun 的收购，获得 MySQL，引发 MySQL 社区对 Oracle 垄断的担忧；（5）Widenius 2009 年离开 Sun，发起 MariaDB fork 以保护 MySQL 开源遗产

  | MySQL AB 商业化与收购时间线 | 时间 | 事件 |
| ------------------------- | -- | -- |
| MySQL AB 创立 | **1995 年** | Widenius、Axmark、Allan Larsson 在瑞典创立，双许可证模式（2000 年 GPL 化后确立） |
| 风险投资 | 2000 年代初 | Benchmark Capital 等 |
| Sun 收购 | **2008 年** | Sun Microsystems 以约 10 亿美元收购 MySQL AB |
| MariaDB fork | **2009 年** | Widenius 离开 Sun，发起 MariaDB fork |
| Oracle 收购 Sun | **2010 年** | Oracle 完成对 Sun 的收购，获得 MySQL |

## 60.3.4 MySQL 与 FreeBSD Ports 的共生关系

  **要点**：MySQL 与 FreeBSD Ports 的共生关系：（1）FreeBSD Ports 系统（1994 年 Jordan Hubbard 创建）使 MySQL 易于在 FreeBSD 上安装；（2）MySQL FreeBSD Port 维护者（如 The FreeBSD Ports MySQL 维护团队）持续更新 MySQL 版本；（3）MySQL 在 FreeBSD 上的部署推动 FreeBSD 在 Web 服务器市场（LAMP 栈）的应用；（4）MySQL 与 FreeBSD Ports 的共生反映开源生态的实用主义

  | FreeBSD Ports 系统创建 commit | 内容 |
| --------------------------- | -- |
| 创建者 | Jordan K. Hubbard（乔丹·哈伯德） |
| 创建时间 | **1994-08-21T13:12:57Z** |
| commit 信息 | “Commit my new ports make macros...” |
| 后续 commit | **1994-08-21T13:19:28Z**：“The start of the 2.0 ports collection” |

  | LAMP/FAMP 栈对比 | 缩写 | 组件 |
| -------------- | -- | -- |
| LAMP | Linux + Apache + MySQL + PHP/Perl/Python | Michael Kunze **1998 年** 在德国 c't Magazine 创造 |
| FAMP | FreeBSD + Apache + MySQL + PHP | FreeBSD 上的等价栈，1990 年代后期已流行 |

**史料**：FreeBSD Ports 1994 Hubbard 创建档案、MySQL FreeBSD Port 维护档案、LAMP 栈部署档案［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L1 代码/L3 官方文档〕
  
**史观**：第 9 条经验优先与第 4 条分离与聚合——MySQL（GPL）与 FreeBSD Ports（BSD）在许可证上分离，但在部署生态上聚合
  
**辨析**：FreeBSD Ports 系统创建——经 freebsd.duckdb 查询（SQL: `SELECT commit_hash, author_name, author_date, message_subject FROM commits WHERE repo_name='freebsd-ports' ORDER BY author_date ASC LIMIT 5`），Jordan K.
