# 060.0.1 史料

- [WEB:dl.acm.org ACM Curricula 1968-1981] ACM 课程建议书（一手）：Curriculum 68 奠定计算机科学学科化基础，伯克利 1967 年 7 月 1 日于文理学院设立 CS 系（同日电气工程系更名 EECS）、1968 年 EE 教师转入扩建属此浪潮 [考据完成：2026-09-12 建系口径经 EECS 官方讣闻与学术评议会纪念文联网复核校正，原“1968 年设立独立 CS 系”表述据此修正]
- [WEB:Berkeley CS History] UC Berkeley CS 系史：1967 年建系（首任系主任 Beresford Parlett，1967 年任命；原“David Hart”说经同上复核未见权威记载，予以更正）；1970s-80s BSD Unix/FFS/TCP/IP、RISC-I/II（Patterson 与 Ditzel 1980 年《The Case for the RISC》，Computer Architecture News 8(6)；Patterson 1985 年于 CACM 另有 RISC 论文）——CSRG 学术成就主线；图灵奖得主 Michael Stonebraker（Ingres/Postgres 数据库研究）与伯克利 CS 的交集
- [WEB:mckusick.com/articles.html] McKusick 论文总目录（一手）：CSRG 核心产出文献链——FFS（4.2BSD fast filesystem）、Soft Updates（TOCS 2000）、《The Design and Implementation of the 4.4BSD Operating System》（1996 Addison Wesley）等学术发表记录
