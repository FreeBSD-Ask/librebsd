# 064.4.3 主持人所在的非营利机构按每年更换四分之一机器的节奏滚动更新设备恰逢Vista默认

- 主持人所在的非营利机构按每年更换四分之一机器的节奏滚动更新设备，恰逢 Vista 默认启用 IPv6，加之微软市场份额使任何其默认开启的协议迅速进入组织议程，促使他在 2007 年年中提前组建 IPv6 测试网络。（BSDTalk EP119，[145.4-226.6]，L1）
- 实验以一台双网卡的 OpenBSD 机器充当路由器，启用路由通告守护进程后，两侧网络的工作站自动获得 2001 开头的全局单播地址并可跨路由器互通；其间需手动通过 sysctl 打开 IPv6 转发，且为验证起见刻意只转发 IPv6 流量。（BSDTalk EP119，[445.04-539.2]，L1）
- 因其 ISP 与在用的商用防火墙均不支持 IPv6，主持人改用 Hurricane Electric 的 tunnelbroker.net 服务，把 IPv6 包封装进 IPv4 载荷建立隧道，注册即获得一段地址块；该网站还能按所选操作系统自动生成示例配置命令，接入后再启用转发即可自动路由。（BSDTalk EP119，[565.04-666.4]，L1）
- IPv6 地址对人不可记忆，使 DNS 从辅助服务上升为网络关键基础设施；路由通告机制并未覆盖 DNS 服务器分发，业界在让路由通告携带 DNS 与采用 DHCPv6 之间摇摆，微软则选择了互联网草案中的站点本地 DNS 地址方案，每台 Vista 工作站自动预配三个默认解析地址。（BSDTalk EP119，[694.6-793.76]，L1）
- OpenBSD 默认安装 BIND，其自带配置文件稍加修改即可充当递归解析服务，只需令其同时侦听站点本地 DNS 地址，Vista 客户端便立即完成解析上网；主持人由此判断以 OpenBSD 承载网络基础设施的配置成本相当低。（BSDTalk EP119，[793.76-878.88]，L1）
