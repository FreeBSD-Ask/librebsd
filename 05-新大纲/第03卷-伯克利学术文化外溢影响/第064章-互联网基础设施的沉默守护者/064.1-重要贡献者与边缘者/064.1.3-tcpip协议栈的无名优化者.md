# 064.1.3 TCP/IP 协议栈的无名优化者

  **要点**：TCP/IP 协议栈的无名优化者包括：（1）BBN 的 Jack Haverty 等实现原始 TCP/IP 代码；（2）CSRG 的 Joy 与 Leffler 优化 4.2BSD TCP/IP；（3）4.3BSD 的网络代码优化贡献者（如 Sam Leffler 的网络驱动优化）；（4）Internet Initiative Japan（IIJ）的 Suzuki 等日本贡献者优化 BSD TCP/IP；（5）这些无名优化者的贡献多隐藏在源码注释与提交记录中

  | TCP/IP 协议栈的无名优化者 | 机构 | 贡献 |
| ----------------------- | -- | -- |
| Jack Haverty 等 | BBN | 实现原始 TCP/IP 代码 |
| Bill Joy | CSRG | 优化 4.2BSD TCP/IP（VAX 汇编部分、mbuf 内存缓冲管理） |
| Sam Leffler | CSRG | 优化 4.2BSD TCP/IP（网络驱动与中断处理、设备无关网络接口层） |
| 4.3BSD 贡献者 | CSRG | 网络代码优化（如 Leffler 的网络驱动优化） |
| Suzuki 等 | Internet Initiative Japan（IIJ） | 日本贡献者优化 BSD TCP/IP |

  | IIJ 关键要素 | 内容 |
| ---------- | -- |
| 全称 | Internet Initiative Japan |
| 成立 | **1992 年**（日本首家 ISP） |
| 贡献者 | Suzuki 等日本贡献者 |
| 贡献时期 | 1990 年代 |
| 贡献内容 | BSD 网络代码优化（具体贡献保留 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］） |
