# 064.3.3 Solaris 的 Netscape 服务器路径

  **要点**：Solaris（Sun Microsystems 1992 发布 Solaris 2.0）的 Netscape 服务器路径：（1）Netscape（1994 年 Marc Andreessen 与 Jim Clark 创立）发布 Netscape Enterprise Server；（2）Solaris 与 Netscape 在企业 Web 服务器市场形成商业组合；（3）Sun 与 Netscape 的合作（1998 年 12 月宣布联盟）强化 Solaris+Netscape 路径；（4）1999 年 Sun 收购 Netscape 服务器业务，但 Solaris+Netscape 路径最终被 Linux+Apache 超越

  | Solaris 与 Netscape 时间线 | 时间 | 事件 |
| ------------------------ | -- | -- |
| Solaris 2.0 发布 | **1992 年** | Sun Microsystems，基于 SunOS 4.x 衍生为 SVR4 |
| Netscape 创立 | **1994 年 4 月** | Marc Andreessen 与 Jim Clark 创立，原名 Mosaic Communications Corporation |
| Netscape Enterprise Server | 1990 年代 | 发布企业 Web 服务器 |
| Sun-Netscape 联盟 | **1998 年 12 月** | Sun 与 Netscape 宣布联盟，强化 Solaris+Netscape 路径 |
| Sun 收购 Netscape 服务器业务 | **1999 年 3 月** | Sun 与 Netscape 宣布联盟 |
| 最终结局 | 2000 年代 | Solaris+Netscape 路径被 Linux+Apache 超越 |

  | Solaris+Netscape 与 Linux+Apache 对比 | Solaris+Netscape | Linux+Apache |
| ----------------------------------- | -------------- | ---------- |
| 性质 | 商业组合 | 开源组合 |
| 市场 | 企业 Web 服务器市场 | 通用 Web 服务器市场 |
| 最终结局 | 被超越 | 主导 |
