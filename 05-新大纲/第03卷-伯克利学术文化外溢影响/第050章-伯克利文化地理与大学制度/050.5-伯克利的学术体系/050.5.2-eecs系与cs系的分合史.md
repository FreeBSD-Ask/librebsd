# 050.5.2 EECS 系与 CS 系的分合史

  **要点**：伯克利 EECS 系（Electrical Engineering and Computer Sciences）由原 EE 系（电气工程）与 CS 系（计算机科学）于 **1973 年** 合并而成，但内部保留 EE 与 CS 两个分支，CSRG 隶属 EECS 系，CSRG 成员（如 Fabry、McKusick）跨越 EE 与 CS 边界，此合并使 BSD 硬件相关研究（VAX、SPARC 移植）与软件研究（内核、网络）形成组织协同

  | 系所 | 学科分支 | 与 CSRG 的关系 |
| -- | ------ | ------------ |
| 原 EE 系（电气工程） | 硬件研究 | BSD 硬件相关研究（VAX、SPARC 移植） |
| 原 CS 系（计算机科学） | 软件研究 | BSD 软件研究（内核、网络） |
| EECS 系（**1973 年** 合并） | 内部保留 EE 与 CS 两个分支 | CSRG 隶属 EECS 系 |
| CSRG 成员跨越边界 | Fabry、McKusick 等 | 形成 BSD 硬件-软件组织协同 |

**史料**：EECS 系合并档案（**1973**）、EECS 系组织章程、CSRG 在 EECS 系内的定位记录 ［A］
  
**史观**：第 4 条分离与聚合——EE 与 CS 在学科上分离（硬件 vs 软件），但在 EECS 系的组织上聚合，BSD 的硬件-软件协同开发正是此分离与聚合的产物
  
**辨析**：EECS 合并的具体时间（1973 年）需核对伯克利 EECS 系史；CSRG 在 EECS 系内的行政归属需核对；EE 与 CS 分支的具体关系需核对
