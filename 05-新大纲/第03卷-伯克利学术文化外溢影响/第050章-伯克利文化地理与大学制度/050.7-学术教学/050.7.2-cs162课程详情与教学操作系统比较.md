# 050.7.2 CS162 课程详情与教学操作系统比较

  **要点**：CS162（操作系统与系统编程）是伯克利 OS 教学的核心课程，CSRG 时期学生须实现 BSD 内核子系统（如文件系统、进程调度），教学项目先后使用 TOY 操作系统〔存疑：“Ken Thompson **1973 年** 开发”缺乏一手佐证——1973 年 Thompson 系贝尔实验室雇员，**1975-1976 年** 方在伯克利休假，TOY 的作者与年代待按伯克利 CS 系教学档案核正〕与 Nachos（**1993 年** 左右引入）；CS162 直接使用真实生产 OS（BSD）作为教学案例，反映了伯克利 “真实系统教学” 传统；MIT 6.828（**2002 年秋季** 首次开设，晚于 CSRG 解散）与 Stanford CS140（使用 Pintos 教学 OS）的对比为回溯性比较，非 CSRG 时期的历史事实

  | 课程 | 学校 | 教学项目 | 备注 |
| -- | -- | ------ | -- |
| CS162 | 伯克利 | TOY 操作系统〔存疑：作者与年代待核，见要点〕→ Nachos（**1993 年** 左右引入）；CSRG 时期学生须实现 BSD 内核子系统 | 直接使用真实生产 OS（BSD）作为教学案例 |
| 6.828 | MIT | 后续教学操作系统 | **2002 年秋季** 首次开设，晚于 CSRG 解散（回溯性比较） |
| CS140 | Stanford | Pintos 教学 OS | 回溯性比较 |
