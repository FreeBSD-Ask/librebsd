# 050.7.1 伯克利 CS 本科课程体系

  **要点**：伯克利 CS 本科课程体系以 CS61A（计算机程序设计与解释，基于 SICP《计算机程序的构造和解释》**1985 年** 由 Abelson 与 Sussman 编写）、CS61B（数据结构）、CS61C（计算机组成原理）、CS70（离散数学与概率论）为基础四课，CS162（操作系统与系统编程）为操作系统核心课程，CS164（编译器）、CS170（算法）等为高阶课程，此体系与 BSD 教学载体的关联在于 CS162/CS164 等课程使用 BSD 作为实验平台

| ---- | ---- | -- |
| CS61A | 计算机程序设计与解释（基于 SICP《计算机程序的构造和解释》**1985 年** 由 Abelson 与 Sussman 编写） | 基础四课 |
| CS61B | 数据结构 | 基础四课 |
| CS61C | 计算机组成原理 | 基础四课 |
| CS70 | 离散数学与概率论 | 基础四课 |
| CS162 | 操作系统与系统编程 | 操作系统核心课程 |
| CS164 | 编译器 | 高阶课程 |
