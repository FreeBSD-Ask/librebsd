# 050.2.1 旧金山湾区的地理优势

  **要点**：伯克利地处旧金山湾东岸，与硅谷（**1971 年** “Silicon Valley” 一词首见报端）隔湾相望，与旧金山形成 “学术 + 商业 + 文化” 三角，湾区地理优势使伯克利吸引来自硅谷的硬件资源（DEC VAX、Sun 工作站捐赠）与商业反馈（Sun、Mt Xinu 等基于 BSD 的商业公司），形成学术与商业的地理互嵌

  | 湾区地理节点 | 角色 | 与伯克利的地理关系 |
| ---------- | -- | ---------------- |
| 伯克利 | 学术（CSRG） | 旧金山湾东岸 |
| 硅谷 | 商业（Sun、Mt Xinu 等基于 BSD 的公司） | 隔湾相望 |
| 旧金山 | 文化 | 形成 “学术 + 商业 + 文化” 三角 |
| 硬件资源 | DEC VAX、Sun 工作站捐赠 | 来自硅谷 |
