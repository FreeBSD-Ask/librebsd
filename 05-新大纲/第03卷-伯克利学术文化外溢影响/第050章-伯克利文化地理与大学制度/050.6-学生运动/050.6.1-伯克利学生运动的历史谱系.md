# 050.6.1 伯克利学生运动的历史谱系

  **要点**：伯克利学生运动的历史谱系包括：1930 年代学生罢课（反对学校开除抗议学生）、**1964-1965 年** 自由言论运动（FSM，Mario Savio 领导）、**1968-1969 年** 第三世界解放阵线（TWLF）争取建立种族研究系、**1969 年** 人民公园事件、**1970 年** 反越战罢课（柬埔寨入侵后全国罢课）、**1985 年** 反种族隔离撤资运动、**1999 年** TWLF 第二波罢课，此谱系形成伯克利学生运动的连续传统

  | 时间 | 学生运动 | 关键人物/诉求 |
| -- | ------ | ----------- |
| 1930 年代 | 学生罢课 | 反对学校开除抗议学生 |
| **1964-1965 年** | FSM（自由言论运动） | Mario Savio 领导 |
| **1968-1969 年** | TWLF（第三世界解放阵线） | 争取建立种族研究系 |
| **1969 年** | 人民公园事件 | 详见 22.9 |
| **1970 年** | 反越战罢课 | 柬埔寨入侵后全国罢课 |
| **1985 年** | 反种族隔离撤资运动 | Anti-Apartheid Divestment Movement |
| **1999 年** | TWLF 第二波罢课 | 晚于 CSRG 时期 |

**史观**：第 5 条没有必然性，只有偶然性——伯克利学生运动的连续传统是多重偶然事件（FSM、TWLF、人民公园等）叠加的产物，每一波运动为下一波积累文化与组织资源
  
**辨析**：每一波运动的具体时间、领导人与诉求需核对原始档案；谱系的连续性需避免事后建构，需核对各波运动之间的实际传承关系；1999 年 TWLF 第二波晚于 CSRG 时期，须明确区分
