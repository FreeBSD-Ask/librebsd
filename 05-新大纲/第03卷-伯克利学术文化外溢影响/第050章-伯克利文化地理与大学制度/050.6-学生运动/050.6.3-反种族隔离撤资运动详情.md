# 050.6.3 反种族隔离撤资运动详情

  **要点**：**1985 年** 反种族隔离撤资运动（Anti-Apartheid Divestment Movement）是伯克利学生对南非种族隔离政策的抗议，诉求加州大学从在南非经营的跨国公司撤资，运动包括学生占领 Sproul 广场、搭建 “shantytown”（棚户区）模拟南非黑人居住条件，**1986 年** 加州大学董事会同意部分撤资，此运动是 1980 年代全美反种族隔离运动的一部分

  | 反种族隔离撤资运动要素 | 内容 |
| -------------------- | -- |
| 时间 | **1985 年** 开始 |
| 诉求 | 加州大学从在南非经营的跨国公司撤资 |
| 行动 | 占领 Sproul 广场、搭建 “shantytown”（棚户区）模拟南非黑人居住条件 |
| 结果 | **1986 年** 加州大学董事会同意部分撤资 |
| 历史地位 | 1980 年代全美反种族隔离运动的一部分 |
