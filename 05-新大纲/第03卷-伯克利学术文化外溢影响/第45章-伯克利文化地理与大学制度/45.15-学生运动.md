# 45.15 学生运动：伯克利学生运动的历史谱系与 CSRG 文化

## 45.15.1 伯克利学生运动的历史谱系

  **要点**：伯克利学生运动的历史谱系包括：1930 年代学生罢课（反对学校开除抗议学生）、**1964-1965 年** 自由言论运动（FSM，Mario Savio 领导）、**1968-1969 年** 第三世界解放阵线（TWLF）争取建立种族研究系、**1969 年** 人民公园事件、**1970 年** 反越战罢课（柬埔寨入侵后全国罢课）、**1985 年** 反种族隔离撤资运动、**1999 年** TWLF 第二波罢课，此谱系形成伯克利学生运动的连续传统

  | 时间 | 学生运动 | 关键人物/诉求 |
| -- | ------ | ----------- |
| 1930 年代 | 学生罢课 | 反对学校开除抗议学生 |
| **1964-1965 年** | FSM（自由言论运动） | Mario Savio 领导 |
| **1968-1969 年** | TWLF（第三世界解放阵线） | 争取建立种族研究系 |
| **1969 年** | 人民公园事件 | 详见 22.9 |
| **1970 年** | 反越战罢课 | 柬埔寨入侵后全国罢课 |
| **1985 年** | 反种族隔离撤资运动 | Anti-Apartheid Divestment Movement |
| **1999 年** | TWLF 第二波罢课 | 晚于 CSRG 时期 |

**史观**：第 5 条没有必然性，只有偶然性——伯克利学生运动的连续传统是多重偶然事件（FSM、TWLF、人民公园等）叠加的产物，每一波运动为下一波积累文化与组织资源

## 45.15.2 TWLF 1969 年罢工详情

  **要点**：第三世界解放阵线（Third World Liberation Front, TWLF）**1969 年** 罢工是伯克利历史上最长的学生罢课，TWLF 由非裔、亚裔、拉美裔、原住民学生组织联合组成，诉求建立种族研究系（Ethnic Studies Department）与亚裔美国人研究系，罢课持续约 10 周（**1969 年 1-3 月**），最终校方妥协成立种族研究系，此罢工直接影响伯克利的多元化政策

  | TWLF 罢工要素 | 内容 |
| ----------- | -- |
| 时间 | **1969 年 1-3 月**（持续约 10 周） |
| 历史地位 | 伯克利历史上最长的学生罢课 |
| TWLF 组成 | 非裔、亚裔、拉美裔、原住民学生组织联合 |
| 诉求 | 建立种族研究系（Ethnic Studies Department）与亚裔美国人研究系 |
| 结果 | 校方妥协成立种族研究系（**1969 年**） |
| 影响 | 直接影响伯克利的多元化政策 |

**史料**：TWLF **1969 年** 罢工档案、罢工传单与标语、校方与 TWLF 谈判记录、种族研究系成立档案（**1969**）［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档与公告〕

## 45.15.3 反种族隔离撤资运动详情

  **要点**：**1985 年** 反种族隔离撤资运动（Anti-Apartheid Divestment Movement）是伯克利学生对南非种族隔离政策的抗议，诉求加州大学从在南非经营的跨国公司撤资，运动包括学生占领 Sproul 广场、搭建 “shantytown”（棚户区）模拟南非黑人居住条件，**1986 年** 加州大学董事会同意部分撤资，此运动是 1980 年代全美反种族隔离运动的一部分

  | 反种族隔离撤资运动要素 | 内容 |
| -------------------- | -- |
| 时间 | **1985 年** 开始 |
| 诉求 | 加州大学从在南非经营的跨国公司撤资 |
| 行动 | 占领 Sproul 广场、搭建 “shantytown”（棚户区）模拟南非黑人居住条件 |
| 结果 | **1986 年** 加州大学董事会同意部分撤资 |
| 历史地位 | 1980 年代全美反种族隔离运动的一部分 |

**史料**：**1985 年** 伯克利反种族隔离撤资运动档案、shantytown 占领记录、加州大学董事会撤资决议（**1986**）、学生传单与标语［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档与公告〕
  
**史观**：第 10 条动手者创造历史——学生作为边缘群体，通过直接行动（搭建 shantytown）迫使大学改变投资政策，边缘者的行动塑造了大学的金融结构
  
**辨析**：撤资运动的具体时间（1985 年开始）需核对；加州大学董事会的撤资决议（1986 年）的具体条款需核对；“部分撤资” 的范围需核对
  
**文献**：1985 年伯克利反种族隔离撤资运动档案；加州大学董事会 1986 年撤资决议；Massie, R. K. (1997) "Loosing the Bonds: The United States and South Africa in the Apartheid Years"［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］

## 45.15.4 学生运动与 CSRG 文化的关系

  **要点**：学生运动与 CSRG 文化的关系是间接但深刻的：FSM 的 “言论自由” 与反权威精神为 CSRG 的 hacker 伦理提供文化土壤；TWLF 的 “边缘者发声” 为 CSRG 的开源共享传统提供道德资源；人民公园事件的反私有化抗争为 BSD 的 “自由许可” 提供政治隐喻（关联强度需谨慎，见辨析）；CSRG 成员（如 Joy、McKusick）多为 1970 年代入学，亲历反越战罢课与人民公园后续影响，其反权威倾向受学生运动塑造

  | 学生运动 | 对 CSRG 文化的影响 |
| ------ | ---------------- |
| FSM | “言论自由” 与反权威精神为 CSRG hacker 伦理提供文化土壤 |
| TWLF | “边缘者发声” 为 CSRG 开源共享传统提供道德资源 |
| 人民公园事件 | 反私有化抗争为 BSD “自由许可” 提供政治隐喻 |
| 反越战罢课 | CSRG 成员亲历后续影响，反权威倾向受塑造 |

**史料**：CSRG 成员的学生时代记录、Joy/McKusick 关于学生运动的回忆、CSRG 文化与学生运动的关联分析 ［B］
  
**史观**：第 9 条经验优先与第 5 条没有必然性，只有偶然性——CSRG 的 hacker 伦理实践先于其理论表述，学生运动的偶然文化土壤塑造了 CSRG 文化的实践形态
  
**辨析**：CSRG 成员亲历学生运动的具体情况需核对（Joy 1975 年入伯克利、McKusick 1970 年代末入学，二人是否亲历 FSM 与人民公园需核对）；“反私有化” 与 “自由许可” 的关联需谨慎，避免事后建构
  
**文献**：Joy/McKusick 回忆录；CSRG 文化档案；Rorabaugh, W. J. (1989) “Berkeley at War: The 1960s” ［B］

## 45.15.5 学生运动对大学治理的效应

  **要点**：学生运动对伯克利大学治理产生深远影响：FSM 后学生获得校内言论自由权利；TWLF 后学生代表进入部分校方委员会；反越战罢课后校方对联邦军事研究（如 DARPA 资助）的透明度要求提高；反种族隔离撤资运动后学生参与大学投资政策；此治理影响间接塑造了 CSRG 的运作环境（如 DARPA 资助的透明度要求使 CSRG 须向校方报告）

  | 学生运动 | 对大学治理的效应 | 对 CSRG 的间接影响 |
| ------ | -------------- | ---------------- |
| FSM | 学生获得校内言论自由权利 | — |
| TWLF | 学生代表进入部分校方委员会 | — |
| 反越战罢课 | 校方对联邦军事研究（如 DARPA 资助）的透明度要求提高 | CSRG 须向校方报告 |
| 反种族隔离撤资运动 | 学生参与大学投资政策 | — |

**史料**：FSM 后校方言论自由政策、TWLF 后学生代表制度、反越战罢课后 DARPA 透明度要求、反种族隔离撤资运动后学生参与投资政策［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档与公告〕
  
**史观**：第 2 条历史是形式主义化的非存在——学生参与大学治理的形式逻辑（学生代表）吞并了实质的权力关系，学生代表形式上参与但实质上权力有限，形式与实质存在张力
  
**辨析**：学生代表的具体权力范围需核对校方章程；DARPA 透明度要求的具体内容需核对 CSRG 报告档案；学生运动对 CSRG 的间接影响需谨慎关联
