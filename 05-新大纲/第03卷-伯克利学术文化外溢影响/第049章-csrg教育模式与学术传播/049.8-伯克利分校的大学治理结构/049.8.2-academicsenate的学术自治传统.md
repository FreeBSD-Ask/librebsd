# 049.8.2 Academic Senate 的学术自治传统

  **要点**：加州大学 Academic Senate 由教授组成，拥有学术政策、课程设置、教师晋升等学术事务的决策权，Academic Senate 的学术自治传统使 CSRG 在研究方向上有较大自主权，不受校方行政干预

  | Academic Senate 职权范围 | 内容 |
| ---------------------- | -- |
| 学术政策 | 教授组成的决策机构 |
| 课程设置 | 学术事务决策权 |
| 教师晋升 | 学术事务决策权 |
| 对 CSRG 的效应 | 研究方向上较大自主权，不受校方行政干预 |

**史料**：加州大学 Academic Senate 章程、Academic Senate 历史档案、CSRG 与 Academic Senate 的关系记录 ［A］
  
**史观**：第 4 条分离与聚合——Academic Senate 将学术决策（分离）与行政决策（聚合）辩证统一，分离与聚合的辩证统一保障 CSRG 学术自主
  
**辨析**：Academic Senate 的 “实际权力” 需核对，避免事后夸大，需核对实际决策记录
  
**文献**：加州大学 Academic Senate 章程；Academic Senate 档案；Douglass, J. (2007) “The California Idea and American Higher Education” ［A］
