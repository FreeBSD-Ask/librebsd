# 049.5.2 FSM 对 CSRG 文化的潜在效应

  **要点**：伯克利自由言论运动（Free Speech Movement, FSM，**1964-1965**）由 **Mario Savio（马里奥·萨维奥）** 领导，主张学生政治言论自由，FSM 的 “质疑权威” 精神可能影响 CSRG 文化的反权威倾向，但 CSRG 成员多在 FSM 后期入学，影响为潜在而非直接

  | 时间 | FSM 事件 | CSRG 成员入学 |
| -- | ------ | ----------- |
| **1964-1965** | FSM 由 Mario Savio 领导 | — |
| **1970 年代末** | FSM 后期 | Joy（**1975**）、McKusick（**1976**）等入学 |
| 影响性质 | 潜在（非直接） | “质疑权威” 精神可能影响 CSRG 反权威倾向 |

**史观**：第 5 条偶然性——FSM 对 CSRG 文化的影响是潜在的，若 FSM 未发生，CSRG 文化可能不同，但因果关系难以确证
  
**辨析**：FSM 影响的 “直接性” 需核对，CSRG 成员未必直接参与 FSM，需区分 “时代氛围影响” 与 “直接参与”
