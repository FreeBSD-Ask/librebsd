# 049.4.1 BSD 论文的学术传播路径

  **要点**：BSD 论文的学术传播路径包括：伯克利 CSRG 技术报告（如 CSRG TR）、USENIX 会议论文、ACM 操作系统评论（OSR）、IEEE Transactions on Software Engineering，Joy 的 4.2BSD 论文（1983）、McKusick 的 FFS 论文（1984）等成为高引用文献
  
**史料**：CSRG 技术报告清单、USENIX 会议论文集（1980-1995）、ACM OSR 期刊、IEEE TSE 期刊 ［B］
  
**史观**：总纲第 4 条分离聚合是永恒规律——论文传播将 BSD 代码（聚合）转化为学术论文（分离），分离的论文扩大 BSD 影响力
  
**辨析**：论文传播的 “具体路径” 需核对，部分 BSD 代码未发表对应论文，需区分 “代码发布” 与 “论文发表”。经参考文献库核查：McKusick、Joy、Leffler、Fabry（1984）《A Fast File System for UNIX》ACM TOCS 2(3):181-197（reference_id=20）确证 McKusick 的 FFS 论文发表于 1984 年，为本节“McKusick 的 FFS 论文（1984）”提供库内证据；Joy 的 4.2BSD 相关论文（1983）两库未收录原文，保留原考据
  
**文献**：CSRG 技术报告；USENIX 会议论文集；McKusick, K. (1984) “A Fast File System for UNIX” ［B］
