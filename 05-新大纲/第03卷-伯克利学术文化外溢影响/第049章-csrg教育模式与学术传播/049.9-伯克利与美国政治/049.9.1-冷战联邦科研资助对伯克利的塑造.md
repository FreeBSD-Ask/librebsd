# 049.9.1 冷战联邦科研资助对伯克利的塑造

  **要点**：冷战时期联邦科研资助对伯克利的塑造为：DARPA（**1958 年** 成立）持续资助伯克利计算机科学（含 CSRG 的 BSD 开发）、NSF 资助学术基础设施、ONR 资助海军相关研究、DOE（继承 AEC）资助劳伦斯伯克利国家实验室，多元资助体系使伯克利形成 “联邦资助 + 学术自治” 的科研模式

  | 联邦资助方 | 资助领域 | 前身/继承 |
| -------- | ------ | ------- |
| DARPA | 伯克利计算机科学（含 CSRG 的 BSD 开发） | 前身 ARPA，**1958 年** 成立 |
| NSF | 学术基础设施 | — |
| ONR | 海军相关研究 | — |
| DOE | 劳伦斯伯克利国家实验室（LBNL） | 继承 AEC 原子能委员会 |

**史料**：DARPA 资助伯克利的合同记录、NSF 资助记录、ONR 资助记录、DOE/LBNL 资助记录 ［A］
  
**史观**：第 5 条偶然性——冷战联邦资助是地缘政治偶然事件，但此偶然资助塑造伯克利科研模式
  
**辨析**：联邦资助的 “具体金额” 需核对，避免事后夸大，需核对合同记录
