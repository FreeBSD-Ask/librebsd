# 049.9.2 1964-1965 年自由言论运动

  **要点**：**1964-1965 年** 伯克利自由言论运动（FSM）由 **Mario Savio（马里奥·萨维奥）** 领导，起因为校方禁止学生在校园进行政治宣传活动，FSM 占领 Sproul Hall、组织罢课，**1964 年 12 月** 800 余人被捕，**1965 年** 校方让步允许学生政治活动，FSM 成为 1960 年代美国学生运动标志

  | 时间 | FSM 关键事件 |
| -- | ---------- |
| **1964-1965 年** | FSM 由 Mario Savio 领导 |
| 起因 | 校方禁止学生在校园进行政治宣传活动 |
| 行动 | 占领 Sproul Hall、组织罢课 |
| **1964 年 12 月** | 800 余人被捕 |
| **1965 年** | 校方让步允许学生政治活动 |
| 历史地位 | 1960 年代美国学生运动标志 |
