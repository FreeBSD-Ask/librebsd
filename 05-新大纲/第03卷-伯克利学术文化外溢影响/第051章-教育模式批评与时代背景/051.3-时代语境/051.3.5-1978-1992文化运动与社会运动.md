# 051.3.5 1978-1992 文化运动与社会运动

  **要点**：1978-1992 文化运动与社会运动包括：（1）反文化运动延续（嬉皮士、New Age 运动）；（2）反核运动（**1979** 三里岛核事故后强化）；（3）反种族隔离运动（**1985** 伯克利撤资运动，详见 22.15）；（4）女权运动第二波与第三波过渡（**1980 年代**）；（5）LGBT 权利运动（**1969** 石墙起义后续，**1980 年代** AIDS 危机）；（6）环保运动（**1970** 地球日后续，**1987** 蒙特利尔议定书）；此运动谱系为 CSRG 的 hacker 伦理与开源共享传统提供文化土壤

  | 运动 | 时间 | 关键事件 | 与 CSRG 关联 |
| -- | -- | ------ | ---------- |
| 反文化运动 | **1960 年代** 起 | 嬉皮士、New Age 运动（**1970 年代后期** 起） | 反权威文化土壤 |
| 反核运动 | **1979.3.28** 后强化 | 三里岛核事故，**1982.6.12** 纽约百万人反核集会 | 技术风险反思 |
| 反种族隔离运动 | **1985** | 伯克利撤资运动（校方从南非相关公司撤资） | 学生运动氛围 |
| 女权运动 | **1960-1980 年代**/1990 年代起 | 第二波与第三波过渡期 | — |
| LGBT 权利运动 | **1969.6** 石墙起义后续 | **1981** AIDS 危机，**1987** ACT UP 成立 | 边缘者共鸣 |
| 环保运动 | **1970.4.22** 首届地球日 | **1987.9.16** 蒙特利尔议定书签署 | 技术责任反思 |
