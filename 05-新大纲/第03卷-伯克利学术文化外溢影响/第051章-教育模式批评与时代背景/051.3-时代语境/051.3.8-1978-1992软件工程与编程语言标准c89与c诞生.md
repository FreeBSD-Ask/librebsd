# 051.3.8 1978-1992 软件工程与编程语言标准：C89 与 C++ 诞生

  **要点**：1978-1992 软件工程与编程语言标准：（1）C 语言标准化（ANSI C，**1989 年** 发布 C89，ISO **1990 年** 采纳为 ISO/IEC 9899:1990）；（2）C++ 诞生（Bjarne Stroustrup（本贾尼·斯特劳斯特鲁普） **1979 年** 开始开发 “C with Classes”，**1984 年** 正式命名 C++，**1985 年 10 月** 发布 Cfront 1.0 首个商业版本）；（3）Objective-C 诞生（Brad Cox **1984 年** 发布）；（4）软件工程方法论（Yourdon 结构化方法、Booch OOD 方法）；此标准化进程影响 BSD 代码的 C 语言风格

  | 语言/标准 | 起源时间 | 关键事件 | 与 BSD 关系 |
| ------- | ------ | ------ | --------- |
| K&R C | **1978** | Kernighan & Ritchie《The C Programming Language》第一版 | 4.2BSD（**1983**）、4.3BSD（**1986**）使用 K&R C 风格 |
| C89（ANSI X3.159-1989） | **1989 年 12 月 14 日** | ANSI 批准发布 | CSRG 后期代码逐步采纳函数原型 |
| ISO/IEC 9899:1990 | **1990** | ISO 采纳 C89 为国际标准 | — |
| C with Classes → C++ | **1979/1983-1984** | Stroustrup 开发，**1983.10** 命名 C++ | — |
| Cfront 1.0 | **1985 年 10 月** | 首个 C++ 编译器（C++ 到 C 翻译） | — |
| Objective-C | **1984 年 6 月** | Brad Cox 发布，1988 年 NeXT 获授权 | 后成为 NeXTSTEP/macOS 核心语言 |

**史料**：ANSI C89 标准（**1989**）、ISO/IEC 9899:1990、Stroustrup C++ 论文与 Cfront 1.0（**1985**）、Cox Objective-C（**1984**）、软件工程方法论文献 ［B］
  
**史观**：第 9 条经验优先——BSD 的 C 代码实践（1978 年起）先于 C89 标准（1989），实践先于理论，C89 标准化反过来影响 BSD 后续代码风格
  
**辨析**：C89 发布时间 1989 年 12 月经 ANSI 档案确认——ANSI X3.159-1989 于 1989 年 12 月 14 日批准发布，ISO 1990 年采纳为 ISO/IEC 9899:1990；C++ 命名时间存在史料分歧——Stroustrup 1979 年开始开发 “C with Classes”，1983 年 10 月（部分史料记为 1984 年）正式命名为 C++（保留 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 区分 “命名决策” 与 “公开发表”），Cfront 1.0 于 1985 年 10 月发布为首个 C++ 编译器（实现 C++ 到 C 的翻译）；Objective-C 发布 1984 年 6 月经 Brad Cox 与 Stepstone 公司档案确认——Cox 1984 年发表 “Object-Oriented Programming: An Evolutionary Approach” 并发布 Objective-C 首个实现；BSD 代码风格与 C89 的关系——BSD 4.2BSD（1983）与 4.3BSD（1986）使用 K&R C 风格（Kernighan & Ritchie 1978 年 “The C Programming Language” 第一版），CSRG 后期代码（4.4BSD-Lite 1994）逐步采纳 ANSI C 函数原型与特征，但 CSRG 解散前未完全迁移至 C89 标准
