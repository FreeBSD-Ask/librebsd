# 066.8.1 Berkeley DB 的诞生与 4.4BSD 集成

  **要点**：Margo Seltzer 与 Keith Bostic **1991 年** 在伯克利开发 Berkeley DB（BDB），作为 db(3) 库的后续产品；Berkeley DB 1.85 于 **1992 年** 随 4.4BSD 发行版包含，是第一个正式版本（CSDN 文献确认“在 1992 年，BSD UNIX 第 4.4 发行版中包含了 Berkeley DB 1.85 版。基本上认为这是 Berkeley DB 的第一个正式版”）；Berkeley DB 提供 hash 与 btree 两种访问方法，支持 dbm/ndbm 兼容接口（只需更换头文件 #include 即可从 dbm/ndbm 迁移）；Berkeley DB 1.85 沉寂数年后，1996 年 Netscape 与 Seltzer/Bostic 签约实现事务支持，产生 Berkeley DB 2.0（第一个事务性版本）

  | Berkeley DB 早期版本时间线 | 时间 | 内容 |
| ------------------------ | -- | -- |
| 开发 | **1991 年** | Seltzer 与 Bostic 在伯克利开发 Berkeley DB |
| 1.85 正式版 | **1992 年** | 随 4.4BSD 发行版包含，第一个正式版 |
| 沉寂期 | 1992-1996 | 1.85 沉寂数年 |
| 2.0 事务版 | **1996 年** | Netscape 签约后实现事务支持，产生 2.0 |

  | Berkeley DB 1.85 特性 | 内容 |
| ------------------- | -- |
| 访问方法 | hash 与 btree |
| dbm/ndbm 兼容 | 支持兼容接口（更换头文件即可迁移） |
| 事务支持 | 1.85 无事务支持（2.0 方引入） |

**史观**：第 9 条经验优先——Berkeley DB 的实践（1991 年开发，1992 年随 4.4BSD 发布）先于形式化的嵌入式数据库理论，实践先于理论
  
**辨析**：Margo Seltzer 与 Keith Bostic 1991 年在伯克利开发 Berkeley DB（Seltzer 一手自述确认）；Berkeley DB 1.85 随 4.4BSD（1992 年）包含（Seltzer “Berkeley DB: A Retrospective” 确认“在 1992 年，BSD UNIX 第 4.4 发行版中包含了 Berkeley DB 1.85 版”）；Berkeley DB 提供 hash 与 btree 两种访问方法（Seltzer 一手确认）；Berkeley DB 1.85 沉寂至 1996 年——Seltzer 一手自述确认“Berkeley DB 1.85 沉寂了一些年，直到 1996 年 Netscape 与 Margo Seltzer 和 Keith Bostic 签约来实现 libtp 论文中描述的全部事务设计并且实现一个生产质量级的版本。这项工作产生了 Berkeley DB 的第一个事务性版本，版本 2.0”；[史料缺失声明：Netscape 1996 年签约 Seltzer/Bostic 的合同金额与具体条款需查阅 Sleepycat Software 公司档案或 Netscape 公司档案，freebsd.duckdb 不适用于此时期（freebsd-src 仓库最早 commit 为 1993-06-12，远晚于 Berkeley DB 1991 年开发与 1992 年 4.4BSD 发布），暂保留存疑]
