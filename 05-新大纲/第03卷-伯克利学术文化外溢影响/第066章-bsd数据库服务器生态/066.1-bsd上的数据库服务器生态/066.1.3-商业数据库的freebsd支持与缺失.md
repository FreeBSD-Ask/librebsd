# 066.1.3 商业数据库的 FreeBSD 支持与缺失

  **要点**：商业数据库的 FreeBSD 支持与缺失：（1）Oracle Database 服务器不提供 FreeBSD 原生支持——Oracle 官方支持平台为 Linux、Windows、Solaris 与 Oracle Cloud；但 Oracle 客户端库通过 freebsd-ports 提供：databases/oracle7-client 于 2002-05-28T08:50:14Z by Sergey Skvortsov 引入（commit 79dd3ec0），databases/oracle8-client 于 2005-08-31T19:01:28Z by Max Khon 引入（commit 1e36813e），客户端库允许 FreeBSD 应用连接远程 Oracle 数据库但本机不运行 Oracle 服务器；（2）IBM DB2 服务器不提供 FreeBSD 原生支持，IBM DB2 官方支持平台为 Linux、Windows、AIX、Solaris；（3）Microsoft SQL Server 在 2017 年前仅支持 Windows，2017 年发布 SQL Server for Linux（基于 Linux 容器与 Ubuntu/RHEL/SLES），但仍不支持 FreeBSD；（4）SAP HANA 仅支持 SUSE Linux Enterprise Server 与 Red Hat Enterprise Linux；（5）商业数据库服务器的缺失使 FreeBSD 数据库生态以开源（PostgreSQL、MySQL、SQLite）为主，反映 BSD 在企业数据库市场的边缘地位

  | 商业数据库 FreeBSD 支持矩阵 | 数据库 | FreeBSD 服务器支持 | FreeBSD 客户端支持 |
| ------------------------- | ---- | ---------------- | ---------------- |

**史料**：freebsd.duckdb commit_files 表（databases/oracle7-client commit 79dd3ec0，2002-05-28 by Sergey Skvortsov；databases/oracle8-client commit 1e36813e，2005-08-31 by Max Khon）、Oracle/IBM DB2/Microsoft SQL Server/SAP HANA 官方支持平台列表 ［B］
  
**史观**：第 2 条形式主义与第 5 条偶然性——商业数据库的形式逻辑（平台支持决策基于市场份额）吞并了 FreeBSD 的潜在市场，偶然的商业决策使 FreeBSD 数据库生态以开源为主
  
**辨析**：Oracle 客户端库与服务器区分——freebsd-ports 中存在 databases/oracle7-client（2002-05-28 by Sergey Skvortsov）与 databases/oracle8-client（2005-08-31 by Max Khon），但这些是 Oracle Instant Client 的 FreeBSD 移植，仅提供客户端连接能力，FreeBSD 从未运行 Oracle Database 服务器；IBM DB2 服务器官方支持平台经 IBM 官方文档确认为 Linux、Windows、AIX、Solaris，FreeBSD 不在列表中；Microsoft SQL Server 2017 年发布 SQL Server for Linux，支持 Ubuntu、RHEL、SLES 与 Docker 容器，但仍不支持 FreeBSD；SAP HANA 仅支持 SUSE 与 RHEL；商业数据库服务器的 FreeBSD 缺失是平台支持决策的产物，反映 FreeBSD 在企业数据库市场份额的边缘地位
