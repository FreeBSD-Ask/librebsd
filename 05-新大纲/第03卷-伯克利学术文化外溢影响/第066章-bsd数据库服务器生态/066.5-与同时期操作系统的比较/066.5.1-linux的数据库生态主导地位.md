# 066.5.1 Linux 的数据库生态主导地位

  **要点**：Linux 的数据库生态主导地位：（1）Linux 运行所有主流数据库服务器——Oracle Database（1998 年首次支持 Linux，Oracle 8 for Linux）、IBM DB2（1999 年支持 Linux）、Microsoft SQL Server（2017 年发布 SQL Server for Linux）、SAP HANA（自 2010 年代起仅支持 SUSE 与 RHEL）、MySQL、PostgreSQL、SQLite；（2）Linux 的 GPL 许可证与商业数据库的兼容性——GPL 与商业数据库服务器的客户端库许可证无冲突，使厂商优先支持 Linux；（3）Linux 容器生态主导数据库部署——Docker（2013-03 由 dotCloud 创始人 Solomon Hykes 在 PyCon 公开演示后开源）与 Kubernetes（2014-06 Google 发布 v0.1，2015-07 1.0 发布，CNCF 成立）推动云原生数据库部署；（4）Linux 在企业数据库市场份额自 2010 年代后期超过 Windows 与 Unix 之和 〔存疑：具体市场份额数据需多源交叉验证，不同来源统计口径差异较大，暂保留存疑〕；Linux 的主导地位反映商业支持与容器生态的综合优势

  | Linux 商业数据库支持时间线 | 时间 | 厂商与产品 |
