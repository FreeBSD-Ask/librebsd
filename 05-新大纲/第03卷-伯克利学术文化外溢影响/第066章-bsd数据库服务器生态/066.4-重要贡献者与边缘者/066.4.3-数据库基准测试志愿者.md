  **要点**：数据库基准测试志愿者包括：（1）社区邮件列表与个人博客中的 PostgreSQL on FreeBSD 性能基准测试记录——系统性学术基准文献稀缺，多为爱好者自发测试；（2）Yahoo! 等公司的 MySQL on FreeBSD 生产环境性能数据——Yahoo! 1990 年代后期在 FreeBSD 4.x 上运行 MySQL 为典型生产案例，但内部基准数据未公开；（3）Phoronix 等媒体的 FreeBSD/Linux 数据库性能比较——Phoronix 自 2008 年起定期发布 FreeBSD vs Linux 性能比较，包含 PostgreSQL 与 MySQL 基准，但测试方法与样本选择存在争议；（4）这些志愿者的工作为 FreeBSD 数据库生态提供性能数据，但常被忽视且缺乏系统性
