# 066.9.1 Redis 2009 年诞生与 BSD 许可证

  **要点**：Salvatore Sanfilippo（网名 antirez）**2009 年** 开发 Redis（Remote Dictionary Server），最初为解决意大利创业公司 Merzia 的访客信息追踪网站 LLOOGG.com 的实时统计系统性能问题；Redis 是内存键值存储，支持字符串、列表、集合、哈希、有序集合等数据结构；Redis 最初采用 BSD 许可证（BSD 3-Clause），与 BSD UNIX 哲学共鸣——“做一件事并做好”；Sanfilippo 后将 Redis 开源，Redis Labs（后改名 Redis Inc.）商业化运营

  | Redis 关键要素 | 内容 |
| ------------ | -- |
| 开发者 | Salvatore Sanfilippo（antirez） |
| 开发时间 | **2009 年** |
| 全称 | Remote Dictionary Server |
| 初衷 | 解决 LLOOGG.com 实时统计性能 |
| 数据结构 | 字符串/列表/集合/哈希/有序集合 |
| 原始许可证 | BSD 3-Clause |

  | Redis 与 BSD 哲学共鸣 | 维度 | 内容 |
| ------------------- | -- | -- |
| “做一件事并做好” | Redis 专注于内存键值存储 | 不试图成为关系数据库 |
| BSD 许可证 | 最初采用 BSD 3-Clause | 与 BSD UNIX 许可证传统一致 |
