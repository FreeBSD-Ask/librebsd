### 新闻条目 1

- **新闻标题（中英）**：BSD Now 第 278 期 McKusick 访谈：“The Real McCoy”（BSD Now Episode 278，Allan Jude（艾伦·裘德） 主持，2018 年 12 月 27 日发布，BSD 网络代码传播主题）
- **新闻来源**：BSD Now 播客第 278 期“The Real McCoy”，主持人 Allan Jude，受访者 Marshall Kirk McKusick，2018 年 12 月 27 日发布
- **URL**：**<https://www.bsdnow.tv/278>**

- **新闻摘要**：McKusick 在 BSD Now 278 期访谈中详述 BSD 网络代码传播过程，包括 4.2BSD socket API 与 TCP/IP 协议栈如何通过自由再分发与厂商整合成为早期互联网基础设施标准；BSD 网络代码经 4.2BSD 广泛分发获得大量测试与改进；4.3BSD 网络子系统虽多数厂商转向 System V 但仍被整合入厂商系统；Networking Release 1 的自由再分发使 BSD 网络代码得以在 PC 市场独立 TCP/IP 网络产品中广泛使用。McKusick 作为 CSRG 成员，对 BSD 在 Internet 演进中地位的叙述可能存在阵营立场偏向。
- **与本章主题的关联说明**：直接对应本章“互联网的诞生与 BSD”主题中 BSD 网络代码传播部分，是 McKusick 对 BSD 网络代码在互联网中地位的口述史补充。
- **与官方史料的交叉验证结论**：与 McKusick 1999 Open Sources 章节（条目 1）对 BSD 网络代码传播描述一致；与项目考据记录 `20260724_kirk-mckusick-bsdnow-278-internet.md` 中记录的访谈内容一致。

- **新闻摘要**：Salus 1994 年著作详述 BSD 与互联网关系：BSD 对 Unix 最重要的贡献之一是 TCP/IP；4.2BSD 引入的 socket API 与 TCP/IP 协议栈通过广泛分发成为早期互联网基础设施标准；4.3BSD 网络子系统虽厂商转向 System V 但仍被整合入厂商系统；Networking Release 1 的自由再分发加速了 BSD 网络代码在 PC 市场与早期互联网中的传播。
- **与本章主题的关联说明**：为本章“互联网的诞生与 BSD”叙事提供独立学者视角的旁证，确认 BSD 网络代码在早期互联网基础设施中的核心地位。
- **与官方史料的交叉验证结论**：与 McKusick 1999 Open Sources 章节（条目 1）对 BSD 网络代码传播描述一致；与 Leffler ACM Queue 访谈（条目 2）对 4.2BSD 与 Internet 关系描述一致。
