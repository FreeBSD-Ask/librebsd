# 062.3.3 BIND 4/8/9 的版本演进

  **要点**：BIND 版本演进：（1）BIND 4.x（1980 年代后期，4.3BSD 集成版本）；（2）BIND 4.8/4.9（1990 年代早期，DEC 的 Paul Vixie 维护，Vixie Enterprises 接管）；（3）BIND 8（1997 发布，Internet Software Consortium，ISC，Vixie 主导）；（4）BIND 9（2000 发布，ISC，重写以提升安全性与 IPv6 支持）；BIND 9 至今仍是主流 DNS 服务器之一

  | BIND 版本 | 时间 | 维护方 | 特征 |
| ------- | -- | ---- | -- |
| BIND 4.x | **1980 年代后期** | 4.3BSD 集成 | 4.3BSD 集成版本 |
| BIND 4.8/4.9 | **1990 年代早期** | DEC 的 Paul Vixie 维护，Vixie Enterprises 接管 | — |
| BIND 8 | **1997 年** | ISC（Internet Software Consortium），Vixie 主导 | 重写 |
| BIND 9 | **2000 年** | ISC | 完全重写以提升安全性与 IPv6 支持 |

  | ISC 关键要素 | 内容 |
| ---------- | -- |
| 全称 | Internet Software Consortium（后更名为 Internet Systems Consortium） |
| 创立时间 | **1994 年** |
| 创始人 | Rick Adams、Paul Vixie、Carl Malamud 三人共同创立 |

**史观**：第 5 条偶然性——BIND 从学生项目到全球基础设施的演进是多重偶然事件叠加（Vixie 接管、ISC 成立、BIND 9 重写）的产物
