# 062.3.1 BIND 的伯克利起源与四位研究生

  **要点**：BIND（Berkeley Internet Name Domain）由伯克利 CSRG 的四名研究生开发：Douglas Terry、Mark Painter、David Riggle、Songnian Zhou，1984 年基于 Paul Mockapetris（USC ISI）的 DNS 协议设计（RFC 882/883 1983）实现，BIND 作为 4.3BSD 的组成部分发布，是 DNS 协议的首个参考实现，BIND 的伯克利起源使其与 BSD 深度绑定

  | 序号 | 姓名 | 机构 |
| ----------------- | -- | -- |
| 1 | Douglas B. Terry | 伯克利 CSRG 研究生 |
| 2 | Mark Painter | 伯克利 CSRG 研究生 |
| 3 | David W. Riggle | 伯克利 CSRG 研究生 |
| 4 | Songnian Zhou（周松年） | 伯克利 CSRG 研究生 |

  | BIND 关键要素 | 内容 |
| ----------- | -- |
| 开发时间 | **1984 年** |
| 基于 | Paul Mockapetris（USC ISI）的 DNS 协议设计（RFC 882/883 **1983**） |
| 集成版本 | 作为 4.3BSD 组成部分发布 |
| 历史地位 | DNS 协议的首个参考实现 |

**史料**：BIND 1984 开发档案、四位研究生（Terry/Painter/Riggle/Zhou）的论文与项目记录、Mockapetris DNS RFC 882/883（1983）、4.3BSD BIND 集成记录 ［B］
  
**史观**：第 9 条经验优先与第 14 章边缘者——BIND 的实践（学生实现）先于 DNS 协议的形式化标准，四位研究生作为边缘者（学生身份）创造了全球互联网基础设施
  
**辨析**：BIND 开发时间（1984）经多源确认；四位研究生的姓名经多源确认（Douglas B. Terry、Mark Painter、David W. Riggle、Songnian Zhou 周松年，均为伯克利 CSRG 研究生，经 Terry 等 1984 年 USENIX 会议原始论文等一手来源佐证）；Terry/Painter/Riggle/Zhou 的具体分工——原始论文与项目记录未明确分工，保留 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］；BIND 作为 4.3BSD 组成部分发布经多源确认（4.3BSD 1986 年 6 月发布，BIND 作为 DNS 参考实现集成入 4.3BSD）。经两库检索：参考文献库 technologies_mentioned 表无 BIND 条目（仅有无关的 ypbind），Mockapetris 的 RFC 882/883（1983）亦未收录原文，故 BIND 四位研究生与 DNS 协议细节两库无法验证；邮件列表库（Usenet 1981-）可验证 1983 年 CSRG 网络代码讨论现场——comp.unix.wizards 中 `sam at ucbvax.UUCP`（Sam Leffler）1983-12-13 发帖讨论 UNIX domain socket 命名（message_id <2@ucbvax.UUCP>），comp.bugs.4bsd 中 1983 年有 4.1c/4.2BSD socket 与 `bind()` 讨论，为 BSD 网络栈早期开发提供社区讨论佐证，但不足以直接验证 BIND 四位研究生
