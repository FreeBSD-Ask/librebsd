# 062.1.4 要点互联网前BSD时代19691983的协议生态包括1NCPNetworkCon

  **要点**：互联网前 BSD 时代（1969-1983）的协议生态包括：（1）NCP（Network Control Program，ARPANET 1971-1983 使用）；（2）X.25（CCITT 1976 标准的分组交换协议，用于 Tymnet、Telenet 等公共网络）；（3）SNA（IBM 1974 发布的系统网络架构）；（4）DECnet（DEC 1975 发布的网络架构）；（5）UUCP（UNIX-to-UNIX Copy，1978 年由 Bell Labs 的 Mike Lesk 开发，用于 Usenet）；此多元协议生态在 TCP/IP 切换后逐步被 TCP/IP 统一

  | 协议 | 时间 | 来源 | 用途 |
| -- | -- | -- | -- |
| NCP（Network Control Program） | **1971-1983 年** | BBN 的 Steve Crocker 团队设计 | ARPANET 主机间通信协议 |
| X.25 | **1976 年** | CCITT 标准 | 分组交换协议（Tymnet、Telenet 等公共网络） |
| SNA（Systems Network Architecture） | **1974 年** | IBM | 专有网络架构 |
| DECnet | **1975 年** | DEC（Phase I） | 网络架构 |
| UUCP（UNIX-to-UNIX Copy） | **1978 年** | Bell Labs 的 Mike Lesk | UNIX 系统间文件传输与命令执行（USENET 基础传输层） |

**史料**：NCP 协议文档、X.25 CCITT 1976 标准、SNA IBM 1974 文档、DECnet DEC 1975 文档、UUCP Lesk 1978 文档［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档与公告〕
  
**史观**：第 4 条分离与聚合——多元协议（NCP/X.25/SNA/DECnet/UUCP）在分离竞争中发展，TCP/IP 的聚合统一使其他协议逐步边缘化，分离与聚合的辩证关系塑造互联网协议史
  
**辨析**：NCP（Network Control Program）使用时间确认为 1971-1983 年（ARPANET 主机间通信协议，由 BBN 的 Steve Crocker 团队设计，1983.1.1 ARPANET 切换至 TCP/IP 后弃用）；X.25 为 CCITT 1976 年标准的分组交换协议（用于 Tymnet、Telenet 等公共数据网络，多源一致）；SNA（Systems Network Architecture）为 IBM 1974 年发布的专有网络架构（多源一致）；DECnet 为 DEC 1975 年发布的网络架构（Phase I，多源一致）；UUCP（UNIX-to-UNIX Copy）为 Bell Labs 的 Mike Lesk 1978 年开发的 UNIX 系统间文件传输与命令执行协议（多源一致，UUCP 是 USENET 1980 年建立的基础传输层）
