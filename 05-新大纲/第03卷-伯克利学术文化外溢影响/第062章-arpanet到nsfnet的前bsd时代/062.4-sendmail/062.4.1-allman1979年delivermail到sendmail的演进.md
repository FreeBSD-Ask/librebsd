# 062.4.1 Allman 1979 年 delivermail 到 Sendmail 的演进

  **要点**：Eric Allman 1979 年在伯克利 INGRES 数据库项目中开发 delivermail（ARPANET 邮件传输代理），随 4.0BSD/4.1BSD 分发，delivermail 最初使用硬编码路由表通过 FTP 邮件协议转发；1981-1982 年 Allman 在 4.1cBSD 开发期间改写为 Sendmail 以支持 SMTP（RFC 821 1982）与 UUCP 等多协议路由，引入地址重写规则；Sendmail 1983 年 8 月随 4.2BSD 作为默认邮件传输代理（MTA）发布，Allman 的 delivermail 到 Sendmail 演进反映了互联网邮件协议从 ARPANET（FTP-based）到 SMTP 的转型

  | delivermail/Sendmail 演进时间线 | 时间 | 事件 |
| ----------------------------- | -- | -- |
| delivermail 开发 | **1979 年** | Eric Allman 在伯克利 INGRES 项目中开发 |
| delivermail 分发 | **1980-1981 年** | 随 4.0BSD/4.1BSD 分发 |
| Sendmail 重写 | **1981-1982 年** | Allman 在 4.1cBSD 开发期间改写 |
| Sendmail 正式发布 | **1983 年 8 月** | 随 4.2BSD 作为默认 MTA 发布 |
| SMTP RFC 821 | **1982 年** | Allman 的 Sendmail 支持 SMTP |

  | INGRES 与 CSRG 关系 | 内容 |
| ----------------- | -- |
| INGRES 项目 | Stonebraker 主持，伯克利 CS 系数据库研究组 |
| CSRG | Fabry/McKusick 主持，伯克利 CS 系操作系统研究组 |
| 关系 | 伯克利 CS 系下两个独立研究组，共享 PDP-11/VAX 硬件与部分人员 |
| Allman 角色 | 在 INGRES 项目期间开发 delivermail，后为 BSD 发行版开发 Sendmail |

**史料**：Allman delivermail/sendmail 开发档案、4.0BSD/4.1BSD delivermail 源代码、4.1cBSD/4.2BSD Sendmail 源代码、Sendmail 4.2BSD 集成档案（1983.8）、SMTP RFC 821（1982） ［A］
  
**史观**：第 9 条经验优先与第 5 条偶然性——Allman 的 delivermail/Sendmail 实践先于 SMTP 标准化（RFC 821 1982），偶然的伯克利环境（Allman 作为 CSRG 关联人员）使 Sendmail 成为 4.2BSD MTA
