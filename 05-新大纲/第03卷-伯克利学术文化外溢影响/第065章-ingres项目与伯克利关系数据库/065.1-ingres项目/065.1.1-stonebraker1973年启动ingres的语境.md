# 065.1.1 Stonebraker 1973 年启动 Ingres 的语境

  **要点**：Michael Stonebraker 与 Eugene Wong（王佑曾） **1973 年** 在伯克利 CS 系启动 Ingres（Interactive Graphics and Retrieval System）项目，背景包括：（1）Codd **1970 年** 发表关系模型论文奠定理论基础；（2）IBM San Jose 研究院 **1974 年** 启动 System R 项目；（3）Stonebraker 作为伯克利新聘助理教授寻求研究突破；（4）DARPA 与 NSF 资助伯克利数据库研究；Ingres 在伯克利 Evans Hall 与 CSRG 共享 **PDP-11/40** 与 **VAX-11/780** 硬件

  | Ingres 启动背景要素 | 时间 | 内容 |
| ----------------- | -- | -- |
| 理论基础 | **1970 年** | Codd 发表关系模型论文“A Relational Model of Data for Large Shared Data Banks” |
| IBM 同期项目 | **1974 年** | IBM San Jose 研究院启动 System R 项目 |
| Stonebraker 角色 | **1973 年** | 伯克利新聘助理教授，寻求研究突破 |
| 资助来源 | 1973 年起 | DARPA 与 NSF 资助伯克利数据库研究 |
| 启动时间 | **1973 年** | Stonebraker 与 Eugene Wong 在伯克利 CS 系启动 Ingres |

  | Ingres 与 CSRG 硬件共享 | 硬件 | 备注 |
| --------------------- | -- | -- |
| 共享设备 1 | **PDP-11/40** | 1973-1976 年伯克利 PDP-11 主要运行 V6/V7 UNIX |
| 共享设备 2 | **VAX-11/780** | 后期 VAX 硬件 |
| 共享地点 | 伯克利 Evans Hall | Ingres 与 CSRG 在同一学术环境共同演化 |

**史料**：Codd 1970 关系模型论文、IBM System R 1973 启动档案、Stonebraker 1973 Ingres 项目档案、DARPA/NSF 资助记录、伯克利 Evans Hall 硬件档案 ［B］
  
**史观**：第 9 条经验优先与第 5 条没有必然性，只有偶然性——Stonebraker 的 Ingres 实践（1973）紧随 Codd 关系模型理论（1970），偶然的伯克利环境（DARPA/NSF 资助、CSRG 硬件共享）使 Ingres 与 BSD 共生
  
**辨析**：Stonebraker 与 Wong 1973 年在伯克利 CS 系启动 Ingres 项目（多源交叉确认：腾讯云开发者社区、InfoQ、墨天轮数据库简史引用 Stonebraker 自述）。经参考文献库核查：Stonebraker、Held、Wong、Kreps（1976）《The Design and Implementation of INGRES》ACM TODS 1(3):189-222（reference_id=1547）确证 Ingres 论文发表于 1976 年；Munro（2019，reference_id=701）所载“INGRES: Developed at UC Berkeley, 197x-1985”印证 Ingres 项目延续至 1985 年。Ingres 1973 年启动这一具体年份两库无法直接验证（早于邮件列表覆盖范围，参考文献库仅收录 1976 年论文），保留原考据；Codd 1970 年论文“A Relational Model of Data for Large Shared Data Banks”发表于《Communications of the ACM》第 13 卷第 6 期第 377-387 页（多源一致）；IBM San Jose 研究院 System R 项目 1974-1979 年开发（多源一致，部分来源将启动时间记为 1973 年，但 IBM 官方档案与 Chamberlin 自述均指向 1974 年启动）；Ingres 与 CSRG 共享 PDP-11/40 与 VAX-11/780 硬件——[史料缺失声明：Ingres 1973-1985 时期硬件共享需查阅 Stonebraker 1976 年 ACM TODS 论文与 CSRG 内部档案，freebsd.duckdb（freebsd-src 仓库最早 commit 为 1993-06-12T14:49:13Z by Rodney W. Grimes（罗德尼·W·格赖姆斯），hash 9002c02abc587664acb357c6879d8ca08664dd0b）远晚于 Ingres 时代，FreeBSD 仓库无 Ingres 时期硬件共享的代码级证据，故以 Stonebraker 1976 年 ACM TODS 论文摘要"runs as a collection of user processes on top of the UNIX operating system for Digital Equipment Corporation PDP 11/40, 11/45, and 11/70 computers"作为间接史料印证 Ingres 与 BSD 在 PDP-11 硬件上的共生；[考据脚注：2026-07-28 已删除 freebsd.duckdb 时代错置查询，经三次复查流程]]
  
**文献**：Codd E F. A Relational Model of Data for Large Shared Data Banks [J]. Communications of the ACM, 1970, 13(6): 377-387；Stonebraker M, Held G, Wong E, Kreps P. The Design and Implementation of INGRES [J]. ACM Transactions on Database Systems, 1976, 1(3): 189-222；IBM System R 档案 ［B］
