# 065.1.4 Ingres 的商业化分支与遗产

  **要点**：Ingres 的商业化分支与遗产：（1）Ingres 1980 年由 Stonebraker 等创立 Relational Technology Inc.（RTI，后改名 Ingres Corp.）商业化；（2）RTI/Ingres Corp. 1980 年代后期与 Oracle 竞争关系数据库市场，但逐步落后；（3）Sybase 1986 年基于 Ingres 代码（QUEL 改 SQL）开发 Sybase SQL Server；（4）Microsoft 1989 年与 Sybase 合作开发 SQL Server for OS/2，后独立为 Microsoft SQL Server；（5）Ingres 的遗产通过 Sybase/Microsoft SQL Server 延续，但伯克利起源被遗忘

  | Ingres 商业化分支时间线 | 时间 | 事件 |
| --------------------- | -- | -- |
| RTI 创立 | **1980 年** | Stonebraker 等创立 Relational Technology Inc.（后改名 Ingres Corp.） |
| RTI 竞争 | 1980 年代后期 | 与 Oracle 竞争关系数据库市场，逐步落后 |
| Sybase 创立 | **1984 年** | Mark Hoffman 与 Bob Epstein 创立 Sybase（Bob Epstein 为伯克利 Ingres 项目成员） |
| Sybase SQL Server 1.0 | **1987 年 5 月** | 发布 Sybase SQL Server 1.0 |
| Microsoft 合作 | **1989 年** | Microsoft 与 Sybase 合作开发 SQL Server for OS/2 |
| Microsoft 独立 | **1993 年** | Microsoft 与 Sybase 分道扬镳，SQL Server 独立演化 |

**史观**：第 13 条法律与道德是利益分配——Ingres 作为伯克利学术项目被商业力量（Oracle、Microsoft）边缘化，但偶然的 Sybase/Microsoft 合作使 Ingres 遗产延续
  
**辨析**：Relational Technology Inc.（RTI）1980 年由 Stonebraker 等创立以商业化 Ingres（多源一致，Computer History Museum Stonebraker 个人档案确认其创立公司商业化 Ingres，但 RTI 具体创立日期存疑——部分来源记为 1980 年，部分来源记为 1982 年，采信 1980 年创立说作为主流记载；后改名 Ingres Corp.，被 ASK Group 收购，再被 Computer Associates 收购）；Sybase 1984 年由 Mark Hoffman 与 Bob Epstein 创立——Bob Epstein 是伯克利 Ingres 项目成员，但 Sybase SQL Server 是重新设计而非基于 Ingres 代码（原大纲“Sybase 1986 年基于 Ingres 代码（QUEL 改 SQL）”表述不准——Sybase 自始采用 SQL 而非 QUEL，且其代码为自研而非 Ingres 派生；采信 Sybase 1984 年创立说，部分中文来源误记 1986 年，原史料字段中“Sybase 1986 创立档案”已修正为“Sybase 1984 创立档案”）；Sybase 1987 年 5 月发布 Sybase SQL Server 1.0；Microsoft 1989 年与 Sybase 合作开发 SQL Server for OS/2，1993 年 Microsoft 与 Sybase 分道扬镳，Microsoft SQL Server 走向独立演化（多源一致）

**观点**：1981 年 9 月，署名 IngVAX.eric@Berkeley 的用户在 setuid 机制之争中投反对票：Ingres 以 “ingres” 用户身份 setuid 运行并以 600 权限建文件，“设想一下 root 创建一个关系的后果”，足见该机制之危险。
**邮件来源**：IngVAX.eric@Berkeley，comp.unix.wizards，1981 年 9 月，Message-ID: `ucbvax.2892`
**史学意义**：发帖主机 IngVAX 是伯克利运行 Ingres 的专用 VAX，其管理员以 Ingres 的实际部署细节参与 Unix 内核机制辩论，说明该数据库项目在 1981 年已是伯克利系统实践的一等公民。
