# 065.3.1 MySQL 1995 年发布与早期架构

  **要点**：MySQL 1995 年由 Michael“Monty”Widenius、David Axmark 与 Allan Larsson 在瑞典创立 MySQL AB 并发布 MySQL，MySQL 早期架构包括：（1）基于 mSQL（Mini SQL，David Hughes 开发）的 API 兼容改进而非代码派生；（2）使用 ISAM（Indexed Sequential Access Method）存储引擎（后发展为 MyISAM）；（3）支持 SQL 查询但早期版本功能简化（无事务、无外键）；（4）MySQL 采用 GPL 与商业双许可证模式（2000 年 GPL 化后确立，创立初期并非 GPL）；MySQL 名称来源于 Widenius 的女儿 My；MySQL 的早期架构反映实用主义哲学（“快与简单”优先于“完整与严格”）

  | MySQL 创立关键要素 | 内容 |
| ---------------- | -- |
| 创立时间 | **1995 年** |
| 创立地点 | 瑞典 |
| 联合创始人 | Michael“Monty”Widenius、David Axmark、Allan Larsson |

| 名称来源 | Widenius 的女儿 My |

  | MySQL 早期架构要素 | 内容 |
| ---------------- | -- |

| SQL 功能 | 早期版本简化（无事务、无外键） |
| 许可证模式 | GPL + 商业双许可证（2000 年 GPL 化后） |
| 实用主义哲学 | “快与简单”优先于“完整与严格” |

**史观**：第 9 条经验优先与第 5 条偶然性——MySQL 的实践（1995，早期无事务设计）先于其对事务形式化理论（ACID，1983 年 Härder/Reuter 已形式化）的采纳，偶然的瑞典环境（Widenius/Axmark/Larsson）使 MySQL 与 FreeBSD 共生
  
**辨析**：MySQL 1.0 于 1995 年由 Michael “Monty” Widenius 与 David Axmark 发布，但 1.0 版本仅供内部使用（Oracle 官方回顾 blogs.oracle.com/mysql 与社区资料交叉印证：MySQL 1.0（1995 年）为首个版本、仅简化 SQL 语法且仅供内部使用；原引 CSDN/博客园等社区帖已降为旁证）；首个公开版本为 MySQL 3.11.1（1996 年），直接跳过 2.x 版本（多源一致）；MySQL 以联合创始人 Monty Widenius 的女儿 My 命名（MySQL 官方手册 <https://dev.mysql.com/doc/refman/8.0/en/history.html> 确认）；MySQL 最初并非 GPL 许可证，2000 年方以 GPL 条款开源（learnku MySQL 历史确认“2000 MySQL 是开源的，并根据 GPL 的条款发布软件。结果，公司的收入下降了 80%”）；MySQL 官方历史版本存档位于 （MySQL 官方存档页面 <https://downloads.mysql.com/archives/community/> 确认）；MySQL AB 1995 年创立（非 2001 年）已确认；Allan Larsson 为联合创始人（原文件遗漏）；mSQL 1994 发布时间据一手文献印证消解^doubt-resolved-139［考据结论：经多源交叉验证，mSQL 由 David Hughes 开发并于 1994 年首次发布，正文“API 兼容改进而非代码派生”表述成立］；MySQL GPL 许可证采用时间已确认（2000 年）〔原禁引来源（仅作考据留痕）·已改引官方主源 ref2513（Oracle MySQL 官方回顾 blogs.oracle.com/mysql）〕
