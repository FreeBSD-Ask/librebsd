# 065.3.3 MySQL AB 的商业化与 Sun/Oracle 收购

  **要点**：MySQL AB 的商业化与 Sun/Oracle 收购：（1）MySQL AB 1995 年由 Widenius、Axmark 与 Allan Larsson 创立（瑞典），采用 GPL + 商业双许可证模式；（2）MySQL AB 2000 年代初获得风险投资（Benchmark Capital 等）；（3）Sun Microsystems 2008 年以约 10 亿美元收购 MySQL AB；（4）Oracle 2010 年完成对 Sun 的收购，获得 MySQL，引发 MySQL 社区对 Oracle 垄断的担忧；（5）Widenius 2009 年离开 Sun，发起 MariaDB fork 以保护 MySQL 开源遗产

  | MySQL AB 商业化与收购时间线 | 时间 | 事件 |
| ------------------------- | -- | -- |
| MySQL AB 创立 | **1995 年** | Widenius、Axmark、Allan Larsson 在瑞典创立，双许可证模式（2000 年 GPL 化后确立） |
| 风险投资 | 2000 年代初 | Benchmark Capital 等 |
| Sun 收购 | **2008 年** | Sun Microsystems 以约 10 亿美元收购 MySQL AB |
| MariaDB fork | **2009 年** | Widenius 离开 Sun，发起 MariaDB fork |
| Oracle 收购 Sun | **2010 年** | Oracle 完成对 Sun 的收购，获得 MySQL |
