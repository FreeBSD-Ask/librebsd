# 065.3.4 MySQL 与 FreeBSD Ports 的共生关系

  **要点**：MySQL 与 FreeBSD Ports 的共生关系：（1）FreeBSD Ports 系统（1994 年 Jordan Hubbard 创建）使 MySQL 易于在 FreeBSD 上安装；（2）MySQL FreeBSD Port 维护者（如 The FreeBSD Ports MySQL 维护团队）持续更新 MySQL 版本；（3）MySQL 在 FreeBSD 上的部署推动 FreeBSD 在 Web 服务器市场（LAMP 栈）的应用；（4）MySQL 与 FreeBSD Ports 的共生反映开源生态的实用主义

**观点**：1997 年，Mark Blythe 报告把基于线程的 MySQL 移植到 BSDI 3.0 的主要障碍：该系统 pthreads 实现缺失 sigset 与 sigwait 两个函数，他公开求替代方案并自称 “快被逼疯了”。
**邮件来源**：Mark Blythe，comp.unix.bsd.bsdi.misc，1997 年，Message-ID: `33D99784.23BEC391@cvp.com>#1/1`
**史学意义**：这份一线移植报告把 MySQL 的 BSD 化难题精确定位在 POSIX 线程函数缺失上，与同期其他用户的 pthread 抱怨互证，说明数据库线程化架构与 BSD 线程库成熟度的错位是 1997 年的核心工程障碍。
