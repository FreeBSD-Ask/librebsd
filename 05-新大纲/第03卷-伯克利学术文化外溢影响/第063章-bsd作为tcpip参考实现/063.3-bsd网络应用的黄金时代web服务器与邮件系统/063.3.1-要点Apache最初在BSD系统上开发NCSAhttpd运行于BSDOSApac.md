# 063.3.1 要点Apache最初在BSD系统上开发NCSAhttpd运行于BSDOSApac

**要点**：Apache 最初在 BSD 系统上开发——NCSA httpd 运行于 BSD/OS，Apache 的 prefork 模型直接受益于 BSD fork() 实现效率。sendmail（Eric Allman（埃里克·奥尔曼）, 1981）为 4.1cBSD 开发，是互联网 SMTP 事实标准。

**史料**：Apache HTTP Server 项目历史； Allman 1983 USENIX ［A］

**史观**：总纲第 4 条——分离聚合是永恒规律。

**辨析**：BSD 网络栈的历史叙事常以“参考实现”自居，但需注意同一时期存在多个竞争性网络实现（如 MIT 的 PC/IP、CMU 的 Mach 网络栈）。BSD 网络栈的“标准”地位是事后建构——在 1980 年代它只是众多实现之一。Web 服务器市场的数据受制于 Netcraft 等第三方统计的方法论局限。

**文献**：Apache 历史； Allman 1983 ［A］

**史学意义**：ISP 经营者把 “上 Apache”当作多域名虚拟主机的标准答案，说明虚拟主机这一互联网商业化关键需求是以 Apache 加 BSD 的组合为事实方案落地的。
