# 063.4.1 BIND 安全漏洞与市场份额流失

  **要点**：BIND 安全漏洞与市场份额流失的批评：（1）BIND 4.9.x 1990 年代后期多个远程漏洞；（2）BIND 8.2.x 1999 年 NXT/SIG/SO_LINGER 等多个漏洞（CERT Advisory CA-1999-14）；（3）Dan Kaminsky 2008 年披露的 DNS 缓存投毒漏洞（CERT VU#800113，协议设计层缺陷，影响多数 DNS 实现）；（4）BIND 安全问题推动替代品 PowerDNS（1999）、Unbound（2008 年首个正式版，2007 系开发起点口径）、NSD（2003）的发展；（5）BIND 在 DNS 服务器市场份额从 1990 年代约 90% 逐步下降；（6）BIND 安全漏洞的批评反映 BSD 互联网技术的 “成功负担”——统治地位使 BIND 成为攻击目标

  | BIND 安全漏洞史 | 时间 | 版本 | 漏洞 | CERT 编号 |
| ------------- | -- | -- | -- | ------- |
| BIND 4.9.x | **1990 年代后期** | 4.9.x | 多个远程漏洞 | — |
| BIND 8.2.x | **1999 年** | 8.2.x | NXT/SIG/SO_LINGER 等 | CERT Advisory CA-1999-14 |
| DNS 缓存投毒 | **2008 年** | 协议设计层 | Dan Kaminsky 披露 | CERT VU#800113 |

  | BIND 替代品 | 发布时间 | 特征 |
| --------- | ------ | -- |
| PowerDNS | **1999 年** | 替代品之一 |
| NSD | **2003 年** | 替代品之一（权威域名服务器） |
| Unbound | **2008 年**（首个正式版；2007 系开发起点口径） | 替代品之一（DNSSEC 验证解析器） |

  | BIND 市场份额变化 | 时期 | 份额 |
| --------------- | -- | -- |
| 1990 年代 | — | 约 90% |
| 后续 | 逐步下降 | 被替代品蚕食 |

**史观**：第 2 条历史是形式主义化的非存在——BIND 的形式统治（DNS 协议实现）吞并了实质的安全责任，形式统治与实质安全存在张力
  
**辨析**：BIND 8.2.x 1999 年 NXT/SIG/SO_LINGER 漏洞以 CERT Advisory CA-1999-14 为准；Dan Kaminsky 2008 年漏洞（CERT VU#800113）为 DNS 协议设计层缺陷，非 BIND 特有漏洞；PowerDNS（1999）/Unbound（2008-05 首个正式版，2007 系开发起点口径）〔订正注：原记 Unbound（2007），按 NLnet Labs 发布史核正〕/NSD（2003）发布时间需以各项目官方档案为准；BIND 市场份额演变数据需以 Netcraft 或 DNS 服务器统计为准
