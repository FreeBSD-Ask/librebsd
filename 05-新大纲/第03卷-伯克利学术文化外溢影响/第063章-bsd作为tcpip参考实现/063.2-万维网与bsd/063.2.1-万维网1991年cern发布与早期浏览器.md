# 063.2.1 万维网 1991 年 CERN 发布与早期浏览器

  **要点**：万维网（World Wide Web）1991 年 8 月 6 日由 Tim Berners-Lee 在 CERN 发布，首个网站 info.cern.ch 上线，早期浏览器包括：（1）WorldWideWeb（Berners-Lee 1990 在 NeXTSTEP 上开发，1991 公开）；（2）Erwise（1992，芬兰 Helsinki 大学，基于 X Window）；（3）ViolaWWW（1992，Pei-Yuan Wei，基于 X Window）；（4）Mosaic（1993，NCSA Marc Andreessen 与 Eric Bina）；万维网早期浏览器多运行于 Unix 工作站（含 BSD 系统）

  | 万维网关键节点 | 时间 | 事件 |
| ------------ | -- | -- |
| 万维网发布 | **1991 年 8 月 6 日** | Tim Berners-Lee 在 CERN 发布 |
| 首个网站 | **1991 年 8 月 6 日** | info.cern.ch 上线 |
| 发布者 | — | Tim Berners-Lee（CERN） |

  | 早期浏览器 | 时间 | 作者/机构 | 平台 |
| -------- | -- | ------- | -- |
| WorldWideWeb | **1990 年** 开发，**1991 年** 公开 | Berners-Lee | NeXTSTEP |
| Erwise | **1992 年** | 芬兰 Helsinki 大学 | X Window |
| ViolaWWW | **1992 年** | Pei-Yuan Wei | X Window |
| Mosaic | **1993 年** | NCSA Marc Andreessen 与 Eric Bina | Unix 工作站（含 BSD 系统） |

**史观**：第 5 条——没有必然性，只有偶然性——万维网的诞生是 CERN 内部信息管理需求的偶然产物，其全球扩散是早期浏览器（Mosaic）的偶然推动
  
**辨析**：万维网发布日期（1991 年 8 月 6 日）经多源确认（Tim Berners-Lee 在 CERN 发布万维网，首个网站 info.cern.ch 上线）；info.cern.ch 上线时间与万维网发布日期一致（1991.8.6）；WorldWideWeb 浏览器（Berners-Lee 1990 在 NeXTSTEP 上开发，1991 公开）、Erwise（1992，芬兰 Helsinki 大学，基于 X Window）、ViolaWWW（1992，Pei-Yuan Wei，基于 X Window）、Mosaic（1993，NCSA Marc Andreessen 与 Eric Bina）——多源一致确认；万维网早期浏览器多运行于 Unix 工作站（含 BSD 系统），Mosaic 的广泛扩散推动万维网从学术工具向公共基础设施转型
