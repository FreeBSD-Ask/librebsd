# 063.1.4 BSD 套接字 API 的跨平台效应

  **要点**：BSD 套接字 API（socket API）由 CSRG 在 4.2BSD 中引入，统一网络 I/O 接口（如 socket、bind、listen、accept、connect、send、recv），套接字 API 成为 POSIX 标准（IEEE Std 1003.1g，后被纳入 POSIX.1），被 Linux、Solaris、AIX、Windows Sockets（WinSock）等平台采纳，BSD 套接字 API 的跨平台影响使 BSD 网络编程模型成为互联网编程的事实标准

  | 4.2BSD 套接字 API 核心函数 | 手册页 |
| ------------------------ | ---- |
| socket | **socket(2)** |
| bind | **bind(2)** |
| listen | **listen(2)** |
| accept | **accept(2)** |
| connect | **connect(2)** |
| send | **send(2)** |
| recv | **recv(2)** |
| close | **close(2)** |

  | 套接字 API 标准化与采纳 | 平台/标准 | 时间 |
| --------------------- | ------- | -- |
| 4.2BSD 引入 | BSD | **1983 年** |
| POSIX IEEE Std 1003.1g | “Protocol Independent Interfaces” | **1996 年** 草案，**2000 年** 纳入 POSIX.1 |
| Linux | 采纳 | — |
| Solaris | 采纳 | — |
| AIX | 采纳 | — |
| WinSock 1.0 | Windows Sockets | **1993 年** 发布 |

**史料**：4.2BSD 套接字 API 文档、POSIX IEEE Std 1003.1g 标准、Linux/Solaris/AIX/WinSock 采纳记录［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档与公告〕
  
**史观**：第 9 条经验优先与第 5 条偶然性——BSD 套接字 API 的实践（4.2BSD 1983）先于 POSIX 标准化（1990 年代），偶然的 BSD 统治使套接字 API 成为跨平台标准
  
**辨析**：4.2BSD 套接字 API 的核心函数经 4.2BSD 手册页确认——socket(2)、bind(2)、listen(2)、accept(2)、connect(2)、send(2)、recv(2)、close(2) 等，统一网络 I/O 接口；POSIX IEEE Std 1003.1g“Protocol Independent Interfaces”（P1003.1g，1996 年草案，2000 年纳入 POSIX.1）标准化了套接字 API——多源一致确认；WinSock（Windows Sockets）1.0 于 1993 年发布（由 Martin Hall、Mark Towfiq、Geoff Arnold 等主导），采纳 BSD 套接字 API 以实现 Windows 与 UNIX 网络编程的源代码级兼容——多源一致确认
