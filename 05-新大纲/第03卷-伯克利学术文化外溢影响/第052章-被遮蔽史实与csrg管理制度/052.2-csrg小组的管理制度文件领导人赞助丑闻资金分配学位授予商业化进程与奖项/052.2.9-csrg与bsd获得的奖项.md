# 052.2.9 CSRG 与 BSD 获得的奖项

  **要点**：CSRG 与 BSD 获得的奖项包括——其一，**1986 年** ACM Software System Award 颁给 Unix（颁奖对象为 Unix 系统，BSD 作为 Unix 谱系的重要分支共享声誉，但具体颁奖对象为 Bell Labs Unix 而非 BSD，区分 “Unix 系统获奖” 与 “BSD 直接获奖”）；其二，USENIX Lifetime Achievement Award 提名（**1994 年** CSRG 解散前，CSRG 获提名但未最终获奖，反映 CSRG 的历史地位）；其三，Marshall Kirk McKusick 个人获得 **1994 年** ACM Grace Murray Hopper Award 提名（虽未获奖，但反映 McKusick 个人与 CSRG 的学术影响力）；其四，4.4BSD-Lite 作为 CSRG 最后作品，在 **1994 年** CSRG 解散后仍持续影响开源世界，被 USENIX 等机构视为系统软件的里程碑。CSRG 时期的奖项相对有限，CSRG 作为研究小组的学术地位与商业 Unix 厂商（如 Sun/IBM）的奖项规模存在差距——Sun/IBM 等商业公司有专门的奖项申报团队与公关资源，CSRG 作为学术研究小组无此类资源

  | 奖项 | 时间 | 获奖对象 | CSRG/BSD 关系 | 结果 |
| -- | -- | ------ | ----------- | -- |
| ACM Software System Award | **1986** | Unix 系统（Bell Labs） | BSD 作为 Unix 分支共享声誉 | 间接获奖 |
| USENIX Lifetime Achievement Award | **1994** | CSRG（提名） | 直接提名 | 未最终获奖 |
| ACM Grace Murray Hopper Award | **1994** | McKusick（提名） | 个人提名 | 未获奖 |

**史料**：ACM Software System Award **1986 年** 公告；USENIX Lifetime Achievement Award **1994 年** 提名档案；ACM Grace Murray Hopper Award **1994 年** 提名档案 ［B］
  
**史观**：第 14 章社区与文明历史哲学，CSRG 奖项的有限反映其作为研究小组的学术地位；第 22 条知识注定过时，CSRG 解散前的奖项提名反映其历史地位
  
**辨析**：ACM Software System Award 1986 年的具体颁奖对象——ACM 官方公告确认 1986 年颁奖对象为 Unix 系统（Bell Labs 的 Thompson/Ritchie/Kernighan/McIlroy 等为代表团队），BSD 作为 Unix 谱系分支共享声誉但不直接获奖，BSD 共享声誉的具体形式（如 CSRG 是否在颁奖名单中被提及）以 ACM 1986 年公告原文为准；USENIX/ACM 提名档案以 USENIX 与 ACM 原始档案为准；“奖项规模差距” 的判断——Sun Microsystems 1980-1990 年代获得的奖项数量与规模（如 Sun 获得的 ACM/IEEE 各类奖项）远超 CSRG，具体比较数据以 ACM/IEEE 奖项数据库为准
  
**文献**：ACM Software System Award 公告；USENIX 提名档案；ACM 提名档案 ［B］
