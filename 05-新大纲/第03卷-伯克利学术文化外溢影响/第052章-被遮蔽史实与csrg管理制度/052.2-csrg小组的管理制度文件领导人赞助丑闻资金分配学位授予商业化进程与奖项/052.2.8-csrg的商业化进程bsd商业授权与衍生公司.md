# 052.2.8 CSRG 的商业化进程：BSD 商业授权与衍生公司

  **要点**：CSRG 的商业化进程包括——其一，BSD 商业授权（commercial license），商业公司使用 BSD 代码须向伯克利 OTL 缴纳授权费，Sun/DEC/IBM/HP 等公司均购买 BSD 商业授权；其二，BSD 衍生公司，CSRG 成员毕业后创办或加入多家 BSD 相关公司——Bill Joy 联合创办 Sun Microsystems（**1982**），Sun 的 SunOS 基于 BSD；Sam Leffler 转至 Silicon Graphics 与 Cisco；Bob Fabry 转至 DEC；其三，BSDi（Berkeley Software Design, Inc.）由 CSRG 成员创办（**1991 年**），商业销售 4.4BSD-Lite 与 BSD/OS，后卷入 USL 诉讼；其四，Walnut Creek CDROM 销售 FreeBSD/Slackware CD-ROM，是 **1990 年代** BSD 商业分发的重要渠道。CSRG 的商业化进程反映 BSD 在 **1980-90 年代** Unix 商业化浪潮中的核心地位
