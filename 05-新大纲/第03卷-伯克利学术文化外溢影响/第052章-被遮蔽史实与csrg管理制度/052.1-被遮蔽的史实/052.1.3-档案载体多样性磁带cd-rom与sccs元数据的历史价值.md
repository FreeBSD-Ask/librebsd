# 052.1.3 档案载体多样性：磁带、CD-ROM 与 SCCS 元数据的历史价值

  **要点**：CSRG 档案载体多元，包括 9 磁道磁带（早期 BSD 发行）、QIC 磁带（中期备份）、CD-ROM（后期发行）、SCCS 版本控制元数据（源码演化记录）、纸质技术手册与笔记（决策记录），不同载体的物理寿命与可读性差异显著——磁带约 10-30 年寿命、CD-ROM 约 30-100 年寿命、纸质约 100+ 年寿命，载体多样性本身是档案保存的工程问题；SCCS 元数据尤其珍贵，因其记录了 BSD 源码的逐次提交时间、作者、注释，是 BSD 演化史的一手数字证据

  | 载体类型 | 用途 | 时期 | 估计寿命 |
| ------ | -- | -- | ------ |
| 9 磁道磁带 | 早期 BSD 发行 | CSRG 早期 | 约 10-30 年 |
| QIC 磁带 | 中期备份 | CSRG 中期 | 约 10-30 年 |
| CD-ROM | 后期发行 | CSRG 后期 | 约 30-100 年 |
| SCCS 版本控制元数据 | 源码演化记录 | CSRG 全期 | 随载体而定 |
| 纸质技术手册与笔记 | 决策记录 | CSRG 全期 | 约 100+ 年 |

  | SCCS 元数据要素 | 内容 |
| ------------- | -- |
| 提交时间 | BSD 源码逐次提交的时间戳 |
| 作者 | 每次提交的作者标识 |
| 注释 | 每次提交的注释说明 |
| 史料价值 | BSD 演化史的一手数字证据 |
| 研究方法 | 代码考古学 |

**史观**：第 19 条解释学循环是历史认识的根本条件与第 22 条知识注定过时，载体多样性是 1970-1990 年代信息技术演化的物质遗存，档案保存本身是技术史研究的子问题；SCCS 元数据的保存使 BSD 演化可被代码考古学方法系统化研究，体现了组织解散后源码演化证据经由版本元数据获得延续的典型路径
