# 385.6 FreeBSD 与 386BSD 的关系

## 385.6.1 继承、断裂与否认的三重叙事

  **要点**：FreeBSD 与 386BSD 的关系有三层可证事实：其一，代码继承——FreeBSD 以 386BSD 0.1 为直接基线之一（freebsd-src 中 Rodney W. Grimes 1993-06-20“Initial import of 386BSD 0.1 othersrc/etc”commit `1bf9d5d9518e789360439c1db3d568b113caf60d` 为硬证据），1.0 发行物明含 386BSD 组件；其二，叙事断裂——FreeBSD 网站当时称 386BSD 受困于 neglect，以“继承并继续”自我定位；其三，否认叙事——386BSD 官方站称 FreeBSD 的 roots 叙事“完全虚构、为掩盖对 386BSD 用户群的整批接收而发明”；三重叙事并存，代码事实与归属评价分属不同证据层
  
**史料**：freebsd-src Grimes 1993-06-20T13:41:45Z import commit `1bf9d5d9518e789360439c1db3d568b113caf60d`（freebsd.duckdb）；FreeBSD Handbook（neglect 表述与三源结构）；386BSD 官方站反驳（“This whole FreeBSD roots is completely fictitious...”）<https://butthurtfork.com/fork/386bsd> 与 <https://en.chped.com/wiki/386BSD> 转载［2026-10-03 访问］；本项目磁盘第 65 章（FreeBSD 与 386BSD 代码共享比例的不同估计）［A］
  
**史观**：
- 总纲第 19 条——解释学循环是历史认识的根本条件：继承事实须经代码层（commit）与话语层（双方叙事）的循环互证，任何单层都不足
- 总纲第 2 条——历史是形式主义化的非存在：“FreeBSD 继承 386BSD”在代码层为存在，在话语层被一方否认——历史书写的对象部分地是非存在
- 总纲第 8 条——本体论上各方平等：Jolitz 的否认叙事与 FreeBSD 的继承叙事同为对等形式，本节并陈不裁断
- 总纲第 4 条——分离聚合是永恒规律：import commit 是“分离时携带的嫁妆”的物质清单
- 总纲第 13 条——法律与道德是利益分配：用户群与名誉的转移无法律程序，归属之争本质是道德经济之争

**辨析**：代码共享比例（FreeBSD 中 386BSD 成分几何）无第三方量化研究，FreeBSD 方倾向强调独立性、386BSD 方强调继承性，均系位置话语；Grimes import（1993-06-20）为“othersrc/etc”部分，内核主体 import 的时点与 commit 须另行提取，勿以一处 import 推全貌；386BSD 官方站的“窃取”表述系当事人激烈修辞，引用须原样标注出处，不作编纂者立场
