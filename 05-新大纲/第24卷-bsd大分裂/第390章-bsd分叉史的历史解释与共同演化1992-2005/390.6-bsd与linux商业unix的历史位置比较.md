# 390.6 BSD 与 Linux、商业 UNIX 的历史位置比较

## 390.6.1 三线并行的 1990 年代

  **要点**：1992-2005 年 BSD 分叉期恰与 Linux 崛起、商业 UNIX 整合并行，三者构成操作系统史的三线：Linux（1991-）以 copyleft 与单一内核多发行版形态快速增长；商业 UNIX（SVR4 整合、Unix 战争收束）以企业市场为主战场；BSD 自由分支线（本卷对象）以许可证自由与 Berkeley 谱系为身份；历史位置的比较要点：其一，法律位置——USL 诉讼冻结了 BSD 的商业发行（BSDi／BSD/386 线）而 386BSD 及其分叉从未受限（非当事方），BSD 自由分支恰在诉讼阴影下完成了谱系重建；其二，治理位置——BSD 的分叉式多中心与 Linux 的单一主线多发行形成治理对照；其三，传播位置——CD-ROM 商业发行（Walnut Creek）使 BSD 与 Linux 同享 1990 年代发行革命；三线的互构（Linux 借鉴 BSD 网络栈、BSD 吸收 Linux 硬件支持经验）属横向比较卷的展开，本节存其框架

**史观**：
- 总纲第 3 条——不存在进步，只有权力再分配：三线的市场份额排序是资源与法律环境的再分配结果——本节拒绝以装机量倒推技术优劣
- 总纲第 13 条——法律与道德是利益分配：诉讼对不同 BSD 线的差别作用（商业线受限、自由线不受限）显示法律位置如何塑造生态位
- 总纲第 4 条——分离聚合是永恒规律：BSD 的多中心与 Linux 的单核多发行是同一“分离聚合”问题的两种解法
- 总纲第 12 条——形式主义的嵌套：三线的代码互借（网络栈、用户工具）构成形式体系间的持续嵌套
- 总纲第 8 条——本体论上各方平等：三线作为三个对等主体并陈——本节框架为比较，非竞赛排名

**辨析**：“诉讼冻结商业发行”的作用时点与强度（BSDi 1992-1994）属目录页第九卷事件编年，本节仅作位置性引用；Linux 与 BSD 的规模交叉点（何年用户量反超）无可靠同时期统计，通行说法多为事后估计，本节不作交叉点断言；“三线互构”的案例（eBPF 谱系等）属技术专题卷，此处仅存方向；比较框架（三线）系编纂设定，当事人语境中的主要对照常是两两的（BSD vs Linux），勿以三线框架回投 1993 年当事人意识
