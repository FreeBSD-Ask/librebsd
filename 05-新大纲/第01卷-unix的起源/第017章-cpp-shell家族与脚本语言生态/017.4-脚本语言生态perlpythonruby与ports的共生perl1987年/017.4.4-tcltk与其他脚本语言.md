# 017.4.4 Tcl/Tk 与其他脚本语言

**要点**：Tcl（Tool Command Language）由 John Ousterhout 于 1988 年设计，Tk 图形工具包于 1991 年发布；Tcl/Tk 在 1990 年代 UNIX/BSD 环境中广泛用于快速 GUI 原型开发，通过 FreeBSD Ports（lang/tcl、x11-toolkits/tk）提供；除主要脚本语言外，FreeBSD Ports 还提供 awk、sed、m4、yacc/lex/bison/flex、Lua、PHP、Haskell、OCaml、Scheme/Guile、Tcl、Expect、Rexx 等数十种语言；Basic、APL 等早期语言主要通过 Ports 中的复古实现提供（如 lang/bwbasic、lang/apl），未进入基本系统；Lisp/Scheme 在 BSD 历史上有多种实现——MIT Scheme、GNU Guile、CMU CL、SBCL、CLISP 等均通过 Ports 提供

**史料**：Ousterhout 1990 "Tcl: An Embeddable Command Language"（USENIX）、Ousterhout 1994 "Tcl and the Tk Toolkit"、FreeBSD Ports lang/ 与 x11-toolkits/ 类目 ［B］

**史观**：总纲第 2 条与第 22 条——实践先于理论与开源运动：Tcl/Tk 从嵌入式命令语言需求中诞生，Ports 系统实现语言生态多样性

**辨析**：Tcl/Tk 从未进入 FreeBSD 基本系统，但对 1990 年代 BSD GUI 开发有重要影响；Basic、APL 在早期 BSD（1BSD-4BSD）中是否存在——经 freebsd.duckdb 数据库考据确认：FreeBSD 基本系统从未包含 Basic 语言实现（查询条件 `SELECT c.commit_hash, c.author_date, c.message_subject, cf.file_path FROM commits c JOIN commit_files cf ON c.commit_hash=cf.commit_hash AND c.repo_name=cf.repo_name WHERE c.repo_name='freebsd-src' AND (cf.file_path LIKE '%basic%' OR cf.file_path LIKE '%bwbasic%') ORDER BY c.author_date ASC LIMIT 20` 仅返回 GCC `basic-block.h`（编译器基本块优化头文件，非 Basic 语言）、GNU Regex `psx-basic.c`（POSIX 基本正则测试文件，非 Basic 语言）、FreeBSD handbook `basics.sgml`（基础文档，非 Basic 语言），均非 Basic 语言实现）；FreeBSD 基本系统从未包含 APL 语言实现（查询条件 `SELECT c.commit_hash, c.author_date, c.message_subject, cf.file_path FROM commits c JOIN commit_files cf ON c.commit_hash=cf.commit_hash AND c.repo_name=cf.repo_name WHERE c.repo_name='freebsd-src' AND (cf.file_path LIKE '%/apl%' OR cf.file_path LIKE 'apl%' OR cf.file_path LIKE '%apl/%') ORDER BY c.author_date ASC LIMIT 20` 仅返回 `usr.bin/file/magdir/apl` 与 `usr.bin/file/Magdir/apl`（**file(1)** 命令识别 APL 文件类型的魔术数据库条目，非 APL 解释器/编译器）与 `contrib/bind9/lib/dns/rdata/in_1/apl_42.c`（BIND9 DNS 中 APL 记录类型实现，与 APL 语言无关））；freebsd.duckdb 数据库覆盖 1993-06-12 起的 freebsd-src 历史，1BSD-4BSD（1978-1980）早于 FreeBSD 仓库最早 commit（1993），但 V7 UNIX 是否包含 Basic、1BSD-4BSD 是否继承仍需以 V7/1BSD-4BSD 原始磁带档案考据为准；FreeBSD 基本系统自 1993-11-01 FreeBSD 1.0 起从未包含 Basic 或 APL 语言实现，存疑解除

**文献**：Ousterhout J K. Tcl: An Embeddable Command Language [C]//Proceedings of the Winter 1990 USENIX Conference, 1990: 133-146；Ousterhout J K. Tcl and the Tk Toolkit [M]. Addison-Wesley, 1994. ISBN 0-201-63337-X；FreeBSD Ports Tree (lang/tcl, lang/lua, lang/php, lang/sbcl, x11-toolkits/tk)；freebsd.duckdb `commits`+`commit_files` 表 JOIN 查询（覆盖 1993-06-12 起 freebsd-src 全部历史，无 Basic/APL 语言实现 commit）
