# 017.2.4 要点BSD系统启动脚本rcdPorts系统大量系统工具均使用Bourneshel

**要点**：BSD 系统启动脚本（rc.d）、Ports 系统、大量系统工具均使用 Bourne shell 语法（sh）编写；csh 因编程特性缺陷（变量处理、语法不一致）不适合脚本编程，主要用于交互式使用；sh 作为 POSIX 标准 shell 保证脚本可移植性；FreeBSD 基本系统中的 sh 为 Almquist shell 衍生物，轻量且符合 POSIX，不包含 bash 特有扩展

**史料**：FreeBSD rc.d 脚本源码、FreeBSD Porter's Handbook、POSIX 1003.1 Shell Command Language 标准 ［A］

**史观**：总纲第 17 条——软件工程：shell 脚本作为 UNIX/BSD 系统管理的 “胶水语言”

**辨析**：csh 不适合脚本编程——这是 UNIX 社区长期共识，经典论文《Csh Programming Considered Harmful》有详述 [存疑脚注：年份存疑（通行流传版为 1995/1996 年起），引用时以可核验在线版本为准]；系统脚本坚持使用 POSIX sh 是工程与可移植性的选择

**文献**：FreeBSD src/etc/rc.d/ 脚本源码；POSIX 1003.1-2008 Shell Command Language；FreeBSD Porter's Handbook ［A］
