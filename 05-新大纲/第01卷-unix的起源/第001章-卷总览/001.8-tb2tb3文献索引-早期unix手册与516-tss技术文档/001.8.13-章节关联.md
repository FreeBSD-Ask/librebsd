# 001.8.13 章节关联

本批文献主要关联以下章节：

- **第 8 章 贝尔实验室的黄金时代**：Bell Labs 早期 UNIX 手册（3693、3698、3699、3707）——四件均为 Bell Labs 内部技术备忘录（E.7.4、F.1.1、F.1.2、F.5.4 号），覆盖 VPM 通信接口、PDP-11 控制台运维、文件系统检查与 PDP-11 汇编器。其中 3698 署址为 **Piscataway**，其余三件署址为 **Murray Hill**，两址并存是 UNIX 组在两址分设时期的直接痕迹
- **第019章 小型机的诞生与 DEC-PDP 谱系**：516-TSS 技术文档（3589–3599、3600、3630、3646、3647）——DDP-516 属 Honeywell Series 16 十六位小型机家族（116／316／416／**516**／716，1966），与 DEC PDP 谱系同期。15 件文档构成一套完整的部门级分时系统设计资料：分段／非分段两套汇编器与 GE 后处理器、线程保存块与可重入代码、环形网与节点调制解调器、引导装载器与调试工具
- **2026-10-02 增补件的章节关联**：516-TSS 补遗 61 件同属“第019章 小型机的诞生与 DEC-PDP 谱系”范畴（与上表 15 件同一系统）；PWB/UNIX 4.0 文档集 13 件支撑“第009章 贝尔实验室的黄金时代”与“第023章 编程语言史”（其中 A.2.1 为 Ritchie & Thompson 论文重印，B.2.x/C.x 为 Kernighan 等人的教程与工具文档，D.2.1 为 Feldman & Weinberger 的 f77）；UNIX/32V Version 1.0（1979-02）支撑“第002章 unix 的起源”的 1979 年 VAX 移植脉络
- **第003章 Multics 的起源与三方合作**（旁证）：516-TSS 资料与 Multics 计划有器材层面的关联——据 The Unix Archive 中 `Other/516-TSS/` 目录 README 记载，该部门另有一台“源自 Multics 项目的 GE-635 或 645”，可能因 Honeywell 收购 GE 计算机业务而改名为 Honeywell 6070；此条为二手叙述，本批 11 件转录文档中未见 GE-645 字样，仅作旁证登记

**516-TSS 与 UNIX 的传承线索**（据 The Unix Archive `Other/516-TSS/` 目录 README，二手叙述，供正文取用时复核）：516-TSS 是最早的部门级分时系统之一，围绕 Honeywell DDP-516 构建；CTSS 更早但需价值约 300 万美元的 IBM 7090，而一台 DDP-516 约 5 万美元。该 README 称，516-TSS“把电话接上去调用计算机中心”的广域网式做法，后来在 UNIX 中以 `tss` 命令的形式出现。**此条为归档方 README 的二手说法，本批转录文档中无 `tss` 字样，未作核证，登记于此以待正文取用时复核。**
