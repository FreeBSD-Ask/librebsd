# 020.3.2 FreeBSD50ULE调度器时间辨析FreeBSD502003年1月首次引入U

**FreeBSD 5.0 ULE 调度器时间辨析**：FreeBSD 5.0（2003 年 1 月）首次引入 ULE 调度器，但 ULE 调度器在 FreeBSD 5.x 阶段（2003-2006）性能不稳定，至 FreeBSD 7.0（2008 年 2 月）ULE 调度器重新设计后才稳定并成为默认调度器。部分二手资料误将 ULE 调度器成熟时间记为 "FreeBSD 5.0"。本子节采用 “ULE 调度器 2003 年 FreeBSD 5.0 首次引入，2008 年 FreeBSD 7.0 重新设计后稳定” 的双时间表述。

**ARM64 与 FreeBSD 13.0 关系辨析**：FreeBSD 13.0（2021 年 4 月）对 ARM64 的支持进一步优化，但 ARM64 自 FreeBSD 12.0（2018 年 12 月）已是 tier-1 架构。部分二手资料误将 FreeBSD 13.0 描述为 “ARM64 首次成为 tier-1”。本子节明确 “FreeBSD 12.0 ARM64 tier-1（2018）” 与 “FreeBSD 13.0 ARM64 优化（2021）” 的不同定位。

**“硬件决定软件” 叙事辨析**：常见二手资料多采用 “硬件决定软件” 或 “软件决定硬件” 的单向因果叙事，但项目统摄史观拒绝这种形式唯物主义的简化。本子节明确 “硬件与软件互为形式主义化的辩证共构”——硬件限制塑造软件设计（如 PDP-7 缺乏磁盘塑造 UNIX 文件系统），软件需求也塑造硬件演化（如 4.2BSD 的虚拟内存需求塑造 VAX 的页面调度机制）。这是分离聚合规律在硬件-软件层面的展开，非单向因果。

**“小型机精神延续” 叙事辨析**：常见二手资料多将 ARM 服务器与 RISC-V 描述为 “小型机精神的延续”，但 1980 年代小型机厂商（DEC、Sun、HP、SGI、Apollo）皆以专有架构为核心，与当代 ARM/RISC-V 开放架构有本质差异。本子节拒绝 “小型机精神延续” 的简化叙事，明确 “专有小型机的终结” 与 “开放小型机以 ARM/RISC-V 形式延续” 是两个不同范畴，二者不能简单等同。

### 关键术语

| 术语 | 释义 |
| -- | -- |
| 小型机（minicomputer） | 1960-1980 年代介于大型机与微型机之间的中型计算机类别，DEC PDP、VAX、Data General Nova、王安 VS 等为代表 |
| 工作站（workstation） | 1980-2000 年代桌面专用高性能计算机，Sun SPARC、SGI IRIS、HP 9000、IBM RS/6000、Apollo DN 等为代表 |

| MIPS | Stanford 1985 年发布的 RISC 架构，SGI 工作站与嵌入式市场的基础 |
| ARM（Advanced RISC Machines） | Acorn 1985 年发起、ARM Holdings 1990 年商业化的 RISC 架构，移动与服务器市场主导 |
