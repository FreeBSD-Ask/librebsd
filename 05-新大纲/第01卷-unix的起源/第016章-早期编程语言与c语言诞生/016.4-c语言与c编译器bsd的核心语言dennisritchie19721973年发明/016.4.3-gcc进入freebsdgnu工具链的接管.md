# 016.4.3 GCC 进入 FreeBSD：GNU 工具链的接管

**要点**：Richard Stallman 于 1987 年 3 月 22 日发布 GCC 0.9（第一个 beta 版本），随后于 1987 年 5 月 23 日正式发布 GCC 1.0（GNU C Compiler）；386BSD（1992）与早期 FreeBSD（1.0/2.0，1993-1994）已采用 GCC 作为系统编译器，PCC 逐步退役；FreeBSD 基本系统长期使用 GCC 2.7.2.3 → GCC 2.95 → GCC 3.x → GCC 4.2.1 的演进路径；FreeBSD 9.0（2012 年 1 月）仍以 GCC 4.2.1 为默认编译器，同时默认安装 Clang 3.0 作为可选；GCC 采用 GPLv2+ 许可证，为后续许可证争议埋下伏笔。**FreeBSD 基本系统 C 编译器演进**：

| 时间节点 | FreeBSD 版本 | 默认编译器 | 备注 |
| ------ | ---------- | -------- | -- |
| 1987-03-22 | — | GCC 0.9（beta）发布 | Stallman 发布首个 GCC beta |
| 1987-05-23 | — | GCC 1.0 发布 | GCC 首个正式版本 |
| 1993-11 | FreeBSD 1.0 | GCC 2.x | freebsd.duckdb 印证含 `gnu/gcc2/lib/basic-block.h` |
| 1994-1995 | FreeBSD 1.1/2.0 | GCC 2.x | PCC 逐步退役 |
| — | FreeBSD 2.x-8.x | GCC 2.7.2.3 → 2.95 → 3.x → 4.2.1 | 长期 GPLv2 演进路径 |
| 2012-01 | FreeBSD 9.0 | GCC 4.2.1（默认）+ Clang 3.0（可选） | `WITH_CLANG_IS_CC` 可切换 |
| 2014-01 | FreeBSD 10.0 | Clang/LLVM 3.3 | i386/amd64/arm 正式切换，GCC 4.2.1 不再默认构建 |
| FreeBSD 12/13 | — | Clang/LLVM | GCC 4.2.1 最终从基本系统移除 |

**史料**：Stallman R M. GNU Compiler Collection Release History；FreeBSD SVN 源码树（gnu/usr.bin/cc/）；FreeBSD 9.0 Release Notes（2012-01）；freebsd.duckdb 数据库交叉验证——`SELECT tag_name, target_commit_date, tag_message FROM tags WHERE repo_name='freebsd-src' AND tag_name LIKE 'release/1.0%'` 返回 FreeBSD 1.0 tag `release/1.0.0_cvs`（target_commit_date 1993-11-01），对应 commit 8503f4f13f77 含 `gnu/gcc2/lib/basic-block.h` 文件，证实 FreeBSD 1.0 已使用 GCC 2.x；`SELECT commit_hash, author_date, message_subject FROM commits WHERE repo_name='freebsd-src' AND (message_subject LIKE '%GCC 1.0%' OR message_subject LIKE '%Stallman%')` 未返回相关 commit（GCC 1.0 1987 发布远早于 FreeBSD 仓库最早 commit 1993-06-12，Stallman 不直接 commit 至 FreeBSD），GCC 1.0 发布日期须以 FSF 官方 GCC Releases 页面为准 ［A］

**史观**：总纲第 22 条与第 24 条——开源运动与许可证：GCC 的 GPL 许可证与 BSD 许可证哲学的张力

**辨析**：GCC 取代 PCC 的具体版本——FreeBSD 1.0（1993）已使用 GCC，但 PCC 在 contrib/ 目录中保留一段时间；GCC 4.2.1 是 FreeBSD 基本系统中最后一个 GPLv2 版本的 GCC，因 GCC 4.3+ 采用 GPLv3 引发许可证担忧；[考据脚注·GCC 0.9 beta 与 GCC 1.0 发布日期的考据过程] 经三轮 WebSearch 与 WebFetch 核实：其一，GCC 官方发布历史页面（gcc.gnu.org/releases.html，2026-07-28 WebFetch 核实）"GCC Timeline" 表格明确记载 "0.9 (first beta release) | March 22, 1987" 与 "1.0 | May 23, 1987"——即 1987 年 3 月 22 日是 GCC 0.9 beta 的发布日期，1987 年 5 月 23 日才是 GCC 1.0 正式版本的发布日期；其二，GCC Timeline 表格还显示 GCC 1.0 至 1.42（1992-09-20）间共发布 40 余个 1.x 版本，1988 年起 GCC 进入快速迭代期（1.16 于 1987-12-19、1.17 于 1988-01-09、1.40 于 1991-06-01）；其三，原要点字段中 “Richard Stallman 于 1987 年 3 月 22 日发布 GCC 1.0” 系日期错误——3 月 22 日实为 GCC 0.9 beta 的发布日期，GCC 1.0 正式版本发布于 1987 年 5 月 23 日，已纠正；其四，FreeBSD 1.0 已使用 GCC 2.x 一事经 freebsd.duckdb 交叉印证——commit 8503f4f13f77（"Release FreeBSD 1.0"，1993-11-01）含 `gnu/gcc2/lib/basic-block.h` 等 GCC 2.x 源码文件；综上，GCC 1.0 正式发布日期已纠正为 1987 年 5 月 23 日，GCC 0.9 beta 发布日期为 1987 年 3 月 22 日，二者不可混淆。
