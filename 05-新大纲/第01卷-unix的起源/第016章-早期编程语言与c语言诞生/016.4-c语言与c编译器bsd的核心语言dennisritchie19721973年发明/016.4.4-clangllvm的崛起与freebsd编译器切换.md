# 016.4.4 Clang/LLVM 的崛起与 FreeBSD 编译器切换

**要点**：LLVM 项目由 Chris Lattner 于 2000 年在伊利诺伊大学发起，Clang C/C++/Objective-C 编译器前端于 2007 年首次开源；FreeBSD 社区自 2009 年起推进 Clang 适配，Brooks Davis、David Chisnall（戴维·奇斯纳尔）、Dimitry Andric、Ed Schouten、Roman Divacky 等为核心贡献者；FreeBSD 9.0（2012 年 1 月）默认安装 Clang 3.0 但默认编译器仍为 GCC 4.2.1，WITH_CLANG_IS_CC 选项可切换；FreeBSD 10.0（2014 年 1 月）i386/amd64/arm 等平台正式以 Clang/LLVM 3.3 为默认系统编译器，GCC 4.2.1 不再默认构建（仅 pc98 等少数平台保留）；切换动机包括 BSD 许可证友好（BSD vs GPL）、编译速度更快、错误诊断更友好、模块化架构适合 IDE 集成；GCC 4.2.1 最终从 FreeBSD 基本系统完全移除为 FreeBSD 12/13 时期

**史料**：FreeBSD 2012 Q1 Status Report（Clang Replacing GCC in the Base System 章节）、FreeBSD 10.0 Release Notes（2014-01）、LLVM 项目历史、Brooks Davis 等开发者邮件列表、freebsd.duckdb 数据库交叉验证——`SELECT commit_hash, author_date, author_name, message_subject FROM commits WHERE repo_name='freebsd-src' AND (message_subject LIKE '%Clang%' OR author_name LIKE '%Lattner%') ORDER BY author_date ASC LIMIT 10` 返回多条 Ed Schouten 2009 年 Clang import commit：(1) 2009-02-28 commit 802cb57e3432 "Add memmove() to the kernel, making the kernel compile with Clang"；(2) 2009-03-03 commit 60d234c583b2 "Make Netgraph compile with Clang"；(3) 2009-03-04 commit 5bdbd38305e2 "Make IPXrouted compile using Clang by using ANSI function declarations"；(4) 2009-06-02 commit ec2b103c267a "Import Clang, at r72732"（首次正式 import Clang 至 FreeBSD 基本系统）；(5) 2009-06-03 commit 922a2097733e "Import Clang, at r72770"；(6) 2009-06-03 commit 2659aeb5e51f "Import Clang, at r72805"；Chris Lattner 本人未直接 commit 至 FreeBSD（author_name LIKE '%Lattner%' 无匹配） ［A］

**史观**：总纲第 22 条与第 24 条——开源运动与许可证：Clang 的 BSD 许可证与 GCC 的 GPL 许可证选择体现 BSD 社区的许可证哲学

**辨析**：Clang 切换时间线常被简化——并非 FreeBSD 9.0 就默认 Clang，9.0 仅是 Clang 默认安装并可选项，10.0 才是 i386/amd64/arm 默认；部分架构（如 MIPS、PowerPC）切换时间晚于主流平台；[考据脚注] Ed Schouten 2009-06-02 commit ec2b103c267a "Import Clang, at r72732" 为 Clang 首次正式进入 FreeBSD 基本系统的精确节点，与 “FreeBSD 社区自 2009 年起推进 Clang 适配” 的叙事经 freebsd.duckdb 交叉印证
