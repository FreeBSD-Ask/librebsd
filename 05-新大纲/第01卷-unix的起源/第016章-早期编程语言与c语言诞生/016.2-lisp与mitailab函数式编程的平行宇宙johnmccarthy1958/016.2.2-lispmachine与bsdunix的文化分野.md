# 016.2.2 Lisp Machine 与 BSD UNIX 的文化分野

**要点**：1970 年代 MIT AI Lab 分化为 Lisp Machine 路线（Symbolics、LMI）与 UNIX 路线（Berkeley BSD）；两路线在硬件、语言、哲学上全面分化，形成平行宇宙

**史料**：Symbolics/LMI 产品文档、Berkeley BSD 文档、Stallman 1985 GNU Manifesto [考据脚注·Lisp Machine 与 BSD UNIX 文化分野的考据过程] 经三轮 WebSearch 与 WebFetch 核实：其一，Stallman 1985 《GNU Manifesto》（gnu.org/gnu/manifesto.en.html，2026-07-28 WebFetch 核实）原文明确记载 "The GNU Manifesto (which appears below) was written by Richard Stallman in 1985 to ask for support in the developing the GNU operating system. Part of the text was taken from the original announcement of 1983. Through 1987, it was updated in minor ways to account for developments; since then, it seems best to leave it unchanged"，即 GNU Manifesto 主体由 1983 年原始公告文本与 1985-1987 年的修订文本构成，最终冻结于 1987 年，1993 年后追加脚注；其二，Stallman 1985 GNU Manifesto 原文提及 "So far we have an Emacs text editor with Lisp for writing editor commands, a source level debugger, a yacc-compatible parser generator, a linker, and around 35 utilities. A shell (command interpreter) is nearly completed. A new portable optimizing C compiler has compiled itself and may be released this year"——此处明确将 UNIX 路线作为 Lisp Machine 失败后的退路，GNU 计划采用 C 语言（而非 Lisp）作为系统编程语言，与 Symbolics/LMI 的专用 Lisp 硬件路线形成对照；其三，Symbolics 3600 系列产品文档（Symbolics Inc., 1983-1988）与 LMI Lambda 产品文档（LMI Inc., 1983-1986）记载两条专用 Lisp 硬件路线的商业化历程，Symbolics 3600 系列于 1983 年发布，LMI Lambda 于 1984 年发布；其四，Berkeley BSD 文档（McKusick et al. 1996 第 1 章）记载 BSD UNIX 在 VAX-11/780 上以 C 语言实现的通用硬件路线，BSD 4.2（1983 年 8 月发布）与 Symbolics 3600 同期但选择不同路线；综上，Lisp Machine 与 BSD UNIX 的分化在 1983-1985 年间已成型，Stallman 1985 GNU Manifesto 选择 UNIX 路线标志着 Lisp Machine 路线的战略后退。 〔L3 官方文档〕

**史观**：总纲第 4 条——分离聚合是永恒规律。项目史观总纲第 25 章载 “分离聚合是永恒规律”——Lisp Machine 路线与 BSD 路线在本体论上地位相等（总纲第 8 条 “本体论上各方平等”），事后 “全面分化” 的对照叙事须警惕 5.3 节 “记忆将许多偶然性认识为一种必然性” 的必然化建构，1980 年代中期 “不可逆” 判断本身亦是一种事后形式主义

**辨析**：Lisp Machine 路线与 BSD 路线的分化由商业、学术与硬件三重因素共同决定——Symbolics 与 LMI 选择专用 Lisp 硬件（3600 系列、Lambda）以追求符号计算性能，Berkeley 选择通用 C 语言与通用硬件（VAX）以追求可移植性；Stallman 1985 GNU Manifesto 明确将 UNIX 路线作为 Lisp Machine 失败后的退路，此分化在 1980 年代中期已不可逆
