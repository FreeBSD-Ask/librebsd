# 010.5.12 本期提及的一手史料ports树移除EOL兼容代码的提交与FreeBSD11新发布

- 本期提及的一手史料：ports 树移除 EOL 兼容代码的提交与 FreeBSD 11 新发布节奏说明；Capsicum 化 traceroute 的 Phabricator 评审（含 Casper system.dns 用法）；The Tao of Tmux 一文及其引用的 McKusick《The Design and Implementation of the FreeBSD Operating System》第二版进程管理与终端处理章节、Linus Åkesson 的 TTY Demystified；BSD Router Project 9.70 发布公告（Fib4 转发改进、netmap 包生成器 IPv6 支持、OpenVPN 2.4 AES-GCM）；DragonFly UEFI 安装器提交与 HAMMER 构建脚本；Adrian Chadd 关于 AR9380 驱动 UDP 吞吐自 250 提至 355 Mbps 的推文；Computer Chronicles 1985 年 Unix 专题（archive.org 公有领域收藏）；Reddit 上在 NetBSD 运行 Minecraft 的指南（Linux 仿真加 Oracle JRE）；SDF 三十周年公告与 BBS Documentary 纪录片；听众 Jason 经 Windows Subsystem for Linux 在 Windows 10 原生运行 Tarsnap 的操作说明；Knoxbug 树莓派安装聚会公告。（BSD Now EP178，[3537.92-3623.44]，L2）
- 当事人一手自述：David Maxwell 回忆 20 世纪 80 年代中后期经 SunOS 初识 BSD，1993 年 8 月入职新公司的首项任务即将 NetBSD 自 0.8 升级至 0.9 且过程顺利，此后个人与职业生涯长期投入 NetBSD；2001 至 2006 年前后任 NetBSD 安全官约五年，其后任 FreeBSD 基金会董事一届两年，因日常职务繁忙未续任。（BSD Now EP73，[1411.60-1478.57]，L1）
- Maxwell 自述于 meetBSD 演讲 Pipecut 后专门致信管道概念发明人 Doug McIlroy，贝尔实验室管道原创者、其时执教达特茅斯学院，致谢并告知 Pipecut 构想；McIlroy 回信提及门下研究生已为非行导向输入开发 UNIX 类工具库，Maxwell 将调研列入计划（2937.14-2979.58）。（BSD Now EP73，[2937.14-2979.58]，L1）

**史观**：

- 总纲3 不存在进步，只有权力再分配：FreeBSD 11 发布节奏改革被主持人称为“非常必要的改变”（241.96-249.36），其本质并非单纯的技术进步而是维护负担的再分配：移植者从五版本验证矩阵中解放、ports 树得以跟进新驱动，代价是旧版本用户被限期升级，否则包系统直接拒绝安装；技术演进由支持边界的重划与维护成本的转嫁驱动，而非由先进性自身推动。（BSD Now EP178，[226.84-288.0]，L2）
- 总纲10 动手者创造历史：本期社群史叙述以动手者的一手经验为基底：12 岁架设 Renegade BBS、生日获赠专用电话线、邀同学到家中轮流连线游玩，被当事人自述为系统管理热情的发现时刻（2983.5-3016.92）；公共 shell 作为多数人的 Unix 入门路径同样由使用者记忆而非机构文献支撑。普通实践者的个人经验，而非台面人物与里程碑清单，构成这段历史的实质内容。（BSD Now EP178，[2953.7-3016.92]，L2）
- 总纲5 没有必然性，只有偶然性：Maxwell 与 NetBSD 的终身结缘并无必然性可言：他自述“我碰巧进入一份对 NetBSD 已有兴趣的工作”（1425.70-1433.73），入职首项任务恰是把 NetBSD 从 0.8 升到 0.9，一次寻常的工作分配把人送进尚处早期的社区并塑造其后数十年职业轨迹；技术史中的个人分岔多由此类偶然事件促成，而非任何先验规划。（BSD Now EP73，[1411.60-1437.82]，L1）
- 总纲10 动手者创造历史：本期技术史细节全由一线动手者承载：KMS/DRM 代码合入 head 依赖 Adrian Chadd 等测试者排障，USB 大容量存储驱动提交留言“先中止各条管道，再释放传输，否则小丑会撞上你”（5055.30-5061.98）记录了一处释放顺序的教训，Dru Lavigne 全职撰写 FreeNAS 文档，Maxwell 自陈其仓库痕迹多为零散 bug 修复与 pkgsrc 小项——BSD 的历史由这类无名修补累积而成。（BSD Now EP73，[5027.40-5073.98]，L3） [订正：原 否则 panic 会找上你，2026-09-30 SenseAudio 重转核对]

**辨析**：

- Pipecut 与 UNIX 哲学的紧张在演讲现场即被点破：Maxwell 转述 Jordan Hubbard 评议“你在构建一个把 Unix 里所有事都做了的工具”（2024.86-2030.24），并承认若要理解全部命令则项目永无完工之日；其折中是 black box 机制——单引号包裹的命令以 exec 原样执行，工具只对其输出作弱假设。对“每程序只做一件事并做好”的偏离与守成，构成对该哲学一次具体的当代检讨。（BSD Now EP73，[2015.46-2043.30]，L2）
- LibreSSL 替代 FreeBSD base 系统 OpenSSL 在 2015 年初仍是未竟之问：base 更新受制于测试与发布流程而滞后于 ports，committers 已开始记录以 make.conf 变量改用 ports OpenSSL 并试验 LibreSSL portable 的过程，OpenZFS 团队亦透露考虑在 ports 与 base 双线切换；主持人提醒“不愿看到他们在未权衡全部影响前就切换”（1084.02-1088.02），且部分 Python ports 的不兼容标记属陈年遗留而非实际依赖。（BSD Now EP73，[943.92-1090.34]，L2） [订正：原 OPNsense 团队，2026-09-30 SenseAudio 重转核对]
