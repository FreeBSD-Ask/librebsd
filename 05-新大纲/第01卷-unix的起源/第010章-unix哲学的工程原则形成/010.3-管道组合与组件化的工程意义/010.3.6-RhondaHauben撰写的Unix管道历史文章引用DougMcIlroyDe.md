**史观**：

- 总纲5 没有必然性，只有偶然性：管道从 1969 年提议到 1972 年实现，其间经历了被质疑“缺乏想象”的搁置，具体技术路径由当时的人与偶然条件决定，而非线性必然。（BSD Now EP166，[233.7-308.86]，L3）
- 总纲9 经验优先：McIlroy 以“简单管线连接程序与数据”的经验表述总结工程实践，Unix 的哲学原则从具体动手经验中凝结而成。（BSD Now EP166，[398.14-414.98]，L3）
- 总纲1 一切真历史都是古代史：主持人感叹管道今日被当作理所当然，而忽略其曾有“没有管道的时代”，历史书写把建构产物自然化为恒常存在。（BSD Now EP166，[239.06-247.66]，L3）
- 总纲4 分离聚合是永恒规律：Adhoku 以 jail 做应用级分离、以反向代理做流量聚合，呈现分离与聚合的交替结构，而非单一集中或单一分散。（BSD Now EP166，[1636.04-1775.64]，L3）
- 总纲10 动手者创造历史：MySQL 与 ZFS 的优化均来自动手部署者的具体记录，性能改进由实际操作者而非抽象方案推动。（BSD Now EP166，[566.72-1010.56]，L3）
- 总纲9 经验优先：主持人的全部论证以个人运维经验为据：单用户模式手工修复文件系统的经历、以旧脚本稍加修改应对新任务的复用习惯、图形环境中仍开文本终端的个人动作史——CLI 的价值判断由动手者的经验累积得出，而非抽象性能比较，工具偏好的知识形态是经验的。（BSDTalk EP127，[102.72-125.72]，L1）
- 总纲15 文化即形式主义：主持人转述的 Unix 哲学——写程序只做一件事并做好、再以管道组合，Unix 是程序员为程序员设计的操作系统——显示 CLI 与 GUI 之分并非纯技术优劣，而是不同共同体形式偏好之争：文本作为统一表示形式使系统整体可读、可组合、可传承，界面之争实为共同体文化的表达之争。（BSDTalk EP127，[267.80-288.16]，L1）
- 总纲10 动手者创造历史：主持人以乐高积木作比提出工具本位宣言：自由操作系统效仿的是 Unix 哲学而非 Windows 哲学，其力量不在某个功能齐备的成品应用，而在一切皆文本文件、众多小工具经管道自由组合的构造过程；把 BSD 仅当作免费 Windows 克隆，会错失这套系统真正的力量，使用者必须亲手在命令行中学会拼装。（BSDTalk EP14，[265.45-439.50]，L2）
- 总纲5 没有必然性，只有偶然性：BSDCan 的创建没有任何机构授权或长期规划作为前提，它源于一次个人化的类比行动：Langille 看到相识的 Linux 会议组织者能够办成，便认定自己在渥太华同样可以；社区性制度设施由此从具体个人的偶然模仿中生长出来。（BSDTalk EP14，[490.23-504.44]，L1）
