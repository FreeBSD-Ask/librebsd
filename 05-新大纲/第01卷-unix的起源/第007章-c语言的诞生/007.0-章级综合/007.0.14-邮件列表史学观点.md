# 007.0.14 邮件列表史学观点

<!-- MAIL_INSIGHT: <1989Jul12.014327.15180@jarvis.csri.toronto.edu> -->
**观点**：1989 年 7 月 12 日，D. Hugh Redelmeier 在 Usenet 上发表了关于 C 语言函数原型（function prototypes）的详细分析，以 `int func1(const int)` 与 `int func1(int p)` 之间的兼容性为例，指出 C 标准草案（ANSI C）中 3.5.4.3 节与 3.1.2.6 节之间存在内部不一致性——类型限定符的兼容性规则与复合类型构造规则产生了逻辑矛盾。
**邮件来源**：D. Hugh Redelmeier <hugh@dgp.toronto.edu>，Usenet comp.lang.c，1989-07-12，Message-ID: <1989Jul12.014327.15180@jarvis.csri.toronto.edu>
**史学意义**：这份 1989 年的讨论揭示了 C 语言标准化过程中类型系统的内在张力——Ritchie 1972-1973 年设计的原始 C 语言类型系统是基于‘信任程序员’的实用主义哲学，而 ANSI C 标准化委员会试图引入更严格的类型检查时，与原始设计哲学产生了冲突。这一张力在 C 语言的后续演化（C99/C11/C23）中持续存在。
