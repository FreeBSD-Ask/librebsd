# 025.1.3 总纲10动手者创造历史Callahan以持续移植编译器教学与组织用户组的具体劳动

- 总纲10 动手者创造历史：Callahan 以持续移植编译器、教学与组织用户组的具体劳动扩展 OpenBSD 生态，体现动手者的长期积累。（BSD Now EP422，[379.4-752.7]，L1）[订正：原 [384.1-735.94]，2026-09-30 SenseAudio 重转核对]
- 总纲10 动手者创造历史：本期几乎是一部“动手者如何再生产动手者”的实录：Kois 指导 Reuschling 取得 commit bit，Reuschling 又以 mentoring 培养后来者，最终在节目现场为 Alan Jude 设三位导师启动同一路径；与之呼应的是 45 分钟送达的 BHyve 补丁与一夜长出的安装器特性——项目的延续不靠制度文本，而靠一双手把手地把下一双手带进树里。（BSD Now EP41，[1124.36-2332.20]，L1）
- 总纲6 和解优于斗争：受访者对邮件列表与 IRC 冲突的观察揭示了解释学处境：文本交流剥离语气与人格，技术分歧极易升级为性格对抗且难以收束；会议把对话还原为面对面的在场交流，冲突通常可当场化解并确立共同基础——OpenBSD 与 BHyve 开发者被置于同一房间数小时而非隔空争论，数日后即达成可行结果；开源社区的常态运转依赖这种周期性的和解机制。（BSD Now EP41，[1896.20-2091.16]，L1）
- 总纲10 动手者创造历史：认证体系由志愿者自建考纲、自筹资金、以 DVD 销售供养专业心理测量师，备考路径完全公开自学，是社区动手者自下而上搭建人力资本基础设施、不依赖任何基金或企业赞助的典型实践。（BSDTalk EP209，[426.54-777.62]，L1）
- 总纲8 本体论上各方平等：BSDA 把 FreeBSD、NetBSD、OpenBSD 与 DragonFly BSD 四系统纳入同一张考卷并强调共同性基础，不以任一系统为中心，认证制度本身即在制度层面承认四大 BSD 的对等地位。（BSDTalk EP209，[450.14-525.16]，L1）
- 总纲17 证明世界先于解释和改造世界：BSDP 选择以动手实验考试作为技能的确证方式，把认证的效力落在可操作的真实任务上，而非纸面知识陈述，体现以实际证明先于解释性资格的理念。（BSDTalk EP209，[249.42-287.42]，L1）

**辨析**：

- NYC*BUG 的成立年份与“最古老用户组之一”的说法为当事人估计，需与用户组档案及其他 BSD 用户组成立记录交叉核对。 [存疑脚注] 用户组成立年份为当事人记忆性表述，宜与其他地区 BSD 用户组史料比对。（BSD Now EP422，[2090.4-2120.4]，L4）[订正：原 [2090.58-2102.08]，2026-09-30 SenseAudio 重转核对]
- OpenBSD 磁盘性能悬案：自 Arch Linux（经 GRsecurity 与 PaX 长期加固）转向 OpenBSD 5.5 stable 的听众报告 SSD 上 iostat 峰值仅约 180MB/s，而 Linux 全盘 AES-256 加密可达 350MB/s；主持人指出 OpenBSD 出于安全考量以 Giant Lock 将多核操作强制于单锁之下、多核性能受限，同时提醒 Linux 数字可能包含不安全的写缓存，并强调 FFS/UFS 本身并不慢，建议核对 CPU 占用；该问题当期未获最终解释，留待 OpenBSD 社区反馈。 [存疑脚注] 性能差异成因仅为主持人基于 Giant Lock 架构的推断，当期无实测结论（BSD Now EP41，[3094.68-3315.54]，L2）
