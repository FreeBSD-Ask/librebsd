# 006.3.2 IBM DOS/360 的批处理路径

**要点**：IBM DOS/360 (Disk Operating System) 为 System/360 的简化版操作系统，以批处理为主；1966 年发布，针对中小型 360 机型；与 UNIX 同期但设计目标完全不同

**史料**：IBM DOS/360 手册、IBM Systems Journal ［A］

**史观**：总纲第 6 条——批处理与分时的路线分化

**辨析**：DOS/360 与 OS/360 的关系常被混淆——DOS/360 为简化版

**文献**：IBM DOS/360 System Control Manual (1966)；Emerson Pugh“IBM's 360 and Early 370 Systems” (1991) ［ 据 SaltzerSchroeder (19USA 一手文献印证消解^doubt-resolved-34：DOS/360 与 OS/360 的关系常被混淆，Pugh 1991 侧重硬件系统史，对 DOS/360 软件设计细节描述有限，须对照 IBM DOS/360 System Control Manual 原始文档核验。］
