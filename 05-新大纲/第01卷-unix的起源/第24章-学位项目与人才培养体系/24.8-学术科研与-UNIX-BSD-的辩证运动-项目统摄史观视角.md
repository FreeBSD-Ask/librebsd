# 24.8 学术科研与 UNIX/BSD 的辩证运动——项目统摄史观视角

## 要点

学术科研与 UNIX/BSD 的关系并非单向（学术生产 BSD 或 BSD 服务学术），而是辩证运动——学术科研作为 BSD 的 “合法性生产者”（CSRG 团队隶属 Berkeley EECS、DARPA 资助 CSRG 开发 BSD、CSRG 团队通过 SOSP/TOCS 等顶会顶刊发表 BSD 论文使 BSD 获得 CS 学术合法性）；BSD 作为学术科研的 “物质基础设施”（4.2BSD TCP/IP 使 ARPANET 与学术机构互联成为可能、BSD UNIX 使 1980-1990 年代学术 CS 研究者具有统一开发环境、BSD 工具链如 grep/awk/sed/vi 使学术研究者具有高效工具）。
学术谱系与 BSD 谱系的交叉网络：CSRG 成员的学术谱系——Bob Fabry（Berkeley EECS 教授）、Bill Joy（Berkeley EECS 硕士 →Sun 联合创始人）、Marshall Kirk McKusick（Berkeley EECS 博士 →Berkeley EECS 教授 + FreeBSD Foundation 董事）、Mike Karels（Berkeley EECS→FreeBSD Core Team）、Keith Bostic（基思·博斯蒂克）（Berkeley EECS→FreeBSD Core Team）；CSRG 的学术谱系直接塑造 BSD UNIX 谱系；BSD 谱系的分支（FreeBSD/NetBSD/OpenBSD/DragonFly BSD）亦各自与学术机构形成交叉网络——FreeBSD 与 Berkeley、NetBSD 与 MIT/CMU、OpenBSD 与 Calgary 大学、DragonFly BSD 与 Oregon State University。
学术合法性认证与 BSD 的双向塑造：BSD 通过 SOSP/OSDI/TOCS 等顶会顶刊论文（McKusick 1984 FFS、McKusick 1989 4.3BSD 设计、Karels 1990 4.3BSD-Reno、Bostic 1991 4.4BSD-Lite 等）获得 CS 学术合法性认证；BSD 的学术合法性反过来吸引学术研究者使用与改进 BSD——1990 年代起 Berkeley CSRG 解散后，FreeBSD/NetBSD/OpenBSD 继续作为学术研究载体（如 Robert Watson 在 Cambridge 的 CHERI/Capsicum 基于 FreeBSD、Poul-Henning Kamp（波尔-亨宁·坎普） 的 Varnish 基于 FreeBSD）；学术合法性认证（顶会顶刊论文）与开源社区合法性认证（commit bit、mailing list 地位）形成双轨制。
学术科研范式转变与 BSD 的位置：1960-1980 年代 “系统开发 + 学术研究” 统一范式（CSRG 既开发 BSD 又发表论文）在 1990 年代后分化——学术研究侧转向 SOSP/OSDI 论文驱动的 “小创新 + 理论严谨” 范式（如 Exokernel、Singularity、Barrelfish 等学术 OS 项目），系统开发侧转向 Linux/开源社区驱动的 “工程实用 + 大规模部署” 范式（如 Linux Kernel、FreeBSD、OpenBSD 等社区 OS 项目）；BSD 谱系在分化中占据特殊位置——FreeBSD/OpenBSD 在工程实用侧持续演化（如 Capsicum、pledge/unveil 等安全机制），同时通过 Robert Watson 等 Cambridge 学者保持与学术研究侧的联系（CHERI/Capsicum 论文发表于 ASPLOS 2015 等）。
当代学术科研的 BSD 基础设施化：至 2026 年，BSD/UNIX 已深度基础设施化——Linux 主导超算（Top500 2025 年 11 月约 100% 跑 Linux），macOS 主导 CS 研究者桌面（约 40-50%），FreeBSD 在 Netflix CDN、WhatsApp 等基础设施中持续应用；BSD 的 “基础设施化” 使其从 “显性研究对象” 转为 “隐性研究环境”——CS 研究者使用 macOS/Linux 但不再将 BSD 本身作为研究对象，BSD 研究转化为少数系统研究者（如 FreeBSD Foundation 资助的研究者）的专门领域。

#### 史观

本子节史观映射覆盖以下 7 条相关总纲，皆已回溯到 29 章原文核验：

**总纲 1（形式主义是世界的真实存在）**——据原文第 1 章 1.1-1.2 节：

> “形式主义是世界的真实存在，其余一切存在皆不真实。”
>
> “人类的认识本质上是一种对存在的人化过程，即形式主义化过程。”

学术科研与 UNIX/BSD 的关系作为形式主义化的建构——“学术科研生产 BSD” 与 “BSD 服务学术科研” 的二元划分并非 “客观事实” 的发现，而是史家对二者关系的主体性归类；同一研究项目（如 CHERI/Capsicum）可能同时是 “学术科研”（Cambridge 博士论文）与 “BSD 开发”（FreeBSD commit），所谓 “学术” 与 “工程” 的边界是形式主义化的产物。

**总纲 4（分离聚合是永恒规律）**——据原文第 4 章 4.1 节：

> “分离聚合是世界发展的规律。分久必合，合久必分，具有必然性。”

学术科研与 BSD 开发从聚合（1960-1980 年代 CSRG 既开发 BSD 又发表论文）到分离（1990 年代后学术 OS 转向 Exokernel/Barrelfish 等独立项目，BSD 转向社区驱动），再到部分再聚合（2010 年代后 Robert Watson 等 Cambridge 学者将 CHERI/Capsicum 论文与 FreeBSD commit 结合）——这一系列分离聚合并非线性进步，而是不同形式主义的循环呈现。

**总纲 3（不存在进步，只有权力再分配）**——据原文第 3 章 3.2 节：

> “所谓进步只不过是权力再分配，把演讲台上的人割一茬，换他来一个样。”

学术科研与 BSD 关系的发展并非 “协作深化” 的进步，而是权力的再分配——CSRG 时代 Berkeley 主导 BSD 学术合法性生产（CSRG 团队同时是 Berkeley EECS 教授与 BSD 核心开发者），CSRG 解散后学术合法性生产权力从 Berkeley 分散至 Cambridge（Robert Watson/CHERI）、Calgary（OpenBSD）、Oregon State（DragonFly BSD）等多点；所谓 “BSD 学术化必然深化” 的叙事掩盖了 CSRG 解散后 BSD 与学术研究联系的弱化。

**总纲 5（没有必然性，只有偶然性）**——据原文第 5 章 5.2 节：

> “将英雄人物的出现必然化是一种机械的错误，没有认识到偶然性和自由的意义。”

若 Bob Fabry 未在 1977 年启动 BSD 项目，若 Marshall Kirk McKusick 未在 1984 年完成 FFS 论文，若 Robert Watson 未在 2010 年代将 CHERI 与 FreeBSD 结合，学术科研与 BSD 关系史会完全不同。所谓 “BSD 必然与学术科研结合” 的叙事是史家的事后重构。

**总纲 10（动手者创造历史）**——据原文第 14 章 14.1-14.2 节：

> “这个世界不是靠什么精英也不是靠什么人民更不是靠什么其他人运转的，而是我们这些老实人，才让世界运转了起来。”

Bob Fabry 亲自撰写 DARPA 合同提案并启动 BSD 项目，Marshall Kirk McKusick 亲自实现 FFS 与 BSD 内核，Robert Watson 亲自实现 CHERI/Capsicum 并将论文与 FreeBSD commit 结合——这些是动手者的实践，而非 “Berkeley 决定” 或 “Cambridge 决定” 等组织决策的产物。须注意：DARPA 资助与 Cambridge 教职是外部条件，但具体研究与实现是研究者的主体性选择。

**总纲 2（历史是形式主义化的非存在）**——据原文第 2 章 2.5 节：

> “谁试图诠释历史，谁就在篡改历史。”

所谓 “学术科研与 BSD 辩证运动” 的判定本身即形式主义化的非存在——若以工业研究为主线（Bell Labs、IBM Research、Xerox PARC），若以开源社区为主线（Linux Kernel Community、Apache Foundation），若以国家实验室为主线（LANL、ORNL、Sandia），“CS 学术与 BSD 关系史” 会呈现完全不同的脉络。本子节选取 “学术科研与 BSD 辩证运动” 为主线，但这一选取本身须以自反性声明显化。

**总纲 7（理论必须自反）**——据原文第 6 章 6.3 节：

> “真正的理论体系应该是自反的。一个理论越宣称自己怎样，它在实质上就越不怎样，这是一种辩证的自反。”

本子节对 “学术科研与 BSD 辩证运动” 的叙述本身亦须被自反地对待——所谓 “辩证运动” 的判定本身即史家的形式主义化建构，“学术科研” 与 "BSD" 作为分析范畴皆是史家的事后归类，二者关系并非 “客观辩证” 的发现，而是史家对复杂历史事件的形式主义化整理。本子节承认 “辩证运动” 叙述本身的非自足性，欢迎被更自反的释读所超越。

**自反性声明**：本子节选取 “学术科研与 BSD 辩证运动” 为主线，但这一选取本身即形式主义化的非存在。若以工业研究为主线（Bell Labs UNIX/C、IBM Research RISC/System R、Xerox PARC Smalltalk/Alto），若以开源社区为主线（Linux Kernel Community、Apache Foundation、Python Foundation），若以国家实验室为主线（LANL/IBM BlueGene、ORNL/Cray Jaguar、Sandia/Red Storm），“CS 学术与 BSD 关系史” 会呈现完全不同的脉络。本子节承认主轴选取本身是史家的形式主义化决策，欢迎被更自反的释读所超越。

#### 辨析

**CSRG 时代 “系统开发 + 学术研究” 统一范式辨析**：部分二手资料称 “CSRG 时代学术研究与系统开发完全统一”，但 CSRG 团队内部亦有侧重差异——Bob Fabry 侧重学术（Berkeley EECS 教授），Bill Joy 侧重工程（Berkeley EECS 硕士后加入 Sun），Marshall Kirk McKusick 横跨学术与工程（Berkeley EECS 博士 + 教授，同时是 BSD 核心开发者）。本子节采用 “CSRG 时代学术与工程高度聚合但内部亦有侧重差异” 的限定性表述。

**CSRG 解散后 BSD 与学术关系辨析**：部分二手资料称 “CSRG 解散后 BSD 与学术完全脱钩”，但 2000 年代后 Cambridge（Robert Watson/CHERI）、Calgary（OpenBSD hackathons 在 Calgary 大学举办）、Oregon State（DragonFly BSD 由 Matthew Dillon（马修·狄龙） 在 Oregon 持续开发）等学术机构仍与 BSD 保持联系；考据结论：CSRG 解散后 BSD 与学术直接联系弱化但未完全脱钩。本子节采用 “CSRG 解散后 BSD 与学术直接联系弱化但未完全脱钩（Cambridge、Calgary、Oregon State 等仍保持联系）” 的限定性表述。

**BSD 学术合法性认证双轨制辨析**：部分二手资料称 “BSD 学术合法性通过顶会顶刊论文认证”，部分称 “通过 commit bit 与 mailing list 地位认证”；考据结论：BSD 学术合法性认证呈现双轨制——顶会顶刊论文（如 McKusick 1984 FFS、Watson 2015 CHERI）+commit bit 与 mailing list 地位（如 FreeBSD Core Team、OpenBSD Leader）——双轨制使 BSD 同时具有学术合法性（论文）与社区合法性（commit）。本子节采用 “BSD 学术合法性认证双轨制” 的限定性表述。

**BSD 基础设施化的影响辨析**：部分二手资料称 “BSD 基础设施化使 BSD 研究边缘化”，部分称 “BSD 基础设施化使 BSD 研究深化”；考据结论：BSD 基础设施化使 BSD 从 “显性研究对象” 转为 “隐性研究环境”，对 BSD 研究具有双重影响——一方面使 BSD 本身作为研究对象的可见度降低，另一方面使 BSD 作为研究环境的渗透度提高。本子节采用 “BSD 基础设施化具有双重影响（显性研究对象可见度降低 + 隐性研究环境渗透度提高）” 的限定性表述。

### 关键术语

- **CSRG（Computer Systems Research Group）**：1977-1995 年 Berkeley EECS 下属的研究小组，开发 BSD UNIX 1BSD-4.4BSD-Lite，是学术科研与 BSD 直接结合的典型载体。
- **DARPA IPTO/I2O**：美国国防部高级研究计划局信息处理技术办公室（后改名信息创新办公室），1962 年设立，Licklider 任首任主任，资助 BSD/CSRG、ARPANET、Project MAC、SAIL 等关键项目。
- **四大枢纽**：CMU、Stanford、MIT、Berkeley 四所大学，1965-1980 年代在 CS 学科化早期具有举足轻重地位，与 BSD/UNIX 谱系形成交叉网络。
- **顶会顶刊**：CS 领域顶级会议（SOSP/OSDI/ASPLOS/POPL/SIGCOMM/NeurIPS 等）与顶级期刊（CACM/JACM/TOCS/TSE 等），是 CS 学术合法性认证的核心渠道。
- **可复现性危机**：2016 年 *Nature* 调查显示 70% 研究者无法复现他人实验的科研危机，CS 领域体现为训练数据未公开、训练成本过高、超算资源不平等等。
- **AI for Science**：2010 年代后期兴起的跨学科研究范式，以 AlphaFold（蛋白质结构预测）、GNoME（材料发现）等为代表，使自然科学研究范式发生根本性转变。
- **BSD 学术合法性认证双轨制**：BSD 通过顶会顶刊论文（学术合法性）+commit bit 与 mailing list 地位（社区合法性）形成双轨制认证。
- **BSD 基础设施化**：BSD/UNIX 至 2026 年深度基础设施化——Linux 主导超算、macOS 主导 CS 研究者桌面、FreeBSD 在工业基础设施中持续应用，使 BSD 从显性研究对象转为隐性研究环境。
