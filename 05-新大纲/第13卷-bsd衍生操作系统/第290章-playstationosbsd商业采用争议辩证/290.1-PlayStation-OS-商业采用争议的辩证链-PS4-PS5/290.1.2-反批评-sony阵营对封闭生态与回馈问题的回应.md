# 290.1.2 反批评——Sony 阵营对封闭生态与回馈问题的回应

  - 要点：Sony 阵营（含 BSD 许可证哲学辩护者）对上述三重张力的回应沿四条线索展开——（1）BSD 许可证的设计本意即允许封闭使用：BSD 许可证的核心自由之一是 “允许衍生作品闭源”，这是 BSD 与 GPL 的根本哲学分歧——FreeBSD 社区选择 BSD 许可证即已同意商业实体可封闭化使用而无须 copyleft 回馈，Sony 的封闭化使用是 BSD 许可证赋予的合法权利，非 “回馈不对称” 的过错；批评 Sony 封闭化使用等于否定 BSD 许可证本身的设计哲学，是 GPL 立场对 BSD 立场的越界要求；（2）Sony 通过非 commit 渠道回馈 FreeBSD 社区：Sony 工程师在 BSDCan 等会议披露 PlayStation 对 FreeBSD 的使用，PS4 系统软件开源软件声明页面公开列出 FreeBSD Kernel 等开源组件（履行 BSD 许可证的版权声明义务），Sony 通过公开演讲、合规披露、技术会议参与等形式回馈 FreeBSD 社区——回馈不限于 commit，亦包括使用披露、会议参与、合规履行；（3）游戏主机的封闭生态是行业普遍特征而非 Sony 独有：Xbox（Microsoft）、Nintendo Switch 均维持封闭生态，游戏主机厂商通过数字签名认证、固件加密、DRM 等机制控制可运行代码——Sony 的封闭化是游戏主机行业的结构性约束而非对 BSD “开放” 传统的背叛；游戏主机的封闭生态使 Sony 须对 PS4/PS5 上运行的所有代码承担安全责任（防止盗版、防止恶意代码、保护未成年人），封闭化是商业与法律责任的必然要求；（4）Sony 对 Linux 上游的 1014 commits 反映 Sony 工程师对开源社区的实质回馈：Sony 工程师（如 <frank.rowand@sony.com> 119 次、<geoffrey.levand@am.sony.com> 152 次）对 linux-kernel 的持续贡献证明 Sony 并非 “零回馈”——Sony 选择对 Linux 上游回馈而非 FreeBSD 上游回馈，可能反映 Sony 内部 Linux 部署更广（如 Sony 网络摄像机、Sony 嵌入式设备），而非对 FreeBSD 的故意忽视
