- **GPU/DRM**（硬件支持，2005–2026）：显卡驱动：Linux DRM 2010s 成熟，FreeBSD 借 LinuxKPI 移植 DRM
- **ARM**（硬件支持，2005–2026）：ARM64 支持：Linux 2012 官方；FreeBSD 2016 起
- **性能优化**（性能，2004–2026）：持续性能工程：内核网络/存储/调度微优化
- **SMP/多核**（进程/并行，2004–2026）：对称多处理与内核并行化（自旋锁→睡眠锁→无锁结构）
- **内存管理**（内存管理，2005–2026）：虚拟内存、slab 分配、大页/HugeTLB 透明大页
- **无线**（网络，2002–2026）：802.11 无线栈：FreeBSD 用 net80211，Linux 用 mac80211/cfg80211
- **USB**（硬件支持，2001–2026）：USB 栈：FreeBSD usb4bsd 重写，Linux 成熟
- **TLS/加密**（安全，2005–2026）：传输加密：OpenSSL→LibreSSL（OpenBSD 2014 分叉）
- **TCP/IP**（网络，2005–2026）：TCP 拥塞控制演进：Reno→NewReno→CUBIC，BSD 与 Linux 并行
- **虚拟化**（虚拟化，2005–2026）：CPU 虚拟化：FreeBSD bhyve、Linux KVM/Xen、NetBSD Xen、OpenBSD vmm
- **调度器**（进程/并行，2005–2026）：任务调度策略：FreeBSD ULE、Linux CFS/EEVDF、NetBSD sched_4BSD
- **Clang/LLVM**（工具链，2006–2026）：C 编译器栈：FreeBSD 2012 用 Clang 取代 GCC（许可证原因）
- **许可/治理**（治理，2005–2026）：许可证与治理：BSD 许可宽松，Linux GPL；基金会治理（FreeBSD/NetBSD/OpenBSD 基金会）
- **NUMA**（硬件支持，2005–2026）：非一致内存访问：多路 CPU 的内存亲和性调度
- **RISC-V**（硬件支持，2016–2026）：开放指令集：Linux 2017；BSD 陆续支持
- **eBPF**（可观测性，2014–2026）：内核可编程字节码虚拟机（2014），网络/追踪/安全
- **UFS/FFS**（存储，2005–2026）：伯克利快速文件系统（1984），soft updates（1998）
- **KVM**（虚拟化，2006–2026）：Linux 内核虚拟机（2006），依托 VT-x/SVM 硬件虚拟化
