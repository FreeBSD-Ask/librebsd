# 280.3.2 FreeBSD 内核 ABI 政策：大版本内稳定，跨大版本不保证

  - 要点：FreeBSD 内核 ABI 政策为“大版本内稳定，跨大版本不保证”——同一大版本（如 FreeBSD 14.x）内的内核 ABI 稳定，跨大版本（如 FreeBSD 13.x → 14.x）的内核 ABI 不保证稳定。这一政策使 FreeBSD 在大版本升级时常需要重新编译内核模块与部分用户空间程序。FreeBSD 的 ABI 政策比 Linux 保守——Linux 承诺用户空间 ABI 跨版本稳定，FreeBSD 仅承诺大版本内稳定。FreeBSD ABI 政策的工程后果是——FreeBSD 在大版本升级时较痛苦，但内核内部 API 可以在跨大版本时进行必要的重构。
  - **FreeBSD 与 Linux 内核 ABI 政策对照表**：

| 维度 | Linux | FreeBSD |
| --- | --- | --- |
| 大版本内 ABI | 稳定 | 稳定 |
| 跨大版本 ABI | 稳定 | 不保证稳定 |
| 大版本升级影响 | 用户空间无须重新编译 | 常需重新编译内核模块与部分用户空间 |
| 内核内部 API | 频繁变化 | 跨大版本可进行必要重构 |
| 企业市场竞争力 | 强 | 较弱（大版本升级痛苦） |
