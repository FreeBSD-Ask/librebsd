# 284.2.1 从 FreeBSD/NetBSD/OpenBSD 分叉的衍生

  - 要点：衍生操作系统以 FreeBSD（JunOS、PlayStation、TrueNAS、pfSense）与 NetBSD（部分嵌入式）为主要上游；同一 BSD 基础经不同产品工程形成异构谱系，体现 “同源多枝”。
  - **4 个 fork 项目 2016/2017 年 merge commit 比例对照表**：

- 史料：各产品官方架构文档、FreeBSD 衍生列表（项目官网）；openbsd.duckdb 查询 L7.1.1 显示：7 个 fork 项目（trueos-src、ghostbsd-src、hardenedbsd-src、midnightbsd-src、truenas-middleware、opnsense-core、pfsense-src）的 merge commit 比例时间序列汇总，反映 fork 项目与上游 FreeBSD 的同步节奏与本地分歧量——ghostbsd-src 2015 年 merge_commits = 543/total = 25,675（2.1%）、2017 年 601/20,562（2.9%），hardenedbsd-src 2016 年 merge_commits = 10,726/total = 44,207（24.3%）、2017 年 9,667/40,943（23.6%），pfsense-src 2016 年 merge_commits = 661/total = 28,813（2.3%）、2017 年 629/26,654（2.4%），trueos-src 2016 年 merge_commits = 393/total = 18,601（2.1%）、2020 年 8/154（5.2%），hardenedbsd-src 的 merge commit 比例显著高于其他 fork 反映其频繁同步上游 hardened 分支的工程模式［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］〔L1 代码/构建产物/L3 官方文档与公告〕
- 史观：总纲第 6 条——技术路线分化与并行演化；统计结论印证：C-54（跨数据库关联分析 Task 28 多元 Spearman 相关矩阵）显示 ghostbsd-src 与 pfsense-src commit 月度量强相关（rho = 0.9355），反映 BSD 衍生谱系在 “同源多枝” 拓扑下的工程节奏同源——多个 fork 项目虽产品形态各异（防火墙/桌面/存储）但 commit 时间序列呈强正相关，0 信任原则适用：commit 量相关不等于工程内容相关，且 hardenedbsd-src 2016 年 merge 比例 24.3% 显著高于其他 fork（2.1%-2.3%），反映其工程模式（频繁重基 hardened 分支）与其他 fork 的差异；统计结论 [C-41] 资料数据库.duckdb references 表总数 16,867 条（SQL 查询 `SELECT COUNT(*) FROM "references"`，查询日期 2026-07-27）构成 BSD 衍生谱系叙事的文献计量学基础——其中卷章集中度 Top 10% 章节占 28.23%、Gini 0.3913（统计结论 C-44，文献计量学分析 Task 23）反映参考文献在第十卷 “扩散的谱系” 等核心卷章的集中倾向，与 BSD 衍生谱系 “同源多枝” 拓扑下少数核心 fork 项目（如 hardenedbsd-src、pfsense-src、trueos-src）占据主要 commit 量与文献引用量的格局相互印证，0 信任原则适用：references 卷章集中度反映编纂期史料分布而非 BSD 衍生谱系本身的客观重要性分布，且 Top 10% 章节占比 28.23% 属中等集中度（Gini 0.3913 < 0.5），不可解读为 “少数 fork 项目垄断 BSD 衍生生态”
- 辨析：衍生 “基于 FreeBSD” 的程度各异（部分仅用网络栈，部分用完整用户空间），须逐产品界定；freebsd.duckdb 查询 L7.1.1 的 fork 分歧识别须警惕局限——fork 项目的 commit 量包含合并上游的 commit，识别本地特有 commit 须通过 merge commit 与 parent_hashes 交叉验证，不可仅凭时间戳，merge commit 比例高可能反映频繁同步上游而非本地创新，hardenedbsd-src 2014 年后 merge commit 比例的跳升（2013 年 442/23,986 = 1.8%，2014 年 5,986/34,708 = 17.2%）须考据 HardenedBSD 项目重基（rebase）策略变更的工程背景；【0 信任原则·references 表录入偏差】统计结论 [C-41] 16,867 条 references 中 `gbt7714` 字段为自由文本著录、格式不统一，年份正则提取率仅 44.42%（7,493/16,867），卷章字段（`vol`/`ch`）填充率影响 C-44 卷章集中度计算，须结合提取率与填充率审慎解读；【0 信任原则·卷章集中度解读】C-44 Top 10% 章节占 28.23% 与 Gini 0.3913 仅反映编纂期 references 在卷章维度的分布，不等于 BSD 衍生谱系本身的客观重要性分布，且集中度受编纂者录入偏好影响（部分 fork 项目史料录入更完整），须结合 freebsd.duckdb 实际 commit 量分布交叉验证；详见文献计量学分析.md Task 22/Task 23 与考据记录 20260727_第十卷-统计学整合.md
