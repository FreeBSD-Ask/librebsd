# 291.0.1 要点

- 本节作为统一审视的合图层，须同时承认两层判断——（1）不可调和性：OtherOS 移除争议与 PS4/PS5 商业采用争议在 BSD 许可证哲学框架内具有结构性不可调和性——BSD 许可证“允许封闭”的合法权利行使（Sony 阵营立场）与 FreeBSD 社区“期待回馈”的诉求（BSD/Linux 阵营立场）各自成立，差异不是“对错”而是“许可证结构内的利益分配差异”；（2）和解路径：两层判断可在“合法”与“合乎伦理期待”的区分上并存——Sony 行使许可证授予的封闭权利属法律合法范畴，社区的回馈诉求属许可证之外的伦理期待范畴，两者并存不悖；具体而言，OtherOS 移除与 PS4/PS5 封闭采用均不违反 BSD 许可证条款，社区所能主张者是许可证外的伦理对话与自愿回馈，而非法律强制（详见 266.8 节审视）
