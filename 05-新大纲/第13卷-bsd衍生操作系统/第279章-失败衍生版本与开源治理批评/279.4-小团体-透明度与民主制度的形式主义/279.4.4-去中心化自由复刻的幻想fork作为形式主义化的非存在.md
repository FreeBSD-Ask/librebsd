# 279.4.4 去中心化自由复刻的幻想：fork 作为“形式主义化的非存在”

  - 要点：开源运动的“去中心化自由复刻”（fork freedom）常被视为开源许可证的核心价值——任何人都可以 fork 项目并独立发展，但实际 fork 的成功率极低。BSD 史上的 fork 包括 386BSD→FreeBSD/NetBSD（1993 年）、FreeBSD→DragonFly BSD（2003 年）、NetBSD→OpenBSD（1995 年 10 月 fork，1996 年 6 月 2.0 首发）等成功案例，但更多 fork 是失败的——如 FreeBSD→DesktopBSD（2006 年，已停摆）、FreeBSD→PC-BSD（2005 年；PC-BSD→TrueOS→Project Trident 谱系，Trident 2019 年改基 Void Linux、2022 年关闭，本体 2020 年停止开发）、OpenBSD→OliveBSD（2005 年，立即停摆）、FreeBSD→FreeSBIE（2004 年，已停摆）。Linux 阵营鲜有真正 fork——对照性案例：GNU Hurd 系 GNU 项目 1990 年启动的原创微内核系统（早于 Linux，非其 fork）；Android 使用 Linux 内核但属下游使用而非 fork，两者均不属“Linux 的 fork”范畴。fork 的失败率反映“去中心化自由复刻”作为形式主义化的幻想——法律上允许 fork 但工程上 fork 难以维持。
  - **BSD/Linux fork 案例对照表**：

| 上游 | fork 项目 | 年份 | 类型 | 结果 |
| --- | --- | --- | --- | --- |
| 386BSD | FreeBSD/NetBSD | 1993 | BSD fork | 成功 |
| FreeBSD | DragonFly BSD | 2003 | BSD fork | 成功 |
| NetBSD | OpenBSD | 1995-10（2.0 首发 1996-06） | BSD fork | 成功 |
| FreeBSD | DesktopBSD | 2006 | BSD fork | 已停摆 |
| FreeBSD | PC-BSD | 2005 | BSD fork | 已停摆（后继 Project Trident 转向 Void Linux 后于 2022 年关闭） |
| OpenBSD | OliveBSD | 2005 | BSD fork | 立即停摆 |
| FreeBSD | FreeSBIE | 2004 | BSD fork | 已停摆 |
| Linux | Hurd | — | GNU 微内核替代 | 长期未完成 |
| Linux | Android | — | 下游使用而非 fork | 非真正 fork |

- 史观：总纲第 2 条——历史是形式主义化的非存在，“fork 自由”作为形式主义操作，其“自由”在工程实际上常呈现非存在；总纲第 3 条——不存在进步，只有权力再分配，fork 的失败反映衍生项目维度的资源与权力分配现实
- 辨析：fork 的“成功”与“失败”判断须有明确标准（如项目是否仍活跃、是否独立于上游）；386BSD→FreeBSD/NetBSD 的 fork 时间与背景须考据；Android 是否为 Linux fork 须有技术辨析（Android 使用 Linux 内核但非 fork）
