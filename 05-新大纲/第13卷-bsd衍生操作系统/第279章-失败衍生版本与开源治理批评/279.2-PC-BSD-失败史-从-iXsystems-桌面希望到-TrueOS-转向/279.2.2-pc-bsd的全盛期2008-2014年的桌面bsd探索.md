# 279.2.2 PC-BSD 的全盛期：2008-2014 年的桌面 BSD 探索

  - 要点：2008-2014 年是 PC-BSD 的全盛期，期间 PC-BSD 发布了 7.x 至 10.x 多个版本，引入了 Warden（jail 管理图形前端）、Life Preserver（备份与快照工具）、AppCafe（PBI 应用商店图形前端）等桌面工具；PC-BSD 9.0（2012 年）基于 FreeBSD 9.0，引入了对 ZFS 根分区的图形安装支持；PC-BSD 10.0（2014 年）基于 FreeBSD 10.0，引入了对 UEFI 引导的初步支持。这一时期 PC-BSD 在 Distrowatch 排名一度进入前 20，是 BSD 衍生发行版中排名最高的桌面项目。然而，PC-BSD 的全盛期恰逢 Linux 桌面（特别是 Ubuntu）的全面普及，PC-BSD 的市场份额“绝对值增长但相对值萎缩”——用户总数增加，但相对 Linux 桌面用户基数的比例持续下降。
  - **PC-BSD 全盛期版本时间线表**：

| 版本 | 发布年份 | FreeBSD 基线 | 关键特性 |
| --- | --- | --- | --- |
| PC-BSD 7.x | 2008 | FreeBSD 7.x | 桌面工具引入起点 |
| PC-BSD 9.0 | 2012 | FreeBSD 9.0 | ZFS 根分区图形安装支持 |
| PC-BSD 10.0 | 2014 | FreeBSD 10.0 | UEFI 引导初步支持 |

- **PC-BSD 全盛期桌面工具对照表**：

| 工具 | 功能 |
| --- | --- |
| Warden | jail 管理图形前端 |
| Life Preserver | 备份与快照工具 |
| AppCafe | PBI 应用商店图形前端 |

- 史料：PC-BSD 7.x-10.x 发布公告；Warden/AppCafe/Life Preserver 设计文档；Distrowatch 2008-2014 年 PC-BSD 排名历史；phoronix.com 对 PC-BSD 的报道 ［C］
- 史观：总纲第 8 条——经济历史哲学，PC-BSD 的“绝对增长相对萎缩”是商业生态结构性弱势的呈现；BSD 反向影响线，PC-BSD 的桌面工具是 BSD 工程哲学在桌面的反向尝试
- 辨析：PC-BSD 各版本的具体发布日期与功能须以原始公告为准；Distrowatch 排名的历史快照须以互联网档案馆存档为准，避免基于当前页面推断；“绝对增长相对萎缩”的判断须有用户统计数据支持，避免主观估算
