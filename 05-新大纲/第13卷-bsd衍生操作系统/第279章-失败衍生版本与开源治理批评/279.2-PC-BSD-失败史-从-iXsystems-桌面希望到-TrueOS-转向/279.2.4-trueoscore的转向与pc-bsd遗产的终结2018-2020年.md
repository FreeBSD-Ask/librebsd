# 279.2.4 TrueOS Core 的转向与 PC-BSD 遗产的终结：2018-2020 年

  - 要点：2018 年，TrueOS 进一步拆分为 **TrueOS Core**（基本系统）与 **Project Trident**（桌面环境），Project Trident 由 **Ken Moore** 主导，试图延续 PC-BSD 的桌面 BSD 传统。但 Project Trident 在 **2020** 年宣布放弃 FreeBSD 底座，转向 **Void Linux**，标志着 PC-BSD 桌面 BSD 传统的实质性终结。Ken Moore 在公告中明确指出，转向 Linux 的原因是“FreeBSD 桌面生态的硬件兼容性与图形栈支持已无法满足桌面发行版的可持续维护”。TrueOS Core 本身于 2020 年后停止独立发布，iXsystems 的 BSD 投入全面转向 **TrueNAS CORE**（基于 FreeBSD）与 **TrueNAS SCALE**（基于 Debian Linux）。PC-BSD 从 2005 年起到 2020 年 Project Trident 转向 Linux 止，15 年的桌面 BSD 尝试以失败告终。
  - **Project Trident 公告引文**：

> FreeBSD 桌面生态的硬件兼容性与图形栈支持已无法满足桌面发行版的可持续维护。
>
> ——Ken Moore，Project Trident 2020 年转向 Void Linux 公告

- **iXsystems BSD 投入转向对照表**：

| 阶段 | 项目 | 底座 | 定位 |
| --- | --- | --- | --- |
| 2005-2017 | PC-BSD | FreeBSD | 桌面 BSD |
| 2017-2018 | TrueOS | FreeBSD-CURRENT | 桌面/服务器混合 |
| 2018-2020 | TrueOS Core + Project Trident | FreeBSD | 基本系统 + 桌面环境 |
| 2020 后 | TrueNAS CORE | FreeBSD | 存储/服务器（iXsystems 主线） |
| 2020 后 | TrueNAS SCALE | Debian Linux | 存储/服务器（Linux 分支） |
| 2020 后 | Project Trident | Void Linux | 桌面（放弃 FreeBSD 底座） |

- 史观：终结中的延续，PC-BSD/TrueOS/Project Trident 的失败是 BSD 桌面战略的终结，但 BSD 桌面哲学的反思仍在延续；经济历史哲学，Project Trident 转向 Linux 反映 BSD 桌面生态的商业不可持续性
- 辨析：Project Trident 转向 Void Linux 的具体日期与公告原文须考据；Ken Moore 公告中“FreeBSD 桌面生态的硬件兼容性与图形栈支持”的具体内容须以原文为准；TrueOS Core 停止独立发布的具体时间须考据；openbsd.duckdb 查询 L7.1.1.trueos-src 的 commit 量骤降须警惕 fork 分歧识别局限——fork 项目的 commit 量包含合并上游的 commit，识别本地特有 commit 须通过 merge commit 与 parent_hashes 交叉验证，不可仅凭时间戳，2020 年 commit 量骤降可能由仓库迁移至归档状态、镜像同步停止等多种原因导致，须与 Project Trident 公告、iXsystems 商业战略说明交叉验证；openbsd.duckdb 查询 L3.5.1.trueos-src 的文件生命周期须警惕重命名（status =‘R’）可能被误判为删除 + 新增，且仅计算被删除的文件，仍在使用的文件不计入
