# 289.2.1 Orbis/Prospero OS 的 FreeBSD 9 基础

  - 要点：PS4（2013）的 Orbis OS 基于 FreeBSD 9，PS5（2020）的 Prospero OS 延续 FreeBSD 基底并适配 AMD APU；Sony 与 FreeBSD 社区保持代码交流（如 GPU 驱动、网络栈修复回馈）。
  - 史料：Sony 工程演讲（BSDCan 等）、PS4/PS5 系统文档、FreeBSD 中与 Sony/PlayStation 相关 commit（freebsd.duckdb）。 ［A］
  - 史观：总纲第 4 条——分离聚合是永恒规律，FreeBSD 在主机世代间延续；统计结论印证：C-54（跨数据库关联分析 Task 28）显示 BSD 衍生 fork 项目 commit 时间序列呈强正相关（ghostbsd-src ~ pfsense-src rho = 0.9355），而 PlayStation OS 作为商业闭源 fork 其 commit 不在公开仓库 Spearman 相关矩阵中，反映商业闭源 fork 与社区开源 fork 在工程可观测性上的结构性差异——PS3/PS4/PS5 跨越三个主机世代的 FreeBSD 延续无法通过 commit 时间序列统计分析验证，须以 Sony 工程演讲与系统文档交叉印证，0 信任原则适用：Orbis/Prospero 的 FreeBSD 版本号须以 Sony 披露核实，未公开细节已考据完成（详见辨析字段），不得以统计分析推断闭源产品的版本同步节奏
