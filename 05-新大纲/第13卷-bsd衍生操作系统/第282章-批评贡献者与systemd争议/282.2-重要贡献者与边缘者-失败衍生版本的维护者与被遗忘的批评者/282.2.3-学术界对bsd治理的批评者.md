# 282.2.3 学术界对 BSD 治理的批评者

  - 要点：学术界对 BSD 治理的批评者包括——开源治理研究学者（如 O'Mahony、Kelty 等）对 BSD 治理模式的批评；操作系统研究学者对 BSD 工程选择的批评；许可证哲学研究学者对 BSD 许可证的批评。这些学术批评者多非 BSD committer，其批评工作常被 BSD 社区忽视。
  - 史料：O'Mahony/Kelty 等学术批评文献；操作系统研究学者对 BSD 的批评论文 ［B］
  - 史观：总纲第 10 条——动手者创造历史，学术批评者的批评实践构成 BSD 史编纂不可忽略的一手材料；总纲第 9 条——经验优先〔存疑：对位待复核〕，学术批评须被纳入 BSD 史学的考据范围
  - 辨析：学术批评的具体内容须以原文为准；“被 BSD 社区忽视”的判断须有具体案例支持
  - 文献：O'Mahony/Kelty 文献；操作系统研究论文 ［B］
