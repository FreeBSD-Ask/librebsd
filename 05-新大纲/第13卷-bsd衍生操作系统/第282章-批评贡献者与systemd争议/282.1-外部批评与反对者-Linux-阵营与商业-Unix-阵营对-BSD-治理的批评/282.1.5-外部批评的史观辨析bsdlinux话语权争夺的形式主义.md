# 282.1.5 外部批评的史观辨析：BSD/Linux 话语权争夺的形式主义

- 要点：BSD/Linux 话语权争夺是开源运动内部的阵营对立，其形式主义呈现——BSD 阵营与 Linux 阵营各自以对方为“他者”建构自身认同，BSD 阵营以“许可证哲学纯粹性”建构认同，Linux 阵营以“市场份额与商业成功”建构认同。话语权争夺的形式主义化使双方均难以客观评价对方——BSD 阵营低估 Linux 的工程效率，Linux 阵营低估 BSD 的哲学价值。形式主义批评的史观辨析须保留双方的实质内容，同时警惕话语权运作的形式主义化。
- **BSD/Linux 阵营认同建构与互相低估对照表**：

| 阵营 | 认同建构基础 | 对对方的低估 |
| --- | --- | --- |
| BSD 阵营 | 许可证哲学纯粹性 | 低估 Linux 的工程效率 |
| Linux 阵营 | 市场份额与商业成功 | 低估 BSD 的哲学价值 |
