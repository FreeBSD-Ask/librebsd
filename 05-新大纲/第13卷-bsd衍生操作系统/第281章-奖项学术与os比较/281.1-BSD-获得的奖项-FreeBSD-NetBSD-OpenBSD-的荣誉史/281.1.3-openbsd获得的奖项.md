# 281.1.3 OpenBSD 获得的奖项

  - 要点：OpenBSD 项目获得的主流形式奖项极少——经 0 信任考据，2000 年获 USENIX STUG Award 者为原始 SSH 作者 Tatu Ylönen，并非 OpenBSD 系的 OpenSSH；OpenSSH 本身无可考的形式奖项。OpenBSD 的安全审计方法论多次被信息安全社区表彰；OpenSSH 作为全球 SSH 事实标准，间接为 OpenBSD 项目带来声誉。OpenBSD 项目的奖项相对较少，Theo de Raadt（西奥·德·若特） 个人对奖项态度冷淡，OpenBSD 项目不主动追求奖项。
  - **OpenBSD/OpenSSH 主要奖项与声誉来源表**：

| 年份 | 奖项/声誉来源 | 颁发/认可机构 | 性质 |
| --- | --- | --- | --- |
| 2000 | USENIX STUG Award（原始 SSH，作者 Tatu Ylönen） | USENIX Software Tools User Group | 形式奖项（与 OpenBSD/OpenSSH 项目无涉） |
| 不详 | 安全审计方法论表彰 | 信息安全社区 | 社区认可 |
| 持续 | OpenSSH 作为全球 SSH 事实标准 | 全球产业 | 间接声誉 |

- 史料：USENIX STUG Award 2000 年公告（得主 Tatu Ylönen，原始 SSH）；OpenBSD 项目关于奖项的声明；信息安全社区对 OpenBSD 安全审计的表彰档案 ［B］
- 史观：总纲第 15 条——文化即形式主义，OpenBSD 奖项的稀缺与 Theo de Raadt 的态度反映 OpenBSD 项目的反奖项文化；总纲第 10 条——动手者创造历史，OpenSSH 作为全球 SSH 标准是 OpenBSD 开发者动手成果反向影响的最重要呈现
- 辨析：USENIX STUG Award 2000 年得主为原始 SSH 作者 Tatu Ylönen，OpenSSH 与 OpenBSD 项目并非 STUG 得主，须以 USENIX 官方历年得主页为准；Theo de Raadt 对奖项的态度须以公开声明为据
- 文献：USENIX STUG Award 公告；OpenBSD 声明；信息安全社区表彰档案 ［B］
