# 281.2.3 BSD 在 TCP/IP 与网络协议研究中的引用

  - 要点：BSD 在 TCP/IP 与网络协议研究中被广泛引用——4.2BSD 的 TCP/IP 实现（1983 年）是互联网协议的事实参考实现，BSD sockets API 成为 POSIX 网络编程接口标准；BSD TCP 拥塞控制算法（Tahoe/Reno/NewReno）是拥塞控制研究的经典案例，Jacobson 1988 年 SIGCOMM 论文“Congestion Avoidance and Control”基于 4.3BSD Tahoe 实现；现代 TCP 拥塞控制研究（如 BBR）常以 BSD TCP 栈为对比基准。BSD 在网络协议研究的引用反映 BSD 作为互联网基础设施的反向影响。
  - **BSD 在网络协议研究中的经典引用表**：

| 年份 | BSD 贡献 | 研究意义 | 关键论文/标准 |
| --- | --- | --- | --- |
| 1983 | 4.2BSD TCP/IP 实现 | 互联网协议事实参考实现 | 4.2BSD TCP/IP 实现文档 |
| — | BSD sockets API | POSIX 网络编程接口标准 | POSIX 标准 |
| 1988 | 4.3BSD Tahoe 拥塞控制 | Tahoe/Reno/NewReno 拥塞控制算法研究经典 | Jacobson“Congestion Avoidance and Control”（SIGCOMM 1988） |
| 2016 | BSD TCP 栈作为对比基准 | BBR 等现代拥塞控制研究的参照 | BBR 论文（2016） |

- 史料：4.2BSD TCP/IP 实现文档；Jacobson 1988 年 SIGCOMM 论文；BBR 论文（2016） ［B］
- 史观：BSD 反向影响线，BSD 在网络协议研究中的引用是其反向影响的核心呈现；科学技术历史哲学，BSD TCP/IP 实现是工程实践先于理论标准化的典型
- 辨析：Jacobson 1988 年 SIGCOMM 论文须以原文为准；BBR 论文须以原文为准；BSD sockets API 的 POSIX 标准化过程须考据
- 文献：4.2BSD TCP/IP 文档；Jacobson 1988 论文；BBR 论文 ［B］
