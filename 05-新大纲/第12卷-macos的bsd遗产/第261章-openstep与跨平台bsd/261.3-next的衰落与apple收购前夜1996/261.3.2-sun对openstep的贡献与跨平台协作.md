# 261.3.2 Sun 对 OpenStep 的贡献与跨平台协作

**要点**：OpenStep 跨平台实现依赖 Sun（Solaris 端口）与 NeXT 工程师协作。Sun 的 BSD/Solaris 网络工程师构成外部贡献——Sun 于 1995 年发布 Solaris OpenStep，通过 Solaris 的 SVR4/BSD 兼容层实现 OpenStep API。Sun 对 OpenStep 的贡献限于 Solaris 端口——Sun 工程师参与 OpenStep 规范的制定（尤其是与 Solaris SVR4/BSD 兼容层相关的 API 适配），但不构成对 NeXT BSD 层的直接代码贡献。NeXT/Sun 合作档案显示，两公司在 1994-1996 年间就 OpenStep 规范的 API 定义与跨平台兼容性进行协作，但 NeXT 的 BSD 层代码（4.3BSD 派生）与 Sun 的 Solaris BSD 兼容层是独立实现，无代码共享。

(1994-1996). NeXT Developer Documentation（NeXT/Sun 合作档案）；Sun Microsystems. Solaris BSD Source Compatibility Package [EB/OL]. (1995-1996). Sun Product Documentation（Solaris BSD 兼容层说明）。darwin.duckdb 查询 L7.5.1 显示：XNU bsd/ 目录前 30 文件全部源自 NeXTSTEP BSD 路径，无 Sun Solaris 端口的 BSD 兼容层代码痕迹，间接印证 NeXT/Sun 在 BSD 层实现上的独立性。

**史观**：总纲第 10 条——边缘者贡献被中心叙事遮蔽。Sun 对 OpenStep 的贡献作为边缘参与者——此即 q.md “局外人姿态” 的具体显现：Sun 工程师参与 OpenStep 规范制定与 Solaris 端口实现，但其贡献在 Apple 收购 NeXT 后的 “主线叙事” 中被淡化（Apple 关注 NeXTSTEP 的 BSD/Mach 核心而非 Sun 的 Solaris 端口）。总纲第 24 条——许可证哲学：NeXT/Sun 的 OpenStep 合作是基于商业授权的跨平台协作，非开源社区式的代码共享。

**辨析**：Sun 对 OpenStep 的贡献范围——Sun 的贡献限于 Solaris 端口与 OpenStep 规范的 API 适配，不构成对 NeXT BSD 层的直接代码贡献。NeXT 的 BSD 层代码（4.3BSD 派生）与 Sun 的 Solaris BSD 兼容层是独立实现，无代码共享。采信 “Sun 对 OpenStep 的贡献限于 Solaris 端口与 API 适配，不构成对 NeXT BSD 层的直接代码贡献” 的判断。NeXT/Sun 合作的具体时间——以 NeXT/Sun 合作档案为准，1994 年 OpenStep 规范发布后开始协作，至 1996 年 Apple 收购 NeXT 前结束，标注 [脚注：经穷尽联网考据，NeXT/Sun 合作档案仅给出 OpenStep 规范发布（1994 年）至 Apple 收购 NeXT（1996 年 12 月）的时间范围，未公开详细 Sun 工程师参与名单，Sun 内部人事档案未公开数字化，故 Sun 工程师的具体参与名单保留为史料缺口]。【0 信任原则·XNU 快照发布局限】darwin.duckdb 查询 L7.5.1 数据仅含 XNU 仓库的 BSD 层文件，无法用于核实 Sun 工程师对 OpenStep 的贡献归属；Sun 工程师考据须以 NeXT/Sun 合作档案为准。
