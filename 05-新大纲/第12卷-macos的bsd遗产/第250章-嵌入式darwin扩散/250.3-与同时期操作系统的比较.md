# 250.3 与同时期操作系统的比较

## 250.3.1 嵌入式 Darwin 与 Android/Linux 内核、嵌入式 FreeBSD 的架构对比

**要点**：**2007-2024 年** iOS 系（含 iPadOS/watchOS/tvOS/visionOS）对比 Android（Linux 2.6/3.x/4.x/5.x 内核 + ART 虚拟机）、嵌入式 FreeBSD（如 PlayStation 3/4/5 系统软件基于 FreeBSD 9.x/11.x、NetBSD 的路由器固件）、Windows Phone（Windows NT 内核，2010-2017 年，后停产），其 Mach/BSD 混合内核在移动端独树一帜——Android 与 Windows Phone 均采用宏内核（Linux 或 NT），iOS 的 XNU 是移动端唯一大规模部署的混合内核（Mach 微内核 + BSD 宏内核子系统）。iOS 的应用沙盒基于 BSD 层的 `sandbox_*` 系统调用，Android 的应用隔离基于 Linux 的 `cgroups` 与 `namespaces`——二者实现路径不同但目标相同。iOS 至 **2024 年** 全球活跃设备超过 **18 亿台**（Apple 2024 财年财报披露 iPhone 装机基数），此规模使 iOS 的 BSD 层成为全球部署规模最大的 BSD 派生系统（远超 macOS 的 1 亿台）。

  | 操作系统 | 内核类型 | 应用隔离机制 | 装机规模（2024 年） |
  | --- | --- | --- | --- |
  | **iOS 系** | XNU（Mach + BSD 混合） | BSD `sandbox_*` 系统调用 | **18 亿台**（最大 BSD 派生系统） |
  | **Android** | Linux 宏内核 | `cgroups` + `namespaces` | 约 30 亿台 |
  | **嵌入式 FreeBSD** | FreeBSD 单内核 | **jail(8)** | 约 400 万台（PS3/4/5、路由器） |
  | **Windows Phone** | NT 内核 | — | 已停产（2017 年） |

  | 2024 年移动 OS 市场份额 | 比例 | BSD 层部署规模 |
  | --- | --- | --- |
  | **iOS** | 约 28% | 18 亿台 |
  | **Android** | 约 70% | 无 BSD 层（Linux 内核） |
  | **其他** | 约 2% | — |

  > iOS 的市场份额不及 Android（28% vs 70%）但 BSD 代码的绝对部署规模超过所有其他 BSD 系统的总和——此 “小份额大规模” 现象是 iOS 作为 BSD 谱系成员的独特定位。

Android Platform Distribution Statistics [EB/OL]. <https://developer.android.com/about/dashboards>（Android 版本分布统计）；Sony Interactive Entertainment. PlayStation System Software License [EB/OL]. <https://doc.dl.playstation.net/doc/ps3-oss/>（PlayStation 3 开源组件清单，含 FreeBSD 9.x 引用）。〔L3 官方文档与公告〕

**史观**：总纲第 6 条——主体性与和解。iOS 与 Android 的内核架构差异是 “主体性” 的显现——此即项目史观总纲第六章的具体呈现：iOS（Mach/BSD 混合内核）与 Android（Linux 宏内核）共享 Unix 哲学的根基但发展出不同的主体性。q.md “好望角与塔式起重机” 在此显现：iOS 与 Android 的差异是 “塔式起重机” 式的渐进分化（在 Unix 基础上各自选择不同内核路线），而非 “好望角” 式的根本转向（二者均承袭 Unix 传统）。

**辨析**：iOS 的市场份额与 Android 的市场份额对比须分开论述——2024 年 iOS 全球市场份额约 28%、Android 约 70%（StatCounter 数据），但 iOS 的 BSD 层部署规模（18 亿台）仍远超任何其他 BSD 派生系统（FreeBSD 服务器装机量约 400 万台、macOS 约 1 亿台）。此 “小份额大规模” 现象是 iOS 作为 BSD 谱系成员的独特定位——市场份额不及 Android 但 BSD 代码的绝对部署规模超过所有其他 BSD 系统的总和。采信 “iOS 是 BSD 谱系中部署规模最大的成员” 的判断。
