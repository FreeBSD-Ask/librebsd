- **新闻来源**：VMware 官方公告 + 2007-08-06 + <https://www.vmware.com/products/fusion.html> + 存档：<https://web.archive.org/web/2007/https://www.vmware.com/products/fusion.html>
- **新闻摘要**：VMware 于 2007-08-06 正式发布 VMware Fusion 1.0，首款面向 Intel Mac 的桌面虚拟化产品。Fusion 允许 Mac 用户运行 Windows、Linux 等 x86 操作系统，与 Parallels Desktop（2006 年发布）竞争。Fusion 基于 VMware Workstation 技术，针对 macOS 优化界面与集成。Fusion 1.0 支持 Unity 视图（Windows 应用窗口与 macOS 桌面融合）、Boot Camp 分区虚拟化、Snapshots 快照。VMware Fusion 后续版本持续演进：Fusion 7（2014，Yosemite 适配）、Fusion 12（2020，Apple Silicon 预览）、Fusion 13（2022，Apple Silicon 正式支持）。Fusion 12 后 Player 版本免费供个人使用。Fusion 在 Apple Silicon Mac 上仅支持 ARM64 客户机操作系统，无法运行 x86 Windows。

## 里程碑事件类

### 新闻条目 1

- **新闻标题（中英）**：Apple Virtualization Framework introduced / Apple Virtualization Framework 引入
- **新闻来源**：Apple WWDC 2020 + 2020-06-22 + <https://developer.apple.com/documentation/virtualization> + 存档：<https://web.archive.org/web/2020/https://developer.apple.com/documentation/virtualization>
- **新闻摘要**：Apple 于 WWDC 2020 发布 Virtualization Framework，macOS 11 Big Sur 原生虚拟化框架。Virtualization Framework 基于 Hypervisor.framework（macOS 10.10 Yosemite 引入），提供高层次 API 简化虚拟机创建与管理。Virtualization Framework 支持运行 Linux（ARM64）与 macOS（ARM64）客户机，但不支持 Windows（因 Apple Silicon 不支持 x86 原生）。框架特点：Swift API、与 macOS 深度集成、轻量级、高性能。Virtualization Framework 的引入降低 macOS 虚拟化开发门槛，催生 Lume、Multipass、Colima 等基于 Virtualization Framework 的开源工具。Virtualization Framework 不支持 Intel Mac 运行 x86 客户机（Intel Mac 仍使用 Hypervisor.framework）。

## 商业产业新闻类

### 新闻条目 1

- **新闻标题（中英）**：UTM open source virtualization for Apple Silicon / UTM Apple Silicon 开源虚拟化
- **新闻来源**：UTM 官方网站 + 2021+ + <https://mac.getutm.app/> + 存档：<https://web.archive.org/web/2021/https://mac.getutm.app/>
- **新闻摘要**：UTM 是基于 QEMU 的开源虚拟化软件，专为 Apple Silicon Mac（M1/M2/M3）设计。UTM 由 Maxwell Chan 开发，2021 年随 Apple Silicon Mac 普及而流行。UTM 不同于 Parallels Desktop 与 VMware Fusion 的商业虚拟化方案，采用 QEMU 模拟器底层，支持 ARM 与 x86 架构虚拟机。UTM 特点：免费开源、图形化界面友好、支持多架构（x86、ARM、RISC-V、PPC 等）、通过 QEMU 模拟运行 x86 Windows（性能较低）。UTM 在 Apple Silicon Mac 上的优势是开源与多架构支持，劣势是性能低于原生虚拟化方案（如 Virtualization Framework）。UTM 后续通过 Triton 项目集成 DirectX 11 支持，提升 Windows 3D 应用兼容性。UTM 同时支持 Intel Mac，但 Apple Silicon 版本使用更广。
