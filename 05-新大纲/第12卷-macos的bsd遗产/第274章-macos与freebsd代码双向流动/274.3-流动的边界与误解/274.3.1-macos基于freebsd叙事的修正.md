# 274.3.1 “macOS 基于 FreeBSD” 叙事的修正

**要点**：“macOS 基于 FreeBSD” 的简化叙事须经架构事实修正——Darwin 内核为 XNU（**Mach 3.0 微内核** + BSD 宏内核子系统 + I/O Kit），FreeBSD 为传统单内核（monolithic kernel），二者架构根本不同。代码流动是部分、双向、随版本变化的，非整体派生。freebsd.duckdb 查询 3 显示，freebsd-src 仓库中 author_email 含 apple.com 的 commit 仅 **6 条**（**2021-2024 年**），来自 2 位贡献者（**Cosimo Cecchi** 3 条、**Yann Kerherve** 3 条），而 Apple 从 FreeBSD 吸收的代码涉及 libc、网络栈、用户态工具等核心子系统——此数据差异即 “不对称流动” 的量化证据。

  | 内核架构对比 | Darwin（macOS） | FreeBSD |
  | --- | --- | --- |
  | 内核类型 | XNU 混合内核 | 传统单内核 |
  | 微内核 | **Mach 3.0** | 无 |
  | BSD 子系统 | 宏内核子系统 | 整体 BSD |
  | 驱动框架 | I/O Kit | 内核内驱动 |
  | 代码同步方式 | 部分双向，随版本变化 | 部分双向，随版本变化 |

  | --- | --- |

  “macOS 基于 FreeBSD” 系误解，事实上 Darwin 内核为 XNU（Mach 3.0 + BSD 子系统 + I/O Kit），与 FreeBSD 单内核架构根本不同——代码流动是部分、双向、随版本变化的，非整体派生。
**史料**：darwin.duckdb 查询 2 与查询 3 结果（apple.com 邮箱贡献者 2 位、6 条 commit）；XNU 架构文档（<https://github.com/apple-oss-distributions/xnu>）；FreeBSD 架构文档（<https://docs.freebsd.org/en/books/architecture-handbook/>）。〔L1 代码/构建产物/L3 官方文档与公告〕

**史观**：总纲第 2 条——历史是形式主义化的非存在。“macOS 基于 FreeBSD” 作为形式主义化的误置获得了真实的传播力，但其 “非存在”（与架构事实不符）是事实——此即总纲第 2 条的显现：简化叙事作为形式主义化的非存在，其影响力反而超过真实的架构描述。

**辨析**：避免两种极端——既非 “完全基于 FreeBSD” 亦非 “与 FreeBSD 无关”。freebsd.duckdb 查询 6 显示，freebsd-src 中 MFC 相关且含 Apple/Darwin 的 commit 有 30 条，多为 Apple 硬件支持（Apple HFS 分区、Apple Mac codec ID、Apple Kauai ATA 控制器、Apple PowerMac SMP 支持），由 Nathan Whitehorn、Alexander Motin 等 FreeBSD committer 提交——此即 FreeBSD 对 Apple 硬件的支持性回馈，与 Darwin 对 FreeBSD 用户态代码的吸收是不同方向的流动。

**文献**：Apple Inc. XNU Source Code [EB/OL]. <https://github.com/apple-oss-distributions/xnu>; FreeBSD Project. FreeBSD Architecture Handbook [EB/OL]. <https://docs.freebsd.org/en/books/architecture-handbook/>.
