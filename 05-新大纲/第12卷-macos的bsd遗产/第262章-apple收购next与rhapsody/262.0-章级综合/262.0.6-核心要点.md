# 262.0.6 核心要点

**要点**：Apple 于 1996 年 12 月宣布以 4.29 亿美元收购 NeXT Software（1997 年初完成交割），OpenStep 技术与 NeXT 工程团队（Avie Tevanian 等）随之进入 Apple；Rhapsody（DR1 1997、DR2 1998）期间 XNU 内核（Mach 微内核与 BSD 层的聚合）成形；1999 年 3 月发布的 Mac OS X Server 1.0 是 BSD 层首次商用落地（239.1-239.3）。

**史料**：Apple 1996 年 12 月收购公告与 SEC 8-K 文件；Rhapsody DR1/DR2 开发者预览文档；Mac OS X Server 1.0（1999）release notes 与 XNU 内核架构白皮书；Tevanian 1993 年 USENIX 论文与 Mach 3.0 技术报告（CMU-CS-94-146）；Jobs 1997 WWDC 主题演讲；Hubbard 2002 bsdtalk 访谈；original_sources 库 20 条 L3 过程性互证记录（见 COL_SCAN 块，引用须回溯原始文献）。

**史观**：总纲第 3 条——不存在进步，只有权力再分配：收购并非线性的“技术进步”叙事，而是软件路线控制权的再分配——被收购方 NeXT 的工程团队反向主导了收购方 Apple 的操作系统未来；总纲第 4 条——分离聚合是永恒规律：Mach 与 BSD 层自 CMU/NeXT 谱系聚合入 Apple 的 XNU 内核，Rhapsody 蓝盒/黄盒双轨则是这一聚合进程中的分离尝试。

**辨析**：收购金额 4.29 亿美元为已确证锚点；Rhapsody 作为产品线商业上未成，但其技术谱系经 Mac OS X Server 1.0 延续至 Mac OS X，引用时须区分“产品成败”与“技术延续”两个层面；COL_SCAN 证据点系过程性互证记录而非独立史料，单一文献支撑的陈述须标注待交叉验证。自反性声明：本节五字段系 2026-09-13 章级核查整改补写，提炼自本章索引各节与自动增补块，补写行为本身受总纲第 23 条“一切历史写作都是基于哲学设定的历史小说”约束——本节口径不预设为终局，后续核查可推翻。
