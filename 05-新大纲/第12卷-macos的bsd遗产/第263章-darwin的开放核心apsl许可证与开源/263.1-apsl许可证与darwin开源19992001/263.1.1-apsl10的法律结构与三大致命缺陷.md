# 263.1.1 APSL 1.0 的法律结构与三大致命缺陷

**要点**：**1999 年 3 月 16 日** Apple 随 Mac OS X Server 1.0 发布 Darwin 源代码，以 **APSL 1.0** 授权。APSL 1.0 含三项致命缺陷：其一，**不尊重隐私**——修改后仅供私人使用亦须公开源代码；其二，**中央控制**——发布或使用修改版本须通知 Apple 这一个特定组织；其三，**可随时撤销**——终止条款允许 Apple 在有人指控专利或版权侵权时撤销许可并禁止继续使用。APSL 1.0 与 BSD 许可证的关键差异在于专利授权范围、商标限制与上述三项终止条款，不可混为一谈。**FSF** 于 1999 年公开发表立场（文题《The Problems (with older versions) of the Apple Public Source License (APSL)》，见 <https://www.gnu.org/philosophy/historical-apsl.html>），认为 APSL 1.0 不构成自由软件许可证。

  | APSL 1.0 缺陷 | 描述 | FSF 评价 |
  | --- | --- | --- |
  | **不尊重隐私** | 修改后仅供私人使用亦须公开源代码 | 违反自由软件隐私底线 |
  | **中央控制** | 发布或使用修改版本须通知 Apple | 单一组织保留控制权 |
  | **可随时撤销** | 专利或版权侵权指控时 Apple 可撤销许可 | 终止条款威胁使用者权利 |

  > FSF 1999 年公开立场声明明确指出：APSL 1.0 因上述三项致命缺陷不构成自由软件许可证，Apple 官方虽使用 “open source” 话语但法律实质未达自由软件标准。

**史观**：总纲第 13 条——法律与道德是利益分配。APSL 1.0 的三项致命缺陷是许可证条款背后利益分配格局的显现：Apple 通过 APSL 1.0 的终止条款与中央控制条款，在 “开源” 外衣下保留对代码使用的最终裁量权，“开源” 形式被 Apple 用于品牌叙事但其法律实质未达自由软件标准。总纲第 9 条——经验优先在此显现：对 APSL 1.0 的评价须以法律文本逐条分析，不得仅凭 “Apple 开源” 的品牌叙事采信。

**辨析**：APSL 1.0 是否 “自由软件”——以 FSF 1999 年公开立场声明为准，APSL 1.0 因三项致命缺陷不构成自由软件许可证。Apple 官方声称 “开源” 但 FSF 与 OSI 的评价存在分歧——OSI 早期对 APSL 1.0 的认证较为宽松，FSF 则坚持三项缺陷致命。采信 “APSL 1.0 经 OSI 认证为开源许可证，但 FSF 认为其不构成自由软件许可证” 的判断。【0 信任原则·关键词匹配局限】darwin.duckdb 查询 L3.6.1 基于 license/copyright/patent/BSD 关键词匹配，可能含误报（如与 Apple APSL 无关的 BSD 许可证讨论）；关键词匹配无法直接对应 APSL 1.0 的具体影响范围，APSL 法律实质须以 FSF 立场声明与 APSL 原文为准。【0 信任原则·XNU 快照发布局限】darwin.duckdb 查询 L7.5.1 数据基于 XNU 仓库仅 155 条 commit，趋势分析价值有限；bsd/ 目录文件可能包含 Apple 自有修改，非纯 BSD 代码。【统计结论 C-41 C-42 背景】references 表 16,867 条中 2000-2004 年累计 3,411 条（年份提取率 44.42%），显示此期 BSD 谱系学术文献的活跃积累为 Darwin 开源与 APSL 许可证讨论提供学术资源背景；文献数量不直接等同于 Darwin 开源的因果驱动，详细口径见文献计量学分析.md Task 22（2026-07-22）。
