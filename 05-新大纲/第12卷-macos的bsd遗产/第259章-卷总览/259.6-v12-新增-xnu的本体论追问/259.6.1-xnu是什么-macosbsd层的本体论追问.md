# 259.6.1 XNU 是什么？——macOS BSD 层的本体论追问

> **史观框架**：shigang §2 本体论

- 要点：“macOS 基于 BSD”是一个流传广泛但本体论上模糊的陈述。XNU（X is Not Unix）内核由 Mach 微内核 + FreeBSD 内核组件 + I/O Kit 三层组成。从 shigang §2 的视角，追问“XNU 是 BSD 吗？”与追问“FreeBSD 是 UNIX 吗？”共享相同的本体论结构——“是”不是一个事实判断，而是一个形式主义化的分类操作。“不能两次踏进同一条河流”（赫拉克利特）——如果说 FreeBSD 14.0 不是 FreeBSD 4.0，那么“是 FreeBSD”到底在说什么？XNU 中的 BSD 层来自 FreeBSD 4.x/5.x 时代的代码——但经过 Apple 的修改（Grand Central Dispatch 集成、launchd 替代 init、sandbox 扩展），它已经不是原来的 FreeBSD 代码。“xnu/bsd/”子树中的文件有 Apple 的版权声明，“xnu/bsd/sys/”中的头文件在 FreeBSD 和 macOS 中已经分化。从 shigang §2 的“形式主义本体论”，XNU 不是“部分是 BSD 部分不是”的混合体——它就是一个新的形式主义实体。说“macOS 基于 BSD”是为这个新实体建立一个谱系（genealogical）链接——正如说“人类基于猿类”是一个谱系链接而非本体论等同。

- 史料：XNU 源码（opensource.apple.com）；Darwin 9.0 源码中的 FreeBSD 贡献标注；Singh, A. (2006). *Mac OS X Internals*; Levin, J. (2012-). *Mac OS X and iOS Internals*; shigang.md §2（本体论——“不能两次踏进同一条河流” 1.4 节教材试样实证）
- 史观：shigang §2——“人们通过感性接触并经理性分析所得之物，并非真正真实的存在物。”(1.1 节) “XNU 是 BSD”是一个经过感性接触（阅读源码）和理性分析（比较代码结构）后的判断——但这个判断不是对 XNU“真实身份”的揭示，而是对 XNU 的形式主义化分类。“是 BSD”和“不是 BSD”在分类学上都是合法的——取决于你选择的分类标准（代码比例？函数签名兼容性？版权声明？社区认同？）。本体论平等的立场（shigang §1.9）要求我们不声称其中一个分类标准“更正确”。
- 文献：Singh (2006); Levin (2012-); XNU 源码 (opensource.apple.com); shigang.md §2
