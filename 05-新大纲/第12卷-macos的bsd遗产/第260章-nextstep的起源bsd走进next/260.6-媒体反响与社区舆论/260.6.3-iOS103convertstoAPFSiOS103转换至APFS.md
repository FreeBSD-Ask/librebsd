### 新闻条目 1

- **新闻标题（中英）**：iOS 10.3 converts to APFS / iOS 10.3 转换至 APFS
- **新闻来源**：Apple iOS 10.3 发布说明 + 2017-03-27 + <https://support.apple.com/en-us/HT208066> + 存档：<https://web.archive.org/web/2017/https://support.apple.com/en-us/HT208066>
- **新闻摘要**：Apple 于 2017-03-27 发布 iOS 10.3，所有兼容设备升级时自动将文件系统从 HFS+ 转换至 APFS。这是 APFS 首次大规模部署，影响数亿 iOS 设备。转换在升级过程中自动完成，用户无需手动操作，但 Apple 在更新说明中标注 “更新 iOS 后设备存储将转换为 APFS”。Ars Technica 的 Andrew Cunningham 评述称，由于 Apple 完全控制 iOS 平台的硬件与分区架构，转换风险可控，是合理举措。APFS 在 iOS 上带来更高效的存储利用，部分 16GB/32GB 设备用户反馈可用空间增加。转换后 iCloud 备份仍可恢复至 HFS+ 设备，Apple 通过特殊机制处理跨文件系统恢复。

### 新闻条目 2

- **新闻标题（中英）**：macOS High Sierra introduces APFS / macOS High Sierra 引入 APFS
- **新闻来源**：Apple Newsroom + 2017-09-25 + <https://www.apple.com/newsroom/2017/09/macos-high-sierra-available-today/> + 存档：<https://web.archive.org/web/2017/https://www.apple.com/newsroom/2017/09/macos-high-sierra-available-today/>
- **新闻摘要**：Apple 于 2017-09-25 发布 macOS High Sierra 10.13，正式将 APFS 引入 Mac 平台作为默认文件系统。Mac 上的 APFS 转换与 iOS 不同：仅 SSD 启动盘自动转换为 APFS，融合硬盘（Fusion Drive）与机械硬盘保持 HFS+。High Sierra 引入 APFS 后，Mac 用户获得克隆、快照、空间共享等新特性，但部分老应用与工具（如磁盘修复工具、Time Machine 初期版本）需适配。Apple 同时发布 APFS 规范文档（Apple File System Reference），供开发者参考。High Sierra 还引入 HEVC 视频编码与 Metal 2 图形 API，与 APFS 共同构成 “核心技术更新” 版本。

### 新闻条目 3

- **新闻标题（中英）**：APFS Reference documentation published / APFS 规范文档发布
- **新闻来源**：Apple 开发者文档 + 2017 + <https://developer.apple.com/go/?id=apfs-file-format-spec> + 存档：<https://web.archive.org/web/2017/https://developer.apple.com/go/?id=apfs-file-format-spec>
- **新闻摘要**：Apple 于 2017 年同步发布 Apple File System Reference 规范文档，详述 APFS 磁盘格式与内部结构。规范文档涵盖：B-树结构、容器与卷的层次、inode 格式、扩展（extent）分配、快照机制、克隆实现、加密容器（AES-XTS）、空间共享容器。文档面向需要直接访问文件系统（不通过框架）的开发者，如磁盘工具开发者、取证工具开发者、第三方文件系统驱动开发者。APFS 规范的发布回应了开发者社区对透明度的诉求，但部分实现细节（如具体加密密钥派生）仍保留专有。APFS 规范文档后续随 macOS 版本更新而修订，最新版本对应 macOS 15 Sequoia。

### 新闻条目 4

- **新闻标题（中英）**：Fusion Drive APFS support added in macOS Catalina / 融合硬盘 APFS 支持在 macOS Catalina 中加入
- **新闻来源**：Apple 支持文档 + 2019-10-07（Catalina 发布）+ <https://support.apple.com/en-us/HT208079> + 存档：<https://web.archive.org/web/2019/https://support.apple.com/en-us/HT208079>
- **新闻摘要**：Apple 于 macOS Catalina（10.15，2019-10-07 发布）扩展 APFS 支持至融合硬盘（Fusion Drive）。High Sierra 中融合硬盘保持 HFS+，Catalina 后升级的融合硬盘 Mac 可转换为 APFS。Catalina 同时引入只读系统卷（Read-Only System Volume）架构：系统文件存储于单独的 APFS 卷（System 卷，只读），用户数据存储于另一 APFS 卷（Data 卷，可读写），两者共享同一容器的空闲空间。这一架构通过 APFS 空间共享特性实现，是 SIP 之后 macOS 安全模型的进一步强化。Catalina 后所有 Mac 均使用 APFS，HFS+ 仅保留对外置硬盘与 Time Machine 备份的支持。
