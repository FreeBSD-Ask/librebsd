### 新闻条目 1

- **新闻标题（中英）**：Mac OS X: The Future Is Here – Coming Soon! / Mac OS X：未来已来——即将登场！
- **新闻来源**：TidBITS + Adam Engst + 2001-03-26 + <https://tidbits.com/2001/03/26/mac-os-x-the-future-is-here-coming-soon/> + <https://web.archive.org/web/2001*/tidbits.com/2001/03/26/mac-os-x-the-future-is-here-coming-soon/>
- **新闻摘要**：TidBITS 创始人 Adam Engst 在 Mac OS X 10.0（Cheetah）于 2001-03-24 上市后撰文评述。Apple 官方对该版本采取低调发布策略，建议大多数用户暂缓升级；同时 Engst 指出 Mac OS X 10.0 暂缺 DVD 播放、CD/DVD 刻录等功能，并存在外设兼容性问题，预期到 2001-07 Macworld Expo NY 才会预装于新 Mac。
- **与本章主题的关联说明**：本章核心叙事为 Mac OS X 10.0-10.5 时期的发展历程，Adam Engst 的报道提供了 Mac OS X 10.0 发布当时社区主流观点——即 10.0 尚非成熟大众化产品，但奠定 BSD UNIX 之上的 macOS 工程根基。
- **与官方史料的交叉验证结论**：与 Apple 官方新闻稿（2001-03-21 PR）“Apple Releases Mac OS X” 时间节点一致（2001-03-24 上市）；与 Apple 开发者文档记录的 Mac OS X 10.0 系统需求、缺失功能（DVD 播放等）一致。Engst 描述的 130 美元定价与 Apple 官方建议零售价一致。新闻报道所述 “7 月 Macworld Expo 预装” 为前瞻性推测，2001-07 Macworld Expo NY 上 Apple 确实宣布新 Mac 预装 Mac OS X 10.1。

### 新闻条目 2

- **新闻标题（中英）**：Unix Switchers / Unix 切换者
- **新闻来源**：Daring Fireball + John Gruber + 2002-08-29 + <https://daringfireball.net/2002/08/unix_switchers> + <https://web.archive.org/web/2002*/daringfireball.net/2002/08/unix_switchers/>
- **新闻摘要**：John Gruber 引述 Tim O‘Reilly 在 O’Reilly Network（macdevcenter.com）发表的观察：Mac OS X 在 Unix/Linux 用户群中引发大规模切换潮，远超 Apple “Switch” 广告活动所针对的 Windows 用户。O'Reilly 引用受访者 Jim Thompson 的描述，Mac OS X “插上打印机就能用”，对 Unix 用户而言体验 “诡异”。Gruber 总结 Mac OS X 是 “世界最佳桌面 Unix”，但对 Mac OS 9 用户而言尚有粗糙边缘。
- **与本章主题的关联说明**：本章关注 Mac OS X 10.0-10.5 时期 BSD/Unix 基因对社区的吸引力。Gruber 的报道佐证了 Darwin/BSD 内核在 10.0-10.2 时期对 Unix 用户的强大吸引力，与本章 BSD 遗产叙事高度契合。
- **与官方史料的交叉验证结论**：与 Apple 2002-08-23 Mac OS X 10.2 “Jaguar” 发布新闻稿（08-24 上市）记录一致；与 Tim O‘Reilly 原文（O’Reilly Network 2002-08）一致。Gruber 提及 “Apple Switch 广告活动” 与 Apple 2002-06 启动的 “Real People” 广告活动一致。

### 新闻条目 3

- **新闻标题（中英）**：Siracusa on Jaguar / Siracusa 谈 Jaguar
- **新闻来源**：Daring Fireball + John Gruber + 2002-09-10 + <https://daringfireball.net/2002/09/siracusa_on_jaguar> + <https://web.archive.org/web/2002*/daringfireball.net/2002/09/siracusa_on_jaguar/>
- **新闻摘要**：John Gruber 推荐 Ars Technica John Siracusa 的 Mac OS X 10.2 Jaguar 长篇评论，称该评论足够 “撑过等待”。Siracusa 的评论刊载于 arstechnica.com/reviews/02q3/macosx-10.2/，是早期 Mac OS X 版本评估的权威长文。
- **与本章主题的关联说明**：本章关注 Mac OS X 10.2 Jaguar 在 2002-08-24 发布后的社区反响。Gruber 的推荐为 Siracusa 长篇评论作了媒体呼应，证明 Ars Technica 长文在 Mac OS X 早期社区中具有权威地位。
- **与官方史料的交叉验证结论**：与 Apple 2002-08-23 Mac OS X 10.2 Jaguar 发布新闻稿一致；与 Siracusa 评论原文 URL（arstechnica.com/reviews/02q3/macosx-10.2/macosx-10.2-1.html）一致，该 URL 现已 301 重定向至 arstechnica.com/gadgets/2002/09/macosx-10-2/。

### 新闻条目 4

- **新闻标题（中英）**：Siracusa on Panther / Siracusa 谈 Panther
- **新闻来源**：Daring Fireball + John Gruber + 2003-11-19 + <https://daringfireball.net/2003/11/siracusa_on_panther> + <https://web.archive.org/web/2003*/daringfireball.net/2003/11/siracusa_on_panther/>
- **新闻摘要**：John Gruber 推荐 John Siracusa 的 Mac OS X 10.3 Panther 长篇评论（2003-10-24 Panther 发布后刊载）。Siracusa 评论覆盖 Panther 的 Finder 重写、快速用户切换、FileVault、Exposé 等新功能。
- **与本章主题的关联说明**：本章关注 Mac OS X 10.3 Panther 在 2003-10-24 发布后的工程演进。Gruber 持续推荐 Siracusa 评论，建立 Daring Fireball 与 Ars Technica 的早期媒体协同生态。
- **与官方史料的交叉验证结论**：与 Apple 2003-10-08 Mac OS X 10.3 Panther 发布新闻稿一致；与 Siracusa 评论原文一致。Panther 弃 Power Mac G3 Beige 与原始 iMac 支持，与 Apple 官方技术规格一致。

### 新闻条目 5

- **新闻标题（中英）**：Mac OS X 10.5 Leopard: the Ars Technica review / Mac OS X 10.5 Leopard：Ars Technica 评论
- **新闻来源**：Ars Technica + John Siracusa + 2007-10-29 + <https://arstechnica.com/gadgets/2007/10/mac-os-x-10-5/> + <https://web.archive.org/web/2007*/arstechnica.com/apple/reviews/2007/10/mac-os-x-10-5.ars>
- **新闻摘要**：John Siracusa 在 Mac OS X 10.5 Leopard 于 2007-10-26 发布后撰写的长篇权威评论。文章覆盖 Leopard 经过 2.5 年开发周期（最长的一次 Mac OS X 开发周期，仅次于 10.0）的演进，包含对 Leopard 全部 300+ 新功能的深度技术分析，包括 Time Machine、Spaces、Quick Look、Boot Camp、64 位 GUI 应用、Core Animation、ACL 权限模型等。
- **与本章主题的关联说明**：本章关注 Mac OS X 10.0-10.5 时期的演进总结。Siracusa 的评论是 Leopard（Mac OS X 经典时代收尾之作）权威长文，覆盖 Darwin 9.0 内核、XNU 1228 与 BSD 派生层组件，与本章 BSD 遗产叙事高度契合。
- **与官方史料的交叉验证结论**：与 Apple 2007-10-26 Leopard 发布新闻稿一致；与 Apple 开发者文档记录的 Leopard 300+ 新功能一致。Siracusa 提及 Leopard 是首个获得 UNIX 03 认证（The Open Group）的 Mac OS X 版本，与 The Open Brand 证书 C5681 一致。Siracusa 提到的 2.5 年开发周期（2005-04 Tiger 至 2007-10 Leopard）与 Apple 公布的发布时间间隔一致。
