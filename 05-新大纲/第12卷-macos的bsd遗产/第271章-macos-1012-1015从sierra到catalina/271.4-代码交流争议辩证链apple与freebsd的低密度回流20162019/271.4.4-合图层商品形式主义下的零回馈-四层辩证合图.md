# 271.4.4 合图层：商品形式主义下的零回馈——四层辩证合图

**要点**：将批评层、反批评层、再批评层合图，可见“2016-2019 年零回馈”争议的本质不是回馈量的多寡，而是商品形式主义下的权力结构。Apple 以 BSD 代码为底层组件构建 macOS 商业生态（商品化），FreeBSD 以非营利模式维护代码源头（非商品化）——同一代码在两端的“商品化程度”不同，决定了回馈的不对称。项目史观总纲第 11 条“商品是形式主义”在此显现：技术市场的选择不是自然选择，Apple 的商业成功与 FreeBSD 的边缘化不是技术优劣而是形式主义的权力运作。BSD 许可证“允许不回馈”的设计，在商品形式主义下演化为“劣币驱逐良币”的机制——商业封装的 macOS 获得市场主导权，非营利的 FreeBSD 在服务器市场被 Linux（GPL 强制回馈的生态）挤压。APFS 自研是商品形式主义在文件系统层面的极端显现——Apple 不采用开源 ZFS 而选择自研闭源 APFS，因商品化 macOS 须将文件系统作为核心组件控制，此控制逻辑与开源共享逻辑在形式主义层面已分叉。合图层的判断是：零回馈是 BSDL 哲学的必然代价，此代价由 FreeBSD 社区自觉承担，但不应被伪装为“无代价”或“双向对等”。

**史观**：总纲第 11 条——商品是形式主义。macOS 的商业成功是 BSD 代码商品化的结果，FreeBSD 的非营利地位是 BSD 代码去商品化的坚持，二者同一源头的分流即“商品是形式主义”的历史显现。劣币驱逐良币是普遍规律——占据主流的 macOS 未必在架构上优于 FreeBSD，但在市场形式主义下获得了远超 FreeBSD 的影响力。APFS 自研是商品形式主义在文件系统层面的极端显现——Apple 须将文件系统作为商品化 macOS 的核心组件控制。

**辨析**：合图层须避免两种极端——既不应将 Apple 描绘为纯粹的“剥削者”（BSDL 的宽容是 FreeBSD 自愿授予），亦不应将“零回馈”粉饰为“双向对等”（量化数据明确显示 apple.com 邮箱 commit 为零）。项目统摄史观的审视要求史家承认：零回馈是形式主义的必然，而非可被技术手段消除的“问题”。此判断不预设价值褒贬——BSDL 选择“允许不回馈”的自由，亦选择承担“零回馈”的后果，这是自由的代价而非自由的失败。采信“零回馈是 BSDL 哲学的必然代价，不应被伪装为双向对等”的判断。
