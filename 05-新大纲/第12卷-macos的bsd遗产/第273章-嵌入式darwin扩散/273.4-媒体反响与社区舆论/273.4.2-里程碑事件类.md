# 273.4.2 里程碑事件类

### 新闻条目 1

- **新闻标题（中英）**：Apple Virtualization Framework introduced / Apple Virtualization Framework 引入
- **新闻来源**：Apple WWDC 2020 + 2020-06-22 + <https://developer.apple.com/documentation/virtualization> + 存档：<https://web.archive.org/web/2020/https://developer.apple.com/documentation/virtualization>
- **新闻摘要**：Apple 于 WWDC 2020 发布 Virtualization Framework，macOS 11 Big Sur 原生虚拟化框架。Virtualization Framework 基于 Hypervisor.framework（macOS 10.10 Yosemite 引入），提供高层次 API 简化虚拟机创建与管理。Virtualization Framework 支持运行 Linux（ARM64）与 macOS（ARM64）客户机，但不支持 Windows（因 Apple Silicon 不支持 x86 原生）。框架特点：Swift API、与 macOS 深度集成、轻量级、高性能。Virtualization Framework 的引入降低 macOS 虚拟化开发门槛，催生 Lume、Multipass、Colima 等基于 Virtualization Framework 的开源工具。Virtualization Framework 不支持 Intel Mac 运行 x86 客户机（Intel Mac 仍使用 Hypervisor.framework）。
