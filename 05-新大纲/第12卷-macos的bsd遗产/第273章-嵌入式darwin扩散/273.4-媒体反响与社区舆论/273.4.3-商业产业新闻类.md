# 273.4.3 商业产业新闻类

### 新闻条目 1

- **新闻标题（中英）**：UTM open source virtualization for Apple Silicon / UTM Apple Silicon 开源虚拟化
- **新闻来源**：UTM 官方网站 + 2021+ + <https://mac.getutm.app/> + 存档：<https://web.archive.org/web/2021/https://mac.getutm.app/>
- **新闻摘要**：UTM 是基于 QEMU 的开源虚拟化软件，专为 Apple Silicon Mac（M1/M2/M3）设计。UTM 由 Maxwell Chan 开发，2021 年随 Apple Silicon Mac 普及而流行。UTM 不同于 Parallels Desktop 与 VMware Fusion 的商业虚拟化方案，采用 QEMU 模拟器底层，支持 ARM 与 x86 架构虚拟机。UTM 特点：免费开源、图形化界面友好、支持多架构（x86、ARM、RISC-V、PPC 等）、通过 QEMU 模拟运行 x86 Windows（性能较低）。UTM 在 Apple Silicon Mac 上的优势是开源与多架构支持，劣势是性能低于原生虚拟化方案（如 Virtualization Framework）。UTM 后续通过 Triton 项目集成 DirectX 11 支持，提升 Windows 3D 应用兼容性。UTM 同时支持 Intel Mac，但 Apple Silicon 版本使用更广。
