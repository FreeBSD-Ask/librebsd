### 新闻条目 1

- **新闻标题（中英）**：OpenDarwin Project Shutdown Announcement / OpenDarwin 项目关停公告
- **新闻来源**：OpenDarwin 官方公告 + 2006-07-25 + 原始链接失效，互联网档案馆存档：<https://web.archive.org/web/2006/http://www.opendarwin.org/> + 邮件列表存档：opendarwin.org 邮件列表（互联网档案馆存档）
- **新闻摘要**：OpenDarwin 项目于 2006-07-25 宣布关停。OpenDarwin 于 2002-04 由 Apple 工程师 Jordan Hubbard（FreeBSD 联合创始人）与 Apple Darwin 团队主导创立，目标是构建基于 Apple Darwin 开源代码的社区操作系统。Apple 自 1999 年起将 Darwin 操作系统以 **Apple Public Source License（APSL）** 逐版开源（官方公告 1999-03-16，随 Mac OS X Server 1.0 发布），OpenDarwin 项目作为社区协作平台，承接 Apple Darwin 开源代码并允许外部开发者参与改进。OpenDarwin 关停公告称，“由于 Apple 与开源社区之间的协作模式未达预期，且 Apple 内部对 Darwin 开源策略调整，OpenDarwin 项目无法继续维持活跃开发”，项目宣布正式关停。OpenDarwin 关停后，社区分裂为两个方向：一是 PureDarwin 社区项目（继续基于 Darwin 开源代码构建可用系统），二是 Apple 内部继续维护 macOS 闭源路线，Darwin 开源代码更新逐渐减少。OpenDarwin 关停标志着 Apple 对 Darwin 完全开源路线的实质性放弃，仅保留部分 Darwin 代码（如 XNU 内核）的开源发布。
- **与本章主题的关联说明**：OpenDarwin 是 Apple 将 BSD 层遗产（Darwin/XNU）开放给社区的关键平台，其 2006 年关停直接标示 Apple 开源策略收缩，为“macOS 的 BSD 层技术哲学”提供反向坐标。
- **与官方史料的交叉验证结论**：关停日期 2006-07-25 与创立信息（2002-04，Jordan Hubbard 与 Apple Darwin 团队）经互联网档案馆公告回放与 Hubbard 官方履历互证成立；公告引语的逐字核对回源待办。
