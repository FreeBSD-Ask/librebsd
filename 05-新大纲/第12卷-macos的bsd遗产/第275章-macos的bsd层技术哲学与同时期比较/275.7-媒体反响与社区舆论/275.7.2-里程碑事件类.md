### 新闻条目 1

- **新闻标题（中英）**：A New Direction: Short Term and Long Term Goals / 新方向：短期与长期目标
- **新闻来源**：PureDarwin 官方网站 + KevDoy 与 InSaneDarwin（Cliff Sekel）+ 2024-11-03 + <https://www.puredarwin.org/news/A-New-Direction.html> + 存档：<https://web.archive.org/web/2024/https://www.puredarwin.org/news/A-New-Direction.html>
- **新闻摘要**：PureDarwin 项目于 2024-11-03 由 KevDoy 与 InaneDarwin（Cliff Sekel）联合发表《新方向》文章，宣布项目未来路线图。文章提出 PureDarwin 短期目标为引入 MATE 桌面与 LightDM 登录管理器实现图形界面，长期目标为构建完全独立的 Darwin 桌面环境。PureDarwin 同期引入新版本号系统，从旧的 “PureDarwin Test Build 17.2”（基于 Darwin 版本）改为 “PureDarwin 0.3.0 Alpha (Darwin 24)”（独立版本号 + 状态标签 + Darwin 版本），明确区分 PureDarwin 自身进度与 Apple Darwin 上游版本。文章承认旧版 “Xmas release”（基于 Darwin 9，2007 年发布）仍被部分用户索求，反映 PureDarwin 长期开发缓慢的现实。PureDarwin 在 2018-07-01 发布 PD-17.4 Test Build（基于 Darwin 17，对应 macOS High Sierra 10.13.x），为最小系统，仅作为虚拟机磁盘（VMDK）通过 QEMU 运行，缺乏图形界面与硬件支持。PureDarwin 因 Apple 不再完全开源 Darwin（网络驱动、系统库等关键组件闭源），须社区自行开发替代实现，开发进度受限。
- **与本章主题的关联说明**：PureDarwin 路线图显示 Apple 收缩开源后社区的自救路径与版本体系重构，反衬 Darwin 开源边界（驱动/系统库闭源）对 BSD 层技术研究的约束。
- **与官方史料的交叉验证结论**：文章日期 2024-11-03 与存档 URL 在列；“Xmas release”（Darwin 9，2007）与 PD-17.4 Test Build（2018-07-01）同 puredarwin.org 官方历史信息一致；MATE/LightDM 等细节以原文回读为准。

### 新闻条目 2

- **新闻标题（中英）**：Remembering Cliff Sekel (InsaneDarwin) / 缅怀 Cliff Sekel（InsaneDarwin）
- **新闻来源**：PureDarwin 官方网站 + PD-Team + 2026-01-03 + <https://www.puredarwin.org/news/Remembering-Cliff-Sekel.html> + 存档：<https://web.archive.org/web/2026/https://www.puredarwin.org/news/Remembering-Cliff-Sekel.html>
- **新闻摘要**：PureDarwin 项目于 2026-01-03 发表悼文，宣布项目领导者 Cliff Sekel（社区昵称 InsaneDarwin）于 2025-11 辞世。悼文称 Cliff 是 PureDarwin 项目的 “实际领导者” 与 “社区守护人”，在项目最艰难时期 “拒绝让 PureDarwin 默默消失”。Cliff 领导 PureDarwin 完成了近年来首个真正可启动的构建——PureDarwin 17.4——标志项目从 “档案保留” 转向 “活体系统” 的关键转折。该构建非单一补丁或变通方案，而是基于 Cliff 对系统级理解的持续投入与跨内核和构建工具的精心整合。Cliff 长期与 Apple 工程师直接沟通，争取 Apple 开源缺失组件（特别是网络与系统库），虽未完全成功，但其倡导帮助界定了 PureDarwin 须自行重实现的边界。悼文称 Cliff 是 “自由开源软件倡导者”，“相信系统应当可被运行者理解、检查、构建”，PureDarwin 对他 “不是学术练习或怀旧项目，而是 Darwin 应当在专有墙外存在的信念”。PureDarwin 社区由 Cliff 一人维系，回答问题、指导贡献者、整理仓库、保持机构知识。悼文呼吁社区 “以同样的关怀、耐心与坚持理解” 继续 Cliff 的工作。
- **与本章主题的关联说明**：当事人离世记录补全 PureDarwin 社区史的代际断层；其与 Apple 工程师直接沟通、争取开源缺失组件的经历是 Darwin 开源边界的当事人证词。
- **与官方史料的交叉验证结论**：悼文日期 2026-01-03 与存档 URL 在列；辞世时间 2025-11 系官方悼文单源陈述，尚无独立讣告旁证，采信时保留单源标注。

### 新闻条目 3

- **新闻标题（中英）**：Fedora Asahi Remix Released / Fedora Asahi Remix 发布
- **新闻来源**：Asahi Linux 官方网站 + 2023-08 + <https://asahilinux.org/fedora> + 存档：<https://web.archive.org/web/2023/https://asahilinux.org/fedora>
- **新闻摘要**：Asahi Linux 项目与 Fedora Project 合作，于 2023-08 在 Flock 大会上正式发布 Fedora Asahi Remix 39，作为 Apple Silicon Mac 上 “最 polished 的 Linux 体验”。Fedora Asahi Remix 基于 Fedora Linux 39（后续 2024 年发布 40 版本），支持 M1 与 M2 系列 MacBook、Mac mini、Mac Pro、Mac Studio 与 iMac 设备。Fedora Asahi Remix 默认采用 KDE Plasma 桌面（后续 40 版本升至 KDE Plasma 6.0），亦提供 GNOME 与 Minimal/Server 镜像。Fedora Asahi Remix 提供 100% Wayland 体验，并搭载全球首个通过 Khronos 认证的 Apple Silicon OpenGL 4.6、OpenGL ES 3.2、OpenCL 3.0 与 Vulkan 1.4 实现，支持开放式图形标准而非依赖 Apple Metal 专有 API。Fedora Asahi Remix 内置 PipeWire + WirePlumber DSP 音频方案，针对 8 种以上机型单独测量与校准，配合自研 Bankstown 低音增强与 Smart Amp 安全实现，提供 “Linux 笔记本最佳音频体验”。Asahi Linux 项目由 Hector Martin（marcan）于 2021 年发起，通过 Patreon 众筹启动开发，目标是为 Apple Silicon Mac 提供 Linux 移植。Asahi Linux 对 BSD 生态的影响在于：Apple Silicon Mac 上 Linux 可原生运行，但 FreeBSD 等 BSD 系统在 Apple Silicon 上的支持仍滞后，Asahi Linux 的逆向工程工作（M1 GPU 驱动、Apple Virtualization Framework 兼容性等）部分被 BSD 社区参考，但 BSD 端 Apple Silicon 移植进度远落后于 Linux。
- **与本章主题的关联说明**：Apple Silicon 上 Linux 生态的成熟度构成 BSD 移植滞后的参照系，其逆向成果是 BSD 端移植的外部依赖，服务本章“同时期比较”维度。
- **与官方史料的交叉验证结论**：发布时点 2023-08（Flock 大会）、Fedora 39 基线、KDE Plasma 默认与 Khronos 认证（OpenGL 4.6/ES 3.2/OpenCL 3.0/Vulkan 1.4）与 asahilinux.org/fedora 官方页面一致；认证细节以 Khronos 官方公告回源为准。

### 新闻条目 4

- **新闻标题（中英）**：Hector Martin Resigns as Asahi Linux Project Lead / Hector Martin 辞去 Asahi Linux 项目负责人职务
- **新闻来源**：TechPowerUp + 2025-02-17 + 原始链接失效，互联网档案馆存档：<https://web.archive.org/web/2025/https://www.techpowerup.com/> + 交叉验证：新浪财经 + 2025-02-17 + <https://cj.sina.cn/article/norm_detail?url=http%3A%2F%2Ffinance.sina.cn%2F2025-02-17%2Fdetail-inekvake7546983.d.html>
- **新闻摘要**：2025-02-17（周一），TechPowerUp 报道 Hector Martin（marcan）辞去 Asahi Linux 项目负责人职务，主因是工作倦怠（burnout）。Hector Martin 是 Asahi Linux 项目发起人，起初目标是为 M1 Mac 用户提供 Linux 移植，并通过 Patreon 众筹方式启动开发。五年后（2025 年初），Hector Martin 先已辞去 Apple ARM 支持维护者职位，最终于 2025-02 辞去 Asahi Linux 项目负责人职务。报道指出，Hector Martin 在辞职声明中表达了对项目长期可持续性的担忧，以及个人在维系高强度逆向工程工作时的倦怠。Hector Martin 辞职后，Asahi Linux 项目由剩余社区成员维护，Fedora Asahi Remix 后续版本（如 40、44）仍持续发布。此事件对 BSD 生态的间接影响在于：Apple Silicon 逆向工程工作的核心人物离场，可能延缓 Apple Silicon 上 BSD 移植的进展，因 BSD 端移植高度依赖 Asahi Linux 的逆向工程成果（如 M1 GPU 驱动、IOMMU、Apple Virtualization Framework 兼容性等）。
- **与本章主题的关联说明**：项目核心人物离场直接影响 Apple Silicon 逆向成果向 BSD 外溢的节奏，是本章“同时期比较”维度的生态联动样本。
- **与官方史料的交叉验证结论**：辞任日期 2025-02-17 与 burnout 主因经 TechPowerUp 与新浪财经双源报道互证；“先辞 Apple ARM 支持维护者、后辞 Asahi 负责人”的先后次序与当事人公开声明待回源比对。
