# 265.4.1 Mac OS X 10.0-10.3 对比 FreeBSD 4.x/5.0、Linux 2.4/2.6、Windows XP

**要点**：**2001-2003 年** Mac OS X 10.0-10.3 对比 **FreeBSD 4.x**（2001-2003 年）/**5.0**（**2003 年 1 月 19 日** 发布）、**Linux 2.4**（**2001 年 1 月 4 日** 发布）/**2.6**（**2003 年 12 月 17 日** 发布）、**Windows XP**（**2001 年 10 月 25 日** 发布），其 BSD 内核 + Aqua 桌面的组合首次让普通用户接触完整 Unix。FreeBSD 4.x/5.0 在服务器市场有稳固地位，但桌面用户体验远不及 Mac OS X 的 Aqua。Linux 2.4/2.6 在服务器市场增长迅速，桌面用户体验（KDE/GNOME）在 2001-2003 年间仍不成熟。Windows XP 是 2001-2003 年桌面市场的主导者（市场份额约 90%），但不提供 Unix 兼容环境（Services for UNIX 为可选安装，非默认）。

  | 操作系统 | 发布时间 | 内核类型 | 桌面环境 | Unix 兼容性 | 市场定位 |
  | --- | --- | --- | --- | --- | --- |
  | **Mac OS X 10.0-10.3** | 2001-03 至 2003-10 | XNU（Mach+BSD） | Aqua | 完整 BSD 用户空间 | 消费桌面 + 服务器 |
  | **FreeBSD 4.x/5.0** | 2001-2003 | FreeBSD 单内核 | 命令行为主 | 原生 BSD | 服务器市场 |
  | **Linux 2.4/2.6** | 2001-01-04 / 2003-12-17 | Linux 单内核 | KDE/GNOME（不成熟） | POSIX 兼容 | 服务器 + 开发者 |
  | **Windows XP** | 2001-10-25 | NT 内核 | Explorer | Services for UNIX（可选） | 桌面主导（约 90%） |

  > 2001-2003 年 Mac OS X 的 BSD 身份未被大众重视，消费者关注 Aqua 界面与 Mac 品牌而非底层 BSD；开发者社区对 Mac OS X 的 Unix 兼容性有认知，但市场份额仍以 Windows XP 为主（约 90%）。

**史观**：总纲第 6 条——主体性与和解。Mac OS X、FreeBSD、Linux、Windows XP 在 2001-2003 年的对比是 “主体性” 的显现——此即项目史观总纲第六章的具体呈现：Mac OS X（BSD 内核 + Aqua 桌面）、FreeBSD（BSD 内核 + 命令行）、Linux（Linux 内核 + KDE/GNOME）、Windows XP（NT 内核 + Explorer）共享 Unix/POSIX 哲学的根基但发展出不同的桌面主体性。

**辨析**：消费市场对 “Unix” 认知模糊——2001-2003 年间 Mac OS X 的 BSD 身份未被大众重视，消费者关注 Aqua 界面与 Mac 品牌而非底层 BSD。开发者社区对 Mac OS X 的 Unix 兼容性有认知，但市场份额仍以 Windows XP 为主（约 90%）。采信 “Mac OS X 的 BSD 身份在开发者社区有认知，但消费市场关注 Aqua 界面与品牌而非底层 BSD” 的判断。
