# 367.3.3 BSD 关西会议与地方活动

  **要点**：BSD 关西会议（Kansai BSD Conference）是日本关西地区（大阪/京都/神户）的 BSD 社区会议，与 AsiaBSDCon 互补，规模较小但更聚焦本地社区。此外日本各地不定期举办 BSD 安装会（Install Fest）与黑客松（Hackathon）。
