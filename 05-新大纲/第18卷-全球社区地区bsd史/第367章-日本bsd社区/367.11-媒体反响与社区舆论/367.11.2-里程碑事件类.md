# 367.11.2 里程碑事件类

### 新闻条目 1

- **新闻标题（中英）**：OpenSSF EU Cyber Resilience Act / OpenSSF 欧盟网络弹性法案
- **新闻来源**：Open Source Security Foundation（OpenSSF）官方公共政策页面 + URL <https://openssf.org/public-policy/eu-cyber-resilience-act/>
- **新闻摘要**：OpenSSF 作为 Linux Foundation 旗下开源安全基金会，提供 CRA 合规资源，并间接推动 SSDF 实践在开源生态中的采纳。CRA 部分要求于 2026-09-11 起强制执行，2027-12-11 全面适用。
- **与本章主题的关联说明**：这是 Linux Foundation 旗下 OpenSSF 对 SSDF 与 CRA 衔接的官方资源页面，是本章 “G 类 Linux Foundation 官方通讯” 与 “SSDF 与 CRA 衔接” 小节的辅助史料。
- **与官方史料的交叉验证结论**：OpenSSF 页面位于 `openssf.org` 官方域，CRA 时间节点与 EU Commission 官方页面一致。
