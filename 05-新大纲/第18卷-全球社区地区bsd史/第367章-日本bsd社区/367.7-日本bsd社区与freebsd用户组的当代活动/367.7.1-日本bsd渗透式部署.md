# 367.7.1 日本 BSD ‘渗透式部署’


> 注：文件名 slug 含“与freebsd用户组”，H1 与 SUMMARY 收录标题（“日本 BSD 社区的当代活动”）保持一致；文件名重命名须同步 SUMMARY，属结构性变更，登记 DEFERRED（2026-09-12 整改）。

**要点**：FreeBSD 在日系路由器（Yamaha）、家电嵌入式系统（PlayStation 3/4）、学术 HPC 中广泛但低调部署。JBUG/Japan BSD Users Group 年会 50-100 人。
**史料**：JBUG（Japan BSD Users Group）活动记录；日本部署案例（IIJ、东京大学） 〔L4 事后叙述〕
**史观**：总纲第 15 条——文化即形式主义，日本的“渗透式部署”是技术文化形式化建构的地域显现。
**辨析**：日本 BSD 社区呈现“低调渗透”特征——FreeBSD 在嵌入式与网络设备中广泛部署但用户组活动规模有限，与欧美 BSD 社区的“会议驱动”模式形成对比。日语技术文献丰富但英语输出极少，导致日本 BSD 实践在国际社区中可见度低。PS3/PS4 的 FreeBSD 使用已由 Sony 官方公开披露——PS4 官方开源软件披露页（playstation.com/en-us/oss/ps4/）列明 FreeBSD Kernel、BSD libc、libusb FreeBSD 等组件及其许可声明，PS4/PS5 基于 FreeBSD 亦经 FreeBSD 官方文档更新记录；但 Sony 未公开其修改后内核的完整源码，具体修改范围仍增加史料考据的难度。JBUG 年会参与人数稳定但未增长，暗示日本 BSD 社区面临老龄化问题。
**文献**：JBUG（Japan BSD Users Group）活动记录；IIJ 工程报告；东京大学相关部署记录 〔L4 事后叙述〕
