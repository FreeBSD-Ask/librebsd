# 367.2.2 IPv6 协议栈的 BSD 实现

  **要点**：KAME 项目在 FreeBSD、NetBSD、OpenBSD 上实现了完整的 IPv6 协议栈，包括邻居发现协议（NDP）、地址自动配置（SLAAC）、IPv6 over IPv4 隧道、多播侦听器发现（MLD）等。KAME 的 IPv6 栈成为 Linux 以外最成熟的 IPv6 实现之一〔订正：原“2002-2004 年逐步合并（FreeBSD 4.0 起）”时间自斥，FreeBSD 4.0-RELEASE 为 2000 年 3 月且已含 KAME IPv6/IPsec 栈，现按 4.0=2000-03 为基准重述〕。KAME 的 IPv6 代码自 FreeBSD 4.0-RELEASE（2000 年 3 月）起即合入 FreeBSD src tree（4.0 已随附 KAME IPv6/IPsec 栈），其后至 2004 年前后随各 FreeBSD 版本持续演进更新，KAME 的 IPv6 栈成为 Linux 以外最成熟的 IPv6 实现之一。
