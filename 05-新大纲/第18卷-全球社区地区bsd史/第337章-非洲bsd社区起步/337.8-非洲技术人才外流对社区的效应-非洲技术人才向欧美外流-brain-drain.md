# 337.8 非洲技术人才外流对社区的效应——非洲技术人才向欧美外流（brain drain）对本土 BSD 社区演进的负面效应、外流人才在国际 BSD 社区的贡献

## 337.8.1 brain drain 的具体数据与案例

  **要点**：非洲技术人才向欧美外流（brain drain）对本土 BSD 社区发展造成负面影响；外流人才中部分在国际 BSD 社区做出贡献；具体数据须通过世界银行移民统计与 BSD committer 地理分布核查
  **史料**：世界银行非洲人才外流统计、BSD committer 地理分布、外流人才个人访谈 ［A］
  **史观**：边缘者的贡献被中心叙事遮蔽，非洲人才外流反映全球技术人才流动的不平等
  **辨析**：brain drain 的具体数据须通过权威统计核查——世界银行、国际移民组织等；外流人才的 BSD 贡献须量化
  **文献**：世界银行非洲人才外流统计；BSD committer 地理分布统计；外流人才访谈记录 ［A］

## 337.8.3 非洲与印度人才外流比较

  **要点**：印度技术人才外流规模显著大于非洲，但印度因 IT 产业基础较好，本土 BSD 社区仍能维持；非洲因 IT 产业基础薄弱，人才外流对本土 BSD 社区冲击更大；比较须控制 IT 产业基础与教育体系变量

  **史观**：边缘者的贡献被中心叙事遮蔽，非洲人才外流的冲击反映 IT 产业基础的不平等
  **辨析**：印度 “IT 产业基础较好” 的判断须具体化——产业规模、就业人数；非洲 “冲击更大” 的原因须具体分析
