# 377.1.1 哈萨克斯坦互联网早期与 FreeBSD


115.1 **哈萨克斯坦的 BSD 采用**———哈萨克斯坦的 BSD 采用始于 1990 年代末，哈萨克斯坦互联网早期（KazNet）部分 ISP 使用 FreeBSD 作为骨干服务器，哈萨克斯坦国立大学（KazNU）与哈萨克斯坦-英国技术大学（KBTU）开设 BSD 相关课程

  **要点**：哈萨克斯坦互联网（KazNet）1990 年代末的早期发展中有 FreeBSD 的参与，部分 ISP（如 Kazakhtelecom 的早期网络、Nursat 等）使用 FreeBSD 作为网络服务器。哈萨克斯坦的互联网基础设施起步较晚（1994 年 .kz 域名注册），FreeBSD 在哈萨克斯坦 ISP 中作为廉价的服务器操作系统被采用
