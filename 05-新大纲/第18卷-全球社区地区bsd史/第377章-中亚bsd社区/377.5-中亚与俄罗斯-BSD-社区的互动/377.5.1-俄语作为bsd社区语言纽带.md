# 377.5.1 俄语作为 BSD 社区语言纽带


115.5 **中亚与俄罗斯 BSD 社区的互动**———中亚 BSD 社区与俄罗斯 BSD 社区（特别是莫斯科、新西伯利亚、叶卡捷琳堡的 BSD 用户组）有密切联系，俄语是连接中亚与俄罗斯 BSD 社区的语言纽带，中亚 BSD 用户主要通过俄语在线社区参与 BSD 生态

  **要点**：俄语是中亚 BSD 用户与俄罗斯 BSD 社区之间的语言纽带，中亚 BSD 用户主要通过俄语 BSD 论坛、俄语 Telegram 频道、俄语 BSD 邮件列表参与全球 BSD 生态。俄语 BSD 社区（如俄罗斯 FreeBSD 用户组 RUBSD）是中亚 BSD 用户获取技术信息与社区支持的主要渠道
