# 377.4.1 哈萨克斯坦学术与政府部门的 BSD 部署


115.4 **中亚 BSD 在学术与政府部门的部署**———中亚 BSD 在学术与政府部门的部署极为有限，哈萨克斯坦部分大学与政府部门使用 BSD 作为服务器操作系统，乌兹别克斯坦与吉尔吉斯斯坦的学术部署稀疏

  **要点**：哈萨克斯坦部分大学（KazNU、KBTU、纳扎尔巴耶夫大学）在高性能计算与网络安全研究中使用 BSD 系统。哈萨克斯坦政府部门（如哈萨克斯坦国家信息技术股份公司）在部分服务器基础设施中使用 FreeBSD，但规模远小于 Linux。
