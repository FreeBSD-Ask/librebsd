# 377.4.3 中亚政府部门的开源政策与 BSD

  **要点**：中亚各国政府部门（哈萨克斯坦、乌兹别克斯坦）在 2010 年代后逐渐制定开源政策，哈萨克斯坦 2018 年发布《数字哈萨克斯坦》国家计划，鼓励政府部门使用开源软件，但 BSD 在政府开源采用中占比极小，Linux 是主要受益者
