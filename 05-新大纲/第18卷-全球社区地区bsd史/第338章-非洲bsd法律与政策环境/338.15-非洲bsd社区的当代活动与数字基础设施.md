# 338.15 非洲 BSD 社区的当代活动与数字基础设施

## 338.15.1 BSD 在非洲教育网络与研究机构的部署

**要点**：集中于大学网络基础设施（Stellenbosch、开普敦大学）、ccTLD DNS 基础设施（部分 .za 域名）、NGO 邮件系统。缺乏正式用户组但存在活跃线上协作。
**史料**：AfriNIC/ICANN 非洲 DNS 报告； 大学部署案例 ［B］
**史观**：总纲第 15 条——基础设施需求驱动开源采用。
**辨析**：非洲 BSD 的部署模式呈现“看不见的基础设施”特征——BSD 在 ccTLD DNS、大学网络、NGO 邮件系统中静默运行，但几乎没有形成组织化的社区可见性。OpenBSD Ghana 用户组是非洲大陆极少数正式登记的 BSD 组织之一，但其活动频率与规模缺乏公开记录。非洲 BSD 社区面临的核心挑战不是技术能力，而是缺乏本地化的 BSD 技术文档、培训资源与导师网络——这是 Linux 在非洲压倒性优势的结构性原因之一。AfriNIC 与 ICANN 的 DNS 报告提供了间接证据，但 BSD 在非洲的具体部署规模仍需更系统的田野调查。
**文献**：AfriNIC 报告； 大学案例 ［B］
