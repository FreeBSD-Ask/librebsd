# 331.3 中国大陆 BSD 贡献者与 committer

## 331.3.1 中国大陆 committer 权限记录

  **要点**：中国大陆 committer 权限授予记录分散在邮件列表公告与 commit log 中；2010 年代后随社区国际化推进，中国大陆 committer 比例逐步上升但整体数量仍偏低
  **史料**：FreeBSD commit log、邮件列表公告、Foundation 年度报告 ［A］
  **史观**：边缘者的贡献被中心叙事遮蔽，中国大陆 committer 的实际贡献须从提交日志中重建
  **辨析**：committer 名单的真实性须查 commit log；地域归属须经提交日志中的机构域名与时区信息推断
  **文献**：FreeBSD commit log；邮件列表公告；Foundation 年度报告 ［A］

## 331.3.2 提交者权限的演变过程

  **要点**：中国大陆 committer 权限授予从早期零星授予发展为 mentor 制度下的规范流程；2010 年代后随中文社区代际更替，部分早期 committer 自动退休
  **史料**：mentor 制度文档、commit log 分析、邮件列表讨论 ［A］
  **史观**：总纲第 4 条——权限授予模式的演变体现社区治理的转型
  **辨析**：演变的具体时间节点须考据；自动退休名单的完整性需评估
  **文献**：mentor 制度文档；commit log 分析；邮件列表讨论 ［A］

## 331.3.3 文档翻译与手册贡献者

  **要点**：中文 Handbook 与 FAQ 翻译项目的长期贡献者是中国大陆 BSD 社区的重要力量；翻译项目从零星翻译发展为系统化翻译，但面临可持续性问题
  **史料**：翻译项目存档、SVN/Git 提交日志、社区成员访谈 ［A］
  **史观**：边缘者的贡献被中心叙事遮蔽，翻译者的贡献长期被代码贡献叙事遮蔽
  **辨析**：翻译贡献者的完整名单须考据；翻译质量的评估标准需明确
  **文献**：翻译项目存档；SVN/Git 提交日志；社区成员访谈 ［A］

## 331.3.4 贡献者与 committer 记录的史料辨析

  **要点**：贡献者与 committer 记录分散在 commit log、邮件列表、翻译项目存档中，须交叉验证；部分自动退休的 committer 名单未公开；早期翻译贡献者的档案尤其稀缺
  **史料**：commit log、邮件列表、翻译项目存档、Foundation 档案 ［A］
