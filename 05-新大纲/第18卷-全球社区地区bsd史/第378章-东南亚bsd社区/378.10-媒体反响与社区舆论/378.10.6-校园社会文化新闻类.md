# 378.10.6 校园社会文化新闻类

### 新闻条目 2

- **新闻标题（中英）**：MyBSD Malaysia Project：吉隆坡 BSD 用户组 / MyBSD Malaysia Project: Kuala Lumpur based BSD user group
- **新闻来源**：FreeBSD 官网“User Groups”页面 + URL <https://www.freebsd.org/usergroups/>
- **新闻摘要**：MyBSD Malaysia Project 是一个立足吉隆坡的 BSD 用户组，面向 BSD 用户与开源社群，推广和支持 FreeBSD、OpenBSD、NetBSD 及开源的使用；通常每月聚会一次，地点多在马来亚大学或 Bahadur Shah 餐厅，其项目之一是开发一个 Unix 文件管理器。
- **与本章主题的关联说明**：MyBSD 是东南亚本地化 BSD 社区组织的代表个案，其依托高校（马来亚大学）的聚会形态与本章 343.2“马来西亚的 BSD 社区与教育”子节直接相关。
- **与官方史料的交叉验证结论**：freebsd.org 为 FreeBSD 项目官方域，其“User Groups”页面与官方文档树中的 usergroups.sgml 源文件一致；条目原文以组方自述为准，聚会地点等细节仍属用户组自我陈述，使用时注意与第三方报道互证。
