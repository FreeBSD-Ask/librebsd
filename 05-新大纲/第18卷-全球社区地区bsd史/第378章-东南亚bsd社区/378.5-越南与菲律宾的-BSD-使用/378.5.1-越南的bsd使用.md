# 378.5.1 越南的 BSD 使用


117.5 **越南与菲律宾的 BSD 使用**———越南与菲律宾的 BSD 使用极为稀少，越南 BSD 社区以河内与胡志明市为中心，菲律宾 BSD 社区以马尼拉为中心，两国 BSD 社区规模极小但存在

  **要点**：越南 BSD 使用极为稀少，以河内（Hanoi）与胡志明市（Ho Chi Minh City）为中心的 IT 产业中有少量 BSD 部署。越南 IT 产业以软件外包与 IT 服务为主，部分企业使用 FreeBSD 作为服务器操作系统。越南 BSD 用户组规模极小，活动频率低
