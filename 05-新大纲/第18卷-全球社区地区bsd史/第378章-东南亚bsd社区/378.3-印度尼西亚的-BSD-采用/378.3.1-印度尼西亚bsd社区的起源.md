# 378.3.1 印度尼西亚 BSD 社区的起源


343.3 印度尼西亚的 BSD 采用——印度尼西亚 BSD 采用以雅加达与万隆为中心，印度尼西亚大学（UI）与万隆理工学院（ITB）开设 BSD 相关课程，印度尼西亚 BSD 社区通过在线社区（如 Kaskus、Telegram）组织活动

**要点**：印度尼西亚 BSD 社区以雅加达（Jakarta）与万隆（Bandung）为中心，印度尼西亚互联网早期（1990 年代，以 IndoNet 与 RadNet 为代表的 ISP）据称使用 FreeBSD 作为网络服务器〔存疑：IndoNet、RadNet 采用 FreeBSD 的断言暂无可核验一手出处〕。印度尼西亚 BSD 用户组的形成受到印度尼西亚开源社区（如 Indonesia Linux Community）的影响
