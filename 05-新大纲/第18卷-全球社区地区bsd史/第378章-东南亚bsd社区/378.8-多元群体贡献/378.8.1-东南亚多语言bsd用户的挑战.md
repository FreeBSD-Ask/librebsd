# 378.8.1 东南亚多语言 BSD 用户的挑战


117.8 **多元群体贡献**———东南亚 BSD 社区中不同语言、宗教、民族、职业背景的贡献者群体——新加坡多民族 BSD 用户、马来西亚马来族/华族/印度族 BSD 用户、印度尼西亚 BSD 用户——的多元贡献模式

  **要点**：东南亚多语言环境（英语、马来语、印尼语、泰语、越南语、菲律宾语等）对 BSD 技术文档的本地化构成巨大挑战。新加坡 BSD 用户以英语为工作语言，马来西亚与印度尼西亚 BSD 用户主要使用英语与马来语/印尼语，泰国与越南 BSD 用户面临更严重的语言障碍
