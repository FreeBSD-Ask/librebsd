# 379.10.6 校园社会文化新闻类

### 新闻条目 2

- **新闻标题（中英）**：FreeBSD 官网“User Groups”收录悉尼与墨尔本 BSD 用户组 / FreeBSD User Groups page lists Sydney and Melbourne BSD user groups
- **新闻来源**：FreeBSD 官网“User Groups”历史页面存档 + URL <https://people.freebsd.org/~kuriyama/www/usergroups.html>
- **新闻摘要**：FreeBSD 官方用户组名录的历史存档中，澳大利亚收录两个用户组：BSD Users Group Sydney（BUGS），每两个月聚会一次，邮件列表成员遍布新南威尔士州；Victoria's FreeBSD Users Group（VicFUG），驻墨尔本，可经邮件列表加入。这两个组织是大洋洲 BSD 社区早期组织化形态的直接官方记载。
- **与本章主题的关联说明**：悉尼与墨尔本两大用户组的官方收录，与本章 344.2“澳大利亚 BSD 用户组与会议”子节所记 SBUG（悉尼）、MBUG（墨尔本）的地理分布一致，可互证。
- **与官方史料的交叉验证结论**：people.freebsd.org 为 FreeBSD 项目官方域，该页为其用户组名录的历史快照；用户组自述（聚会频率、地理范围）属组织自我陈述，采信时须与活动记录互证。
