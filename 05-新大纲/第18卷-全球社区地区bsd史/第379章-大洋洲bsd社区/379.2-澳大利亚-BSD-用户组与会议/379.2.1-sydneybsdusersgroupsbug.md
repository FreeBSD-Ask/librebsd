# 379.2.1 Sydney BSD Users Group（SBUG）


118.2 **澳大利亚 BSD 用户组与会议**———澳大利亚 BSD 用户组包括 Sydney BSD Users Group（SBUG）、Melbourne BSD Users Group（MBUG）、Australian BSD Conference（BSDCon Australia）等

**要点**：Sydney BSD Users Group（SBUG）是澳大利亚最大的 BSD 用户组之一，以悉尼为中心，定期举办技术讲座与安装会。SBUG 受益于悉尼作为澳大利亚最大城市与 IT 中心的地位，成员涵盖悉尼大学、UNSW 的学生与悉尼 IT 企业工程师
