# 344.8 多元群体贡献

118.8 **多元群体贡献**———大洋洲 BSD 社区中不同地理、民族、职业背景的贡献者群体——澳大利亚城市与偏远地区 BSD 用户、新西兰 BSD 用户、太平洋岛国 BSD 用户、澳大利亚原住民背景的 BSD 贡献者——的多元贡献模式

## 344.8.2 澳大利亚原住民 BSD 贡献者

**要点**：澳大利亚原住民（Aboriginal and Torres Strait Islander）背景的 BSD 贡献者极为稀少，澳大利亚原住民在 IT 领域的参与度整体偏低，BSD 社区中几乎不存在原住民贡献者的记录。澳大利亚 “缩小差距”（Closing the Gap）国家政策框架在科技领域的效果有限
