### 史观映射

> 欧洲的 BSD 史是学术传统与工程文化交汇的独特篇章——从剑桥大学 Capsicum/CHERI 项目到丹麦 phk 的 Jails 与 GEOM，欧洲贡献者的模式始终不同于美国：学术严谨先于商业效率。欧洲对“自由软件”的理解有着与美国截然不同的前理解，FSFE 的 copyleft 传统与 BSD 许可证的宽松精神长期拉锯，这不是对错之争而是解释学循环中不同起点的必然分歧。欧盟法律框架从 GDPR 到 Software Directive，每一项都是形式主义化的产物，塑造了 BSD 在欧洲的合规边界。而 phk 等欧洲核心开发者以最朴素的方式证明：代码本身就是最好的论证 ｜ **子-子节**：365.11.1 欧洲 BSD 与 Linux 部署比较；330.21.2 OS 选择偏好的演变；330.21.3 与其他地区 OS 格局比较；330.21.4 OS 比较数据的史料辨析
