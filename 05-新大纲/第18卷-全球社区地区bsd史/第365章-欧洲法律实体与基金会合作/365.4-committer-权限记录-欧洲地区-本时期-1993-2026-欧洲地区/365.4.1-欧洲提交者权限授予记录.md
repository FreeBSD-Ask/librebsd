# 365.4.1 欧洲提交者权限授予记录

  **要点**：欧洲地区 committer 权限授予记录分散在邮件列表公告与 commit log 中，依据 “18 个月不活跃自动退休” 条款自动失效的欧洲 committer 名单须逐项考据
  **史料**：FreeBSD commit log、邮件列表公告、Foundation 年度报告 ［A］
  **史观**：边缘者的贡献被中心叙事遮蔽，自动退休条款的执行记录容易被忽略
  **辨析**：committer 名单的真实性须查 commit log；自动退休的执行情况须逐项核查
  **文献**：FreeBSD commit log；邮件列表公告；Foundation 年度报告 ［A］
