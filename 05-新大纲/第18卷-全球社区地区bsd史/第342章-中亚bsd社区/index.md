# 第342章 中亚bsd社区

## 要点

- 哈萨克斯坦互联网（KazNet）1990 年代末的早期发展中有 FreeBSD 的参与，部分 ISP（如 Kazakhtelecom 的早期网络、Nursat 等）使用 FreeBSD 作为网络服务器。哈萨克斯坦的互联网基础设施起步较晚（1994 年 .kz 域名注册），FreeBSD 在哈萨克斯坦 ISP 中作为廉价的服务器操作系统被采用
- 哈萨克斯坦国立大学（KazNU，阿拉木图）与哈萨克斯坦-英国技术大学（KBTU，阿拉木图）在 2000 年代开设 UNIX/BSD 相关课程，哈萨克斯坦 IT 教育体系受俄罗斯影响较深，BSD 教育在哈萨克斯坦高校中规模较小但存在
- 哈萨克斯坦 BSD 用户组在 2000 年代形成，起初以阿拉木图为中心，通过在线论坛（如哈萨克斯坦 IT 论坛、俄罗斯 BSD 论坛的哈萨克斯坦分区）与线下聚会组织活动。哈萨克斯坦 BSD 用户组与俄罗斯 BSD 社区（特别是新西伯利亚与莫斯科的 BSD 用户组）有密切联系
- 哈萨克斯坦 BSD 早期部署记录是评估哈萨克斯坦 BSD 采用的关键史料，但记录保存不完整，大部分资料为俄文或哈萨克文
- 乌兹别克斯坦 BSD 社区以首都塔什干为中心，乌兹别克斯坦互联网（UzNet）1990 年代末的早期发展中有 FreeBSD 的使用记录。乌兹别克斯坦的 IT 基础设施受苏联遗产影响，早期网络设备中 BSD 衍生系统作为低成本解决方案被采用
