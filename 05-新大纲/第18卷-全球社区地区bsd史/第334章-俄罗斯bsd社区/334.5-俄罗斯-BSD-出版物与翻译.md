# 334.5 俄罗斯 BSD 出版物与翻译

## 334.5.1 俄语 BSD 文档翻译项目

  **要点**：Russian FreeBSD Documentation Project 长期翻译 FreeBSD Handbook 与 FAQ；翻译项目分三阶段——1990 年代的零星翻译期、2000-2010 年的系统化翻译期、2011 年后的维护期（更新放缓）；演变与俄语 BSD 社区活跃度同步
  **史料**：Russian FreeBSD Documentation Project 提交记录、freebsd-russian 邮件列表活跃度统计 ［A］
  **史观**：技术路线的分化与并行演化，俄语文档翻译演变与社区活跃度同步
  **辨析**：三阶段划分须经提交记录量化分析核查；2011 年后的维护期是否单纯因社区衰退需辨析
  **文献**：Russian FreeBSD Documentation Project 仓库；freebsd-russian 邮件列表 ［A］

## 334.5.2 Habr 与俄语技术媒体中的 BSD

  **要点**：Habr（原 Habrahabr，2006 年 6 月上线，Denis Kryuchkov 创建，2018 年 4 月 24 日改名 Habr）是俄语技术社区最大的内容平台，涵盖 BSD 相关技术文章；俄罗斯因 Habr 等技术媒体而使 BSD 有较高公众可见度
  **史料**：Habr 历年 BSD 相关文章、freebsd-russian 邮件列表 ［A］
  **史观**：边缘者的贡献被中心叙事遮蔽，俄语技术媒体对 BSD 的报道是公众认知的重要来源
  **辨析**：Habr 上线时间 2006 年 6 月与改名时间 2018 年 4 月 24 日须经原始档案核查；媒体报道的 “零星” 程度须量化分析
  **文献**：Habr 历年档案；freebsd-russian 邮件列表 ［A］

## 334.5.4 俄语翻译项目与其他非英语翻译的比较

  **要点**：其他非英语 BSD 文档翻译项目（如日语、简体中文、繁体中文、德语）与俄语翻译存在差异；日语翻译因 AsiaBSDCon 与日本学术传统而质量较高；俄语翻译因语言壁垒与地缘政治而相对独立
  **史料**：各国 BSD 文档翻译项目档案、freebsd-translators 邮件列表 ［A］
  **史观**：边缘者的贡献被中心叙事遮蔽，非英语翻译比较须结合地域文化语境
  **辨析**：翻译质量的判定标准须明确；“独立性” 的量化方法须考据
  **文献**：各国 BSD 文档翻译项目仓库；freebsd-translators 邮件列表 ［A］
