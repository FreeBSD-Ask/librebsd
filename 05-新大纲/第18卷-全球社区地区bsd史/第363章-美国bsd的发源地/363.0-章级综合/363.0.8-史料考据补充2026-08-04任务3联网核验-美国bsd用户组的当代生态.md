# 363.0.8 史料考据补充（2026-08-04 任务3 联网核验）——美国 BSD 用户组的当代生态

> 主题：美国 BSD 用户组的当代生态——BUUG 伯克利、NYCBUG、CDBUG（2004 成立）、TFUG 等

<!-- 语义复核范围：BSD Now EP270、BSD Now EP261、BSDTalk EP21（共 3 期）；逐期通读转写全文后重写，非关键词或实体评分提取 -->

**要点**：

- OpenBSD 6.4 发布，引入 unveil 系统调用以限制文件系统访问，VMM 增加 QCOW2 磁盘与快照支持，并新增 RETGUARD 返回地址保护与多项 Spectre 缓解。（BSD Now EP270，[66.06-184.52]，L2）
- MeetBSD 2018 在 Intel 圣克拉拉总部举行，首次设立独立程序委员会并公开征稿，穿插闪电演讲与分组讨论，最终以 FreeBSD 25 周年庆典收尾。（BSD Now EP270，[775.34-883.66]，L1）
- Michael Dexter 的回顾称 MeetBSD 结合正式演讲与非会议活动，大型礼堂的弹性空间促成多次即兴黑客聚会，把“走廊轨道”推向新高度。（BSD Now EP270，[1475.34-1519.30]，L2）
- Bjorn Zeeb 提交 IETF draft 6man IPv6-only 标志的初始实现，使 FreeBSD 路由器可宣告链路仅支持 IPv6，并在接口层过滤 IPv4 与 ARP 帧。（BSD Now EP270，[2217.54-2447.32]，L2）
- 1999 年 10 月 17 日第一届 FreeBSDCon 在伯克利举行，300 余人参加，超主办方预期约一半；Kirk McKusick 的 FreeBSD 内部机制教程因人数过多而讲授两遍。（BSD Now EP261，[1365.46-1416.94]，L2）
- 会议设 advocacy、business、development、networking 与安全、panels 六轨；keynote 有 Jordan Hubbard、Jeremy Allison（Samba）、Brian Behlendorf（Apache）；Apple 的 Wilfredo Sanchez 谈 Darwin 与 BSD/FreeBSD 在苹果路线图中的角色。（BSD Now EP261，[1492.16-1605.62]，L2）
- 回放称 Yahoo 有数百台 FreeBSD 机器、Hotmail 约有 2000 台 FreeBSD 机器；Jail 安全机制由 R&D Associates 贡献并引入 FreeBSD 3 与 4；Walnut Creek 赞助会议、Yahoo 负担 core team 赴会费用。（BSD Now EP261，[1731.02-1862.82]，L2）
- TrueOS 团队书面答复：TrueOS 桌面部分拆分为 Project Trident 作为延续，TrueOS 本体转为面向任意 BSD 项目的发行框架，以单一 JSON manifest 描述构建，Lumina 2.0 推迟而先发 1.5 分支。（BSD Now EP261，[430.98-530.70]，L1）
- SDF 的起源链完整可考：Ted Uelman 于 1987 年以 Apple II BBS 起家，用户圈为达拉斯-沃斯堡本地 BBS 社区的日本动漫爱好者，当时运行 ProDOS 并追求更命令行化的界面；1989 年 Stephen Jones 加入，先后弄到 Unix 克隆 Coherent 与移植到 386 的 System V；转折发生在 1990 年 2 月——本地公共访问 Unix 系统 Killer（killer.dallas.tx.us，Charlie Boykin 运营）在 Operation Sun Devil 中被美国特勤局查封，起因是泄露的 AT&T E911 文档据报存于该站；两人决意自建系统取而代之，初期被本地 Unix 管理员视为惹事的孩子而处处受阻，随后 Killer 老用户陆续迁入，Apple II BBS 遂被彻底放弃。（BSDTalk EP21，[88.93-271.01]，L1）
- 联网路径上，SDF 先以 UUCP 经由南卫理公会大学与 Adaptec 等本地中心交换邮件与新闻，1991 年加入 LoneStar.org（该域名 1989 年注册，加入时约五百台主机，成员从跑邮件与新闻的公司 Unix 到在家运行 3B2、3B1 的个人），因而沿用 sdf.lonestar.org 而未自注域名；1992 年两位创始人路线分歧：Ted 希望附带营利商业计划，理想主义且反企业的 Jones 坚持系统完全自由不受限，Ted 遂与部分用户另立 Texas Metronet，成为达拉斯-沃斯堡地区的第一个 ISP，而 SDF 保持非商业路线直至 2001 年才注册为非营利组织。（BSDTalk EP21，[284.01-404.93]，L1）
- 进入 BSD 世界靠两位引路人：1993 年在超导超级对撞机项目工作的 Charles Chang 送他一套 386BSD，运行 UUCP 中心与 SLIP 连接的 Eric Schnobel 介绍他接触当时的 BSD 1.1 并说服其在另一台机器上运行，但 SDF 主系统仍坚守 System V 直到 1997 年前后 PC 的性能与可靠性追平 AT&T 3B2；迁移目标选定 NetBSD——Hurd 远未可用、Linux 被他贬为 SVR4 式的符号链接噩梦，既非纯 BSD 亦非纯 System V，与他对极简系统的要求不合；他的论证旁证是替澳大利亚电子乐团 Severed Heads 运营的 sevcom.com 邮件列表、FTP 与网站自 1993 年起一直跑 NetBSD。（BSDTalk EP21，[406.13-547.77]，L1）
- 迁移的最大技术障碍是密码数据库：NetBSD 以 Berkeley DB 管理口令，与 System V 的做法迥异，而公共访问系统每天大量创建删除账户导致频繁重建，一万五千用户规模下重建一次约一分钟，调整 pwd_mkdb 的哈希参数也仅压到三十秒；2000 年他连同架构更换全力转向 NetBSD/Alpha，以把密码文件置入 MFS 内存文件系统的办法把 Berkeley DB 构建速度提高数倍，不久后 NetBSD 官方也优化了 pwd_mkdb，问题就此消解。（BSDTalk EP21，[561.91-750.44]，L1）
- 运维形态随硬件两度演进：早期两三台机器以 NFS 互相依赖被他自嘲为近亲式文件共享，后改为中央文件服务器加准无盘客户端——本地盘只放临时与交换区、系统文件与工具全赖 NFS；如今是一整排 DS-10L 与 DS-20L 刀片，上架接控制台、走本地 NFS 安装，十五分钟即可使一台系统就绪，控制台可远程开关机使他三年多不必亲赴达拉斯；生产运行 NetBSD 2.1——他称其为 Alpha 上首个稳定的 SMP 内核，CS20 测试机已试 3.0 并配两 TB Fibre Channel 阵列；Alpha 平台的存续判断是 OpenVMS 的大客户群使厂商继续供应零件，他甚至期待三年后在路边捡到理论上可扩至 512 处理器的 HP 顶级 Alpha 机器来跑 SDF。（BSDTalk EP21，[811.15-1424.97]，L1）
- SDF 的用户与治理结构：约两万活跃用户以三个月内登录为活跃标准，空间紧张时按此清理账户、终身会员豁免；提供哪些服务由成员投票决定，涵盖 Gopher、web、FTP、SSH、SSH 隧道与端口转发、screen、cron 等，并虚拟托管约两百个域名、在三个网络上做主辅 DNS 冗余；Gopher 拥有狂热的用户群（包括 Floodgap 一系的人），在复古计算展会 Vintage Computer Festival 上常有人认出他是 SDF 的人；其拨号服务据称是唯一允许拨入 shell 而非 PPP 会话的全国性 ISP；会员分免费、ARPA（1994 年设立以支付账单，名称源于当年含 telnet 与 ftp 的 ARPA 工具包）与 MetaARPA 三级，后者享有更多信任、可跑 cron 与独享服务器，而 telnet 登录后以 new 开户的方式十六年未变；文化生态上还有年度音乐合辑（第四年）、源于 Usenet 贴码的 ASCII 游戏复兴、一款在作者沉寂十五年后复活的多人 Rogue 类游戏、以卢卡斯电影 THX 1138 为主题的自有 MUD，以及经请求板接受安装申请的软件机制，PHP 5 与 MySQL 5 的迁移因 Pine 曾数个版本严重缺陷的教训而格外谨慎。（BSDTalk EP21，[886.00-1290.74]，L1）

**史料**：

- MeetBSD 2018 演讲清单：Chris Moore 的 TrueOS 引导、Kirk McKusick 的“BSD 早年”互动演讲、Michael W. Lucas 的“YBSD”主题演讲、OpenZFS 专家座谈与虚拟化专题讨论。（BSD Now EP270，[993.86-1367.26]，L1）
- OpenSSH 7.9 随 OpenBSD 6.4 发布：CA 签名算法选项禁止以 DSA 作为证书机构、认证日志格式加入证书指纹，并新增按 SHA-256 哈希撤销密钥的能力。（BSD Now EP270，[577.30-750.34]，L2）
- 一手史料：TrueOS 与 Project Trident 团队对问题清单的书面答复（经主持人朗读）；Theo de Raadt 发布于 openbsd-tech 的禁用 SMT/超线程邮件。（BSD Now EP261，[1931.86-2102.50]，L1）
- 二手史料：FreeBSDCon 1999 会议回顾文章；Matt Dillon 在 DragonFly 邮件列表发布的 Threadripper 2990WX 跑分与邮件原文。（BSD Now EP261，[3015.28-3487.92]，L2）

**史观**：

- 总纲18 时间是一种形式主义：FreeBSD 二十五周年被庆典化呈现，但与会者强调“二十五年才能成为二十五年项目”无法抄近路，项目年龄本身就是时间累积的形式。（BSD Now EP270，[1443.38-1475.34]，L1）
- 总纲10 动手者创造历史：unveil 与 RETGUARD 延续 OpenBSD 以安全机制逐步收紧运行边界的方向，主持人将其视为对既有代码进行持续加固而非另起炉灶。（BSD Now EP270，[175.16-247.24]，L2）
- 总纲10 动手者创造历史：第一届会议由开发者与倡导者自发组织，规模超出预期，core team 成员七年来首次线下聚首，体现动手者自己组织历史现场。（BSD Now EP261，[1862.82-1873.30]，L2）
- 总纲6 和解优于斗争：core team 成员多年线上协作后首次面对面，商业伙伴与社区同席，呈现协作优先于对抗的组织形态。（BSD Now EP261，[1857.86-1873.30]，L2）
- 总纲8 本体论上各方平等：Jones 对 Alpha 加 NetBSD 组合的辩护展示了一种以边缘性为生存策略的生态观：架构冷僻使攻击者缺乏兴趣，NetBSD 的冷僻再加一层保险，受限的可及性反而成了安全属性；三十五台 Alpha 刀片在主流叙事宣判其死亡多年后仍高速可靠地服务两万用户——平台的存亡不取决于市场份额的宣判，而取决于具体机器是否仍在被使用与维护。（BSDTalk EP21，[1312.26-1345.33]，L1）

- 本期对 OpenBSD 6.4 特性的转述与章节考据的发布时间（2018-10-25）一致，但 unveil 与 RETGUARD 的提交细节须以 OpenBSD commit log 与 Release Notes 交叉核实。（BSD Now EP270，[175.16-212.76]，L3）
