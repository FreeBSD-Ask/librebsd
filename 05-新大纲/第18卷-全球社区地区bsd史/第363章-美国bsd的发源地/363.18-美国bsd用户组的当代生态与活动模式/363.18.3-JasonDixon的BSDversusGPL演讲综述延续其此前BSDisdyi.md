# 363.18.3 JasonDixon的BSDversusGPL演讲综述延续其此前BSDisdyi

- Jason Dixon 的 BSD versus GPL 演讲综述：延续其此前 BSD is dying 演讲的轻松幽默风格，以笑话包裹许可证议题——讨论人们对各许可证自由程度的假设与哪种更自由的持久争论，并强调正试探涉足开源的企业有必要了解各许可证在可为与不可为、担保与自由保障上的差异。（BSDTalk EP161，[1152.98-1223.62]，L2）
- 首届 DCBSDCon 定于 2009 年 2 月在华盛顿特区举行，由华盛顿地区 BSD 用户组 CAPBUG 主办，筹办者 Jason Dixon 自 OpenBSD committer 朋友 Mike Erdly 起酝酿多年，最终借与 ShmooCon 黑客大会衔接的思路落地：ShmooCon 创始人 Bruce Potter 本身是 BSD 支持者，两会同城衔接可共享既到场的 BSD 倾向听众并获得规模经济。议题征集初以安全为指引主题，因收到大量与安全无关的优秀投稿而改为一般性 BSD 会议；各 BSD 均有代表，唯 MirOS BSD 缺席。（BSDTalk EP167，[65.46-155.38]，L1）
- 会议形态设计为两天单轨、每日约五至六场演讲，节奏仿照纽约 BSD Con（筹办者曾在此演讲），追求内容充实而不疲于奔命的社交友好型安排；注册目标价 50 至 75 美元以保持门槛亲民；现场设 BSDA 认证考试，由 Drew Levine 主理数场；赞助包与志愿者（已自 CAPBUG 召集）陆续落实。已确认的重磅演讲人包括 FFS 与 Soft Updates 之父 Kirk McKusick，以及 OpenNTPD、OpenBGPD 作者兼 OpenBSD PF 主力开发者 Henning Brauer。（BSDTalk EP167，[403.76-563.28]，L1）
- SysAdmin challenge 竞赛源于 CAPBUG 例会演示形式趋于陈旧的自省：筹办者把小学课堂黑板竞赛的组队对抗记忆与电视问答节目的求助环节混合，设计出团队系统管理挑战赛——在一台 VMware 服务器上部署四个 BSD 镜像，各队被投入未必熟悉的 BSD 环境，完成一系列只有主持人知晓的目标，期间可获得求助线；该赛制于数月前在 CAPBUG 试办大获成功，决定搬上首届大会。（BSDTalk EP167，[292.26-397.76]，L1）
- 节目片头新闻记录了一个资源节点：YouTube 上建立了 BSD conferences 频道，开始集中上传本年度与上一年度各 BSD 会议的演讲视频，会议影像自此有了聚合出口。（BSDTalk EP167，[27.10-41.86]，L2）
- 受访者在 ShmooCon 2006 演讲中把网络安全监控数据划分为告警、统计、会话与全内容四类，主张以 Bamm Visscher 主导开发的开源接口 Sguil 整合四类数据；他批评当时流行的 Snort 告警界面 ACID 与 BASE 无法满足严肃入侵检测需求，同台者 David Bianco 又演示了不依赖任何签名、仅凭会话数据发现 Windows WMF 漏洞利用活动的检测路径。（BSDTalk EP13，[528.07-656.97]，L1）
- 受访者回忆其 FreeBSD 使用史：1999 年获赠 FreeBSD 3.2 安装光盘，2000 年前后在得克萨斯州圣安东尼奥的空军计算机应急响应组任上尉期间，因同僚看重 FreeBSD 网络栈的稳固而促成部队以此构建传感器；2001 年初退役进入托管安全服务行业后，所在公司选定 FreeBSD 4.2 作为传感器平台，此后他创办 Tao Security，所有自建传感器仍全部基于 FreeBSD。（BSDTalk EP13，[1208.39-1310.62]，L1）
- 截至 2006 年初，美国国防部已规定 2008 年起骨干网强制采用 IPv6；受访者以审读 O’Reilly《IPv6 Network Administration》与 Apress《Running IPv6》两本专著并在 FreeBSD 上动手实验为基础，判断 128 位源与目的地址使抓包分析的可读性显著恶化；同时指出 BSD 阵营的蓝牙安全扫描工具远少于 Linux，已有社区成员尝试将相关工具移植入 FreeBSD ports。（BSDTalk EP13，[840.37-938.92]，L1）
- NYCBSDCon 2010 定于 11 月 13 至 15 日在曼哈顿东村的 Cooper Union 举行，后者是一所以建筑与工程著称的学校，林肯曾在此发表关于分裂之家的著名演讲；较之往年上城 Columbia 附近的场地，新址周边有远为便宜的住宿，是迁址带来的实际改善。（BSDTalk EP196，[152.48-178.80]，L1）[订正：原 [152.48-184.20]，2026-09-30 SenseAudio 重转核对]
- 会议延续往届结构：单一技术轨道收录经提交与评审的论文，话题兼顾内核层面的深技术与非内核的高层次内容；另设 BoF 轨道由 George Neville-Neil 负责征集议题；注册于 9 月 15 日开启，费用 95 美元、含早餐与午餐，与往年持平，日程随后在 nycbsdcon.org 公布。（BSDTalk EP196，[184.20-376.56]，L1）
- 赞助生态仍在扩充：已确认 about.com、NYI（New York Internet）、iXsystems、FreeBSD Foundation、Pearson 与 pfSense 及若干小型企业赞助者；Mark Saad 自述其雇主 about.com 为本年主要赞助商之一，工作与家中皆重度使用 FreeBSD。 [存疑脚注] 转写将 iXsystems 误作 IAC systems、FreeNAS 误作 Freedance，依语境辨正，建议核对原始音频。（BSDTalk EP196，[273.72-296.20]，L1）
- NYCBSDCon 2014 的定位与往届不同：以 BSD 用于生产为主题，议程讲 BSD 的实际应用而非开发新调度算法一类研究话题，目标受众多元，明确希望吸引 Linux 管理员、开发者、Solaris 难民与网络运营商进入 BSD 世界，比以往会议更面向更大的技术社群。（BSDTalk EP236，[107.32-135.74]，L1）
- 会议定于 2014 年 2 月 8 日单日举行，场地是华尔街上方百老汇 111 号的 Suspenders 餐吧，即 NYCBUG 例会的固定场所，单轨议程，散场后恢复为普通周六酒吧营业；票价刻意压低以保可及性——会员活动现金 25 美元、在线 50 美元、当日 30 美元、学生 15 美元，且含早餐与午餐，现金价几乎只相当于一顿饭钱。（BSDTalk EP236，[459.46-552.74]，L1）
- 议程构成：约半数讲者已定，包括 Michael W. Lucas、Scott Long 与 Andrew Wong，其余半数向公众征集演讲；Andrew Wong 的演讲围绕 PostgreSQL、ZFS 与 FreeBSD 三件套的数据仓库实战；午间首创 exposés 展示环节，让做小型用户项目的使用者向更大的技术社群展示成果，Brian Callahan 计划带 OpenBSD MIPS 笔记本与设备供人上手。（BSDTalk EP236，[569.66-692.50]，L1）
- 两位当事人的自我定位：Brian Callahan 是 OpenBSD 开发者，兴趣在少有人涉足的架构，做 Octeon、Loongson、SGI 等 MIPS 相关移植工作；Ike Levy 自称不是任何项目的 committer、是 OpenBSD 的“找茬者”，职业是构建高可用系统与网络基础设施，长期使用 ZFS，BSD 与高可用系统在其整个职业生涯中相伴而行。（BSDTalk EP236，[1011.98-1094.54]，L1）
- 系统管理员 NJ Thomas 的参会自述最具代表性：作为以 Linux 维生、在个人服务器上使用 BSD 的用户，他几乎每届 NYCBSDCon 必到（仅首届因婚礼缺席），认为这种日场会的收获远超票价——发布最佳实践、新技术，以及 session 之间的“走廊轨道”交流；他今年带来日职的存储工程师现场试用 ZFS on BSD、带来乐于接触新技术的应用开发者，会间大家讨论数据库选型与策略，并向新人推荐 NYCBUG 例会。（BSDTalk EP238，[85.00-161.90]，L1）
- 与会者中可见内容与代码的生产者：DragonFly BSD Digest 的维护者 Justin Sherrill 来会是为了寻找源源不断的可发布素材；天文学家出身的软件开发者 John Vranaleo 自 Linux 背景转入，正在参与并贡献较新的 BSD 衍生项目 BitRig，作为纽约本地人来此与区域内的 BSD 同好相聚。（BSDTalk EP238，[163.32-197.58]，L1）
- 会上自述的商业采用案例：Calyptic Security 的 CEO Ben Yarbrough 称公司以 BSD（主要是 OpenBSD）为核心为小企业提供简化的网络安全产品，来会寻求成长资源；OneCloud Labs 的 Nate Van Voorst 介绍其从 VMware 数据中心向 Amazon 云做灾备的创业项目、客户端以 FreeBSD 为基底，并借会招募新英格兰地区的工程师；软件咨询公司 BitBase 用 BSD 支撑移动应用后端，深耕 ZFS 与 PostgreSQL 以求系统更优。（BSDTalk EP238，[196.42-330.08]，L1）
- 口述样本亦覆盖了光谱的另一端：OpenBSD Project 的 Mike Erdly 专程到会支持美国东海岸的会议；Amplify Education 的系统管理员自称 1998 年起的 FreeBSD 老用户、来此社交；初到纽约、任职 Warby Parker 自动化部门的 David Neudorfer 终生使用 Mac、深谙终端却几乎无 BSD 服务器经验，为 ZFS 与 BSD 网络设备而来；另有康涅狄格的技术顾问首次参加 BSD 活动、九十年代从 Sun 起步的老兵四年来首次回归，以及一位机械工程训练出身、六年前借 FreeBSD 学 Unix 管理的爱好者。（BSDTalk EP238，[365.42-419.44]，L1）
- 一位 Debian 老用户的参会动机集中显示 2014 年初 BSD 对 Linux 用户的吸引点：两场 ZFS 演讲是其最大亮点，Netflix“三分之一互联网流量”的演讲标题对他冲击极大，而关于集成 BSD 设备的演讲让他第一次意识到 Juniper 等大型公司基于 BSD；他此前仅在 OpenIndiana 上为跑通 ZFS 数据共享而短暂使用，损坏过数次数据仍相当满意，并因想要最新版 ZFS 而 Linux 发行版不能原生附带、当时几乎没有别的途径。（BSDTalk EP238，[419.44-500.74]，L1）
