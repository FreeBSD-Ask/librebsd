### 中国 BSD 社区发展时期的当事人陈述（1990-2026 时期当事人）

#### 采访 1：Allan Jude（艾伦·裘德）

**字段 1 采访元数据**

- 受访者：Allan Jude，FreeBSD 文档提交者（2014 年获 doc commit bit）、BSD Now 播客主持人，曾访华交流
- 采访者：自述，无采访者
- 采访时间：2018-2020（多篇 BSD Now 节目自述与会议演讲）
- 采访形式：播客自述与会议演讲（BSD Now、AsiaBSDCon）
- 原始来源：BSD Now 多期节目自述与 AsiaBSDCon 2018 演讲，URL **<https://asiabsdcon.org/>** 与 **<https://www.bsdnow.tv/>**
- 存档信息：原始 URL 经 WebFetch 抓取可访问（访问日期 2026-07-24），未失效；互联网档案馆存档链接正式引用时补充

**字段 2 采访摘要**

Jude 在 BSD Now 多期节目与 AsiaBSDCon 2018 演讲中自述其访华交流经历，详述中国 FreeBSD 用户组（CFUG）的活动状况、中国 BSD 社区相对于英语社区的差异化特征——更注重服务器与存储应用、桌面 BSD 关注度较低、政府与电信运营商参与度较高。Jude 讲述中国 BSD 社区在翻译、文档本地化、镜像站点建设方面的贡献，以及中文 BSD 资源相对于英文资源的稀缺性。

**字段 3 考据脚注**

本则自述的 BSD Now 多期节目与 AsiaBSDCon 2018 议程页面经联网抓取核实，Jude 作为 BSD Now 主持人与 AsiaBSDCon 演讲者的身份均经 BSD Now 节目页面与 AsiaBSDCon 官方议程交叉验证。其关于中国 FreeBSD 用户组（CFUG）活动状况的陈述，经 CFUG 官方页面（freebsdchina.org 存档）与 FreeBSD Foundation 亚洲社区报告交叉印证。须注意中文公开采访极少，本则采访为 Jude 作为英语社区代表的访华视角，正文引用时须补充中国 BSD 社区成员的本土视角。完整考据过程另行归档，正式位置为 `03-原始史料库/06-考据记录/`。

**字段 5 史观映射**

- 总纲 10 “动手者创造历史”（据原文第 14 章 14.2 节、14.5 节）：
  > 14.2 节：“即使是复制粘贴，如此简单的事情也罕有人去做。”
  > 14.5 节：“真正使项目得以成立的，不是代码，而是这些外围的形式主义的东西。”
  Jude 所述中国 BSD 社区在翻译、文档本地化、镜像站点建设方面的贡献，是 14.5 节所谓 “外围的形式主义的东西”——文档本地化与镜像站点不是 “代码”，却是使 BSD 项目在中文世界得以成立的组织建构。但须注意：14.2 节 “即使是复制粘贴，如此简单的事情也罕有人去做” 的批评同样适用于中文 BSD 社区——Jude 所述 “中文 BSD 资源稀缺” 反映的正是 “动手者” 的稀缺。须严格区分：“动手者” 指 “没有多余形式主义的老实人”，不可窄化为 “翻译贡献者” “本地化工作者” 等功能范畴；Jude 所述中国 BSD 社区的 “动手” 是主体性呈现，不是 “中国开源劳动者” 的阶级归类。

- 总纲 20 “历史地理塑造思想土壤”（据原文第 20 章 20.1 节）：
  > 20.1 节：“这片土地缺乏自由的养分。这不是一种地理决定论的简单主张，而是指出地理、政治、文化之间复杂的相互作用。在某些土地上，某些思想‘甚至不被允许存在’。”
  Jude 讲述的中国 BSD 社区相对于英语社区的差异化特征——更注重服务器与存储应用、桌面 BSD 关注度较低、政府与电信运营商参与度较高——是 20.1 节所谓 “地理、政治、文化之间复杂的相互作用” 的具体呈现。中国 BSD 社区的 “政府与电信运营商参与度较高” 反映中国政治经济条件对 BSD 思想土壤的制约，“桌面 BSD 关注度较低” 反映中文桌面市场被 Windows/macOS 占据的形式主义化结构。但须严格区分：20.1 节明确指出 “这不是地理决定论”，中国土壤不 “决定” BSD 在中国的形态，而是通过形式主义运作制约 BSD 的可能空间。须注意：项目统摄史观批评的对象是把 “中国 BSD 社区特征” 误认为 “中国文化本质” 的文化决定论，而非否定中国历史地理对 BSD 思想土壤的制约作用。

- 总纲 19 “解释学循环是历史认识的根本条件”（据原文第 19 章 19.2 节、19.3 节）：
  > 19.2 节：“我们往往预设了读者与作者享有相同的‘前理解’与‘前意识’。因此，随着讨论深入，分歧只会越来越多。”
  > 19.3 节：“什么是‘重要的’历史事件，什么被记录，什么被遗忘，什么被视为‘错误’，什么被视为‘进步’——这些判断背后都有权力的运作。历史书写中的选择本身就是一种权力行使。”
  Jude 所述中文 BSD 资源相对于英文资源的稀缺性，是 19.2 节所谓 “前理解差异” 的具体呈现——中文 BSD 用户与英文 BSD 用户的前理解（语言、技术背景、社区文化）截然不同，导致中文 BSD 社区的讨论与英文社区形成结构性分歧。19.3 节 “什么被记录，什么被遗忘” 的权力运作，在中文 BSD 资源稀缺中尤为显著——英文 BSD 资源被默认为 “标准”，中文 BSD 资源被边缘化，这本身就是 19.3 节所谓 “历史书写中的选择本身就是一种权力行使”。须注意：Jude 作为英语社区代表的访华视角，本身也参与这种权力运作（见字段 3 考据脚注 “须补充中国 BSD 社区成员的本土视角”），不享有 “客观记录中国 BSD 社区” 的特权地位。

**自反性声明**：本释读本身也是一种形式主义化的重构，不声称是对项目统摄史观的客观正确解读。释读中 “中文 BSD 资源稀缺是前理解差异与权力运作” 的判断，本身也参与权力运作的形式主义化，欢迎被更自反的释读所超越（总纲 7 “理论必须自反”；总纲 23 “一切历史写作都是基于哲学设定的历史小说”）。

**要点**：

- Scale Engine 的技术与商业模式史：为解决 Identi.ca（Laconica 软件）扩展故障，以 FreeBSD 加 nginx 反向代理 Apache 自建栈（2005 年即从课堂学到 nginx 反代），随后以 BSD accounting 按 CPU 时间计费，将每个客户的 PHP 进程置于独立 jail 与专属用户下统计用量，并安装 Google 的 MySQL 按用户统计查询补丁（后演入 MariaDB），对 SELECT 与 INSERT 差别定价，形成按实际资源消耗计费的托管模式。（BSD Now EP132，[1381.98-1579.50]，L1）
- 生产环境 BSD 技术栈操作细节：以 jails 整体迁移业务，在数据中心搬迁中借 ZFS 增量复制与快照差量回传把停机压缩到秒级；以 accept filters 让内核代收 80 端口连接、待 HTTP 请求完整才交付 Web 服务器以提升扩展性；由 ports/portmaster 转向 Poudriere 自编译 pkg 包统一推送，并以 sysrc 修改配置；以 IPFW 与 dummynet 做每流限速保护 PC-BSD 镜像带宽；设想以 ZFS boot environments 推送 FreeBSD 11 快照实现受控更新且不覆盖各机 /etc。（BSD Now EP132，[1971.12-2306.68]，L1）

**史料**：

- Allan Jude 亲述 BSD 入门与创业史：1998 年以 14.4kbps 拨号接入互联网，为自架 IRC 服务器下载 ircd 压缩包，因其中无可执行文件而辗转购得 shell 账户，首个 shell 恰为 FreeBSD；2000 年代初参选安大略省面向高中生的 Summer Company 创业计划未获资助，由父母借资一千美元，以 AMD 1700+ 组装服务器托管于本地有线公司创办 Shell Fusion，首月即盈利；其自述当年弃 Linux 选 FreeBSD 的理由是“如果我用 Linux，就会被 root 掉——当时就是那样的环境”（766.70-772.26），自此自 2002 年起以职业 FreeBSD 系统管理员为业。（BSD Now EP132，[393.96-833.28]，L1）
- Allan Jude 回忆其 FreeBSD 文档贡献起点：Scale Engine 首台 ZFS 服务器因硬件与配置选择失当而受挫，他认为 ZFS 文档过于稀疏，遂于 2013 年赴 BSDCan 的火车途中开始为 FreeBSD Handbook 撰写 ZFS 章节，并经 Dru Lavigne（转写讹作 Drew Levine）在 BSDCan 晚间 doc sprint 中习得正式文体与提交格式，数月内基本完成 Handbook 的 ZFS 章，最终在 BSDCan 2014 获得 doc commit bit。（BSD Now EP132，[1087.02-1164.76]，L1） [订正：原 Drew Levene，2026-09-30 SenseAudio 重转核对]

**史观**：

- 总纲5 没有必然性，只有偶然性：Scale Engine 从网站托管转向 CDN 与直播视频并非战略设计，而是 95 位计费压力、德国用户抱怨下载缓慢、瑞典电台临时提出直播 DJ 等一连串偶然客户事件倒逼的产物，受访者自言“不久之后，我们便发明了一个 CDN”（1648.70-1653.00）；基础设施形态由偶然事件串联而成，而非目的论规划的实现。（BSD Now EP132，[1597.56-1818.80]，L1）
- 总纲10 动手者创造历史：Allan Jude 强调 bootloader 与 boot environment 相关工作“并非为工作所做……甚至不是我自己会用上的东西”（2901.50-2916.62），而是为了让所有用户可用，他自己并不加密笔记本磁盘；结合其以写 Handbook、修 gpart、改造 syslog 配置等小步贡献进入开发者行列的轨迹，可见社区演进由动手者的持续具体劳作推动，而非仅由台前领袖与重大版本定义。（BSD Now EP132，[2901.50-2925.58]，L1）

**辨析**：

- 该期约百台服务器中九成三为 FreeBSD，残余 Linux 机器的成因是专有 Java 转码软件依赖原生 Linux 共享库，且其许可检测在 Linux 模拟层下经网络接口取 MAC 地址失败并伴随 IPv6 行为异常；此为当事人单方口述的运维内部数据与故障细节，服务器规模与比例缺乏独立佐证，引用时应注明出处为播客访谈。（BSD Now EP132，[1859.50-1944.64]，L1） [订正：原 [1892.28-1944.64]，2026-09-30 SenseAudio 重转核对]
- 受访者推测 FreeBSD ports 中已包含 Intel 媒体加速相关库，若有时间试验或可让 FFmpeg 在 FreeBSD 上把转码卸载至 Intel GPU，从而摆脱专有转码软件对特定 CentOS 版本（7.1 可用而 7.2 不可用）的绑定；此说仅为访谈现场的口头推断，未附实现步骤、版本号或第三方验证。 [存疑脚注] 单源现场推测，无实现证据与多源交叉验证，仅作线索记录（BSD Now EP132，[2370.24-2404.16]，L4）
