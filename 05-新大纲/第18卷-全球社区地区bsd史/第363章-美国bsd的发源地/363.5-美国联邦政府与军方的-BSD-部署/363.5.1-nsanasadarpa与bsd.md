# 363.5.1 NSA/NASA/DARPA 与 BSD


> 本章导语：NSA SELinux 早期对 BSD 的研究、NASA 喷气推进实验室、美国国防部与 DARPA 资助历史、美国海军潜艇系统、美国空军空管系统。

  **要点**：NSA 于 2000-2001 年将 SELinux（FLASK/Type Enforcement 架构）以 GPL 发布，其强制访问控制架构与 FreeBSD TrustedBSD MAC 框架同属一条技术谱系，NSA 研究人员与 TrustedBSD 社区曾就 MAC 架构公开交流（TrustedBSD MAC 框架借鉴 FLASK 架构，见 137 章安全模型章）；DARPA 对 CSRG 的资助（1990 年代初至 1995）支撑了 4.4BSD 与 Net/2 的开发，是联邦资助塑造 BSD 的制度性节点（解密背景详述见 363.5.5）；NASA JPL 的 BSD 部署具体案例公开记录稀少〔存疑：待回源〕。
  **史料**：NSA SELinux 发布公告与技术文档（nsa.gov/selinux）；TrustedBSD MAC 框架设计论文（Watson 等，2001-2003）；DARPA 资助 CSRG 合同记录 ［A］
  **史观**：总纲第 13 条——法律与道德是利益分配：国防投入作为联邦资源分配塑造了技术应用路径
  **辨析**：各机构部署的具体规模需考据；保密性影响史料完整性需评估
  **文献**：NSA SELinux Documentation；DARPA Funding Records ［A］
