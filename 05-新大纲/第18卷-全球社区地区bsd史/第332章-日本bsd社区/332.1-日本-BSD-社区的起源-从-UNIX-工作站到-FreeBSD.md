# 332.1 日本 BSD 社区的起源：从 UNIX 工作站到 FreeBSD

108.1 **日本 BSD 社区的起源：从 UNIX 工作站到 FreeBSD**———1980 年代日本 UNIX 工作站（Sony NEWS、NEC EWS、富士通 S 系列）运行 BSD 衍生系统，1990 年代 FreeBSD 在日本服务器与 ISP 领域迅速普及，早稻田大学、东京大学、东京工业大学等高校成为 BSD 人才培养基地

## 332.1.1 日本 UNIX 工作站时代的 BSD 遗产

  **要点**：1980 年代日本 UNIX 工作站包括 Sony NEWS（1987 年推出，运行 Sony NEWS-OS，基于 4.2BSD/4.3BSD）、NEC EWS-4800（运行 EWS-UX，基于 System V 与 BSD 混合）、富士通 S 系列（运行 UXP/DS，BSD 衍生），这些工作站为日本 BSD 社区奠定了技术土壤。1990 年代 FreeBSD 在日本服务器与 ISP 市场迅速普及，IIJ（Internet Initiative Japan）1992 年成立后大量使用 FreeBSD 作为骨干路由与邮件服务器。
  **史料**：Sony NEWS 技术手册、NEC EWS-4800 系统文档、IIJ 技术报告、富士通 UXP 文档 ［A］
  **史观**：总纲第 20 条——日本作为 UNIX 工作站大国，其硬件生态塑造了 BSD 的早期渗透路径
  **辨析**：Sony NEWS-OS 的 BSD 衍生程度需区分不同版本；IIJ 使用 FreeBSD 的具体规模需考据

## 332.1.2 早稻田大学等高校 BSD 教育

  **要点**：早稻田大学、东京大学、东京工业大学、庆应义塾大学等高校在 1990 年代开设 BSD 相关课程，东京大学 1991 年出版《The Design and Implementation of the 4.3BSD UNIX Operating System》日文译本（Addison-Wesley Japan 出版），早稻田大学 1995 年起开设 FreeBSD 系统管理课程
  **史料**：各大学课程目录、BSD 教材日文译本出版记录、日文 BSD 教材 Archive ［B］

## 332.1.3 日本 ISP 与 FreeBSD 的早期互构

  **要点**：日本互联网早期（1992-2000 年）ISP 行业大量采用 FreeBSD 作为骨干服务器，IIJ、BIGLOBE（NEC 运营）、@nifty（富士通运营）、OCN（NTT 运营）等 ISP 的早期骨干均曾运行 FreeBSD，日本 FreeBSD 用户组的诞生与 ISP 系统管理员群体的需求密切相关
