# 369.6.1 制裁下的本土化适应

**要点**：2014 年后制裁推动本土化——开发者开发了多个基于 FreeBSD 的本土系统（如 ROSA BSD 分支、Astra Linux BSD 兼容层）。FreeBSD 在俄学术网络（RUNNet）与政府网关中持续使用。
**史料**：Russian FreeBSD 用户组； 俄罗斯开源政策文件 ［B］
**史观**：总纲第 12 条——政治压力塑造开源生态。
**辨析**：俄罗斯 BSD 社区面临的核心张力在于制裁与开源之间的结构性矛盾——BSD 许可证的开放性理论上允许任何人在任何政治环境下使用，但西方科技公司的合规部门对俄罗斯 IP 的排斥使得俄罗斯 BSD 开发者难以参与上游社区。ROSA BSD 等本土分支的兴起是适应而非创新——它们更接近安全补丁的本地化维护而非独立的技术路线。Telegram 迁移（freebsd_ru 从 IRC 迁至 Telegram）反映了俄罗斯技术社区对西方平台信任度的下降，但也使俄罗斯 BSD 社区与国际 BSD 社区的信息流通进一步受阻。Lissyara 论坛的存在表明俄语 BSD 技术讨论仍有活跃生态，但其封闭性使外部研究者难以评估其规模与深度。
**文献**：RBUG 记录； 俄罗斯政策文件 ［B］
