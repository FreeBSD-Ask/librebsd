# 369.7.4 俄语翻译者与文档贡献者

  **要点**：**Russian FreeBSD Documentation Project** 的长期翻译者将 FreeBSD Handbook 与 FAQ 系统化翻译为俄语；翻译者的贡献长期被代码贡献叙事遮蔽
  **史料**：**Russian FreeBSD Documentation Project** 提交记录、**freebsd-russian** 邮件列表 ［A］
  **史观**：边缘者的贡献被中心叙事遮蔽，翻译者的贡献长期被代码贡献叙事遮蔽
  **辨析**：翻译贡献者的完整名单须考据；翻译质量的评估标准需明确
  **文献**：**Russian FreeBSD Documentation Project** 仓库；**freebsd-russian** 邮件列表 ［A］
