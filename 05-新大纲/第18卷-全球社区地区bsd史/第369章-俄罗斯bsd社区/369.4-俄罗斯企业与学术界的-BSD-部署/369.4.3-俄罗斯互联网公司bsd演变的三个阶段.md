# 369.4.3 俄罗斯互联网公司 BSD 演变的三个阶段

  **要点**：演变分三阶段——1996-2005 年的 BSD 主导期（Yandex、Mail.ru、Rambler 均基于 FreeBSD）、2006-2015 年的 Linux 迁移期（Yandex 等逐步迁移至 Linux）、2016 年后的多元化期（含云原生与容器化）；演变与国际互联网公司技术栈趋势同步
  **史料**：Yandex 与 Mail.ru 技术博客历年档案、招聘信息历年变化 ［C］
  **史观**：技术路线的分化与并行演化，俄罗斯互联网公司 BSD 演变与国际趋势同步但有地域特色
  **辨析**：三阶段划分须经公司技术博客量化分析核查；Linux 迁移的原因须结合具体场景分析
