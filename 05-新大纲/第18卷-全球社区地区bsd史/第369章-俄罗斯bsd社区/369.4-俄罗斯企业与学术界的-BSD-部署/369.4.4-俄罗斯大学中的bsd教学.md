# 369.4.4 俄罗斯大学中的 BSD 教学

  **要点**：俄罗斯高校 BSD 教学以莫斯科国立大学（MSU）、圣彼得堡国立大学（SPbSU）、莫斯科物理技术学院（MIPT）、圣彼得堡理工大学（SPbPU）为主；教学以 FreeBSD 与 Linux 并重，部分课程使用 BSD 作为操作系统课程实验平台
  **史料**：俄罗斯高校课程目录、freebsd-russian 邮件列表中高校教师讨论 ［A］
  **史观**：组织结构对技术路径的塑造，俄罗斯高校的 BSD 教学传统塑造本土 BSD 人才储备
  **辨析**：高校 BSD 教学的具体规模须经教务档案核查；“BSD 课程” 的判定标准须明确
  **文献**：MSU、SPbSU、MIPT、SPbPU 课程目录；freebsd-russian 邮件列表 ［A］
