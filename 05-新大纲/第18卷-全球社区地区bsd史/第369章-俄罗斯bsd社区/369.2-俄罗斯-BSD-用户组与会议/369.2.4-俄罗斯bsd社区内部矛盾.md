# 369.2.4 俄罗斯 BSD 社区内部矛盾

  **要点**：俄罗斯 BSD 社区内部矛盾主要表现为语言壁垒与地缘政治导致的封闭性；2022 年制裁后俄罗斯社区进一步封闭，与西方 BSD 社区的交流减少
  **史料**：freebsd-russian 与 freebsd-hackers 邮件列表 ［A］
  **史观**：边缘者的贡献被中心叙事遮蔽，社区矛盾叙事须警惕政治立场偏差
  **辨析**：矛盾事件的描述须以原始档案为准，避免事后叙事的夸大；“封闭性” 的判定标准须明确
  **文献**：freebsd-russian 与 freebsd-hackers 邮件列表 ［A］
