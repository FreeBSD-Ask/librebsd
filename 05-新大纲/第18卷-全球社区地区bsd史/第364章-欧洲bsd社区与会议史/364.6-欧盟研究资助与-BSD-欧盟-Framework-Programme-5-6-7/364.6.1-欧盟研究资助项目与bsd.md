# 364.6.1 欧盟研究资助项目与 BSD

  **要点**：欧盟 Framework Programme 自 FP5（1998-2002）起持续资助 BSD 相关项目，FP5 IST-2001-32613、FP6 IST-2004-511531、FP7 ICT-2007-216426、H2020 ICT-2014-644058 等项目编号可查；Horizon Europe（2021-2027）延续对开源基础设施的资助框架

| Framework Programme | 时间跨度 | 项目编号 | 资助方向 |
| ----------------- | ------ | ------ | ------ |
| **FP5** | 1998-2002 | `IST-2001-32613` | BSD 相关项目 |
| **FP6** | 2002-2006 | `IST-2004-511531` | BSD 相关项目 |
| **FP7** | 2007-2013 | `ICT-2007-216426` | BSD 相关项目 |
| **H2020** | 2014-2020 | `ICT-2014-644058` | BSD 相关项目 |
| **Horizon Europe** | 2021-2027 | — | 延续对开源基础设施的资助框架 |
