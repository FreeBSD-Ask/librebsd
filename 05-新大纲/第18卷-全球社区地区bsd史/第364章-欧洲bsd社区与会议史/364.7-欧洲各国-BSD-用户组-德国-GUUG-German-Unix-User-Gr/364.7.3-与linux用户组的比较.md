# 364.7.3 与 Linux 用户组的比较

  **要点**：欧洲 Linux 用户组（如德国 LinuxTag 1996 年首届、法国 Solution Linux 1999 年首届）规模普遍大于 BSD 用户组，商业赞助更充裕；BSD 用户组更注重技术深度与学术传统

| 维度 | 欧洲 Linux 用户组 | 欧洲 BSD 用户组 |
| -- | --------------- | ------------- |
| 规模 | 较大 | 较小 |
| 商业赞助 | 充裕 | 有限 |
| 技术焦点 | 商业实用主义 | 技术深度与学术传统 |
| 代表会议 | 德国 LinuxTag（1996 首届）、法国 Solution Linux（1999 首届） | EuroBSDCon（2001 首届） |
