# 345.9 南亚与同时期操作系统的比较

南亚与同时期操作系统社区的对比：南亚 Linux 社区（印度 Linux 用户组 ILUG、巴基斯坦 Linux 用户组）、南亚在 IT 产业中的独特地位（外包大国）、南亚 BSD 社区的极度边缘化。

## 345.9.1 南亚 Linux 社区对比

  **要点**：南亚 Linux 社区（以印度 Linux 用户组 ILUG 为核心，1990 年代成立）规模远超 BSD 社区，ILUG 在班加罗尔、孟买、德里、钦奈等城市有活跃分会。印度 Linux 内核贡献者包括 Amit Shah（虚拟化）、Aneesh Kumar K.V.（ext4 文件系统）等。南亚 Linux 社区受益于印度 IT 产业的巨大规模
  **史料**：ILUG 记录、印度 Linux 内核贡献者列表、南亚 OS 社区对比研究〔L3 官方文档与公告/L5 二手研究〕
  **史观**：总纲第 6 条——和解优于斗争；本节引申：南亚 Linux 与 BSD 社区的分化与并行演化是社区间和平共处、各自演化的体现
  **辨析**：南亚 Linux 社区的具体规模需统计；Linux 在南亚超越 BSD 的时间节点需考据
  **文献**：ILUG Archive；印度 Linux 内核贡献者统计〔存疑：两项均为泛称，无作者、年份、题名与可核验链接，属史料缺口，待回源补全〕

## 345.9.2 印度 IT 产业与 BSD 的关系

  **要点**：印度作为全球最大的 IT 外包与服务业大国，其 IT 产业对 BSD 的采用有限，Linux 是印度 IT 产业的主流选择。印度 IT 产业的外包特性（为客户企业运行 Linux 系统）客观上限制了 BSD 在印度的采用
  **史料**：印度 IT 产业报告、印度 IT 产业操作系统采用统计、印度 IT 产业 BSD 使用分析〔L5 二手研究〕
  **史观**：总纲第 11 条——商品是形式主义；本节引申：印度 IT 产业的外包特性是形式主义市场选择对 BSD 不利的体现
  **辨析**：印度 IT 产业 BSD 采用的具体比例需统计；外包业务对 BSD 采用的影响需分析
  **文献**：印度 IT 产业报告；印度 IT 产业操作系统采用统计〔存疑：两项均为泛称，无作者、年份、题名与可核验链接，属史料缺口，待回源补全〕

## 345.9.3 南亚 BSD 社区的极度边缘化辨析

  **要点**：南亚 BSD 社区在全球 BSD 社区中处于边缘地位——南亚 BSD 贡献者人数远低于其人口与 IT 产业规模的比例，南亚 BSD 用户在英文 BSD 社区中的可见度极低，南亚在 BSD 历史叙事中几乎缺席
  **史料**：全球 BSD 社区地理分布统计、南亚 BSD 用户可见度分析、BSD 历史叙事中的南亚缺席；bsd_commits.duckdb 查询显示：统计结论 [C-01] 23 仓库总 commit 数 8,404,839 与统计结论 [C-02] 23 仓库总贡献者数 60,198 共同构成全球 BSD 社区的量化规模基础，南亚 BSD 贡献者（.in TLD 仅 625 commit / 59 贡献者，见 157.3.1 节）占全球 60,198 贡献者的比例不足 0.1%，反映南亚在 BSD 全球社区中的极度边缘化（详见 `原材料/研究/bsd仓库分析/数据分析/宏观趋势统计.md` §C-01/C-02）〔L1 代码/构建产物/L5 二手研究〕
  **史观**：总纲第 8 条——本体论上各方平等；本节引申：南亚 BSD 社区的边缘化是人口大国在 BSD 全球社区中极度代表性不足的典型案例；统计结论 [C-01] 23 仓库总 commit 8,404,839 与统计结论 [C-02] 总贡献者 60,198 反映全球 BSD 社区的量化规模，南亚贡献者占比不足 0.1% 印证这一判断（Granger 因果检验 [C-37]、三库 Spearman 分析 [C-53] 等与南亚对比主题无关的统计项已移出，详见 `时间序列分析.md` Task 16、`跨数据库关联分析.md` Task 27）
  **辨析**：南亚 BSD 社区边缘化的原因需系统分析（英语障碍、IT 产业外包特性、Linux 主导等）；边缘化是否为结构性特征需评估；【0 信任原则·总 commit 数含 GitHub 镜像】统计结论 [C-01] 8,404,839 commits 含 GitHub 镜像 commit，镜像 commit 可能滞后于主仓，实际主仓 commit 数可能小于该总数；【0 信任原则·贡献者数含重复】统计结论 [C-02] 60,198 贡献者基于 author_email 去重，但同一人可能使用多个邮箱导致多人计数，实际独立贡献者数可能小于该总数；【统计显著 ≠ 实际显著】南亚贡献者占比不足 0.1% 不直接等同于 “南亚 BSD 社区无贡献”，须结合贡献质量（关键子系统维护、文档翻译、社区组织）综合判断
  **文献**：全球 BSD 社区地理分布统计；南亚 BSD 用户可见度分析；bsd_commits.duckdb 查询（23 仓库总 commit 8,404,839、总贡献者 60,198），见 `原材料/研究/bsd仓库分析/数据分析/宏观趋势统计.md` §C-01/C-02〔存疑：前两项均为泛称，无作者、年份、题名与可核验链接，属史料缺口，待回源补全〕

### 史观映射

> 南亚 BSD 社区的历史是一部在人口大国中的极度边缘化史——印度 14 亿人口、全球最大的 IT 外包产业，但在 BSD 全球社区中几乎缺席。IIT 的 BSD 教育传统、印度 ISP 的早期 FreeBSD 采用、Deb Goodkin（德布·古德金） 在 FreeBSD Foundation 的领导——这些微弱的火种在南亚的 Linux 主导、多语言障碍、IT 人才外流中艰难延续。南亚 BSD 社区的极度边缘化是全球 BSD 社区中心化结构的极端体现：南亚在 BSD 全球贡献者中的代表性严重不足，英语中心主义对南亚多语言用户构成独特障碍，海外南亚裔 BSD 贡献者的光芒遮蔽了南亚本土 BSD 社区的困境。南亚 BSD 的 “动手者” 在班加罗尔的机房与 IIT 的教室中延续了 BSD 的传统，但他们的贡献在全球 BSD 叙事中几乎完全不可见
