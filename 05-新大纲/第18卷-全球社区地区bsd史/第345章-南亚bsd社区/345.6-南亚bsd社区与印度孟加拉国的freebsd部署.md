# 345.6 南亚 BSD 社区与 FreeBSD 部署

## 345.6.1 BSD 在印度 IIT 系统与孟加拉国 ISP 中的使用

**要点**：IIT Bombay/Kanpur 长期以 BSD 教学，孟加拉国 ISP 以 BSD 为低成本邮件系统——低许可成本在低收入国家扩展中发挥关键作用。
**史料**：IIT BSD 教学资源； 孟加拉国 ISP 技术报告 ［B］
**史观**：总纲第 15 条——教育机构在低收入国家技术扩散中的中介角色。
**辨析**：南亚 BSD 社区的核心叙事围绕“低成本扩散”展开——IIT 系统中 BSD 作为教学平台的选择与孟加拉国 ISP 以 BSD 为低成本邮件系统的实践，共同构成了 BSD 在低收入国家技术扩散的典型案例。然而，这两个案例都面临验证难题：IIT 的 BSD 教学使用缺乏公开的课程大纲或教学材料记录；孟加拉国 ISP 的 BSD 部署因商业保密而无法获取第一手数据。南亚 BSD 社区与印度自由软件运动（FSF India）之间存在微妙张力——FSF India 以 GNU/Linux 为推广重心，BSD 许可证的“过度自由”在南亚开源语境中常被误解为“缺乏社区保护”。AsiaBSDCon 的印度参与者数量有限，南亚 BSD 研究者更多依赖远程参与而非本地活动。
**文献**：IIT 教学； ISP 报告 ［B］
