# 345.2 印度 BSD 社区与用户组

122.2 **印度 BSD 社区与用户组**———印度 BSD 社区与用户组包括 Bangalore BSD Users Group（印度硅谷班加罗尔）、Mumbai BSD Users Group、Delhi BSD Users Group 等，印度 BSD 用户组的活动以技术讲座与安装会为主

## 345.2.1 印度 BSD 用户组的形成

  **要点**：印度 BSD 用户组在 2000 年代形成，以班加罗尔（印度硅谷）、孟买、德里、海德拉巴、钦奈等 IT 中心为主要聚集地。Bangalore BSD Users Group（BBUG）是印度最大的 BSD 用户组，受益于班加罗尔作为印度 IT 产业中心的地位
  **史料**：印度 BSD 用户组活动记录、BBUG 邮件列表、印度 BSD 用户组在线社区 ［A］
  **史观**：总纲第 22 条——印度 BSD 用户组是 BSD 在南亚本土化的组织载体
  **辨析**：各用户组的确切成立日期需考据；不同城市用户组的活跃度对比需分析
  **文献**：BBUG 邮件列表 Archive；印度 BSD 用户组活动记录 ［A］

## 345.2.2 印度 BSD 用户组的活动形式

  **要点**：印度 BSD 用户组的活动以技术讲座（Tech Talks）、BSD 安装会（Install Fest）、黑客松（Hackathon）为主，活动频率低于欧美 BSD 用户组。印度 BSD 用户组与印度 Linux 用户组（ILUG）有交叉参与，部分 BSD 用户同时活跃于 Linux 社区
  **史料**：印度 BSD 用户组活动照片与记录、印度 BSD 技术讲座议程、印度 BSD 用户组博客 ［C］
  **史观**：总纲第 22 条——印度 BSD 用户组的活动形式反映了 BSD 在南亚的务实与低姿态
  **辨析**：活动频率的具体数据需统计；与 ILUG 的交叉参与程度需分析

## 345.2.3 印度 BSD 社区参与亚洲 BSD 会议

  **要点**：印度 BSD 社区在 AsiaBSDCon（2007 年起）中有少量参与，印度 BSD 贡献者（如 FreeBSD 文档贡献者）在 AsiaBSDCon 发表过演讲。印度 BSD 社区的参会人数在亚洲 BSD 社区中较少，远低于日本、韩国
