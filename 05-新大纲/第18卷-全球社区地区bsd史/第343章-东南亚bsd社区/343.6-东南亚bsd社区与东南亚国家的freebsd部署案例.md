# 343.6 东南亚 BSD 社区与 FreeBSD 部署案例

## 343.6.1 东南亚数据中心 BSD 部署

**要点**：马来西亚、新加坡多家 VPS 提供商提供 FreeBSD 默认选项。印尼 ID-BSD 小但活跃，定期在雅加达/万隆举办 meetup。
**史料**：东南亜 VPS 提供商统计； ID-BSD 活动记录 ［B］
**史观**：总纲第 15 条——商业生态影响开源选择。
**辨析**：东南亚 BSD 社区呈现“商业驱动”的独特模式——马来西亚、新加坡的 VPS 提供商以 FreeBSD 为默认选项更多是出于商业效率（低许可成本、高稳定性）而非社区信仰。印尼 ID-BSD 是东南亚少有的由社区自发组织的 BSD 用户组，但其规模与 FreeBSD 在 VPS 市场的份额不成比例——大量 BSD 用户是“静默消费者”而非“社区参与者”。东南亚 BSD 与亚洲 BSD 大会（AsiaBSDCon）的关系值得关注：AsiaBSDCon 在日本举办，东南亚参与者的能见度低于日本、韩国、台湾的参与者。VPS 提供商统计中 FreeBSD 的份额需要与 Linux 份额对照解读——FreeBSD 在东南亚 VPS 市场的份额为个位数百分比，远低于 Linux。
**文献**：VPS 统计； ID-BSD 记录 ［B］
