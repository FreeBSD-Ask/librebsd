# 336.14 南美社区内部矛盾与排外——巴西 BSD 社区（FUG-BR）与西班牙语社区（阿根廷、智利、哥伦比亚等）的语言隔阂——葡萄牙语与西班牙语社区形成相对独立的邮件列表、IRC 频道与论坛，跨语言协作稀少

## 336.14.1 葡语与西语社区的语言隔阂

  **要点**：葡语与西语 BSD 社区因语言差异形成相对独立的邮件列表、IRC 频道与论坛，跨语言协作稀少；语言隔阂反映了南美语言文化的多样性；具体隔阂须经邮件列表与社区档案核查
  **史料**：FUG-BR 与西语 BSD 用户组邮件列表存档、IRC 频道日志 ［A］
  **史观**：边缘者的贡献被中心叙事遮蔽，语言隔阂叙事须警惕地域偏见
  **辨析**：语言隔阂的描述须以原始档案为准，避免事后叙事的夸大；“协作稀少” 的量化标准须明确
  **文献**：FUG-BR 邮件列表存档；西语 BSD 用户组邮件列表存档；IRC 频道日志 ［A］

## 336.14.2 社区排外现象的演变与效应

  **要点**：社区排外现象演变分三阶段——1990 年代的隐性期、2000-2010 年的显性期、2011 年后的固化期；影响包括跨语言协作减少、社区资源分散、整体影响力下降
  **史料**：FUG-BR 与西语 BSD 用户组邮件列表活跃度统计、跨语言协作事件记录 ［A］
  **史观**：技术路线的分化与并行演化，语言隔阂塑造社区排外的演化路径
  **辨析**：三阶段划分须经量化数据核查；2011 年后的固化是否单纯因语言隔阂需辨析
  **文献**：FUG-BR 与西语 BSD 用户组邮件列表；跨语言协作事件档案 ［A］

## 336.14.3 南美与中东社区排外比较

  **要点**：南美与中东社区排外存在差异；中东社区因语言（阿拉伯语、希伯来语、波斯语）与政治（以巴冲突）而排外更严重；南美社区因语言（葡语、西语）相近而排外较轻；比较须警惕 “中东更排外” 的预设偏差
  **史料**：南美与中东 BSD 社区档案、邮件列表 ［A］
  **史观**：边缘者的贡献被中心叙事遮蔽，社区排外比较须结合地域政治语境
  **辨析**：排外的比较标准须明确；“严重” 的判定须考据
  **文献**：南美与中东 BSD 社区档案；freebsd-hackers 邮件列表 ［A］
