# 336.11 南美 BSD 商标与版权实践——FreeBSD 商标在南美各国的注册情况、南美开源社区对 BSD Daemon 版权的处理、南美 BSD 衍生产品的商标问题

## 336.11.1 FreeBSD 商标在南美的注册情况

  **要点**：FreeBSD 商标在南美各国（巴西、阿根廷、智利、哥伦比亚等）的注册情况须经各国商标注册数据库核查；BSD Daemon 图像的版权由 Marshall Kirk McKusick（马歇尔·柯克·麦库西克） 持有，南美开源社区在衍生产品中使用须经授权；南美 BSD 衍生产品的商标使用须考据
  **史料**：巴西专利商标局（INPI）商标数据库、阿根廷商标数据库、智利商标数据库 ［A］
  **史观**：法律结构对技术创新的制约与解放，商标与版权的法律框架塑造 BSD 衍生产品的商业化路径
  **辨析**：商标注册号与注册日期须经原始数据库核查；BSD Daemon 图像授权的具体条款须查原始授权书
  **文献**：巴西 INPI 商标检索；阿根廷商标检索；智利商标检索 ［A］

## 336.11.2 BSD Daemon 版权处理实践演变

  **要点**：BSD Daemon 版权处理实践演变分两阶段——2000 年前的宽松期（社区对版权关注较少）、2001 年后的规范化期（FreeBSD Foundation 商标政策推动合规化）；演变与 FreeBSD Foundation 2003 年后商标集中管理同步
  **史料**：FreeBSD Foundation 商标政策文件、南美 BSD 衍生产品历史档案 ［A］
  **史观**：技术路线的分化与并行演化，南美版权实践节奏与 FreeBSD Foundation 政策节奏不同步
  **辨析**：2001 年的节点划分须经 FreeBSD Foundation 商标注册时间核查；南美各国演变节奏不同步须分别分析
  **文献**：FreeBSD Foundation 商标政策档案；美国专利商标局 FreeBSD 商标注册记录；南美各国商标数据库 ［A］

## 336.11.3 南美与北美商标实践比较

  **要点**：北美 BSD 商标实践受 FreeBSD Foundation 2003 年后商标政策影响；南美商标实践因法律传统不同而与国际接轨程度不同；比较须警惕 “北美更合规” 的预设偏差
  **史料**：美国专利商标局、南美各国商标数据库 ［A］
  **史观**：法律结构对技术创新的制约与解放，不同法律传统塑造差异化的商标实践
  **辨析**：“与国际接轨” 的判定标准须明确；商标实践的特殊性须客观分析
  **文献**：美国专利商标局；南美各国商标数据库 ［A］

## 336.11.4 南美商标史料辨析

  **要点**：商标档案的史料来源包括官方商标数据库、企业档案、社区记录；南美商标数据库保存较为完整，但早期（1990 年代）部分档案未数字化；社区记录中的商标使用情况须与官方档案交叉验证
  **史料**：南美官方商标数据库、企业档案、社区论坛与邮件列表 ［A］
  **史观**：终结中的延续，商标档案的系统化保存是 BSD 商业化史研究的基础
  **辨析**：商标注册号与实际使用情况的对应关系须考据；社区记录中的商标使用是否经授权须辨析
  **文献**：南美官方商标数据库；FreeBSD Foundation 商标授权档案；社区论坛历史存档 ［A］
