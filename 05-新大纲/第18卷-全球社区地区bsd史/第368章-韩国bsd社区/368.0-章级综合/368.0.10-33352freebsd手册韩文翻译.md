# 368.0.10 333.5.2 FreeBSD 手册韩文翻译

- 要点：FreeBSD 手册（FreeBSD Handbook）的韩文翻译由韩国 BSD 社区志愿者完成，翻译进度与质量受限于韩国 BSD 社区规模。韩文翻译版本在 2000 年代中期起步，但完整度不及日文翻译版本。
- 史料：FreeBSD 手册韩文翻译项目记录、韩国 BSD 社区翻译讨论、翻译项目页面 ［A］
- 史观：总纲第 15 条——文化即形式主义，韩文 BSD 出版物是 BSD 文化在韩国形式主义化的重要载体，韩文翻译的进度滞后亦反映韩国 BSD 社区的规模限制
- 辨析：各书籍的具体出版日期需考据；韩文翻译的准确性需评估；韩文翻译的完成度需评估；与日文翻译版本的对比需分析
