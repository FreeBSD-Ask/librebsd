# 368.0.7 333.2.2 韩国 BSD 社区参与 AsiaBSDCon

- 要点：韩国 BSD 社区自 2007 年 AsiaBSDCon 首届起即参与，韩国 BSD 贡献者（如 Hye-Shik Chang、Jung-uk Kim 等）在 AsiaBSDCon 发表论文与演讲。韩国 BSD 社区的参会者人数在亚洲 BSD 社区中仅次于日本。
- 辨析：韩国 committer 的具体人数需统计；各 BSD 项目中的分布比例需分析；【0 信任原则·地理识别局限】author_email TLD 不等于实际地理位置，.kr 邮箱未单独统计意味着韩国贡献者数量被低估，且 +09:00 时区同时覆盖日本与韩国，时区偏移不等于居住地，远程办公、VPN、移民等因素使时区—地理位置映射须慎重；【0 信任原则·committer_date 异常】L3.3.1（committer_date 时区偏移分布前 30，22 仓库合计，30 行结果）显示 +09:00 与日本共用时区桶，38,272 commit / 3,046 贡献者无法单独区分韩国贡献者；L3.3.2（author_email 域名 TLD 分布，22 仓库合计，16 行结果）显示 .kr 域未单独列出、归入 other 类（other 类合计 1,277,384 commit / 4,252 uniq）
- 文献：FreeBSD Committers List；committer 个人主页 ［A］；openbsd.duckdb 查询 L3.3.1、L3.3.2，见 `原材料/研究/bsd仓库分析/数据分析/深层信息挖掘.md` §L3.3.1、§L3.3.2
