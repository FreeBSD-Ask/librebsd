# 368.0.2 要点

- 韩国互联网的早期发展（1990 年代）与 FreeBSD 密切相关，韩国最早一批 ISP（如 KORNET、BORANET、Dacom）在 1990 年代中期使用 FreeBSD 作为 Web 服务器与邮件服务器。韩国互联网的快速普及（1990 年代末宽带普及率全球领先）推动了 FreeBSD 在韩国服务器市场的早期采用。
- KAIST（韩国科学技术院）、首尔大学、浦项工科大学（POSTECH）、延世大学、高丽大学等高校在 1990 年代开设 UNIX/BSD 相关课程，KAIST 的系统架构实验室（System Architecture Lab）在 BSD 内核研究方面做出了贡献。韩国高校的 BSD 课程培养了一批后续成为 FreeBSD/NetBSD committer 的韩国工程师。
- 韩国 BSD 用户组（Korea BSD Users Group，한국 BSD 사용자 그룹）1990 年代末成立，早期通过 Daum Cafe、Naver Cafe 等韩国在线社区平台组织活动，邮件列表（freebsd-users-kr）与 IRC 频道（#freebsd-kr）是主要交流渠道。韩国 BSD 用户组与日本 BSD 用户组（JBUG）有频繁交流。
- 韩国 BSD 早期部署记录与高校档案是评估韩国 BSD 社区起源的关键史料，需交叉验证 ISP 技术文档与高校课程记录
- 韩国 BSD 用户组从 1990 年代末的在线社区（Daum Cafe）逐步演变为线下定期聚会，2000 年代后在首尔（江南区、弘大区域）、大田（KAIST 周边）、大邱等地举办 BSD 安装会与研讨会。韩国 BSD 用户组与 Linux 社区（Korea Linux Forum）有交叉参与。
