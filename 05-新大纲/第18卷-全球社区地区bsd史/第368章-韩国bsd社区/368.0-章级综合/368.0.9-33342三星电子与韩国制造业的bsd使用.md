# 368.0.9 333.4.2 三星电子与韩国制造业的 BSD 使用

- 要点：三星电子（Samsung Electronics）在部分嵌入式系统与网络设备中使用 BSD 衍生系统，三星的 Tizen 操作系统虽以内核 Linux 为主体，但部分子系统参考了 BSD 实现。韩国其他制造业企业（如 LG 电子、现代汽车）在嵌入式系统中也存在 BSD 使用案例。
