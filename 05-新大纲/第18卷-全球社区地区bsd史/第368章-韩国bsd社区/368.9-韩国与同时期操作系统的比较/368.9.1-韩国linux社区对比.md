# 368.9.1 韩国 Linux 社区对比

  **要点**：韩国 Linux 社区以 2012 年 10 月首次举办的 Korea Linux Forum（Linux Foundation 主办、三星赞助，首尔 JW Marriott）为标志走向组织化，1990 年代已有零散用户团体〔存疑：1990 年代韩国 Linux 用户团体成立年份与规模待核〕；韩国 Linux 内核贡献者包括 Byungchul Park（LGE，lockdep crossrelease 与 DEPT 依赖跟踪器）、Jaegeuk Kim（三星，F2FS 文件系统创始人）等。韩国 Linux 社区在 2000 年代后规模远超 BSD 社区〔存疑：两国社区规模对比的量化口径待核〕，韩国政府部门与大型企业的开源采用以 Linux 为绝对主体〔存疑：韩国政府开源采用比例无一手出处，待补〕
  **史料**：Korea Linux Forum 2012 官方公告（linuxfoundation.org）、LWN 2012-10 报道（https://lwn.net/Articles/519919）、F2FS 内核补丁集（lore.kernel.org，2012-10）〔考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准〕〔L3 官方文档与公告/L5 二手研究〕
  **史观**：总纲第 6 条——韩国 Linux 与 BSD 社区的分化与并行演化
  **辨析**：韩国 Linux 社区的具体规模对比属待核考点，尚无统一口径；Linux 在韩国超越 BSD 的时间节点需考据〔存疑〕
