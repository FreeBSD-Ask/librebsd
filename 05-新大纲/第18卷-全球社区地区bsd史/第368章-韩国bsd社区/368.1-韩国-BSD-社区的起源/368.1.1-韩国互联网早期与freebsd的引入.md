# 368.1.1 韩国互联网早期与 FreeBSD 的引入


109.1 **韩国 BSD 社区的起源**———1990 年代韩国互联网早期 FreeBSD 在 ISP 与大学服务器中普及，KAIST（韩国科学技术院）、首尔大学、浦项工科大学（POSTECH）等高校成为 BSD 人才孵化基地，韩国 BSD 用户组 1990 年代末成立

  **要点**：韩国互联网的早期发展（1990 年代）与 FreeBSD 密切相关，韩国最早一批 ISP（如 KORNET、BORANET、Dacom）在 1990 年代中期使用 FreeBSD 作为 Web 服务器与邮件服务器。韩国互联网的快速普及（1990 年代末宽带普及率全球领先）推动了 FreeBSD 在韩国服务器市场的早期采用。
