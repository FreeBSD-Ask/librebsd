# 366.5.1 台湾 BSD 社区的起源

  **要点**：台湾 BSD 社区起源于 1990 年代，与台湾早期互联网发展同步；台湾大学、交通大学等高校是 BSD 早期采用与教学的重要基地；繁体中文 BSD 文档翻译项目起步较早
  **史料**：台湾 BSD 用户组档案、高校课程记录、繁体中文翻译项目存档 ［A］
  **史观**：边缘者的贡献被中心叙事遮蔽，台湾 BSD 社区的贡献在英语中心叙事中被忽略
  **辨析**：台湾 BSD 社区的确切起源时间须考据；早期高校 BSD 教学的具体情况须查档案
  **文献**：台湾 BSD 用户组档案；高校课程记录；繁体中文翻译项目存档 ［A］
