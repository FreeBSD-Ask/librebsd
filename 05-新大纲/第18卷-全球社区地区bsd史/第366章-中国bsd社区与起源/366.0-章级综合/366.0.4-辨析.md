# 366.0.4 辨析

- CFC（Chinese FreeBSD Collection）的技术内容与定位须考据：历史上有多個不同团体曾使用“CFC”之名，须逐一辨析其各自成立时间、核心人物、活动范围与消亡原因，不能将不同团体混为一谈
- FreeBSD China 2003 年创建时间须查网站快照；“最主要”地位的判定需评估
- committer 权限演变的具体时间节点须考据；自动退休名单的完整性需评估
- 各高校的 BSD 课程与社团须分别考据；镜像站的具体情况需查档案
- 中国台湾 BSD 用户组活动的具体时间与规模须考据；与日本社区的交流深度需评估
- 思科诉华为案双方叙事对立、中立方专家报告全文未公开，须以 0 信任原则表述考据结论（详见 331.10 辨析）
