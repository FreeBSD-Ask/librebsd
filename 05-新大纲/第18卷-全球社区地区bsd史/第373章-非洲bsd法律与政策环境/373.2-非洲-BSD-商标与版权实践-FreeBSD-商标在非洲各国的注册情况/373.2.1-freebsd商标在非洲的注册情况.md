# 373.2.1 FreeBSD 商标在非洲的注册情况

  **要点**：FreeBSD 商标在非洲各国的注册情况参差不齐，主要在南非、埃及等经济较发达国家注册；非洲开源社区对 BSD Daemon 版权的处理遵循 FreeBSD Foundation 的商标政策；具体注册情况须通过各国商标局档案核查
  **史料**：非洲各国商标局档案、FreeBSD Foundation 商标政策文件、非洲开源社区商标处理记录 ［A］
  **史观**：法律结构对技术创新的制约与解放，商标注册的差异反映非洲各国法律体系的差异
  **辨析**：FreeBSD 商标在非洲各国的注册情况须通过各国商标局原始档案核查；“参差不齐” 的判断须量化
  **文献**：非洲各国商标局档案；FreeBSD Foundation 商标政策文件；非洲开源社区商标处理记录 ［A］
