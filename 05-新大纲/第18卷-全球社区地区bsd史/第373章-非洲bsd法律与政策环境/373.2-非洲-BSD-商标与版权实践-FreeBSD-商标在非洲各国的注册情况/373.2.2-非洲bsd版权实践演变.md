# 373.2.2 非洲 BSD 版权实践演变

  **要点**：1990 年代至 2010 年代非洲 BSD 版权实践逐步规范化，主要受 FreeBSD Foundation 商标政策与各国版权法影响；非洲 BSD 衍生产品的商标问题较少，主要因衍生产品规模小；演变须通过商标注册统计验证
  **史料**：非洲各国商标注册统计、FreeBSD Foundation 商标政策演变、非洲 BSD 衍生产品档案 ［A］
  **史观**：法律结构对技术创新的制约与解放，版权实践的演变反映法律框架的渐进完善
  **辨析**：“规范化” 的判断须具体化——各国进度差异显著；衍生产品 “规模小” 的判断须量化
  **文献**：非洲各国商标注册统计；FreeBSD Foundation 商标政策档案；非洲 BSD 衍生产品档案 ［A］
