# 373.8.3 非洲与南美公众认知比较

  **要点**：南美公众对 BSD 的认知较非洲相对准确，主要因南美有更长的 UNIX 传统与更完善的技术教育；非洲公众认知的偏差与非洲 UNIX 传统的薄弱直接相关；比较须控制教育体系与媒体生态变量
  **史料**：非洲与南美技术媒体对 BSD 的报道、非洲与南美技术教育课程对比 ［C］
  **史观**：边缘者的贡献被中心叙事遮蔽，非洲公众认知的偏差是 BSD 全球叙事边缘化的体现
  **辨析**：南美 “相对准确” 的判断须具体化——南美各国公众认知差异显著；非洲 “UNIX 传统薄弱” 的判断须通过大学课程与产业历史验证
  **文献**：非洲与南美技术媒体存档；非洲与南美大学计算机科学课程档案 ［A］
