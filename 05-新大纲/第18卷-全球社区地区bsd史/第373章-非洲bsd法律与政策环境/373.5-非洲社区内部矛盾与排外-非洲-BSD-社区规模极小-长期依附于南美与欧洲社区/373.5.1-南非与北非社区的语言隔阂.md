# 373.5.1 南非与北非社区的语言隔阂

  **要点**：非洲 BSD 社区内部存在南非（英语/阿非利卡语）与北非（阿拉伯语/法语）的语言隔阂；语言隔阂导致社区协作困难，长期依附不同外部社区——南非依附欧洲，北非依附中东与法国；隔阂的具体表现须通过社区档案与邮件列表核查
  **史料**：ZA FreeBSD User Group 邮件列表、北非 BSD 社区档案、非洲语言分布数据 ［A］
  **史观**：组织结构对技术路径的塑造，语言隔阂反映非洲社区组织的结构性限制
  **辨析**：语言隔阂的具体表现须量化——邮件列表语言分布；“依附不同外部社区” 的判断须通过合作项目分析
  **文献**：ZA FreeBSD User Group 邮件列表存档；北非 BSD 社区档案；非洲语言分布数据 ［A］
