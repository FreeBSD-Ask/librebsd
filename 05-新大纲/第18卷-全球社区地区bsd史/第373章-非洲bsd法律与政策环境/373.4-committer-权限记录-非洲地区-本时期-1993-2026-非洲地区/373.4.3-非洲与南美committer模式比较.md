# 373.4.3 非洲与南美 committer 模式比较

  **要点**：南美 committer 数量与活跃度略高于非洲，主要因南美有更完善的 BSD 社区组织与产业基础；非洲 committer 多来自南非，南美 committer 多来自巴西；比较须控制社区组织与产业基础变量
  **史料**：非洲与南美 FreeBSD committer 统计、非洲与南美 BSD 社区组织对比、FreeBSD commit 历史 ［A］
  **史观**：边缘者的贡献被中心叙事遮蔽，非洲 committer 模式的依附性反映 BSD 全球叙事不平等
  **辨析**：南美 “略高” 的判断须量化——committer 数量、commit 次数；committer 来源的分布须通过 commit 历史分析
  **文献**：非洲与南美 FreeBSD committer 统计；非洲与南美 BSD 社区组织对比研究；FreeBSD commit 历史档案 ［A］
