# 373.0.4 概述导言

> 本子章由原第 337 章拆分而来（chapter_reviews 映射：旧章号 +1 → 现行章号，旧 337.9-337.13 即现行 338.9-338.19 区段前身），承载 338.9-338.19 节。

### 核心内容

本章考察 1993-2026 年非洲各法域与 BSD 相关的法律、开源政策与数据保护环境，与第372章（非洲 BSD 社区起步：南非技术社区、ISP 与金融业的 BSD 部署）的分工在于——337 章侧重社区与部署的历史演进，本章侧重约束与塑造这些活动的法律、政策与制度环境。全章由 338.9-338.19 共 11 节构成：338.9-338.12 为法律与制度层面（非洲 BSD 相关法律与开源政策——南非版权法、POPIA、埃及知识产权法、尼日利亚版权法、肯尼亚 Data Protection Act 2019；商标与版权实践；捐赠与筹款记录；committer 权限记录）；338.13-338.15 为社区与政企层面（社区内部矛盾与排外、政府企业与 BSD 项目的内部张力、社区当代活动与数字基础设施）；338.16-338.19 为认知与比较层面（公众的认识、外部批评与反对者、重要贡献者与边缘者、非洲地区 OS 比较）。各节分布详见下节索引。
