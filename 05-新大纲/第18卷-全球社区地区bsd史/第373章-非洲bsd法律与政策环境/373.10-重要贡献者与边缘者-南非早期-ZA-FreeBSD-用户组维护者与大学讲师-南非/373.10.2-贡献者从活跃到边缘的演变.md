# 373.10.2 贡献者从活跃到边缘的演变

  **要点**：非洲 BSD 贡献者多从学生时代活跃，毕业后因就业压力与人才外流转向其他领域；ZA FreeBSD User Group 活跃度在 2000 年代中期达峰后下滑；演变须通过邮件列表活跃度统计验证
  **史料**：ZA FreeBSD User Group 邮件列表活跃度统计、贡献者个人访谈、非洲 IT 就业市场数据 ［A］
  **史观**：边缘者的贡献被中心叙事遮蔽，贡献者的边缘化反映 BSD 在非洲产业中的弱势
  **辨析**：贡献者边缘化的原因须具体分析——就业压力、人才外流、社区内部矛盾等；“活跃度下滑” 须量化
  **文献**：ZA FreeBSD User Group 邮件列表存档；贡献者访谈；非洲 IT 就业市场报告 ［A］
