# 375.3.3 中东与非洲捐赠模式比较

  **要点**：中东企业对 FreeBSD Foundation 的捐赠规模与频次略高于非洲，主要因中东有更完善的 BSD 社区组织与产业基础；非洲捐赠多来自南非，中东捐赠多来自以色列与海湾国家；比较须控制经济发展水平与社区组织变量
