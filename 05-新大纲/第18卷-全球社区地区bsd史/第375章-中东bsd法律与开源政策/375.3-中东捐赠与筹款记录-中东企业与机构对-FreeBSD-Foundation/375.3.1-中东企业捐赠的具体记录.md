# 375.3.1 中东企业捐赠的具体记录

  **要点**：中东企业与机构对 FreeBSD Foundation 的捐赠记录较少，主要来自以色列 Check Point 等安全公司与海湾电信公司；以色列海湾国家合作背景下对开源的共同投资有限；捐赠的具体金额与时间须通过 FreeBSD Foundation 年度报告与企业档案核查
  **史料**：FreeBSD Foundation 年度报告、Check Point 企业档案、海湾电信公司档案、以色列海湾国家合作文件 ［B］
  **史观**：企业研究投入的双重性，中东企业捐赠的稀少反映 BSD 在中东产业中的弱势
  **辨析**：捐赠的具体金额须通过 FreeBSD Foundation 原始年度报告核查；“较少”的判断须量化——与其他地区对比
  **文献**：FreeBSD Foundation 年度报告；Check Point 企业档案；海湾电信公司档案；以色列海湾国家合作文件 ［B］
