# 375.4.3 中东与俄罗斯 committer 比较

  **要点**：俄罗斯 committer 数量与活跃度显著大于中东，主要因俄罗斯有更完善的 BSD 社区组织与产业基础；中东 committer 多来自以色列，俄罗斯 committer 多来自莫斯科与圣彼得堡；比较须控制社区组织与产业基础变量
  **史料**：中东与俄罗斯 FreeBSD committer 统计、中东与俄罗斯 BSD 社区组织对比、FreeBSD commit 历史 ［A］
  **史观**：边缘者的贡献被中心叙事遮蔽，中东 committer 模式的依附性反映 BSD 全球叙事不平等
  **辨析**：俄罗斯“数量较大”的判断须量化——committer 数量、commit 次数；committer 来源的分布须通过 commit 历史分析
  **文献**：中东与俄罗斯 FreeBSD committer 统计；中东与俄罗斯 BSD 社区组织对比研究；FreeBSD commit 历史档案 ［A］
