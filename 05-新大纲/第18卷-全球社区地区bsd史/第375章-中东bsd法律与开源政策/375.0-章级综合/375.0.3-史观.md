# 375.0.3 史观

- 总纲第 13 条——法律与道德是利益分配：中东各国版权法、商标法与数据保护法对 BSD 部署的规制，反映不同法域间产业利益的分配格局（340.10）
- 总纲第 19 条——解释学循环是历史认识的根本条件：法律文本与社区史料的辨析须在文本与解释之间往复，并交代编纂者的选择（340.10、340.14）
- 总纲第 20 条——历史地理塑造思想土壤：地缘政治格局塑造中东 BSD 社区的合作与隔阂（340.14）
- 总纲第 8 条——本体论上各方平等：以色列 BSD 社区与阿拉伯语 BSD 社区在本体论上地位相等，差异是历史语境的不同而非本体等级（340.14）
- 总纲第 9 条——经验优先：法律事实以 WIPO Lex 与各国官方公报等一手文本为准，社区事实以邮件列表存档与 commit 历史等一手记录为准（340.10、340.13）
