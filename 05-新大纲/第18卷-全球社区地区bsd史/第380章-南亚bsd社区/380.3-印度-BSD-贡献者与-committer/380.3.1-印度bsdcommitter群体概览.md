# 380.3.1 印度 BSD committer 群体概览


122.3 **印度 BSD 贡献者与 committer**———印度 BSD 贡献者与 committer 包括 Deb Goodkin（FreeBSD Foundation 执行董事）、印度裔 FreeBSD committer（如部分 FreeBSD ports 维护者）、印度 NetBSD 贡献者

  **要点**：印度 BSD committer 群体涵盖 FreeBSD、NetBSD 项目，代表性人物包括 Deb Goodkin（FreeBSD Foundation 执行董事，2010 年代起任职，推动 Foundation 筹款与治理改革）、印度裔 FreeBSD committer（如部分 ports 维护者与文档贡献者）。印度 BSD committer 的人数在亚洲 BSD 社区中少于日本、韩国
  **史料**：FreeBSD committer 名单、NetBSD developer 名单、committer 个人主页 ［A］；openbsd.duckdb 查询 L3.3.2 显示：23 仓库合计 author_email 域名 TLD 分布中 .in（印度 ccTLD）仅 625 commit / 59 贡献者，远低于 .jp（6,471/205）、.cn（9,650/591）、.au（10,866/150），且 .pk（巴基斯坦）、.lk（斯里兰卡）、.np（尼泊尔）、.bd（孟加拉国）等南亚其他 ccTLD 全部归入 other 类（未单独列出），反映南亚 BSD 贡献者在 author_email 域名维度的极度稀缺
  **史观**：总纲第 10 条——印度 BSD committer 是 “动手者创造历史” 的跨国体现
  **辨析**：印度 committer 的具体人数需统计；印度裔 committer 中居住于印度本土的比例需区分；【0 信任原则·地理识别局限·author_email 域名不等于实际地理位置】L3.3.2 基于 author_email 域名 TLD 统计，.in 仅统计邮箱后缀为 .in 的贡献者，大量印度本土贡献者使用 .com（Gmail 等）、.org、.edu（IIT 等高校）邮箱，其实际地理位置无法通过 author_email 域名识别，故 .in 625/59 严重低估印度本土实际贡献者数量；【0 信任原则·海外印度裔归因局限】Deb Goodkin 等海外印度裔 BSD 贡献者使用美国 .com/.org 邮箱，其贡献被归入 .com/.org 而非 .in，无法反映印度裔整体贡献；【0 信任原则·南亚其他 ccTLD 归入 other】.pk/.lk/.np/.bd 等南亚其他 ccTLD 因贡献者数量过少被归入 other 类，无法单独统计，反映南亚 BSD 社区在 author_email 域名维度的数据严重缺失
  **文献**：FreeBSD Committers List；NetBSD Developers List ［A］；openbsd.duckdb 查询 L3.3.2（author_email 域名 TLD 分布，16 行结果），见 `原材料/研究/bsd仓库分析/数据分析/深层信息挖掘.md` §L3.3.2
