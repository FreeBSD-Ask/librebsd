# 380.9.3 南亚 BSD 社区的极度边缘化辨析

  **要点**：南亚 BSD 社区在全球 BSD 社区中处于边缘地位——南亚 BSD 贡献者人数远低于其人口与 IT 产业规模的比例，南亚 BSD 用户在英文 BSD 社区中的可见度极低，南亚在 BSD 历史叙事中几乎缺席
  **史料**：全球 BSD 社区地理分布统计、南亚 BSD 用户可见度分析、BSD 历史叙事中的南亚缺席；bsd_commits.duckdb 查询显示：统计结论 [C-01] 23 仓库总 commit 数 8,404,839 与统计结论 [C-02] 23 仓库总贡献者数 60,198 共同构成全球 BSD 社区的量化规模基础，南亚 BSD 贡献者（.in TLD 仅 625 commit / 59 贡献者，见 157.3.1 节）占全球 60,198 贡献者的比例不足 0.1%，反映南亚在 BSD 全球社区中的极度边缘化（详见 `原材料/研究/bsd仓库分析/数据分析/宏观趋势统计.md` §C-01/C-02）〔L1 代码/构建产物/L5 二手研究〕
  **史观**：总纲第 8 条——本体论上各方平等；本节引申：南亚 BSD 社区的边缘化是人口大国在 BSD 全球社区中极度代表性不足的典型案例；统计结论 [C-01] 23 仓库总 commit 8,404,839 与统计结论 [C-02] 总贡献者 60,198 反映全球 BSD 社区的量化规模，南亚贡献者占比不足 0.1% 印证这一判断（Granger 因果检验 [C-37]、三库 Spearman 分析 [C-53] 等与南亚对比主题无关的统计项已移出，详见 `时间序列分析.md` Task 16、`跨数据库关联分析.md` Task 27）
  **辨析**：南亚 BSD 社区边缘化的原因需系统分析（英语障碍、IT 产业外包特性、Linux 主导等）；边缘化是否为结构性特征需评估；【0 信任原则·总 commit 数含 GitHub 镜像】统计结论 [C-01] 8,404,839 commits 含 GitHub 镜像 commit，镜像 commit 可能滞后于主仓，实际主仓 commit 数可能小于该总数；【0 信任原则·贡献者数含重复】统计结论 [C-02] 60,198 贡献者基于 author_email 去重，但同一人可能使用多个邮箱导致多人计数，实际独立贡献者数可能小于该总数；【统计显著 ≠ 实际显著】南亚贡献者占比不足 0.1% 不直接等同于 “南亚 BSD 社区无贡献”，须结合贡献质量（关键子系统维护、文档翻译、社区组织）综合判断
  **文献**：全球 BSD 社区地理分布统计；南亚 BSD 用户可见度分析；bsd_commits.duckdb 查询（23 仓库总 commit 8,404,839、总贡献者 60,198），见 `原材料/研究/bsd仓库分析/数据分析/宏观趋势统计.md` §C-01/C-02〔存疑：前两项均为泛称，无作者、年份、题名与可核验链接，属史料缺口，待回源补全〕
