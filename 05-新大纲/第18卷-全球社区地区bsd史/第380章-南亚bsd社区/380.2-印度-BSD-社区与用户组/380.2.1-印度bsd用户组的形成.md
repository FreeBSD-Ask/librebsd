# 380.2.1 印度 BSD 用户组的形成


122.2 **印度 BSD 社区与用户组**———印度 BSD 社区与用户组包括 Bangalore BSD Users Group（印度硅谷班加罗尔）、Mumbai BSD Users Group、Delhi BSD Users Group 等，印度 BSD 用户组的活动以技术讲座与安装会为主

  **要点**：印度 BSD 用户组在 2000 年代形成，以班加罗尔（印度硅谷）、孟买、德里、海德拉巴、钦奈等 IT 中心为主要聚集地。Bangalore BSD Users Group（BBUG）是印度最大的 BSD 用户组，受益于班加罗尔作为印度 IT 产业中心的地位
  **史料**：印度 BSD 用户组活动记录、BBUG 邮件列表、印度 BSD 用户组在线社区 ［A］
  **史观**：总纲第 22 条——印度 BSD 用户组是 BSD 在南亚本土化的组织载体
  **辨析**：各用户组的确切成立日期需考据；不同城市用户组的活跃度对比需分析
  **文献**：BBUG 邮件列表 Archive；印度 BSD 用户组活动记录 ［A］
