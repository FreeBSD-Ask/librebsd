- **新闻标题（中英）**：EuroBSDCon 2026 — European BSD Conference in Brussels, Belgium / EuroBSDCon 2026——比利时布鲁塞尔欧洲 BSD 会议
- **新闻来源**：EuroBSDCon 官方 + URL `<https://eurobsdcon.org/>` 与 `<https://2026.eurobsdcon.org/about.html>`
- **新闻摘要**：EuroBSDCon 2026 将于 2026-09-09 至 2026-09-13 在比利时布鲁塞尔举办。重要日期包括 2026-03-01 征文启动（CfP opens）、2026-05-19 注册开放、2026-06-20 征文截止、2026-07-15 议程发布。组织委员会由 Kristof Provost 与 Aymeric Wibo 组成；程序委员会由 Peter N.M. Hansteen（主席，挪威）、Philipp Buehler、Tom Jones、Kristen Nielsen、Mischa Peters、Benny Siegert 组成。会议由 EuroBSDCon Foundation 主办。Paul Schenkeveld 旅行资助申请窗口为 2025-10-01 至 2026-02-01。

### 新闻条目 2

- **新闻标题（中英）**：FreeBSD: Shorter support for the professional focus / FreeBSD：缩短支持周期以聚焦专业领域
- **新闻来源**：Heise Online（德国 heise.de）英文版 + URL `<https://www.heise.de/en/news/FreeBSD-Shorter-support-for-the-professional-focus-9801104.html>` 与德文版 `<https://www.heise.de/news/FreeBSD-Kuerzerer-Support-fuer-den-Profi-Fokus-9801075.html>`
- **新闻摘要**：Heise Online 报道 FreeBSD 项目自 FreeBSD 15 起调整支持周期。FreeBSD 13 支持将于 2025-03 随 13.5 版本结束；FreeBSD 14 支持将于 2027-03 随 14.6 版本结束；FreeBSD 15 支持将于 2029-03 随 15.6 版本结束。自 FreeBSD 15 起仅提供四年支持，但承诺更频繁的更新。多个项目团队表示需要减轻维护负担以聚焦专业领域。
- **与本章主题的关联说明**：这是德国科技媒体对 FreeBSD 支持周期调整的报道，是本章 “I 类德国地区媒体” 与 “FreeBSD 项目治理与发布策略” 小节的关键一手史料，反映欧洲科技媒体对 FreeBSD 项目治理的持续关注。
- **与官方史料的交叉验证结论**：`heise.de` 为 Heise 集团官方域名；支持周期时间表（13.5 → 2025-03、14.6 → 2027-03、15.6 → 2029-03）须与 FreeBSD 官方发布工程页面 `freebsd.org/releases` 与 FreeBSD Foundation 状态报告核验。

### 新闻条目 3

- **新闻标题（中英）**：FreeBSD entwickelt Systemd-Alternative / FreeBSD 开发 systemd 替代方案
- **新闻来源**：Pro-Linux.de（德国）+ URL `<https://www.pro-linux.de/news/1/22898/freebsd-entwickelt-systemd-alternative.html>`
- **新闻摘要**：Pro-Linux.de 报道 FreeBSD 各团队正在实现 Linux 中已存在多年的功能，部分采纳 Linux 代码、部分走自有路线。报道指出 FreeBSD 同时也在独立创新，并非简单跟随 Linux。这一报道反映了欧洲德语区开源社区对 FreeBSD 与 Linux 系统服务架构差异的持续关注。
- **与本章主题的关联说明**：这是德国开源媒体 Pro-Linux.de 对 FreeBSD 系统服务架构的报道，是本章 “I 类德国地区媒体” 与 “欧洲开源社区对 BSD 与 Linux 比较的舆论” 小节的辅助一手史料，反映德语区开源社区对 BSD 哲学的讨论。
- **与官方史料的交叉验证结论**：`pro-linux.de` 为德国开源媒体官方域名；报道所述 FreeBSD 系统服务实现细节须与 FreeBSD 官方源码仓库 `cgit.freebsd.org` 与 FreeBSD 邮件列表存档核验 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］。
