# 380.7.1 印度小型 ISP 系统管理员


122.7 **重要贡献者与边缘者：被忽视的南亚 BSD 社区维护者**———南亚 BSD 社区中被忽视的维护者包括印度小型 ISP 系统管理员、巴基斯坦与孟加拉国的 BSD 教师、通过印度 BSD 社区匿名贡献的南亚 BSD 用户
