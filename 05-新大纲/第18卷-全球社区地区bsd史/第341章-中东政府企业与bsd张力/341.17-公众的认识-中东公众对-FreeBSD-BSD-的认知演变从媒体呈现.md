## 341.17.2 公众认知从空白到偏见的演变

  **要点**：1990 年代中东公众对 BSD 普遍空白，将其与 Linux 混淆；2000 年代后随 Linux 在中东主流化，BSD 被部分公众视为“过时的西方技术”；演变须通过历届中东技术会议公众调查与媒体报道分析
  **史料**：中东技术会议公众调查、中东技术媒体报道、BSD 与 Linux 用户论坛讨论 ［C］
  **史观**：技术路线的分化与并行演化，公众认知的演变反映 Linux 在中东的主流化
  **辨析**：“空白”与“偏见”的判断标准须明确；Linux 主流化对 BSD 公众认知的影响须量化
  **文献**：中东技术会议公众调查档案；中东技术媒体存档；BSD 与 Linux 用户论坛历史讨论 ［A］

## 341.17.3 中东与非洲公众认知比较

  **要点**：中东公众对 BSD 的认知较非洲相对准确，主要因中东有更长的 UNIX 传统（以色列 Check Point 等）与更完善的技术教育；非洲公众认知的偏差与非洲 UNIX 传统的薄弱直接相关；比较须控制教育体系与媒体生态变量
  **史料**：中东与非洲技术媒体对 BSD 的报道、中东与非洲技术教育课程对比 ［C］
  **史观**：边缘者的贡献被中心叙事遮蔽，中东与非洲公众认知的差异反映两地 UNIX 传统的不同
  **辨析**：中东“相对准确”的判断须具体化——中东各国公众认知差异显著；非洲“UNIX 传统薄弱”的判断须通过大学课程与产业历史验证
  **文献**：中东与非洲技术媒体存档；中东与非洲大学计算机科学课程档案 ［A］
