# 376.5.2 贡献者从活跃到边缘的演变

  **要点**：中东 BSD 贡献者多从学生时代或工程师生涯活跃，后因就业压力、地缘政治限制、人才外流等转向其他领域；Israel FreeBSD User Group 活跃度在 2000 年代中期达峰后下滑；演变须通过邮件列表活跃度统计验证
  **史料**：Israel FreeBSD User Group 邮件列表活跃度统计、贡献者个人访谈、中东 IT 就业市场数据 ［A］
  **史观**：边缘者的贡献被中心叙事遮蔽，贡献者的边缘化反映 BSD 在中东产业中的弱势
  **辨析**：贡献者边缘化的原因须具体分析——就业压力、地缘政治限制、人才外流等；“活跃度下滑”须量化
  **文献**：Israel FreeBSD User Group 邮件列表存档；贡献者访谈；中东 IT 就业市场报告 ［A］
