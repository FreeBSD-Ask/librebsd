# 376.3.1 Geektime/Webrazzi 等媒体对 BSD 的报道

  **要点**：以色列技术媒体 Geektime（前身为 Newsgeek，2009 年由 Yaniv Feldman 与 Moran Bar 在特拉维夫创立）对 BSD 的报道以事件驱动为主，主要涉及 Check Point、Juniper 等以色列安全公司与网络设备厂商的新闻；Geektime 是以色列最大的技术博客，2014 年起扩展至英文市场；土耳其技术媒体 Webrazzi 对 BSD 的报道有限
  **史料**：Geektime 历史文章、Webrazzi 历史文章、Check Point/Juniper 公司档案［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］〔L4 事后叙述〕
  **史观**：技术路线的分化与并行演化，媒体报道反映 BSD 在中东的边缘地位
  **辨析**：Geektime 的创立时间（2009 年）、前身（Newsgeek）、创始人（Yaniv Feldman 与 Moran Bar）、2014 年扩展英文市场须经三项独立来源交叉验证（Calcalistech 2022 年 2 月 Moran Leshem Bar 专访、Kochava Media Index）；Check Point/Juniper 的 BSD 使用情况须通过企业档案验证
  **文献**：Geektime 历史文章存档；Webrazzi 历史文章存档；Check Point/Juniper 公司档案；Calcalistech 专访；Kochava Media Index ［A］
