# 370.5.3 加拿大 BSD 法语内容的缺乏

  **要点**：加拿大 BSD 社区中法语内容（法语 BSD 书籍、法语 BSD 技术博客、法语 BSD 会议）严重缺乏，尽管加拿大是双语国家（英语/法语），魁北克省 BSD 用户（如 MBUG 成员）主要使用英语技术资料，法语 BSD 内容的空白是加拿大 BSD 社区多样性的短板
  **史料**：加拿大法语 BSD 内容调查、MBUG 成员的访谈、加拿大 BSD 社区语言分析 ［B］
