# 370.0.9 要点加拿大通信安全局CSECommunicationsSecurityEstab

- 要点：加拿大通信安全局（CSE，Communications Security Establishment）与加拿大国防部在部分网络安全系统与通信基础设施中使用 BSD 系统。加拿大政府部门的开源采用政策（如 2018 年《加拿大数字政府开源指令》）为 BSD 在政府部门的使用提供了制度空间
- 史料：加拿大政府开源
