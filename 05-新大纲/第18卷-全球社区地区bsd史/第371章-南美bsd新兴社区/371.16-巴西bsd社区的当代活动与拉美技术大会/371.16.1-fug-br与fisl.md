# 371.16.1 FUG-BR 与 FISL

**要点**：巴西 FreeBSD 用户组（FUG-BR, 1998 年成立）是南美最早 BSD 组织之一。在 FISL 中的轨迹展示了全球南方在开源运动中的独特角色。
**史料**：FUG-BR 活动记录（1998-2024）; FISL BSD 专题 ［B］
**史观**：总纲第 15 条——全球南方的 BSD 代表性。
**辨析**：FUG-BR 是南美历史最悠久的 BSD 组织之一，但其 1998 年成立至今的活动记录存在明显断层——2000 年代中期至 2010 年代中期的活动轨迹几乎不可考。FISL（国际自由软件论坛）中的 BSD 专题轨迹反映了全球南方开源运动中 BSD 的边缘化：FISL 以 Linux 和 GNU 为主导叙事，BSD 专题往往被压缩为半天或更短的附属议程。巴西 BSD 社区与葡萄牙语 BSD 社区（葡萄牙、安哥拉、莫桑比克）之间存在语言纽带，但跨大西洋的 BSD 协作尚未形成制度化机制。南美 BSD 社区的口述史采集几乎空白，是亟待填补的学术缺口。
**文献**：FUG-BR 记录； FISL 数据 ［B］
