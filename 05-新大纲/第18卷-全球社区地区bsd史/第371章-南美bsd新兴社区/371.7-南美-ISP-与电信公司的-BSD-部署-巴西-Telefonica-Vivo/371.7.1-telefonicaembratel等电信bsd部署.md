# 371.7.1 Telefonica/Embratel 等电信 BSD 部署

  **要点**：巴西 Telefonica/Vivo、Embratel、Argentine Telecom、Chilean Entel 等南美电信公司在 1990-2000 年代广泛部署 FreeBSD 作为网络服务器与路由器平台；具体部署规模须经公司技术档案与招聘信息核查
  **史料**：南美电信公司技术档案、招聘信息、FUG-BR 邮件列表 ［A］
  **史观**：企业研究投入的双重性，南美电信公司对 BSD 的使用与回馈存在不对称
  **辨析**：电信公司 BSD 部署的具体规模须经公司技术档案核查；“广泛部署” 的量化标准须明确
  **文献**：南美电信公司技术档案；FUG-BR 邮件列表；招聘信息档案 ［A］
