# 371.5.3 BSD 与 GPL 阵营在南美的比较

  **要点**：GPL 阵营在南美因卢拉政府支持而占主导地位；BSD 因 “允许专有化” 受 FSF 南美分支批评；比较须警惕 “GPL 更进步” 的预设偏差；BSD 与 GPL 在南美的竞争反映开源运动的意识形态分歧
  **史料**：FSF 南美分支档案、freebsd-brasil 邮件列表 ［A］
  **史观**：法律结构对技术创新的制约与解放，许可证意识形态塑造 BSD 与 GPL 阵营的竞争
  **辨析**：“进步” 的判定标准须明确；“允许专有化” 的批评是否公平须考据
