# 371.0.1 要点

- FUG-BR（FreeBSD User Group - Brasil）1995 年由 Edson Brandi 创立（其本人在 freebsd-translators 邮件列表 2019-12-27 自介中明确），为巴西最早且最具影响力的 FreeBSD 用户组；组织结构以邮件列表与论坛为核心，无固定主席，采用协调人轮换制；具体创立过程须经 FUG-BR 邮件列表存档与参与者口述访谈核查
- FUG-BR 邮件列表与论坛活跃度演变分三阶段——1995-2005 年的高速增长期、2006-2015 年的稳定期、2016 年后的衰退期（受社交媒体与 Slack/Discord 冲击）；演变与国际 BSD 社区趋势同步
- FUG-BR 与巴西 ISP 圈互动紧密，部分 ISP 工程师为 FUG-BR 活跃成员；ISP 工程师通过 FUG-BR 交流 BSD 部署经验与故障排查；互动促进了 BSD 在巴西 ISP 圈的普及；具体互动须经邮件列表与 ISP 技术档案核查
- FUG-BR 史料来源包括邮件列表存档、官方网站、参与者口述访谈；邮件列表存档可能不完整；参与者口述访谈的记忆偏差须警惕
- 巴西版权法（Lei 9.610/1998，1998-02-19 由 Fernando Henrique Cardoso 总统签署，1998-06-20 全面生效，原书所引 “Lei 10.610/1998” 系讹误）与软件专门法（Lei 9.609/1998）对开源许可证的承认经历演变；2014 年《互联网民法框架》（Marco Civil da Internet，Lei 12.965/2014-04-23）为巴西互联网法律框架基础；具体法律细节须经原始法律文本核查
