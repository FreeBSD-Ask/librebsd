# 371.18.3 拉美与非洲反对话语比较

  **要点**：拉美的 “技术民族主义” 批评与非洲的 “数字殖民” 话语均质疑 BSD 的 “美国中心”；但拉美批评侧重许可证意识形态，非洲批评侧重基础设施依赖；比较须控制殖民历史与经济发展水平变量
  **史料**：拉美 FSF 分支声明、非洲 FOSSFA 与 Idlelo 声明、拉美与非洲技术媒体报道 ［C］
  **史观**：边缘者的贡献被中心叙事遮蔽，拉美与非洲的反对话语是 BSD 全球叙事边缘化的双重体现
  **辨析**：拉美与非洲反对话语的相似性与差异性须具体分析；“数字殖民” 与 “技术民族主义” 的概念边界须明确
  **文献**：拉美 FSF 分支声明；非洲 FOSSFA 与 Idlelo 声明档案；拉美与非洲技术媒体存档 ［A］
