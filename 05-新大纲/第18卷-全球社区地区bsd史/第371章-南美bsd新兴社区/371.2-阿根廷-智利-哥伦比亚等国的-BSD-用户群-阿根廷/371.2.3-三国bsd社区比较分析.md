# 371.2.3 三国 BSD 社区比较分析

  **要点**：阿根廷、智利、哥伦比亚三国 BSD 社区存在差异；阿根廷因学术传统较强而 BSD 教学应用较多；智利因电信业发达而 ISP 部署较多；哥伦比亚因经济波动而社区规模较小；比较须警惕 “阿根廷最发达” 的预设偏差
