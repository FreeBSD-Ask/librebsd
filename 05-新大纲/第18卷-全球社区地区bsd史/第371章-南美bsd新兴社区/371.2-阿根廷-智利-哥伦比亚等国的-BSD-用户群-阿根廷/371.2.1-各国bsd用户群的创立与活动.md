# 371.2.1 各国 BSD 用户群的创立与活动

  **要点**：阿根廷 FreeBSD User Group、智利 BSD 用户组、哥伦比亚 BSD 社区等南美西语 BSD 用户群在 1999-2005 年间陆续成立；秘鲁、乌拉圭、委内瑞拉等国为小规模 BSD 社区；具体创立过程须经各国邮件列表与社区档案核查
  **史料**：各国 BSD 用户组邮件列表存档、官方网站历史、参与者口述访谈 ［A］
  **史观**：边缘者的贡献被中心叙事遮蔽，南美西语 BSD 社区须从邮件列表与档案中重建
  **辨析**：各国 BSD 用户群的具体成立时间须经原始档案核查；“小规模” 的判定标准须明确
  **文献**：各国 BSD 用户组邮件列表存档；官方网站档案；参与者个人回忆 ［A］
