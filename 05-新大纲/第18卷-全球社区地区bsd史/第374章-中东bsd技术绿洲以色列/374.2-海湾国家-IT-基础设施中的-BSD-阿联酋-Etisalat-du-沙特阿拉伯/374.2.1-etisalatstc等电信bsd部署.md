# 374.2.1 Etisalat/STC 等电信 BSD 部署

  **要点**：阿联酋 Etisalat 与 du、沙特 STC 与 Mobily、卡塔尔 Ooredoo、科威特 Zain 与 Ooredoo、巴林 Batelco、阿曼 Omantel 等海湾电信公司在 1990 年代至 2000 年代曾广泛部署 FreeBSD 用于网络服务；BSD 部署的具体规模与时间须通过企业档案与工程师访谈核查
  **史料**：Etisalat/du/STC/Mobily/Ooredoo/Zain/Batelco/Omantel 企业档案、海湾电信行业报告、工程师访谈 ［B］
  **史观**：总纲第 9 条——经验优先，海湾电信公司的 BSD 部署决策源于一线运维经验对稳定性的实用主义选择
  **辨析**：各电信公司的具体 BSD 部署时间须通过企业档案核查；BSD 与 Linux 在海湾电信部署中的占比须量化
