# 374.7.1 以色列/沙特/伊朗用户组活动

  **要点**：Israel FreeBSD User Group、Saudi Arabian Unix Users Group、Iran Unix User Group 等组织在 1990 年代至 2000 年代曾有零星活动；活动多依赖个人推动，缺乏制度化保障；具体活动须通过邮件列表与社区档案核查
  **史料**：Israel FreeBSD User Group 邮件列表、Saudi Arabian Unix Users Group 档案、Iran Unix User Group 档案 ［A］
  **史观**：组织结构对技术路径的塑造，中东 BSD 用户组的零星性反映社区组织的结构性限制
  **辨析**：Saudi Arabian Unix Users Group 与 Iran Unix User Group 的实际活动须通过原始档案核实——警惕“传说中”的组织；用户组的活动规模须量化
  **文献**：Israel FreeBSD User Group 邮件列表存档；Saudi Arabian Unix Users Group 档案；Iran Unix User Group 档案 ［A］
