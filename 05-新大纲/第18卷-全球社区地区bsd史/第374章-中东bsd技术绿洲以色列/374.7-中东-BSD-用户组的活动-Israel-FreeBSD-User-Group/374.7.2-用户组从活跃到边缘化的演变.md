# 374.7.2 用户组从活跃到边缘化的演变

  **要点**：中东 BSD 用户组多在 2000 年代中期后边缘化，主要原因包括核心维护者外流、Linux 主流化、地缘政治限制；演变须通过邮件列表活跃度统计验证
  **史料**：用户组邮件列表活跃度统计、社区论坛历史讨论、核心维护者访谈 ［A］
  **史观**：技术路线的分化与并行演化，用户组的边缘化反映 Linux 在中东社区中的主流化
  **辨析**：边缘化的原因须具体分析——维护者外流、Linux 主流化、地缘政治限制等；“边缘化”的判断须通过邮件列表流量量化
  **文献**：用户组邮件列表存档；社区论坛历史讨论；核心维护者访谈记录 ［A］
