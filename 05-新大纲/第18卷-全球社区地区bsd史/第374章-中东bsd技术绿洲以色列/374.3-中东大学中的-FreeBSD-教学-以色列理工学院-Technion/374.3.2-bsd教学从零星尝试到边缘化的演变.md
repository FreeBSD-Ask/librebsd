# 374.3.2 BSD 教学从零星尝试到边缘化的演变

  **要点**：中东大学 BSD 教学多在 2000 年代中期后边缘化，主要原因包括教师退休或外流、Linux 主流化、教育资源转向；演变须通过课程档案与教师访谈验证
  **史料**：中东大学课程档案、教师访谈、中东教育政策文件 ［B］
  **史观**：技术路线的分化与并行演化，BSD 教学的边缘化反映 Linux 在中东教育中的主流化
  **辨析**：边缘化的原因须具体分析——教师外流、Linux 主流化、教育资源转向等；“边缘化”的判断须通过课程持续情况量化
  **文献**：中东大学课程档案；教师访谈记录；中东教育政策档案 ［B］
