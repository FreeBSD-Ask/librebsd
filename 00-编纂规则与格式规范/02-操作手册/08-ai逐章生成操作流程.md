> **适用范围说明**：本文件的批次生成表基于旧 12 卷 157 章大纲结构，卷名、卷号、章号范围均已变更（现行大纲见 `05-卷册大纲/index.md`），批次生成表中的卷名与章号均为旧值。正文编纂已禁止、`06-正式书稿/` 已整体移除，本文件的逐章正文生成流程（8.1—8.3 节）不再执行；`05-卷册大纲/SUMMARY.md` 为唯一 GitBook 导航。第 8.4 节“新增 PDF 自动检测与入库流程”为现行有效流程，由流程规则.md“新增文献自动检测规则”引用。

### 8.1 单章生成流程

```text
对每一章：
1. 阅读本文件中该章的"核心内容"列，明确写作范围
2. 查阅"史观映射"列，明确本章须体现的1.md史观原则
3. 查阅"核心史料指引"中对应的一手/二手资料
3.5 资料获取：如需书籍，自行爬取安娜的档案（Anna's Archive）下载 PDF 后 OCR，或下载 EPUB，作为史料补充；获取后仍须按 0 信任原则考据
3.6 合规认证核查：如本章涉及 POSIX、C 标准、RFC、FIPS 140、Common Criteria、SSDF Attestation、FISMA、FedRAMP、HIPAA、SOX、GDPR、CCPA、CPRA、PIPL 等合规认证标准，须按 09-特别注意事项.md 第 37 条与 8.3 节"合规认证标准检查"清单逐项核查，明确区分"FreeBSD 作为运行环境被列入证书"与"FreeBSD 持有证书"两类事实
4. 按"每章写作模板"结构生成全文（含作者注、正文、技术注解、大事记、史料来源）
5. 标注脚注——按 GB/T 7714-2015 格式著录真实参考文献，禁止以"大纲，第 X 章 X.X 节要点"作为脚注；大纲要点与正文的映射关系写入 `05-卷册大纲/` 下的映射文件（详见写作规则.md"书稿与大纲文件布局规范"）
6. 标注史料可靠性分级——A/B/C/D 级，D 级史料标注"须交叉验证"（详见 4.5.3 节）
7. 检查字数是否达标——只允许多于概述标题标注的目标字数，不得少于目标
8. 检查技术准确性——三重验证原则，关键事实须至少三个独立来源验证（详见 4.9.2 节）
9. 检查史观是否自然融入（无理论标签）
10. 检查自反性是否体现（作者注、史料来源中的自反注）
11. 检查学术格式——脚注格式、引文格式、表格图表编号、缩略语全称、标点规范（详见 7.2.2 节）
12. 检查 GitBook 格式——YAML Front Matter、hint 提示框、tabs 选项卡、page-ref 交叉引用、Mermaid 图表、代码块语言标签（详见 7.2.3 节）
13. 检查与前后章的衔接
14. 模拟内部审稿——AI 以"审稿人"角色从技术准确性、史料可靠性、叙事连贯性、史观一致性四维度审阅（详见 4.9.5 节）
15. 生成章末"建议阅读"并标注史料分级
16. 输出为 GitBook 兼容的章节文件夹结构——每章一个文件夹，内含 `概述.md` 与各节独立 `.md` 文件，布局严格遵循 `05-卷册大纲/SUMMARY.md` 的目录结构；禁止将整章写成一个独立 .md 文件（详见 4.10.1-4.10.2 节与写作规则.md"书稿与大纲文件布局规范"）
17. （卷末章）生成"卷末参考文献"与"书目述评"
```

## 8.4 新增 PDF 自动检测与入库流程

### 8.4.1 适用场景

当用户向 `04-现代研究文献/03-文献下载/` 目录下新增 PDF、EPUB 或 CAJ 文献时，须运行自动检测脚本执行完整入库管线。该流程确保每篇新文献被数据库收录、匹配到对应章节、在综述中引用、在参考文献总目中著录。

### 8.4.2 入库管线七步

```text
1. 去重检查
   - SHA-256 精确去重：与 references.sha256 比对
   - 标题+作者+年份模糊去重：忽略大小写与标点后比对
   - 重复文件写入 reference_duplicates 表，跳过入库

2. 元数据采集（三级回退）
   - 第一级：从已有 .md 摘要文件的 YAML frontmatter 采集（作者、年份、页数）
   - 第二级：从文件名模式匹配（YYYY_作者_标题_lang.ext）
   - 第三级：从 PDF metadata 采集（PyMuPDF 读取 metadata 字段）
   - 无法采集的字段填"未知"/"不详"

3. 数据库录入
   - 写入 references 表（含 file_path、filename、format、title、author、year、page_count、file_size、sha256、bibliography_entry、status、summary_md_path）
   - 写入 summaries 表（含 summary、topic_keywords、important_excerpts）

4. 章节匹配
   - 基于文件名关键词、摘要议题关键词与全书章节标题的相似度自动匹配
   - 关键词重合 ≥ 2 项：高置信度匹配（match_confidence ≥ 0.7），自动入库
   - 关键词重合 < 2 项：低置信度匹配（match_confidence < 0.5），日志标记"需人工确认"
   - 写入 chapter_matches 表

5. 综述追加
   - 在匹配到的主章节的 chapter_reviews.revised_review_text 末尾追加新文献引用段落
   - 追加后字数须在 300-5000 字范围内
   - 超长（>5000字）时不追加，日志标记"需人工精简"
   - 更新 revised_word_count、revised_at、revised_by

6. CSV 更新
   - 向 _匹配映射表.csv 追加新行（文件路径,作者,年份,主匹配卷号,主匹配章号,副匹配章号,匹配依据）

7. 参考文献总目著录
   - 根据文件所在子目录确定类别
   - 按类别追加到 01-参考文献总目/ 对应分类 .md 文件末尾
   - 著录格式：GB/T 7714-2015
```

### 8.4.3 运行方式

```bash
# 检测并入库所有新增文件
python script/auto_ingest_new_pdfs.py

# 仅检测不执行入库（dry-run 模式）
python script/auto_ingest_new_pdfs.py --dry-run

# 指定单个文件入库
python script/auto_ingest_new_pdfs.py --file "04-现代研究文献/03-文献下载/01-pdf/New_Book.pdf"
```
