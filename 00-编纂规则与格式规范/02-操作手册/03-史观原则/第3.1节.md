### 3.1 总纲 25 条在全书中的映射

#### 简表

| 总纲条目 | 1.md 原文 | 在 FreeBSD 史中的具体体现 |
| -------- | --------- | ------------------------- |
| 1. 一切真历史都是古代史 | BSD 史并非现代史，与古代史无本质区别 | FreeBSD 30 年与罗马帝国兴衰无本质区别——都是形式主义的循环 |
| 2. 历史是形式主义化的非存在 | 所写皆是当下主体的重构，从不宣称呈现历史本身 | 每章开篇须承认：本章叙事是形式主义的建构，非“历史真相” |
| 3. 不存在进步，只有权力再分配 | 技术演进不是进步，而是形式主义的诡异曲线 | 不写“FreeBSD 从简陋到成熟”，写“FreeBSD 的形式主义不断替代” |
| 4. 分离聚合是永恒规律 | UNIX 与 BSD、BSD 各分支之间的分合循环 | 全书主线即分离聚合：UNIX→BSD→386BSD→FreeBSD/NetBSD/OpenBSD→DragonFly |
| 5. 没有必然性，只有偶然性 | 每个关键人物、每次 fork、每个技术决定都是偶然 | 强调 Thompson 在 PDP-7 上写 UNIX 的偶然性、Jolitz 停滞的偶然性 |
| 6. 和解优于斗争 | 历史动力不是对抗，而是各主体性的呈现与和解 | 不写 Linux vs BSD 的对抗史，写两者各自主体性的呈现 |
| 7. 理论必须自反 | 承认自身的形式主义性质，以自反姿态打开裂缝 | 每卷末书目述评须自反：讨论本章叙事的形式主义性质 |
| 8. 本体论上各方平等 | FreeBSD/OpenBSD/NetBSD/DragonFly 在本体论上地位相等 | 不以 FreeBSD 为“正统”叙事中心，给予各分支平等篇幅 |
| 9. 经验优先 | 优先呈现质朴的事实与当事人直接经验 | 引用 commit message、邮件列表原文，而非二手评论 |
| 10. 动手者创造历史 | 真正主角是动手做事的老实人 | 重点书写默默提交补丁的普通开发者，而非只写大佬 |
| 11. 商品是形式主义 | 技术市场选择不是自然选择，而是权力运作 | 分析 Linux 胜出的具体史实：①Red Hat 1999 年 8 月 11 日 IPO 筹资建立全职内核团队（首日股价从 14 美元涨至 52 美元），FreeBSD 至 2000 年 3 月方有 Foundation 接受捐赠；②GPL 强制回馈使 IBM/Intel/Google 等企业的内核贡献回流上游，BSDL 允许 Apple/Juniper 等企业 fork 后不回馈；③Linus Torvalds 1991-2024 单一领导 33 年 vs FreeBSD Core Team 9 届换届（1992-2022）的路线连续性差异——而非简单归因“技术更好” |
| 12. 科学是形式主义 | 科学性不等于真理性 | 技术注解中承认：技术“科学性”不能保证“正确性” |
| 13. 法律与道德是利益分配 | 道德问题本质是利益问题 | USL 诉讼、许可证争议须从利益分配角度分析 |
| 14. 苦难不值得被提倡 | BSD 的长期主义不是苦难哲学 | 不将 BSD 的边缘地位浪漫化为“苦难的坚守” |
| 15. 文化即形式主义 | 社区治理结构即形式主义政治产物 | Core Team 选举、committer 制度都是形式主义；第十二卷系统呈现全球各区域社区文化的形式主义差异（第 141-153 章） |
| 16. 信仰是生存维系 | BSD 社区中的准宗教现象应被识别 | 识别“UNIX 哲学”崇拜的信仰属性；中东等特殊环境下技术社区的准信仰属性（第 150 章） |
| 17. 证明世界先于改造世界 | FreeBSD 是否存在本身是开放问题 | 质疑“FreeBSD”这一观念性存在是否真实存在 |
| 18. 时间是一种形式主义 | 等待、记忆、历史欣赏具有时间性 | 强调版本迭代的时间性——每一版都是“一刻” |
| 19. 解释学循环是根本条件 | 前理解差异使分歧不可避免 | 不同社区对同一事件的不同叙述；中日韩区域的文化前理解对技术采用的差异化塑造（第 143-145 章） |
| 20. 历史地理塑造思想土壤 | 土地与自由的养分 | 伯克利、贝尔实验室、剑桥大学——地理与思想的关系；第十二卷系统呈现全球各区域的地理-社区关系（第 141-153 章） |
| 21. 革命与改革是方法论分歧 | Linux 靠革命，BSD 靠改革 | 系统对比 Linux 的革命式开发与 BSD 的渐进式改革 |
| 22. 知识注定过时 | 技术史可能在出版之日就已过时 | 承认本书的技术细节可能很快过时 |
| 23. 一切历史写作都是历史小说 | 史家以为在书写历史，但历史人物藉着史家书写自己的故事 | 承认 Bill Joy、phk 等人物可能正在“藉着”本书书写他们自己的故事 |
| 24. 美是消解性的体验 | 大音希声 | UNIX 哲学的简洁即消解形式主义的美 |
| 25. 逻辑是形式主义 | 自反性不是逻辑悖论 | 全书的自反结构——承认自身是形式主义——不是逻辑漏洞 |
