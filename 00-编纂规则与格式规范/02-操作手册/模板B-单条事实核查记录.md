# 模板 B：单条事实核查记录

> 本模板用于 `07-事实核查记录/` 下单条事实核查记录（原子单元）。所有 Markdown 文件头部须包含上述 YAML Frontmatter，字段对应 spec.md Schema 5 模板 B。

## 使用说明

- `id`：核查记录编号，格式 `FC-<核查记录编号>`（如 `FC-2026-001`）
- `claim`：待核查的事实陈述（一句话）
- `evidence_strength`：证据强度评级，`A` / `B` / `C`，A 为最强
  - `A`：多个独立一手来源相互印证
  - `B`：单一一手来源或多个二手来源印证
  - `C`：仅二手来源或单一来源，存在不确定性
- `page`：出处页码或定位信息（如 `p.123` 或 `commit abc123`）
- `controversy`：学术争议标注，无则填 `none`
- `verifier`：核查人（中文姓名）
- `verified_date`：核查日期，YYYY-MM-DD 格式
- `status`：`pending` / `verified` / `disputed`
