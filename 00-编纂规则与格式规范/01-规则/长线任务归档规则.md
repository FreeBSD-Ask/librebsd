# 长线任务归档规则

> **立**：2026-10-18（主理人令“把《长线任务总登记表》已经完成的内容独立存档，其下按任务分别新建目录进行拆分”）。本规则约束已收官长线从《长线任务总登记表》向归档目录的迁出与后续维护。

## 一、归档对象与触发条件

1. **对象**：《长线任务总登记表》17 条长线中终态为 `CLOSED`／收官／一次性任务完成的线（终态口径见登记表 §一 状态枚举与归档目录归档件）。
2. **不归档**：`文档源` 仍在推（如 A 线）、`DORMANT`（dragonfly T2、B 线）、`人工维护` 未完成（迁移准备层 T1–T10）、已移出长线范围（Linux 战线 Phase 3）者仍在总登记表。
3. **触发**：归档由主理人明示发起——本规则约束“怎么归档”，不授权“何时归档”。

## 二、归档位置与结构

- **归档目录**：`01-项目管理/01-编纂规划与报告归档/长线任务归档总登记表/`，与《长线任务总登记表》同目录。
- **结构**：目录根一个 `index.md` 总册（归档线清单＋归档口径＋指向关系）；其下**按任务分目录**，命名 `NN-<线名slug>/`，每目录一个 `index.md`。

## 三、归档内容（迁什么／不迁什么）

| 类别 | 处置 |
| ---- | ---- |
| 登记表 §一 该线总览表行 | 快照迁入归档件（总登记表表行保留不删） |
| 该线专属章节全文 | **逐字迁入**归档件；总登记表对应节改写为指针节（终态一句＋归档指针），**不得保留同内容全文**（双源禁止） |
| §一 总览表／§十五 变更记录／文末机读块 | **不迁**（编年日志与机读块留在总登记表） |
| 线级任务书／交接书 | 不迁，仍在《任务书迁移登记.md》登记的现路径；归档件内留指针 |
| 机读源（JSON／TSV／DuckDB／脚本） | **绝不迁**（探针与聚合器按原路径读取） |

## 四、操作纪律

1. **写前备份**：总登记表先落同目录 `长线任务总登记表.md.prebak-<主题>-<日期戳>` 副本。
2. **脚本手术**：登记表改动一律走临时脚本（`script/`，UTF-8 无 BOM＋LF），锚点定位＋逐处断言恰好出现 1 次；**禁在登记表上直接 `open("w")` 截断写**，写盘走同目录临时件 → `os.replace`（SMB 上退避重试，同聚合器纪律）。
3. **机读块勿动**：`LONGLINE_STATUS_BEGIN…END` 之间逐字节不变；改后必跑 `C:/Python314/python.exe 00-编纂规则与格式规范/01-规则/脚本与命令/_longline_status.py --check`（须 PASS）。
4. **逐字保真**：迁入归档件的章节全文与登记表原文逐字一致；归档后总登记表侧以指针替代，原节零残留。
5. **登记**：归档批记 changelog（`id` 动态取 `max+1`）；归档线清单同步更新归档目录根 `index.md`。
6. **并发写者**：总登记表存在并发写者（他会话批次收口即改）——编辑前实测 mtime 与 `git diff`，编辑后断言“仅本批意图段变更”；写入者未收敛（短窗内 mtime 变动）时暂缓手术。

## 五、与其他规则的关系

- 线级任务书迁移口径见 `01-项目管理/01-编纂规划与报告归档/任务书迁移登记.md`（线级迁、批级与机读源不迁）。
- 文件编码（UTF-8 无 BOM／LF）、临时脚本规则、过时内容处理见 `流程规则.md`。
- 在推线的登记与续跑入口仍以《长线任务总登记表》为唯一入口（AGENTS.md“长线任务入口”节）。
