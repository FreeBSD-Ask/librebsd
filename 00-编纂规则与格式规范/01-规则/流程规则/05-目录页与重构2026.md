**说明**：本节规定（`05-卷册大纲/目录/index.html`）对外提供服务的**唯一实现**与其行为契约。此前并存两份实现——固定脚本 `脚本与命令/serve_refactor2026.py`（`0.0.0.0:8090`，`ThreadingTCPServer`）与 `05-卷册大纲/目录/server/serve_index.py`（`0.0.0.0:80`，单线程）——二者**语义分叉**（端口／并发模型／`allow_reuse_address` 取值相反／幂等守卫有无）且**均缺传输压缩、均缺安全响应头、均开启目录列表**，而 `05-卷册大纲/目录/server/README.md` 旧版声称“不给目录列表”、62 号文 §7／§8 记录的 `serve_https.py` 已不存在却仍被引用为现状。

**内容源语法**（`data/outline.txt`）：

- `# 卷题` → `<h2>`（“第N卷”与题名间 **2 个半角空格**）
- `> 卷导言` → `<p class="vol-overview">`（可选）；`! 卷分工注` → `<p class="vol-note">`（可选）
- `## 章题` → `<h3 class="chapter">`（含“第 M 章 ”前缀）
- `- 节号 节题` → `<li>`（节号与题文间 **1 个半角空格**）
- `- 节号 @@溯源注@@ 节题` → 溯源注**前置**（紧跟节号）；`- 节号 节题@@溯源注` → 溯源注**后置**（行尾）
- 内容源存**解码文本**（如 `AT&T`），HTML 转义由装配器负责（`&`→`&amp;`）
- `⟦lang:文本⟧` → `<span lang="lang">文本</span>`——**语言标记**（WCAG 2.1 AA 3.1.2 局部语言；2026-10-12 立，136 批）：`lang` 为小写 BCP47 主码（`en`、`en-US`……），置于舶来语种文本（如 `⟦en:USENIX⟧`）两侧；装配期由 `esc()` 消费、定界符不落产物（`plain()` 供 JSON-LD 等非 HTML 语境）；未配对／嵌套／空文本／编码不符即装配**硬失败**（不静默透传）；标注渐进填充，第七件 Q 组护栏“⟦⟧ 零泄漏”

**标准形（canonical）**：一元素一行、LF、UTF-8 无 BOM；卷题后空一行；`<h3>` 与 `<ul class="sections">` 紧邻；节 `<li>` 之间无空行；`</ul>` 紧邻下一 `<h3>` 或 `</section>`；卷块之间空一行。

**口径派生**：doc-metrics／og:description／meta description／footer／JSON-LD 五处口径数字**一律由内容源派生**（`{{N_VOL}}`／`{{N_CH}}`／`{{N_SEC}}`／`{{N_CH_MAIN}}`／`{{N_CH_BIBLIO}}`／`{{TRIPLE}}` 占位符），不手工维护——口径与内容结构性同源，不可能漂移。

**装配与门禁**：

- `python assemble_index.py` —— 装配（幂等：同一组源两次装配产物位相同）
- `python assemble_index.py --check` —— 漂移检测（**第八件门禁**；不一致即退出码 1）
- 修改任一源后应跑：装配 → 九件门禁 → 三套浏览器回归
- `embed.py` 保留为**数据层序列化模块 ＋ 门禁**（`--check` 三项），装配器复用其 `encode_blob`／`integrity_of`／`serialize_content`

**禁止事项**：①不应直接手改 `index.html`（产物）；②不应在内容源中写入 HTML 标记；③不应在模板或内容源中硬编码口径数字（应用占位符）。
