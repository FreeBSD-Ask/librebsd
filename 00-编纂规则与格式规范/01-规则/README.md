# 规则总览与索引

本文件是 FreeBSD 历史书编纂项目规则体系的总览与索引入口，集中收录四类规则的简介、文件索引与调用方式说明。所有撰写、修改、考据工作开始前须先查阅本文件，再按需跳转至对应规则文件。

## 单一来源真相声明

本目录（`规则/`）是项目所有规则的**唯一来源真相（Single Source of Truth）**。

- 规则正文仅活在 `规则/*.md` 中
- `CLAUDE.md` 仅保留项目级布局、修改记录、已修复问题等独有内容，不复制规则正文
- memory 文件（`user_profile.md`、`project_memory.md`）仅保留项目特定约束与用户偏好，不复制规则正文
- 规则如有冲突，以 `规则/` 目录最新版本为准
- 命名规范以 `规则/流程规则.md` 的“序号调整例外”、“编号缺口登记”小节为唯一来源，CLAUDE.md 不复制命名规范展开内容，仅保留索引

详见 [规则/流程规则.md](流程规则.md) “CLAUDE.md 与规则目录去重规则”小节。

## 七类规则简介

本项目规则体系按职责分为八类：考据规则、写作规则、流程规则、主题规则、释读规则、功能对比与数据库回写规则、镜像站挖掘与 OCR 流水线规则、ROW_MINE 块体格式规则，分别承载不同维度的约束。另有研究缺口.md（逐节缺口清单与增补策略，非规则正文）。

- **考据规则（考据规则.md）**：约束史实核查、来源可信度、交叉验证、防幻觉、考据留痕等行为，确保全书内容可查且可信。
- **写作规则（写作规则.md）**：约束标点符号、路径与 IP 加粗、命令行间代码、手册页引用、术语翻译、欧化汉语规避等文字层面的规范。
- **流程规则（流程规则.md）**：约束修改前后复核、脚本执行安全规程、AutoCorrect 调用、三轮完整执行、临时文件放置、PowerShell 转 Python、文件编码、过时内容处理等操作流程；含“批量过滤与删除型修复的安全规则”（正向收紧优先、删除前影响面评估、双向复核、对称验证、禁止黑名单膨胀、回退还原）。
- **主题规则（主题规则.md）**：约束特定主题（合规认证标准叙事、Linux 文化挪用研究、仅 FreeBSD 内容跨 BSD/UNIX/macOS 扩展）的撰写规范，避免模糊表述与淡化措辞，确保跨系统比较叙事的核查严谨性。
- **释读规则（释读规则.md）**：约束一刻哲学的引用、释读、映射，确保精确到一手资料、覆盖所有相关总纲、禁止模板化套用、结合采访实际内容独立撰写，并明确区分一刻哲学主张与一刻哲学批评的对象。
- **功能对比与数据库回写规则（功能对比与数据库回写规则.md）**：约束“现代操作系统功能实现对比（4 大 BSD 与 Linux）”分析与分析结果回写既有代码仓库数据库（02-10）的规范，涵盖首现年数据源约束、词典误报校验、去重回写、幂等与验证留痕。
- **镜像站挖掘与 OCR 流水线规则（镜像站挖掘与OCR流水线规则.md）**：约束历史镜像站/档案馆批量挖掘（探查→批量下载→完整性校验）、扫描件 OCR（文本层优先、RapidOCR 替代、质量分级）、全文索引入库（组/文件级双轨、幂等入库、大纲回写增量安全）的完整流程与经验教训。

## 规则调用方式

开始任何撰写、修改、考据工作前须先查阅本文件（规则/README.md），明确本轮工作涉及哪几类规则，再按需跳转至对应文件逐条对照执行。各类规则的查阅时机如下：

> **正文编纂已禁止**：`06-正式书稿/` 已整体移除，不再撰写正文；写作规则.md“书稿与大纲文件布局规范”小节中与正文相关的流程、操作手册模板 A、08-ai逐章生成操作流程的逐章生成流程（8.1—8.3 节）均已停用（其 8.4 节新增文献自动检测流程仍有效）。大纲、考据、数据库等工作照常执行。

- **涉及史料考据时**：查阅 规则/考据规则.md，重点核对 0 信任原则、多源交叉验证不可靠性规则、来源可信度硬性约束、防幻觉原则等。
- **涉及文字、标点、格式时**：查阅 规则/写作规则.md，重点核对标点符号规则、路径与 IP 加粗规则、命令行间代码规则、手册页引用规则、中文引号强制规则、行间代码与代码块不可篡改规则、中英文混合判断原则、术语翻译统一规则、人名翻译规则等。
- **涉及大纲文件结构化组织时**：查阅 规则/写作规则.md 结构化大纲规则小节，重点核对一段一要点原则、综合使用 Markdown 标记原则、不混杂原则、结构清晰原则、积极使用表格原则等。
- **涉及工作流程、修改规范时**：查阅 规则/流程规则.md，重点核对修改前后复核规则、脚本执行安全规程、AutoCorrect 调用规范、三轮完整执行规则、临时文件规则等。
- **涉及批量过滤、黑名单、删除型修复（内容提取/清理/去重等）时**：查阅 规则/流程规则.md 的“批量过滤与删除型修复的安全规则”小节，重点核对正向收紧优先、删除前影响面评估、双向复核（false positive 与 false negative）、对称验证、禁止追加式黑名单膨胀、发现误杀即回退等。
- **涉及特定主题（合规认证、Linux 文化挪用、仅 FreeBSD 内容跨 BSD/UNIX/macOS 扩展）时**：查阅 规则/主题规则.md，重点核对合规认证标准叙事要求、FreeBSD 不持有证书须明确区分、Linux 文化挪用研究规范、仅 FreeBSD 内容识别规则、大纲是否真实缺少核查流程、BSD/UNIX/macOS 三档分别判定、五字段补全规范等。
- **涉及一刻哲学引用、释读、映射时**：查阅 规则/释读规则.md，重点核对手资料原则、不信任转引原则、全面释读原则、辩证性原则、区分原则、自反性检验、覆盖所有总纲原则、禁止模板化原则、结合采访实际内容原则等。
- **涉及操作系统功能实现对比或分析结果回写代码仓库数据库（02-10）时**：查阅 规则/功能对比与数据库回写规则.md，重点核对首现年数据源约束、0 信任原则适用、词典误报校验、首现年合理性审核、五维对比字段、去重回写原则、幂等可重跑、元数据留痕、禁止事项等。
- **涉及 changelog 数据库更新时**：查阅 规则/流程规则.md 的 changelog 去重规则小节，重点核对去重检查触发时机、无效内容与重复内容判定标准、去重操作规范（SQL 查询辅助）、去重后验证要求等。
- **涉及新增 PDF/EPUB/CAJ 文献入库时**：查阅 规则/流程规则.md 的新增文献自动检测规则小节，重点核对自动检测触发条件、去重执行要求、元数据验证标准、章节匹配置信度阈值、综述追加程序、CSV 与参考文献总目更新、日志核验协议、自动入库与人工复核关系等；详细操作步骤见 操作手册/08-ai逐章生成操作流程.md 第 8.4 节。

## 与 CLAUDE.md 协作指南的关系

CLAUDE.md 与 规则/ 目录的关系是“高层概览 + 详细规则”的分工关系，二者互补而不重叠。

- **CLAUDE.md**：提供项目布局、文件结构、修改记录、协作规范等高层概览，是项目级协作指南的入口。
- **规则/**：提供七类规则的详细展开，是撰写、修改、考据过程中逐条对照执行的规则集。

二者发生冲突时，以 规则/ 中对应类别文件的具体规则为准；规则/ 未覆盖的事项，以 CLAUDE.md 为准。新增规则须先落入对应类别文件，再在 CLAUDE.md 的修改记录中登记变更摘要。
