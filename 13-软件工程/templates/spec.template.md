## 4.5 需求特征自检（ISO/IEC/IEEE 29148:2018 §5.2.5／§5.2.6）

逐条二值判定，缺一即退回：

- [ ] 必要（necessary）：删去即出现能力或质量缺口，且不能由其他需求补足。
- [ ] 适当（appropriate）：细节层级与实体层级相称，不夹带实现方案。
- [ ] 无歧义（unambiguous）：只有一种读法。
- [ ] 完整（complete）：无需外部信息即可理解。
- [ ] 单一（singular）：一条只讲一个能力、特性、约束或质量因子。
- [ ] 可行（feasible）：在成本、进度、技术约束与可接受风险内可实现。
- [ ] 可验证（verifiable）：有可复现的验证方法与证据位置。
- [ ] 正确（correct）：准确表达其来源需要。
- [ ] 合规（conforming）：符合本模板与项目体例。
- [ ] 集合完整、一致、可行、可理解、可确认（complete／consistent／feasible／comprehensible／able to be validated）。

**语言判据**（§5.2.7）：禁用最高级（最佳／最优）、主观词（友好／易用）、模糊代词（它／这）、开放式词（提供支持／不限于）、比较句（更好／更高）、漏洞词（如适用／尽可能）、全体词（所有／永远／从不）、不完整引用（无版本或条款）。
