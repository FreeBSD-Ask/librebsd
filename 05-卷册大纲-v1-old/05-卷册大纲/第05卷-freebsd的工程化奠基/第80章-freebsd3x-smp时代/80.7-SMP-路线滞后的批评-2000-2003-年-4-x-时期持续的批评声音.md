# 90.7 SMP 路线滞后的批评——2000-2003 年 4.x 时期持续的批评声音

## 90.7.1 SMP 路线滞后的批评
  - 要点：批评者认为 FreeBSD 3.x SMP 路线滞后于 Linux 与 Solaris，Giant Lock 在多 CPU 服务器扩展性差，导致部分用户转向 Linux；批评在 2000-2003 年 4.x 时期持续
  - 史料：freebsd-smp 邮件列表批评、BSDCon 辩论、用户迁移案例 ［A］
  - 史观：总纲第 3 条——形式主义膨胀，批评可能以理论标准评判工程实践
  - 辨析：滞后是否导致用户流失需量化数据
  - 文献：freebsd-smp 邮件列表；BSDCon 辩论；用户迁移案例 ［A］
## 90.7.2 与 Linux/Solaris 的差距
  - 要点：FreeBSD 3.x 与 Linux 2.2/Solaris 8 的 SMP 差距在 4 CPU 以上负载下显著，Linux 2.2 已细化 BKL，Solaris 8 已完全抢占，FreeBSD 3.x 仍 Giant Lock
  - 史料：SMP 性能基准测试、freebsd-smp 讨论 ［A］
  - 史观：总纲第 7 条——硬件与软件辩证，多 CPU 硬件普及暴露 FreeBSD SMP 滞后
  - 辨析：差距的具体量化需对照基准测试
  - 文献：SMP 性能报告；freebsd-smp 邮件列表 ［A］
