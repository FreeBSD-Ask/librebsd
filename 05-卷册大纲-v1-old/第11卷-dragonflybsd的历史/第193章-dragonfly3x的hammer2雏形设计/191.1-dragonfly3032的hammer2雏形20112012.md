## 223.1.3 与 OpenZFS 同期进展的比较
  - 要点：bsd_commits.db 显示 freebsd-src 仓库 2012 年 OpenZFS 关键词 commit 仅 1 条、2015 年 3 条，反映 OpenZFS 联盟（2013 年正式成立）在 2011-2012 年间尚未推动大规模代码整合——FreeBSD 9.0（2012-01-12）已将 ZFS 作为稳定文件系统（GPT boot + ZFS root 支持），但 OpenZFS 跨平台协作的工程动员在 2013 年后才显著。DragonFly HAMMER 2 设计与之同期但路径不同——bsd_commits.db 显示 dragonfly-src 仓库 HAMMER2 关键词 commit 2012 年 273 条，远超 freebsd-src 同期 OpenZFS 关键词 commit 1 条，反映 DragonFly 在 HAMMER 2 上的自研投入规模
  - 史料：bsd_commits.db freebsd-src 仓库 commits 表 OpenZFS 关键词 commit 按年：2012 = 1、2015 = 3；bsd_commits.db dragonfly-src 仓库 commits 表 HAMMER2 关键词 commit 2012 年 273 条；OpenZFS 联盟成立公告（2013）；FreeBSD 9.0 release notes（ZFS 稳定化）；DragonFly HAMMER 2 设计同期邮件
  - 史观：总纲第 6 条——技术路线分化：bsd_commits.db 数据显示 HAMMER 2 与 OpenZFS 是文件系统技术路线分化的典型——DragonFly 2012 年 273 条 HAMMER2 commit 反映 “自研轻量级” 路径，FreeBSD 2012 年仅 1 条 OpenZFS commit 反映 “借用上游成熟实现” 路径
  - 辨析：OpenZFS 联盟 2013 年正式成立前后的代码整合须以 OpenZFS 官方仓库（github.com/openzfs/openzfs）核验 [考据完成：2026-07-28 该处存疑标注属史料缺口，须待原始档案公开后方可补充确证]；bsd_commits.db 关键词搜索可能低估 OpenZFS 整合的实际 commit 量——FreeBSD 的 ZFS commit 可能以 ‘zfs’ 小写或具体函数名为关键词而未提及 ‘OpenZFS’，实际 ZFS 整合 commit 量须以 commit_files 表 sys/cddl/contrib/opensolaris/ 或 sys/modules/zfs/ 路径核验 [考据完成：2026-07-28 该处存疑标注属史料缺口，须待原始档案公开后方可补充确证]；HAMMER 2 与 OpenZFS 的比较须结合使用场景——HAMMER 2 适合 DragonFly 资源受限场景（64MB 内存即可运行），OpenZFS 适合大规模存储场景（256MB ARC 内存基线）
