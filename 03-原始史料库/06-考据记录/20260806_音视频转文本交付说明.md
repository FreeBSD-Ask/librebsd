## 二、技术路线（可复用经验）
1. **引擎**：faster-whisper（CTranslate2，CPU 可用），替代 openai-whisper（torch 2GB+ 在本环境装不完）。
2. **依赖安装**：默认 PyPI SSL 中断 → 必须用清华镜像 `pip install -i https://pypi.tuna.tsinghua.edu.cn/simple faster-whisper pysubs2 opencc-python-reimplemented pillow`。
3. **模型获取**：huggingface.co / hf-mirror.com 均不可达 → 从 **ModelScope** 下载：
   `https://modelscope.cn/models/Systran/faster-whisper-small/resolve/master/{config.json,tokenizer.json,vocabulary.txt,model.bin}`
   放本地目录后 `WhisperModel("<本地目录>")` 直接加载，无需 HF 缓存布局。
4. **工具**：本机 `video-subtitle-tool` 技能（`~/.workbuddy/skills/video-subtitle-tool__skillhub/scripts/`）：
   - `transcribe.py <mp3> <out.srt> --model <本地模型目录> --lang en --device cpu`（mp3 直喂，无需 ffmpeg）
   - `export_doc.py <srt> --txt <out.txt> --title <标题>`（去时间码、合并自然段落）
