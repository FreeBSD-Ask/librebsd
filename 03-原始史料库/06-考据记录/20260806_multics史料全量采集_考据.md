**二轮关键经验**：
1. **swenson.org MCR Admin 是 WASM 应用**——静态 curl 只能拿到加载壳（3176 字节），须浏览器 CDP 执行后从 DOM 提取 S3 PDF 直链（`s3.amazonaws.com/eswenson-multics/public/mcrs/MCR101xx.pdf`）；163 条 MCR 中 126 条有 PDF
2. **multics-wiki.swenson.org 需 `curl -k`（自签证书）**，且 http 端口被 Cloudflare 拦截（400）
3. **LDD 索引页链接为无引号格式**（`href=../ldd_listings/mcs/xxx.list`），常规 `href="..."` 正则捕获不到，须用 `href=([^\s>]+)`
4. **MIT 源码站支持 8 个子系统目录**（mcs/sss/t/unb_1/unb_2/355/bos/h），共 5376 个 .list 文件
5. **下载重命名坑**：LDD 按子目录重命名（`355/acu_tables.list`→磁盘 `355_acu_tables.list`），数据库 URL 反查须用"子目录_文件名"键
