## 交叉验证方法

- 对 blocks 全量逐行审读后，以 file_id + block_type + block_metadata 的 key_path/row_index 字段识别内容块来源：
  - file_id=1 + json_node + key_path 形如 `N.volume / N.chapter / N.title / N.slug / N.path / N.sections.M.section_title` → chapter_index.json 逐节点展开，属章节元数据。
  - file_id=2 + csv_row + row_index/is_header → cross_reference_map.csv 行，表头 `source_id,target_id,reference_type,context,page,status`，属交叉引用映射。
- 对 timeline_records 逐行核对 event_date 与公开一手公告：
  - 与 FreeBSD 官方 release 公告页、FreeBSD 使用手册历史节、UC Berkeley CU-551 档案三方比对。
  - 仅将“月/年亦不符”的行判 needs_recheck；“日”位为 01 占位但年月相符的行，视为派生时间线占位，判 no_value。
