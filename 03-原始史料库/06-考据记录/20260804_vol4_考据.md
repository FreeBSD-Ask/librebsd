## 一、考据方法与 0 信任原则执行说明

本卷考据严格遵循以下铁律：

1. **0 信任原则**：所有资料须与至少两个独立来源交叉验证后方可采信。
2. **三次复查**：每条关键史实执行“查证—交叉验证—判定”三轮，再复查一轮。
3. **来源约束**：禁用维基百科（任何语言）/百度百科/CSDN/HandWiki/owiki.org/en-academic.com/阮一峰等；
优先项目官网、USENIX、ACM、IEEE、同行评审期刊、大学出版社、法院判决书、邮件列表原始存档、正式书籍。
4. **失效网址**以 web.archive.org 取存档；结论基于 WebSearch/WebFetch 真实返回；禁止强行采信。
5. **留痕**：每条结论记“查证来源 + 交叉验证方法 + 存疑判定依据”；无法确证者保留 `[存疑]` 标注，并写入 JSON `doubts`。
