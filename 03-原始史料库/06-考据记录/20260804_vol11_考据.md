## 三、逐章考据核验

### 第 213 章 DragonFly BSD 的诞生：Fork 公告与启动
**核验要点**
1. **主张**：2003-07-16 Matt Dillon 于 freebsd-current 发布 fork 公告；引文 "it is simply too heavily mutexed"。
   - **查证来源**：freebsd-current #006889（已访问，标题 "Annoucning DragonFly BSD!"、时间戳 2003-07-16 12:41:34 PDT、引文逐字一致）。
   - **判定**：**采信**（一手邮件，零信任满足）。
2. **主张**：公告选在 FreeBSD 5.x SMPng 性能争议高峰期；DragonFly 仓库首 commit 2003-07-01，早于公告 15 天。
   - **判定**：**采信**（与公告"我已开始代码工作"表述及 commit 数据库一致）。
3. **主张**："7.23 与 7.27 两种说法"误传，实际 7 月 16 日。
   - **判定**：**采信**（与一手邮件时间戳一致）。

### 第 214 章 DragonFly BSD 的诞生：Hsu 评价与早期反馈
**核验要点**
1. **主张**：Dillon 1998 年起活跃于 FreeBSD 提交，首 commit 1998-08-26；FreeBSD Core Team 撤销其提交权限（标题）。
   - **查证来源**：GitHub 贡献者列表（"Matthew Dillon (1998–2003)"）部分印证 1998 首 commit；撤权具体日期见下。
   - **判定**：**部分采信**——首 commit 日期与 GitHub 列表一致，但非独立一手核验；撤权精确日期原文留为"2003 年中（存疑）"，本考据已可补正为 **2003-02-03**（见 D-02 / 基线）。
2. **主张**：撤权与 fork 因果关系（末次 freebsd-src commit 2003-01-28 → 撤权 → fork）。
   - **判定**：**采信**（时间线逻辑与一手日记一致：撤权 2 月初，fork 准备 6 月，公告 7 月）。
3. **主张**：HAMMER 为自研 B-tree 写时复制文件系统，与 ZFS 对照。
   - **判定**：**采信**（与 HAMMER 设计文档、官网一致）。
4. **主张**：DragonFly 沿用 FreeBSD 的 BSD 许可证。
   - **判定**：**采信**（dragonflybsd.org 官方许可证页）。

### 第 215 章 DragonFly BSD 早期演进：现状与维护
**核验要点**
1. **主张**：Dillon 长期个人主导，无 Core Team、无 Foundation 治理，与 OpenBSD de Raadt 模式对照。
   - **判定**：**采信**（治理事实；与多处权威叙述一致）。
2. **主张**：Dillon 被撤权后与 FreeBSD Core Team 长期交恶。
   - **判定**：**采信**（与 peerproduction.net 所述撤权后的紧张关系一致）。
3. **备注**：本章概述 `DATA_VERIFY_BLOCK` 自报"存疑点 30 条"，多为内部 DB 统计类存疑，非硬史实，归并至覆盖说明。

### 第 217 章 DragonFly BSD 早期演进：vkernel 虚拟内核
**核验要点**
1. **主张**：vkernel 机制于 1.6 系列（2006-10-22 首 commit）开始引入，基于 LWKT 消息传递，用户态运行内核实例。
   - **查证来源**：第 217 章内部 commit 记录（sys/platform/vkernel/ 2006-10-22）；维基百科发布史（"1.8 virtual kernel implementation" 2007-01-30）；LWN.net 2007-04 "A peek at the DragonFly Virtual Kernel"。
