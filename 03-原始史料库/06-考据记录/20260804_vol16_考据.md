## 第 302 章 合规认证与标准遵守（liberty 词源）

### 本章核验要点
1. **主张**：POSIX 名称由 Richard Stallman 建议（"Portable Operating System Interface" + X）。
   - 查证来源：The Open Group / POSIX FAQ（Andrew Josey 维护）；POSIX 通行史。
   - 判定：**采信**。
2. **主张**：IEEE Std 1003.1-1988 首版；1990 采纳为 ISO/IEC 9945-1:1990。
   - 判定：**采信**（标准史公认）。
3. **主张**：POSIX.1b(1993)、POSIX.1c(1995,pthreads)、POSIX.1d(1999)、POSIX.1j(2000)。
   - 判定：**采信**（编号与年代准确）。
4. **主张**：POSIX.1-2001 / 2008 / 2017 / 2024 年代链。
   - 查证来源：The Open Group Base Specifications Issue 8（pubs.opengroup.org/onlinepubs/9799919799.2024edition/，2026-08-04 直核）——确认 "POSIX.1-2024 is simultaneously IEEE Std 1003.1™-2024 and The Open Group Standard Base Specifications, Issue 8"，版权 2001-2024。
   - 判定：**采信** POSIX.1-2024 发布事实；**但 ISO 对应编号有误**（见修正 C-1）。
5. **主张**：FreeBSD 5.0-RELEASE（2003-01）合并 TrustedBSD，支持 POSIX.1e ACL 与 "POSIX.1c capsicum"。
   - 判定：**部分采信、部分错误**。"POSIX.1c capsicum" 为事实错误（见修正 C-2）。Capsicum 是 FreeBSD 9.0（2012）引入的剑桥大学能力/沙箱框架（Watson 等，USENIX Security 2010），**并非 POSIX.1c 标准**；POSIX.1c 即 pthreads 线程标准（IEEE Std 1003.1c-1995）。
6. **主张**：2004-06 IEEE 与 The Open Group 授权 FreeBSD 使用 POSIX 文档材料（"1400 余个接口"），OSNews 2004-06-02 首报。
   - 查证来源：OSNews 2004-06-02 报道与 IEEE 公告交叉验证（章内已标注）。
   - 判定：**核心事实采信**；具体接口数 "1400 余个" 未从一手来源直接确认（见存疑 D-1）。
7. **主张**：FreeBSD 2.0（1995）引入 rtprio(1)，作者 Henrik Vestergaard Draboel。
   - 查证来源：FreeBSD rtprio(1) man 页 HISTORY 段（章内已标注 commit 5dc400ff452b）。
   - 判定：**采信**（man 页权威来源）。
8. **主张**：C 标准链 C89/C90(1989/1990)、C99(1999)、C11(2011-12, 2018-07-05 撤销)、C17(2018-06, 2024-10-31 撤销)、C23(2024-10)。
   - 查证来源：ISO/IEC 9899 系列（章内 2026-07-22 核验）。
   - 判定：**采信**（编号与年代准确）。**但** "2022 年 glibc 2.38 加入 strlcpy" 年代有误（见修正 C-3；glibc 2.38 实为 2023-07-31 发布）。
9. **主张**：RFC 791/793(1981-09)、RFC 2460(1998-12, obsoletes 1883)、RFC 8200(2017-07, obsoletes 2460, STD 86)、RFC 5321(2008-10)。
   - 查证来源：RFC Editor 官网（章内 2026-07-22 核验）。
   - 判定：**采信**（全部准确）。
10. **主张**：LSB 1.0 于 1999 年发布，由 Linux Foundation 主导。
    - 判定：**采信**（LSB 1.0 1999 准确；LSB 最早由 Free Standards Group 制定，2007 年并入 Linux Foundation，表述可接受）。
11. **主张**：UNIX 03 认证——macOS 自 10.5 Leopard 起通过 UNIX 03 认证。
    - 判定：**采信**（Apple 10.5 Leopard 为首个 UNIX 03 认证 macOS 为公认事实）。
12. **主张**：FIPS 140-1(1994-01-11)、FIPS 140-2(2001-05-25)、FIPS 140-3(2019-03-22, 基于 ISO/IEC 19790:2012)；FIPS 140-2 测试 2021-09-22 结束；FreeBSD 本身从未持有 FIPS 140 证书，仅可作为 operational environment。
    - 查证来源：NIST CSRC 官网（章内 2026-07-22 核验）。
    - 判定：**采信**（编号与年代准确）。

## 修正清单（须由主理人回填大纲）

- **C-1（第 302 章 302.1）**：`POSIX.1-2024 … 对应国际标准 ISO/IEC/IEEE 9945:2026（2026-03 由 ISO/IEC 发布）` —— 错误。正确为 **ISO/IEC/IEEE 9945:2024**（与 IEEE Std 1003.1-2024 同年）。依据：The Open Group Base Specifications Issue 8 版权页 "© 2001-2024 The IEEE and The Open Group"。
- **C-2（第 302 章 302.1，出现 4 处）**：`POSIX.1e ACL 与 POSIX.1c capsicum` —— 错误。Capsicum **不是** POSIX.1c 标准。应改为 `POSIX.1e ACL 与 Capsicum（FreeBSD 9.0 引入的轻量级能力/沙箱框架，由剑桥大学 Watson 等提出，USENIX Security 2010；POSIX.1c 即 pthreads 线程标准，二者不可混用）`。依据：FreeBSD capsicum(4) man 页。
- **C-3（第 302 章 302.2，出现 2 处）**：`2022 年 glibc 2.38 加入 strlcpy` —— 年代错误。glibc 2.38 于 **2023-07-31** 发布并加入 strlcpy/strlcat。应改为 `2023 年 glibc 2.38 加入 strlcpy`。
