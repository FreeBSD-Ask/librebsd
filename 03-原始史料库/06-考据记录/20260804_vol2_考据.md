## 一、全卷核心结论（摘要）

1. **主文献库数据完整性事故**：本卷 139 处 `<!-- NEWREF:ID -->` 标记指向主文献库 `references_fulltext.db`（表 `references`），但该库 records 绝大部分已被与 BSD 无关的语料整体覆盖（数论 BSD 猜想论文、物理、现代 AI/网络/功率流、NASA 报告等）。经逐条核对，仅约 60 个 ID 确为 BSD 真实史料，其余约 79 个 ID 主库记录与所在章 BSD 主题完全无关，判定为“主库被整体重灌 / 引用 ID 错配”。正确引用应见分章库 `资料数据库.db`（按 `vol=2, ch, sec` 组织，已含规范 GB/T 7714 著录）。
2. **史实核验**：1BSD(1978-03-09, ~30份磁带)、2BSD(1979-05)、4.2BSD(1983-08)、4.3BSD(1986-06)、4.3BSD-Tahoe(1988-06)、4.3BSD-Reno(1990初)、Morris 蠕虫(1988-11-02 20:30, MIT, Robert Tappan Morris, 利用 sendmail 调试模式/fingerd/rsh)、Net/2(1991-06)、USL 诉 BSDi(1992-04 立案, 1993-03-03 Debevoise 拒初步禁令, 1993-07 Novell 收购 USL, 1994-01 和解, 删3改70)、Sun(1982-02 成立, Joy 晚春加入)、AT&T(1982-01-08 签署和解, 1984-01-01 分拆生效)、BSD 小恶魔(Foglio 1976 初稿, McKusick 1988 版权) 等均经双源验证无误。
