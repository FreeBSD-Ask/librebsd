ZFS - snapshots
A snapshot is a read-only copy of a file system or volume. 
Snapshots can be created almost instantly, and they initially 
consume o additional disk space within the pool. However, as data 
within the active dataset changes, the snapshot consumes disk 
space by continuing to reference the old data, thus preventing the 
disk space from being freed. 
https://docs.oracle.com/cd/E23824_01/html/821-1448/gbciq.html
