# 《给我自由——一部 BSD 的历史》

[![CI](https://github.com/FreeBSD-Ask/librebsd/actions/workflows/ci.yml/badge.svg)](https://github.com/FreeBSD-Ask/librebsd/actions/workflows/ci.yml)

科学技术史体裁学术专著《给我自由——一部 BSD 的历史》的编纂工程仓：以 AI 参与撰写、人在场的会话按批推进，规划规模约 300–400 万字。当前处于**大纲、考据、数据库与目录页**建设阶段，正文编纂尚未启动。

本 README 只作入口页与质量设施说明：结构职责、绝对红线与门禁判据一律以 [AGENTS.md](AGENTS.md) 为唯一权威；卷／章／节口径数字的唯一机器可读权威是目录页页首 `doc-metrics`，本文件不复述。

## 环境要求

- Python 3.14；门禁脚本除数据库类外只用标准库。
- DuckDB 运行时锁定 `duckdb==2.0.0`，唯一声明源为 `00-编纂规则与格式规范/01-规则/脚本与命令/duckdb-version-baseline.txt`；数据库工作副本不入库。
- Node ≥ 22（本地钉定 markdownlint-cli2 0.24.0，CI 侧装 Node 24）：目录页视觉回归三套件与 markdownlint 所需。
- 全新克隆只含文本与装配产物：数据库类门禁须在本机恢复 `12-数据库备份/` 副本后执行。

## 本地运行门禁

命令均在仓库根目录执行（示例）：

```sh
python 00-编纂规则与格式规范/01-规则/脚本与命令/audit_markdown_lint.py
python 00-编纂规则与格式规范/01-规则/脚本与命令/audit_outline_landing.py
python 00-编纂规则与格式规范/01-规则/脚本与命令/_longline_status.py --check
node 05-卷册大纲/目录/tests/visual_regression.mjs --headless
```

每批必跑门禁链与触发面查表见 [AGENTS.md](AGENTS.md)“每批必跑门禁”，判据正文见 `00-编纂规则与格式规范/01-规则/流程规则/00-索引.md`。

## CI（GitHub Actions）

[.github/workflows/ci.yml](.github/workflows/ci.yml) 在 push、pull request 与手动触发时运行，收编范围为**不依赖本地数据库、浏览器与机器固定路径**的门禁，按层分步执行：

- 文本与格式层：Markdown 格式、直角引号清零、加粗空格、AI 不可见字符、行为源块作用域、磁盘术语一致性、旁路备份残留、测试夹具新鲜度、主题词索引等。
- 大纲与目录页结构层：目录页结构自检、节号章号连续性、DATA 数据完整性、内嵌数据块一致性、口径同步、页面资产层、服务器契约、页面版本号递增、小节标题一致性与题名术语形态、装配漂移自证、四级行合并器幂等自证。
- 守卫、锚与交叉引用层：改号同源守卫、静默丢失守卫、大纲重复锚与重复块、目录页交叉引用、分工注四判据。
- 落地与治理层：大纲落地一致性、门禁体系元门禁、工程实践基线、目录页自检测试。
- 另有 `compileall` 与 `node --check` 语法冒烟。

未收编门禁及原因（详因见工作流内注释）：

- 浏览器类（视觉回归三套件、无障碍门禁）：夹具硬编码本机 Playwright／Chromium 路径，限本机 Windows 运行。
- 数据库类（写库门禁、人物库语义完整性、锚解析、长线登记表数值校验等）：依赖不入库的 DuckDB 工作副本。
- 扫描面不入库（任务生命周期门禁）：扫描面 `.trae/specs/` 按裁决不入库，全新克隆下按设计退出。
- 存量缺损未清（成对锚配平、BEGIN/END 章内配对）：待 [锚配平缺损清单与处置施工单](01-项目管理/02-工程决策与技术债/锚配平缺损清单与处置施工单-20261029.md) 清零后，以显式 `--check` 收编。

供应链纪律：工作流引用的第三方 action 一律以 40 位提交 SHA 钉定（行尾注释记语义版本），不用浮动 tag；升级由 [.github/dependabot.yml](.github/dependabot.yml) 的 github-actions 生态提 PR。

派生索引同批义务：`05-卷册大纲/` 内题名变动须同批以 `build_theme_index.py --write` 重建 `chapter_keywords.json`／`theme_index.json`，漏重建会被主题词索引门禁按设计拦截。
