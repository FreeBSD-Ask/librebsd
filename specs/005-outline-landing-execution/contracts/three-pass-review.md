# Contract: 主代理三趟串行复核（three-pass review）

**版本**: 1.0（2026-10-24）| 依据：ykla 令“不使用子代理”＋spec FR-008/FR-009/FR-011/FR-012

## 1. 输入包（只读密封）

- 每子批一个输入包：`review/packs/<卷>-<子批>.tsv`（源文摘要＋旧路径＋特殊结构标记）＋完整 `target-catalog.md`（3,705 节）＋源文全文读取权（旧树只读）。
- **输入包在三趟期间内容与路径不变**；任何趟不得写 packs/。

## 2. 三趟执行序（严格串行，同一主代理）

| 趟 | 策略（判定检索路径强制差异化） | 输出文件 |
| -- | ---- | ---- |
| A | **题面语义优先**：先以源文 H1 题面与目标节题面做语义对齐，题面无解再查内容 | `judgments/<卷>-<子批>-A.tsv` |
| B | **内容主题词优先**：先从源文正文提炼主题词匹配目标节题面与上下文，题面仅作旁证 | `judgments/<卷>-<子批>-B.tsv` |
| C | **结构与编号线索优先**：先按旧卷/章/节编号、目录层级与相邻件已判落点推断，语义仅作旁证 | `judgments/<卷>-<子批>-C.tsv` |

每趟输出列：`source_id／target_id／reason／strategy／pass_id`；`target_id` 空值＝该趟判“无落点”（仅允许带理由）。

**密封规则**：趟 B 起手时，A 的输出已落盘且本趟**不读**；趟 C 同理不读 A/B。合并器是三趟输出唯一汇聚点。趟内可读：输入包、target-catalog、旧树源文、（C 趟）同卷**已合并**子批的 CONFIRMED 落点（结构线索）；不可读：本子批任何未合并趟输出。

## 3. 合并器（硬判据，脚本执行非人工）

**前置断言（dry-run F4 教训）**：目录解析器须处理**汉字数字卷头**（“第一卷”…“第七十五卷”），起手断言“解析节数==3,705”，不足即停批——初版只认阿拉伯数字曾致题面全空、三同件被硬塞判据全量误降级。

1. 三文件 source_id 集合相等（否则停批——丢行即缺陷）。
2. 逐条：三 `target_id` 字符串全同且非空 → `CONFIRMED`（review_a/b/c 各记“target_id＋理由摘要＋策略”）；三趟全判空且有理由 → `UNMAPPED`；其他任何组合 → `DISPUTED`（disputes.tsv 记三趟值、差异摘要与 **subtype**：adjacent＝同章/邻章 2:1 分裂、empty-vs-value＝题面空趟对内容趟、generic＝其余——先导实测 7 例分歧 6 例 adjacent）。
3. **禁硬塞**：合并前对拟 CONFIRMED 行跑“目标节题面与源文题面/主题词交集”检查（字符二元组交）——无交集降级 DISPUTED（reason=hard-stuff-suspect）。
4. 守恒断言：合并后（子批内）`PENDING+CONFIRMED+UNMAPPED+DISPUTED+DUPLICATE+DISCARDED+TARGET_LOST+REMAP` 增量守恒；全表和恒==37,484。
5. 写 checkpoint、打印状态分布与分歧率（分歧率=DISPUTED/（CONFIRMED+DISPUTED+UNMAPPED）；**先导干执行基线 58.3%（12 件小样本），生产先导批 300–500 条为决策点**）。

## 4. 复核轮（第四视角，时间分离）

- 起手声明“独立复核轮”＋轮次号；不复用合并器缓存，守恒与列完整**重算**。
- 每卷抽 ≥30 条 CONFIRMED 回放（源文↔目标节题面主题交集）；DISPUTED 全量差异归类；checkpoint↔台账对账。
- FAIL 处置：停批整改→重跑该轮；结论与轮次写 `任务复核台账.md`。

## 5. 签收

- 三轮（卷级／全批／整改复验）齐且 PASS 后，收口行呈 ykla **本人签收**；不得代签、不得以批记录替代签收行。

## 6. 禁止事项

- 禁调用 Agent 工具派发子代理执行任何一趟（NFR-001）。
- 禁同一轮内“判完即自审”（D2）。
- 禁以算法模拟值替代三趟真实判定（任务书 §4.4 结论）。
- 禁对旧树源文与 packs 的任何写操作。
