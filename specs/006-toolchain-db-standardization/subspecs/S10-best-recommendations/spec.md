# S10 综合最佳建议

## 1. 意图确证（档 A 摘要）

- **用户原话（节录）**：综合项目提出不计成本，符合学术规范，标准的最佳建议。
- **目标**：把 S01—S12 的结论组合成 3—4 条路线（保守／标准／进取／研究型），给出成本、风险、收益、依赖、回退与决策记录；声明学术规范与限制。
- **非目标**：
  - 不执行建议；只出方案。
  - 不以“技术先进”代替“适配”。
  - 不隐瞒成本与风险。
  - 不伪造引用或数据。
- **验收判据**：
  - 12 目标全部被至少一条路线覆盖。
  - 每条路线有成本、风险、收益、依赖、回退。
  - 建议按风险×影响×不可逆性排序，不按技术时髦。
  - 学术规范声明含引用、复现、限制、AI 披露、许可。
- **手段自由度**：
  - 汇总 S01—S12 产物；不新增未经验证的结论。
  - 成本用人力／时间／风险分级；收益用可测指标。
  - 独立复核与 ykla 抽审。
- **未知／[待验证]**：
  - ykla 对路线偏好。
  - 执行资源与时间窗口。
  - Task 8.2／8.3 收口时点。

## 3. 用户故事与验收场景

### US-S10-1 组合而非清单

**Why this priority**：建议要能选，不是把所有事都做。

**Independent Test**：任取一条路线，能说清做什么、不做什么、先后。

**Acceptance Scenarios**：

1. Given 保守路线，When 查范围，Then 有 included／excluded。
2. Given 进取路线，When 查风险，Then 有回退。

### US-S10-2 成本风险透明

**Why this priority**：不计成本不等于无代价。

**Independent Test**：每条建议有成本级别、风险、收益、依赖。

**Acceptance Scenarios**：

1. Given 一条建议，When 查成本，Then 有人力／时间级别。
2. Given 一条高风险建议，When 查回退，Then 有步骤。

### US-S10-3 学术规范

**Why this priority**：建议本身也要符合学术规范。

**Independent Test**：引用可定位；限制与反例如实披露。

**Acceptance Scenarios**：

1. Given 一条引用，When 查，Then 有 URL／标准号。
2. Given 一条结论，When 查限制，Then 有适用范围。
