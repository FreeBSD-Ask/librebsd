# 许可评估（S12-FR-10）

| 组件 | 许可 | 用途 | 风险 | 处置 |
| ---- | ---- | ---- | ---- | ---- |
| Tesseract | Apache-2.0 | OCR 引擎 | 低 | 采用；语言包随源（GPL-兼容笔记归档） |
| PaddleOCR | Apache-2.0 | 对比批 OCR | 低 | 可选 |
| PyMuPDF（fitz） | AGPL-3.0（商业另购） | 文本层/渲染 | **高（AGPL 传染）** | 仅作本地分析工具、不随书稿分发；如需分发改 pdfium（Apache-2.0）/pypdfium2 |
| Whisper（openai/whisper） | MIT | ASR 本地 | 低 | 采用；模型权重许可随 repo（MIT） |
| SenseAudio | 服务条款约束 | ASR API | 中（账号/配额/数据出境） | 按批评估；禁凭据入库（工程实践规则 §5.2） |
| ffmpeg | LGPL-2.1/GPL（编译选项） | 抽轨/响度/元数据 | 低（本地使用） | 采用；分发需注意 GPL 编译选项 |
| 参考稿/音频原件 | 各自版权 | 转写输入 | 中 | 按考据规则登记来源与许可；版权未清件禁入批 |

**结论**：本地流水线（Tesseract+Whisper+ffmpeg+PyMuPDF 本地分析）可执行；分发面（如把 PDF/A 成果对外发布）触发 AGPL 复核，须 ykla 明示。AI 披露类规范不采纳（ykla 2026-11-27 裁定），不影响本表。
