# 保留清单（不建议改写；S04-FR-11）

- 生态绑定（PDF/OCR/网络/DuckDB 交互重）：81 件——Rust 生态成本＞收益，保留 Python。
- 其余为 观察态：无基准前不下结论。

## 保留理由（逐类）

1. **PDF/OCR/图像**（fitz/PIL/tesseract）：Rust 生态（pdfium-render/leptess）成熟度与运维成本劣于 Python 现状。
2. **网络采集**（requests/bs4/批量爬取）：reqwest 可行但重写收益低、限速/重试语义迁移成本高。
3. **DuckDB 交互批**：duckdb-rs 可行，但这些脚本同时承担业务口径（guard/waterlock/回读断言），改写风险集中于口径漂移。
4. **门禁类**：门禁自身是项目判据的执行体；改写会让“判据正确性”依赖新实现的正确性，性价比低。
