# 编程语言标准（S04-FR-05；三级：强制/推荐/禁止）

## Python 3.15

- 强制：公共函数类型标注；ruff 通过；UTF-8 无 BOM/LF；不可信输入以 `-I` 运行；弯引号；无硬编码盘符。
- 推荐：pyright/mypy；pytest；docstring 首行用途。
- 禁止：裸 `python -c` 内含反引号/`$`（bash 替换掏空）；隐式全局状态；`except: pass` 吞错。

## Rust（Edition 2024）

- 强制：`cargo fmt --check`；`clippy -D warnings`；`cargo deny check`；`cargo audit`；`Cargo.lock` 提交；`rust-version` 声明。
- 推荐：nextest；criterion（基准）；proptest（解析/纯函数）；Miri（unsafe 路径强制）。
- 禁止：无审计 unsafe；nightly-only 特性进生产；未锁定依赖；跨 FFI 共享可变引用；把 N−2 支持写成对外承诺。

## JavaScript/TypeScript（bun）

- 强制：bun 运行；ESM；锁文件入库。
- 推荐：TS 类型；ESLint。
- 禁止：npm（项目口径禁 npm）；新代码 CommonJS。

## SQL（DuckDB 2.0.0 方言）

- 强制：显式列名；显式事务；标识符加引号；参数化查询；只读剖析用 `read_only=True`。
- 推荐：`EXPLAIN` 审查重查询；`PRAGMA` 设置写入运行手册。
- 禁止：`SELECT *` 入生产；未加引号保留字；隐式类型转换依赖。

## Shell（Git Bash）

- 强制：`set -euo pipefail`；路径加引号。
- 推荐：用途注释头部。
- 禁止：PowerShell 脚本；`rm -rf`；通配删除。

## 义务级用语

- 规则文本 MUST/SHOULD 按 RFC 2119/8174（全大写才有规范含义）；中文“须/应/宜/不得”映射见第四十五件。
