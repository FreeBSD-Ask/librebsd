# Rust 生产改写方案（S04-FR-09/12；ykla 2026-11-27 已批准）

## 一、批准与边界

- 生产改写已获 ykla 2026-11-27 批准；**每个改写批仍须**：矩阵过筛（eco_conflict=no 且 CPU 类）→ 基准（FR-02）→ 影子运行 → 灰度 → 回退演练 → 任务审计准入。
- 首批候选：本矩阵“改写候选（待基准）”清单（4 件）——全部为纯 CPU 文本/哈希密集、无重生态绑定。

## 二、影子运行协议（S04-FR-09）

1. 双实现同输入：Python（现行）与 Rust 各跑 N 次；输出逐字节比对（文本类）或逐记录比对（TSV/JSON 类，键序归一）。
2. 比对通过 → 记录基准（启动延迟/吞吐/内存/输出一致性）→ 灰度：先 1 个非关键批 → 观测指标（正确性/耗时/内存/崩溃率）→ 全量切换。
3. 回退开关：`LIBREBSD_USE_RUST=0` 环境变量强制走 Python 入口；Python 入口保留 ≥1 个季度。
4. 每批收口：任务审计台账准入/收口行＋changelog＋（如产出）BOM/LF/引号门禁。

## 三、工程基线（S04-FR-06/07/08）

- 工作区 `01-规则/脚本与命令/rust/`（Cargo workspace；源码入库，产物不入库）。
- Edition 2024；每 crate `rust-version`；CI 双跑 MSRV 与 stable；`Cargo.lock` 提交。
- `cargo fmt --check`＋`clippy -D warnings`＋`cargo deny check`＋`cargo audit`；`#![forbid(unsafe_code)]` 默认，例外 crate 白名单＋SAFETY 注释＋Miri。
- FFI/PyO3 边界：`Send`/`Sync` 显式；禁共享可变引用；错误映射为 Python 异常。
