## 二、分类与判据（S11-FR-01/02）

| 类别 | 判据 | 默认动作 |
| ---- | ---- | -------- |
| cache_dir | 目录名 ∈ {`__pycache__`,`.pytest_cache`,`.ruff_cache`,`.mypy_cache`,`node_modules`,`target`,`dist`,`.build`,`build`,`.cache`} 或 `.vitepress/cache`；**克隆树内除外** | delete（整目录） |
| sidecar_backup | `.bak/.bak-*/.bak_*/.prebak*/.pre/.orig/.rej/~/.bak.N` | delete |
| pycache_file | `.pyc/.pyo` | delete |
| misnamed_dir | 名含 `…`/`...`/零宽/`[MASKED]`/`[path]`、前导 `._`、尾部 `~`；克隆树内除外 | quarantine（整目录移隔离区） |
| one_shot | `script/` 等 allowlist 顶层内、未跟踪、>30 天、basename 未被规则引用 | delete |
| stale_temp | allowlist 顶层内 >30 天的其他件 | quarantine |
| gone_during_scan | 扫描窗口内消失（错名目录幻影件） | 随父目录隔离 |

**保护清单**（零越界，实测通过）：Git 跟踪件、`03-原始史料库/01-代码仓库史料/`（克隆树不可拆散——首轮 plan 曾误报克隆树内 `build/` 为缓存，已修复并在清单断言 0 动作）、数据库后缀、受保护顶层。
