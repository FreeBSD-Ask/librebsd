# ADR 草案 0024：工具总表派生视图与生命周期门禁

**状态**：草案｜**日期**：2026-11-28｜**关联**：TG-019、S09

## 背景与问题

139 件固定工具无机器可读台账；stable 判据缺口 61 件（缺 selftest 或规则引用）；CLI 契约缺口 119/121；工具增删无门禁拦截。

## 选项

A. 只留 README 手工表——漂移继续。
B. 工具总表 TSV/MD 派生视图＋`build_tool_registry.py`/`audit_tool_registry.py` 固定脚本＋入第十六件登记（推荐）。
C. 全量 121 件立即补契约——一次性成本过高且会扰动在途批。

## 决定（建议）

B。分两步：①本批 v0 表已产出（`deliverables/S09/`）；②下一步把生成器/校验器转正为固定脚本（登记第十六件），stable 未达标 61 件列入整改批（补 selftest 或规则引用），CLI 契约按高频工具优先补齐。

## 后果

- 正面：R4/R7 有机器判据；生命周期 TTL 可执行；工具增删可审。
- 负面：新增两门禁脚本的维护成本；experimental 90 天 TTL 需要人执行（无自动化）。
- 失效：连续两季工具表零引用 → 降级为说明文档。
