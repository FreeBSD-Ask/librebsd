# 真值文件与数据模型

本文件描述三类结构化真值：内容源 `outline.txt`、映射层 TSV、以及 `mapping.duckdb` 的派生视图。取数日期 2026-10-28。

## 一、内容源：`outline.txt`

路径 `05-卷册大纲/目录/data/outline.txt`，纯文本行式、零 HTML、UTF-8 无 BOM、LF。行型共六类：

| 行型 | 语法 | 说明 |
| ---- | ---- | ---- |
| 卷题 | `# 第一卷  题名` | “第N卷”与题名之间为 2 个半角空格；渲染为 `<h2>` |
| 卷导言 | `> 文本` | 可选；自反性声明所在行 |
| 卷分工注 | `! 文本` | 可选；分工、拆卷、定位说明 |
| 章题 | `## 第 M 章 题名` | 含章号前缀；渲染为 `<h3 class="chapter">` |
| 节行 | `- M.N 题名` | 节号＋1 个半角空格＋题文；渲染为 `<li>` |
| 语言标记 | `⟦en:文本⟧` | 行内标记，装配期转 `<span lang>` 并从纯文本剥离 |

节行的溯源注有两种位置：

- **前置**：`- 2.1 @@〔注〕@@ 题名`，注紧跟节号；
- **后置**：`- 7.8 题名@@〔时间：1978 年〕`，注在行尾。

分工注、迁移说明等长注以 `〔…〕` 包裹，多个注并列时逐条 `〔〕`。

**口径派生**：卷／章／节数量由内容源派生，不手工维护；`assemble_index.py` 的 `derive_metrics()` 统计后写入 `index.html` 的 `doc-metrics`。当前为 76 卷 544 章 3951 节。

## 二、映射层 TSV

目录 `05-卷册大纲/映射/`。字段、状态机与批次的权威说明在 `映射/README.md`，此处只给字段与实测不变量。

### 2.1 `targets.tsv`：目标注册表

12 列：

| 字段 | 取值 | 实测约束 |
| ---- | ---- | -------- |
| `node_id` | `V-NNN`／`C-NNNN`／`S-NNNNNN` | 号段连续无缺号、无重号；一经分配不复用 |
| `level` | `vol`／`ch`／`sec` | 与 `node_id` 前缀一一对应 |
| `parent_id` | 空／`V-`／`C-` | 卷为空；章指向卷；节指向章；实测 100% 合规 |
| `vol_no` | 整数 | 三级节点均填，节与父章一致 |
| `ch_no` | 整数／空 | 章与节均填，节与父章一致；卷为空 |
| `sec_no` | `M.N`／空 | 仅节填写 |
| `title` | 文本 | 读者可见标题 |
| `path_title` | 文本 | 路径与排序用标题；改名过渡期可与 `title` 不同 |
| `status` | `active`／`retired` | 仅此两值 |
| `first_seen` | `YYYY-MM-DD` | 进入注册表日期 |
| `last_seen` | `YYYY-MM-DD` | 最后处理日期 |
| `renamed_from` | 文本／空 | 最近一次改名的旧标题 |

实测：4,578 行 ＝ 卷 77（active 76／retired 1）＋ 章 545（544／1）＋ 节 3,956（3,951／5）；`renamed_from` 非空 1 行。**active 三级计数与 `outline.txt` 派生的 76／544／3,951 相等**，这是 L1 的判据基础。

### 2.2 `mapping.tsv`：映射台账

16 列：`source_id`、`source_relpath`、`source_sha256_pre`、`source_sha256`、`source_title`、`source_section_path`、`status`、`method`、`confidence`、`review_a`、`review_b`、`review_c`、`target_id`、`order`、`review_state`、`note`。

实测 37,484 行，状态分布：`CONFIRMED` 15,206／`UNMAPPED` 14,396／`PENDING` 4,739／`DISPUTED` 3,143；`method` 以三趟评审为主（37,454），另有 `THREE_PASS_RULED` 16、`READJUDICATED_20261026` 14；`review_state` 全为 `JUDGED`。

三条硬关系：

- `target_id` 非空恰 15,206，与 `CONFIRMED` 一一对应，无“已确认却无目标”的行；
- `CONFIRMED` 只在落盘成功后置位（Task 8 口径），落盘前只允许 `PENDING`／`DISPUTED`／`UNMAPPED`／`DUPLICATE`；
- `DISPUTED` 行须在 `review/disputes.tsv` 有对应行（双向差集为零）。

`TARGET_LOST`、`REMAP`、`DUPLICATE`、`DISCARDED` 属台账与挂账口径，现行数据中无这些取值；L12／L15 读的是状态标记与 `target-lost.tsv`／`remap.tsv` 的存在性。

### 2.3 `layout.tsv`：布局清单

7 列：`source_id`、`source_relpath`、`dest_relpath`、`dest_title`、`rename_tags`、`op`、`flag`。

实测 15,206 行，`op` 全为 `move`，与 `CONFIRMED` 行数相等；`dest_relpath` 为自仓库根起的完整路径（`05-卷册大纲/第NN卷-题名/第N章-题名/M.N-题名/M.N.P-题名.md`）；`rename_tags` 记录前缀剥离（`prefix-strip`）与题名复核标记（`title-review:slug`／`truncated` 等）。

## 三、派生视图：`mapping.duckdb`

基表 `mapping`（37,484 行）与 `schema_meta`（1 行），四个视图：

| 视图 | 列 | 语义 |
| ---- | -- | ---- |
| `v_status_dist` | `status`、`review_state`、`n` | 状态×评审态计数 |
| `v_target_dist` | `target_id`、`n` | 每个目标节点被多少旧件指向 |
| `v_coverage` | `total`、`judged`、`pct` | 评审覆盖率 |
| `v_dup_groups` | `source_sha256`、`n` | 同摘要重复组 |

**重要：该库是派生快照，落后于 TSV。** `schema_meta` 自述“只读派生自 `mapping.tsv`，本库未被单独写入”；实测库内仍为落盘前分布（`PENDING` 10,127／`UNMAPPED` 20,923／`DISPUTED` 6,434，无 `CONFIRMED`），与现行 TSV 不一致。凡涉及真值的判断一律读 TSV；库只用于分析，且引用时须注明快照时间。
