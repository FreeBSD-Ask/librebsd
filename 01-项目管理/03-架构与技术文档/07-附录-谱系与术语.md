# 附录：谱系与术语

## 一、BSD 家族谱系（速览）

纯文本全谱见仓库根级 `bsd-family-tree-zh.txt` 与 `bsd-family-tree.txt`（第三方维护的家族树，逐年更新），本处只给主干：

```
Research UNIX (V1–V7)
   └─ 32V ─ 3BSD ─ 4BSD ─ 4.2BSD ─ 4.3BSD
        ├─ 4.3BSD-Tahoe / Reno / Net/2
        │     ├─ 386BSD 0.0/0.1/1.0
        │     │     ├─ FreeBSD 1.0 → 2.x → …（现行主线）
        │     │     └─ NetBSD 0.8/0.9 → 1.x → …（现行主线）
        │     │            └─ OpenBSD 2.3 → …（1995 起分支）
        │     └─ BSD/386 → BSD/OS（商业分支，已终止）
        └─ 4.4BSD / 4.4BSD-Lite / Lite2
              ├─ FreeBSD 2.0 起的合法化基线
              └─ NetBSD 1.x 起的合法化基线
DragonFly BSD（2003 起，自 FreeBSD 4.x 分支）
macOS / Darwin（NeXTSTEP → Rhapsody → Darwin 线，源头为 4.3BSD 系）
Linux（独立起源，1991；与 BSD 共享 UNIX 思想与 POSIX 接口，无代码承袭关系）
```

要点：BSD 与 Linux 是**并行**传统，不是父子；macOS 经 NeXT 承 4.3BSD 系；BSD/OS 与 DragonFly 属旁支。书中涉及承袭关系的断言一律以 `bsd-family-tree*.txt` 与一手史料为准，不以本速览为判据。

## 二、术语

| 术语 | 含义 |
| ---- | ---- |
| 口径 | 卷／章／节的权威计数，唯一来源是 `index.html` 的 `doc-metrics` |
| 内容源 | `05-卷册大纲/目录/data/outline.txt`，题面唯一编辑入口 |
| 落点 | 旧件迁入新树后的目标 `.md` 路径 |
| 映射 | 旧件到目标节点的对应关系，记在 `mapping.tsv` |
| 台账 | 记录状态与证据的 TSV 或表，如 `mapping.tsv`、`layout.tsv`、`title-review.tsv` |
| 件次 | 固定门禁脚本的编号，如第八件装配、第三十七件落地门禁 |
| 阶段 | 工程生命周期 G0–G5 |
| 元门禁 | 检查门禁自身是否登记、可编译、被引用的门禁（第十六件） |
| 常备门禁 | 不涉改动亦须每批执行的四项 |
| 溯源注 | 节行内 `@@〔…〕` 包裹的来源说明，分前置与后置 |
| 分工注 | 卷级 `! ` 行，说明卷际分工与拆并 |
| 自反性声明 | 每卷开头的 `> ` 导言，声明重构性质 |
| ROW_MINE 块 | 大纲中按固定块体格式写入的史料行区块 |
| 派生件 | 由脚本再生、不得手改的产物（`index.html`、`SUMMARY.md`、两个索引 JSON） |
| 半损 | `mapping.tsv` 与 `layout.tsv` 只存在一件的状态，落地门禁判 FATAL |
