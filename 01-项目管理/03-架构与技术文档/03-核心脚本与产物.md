## 二、目录页装配器 `assemble_index.py`

- **唯一写者**：`05-卷册大纲/目录/index.html` 是装配产物，一切修改走本器；手改即违规。
- **四层源**：内容层 `data/outline.txt`、格式层 `assets/doc.css`、现代化层 `assets/modern.css`、行为层 `assets/theme-preset.js` 与 `assets/doc.js`；另有数据层 `data/catalog.json`／`data/schema.jsonld` 与页壳 `assets/page.template.html`。
- **行为层派生**：`assets/doc.js` 由 `src/js/manifest.txt` 按清单顺序拼接；拼接结果与盘面不一致时，常规装配会刷新，`--check` 模式直接判 FAIL。
- **占位符**：页壳用 `{{…}}` 注入；`{{IF:<度量键>}}…{{ENDIF}}` 为同行条件区块，键值为 0 或缺省时整行剔除。
- **口径派生**：`derive_metrics()` 统计卷／章／节／书目／待补项，写 `doc-metrics`；不在源中硬编码数字。
- **幂等与漂移**：`--check` 重装到内存后与磁盘逐字节比对，报首个差异；装配路径写盘后应字节稳定。
- **常见硬失败**：节行格式不符、语言标记 `⟦⟧` 未配对或语言码非法、模板缺占位符——一律 `sys.exit`，不静默降级。

## 三、落地门禁 `audit_outline_landing.py`

对“目录真值、映射台账、磁盘落点、派生件”做 L1–L17 全量一致性审计，是这套判据的唯一执行件。默认只读；`--check` 为兼容门禁调用惯例的等价开关，`--json` 附机器汇总，`--root`／`--map` 可改根。

判据一览（正文见 `流程规则/06-门禁体系.md`）：

| 编号 | 判据 | 依赖映射层 |
| ---- | ---- | ---------- |
| L1 | 树卷／章／节计数等于 `targets.tsv` 中 active 三级计数 | 否 |
| L2 | `CONFIRMED` 每条的 layout 落点文件存在 | 是 |
| L3 | 树内 `.md` 集合等于 `CONFIRMED` 落点集合 | 是 |
| L4 | 文件名 `M.N.P` 与首行 `# M.N.P ` 一致 | 否 |
| L5 | 旧三段号 `0NN.M.P` 未在 `ref-unresolved.tsv` 挂账者判 FAIL | 是 |
| L6 | 落点 SHA-256 无重复组 | 是 |
| L7 | 每条 `CONFIRMED` 落点的父节目录名在 `SUMMARY.md` 有条目行 | 是 |
| L8 | `chapter_keywords.json` 的 schema 为 `theme-index/4`，计数与树一致 | 否 |
| L9 | 落点无 BOM、无 CRLF | 否 |
| L10 | 卷层只允许章目录，章层只允许节目录，节层只允许 `.md` 与 `.gitkeep` | 否 |
| L11 | `layout.tsv` 每条 dest 在磁盘存在 | 是 |
| L12 | `TARGET_LOST` 行须在 `target-lost.tsv` 挂账 | 是 |
| L13 | 超 260 字符落点须在 `path-overlong.tsv`；文件名禁特定字符 | 是 |
| L14 | active 节复合键 `V{卷}-C{卷内章}-{节号}` 唯一 | 否 |
| L15 | `REMAP` 行须挂账且后继为 active 目标 | 是 |
| L16 | 旧二段号 `0NN.M` 未挂账者判 FAIL | 是 |
| L17 | 节目录内 `.md` 与 `.gitkeep` 不得并存；无 `.md` 时须有 `.gitkeep` | 否 |

**SKIP 语义**：依赖映射层的 10 条（L2、L3、L5、L6、L7、L11、L12、L13、L15、L16）在 `mapping.tsv` 与 `layout.tsv` 同时缺失时标 SKIP，不计 FAIL；**只缺一件视为台账半损，直接判 FATAL、退出码 2**（防半损被判绿）。缺 `targets.tsv` 或大纲根不存在同样 FATAL。常时可判的 L1、L4、L8、L9、L10、L14、L17 不因映射缺失而跳过。

## 四、镜像器 `sync_outline_mirror.py`

- **产物三件**写 `05-卷册大纲/` 根级：`SUMMARY.md`、`chapter_keywords.json`、`theme_index.json`。
- **SUMMARY 结构**：`# Summary` 后逐条列表，缩进 0／2／4／6 对应卷／章／节／小节；标题与磁盘目录名、文件名逐字一致。
- **双射校验**：`--check`（缺省）在内存生成后与磁盘逐字节／逐键比对，并跑独立校验器；缺条、树外条、死链、题面改字、缩进错位、`subs` 空键、章键缺多、编号越界均判漂移。**不以条目计数相等替代逐条比对。**
- **写盘**：经 `wo007_idempotency.py` 的 `write_guard()`，回读逐字节校验后 `os.replace` 原子替换；归一化会改写目录名时报 `W_NORM` 拒绝写入。
- **主题索引委派**：2026-10-21 起委派 `build_theme_index.py`，模块缺失时镜像功能可降级运行，但写盘会报错。

## 五、主题索引 `build_theme_index.py`

- **两件产物**：`chapter_keywords.json`（schema `theme-index/4`）与 `theme_index.json`（schema `theme-reverse/2`），均写大纲树根级。
- **取词**：题面 ×3、要点段 ×2、正文 ×1，按小节文档频率计 IDF；最长匹配优先；泛词由词表 `banned` 排除。普通节 3–6 词、元节 1–3 词；小节只存与所属节的差分。
- **节键**：`V01-C001-1.1` 复合键，避免 `N.M` 跨章碰撞。
- **用法**：`--check` 结构＋哈希（快）、`--check --deep` 全量重算（慢）、`--write` 幂等写盘、`--list` 统计、`--selftest` 负向夹具。

## 六、元门禁 `audit_gate_registry.py`

R1 存在性、R2 可编译、R3 无漏接线（`audit_*.py` 全部登记）、R4 有规则引用、R5 套件清单一致、R6 自检覆盖（仅报告）、R7 未登记脚本（仅报告）、R8 阶段映射合法。新增固定脚本必须同时进 `REGISTRY` 与 `STAGE_MAP`，否则 R3／R4／R8 判 FAIL。

## 七、提交门禁 `git_commit_gate.py`

由 `.git/hooks/pre-commit` 与 `.git/hooks/commit-msg` 两条薄壳调用（薄壳不入库，重建 clone 后须重装）：

- **pre-commit（自动改正，不拒收）**：F1 直角引号弯化、F2 不可见字符全口径清理、F3 CRLF→LF 与去 BOM；仅文档类文件，围栏与行内代码按实现口径处理。
- **commit-msg（阻断）**：G1 忽略条目、G2 单个超 5 MB、B2 根目录新增越界、B3 删备份、B4 全角空格、B5 旁路备份副本、H1 提交说明质量、H3 暂存 `.md` 含直角引号。

放行标记与判据正文见 `流程规则/08-Git 与提交.md`。**不设自动化**：钩子只在提交时本地执行，项目无 CI。
