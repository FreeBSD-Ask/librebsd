# 架构与技术文档

本目录是《给我自由——一部 BSD 的历史》编纂工程的**架构与技术说明**，收录系统上下文、真值文件模型、固定脚本、门禁与核查体系、数据层与运维口径。

## 一、定位（派生描述，不是规则）

本模块是**派生视图**（`ADR-0018`）：它描述现状，不制定判据。发生冲突时按下列真值层级取上：

1. 目录页口径：`05-卷册大纲/目录/index.html` 的 `doc-metrics`（唯一机器可读权威，当前 76 卷 544 章 3951 节）。
2. 映射层字段与状态机：`05-卷册大纲/映射/README.md`。
3. 规则判据：`00-编纂规则与格式规范/01-规则/`（门禁、写库、备份、提交、编码等正文只在那里）。
4. 脚本行为：`00-编纂规则与格式规范/01-规则/脚本与命令/` 源码 docstring 与 `--help`。
5. 本模块：以上四者的描述性归纳。

本模块**不复制规则正文**。凡涉及判据、阈值、放行标记、状态机允许值，一律给指针，不在本目录重述。

## 四、维护口径

- **触发同步**：目录页口径变动、映射层字段或状态机修订、固定脚本新增或件次变更、`mapping.duckdb` 重灌、备份体系调整。
- **同步方式**：只改描述与指针，不改判据；改后跑文档门禁（markdownlint、直角引号、加粗空格、不可见字符）与 `audit_engineering_practice.py`、`audit_task_lifecycle.py`。
- **数字纪律**：卷／章／节只在 `doc-metrics` 维护；本模块引用时须标注取数日期，不手写“最新”。
- **失效条件**：规则体系、装配体系或映射层被替换，或连续两批复审出现不可调和漂移，本模块整体重写（`ADR-0018` §8）。
