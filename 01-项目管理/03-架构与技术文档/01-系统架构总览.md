# 系统架构总览

## 一、系统上下文

参与者与系统边界：

| 参与者 | 关注面 | 主要入口 |
| ------ | ------ | -------- |
| 编纂者 | 卷／章／节题面、导言、分工注 | `05-卷册大纲/目录/data/outline.txt` |
| 落地执行者 | 旧树到新树的映射与落盘 | `05-卷册大纲/映射/` 四类台账 |
| 核查者 | 事实、来源、格式、一致性 | 门禁脚本与 `08-核查报告与多轮复核/` |
| 维护者 | 装配、脚本、数据库、备份 | `脚本与命令/`、`12-数据库备份/` |
| 读者 | 浏览器阅读大纲目录 | `05-卷册大纲/目录/index.html` |

系统**不产出正文**：范围为大纲、考据、数据库与目录页（见 `AGENTS.md` 红线 1）。凡把 `05-卷册大纲/` 描述为“正文”的说法均属错误。

## 二、分层与真值

六层单向依赖，下游依赖上游，上游不反向消费下游产物：

```
内容层      data/outline.txt（纯文本行式，零 HTML）
             ↓
映射层      targets.tsv（目标注册表）→ mapping.tsv（映射台账）→ layout.tsv（布局清单）
             ↓
落点层      05-卷册大纲/第NN卷/第N章/N.M/N.M.P-slug.md
             ↓
派生层      SUMMARY.md、chapter_keywords.json、theme_index.json
             ↓
装配层      assets/doc.css、modern.css、theme-preset.js、src/js/manifest.txt → doc.js、data/catalog.json、data/schema.jsonld、page.template.html
             ↓
产物层      05-卷册大纲/目录/index.html（唯一写者为 assemble_index.py）
```

要点：

- **内容层是题面唯一编辑入口**：卷／章／节题、卷导言、分工注只在 `outline.txt` 改；改 `index.html` 属违规。
- **映射层三表分工**：`targets.tsv` 给稳定节点身份，`mapping.tsv` 记旧件去向与状态，`layout.tsv` 记已确认落点的目标路径。字段与状态机以 `05-卷册大纲/映射/README.md` 为准。
- **派生层由脚本再生**：`SUMMARY.md`、`chapter_keywords.json`、`theme_index.json` 都是派生物，手改即漂移。
- **装配层四层解耦**：格式、现代化、行为、数据各自独立成文件，装配器只做拼接与占位符替换。

## 三、端到端数据流

1. **旧树清点**：只读扫描 `旧大纲-20261023/`，产出 `inventory.tsv`、`path-coupling.tsv`、`old-tree-normalization.tsv`。
2. **目标注册**：为新树卷／章／节分配 `V-`／`C-`／`S-` 节点 ID，落 `targets.tsv`。
3. **映射判定**：旧件逐条判定并写 `mapping.tsv`（三趟评审记录在 `review_a`／`review_b`／`review_c`）。
4. **落盘**：已确认件 `git mv` 到目标路径，同时写入 `layout.tsv`；落盘成功前 `status` 不置 `CONFIRMED`。
5. **派生再生**：`sync_outline_mirror.py --write` 生成根级三件；`assemble_index.py` 重新装配 `index.html`。
6. **门禁**：`audit_outline_landing.py` 跑 L1–L17；通过后跑目录页九件与三套浏览器回归。

旧树为只读快照，取证入口是 Git 标签 `outline-pre-landing-20261023`；迁移已按批消耗旧树，现盘 `.md` 数量小于迁移前（详见 `映射/README.md`）。

## 四、关键设计取舍

| 取舍 | 选择 | 理由 | 代价 |
| ---- | ---- | ---- | ---- |
| 真值载体 | TSV＋`outline.txt` 纯文本 | 可 diff、可逐行评审、不被编辑器自动格式化 | 无类型约束，靠门禁与脚本校验 |
| 数据库角色 | DuckDB 作分析层 | 列式、离线批量、SQL 友好 | 库是派生快照，会滞后于 TSV，不能当真值 |
| 目录页形态 | 单体自包含 `index.html` | 离线可读、无外部依赖、单一交付物 | 体积与装配时间随内容增长 |
| 分层 | 四层解耦 | 作者只碰 `outline.txt`，样式与行为独立演进 | 装配器是单点，改模板须全量回归 |
| 门禁实现 | 一个总门禁＋若干专件 | 判据集中（L1–L17 单一执行件），专件各管一面 | 件次与触发面须靠元门禁维持接线 |

## 五、可扩展点

- **新增 L18 及以后判据**：改 `audit_outline_landing.py` 的 `run_gate()`，在 `流程规则/06-门禁体系.md` 的判据表登记语义与 SKIP 面，补负向夹具，保持退出码 0／1／2 语义。
- **新增固定脚本**：先落 ADR（`工程实践规则.md` §2.1），再进 `脚本与命令/`，在 `audit_gate_registry.py` 的 `REGISTRY` 与 `STAGE_MAP` 登记，否则元门禁 R3／R4／R8 判 FAIL。
- **新增映射状态**：先改 `映射/README.md` 的状态机，再核 L1–L17 中落点、挂账、后继、复合键的影响面。
