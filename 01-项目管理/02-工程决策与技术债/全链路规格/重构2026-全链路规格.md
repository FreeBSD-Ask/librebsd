# 重构2026 目录页及关联项目全链路规格

- **规格编号**：SPEC-R2026-001
- **日期**：2026-10-22
- **依据**：`ADR-0003`、`ADR-0004`、`ADR-0006`；`全链路工程化审计-20261022.md` §三；`工程实践规则.md` §1；`流程规则.md`“重构大纲目录口径同步规则”“门禁体系元门禁”“重构大纲目录四层解耦与装配规则”

- **性质**：线级需求与验收基线。本规格给编号、二值判据、证据位置与证伪条件，不替代任务书；任务书仍是操作入口，规则正文仍以 `00-编纂规则与格式规范/01-规则/` 为准。

## 范围

本规格覆盖重构2026 目录页从内容源到归档的工程链路，对象是“怎么产出与怎么验收”，不是“目录写什么”。阶段与条目对应如下：

| 阶段 | 输入→输出 | 本规格条目 |
| ---- | --------- | ---------- |
| 内容源 | `data/outline.txt`→卷／章／节题与溯源注 | FR-R01 |
| 装配 | 六类装配源→`index.html`，`src/js` 清单→`assets/doc.js` | FR-R02 |
| 数据层 | `data/catalog.json`→压缩数据块与完整性摘要 | FR-R03 |
| 资产层 | `doc.css`／`modern.css`／字体子集／品牌件→页面资产 | FR-R04 |
| 服务器 | 产物→HTTP 契约 | FR-R05 |
| 浏览器回归 | 产物→三套 `.mjs` 套件 | FR-R06、NFR-R07 |
| 无障碍 | 产物→axe-core 与键盘契约 | FR-R07 |
| 口径同步 | 产物 metrics→全库口径声明与 ADR 预算注记 | FR-R08、NFR-R01–NFR-R04 |
| 号文与归档 | 批次证据→92／98 号文、changelog | FR-R09 |
| 元登记 | 门禁体系自身→登记表、阶段表、自检声明 | FR-R10、FR-R11、FR-R12 |

## 非目标

- 不增删、不改写卷／章／节内容与题面；内容批次由目录内容规则主导，本规格只约束其工程出口。
- 不改 `05-卷册大纲/目录/data/outline.txt`、`assets/doc.css`、`assets/modern.css`、`src/js/`、`assets/page.template.html`、`server/`、字体源；本规格只登记其权威性与验收面。
- 不改写 70—151 号文历史；历史快照按“历史豁免原则”整体不动。
- 不吸收 152 批工作区改动；该批在途改动属他会话，本规格不纳入、不评判、不代改。
- 不重构 `embed.py`、`font_subset_rebuild.py` 的写盘行为；是否收归装配器列为挂账，等 ykla 裁定。
- 不引入多页架构、前端框架、打包器或外部依赖；不改变读者可见的交互与视觉设计。
- 不覆盖 F1–F4、H1–H4 三条线；三线登记见 `全链路规格/index.md`，本规格不代行其判据。
