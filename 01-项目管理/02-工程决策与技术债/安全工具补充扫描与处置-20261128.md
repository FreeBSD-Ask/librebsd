## 4. 已修复（4 条）

### 4.1 `assemble_index.py`：JSON-LD 注入值转义（FIXED）

Semgrep 在 `page.template.html:93` 报 `var-in-script-tag`。该行是 `<script type="application/ld+json">{{JSONLD}}</script>`，JSON-LD 的 `hasPart` 卷名由数据注入；若卷名含 `</`，HTML 解析器会提前闭合 script 元素。`UI_JSON` 早已按 `</` → `<\/` 转义，JSON-LD 没有。

改法：`"JSONLD": schema.strip("\n").replace("</", "<\\/")`，与 `UI_JSON` 同口径。当前 `schema.jsonld` 与卷名均无 `</`，装配产物零漂移（`assemble_index.py --check` 报“无漂移”）。

### 4.2 `backup_databases.py`：归档解包加 data 过滤（FIXED）

Semgrep（`trailofbits.python.tarfile-extractall-traversal`）在备份验证路径报 `tarfile.extractall(dst)`。归档来自历史备份槽或人工放置件，理论上可含 `../`、符号链接或设备文件。

改法：`tar.extractall(dst, filter="data")`（PEP 706；Python 3.12+ 支持，本项目运行时 3.15）。data 过滤拒绝越界路径、链接与特殊文件，备份验证行为不变。

### 4.3 `verify_tuhs_wiki.py`／`verify_tuhs_wiki_sql.py`：SSRF 前置防线（FIXED，承父 PR）

Semgrep 在 `urlopen` 处报 `dynamic-urllib-use-detected`。两件已在 Mimosa 批加入 `ssrf_rejection()`：仅 http／https 公网地址、拒 URL 内嵌凭据、解析后逐地址 `is_global` 校验；selftest 各增 4 例。本分支基于该批，修复随父 PR 一并审查。

## 6. SonarQube 实测记录

连接：`https://sonarcloud.io`，org `freebsd-ask`，token 存 OS Keychain，`sonar auth status` 返回已连接。项目 `FreeBSD-Ask_librebsd` 已存在。

实测四项：

1. **项目状态**：`sonar quality-gate status` 返回“Not computed”——该项目从未分析过（main 分支无分析记录），`sonar list issues` 为 0 条。SonarCloud 侧没有可复用的规则扫描结果。

3. **SCA**：`sonar analyze dependency-risks` 返回“Software Composition Analysis is not available for the current connection”，当前计划不含 SCA。
4. **Secrets（本地）**：唯一可全量执行的 Sonar 能力。目录级调用受 60 秒硬超时限制，改为按 git 跟踪的代码与配置文件分批（每批 80 件），共 17 批 1 356 件，0 超时。

## 7. Claude Security 未运行登记

本会话工具集中没有 `Workflow` 工具，而 Claude Security 的 `claude-security:scan` 只能作为该 Workflow 运行；插件契约明确禁止由主代理自派 researcher／verifier 冒充管线，也不允许手写 `votes.json`，否则报告会声称一次并未发生的验证。按契约，本批未运行扫描、未创建 `CLAUDE-SECURITY-*` 目录、未写任何 findings 文件。

若后续要跑：需在 ZCode 侧启用 Dynamic workflows（`/config` 有对应行）并重启会话，使 `Workflow` 工具可用；随后以“全仓 high”重新发起。该批与本批的 Semgrep 结果互补：Semgrep 是规则匹配，Claude Security 是研究者＋三票验证面板。

## 8. 覆盖边界与残余风险

1. **Semgrep 未覆盖 54 万件第三方语料**：`03-原始史料库` 的邮件存档、克隆源码与 `dvd6/`、`旧大纲-20261023/` 属外部数据，不是本仓发布面；对其跑规则只会在上游代码里产生噪声。其本机工作脚本（`.py`）已覆盖。
2. **Secrets 未扫 6.5 万件 `.md` 与 7 000 件 `.tsv`**：为避开 60 秒超时与语料噪声，本批只扫代码与配置白名单（1 356 件）。Semgrep `p/secrets` 对 188 件跟踪代码的扫描为 0 命中；`.md` 语料中的“口令”多为引文与示例，若需逐字排查应另立语料专项。
3. **Sonar 规则引擎缺席**：Vortex 403、SCA 不可用、项目无分析，意味着本批没有 Sonar 的规则库结论；只有 Secrets 一项生效。
4. **Semgrep 是模式匹配**：212 条全部为静态命中，未经动态复现；FIXED 判定以代码审读与项目门禁为准，不等于“已证明无漏洞”。
5. **规则噪声**：SQLAlchemy 与 formatted-sql-query 两类规则对本仓引擎与写法系统性误报，116 条已逐条回读，但未来新增脚本仍会被同一规则命中，需在报告中持续解释而非逐条改代码。
