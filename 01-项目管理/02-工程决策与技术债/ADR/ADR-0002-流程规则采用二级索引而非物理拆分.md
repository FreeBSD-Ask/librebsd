# ADR-0002：流程规则采用二级索引而非物理拆分

- **状态**：已接受
- **日期**：2026-10-22
- **裁决人**：主理人
- **执行者**：主代理
- **复审日期**：2027-04-22
- **替代关系**：无

## 1. 形式

在 `流程规则.md` 顶部增加“二级索引（按域）”标记块，按六个域列出全部 H2 小节；`audit_engineering_practice.py` 新增 E7，校验索引条目与 H2 标题集合严格一致。物理拆分不在本批执行。

边界：索引只覆盖 H2；H3／H4 仍靠全文检索。索引不复制判据正文，只做导航。

## 2. 矛盾

`流程规则.md` 已 249,573 B、50 个 H2、84 个 H3、35 个 H4，检索与复审成本高；若不治理，规则改动易漏引用，复审者难以确认是否读完相关小节。

受影响者：主代理（执行与复审）、主理人（审批与抽查）、后续接手会话。

## 3. 正面

- 不触碰 152 个引用 `流程规则.md` 的文件，避免大规模改指针与门禁 R4 失效；
- 顶部索引给出按域导航，复审者可在数秒内定位相关域；
- E7 把索引与标题集合绑定，章节增删后索引漂移即 FAIL；
- 为未来物理拆分保留决策入口：若索引仍不足，可按 ADR 拆分。

验证方式：`audit_engineering_practice.py` E7 正样本 PASS、负向夹具命中；索引覆盖 50 个 H2。

## 4. 负面

- 文件体积未降低，单文件仍约 250 KB；承担者：主代理与复审者；
- 索引只到 H2，H3／H4 仍需全文搜索；承担者：执行者；
- 维护成本：新增 H2 时必须同步索引，否则 E7 FAIL；承担者：改规则的人；
- 索引本身可能变成形式：若无人使用，只是多一个表；承担者：复审者。

## 5. 承担者

| 负面 | 承担者 | 承担时点 |
| ---- | ------ | -------- |
| 单文件体积 | 主代理、复审者 | 每次规则检索与复审 |
| H3／H4 未索引 | 执行者 | 深度检索时 |
| 索引同步 | 改规则的人 | 新增／删除 H2 时 |
| 索引空壳化 | 复审者 | 季度复审 |

## 6. 过去依据

- 2026-10-22 规则治理专项实测：`流程规则.md` 249,573 B，占规则总字节约 55%；全库 152 个 `.md` 引用它。
- 项目此前已多次因“工具已文档化 ≠ 工具已生效”失效；单靠文档目录不足以防止漂移，必须有门禁。
- 2026-09-28 门禁体系元门禁已证明：登记表、磁盘与规则文档三方一致可以机检；本 ADR 把同样思路用于章节索引。

## 7. 现在依据

- 2026-10-22 实测：50 个 H2、84 个 H3、35 个 H4；索引块覆盖 50 个 H2。
- E7 自检：正样本 0 FAIL；负向夹具“索引条目与 H2 不一致”被命中。
- 物理拆分的代价：152 个引用文件、`audit_gate_registry.py` R4、`AGENTS.md` 门禁表、`脚本与命令/README.md` 与多个门禁脚本的规则位置都需同步；本批风险不可接受。

## 8. 将来失效条件

出现下列任一条件时，本 ADR 应复审或替代：

1. `流程规则.md` 超过 300 KB 或 H2 超过 60 个，索引仍不能支持检索；
2. 复审者连续两次反馈“按索引找不到相关小节”；
3. 物理拆分获得独立 ADR，且迁移脚本、旧路径指针与 R4 校验方案就绪；
4. 规则体系改用外部文档平台或自动生成的目录，索引块不再是唯一导航。

## 9. 0 信任校验

- 规模与引用面数据来自 `script/_rule_governance_audit_20261022.py` 的只读输出；
- E7 正负样本由 `audit_engineering_practice.py --selftest` 实测；
- 独立复现：`C:/Python314/python.exe 00-编纂规则与格式规范/01-规则/脚本与命令/audit_engineering_practice.py`。
- 原始证据：`规则治理专项审计-20261022.md` §2、§4。

## 10. 自由影响

- 不改变读者可见界面；不影响退出、导出、离线能力；
- 索引与规则均为仓库内开放文本，可导出、可替换；
- 不引入账户、联网、遥测或私有格式锁定。

## 11. 安全和解

- 资产：规则文本、索引、门禁脚本；
- 对手：误删 H2、索引漂移、批量改写未同步；
- 攻击面：规则文件写盘、Git 暂存；
- 信任边界：主代理执行，主理人批准；
- 现有控制：E7、markdownlint、引号与不可见字符门禁、Git 暂存门禁、changelog；
- 残余风险：E7 只校验标题集合，不校验索引分组语义；H3／H4 未覆盖；
- 证据：E7 自检与实跑；
- 代价：新增 H2 时须同步索引；
- 失效条件：规则文件被整体替换或索引块被删除（E7 会 FAIL）。

## 12. 复审触发

- 时间：2027-04-22；
- 事件：`流程规则.md` 超过 300 KB 或 60 个 H2、复审者两次反馈索引不足、物理拆分立项、规则平台迁移；
- 复审动作：评估是否升级为 H3 索引或物理拆分；结论写入 `工程实践复审台账.md`，必要时替代本 ADR。
