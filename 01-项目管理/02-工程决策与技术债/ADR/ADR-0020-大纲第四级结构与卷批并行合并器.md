# ADR-0020：大纲第四级（小节）结构、targets 注册与卷批并行合并器

- **状态**：已接受
- **日期**：2026-11-06
- **裁决人**：ykla
- **执行者**：主代理
- **复审日期**：2027-02-06
- **替代关系**：无（与 `ADR-0015` 目录真值派生互补：三级结构真值不变，本 ADR 增第四级）

## 1. 形式

- **四级行格式**：`目录/data/outline.txt` 在节行（`- M.N 题名`）下增第四级小节行，形制＝**两个前导空格 ＋ `- M.N.P 题名`**（M＝章号、N＝节号、P＝节内小节号；P 自 1 连续递增）；小节行支持与节行同一套 `@@` 定界注文（前置紧跟节号、后置在行尾）。节内小节号连续、唯一、前两段与父节号一致；题名非空；禁 ABCD 等字母后缀（承 AGENTS.md 章题禁例）。
- **磁盘形态不变**：小节仍是一树内 `.md` 文件（`M.N.P-slug.md`，无小节级目录）；**每个小节必须有 `.md`**（有史料填块，无史料建空骨架），不允许只有 outline 行无 `.md` 的"设计级"。
- **装配与页面**：`assemble_index.py` 为四级唯一解析与渲染入口——正文区节 `<li>` 下嵌套 `<ul class="subsections">`（含 `M.N.P` 编号与深链锚点 `vol-V-ch-C-sec-M-N-sub-P`），无脚本静态 TOC 与动态 TOC 同步嵌套；`doc-metrics` 增总小节数（N_SUB，计全部小节含空骨架）；页首 meta／og 描述与页脚口径串同步为四级口径。
- **targets 第四级**：`映射/targets.tsv` 新增 `level=subsec` 节点，稳定 ID `SS-` ＋ 7 位零填充全局序号（`SS-0000001` 起），`sec_no` 列承载 `M.N.P` 三段形态；列结构不变；三级节点与既有 ID 一律保留、不替代。
- **合并器单写者**：`outline.txt` 的小节行唯一写者＝新合并器 `merge_subsections.py`（按卷序合并已批准 fragment，复合键 `V/C/S`，幂等）；只合并 `approved/V{NN}.title.ok` 与 `.land.ok` 齐备且 `ledger_sha256` 与当前台账一致的卷；`index.html` 唯一写者仍为 `assemble_index.py`。
- **边界**：不撰写正文；不改三级结构（升格提案另批）；不手改 `index.html`；旧树只读。

## 2. 矛盾

- 不做的后果：目录页与 `outline.txt` 看不到小节，小节继续是磁盘史料装箱；Task 3A 已批准的 19 461 题没有落点；76 卷并行生产无合并协议，`outline.txt` 多写者必然互踩。受损者：读者（目录不可读出论证结构）、正文批（无宿主）、各并行会话（写冲突）。
- 受影响者：ykla（批准与验收）、主代理（施工）、第七件／第三十七件等门禁维护线、三套浏览器回归基线、CI 结构层。

## 3. 正面

- 能力：四级同源（outline ↔ targets ↔ 页面 ↔ 磁盘 `.md` 双射可审计）；四源定题有落点；小节簇升格有据；fragment 幂等合并支撑按卷并行与中断续跑；门禁可在数据落盘前先建成（本批 outline.txt 零小节行、产物零漂移）。
- 受益者：读者、ykla、Task 6—8 各批会话、门禁与 CI 维护线。
- 验证方式：`assemble_index.py --check`；第七件（小节编号组）；第三十七件 L1 四级计数＋L19 三向双射；第三十八件 `audit_subsection_design.py`；合并器 `--check`／`--selftest`；目录页九件与三套浏览器回归；第二十九件 E1/E2。

## 4. 负面

- 成本：装配器、TOC 引擎、面包屑、数据视图、第七件、第三十七件、targets 再生器、口径同步器、CI 共九处同批改动；三套浏览器回归断言更新；字体子集随小节题新用字重建（内容批阶段）。
- 风险：行为层遍历 `ul.sections` 的 5 处 JS 对嵌套 `<ul>` 的计数与注入须逐一适配（已知 `90-data-views.js` 节数统计会误计嵌套 ul）；`doc-metrics` 口径变更牵动 AGENTS.md 基准块、`schema.jsonld`、92／98 号文与长线登记表；第四级数据入库后产物体积显著增长（O17 膨胀守卫将告警，属预期）。
- 边界：本批不写入任何实际小节行（outline.txt 不动）；N_SUB 初值 0；"设计级豁免"自本 ADR 生效即废止。

## 6. 过去依据

- 历史条件：2026-10-28 落地 15 206 件为史料装箱（单件中位 15 976 B、题面不合格 68.4%、题指纹命中率 6.4%、642 节目录平均 23.7 件）；2026-10-29 ykla 令置零并确立"大纲文件加第四级""小节注册为第四级节点""不允许设计级，每小节必须有 .md"。

## 8. 将来失效条件

1. 2—12 小节分布无法承载 16 797 B 承载规则且升格／档案节方案均不适用；
2. 页面嵌套渲染在真实数据量（约 2.0—2.8 万小节）下性能不可接受且无等效降级；
3. 合并器幂等或 hash 校验在并行批中被证明不可靠（复合键冲突、断点重跑漂移）;
4. 出现比"outline 四级行＋SS 稳定 ID"更少变动、更可核验的小节结构载体。

## 10. 自由影响

- 退出：目录页保持无脚本可读（静态 TOC 含小节嵌套）；不引入登录或 JS 依赖。
- 导出：SUMMARY／JSON／CSV 导出在数据视图适配后含小节层级。
- 离线：全部本机执行；页面仍自包含单体。
- 默认值可撤销性：本 ADR 可被后续 ADR 替代；`outline.txt`／`targets.tsv` 改动走 Git revert；fragment 保留可重跑。

## 11. 安全和解

- 资产：`outline.txt`、`index.html` 装配源、`targets.tsv`、映射台账、76 卷标题批准件。
- 对手：多会话并发写 outline、未批卷混入合并、fragment 重复插入、装配器与小节门禁假设漂移。
- 攻击面：合并器（唯一四级行写者）、`assemble_index.py`（唯一页面写者）、批准 hash 校验。
- 信任边界：会话只写本卷 fragment；合并器与装配器单写者；ykla 批准件为放行凭证。
- 现有控制：`approved/*.ok` 与 `ledger_sha256` 校验、复合键唯一、幂等合并、门禁全链、`commit.lock` 串行化；回滚以 Git 为唯一载体（承 `ADR-0016`）。
- 残余风险：语义归属错判由例外报告兜底；产物膨胀由 O17 守卫告警。
- 证据：Task 5 门禁输出；Task 6—8 每卷批 done 记录。
- 代价：每卷批一次合并＋重装配＋全链门禁。
- 失效条件：见 §8。

## 附：替代方案与取舍

| 方案 | 正面 | 负面 | 为何未选 |

| A：小节只进 outline 不进 targets | 改动面最小 | targets 与磁盘 `.md` 无四级对位，L1 无法守恒校验；mapping／layout 无法延伸到 subsec | 违背"小节注册为第四级节点"（ykla 2026-10-29） |
