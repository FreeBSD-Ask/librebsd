# ADR-0022：目录页数据层 persons 段真值归位——catalog.json 改为人物真值库的派生投影

- **状态**：已接受（2026-11-21 ykla 对 catalog-recon 线方案全量批准）
- **日期**：2026-11-21
- **裁决人**：ykla
- **执行者**：主代理
- **复审日期**：2027-02-21
- **替代关系**：无（承接 120 号文人物治理与第十五件门禁的派生面延伸）

## 1. 形式

- 唯一真值＝`10-交叉索引/cross_indexes.duckdb.person_bio_research` 全表（第十五件门禁对象）；目录页数据层 `05-卷册大纲/目录/data/catalog.json` 的 persons 段改为**派生投影**，唯一写者＝`00-编纂规则与格式规范/01-规则/脚本与命令/export_catalog_data.py`（从库全表派生：id 顺序重排 p-NNNN、names/status/affiliations 形态转换、别名净化剔邮箱与 `person_id_(legacy|new):` 等内部标识串、混形 `alive_status` 归一）；**禁止手工编辑 catalog.json persons 段**。refs/revs 段 v1 透传（refs 真值归位由长线承接后导出器升级 v2 接管）。产物链：派生 → `assemble_index.py` 重装配 → DATA 门禁维度 5（产物 blob 与库派生逐字节比对；CI 库不可达降级 INFO 跳过）→ 三套浏览器回归。人物新增/修订只写库（写库门禁＋P1—P4 判据），幻觉人物（120 号文定谳者）不入库。

## 2. 矛盾

- 不做的后果：双真值并行漂移继续扩大——实测目录页侧在册已定谳幻觉人物 Christina Loconti（120 号文）、缺 CSRG 官方名单等 16 名真值库在册人物、Corbató／ESR 同人两行；目录页作为对外唯一交付物承载事实错误。
- 受影响者：目录页读者（人物数据正确性）；后续人物维护会话（单点写入纪律）；refs 维护线（过渡期手工池仍在）。

## 3. 正面

- 能力：人物维护单点化（写库＋派生），门禁闭环（第十五件管库、DATA 维度 5 管投影）；CSRG 官方名单等真值库修复首次全量投影进目录页；15 名差缺人物 0 信任核验入库（五处字段级存疑显式落 doubt_flags）。
- 受益者：目录页读者；后续人物批（不再双写）；refs 真值归位长线（先例与导出器骨架）。
- 验证方式：`export_catalog_data.py --check` 逐字节一致；`audit_data_integrity.py` 0 违例（含维度 5）；三套浏览器回归 25/25、628/628、27/27（T3 人名浮层实测新数据渲染）。

## 4. 负面

- 成本：catalog.json persons id 全量重排（2 269→2 280，已核实 JS 仅用 length 与遍历、无外部 id 引用）；导出器三处库存量形态兼容分支（affiliations JSON 串／None 字面／别名污染）。
- 风险：`volume` 字段透传库 `vol_ch` 的旧编号语义（'346' 式）为已知漂移，展示层语义待 refs 线清理；DATA 门禁假绿缺陷修复后暴露存量污染（14 处，已净化）。
- 边界：不承担 refs 段真值归位（长线承接）；不承担目录页本体结构改动（opt-data-blob 内嵌等自包含设计维持，ADR-0006）。

## 5. 承担者

| 负面 | 承担者 | 承担时点 |
| ---- | ------ | -------- |
| volume 旧编号语义漂移 | refs 真值归位线 | 长线批次 |
| refs 段手工池与库漂移继续（过渡期） | refs 真值归位线 | v2 接管前每批 DATA 门禁披露 |
| 导出器形态兼容随库形态演进失效 | 主代理 | 派生批次跑 --check 时暴露 |

## 6. 过去依据

- 120 号文（2026-10-06）：Loconti 幻觉定谳与 CSRG 官方名单补库——真值库侧已按正确结论修复，目录页侧未同步，双真值漂移已致事实错误。
- 第十五件门禁（2026-10-06 立）：人物库 0 信任判据（P1 sources／P2 doubt_flags／P3 check_date／P4 priority）——真值侧治理已成形，缺派生面。
- AGENTS.md 数据库五条通则第 2 条（claim 库唯一真值）与红线 2（装配产物唯一写者）——本决策为二者在目录页数据层的落实。

## 8. 将来失效条件

- 人物真值迁移出 `cross_indexes.duckdb`（如并入统一身份库）——派生器需换真值源并重审本 ADR。
- 目录页 DATA 段改为构建期直读库（如 VitePress 线 ADR-0021 的 data loader 直读扩展到 persons）——派生 JSON 中间层失效，本 ADR 由该线承接后废止。
- refs 段 v2 接管完成后 persons/refs 派生合并为单一数据层契约，本 ADR 的 persons 专节可并入。

## 9. 0 信任校验

- 对账不采信任何一侧计数：catalog 2 269／库 2 265 双向逐行匹配（三轮判据递进，第二轮 4 例 Jaccard≥0.4 近似经人工复核判为错配排除）。
- 15 人核验逐人独立来源（不采信 catalog 旧档自我循环）；未独立确证字段（Weiss/Ylönen 生年、钱华林月分、Green/Troup 机构、Applebaum 生卒）保留旧值并落 doubt_flags，不臆造、不静默丢弃。
- Loconti 不做"再核验后收编"——直接采 120 号文人物级否定判定（官方名单 0 命中），避免幻觉人物经派生回流。
- 导出器净化判据与 DATA 门禁判据 2／3 同口径互证（邮箱与内部标识串双面拦截）。

## 10. 自由影响

- 人物数据单点真值化不改变叙事自由度：人物取舍与详略仍由卷批与人物库轮次决定，目录页只投影；无新增叙事约束。
- 库 schema 不变（零 DDL 变更），其他消费方（章节元数据、交叉索引）不受影响。

## 11. 安全和解

- 写库侧：guard PASS＋waterlock pre/post 落槽＋专项正式备份 `20261121_010451.duckdb.gz`（parquet-tar-gz 三段校验 integrity=ok），失败路径由备份回灌（load.sql 逻辑导出口径）。
- 幻觉人物出清是对既有事实错误的和解性修正（不掩盖——120 号文结论与出清动作均在批记留痕）。
- 多会话同树：他线 V74 批（id=3397）在窗口内先行装配污染版 catalog，本批净化版重装覆盖，装配 `--check` 归一；changelog 取号撞 3404（G8 retitle-V74-c3 竞速）跳段改号 3405 留痕（G3 先例）。

## 12. 复审触发

- refs 真值归位长线完成（v2 接管）时复审本 ADR 的数据层契约是否统一。
- 任何一次派生 `--check` 或 DATA 维度 5 FAIL（库形态演进、派生逻辑漂移）时复审导出器判据。
- 复审日期 2027-02-21（季度例行）。
