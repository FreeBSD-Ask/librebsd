# ADR-0009：验证单元采用读写一体循环

- **状态**：已接受（有条件生效）
- **日期**：2026-10-22
- **裁决人**：ykla
- **执行者**：主代理
- **复审日期**：2027-01-22
- **替代关系**：补充 ADR-0001／ADR-0006／ADR-0008，不替代其他 ADR
- **生效条件**：TD-015 补齐 L3 逐条内容回读、L5 stdout 可见并复跑循环通过；条件满足前，新批次按 L0–L5 执行但不得宣称“全局生效”，在途批次不追溯

## 1. 形式

本决策把验证单元固定为一条可判原则：

- **验证单元＝一次完整读写循环**：`读入 → 写入 → 回读 → 还原`。不是两个阶段，也不存在“先写后读”或“先读后写”的优先顺序。
- **六项断言**：
  - `L0` 生产零改动（前置）；
  - `L1` 读入真实（N 个单位）；
  - `L2` 写入真实（M 条到生产等价副本）；
  - `L3` 回读一致（逐条内容比对，不只比计数）；
  - `L4` 幂等＋还原（内容级幂等判据、二跑 +0、回滚哈希复原）；
  - `L5` 失败环可见（坏件停摆、stdout 可见计数、零写入）。
- **边界**：纯阅读型任务可书面声明“无写入面”，只执行 L1／L0；在途批次不追溯；不新增门禁编号，L0–L5 以批次收口检查清单执行。

## 2. 矛盾

- 不做的后果：260 单位演练只走读侧半环，写侧一行未验；首次补写侧即暴露 TD-015（入纲脚本路径全失效、文件级幂等会重复插入 493 块，推算重复 464–466 块）。历史最严重的 2026-10-13 广播事故（472,510 行覆盖）也发生在写侧。
- 受影响者：主代理（验证范围与顺序）、ykla（验收）、复核者（判据是否覆盖写侧）、接手者（复现与续跑）。

## 3. 正面

- 能力：任一链路的“通过”都必须同时有读侧观察、写侧后果与回读证据；半环结论不能再冒充全链验证。
- 受益者：ykla、复核者、接手会话。
- 验证方式：TD-015 试点 L0–L5（H／F 两线）；`script/_pilot_20261022/theory_pilot_h/PILOT.md`、`theory_pilot_f/PILOT.md`；`audit_engineering_practice.py` E1–E7。

## 4. 负面

- 成本：每批增加一次真实写入与回读；沙箱化需处理硬编码常量（F 线已发现 `ROOT`／`JUD`／`WORK`／`OVER22`／`PROC`／`--ledger` 漏网）。
- 风险：回读成本高；沙箱与生产不等价会得出假结论；L5 的 stdout 判据要求改既有脚本输出。
- 边界：本轮不修生产脚本；TD-015／TD-016 承担修复；在途批次不追溯。

## 5. 承担者

| 负面 | 承担者 | 承担时点 |
| ---- | ------ | -------- |
| 每批循环成本 | 主代理 | 每批收口 |

| L5 stdout 改造 | 主代理 | TD-016 修复时 |

## 6. 过去依据

- 2026-10-22 两轮共 260 单位演练只覆盖读侧：读侧查出认领清单 0/1,097 命中、“行≠封”、非数字 pk 静默跳过；写侧空白。
- 2026-10-22 首次写侧演练：H 线块级判据 +0、文件级判据首跑 +16（生产 493 块推算重复 464–466）；F 线二跑 +0；两线 L0 PASS；L3 内容回读未做、L5 stdout 可见 FAIL。
- 2026-10-13 广播事故：单条缺关联 UPDATE 覆盖 472,510 行。
- 2026-10-22 ykla 裁定：“不是写先于读，读写本为一体”。

- 测试：TD-015 试点，H／F 两线沙箱，生产零写入；报告见 `script/_pilot_20261022/theory_pilot_h/PILOT.md`、`theory_pilot_f/PILOT.md`。

## 8. 将来失效条件

1. 出现无写入面的纯阅读线成为主流；
2. 出现比完整循环更早暴露真值的验证单元；
3. L0–L5 在三个批次内被两次证明不可执行；
4. 回读成本高到单批无法完成且无等价替代。

## 9. 0 信任校验

- 独立复现：TD-015 试点报告中的命令与原始输出；L0 生产聚合哈希；L4 二跑计数；L5 坏件注入。
- 交叉验证：沙箱宿主 SHA-256 与生产一致；临时库四表结构由生产 `LIMIT 0` 复制；门禁与 `--selftest` 对照。
- 原始证据：`script/_pilot_20261022/theory_pilot_h/PILOT.md`、`theory_pilot_f/PILOT.md`、`drill_h/H-drill.md`、`drill/F-drill.md`。

## 10. 自由影响

- 退出：不改变读者可见界面。
- 导出：规则与报告均为普通 Markdown／Python。
- 离线：全部本机执行。
- 默认值可撤销性：条件生效由 ykla 判定；可开新 ADR 替代。

## 11. 安全和解

- 资产：生产大纲、claim 库、台账、认领清单、宿主文件。
- 对手：半环验证导致的假绿、硬编码路径、文件级幂等、stderr-only 静默失败、沙箱逃逸。
- 攻击面：脚本常量、幂等判据、输出通道、沙箱路径。
- 信任边界：主代理执行、ykla 批准、复核只读。
- 现有控制：L0 哈希、副本链、`commonpath` 建议、selftest、changelog。
- 残余风险：L3 内容回读与 L5 stdout 尚未在生产工具中落地；沙箱常量仍有漏网。
- 证据：试点报告与 TD-015／TD-016。
- 代价：每批一次真实写入＋回读。
- 失效条件：见 §8。

## 附：替代方案与取舍

| 方案 | 正面 | 负面 | 为何未选 |
| ---- | ---- | ---- | -------- |
| 写先于读 | 看似突出写侧 | 仍是二分法，回读缺席时仍会假绿 | ykla 裁定“读写一体” |
| 只加写侧演练、不改验证单元 | 成本低 | 读侧判据仍可脱离写侧自证 | 不能消除半环假绿 |
| **读写一体循环 L0–L5（本件）** | 可判、可复现、覆盖静默失败 | 每批成本上升；需修 L3／L5 | 采用 |
