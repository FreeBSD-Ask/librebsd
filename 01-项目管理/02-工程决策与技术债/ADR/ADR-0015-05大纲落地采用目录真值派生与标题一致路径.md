# ADR-0015：05 大纲落地采用目录真值派生、标题一致路径与 TSV 映射台账

- **状态**：已接受
- **日期**：2026-10-23
- **裁决人**：ykla
- **执行者**：主代理
- **复审日期**：2027-01-23
- **替代关系**：无

## 1. 形式

- 形式：`05-卷册大纲/` 以 `目录/data/outline.txt` 为卷/章/节结构唯一真值；卷/章/节/小节路径采用“编号前缀＋标准化标题原文”，不做 slug、缩写或截断；旧树 `05-卷册大纲/` 重命名为 `旧大纲-20261023/` 并打 Git 标签；旧子节以 TSV 映射台账逐条映射到现行 3 705 节；`mapping.duckdb` 仅作派生查询副本；目录变动时稳定 ID 不变，人工确认后逐卷 `git mv`。
- 章号口径（2026-10-23 ykla 裁定，取代“全局章号三位”旧法）：章目录名 `第N章-slug` 取**卷内章号**（每卷永远以第一章开始，一位零填充，如 `第1章`…`第12章`），与 `data/outline.txt` 的 `## 第 N 章` 及 `index.html` 目录逐卷一致；节 `M.N-slug` 的 M 同取卷内章号；全书跨卷唯一的章序号只存于 `映射/targets.tsv` 的稳定 ID（`C-0001`…`C-0523`），不进任何目录名。523 个章目录已按此改号（2026-10-23 章号口径批），全树实测 0 违例。
- 边界：不撰写正文；旧树只做已批准的机械格式修复与标题标准化；术语替换、删除类与语义改名逐条列清单待 ykla 裁决；未映射/分歧挂账不阻塞收口。

## 2. 矛盾

- 不做的后果：目录 75 卷/523 章/3 705 节与磁盘 24 卷/449 章/3 274 节继续分叉；目录每次变动都无法传导到磁盘；旧子节无法按现行目录检索；H/F 等线继续在旧路径上积累不兼容。
- 受影响者：ykla（验收与裁决）、主代理（迁移与门禁）、复核者（三路映射复核与独立复核）、H1–H4/F1–F4/OAA/mail2d/DDJ 等线（路径与入纲宿主）、读者（SUMMARY 与目录页）。

## 3. 正面

- 能力：目录与磁盘结构同源；旧子节可按现行节检索；路径与标题一一对应；目录变动可通过稳定 ID＋布局清单增量传导，不重审语义映射。
- 受益者：ykla、接手会话、读者、各长线维护者。
- 验证方式：`audit_outline_landing.py` L1–L17（2026-10-23 由 L1–L13 扩至 17 条，见第三十七件判据正文）；三路映射复核；L0–L5 读写一体循环；目录页九件、三套浏览器回归、文档门禁、`audit_task_lifecycle.py` L1–L12、`audit_engineering_practice.py` E1–E7。

## 4. 负面

- 成本：37 484 个子节需逐条映射与三路复核；旧树 6 291 个文件名含反引号、7 527 条杂质名、13 504 条截断/短名需标准化或裁决；目录标题 2 卷/14 章/142 节含 `/`、4 节含 `:`、2 节含 `*`，需改全角并重装配。
- 风险：路径含空格/括号/全角标点导致 SUMMARY 链接失效；旧树修复与标题标准化改动范围大；映射语义错判；跨线路径未覆盖导致入纲断链；DuckDB 派生库带来写库门禁成本。
- 边界：不自动改语义标题；不删除旧树；不写正文；不做定时/自动任务；路径超 260 或大小写冲突即停并请示。

## 6. 过去依据

- 历史条件：旧树为 24 卷/449 章/3 274 节四层树；现行目录为 75 卷/523 章/3 705 节；旧树 37 484 个子节文件；旧根级 SUMMARY 10.9 MB。
- 此前形式为何失效：目录与磁盘无派生关系；slug 规则要求 ≤40 字，与“路径＝标题”冲突；旧树含反引号文件名，PowerShell 直读已实测失败；目录标题含 Windows 非法字符，无法直接作为路径。

## 7. 现在依据

- 测试／测量／故障／反馈：2026-10-23 实测旧树 37 486 个 `.md`（37 484 小节）；6 291 个文件名/6 337 处反引号；7 527 条杂质名；13 504 条截断/短名；目录 2 卷/14 章/142 节含 `/`、4 节含 `:`、2 节含 `*`、75 卷双空格；剥离编号后精确标题路径最长 232 字符、0 条 >240、0 条 >260。
- 日期与环境：2026-10-23，Windows，`d:\librebsd`。
- 证据路径：本 ADR、`.trae/specs/migrate-refactor2026-into-outline-20261023/spec.md`、`tasks.md`、`checklist.md`；Task 1 清点与 Task 7.10 L0–L5 证据。

## 8. 将来失效条件

1. 出现比“目录真值派生＋标题一致路径”更少变动、更可核验的结构载体；
2. 标题原文路径在三个批次内两次导致工具链不可用且无等价替代；
3. TSV 真值＋DuckDB 派生被证明无法支撑映射查询或审计；
4. 稳定 ID＋布局清单在目录高频变动下产生不可接受的重命名噪声。

## 10. 自由影响

- 退出：不改变读者可见界面的退出能力；目录页仍可离线打开。
- 导出：目录页 HTML/CSV/PDF/SUMMARY 导出保持。
- 离线：全部本机执行，不引入外部服务。
- 默认值可撤销性：ADR 可被后续 ADR 替代；路径与映射台账可回滚到 Git 标签。
