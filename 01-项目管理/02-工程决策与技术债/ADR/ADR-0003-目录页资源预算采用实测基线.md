# ADR-0003：目录页资源预算采用实测基线

- **状态**：已接受
- **日期**：2026-10-22
- **裁决人**：主理人
- **执行者**：主代理
- **复审日期**：2027-01-22
- **替代关系**：无

## 1. 形式

本决策的形式是“项目资源预算表 + 只读测量脚本”。适用于 `08-核查报告与多轮复核/重构2026/index.html` 及其装配源；不适用于其他页面或未来多页架构。

## 2. 矛盾

教义 06 的“首屏 JS ≤50 KB、CSS ≤20 KB、DOM ≤2000 节点”是针对常规 Web 应用的预算。本目录页是 74 卷 521 章 3671 节的单文件自包含页面，DOM 实测 14,954 元素／34,929 全节点，直接套用 2000 节点会得到“永远超预算”的假失败；若完全不设预算，页面体积又会无声增重。受影响者：主理人（验收）、主代理（改版与门禁）、读者（加载体验）。

## 3. 正面

- 给出可执行的项目预算：JS gzip ≤50 KB、CSS（扣内嵌字体）gzip ≤20 KB、DOM ≤16,000 元素／≤37,000 全节点、整页 gzip ≤1.5 MB；
- 2026-10-22 实测：JS 37,468 B、CSS 16,355 B、DOM 14,954 元素／34,929 节点、整页 1,241,867 B，均在预算内；
- 测量脚本可复跑，改版后可同口径对比；
- 明确 2000 节点不适用，避免把教义数值当作形式主义判据。

验证方式：`script/_td001_page_budget_20261022.py` 复跑；页面改版后同口径测量。

> **2026-10-22 复测注记（152 批在途时点）**
>
> - 权威三元组：`python 00-编纂规则与格式规范/01-规则/脚本与命令/sync_refactor2026_baseline.py --list` 输出“74 卷 521 章 3694 节”；152 批在途会继续改变节数，运行前以该命令现测为准，本节只记时点值。
> - 整页实测：`08-核查报告与多轮复核/重构2026/index.html` 2,911,828 B；gzip 1,254,805 B（Python `gzip.compress` 整体压缩，默认级别与 level 9 实测同值；含全部内联资源，非分块压缩口径）。
> - DOM 节点数未在本轮复测，原 14,954／34,929 为 2026-10-22 前值；预算阈值不变（JS gzip ≤50 KB、CSS 逻辑 gzip ≤20 KB、DOM ≤16,000 元素／≤37,000 全节点、整页 gzip ≤1.5 MB）。

## 4. 负面

- DOM 预算为教义值的 8 倍（元素）／18.5 倍（全节点），承担者是主代理与主理人；
- CSS 预算仅余约 3.6 KB，新增样式空间有限；承担者是改版执行者；
- 整页 1.24 MB，移动网络首载仍偏重；承担者是读者与发布者；
- 预算可能随内容增长再次失效；承担者是复审者。

## 5. 承担者

| 负面 | 承担者 | 承担时点 |
| ---- | ------ | -------- |
| DOM 预算放宽 | 主代理、主理人 | 每次改版验收 |
| CSS 余量有限 | 改版执行者 | 新增样式时 |
| 整页体积 | 读者、发布者 | 每次发布 |
| 预算复审 | 复审者 | 2027-01-22 或页面重构时 |

## 6. 过去依据

- 教义 06 的预算面向常规 Web 应用；本项目目录页为单文件自包含页面，内嵌字体与 74 卷目录数据使其体积天然高于常规站点。
- 2026-09-28 服务器实测页面 1,583,076 B；2026-10-22 已增至 2,852,715 B，说明不设预算会持续增重。
- 项目已有 `audit_page_assets.py`、`audit_a11y.py` 与三套浏览器回归，但此前无 DOM／JS／CSS 预算判据。

## 7. 现在依据

- 测量脚本：`script/_td001_page_budget_20261022.py`；报告：`script/_td001_page_budget.md`。
- 方法：Playwright 驱动本机 Chrome，`load` 后 2.5 s 稳态；DOM 用 `TreeWalker SHOW_ALL` 与 `getElementsByTagName('*')`；gzip 用 `zlib level 9 / wbits=31`；CSS 扣除 `data:font/woff2;base64` 字体 URI；JS 排除 JSON、ld+json 与 gzip 数据岛。
- 数值：整页 2,852,715 B → gzip 1,241,867 B；CSS 逻辑 52,775 B → 16,355 B；行内 JS 117,100 B → 37,468 B；DOM 14,954 元素／34,929 全节点；JS 禁用页 23,588 元素；脚本错误 0。

## 8. 将来失效条件

出现下列任一条件时，本 ADR 应复审或替代：

1. DOM 元素超过 16,000 或全节点超过 37,000；
2. JS gzip 超过 50 KB、CSS 逻辑 gzip 超过 20 KB、整页 gzip 超过 1.5 MB；
3. 目录页改为多页、引入框架或打包器；
4. 读者端实测首屏时间显著恶化，且预算内仍不能满足体验；
5. 内容规模变化使 74 卷 521 章 3671 节的单页模型不再成立。

## 9. 0 信任校验

- 数值由只读脚本实测，报告保留命令、环境与口径；
- 独立复现：`C:/Python314/python.exe script/_td001_page_budget_20261022.py`；
- 原始证据：`script/_td001_page_budget.md`；
- 不以单次测量作为长期结论；页面改版后必须复测。

## 10. 自由影响

- 不改变读者可见界面的退出、导出、离线能力；
- 不引入账户、联网、遥测或私有格式锁定；
- 预算只约束资源，不限制内容表达。

## 11. 安全和解

- 资产：页面可用性、读者加载体验、装配源完整性；
- 对手：无声增重的样式／脚本、第三方资源引入；
- 攻击面：页面资源、内嵌字体、装配源；
- 信任边界：主代理执行，主理人验收；
- 现有控制：页面资产门禁、无障碍门禁、三套浏览器回归、E7 索引；
- 残余风险：预算内仍可能首屏慢；DOM 预算放宽可能掩盖结构膨胀；
- 证据：测量脚本与报告；
- 代价：每次改版需复测，CSS 余量有限；
- 失效条件：见 §8。

## 12. 复审触发

- 时间：2027-01-22；
- 事件：页面改版、JS／CSS 新增、DOM 增长超过 10%、目录页架构变化、读者端性能反馈；
- 复审动作：复跑测量脚本，更新预算或替代本 ADR；结论写入工程实践复审台账。
