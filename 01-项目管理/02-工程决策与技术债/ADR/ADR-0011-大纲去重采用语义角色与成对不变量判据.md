# ADR-0011：大纲内容去重采用语义角色与成对不变量判据

## 1. 形式

本决策把 `05-卷册大纲/` 的内容级去重固定为三层判据，任何清理批次必须同时满足：

1. **语义角色前置**：删除单元先标注角色——正文段、结构标签、引文、成对标记、书目条目。**无角色标注的删除一律不执行**。`**字段 N …**`、短粗体标签、清单标签等结构标签不判重。
2. **冗余三分**：字面冗余（字节相同）、结构冗余（按记录重复的标签与骨架）、信息冗余（同一知识重复陈述）。**只有信息冗余可删**；结构冗余即使逐字相同也保留。
3. **成对不变量**：`DB_POINTS`、`MAIL_INSIGHT`、`PODCAST_REVIEW`、`DB_REF`、`REVIEW-ANNOT`、`W172-YT-ROUTE`、`dangan-*` 等成对锚，禁止单侧删除；删除区间若含成对锚，必须整对同删，且**批前批后逐文件配平状态相等**。解析须多行注释感知，不得按行号盲切。
4. **差分不变量**：以批前 HEAD 为基线逐文件比较，不以绝对计数或绝对配平作为判据。基线本身存在存量失配时，只要求“差值相等”，不要求“全树归零”。
5. **自动层边界**：自动执行仅限 P1-1（同一文件内同一 ROW_MINE 条目单元逐字重复，保留首次）。P1-2（段落）与 P1-3（注释标记）**永久退出自动层**，只能以人工批准的角色标注清单执行。
6. **写盘契约**：沿用 ADR-0010 的“临时件 → `os.replace` → 写后断言”；按卷分批提交，暂存即提交，git 为唯一留痕，禁建备份副本。

## 2. 矛盾

- 不做的后果：157 批以“同文件段落逐字相同”为唯一判据执行 1,950 条删除，实测 **779 条明确误删（39.9%）**：其中 `**字段 N …**` 结构标签 700 条、成对锚单侧删除 79 条并造成 9 个文件配平状态变化；因整类风险撤回 1,030 条（52.8%）。若继续以文本相等判重，后续 P2／P3 的潜在误删面为 206 万至 418 万字符。
- 受影响者：主代理（清理执行）、复核子代理（抽审）、主理人（体例与批准）、接手者（复现与验收）。

## 3. 正面

- 能力：删除决策可解释到“角色＋基线差值”，假阳性可在执行前被白名单拦截；成对锚不再被行级删除破坏。
- 受益者：全部大纲清理批次；P2 跨文件同锚与 P3 书目列表的裁决；后续生成器幂等改造。
- 验证方式：逐文件字段标签计数、逐文件配平差分、被删区间字节反向复原、ROW_MINE 锚 ID 集合守恒；四项全部通过才允许提交。

## 4. 负面

- 成本：每个删除单元需角色标注；新增多行注释感知的配对审计；每卷至少 5 个文件人工抽审，短块（≤40 字）100% 过目。
- 风险：角色分类仍含主观判断；基线有 3,763 个文件存量配平异常，差分判据只能保证“不劣化”；规则趋严后清理收益下降（157／158 批净留存仅 920 块，占 1,087,251 块的 0.0846%）。
- 边界：不改写正文、不合并段落、不重排、不动层级与根级三件镜像。

## 8. 将来失效条件

1. 结构标签改为模板渲染或唯一 ID 生成，不再逐条重复出现；
2. 成对锚改为结构化 AST／XML 校验与结构化编辑，行级删除不再可能破坏配对；
3. 大纲改为数据库单一写入，文本层不再直接编辑；
4. 全树配平基线归零并由常驻门禁维持，差分判据可由绝对判据替代；
5. P2／P3 的重复来源在生成器侧根除，文本层不再产生新的重复条目。
