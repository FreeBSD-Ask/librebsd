## 二、角色枚举

| 角色 | 含义 | 可否作为唯一复核 |
| ---- | ---- | ---------------- |
| 作者 | 执行本任务的会话或代理 | 否 |
| 复核子代理 | 只读复核、反例优先、独立复现 | 可作为独立复核，但不得作为唯一安全／平台／性能批准 |
| 独立复核 | 与作者不同会话的只读复核 | 可 |
| 主理人 | 验收、签收与高风险批准 | 可；高风险任务必须有一轮主理人签收 |

## 三、写入口径

- 每轮复核新增一行；复核 ID 按 `RV-YYYYMMDD-NNN` 递增，不跳号、不复用。
- `输入版本` 写 spec 版本、提交号或输入文件 SHA-256；不得只写“最新”。
- `结论` 只用 PASS／FAIL／不适用；FAIL 必须写发现项与处置。
- `证据` 写可定位路径、命令或输出摘要；不得只写“已复核”。
