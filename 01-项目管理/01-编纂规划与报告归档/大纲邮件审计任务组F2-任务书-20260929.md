**开工三步（每批必做）**：
```bash
python 00-编纂规则与格式规范/01-规则/脚本与命令/oaa_beacon.py --refresh        # ① 刷新浮标（合并全部台账→扫大纲→算本组 pending/新增）

```

**收工**：组内 register（**写分片台账**）→ 再 `--refresh` 更新浮标 → 他组立即可见。

**去重原理**：合并集 ＝ `processed.jsonl` ∪ `processed_f1..f4.jsonl`。
**新增识别**：大纲新增条目在下次 `--refresh` 自动出现在对应组 pending（`delta_vs_last` 为正＝本组新增数）。
**未归组告警**：`beacon/claims_UNCLAIMED.txt` 非空＝出现新宿主未归组，**须先人工归组**（改 `oaa_beacon.py` 的 `GROUP_VOLS`/`PERIPH`）再执行本批。
