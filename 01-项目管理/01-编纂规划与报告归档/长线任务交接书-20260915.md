## 十一、你的推进循环

```
while 未超时:
  u = 队列中优先级最高的 PENDING 单元
  if 无 → 退出（队列耗尽）
  preflight(u)                    # 逐文件 pre_sha1；已变 → 跳过该文件
  执行（有执行器则自动；否则出工单标 NEEDS_MANUAL）
  验收（G1/G4/G5 全绿才继续）
  路径限定提交 + 归属甄别
  登记台账（R 号 MAX+1）+ 写 progress.tsv
  标 DONE
```

**中断安全**：单元是原子，中断点 = 单元边界。**超时只退出循环，绝不打断当前单元。**
**失败即停**：任一验收不过 → 标 FAILED 并停止本轮，不继续下一单元。
