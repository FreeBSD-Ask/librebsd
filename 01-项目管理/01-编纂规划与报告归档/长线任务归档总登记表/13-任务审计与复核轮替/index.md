> **性质**：轮替件，不是线归档件。本目录只收纳 `任务审计台账.md` 与 `任务复核台账.md` 中**已收口**任务的逐字迁出记录；未收口任务不得迁出。

## 一、轮替口径

| 项 | 口径 |
| -- | ---- |
| 触发 | 主表超过 100 行、200 KB 或跨季度，三者先到者 |
| 对象 | 已收口任务（收口结论 PASS 或 不适用） |
| 保留 | 未收口任务留在主表；主表只留指针与统计行 |
| 迁移 | 逐字迁移，先备份，原子替换，写 changelog |
| 双源 | 禁止；同一任务不得同时留在主表与轮替件 |
| 命名 | `YYYY-QN/任务审计台账.md`、`YYYY-QN/任务复核台账.md`、`YYYY-QN/index.md` |
| 保留期 | 永久保留，不删除 |
