## 三、单批标准流程（七步，B3–B6 已验证）

### 1. 生成本批宿主清单
**⚠️ 必须先扣除 F3 认领的外围宿主**（F3 任务书 §三.1 定义，两组的第05卷认领互斥）。
```bash
python - <<'EOF'
import glob,os,re,json
from collections import Counter
RM=re.compile(r'ROW_MINE:\s*([\w-]+)\.([\w.]+)\.(\d+)')
done=set()
for l in open('script/_db_row_mining/audit_outline/processed.jsonl',encoding='utf-8'):
    if l.strip(): done.add(json.loads(l)['key'])
PERIPH={'freebsd-doc','freebsd-advocacy','freebsd-chat','freebsd-newbies','freebsd-hubs',
'freebsd-hardware','freebsd-office','freebsd-openoffice','freebsd-chromium','freebsd-gecko',
'freebsd-x11','freebsd-apache','freebsd-elastic','freebsd-www','freebsd-perl','freebsd-alpha',
'freebsd-ppc','freebsd-sparc64','freebsd-i386','freebsd-ia64','freebsd-mips','freebsd-arm',
'freebsd-lite','freebsd-vendors','freebsd-binup','ctm-announce',
'freebsd-smp','freebsd-emulation','freebsd-scsi','freebsd-acpi','freebsd-geom',
'freebsd-ipfw','freebsd-isdn','freebsd-net','freebsd-isp'}   # 后 9 库 2026-09-29 补入，平衡 F1/F3 体量
hosts=[]
for f in sorted(glob.glob('05-卷册大纲/第05卷-freebsd的工程化奠基/**/*.md',recursive=True)):
    if os.path.basename(f) in ('index.md','概述.md','00-总览.md'): continue
    rel=f.replace(chr(92),chr(47)); txt=open(f,encoding='utf-8').read()
    b=[(m.group(1),m.group(3)) for m in RM.finditer(txt)
       if f'{m.group(1)}|{m.group(3)}|{rel}' not in done]
    if not b: continue
    main=Counter(db for db,_ in b).most_common(1)[0][0]
    if main in PERIPH: continue   # 归 F3
    hosts.append((rel,len(b)))
for r,n in sorted(hosts,key=lambda x:-x[1]): print(n,r)
EOF
```
按块数聚类切批（每批 ≤6,000 块），写入 `work/hosts_f1_<批号>.txt`。**F1 与 F3 认领清单须互不重叠、合起来覆盖第05卷全部宿主。**

### 2. fetch 反查（**必须用 Python 循环，勿用 bash for——中文路径在 Git Bash 会只跑首个**）
```bash
python - <<'EOF'
import subprocess
for h in [l.strip() for l in open('script/_db_row_mining/audit_outline/work/hosts_f1_<批号>.txt',encoding='utf-8') if l.strip()]:
    r=subprocess.run(['python','00-编纂规则与格式规范/01-规则/脚本与命令/oaa_fetch.py','--host',h],capture_output=True,text=True)
    print(h[-40:], [l for l in r.stdout.splitlines() if 'claim' in l][-1:])
EOF
```
产出 `work/<宿主名>.fetch.jsonl`。**记录 claim 缺/src 缺计数**（src 缺须为 0）。

## 四、本组特有风险

1. **超大单宿主**：第 05 卷部分宿主块数极大（>1,000），单片需再切子片（23 块/片 → 该宿主独占多片），批次推进时单批可只覆盖 1–2 个大宿主。
