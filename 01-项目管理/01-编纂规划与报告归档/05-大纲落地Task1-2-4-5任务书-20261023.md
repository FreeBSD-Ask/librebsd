## 三、Task 4：映射基础设施

**状态**：未开工。前置 `targets.tsv` 已就绪。

### 3.1 目标
建立“旧子节 → 目标节”的**唯一映射台账**，使 37,484 条旧子节每一条都有状态、可统计、可断点。

### 3.2 步骤
1. 由 `inventory.tsv` 生成 `映射/mapping.tsv` 表头＋37,484 行 `PENDING`。
   **16 列**（checklist 口径，spec 4.1 的 6 列为必填子集）：
   `source_id`／`source_relpath`／`source_sha256_pre`／`source_sha256`／`source_title`／
   `source_section_path`／`status`／`method`／`confidence`／`review_a`／`review_b`／
   `review_c`／`target_id`／`order`／`review_state`／`note`。
2. `source_id` 规则：`S-%06d`，按旧树卷序→章序→节序→文件名升序稳定分配；一经分配永不复用。
3. SHA-256 分组：同哈希多条只保留 1 条候选，其余预标 `DUPLICATE`（`note` 记代表件 `source_id`）。
4. 建 `映射/target-catalog.md`：完整 3,705 节目录（卷／章／节号＋题面），供三路复核直接读取。
5. 按旧卷生成复核工作包 `映射/review/packs/<旧卷>.tsv`（源文摘要／旧路径／特殊结构标记）。
6. `mapping.duckdb` 只读派生器：覆盖率、状态分布、目标节分布、重复内容统计。

### 3.3 判据
- `mapping.tsv` 数据行 == 37,484；每行 16 列；
- 状态守恒：`PENDING + CONFIRMED + UNMAPPED + DISPUTED + DUPLICATE + DISCARDED +
  TARGET_LOST + REMAP == 37,484`；
- 同 SHA 组恰 1 个代表件，其余全 `DUPLICATE`；
- `target-catalog.md` 的 75／523／3,705 与 `targets.tsv` 逐项相等；
- `audit_outline_landing.py --check` 的 L1／L8／L14／L17 保持 PASS。

## 四、Task 5：三路复核与重复件分组

**状态**：未开工。前置 Task 4。

### 4.1 目标
对 37,484 条旧子节逐条判定其应落到哪一个现行节；三路独立、互不可见，全一致才确认。

### 4.2 步骤
1. 按旧卷分批：01–04（5,334 文件量级）→ 05–08 → 09–12 → 13–16 → 17–20 → 21–24；
   单批 10–20 条，超 1,000 条按子批切分。
2. **每批三路独立**：A／B／C 三份输入互不可见（同一源文＋完整 3,705 节目录），各自给出
   `target_id` 与理由；任一路不得看到另两路的结论。
3. 合并：三路一致 → `CONFIRMED`（`review_a`／`review_b`／`review_c` 全填）；
   任一路不一致 → `DISPUTED` 入 `映射/disputes.tsv`。
4. 无法归入任何节 → `UNMAPPED`（须给理由，禁硬塞）；目标节已被裁撤 → `TARGET_LOST`；
   拆分/合并 → `REMAP` 并登记后继 ID（非空且 active）。
5. 每批收口：行数守恒、状态合法、`DUPLICATE` 组均有代表件、三路记录非空、更新
   `mapping.duckdb` 统计；记录分歧率。

### 4.3 判据
- 任一时刻 `PENDING` 单调下降，且 `PENDING + 各状态 == 37,484`；
- `CONFIRMED` 必三路记录俱全；`DISPUTED` 必有 `disputes.tsv` 行；
- `UNMAPPED` 逐条有理由；无“硬塞”（目标节题面与源文主题无交集者不得 CONFIRMED）；
- 每批 `audit_outline_landing.py --check` 不因映射写入而新增 FAIL。

### 4.4 干执行（本日已做）
取 30 条跨卷样本，构造三路输入包并模拟合并，跑了**两种算法族**：
- 三路同族（同一相似度规则的阈值变体）：一致率 **100%**、分歧 0；
- 三路异族（序列相似度／词元 Jaccard／前缀池）：一致率 **0%**、分歧 30。

两个极端说明：**算法模拟无法外推真实分歧率**——分歧率完全由算法族决定。真实分歧率只能由
三路真实 LLM 独立判定得出（沙箱历史经验为 40%，且集中于同章相邻节）。干执行只证明了
流程可跑、状态守恒成立、输入包可切分，**不能**作为 Task 5 的质量结论。

### 4.5 干执行发现的分批约束
工作包按旧卷切分**严重不均**：最大 9,454 条（第 05 卷）、次 5,596（第 20 卷）、
4,072（第 09 卷），最小 26 条。故 Task 5 必须：
- 单卷 >1,000 条按子批切分（如 05 卷拆 10 个子批，每批 ≤1,000）；
- 每子批独立 checkpoint，避免单批超时后整卷重跑；
- 72 小时窗口内优先 01–04 卷（合计约 5,300 子节量级），05 卷单独排期。
