### ◐D UNC／D 盘环境适配规约（D:\librebsd 与 \\DESKTOP-M5P610N\d\librebsd 为同一仓库双身份）

1. **路径写法表**：
   - Write／Edit 工具 → **Windows 反斜杠路径**（`\\DESKTOP-M5P610N\d\librebsd\...` 或
     `D:\librebsd\...`）；POSIX 路径（`/d/librebsd/...`）会**报成功但不落盘**；
   - bash → `//DESKTOP-M5P610N/d/...`（无 `/mnt`）；
   - Python → 正斜杠 `d:/librebsd/...`（反斜杠 UNC 会解析到只含 `_tmp` 的幻影目录）；
     主会话自写脚本一律四反斜杠 UNC。
2. **🔴 禁内联 `python -c` 与 heredoc 直接写／校验 UNC 路径**
   （`FileNotFoundError` 指向明明存在的目录，已三次以上坐实）——一律写 `.py` 文件再跑。
3. **写后必须独立验盘**：Write／Edit 报成功 ≠ 落盘（UNC 静默失败家族）；写后用**独立命令**
   （`ls -la` 字节数／`wc -l`／`grep` 锚点计数）复核；`os.path.isfile` 对刚写完的文件
   可能返回过期 False（写后负缓存），间隔重读再判。
4. **UNC 假阴性三族**：`os.listdir` 可能漏列真实存在的项（按精确路径 `os.stat` 复核才可信）；
   `grep -c` 对中文路径宿主可能假阴报 0（真值取 Python `io.open`）；
   **子代理报“文件不存在”先按 SMB 假阴处理**，主会话复核后才可判死。
5. **慢 IO 纪律**：单代理内并行 Read 多份输入会 30s 双双超时——一律串行读；
   `ls`／`grep` 走 UNC 极慢，计数类统计用单进程 Python 遍历。
6. **mtime 口径**：UNC 与本机时钟存在 ~15h 时区**标签**差（git `+0800`／`−0700` 混用同源，
   全链无真实漂移）；mtime 绝对值可信、相对年龄不可用；HOT 判据（mtime<2 分钟）以本机钟为准。
7. **git 纪律**：提交前 `git update-index --refresh`（UNC stat 缓存会让已写盘文件显示无改动）；
   pathspec 白名单精确列出（`*bNNN*` 通配会撞他线标签）；禁 `git add -A`、禁 amend、
   不删 `.git/index.lock`（持锁 sleep 15 重试）；管道别用 `tail`（吞非零退出码）；
   校验 CRLF（shell 重定向会带 CR）。
8. `glob.glob` 在 Windows 返回反斜杠路径，跨平台匹配一律 `os.path.basename`。
