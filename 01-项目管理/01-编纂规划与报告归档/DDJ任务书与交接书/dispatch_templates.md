# dispatch_templates.md — 子代理派单模板（T008）

通用铁律（每个派单词内必须原文包含）：

1. 目标文件不存在、必须用 Write 工具落盘；禁止 bash/heredoc/cat>/echo/Python 脚本落盘。
2. UNC 路径一律 Windows 反斜杠形（`\\DESKTOP-M5P610N\d\librebsd\...`）。
3. 回报必须贴校验命令的原始输出（禁凭记忆报数）；产物可信、回报自述不可信，主会话以磁盘回读为准。
4. 照录不改字：读不清写 `[?]` 或 `[此处不可辨]`，禁止臆造补全；禁止按常识改字。
5. 禁止使用任何本地 OCR/转录模型——只准用你自己的视觉直接读图。

## A. 图片转写派单（T022 用）

```text
任务：逐张转写下列 N 张图片中的全部文字/代码/数字/符号（含代码截图、图表坐标轴、表格）。
图片（Windows 路径逐行列出）：
  \\DESKTOP-M5P610N\d\librebsd\...\<name1>.gif
规则：
- 用 Read 工具直接读图（每次 ≤2 张，读完立即转写再读下一张）。
- 输出 JSONL（UTF-8 无 BOM、LF）到 <out.jsonl>，每行：
  {"image_name":"<name>","kind":"code|text|table|chart|mixed","text":"<全部转写文本>"}
- 图内多段代码用与原图一致的分行照录；列对齐用空格还原到可读程度即可，禁止重排。
- 无法辨认的部分写 [?]；整块不可辨认写 [此处不可辨]。
- 产毕用 python -c 统计 jsonl 行数与 N（必须相等）并把命令与输出贴进回报。
```

## B. 存疑图片判读派单（figures uncertain 复核用）

```text
任务：判断下列图片是“含文字/代码的内容图”还是“艺术图（logo/装饰/照片）”。
- 用 Read 读图后回报 judgment: content|art|uncertain 与理由一句话。
- content 图按模板 A 立即转写；art 图回报即可（主会话转 base64）。

判据（唯一判据＝图内是否有可读字符，不是“像不像图”）：
- 出现任意字母、数字、运算符、下标、公式项（如 F1·P1、C=...）、坐标轴刻度、图例、表格数字、
  页眉页脚、箭头旁的短标签——只要有 1 个可读字符，一律 judgment: content，按模板 A 转写。
- 只有图形元素（曲线、圆、椭圆、菱形、节点方块、线条、色块）且**一个字符都没有**，才 judgment: art。
- 几何图形里有节点/连线不等于艺术图；先看节点上或节点旁有无标签字符。
- 反例（必须转写，不得判 art）：ddj_426 `9705nf1.gif`——双栏图，含 F1/F2/F3/F4、P1–P4、
  "Interval of 1" 与公式 C=F1·P1+F2·P2+F3·P3+F4·P4；虽以图形为主，字符必须逐字转写。
- 正例（可判 art）：ddj_427 `9705nf7.gif`——圆＋椭圆各内接黄色菱形、4 个方块标记，零字符。
  ddj_423 `9705df1.gif`——卡通狗，零字符。
- 放大图（_zoom/_upscale 副本）按原图判；放大不产生字符。
- 渲染成全黑/全白时写 judgment: uncertain 并注明“疑似渲染黑屏”，不要凭黑屏猜 art。
```

## C. 源码/正文摘录派单（仅当机械抽取失败时的兜底）

```text
任务：把 <源文件路径> 的内容逐字转录为 <out.txt>。
- 必须用 Read 读源文件后用 Write 落盘；逐字照录不改字、不重排、不补注。
- 编码异常字符照原样保留；无法显示的写 [?]。
- 回报贴 `wc -c` 与 `md5sum` 原始输出。
```

## 派发节奏

- 40 路滚动在途：一路终态立即补位；先 `ls`＋字节数验盘再决定重派（死代理可能已落盘）。
- 已落盘分件永不重派；rpm/token 配额见错即停，不重试不降配。
