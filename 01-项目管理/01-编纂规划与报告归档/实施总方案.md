### 尽善尽美验收标准
1. **完整性**：348 章全闭环（大纲→综述→史料→正文→审核）
2. **一致性**：每章≥目标字数；"软件自由"主线贯穿 18 卷
3. **可追溯性**：每条断言有出处；存疑有台账有 review
4. **0 信任**：不可信来源 0；失效 URL 均走 archive.org；事实核查全覆盖
5. **可复现性**：批量操作有脚本、有备份、可重跑；手工修改有 changelog
6. **导航完备**：双 SUMMARY 死链 0；总目/索引/术语/人名完备

### 四阶段全景
```
准备阶段(当前;A/B/C/D/T 五层并行) → 正文阶段(E/F/G 三层逐卷) → 审校阶段(H/I/J) → 出版阶段(K/L/M)
```

## 三、质量管理机制

| 机制 | 规则 |
|------|------|
| 复核 | 批量操作前后必复核；任何内容修改后 T5 重跑确保死链 0 |
| 0 信任 | 不可信来源一律清退；失效 URL→archive.org 存档；断言须引一手/权威二手 |
| 数据库 | 破坏性操作：先备份→只读核对→批准→一次性执行；防链式污染 |
| 进度 | 子任务完成登记 changelog + word_count_summary；里程碑：18 卷综述全齐→缺口清零→准备结束→每 100 万字正文核验 |
