As root:

cd /usr/ports/mail/popper

make

make install

You then need to enable it in /etc/inetd.conf. Add the line:

pop3    stream  tcp     nowait  root    /usr/local/libexec/popper popper -s

Save the changes and exit. Then:

kill -1 1

To reload inetd.conf.
