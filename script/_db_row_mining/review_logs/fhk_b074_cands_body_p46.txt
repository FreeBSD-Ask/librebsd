According to Alfred Perlstein:
> could you please check your shared mem segments on the next crash? just

It always leave a few dozen shared mem segments laying around. Even when it 
does exit cleanly. I have a script that wipe out the shared segments after
running SO4.

-=-=-=-
#! /sbin/tcsh
set path=(/z/Office40/bin $path)
mesg n
soffice $*
ipcs | awk '/^m/ {print $2}' | xargs -n1 -t ipcrm -m
-=-=-=-

Use with caution if you have other applications used shmseg.
