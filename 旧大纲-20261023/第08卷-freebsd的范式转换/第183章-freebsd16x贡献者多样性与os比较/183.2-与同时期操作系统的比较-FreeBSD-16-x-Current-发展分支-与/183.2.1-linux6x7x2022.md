# 183.2.1 Linux 6.x / 7.x（2022-）

**要点**：Linux 6.x（2022 起）与开发中的 7.x 持续强化 eBPF、异构计算（GPU/DPU）、Rust 内核组件与实时性（PREEMPT_RT 合入）；FreeBSD 16.x/Current 在同类方向（hw offload、DTrace/ktrace 演进）跟进但生态规模与贡献者基数远小于 Linux，二者在“社区规模驱动创新”与“小而精的 BSD 路线”上对照。

**史料**：Linux 6.x/7.x 发布说明与 LWN.net 报道；FreeBSD 16.x/CURRENT 状态报告 ［B］

**史观**：终结与延续：FreeBSD 16.x 延续 5.x 起的现代化路线，与 Linux 的主线演进并驾但节奏不同。

**辨析**：Linux 的 Rust 尝试与 FreeBSD 的保守 C 基调反映不同风险偏好；“跟随 Linux 特性”不等于技术劣势，而是生态位差异。

**文献**：Linux Kernel. Release Notes [EB/OL]；FreeBSD. Project Reports [EB/OL]. ［B］
