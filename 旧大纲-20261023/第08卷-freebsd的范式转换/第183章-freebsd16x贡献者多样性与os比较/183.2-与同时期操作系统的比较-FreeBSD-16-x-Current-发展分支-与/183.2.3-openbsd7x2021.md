# 183.2.3 OpenBSD 7.x（2021-）

**要点**：OpenBSD 7.x 持续强化安全（如 unveil 扩展、固件签名、firmware 加载策略），在 16.x 同期保持“安全优先”路线；与 FreeBSD 16.x 的“现代化 + 兼容”路线对照，体现 BSD 家族内部目标分化。

**史料**：OpenBSD 7.x 发布说明（2021-）［A］

**史观**：BSD 谱系：OpenBSD 与 FreeBSD 同期演进，安全哲学差异持续；二者共享基础但优先级分叉。

**辨析**：OpenBSD 7.x 的新硬件支持通常晚于 FreeBSD，但其安全特性常为 FreeBSD 借鉴（如部分加固思路）。

**文献**：OpenBSD. 7.x Release Notes [Z]. ［A］
