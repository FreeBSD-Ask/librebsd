# 179.2.8 基础科学、CS 与 BSD 的互构：CHERI 能力架构、形式化验证与安全

**要点**：2010-2026 计算机安全基础研究与 FreeBSD 的互动：① **CHERI 能力架构**——由剑桥大学 罗伯特·N. M. 沃森（Robert Watson）（也是 FreeBSD committer rwatson@）团队与 SRI International 联合开发，基于能力的硬件安全架构，提供硬件强制的内存安全与 compartmentalization；CHERI-MIPS、CHERI-RISC-V、ARM Morello（2022 ARM 原型芯片）原型实现；CheriBSD（FreeBSD 的 CHERI 扩展版本）由剑桥大学与 FreeBSD 社区联合开发，是 CHERI 架构的主要软件原型；② **Capsicum 能力模式**——由 罗伯特·N. M. 沃森（Robert Watson）与 Jonathan Anderson 在 FreeBSD 上实现的 OS 级能力沙箱，自 FreeBSD 10.x 起部分集成入 base；③ **形式化验证**——seL4 微内核完整形式化验证（2009 年首次证明，2013 年完成全面验证）；CompCert 形式化验证的 C 编译器；④ **模糊测试与漏洞赏金**——syzkaller 内核 fuzzing、FreeBSD Security Team 漏洞处理流程；⑤ **内存安全语言**——Rust 在系统编程中的兴起

  **计算机安全基础研究与 FreeBSD 互动五大方向**：

  | 序号 | 方向 | 与 FreeBSD 关系 |
  |---|---|---|
  | ① | **CHERI 能力架构** | 剑桥大学 罗伯特·N. M. 沃森（rwatson@）团队开发，CheriBSD 基于 FreeBSD |
  | ② | **Capsicum 能力模式** | 罗伯特·N. M. 沃森 与 Jonathan Anderson 在 FreeBSD 上实现，自 10.x 起部分集成入 base |
  | ③ | 形式化验证 | seL4 微内核（2009/2013）、CompCert 编译器 |
  | ④ | 模糊测试与漏洞赏金 | syzkaller 内核 fuzzing、FreeBSD Security Team 漏洞处理流程 |
  | ⑤ | 内存安全语言 | Rust 在系统编程中的兴起 |

**史料**：CHERI Project 文档；Watson R N M, et al. CHERI 架构论文；CheriBSD 项目主页；Capsicum 论文与 FreeBSD 实现 ［B］

**史观**：总纲第 14 条——哲学思潮：CHERI/Capsicum 代表了与 “Rust 内存安全” 不同的安全范式——Rust 通过语言类型系统在编译时保证内存安全，CHERI 通过硬件指令集在运行时强制内存安全；前者需要重写软件，后者需要新硬件；FreeBSD 作为 CHERI 研究的主要实验平台（CheriBSD 基于 FreeBSD），为未来 20-30 年的硬件安全演进提供了软件基础

**辨析**：CheriBSD 不是 FreeBSD 的分支版本，而是 FreeBSD 的一个研究扩展——它是 FreeBSD 源码树的一个分支/port，包含 CHERI 相关修改，由剑桥大学维护；CHERI 架构在 2026 年仍处于研究与原型阶段，ARM Morello 是研究原型而非量产芯片，但 RISC-V CHERI 扩展可能在未来量产 RISC-V 芯片中出现
