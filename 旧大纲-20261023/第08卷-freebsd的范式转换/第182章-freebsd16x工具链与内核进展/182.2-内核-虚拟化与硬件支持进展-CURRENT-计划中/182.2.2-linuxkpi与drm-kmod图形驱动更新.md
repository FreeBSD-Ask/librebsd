# 182.2.2 LinuxKPI 与 drm-kmod 图形驱动更新

**要点**：LinuxKPI（Linux Kernel Programming Interface 兼容层）在 16.x 周期持续对齐 Linux 6.x LTS 内核 API，以支持更现代的硬件驱动；drm-kmod（直接渲染管理器内核模块，提供 AMD/Intel GPU 支持）持续更新，2026Q1 状态报告显示 drm-kmod 已在 16.0-CURRENT 的 ARM64 上构建和运行，这是图形驱动在 ARM 平台的重要进展；LinuxKPI 802.11（无线兼容层）和原生无线驱动更新是 2026Q1 重点项目之一，旨在改善 WiFi 硬件支持

**史料**：FreeBSD 2026Q1 Status Report（LinuxKPI 802.11 and Native Wireless Update 条目、drm-kmod: Build and run on ARM64 with 16.0-CURRENT 条目）、FreeBSD src main 分支 LinuxKPI 提交记录、graphics/drm-kmod port 信息、FreeBSD WiFi 驱动相关文档和项目［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］〔L1 代码/构建产物/L3 官方文档与公告〕

**史观**：技术路线分化：LinuxKPI 是 FreeBSD 在硬件支持上采取的务实策略——通过提供 Linux 内核 API 兼容层来移植 Linux 驱动，而非从零开始重写所有驱动；这一策略在许可证纯洁化（drm-kmod 等作为 ports 中的独立模块）和硬件支持广度之间取得了平衡

**辨析**：LinuxKPI 与 Linux 内核并非 100% 兼容，仅实现了驱动移植所需的子集；drm-kmod 在 ARM64 上构建运行是 CURRENT 中的进展，截至 2026 年 7 月可能仍有稳定性问题或功能限制；WiFi 6/6E/7 支持截至 2026 年 7 月是持续改进中的领域，具体支持程度因硬件芯片而异
