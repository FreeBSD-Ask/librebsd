# 178.2.4 FreeBSD Foundation 2025-2026 资助项目

**要点**：FreeBSD Foundation 在 2025-2026 年持续资助多个关键开发领域，包括：① LinuxKPI 与 WiFi 驱动改进（持续资助）；② GPU 驱动（drm-kmod）改进；③ pkgbase 开发与稳定化（Lexi Winter 等）；④ RISC-V 平台支持完善；⑤ 安全改进（Capsicum、MAC 框架、沙箱）；⑥ bhyve 虚拟化改进；⑦ CI/CD 基础设施与可重现构建；⑧ 文档与开发者工具改进；Foundation 资金来源包括企业捐赠（Netflix、Google、Microsoft、AWS、Juniper Networks、Netgate/iXsystems 等）、个人捐赠、会议收入等

  **FreeBSD Foundation 2025-2026 资助领域**：

  | 序号 | 资助领域 | 说明 |
  |---|---|---|
  | ① | LinuxKPI 与 WiFi 驱动改进 | 持续资助 |
  | ② | GPU 驱动（drm-kmod）改进 | - |
  | ③ | pkgbase 开发与稳定化 | Lexi Winter 等 |
  | ④ | RISC-V 平台支持完善 | - |
  | ⑤ | 安全改进 | Capsicum、MAC 框架、沙箱 |
  | ⑥ | bhyve 虚拟化改进 | - |
  | ⑦ | CI/CD 基础设施与可重现构建 | - |
  | ⑧ | 文档与开发者工具改进 | - |

**史料**：FreeBSD Foundation 2025 年度报告（2026 年发布）；Foundation 博客 “Sponsored Projects” 系列文章；各 commit 中的 “Sponsored by: FreeBSD Foundation” 标记 ［A］

**史观**：企业赞助与开源可持续发展（专题语）：FreeBSD Foundation 的企业赞助模式是 2020 年代开源可持续发展的典型案例——Netflix、Google、Microsoft 等大公司作为 FreeBSD 的重度用户，通过 Foundation 赞助专职开发者改进他们所依赖的功能，这些改进全部回馈社区；这与 Red Hat 资助 Linux 开发、Apple 资助 LLVM/Clang 开发属于同一模式

**辨析**：Foundation 资助项目不代表 FreeBSD 的 “官方方向”——Core Team 对技术决策仍有最终决定权，Foundation 资助是 “催化剂” 而非 “指挥棒”；历史上 Foundation 确实成功推动了多个关键项目（如 WireGuard 重写、pkgbase、LinuxKPI WiFi 驱动），但所有代码仍需经过正常的 committer 审查流程才能进入 base
