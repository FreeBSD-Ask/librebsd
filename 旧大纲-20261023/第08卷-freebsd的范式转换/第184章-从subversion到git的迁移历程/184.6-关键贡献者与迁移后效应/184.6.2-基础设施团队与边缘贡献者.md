# 184.6.2 基础设施团队与边缘贡献者

**要点**：除 Git 工作组核心成员外，Git 迁移的成功还依赖于许多“不可见”的贡献：(1) **集群管理员团队**——运维 git.freebsd.org 主仓库、GeoDNS 镜像、备份和灾难恢复；(2) **cgit 维护者**——维护 Web 代码浏览界面；(3) **镜像维护志愿者**——维护全球各地的 Git 镜像站点，包括不少社区志愿者个人维护的镜像；(4) **文档贡献者**——更新 Committer's Guide、Handbook、Wiki、FAQ 等文档；(5) **早期测试者**——在测试阶段就使用 Git 镜像、报告 bug、提出改进建议的 committer 和用户；(6) **ports 提交者**——帮助测试 ports 仓库转换、适应新工作流的 portmgr 团队和 ports committer；这些贡献者的工作大部分不在聚光灯下，但对迁移的平稳完成至关重要

**史料**：FreeBSD 集群管理员团队文档；镜像维护者名单；Committer's Guide 提交历史；freebsd-git 邮件列表问题报告和反馈 ［A］

**史观**：总纲第 10 条——动手者创造历史〔订正：原挂“总纲第 10 条——边缘者贡献”系伪标签名目，依核查报告按权威全称正名〕：基础设施运维、文档编写、测试反馈等工作往往不被主流叙事关注，但这些“边缘贡献”是大型工程成功的必要条件；历史书写应当记录这些不那么耀眼但至关重要的工作

**辨析**：边缘贡献者的名单永远不可能完整——许多人在 IRC/Slack/私信中提供帮助、在本地聚会上分享经验、私下帮助同事适应 Git，这些贡献没有留下公开记录；史笔至此只能记录可查证的贡献，对无法查证的贡献保持敬意

**文献**：FreeBSD Cluster Administration Team. *Git Infrastructure Maintenance Records*. wiki.freebsd.org; FreeBSD documentation repository. Committer's Guide Git chapter commit history; freebsd-git mailing list. Beta tester feedback threads (2020). ［A］
