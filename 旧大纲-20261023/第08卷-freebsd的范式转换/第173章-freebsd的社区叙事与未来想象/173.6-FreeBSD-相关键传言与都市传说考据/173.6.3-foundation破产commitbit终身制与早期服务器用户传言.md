# 173.6.3 Foundation 破产、commit bit 终身制与早期服务器用户传言

**要点**：FreeBSD 在社区治理与历史应用领域伴随三类典型传言——(1) “FreeBSD Foundation 曾面临破产”（史实失实：未找到任何 Foundation 官方声明、年度报告、财务报表支持“破产”或“濒临解散”，2005-2006 年年度募捐属常规小型非营利组织运营，Foundation 官网 financials 页面定期发布年度预算与审计报告）；(2) “FreeBSD commit bit 一旦授予终身有效”（真伪混杂：commit bit 18 个月未提交可被收回的过期政策由 Marc Fonvieille 于 2021-02-27 修订，但历史上存在 core team 成员主动放弃或被收回的案例，“终身有效”是社区对 commit bit 文化意义的夸张表述）；(3) “FreeBSD 是 Wikipedia/Hotmail/Yahoo! 早期服务器系统”（真伪混杂：Yahoo! 确实长期使用 FreeBSD 作为前端服务器，Hotmail 早期使用 FreeBSD 后被 Microsoft 迁移至 Windows，Wikipedia 早期使用混合架构含 FreeBSD 但具体比例须考据）

FreeBSD 使用历史（BSDCan 演讲与 FreeBSD Foundation 案例研究）；Hotmail 历史架构变迁（Microsoft 收购后的迁移记录） ［A］

**史观**：总纲第 13 条——法律与道德是利益分配，FreeBSD Foundation 作为 501(c)(3) 非营利组织的财务透明度是利益分配机制的具体显现，“破产”传言将常规募捐误读为危机是社区对基金会治理的形式主义化投射；总纲第 9 条——经验优先，commit bit 收回政策是 18 个月未提交的工程经验沉淀，“终身有效”传言是社区对 commit bit 文化意义的夸张；总纲第 19 条——解释学循环是历史认识的根本条件，Yahoo!/Hotmail/Wikipedia 早期服务器系统的传言须在 BSDCan 演讲、Foundation 案例研究、企业官方文档之间往复印证；总纲第 7 条——理论必须自反，本子节作为社区治理与历史应用传言考据叙事，自身亦嵌入“Foundation 治理即善”的前理解，须自觉呈现这一前理解

**辨析**：考据过程留痕——【查证来源】Foundation 官方关于页面与 financials 页面经 freebsdfoundation.org 一手核验；2005-2006 年主页存档经 web.archive.org 核验，显示基金会当时资金规模较小但属正常运营；Commit Bit Expiration Policy 经 freebsd.org/internal/expire-bits/ 一手核验；【交叉验证方法】Foundation 财务记录须以官网 financials 页面与年度审计报告互证；commit bit 收回案例须以政策文本与实际收回公告互证；Yahoo!/Hotmail/Wikipedia FreeBSD 使用须以 BSDCan 演讲与企业官方文档互证；【0 信任原则·“破产”传言溯源】未找到任何 Foundation 官方声明、年度报告、财务报表支持“破产”说法，2005-2006 年年度募捐属常规小型非营利组织运营；【0 信任原则·Hotmail 迁移时点】Hotmail 早期使用 FreeBSD 后被 Microsoft 迁移至 Windows 的具体时点与迁移范围须进一步考据 Microsoft 官方文档；【自反性声明】本子节作为 FreeBSD 社区治理与历史应用传言考据叙事，自身嵌入“Foundation 治理即善”的前理解，实际 Foundation 财务状况与 commit bit 文化的工程效应须以多源交叉验证逼近史实
