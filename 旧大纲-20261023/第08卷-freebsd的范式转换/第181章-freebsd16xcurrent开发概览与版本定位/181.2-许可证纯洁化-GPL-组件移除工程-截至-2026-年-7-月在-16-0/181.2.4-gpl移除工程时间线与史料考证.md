# 181.2.4 GPL 移除工程时间线与史料考证

**要点**：FreeBSD 基本系统 GPL 移除是持续十余年的渐进工程：2007-2010 年 GPLv3 争议促使项目加速寻找替代方案；2009-2014 年 Clang/LLVM 逐步替代 GCC（10.0 正式废弃 GCC 4.2.1 默认编译器地位，13.0 彻底移除 GCC 4.2.1）；2010 年代 GNU grep→bsdgrep、GNU patch→BSD patch（来自 DragonFly BSD，2013 年 r246074）、gdb→lldb、binutils→LLVM 工具链逐步完成；2024 年 3 月 libdiff 从 OpenBSD GoT 集成；2026 年 2 月 diff3 替换为 OpenBSD 版本；2026 年 6-7 月 dialog/dpv 移除、gnu/目录退役——截至 2026 年 7 月 16.0-CURRENT 分支 base system 实现 GPL 清零

  **FreeBSD GPL 移除工程时间线**：

  | 时间 | 事件 |
  |---|---|
  | 2007-2010 | GPLv3 争议促使项目加速寻找替代方案 |
  | 2009-2014 | Clang/LLVM 逐步替代 GCC |
  | 2014 | 10.0 正式废弃 GCC 4.2.1 默认编译器地位 |
  | 2010 年代 | GNU grep→bsdgrep、GNU patch→BSD patch、gdb→lldb、binutils→LLVM 工具链 |
  | 2021.4 | 13.0 彻底移除 GCC 4.2.1 |
  | 2024.3 | libdiff 从 OpenBSD GoT 集成 |
  | 2026.2 | diff3 替换为 OpenBSD 版本 |
  | 2026.6-7 | dialog/dpv 移除、gnu/ 目录退役 |

**史观**：形式主义膨胀〔订正注：原误挂总纲第 3 条，权威 3=不存在进步只有权力再分配，去号〕：GPL 移除工程的时间线考据本身是形式主义在历史书写中的延伸，每个 commit hash、审查票编号、日期的核实都是对叙事准确性的形式化追求；“GPL 清零”叙事存在被简化为单一事件的倾向，实际是跨越十余年、数十位开发者参与的多阶段工程

**辨析**：关键时间节点须严格考证：GCC 4.2.1 在 13.0（2021 年 4 月）已被移除，而非 16.0 才移除；dialog/dpv 移除和 gnu/目录清理在 16.0-CURRENT 分支完成，截至 2026 年 7 月尚未进入 RELEASE；部分二手媒体报道称“FreeBSD 4 年完成 GPL 清理”，这一时间计算可能从 bsddialog 开始开发或引入 base 算起，但整个替代工程实际跨度超过 15 年；须区分“LGPL”与“GPL”——dialog 部分版本可能使用 LGPL，同样属于 copyleft 许可范畴
