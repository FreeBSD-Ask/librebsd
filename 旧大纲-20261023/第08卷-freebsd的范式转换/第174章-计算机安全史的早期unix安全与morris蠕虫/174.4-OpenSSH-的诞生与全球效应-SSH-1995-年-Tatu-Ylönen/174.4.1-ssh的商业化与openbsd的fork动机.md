# 174.4.1 SSH 的商业化与 OpenBSD 的 fork 动机

**要点**：梳理 SSH 从开源到商业化的转变过程——Tatu Ylönen 1995 年开发 SSH 1.0 并以开放许可发布，1.2.12 为最后一个可自由复用的版本，此后 Datafellows 公司（后更名 SSH Communications Security）推出的后续版本许可逐步收紧（禁止 Windows/DOS 移植、禁止商业使用），同时因 libgmp 的 GPL 许可证问题构成合规风险，促使 OpenBSD 团队寻求完全自由的 SSH 实现

**史料**：OpenSSH Project History 官方页面、Ylönen 1996 年 SSH 论文、Björn Grönvall 的 OSSH 项目存档、1999 年 10 月 25 日 OpenBSD 官方新闻稿、SSH Communications Security 公司历史 ［A］

**史观**：开源运动：OpenSSH 的诞生是开源运动对软件商业化封闭趋势的直接回应——当一个关键基础设施工具从自由转向专有，社区有能力 fork 并重新建立开放的替代方案

**辨析**：OpenSSH 的直接上游是 Björn Grönvall 的 OSSH（基于 SSH 1.2.12），而非直接从 Tatu Ylönen 的 SSH fork；fork 的动机是复合的——许可证限制、GPL 污染、安全审计需求三者交织，不可简单归结为单一原因
