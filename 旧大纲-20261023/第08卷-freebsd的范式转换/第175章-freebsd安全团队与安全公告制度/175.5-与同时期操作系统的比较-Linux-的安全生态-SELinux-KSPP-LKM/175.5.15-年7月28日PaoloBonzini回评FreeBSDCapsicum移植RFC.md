# 175.5.15 年7月28日PaoloBonzini回评FreeBSDCapsicum移植RFC

2014 年 7 月 28 日，Paolo Bonzini 回评 FreeBSD Capsicum 移植 RFC，反对把权利检查放在打开文件上，坚持 they have to be in the file descriptor，理由是同一文件描述符可被 dup 后以不同能力传给不同进程，并举经 SCM_RIGHTS 传 eventfd 只允许写为例。以上为邮件列表当事人一手自述，属过程性证据，不得单独引为定论。
