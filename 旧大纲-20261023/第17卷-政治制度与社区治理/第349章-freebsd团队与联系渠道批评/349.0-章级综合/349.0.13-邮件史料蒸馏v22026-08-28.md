**观点**：Mike Smith 2002 年辞去 core team 职务时写道"FreeBSD used to be fun. It used to be about doing things the right way“，这是 BSD 社区治理疲劳的公开化——从”fun-driven“到”rule-driven"治理模式转型的阵痛，标志着 FreeBSD 从个人英雄主义到组织化维持的转变。
**邮件来源**：Mike Smith，freebsd-hackers，2002-05-08，Message-ID: `20020508221506.43B3F38CC@overcee.wemm.org`
**史学意义**：Smith 的辞职是 BSD 社区“创始人退出”模式的一部分——从 Charles Hannum 到 Satoshi Asami 到 Mike Smith，关键人物的离开标志着 BSD 从“个人英雄主义”到“组织化维持”的转变，是开源社区生命周期的普遍现象。
