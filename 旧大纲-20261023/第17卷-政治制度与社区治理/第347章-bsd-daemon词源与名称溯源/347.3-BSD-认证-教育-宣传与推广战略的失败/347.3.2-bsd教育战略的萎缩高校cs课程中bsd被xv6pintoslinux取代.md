# 347.3.2 BSD 教育战略的萎缩：高校 CS 课程中 BSD 被 xv6/Pintos/Linux 取代

  **要点**：1980-90 年代 BSD（特别是 4.4BSD-Lite 与 FreeBSD）曾是高校操作系统课程的主要教学平台；2000 年代后 MIT 6.828 课程采用 xv6（MIT 开发的类 Unix 教学内核，2006 年夏由 Russ Cox、Frans Kaashoek、Robert Morris（罗伯特·莫里斯） 编写，pdos.csail.mit.edu 6.828 历史档案 2006 年秋季首次使用，pdos.csail.mit.edu/6.828/2006 与 2012 xv6.html 交叉印证），斯坦福 CS140 自 21 世纪初采用 Pintos（Ben Pfaff 编写，pintos-os.org 官方档案确证 Pintos 系为 CS140 课程作为 Nachos 继任者开发，pintos-os.org 主页与 SIGCSE 2009 论文交叉印证，具体起始年份须通过 CS140 历届课程档案进一步核查），伯克利 CS162 等高校的 BSD 课程逐渐被 Linux 与教学内核取代；Linux 内核因其开源与商业普及性逐渐取代 BSD 作为高校 OS 教学内核；BSD 在高校 CS 课程的萎缩直接导致 BSD 社区新鲜血液不足（参见相关章节提交者老龄化部分）；BSD 教育战略的缺位反映 FreeBSD Foundation 对高校教育投入不足
  **史料**：MIT 6.828 课程档案；斯坦福 CS140 Pintos 档案；伯克利 CS162 课程档案；FreeBSD Foundation 教育项目档案；高校 CS 课程教材演变档案 ［B］
  **史观**：教育战略萎缩是 BSD 反向影响线断裂的关键节点（专题语，不设总纲条号）；总纲第 15 条——文化即形式主义，教育是文明延续的根本，BSD 教育萎缩即 BSD 文明的代际断层
  **辨析**：“BSD 是 1980-90 年代高校 OS 教学主要平台”的判断须考据具体高校与课程；xv6 与 Pintos 的兴起是否直接取代 BSD 须分课程验证；FreeBSD Foundation 教育项目（如 FreeBSD Journal、文档项目）的具体投入与产出须量化考据
