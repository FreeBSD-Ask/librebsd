# 354.1.4 BSD/Linux 论战俚语、版本号俚语与工具命令俚语：GNUtian、BSD is dying、CURRENT/STABLE、make buildworld 与 ZFS 的工程话语

  **要点**：BSD/Linux 论战俚语、版本号俚语与工具命令俚语是 BSD/UNIX 社区工程话语层的三类核心词汇。BSD/Linux 论战俚语覆盖阵营称谓（GNUtian、Linux fanboy、BSD fanboy、GPL troll、BSD troll）、商业领袖言论（“Linux is a cancer”，Steve Ballmer 2001 年）、recurring 梗（“BSD is dying”，无单一源头，每隔数年重新出现）与排他性论调（“If it‘s not Linux, it’s not Unix”）四类。版本号俚语覆盖分支命名（CURRENT、STABLE、RELEASE、PRERELEASE、BETA、RC）、补丁级别（-p0/-p1/-p2）、候选版本（-RC1/-RC2、-ALPHA）、分支术语（tip-of-tree、trunk、main、master（已弃用）、head、vendor branch、upstream、downstream）四类，其中 master 分支名称自 2020 年起因包容性考量被 Git、GitHub、FreeBSD 等项目逐步替换为 main，FreeBSD 仓库于 2020 年从 Subversion 迁移至 Git 时即采用 main 作为主分支名称。工具命令俚语覆盖编译器与虚拟化（clang、LLVM、ZFS、DTrace、bhyve）、BSD 专属工具（jail、capsicum、**pf(4)**、**ipfw(8)**）与构建命令（make buildworld、make installworld、make buildkernel、make installkernel、mergemaster、portsnap、pkg）三类，ZFS 被社区称为“最后的文件系统”（The Last Word in File Systems），**jail(8)** 是 BSD 容器化的先驱，**pf(4)** 是 OpenBSD 主导的包过滤器，**bhyve(8)** 是 FreeBSD 原生虚拟机监视器
  **史料**：Jargon File 4.4.7 版本（`catb.org/jargon/`，GNUtian、Linux fanboy、BSD fanboy、GPL troll、BSD troll、“Linux is a cancer”、“BSD is dying”、“If it‘s not Linux, it’s not Unix”词条，经一手核验）；Steve Ballmer 2001 年关于“Linux is a cancer”的言论（经多源核验，Ballmer 在 2001 年 6 月接受 Chicago Sun-Times 采访时发表此言论）；FreeBSD Committer's Guide（`docs.freebsd.org/en/articles/committers-guide/`，分支约定"Noteworthy src/ Git Branches: stable/n (n-STABLE), main (-CURRENT)"，经一手核验）；Git 项目文档（`git-scm.com/docs/`，git-cherry-pick、master/main 分支名称变更说明，经一手核验）；FreeBSD Manual Pages（`man.freebsd.org`，**pf(4)**、**ipfw(8)**、**jail(8)**、**bhyve(8)**、**capsicum(4)**、**zfs(8)**、**dtrace(1)** 手册页 HISTORY 段，经一手核验）；OpenBSD Project Goals（`openbsd.org/goals.html`，OpenBSD 治理结构与项目目标，经一手核验）；`comp.unix.bsd.*` Usenet 存档（`groups.google.com`，早期 BSD/Linux 论战场所，经互联网档案馆存档核验）［A］
  **史观**：总纲第 8 条——本体论上各方平等，BSD 阵营与 Linux 阵营、BSD license 与 GPL、master 与 main 分支名称在本体论上地位相等，无道德高下之分；总纲第 13 条——法律与道德是利益分配，“Linux is a cancer”（Steve Ballmer 2001）与“BSD is dying”（recurring 梗）是商业公司（Microsoft）与开源阵营（Linux 社区）对竞争对手的话语攻击，皆是利益分配的话语呈现；总纲第 19 条——解释学循环是历史认识的根本条件（原“解释学循环与权力知识共谋”系增衍名目，正名），BSD/Linux 论战俚语的传播受前理解差异制约（BSD 阵营以“工程传统”为前理解，Linux 阵营以“治理现代化”为前理解），话语权争夺的非对称性是权力知识共谋的具体显现；总纲第 21 条——革命与改革，master 分支名称被 main 替换是“革命性”重构，FreeBSD Core Bylaws 2000 年章程沿用 26 年至 2026 新章程是“改革性”调整，二者在本体论上地位相等；总纲第 23 条——一切历史写作都是基于哲学设定的历史小说，本节作为 BSD/Linux 论战俚语、版本号俚语与工具命令俚语的审视本身是历史小说，史家须自觉呈现自身的哲学设定
