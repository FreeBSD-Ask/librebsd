# 354.1.5 文件系统俚语与文化梗：UFS、FFS、ZFS、HAMMER、BSD is dying 与 recurring 梗的文化基因

  **要点**：文件系统俚语与文化梗是 BSD/UNIX 社区技术话语与文化叙事的两类核心层。文件系统俚语覆盖 BSD/UNIX 文件系统名称（UFS、FFS、ZFS、HAMMER、HAMMER2、LFS、tmpfs、fdescfs、procfs、linprocfs、nullfs、unionfs、mdconfig、geli、gbde），UFS（Unix File System）是 UNIX 最早的文件系统，FFS（Fast File System）是 BSD 4.2（1983）引入的优化版本，ZFS（Zettabyte File System）是 Sun Microsystems 2005 年发布的现代文件系统，HAMMER 与 HAMMER2 是 DragonFly BSD 主导的文件系统，tmpfs 是内存文件系统，procfs 与 linprocfs 是进程文件系统（linprocfs 为 FreeBSD 提供 Linux 兼容性）。文化梗与 recurring 梗覆盖 BSD is dying（自 1990s 至今的 recurring 梗，无单一源头，每隔数年在 BSD 重大事件时重新出现）、“In Soviet Russia, BSD forks you”（源自 Yakov Smirnoff“In Soviet Russia”笑话格式的变体）、“Compile the kernel”（编译内核，BSD 文化对从源码构建系统的强调）、“Did you try turning it off and on again”（IT Crowd 经典台词，技术支持文化的自嘲）、“It works on my machine”（开发者推卸 bug 责任的常见借口）、“PEBKAC”（Problem Exists Between Keyboard And Chair，技术支持黑话）、BSD vs Linux flame war（BSD 与 Linux 阵营的论战传统）、“Get a real OS”（BSD 阵营对 Linux 的反击）、“sudo make me a sandwich”（xkcd 漫画引发的梗，结合 sudo 命令与 sandwich 网络迷因）。BSD is dying 梗是 BSD 社区身份认同的核心副产品，BSD 项目长期处于 Linux 阴影下但持续活跃，故“消亡论”与“持续活跃的现实”形成持续张力，催生此 recurring 梗
  **史料**：Jargon File 4.4.7 版本（`catb.org/jargon/`，BSD is dying、“In Soviet Russia, BSD forks you”、“Compile the kernel”、“Did you try turning it off and on again”、“It works on my machine”、“PEBKAC”、BSD vs Linux flame war、“Get a real OS”、“sudo make me a sandwich”词条，经一手核验）；FreeBSD Manual Pages（`man.freebsd.org`，**ffs(7)**、**ufs(7)**、**zfs(8)**、**tmpfs(5)**、**procfs(5)**、**linprocfs(5)**、**mdconfig(8)**、**geli(8)**、**gbde(8)** 手册页 HISTORY 段，经一手核验）；DragonFly BSD HAMMER 文件系统文档（`dragonflybsd.org/docs/`，HAMMER 与 HAMMER2 设计文档，经一手核验）；OpenBSD Project Goals（`openbsd.org/goals.html`，OpenBSD 治理结构与项目目标，经一手核验）；xkcd 漫画“sudo make me a sandwich”（`xkcd.com/149/`，2006 年发布，经一手核验）；IT Crowd 电视剧（Channel 4, 2006-2013，“Did you try turning it off and on again”经典台词来源，经一手核验）［A］
  **史观**：专题语（不设总纲条号）——文化历史哲学（原挂总纲第 7 条系自创名目，删条号），文件系统俚语（UFS、FFS、ZFS、HAMMER）的命名层积是 BSD/UNIX 技术话语的文化编码，词源考的真正意义不在还原“原义”而在揭示“语义层积”的过程；总纲第 8 条——本体论上各方平等，UFS、FFS、ZFS、HAMMER 各文件系统在本体论上地位相等，无道德高下之分；总纲第 13 条——法律与道德是利益分配，ZFS 由 Sun Microsystems（后被 Oracle 收购）开发，其 CDDL 许可证与 BSD license 的兼容性问题是利益分配的具体显现；总纲第 19 条——解释学循环是历史认识的根本条件（原“解释学循环与权力知识共谋”系增衍名目，正名），“BSD is dying”梗的传播渠道非对称性（Linux 阵营多渠道 vs BSD 阵营 `freebsd-advocacy` 邮件列表 2022-2024 年共 7 条消息，经 `lists.freebsd.org/archives/freebsd-advocacy/` 一手核验）是权力知识共谋的具体显现，“什么被记录、什么被遗忘”本身就是权力行使；总纲第 21 条——革命与改革，ZFS 是 Sun Microsystems“革命性”文件系统重构，HAMMER 是 DragonFly BSD“改革性”文件系统设计，二者在本体论上地位相等；总纲第 23 条——一切历史写作都是基于哲学设定的历史小说，本节作为文件系统俚语与文化梗的审视本身是历史小说，史家须自觉呈现自身的哲学设定
