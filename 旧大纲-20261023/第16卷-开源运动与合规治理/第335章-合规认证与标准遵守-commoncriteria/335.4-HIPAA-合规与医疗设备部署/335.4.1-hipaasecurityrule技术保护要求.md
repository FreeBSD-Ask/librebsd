# 335.4.1 HIPAA Security Rule 技术保护要求


103.10 **HIPAA 合规与医疗设备部署**———HIPAA（Health Insurance Portability and Accountability Act，健康保险流通与责任法案）1996 年由美国国会通过，建立电子受保护健康信息（ePHI）的国家级隐私与安全标准，2009 年 HITECH Act 加强直接追究业务伙伴（Business Associate）责任并大幅提高民事罚款，2013 年 Omnibus Rule 将 HITECH 修订纳入 HIPAA 规则

  **要点**：HIPAA Security Rule 45 CFR §164.312 要求 ePHI 的访问控制、审计控制、完整性、身份验证、传输安全，FreeBSD 的 **auditd(8)** 与 OpenBSM 可作为审计控制实现

| HIPAA 法案/修订 | 公法编号 | 通过日期 | 备注 |
| ------------- | ------ | ------ | -- |
| HIPAA 1996 | Public Law 104-191 | 1996-08-21 | 104th Congress H.R. 3103 |
| HITECH Act | 2009 | - | 加强直接追究业务伙伴（Business Associate）责任并大幅提高民事罚款 |
| Omnibus Rule | 2013 | - | 将 HITECH 修订纳入 HIPAA 规则 |

| 45 CFR §164.312 技术保护要求 | FreeBSD 实现工具 |
| -------------------------- | -------------- |
| 访问控制 | MAC 框架 |
| 审计控制 | **auditd(8)** 与 OpenBSM |
| 完整性 | ZFS、文件系统校验 |
| 身份验证 | PAM、Kerberos |
| 传输安全 | OpenSSL |
