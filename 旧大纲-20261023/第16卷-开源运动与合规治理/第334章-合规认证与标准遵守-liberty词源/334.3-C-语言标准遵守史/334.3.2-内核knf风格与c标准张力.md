# 334.3.2 内核 KNF 风格与 C 标准张力

**要点**：FreeBSD 内核沿用 CSRG/4.4BSD 的 KNF（Kernel Normal Form）风格，对 C 标准新特性（如 C99 变长数组、C11 _Generic）的采纳保守，常滞后于用户空间
**史料**：FreeBSD src/share/misc/style 文件、freebsd-hackers 邮件列表关于 KNF 与 C 标准的讨论、style(9) 手册页 ［A］
**史观**：延续与终结，KNF 风格是 BSD 传统的延续，对 C 新特性的保守是形式上的克制
**辨析**：内核中是否完全禁用变长数组存在争议，2017 年后部分驱动引入 VLA 但 2020 年又移除；**style(9)** 的具体条款版本演变需追溯
**文献**：FreeBSD style(9) 手册页；McKusick M K. Twenty Years of Berkeley Unix: From AT&T-Owned to Freely Redistributable[M]//Open Sources: Voices from the Open Source Revolution. Sebastopol: O'Reilly, 1999.（原引题名“Twenty Years of Berkeley Software Distribution”系通行题名变体，已按 O'Reilly 原书目录校正） ［A］
