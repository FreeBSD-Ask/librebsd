# 367.3.1 JBUG 的用户组历史


108.3 **日本 BSD 用户组与会议**———日本 FreeBSD 用户组（JBUG）1990 年代成立，BSD 会议包括 AsiaBSDCon（首届 2004 年于台北，2007 年届在东京）[修正脚注]与 BSD 关西会议，日本 BSD 用户组的邮件列表与 IRC 频道是社区交流的核心渠道

  **要点**：日本 BSD 用户组（JBUG，Japan BSD Users Group）1990 年代末成立，由 IIJ 与 WIDE 项目的系统管理员发起，早期东京、大阪、名古屋等城市均有本地用户组。JBUG 的邮件列表（freebsd-users-jp）与 IRC 频道（#bsd-jp）是日本 BSD 用户交流的核心渠道。
  **史料**：JBUG 邮件列表 Archive、freebsd-users-jp 档案、JBUG 早期活动记录 ［A］
  **史观**：总纲第 22 条——日本 BSD 用户组是 BSD 社区去中心化组织结构的重要体现
  **辨析**：JBUG 的确切成立日期需考据；东京/大阪/名古屋各地用户组的活跃时间需分析
  **文献**：freebsd-users-jp Mailing List Archive；JBUG 活动记录 ［A］
