# 371.3.1 USP/UNICAMP/UBA/PUC 的 BSD 课程

  **要点**：巴西 USP（圣保罗大学）、UNICAMP、阿根廷 UBA（布宜诺斯艾利斯大学）、智利 PUC（天主教大学）等高校开设 BSD 相关课程；课程以 FreeBSD 与 Linux 并重，部分课程使用 BSD 作为操作系统课程实验平台；具体课程设置须经高校教务档案核查
  **史料**：南美高校课程目录、freebsd-hackers 邮件列表中高校教师讨论 ［A］
  **史观**：组织结构对技术路径的塑造，南美高校的 BSD 教学传统塑造本土 BSD 人才储备
  **辨析**：高校 BSD 教学的具体规模须经教务档案核查；“BSD 课程” 的判定标准须明确
  **文献**：USP、UNICAMP、UBA、PUC 课程目录；freebsd-hackers 邮件列表 ［A］
