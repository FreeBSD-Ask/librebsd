# 371.17.2 公众认知从无知到偏见的演变

  **要点**：1990 年代南美公众对 BSD 普遍无知，将其与 Linux 混淆；2000 年代后随 GPL 与自由软件运动主流化，BSD 被部分公众视为 “允许闭源的妥协许可证”；演变须通过历届 FISL 公众调查与媒体报道分析
  **史料**：FISL 历届公众调查、南美技术媒体报道、BSD 与 Linux 用户论坛讨论 ［C］
  **史观**：技术路线的分化与并行演化，公众认知的演变反映许可证意识形态的分化
  **辨析**：“无知” 与 “偏见” 的判断标准须明确；GPL 阵营对 BSD 许可证的批评是否被公众准确理解须考据
  **文献**：FISL 公众调查档案；南美技术媒体存档；BSD 与 Linux 用户论坛历史讨论 ［A］
