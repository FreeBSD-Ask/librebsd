# 371.19.1 FUG-BR 历届协调人的贡献

  **要点**：FUG-BR 历届协调人维持了南美最大 BSD 社区的运作；协调人的具体贡献包括邮件列表维护、新成员引导、与 FreeBSD Foundation 的联络；贡献的具体内容须通过 FUG-BR 邮件列表与协调人自述核查
  **史料**：FUG-BR 邮件列表存档、协调人自述、FreeBSD Foundation 年度报告 ［A］；openbsd.duckdb 查询 L3.3.1 显示：22 仓库合计 committer_date 时区偏移分布中，拉美主要时区 -02:00（巴西东南部，含里约热内卢、圣保罗）13,306 commit / 1,069 贡献者，-03:00（巴西东部、阿根廷、乌拉圭，与加拿大海洋省份共用）58,281 / 2,962，-04:00（智利、玻利维亚、委内瑞拉，与加拿大海洋省份共用）181,933 / 9,386，-05:00（秘鲁、哥伦比亚，与美国东部共用）144,926 / 8,901，因 -03:00/-04:00/-05:00 与北美共用，仅 -02:00 为巴西独占时区；openbsd.duckdb 查询 L3.3.2 显示：author_email TLD 分布中 .br 域 1,144 commit / 112 unique emails（巴西 ccTLD，唯一进入前 15 的拉美 ccTLD），其他拉美 ccTLD（.ar/.cl/.mx/.co/.pe/.ve 等）归入 other 类
  **史观**：边缘者的贡献被中心叙事遮蔽，FUG-BR 协调人的工作在 BSD 全球叙事中长期被忽视；统计结论印证：统计结论 [L3.3.1] 时区分布 -02:00 巴西独占 13,306 commit / 1,069 贡献者（-03:00/-04:00/-05:00 与北美共用无法单独区分拉美贡献者）与统计结论 [L3.3.2] TLD 分布 .br 1,144 commit / 112 unique emails 为唯一进入前 15 的拉美 ccTLD 共同印证拉美作为 BSD 社区边缘地带的量化基础，与 148.19.1 节所述“FUG-BR 协调人的工作在 BSD 全球叙事中长期被忽视”在数据层面互证——巴西独占 -02:00 时区 commit 量与 .br ccTLD 邮箱数均偏低，反映总纲第 10 条边缘者批评的量化印证；freebsd.duckdb L3.3.1/L3.3.2 查询覆盖 freebsd-src 等 22 仓库 commit author_email 时区推断与 TLD 提取
  **辨析**：协调人名单须通过 FUG-BR 邮件列表核实；贡献的量化须避免事后美化；【0 信任原则·地理识别局限】author_email TLD 不等于实际地理位置，.br 邮箱可由旅巴外籍人员使用，且 -03:00/-04:00/-05:00 与北美共用，时区偏移无法区分拉美与北美贡献者，仅 -02:00 为巴西独占，时区偏移不等于居住地，远程办公、VPN、移民等因素使时区—地理位置映射须慎重；【0 信任原则·committer_date 异常】L3.3.1 基于 committer_date 提取时区偏移，但 GitHub 镜像仓库的 committer_date 可能被重写为同步时间，分析时须改用 author_date 复核；【0 信任原则·author 字段可伪造】L3.3.2 基于 author_email 统计，.br 域数据仅为下限，且其他拉美 ccTLD 未单独列出，部分拉美贡献者使用 .com 邮箱提交，未计入对应 ccTLD
  **文献**：FUG-BR 邮件列表存档；协调人个人页面或访谈；FreeBSD Foundation 年度报告 ［A］；openbsd.duckdb 查询 L3.3.1（committer_date 时区偏移分布前 30，22 仓库合计，30 行结果）、L3.3.2（author_email 域名 TLD 分布，22 仓库合计，16 行结果），见 `原材料/研究/bsd仓库分析/数据分析/深层信息挖掘.md` §L3.3.1、§L3.3.2
