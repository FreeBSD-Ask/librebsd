# 372.1.4 南非 BSD 史料辨析

  **要点**：南非 BSD 史料以邮件列表、企业档案、技术媒体报道为主，缺乏系统性的学术研究；企业档案须警惕商业秘密限制；媒体报道须警惕政治立场与商业利益
  **史料**：ZA FreeBSD User Group 邮件列表、南非 ISP 与银行企业档案、南非技术媒体报道 ［A］
  **史观**：终结中的延续，史料辨析是南非 BSD 史研究的基础
  **辨析**：企业档案的可获得性须评估——商业秘密限制可能导致关键数据缺失；媒体报道的覆盖率须量化
  **文献**：ZA FreeBSD User Group 邮件列表存档；南非 ISP 与银行企业档案；南非技术媒体存档 ［A］
