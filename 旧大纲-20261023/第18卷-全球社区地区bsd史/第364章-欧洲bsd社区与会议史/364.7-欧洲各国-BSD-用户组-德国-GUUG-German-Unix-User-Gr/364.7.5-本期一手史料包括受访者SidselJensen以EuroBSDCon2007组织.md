# 364.7.5 本期一手史料包括受访者SidselJensen以EuroBSDCon2007组织

**史料**：

- 本期一手史料包括：受访者 Sidsel Jensen 以 EuroBSDCon 2007 组织者身份的全程口述（会议缘起、筹备实务与程序委员会数据）；片头新闻提及的 SDF 公共访问 Unix 系统创立二十周年（1987 至 2007）与 NetBSD 官网改版上线；节目明示的 EuroBSDCon 2007 官方网站 2007.eurobsdcon.org 征稿与注册信息；节目存档址 bsdtalk.blogspot.com。（BSDTalk EP118，[39.52-491.84]，L1）

**史观**：

- 总纲5 偶然性优先：偶然性优先：受访者从 Linux 转向 FreeBSD 的经历表明，用户技术路线的分岔并非产品优劣理性权衡的产物，而是由一次偶发的社区人际干预决定——“有人过来说，不，这不是合适的操作系统，你该用这个”（2007-06-22，383.88-392.16），随后一张光盘改写了其此后七年的操作系统生涯；个体采用史由无数此类微小偶然累积而成，构成社区技术扩散的真实底层。（BSDTalk EP118，[380.92-392.16]，L1）
- 总纲10 动手者创造历史：动手者创造历史：EuroBSDCon 2007 的组织架构中没有职业会议经理人，只有 BSD 用户组前董事、既有 Linux 会议的志愿操办者与受同侪相邀而入的业余组织者；会议史的书写重心因此不在台前演讲的名家，而在敲定旅舍、预算与日程的台下之手——正是这些默默做事者把分散于欧洲各国的开发者维系为年度相聚的共同体。（BSDTalk EP118，[317.1-358.68]，L1）
- 总纲10 动手者创造历史：BSD会议与用户组的运转被当事人归结为“这些活动因人们主动帮忙而发生”：其本人卷入始于一句愿出讲者、缺人组织，帮忙者渐被赋予更多职责；BSD会议由志愿者为志愿者及同好而办，曼彻斯特BSD用户组更是从朋友每月酒馆聚会自然生长、靠邮件列表被检索到而延续八年——社区的实体存在系于动手者的持续到场而非正式建制。（BSDTalk EP187，[1322.04-1475.54]，L1）

**辨析**：

- 转写与口述的可信度须双重核验：其一，本期自动转写对专名存在系统性识别错误，EuroBSDCon 误作 Euribus Decon、FreeBSD 误作 frig.SD、Mac OS X 误作 megawiss、ZFS 误作 set of file system、UFS 误作 USB，凡引用均须对照音频校正；其二，会议 2001 年发起缘起仅系受访者转述，其自身亦以“我们创办了会议，或者说英国人创办了会议”（2007-06-22，109.8-113.92）含糊带过，与会议史的精确纪年须另行多源交叉核对。 [存疑脚注] 自动转写专名错误未对照音频逐段复核；EuroBSDCon 2001 年发起细节仅有本期受访者间接转述一源，发起人名单、首届议程与 364.1 节通行纪年（2001 年 11 月 9-11 日）的对应关系待考。（BSDTalk EP118，[86.52-113.92]，L4）
- 本期转写专名失真：“Plotting Camp”应为Poul-Henning Kamp，“Eurostecom”应为EuroBSDCon，FreeBSD jail机来源“Exynatrik”无法辨识（疑为某供应商名，存疑）；当事人对UKUUG会员构成的描述援引自其记忆中的会员调查而未给出调查年份，[存疑脚注] 上述专名与调查时点引用前须对照原始资料核正。 [存疑脚注] 会员调查年份不详，Exynatrik所指不明，专名核正系依语境推断。（BSDTalk EP187，[650.88-679.52]，L4）
