# 380.0.6 345.2.2 印度 BSD 用户组的活动形式

- 要点：印度 BSD 用户组的活动以技术讲座（Tech Talks）、BSD 安装会（Install Fest）、黑客松（Hackathon）为主，活动频率低于欧美 BSD 用户组。印度 BSD 用户组与印度 Linux 用户组（ILUG）有交叉参与，部分 BSD 用户同时活跃于 Linux 社区
- 史料：印度 BSD 用户组活动照片与记录、印度 BSD 技术讲座议程、印度 BSD 用户组博客 ［C］
- 史观：总纲第 20 条（历史地理塑造思想土壤）——印度 BSD 用户组是 BSD 在南亚地方组织化的载体
- 辨析：印度 committer 的具体人数需统计；印度裔 committer 中居住于印度本土的比例需区分；【0 信任原则·地理识别局限·author_email 域名不等于实际地理位置】L3.3.2 基于 author_email 域名 TLD 统计，.in 仅统计邮箱后缀为 .in 的贡献者，大量印度本土贡献者使用 .com（Gmail 等）、.org、.edu（IIT 等高校）邮箱，其实际地理位置无法由邮箱域名推断，.in 统计仅构成本土贡献者占比的下限
  - 文献：FreeBSD Committers List；NetBSD Developers List ［A］；openbsd.duckdb 查询 L3.3.2（author_email 域名 TLD 分布，16 行结果），见 `原材料/研究/bsd仓库分析/数据分析/深层信息挖掘.md` §L3.3.2
