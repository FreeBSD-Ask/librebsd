# 380.0.5 345.2.1 印度 BSD 用户组的形成

- 要点：印度 BSD 社区与用户组包括 Bangalore BSD Users Group（驻印度硅谷班加罗尔）、Mumbai BSD Users Group、Delhi BSD Users Group 等；印度 BSD 用户组在 2000 年代形成，以班加罗尔（印度硅谷）、孟买、德里、海德拉巴、钦奈等 IT 中心为主要聚集地。Bangalore BSD Users Group（BBUG）是印度最大的 BSD 用户组，受益于班加罗尔作为印度 IT 产业中心的地位
- 辨析：各用户组的确切成立日期需考据；不同城市用户组的活跃度对比需分析
