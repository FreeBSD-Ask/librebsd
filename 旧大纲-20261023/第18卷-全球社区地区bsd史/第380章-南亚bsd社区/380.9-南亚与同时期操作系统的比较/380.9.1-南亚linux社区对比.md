# 380.9.1 南亚 Linux 社区对比


南亚与同时期操作系统社区的对比：南亚 Linux 社区（印度 Linux 用户组 ILUG、巴基斯坦 Linux 用户组）、南亚在 IT 产业中的独特地位（外包大国）、南亚 BSD 社区的极度边缘化。

  **要点**：南亚 Linux 社区（以印度 Linux 用户组 ILUG 为核心，1990 年代成立）规模远超 BSD 社区，ILUG 在班加罗尔、孟买、德里、钦奈等城市有活跃分会。印度 Linux 内核贡献者包括 Amit Shah（虚拟化）、Aneesh Kumar K.V.（ext4 文件系统）等。南亚 Linux 社区受益于印度 IT 产业的巨大规模
  **史料**：ILUG 记录、印度 Linux 内核贡献者列表、南亚 OS 社区对比研究〔L3 官方文档与公告/L5 二手研究〕
  **史观**：总纲第 6 条——和解优于斗争；本节引申：南亚 Linux 与 BSD 社区的分化与并行演化是社区间和平共处、各自演化的体现
  **辨析**：南亚 Linux 社区的具体规模需统计；Linux 在南亚超越 BSD 的时间节点需考据
