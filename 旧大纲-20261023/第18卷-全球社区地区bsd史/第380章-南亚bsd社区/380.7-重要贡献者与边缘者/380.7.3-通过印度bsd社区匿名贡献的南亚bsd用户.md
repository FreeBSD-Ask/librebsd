# 380.7.3 通过印度 BSD 社区匿名贡献的南亚 BSD 用户

  **要点**：大量南亚 BSD 用户通过印度 BSD 社区（BBUG 等）匿名贡献（如技术问答、文档翻译），他们的贡献在全球 BSD 历史叙事中几乎完全不可见，其姓名与贡献内容已不可考
  **史料**：印度 BSD 用户组匿名贡献记录、BBUG 邮件列表、南亚 BSD 用户匿名贡献 ［D］
  **史观**：总纲第 10 条——通过印度 BSD 社区匿名贡献的南亚 BSD 用户是 BSD 历史上最不可见的 “动手者”
  **辨析**：匿名贡献者的具体名单已不可考；其贡献的具体内容与影响需评估
  **文献**：BBUG 邮件列表 Archive；印度 BSD 用户组记录 ［A］
