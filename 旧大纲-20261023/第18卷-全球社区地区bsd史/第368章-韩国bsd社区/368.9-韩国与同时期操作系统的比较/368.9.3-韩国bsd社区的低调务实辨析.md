# 368.9.3 韩国 BSD 社区的低调务实辨析

  **要点**：韩国 BSD 社区以低调务实著称属待验证命题〔存疑：风格判断缺乏一手依据，须以邮件列表存档区间与消息量、BSD 相关会议韩国场次等可核数据支撑〕——与日本 BSD 社区相比，韩国 BSD 社区规模较小〔存疑：会员数对比无公开统计〕但凝聚力强，韩国 BSD 用户多为系统管理员与企业工程师〔存疑：从业构成无公开调查，基于社区早期邮件自述〕，社区活动以技术实践为导向，较少参与 BSD 治理讨论〔存疑：参与治理的量化证据待核〕
  **史料**：韩国 BSD 邮件列表存档〔存疑：具体列表与区间待核〕；BSD 相关会议韩国场次记录〔存疑〕；韩国 BSD 用户访谈记录〔存疑：访谈对象与入库 id 待核〕 ［B］
  **史观**：总纲第 8 条——韩国 BSD 社区的务实风格是对全球 BSD 社区 “动手者” 传统的延续
  **辨析**：韩国 BSD 社区的低调是否影响了其国际影响力需以邮件线程与会议记录为据；与日本 BSD 社区的对比需考据〔存疑〕
  **文献**：韩国 BSD 社区活动记录；韩国 BSD 用户访谈 ［B］
