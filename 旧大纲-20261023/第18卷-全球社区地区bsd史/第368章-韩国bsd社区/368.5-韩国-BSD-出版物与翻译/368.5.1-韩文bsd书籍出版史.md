# 368.5.1 韩文 BSD 书籍出版史


109.5 **韩国 BSD 出版物与翻译**———韩国 BSD 出版物与翻译包括《FreeBSD 完全理解》（프리 BSD 완전이해）等韩文 BSD 书籍、FreeBSD 手册韩文翻译、韩国 BSD 技术博客

  **要点**：韩国 BSD 出版物包括《FreeBSD 完全理解》（프리 BSD 완전이해，2000 年代初出版）、《FreeBSD 服务器构建指南》（프리 BSD 서버 구축 가이드）等韩文 BSD 书籍。韩文 BSD 书籍的出版方包括 Hanbit Media（한빛미디어）、Youngjin.com（영진닷컴）等韩国 IT 出版商
  **史料**：韩文 BSD 书籍出版目录、Hanbit Media 书目、Youngjin.com 书目 ［B］
  **史观**：总纲第 15 条——韩文 BSD 出版物是 BSD 文化在韩国形式主义化的重要载体
  **辨析**：各书籍的具体出版日期需考据；韩文翻译的准确性需评估
  **文献**：Hanbit Media BSD 书籍目录；Youngjin.com BSD 书籍记录 ［B］
