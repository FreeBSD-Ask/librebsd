# 368.2.1 韩国 BSD 用户组的组织演变


**韩国 BSD 用户组与会议**——韩国 BSD 用户组定期举办 BSD 安装会与研讨会，韩国 BSD 社区参与 AsiaBSDCon（2007 年东京首届起；此前亚洲 BSD 会议先例为 2004 年台北 USENIX Asia BSD Conference），韩国开源社区会议（如 KOSSCON、FOSSASIA）中 BSD 的参与

  **要点**：韩国 BSD 用户组从 1990 年代末的在线社区（Daum Cafe）逐步演变为线下定期聚会，2000 年代后在首尔（江南区、弘大区域）、大田（KAIST 周边）、大邱等地举办 BSD 安装会与研讨会。韩国 BSD 用户组与 Linux 社区（Korea Linux Forum）有交叉参与。
