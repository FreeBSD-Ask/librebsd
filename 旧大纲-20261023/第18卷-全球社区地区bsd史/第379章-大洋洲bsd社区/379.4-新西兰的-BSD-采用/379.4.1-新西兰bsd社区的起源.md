# 379.4.1 新西兰 BSD 社区的起源


118.4 **新西兰的 BSD 采用**———新西兰 BSD 采用以奥克兰与惠灵顿为中心，新西兰 ISP（如 Xtra、Vodafone NZ）在早期使用 FreeBSD，新西兰 BSD 社区规模较小但持续活跃

**要点**：新西兰 BSD 社区以奥克兰（Auckland）与惠灵顿（Wellington）为中心，新西兰互联网早期（1990 年代，以 Waikato University 的早期网络连接为代表）使用 BSD 系统。新西兰 ISP（如 Xtra、Vodafone NZ、Orcon）在 1990 年代使用 FreeBSD 作为网络服务器
