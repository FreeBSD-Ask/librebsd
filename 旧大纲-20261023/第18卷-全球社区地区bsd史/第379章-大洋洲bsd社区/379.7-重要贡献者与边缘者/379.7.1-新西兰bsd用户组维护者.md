# 379.7.1 新西兰 BSD 用户组维护者


118.7 **重要贡献者与边缘者：被忽视的大洋洲 BSD 社区维护者**———大洋洲 BSD 社区中被忽视的维护者包括新西兰 BSD 用户组维护者、太平洋岛国 BSD 用户、澳大利亚偏远地区 BSD 用户、被 Peter Wemm（彼得·韦姆） 与 Bruce Evans 主导叙事遮蔽的澳大利亚 BSD 贡献者

**要点**：新西兰 BSD 用户组维护者（NZ-BUG 的组织者）的贡献被澳大利亚 BSD 社区的光芒遮蔽，新西兰 BSD 社区在大洋洲 BSD 叙事中处于边缘地位。新西兰 BSD 用户组的规模与活跃度远低于澳大利亚 SBUG/MBUG

**史料**：NZ-BUG 组织者记录、新西兰 BSD 用户组活动记录、大洋洲 BSD 社区对比分析［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］；openbsd.duckdb 查询 L3.3.2 显示：author_email TLD 分布中 .au 域 10,866 commit / 150 unique emails（澳大利亚 ccTLD），.nz 域（新西兰）未单独列出归入 other 类，表明大洋洲 ccTLD 邮箱在 22 仓库中占比偏低；openbsd.duckdb 查询 L3.3.1 显示：22 仓库合计 committer_date 时区偏移分布中，+10:00（澳大利亚东部，含悉尼、墨尔本、布里斯班）30,414 commit / 1,809 贡献者，+09:30（澳大利亚中部，含阿德莱德）1,216 commit / 258 贡献者，+10:30（澳大利亚 Lord Howe）1,207 commit / 215 贡献者，+12:00（新西兰、斐济）343 commit / 61 贡献者（与俄罗斯彼得罗巴甫洛夫斯克共用）

**史观**：总纲第 10 条——新西兰 BSD 用户组维护者是大洋洲 BSD 社区被忽视的 “边缘者”；统计结论印证：统计结论 [L3.3.1] 时区分布大洋洲主要时区 +10:00（澳大利亚东部）30,414 commit / 1,809 贡献者、+09:30（澳大利亚中部）1,216 commit / 258 贡献者、+10:30（澳大利亚 Lord Howe）1,207 commit / 215 贡献者、+12:00（新西兰、斐济）343 commit / 61 贡献者（与俄罗斯彼得罗巴甫洛夫斯克共用）中，新西兰所在 +12:00 与俄罗斯共用无法单独区分新西兰贡献者，与统计结论 [L3.3.2] TLD 分布 .au 域 10,866 commit / 150 unique emails（澳大利亚 ccTLD）但 .nz 域（新西兰）未单独列出归入 other 类（other 类合计 1,277,384 commit / 4,252 unique emails）共同印证新西兰作为大洋洲 BSD 社区被忽视的 “边缘者” 的量化边缘性，与 153.7.1 节所述 “新西兰 BSD 用户组维护者是大洋洲 BSD 社区被忽视的边缘者” 在数据层面形成 “叙事存在但量化缺失” 的张力——新西兰 BSD 社区以 NZ-BUG 用户组、奥克兰/惠灵顿 BSD 部署等形式存在但 .nz 域邮箱在 22 仓库中未单独列出，反映总纲第 10 条边缘者批评的量化印证；freebsd.duckdb L3.3.1/L3.3.2 查询覆盖 freebsd-src 等 22 仓库 commit author_email 时区推断与 TLD 提取

**辨析**：新西兰 BSD 用户组维护者的具体名单需考据；新西兰 BSD 社区的边缘化程度需评估；【0 信任原则·地理识别局限】author_email TLD 不等于实际地理位置，.nz 域归入 other 类意味着新西兰贡献者数据缺失，且 +12:00 与俄罗斯彼得罗巴甫洛夫斯克共用，时区偏移无法单独区分新西兰与俄罗斯贡献者，时区偏移不等于居住地，远程办公、VPN、移民等因素使时区—地理位置映射须慎重；【0 信任原则·committer_date 异常】L3.3.1 基于 committer_date 提取时区偏移，但 GitHub 镜像仓库的 committer_date 可能被重写为同步时间，分析时须改用 author_date 复核；【0 信任原则·author 字段可伪造】L3.3.2 基于 author_email 统计，.au 域数据仅为下限，部分澳大利亚与新西兰贡献者使用 .com 邮箱（如 Gmail）或公司邮箱提交，未计入 .au/.nz 域；【统计显著 ≠ 实际显著】.nz 域归入 other 类与 +12:00 时区 commit 量极低不直接等同于 “新西兰社区贡献度低”，须结合新西兰 IT 产业规模较小、人口基数低、与澳大利亚 BSD 社区高度融合等结构性变量综合判断，统计显著性与实际显著性须区分；详见描述性统计.md L3.3.1/L3.3.2 节与考据记录 20260727_第十二卷-统计学整合.md
