# 366.0.1 要点

- CNFUG（China FreeBSD User Group）是中国大陆最早的 BSD 用户组织之一，定期发布《CNFUG 期刊》共 18 期，技术论坛活跃；2006 年存档停更，标志着第一代中文 BSD 社区的阶段性终结
- FreeBSD China（freebsdchina.org）约 2003 年起活跃，曾是中国大陆最主要的 FreeBSD 交流平台；论坛与 wiki 社区并重，承载了第一代中文 BSD 用户的技术交流
- ChinaFreeBSD 为另一社区站点，GoBSD 涵盖 FreeBSD/NetBSD/OpenBSD 的中文用户社区；二者与 CNFUG、FreeBSD China 共同构成了 2000 年代中国大陆 BSD 社区的多元生态
- CFC（Chinese FreeBSD Collection）的技术内容与定位须考据；历史上有多個不同团体曾使用“CFC”之名，须逐一辨析其各自成立时间、核心人物、活动范围与消亡原因
- 中国大陆 BSD 社区起源的史料分散在期刊存档、论坛快照、个人回忆中；部分早期档案未数字化，CNFUG 期刊的完整性需评估
