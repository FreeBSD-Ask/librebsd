# 374.3.1 Technion/KAUST 等高校 BSD 课程

  **要点**：以色列理工学院（Technion）、特拉维夫大学（TAU）、希伯来大学（HUJI）、阿联酋哈利法大学（Khalifa University）、沙特阿卜杜拉国王科技大学（KAUST）、卡塔尔卡内基梅隆大学卡塔尔分校（CMU-Q）等高校在 1990 年代至 2000 年代曾有零星 BSD 课程；课程多由个人教师推动，缺乏制度化保障；具体课程内容与时间须通过大学课程档案核查
  **史料**：Technion/TAU/HUJI/Khalifa University/KAUST/CMU-Q 计算机科学系课程档案、教师个人页面、学生回忆［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］〔L3 官方文档与公告/L5 二手研究〕
  **史观**：组织结构对技术路径的塑造，中东大学 BSD 课程的零星性反映教育体系的结构性限制
  **辨析**：BSD 课程的实际存在须通过大学课程档案核实——警惕“传说中”的课程；课程内容须具体化，不能仅凭教师自述
