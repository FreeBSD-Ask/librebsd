# 365.7.1 EuroBSDCon 社区凝聚功能

**要点**：欧洲 BSD 用户组呈多国并立格局——BSDAustria、BSD Poland、BUGS（英国）、BSDNL（荷兰）、BSDfr 等各以本国语言与本地活动为主；EuroBSDCon 年度会议为跨国凝聚核心（2001 年自 Brighton 起办，2011 年设 EuroBSDCon Foundation 承接常设运营，2011 年后出席人数稳定于 200-250），规模小于 FOSDEM 但深度更集中。
**史料**：EuroBSDCon 历史数据（2001-2024）; 欧洲用户组网站 ［B］
**史观**：总纲第 15 条——文化即形式主义，年度会议与用户组活动构成社区记忆与制度文化的形式化载体。
**辨析**：欧洲 BSD 用户组面临多语种分散化的挑战——各国用户组以本国语言交流为主，跨国协作依赖 EuroBSDCon 等英语会议。与 FOSDEM 的万人规模相比，EuroBSDCon 的 200-300 人规模表明 BSD 在欧洲开源生态中处于小众位置。GDPR 合规要求对 BSD 基金会的数据处理产生额外合规成本，但也为 BSD 在隐私敏感领域提供了差异化优势。部分东欧国家 BSD 用户组活动数据因语言障碍和缺乏线上记录而难以完整统计。
**文献**：EuroBSDCon; 用户组网站 ［B］

**要点**：

- EuroBSDCon 的起点是一连串偶然：Paul Schenkeveld 自述偶然在 FreeBSD 邮件列表读到两名英国人拟于 2001 年把 BSD 会议带到欧洲，因确认 Greg Lehey 将开设内核调试教程而下定决心参加，首届于 2001 年 11 月在英国 Brighton 举行，此后他一届未缺——会议史由具体教程与具体人物牵引，而非任何自上而下的规划。（BSD Now EP66，[1043.46-1086.07]，L1）
- 基金会制度化的动因是终结年度重复劳动：前八届 EuroBSDCon 由不同欧洲国家的团队逐年承办，每年从零搭网站、组程序委员会、开银行账户并另建注册支付系统，全是完事即散的一次性工程；2011 年荷兰第十届承办团队决议成立 EuroBSDCon Foundation 以承接知识、经验与资源，此后财务、常设网站与注册系统由基金会统一负责，本地组织得以专注于场地、演讲者住宿、餐饮与社交活动等本地事务。（BSD Now EP66，[1092.47-1223.47]，L1）
- 治理结构内嵌项目平等原则：基金会规则写明每个主要 BSD 项目至少设一名董事会代表，时任 FreeBSD、OpenBSD、NetBSD 各占一席，用以回应历史上个别项目对会议曝光不均的抱怨；Paul 同时观察到 NetBSD 与 OpenBSD 参会人数近年回升、本届出现 DragonFly BSD 报告，多项目并存的会议生态被视为常态。（BSD Now EP66，[1586.16-1644.96]，L1）
- EuroBSDCon 2009 剑桥站的缘起系当事人在曼彻斯特一次活动中与Robert Watson、Poul-Henning Kamp共进晚餐时提出，后者表示愿出讲者但须有人承担组织；从决定到实际举办历时约两年，于前一年的会上宣布；组织团队不大但分工明确，Watson承担最多（联络讲者并主办配套dev summit）；会议开始后可能灾难性出错的事项极少且难补救，主办方仅能保持体面；主会议轨完成录音以便会后回听。（BSDTalk EP187，[58.26-252.36]，L1）
- EuroBSDCon逐年换地使组织团队如接力赛般传递：坏处是一致性缺失，好处是每年犯下不同的新错误而吸取新教训；活动风格随组织者而变（剑桥站呈UKUUG风格、哥本哈根站气质迥异），当事人视之为既是优点也是缺点的双刃特征；下届定于2010年10月8日至10日德国卡尔斯鲁厄。（BSDTalk EP187，[255.76-379.72]，L1）
- 志愿BSD会议的运营经济学：论文投稿是根本性贡献（无论文则会议无从成立）；赞助用于讲者机票、场地、住宿与餐饮，直接降低与会成本并提供低价学生名额；英国自持货币带来汇率管理问题（美国赞助者要求以美元计），赞助到账通常先于支出故可作有依据的预估；BSD的志愿文化中主动帮忙者往往“被奖以更多工作”，组织者永远稀缺。（BSDTalk EP187，[374.52-565.52]，L1）
- UKUUG成立于1976年、至访谈时已三十四年，由会员出资、完全独立于软硬件厂商、以自身盈余自我维持；90年代中期其Linux特别兴趣小组因Linux不再是特殊兴趣而解散，Linux夏季会议后并入常规活动；会员调查显示Solaris与商业UNIX仍在大量使用（渐少但在用），而Linux是个体兴趣的最大项；当事人看重跨系统用户组形式，乐于比较各UNIX处理同类问题的管理界面与强弱项。（BSDTalk EP187，[592.32-824.84]，L1）
- 当事人的BSD入门史三段：本科时因Linux服务器问题决意迁往FreeBSD 3.0，迁移六小时后发现新版不再支持其SCSI卡（基础设施变更后驱动未跟上），凌晨两点文件系统已重格式化，改试具实验性ext2支持的NetBSD得以启动但夜间暴露稳定性问题，数月后暂回Linux；其后在笔记本装OpenBSD，恰逢施工挖断大楼主电源致全楼断电三秒，装机三小时的笔记本撑起整个下午且所需软件两小时内自ports补齐；自此以OpenBSD为主力（桌面与服务器），另置一台FreeBSD jail机。（BSDTalk EP187，[827.84-1063.20]，L1）
- 其大学研究组技术团队仅一人而高校不干预研究员的平台选择；工作以Perl为主（平台无关）并依赖ports安装软件；一年三四次更新OpenBSD snapshot（先置放24小时观察再上主工作站），一条命令即可升级全部ports与packages而系统不坏，当事人以此展示对系统的深度信任；OpenBSD将Perl置于base、base与packages同步升级保持整体一致，避免旧版本依赖断裂，契合其半生产staging用途。（BSDTalk EP187，[1068.64-1215.20]，L1）
- Paul Schenkeveld 于 1978 年进入 IT 行业，1983 年接触 UNIX 并决意以之为终身事业；九十年代初受托接管欧洲一份 BSD 的 FTP 镜像维护，此后工作重心转向 FreeBSD；他因 EuroBSDCon 社区的技术口碑于两年前首次参加 BSDCan，去年因 EuroBSDCon 组织事务缺席，本届 BSDCan 重返。（BSDTalk EP213，[75.88-137.20]，L1）
- EuroBSDCon 起源于 2001 年英格兰几位人士的实验性会议，次年有人效仿续办，至今已举办十届、巡游不同国家、由不同团队组织且成功程度不一，每年都要重新发明轮子；2011 年第十届时组织者决定成立 EuroBSDCon Foundation，以在年度之间传递知识与资源；受访者正是通过基金会参与协助波兰团队筹办 2012 年会议。（BSDTalk EP213，[156.52-206.40]，L1）
- EuroBSDCon 2012 定于 10 月 18 日至 21 日在华沙理工大学举行，本地组织由 FreeBSD GEOM 层与 ZFS 移植的作者 Paweł Dawidek 领导；波兰此前已办过三届 MeetBSD，其组织者已加入基金会团队；基金会承担会议的财务责任并运营注册与支付系统——一国基金会在另一国办会须应对欧洲各国税制与规则的差异，集中建设注册支付系统正是为了终结每年重造轮子的时间浪费。（BSDTalk EP213，[206.40-336.48]，L1）
- 会议采用四天格式：两天 tutorial 期间同期举办 FreeBSD 与 NetBSD 开发者峰会，另两天为 talk（周四五安排 tutorial 与峰会、周六日安排 talk），与 BSDCan 的格式相近；会议自创办起以英语为百分之百的工作语言，track 之外允许使用母语；本届 CFP 于 5 月 20 日截止，约三四周内确定讲者名单，注册预计 6 月中旬开放。（BSDTalk EP213，[729.98-771.72]，L1）
- 基金会治理与人力需求：董事会现仅三人、皆出自去年组织团队，计划扩充——至少各一名 OpenBSD、NetBSD、FreeBSD 项目代表，并吸纳去年、今年与明年组织团队的人，通过定期电话会议保证知识与经验传递顺畅；基金会网站需要程序员、设计师、美工志愿者并考虑更换永久 logo；会议志愿者应先联系波兰本地团队，社区联络可径致 Paweł Dawidek（PJD@freebsd.org）。（BSDTalk EP213，[388.68-557.36]，L1）
- 会议生态观察：BSD 活动逐年增多导致排期愈发困难，十月还需避开纽约的既有传统会议；受访者两个月内参加了五个 BSD 会议，另有 SCALE 等设 FreeBSD 展位的泛开源会议；连续参加两三届后即可认出熟面孔，会议对他已如家庭聚会；场地方面华沙理工大学带宽与建筑俱佳，波兰的酒店与餐饮成本远低于荷兰与英国。（BSDTalk EP213，[557.36-684.04]，L1）

**史料**：

- 本期留存的当事人一手材料包括：Paul Schenkeveld 回忆 1993 年受荷兰一家大型 FTP 档案馆之托维护 FreeBSD 1.0 发布前的镜像、经慢速调制解调器下载软盘并艰难寻找兼容硬件装机，随后把自营公司客户整体迁至 FreeBSD 并近乎独占使用二十年；其存储教程的直接起因是邮件列表上一封系统管理员的求教信——自述落后于 GPT 分区、加密与 ZFS 等新进展——邮件列表作为一手史料在此直接塑造了会议议程。（BSD Now EP66，[990.57-1034.95]，L1）
- Paul Schenkeveld 关于 EuroBSDCon 2001 年起源、十届巡游与 2011 年成立基金会决策的当事人口述；EuroBSDCon 2012 华沙理工大学会期、Paweł Dawidek 本地组织、基金会财务与注册支付系统职责的口述。（BSDTalk EP213，[156.52-336.48]，L1）
- 欧洲跨国办会的税制与规则复杂性陈述；四天会议格式（双日 tutorial、FreeBSD 与 NetBSD Dev Summit、双日 talk）与英语政策的当事人说明，可与历届 EuroBSDCon 网站存档交叉核对。（BSDTalk EP213，[288.60-490.00]，L1）

**史观**：

- 总纲10 动手者创造历史：动手者而非 committer 定义社区生命线：Paul 自述从未成为 committer，二十余年以镜像维护、会议组织与教程讲授参与项目；主持人补充项目需要开发者之外的教学、传播、文档乃至最终的用户，Paul 进而强调项目之美在于并非只有讨论算法与比特的单一文化、多背景者皆可归宿——BSD 的延续依赖这些默默维护基础设施与传递经验的动手者。（BSD Now EP66，[1711.03-2055.90]，L1）
- 总纲4 分离聚合是永恒规律：会议是周期性聚合的肥料机制：Paul 以肥料作喻，称走廊谈话即可催生灵感，用户得以偶遇塑造技术未来的大人物并发现其平易近人，教程则吸引专程而来的用户顺带入会——分散于欧洲各地的开发者与用户周期性聚合并把热情与经验带回各自环境，这种分离聚合的节律是 BSD 项目存续的有机机制，而非附属于代码发布的边缘活动。（BSD Now EP66，[1760.88-1812.52]，L1）
- 总纲10 动手者创造历史：BSD会议与用户组的运转被当事人归结为“这些活动因人们主动帮忙而发生”：其本人卷入始于一句愿出讲者、缺人组织，帮忙者渐被赋予更多职责；BSD会议由志愿者为志愿者及同好而办，曼彻斯特BSD用户组更是从朋友每月酒馆聚会自然生长、靠邮件列表被检索到而延续八年——社区的实体存在系于动手者的持续到场而非正式建制。（BSDTalk EP187，[1322.04-1475.54]，L1）
- 总纲4 分离聚合是永恒规律：十届分散于各国、各团队、各成功程度的会议经验，经由基金会聚合为可跨年传递的知识、注册支付系统等制度资产，是分散实践重新聚合为共同基础设施的进程。（BSDTalk EP213，[177.52-336.48]，L1）
- 总纲5 没有必然性，只有偶然性：EuroBSDCon 的开端只是 2001 年一次无长期规划的实验性聚会，因后来者偶然效仿才成为延续至今的传统，会议制度史的起点系于偶然而非设计。（BSDTalk EP213，[156.52-173.52]，L1）
- 总纲8 本体论上各方平等：基金会董事会按设计吸纳 OpenBSD、NetBSD、FreeBSD 三方代表及历年组织团队，以制度方式防止任一项目或单届团队主导欧洲会议，体现对各 BSD 与各届组织者对等地位的自觉维护。（BSDTalk EP213，[393.48-423.60]，L1）
- 总纲10 动手者创造历史：基金会成立的直接动因是历届组织者重造轮子的实际痛感，制度创新由动手组织者的经验教训驱动，而非自上而下的治理设计。（BSDTalk EP213，[309.16-336.48]，L1）

**辨析**：

- 出席人数的制度化归因须谨慎：Paul 给出的数据是前十届参会人数在 100 至 250 之间大幅波动，2011 年基金会成立后每年稳定于 200 至 250、本届注册 225 人，但访谈并未论证制度化与稳定之间的因果关系；而选址撞期等外部偶然因素（2011 年荷兰险些与马拉松同期，节目另一音轨亦提及会议与 Comic-Con 争抢酒店客房的教训）提示波动可能更多受偶然条件左右，因果链条不应径直建立。 [存疑脚注] 制度化导致出席稳定的因果判断为卡片作者推断，访谈仅呈现前后对比数据，未控制场地、经济与并行活动等变量（BSD Now EP66，[1350.86-1378.42]，L4）
- 技术史细节在口传中传承与失真并存：新闻环节转述 HardenedBSD 移除 a.out 可执行格式，主持人补充该名称系 Ken Thompson 1968 年为其 PDP-7 汇编器输出所定的 assembler output 之称，并称 FreeBSD 在 2.2 与 3.0 之间弃用此格式、Julian Elischer 在邮件列表自述仍于 jail 中运行 FreeBSD 1.0 二进制——同一期节目内，词源来自维基百科速查、时间线出自主持人口头转述、轶闻出自邮件列表回忆，精度参差，引述须分别核验。 [存疑脚注] a.out 词源解释系主持人转引维基百科，FreeBSD 2.2 至 3.0 的弃用时间线与 Julian Elischer 轶闻均为现场口头单一来源，未经独立核验（BSD Now EP66，[2831.37-2903.68]，L4）
- 本期转写专名失真：“Plotting Camp”应为Poul-Henning Kamp，“Eurostecom”应为EuroBSDCon，FreeBSD jail机来源“Exynatrik”无法辨识（疑为某供应商名，存疑）；当事人对UKUUG会员构成的描述援引自其记忆中的会员调查而未给出调查年份，[存疑脚注] 上述专名与调查时点引用前须对照原始资料核正。 [存疑脚注] 会员调查年份不详，Exynatrik所指不明，专名核正系依语境推断。（BSDTalk EP187，[650.88-679.52]，L4）
- 受访者早年维护的 FTP 镜像对象转写为 3BSD、时点含 0.45 字样，疑指 386BSD 0.45 或其他 BSD 版本，无法据转写确证，引用前须核；转写讹误：Pao Woldavedecker 应为 Paweł Jakub Dawidek，CFS sport 应为 ZFS port，meat BSDs 应为 MeetBSD，URBSD con 应为 EuroBSDCon，BST Can 应为 BSDCan；波兰成本与天气的评述属闲谈式印象，不作史料引用。 [存疑脚注] 早年 FTP 镜像对象与时点无法据转写确证；会议排期与社区家庭感为主观印象式陈述。（BSDTalk EP213，[86.92-103.52]，L4）
