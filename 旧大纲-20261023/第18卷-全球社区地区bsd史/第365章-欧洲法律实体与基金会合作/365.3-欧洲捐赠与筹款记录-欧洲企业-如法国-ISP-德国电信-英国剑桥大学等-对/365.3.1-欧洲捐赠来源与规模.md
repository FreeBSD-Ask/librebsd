# 365.3.1 欧洲捐赠来源与规模

  **要点**：欧洲捐赠来源包括法国 ISP、德国电信、英国剑桥大学等企业与学术机构；NLnet（欧洲开源基金会）与 AdaCore（欧洲商业软件企业）等机构与 FreeBSD Foundation 建立合作关系

| 捐赠来源 | 类型 | 性质 |
| ------ | -- | -- |
| 法国 ISP | 企业 | 定向捐赠 |
| 德国电信 | 企业 | 定向捐赠 |
| 英国剑桥大学 | 学术机构 | 定向捐赠 |
| NLnet Foundation | 欧洲开源基金会 | 长期合作 |
| AdaCore | 欧洲商业软件企业 | 合作 |
