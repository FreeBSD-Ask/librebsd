# 378.2.1 马来西亚 BSD 社区的起源


117.2 **马来西亚的 BSD 社区与教育**———马来西亚 BSD 社区以吉隆坡与槟城为中心，马来西亚多媒体大学（MMU）与马来西亚理科大学（USM）开设 BSD 相关课程，马来西亚 BSD 社区规模较小但持续活跃

  **要点**：马来西亚 BSD 社区以吉隆坡（Kuala Lumpur）与槟城（Penang）为中心，马来西亚 IT 产业（如 MSC Malaysia 多媒体超级走廊计划，1996 年启动）为 BSD 在马来西亚的采用提供了政策环境。马来西亚早期 ISP（如 TMnet、Jaring）在 1990 年代使用 FreeBSD
