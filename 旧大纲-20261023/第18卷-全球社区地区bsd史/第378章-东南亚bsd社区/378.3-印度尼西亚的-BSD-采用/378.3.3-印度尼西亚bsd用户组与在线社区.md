# 378.3.3 印度尼西亚 BSD 用户组与在线社区

**要点**：据社区流传，Indonesia BSD Users Group（ID-BSD）是印度尼西亚 BSD 社区的核心组织，通过在线社区（如 Kaskus 论坛 BSD 板块、Telegram BSD 频道、Facebook BSD 群组）组织活动。印度尼西亚 BSD 用户组以雅加达为中心，据称定期举办安装会与研讨会；其前史可上溯至 2001 年 5 月 infofreebsd.org 用户组以 IRC 频道 #indofreebsd 聚会（见本节末 L4 当事人记录）
