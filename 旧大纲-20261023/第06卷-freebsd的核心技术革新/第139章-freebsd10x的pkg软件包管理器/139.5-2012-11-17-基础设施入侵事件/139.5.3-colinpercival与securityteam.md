# 139.5.3 Colin Percival 与 Security Team

**要点**：2012 年入侵事件发生时 Colin Percival（cperciva@）担任 FreeBSD Security Officer。Percival 自 2005 年起担任 Security Officer，是 FreeBSD 历史上任期最长的 Security Officer 之一，他建立了 FreeBSD Security Team 的响应流程与安全公告发布机制。Dag-Erling Smørgrav（des@）在 10.0 公告中列为 Security Officer（Percival 为 Security Officer Emeritus 荣誉身份），Xin Li（delphij@）在 10.1 起加入 Security Team 并在后续版本中承担 Security Officer 职责。Security Officer 职位交接体现了 FreeBSD 安全团队的连续性。Percival 还是 **freebsd-update(8)** 工具作者、Amazon EC2 FreeBSD 镜像维护者、Tarsnap 备份服务创始人。

**史料**：FreeBSD 10.0-10.1 Announcements 中 Security Team 名单变化、Colin Percival Security Officer 历史、Dag-Erling Smørgrav 与 Xin Li 个人贡献记录。［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档〕

**史观**：社区治理：Security Officer 是 FreeBSD 项目最敏感的职位之一——该职位掌握所有安全漏洞的未公开信息，其个人能力与诚信直接关系到数百万 FreeBSD 系统的安全。Colin Percival 到 Dag-Erling Smørgrav/Xin Li 的交接平稳完成，体现了 FreeBSD 核心团队在关键职位上的传承能力。

**辨析**：Security Officer Emeritus 是荣誉头衔——Percival 卸任日常 Security Officer 职责后仍作为 Emeritus 参与安全咨询工作，但不承担日常安全响应职责；10.0 公告中 Dag-Erling Smørgrav 列为 Security Officer，10.1 起 Xin Li 加入 Security Team，三人共同构成 10.x 时期安全团队核心。
