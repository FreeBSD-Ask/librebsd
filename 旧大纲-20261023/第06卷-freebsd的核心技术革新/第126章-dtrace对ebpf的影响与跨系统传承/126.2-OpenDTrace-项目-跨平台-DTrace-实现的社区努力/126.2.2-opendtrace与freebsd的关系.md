# 126.2.2 OpenDTrace 与 FreeBSD 的关系

**要点**：FreeBSD 与 OpenDTrace 的关系是参与者和受益者——FreeBSD src/sys/cddl/contrib/opensolaris/ 中的 DTrace 代码最初从 OpenSolaris 导入，后通过 illumos 和 OpenDTrace 同步上游改进；OpenDTrace 的跨平台目标使其代码可以被多个 BSD 系统共享；FreeBSD 基金会是否专门资助过 OpenDTrace 开发经 FreeBSD Foundation 网站项目页面检索未发现明确记录 [存疑脚注：2026-08-17 FreeBSD Foundation 项目页面未发现资助 OpenDTrace 的明确记录，无法确证资助关系]；FreeBSD 社区中 George Neville-Neil 等人长期参与 DTrace 维护

**史观**：治理技艺〔订正注：原误挂总纲第 15 条，权威 15=文化即形式主义，去号〕：OpenDTrace 采取了宽松的多许可证策略（CDDL for OpenSolaris 代码，BSD 2-Clause for new code）以最大化跨平台接受度，这是务实的许可证治理选择——它允许不同操作系统社区按需使用代码而不引入许可证冲突

**辨析**：原文标题“FreeBSD 基金会资助”需修正——经 FreeBSD Foundation 网站检索未能确认对 OpenDTrace 的专项资助，OpenDTrace 主要由社区志愿者和各平台贡献者维护；Microsoft 2018 年从 FreeBSD 移植 DTrace 到 Windows 时使用的是 FreeBSD 中的 DTrace 代码（而非 OpenDTrace 直接），但 OpenDTrace 的文档工作对跨平台理解有帮助
