# 146.9.5 freebsd-src 趋势统计与 FreeBSD 12.x 工具链现代化的定量印证

**要点**：**统计分析印证**——`freebsd.duckdb` freebsd-src 仓库 1993-2026 年 commit 月度量 Mann-Kendall 趋势检验结果为显著上升趋势（Sen's slope =+1.40/月，p < 0.001，95% CI [1.11, 1.69]）（统计结论 C-03）；ARIMA(5,0,5) 模型拟合 AIC = 107.39（统计结论 C-29）；freebsd-src 文件生命周期 Kaplan-Meier 生存估计——414,802 文件中位数寿命 1,329.3 天（3.64 年），95% CI [1,329.3, 1,344.8]，右删失 14.39%（统计结论 C-40）；FreeBSD 12.x 系列（2018-2023）以 GCC 4.2.1 从 x86 base 移除、VIMAGE 默认、RISC-V 引入、Meltdown/Spectre 缓解等工具链现代化为特征，该时期 freebsd-src 趋势持续上升，未因工具链现代化而中断 commit 增长趋势；Kaplan-Meier 生存估计反映 12.x 时期文件生命周期——中位数寿命 3.64 年意味着 12.x 时期引入的文件预计在 FreeBSD 15.x/16.x 时期经历显著重构

**史料**：`freebsd.duckdb` `commits` 表 freebsd-src 仓库 commit 月度量与 `commit_files` 表文件生命周期；SQL 查询 `SELECT strftime('%Y-%m', committer_date) AS month, COUNT(*) AS commit_count FROM commits WHERE repo_name='freebsd-src' GROUP BY month ORDER BY month`；Python 脚本 `script/phase3_inferential_stats.py` Task 5（Mann-Kendall 趋势检验）；Python 脚本 `script/phase4_time_series.py` Task 14（ARIMA 建模）；Python 脚本 `script/phase2_descriptive_stats.py` SubTask 2.4（Kaplan-Meier 生存估计）；统计结论编号 C-03、C-29、C-40；查询日期 2026-07-27 ［A］

**史观**：赓续而非断裂：freebsd-src 趋势检验显示 12.x 时期（2018-2023）工具链现代化前后 commit 量均呈上升趋势，未出现因 GCC 移除或 VIMAGE 默认化导致的 “开发断裂”——统计数据印证 FreeBSD 在工具链现代化中赓续了 CSRG 未竟事业而非中断主线开发；软件工程：Kaplan-Meier 生存估计反映 freebsd-src 文件的工程生命周期——中位数寿命 3.64 年意味着 12.x 时期引入的文件将经历持续重构，体现 FreeBSD 工程文化的持续演进

**辨析**：**统计局限性标注**——(1) 统计显著 ≠ 实际显著：Mann-Kendall 趋势检验 p < 0.001 表明 freebsd-src commit 量存在统计学显著上升趋势，但 12.x 时期工具链现代化的实际工程意义须结合 GCC 移除、VIMAGE 默认化的具体代码变更综合判断；(2) Kaplan-Meier 适用性：中位数寿命 1,329.3 天为 freebsd-src 全部 414,802 文件的统计结果，未单独计算 12.x 时期引入文件的生存曲线，12.x 文件寿命可能与整体分布存在差异；(3) ARIMA 模型局限：ARIMA(5,0,5) AIC = 107.39 为 freebsd-src 整体 commit 序列拟合结果，未单独建模 12.x 时期 commit 子序列；(4) 多重比较风险：本结论与第五卷其他章节引用相同 freebsd-src 趋势统计存在多重比较风险，Bonferroni 校正后显著性可能降低；(5) SVN-to-Git 迁移影响：12.x 时期跨越 SVN-to-Git 迁移（2020-01），迁移前后 commit 粒度可能存在差异
