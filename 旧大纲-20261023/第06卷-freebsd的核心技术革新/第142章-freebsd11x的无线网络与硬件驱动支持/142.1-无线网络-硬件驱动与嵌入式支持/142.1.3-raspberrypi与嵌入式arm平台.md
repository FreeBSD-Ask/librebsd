# 142.1.3 Raspberry Pi 与嵌入式 ARM 平台

**要点**：11.x 时期 FreeBSD/ARM 支持显著改善。armv6（32 位 ARMv6/v7）在 10.x 已加入发布支持，11.x 持续改进稳定性与驱动支持。arm64/AArch64 11.0 正式发布后支持的开发板逐步增多：Raspberry Pi 3（BCM2837，四核 Cortex-A53）的 arm64 支持在 11.x 逐步完善（RPi 3 既可运行 armv7 32 位镜像也可运行 aarch64 64 位镜像）；Raspberry Pi 2（BCM2836/BCM2837，Cortex-A7/A53）armv7 支持持续稳定；BeagleBone Black/BeagleBone AI、Pine64、SoftIron Overdrive 等开发板支持改进；SD 卡镜像持续提供并优化。11.x 还支持多种嵌入式网络与存储设备。嵌入式场景下，FreeBSD 的轻量级（base 系统可裁剪至数 MB）、GEOM 存储框架、ZFS 可靠性、网络栈性能是其相对于 Linux 嵌入式发行版的优势。

**史料**：FreeBSD 11.x Release Notes ARM Support 章节、FreeBSD/arm 邮件列表、Raspberry Pi FreeBSD 镜像文档、FreeBSD Quarterly Status Reports ARM 章节。 ［A］

**史观**：总纲第 10 条——动手者创造历史〔订正注：2026-09-14 原挂“总纲第 10 条——边缘者贡献”系名目非权威，权威第 10 条为“动手者创造历史”；条号可成立按权威名目正名〕：ARM 平台支持长期由少数核心开发者（Andrew Turner、Ian Lepore、Oleksandr Tymoshenko 等）推动，属于“边缘架构”持续改进。与 amd64 由多家公司赞助不同，ARM 支持更多依赖社区志愿贡献与 FreeBSD Foundation 部分赞助。Raspberry Pi 作为全球最流行的单板计算机，其 FreeBSD 支持主要由社区完成而非 Raspberry Pi Foundation 官方支持。

**辨析**：Raspberry Pi 3 的内置 Wi-Fi/蓝牙在 11.x 支持不完善——部分组件需要额外的 firmware 与驱动配置，支持状态因版本而异；Raspberry Pi 4 不在 11.x 支持范围内（RPi 4 于 2019 年发布，支持在 12.x/13.x 完善）；Raspberry Pi 0/0 W/1 在 11.x 通过 armv6 镜像支持但性能有限。
