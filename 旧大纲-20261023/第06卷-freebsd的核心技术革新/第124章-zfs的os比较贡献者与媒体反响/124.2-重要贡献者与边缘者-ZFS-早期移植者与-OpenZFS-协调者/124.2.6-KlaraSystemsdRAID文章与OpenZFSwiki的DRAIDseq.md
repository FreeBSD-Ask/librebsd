**史观**：

- 总纲22 知识注定过时：27 年前的调优书今日仍被整期研读，其价值不在参数而在方法论；DNLC 14 字符限制等具体知识已彻底过时——技术图书的经典性恰以内容过时为前提，留存下来的是测量学经验。（BSD Now EP393，[89.12-299.56]，L2）
- 总纲5 没有必然性，只有偶然性：Signal 伊朗封锁这一偶然地缘事件催生反审查代理教程：FreeBSD 社区的技术响应方向由外部政治偶然性牵引，而非既定技术路线图。（BSD Now EP393，[1088.66-1102.9]，L2）
- 总纲13 法律与道德是利益分配：Facebook 黑名单 CSS 过滤器的失败史揭示安全机制同样是利益与权力的分配装置：默认允许加枚举坏人的架构把防御成本转嫁给未来，枚举权的失效即秩序的失效。（BSD Now EP393，[1843.98-1866.94]，L2）
- 总纲4 分离聚合是永恒规律：dRAID 把 scrub 的整体校验分离为顺序重建与 healing 补全两阶段再聚合，其设计哲学是让数据布局的分离-聚合服务于修复路径的最小化。（BSD Now EP393，[497.16-704.2]，L2）
- 总纲1 一切真历史都是古代史：对 1994 年图书的认真重读表明：理解当下存储系统行为（预读、缓存、测量偏差）须不断回到“古代”文本，性能史是一部被反复重写的古代史。（BSD Now EP393，[155.36-186.48]，L2）
- 总纲3 不存在进步，只有权力再分配：缓存技术的存废由消费者需求而非技术逻辑再分配：persistent L2ARC 代码去年夏天检查时已接近完成，却因 Delphix 产品不用 L2ARC 而停在等待有人接手“最后冲刺”的状态；compressed ARC 则因客户内存可换来两到三倍等效缓存、成为好卖的卖点而被排进下一个发布周期——同一代码库内，功能的命运取决于商业方愿为谁的资源买单（当事人自述，ts 1923.98-2059.10）。（BSD Now EP77，[1923.98-2059.10]，L1）
- 总纲4 分离聚合是永恒规律：m0n0wall 在 2015 年宣布停止开发，但它的形式并未随项目一起死去：主持人指出 pfSense fork 自 m0n0wall，“甚至 FreeNAS 最初也是从 m0n0wall fork 的，因为它已经具备 appliance 胶水与构建脚本”（ts 809.29-815.56），OPNsense 再自 pfSense 衍生，BSD Router Project 亦在此谱系中——项目解体而特性扩散，分离聚合延续了这条防火墙发行品的生命（主持人转述，ts 773.14-842.24）。（BSD Now EP77，[773.14-842.24]，L2）
- 总纲9 经验优先：总纲9 经验优先：三则战例的因果结论均非源于规格推演，而是现场实验逐层排除所得（大象脚印的比喻——只能确认大象来过与坠点，无法从屋顶复原来路）；iSCSI 块大小问答的最终建议（缓存命中时块大小无关紧要、缺缓存就加内存）亦出自实测微基准。生产 ZFS 知识以此类经验性战例传承。（BSD Now EP45，[505.16-550.44]，L3）
- 总纲5 没有必然性，只有偶然性：总纲5 没有必然性，只有偶然性：灾难得免的决定因素是一连串具体偶然——备份机恰好先扩展且未损、只读导入恰好绕开 spacemap 写路径、客户恰好尚有未复制数据、救援发生在长周末前；同一升级操作在备份机上即时成功，在主机上毁池。历史由这些偶然条件而非必然规律构成。（BSD Now EP45，[288.48-345.96]，L3）
- 总纲22 知识注定过时：Ahrens 自述年少无知反而是设计自由之源：不识既有成规便可一一追问其存在理由并予以抛弃，这种天真使人敢于设想更大的改动；若今日有人提议彻底重构 ZFS，他反会顾虑代价。既有知识既是积累也是边界，年轻而不知难，才有时机与人力把激进设计做成现实。（BSDTalk EP227，[315.90-381.66]，L1）
- 总纲8 本体论上各方平等：Ahrens 阐明 OpenZFS 的长期目标是不专属任何平台、各平台地位平等：ZFS 不是 Illumos 的技术，更不只是 Oracle 的技术，而是跨平台技术；不应偏袒任何一方，要在维持质量红线的同时不让其他平台多付额外代价。（BSDTalk EP227，[998.08-1034.98]，L1）
- 总纲13 法律与道德是利益分配：CDDL 与 GPL 的不兼容无法通过改授权解决：既有代码版权分散在包括 Oracle 在内的众多公司与个人手中，且他们不会以 GPL 重授权。Linux 侧的实践者遂以可加载内核模块的方式实现 ZFS，按许可允许的状态假定推进，寄望主流发行版分装；当下各主流发行版已有可安装的包。许可与版权结构直接塑造了 ZFS 在 Linux 的存在形态。（BSDTalk EP227，[1036.12-1103.10]，L1）

- 主持人对 dRAID 中“分布式热备”的物理形态存疑（是否存在可指认的专属 parity 盘），文献表述易生歧义，须以 OpenZFS dRAID 手册页与实现代码裁决。（BSD Now EP393，[856.86-883.22]，L2）

- Fabricator 文章“若早做这些 Facebook 可省巨额成本”系作者的反事实推测，无法核验。[存疑脚注] 该清单的 Facebook 受益估算属推测性表述 [存疑脚注] 清单对 Facebook 的反事实收益估算无法核验（BSD Now EP393，[1744.1-1750.76]，L4）
