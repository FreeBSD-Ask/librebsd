# 129.1.4 CHERI 许可策略史料考证

**要点**：CHERI 许可策略的一手史料可在 CTSRD-CHERI GitHub 各仓库的 LICENSE 文件、CHERI 官方网站 cheri-cpu.org 的使用条款、CheriBSD 源码仓库的版权声明中查阅；CHERI 项目采用的许可证体系整体上是 BSD 风格的宽松许可，但需注意不同组件的细微差别：(1) CHERI ISA 规范文档和技术报告——Cambridge 开放发布，允许学术引用和实现；(2) CHERI 硬件 RTL（Piccolo/Flute 等）——BSD 许可；(3) CheriBSD——BSD 许可（作为 FreeBSD 分支，继承 FreeBSD 的 BSD 许可体系）；(4) LLVM/GCC CHERI 扩展——BSD/Apache 风格许可（继承 LLVM/GCC 的原始许可）；(5) ARM Morello 硬件设计——ARM 专有；CHERI Alliance 2024 年 11 月成立后将扮演产业协调角色，类似于 RISC-V International 在 RISC-V 生态中的角色，但 Alliance 不拥有 CHERI IP，IP 由各成员和学术机构持有

**史料**：CTSRD-CHERI GitHub 组织各仓库 LICENSE 文件（github.com/CTSRD-CHERI）；CHERI Alliance 官方网站 cheri-alliance.org（成立于 2024 年 11 月）；CheriBSD 源码仓库版权头；Cambridge/SRI CHERI 技术报告版权声明 ［A］

**史观**：总纲第 15 条——文化即形式主义〔存疑：原挂“第 3 条——形式主义膨胀”系伪标签，权威表第 3 条为“不存在进步，只有权力再分配”，待主理人审定〕：CHERI 的许可体系在 ISA 规范层面是开放的，但硬件实现层面存在“开源核心（RISC-V）”和“专有实现（ARM Morello、未来商业芯片）”的双轨结构；这种双轨结构与 RISC-V 生态高度类似（RISC-V 国际基金会管理开放标准，商业公司如 SiFive/Andes/Codasip 提供商业 IP，学术界提供开源核心）；关键区别在于：CHERI 作为安全扩展尚未到达 RISC-V 那样的标准化成熟度，RISC-V CHERI 扩展仍在标准化过程中

**辨析**：原大纲本节称“CHERI ISA 以 BSD 许可证发布”需更精确表述——CHERI ISA 规范不是单一许可证文件覆盖的软件项目，而是技术文档和架构规范；具体实现代码（硬件 RTL、软件）使用 BSD 许可，规范本身由 Cambridge/SRI 以允许自由实现的条款发布；“ARM Morello 原型板的硬件设计文档受 ARM 商业许可约束”这一表述准确，但研究者可以通过 DSbD 计划免费获得 Morello 板用于学术研究
