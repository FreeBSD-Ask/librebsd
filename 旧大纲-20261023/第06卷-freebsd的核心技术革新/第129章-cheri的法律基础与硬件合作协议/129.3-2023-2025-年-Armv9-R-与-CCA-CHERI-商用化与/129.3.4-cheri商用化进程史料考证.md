# 129.3.4 CHERI 商用化进程史料考证

**要点**：CHERI 商用化进程的一手史料包括：CHERI 官方网站 cheri-cpu.org（持续更新项目进展和技术报告）；CHERI Alliance 官方网站 cheri-alliance.org（2024 年 11 月成立后的产业公告）；CheriBSD 各版本 Release Notes（22.05-25.03，记录 Morello 支持成熟度）；Arm Morello Program 官方文档（arm.com）；Codasip 和 Microsoft 等商业公司的 CHERI 相关公告；学术论文（ISCA、IEEE S&P、MICRO、ASPLOS 等顶级会议的 CHERI 系列论文）；关键时间线节点见下表，覆盖 2010 年 DARPA CRASH 启动至 2025 年 CheriBSD 25.03 发布的 15 年演进路径。

| 年份 | 关键节点 | 主要参与方 |
| --- | --- | --- |
| 2010 | DARPA CRASH 项目启动 | DARPA/Cambridge/SRI |
| 2012 | CHERI-MIPS 原型首次公开 | Cambridge/SRI |
| 2014 | ISCA 论文发表，CheriBSD 首次演示完整 FreeBSD 运行 | Cambridge/SRI |
| 2015 | Arm 加入项目，IEEE S&P 论文发表 | Cambridge/SRI/Arm |
| 2019 | CheriABI ASPLOS 论文发表 | Cambridge |
| 2020 | UKRI DSbD 计划启动（£1.7 亿投资） | UKRI/Arm/工业界 |
| 2021-2022 | Morello 板交付研究者 | Arm/UKRI |
| 2023 | Codasip 发布商业 CHERI-RISC-V IP；CHERIoT MICRO 论文发表 | Codasip/Microsoft |
| 2024.11 | CHERI Alliance 成立 | Google/Microsoft/Arm/Codasip/lowRISC/Cambridge/SRI |
| 2025 | CheriBSD 25.03 发布，支持 **bhyve(8)** 虚拟化和 KDE 桌面 | Cambridge/CHERI Alliance |

**史料**：CHERI Project. cheri-cpu.org (project timeline and publications); CHERI Alliance. cheri-alliance.org; CheriBSD Release Notes (22.05-25.03); Arm Morello Program. arm.com; UKRI DSbD Programme. ukri.org; DARPA CRASH Program. darpa.mil; ISCA/IEEE S&P/ASPLOS/MICRO 会议论文集（2012-2024 CHERI 系列论文） ［B］

**史观**：总纲第 18 条——时间是一种形式主义：CHERI 从学术研究项目到产业联盟的演进历程（2010-2025 年，15 年）反映了计算机架构研究的典型时间尺度——从概念提出到硬件原型需要 5-10 年，从原型到商业产品可能需要另一个 5-10 年；这与 RISC-V 从 2010 年伯克利项目启动到 2020 年代商业成功的时间尺度相当；CHERI 史料保存状况良好，得益于剑桥团队有意识的开源发布和技术报告系列，但商业公司内部的 CHERI 研发记录（如 Arm、Google、Microsoft 的内部评估）可能不公开

**辨析**：关于 “FreeBSD Foundation 2024 年 Capsicum 与 bhyve 安全审计”——经检索 FreeBSD Foundation 官方博客和公告，2023-2024 年 FreeBSD Foundation 确实资助了多项安全审计工作，但专门针对 Capsicum+bhyve 的 Trail of Bits 审计报告公开信息有限 [存疑脚注：2026-08-17 Capsicum+bhyve 的 Trail of Bits 审计报告公开信息有限，无法确证细节]；FreeBSD 安全公告和 FreeBSD Foundation 季度报告中有关于安全改进的记录，但精确审计公司、发现漏洞数等细节需进一步核实；本节不虚构该审计细节，标注为 [存疑脚注：2026-08-17 联网未取得可确证的一手来源，维持存疑] 并建议查阅 FreeBSD Foundation 官方报告
