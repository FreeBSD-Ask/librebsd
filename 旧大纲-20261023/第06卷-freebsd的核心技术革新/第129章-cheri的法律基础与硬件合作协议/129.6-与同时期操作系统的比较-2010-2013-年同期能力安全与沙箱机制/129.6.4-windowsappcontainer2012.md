# 129.6.4 Windows AppContainer（2012）

**要点**：Microsoft 在 Windows 8（2012）引入 AppContainer，为 Modern 应用提供沙箱隔离（低完整性级别、受限 token、网络/文件能力显式授予）；其 “能力显式授予” 理念与 Capsicum 的最小权限方向一致，但基于 Windows 的 token/ACL 体系而非 UNIX capability。

**史料**：Microsoft Windows 8 AppContainer 文档（2012）［A］

**史观**：总纲第 8 条——本体论上各方平等：AppContainer 的 “能力令牌” 与 Capsicum 的 “能力句柄” 趋同但实现迥异，闭源与开源沙箱的工程路径平等对照、不分高下。

**辨析**：AppContainer 与 Capsicum 目标相似（最小权限沙箱）但无法跨生态共享代码；二者证明 “能力沙箱” 是 2010 年代操作系统的普遍方向。
