# 134.4.1 SUJ 技术设计与 麦库西克（Marshall Kirk McKusick）实现

**要点**：SUJ（Soft Updates Journaling）由 麦库西克 设计实现，在 9.0-RELEASE 中正式支持，且 bsdinstall 自动为新创建的 UFS 文件系统启用；SUJ 在 soft updates 基础上增加意向日志（intent log），解决了传统 soft updates 在异常卸载后仍需前台 **fsck(8)** 扫描以释放未完成事务资源的问题——启用 SUJ 后，非正常关机后的文件系统恢复无需等待漫长的 fsck，日志可直接重放完成恢复；SUJ 通过 **newfs(8)** `-j` 标志或 **tunefs(8)** `-j enable` 启用，r207141（2010.4.23）为核心实现 commit

**史料**：McKusick M K. SUJ 设计文档与源码提交（svn r207141、r218726）、McKusick 在 BSDCon/USENIX 关于 SUJ 的演讲、FreeBSD 9.0 Release Notes、McKusick 2014 年版 Design and Implementation 中 UFS 日志章节 ［A］

**史观**：总纲第 17 条——软件工程：SUJ 是 McKusick 作为 UFS/FFS 原始设计者对其作品的 “晚年修订”——soft updates 本身是 Ganger & Patt 于 1990 年代提出的元数据一致性方案，McKusick 在 FreeBSD 中实现并维护 15 年后，通过 SUJ 解决了其最后的痛点（崩溃后 fsck 时间）；这体现了核心系统软件 “作者终身维护” 的 BSD 传统

**辨析**：SUJ 不是 “日志文件系统”（journaling filesystem）的完整实现——它仅对 soft updates 元数据更新增加意向日志以加速恢复，而非像 ext3/ext4、XFS 那样对元数据甚至数据进行完整日志记录；这一设计选择保持了 soft updates 的性能优势，同时消除了其最显著的运维缺陷（服务器异常断电后 fsck 时间与文件系统大小成正比）

**文献**：McKusick M K, Neville-Neil G V, Watson R N M. The Design and Implementation of the FreeBSD Operating System [M]. 2nd ed. Boston: Addison-Wesley, 2014. ISBN 978-0-321-96897-5（第 8 章 UFS 章节）；svn commit r207141, r218726；FreeBSD 9.0-RELEASE Release Notes（File Systems 章节） ［A］
