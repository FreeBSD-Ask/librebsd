# 127.4.2 校园社会文化新闻类

### 新闻条目 1

- **新闻标题（中英）**：Linux 内核可能采用 FreeBSD 的 Capsicum 安全框架（The Linux Kernel Might Use FreeBSD's Capsicum Security Framework）
- **新闻来源**：Phoronix + Michael Larabel + 2014-07-07 + <https://www.phoronix.com/news/MTczNjM> + <https://web.archive.org/web/2014/https://www.phoronix.com/news/MTczNjM>
- **新闻摘要**：2014 年 7 月 Phoronix 报道 Linux 内核社区正在讨论采用 FreeBSD 的 Capsicum 安全框架作为 Linux 安全模块（LSM）之一。Capsicum 由 Cambridge University 与 Google 联合开发，2010 年首次集成到 FreeBSD 9.0 中作为沙箱框架。Linux 社区讨论反映了 Capsicum 设计对跨平台操作系统安全的影响。
- **与本章主题的关联说明**：本章记述 Capsicum 在 FreeBSD 中的起源与演进，2014 年 Linux 社区讨论采用 Capsicum 是其跨平台影响力的关键标志。
- **与官方史料的交叉验证结论**：Capsicum 论文（Watson 等，USENIX Security 2010）与 FreeBSD 9.0-RELEASE 发行说明可交叉验证；Linux 内核邮件列表（LKML）2014 年讨论可验证 Linux 社区意向。Phoronix 报道与学术及官方史料一致。
