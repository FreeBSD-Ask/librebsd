### 新闻条目 1

- **新闻标题（中英）**：FreeBSD 11.0 在 Ubuntu 16.04 vs. macOS Sierra 基准测试中表现不佳（FreeBSD 11.0 Comes Up Short In Ubuntu 16.04 vs. macOS Sierra Benchmarks）
- **新闻来源**：Phoronix + Michael Larabel + 2016-09-29 + <https://www.phoronix.com/review/freebsd-ubuntu-sierra> + <https://web.archive.org/web/2016/https://www.phoronix.com/review/freebsd-ubuntu-sierra>
- **新闻摘要**：2016 年 9 月 Phoronix 发布 FreeBSD 11.0-RC 与 Ubuntu 16.04、macOS Sierra 的性能对比测试，FreeBSD 11.0 在多项桌面与服务器基准测试中表现不佳。这一结果反映了 FreeBSD 11.x 在桌面性能优化方面仍落后于 Linux 与 macOS。
- **与本章主题的关联说明**：本章记述 FreeBSD 11.x 的性能与定位，Phoronix 2016-09 基准测试反映了 11.x 在桌面场景的局限性。
- **与官方史料的交叉验证结论**：FreeBSD 11.0-RELEASE 发行说明（2016-10-10）与 Phoronix 测试交叉验证；测试为独立第三方，技术细节与 FreeBSD 官方文档一致。

### 新闻条目 2

- **新闻标题（中英）**：Windows Server 2016 vs. FreeBSD 11.2 vs. 8 种 Linux 发行版性能对比（Windows Server 2016 vs. FreeBSD 11.2 vs. 8 Linux Distributions Performance）
- **新闻来源**：Phoronix + Michael Larabel + 2018-07-13 + <https://www.phoronix.com/review/windows-freebsd112-8linux> + <https://web.archive.org/web/2018/https://www.phoronix.com/review/windows-freebsd112-8linux>
- **新闻摘要**：2018 年 7 月 Phoronix 发布 Windows Server 2016、FreeBSD 11.2 与 8 种 Linux 发行版的性能对比测试。FreeBSD 11.2 在服务器场景的部分基准测试中表现良好，但在桌面与开发者场景仍落后于 Linux。
- **与本章主题的关联说明**：本章记述 FreeBSD 11.x 在 2018 年的性能定位，11.2 是 11.x 系列的最后一个稳定版本。
- **与官方史料的交叉验证结论**：FreeBSD 11.2-RELEASE 发行说明（2018-06-27）与 Phoronix 报道交叉验证。
