# 155.1.3 SCTP、IPv6/KAME 与无线驱动支持

**要点**：SCTP（Stream Control Transmission Protocol，RFC 4960）是一个现代传输层协议，支持多流（multi-streaming）、多宿主（multi-homing），最初为电信信令设计但也用于通用网络；FreeBSD SCTP 实现主要由 Randall Stewart 和 Michael Tuexen 维护，于 FreeBSD 7.0（2008 年）正式合入基本系统，是业界质量最高的 SCTP 实现之一；IPv6 支持来自日本 KAME 项目——KAME 是 1998-2006 年日本多家公司和研究机构（NEC、Toshiba、Hitachi、IIJ、Keio University、WIDE 项目）合作的 BSD IPv6/IPsec 参考实现项目；FreeBSD 4.0（2000 年）引入 KAME IPv6 栈，是最早原生支持 IPv6 的主流操作系统之一；无线驱动方面 FreeBSD 支持多种无线网卡：**ath(4)**（Atheros，Sam Leffler 维护，质量最好）、**iwn(4)**/**iwm(4)**（Intel Wireless）、**urtw(4)**/**rtwn(4)**（Realtek USB WiFi）、**wpi(4)**（Intel 3945）等；无线子系统和 **wlan(4)** 802.11 层主要由 Sam Leffler 开发和维护

**史料**：**sctp(4)**、**inet6(4)**、**wlan(4)**、**ath(4)**、**iwm(4)** 手册页；KAME 项目官网（kame.net 存档）；Stewart, R. SCTP 相关 RFC 和 FreeBSD 实现文档；FreeBSD 4.0/7.0 Release Notes IPv6/SCTP 章节；Leffler, S. 无线子系统设计文档 ［A］

**史观**：总纲第 4 条——分离聚合是永恒规律（存疑）〔订正注：原挂“总纲第 22 条——开源运动”系自创名目伪标签，权威第 22 条为“知识注定过时”；按论旨改挂第 4 条〕：KAME 项目是国际开源协作的典范——日本多家公司和大学联合开发 IPv6 栈并贡献给所有 BSD 系统；在 1998-2005 年全球 IPv6 采用早期，KAME 代码是最成熟的 IPv6 实现，被 FreeBSD、NetBSD、OpenBSD、DragonFly 和 Mac OS X 采用

**辨析**：SCTP 引入版本——FreeBSD 7.0（2008）正式合入，6.x 时可作为补丁和内核选项实验性使用；IPv6 引入——FreeBSD 4.0（2000）包含 KAME IPv6，但更早的 FreeBSD 3.x 有 experimental IPv6 支持；KAME 项目结束时间——2006 年 3 月项目正式结束，代码已完整并入各 BSD 系统；无线驱动质量——FreeBSD 无线支持不如 Linux 全面，主要因为无线厂商很少提供开源驱动文档，尤其是最新的 802.11ac/ax 网卡支持滞后；Sam Leffler 在 FreeBSD 无线子系统的角色非常重要
