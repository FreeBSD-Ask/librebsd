# 162.6.1 Google v. Oracle 案语境与判决结果

**要点**：Google LLC v. Oracle America, Inc.（593 U.S. 1, Docket No. 18-956）是美国最高法院关于 API 版权的里程碑案件，判决于 **2021 年 4 月 5 日** 下达（距 FreeBSD 13.0 发布仅 8 天）：(1) 案件起因：Google 在 Android 中使用了 Java 的 37 个 API 包（约 11,500 行声明代码），Oracle（收购 Sun Microsystems 后）起诉 Google 侵犯版权；(2) 联邦巡回上诉法院先前判决 API 受版权保护且 Google 使用不构成 fair use；(3) 最高法院 6-2 判决（Justice Breyer 主笔，Roberts、Sotomayor、Kagan、Gorsuch、Kavanaugh 加入；Thomas、Alito 异议；Barrett 未参与）：Google 对 Java API 的重新实现构成 **fair use（合理使用）**；(4) 判决理由：API 是“调用系统”，其重新实现属于 transformative use（转换性使用），符合 fair use 四要素分析

**史料**：Google LLC v. Oracle America, Inc., 593 U.S. 1 (2021) 判决书全文；Oyez 案件摘要（oyez.org/cases/2020/18-956）；电子前哨基金会（EFF）关于判决的分析 ［A］

**史观**：法律结构：这一判决对 BSD 社区具有特殊历史意义——BSD 从诞生之日起就在重新实现 UNIX API（从 BSD 4.x 到 386BSD 到 FreeBSD），API 重新实现的法律地位长期处于灰色地带；最高法院的判决为“重新实现 API 构成 fair use”提供了法律确定性，这是 BSD 社区 40 年实践的法律背书

**辨析**：判决并未直接裁定“API 不受版权保护”——多数意见回避了这一宪法问题，而是基于 fair use 作出判决，这是司法最小主义（judicial minimalism）的体现；判决对软件行业影响深远，但具体边界仍需后续案件澄清
