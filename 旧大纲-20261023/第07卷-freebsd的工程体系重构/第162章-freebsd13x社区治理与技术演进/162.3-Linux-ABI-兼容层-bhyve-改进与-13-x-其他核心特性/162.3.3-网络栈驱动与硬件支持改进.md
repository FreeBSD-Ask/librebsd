# 162.3.3 网络栈、驱动与硬件支持改进

**要点**：13.x 期间网络和驱动改进包括：(1) **iflib 网络驱动框架** 成为更多网卡驱动的默认框架，统一了网卡驱动的编写模型，提高代码复用率；(2) **Intel ** **iwlwifi(4)** ** 驱动**：13.1 引入基于 LinuxKPI 802.11 兼容层的 iwlwifi 驱动，支持较新的 Intel WiFi 芯片，补充了原有 **iwm(4)** 驱动；(3) **netlink(4)**：13.2 引入 netlink 网络配置协议（源自 Linux），提供更现代的网络配置接口；(4) ASLR（地址空间布局随机化）在 13.2 中对 64 位可执行文件默认启用，提高安全性；(5) **ice(4)** Intel E810 网卡驱动更新；(6) **qat(4)** Intel QuickAssist 加密加速驱动；(7) 多个 PowerPC64 驱动移植；(8) VIMAGE/vnet jail 网络虚拟化持续完善，13.3 中 NFS 服务器可在 vnet jail 中运行

**史料**：FreeBSD 13.x Release Notes“Networking” “Drivers” “Security”章节；**iflib(9)**, **iwlwifi(4)**, **netlink(4)**, **VNET(9)** 手册页 〔L3 官方文档〕

**史观**：软件工程：基于 LinuxKPI 的 WiFi 驱动是 FreeBSD 工程的务实选择——Linux 拥有最新的 WiFi 芯片驱动，重新从零编写驱动成本极高且难以跟进新芯片，通过 LinuxKPI 兼容层可以以较低成本引入 Linux 驱动；这是“代码复用优先于 NIH 综合症”的体现

**辨析**：LinuxKPI 层不是“在 FreeBSD 上运行 Linux 驱动模块”，而是提供一套与 Linux 内核 API 兼容的接口层，让 Linux 驱动源码可以重新编译为 FreeBSD 内核模块；WiFi 驱动在 13.x 时期仍不如 Linux 完善，特别是较新的消费级 WiFi 芯片支持可能有延迟

**文献**：FreeBSD Manual Pages: **iflib(9)**, **iwlwifi(4)**, **netlink(4)**; FreeBSD Project. LinuxKPI source code (sys/compat/linuxkpi/). ［A］
