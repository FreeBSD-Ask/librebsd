# 162.7.3 OpenSSL 1.0.2 移除与 1.1.1 时代

**要点**：FreeBSD 13.0 移除了旧版本 OpenSSL 1.0.2，base 系统仅保留 OpenSSL 1.1.1；OpenSSL 1.0.2 于 2019 年 12 月 31 日 EOL（End of Life），FreeBSD 12.x 期间为兼容性保留了 1.0.2，13.0 彻底移除；OpenSSL 1.1.1 是 TLS 1.3 支持的首个 LTS 版本，引入 ChaCha20-Poly1305、X25519 等现代密码学算法；FreeBSD 13.x 全程保持 OpenSSL 1.1.1 系列，未升级到 OpenSSL 3.0——OpenSSL 3.0 升级在 FreeBSD 14.0（2023-11）才进行；同期 LibreSSL（OpenBSD fork）和 BoringSSL（Google fork）作为替代加密库存在，但 FreeBSD base 系统继续使用 OpenSSL

**史料**：FreeBSD 13.0 Release Notes；OpenSSL 1.0.2 EOL 公告（2019-12-31）；OpenSSL 1.1.1 Release Notes；freebsd-security@ 邮件列表关于 OpenSSL 升级的讨论 ［A］

**史观**：技术债务与代码考古：OpenSSL 1.0.2 在 EOL 后继续保留在 FreeBSD 12.x 中是典型的技术债务——兼容性要求推迟了不可避免的升级；13.0 偿清了这笔债务

**辨析**：OpenSSL 3.0 未在 13.x 引入是保守工程决策——OpenSSL 3.0 引入了新的 API 和许可证变更（Apache 2.0），且发布初期有较多兼容性问题，在稳定分支中引入风险过大；稳定分支（stable/13）通常不引入 OpenSSL 大版本升级
