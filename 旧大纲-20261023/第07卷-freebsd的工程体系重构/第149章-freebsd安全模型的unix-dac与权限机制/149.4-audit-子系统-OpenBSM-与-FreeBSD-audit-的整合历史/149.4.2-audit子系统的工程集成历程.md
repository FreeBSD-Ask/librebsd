# 149.4.2 audit 子系统的工程集成历程

**要点**：OpenBSM 的开发始于 2004 年前后，最初作为 FreeBSD ports 中的 security/openbsm-port 提供；FreeBSD 6.2-RELEASE（2007 年 1 月 15 日）首次将 OpenBSM 审计子系统集成到 FreeBSD 基本系统中，包括 **auditd(8)**、内核 **audit(4)** 支持和相关工具链；集成过程中，TrustedBSD 团队对 FreeBSD 内核进行了系统调用审计点插桩（instrumentation），在关键系统调用入口/出口处添加审计事件记录；审计子系统支持通过 **audit_control(5)** 配置文件选择审计事件类（如 lo（登录/登出）、ad（管理操作）、fd（文件删除）、fm（文件属性修改）、ex（execve）等），通过 **audit_user(5)** 配置特定用户的审计掩码；FreeBSD 10.x/11.x 中审计子系统持续完善，增加了对 Capsicum 能力模式事件、jail 事件等的审计支持

**史料**：FreeBSD 6.2-RELEASE Release Notes（2007-01-15，Security 章节记载 OpenBSM 集成）；FreeBSD src/sys/security/audit/ 目录源码（内核审计实现）；FreeBSD src/usr.sbin/auditd/ 目录（审计守护进程）；**audit_control(5)**、**audit_user(5)**、**audit.log(5)** 手册页；OpenBSM ChangeLog 和 commit 历史；**freebsd.duckdb** `commits` 表 `freebsd-src` 仓库数据库验证——OpenBSM 首次 vendor import commit 为 `ca0716f5714781ac39461f60647d795321921363`，author = 罗伯特·N. M. 沃森（Robert Watson），author_date = 2006-01-31T19:40:12Z，committer_date = 2006-01-31T19:40:12Z，subject ="Initial vendor import of the TrustedBSD OpenBSM distribution, version 1.0 alpha 1, an implementation of the documented Sun Basic Security Module (BSM) Audit API and file format, as well as local extensions to support the Mac OS X and FreeBSD operating systems."；此 2006-01-31 的 vendor import 时间点早于 FreeBSD 6.2-RELEASE（2007-01-15）约 11.5 个月，反映 OpenBSM 在 vendor import 后经历了约一年的集成测试与文档完善才作为基本系统组件正式发布；数据库另显示 Watson 于 2004-10-23 提交 `3e8c244949b99308a9064edc56d00f71aa808071`（"Add system call place-holders for the following system calls implementing Sun's BSM Audit API on FreeBSD"），2005-05-30 提交 `c64e9e6833f7bdadd775f1d303a80ebc3c3f86f9`（"Add /etc/security, into which the BSM audit configuration files will be installed"），2006-02-04 提交 `742561f0d7f17fb93b895617da2bc1770f43d101`（“Import OpenBSM 1.0 alpha 2”），表明 OpenBSM 集成是一个跨年度的多阶段工程，从 2004 年系统调用号预留到 2007 年 FreeBSD 6.2 正式发布历时约 2 年 3 个月；0 信任原则提示：此时期 FreeBSD 仍处于 SVN 时代，commit hash 经 2020 年 SVN-to-Git 迁移重算，author_date 可能由迁移脚本根据原始 SVN commit 元数据回填，可信度较高但非原始 Git 时代记录 ［A］

**史观**：总纲第 25 条——终结与延续：OpenBSM 的集成标志着 TrustedBSD 项目从“MAC 框架单一焦点”扩展为“多组件安全基础设施”——TrustedBSD 项目先后贡献了 MAC 框架、ACL、扩展属性、OpenPAM、OpenBSM 审计、Capsicum 等安全组件，其中大部分已合入 FreeBSD 基本系统；但审计子系统在默认安装中未启用（需手动配置 **auditd_enable =“YES”** 到 rc.conf 并设置审计策略），这延续了 FreeBSD“默认最小化、按需启用”的传统

**辨析**：原大纲称 OpenBSM 在 FreeBSD 5.x 集成——经 FreeBSD 6.2 Release Notes 和手册页 HISTORY 节交叉验证，OpenBSM 作为基本系统组件正式发布是在 FreeBSD 6.2（2007 年 1 月），5.x 时代仅可通过 ports 安装；数据库证据进一步精确化此时间线：vendor import 实际发生在 2006-01-31（早于 6.2-RELEASE 约 11.5 个月），系统调用号预留更早至 2004-10-23，反映 OpenBSM 集成是一个跨年度多阶段工程而非单次事件；“FreeBSD audit 与 Solaris audit 日志 100% 兼容”说法过于绝对——OpenBSM 实现了 BSM 标准 API 和基本日志格式，但 Sun/Oracle 在后续 Solaris 版本中添加了私有扩展，完全兼容性取决于具体版本和功能集；[双库核查：2026-08-14] 本节要点“OpenBSM 于 FreeBSD 6.2-RELEASE（2007-01-15）首次集成进基本系统”两库无法直接验证（文献库无 FreeBSD 6.2 Release Notes 全文；邮件列表库检索“OpenBSM”命中多为 tinderbox/dfilter 自动邮件，未见当事人讨论），但本节已有 freebsd.duckdb 证据（vendor import 2006-01-31，早于 6.2 约 11.5 个月）与 FreeBSD 6.2 Release Notes 记载一致，维持现有结论
