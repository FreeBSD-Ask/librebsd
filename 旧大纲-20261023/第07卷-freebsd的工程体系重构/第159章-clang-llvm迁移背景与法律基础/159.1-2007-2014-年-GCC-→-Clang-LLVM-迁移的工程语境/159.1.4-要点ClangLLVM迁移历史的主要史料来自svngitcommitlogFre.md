# 159.1.4 要点ClangLLVM迁移历史的主要史料来自svngitcommitlogFre

**要点**：Clang/LLVM 迁移历史的主要史料来自 svn/git commit log、FreeBSD Quarterly Status Reports、邮件列表公告和 Release Notes。一手核心史料包括：Roman Divacky 2009 内核可启动公告、Brooks Davis 2012 年 x86 默认切换公告、各版本 Release Notes 和 Announcement（9.0/9.1/10.0/11.0/12.0/13.0）、核心开发者 AsiaBSDCon/BSDCan 会议论文（David Chisnall 2014）。二手史料存在多处时间错置和事实错误：中文技术博客普遍误记默认切换版本（9.0 或 11.0），部分资料混淆 “导入 base” 与 “成为默认” 两个节点，部分文章错误归因 OpenBSD 切换时间和贡献者。David Chisnall 的姓名在中文资料中常被误写为 “Theresa Chisnall”，这是对 <theraven@FreeBSD.org> 用户名的误读（其全名为 David Chisnall），须以邮件列表署名和 AsiaBSDCon 论文作者信息为准。

**史料**：FreeBSD SVN/Git 提交历史（svnweb.freebsd.org）、FreeBSD Quarterly Status Reports 2009-2014、freebsd-current/freebsd-arch 邮件列表归档、David Chisnall AsiaBSDCon 2014 论文作者署名、各版本 Release Notes 与 Announcement。 ［A］

**史观**：总纲第 3 条——形式主义膨胀：编译器迁移是工程事实而非意识形态叙事，但二手叙述的版本错置和人名误读揭示了开源历史书写的一个普遍问题——缺乏一手史料考证的技术博客以讹传讹，最终形成 “常识性错误”。0 信任原则要求对每一个日期、人名、版本号返回 commit log 和官方公告核实。

**辨析**：Clang 导入 ports（devel/llvm）的精确时间早于导入 base，但早期 ports 版本与 base 版本的切换点需进一步核 SVN 历史确认；FreeBSD 9.0 发布时 Clang 版本为 3.0，但 9-STABLE 后续更新中 Clang 版本随季度更新升级，不同 9.x RELEASE 携带的 Clang 版本需逐版本核实。

**文献**：FreeBSD Project. FreeBSD Quarterly Status Reports 2009-2014 [R]. freebsd.org/news/status/；Chisnall D. LLVM in the FreeBSD Toolchain [C]//AsiaBSDCon 2014. Tokyo, 2014（作者署名：David Chisnall，明确非 “Theresa”）.
