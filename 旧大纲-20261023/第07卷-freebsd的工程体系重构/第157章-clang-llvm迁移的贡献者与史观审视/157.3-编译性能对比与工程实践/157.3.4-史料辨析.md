# 157.3.4 史料辨析

**要点**：编译器性能基准测试的史料主要来自 Phoronix、OpenBenchmarking.org 和 Clang/LLVM 官方数据。需注意：①Phoronix 测试在 Linux 平台进行，FreeBSD 上的结果可能不同（编译器后端代码相同但系统调用、链接器、libc 差异影响结果）；② 旧 GCC 4.2.1 与现代 Clang 的性能对比几乎无意义——GCC 4.2.1 是 2007 年版本，Clang 持续改进 15 年，比较的是两个时代的技术；③ 内核配置和编译选项（-O2 vs -O3、LTO、PGO）对结果影响极大，测试间比较需控制变量。FreeBSD 官方 buildworld/buildkernel 时间对比缺乏系统性公开数据，多为开发者个人经验。

**史料**：Phoronix 编译器基准测试系列（2010-2023）、OpenBenchmarking.org 结果库、FreeBSD 邮件列表开发者对 Clang 构建速度的个人报告。 ［A］

**史观**：形式主义膨胀：性能基准测试是开源社区最容易出现 cherry-picking 证据的领域——Clang 支持者引用编译速度和诊断质量，GCC 支持者引用特定生成代码性能基准。历史书写应呈现性能对比随版本演变的动态图景，而非静态定论。

**辨析**：GCC 4.2.1（FreeBSD 冻结版本）与 Clang 的比较在许可证纯洁化决策时（2007-2012）是相关比较，但 2020 年代现代 GCC（GCC 12/13/14）与 Clang 的对比已是不同语境——FreeBSD 迁移已完成，现代 GCC 仅存在于 ports 中。

**文献**：Larabel M. Phoronix Compiler Benchmarks [EB/OL]. phoronix.com/benchmarks, 2010-2023；Clang Team. Clang Performance and Diagnostics [EB/OL]. clang.llvm.org/features.html.［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］
