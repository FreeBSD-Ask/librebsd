# 156.3.2 lld 链接器替换 GNU ld

**要点**：LLVM 项目的 lld 链接器是 Clang/LLVM 工具链替换 GNU ld（GNU binutils 一部分，GPLv3 许可）的关键组件。lld 设计目标是高速、兼容 GNU ld 命令行选项、原生支持 LTO（Link-Time Optimization）。FreeBSD 12.0（2018.12）将 lld 设为 amd64、i386、armv7 架构的默认 bootstrap linker（提交 r334391、r336901、r337057），后续版本将 lld 扩展到所有支持架构。lld 的链接速度相比 GNU ld 有数量级提升（尤其在大型项目 LTO 构建时），这对 FreeBSD 本身的构建速度（buildworld/buildkernel）和 ports 中大型软件（如 Chromium、LLVM 自身）的编译速度有显著改善。

**史料**：FreeBSD 12.0 Release Notes（Userland Application Changes: "The default bootstrap linker has been changed to ld.lld(1) for amd64/i386/armv7"，r334391/r336901/r337057 引用）、lld 官方文档（lld.llvm.org）、Rafael Espíndola（lld 主要作者）等关于 lld 设计的演讲。 ［B］

**史观**：软件工程：链接器是工具链中最保守的组件（因为其 bug 可能导致所有程序失效），lld 从实验到默认用了更长时间（比 Clang 编译器晚约四年）。FreeBSD 作为最早大规模采用 lld 作为系统链接器的主流操作系统之一，为 lld 的成熟提供了重要的真实世界测试。

**辨析**：lld 在 FreeBSD 12.0 中是 “bootstrap linker”（构建世界/内核时使用的链接器），GNU ld 在 base 中仍保留一段时间以支持旧架构和特殊需求；完全移除 GNU ld 的过程持续到后续版本。
