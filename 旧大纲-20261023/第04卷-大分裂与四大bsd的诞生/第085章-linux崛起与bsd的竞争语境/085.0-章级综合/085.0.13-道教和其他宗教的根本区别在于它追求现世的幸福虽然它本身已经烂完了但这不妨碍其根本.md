# 085.0.13 道教和其他宗教的根本区别在于它追求现世的幸福虽然它本身已经烂完了但这不妨碍其根本

道教和其他宗教的根本区别在于，它追求现世的幸福。虽然它本身已经烂完了，但这不妨碍其根本取向的独特性。其他宗教大多承诺来世的救赎，而道教关切此岸的安宁。这种现世取向使道教在宗教谱系中占据特殊位置：它不回避苦难，但也不美化苦难，而是试图在现世中寻找出路。
