# 080.3.2 里程碑事件类

### 新闻条目 1

- **新闻标题（中英）**：OpenBSD Cryptography（OpenBSD 密码学）
- **新闻来源**：OpenBSD Project 官方网站 + OpenBSD 项目维护者集体署名 + 持续维护至 2026 年 + **<https://www.openbsd.org/crypto.html>**［引用日期 2026-07-27］
- **新闻摘要**：OpenBSD 密码学页面明确记载：“OpenBSD was the first operating system to ship with an IPsec stack. We've been including IPsec since the OpenBSD 2.1 release in 1997.”该页面同时说明 OpenBSD 选择加拿大作为开发地的法律依据：“The OpenBSD project is based in Canada. The Export Control List of Canada places no significant restriction on the export of cryptographic software, and is even more explicit about the free export of freely-available cryptographic software.”页面列出 OpenBSD 团队在 USENIX 1999 发表的多篇密码学论文，包括 Niels Provos 与 David Mazieres 的“A Future-Adaptable Password Scheme”（bcrypt 论文）、Theo de Raadt（西奥·德·若特） 等人的“Cryptography in OpenBSD: An Overview”。
- **与本章主题的关联说明**：本章叙事须呈现 OpenBSD 安全文化奠基期的密码学工程化里程碑，OpenBSD 密码学页面明确记载“OpenBSD 是第一个内置 IPsec 协议栈的操作系统，自 OpenBSD 2.1（1997）起包含 IPsec”，构成本章“安全文化奠基”叙事的密码学工程化里程碑。OpenBSD 选择加拿大作为开发地的法律依据亦是本章“安全文化奠基”叙事的地缘政治维度。OpenBSD 团队在 USENIX 1999 发表的多篇密码学论文为本章衔接第083章“三足鼎立”叙事中 OpenBSD 密码学领先地位的学术层证据。
- **与官方史料的交叉验证结论**：该页面为 OpenBSD 项目官方史料，所述“OpenBSD 是第一个内置 IPsec 协议栈的操作系统，自 OpenBSD 2.1（1997）起包含 IPsec”与 OpenBSD 2.1 变更日志（条目 1）所述工程变更形成时序印证——2.1 周期引入 IPsec，标志 OpenBSD 密码学工程化的早期里程碑。所述“OpenBSD 团队在 USENIX 1999 发表的多篇密码学论文”为后续章节衔接第 76 章叙事的学术层证据。

### 新闻条目 2

- **新闻标题（中英）**：A Future-Adaptable Password Scheme（一种未来可适应的密码方案）—— bcrypt 论文
- **新闻来源**：USENIX 1999 + Niels Provos 与 David Mazieres（OpenBSD 开发者） + 1999 + **<https://www.openbsd.org/papers/bcrypt-paper.ps>**［引用日期 2026-07-27］
- **新闻摘要**：Niels Provos 与 David Mazieres 在 USENIX 1999 发表“A Future-Adaptable Password Scheme”论文，正式提出 bcrypt 密码哈希算法。该论文基于 OpenBSD 2.1 周期引入的 BLOWFISH-based crypt 算法工程实践（参见条目 1），提出可配置成本系数的密码哈希方案，使密码哈希能够随硬件性能提升而增强。bcrypt 论文的发表标志 OpenBSD 密码学工程化从工程实践上升为学术贡献，是 OpenBSD 安全文化奠基期的学术里程碑。
- **与本章主题的关联说明**：本章叙事须呈现 OpenBSD 安全文化奠基期的学术贡献，bcrypt 论文是 OpenBSD 团队首次在 USENIX 学术会议上发表密码学论文，构成本章“安全文化奠基”叙事的学术层证据。论文基于 OpenBSD 2.1 周期引入的 BLOWFISH-based crypt 算法工程实践，体现 OpenBSD 安全文化“工程实践—学术贡献”的双向流动特征。
- **与官方史料的交叉验证结论**：该论文为 OpenBSD 团队成员在 USENIX 1999 发表的学术论文，与 OpenBSD 2.1 变更日志所述“New scalable BLOWFISH-based crypt algorithm for passwd file entries”形成工程实践—学术贡献双重印证。论文所述 bcrypt 算法与 OpenBSD 2.1 引入的 BLOWFISH-based crypt 算法为同一工程实践的学术化提炼。

### 新闻条目 3

- **新闻标题（中英）**：Cryptography in OpenBSD: An Overview（OpenBSD 中的密码学：概述）—— Theo de Raadt 等人 USENIX 1999 论文
- **新闻来源**：USENIX 1999 + Theo de Raadt、Niklas Hallqvist、Artur Grabowski、Angelos D. Keromytis、Niels Provos（OpenBSD 开发者集体署名） + 1999 + **<https://www.openbsd.org/papers/crypt-paper.ps>**［引用日期 2026-07-27］
- **新闻摘要**：Theo de Raadt 等五名 OpenBSD 开发者在 USENIX 1999 发表“Cryptography in OpenBSD: An Overview”论文，系统阐述 OpenBSD 密码学工程的总体架构，包括 IPsec 协议栈、SSL/OpenSSL 集成、随机数基础设施、密码哈希算法、加密文件系统等组件。该论文是 OpenBSD 团队对 1996-1999 年密码学工程化实践的学术总结，标志 OpenBSD 安全文化从工程实践上升为系统化的学术贡献。
- **与本章主题的关联说明**：本章叙事须呈现 OpenBSD 安全文化奠基期的学术总结，“Cryptography in OpenBSD: An Overview”论文是 OpenBSD 团队对 1996-1999 年密码学工程化实践的学术总结，构成本章“安全文化奠基”叙事的学术总结层证据。论文由 Theo de Raadt 等 5 名 OpenBSD 开发者集体署名，体现 OpenBSD 安全文化的集体协作特征。
- **与官方史料的交叉验证结论**：该论文为 OpenBSD 团队成员在 USENIX 1999 发表的学术论文，与 OpenBSD crypto.html（条目 4）所述“OpenBSD 是第一个内置 IPsec 协议栈的操作系统”形成工程实践—学术总结双重印证。论文所述密码学工程总体架构与 OpenBSD 2.0/2.1/2.2 变更日志所述工程变更形成系统性印证。
