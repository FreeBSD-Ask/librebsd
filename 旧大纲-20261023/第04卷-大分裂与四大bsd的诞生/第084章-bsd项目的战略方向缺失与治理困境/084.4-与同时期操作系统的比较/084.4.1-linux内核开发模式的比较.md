# 084.4.1 Linux 内核开发模式的比较


**1996 年** 同期操作系统治理结构对照如下：

| 操作系统 | 治理模式 | 主导主体 | 与 BSD 对照 |
| ------ | ------ | ------ | --------- |
| FreeBSD | Core Team 选举制 | committer 选举 | 民主化技术决策 |
| NetBSD | Foundation 董事会制 | 成员选举 | 法律与资金组织化 |
| OpenBSD | 个体主导制 | de Raadt 个人 | 独裁式技术决策 |
| Linux 内核 | 个人主导制 | Linus Torvalds 个人 | 依赖贡献者提交补丁 |
| Windows NT 4.0 | 公司主导 | Microsoft 公司 | 商业开发团队 |
| Solaris 2.5.1 | 公司主导 | Sun 公司 | 商业开发团队 |

  **要点**：1996 年 Linux 内核开发模式——Linus Torvalds 个人主导，依赖贡献者提交补丁；模式与 BSD 三项目形成对照，影响后续开源项目治理
