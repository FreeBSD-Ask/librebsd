# 082.1.2 与 Intel、Broadcom 等厂商的冲突

  **要点**：OpenBSD 固件加载政策导致与 Intel、Broadcom 等厂商的冲突——厂商拒绝开放固件源码，OpenBSD 拒绝加载二进制固件；冲突影响 OpenBSD 硬件支持范围
  
**史料**：OpenBSD 与 Intel/Broadcom 历年邮件存档、de Raadt 关于厂商冲突的公开声明、厂商关于固件开放的声明 ［A］
  
**史观**：总纲第 3 条——不存在进步，只有权力再分配：固件加载政策冲突反映开源社区与硬件厂商的张力
  
**辨析**：冲突的具体表现在不同厂商叙事中略有差异——需对照多方公开声明核实
  
**文献**：OpenBSD 与厂商邮件存档；de Raadt 公开声明 ［A］
