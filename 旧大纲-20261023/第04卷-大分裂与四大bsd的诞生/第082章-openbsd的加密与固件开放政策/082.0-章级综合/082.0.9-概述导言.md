# 082.0.9 概述导言

> 本章由原第032章（旧章号体系）拆分而来（同批拆出第 73、74 章），承载 75.11-75.14 节。

本章以 OpenBSD 的加密与固件开放政策为题，按四个子节展开：75.11 界定 OpenBSD 坚持不加载二进制固件、源码必须开放的立场及其在无线固件上的适用；75.12 将该时期（1995-1996 年前后）与 Linux 内核安全审计、Windows NT 4.0 安全模型、Solaris 2.5 安全机制并列比较；75.13 梳理 OpenBSD 2.6/3.7/3.8/3.9 时期的 OpenSSH/isakmpd/USER_LDT 漏洞群与 errata 机制的成熟；75.14 从项目统摄史观审视独裁模式、代码审计团队与被疏远贡献者的本体论平等。各子节内容以对应节文件为准，本章不重复展开。

> 自反性声明：本章所书皆是形式主义化的重构，并非对“真实的 BSD 历史”的呈现。本章的议题划分、事件选择与因果归因全部基于编纂者的哲学设定，不声称客观或中立，欢迎被更诚实的叙事所超越。
