# 076.1.1 事件时间线

  **要点**：**1994 年 12 月** Theo de Raadt 被 NetBSD Core Team 逐出——具体时间线涉及邮件列表讨论、内部决议与通知发布；时间线是后续 OpenBSD 创建的关键节点。de Raadt 离开 NetBSD 与 OpenBSD 创建事件时间线如下：

| 事件 | 日期 | 备注 |
| -- | -- | -- |
| de Raadt 末次 netbsd-src commit | 1994-12-17 | `699d2a37b0e3c0c6ff29ea0d407c3feeba5642b4` |
| Chris Demetriou Core Team 扩容通知 | 1994-12-22 | J.T. Conklin 与 Paul Kranenburg 加入 core |
| Adam Glass（亚当·格拉斯） 逐出通知邮件 | 1994-12-23 | netbsd-users 邮件列表 |
| Chris Demetriou 邮件列表存档恢复通知 | 1994-12-25 | 技术性通知，未触及驱逐事件 |
| OpenBSD CVS 仓库初始导入 | 1995-10-18 | `df930be708d50e9715f173caa26ffe1b7599b157` |
| OpenBSD 1.2 首次公开发布 | 1996-07-01 | 首个公开版本 |
| OpenBSD 2.0 发布 | 1996-10-01 | 确立 6 个月发布节奏 |

**史料**：netbsd-users 邮件列表 1994.12 归档、Adam Glass 1994.12.23 通知邮件原文、de Raadt 个人主页自述；**netbsd.duckdb** 统计结论 C-04 显示：netbsd-src 总 commit 数 773,683（统计档案查询时点 2026-07-27，其后库有增补；SQL 查询 `SELECT COUNT(*) FROM commits WHERE repo_name='netbsd-src'`），其中 1994 年 netbsd-src = 17,726 commits（**netbsd.duckdb** 查询 L1.1.1），反映 Theo fork 当年 NetBSD 仍保持高活跃度开发；**netbsd.duckdb** 推断性统计 C-18 显示：Theo de Raadt 于 1994-12 离开 NetBSD fork OpenBSD，其前后 6 个月 NetBSD commit 量配对样本 Wilcoxon 符号秩检验结果为 W = 10、p = 0.9165、效应量 r = 0.043，不拒绝 H0（即 Theo fork 对 NetBSD 短期 commit 量无统计显著影响），Python 脚本 `scipy.stats.wilcoxon`，反映 1994-12 的 fork 事件在 commit 量层面未造成显著冲击——NetBSD 项目在 de Raadt 离开后由 Core Team 其他成员（christos、cgd 等）维持开发节奏；deraadt（Theo de Raadt）在 netbsd-src 末次 commit 为 1994-12-17T23:12:41Z（commit_hash `699d2a37b0e3c0c6ff29ea0d407c3feeba5642b4`），与 Wilcoxon 检验的 fork 时间点（1994-12）完全一致

**史观**：总纲第 5 条——没有必然性，只有偶然性：de Raadt 被逐的个人事件是 OpenBSD 创建的偶然诱因；统计结论印证总纲第 4 条——分离聚合是永恒规律——C-18 Wilcoxon 不拒绝 H0 表明 fork 短期 commit 量影响有限，但长期影响（OpenBSD 成为安全领域独立分支）超出统计窗口，分离-聚合-再分离的辩证运动在 NetBSD/OpenBSD 案例中得到量化印证；第 9 条经验优先——统计结论为 “个人事件对项目工程产出的短期影响” 提供量化参照，不替代社区政治与文化维度的考据

**辨析**：事件的具体时间线在不同叙事中差异较大——部分资料称 1994 年 12 月，部分称 1995 年初；需对照邮件列表存档交叉验证；【0 信任原则·统计显著 ≠ 实际显著】C-18 Wilcoxon p = 0.9165 不拒绝 H0 仅表明 Theo fork 前后 6 个月 NetBSD commit 量无统计显著差异，不等于 fork 事件对 NetBSD 社区凝聚力、技术方向、贡献者士气无实际影响——de Raadt 作为 NetBSD 早期核心开发者其离开必然造成社区关系破裂与技术路线调整，此类影响无法由 commit 量捕获；【0 信任原则·效应量与样本量】C-18 效应量 r = 0.043 为极小效应，配对样本数 N = 6 月份对，统计功效较低，不拒绝 H0 可能存在第二类错误风险——若 fork 事件实际存在中等程度影响，6 个月窗口的 Wilcoxon 检验可能无法检测；【0 信任原则·多重比较风险】C-04 netbsd-src commit 量与 C-18 Wilcoxon 检验跨章引用（第 26、28、31 章均引用）时存在多重比较风险，须按 Bonferroni 或 Benjamini-Hochberg 校正后解读；【0 信任原则·CVS-to-Git 迁移风险】netbsd-src 为 CVS 主仓的 GitHub 镜像，CVS-to-Git 转换可能重写 commit_date 字段，1994-12-17 末次 commit 时间戳须与邮件列表存档交叉验证；【0 信任原则·commit 量不等于质量】C-04 netbsd-src 773,683 commits 反映累计开发活跃度但不等于代码质量，Theo fork 后 NetBSD 可能通过更严格的 code review 维持质量，commit 量与质量的脱钩须结合 commit_files 表与 commit 规模综合判断
