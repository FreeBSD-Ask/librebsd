- 【Linux社区】2003 年 8 月 Matthias Andree 在 lkml Promise SATA driver GPL'd 讨论串中援引 FreeBSD 4-STABLE 与 5-CURRENT 内核源码，为 Promise 控制器 tagged command queueing 兼容性问题作证，原文 It appears that FreeBSD 4-STABLE blacklists some older (before-TX2) Promise chips because they apparently lock up when used with tagged command queueing，并附 freebsd.org cvsweb 上 ad_tagsupported() 黑名单函数与 ATAng 驱动链接；是 BSD 早期 ATA 层错误经验作为 Linux libata 移植决策参照的直接证据。 <!-- ROW_MINE: lkml.messages.1726774 -->`
- 【Linux社区】Matthias Andree 以 FreeBSD 4.2-STABLE 客户端复现 Linux 2.2.18 NFS v3 服务端 ACCESS 过程错误：只读导出时服务端应返回带实际权限（含 READ|LOOKUP|EXECUTE 位）的 OK，而实际返回按 RFC-1813 无效的 NFS3ERR_ROFS，致 FreeBSD 客户端挂载后 ls 直接报 read-only；抓包证据附 libpcap 0.6.1 与 ethereal 0.8.15 输出，并 cc Alan Cox 作内核发布维护者使问题成为已知议题。BSD 客户端作 Linux 内核 bug 复现器。 <!-- ROW_MINE: lkml.messages.1988789 -->`
