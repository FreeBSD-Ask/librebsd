- 【Linux社区】Andy Lutomirski：回应 Bottomley 的“只想要更安全、损害更小”诉求，提出 user namespace 隔离的具体路径——**“我们差不多到了这样一个时点：把系统上基本每一个服务都塞进一个 user namespace 是合理的做法；那样的话，除非有 bug，你就不该能拿下内核。我想知道这是否差不多正好是你要的东西”**；并给出操作顺序 **“挂载你的文件系统、新建一个 userns、把所有网络设备移进由该 userns 拥有的新 netns、unshare 挂载命名空间，并设法让你用的 systemd 或别的 init 程序配合”**，还指出 **“如果你只是想保护内核，甚至可以原样映射所有 uid，包括 root”**；主要障碍是 **“在 userns 里几乎不可能挂载真正的文件系统（即非 tmpfs），可以有个外部守护进程来帮忙”**（KS2014 档案） `<!-- ROW_MINE: ksummit-discuss.messages.346912 -->`
