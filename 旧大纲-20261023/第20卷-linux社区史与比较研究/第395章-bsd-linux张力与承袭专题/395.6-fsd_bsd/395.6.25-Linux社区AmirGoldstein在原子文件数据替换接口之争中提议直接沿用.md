# 395.6.25 Linux社区AmirGoldstein在原子文件数据替换接口之争中提议直接沿用

- 【Linux社区】Amir Goldstein 在原子文件数据替换接口之争中提议直接沿用 BSD 的 exchangedata 调用而非另造语义，指出 ext4 的 EXT4_IOC_EXT_MOVE ioctl 只是前一线程已提及的 exchangedata() BSD API 的更细粒度同类机制；他并建议把推动口号改成实现 exchangedata、说服 VFS 支持该调用，使 Linux VFS 向 BSD 既有接口靠拢而非另立一套原子替换语义。`<!-- ROW_MINE: linux-fsdevel.messages.693496 -->`
- 【Linux社区】Adam J. Richter 就 DualFS 分离元数据与数据区的收益论证作出澄清，明确承认 BSD 快速文件系统 bsd-ffs 与 ext2、ext3 早已把元数据聚合在 cylinder group 内，可改进之处仅在于不同 cylinder group 之间较少发生的元数据寻址开销，属对 BSD 磁盘布局事实的正面承认。`<!-- ROW_MINE: linux-fsdevel.messages.694200 -->`
- 【Linux社区】Trampoline 文件描述符 RFC 的 W^X 语义之争中，Mark Rutland 反驳把 JIT 临时可写执行缓冲列为违例，指可查证 W^X 词条所引的 OpenBSD 3.3 发行说明与相关演示，并称其本就预期 JIT 以 mprotect 翻转写与执行属性；本信作者 Mickaël Salaün 则以 PaX 自 2000 年起、早于 2003 年 OpenBSD 的部分实现为由反转时间线，BSD 在此同时充当语义判据与年代争议的双方共同对象。`<!-- ROW_MINE: linux-fsdevel.messages.694217 -->`
