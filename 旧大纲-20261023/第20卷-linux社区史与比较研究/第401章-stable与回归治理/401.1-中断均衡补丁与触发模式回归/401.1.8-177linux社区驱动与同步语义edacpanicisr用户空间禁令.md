# 401.1.8 17.7 【Linux社区】驱动与同步语义（EDAC panic/ISR 用户空间禁令）

**要点（判定表逐字）**：Joop Boonen（2006-03-01）答 Randy.Dunlap：内核 2.6.16-rc3-git3-2-smp；tiger s2460 mainload（原文如此）+ 2 thouroughbred A 1800+（原文拼写如此）；EDAC MC0 UE 报 AMD762 即 Kernel panic，Badness in smp_call_function at arch/i386/kernel/smp.c:595（手抄自屏幕、有数码照片佐证）；“The bluesmoke developer team is also looking into this.”——EDAC/amd76x_edac panic 双线追踪实录；Mark Hapke（2002-05-22，不来梅 tzi.de）：双 P3 933 ServerWorks CNB20LE 2.4.9——**ISR 在另一 CPU 时 __put_user_asm 返回 -EFAULT、同 CPU 才行**——ISR 跨核用户空间访问失败样本（与 035 Cox 裁定成对）；Alan Cox（2002-05-30）答 Hapke：**“User space access from interrupts is a complete no-no. If you absolutely must share memory directly then allocate kernel memory, mmap it into the user process and write to the kernel address. Have a look at the mmap code in the sound drivers”**（此前“might work by chance if the IRQ happens to occur on the same CPU...and the wind is in the right direction”）——ISR 用户空间访问禁令权威裁定
