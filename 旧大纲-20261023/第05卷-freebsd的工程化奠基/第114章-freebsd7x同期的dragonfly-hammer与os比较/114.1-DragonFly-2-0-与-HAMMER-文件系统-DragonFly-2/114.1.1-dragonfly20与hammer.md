# 114.1.1 DragonFly 2.0 与 HAMMER

  **要点**：DragonFly BSD 2.0（2008.7.20）引入 HAMMER 文件系统，由 Matt Dillon 单人开发；HAMMER 采用 B-tree 写时复制设计，支持可配置历史保留、即时快照、崩溃即时恢复（无需 **fsck(8)**）、近实时镜像
  
**史料**：DragonFly BSD 2.0 Release Notes、HAMMER 文档［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档〕
  
**史观**：边缘者的作用，Dillon 单人开发体现边缘者力量
  
**辨析**：HAMMER 是否真优于 ZFS/UFS，需查基准测试
