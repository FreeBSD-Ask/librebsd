**史观**：技术债务与代码考古，6.x 是 5.x 债务的偿还
  
**辨析**：经 freebsd.duckdb tags 表验证，6.0-RELEASE 的 tagger_date 为 2005-11-03T00:35:26Z（非旧叙事 2005.11.4，误差 1 天，可能为公告日期与 tag 日期差异）；6.x 是否真稳定，需查早期 bug 报告；0 信任原则适用说明：L1.1.1 年度 commit 量基于 author_date 聚合，FreeBSD SVN-to-Git 2020 迁移可能引入日期偏差；L1.1.1/L1.1.2 报告截断（仅显示前 30 行）导致 2004-2008 年 freebsd-src 数据不可直接获取，须直接查询 freebsd.duckdb 验证；L1.3.2 文件修改数为替代指标，不等于 commit 量（单个 commit 可修改多文件）；L1.4.1/L1.4.2 release tag 间隔报告同样截断，部分 tag 为 svn2git 重构标签须排除 _cvs 后缀
