# 107.1.9 模块化存储层的设计

  **要点**：GEOM 由 Poul-Henning Kamp（波尔-亨宁·坎普）(phk) 设计，是 FreeBSD 5.0 引入的模块化存储层框架，将磁盘 IO 路径抽象为 GEOM class 链，每个 class 可实现 transformation(如 mirror、stripe、encryption)；目标是替代 4.x 静态磁盘子系统
  
**史料**：phk GEOM 演讲、GEOM(4) 手册页、FreeBSD 5.0 Release Notes ［A］
  
**史观**：专题语（不设总纲条号）——形式主义膨胀与抽象克制，GEOM 是抽象克制的典范
  
**辨析**：GEOM 是否受 Linux device-mapper 影响，需查 phk 演讲
  
**文献**：phk 演讲；GEOM(4) 手册页 ［A］
