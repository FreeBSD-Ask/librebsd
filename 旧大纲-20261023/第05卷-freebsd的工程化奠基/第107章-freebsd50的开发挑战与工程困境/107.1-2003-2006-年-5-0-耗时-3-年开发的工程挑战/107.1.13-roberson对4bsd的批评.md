# 107.1.13 Roberson 对 4BSD 的批评

  **要点**：Jeff Roberson 在 BSDCon 2003 论文 “ULE: A Modern Scheduler for FreeBSD” 中批评 4BSD 调度器 “核心算法是 O(n) 的，在进程数量极大的环境中不可取” 且 “缺乏 CPU 亲和性，某些工作负载在 SMP 上反而比 UP 更慢”

  Roberson 对 4BSD 调度器的批评原文：

  > The core algorithm is O(n) in the number of processes, making it unsuitable for environments with extremely large numbers of processes
  >
  > It lacks CPU affinity, and some workloads actually perform worse on SMP than on UP
  >
  > ——Jeff Roberson, “ULE: A Modern Scheduler for FreeBSD”, BSDCon 2003

**史料**：Roberson BSDCon 2003 论文、freebsd-hackers 邮件讨论 ［A］
  
**史观**：专题语（不设总纲条号）——技术债务与代码考古，4BSD 调度器是 1980s 设计的债务
  
**辨析**：Roberson 批评是否公平，需独立验证 4BSD 调度器性能
