# 107.5.4 强制访问控制的引入

  **要点**：MAC(Mandatory Access Control) 框架由 Robert Watson 等在 FreeBSD 5.0 引入，允许加载多个安全策略模块 (如 mac_biba/mac_mls/mac_none/mac_seeotheruids/mac_partition/mac_portacl)；目标是提供细粒度访问控制替代传统 UNIX 自主访问控制
  
**史料**：Watson BSDCon 2001 MAC 演讲、mac(4) 手册页、FreeBSD 5.0 Release Notes ［A］
  
**史观**：形式主义膨胀与抽象克制，MAC 框架是抽象克制设计
  
**辨析**：MAC 是否真被广泛使用，需查部署案例
  
**文献**：Watson BSDCon 2001 演讲；mac(4) 手册页；FreeBSD 5.0 Release Notes ［A］
