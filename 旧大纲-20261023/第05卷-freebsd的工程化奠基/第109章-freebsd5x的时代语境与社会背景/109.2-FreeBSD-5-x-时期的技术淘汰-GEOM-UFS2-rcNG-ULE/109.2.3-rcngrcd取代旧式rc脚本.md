# 109.2.3 rcNG（rc.d）取代旧式 rc 脚本

  **要点**：FreeBSD 5.0-RELEASE（2003 年 1 月 16 日，release/5.0.0 tagger_date = 2003-01-16T16:56:23Z）默认采用 rcNG（Next Generation rc，即 rc.d 系统），取代 4.x 时代的单文件 /etc/rc 启动脚本；rcNG 由 Mike Makonnen 等设计实现，采用 rcNG 风格的 rc.d/ 目录脚本，每个服务一个独立脚本（如 /usr/local/etc/rc.d/apache.sh），通过 **rcorder(8)** 解析依赖关系，支持并行启动、依赖管理、PROVIDE/REQUIRE/BEFORE 关键字；rcNG 在 FreeBSD 5.0 成为默认，4.x 仍使用旧 rc 直至 4.11（2005 年）；NetBSD 1.5（2000 年 12 月）已先于 FreeBSD 引入类似 rc.d 系统，FreeBSD rcNG 设计借鉴 NetBSD 但增加 /etc/rc.conf.d/ 模块化配置；rcNG 至今仍是 FreeBSD 标准启动系统，与 systemd（Linux 2010 年起）路径形成对照
  
**史料**：FreeBSD 5.0-RELEASE Release Notes (2003.1) rcNG 章节、Makonnen 2002 “rcNG Design” 邮件列表文档、rc(8) 与 rcorder(8) 手册页、NetBSD 1.5-RELEASE Release Notes (2000.12) rc.d 章节；freebsd.duckdb freebsd-src 仓库 tags 表 release/5.0.0 的 tagger_date = 2003-01-16T16:56:23Z ［A］
  
**史观**：总纲第 4 条——分离与聚合：rcNG 把单文件 rc 分离为独立服务脚本，通过 rcorder 聚合为依赖有序的启动序列；总纲第 15 条——文化即形式主义：rc.d 系统是软件工程对启动管理的模块化设计
  
**辨析**：经 freebsd.duckdb tags 表验证，5.0-RELEASE 的 tagger_date 为 2003-01-16（非旧叙事 2003.1.19，误差 3 天，可能为公告日期与 tag 日期差异）；rcNG 与 NetBSD rc.d 的关系需辨析——FreeBSD 借鉴 NetBSD 但实现不同；rcNG 与 systemd 的对比存在工程争议——前者简洁但功能有限，后者复杂但功能强大；rcNG 与 systemd 的哲学分野参见 BSD init 发展史相关章节
