# 104.1.1 Lemon 的设计动机

  **要点**：Jonathan Lemon 在 2000 年向 freebsd-hackers 提交 kqueue 提案，动机是 **select(2)**/**poll(2)** 在高并发连接下的 O(N) 扫描成本与状态丢失，无法支撑 Yahoo!/Hotmail 级别的事件驱动服务器；kqueue 首次 commit 于 2000 年 4 月 16 日（4.0-RELEASE 2000.3.20 之后，4.1-RELEASE 2000.7.26 之前）
  
**史料**：Lemon 的 freebsd-hackers 2000.7 邮件 “kqueue - kernel event notification”、kqueue(2) 手册页原始版本；freebsd.duckdb freebsd-src 仓库 commits 表 kqueue 首次 commit 为 2000-04-16T18:53:38Z Jonathan Lemon（commit cb679c385ef325d11f162e09b604df7532fc8009，subject = "Introduce kqueue() and kevent(), a kernel event notification facility."），sys/sys/event.h 同日 19:02:08 首次引入（commit 3ee12e4fe3c884db74bc236f6f76dfb7539eb0d1） ［A］
  
**史观**：实践先于理论，select/poll 的工程瓶颈催生 kqueue 设计而非理论驱动
  
**辨析**：经 freebsd.duckdb commits 表验证，kqueue 首次 commit 为 2000-04-16（非旧叙事 2000.7.5），属 4.1-CURRENT 开发周期内合入主干，4.1-RELEASE 2000.7.26 正式发布；经邮件列表库验证通过（fact-check 2026-08-14），Jonathan Lemon 2000-06-22《Re: tail after kqueue changes》（freebsd-current，Message-ID `<no-id-freebsd-current-798100dde2fde2f6>`）与 2000-10-25《Re: kqueue microbenchmark results》（freebsd-hackers，署名 <jlemon@flugsvamp.com>）两条一手邮件佐证 Lemon 于 2000 年作为 kqueue 作者的活跃期，与 commit 时间线一致；Lemon 的雇主关系存在争议，部分来源称其受 Yahoo! 工作驱动，需查 commit metadata 与邮件签名确认
