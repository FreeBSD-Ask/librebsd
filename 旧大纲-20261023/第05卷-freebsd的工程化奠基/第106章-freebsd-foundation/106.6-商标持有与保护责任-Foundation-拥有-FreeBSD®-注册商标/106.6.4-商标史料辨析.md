# 106.6.4 商标史料辨析

  **要点**：商标史料疑点：(1) 商标最初注册人是 FreeBSD Project 还是 Walnut Creek CDROM;(2) 移交时间与流程；(3) USPTO 注册日期的精确性
  
**史料**：USPTO 注册记录、Walnut Creek CDROM 退出文件、Foundation 商标页 ［A］；openbsd.duckdb 查询 L3.6.1 显示：含 license/copyright/patent/BSD 关键词的 commit 时间分布——1996 年 6,473 条/149 contributors、1997 年 8,296 条/220 contributors、2000 年 15,456 条/496 contributors、2002 年 24,711 条/586 contributors、2005 年 20,222 条/713 contributors、2010 年 18,614 条/729 contributors，license/copyright 关键词 commit 量在 2002 年达峰值（24,711 条）后逐步下降，反映 BSD 许可证相关讨论在 2000-2002 年互联网泡沫期最活跃，与 Foundation 2000 年成立后加强商标与许可证管理的时序吻合
  
**史观**：0 信任原则，USPTO 与 Foundation 自述需交叉验证
  
**辨析**：USPTO 注册日期与 Foundation 自述日期是否一致，需逐项核对；【0 信任原则·关键词匹配】L3.6.1 的关键词匹配基于 LIKE 操作（大小写不敏感），可能将 commit message 中非许可证语境的 “BSD”（如 BSDCon、BSDCan 会议名）误匹配为许可证关键词，须结合 commit message 全文上下文验证
  
**文献**：USPTO 注册记录；Foundation 商标页 ［A］；openbsd.duckdb 查询 L3.6.1：含 license/copyright/patent/BSD 关键词的 commit 时间分布（1996-2010）[DB/OL]. 原材料/研究/bsd 仓库分析/数据分析/深层信息挖掘.md
