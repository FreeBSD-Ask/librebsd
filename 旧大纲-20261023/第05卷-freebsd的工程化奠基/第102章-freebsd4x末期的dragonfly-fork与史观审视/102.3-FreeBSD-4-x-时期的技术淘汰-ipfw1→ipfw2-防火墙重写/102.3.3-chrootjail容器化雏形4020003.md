# 102.3.3 chroot → jail 容器化雏形（4.0，2000.3）

  **要点**：传统 UNIX **chroot(2)** 自 4.4BSD 时代起提供文件系统根目录隔离，但缺少进程隔离、网络隔离、用户隔离、设备隔离；chroot 容易被 root 用户逃逸，无法作为真正的安全容器；FreeBSD 4.0-RELEASE（2000.3.20）引入 **jail(2)** 系统调用与 **jail(8)** 管理工具，初始实现由 Poul-Henning Kamp（波尔-亨宁·坎普） 于 1999 年 4 月 28 日提交（早于 4.0-RELEASE 近一年，属 4.0-CURRENT 开发周期），Robert Watson 后续在 4.x 时期贡献安全增强；jail 在 chroot 基础上增加进程隔离（jail 内进程无法访问 jail 外进程）、网络隔离（jail 绑定特定 IP 地址）、用户隔离（jail 内 root 权限受限）、设备隔离（jail 内无法访问原始设备节点）；jail 早于 Linux 容器（LXC，2008）与 Docker（2013）近十年，被视为现代容器化的先驱；jail 在 4.x 时期被 Yahoo! 等大规模部署用于共享主机服务
  
**史料**：FreeBSD 4.0-RELEASE Release Notes；Poul-Henning Kamp 与 Robert Watson 在 freebsd-arch 邮件列表 1999-2000 年关于 jail 设计的讨论；man **jail(2)** 与 **jail(8)** 历次版本；Robert Watson “Jails on FreeBSD”（2001 BSDCon 论文）；freebsd.duckdb freebsd-src 仓库 commits 表 jail 首次 commit 为 1999-04-28T11:28:49Z Poul-Henning Kamp（commit 02daf150a4434305b9181b0ac9150762afb4c8ce，subject = “Add the jail system call.”），同日 11:38:52 提交完整实现（commit 75c13541908625d7ee0894cc03f96ab773f7dae2，subject = “This Implements the mumbled about ‘Jail’ feature.”），**sys/sys/jail.h** 与 **sys/kern/kern_jail.c** 同日首次引入 ［A］
  
**史观**：总纲第 10 条——动手者创造历史（原“边缘者贡献”系伪名目，按权威表正名）：jail 设计影响后续 Linux 容器、Solaris Zones（2004）、illumos Zones；专题语（不设总纲条号）——形式与内容（原挂总纲第 17 条系自创名目，删条号）：jail 作为 “形式”（轻量级隔离原语）改变 “内容”（系统管理员可用的部署架构）
