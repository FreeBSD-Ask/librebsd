# 113.1.1 ULE 从 5.0 到 7.1 的六年演进

  **要点**：ULE 调度器由 Jeff Roberson 设计，2003 年 1 月 26 日首次提交（commit_hash = 35e6168fcdc76ba3ff2927279f9a48aa5ac3157d，committer_date = 2003-01-26T05:23:15Z，message_subject ="Add the ule scheduler. This is intended to be a general purpose process scheduler with many SMP benefits. It is still very experimental and should be used only in test environments."）并随 FreeBSD 5.0 引入作为实验性调度器，2008 年 12 月 31 日 7.1-RELEASE（release/7.1.0 tagger_date = 2008-12-31T22:57:14Z，tagger = Ken Smith，target_commit_hash = a1fc2b0c89a1dd2ca090ae990ab45b21363ab76e；官方公告日期为 2009 年 1 月 4 日）成为 amd64 与 i386 GENERIC 内核默认调度器，历时 6 年；演进包括 SMP 扩展优化、交互响应改进、公平性修复；7.0-RELEASE（release/7.0.0 tagger_date = 2008-02-24T05:45:17Z，tagger = cvs2svn，target_commit_hash = ba209d619d07461cc752dcdd596ab0d9b50e847a；官方公告日期为 2008 年 2 月 27 日）ULE 2.0 已大幅改进但 4BSD 仍为默认，7.0 公告明确"ULE scheduler is vastly improved...the 4BSD scheduler is still the default for 7.0 but ULE may become the default for 7.1"

**史观**：实践先于理论，ULE 的 6 年演进是工程实践驱动的而非理论预设
  
**辨析**：ULE 是否真比 4BSD 优越，需查基准测试；6 年成熟期是否过长；7.0 与 7.1 对 ULE 状态的表述差异；经 freebsd.duckdb tags 表验证，7.0-RELEASE 的 tagger_date 为 2008-02-24T05:45:17Z（cvs2svn 创建 tag），7.1-RELEASE 的 tagger_date 为 2008-12-31T22:57:14Z（Ken Smith 创建 tag），二者均为 SVN tag 创建时间而非官方公告时间；FreeBSD 官方公告日期通常晚于 tag 创建日期数日（7.0 公告为 2008-02-27，7.1 公告为 2009-01-04），叙事中须明确区分“tag 创建时间”与“公告发布时间”两类时间点；0 信任原则适用说明：L1.1.1 年度 commit 量基于 author_date 聚合，报告截断导致 2007-2009 年 freebsd-src 数据不可直接获取，L1.3.2 文件修改数为替代指标不等于 commit 量；L1.4.1 release tag 间隔报告截断，release/7.0.0 至 release/7.1.0 间隔从 tags 表 tagger_date 直接计算；L1.2.1 新增贡献者数基于 author_email 首次出现年份聚合，author 字段可伪造须与 committer 字段交叉验证；L1.2.1 统计覆盖 22 个仓库（含 linux-kernel/xnu/illumos-gate），freebsd-src 单仓库新增贡献者数可能低于此数值
