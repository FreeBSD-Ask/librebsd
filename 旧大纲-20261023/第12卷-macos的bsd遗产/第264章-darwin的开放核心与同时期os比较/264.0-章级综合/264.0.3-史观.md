# 264.0.3 史观

- 总纲第 6 条——主体性与和解：Mac OS X、FreeBSD 4.x、Linux 2.4、Windows XP 共享 Unix/POSIX 哲学根基而发展出不同桌面主体性（据 241.1）。
- 总纲第 11 条——商品是形式主义：Darwin “开放核心” 商品是 Apple 商品战略的形式主义运作，“劣币驱逐良币” 显现为以最低限度的开源换取最大限度的商业利益（据 241.2.1）。
- 总纲第 13 条——法律与道德是利益分配：APSL 2.0 通过 FSF 法律标准但被 FSF 建议不发布新软件，法律层面达成合图而道德层面分歧不可调和（据 241.2.2）。
- 总纲第 19 条——解释学循环是历史认识的根本条件：FSF 与 Apple 前理解差异使分歧不可避免，APSL 历史书写中记录什么、遗忘什么本身就是权力行使（据 241.2.3）。
- 专题语（不设条号）：第 11、13、19 条共时审视构成 APSL 争议的 “三重形式主义结构”——物质基础（商品）、制度表达（法律）、认识论条件（解释学）（据 241.2.4）。
