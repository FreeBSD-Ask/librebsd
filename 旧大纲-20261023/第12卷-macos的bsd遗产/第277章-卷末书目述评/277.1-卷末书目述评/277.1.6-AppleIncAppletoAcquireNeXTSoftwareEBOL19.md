# 277.1.6 AppleIncAppletoAcquireNeXTSoftwareEBOL19

### 一手史料

- **Apple Inc. Apple to Acquire NeXT Software [EB/OL]. (1996-12-20). Apple Press Release.**
Apple 于 1996 年 12 月 20 日发布的收购 NeXT 新闻稿，与 Apple 1997 财年 Form 10-K 向 SEC 披露的交易条款（约 4.29 亿美元、150 万股 Apple 股票、Jobs 回归任 iCEO）互参，构成 NeXTSTEP BSD/Mach 工程遗产转移至 Apple 的法律起点。该新闻稿叙事集中于“下一代操作系统”与“Jobs 回归”，对 BSD 层只字未提，本身即“隐形 BSD 基石”史观的典型文本。
- **NeXT Computer, Sun Microsystems. OpenStep Specification [Z]. 1994.**
NeXT 与 Sun 1994 年联合发布的 OpenStep 规范原文，含 Foundation、App Kit、Display PostScript、Distributed Objects API 定义。规范将 NeXTSTEP 上层 API 抽象为跨平台标准，可在 Solaris、Windows NT、NeXTSTEP 上实现，但底层 BSD 接口仍保留。此规范是后续 Yellow Box/Cocoa 与 Darwin 开放核心的法律前提，须与 Stanford University Library NeXT Inc. Records M1412 档案互参。
- **Apple Inc. Mac OS X Server 1.0 Release Notes [EB/OL]. (1999-03-16). Apple Developer.**
Mac OS 史上首次内建完整 BSD 环境的发布说明，基于 Rhapsody 5.3 内核，含 BSD 子系统、NetBoot、QuickTime Streaming Server、Apache 1.3.x 集成说明。Server 1.0 的 BSD 用户空间源自 NeXTSTEP 的 4.3BSD 派生代码，非 FreeBSD 3.x 派生，须与 Singh《Mac OS X Internals》及 Darwin 源码仓库交叉验证。
- **Apple Public Source License 1.0/1.1/1.2/2.0 [EB/OL]. (1999-2003). <https://opensource.apple.com/apsl/>.**
APSL 各版本原文，覆盖 Darwin 开源的许可证演进。APSL 1.0（1999-03）因三大致命缺陷遭 FSF 否定，1.1（1999）、1.2（2001-01）逐步修订，2.0（2003-08-06）经 Ernest Prabhakar 提交 OSI 认证并获 FSF 认可为自由软件许可证。Apple 律师与 FSF 协作修订许可证的法律协作过程，须与 FSF 立场声明、OSI license-discuss 邮件列表存档互参。
- **Apple Inc. WWDC 1997-2024 Technical Sessions [EB/OL]. (1997-2024). Apple Developer. <https://developer.apple.com/videos/>.（访问日期 2026-07-30）**
Apple 全球开发者大会技术会议档案，含 Rhapsody 架构（1997）、Yellow Box/Blue Box（1997）、Carbon 与 Cocoa 路线图（1998）、Mac OS X Roadmap（1998）、Spotlight（2005）、Intel 转移（2005）、DTrace（2007）、Snow Leopard 性能（2009）、Gatekeeper（2012）、Apple Silicon 转移（2020）等技术披露。WWDC 档案是 Apple 自身对其 BSD/Mach 内核演进的最系统官方叙述。【2026-07-30 联网核查：Apple Developer WWDC 档案 `developer.apple.com/videos/` 经 WebFetch 检索可访问，访问日期 2026-07-30，URL 稳定——详 `03-原始史料库/06-考据记录/20260730_jianyi缺口补全考据.md` §9ad】
- **Apple Open Source. Darwin Source Releases [EB/OL]. <https://opensource.apple.com/>.**
Darwin 源码仓库，含 Darwin 1.x 至 24.x 各版本源码包、CREDITS 文件与发布记录。Apple 以 release tag 形式发布 XNU 快照而非逐 commit 镜像内部 Git 历史，使 XNU 公开源码 first_commit 集中于 2003-08-08，此发布机制使个人贡献者被“文件级聚合”遮蔽，是 Darwin 开源社区运作方式考据的核心数字史料。
- **NeXT Software. WebObjects 1.0 Release Notes [EB/OL]. (1995-12). NeXT Developer Documentation.**
WebObjects 1.0 发布说明，含基于 Objective-C 的应用服务器架构与 BSD socket 依托说明。WebObjects 是 NeXT 退出硬件业务后转向软件与服务市场的核心产品，其商业化成功是 Apple 1996 年收购 NeXT 的双因估值基础之一，须与 Apple 收购公告与 1997 Form 10-K 交叉验证。
- **Stanford University Library. NeXT Inc. Records, 1985-1996 [Z]. M1412.**
斯坦福大学图书馆特藏部 NeXT 公司档案全宗，含工程文档、邮件列表存档、内部备忘录、工程组织架构图。该档案保留了 Mike Parkhill（BSD VFS 层移植）、Doug McCallum（BSD 网络栈适配）、Peter Lipson（Mach/BSD 桥接层）等低公开度 NeXT 工程师的贡献记录，是纠正“Apple 品牌中心叙事”的关键边缘者史料，需现场查阅。

### 二手研究

- **Singh A. Mac OS X Internals: A Systems Approach [M]. Boston: Addison-Wesley, 2006. ISBN 0-321-36645-0.**
macOS/Darwin 内核架构的权威剖析专著，含 XNU（Mach 3.0 + BSD 层 + IOKit）三层交互机制、Darwin 社区与 Apple 工程师结构、Yellow Box/Blue Box 架构演进的系统陈述。Singh 以代码级深度解读 XNU 的 BSD 层源自 NeXTSTEP 的 4.3BSD 派生而非 FreeBSD，纠正“XNU 源自 FreeBSD”的常见误读，是本卷最核心的二手技术文献。
- **Free Software Foundation. The Problems with older versions of the Apple Public Source License (APSL)[EB/OL]. <https://www.gnu.org/philosophy/historical-apsl.html>.**
FSF 对 APSL 1.0/1.1/1.2 的立场声明，含三大致命缺陷（隐私使用须公开源码、Apple 中央控制、可随时撤销）的具体法律分析。该声明直接推动 Apple 修订许可证，是 APSL 1.x 到 2.0 演进的当事人一方叙述，须与 Apple 的法律协作回应及 OSI license-discuss 邮件列表存档交叉验证，避免单方立场偏差。
- **Free Software Foundation. FSF Opinion of the Apple Public Source License (APSL) 2.0 [EB/OL]. <https://www.gnu.org/philosophy/apsl.html>.**
FSF 对 APSL 2.0 的正式立场声明，明确表述 Apple 律师与 FSF 协作修订许可证的过程，并指出两项实践问题（非真正 copyleft、与 GPL 不兼容）。该声明揭示 Darwin 开源的许可证哲学张力——Apple 通过法律协作获得 FSF 认可，但 copyleft 不彻底使 Darwin 仍可被闭源商品化。
- **Open Source Initiative. OSI License List: Apple Public Source License 2.0 [EB/OL]. <https://opensource.org/licenses/apsl-2.0.php>.**
OSI 对 APSL 2.0 的认证记录，对应 Ernest Prabhakar 2003 年 8 月 6 日向 license-discuss 邮件列表提交的认证申请。OSI 认证使 APSL 2.0 正式进入 OSI 批准许可证清单，是 Darwin 开源社区合法化的关键制度节点，须与 FSF 立场声明互参以呈现开源运动两大组织对同一许可证的差异化评价。
- **TrustedBSD Project. MAC Framework Documentation [EB/OL]. <https://www.trustedbsd.org/>.（访问日期 2026-07-30）**
Robert Watson 主持的 TrustedBSD 项目文档，含 MAC（Mandatory Access Control）框架的设计与 FreeBSD 5.0（2003-01-19）首次引入说明。MAC 框架是 Apple Tiger（10.4，2005）ACL 引入与 El Capitan（10.11，2015）SIP 系统完整性保护的上游参照，揭示 macOS 安全模型的 FreeBSD 学术谱系，构成 BSD 到 macOS 单向流动的核心案例。【2026-07-30 联网核查：TrustedBSD Project `trustedbsd.org` 经 WebFetch 检索可访问，包含 MAC Framework 文档，访问日期 2026-07-30——详 `03-原始史料库/06-考据记录/20260730_jianyi缺口补全考据.md` §9ae】
- **KAME Project [EB/OL]. <https://www.kame.net/>.（访问日期 2026-07-30）**
日本 WIDE 项目主持的 IPv6/IPsec 实现文档，含 KAME 项目 1998 年启动与 2000 年合入 FreeBSD 4.0 的说明。KAME 是 Jaguar（10.2，2002）IPv6 实现的上游来源，是 BSD 学术研究经 FreeBSD 进入 macOS 的另一关键路径，须与 FreeBSD 4.0 Release Notes 及 Apple Mac OS X 10.2 Release Notes 交叉验证。【2026-07-30 联网核查：KAME Project `kame.net` 经联网核查已不再更新但历史快照可访问，访问日期 2026-07-30——详 `03-原始史料库/06-考据记录/20260730_jianyi缺口补全考据.md` §9ae】
- **Leventhal A H. Mac OS X and the missing probes [EB/OL]. (2008-01-18). <https://www.dtrace.org/blogs/ahl/2008/01/18/mac-os-x-and-the-missing-probes/>.**
Apple 工程师 Adam Leventhal（DTrace 共同作者）对 Mac OS X Leopard DTrace 实现缺陷的反思，揭示 Apple 在引入 CDDL 许可的 DTrace 时为商业利益修改原实现的工程妥协。该文是 Apple 消费式开源——开源上游代码但闭源商业修改——的当事人自述，须与 Sun OpenSolaris DTrace 源码及 Apple 开源仓库 dtrace 目录互参。

CMU Mach 项目组 1986 年发表的奠基性论文，作者含 Tevanian（后任 NeXT 与 Apple 软件工程副总裁）与 Rashid（后任 Microsoft Research 副总裁）。论文系统陈述 Mach 微内核的 IPC、虚拟内存、任务线程模型，是 NeXTSTEP 与 XNU 内核设计的直接学术来源，揭示 macOS 的 Mach 微内核谱系可追溯至 CMU 1985-1994 年 DARPA 资助研究。

### 工具书与参考

- **The Open Group. Single UNIX Specification v3/v4 [EB/OL]. <https://www.opengroup.org/susv3/>.**
SUSv3/SUSv4 规范，为 macOS 自 Leopard（10.5，2007-10-26）起获 UNIX 03 认证的合规标准参照。须明确区分 macOS 持证与 FreeBSD 不持证——FreeBSD 仓库虽实现 POSIX 兼容但未向 Open Group 申请认证，此区分是本卷合规认证叙事的核心史观，避免模糊表述。
