macOS 的 BSD 遗产是当代计算史中一段“隐形的基石”叙事：BSD 代码与 Mach 微内核经由 NeXT（1985 年创立）进入 Apple（1996 年收购），最终以 Darwin 开源（1999 年）与 Mac OS X 桌面化（2001 年）面向公众，却长期被“Apple 品牌中心叙事”所遮蔽。本卷十七章所处理的，正是这一“隐形”的展开过程——从 NeXTSTEP 0.9 基于 4.3BSD-Tahoe 的工程选型，经 OPENSTEP 跨平台抽象、Rhapsody 与 XNU 成形、Darwin 以 APSL 开源、Mac OS X 10.0-10.3 用户空间奠基、Tiger/Leopard 的 UNIX 03 认证、Snow Leopard 的 GCD 并发抽象、Lion 至 El Capitan 的沙盒与 SIP 收紧、Sierra 至 Catalina 的 APFS 与 64 位过渡、Big Sur 至 Sequoia 的 Apple Silicon 转型，直至嵌入式 Darwin 扩散至 iOS/iPadOS/watchOS/tvOS/visionOS 全系设备。
这一谱系的史学意义在于：它揭示了 BSD 代码如何在“非 BSD 品牌”的商业操作系统中获得最大规模的部署，又如何在“开放核心 + 品牌控制”策略下被重新定义其“开放”的边界。与 FreeBSD、NetBSD、OpenBSD 等“以 BSD 为名”的项目不同，macOS 的 BSD 层始终处于“既承袭又改写”的张力之中——承袭体现在 4.3BSD/4.4BSD 与 FreeBSD 用户空间的代码流动，改写体现在 Mach 3.0 微内核的混入、APSL 许可证的中央控制条款、以及 Apple Silicon 期对 BSD 层 ARM64 适配的闭源化处理。
本综述围绕三条相互交织的线索展开：其一，史料谱系——Apple 官方档案、NeXT 时期档案、许可证法律文书三大支柱如何分工又如何相互制约；其二，学术论争——Darwin 开源程度、macOS 用户空间的 BSD 归属、iOS 的 Darwin 派生性质三项争议如何在 FSF/OSI/Apple 三方叙事与代码级证据之间展开；其三，方法论反思——面对 Apple 以 release tag 形式发布 XNU 快照而非逐 commit 镜像内部 Git 历史的发布机制，史家如何处理“文件级聚合”对个人贡献者的遮蔽，以及如何在“Apple 品牌中心叙事”与“边缘者贡献”之间维持平衡的叙事立场。
