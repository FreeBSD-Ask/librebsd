# 271.2.2 外部贡献者与 APSL 2.0 流程

**要点**：此期 Darwin 开源仍经 **APSL 2.0 许可证**（**2003 年 8 月 6 日** 起），独立开发者贡献网络与安全补丁。freebsd.duckdb 查询显示 **2016-2019 年** 间 freebsd-src 仓库中 message_subject 含“From Apple”/“From Darwin”的 commit 数量较低（延续 2010 年后的“低密度回馈”特征），主要涉及 Apple HFS 分区、Apple Mac codec ID 与少量 Apple 开发者工具补丁（**Pedro F. Giffuni** 的 6 条 commit 至 **2014 年** 结束）。此期 FreeBSD 端的 Apple 相关 commit 以硬件支持为主，而非用户空间代码回馈。

  | APSL 2.0 流程要素 | 内容 |
  | --- | --- |
  | 许可证生效日 | 2003-08-06 |
  | 独立开发者贡献类型 | 网络补丁、安全补丁 |
  | Apple 相关 commit 主题 | “From Apple”/“From Darwin” |
  | 主要内容 | Apple HFS 分区、Apple Mac codec ID |
  | Pedro F. Giffuni 贡献 | 6 条 commit（至 2014 年结束） |

  > 2016-2019 年间 FreeBSD 端的 Apple 相关 commit 以硬件支持为主，Apple 向 FreeBSD 回馈用户空间代码为辅——此即“低密度回馈”特征在 Sierra-Catalina 期的延续。
**史料**：freebsd.duckdb 查询结果（freebsd-src 仓库 message_subject 含“From Apple”/“From Darwin”的 commit，2016-2019 年）；Apple Open Source. Darwin Source Releases [EB/OL]. <https://opensource.apple.com/releases/>（xnu-4903 系列对应 macOS 10.15 Catalina）。〔L1 代码/构建产物〕

**史观**：总纲第 10 条——边缘者贡献被中心叙事遮蔽。此期 Apple 对 FreeBSD 的直接代码回馈仍然有限，FreeBSD 端的 Apple 相关 commit 以硬件支持为主——此即 q.md“局外人姿态”的具体显现：FreeBSD 社区为 Apple 硬件提供支持，但此支持不进入 Apple 的“主线叙事”。

**辨析**：2016-2019 年间 Apple 与 FreeBSD 的代码交流是否“双向”——darwin.duckdb 显示 FreeBSD 端的 Apple 相关 commit 以硬件支持为主（FreeBSD→Apple 硬件适配），而 Apple→FreeBSD 的用户空间代码回馈较少。采信“此期代码交流以 FreeBSD 适配 Apple 硬件为主，Apple 向 FreeBSD 回馈用户空间代码为辅”的判断。
