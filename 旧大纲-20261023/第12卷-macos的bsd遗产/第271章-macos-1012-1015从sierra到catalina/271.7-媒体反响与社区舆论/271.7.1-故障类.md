### 新闻条目 1

- **新闻标题（中英）**：Asahi Linux project begins Apple Silicon port / Asahi Linux 项目启动 Apple Silicon 移植
- **新闻来源**：Asahi Linux 官方博客 + 2021-01-25 + <https://asahilinux.org/2021/01/initial-hello-world/> + 存档：<https://web.archive.org/web/2021/https://asahilinux.org/2021/01/initial-hello-world/>
- **新闻摘要**：Asahi Linux 项目由 Hector Martin（marcan）于 2021 年 1 月启动，目标是逆向工程 Apple Silicon Mac 的启动协议与硬件接口，将 Linux 原生移植至 M1 Mac。Asahi Linux 是首个在 Apple Silicon Mac 上原生运行的 Linux 发行版。项目通过逆向 m1n1 引导加载器与 U-Boot 移植，逐步攻克 Apple Silicon 的设备树、GPU 驱动、显示驱动、网络驱动、电源管理。Asahi Linux 的工作间接影响 BSD 项目：逆向所得的 Apple Silicon 硬件文档（如 AIC 中断控制器、ASC 协处理器、SMC 系统管理控制器）为 BSD 移植提供参考。2022-03 Asahi Linux Alpha 发布，2025-12 支持 Linux Kernel 6.18，覆盖 M1/M2/M3 系列。Asahi Linux 的成果使 BSD 社区重新评估 Apple Silicon 原生支持的可能性。
- **与本章主题的关联说明**：本条目（Asahi Linux 项目启动，2021-01）属 2020-2024 年 Apple Silicon 时代事件，超出本章 macOS 10.12-10.15（2016-2019）时段；与本章主题仅存在远期延伸关联（Apple Silicon 硬件文档逆向对 BSD 移植的参考价值），非本章时段内媒体舆论。条目移至对应章节涉跨文件迁移，已登记 DEFERRED 待主代理处置。
