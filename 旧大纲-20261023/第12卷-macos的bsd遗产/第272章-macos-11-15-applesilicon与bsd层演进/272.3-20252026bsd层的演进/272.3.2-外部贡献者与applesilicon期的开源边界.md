# 272.3.2 外部贡献者与 Apple Silicon 期的开源边界

**要点**：Apple Silicon 期的 Darwin 开源仍经 **APSL 2.0 许可证**，独立开发者与 FreeBSD 社区维持单向/双向代码交流。freebsd.duckdb 查询显示 **2021-2024 年** freebsd-src 仓库中 author_email 含 apple.com 的 commit 有 **6 条**（来自 **Cosimo Cecchi** 3 条、**Yann Kerherve** 3 条），主要涉及 HFS 分区支持与 Mac codec ID——此数据延续 2018-2024 年的 “低密度回馈” 特征。**Asahi Linux 项目**（由 **Hector Martin** 主持，**2021 年** 起）在 Apple Silicon Mac 上移植 Linux，此项目逆向工程了 Apple Silicon Mac 的启动流程与硬件接口，间接显示了 Apple Silicon Mac 的 BSD 层（Darwin）与硬件的协同细节。

**史观**：总纲第 10 条——动手者创造历史。Asahi Linux 项目的 Hector Martin 是 Darwin 谱系中的 “边缘者”——他的贡献不进入 Apple 的 “主线叙事”，但通过逆向工程 Apple Silicon Mac 的硬件接口，间接验证了 Darwin BSD 层在 ARM64 上的实现细节。此即 q.md “局外人姿态” 的具体显现：Hector Martin 作为 Linux 社区的 “局外人” 逆向工程 Darwin，其工作显示了 Apple 官方未公开的 BSD 层与硬件协同细节。

**辨析**：Asahi Linux 项目是否 “帮助” 了 Darwin——Asahi Linux 的目标是移植 Linux 而非改进 Darwin，但其逆向工程工作间接显示了 Darwin 的硬件适配细节。Apple 未公开承认参考 Asahi Linux 的工作，故采信 “Asahi Linux 间接显示 Darwin 实现细节，但未直接贡献 Darwin 代码” 的判断。
