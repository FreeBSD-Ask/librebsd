- **新闻摘要**：Apple 于 2017 年 4 月在 GitHub 建立 darwin-xnu 仓库镜像，将原本仅通过 opensource.apple.com 发布的 XNU 内核源码同步至 GitHub，便于开发者社区参与。XNU 是 Darwin 操作系统的内核，是 “XNU is Not Unix” 的递归缩写，由 Mach 微内核、BSD 层与 I/O Kit 驱动框架组成。GitHub 仓库建立后，开发者可直接通过 Pull Request 提交补丁。仓库持续更新至 2021-07-07（xnu-7195.121.3），此后标记为 Public archive（公开归档），不再接受新提交。仓库共 123 个 Tag、123 个 Commit。

### 新闻条目 3

- **新闻标题（中英）**：PureDarwin project continues Darwin OS development / PureDarwin 项目持续 Darwin 操作系统开发
- **新闻来源**：PureDarwin 官方网站 + 持续维护 + <https://www.puredarwin.org/> + 存档：<https://web.archive.org/web/2024/https://www.puredarwin.org/>
- **新闻摘要**：PureDarwin 是社区项目，目标是基于 Apple 公开的 Darwin 源码构建可独立运行的 Darwin 操作系统，不依赖 macOS 专有组件。截至 2024 年项目仍活跃维护，但开发进度较慢，主要通过社区贡献推进。最新版本为 PD-17.4 Test Build，基于 Darwin 17（对应 macOS High Sierra 10.13.x），是最小系统，以 VMDK 虚拟机磁盘格式分发，须通过 QEMU 运行。由于缺乏 macOS 专有组件，网络驱动与硬件支持不完整。项目正在开发 PureDarwin Native SDK 与修改版 XNU 内核。2024-11-03 项目宣布 “A New Direction” 新方向，2026-01-03 发布纪念已故贡献者 Cliff Sekel 的文章。
