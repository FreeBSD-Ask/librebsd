# 261.1.1 OpenStep 规范的底层 BSD 抽象

**要点**：**OpenStep 规范** 由 **NeXT** 与 **Sun Microsystems** 于 **1994 年** 联合发布，是一组面向对象的 API 规范（**Foundation** + **App Kit** + **Display PostScript** + **Distributed Objects**），与具体实现解耦。OpenStep 规范的核心设计是将应用框架（Foundation/AppKit）与底层操作系统解耦——在 NeXT、Sun Solaris、Windows NT 上的实现共享同一套上层 API，但底层的 BSD 服务（POSIX、BSD socket）由各平台桥接层提供。**NeXT 版**（OpenStep/Mach）仍直接调用 **4.3BSD 派生代码**（NeXTSTEP 时期的 BSD 层），**Sun 版**（Solaris OpenStep）调用 Solaris 的 SVR4/BSD 兼容层，**Windows NT 版**（OpenStep Enterprise）调用 Win32 的 POSIX 子系统。OpenStep 规范的 “BSD 共性” 仅限于 API 层面——底层在不同平台由不同机制实现，须避免将 “API 兼容” 误读为 “代码同源”。

  | 实现版本 | 上层 API | 底层 BSD 服务提供者 | 代码同源性 |
  | --- | --- | --- | --- |
  | OpenStep/Mach（NeXT） | Foundation/AppKit | 4.3BSD 派生（NeXTSTEP BSD 层） | 同源 |
  | Solaris OpenStep | Foundation/AppKit | SVR4/BSD 兼容层 | 独立实现 |
  | OpenStep Enterprise | Foundation/AppKit | Win32 POSIX 子系统 | 独立实现 |

  > OpenStep 规范明确将应用框架与底层操作系统解耦，此即 NeXT/Sun 所称 “独立于操作系统的面向对象应用框架”——API 是统一的，实现是分化的。

**史观**：总纲第 13 条——法律与道德是利益分配。OpenStep 规范的授权安排决定其跨平台可移植性——许可证条款即跨平台利益分配的界面，此即 q.md “自由的张力”〔源文本引语，非总纲条号〕的具体显现：NeXT 通过将 NeXTSTEP 抽象为 OpenStep 规范，使其应用框架可在 Sun Solaris 与 Windows NT 上运行，此跨平台策略是 NeXT 退出硬件业务后转向软件授权的商业选择。q.md “道与术的辩证” 在此显现：OpenStep 规范是 “道”（API 设计哲学），各平台的桥接层实现是 “术”（工程实现），二者并行但分属不同层面。

**辨析**：OpenStep 的 “BSD 共性”——OpenStep 规范定义的是 API 层面（POSIX、BSD socket 等系统服务接口），非底层代码同源。NeXT 版（OpenStep/Mach）的底层是 NeXTSTEP 的 4.3BSD 派生代码，Sun 版（Solaris OpenStep）的底层是 Solaris 的 SVR4/BSD 兼容层，Windows NT 版（OpenStep Enterprise）的底层是 Win32 的 POSIX 子系统。采信 “OpenStep 的‘BSD 共性’仅限于 API 层面，底层在不同平台由不同机制实现，非代码同源” 的判断。OpenStep 规范与 NeXTSTEP 的关系——OpenStep 规范是从 NeXTSTEP 的 API 抽象而来，NeXTSTEP 是 OpenStep 规范的首个实现（OpenStep/Mach），但 OpenStep 规范的设计使其可在非 NeXTSTEP 平台上实现。【0 信任原则·XNU 快照发布局限】darwin.duckdb 查询 L7.5.1 数据无法直接反映 1994-1995 年 OpenStep 规范制定时期的 BSD 层状态，XNU 快照 first_commit 均为 2003-08-08，OpenStep 跨平台 BSD 共性须以 OpenStep 规范原文与 NeXT/Sun 合作档案为准。【统计结论 C-41 整合】统计结论 [C-41] references 表总数 16,867 条——OpenStep 时期（1994-1997）的 BSD 谱系学术文献在 references 表中有对应积累，但 NeXT 仓库不在 darwin.duckdb 中，本时期无直接 BSD commit 数据可查（数据局限性继承自描述性统计.md 数据局限性总述）；0 信任原则提示：references 表文献数量反映学术关注度，不直接等同于 OpenStep 跨平台实现的工程影响，且 1994-1997 年具体文献量须以 references 表按年份精确查询为准。
