# 032.3.1 vi 谱系的现代延续：vim、neovim 与 vi 克隆

**要点**：vi 的模态设计自 1978 年 2BSD 发布以来持续影响现代编辑器生态，形成 “vi 谱系” 的漫长演化链——**vim**（Bram Moolenaar 1988 年在 Amiga 上开始开发，**1991 年 11 月** 首次公开发布 Vim 1.14 于 Fred Fish Disk #591，最初名为 “Vi IMitation”，**1992 年** Vim 1.22 移植到 UNIX/MS-DOS 后更名为 “Vi IMproved”）、**elvis**（Steve Kirkendall **1990 年** 开发，**1992 年** 被引入 BSD 用作 AT&T vi 代码移除后的临时替代）、**nvi**（Keith Bostic（基思·博斯蒂克） **1994 年** 为 4.4BSD-Lite 基于 elvis 1.8 重写）、**Neovim**（Thiago de Arruda **2014 年** 发起，fork Vim 代码库以 “aggressively refactor” 为目标，首版 v0.1.0 于 **2015 年 11 月 1 日** 由 justinmk 在 GitHub 打标签发布，仓库 <https://github.com/neovim/neovim>）；Neovim 的 fork 缘起于 Moolenaar 拒绝 De Arruda 提交的大型多线程补丁，De Arruda 遂 fork Vim 代码库另立项目，旨在简化维护、分割开发工作、启用基于 coprocess 的新插件架构、移除遗留平台支持与 Vi 兼容模式（`nocompatible` 成为 no-op）；Neovim 保留 Vimscript 兼容性但引入 Lua 作为首选扩展语言，内置 tree-sitter 解析器、LSP 客户端与现代 GUI 解耦架构

**史料**：Neovim GitHub 仓库（<https://github.com/neovim/neovim>，访问日期 2026-07-28，v0.1.0 标签日期 2015-11-01T21:16:53Z，标签者 justinmk，commit c4826c3）；Neovim 官方 Introduction Wiki（<https://github.com/neovim/neovim/wiki/Introduction>，访问日期 2026-07-28，引文 "Neovim is a project that seeks to aggressively refactor Vim source code“、”this is not a project to rewrite Vim fromscratch“、”Vi emulation will also be removed (setting nocompatible will be a no-op)"）；Neovim 官方 vim_diff 文档（<https://neovim.io/doc/user/vim_diff.html>，访问日期 2026-07-28）；Moolenaar, B. (1991) Vim 1.14 首次公开发布（Fred Fish Disk #591）；Bostic, K. (1994) nvi for 4.4BSD-Lite；Kirkendall, S. (1990) elvis editor ［A］

**史观**：第 4 条分离与聚合——vi 谱系在演化中既分离（vim、elvis、nvi、Neovim 各自独立发展）又聚合（均保留 vi 模态编辑核心）；第 2 条实践先于理论——Neovim 的 fork 缘起于具体的补丁拒绝事件而非理论分歧，体现实践冲突驱动技术演化；第 1 条偶然性——Moolenaar 拒绝 De Arruda 的补丁是偶然事件，但此偶然事件催生了 Neovim 这一持续影响现代编辑器生态的项目，“Vi IMitation” 更名为 “Vi IMproved” 亦体现命名的偶然性
