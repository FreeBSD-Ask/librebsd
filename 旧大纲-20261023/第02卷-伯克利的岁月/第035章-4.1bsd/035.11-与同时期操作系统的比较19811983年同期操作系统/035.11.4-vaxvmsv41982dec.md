# 035.11.4 VAX/VMS V4（1982，DEC）

**要点**：VMS（Virtual Memory System）是 DEC 为 VAX-11 系列大型/超级小型机开发的原生操作系统，V4（约 1982）时期与 4.1BSD 同期运行在同一 VAX 硬件上；VMS 由 Dave Cutler 团队主导，强调工程稳定性、集群（VAXcluster）与企业特性，与 BSD 在 VAX 平台上形成直接的 “原生系统 vs 研究 UNIX” 路线之争。

**史料**：DEC VAX/VMS V4 技术手册与发布说明（约 1982）［A］；Cutler 后续访谈与《Inside Windows NT》旁证其哲学 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］

**史观**：技术路线分化：VMS 与 BSD 在同一硬件（VAX）上竞争，VMS 走封闭工程化路线、BSD 走开放研究路线，这一对照是理解 1980 年代操作系统哲学分裂的关键案例。

**辨析**：VMS 并非 “击败” BSD——在科研/学术/网络服务领域 BSD 占优，在企业/集群/关键业务领域 VMS 占优；两者长期并存，VMS 的影响经 Cutler 延续至 Windows NT。
