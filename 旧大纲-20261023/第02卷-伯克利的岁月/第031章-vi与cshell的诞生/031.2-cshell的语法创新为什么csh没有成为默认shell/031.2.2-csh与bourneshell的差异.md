# 031.2.2 csh 与 Bourne Shell 的差异

**要点**：**csh** 与 **Bourne Shell**（sh，Stephen Bourne 开发）在语法结构（C 风格 vs ALGOL 风格）、交互功能（csh 有历史/别名/作业控制，sh 无）、脚本可移植性（sh 更通用）等方面存在根本差异；Bourne Shell 开发始于 1975 年末/1976 年初，1979 年随 V7 UNIX 正式发布，csh 1978 年开发、随 2BSD 1978 年中发布，二者开发时间重叠但发布时间 csh 略早于 V7

| 维度 | C Shell（csh） | Bourne Shell（sh） |
| -- | ------------ | ---------------- |
| 作者 | Bill Joy（伯克利） | Stephen Bourne（Bell Labs） |
| 开发时间 | 1978 年 | 1975 年末/1976 年初 |
| 首次发布 | 2BSD（1978 年中） | V7 UNIX（1979 年） |
| 语法风格 | C 风格 | ALGOL 风格 |
| 历史替换（`!`） | 有 | 无 |
| 别名机制（`alias`） | 有 | 无 |
| 作业控制（`jobs`/`bg`/`fg`） | 有 | 无 |
| 波浪号（`~`）主目录 | 有 | 无 |
| 脚本可移植性 | 差 | 好 |
| 适用场景 | 交互式 | 脚本式 |

**史料**：csh 与 sh 源代码对比、Bourne 的 shell 设计文档、USENIX 会议论文、V7 UNIX 发布记录 ［A］

**史观**：第 6 条技术路线分化——csh 与 sh 的分化代表了交互式与脚本式两条技术路线的分野

**辨析**：Bourne Shell 的开发始于 1975 年末/1976 年初，正式发布为 1979 年 V7 UNIX，~~先前 1977/1978 年的说法不准确~~（修正：经核实开发始于 **1975 年末/1976 年初**，1979 年随 V7 发布）；Bourne Shell 与 csh 开发同期但独立进行，不存在一方直接影响另一方的证据
