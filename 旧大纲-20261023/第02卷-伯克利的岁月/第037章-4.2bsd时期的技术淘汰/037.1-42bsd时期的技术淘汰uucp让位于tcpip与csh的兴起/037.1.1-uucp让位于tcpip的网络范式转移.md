# 037.1.1 UUCP 让位于 TCP/IP 的网络范式转移

**要点**：UUCP（Unix-to-Unix Copy Program）由 Mike Lesk 于 1976 年在 Bell Labs 开发，1977 年随 V7 进入标准 UNIX 发行，是 1970 年代后期至 1980 年代早期 UNIX 机器间文件传输与邮件中继的事实标准；4.2BSD（1983 年 8 月）首次将 DARPA 资助的 TCP/IP 协议栈与 socket API 完整集成入 base system，标志网络范式从 UUCP 的“存储-转发”（store-and-forward）拨号模式转向 TCP/IP 的“实时双向”模式；1986 年 NNTP 协议在 UUCP 之上开发（San Diego 与 Berkeley 之间首次连接），1990 年代早期 UUCP 仍是 Usenet 新闻传输主干，至 1990 年代中期被 TCP/IP 上的 NNTP/HTTP/SMTP 全面取代；UUCP 至今仍作为传统协议在 BSD/UNIX 中保留（FreeBSD base 中保留 **uucp(1)**、**uux(1)**、**uucico(8)**），但实际部署规模已边缘化

| 维度 | UUCP | TCP/IP |
| -- | -- | ---- |
| 引入时间 | 1976（Bell Labs，Mike Lesk） | 4.2BSD（1983.8） |
| 网络模式 | 存储-转发（store-and-forward） | 实时双向（分组交换） |
| 连接方式 | 拨号 | 持久连接 |
| 典型应用 | 邮件中继、Usenet 新闻 | 互联网协议 |
| 退出主流 | 1990 年代中期 | 至今主导 |

**史料**：Lesk 1976“A (Maybe) Optimum Hierarchic File System Design”Bell Labs 内部备忘录、UUCP V7 手册、4.2BSD Release Notes (1983.8) TCP/IP 章节、Spencer & Lawrence 1986“Managing UUCP and Usenet”McGraw-Hill、Quarterman & Hoskins 1986 CACM“Computer Networks of the World”对 UUCP 与 ARPANET 并存状态的描述 ［A］

**史观**：技术路线分化：UUCP（拨号、存储-转发）与 TCP/IP（实时、分组交换）形成 1980 年代 UNIX 网络的双轨；信息技术：网络协议的演化反映信息技术自身的范式转移

**辨析**：UUCP 在 1990 年代后才真正退出主流，“4.2BSD 取代 UUCP”的叙事应理解为“开启取代进程”而非“完成取代”；4.2BSD 的 TCP/IP 实现选择 Joy 自写版本而非 BBN 版本，这一选择对后续 BSD 网络栈影响深远，需考据 DARPA 测试报告
