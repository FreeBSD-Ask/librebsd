### 新闻条目 1

- **新闻标题（中英）**：《UNIX 二十五年》（A Quarter Century of UNIX，Peter H. Salus（彼得·H·萨卢斯） 著，1994 年 Addison-Wesley 出版，4.2BSD 章节）
- **新闻来源**：Peter H. Salus，《A Quarter Century of UNIX》，1994 年 Addison-Wesley 出版，ISBN 0-201-54777-5
- **URL**：项目考据记录 **03-原始史料库/06-考据记录/20260724_salus-quarter-century-unix.md**
- **存档 URL**：项目考据记录已存
- **新闻摘要**：Salus 1994 年著作详述 4.2BSD 里程碑意义：4.2BSD 是 BSD 历史上最重要的版本之一，引入 Berkeley Fast File System (FFS)、socket API、TCP/IP 协议栈、进程组、可靠信号等关键特性；4.2BSD 在 18 个月内签发 1000+ 站点许可证，超过此前所有 BSD 分发总和；大多数 Unix 厂商选择 4.2BSD 而非 AT&T System V，因为 System V 既无网络也无 Berkeley Fast File System；BSD 在商业 Unix 市场的主导地位仅维持数年，随着网络与 4.2BSD 改进被整合入 System V 后，厂商通常转回 System V，但后续 BSD 开发持续被整合入 System V。
- **与本章主题的关联说明**：为本章 4.2BSD 叙事提供独立学者视角的旁证，确认 4.2BSD 里程碑地位（FFS、socket、TCP/IP）、商业成功（1000+ 站点许可证）、对 Unix 厂商选择的影响。
- **与官方史料的交叉验证结论**：与 McKusick 1999 Open Sources 章节（条目 1）对 4.2BSD 里程碑地位与 1000+ 站点许可证描述一致；与 Leffler ACM Queue 采访（条目 3）对 4.2BSD 网络栈影响描述一致。
