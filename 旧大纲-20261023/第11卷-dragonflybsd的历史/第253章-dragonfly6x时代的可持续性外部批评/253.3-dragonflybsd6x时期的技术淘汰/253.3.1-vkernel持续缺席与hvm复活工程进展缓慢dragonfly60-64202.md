# 253.3.1 vkernel 持续缺席与 HVM 复活工程进展缓慢（DragonFly 6.0-6.4，2021-2025）

**要点**：DragonFly 6.0（2021-05-07，v6.0.0 tagger_date）因 VM 系统重大改造移除 MAP_VPAGETABLE mmap() 特性（commit 4d4f84f5），**vkernel(7)** 随之不可用；Girr 工单 #3389 跟踪其恢复进展，UPDATING 对此次移除无专门记载。dragonfly.duckdb 显示 6.x 时期（2021-05-07 后）message_subject 含 ‘vkernel’ 的 commit 仅 13 条（2021-06-25 至 2026-04-14），均为维护性工作而非 vkernel 本身的复活；message_subject 含 ‘HVM’ 的 commit 仅 1 条（2021-07-11T22:44:28+08:00），反映 HVM（Hardware Virtual Machine）复活工程实际推进幅度极低。截至 2026-07-22 vkernel 仍未恢复，DragonFly-on-DragonFly 虚拟化需依赖外部 hypervisor（bhyve/KVM/Xen）。vkernel 与 HVM 在 6.x 时期 commit 对照如下：
