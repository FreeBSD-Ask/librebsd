# 246.2.1 HAMMER 2 开发周期的史实基础——设计文档演化与发布时序考据

**要点**：HAMMER 2 的开发周期经 DragonFly BSD 官方 hammer 页面与 release notes 一手核验，呈现为“设计阶段（2012-2017）—实验性发布（2017.10）—生产可用（2019.06）”三阶段序列。DragonFly BSD 官方 hammer 页面（dragonflybsd.org/hammer/）记载 HAMMER2 设计文档共经历六次大修订——HAMMER2 Design v1（2012-02-08）、v2（2013-05-14）、v3（2015-04-03）、v4（2016-07-09）、v5（2017-07-24）、v6（2018-12-08），反映设计在七年间的持续演化；DragonFly 5.0.0（2017-10-16）release notes 明确记载"Preliminary HAMMER2 support has been released into the wild as-of the 5.0 release. This support is considered EXPERIMENTAL and should generally not yet be used for production machines and important data"——HAMMER2 首次可启动但被官方标记为实验性；DragonFly 5.6.0（2019-06-17）release notes 记载 HAMMER2 成为默认文件系统（仍为选项），dragonfly.duckdb dragonfly-src 仓库 tags 表 v5.6.0 tagger_date 核验发布时点；dragonfly.duckdb 显示 HAMMER2 关键词 commit 2011 = 2、2012 = 273（峰值）、2013 = 81、2014 = 48、2015 = 86，sys/vfs/hammer2/ 目录 distinct commit 2012 = 101、2014 = 29、2015 = 75，反映 HAMMER 2 在 2012 年达 commit 峰值后投入持续但非线性的工程演进。DragonFly 4.0.0（2014-11-23）release notes 经一手核验未将 HAMMER2 列为 big-ticket items——4.0 时期 HAMMER2 代码已在仓库中但未达到发布标准，原大纲 98.3“4.0 引入 HAMMER 2 文件系统”的表述须辨析为“4.0 时期 HAMMER2 代码已在仓库中但未作为生产可用文件系统发布”。HAMMER 2 从设计文档 v1（2012-02）到生产可用（2019-06）共约 7 年 4 个月，从 DragonFly 3.0（2012-01-22）设计讨论启动到 5.6（2019-06-17）成为默认文件系统共约 7 年 5 个月

**史料**：DragonFly BSD 官方 hammer 页面（dragonflybsd.org/hammer/）HAMMER2 设计文档 v1-v6 链接与日期（v1 = 2012-02-08、v2 = 2013-05-14、v3 = 2015-04-03、v4 = 2016-07-09、v5 = 2017-07-24、v6 = 2018-12-08）；DragonFly 5.0.0 release notes（dragonflybsd.org/release50）“Preliminary HAMMER2 support...EXPERIMENTAL”原文；DragonFly 5.6.0 release notes（dragonflybsd.org/release56）HAMMER2 成为默认文件系统记载；dragonfly.duckdb dragonfly-src 仓库 tags 表 v5.0.0/v5.6.0 tagger_date；dragonfly.duckdb dragonfly-src 仓库 commits 表 HAMMER2 关键词按年（2011 = 2、2012 = 273、2013 = 81、2014 = 48、2015 = 86）；dragonfly.duckdb dragonfly-src 仓库 commit_files 表 sys/vfs/hammer2/ 目录 distinct commit 按年（2012 = 101、2014 = 29、2015 = 75）；DragonFly 4.0.0 release notes（dragonflybsd.org/release40）big-ticket items 经一手核验未列 HAMMER2；dragonfly.duckdb dragonfly-src 仓库 tags 表 v4.0.0 tagger_date = 2014-11-23T19:54:13-05:00 ［A］

**史观**：软件工程：dragonfly.duckdb 数据与 HAMMER2 设计文档版本序列共同呈现 HAMMER 2 开发的工程节奏——2012 年 commit 峰值（273 条）反映设计转入实现的工程动员，2013-2015 年 commit 量下降（81/48/86）反映实现期的持续投入，2017 年实验性发布与 2019 年生产可用反映“先设计后实现、先实验后生产”的渐进工程哲学；总纲第 25 条——终结与延续：DragonFly 5.0 release notes 明确标记 HAMMER2 为“EXPERIMENTAL”是 0 信任原则下的官方承认——HAMMER2 在 2017 年时尚未达到生产可用，release notes 较事后叙事更为可靠
