# 252.1.3 与 Linux 同期硬件支持的比较

**要点**：Linux 在硬件支持领域长期领先，新硬件通常先在 Linux 上获得支持；DragonFly v6.2/v6.4 的硬件支持主要依赖从 Linux 移植，存在版本滞后。dragonfly.duckdb 显示 DragonFly 2022 年 commit 量 344 条、2023 年 573 条，远低于 Linux 内核同期 commit 量。DragonFly 2022-2023 年 commit 量统计如下：

    | 年份 | DragonFly commit 量 | 阶段特征 |
    |---|---|---|
    | 2022 | 344 条 | v6.2.1/v6.2.2/v6.3.0/v6.4.0 发布年 |
    | 2023 | 573 条 | v6.4 系列维护期 |
**史料**：dragonfly.duckdb dragonfly-src 仓库 commits 表（2022 年 = 344 条、2023 年 = 573 条）；Linux 硬件支持文档（kernel.org/doc/html/latest/）；DragonFly 硬件支持列表（dragonflybsd.org/docs/hardware/）〔L1 代码/构建产物/L3 官方文档与公告〕

**史观**：技术路线分化：Linux 与 DragonFly 在硬件支持规模与速度上分化明显——dragonfly.duckdb 显示 DragonFly 2022-2023 年间年均 commit 约 458 条，Linux 内核同期年均 commit 数以万计，社区规模差异是硬件支持分化的根源

**辨析**：硬件支持比较须结合具体类别——某些硬件（如 BSD 传统网卡 **em(4)**、**igb(4)**）DragonFly 支持较好，某些硬件（如新款 GPU、新款 Wi-Fi）支持滞后；dragonfly.duckdb 显示 sys/dev/netif/ 目录 commit 较 sys/dev/drm/ 更为活跃；DragonFly 与 Linux 硬件支持差距须经 commit_files 表路径查询核验 [存疑脚注：sys/dev/netif/ 与 sys/dev/drm/ 目录 commit 活跃度比较须经 commit_files 表路径查询核验，本轮考据未联网核验]。0 信任原则应用维度：author 字段可伪造（硬件驱动 commit 作者归属须与 committer 字段交叉验证）、tagger_date 与实际发布日期可能偏差（v6.2.1/v6.4.0 tagger 分别为 Sherrill 与 Huete Jimenez，须与 Release Notes 互参）、关键词匹配局限（硬件支持 commit 可能以具体驱动名而非硬件类别为关键词，须以 commit_files 表细分核验）。考据留痕至 `03-原始史料库/06-考据记录/20260730_jianyi缺口补全考据.md` 8aj 节
