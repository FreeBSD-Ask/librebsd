# 247.2.3 OpenBSD 5.x（2012-2014）

**要点**：openbsd.duckdb 显示 openbsd-src 仓库 2012 年 commit 量 5221 条、2013 年 6888 条、2014 年 10907 条（年均约 7672 条），约为 DragonFly 3.x 同期年均（2598 条）的 3.1 倍。OpenBSD 在 DragonFly 3.x 同期为 5.x（5.2 = 2012-11-01、5.3 = 2013-05-01、5.4 = 2013-11-01、5.5 = 2014-05-01、5.6 = 2014-11-01［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 须以 OpenBSD 官方 release notes 核验），以安全与 FFS/softraid 简洁著称，未自研新 FS——OpenBSD 5.x 坚持简单可信 FS，DragonFly 3.x 探索复杂 CoW HAMMER2（2012 年 273 条 HAMMER2 commit 峰值），体现目标分化

**史料**：openbsd.duckdb commits 表 openbsd-src 仓库 2012-2014 年 commit 量（2012 = 5221、2013 = 6888、2014 = 10907）；dragonfly.duckdb dragonfly-src 仓库 commits 表 HAMMER2 关键词 2012 年 273 条；OpenBSD 5.x release notes；DragonFly 3.x HAMMER2 设计文档〔L1 代码/构建产物/L3 官方文档与公告〕

**史观**：总纲第 4 条——分离聚合是永恒规律：dragonfly.duckdb 数据显示 OpenBSD 的 “坚守 FFS/softraid” 路径与 DragonFly 的 “自研 HAMMER2” 路径是文件系统技术路线分化的典型——OpenBSD 2012-2014 年年均 7672 条 commit 反映其工程动员集中于安全审计而非新 FS 自研，DragonFly 同期年均 2598 条但押注 HAMMER2；总纲第 15 条——文化即形式主义：OpenBSD 的 de Raadt 主导治理使其可激进坚持 “简单可信” FS 哲学（拒绝 CoW 复杂度），DragonFly 的 Dillon 主导治理使其可激进坚持 “自研 CoW” FS 哲学——两种个人主导治理导向截然不同的 FS 路径
