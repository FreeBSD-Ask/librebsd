**史观**：边缘者贡献：2.x 周期网络栈漏洞修复由 Sepherosa Ziehau（ieee80211）、Hasso Tepper（IPv6 NDP、Intel G33）等核心开发者分担——Ziehau 与 Tepper 作为 DragonFly 网络栈维护者承担了网络层漏洞的主要响应工作，与 Avalos 承担 OpenSSL 响应形成分工，体现 small-team 项目中 “按子系统分工的安全响应” 模式

**辨析**：CVE-2008-2476 影响 IPv6 邻居发现协议（NDP），技术机制为未校验邻居发现消息来源——攻击者可借伪造消息篡改邻居缓存与转发信息库（FIB），导致拒绝服务（连接中断）或读取私有网络流量，并非远程代码执行；此漏洞影响 FreeBSD 6.3-7.1、OpenBSD 4.2/4.3、NetBSD 等多种 IPv6 实现；CVE-2008-1447 DNS cache poisoning（Kaminsky 漏洞）是 2008 年最重大的 DNS 安全事件，影响所有 DNS resolver——DragonFly 通过 BIND 9.3.5-P1 升级修复；CVE-2008-3831 系 i915 DRM 驱动未将 DRM_I915_HWS_ADDR ioctl 限制于 DRM master，本地用户可借构造的 ioctl 调用致拒绝服务（内存破坏）——commit 自述仅影响 Intel G33 系列及更新芯片组，范围有限 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］
