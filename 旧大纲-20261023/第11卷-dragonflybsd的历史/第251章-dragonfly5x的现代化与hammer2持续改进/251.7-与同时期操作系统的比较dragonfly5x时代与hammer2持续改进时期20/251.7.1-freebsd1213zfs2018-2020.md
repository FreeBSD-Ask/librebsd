# 251.7.1 FreeBSD 12/13（ZFS，2018-2020）

**要点**：freebsd.duckdb 显示 2018-2020 年间 freebsd-src 仓库年均 commit 量约 14487 条（2018 = 14985、2019 = 14273、2020 = 14203），dragonfly-src 仓库年均约 1752 条（2018 = 1709、2019 = 1962、2020 = 1585），FreeBSD 是 DragonFly 的 8.3 倍。FreeBSD 12.0（2018-12-11 发布）引入 OpenZFS 整合与 ZFS 引导改进，13.0（2021-04-13 发布）改进 ZFS 加密；DragonFly 5.x 同期打磨自研 HAMMER2（dragonfly.duckdb 显示 2018-2019 年 HAMMER2 关键词 commit 共 231 条），两者存储哲学持续分化——FreeBSD 上游 ZFS，DragonFly 自研 HAMMER2。FreeBSD 12/13 与 DragonFly 5.x 存储路线对照如下：

| 维度 | FreeBSD 12/13 | DragonFly 5.x |
|---|---|---|
| 文件系统 | OpenZFS（上游整合） | HAMMER2（自研） |
| 12.0/13.0 发布日 | 2018-12-11 / 2021-04-13 | — |
| 2018-2020 年均 commit | 14487 条 | 1752 条 |
| HAMMER2/ZFS commit | — | 231 条（2018-2019） |
| 路线 | 上游成熟方案 | 自研轻量级方案 |

**史料**：freebsd.duckdb commits 表（freebsd-src 2018-2020 年统计）；dragonfly.duckdb dragonfly-src 仓库 commits 表（dragonfly-src 2018-2020 年对照、HAMMER2 关键词 2018-2019 年统计）；FreeBSD 12.0/13.0 release notes；DragonFly 5.x HAMMER2 文档〔L1 代码/构建产物/L3 官方文档与公告〕

**史观**：总纲第 4 条——分离聚合是永恒规律：FreeBSD 与 DragonFly 在存储路线上持续分化——FreeBSD 12.x/13.x 时期 OpenZFS 整合属“采用上游成熟方案”，DragonFly 5.x 时期 HAMMER2 打磨属“自研轻量级方案”，两者投入方向不同；dragonfly.duckdb 显示 HAMMER2 关键词 commit 2018-2019 年共 231 条，反映 DragonFly 在自研路径上的持续投入

**辨析**：HAMMER2 的集群复制是 ZFS 之外特性，DragonFly 5.x 持续投入；dragonfly.duckdb 关键词搜索可能低估 HAMMER2 改进的实际 commit 量，须以 commit_files 表核验；FreeBSD 12.0/13.0 的 ZFS 改进 commit 量须单独统计
