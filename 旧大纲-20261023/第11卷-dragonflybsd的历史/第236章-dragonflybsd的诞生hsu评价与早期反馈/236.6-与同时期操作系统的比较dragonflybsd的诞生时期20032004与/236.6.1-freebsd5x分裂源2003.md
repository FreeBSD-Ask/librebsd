# 236.6.1 FreeBSD 5.x（分裂源，2003）

**要点**：DragonFly 由 Matt Dillon 于 2003-06-17 fork 自 FreeBSD 4.8-RELEASE（dragonfly.duckdb dragonfly-src 首 commit `984263bcb83a`，author_date = 2003-06-17T02:57:24Z，message_subject = “Initial import from FreeBSD RELENG_4”），因对 FreeBSD 5.x 的 SMPng（细粒度锁）路线不满、主张消息传递并发（LWKT，commit `8ad65e080342`，2003-06-20）。分叉是 BSD 家族 “代码自由流动 + 路线分叉” 的极端案例，直接源于并发哲学分歧

**史料**：dragonfly.duckdb dragonfly-src 仓库 commits 表首 commit = 984263bcb83a（2003-06-17T02:57:24Z, “Initial import from FreeBSD RELENG_4”）；dragonfly.duckdb dragonfly-src 仓库 commits 表 LWKT 首引 commit = 8ad65e080342（2003-06-20T02:09:59Z）；Dillon 2003.7.16 fork 公告邮件；FreeBSD 5.0-RELEASE release notes（2003-01-19）

**史观**：总纲第 4 条——分离聚合是永恒规律：DragonFly 自 FreeBSD 4.8 fork 是家族内路线分叉的典型——dragonfly.duckdb 显示 fork 首 commit 标题 “Initial import from FreeBSD RELENG_4” 明确基线选择，BSD 许可允许自由分叉是 fork 的法律前提

**辨析**：分叉非否定 FreeBSD，而是并发哲学分歧——freebsd.duckdb 显示 LWKT 首引（2003-06-20）距 fork 首 commit（2003-06-17）仅 2 天 19 小时 36 分钟，反映 Dillon 在 fork 前 4.5 个月（2003-01-28 末次 freebsd-src commit 至 2003-06-17 dragonfly-src 首 commit）已完成 LWKT 设计
