# 300.3.3 committer 协作的远程化转型

**要点**：**COVID-19** 期间 BSD committer 普遍转为远程工作，部分 committer 因家庭照护责任（如子女远程学习）提交频率下降，**Core Team** 通过 `phabricator` 与 `GitLab` 增强异步审查

  | 仓库类型 | 2020 年 commit 量 | 2020 年 contributors | 对比基准 |
  |---|---|---|---|
  | BSD 4 大 src 仓库合计 | 36,392〔存疑：实测口径 58,441，待复核〕 | 574 | L7.3.1 查询 |
  | Linux kernel | 90,911 | 4,864 | L7.3.1 查询 |
  | linux_to_bsd_ratio | 2.50（commit 倍率） | 8.47（contributors 倍率） | — |
**史料**：`freebsd-hackers` 邮件列表 2020-2021、`phabricator` 审查记录、committer 个人声明 ［A］；freebsd.duckdb 查询 L1.1.4 显示：**COVID-19** 期间（2020-2022）每季度 commit 量分布查询共返回 2206 行，涵盖 23 个仓库的季度 commit 数据，可用于识别远程协作对开发节奏的季节性影响（如 Q3 编程之夏高峰）；freebsd.duckdb 查询 L7.3.1 显示：2020 年 BSD 4 大 src 仓库合计 36,392 commit、574 contributors〔存疑：2026-09-12 四库按 author_date 实测为 58,441 条（freebsd-src 14,203＋netbsd-src 34,930＋openbsd-src 7,723＋dragonfly-src 1,585），与 36,392 相差约 22k，两口径必有一误——L7.3.1 或用不同仓库集合/日期字段/统计时点，待按原报告 SQL 复核后取一〕，Linux kernel 90,911 commit、4,864 contributors，linux_to_bsd_ratio 为 2.50，反映 **COVID-19** 首年 BSD 阵营开发活跃度仍维持量级

**史观**：总纲第 15 条——文化即形式主义〔映射存疑，待主理人审定〕，远程工作是疫情对 committer 协作的根本性重塑

**辨析**：committer 提交频率的下降幅度需通过 commit log 统计；0 信任原则局限标注：L1.1.4 查询基于 author_date 字段，但 git 的 author 字段可由提交者任意填写，分析 committer 归属时须与 committer 字段交叉验证；FreeBSD SVN-to-Git 迁移风险（2020 年迁移可能引入日期偏差）；commit 量仅反映开发活跃度，须结合 commit 规模（additions/deletions）与 message 质量综合判断，不可直接等同于代码质量或协作效率
