# 020.0.10 邮件列表史学观点（V2）

> 观点是提炼后的史实陈述，非原始邮件片段。

<!-- MAIL_INSIGHT: 2003-11-22 Interactivity scheduler tests and FreeBSD implementation -->
**观点**：2003 年 11 月 22 日，Kimmo Sundqvist 在 Linux 内核邮件列表上进行了 Linux 2.6 O(1) 调度器（Ingo Molnar）与 FreeBSD ULE 调度器（Jeff Roberson）的交互性测试比较。两者几乎同时开发，都旨在解决 SMP 系统上的调度器可扩展性问题。Linux 的 O(1)→CFS 演进和 FreeBSD 的 4BSD→ULE 演进代表了两种不同的设计哲学：Linux 追求公平性和交互性，FreeBSD 追求简单性和可预测性。
**邮件来源**：Kimmo Sundqvist，Linux Kernel Mailing List，2003-11-22，Message-ID: 2003-11-22 Interactivity scheduler tests and FreeBSD implementation
**史学意义**：调度器设计的跨项目讨论是 RISC 时代小型机终结后，BSD 与 Linux 在 SMP 多处理器架构上技术竞争的一个缩影。从 VAX 单处理器到 x86 SMP 多处理器再到 ARM 多核，调度器设计的演进反映了硬件架构变革对操作系统内核的深刻影响——RISC 战争虽然结束了小型机时代，但 SMP 可扩展性的挑战将调度器设计推向了新的技术前沿。
