# 008.3.3 介质费分发模式的具体运作

**要点**：大学许可证申请流程——大学填写申请表、签署保密协议、支付介质费、Bell Labs 通过 Western Electric 邮寄 9-track 磁带；磁带包含 UNIX 完整源代码与编译后的二进制；大学可自行修改但修改版本不得商业分发

**史料**：UNIX V6/V7 分发磁带（部分存于 TUHS）、Bell Labs 1976-1979 分发记录 [考据脚注：UNIX V6/V7 分发磁带、TUHS 存档等核心事实经 Salus 1994 与 TUHS 保存的 PDP-11 磁带镜像交叉验证确证。] 〔L1 代码 + L3 官方文档〕

**史观**：总纲第 23 条与第 24 条——社区治理与许可证：介质费模式催生早期学术 UNIX 社区

**辨析**：磁带分发的物理流程在不同来源中描述详略不一——部分大学收到磁带后无法立即安装需 Bell Labs 技术支持

**文献**：TUHS V6/V7 磁带档案；McIlroy 1986 AT&T Tech. Journal 对分发的描述 ［B］
