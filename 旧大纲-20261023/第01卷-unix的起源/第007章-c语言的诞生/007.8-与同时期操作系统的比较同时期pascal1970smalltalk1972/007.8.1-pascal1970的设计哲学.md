# 007.8.1 Pascal（1970）的设计哲学

**要点**：Niklaus Wirth 1970 年在苏黎世联邦理工发布 Pascal，目标为教学语言与结构化编程示范；Pascal 强调强类型、块结构、显式声明，与 C 的 “信任程序员” 形成对照；Pascal 后续演化出 Modula-2、Oberon 等分支

**史料**：Wirth 1971 “The Programming Language Pascal” (Acta Informatica)、Wirth 1974 “On the Design of Programming Languages” [考据脚注：Wirth 1971 Pascal 语言定义、1974 年设计反思等核心事实经 Wirth 1971 Acta Informatica 原文与 Wirth 1974 论文交叉验证确证。] 〔L5 学术论文〕

**史观**：技术路线分化：Pascal 与 C 选择截然不同的语言哲学

**辨析**：Pascal 的 “教学语言” 定位是否限制其工程应用——Wirth 本人在不同场合有不同表述

**文献**：Wirth 1971 Acta Informatica “The Programming Language Pascal”；Wirth 1974 “On the Design of Programming Languages” [考据脚注：Pascal 与 C 语言哲学对比经 Wirth 1971/1974 与 Ritchie 1993 HOPL II 交叉验证确证。]
