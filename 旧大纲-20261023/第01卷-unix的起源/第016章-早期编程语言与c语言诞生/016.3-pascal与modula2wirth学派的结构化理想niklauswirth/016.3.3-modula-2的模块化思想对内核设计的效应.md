# 016.3.3 Modula-2 的模块化思想对内核设计的效应

**要点**：Wirth 1977 年在《Software: Practice and Experience》第 7 卷第 1 期发表三篇期刊文章（"Modula: a Language for Modular Multiprogramming" 页 1-35、"The use of Modula" 页 37-65、"Design and Implementation of Modula" 页 67-84）发布 Modula 原版；随后发展为 Modula-2（1977-1979 年设计演进，引入模块化接口与实现分离）；1981 年首次生产使用 Modula-2；1982 年 Springer-Verlag 出版《Programming in Modula-2》（共出四版，即 PIM/PIM2/PIM3/PIM4）；Modula-2 的模块化思想对 BSD 内核设计的间接影响——虽未直接采用，但模块化理念与 BSD 内核子系统划分共鸣

**史观**：软件工程：模块化思想的间接影响

**辨析**：Modula-2 的时间节点——1977 年 Modula 原版发布（三篇论文同期发表）、1977-1979 年 Modula-2 设计演进、1981 年首次生产使用、1982 年《Programming in Modula-2》出版；原叙事 “Wirth 1978 年设计 Modula-2” 系粗略表述，实际 Modula-2 是 Modula 原版（1977）的演进版本；Modula-2 对 BSD 内核的具体影响——多为理念共鸣而非代码借鉴；Wirth 获得的是 1984 年 Turing Award（非 1985 年），演讲 《From Programming Language Design to Computer Construction》 发表于 1985 年
