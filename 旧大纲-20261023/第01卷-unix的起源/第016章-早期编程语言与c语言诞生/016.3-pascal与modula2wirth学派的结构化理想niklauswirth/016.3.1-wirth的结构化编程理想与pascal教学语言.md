# 016.3.1 Wirth 的结构化编程理想与 Pascal 教学语言

**要点**：Niklaus Wirth 1968-1969 年完成 Pascal 设计（Wirth 1979 年论文 《Recollections about the Development of Pascal》 明确 "was designed in the years 1968-1969"），1970 年初第一个 Pascal 编译器在 CDC 6000 上运行并同时发布语言定义；1971 年 3 月在《Acta Informatica》创刊号第 1 卷第 1 期第 35-63 页发表首篇论文 《The Programming Language Pascal》（DOI 10.1007/BF00264291）；同期 Wirth 1971 年 10/12 月在《Software: Practice and Experience》第 1 卷第 4 期第 309-333 页发表 《The design of a Pascal compiler》（DOI 10.1002/spe.4380010403）详细描述 CDC 6000 自编译编译器实现；Pascal 强调类型严格与块结构，影响后续教学语言（Modula-2、Oberon）与商业语言（Ada、Delphi）

**史料**：Wirth 1971 《The Programming Language Pascal》 (Acta Informatica Vol. 1 Issue 1, March 1971, pp. 35-63)、Wirth 1971 《The design of a Pascal compiler》 (Software: Practice and Experience Vol. 1 Issue 4, October/December 1971, pp. 309-333)、Wirth 1979 《Recollections about the Development of Pascal》（ACM SIGPLAN History of Programming Languages Conference）、Jensen & Wirth 1974 "Pascal User Manual and Report" [考据脚注·Wirth 1971 Pascal 编译器论文与 CDC 6000 关联的考据过程] 经三轮 WebSearch 与 WebFetch 核实：其一，Wiley Online Library DOI 页面（onlinelibrary.wiley.com/doi/10.1002/spe.4380010403，2026-07-28 WebFetch 核实）显示 Wirth 1971 "The design of a pascal compiler" 的元数据为 "Software: Practice and Experience, Volume 1, Issue 4, October/December 1971, Pages 309-333, DOI 10.1002/spe.4380010403"，作者单位为 "Eidgenössische Technische Hochschule, Zürich, Switzerland"；其二，Wiley 页面摘要明确记载 "The development of a compiler for the programming language PASCAL is described in some detail. Design decisions concerning the layout of program and data, the organization of the compiler including its syntax analyser, and the over-all approach to the project are discussed. The compiler is written in its own language and was implemented for the CDC 6000 computer family"——即论文全文（pp. 309-333，共 25 页）描述了 Pascal 编译器的开发细节，编译器用 Pascal 自身编写（自编译，self-compiling），在 CDC 6000 计算机系列上实现，论文讨论了程序与数据布局、编译器组织（含语法分析器）及整体项目方法；其三，论文参考文献第 8 条引用 "Control Data Corporation, SCOPE Reference Manual, Publication No. 60189400"——此为 CDC 6000 系列 SCOPE 操作系统的官方手册，印证编译器实现依赖 CDC 6000 的 SCOPE 操作系统环境；其四，论文参考文献第 1 条引用 Wirth 1971 "The programming language PASCAL" Acta Informatica 1, 35-63 (1971)，印证编译器论文与语言定义论文的配套关系——语言定义论文（pp. 35-63）定义 Pascal 语言的语法与语义，编译器论文（pp. 309-333）描述该语言的编译器实现，二者构成 Pascal 项目的语言定义与实现两个支柱；综上，CDC 6000 编译器事实与 Wirth 1971 Softw. Pract. Exper. 1(4): 309-333 论文的关联已确认——论文全文 25 页（309-333）描述 CDC 6000 自编译编译器的实现细节，论文摘要与参考文献第 8 条（SCOPE Reference Manual）共同印证 CDC 6000 平台依赖。 〔L5 学术论文 + L5 书籍〕

**史观**：软件工程：Pascal 推动结构化编程教学

**辨析**：Pascal 多个时间节点——1968-1969 年设计、1970 年初第一个编译器运行与语言定义发布、1971 年 3 月论文发表、1971 年末编译器论文发表、1974 年首本教材出版；不同来源引用不同节点导致 1968/1969/1970/1971/1974 多种说法并存；首版编译器目标平台为 CDC 6000 系列，编译器用 Pascal 自身编写（自编译），实现细节详见 Wirth 1971 《The design of a Pascal compiler》 论文 pp. 309-333 全文 25 页——其中程序与数据布局设计、编译器组织（含语法分析器）、整体项目方法为论文核心内容，CDC 6000 平台依赖经论文摘要与参考文献第 8 条（SCOPE Reference Manual）共同印证
