# 018.7.4 要点FreeBSD基本系统以C与shell为根本Ports层容纳多语言BSD选择

**要点**：FreeBSD 基本系统以 C 与 shell 为根本，Ports 层容纳多语言；BSD 选择 C 既因工程惯性，也因 UNIX 哲学 “做一件事并做好” 对语言简洁性的要求

**史料**：FreeBSD 源码树、freebsd-arch 邮件列表讨论 ［A］

**史观**：总纲第 3 条与第 23 条——形式主义膨胀与社区治理：BSD 对语言保守主义的坚守

**辨析**：BSD 语言保守主义不简单为 “优点” 或 “缺点”——以工程权衡论，C 语言的稳定性、可移植性、工具链成熟度为基本系统提供长期保障；以哲学选择论，“做一件事并做好” 对语言简洁性的要求与 C 语言的 32 关键字设计契合；价值判断须基于具体场景而非抽象立场

**文献**：FreeBSD Source Tree；freebsd-arch 邮件存档；McKusick et al.《Design of 4.4BSD》 (1996) ［A］
