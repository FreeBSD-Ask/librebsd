# 017.4.2 Python 在 FreeBSD 上的生态演进

**要点**：Guido van Rossum 1991 年 2 月 20 日在 Usenet 新闻组 alt.sources 发布 Python 0.9.0（van Rossum 本人在 gvanrossum.github.io "A Brief Timeline of Python" 中确认 "February 20, 1991 0.9.0 (released to alt.sources)"），项目起始于 1989 年 12 月（圣诞节假期个人业余项目），1990 年 CWI（Centrum Wiskunde & Informatica，荷兰国家数学与计算机科学研究所）内部发布，1991 年 2 月 20 日首度公开发布；Python 在 FreeBSD 上稳定运行，Ports 提供多版本（python2.7、python3.x）；Python 用于 FreeBSD 部分外围工具如 freebsd-update，但基本系统长期不以 Python 为必须依赖；**1999 年 8 月 van Rossum 向 DARPA 提交 "Computer Programming for Everybody"（CP4E）修订资助提案**（CNRI Proposal #90120-1a，PI: Guido van Rossum，Corporation for National Research Initiatives 1999 年 7 月），提出 “让每个计算机用户都能打开自己计算机的‘hood’（引擎盖）并改进其中的应用程序” 的愿景，DARPA 部分资助该项目（1999 年末启动，原计划两年但仅获首年资助至 2000 年 10 月），CP4E 项目产出包括 IDLE（Python's Interactive DeveLopment Environment）开发环境，但因 Python 开发团队转移至其他雇主而未能在 CNRI 完整完成

**史料**：van Rossum 1991-02-20 alt.sources Python 0.9.0 公告、gvanrossum.github.io "A Brief Timeline of Python"（2009-01-20 原发于 The History of Python 博客）、van Rossum 1999 "Computer Programming for Everybody" CNRI Proposal #90120-1a（python.org/doc/essays/cp4e/，2026-07-28 WebFetch 核实，含 van Rossum 本人的修订说明与 CNRI 提案编号）、FreeBSD Ports Python 类目 ［C］

**史观**：开源运动：Python 开源生态与 FreeBSD 共生；CP4E 项目体现总纲第 2 条 “实践先于理论”——van Rossum 并非从 “人人皆可编程” 的理论出发，而是从 Python 在 CWI 与 CNRI 的实际开发经验中归纳出此愿景，CP4E 是对既有实践的自反性理论化（总纲第 7 条）

**辨析**：FreeBSD 基本系统中 Python 的使用——基本系统长期保持 C 与 shell，Python 多用于外围工具与 Ports，需区分基本系统与 Ports；Python 公开发布日期常被笼统记为 “1991 年”，实际精确日期为 1991 年 2 月 20 日（van Rossum 本人时间线确认）；**CP4E 提案的两个版本与日期**——根据 python.org/doc/essays/cp4e/ 页面 van Rossum 本人说明（2026-07-28 WebFetch 核实），CNRI 于 1999 年 3 月收到 DARPA 接受通知，同年 8 月提交修订版提案（修订版日期标为 1999 年 7 月），工作于 1999 年末启动；CP4E 的实际影响有限——van Rossum 本人在页面中说明 "the move of the Python development team to other employers meant that we didn't get to complete the CP4E project at CNRI"，仅 IDLE 开发环境延续，其他目标由 EDU-SIG 邮件列表社区继续推进；[考据脚注·CP4E 提案的考据过程] 经三轮核实：其一，python.org/doc/essays/cp4e/ 页面（2026-07-28 WebFetch 核实）明确标注为 "Revised Proposal"、CNRI Proposal #90120-1a、1999 年 7 月，PI 为 Guido van Rossum；其二，van Rossum 本人在页面开头说明此为 "revised funding proposal that we sent to DARPA in August 1999"，并明确 "at least an earlier version of the proposal was accepted by DARPA" 在 1999 年 3 月；其三，CP4E 项目产出 IDLE 仍由 Python 社区维护（python.org/idle/），但 CP4E 作为整体项目 "now in limbo"（van Rossum 原话）
