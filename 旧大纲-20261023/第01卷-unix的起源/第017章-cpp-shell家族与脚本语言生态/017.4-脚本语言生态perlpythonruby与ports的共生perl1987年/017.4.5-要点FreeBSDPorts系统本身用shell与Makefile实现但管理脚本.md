# 017.4.5 要点FreeBSDPorts系统本身用shell与Makefile实现但管理脚本

**要点**：FreeBSD Ports 系统本身用 shell 与 Makefile 实现，但管理脚本语言包；Ports 提供分发渠道，脚本语言丰富 Ports 内容，二者相互促进

**史料**：FreeBSD Porter's Handbook、Ports Tree 历史变更 ［B］

**史观**：社区治理：Ports 系统作为社区治理的语言中立基础设施

**辨析**：Ports 系统的 “语言中立性”——实际偏向 C 与 shell，脚本语言为被管理对象

**文献**：FreeBSD Porter's Handbook；FreeBSD Ports Tree；FreeBSD Documentation ［B］
