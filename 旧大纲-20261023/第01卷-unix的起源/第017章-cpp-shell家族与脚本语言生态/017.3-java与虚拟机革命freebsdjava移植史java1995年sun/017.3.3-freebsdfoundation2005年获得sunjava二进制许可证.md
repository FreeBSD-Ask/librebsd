# 017.3.3 FreeBSD Foundation 2005 年获得 Sun Java 二进制许可证

**要点**：FreeBSD Foundation 2003 年 8 月 25 日（Boulder, CO）首次通过 Sun Community Source License (SCSL) 取得 Java 二进制分发权，同日公告 "Foundation Announces Native Support for JDK 1.3.1 on FreeBSD" 并发布首个 Java JDK/JRE 1.3.1 二进制（FreeBSD Foundation 官方公告与 freebsdfoundation.org/news-and-events/latest-news/august-2003-freebsd-jdk-and-jre-1-3-1-binary-distributions/ 存档可查），Core Team 成员 Wes Peters 称此举 "hallmarks a new era of Java support for FreeBSD"，Justin T. Gibbs（贾斯廷·T·吉布斯） 声明 Foundation 已将工作重心转向 1.4.X JDK；2004 年 12 月 21 日 Foundation Newsletter 披露 Sun 因统一 Java 收入模型向 Foundation 发出 SCSL 撤销通知，要求重新谈判（2005 年 1 月 5 日 InfoWorld Paul Krill 询问、2005 年 1 月 7 日 OSNews Eugenia Loli 报道、2005 年 1 月 10 日 Sunhelp.org Bill Bradford 转载、2005 年 1 月 12 日 UTC LWN "Sun yanks FreeBSD's Java license" 文章详细报道）；经多轮谈判，Foundation 与 Sun 在 2005-2006 年间重新签订协议；2006 年 4 月 5 日（PRWeb Boulder, Colo.）Foundation 正式公告 Sun JDK/JRE 1.5 二进制发布（即 Diablo JDK，基于 Sun JDK 1.5 Update 6 源码，已通过 Sun 全部认证测试），官方支持 FreeBSD 5.4 与 FreeBSD 6.0 的 i386 平台；Robert Watson（时任 Foundation 主席）声明将继续推进 5.5/6.1 与 amd64 认证，Deb Goodkin（德布·古德金）（Director of Operations）声明 OEM 可捆绑 Java 应用与 JRE/JDK 用于 FreeBSD 分发；主要维护者 Greg Lewis 表示 "official JRE and JDK binaries based on Sun's latest partner sources provide end-users and developers alike with confidence that they can use and create Java applications on FreeBSD with the same degree of portability, robustness and stability that they have come to expect from other supported operating systems" **FreeBSD Foundation Java 许可证时间线**：

**辨析**：“2005 年获得许可证” 的精确表述——2003-08-25 首次获得 SCSL 许可证并发布 1.3.1 二进制，2004-12-21 被撤销，2005-01 多方媒体报道，2006-04-05 重新达成协议并发布 1.5（Diablo）二进制；常被简化的 “2005 年获得” 实际跨越 2003-08-25 首次发布 1.3.1、2004-12-21 撤销通知、2005-01 媒体报道、2006-04-05 重新达成并发布 1.5 四个节点；当时主要维护者为 Greg Lewis 与 Kurt Miller 等；Diablo JDK 名称源自 Foundation 内部代号，与 SCSL 港口移植版本（基于初始 JDK 1.5 源码、无 Update 源码访问权）并行存在；经邮件列表库验证通过（freebsd-java，2005-01-05"FW: Sun revokes FreeBSD license for Java"，Message-ID `LOBBIFDAGNMAMLGJJCKNEEPBEPAA.tedm@toybox.placo.com`）：2005 年 1 月 Sun 撤销 SCSL 事件与 InfoWorld Paul Krill 询问在 freebsd-java 列表存有一手转发记录，正文“2004-12-21 撤销通知、2005-01 多方报道”时间线获邮件列表佐证
