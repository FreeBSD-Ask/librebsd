# 017.2.3 tcsh、bash、ksh、zsh：多 shell 生态与 Ports

**要点**：tcsh（TENEX C shell）由 Ken Greer 于 1981 年在 CMU 基于 TENEX 命令行特性开发，后经多名贡献者增强，提供命令补全、拼写纠正等增强功能，自 4.3BSD 起可通过 contrib/ 获取，后进入 FreeBSD Ports（shells/tcsh）；Bourne Again shell（bash）由 Brian Fox 于 1989 年为 GNU 项目开发，结合了 Bourne shell 脚本能力与 csh/ksh 交互特性，通过 FreeBSD Ports（shells/bash）提供；Korn shell（ksh）由 David Korn 于 1983 年在 Bell Labs 开发，为 Bourne shell 的超集且加入交互特性，FreeBSD 基本系统自［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 起包含兼容 POSIX 的 pdksh/mksh（shells/ksh）；Z shell（zsh）由 Paul Falstad 于 1990 年开发，功能最为丰富，通过 Ports（shells/zsh）提供；FreeBSD 基本系统长期以 sh（Bourne shell 衍生的 Almquist shell，即 ash/dash 祖先）为 /bin/sh，root 默认 shell；csh/tcsh 长期为 root 与普通用户的默认交互式 shell 选项

**辨析**：FreeBSD 默认 shell 历史——/bin/sh 长期为 Almquist shell（ash）的 FreeBSD 衍生版，而非 GNU bash；csh/tcsh 为交互式默认选项之一；bash 从未进入 FreeBSD 基本系统（因 GPL 许可证），需通过 Ports 安装
