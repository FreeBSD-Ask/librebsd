# 216.5.3 Beck/Flöter 的安全与网络贡献

**要点**：Bob Beck 是 OpenSSH 与 OpenSSL（后 LibreSSL）的长期贡献者，在 Heartbleed 后协调 LibreSSL fork（openbsd.duckdb 显示 beck 自 2014-04-14 起参与 OpenSSL 代码清理，commit af0b15b8442f 之前由 djm 提交 Heartbleed fix）；Reyk Flöter 是 relayd、snmpd、iked 等 OpenBSD 守护进程的开发者（relayd 由其与 Pierre-Yves Ritschard 于 2004-2006 年间开发，2006 年随 OpenBSD 4.1 发布；iked 即 OpenIKED 亦由其启动）；两人的贡献让 OpenBSD 在网络与安全领域占据独特地位

**史料**：openbsd.duckdb openbsd-src 仓库 Beck 的 OpenSSH/LibreSSL 相关 commit（2014-04-14 起 beck 移除 OpenSSL 引擎、2014-05-29 beck 定义 LIBRESSL_INTERNAL）、Flöter 的 relayd/snmpd/iked 相关 commit；misc@、tech@ 邮件列表中两人的发言（<https://marc.info/?l=openbsd-tech>）［A］

**史观**：边缘者贡献：Beck 与 Flöter 作为非显性贡献者——Beck 在 Heartbleed 后协调 LibreSSL fork（对外沟通与 dead code 清理），Flöter 开发 relayd、snmpd、iked 等网络服务，二者的贡献虽不如 de Raadt 显性但构成了 OpenBSD 安全与网络基础设施的关键组件

**辨析**：Flöter 的姓名拼写以 OpenBSD 官方 committer 名单为准——OpenBSD CVS 与 commit log 中使用“reyk”作为用户名，全名拼写为 Reyk Flöter；Beck 在 LibreSSL fork 中的角色以 openbsd.duckdb openbsd-src 仓库 2014-04 至 2014-07 的 commit 为准——beck 是 fork 的主要协调者（移除引擎、定义 LIBRESSL_INTERNAL），jsing 是 libressl 库初始代码的提交者（2014-07-12 commit b6553af36068“Initial version of libressl”）；需辨明的是，CARP 协议由 Ryan McBride 主设计（Michael Shalayeff、Marco Pfatschbacher、Markus Friedl 协助，见 OpenBSD FAQ 6.11 与 carp(4) 版权行“Copyright (c) 2003, Ryan McBride”），ldapd(8) 由 Martin Hedenfalk 编写（见 OpenBSD innovations 页 2010-05-31 入树记录），二者均非 Flöter 的工作——Flöter 的代表性成果是 relayd（与 Pierre-Yves Ritschard 共同开发）、snmpd、hostapd 与 OpenIKED（iked，2010-06-03 入树，验证方法：cvsweb.openbsd.org www/innovations.html 各条目入树日期与维护人记录）
