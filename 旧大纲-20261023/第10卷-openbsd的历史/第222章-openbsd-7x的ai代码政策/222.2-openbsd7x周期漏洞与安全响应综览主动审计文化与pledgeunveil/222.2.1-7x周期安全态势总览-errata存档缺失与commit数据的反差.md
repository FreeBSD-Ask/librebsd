# 222.2.1 7.x 周期安全态势总览——errata 存档缺失与 commit 数据的反差

**要点**：OpenBSD 7.x 周期（**2021 年 10 月 14 日** 7.0 发布至 **2026 年 7 月 22 日**）openbsd-src 仓库共出现 **60 条 CVE 相关 commit** 与 **10 条无 CVE 编号的安全修复 commit**，对应 **88 个去重 CVE**；CVSS v3.x 评分分布为 0 个 Critical、3 个 High（CVE-2024-1931、CVE-2024-7594、CVE-2024-8176，均为 7.5）、1 个 Medium（CVE-2024-8508，5.3）、84 个无评分——无评分比例高达 95.5%，远超 FreeBSD 14.x 周期的 91.6%，反映 OpenBSD commit message 较少显式引用 CVE 编号的工程习惯；**关键考据发现**：本地 errata 存档 `原材料/研究/bsd漏洞史/官方公告/openbsd-errata.md` 中 OpenBSD 7.0-7.9 全部 10 个版本均显示 “errata 条目数：0”，与 60 条 CVE commit 数据形成强烈反差——这一反差不代表 7.x 周期无漏洞修复，而是反映本地 errata 抓取工作流在 7.x 系列失效 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］；OpenBSD 不发布 FreeBSD 式的 Security Advisory（SA），而通过 errata patches 与 CVS commit 直接发布修复，这是 OpenBSD 与 FreeBSD 安全发布机制的根本差异

**史料**：**openbsd.duckdb** `commits` 表 openbsd-src 仓库 7.x 周期 CVE commit 查询：`SELECT count(*) FROM commits WHERE repo_name='openbsd-src' AND author_date>='2021-10-14' AND author_date<'2026-07-22' AND (message_subject LIKE '%CVE-%' OR message_body LIKE '%CVE-%')`；`原材料/研究/bsd漏洞史/版本周期/openbsd-7.x.md` 版本周期归档（2026-07-22 整理）；`原材料/研究/bsd漏洞史/官方公告/openbsd-errata.md` 本地 errata 存档 7.0-7.9 条目统计；OpenBSD 官方 errata 页面 `https://www.openbsd.org/errata70.html` 至 `errata79.html` ［A］

**史观**：总纲第 25 条——0 信任原则：7.x 周期 errata 存档缺失是 0 信任原则在数据驱动考据中的典型样本——本地 errata 存档显示 “0 条目” 不等于 “OpenBSD 7.x 无漏洞修复”，commit 数据已证明 60 条 CVE commit 的存在；任何单一数据源（无论是 errata 存档、commit 数据库还是 cvelistV5）都不能单独作为安全态势的判据，须多源交叉验证；OpenBSD 在 cvelistV5 中元数据较少（84 个 CVE 无 CVSS 评分），更须以本地 commit 存档为主、数据库为辅，这与 FreeBSD 14.x 周期以 SA 公告为主、数据库为辅的考据路径形成对照

**辨析**：**须严格区分** 三种数据源的可信度层级：① openbsd-src 仓库 commit 是最可信的一手史料（代码变更的直接记录）；② OpenBSD 官方 errata 页面是二一手史料（经发布的修复公告），但本地抓取存档可能失效；③ cvelistV5 元数据是三手史料（CVE 编号分配机构的记录），OpenBSD commit 不引用 CVE 编号时 cvelistV5 与 commit 的对应关系须人工建立；**与 FreeBSD 14.x 周期对比**：FreeBSD 14.x 周期发布 80 个 SA，OpenBSD 7.x 周期无 SA 仅有 errata patches 与 commit——这一差异不意味着 OpenBSD 安全态势更好或更差，而是两个项目安全发布机制的根本不同（FreeBSD 集中式 SA 披露 vs OpenBSD 分散式 errata + commit）；**CVSS 评分缺失的辨析**：84 个 CVE 无 CVSS 评分不代表这些漏洞不严重，而是 OpenBSD 修复时未同步上游 CVSS 评估，libexpat 系列 CVE 多数在上游有评分但本地未录入
