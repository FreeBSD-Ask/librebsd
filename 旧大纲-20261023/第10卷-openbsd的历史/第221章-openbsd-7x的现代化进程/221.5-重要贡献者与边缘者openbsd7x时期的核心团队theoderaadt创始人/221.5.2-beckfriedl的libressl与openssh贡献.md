# 221.5.2 Beck/Friedl 的 LibreSSL 与 OpenSSH 贡献

**要点**：Bob Beck 在 2014 年 Heartbleed 后主导 LibreSSL fork 与持续维护；Markus Friedl 持续维护 OpenSSH 协议实现与安全特性；两人的贡献让 OpenBSD 在 TLS 与 SSH 基础设施领域占据独特地位

**史料**：OpenBSD CVS commit log 中 Beck 的 LibreSSL commit、Friedl 的 OpenSSH commit（<https://cvsweb.openbsd.org/>）；misc@、tech@ 邮件列表中两人的发言；LibreSSL/OpenSSH 项目文档 ［A］

**史观**：边缘者贡献：Beck 与 Friedl 分别守护 TLS 与 SSH 两大互联网基础协议的 OpenBSD 实现——LibreSSL 从 OpenSSL fork 后由 Beck 持续维护，OpenSSH 从 SSH Communications Security fork 后由 Friedl 持续维护，二者的维护工作是 “边缘者守护全球基础设施” 的典型

**辨析**：Beck 在 LibreSSL 中的具体角色以 **openbsd.duckdb** openbsd-src 仓库 lib/libressl/ 路径下 Beck 的 commit 为准——LibreSSL 是团队成果（Beck、Joel Sing（乔尔·辛）、Theo de Raadt 等共同维护），Beck 为主要协调者；Friedl 在 OpenSSH 中的贡献边界以 usr.bin/ssh/ 路径下 Friedl 的 commit 为准——Friedl 负责协议实现与安全特性
