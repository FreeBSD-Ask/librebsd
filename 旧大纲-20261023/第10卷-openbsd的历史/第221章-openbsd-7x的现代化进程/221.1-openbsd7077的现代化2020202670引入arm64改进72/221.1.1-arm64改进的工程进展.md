# 221.1.1 ARM64 改进的工程进展

**要点**：OpenBSD 7.0（2021-10）将 arm64 提升为 Tier-1 平台；7.2-7.4 持续改进 ARM64 支持——包括树莓派 4/5、Apple Silicon（M1/M2）的实验性支持；ARM64 改进让 OpenBSD 在嵌入式与单板计算机市场获得存在感

  **OpenBSD 7.x 版本发布时间线**：

  | 版本 | 发布日期 | 关键特性 |
  | --- | --- | --- |
  | 7.0 | 2021-10-14 | arm64 提升为 Tier-1 平台 |
  | 7.1 | 2022-04 | unveil 设为默认、**malloc.c** 随机化 |
  | 7.2 | 2022-10 | Wayland 实验性支持、桌面改进 |
  | 7.3 | 2023-04 | malloc 自检、unveil 改进 |
  | 7.4 | 2023-10 | **iwx(4)** 无线驱动、多音频设备 |
  | 7.5 | 2024-05 | Raspberry Pi 5 支持 |
  | 7.6 | 2024-10 | unveil 路径规范化 |
  | 7.7 | 2025-05 | 持续安全改进 |

**史料**：OpenBSD 7.0-7.4 Release Notes arm64 部分；arm64 移植邮件列表；CVS commit log；openbsd.duckdb openbsd-src 仓库 commit `88549df51ff4`（2021-10-15T14:46:46Z deraadt，message "openbsd 7.0 release shipped with the (hopefully last) scp that uses RCP protocol"） ［A］

**史观**：总纲第 7 条——技术选择即政治选择：OpenBSD 将 arm64 提升为 Tier-1 平台是 ARM64 硬件市场普及背景下的政治选择——以 “主流架构必须支持” 为预设，将有限的工程资源投入 arm64 而非维护更多 Tier-2/Tier-3 平台，与 NetBSD “支持一切硬件” 的路线不同

**辨析**：Apple Silicon 支持的具体进度在 OpenBSD 7.2-7.4 Release Notes 中有记录——M1 实验性支持始于 7.2，M2 支持在 7.4 后逐步完善；arm64 Tier-1 的定义为 OpenBSD 平台支持政策文档所载——Tier-1 平台获得完整安装介质、二进制快照、长期维护承诺；经 openbsd.duckdb openbsd-src commits 表验证，OpenBSD 7.0 release 相关 commit 为 2021-10-15（“openbsd 7.0 release shipped with...”），与 7.0（2021.10）发布时间一致
