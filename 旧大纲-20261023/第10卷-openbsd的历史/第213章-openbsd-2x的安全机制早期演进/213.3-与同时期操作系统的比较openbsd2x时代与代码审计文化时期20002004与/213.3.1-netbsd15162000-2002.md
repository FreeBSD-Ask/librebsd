# 213.3.1 NetBSD 1.5/1.6（2000-2002）

**要点**：NetBSD 在 OpenBSD 2.x 同期为 1.5（2000）/1.6（2002），以多平台与代码整洁见长；与 OpenBSD 2.x 的“代码审计/安全第一”文化对照——NetBSD 1.x 重可移植与工程，OpenBSD 2.x 重安全审查，二者同源但优先级分野。

**史料**：NetBSD 1.5/1.6 发布说明；OpenBSD 2.x 发布说明（2001-2002）［B］

**史观**：总纲第 4 条——分离聚合是永恒规律：NetBSD 与 OpenBSD 同源于 4.4BSD-Lite，安全 vs 可移植文化分化。

**辨析**：NetBSD 1.x 的代码整洁文化为安全审计提供基础，但 OpenBSD 2.x 将审计制度化。

**文献**：NetBSD. 1.5/1.6 Release Notes [EB/OL]；OpenBSD. 2.x Release Notes [Z]. ［B］
