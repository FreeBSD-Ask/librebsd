# 213.3.2 FreeBSD 4.x/5.0（2000-2003）

**要点**：FreeBSD 在 OpenBSD 2.x 同期为 4.x（2000-2002）与 5.0（2003），以 x86 性能、Ports 与 SMPng 演进见长；与 OpenBSD 2.x 的安全文化对照——FreeBSD 4.x 重性能/兼容，OpenBSD 2.x 重代码审计，二者在 BSD 家族内目标分化。

**史料**：FreeBSD 4.x/5.0 发布史；freebsd.duckdb freebsd-src ［A］

**史观**：总纲第 4 条——分离聚合是永恒规律：FreeBSD 与 OpenBSD 同期演进，性能 vs 安全目标分化。

**辨析**：FreeBSD 4.x 的健壮性部分源自长期工程，但安全审计制度化由 OpenBSD 引领。

**文献**：FreeBSD. 4.x/5.0 Release Notes [EB/OL]；freebsd.duckdb freebsd-src [DB/OL]. ［A］
