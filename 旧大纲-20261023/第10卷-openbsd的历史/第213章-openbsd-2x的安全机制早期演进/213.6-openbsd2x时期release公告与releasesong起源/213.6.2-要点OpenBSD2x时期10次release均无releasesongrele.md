# 213.6.2 要点OpenBSD2x时期10次release均无releasesongrele

**要点**：OpenBSD 2.x 时期 10 次 release 均无 release song，release song 传统自 3.0（2001-12-01，“The Wizard of OS”）起方有；release song 的起源与 OpenBSD 的发行文化（CD 销售、海报传统）相关——de Raadt 将 release song 作为发行文化的形式主义化标记，使每次 release 不仅是技术发布，更是文化事件；2.x 时期 release song 的缺席反映 OpenBSD 早期以工程为主、文化为辅的取向，至 3.0 时期项目文化成熟后方引入 release song 传统

**史料**：OpenBSD 官网 release 页面 3.0（<https://www.openbsd.org/30.html>，记载 release song“The Wizard of OS”）；OpenBSD 邮件列表关于 release song 起源的讨论存档；OpenBSD Jumpstart 项目介绍 ［A］

**史观**：总纲第 15 条——文化即形式主义：release song 作为发行文化的形式主义化产物，将“6 个月发布周期”从工程节奏重构为文化节奏；总纲第 15 条——文化即形式主义：release song 成为 OpenBSD 社区文化的标志性资产，与 CD 销售海报传统共同构成发行文化

**辨析**：release song 起源的具体动机须考据——de Raadt 在 3.0 引入 release song 是个人决策还是团队讨论结果须以 OpenBSD misc@ 邮件列表 2001 年存档核验；release song 的创作流程（词曲作者、录制时间）须考据；2.x 时期 release song 缺席是否为“尚未引入”还是“曾尝试但未成稿”须考据

**文献**：OpenBSD 官网 3.0 release 页面 ［EB/OL］. <https://www.openbsd.org/30.html>；OpenBSD 邮件列表存档；OpenBSD Jumpstart 项目介绍 ［A］
