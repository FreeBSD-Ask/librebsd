# 220.3.2 文化即形式主义视角下的 LibreSSL fork 叙事与 RETGUARD 加固叙事

**要点**：从项目史观总纲第 15 条“文化即形式主义”审视，LibreSSL fork 叙事与 RETGUARD 加固叙事皆是形式主义化的传统——LibreSSL fork 的“许可证纯洁性”动机在形式主义化过程中被固化为 OpenBSD 项目意识形态的标志，fork 的工程动机（dead code 清理）与意识形态动机（ISC 许可证偏好）在形式主义化过程中被简化为单一叙事；RETGUARD 的“安全优先于性能”哲学在形式主义化过程中被固化为 OpenBSD 工程文化的核心，5-10% 的性能开销在形式主义化过程中被重构为“安全代价的必要支付”而非“工程折中的权衡成本”；文化即形式主义意味着 LibreSSL fork 与 RETGUARD 的“传统”并非自然传承而是权力运作的形式主义重构——什么被记录为“OpenBSD 安全创新”（如 LibreSSL fork、RETGUARD 引入）、什么被遗忘（如 fork 的生态成本、RETGUARD 的架构覆盖局限），本身就是权力行使；知音难觅同样适用于技术社区——OpenBSD 阵营以“工程自主”与“安全优先”为知音共识，OpenSSL 阵营以“生态完整”与“功能全面”为知音共识，二者知音网络不重叠，未被纳入对方知音网络的叙事即被形式主义地边缘化

**史料**：项目史观总纲第 15 条原文、LibreSSL fork 公告与 OpenBSD 阵营声明（fork 叙事的形式主义化产物）、RETGUARD 设计文档与 tech@ 邮件列表讨论（加固叙事的形式主义化产物）、OpenSSL 阵营对 LibreSSL 的批评（被边缘化的叙事）、RETGUARD 性能开销与架构覆盖局限的批评（被边缘化的叙事）

**史观**：总纲第 15 条——文化即形式主义：LibreSSL fork 叙事与 RETGUARD 加固叙事是形式主义化的传统，其“自然性”须被解构

**辨析**：文化即形式主义不意味着叙事是虚假的——LibreSSL fork 与 RETGUARD 在工程产出上具有实际效应（如 LibreSSL 的低 CVE 频率、RETGUARD 的 ROP 防护），但这一实际效应不否定其叙事的形式主义性质；【0 信任原则·叙事权力的维度】“OpenBSD 安全创新”叙事须被审视——谁在定义创新（OpenBSD 阵营）、谁的成本被遗忘（OpenSSL 阵营与下游应用维护者），本身就是权力行使；【0 信任原则·形式主义化的动态性】形式主义化是持续过程——LibreSSL fork 从 2014 年的工程回应演化为 2026 年的 OpenBSD 意识形态标志，RETGUARD 从 2018 年的编译时加固演化为 OpenBSD 安全哲学的核心象征，这一演化本身须被考据记录
