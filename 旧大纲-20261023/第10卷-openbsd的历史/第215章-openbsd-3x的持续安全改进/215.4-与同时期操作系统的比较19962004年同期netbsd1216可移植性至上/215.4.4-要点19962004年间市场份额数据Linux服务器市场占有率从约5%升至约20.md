# 215.4.4 要点19962004年间市场份额数据Linux服务器市场占有率从约5%升至约20

**要点**：1996-2004 年间市场份额数据——Linux 服务器市场占有率从约 5% 升至约 20%，FreeBSD 约 2%-3%，NetBSD 不足 0.5%，OpenBSD 不足 0.5%；Solaris 从约 30% 降至约 15%；BSD 整体被 Linux 挤压但 OpenBSD 在安全场景保持存在

**史料**：Netcraft Web Server Survey 1996-2004；IDC 服务器操作系统市场报告〔L5 二手研究〕

**史观**：总纲第 7 条——理论必须自反：本节引用的每一份市场份额统计（Netcraft 的 Web 服务器签名、IDC 的出货口径）都是特定测量方法的建构物——理论必须自反地承认：说“OpenBSD 不足 0.5%”之前，须先审视测量工具能否看见 OpenBSD 的典型部署（防火墙、VPN 网关等不经 Web 签名暴露的形态）。

**辨析**：OpenBSD 在防火墙场景的部署（如 pfSense 早期基于 m0n0wall）未被服务器市场报告统计；市场份额数据在不同调查中差异较大

**文献**：Netcraft Web Server Survey 1996-2004；IDC 服务器操作系统市场报告
