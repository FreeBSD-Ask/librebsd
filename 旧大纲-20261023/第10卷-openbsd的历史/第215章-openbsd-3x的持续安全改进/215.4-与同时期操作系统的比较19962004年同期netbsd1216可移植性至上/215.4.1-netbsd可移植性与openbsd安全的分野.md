# 215.4.1 NetBSD 可移植性与 OpenBSD 安全的分野

**要点**：NetBSD 1996-2004 年间专注跨平台移植（支持 30+ 平台），OpenBSD 专注安全审计；两项目从 NetBSD 1.1 fork 出发，至 2004 年在工程哲学上完全分化；NetBSD 与 OpenBSD 的分野反映 BSD 哲学的两条路径——“广度”与“深度”

**史料**：NetBSD 1.2-1.6 Release Notes；OpenBSD 1.0-3.6 Release Notes；两项目 CVS 源码对照 ［A］

**史观**：总纲第 21 条——革命与改革是历史方法论的分歧：NetBSD 选择“可移植性”、OpenBSD 选择“安全”，是同一 BSD 传统内部两条改进路径的方法论分歧——一方以渐进移植扩展自由软件的疆域，一方以激进审计重铸既有代码；两种路径无对错之分，却塑造了此后十年 BSD 阵营的分化格局。

**辨析**：两项目的“广度”与“深度”对比缺乏权威评估——需对照实际功能对比核验；两项目代码共享比例在 1996-2004 年间的下降曲线需考据

**文献**：NetBSD/OpenBSD Release Notes；CVS 源码对照 ［A］
