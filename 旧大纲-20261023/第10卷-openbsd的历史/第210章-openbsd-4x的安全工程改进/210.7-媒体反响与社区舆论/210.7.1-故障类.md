# 210.7.1 故障类


> 本子节汇总与本章主题相关的新闻报道与社区舆论，按“故障类 / 冲突类 / 里程碑事件类”三类组织。所有新闻条目遵循 0 信任原则，须与官方史料交叉验证后方可采信。

### 新闻条目 1

- **新闻标题（中英）**：Patches for OpenSSL bounds checking bug + heartbleed vs malloc.conf (updated)（OpenSSL 边界检查漏洞补丁 + Heartbleed 对 malloc.conf 影响）
- **新闻来源**：undeadly.org + 编辑署名 + 2014-04-08 / 2014-04-09 + URL: <https://undeadly.org/cgi?action=article;sid=20140408063423> + <https://undeadly.org/cgi?action=article;sid=20140409195016>- **新闻摘要**：undeadly.org 报道 2014-04-07 披露的 Heartbleed 漏洞（CVE-2014-0160），OpenBSD 项目立即发布补丁。后续报道揭示 OpenBSD 自身 malloc.conf 配置（含 SB（single byte）模式与 GF（guard page）模式）实际上早在 Heartbleed 披露前已部分缓解该漏洞影响。Heartbleed 是 OpenSSL 历史上最严重漏洞之一，直接触发 OpenBSD 项目 fork OpenSSL 为 LibreSSL。
- **与本章主题的关联说明**：本章叙述 OpenBSD 5.x 时期，Heartbleed 漏洞 2014-04-07 披露直接催生 LibreSSL fork，是本章 “OpenBSD 5.x 安全路线转折点” 叙事的核心事件。
- **与官方史料的交叉验证结论**：undeadly.org 报道与 CVE-2014-0160 官方公告时序一致；OpenBSD malloc.conf 缓解机制与 OpenBSD 4.8（2010）开始引入的 malloc 选项一致；与 OpenSSL 官方 2014-04-07 公告、互联网安全研究小组披露一致。一致采纳。
