# 210.3.3 network encryption 的全面支持

**要点**：OpenBSD 网络加密主要由 IPSec 栈（与 NRL 合作）、**isakmpd(8)**（IKE 密钥协商，1998-11-15 niklas commit 2040585efcaf “Initial import of isakmpd” 首次导入）、OpenSSH 默认远程登录、**ssl(8)** SSL/TLS 库组成；**iked(8)** 于 2010-06-28 reyk commit 54a1861596 "Add iked to rc/rc.conf, you can enable it on boot with the iked_flags = var" 首次引入（4.8 周期，2010.11），作为 isakmpd 的现代替代——iked 与 isakmpd 在 4.8 后并存，isakmpd 未立即弃用；OpenBSD 网络加密的 “默认安全” 哲学让其在 VPN 与边界设备部署中获得存在感

**史料**：openbsd.duckdb openbsd-src 仓库 commit 2040585efcaf（1998-11-15 niklas “Initial import of isakmpd”）、commit 54a1861596（2010-06-28 reyk “Add iked to rc/rc.conf”）；OpenBSD Release Notes IPSec 部分；NRL IPSec 文档；OpenBSD **isakmpd(8)**、**iked(8)**、**ipsec(4)** 手册页 ［A］

**史观**：总纲第 13 条——法律与道德是利益分配〔存疑：原描述符“组织结构塑造技术路径”系伪标签，按核查报告处方重挂待终核〕：OpenBSD 与 NRL 的合作让 IPSec 路径固化于基本系统——NRL IPSec 代码作为研究实现被 OpenBSD 集成，后续由 OpenBSD 团队持续维护与重写，这一路径使 OpenBSD IPSec 与 Linux/FreeBSD 的 IPSec 实现产生分化

**辨析**：NRL IPSec 与 OpenBSD IPSec 的代码血缘以 commit log 的 author_name 与 message_body 交叉确认——部分文件保留 NRL 版权头，部分由 OpenBSD 重写；**iked(8)** 取代 **isakmpd(8)** 的过程是渐进的——iked 于 4.8（2010.11）引入，isakmpd 在后续 release 中仍保留，二者并存至 5.x 周期
