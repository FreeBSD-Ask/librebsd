# 288.2.1 持续的控制平面 BSD 基础

  - 要点：JunOS 历次大版本（如 2000 年代至 2020 年代）维持 FreeBSD 控制平面，later 引入 Linux 兼容层（以运行现代工具），但核心仍为 BSD；具体版本对应 FreeBSD 基底须以 Juniper 文档核实。
  - 史料：JunOS 版本发布说明、Juniper 技术博客。 ［C］
  - 史观：终结中的延续，BSD 控制平面在 JunOS 长期延续；统计结论印证：C-54（跨数据库关联分析 Task 28）显示 BSD 衍生 fork 项目 commit 时间序列呈强正相关（ghostbsd-src ~ pfsense-src rho = 0.9355），而 JunOS 作为商业闭源 fork 其 commit 不在公开仓库 Spearman 相关矩阵中，反映商业闭源 fork 与社区开源 fork 在工程可观测性上的结构性差异——社区 fork 的 commit 节奏可被统计分析，商业闭源 fork 的内部安全补丁回灌清单不可审计，0 信任原则适用：JunOS 内部 fork 的 FreeBSD 版本同步滞后（5.x 至 14.x 长期基于 FreeBSD 6.x）须以 Juniper 官方发行说明逐一核验，不得以无法核验即推论未回灌
  - 辨析：JunOS 引入 Linux 兼容层不意味放弃 BSD，须准确描述混合结构。
  - 文献：作者不详. Juniper JunOS 版本发布说明与官方文档[EB/OL]. 年份不详 ［B］
