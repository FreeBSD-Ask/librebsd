- OpenBSD 的 Philip Guenther 与 Brian Steele 为 AMD64 增加 Spectre RSB 等推测执行缓解，在进入内核与返回用户空间时填充返回栈缓冲区，并将该缓解扩展到 VMM 虚拟机退出路径。（BSD Now EP258，[3532.28-3667.74]，L2）[订正：原 Philippe Gontier，2026-09-30 SenseAudio 重转核对]
- Olivier 自述其 BSD 之路始于 2005 年为家用 NAS 寻找方案：Linux 嵌入式工具链与 BusyBox 编译过于繁难，他参照 m0n0wall 官方开发者指南，以纯 PHP 重写脚本，在与 FreeBSD 底座的接触中造出 Freedance，即后来的 FreeNAS 前身；后因自认缺乏存储领域的视野，甚至从 FreeNAS 功能请求列表中才初识“快照”概念，遂将项目移交他人，回到网络本业另创 BSD Router Project。（BSD Now EP60，[982.74-1217.36]，L1）
- BSDRP 被作者界定为面向电信运营商与 ISP 的路由发行版而非家用防火墙：不含 web 界面，仅以 SSH 命令行管理，以 nanoBSD 定制镜像集成 Bird、Quagga、OpenVPN、StrongSwan 等路由与安全组件；其判断前提是 x86 商品服务器的转发瓶颈纯在软件侧（netmap、DPDK 一类路径），云时代一周部署上百台路由器的批量运维将淘汰逐台人工配置，软件路由因此将持续扩张。（BSD Now EP60，[1220.80-1347.96]，L1）
- 对 OpenBSD 作为路由底座的评估呈两面：ospfd、bgpd 等守护进程配置语法的同质性极利于管理工具开发；但以其在 OpenBSD 5.x 时期的基准测试，OpenBSD 缺乏多队列网卡驱动与多线程网络栈，转发性能不及 FreeBSD，作为参照，禁用 FreeBSD 的多处理器特性后两者路径趋同。（BSD Now EP60，[1611.26-1680.98]，L1）
- Alan Jude 以当事人身份复盘 Lenovo BIOS 的 GPT 引导缺陷：固件仅检查 protective MBR 中是否置有活动分区标志，未置位即拒绝引导而不查看真正的 GPT；其补丁以 gpart set -a active 对整盘置位解决，并已合入安装器的 ZFS 自动模式，同期亦有 ThinkPad T420 经 UEFI 安装 FreeBSD 11 快照的完整流程记录。（BSD Now EP60，[1953.12-2071.68]，L1）
- OpenBSD tech 邮件列表披露 col(1) 工具 -f 选项的缺陷自 1990 年 5 月 22 日引入，波及 4.3BSD Reno 以降的 4.4BSD、4.4BSD-Lite、386BSD 及 NetBSD、FreeBSD、OpenBSD、DragonFly 全系，乃至 Debian 等部分 Linux，潜伏 24 年后经 hexdump 对比验证修复，构成一个横贯 BSD 谱系代码传承的考古样本。（BSD Now EP60，[3715.96-3795.84]，L2）
- Theo 为 LibreSSL 重新设置 warrant canary：以项目网站字体是否维持 Comic Sans 作为收到国家安全信函而被禁言的暗示信号，以近乎戏谑的方式延续“未受传票”的公开声明机制；该机制的效力依赖公众对信号缺席的持续关注。（BSD Now EP60，[3801.04-3867.56]，L2）
