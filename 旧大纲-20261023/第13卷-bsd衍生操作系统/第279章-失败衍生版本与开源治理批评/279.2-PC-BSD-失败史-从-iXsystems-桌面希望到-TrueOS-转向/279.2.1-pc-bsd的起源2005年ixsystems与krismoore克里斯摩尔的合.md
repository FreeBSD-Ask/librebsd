# 279.2.1 PC-BSD 的起源：2005 年 iXsystems 与 Kris Moore（克里斯·摩尔） 的合作

  - 要点：PC-BSD 由 **Kris Moore** 于 **2005** 年发起，最初为基于 FreeBSD 5.x 的桌面 BSD，目标是提供“开箱即用”的 BSD 桌面体验；**iXsystems**（前身 IX Systems）很快成为 PC-BSD 的商业资助方，Kris Moore 加入 iXsystems 担任 PC-BSD 主导开发者；PC-BSD 1.0 于 **2006** 年发布，采用基于 FreeBSD 5.4 的内核与自研的 **PBI**（Push Button Installer）软件包管理系统，PBI 试图解决 FreeBSD Ports/pkg 在桌面场景下的依赖问题，将应用打包为独立可执行单元，类似 macOS 的 .app 包。PC-BSD 的早期定位是“Windows 用户的 BSD 入口”，iXsystems 希望通过桌面 BSD 拓展 BSD 用户基数，间接反哺其服务器与存储商业。
  - **PC-BSD 1.0 关键参数表**：

| 项目 | 内容 |
| --- | --- |
| 发布年份 | 2006 |
| 内核基线 | FreeBSD 5.4 |
| 软件包管理 | PBI（Push Button Installer） |
| PBI 设计意图 | 解决 Ports/pkg 桌面依赖问题，打包为独立可执行单元 |
| 类比 | macOS 的 .app 包 |
| 商业资助方 | iXsystems |
| 主导开发者 | Kris Moore |
| 早期定位 | “Windows 用户的 BSD 入口” |

- 史料：PC-BSD 1.0 发布公告（2006）；Kris Moore 早期邮件与访谈；iXsystems 2005-2006 年关于 PC-BSD 的官方声明；PBI 软件包管理系统设计文档 ［B］
- 史观：经济历史哲学，PC-BSD 的商业资助反映 iXsystems 试图通过桌面 BSD 拓展用户基数以反哺服务器商业的经济理性；BSD 反向影响线，PBI 软件包管理系统是 BSD 软件包管理哲学在桌面维度的反向尝试
