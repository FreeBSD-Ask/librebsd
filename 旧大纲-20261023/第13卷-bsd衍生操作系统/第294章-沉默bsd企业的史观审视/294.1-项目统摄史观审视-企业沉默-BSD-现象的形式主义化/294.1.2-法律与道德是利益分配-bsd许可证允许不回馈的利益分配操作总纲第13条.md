# 294.1.2 法律与道德是利益分配——BSD 许可证“允许不回馈”的利益分配操作（总纲第 13 条）

  - 要点：总纲第 13 条“法律与道德是利益分配”指出“任何道德问题本质上是利益问题，社区治理亦是形式主义的政治产物”。BSD 许可证“允许不回馈”是“法律与道德是利益分配”在 BSD 史中的典型显现——Berkeley CSRG 与 FreeBSD 项目自觉选择“允许不回馈”的许可证模式，是将“宽松自由”的道德立场转化为法律结构的形式主义操作，这一形式主义操作在利益分配层面使企业可汲取非营利社区代码而无需对等回馈。“允许不回馈”作为利益分配的形式主义操作具有不可证伪性：BSD 社区任何对企业沉默的道德质疑均可被企业重构为“许可证允许即合法”，BSD 社区无法在“许可证允许”话语框架内有效反驳——因为“许可证允许”是法律事实而非道德判断。这一形式主义话语运作使 BSD 社区的“隐性社会契约”诉求（使用即应回馈）被遮蔽为“道德呼吁”，企业的“法律权利行使”被重构为“不可质疑的合法行为”——总纲第 13 条在此显现：企业的“许可证允许不回馈”话语是利益分配的形式主义操作，将企业商业利益（不回馈以降低成本）重构为不可质疑的“法律权利”。BSD 与 GPL 的许可证哲学差异在此显现：GPL v3 §5 强制回馈使 Linux 企业（如 IBM/Red Hat）必须开源衍生作品，BSD 许可证“允许不回馈”使“沉默 BSD”企业可闭源使用——两种许可证哲学在利益分配层面形成对照，BSD 选择的“宽松自由”代价是“沉默 BSD”现象，GPL 选择的“强制回馈”代价是“商业不友好”——两种代价均是利益分配的形式主义结果，非“客观优劣”
  - **BSD 与 GPL 许可证哲学对照表**：

| 维度 | BSD 许可证 | GPL v3 |
| --- | --- | --- |
| 回馈要求 | 允许闭源使用不要求回馈 | §5 强制回馈衍生作品开源 |
| 哲学立场 | 宽松自由 | Copyleft 强制回馈 |
| 商业友好度 | 高（可闭源） | 低（衍生作品必须开源） |
| 代价 | “沉默 BSD”现象 | 商业不友好 |
| 典型企业 | WhatsApp、NetApp、Isilon、Citrix（沉默 BSD） | IBM/Red Hat（强制回馈 Linux 上游） |
| 利益分配性质 | 形式主义结果，非客观优劣 | 形式主义结果，非客观优劣 |

- 史观：总纲第 13 条——法律与道德是利益分配：BSD 许可证“允许不回馈”是利益分配的形式主义操作，将企业商业利益（不回馈以降低成本）重构为不可质疑的“法律权利”；总纲第 25 条——0 信任原则：本书对“允许不回馈形式主义操作”的审视本身亦须考据——BSD 许可证原文、GPL v3 §5 文本、Berkeley CSRG 公告、FreeBSD Foundation 立场文件均须以原始文档交叉验证
- 辨析：考据过程留痕——【查证来源】BSD-3-Clause 许可证文本经 Open Source Initiative（**<https://opensource.org/licenses/BSD-3-Clause>**）一手核验，确实允许闭源使用而不要求回馈；GPL v3 文本经 GNU 官方（** <https://www.gnu.org/licenses/gpl-3.0.html**>）一手核验，确为 copyleft 强制回馈许可证；Berkeley CSRG 1999.7.22 William Hoskins 公告（弃用广告条款）经多来源交叉确认；**02-sacred源材料/sacred_sources.duckdb（第 25 章）** 总纲第 13、25 条原文经本项目哲学源材料核验；freebsd.duckdb 查询 L7.2.1 一手确认“沉默 BSD”企业邮箱未在前 30 名贡献者中出现；【交叉验证方法】“允许不回馈具有不可证伪性”论断须以 BSD 许可证原文（无回馈条款）与企业实际行使“不回馈”权利的案例（freebsd.duckdb L7.2.1 量化数据）为支撑，不得仅凭哲学推论即断定“不可证伪性”；企业的“许可证允许不回馈”声明须与 BSD 社区邮件列表讨论、FreeBSD Foundation 立场文件、Berkeley CSRG 历史声明交叉验证后方可评估；BSD 与 GPL 的许可证哲学差异须以 BSD/GPL 商业回馈数据的对照为支撑；【存疑判定依据】企业的“许可证允许不回馈”声明是企业阵营的单方面叙事，存在自利偏差，须经 BSD 社区邮件列表讨论、FreeBSD Foundation 立场文件、Berkeley CSRG 历史声明交叉验证后方可评估；“两种代价均是利益分配的形式主义结果，非客观优劣”的论断须以 BSD/GPL 商业回馈数据的对照为支撑，不得仅凭哲学推论即断定“非客观优劣”。法律与道德形式主义操作的论点式辨析——须区分“许可证允许的法律事实”与“许可证允许的道德评估”——BSD 许可证确实允许不回馈，这是法律事实，但“允许”是否等于“鼓励”须经 BSD 许可证哲学文献核实；【0 信任原则·当事人自辩不免检】企业的“许可证允许不回馈”声明是企业阵营的单方面叙事，存在自利偏差，须经 BSD 社区邮件列表讨论、FreeBSD Foundation 立场文件、Berkeley CSRG 历史声明交叉验证后方可评估；【0 信任原则·多源交叉验证不可靠性规则】“允许不回馈具有不可证伪性”的论断须以 BSD 许可证原文（无回馈条款）与企业实际行使“不回馈”权利的案例（freebsd.duckdb L7.2.1 量化数据）为支撑，不得仅凭哲学推论即断定“不可证伪性”；BSD 与 GPL 的许可证哲学差异是历史事实，但“两种代价均是利益分配的形式主义结果”的论断须以 BSD/GPL 商业回馈数据的对照为支撑，不得仅凭哲学推论即断定“非客观优劣”
