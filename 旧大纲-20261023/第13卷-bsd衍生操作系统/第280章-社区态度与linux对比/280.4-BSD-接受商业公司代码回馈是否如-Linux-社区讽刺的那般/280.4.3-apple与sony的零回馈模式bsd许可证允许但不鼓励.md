# 280.4.3 Apple 与 Sony 的零回馈模式：BSD 许可证允许但不鼓励

  - 要点：与 Netflix/Juniper/NetApp 的积极回馈相对，Apple 与 Sony 是 BSD 阵营中“零回馈”的典型——Apple 的 macOS/iOS Darwin 内核基于 FreeBSD 但 Apple 向 FreeBSD 上游贡献极少（Darwin 代码以 Apple Public Source License 发布，部分组件回馈 FreeBSD 但远小于 Apple 取走的量）；Sony 的 PS3/PS4/PS5 Orbis OS 基于 FreeBSD 9.0 但 Sony 向 FreeBSD 上游贡献几乎为零（Sony 法务严格限制任何外部技术披露）。Apple 与 Sony 的零回馈模式是 BSD 许可证“无回馈条款”的直接结果——BSD 许可证允许闭源使用而不要求回馈，故 Apple 与 Sony 无法律义务回馈。
  - **Apple 与 Sony 零回馈模式对照表**：

| 公司 | BSD 衍生产品 | 基线 | 回馈 FreeBSD 上游情况 | 零回馈原因 |
| --- | --- | --- | --- | --- |
| Apple | macOS/iOS Darwin 内核 | FreeBSD | 极少（部分组件回馈，远小于取走的量） | BSD 许可证“无回馈条款” |
| Sony | PS3/PS4/PS5 Orbis OS | FreeBSD 9.0 | 几乎为零 | Sony 法务严格限制外部技术披露 |

- 史料：Darwin 开源代码与 Apple 对 FreeBSD 上游的贡献记录；Sony PS3/PS4/PS5 技术文档与 Sony 对 FreeBSD 上游的贡献记录 ［A］
- 史观：经济历史哲学，Apple 与 Sony 的零回馈模式是 BSD 许可证经济结构的直接结果；总纲第 12 条——形式主义即非存在，“BSD 许可证允许但不鼓励”作为形式主义操作，其“允许”在实质回馈上常呈现非存在
- 辨析：考据过程留痕——【查证来源】Apple 对 FreeBSD 上游的具体贡献须以 FreeBSD commit 历史（freebsd.duckdb freebsd-src 仓库）为原始一手来源，Darwin 开源代码（Apple OSS Distributions）为 Apple 自述二手来源；Sony 对 FreeBSD 上游的贡献须以 FreeBSD commit 历史为准，Sony PS3/PS4/PS5 技术文档为二手资料；【交叉验证方法】FreeBSD commit 历史（代码级证据）与 Darwin 开源代码（Apple OSS Distributions 509 个仓库）与 Sony 技术文档三方互证，确认 Apple/Sony 的零回馈模式；freebsd.duckdb 可查询 freebsd-src 仓库中 Apple 相关 committer（如 theraven@、pfg@、jkh@ 等）的 commit 量，Jordan Hubbard（jkh@）2001 年加入 Apple 后的 commit 量变化须按年分组统计以辨 Apple 雇佣对 FreeBSD 贡献的间接影响；Sony 相关 committer 在 freebsd-src 仓库的 commit 量若为零或极少，则佐证“零回馈”判断；【存疑判定依据】“零回馈”的判断须警惕绝对化——Apple 可能通过雇佣 FreeBSD committer（如 Jordan Hubbard 2001 年加入 Apple）间接贡献，Sony 可能通过未公开渠道贡献；本节“几乎为零”的判断须以 commit 历史为准，但须承认 commit 历史无法捕捉所有形式的贡献（如设计影响、技术交流、未署名的代码审查等），故标注 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］；Jordan Hubbard 加入 Apple 后的 commit 频率变化的精确数据须按年分组统计 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］
