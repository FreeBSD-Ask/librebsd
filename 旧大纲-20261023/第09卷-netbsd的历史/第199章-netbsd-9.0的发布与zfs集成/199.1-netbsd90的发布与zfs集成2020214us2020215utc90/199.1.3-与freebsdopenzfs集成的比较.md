# 199.1.3 与 FreeBSD OpenZFS 集成的比较

**要点**：FreeBSD 7.0（2008.2）首次引入实验性 ZFS 移植，8.x-13.x 持续改进至 OpenZFS 2.x；NetBSD 9.0（2020.2.14）ZFS 集成晚于 FreeBSD 12 年；两者均通过 OpenZFS 仓库共享代码，但 FreeBSD 因经验积累稳定性领先

**史料**：FreeBSD 7.0-13.0 Release Notes ZFS 部分；OpenZFS 项目历史；NetBSD 9.0 ZFS 文档；freebsd.duckdb freebsd-src 仓库 tags 表验证：release/7.0.0 tag tagger_date = 2008-02-24T05:45:17Z（tagger = cvs2svn，FreeBSD 7.0 release tag 时间戳，验证 FreeBSD 7.0 发布日期 2008.2 与原叙事吻合）；netbsd.duckdb netbsd-src 仓库 commits 表验证：chs 2018-05-28T20:52:50Z"import new CDDL dtrace and ZFS code from FreeBSD svn r315983."（commit aa52db7bd6f0f630edc90d06231f27ac9af1a442，明确证实 NetBSD ZFS 直接从 FreeBSD SVN r315983 移植）；netbsd.duckdb 查询 L1.1.1 显示：netbsd-src 2018 年 commit_count = 10,983，2019 年 = 10,227（9.0 开发年），对比 freebsd-src 2018 年 commit_count 远高于 netbsd-src（freebsd-src 2018 年 14,985 commits，freebsd.duckdb 全库三仓合计 47,408；netbsd-src 10,983；2026-09-13 实测订正，原记“约 60,000+ commits”与实测不符，src 口径实差约 1.36 倍而非 5.5 倍），反映两项目 commit 量存在差距但非数量级差异；netbsd.duckdb 查询 L2.3.1.zfs 显示：netbsd-src 2018 年 ZFS 相关 commit = 31，2019 年 = 40，对比 freebsd-src L6.2.1 查询 sys/contrib/openzfs/ 路径 2020 年触及 commit = 40（commit_files 行数 80、distinct 路径 51；2026-09-13 实测订正，原记 80 系 commit_files 行数误作 commit 数；原“约为 NetBSD 的 2 倍”论断系口径错置（40 对 40 大致相当）且与辨析自警“两查询口径不可直接对比绝对值”相抵，撤销倍数结论），反映 NetBSD ZFS 集成规模（2019 年 40 commit）与 FreeBSD OpenZFS 集成规模（2020 年触及 40 commit）大致相当 ［A］

**史观**：组织结构塑造技术路径〔订正注：原挂“总纲第 5 条——组织结构塑造技术路径”系伪标签，权威第 5 条为“没有必然性，只有偶然性”，去条号留中性论旨〕：FreeBSD 早期投入 ZFS 的组织结构决定其领先地位，NetBSD 延迟投入难以追赶

**辨析**：NetBSD ZFS 与 FreeBSD OpenZFS 的“代码共享程度”需对照源码核验——两者均从 OpenZFS 仓库同步，但 NetBSD 的本地修改可能较 FreeBSD 更少。经 netbsd.duckdb netbsd-src 仓库 commits 表验证：NetBSD ZFS 代码由 chs 于 2018-05-28 从 FreeBSD SVN r315983 直接导入（commit aa52db7bd6f0f630edc90d06231f27ac9af1a442），并非从 OpenZFS 仓库同步——原叙事中“两者均通过 OpenZFS 仓库共享代码”声明不准确，存疑已部分解决（NetBSD 是从 FreeBSD SVN 移植，FreeBSD 在 13.x 之前也是从 OpenZFS 仓库同步但 NetBSD 9.0 时期是直接从 FreeBSD SVN 导入）；FreeBSD 7.0 release tag tagger_date = 2008-02-24 验证了 FreeBSD 7.0 发布日期 2008.2 与原叙事吻合；ZFS 在两项目中的性能对比缺乏权威基准 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］；9.0 发布日期 2020.2.14 仍须以 NetBSD 官方公告为准。L1.1.1 查询的 commit 量数据存在 GitHub 镜像滞后风险——netbsd-src 为 GitHub 镜像（主仓为 Mercurial **hg.NetBSD.org**），freebsd-src 亦为 GitHub 镜像（主仓为 FreeBSD self-hosted Git/SVN），2018-2019 年两项目 commit 量可能均不完整；L2.3.1.zfs 与 L6.2.1 查询路径不同（前者基于 message_subject LIKE'%ZFS%’全仓匹配，后者基于 sys/contrib/openzfs/ 路径匹配），两查询口径不可直接对比绝对值，仅可对比趋势——L6.2.1 仅统计 sys/contrib/openzfs/ 路径下的 commit（FreeBSD OpenZFS 集中区），L2.3.1.zfs 统计全仓 ZFS 相关 commit（含 NetBSD 本地 ZFS 适配），后者范围更广但匹配更粗；FreeBSD OpenZFS 集成规模（2020 年触及 40 commit，commit_files 行数 80）与 NetBSD ZFS 集成规模（2019 年 40 commit）大致相当〔订正注：原“约为……2 倍”系 80（文件行数）对 40 的口径错置，撤销〕，此对比亦未考虑 FreeBSD 2020 年 OpenZFS 2.x 大重构的特殊投入
