# 197.1.1 6.0 线程调度器的设计

  **netbsd-src 仓库 2010-2012 年度 commit 量与 SMP 相关 commit 量统计**：

  | 年份 | 年度 commit_count | SMP 相关 commit | 备注 |
  | --- | --- | --- | --- |
  | 2010 | 21,916 | 14 | 6.0 开发早期 |
  | 2011 | 25,959 | 18 | 开发峰值，较 2010 年增长 18.5% |
  | 2012 | 19,358 | 26 | 6.0 发布年（**2012.10.17**），SMP commit 峰值 |

**要点**：NetBSD 6.0（**2012.10.17**）继续由 Andrew Doran（安德鲁·多兰） 改进的线程调度器，引入更细粒度的优先级继承与多核负载均衡；6.0 的 SMP 改进特别针对 8 核以上机器优化；调度器设计延续 5.0 渐进式路径，未引入革命性重构

**史料**：NetBSD 6.0 Release Notes；tech-kern 邮件列表 Doran 设计帖；CVS commit log；netbsd.duckdb netbsd-src 仓库 branches 表验证：origin/netbsd-6-0 branch commit_date = 2018-07-02T14:40:25Z（commit 5b641b39b45a，远晚于 6.0 发布 2012.10.17 约 5 年 9 个月，属分支末次维护更新时间，非发布时间）；origin/netbsd-6-1 branch commit_date = 2018-07-02T14:39:15Z（commit 796dca000579，与 6.0 分支末次更新同期，反映 6.x 系列共同维护至 2018.7）；netbsd.duckdb 查询 L1.1.1 显示：netbsd-src 2010 年 commit_count = 21,916，2011 年 = 25,959（开发峰值，较 2010 年增长 18.5%），2012 年 = 19,358（6.0 发布年，较 2011 年下降 25.4%），2011 年的 commit 量峰值反映 6.0 开发周期中段（2010-2012）的工程投入集中，2012 年发布年 commit 量下降反映进入发布收尾阶段；netbsd.duckdb 查询 L2.3.1.smp 显示：netbsd-src 2010 年 SMP 相关 commit = 14，2011 年 = 18，2012 年 = 26（6.0 发布年，较 2011 年增长 44.4%），2012 年 SMP commit 增长反映 6.0 发布前最后的 SMP 调度器优化集中投入；统计结论 [C-04]: netbsd-src 仓库总 commit 数 773,683（截至 2026-07-27 查询），为 4 大 BSD src 仓库中 commit 累计最高者，本章时期（2010-2012）的 commit 活动构成此总量的中后段；统计结论 [C-13]: netbsd-src 月度 commit 量 Pettitt 检验变点为 2012-04、BUISHAND R 检验变点为 2011-09（10,000 次 Monte Carlo），两检验变点均落在本章时期（2010-2012）内，反映本章时期是 netbsd-src 长期下降趋势的结构性转折区间，变点事件或对应 NetBSD 主仓由 CVS 迁移至 Mercurial 的过渡期〔存疑：主仓版本控制迁移的通行记载在 2020 年前后，与本章 2011-2012 变点年份相距过远，此归因系待核假设〕 ［A］

**史观**：专题语（不设条号）——组织结构塑造技术路径：NetBSD 调度器的“渐进式”路径延续，体现组织结构对技术路径的塑造

**辨析**：6.0 调度器相比 5.0 的具体改进幅度在不同来源中差异较大——部分基准显示显著提升，部分显示微小改进，需对照同硬件测试核验。经 netbsd.duckdb netbsd-src 仓库 branches 表验证：origin/netbsd-6-0 与 origin/netbsd-6-1 的 commit_date 均为 2018-07-02（前后相差仅 1 分钟），反映 6.x 系列分支在 2018.7 同期停止维护，与 NetBSD 8.0（2018.7）发布时序吻合（8.0 发布后 6.x 系列进入 EOL）；6.0 发布日期 2012.10.17 仍须以 NetBSD 官方公告为准。L1.1.1 查询的 commit 量数据存在 GitHub 镜像滞后风险——netbsd-src 为 GitHub 镜像（主仓为 Mercurial **hg.NetBSD.org**），2010-2012 年 commit 量可能不完整，2011 年的峰值可能因镜像同步延迟而与主仓实际数据存在偏差；L2.3.1.smp 查询基于 message_subject LIKE '%SMP%’ 匹配，14/18/26 这组数字是 SMP 相关 commit 的下限，实际涉及线程调度器改进的 commit 可能更多（如 subject 中含“scheduler”“thread”“preemption”“runqueue”但未含“SMP”的 commit 未被统计）。统计结论 [C-13] 局限性继承：Pettitt 检验变点 2012-04 与 BUISHAND R 检验变点 2011-09 相差约 7 个月，反映两检验对序列尾部敏感度差异，非数据矛盾；变点事件对应 NetBSD 主仓由 CVS 迁移至 Mercurial 的过渡期，但变点检测不区分 “版本控制迁移影响” 与 “实际开发活动结构性变化”，变点成因须结合 commit message 与文件路径分析；10,000 次 Monte Carlo 模拟提供 p 值近似，但小样本（netbsd-src 月度序列仅约 400 个月）下变点位置的 95% 置信区间较宽，变点年份判定存在不确定性
