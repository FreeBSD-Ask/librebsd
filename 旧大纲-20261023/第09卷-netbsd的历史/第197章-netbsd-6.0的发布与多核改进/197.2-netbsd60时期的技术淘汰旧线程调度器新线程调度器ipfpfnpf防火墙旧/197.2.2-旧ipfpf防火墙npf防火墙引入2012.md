# 197.2.2 旧 IPF/PF 防火墙 → NPF 防火墙引入（2012）

**要点**：NetBSD 6.0（2012.10）引入 NPF（NetBSD Packet Filter）作为新防火墙框架，由 Mindaugas Rasiukevicius 设计；NPF 提供 IPF（IPFilter）与 PF（OpenBSD 移植）的现代替代品，支持状态跟踪、NAT、流量整形；NPF 使用 BPF 字节码，强调可扩展性与性能；旧 IPF 与 PF 在 6.0 中仍可共存，未被强制淘汰，体现“分离与聚合”的工具独立哲学

**史料**：NPF 设计文档与 **npf(7)** 手册页；tech-net 邮件列表讨论；CVS commit log 中 npf 相关 commit ［A］

**史观**：总纲第 4 条——分离聚合是永恒规律：NPF 作为独立防火墙框架与 NetBSD 内核聚合，但与 IPF/PF 在概念上分离，体现工具独立哲学；总纲第 3 条——不存在进步，只有权力再分配：旧 IPF 与 PF 在 6.0 中未被强制淘汰，新旧框架的取舍并非单向进步

**辨析**：NPF 与 OpenBSD PF 的关系存在叙事分歧——部分资料称 NPF 借鉴 PF 设计，部分称独立设计，需对照源码核验；NPF 在 6.0 中的实际采用率（与 IPF/PF 共存情况）需考据；NPF 的默认状态（默认启用 vs 默认禁用）需对照 Release Notes 核验

**文献**：NPF 设计文档；OpenBSD **pf(4)** 手册页；Mindaugas Rasiukevicius 演讲 ［A］
