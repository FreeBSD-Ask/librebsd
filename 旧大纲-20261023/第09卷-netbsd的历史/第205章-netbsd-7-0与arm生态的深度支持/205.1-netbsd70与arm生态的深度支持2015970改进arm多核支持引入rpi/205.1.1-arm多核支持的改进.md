**要点**：NetBSD 7.0（**2015.9**）改进 ARM 多核支持，支持 Cortex-A15/A57 等多核 SoC；~~引入 big.LITTLE 架构支持~~（经 netbsd.duckdb netbsd-src 仓库 commits 表查询 `message_subject LIKE '%big.LITTLE%' OR '%big_little%' OR '%biglittle%'` 未找到与 ARM big.LITTLE 架构直接相关的 commit，存疑待考据【考据完成：2026-08-02 经项目数据库（netbsd.duckdb/netbsd.duckdb netbsd-src 仓库 commits 表）精确查询核验，结果详见本子节史料/辨析字段；相关声明未获代码级确认，维持存疑，特性是否引入留待官方 Release Notes 复核】）；ARM SMP 调度器优化；7.0 是 NetBSD 在 ARM 嵌入式市场重新获得关注的关键版本

**史料**：NetBSD 7.0 Release Notes ARM 部分；tech-port-arm 邮件列表讨论；CVS commit log 中 arm 相关 commit；netbsd.duckdb netbsd-src 仓库 branches 表验证：origin/netbsd-7-0 branch commit_date = 2020-05-07T12:03:47Z（commit f76d427f5b4c，远晚于 7.0 发布 2015.9 约 4 年 8 个月，属分支末次维护更新时间，非发布时间）；netbsd.duckdb netbsd-src 仓库 commits 表 aarch64 相关 commit 验证：joerg（Joerg Sonnenberger）2013-02-04T15:00:31Z "Update to LLVM/Clang snapshot r174288. This brings in the new AArch64 backend as..."（commit 96fc3e30a7c3，LLVM/Clang AArch64 后端首次引入，远早于 7.0 发布约 2 年 7 个月）；matt（Matt Thomas）2013-10-29T00:45:00Z “Add AARCH64 definitions”（commit f4eee7a46719，AARCH64 定义首次引入）；matt 2014-01-29T01:36:43Z “Add latent AArch64 support.”（commit 25b6650f1bb1，latent AArch64 支持添加）；matt 2014-03-24T04:45:08Z " Use sizeof(__int128_t) for aarch64 and sizeof(long long) for ARM EABI "（commit eec17c6e0612，aarch64 类型宽度处理）；netbsd.duckdb 查询 L1.1.1 显示：netbsd-src 2013 年 commit_count = 19,460，2014 年 = 20,949（较 2013 年增长 7.6%），2015 年 = 17,365（7.0 发布年，较 2014 年下降 17.1%），2014 年的 commit 量增长反映 7.0 开发中段（2013-2015）ARM 移植与 aarch64 准备的工程投入，2015 年发布年 commit 量下降反映进入发布收尾阶段；netbsd.duckdb 查询 L2.3.1.arm 显示：netbsd-src 2013 年 ARM 相关 commit = 854（开发峰值），2014 年 = 670，2015 年 = 464（7.0 发布年），2013 年 ARM commit 峰值与 aarch64 后端首次引入（2013.2.4）时序吻合，反映 2013 年是 ARM 生态深度支持的核心开发年，2015 年发布年 ARM commit 量下降反映 ARM 移植已趋稳定 ［A］

**史观**：专题语（不设总纲条号）：NetBSD 长期投入 ARM 支持，在树莓派爆发后获得回报，但 x86 性能因此落后

**辨析**：NetBSD ARM 多核支持与 Linux ARM 多核支持的成熟度对比缺乏权威基准——需对照同硬件测试核验。经 netbsd.duckdb netbsd-src 仓库 commits 表验证：aarch64 后端于 2013.2.4 由 joerg 首次引入（LLVM/Clang snapshot r174288），AARCH64 定义于 2013.10.29 由 matt 添加，latent AArch64 支持于 2014.1.29 由 matt 添加后又于同日删除（“Remove AArch64 stuff.” commit 8e5b387ff0e4），反映 7.0 时期 aarch64 支持在主分支处于 “开发中-回退-再引入” 的反复状态，与 “7.0 引入 big.LITTLE 架构支持” 叙事需进一步核验。重要修正：netbsd.duckdb netbsd-src 仓库 commits 表查询 `message_subject LIKE '%big.LITTLE%' OR '%big_little%' OR '%biglittle%'` 未找到与 ARM big.LITTLE 架构直接相关的 commit（搜索结果均为 big/little endian 大小端处理），原叙事中 “7.0 引入 big.LITTLE 架构支持” 声明暂未得到代码级确认，存疑待考据【考据完成：2026-08-02 经项目数据库（netbsd.duckdb/netbsd.duckdb netbsd-src 仓库 commits 表）精确查询核验，结果详见本子节史料/辨析字段；相关声明未获代码级确认，维持存疑，特性是否引入留待官方 Release Notes 复核】；7.0 发布日期 2015.9 仍须以 NetBSD 官方公告为准。L1.1.1 查询的 commit 量数据存在 GitHub 镜像滞后风险——netbsd-src 为 GitHub 镜像（主仓为 Mercurial **hg.NetBSD.org**），2013-2015 年 commit 量可能不完整；L2.3.1.arm 查询基于 message_subject LIKE '%ARM%’ 匹配，854/670/464 这组数字是 ARM 相关 commit 的下限，实际涉及 ARM 移植的 commit 可能更多（如 subject 中含 “evbarm” “Cortex” “Raspberry Pi” “aarch64” 但未含 “ARM” 的 commit 未被统计）；2013 年 ARM commit 峰值（854）与 aarch64 后端首次引入时序吻合，但 commit 量峰值不等于技术成熟度峰值，2015 年发布年 commit 量下降可能反映 ARM 移植已进入稳定维护而非开发衰退
