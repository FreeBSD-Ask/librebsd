**史观**：总纲第 4 条——分离聚合是永恒规律：NVMM 作为独立虚拟化框架与 NetBSD 内核聚合，但设计上与 bhyve/KVM 分离

**辨析**：NVMM 与 bhyve 的关系存在叙事分歧——部分资料称 NVMM 借鉴 bhyve，部分称独立设计，需对照源码核验。重要修正：经 netbsd.duckdb netbsd-src 仓库 commits 表验证：NVMM 首次导入时间为 2018-11-07（maxv commit f3a4baf7484784132d2a9cb396481ffe77c9010b“Add NVMM - for NetBSD Virtual Machine Monitor”），晚于 NetBSD 8.0 发布 2018.7 约 4 个月，反映 NVMM 实际在 8.0 发布后才在主分支引入，原叙事中“NetBSD 8.0 引入 NVMM”声明不正确——NVMM 应归入 9.0 时期（或 8.1，需对照 NetBSD 官方版本归属确认），存疑已部分解决（NVMM 引入时间得到代码级确认，但版本归属仍需对照 NetBSD 官方 Release Notes 核验）；NVMM 作者归属 maxv（Maxime Villard）与“由 Maxime Villard 设计”叙事吻合；NVMM 的实际采用率（vs 其他虚拟化方案）需考据；8.0 发布日期 2018.7 仍须以 NetBSD 官方公告为准
