# 204.8.1 可移植性口号、Theo de Raadt（西奥·德·若特） 驱逐与 Tainted Code 政策传言

**要点**：NetBSD 在 BSD 生态中长期伴随三类典型传言——(1) “NetBSD 几乎可以运行在任何硬件上”与“Of course it runs NetBSD”口号（史实属实：NetBSD 官方 Ports 列表显示支持 50 个以上硬件平台，项目自 1993 年创立即以可移植性为核心目标，口号经 NetBSD 官方 Gallery 页面收录实例印证为“官方默许的社区口号”）；(2) “Theo de Raadt 被 NetBSD 驱逐的真实原因”（真伪混杂：1994-12-23 Adam Glass（亚当·格拉斯） 邮件列表通知被逐事件本身史实属实，OpenBSD 官方 FAQ 陈述“forced to resign”，但“真实原因”无法确证为单一因素，Core Team 内部讨论过程不在邮件中公开，社区流传的“个人冲突说”“沟通风格说”“治理分歧说”均为单方叙事的不同侧面解读）；(3) “NetBSD 的 Tainted Code 政策导致项目衰落”（史实失实：Tainted Code 政策起源于 2024-05，而 NetBSD 项目活力下降趋势自 2010 年代起即存在，将 2024 年政策与 2010 年代趋势直接因果关联是时序倒置，政策针对 AI 生成代码而非限制人类贡献者）

**史料**：NetBSD Project 官方历史页面（**<https://www.netbsd.org/about/history.html>**）；NetBSD Project Goals 页面（** <https://www.netbsd.org/about/goals.html**>，将 portability 列为首要目标）；NetBSD Ports 列表（**<https://www.netbsd.org/ports/>**，显示 50+ 硬件平台）；NetBSD Gallery 页面（** <https://www.netbsd.org/gallery/**>，收录“Of course it runs NetBSD”实例）；Adam Glass 1994-12-23 netbsd-users 邮件列表通知（**<https://mail-index.netbsd.org/netbsd-users/1994/12/23/0000.html>**）；OpenBSD FAQ 历史章节（** <https://www.openbsd.org/faq/faq1.html#History**>，陈述“forced to resign”）；OpenBSD History 页面（**<https://www.openbsd.org/history.html>**）；NetBSD Developer Guidelines（** <https://www.netbsd.org/developers/**>，Tainted Code 政策）；NetBSD 10.0 Release（**2024-03-30**，**<https://www.netbsd.org/releases/formal-10/NetBSD-10.0.html>**）；netbsd.duckdb netbsd-src 仓库 1993-1995 年 commit 记录 ［A］

**史观**：总纲第 9 条——经验优先，“Of course it runs NetBSD”口号是 NetBSD 在大量硬件平台移植成功的经验沉淀，而非预先设计的市场口号；总纲第 19 条——解释学循环是历史认识的根本条件，Theo de Raadt 被逐事件的“removed”（Glass 邮件）与“forced to resign”（OpenBSD FAQ）措辞差异是双方前理解差异在文本中的显现，史家须在两方叙事间往复印证；总纲第 15 条——文化即形式主义，“Tainted Code 政策导致衰落”传言将 2024 年政策与 2010 年代趋势因果关联是社区对 NetBSD 活力下降的形式主义化归因；总纲第 7 条——理论必须自反，本子节作为 NetBSD 传言考据叙事，自身亦嵌入“可移植性即善”的前理解，须自觉呈现这一前理解；总纲第 23 条——一切历史写作都是基于哲学设定的历史小说，“驱逐原因”的单一因素归因是史家基于单方叙事的形式主义建构；本节亦以 6 条 NetBSD 传言为经验材料检验项目统摄史观，同时以项目统摄史观为分析工具释读 NetBSD 传言，构成双向检验的方法论实验

**辨析**：考据过程留痕——【查证来源】NetBSD 官方 Ports 列表经 netbsd.org/ports/ 一手核验显示 50+ 硬件平台；Adam Glass 1994-12-23 邮件经 mail-index.netbsd.org 一手核验；OpenBSD FAQ 经 openbsd.org/faq/faq1.html#History 一手核验“forced to resign”措辞；Tainted Code 政策起源时间 2024-05 经本项目既有考据记录 `20260727_customs-bsd.md` 第 2.4 节核验；【交叉验证方法】被逐事件须以 Adam Glass 邮件（NetBSD 阵营）与 OpenBSD FAQ（OpenBSD 阵营）两方独立来源互证，双方措辞差异“removed”vs“forced to resign”须在前理解差异中解读；Tainted Code 政策与项目衰落的因果关联须以政策起源时间（2024-05）与项目活力下降趋势（2010 年代起）的时序核验；【0 信任原则·“真实原因”模糊性】Core Team 内部讨论过程的具体细节不在邮件中公开，邮件通知的是结果而非讨论过程，社区流传的“个人冲突说”“沟通风格说”“治理分歧说”均为对单方叙事的不同侧面解读；【0 信任原则·Tainted Code 时序倒置】Tainted Code 政策起源于 2024-05，而 NetBSD 项目活力下降趋势自 2010 年代起即存在，时序倒置使“政策导致衰落”的因果关联不成立；【0 信任原则·口号“非官方”性质】“Of course it runs NetBSD”口号虽非 NetBSD 官方注册口号，但与项目官方陈述的可移植性目标完全一致，且被 NetBSD 官方 Gallery 页面收录实例；【自反性声明】本子节作为 NetBSD 传言考据叙事，自身嵌入“可移植性即善”的前理解，实际 NetBSD 可移植性的工程代价与治理冲突的复杂性须以多源交叉验证逼近史实
