**要点**：Dreamcast（Sega 1998 游戏机，Hitachi SH-4 处理器）与 Sharp Zaurus（PDA）的 NetBSD 移植——NetBSD/dreamcast 与 NetBSD/zaurus 移植展示 NetBSD 在嵌入式与消费电子的应用；移植反映 NetBSD “of course it runs NetBSD” 的可移植性

**史料**：NetBSD/dreamcast 移植档案；NetBSD/zaurus 移植档案；Dreamcast 与 Zaurus 硬件文档；netbsd.duckdb netbsd-src 仓库 commits 表验证：Dreamcast 移植 msaitoh 2000-07-13T18:11:53Z “config file for Dreamcast”（commit 早期配置文件），marcus 2000-12-11T18:19:12Z "Initial import of port ‘dreamcast’ (cloned from port ‘evbsh3’)”（commit 端口正式导入，从 evbsh3 克隆），fair 2000-12-15T00:01:53Z “add port-dreamcast”（commit 端口登记）；Zaurus 移植 ober 2006-12-16T02:59:33Z “Updated to include the new Zaurus port for ARM. OK'd by gimpy”（commit Zaurus ARM 端口引入），ober 2006-12-16T03:35:51Z “Zaurus Port from OpenBSD by Nonaka Kimihiro OK gimpy”（commit Zaurus 端口从 OpenBSD 移植，作者 Nonaka Kimihiro） ［A］

**史观**：总纲第 3 条——不存在进步，只有权力再分配〔存疑：重挂待复核〕：嵌入式移植付出维护成本，但获得嵌入式市场应用

**辨析**：移植的具体时间需考据——NetBSD/dreamcast 与 NetBSD/zaurus 的具体发布时间需对照 Release Notes 核实。经 netbsd.duckdb netbsd-src 仓库 commits 表验证：NetBSD/dreamcast 端口正式导入时间为 **2000-12-11**（marcus “Initial import of port ‘dreamcast’ (cloned from port ‘evbsh3’)”），Dreamcast 硬件本身于 1998 年发布（Sega Dreamcast 日本 **1998.11**、北美 **1999.9**），NetBSD 端口滞后硬件约 2 年；NetBSD/zaurus 端口正式导入时间为 **2006-12-16**（ober “Zaurus Port from OpenBSD by Nonaka Kimihiro OK gimpy”），Zaurus 硬件 SL-5000D 于 2002 年发布，NetBSD 端口滞后硬件约 4 年；重要修正：~~Zaurus 端口导入时间（2006.12.16）超出本章覆盖时期（1998-2004），应归入第040章 NetBSD 4.0 时期（2005-2009）的嵌入式叙事~~（已调整：Zaurus 端口叙事保留在本章作为对比参照，但明确标注其导入时间超出本章时期），存疑已解决（Dreamcast 在本章时期内；Zaurus 导入时间超出本章时期，处置为保留在本章作对比参照并明确标注超期）；Zaurus 端口从 OpenBSD 移植而来（作者 Nonaka Kimihiro），体现 BSD 生态内的代码共享传统〔存疑：NetBSD/zaurus 源出 OpenBSD、面向 PXA/XScale 的 SL-C 系机型，SL-5000D 系 StrongARM 机型，设备-端口对应待按 port-zaurus 支持清单复核；全书另有锚点记 Zaurus 为 NetBSD/hpcmips、ZA300〕
