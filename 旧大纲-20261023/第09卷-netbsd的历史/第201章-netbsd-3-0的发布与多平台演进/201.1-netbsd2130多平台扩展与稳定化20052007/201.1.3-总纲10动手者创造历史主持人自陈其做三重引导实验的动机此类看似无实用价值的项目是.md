# 201.1.3 总纲10动手者创造历史主持人自陈其做三重引导实验的动机此类看似无实用价值的项目是

- 总纲10 动手者创造历史：主持人自陈其做三重引导实验的动机：此类看似无实用价值的项目，是发现操作系统间差异与新知的好方式。以亲自动手的经验而非文档或宣传作为认识操作系统的途径，体现了动手者以实践创造并检验历史细节的路径。（BSDTalk EP6，[224.86-234.88]，L1）
- 总纲10 动手者创造历史：学区网络的真实形态由一线管理员以捐赠旧硬件、活页夹灾备文档与 LDAP 集成逐步搭建，FreeBSD、NetBSD 与 Apple 的取舍由经费约束、旧硬件复用与运维人手现实决定，而非任何厂商路线图——技术历史在这种日常动手维护中被具体地塑造。（BSDTalk EP10，[190.32-660.80]，L1）
- 总纲8 本体论上各方平等：Jones 对 Alpha 加 NetBSD 组合的辩护展示了一种以边缘性为生存策略的生态观：架构冷僻使攻击者缺乏兴趣，NetBSD 的冷僻再加一层保险，受限的可及性反而成了安全属性；三十五台 Alpha 刀片在主流叙事宣判其死亡多年后仍高速可靠地服务两万用户——平台的存亡不取决于市场份额的宣判，而取决于具体机器是否仍在被使用与维护。（BSDTalk EP21，[1312.26-1345.33]，L1）
- 总纲9 经验优先：当事人反驳“BSD 安静/垂死”的流行论调：只要订阅任一 BSD 项目的邮件列表就能看到海量流量，BSD 专题网站相对 Linux 确实较少，根由在于其他操作系统背后有大公司的新闻稿与广告经费，而 BSD 缺乏营销资源；社区“水面沉静而深处湍急”，大社区亦有代价，BSD 恰在这一平衡中运作良好。（BSDTalk EP28，[744.82-854.84]，L1）
