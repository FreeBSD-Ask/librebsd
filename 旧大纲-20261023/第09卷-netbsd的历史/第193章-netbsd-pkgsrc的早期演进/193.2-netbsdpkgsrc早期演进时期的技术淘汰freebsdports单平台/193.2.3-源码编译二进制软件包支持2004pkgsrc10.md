# 193.2.3 源码编译 → 二进制软件包支持（2004 pkgsrc 1.0）

**要点**：pkgsrc 早期仅支持源码编译安装，用户需自行处理编译依赖与冲突；2004 年 pkgsrc 1.0 引入正式的二进制软件包支持，通过 `pkg_create` 与 `pkg_add` 工具生成与安装预编译软件包；二进制软件包支持使 pkgsrc 用户可跳过编译步骤直接安装，降低使用门槛；同期 FreeBSD Ports 亦通过 `pkg_create` 提供二进制软件包，OpenBSD Ports 通过 packages 提供二进制软件包

**史料**：pkgsrc 1.0 Release Notes（2004）；`pkg_create` 与 `pkg_add` commit log；tech-pkg 邮件列表二进制软件包讨论帖 ［A］

**史观**：总纲第 15 条——文化即形式主义〔映射存疑，待主理人审定〕：二进制软件包作为 “形式” 改变了用户安装 “内容” 的方式；总纲第 15 条——文化即形式主义〔映射存疑，待主理人审定〕：二进制软件包支持付出存储与维护代价，但获得使用门槛降低

**辨析**：pkgsrc 1.0 的具体发布日期在不同来源中存在差异——部分资料称 2004.12，需对照 Release Notes 核验；二进制软件包支持的早期实现细节需对照 commit log 核验
