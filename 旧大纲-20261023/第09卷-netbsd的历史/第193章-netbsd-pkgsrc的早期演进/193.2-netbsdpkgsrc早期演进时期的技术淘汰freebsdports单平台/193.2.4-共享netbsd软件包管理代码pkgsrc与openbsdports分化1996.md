# 193.2.4 共享 NetBSD 软件包管理代码 → pkgsrc 与 OpenBSD Ports 分化（1996 起）

**要点**：OpenBSD 1996 年 7 月 fork 自 NetBSD 1.0（首个正式发行版 OpenBSD 1.2），初期共享 NetBSD 软件包管理代码；1996 年后 OpenBSD Ports 在 de Raadt 主导下独立发展，引入 packages 与 ports 分离、签名验证等特性；pkgsrc 与 OpenBSD Ports 从共同起源分化为两个独立系统，反映 BSD 生态的多元化；分化使两系统在软件包数量、依赖管理、安全模型上各自演进

**史料**：OpenBSD Ports 创建档案（1996）；pkgsrc 与 OpenBSD Ports 早期代码 diff；tech-pkg 与 ports@openbsd 邮件列表对比；OpenBSD 官方 changelog（openbsd.org/plus.html）；openbsd.duckdb openbsd-src 仓库 commits 表最早 commit 1995-10-18T08:37:01Z（commit df930be708d5，author = deraadt），当日 deraadt 连续提交 10+ 条 commit，可视为 OpenBSD 仓库正式启动的代码级证据 ［A］

**史观**：总纲第 4 条——分离聚合是永恒规律：OpenBSD Ports 从 NetBSD 软件包管理分离并独立聚合；0 信任原则（考据规则，不设总纲条号）：分化叙事需考据，两系统代码 diff 需对照源码核验

**辨析**：OpenBSD Ports 与 pkgsrc 的分化时间需考据——OpenBSD 1996 年 7 月 fork 后软件包管理何时完全独立需对照 commit log 核验；OpenBSD 1.1 CVS 标签日期（1995.10.18）与 OpenBSD 1.2 首次正式发行日期（1996.7）在不同来源中混用，需对照 OpenBSD 官方发布档案进一步核验。经 openbsd.duckdb openbsd-src 仓库 commits 表验证：1995.10.18 实为 openbsd-src 仓库首条 commit 时间（即 fork 实际启动日），与 “OpenBSD 1.1 CVS 标签日期 1995.10.18” 叙事吻合，但此非 OpenBSD 1.1 发布日期；OpenBSD 1.1 是 fork 后首个公开版本（依 OpenBSD 官方档案，1996 年 1 月发布），OpenBSD 1.2 于 1996 年 7 月发布；故 “1995.10.18” 对应 fork 启动，“1996.1” 对应 1.1 发布，“1996.7” 对应 1.2 发布，三者各自指代不同事件，非混用；deraadt 在 netbsd-src 末条 commit 1994-12-17 与 1994.12.23 决议日期吻合（差 6 天），deraadt 在 openbsd-src 首条 commit 1995-10-18 与 “1995 年下半年开始筹备 fork” 叙事吻合，存疑已解决；两系统软件包数量的具体对比需对照各自统计核验
