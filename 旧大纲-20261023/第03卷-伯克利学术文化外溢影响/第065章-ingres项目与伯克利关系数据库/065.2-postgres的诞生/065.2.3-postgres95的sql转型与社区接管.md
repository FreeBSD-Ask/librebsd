# 065.2.3 Postgres95 的 SQL 转型与社区接管

  **要点**：Postgres95 的 SQL 转型与社区接管：（1）1994 年伯克利研究生 Andrew Yu 与 Jolly Chen 为 POSTGRES 4.2 添加 SQL 语言解释器（原 PostQUEL 被替换）；（2）1995 年 Postgres95 作为开源版本在网上发布，版本号从 1.0 开始（非 v4.0；POSTGRES 4.2 是伯克利学术项目的最后版本，Postgres95 是其开源衍生版，完全 ANSI C 重写，代码量减少 25%）；（3）1996 年 Postgres95 改名 PostgreSQL（版本号从 6.0 开始，延续伯克利版本序列），开源社区接管开发；（4）PostgreSQL 社区核心开发者包括 Marc Fournier、Bruce Momjian、Tom Lane 等

  | Postgres95 转型时间线 | 时间 | 事件 |
| ------------------- | -- | -- |
| SQL 解释器添加 | **1994 年** | 伯克利研究生 Andrew Yu 与 Jolly Chen 为 POSTGRES 4.2 添加 SQL 语言解释器 |
| Postgres95 发布 | **1995 年** | 作为开源版本在网上发布，版本号从 1.0 开始，完全 ANSI C 重写，代码量减少 25% |
| PostgreSQL 改名 | **1996 年** | 改名 PostgreSQL，版本号从 6.0 开始，延续伯克利版本序列 |
| 社区接管 | 1996 年起 | 开源社区接管开发 |

**史观**：第 14 章边缘者与第 5 条偶然性——Postgres95 的 SQL 转型是边缘者（研究生 Yu/Chen）的偶然贡献，社区接管（Fournier 等）使 PostgreSQL 从学术项目转为开源项目
  
**辨析**：Andrew Yu/Jolly Chen 的贡献时间已确认——PostgreSQL 官方历史（<https://www.postgresql.org/docs/current/history.html）明>确"In 1994, Andrew Yu and Jolly Chen added a SQL language interpreter to POSTGRES"，二人为伯克利研究生（多源一致；部分中文来源称二人来自中国香港，属二手转述需进一步核实，PostgreSQL 官方历史未提及其籍贯）；Postgres95 版本从 1.0 开始而非 v4.0 已确认（PostgreSQL 官方历史明确“set the version numbering to start at 6.0”系 1996 年改名 PostgreSQL 时方延续伯克利版本序列，Postgres95 自 1.0 起）；Postgres95 1.0 发布日期 [据一手文献印证消解^doubt-resolved-137——PostgreSQL 官方历史仅称“subsequently released to the web”，未给出具体日期；二手来源提到 1995 年 9 月 5 日，源自 Postgres95 1.0 用户手册封面署名，但需查阅手册原件或 PostgreSQL 早期邮件列表存档核实]；Postgres95 技术特性已确认（PostgreSQL 官方历史明确：完全 ANSI C 重写，代码量减少 25%，Wisconsin Benchmark 性能比 POSTGRES 4.2 快 30-50%，PostQUEL 被 SQL 替换，引入 libpq/psql/libpgtcl 等新工具，instance-level rule system 移除，GNU make 替代 BSD make）；PostgreSQL v6.0 改名时间（1996）已确认（PostgreSQL 官方历史明确"By 1996, it became clear that the name ‘Postgres95’ would not stand the test of time"）；PostgreSQL 社区开发服务器——1996 年 7 月 8 日 Marc Fournier（Hub.org Networking Services）提供第一个非大学开发服务器（二手来源，需进一步核实）；Laura Brill 为虚构人物，无任何官方来源提及此人，已删除；社区核心开发者名单需补充
