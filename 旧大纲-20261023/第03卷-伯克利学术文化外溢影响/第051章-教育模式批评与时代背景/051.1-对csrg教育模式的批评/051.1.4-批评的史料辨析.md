# 051.1.4 批评的史料辨析

  **要点**：对 CSRG 教育模式批评的史料辨析包括：（1）批评多来自事后回忆（如 McKusick **1999 年** 文章），存在记忆偏差与自利偏差；（2）外部观察者的批评可能缺乏对 CSRG 内部的深入了解，存在信息不全；（3）CSRG 内部成员的批评可能受个人恩怨影响，须交叉验证；（4）史料辨析须遵循多源交叉验证方法，对所有批评来源进行考据验证

  | 史料辨析维度 | 具体内容 |
| ---------- | ------ |
| （1）事后回忆 | 批评多来自事后回忆（如 McKusick **1999 年** 文章），存在记忆偏差与自利偏差 |
