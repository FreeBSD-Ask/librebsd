# 051.1.1 学徒制局限的批评

  **要点**：对 CSRG 学徒制局限的批评包括：（1）学徒制依赖师徒个人关系，缺乏制度化培养路径，难以规模化；（2）学徒制的 “做中学” 使理论学习薄弱，CSRG 成员虽擅长系统编程但缺乏形式化方法训练；（3）学徒制的选拔依赖 Fabry/McKusick 等个人判断，存在主观性与偏见；（4）学徒制使 CSRG 文化封闭，难以接纳外部贡献者

  | 批评维度 | 具体内容 |
| ------ | ------ |
| （1）规模化困难 | 学徒制依赖师徒个人关系，缺乏制度化培养路径，难以规模化 |
| （2）理论学习薄弱 | “做中学” 使 CSRG 成员虽擅长系统编程但缺乏形式化方法训练 |
| （3）选拔主观性 | 依赖 Fabry/McKusick 等个人判断，存在主观性与偏见 |
| （4）文化封闭 | 使 CSRG 文化封闭，难以接纳外部贡献者 |

**史料**：CSRG 学徒制批评的内部讨论、CSRG 成员关于学徒制局限的回忆、外部观察者对 CSRG 文化的批评［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L4 事后叙述〕
  
**史观**：专题语（不设总纲条号）——形式与实质分析：学徒制的形式逻辑（师徒传承）吞并了实质的教育公平，形式上的 “做中学” 掩盖了实质的精英选拔
