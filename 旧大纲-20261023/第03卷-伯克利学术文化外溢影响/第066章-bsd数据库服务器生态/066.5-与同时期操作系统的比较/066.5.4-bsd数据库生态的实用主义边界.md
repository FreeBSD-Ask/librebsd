# 066.5.4 BSD 数据库生态的实用主义边界

  **要点**：BSD 数据库生态的实用主义边界：（1）BSD 数据库生态以开源（PostgreSQL、MySQL、SQLite）为主，缺乏商业数据库服务器（Oracle Database、IBM DB2、Microsoft SQL Server、SAP HANA）原生支持；（2）BSD 的实用主义哲学——采用最佳工具而非宗教式坚持自研，体现于 FreeBSD 引入 ZFS（2007-04-06 by Pawel Jakub Dawidek，源自 Sun Solaris/CDDL）、导入 Heimdal 1.5（2011-10-05 by Stanislav Sedov），其依赖促成 base 引入 SQLite（2013-06-18 by Peter Wemm）等决策；（3）BSD 的实用主义边界反映其市场份额与商业支持的局限——商业数据库厂商基于市场份额决策不支持 FreeBSD，使 BSD 数据库生态以开源为主既是哲学选择也是市场约束的产物；（4）BSD 数据库生态的实用主义边界须与 Linux 的商业主导（Oracle/IBM/Microsoft/SAP 全面支持 + Docker/Kubernetes 容器生态）、Windows 的全栈（SQL Server + .NET）、Solaris 的垂直整合（Oracle + ZFS + DTrace）对比理解

  | BSD 实用主义决策表 | 时间 | 决策 | commit/版本 |
| ---------------- | -- | -- | --------- |
| 引入 ZFS | **2007 年 4 月 6 日** | 引入 Sun Solaris/CDDL 的 ZFS 而非自研文件系统 | `f0a75d27` by Pawel Jakub Dawidek |
| 导入 Heimdal 1.5 | **2011 年 10 月 5 日** | 由 Stanislav Sedov 导入 Heimdal 1.5，其依赖促成 base 于 2013-06-18 引入 SQLite（by Peter Wemm），而非自研嵌入式数据库 | by Stanislav Sedov |
| 引入 pkgng | **2014 年 1 月** | FreeBSD 10.0 默认使用 pkgng（SQLite 后端）而非坚持旧版 pkg_install | FreeBSD 10.0 Release |

  | 四象限对比：操作系统数据库生态 | 操作系统 | 路径 | 特征 |
| ---------------------------- | ------ | -- | -- |
| Linux | 商业主导 | Oracle/IBM/Microsoft/SAP 全面支持 + Docker/Kubernetes 容器生态 | |
| Windows | 商业全栈 | SQL Server + .NET | |
| Solaris | 垂直整合 | Oracle + ZFS + DTrace | |
| BSD | 开源主导 + 实用主义采用 | PostgreSQL/MySQL/SQLite + 采用最佳工具 | |

  | BSD 数据库生态的双重性质 | 维度 | 内容 |
| ---------------------- | -- | -- |
| 哲学选择 | 实用主义 | 采用最佳工具而非宗教式坚持自研 |
| 市场约束 | 商业数据库厂商基于市场份额决策 | 不支持 FreeBSD |
| 结果 | 开源为主 | PostgreSQL/MySQL/SQLite |
| 缺失 | 商业数据库服务器原生支持 | Oracle Database/IBM DB2/Microsoft SQL Server/SAP HANA |

**史观**：总纲第 10 条——动手者创造历史；总纲第 9 条——经验优先——BSD 数据库生态作为市场份额的边缘者（份额小但质量高），实用主义边界反映其基于实践（采用最佳工具）而非理论（市场份额或宗教式坚持自研）的哲学
  
**辨析**：BSD 实用主义哲学的具体表现——FreeBSD 引入 ZFS（2007-04-06 by Pawel Jakub Dawidek，源自 Sun Solaris/CDDL）而非坚持自研文件系统，导入 Heimdal 1.5（2011-10-05 by Stanislav Sedov），其依赖促成 base 引入 SQLite（2013-06-18 by Peter Wemm）而非自研嵌入式数据库，引入 pkgng（FreeBSD 10.0，2014-01，使用 SQLite 后端）而非坚持旧版 pkg_install——这些决策反映“采用最佳工具”的实用主义；BSD 数据库生态市场份额较小为多源一致事实，但精确百分比 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］；与 Linux/Windows/Solaris 的对比——Linux 商业主导（商业数据库全面支持 + 容器生态）、Windows 全栈（SQL Server + .NET）、Solaris 垂直整合（Oracle + ZFS + DTrace），BSD 路径为开源主导 + 实用主义采用，四者形成数据库生态的四象限对比
