# 049.4.3 BSD 在全球大学的学术采用

  **要点**：BSD 在全球大学的学术采用包括：北美（MIT、Stanford、CMU、伯克利、多伦多大学）、欧洲（Vrije 大学、爱丁堡大学、KTH）、亚洲（东京大学、清华、台湾大学），**1980-1990 年代** BSD 成为全球大学计算机系的标准教学与研究平台；统计结论 [C-41] references 表总数 16,867 条（考据时点 2026-07-27 数，2026-09 复核现库 17,355 条），[C-42] 年份提取率 44.42%（7,493/16,867），CSRG 时期（1969-1995）累计 1,879 条占比 25.08%——CSRG 时期参考文献占比四分之一强，反映 BSD 全球大学学术采用对文献产出的推动；外部基准对照（统计结论 E-04、E-05）——Apache 软件基金会 Top 4 项目（Spark、HTTP Server、Hadoop、Kafka）GitHub 镜像 commit 总量 130,196（Spark 49,256 + HTTP Server 34,727 + Hadoop 28,289 + Kafka 17,924），Apache 全基金会志愿者 FY2021-2022 为 8,200 人、运营 350+ TLP（Top Level Project）；CSRG 时期（1969-1995）BSD 学术文献产出（1,879 条参考文献）与 Apache 软件基金会当代组织规模（8,200 志愿者、350+ TLP）的对照反映 “学术驱动型社区”（BSD/CSRG）与 “基金会驱动型社区”（Apache）两种开源组织模式的代际差异——CSRG 时期 BSD 以大学学术网络为核心，Apache 以基金会伞形组织为核心，二者不可直接对比但可作历史演化参照

  | 地区 | 代表大学 | 采用 BSD 时期 | 采用形式 |
| -- | ------ | ----------- | ------ |
| 北美 | MIT、Stanford、CMU、伯克利、多伦多大学 | **1980-1990 年代** | 教学与研究平台 |
| 欧洲 | Vrije 大学、爱丁堡大学、KTH | **1980-1990 年代** | 教学与科研部署 |
| 亚洲 | 东京大学、清华、台湾大学 | **1980-1990 年代** | 教学与研究平台 |

**史料**：**1980-1990 年代** BSD 大学采购记录、各大学 CS 系历史、BSD 用户邮件列表 ［A］；资料数据库.duckdb 文献计量学统计（C-41、C-42）——references 表总数 16,867 条（考据时点 2026-07-27 数，2026-09 复核现库 17,355 条），年份提取率 44.42%（7,493/16,867），CSRG 时期（1969-1995）累计 1,879 条占比 25.08%；SQL 查询 `SELECT COUNT(*) FROM "references"` 与 `SELECT strftime('%Y', ingest_date) AS year, COUNT(*) FROM "references" GROUP BY year`，〔存疑：按 ingest_date 分组无法产出出版年口径的统计结论，实际提取 SQL 待考〕；Python 脚本执行留痕见 `03-原始史料库/01-代码仓库史料/01-数据库本体/统计分析/文献计量学分析.md` Task 22；外部基准报告（E-04、E-05）——Apache Top 4 项目 commit 数据来源 GitHub `apache` 组织页面（`github.com/apache/spark`、`github.com/apache/httpd`、`github.com/apache/hadoop`、`github.com/apache/kafka`，2026-07-27 获取），Apache 志愿者数与 TLP 数来源 ASF IRS Form 990 税务披露文件（`apache.org/foundation/records/990-2021.pdf`，FY2021-2022）
  
**史观**：第 5 条偶然性——BSD 全球学术采用是多重偶然事件叠加的产物，AT&T 1956 同意令的低成本分发是关键偶然因素；统计结论 [C-41] 印证——references 表 CSRG 时期（1969-1995）累计 1,879 条占比 25.08%，与总纲第 5 条 “没有必然性只有偶然性” 形成量化印证（AT&T 1956 同意令的低成本分发偶然性推动 BSD 学术传播与文献产出），但须遵循 0 信任原则——统计显著 ≠ 实际显著，CSRG 时期文献占比亦可能受同期 UNIX 研究整体扩张影响，不得单凭此数据归因于 BSD 全球学术采用的效应；统计结论 [E-04]、[E-05] 印证——Apache 软件基金会当代组织规模（8,200 志愿者、350+ TLP、Top 4 项目 commit 130,196）与 CSRG 时期 BSD 学术网络形成历史对照，印证总纲第 4 条 “分离聚合是永恒规律”——BSD 学术传播将大学网络（聚合）转化为文献产出（分离），Apache 基金会则将分散项目（分离）聚合为伞形组织（聚合），两种模式皆为分离聚合律的体现，但组织形态从 “学术网络” 向 “基金会伞形组织” 的演化反映开源社区组织模式的代际变迁
  
**辨析**：BSD 全球采用的 “具体范围” 需核对，避免事后夸大，需核对各大学实际采购记录；统计局限性标注——references 表年份提取率仅 44.42%（7,493/16,867），超半数文献缺年份字段，CSRG 时期占比 25.08% 为提取年份后的子集统计，不得外推为全表结论；外部基准方法学局限——(1) Apache Top 4 项目 commit 总量 130,196（E-04）为 GitHub 镜像数据，与 `gitbox.apache.org` 主仓库可能存在克隆时点差异，且 Apache 聚合多项目与 BSD 单一 src 仓库不可直接对比；(2) Apache 志愿者数 8,200（E-05）来自 IRS Form 990 自行估计填报，“志愿者” 定义模糊（非严格意义上的 Committer 或 Contributor），ASF 历年填报数字波动较大（FY2019-2020 为 6,000，FY2020-2021 跳升至 8,200），可能反映统计口径调整而非实际人数变化；(3) CSRG 时期（1969-1995）与 Apache 基金会（1999 成立）存在时间错位，E-04、E-05 仅作组织模式演化的历史参照，不构成 CSRG 时期 BSD 教育文化本身的对照基准；(4) 0 信任原则适用：Apache 数据为外部基准，其统计口径与本书 references 表不兼容，不得直接相减或相除得出 “BSD vs Apache” 的强弱结论
