# 050.1.1 反文化运动对伯克利技术文化的土壤作用

  **要点**：**1960-1970 年代** 反文化运动（counterculture）对伯克利技术文化的土壤作用为：反战运动、嬉皮士运动、民权运动形成 “反权威、自由、共享” 的文化氛围，此氛围为 CSRG 的 hacker 伦理与 BSD 开源传统提供文化土壤，但影响为间接而非直接

  | 反文化运动 | 文化氛围 | 对 CSRG/BSD 的土壤作用 |
| -------- | ------ | -------------------- |
| 反战运动 | 反权威 | CSRG hacker 伦理的反权威倾向 |
| 嬉皮士运动 | 自由 | BSD 开源传统的自由理念 |
| 民权运动 | 共享 | BSD 开源共享传统 |

**史料**：伯克利反文化运动档案、CSRG 成员访谈、伯克利校园文化变迁记录 ［B］
  
**史观**：第 5 条偶然性——反文化运动是文化偶然事件，但此偶然为 CSRG 技术文化提供土壤
  
**辨析**：土壤作用的 “具体机制” 需核对，避免事后归因，需区分 “文化土壤” 与 “直接因果”
  
**文献**：Roszak, T. (1969) “The Making of a Counter Culture”；伯克利反文化运动档案；CSRG 文化访谈 ［B］
