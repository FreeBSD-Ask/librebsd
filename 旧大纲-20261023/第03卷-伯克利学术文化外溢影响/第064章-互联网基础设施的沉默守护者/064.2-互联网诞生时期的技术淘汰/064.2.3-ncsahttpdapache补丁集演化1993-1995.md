# 064.2.3 NCSA httpd → Apache 补丁集演化（1993-1995）

  **要点**：1991 年 Tim Berners-Lee 在 CERN 发布万维网（World Wide Web），1993 年 Rob McCool 在伊利诺伊大学 NCSA（National Center for Supercomputing Applications）开发 NCSA httpd 0.1 作为万维网服务器；NCSA httpd 基于 BSD 套接字 API 与 HTTP/0.9 协议（1991），是早期万维网主流服务器；1994 年中期 McCool 离开 NCSA 加入 Netscape，NCSA httpd 开发停滞，社区补丁积压，Brian Behlendorf（布莱恩·贝伦多夫） 等社区成员组织 “NCSA httpd 补丁集” 维护项目；1995 年 2 月 Apache httpd 0.6.2 发布（基于 NCSA httpd 1.3 补丁集，名称 “a patchy server” 双关），Apache 1.0（1995.12）正式独立于 NCSA httpd；NCSA httpd 在 1995 年后被 “淘汰” 为 Apache httpd，Apache 长期主导互联网 Web 服务器市场（1996 年起超越 NCSA httpd，2000 年代占 Web 服务器市场约 60% 份额）；Apache httpd 后被 Nginx（Igor Sysoev 2004 年发布，BSD 许可证）与 lighttpd（Jan Kneschke 2003 年发布，BSD 许可证）等替代品部分挑战，但 Apache 在 BSD 与 Linux Web 服务器市场仍占重要份额

**史观**：第 9 条经验优先——Apache 是工程实践驱动（补丁集维护）而非 Web 服务器理论先行，“a patchy server” 双关体现社区补丁集的实践起源；BSD 反向影响线——Apache 在 BSD 系统上长期主导 Web 服务器市场，是 BSD 反向影响互联网基础设施的具体呈现
  
**辨析**：NCSA httpd 被 “淘汰” 为 Apache 指 Apache 主线代码基于 NCSA httpd 补丁集演化，但 Apache 1.0（1995.12）后逐步重写大部分代码，须区分 “补丁集阶段”（Apache 0.6.2-0.8.x）与 “独立重写阶段”（Apache 1.0+）；Nginx/lighttpd 替代 Apache 是 2000 年代后演化，须区分 “1995-2000 年代 Apache 主导” 与 “2000 年代后期 Nginx 挑战”；“a patchy server”双关名称来源在不同史料中描述详略不一，腾讯云开发者社区等多源确认“A Patchy Server”与“Apache”为谐音双关，但 Apache 早期邮件列表（apache-httpd-dev 1995 年存档）的原始记录保留 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］
