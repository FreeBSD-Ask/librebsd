# 322.3.3 专利流氓对 BSD 商业用户的威胁

**要点**：2000 年代后期起，非实施实体（NPE）如 IP Innovation、Uniloc 对 BSD 商业用户（如 Apple、NetApp）发起专利诉讼，BSD 许可证的“不提供专利保护”特性使用户需自行承担专利风险
