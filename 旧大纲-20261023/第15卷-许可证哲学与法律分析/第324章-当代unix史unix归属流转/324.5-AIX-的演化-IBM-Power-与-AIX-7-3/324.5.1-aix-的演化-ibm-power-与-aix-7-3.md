# 324.5.1 AIX-的演化-IBM-Power-与-AIX-7-3

**要点**：

AIX（Advanced Interactive eXecutive）1986 年首次发布（AIX 1.0，基于 RT/PC），1990 年 AIX 3.1 随 RS/6000 发布；1994 年 AIX 4.1 发布，引入 PowerPC 601/604 支持、Journaled File System 2（JFS2）、Workload Manager（WLM）雏形；1997 年 AIX 4.3 引入 64 位支持（首个 64 位 UNIX 之一，与 Solaris 7 同年）、TCP/IP v6 协议栈、Java 集成；1999 年 AIX 4.3.3 引入 Workload Manager 正式版。
2001 年 AIX 5L 发布（L 代表 Linux affinity），引入 Linux 应用二进制接口（ABI）兼容性（通过 lxrun 与 AIX Toolbox for Linux Applications）、JFS2 默认文件系统、NUMA 支持；2007 年 AIX 6.1 引入 Workload Partition（WPAR，类似 Solaris Zones 的容器技术）、Live Application Mobility、Trusted AIX（Mandatory Access Control）。
2010 年 AIX 7.1 引入 Power 7 平台支持、Kernel WPAR、跨 LPAR 线程调度；2015 年 AIX 7.2 引入 Power 8/9 平台支持、加密虚拟化、AIX Live Update（无需重启打补丁）；2021 年 AIX 7.3 引入 Power10 平台支持、改进的 RAS（Reliability, Availability, Serviceability）、增强的容器支持（通过 AIX Container for Linux Applications，运行 Linux 二进制）。
IBM POWER 芯片谱系：POWER1（1991，RS/6000）、POWER2（1993）、POWER3（1998，首个 64 位 Power）、POWER4（2001，首个多核 PowerPC）、POWER5（2004，SMT）、POWER6（2007，5GHz 高频）、POWER7（2010，8 核 32 线程）、POWER8（2014，12 核 96 线程，OpenPOWER 基金会成立）、POWER9（2017，14nm，CAPI/NVLink 加速）、Power10（2021，7nm，24 核 8 线程，Memory Persistence）；2024 年 IBM 公布 Power11 路线图（预计 2025-2026 量产，5nm 工艺，AI 加速增强）。
2026 年 7 月 27 日现状：AIX 7.3 TL5（Technology Level 5）为最新版本，运行于 Power10 服务器（E1080、S1022、S1024），主要客户为银行业核心系统、政府数据中心、SAP HANA 大型部署；IBM i 7.5（前 AS/400 OS/400）与 AIX 7.3 在同一 Power 平台共栖，IBM i 客户可通过 PASE（Portable Application Solutions Environment）运行 AIX 二进制；Power11 路线图仍在推进，但 IBM 已将战略重心转移至 RHEL on Power 与 IBM Cloud Power Virtual Server。

**总纲 4（分离聚合是永恒规律）**——见原文第 4 章 4.1 节：

> “分离聚合是世界发展的规律。分久必合，合久必分，具有必然性。”

IBM AIX 与 IBM i（前 AS/400 OS/400）从分离（两个独立操作系统，OS/400 面向 AS/400、AIX 面向 RS/6000）到聚合（Power 平台统一硬件后，AIX 与 IBM i 共栖于同一服务器，IBM i 通过 PASE 运行 AIX 二进制）；AIX 与 Linux 从分离（AIX 5L 之前完全独立）到部分聚合（AIX 5L 引入 Linux affinity，AIX 7.3 引入 AIX Container for Linux Applications）——这一系列分离聚合并非线性进步，而是 IBM 在不同历史阶段对硬件平台与操作系统生态的主体性选择。

**总纲 3（不存在进步，只有权力再分配）**——见原文第 3 章 3.2 节：

> “所谓进步只不过是权力再分配，把演讲台上的人割一茬，换他来一个样。”

IBM 从 POWER8 起发起 OpenPOWER 基金会（2013），将 Power 架构授权给第三方厂商（Tyan、Wistron、Inspur、Hitachi 等），并非 “IBM 开放 Power 架构” 的技术进步，而是商业资本的权力再分配——IBM 试图通过开放 Power 架构对抗 Intel x86 在企业市场的垄断，将 Power 生态的资源从 IBM 独占重新分配至联盟厂商。所谓 “OpenPOWER 民主化 Power 架构” 的叙事，掩盖了 IBM 真正的动机（市场份额保卫战）。

**总纲 5（没有必然性，只有偶然性）**——见原文第 5 章 5.2 节：

> “将英雄人物的出现必然化是一种机械的错误，没有认识到偶然性和自由的意义。”

AIX 7.3（2021）引入 AIX Container for Linux Applications，并非 “AIX 必然走向 Linux 兼容” 的进步，而是依赖多重偶然——若 IBM 未在 2019 年收购 Red Hat（340 亿美元），若 Red Hat Enterprise Linux 未在企业市场占据主导地位，AIX 7.3 可能不会引入 Linux 兼容特性。所谓 “AIX 必然与 Linux 融合” 的叙事是史家的事后重构。

**总纲 10（动手者创造历史）**——见原文第 14 章 14.1-14.2 节：

> “这个世界不是靠什么精英也不是靠什么人民更不是靠什么其他人运转的，而是我们这些老实人，才让世界运转了起来。”

AIX 工程师团队（Austin、Rochester、Boeblingen 研发中心）亲自实现 JFS2、WLM、WPAR、Live Update 等特性；IBM POWER 芯片设计团队（Austin、Rochester）亲自设计 POWER1 至 Power10 的指令集与微架构——这些是动手者的实践，而非 “IBM 决定” 等高管决策的产物。须注意：IBM 高管的资助是外部条件，但 AIX 与 POWER 的具体设计与实现是工程师的主体性选择。

**总纲 2（历史是形式主义化的非存在）**——见原文第 2 章 2.5 节：

> “谁试图诠释历史，谁就在篡改历史。”

所谓 “AIX 演化史（1994-2026）” 的判定本身即形式主义化的非存在——若以 POWER 芯片演化为主线，若以 IBM i（OS/400）谱系为主线，若以 AIX 在中国市场的特殊地位为主线（中国银行业核心系统长期依赖 AIX），“AIX 史” 会呈现完全不同的脉络。本子节选取 “AIX 版本演化+POWER 平台演化” 为主线，但这一选取本身须以自反性声明显化。

**自反性声明**：本子节选取 “AIX 4.1→7.3+POWER1→Power10” 为 AIX 谱系演化主线，但这一选取本身即形式主义化的非存在。若以 IBM i（OS/400）谱系为主线，若以 AIX Linux affinity 演化为主线，若以 AIX 在银行业的应用为主线，“AIX 史” 会呈现完全不同的脉络。本子节承认主轴选取本身是史家的形式主义化决策，欢迎被更自反的释读所超越。

**辨析**：

**AIX 5L 与 Linux affinity 辨析**：部分二手资料称 “AIX 5L 可运行 Linux 二进制”，但 AIX 5L 实际通过 lxrun 兼容层与 AIX Toolbox for Linux Applications（重新编译的 Linux 开源软件）实现 Linux 兼容性，并非原生运行 Linux 二进制；AIX 7.3 的 AIX Container for Linux Applications（ACLA）才部分实现 Linux 二进制原生运行（通过内核级 Linux 系统调用翻译）。本子节采用 “AIX 5L 通过 lxrun 与 AIX Toolbox 实现 Linux 兼容性（非原生），AIX 7.3 引入 ACLA 部分原生运行” 的限定性表述。

**AIX 7.3 与 Power10 关系辨析**：部分二手资料称 “AIX 7.3 专为 Power10 设计”，但 AIX 7.3 同时支持 Power8、Power9、Power10，Power10 特性（如 Memory Persistence、AI 加速）需要 AIX 7.3 TL3+ 才能完整利用。本子节采用 “AIX 7.3 支持 Power8/9/10，Power10 完整特性需 TL3+” 的限定性表述。

**Power11 路线图辨析**：IBM 于 2024 年公布 Power11 路线图，但截至 2026 年 7 月 27 日，Power11 芯片尚未正式量产；部分二手资料称 “Power11 将于 2025 年量产”，但 IBM 官方未给出具体量产日期。本子节采用 “Power11 路线图推进中，截至 2026 年 7 月未正式量产” 的限定性表述。

**IBM i 与 AIX 关系辨析**：IBM i（前 AS/400 OS/400）与 AIX 是两个独立操作系统，但自 Power5 起可在同一 Power 服务器上共栖（通过 LPAR 或 PowerVM 虚拟化）；IBM i 通过 PASE（Portable Application Solutions Environment）运行 AIX 二进制，但 IBM i 内核与 AIX 内核不同。本子节采用 “IBM i 与 AIX 独立但共栖，IBM i 通过 PASE 运行 AIX 二进制” 的限定性表述。
