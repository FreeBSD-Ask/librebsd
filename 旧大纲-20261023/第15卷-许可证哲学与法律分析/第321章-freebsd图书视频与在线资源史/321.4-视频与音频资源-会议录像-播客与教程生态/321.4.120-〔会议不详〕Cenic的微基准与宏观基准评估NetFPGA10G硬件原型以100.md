- 〔会议不详〕Cenic 的微基准与宏观基准评估。NetFPGA-10G 硬件原型以 100 MHz 综合出 1000 个硬件限流器（比 Intel 82599 的 128 个高一个数量级），平均包间时延与理想 pacer 偏差仅 0.038% 且标准差极低，每次调度决策 5 次 SRAM 查询约 50 纳秒，远低于 40 Gbps 下传输一个 MTU 包的 300 纳秒预算。软件原型实验中 10 个 Memcached 租户（共享 6 Gbps 限速）与后台 3 Gbps UDP 租户争用下，Cenic 在 97% 负载仍保持 4 毫秒的 99.9 分位尾时延并逼近视配吞吐，显著优于 Linux 事实标准 HTB 与多核友好的 PTB；TSO 通过逐 MTU 段 DMA 头部与载荷实现交错传输，所需约 650 万次/秒 DMA 远低于实测 Mellanox 40G 网卡 1300-1400 万次/秒的持续能力。讲者会后并就 Intel 82599 等商用网卡移植问题答疑，称多数部件已存在只需重组流水线。（YouTube EPIkf4tzD8cU8，[587.5-1252.7]，L1）
- 〔会议不详〕自动机引导的控制流敏感模糊测试驱动生成。主讲人 Chen Zhang（南洋理工大学 Continental-NTU 企业实验室，与香港理工大学、西安电子科技大学、新加坡管理大学合作）指出模糊测试强依赖目标可执行，而大量代码以库 API 形式提供，需人工编写 fuzz driver（如 Google OSS-Fuzz 中由安全审计员与开发者维护、7 年累计发现数万 bug），耗时费力。关键观察是现有方案（FuzzGen、FuzzCraft 等）遵循先学习后合成的范式，却未能正确建模 API 用法中的条件分支与循环等控制流依赖，损害驱动有效性；团队因此选用自动机作为使用模型，定义 API 函数事件（执行 API 并绑定返回值）与条件事件（布尔表达式满足）来表示 API 序列与分支。（YouTube EPIoaU7-CjZpk，[8.6-345.5]，L1）
- 〔会议不详〕循环建模与 Rubik 原型评估。自动机按初始化器、增量器与停止条件三个组件分三种情形由简到繁建模循环，对非 API 的迭代逻辑（如遵循常见迭代器接口的成员函数）引入 mock API 事件包装，并用静态分析识别循环变量的数据流传播。框架含三个环节：静态分析提取原始自动机、经去噪去重的蒸馏组件与自动机主动学习合并为统一自动机、以及更有效利用自动机引导喂送的利用组件。Java 库原型 Rubik 在 Apache 等流行库（示例爬取自 GitHub、GitLab）的评估中优于现有方案且误报率最低，并成功猎得可利用于多款流行 Android 应用的新 bug。（YouTube EPIoaU7-CjZpk，[423.3-756.7]，L1）
- 〔会议不详〕Swoosh：高效格基非交互式密钥交换。讲者 Philip Gai 与 Miguel（与 Giulio Malavolta、Peter Schwabe 合作）指出 Diffie-Hellman 密钥交换广泛部署但无后量子安全，NIST 后量子标准化聚焦于天生两阶段交互的 KEM（如 Classic McEliece、Kyber），而民间共识认为格上 NIKE 不实用。他们在具体参数（而非渐近 regime）下给出可行方案：模块格 LWE 上的 NIKE，双方广播短范数秘密向量导出的 LWE 公钥，共享密钥推导需确定性协调过程消除 s 与 e 项差异；由于需较大 β、d、n 保证 LWE 硬度，须以更大模数补偿正确性误差，并定义更强的半恶意正确性（Bob 可在见 Alice 公钥后构造正确性误差，以双方公钥哈希的随机标量纳入协调过程应对）。（YouTube EPIpavvH9hJm0，[20.5-400.4]，L1）
- 〔会议不详〕主动安全、参数选择、实现与比较。通过非交互零知识证明（对“我知道公钥对应秘密”语言的证明附于公钥）由被动安全获得更强主动安全。Miguel 介绍参数取舍：214 比特素数模数（需多精度算术）、256 次多项式与数论变换（NTT），NTT 原位执行并将矩阵 A 与公钥存于 NTT 域可近乎减半变换次数；PRF 用 AES-256 计数器模式，随机偏移计算用 cSHAKE-256。被动 Swoosh 以 Rust 与 Jasmin（转写作 Jasmine）实现，达到对量子敌手 120 比特安全，公钥小于 Classic McEliece、密钥生成与共享密钥推导快于 NTRU；比较显示 ECDH 最快但无后量子安全，Kyber 与 Classic McEliece 等 KEM 需交互。（YouTube EPIpavvH9hJm0，[439.2-795.0]，L1）
- 〔会议不详〕CascadeNet：时序模式高保真的网络流量生成框架。主讲人 Xinyu Li（卡内基梅隆大学，与 NYU 上海、北京大学、USTC、HKUST 合作）指出隐私与专有限制使真实轨迹获取困难，而现有 ML 生成器无法刻画包速率、吞吐、突发性等时序模式：EWGAN-GP 完全扭曲包速率模式，最先进的 NetShaper 甚至学到不存在的周期模式。根因在数据表示（独立记录忽略时序、数万包的长序列难学长期依赖、按流切分仍受大象流拖累），核心洞察是时序模式为跨记录聚合特征，应先将轨迹按流切分再聚合成定长包计数时间序列，显式将模式暴露给模型并获得与包数无关的可扩展性。（YouTube EPIqqK2xe7J3g，[17.9-436.0]，L1）
- 〔会议不详〕CascadeGAN 分层生成模型与评估结果。CascadeGAN 由三对生成器-判别器从粗到细构成（MLP 生成五元组、LSTM 生成聚合时间序列、MLP 以时间序列滑动窗口生成记录字段），两阶段训练（先以真实输入分对预训练再联合微调）避免“级联发散”；后处理以 ML 法恢复时间戳，零膨胀法应对高达 88% 的稀疏零值，流级条件输入（流时长、最大包速率）抑制模式坍缩。在 KDD、DC、CA、TON IoT 四个 IPv4 轨迹上对比 6 类基线：时序保真（EMD）提升 41%-76%，统计保真相当，下游突发分析（IMC 方法）、吞吐预测与异常检测（NetML 一类 SVM）均领先；99.9% 以上生成记录异于训练数据（对比 RealFormer 记忆 1.7%-56.5%），训练快 7-25 倍、生成快 9-62 倍。（YouTube EPIqqK2xe7J3g，[439.7-871.7]，L1）
- 〔会议不详〕IHOP：基于二次优化的可搜索加密统计查询恢复攻击。主讲人 Simon 与导师 Florian Kerschbaum（均为滑铁卢大学）指出加密搜索索引虽保护数据内容却泄露访问模式，敌手可借助统计相似但不相交的辅助数据集计算体量共现矩阵（对角为关键词热度、非对角为两关键词共有文档数），并以点积从访问模式得到观测矩阵，进而匹配查询令牌与关键词。该问题可一般化为二次分配问题（NP 难）；既往攻击或用次优启发式算法，或忽略非对角项仅按对角体量做线性分配（匈牙利算法）——即其团队去年在 USENIX 发表的工作——导致 dog/cat 这类体量相近的关键词极易混淆。（YouTube EPIqzH4PDTaBk，[8.5-354.5]，L1）
- 〔会议不详〕迭代冻结攻击、实验与 Pancake 防御适配。IHOP 从全指派出发，随机冻结部分指派并把冻结信息计入距离矩阵，对余下关键词-查询求解线性分配问题并持续迭代；虽无收敛证明但所有实验均收敛，且每轮迭代高效并利用共现信息。对称设定（对 N 个关键词全部查询）下准确率近乎完美且随关键词数几乎不降，1000 关键词约 15 分钟完成而图匹配需近 3 天；非对称设定（500 个查询对更多关键词）也远胜其他攻击。将攻击适配 Pancake 防御（使各文档访问频率近乎均匀、倍增数据集并加入哑文档与哑查询）后发现：当 Alice 的查询按马尔可夫过程相关时防御并不完备，部分运行或数据集上攻击准确率可超 80%。（YouTube EPIqzH4PDTaBk，[355.2-723.2]，L1）
- 〔会议不详〕Binoculars：利用页表遍历器的无状态间接侧信道。主讲人 Neil Zhou（伊利诺伊大学）提出首个无状态间接信道——Intel 处理器上的跨超线程信道：一线程 TLB 缺失触发的页表遍历加载（经 L1 缓存、地址比特 11-3 由对应 9 比特页级索引决定）与兄弟线程普通内存访问发生 4KB 别名（共享比特 11-0）争用时，页遍历操作可被延迟至多 20000 周期，且与页遍历加载命中的缓存层级无关。据此构造两个攻击原语：store-to-load 信道（攻击者读、受害者写）以 8 字节子缓存行粒度泄露受害者存储偏移（演示中写者持续写向秘密偏移 0x528），load-to-store 信道（攻击者写、受害者页遍历）泄露所访问页的页级索引集合，配合附加信息可重建完整虚拟页号。（YouTube EPIrsH83JSyCs，[7.7-385.2]，L1）
- 〔会议不详〕根因逆向与端到端攻击。借助性能计数器（含未公开计数器）与 Intel 专利逆向确认：争用源于将页遍历加载作为 stuffed load 发出以绕过指令调度器避免调度时延的优化——调度器无法察觉 stuffed flow 与普通 store 的冲突，写者全速运行而读者饿死，直至看门狗在约 20000 周期后以更高优先级中止并重启页遍历。端到端攻击针对用 Montgomery ladder 加速的 ECDSA 签名实现：代码存在依赖密钥的 store 重排（ki 为 1 时 madd/mdouble 写 x1/z1，为 0 则顺序反转），用 store-to-load 信道监控大数变量并对原始时延轨迹做信号处理恢复迭代边界，单次受害者执行即以高准确率与有限剩余暴力枚举恢复 nonce 并导出私钥；论文还展示对 Linux 内核 ASLR 的攻击，绕过软件缓解并达 100% 准确率。（YouTube EPIrsH83JSyCs，[421.9-766.8]，L1）
- 〔NDSS（推测）〕NetHide：抗链路洪泛攻击的网络拓扑混淆。ETH Zurich 研究者（与 Peter Tschentscher、Laurent Vanbever 等及 Armasuisse 的 Solenders 合作，转写中姓名为音译）指出链路洪泛攻击不同于传统 DoS：僵尸网络从多源向多目的地发送大量小流，但全部交叉同一目标链路并使其拥塞（曾真实发生于一家安全邮件服务商），极难检测；其前提是攻击者获知拓扑（如 traceroute 递增 TTL 逐跳探测，且公共测量平台可代劳），而完全隐藏拓扑会剥夺合法用户调试连通性的主要手段（nanog 邮件列表为证）。NetHide 以现有物理拓扑为输入求虚拟拓扑：对链路洪泛鲁棒（每链路流密度不超过容量）且具最大实用性（准确性——虚实路径相似；效用——如实呈现链路失效），建模为 ILP 并对每节点转发行为随机采样以将指数解空间降为线性、同时增强混淆不可逆性。（YouTube EPIsLiNMH7LBM，[10.2-714.4]，L1）
- 〔NDSS（推测）〕基于 P4 的部署与评估。为让 traceroute 依然工作、不影响网络性能并可扩展到大型网络，NetHide 不用中心代理或虚拟仿真（会丢失真实链路失效），而是让探测包穿过真实网络：用 P4 可编程数据平面改写包头使包在虚拟路径所示路由器处过期，并在发送前将原始包内容编码进附加自定义头、应答返回时读回还原，从而在可编程设备中零动态状态。中等规模拓扑实验显示：即便在 80% 流密度削减（强混淆）下准确性与效用仍保持高值，且 82% 的路径完全未加改动、调试能力不受影响；Q&A 说明方案要求被混淆路径上至少一台路由器支持 P4，主要面向单运营商网络而非互联网，时序侧信道难以奏效因为探测时延主要由路由器生成 ICMP 应答的控制面主导。（YouTube EPIsLiNMH7LBM，[747.1-1415.7]，L1）
- 〔会议不详〕Unix 的诞生：从 Multics 溃败到 PDP-7 上的三周。视频叙述 1964 年 MIT、通用电气与贝尔实验室合作构建分时计算公用系统 Multics（运行于 GE 645 大型机），因臃肿昂贵、承诺迟迟不至，1969 年 AT&T 撤资退出；Ken Thompson 与 Dennis Ritchie 吸收其层次文件系统等思想，认为错的只是规模。1969 年夏 Thompson 趁妻子携子赴加州探亲的三周独自在无人要的废弃 DEC PDP-7 上写出第一版 Unix（直接动因是寻找运行其 Space Travel 游戏的机器），1970 年又借专利部门文字处理需求换得 PDP-11 与正式预算。此后 1972 年 McIlroy 倡导的管道落地（竖线记号）并确立“写程序只做好一件事并使之协同工作”的 Unix 哲学，1973 年用由 B 发展而来的 C 语言重写内核，1978 年移植到 Interdata 8/32 证明操作系统可脱离硬件；而 1956 年反垄断同意判决禁止 AT&T 进入计算机业务，反而迫使 Unix 以近乎工本费的代价向大学开放完整源码，造就一代在 Unix 内核上成长的学生。（YouTube EPIt5Nb03YmoU，[0.0-1455.0]，L1）
- 〔会议不详〕伯克利崛起、诉讼反噬与 Unix 的最终胜利。视频后半讲述 Thompson 1975 年休假回到伯克利播下种子，Bill Joy 1977 年将改进打包为 1BSD（含 Pascal 编译器与 ex 编辑器）、1978 年 2BSD 携 vi 与 C shell 问世，DARPA 选中伯克利 Unix 资助 CSRG 并要求将 TCP/IP 深植于 4.2BSD（1983），使 Unix 与互联网共同成长。1984 年 AT&T 解体使其摆脱 1956 年限制，随即商用化 System V、抬高许可费并禁止源码用于教学（催生 Tanenbaum 的 Minix），SunOS/HP-UX/AIX/Xenix 等专有变体造成碎片化与 Unix 内战（System V 阵营对阵 Open Software Foundation）。1991 年伯克利发布仅缺 6 个文件的 Networking Release 2，BSDI 以 995 美元销售含源码的 386 BSD 并打出“1-800-ITS-UNIX”广告，1992 年 USL 起诉 BSDI 与加州大学，令 BSD 冻结两年，为 Linus Torvalds 基于 GPL 的 Linux（1991）填补空缺——Torvalds 自言若 386 版 BSD 当时可用“Linux 可能根本不会发生”。1994 年庭外和解后 4.4BSD-Lite 成为 FreeBSD/NetBSD/OpenBSD 的基础；如今 macOS 获 Unix 认证、Android 与绝大多数服务器、超算、云端运行 Linux，而 AT&T 早在 1993 年便将 Unix 业务售予 Novell，几乎一无所得。（YouTube EPIt5Nb03YmoU，[1472.8-3042.6]，L1）
- 〔SREcon〕Honeycomb 联合创始人 Charity Majors（联合作者 Liz Fong-Jones 在场）在 SREcon 演讲《Is It Already Time to Version Observability?》，提出可观测性（observability）一词定义泛滥、持续被重新定义。她主张把可观测性定义为复杂系统（社会技术系统）的一种属性，如同可靠性与性能，描述的是系统而非工具，并以语义版本为框架区分 Observability 1.0（基于指标/日志/追踪三支柱、多个工具、静态仪表盘、写时聚合、面向 MTTR 等运维场景）与 Observability 2.0（单一事实来源、任意宽的结构化事件、高基数、探索式交互、从 SLO 下钻到单个请求）。（YouTube EPItFc1YsVHN8，[124-506]，L1）
