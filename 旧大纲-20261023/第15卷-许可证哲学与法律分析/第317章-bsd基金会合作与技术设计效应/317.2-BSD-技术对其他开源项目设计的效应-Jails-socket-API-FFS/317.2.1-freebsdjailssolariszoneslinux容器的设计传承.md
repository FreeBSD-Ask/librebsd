# 317.2.1 FreeBSD Jails → Solaris Zones → Linux 容器的设计传承

**要点**：FreeBSD Jails 由 Poul-Henning Kamp（波尔-亨宁·坎普） 于 2000 年 3 月随 FreeBSD 4.0 发布，为 R&D Associates 解决多租户主机隔离问题，原始论文由 Kamp 与 Robert Watson 合著；Jails 在 chroot 基础上扩展进程隔离、网络隔离、文件系统隔离与系统调用限制；Solaris Zones（2005 年 1 月 31 日随 Solaris 10 FCS 发布，先前叙事称 “2004 年随 Solaris 10 发布” 有误，Solaris 10 FCS 实际发布日期为 2005-01-31；设计论文 Price 与 Tucker 于 LISA 2004 年 11 月会议发表，早于 FCS 两个月）由 Sun 工程师 Daniel Price 与 Andrew Tucker 设计（先前叙事称 “Dennis Clarke 等开发” 有误，Dennis Clarke 为 Solaris 系统管理员与社区倡导者，非 Zones 设计者；Price 与 Tucker 的 LISA 2004 论文 "Solaris Zones: Operating System Support for Consolidating Commercial Workloads" 明确署名二人为 Sun Microsystems 工程师），明确借鉴 Jails 设计；Linux 容器（LXC，2008 年；Docker，2013 年 3 月首次发布）基于 Linux cgroups（2007 年改名并入 2.6.24，2008 年 1 月）与 namespaces（2002 年起逐步加入，mount namespace 始于 Linux 2.4.19），设计灵感部分源自 Jails 与 Zones；Jails 早于 Docker 13 年，但 Docker 的市场推广使 “容器” 概念流行化

**史料**：FreeBSD 4.0 release notes（2000.3）、Kamp-Watson Jails 论文（papers.freebsd.org/2000/phk-jails/）、Solaris 10 3/05 release 文档（docs.oracle.com/cd/E19957-01/820-2714/）、Price-Tucker LISA 2004 论文 "Solaris Zones: Operating System Support for Consolidating Commercial Workloads"（usenix.org/legacy/events/lisa04/tech/full_papers/price/price.pdf）、LXC 项目历史、Docker 官方历史、vivianvoss.net/blog/technical-beauty-jails ［A］

**史观**：总纲第 4 条——分离聚合是永恒规律：Jails-Zones-容器设计传承体现 BSD 对 UNIX 谱系的塑造；总纲第 13 条——法律与道德是利益分配：Docker 商业化成功而 Jails 长期被忽视

**辨析**：Solaris Zones 是否真 “借鉴” Jails 须查 Sun 内部文档或工程师访谈；Docker 与 Jails 的设计差异（Docker 基于 namespaces+cgroups，Jails 基于 chroot+ 内核扩展）须辨析；“Jails 早于 Docker 13 年” 的时间对比须查 FreeBSD 4.0 与 Docker 0.1 的具体发布日期；Solaris 10 FCS 日期 2005-01-31 经 Oracle 文档与多源交叉验证，先前叙事 “2004 年” 已修正为 2005 年 1 月 31 日；Zones 设计者归属经 LISA 2004 论文署名核实，先前叙事 “Dennis Clarke 等开发” 错误已修正为 Daniel Price 与 Andrew Tucker

**文献**：Kamp-Watson Jails 论文；FreeBSD 4.0 release；Solaris 10 文档；Price-Tucker LISA 2004 论文；Docker 官方历史 ［B］
