本封回应 Nick Piggin 的 fsblock（buffer layer 重写）提案。系被引内容中 Nick 称 buffer layer 并非 unix 意义上的缓冲缓存“the buffer cache of unix”，块设备缓存已与 pagecache 统一。本封直接表述：传统 Unix 缓冲缓存总是按物理块索引，即“Traditional unix buffer cache is always physical block indexed”；而 Linux 现状是“a really crappy hybrid of a traditional unix buffercache implemented ontop of the pagecache”，即传统缓冲缓存叠加在 pagecache 之上。他主张暂留 buffer_heads 处理元数据、把数据路径与之解耦，并点名 fsblock 中两者耦合仍太深；收尾评论说他愿跳过向 extent 型 API 演进的中间步骤，因为长期写过高性能文件系统的 I/O 路径后，按页乃至半页结构实在难对付。
