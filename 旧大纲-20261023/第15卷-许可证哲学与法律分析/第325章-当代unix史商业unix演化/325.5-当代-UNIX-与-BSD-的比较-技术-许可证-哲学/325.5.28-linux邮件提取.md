在"Linux TCP 请求队列处理"问题的讨论中，Paul Albrecht 指出 Linux 的行为与 Stevens《TCP/IP Illustrated》对该场景的描述不一致：若服务器 socket backlog 将超限，在 TCP 层继续握手（发送 syn/ack 并转入 syn_recd 状态）是不正确的，并追问如何解释 Linux 与其他伯克利派生实现之间的差异。Andi Kleen 回应："The 4.4BSD-Lite code described in Stevens is long outdated. All modern BSDs (and probably most other Unixes too) do it in a similar way to what Nivedita described. The keywords are 'syn flood attack' and 'DoS'."，即以防范 SYN 洪泛攻击与 DoS 为由，指出现代 BSD 与 Linux 此处行为已趋同。Doug McNaught 本封补一句："And furthermore, IIRC, the current Linux networking code is not Berkeley-derived, though an earlier version was."——据他回忆，现网 Linux 网络代码并非伯克利派生，尽管更早的版本曾是。
