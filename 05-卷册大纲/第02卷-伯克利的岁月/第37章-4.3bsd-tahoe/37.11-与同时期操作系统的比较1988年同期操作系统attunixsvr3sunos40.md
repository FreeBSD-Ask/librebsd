# 37.11 与同时期操作系统的比较：1988 年同期操作系统


AT&T UNIX SVR3、SunOS 4.0、MS-DOS 3.3/4.0、A/UX、OS/2——BSD 在多平台移植浪潮中的坐标
## 37.11.1 AT&T UNIX SVR3 / SVR3.2（1987-1988）

**要点**：1987 年 AT&T 发布 System V Release 3（SVR3），1988 年 SVR3.2，引入 STREAMS 可堆叠 I/O 框架、远程文件共享（RFS）、网络回路（Network Loopback）与进程间通信增强；SVR3 是 AT&T 商业化 UNIX 的主线，与 BSD 在 I/O 模型（STREAMS vs 套接字）、文件系统（S5FS vs FFS）上形成鲜明对照。4.3BSD-Tahoe（1988）发布时，两条 UNIX 谱系的功能差距进一步扩大，许可证与二进制兼容性成为用户选型的关键。

| 1988 年同期操作系统 | 厂商 | 平台 | 与 4.3BSD-Tahoe 的关系 |
| ----------------- | -- | -- | -------------------- |
| SVR3 / SVR3.2 | AT&T | 多平台 | 商业 UNIX 主线，STREAMS vs BSD 套接字 |
| SunOS 4.0 | Sun | Sun-3/Sun-4 | 同脉 BSD（4.3BSD 基础 + Sun VM），商业工作站主导 |
| MS-DOS 3.3 / 4.0 | Microsoft | IBM PC 兼容机 | 无直接竞争，装机量碾压 UNIX |
| A/UX 1.0 | Apple | Macintosh II | 混合 SVR2 + 4.2BSD，Apple 试探 UNIX 市场 |
| OS/2 1.0 / 1.1 | IBM + Microsoft | 80286/386 PC | PC 平台保护模式多任务，与 BSD 路线错位 |

**史料**：AT&T SVR3/SVR3.2 发行文档与《System V Interface Definition》(SVID) ［A］；Goodheart《The Magic Garden Explained》(1994) 对 SVR3 的权威描述 ［B］

**史观**：技术路线分化：SVR3 的 STREAMS 与 BSD 的套接字代表两种网络 I/O 哲学，AT&T 的封闭标准与 BSD 的开放实现之争贯穿 1980 年代末。

**辨析**：SVR3 并非“技术领先”——在 TCP/IP 与网络编程上 BSD 反而更成熟；SVR3 的优势在于 AT&T 的企业支持与 SVID 标准化，而非技术先进性。

**文献**：AT&T. UNIX System V Release 3 Documentation [Z]. 1987；Goodheart B, Cox J. The Magic Garden Explained [M]. Prentice-Hall, 1994. ［B］

## 37.11.2 SunOS 4.0（1988）

**要点**：Sun Microsystems 于 1988 年发布 SunOS 4.0，基于 4.3BSD 并集成 Sun 自研的虚拟内存系统（Sun VM，统一了 BSD 的 VM 与 Sun 的内核页管理），引入 OpenWindows 与 NFS 早期支持；SunOS 4.x 是 1980 年代末工作站市场的主导 UNIX，与 4.3BSD-Tahoe 共享深厚的 BSD 谱系，是 BSD 技术路线在商用工作站上的最大受益者。

**史料**：Sun SunOS 4.0 发行说明与《SunOS 4.0 System Administrator's Guide》(1988) ［A］；Sun 工程师对 Sun VM 的技术报告 ［B］

**史观**：BSD 谱系：SunOS 4.0 是 BSD 谱系在商业领域最成功的延伸，证明 BSD 研究代码可转化为稳定商用产品；其 BSD 血统使其与 4.3BSD-Tahoe 高度兼容。

**辨析**：SunOS 4.0 与 4.3BSD-Tahoe 并非竞争关系而是同脉——SunOS 直接衍生自 BSD，二者差异主要在 VM 子系统与硬件支持；Sun 后来转向 SVR4（Solaris 2）才与 BSD 分道扬镳。

## 37.11.3 MS-DOS 3.3（1987）/ 4.0（1988）

**要点**：MS-DOS 3.3（1987）完善了硬盘分区与网络支持，4.0（1988）引入 DOS Shell 图形外壳，仍是单用户、单任务操作系统；它与 4.3BSD-Tahoe 面向完全不同的市场（IBM PC 兼容机 vs VAX/多平台科研机），却在装机量上碾压所有 UNIX 变体，是 1980 年代末最普及的操作系统。

**史料**：Microsoft MS-DOS 3.3/4.0 用户手册（1987-1988）［A］；PC 兼容机市场销量统计（1988）［C］

**史观**：技术路线分化：MS-DOS 以极简单用户设计适配廉价硬件，与 BSD 的多用户研究路线形成极端对照；Tahoe 的多平台化努力（68030）也无法触及 DOS 的微机海量市场。

**辨析**：MS-DOS 与 BSD 无直接竞争——硬件平台（8088/286 vs VAX/68030）与用户群（家庭/办公 vs 科研/服务器）完全错位；DOS 的普及是 IBM PC 标准的结果，而非技术对标。

**文献**：Microsoft. MS-DOS User's Guide [Z]. 1988；Duncan R. The MS-DOS Encyclopedia [M]. Microsoft Press, 1988. ［B］

## 37.11.4 A/UX（Apple，1988）

**要点**：Apple 于 1988 年发布 A/UX，是其 Macintosh II 上的 UNIX 实现，混合了 AT&T System V Release 2 与 4.2BSD 组件，并保留了 Macintosh 图形界面；A/UX 是 Apple 对 UNIX 工作站市场的试探，但因 Mac 硬件封闭与性能问题未能成为主流。

**史料**：Apple A/UX 发行公告与技术文档（1988）［A］；A/UX 用户手册 ［B］

**史观**：BSD 谱系：A/UX 复用 4.2BSD 用户空间组件，是 BSD 代码进入 Apple 生态的早期案例，预示了日后 Darwin/macOS 对 BSD 的更深度吸收。

**辨析**：A/UX 与 4.3BSD-Tahoe 是“同源异构”——二者共享 4.2BSD 用户空间，但 A/UX 叠加了 SVR2 内核元素与 Mac GUI；其失败主要在于 Apple 硬件封闭而非 BSD 技术问题。

## 37.11.5 OS/2 1.0/1.1（1987-1988）

**要点**：OS/2 是 IBM 与微软为 80286/386 平台开发的“下一代”PC 操作系统，1.0（1987）为文本模式、1.1（1988）引入 Presentation Manager 图形界面与保护模式多任务；它面向比 MS-DOS 更强的硬件，却在与 Windows 3.0（1990）的竞争中失利，未能取代 DOS 成为 PC 标准。

**史料**：IBM/Microsoft OS/2 1.0/1.1 发行文档（1987-1988）［A］；Dunn《The OS/2 War》等回顾 ［C］

**史观**：技术路线分化：OS/2 代表“PC 平台向上生长”的路线（保护模式、多任务），与 BSD 的“小型机向下兼容”路线在 1988 年尚未交汇，预示了 1990 年代 PC 操作系统与 UNIX 的正面竞争。

**辨析**：OS/2 与 BSD 无直接竞争——OS/2 瞄准 286/386 PC 的企业市场，BSD 固守 VAX/科研；OS/2 真正的对手是 Windows 与 DOS，而非 UNIX 变体。

**文献**：IBM. OS/2 1.1 Technical Reference [Z]. 1988；Dunn R. The OS/2 War [M]. 1994. ［C］
