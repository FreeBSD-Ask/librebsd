# 034.2.1 虚拟内存的架构设计

**要点**：3BSD 在 VAX 上实现请求调页式虚拟内存，利用 VAX 硬件的页表与 TLB 支持，使进程拥有独立虚拟地址空间，超越 32V 的简单换页机制；3BSD 虚拟内存的核心设计——请求调页（demand paging）+ 全局 CLOCK 页面置换策略（LRU 近似）+ working set 风格的多道程序度控制，由 Özalp Babaoğlu（厄扎尔普·巴巴奥卢） 主导设计实现、Bill Joy 协助内核集成调试；针对 VAX-11/780 硬件缺乏 reference bit（页引用位）的限制，采用软件检测方案克服，性能开销相对较小；3BSD 内核镜像命名为 `/vmunix`（virtual memory UNIX），此命名延续至 4.4BSD

**史料**：3BSD 虚拟内存源代码（`/sys/vmsystm.c`、`/sys/vm_page.c` 等内核文件）；VAX 硬件手册（DEC VAX-11/780 Hardware User's Guide）；Babaoğlu 博士论文（UCB/ERL M81/92, 1981-11-17，导师 Domenico Ferrari，URL: <https://www2.eecs.berkeley.edu/Pubs/TechRpts/1981/7560.html，PDF>: <https://digicoll.lib.berkeley.edu/record/134368/files/ERL-m-81-92.pdf）；Babaoğlu> & Joy SOSP '81 会议论文（"Converting a swap-based system to do paging in an architecture lacking page-referenced bits", SOSP ’81 Proceedings, pp. 78-86, 1981-12-01, DOI: 10.1145/800216.806595）；Babaoğlu, Joy & Porcar 设计论文（"Design and Implementation of the Berkeley Virtual Memory Extensions to the UNIX Operating System"，Berkeley CS 技术报告，确切编号经考据确认：该文发表于 ASPLOS-I（1982.3）【考据完成：2026-08-02】，PDF: <http://roguelife.org/~fujita/COOKIES/HISTORY/3BSD/design.pdf）［A］>

**史观**：第 7 条硬件与软件辩证——VAX 的硬件虚拟内存支持使 3BSD 的虚拟内存实现成为可能，硬件能力决定软件设计空间；第 17 条软件工程——Babaoğlu 针对 VAX 缺乏 reference bit 的硬件限制设计软件检测方案，是软硬件协同工程的典型案例

**辨析**：3BSD 虚拟内存是否基于 TENEX/TOPS-20 设计存在争议，需核对设计文档；Babaoğlu 博士论文与 SOSP '81 论文均发表于 1981 年（3BSD 1979.12 发布后约两年），3BSD 发布时尚无正式技术报告发表，正式学术发表滞后于工程实现；原 “伯克利 CSRG 技术报告 CSD-79-231” 引用经 2026-07-29 联网核查 Berkeley EECS 1979 年技术报告档案（<https://www2.eecs.berkeley.edu/Pubs/TechRpts/1979）确认为错误引用——Berkeley> EECS 1979 年技术报告使用 M79/xx 编号格式（如 Babaoğlu 1979 年唯一可查的技术报告为 M79/75 "Efficient Generation of Memory Reference Strings Based on the LRU Stack Model of Program Behavior“，与 3BSD 虚拟内存无直接关联），CSD 技术报告系列始于 1982 年（据 Berkeley EECS 官方说明 ”the CS Technical Report series from 1982 to 2005“），故不存在 CSD-79-231 这一编号；Babaoğlu, Joy & Porcar ”Design and Implementation" 论文确切的 Berkeley CS 技术报告编号与发表年份须进一步核查 Berkeley EECS 1980-1982 年技术报告档案确认；[2026-08-14 两库核查：参考文献库 people “Babaoglu” 0 命中，SOSP ’81 论文不在库内，邮件库 usenet 1981- 无 3BSD 虚拟内存讨论，Babaoğlu 实现与 Joy 集成两库无法验证]
