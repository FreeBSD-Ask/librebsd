# 040.2.1 Tahoe 代号的来源

**要点**：Tahoe 代号来源于 Computer Consoles Inc.（CCI）为 Power 6/32 机器使用的内部开发代号（McKusick 1999 一手记载："The name Tahoe came from the development name used by Computer Consoles, Incorporated, for the machine that they eventually released as the Power 6/32"），与加州太浩湖（Lake Tahoe）地名巧合相同；CSRG 惯例以地名作为版本代号始于 4.3BSD-Reno（以 Reno 市命名，暗喻 interim release 的“赌博”性质），Tahoe 版本代号直接沿用 CCI 硬件开发名，4.3BSD Tahoe（1988 年 6 月）由 Keith Bostic（基思·博斯蒂克）、Mike Karels、Kirk McKusick 三人联合公告

**史料**：CSRG 内部命名惯例记录、4.3BSD Tahoe Release Notes（1988.6）、McKusick 关于命名惯例的访谈 ［B］

**史观**：第 9 条经验优先——版本命名是工程文化实践，而非理论先行，反映 CSRG 团队的地理认同

**辨析**：Tahoe 代号来源经 McKusick 1999 一手当事人记载确认为 Computer Consoles Inc.（CCI）Power 6/32 机器的内部开发代号，与加州太浩湖（Lake Tahoe）为巧合同名而非刻意以地名命名；CSRG 以地名作为版本代号的惯例始于后续的 4.3BSD-Reno（Reno 为内华达州城市，暗喻 interim release 的“赌博”性质）

**文献**：4.3BSD Tahoe Release Notes（1988.6）；McKusick, K. (1999) “Twenty Years of Berkeley Unix”；CSRG 内部档案 ［B］
