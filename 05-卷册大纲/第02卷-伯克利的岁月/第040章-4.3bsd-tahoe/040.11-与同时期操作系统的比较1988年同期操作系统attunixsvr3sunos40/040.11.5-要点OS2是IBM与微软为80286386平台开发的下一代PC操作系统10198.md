# 040.11.5 要点OS2是IBM与微软为80286386平台开发的下一代PC操作系统10198

**要点**：OS/2 是 IBM 与微软为 80286/386 平台开发的“下一代”PC 操作系统，1.0（1987）为文本模式、1.1（1988）引入 Presentation Manager 图形界面与保护模式多任务；它面向比 MS-DOS 更强的硬件，却在与 Windows 3.0（1990）的竞争中失利，未能取代 DOS 成为 PC 标准。

**史料**：IBM/Microsoft OS/2 1.0/1.1 发行文档（1987-1988）［A］；Dunn《The OS/2 War》等回顾 ［C］

**史观**：技术路线分化：OS/2 代表“PC 平台向上生长”的路线（保护模式、多任务），与 BSD 的“小型机向下兼容”路线在 1988 年尚未交汇，预示了 1990 年代 PC 操作系统与 UNIX 的正面竞争。

**辨析**：OS/2 与 BSD 无直接竞争——OS/2 瞄准 286/386 PC 的企业市场，BSD 固守 VAX/科研；OS/2 真正的对手是 Windows 与 DOS，而非 UNIX 变体。

**文献**：IBM. OS/2 1.1 Technical Reference [Z]. 1988；Dunn R. The OS/2 War [M]. 1994. ［C］
