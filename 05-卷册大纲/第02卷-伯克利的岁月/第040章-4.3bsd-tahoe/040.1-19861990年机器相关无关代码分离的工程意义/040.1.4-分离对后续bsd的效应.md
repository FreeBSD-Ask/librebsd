# 040.1.4 分离对后续 BSD 的效应

**要点**：分离对后续 BSD 的影响深远：1991 年 386BSD 基于 Net/2 成功移植到 386 平台、1993 年 NetBSD 0.8 以分离架构支持多平台、1993 年 FreeBSD 1.0 基于 386BSD、1995 年 OpenBSD 从 NetBSD fork，分离工作奠定后续 BSD 多分支共同基础

**史料**：386BSD Release Notes（1992）、NetBSD 0.8 Release Notes（1993）、FreeBSD 1.0 Release Notes（1993）、OpenBSD fork 公告（1995）［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档〕

**史观**：第 5 条偶然性——分离工作的历史后果（多 BSD 分支）并非 CSRG 的预期，而是 1991-1995 多重偶然事件叠加的产物

**辨析**：分离工作与多分支形成的因果关系需谨慎判断，避免线性因果，386BSD 的 Bill Jolitz 个人努力亦是关键因素
