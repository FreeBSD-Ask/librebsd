# 040.10.3 早期 BSD 网络栈（含 AT&T 衍生代码） → Net/1 自由网络代码（无 AT&T 代码）的发布（Bostic 公告 1988.12.7，二手史料记载 1989.6）

**要点**：4.2BSD/4.3BSD/4.3BSD-Tahoe 的网络栈（TCP/IP、套接字 API、telnet/ftp/rsh 工具、inetd 守护进程）虽由伯克利原创开发但与 AT&T UNIX 内核源代码混合分发，厂商与机构需购买 AT&T UNIX 源代码许可证方可使用 BSD 网络栈；1984 年 AT&T 反垄断分拆后 UNIX 源代码许可费从 1970 年代教育机构免费/200 美元持续上涨到 1983 年商业 $43,000 起每 CPU + \$16,000 每 CPU、1989-1990 年 SVR4 商业版 $100,000（AT&T UNIX Software Operation 1990.3.28 公开邮件列表原文"The Price of \$100,000 is the commercial price for a Release 4.0 license“）、McKusick 1999 视频中回忆”such a license would cost $250,000"（klarasystems 转引 McKusick 1999 视频，但 McKusick 未指明具体年份）。注意：相关章节中“200,000 美元起”（1985 年）与“400,000 美元”（1987 年）的具体数字 **无独立一手史料确认**——TUHS 邮件列表、McKusick 1999 视频、Salus 1994 等多源交叉印证仅能确认 1983 年商业约 \$43k/CPU、1989-1990 年 SVR4 商业 $100,000、McKusick 回忆“约 \$250,000”等大致范围，“1985 年 200,000 美元”与“1987 年 400,000 美元”系 **疑似臆造或与其他数字混淆**，应在正文中标注存疑或删除；Net/1（Bostic USENET 公告日期 1988.12.7，McKusick 1999 等二手史料记载为 1989 年 6 月 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］）是首个完全自由的 BSD 网络代码发布，含 BSD 原始 TCP/IP 实现（不含 BBN 衍生部分）、套接字 API（4.2BSD 原创）、网络驱动框架、telnet/ftp/rsh 等网络工具，所有代码在 BSD 许可证下发布，无 AT&T 版权限制，可自由使用、修改、再分发；Net/1 公告原文“a complete list of files is attached to this message”明确未公布代码行数；Net/1 的发布使早期 BSD 网络栈（含 AT&T 代码）在自由软件路径中被“淘汰”为完全自由版本，为 Net/2（1991）、386BSD（1991-1992）、FreeBSD/NetBSD（1993）提供合法网络代码来源

**史料**：4.2BSD/4.3BSD/4.3BSD-Tahoe 网络栈源代码（含 AT&T 衍生代码）；AT&T 1983-1990 年 UNIX 源代码许可费价格表（AT&T UNIX Software Operation 1990.3.28 TUHS comp.unix.questions 邮件列表原文"The Price of $100,000 is the commercial price for a Release 4.0 license"）；Bostic 1988.12.7 Net/1 USENET 公告（gunkies.org 存档，一手原文）；Net/1 源代码（无 AT&T 代码）；BSD 许可证原文（1988-1989 版本）；McKusick, K. (1999) “Twenty Years of Berkeley Unix”；McKusick 1999 视频（klarasystems 转引 \$250,000 数字）；CSRG 法律评估文件（1988-1989） ［A］

**史观**：第 13 条法律与道德是利益分配——BSD 许可证允许 Net/1 网络代码自由再分发，与 AT&T 商业许可证形成鲜明对比，许可证模式决定了 BSD 网络代码的自由路径；形式主义——AT&T 商业化形式逻辑（许可费飙升）催生 Net/1 反向形式逻辑（完全自由），两种形式主义对立驱动 BSD 走向完全自由

**辨析**：Net/1 中“完全无 AT&T 代码”的法律判断需核对，部分网络工具可能含有 AT&T 原始代码的衍生，CSRG 法律评估文件（1988-1989）是判断依据，须区分“CSRG 法律判断”与“实际代码纯度”；Net/1 替代早期 BSD 网络栈指自由软件路径的替代，早期 BSD 网络栈本身在 4.3BSD-Tahoe/4.3BSD-Reno 中仍以含 AT&T 代码形式延续，须区分“自由软件路径替代”与“BSD 主线延续”；Net/1 与 Net/2（1991）的关系需严格区分——Net/1 仅网络代码自由化（Bostic 公告 1988.12.7，二手史料 1989.6据一手文献印证消解^doubt-resolved-223：此处事实待多源交叉验证 ］，磁带分发费据 Bostic 一手公告为 $400.00 US），Net/2 是完整 BSD 用户空间与内核大部分代码自由化（1991.6，18,000 个文件，诉讼和解后删除 3 个文件）；Net/1 公告“a complete list of files is attached”但未公布代码行数，“约 18,000 行代码”系混淆 Net/2（1991）的 18,000 个文件数而非 Net/1 代码行数（McKusick 1999 原文："three files were removed from the 18,000 that made up Networking Release 2"），Net/1 代码行数标注［存疑脚注：此处事实待多源交叉验证］；AT&T UNIX 源代码许可费具体数字“200,000 美元”（1985）、“400,000 美元”（1987）、大学许可费“1,200 美元”（Release 3.0）均 **无独立一手史料确认**，应标注存疑，可确认数字为：1983 年商业约 \$43,000/CPU、1989-1990 年 SVR4 商业 $100,000、McKusick 回忆“约 \$250,000”；经 freebsd.duckdb 查询未得明确证据（查询条件：`SELECT * FROM commits WHERE message_subject LIKE '%Net/1%' OR message_subject LIKE '%AT&T%' OR message_subject LIKE '%license fee%' OR message_subject LIKE '%200000%' OR message_subject LIKE '%400000%'`，freebsd-src 仓库最早 commit 为 1993-06-12T14:49:13Z by Rodney W.
