# 031.3.3 从 PDP-11 到 VAX 的迁移压力

**要点**：PDP-11 的地址空间限制使 BSD 无法支撑日益增长的网络与虚拟内存需求，1979-1980 年伯克利启动向 VAX 32 位架构的迁移，催生 3BSD

**史观**：第 7 条硬件与软件辩证——PDP-11 的硬件瓶颈迫使 BSD 寻求新平台，硬件演化推动软件迁移
