# 045.7.5 法律环境对操作系统生态的效应

**要点**：法律环境对操作系统生态的影响：USL v. BSDi 加速 BSD 完全自由化与 Linux 崛起、SCO v. IBM 阻止 SCO 阻止 Linux 发展、Apple v. Microsoft 使 Microsoft Windows 主导 GUI 市场，三案显示法律环境对操作系统生态的长期影响

**史料**：1990-2010 年操作系统市场份额报告、Linux/BSD/Windows 发展记录［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档 + L5 研究报告〕

**史观**：第 5 条没有必然性只有偶然性——法律环境的偶然变化（诉讼、和解、判决）塑造操作系统生态长期格局

**辨析**：法律环境的 “决定性” 需核对，避免将法律因素等同于唯一因素，技术与市场因素亦重要
