# 045.7.3 Apple v. Microsoft 的对比

**要点**：Apple v. Microsoft（1988-1997）案中 Apple 起诉 Microsoft Windows 侵犯 Macintosh GUI 版权，与 USL v. BSDi 类似均为软件版权诉讼，但 Apple 案中 Apple GUI 版权范围被法院限缩，1997 年 Apple 与 Microsoft 和解（Microsoft 投资 Apple），对比显示软件版权诉讼的法律不确定性

**史观**：第 5 条没有必然性只有偶然性——Apple 案与 USL 案均为软件版权诉讼，但 Apple 案因 1985 年许可协议而败诉，USL 案因版权瑕疵而和解，偶然因素决定诉讼结果
