# vi 与 C Shell 在非 BSD 系统中的应用与影响


## vi.1 vi 编辑器的跨系统移植与标准化

- 要点：vi 自 2BSD 诞生后迅速移植到 System V、SunOS、HP-UX 等系统。1985 年 POSIX 标准将 vi 列为必选编辑器。1991 年 Bram Moolenaar 开发 Vim（Vi IMproved）作为 vi 的开源替代，进一步扩展了 vi 的使用生态。
- 史料：POSIX.2 Shell and Utilities (1992); Bram Moolenaar, Vim 文档 ［A］；[2026-08-14 两库核查：vi 列入 POSIX（1985/1992）与 Vim 1991 首发，两库无直接条目（邮件库 usenet 1991 “vim” 0 命中，参考文献库 tech “vim” 无），两库无法验证]
- 史观：总纲第 4 条——技术传播的社会网络效应：vi 的跨系统成功源于其与 BSD 学术网络捆绑传播。
- 文献：POSIX.2 标准； Vim 官方文档； McKusick et al. 1996 ［A］

## vi.2 C Shell 的特性在其他 shell 中的继承

- 要点：csh 的 history 机制、别名（alias）、作业控制（job control）先后被 bash（1989）、tcsh（1983）和 zsh（1990）继承。但 csh 的脚本语法缺陷（Csh Programming Considered Harmful, Tom Christiansen 1995）也引发了 shell 编程哲学的深刻反思。
- 史料：Tom Christiansen, 'Csh Programming Considered Harmful' (1995); bash 手册 ［A］；[2026-08-14 两库核查：bash（1989）/tcsh（1983）/zsh（1990）继承 csh 交互特性与 Christiansen 批评文，参考文献库无对应条目，邮件库 usenet 1996 年有 “csh programming considered harmful” 短语佐证批评流传，各 shell 首发年份两库无法验证]
- 史观：总纲第 2 条——实用主义与其局限。
