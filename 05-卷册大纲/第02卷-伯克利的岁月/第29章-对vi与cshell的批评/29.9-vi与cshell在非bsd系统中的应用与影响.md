# 29.9 vi 与 C Shell 在非 BSD 系统中的应用与影响

## 29.9.1 vi 编辑器的跨系统移植与标准化

**要点**：vi 自 2BSD 诞生后迅速移植到 System V、SunOS、HP-UX 等系统。1985 年 POSIX 标准将 vi 列为必选编辑器。1991 年 Bram Moolenaar 开发 Vim（Vi IMproved）作为 vi 的开源替代，进一步扩展了 vi 的使用生态。

**史料**：POSIX.2 Shell and Utilities (1992); Bram Moolenaar, Vim 文档 ［A］；[2026-08-14 两库核查：vi 列入 POSIX（1985/1992）与 Vim 1991 首发，两库无直接条目（邮件库 usenet 1991 “vim” 0 命中，参考文献库 tech “vim” 无），两库无法验证]

**史观**：总纲第 4 条——分离聚合是永恒规律：vi 的跨系统成功源于其与 BSD 学术网络捆绑传播（原“技术传播的社会网络效应”不在权威表，按权威表改挂——2026-09-12 整改，批次 B042 问题 1 同源）。

**辨析**：vi 列入 POSIX 的标准版本与年份存在张力——正文“1985 年 POSIX 标准”与所引“POSIX.2 Shell and Utilities (1992)”口径不一：vi 列入必选实用程序的确切标准为 IEEE Std 1003.2-1992（POSIX.2），1985 年系 POSIX.1 系统接口草案期，非 vi 入标时点，正文表述按 1992 核准（[存疑脚注：vi 入标的精确标准条款号待 IEEE 1003.2 原文核验]——2026-09-12 整改补辨析，批次 B042 问题 1/5）。

**文献**：POSIX.2 标准； Vim 官方文档； McKusick et al. 1996 ［A］

## 29.9.2 C Shell 的特性在其他 shell 中的继承

**要点**：csh 的 history 机制、别名（alias）、作业控制（job control）先后被 bash（1989）、tcsh（1983）和 zsh（1990）继承。但 csh 的脚本语法缺陷（Csh Programming Considered Harmful, Tom Christiansen（汤姆·克里斯蒂安森），流传始于 1996——年份统一见辨析）也引发了 shell 编程哲学的深刻反思。

**史料**：Tom Christiansen《Csh Programming Considered Harmful》(1996)（年份统一见辨析）; bash 手册 ［A］；[2026-08-14 两库核查：bash（1989）/tcsh（1983）/zsh（1990）继承 csh 交互特性与 Christiansen 批评文，参考文献库无对应条目，邮件库 usenet 1996 年有 “csh programming considered harmful” 短语佐证批评流传，各 shell 首发年份两库无法验证]

文件系统概念演化大体历经：①顺序/平坦期（1950–1960s）：磁带顺序访问与早期磁盘平面目录；②层次化突破（1960s–1970s）：Multics（始于 1965）首创树状文件目录与路径名，Unix（1970s）以 inode 架构、挂载点、“一切皆文件”简明化并推广层次文件系统；③性能重构期（1980s）：Marshall Kirk McKusick 等为 4.2BSD 设计 Fast File System（FFS/现称 UFS1，1982 年写出、随 4.2BSD 发行），引入柱面组、碎片、软更新，UFS2（2002–2003）改用 64 位块指针扩展至多 TB；④网络化期：Sun Microsystems 1984 年推出网络文件系统 NFS，确立 VFS/vnode 接口；⑤存储与纠错集成期：如 ZFS（2001–2006）将文件系统与卷管理、写时拷贝、校验和集成。

Capsicum 源自剑桥大学计算机实验室 Robert N.M. GEOM 由 Poul-Henning Kamp 提出构想（早期思想文《Geometry —— an idea》），最原始前身是作者对 Minix 1.2 所做的一个从未发布的 hack。2002 年 Kamp 在 NAI Labs 支持下，于 DARPA/SPAWAR 合同与 DARPA CHATS 研究计划框架内开发成形。2003 年 Kamp 在 BSDCon 发表 GEOM 教程。GEOM 自 FreeBSD 5.0（2003）起提供，明确定义 class/geom/provider/consumer/rank 等拓扑概念，提供分区（FDISK/MBR、GPT、BSD slice）、镜像（geom_mirror）、RAID、UFS 卷标、GBDE/geli 磁盘加密等类，并支持 ggate 用户态网关。至 FreeBSD 13.0，GEOM_BSD、GEOM_MBR、GEOM_SUNLABEL 等过时组件被移除，由 GEOM_PART_* 与 GEOM_LABEL 等替代，框架持续演化。
