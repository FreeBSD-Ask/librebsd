# 31.6 curses 库与屏幕终端处理——Ken Arnold 的贡献

## 31.6.1 Ken Arnold 与 curses 库
- 要点：curses 是一个终端屏幕优化库，提供与终端无关的屏幕更新能力，由 Ken Arnold 在伯克利开发；curses 建立在 Bill Joy 的 termcap（terminal capability database）之上，termcap 本身是为支持 vi 编辑器（Joy 在 ADM-3a 终端上开发）而创建的终端特性描述数据库；curses 最初随 4BSD（1980 年 10 月）分发，为全屏幕应用程序（如 rogue 游戏、系统管理工具）提供了终端无关的屏幕 I/O 接口；curses 后演化为 System V curses、ncurses 等多个实现，是 UNIX 全屏幕 TUI（文本用户界面）编程的基础库 [考据完成：2026-07-28 经 TUHS Unix Tree CSRG 档案（Kirk McKusick 捐赠）核验，4BSD（1980-10）相对 3BSD（1980-03）的新增特性明确列出 the Curses programming library，2BSD（1979-04）仅含 C-shell、ex、vi、Pascal 系统不含 curses，3BSD（1980-03）以虚拟内存为核心特性不含 curses，curses 首次分发版本确认为 4BSD（1980-10）]
- 史料：curses 源代码；Arnold, K. (1980s) "curses: Screen Optimization for UNIX"；4BSD/4.1BSD 发行磁带；rogue 游戏源代码 ［A］
- 史观：第 17 条软件工程——curses 与 termcap 是硬件抽象的早期实践，将应用程序与终端硬件特性解耦
- 辨析：curses 作者 Ken Arnold 是 CSRG 重要贡献者，除 curses 外还参与 rogue 游戏等开发；curses 与 termcap 的关系——termcap 提供终端特性数据库，curses 在此基础上提供屏幕优化更新；curses 精确引入版本经 TUHS Unix Tree CSRG 档案确认为 4BSD（1980-10），2BSD 与 3BSD 均不含 curses；bsd_commits.db 查询最早 commit 为 1993-06-12 by Rodney W. Grimes（罗德尼·W·格赖姆斯）（hash 9002c02abc587664acb357c6879d8ca08664dd0b），早于 4BSD 约 13 年，commit 历史中无 curses 首次引入版本的代码级证据，故以 TUHS CSRG 档案为一手依据；[2026-08-14 两库核查：参考文献库 tech "curses" 0 命中，curses 作者 Ken Arnold 与 4BSD（1980.10）首次分发两库无法验证]
