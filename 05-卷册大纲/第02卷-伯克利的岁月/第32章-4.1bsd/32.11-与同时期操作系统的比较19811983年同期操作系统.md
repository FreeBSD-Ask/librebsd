# 32.11 与同时期操作系统的比较：1981-1983 年同期操作系统

AT&T UNIX System III/V、Xenix、MS-DOS、VAX/VMS、Coherent——BSD 在小型机 UNIX 阵营中的定位

## 32.11.1 AT&T UNIX System III（1982）与 System V Release 1（1983）

**要点**：1982 年 AT&T 发布 UNIX System III，1983 年发布 System V Release 1（SVR1），将 UNIX 从 Bell Labs 内部研究系统转变为 AT&T 正式商业化产品；System III 引入可移植 C 编译器（pcc，Portable C Compiler）、将文件系统工具拆分至独立命令（如 /etc/fsck、/etc/fsdb），并在 curses、termcap 等层面与 BSD 拉开差异；SVR1 进一步确立 AT&T 主线，成为此后 SVR2/SVR3/SVR4 的源头。BSD 一脉（此时为 4.1BSD）在 TCP/IP 网络栈、套接字接口、虚拟内存（已领先 AT&T）、csh、vi 等方面已形成显著差异，两条 UNIX 谱系自此正式分叉。

**史料**：AT&T UNIX System III / System V 发行文档与用户手册（1982-1983）；SVR1 发布说明 ［A］；Bach《The Design of the UNIX Operating System》(1986) 对 SVR2 体系的描述可作旁证 ［B］

**史观**：技术路线分化：1980 年代初 AT&T 商业化 UNIX 与 BSD 研究 UNIX 在许可证、工具链、网络模型上走向两条路线，BSD 的 TCP/IP 与套接字成为日后的事实标准。

**辨析**：常见误解认为 “System V 是 UNIX 正统、BSD 是分支”——事实上二者同源 V7，BSD 在 4.x 时期在网络与 VM 上反而领先；“正统性” 是 AT&T 许可证与商业化叙事的产物，而非技术事实。

**文献**：AT&T. UNIX System V User's Manual [M]. 1983；Bach M J. The Design of the UNIX Operating System [M]. Prentice-Hall, 1986. ［B］

## 32.11.2 Xenix（Microsoft/Intel/SCO，Xenix 3.0 约 1982）

**要点**：Xenix 是微软从 AT&T 取得 UNIX 授权后移植到 16 位微处理器的版本，先后支持 Intel 8086/80286、Motorola 68000、Zilog Z8000 等；Xenix 3.0（约 1982）是微机界最普及的 UNIX，在 Linux 出现之前长期是 x86 上的主流 UNIX 选择。微软借 Xenix 进入操作系统市场，但 1980 年代中期后将重心转向 MS-DOS/OS/2，Xenix 后续交由 SCO 维护并演化为 SCO UNIX。

**史料**：Microsoft Xenix 授权与移植公告（1980-1982）；SCO Xenix 发行说明 ［B］；Xenix 历史回顾文章 ［C］

**史观**：技术路线分化：Xenix 代表 “UNIX 下移到微机” 的路线，与 BSD 固守 VAX/小型机科研市场形成对照；二者市场基本不重叠。

**辨析**：Xenix 与 BSD 并非直接竞争——Xenix 面向 8086 微机、BSD 面向 VAX 小型机，硬件与用户群差异显著；Xenix 后来不敌 MS-DOS 在 PC 上的统治，而非被 BSD 击败。

## 32.11.3 MS-DOS 1.0（1981，IBM PC 5150）/ 2.0（1983）

**要点**：MS-DOS（IBM PC DOS）是微软为 IBM PC 5150（1981）开发的单用户、单任务磁盘操作系统，2.0（1983）引入目录结构与硬盘支持；它与 UNIX/BSD 无共同谱系，缺乏多用户、多任务、内存保护，却在 IBM PC 生态中迅速统治微机市场，成为 1980 年代个人计算机的事实标准。

**史料**：IBM PC 5150 技术参考（1981）；MS-DOS 2.0 用户手册（1983）［A］；Paterson 关于 86-DOS/QDOS 起源的回顾 ［C］

**史观**：技术路线分化：MS-DOS 选择极简单用户路线以适配 8088 硬件与成本约束，与 BSD 的多用户研究路线形成极端对照，预示了 “微机消费” 与 “小型机科研” 两大市场的永久分裂。

**辨析**：不应将 MS-DOS 视为 BSD 的 “竞争对手”——二者目标平台与设计哲学完全不同；MS-DOS 的成功源于 IBM PC 标准而非技术优越性，BSD 在技术上长期领先却在微机市场缺位。

**文献**：Microsoft. MS-DOS User's Guide and Reference [Z]. 1983；Freiberger P, Swaine M. Fire in the Valley [M]. McGraw-Hill, 1984/2000. ［B］

## 32.11.4 VAX/VMS V4（1982，DEC）

**要点**：VMS（Virtual Memory System）是 DEC 为 VAX-11 系列大型/超级小型机开发的原生操作系统，V4（约 1982）时期与 4.1BSD 同期运行在同一 VAX 硬件上；VMS 由 Dave Cutler 团队主导，强调工程稳定性、集群（VAXcluster）与企业特性，与 BSD 在 VAX 平台上形成直接的 “原生系统 vs 研究 UNIX” 路线之争。

**史料**：DEC VAX/VMS V4 技术手册与发布说明（约 1982）［A］；Cutler 后续访谈与《Inside Windows NT》旁证其哲学 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］

**史观**：技术路线分化：VMS 与 BSD 在同一硬件（VAX）上竞争，VMS 走封闭工程化路线、BSD 走开放研究路线，这一对照是理解 1980 年代操作系统哲学分裂的关键案例。

**辨析**：VMS 并非 “击败” BSD——在科研/学术/网络服务领域 BSD 占优，在企业/集群/关键业务领域 VMS 占优；两者长期并存，VMS 的影响经 Cutler 延续至 Windows NT。

**文献**：DEC. VAX/VMS System Manager's Manual [Z]. 1982；Custer H. Inside Windows NT [M]. Microsoft Press, 1993. ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］

## 32.11.5 Coherent（Mark Williams Co.，约 1983）

**要点**：Coherent 是 Mark Williams Company 从零实现、与 UNIX 高度兼容的操作系统，先支持 PDP-11、后支持 Intel 386，作为商业克隆销售；它不与 AT&T 或 BSD 共享代码，却能提供近似 UNIX 的用户体验，反映了当时对平价 UNIX 类系统的真实需求。

**史料**：Mark Williams Co. Coherent 产品手册与广告（约 1983）；计算机历史博物馆相关档案 ［B］

**史观**：BSD 谱系：Coherent 虽非 BSD 谱系，却与 BSD 共享 “提供平价/可移植 UNIX 体验” 的目标，是 UNIX 兼容生态多元化的佐证；其存在也说明 AT&T 许可证壁垒催生了独立实现。

**辨析**：Coherent 与 BSD 无代码渊源，不应混为一谈；其市场影响有限（主要面向教育/爱好者），但作为 “无 AT&T 代码的 UNIX 兼容系统” 具有象征意义，预示了后来 Minix、Linux 的 “干净实现” 路线。
