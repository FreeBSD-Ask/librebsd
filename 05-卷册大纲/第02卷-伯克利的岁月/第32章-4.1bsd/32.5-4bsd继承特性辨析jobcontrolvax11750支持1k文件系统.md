# 31.5 4BSD 继承特性辨析——Job Control、VAX-11/750 支持、1K 文件系统

## 31.5.1 Jim Kulp 与 Job Control（作业控制）
- 要点：Job Control（作业控制，允许 shell 挂起/恢复/前后台切换进程）非 4.1BSD 新功能，而是 4BSD（1980 年 10 月）引入的特性；该功能源自 IIASA（International Institute for Applied Systems Analysis，奥地利拉森堡）的 Jim Kulp 实现，Bill Joy 将其集成入 4BSD 内核与 C shell（McKusick 1999 原文："Joy incorporated Jim Kulp's job control"）；Job Control 后成为 POSIX 标准的一部分，是现代 UNIX shell 的核心功能
- 史料：4BSD Release Notes (1980.10)；Kulp, J. (1979) "Job Control for UNIX" IIASA 报告；C shell 源代码；McKusick, K. (1999) "Twenty Years of Berkeley Unix" ［A］
- 史观：第 3 条贡献者谱系——Job Control 是外部贡献者（IIASA Jim Kulp）而非 Joy 原创，Joy 的贡献在于集成与产品化
- 辨析：Job Control 常被误归于 4.1BSD 或 Joy 原创，经 McKusick 1999 当事人一手叙述确认为 4BSD（1980.10）引入、作者 Jim Kulp at IIASA；Kulp 1979 年在 IIASA 实现了 Job Control 原型，Joy 将其集成入 BSD；具体实现细节（信号机制、terminal driver 改动）需核对 4BSD 源代码
- 文献：McKusick, K. (1999) "Twenty Years of Berkeley Unix"（当事人一手记载 Jim Kulp job control 在 4BSD 中引入）；4BSD Release Notes (1980.10) ［B］

## 31.5.2 VAX-11/750 支持
- 要点：VAX-11/750 支持非 4.1BSD 新功能，而是 4BSD（1980 年 10 月）引入的硬件支持（McKusick 1999 原文："support for the latest VAX machine, the VAX-11/750"）；VAX-11/750（代号 "Comet"）是 DEC 于 1980 年 10 月发布的中端 VAX 机型，比 VAX-11/780 便宜，推动了 VAX 的普及；3BSD 仅支持 VAX-11/780，4BSD 新增 750 支持
- 史料：4BSD Release Notes (1980.10)；DEC VAX-11/750 硬件文档；McKusick, K. (1999) "Twenty Years of Berkeley Unix" ［B］
- 史观：第 7 条硬件与软件辩证——新机型支持扩大了 BSD 用户基础
- 辨析：VAX-11/750 支持在 4BSD 中引入而非 4.1BSD，常被误记为 4.1BSD 特性；750 的支持与 autoconfig（4.1BSD）配合使 BSD 在多 VAX 机型上的部署更加便捷
- 文献：McKusick, K. (1999) "Twenty Years of Berkeley Unix"（当事人一手记载 VAX-11/750 支持在 4BSD 中引入）；4BSD Release Notes (1980.10) ［B］

## 31.5.3 其他 4BSD 特性（非 4.1BSD 新增）
- 要点：4BSD（1980.10）除 Job Control 与 VAX-11/750 支持外，还包含：auto reboot（自动重启）、1K block 文件系统（4BSD 从 512 字节块改为 1024 字节块以提升性能，但 FFS 柱面组优化尚未实现）、Pascal 编译器（Peter Kessler 与 Kirk McKusick 移植）、Franz Lisp 系统、增强的邮件处理系统（delivermail）；这些均为 4BSD 特性而非 4.1BSD 新增（McKusick 1999 原文完整列举）

| 4BSD 特性 | 说明 | 引入版本 |
| --- | --- | --- |
| Job Control（作业控制） | Jim Kulp（IIASA）实现，Joy 集成 | 4BSD（1980.10） |
| VAX-11/750 支持 | 代号 "Comet" 中端 VAX 机型 | 4BSD（1980.10） |
| auto reboot（自动重启） | 系统崩溃后自动恢复 | 4BSD（1980.10） |
| 1K block 文件系统 | 从 512 字节改为 1024 字节块 | 4BSD（1980.10） |
| Pascal 编译器 | Kessler 与 McKusick 移植 | 4BSD（1980.10） |
| Franz Lisp 系统 | Lisp 方言实现 | 4BSD（1980.10） |
| delivermail | Allman 开发的早期 MTA | 4BSD（1980.10） |

- 史料：4BSD Release Notes (1980.10)；McKusick, K. (1999) "Twenty Years of Berkeley Unix" ［B］
- 史观：第 5 条组织结构——DARPA 合同资助下的 CSRG 系统化开发模式开始成形
- 辨析：1K 块文件系统是从 512 字节到 FFS（4.2BSD，8K/片段）的中间步骤；Pascal 系统源自 Bill Joy 与 Chuck Haley（查克·黑利） 早期工作，后由 Kessler 与 McKusick 移植到 VAX
- 文献：McKusick, K. (1999) "Twenty Years of Berkeley Unix"（当事人一手完整列举 4BSD 特性清单）；4BSD Release Notes (1980.10) ［B］
