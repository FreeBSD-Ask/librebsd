### 说明

- (ref 1564, Leffler, 1989)：4.3BSD Architecture Manual 由 CSRG 编写，系统描述 4.3BSD 的内核子系统：虚拟内存（含分页/交换）、进程管理、I/O 与文件系统（FFS）、网络子系统与 socket 接口、系统调用层、以及进程间通信。这为第 33 章（4.3BSD 架构）提供了权威的架构一手文档。（单一文献支撑，需后续交叉验证）
- (ref 1562, Morris, 1985)：Robert T. Morris 的《A Weakness in the 4.2BSD Unix TCP/IP Software》指出 4.2BSD 基于 TCP/IP 协议族提供大量软件，其远程执行服务（端口 514）依据源主机标识信任其他主机，使不可信主机可冒充受信主机用户在不提供口令的情况下远程执行命令，暴露了 4.2BSD 信任模型的安全缺陷；这是 4.2BSD 时期安全缺陷与“隐式信任”模型的一手文献。（单一文献支撑，需后续交叉验证）
- (ref 20, McKusick 等, 1984)：McKusick、Joy、Leffler 与 Fabry 的《A Fast File System for UNIX》描述了从原始 512 字节 UNIX 文件系统到随 4.2BSD 发布的新文件系统（快速文件系统 FFS）的变更、动机、方法与实现，标志 4.2BSD 时期文件系统技术对旧 512 字节文件系统的淘汰；该文发表于 ACM Transactions on Computer Systems 第 2 卷第 3 期（1984 年 8 月）。（单一文献支撑，需后续交叉验证）

### 观点

- (ref 1564, Leffler, 1989)：手册强调 BSD 网络子系统与内核其他部分“通过 socket 抽象层解耦”，使 TCP/IP 协议栈可作为独立可替换模块存在；这一设计使后续 4.3BSD-Tahoe/Reno 能渐进引入 NFS、OSI 等新协议。该观点可与第 33 章关于“可扩展网络架构”的论述相互印证。（单一文献支撑，需后续交叉验证）
