# 34.7 4.2BSD 时期的技术淘汰——UUCP 让位于 TCP/IP 与 csh 的兴起

## 34.7.1 UUCP 让位于 TCP/IP 的网络范式转移

**要点**：UUCP（Unix-to-Unix Copy Program）由 Mike Lesk 于 1976 年在 Bell Labs 开发，1977 年随 V7 进入标准 UNIX 发行，是 1970 年代后期至 1980 年代早期 UNIX 机器间文件传输与邮件中继的事实标准；4.2BSD（1983 年 8 月）首次将 DARPA 资助的 TCP/IP 协议栈与 socket API 完整集成入 base system，标志网络范式从 UUCP 的“存储-转发”（store-and-forward）拨号模式转向 TCP/IP 的“实时双向”模式；1986 年 NNTP 协议在 UUCP 之上开发（San Diego 与 Berkeley 之间首次连接），1990 年代早期 UUCP 仍是 Usenet 新闻传输主干，至 1990 年代中期被 TCP/IP 上的 NNTP/HTTP/SMTP 全面取代；UUCP 至今仍作为传统协议在 BSD/UNIX 中保留（FreeBSD base 中保留 **uucp(1)**、**uux(1)**、**uucico(8)**），但实际部署规模已边缘化

| 维度 | UUCP | TCP/IP |
| -- | -- | ---- |
| 引入时间 | 1976（Bell Labs，Mike Lesk） | 4.2BSD（1983.8） |
| 网络模式 | 存储-转发（store-and-forward） | 实时双向（分组交换） |
| 连接方式 | 拨号 | 持久连接 |
| 典型应用 | 邮件中继、Usenet 新闻 | 互联网协议 |
| 退出主流 | 1990 年代中期 | 至今主导 |

**史料**：Lesk 1976“A (Maybe) Optimum Hierarchic File System Design”Bell Labs 内部备忘录、UUCP V7 手册、4.2BSD Release Notes (1983.8) TCP/IP 章节、Spencer & Lawrence 1986“Managing UUCP and Usenet”McGraw-Hill、Quarterman & Hoskins 1986 CACM“Computer Networks of the World”对 UUCP 与 ARPANET 并存状态的描述 ［A］

**史观**：技术路线分化：UUCP（拨号、存储-转发）与 TCP/IP（实时、分组交换）形成 1980 年代 UNIX 网络的双轨；信息技术：网络协议的演化反映信息技术自身的范式转移

**辨析**：UUCP 在 1990 年代后才真正退出主流，“4.2BSD 取代 UUCP”的叙事应理解为“开启取代进程”而非“完成取代”；4.2BSD 的 TCP/IP 实现选择 Joy 自写版本而非 BBN 版本，这一选择对后续 BSD 网络栈影响深远，需考据 DARPA 测试报告

**文献**：Lesk, M. 1976 Bell Labs Internal Memo；UUCP V7 Manual Section 1；4.2BSD Release Notes (1983.8)；Spencer, D. & Lawrence, D. 1986“Managing UUCP and Usenet”McGraw-Hill；Quarterman, J. & Hoskins, J. 1986 CACM“Computer Networks of the World”Vol. 29 No. 10 ［B］

## 34.7.2 csh 与 shell 生态演进

**要点**：C shell（csh）由 Bill Joy 在 2BSD（1978 年中，mid-1978）中引入，提供 C 风格语法、历史记录（!!）、作业控制（Job Control 源自 IIASA Jim Kulp 的工作，由 Joy 集成入内核与 csh）；4.2BSD（1983 年 8 月）将 csh 作为默认交互 shell（interactive shell），但系统脚本仍使用 Bourne shell（/bin/sh）；csh 在 BSD 阵营长期保持默认交互 shell 地位，4.4BSD-Lite（1994 年）仍以 csh 为默认；1990 年代起 tcsh（Ken Greer 1981 年 CMU 原型，1983 年 10 月公开发布）逐步取代 csh 成为 BSD 用户的事实选择，FreeBSD 5.0（2003 年 1 月）将 root 默认 shell 从 csh 改为 tcsh；csh/tcsh 在 BSD base system 中延续至今，但用户默认 shell 市场份额被 bash（1989 年 GNU）与 zsh（1990 年 Paul Falstad）持续侵蚀；CSRG 选择 csh 作为默认交互 shell 而非 Bourne shell 反映 BSD 阵营对 C 语言语法亲和性的偏好

**史料**：Joy, B. (1978) “An Introduction to the C Shell”（2BSD 文档）；McKusick 1999（记载 Jim Kulp job control 由 Joy 集成入 4BSD，1980.10）；4.2BSD Release Notes (1983.8)；4.4BSD-Lite Release Notes (1994.6)；FreeBSD 5.0 Release Notes (2003.1) 默认 shell 变更条目；Anderson, G. & Anderson, P. (1986) “The UNIX C Shell Field Guide” ［B］

**史观**：技术路线分化：BSD（csh/tcsh 谱系）与 System V（Bourne shell/Korn shell 谱系）形成 UNIX shell 的两大分支，分化延续至今；哲学思潮：csh 的“接近 C 语法”反映 1970 年代 C 语言作为高级语言正典化的影响

**辨析**：Job Control 非 Joy 原创，而是源自 IIASA（奥地利）Jim Kulp 的工作，由 Joy 集成入 4BSD（1980.10）内核与 csh（McKusick 1999 原文“Joy incorporated Jim Kulp's job control”）；4.2BSD 将 csh 设为“默认交互 shell”但系统脚本仍使用 /bin/sh，“默认 shell”表述需精确区分交互与脚本场景；FreeBSD 在 5.0 之前 root 默认 shell 为 csh 而非 bash

## 34.7.3 FFS 取代原始 UNIX 文件系统与其他核心特性

**要点**：4.2BSD（1983 年 8 月）引入 Fast File System（FFS，又称 Berkeley Fast File System，后称 UFS1），由 Marshall Kirk McKusick（马歇尔·柯克·麦库西克） 主导实现（论文作者为 McKusick/Joy/Leffler/Fabry 四人），取代 V7/3BSD 的原始 UNIX 文件系统（old file system）；原始 UNIX 文件系统采用 512 字节块、无柱面组、单间接块设计，磁盘寻道效率极差；FFS 引入柱面组（cylinder group）、4KB/8KB 大块、旋转优化、可配置碎片（fragment），McKusick 等 1984 ACM TOCS 论文原文记载吞吐量较原文件系统提升约 8-10 倍（不同基准测试下有差异）；FFS 原型于 1982 年 6 月集成入 4.1b，4.2BSD 正式发布，论文 1984 年 8 月发表于 ACM TOCS；其他 4.2BSD 核心特性还包括：磁盘配额（disc quotas，来自 Robert Elz/墨尔本大学，由 Leffler 集成）、可靠信号机制（new signal facilities，Leffler 实现）、重写独立 I/O 系统简化安装；符号链接（symbolic links）经 FreeBSD 官方手册页 symlink(2) 的 HISTORY 段确认首次出现于 4.2BSD（1983.8）［考据注：2026-07-28 联网考据留痕，模板句式已按 0 信任原则精简（WO-004）；语义以正文与所引来源为准］；sendmail（Eric Allman（埃里克·奥尔曼） 编写）随 4.2BSD 正式发布，取代 4BSD 中的 delivermail；BIND（Berkeley Internet Name Domain）早期版本（4.8.3 及之前）由 CSRG 维护随 4.2BSD 分发，由 Douglas Terry、Mark Painter、David Riggle、Songnian Zhou 四位研究生在 DARPA 资助下开发，Kevin Dunlap（DEC 借调）1985-1987 年重大重写，Paul Vixie 1985 年后才成为主要维护者（非 4.2BSD 时期）；NFS（Network File System）由 Sun 开发，BSD 版本在 4.3BSD-Reno（1990 年初）才由 Rick Macklem（圭尔夫大学）集成入 BSD，非 4.2BSD 特性；FFS 是 BSD 标准文件系统直至 4.2BSD→4.3BSD→4.4BSD 全过程，FreeBSD 中延续为 UFS1，直至 FreeBSD 5.0（2003 年 1 月）引入 UFS2（McKusick 与 Poul-Henning Kamp（波尔-亨宁·坎普） 共同设计）后逐步被取代（UFS1 仍保留兼容支持）；FFS 的设计思想直接影响后续 Linux ext2/ext3/ext4 等文件系统

**史料**：McKusick et al. 1984 ACM TOCS“A Fast File System for UNIX”论文（DOI: 10.1145/989.990，记载 8-10 倍性能提升）；McKusick 1999（记载 FFS 4.1b 1982.6 原型、Elz 磁盘配额、Leffler 实现信号设施、sendmail 取代 delivermail）；ISC 官方 BIND History（记载 BIND 最初四位研究生作者、4.8.3 及之前 CSRG 维护、Dunlap 1985-1987 重写、Vixie 后续维护）；Costales & Allman (1993) 《sendmail》（ISBN 1-56592-056-5）；4.2BSD FFS/网络源代码；Thompson 1978“UNIX Implementation”Bell Labs Tech. Journal ［A］

**史观**：实践先于理论：FFS 的设计源于实际磁盘性能优化需求而非文件系统理论；软件工程：FFS 的柱面组设计是软件工程针对硬件特性的典型优化

**辨析**：FFS 论文作者为四人合著（McKusick/Joy/Leffler/Fabry），非 McKusick 单人设计；FFS 原型集成于 4.1b（1982.6），正式随 4.2BSD（1983.8）发布，论文 1984 年 8 月发表于 ACM TOCS 期刊；FFS 与原始 UNIX 文件系统的关系并非完全取代，而是保留 inode 模型与目录结构，仅替换块分配策略；性能提升“约 8-10 倍”数据出自 McKusick 等 1984 论文原始基准测试，不同硬件配置下结果有差异；NFS 非 4.2BSD 特性，而是 4.3BSD-Reno（1990 初）引入；Paul Vixie 在 4.2BSD 时期（1983）尚未参与 BIND 维护，BIND 4.2BSD 版本由 CSRG 维护；LFS（Log-structured File System，Rosenblum & Ousterhout 1992）在 4.4BSD 中作为实验特性引入，未能取代 FFS；符号链接精确引入版本经 FreeBSD 官方手册页 symlink(2) 确认为 4.2BSD（详见上文考据脚注）——freebsd.duckdb 最早 commit 为 1993-06-12 by Rodney W. Grimes（罗德尼·W·格赖姆斯）（hash 9002c02abc587664acb357c6879d8ca08664dd0b），早于 4.2BSD 约 10 年，无符号链接首次引入的代码级证据，故以 FreeBSD 官方手册页 symlink(2) HISTORY 段为权威依据

## 34.7.4 4.2BSD 时期淘汰史的辨析

**要点**：4.2BSD 时期的技术淘汰具有 “同一版本中并行引入与淘汰” 的特征——4.2BSD 在引入 TCP/IP、FFS、socket 等新组件的同时，使 UUCP、原始文件系统、Thompson shell 等老组件退出默认地位；这种 “并行替代” 模式不同于 1970 年代的 “单点替代”，反映 BSD 项目作为研究集合体在功能引入上的高密度特征；需警惕将 4.2BSD 叙事为 “革命性替代” 的回溯性建构——多数老组件仍以兼容形式延续，淘汰是渐进而非一次性；统计结论 [C-41] references 表总数 16,867 条，[C-42] 年份提取率 44.42%（7,493/16,867），4.2BSD 发布年 1983 年参考文献 92 条累计 886 条（11.82%）、次年 1984 年 96 条累计 982 条（13.11%），4.2BSD 时期 1983-1984 年文献量较 1981-1982 年（39+34 = 73 条）跃升约 2.6 倍（165 条），反映 4.2BSD 集成 TCP/IP 后 BSD 学术影响力显著提升，CSRG 时期（1969-1995）累计 1,879 条占比 25.08%，4.2BSD 时期是 CSRG 文献产出的关键转折点

**史料**：4.2BSD Release Notes (1983.8)——TUHS utree 归档精确路径：`4.2BSD/usr/doc/uchanges/0.t`（标题页，543 字节，1983-08-02，URL: <https://www.tuhs.org/cgi-bin/utree.pl?file=4.2BSD/usr/doc/uchanges/0.t>，标题“Bug fixes and changes in 4.2BSD”，作者 Samuel J.
