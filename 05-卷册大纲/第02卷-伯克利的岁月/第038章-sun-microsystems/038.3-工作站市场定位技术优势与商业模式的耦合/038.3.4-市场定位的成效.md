# 038.3.4 市场定位的成效

**要点**：Sun 市场定位成效显著，**1984 年** 营收 **1.15 亿美元**，**1986 年** **5.46 亿美元**，**1988 年** **12 亿美元**，**1986 年** 超越 Apollo 成为工作站市场第一，**1988 年** 市场份额约 35%，成为 BSD 路线商业化的最大受益者

| 年份 | 营收 | 市场份额 / 里程碑 |
| -- | -- | --------------- |
| 1984 | 1.15 亿美元 | 起步阶段 |
| 1986 | 5.46 亿美元 | 超越 Apollo，成为工作站市场第一 |
| 1988 | 12 亿美元 | 市场份额约 35% |

**史料**：Sun 年报（1984-1988）、Dataquest 市场份额报告、Apollo Computer 破产记录（1989） ［B］

**史观**：第 5 条偶然性——Sun 超越 Apollo 有 BSD 软件优势，亦有 Apollo 内部管理问题等偶然因素，多重偶然叠加决定市场格局

**辨析**：营收数字与市场份额数字需核对 SEC 年报与第三方调研，警惕厂商自夸数据

**文献**：Sun Microsystems 10-K 年报（1984-1988）；Dataquest (1988) “Workstation Market Share”；Apollo Computer SEC 文件（1987-1989） ［B］
