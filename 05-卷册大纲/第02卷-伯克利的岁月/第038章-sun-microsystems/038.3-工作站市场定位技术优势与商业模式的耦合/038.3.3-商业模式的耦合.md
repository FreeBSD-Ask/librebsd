# 038.3.3 商业模式的耦合

**要点**：Sun 采用 “硬件 + 软件 + 服务” 的整合商业模式，硬件销售为主，SunOS 软件作为硬件附加值免费提供，服务收入（培训、咨询、维护）作为辅助，此模式与 BSD 许可证兼容，因 BSD 允许商业再分发

**史料**：Sun 商业计划书（1982）、年报收入结构（1984-1988）、Sun 服务价格表 ［B］

**史观**：专题——“硬件 + 软件 + 服务” 的形式逻辑与 BSD 学术协作的开放逻辑（不设总纲条号）：商业模式的耦合使 BSD 代码被锁定为专有产品组件

**辨析**：SunOS “免费” 提供并非真正免费，其成本隐含在硬件售价中，需区分 “软件定价为零” 与 “软件为公共品”

**文献**：Sun Microsystems 年报（1984-1988）；Southwick (1999) “High Noon”；Rifkin (1991) “Radical Marketing” ［B］
