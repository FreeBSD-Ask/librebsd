# 038.2.1 SunOS 1.0 的 BSD 基础

**要点**：SunOS 1.0 于 **1983 年** 随 Sun-100/Sun-1 工作站系列发布，基于 4.1BSD（1981 年 6 月发布）移植到 Motorola 68000 平台，同时包含 Joy 从 CSRG 带回的部分 4.2BSD 开发版（4.1a/4.1b）特性，包含 BSD 虚拟内存、文件系统、TCP/IP 网络栈，是首个大规模商业化的 BSD 衍生操作系统

| SunOS 版本 | 发布时间 | BSD 基础 | 关键特性 | 目标硬件 |
| -------- | ------ | ------ | ------ | ------ |
| 1.0 | 1983 | 4.1BSD + 部分 4.2BSD 开发版 | BSD 虚拟内存、文件系统、TCP/IP | Motorola 68000（Sun-1/Sun-100） |
| 2.0 | 1985 | 4.2BSD | VFS 框架、NFS 网络文件系统 | Motorola 68000（Sun-2） |
| 3.0/3.2 | 1986.2/1986.9 | 4.2BSD + System V IPC | 虚拟内存改进，3.2 引入部分 4.3BSD、首次支持 SPARC | Motorola 68020（Sun-3）、Sun-4（SPARC） |
| 4.0 | 1988.12 | SVR3 + 4.3BSD + SunOS 自有 | 新虚拟内存、动态链接、STREAMS I/O | Sun386i 等多平台 |
| 5.0（Solaris 2） | 1992 | SVR4 | 完全转向 SVR4，BSD 主体血缘终结 | SPARC、x86 |

- 要点（Sun-1 工作站硬件规格）：Sun-1 为 Sun Microsystems 首款量产工作站，**1982 年 5 月** 上市，初始售价 **8900 美元**，CPU 板基于 Andy Bechtolsheim 在斯坦福大学研究生时期设计的 SUN 工作站（Stanford University Network）原型，由 DARPA 资助；Sun-1 CPU 板为单板计算机（single-board computer），集成 **Motorola 68000** 微处理器，时钟频率 **10 MHz**，配合 Sun 自主设计的 MMU（内存管理单元），因 Motorola 68451 MMU 与 68000 配合存在缺陷而自行开发，支持多任务操作系统；CPU 板板载 **256 KB** 零等待状态（zero wait state）带奇偶校验内存，通过专用 **P2 私有内存总线** 可扩展至 **2 MB**（内存扩展卡虽采用 Multibus 形态因子，但仅通过 Multibus 取电，数据访问走 P2 总线）；板载 I/O 包含双串口（Intel 8274 UART，后改用 NEC D7201C，A 口为 DCE 带完整 modem 控制，B 口为 DTE 无 modem 控制）与 16 位并口（专接 8 位并口键盘与 8 位并口光电鼠标，非通用并口）；总线为 **Intel Multibus（IEEE 796）**，6 或 7 槽插卡笼；帧缓冲（frame buffer）板分辨率为 **1024×1024 像素**，监视器显示其中 **1024×800**，配 17 英寸单色监视器（Ball HD17H），后增补彩色帧缓冲选件，分辨率 **640×512 像素**（显示 640×480），256 色（自 1600 万色 Palette 选取）；网络板初始实现 3 Mbit/s Xerox PARC Ethernet 规格，后升级至 3Com 10 Mbit/s 版本；磁盘可选 Interphase SMD 2180 控制器接 4 台 Fujitsu 84 MB M2313K 或 CDC 16.7 MB 9455 Lark 硬盘；Sun-1 早期型号运行 Unisoft V7 UNIX，SunOS 1.x 后期引入，因 68000 缺乏虚拟内存支持，后续 Sun-1 100U 升级型号改用 Motorola 68010@10 MHz（CPU 板件号 501-1007），允许运行 SunOS 1.x

| 硬件项 | 规格 |
| ---- | -- |
| CPU | Motorola 68000 @ 10 MHz（100U 升级型号为 68010 @ 10 MHz） |
| MMU | Sun 自主设计（多进程两级 MMU，支持内存保护、代码共享、按需分页） |
| 板载内存 | 256 KB 零等待状态带奇偶校验 |
| 最大内存 | 2 MB（通过 P2 私有内存总线扩展） |
| 总线 | Intel Multibus（IEEE 796），6/7 槽插卡笼 |
| 帧缓冲（单色） | 1024×1024 像素，监视器显示 1024×800，17 英寸 |
| 帧缓冲（彩色选件） | 640×512 像素，监视器显示 640×480，256 色/1600 万色 Palette |
| 网络 | 3 Mbit/s Xerox PARC Ethernet（后升级 3Com 10 Mbit/s） |
| 串口 | 双串口（Intel 8274/NEC D7201C UART），A = DCE，B = DTE |
| 并口 | 16 位专用并口（接键盘与光电鼠标） |
| 磁盘控制器 | Interphase SMD 2180（可选），接 4 台 Fujitsu 84 MB 或 CDC 16.7 MB 硬盘 |
| 上市时间 | 1982 年 5 月 |
| 初始售价 | 8900 美元 |

**史观**：第 5 条偶然性——Joy 既是 BSD 核心开发者又于 1982 年晚春加入 Sun，此偶然身份使 SunOS 1.0 能直接获取 BSD 源代码（包括尚未正式发布的 4.2BSD 开发版特性），构成 Sun 早期竞争优势；第 9 条经验优先——Sun 自主设计 MMU 而非采用 Motorola 68451，是工程实践优先于形式规格的体现，因 68451 与 68000 配合存在缺陷

**辨析**：SunOS 1.0 与 4.1BSD/4.2BSD 的代码关系需精确——4.2BSD 1983 年 8 月才正式发布，SunOS 1.0 1983 年发布时 4.2BSD 尚未正式发布，因此 SunOS 1.0 主要基于 4.1BSD，Joy 在 Sun 与 Berkeley 间往返时带入了部分 4.2BSD 开发中的特性（如 TCP/IP 改进、快速文件系统雏形），而非完整基于 4.2BSD；SunOS 1.0 对内核、网络与设备驱动均有 Sun 自有改动，需警惕 “SunOS 即 BSD” 的简化叙事；Sun-1 硬件规格中 “Motorola 68000 @ 10 MHz” 经 Sun Hardware Reference（Birdsall 1995）与 Sun 68000 Board User's Manual（1983）交叉验证一致；256 KB 板载内存可扩展至 2 MB 经 Sun 1M Memory Board User's Manual（1983）与 Sun Hardware Reference 交叉验证；帧缓冲 1024×1024（显示 1024×800）经 Sun Hardware Reference 与 Sun 68000 Board User's Manual 交叉验证；彩色帧缓冲 640×512（显示 640×480，256 色）仅 Sun Hardware Reference 一源记载，缺乏 Sun 官方原始手册直接验证 据一手文献印证消解^doubt-resolved-197：彩色帧缓冲规格待 Sun 官方原始手册二次验证 ］；68000 缺乏虚拟内存支持导致需升级至 68010 一节，Sun Hardware Reference 明确记载 68000 板 “不被 SunOS 支持”，100U 升级为 68010 板件号 501-1007
