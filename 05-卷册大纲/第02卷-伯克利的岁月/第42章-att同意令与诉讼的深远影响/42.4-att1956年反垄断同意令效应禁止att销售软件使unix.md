# 42.4 AT&T 1956 年反垄断同意令效应——禁止 AT&T 销售软件，使 UNIX 源代码以极低成本分发至大学

## 42.4.1 1956 年同意令的内容

**要点**：**1956 年** AT&T 反垄断同意令（Consent Decree）由新泽西地区法院批准，内容包括：AT&T 保留电话业务垄断、禁止 AT&T 销售非电话业务（含计算机与软件）、Bell Labs 研究成果须以合理价格许可、UNIX 源代码可分发至大学但仅收取介质费

| 条款 | 内容 | 对 UNIX 影响 |
| -- | -- | ---------- |
| 业务范围 | AT&T 保留电话业务垄断 | — |
| 业务限制 | 禁止 AT&T 销售非电话业务（含计算机与软件） | UNIX 不能商业销售，仅以介质费分发至大学 |
| 许可义务 | Bell Labs 研究成果须以合理价格许可 | UNIX 源代码可分发至大学 |
| 介质费 | 仅收取介质费（约 200 美元） | 大学获得极低成本的 UNIX 源代码 |

**史料**：United States v. Western Electric Co., **1956** Consent Decree 全文、Bell Labs 1956-1984 年 UNIX 分发记录、AT&T **1956 年** 年报 ［B］

**史观**：第 5 条偶然性——1956 年同意令是反垄断偶然事件，但此偶然使 UNIX 源代码以极低成本分发至大学，奠定 BSD 诞生基础

**辨析**：同意令的具体条款在不同史料中有不同表述，需核对法院判决原文与 AT&T 内部备忘录

**文献**：United States v. Western Electric Co., 1956 Consent Decree；Temin, P. (1987) “The Fall of the Bell System”；Salus, P. (1994) “A Quarter Century of UNIX”［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］

## 42.4.2 同意令对 UNIX 分发的效应

**要点**：1956 年同意令对 UNIX 分发的影响：1969-1984 年 AT&T 以介质费（约 200 美元）向大学分发 UNIX 源代码、大学可自由修改与再分发（如 BSD）、UNIX 在学术社区广泛传播、BSD 与其他 UNIX 变体（如 Vrije 大学 MINIX）得以发展

**史料**：AT&T UNIX 分发记录（1969-1984）、伯克利 CSRG 与 AT&T 的通信、大学 UNIX 采购记录 ［A］

**史观**：第 5 条偶然性——同意令的 “禁止销售软件” 条款是反垄断偶然事件，但此偶然使 UNIX 学术分发成为可能

**辨析**：UNIX 分发的 “极低成本” 需具体化，1969-1975 年仅收介质费，1975-1984 年开始收取少量许可费，需核对 AT&T 价格表

**文献**：AT&T UNIX 分发记录；Salus, P. (1994) “A Quarter Century of UNIX”；McKusick, K. (1999) “Twenty Years of Berkeley Unix” ［B］

## 42.4.3 1984 年 AT&T 拆分后的变化

**要点**：**1984 年 1 月 1 日** MFJ 生效后 AT&T 拆分为 7 个区域性贝尔运营公司，AT&T 保留 Western Electric、Bell Labs、长途电话业务，同时获准进入计算机市场与软件商业化，**1956 年** 同意令对软件销售的限制解除，AT&T 可自由定价 UNIX 源代码

**史料**：MFJ 判决书、AT&T **1984 年** 年报、AT&T UNIX 商业化战略备忘录 ［A］

**史观**：第 4 条分离聚合是永恒规律——**1984 年** 拆分是分离运动，但分离释放了 AT&T 商业化能量，聚合 UNIX 商业化权利

**辨析**：**1984 年** 后 AT&T 的 UNIX 商业化策略需核对，避免将 “商业化权利” 等同于 “立即商业化”，**1984-1986 年** AT&T 仍维持学术折扣

**文献**：MFJ 判决书；Temin, P. (1987) “The Fall of the Bell System”；AT&T **1984 年** 报 ［A］

## 42.4.4 许可费飙升的后果

**要点**：**1985-1988 年** AT&T UNIX 源代码许可费从教育机构免费/200 美元飙升到商业高价（多源交叉印证仅能确认有源区间：**1983 年** 商业约 $43,000/CPU、**1989-1990 年** SVR4 商业 $100,000、McKusick 回忆 “ 约 $250,000 ” 等大致范围；“**1985 年** 200,000 美元 ” 与 “**1987 年** 400,000 美元 ” 两数字无一手来源，系疑似臆造或与其他数字混淆，正文不采信），后果包括：CSRG 启动 Net/1 与 Net/2 重写运动、BSD 商业 fork 厂商寻求替代方案、BSD 路线走向完全自由化、为 Linux **1991 年**发布创造市场需求

**史料**：AT&T UNIX Software Operation **1990.3.28** 公开邮件列表原文（确认 SVR4 商业版 $100,000，"The Price of $100,000 is the commercial price for a Release 4.0 license”）、McKusick 1999 视频（klarasystems 转引，回忆” such a license would cost $250,000"但未指明具体年份）、TUHS 邮件列表 **1983 年**商业约 $43k/CPU 记录、CSRG 关于许可费飙升的备忘录、BSD 商业 fork 厂商的应对记录 ［A］

**史观**：第 2 条历史是形式主义化的非存在——AT&T 的商业化形式逻辑（最大化许可费）催生 BSD 完全自由形式逻辑，形式主义对立驱动 BSD 重写

**辨析**：许可费飙升的 “具体数字” 需按 0 信任原则核对——区分 “教育折扣” 与 “商业价格”，避免将单一价格表等同于普遍价格；“200,000-400,000 美元” 区间无独立一手史料确认，1983 年商业约 $43k/CPU、1989-1990 年 SVR4 商业 $100,000、McKusick 回忆 “约 $250,000”等数字各有来源但无法拼出“1985 年 200,000 美元起、1987 年 400,000 美元”的连续曲线［存疑脚注：doubt-resolved-246——此处事实待多源交叉验证］；AT&T UNIX Software Operation 1990.3.28 公开邮件列表原文确认 SVR4 商业 $100,000 为权威一手来源；经 freebsd.duckdb 查询未得明确证据（查询条件：`SELECT * FROM commits WHERE message_subject LIKE '%license%' OR message_subject LIKE '%fee%' OR message_subject LIKE '%price%' OR message_subject LIKE '%AT&T%'`，freebsd-src 仓库无 AT&T 许可费相关 commit，无法对“ 1985 年 200,000 美元 ”与“ 1987 年 400,000 美元 ” 等具体数字提供代码级证据），暂保留存疑

**文献**：AT&T UNIX Software Operation (1990.3.28) 公开邮件列表（确认 SVR4 商业 $100,000）；McKusick, K. (1999) “Twenty Years of Berkeley Unix” 及 klarasystems 转引的 McKusick 1999 视频（回忆“约 $250,000 ”）；Salus, P. (1994) “ A Quarter Century of UNIX ”；TUHS 邮件列表 1983 年 $43k/CPU 记录 ［A］

**要点**：

- 受访者系统口述了 BSD 起源的制度条件：1956 年反垄断同意令禁止 AT&T 经营计算机软件业，Unix 因此以近乎无偿方式连同源码授权给各大学用于教学研究，伯克利在此基础上持续增补形成 BSD；其后 BSDi 以 1-800-ITS-UNIX 电话号码销售 BSD 触怒持有 Unix 商标的 AT&T，USL 诉讼将 BSD 代码拖入数年法律泥潭，受访者并转引 Linus 的说法称若非 BSD 陷于诉讼，他大概不会另起 Linux。　[考据脚注] 受访者转引 Linus 语录未给出处，须回查原始访谈文本方可征引。（The Changelog EP574，[2411.00-2647.20]，L2）
- 关于诉讼结局与许可证分野，受访者称争议最终仅以约四个文件的重写了结、并无实质侵权成立，但诉讼已足以吓退用户并拖延 BSD 进程；他并回顾 BSD 许可证从含广告条款的多条款版演化为两句条款版——只须保留版权声明、不得冒称己作——并将其概括为 copyfree 与 GPL 的 copyleft 之别：后者要求修改回馈与随附源码，给嵌入式厂商带来持续合规负担，前者只须在手册附一页版权致谢，这正是大量 appliance 厂商选择 BSD 的制度原因。　[考据脚注] “仅四个文件被重写”与广告条款删除过程均系受访者单方陈述，应对照和解协议文本与 4.4BSD-Lite 发布记录核验。（The Changelog EP574，[480.00-795.15]，L2）
- 受访者解释 CDDL 与 GPL 的不兼容机理：CDDL 改编自 Mozilla 公共许可证，允许 CDDL 代码编入以任意许可发布的产品，但 GPL 要求并入代码同样以 GPL 授权且不可改许，形成单向不通；FreeBSD 借两句式许可证将 OpenZFS 全量源码置于 base 系统，由此获得引导器直读 ZFS 池、boot environment 快照回滚、top 直接呈现 ARC 用量等深度集成，并追述其前身为双分区镜像互备的 NanoBSD。　[考据脚注] 受访者自陈非法律人士，许可证解读应与 FSF 正式分析互证。（The Changelog EP574，[1690.00-1982.19]，L2）
- 关于 jails 的谱系，受访者称其概念源于 1999 年一家希望同时托管 PHP 3 与 PHP 4 的网站托管商出资定制、并约定项目完成后一年开源；FreeBSD 由此在 2000 年率先实现操作系统级容器，远早于 Linux 的 namespaces 方案，Sun 亦据此外推 Solaris Zones，而 Solaris 的借鉴反过来使 ZFS 具备向容器委托数据集的能力，形成跨系统循环。　[考据脚注] 委托方与开发者身份系受访者转述，应与 PHK 的原始叙述及 jails 提交记录互证。（The Changelog EP574，[2841.21-3015.00]，L2）

**史观**：

- 总纲3 不存在进步，只有权力再分配：受访者以亲历者身份描述 FreeBSD 治理：每两年由拥有仓库写权限的提交者选举九人组成 core team，其职能是协调方向、仲裁争论与授予写权限，而非自上而下规定路线，他本人曾任两届；以定期改选的委员会替代单一个人权威，使项目权力以制度化节奏反复再分配，并降低对单个个体倦怠或离场的依赖。（The Changelog EP574，[3971.06-4040.29]，L1）
- 总纲5 没有必然性，只有偶然性：受访者提醒，世纪初 BSD 系统管理员的“硬核”光环与 Linux 的“玩具”标签是可反转的历史建构：当年 BSD 文档反而更完善、托管业务首选 BSD，其后 Linux 经 IBM 数十亿美元投入与对 Red Hat 的收购而成熟，两阵营声望结构在二十年间整体倒置；这一位序变动由诉讼、资本与生态事件等偶然条件叠加而成，并非技术优劣的必然。他另以“Unix 不阻止你做蠢事，因为那也会阻止你做聪明事”概括无护栏设计的代价。（The Changelog EP574，[4680.24]，L2）

**辨析**：

- 受访者给出的最有分量的自我批评是把 FreeBSD 比作乐高积木：构件齐备但缺最后 10% 的成品化——jails 自 2000 年即存在，却始终没有 Docker 式拉取即用的镜像仓库；他辨析其中兼有安全考量（永不更新的镜像存在风险）与许可优势（appliance 厂商借此规避 GPL 合规），这也解释了 BSD 生态以 appliance 形态繁荣的格局，但对该批评是否随容器生态演进而失效未作判断。（The Changelog EP574，[4197.15-4448.05]，L2）
