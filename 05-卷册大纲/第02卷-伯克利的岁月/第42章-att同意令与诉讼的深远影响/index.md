# 第 42 章 att同意令与诉讼的深远影响

## 要点

- 法律环境对操作系统生态的影响：USL v. BSDi 加速 BSD 完全自由化与 Linux 崛起、SCO v. IBM 阻止 SCO 阻止 Linux 发展、Apple v. Microsoft 使 Microsoft Windows 主导 GUI 市场，三案显示法律环境对操作系统生态的长期影响
- 将 USL v. BSDi（1992-1994）与两起微软反垄断案对照，可见三案结局分化的多维因素——USL 案以和解收场（3 删 70 改 + 4.4BSD-Lite 发布 + 不起诉承诺，见本卷 40.3/42 章）、US v. Microsoft 以行为和解收场（放弃拆分）、EU v. Microsoft 以维持罚款收场（4.97 亿欧元），三案均未走向“被告被拆解”的最极端救济；关键差异在
- 微软反垄断诉讼谱系（US v. Microsoft 1998-2001、EU v. Microsoft 2004-2007、Caldera v. Microsoft 1996-2000、Novell v. Microsoft 2005-2012）与 USL v. BSDi（1992-1994）共同构成 1990-2010 年代操作系统/软件产业法律战的完整图景：微软案以“反垄断+捆绑”为核心，US
- **1985-1988 年** AT&T UNIX 源代码许可费从教育机构免费/200 美元飙升到商业高价（具体数字 [存疑脚注：2026-08-17 “1985 年 20 万美元”“1987 年 40 万美元”两数字无一手来源，“1983 年 4.3 万美元/CPU、SVR4 10 万美元、McKusick 回忆约 25 万美元”为可查范围，具体年份数字无法确证]：TUHS 邮件列表、McKus
- 版权登记瑕疵的影响：使 USL 初步禁令被驳回、削弱 USL 版权主张、为 BSDi 与伯克利赢得诉讼时间、为 1994 年和解创造有利条件、显示版权登记形式要求对软件版权的重要性，1992-1994 年诉讼中版权瑕疵成为关键论点

## 辨析

- 法律环境的 “决定性” 需核对，避免将法律因素等同于唯一因素，技术与市场因素亦重要
- 三案对照的史料基础须说明——微软两案均为反垄断（不是版权案），与 USL 案的“版权+商业秘密”性质不同，比较时须限定在“软件业大型法律战”层面，避免类比过度；EU v. Microsoft 的互操作披露救济在 2010 年代后被互操作标准与开源替代所部分消解，其历史意义更多在反垄断法教义层面 ［A］
- 对照须限定在“操作系统/UNIX 谱系软件法律战”层面——Caldera/Novell 案是反垄断（非版权），USL 案是版权（非反垄断），微软政府案是反垄断，法律性质各异；但五案共享的“软件业巨头+政府/竞争者+巨额和解”结构使其具备比较价值；另须说明 Caldera 案的 2.8 亿美元为估计值（WSJ 报道 2.75 亿、Groklaw 披露 2.8 亿），以 Groklaw 披露的和解协议
- 许可费飙升的 “具体数字” 需按 0 信任原则核对——区分 “教育折扣” 与 “商业价格”，避免将单一价格表等同于普遍价格；“200,000-400,000 美元” 区间无独立一手史料确认，1983 年商业约 $43k/CPU、1989-1990 年 SVR4 商业 $ 100,000、McKusick 回忆 “约 $250,000”等数字各有来源但无法拼出“1985 年 200,000 美元起、
- 版权瑕疵影响的 “决定性” 需核对，诉讼结果是多重因素叠加，版权瑕疵是关键但非唯一因素
