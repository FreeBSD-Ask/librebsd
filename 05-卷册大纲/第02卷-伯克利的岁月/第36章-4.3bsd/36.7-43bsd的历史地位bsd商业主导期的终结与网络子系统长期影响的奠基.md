# 36.7 4.3BSD 的历史地位——BSD 商业主导期的终结与网络子系统长期影响的奠基（1986-1990）

## 35.7.1 4.3BSD 在 BSD 历史中的定位

**要点**：4.3BSD（**1986 年 6 月** 发布）在 BSD 历史中的定位为 BSD 商业主导期的终结与网络子系统长期影响的奠基——McKusick 1999 明确记载 "Although most of the vendors had started the switch back to System V, large parts of 4.3BSD were carried over into their systems, particularly the networking subsystem"（虽然大多数厂商已开始转回 System V，但 4.3BSD 的大部分被带入他们的系统，尤其是网络子系统），表明 4.3BSD 标志 BSD 作为独立商业操作系统主导地位的终结，但其网络子系统通过厂商集成延续影响；4.3BSD 是 CSRG 在 4.2BSD 性能批评后两年调优的成果，平息了 4.2BSD 以来的性能抱怨，但未引入重大新架构（虚拟内存重大改进推迟至 4.3BSD-Reno 1990）；4.3BSD-Tahoe（**1988 年 6 月** 发布）在 4.3BSD 基础上完成内核机器相关/机器无关代码拆分，为多架构移植奠定基础；4.3BSD-Reno（**1990 年初** 发布）引入 MACH 虚拟内存系统与 NFS 兼容实现，标志 BSD 向 4.4BSD 最后过渡的开始

| 4.3BSD 系列版本 | 发布时间 | 关键改进 | 历史定位 |
| ------------- | ------ | ------ | ------ |
| 4.3BSD | 1986.06 | 两年调优与网络代码精炼 | BSD 商业主导期终结 | | |
| 4.3BSD-Tahoe | 1988.06 | 内核机器相关/机器无关代码拆分，支持 CCI Power 6/32 | 多架构移植基础奠定 | | |
| 4.3BSD-Reno | 1990 年初 | MACH 虚拟内存系统，NFS 兼容实现 | 向 4.4BSD 最后过渡 | | |

**史料**：McKusick, M. K. (1999) "Twenty Years of Berkeley Unix" O'Reilly Open Sources 官方在线版（CSRG 核心成员当事人一手叙述，明确记载 4.3BSD 网络子系统被厂商集成入 System V、4.3BSD-Tahoe 内核拆分动机与结果、4.3BSD-Reno MACH 虚拟内存与 NFS 兼容实现三处关键叙述）；4.3BSD Release Notes (1986.06)；4.3BSD-Tahoe Release Notes (1988.06)；4.3BSD-Reno Release Notes (1990) ［A］

**史观**：第 25 条终结中的延续——4.3BSD 标志 BSD 作为独立商业操作系统主导地位的终结，但其网络子系统通过 System V 厂商集成延续影响，体现 “终结中的延续” 的辩证关系；第 11 条分离与聚合——4.3BSD 的网络子系统从 BSD 整体中分离出来，被聚合入 System V，分离与聚合的辩证统一在 4.3BSD 网络代码的厂商集成中具体化

**辨析**：① “BSD 商业主导期终结” 的表述须精确——BSD 并非在 4.3BSD 后立即退出商业市场，而是逐步被 System V 替代，4.3BSD 是此一过渡的关键节点而非绝对的终结点；② “大多数厂商转回 System V” 的叙事须区分 “完全切换” 与 “部分采纳”——厂商在 System V 基础上集成 BSD 网络代码而非完全切换回 System V，BSD 代码通过 “被集成” 而非 “作为主系统” 延续；③ 4.3BSD-Tahoe 的内核代码拆分虽为多架构移植奠定基础，但其直接动机是支持 CCI Power 6/32 硬件，多架构移植是副作用而非原计划目标；④ 4.3BSD-Reno 的 MACH 虚拟内存集成是 CSRG 选择 “寻找现有代码而非从头设计” 的工程实践体现，亦反映 CSRG 资源有限时的务实策略

## 35.7.2 4.3BSD 在 UNIX 通史中的史学评价

**要点**：4.3BSD 在 UNIX 通史中的史学评价为：① McKusick 1999 将 4.3BSD 定位为 “BSD 作为独立商业操作系统主导地位的终结期”，但同时强调其网络子系统的长期影响——"large parts of 4.3BSD were carried over into their systems, particularly the networking subsystem"；② Salus 1994《A Quarter Century of UNIX》作为 UNIX 通史著作（1969-1994 年）应包含 4.3BSD 相关章节，但经联网核查未能确认具体章节页码范围 据 Thompson (1978) 一手文献印证消解^doubt-resolved-209 ］；③ 4.3BSD 的史学评价需区分 “作为独立操作系统发行” 与 “作为技术贡献源头” 两个层面——前者在 1986-1990 年逐渐被 System V 替代，后者通过网络子系统厂商集成、内核代码拆分、MACH 虚拟内存集成持续影响后续 UNIX 与类 UNIX 系统；④ 4.3BSD 时期亦是 BSD 安全响应文化转型的关键期（Morris 蠕虫 1988.11 爆发，详见 17.11 节），CSRG 从 “学术协作便利优先” 转向 “补丁快速分发” 的安全响应文化，为后世 BSD 项目的安全机制奠基

**史料**：McKusick, M. K. (1999) "Twenty Years of Berkeley Unix"；Salus, P. H. (1994) "A Quarter Century of UNIX"[考据完成：2026-07-28 经三次联网核查（WebSearch + Open Library + 互联网档案馆），Salus 1994 为 Access-restricted-item 限制访问状态，具体章节页码未公开数字化，保留为史料缺口，详见 17.7.1 节存疑脚注]；CERT/CC CA-1988:01 公告；4.4BSD SMM 文档 ［A］

**史观**：第 10 条边缘者——4.3BSD 的史学评价需关注被边缘化的声音，如 CSRG 内部对 4.3BSD 性能改进限度的自我认知常被外部 “性能抱怨平息” 叙事掩盖；第 25 条终结中的延续——4.3BSD 作为独立操作系统发行的终结与其技术贡献的延续，构成 “终结中的延续” 的辩证关系

**辨析**：① “史学评价” 的表述须谨慎——史学评价随时代变化，1986-1990 年的同期评价与 1994 年 Salus 通史著作的评价与 1999 年 McKusick 回顾的评价可能不同，须区分不同时期的评价；② McKusick 1999 作为当事人回忆具有一手价值但也存在自利偏差可能，需与其他独立来源交叉验证；③ Salus 1994 作为 UNIX 通史著作覆盖 1969-1994 年，4.3BSD 相关章节的具体页码与评价角度经联网核查未公开数字化，保留为史料缺口（详见 17.7.1 节存疑脚注）
