# 041.5.3 AIX 的对比

**要点**：IBM AIX（1986-）基于 System V Release 2 与 4.3BSD 混合，运行于 IBM RT、RS/6000、Power 平台，AIX 1.0（1986）BSD 占比较高，AIX 3.0（1990）转向 SVR3 主体，AIX 4.0（1994）转向 SVR4，网络栈早期 BSD 套接字，后期 SVR4 TLI/XTI

**史料**：IBM AIX Release Notes（1986-1995）、IBM RS/6000 硬件手册、IBM 年报 ［A］

**史观**：第 11 条分离与聚合——AIX 与 HP-UX 类似，早期 BSD/SysV 混合，后期 SVR4 化，反映 1980-1990 年代 UNIX 商业路线趋同

**辨析**：AIX 的 BSD 部分占比在不同史料中有不同说法，需核对 IBM 内部开发记录

**文献**：IBM AIX Release Notes（1986-1995）；IBM 年报；Salus, P. (1994) “A Quarter Century of UNIX” ［B］
