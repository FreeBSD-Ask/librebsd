# 28.5 csh 与 sh 的竞争——man page 版本对照与归档

## 28.5.1 csh man page 的版本演化

**要点**：**csh 手册页**首次出现于 **2BSD**（man page 内部日期 **1979-02-24**），由 Bill Joy 编写，对应 csh 1.0 版本；**1BSD**（1978.3.9，TUHS 归档 1BSD/man1/ 目录确认）不含 csh man page，1BSD/man1/ 仅含 cd.1、lib.1、login.1、sh.1（Bourne Shell）、su.8、wait.1 共 6 个 man page，1BSD READ_ME 提及的 “modified shell” 与 “new shell” 均无独立 man page；csh man page 在 2BSD 中文件名为 **csh.u**（位于 `man/csh.u`，UCB 本地卷标记 `.TH CSH UCB 2/24/79 UCB`），并非标准的 `csh.1`——`.u` 后缀为 2BSD 时期伯克利本地 man page 卷（Berkeley local volume），2BSD/man/ 目录下所有 man page（共 70 余个）均使用 `.u` 后缀（如 vi.u、ex.u、termcap.u 等）；自 **3BSD**（1979-11-07）起 csh man page 改用标准文件名 **csh.1**（位于 `usr/man/man1/csh.1`，TH 行 `.TH CSH 1 11/7/79`，使用标准 man page 卷 1）；csh man page 在 4BSD（1980-09-28，TH 行 `.TH CSH 1 9/28/80`、`.UC 4`）、4.1cBSD（1983-02-09，TH 行 `.TH CSH 1 "9 February 1983"`、`.UC 4`）、4.2BSD（1983-07-18，TH 行 `.TH CSH 1 "18 July 1983"`、`.UC 4`）、4.3BSD（1986-06-05，TH 行 `.TH CSH 1 "June 5, 1986"`）中持续更新，TH 行内部日期随 csh 功能扩展（作业控制增强、信号处理改进、文件名补全等）而递增；TUHS utree 提供 csh man page 各版本的可直接访问 URL（见史料字段）
