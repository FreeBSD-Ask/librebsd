# 28.1 1978 年 2BSD 与 vi 编辑器的诞生——Joy 在 300 波特调制解调器上的设计约束

## 28.1.1 2BSD 发布的时间语境

**要点**：**2BSD** 的发布时间存在史料分歧——McKusick 1999 一手原文与 Salus 1994 记为 “mid-1978”（1978 年中），TUHS RELEASE_DATES 一手归档亦记为 “2 BSD mid 1978 [QCU]”（[QCU] 表示来源为 Salus《A Quarter Century of UNIX》）；但 TUHS 归档的 2BSD 实体磁带标签（Keith Bostic（基思·博斯蒂克） 提交）显示 “Second Berkeley Software Tape May 10, 1979 TAR 800BPI”，READ_ME 文件日期戳为 “Thu Apr 19 1979”——此为按 0 信任原则优先采信的一手物理证据；2BSD 在 1BSD 基础上新增 vi 可视编辑器、C Shell 与 curses 库，是 PDP-11 平台上 BSD 的成熟版本；2BSD 时期累计发出约 75 份磁带拷贝

> By mid-1978, the software distribution clearly needed to be updated...The result of the update was the 'Second Berkeley Software Distribution’
>
> ——McKusick, K. (1999) “Twenty Years of Berkeley Unix”

| 2BSD 新增组件 | 作者 | 首次出现版本 | 说明 |
| ----------- | -- | ---------- | -- |
| vi 可视编辑器 | Bill Joy（基于 Coulouris em 与 ex） | 2BSD | 完整可视模式，1BSD 仅有 ex 1.1 |
| C Shell（csh） | Bill Joy | 2BSD | 类 C 语法、历史替换、作业控制 |
| curses 库 | Ken Arnold | 2BSD | vi 全屏可视化的技术前提 |
| termcap 数据库 | Bill Joy / Mark Horton（归属存疑） | 2BSD | 终端能力抽象化 |
| Berknet | Eric Schmidt（硕士论文） | 2BSD | 伯克利本地网络协议 |

## 28.1.3 300 波特调制解调器的技术约束

**要点**：Joy 通过 300 波特调制解调器远程访问 PDP-11，每秒约 30 字符的传输速率使其倾向于减少按键次数，直接塑造了 vi 的模态编辑与快捷键设计

**史料**：Joy 的回忆访谈、1970 年代调制解调器技术手册、伯克利网络配置记录 ［A］

**史观**：第 7 条硬件与软件辩证——低速调制解调器的物理约束催生了 vi 的模态设计，硬件限制成为软件创新的源泉

**辨析**：Joy 使用的调制解调器确切速率（300 还是 110 波特）在不同访谈中存在出入，需核对原始设备记录

**文献**：Joy, W. (1978) “An Introduction to Display Editing with vi”；AT&T (1976) “Bell System Modem Handbook” ［B］

## 28.1.4 vi 与 ed/ex 的谱系关系

**要点**：vi 的谱系源于 ed（Ken Thompson 1971 年行编辑器）→ em（George Coulouris 1975 年秋在 QMC 开发，1976 年夏带到伯克利）→ ex（Joy 与 Haley 1976-1977 年在 em 基础上扩展的行编辑器）→ vi（Joy 1978 年在 ex 基础上添加可视模式，随 2BSD 1978 年中首次以 vi 名称发布），体现编辑器的渐进演化

| 谱系节点 | 名称 | 含义 | 时间 | 主要作者 | 平台 |
| ------ | -- | -- | -- | ------ | -- |
| 0 | ed | 标准 | 1971 | Ken Thompson（Bell Labs） | PDP-7/11 |
| 1 | em | Editor for Mortals | 1975 秋 | George Coulouris（QMC） | PDP-11 |
| 2 | ex | eXtended | 1976-1977 | Joy/Haley（伯克利） | PDP-11 |
| 3 | vi | visual | 1978 | Bill Joy（伯克利） | PDP-11，随 2BSD 发布 |

**要点**：

- McKusick 亲述 BSD 名称起源：Bill Joy 为磁带分发而命名为 Berkeley Software Distribution，早期无版本号，后以 2BSD 起开始编号，至 3BSD 才统一源码与 make 构建。（BSD Now EP5，[1151.64-1265.94]，L1）
- McKusick 亲述 UFS 设计：文件系统被分为策略与实现两层，实现层写于 1982 年、此后未改一行，日志、布局与更新策略的演进均落在策略层。（BSD Now EP5，[1883.32-1986.24]，L1）
- BSD 曾拟从 Sun 引入其重构的虚拟内存系统以支持 mmap，因法律顾虑被律师否决，转而引入 CMU Mach 的 VM，后由 FreeBSD 开发者精简其外部 pager 等机制。（BSD Now EP5，[1338.02-1537.26]，L1）
- FreeBSD 9.2 正式发布，带来 ZFS TRIM 与 LZ4、virtio 驱动、DTrace 更新及 OpenSSH 更新等；同期基础系统以 Unbound 与 LDNS 取代 BIND。（BSD Now EP5，[70.76-89.24]，L2）

**史料**：

- 当事人 Marshall Kirk McKusick 自述 1970 年代入读加州大学伯克利分校，与 Bill Joy 同室，师从 Susan Graham 从事程序设计语言研究，是本期 BSD 起源叙述的一手来源。（BSD Now EP5，[960.48-1006.58]，L1）
- 当事人提及 David Greenman、Doug Rabson 精简 VM、Rick Macklem 长期维护 NFS、Jeff Roberson 完成 SUJ 主体，均为其亲述的同行贡献。（BSD Now EP5，[1638.30-1764.70]，L1）
- 当事人自述正与 George Neville-Neil、Robert Watson 撰写《The Design and Implementation of the FreeBSD Operating System》第四版，目标当年底完成初稿。（BSD Now EP5，[2038.08-2064.36]，L1）

**史观**：

- 总纲9 经验优先：McKusick 自述 UFS 实现层自 1982 年起未改一行，并坦言其设计事后证明是好的，稳定性的根据是长期经验而非事先的完备规划。（BSD Now EP5，[1883.32-1986.24]，L1）
- 总纲5 没有必然性，只有偶然性：Sun 因法律顾虑拒绝回授 VM，迫使 BSD 转而采用 CMU Mach，这一关键技术路线由偶然的法律与组织因素塑造，而非必然的技术演进。（BSD Now EP5，[1338.02-1537.26]，L1）
- 总纲10 动手者创造历史：访谈记录 Bill Joy、Jeff Roberson、Rick Macklem 等具体动手者在磁带分发、文件系统与 NFS 上的具体工作，而非以机构或领袖为中心。（BSD Now EP5，[1638.30-1764.70]，L1）
