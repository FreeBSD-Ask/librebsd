# 046.4.2 里程碑事件类

### 新闻条目 1

- **新闻标题（中英）**：NetBSD 2007 年度变更：Kauth 框架与 Veriexec 改进（NetBSD 2007 Changes: Kauth Framework and Veriexec Improvements）
- **新闻来源**：NetBSD 官方变更页（jp.netbsd.org 镜像）+ 2007 年度归档 + URL `<http://jp.netbsd.org/changes/2007.html>` + 存档 URL `<https://web.archive.org/web/2008/https://www.netbsd.org/changes/2007.html`>
- **新闻摘要**：NetBSD 2007 年度变更记录提及 Kernel Authorization（Kauth）框架与 Veriexec 文件完整性子系统的改进。Kauth 作为 NetBSD 内核授权的统一抽象层，将传统的超级用户与 securelevel 模型与系统解耦；Veriexec 用于加固系统抵御木马攻击，提供文件指纹验证机制。这两项改进构成 NetBSD 现代安全模型的基础设施。
- **与本章主题的关联说明**：2007 年 Kauth 框架与 Veriexec 改进是 NetBSD 安全模型现代化进程中的关键里程碑，标志 NetBSD 从传统 BSD securelevel 模型向可插拔 secmodel 框架演进。
- **与官方史料的交叉验证结论**：与 NetBSD 官方 `<https://www.netbsd.org/changes/2007.html>` 一致；Kauth 框架说明与 `<https://man.netbsd.org/kauth.9>` 手册页一致；Veriexec 说明与 `<https://man.netbsd.org/veriexec.9>` 手册页一致。

### 新闻条目 2

- **新闻标题（中英）**：NetBSD about：Security and memory hardening features（NetBSD 安全与内存加固特性）
- **新闻来源**：NetBSD 官方介绍页 + 持续维护 + URL `<https://www.netbsd.org/about/>` + 存档 URL `<https://web.archive.org/web/2024/https://www.netbsd.org/about/`>
- **新闻摘要**：NetBSD 官方介绍页明确列出 NetBSD 的安全与内存加固特性：包括 PaX MPROTECT（W^X）默认全局强制执行并可选排除特定二进制文件；Veriexec 提供文件完整性保护；传统 BSD securelevels 进一步限制超级用户的操作；NetBSD 原生防火墙 NPF；内核与用户态经过代码 sanitizer 与自动化测试的广泛检查。
- **与本章主题的关联说明**：直接对应本章 “NetBSD 安全模型（1994-2026）” 主题的官方自我表述；PaX MPROTECT、Veriexec、securelevel、NPF 四大安全支柱均在官方介绍中得到权威说明。
- **与官方史料的交叉验证结论**：本身即为 NetBSD 官方介绍页面，与 `<https://man.netbsd.org/security>` 安全手册页、`<https://man.netbsd.org/veriexec>` Veriexec 手册页、`<https://man.netbsd.org/secmodel_securelevel>` securelevel 手册页、`<https://man.netbsd.org/npf>` NPF 手册页逐一交叉验证一致。

### 新闻条目 3

- **新闻标题（中英）**：secmodel(9) — NetBSD Manual Pages（secmodel(9) 手册页：NetBSD 安全模型框架）
- **新闻来源**：NetBSD 官方手册页 + 持续维护 + URL `<https://man.netbsd.org/secmodel.9>` + 存档 URL `<https://web.archive.org/web/2024/https://man.netbsd.org/secmodel.9`>
- **新闻摘要**：secmodel(9) 手册页详细说明 NetBSD 的可插拔安全模型框架。NetBSD 通过 kauth(9) scope 与 action 集合提供对底层安全模型的完整抽象，允许通过附加/分离 kauth(9) 监听器修改安全模型（轻微修改或采用完全不同的模型）。secmodel 通常实现为内核 module(9)，可静态内建或运行时动态加载；其决策可基于内核直接信息、用户态守护进程或集中式网络授权服务器。
- **与本章主题的关联说明**：secmodel(9) 手册页是理解 NetBSD 安全模型架构的权威一手史料；展示 NetBSD 从传统 securelevel 向可插拔、模块化安全模型框架的演进路径。
- **与官方史料的交叉验证结论**：本身即为 NetBSD 官方手册页，与 `<https://man.netbsd.org/kauth.9>` kauth 手册页、`<https://man.netbsd.org/module.9>` module 手册页相互引用一致；secmodel_register()、secmodel_deregister()、secmodel_eval() API 与 NetBSD 源码 `sys/secmodel/` 一致。
