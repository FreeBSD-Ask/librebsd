# 039.11.1 sendmail DEBUG 命令调试模式后门 → 弃用与默认禁用（1988.11-1989）

**要点**：4.2BSD 与 4.3BSD 早期 sendmail 配置默认开启 DEBUG 命令模式（`-d` 调试标志），DEBUG 命令允许远程主机通过 SMTP `DEBUG` 命令直接调用 sendmail 内置的解释器执行任意 shell 命令，本为开发期调试便利而保留为生产默认配置（4.3BSD sendmail 默认开启 DEBUG 模式，具体版本号 [考据完成：2026-08-17 sendmail DEBUG 后门经 Spafford（CACM 1989）与 FBI 确认、4.3BSD 默认开启；具体版本号各源记载不一（5.59/5.61），不锁定单一版本]）；Morris 蠕虫（**1988 年 11 月 2 日晚 8:30** EST）利用此漏洞作为主要感染路径之一，从 MIT AI Lab 释放后通过 sendmail DEBUG 命令远程感染约 **6000 台** 4BSD/Sun-3 UNIX 机器；Berkeley 与 MIT 团队 **1988 年 11 月 4 日** 起逆向分析蠕虫代码，**1988 年 11 月 8 日** National Computer Security Center 主持 Worm Postmortem Meeting（apricot.net 1997 回顾性编年史料，非一手文档）同步发布修复补丁默认禁用 DEBUG 命令；4.3BSD-Tahoe（**1988 年 6 月** 发布）早于 Morris 蠕虫（**1988 年 11 月**）发布，未包含蠕虫修复补丁；sendmail DEBUG 后门的默认禁用是 Morris 蠕虫事件直接推动的安全改进，标志 BSD 安全模型从 “开发便利优先” 向 “生产安全优先” 的迁移

| 旧机制（4.3BSD 早期） | 新机制（Morris 蠕虫后） | 修复版本 |
| ------------------- | --------------------- | ------ |
| sendmail DEBUG 默认开启 | 默认禁用 DEBUG 命令 | 1988.11.8 修复补丁 |
| fingerd 固定 512 字节缓冲区 | 动态分配 + 输入长度检查 | 1988.11.8 修复补丁，4.3BSD-Reno 完善 |
| rshd 跨主机信任链传递 | 禁止跨主机信任链、要求显式 `.rhosts` | 1988.11.8 修复补丁，4.3BSD-Reno/Net/2 完善 |
| 隐式信任安全模型 | 显式审计日志 + CERT/CC 制度化响应 | 4.3BSD-Reno 引入审计，CERT/CC 1988.11.17 成立 |

**史料**：4.3BSD sendmail 源代码（含 DEBUG 命令实现）；Morris 蠕虫源代码（Berkeley 逆向分析版本）；BSD 修复补丁（1988.11.8，禁用 sendmail DEBUG）；Spafford, E. (1989) “The Internet Worm Program”；Eichin, M. & Rochlis, J. (1989) “With Microscope and Tweezers”；CERT/CC CA-1988-01 公告 ［A］

**史观**：第 2 条形式主义——sendmail 调试模式后门是形式主义便利（开发期调试）吞并安全实质，形式便利膨胀为安全灾难，Morris 蠕虫事件后形式便利被淘汰；第 5 条偶然性——Morris 蠕虫偶然事件直接推动 sendmail DEBUG 后门弃用，偶然事件触发系统性安全改进

**辨析**：sendmail DEBUG 命令被 “淘汰” 指默认禁用而非完全删除，管理员仍可显式启用，须区分 “默认禁用” 与 “完全弃用”；据 McKusick 1999 当事人一手叙述确认，4.3BSD-Tahoe 发布于 1988 年 6 月，早于 Morris 蠕虫（1988 年 11 月），故 Tahoe 版本不可能预先包含蠕虫修复补丁；Morris 蠕虫利用 sendmail DEBUG 是主要感染路径还是辅助路径在不同史料中描述详略不一，需核对 Spafford 蠕虫分析原始手稿；4.3BSD sendmail DEBUG 模式具体版本号 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］——经 freebsd.duckdb 查询未得明确证据（查询条件：`SELECT * FROM commits WHERE message_subject LIKE '%sendmail%' OR message_subject LIKE '%DEBUG%' OR message_subject LIKE '%4.3BSD%'`，freebsd-src 仓库最早 commit 为 1993-06-12T14:49:13Z by Rodney W.
