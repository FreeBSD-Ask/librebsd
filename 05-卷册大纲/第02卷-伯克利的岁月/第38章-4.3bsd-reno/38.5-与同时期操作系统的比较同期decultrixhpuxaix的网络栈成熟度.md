# 38.5 与同时期操作系统的比较：同期 DEC Ultrix、HP-UX、AIX 的网络栈成熟度

## 38.5.1 DEC Ultrix 的对比

**要点**：DEC Ultrix（1984-1995）基于 4.2BSD 与 4.3BSD，运行于 VAX 与 DECstation（MIPS）平台，网络栈直接源自 BSD，成熟度与 4.3BSD 相当，但 DEC 后期转向 OSF/1（1990），Ultrix 维护减弱，1995 年停止开发

**史料**：DEC Ultrix Release Notes（1984-1995）、DEC OSF/1 迁移指南、DEC 年报（1984-1995） ［B］

**史观**：第 11 条分离与聚合——Ultrix 与 BSD 主干既分离（厂商 fork）又聚合（直接基于 BSD 源代码），分离与聚合的辩证统一

**辨析**：Ultrix 与 BSD 源代码的具体关系需核对，部分史料称 Ultrix“直接基于 BSD”，部分称“基于 BSD 与 System V 混合”，需核对 DEC 内部开发记录

**文献**：DEC Ultrix Release Notes（1984-1995）；DEC 年报；Salus, P. (1994) “A Quarter Century of UNIX” ［B］

## 38.5.2 HP-UX 的对比

**要点**：HP-UX（1984-）早期基于 System III 与 BSD 混合，1.0（1984）支持 HP 9000 系列，网络栈早期基于 BSD 套接字，后期转向 SVR4，HP-UX 9.0（1992）后完全 SVR4 化，网络栈成熟度低于同期 4.3BSD，但商业支持更强

**史料**：HP-UX Release Notes（1984-1995）、HP 9000 硬件手册、HP 年报 ［A］

**史观**：第 11 条分离与聚合——HP-UX 早期 BSD/System III 混合聚合，后期 SVR4 转向分离 BSD 路线

**辨析**：HP-UX 早期版本的 BSD 占比需核对，部分史料夸大 BSD 占比，需核对源代码版权头

**文献**：HP-UX Release Notes（1984-1995）；HP 年报；Salus, P. (1994) “A Quarter Century of UNIX” ［B］

## 38.5.3 AIX 的对比

**要点**：IBM AIX（1986-）基于 System V Release 2 与 4.3BSD 混合，运行于 IBM RT、RS/6000、Power 平台，AIX 1.0（1986）BSD 占比较高，AIX 3.0（1990）转向 SVR3 主体，AIX 4.0（1994）转向 SVR4，网络栈早期 BSD 套接字，后期 SVR4 TLI/XTI

**史料**：IBM AIX Release Notes（1986-1995）、IBM RS/6000 硬件手册、IBM 年报 ［A］

**史观**：第 11 条分离与聚合——AIX 与 HP-UX 类似，早期 BSD/SysV 混合，后期 SVR4 化，反映 1980-1990 年代 UNIX 商业路线趋同

**辨析**：AIX 的 BSD 部分占比在不同史料中有不同说法，需核对 IBM 内部开发记录

**文献**：IBM AIX Release Notes（1986-1995）；IBM 年报；Salus, P. (1994) “A Quarter Century of UNIX” ［B］

## 38.5.4 网络栈成熟度比较

**要点**：1986-1990 年网络栈成熟度比较：4.3BSD > DEC Ultrix（直接基于 BSD） > HP-UX（BSD/SysV 混合） > AIX（SysV 为主） > System V Release 3（无 TCP/IP），BSD 在 TCP/IP 实现成熟度上领先，TCP/IP 在 **1990 年** SVR4 才成为标准

| 操作系统 | 网络栈来源 | TCP/IP 成熟度 | SVR4 化时间 | 备注 |
| ------ | -------- | ----------- | --------- | -- |
| 4.3BSD（含 Tahoe/Reno） | CSRG 原生 | ★★★★★ 最高 | — | TCP/IP 实现源头，1980 年代起持续领先 |
| DEC Ultrix | 4.2BSD/4.3BSD 直接派生 | ★★★★ 高 | 1990 转 OSF/1 | 1995 年停止开发 |
| HP-UX | BSD/System III 混合 | ★★★ 中 | 1992（HP-UX 9.0） | 早期 BSD 套接字，后期 SVR4 TLI/XTI |
| IBM AIX | System V R2 + 4.3BSD 混合 | ★★ 中低 | 1994（AIX 4.0） | AIX 3.0（1990）转 SVR3，BSD 占比下降 |
| System V Release 3 | 无 TCP/IP | ★ 无 | — | TCP/IP 在 1990 年 SVR4 才成为标准 |

**史料**：1986-1990 年各操作系统 TCP/IP 性能基准测试、各厂商网络栈源代码对比 ［A］

**史观**：第 9 条经验优先——BSD 在 TCP/IP 上的领先源于 1980 年代早期实践积累，而非理论先行

**辨析**：成熟度比较需基于具体指标（吞吐量、延迟、稳定性），避免主观判断，需核对第三方基准测试

**文献**：CSRG 网络栈性能报告（1988）；各厂商 TCP/IP 性能基准测试（1986-1990）；Salus, P. (1994) “A Quarter Century of UNIX”［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］
