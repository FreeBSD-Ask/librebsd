# 31.10 3BSD 时期的技术淘汰——PDP-11→VAX 平台迁移、32V 简单换页 →3BSD 请求调页式虚拟内存与 3BSD 内核改造（1979）

## 31.10.1 PDP-11 平台 → VAX-11/780 平台的迁移与 PDP-11 主流地位退场（1979）

**要点**：BSD 早期开发（1BSD 1977 年初、2BSD 1978 年中）以 PDP-11 为主要平台，PDP-11 的 16 位地址空间（64KB）与最大 4MB 物理内存成为 BSD 功能扩展的硬件瓶颈——无法支持完整 TCP/IP 网络栈、虚拟内存、大型数据库等需求；1977 年 10 月 25 日 DEC 发布 VAX-11/780（32 位地址空间、4GB 虚拟内存、硬件页表与 TLB 支持），为 BSD 提供超越 PDP-11 的硬件基础；3BSD（1979 年 12 月发布）是 BSD 首次在 VAX 上运行的完整版本，由 Özalp Babaoğlu（厄扎尔普·巴巴奥卢） 实现核心虚拟内存系统、Bill Joy 协助集成调试并完成 2BSD 工具移植；3BSD 标志着 BSD 主平台从 PDP-11 向 VAX 的迁移，PDP-11 上的 2BSD 进入维护模式（1980 年代后期由 Keith Bostic（基思·博斯蒂克） 维护 2.11BSD，1990 年代才逐步停止），但 PDP-11 不再是 BSD 主要功能开发平台；VAX 平台主导 BSD 后续 4BSD（1980.10）、4.1BSD（1981.6）、4.2BSD（1983.8）、4.3BSD（1986.6）、4.4BSD-Lite（1994.6）全部版本直至 1990 年代初 BSD 分支转向 386 与 SPARC；统计结论 [C-41] references 表总数 16,867 条，[C-42] 年份提取率 44.42%（7,493/16,867），1979 年（3BSD 发布年）参考文献 58 条累计 681 条（9.09%）、1980 年（DARPA 合同年）40 条累计 721 条（9.62%），CSRG 时期（1969-1995）累计 1,879 条占比 25.08%，3BSD 所处 1979-1980 年属 CSRG 时期文献积累的早期阶段

## 31.10.2 UNIX/32V 简单换页机制 → 3BSD 请求调页式虚拟内存的引入（1979）

**要点**：UNIX/32V（Bell Labs 1978 年由 John Reiser 和 Tom London 完成移植，UNIX V7 内核的 VAX 移植版）仅支持简单的换页（swapping）机制——整个进程在内存与磁盘交换区之间整体换入换出，无法按需调页，导致进程地址空间受物理内存限制、上下文切换开销大；**3BSD**（**1979 年 12 月**）由 Özalp Babaoğlu 实现核心 working set 分页系统、Bill Joy 协助集成到 32V 内核并调试，加入请求调页式虚拟内存（demand paging）——利用 VAX 硬件页表与 TLB，进程可使用大于物理内存的虚拟地址空间，仅按需将页面从磁盘调入内存，淘汰了 32V 的整体换页机制；3BSD 内核镜像命名为 `/vmunix`（virtual memory UNIX），此命名延续至 4.4BSD；3BSD 虚拟内存机制是 BSD 在 VAX 上的核心创新，为后续 4BSD（1980.10）、4.1BSD（1981.6）、4.2BSD（1983.8）、4.3BSD（1986.6）的虚拟内存子系统奠定基础；4.4BSD（1994）采用从 CMU Mach 2.5 移植的虚拟内存系统，UVM（Universal Virtual Memory）为 NetBSD 于 1998 年左右引入的替代 VM 系统，非 4.4BSD 所有；请求调页的核心设计可追溯至 3BSD

| 维度 | UNIX/32V（1978） | 3BSD（1979.12） |
| -- | -------------- | ------------- |
| 内存机制 | 简单换页（swapping） | 请求调页（demand paging） |
| 进程地址空间 | 受物理内存限制 | 大于物理内存的虚拟空间 |
| 硬件利用 | 无虚拟内存硬件支持 | 利用 VAX 页表与 TLB |
| 上下文切换 | 整体换入换出，开销大 | 按需调页，开销小 |
| 内核镜像命名 | — | `/vmunix` |
| 核心实现者 | John Reiser、Tom London（32V 移植） | Özalp Babaoğlu（VM）、Bill Joy（集成） |

**史料**：UNIX/32V 源代码与文档（1978）；3BSD 内核源代码；Babaoğlu 博士论文（UCB/ERL M81/92, 1981-11-17，“Virtual Storage Management in the Absence of Reference Bits”，URL: <https://www2.eecs.berkeley.edu/Pubs/TechRpts/1981/7560.html）；Babaoğlu> & Joy SOSP '81 论文（"Converting a swap-based system to do paging in an architecture lacking page-referenced bits", SOSP ’81, pp. 78-86, 1981-12-01, DOI: 10.1145/800216.806595）；Babaoğlu, Joy & Porcar 设计论文（"Design and Implementation of the Berkeley Virtual Memory Extensions to the UNIX Operating System"，PDF: <http://roguelife.org/~fujita/COOKIES/HISTORY/3BSD/design.pdf）；DEC> (1978) “VAX Architecture Reference Manual”；McKusick, K. (1999) “Twenty Years of Berkeley Unix”；Quarterman, J. S. et al. (1985) “4.2BSD and 4.3BSD as Examples of the UNIX System” ［A］

**史观**：第 7 条硬件与软件辩证——VAX 的硬件虚拟内存支持（页表、TLB）使 3BSD 的请求调页实现成为可能，硬件能力决定软件设计空间；第 17 条软件工程——请求调页是软件工程中内存管理抽象化的关键迁移，从整体换页到按需调页

**辨析**：32V 的换页机制被 “淘汰” 指 BSD 谱系中的弃用，32V 本身作为 Bell Labs 产品未被立即淘汰，须区分 BSD 内部迁移与 AT&T 32V 产品延续；3BSD 虚拟内存的核心实现者为 Özalp Babaoğlu（主导 working set paging 设计与初始实现），Bill Joy 协助内核集成、调试与用户空间工具移植；UNIX/32V 移植者为 Bell Labs 的 John Reiser 与 Tom London，David Kashtan 为 SRI 研究员（未参与 32V 或 3BSD 开发，后做 VMS vs BSD 性能基准测试）；3BSD 虚拟内存是否受 TENEX/TOPS-20 设计影响存在争议，需核对设计文档；`/vmunix` 命名在 CSRG 4.xBSD 系列中一直沿用，4.4BSD-Lite（1995）仍为 `/vmunix`；FreeBSD 2.x/3.x 时代仍使用 `/vmunix`，后改为 `/kernel`，现代 FreeBSD 使用 `/boot/kernel/kernel`，须区分各 BSD 版本与分支的内核镜像命名演变；[2026-08-14 两库核查：32V（John Reiser、Tom London 1978）与 3BSD（1979.12）请求调页迁移早于邮件库覆盖范围，参考文献库无 32V/3BSD 条目，两库无法验证]

## 31.10.3 32V 内核改造为 3BSD 内核与 BSD 独立内核谱系的起点（1979）

**要点**：UNIX/32V（1978 年由 Bell Labs 的 John Reiser 和 Tom London 完成移植）作为 Bell Labs V7 UNIX 的 VAX 移植版，其内核结构与 V7 UNIX 基本一致——简单换页、无虚拟内存抽象、无网络支持；3BSD（1979.12）以 32V 内核为基础进行深度改造——加入由 Özalp Babaoğlu 实现的请求调页式虚拟内存、加入 2BSD 工具集（vi、csh、Pascal）、改造内核引导与初始化流程；3BSD 是 BSD 谱系首次以完整独立系统形式发布（1BSD 1977 年初、2BSD 1978 年中均为 V6/V7 UNIX 附加组件，仅含 Pascal、ex/vi、termcap、csh 等用户工具，未含独立内核），标志着 BSD 从 Bell Labs UNIX 附加组件向独立操作系统的转型起点；3BSD 内核被后续 4BSD（1980.10）、4.1BSD（1981.6）、4.2BSD（1983.8）、4.3BSD（1986.6）、4.3BSD-Tahoe（1988.6）、4.3BSD-Reno（1990 初）、4.4BSD（1994.6）、4.4BSD-Lite（1995.6）继承与发展，直至 CSRG 解散后 FreeBSD、NetBSD、OpenBSD 各分支独立演化；3BSD 内核改造是 BSD 谱系独立性的技术奠基

**史料**：UNIX/32V 源代码（1978）；3BSD 内核源代码；3BSD Release Notes (1979.12)；Joy, W. (1979) “3BSD Kernel Changes”；McKusick, K. (1999) “Twenty Years of Berkeley Unix”；CSRG 内部档案 ［A］

**史观**：第 4 条分离与聚合——3BSD 将 2BSD 工具集与 32V 内核聚合为统一系统，体现技术演化的聚合特征；第 17 条软件工程——3BSD 内核改造是软件工程中 “基础重写” 的典型案例，从 Bell Labs 移植版到独立 BSD 内核

**辨析**：3BSD 是 “BSD 谱系首次以完整独立系统形式发布” 须严格区分——1BSD（1977 年初）、2BSD（1978 年中）虽为伯克利发布但本质为 Bell Labs UNIX 的附加组件（含 Pascal 系统、ex/vi 编辑器、termcap、csh 等用户工具），依赖 AT&T V6/V7 内核运行，不具独立内核；3BSD 内核改造程度在不同史料中描述详略不一，需核对 3BSD 与 32V 源代码 diff；3BSD 不包含网络支持——TCP/IP 网络协议栈由 BBN 的 Rob Gurwitz 交付早期原型，经 Bill Joy 集成调优后在 4.2BSD（1983.8）才完整引入，3BSD 仅有可能存在极早期实验性代码但未作为正式功能发布；4.1BSD（1981.6）发布于 4BSD（1980.10）之后，原 “1981.4” 系误记，据 McKusick 当事人一手叙述修正；4.4BSD-Lite（1995.6）后 CSRG 解散，BSD 谱系分裂为 FreeBSD、NetBSD、OpenBSD 等分支，须区分 “3BSD 起点的 CSRG 连续谱系” 与 “4.4BSD-Lite 后的各分支独立演化”

**文献**：UNIX/32V 源代码（1978）；3BSD 内核源代码；3BSD Release Notes (1979.12)；Joy, W. (1979) “3BSD Kernel Changes”；McKusick, K. (1999) “Twenty Years of Berkeley Unix” ［A］
