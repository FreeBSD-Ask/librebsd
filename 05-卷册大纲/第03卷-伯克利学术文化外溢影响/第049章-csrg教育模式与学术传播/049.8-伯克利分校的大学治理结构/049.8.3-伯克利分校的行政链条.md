# 049.8.3 伯克利分校的行政链条

  **要点**：伯克利分校的行政链条为：加州大学系统校长（President）→ 伯克利分校校长（Chancellor）→ 教务长（Provost）→ 学院院长（Dean）→ 系主任（Department Chair）→ CSRG 主任，行政链条使 CSRG 在大学治理结构中有明确位置，但实际运作中 CSRG 有较大自主权

  | 层级 | 职务 | 对 CSRG 的关系 |
| -- | -- | ------------ |
| 1 | 加州大学系统校长（President） | 系统层面 |
| 2 | 伯克利分校校长（Chancellor） | 分校层面 |
| 3 | 教务长（Provost） | 学术事务 |
| 4 | 学院院长（Dean） | 学院层面 |
| 5 | 系主任（Department Chair） | EECS 系 |
| 6 | CSRG 主任 | CSRG 直接上级 |

**史观**：第 2 条形式主义——行政链条的形式逻辑（层级管理）吞并了 CSRG 的实质自主，形式管理与实质自主并存
  
**辨析**：行政链条的 “实际约束力” 需核对，CSRG 实际运作中可能绕过部分行政层级，需核对内部档案
