# 44.2 BSD 文档作为教育载体：man pages、手册与论文——BSD man pages 的教育哲学含义、CSRG 发布的各类技术手册作为知识形式主义、4.2BSD Manual 与 4.4BSD Manual 的文档史、BSD 文档的修道度人维度

## 43.2.1 BSD man pages 的教育哲学含义

  **要点**：BSD man pages 的教育哲学含义为：man pages 是 “代码即文档” 传统的具体化，每个命令、系统调用、库函数均有对应 man page，man pages 既是技术参考也是教学文本，其简洁性与精确性体现 BSD 工程哲学，与 GNU info 系统的扩展性形成对比

  | man page 分类 | 含义 | 示例 |
| ----------- | -- | -- |
| **命令 (1)** | 用户命令 | **ls(1)**、**vi(1)**、**csh(1)** | | |
| **命令 (2)** | 系统调用 | **open(2)**、**read(2)**、**fork(2)** | | |
| **命令 (3)** | 库函数 | **printf(3)**、**malloc(3)** | | |
| **命令 (4)** | 设备与特殊文件 | **tty(4)**、**null(4)** | | |
| **命令 (5)** | 文件格式 | **fstab(5)**、**passwd(5)** | | |
| **命令 (6)** | 游戏 | **trek(6)**、**rogue(6)** | | |
| **命令 (7)** | 杂项 | **ascii(7)**、**environ(7)** | | |
| **命令 (8)** | 系统管理与维护 | **mount(8)**、**fsck(8)** | | |

**史料**：4.2BSD man pages 原文、CSRG 关于 man pages 编写规范的文档、Unix Programming Manual（Kernighan & Pike 1984） ［B］
  
**史观**：第 2 条形式主义——man pages 的 “命令 (N)” 分类形式逻辑（命令分类）吞并了文档的实质组织，形式分类成为 BSD 文档的标准
  
**辨析**：man pages 的 “教育性” 需核对，部分 man pages 偏技术参考，教学性有限，需区分 “参考文档” 与 “教学文档”
  
**文献**：Kernighan, B. & Pike, R. (1984) "The Unix Programming Environment"；4.2BSD man pages；McKusick, K. (1999) "Twenty Years of Berkeley Unix" ［B］

## 43.2.2 CSRG 技术手册作为知识形式主义

  **要点**：CSRG 发布的技术手册包括 4.2BSD Manual（**1983**）、4.3BSD Manual（**1986**）、4.4BSD Manual（**1994**）、BSD System Manager's Manual、BSD User's Reference Manual、BSD Programmer's Manual，手册作为知识形式主义将 BSD 系统分类为可索引、可检索的知识体系

  | 手册名称 | 出版年 | 分类 |
| ------ | ---- | -- |
| 4.2BSD Manual | **1983** | 系统总手册 | | |
| 4.3BSD Manual | **1986** | 系统总手册 | | |
| 4.4BSD Manual | **1994** | 系统总手册 | | |
| BSD System Manager's Manual | — | 系统管理（Manager） | | |
| BSD User's Reference Manual | — | 用户参考（User） | | |
| BSD Programmer's Manual | — | 程序员参考（Programmer） | | |

**史料**：4.2/4.3/4.4BSD Manual 原文、CSRG 手册编写记录、BSD 手册分类规范 ［A］
  
**史观**：第 2 条形式主义——手册的分类形式逻辑（User/Programmer/Manager）吞并了 BSD 系统的实质组织，形式分类塑造 BSD 知识体系
  
**辨析**：手册的 “形式主义” 需核对，分类有其工程实用性，需区分 “形式逻辑” 与 “实用分类”
  
**文献**：4.2/4.3/4.4BSD Manual；McKusick, K. (1999) "Twenty Years of Berkeley Unix"；CSRG 手册编写规范 ［A］

## 43.2.3 4.2BSD Manual 与 4.4BSD Manual 的文档史

  **要点**：4.2BSD Manual（**1983**）由 Joy、Fabry、Leffler 等编写，约 1000 页，奠定 BSD 文档传统；4.4BSD Manual（**1994**）由 McKusick、Karels、Bostic 等编写，约 2000 页，是 CSRG 最后一份完整文档，两份手册的对比显示 BSD 系统 11 年的演化轨迹

  | 维度 | 4.2BSD Manual | 4.4BSD Manual |
| -- | ----------- | ----------- |
| 出版年 | **1983** | **1994** | | |
| 主要编写者 | Joy、Fabry、Leffler | McKusick、Karels、Bostic | | |
| 页数 | 约 1000 页 | 约 2000 页 | | |
| 历史地位 | 奠定 BSD 文档传统 | CSRG 最后一份完整文档 | | |
| 演化跨度 | 11 年 BSD 系统演化轨迹 | 同左 | | |

**史料**：4.2BSD Manual（**1983**）、4.4BSD Manual（**1994**）、CSRG 文档编写记录[考据完成：2026-07-28 经穷尽联网考据，上述史料清单为已知公开来源汇总，部分原始档案未公开数字化或须档案馆藏地现场核验，属史料缺口，须待原始档案公开后方可补充确证] 〔L3 官方文档与公告〕
  
**史观**：第 9 条经验优先——手册演化是 BSD 系统演化的事后文档化，实践先于文档
  
**辨析**：手册页数的 “具体数字” 需核对，避免事后估算，需核对原始手册。经参考文献库核查：4.2BSD Manual（1983）与 4.4BSD Manual（1994）的出版年份与 Salus（1994，reference_id=810）所载 4.2BSD 1983 年发布、dexter（2017，reference_id=596）所载 4.4BSD-Lite2 1995 年时间线相符；但“约 1000 页”“约 2000 页”的具体页数两库无法验证，保留原考据
  
**文献**：4.2BSD Manual（1983）；4.4BSD Manual（1994）；McKusick, K. (1999) "Twenty Years of Berkeley Unix" ［B］

## 43.2.4 BSD 文档的修道度人维度

  **要点**：BSD 文档的修道度人维度为：文档编写是开发者自我修行（修道），文档阅读是后来者学习（度人），两者辩证统一，CSRG 成员通过编写 man pages 与手册实现自我修行，同时通过文档发布帮助后来者学习 BSD

  > 代码即文档，文档即修行；写文档的人度不了别人，但写文档这件事本身就是在修行。

  | 维度 | 修道（自我修行） | 度人（后来者学习） |
| -- | -------------- | ---------------- |
| 主体 | CSRG 成员（文档编写者） | 后来者（文档阅读者） | | |
| 形式 | 编写 man pages 与手册 | 阅读 man pages 与手册 | | |
| 关系 | 辩证统一 | 同左 | | |

**史料**：McKusick 关于文档编写的访谈、CSRG 文档编写规范、BSD 文档用户反馈 ［B］
  
**史观**：第 14 章边缘者——文档编写的 “度人” 维度常被代码开发的 “修道” 维度掩盖，需恢复文档编写的度人价值
  
**辨析**：修道度人的 “哲学深度” 需谨慎，CSRG 成员未必有系统的修道度人思考，需区分 “实践哲学” 与 “理论哲学”
  
**文献**：McKusick, K. (1999) "Twenty Years of Berkeley Unix"；CSRG 文档档案；Unix Programming Manual ［B］
