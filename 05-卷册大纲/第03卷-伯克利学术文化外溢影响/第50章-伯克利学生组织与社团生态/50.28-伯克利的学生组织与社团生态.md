# 50.28 伯克利的学生组织与社团生态：ASUC 章程与历史、GA 章程与职能、学生社团分类与注册管理、兄弟会与姐妹会生态、学生媒体的独立性、CSRG 时期学生组织对 BSD 开发的间接支持——CSRG 运作所在的学生社团土壤

> 伯克利分校的学生组织与社团生态由 ASUC（Associated Students of the University of California）作为本科生官方代表机构、GA（Graduate Assembly）作为研究生与专业学生官方代表机构、CalLink 作为社团注册管理平台、Cal Greeks 作为兄弟会姐妹会统一品牌、The Daily Californian 与 KALX 电台作为独立学生媒体共同构成。CSRG 作为伯克利 EECS 系内的研究小组，其运作所在的学生社团土壤既是 CSRG 成员（多数为研究生）的校园生活背景，也是 BSD 开发的间接支持环境——CSRG 时期的学生组织通过 OCF（Open Computing Facility）等学生自治计算设施间接支持 Unix/BSD 文化在学生中的传播。本节以 6 个子-子节铺陈此学生社团土壤，史观自反承认：将 “学生组织与社团生态” 与 “CSRG 运作” 关联是史家的解释学循环，CSRG 当事人未必以此社团框架理解自身处境。

## 50.28.1 ASUC 章程、选举、预算与历史

  **要点**：（一）成立：ASUC 成立于 **1887 年 3 月 2 日**（ASUC 宪法序言明示 “ASUC Constitution, March 2, 1887”），原为 UC 系统唯一校区（伯克利）的学生会；（二）法律地位：ASUC 为独立的 501(c)(3) 非营利组织，独立于大学治理结构（ASUC 官方页面明示 "the ASUC is an independent 501(c)3 non profit organization separate from University governance"），是全国最大、最具自治性的学生组织之一；（三）历史：早期 ASUC 控制学术以外的所有校园事务（学生行为、学生商店、Cal Athletics、所有学生组织服务），二战后 ASUC 将部分活动交还大学，保留 Lower Sproul 综合体的学生服务，**1990 年代** ASUC 与大学签订协议，确立当前商业活动与学生服务的共享治理结构；（四）职能：ASUC 控制学生社团与组织的资助、提供资源与学生项目、监督商业活动与学生服务（含 Cal Student Store 与 Lower Sproul Plaza，与 ASUC Student Union 合作）、在大学/地方/州/国家层面代表学生利益、在行政校园委员会上代表学生主体；（五）项目：ASUC 资助 SUPERB、OCF（Open Computing Facility）、DeCals 等项目，其中 OCF 与 BSD/Unix 文化在学生中的传播直接相关

  | 时间 | ASUC 事件 | 性质 |
| -- | ------- | -- |
| **1887 年 3 月 2 日** | ASUC 成立 | 学生会建立 |
| 二战后 | ASUC 将部分活动交还大学 | 职能调整 |
| **1990 年代** | ASUC 与大学签订共享治理协议 | 当前结构确立 |
| CSRG 时期（1978-1992） | ASUC 资助 OCF 等项目 | 间接支持 Unix/BSD 文化 |

### 史观映射

> 伯克利的学生组织与社团生态不是 CSRG 运作的 “背景”，而是 CSRG 生长的具体学生社团土壤——ASUC（1887 年成立的独立 501(c)(3) 非营利组织）、GA（研究生与专业学生官方代表机构）、CalLink（社团注册管理平台）、Cal Greeks（四个 Greek Councils 的统一品牌）、The Daily Californian 与 KALX 电台（独立学生媒体），构成 CSRG 运作所在的学生社团土壤。学生组织对 BSD 开发的支持主要是间接的——通过 OCF 提供 Unix 计算设施、通过学生社团传播 Unix/BSD 文化、通过学生媒体报道计算机相关议题。史家在叙事中须自反承认：将 “学生组织与社团生态” 与 “CSRG 运作” 关联是一种阐释而非当事人自述，CSRG 核心成员本人是否将学生组织视为支持 BSD 开发的重要因素未见明确口述记录。本节呈现的是学生组织作为 CSRG 生长学生社团土壤的长时段语境，而非 CSRG 作为学生组织组成部分的因果叙事——避免时代错置与简单归因。史观自反检验：本节所给出的 “学生组织间接支持” 与 “CSRG 运作” 的关联本身也是一种形式主义的建构，是项目史观总纲第 27 章 27.2 节原文 “反对形式主义必须走个形式，而反对之要点就是用形式反对形式主义，只要反对得好，就不是形式主义” 在史编纂中的具体应用——本节以形式主义化的叙事呈现学生社团土壤，但自反承认其形式主义性质。
