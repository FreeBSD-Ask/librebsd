# 066.7.1 db(3) 库的设计与实现

  **要点**：CSRG 的 db(3) 库研究起于 **1987-1988 年**（Seltzer 的动态哈希研究）、实现完成于 **1990-1991 年**，随 **4.4BSD**（1993-06）发布（又称 BSD db 库），提供三种访问方法：（1）hash——基于 Margo Seltzer 的动态哈希算法实现（Seltzer & Ozmat 1992 年论文“Hash Strategies for Hash-Based Databases”〔题名待一手核验〕）；（2）btree——基于 B+ 树实现有序键访问；（3）recno——基于固定/变长记录号访问；db(3) 库的接口由 Keith Bostic 设计，统一三种访问方法于同一 API（dbopen/DBTYPE/close/del/get/put/seq/sync）；db(3) 是 Berkeley DB 的前身，Seltzer 与 Bostic 后续基于 db(3) 的经验开发 Berkeley DB

| 访问方法 | 数据结构 | 实现者 |
| --- | --- | --- |
| hash | 动态哈希表 | Margo Seltzer |
| btree | B+ 树 | Keith Bostic〔btree 实现归属须核 4.4BSD 源码注释，不宜一律记 Bostic〕 |
| recno | 固定/变长记录号 | Keith Bostic〔同上待核〕 |

  | db(3) 统一 API | 功能 |
| ------------ | -- |
| dbopen | 打开数据库，指定访问方法（hash/btree/recno） |
| close/del/get/put/seq/sync | 关闭/删除/获取/存储/顺序遍历/同步 |

**史料**：4.4BSD db(3) 源代码与手册页（**dbopen(3)**、**hash(3)**、**btree(3)**、**recno(3)**）、Seltzer & Ozmat 1992 年哈希策略论文、CSRG 内部档案 ［B］
  
**史观**：第 9 条经验优先与第 4 条分离与聚合——db(3) 的实践（统一三种访问方法）先于形式化的数据库访问方法理论，hash/btree/recno 在数据结构上分离但在 API 上聚合，分离与聚合的辩证关系使 db(3) 既灵活又统一
  
**辨析**：db(3) 时间线经发行史核验修正——研究起于 1987-1988（Seltzer 动态哈希研究）、实现完成于 1990-1991、随 4.4BSD（1993-06）发布（多源一致：4.4BSD-Lite 发行说明与 Berkeley DB 发布记录确认 db 库首个发行版于 1991 年出现，含 b+ 树数据访问算法；原“1986-1988 年在 4.4BSD 中实现”与发行史矛盾已改正）；db(3) 提供三种访问方法（hash/btree/recno）——多源一致，hash 基于动态哈希表，btree 基于 B+ 树，recno 基于记录号；hash 方法基于 Margo Seltzer 的实现——Seltzer 与 Ozmat 1992 年论文“Hash Strategies for Hash-Based Databases”描述了动态哈希算法 [存疑脚注：论文题名与期刊卷期待一手原文核验]；db(3) 的统一 API（dbopen）由 Keith Bostic 设计——多源一致，Bostic 是 CSRG 核心成员，后与 Seltzer 共同开发 Berkeley DB；db(3) 与 Berkeley DB 1.85 的关系——db(3) 是 4.4BSD 自带的数据库库，Berkeley DB 1.85 是 Seltzer/Bostic 基于 db(3) 经验开发的独立产品，二者在 4.4BSD 中共存 [存疑脚注：需核对 4.4BSD-Lite 源代码确认 db(3) 与 Berkeley DB 1.85 的具体文件分布与调用关系]；[考据脚注：db(3) 源代码随 4.4BSD-Lite 发布，可在 CSRG Archive CD-ROM 或 TUHS 归档查阅 4.4BSD-Lite 源代码中的 db/hash/btree/recno 目录核实]
  
**文献**：4.4BSD-Lite db(3) 源代码与手册页（CSRG Archive CD-ROM / TUHS 归档）；Seltzer M, Ozmat N. Hash Strategies for Hash-Based Databases [J]. 1992 [存疑脚注：具体期刊与卷期待一手原文核验]；McKusick M K, Bostic K, Karels M J, Quarterman J S. The Design and Implementation of the 4.4BSD Operating System [M]. Reading, MA: Addison-Wesley, 1996 ［B］
