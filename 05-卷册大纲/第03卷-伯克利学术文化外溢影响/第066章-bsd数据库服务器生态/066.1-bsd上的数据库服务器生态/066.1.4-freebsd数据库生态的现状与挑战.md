# 066.1.4 FreeBSD 数据库生态的现状与挑战

  **要点**：FreeBSD 数据库生态的现状与挑战：（1）现状：FreeBSD 数据库生态以 PostgreSQL、MySQL、SQLite 为核心，freebsd-ports/databases/ 下维护数百个数据库相关 Port；（2）挑战：商业数据库服务器（Oracle Database、IBM DB2、Microsoft SQL Server、SAP HANA）原生缺失使 FreeBSD 在传统企业数据库市场难以与 Linux 竞争；（3）挑战：Linux 容器（Docker 2013、Kubernetes 2014）生态主导云原生数据库部署，FreeBSD Jails 虽早于 Docker 14 年（1999 vs 2013）但生态较小，sysutils/docker Port（2015-07-06T15:37:33Z by Kris Moore）为 FreeBSD 上的 Docker 移植但非原生；（4）挑战：FreeBSD 性能优化资源（开发者数量、企业资金）少于 Linux，使数据库性能优化在硬件新特性支持上滞后；FreeBSD 数据库生态须基于实用主义哲学（开源为主、质量优先）应对挑战

  | FreeBSD 数据库生态现状 | 内容 |
| -------------------- | -- |
| 核心数据库 | PostgreSQL、MySQL、SQLite |
| Port 数量 | freebsd-ports/databases/ 下维护数百个数据库相关 Port |

  | FreeBSD 数据库生态挑战 | 类型 | 内容 |
| -------------------- | -- | -- |
| 商业数据库缺失 | 传统企业市场 | Oracle/IBM DB2/Microsoft SQL Server/SAP HANA 原生缺失 |
| 容器生态落后 | 云原生数据库 | Linux 容器（Docker 2013、Kubernetes 2014）主导；Jails 早 14 年但生态较小 |
| 性能资源不足 | 硬件新特性 | 开发者数量、企业资金少于 Linux，硬件新特性支持滞后 |

**史料**：freebsd.duckdb commit_files 表（sysutils/docker commit b9d84bad，2015-07-06 by Kris Moore）、freebsd-ports/databases/ 目录、Docker 2013 发布档案、Kubernetes 2014 发布档案、Jails 1999 引入档案 ［B］
  
**史观**：第 14 章边缘者与第 9 条经验优先——FreeBSD 数据库生态作为边缘者（市场份额小但质量高），须基于实践（开源为主、质量优先）而非理论（市场份额）应对挑战；Jails（1999）早于 Docker（2013）14 年但生态较小，反映实践先于理论但市场成功非纯技术因素
  
**辨析**：Docker 引入 freebsd-ports 时间经 freebsd.duckdb 查询确认为 2015-07-06T15:37:33Z by Kris Moore（commit b9d84bad“FreeBSD port of Docker”），同日 x11/docker 重命名为 x11/docker-tray（commit dd5c9a9c by Kris Moore“- Rename x11/docker -> x11/docker-tray”）以腾出 docker 名字给容器工具——原 x11/docker（2003-06-05 by Adam Weinberger）是 X11 dock 应用，与 Linux 容器 Docker 同名但无关；Kubernetes 在 freebsd-ports 中无原生主 Port，仅有依赖库（如 rubygem-azure_mgmt_kubernetes_configuration，2020-04-24 by Sunpoet Po-Chuan Hsieh）与补丁文件，反映 Kubernetes 在 FreeBSD 上无官方支持；Linux 容器生态主导数据库部署的时间点为 Docker 2013 年开源（dotCloud 创始人 Solomon Hykes 于 2013-03 公开演示）后至 Kubernetes 2014 年发布（Google 于 2014 年 6 月发布 Kubernetes v0.1）

**观点**：1997 年，Wolfram Schneider 的 FreeBSD ports 双周公告首次以“Main Category databases”列出 db-2.1.0（Berkeley DB 2.0.6）、mysql-3.20.22、p5-DBD-Pg 与 PostgreSQL 6.1、p5-DBD-mysql 等条目。
**邮件来源**：Wolfram Schneider，comp.unix.bsd.freebsd.announce，1997 年，Message-ID: `5p6fl1$dk7@bonkers.taronga.com>#1/1`
**史学意义**：ports 官方公告将 Berkeley DB、MySQL、PostgreSQL 并列为独立的 databases 门类，标志 BSD 数据库服务器生态在 1997 年完成从散件到类目的制度化。
