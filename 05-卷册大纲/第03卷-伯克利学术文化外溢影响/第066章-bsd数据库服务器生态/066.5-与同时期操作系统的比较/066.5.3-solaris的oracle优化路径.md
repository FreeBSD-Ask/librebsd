# 066.5.3 Solaris 的 Oracle 优化路径

  **要点**：Solaris 的 Oracle 优化路径：（1）Oracle Database 在 Solaris 上深度优化——Solaris 与 Oracle Database 的集成可追溯至 Solaris 2.x 时代（1990 年代），Oracle 收购 Sun（2010-01 完成收购）后强化 Solaris 优化；（2）Solaris 的 ZFS 文件系统（2005-01 随 Solaris 10 正式发布）与 Oracle Database 深度集成，提供快照、复制、校验和等数据完整性保障；（3）Solaris 的 DTrace 由 Bryan Cantrill（布莱恩·坎特里尔）、Michael Shapiro、Adam Leventhal 设计，2004 年 USENIX ATC 发表论文“Dynamic Instrumentation of Production Systems”（获最佳论文奖），2005-01 随 Solaris 10 正式发布，提供数据库性能分析；（4）2010-01 Oracle 收购 Sun 后，Solaris 的 Oracle 优化路径延续但市场逐步萎缩，Oracle Database 12c 后 Solaris 优先级下降；Solaris 的路径反映垂直整合哲学

  | Solaris Oracle 优化时间线 | 时间 | 事件 |
| ----------------------- | -- | -- |
| Solaris 2.x 集成 | 1990 年代 | Solaris 与 Oracle Database 的集成可追溯至此 |
| DTrace 论文发表 | **2004 年** | Cantrill、Shapiro、Leventhal 于 USENIX ATC（获最佳论文奖） |
| Solaris 10 正式发布 | **2005 年 1 月 31 日** | ZFS 与 DTrace 随 Solaris 10 正式发布 |
| Oracle 收购 Sun 完成 | **2010 年 1 月 27 日** | Oracle 强化 Solaris 优化 |
| Solaris 11.4 | **2018 年 8 月** | 最后一个主要版本 |
| Oracle Database 12c 后 | **2013 年** | Solaris 优先级下降 |

  | Solaris 关键技术 | 引入时间 | 与数据库的关系 |
| -------------- | ------ | ------------ |
| ZFS | **2005 年 1 月**（Solaris 10） | 与 Oracle Database 深度集成，提供快照、复制、校验和等数据完整性保障 |
| DTrace | **2005 年 1 月**（Solaris 10） | 提供数据库性能分析（Cantrill/Shapiro/Leventhal 设计，2004 USENIX ATC 最佳论文） |

  | Solaris 市场萎缩时间线 | 时间 | 事件 |
| -------------------- | -- | -- |
| Oracle Database 12c | **2013 年** | Solaris 优先级下降 |
| Oracle Database 18c | **2018 年** | Solaris 优先级进一步下降 |
| Solaris 11.4 | **2018 年 8 月** | 最后一个主要版本 |

**史料**：Oracle Database on Solaris 优化档案、ZFS 与 Oracle Database 集成文档、Cantrill/Shapiro/Leventhal 2004 USENIX DTrace 论文（获最佳论文奖）、Solaris 10（2005-01）DTrace 与 ZFS 引入档案、Oracle 2010-01 收购 Sun 后 Solaris 市场萎缩档案 ［B］
  
**史观**：第 4 条分离与聚合——Solaris 的垂直整合（Oracle + Solaris + ZFS + DTrace）反映聚合路径，与 BSD 的开源分离路径形成对比
  
**辨析**：Oracle 收购 Sun 完成时间确认为 2010-01-27（Oracle 官方公告）；Solaris 10 正式发布时间确认为 2005-01-31（Sun 官方公告）；DTrace 论文“Dynamic Instrumentation of Production Systems”由 Cantrill、Shapiro、Leventhal 联合发表于 2004 年 USENIX Annual Technical Conference，获最佳论文奖（USENIX 官方档案确认）；ZFS 随 Solaris 10 2005-01 发布（Sun 官方公告确认）；Solaris 市场萎缩——Oracle Database 12c（2013）后 Solaris 优先级下降，Oracle Database 18c（2018）后进一步下降，Solaris 11.4（2018-08）为最后一个主要版本
