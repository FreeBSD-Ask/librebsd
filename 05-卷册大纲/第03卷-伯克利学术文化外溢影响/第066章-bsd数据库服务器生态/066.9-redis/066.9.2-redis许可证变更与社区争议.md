# 066.9.2 Redis 许可证变更与社区争议

  **要点**：Redis 最初采用 BSD 3-Clause 许可证，**2018 年** Redis Labs 将 Redis 模块（Redis Modules）许可证从 AGPL 改为 Commons Clause（限制云服务商免费使用），引发社区争议；**2024 年 3 月** Redis 核心版本从 BSD 3-Clause 改为 RSALv2（Redis Source Available License v2）与 SSPLv1（Server Side Public License v1）双重许可证，不再属于开源软件（OSI 认定 RSALv2 与 SSPL 不符合开源定义）；此许可证变更引发社区分叉——Valkey（Linux Foundation 项目，2024 年 3 月由 AWS、Google Cloud、Oracle 等发起）作为 Redis 的 BSD 许可证分支延续开源传统

  | Redis 许可证变更时间线 | 时间 | 事件 |
| -------------------- | -- | -- |
| 初始许可证 | **2009 年** | BSD 3-Clause |
| 模块许可证变更 | **2018 年** | Redis Modules 改为 Commons Clause |
| 核心许可证变更 | **2024 年 3 月** | 改为 RSALv2 + SSPLv1 |
| 社区分叉 | **2024 年 3 月** | Valkey（Linux Foundation，BSD 许可证） |

  | Redis vs Valkey 对比 | 项目 | 许可证 | 发起方 |
| ------------------ | -- | ---- | ---- |
| Redis | RSALv2 + SSPLv1（非开源） | Redis Inc. | |
| Valkey | BSD 3-Clause（开源） | AWS/Google Cloud/Oracle（Linux Foundation） | |

### 史观映射

> 数据库的历史与 BSD 的历史在伯克利的 Evans Hall 四楼交汇——Ingres 和 BSD 共享同一台 PDP-11，Stonebraker 和 Joy 在同一个走廊里擦肩而过，关系数据库和 UNIX 操作系统在同一个学术环境中共同演化。但演化方向的分离来得比任何人预想的都快：Ingres 变成了 Sybase 和 SQL Server，Postgres 变成了 PostgreSQL，而 BSD 变成了 FreeBSD——它们都从伯克利出发，但走向了不同的商业命运。MySQL 在 FreeBSD 上跑得很好，PostgreSQL 在 BSD 许可证下活得很好，但 Oracle 从来没有认真考虑过 FreeBSD——数据库的世界被 Linux 和 Windows 瓜分，BSD 在角落里安静地跑着它自己的小数据库，偶尔有人想起“其实 Ingres 也是从伯克利出来的”
