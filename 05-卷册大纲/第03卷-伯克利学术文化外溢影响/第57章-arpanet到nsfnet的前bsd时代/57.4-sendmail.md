# 57.4 Sendmail：Allman 的邮件传输革命——Eric Allman（埃里克·奥尔曼） 1979 年在伯克利 INGRES 项目中开发 delivermail，1981-1982 年在 4.1cBSD 中重写为 Sendmail，1983 年随 4.2BSD 正式发布，Sendmail 的 M4 宏配置系统与安全漏洞史，Sendmail 的全球部署与替代品（Postfix、Qmail）的挑战

## 56.4.1 Allman 1979 年 delivermail 到 Sendmail 的演进
  - 要点：Eric Allman 1979 年在伯克利 INGRES 数据库项目中开发 delivermail（ARPANET 邮件传输代理），随 4.0BSD/4.1BSD 分发，delivermail 最初使用硬编码路由表通过 FTP 邮件协议转发；1981-1982 年 Allman 在 4.1cBSD 开发期间改写为 Sendmail 以支持 SMTP（RFC 821 1982）与 UUCP 等多协议路由，引入地址重写规则；Sendmail 1983 年 8 月随 4.2BSD 作为默认邮件传输代理（MTA）发布，Allman 的 delivermail 到 Sendmail 演进反映了互联网邮件协议从 ARPANET（FTP-based）到 SMTP 的转型

## 56.4.2 Sendmail 4.2BSD 集成的历史意义
  - 要点：Sendmail 4.2BSD 集成（1983.8）的历史意义：（1）Sendmail 作为默认 MTA 集成入 BSD，使 BSD 系统开箱即用支持 SMTP 邮件；（2）Sendmail 的部署推动 SMTP 成为互联网邮件事实标准；（3）Sendmail 的开放配置（sendmail.cf）使管理员可定制邮件路由，但也带来配置复杂性；（4）Sendmail 与 BIND 一起使 BSD 成为互联网基础设施的核心

  | Sendmail 4.2BSD 集成历史意义 | 内容 |
  | --- | --- |
  | 集成时间 | **1983 年 8 月**（4.2BSD 发布） |
  | 默认 MTA | 使 BSD 系统开箱即用支持 SMTP 邮件 |
  | 推动 SMTP | Sendmail 的部署推动 SMTP 成为互联网邮件事实标准 |
  | 配置开放 | sendmail.cf 使管理员可定制邮件路由，但也带来配置复杂性 |
  | 基础设施核心 | Sendmail 与 BIND 一起使 BSD 成为互联网基础设施的核心 |

  - 史料：Sendmail 4.2BSD 集成档案（1983.8）、Sendmail.cf 配置文件历史、Sendmail 推动 SMTP 标准化档案[考据完成：2026-07-28 经穷尽联网考据，上述史料清单为已知公开来源汇总，部分原始档案未公开数字化或须档案馆藏地现场核验，属史料缺口，须待原始档案公开后方可补充确证] 〔L1 代码/L3 官方文档〕
  - 史观：第 9 条经验优先——Sendmail 的实践（BSD 集成）先于 SMTP 标准化，BSD 的 “开箱即用” 使 Sendmail 成为互联网邮件事实标准
  - 辨析：Sendmail 4.2BSD 集成时间确认为 1983 年 8 月（4.2BSD 1983.8 发布，Sendmail 作为默认 MTA 集成，与 23.4.1 一致）；sendmail.cf 的配置复杂性——Sendmail 使用 M4 宏预处理器生成 sendmail.cf 配置文件，M4 宏简化配置编写但生成的 sendmail.cf 仍为复杂的规则集，管理员须理解地址重写规则（rewriting rules）方能维护，此复杂性是后来 Postfix（1998）以配置简洁性取代 Sendmail 的市场动因（详见 23.4.4）；Sendmail 对 SMTP 标准化的推动——Sendmail 作为 4.2BSD 默认 MTA 广泛部署，使 SMTP（RFC 821 1982）成为互联网邮件事实标准，IETF 后续邮件相关 RFC（如 RFC 822 邮件格式、RFC 1869 SMTP 扩展）均以 Sendmail 实现为参考

## 56.4.3 Sendmail 的 M4 配置与安全漏洞

## 56.4.4 Postfix、Qmail 等替代品的挑战
  - 要点：Sendmail 的替代品：（1）Qmail 1995 年由 D. J. Bernstein 发布，强调安全性，Qmail 的安全设计（最小特权、沙箱）使 Sendmail 安全问题凸显，许可证：公有领域（Bernstein 本人于 cr.yp.to/qmail/dist.html 声明将 qmail 置于公有领域）[考据脚注：经 cr.yp.to/qmail/dist.html 一手来源确证。]；（2）Postfix 1998 年由 IBM 的 Wietse Venema 发布（原名 VMailer，使用 IBM Public License），强调安全性与性能，Postfix 逐步取代 Sendmail 在新建部署中的地位；（3）Exim 1995 年由 Cambridge 的 Philip Hazel 发布，欧洲市场流行；这些替代品反映 Sendmail 安全问题的市场反应
