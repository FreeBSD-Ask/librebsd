# 063.4.2 Sendmail 复杂性被 Postfix 超越的批评

  **要点**：Sendmail 复杂性被 Postfix 超越的批评：（1）Sendmail 的 sendmail.cf 配置复杂性（M4 宏生成）使管理员难以维护；（2）Postfix 1998 年由 IBM 的 Wietse Venema 发布（原名 VMailer，使用 IBM Public License），强调安全性与配置简洁性；（3）Postfix 在新建部署中逐步取代 Sendmail；（4）此批评反映 BSD 互联网技术的 “复杂性负担”——早期设计的选择使后期维护困难

  | Sendmail 与 Postfix 对比 | Sendmail | Postfix |
| ---------------------- | ------ | ----- |
| 发布时间 | **1983 年 8 月**（4.2BSD） | **1998 年** |
| 原名 | Sendmail | VMailer |
| 作者 | Eric Allman（埃里克·奥尔曼） | IBM 的 Wietse Venema |
| 许可证 | BSD 许可证 | IBM Public License |
| 配置 | sendmail.cf（M4 宏生成，复杂） | 配置简洁性 |
| 强调点 | 早期互联网邮件传输 | 安全性与配置简洁性 |
| 市场趋势 | 早期主导，新建部署被 Postfix 取代 | 新建部署逐步取代 Sendmail |

  | 批评要点 | 内容 |
| ------ | -- |
| 配置复杂性 | Sendmail 的 sendmail.cf 配置复杂性（M4 宏生成）使管理员难以维护 |
| Postfix 取代 | Postfix 在新建部署中逐步取代 Sendmail |
| “复杂性负担” | 反映 BSD 互联网技术早期设计的选择使后期维护困难 |

**史观**：第 2 条历史是形式主义化的非存在——Sendmail 的 M4 配置形式逻辑（宏生成）吞并了实质的配置复杂性，形式简化与实质复杂存在张力
