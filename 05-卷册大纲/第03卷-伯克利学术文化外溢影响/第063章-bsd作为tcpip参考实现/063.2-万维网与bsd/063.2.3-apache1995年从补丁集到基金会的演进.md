# 063.2.3 Apache 1995 年从补丁集到基金会的演进

  **要点**：Apache 1995 年从 NCSA httpd 的补丁集（“a patchy server” 双关）诞生，Apache 创始成员包括 Brian Behlendorf（布莱恩·贝伦多夫）、Cliff Skolnick、Roy Fielding 等 8 人，Apache 1.0 1995.12 发布，Apache 逐步取代 NCSA httpd（McCool 离开 NCSA 加入 Netscape）成为主流 Web 服务器，1999 年 Apache 软件基金会（Apache Software Foundation，ASF）成立，Apache 成为开源治理的范本
