# 064.4.2 总纲10动手者创造历史据原文第14章142节真正的问题不在于技术发展的程度而在于

- 总纲 10“动手者创造历史”——据原文第 14 章 14.2 节“真正的问题不在于技术发展的程度，而在于是否动手。技术的发展使曾经需要数年完成的工作如今数日可成，但问题始终在于是否有人去做”，CSRG 网络代码通过学术分发渠道扩散到全球研究机构，是“问题始终在于是否有人去做”的长尾显现——socket API 的长期影响不是规划出来的战略布局，而是有人动手写出网络代码并随 BSD 一起分发出去后自然生出的后果。但据 14.1 节“决定世界的并非某个阶级，也不是什么经济”，此处“动手者”不可简化为“网络代码分发者”的固定身份——CSRG 成员通过学术分发渠道扩散代码，是主体性未被理论遮蔽的状态。
- 总纲 22“知识注定过时”——据原文第 22 章 22.1 节“今天书写的技术史，可能在出版之日就已过时。但这不意味着史学写作无意义，而是要求史家有此自觉”，BSD 网络代码的具体实现随时间过时，但 socket API 延续。22.2 节“技术债务是历史设计的代价。许多今天看来不合理的设计，源于其诞生年代的硬件与技术限制，但这一历史遗产至今仍由全球数百万用户承担”提示：socket API 作为历史遗产，既被后续网络编程继承，也成为技术债务——其 1980 年代的设计权衡在 2018 年已成为现代网络编程的历史包袱。
- 总纲 4“分离聚合是永恒规律”——据原文第 4 章 4.1 节“分离聚合是世界发展的规律。分久必合，合久必分，具有必然性”，BSD 网络代码作为聚合点，催生后续 Internet 治理的分离——BSD 网络代码聚合了 DARPA、CSRG、BBN 等多方主体的工作，而后续 IETF、IANA 等 Internet 治理机构的独立是从此聚合中分离出的新形态。但 4.2 节“否定后必然会再次产生，这是社会发展的根本动力”提示：Internet 治理的分离并非 BSD 网络代码的终结，而是通过此分离产生了新的网络治理形态。
- 总纲 11“商品是形式主义”——据原文第 25 章 总纲 11“技术市场的选择不是自然选择，而是形式主义的权力运作。劣币驱逐良币是普遍规律”，BSD 网络代码在 1990 年代商业互联网爆发中的奠基作用是形式主义的权力运作——这不构成对 BSD 的道德赞美，而是项目统摄史观对“商品化”的中性描述。BSD 网络代码作为“事实标准”被商业互联网采纳，不是“技术优秀”的自然选择，而是形式主义的市场权力运作。
- 总纲 3“不存在进步，只有权力再分配”——据原文第 25 章 总纲 3“技术演进不是从低级到高级的进步，而是形式主义的诡异曲线”，socket API 的长期影响并非“网络编程进步”，而是第 9 章 9.3 节“不存在绝对的发展。修仙小说设定古法强于今法存在逻辑悖论，但反过来说今法绝对强于古法同样存在问题”所述的形式主义演化——socket API 在 1980 年代的设计权衡，在现代网络编程中既是基础也是技术债务，不能简单视为“进步”。
- 总纲 18“时间是一种形式主义”——据原文第 25 章 总纲 18“等待、记忆、历史的欣赏都具有时间性。沥青滴落般的时间尺度要求史家具备宏观的时间自觉”，麦库西克 2018 年回望 1980 年代 BSD 网络代码的奠基作用，是沥青滴落式的时间尺度——第 27 章 27.4 节“和解往往取决于等待，或者说，取决于时间。这世间种种的等待，就好像沥青在滴落”提示：socket API 数十年的延续是 BSD 长期主义的体现，但此长期主义非苦难哲学（见总纲 14）。
- 总纲 9“经验优先”——据原文第 25 章 总纲 9“优先呈现质朴的事实与当事人的直接经验，而非套用复杂框架”，麦库西克作为 CSRG 核心成员的当事人直接经验，优先于任何事后理论框架。但据第003章 003.3 节“记忆的东西从来都是不存在的——那天的偶然性都被转为了必然性，都是不存在的”，其 2018 年的回忆仍是一种形式主义化的重构——BSD 网络代码的奠基作用在回忆中可能已被定格为某种必然叙事，而当日动手分发代码的具体偶然已不可还原。

**自反性声明**：本释读本身也是一种形式主义化的重构，不声称是对项目统摄史观的客观正确解读。释读中“CSRG 网络代码通过学术分发渠道扩散是动手去做的长尾显现”的判断本身也是一种形式主义化的工具理性归类，把代码扩散简化为“动手分发”的延伸投射，可能遮蔽 BSD 许可证条款对分发权限的法律支撑无法被“动手”涵盖；释读中“BSD 网络代码具体实现过时但 socket API 延续”的判断本身也参与过时/延续二元对立的形式主义运作，可能遮蔽 socket API 部分语义（如阻塞 I/O 模型）在现代异步 I/O 范式下实际失效而非完全延续；释读中“BSD 网络代码作为聚合点催生 Internet 治理分离”的判断本身也是一种形式主义化的循环论归因，把治理演化简化为“聚合—分离”的抽象循环，可能遮蔽 IETF 独立化中 Vint Cerf 等主体的主动组织建构而非抽象的“分离”；释读中“BSD 网络代码在商业互联网爆发中的奠基作用是形式主义权力运作”的判断本身也是一种形式主义化的市场还原论，把商业采纳简化为权力运作，可能遮蔽 BSD 网络代码在协议栈完整性等可度量维度上相对商业专有方案的实际工程优势；释读中“socket API 长期影响是形式主义演化而非网络编程进步”的判断本身也是一种形式主义化的相对化运作，可能遮蔽 socket API 在抽象层统一性上相对早期 per-protocol 接口的可度量进步；释读中“麦库西克 2018 年回望是沥青滴落式的时间尺度”的判断本身也是一种形式主义化的时间浪漫化，可能遮蔽 socket API 数十年延续更源于 BSD 许可证的传播学优势而非抽象的时间累积；释读中“麦库西克 2018 年回忆仍是形式主义化的重构”的判断本身也是一种形式主义化的时间归因，可能遮蔽麦库西克作为长期参与者对 socket API 演化细节的累积性认知，欢迎被更自反的释读所超越（见 据原文第 27 章 27.2 节）。
