# 064.1.2 Sendmail 安全补丁作者

  **要点**：Sendmail 安全补丁作者包括：（1）Eric Allman（埃里克·奥尔曼） 作为 Sendmail 创始者长期维护；（2）Sendmail Consortium（1998 年成立）维护 Sendmail 开源版本；（3）Sendmail Inc.（1998 年 Allman 创立）商业化 Sendmail；（4）CERT/CC 与 Sendmail 安全补丁作者合作处理安全漏洞；Allman 作为 Sendmail 长期维护者是互联网基础设施的关键贡献者

  | Sendmail 安全补丁作者 | 时间 | 内容 |
| ------------------- | -- | -- |
| Eric Allman | 长期维护 | Sendmail 创始者（1979 delivermail，1981-1982 Sendmail 重写） |
| Sendmail Consortium | **1998 年** 成立 | 维护 Sendmail 开源版本 |
| Sendmail Inc. | **1998 年** 成立 | Allman 创立以商业化 Sendmail |
| CERT/CC 合作 | 持续 | 与 Sendmail 安全补丁作者合作处理安全漏洞 |

  | Allman 的 Sendmail 维护时期 | 内容 |
| ------------------------- | -- |
| 创始期 | **1979 年** delivermail（INGRES 项目） |
| 重写期 | **1981-1982 年** Sendmail 重写（4.1cBSD） |
| 长期维护 | 维护至 1990 年代后期 |
| 商业化 | **1998 年** 创立 Sendmail Inc. |
