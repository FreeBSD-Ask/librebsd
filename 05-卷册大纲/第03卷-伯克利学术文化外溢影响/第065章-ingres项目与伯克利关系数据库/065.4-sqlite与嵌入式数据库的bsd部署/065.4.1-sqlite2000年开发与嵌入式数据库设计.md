# 065.4.1 SQLite 2000 年开发与嵌入式数据库设计

  **要点**：SQLite 1.0 于 2000 年 8 月 17 日由 D. Richard Hipp 正式发布，背景包括：（1）Hipp 为美国海军合同开发嵌入式数据库（无管理员、无服务器架构）；（2）SQLite 设计为单文件嵌入式数据库（无独立服务器进程，整个数据库存储于一个跨平台磁盘文件）；（3）SQLite 使用 SQL 查询但避免客户端-服务器架构，实现零配置运行；（4）SQLite 采用公有领域（Public Domain）许可证（后改为 Blessing 许可）使其可被任意使用；SQLite 的设计反映“做一件事并做好”的 UNIX 哲学

  | SQLite 1.0 发布关键要素 | 内容 |
| --------------------- | -- |
| 发布日期 | **2000 年 8 月 17 日** |
| 作者 | D. Richard Hipp |
| 合同方 | 美国海军（Hipp 为 General Dynamics 子公司 Bath Iron Works 雇员，合同最终客户为美国海军）[考据脚注：经多源交叉验证，Hipp 于 2000 年在 General Dynamics 子公司 Bath Iron Works 工作时为美国海军合同开发 SQLite，合同方与雇主为不同概念。] |
| 架构 | 无管理员、无服务器、单文件嵌入式数据库 |
| 跨平台磁盘文件 | 整个数据库存储于一个文件 |
| SQL 支持 | 使用 SQL 查询但避免客户端-服务器架构 |
| 零配置 | 实现零配置运行 |
| 许可证 | 公有领域（Public Domain），后改为 Blessing 许可 |
