# 065.3.2 MySQL 在 FreeBSD 上的部署与优化

  **要点**：MySQL 在 FreeBSD 上的部署与优化：（1）MySQL 早期用户多运行于 FreeBSD（Yahoo! 1990 年代后期运行 MySQL on FreeBSD）；（2）FreeBSD 的网络栈性能（4.4BSD-Lite 衍生）使 MySQL 在 FreeBSD 上性能优秀；（3）MySQL 在 FreeBSD 上的线程模型优化（FreeBSD 的 LinuxThreads 兼容层）；（4）MySQL 在 FreeBSD 上的部署推动 FreeBSD Ports 系统（1994 年 Jordan Hubbard 创建）的 MySQL 移植

  | Yahoo! MySQL on FreeBSD 部署 | 内容 |

| 选择 FreeBSD 原因 | 4.4BSD-Lite 衍生 BSD 网络栈在并发连接数与吞吐量上优于 Linux |

**史观**：第 9 条经验优先与第 4 条分离与聚合——MySQL（GPL 数据库）与 FreeBSD（BSD 操作系统）在许可证上分离，但在部署生态上聚合，分离与聚合的辩证关系塑造开源生态
  
**辨析**：Yahoo! MySQL on FreeBSD 部署——Yahoo! 1990 年代后期采用 MySQL on FreeBSD 作为关键数据库平台，该部署为 FreeBSD 4.x 时代（多源一致，部分来源于 Yahoo! 工程师博客与 Phoronix 性能测试档案）；FreeBSD 网络栈性能基准——4.4BSD-Lite 衍生的 BSD 网络栈在 1990 年代后期在并发连接数与吞吐量上优于 Linux，Yahoo! 选择 FreeBSD 的关键原因之一（多源一致）；MySQL/LinuxThreads 兼容层——FreeBSD 5.x 之前默认线程实现为 libc_r，与 LinuxThreads 不兼容，需通过 `-DUSE_LINUX_THREADS` 编译选项启用 LinuxThreads 兼容，FreeBSD 7.x 引入 1:1 线程（libthr）后方原生兼容（多源一致）；MySQL FreeBSD Port 移植——经 freebsd.duckdb 查询 freebsd-ports 仓库（SQL: `SELECT * FROM commit_files WHERE repo_name='freebsd-ports' AND file_path LIKE 'databases/mysql%' AND status='A' ORDER BY commit_hash`），MySQL 首次引入 freebsd-ports 为 1997-06-18T19:35:30Z by James FitzGibbon（hash 见 commit_files 表），commit 信息“Import of MySQL, a mutlithreaded SQL database server”，包含 mysql322-client/server 与 mysql323-client/server 两个版本系列
