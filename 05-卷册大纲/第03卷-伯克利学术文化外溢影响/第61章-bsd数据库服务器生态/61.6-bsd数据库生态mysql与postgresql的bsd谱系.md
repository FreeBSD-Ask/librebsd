# BSD 数据库生态——MySQL 与 PostgreSQL 的 BSD 谱系

## BSD.1 PostgreSQL 的 BSD 学术根源与 MySQL 的跨平台策略

**要点**：PostgreSQL 起源于 UC Berkeley POSTGRES 项目（Stonebraker, 1986），运行于 4.3BSD。MySQL 虽源自 Linux 但始终维护 BSD 完整支持，FreeBSD ports 中的 MySQL 端口是数据库-OS 协作的典型案例。

**史料**：Stonebraker & Rowe SIGMOD 1986; MySQL FreeBSD 安装指南 ［A/B］
