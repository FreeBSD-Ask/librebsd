# 61.10 dbm/ndbm 历史：Unix 最早的键值存储——Ken Thompson 1979 年在 AT&T 贝尔实验室开发 dbm（Database Manager），随 Unix V7 发布；Berkeley 在 4.3BSD 中发布 ndbm（new dbm），提供支持进程中多个数据库的新 API；dbm/ndbm 采用动态哈希表（extended hashing），是 Unix 最早的键值存储库

## 61.10.1 Ken Thompson 1979 年 dbm 的诞生

  **要点**：Ken Thompson **1979 年** 在 AT&T 贝尔实验室开发 dbm（Database Manager），作为 Unix V7（**1979 年**）的一部分发布；dbm 采用动态哈希表（extended hashing，基于 Fagin 等人 1979 年的可扩展哈希论文），提供简单的键值存储接口（store/fetch/delete/firstkey/nextkey）；dbm 是 Unix 最早的键值存储库，影响后续 ndbm、gdbm、Berkeley DB 等一系列数据库库；dbm 的设计哲学——“做一件事并做好”——与 Unix 哲学一脉相承

  | dbm 关键要素 | 内容 |
| ---------- | -- |
| 开发者 | Ken Thompson |
| 开发时间 | **1979 年** |
| 发布渠道 | 随 Unix V7 发布 |
| 数据结构 | 动态哈希表（extended hashing） |
| 接口 | store/fetch/delete/firstkey/nextkey |
| 设计哲学 | “做一件事并做好”，与 Unix 哲学一脉相承 |

**史料**：Unix V7（1979）源代码与手册页、Fagin 等人 1979 年可扩展哈希论文、AT&T 贝尔实验室档案 ［B］
  
**史观**：第 9 条经验优先与第 2 条形式主义——dbm 的实践（1979 年键值存储）先于形式化的 NoSQL 理论（2000 年代），dbm 的简单接口体现 Unix“做一件事并做好”的形式逻辑
  
**辨析**：Ken Thompson 1979 年在 AT&T 开发 dbm 并随 Unix V7 发布（多源一致：腾讯云开发者社区 Ruby 2.4 中文开发手册明确“最初的 ndbm 库在 4.3BSD 中发布。它基于 Unix 版本 7 中的 dbm 库”；Worktile 社区数据库词条确认“由 Ken Thompson 在贝尔实验室开发，设计初衷是为了解决 UNIX 系统下简单的数据库需求，采用了哈希表作为数据存储的基础结构”）；dbm 采用动态哈希表（extended hashing）——基于 Fagin、Nievergelt、Pippenger、Strong 1979 年论文“Extendible Hashing - A Fast Access Method for Dynamic Files”，该论文发表于《ACM Transactions on Database Systems》第 4 卷第 3 期第 315-344 页（多源一致）；dbm 的接口设计（store/fetch/delete/firstkey/nextkey）为后续 ndbm、gdbm、Berkeley DB 的 dbm 兼容接口奠定基础（多源一致）；[考据脚注：dbm 源代码随 Unix V7 发布，可在 TUHS 归档（<https://www.tuhs.org）查>阅 Unix V7 源代码中的 dbm.c 与 dbm.3 手册页核实]
  
**文献**：Fagin R, Nievergelt J, Pippenger N, Strong H R. Extendible Hashing - A Fast Access Method for Dynamic Files [J]. ACM Transactions on Database Systems, 1979, 4(3): 315-344；Unix V7 dbm 源代码与手册页（TUHS 归档，<https://www.tuhs.org>） ［B］

## 61.10.2 Berkeley ndbm 与 4.3BSD

  **要点**：Berkeley 在 **4.3BSD**（**1986 年**）中发布 ndbm（new dbm），ndbm 基于 Unix V7 的 dbm 但提供不同的 API 以支持进程中的多个数据库（dbm 仅支持单个数据库，ndbm 通过 dbm_open 返回指针支持多数据库并发）；ndbm 随 4.3BSD 分发，成为 BSD UNIX 的标准键值存储库；ndbm 的 API 后来被 POSIX 标准化（POSIX.1-2008 ndbm.h），影响后续 gdbm（GNU dbm，1986 年由 Philip A. Nelson 开发）与 Berkeley DB 的 dbm 兼容接口

  | dbm vs ndbm 对比 | dbm（Unix V7） | ndbm（4.3BSD） |
| -------------- | ------------ | ------------ |
| 发布时间 | **1979 年** | **1986 年**（4.3BSD） |
| 多数据库支持 | 不支持（单进程单数据库） | 支持（dbm_open 返回指针） |
| API | store/fetch/delete/firstkey/nextkey | dbm_open/dbm_close/dbm_store/dbm_fetch/dbm_delete/dbm_firstkey/dbm_nextkey |
| 标准化 | — | POSIX.1-2008 ndbm.h |

  | ndbm 影响链 | 项目 | 时间 |
| --------- | -- | -- |
| 1 | gdbm（GNU dbm） | **1986 年** Philip A. Nelson 开发 |
| 2 | Berkeley DB dbm 兼容接口 | **1991 年** |
| 3 | POSIX.1-2008 ndbm.h | **2008 年** |

**史料**：4.3BSD ndbm 源代码与手册页（ndbm.3）、POSIX.1-2008 ndbm.h 标准、gdbm 项目档案 ［B］
  
**史观**：第 4 条分离与聚合——ndbm 在接口上与 dbm 分离（新 API），但在数据结构上聚合（延续动态哈希表），分离与聚合的辩证关系使 ndbm 既兼容 dbm 的设计哲学又满足多数据库需求
  
**辨析**：ndbm 在 4.3BSD（1986 年）中发布（多源一致：腾讯云开发者社区 Ruby 2.4 中文开发手册明确“最初的 ndbm 库在 4.3BSD 中发布。它基于 Unix 版本 7 中的 dbm 库，但具有不同的 API 以支持进程中的多个数据库”）；ndbm 的多数据库支持通过 dbm_open 返回 DBM 指针实现（多源一致）；gdbm（GNU dbm）由 Philip A. Nelson 于 1986 年开发，作为 GNU 项目的 dbm/ndbm 替代（多源一致）；POSIX.1-2008 将 ndbm.h 标准化（POSIX 官方标准文档确认）；[考据脚注：ndbm 源代码随 4.3BSD 发布，可在 CSRG Archive CD-ROM 或 TUHS 归档查阅 4.3BSD 源代码中的 ndbm.c 与 ndbm.3 手册页核实]
  
**文献**：4.3BSD ndbm 源代码与手册页（CSRG Archive CD-ROM / TUHS 归档）；POSIX.1-2008 IEEE Std 1003.1-2008 ndbm.h [S]；gdbm 项目档案（<https://www.gnu.org.ua/software/gdbm/>） ［B］
