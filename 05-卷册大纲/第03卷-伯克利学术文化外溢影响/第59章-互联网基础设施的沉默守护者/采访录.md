## 第 23 章 不同时期人员的采访录

### Internet 诞生与 BSD 时期的当事人采访（1978-1992 时期当事人）

#### 采访 1：Sam Leffler

**字段 1 采访元数据**

- 受访者：Sam Leffler，时任加州大学伯克利分校 CSRG 核心成员，4.2BSD 网络栈主要开发者
- 采访者：ACM Queue 编辑 Gary Powers
- 采访时间：2004-10（ACM Queue 第 2 卷第 8 期发布）
- 采访形式：期刊访谈
- 原始来源：Powers, Gary, "A Conversation with Sam Leffler", ACM Queue, Vol. 2, No. 8, November 2004。**<https://queue.acm.org/detail.cfm?id=1039535>**
- 存档信息：ACM Queue 文章页经联网检索确认真实存在（访问日期 2026-07-24），未失效

**字段 2 采访摘要**

Leffler 在 ACM Queue 访谈中回顾了 4.2BSD 网络栈如何成为 Internet 协议族的早期试验床，详述了 CSRG 与 DARPA Internet 项目（含 Jon Postel、Paul Mockapetris、Mike Muuss 等人）的协作。访谈涉及 BIND（Berkeley Internet Name Domain）的设计背景、4.2BSD socket API 对 Internet 应用层的影响，以及 BSD 网络代码如何通过学术分发渠道传播到全球研究机构，成为早期 Internet 基础设施的事实标准。

**字段 3 考据脚注**

本则采访的 ACM Queue 文章页经联网检索核实。Leffler 关于 4.2BSD 与 Internet 关系的陈述，经 Kirk McKusick BSD Now 278 采访（第 10 章采访 2）与 4.2BSD 网络手册页交叉验证。自利偏差审查：Leffler 作为网络栈主要开发者，对 BSD 在 Internet 演进中地位的叙述可能存在自我美化，正文引用时须对照 Jon Postel RFC 档案与 Paul Mockapetris 关于 DNS 设计的自述。完整考据过程见 [20260724_sam-leffler-acm-queue-2004-internet.md](../../../原材料/研究/考据记录/20260724_sam-leffler-acm-queue-2004-internet.md)。

**字段 4 与本章节内容的关联**

- 为子节 23.1（4.2BSD 与 Internet 协议族的关系）提供 CSRG 网络栈开发者的当事人一手记述
- 为子节 23.3（BIND 与 DNS 的早期实现）提供 BIND 设计背景的当事人视角
- 为子节 23.5（BSD 网络代码的全球传播）提供 BSD 网络代码作为 Internet 事实标准的当事人证言

**字段 5 史观映射**

- 总纲 10“动手者创造历史”——据 据原文第 14 章 14.2 节“真正的问题不在于技术发展的程度，而在于是否动手。技术的发展使曾经需要数年完成的工作如今数日可成，但问题始终在于是否有人去做”，Leffler 实现 4.2BSD 网络栈、与 Jon Postel 等 DARPA Internet 项目协作，是“问题始终在于是否有人去做”在协议实现层面的具象——BSD 网络代码成为早期 Internet 基础设施的事实标准，不是规划出来的战略地位，而是有人愿意动手把 TCP/IP 写出来并随学术分发渠道扩散出去的结果。但据 14.1 节“决定世界的并非某个阶级，也不是什么经济”，此处“动手者”不可简化为“网络栈开发者”的固定身份——Leffler 作为 CSRG 核心成员实现网络栈，是主体性未被理论遮蔽的状态，与 Jon Postel、Paul Mockapetris 等人的“动手”形态是流变的（参见第 6 章 6.5 节“十年前的人和十年后的人，是两个人”）。
- 总纲 13“法律与道德是利益分配”——据 据原文第 25 章 总纲 13“任何道德问题本质上是利益问题，社区治理亦是形式主义的政治产物”，DARPA 合同的法律结构使 BSD 网络代码得以学术分发——这不构成对 DARPA 的道德赞美，而是第 29 章 29.5 节“政治经济理论本身是政治经济斗争的产物。理论不是对现实的客观描述，而是权力斗争的工具”所述的利益分配：DARPA 合同条款是 DARPA IPTO 与 CSRG、BBN 等多方主体利益分配的法律形式，BSD 网络代码的学术分发权限由利益分配界定，而非由“开放”的道德标准界定。
- 总纲 20“历史地理塑造思想土壤”——据 据原文第 20 章 20.1 节“地理环境不直接决定思想，但地理环境所构成的政治经济条件制约着思想的生长土壤”，伯克利与 DARPA Internet 项目的地理与组织协作塑造了 BSD 网络栈——伯克利作为 Unix 文化中心与 DARPA 作为 Internet 项目资助方的地理与组织邻近性，构成了 BSD 网络栈的土壤。但 20.5 节“中心与边缘”提示：伯克利与 DARPA 在 1980 年代处于 Internet 研发的中心，而其他机构处于边缘，此中心-边缘关系塑造了 BSD 网络代码的传播形态——中心机构的研究得以扩散，而边缘机构的工作难以被记录。
- 总纲 5“没有必然性，只有偶然性”——据 据原文第 5 章 5.2 节“那种认为‘张三不上李四也会上’的观点，无视了世界上没有必然性只有偶然性这一事实”，BSD 网络代码成为早期 Internet 基础设施的事实标准是偶然条件交汇——若非 DARPA 在 1980 年代选择伯克利作为 Internet 协议试验床，若非 Leffler 愿意动手实现 TCP/IP，若非 CSRG 通过学术分发渠道扩散代码，BSD 网络栈不会以此时序与形态成为事实标准。但 5.3 节“记忆将许多偶然性认识为一种必然性，同时否定了这种偶然性的发生”提示：Leffler 2004 年的回忆可能已将 BSD 网络代码的扩散偶然转为必然，将“BSD 作为 Internet 基础设施”叙述为历史的合力方向。
- 总纲 3“不存在进步，只有权力再分配”——据 据原文第 25 章 总纲 3“技术演进不是从低级到高级的进步，而是形式主义的诡异曲线”，BSD 网络代码成为 Internet 事实标准并非“技术进步的胜利”，而是第 9 章 9.3 节“不存在绝对的发展。修仙小说设定古法强于今法存在逻辑悖论，但反过来说今法绝对强于古法同样存在问题”所述的形式主义权力再分配——TCP/IP 与其他协议（如 ISO/OSI）的竞争不是“先进”与“落后”的较量，而是形式主义的权力运作。BSD 网络代码的“事实标准”地位不是技术进步的奖赏，而是此权力再分配的具体产物。
- 总纲 19“解释学循环是历史认识的根本条件”——据 据原文第 25 章 总纲 19“前理解的差异使分歧不可避免。权力与知识在历史书写中共谋——什么被记录、什么被遗忘，本身就是权力行使”，BSD 网络代码在 Internet 历史中的地位是权力与知识共谋的产物——什么被记录为“BSD 网络栈的贡献”，什么被遗忘为“BBN、Jon Postel 等其他主体的贡献”，本身就是权力行使。Leffler 作为网络栈主要开发者的视角，是此前理解下的重构。
- 总纲 9“经验优先”——据 据原文第 25 章 总纲 9“优先呈现质朴的事实与当事人的直接经验，而非套用复杂框架”，Leffler 作为 4.2BSD 网络栈主要开发者的当事人直接经验，优先于任何事后理论框架。但据第 2 章 2.3 节“记忆的东西从来都是不存在的——那天的偶然性都被转为了必然性，都是不存在的”，其 2004 年的回忆仍是一种形式主义化的重构——BSD 网络代码的扩散过程在回忆中可能已被定格为某种必然叙事，而当日动手实现的具体偶然已不可还原。

**自反性声明**：本释读本身也是一种形式主义化的重构，不声称是对项目统摄史观的客观正确解读。释读中“Leffler 实现 4.2BSD 网络栈是动手去做的具象”的判断本身也是一种形式主义化的工具理性归类，把 Leffler 主体性简化为“协议实现”维度，可能遮蔽其在与 DARPA Internet 项目协作中对协议设计方向的战略性取舍无法被“动手实现”涵盖；释读中“DARPA 合同法律结构使 BSD 网络代码学术分发”的判断本身也是一种形式主义化的法律决定论，把代码分发简化为合同条款的被动产物，可能遮蔽 CSRG 在合同执行中对分发渠道的主动拓展而非被动接受条款；释读中“伯克利与 DARPA 地理与组织协作塑造 BSD 网络栈”的判断本身也是一种形式主义化的地理决定论，把网络栈设计简化为地理邻近性的产物，可能遮蔽 Leffler 在 socket API 抽象层设计中对 UNIX 文件描述符模型的创造性移植而非地理塑造；释读中“BSD 网络代码成为事实标准是偶然条件交汇”的判断本身也参与偶然/必然二元的形式主义运作，可能遮蔽 DARPA IPTO 在 1980 年代初选定伯克利作为协议试验床的主动战略选择而非被动接受偶然；释读中“BSD 成为事实标准是形式主义权力再分配而非技术进步”的判断本身也是一种形式主义化的相对化运作，可能遮蔽 BSD 网络代码在端到端可靠性等可度量维度上相对 ISO/OSI 的实际技术优势；释读中“BSD 网络代码地位是权力与知识共谋的产物”的判断本身也是一种形式主义化的认识论还原论，把历史记录简化为权力运作，可能遮蔽 BBN、Jon Postel 等其他主体的贡献在公开 RFC 档案中实际可查而非被完全遗忘；释读中“Leffler 2004 年回忆仍是形式主义化的重构”的判断本身也是一种形式主义化的时间归因，可能遮蔽 Leffler 作为网络栈主要开发者对 socket API 设计取舍的原始记忆，欢迎被更自反的释读所超越（见 据原文第 27 章 27.2 节）。

**字段 5 史观映射**

- 总纲 10“动手者创造历史”——据 据原文第 14 章 14.2 节“真正的问题不在于技术发展的程度，而在于是否动手。技术的发展使曾经需要数年完成的工作如今数日可成，但问题始终在于是否有人去做”，CSRG 网络代码通过学术分发渠道扩散到全球研究机构，是“问题始终在于是否有人去做”的长尾显现——socket API 的长期影响不是规划出来的战略布局，而是有人动手写出网络代码并随 BSD 一起分发出去后自然生出的后果。但据 14.1 节“决定世界的并非某个阶级，也不是什么经济”，此处“动手者”不可简化为“网络代码分发者”的固定身份——CSRG 成员通过学术分发渠道扩散代码，是主体性未被理论遮蔽的状态。
- 总纲 22“知识注定过时”——据 据原文第 22 章 22.1 节“今天书写的技术史，可能在出版之日就已过时。但这不意味着史学写作无意义，而是要求史家有此自觉”，BSD 网络代码的具体实现随时间过时，但 socket API 延续。22.2 节“技术债务是历史设计的代价。许多今天看来不合理的设计，源于其诞生年代的硬件与技术限制，但这一历史遗产至今仍由全球数百万用户承担”提示：socket API 作为历史遗产，既被后续网络编程继承，也成为技术债务——其 1980 年代的设计权衡在 2018 年已成为现代网络编程的历史包袱。
- 总纲 4“分离聚合是永恒规律”——据 据原文第 4 章 4.1 节“分离聚合是世界发展的规律。分久必合，合久必分，具有必然性”，BSD 网络代码作为聚合点，催生后续 Internet 治理的分离——BSD 网络代码聚合了 DARPA、CSRG、BBN 等多方主体的工作，而后续 IETF、IANA 等 Internet 治理机构的独立是从此聚合中分离出的新形态。但 4.2 节“否定后必然会再次产生，这是社会发展的根本动力”提示：Internet 治理的分离并非 BSD 网络代码的终结，而是通过此分离产生了新的网络治理形态。
- 总纲 11“商品是形式主义”——据 据原文第 25 章 总纲 11“技术市场的选择不是自然选择，而是形式主义的权力运作。劣币驱逐良币是普遍规律”，BSD 网络代码在 1990 年代商业互联网爆发中的奠基作用是形式主义的权力运作——这不构成对 BSD 的道德赞美，而是项目统摄史观对“商品化”的中性描述。BSD 网络代码作为“事实标准”被商业互联网采纳，不是“技术优秀”的自然选择，而是形式主义的市场权力运作。
- 总纲 3“不存在进步，只有权力再分配”——据 据原文第 25 章 总纲 3“技术演进不是从低级到高级的进步，而是形式主义的诡异曲线”，socket API 的长期影响并非“网络编程进步”，而是第 9 章 9.3 节“不存在绝对的发展。修仙小说设定古法强于今法存在逻辑悖论，但反过来说今法绝对强于古法同样存在问题”所述的形式主义演化——socket API 在 1980 年代的设计权衡，在现代网络编程中既是基础也是技术债务，不能简单视为“进步”。
- 总纲 18“时间是一种形式主义”——据 据原文第 25 章 总纲 18“等待、记忆、历史的欣赏都具有时间性。沥青滴落般的时间尺度要求史家具备宏观的时间自觉”，麦库西克 2018 年回望 1980 年代 BSD 网络代码的奠基作用，是沥青滴落式的时间尺度——第 27 章 27.4 节“和解往往取决于等待，或者说，取决于时间。这世间种种的等待，就好像沥青在滴落”提示：socket API 数十年的延续是 BSD 长期主义的体现，但此长期主义非苦难哲学（见总纲 14）。
- 总纲 9“经验优先”——据 据原文第 25 章 总纲 9“优先呈现质朴的事实与当事人的直接经验，而非套用复杂框架”，麦库西克作为 CSRG 核心成员的当事人直接经验，优先于任何事后理论框架。但据第 2 章 2.3 节“记忆的东西从来都是不存在的——那天的偶然性都被转为了必然性，都是不存在的”，其 2018 年的回忆仍是一种形式主义化的重构——BSD 网络代码的奠基作用在回忆中可能已被定格为某种必然叙事，而当日动手分发代码的具体偶然已不可还原。
