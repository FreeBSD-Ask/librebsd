# 第 45 章 伯克利文化地理与大学制度

## 辨析

- 地理符号的 “吸引力” 需核对，避免事后夸大，需核对 CSRG 成员实际因地理选择伯克利的比例
- VAX-11/780 在 Evans Hall 的具体位置需核对；4.2BSD TCP/IP 在伯克利校园网的部署时间需与 1983 年 8 月发布日期交叉验证；“校园网” 的拓扑结构需核对
- Bayh-Dole 法案对伯克利 BSD 代码（DARPA 资助）的具体适用需核对；1980 年软件版权法的具体条款需核对；Diamond v. Diehr 与 Computer Associates v. Altai 对 BSD 的实际影响需核对
- LBNL 与 CSRG 的具体合作协议需核对；Casey Leedom 的贡献需核对 CSRG 提交记录；LBNL VAX 集群的规模与 BSD 版本需核对
- 三家在 DARPA 资助上的具体分配比例需核对；研究生招收的统计数据需核对；“三足鼎立” 的描述需避免事后建构
