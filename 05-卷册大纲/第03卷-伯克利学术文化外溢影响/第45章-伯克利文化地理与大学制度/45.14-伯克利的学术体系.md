## 44.14.1 终身教职制与 CSRG 成员的定位

  **要点**：伯克利作为公立研究型大学采用标准美国终身教职制（tenure track），助理教授、副教授、教授的晋升须经 Academic Senate 审查，CSRG 核心成员（McKusick、Karels、Bostic 等）多为研究序列（research series）而非教学序列（teaching series），其职位性质介于教职与研究科学家之间，McKusick 早期为研究生 RAship，后转为研究科学家，未走传统终身教职路径

  | 职位序列 | 晋升路径 | CSRG 成员定位 |
| ------ | ------ | ----------- |
| 教学序列（teaching series） | 助理教授 → 副教授 → 教授（须经 Academic Senate 审查） | McKusick 等未走此路径 | | |
| 研究序列（research series） | 介于教职与研究科学家之间 | McKusick、Karels、Bostic 等多为研究序列 | | |
| McKusick 个人轨迹 | 研究生 RAship → 研究科学家 | 未走传统终身教职路径 | | |

**史料**：伯克利 Academic Senate 章程、研究序列职位定义、McKusick/Karels/Bostic 的职位档案、CSRG 人事记录 ［A］
  
**史观**：第 2 条形式主义——终身教职制的形式逻辑（教学 + 研究 + 服务）吞并了 CSRG 成员的纯研究贡献，研究序列的形式定位使 CSRG 成员在学术体系中处于边缘，此边缘性反而给予 BSD 开发的自主性
  
**辨析**：研究序列与教学序列的具体区别需核对伯克利 Academic Senate 章程；McKusick 等的职位演变需核对人事档案；“边缘性” 的描述需核对 CSRG 成员的自述

## 44.14.2 EECS 系与 CS 系的分合史

  **要点**：伯克利 EECS 系（Electrical Engineering and Computer Sciences）由原 EE 系（电气工程）与 CS 系（计算机科学）于 **1973 年** 合并而成，但内部保留 EE 与 CS 两个分支，CSRG 隶属 EECS 系，CSRG 成员（如 Fabry、McKusick）跨越 EE 与 CS 边界，此合并使 BSD 硬件相关研究（VAX、SPARC 移植）与软件研究（内核、网络）形成组织协同

  | 系所 | 学科分支 | 与 CSRG 的关系 |

| EECS 系（**1973 年** 合并） | 内部保留 EE 与 CS 两个分支 | CSRG 隶属 EECS 系 | | |

**史观**：第 4 条分离与聚合——EE 与 CS 在学科上分离（硬件 vs 软件），但在 EECS 系的组织上聚合，BSD 的硬件-软件协同开发正是此分离与聚合的产物
