# 058.0.3 史观

（章级史观/辨析按子节字段聚合回填——本卷 53 章；2026-09-11 整改将占位改为编排说明，完整聚合随正文阶段逐章完成。子节级映射详见各节史观字段。）

史观映射：伯克利大学在 CSRG 时期的发展（1978-1992）不是 CSRG 的“背景”，而是 CSRG 生长的具体制度土壤——分校的多元化扩张（TWLF 后的种族研究系、Bakke 判决后的招生政策、SP-1 决议后的 Berkeley Pledge）、CS 系的崛起与 EECS 合并、与 MIT/Stanford 的全国地位竞争、Gardner-Heyman 校长时期的双层治理、Tien 校长接任前夕的过渡，构成 CSRG 生长的具体条件。史家在叙事中须自反承认：将“分校发展”与“CSRG 生长”关联是一种阐释而非当事人自述，CSRG 核心成员本人是否将伯克利分校的制度发展视为影响其研究的重要因素未见明确口述记录。本节呈现的是伯克利分校作为 CSRG 生长土壤的长时段制度语境，而非 CSRG 作为分校发展组成部分的因果叙事——避免时代错置与简单归因。史观自反检验：本节所给出的“制度土壤”与“CSRG 生长”的关联本身也是一种形式主义的建构，是“以形式反对形式主义”（总纲第 27 章 27.2 节，概念性指涉）在史编纂中的具体应用——本节以形式主义化的叙事呈现制度语境，但自反承认其形式主义性质。（2026-09-12 整改：本段原内嵌于“## 文献”节末尾，移至“## 史观”节；总纲原文逐字引用与“项目史观”自称改为概念性表述——批次 C045 问题 5/7）
