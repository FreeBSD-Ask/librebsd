## 58.6.2 NCSA httpd 1993 年与 BSD 系统的关系

  **要点**：NCSA httpd 1993 年由 NCSA（National Center for Supercomputing Applications，Illinois 大学）的 Rob McCool 开发，NCSA httpd 基于 NCSA Mosaic 项目经验，运行于 Unix 工作站（含 BSD 系统），NCSA httpd 1.0 1993 年发布，提供 HTTP/0.9 与 HTTP/1.0 支持，NCSA httpd 在 1995 年前是主流 Web 服务器，其 BSD 系统部署反映 BSD 作为 Web 服务器平台的统治地位

  | NCSA httpd 关键要素 | 内容 |
| ----------------- | -- |
| 开发方 | NCSA（National Center for Supercomputing Applications，Illinois 大学） |
| 开发者 | Rob McCool |
| 发布时间 | **1993 年**（NCSA httpd 1.0） |
| 项目基础 | NCSA Mosaic 项目经验 |
| 运行平台 | Unix 工作站（含 BSD 系统） |
| HTTP 支持 | HTTP/0.9 与 HTTP/1.0 |
| 主流时期 | **1995 年前** 主流 Web 服务器 |
| 后续 | McCool **1994 年中期** 离开 NCSA 加入 Netscape，开发停滞 |

## 58.6.4 Apache 许可证与 BSD 许可证的哲学共鸣

  **要点**：Apache 许可证（Apache License 1.0 1995、2.0 2004）与 BSD 许可证在哲学上共鸣：（1）二者均为宽松开源许可证，允许商业使用与闭源衍生；（2）Apache 许可证 1.0 借鉴 BSD 许可证，增加专利反诉条款；（3）Apache 与 BSD 的宽松许可证哲学与 GPL 的 copyleft 哲学形成对比；（4）Apache 服务器在 BSD 系统上的主导地位反映二者的哲学共鸣

  | Apache 与 BSD 许可证哲学共鸣 | 内容 |
| -------------------------- | -- |
| 共同点 1 | 二者均为宽松开源许可证，允许商业使用与闭源衍生 |
| 共同点 2 | Apache License 1.0 借鉴 BSD 许可证 |
| 差异 | Apache License 2.0 增加专利反诉条款 |
| 与 GPL 对比 | Apache 与 BSD 的宽松许可证哲学与 GPL 的 copyleft 哲学形成对比 |
| 部署关系 | Apache 服务器在 BSD 系统上的主导地位反映哲学共鸣 |

  | Apache License 演进 | 时间 | 关键变化 |
| ----------------- | -- | ------ |
| Apache License 1.0 | **1995 年** | 借鉴 BSD 许可证 |
| Apache License 2.0 | **2004 年** | 增加专利反诉条款与 Apache 品牌保护条款 |

  | Apache 2.0 专利反诉条款 | 内容 |
| --------------------- | -- |
| 触发条件 | 使用者对 Apache 2.0 许可的软件提起专利诉讼 |
| 后果 | 其在该软件下的专利授权自动终止 |
| 法律意义 | Apache 2.0 相对于 BSD 许可证的主要法律差异 |

  | BSD 许可证变体 | 内容 |
| ------------ | -- |
| BSD 2-Clause | Simplified BSD License |
| BSD 3-Clause | New BSD License |
| 共同条款 | 保留版权声明与免责条款 |
| 允许范围 | 商业使用与闭源衍生 |

**史料**：Apache License 1.0（1995）与 2.0（2004）原文、BSD 许可证原文、Apache 与 BSD 许可证哲学比较文档［考据注：2026-07-28 联网考据留痕，模板句式已按 0 信任原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档与公告〕
  
**史观**：第 2 条——历史是形式主义化的非存在——与第 4 条——分离聚合是永恒规律——Apache 与 BSD 许可证在形式上分离（不同许可证文本），但在哲学上聚合（宽松开源），分离与聚合的辩证关系塑造开源许可证谱系
  
**辨析**：Apache License 1.0（1995）与 2.0（2004）经多源确认（Apache License 1.0 借鉴 BSD 许可证，2.0 增加专利反诉条款与 Apache 品牌保护条款）；BSD 许可证版本——BSD 2-Clause（Simplified BSD License）与 BSD 3-Clause（New BSD License）为两种主要变体，均允许商业使用与闭源衍生，保留版权声明与免责条款；Apache 2.0 专利反诉条款——若使用者对 Apache 2.0 许可的软件提起专利诉讼，则其在该软件下的专利授权自动终止，此条款为 Apache 2.0 相对于 BSD 许可证的主要法律差异
