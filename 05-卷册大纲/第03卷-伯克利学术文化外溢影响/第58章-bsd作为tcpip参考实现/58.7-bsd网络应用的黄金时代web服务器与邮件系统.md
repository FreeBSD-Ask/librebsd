# BSD 网络应用的黄金时代——Web 服务器与邮件系统

## BSD.1 Apache 与 sendmail 的 BSD 血缘

**要点**：Apache 最初在 BSD 系统上开发——NCSA httpd 运行于 BSD/OS，Apache 的 prefork 模型直接受益于 BSD fork() 实现效率。sendmail（Eric Allman（埃里克·奥尔曼）, 1981）为 4.1cBSD 开发，是互联网 SMTP 事实标准。
