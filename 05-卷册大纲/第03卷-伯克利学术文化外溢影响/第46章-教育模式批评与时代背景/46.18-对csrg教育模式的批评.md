## 45.18.5 CSRG 精英化与美国左派教育语境的交叠

  **要点**：CSRG 精英化与伯克利 1960-1980 年代左派教育语境的交叠呈现三重结构：（一）选拔机制的交叠——CSRG **1976 年** 正式成立时伯克利 EECS 系正处于后 FSM 时代的 “学术左派” 兴起阶段，CSRG 沿用 Fabry/McKusick 个人推荐加学术成绩的选拔机制，与伯克利左派学者圈子（如 Critical Legal Studies、Feminist Scholarship）的 “师承式” 招募方式同构，二者均依赖导师个人判断而非制度化的公开招聘，使反精英的左派立场在实践中再生产出新的文化精英；（二）“精英化悖论” 的呼应——**1964-1969 年** FSM、反越战、人民公园等左派街头运动以反精英（反校方权威、反联邦政策、反私有化）为号召，但其运动骨干（Mario Savio（马里奥·萨维奥）、SDS 领导层）多为白人中产阶层大学生，运动退潮后骨干转入学术体制（Savio **1965 年** 退学后于 **1990 年代** 回归旧金山州立大学任教），形成 “反精英运动产生新精英” 的悖论，CSRG 的技术精英化（Joy/McKusick/Karels/Bostic 等核心成员构成相对封闭的工程精英圈）是此悖论在工程学术领域的间接投影；（三）CSRG 作为伯克利学术左派的间接产物——CSRG 的反权威文化（质疑 AT&T 商业化、坚持源代码自由分发、警惕商业封闭）与伯克利左派 “质疑权威” 的校园氛围在气质上共鸣，但二者无直接因果，CSRG 的反权威更多源于 Unix 早期 hacker 伦理（Thompson/Ritchie 在 Bell Labs 的工程平等主义）与伯克利校园氛围的接合，而非左派政治立场的直接延续

  | 交叠维度 | 具体内容 |
| ------ | ------ |
| （一）选拔机制交叠 | CSRG **1976 年** 成立，沿用 Fabry/McKusick 个人推荐加学术成绩的选拔机制，与伯克利左派学者圈子（Critical Legal Studies、Feminist Scholarship）的 “师承式” 招募同构 | | |
| （二）“精英化悖论” 呼应 | **1964-1969 年** FSM、反越战、人民公园等左派街头运动骨干（Mario Savio、SDS 领导层）多为白人中产阶层大学生；Savio **1965 年** 退学后于 **1990 年代** 回归旧金山州立大学任教；CSRG 技术精英化是此悖论的间接投影 | | |
| （三）CSRG 作为伯克利学术左派的间接产物 | CSRG 反权威文化与伯克利左派 “质疑权威” 在气质上共鸣，但二者无直接因果；CSRG 反权威更多源于 Unix 早期 hacker 伦理（Thompson/Ritchie 在 Bell Labs 的工程平等主义）与伯克利校园氛围的接合 | | |
