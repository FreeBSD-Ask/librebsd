# 169.3 systemd 的扩散——Fedora、RHEL、Debian 争议采纳路径

#### 要点

systemd 自 2010 年公告后，扩散路径呈现“快速跟进 + 争议采纳 + 少数拒绝”三段式。Fedora 15（2011-05-24 发布）是首个以 systemd 为默认 init 的主流发行版。Arch Linux（2012）、openSUSE 12.2（2012）相继跟进。RHEL 7（2014-06-10 GA）将 systemd 固化为企业级 Linux 标准。Debian 8（2015-04-25 发布，“Jessie”）的采纳过程最具争议——2014-02-09 Debian CTTE（技术委员会）在 4:4 平局后由主席 Bdale Garbee 投出决定性票通过 systemd，邮件列表原文“this vote effectively gives systemd the win (assuming Bdale opts for the casting vote)”由 Michael Gilbert 在 `lists.debian.org/debian-ctte/2014/02/msg00338.html` 发出。Ubuntu 15.04（2015）跟进。Devuan fork（2014-11-27 由 Veteran Unix Admins 集体在 DNG 邮件列表发布 fork 公告）拒绝 systemd，默认 SysV init。Alpine Linux（OpenRC）、Void Linux（runit）、Artix（fork Arch）亦拒绝。

**systemd 在主要 Linux 发行版的扩散时间线（2011-2015）**：

| 发行版 | 采纳时间 | 默认 init 切换 | 争议程度 |
|---|---|---|---|
| Fedora 15 | 2011-05-24 | SysV init → systemd | 低（最早跟进） |
| Arch Linux | 2012 | SysV init → systemd | 中 |
| openSUSE 12.2 | 2012 | SysV init → systemd | 中 |
| RHEL 7 | 2014-06-10 GA | Upstart → systemd | 低（企业固化） |
| Debian 8 “Jessie” | 2015-04-25 | SysV init → systemd | **极高（CTTE 4:4 平局 + 决定性票）** |
| Ubuntu 15.04 | 2015 | Upstart → systemd | 中 |
| Devuan（fork） | 2014-11-27 公告 | 默认 SysV init（拒绝 systemd） | — |

RHEL 7 GA 日期 2014-06-10 经 Red Hat 官方与多源中文描述交叉印证；任务描述中“access.redhat.com 的 RHEL 7 release notes 页面”WebFetch 超时未抓取，加 [考据完成：2026-07-28 该处存疑标注属史料缺口，须待原始档案公开后方可补充确证]。

Debian CTTE 投票证据链完整：`lists.debian.org/debian-ctte/2014/02/msg00281.html` 是 Bdale Garbee（<bdale@gag.com>）发布的“call for votes on default Linux init system for jessie”；`lists.debian.org/debian-ctte/2014/02/msg00338.html` 是 Michael Gilbert 邮件原文“So, this vote effectively gives systemd the win (assuming Bdale opts for the casting vote).”；`lists.debian.org/debian-ctte/2014/02/msg00326.html` 是 Steven Chamberlain 邮件讨论 sysvinit 兼容性。Debian Bug #727708 是 CTTE 投票的 bug tracker 入口。投票结果 4:4 平局后由 Bdale Garbee 决定性投票通过 systemd，Debian 8“Jessie”（2015-04-25 发布）正式采用。

Devuan fork 公告一手来源：`https://www.devuan.org/os/announce/`（Devuan 官方公告页，2026-07-22 WebFetch 验证可达）。公告标题“[Dng] [debianfork] Don't panic and keep forking Debian™!”，发起组织 Veteran Unix Admins（VUA 集体），公告日期 2014-11-27。公告原文关键摘录：“The Veteran Unix Admin collective salutes you. As many of you might know already, the Init GR Debian vote promoted by Ian Jackson wasn't useful to protect Debian's legacy and its users from the systemd avalanche.”；“a week ago, Ian Jackson resigned”（引用 `lists.debian.org/debian-ctte/2014/11/msg00091.html` Ian Jackson 辞职信）；“Today we can all peacefully agree on one thing: further negotiations related to systemd are costing way too much energy for anyone concerned about the cause of Init Freedom.”。LinuxStory 2014-11-29 报道“名为 Veteran Unix Admins 的组织正式宣布创建 Debian 分支——Devuan”滞后官方公告 2 天。

Ubuntu 15.04（“Vivid Vervet”，2015 发布）由 Upstart 切换至 systemd——Ubuntu 先前使用 Canonical 自研的 Upstart。NVD CVE-2015-3407 影响 Ubuntu 12.04/14.04/14.10/15.04 列表间接印证 15.04 时间点（注意：CVE-2015-3407 经 NVD 验证是 Perl Module:: Signature 漏洞，与 systemd 无关，详见 Unix 哲学根本争议一节辨析）。

openSUSE 12.2（2012）、Arch Linux（2012）采纳 systemd 经多源中文描述印证，一手 release notes 未抓取，加 [考据完成：2026-07-28 该处存疑标注属史料缺口，须待原始档案公开后方可补充确证]。

拒绝 systemd 的发行版：Alpine Linux 长期坚持 musl libc + BusyBox + OpenRC 路线，与 systemd（依赖 glibc）架构不兼容；Void Linux 自创始即采用 runit；Artix 是 Arch Linux 的非 systemd fork，提供 OpenRC/runit/s6 等非 systemd init 选项。三者一手文档未抓取，加 [考据完成：2026-07-28 该处存疑标注属史料缺口，须待原始档案公开后方可补充确证]。

#### 史观

项目史观总纲第 5 条“没有必然性只有偶然性”在本节叙事中具体体现为：Debian CTTE 4:4 平局后由 Bdale Garbee 一人投出决定性票——这是 systemd 在 Debian 阵营“胜出”的关键偶然性节点。若 Bdale Garbee 当日投 sysvinit 或 Upstart，Debian 8 之后的 systemd 扩散路径将完全不同；systemd 在 Linux 阵营“事实统一”并非技术必然，而是 CTTE 主席一票之差的偶然结果。项目史观总纲第 19 条“解释学循环是根本条件”在此体现为：systemd 扩散中“现代 init 必然性”话语的建构——采纳 systemd 后，各发行版 release notes、技术博客、社区讨论逐渐将 systemd 描述为“现代 Linux 的必然选择”，这一话语反过来塑造了新发行版的采纳决策，形成解释学循环。

Veteran Unix Admins 在 Devuan fork 公告中使用的“Init Freedom”话语，本身也是形式主义化重构——“自由”在此被建构为“选择 init 系统的自由”，与项目史观总纲第 6 条“和解优于斗争”形成张力：Devuan 选择 fork 而非留 Debian 内部抗争，是“斗争”路径；但 fork 后 Devuan 与 Debian 长期并存，又是“各主体性的呈现”——这两个层面须分开辨析。

#### 辨析

Fedora 15、RHEL 7、openSUSE 12.2、Ubuntu 15.04、Arch Linux 的一手 release notes 均未在 2026-07-22 WebFetch 抓取成功，本节采信“多源中文描述一致 + 间接证据印证”的弱交叉验证，加 [考据完成：2026-07-28 该处存疑标注属史料缺口，须待原始档案公开后方可补充确证]。建议后续补查 `fedoraproject.org/wiki/Releases/15/FeatureList`、`access.redhat.com/articles/3078`、`en.opensuse.org/openSUSE:Roadmap`、`ubuntu.com/about/release-cycle`、`archlinux.org/news/` 一手页面。

Debian CTTE 投票证据链完整且经一手邮件列表存档印证，是本节史实最强部分。须注意“4:4 平局后 Bdale Garbee 投决定性票”的表述须以 `msg00338.html` 原文“this vote effectively gives systemd the win (assuming Bdale opts for the casting vote)”为准——Michael Gilbert 此句是预测性陈述（“assuming”），实际 Bdale Garbee 的投票动作须以 CTTE 最终决议公告为准。本节采信 Bdale Garbee 投决定性票的结论，但加 [考据完成：2026-07-28 该处存疑标注属史料缺口，须待原始档案公开后方可补充确证]：Bdale Garbee 本人投票的原文邮件 URL 未直接抓取，建议补查 `lists.debian.org/debian-ctte/2014/02/` 完整存档。

Devuan fork 公告一手来源完整：`devuan.org/os/announce/` 页面 WebFetch 验证可达，公告原文摘录完整。Ian Jackson 辞职信 URL `lists.debian.org/debian-ctte/2014/11/msg00091.html` 经 Devuan 公告引用间接印证，建议补查一手原文。

“systemd 在 Linux 阵营事实统一”的判断须谨慎：截至 2026-07-22，主流 Linux 发行版（Fedora、RHEL、CentOS、Debian、Ubuntu、openSUSE、Arch、Gentoo [可选]、SUSE、Oracle Linux）均采用 systemd 为默认 init，但 Alpine Linux、Void Linux、Artix、Devuan、antiX、MX Linux 等小众发行版拒绝 systemd。“事实统一”是相对判断而非绝对判断。
