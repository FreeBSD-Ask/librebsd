# 184.2.1 Git 工作组的成立语境与核心成员

**要点**：经过多年讨论和初步试验，FreeBSD Core Team 于 **2019 年 Q2** 正式任命 Git 工作组（Git Working Group）负责规划和执行从 SVN 到 Git 的迁移；FreeBSD 基金会提供专项资金资助迁移工作，这是基金会早期（或首个大型）为单一基础设施项目提供的专项资助之一〔“首次”表述未穷尽核验，按存疑软化〕；Git 工作组核心成员经多源交叉验证包括：主席 **Ed Maste（埃德·马斯特）（emaste@）**（FreeBSD 基金会技术总监，整体协调与对外沟通）、**Ulrich Spörlein（uqs@）**（SVN→Git 转换工具与历史完整性）、**Li-Wen Hsu（许立文）（lwhsu@）**（基础设施、CI/CD 与镜像运维）、**Warner Losh（沃纳·洛什）（imp@）**（文档、committer 培训与迁移指南）、**Glen Barber（格伦·巴伯）（gjb@）**（发布工程适配与 releng 分支迁移）、**Baptiste Daroussin（巴蒂斯特·达鲁桑）（bapt@）**（ports 仓库迁移）；工作组采用公开透明的工作方式，所有讨论在 freebsd-git@ 邮件列表公开进行

  **Git 工作组核心成员与分工**：

  | 成员 | 用户名 | 主要职责 |
  |---|---|---|

  | Li-Wen Hsu | lwhsu@ | 基础设施、CI/CD 与镜像运维 |

**史料**：FreeBSD Core Team 2019 年 Q2 状态报告（Git 工作组成立公告）；FreeBSD Foundation 2019 年度报告（Git 迁移资助说明）；freebsd-git 邮件列表早期存档（2019）；BSDCan 2019 DevSummit Core Team 状态更新 ［A］

**史观**：总纲第 15 条——文化即形式主义：Git 工作组的成立标志着 FreeBSD 基础设施决策从“松散讨论”走向“有组织的工程实施”，基金会资助与专门工作组的模式为此后的大型基础设施项目（如 WiFi 驱动改进、aarch64 优化等）树立了先例

**辨析**：Git 工作组成员名单在不同来源中略有差异——核心成员（Ed Maste、Ulrich Spörlein、Li-Wen Hsu、Warner Losh）在所有官方公告中一致，其他成员（如 Glen Barber、Baptiste Daroussin）因负责特定仓库迁移而深度参与，但不总是出现在正式名单中；这是典型的开源项目“核心团队 + 领域专家”协作模式
