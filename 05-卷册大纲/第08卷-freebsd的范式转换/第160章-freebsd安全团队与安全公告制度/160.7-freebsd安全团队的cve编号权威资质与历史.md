# 160.7 FreeBSD 安全团队 CNA 资质与历史

## 160.7.1 FreeBSD 获得 CNA 资质（2019-2020）

**要点**：2020 年从 MITRE 获得 CNA 资质——成为少数拥有独立 CVE 分配权的开源项目，显著缩短安全公告发布周期。

**史料**：MITRE CNA 列表； Foundation 2020 年报 ［A］

**史观**：总纲第 12 条——制度基础设施支撑安全生态。

**辨析**：

**辨析**：安全事件的公开披露与修复时间线存在选择性记录——项目倾向披露已修复的漏洞而淡化未修复的零日漏洞。安全审计的外部独立验证不足，大部分安全声明依赖项目自述。不同 BSD 项目间的安全实践比较需注意威胁模型的差异——面向服务器的 OpenBSD 与面向嵌入式 NetBSD 的安全需求不可直接对比。
**文献**：MITRE CNA 数据库； Foundation 年报 ［A］
