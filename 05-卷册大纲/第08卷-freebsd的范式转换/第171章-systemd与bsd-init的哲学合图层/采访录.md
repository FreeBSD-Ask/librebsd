**字段 1 采访元数据**

- 受访者：Poul-Henning Kamp，FreeBSD 核心开发者，BSD init 哲学立场代表人物
- 采访者：自述，无采访者（期刊文章）

- 存档信息：原始 URL 经联网检索核实可访问（访问日期 2026-07-24），未失效

**字段 2 采访摘要**

Kamp 在 ACM Queue 专栏文章中从 BSD 立场批评了 systemd 的设计哲学，详述 BSD init 的简洁性与可组合性传统、systemd 的复杂性扩张对 UNIX 哲学的背离，以及 systemd 之争对跨发行版兼容性的影响。文章还讨论了 FreeBSD rc.d 系统的设计哲学与 systemd 的根本差异。

**字段 3 考据脚注**

文章经联网抓取 ACM Queue 官网核实，页面标注作者 Poul-Henning Kamp 与发布时间 2017。Kamp 作为 FreeBSD 核心开发者的身份经 FreeBSD 源码仓库 commit 历史与 ACM Queue 作者档案交叉验证。自利偏差审查：Kamp 对 BSD init 的辩护须对照 systemd 维护者的异见。完整考据过程见 [20260724_kamp-systemd-critique-queue.md](../../../原材料/研究/考据记录/20260724_kamp-systemd-critique-queue.md)。

**字段 5 史观映射**

- 总纲 17“证明世界先于解释和改造世界”——据第 25 章总纲 17“问题不在于解释世界和改造世界，而在于证明世界。我们在行动之前必须先使世界‘生成’。FreeBSD 是否存在，本身就是一个开放的问题”，Kamp 对 systemd 的批评不是对 systemd 的“解释”，而是 FreeBSD rc.d 在 systemd 之争中得以“证明”的具体方式——BSD init 哲学立场的陈述本身是 FreeBSD 得以生成的具现，与 14.2 节“真正的问题不在于技术发展的程度，而在于是否动手”同源；这不是“形式决定内容”的辩证（项目统摄史观批评此类机械二元），而是证明世界的实践性回应。
- 总纲 21“革命与改革是历史方法论的分歧”——据第 25 章总纲 21“Linux 靠革命，BSD 靠改革。改革的困难远高于革命。破山中贼易，破心中贼难”，systemd 与 BSD init 的哲学分野正是革命与改革方法论分歧的具体呈现——systemd 作为 Linux 革命方法论，BSD init 作为 BSD 改革方法论；这不是“systemd 战胜 BSD init”的进步叙事，而是革命与改革的方法论分歧，与总纲 3“不存在进步，只有权力再分配”同构。
- 总纲 6“和解优于斗争”——据第 25 章总纲 6“历史的动力不是对抗，而是各主体性的呈现与和解。和解是事物真正完整的一刻”，systemd 与 BSD init 路线分化并非“systemd 战胜 BSD init”或“BSD init 抵御 systemd”的斗争叙事，而是各主体性的呈现与和解——跨发行版兼容性争议中的协商是和解的具体一刻；这是各主体性的形式主义化重构，非“技术演进”的进步叙事。
- 总纲 4“分离聚合是永恒规律”——据第 25 章总纲 4“UNIX 与 BSD、BSD 各分支之间的分合循环，是历史的根本结构”，systemd 与 BSD init 的分野是分离聚合的具体一例——Linux 与 BSD 在初始化系统上的分合循环；这不是“init 系统演进”的进步叙事，而是分合循环的诡异曲线，与总纲 3“不存在进步，只有权力再分配”同构。
- 总纲 13“法律与道德是利益分配”——据第 25 章总纲 13“任何道德问题本质上是利益问题，社区治理亦是形式主义的政治产物”，systemd 之争对跨发行版兼容性的影响并非中立的技术决策，而是利益分配的形式主义政治产物——systemd 推广服务于特定的利益相关者（发行版厂商、企业用户、依赖生态）；Kamp 对 BSD init 的辩护须对照 systemd 维护者的异见，正体现治理话语的非中立性。
