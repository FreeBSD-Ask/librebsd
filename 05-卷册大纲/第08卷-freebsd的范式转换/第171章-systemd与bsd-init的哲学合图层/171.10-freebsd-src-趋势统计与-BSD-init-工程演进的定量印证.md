# 171.10 freebsd-src 趋势统计与 BSD init 工程演进的定量印证

## 171.10.1 freebsd-src commit 趋势与 BSD init 子系统演进的统计印证

**要点**：**统计分析印证**——`freebsd.duckdb` freebsd-src 仓库 1993-2026 年 commit 月度量 Mann-Kendall 趋势检验结果为显著上升趋势（Sen's slope =+1.40/月，p < 0.001，95% CI [1.11, 1.69]）（统计结论 C-03）；Pettitt 与 BUISHAND R 双变点检验一致判定 freebsd-src 变点为 1999-08（p < 0.001，距 2020-01 SVN-to-Git 迁移 245 个月，判定非迁移伪变点）（统计结论 C-08、C-12）；ARIMA(5,0,5) 模型拟合 AIC = 107.39（统计结论 C-29），预测精度 MAPE = 24.56% RMSE = 456.55 coverage = 94.74%（统计结论 C-33），表明 freebsd-src commit 月度量可由 ARIMA 模型较好刻画；BSD init 子系统演化横跨 1993-2026 全期——从 FreeBSD 1.0 的 BSD 经典 init（基于 UNIX V6 init 谱系）到 2003 年 rc.d 框架引入（NetBSD rc.d 移植），再到 2014 年 OpenRC 适配实验与 2020 年代 service(8) 整合，freebsd-src 趋势检验显示 BSD init 子系统演进未导致 commit 量显著变点——1999-08 变点归因于 CSRG 解散前后 FreeBSD 独立项目启动的结构变化，与 init 子系统演进无直接因果关系；systemd 争议期（2010-2014）前后 freebsd-src 趋势持续上升，BSD 社区坚持 rc.d 路线未导致主线开发活跃度下降

**史料**：`freebsd.duckdb` `commits` 表 freebsd-src 仓库 commit 月度量查询；SQL 查询 `SELECT strftime('%Y-%m', committer_date) AS month, COUNT(*) AS commit_count FROM commits WHERE repo_name='freebsd-src' GROUP BY month ORDER BY month`；Python 脚本 **script/phase3_inferential_stats.py** Task 5-6（Mann-Kendall 趋势检验 + Pettitt/BUISHAND R 变点检验）；Python 脚本 **script/phase4_time_series.py** Task 14-15（ARIMA 建模与预测）；统计结论编号 C-03、C-08、C-12、C-29、C-33；查询日期 2026-07-27 ［A］

**史观**：总纲第 15 条——文化即形式主义〔映射存疑，待主理人审定〕：rc.d 路线作为工程文化的延续形态：freebsd-src 趋势检验显示 BSD init 子系统从经典 init 到 rc.d 再到 service(8) 整合的演进未导致 commit 量显著变点——统计数据印证 FreeBSD 在 init 系统保守演化中赓续 CSRG 未竟事业而非中断主线开发；总纲第 15 条——文化即形式主义〔映射存疑，待主理人审定〕：BSD 坚持的 rc.d 路线相比 systemd 的 “激进整合” 更符合 “渐进式改革” 工程方法论，freebsd-src 持续上升趋势为这一工程哲学的统计印证；总纲第 21 条——革命与改革是历史方法论的分歧：BSD init 与 systemd 的路线分化是 BSD/Linux 文化差异的标志性事件，freebsd-src 趋势检验显示 BSD 的保守路线未导致开发活跃度劣势——commit 量持续上升而非停滞

**辨析**：**统计局限性标注**——(1) 统计显著 ≠ 实际显著：Mann-Kendall 趋势检验 p < 0.001 表明 freebsd-src commit 量存在统计学显著上升趋势，但 BSD init 子系统演进的实际工程意义须结合 init 相关 commit 比例综合判断——init 子系统 commit 仅占 freebsd-src 总量的一小部分，整体趋势不能等同于子系统趋势；(2) 变点归因存疑：1999-08 变点与 BSD init 子系统演进（2003 年 rc.d 引入、2014 年 OpenRC 实验）时间不匹配，归因单一化风险高；(3) ARIMA 模型局限：ARIMA(5,0,5) AIC = 107.39 为 freebsd-src 整体 commit 序列拟合结果，未单独建模 init 子系统 commit 子序列，init 演进对整体趋势的贡献率未单独量化；(4) 多重比较风险：本结论与第五卷其他章节引用相同 freebsd-src 趋势统计存在多重比较风险，Bonferroni 校正后显著性可能降低；(5) 0 信任原则适用：commit 量统计不区分 init 子系统与其他子系统，BSD init 演进的工程影响须结合 `libexec/rc/`、`etc/rc.d/`、`sbin/init/` 等目录的 commit 单独量化；(6) systemd 对照局限：freebsd.duckdb 未包含 systemd 上游仓库，跨项目 init 对照仅能基于文献与定性分析，不能进行 commit 量直接比较
