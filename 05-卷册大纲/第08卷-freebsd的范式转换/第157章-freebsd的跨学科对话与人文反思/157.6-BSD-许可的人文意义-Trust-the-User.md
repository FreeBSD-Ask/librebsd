# 156.6 BSD 许可的人文意义：Trust the User

## 156.6.1 BSD 许可证的哲学：信任与自由
  - 要点：BSD 许可证的人文意义远超法律文本本身：(1) **BSD 许可证的历史演变**——最初的 4-clause BSD license（广告条款）源自 UC Berkeley 1980 年代，要求所有广告材料提及 “本产品包含由加州大学伯克利分校及其贡献者开发的软件”；1999 年 7 月 22 日，William Hoskins（UC Berkeley 技术许可办公室主任）正式宣布删除广告条款（第 3 条），形成 3-clause BSD license；2-clause BSD license（又称 FreeBSD license，简化版）进一步删除了 “不允许用贡献者名字背书” 条款；FreeBSD 自 2000 年代起采用 2-clause BSD license 作为新代码的默认许可证；(2) **“Trust the user” 哲学**——BSD 许可证的核心不是 copyleft 的 “强制保持开放”，而是 “信任用户会做正确的事”——你可以自由使用、修改、甚至闭源分发 BSD 代码，只要保留版权声明和免责声明；这种模式基于对人的信任，而非基于法律强制；(3) **与 GPL 的人文对比**——GPL 是 “自由的捍卫者”：通过 copyleft 确保代码永远保持自由；BSD 是 “自由的给予者”：我给你自由，你可以用它做任何事，包括闭源；这不是谁对谁错，而是两种不同的自由观——GPL 更接近积极自由（有权利做什么），BSD 更接近消极自由（不被干涉做什么）；(4) **BSD 许可的实际影响**——BSD 代码被融入了几乎所有现代操作系统：Linux（部分驱动和工具）、macOS/iOS（大量代码）、Windows（TCP/IP 栈历史上受 BSD 影响，现代 Windows 也包含 BSD 代码）、PlayStation、Juniper Junos、Netflix Open Connect 等等
  - 史料：UC Berkeley Office of Technology Licensing. (1999, July 22). *BSD License Advertising Clause Delete Announcement* (official letter from William Hoskins); FreeBSD Project. *FreeBSD License Text*. freebsd.org/copyright/freebsd-license.html; Open Source Initiative. *The 3-Clause BSD License* (opensource.org/licenses/BSD-3-Clause); Free Software Foundation. *Various Licenses and Comments about Them*. gnu.org/licenses/license-list.en.html ［A］
  - 史观：总纲第 14 条——哲学思潮：BSD 许可的 “Trust the user” 是自由意志主义哲学在软件领域的体现——相信技术使用者的判断权，不预设他们会滥用自由；这与 1.md 项目统摄史观中 “信任个体体验” 的立场有深层共鸣：自由不是被授予的，而是被承认的
  - 辨析：常见误解称 “BSD 许可不保护自由”——这是用 GPL 的自由观来评判 BSD；BSD 认为真正的自由包括选择闭源的自由——如果我只能以特定方式使用代码，那不是真自由；当然，这也意味着 BSD 代码可能被 “夺走” 并变成专有软件，但 BSD 社区认为这是自由的代价，而且从长期看，开放协作的价值会胜出（这一点已被 40 年历史部分验证）

## 156.6.2 CSRG 传统的延续：Bostic、Karels、Leffler 等人的科学精神
  - 要点：CSRG（Computer Systems Research Group）的科学精神通过代码和文化传承给了 FreeBSD：(1) **Keith Bostic**——CSRG 核心成员，主导了 Net/2 重写（1991 年为应对 USL 诉讼，带领团队重写了所有 AT&T 代码）、nvi 编辑器（原 vi 许可证问题的重写版）、Berkeley DB 等项目；Bostic 的工作体现了 “为了自由重写一切” 的决心；(2) **Mike Karels**——CSRG 技术领导（1983 年后与 McKusick 共同领导），4.2BSD/4.3BSD 主要架构师之一，后加入 BSDi；Karels 以对代码质量的苛刻要求和细致的代码审查著称；(3) **Sam Leffler**——4.2BSD 技术主管（1982-1983），TCP/IP 栈实现的主要作者之一；1983 年离开 CSRG 加入 Lucasfilm（John Lasseter 正是通过 Leffler 的关系为 4.3BSD 画了 daemon！），后创立 Silicon Graphics 的 BSD 部门，再后创建 Whistle Communications（嵌入式 BSD 产品）；Leffler 是典型的 “从学术到工业” 的桥梁人物；(4) **CSRG 的同行评审传统**——在互联网时代之前，CSRG 就已经在实施类似现代 code review 的实践——所有代码提交都要经过 Karels 或 McKusick 的审查；(5) **可重复实验精神**——CSRG 发布的不仅是代码，还有完整的文档、论文和设计说明（如 4.3BSD 设计书），使得其他人可以理解、复现、改进他们的工作
  - 史料：McKusick, M. K. (1999). *Twenty Years of Berkeley Unix*. in Open Sources; Salus, P. H. (1994). *A Quarter Century of UNIX*. Addison-Wesley; Leffler, S. J., McKusick, M. K., Karels, M. J., & Quarterman, J. S. (1988). *The Design and Implementation of the 4.3BSD UNIX Operating System*. Addison-Wesley; Bostic, K. (1990s). *Net/2 Source Tree Release Notes*. CSRG, UC Berkeley ［B］
  - 史观：总纲第 25 条——终结与延续：CSRG 的科学精神没有随 CSRG 1995 年解散而消失——它通过 FreeBSD、NetBSD、OpenBSD、Darwin 等后代项目延续至今；FreeBSD 的 code review 流程、release engineering 纪律、文档传统都是 CSRG 精神的直接继承者
  - 辨析：需要区分 “CSRG 神话” 与历史真实——CSRG 不是完美的理想国，他们也有代码 bug、内部政治、截止日期压力、人为错误；但他们确实建立了一套在当时非常先进的工程实践，为后来的开源运动提供了参考模型
  - 文献：McKusick, M. K. (1999). Twenty Years of Berkeley Unix. In *Open Sources: Voices from the Open Source Revolution*. O'Reilly; Salus, P. H. (1994). *A Quarter Century of UNIX*. Addison-Wesley.
