# 173.6.2 Juniper Junos 内核、Sony PS4 系统与 FreeBSD 5.x SMP 失败传言

**要点**：FreeBSD 在商业嵌入式领域伴随三类典型传言——(1) “FreeBSD 是 Juniper Junos 的内核”（史实属实需补充版本细节：传统 Junos OS 基于 FreeBSD 内核，早期 6.x 后续升级至 10.x、12.x，但 Junos OS Evolved 基于 Linux 而非 FreeBSD）；(2) “Sony PlayStation 4 系统 OS 基于 FreeBSD 9”（史实属实：PS4 SDK 文档与系统“About”页面开源软件声明列出 FreeBSD 版权，越狱开发者 CTurt 2015-2016 年技术分析确认内核为 FreeBSD 9.0 衍生，PS5 同样基于 FreeBSD 11.x 或 12.x）；(3) “FreeBSD 5.x 的 SMP 重写是一次失败”（真伪混杂：FreeBSD 5.0-RELEASE 2003-01-19 公告自带警告建议保守用户继续使用 4.X，5.0-5.4 SMP 性能未达预期，但 SMPng 引入的细粒度锁、ULE 调度器、KSE 概念在 6.x 之后成熟，5.x 更准确是“痛苦的过渡版本”而非“失败”）

**史料**：Juniper Networks 官方文档（**<https://www.juniper.net/documentation/product/us/en/junos-os/>** 与 **<https://www.juniper.net/documentation/product/us/en/junos-os-evolved/>**）；Juniper 工程师 Andy Foss、Eugene O'Neil 等 BSDCan 2012、2014、2016 演讲；Sony Interactive Entertainment PS4 SDK 文档与系统“About”页面开源软件声明；PS4 越狱开发者 CTurt 2015-2016 年技术分析（GitHub 与个人博客）；FreeBSD 5.0-RELEASE 发行公告（**2003-01-19**，Scott Long 以 <scottl@FreeBSD.org> 名义发布，**<https://www.freebsd.org/releases/5.0R/announce/>**）；Greg Lehey《SMPng: A Progressive Implementation of SMP Support for FreeBSD》（DAFFSBN, 2000）；FreeBSD Foundation 2007 年网页存档（web.archive.org） ［A］

**史观**：总纲第 9 条——经验优先，Juniper 与 Sony 选择 FreeBSD 而非 Linux 的动机是 BSD 许可证允许深度定制与闭源商业化的经验结果，而非理论优越性；总纲第 5 条——没有必然性，只有偶然性，FreeBSD 5.x SMPng 重写是 John Baldwin、Julian Elischer 等主导的偶然工程选择，其实现过程漫长困难，但 6.x 之后的成熟是多次迭代修复的结果而非设计必然；总纲第 22 条——知识注定过时，Junos OS Evolved 转向 Linux 反映 BSD 在高端路由器市场的知识迭代面临 Linux 竞争；总纲第 7 条——理论必须自反，本子节作为商业应用传言考据叙事，自身亦嵌入“BSD 许可证即商业友好”的前理解，须自觉呈现这一前理解；总纲第 23 条——一切历史写作都是基于哲学设定的历史小说，“5.x 是失败”的定性是社区主观判断的形式主义化建构

**辨析**：考据过程留痕——【查证来源】Juniper 官方文档经 juniper.net/documentation 核验，Junos OS 与 Junos OS Evolved 并列展示且内核基础不同；PS4 SDK 文档与“About”页面经 Sony 官方开源软件声明核验；FreeBSD 5.0 公告经 freebsd.org/releases/5.0R/announce/ 一手核验，原文明确警告“may not be suitable for all users”；【交叉验证方法】Junos OS FreeBSD 基础版本演进须以 BSDCan 演讲与 Juniper 文档互证；PS4 内核版本须以 Sony SDK 文档与 CTurt 越狱分析互证；5.x SMP 性能问题须以发行公告与邮件列表讨论、6.x 修复互证；【0 信任原则·Juniper 内核版本对应】Juniper 官方文档未在公开页面直接声明“kernel based on FreeBSD”，但 BSDCan 演讲与 Juniper 工程师社区讨论已多次确认，具体版本对应关系需进一步查阅 Juniper 内部文档；【0 信任原则·PS5 内核版本】PS5 系统软件的 FreeBSD 基础版本（11.x 或 12.x）据开发者分析但 Sony 未公开声明；【0 信任原则·5.x“失败”定性】“失败”一词的主观判断无法量化，不同工作负载下 5.x 表现差异显著，邮件列表中既有抱怨也有正面反馈；【自反性声明】本子节作为 FreeBSD 商业应用与版本评价传言考据叙事，自身嵌入“BSD 许可证即商业友好”的前理解，实际商业采用与版本演化的工程代价须以多源交叉验证逼近史实
