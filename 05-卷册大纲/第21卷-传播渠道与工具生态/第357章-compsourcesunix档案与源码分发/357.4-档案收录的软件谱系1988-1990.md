# 357.4 档案收录的软件谱系（1988-1990）

## 357.4.1 语言与开发工具

  **要点**：该时段档案收录的开发工具涵盖语言实现与工具链多个层次。语言实现方面，最著者为 Larry Wall 的 **Perl 3.0**（`perl3.0/part01` 起共 24 部分），主持人注明此为「perl3.0 首次以 GNU 版权条款分发」；另有 Edoardo Biagioni 的 FP 语言可移植编译器 `fpc`。工具链方面收录：Vern Paxson 的 **Flex**（`flex2`，快速的 LEX 替代）、Mike Haertel 的 **GNU grep**（`gnugrep`，主持人称其「取代此前流传的各种 grep」）及 GNU Grep 1.2→1.3 补丁、Chin Huang 的 `cproto`（从 C 源生成函数原型）、Douglas C. Schmidt 的 `gperf`（完美哈希生成器）、Ozan Yigit 的 `indent`（C 重排版）、Bob McQueer 的 `hat-n-coat`（头文件依赖分析）与 `mcqueer-lib`、Harold G. Walters 的 `xxalloc`（多维动态数组，含 109 个函数）、Hans Boehm 的 `c-gc`（垃圾回收式分配器）、Brian Renaud 的 `metrics`（软件度量）、Paul Haahr 的 `lcomp`（动态指令计数）、Fred J. E. Long 的 `multi-include`。

  **史料**：comp.sources.unix 第 17-20 卷相关期次（`v20i084`、`v20i050`、`v19i055`、`v17i098`、`v18i019`、`v20i039`、`v20i040`、`v18i049`、`v18i052`、`v18i054`、`v20i028`、`v20i002`、`v20i008`、`v20i082`、`v20i080`）；`historical_claims.duckdb` claim CL-RM 段（list 34） ［A］

  **史观**：待核定——本节系 2026-09-15 依主理人“新设卷/章/节”授权新建，史观归属待主理人核定，不预设总纲条目以免伪标签。

  **辨析**：本节的「谱系」为**档案收录谱系**，非软件自身的版本演化谱系——同一软件在档案中的期次顺序不等于其开发顺序（如 GNU grep 1.3 补丁先于其他条目发布，而其对应版本已在此前流传）。主持人夹注中的评价（如「取代此前流传的各种 grep」）为当事人判断，本节引其作为编辑裁量的证据，不作为技术评价的定论。

  **文献**：comp.sources.unix 第 17-20 卷相关期次全文（list 34）；各软件的原始 README 与 Makefile ［A］

## 357.4.2 系统工具、网络与安全

  **要点**：系统与网络工具方面，该时段收录：Kenneth Almquist 的 **ash**（System V shell 重实现，可运行于 4.2/4.3BSD 与 System V 各版本）及其补丁、`atty`（类 Emacs 行编辑）、Dan Farmer 的 **COPS**（系统安全分析工具，`v21i024`-`v21i027` 共 5 部分，附作者说明帖）、Maarten Litmaath 的 `indir`（安全运行 setuid shell 脚本）、Carel Braam 的 `opcom`（受限特权操作接口）、Barry Books 的 `posix.h-tester`（POSIX 1003.1 头文件测试器）、Alexander Dupuy 的 `etherlib`（用户态以太网访问库）、Kent Landfield 的 `rkive`（Usenet 源码归档器）、Steven Grimm 的 `rc.user`（启动时自动运行用户脚本）与 `biff-comsat`（可监控远程邮箱）、Vic Abell 的 `ofiles`（查找谁在占用文件）及其修订版、Cliff Spencer 的 `process-cwd`（打印进程当前工作目录）、Rayan Zachariassen 的 `backup`（增量备份）、Dave Settle 的 `diskhog2`（非 BSD 站点磁盘配额）、Don Libes 的 `pwdiff`（口令文件合并辅助）、Rich Baughman 的 `sls`（可控目录列举）、Antti Louko 的 DES 例程（声明不受美国出口管制）、John Cowan 的 `hill`（Hill 密码加密）。

  **史料**：comp.sources.unix 第 17-21 卷相关期次（`v19i001`/`v19i009`/`v19i010`、`v21i024`-`v21i027`、`v21i031`、`v20i049`、`v20i001`、`v20i058`、`v19i098`、`v20i007`、`v18i055`、`v18i056`、`v18i057`、`v20i046`、`v19i102`、`v18i067`、`v18i068`、`v18i069`、`v18i007`、`v17i092`）；`historical_claims.duckdb` claim CL-RM 段（list 34） ［A］

  **史观**：待核定——本节系 2026-09-15 依主理人“新设卷/章/节”授权新建，史观归属待主理人核定，不预设总纲条目以免伪标签。

  **辨析**：DES 例程的「不受美国出口管制」声明为该投稿人的自述，本节照录而不核验其法律效力——此类声明在 1990 年代初的密码学软件分发中常见，其实际约束力须另据当时的出口管制法规判断。另须注意 COPS 的收录（1990-03）与同年 1 月 COPS 作者自述的投递说明（`COPS, note #2`）分属两帖，后者说明 shar 文件无顺序要求、开头加 mkdir 以保留目录结构。

  **文献**：comp.sources.unix 第 17-21 卷相关期次全文（list 34）；各工具原始 README ［A］
