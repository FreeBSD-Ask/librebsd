# 3.3.3 引用与后续影响范围

<!-- MAIL_INSIGHT: 199601151609.RAA09152@labinfo.iet.unipi.it -->
**观点**：1996 年 1 月，Luigi Rizzo 在 freebsd-hackers 提议社区就 IEEE Computer 刊登 Bokhari 论文未提 BSD 一事“step into the discussion”——被动等待学术出版修正，不如主动介入叙事之争。
**邮件来源**：Luigi Rizzo，freebsd-hackers，1996-01-15，Message-ID: `199601151609.RAA09152@labinfo.iet.unipi.it`
**史学意义**：社区在 1996 年即形成历史叙事须主动争夺的自觉，这预言了未来 BSD 史书写的方向问题——书写权若不自持，就只能由外部叙事代笔。本书与社区档案的深度绑定，正是这一方向在编纂学上的延伸。
