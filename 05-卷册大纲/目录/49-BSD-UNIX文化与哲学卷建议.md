## 二、新卷内容边界建议（分裂前、不含四大 BSD 社区文化）

### 建议卷名

**“BSD UNIX 的文化与哲学（1974—1993）”**——用“BSD UNIX”点明对象是分裂前作为单一项目的 BSD，与现第三卷“UNIX 文化与哲学”（纯 UNIX）形成姊妹卷关系；时段限定词与本书卷 5—9 的断代体例一致。

### 建议章结构（4 章 16 节）

**第 1 章 BSD UNIX 的哲学气质：在贝尔实验室遗产上偏移**

- 1.1 Berkeley Unix 对 UNIX 哲学的偏移：务实主义 vs 纯粹主义（CSRG 如何既继承又偏离 McIlroy/Ritchie 式极简）
- 1.2 快速文件系统（FFS）的设计美学：性能导向与“工程师直觉”的哲学含义
- 1.3 vi 与 csh 的交互设计哲学：Joy 式实用主义的文本证据
- 1.4 网络先行主义：BSD 把 TCP/IP 当作第一公民的价值观转向
- 1.5 学术共同体的开放式工程文化：研究生驱动的开发模式与“晒代码”传统

**第 2 章 BSD UNIX 的符号体系（分裂前）**

- 2.1 BSD Daemon 词源：MIT Project MAC 1963 → 麦克斯韦妖 → 希腊 daimon 的语义层积【自 vol-25 第 6 章 6.4 迁入，迁入后仍可整节保留】
- 2.2 daemon 形象的视觉诞生：Foglio 1976 芝加哥作画与 1988 版权注册【分裂前部分；Beastie 1990s 谱系留原卷】
- 2.3 “BSD”名称本身的符号史：伯克利市 → 贝克莱主教 → 七重形式化【盘内存量考据 314.2 可直接支撑】
- 2.4 传播载体中的符号初现：Usenix 手册封面、net.sources 公告与早期杂志插画（≤1988）

**第 3 章 BSD UNIX 的价值观与社区规范（分裂前）**

- 3.1 “release early, release often”的前身：伯克利分发的偶然节奏与 Net/1 实验
- 3.2 贡献规范的原型：1980 年代 bug 报告文化（4.3BSD 手册 bug 清单）与 Usenet 协作
- 3.3 与 UNIX 黑客文化的同源分流：Jargon File 之前、BSD 特有的工程俚语萌芽【承接卷 3 的 2.5 节分工，收编其“BSD 专属俚语”过时指针所指内容】

**第 4 章 分裂前夕的文化积淀：哪些气质被三家继承**

- 4.1 1993 分叉前夜：三种“何为 BSD”答案的文化根系【与 vol-9 第 8 章互设分工注，不重复承载】
- 4.2 CSRG 解散的文化遗产清单：代码之外的惯例与信条
- 4.3 新卷自反性声明（卷首）

> 说明：以上骨架均为“分裂前 BSD 单一项目”域内；四大 BSD 的社区文化、治理、符号的当代演绎仍分别留在 vol-23（治理）、vol-19（公众记忆）、vol-25 第 6 章 6.1—6.3（Beastie 当代谱系）。

## 二之补：与 Linux 文化挪用研究的边界（ykla 追问）

新卷与全书既有的 Linux 文化挪用研究（主题规则“Linux 文化挪用研究规范”+ vol-17 第 9/10 章 + vol-22 第 1/10/11 章）**是两类不同性质的学术工作，边界如下**：

| 维度 | 新卷“BSD UNIX 文化与哲学” | 既有 Linux 文化挪用研究 |
| ---- | --------------------------- | ----------------------- |
| 研究对象 | BSD 自身（1974—1993 单一项目）的**内在**文化气质 | Linux 世界对 BSD/UNIX 遗产的**外向**取用行为 |
| 问题意识 | “BSD 是什么”——重建其哲学、符号、价值观的正面谱系 | “BSD 被怎样对待”——揭露叙事层对谱系的移植、偏斜、不归名 |
| 方法论 | 内部主义（internalist）文化史：一手文本、发行物、惯例考古 | 谱系学批判 + 0 信任考据：逐案例交叉验证挪用链条 |
| 时间边界 | 严格限于分裂前（≤1993） | 跨时段（1991 Linux 诞生至今的叙事与产业史） |
| 措辞 | 不使用“文化挪用”类判定词——本卷是建设性谱系重建，非批判 | 强制统一用“文化挪用”，禁用“借鉴/参考/启发”等淡化措辞（主题规则） |
| 已有承载 | 全新（当前 25 卷无此正面文化史卷） | vol-17 第 9 章（挪用机制）、第 10 章（不归名四种方式）、vol-22 第 10/11 章（代码谱系无关性 C1—C4 证明） |

**分工注（落位时互设）**：

- 新卷第 3 章 3.3“BSD 特有工程俚语萌芽”与 vol-17 第 9 章的关系是**先后关系而非重叠关系**——新卷写 1980s 俚语的原生形成（分裂前 BSD 内部），vol-17 第 9 章写 1990s 后这些话语符号如何被 Linux 叙事挪用（分裂后外向取用）。两卷在时间轴与视角上首尾相接，不重复承载；
- 新卷第 4 章 4.2“CSRG 解散的文化遗产清单”与 vol-17 第 10 章“不归名的四种方式”互设分工：新卷正面清点遗产，vol-17 反向记录遗产被抹除的机制——一立一破，同一事实的两个观察方向。

**结论**：新卷不是“文化挪用研究”的复制或扩展，而是其**前提性补全**——挪用研究预设了“BSD 有自己的文化”这一事实，而该事实目前在全书 25 卷中恰好没有正面承载；新卷填上这一环，挪用研究的批判才有所本（“被挪用的原本”从缺位变为在场）。

## 四、新卷位置建议（三个方案）

**方案甲（推荐）**：置于**第三卷之后、第四卷之前**，即全书第 4 卷位。

- 理由：与第三卷“UNIX 文化与哲学”构成姊妹对（UNIX 域 → BSD UNIX 域），读者从 UNIX 哲学自然过渡到 BSD 对它的偏移；紧接其后第四卷（通往伯克利）开始 CSRG 实体史，哲学卷作为“先讲气质、后讲机构”的铺垫。
- 代价：卷 4—25 整体后移一位，全书 26 卷，跨卷引用需同步 25 处卷号（有一行脚本可完成，历史迁移注保留旧卷号语义）。

**方案乙**：置于**第五卷之前**（即 4 卷后、BSD 创建史前）。

- 理由：第一卷至第四卷讲完 UNIX 与伯克利背景后，进 BSD 实体史（1BSD）之前插入哲学卷，时间顺序上最贴合。
- 代价：与卷 3 的姊妹对关系被第四卷隔开，读者需跳两卷才能连读文化线。

**方案丙（零位移）**：不新开卷位，作为**第三卷的第 4 章**并入现卷，卷名改为“UNIX 与 BSD UNIX 的文化与哲学”。

- 理由：无重编号成本，姊妹卷并作一卷。
- 代价：卷名变长；且现卷 3 是纯 UNIX 域（21 节已密），BSD UNIX 内容与 Plan 9 批判并列的“批判-反批判”结构会被稀释；与新开卷的意图（分域清晰）相悖。
