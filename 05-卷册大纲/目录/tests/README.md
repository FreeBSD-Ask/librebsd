### 已修复的缺陷（矩阵首轮发现）

1. **字号缩放横向溢出（P1）**：`applyFontSize` 仅设 `.doc-page { zoom }`，盒宽（372 布局 px）随 zoom 等比放大，140% 时 412px 视口渲染 521px、768px 视口渲染 1014px。修复：zoom 设置前取 `document.body.clientWidth`（不受子元素 zoom 影响；注意不能用 `documentElement.clientWidth`——Chromium 标准化 zoom 下它会返回已放大值），同步写入 `width: calc(vw/z − 水平边距)`，并挂 `resize` 监听重算；100% 档与原值完全一致，零回归。
