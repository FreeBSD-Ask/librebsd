## 一、新版总纲定位说明

### 1.1 本书的研究对象（总纲§1 核心定义）

新版总纲明确：本书研究对象**不是单纯的BSD操作系统**，而是：

> BSD作为一种技术传统、组织模式、知识生产方式、软件自由观念和历史记忆对象的形成、发展、传播、分裂、继承与再解释过程。

这个定义将BSD从"软件产品"升级为"历史分析对象"，五维度与现有编纂体系（技术/法律/社区/商业/文化，lishidagang.md §1.1）高度自洽，但新增了**记忆对象的维度**——这正是04号文七维矩阵中标为"最弱"的维度，也是03号文增补记忆史章群M1-M7的依据。

## 四、章节统一模板（总纲§4）——与现有章概述.md的关系

新版总纲规定每章必须包含8节：

```text
1. 历史问题（本章研究什么？）
2. 历史背景（当时的技术/学术/商业/法律/社会环境）
3. 历史事件（发生了什么？）
4. 因果机制（Cause→Mechanism→Effect，必须多因素分析）
5. 技术分析（代码/架构/实现/设计）
6. 人物与组织（人物不是英雄——研究人与制度的关系）
7. 后世解释（后来如何理解这些事件？）
8. 历史反思（本章改变我们对BSD的什么认识？）
```

### 4.1 与现有体系的对照

现有章概述.md 结构为lishidagang.md规定的五（六）段式（背景-事件-分析-影响-遗产-偶然性反事实）。与新版8节模板的映射：

| 新版8节 | 现有五段式 | 匹配度 | 操作 |
| ------- | ---------- | ------ | ---- |
| 1. 历史问题 | 概述中的问题陈述（非制度化的段） | 🟡 | 制度化为独立节 |
| 2. 历史背景 | 第1段"背景" | 🟢 | 直接对应 |

| 角色 | 职责 | 禁止 |

## 八、最终质量标准（总纲§7）

新版总纲规定完成后必须回答四个问题：

1. 为什么这样解释BSD？
2. 证据是什么？
3. 有没有反例？
4. 有没有其他解释？为什么选择这一解释？

最终目标：不是写"一本关于BSD的书"，而是写"一部解释BSD为何成为一种历史传统的科学技术史"。

### 8.1 与现有17号文六项质量指标对照

| 新版总纲验收问题 | 现有17号文指标 | 匹配度 |
| ---------------- | -------------- | ------ |
| 为什么这样解释？ | IC（解释覆盖度——覆盖了多少解释方向） | 🟡 IC测的是覆盖度而非选择理由 |
| 证据是什么？ | EQ（证据质量）+ PS（一手来源覆盖度） | 🟢 |
| 有没有反例？ | EI（证据独立性）+ CC（争议覆盖度——含反例） | 🟢 |
| 有没有其他解释？为什么选这一解释？ | IC（解释覆盖度） | 🟡 IC测多样性与完备性，不测选择的论证过程 |

**缺口**：现有指标覆盖了"有多少解释方向"（IC）和"证据质量"（EQ），但未覆盖**"为什么选择这一解释"的论证质量**。建议在17号文中增设第七项指标——"解释选择论证完整度"（JA，Justification Adequacy），测量每章在选择某一解释方向时是否给出选择理由、是否记录了被排除的解释及排除原因。

### 8.2 "最终目标"的文本落脚建议

新版总纲的最终目标——"一部解释BSD为何成为一种历史传统的科学技术史"——应写入以下位置：

1. index.md 的主线表述（R34叙事主线候选甲的末句）；
2. 各卷00-总览.md的"本卷在全书中的位置"段；
3. 编纂学卷（V19）卷首自反性声明。
