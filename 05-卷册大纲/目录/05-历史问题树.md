## 0. 本文的定位与方法

### 0.1 为什么用"问题树"取代"目录树"

《原则清单》P33（总纲 23"历史小说史观"）与 P29（总纲 19"解释学循环与具体性约束"）共同给出一个指令：本书的组织单位应当是**问题**而非**时间线**。原文依据：

- 总纲 19 编纂指令："与其争论 FreeBSD 是'成功'还是'失败'，不如忠实记录具体事件——在具体性中过度诠释自然受到约束。"（dagang.md 总纲 19）
- 总纲 23："史家不是发现了历史，而是基于自己的哲学设定建构了历史。"
- 《约束矩阵》§4 重组 O14 已判定：FreeBSD 四卷卷名连读构成"奠基→革新→重构→范式转换"的隐性阶梯（违反 R2 反进步）。这暴露了**以时间/阶段为纲的目录树天然携带进步叙事的引力**。

〔推断〕因此，问题树的功能是：把全书的组织原则从"时间先后"翻转为"问题牵引"——时间线退为呈现循环的载体（总纲 4），问题成为读者进入历史的入口。这与 lishidagang.md §2.1.1c"每卷独立可读"的设计一致：问题树让任一问题节点都可独立进入。

### 0.2 问题树的构造约束（问题措辞本身受原则管辖）

问题树中的每一个问题措辞都必须通过《原则清单》的措辞审查。关键约束：

| 约束 | 依据 | 对问题措辞的要求 |
| ---- | ---- | ---------------- |
| 禁必然性 | 总纲 5（没有必然性只有偶然性） | 不得问"BSD 为何**必然**产生"；须问"**哪些偶然条件**使 BSD 得以产生" |
| 禁进步/成败 | 总纲 1/3、标准 3、总纲 8 | 不得问"BSD 为何**失败**""BSD 是否**成功**"；须问"BSD 的**边缘位置如何形成、并生产了什么**" |
| 禁斗争框架 | 总纲 6 | 不得问"BSD 为何**输给** Linux"；须问"BSD 与 Linux 构成**同一形式主义的哪两个相位**" |
| 禁理念冲突还原 | 总纲 13 | 不得问"BSD 与 GPL 的**自由理念冲突**"；须问"BSD 与 GPL **各是谁的利益分配方案**" |
| 禁倒灌 | 总纲 5 推论、§2.3.2 | 不得用今天的"重要/失败"倒灌当时的处境 |
| 不给定论 | §3.2.4 多版本并置 | 顶层问题不预设单一答案；允许多解释方向并置 |

〔推断〕这套约束意味着：**问题树的每一个节点在措辞上就已经是一次哲学执行**，而非中性的标签。这是问题树区别于普通目录的根本点。

### 0.3 三个根（Root）

《原则清单》第二部分问题 1 判定本书研究问题是三层的。问题树据此设三个根：

- **根 A（实质根）**："BSD 家族五十余年是什么、如何运作的？"——对应五维度（技术/法律/社区/商业/文化）的分离聚合循环与权力再分配。
- **根 B（价值根）**："'自由'在 BSD 史中的命运是什么？"——对应书名《给我自由》（问题 10），是全书的价值问题意识。
- **根 C（元根）**："我们如何能诚实地书写这段历史？"——对应方法论层（问题 1/9），由第 19 卷承载。

八大主问题（Q1-Q8）挂于根 A 与根 B 之下；根 C 单独展开为元问题层。
