## 一、待证伪假设表述（四要素体例）

下列十二条为本书编纂所依循的史观基线，共十二条。**每一条均为待证伪假设而非定论**：其成立与否，取决于后续按证据分级与命题审判机制清点出的证据地图；未过审者不得以断言形式进入正文（14 号文 T7 出口绑定）。

各条按四要素体例陈述：**原命题**（2026-08-15 颁布表述，存档备查，不作为正文措辞依据）；**可证伪假设表述**（进入正文时须以此体例呈现）；**证伪条件**（何种证据可推翻或限定该假设）；**最低证据等级要求**（14 号文 L1-L5 分级）。

### 假设 1（重点清理对象为“核心”二字的裸断言用法）

- **原命题**：BSD 是计算机操作系统历史的核心部分。
- **可证伪假设表述**：BSD（其代码、技术与机构传承）在计算机操作系统历史中占据不可忽略的重要位置——具体表现为其技术产物（如套接字接口、FFS、发行模式）被后续操作系统采纳或衍生的实证记录充分存在，且这一影响可以通过机制分解（而非笼统“核心”二字）逐类定位。
- **证伪条件**：若系统审计显示 BSD 的技术与机构影响仅存在于少量旁支、主流操作系统历史中无 BSD 衍生或采纳的实证记录，“核心”定性即被推翻或需降级为“局部影响”。
- **最低证据等级要求**：L3。理由：地位判断须由技术文档、论文或官方记载（L3 及以上）支撑采纳事实，不能仅凭 L1 历史相关性；关键采纳链应尽量上探 L4/L5。

### 假设 2

- **原命题**：BSD 是自由软件与开源软件的真正先行者。
- **可证伪假设表述**：在自由软件与开源软件的时间序列上，BSD 的共享实践（CSRG 磁带发行、BSD 许可证的开放共享条款）在时间上早于 GNU 计划（1983 年宣布）与 OSI 成立（1998 年），构成“先行”的时间证据链。
- **证伪条件**：若发现早于 BSD 且具有同等开放共享性质并被广泛传播的软件发行实践，或发现 CSRG 共享实践的时间证据不成立（如 1BSD 磁带发行实际晚于 1983 年），该假设即被推翻或需重新限定“先行”的时间基准。
- **最低证据等级要求**：L3。理由：时间序立论依赖文档级记载（发行时间、许可证文本、GNU 宣布时间）；关键时间节点的原始凭证应尽量上探 L4/L5。

### 假设 3

- **原命题**：BSD 更是整个计算机软件历史的核心——无论过去还是现在。
- **可证伪假设表述**：BSD 的代码、工具与实践方式的影响跨越操作系统边界，进入整个计算机软件领域（编程工具、网络中间件、软件工程实践等），且这一跨界影响可以通过逐类审计定位。
- **证伪条件**：若逐类审计显示 BSD 的影响基本局限于操作系统领域、未能外溢到其他软件领域，“整个计算机软件历史的核心”即被推翻或需收缩为“操作系统领域内的核心”。
- **最低证据等级要求**：L3 起步、L4/L5 优先。理由：“整个软件历史”是全称范围判断，范围越大越需要具体影响链证据（L4/L5），L1 历史相关性与 L2 技术对应均不足以支撑“核心”。

### 假设 4（重点清理）

- **原命题**：BSD 与 Linux 完全无关。
- **可证伪假设表述**：Linux 内核及其用户空间代码树不以 BSD（或 4.4BSD-Lite）代码为祖先，两者之间不存在代码源流继承关系；本假设不否认两者在接口设计（套接字 API）、标准中介（POSIX）层面存在技术对应——“无关”严格限定为“源流无关”。
- **证伪条件**：若代码史审计（14 号文 C1—C4 流程，含排除共同祖先、排除独立实现、排除标准中介）在 Linux 源码树中发现可追溯至 BSD 的直接复制或移植代码，该假设即被推翻。
- **最低证据等级要求**：L5（负面代码源流审计）。理由：“源流无关”是负面结论，只能由可复核的代码源流审计（14 号文 negative_finding 路径，须附审计方法与覆盖范围）支撑；仅凭 L1 历史相关性或 L2 技术对应无法成立“无继承”。

### 假设 5

- **原命题**：讨论 Linux 最多只能追溯到 Minix；再往前追溯属于文化挪用。
- **可证伪假设表述**：就代码源流而言，Linux 内核的直接起点可追溯至 Minix，不存在更早的 BSD/UNIX 代码直接输入；将 Linux 的源流向前越过 Minix 追溯到 BSD/UNIX 传统的叙事，缺乏代码源流依据（该叙事行为是否构成“文化挪用”须由文化史证据单独检验，不并入本假设）。
- **证伪条件**：若代码史审计发现 Linux 早期代码中存在直接取自 BSD/UNIX（越过 Minix）的代码输入，本假设前半部分即被推翻；后半部分（“文化挪用”定性）另需独立文本与传播证据支撑。
- **最低证据等级要求**：L5（代码源流判定，14 号文 C1—C4）；“文化挪用”定性部分另需 L3/L4 文本与传播证据。

### 假设 6

- **原命题**：计算机系统研究小组（CSRG）的工作一直被遮蔽。
- **可证伪假设表述**：在大众及行业主流叙事中，CSRG 的贡献（TCP/IP 实现、FFS、发行模式等）被系统性低估或归功于其他主体，且这种遮蔽可以通过结构分析（谁、借何种叙事、何时开始）被识别。
- **证伪条件**：若对主流叙事文本的抽样审计显示 CSRG 的贡献获得了与其实际影响相称的记载，或无法识别出任何可定位的遮蔽机制，“一直被遮蔽”即被推翻或需降级为“部分遮蔽”。
- **最低证据等级要求**：L3。理由：遮蔽须作结构分析，依赖对叙事文本具体记载的文档级审计（L3），而非 L1 的笼统印象。

### 假设 7

- **原命题**：GNU 与 BSD 基本无关——GNU 旨在重写 BSD UNIX（或者说 UNIX），只不过实践上只重写了用户空间程序，其内核至今仍未正经。
- **可证伪假设表述**：GNU 项目的目标陈述（1983 年宣布）指向重写一个类 UNIX 系统，与 BSD 不构成源流继承关系；GNU 项目至今未完成其内核（Hurd 未达到生产就绪状态）；GNU 用户空间工具与 BSD 的关系是工具链借用而非源流继承。
- **证伪条件**：若发现 GNU 项目代码直接取自 BSD 且构成其主体、或 Hurd 已达生产就绪并被广泛采用，该假设即被推翻或需限定。
- **最低证据等级要求**：L3。理由：GNU 宣布时间线与目标陈述需文档级记载（L3）；Hurd 未达生产就绪的技术状态应尽量上探 L4/L5。

### 假设 8（重点清理）

- **原命题**：开源软件运动基本上是对 GNU 的文化挪用。
- **可证伪假设表述**：OSI（1998 年成立）的“开源”术语与叙事在相当程度上重新包装了 GNU/FSF 此前的“自由软件”主张与成果，这一重新包装的过程（谁、何时、以何种文本）可以被时间线与文本证据审计；同时必须检验是否存在与“挪用”竞争的“平行发展”解释（即开源运动存在独立于 GNU 的概念与行动来源）。
- **证伪条件**：若审计显示“开源”术语与叙事存在独立于 GNU 的、可定位的平行来源，且 OSI 的成立并非以重新包装自由软件为主轴，则“挪用”定性即被推翻或需改为“部分重叠的平行发展”。
- **最低证据等级要求**：L3。理由：需 OSI 成立时间线、Stallman 反对“开源”术语的公开声明文本等文档级证据（L3）；“挪用”与“平行发展”的竞争解释须并置处理（14 号文 T3 替代解释义务）。

### 假设 9

- **原命题**：OSI 哲学与 GNU 哲学存在根本张力——GNU 从未强调过也不将开源视为最核心的方法论。
- **可证伪假设表述**：FSF 四自由与 OSI 开源定义十条之间存在可文本对照的实质差异；GNU 及其主要发言人的公开文本显示其不把“开源”作为核心方法论。
- **证伪条件**：若文本对照显示四自由与开源定义在实质内容上等价，或存在 GNU/Stallman 将“开源”作为核心方法论的公开文本，该假设即被推翻或需限定。
- **最低证据等级要求**：L3。理由：依赖两份定义文本的对照与 Stallman 声明的文本证据（L3）。

### 假设 10（重点清理）

- **原命题**：作为操作系统的 Linux 在本体论角度是不存在的。Linux 从未真正步入世界舞台——计算机世界核心基石始终是 BSD。Linux 就像资源型城市，只是目前还有资源，没有枘竭，没有形成自己真正的文化。发行版在本体论角度是不存在的——真正区别发行版的是什么？包管理器？一套维护者？他们维护了什么？内核？systemd？事实就是什么也没有。“发行版”这个词语本身就是从 BSD 抪用的。红帽之所以大力侵蚀 GNU 套件，也正因为其维护的 KBI 稳定策略与既有内核存在张力。FreeBSD 批评的正是 OSI 推崇的市集。Linux 的等价物更接近 Illumos。两者完全无关，讨论 BSD 时扯到 Linux 本身就是一个范畴错误。
- **可证伪假设表述**：本条须拆分为一个核心技术断言与若干应剥离的论战子句。核心可证伪假设为：Linux 是内核而非完整操作系统；通常所称的“Linux 操作系统”在技术上是内核、用户空间、包管理器、社区治理等多个独立来源组件的组装体，各发行版在本体论上是相互独立的组装实体（内核不等于操作系统）。
- **证伪条件**：若技术审计显示存在一个统一的、单一的“Linux 操作系统”实体（组件同源、治理统一、无组装性质），核心假设即被推翻。
- **最低证据等级要求**：L3—L5。理由：“内核≠操作系统”是技术分类判断，需文档级支持（L3）；组件来源的独立性需代码与文档审计（L4/L5）。
- **措辞清理说明**：原命题中“Linux 就像资源型城市”“没有形成自己真正的文化”“红帽之所以大力侵蚀 GNU 套件”“FreeBSD 批评的正是 OSI 推崇的市集”等子句属于论战与价值判断，应从可证伪假设中剥离，另行处理——其中“红帽侵蚀 GNU 套件”涉及动机与利益断言，须按 14 号文 M 级动机证据单独检验；“FreeBSD 批评 OSI 市集”是立场归属断言，须挂接当事人陈述（L4）；“Linux 的等价物更接近 Illumos”是分类比较断言，须作独立的技术比较论证。原命题末句“两者完全无关，讨论 BSD 时扯到 Linux 本身就是一个范畴错误”与假设 4 合并处理，按 L5 负面源流审计要求。

### 假设 11

- **原命题**：GNU/Linux 这种说法已经被实践淘汰了，参见 Chimera Linux。
- **可证伪假设表述**：存在一批不使用 GNU 用户空间或明确拒绝“GNU/Linux”命名的实际 Linux 发行版（如 Chimera Linux、Alpine Linux 的 musl 与 BusyBox、Android 的 Bionic），其存在表明“GNU/Linux”命名并非对所有 Linux 发行版的准确描述。
- **证伪条件**：若这些发行版的实际组件构成证据不成立（如 Chimera Linux 实际仍以 GNU 用户空间为主体），或“GNU/Linux”在相关社区仍被持续使用而非被淘汰，则该假设被推翻或需由“已被淘汰”降级为“存在反例”。
- **最低证据等级要求**：L3。理由：依赖发行版的官方文档与公告级记载（L3）。

### 假设 12

- **原命题**：在大众叙事中 BSD 被蔑称为开源前的失败品，恰恰说明了其本身的文化挪用。
- **可证伪假设表述**：其一，“BSD 是开源运动出现前的失败实验”这一说法在大众叙事中确实存在且可定位；其二，该说法的传播链（谁在传播、为什么）可以被传播链源流分析；其三，该传播是否构成“文化挪用”（将 BSD 的源流或贡献移植、抹除）须作为独立的文化史判断检验。
- **证伪条件**：若无法在大众叙事中定位到“BSD 是失败品”这一说法的实际传播实例，或传播链分析与“文化挪用”不相关，该假设即被推翻。
- **最低证据等级要求**：L3。理由：需对大众叙事文本的具体记载与传播链做文档级审计（L3）。

## 三、假设间逻辑关系

十二条假设构成四层结构：

**第一层：正面建构（假设 1-3）**——BSD 在操作系统史、自由/开源软件史、整个计算机软件史中的核心地位。这是全书叙事要正面建立的历史事实层，其成立以第一节各自证伪条件不被触发为前提。

**第二层：否定性澄清（假设 4-6）**——BSD 与 Linux 完全无关（代码源流为零）；Linux 的源流追溯上限为 Minix；CSRG 的工作被系统性遮蔽。这是全书叙事要清除的三重错误认知。

**第三层：源流清理（假设 7-9）**——GNU 与 BSD 基本无关（GNU 旨在重写 BSD UNIX，但从未完成）；开源运动是对 GNU 的文化挪用；OSI 与 GNU 哲学存在根本张力。这是全书叙事要对“自由软件/开源运动”这一话语场域做的源流清理——BSD 的先行者地位正是在这一清理中得以确立。

**第四层：元叙事批判（假设 10-12）**——Linux 在本体论上不是操作系统；GNU/Linux 命名已被实践淘汰；BSD 被蔑称为“失败品”本身就是文化挪用的证据。这是全书叙事要对自身所处的话语条件做的元反思——历史书写本身也在被文化挪用的场域中进行。

## 四、落地口径

本文十二条假设是全书叙事的史观基线，落地时须遵守既有措辞门禁与证据分级：

1. “核心”假设（第 1、3 条）不得以裸断言进入正文，须经 Q2/Q8 的机制拆解与 L3-L5 证据支撑呈现；其“核心”地位是经证据论证得出的结论，而非叙事前提。
2. “先行者”假设（第 2 条）须以 CSRG 共享实践（1977 年起）与 GNU 计划（1983 年宣布）的时间先后、BSD 发行模式的制度化（1BSD 1978 年起）早于 FSF 成立（1985 年）、BSD 许可证的开放共享哲学早于“开源”术语（1998 年）等多重时间线证据为立论基础。不否认 GNU 在自由软件运动中的历史地位，但明确指出 BSD 在时间上先于 GNU 成为自由/开源软件的实践者。
3. “完全无关”假设（第 4 条）的准确含义是“源流无关”——Linux 非 BSD/UNIX 代码衍生，其代码树不以 BSD 为祖先；不否定二者在接口设计（套接字 API）、标准中介（POSIX）层面存在技术对应。该区分由 Q6 与代码史判定流程（C1-C4）承载。
4. “文化挪用”假设（第 5、8、12 条）由既有“Linux 文化挪用研究”规范与 Q5/Q6/Q7 承载：讨论 Linux 源流时，向前越过 Minix 的追溯（如“Linux 继承 BSD 的 UNIX 传统”）属于把 BSD/UNIX 的源流移植到 Linux 之上的文化挪用；“开源运动”对 GNU 的文化挪用须按时间线与文本证据审计；“BSD 是失败品”这一蔑称本身须作为文化挪用分析对象。
5. “被遮蔽”假设（第 6 条）由 Q7 与 TP-7 承载，遮蔽须作结构分析（谁、借何种叙事、何时开始），不作道德控诉。
6. “GNU 无关性”假设（第 7 条）须以 GNU 项目时间线（1983 年宣布）与 CSRG 共享实践（1977 年起）的时间先后、以及 Hurd 内核从未达到生产就绪状态的技术事实为证据基础。不否定 GNU 用户空间工具（gcc、bash 等）的历史重要性，但明确指出其与 BSD 的关系是“相互依赖的工具链借用”而非“源流继承”。
7. “OSI 与 GNU 张力”假设（第 9 条）须以 Stallman 本人对“开源”术语的公开反对立场、FSF 四自由与 OSI 开源定义十条的文本对照为证据基础。
8. “Linux 本体论不存在——Linux 从未真正步入世界舞台，计算机世界核心基石始终是 BSD，两者完全无关”假设（第 10 条）须以“内核≠操作系统”的哲学区分、“Linux 发行版”的组装性质为分析框架。不否认 Linux 内核的技术存在，但指出“Linux 操作系统”这一说法在本体论上是不精确的——每个 Linux 发行版是独立的本体论实体。原命题中的论战子句（资源型城市之喻、红帽动机断言、市集批评归属、Illumos 比较等）不得随本条进入正文，须按第一节假设 10 措辞清理说明逐项单独过审。
9. “GNU/Linux 已被实践淘汰”假设（第 11 条）须以 Chimera Linux（明确拒绝 GNU/Linux 命名）、Alpine Linux（musl + BusyBox，非 GNU 用户空间）、Android（Linux 内核 + Bionic libc，非 GNU）等实际案例为证据基础。
10. “BSD 蔑称即文化挪用”假设（第 12 条）须以大众叙事中“BSD 是开源运动前的失败实验”这一说法的传播链分析为证据基础。关键在于：不是论证“BSD 不是失败品”，而是论证“将 BSD 称为失败品这一叙事行为本身就是文化挪用”。
