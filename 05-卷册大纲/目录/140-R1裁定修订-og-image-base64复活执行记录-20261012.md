# 140 批执行记录：R1 裁定修订——og:image（base64）复活（2026-10-12）

缘起：ykla 对 139 批注销依据指正——“新增图片引用会触碰零外链红线，但是图片可以 base64 离线”。本批为**修订批**：复核指正、修订 R1 裁定为分态处置；零产物变更。

## 一、技术复核（0 信任实证）

- 第九件 D1 四正则（`src=\s*["']https?://`／`href=…`／`url(…`／`@import`，audit_page_assets.py L424-427）**只覆盖资源引用形态**，不覆盖 `meta content=` 属性。
- **合成用例实证**（script/_140_d1test.py）：og:image（base64 data URI）／og:image:width·height·alt／og:site_name／twitter:card·twitter:image（data URI）——**全部 0 命中**；og:url（content= 形态 https 字符串）0 命中；canonical（link href）——**FAIL href= 外链**。
- 结论：ykla 指正成立——139 批注销依据第 2 条（“og:image 触零外链红线”）仅对**外部 URL 形态**成立；base64 data URI 形态为纯内联，不违红线。方案原文 D4 把“规范要求绝对 HTTPS URL”（功能性）与“触碰零外链红线”（仅外部形态）混为一谈，139 批未予拆分——系本批修订缘由。

## 三、og:image 复活项的实施门槛（点名施工时执行）

1. **载体图字节权衡**：复用既有 apple-touch-icon.png（180²，8,737 B→base64 约 11.6KB）或生成专用卡图（标准 1200×630 约 30-60KB）——实施批定夺；
2. **判据面**：第九件 C 类扩展（og:image data URI 形制＋与磁盘派生件逐字节一致，同 C3 型）＋登记四方（registry 第九件描述更新／脚本 README／流程规则／CLAUDE）；
3. **功能注记如实披露**：多数社交平台爬虫忽略 data URI——社交卡片实效有限；offline／归档类消费者可读；
4. **全链义务**：版本递增＋装配＋门禁 26 项＋三套回归。
