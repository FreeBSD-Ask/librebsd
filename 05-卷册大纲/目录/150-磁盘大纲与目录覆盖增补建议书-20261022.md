## 一、方法（禁止机械比较的三层法）

1. **溯源注引用集**：目录注文引用磁盘路径共 15 章（`05-卷册大纲/第N卷-…/第M章-…`）——直接映射集，不作候选。
2. **关键词预筛（只作候选，不作事实）**：449 章的 slug 分词与目录标题全集比对，取命中率最低 55 章为候选池。依据 w172 战役教训，本地关键词预筛系统性假阳/假阴，**候选池内每一件均须逐个语义核验后才可判定**。
3. **逐个语义核验**：对候选池 55 章逐一取特征词检索目录（章题＋节题＋注文），按“命中位置是否承载该主题本体”判定——异名同义、压缩归并、注文引用均计为覆盖；仅豁免登记/历史提及中出现不计。

## 三、逐条分析与增补建议（真缺口 6 项）

### 3.1 FreeBSD 源码仓库版本控制迁移史（部分覆盖 → 建议增补节）

- **磁盘来源**：盘 07 第 117 章“cvs 到 subversion”＋盘 08 第 184 章“从 subversion 到 git 的迁移历程”。
- **覆盖核验**：目录 2.7“从 SCCS 到 Git：代码比对与版本追踪的工具演进”载泛工具演进（SCCS 1972／RCS 1982／CVS 1986／BitKeeper／Git 2005），**未点名 Subversion，未载 FreeBSD src 仓库迁移**；卷 46 ch9 9.1 所载“2008 年 11 月自 CVS 转入 git”系 **DragonFly** 的迁移；FreeBSD src 仓库两次迁移（2008 CVS→SVN、2020—2021 SVN→Git）零专载（cgit／GitHub 仅见于注文）。
- **判定**：十二年 SVN 时代与 2021 git 化是 FreeBSD 工程史主干事件，泛演进节不能承载，真缺口。
- **建议落点**：卷 33（FreeBSD 操作系统史）ch14 后增节，或卷 34 FreeBSD 软件生态章内。拟节题：**“src 仓库版本控制迁移：CVS、Subversion 与 Git（2008—2021）”**。
- **优先级**：高（一手史料充足：commit 邮件、release 公告、UPDATING）。

### 3.2 邮件反垃圾战争（F-13 静默丢失章，部分覆盖 → 建议回写）

- **覆盖核验**：“反垃圾/垃圾邮件/spam”全目录仅 1 处——5.1“spamd 与网络服务防护”（OpenBSD spamd 一节）。RBL、ORBS、sendmail 反垃圾配置时代、内容过滤共同体战争零专载。
- **判定**：F-13 豁免在案（92 号文 L608，CL-RM-010184/010621 证据充足），覆盖现值不足以承载原章主题，建议回写。
- **建议落点**：卷 42 OpenBSD 技术专题史 ch5/ch9 扩展节，或卷 63 BSD 分支的治理制度。拟节题：**“邮件反垃圾战争：RBL、ORBS 与内容过滤（1996—2010）”**。
- **优先级**：高（证据已灌库，回写即接驳）。

### 3.3 BSD 桌面图形栈（缺失 → 建议增补节）

- **磁盘来源**：盘 21 第 412 章“图形绘图与桌面应用工具”。
- **覆盖核验**：“X11/Wayland/图形栈”全目录仅 1 处——5.1“MIT、X11 与 Expat 许可证”（许可侧），图形栈本体零专载：XFree86、X.Org 分叉、X11 在 BSD 上的服务器生态、Wayland on FreeBSD 均无承载。
- **判定**：真缺口。桌面可用性是 BSD 大众化叙事的必要组成，且卷 21 盘树“传播渠道与工具生态”域在目录侧对应章未覆盖图形面。
- **建议落点**：卷 34 FreeBSD 技术专题史工具生态章内增节；拟节题：**“BSD 桌面图形栈：XFree86、X.Org 与 Wayland（1992—2026）”**。
- **优先级**：中。

### 3.4 美国政治制度史：历任总统时代史（缺失 → A/B 待裁决）

- **磁盘来源**：盘 17 第 359 章“美国政治制度史-历任总统时代史”＋第 360 章“总统画像与辩证运动”。

- **判定**：A/B 二选一——**A**：有限并入卷 2 ch2 作“法律与政策的政治语境”节（拟题“联邦政治语境：监管与科研资助的总统时代（1970s—2026）”）；**B**：不采（主题边界——FreeBSD 中心主义下，总统时代史与书主题关联弱，盘树该两章系背景层）。

- **判定**：同 §3.4 A/B——东岸语境（DEC、IBM、MIT 所在）与卷 3 物质条件章（机器、产业与商业时代）存在真实接口，**倾向 A 有限并入**卷 3 一节（拟题“东岸产业地理：波士顿 Route 128 与大型机产业”）。

### 3.6 双向检验：验证方法论史（缺失 → 建议增补节）

- **磁盘来源**：盘 19 第 391 章“bsd 史编纂的双向检验”。
- **覆盖核验**：“双向检验/QAA”零命中。卷 71 ch3 之 3.2“周期性结构的检验”与 3.3“分离与衰落关系的再检验”检验的是分离聚合模型，**非验证方法论本体**；逐条对照式双向检验（QAA SBS 传统、0 信任、三次复查）作为史学实践方法无承载。
- **判定**：真缺口（小而实）。方法论自反性是全书七条方法论规范之一，其“实践如何被检验”应有史体裁体面。
- **建议落点**：卷 71 ch3 增节；拟节题：**“双向检验：从对照式核查到 0 信任复核（1990s—2026）”**。
- **优先级**：中（lishidagang.md 第四/五部分为一手底本）。
