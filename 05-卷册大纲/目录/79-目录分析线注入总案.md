## 三、吸收口径与冲突仲裁

### 3.1 为什么不能照搬"正统"

本建议所称“正统”在学界通常指**后人在系统化过程中形成的教条**（历史分五阶段依次递进、经济条件单向决定其余、三段式上升、终局论）。这套系统化成果与三源（`dagang.md`／`shigang.md`／`lishidagang.md`）**正面冲突**，且冲突点已被三源逐条点名（见 3.4）。

另一方面，**著作本身**（而非后人系统化）中可用的分析面与三源高度相容，可归结为七项：做事的过程与所用的工具、协作与分工的形态、成果归谁与有无回偿、说法如何把做法讲成物的属性、跨国往来的格局、把零散材料读成整体、以及先立大概还是先摆材料的叙述次第。

**因此吸收口径＝“取可用分析面、拒系统教条”。** 这一路线在三源内部本身有依据：`第29章 29.5 节`所批评的正是"后人编造"的系统化，而非著作文本本身。

### 3.2 吸收原则

| | 原则 | 做法 |
| ---- | ---- |
| --- | ---- | ---- |
| **乙** | **拒系统教条** | 明确不吸收：历史分五阶段依次递进、经济条件单向决定其余、三段式上升、终局论、以投入耗时衡量价值、以阵营对抗解释一切动力 |
| **丙** | **归位为并列分析线** | 吸收后的范畴**不作为总解释框架**，只作为与时间、地理、信仰、审美、文化并列的一条分析线；凡涉因果处一律写"并列/交织"，禁写"决定/归根到底" |

## 五、卷、章、节各怎么用

ykla 2026-09-25 意见为拆分打散，卷、章、节均允许新增，但以打散为准；成稿用词另须避开一整套术语（见第四节的映射表与本节末）。据此本轮对三个层级的用法如下。

**卷不用。** 不是因为成本，而是因为新增专卷等于把这条分析线立成全书的第二骨架。三源的多条总纲指向相反的处置：总纲 8 讲各方本体平等，总纲 10 明言“决定世界的并非某个阶级，也不是什么经济”，总纲 20 讲中心与边缘是形式主义运作的固有结构而非可纠正的偏差。真要为它开一卷，就得在目录层承认存在一条贯穿六十年的主轴，这与上述判断相悖。本文前一稿拟过新卷第 29 卷，已撤回，理由记录于此备将来复核。

将来若确实需要新卷，判据应当是材料而非主题：既有各卷在某一时段或某一对象的材料都已落到无章可容、且总量超过三章时，再议。目前不满足。

**章用两处。** 用在没有主题归属的宿主上：卷二（UNIX 的物质基础）与卷三十八（史学史与方法）。这两卷的章本就按“某一类条件”“某一类史料”分章，加一章不构成对任何主题线的集中；反过来，若在卷十六、卷二十八、卷三十三这类项目卷或主题卷里加章，那个卷立刻会显出轮廓，与打散相悖。两处新章各六节，见第七节。

**节是主力。** 三十二处在既有章内新增，每章最多落一处，另加五十一处加注、两处节题改写。这样这条线在有材料的地方密、无材料的地方稀，而不是每卷等量铺一遍。

**用词纪律。** 节题、章题、注文与卷首综述段一律避开一整套术语，含“劳动”“雇佣”“资本”三例及其全部派生词。三十条的逐条替换见第四节，本文不再复列。第七至第九节所列条目已按此纪律逐条核过，目录层零出现。
