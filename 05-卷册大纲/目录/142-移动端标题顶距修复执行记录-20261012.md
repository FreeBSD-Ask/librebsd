# 142 批执行记录：移动端标题顶距修复（面包屑顶覆化）（2026-10-12）

ykla 报障：“给我自由——一部 BSD 的历史标题在移动端距离顶部过远，缩短为既有50%”。

## 一、根因（390×844 探针实测，0 信任）

- 标题顶距 **148px**＝`.doc-page` padding-top **64px**（+safe-area）＋面包屑盒 **70px**（路径两行换行）＋margin-bottom **14px**。
- 面包屑系 doc.js 动态插入 .doc-page 首位（模板无此元素），`scrollY>120` 才显示；CSS 默认 `visibility:hidden`——**但 sticky 流内保留位在加载态照常占位**，84px 纯属不可见占位，把标题推低。
- `.opt-tools`／`.toc-toggle` 浮动控件固定于 y 18..62——padding 64px 系让位控件的功能性净空，不可再压。

## 二、修复（≤560px 手机块；821-820 平板按范围界定未动）

1. **面包屑改 fixed 顶覆浮层**：`position: fixed; top: 0; left: 20px; right: 20px; margin: 0`——隐藏态零占位；显示时机不变（doc.js scrollY>120）；z 40 低于浮动控件 70，层叠不变；滚动态与既有 sticky 吸顶视觉一致（毛玻璃胶囊）。
2. **padding-top 64→72px**：对齐桌面基线 72px；标题顶距＝72px＝既有 148px 的 **48.6%≈50%**。
3. **块位纪律（级联反压同族再犯）**：覆写首版置于前部 560 块被基线 `.breadcrumb`（L797 区，源序在后、同特异性）反压——实测 position 仍 sticky；改置于晚期 1099 面包屑避让块（L1047 区）之后生效。**137 批级联反压教训的同族再现：媒体块内覆写“前置基线”类规则必须核对源序**。
4. **T16 判据修订**（tests/visual_regression.mjs）：①补 `visibility` 维度——`visibility:hidden` 的元素不构成视觉重叠，仅查 display 会把不可见面包屑误计；②测量前显式 `scrollTo(0,0)`＋300ms——加载态语义确定（前序用例有滚动）。

## 三、核验

- **390px**：标题顶距 148→**72px**（48.6%）；**560px**：121→72px；**820px**：125px（未动）。
- load 态：面包屑 `fixed`＋`hidden`＋零流占位；滚动态（scrollY=800）：`fixed`＋`visible`＋y=0、x 20..370 顶覆正常。
- **visual 23/23 全绿**（T15 抽屉层叠、T16 新判据、T18 横向溢出三视口全过）；matrix／fullsize 见落账核验；门禁 26 项＝23 绿＋3 既有另线（同基线集）。
- 装配 `--check` 无漂移；页面 2,741,621→**2,742,685 B**（+518，注释与规则行）；版本 **2026.10.12-17:16**；口径守恒 67／483／3468／注 1262。
