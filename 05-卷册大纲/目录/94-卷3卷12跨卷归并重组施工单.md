## 一、判据（v2 订正，取代 v1 的“时段”判据）

ykla 令：**区分哪些是 UNIX 原创且后来变化不大，哪些是 BSD 原创或颠覆 UNIX**。据此定三分类：

| 类 | 定义 | 归卷 |
| -- | ---- | ---- |
| **甲·UNIX 原产·低变** | Bell Labs／Research UNIX 原创，且 BSD 时代**未根本改变** | **卷 3** |
| **乙·BSD 原创／颠覆** | Berkeley 原创，或对 UNIX 模型作**根本改造**（颠覆） | **卷 12** |
| **丙·第三方** | System V／GNU／ANSI／POSIX／Mach／Sun 等非 Bell 非 Berkeley 来源 | 按谱系：通用技术史→卷 3；BSD 采用实践→卷 12 |

**与 v1 的关键差别**：v1 只做“卷 12 → 卷 3”单向并并（把 UNIX 基底并走），漏了**卷 3 里现居的 BSD 原创内容**。v2 是**双向**——BSD 原创（FFS/UFS、demand paging、csh、vi、sockets、RPC/NFS 等）即使现居卷 3，也应移入卷 12。
