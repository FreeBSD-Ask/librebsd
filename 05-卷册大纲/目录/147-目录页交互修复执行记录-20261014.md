# 147 批执行记录：目录页交互修复（页内导航历史中性化＋左侧按钮与面包屑干涉）（2026-10-14）

ykla 报障两项：“①页面未改变，仅滑动，却产生了一堆历史记录在浏览器；②左侧边栏按钮与面包屑存在干涉。处理方案应同右侧按钮。”
当晚补充定裁第①项处置目标：“**无论怎样点击都不应当产生历史记录（应仅有一个）**”。

## 一、根因（0 信任实测，钉定 Chromium-1200＋系统 Chrome 双浏览器）

### ① 历史记录

- 纯滚动**不**产生条目（滚动智能同步走 `history.replaceState`，实测 Δlen=0、`history.back()` 直接返回上层页）——ykla 所见“一堆历史记录”来自**页内锚点的默认导航**：目录链接、卷导航、注内深链、检索结果等每点一次即 push 一条同文档条目（复现脚本实测点击两处目录 len 6→7→8；n／p 键的 `location.hash` 赋值亦 +1）。
- 叠加效应：后退键须逐条“页内滑动”方能离开——正是“页面未改变，仅滑动，却产生了一堆历史记录”。

### ② 左按钮干涉

- 142 批（10-12）面包屑改 ≤560px fixed 顶覆（left/right 20px、margin 0）后，与左上“目录”按钮（`.toc-toggle` [16,16→60,60]）几何重叠 40×29～44px；
- 面包屑与按钮**同位 z 40**、面包屑 DOM 源序在后 → 面包屑压在上层，**按钮中心被盖住不可点**（命中测试：`elementFromPoint(38,38)` → `.breadcrumb`〔含 `prog`〕；遮罩未清理场景为 `tocScrim`）；右上“设置”因 ≤820px z 90 始终浮于上层、可点——ykla 指定处置即以此为准。

## 二、修复（装配源层施工）

1. **`src/js/80-breadcrumb.js` 新增 §6a 页内锚点历史中性化**：全部页内 `#` 链接经 document 级委托统一接管——`preventDefault → scrollIntoView({block:'start'})`（与原生锚点同构：尊重 scroll-margin 与 CSS scroll-behavior、减动效回落）`→ history.replaceState('#id') → jump()` 收尾（注展开／当前项高亮）；修饰键与非左键一律放行（保留新标签打开等原生语义）；§11 的 n／p 由 `location.hash =` 赋值改走同一 `goInPage()` 通道。本页恒只占载入时一条，Back 即离开本页（深层位置仍随片段保留，前进返回可复原）。
2. **`assets/doc.css` ≤560px 块（承 142 晚期块）**：`.toc-toggle { z-index: 90; }`（与 ≤820px `.opt-tools` 同值——浮于面包屑之上，中心始终可点，处置同右侧按钮）；`.doc-page .breadcrumb { padding-left: 44px; }`（按钮右缘 60＋5px 净空——卷题首字不再被浮钮切入；右侧尾端为进度条〔非题文〕无需避让；双类选择器胜过现代化层同专指胶囊内衬，先例 `.doc-metrics .selfcheck`）。
