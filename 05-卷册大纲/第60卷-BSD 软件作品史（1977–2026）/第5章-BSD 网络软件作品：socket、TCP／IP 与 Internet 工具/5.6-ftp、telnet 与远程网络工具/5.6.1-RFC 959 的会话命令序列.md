# 5.6.1 RFC 959 的会话命令序列

<!-- MAIL_INSIGHT: ghptvle00WD5QoWx41@andrew.cmu.edu -->
**观点**：1994 年 5 月，卡内基梅隆大学的 Derrick Brashear 在 comp.unix.bsd 指出，IETF 的 telnet 工作组新实现 “基本就是 4.4 BSD telnet”，外加 Kerberos 4 与 Kerberos 5 支持，并已稳定运行数月。
**邮件来源**：Derrick Brashear，comp.unix.bsd，1994 年 5 月，Message-ID: `ghptvle00WD5QoWx41@andrew.cmu.edu`
**史学意义**：IETF 工作组直接以 4.4BSD 代码为底本制作互联网标准实现，为 “BSD 参考实现作为 IETF running code 的物质载体”提供了 1994 年的具体例证，补充了 RFC 制度与 BSD 代码之间从共鸣到融合的关键一环。
