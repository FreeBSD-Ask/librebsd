# 2.7.3 教材与课程的传播

<!-- MAIL_INSIGHT: unc.963 -->
**观点**：1981 年 7 月，北卡州立的 Bill Mitchell 报告已把 4BSD 版 vi 改到 VMS 上的 Eunice 运行，vi 在 C shell 下正常，还询问是否有人让 4BSD 的 C shell 在 Eunice 上工作。
**邮件来源**：Bill Mitchell（北卡州立大学），comp.os.eunice，1981 年，Message-ID: `unc.963`
**史学意义**：证明 vi 与 csh 在 1981 年即通过 Eunice 进入非 BSD 的 VMS 生态，是其跨系统扩散的早期实例。
