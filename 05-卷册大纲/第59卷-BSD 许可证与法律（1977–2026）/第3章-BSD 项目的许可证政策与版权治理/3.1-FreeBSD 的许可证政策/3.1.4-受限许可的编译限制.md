# 3.1.4 受限许可的编译限制

<!-- MAIL_INSIGHT: 2018-04-22 [patch 6/9] LICENSES: Add CDDL-5.0 -->
**观点**：2018 年 4 月 22 日，Thomas Gleixner 将 CDDL-5.0 许可证文本正式加入 Linux 内核树（LICENSES/other/CDDL-5.0），Greg Kroah-Hartman 审阅批准。CDDL 是 ZFS 使用的许可证，将其文本加入内核树是 SPDX 许可证标准化的一部分，但 ZFS 代码本身因 CDDL 与 GPL 的不兼容性从未进入 Linux 主线内核。
**邮件来源**：Thomas Gleixner <tglx@linutronix.de>，Linux Kernel Mailing List，2018-04-22，Message-ID: 2018-04-22 [patch 6/9] LICENSES: Add CDDL-5.0
**史学意义**：CDDL 文本进入内核树但 ZFS 代码被拒门外，揭示了开源许可证研究的核心悖论：许可证文本的标准化（SPDX）解决了元数据层面的互操作性，但无法解决实质性的法律冲突。这一案例为理解 UNIX 从 AT&T 许可证到 BSD 许可证再到 GPL 的演化提供了当代参照。
