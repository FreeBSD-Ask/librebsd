# 5.6.4 与 GPL 的不兼容争议

<!-- ROW_MINE: freebsd-hackers.messages.1279222 -->`
- 【Linux社区】2005年2月 Edward Smith III(ed.smithiii@us.army.mil) 在“Star & FreeBSD”串中 追问Jörg Schilling将star从GPL改为CDDL后是否可入FreeBSD，“you may have a program that behaves 98% like gnu tar but is not based on the GPL”是 工具方主动从GPL切换到CDDL以兼容BSD的具体案例 `

<!-- ROW_MINE: freebsd-hackers.messages.1292377 -->`
- 【Linux社区】2008年 Robert Watson (rwatson at FreeBSD.org) 在“licensing question APSL”串中阐述 FreeBSD 立场“on-going efforts to identify and replace non-BSD licensed code with BSD licensed code”并列举 ZFS/DTrace 的 CDDL 隔离实践，是 BSD 治理层制度化处理非 BSD 许可证代码的纲领性表述 `

<!-- ROW_MINE: freebsd-hackers.messages.1321512 -->`
- 【Linux社区】2020年 Josh Paetzel (jpaetzel at FreeBSD.org) 在“open-vm-tools in base”串中提议将 VMware 工具并入 base 引发争议“the vmmemctl driver for FreeBSD is GPL'd, and vmblock is under 2-clause BSDL. Do we accept GPL'd kernel modules?”，是 FreeBSD 治理层就 GPL 内核模块入基线展开的历史性辩论 `

<!-- ROW_MINE: freebsd-hackers.messages.2536255 -->`
- 【Linux社区】2024年 obiwac (obiwac@freebsd.org) 在“Re: Questions about best practices w.r.t. writing a kernel module port which modified LinuxKPI (BATMAN)”串中询问 FreeBSD 政策“the kernel module for batman can't be shipped with FreeBSD as it's GPL”，是 BSD 维护者在 LinuxKPI 移植 Linux 内核模块时直面 GPL 传染性约束的实证 `
