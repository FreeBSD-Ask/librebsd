# 184.1 NetBSD 2.1/3.0 多平台扩展与稳定化（2005-2007）

**NetBSD 3.0 发布 commit 原文**：

> Welcome to NetBSD 3.0 release.
>
> ——netbsd-src 仓库，commit 2005-12-18T14:11:21Z

**要点**：NetBSD 2.1（2005.11）与 3.0（2005.12）以稳定化为主，扩展新平台支持（如 AMD64、ARM 多变体）；3.0 强化 SMPng 在嵌入式与服务器场景的可用性

**史料**：NetBSD 2.1/3.0 Release Notes；NetBSD Foundation 2005-2007 年度报告；tech-kern 邮件列表稳定化讨论；netbsd.db netbsd-src 仓库 commit 证据（"Add configurations for the NetBSD 2.1 release" commit_hash 见 netbsd-src 2005-10-22；"Welcome to NetBSD 3.0 release." commit 2005-12-18；"Add that NetBSD 2.0 was released on December 09, 2004" commit 2005-03-12）；netbsd.db 查询 L1.1.1 显示：netbsd-src 2005 年 commit_count = 30,344（2.1/3.0 双发布年），2006 年 = 30,561（较 2005 年微增 0.7%），2007 年 = 28,670（较 2006 年下降 6.2%），反映 2.x-3.x 时期社区投入趋于稳定但增长乏力；netbsd.db 查询 L2.3.1.smp 显示：netbsd-src 2005 年 SMP 相关 commit = 15，2006 年 = 8（较 2005 年下降 46.7%），2007 年 = 38（较 2006 年增长 375.0%，2.x-3.x 时期 SMP 峰值），反映 SMP 工作在 2007 年有明显集中投入 ［A］

**史观**：技术选择的代价，多平台扩展付出维护成本，但巩固了 "of course it runs NetBSD" 的品牌定位

**辨析**：经 netbsd.db 验证，NetBSD 3.0 发布日期为 2005.12.18（"Welcome to NetBSD 3.0 release." commit author_date = 2005-12-18T14:11:21Z），原大纲误标为 2006 年已修正；2.1 与 3.0 的实质差异需对照 Release Notes 区分，部分叙事将二者混为一谈。L1.1.1 查询的 commit 量数据存在 GitHub 镜像滞后风险——netbsd-src 为 GitHub 镜像（主仓为 Mercurial **hg.NetBSD.org**），2005-2007 年 commit 量可能不完整；2007 年 SMP commit 峰值（38）需对照 tech-smp 邮件列表核验是否有特定 SMP 项目集中投入（如 SMPng 后续优化或新调度器工作），commit 量峰值不等于技术成熟度峰值；L2.3.1.smp 查询基于 message_subject LIKE 匹配，38 这组数字是 SMP 相关 commit 的下限，实际涉及 SMP 的 commit 可能更多
