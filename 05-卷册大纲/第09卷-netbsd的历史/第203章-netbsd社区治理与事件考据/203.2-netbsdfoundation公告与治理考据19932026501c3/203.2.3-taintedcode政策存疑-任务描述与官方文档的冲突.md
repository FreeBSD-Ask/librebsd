# 203.2.3 Tainted Code 政策存疑——任务描述与官方文档的冲突

**要点**：**任务描述提及的“NetBSD Foundation Tainted Code 政策（2024-05）”在 NetBSD 官方未找到对应文件**——NetBSD Foundation Policies 目录（**<https://www.netbsd.org/foundation/policies/>**）仅有 4 件政策文件（Donation Policy 2003-07-15、Reimbursement Policy 2018-05-02、application-procedure、membership-app），无任何名为“Tainted Code”的政策；WebSearch 检索“NetBSD Foundation ‘tainted’ code policy GPL license 2024”与“NetBSD Foundation Tainted Code policy 2024 announcement”均未返回 NetBSD 官方相关结果；任务描述中的“2024-05 Tainted Code 政策”可能系与其他 BSD 项目的政策混淆（如 FreeBSD 的 GPL 软件移除工程、OpenBSD 的 license audit 政策），或为任务描述的误信息［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］；** 考据原则**：穷尽 NetBSD 官方公开渠道后未找到对应文件，保留存疑状态，不得强行采信低质量来源补全

**史料**：NetBSD Foundation Policies 目录（**<https://www.netbsd.org/foundation/policies/>**，访问日期 2026-07-23）仅列出 4 件政策文件——`20030715-donations.txt`（Donation Policy，2003-07-15）、`20180502-reimbursement.txt`（Reimbursement Policy，2018-05-02）、`application-procedure.html/.xml`（New NetBSD developer application procedure）、`membership-app.txt`；WebSearch 检索结果（未返回 NetBSD 官方相关结果）；考据记录 20260723_announcements-netbsd.md §A.4 第 18 条、§ 交叉验证方法-三 -3、§ 存疑判定依据-二 -1 ［A］

**史观**：0 信任原则：Tainted Code 政策存疑是 0 信任原则在政策考据中的实践——不得因任务描述提及即直接采信，须以官方文档为准；穷尽考据后仍无法确证的，保留存疑状态，不强行采信低质量来源补全
