# 206.6.3 容器支持不足的抱怨

**要点**：NetBSD 缺乏原生容器能力（无 cgroups、namespaces 等价物），用户在 NetBSD 上无法直接运行 Docker；用户在邮件列表与论坛抱怨“Docker/容器支持不足”；NetBSD 的 jail（移植自 FreeBSD）功能有限；pkgsrc 在 Docker 中的存在感微弱

**史料**：current-users 邮件列表抱怨帖；NetBSD jail 文档；pkgsrc Docker Hub 文档 ［A］

**史观**：商业与社区的张力：Linux 容器生态凭借商业赞助主导市场，NetBSD 难以跟进

**辨析**：NetBSD jail 与 FreeBSD jail 的关系需考据——NetBSD 是否完整移植 FreeBSD jail 功能需对照源码核验；用户抱怨的代表性需考据

**文献**：current-users 邮件列表；NetBSD jail 文档；pkgsrc Docker Hub 文档 ［A］
