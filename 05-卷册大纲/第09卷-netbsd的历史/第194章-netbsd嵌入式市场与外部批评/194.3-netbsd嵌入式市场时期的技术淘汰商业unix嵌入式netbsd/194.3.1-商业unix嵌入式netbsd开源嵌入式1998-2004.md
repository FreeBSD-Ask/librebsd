# 194.3.1 商业 UNIX 嵌入式 → NetBSD 开源嵌入式（1998-2004）

**要点**：1990 年代嵌入式市场由商业 UNIX（如 QNX、VxWorks、pSOS、LynxOS）与商业 BSD（如 BSD/OS）主导，许可证费用高昂；NetBSD 凭借 BSD 许可证与可移植性优势进入嵌入式市场，1998-2004 年间在 Dreamcast、Zaurus、Cobalt Qube 等设备部署；从商业 UNIX 嵌入式到 NetBSD 开源嵌入式的 “淘汰” 降低嵌入式设备开发成本，但 NetBSD 缺乏商业支持体系

**史料**：NetBSD 嵌入式部署列表（www.netbsd.org/gallery/in-where.html）；tech-embed 邮件列表 1998-2004；Dreamcast/Zaurus/Cobalt Qube 部署档案；BSD/OS 商业模式衰退记录；netbsd.duckdb 查询 L3.2.1 显示：1993-2004 年间（即 NetBSD 1.x 嵌入式市场拓展期）4 大 BSD src 仓库的商业实体 commit 占比 commercial_pct 全部为 0.00%（1998 年 commercial_commits = 0/total = 113,492，2000 年 = 0/195,667，2002 年 = 0/264,813，2004 年 = 0/280,209；〔存疑：上述 total 值与 4 库 src 口径复算值 47,333/94,116/122,394/150,661 存在差异，查询口径未标注，待复核〕），2005 年方首次出现非零商业实体 commit（commercial_commits = 153/total = 267,087，约 0.057%），反映 “1998-2004 年 NetBSD 嵌入式市场商用部署” 在代码层面前期主要表现为厂商内部使用而非回流上游，BSD 许可证不强制回馈的特性使嵌入式厂商贡献长期为零；netbsd.duckdb 查询 L3.3.1 显示：4 大 BSD src 仓库 committer_date 时区分布前 5 为 -07:00（788,356 commit/17,719 贡献者）、+02:00（426,606/16,727）、-08:00（381,184/11,405）、+01:00（380,019/15,941）、-04:00（181,933/9,386），反映 BSD 贡献者主要集中在北美（-07/-08/-04/-05 时区，对应美国/加拿大）与欧洲（+01/+02 时区，对应西欧/中欧），与嵌入式厂商主要分布（北美/日本/欧洲）的地理格局吻合〔存疑：库内 committer_date 后缀实查全为 Z（UTC），且前 5 时区计数合计超出库总量，该时区分布数据来源待核对〕；统计结论 [C-04]: netbsd-src 仓库总 commit 数 773,683（截至 2026-07-27 查询），为 4 大 BSD src 仓库中 commit 累计最高者，本章时期（1998-2004）的 commit 活动构成此总量的早期部分；统计结论 [C-09]: netbsd-src 月度 commit 量 Mann-Kendall 趋势检验呈显著下降趋势（Sen's slope=−7.27/月，p<0.001，95% CI [−8.15, −6.42]），本章时期（1998-2004）处于该长期下降趋势的中段，反映 NetBSD 在嵌入式市场拓展期主仓开发活跃度的结构性收敛 ［A］

**史观**：总纲第 13 条——法律与道德是利益分配〔存疑：重挂待复核〕：NetBSD 开源嵌入式与商业 UNIX 嵌入式的张力体现商业-社区张力；总纲第 13 条——法律与道德是利益分配：BSD 许可证允许商业使用而不强制回馈，塑造 NetBSD 嵌入式市场模式

**辨析**：NetBSD 在嵌入式市场的具体部署数量缺乏权威统计——需对照厂商产品文档与 firmware 拆解核验；BSD/OS 衰退的具体时间需对照 BSDi 与 Wind River 收购档案核验；L3.2.1 查询的商业实体识别基于固定邮箱域名列表（Netflix/Juniper/NetApp/EMC/Google/Apple/Microsoft 等），1993-2004 年 commercial_pct = 0.00% 反映此时期 BSD src 仓库无上述大公司邮箱域名的 commit，但嵌入式厂商（如 Dreamcast 的 Sega、Cobalt 的 Sun/Cobalt Networks、Zaurus 的 Sharp）的工程师可能使用个人邮箱或公司未列入识别列表的邮箱提交，故 0.00% 不等于 “无商业参与”，仅反映 “无可识别大公司邮箱 commit”；L3.3.1 查询基于 committer_date 时区，但 GitHub 镜像 committer_date 存在被同步重写的风险（如 netbsd-src GitHub 镜像 committer_date 异常），故时区分布应与 author_date 时区交叉验证；时区不等于地理位置，远程办公者可能用时区不反映实际所在地。统计结论 [C-09] 局限性继承：Mann-Kendall 趋势检验 p < 0.001 显著仅反映 netbsd-src 月度 commit 量存在统计学显著的下降趋势，不等于该下降趋势在 1998-2004 年本章时期内单调递减——Sen's slope = −7.27/月是全期（1993-2026）平均斜率，本章时期内年度 commit 量可能存在波动（如 2000 年与 2002 年的峰值），须结合 L1.1.1 年度 commit 量数据交叉验证；趋势检验不区分 “开发衰退” 与 “开发模式转型”（如向 Mercurial 迁移的过渡期影响），下降原因须结合 commit message 主题词与文件路径分析
