# 182.1 NetBSD 2.0 SMP 架构实现（2003-2004）

**NetBSD 2.x-3.x 版本发布时间线**：

| 版本 | 发布日期 | 关键特性 |
| --- | --- | --- |
| NetBSD 2.0 | **2004.12.09** | SMPng 移植、细粒度锁机制、逐步替换 Giant Lock |
| NetBSD 2.1 | **2005.11.14** | 稳定化、AMD64 与 ARM 多变体支持扩展 |
| NetBSD 3.0 | **2005.12.18** | SMPng 在嵌入式与服务器场景可用性强化 |

- 要点：NetBSD 2.0 分支（约 2003 年底切出）引入基于 FreeBSD SMPng 移植的细粒度锁机制，逐步替换 4.x 时代的 Giant Lock；2.0 正式发布于 2004.12，标志 NetBSD 进入真正的 SMP 时代
- 史料：NetBSD 2.0 Release Notes；tech-smp 邮件列表存档；Jason Thorpe、Frank van der Linden 等 SMPng 移植 commit 日志；FreeBSD SMPng 设计文档对照；netbsd.db netbsd-src 仓库 commit 证据（“Add that NetBSD 2.0 was released on December 09, 2004” commit author_date = 2005-03-12T15:07:56Z，明确记载 2.0 发布日期为 2004-12-09）；netbsd.db 查询 L1.1.1 显示：netbsd-src 2003 年 commit_count = 50,546，2004 年 = 37,918（2.0 发布年，较 2003 年下降 25.0%），反映 2.0 开发周期内社区投入收缩；netbsd.db 查询 L2.3.1.smp 显示：netbsd-src 2003 年 SMP 相关 commit 数据缺失（查询范围起自 2005），2005 年 = 15，反映 2.x 时期 SMP commit 量已开始有量化记录；统计结论 [C-04]: netbsd-src 仓库总 commit 数 773,683（截至 2026-07-27 查询），为 4 大 BSD src 仓库中 commit 累计最高者，本章时期（2003-2008）的 commit 活动构成此总量的中段 ［A］
- 史观：组织结构塑造技术路径，NetBSD 选择从 FreeBSD 移植 SMPng 而非自研，反映两项目间的代码共享传统；统计结论印证：C-04（netbsd-src 总 commit 数 773,683 为 4 BSD src 仓库最高）反映 NetBSD 在本章时期（2003-2008）虽 commit 量逐年下降，但作为 4 BSD 中最早建立的主仓，累计 commit 量仍居首位，0 信任原则适用：高累计量反映历史工程投入沉淀，不等于本章时期开发活跃度最高
- 辨析：经 netbsd.db 验证，NetBSD 2.0 发布日期为 2004.12.09（commit message 明确记载 “NetBSD 2.0 was released on December 09, 2004”）；SMPng 移植的具体完成度需考据，2.0 是否已完全移除 Giant Lock 需对照源码核验。L1.1.1 查询的 commit 量数据存在 GitHub 镜像滞后风险——netbsd-src 为 GitHub 镜像（主仓为 Mercurial **hg.NetBSD.org**），2003-2004 年 commit 量可能不完整；2004 年 commit 量较 2003 年下降 25.0% 反映 2.0 开发后期社区投入收缩，但 commit 量下降不等于技术产出下降——SMPng 移植涉及大规模代码合并，单次 commit 涉及多文件，commit 数量与工程进度不成线性关系；L2.3.1.smp 查询基于 message_subject LIKE ‘%SMP%’ 等关键词匹配（大小写敏感），15/15 这组数字是 SMP 相关 commit 的下限，实际涉及 SMPng 移植的 commit 可能更多（如 subject 中含 “lock” “mutex” “runqueue” “preemption” “work stealing” 等关键词但未含 “SMP” 的 commit 未被统计）。统计结论 [C-04] 局限性继承：netbsd-src 总 commit 数 773,683 为全期累计值（1993-2026），本章时期（2003-2008）的 commit 量仅为此总量的中段部分，累计值不反映本章时期开发活跃度——本章时期 netbsd-src 年度 commit 量从 50,546（2003）降至 26,543（2008），累计降幅 47.5%，须结合 L1.1.1 年度 commit 量数据交叉验证
