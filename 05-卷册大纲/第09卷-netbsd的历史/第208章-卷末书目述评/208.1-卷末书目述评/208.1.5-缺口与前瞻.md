# 208.1.5 缺口与前瞻

本卷史料存在三类缺口，需在未来研究中补全。

档案缺口：其一，**netbsd.duckdb** GitHub 镜像不含 NetBSD release tag。NetBSD 主仓库 2019-2020 年迁至 Mercurial（**<https://anonhg.netbsd.org/>**），GitHub 镜像不携带 Mercurial 主仓的 release tag，使 NetBSD 各正式版本发布日期无法通过 tags 表直接验证，须经 NetBSD 官方 formal.html 页面与 Press Releases 交叉印证。其二，NetBSD Foundation 内部决议与 **<core@NetBSD.ORG>** 私有列表存档未公开访问。1994 年 Theo de Raadt 被逐事件的 Core Team 内部投票记录、2019-2020 年 CVS-Mercurial 迁移决策过程、2024 年 AI 生成代码禁令加入的内部讨论等关键事件内部决策过程难以从内部视角重构。其三，CVS-to-Mercurial 仓库迁移精确完成日期未能从 netbsd-announce 一手来源取得。考据记录 20260723_announcements-netbsd.md § 存疑判定依据-二 -3 留痕考据过程——已逐月抓取 netbsd-announce 2019/02-2020/10 各月存档，均未发现明确的“CVS-to-Mercurial 迁移完成公告”，迁移公告可能发布于 tech-repository、source-changes 或 core 等其他邮件列表。其四，Kantee 博士论文原始 URL **<http://lib.tkk.fi/Diss/2012/isbn9789526049175/isbn9789526049175.pdf>** 因 Helsinki University of Technology 2010 年并入 Aalto University 而存在迁移至 **aaltodoc.aalto.fi** 的可能，2026-07-23 直接访问尝试超时，已通过互联网档案馆存档（2014-12-06）补救，待后续批次补充 Aaltodoc 现行 URL ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］。

方法论缺口：其一，缺乏 NetBSD 跨架构移植的量化分析。**netbsd.duckdb** netbsd-src 仓库 773,687 条 commit 跨越 50+ 移植端口，但各移植端口的 commit 量、活跃度、维护者网络等量化指标缺乏系统分析。未来可借助 **netbsd.duckdb** 进行各移植端口的 commit 量年度变化、维护者贡献分布、跨平台代码共享率等量化分析，重构 NetBSD 跨架构移植的工程演化路径。其二，缺乏 pkgsrc 与 FreeBSD Ports、OpenBSD Ports、Linux RPM/DEB 的跨平台软件包管理框架系统比较研究。Sonnenberger 2006 年 pkg_install 论文与 Campbell 2015 年 cross-compilation 论文均聚焦 pkgsrc 内部设计，缺乏与同期 FreeBSD Ports、OpenBSD Ports、Linux RPM/DEB 的横向比较。其三，缺乏 rump 内核与 Unikernel 生态（MirageOS、OSv）的引用关系核实。Kantee 博士论文被 NetBSD 官方 wiki 引用为 rump 内核理论文献的权威出处，但 MirageOS、OSv 等 Unikernel 项目对 rump kernels 的引用关系未直接核实，BSD 许可证宽松性如何具体促成 rump kernels 进入 Unikernel 研究谱系仍需对照各 Unikernel 项目文档考据。其四，缺乏中文硕博学位论文的 NetBSD 主题检索。中文硕博学位论文待 Task 13.1 单独检索（CNKI/万方/维普），本批次未覆盖。

史学缺口：其一，Theo de Raadt 视角的一手叙述稀缺。de Raadt 本人未在 NetBSD 渠道公开回应被逐事件，OpenBSD FAQ 官方叙事对被逐事件本身多保持沉默，使事件呈现 Core Team 单方面叙事偏向。未来需采集 de Raadt 在 OpenBSD 渠道、BSD Now 播客、CHM 口述史等来源的间接自述。其二，agc（Alistair Crooks）视角的 pkgsrc 早期设计自述未进入公开档案。**netbsd.duckdb** agc 1997-06-05 commit 仅记载“Initial import of FreeBSD packaging tool”，未明确陈述跨平台设计意图，pkgsrc 跨平台框架的形成是否为 agc 个人前瞻性设计抑或为 thorpej 等后续贡献者渐进重构的集体成果，仍需 agc 个人访谈或自述补全。其三，NetBSD 在嵌入式产业的应用案例缺乏系统性整理。IIJ SEIL CPE 路由器（SAITOH 与 Suenaga 2014 AsiaBSDCon 论文）、瘦客户端（Borrill 2009 BSDCan）、NetManager（Borrill 2025 euroBSDcon）等产业应用案例散见于各会议论文，缺乏跨案例的系统性整理与比较研究。其四，NetBSD CVS-Mercurial-Git 工具链迁移的曲折路径（Sonnenberger 2017 评估 →2018 Mercurial 试点 →Siegert 2025 Git 落地）缺乏与 FreeBSD SVN→Git 迁移（2020-12）、DragonFly BSD Git、OpenBSD CVS 等同期 BSD 项目工具链迁移的横向比较研究。

未来研究方向：Aaltodoc 现行 URL 补充与 Kantee 博士论文全文检索，**netbsd.duckdb** NetBSD 各移植端口 commit 量化分析，pkgsrc 与 FreeBSD/OpenBSD Ports、Linux RPM/DEB 跨平台软件包管理框架系统比较研究，rump 内核与 Unikernel 生态引用关系核实，中文硕博学位论文 CNKI/万方/维普检索，agc 个人访谈与 pkgsrc 早期设计自述采集，de Raadt 在 OpenBSD 渠道与 BSD Now 播客等来源的间接自述整理，NetBSD 嵌入式产业应用案例跨案例系统性整理，BSD 项目工具链迁移横向比较研究。这些方向将有助于补全本卷史料的档案缺口、方法论缺口与史学缺口，使第九卷的叙事从“会议本位”文献主导转向档案证据、当事人叙述与量化数据库的批判性三方互证。
