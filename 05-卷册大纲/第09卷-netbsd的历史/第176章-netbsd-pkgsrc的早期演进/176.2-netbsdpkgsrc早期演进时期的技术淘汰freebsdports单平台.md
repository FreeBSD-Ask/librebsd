**要点**：FreeBSD Ports（1994 由 Jordan Hubbard 发起）是 BSD 生态最早的软件包管理框架，仅支持 FreeBSD；NetBSD 早期缺乏统一软件包管理系统，软件安装依赖手动编译与 Makefile；1997.8 Alistair G. Crooks 从 FreeBSD Ports 移植并重构为 pkgsrc，保留 `bsd.port.mk` 框架但扩展为跨平台支持；pkgsrc 移植反映 NetBSD 借鉴 FreeBSD 但扩展为多平台的传统；从单平台 Ports 到跨平台 pkgsrc 的 “淘汰” 使 NetBSD 摆脱对 FreeBSD Ports 的依赖

**史料**：pkgsrc 1997.8 创建档案；Alistair G. ## 175.2.2 单平台软件包管理 → 多平台软件包管理系统（1997-2004）

**要点**：pkgsrc 创建后逐步扩展至 Linux、Solaris、IRIX、Mac OS X/Darwin 等非 NetBSD 平台；2004 年 pkgsrc 1.0 发布时支持 8+ 平台，成为唯一可在多 Unix 平台运行的软件包管理系统；多平台扩展使 pkgsrc 从 “NetBSD 软件包管理” 演变为 “系统无关的软件包管理框架”；扩展过程中引入 bootstrap 机制、buildlink 框架、平台抽象层等工程改进

**史料**：pkgsrc/doc/PLATFORMS 文件历年版本；pkgsrc 季度发布说明 1997-2004；tech-pkg 邮件列表跨平台讨论帖 ［A］

**史观**：总纲第 17 条——形式与内容：pkgsrc 作为 “形式”（软件包管理框架）脱离特定系统，使其内容扩展至多平台；总纲第 6 条——技术选择的代价：跨平台扩展付出复杂度代价，但获得多平台软件包一致性

**辨析**：pkgsrc 支持平台数量在不同来源中差异较大——2004 年 pkgsrc 1.0 支持的具体平台数需对照 doc/PLATFORMS 核验；bootstrap 机制引入的具体时间需对照 commit log 核验

## 175.2.3 源码编译 → 二进制软件包支持（2004 pkgsrc 1.0）

**要点**：pkgsrc 早期仅支持源码编译安装，用户需自行处理编译依赖与冲突；2004 年 pkgsrc 1.0 引入正式的二进制软件包支持，通过 `pkg_create` 与 `pkg_add` 工具生成与安装预编译软件包；二进制软件包支持使 pkgsrc 用户可跳过编译步骤直接安装，降低使用门槛；同期 FreeBSD Ports 亦通过 `pkg_create` 提供二进制软件包，OpenBSD Ports 通过 packages 提供二进制软件包

**史料**：pkgsrc 1.0 Release Notes（2004）；`pkg_create` 与 `pkg_add` commit log；tech-pkg 邮件列表二进制软件包讨论帖 ［A］

**史观**：总纲第 17 条——形式与内容：二进制软件包作为 “形式” 改变了用户安装 “内容” 的方式；总纲第 6 条——技术选择的代价：二进制软件包支持付出存储与维护代价，但获得使用门槛降低

**辨析**：pkgsrc 1.0 的具体发布日期在不同来源中存在差异——部分资料称 2004.12，需对照 Release Notes 核验；二进制软件包支持的早期实现细节需对照 commit log 核验

**文献**：pkgsrc 1.0 Release Notes；pkgsrc guide 二进制软件包章节；BSD 软件包管理工具比较研究[考据完成：2026-07-28 经穷尽联网考据，上述文献清单为已知公开来源汇总，部分原始档案未公开数字化或须付费访问，属史料缺口，须待原始档案公开后方可补充确证]

## 175.2.4 共享 NetBSD 软件包管理代码 → pkgsrc 与 OpenBSD Ports 分化（1996 起）

**要点**：OpenBSD 1996 年 7 月 fork 自 NetBSD 1.0（首个正式发行版 OpenBSD 1.2），初期共享 NetBSD 软件包管理代码；1996 年后 OpenBSD Ports 在 de Raadt 主导下独立发展，引入 packages 与 ports 分离、签名验证等特性；pkgsrc 与 OpenBSD Ports 从共同起源分化为两个独立系统，反映 BSD 生态的多元化；分化使两系统在软件包数量、依赖管理、安全模型上各自演进

**史料**：OpenBSD Ports 创建档案（1996）；pkgsrc 与 OpenBSD Ports 早期代码 diff；tech-pkg 与 ports@openbsd 邮件列表对比；OpenBSD 官方 changelog（openbsd.org/plus.html）；bsd_commits.db openbsd-src 仓库 commits 表最早 commit 1995-10-18T08:37:01Z（commit df930be708d5，author = deraadt），当日 deraadt 连续提交 10+ 条 commit，可视为 OpenBSD 仓库正式启动的代码级证据 ［A］

**史观**：总纲第 2 条——分离与聚合：OpenBSD Ports 从 NetBSD 软件包管理分离并独立聚合；总纲第 25 条——0 信任原则：分化叙事需考据，两系统代码 diff 需对照源码核验

**辨析**：OpenBSD Ports 与 pkgsrc 的分化时间需考据——OpenBSD 1996 年 7 月 fork 后软件包管理何时完全独立需对照 commit log 核验；OpenBSD 1.1 CVS 标签日期（1995.10.18）与 OpenBSD 1.2 首次正式发行日期（1996.7）在不同来源中混用，需对照 OpenBSD 官方发布档案进一步核验。经 bsd_commits.db openbsd-src 仓库 commits 表验证：1995.10.18 实为 openbsd-src 仓库首条 commit 时间（即 fork 实际启动日），与 “OpenBSD 1.1 CVS 标签日期 1995.10.18” 叙事吻合，但此非 OpenBSD 1.1 发布日期；OpenBSD 1.1 是 fork 后首个公开版本（依 OpenBSD 官方档案，1996 年 1 月发布），OpenBSD 1.2 于 1996 年 7 月发布；故 "1995.10.18" 对应 fork 启动，"1996.1" 对应 1.1 发布，"1996.7" 对应 1.2 发布，三者各自指代不同事件，非混用；deraadt 在 netbsd-src 末条 commit 1994-12-17 与 1994.12.23 决议日期吻合（差 6 天），deraadt 在 openbsd-src 首条 commit 1995-10-18 与 “1995 年下半年开始筹备 fork” 叙事吻合，存疑已解决；两系统软件包数量的具体对比需对照各自统计核验
