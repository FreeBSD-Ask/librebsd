## 181.1.3 与 FreeBSD bhyve 与 Linux KVM 的比较

**要点**：FreeBSD bhyve（2014 起）由 Grehan 等设计，强调与 FreeBSD 内核集成；Linux KVM（2007 起）由 Qumranet 设计，后被 Red Hat 推广；NVMM（2018 起）由 Villard 设计，强调安全性与简洁性；三者在性能、功能、生态上各有侧重

**史料**：FreeBSD bhyve 文档；Linux KVM 文档；NVMM 设计文档［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］〔L3 官方文档与公告〕

**史观**：专题语（不设条号）——技术选择即政治选择：bhyve 选择 FreeBSD 集成，KVM 选择 Linux 主线，NVMM 选择 NetBSD 安全风格——选择即政治

**辨析**：三者性能对比缺乏权威基准——需对照同硬件同 guest OS 测试核验；NVMM 与 bhyve/KVM 的功能差异（如 GPU passthrough、SR-IOV）需考据
