# 181.3 与同时期操作系统的比较：NetBSD 8.0 与 64 位 ARM 虚拟化时期（2018）——与 FreeBSD 11.x/12、OpenBSD 6.3、Linux 4.1x、Windows 10/Server 2016 的对照

**2018 年同期操作系统 ARM64 虚拟化对照表**：

| 操作系统 | 版本（2018） | ARM64 支持 | 虚拟化 | 与 NetBSD 8.0 比较 |
| --- | --- | --- | --- | --- |
| NetBSD 8.0 | 8.0（**2018.7**） | aarch64 引入 | NVMM（晚于 8.0 发布） | — |
| FreeBSD | 11.2/12.0（**2018.12**） | ARM64 | bhyve（x86 虚拟化领先） | NetBSD ARM64 虚拟化早，FreeBSD bhyve 偏 x86 |
| OpenBSD | 6.3（**2018.4**） | ARM64 初步 | 有限 | OpenBSD 安全机制（pledge/unveil）领先，虚拟化有限 |
| Linux | 4.1x | ARM64 成熟 | KVM（含 ARM64） | Linux KVM 在 ARM64 服务器市场领先 |
| Windows | 10/Server 2016 | ARM64 受限 | Hyper-V（x86 企业） | Hyper-V 守企业 x86，NetBSD 在开源 ARM64 利基 |

## 181.3.1 FreeBSD 11.x/12（2018）

**要点**：FreeBSD 在 NetBSD 8.0 同期为 11.2/12.0（2018），以 bhyve 虚拟化（x86）、ARM64 支持与 ZFS 成熟见长；与 NetBSD 8.0 的“64 位 ARM 虚拟化”对照——FreeBSD 的 bhyve 在 x86 虚拟化领先，NetBSD 8.0 主打 ARM64 虚拟化与 SMP 扩展。

**史料**：FreeBSD 11.x/12 发布说明（2018）；NetBSD 8.0 发布说明（2018.7）［A］

**史观**：BSD 谱系：FreeBSD 与 NetBSD 同期推进虚拟化与现代硬件，体现家族并行创新。

**辨析**：NetBSD 8.0 的 ARM64 虚拟化与其 SMP 改进同步，FreeBSD 的 bhyve 偏 x86；二者虚拟化路线不同。

**文献**：FreeBSD. 11.x/12 Release Notes [EB/OL]；NetBSD. 8.0 Release Notes [EB/OL]. ［A］

## 181.3.2 OpenBSD 6.3（2018）

**要点**：OpenBSD 在 NetBSD 8.0 同期为 6.3（2018.4），以安全机制（pledge/unveil 演进）与 ARM64 初步支持著称；与 NetBSD 8.0 的“ARM64 虚拟化”分野——OpenBSD 6.3 的 ARM64 支持刚起步，专注安全而非虚拟化。

**史料**：OpenBSD 6.3 发布说明 ［A］

**史观**：BSD 谱系：OpenBSD 与 NetBSD 同期演进，安全 vs 虚拟化目标分化。

**辨析**：OpenBSD 6.3 的虚拟化支持有限，但其安全机制为家族提供借鉴。

**文献**：OpenBSD. 6.3 Release Notes [Z]. ［A］

## 181.3.3 Linux 4.1x（2018）

**要点**：Linux 4.1x（2018）在 NetBSD 8.0 同期以 KVM 虚拟化（含 ARM64）、容器（cgroups v2 进展）与 ARM64 生态成熟著称；与 NetBSD 8.0 的 ARM64 虚拟化对照——Linux 的 KVM 在 ARM64 服务器市场领先，NetBSD 8.0 在 SMP 与嵌入式 ARM64 利基立足。

**史料**：Linux 4.1x 发布说明（2018）［B］

**史观**：技术路线分化：Linux KVM 的 ARM64 规模与 NetBSD 8.0 的虚拟化形成落差。

**辨析**：虚拟化“胜负”由生态（云厂商、芯片）决定，非内核技术优劣。

**文献**：Linux Kernel. 4.1x Release Notes [EB/OL]. ［B］

## 181.3.4 Windows 10 / Server 2016（Hyper-V）

**要点**：Microsoft 在 NetBSD 8.0 同期以 Hyper-V（Windows 10/Server 2016）提供 x86 虚拟化，ARM64 上 Windows 10 仍受限；与 NetBSD 8.0 的 ARM64 虚拟化形成对照——Hyper-V 在企业 x86 主导，NetBSD 8.0 在开源 ARM64 虚拟化利基。

**史料**：Microsoft Hyper-V / Server 2016 文档 ［B］

**史观**：技术路线分化：闭源企业虚拟化 vs 开源 ARM64 虚拟化在 2018 形成分割。

**辨析**：Hyper-V 的 ARM64 支持晚于 NetBSD 8.0，且闭源限制审计。

**文献**：Microsoft. Hyper-V Docs [EB/OL].［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］

## 181.3.5 同期 ARM64 虚拟化总览（2018）

**要点**：2018 年 ARM64 虚拟化成竞争点：Linux KVM 在服务器领先，FreeBSD bhyve 偏 x86，NetBSD 8.0 推 ARM64 虚拟化 + SMP，OpenBSD 6.3 安全利基，Windows Hyper-V 守企业 x86；NetBSD 8.0 以“ARM64 虚拟化 + 多核”强化可移植哲学的现代延伸。

**史料**：各系统 2018 虚拟化史料 ［B］

**史观**：BSD 谱系：NetBSD 8.0 与同族 BSD 在虚拟化时代并行创新。

**辨析**：虚拟化市场由云生态主导，NetBSD 8.0 在嵌入式/教育利基具价值。

**文献**：NetBSD. 8.0 Release Notes [EB/OL]；虚拟化生态史料。［B］
