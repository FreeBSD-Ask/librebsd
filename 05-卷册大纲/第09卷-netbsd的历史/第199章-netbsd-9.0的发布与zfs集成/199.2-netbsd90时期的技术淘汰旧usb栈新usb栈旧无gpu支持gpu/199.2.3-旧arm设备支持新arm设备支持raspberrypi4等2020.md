# 199.2.3 旧 ARM 设备支持 → 新 ARM 设备支持（Raspberry Pi 4 等）（2020）

**要点**：NetBSD 9.0（2020.2.14）改进 ARM 设备支持，引入对树莓派 4（Cortex-A72）等新 ARM 设备的初步支持；新 ARM 设备支持由 Jared McNeill 等推动；9.0 让 NetBSD 在 ARM 嵌入式市场保持存在感；旧 ARMv6/v7 设备支持作为分离路径保留，体现“分离与聚合”

**史观**：边缘者贡献：McNeill 作为边缘者贡献，推动 NetBSD 在新 ARM 设备上的支持；分离与聚合：新 ARMv8 设备支持与旧 ARMv6/v7 路径分离聚合

**辨析**：9.0 树莓派 4 支持的实际可用性（性能、外设支持）需对照社区测试报告核验。经 netbsd.duckdb netbsd-src 仓库 commits 表验证：RPI4 移植由 mlelstv（2019.7.28 PCIe 主桥）、skrll（2019.9.27 BCM2838/2711 支持、2019.12.24/25 命名修正与中断处理）、jmcneill（2020.2.22/23 GENET 以太网、UEFI IRQ、根设备适配）三位开发者共同推动，原叙事中“由 Jared McNeill 等推动”中的“等”应明确包含 mlelstv 与 skrll；RPI4 commit 最早可追溯至 2019-07-28（mlelstv PCIe 主桥），早于 9.0 发布 2020.2.14 约 6 个月 17 天，反映 RPI4 移植在 9.0 发布前半年已启动；skrll 2019-12-24 commit"We follow linux mainline and they're using 2711 and not 2838 for RPI4"反映 NetBSD RPI4 命名跟随 Linux mainline 约定（BCM2711 而非 BCM2838），体现 BSD 与 Linux 的代码协同；与 Linux 树莓派 4 支持的对比需考据；树莓派 4 在 9.0 中的具体支持功能（如 USB 3.0、千兆以太网）需考据——jmcneill 2020-02-22 GENET v5 以太网支持 commit 证实千兆以太网支持在 9.0 时期引入；9.0 发布日期 2020.2.14 仍须以 NetBSD 官方公告为准
