# 199.1.2 GPU 支持的改进

**要点**：NetBSD 9.0 引入改进的 GPU 支持，特别是 Intel i915 DRM（Direct Rendering Manager）与 AMDGPU 的初步支持；GPU 支持由 Taylor R Campbell 等推动；9.0 的 GPU 支持仍落后 Linux 数年，但相比 8.0 有显著进步
