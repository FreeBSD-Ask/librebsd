# 187.3 与 Linux 的生态对照

**BSD 四仓库合计 vs Linux commit 量对照（netbsd.duckdb 数据分析 §L7.3.1，四库合计口径）**：

| 年份 | BSD 合计 commit | Linux commit | Linux/BSD 倍数 | 趋势 |
| --- | --- | --- | --- | --- |
| **2008** | 48,242 | 48,825 | **1.01** | 基本持平 |
| **2020** | 36,392（较 2008 年下降 24.6%） | 90,911（较 2008 年增长 86.2%） | **2.50** | Linux 已达 BSD 的 2.5 倍 |
| **2026** | —（2026 年度统计未完结，绝对值缺） | — | **2.67** | Linux 相对 BSD 持续扩张 |

注：倍数列数值为 Linux commit ÷ BSD 四仓库合计 commit（口径不对等，Linux 为单仓库全子系统，见辨析）。

**要点**：Linux 凭借 GPLv2 强制回馈机制与企业投入（Red Hat、IBM、Intel 等）在 2000 年代快速扩张生态；NetBSD 的 BSDL 允许商业闭源 fork 但缺乏企业回馈机制，生态扩张缓慢；（原要点尾部混入的参考文献计量统计 C-41/C-42/C-44 与本节 OS 对照主题无关，已移除，详见**文献计量学分析.md**）

**史料**：Linux Foundation 年度报告；NetBSD Foundation 年度报告；GPL vs BSDL 对比研究；技术新闻媒体的市场份额统计；netbsd.duckdb 数据分析 §L7.3.1 显示：2008 年 BSD（freebsd-src+netbsd-src+openbsd-src+dragonflybsd-src 合计）commit_count = 48,242，Linux（linux-stable 仓库）commit_count = 48,825，BSD/Linux 比例 = 1.01（基本持平）；2020 年 BSD commit_count = 36,392（较 2008 年下降 24.6%），Linux commit_count = 90,911（较 2008 年增长 86.2%），BSD/Linux 比例 = 2.50（Linux 已达 BSD 的 2.5 倍）；2026 年 BSD/Linux 比例 = 2.67，反映 Linux 生态在 2008-2026 年间相对 BSD 持续扩张；［A］

**史观**：总纲第 13 条——法律与道德是利益分配：许可证哲学直接塑造了生态扩张速度——GPLv2 的强制回馈与企业投入使 Linux 生态快速扩张，BSDL 的宽松许可使 BSD 生态扩张缓慢但分流自由；（原史观尾部混入的 C-41/C-42/C-44 文献计量统计与本节主题无关，已移除）

**辨析**：“Linux 击败 BSD” 的叙事需考据，避免事后叙事化，需呈现 1990-2000 年代的具体历史语境。L7.3.1 查询的 BSD commit 量为 freebsd-src+netbsd-src+openbsd-src+dragonflybsd-src 四仓库合计，Linux commit 量为 linux-stable 单仓库，二者口径不完全对等（Linux 单仓库涵盖全部子系统，BSD 四仓库各自独立）；2008 年 BSD/Linux 比例 = 1.01 反映 2008 年前后 BSD 与 Linux 在 commit 量上基本持平，“Linux 击败 BSD” 的叙事在 2008 年时尚不成立，转折点在 2008 年之后；2020 年 BSD/Linux 比例 = 2.50 与 “Linux 凭借 GPLv2 强制回馈机制与企业投入快速扩张生态” 叙事方向一致，但 commit 量比例不等于市场份额比例——Linux 在服务器、移动、嵌入式市场的份额优势远大于 commit 量比例反映的程度；GitHub 镜像滞后风险——四个 BSD 仓库与 linux-stable 均为 GitHub 镜像，2008-2026 年 commit 量可能不完整。统计结论 [C-41] 局限性继承：references 表总数 16,867 条为全库累计值，包含本书全部参考文献（旧口径记 12 卷 157 章，现行口径 19 卷 355 章），本章（第 187 章 OS 比较）的参考文献仅为此总量的一部分，不得以全库总量推断本章文献覆盖度。统计结论 [C-42] 局限性继承：年份提取率 44.42% 受参考文献格式规范性影响——格式不规范的条目（如缺失出版年份的网页、未标注年份的邮件列表存档）无法提取年份，44.42% 是下限而非上限；年份提取率不反映参考文献的时效性（Price 指数 7.34% 反映近 5 年参考文献占比，详见**文献计量学分析.md** Task 22）。统计结论 [C-44] 局限性继承：Top 10% 章节占 28.23% 与 Gini 0.3913 反映参考文献卷章分布的集中度，但 Gini 系数基于 references 表 vol/ch 字段，部分条目 vol/ch 字段为 NULL（须按 file_path 解析），分布特征可能受字段填充率影响；Gini 0.3913 与 4 BSD src 仓库贡献者集中度（0.8158-0.9188）的对比须注意二者度量对象不同（参考文献 vs 贡献者），可比性有限
