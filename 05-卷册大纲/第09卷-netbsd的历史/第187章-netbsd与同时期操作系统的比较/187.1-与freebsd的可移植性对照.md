# 187.1 与 FreeBSD 的可移植性对照

**netbsd-src 占四大 BSD src 仓库合计 commit 比例年度变化（freebsd.duckdb §L1.1.2）**：

| 年份 | netbsd-src commit | 占比 | 阶段特征 |
| --- | --- | --- | --- |
| **1993** | 14,507 | **94.35%** | BSD 阵营绝对主导地位 |
| **1994** | 17,726 | **80.78%** | FreeBSD 独立后份额开始分流 |
| **1995** | 12,163 | **58.88%** | OpenBSD fork 后首年，份额骤降 |
| **1996** | 16,057 | **54.91%** | 占比首次低于 55% |
| **1997** | 27,179 | **60.25%** | 4.x-5.x 时期回升 |
| **1998** | 24,867 | **62.00%** | 稳定增长 |
| **1999** | 38,645 | **66.31%** | 持续增长 |
| **2000** | 53,895 | **70.44%** | 峰值占比 |
| **2001** | 53,991 | **64.91%** | 微幅回调 |
| **2002** | 58,001 | **66.22%** | 稳定区间 |

**要点**：FreeBSD 长期聚焦 i386/amd64 与 ARM64，明确放弃对冷门架构的支持；NetBSD 维护 50+ 移植端口，覆盖冷门架构（VAX、HP300、sun2/sun3 等）；两项目在 1990 年代后逐步形成 “广度 vs 深度” 的分化

**史料**：NetBSD/doc/PLATFORMS 文件；FreeBSD Release Notes 中 platforms supported 章节；tech-platforms 邮件列表讨论；freebsd.duckdb 查询 L1.1.2 显示：netbsd-src 在四大 BSD src 仓库（freebsd-src+netbsd-src+openbsd-src+dragonflybsd-src）合计 commit 中的占比在 1993 年 = 94.35%（14,507 commits），1994 年 = 80.78%（17,726），1995 年 = 58.88%（12,163，OpenBSD fork 后首年），1996 年 = 54.91%（16,057，占比首次低于 55%），1997 年 = 60.25%（27,179），1998 年 = 62.00%（24,867），1999 年 = 66.31%（38,645），2000 年 = 70.44%（53,895），2001 年 = 64.91%（53,991），2002 年 = 66.22%（58,001）；1993-1996 年占比从 94.35% 骤降至 54.91% 反映 FreeBSD 与 OpenBSD 相继独立后 NetBSD 在 BSD 阵营中的相对份额收缩；1997-2002 年占比回升至 60-70% 区间反映 NetBSD 在 4.x-5.x 时期社区投入稳定增长，但始终未恢复 1993 年的绝对主导地位 ［A］

**史观**：总纲第 6 条技术选择的代价，广度与深度的取舍反映社区价值观

**辨析**：FreeBSD 实际支持的平台数量需考据，部分叙事夸大了 FreeBSD 的 “单一平台” 程度。L1.1.2 查询的占比基于四大 BSD src 仓库合计 commit 量，dragonflybsd-src 在 2003 年后才加入，故 1993-2002 年占比实为 freebsd-src+netbsd-src+openbsd-src 三仓库合计；1995 年占比骤降（58.88%）与 OpenBSD fork（1995.10）时序一致，反映 OpenBSD 独立后从 BSD 阵营 commit 总量中分走部分份额；1993 年 94.35% 的高占比反映 NetBSD 在 BSD 阵营中早期主导地位，但此占比基于 commit 量而非市场份额或影响力，commit 量占比不等于技术影响力占比；GitHub 镜像滞后风险——三个 BSD 仓库均为 GitHub 镜像，1993-2002 年 commit 量可能不完整

**文献**：NetBSD/doc/PLATFORMS 文件 [EB/OL]. <https://github.com/NetBSD/src/blob/trunk/doc/PLATFORMS>（原始链接失效，互联网档案馆无存档）；FreeBSD Release Notes 中 platforms supported 章节 [EB/OL]. <https://www.freebsd.org/releases/>；tech-platforms 邮件列表 [EB/OL]. <https://mail-index.netbsd.org/tech-platforms/>；netbsd.duckdb 数据分析·宏观趋势统计.md §L1.1.2（netbsd-src 占四大 BSD src 仓库合计 commit 比例 1993-2002） ［A］
