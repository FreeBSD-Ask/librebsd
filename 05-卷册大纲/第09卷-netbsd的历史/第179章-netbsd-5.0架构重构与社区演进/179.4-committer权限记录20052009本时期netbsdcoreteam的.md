# 179.4 committer 权限记录（2005-2009）——本时期 NetBSD Core Team 的 committer 权限变更记录，包括自动退休、自愿退役与新 committer 加入

## 179.4.1 自动退休与自愿退役记录

**要点**：NetBSD 实行“自动退休”制度——committer 18 个月无 commit 即自动失去权限，但可申请恢复；2005-2009 年间因社区规模小与商业化支撑衰退（Wasabi 倒闭），自动退休人数显著多于新加入；部分核心 committer 如 Luke Mewburn（卢克·缪伯恩）、Alistair Crooks 在此期间逐步淡出

**史料**：NetBSD Core Team 决议记录；NetBSD CVS commit log；core 邮件列表存档 ［A］

**史观**：总纲第 1 条——偶然性改写历史：Wasabi 衰退与核心 committer 退休是具体的人的具体决定，但连锁影响 NetBSD 工程进展

**辨析**：自动退休的具体人数在不同来源中差异较大——Core Team 年度报告与 CVS commit 统计可能略有出入；Mewburn 与 Crooks 淡出的具体时间点需对照 commit 记录核验

**文献**：NetBSD Core Team 决议记录；CVS commit log 统计；core 邮件列表年度总结 ［A］

## 179.4.2 新 committer 加入流程

**要点**：新 committer 加入流程为现有 committer 提名 →Core Team 审核 → 邮件列表公示 → 授予 commit 权限；2005-2009 年间新 committer 数量相对较少，部分来自编程之夏学生转为正式 committer；流程的“保守性”反映 NetBSD 社区稳健工程文化

**史料**：NetBSD committer 提名与审核邮件；Core Team 决议记录；编程之夏学生转 committer 记录 ［A］

**史观**：组织结构塑造技术路径：committer 加入流程作为组织结构决定了 NetBSD 开发者群体的演进路径

**辨析**：2005-2009 年间新 committer 总数在不同来源中存在差异——Core Team 报告与 CVS author 列表可能略有出入

**文献**：NetBSD Core Team 决议记录；core 邮件列表新 committer 公示；committer 列表变更记录 ［A］

## 179.4.3 与 FreeBSD committer 权限模型的比较

**要点**：FreeBSD 与 NetBSD 都有“自动退休”制度，但 FreeBSD 因商业赞助较多（Juniper、NetApp、Yahoo 等）核心 committer 活跃度更高；FreeBSD 的 committer 分层（src/doc/ports）更细致，NetBSD 较为扁平；FreeBSD Core Team 选举制度更正式，NetBSD Core Team 由现有成员协商产生

**史料**：FreeBSD Committer‘s Guide；NetBSD developer’s guide；两项目 Core Team 章程 ［A］

**史观**：商业与社区的张力：FreeBSD 商业赞助维持 committer 活跃度，NetBSD 缺乏商业支撑导致 committer 流失

**辨析**：两项目 committer 权限模型的“严格程度”对比缺乏权威评估——需对照实际权限变更案例核验；FreeBSD Core Team 选举制度在 2005-2009 年间是否改革需对照章程版本

**文献**：FreeBSD Committer‘s Guide；NetBSD developer’s guide；两项目 Core Team 章程 ［A］

## 179.4.4 Core Team 决议与邮件记录考据

**要点**：NetBSD Core Team 决议记录是研究 2005-2009 年社区治理的核心史料；core 邮件列表存档（部分公开，部分私密）；Core Team 决议涉及新 committer 加入、自动退休、技术路线争议等；考据需对照 core 邮件列表与公开宣布

**史料**：NetBSD core 邮件列表存档；Core Team 决议记录（公开部分）；Core Team 公开宣布 ［A］

**史观**：0 信任原则：Core Team 决议记录需考据——私密邮件部分难以公开获取，需对照公开宣布与 CVS commit 推断

**辨析**：Core Team 决议的私密性使考据困难——部分决议未公开宣布，需对照 CVS commit 的 author 变化推断；Core Team 成员名单在不同来源中可能略有出入

**文献**：NetBSD core 邮件列表；Core Team 决议记录；NetBSD Foundation 年度报告 ［A］
