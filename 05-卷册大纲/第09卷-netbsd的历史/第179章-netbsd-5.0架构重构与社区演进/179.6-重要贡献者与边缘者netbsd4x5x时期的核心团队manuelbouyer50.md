## 179.6.1 Bouyer/Doran 的 5.0 贡献

**要点**：Manuel Bouyer 作为 NetBSD 5.0 release engineer 负责发布协调与集成测试；Andrew Doran 设计并实现新 SMP 调度器与多核改进；两人在 2007-2009 年间构成 NetBSD 5.0 工程核心；Bouyer 同时是 FreeBSD 5.x libpthread 相关代码的贡献者

**史料**：NetBSD 5.0 Release Notes release engineer 致谢；CVS commit log 中 bouyer 与 ad 的提交；tech-kern 邮件列表设计与讨论帖 ［A］

**史观**：总纲第 10 条——边缘者贡献：Bouyer 与 Doran 作为非美国核心开发者，体现 NetBSD 国际化的边缘者贡献

**辨析**：Bouyer 与 Doran 的具体贡献划分需对照 CVS commit log 核验——部分大型 commit 由两人合作，难以单一归属；Doran 的剑桥背景与 NetBSD 学术合作的关联需考据

**文献**：NetBSD 5.0 Release Notes；CVS commit log；tech-kern 邮件列表 ［A］

## 179.6.2 Sonnenberger 的 pkgsrc 维护

**要点**：Joerg Sonnenberger 作为 pkgsrc 长期维护者在 2005-2009 年间提交数千次 commit，是 pkgsrc 跨平台扩展的核心推动者；Sonnenberger 还参与 NetBSD 内核开发，特别是文件系统与构建系统改进；其工作风格以“严格技术标准”著称

**史料**：pkgsrc CVS commit log 中 joerg 的提交记录；tech-pkg 邮件列表讨论；Sonnenberger 的 BSDCan 演讲 ［A］

**史观**：总纲第 10 条——边缘者贡献：Sonnenberger 作为德国开发者，是 NetBSD 欧洲边缘者贡献的代表

**辨析**：Sonnenberger 的具体 commit 数量在不同统计工具中差异较大——需对照 CVS 与 Git 镜像核验；其工作风格在社区中存在争议，部分 committer 称其“过于严格”，需对照邮件列表讨论核验

**文献**：pkgsrc CVS 仓库；tech-pkg 邮件列表；Sonnenberger 的 BSDCan 演讲 ［A］

## 179.6.3 Zoulas 的长期贡献

**要点**：Christos Zoulas 作为 NetBSD 长期核心贡献者自 1990 年代起持续活跃至 2005-2009 年间及以后；贡献涉及终端模拟（libtermcap）、文件系统（ext2fs）、shell（/bin/sh 改进）等核心组件；Zoulas 是 NetBSD CVS 中 commit 数量最多的开发者之一

**史料**：NetBSD CVS commit log 中 christos 的提交记录；tech-userlevel 邮件列表讨论；Zoulas 在 BSDCan 历届演讲 ［A］

**史观**：总纲第 10 条——边缘者贡献：Zoulas 作为希腊裔开发者，体现 NetBSD 国际化的边缘者贡献

**辨析**：Zoulas 的 commit 数量在统计工具中可能被高估——部分 commit 为小修复或 typo，需区分实质性 commit 与 typo；其长期贡献的具体范围需对照 CVS author 列表核验

**文献**：NetBSD CVS 仓库；tech-userlevel 邮件列表；Zoulas 在 BSDCan 演讲 ［A］
