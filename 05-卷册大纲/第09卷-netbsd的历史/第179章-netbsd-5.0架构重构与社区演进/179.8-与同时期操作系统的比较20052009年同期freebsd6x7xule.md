## 178.8.2 OpenBSD 安全审计的对照

**要点**：OpenBSD 4.x（2006-2010）继续推行严格代码审计与大幅清零默认配置；**pledge(2)** 系统调用雏形在 4.9-5.0 期间探索；同期 NetBSD 安全团队在 cross-BSD 协调中借鉴 OpenBSD 审计成果；NetBSD 4.0/5.0 引入 NPF 防火墙，但未引入与 pledge 类似的进程权限控制

**史料**：OpenBSD 4.x Release Notes 与 changelog；NetBSD NPF 设计文档；cross-BSD 安全协调邮件列表 ［A］

**史观**：总纲第 8 条——社区文化即技术资产：OpenBSD 的“安全即文化”与 NetBSD 的“工程稳健”是两种文化资产的不同路径

**辨析**：**pledge(2)** 的雏形在 OpenBSD 不同版本中的引入时间存在叙事分歧——部分资料称 5.0，部分称 5.9，需对照 OpenBSD 源码 commit log 核验；NetBSD 是否曾考虑引入类似 pledge 的机制缺乏公开讨论记录

**文献**：OpenBSD 4.x/5.x Release Notes；NetBSD NPF 文档；OpenBSD pledge(2) 手册页 ［A］
