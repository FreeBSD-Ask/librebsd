## 171.1.1 1993 年分叉动机与 386BSD 停滞

**要点**：1993 年 NetBSD 分叉动机——386BSD 因 Jolitz 维护停顿无法支持新硬件与新功能，Chris Demetriou、Adam Glass、Charles Hannum 等伯克利学生决定 fork 创建 NetBSD，目标是延续 BSD 在多平台上的发展

**史料**：NetBSD 创建公告 1993.4；Demetriou/Glass/Hannum 早期邮件存档；386BSD 维护停滞记录；bsd_commits.db netbsd-src 仓库最早 commit 时间为 1992-07-13（srcmastr/mrg 导入 CSRG 历史代码），Chris Demetriou（cgd）首批 commit 时间为 1993-03-21（共 18 条 commit 同一时间戳导入），Theo de Raadt（deraadt）首条 commit 时间为 1993-04-02T12:24:21Z（commit 355265a86628），与 NetBSD 1993.4 创建公告时间吻合；统计结论 [C-04]: netbsd-src 仓库总 commit 数 773,683（截至 2026-07-27 查询），为 4 大 BSD src 仓库中 commit 累计最高者；bsd_commits.db 查询 L1.1.1 显示：netbsd-src 1993 年 commit_count=14,507，在 4 大 BSD src 仓库中占 94.35%（freebsd-src 同年仅 868 commit，占 5.65%），与“NetBSD 1993 年 fork 后早期开发强度远超 FreeBSD”叙事一致 ［A］

## 171.1.2 0.8 至 1.0 的开发历程

**要点**：NetBSD 0.8（1993.4.20）至 1.0（1994.10.26）的开发历程——约 18 个月内完成从 fork 到正式发布，团队整合 4.4BSD-Lite 预览代码、移植多平台（hp300、i386、sparc）、建立 pkgsrc 雏形；发布周期较长源于 1994 年 USL 诉讼和解促使的 4.4BSD-Lite 基础迁移工程；1.0 的发布奠定 NetBSD“可移植性至上”的定位

**史料**：NetBSD 0.8 与 1.0 Release Notes（netbsd.org/releases/formal-1.0.html）；早期 CVS 提交日志；NetBSD 核心团队开发记录；bsd_commits.db netbsd-src 仓库 branches 表验证（netbsd-src 无 release tag，branches 表 commit_date 为分支最后更新时间非发布时间）：origin/netbsd-0-9 branch commit_date = 1993-08-25T23:58:11Z（commit 4051c5751e24，与 NetBSD 0.9 发布时间 1993.8 时序一致）；origin/netbsd-1-0 branch commit_date = 1994-11-29T04:19:15Z（commit 94ac458bb17d，与 NetBSD 1.0 发布日期 1994.10.26 时序一致，branch 最后更新时间晚于发布约 1 个月，可能含发布后小修补）；bsd_commits.db 查询 L1.1.1 显示：netbsd-src 1994 年 commit_count = 17,726（占 4 大 BSD src 总量 80.78%），1995 年 commit_count = 12,163（占 58.88%，openbsd-src 同期 fork 后首次出现 commit 770 条，占 3.73%）；bsd_commits.db 查询 L1.4.1 显示：netbsd-src 仓库在标准 release tag 过滤条件（tag_name LIKE 'release/%’ OR '%-RELEASE’ OR 'OPENBSD_%’）下无匹配 tag，与 ch70 已用 branches 表代替 tags 表验证 release 节点的处理一致，反映 netbsd-src GitHub 镜像 tag 命名约定不同于 freebsd-src/release/ 前缀格式 ［A］

**史观**：总纲第 6 条——技术选择的代价：NetBSD 选择多平台战略付出复杂度代价，但获得可移植性声誉；总纲第 12 条——法律结构：USL 诉讼和解推动的 4.4BSD-Lite 迁移作为法律结构事件重塑 NetBSD 1.0 代码基础

**辨析**：1.0 发布日期在不同叙事中存在差异——部分早期资料误作 1993.10.4，但 NetBSD 官方发布页面（netbsd.org/releases/formal.html）明确为 1994.10.26；0.8 至 1.0 历时约 18 个月而非 6 个月，多平台移植的具体顺序需对照 CVS 日志核实。经 netbsd.db branches 表验证，origin/netbsd-1-0 branch 最后更新时间 1994-11-29 与 NetBSD 官方公告 1.0 发布日期 1994.10.26 时序一致（branch 最后更新可能含发布后小修补），1993.10.4 说法不正确，存疑已解决；L1.1.1 显示 netbsd-src 1994 年 commit_count = 17,726 较 1993 年 14,507 上升 22.2%，与 1.0 发布前开发强度增加的叙事吻合，但 L1.1.1 commit 量受 GitHub 镜像同步策略影响，须与 hg.NetBSD.org 主仓数据交叉验证；L1.4.1 标准过滤条件未匹配到 netbsd-src release tag，反映 netbsd-src tag 命名约定与 freebsd-src/release/ 前缀不同，须改用 branches 表交叉验证 release 节点

**文献**：NetBSD 早期开发史料；NetBSD 官方发布历史页面（<https://www.netbsd.org/releases/formal.html>）；多平台移植研究；origin/netbsd-0-9. netbsd-src 仓库 branch [DB/OL]. 1993-08-25T23:58:11Z. commit: 4051c5751e24；origin/netbsd-1-0. netbsd-src 仓库 branch [DB/OL]. 1994-11-29T04:19:15Z. commit: 94ac458bb17d；bsd_commits.db 数据分析·宏观趋势统计.md §L1.1.1（netbsd-src 1994/1995 年 commit 量）、§L1.4.1（4 大 BSD src release tag 间隔，netbsd-src 无匹配 tag） ［A］

## 171.1.3 与 FreeBSD 1.0 发布时间的对照

**要点**：NetBSD 1.0（1994.10.26）与 FreeBSD 1.0（1993.11.1）发布时间的对照——FreeBSD 1.0 早于 NetBSD 1.0 近 1 年发布；两项目虽同期发轫于 1993 年 4 月前后的 386BSD 分叉浪潮，但 NetBSD 1.0 因整合 4.4BSD-Lite 基础迁移工程而晚于 FreeBSD 1.0 发布；NetBSD 强调多平台可移植性，FreeBSD 强调 x86 性能优化；发布时间差异奠定两项目的差异化定位

**史料**：NetBSD 1.0 与 FreeBSD 1.0 Release Notes；两项目 1993-1994 年邮件列表对比；freebsd.db freebsd-src 仓库 tags 表 release/1.0.0_cvs tagger_date = 1993-11-01T00:00:00-08:00（tagger = svn2git，2020 年 SVN-to-Git 迁移时重建的 tag，与 FreeBSD 官方公告 1.0 发布日期 1993.11.1 一致）；freebsd.db netbsd-src 仓库 branches 表 origin/netbsd-1-0 commit_date = 1994-11-29T04:19:15Z（与 NetBSD 官方公告 1.0 发布日期 1994.10.26 时序一致）；freebsd.db 查询 L1.1.2 显示：1993 年 4 大 BSD src 中 netbsd-src = 14,507（94.35%）vs freebsd-src = 868（5.65%），1994 年 netbsd-src = 17,726（80.78%）vs freebsd-src = 4,217（19.22%），反映 NetBSD 1.x 早期在 4 大 BSD 中长期保持 commit 量主导地位，直至 2003 年 dragonfly-src fork 后格局方逐步变化 ［A］

**史观**：总纲第 7 条——技术选择即政治选择：NetBSD 与 FreeBSD 的发布时间差异反映不同技术政治选择

**辨析**：NetBSD 1.0 与 FreeBSD 1.0 的发布间隔约 12 个月（FreeBSD 1.0 于 **1993-11-01**，NetBSD 1.0 于 **1994-10-26**）；先前叙事中 ~~“1993.10.4 与 1993.11.1 同期发布”~~ 系误传，需对照 NetBSD 官方发布页面（**<https://www.netbsd.org/releases/formal.html**>）核验。经 bsd_commits.db 验证：freebsd-src tags 表 `release/1.0.0_cvs` tagger_date = 1993-11-01（tagger = svn2git，2020 年 SVN-to-Git 迁移期 tag，须与 SVN 时代邮件列表存档交叉验证）；netbsd-src branches 表 `origin/netbsd-1-0` commit_date = 1994-11-29（与官方公告 1994.10.26 一致）；两者时间间隔约 12 个月，与官方公告吻合，~~1993.10.4 同期发布~~ 说法不正确，存疑已解决；L1.1.2 查询的 4 大 BSD src 比例数据须注意 openbsd-src/netbsd-src 为 GitHub 镜像，commit 量可能不完整，1993-1994 年 netbsd-src 94.35%/80.78% 的高占比应与 hg.NetBSD.org 主仓数据交叉验证，且 commit 量比例不等于技术影响力或市场占比
