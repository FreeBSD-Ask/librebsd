### 新闻条目 1

- **新闻标题（中英）**：历史上的今天：NetBSD 系统发布（On This Day: NetBSD System Released）
- **新闻来源**：网易科技（163.com Tech） + 发布日期 2018-04-20 + URL <https://3g.163.com/tech/article/HKKJCN3S0511FQO9.html> + 存档 URL <https://web.archive.org/web/2023/https://3g.163.com/tech/article/HKKJCN3S0511FQO9.html>
- **新闻摘要**：文章回顾 1993-04-20 NetBSD 首个版本 0.8 发布的历史；1993-09 发布 0.9 版本，仍仅限 PC；1994-10 发布 1.0 版本，是 NetBSD 首个提供多平台支持的版本。NetBSD 项目口号"Of course it runs NetBSD"反映其移植至大量 32 位与 64 位架构的传统。
- **与本章主题的关联说明**：直接对应本章“NetBSD 的起源与理想（1993-1994）”的核心时间线，提供 0.8、0.9、1.0 三大里程碑版本的中文媒体回顾视角。
- **与官方史料的交叉验证结论**：与 NetBSD 官方变更记录页 `https://www.netbsd.org/changes/` 提供的版本时间线一致；版本日期与 NetBSD 官方 releases 页对照后确认无误。

- **新闻来源**：NetBSD 官方文档（huihoo.com 中文镜像）+ 发布日期未注明（持续维护文档）+ URL <https://docs.huihoo.com/netbsd/cn/chap-intro.html> + 存档 URL <https://web.archive.org/web/2024/https://docs.huihoo.com/netbsd/cn/chap-intro.html>

- **与本章主题的关联说明**：直接对应本章“NetBSD 的起源”主题，从源材料角度明确 4.3BSD Lite 与 386BSD 双重谱系来源；为 NetBSD 理想形态提供官方表述。
- **与官方史料的交叉验证结论**：本身即为 NetBSD 官方文档中文镜像，与 `https://www.netbsd.org/about/` 官方页面内容一致；4.3BSD Lite 与 386BSD 双重谱系说法与 CSRG 历史档案吻合。
