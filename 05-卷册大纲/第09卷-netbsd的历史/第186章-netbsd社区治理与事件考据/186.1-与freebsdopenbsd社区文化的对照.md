**三大 BSD 项目社区文化对照表**：

| 项目 | 文化标识 | 治理结构 | Foundation 成立 | 核心安全特性 |
| --- | --- | --- | --- | --- |
| FreeBSD | 实用主义 | Core Team 直选制（2000 年起） | FreeBSD Foundation（2000 年） | Capsicum、jail(8) |
| OpenBSD | 安全洁癖 | de Raadt 主导核心决策 | OpenBSD Foundation（2007 年，加拿大法律实体） | retguard、pledge(2)、unveil(2) |
| NetBSD | 可移植性至上 | Core Team 邀请制 | NetBSD Foundation（成立日期 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］，501(c)(3) 地位获得 2004-01-22） | KASLR（9.0 默认启用）、veriexec |

**要点**：FreeBSD 社区以“实用主义”著称，OpenBSD 社区以“安全洁癖”著称，NetBSD 社区以“可移植性至上”著称；三项目虽同源于 CSRG，但社区文化在 1990 年代后逐步分化；从安全漏洞统计视角看，NetBSD 的 NVD CVE 总数（136 个，1999-2026）与平均 CVSS 评分（5.50）均低于 FreeBSD（421 个，6.24）与 OpenBSD（168 个，6.17），这一数据对照并非反映 NetBSD 安全性更高，而是反映 NetBSD 部署规模较小导致漏洞发现率较低

**史料**：三项目 Core Team 公开声明对比；跨项目邮件列表讨论；BSDCan、AsiaBSDCon 等会议演讲；netbsd.duckdb 查询 L3.7.1 显示：netbsd-src 社区文化相关 commit 在 1993 年 = 79，2022 年 = 43（较 1993 年下降 45.6%），反映 NetBSD 社区文化相关 commit 量在 30 年间持续下降但未中断；社区文化 commit 的持续存在（1993-2022 年每年均有记录）与 NetBSD 社区“可移植性至上”文化认同的延续形成数据层面的呼应；社区文化 commit 量下降趋势与 L1.1.1 总 commit 量下降趋势方向一致，反映社区整体规模收缩对文化相关投入的连带影响；统计结论 [C-04]: netbsd-src 仓库总 commit 数 773,683（截至 2026-07-27 查询），为 4 大 BSD src 仓库中 commit 累计最高者，本章所述 NetBSD 社区“可移植性至上”文化认同在 1993-2026 全期 commit 累积中得以体现；统计结论 [E-23]: NVD NetBSD 相关 CVE 共 136 个（1999-2026 全期拉取，来源 `https://services.nvd.nist.gov/rest/json/cves/2.0?keywordSearch=NetBSD`），较 FreeBSD（421 个）与 OpenBSD（168 个）少，反映 NetBSD 部署规模与漏洞发现率的关系；统计结论 [E-28]: NetBSD 相关 CVE 平均 CVSS 评分 5.50（NVD API 2.0 全量拉取），低于 FreeBSD（6.24）与 OpenBSD（6.17），反映 NetBSD 漏洞严重性分布相对偏低 ［A］

**史观**：总纲第 7 条技术选择即政治选择，三项目的文化分化是其技术路线分化的镜像；统计结论印证：C-04（netbsd-src 总 commit 数 773,683 为 4 BSD src 仓库最高）、E-23（NVD NetBSD CVE 136 个）与 E-28（平均 CVSS 5.50）共同构成 “高累计 commit 量—低 CVE 数量—低 CVSS 评分” 的张力——高累计 commit 量反映 NetBSD 长期工程投入沉淀（C-04），但低 CVE 数量（E-23）与低 CVSS 评分（E-28）不等于 NetBSD 安全性更高，更可能反映 NetBSD 部署规模较小导致漏洞发现率与关注度较低，0 信任原则适用：CVE 数量与 CVSS 评分受部署规模、安全研究关注度、漏洞披露文化等多因素影响，不得简化为 “安全性排名”

**辨析**：文化对照易陷入刻板印象，需以具体事件与一手史料为依据。L3.7.1 查询基于 message_subject LIKE 匹配社区文化相关关键词（如“community”“culture”“foundation”“bylaw”“election”等），1993-2022 年的 commit 数字均为下限，实际涉及社区文化的 commit 可能更多；社区文化 commit 量从 79 降至 43 的下降趋势需结合 NetBSD 社区规模整体收缩（参见 L1.1.1 总 commit 量下降）理解，commit 量下降不等于社区文化衰退——部分文化相关工作可能转移至 Foundation 报告、会议演讲等非 commit 渠道；GitHub 镜像滞后风险——netbsd-src 为 GitHub 镜像（主仓为 Mercurial **hg.NetBSD.org**），1993-2022 年 commit 量可能不完整。统计结论 [C-04] 局限性继承：netbsd-src 总 commit 数 773,683 为全期累计值（1993-2026），不反映本章所述社区文化演进时期的开发活跃度。统计结论 [E-23] 局限性继承：NVD NetBSD CVE 136 个为 1999-2026 全期拉取值，NVD CVE 数量受漏洞披露文化与安全研究关注度影响——NetBSD 部署规模较 FreeBSD 与 OpenBSD 小，漏洞发现率与披露率可能偏低，136 这个数字是 “已披露 CVE” 的下限而非 “实际漏洞数”；NVD keywordSearch = NetBSD 的检索结果可能包含将 NetBSD 作为受影响平台之一但不以 NetBSD 为主要产品的 CVE，存在检索精度局限。统计结论 [E-28] 局限性继承：NetBSD 平均 CVSS 评分 5.50 为 136 个 CVE 的算术平均，CVSS 评分反映漏洞严重性而非实际利用难度，低平均 CVSS 不等于 NetBSD 漏洞危害更低；CVSS 评分存在主观性（如攻击向量与影响指标评估依赖分析师判断），不同 CVE 的 CVSS 评分可比性有限
