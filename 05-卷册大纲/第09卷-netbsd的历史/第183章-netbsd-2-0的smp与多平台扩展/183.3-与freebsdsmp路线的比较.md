# 183.3 与 FreeBSD SMP 路线的比较

**要点**：FreeBSD 5.x（2003-2006）推进 SMPng 与 Giant Lock 细化，5.2（2004）实验性引入 ULE 调度器；NetBSD 2.x/3.x 移植 SMPng 但调度器仍以 4BSD 为基础，反映两项目不同的工程节奏

**史料**：FreeBSD 5.x/6.x Release Notes；NetBSD 2.x/3.x Release Notes；freebsd-arch 与 tech-kern 邮件列表对照

**史观**：总纲第 7 条技术选择即政治选择，FreeBSD 选择 “x86 性能优先”，NetBSD 选择 “多平台一致性优先”

**辨析**：SMPng 是否为两项目共享代码需对照 CVS 历史核验，部分叙事夸大了共享程度

**文献**：FreeBSD 5.x Release Notes [EB/OL]. <https://www.freebsd.org/releases/>；NetBSD 2.x/3.x Release Notes [EB/OL]. <https://www.netbsd.org/releases/formal.html>；freebsd-arch 邮件列表存档 [EB/OL]. <https://lists.freebsd.org/archives/freebsd-arch/> ［A］
