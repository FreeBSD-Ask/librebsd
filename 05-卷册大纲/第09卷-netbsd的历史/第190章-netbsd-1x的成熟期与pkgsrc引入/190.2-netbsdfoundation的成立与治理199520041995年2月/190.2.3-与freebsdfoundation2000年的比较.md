# 190.2.3 与 FreeBSD Foundation（2000 年）的比较

**要点**：NetBSD Foundation（1995）与 FreeBSD Foundation（2000）的比较——NetBSD Foundation 早期注册，FreeBSD Foundation 2000 年才注册；两者治理结构相似但具体条款不同——NetBSD 强调 committer 治理，FreeBSD 强调 Core Team 与 Foundation 双层

**史料**：NetBSD 与 FreeBSD Foundation By-Laws 对比；两 Foundation 注册档案 ［A］
    FreeBSD 社区论文：[FP-2019-021] Cross Platform Parallel Regression and Performance Testing of, and with OpenZFS, FreeBSD and bhyve（Michael Dexter（迈克尔·德克斯特），2019）<https://papers.freebsd.org/2019/bsdcan/dexter-cross_platform_parallel_regression_and_performance_testing/>
    FreeBSD 社区论文：[FP-2019-039] Virtualization of BSD Using the QNX Hypervisor（Quentin Garnier，2019）<https://papers.freebsd.org/2019/bsdcan/garnier-virtualization_of_bsd_using_the_qnx_hypervisor/>
    FreeBSD 社区论文：[FP-2018-018] A Public-Key Trust Infrastructure for FreeBSD（Eric McCorkle，2018）<https://papers.freebsd.org/2018/bsdcan/mccorkle-a_public-key_trust_infrastructure_for_freebsd/>
    FreeBSD 社区论文：[FP-2018-019] Adding verification to FreeBSD loader（Simon Gerraty，2018）<https://papers.freebsd.org/2018/bsdcan/gerraty-adding_verification_to_freebsd_loader/>
    FreeBSD 社区论文：[FP-2017-014] Isolated BSD build environments using virtual and hardware machines（Michael Dexter，2017）<https://papers.freebsd.org/2017/vbsdcon/dexter-isolated_bsd_build_environments_using_virtual_and_hardware_machines/>

**史观**：组织结构塑造技术路径：两 Foundation 治理结构差异反映文化差异

**辨析**：比较需考虑注册时间差异——NetBSD 1995 与 FreeBSD 2000 间隔 5 年，背景不同
