## 故障类

### 新闻条目 1

- **新闻标题（中英）**：New Security Advisories: NetBSD-SA2009-001 through 007 (affecting BIND, OpenSSL, NTPd)
- **新闻来源**：NetBSD 官方变更页 + 2009 年全年 + URL `https://www.netbsd.org/changes/2009.html` + 存档 URL `https://web.archive.org/web/2024/https://www.netbsd.org/changes/2009.html`
- **新闻摘要**：2009 年 NetBSD 发布多条安全公告，包括 NetBSD-SA2009-001 至 NetBSD-SA2009-013。涉及 BIND named 动态更新 DoS 漏洞、SHA2 实现潜在缓冲区溢出、ISC DHCP 服务器 DoS、ISC dhclient 子网掩码栈溢出、OpenSSL 多项漏洞、NTPd 漏洞等。其中 OpenSSL 与 BIND 漏洞反映出 5.0 时期第三方组件安全问题的集中暴露。
- **与本章主题的关联说明**：2009 年集中发布的安全公告反映 NetBSD 5.0 时期安全响应机制的成熟度；OpenSSL/BIND/NTPd 等关键组件的安全维护是 5.0 系列长期支持的重要组成。
- **与官方史料的交叉验证结论**：与 NetBSD 官方安全公告页 `https://www.netbsd.org/support/security/` 一致；每条公告编号与 NetBSD 邮件列表 `security-announce` 公告时间吻合。
