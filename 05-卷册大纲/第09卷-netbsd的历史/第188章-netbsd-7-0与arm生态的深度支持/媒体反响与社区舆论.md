# 第 17.6 节 媒体反响与社区舆论

> 本子节汇总与本章主题相关的新闻报道与社区舆论，按“批评类 / 故障类 / 冲突类 / 里程碑事件类 / 外部冲击类 / 校园社会文化新闻类 / 商业产业新闻类”七类组织。所有新闻条目遵循 0 信任原则，须与官方史料交叉验证后方可采信。

## 里程碑事件类

### 新闻条目 1

- **新闻标题（中英）**：NetBSD 6.0 released!（NetBSD 6.0 发布！）
- **新闻来源**：NetBSD 官方变更页 + 发布日期 2012-10-17 + URL `https://www.netbsd.org/changes/2012.html#netbsd-6-0` + 存档 URL `https://web.archive.org/web/2024/https://www.netbsd.org/changes/2012.html`
- **新闻摘要**：2012-10-17 NetBSD 6.0 正式发布。NetBSD 6.0 引入了多项重要特性：Threaded SMP（多线程对称多处理）、改进的虚拟内存系统、新一代网络栈优化、Xen 4.x 支持、改进的 ARM 多处理器支持、Raspberry Pi 移植基础工作、改进的 Cross-build 工具链、NPF 防火墙等。
- **与本章主题的关联说明**：直接对应本章 "NetBSD 6.x（2012-2014）" 主题的核心发布事件；Threaded SMP 与 NPF 防火墙是 6.0 时期最重要的工程里程碑。
- **与官方史料的交叉验证结论**：与 NetBSD 官方 releases 页面 `https://www.netbsd.org/releases/formal-6.0/` 一致；6.0 引入的特性列表与 NetBSD 6.0 release notes 完全吻合。
