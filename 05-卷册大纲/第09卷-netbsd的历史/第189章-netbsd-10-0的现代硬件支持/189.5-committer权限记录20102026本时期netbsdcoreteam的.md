# 189.5 committer 权限记录（2010-2026）——本时期 NetBSD Core Team 的 committer 权限变更记录，包括 18 个月不活跃自动退休的执行

## 189.5.1 自动退休与新 committer 加入记录

**要点**：NetBSD 2010-2026 年间继续执行“18 个月不活跃自动退休”制度；自动退休人数在新 committer 加入数之上，导致社区规模持续萎缩；新 committer 主要来自编程之夏学生转化与学术合作；部分老 committer 如 Alistair Crooks、Luke Mewburn（卢克·缪伯恩） 等逐步淡出

**史料**：NetBSD Core Team 决议记录；CVS commit log；core 邮件列表；统计结论 [C-21]: netbsd-src 月度 commit 量 编程之夏 季节性 Wilcoxon 符号秩检验 p=0.0362（显著，α=0.05），编程之夏 期（5-8 月）月均 commit 量显著低于非 编程之夏 期——这一反直觉现象反映 NetBSD 主仓开发在 编程之夏 期由核心开发者将精力转向学生指导而非主仓 commit，编程之夏 学生的工作多在 pkgsrc 或子项目仓库积累而非直接进入 netbsd-src 主仓，故本章时期（2010-2026）“新 committer 主要来自编程之夏学生转化”的叙事与 C-21 互补：编程之夏 期主仓 commit 量下降（C-21）与学生转化新 committer（本节叙事）构成“投入-产出”的时序错位 ［A］

**史观**：总纲第 1 条——偶然性改写历史：核心 committer 退休是具体的人的具体决定，但连锁影响 NetBSD 工程进展；总纲第 25 条——0 信任原则：C-21 的 “反直觉” 结论（编程之夏 期主仓 commit 反而更低）须以 0 信任原则审视——统计显著不等于实际显著，编程之夏 期主仓 commit 量下降的可能原因（核心开发者转向指导、学生 commit 进入 pkgsrc 而非 src）须结合 commit message 主题词与作者归属交叉验证

**辨析**：自动退休的具体人数在不同来源中差异较大——需对照 CVS commit log 与 Core Team 决议核验；新 committer 加入的具体时间点需考据。统计结论 [C-21] 局限性继承：编程之夏 季节性 Wilcoxon 检验 p = 0.0362 显著仅反映 netbsd-src 月度 commit 量在 编程之夏 期（5-8 月）与非 编程之夏 期存在统计学显著差异，不等于 编程之夏 项目本身导致主仓 commit 量下降——“显著” 可能是 编程之夏 期核心开发者精力分流至学生指导的副作用，也可能是夏季北半球假期等其他季节性因素的混杂效应；Wilcoxon 检验采用月均率消除期间长度差异（编程之夏 期 4 个月 vs 非 编程之夏 期 8 个月），但未消除其他季节性因素（如夏季假期、年终总结周期等）；C-21 仅针对 netbsd-src 主仓，未涵盖 netbsd-pkgsrc 等其他仓库的 编程之夏 季节性——若学生 commit 主要进入 pkgsrc，则 pkgsrc 的 编程之夏 季节性可能呈现相反模式（编程之夏 期 commit 量反增），须结合 netbsd-pkgsrc 仓库的 编程之夏 季节性 Wilcoxon 检验交叉验证 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］

**文献**：NetBSD Core Team 决议记录；CVS commit log 统计；core 邮件列表；netbsd.duckdb 数据分析·推断性统计.md Task 9 SubTask 9.2（统计结论 C-21：netbsd-src 编程之夏 季节性 Wilcoxon p = 0.0362 显著 编程之夏 期月均更低，Python: `scipy.stats.wilcoxon`，采用月均率消除期间长度差异） ［A］

## 189.5.2 撤权案例（如有）

**要点**：NetBSD 2010-2026 年间是否存在因违反社区准则或技术争议而强制撤权的案例缺乏公开记录；与 OpenBSD 不同（de Raadt 单方面撤权），NetBSD Core Team 撤权需协商；Core Team 决议的私密性使考据困难

**史料**：NetBSD core 邮件列表存档（私密部分）；Core Team 决议记录；公开宣布（若有） ［A］

**史观**：总纲第 8 条——社区文化即技术资产：NetBSD 的“协商撤权”文化与 OpenBSD 的“单方面撤权”文化对比反映治理差异

**辨析**：撤权案例的私密性使考据困难——需对照公开 commit log 的 author 变化推断；部分“撤权”可能是自愿退役而非强制

**文献**：NetBSD core 邮件列表；Core Team 决议记录 ［A］

## 189.5.3 与 FreeBSD committer 权限模型的比较

**要点**：FreeBSD 与 NetBSD 在 2010-2026 年间均执行“自动退休”制度，但 FreeBSD 因商业赞助较多核心 committer 活跃度更高；FreeBSD Core Team 选举制度更正式，NetBSD Core Team 由现有成员协商产生；FreeBSD Core Team 在 2010-2026 年间是否改革需对照章程版本

**史料**：FreeBSD Committer‘s Guide 2010-2026 版本；NetBSD developer’s guide；两项目 Core Team 章程 ［A］

**史观**：总纲第 14 条——商业与社区的张力：FreeBSD 商业赞助维持 committer 活跃度，NetBSD 缺乏商业支撑导致 committer 流失

**辨析**：两项目 committer 权限模型的“严格程度”对比缺乏权威评估——需对照实际权限变更案例核验

**文献**：FreeBSD Committer‘s Guide；NetBSD developer’s guide；两项目 Core Team 章程 ［A］
