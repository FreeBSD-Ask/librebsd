## 189.1.3 与 Linux Apple Silicon 支持的比较

**要点**：Linux Apple Silicon 支持由 Asahi Linux 项目（Hector Martin 等）主导，2022 年起在 M1/M2 上获得可用桌面；NetBSD Apple Silicon 支持远落后 Linux，10.0 仅提供基础内核启动；FreeBSD arm64 自 2021 年起已可实验性引导 Apple M1/M2（支持度落后 Linux，但非“未支持”）；Linux 凭借社区规模与商业赞助（Asahi Linux 众筹）获得压倒性优势

**史料**：Asahi Linux 项目文档；NetBSD Apple Silicon 移植文档；FreeBSD ARM 平台支持列表［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］〔L3 官方文档与公告〕

**史观**：总纲第 13 条——法律与道德是利益分配〔存疑：重挂待复核〕：Linux 凭借 Asahi Linux 众筹与社区规模获得 Apple Silicon 优势，NetBSD 受限于资源难以竞争

**辨析**：NetBSD Apple Silicon 移植与 Asahi Linux 是否共享代码需考据——NetBSD 部分借鉴 Asahi Linux 逆向工程成果，但未直接共享驱动代码；Asahi Linux 的“可用桌面”定义需对照实际功能核验

**文献**：Asahi Linux 项目文档；NetBSD Apple Silicon 文档；FreeBSD ARM 平台支持［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］
