### 新闻条目 1

- **新闻标题（中英）**：NetBSD 7.0（NetBSD 7.0 正式发布）
- **新闻来源**：NetBSD 官方变更页 + 发布日期 2015-09-25 + URL `https://www.netbsd.org/changes/2015.html` + 存档 URL `https://web.archive.org/web/2024/https://www.netbsd.org/changes/2015.html`
- **新闻摘要**：2015-09-25 NetBSD 7.0 正式发布。NetBSD 7.0 引入多项重要特性：改进 ARM 多核支持（覆盖 Cortex-A15/A57 等多核 SoC）、内核时间戳自 32-bit 向 64-bit time_t 迁移以应对 2038 年问题、NPF 防火墙增强以及大量新设备支持。验证方法：对照 NetBSD 7.0 release notes 页 `https://www.netbsd.org/releases/formal-7/NetBSD-7.0.html` 与 `https://www.netbsd.org/changes/2015.html` 官方记载。
- **与本章主题的关联说明**：直接对应本章 “NetBSD 7.0 与 ARM 生态的深度支持（2015）” 主题的核心发布事件；ARM 多核支持与 64-bit time_t 迁移是 7.0 时期最重要的工程里程碑。
- **与官方史料的交叉验证结论**：与 NetBSD 官方 formal releases 页面 `https://www.netbsd.org/releases/formal.html` 一致（7.0 行记为 September 25, 2015）；发布日期与 changes/2015 页 “25 Sep 2015 - NetBSD 7.0” 公告吻合。
