## 175.1.1 FreeBSD 2.x/3.x/4.x（同期竞争与借鉴，1993-2004）

**要点**：FreeBSD 在 NetBSD 1.x 同期从 2.0（1994）演进至 4.x（2000-2004），以 x86 性能与 Ports 生态见长；与 NetBSD 1.x 的“广度优先（多平台）”形成对照——FreeBSD 选择“深度优先（x86 深度优化）”，二者在 1990 年代 BSD 复兴中既竞争又互鉴（如 VM 系统、网络栈代码共享）。

## 175.1.2 OpenBSD 2.x/3.x（1996 fork 后，1996-2004）

**要点**：OpenBSD 自 1995-1996 从 NetBSD fork 后，在 NetBSD 1.x 同期发布 2.x（1996-2000）与 3.x（2002-2004），以安全与代码审计著称；与 NetBSD 1.x 的“可移植性”目标分野，体现 fork 后的路线独立——OpenBSD 承接了 NetBSD 早期部分平台但转向安全优先。

**史料**：OpenBSD 2.x/3.x 发布史；NetBSD/OpenBSD fork 史料（1995.10）［B］
    FreeBSD 社区论文：[FP-2019-081] OpenZFS: Best Filesystem for every OS（Allan Jude（艾伦·裘德），2019）<https://papers.freebsd.org/2019/jude-openzfs-everyos/>

**史观**：总纲第 4 条——分离聚合是永恒规律：OpenBSD 的 fork 是 BSD 家族“代码自由流动 + 路线分叉”的典型案例，与 NetBSD 同期并行。

**辨析**：OpenBSD 的 fork 非否定 NetBSD，而是目标重定（安全 vs 可移植）；二者共享 4.4BSD-Lite 基础。

**文献**：OpenBSD. Release Notes 2.x-3.x [EB/OL]；NetBSD/OpenBSD 分家史料。［B］

## 175.1.3 Linux 1.2/2.0/2.2/2.4（1995-2003）

**要点**：Linux 在 NetBSD 1.x 同期从 1.2（1995）演进至 2.4（2001），以快速迭代、x86 主导与 GNU 工具链生态扩张；与 NetBSD 1.x 的 BSD 许可/多平台形成对照——Linux 以 GPL + 单一内核架构 + 爆发式社区规模在 1990 年代末超越 BSD 的桌面/服务器份额。

**史料**：Linux 1.2-2.4 发布史；LWN 早期报道 ［B］

**史观**：总纲第 4 条——分离聚合是永恒规律：Linux 的单内核 + GPL 社区模式与 NetBSD 的 BSD 许可 + 多平台在 1990 年代形成生态规模落差。

**辨析**：Linux 的份额领先不完全源于技术优劣，而源于 GPL 的“病毒式”生态聚合与 x86 崛起的契合。

**文献**：Linux Kernel. Release Notes [EB/OL]；LWN.net 档案。［B］

## 175.1.4 Windows 95/98/NT 4/2000（1995-2000）

**要点**：Microsoft 在 NetBSD 1.x 同期发布 Windows 95（1995）、98（1998）、NT 4（1996）、2000（2000），以桌面垄断与商业生态主导；与 NetBSD 1.x 的开源多平台形成对照——Windows 在消费端碾压 BSD，但 NetBSD 在嵌入式/学术/服务器小众领域保持存在（如 DECstation、Dreamcast 移植）。

**史料**：Microsoft Windows 95-2000 发布史 ［B］

**史观**：总纲第 4 条——分离聚合是永恒规律：闭源商业桌面生态与开源多平台在 1990 年代形成市场分割，NetBSD 选择非消费市场。

**辨析**：Windows 的成功不否定 NetBSD 价值——后者在可移植性/教育/嵌入式利基持续贡献。

**文献**：Microsoft. Windows 95-2000 Product History [EB/OL].［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］

## 175.1.5 同期 BSD/Linux 生态总览（1993-2004）

**要点**：1993-2004 是 BSD 复兴与 Linux 崛起的重叠期：NetBSD 1.x 以多平台 + 社区治理（NetBSD Foundation 1995）立身，FreeBSD 以 x86 性能 + Ports 领先，OpenBSD 以安全分叉，Linux 以 GPL 社区规模爆发；四者在此期既竞争又互鉴，奠定 2000 年后开源格局。

**史料**：各系统 1993-2004 发布与治理史料 ［B］

**史观**：总纲第 4 条——分离聚合是永恒规律：NetBSD/FreeBSD/OpenBSD 同期并行演进，与 Linux 共同构成 UNIX/类 UNIX 生态的多元复兴。

**辨析**：将此期视为“BSD vs Linux”零和竞争是误读——代码互鉴（如 VM、网络栈）与社区流动持续发生。

**文献**：McKusick M K, Neville-Neil G. The Design and Implementation of the FreeBSD Operating System [M]. 2nd ed. Addison-Wesley, 2015. ［B］
