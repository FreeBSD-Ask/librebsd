# 189.5.2 校园社会文化新闻类

### 新闻条目 1

- **新闻标题（中英）**：What is NetBSD（何谓 NetBSD）
- **新闻来源**：NetBSD 官方文档（huihoo.com 中文镜像）+ 发布日期未注明（持续维护文档）+ URL <https://docs.huihoo.com/netbsd/cn/chap-intro.html> + 存档 URL <https://web.archive.org/web/2024/https://docs.huihoo.com/netbsd/cn/chap-intro.html>
- **新闻摘要**：官方文档中文版，明确指出 NetBSD 萌芽自 4.3BSD Lite 操作系统，源自加州伯克利大学；前身为第一个移植到 Intel 386 CPU 的 BSD——386BSD。文档系统阐述 NetBSD 的可移植性传统与开源 BSD 衍生身份。
- **与本章主题的关联说明**：直接对应本章“NetBSD 的起源”主题，从源材料角度明确 4.3BSD Lite 与 386BSD 双重谱系来源；为 NetBSD 理想形态提供官方表述。
- **与官方史料的交叉验证结论**：本身即为 NetBSD 官方文档中文镜像，与 `https://www.netbsd.org/about/` 官方页面内容一致；4.3BSD Lite 与 386BSD 双重谱系说法与 CSRG 历史档案吻合。

### 新闻条目 2

- **新闻标题（中英）**：NetBSD（具有移植性的 UNIX-like 操作系统）
- **新闻来源**：百度百科经主站镜像 baike.com + 持续维护 + URL <https://m.baike.com/wiki/netbsd/556104> + 存档 URL <https://web.archive.org/web/2024/https://m.baike.com/wiki/netbsd/556104>〔原禁引来源（仅作考据留痕）·已改引官方主源 ref2147（NetBSD 官方历史页 netbsd.org/Misc/history.xml）〕
- **新闻摘要**：词条描述 NetBSD 由 Chris Demetriou、Theo de Raadt（西奥·德·若特）、Adam Glass（亚当·格拉斯）、Charles Hannum 四人发起；项目目标是集合全球开发者开发完全自由的类 UNIX 操作系统。提到 NetBSD 包含来自加州伯克利大学的 4.4BSD-Lite 等代码。
- **与本章主题的关联说明**：明确列出 NetBSD 四位创始人的姓名与身份；与本章“起源与理想”主题中创始人群体肖像完全对应。
- **与官方史料的交叉验证结论**：四位创始人姓名与 NetBSD 官方 `https://www.netbsd.org/people/` 页面及 NetBSD Foundation 历史档案一致；Theo de Raadt 后于 1995 年 fork 出 OpenBSD 的史实亦可与 OpenBSD 官方页面交叉验证。
