## 132.1 Announce loop-AES-v2.2c file/swap crypto package

- 【Linux社区】Jari Ruusu 发布 loop-AES v2.2c：新增 2.6 内核 per-thread 与 per-process rlimits 编译期自动探测及规避、Gentoo 兼容二进制密钥挂载选项、mount 与 losetup 随机密钥选项（可加密 /tmp）、module_param_array 破坏规避，附 tarball 与 md5。 `<!-- ROW_MINE: linux-kernel-announce.messages.724127 -->`

## 132.2 2.6.17-rc1-mm1

- 【Linux社区】Andrew Morton 发布 -mm：开头报 ia64 VGA 黑屏未及排查、Linus 外出联网不定、换用 x86 专用新 kgdb（“好得多”但与 gcc-4.2 严重冲突），含 LED 设备类、交互任务饥饿修复、reiser4 全部补丁合并为单补丁，附 539 补丁清单。 `<!-- ROW_MINE: linux-kernel-announce.messages.724145 -->`

## 132.3 Linux 2.6.12.5

- 【Linux社区】Chris Wright 以 -stable 团队名义发布 2.6.12.5：14 文件 diffstat 与逐人修复摘要，含 CAN-2005-2098/2099 密钥管理信号量钉死与 keyring 销毁 oops、CAN-2005-2458/2459 内核 zlib 漏洞、zisofs 输入缓冲检查、模块 per-cpu 对齐。 `<!-- ROW_MINE: linux-kernel-announce.messages.724250 -->`

## 132.4 2.6.12-rc4-mm2

- 【Linux社区】Andrew Morton 发布 -mm：davem 建 mm-commits 列供审阅增删、Andi 的 x86_64 大更新、至 spurious-interrupt-fix 止均计划并入 2.6.12、又一轮 DVB 子系统更新，Greg 补丁改用稳定命名，附 1166 补丁清单。 `<!-- ROW_MINE: linux-kernel-announce.messages.724256 -->`

## 132.5 2.6.23-rc2-mm2

- 【Linux社区】Andrew Morton 发布 -mm：称 rc2-mm1 的各种问题已修，含 sysctl 大清理移除失效二进制接口、per-BDI 脏页阈值等回写补丁因“崩溃性”整体撤下、FUSE 粘滞位执行权限检查修补，附 1215 补丁清单。 `<!-- ROW_MINE: linux-kernel-announce.messages.724261 -->`

## 132.6 Announce loop-AES-v2.1c file/swap crypto package

- 【Linux社区】Jari Ruusu 发布 loop-AES v2.1c 与 ciphers v2.0i：并入 Russell King 的 flush_dcache_page 修复（缓存别名怪异处理器受影响）、新增 AMD64 汇编 AES/MD5、i386 汇编实现启用到全部 x86、新增 DKMS 配置与 source 符号链接支持。 `<!-- ROW_MINE: linux-kernel-announce.messages.724266 -->`

## 132.7 Announce loop-AES-v2.0c file/swap crypto package

- 【Linux社区】Jari Ruusu 发布 loop-AES v2.0c 与 ciphers v2.0c：修 util-linux 补丁在 2.6 头文件编译、修多密钥模式 SMP 竞态数据损坏（限共享可写映射、加密并发、非正常关机等五条件同时满足），附 tarball 与 md5。 `<!-- ROW_MINE: linux-kernel-announce.messages.724295 -->`

## 132.8 2.6.17-rc4-mm3

- 【Linux社区】Andrew Morton 发布 -mm：撤下若干补丁集盼改善内存管理初始化问题、RH FC5 上 swsusp resume 仍坏疑为用户态 bug，含 genirq handler 改名 chip、x86 vsyscall 页搬移（Xen 准备）、print_fatal_signals 启动项，附 1085 补丁清单。 `<!-- ROW_MINE: linux-kernel-announce.messages.724316 -->`

## 132.9 Linux 2.6.12.6

- 【Linux社区】Chris Wright 发布 2.6.12.6 并声明因 2.6.13 已出故为 2.6.12 最后一版：9 文件 diffstat 与逐人修复摘要，含 NPTL 信号投递死锁、CAN-2005-2555 socket policy 加载限 CAP_NET_ADMIN、icmp/ip6 路径 DST 与 SKB 泄漏。 `<!-- ROW_MINE: linux-kernel-announce.messages.724360 -->`

## 132.10 2.6.15-rc3-mm1

- 【Linux社区】Andrew Morton 发布 -mm：警示 ALSA 与 PCMCIA 树冲突致多个 ISA 声卡驱动及 jsm 编译不过、含 dentry 结构瘦身、简易 SPI 框架、TPM BIOS 测量日志、ext3 外部日志设备挂载选项，附 806 补丁清单。 `<!-- ROW_MINE: linux-kernel-announce.messages.724375 -->`
