# 395.11.12 Linux社区ChristophLameter澄清move_pages2manp

- 【Linux社区】Christoph Lameter 澄清 move_pages.2 manpage 由他撰写后由 Michael Kerrisk 编辑，许可证为 GPL 而非专有许可；他同意将其页面从 VERBATIM_TWO_PARA 改为 Linux-man-pages-copyleft `<!-- ROW_MINE: linux-man.messages.743371 -->`
- 【Linux社区】Rob Landley 反驳 Michael Kerrisk 称 _GNU_SOURCE 是标准方式的说法，质问什么标准？Linux 内核不是、也从未是 GNU 项目的一部分；此前 glibc 团队坚持用 GNU_GNU_GNU_ALL_HAIL_STALLMAN 式宏来暴露该 Linux 专有特性 `<!-- ROW_MINE: linux-man.messages.743615 -->`
- 【Linux社区】Rob Landley 称 GNU 与 Linux 无关，从未相关，并指 Stallman 有冒领他人成果的历史；Colomar 回应称 GNU 是用户空间程序集、Linux 是内核、GNU/Linux 指整个系统，且自己从 GNU/Linux 发行版写作；Landley 进一步指出 busybox/Alpine、Android/toybox/LLVM 等主动避免 GNU 组件 <!-- ROW_MINE: linux-man.messages.744735 -->`
- 【Linux社区】Michael Kerrisk 回应 Rob Landley 的质疑，修正表述为这是 glibc 在 POSIX 头文件中隔离 Linux 专有功能的标准方式，即 _GNU_SOURCE 并非 POSIX 标准而是 glibc 内部约定 `<!-- ROW_MINE: linux-man.messages.745033 -->`
- 【Linux社区】Carlos O'Donell 回应 Andries E. Brouwer 对 man-pages-6.14 统一版权头的质疑（Brouwer 引 Linux Foundation 博文“Don't change someone else's copyright notice without their permission”，认为改动既有版权声明违法）：Carlos 表示同意其解读，即未经版权人明确许可不得移除这些条目；并说明 glibc 的做法是不删除任何既有版权头，而在 DCO 下新增“Copyright The GNU Toolchain Authors.”一行，与“Copyright (C) 1995-2025 Free Software Foundation, Inc.”并列。 <!-- ROW_MINE: linux-man.messages.746894 -->`
- 【Linux社区】Christoph Lameter 在回复中一并转发 Colomar 的通报。Colomar 以“I've added to BCC everyone whose copyright notices have been removed”逐封询问作者是否批准 commit 9f2986c 对其页面的改动，BCC 清单由 git show 该提交被删除行中抽取邮箱生成。他此前拒绝了 Branden Robinson 提议的替代行“See the Git revision history at $URL for records of changes and contributors to this file”，理由是“I don't want to add that overhead to each page”，故“go with a removal without replacement”。 `<!-- ROW_MINE: linux-man.messages.747091 -->`
- 【Linux社区】Mathieu Desnoyers 就其页面内版权头被删一事回复“This change is OK as far as I am concerned”，理由是希望“help lessen the maintenance burden”，并称“Eliminating redundant, copyright information appears to be a good way to it”；同时说明“The git history holds detailed information about the line-by-line modifications to each file anyway”。 `<!-- ROW_MINE: linux-man.messages.748615 -->`
- 【Linux社区】Colomar 说明 commit 9f2986c 将各页版权头统一为“Copyright, The contributors to the Linux man-pages project”并加“SPDX-License-Identifier: Linux-man-pages-copyleft”，原作者改列入 CREDITS。Brouwer 以 man2/unlink.2 为例：原头逐行列有 Drew Eckhardt(1992)、Ian Jackson(1993)、Michael Kerrisk(2006,2014) 版权与 verbatim 授权语，而“Today I read”已改为一行集体署名，故“I no longer find the information about who owns this page”。Colomar 称该讨论历时约三个月，作者名仍在 CREDITS 可查。 `<!-- ROW_MINE: linux-man.messages.748645 -->`
- 【Linux社区】Michael Kerrisk 就 pid_namespaces(7) 引 Biederman 与 Rob Landley 之争，纠正 Landley 所谓“the glibc guys insist on #define GNU_GNU_GNU_ALL_HAIL_STALLMAN in order to access this Linux-specific feature”之误解，称 _GNU_SOURCE 是从 POSIX 头文件暴露 Linux 专属功能的通行方式，且该宏至少自 glibc 2.0（1997 年）即已存在；Landley 则反驳“The Linux kernel is not, and never was, part of the GNU project”，指 musl 以 _ALL_SOURCE 一律开启全部 feature test macro，并称其反对理由在于“Linux system calls are not part of the GNU project”，不应要求该宏才能从 bionic、uClibc、klibc、musl、dietlibc 或 newlib 使用 Linux 系统调用 <!-- ROW_MINE: linux-man.messages.750297 -->`
- 【Linux社区】Brian Inglis 在 SPDX license review 线程中回应 Christoph Lameter：就 Lameter 转引的讨论背景——VERBATIM_TWO_PARA 首次用于 man-pages 3.07（2008 年）的 move_pages.2、后复用于 migrate_pages.2——Lameter 称该页由其撰写、后经 Michael 编辑，且“The licensing was GPL and not a proprietary one”；Inglis 称更新这些许可证对本项目“are really nice to haves”，并指出 FSF 与 Fedora 的实际争议仅在采 LDPv1 许可的 dir_colors(5)，其含受争议条款“c) You must not add notes to the Document implying that the reader had better read something produced using Texinfo”，限制修改，尤对欲推广替代文档格式的 GNU 等项目为甚。 <!-- ROW_MINE: linux-man.messages.751032 -->`
- 【Linux社区】G. Branden Robinson 建议暂缓 man-pages 许可重标注并复述 Fedora 的 Freeness 异议，Colomar 指认被拒许可为 LDP (v1)，理由是“the prohibition to recommend an info manual”；Branden 指出所提四份许可均未显式授予翻译权。 `<!-- ROW_MINE: linux-man.messages.752823 -->`
- 【Linux社区】Andries E. Brouwer 质疑统一版权声明的合法性，引 Linux Foundation 博文“Don't change someone else's copyright notice without their permission”，认为改动既有版权声明违法；Alejandro Colomar 说明其与相关方长达约三个月的讨论并留 commit 链接。 `<!-- ROW_MINE: linux-man.messages.753418 -->`
- 【Linux社区】Andries E. Brouwer 对 system_data_types(7) 采用的 VERBATIM 许可“I severely object”；Michael Kerrisk 回应称该许可自项目创立以来即是最广泛使用的许可（现过半页面采用）。Brouwer 考证其出处：文本出自 Rik Faith，最早见于 1994 年 9 月的 man-pages-1.4（234 页采用），其 1995 年首个发布 man-pages-1.6 亦有 245 页采用。 <!-- ROW_MINE: linux-man.messages.753782 -->`
- 【Linux社区】Richard Fontana 对 man-pages 以 SPDX 标注 GPL-1.0-or-later 表示“pretty unlikely what any contributor to these files intended”，认为早期内核年代 GPL 版本 1“was largely forgotten”而“the GPL”已指向版本 2；他建议若属自身项目会改述为 GPL-2.0-or-later。 `<!-- ROW_MINE: linux-man.messages.754314 -->`
