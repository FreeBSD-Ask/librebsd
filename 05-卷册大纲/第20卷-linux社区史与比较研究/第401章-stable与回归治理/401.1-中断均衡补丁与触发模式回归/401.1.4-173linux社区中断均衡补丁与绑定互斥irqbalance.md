# 401.1.4 17.3 【Linux社区】中断均衡补丁与绑定互斥（irqbalance）

**要点（判定表逐字）**：Jens-S. Voeckler（2003-12-05，University of Chicago）：ASUS P4S800（SiS 648 + SiS 962/963 UDMA133）双 P4 2.60GHz stepping 09、2.4.23——应内核消息报料，/proc/interrupts 中 CPU1 几乎全零（仅 ide0 计 1）：“although both CPUs in the ASUS P4S800 ACPI Rev 1004 go to work, the interrupts are not balanced”；并行重负载时“it appears as if one CPU ‘saturates’ before the other one is doing things”——IO-APIC 下中断不均衡的一手观察；Mark Hounschell（2002-05-23）答 Schmitz, Dave R（Supermicro P4DC6+/P4DCE+/P4DP6，860/E7500，RH 2.4.7-10smp 全部中断落 CPU0）：有多台同型 1.7GHz 机，试成 irq_balance patch（附 sched.c/hardirq.h/io_apic.c/irq.c 全文，2.4.18）——“It is an irq_balance patch. Don't remember where it came from.”；代价：“once you apply it you can no longer bind an irq to a particular processor if you want to”，因实时模拟应用（PCI 卡 6 高分辨率定时器 + 8 外部中断）需绑定 IRQ 而回退；并建议 BIOS 试 MPS 1.1——IRQ 均衡补丁与绑定互斥的一手证词
