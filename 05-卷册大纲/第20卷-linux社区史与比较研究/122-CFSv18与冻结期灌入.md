# 122. CFS v18、容器 v11 与冻结期 37MB 灌入（ann p10）（ann p10）

> 来源：linux-kernel-announce 人工信 p10（10 封全读，2005-07 至 2008-04，-mm 发布八封（CFS v18 与 Xen 容器 v11/git-dma 与 git-e1000new 争议来源/冻结收补仍被灌入 37MB diff/PM QoS 与内核 marker/page-flags 三架构破坏）、stable 2.6.12.5 完整 diff、kmap_atomic 冲突不可达分析）
> 判定：10 CAND / 0 NV。主题分布：2.6.25-rc8-mm2 1、2.6.13-mm2 1、2.6.13-rc4-mm1 1、Re: Linux 2.6.12.5 1、2.6.23-mm1 1、2.6.20-rc3-mm1 1、2.6.23-rc1-mm1 1、Re: kmap_atomic() oopses in current mainline 1、2.6.18-mm2 1、2.6.16-rc2-mm1 1。

## 122.1 2.6.25-rc8-mm2

- 【Linux社区】Andrew Morton 发布 -mm 树快照，评语核心：page-flags 补丁致 mips/sparc64/powerpc 编译破坏，git-drm/git-xfs/git-kvm 因构建或冲突被剔除，git-slub 临时由 git-pekka 顶替（Pekka 代班 Christoph），x86 本地可用但 Rafael 报告崩溃 `<!-- ROW_MINE: linux-kernel-announce.messages.721555 -->`

## 122.2 2.6.13-mm2

- 【Linux社区】Andrew Morton 发布，评语核心：新纳入 Andi 的 x86_64 树、TI acx1xx 无线网卡驱动（自评“粗糙，能让它 ping 通东西”）、pcmcia 挂起大改，明言大量 tty 驱动仍无法编译，并小结 2.6.14 合并进度（x86_64 与 USB 树未合并） `<!-- ROW_MINE: linux-kernel-announce.messages.721565 -->`

## 122.3 2.6.13-rc4-mm1

- 【Linux社区】Andrew Morton 发布，评语核心：剔除 areca-raid 与 iteraid 驱动、整体剔除 CKRM 补丁（“在 -mm 没起什么作用”）、剔除 connector 补丁（netlink 已无可用槽位），x86 汇编清理为虚拟化铺路 `<!-- ROW_MINE: linux-kernel-announce.messages.721592 -->`

## 122.4 Re: Linux 2.6.12.5

- 【Linux社区】stable 维护者 Chris Wright 发布 2.6.12.4 至 2.6.12.5 完整 diff，无文字评语但即修复内容本身：zlib 解压损坏数据报错、isofs zisofs 边界检查、x86_64 TSC 同步竞争修复并新增 smp_call_function_single、mempolicy 负值校验、keyring list_del 竞争修复 `<!-- ROW_MINE: linux-kernel-announce.messages.721600 -->`

## 122.5 2.6.23-mm1

- 【Linux社区】Andrew Morton 发布，评语核心：为 2.6.23 合并冻结收补却仍被子系统维护者灌入 37MB diff，称“运转稍好”；含 PM QoS 接口、内核 marker、FUSE 大更新、容器框架等分组评注 `<!-- ROW_MINE: linux-kernel-announce.messages.721617 -->`

## 122.6 2.6.20-rc3-mm1

- 【Linux社区】Andrew Morton 发布，评语核心：新增 IBM ACPI 驱动树 git-ibm-acpi（Henrique de Moraes Holschuh），块层 plug/unplug 代码重写“似乎可用”；另含 workqueue flush API 重构与用户命名空间虚拟化 struct user 等评注 `<!-- ROW_MINE: linux-kernel-announce.messages.721646 -->`

## 122.7 2.6.23-rc1-mm1

- 【Linux社区】Andrew Morton 发布，评语核心：新增 git-dma 树（Shannon Nelson）与新 e1000 驱动树 git-e1000new（Auke Kok，自评“争议来源”）；补丁组含 CFS 调度器 v18、Xen 半虚拟化、容器 v11、LSM 转静态接口 `<!-- ROW_MINE: linux-kernel-announce.messages.721658 -->`

## 122.8 Re: kmap_atomic() oopses in current mainline

- 【Linux社区】Evgeniy Polyakov 对 Andrew Morton 指出的 async_tx kmap 原子映射缺陷作实质回应：当前仅 RAID 代码使用、读写只取其一故双 KMAP 标志同槽冲突暂不可达，并建议页面来自 alloc_page() 时应一律 kmap_atomic `<!-- ROW_MINE: linux-kernel-announce.messages.721695 -->`

## 122.9 2.6.18-mm2

- 【Linux社区】Andrew Morton 发布，评语核心：新增 SuperH 与 SuperH64 架构树（Paul Mundt）及 PCI-Domain 树（Jeff Garzik），git-input 因 USB 鼠标故障临时剔除，呼吁启用 MSI 实测，并告知 netconsole-over-e100 下 reboot 失效 `<!-- ROW_MINE: linux-kernel-announce.messages.721732 -->`

## 122.10 2.6.16-rc2-mm1

- 【Linux社区】Andrew Morton 发布，评语核心：自评“补丁有增有删，没什么激动人心的”，但公告 smurf（Matthias Urlichs）提供的 -mm git 镜像可用且未经其测试；分组评注含 cpuset 内存分散特性、全新 LED class 子系统、unshare 系统调用 v5 `<!-- ROW_MINE: linux-kernel-announce.messages.721742 -->`
