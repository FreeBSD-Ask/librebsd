# 2.3.3 4.x 延续定位遭官方判过时、双方无缓和叙事

<!-- DOC_MINE: ref10249#url -->
**官方文档**（证据等级：L3，来源：`historical_claims.duckdb.claim.CL-RM-497796`；2026-11-23 V50 补证批 b014）

官方史页自述项目原初定位已过时：“The project was originally billed as "the logical continuation of the FreeBSD 4.x series", as quoted in the announcement, but this description has long since become obsolete.”——4.x 延续定位被官方史页判为早已过时。引文出处：DragonFly BSD Project. DragonFly BSD — History[EB/OL]. https://www.dragonflybsd.org/history/ [2026-11-23].；引文按 L3 纪律：以上为公开文献记载（官方文档或同时代报道），非当事人直接证词，具体结论仍须回核原文与同期一手材料，不得单独引为定论。
