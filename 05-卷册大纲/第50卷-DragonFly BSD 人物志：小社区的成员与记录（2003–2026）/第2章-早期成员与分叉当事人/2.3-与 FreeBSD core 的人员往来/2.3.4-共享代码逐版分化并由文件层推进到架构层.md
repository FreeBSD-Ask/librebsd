# 2.3.4 共享代码逐版分化并由文件层推进到架构层

<!-- DOC_MINE: ref10249#url -->
**官方文档**（证据等级：L3，来源：`historical_claims.duckdb.claim.CL-RM-497798`；2026-11-23 V50 补证批 b014）

官方史页记第一阶段（至 2007 年初）“the DragonFly project focused on rewriting most of the major kernel subsystems to implement required abstractions”，工作遍及几乎每个子系统、官方明言“particularly the filesystem APIs and kernel core”——分叉由文件层推进到架构层。引文出处：DragonFly BSD Project. DragonFly BSD — History[EB/OL]. https://www.dragonflybsd.org/history/ [2026-11-23].；引文按 L3 纪律：以上为公开文献记载（官方文档或同时代报道），非当事人直接证词，具体结论仍须回核原文与同期一手材料，不得单独引为定论。
