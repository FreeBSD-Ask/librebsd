# 2.3.1 撤权经表决而投票记录未公开

<!-- DOC_MINE: ref11121#url -->
**新闻报道**（证据等级：L3，来源：`historical_claims.duckdb.claim.CL-RM-497707`；2026-11-21 V50 补证批 b013）

OSNews 于 2003-02-03 报道：FreeBSD 最活跃内核开发者之一 Matt Dillon 失去向源码树提交代码的权利，且 FreeBSD Project 未给出促成该决定的明确理由（“The FreeBSD Project didn’t give a solid reason on what lead them to this decision.”）——撤权的对外说明面自始留白。引文出处：Jonathan. Matthew Dillon Lost Commit Access to FreeBSD[EB/OL]. (2003-02-03). https://www.osnews.com/story/2722/matthew-dillon-lost-commit-access-to-freebsd/ [2026-11-21].；引文按 L3 纪律：以上为公开文献记载（官方文档或同时代报道），非当事人直接证词，具体结论仍须回核原文与同期一手材料，不得单独引为定论。

**官方文档**（证据等级：L3，来源：`historical_claims.duckdb.claim.CL-RM-497708`；2026-11-21 V50 补证批 b013）

FreeBSD 提交者指南设撤权程序条款：特权被中止或撤销者有权由 core 听证（“a committer whose privileges are suspended or revoked is entitled to a “hearing” by core”），被完全撤销者满六个月可请求复审（“may request a review after a period of 6 months has elapsed.”）——撤权有程序条款可依。引文出处：The FreeBSD Documentation Project. FreeBSD Committer’s Guide[EB/OL]. https://docs.freebsd.org/en/articles/committers-guide/ [2026-11-21].；引文按 L3 纪律：以上为公开文献记载（官方文档或同时代报道），非当事人直接证词，具体结论仍须回核原文与同期一手材料，不得单独引为定论。
