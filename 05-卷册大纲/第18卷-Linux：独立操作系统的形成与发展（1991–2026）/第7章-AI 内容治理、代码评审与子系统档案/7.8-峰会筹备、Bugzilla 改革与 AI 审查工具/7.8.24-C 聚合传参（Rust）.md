- 【Linux社区】深化别名模型讨论：追问能否给出保守的部分规范（stacked/tree borrows 是否只含假阳或假阴），以 Java happens-before 简化模型类比，并对照 C restrict 的实践难度。 `<!-- ROW_MINE: ksummit.messages.926 -->`
