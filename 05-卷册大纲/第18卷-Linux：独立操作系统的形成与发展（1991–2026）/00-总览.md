# 第18卷  Linux：独立操作系统的形成与发展（1991—2026）

> 本卷以独立操作系统的形成为叙事轴心：Minix 作为教学环境创造了技术与共同体条件，Linux 在此条件下涌现并与 GNU 生态组合成完整系统，随后共同体治理与产业扩散逐层展开。各章按“条件—涌现—组合—扩散”的构成关系排列。

**卷分工注**：逻辑—时间定位（2026-10-04 乙案拆章）：本卷载独立操作系统的形成——Minix 与 386 PC 的技术条件、Linux 0.01 的产生与发布、早期协作共同体的形成、GNU 与 Linux 的组合、Linux 共同体与产业扩散（1987—2026）；开源话语的制度化另见第三十二卷；Linux 与 BSD 的来源、判据与遮蔽另见第三十四卷与第六十一、六十二卷；BSD-Linux 关系史见第六十三卷。本卷不属 BSD 共同体编年。
