# 8.2.314 195.23 Rust未定义行为

- **要点**：Linus 请 Rust 社区避免 C 式 UB 优化模型：要么朴素代码生成要么明确警告，举 WG14 N3203 收紧未定义行为为例，称潜在优化不值得代价。Linus 阐明 unsafe 的本义是让源码有意绕过规则而非授权编译器重排访问，以分配器指针运算为例，要求编译器不能证明不别名就不要假设。
