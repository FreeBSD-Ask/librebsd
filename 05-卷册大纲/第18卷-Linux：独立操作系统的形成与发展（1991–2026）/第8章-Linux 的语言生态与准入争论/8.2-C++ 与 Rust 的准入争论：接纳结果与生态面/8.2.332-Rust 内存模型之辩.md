# 8.2.332 Rust 内存模型之辩

- **要点**：Ventura Jack 与 Ralf Jung 论战别名规则：Jung 指别名要求仅限引用、裸指针可全退出且 C 亦无形式化别名模型；VJ 反驳 Miri 似 sanitizer 只测运行时可达路径，实测慢 50 至 400 倍。Ralf Jung 阐明 unsafe 不改变语义、别名优化依赖全程序普适假设，局部豁免即整体失效；Linus 引证 GCC 不重物化载入、C 标准已禁加宽存储，Jung 认为多数基础工作已就绪。Dan Carpenter 讽刺 C 侧抗拒整数溢出检查却要求 Rust 侧守更强规则，举“先乘后判溢出”写法为例，称此类人应被永久禁止宣传 Rust。Ralf Jung 界定写可见性规则：某位置全为原子写时编译器不得凭空增写，一旦出现非原子写即示无并发访问、可引入额外写，C、C++、Rust 规范皆然。
