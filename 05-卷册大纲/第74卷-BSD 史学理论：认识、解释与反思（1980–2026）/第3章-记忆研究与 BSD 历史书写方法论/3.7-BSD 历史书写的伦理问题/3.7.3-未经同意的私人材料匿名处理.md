# 3.7.3 未经同意的私人材料匿名处理

<!-- DOC_MINE: ref10256#url -->
**学术记载**（证据等级：L3，来源：`historical_claims.duckdb.claim.CL-RM-497996`；supp-V74-b010 2026-11-25）

访谈记录抬头须列叙述者与访谈者姓名，或在适当场合使用化名——匿名是可选项而非事后补救。引文出处：ORAL HISTORY ASSOCIATION. Oral history best practices[EB/OL]. [2026-11-25]. https://oralhistory.org/best-practices/.；引文按 L3 纪律：以上为公开文献记载（官方文档或同时代报道），非当事人直接证词，具体结论仍须回核原文与同期一手材料，不得单独引为定论。
