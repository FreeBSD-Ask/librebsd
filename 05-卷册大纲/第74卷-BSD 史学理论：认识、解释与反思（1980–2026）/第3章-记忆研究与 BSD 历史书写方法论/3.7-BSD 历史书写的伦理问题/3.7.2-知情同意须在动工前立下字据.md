# 3.7.2 知情同意须在动工前立下字据

<!-- DOC_MINE: ref10257#url -->
**学术记载**（证据等级：L3，来源：`historical_claims.duckdb.claim.CL-RM-497994`；supp-V74-b010 2026-11-25）
