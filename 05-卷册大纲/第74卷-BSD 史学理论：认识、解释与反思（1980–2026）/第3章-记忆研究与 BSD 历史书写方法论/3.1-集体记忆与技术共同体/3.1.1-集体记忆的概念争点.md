# 3.1.1 集体记忆的概念争点

<!-- MAIL_INSIGHT: 20000717135055.B23145@orion.ac.hmc.edu -->
**观点**：2000 年 7 月，Brooks Davis 在 freebsd-arch 的 bikeshed 词源讨论中表示“Nobody seems to be remember it right so I dug it up in the archives”（原文如此），并附 Poul-Henning Kamp 1999-10-03 原始邮件的归档 URL 与全文转录。
**邮件来源**：Brooks Davis，freebsd-arch，2000-07-17，Message-ID: `20000717135055.B23145@orion.ac.hmc.edu`
**史学意义**：面对集体记忆的系统性失准，社区成员的应对不是争辩而是回到档案——这一词源考古行为本身即是认识论自反的实践示范：记忆会漂移，档案可复核。本书对一切社区传说均须执行同等的归档回溯，而非采信任何一方的回忆。
