# 3.2.1 四项自由的条款来源

<!-- DOC_MINE: ref10658#url -->
**官方文档**（证据等级：L3，来源：`historical_claims.duckdb.claim.CL-RM-495369`；2026-11-15 V32 联网补证批 b032）

定义以编号列举：自由 0 是按意愿运行、用于任何目的，自由 1 是研究并改动程序，且写明“源码可及是此前条件”——条款来源即这四项。引文出处：Free Software Foundation. The Free Software Definition[EB/OL]. [2026-11-15]. https://www.gnu.org/philosophy/free-sw.html.；引文按 L3 纪律：以上为公开文献记载（官方文档或同时代报道），非当事人直接证词，具体结论仍须回核原文与同期一手材料，不应单独引为定论。
