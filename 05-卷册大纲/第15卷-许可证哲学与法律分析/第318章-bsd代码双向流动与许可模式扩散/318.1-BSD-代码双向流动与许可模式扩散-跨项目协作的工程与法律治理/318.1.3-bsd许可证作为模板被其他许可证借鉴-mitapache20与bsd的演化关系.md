# 318.1.3 BSD 许可证作为模板被其他许可证借鉴——MIT、Apache 2.0 与 BSD 的演化关系

**要点**：BSD 许可证作为最早的开源许可证之一，其条款结构被后续多个宽松许可证借鉴——（1）**MIT 许可证与 BSD-2-Clause 的关系**：MIT 许可证（又称 Expat 许可证）的条款结构与 BSD-2-Clause 极为相似，二者均包含 “版权声明” “许可授予” “按现状提供” “不承担担保责任” 四要素，主要差异在条款表述（MIT 更简洁，BSD-2-Clause 更明确）；OSI 许可证列表将二者均归为 “宽松许可证”，FSF 许可证注释亦称 “MIT 许可证与 BSD-2-Clause 实质等价”；BSD-2-Clause 成为现代 BSD 项目（FreeBSD、Nginx、Varnish 等）的主流选择，MIT 许可证则在 X Window System 与现代 JavaScript 生态（如 npm 包）中扩散；（2）**Apache 2.0 与 BSD 的演化关系**：Apache 2.0 许可证由 Apache 软件基金会于 2004 年 1 月发布，在 BSD/MIT 的 “版权声明 + 许可授予 + 不承担担保” 基础上增加了两项关键条款——专利反制条款（第 3 条）与贡献者协议（第 5 条）；Apache 2.0 的专利反制条款是 BSD/MIT 所无的，此条款旨在解决 BSD/MIT 在专利诉讼中的脆弱性；Apache 2.0 在 2000 年代后随 Apache 软件基金会项目扩散，成为 Hadoop、Spark、Kubernetes 等大型项目的首选许可证；（3）**BSD 许可证演化（4 条款 →3 条款 →2 条款）**：BSD 4-Clause（原版 BSD 许可证）包含 “版权声明” “许可授予” “不承担担保” “广告条款”（要求所有采用者在广告材料中注明 “本产品包含由加州大学伯克利分校及其贡献者开发的软件”）四要素；BSD 3-Clause（1999 年 7 月 22 日由 William Hoskins 在 ftp.cs.berkeley.edu 公告中宣布移除广告条款）移除广告条款，保留 “版权声明” “许可授予” “不承担担保” “未获背书” 四要素；BSD 2-Clause（Simplified BSD License 或 FreeBSD License）进一步移除 “未获背书” 条款，仅保留 “版权声明” “许可授予” “不承担担保” 三要素；BSD 许可证演化反映社区对广告条款与背书条款的反对，以及 BSD 许可证向 MIT 简洁性的靠拢。BSD 许可证作为模板被其他许可证借鉴体现 BSD 许可证在许可证谱系中的 “基础设施性”——其条款结构成为后续宽松许可证的基础，但 BSD 标签被 MIT/Apache 等后续许可证的 “品牌化” 掩盖

**史料**：OSI 许可证列表（opensource.org/licenses）；FSF 许可证注释（gnu.org/licenses/license-list.html）；BSD 4-Clause 原始文本（开源促进会 BSD-3-Clause 页面 history 部分）；William Hoskins 1999 年 7 月 22 日 ftp.cs.berkeley.edu 公告（移除广告条款）；Apache 2.0 许可证原文（apache.org/licenses/LICENSE-2.0）；MIT 许可证原文（opensource.org/licenses/MIT）；X Window System MIT 许可证文本（x.org） ［A］

**史观**：总纲第 13 条——法律与道德是利益分配（见 据原文第 11 章 11.1 节）：“任何法律问题都是政治问题，任何政治问题都是利益分配问题”——BSD/MIT/Apache 等宽松许可证的条款结构差异是法律层面的利益分配规则——Apache 2.0 增加专利反制条款是专利诉讼风险下的利益再分配，BSD 4 条款移除广告条款是商业采用者与原许可证持有者之间的利益再分配；总纲第 2 条——历史是形式主义化的非存在（见 据原文第 2 章 2.5 节）：“谁试图诠释历史，谁就在篡改历史。讨论真假无非是在争夺自己的话语权”——BSD 许可证作为模板被 MIT/Apache 借鉴，但 BSD 标签被 MIT/Apache 的 “品牌化” 掩盖，此 “标签遮蔽” 是形式主义化的非存在——BSD 许可证的实质贡献（条款结构）被保留，但 BSD 标签被消除

**辨析**：考据过程留痕——【查证来源】OSI 许可证列表（opensource.org/licenses）经一手核验将 BSD/MIT/Apache 均归为 “宽松许可证”；FSF 许可证注释（gnu.org/licenses/license-list.html）经一手核验称 “MIT 许可证与 BSD-2-Clause 实质等价”；BSD 4-Clause 原始文本与 William Hoskins 1999 年 7 月 22 日 ftp.cs.berkeley.edu 公告经 OSI BSD-3-Clause 页面 history 部分一手核验；Apache 2.0 许可证原文经 apache.org/licenses/LICENSE-2.0 一手核验，专利反制条款为第 3 条；MIT 许可证原文经 opensource.org/licenses/MIT 一手核验；【交叉验证方法】OSI 许可证列表（OSI 官方）与 FSF 许可证注释（FSF 官方）双向印证 “MIT 许可证与 BSD-2-Clause 实质等价” 的判断；Apache 2.0 许可证原文（Apache 官方）与 BSD-2-Clause 许可证原文（FreeBSD 官方）对比印证 “Apache 2.0 在 BSD/MIT 基础上增加专利反制条款” 的事实层面成立；BSD 4→3→2 条款演化经 OSI BSD-3-Clause 页面 history 部分（OSI 官方）与 William Hoskins 1999 公告（伯克利官方）双向核验；【存疑判定依据】“BSD 许可证作为模板被 MIT 借鉴” 的判断在条款结构层面成立（二者条款结构高度相似），但在历史时序层面须辨析——MIT 许可证最早用于 X Window System（1980 年代），BSD 许可证最早用于 BSD（1980 年代），二者时序相近，“借鉴” 关系可能为 “平行演化” 而非 “直接借鉴”（**存疑：MIT 与 BSD 的历史时序关系须查 X Window System 早期许可证文本与 BSD 早期许可证文本的演化路径，以确认是 “借鉴” 还是 “平行演化”**）；“Apache 2.0 在 BSD/MIT 基础上增加专利反制条款” 的判断在条款结构层面成立（Apache 2.0 第 3 条确为 BSD/MIT 所无），但 Apache 2.0 的设计是否直接受 BSD/MIT 影响须查 Apache 软件基金会许可证委员会的设计文档（**存疑：Apache 2.0 设计文档未明确提及 BSD/MIT 为设计来源，“在 BSD/MIT 基础上增加” 为基于条款结构的合理推断但非确证**）；0 信任原则提示：OSI 与 FSF 作为开源/自由软件运动组织，其许可证分类与注释存在立场偏差风险（OSI 倾向宽松许可证，FSF 倾向 copyleft 许可证），须与法律学术文献独立核验；William Hoskins 1999 公告作为伯克利官方声明存在自利偏差风险（倾向淡化广告条款的历史影响），须与当年邮件列表讨论交叉验证
