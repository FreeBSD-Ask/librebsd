# 299.1 GNU 发行版谱系——Debian、Guix、Trisquel、Parabola

#### 要点

1993 年 8 月 16 日，Ian Murdock（普渡大学本科生）发布 Debian 0.01，命名为“Debian GNU/Linux”（Debra + Ian）。Debian 是首个以 GNU 工具链 + Linux 内核组合的社区发行版，与 Slackware（1993 年 7 月由 Patrick Volkerding 发布）并列为最古老的 Linux 发行版。Debian 早期（1993-1995）依赖 Softlanding Linux System (SLS) 的包格式，1994 年 dpkg 包管理器诞生，1995 年 apt 包管理器原型出现，2000 年代 apt 成为 Debian 标志性工具。Debian 的核心治理文件是 Debian Constitution（1998 年通过），确立“开发者大会（DPL）+ 技术委员会 + 项目负责人”的治理结构。
1997 年 7 月 4 日，Debian Social Contract 与 Debian Free Software Guidelines（DFSG）发布，由 Bruce Perens（时任 Debian 项目负责人）主导。Debian Social Contract 承诺 Debian 完全由自由软件构成（DFSG 定义“自由软件”），DFSG 后续成为 OSI（Open Source Initiative，1998 年成立）“开源定义”（Open Source Definition）的基础——Bruce Perens 1998 年离开 Debian 后参与创立 OSI，将 DFSG 略作修改形成 OSD。Debian 与 GNU 项目的关系是“协作但独立”——Debian 是 GNU 项目官方认可的发行版（称“Debian GNU/Linux”），但 Debian 治理独立于 FSF，DFSG 比 GNU 自由软件定义略宽松（如允许 GFDL 与某些商业许可）。
2012 年，GNU Guix 启动，由 Ludovic Courtès（法国 Inria 研究员）主导，作为 GNU 项目的函数式包管理器与发行版。Guix 基于 Nix 包管理器（2003 年由 Eelco Dolstra 在 Utrecht 大学开发）的函数式包管理理念——每个包版本独立存储于 /gnu/store 路径，包依赖关系是纯函数式，支持事务性升级与回滚。Guix 2015 年发布 Guix System（GuixSD），2026 年 Guix System 仍为小众发行版但社区活跃。Guix 与 Debian 的关系是“竞争但互补”——Debian 是传统 FHS 文件系统布局，Guix 是函数式包管理；二者皆是 GNU 发行版但哲学不同。
Trisquel GNU/Linux（2006 年，由西班牙 Galicia 自由软件开发者 Rubén Rodríguez 主导）与 Parabola GNU/Linux-libre（2010 年，由阿根廷开发者主导）是 GNU 项目认可的“完全自由”发行版——二者皆从 Debian 或 Arch Linux 中移除所有非自由软件（包括 Linux 内核中的二进制 blob），使用 Linux-libre 内核（由 FSF Latin America 维护，移除 Linux 内核中的非自由固件）。Trisquel 与 Parabola 是 FSF“完全自由 GNU/Linux 发行版”列表的成员，但用户数极少，主要服务于严格自由软件用户。
Debian、Guix、Trisquel、Parabola 谱系须呈现多方主体性辩证张力——Debian 主流但含非自由软件（根据 DFSG 严格解释，main 仓库完全自由，但 non-free 仓库存在）、Guix 函数式但小众、Trisquel/Parabola 完全自由但用户极少——禁止“Debian 妥协”或“Trisquel 正统”二元判断，呈现自由软件谱系在“严格性”与“实用性”上的不可通约性。

#### 史观

本子节史观映射覆盖以下 5 条相关总纲，皆已回溯到 29 章原文核验：

**总纲 1（形式主义是世界的真实存在）**——据原文第 1 章 1.1-1.2 节：Debian、Guix、Trisquel、Parabola 作为四种形式主义化的建构——Debian 的“社区发行版 + Social Contract”模式、Guix 的“函数式包管理”模式、Trisquel/Parabola 的“完全自由”模式——皆是 GNU 发行版的主体性选择，无“客观最优”的“GNU 发行版本质”。

**总纲 4（分离聚合是永恒规律）**——据原文第 4 章 4.1 节：Debian 从 SLS 的分离（1993），到 DFSG 与 OSD 的聚合（1998，Perens 将 DFSG 修改为 OSD），到 Guix 从 Debian 的分离（2012），到 Trisquel/Parabola 从 Debian/Arch 的分离（2006/2010）——这一系列分离聚合并非线性进步，而是不同形式主义的循环呈现。

**总纲 5（没有必然性，只有偶然性）**——据原文第 5 章 5.2 节：若 Ian Murdock 未在 1993 年发布 Debian，若 Bruce Perens 未在 1997 年主导 Social Contract，若 Ludovic Courtès 未在 2012 年启动 Guix，GNU 发行版谱系会呈现完全不同的脉络。所谓“Debian 必然主导 GNU/Linux 发行版”的叙事是史家的事后重构。

**总纲 10（动手者创造历史）**——据原文第 14 章 14.1-14.2 节：Murdock 亲自创建 Debian，Perens 亲自起草 Social Contract 与 DFSG，Courtès 亲自创建 Guix，Rodríguez 亲自维护 Trisquel 至 2026 年——这些是动手者的实践，而非“GNU 项目决定”或“开源社区决定”等抽象决策的产物。

**总纲 2（历史是形式主义化的非存在）**——据原文第 2 章 2.5 节：所谓“GNU 发行版谱系（1993-2026）”的判定本身即形式主义化的非存在——若以 Slackware（1993.7，早于 Debian）为主线，若以 Red Hat（1994）/SUSE（1994）为主线，若以 Ubuntu（2004，基于 Debian）为主线，“GNU 发行版史”会呈现完全不同的脉络。本子节选取 Debian/Guix/Trisquel/Parabola 为主线，但这一选取本身须以自反性声明显化。

**自反性声明**：本子节选取“Debian → Guix → Trisquel/Parabola”为 GNU 发行版主线，但这一选取本身即形式主义化的非存在。若以 Slackware/Red Hat/SUSE 商业发行版为主线，若以 Ubuntu/Linux Mint 桌面发行版为主线，若以 Alpine/Arch 精简发行版为主线，“GNU 发行版史”会呈现完全不同的脉络。本子节承认主轴选取本身是史家的形式主义化决策，欢迎被更自反的释读所超越。

#### 辨析

**Debian 与 Slackware 发布先后辨析**：部分二手资料称“Debian 是最古老的 GNU/Linux 发行版”，但 Slackware（1993 年 7 月由 Patrick Volkerding 发布）早于 Debian（1993 年 8 月 16 日）；Debian 是最古老的“社区治理”发行版，Slackware 是最古老的“个人维护”发行版。本子节采用“Slackware 1993.7 早于 Debian 1993.8，Debian 是最古老社区治理发行版”的区分性表述。

**DFSG 与 OSD 关系辨析**：部分二手资料称“OSD 是 DFSG 的克隆”，但准确表述是 Bruce Perens 1998 年离开 Debian 后将 DFSG 略作修改（删除 Debian 特定引用、调整部分条款）形成 OSD；二者在“自由软件/开源软件”定义上高度相似但哲学不同——DFSG 服务于 Debian 的“自由软件”承诺，OSD 服务于 OSI 的“开源软件”倡导。本子节采用“DFSG 与 OSD 高度相似但哲学不同”的限定性表述。

**Linux-libre 与 Linux 内核关系辨析**：部分二手资料称“Linux-libre 是 Linux 内核的分支”，但准确表述是 Linux-libre 是 Linux 内核的“去 blob”版本——FSF Latin America 维护脚本自动从 Linux 内核源代码中删除所有二进制 blob（非自由固件），每次 Linux 内核发布后相应发布 Linux-libre 版本；Linux-libre 不是独立开发分支，而是 Linux 内核的“清洁”再分发。本子节采用“Linux-libre 是 Linux 内核的去 blob 再分发，非独立分支”的限定性表述。
