**要点**：

- Michael W. Lucas 以自出版与 Patreon 结合的商业模式持续写作 BSD 技术书，TLS Mastery 为其第 45 本书。（BSD Now EP418，[1499.44-1513.44]，L1）
- 其小说 Git Commit Murder 以渥太华的 UNIX 会议为背景，刻画 BSD 社区成员群像，续作转向 Linux 会议场景。（BSD Now EP418，[747.58-1001.08]，L1）
- 他主张自出版是策略而非战略，大体量书交传统出版，小体量书自出版，并将自出版内容重混进 Absolute FreeBSD 等大书。（BSD Now EP418，[1849.0-1997.66]，L1）
- 一篇教程记述在 FreeBSD jail 中以 easyjail 部署 Gemini 服务器 Molly Brown 的过程，包括克隆接口、SSL 证书、rc.d 服务脚本与 jail 内 SSH 访问，展示 jail 作为轻量隔离环境承载新协议的实践路径。（BSD Now EP406，[273.92-470.8]，L2）
- FreeBSD 2021 年第一季度状态报告显示，doc、src、ports 三仓库已切换至 Git，CI 作业与文档工具链随之迁移至 Git 与 AsciiDoc/Hugo，并记录 13.0 发布与 Linux 兼容层支持 Firefox Widevine 的进展。（BSD Now EP406，[476.4-1461.2]，L2）
- Michael W Lucas 在采访中自述，1995 年美国国家科学基金会全面商业化互联网后，其管理的客户端域名服务器频繁崩溃，直至安装 FreeBSD 名称服务器才获得整夜睡眠，由此转向 OpenBSD 与 FreeBSD 世界并最终成为全职技术作者。（BSD Now EP406，[1721.98-1828.6]，L1）
- 主持人说明 BSD grep 的重写源于 Google Summer of Code，采用现代搜索算法后仍存在边缘情况慢于 GNU grep，最终修复并成为 FreeBSD 默认，GNU grep 保留为编译期选项。（BSD Now EP406，[2820.16-2956.14]，L2）
- Michael W. Lucas 访谈综述：SNMP 新书以克苏鲁恐怖为主题做特别版《Networknomicon》，含虚构的 Miskatonic University 图书馆印章（“勿从金库取出”“勿实现”“勿读”）与 Grimoire 书衣，并把定价刻意设为 66.66 美元，作为赞助者的赠书而非普通商品；TLS 书则改用《公主新娘》主题为枯燥内容增色，因为“结合 TLS、恐怖与 2020 年的美国”过于沉重。（BSD Now EP378，[337.1-424.24]，L1）
- SNMP 史与技术观：SNMP 取代了更早的 Gateway Management Protocol，且诞生于“字节总是 8 位”尚未成为共识的年代；Lucas 回忆 1997 年遇到一台完全靠 SNMP 配置、没有命令行的 Bay Networks 路由器，感叹这是“美好的想法未能经受现实考验”；他当初学 SNMP 时以为只是只读监控，得知可写以配置交换机、路由器时感到“邪恶”，但也承认线路拥塞无法 SSH 时可用单个 SNMP 包关闭接口来争取时间。（BSD Now EP378，[272.06-771.48]，L1）
- 监控的方法论难点在选择：一个小的 BSD 虚拟机经一次 SNMP walk 就能拉出上千项特性，直觉是“因为能画图就全部画图”，但决定监控什么才是真正的困难；Alan 补充 FreeBSD 12.2 从新版 ZFS 引入 per-dataset 读写字节与 IOPS 统计（经 sysctl），可用脚本暴露给 SNMP，用于定位哪个客户或虚拟机在制造磁盘负载，但数百个 dataset 会爆炸成上千维计数器，必须选择性采集。（BSD Now EP378，[787.2-1001.24]，L1）
- TLS 史的僵尸化案例：证书 subject 中的 common name（CN）在 1995 至 2000 年间有效五年后即被判定为问题并应于 2011 年停用，却以“mostly dead”状态继续存续约四倍于其正式寿命，说明互联网上废弃特性的惯性远大于预期；SSL3 可追溯到 1999 年，浏览器已基本弃用旧版本，只应运行 TLS 1.2 与 1.3。（BSD Now EP378，[1087.84-1239.08]，L1）
- 证书生命周期与 ACME：长寿命证书使旧技术难以下线（需提前数年停止签发），短寿命证书则缩短密钥泄露窗口并强迫自动化续期；Let's Encrypt/ACME 以极短有效期“逼迫你做正确的事”，有银行甚至签发不足 24 小时的证书并每几小时续期推送；证书撤销受制于 CRL 体积与 OCSP 的拒绝服务风险，故证书越短、对证书的控制力越强。（BSD Now EP378，[1800.52-1974.68]，L1）
- TLS 拦截与安全语义批判：Lucas 详述以 Squid 等代理做 TLS 拦截时，代理用自签或受托证书把过期、自签的“坏”证书伪装成有效证书呈现给用户；他认识的一位 appliance 厂商故意保留自签警告，拒绝隐藏拦截事实；TLS 1.3 伪装成 TLS 1.2 以穿透中间盒，恰说明拦截设备中存在大量营销式“安全”话术。（BSD Now EP378，[1396.34-1547.64]，L1）
- Lucas 在 TLS 书开头抨击“security”一词已失去意义：它像“人人每天吃热巧克力圣代还永不长胖”的空洞承诺；他承诺除引言外全书不使用该词，只用机密性、认证等具体术语，并把自己的写作责任定义为解释 x509 为何如此、TLS 1.3 为何如此行事，而非诉诸“标准机构腐败”或“计算机都是错误”的默认解释。（BSD Now EP378，[1514.52-1701.54]，L1）
- Cashflow for Creators 的创作者经济：Lucas 写书公开其小企业现金流运营法，指出市面商业书面向开加盟店或雇百人的读者，而创意小企业无书可依；该书恰在疫情初期发布，他因早已备好灾难预案、立即压缩开支而挺过疫情，反观大企业（如达美航空）疫情首周即向政府索要百亿美元；小企业只能靠现金流预案自救，这本质上是把系统运维的灾难恢复思维移植到商业。（BSD Now EP378，[2087.66-2447.58]，L1）
- 疫情与未来计划：因会议取消、无法赴会售书签名，Lucas 改做一次性直接邮件售书并清理库存；他预计 2022 年才可能再见，且不愿仅为见面而旅行；未来计划包括 TLS 书、科幻小说 Drinking Heavy Water、DNS 书修订、小型 OpenBSD 书，以及把文件系统传入 bhyve 的 9PFS 及其“邪恶”。（BSD Now EP378，[2472.78-3157.94]，L1）
- Michael W. Lucas 介绍 FreeBSD Mastery: Jails 一书：区分 base jail 的 origin/derived 组件，提出 incomplete jail 概念，即 jail 是命名空间变换集合，可只做进程分组而不必限制文件系统与网络。（BSD Now EP293，[826.5-1092.8]，L1）
- Lucas 说明 jails 自 1998 年 PHK 首次提交代码以来，配置方式属部落知识，历经多代官方方式与易用方式更替；VNET 在 FreeBSD 12 成为默认，改变了 jail 网络能力。（BSD Now EP293，[448.38-761.02]，L1）
- 访谈提及 iocage 因其 ZFS 感知与插件机制被选为书中管理框架，其官方插件经过审计，可对比 Docker 容器；并提及 RunC 容器框架移植到 FreeBSD jail、可跨 OS 暂停迁移。（BSD Now EP293，[1408.58-1571.16]，L1）
- Michael W. Lucas 自述 Absolute FreeBSD 第三版（2018 年）因 FreeBSD 十年间特性大幅增长，删去 sendmail 与 Web 服务器配置等旧内容，新增 GEOM、ZFS、Poudriere、blacklistd 等主题；第二版基于 FreeBSD 7，第三版对应 FreeBSD 11 至 12 前后的变化。（BSD Now EP267，[1212.72-1245.12]，L1）
- Lucas 回忆第一本 Absolute FreeBSD 缘起于 No Starch 出版社 Bill Pollock 的约稿；此前他在 O’Reilly 撰写 BSD 专栏（Big Scary Daemons），将自学 disk label 与 slices 等主题的文章整理成书，属于自学者向技术写作的转化。（BSD Now EP267，[1900.86-1993.50]，L1）
- 访谈提出 BSD 在 1980 年代被宣告死亡后仍由一群狂热者延续；激进的新事物往往由一两人发起，如 Matt Dillon 与 DragonFly、Theo de Raadt 与 OpenBSD、Peter Wemm 将 FreeBSD 从 CVS 迁往 Subversion，并由此获得 AMD64 支持。（BSD Now EP267，[1667.54-1888.12]，L1）
- Brooks Davis 自述入圈经历：九十年代就读的高中收到 FreeBSD 创始人之一 David Greenman 捐赠的软盘路由器，大学后经 Luigi Rizzo 的 dummynet 重新入坑 FreeBSD 2.2，补丁多到令人厌烦而获得 commit bit，此后运营 FreeBSD 高性能计算集群、维护 GPS 卫星在轨系统。（BSD Now EP140，[1339.00-1437.00]，L1）
- CHERIBSD 是为支持研究处理器而做的 FreeBSD 分叉：基于 MIPS64 ISA 加空间与时间内存安全扩展，纯能力模式下彻底消除缓冲区溢出（SSH 编译后越界将触发硬件异常）；混合过渡模型允许未修改传统二进制与逐指针能力化并存，目标是有硅片后积极合并回 FreeBSD。（BSD Now EP140，[1444.00-1696.00]，L1）

- Backtrace 的 Sammy 介绍其事后调试平台：符号式调试二十年无人改进，其平台自动分析故障核心转储（调用栈签名分组、UMA 与 jemalloc 集成、无效指针与双重释放分类器），libkvm 优化把生成回溯的时间从两分钟降到一秒以内，极端客户案例由 GDB 二十分钟降至两三秒。（BSD Now EP140，[1994.00-2400.00]，L1）

- DuckDuckGo 2016 年 FOSS 捐赠以每项目两万五千美元资助 OpenBSD、自由新闻基金会 SecureDrop、Cryptech 开源硬件加密引擎、Tor、VeraCrypt 等，主题为“提高在线信任标准”；Larry the BSD Guy 自 FossForce 专栏退休。（BSD Now EP140，[3419.00-3560.00]，L2）

- 他介绍 sudo 是分割 root 权限的访问控制工具，写作 Sudo Mastery 源于用户普遍误用 sudo，且大量教程推荐了可被突破权限限制的不安全配置。（BSD Now EP10，[956.9-1167.1]，L1）
