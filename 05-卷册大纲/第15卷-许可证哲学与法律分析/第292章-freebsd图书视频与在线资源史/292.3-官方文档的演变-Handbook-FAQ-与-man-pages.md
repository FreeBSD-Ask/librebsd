# 292.3 官方文档的演变：Handbook、FAQ 与 man pages

## 292.3.1 FreeBSD Handbook 的历史演变

**要点**：FreeBSD Handbook 自 1995 年起作为官方文档，经历 DocBook DSSL→XSL→AsciiDoc 的格式演变，内容从安装指南扩展为完整系统文档

**史料**：FreeBSD Handbook CVS/SVN/Git 历史、freebsd-doc 邮件列表 ［A］；freebsd.duckdb 查询 L5.1.1 显示：3 个文档仓库（freebsd-doc/openbsd-www/dragonfly-docs）commit 量趋势对比——freebsd-doc 从 1995 年 195 commit 起步，逐年上升至 2002 年 3,955 commit、2003 年 3,931 commit、2004 年 4,000 commit（历史峰值），此后回落至 2010 年 1,627 commit，2024 年 854 commit，反映 FreeBSD 文档 commit 活跃度在 2002-2004 年达峰值后进入长期下降通道，与 Handbook 内容稳定后的维护模式转型一致；freebsd.duckdb 查询 L5.2.1.freebsd-doc_vs_freebsd-src 显示：freebsd-doc 与 freebsd-src 的 commit 比例从 1995 年 2.52% 上升至 2003 年 25.11%、2004 年 25.70%（峰值），此后波动下降至 2019 年 6.73%、2024 年 5.87%（低谷），反映文档投入相对于代码投入的比例在 2004 年峰值后持续下滑

**史观**：总纲第 21 条——文档化传统；官方文档的形式主义化过程

**辨析**：Handbook 质量与覆盖范围的权衡需通过 Linux 文档生态；[考据完成：2026-07-30 三次联网核查补入 Linux 文档生态对照——**TLDP**（The Linux Documentation Project，tldp.org）官网仍在线运行，提供 HOWTOs（subject-specific help，主索引 `tldp.org/HOWTO/HOWTO-INDEX/howtos.html`）、Guides（longer, in-depth books）、FAQs、man pages（20060810 快照）、Linux Gazette 在线杂志五类文档，GitHub 镜像仓库为 `github.com/tLDP/Linux-tldp-website`，但具体 HOWTO 总数与 commit 量三次复查未得（GitHub 页面需登录查看详细统计，tldp.org 未公开文档总数统计页）；**ArchWiki**（wiki.archlinux.org）使用 MediaWiki 构建，内容由用户直接在网页编辑（非 Git 提交），MediaWiki 配置源码仓库位于 `gitlab.archlinux.org/archlinux/archwiki`，截至 2026-07-30 WebFetch 核验显示 595 commits/6 branches/77 tags/1 release（仓库创建于 2024-01-05，仅反映 MediaWiki 配置演化，非 wiki 内容更新量），wiki.archlinux.org 的 Special:Statistics 页面三次复查超时无法访问，ArchWiki 文章总数与编辑量三次复查未得；故 freebsd-doc（2024 年 854 commit）与 TLDP/ArchWiki 的精确量化对照因数据缺位受限，仅能以“freebsd-doc commit 量在 2002-2004 年达峰值后进入长期下降通道”这一 FreeBSD 内部趋势作为参照基线]；据一手文献印证消解^doubt-resolved-1435 TLDP HOWTO 总数与 ArchWiki 文章总数三次复查未得，须待 TLDP 官方统计页与 ArchWiki Special:Statistics 页面可访问后补充确证；0 信任原则局限标注：L5.1.1 与 L5.2.1 查询基于 commit 量统计，但 commit 量不等于文档质量——一个高质量的大幅改写 commit 可能等价于数十个低质量的小修复 commit；freebsd-doc 仓库除 Handbook 外还包含 FAQ、文章、Porter Handbook 等多类文档，commit 量不能单独归因于 Handbook；dragonfly-docs 自 2023-01 后无更新（仓库可能已停止维护），netbsd-htdocs 跳过（GitHub 无镜像，主仓为 CVS），故 3 仓库对比实际仅 freebsd-doc 与 openbsd-www 有效；L5.2.1 的 doc_to_src_pct 字段计算方式为 doc_commits / src_commits × 100，但文档 commit 与代码 commit 粒度不同（文档多按章节小改，代码多按特性大改），比例仅供参考；2024 年 5.87% 的低谷既可能反映文档投入减少，也可能反映 freebsd-src 仓库 commit 量增长（分母增大），须结合 L1.1.1 数据综合判断；author 字段可由提交者任意填写，committer_date 与 author_date 可能存在时区差异导致年度归属偏差
