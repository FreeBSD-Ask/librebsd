# 316.1.1 OpenSSH 的诞生与全球采用

**要点**：OpenSSH 由 OpenBSD 项目于 1999 年 9 月 26 日从 Björn Grönvall 的 OSSH（其本身 fork 自 Tatu Ylönen 的 SSH 1.2.12 最后自由版本）import 入 OpenBSD 源代码树，1999 年 12 月 1 日随 OpenBSD 2.6 正式发布；创始团队为 Theo de Raadt（西奥·德·若特）、Niels Provos（尼尔斯·普罗沃斯）、Markus Friedl（马库斯·弗里德尔）、Bob Beck、Aaron Campbell、Dug Song；许可证为 BSD、ISC 与公共领域的混合；OpenSSH 此后被 Linux 发行版、macOS、Windows 10（1803 起 OpenSSH 客户端内置）、Solaris、AIX 等几乎所有现代操作系统采用，成为 SSH 协议事实标准实现；portable 版本由 Damien Miller（达米安·米勒） 等维护，独立于 OpenBSD 基本系统但同步演化

**史观**：BSD 与 UNIX 谱系的连续性：OpenSSH 是 BSD 项目反哺全球 UNIX 谱系的典型案例；商业与社区的张力：OpenSSH 以宽松许可证扩散，商业公司免费取用

**辨析**：OpenSSH 是否真由 OpenBSD “主持” 存在争议——portable 分支独立于 OpenBSD 基本系统维护，OpenBSD 仅控制基本系统中的版本；需通过 openssh.org 与 portable 仓库的 commit 历史核实；Ylönen 后期 SSH 商业化是否构成 “许可证污染” 须查 SSH Communications Security 历年许可证文本
