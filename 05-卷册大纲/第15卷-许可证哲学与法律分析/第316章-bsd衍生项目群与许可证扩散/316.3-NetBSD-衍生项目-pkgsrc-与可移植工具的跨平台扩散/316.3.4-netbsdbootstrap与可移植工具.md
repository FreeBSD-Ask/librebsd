# 316.3.4 NetBSD bootstrap 与可移植工具

**要点**：NetBSD 长期维护一套 bootstrap 工具集（tools/ 目录），用于在新平台上从零启动编译 NetBSD 基本系统；该工具集设计为可移植，包含 gcc、binutils、make 等工具的封装；NetBSD 还维护一系列可移植库（libuuid、libbsd 等）被其他 BSD 项目采用；NetBSD “可移植优先” 的工程哲学使其工具集成为 BSD 阵营共享基础设施

**史料**：netbsd.org/docs/guide/en/chap-build.html、NetBSD src/tools/ 目录、NetBSD 邮件列表 porting 讨论 ［A］

**史观**：技术选择的代价：NetBSD 可移植工具集带来工程复杂度；BSD 与 UNIX 谱系的连续性：NetBSD 工具集延续 UNIX 可移植传统

**辨析**：bootstrap 工具集的具体组成须查 NetBSD src/tools/ 当前版本；“被其他 BSD 项目采用” 的范围须逐项目核实
