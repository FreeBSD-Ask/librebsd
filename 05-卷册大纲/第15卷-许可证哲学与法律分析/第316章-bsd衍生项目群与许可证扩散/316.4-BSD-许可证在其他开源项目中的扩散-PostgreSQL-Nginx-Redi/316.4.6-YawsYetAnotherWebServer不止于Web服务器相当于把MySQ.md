# 316.4.6 YawsYetAnotherWebServer不止于Web服务器相当于把MySQ

- Yaws（Yet Another Web Server）不止于 Web 服务器：相当于把 MySQL、PHP 与 Apache 合为一个紧耦合套件——以 Erlang 取代 PHP、以 Erlang 内置数据库 Mnesia 取代 MySQL；支持虚拟主机、SSL 等常规特性，核心卖点是以极高速度生成动态内容——在他看来当今站点皆动态、皆 Ajax，商业与银行等高要求站点性能需求极高，其动态内容速度极限推迟了购置昂贵负载均衡器、搭建多主机与三层架构的需要；另一独特之处是专为嵌入而生：既可编译为以守护进程方式启动的常规服务器，也可嵌入更大的 Erlang 应用——电信设备、路由器等需要内置 Web 服务器提供 Web GUI 的场景正对其胃口。（BSDTalk EP62，[55.24-291.36]，L1）
- 性能来自 Erlang 语言而非其编程：每个客户端连接在内部对应一个 Erlang 进程；Erlang 是对并发有极佳支持的函数式语言，代码运行于类似 Lisp 机或 Java 运行时的虚拟机中，进程伪并发执行；进程初始占用极小（转写作约 64 字节量级）并随执行动态增长、由垃圾回收器收缩，数十万进程可行；每套接字归一个进程所有，没有主事件循环与状态机分发——编程范式因此彻底改变，无须手工数据结构、分发器与事件循环；语言与网页紧耦合、无外部进程分叉，作者自信动态内容生成难以更快（虽无与 PHP 的对比数字）。（BSDTalk EP62，[333.96-460.2]，L1）
- YAWS 页面惯用法与 PHP 相同：HTML 中内嵌 Erlang 标签；页面首次被请求时由服务器即时编译，此后以目标代码驻留内存、静态部分作为静态缓冲注入编译代码的动态输出流——首取慢而后续极快。（BSDTalk EP62，[466.68-542.44]，L1）
- 连接数上限不在 Yaws 而在操作系统：各 Unix 限制不同，需要数万套接字的站点须调整内核或 sysctl 变量；他提醒不过十年前 SCO Unix 每进程仅 64 套接字且不可调——操作系统对连接数的约束史即服务器扩展史。（BSDTalk EP62，[549.72-596.68]，L1）
- Erlang 的学习门槛与范式转换：语言本身极小、构造简单，有函数式编程或计算机科学背景者更易上手；顺序部分语义与 Lisp 系语言相近，而并发与分布部分对常规程序员陌生——进程极多且创建极易、代码不区分进程在本地还是远程执行（网络编组透明）；正确做法是为现实中每个并发活动建一个进程，套接字即典范，而非构建事件循环与分发器。（BSDTalk EP62，[596.68-705.4]，L1）
- Erlang 诞生史：作者是四位原创作者之一，曾撰写语言的 I/O 系统、垃圾收集器与分布部分；1990 年代 Ericsson 研究实验室受命革新电信应用编程——其程控交换机素以专有语言 PLEX 编程，Erlang 在经历诸多语言尝试后从该实验室生长出来；约十年前决定开源，时间恰在 Netscape 公开浏览器源码之后：大公司敢于如此行事的事实，成为技术人员说服中高层管理层的最后论据，否则 Erlang 将沦为无人问津的专有技术；此后增长在他看来慢得可笑，但 Erlang 在建站与大型复杂并发应用技术上仍居首位。（BSDTalk EP62，[705.4-858.64]，L1）
