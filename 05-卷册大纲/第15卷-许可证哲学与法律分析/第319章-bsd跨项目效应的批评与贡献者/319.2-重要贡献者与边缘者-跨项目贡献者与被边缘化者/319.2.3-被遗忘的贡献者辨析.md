# 319.2.3 被遗忘的贡献者辨析

**要点**：BSD 跨项目贡献中存在被遗忘的贡献者——Björn Grönvall（OSSH 创建者，OpenSSH fork 的源头，1999 年初重新发现 Tatu Ylönen 的 SSH 1.2.12 最后自由版本并修复漏洞，但 OpenBSD 项目成员在 OpenBSD 2.6 发布前不到两个月才发现其工作，随即 fork 为 OpenSSH，Grönvall 此后逐渐淡出，其 OSSH 仅支持 SSH 1.3 协议且“可能在 OpenSSH 成熟后停止了开发”）在 OpenSSH 历史中长期被边缘化；Anders Berg（Varnish 项目发起者，VG 系统管理员，2005 年撰写项目规格书，自述“我是一个思考者而非执行者——我想出了 Varnish Cache 的想法，但执行者是其他人”）在 Varnish 历史中被 PHK 名声掩盖；Anders Nordby（Aftenposten 系统管理员，Varnish 项目的关键连接者——Berg 通过 Nordby 认识 PHK，Nordby 建议“找一个内核开发者”并推荐了 PHK，Varnish Software 官方历史明确记载 Nordby 参与项目启动）在 Varnish 叙事中几乎完全被遗忘；Dag-Erling Smørgrav（FreeBSD 提交者与安全官，2005 年底在巴塞尔 EuroBSD 会议上将 PHK 拉到一旁提出了 Varnish 项目构想，当时任 Linpro 顾问，后担任 FreeBSD Varnish port 维护者）在 Varnish 历史中更多被视为“连接者”而非“开发者”；Luke Mewburn（NetBSD rc.d 设计者，Wasabi Systems 工程师，USENIX ATC 2001 FREENIX Track 论文作者）在 rc.d 跨项目扩散中较少被归功；这些被遗忘的贡献者反映 BSD 跨项目叙事中的“明星效应”——项目创始人被铭记，协助者、连接者与早期推动者被遗忘

**史料**：OpenSSH 官方历史（openssh.org/history.html，明确记载“OpenBSD 项目成员在 OpenBSD 2.6 发布前不到两个月才得知 Björn 的工作”与“Björn 可能在 OpenSSH 成熟后停止了开发”）、Varnish Software 官方历史（varnish-software.com/varnish-history/，明确记载 Anders Nordby 参与项目启动）、Anders Berg 2016 年 Q&A（varnish-software.com/blog，自述“thinker, not a doer”与 Nordby 推荐 PHK 的细节）、PHK 2016 年 Q&A（varnish-software.com/blog，自述“DES 在 EuroBSD 会议上把我拉到一旁”）、Mewburn USENIX 2001 论文“The Design and Implementation of the NetBSD rc.d System”（署名机构 Wasabi Systems, Inc.）、NetBSD rc.d(8) 手册页（"The /etc/rc.d support was implemented in NetBSD 1.5 by Luke Mewburn"）、FreeBSD 提交者指南中 DES 条目（曾任 FreeBSD 安全官）、FreeBSD Bugzilla Varnish port 维护记录（des@ 为维护者） ［A］

**史观**：边缘者贡献：被遗忘的贡献者反映 BSD 跨项目叙事的明星效应；0 信任原则：被遗忘的贡献者辨析需通过考据程序验证

**辨析**：每位被遗忘贡献者的具体贡献须逐个核实——Grönvall 的 OSSH 与 OpenSSH 的关系经 openssh.org 官方历史核实（“fork from the OSSH release”）；Berg 的“发起者”角色经 Varnish Software 官方历史与自述 Q&A 双重印证；Nordby 的关键连接者角色经 Berg 自述与 Varnish Software 官方历史双重印证；DES 的“连接者”角色经 PHK 自述核实（"Dag-Erling Smørgrav pulled me aside at a EuroBSD conference in Basel and suggested it"）；Mewburn 的 rc.d 设计者角色经 NetBSD **rc.d(8)** 手册页与 USENIX 论文双重印证；“明星效应”的判断须避免过度解读——部分被遗忘源于贡献可见度差异而非纯粹叙事偏差
