# 319.1.104 DanielBaluta在TCP多端口绑定修复问题的回复中转述GasparChi

Daniel Baluta 在 TCP 多端口绑定修复问题的回复中转述 Gaspar Chilingarov（非 Kirill）的用户反馈，该用户称因绑定问题在生产环境中转向 FreeBSD 作为网络栈扩展性更好的替代方案："moved production code to FreeBSD as it has better scalable network stack."
