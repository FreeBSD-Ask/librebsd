# 319.1.76 JamesMorris评审NFSv3XATTR侧带协议RFC认为NFSv4命名属

James Morris 评审 NFSv3 XATTR 侧带协议 RFC, 认为 NFSv4 命名属性与 Linux/BSD xattr 模型不相容——“They're filesystems within files, with different semantics to the name/value string model that we use.”,并以命名空间作为关键分歧点:“named attributes have no structured namespace, whereas, Linux/BSD xattrs use namespaces to denote semantics.”;他另举 “system.posix_acl_access” 会与本地 ACL 存储机制相冲为例。
