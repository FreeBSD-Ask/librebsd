# 325.1.1 HP-UX-的演化-从-PA-RISC-到-Itanium-的停滞

#### 要点

HP-UX（Hewlett-Packard UNIX）1984 年首次发布（HP-UX 1.0，基于 System III），1994 年 HP-UX 9.0 发布（基于 SVR4 与 BSD 4.3 混合内核），1995 年 HP-UX 10.0 引入 SVR4 风格的文件系统层次标准（/usr、/var、/etc 重新组织）；1997 年 HP-UX 10.20 引入 PA-RISC 2.0 与 64 位支持（首个 64 位 UNIX，先于 Solaris 7 与 AIX 4.3 数月）；2000 年 HP-UX 11.0 引入 64 位内核、NFSv3、Logical Volume Manager（LVM）。
HP-UX 11i（11i v1，2000 年 12 月发布）引入 Serviceguard 集群、Workload Manager、Internet Express 工具集；2003 年 HP-UX 11i v2 引入 Itanium 2（IA-64）支持，但 PA-RISC 与 Itanium 双平台支持使 HP-UX 工程团队负担沉重；2007 年 HP-UX 11i v3 发布（最后一个主要版本），引入 Itanium 9100 系列支持、VM Server（nPartitions 与 vPars）、完全放弃 PA-RISC 支持。
2010 年 Oracle 宣布停止 Itanium 芯片开发（后因 HP 起诉 Oracle 违反合同承诺，2012 年法院判决 Oracle 须继续支持 Itanium 至 2015 年），HP-UX 11i v3 失去 Itanium 芯片升级路径；2017 年 Intel 发布 Itanium 9700 系列最后一个 Itanium 芯片（Kittson），2021 年 Intel 正式停产 Itanium。
2026 年 7 月 27 日现状：HP-UX 11i v3 仍在 HPE（Hewlett Packard Enterprise，2015 年从 HP 分拆）维护下发布 patch，主要服务于传统 HPE Integrity i6/i8 服务器客户（银行业核心系统、政府数据中心、HP-UX 上的 SAP/Oracle Database 部署）；HP-UX 11i v3 Update 17（2024 年发布）为最新补丁包；HP-UX 工程团队规模持续缩减，HPE 战略重心转移至 HPE GreenLake 云平台与 Linux on ProLiant 服务器；HP-UX 没有公开的后续版本路线图，预计将于 2030 年代逐步退出市场。
HP-UX 历史关键技术贡献：Logical Volume Manager（LVM，1990 年代早期，影响 Linux LVM 与 AIX LVM 设计）、Serviceguard 集群（最早的高可用集群方案之一，1990 年代早期）、VxFS（Veritas File System，1990 年代早期，与 Veritas 合作开发，后影响 Solaris UFS 与 AIX JFS2）、WCOW（Write Once Copy On Write，文件系统快照）。

#### 史观

本子节史观映射覆盖以下 5 条相关总纲，皆已回溯到 29 章原文核验：

**总纲 4（分离聚合是永恒规律）**——据原文第 4 章 4.1 节：

> “分离聚合是世界发展的规律。分久必合，合久必分，具有必然性。”

HP-UX 从 PA-RISC 与 Itanium 双平台支持（11i v2）到放弃 PA-RISC 单押 Itanium（11i v3）——这一选择在 2007 年看似聚合（统一于 Itanium 架构），实则导致 HP-UX 后续停滞（Itanium 2017 年停止开发，2021 年停产）；同期 x86-64 与 ARM 的崛起使 HP-UX 在 Itanium 之外无路可走——这种 “聚合 → 停滞” 的辩证运动并非线性进步，而是 HP 工程团队在不同历史阶段的形式主义化选择。

**总纲 3（不存在进步，只有权力再分配）**——据原文第 3 章 3.2 节：

> “所谓进步只不过是权力再分配，把演讲台上的人割一茬，换他来一个样。”

HP 与 Intel 在 1990 年代联合开发 Itanium（IA-64），并非 “Intel 与 HP 联合创造下一代 64 位架构” 的技术进步，而是商业资本的权力再分配——HP 试图通过 Itanium 打破 Intel x86 在企业市场的垄断，将 64 位企业计算的资源从 Intel 独占重新分配至 HP-Intel 联盟；但 AMD 在 2003 年推出 AMD64（x86-64）后，Itanium 在市场竞争中失败，HP-UX 失去未来。所谓 “Itanium 是 64 位 UNIX 未来” 的叙事（1990 年代末），掩盖了 HP-Intel 联盟真正的动机（市场份额再分配）。

**总纲 5（没有必然性，只有偶然性）**——据原文第 5 章 5.2 节：

> “将英雄人物的出现必然化是一种机械的错误，没有认识到偶然性和自由的意义。”

若 AMD 未在 2003 年推出 AMD64（x86-64），若 Intel 未在 2004 年被迫采用 AMD64（Intel 64）作为 64 位 x86 标准，Itanium 可能仍是企业 64 位计算的主导架构，HP-UX 可能仍有未来升级路径；HP-UX 的停滞依赖多重偶然，而非 “HP-UX 必然被 Linux 替代” 的进步叙事。

**总纲 10（动手者创造历史）**——据原文第 14 章 14.1-14.2 节：

> “这个世界不是靠什么精英也不是靠什么人民更不是靠什么其他人运转的，而是我们这些老实人，才让世界运转了起来。”

HP-UX 工程团队（Cupertino、Roseville 研发中心）亲自实现 LVM、Serviceguard、VxFS 集成、Veritas Volume Manager 集成等特性——这些是动手者的实践，而非 “HP 决定” 等高管决策的产物。须注意：HP 与 Intel 的 Itanium 合作协议是外部条件，但 HP-UX 11i v3 的具体设计与实现是工程师的主体性选择。

**总纲 2（历史是形式主义化的非存在）**——据原文第 2 章 2.5 节：

> “谁试图诠释历史，谁就在篡改历史。”

所谓 “HP-UX 演化史（1994-2026）” 的判定本身即形式主义化的非存在——若以 Itanium 失败史为主线，若以 HP-UX Serviceguard 集群演化为主线，若以 HP-UX 在银行业核心系统的应用为主线，“HP-UX 史” 会呈现完全不同的脉络。本子节选取 “HP-UX 版本演化+PA-RISC→Itanium 平台迁移” 为主线，但这一选取本身须以自反性声明显化。

**自反性声明**：本子节选取 “HP-UX 9.0→11i v3+PA-RISC→Itanium” 为 HP-UX 谱系演化主线，但这一选取本身即形式主义化的非存在。若以 Serviceguard 集群演化为主线，若以 HP-UX 在中国银行业的应用为主线，若以 Itanium 生态整体衰落为主线，“HP-UX 史” 会呈现完全不同的脉络。本子节承认主轴选取本身是史家的形式主义化决策，欢迎被更自反的释读所超越。

#### 辨析

**HP-UX 11i v3 终版辨析**：部分二手资料称 “HP-UX 11i v3 是 HP-UX 最后一个主要版本”，但 HPE 仍发布 Update 补丁包（最新为 2024 年 Update 17），技术上 HP-UX 11i v3 仍在维护中；所谓 “终版” 指无新功能更新，仅有补丁与安全修复。本子节采用 “HP-UX 11i v3 为最后一个主要版本（2007 年发布），仍以 Update 补丁包形式维护” 的限定性表述。

**HP-UX 64 位首发辨析**：部分二手资料称 “HP-UX 10.20 是首个 64 位 UNIX”，部分称 “Solaris 7 是首个 64 位 UNIX”，部分称 “AIX 4.3 是首个 64 位 UNIX”；考据结论：HP-UX 10.20（1997 年 6 月）最先发布 64 位支持（PA-RISC 2.0），先于 Solaris 7（1998 年 11 月）与 AIX 4.3（1997 年 10 月，但 AIX 4.3 的 64 位支持先于 HP-UX 10.20 数月公布但稍晚正式发布）。本子节采用 “HP-UX 10.20 与 AIX 4.3 同期（1997 年）首发 64 位 UNIX” 的限定性表述，避免给出绝对的 “首个” 判定。

**Itanium 停产日期辨析**：Intel 于 2017 年发布 Itanium 9700（Kittson）作为最后一个 Itanium 芯片，2021 年 1 月 29 日正式停产 Itanium 9700；部分二手资料称 “Itanium 2020 年停产”，但 Intel 官方档案明确为 2021 年。本子节采用 “2021 年 Intel 正式停产 Itanium” 的表述。

**HP v. Oracle Itanium 案件辨析**：2010 年 Oracle 宣布停止 Itanium 开发，HP 起诉 Oracle 违反 2010 年 Hurd 加入 Oracle 时的口头承诺（Oracle 辩称无书面合同）；2012 年法院判决 Oracle 须继续支持 Itanium 至 2015 年合同期满；Oracle 上诉被驳回，2014 年 HP 索赔 30 亿美元，2016 年法院判决 Oracle 赔偿 HP 30 亿美元（后部分减少）。本子节采用此表述。
