# 320.1.2 GNU 项目对其他开源项目的效应对比

**要点**：GNU 项目通过 GPL 工具链（GCC、glibc、bash、coreutils、Emacs 等）影响其他开源项目；GNU 工具链长期是 Linux 发行版默认工具链，也是 BSD 项目早期默认工具链（后被 Clang/LLVM 替代）；GNU 项目跨项目影响以“工具链基础”见长，BSD 跨项目影响以“许可证与设计”见长；GNU 与 BSD 的影响重叠于工具链领域（GCC vs Clang、coreutils vs BSD 工具等）

**史料**：GNU 项目官网（gnu.org）、GCC 历史、Emacs 历史、BSD 与 GNU 工具链替换史（参见相关章节）［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］〔L3 官方文档与公告〕

**史观**：许可证：GPL 与 BSD 在工具链领域的竞争；BSD 与 UNIX 谱系的连续性：GNU 与 BSD 同源于 UNIX

**辨析**：GNU 工具链在 Linux 中的“默认”地位是否变化须查当前主流发行版；GCC 与 Clang 的市场份额须查独立统计；“工具链基础”影响的量化须避免简单化
