# 296.6 illumos 与 BSD/UNIX 谱系的比较与史观审视（2010-2026）

#### 要点

illumos 在 UNIX 谱系中的位置：CDDL 许可证、System V 血统（Solaris 10 继承 SVR4 与 BSD 4.x 混合内核）、ZFS/DTrace/Zones 技术遗产，与 BSD 系（BSD 许可证、CSRG 血统）和 Linux 系（GPL、Linus 治理）构成 UNIX 三大开源谱系；illumos 的社区规模远小于 FreeBSD（illumos-gate.db 23,184 条 commit vs freebsd.db 3083MB commit 数据），但技术密度高（ZFS/DTrace 是现代操作系统的标志性组件）；项目统摄史观要求：本书 BSD 主线叙事须自觉对照 illumos 这一“非 BSD 的 UNIX 开源路径”，避免把“自由软件”简化为 BSD/GPL 二元叙事。

#### 辨析

illumos 与 BSD 的技术血缘须精确：Solaris 内核本身即 SVR4 与 BSD 4.x 的混合（SunOS 4.x 基于 BSD 4.3，SunOS 5.x 基于 SVR4），因此 illumos 间接携带 BSD 代码遗产，但法律与治理上完全独立于 BSD 项目；quekou.md C1 建议将 illumos 归入第 15 卷（当代 UNIX 史）而非第 13 卷（BSD 衍生 OS），正是基于这一血缘判断——illumos 是 UNIX 谱系而非 BSD 衍生。**存疑**：phoronix_news.db 的 illumos 新闻覆盖存在媒体采样偏差，反映的是技术媒体的报道偏好而非社区真实规模。
