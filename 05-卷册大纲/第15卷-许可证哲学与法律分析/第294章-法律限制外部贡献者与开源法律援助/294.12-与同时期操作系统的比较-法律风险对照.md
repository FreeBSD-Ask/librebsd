# 294.12 与同时期操作系统的比较——法律风险对照

## 294.12.1 与 Linux 出口管制经历的对照

**要点**：Linux 同样受 ITAR/EAR 影响，1990 年代含加密代码的 Linux 内核需镜像分拆（如 kernel.org 与 non-US 镜像），与 FreeBSD 的 crypto 分支分拆形成同期对照

**史料**：kernel.org 历史档案、Debian non-US 镜像档案、Linux crypto 邮件列表 ［A］

**史观**：总纲第 6 条——技术路线分化，Linux 与 BSD 在出口管制应对上分化为不同镜像策略

**辨析**：Linux 与 BSD 镜像分拆策略的实际效果差异需通过部署统计

**文献**：kernel.org 档案；Debian non-US 档案；Linux crypto 邮件列表 ［A］

## 294.12.2 与 Solaris CDDL 许可证的法律边界对照

**要点**：Solaris 2005 年开源采用 CDDL（弱 copyleft），与 BSDL 在文件级与模块级 copyleft 边界上不同，CDDL 模块化设计便利商业整合但限制衍生作品许可证选择

**史料**：CDDL 文本、Sun Microsystems 开源公告、OpenSolaris 档案［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］〔L3 官方文档与公告〕

**史观**：总纲第 24 条——许可证，CDDL 与 BSDL 在 copyleft 边界上的核心差异

**辨析**：CDDL 模块化设计是否“促进”商业整合存在争议，Oracle 收购后 OpenSolaris 闭源

**文献**：CDDL 文本；Sun 开源公告；OpenSolaris 档案［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］

## 294.12.3 与 Windows NT 商业许可证模式的法律边界对照

**要点**：Windows NT 采用专有 EULA，无开源义务但需逐机授权，与 BSD 商业用户（如 Apple macOS、NetApp Data ONTAP）的法律边界不同；BSD 衍生产品可内嵌于专有产品但需保留归属条款

**史料**：Microsoft EULA 文本、Apple macOS 归属声明、NetApp ONTAP 文档［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］〔L3 官方文档与公告〕

**史观**：总纲第 24 条——许可证，专有 EULA 与 BSDL 在归属义务上的核心差异

**辨析**：BSD 衍生产品的归属义务是否实际执行需通过案例

### 史观映射

> 法律是技术世界的另一种形式主义——它不是对技术现实的反映，而是一种独立的建构，以其自身的逻辑规范着技术的可能性空间；从加密出口管制到 DMCA 反规避条款，从软件专利到许可证可执行性判例，法律框架以形式主义化的方式划定技术创新的边界，而 BSD 项目正是在这些法律的形式主义夹缝中不断寻找生存与发展的可能性
