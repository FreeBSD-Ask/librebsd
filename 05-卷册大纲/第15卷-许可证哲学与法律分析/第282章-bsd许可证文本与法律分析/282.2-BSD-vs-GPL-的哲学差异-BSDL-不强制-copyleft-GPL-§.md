## 282.2.1 copyleft 与非 copyleft 条款对比

**要点**：**GPL §5** 要求分发修改后的完整对应源代码，**BSDL** 无此要求，二者构成 **copyleft** 与非 **copyleft** 的根本分歧。

  |---|---|---|
  | 修改后源码披露 | 不要求 | 要求（§5） |
  | 衍生作品许可 | 自由选择 | 须同许可 |
  | 商业闭源 | 允许 | 禁止 |
  | **copyleft** 机制 | 无 | 有 |

- 主持人列举 BSD 的使用图景：Apple 借采用 BSD 工具使其成为最流行的桌面 Unix；Yahoo 以 FreeBSD 驱动大部分前后端 Web 服务器；Hotmail 被微软收购前全站运行 FreeBSD。他谨慎处理 Hotmail 迁移 Windows 过渡困难的传闻，表述为任何该规模迁移皆困难；该传闻长期流传但缺乏微软工程资料佐证，引用须交叉核证。[存疑脚注] 系主持人二手转述的市场传闻。　[存疑脚注] Hotmail 迁移困难之说为社区传闻，主持人自述为 I believe 层面，需与微软迁移工程资料交叉核证。（BSDTalk EP1，[320.64-381.00]，L2）

**史观**：

- 总纲13 法律与道德是利益分配：“告别 GPL”论断的核心是把许可证还原为利益分配装置：copyleft 的道德叙事在 MongoDB、Elastic 等厂商手中显形为阻止云厂商搭便车的商业工具，许可证之争的本质由此成为软件利益结构的再分配之争。（BSD Now EP402，[403.02-432.58]，L2）
- 总纲3 不存在进步，只有权力再分配：主持人以“不可能拿到一个不含 BSD 代码的专有 SDK”反驳 GPL 阵营的道德话语，指出宽松分发实际改变了软件权力的分布；两种许可证路线的消长并非技术进步，而是分发权力结构的再平衡。（BSD Now EP402，[623.42-669.34]，L2）
- 总纲5 没有必然性，只有偶然性：UTF-8 的诞生史是偶然性改写标准的典型案例：编码方案在餐馆餐垫上于一夜成形，一周内完成全系统实现，这一无预谋的偶然设计此后支撑起整个互联网的文本层。（BSD Now EP402，[2236.8-2268.02]，L1）
- 总纲10 动手者创造历史：Warner Losh 数年维护 bsd-user、自嘲“最后的孤注一掷”式目录拷贝并以 Blitz/Kaizen 分支推进上游化，展示了动手者叙事：决定 FreeBSD 交叉构建生态存续的不是路线图，而是个别工程师对数千补丁的持续清理。（BSD Now EP402，[1254.24-1335.08]，L1）
- 总纲1 一切真历史都是古代史：Xenix 回忆与散伙饭上的时间线考据表明，微软 Unix 史的书写必须回到“古代”档案与当事人记忆中重构；当下对 Xenix 的普遍误解正源于这段历史长期无人书写。（BSD Now EP402，[919.42-1232.8]，L2）
- 总纲10 动手者创造历史：一名独立承包商利用工作间隙完成的个人优化，经偶然的网络传播被 Google 相中，其成果进入开放上游并成为 Android 视频能力的基础：行业的公共底座正是由这类动手者的具体劳作层层垒成，而非由战略规划生成。（BSDTalk EP189，[903.06-909.78]，L1）
- 总纲5 没有必然性，只有偶然性：ARM 从资金窘迫的 Acorn 偶然诞生，此后多年默默嵌入 3DO、PlayStation 等设备而不为人知，直到 iPhone、iPad 一代设备的爆发才走向舞台中央；当事人自陈只是幸运地搭上自己使用二十年的平台突然崛起，其间并无必然的进步逻辑。（BSDTalk EP189，[1067.06-1094.82]，L1）
- 总纲8 本体论上各方平等：总纲8 本体论上各方平等：Losher 明言十三家根运营者间须维持操作系统、硬件与名字服务器软件的多样性——没有人主张 FreeBSD 或 BIND 是唯一正确选择，ISC 亦同时杂用 Linux 与 Windows；多样性被制度化为互联网基础设施的抗脆弱策略，而非某一方的正统性叙事。（BSDTalk EP206，[458.54-505.52]，L1）
- 总纲13 法律与道德是利益分配：总纲13 法律与道德是利益分配：Losher 解释 ISC 许可证的价值在于给商业组织以确定性——集成后不强制开放修改源码，回馈与否“留给最终用户决定，不是自上而下强制”；许可证在此并非道德宣言而是利益分配装置，它决定了 Sun、HP、IBM 等厂商是否愿意资助 BIND 9。（BSDTalk EP206，[301.24-341.92]，L1）
- 总纲8 本体论上各方平等：McKusick 对竞争格局的判断建立在一个历史类比与一个生态学论证上：当年 PC 被讥为小、弱、难用，却因比大型机便宜十倍而被人找到用法，终至 PC 为王、大型机退居利基——开源相对专有软件正是同样的成本结构，IBM 弃自有操作系统拥抱 Linux、Oracle 访谈当周宣布收购 Sleepycat 并酝酿再购两家开源厂商皆是征兆，Linux 将取代 Windows 的主导地位而 Windows 不会消失；他又论证 Windows 的根本弱点在于它是横跨八成机器的单一一致目标，一个病毒即可通吃，计算生态需要遗传多样性，BSD 的价值恰在于既不是 Linux 也不是 Windows——小到病毒作者不感兴趣、久经岁月而足够防弹，装机数百万、缓慢增长，永不称王却是生态中不可替代的一极。（BSDTalk EP18，[847.61-1111.83]，L1）
- 总纲13 法律与道德是利益分配：McKusick 特别纠正了开源回馈的道德化叙事：厂商向伯克利回赠大量代码并非出于利他，而是每次新版发布都须重新合并自有改动的成本压力使然，把改动交回上游后改动随发行物一起维护反而省力——所谓社区美德话语之下运行的是赤裸裸的利益核算。（BSDTalk EP18，[509.95-525.89]，L1）
- 总纲4 分离聚合是永恒规律：主持人叙述 OpenBSD 分叉自 NetBSD 缘于开发者冲突、DragonFly BSD 分叉自 FreeBSD：BSD 谱系以分离与聚合的循环展开，分离既是治理冲突的结果，也成为生态定位分化（可移植、安全、流行度）的方式。（BSDTalk EP1，[449.47-465.62]，L2）
- 总纲13 法律与道德是利益分配：主持人把 GPL 与 BSD 许可证之争归结为对自由的定义分歧——GPL 以版权机制强制回馈社区，BSD 许可证允许商业封闭但不要求回馈——并拒绝裁决孰更自由，视之为利益分配方式的分野而非道德高下。（BSDTalk EP1，[248.96-319.38]，L2）
