# 282.1 BSD 许可证文本的法律分析——BSD 二条款/三条款/四条款许可证的演变

## 282.1.1 BSD 2/3/4-Clause 文本演变

**要点**：**BSD 4-Clause** 原始版含广告条款，1999 年 7 月 22 日 **William Hoskins** 在 **Berkeley** 官方公告中宣布弃用广告条款，演进为 **3-Clause “New BSD”**；两条款简化版（**2-Clause “Simplified BSD”**，即 FreeBSD 许可证文本）系 1990 年代 **FreeBSD** 项目文档采用的版本——“2006 年简化”之说与“FreeBSD 早期采用”两个时点须区分，OSI 批准与 SPDX 收录时点待考〔存疑：2-Clause 的 OSI 批准/SPDX 收录确切年份待核——2026-09-12 整改，批次 C222 问题 2〕。三版许可证英文全文见下方引文块。

> **BSD-2-Clause（Simplified）**：Redistribution and use in source and binary forms, with or without modification, are permitted provided that the following conditions are met: 1. Redistributions of source code must retain the above copyright notice, this list of conditions and the following disclaimer. 2. Redistributions in binary form must reproduce the above copyright notice, this list of conditions and the following disclaimer in the documentation and/or other materials provided with the distribution.
>
> **BSD-3-Clause（New）**：在 2-Clause 基础上增加第 3 条：Neither the name of the organization nor the names of its contributors may be used to endorse or promote products derived from this software without specific prior written permission.（即 endorsements clause）
>
> **BSD-4-Clause（Original）**：在 3-Clause 基础上再增加广告条款（All advertising materials mentioning features or use of this software must display the following acknowledgement…），1999-07-22 经公告删除。（2026-09-12 整改：原 H1 内嵌的三版英文全文移入此处引文块）

  （下表系本行要点的表格化对照——2026-09-12 整改加互见，批次 C222 问题 11）

  | 许可证版本 | 条款数 | 关键特征 | 时间 |
  |---|---|---|---|
  | **BSD 4-Clause** | 4 | 含广告条款 | 1980 年代起 |
  | **BSD 3-Clause “New”** | 3 | 弃用广告条款 | 1999.7.22 起 |
  | **BSD 2-Clause “Simplified”** | 2 | 移除背书条款 | FreeBSD 早期采用（1990 年代）；OSI/SPDX 收录时点待考（原“2006 年起”订正——2026-09-12 整改） |
**史料**：**Berkeley** 1999.7.22 官方公告、**OSI** 2-Clause 批准记录、**SPDX License List** `BSD-2-Clause`/`BSD-3-Clause` 条目 ［A］；[考据完成：2026-07-30 三次联网核查确证（2026-09-12 整改压缩过程记录，保留结论）——公告系 UC Berkeley 技术许可办公室（OTL）版权修正通知，无正式标题，抬头“To All Licensees, Distributors of Any Version of BSD”，1999-07-22 签署（William Hoskins, Director, OTL）并立即生效，删除广告条款第 3 条；系应 FSF/Stallman 请求发布以使 BSD 与 GPL 兼容；完整著录见本节文献字段]；`openbsd.duckdb` 查询 L3.6.1 显示（2026-09-12 整改注：本节论 BSD 许可证通论而该统计仅出自 openbsd 单库，系单库近似而非全 BSD 口径——同 230.5/232.4 族库归属错位，正式引用前须改指对应库或注明近似性质）：含 license/copyright/patent/BSD 关键词的 `commit` 时间分布——1992 年仅 3 `commit`/2 contributors（**CSRG** 末期，许可证讨论极少），2000 年 15,456 `commit`/496 contributors（4-Clause 向 3-Clause 过渡后讨论激增），2010 年 18,614 `commit`/729 contributors，2015 年 49,311 `commit`/807 contributors（历史峰值），2020 年 40,723 `commit`/716 contributors，2021 年 43,729 `commit`/931 contributors，反映许可证相关 `commit` 量在 1999 年广告条款弃用后陡升并在 2015 年达到峰值后维持在 4 万次以上高位

**史观**：总纲第 13 条——法律与道德是利益分配：BSD 许可证文本的逐版简化——广告条款的弃用系许可证条款与 GPL 生态利益兼容的再平衡（原挂“总纲第 14 条——许可证约束”，基线第 14 条为“苦难不值得被提倡”，按权威表改挂——2026-09-12 整改）

**辨析**：广告条款弃用是 1999 年还是更早，Hoskins 公告与 OSI 批准时点可交叉核查；[考据完成：2026-07-30 联网核查确证（2026-09-12 整改压缩）——Hoskins 职务为 Director, Office of Technology Licensing, UC Berkeley，公告发布机构为该校 OTL，无独立正式标题]；0 信任原则局限标注：L3.6.1 查询基于 commit message 关键词匹配（license/copyright/patent/BSD），存在误报风险——“BSD” 作为操作系统名称在非许可证语境中频繁出现（如 commit 描述功能改进时提及 BSD 子系统），可能高估许可证讨论的实际热度；“copyright” 与 “patent” 关键词亦可能在描述代码逻辑而非许可证变更时出现；author 字段可由提交者任意填写，contributors 去重基于 author_email，同一人使用不同邮箱会导致 contributors 被高估；commit 量增长既可能反映许可证讨论实际增加，也可能反映仓库整体 commit 量增长，须结合 L1.1.1 总 commit 量数据归一化判断；2015 年峰值可能受 GitHub 镜像引入与开源许可证讨论热潮多重因素影响，不可简单归因于 BSD 许可证本身

**文献**：Berkeley 1999.7.22 公告（**University of California, Berkeley** **Office of Technology Licensing** 版权修正通知，签署人 **William Hoskins**，Director, Office of Technology Licensing，原始文件 `ftp://ftp.cs.berkeley.edu/pub/4bsd/README.Impt.License.Change`）；OSI License List［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］；openbsd.duckdb L3.6.1 查询报告（深层信息挖掘.md §L3.6.1）

## 282.1.2 条款法律效力与效应

**要点**：**BSD** 许可证核心条款包括版权声明保留、二进制分发文档声明保留、免责声明，**3-Clause** 增加背书禁止条款，**2-Clause** 移除背书条款。

**史料**：**BSD** 许可证文本、**Jacobsen v. Katzer**（Fed. Cir. 2008-08-13）判决、**SPDX** `BSD-2-Clause` 文本［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］〔L3 官方文档与公告〕

**史观**：总纲第 13 条——法律与道德是利益分配：**BSD** 简约条款的法律效力——条件/许可之辨决定违反条款的救济路径，即法律结构对利益分配的安排（原挂“总纲第 14 条——许可证约束”，按权威表改挂——2026-09-12 整改）

**辨析**：**BSD** 许可证是否构成合同还是单纯许可，存在法律争议；**Jacobsen v. Katzer**（535 F.3d 1373, Fed. Cir. 2008）判决中联邦巡回上诉法院区分了许可证条款中的“条件”（condition）与“许可”（covenant）——法院认定 **Artistic License** 中的署名与修改声明条款构成“条件”而非单纯“许可”，违反条件即构成版权侵权而非仅违反合同；此区分对 **BSD** 许可证的启示在于：版权声明保留与免责声明条款若被认定为“条件”，则违反者构成版权侵权，救济手段包括禁令，而非仅损害赔偿；法律评论文章参见 **Moglen** 与 **Rosen** 2008 年系列分析（如 Rosen “ Jacobsen v. Katzer and the open source license enforcement”）[考据完成：2026-07-30 Jacobsen v. Katzer 判决引用基于 535 F.3d 1373 公开判例文本，法律推理摘要基于法院意见书原文]

**文献**：**Jacobsen v. Katzer**, 535 F.3d 1373 (Fed. Cir. 2008-08-13)[Z/OL]；**SPDX** `BSD-2-Clause`［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］

## 282.1.3 与 MIT/Apache 许可证文本比较

**要点**：**MIT** 许可证仅保留版权声明与免责声明，**BSD 2-Clause** 与 **MIT** 实质等价；**Apache 2.0** 增加专利授权与商标条款，复杂度高于 **BSD**。

  | 许可证 | 版权声明 | 免责声明 | 专利授权 | 商标条款 |
  |---|---|---|---|---|
  | **MIT** | 是 | 是 | 否 | 否 |
  | **BSD 2-Clause** | 是 | 是 | 否 | 否 |
  | **BSD 3-Clause** | 是 | 是 | 否 | 背书禁止 |
  | **Apache 2.0** | 是 | 是 | 是 | 是 |
**史料**：**MIT** 许可证文本、**Apache 2.0** 许可证文本、**OSI** 许可证对比表［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］〔L3 官方文档与公告〕

**史观**：总纲第 13 条——法律与道德是利益分配：宽松许可证谱系——MIT/BSD/Apache 的条款差异即权利义务分配密度的差异（原挂“总纲第 14 条——许可证约束”，按权威表改挂——2026-09-12 整改）

**辨析**：**BSD** 与 **MIT** 在法律效力上是否完全等价

**文献**：**MIT License** 文本；**Apache License 2.0** 文本［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］

## 282.1.4 史料辨析

**要点**：**BSD** 许可证原始文本的最早版本需追溯至 1980 年代 **BSD 4.3 Tahoe** 分发，1990 年代通过 **CSRG** 文件标准化为 **4-Clause** 形式。

**史料**：**4.3BSD Tahoe** 源码文件头部、**CSRG** 1994 **4.4BSD-Lite Release Notes** ［A］；资料数据库.duckdb 查询 C-41/C-42/C-43（全书文献计量背景注，2026-09-12 整改压缩：16,867 条参考文献、年份提取率 44.42%、Price 指数 7.34%——全书参考文献整体偏向历史经典，许可证史核心文献多属 1990-2000 年代；完整口径与局限见本节辨析）

**史观**：总纲第 18 条——时间是一种形式主义：**BSD** 许可证文本的史料溯源深受文献时间分布框架的塑形——Price 指数 7.34% 偏低说明许可证史的学术沉淀以历史经典为主，近 5 年许可证变更（如 **Elasticsearch** 改 **SSPL**、**HashiCorp** 改 **BSL**）的学术文献尚未充分进入本书参考文献体系，“史料厚薄”本身是时间切分框架的产物（原挂“总纲第 25 条——终结与延续”，基线第 25 条为“逻辑是形式主义而非世界本身的结构”，按权威表改挂——2026-09-12 整改；C-41/C-42/C-43 统计压缩见史料字段注）

**辨析**：广告条款具体起源于哪个 **BSD** 版本，社区存在不同说法；0 信任原则局限标注：C-41/C-42/C-43 为全书 16,867 条 references 表的整体计算结果，非许可证史单独计算，Price 指数 7.34% 反映全书偏向历史经典，许可证史相关文献占比可能被低估；references 表 `gbt7714` 字段为自由文本，年份正则可能误匹配 ISBN、页码中的数字，55.58% 文献无年份信息存在系统性低估；统计显著 ≠ 实际显著，Price 指数偏低不等于许可证史学术产出不足，可能反映学术出版的时滞效应

**文献**：**4.3BSD Tahoe** 源码；**4.4BSD-Lite Release Notes** ［A］；资料数据库.duckdb C-41/C-42/C-43 查询报告（文献计量学分析.md Task 22）
