# 311.4.2 争议的演变与效应

要点：BSD vs GPL 争议自 1990 年代延续至今，影响 BSD 与 Linux 社区关系、企业采用决策、跨项目代码共享等多方面。

史料：`comp.os.linux.advocacy` Usenet 存档、Slashdot 辩论存档、`lwn.net` 评论 ［A］；`openbsd.duckdb` 实查（2026-09-13 复核，原 L3.6.1 记载的“万级 commit/数百 contributors”组数字经实查证伪弃用——原记 2015 年 49,311 commit/807 contributors 超当年总量 2.2 倍、931 contributors 超全库历史去重人数，系臆造或错库数字）：openbsd-src 仓库含 license/copyright/patent/BSD 关键词的 `commit` 时间分布显示 2000 年命中 879（当年 commit 总量 13,691，GPLv3 起草讨论期），2010 年命中 376（总量 16,628，GPLv3 正式发布后讨论持续），2015 年命中 433（总量 22,014，与 GitHub 开源许可证讨论热潮同步），2020 年命中 288（总量 17,807，COVID 期间），2021 年命中 335（总量 17,315，Elasticsearch 改 SSPL、HashiCorp 改 BSL 等许可证变更引发新一轮讨论），各年去重作者 72-130 人，全库历史去重作者 427 人，反映 BSD vs GPL 争议在 `commit message` 层面持续存在但热度为平稳低热而非爆发性增长

史观：总纲第 4 条——分离聚合是永恒规律：BSD 与 GPL 阵营的对立与交织——商业与社区、专有化与 copyleft、竞争与代码共享——呈分离聚合的长期结构

辨析：争议是否促进了许可证设计的演进；0 信任原则局限标注：L3.6.1 查询的关键词匹配无法区分 `commit` 是支持 BSD 立场还是 GPL 立场，`commit` 量增长可能是 GPL 阵营讨论而非 BSD 阵营讨论，须结合 `commit` message 语义分析方能判断立场分布；2021 年关键词命中量（335）较 2020 年（288）仅小幅上升且当年 commit 总量微降（17,807→17,315），表明讨论热度平稳而非爆发；`@users.noreply.github.com` 邮箱与 GitHub 镜像 `commit` 可能影响去重作者计数，须扣除镜像贡献者后判断真实社区参与度；license/copyright/patent/BSD 四类关键词的权重不同，“BSD” 因操作系统名称重名可能贡献最多但相关性最低，须单独统计其他三类关键词方能更准确反映许可证讨论热度
