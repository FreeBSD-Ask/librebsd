# 第297章 illumosopensolaris的社区续命与unix谱系

## 史料

- [WEB:illumos.org/projects/site/wiki/FAQ] illumos 官方 FAQ（一手）：illumos 为 OpenSolaris 的完全开放社区 fork（2010-08-03 网络研讨会宣布）；Oracle 关闭 OpenSolaris 后社区必要转向；Nexenta/Joyent 发起但独立于商业公司；OpenIndiana/NexentaStor/SmartOS/OmniOS 均以其为基
- [WEB:illumos.org FAQ] illumos 维护开放国际化库、闭源二进制替代、DTrace/ZFS 社区增强与独立安全修复；强调与 Solaris 二进制兼容；illumos Foundation 2012 年加州注册 501(c)6
- [WEB:OpenIndiana 项目史] OpenIndiana 2010-09-14 于伦敦 JISC Centre 宣布（Project Indiana 内部代号源自 Sun，Ian Murdock 领导）；首发未测试版赶在 Oracle OpenWorld 之前发布
- [WEB:undeadly.org 2007-07-26] OpenBSD Journal：OpenBSD Foundation 宣布（Bob Beck, 2007-07-25）——加拿大联邦非营利组织，作为支持 OpenBSD 及 OpenSSH/OpenBGPD/OpenNTPD/OpenSMTPD/LibreSSL 的唯一法律实体接触点
- [WEB:OpenBSD 基金会资助史] 2014-01-14 Bob Beck 电费募款危机（比特币捐赠 2 万美元、共筹 15 万美元）；2014 起 Microsoft/Facebook/Google 与 Core Infrastructure Initiative 大额捐赠；2015 Microsoft 成首个金牌贡献者（2.5-5 万美元支持 OpenSSH，OpenSSH 已入 PowerShell 与 Windows Server 2018）；2016-2017 年度最大捐助者为中国的 Smartisan
