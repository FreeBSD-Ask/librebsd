# 297.5 illumos 的技术遗产：ZFS、DTrace、Zones 的持续演进（2010-2026）

#### 要点

illumos 持续演进 Sun 时代的核心技术：ZFS（文件系统 + 卷管理，Copy-on-Write 与校验和架构）、DTrace（动态追踪框架）、Zones（Solaris Containers 操作系统级虚拟化）在 illumos 下继续开发并反哺生态——OpenZFS 2013 年成为跨项目协作（illumos/FreeBSD/Linux 共享代码库），DTrace 被 FreeBSD 移植（FreeBSD 10，2014），Zones 理念影响 Linux 容器生态；illumos-gate.db 23,184 条 commit 记录 2010-2026 年的持续开发（2015 年后 commit 活跃度保持稳定，佐证项目未停摆）。

#### 史观

#### 辨析

“illumos 反哺生态”的因果方向须精确：OpenZFS 是独立于 illumos 的跨项目协作，illumos 是参与者之一而非唯一源头；FreeBSD 的 DTrace 移植（Pawel Jakub Dawidek 主导）主要基于 Sun 开源代码而非 illumos 分支，illumos 的作用是维持代码库活跃。**存疑**：illumos-gate 的 commit 数据存在 Git 镜像历史边界（Sun 时期 2005-2010 的 commit 不在库中），2010 年前的技术演进须依赖 Sun 时期史料。
