# 284.3 Foundation 治理结构的法律比较——与 Linux Foundation（2010 年由 OSDL 与 FSG 合并，非 501(c)(3) 而是 501(c)(6) 商业联盟）、Apache Software Foundation（1999 年成立，501(c)(3)）、Eclipse Foundation（2004 年成立，比利时注册）、Software in the Public Interest（1997 年成立，501(c)(3)）的治理路径对比

## 284.3.1 各基金会治理结构对比

**要点**：FreeBSD Foundation 采用董事制，Linux Foundation 采用企业会员代表制，Apache 软件基金会 采用精英 meritocracy，Eclipse Foundation 采用欧洲基金会形态，四者治理结构差异显著。

| 基金会 | 治理形态 | 注册地 | 税务身份 |
| ------------ | ------------ | ------ | ------------ |
| FreeBSD Foundation | 董事制 | 美国 | 501(c)(3) |
| Linux Foundation | 企业会员代表制 | 美国 | 501(c)(6) |
| Apache 软件基金会 | 贤能治理（meritocracy） | 美国 | 501(c)(3) |
| Eclipse Foundation | 欧洲基金会形态（AISBL，原 vzw） | 比利时 | 不适用（比利时注册非营利组织，非美国免税身份；AISBL 形态 2021 年起） |
| Software in the Public Interest（SPI） | 成员制非营利（支持 Debian 等项目托管） | 美国 | 501(c)(3) |

**史料**：各基金会 By-Laws 与治理文档——FreeBSD Foundation Bylaws（freebsdfoundation.org/about）；Linux Foundation Bylaws（linuxfoundation.org/about）；Apache Software Foundation Bylaws（apache.org/foundation/bylaws.html）；Eclipse Foundation Governance Documents（eclipse.org/org/foundation/）；SPI Incorporation Articles 与 Bylaws（spi-inc.org）；各文件检索日期 2026-07-23［A］

**史观**：总纲第 3 条——不存在进步，只有权力再分配：基金会治理差异即社区权力的制度化形态——FreeBSD 的董事制将决策权集中于选举产生的董事会，Linux Foundation 的企业会员代表制把权力分配给付费会员企业，Apache 的贤能治理把权力绑定于个人贡献履历，三种形态是同一「开源治理」问题在不同法律与商业语境下的权力再分配方案（原挂「总纲第 7 条——商业形态分化」，基线第 7 条为“理论必须自反”，按权威表改挂并扩写——批次 C071 问题 2/7）。

**辨析**：治理结构对项目发展的实质影响：董事制（FreeBSD）决策链短但依赖董事会成员素养；企业会员代表制（Linux Foundation）资金雄厚但决策受企业利益牵引；贤能治理（Apache）遴选透明但扩张缓慢。四者无优劣定论，须以各基金会的实际决议记录检验（[存疑脚注：本节治理效能判断系框架性描述，具体因果须以董事会纪要与项目演化数据核验]）

**文献**：各基金会 By-Laws ［A］

## 284.3.2 501(c)(3) 与 501(c)(6) 差异

**要点**：501(c)(3) 公益组织可接受免税捐赠但限制商业活动与政治游说，501(c)(6) 商业联盟可开展行业游说但不能接受免税捐赠，二者适用场景不同。

**史料**：IRC §501(c)(3) 与 **§501(c)(6)**、IRS Publication 557［考据注：2026-07-28 联网考据留痕，模板句式已按 0 信任原则精简（WO-004）；语义以正文与所引来源为准］〔L3 官方文档与公告〕

**史观**：总纲第 13 条——法律与道德是利益分配：501(c)(3) 与 501(c)(6) 的税务形态选择本质是利益分配结构的法律固化——(c)(3) 以公益身份换取免税捐赠但让渡游说空间，(c)(6) 以商业联盟身份换取游说自由但放弃捐赠免税，Linux Foundation 选 (c)(6) 使企业会员的利益诉求获得直接政策通道，而 FreeBSD Foundation 的 (c)(3) 使其更依赖个人捐赠与基金增值（原挂「总纲第 14 条——许可证约束」，基线第 14 条为“苦难不值得被提倡”，按权威表改挂并扩写）。

**辨析**：Linux Foundation 选择 501(c)(6) 的可考据考量——其前身 OSDL 即以企业会员制运营，合并 FSG 后延续 (c)(6) 使企业会员（Intel、IBM、Google 等）得以直接治理与政策游说，且不受 (c)(3) 的游说支出限制；「真正原因」的断言须以基金会合并公告与章程修订记录核验（[存疑脚注：动机推断待一手档案确证]）

**文献**：IRC §501；IRS Publication 557［考据注：2026-07-28 联网考据留痕，模板句式已按 0 信任原则精简（WO-004）；语义以正文与所引来源为准］

## 284.3.3 治理模式的法律辨析

**要点**：FreeBSD Foundation 501(c)(3) 身份限制其参与许可证政策游说，而 Linux Foundation 501(c)(6) 身份允许其直接参与开源政策游说，二者政策影响力不同。

**史料**：IRS Lobbying Restrictions for 501(c)(3)、Linux Foundation 政策游说记录［考据注：2026-07-28 联网考据留痕，模板句式已按 0 信任原则精简（WO-004）；语义以正文与所引来源为准］〔L3 官方文档与公告〕

**史观**：总纲第 3 条——不存在进步，只有权力再分配：税务身份直接塑造政策影响力——(c)(6) 身份允许 Linux Foundation 直接参与开源政策游说，(c)(3) 限制 FreeBSD Foundation 的游说规模（IRS 对 (c)(3) 的游说支出上限），政策场的声音差异由此成为法律身份的函数（原挂「总纲第 9 条——商业与社区协作」，基线第 9 条为“经验优先”，按权威表改挂并扩写）。

**辨析**：税务身份对政策影响力的实质影响：可观察差异是 Linux Foundation 参与 EU 政策与美股游说活动的公开记录较多，而 FreeBSD Foundation 的政策活动集中于商标与许可事务——该差异部分源于 (c)(6)/(c)(3) 的法律约束，部分源于资源规模，两因素须分别核验，不可全归于税务身份

**文献**：IRS Lobbying Rules；Linux Foundation 政策记录［考据注：2026-07-28 联网考据留痕，模板句式已按 0 信任原则精简（WO-004）；语义以正文与所引来源为准］
