# 2.3.2 事件通知设施的问题起点

<!-- DOC_MINE: ref10559#url -->
**官方文档**（证据等级：L3，来源：`historical_claims.duckdb.claim.CL-RM-495078`；task82-g7p2-v67-b018）

kqueue 论文摘要以 select() 与 poll() 系统调用为传统事件通知手段，并指其在描述符增多时性能不可扩展。引文出处：Jonathan Lemon. Kqueue: A generic and scalable event notification facility[EB/OL]. 2001[2026-11-14]. https://www.usenix.org/legacy/events/usenix01/freenix01/lemon.html.；引文按 L3 纪律：以上为公开文献记载（官方文档或同时代报道），非当事人直接证词，具体结论仍须回核原文与同期一手材料，不得单独引为定论。

**官方文档**（证据等级：L3，来源：`historical_claims.duckdb.claim.CL-RM-495079`；task82-g7p2-v67-b018）

论文引言明言 FreeBSD 以 poll() 与 select() 检测描述符活动，但两者在监视描述符数量变大时不能良好扩展，数千描述符的高容量服务器将遇瓶颈（引先行工作为注）。引文出处：Jonathan Lemon.
