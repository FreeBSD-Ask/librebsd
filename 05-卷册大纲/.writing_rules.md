# 大纲写入强制规则（WO-007，2026-09-11）
任何脚本向本目录写入内容前必须：
1. import 本规则配套的幂等模块：00-编纂规则与格式规范/01-规则/脚本与命令/wo007_idempotency.py
2. 写入前调用 has_block(text, 块标记) 检查目标块是否已存在；已存在则跳过或走更新逻辑，禁止重复追加。
3. 写盘统一走 write_guard(path, text, repo=...)：自动库名规范化（*.db→*.duckdb；bsd_commits.db 须给 repo）+ 强制 UTF-8 无 BOM + LF。
4. 违反以上任一步的写入视为生成器缺陷，核查工程将整批登记并要求重跑。
