# 大纲写入强制规则（WO-007，2026-09-11）
任何脚本向本目录写入内容前必须：
1. import 本规则配套的幂等模块：00-编纂规则与格式规范/01-规则/脚本与命令/wo007_idempotency.py
2. 写入前调用 has_block(text, 块标记) 检查目标块是否已存在；已存在则跳过或走更新逻辑，禁止重复追加。
3. 写盘统一走 write_guard(path, text, repo=...)：自动库名规范化（*.db→*.duckdb；bsd_commits.db 须给 repo）+ 强制 UTF-8 无 BOM + LF。
4. 违反以上任一步的写入视为生成器缺陷，核查工程将整批登记并要求重跑。

# 目录洁净规则（2026-10-17 立）

1. **禁止在本目录创建备份文件**：不得以 `.bak`／`.bak-`／`.bak_`／`.pre`／`.prebak-`／`.pre_`／`-bak`／`.b050pre` 等任何后缀，或以改名副本（如 `xxx.pre-b052`、`xxx.md.bak_t1`）形式在本目录留存写前／写后副本。一切备份一律置 `script/_bak/<YYYYMMDD>/`。
2. **禁止在本目录创建非 `.md` 文件**：唯一例外为本目录根级 `chapter_keywords.json`（目录关键词索引，供检索脚本读取）。临时清单、日志、JSON、脚本、压缩包一律置 `script/`。
3. **违规处置**：发现即按“识别 → 归档 → 删除 → 复验”四步处置——先归档至 `script/_bak/<YYYYMMDD>/` 并逐件校验 sha256，再删除，最后复验 `.md` 件数与总字节数未变。
4. **自检判据**：于本目录执行 `find . -type f ! -name "*.md" ! -name "chapter_keywords.json"`，输出须为空。
