**要点**：

- 节目据 Chris 的博客系列详解 ZFS block pointer：它是一个约 128 字节的结构，含三个指向磁盘位置的 DVA、256 位校验和与逻辑/物理诞生事务组，block pointer 自身不单独存校验和，而由包含它的上层对象隐式覆盖。（BSD Now EP255，[53.00-1211.90]，L2）
- 节目解释 embedded block pointer 可把至多 112 字节的小数据直接塞进 block pointer 充当载荷，省去额外块分配；由于 copy-on-write，底层块一旦改变即重写并向上逐级更新校验和，逻辑诞生时间因此使 ZFS 增量发送能直接按事务组找变更块，比 rsync 逐文件比对更快。（BSD Now EP255，[596.58-1034.86]，L2）
- 漏洞经纪商 Zerodium 宣布对 FreeBSD、OpenBSD、NetBSD 与 Linux 发行版的零日漏洞提供最高 50 万美元悬赏，把 BSD 零日的收购价从以往约为 Linux 的十分之一提升到同档；公司称其目标是对每个主流系统常备两个以上可用漏洞，价格由市场份额、用户交互成本与默认配置可打性驱动。（BSD Now EP255，[1221.18-1708.68]，L2）
- 2018 年 7 月 4 日 FreeBSD 选出新一届 9 人 Core 团队（含 Alan Jude、Benedict Reuschling、Brooks Davis、John Baldwin、Warner Losh 等）；选举每两年一次，过去 365 天内向任一 FreeBSD 仓库提交过代码的 committer 有资格提名与投票，得票前九者当选。（BSD Now EP255，[2140.74-2356.80]，L1）
- NetBSD 基金会宣布与 Philip Nelson 签约，以 FreeBSD current 代码为基底更新 NetBSD 的 IEEE 802.11 栈，目标是缩小两栈差异以利后续更新，并新增 802.11n/ac、SMP 与虚拟接入点支持。（BSD Now EP255，[2415.36-2570.10]，L2）

**史料**：

- 一手史料：Chris（多伦多大学系统管理员）的 ZFS block pointer 博客系列；FreeBSD Core 团队选举公告（2018 年 7 月 4 日）；NetBSD 基金会 2018 年夏与 Philip Nelson 的 802.11 栈更新合约公告（netbsd-users 邮件列表）；Zerodium 经 Bleeping Computer 转述的收购声明。（BSD Now EP255，[53.00-2570.10]，L2）

**史观**：

- 总纲11 商品是形式主义：零日漏洞被漏洞经纪商按市场份额、利用条件与默认配置可打性定价收购，显示漏洞作为商品的定价机制由市场而非技术内在价值决定。（BSD Now EP255，[1328.42-1609.94]，L2）
- 总纲10 动手者创造历史：Core 团队由过去一年实际提交过代码的 committer 投票产生，治理权归于动手写代码者而非旁观者。（BSD Now EP255，[2283.66-2342.52]，L1）
- 总纲4 分离聚合是永恒规律：NetBSD 以移植 FreeBSD 802.11 栈的方式重新收敛（reconverge）两分支已分化的无线代码，呈现分离之后的再聚合。（BSD Now EP255，[2432.24-2570.10]，L2）
