**要点**：

- Christine Peterson 在 opensource.com 记述 open source 一词的提出：1998 年 2 月 3 日为该词引入二十周年纪念日，她当周在两次会议之间想出该词，2 月 5 日在 VA Research 的策略会议上由 Todd Anderson 造句引入，Eric Raymond 与 Tim O'Reilly 传播，Bruce Perens 加入，最终取代易被误解为价格的 free software 与词义有限的 sourceware。（BSD Now EP235，[40.4-943.7]，L1）[订正：原 Christine Peterson 在 opensource.com 记述自己于 1998 年 2 月 3 日在 VA Research 的策略会议上提出 open source 一词：Todd Anderson 支持，Eric Raymond 与 Tim O'Reilly 传播，Bruce Perens 加入，最终取代易被误解为价格的 free software 与词义有限的 sourceware。（BSD Now EP235，[53.7-943.5]，L1），2026-09-30 SenseAudio 重转核对]
- CBSD 开发者 Goran Mekić 在访谈中说明 CBSD 是 FreeBSD 上的 jail、bhyve 虚拟机与 Xen 隔离管理器，以 jconstruct、bconstruct 等命令自动化配置网络、防火墙与 ZFS，并有过向 DragonFly BSD 与 HAMMER 移植的尝试。（BSD Now EP235，[2064.6-2982.9]，L1）
- Goran Mekić 自述约在 1999 至 2000 年因 Windows 频繁崩溃而经朋友接触 Linux 与 C++，后于 FreeBSD 5.0 时期停用，2016 年在贝尔格莱德 EuroBSD 组织者影响下回归 FreeBSD，现已无 Linux 机器，用 FreeBSD 做家庭录音室、DSP、操作系统教学与数字调音台开发。（BSD Now EP235，[2077.5-2582.5]，L1）
- 一篇博客称 FreeBSD 为 unknown giant，并指出《黑客帝国》的视觉特效由 Manex Visual Effects 使用 FreeBSD 集群渲染：该公司以 SGI 设施不足以完成 CGI 密集镜头，遂与 Dell 合作购买 32 台高端系统，周三到货、周六即投入渲染。（BSD Now EP235，[5825.2-6149.6]，L2）
- NetBSD 基金会赞助 Kamil Rytarowski 将 LLVM sanitizer 用于 NetBSD：内存 sanitizer 已可检测 ps、awk、ksh 等基础工具，提供预构建 LLVM 工具链，并规划 UBSan、ASan、TSan、LSan 及以 lld 替代 GNU ld。（BSD Now EP235，[1633.9-2047.9]，L2）
- Morley 于 1998 年高中时期先试 Linux，两三周内转投 FreeBSD 并成为重度用户；未走大学路线，凭 FreeBSD 经验获聘时为 Tier-1 骨干网的 Genuity 之 Tier-2 UNIX 系统管理员；到职后发现 Solaris、IRIX、HP-UX、AIX 等 UNIX 变体底层概念高度相通，BSD 背景使其能“以用户而不仅是管理员”的身份进入角色。（BSDTalk EP59，[67.84-334.8]，L1）
- 游戏服务器实践：因第一人称射击战队需要服务器，先在家中后转托管机房以 FreeBSD 承载；当时游戏服务器仅有勉强可用的 Linux 移植（客户端本为 Windows 专用），经 FreeBSD 的 Linux 模拟层运行并为守候进程编写监控脚本；为满足约 20 名玩家 20-40 毫秒的低延迟预期，他发现机器响应性不及 Windows 机器的体感，遂调整内核 HZ 时钟设置提高中断频率，以更高 CPU 占用换取更低延迟——专机专用使其成为合算权衡，最终取得可观延迟表现。（BSDTalk EP59，[345.72-478.7]，L1）
- 在企业内的渐进替代：其任职的保险行业软件公司入职时为纯 Windows 店，微软代理服务器频繁需重启且因闭源无解；他主动提出架设路由器，此后 FreeBSD 机器逐级承担路由、经防火墙的异地备份、自动化备份脚本、源码目录 diff 与 md5 变更追踪（Windows 上无简易自动化手段，CVS 在 Windows 店中也未被考虑），最终 Web 应用托管迁至 FreeBSD，使其能专注应用而几乎无需操心底层平台——与 Windows 开发中安装注册卸载软件、服务包后系统文件受保护等纠葛形成对照；同事未必理解 BSD 细节，但明确知道机器崩溃更少，甚至忘了 Windows 代理曾需数月一重启，已一年半未重启。（BSDTalk EP59，[482.3-720.26]，L1）
- 补丁与软件可得性：机构网络高度封闭、使用者高度受限，其补丁流程异于一般建议——偏好在本机或中央机保留源码并下载补丁，强调无论二进制更新或自行编译都必须保持系统最新，外部防火墙有意设为不可自外部访问，并经邮件列表获取补丁通知；软件可得性早年确实受限，但如今办公、通信、即时消息与数据安全需求几乎全有开源替代，仅照片处理与交互媒体等最终用户品类仍缺，某些包在 FreeBSD 上缺席只是因为社区兴趣不在于此。（BSDTalk EP59，[720.26-918.78]，L1）
- 生产栈与数据完整性：现役栈为 FreeBSD 加 Apache、PHP 与 MySQL；Web 应用在每次变更后即写库，MySQL 使用强度极高，因为保险业务数据丢失不可容忍（例如一次录入 300 辆车的车队保单），客户端因此永不丢失已录数据，另有备份兜底；曾评估 Windows 方案——按传统本应顺手，但愈评估愈昂贵、愈复杂且后端与托管可靠性存疑；开源系统、Web 服务器、语言、数据库加 HTML/JavaScript 等开放标准使其可自行排障而不必等待厂商更新，微软舍入函数在大量小数与因子精算中的缺陷正是闭源下无法自行修复的隐患，而 PHP 与 MySQL 的庞大活跃社区则使已知问题被主动处置。（BSDTalk EP59，[1097.1-1302.22]，L1）
- 术语立场与人才供给：选 PHP 而非 Python 或 Ruby，部分原因是更容易找到熟悉 PHP 且接触过 MySQL 的开源开发者——PHP 已跨过普及阈值，他称沿街即可找到数名 PHP 开发者（因其免费面向青少年传播）；免费且可靠的工具一旦用惯，便不会回换付费且更不可靠者；他自称作为 BSD 用户“更多是开源心态而非自由软件心态”，并主张在开源已提供有吸引力方案之处不应仅因其是开源而错过；同时承认说服公司转向并非易事，但在多数场景下确为更优平台。（BSDTalk EP59，[1302.22-1449.74]，L1）

**史料**：

- 一手史料：Christine Peterson 的 opensource.com 亲历记述；Goran Mekić 访谈自述；NetBSD 基金会 LLVM sanitizer 博客；ThinkPad T530 安装指南；Manex Visual Effects 使用 FreeBSD 渲染《黑客帝国》的记述。（BSD Now EP235，[53.7-6149.6]，L2）

**史观**：

- 总纲25 逻辑是形式主义而非世界本身的结构：open source 取代 free software 是对同一事物换上更易被企业与新手接受的形式，而非改变其内在，说明术语是形式化的命名竞争。（BSD Now EP235，[136.9-171.4]，L2）
- 总纲10 动手者创造历史：Goran Mekić 从 Linux 回归 FreeBSD 后自学并加入 CBSD，为 PF 集成、文档与 Reggae 供给作出贡献，说明动手自学者在系统生态中留下真实痕迹。（BSD Now EP235，[3074.8-3305.1]，L1）
- 总纲5 没有必然性，只有偶然性：FreeBSD 在该企业的扩散并非自上而下的平台决策，而是由微软代理服务器反复崩溃这一偶发故障触发：一句“我可以架个路由器”的顺手之举逐级演化为路由、备份、脚本与最终的托管迁移——企业技术替代史由偶发故障与在场者的即兴回应写成。（BSDTalk EP59，[531.68-577.04]，L1）

**辨析**：

- [存疑脚注] open source 一词的起源存在 Christine Peterson、Eric Raymond 与 Richard Stallman 等多份当事人叙述，节目仅采 Peterson 一方，须与其他记述交叉比对。 [存疑脚注] 术语起源系多方当事人不同叙述。（BSD Now EP235，[102.6-131.3]，L4）
- [考据脚注] CBSD 的功能范围、DragonFly 移植状态与 Goran Mekić 个人经历系受访者单方自述，须与 CBSD 文档及版本库交叉核验。 [考据脚注] CBSD 细节系受访者自述。（BSD Now EP235，[2064.6-3029.9]，L4）
