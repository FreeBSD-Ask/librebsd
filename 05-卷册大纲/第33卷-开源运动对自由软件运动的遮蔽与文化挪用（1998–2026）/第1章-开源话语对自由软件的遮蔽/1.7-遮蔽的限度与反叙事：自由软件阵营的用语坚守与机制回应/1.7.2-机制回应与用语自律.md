# 1.7.2 机制回应与用语自律

<!-- ROW_MINE: fb-1048074 -->`
- 【Linux社区】2012年5月 Daniel Gerzo (danger@freebsd.org) 在“FreeBSD Quarterly Status Report January-March, 2012”串中 汇总 GNU-Free C++11 栈、bsdsort 替代 GNU sort 与 linuxulator DTrace 探针工作，是 FreeBSD 系统性建立非 GPL 替代方案的项目化样本 ``Currently the BSD sort reached usable stable stage. It is stable, it is as fast as the GNU sort` `

<!-- ROW_MINE: fb-1060148 -->`
- 【Linux社区】2017年2月 FreeBSD Core 团队季报(bjk@FreeBSD.org)披露 Plans to create a GPLv3 overlay for the base system were shelved，是 BSD 项目对 GPLv3 的明确治理否决 + 同期 Linux DRM 移植并存的季度实录 `

<!-- ROW_MINE: fb-1097962 -->`
- 【Linux社区】2021年1月 FreeBSD Q4 2020 季报(debdrup@FreeBSD.org) 在 GPL in Base 段落披露 the base system to migrate to modern, copyfree or more permissively licensed components 并列出 gnugrep 被 bsdgrep 替换等，是 BSD 项目主动以 BSD 血统代码替换 GPL 血统工具 + 同期 Linuxulator 兼容 Linux 二进制并行推进的季度实录 `

<!-- ROW_MINE: fb-2622096 -->`
- 【Linux社区】2001年8月 Terry Lambert (tlambert2@mindspring.com) 在“Re: bash in /usr/local/bin?”串中 阐述 FreeBSD 通过 GPL 隔离区策略容纳 GPL 代码的机制，是 BSD 项目早期应对 GPL 传染的核心治理策略样本 ``We keep their source code in a ghetto, since we can't` `

<!-- ROW_MINE: fb-2633004 -->`
- 【Linux社区】2002年2月 Matthew Emmerton(matt@gsicomp.on.ca) 在“Re: valgrind”串中警告FreeBSD黑客永远无法进入valgrind主发行版因该工具包含Linux内核与libc代码，形成“putting some BSD-licenced code into a GPL product”的冲突 `

<!-- ROW_MINE: fb-2637039 -->`
- 【Linux社区】2003年7月 Terry Lambert(tlambert2@mindspring.com) 在“Re: Support for XFS in FreeBSD?”串中解释GPL版XFS进入BSD基本系统的法律屏障，指出“Clause 6 of the GPL forbids including it compiled into a FreeBSD distribution kernel binary” `

<!-- ROW_MINE: fb-6308 -->`
- 【Linux社区】2002年1月 Kjell Wooding(kjell@tash.pintday.org) 在“Re: UVM, UBC, and PF criticisms in comp.unix.solaris”串中列出 OpenBSD 未采纳 iptables 的四条理由，包括 GPL 许可不好以及 BSD 与 Linux IP 栈几乎没有共同点，为 BSD 防火墙谱系独立性的官方辩护 `

<!-- ROW_MINE: ob-186102 -->`
- 【Linux社区】2010年1月 Bret S. Lambert (bret.lambert@gmail.com) 在“Re: ath AR5424 support”串中 对拟从 Linux 移植的代码发出 GPL 拒绝通告，是 BSD 维护者执行 GPL 边界执法的直接样本 ``If it is GPL code, it's very unlikely to be commited` `

<!-- ROW_MINE: ob-194702 -->`
- 【Linux社区】2000年4月 John Wright(john@dryfish.org) 在“Re: integrating smbfs”串中追问能否把 GPL 的 smbfs 以内核模块形式并入 OpenBSD，试探 BSD 政策对 GPL 代码的实际边界 `

<!-- ROW_MINE: ob-213086 -->`
- 【Linux社区】2015年12月 Ingo Feinerer (feinerer@logic.at) 在“Update V4L2 API (sys/videoio.h)”串中 提交同步 Linux 视频 API 至 OpenBSD 的补丁并明示跳过 GPL2 头文件，是 BSD 项目处理 Linux 头文件时的 GPL 过滤惯例 ``which was reverted because of GPL2 considerations` `

<!-- ROW_MINE: ob-233983 -->`
- 【Linux社区】2017年2月 Ingo Feinerer(feinerer@logic.at) 在“Re: Sync sys/videoio.h with recent Linux kernel”串中说明 Linux 上游同意把 v4l2-common.h 双许可为 GPL+BSD 以便 OpenBSD 完全同步 Linux 4.10-rc5 的 V4L2 API，是 Linux 上游为 BSD 用户放宽单许可的具体让步 `

<!-- ROW_MINE: ob-249763 -->`
- 【Linux社区】2001年8月 J.C. Roberts(unknown@abac.com) 在“Re: OpenBSD behavior when duplicate IP address is enabled”串中自述正在写 BSD 版 VRRP 以替换 GPL 的 Linux/FreeBSD 实现，是 BSD 血统项目回击 GPL 版本的原点帖 `
