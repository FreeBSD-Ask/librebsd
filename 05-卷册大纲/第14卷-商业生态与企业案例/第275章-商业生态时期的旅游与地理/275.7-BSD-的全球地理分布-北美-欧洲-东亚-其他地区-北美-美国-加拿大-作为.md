# 275.7 BSD 的全球地理分布：北美、欧洲、东亚、其他地区——北美（美国/加拿大）作为 BSD 发源地的地理优势、欧洲学术传统的地理特征、东亚（日本、中国，含中国香港、中国澳门、中国台湾地区）的 BSD 采用地理模式、其他地区（俄罗斯/南美/非洲/中东）的 BSD 地理边缘性

## 275.7.3 与 Linux 全球分布比较

**要点**：Linux 全球分布更广泛，覆盖非洲、南美等发展中地区，BSD 地理分布主要集中于发达国家，二者差距反映社区规模与商业生态差异。

**史料**：Linux 用户组全球目录、BSD 用户组全球目录［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］；外部基准 E-04/E-05 显示：**Apache 软件基金会**（ASF）作为另一全球开源社区，FY2021-2022 志愿者 8,200 人、350+ TLP 项目（来源：ASF IRS Form 990 税务披露文件 `990-2021.pdf`），Apache Top 4 项目（**Spark** 49,256 + **HTTP Server** 34,727 + **Hadoop** 28,289 + **Kafka** 17,924）commit 总量 130,196（来源：GitHub apache 组织页面），与 BSD 4 大 src 仓库 commit 量（`freebsd-src` 444,203 + `netbsd-src` 773,683 + `openbsd-src` 245,904 + `dragonfly-src` 49,280，合计 1,513,070）相比，BSD 谱系在 commit 总量上约为 Apache Top 4 的 11.6 倍，但 Apache 志愿者规模（8,200 人）远超 BSD 4 大 src 仓库 unique contributors 合计，反映 BSD 与 Apache 在地理分布模式上的差异——BSD 集中于北美、欧洲、东亚三极，Apache 凭借企业驱动的 TLP 模式覆盖更广泛的地域〔L1 代码/构建产物/L3 官方文档与公告〕

**史观**：总纲第 7 条——商业形态分化：Linux 与 BSD 全球分布差异；统计结论印证：E-04/E-05 揭示 BSD 与 Apache 在地理分布与社区规模上的结构性差异——BSD 以代码贡献量见长但贡献者地理集中，Apache 以志愿者规模与 TLP 项目数见长且地理分布更广，二者反映 “学术-工程” 模式（BSD）与 “企业-基金会” 模式（Apache）的地理分化

**辨析**：BSD 在发展中地区规模较小的根本原因；0 信任原则局限标注：E-04 查询的 Apache Top 4 项目 commit 量来自 GitHub apache 组织页面，仅统计 GitHub 镜像 commit，不含 ASF 自有 Git 仓库（git-wip-us.apache.org）的独有 commit，可能低估 Apache 实际 commit 量；E-05 查询的志愿者 8,200 人为 ASF IRS Form 990 FY2021-2022 数据，“志愿者” 定义含 committer/PMC/member 多类角色，与 BSD unique contributors（按 author_email 去重）口径不同，不可直接对比；Apache TLP 项目数 350+ 为 2021-2022 年数据，2026 年实际项目数可能已变化；BSD 4 大 src 合计 commit 1,513,070 为 `bsd_commits.duckdb` 查询结果，含 SVN-to-Git 迁移期 commit 粒度变化，与 Apache GitHub 镜像 commit 的粒度可能不一致
