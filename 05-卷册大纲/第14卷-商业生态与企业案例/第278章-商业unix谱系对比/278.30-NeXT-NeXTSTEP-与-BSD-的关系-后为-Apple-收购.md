# 278.30 NeXT（NeXTSTEP 与 BSD 的关系，后为 Apple 收购）——NeXT 1985 年由 Steve Jobs 成立

## 278.30.1 NeXTSTEP 基于 Mach 与 4.3BSD 的架构

**要点**：**NeXTSTEP** 1989 年 1.0 发布，基于 **Mach 2.5** 微内核与 **4.3BSD Tahoe** 用户空间，对象层采用 **Objective-C**，奠定了后续 **Darwin**/**XNU** 架构基础。

**史料**：**NeXTSTEP** 1.0 Release Notes、**Mach 2.5** 文档、**Tevanian** 1993 CMU 论文 ［B］

**史观**：总纲第 2 条——实践先于理论：**Mach** 微内核的工程实践

**辨析**：**NeXTSTEP** 中 **BSD** 与 **Mach** 各自的功能边界

**文献**：NeXT 1989 NeXTSTEP Release；Tevanian 1993 论文 ［B］

## 278.30.2 NeXT 到 Darwin 的技术继承路径

**要点**：**Apple** 1996 年收购 **NeXT** 后，**NeXTSTEP** 经 **Rhapsody**、**Mac OS X Server** 1.0 演化为 **Darwin** 1.0（2001），核心 **XNU** 内核延续 **Mach**+**BSD** 混合架构。

  | 时间 | 产品 | 架构 |
  |---|---|---|
  | 1989 | **NeXTSTEP** 1.0 | **Mach 2.5**+**4.3BSD** |
  | 1999 | **Mac OS X Server** 1.0 | **Rhapsody** 过渡 |
  | 2001 | **Darwin** 1.0 | **XNU**（**Mach**+**BSD**） |
**史料**：**Apple** 1999 **Mac OS X Server** 公告、**Darwin** 1.0 源码发布、**Apple** 公开文档 ［A］

**史观**：总纲第 25 条——终结与延续：**NeXTSTEP** 到 **Darwin** 的延续

**辨析**：**Darwin** 中 **BSD** 部分是基于 **FreeBSD** 直接移植还是从 **NeXT** 4.4BSD 继承

**文献**：Apple 2001 Darwin 源码；Singh 2006 “Mac OS X Internals” ［A］

## 278.30.3 与同期 Sun OS 架构的比较

**要点**：**SunOS 4.x** 基于 **BSD**，**SunOS 5**/**Solaris 2** 基于 **SVR4**，**NeXTSTEP** 基于 **Mach**+**BSD**，三者代表了 1990 年代初 **Unix** 商业分化的不同路径。

  | 系统 | 基线 | 路径 |
  |---|---|---|
  | **SunOS 4.x** | **BSD** | **BSD** 路径 |
  | **SunOS 5**/**Solaris 2** | **SVR4** | **SVR4** 路径 |
  | **NeXTSTEP** | **Mach**+**BSD** | 微内核混合路径 |
