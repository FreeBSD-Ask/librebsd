# 278.26 BSDi（Berkeley Software Design, Inc.）——BSDi 1991 年由 Rick Adams 等人成立，商业化 4.4BSD-Lite

**要点**：**BSDi** 1991 年由 **Rick Adams**、**Mike Karels**、**Marshall Kirk McKusick（马歇尔·柯克·麦库西克）** 等前 **CSRG** 成员成立，商业销售 **BSD/OS**（原 **4.4BSD-Lite**）服务器操作系统，主打 **ISP** 与电信市场。

## 277.26.3 与 Walnut Creek 商业模型的比较
