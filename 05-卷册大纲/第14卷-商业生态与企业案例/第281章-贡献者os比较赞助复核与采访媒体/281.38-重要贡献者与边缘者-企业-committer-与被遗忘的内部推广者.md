# 280.38 重要贡献者与边缘者：企业 committer 与被遗忘的内部推广者——Netflix 的 Jonathan Looney 与 Drew Gallatin、Juniper 的 ARM64 移植团队、Apple Darwin 团队中推动上游回馈的工程师、Sony PS 团队中被法务封锁的工程师、iXsystems 的 Matt Olander（马特·奥兰德） 等

## 280.38.1 Netflix 与 Juniper committer 的贡献
  - 要点：**Netflix** 的 **Jonathan Looney**、**Drew Gallatin** 推动了 `sendfile`、**TLS** 与 **kTLS** 等核心特性，**Juniper** 的 **ARM64** 移植团队贡献了 **FreeBSD** **arm64** 端口基础。

  | 贡献者 | 所属企业 | 核心贡献 |
  |---|---|---|
  | **Jonathan Looney** | **Netflix** | `sendfile`/**kTLS** |
  | **Drew Gallatin** | **Netflix** | **TLS**/网络栈 |
  | **ARM64** 团队 | **Juniper** | **FreeBSD** **arm64** 端口 |

  - 史料：**Netflix** 工程博客、**Looney** **BSDCan** 演讲、**Juniper** **ARM64** 移植 `commit` 记录 ［A］
    FreeBSD 社区论文：[FP-2018-002] Flexible Disk Use in OpenZFS（Matt Ahrens，2018）<https://papers.freebsd.org/2018/bsdcan/ahrens-flexible_disk_use_in_openzfs/>
  - 史观：总纲第 9 条——商业与社区协作：企业 `committer` 的回馈
  - 辨析：**Netflix** 与 **Juniper** 哪家对 **FreeBSD** 上游贡献更大
  - 文献：Netflix 技术博客；FreeBSD 源码 Juniper ARM64 commit ［A］

  - 文献：FreeBSD commit 邮件；BSDCan 录像 ［A］
