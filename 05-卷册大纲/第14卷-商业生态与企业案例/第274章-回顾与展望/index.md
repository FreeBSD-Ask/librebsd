# 第 274 章 回顾与展望

## 要点

- 第六、七卷已述 BSD 商业生态——**Sony PS3/4/5** 运行修改版 FreeBSD、**Netflix** CDN 基于 FreeBSD `sendfile` 与 kernel TLS offload、**Juniper Junos** 路由器基于 FreeBSD、**NetApp ONTAP** 存储系统基于 FreeBSD、**WhatsApp** 早期服务器基于 FreeBSD
- BSD UNIX 哲学在 AI 代码生成时代的处境有二：一是 **LLM** 训练使用 BSD 许可代码不要求署名，与 **Apple** 零回馈模式在许可证层面一致——**BSDL** 不强制回馈使 AI 训练数据可合法使用 BSD 代码而无义务；二是 AI 生成代码是否动摇“做一件事并做好”的工程传统——**GitHub Copilot** 2021 年发布后，自动生成代码的复合性与 UNIX
- FreeBSD 面临的法律与治理新挑战有三：一是 AI 训练数据的许可证问题——LLM 训练使用 BSD 许可代码是否构成“合理使用”（fair use）在 2024-2025 年纽约时报诉 OpenAI 等案中持续争议；二是中美技术脱钩对全球协作的影响——2022 年后美国对华芯片出口管制与 GitHub 服务区域限制使中国 FreeBSD 贡献者面临参与障碍；三是各国“主权互联网”政策对 BS
- 全书收束的自反性结语承认本书的局限（0 信任原则仍可能有遗漏、AI 辅助史学的幻觉风险、当代史书写的认识论困境），将追问本身作为遗产留给未来史家
- 项目统摄史观提出“会者定离”——一切相聚终将离散。BSD 社区的代际更替是“会者定离”的历史实践：CSRG 1995 年解散、第一代贡献者逐步退场、新生代贡献者加入。本书的史学姿态是“局外人”——不试图改变 BSD 社区的命运，而是记录其历史。“局外人”姿态不是冷漠，而是项目统摄史观的“快乐辩护”——承认历史的有限性后仍坚持书写，这本身即是一种伦理选择。本书最终将自身作为“遗产”留给未来史家

## 辨析

- BSDL“宽松自由”是否为商业“无回馈”困境的根本原因存在两派对立：FSF 与 Stallman 认为 BSDL 不强制 copyleft 纵容企业搭便车，是“无回馈”的法律根源；BSD 社区认为不强制回馈是自由（Liberty）的核心设计，企业通过 commit 贡献、bug 报告、资金赞助等方式回馈，二者对“回馈”的界定不同
- AI 代码生成对 BSD 哲学的影响程度需长期观察，当前叙事多属预测
- 地缘政治对 BSD 的影响程度需与 Linux 对照，二者均面临相似压力
- “会者定离”是否为悲观主义？项目统摄史观认为“会者定离”是对历史有限性的诚实承认，不是悲观而是清醒
