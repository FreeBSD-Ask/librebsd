# 303.5.3 与 Cloudflare 基于 Linux 的比较

**要点**：**Cloudflare** 的 **CDN** 基于 **Linux**，与 **Netflix** 的 **FreeBSD** 选择不同。两者在 **CDN** 技术路线上分化，反映 **FreeBSD** 与 **Linux** 在网络性能领域的竞争。

  | CDN 厂商 | 操作系统 | 核心技术 | 路线特征 |
  |---|---|---|---|
  | **Netflix** | **FreeBSD** | **kernel TLS offload** | 上游回馈 |
  | **Cloudflare** | **Linux** | eBPF/QUIC | Linux 生态 |
**史料**：**Cloudflare** 技术博客、**Netflix** 技术博客、**CDN** 性能对比报告 ［C］

**史观**：总纲第 4 条——分离聚合是永恒规律：**CDN** 行业的技术路线分化

**辨析**：性能比较需控制硬件与配置变量

**文献**：Cloudflare 技术博客；Netflix 技术博客 ［C］
