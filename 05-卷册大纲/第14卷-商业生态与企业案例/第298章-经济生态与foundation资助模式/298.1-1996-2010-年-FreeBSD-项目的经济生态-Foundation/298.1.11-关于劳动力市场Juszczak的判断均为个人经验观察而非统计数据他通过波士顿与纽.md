# 298.1.11 关于劳动力市场Juszczak的判断均为个人经验观察而非统计数据他通过波士顿与纽

- 关于劳动力市场，Juszczak 的判断均为个人经验观察而非统计数据：他通过波士顿与纽约的猎头察觉 BSD 技能需求上升；观察到招聘启事若限定特定发行版（如仅要 Red Hat 经验）会收窄候选人池，而写泛化的 Linux 或 UNIX 技能要求的雇主通常决策更灵活；并主张若企业基础设施六至七成以上基于 BSD，就须配备具 Linux 向 BSD 迁移经验的内部人员，因两者存在实质性学习曲线。此观察可与同期职位板数据交叉验证，单独不构成定量结论。 [存疑脚注] 需求上升为当事人经验性判断，无统计支撑，使用时应标注为同期个人观察（BSDTalk EP108，[291.32-374.0]，L1）
- 转写讹误较旧转写减少：George Neville-Neil 与 Hiroki Sato 人名转写正确，gnn@freebsd.org 转写正确，两人职务（general chair 与 program chair）可辨；Satya San 疑为 Sato-san 之讹，www.ajbdcconf.org 与 www.azurebaspic.org 应为 www.asiabsdcon.org，赞助商名 USENIX 本次转写可辨，March 27th to 13th 应为 3 月 27 至 30 日。 [存疑脚注] 网址与日期经上下文推断校正，须以会议官网与公告核证（BSDTalk EP134，[22.4-531.1]，L4） [订正：原 38.11-525.44，2026-09-29 SenseAudio 重转核对]
- 本届日元注册费档位（转写含混，似为 10,000 日元）与上年 80 美元定价之间的折算关系不明，须以会议注册信息核证。 [存疑脚注] 注册费数字转写含混，待官网核证（BSDTalk EP134，[363.55-400.4]，L4） [订正：原 363.55-387.23，2026-09-29 SenseAudio 重转核对]
- 2007 年厂商捐赠分水岭的规模、未公开采用 FreeBSD 的厂商名单与 Flash 授权谈判进度均为受访者单方陈述，本期未提供文件证据，需以基金会年报、捐赠公示及 Sun Java 协议文本交叉验证；Gibbs 对基金会低开销的判断亦属自评。 [存疑脚注] 厂商捐赠规模与 Flash 授权进展为单一来源自述，需对照基金会公开财务文件复核。（BSDTalk EP149，[187.62-319.54]，L1）
- Malt 项目在 DCBSDCon 获良好反响，据称 Henning Brauer 曾对 jail 拥护者回应称其更优；但此后无人接手协助，开发者 Kristaps 因另一项目的政治纠葛受挫，其所在学校拟将 Malt 申报欧盟资助，Malt 能否成为 BSD Fund 项目取决于社区技术与资金双重兴趣。 [存疑脚注] Malt 的技术性质仅凭本期转写无法确证；受访者口中的 Henning Brower 拼写存疑，通行拼写为 Henning Brauer。（BSDTalk EP175，[1059.2-1113.7]，L2）
- 当事人称迁入OpenSolaris为“BSD又回来了”，其身份认同建立在对SunOS早期BSD血统的记忆上，而其运行的Solaris系谱系内核实为System V一脉，血统认同与实际技术谱系在此错位，提示用户迁移决策中的谱系想象与工程现实之别；另转写中“PURL.org”（1081.56秒处，疑为perl.org）与“Randy Harper/FreeBSDGirl”（1390.38秒处，疑为Randi Harper）两处人名站名依语音转写存疑，[存疑脚注] 须对照FLOSS Weekly节目原始信息核正。 [存疑脚注] PURL.org与Randy Harper两处专名系语音转写，未能与原始节目信息交叉验证。（BSDTalk EP183，[457.86-462.90]，L1）

- DiBona 自承不了解 BSD 运行 Linux 二进制兼容层的实际状态，显示即便开源企业负责人对 BSD 技术生态亦存认知盲区；其“BSD 许可为全球第二大流行许可”为个人估计而非统计结论。[存疑脚注] 该排序无出处，仅作 2006 年企业认知样本记录。 [存疑脚注] BSD 许可流行度排序系 DiBona 口头估计，无统计数据佐证。（BSDTalk EP41，[646.06-668.74]，L4）
