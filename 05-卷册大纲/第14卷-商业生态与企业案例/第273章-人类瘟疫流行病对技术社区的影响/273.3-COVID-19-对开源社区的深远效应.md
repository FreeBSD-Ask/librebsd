# 272.3 COVID-19 对开源社区的深远效应

  - 史观：总纲第 16 条——经济周期，COVID-19 对社区线下活动的全面中断是疫情冲击的极端形式
  - 辨析：会议取消与转为线上的比例需逐会议核实
  - 文献：BSDCan 公告；AsiaBSDCon 公告；EuroBSDCon 公告[考据完成：2026-07-28 经穷尽联网考据，上述文献清单为已知公开来源汇总，部分原始档案未公开数字化或须付费访问，属史料缺口，须待原始档案公开后方可补充确证]

## 272.3.3 committer 协作的远程化转型
  - 要点：**COVID-19** 期间 BSD committer 普遍转为远程工作，部分 committer 因家庭照护责任（如子女远程学习）提交频率下降，**Core Team** 通过 `phabricator` 与 `GitLab` 增强异步审查

  | 仓库类型 | 2020 年 commit 量 | 2020 年 contributors | 对比基准 |
  |---|---|---|---|
  | BSD 4 大 src 仓库合计 | 36,392 | 574 | L7.3.1 查询 |
  | Linux kernel | 90,911 | 4,864 | L7.3.1 查询 |
  | linux_to_bsd_ratio | 2.50（commit 倍率） | 8.47（contributors 倍率） | — |

  - 史料：`freebsd-hackers` 邮件列表 2020-2021、`phabricator` 审查记录、committer 个人声明 ［A］；bsd_commits.db 查询 L1.1.4 显示：**COVID-19** 期间（2020-2022）每季度 commit 量分布查询共返回 2206 行，涵盖 23 个仓库的季度 commit 数据，可用于识别远程协作对开发节奏的季节性影响（如 Q3 编程之夏高峰）；bsd_commits.db 查询 L7.3.1 显示：2020 年 BSD 4 大 src 仓库合计 36,392 commit、574 contributors，Linux kernel 90,911 commit、4,864 contributors，linux_to_bsd_ratio 为 2.50，反映 **COVID-19** 首年 BSD 阵营开发活跃度仍维持量级
  - 史观：总纲第 19 条——信息技术，远程工作是疫情对 committer 协作的根本性重塑
  - 辨析：committer 提交频率的下降幅度需通过 commit log 统计；0 信任原则局限标注：L1.1.4 查询基于 author_date 字段，但 git 的 author 字段可由提交者任意填写，分析 committer 归属时须与 committer 字段交叉验证；FreeBSD SVN-to-Git 迁移风险（2020 年迁移可能引入日期偏差）；commit 量仅反映开发活跃度，须结合 commit 规模（additions/deletions）与 message 质量综合判断，不可直接等同于代码质量或协作效率
  - 文献：邮件列表；phabricator 记录；committer 声明 ［A］；bsd_commits.db L1.1.4 查询报告（宏观趋势统计.md §L1.1.4）；bsd_commits.db L7.3.1 查询报告（衍生项目与跨项目对比分析.md §L7.3.1）
## 272.3.4 COVID-19 史料辨析
  - 要点：**COVID-19** 对 BSD 社区影响的史料保存较完整（邮件列表、会议录制、社交媒体），但部分内部讨论未公开，需通过公开档案与当事人回忆

  | 数据维度 | 数值 | 说明 |
  |---|---|---|
  | changelog.db 活动天数 | 10 天（2026-07-16 至 2026-07-25） | 本项目编纂活动记录 |
  | 日条目数范围 | 18 至 264 条 | 反映编纂整理强度 |
  | 数据性质 | 编纂活动元数据 | 非 COVID-19 期间 BSD 历史数据本身 |

  - 史料：邮件列表、会议录制、社交媒体档案 ［A］；openbsd.db 查询 L3.7.1 显示：changelog.db 项目编纂活动共 10 天有记录（2026-07-16 至 2026-07-25），日条目数从 18 到 264 不等，反映本项目（BSD 历史书编纂）对 **COVID-19** 期间 BSD 社区史料的整理活动，非 **COVID-19** 期间的 BSD 历史数据本身；资料数据库.db 查询 C-41 显示：references 表共 16,867 条参考文献，其中 C-42 年份提取率 44.42%（7,493/16,867，正则 `\b(1[89]\d{2}|20[0-2]\d)\b` 提取自 `gbt7714` 字段），C-43 Price 指数 7.34%（550/7,493，近 5 年参考文献占比），反映本书参考文献整体偏向历史经典而非近期文献，**COVID-19** 时期（2020-2024）的参考文献占比受 Price 指数偏低影响，疫情相关史料的学术沉淀尚需时间积累
  - 史观：总纲第 17 条——软件工程，COVID-19 史料保存较完整得益于数字化归档；统计结论印证：C-41/C-42/C-43 反映本书 references 表的文献计量学特征，Price 指数 7.34% 偏低说明疫情时期（2020-2024）的学术文献尚未充分进入本书参考文献体系，与 COVID-19 史料 “保存较完整但学术沉淀不足” 的阶段性特征一致
  - 辨析：部分社交媒体档案的长期保存存在风险；0 信任原则局限标注：L3.7.1 查询反映的是本项目编纂活动的元数据，须严格区分 “编纂活动” 与 “COVID-19 期间 BSD 社区历史数据”，避免将编纂者活动误读为历史主体的活动；changelog.db 的条目由编纂者手动录入，存在选择性偏差与时间滞后；统计局限性标注：C-41/C-42/C-43 为全书 16,867 条 references 表的整体计算结果，非 **COVID-19** 时期单独计算，Price 指数 7.34% 反映全书偏向历史经典，疫情时期文献占比可能被低估；references 表 `gbt7714` 字段为自由文本，年份正则可能误匹配 ISBN、页码中的数字，55.58% 文献无年份信息存在系统性低估；统计显著 ≠ 实际显著，Price 指数偏低不等于疫情时期学术产出不足，可能反映学术出版的时滞效应
