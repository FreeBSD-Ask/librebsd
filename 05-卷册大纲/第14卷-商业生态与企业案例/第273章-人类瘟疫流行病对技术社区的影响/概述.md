# 第 273 章 人类瘟疫：流行病对技术社区的效应

### 核心内容

#### 概率学量化分析

- **P-17**：freebsd-src vs dragonfly-src 贡献者分布 Jeffreys 散度 4.7113 bits，四大 BSD 中分布最接近，反映 fork 后路径继承关系。
- **P-18**：netbsd-src vs openbsd-src 贡献者分布 Jeffreys 散度 10.5543 bits，四大 BSD 中分布差异最大，尽管 OpenBSD 源自 NetBSD。
- **P-19**：freebsd-src vs dragonfly-src 文件路径 Jaccard 相似度 0.0687，四大 BSD 中路径同源性最高，印证 fork 关系。
- **P-20**：freebsd-src vs netbsd-src 文件路径 Jaccard 相似度 0.0141，四大 BSD 中路径同源性最低，反映早期代码分离。
- **P-21**：freebsd-src vs netbsd-src 文件路径互信息 0.8907 bits，四大 BSD 中共现信息量最高，反映早期共享代码。
- **P-33**：贡献者 commit 数标准差 Bootstrap CV=0.1844，95% CI [0.1095, 0.2517]，中-高敏感性，受小样本驱动。
- **P-34**：贡献者 commit 数中位数 Bootstrap CV=0.1810，95% CI [0.1236, 0.2793]，中-高敏感性，受小样本驱动。
- **P-35**：Gini 系数 Bootstrap CV=0.0149，95% CI [0.0050, 0.0222]，极低敏感性，统计稳健。
- **P-36**：文件总数 Bootstrap CV=0.0020，95% CI [0.0013, 0.0030]，极低敏感性，统计稳健。
- **P-55**：四大 BSD 项目生命周期稳态分布趋同 [0.25, 0.50, 0.20, 0.05]（高/中/低/停滞），分位定义算术必然。
- **P-69**：C-51 Granger 因果检验 24 项全部 p>0.05，BIC 近似 BF01 贝叶斯因子中位数 109,063.57，24/24 支持 H0，20/24 强支持 H0，确认 BSD 项目间 commit 量无 Granger 因果关系。
