# 299.2.5 Linux 企业主导模式的压力

**要点**：Linux 企业主导模式对 FreeBSD 的压力：(1) Red Hat/IBM 在企业市场压倒 FreeBSD；(2) Canonical Ubuntu 在云市场主导；(3) Linux Foundation 资金规模远超 FreeBSD Foundation；(4) Linux 商业生态（IBM、Red Hat、Canonical、SUSE、Oracle、Intel、Google 等）形成正向循环；FreeBSD 在企业市场被边缘化

**史料**：Linux Foundation 财报、Red Hat 年报、市场研究报告 ［B］

**史观**：总纲第 3 条——不存在进步，只有权力再分配，Linux 商业话语权压倒 BSD 是生态内话语权力的再分配

**辨析**：压力在主流企业市场致命（Red Hat/IBM 压倒 FreeBSD）但在细分市场非致命——FreeBSD 在 Netflix CDN、Juniper Junos、Sony PS 等嵌入式/网络设备市场找到定位；Linux Foundation 资金规模远超 FreeBSD Foundation 是事实，但 FreeBSD 的细分市场定位使其不需要与 Linux 在所有领域竞争
