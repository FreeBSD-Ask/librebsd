# 086.0.3 史观

本章论战的史观基于项目史观总纲第 6 条（和解优于斗争）、第 8 条（本体论上各方平等）、第 19 条（解释学循环是历史认识的根本条件）：其一，BSD 与 Linux 的争议本质是“广度胜出”与“深度保留”的差异化路径之争而非“胜负”之争，和解路径在于承认双方各有其主体性（第 6 条）；其二，批评方与反批评方的评价标准（市场份额 vs 技术影响力）基于不同评价体系，各方在本体论上平等，不得以单一标准衡量（第 8 条）；其三，对《FreeBSD 大败局》等批评文本的考据处于解释学循环之中——批评者与辩护者的前理解不同，“事实层”与“话语层”的区分正是对这一循环的自觉处理（第 19 条）。详见子节文件史观/辨析字段。
