# 086.2.2 反批评层——BSD 阵营的反批评

  **要点**：BSD 阵营从三个维度反批评——BSD 许可证哲学不同于 GPL（BSD 承认人类有限性，不以强制形式限制自由；GPL 强制回馈是 copyleft 哲学，二者非 “优劣” 而是 “差异”）、BSD 在服务器与嵌入式市场仍有地位（Netflix Open Connect 承载全球约 20% 互联网流量、Juniper JunOS 在路由器市场、PlayStation 在游戏机市场）、市场份额不是唯一标准（技术影响力如 UFS2/ZFS 文件系统对存储行业的贡献、学术价值如 McKusick 4.4BSD 设计与实现对操作系统教学的贡献、长期生态如 BSD 在 CDN/路由器/嵌入式领域的持续深耕）；三个维度共同构成 BSD 阵营的反批评框架。BSD 阵营反批评三维度对照如下：

| 维度 | 具体表现 | 数据支撑 |
| -- | ------ | ------ |
| 许可证哲学差异 | BSD 承认人类有限性，GPL 强制回馈 | BSD 与 GPL 许可证原文 |
| 服务器与嵌入式地位 | Netflix 承载约 20% 互联网流量、Juniper 路由器、PlayStation 游戏机 | Netflix 与 Juniper 与 Sony 财报 |
| 市场份额非唯一标准 | UFS2/ZFS 文件系统、4.4BSD 学术价值、CDN 长期生态 | McKusick 1984 SOSP 论文 |

**史料**：BSD 许可证原文（BSD 3-Clause **1990**）、GPL v2 许可证原文（**1991**）；Netflix Open Connect 技术架构公开资料（Dave Temkin **2015 年** 演讲、Netflix 技术博客）；Juniper JunOS 与 PlayStation 操作系统公开资料；McKusick 1984 SOSP FFS 论文、4.4BSD-Lite Release Notes **1994-06** ［A］

**史观**：总纲第 13 条——法律与道德是利益分配：BSD 与 GPL 许可证哲学差异本质是利益分配问题，不得以 “GPL 优于 BSD” 或 “BSD 优于 GPL” 的道德判断简化；总纲第 10 条——动手者创造历史〔订正：原描述符“边缘者贡献”系不规范变体，依权威表订正，编号不变〕：BSD 在边缘领域（CDN、路由器、嵌入式）的深耕是边缘者动手贡献的体现

**观点**：1997 年 1 月，FreeBSD 核心开发者 John S. Dyson 在被转贴到 comp.unix.bsd.misc 的讨论中解释 BSD 阵营为何缺乏“布道”：这“大概因为我们许多人的职业生涯太长，见过太多操作系统来了又去，我们知道今天的‘答案与工具’不会是终局”。转帖者 Craig Johnston 以此回应 Russell Nelson 对 BSD 缺乏传教士的讥讽。

**辨析**：反批评的具体维度经第三方数据交叉验证——Netflix Open Connect 承载全球约 20% 互联网流量有据可循（Netflix **2023 年** 财报显示其全球订阅用户约 2.6 亿，Open Connect CDN 承载其全部视频流量，经 Sandvine Global Internet Phenomena Report 交叉验证）、Juniper JunOS 在路由器市场有据可循（Juniper **2022 年** 财报显示其路由器市场份额约 15-20%）、PlayStation 在游戏机市场有据可循（Sony **2023 年** 财报显示 PlayStation 4/5 累计销量约 1.7 亿台）；但 BSD 桌面市场份额不足 0.1% 的事实无法被 “服务器市场有地位” 否定，桌面市场失败是客观事实；【0 信任原则·自述数据考据】“Netflix 承载 20% 互联网流量” 须经 Netflix 技术博客与第三方流量统计（Sandvine Global Internet Phenomena Report）交叉验证，不得仅凭 Netflix 自述；【0 信任原则·市场份额与影响力非同一维度】Juniper 路由器市场份额 15-20% 与 BSD 在路由器市场的 “影响力” 非同一维度，市场份额反映商业规模，影响力反映技术渗透
