# 074.1.4 要点NetBSD08基于386BSD01+022patchkit集成了Berke

  **要点**：NetBSD 0.8 基于 386BSD 0.1 + 0.2.2 patch kit，集成了 Berkeley Networking Release 2 (Net/2) 中 386BSD 缺失的程序；NetBSD 1.0 于 1994 年迁移至 4.4BSD-Lite 代码基础 [考据脚注：4.4BSD-Lite 于 1994 年 6 月发布，经 McKusick 1999 一手叙述、CSRG Release Notes 与多源交叉一致确认。]；MI/MD（Machine-Independent/Machine-Dependent）分层架构在后续版本中逐步完善，0.8 仅支持 i386 单平台但架构设计为多平台移植预留了空间
  
**史料**：Demetriou 0.8 原始公告（明确记载"based heavily on 386BSD 0.1, patched with the 0.2.2 patch kit“，”integrated many programs from UCB's second BSD Networking Software Release“）、NetBSD 1.0 Release Announcement（明确记载”based on 4.4BSD Lite and Berkeley Networking Release 2 sources"）、NetBSD 源码树 ［A］
  
**史观**：总纲第 15 条——文化即形式主义：MI/MD 分层是 BSD 工程传统在多平台场景的形式主义化〔存疑：挂条待主理人审定〕
  
**辨析**：MI/MD 架构并非在 0.8 时即完整建立——0.8 仅支持 i386 单平台，多平台支持与完整 MI/MD 分层在 0.9、1.0 及后续版本中逐步完善；4.4BSD-Lite 基础是 1.0 版本（1994.10）才引入的，0.8（1993.4）不基于 4.4BSD-Lite 也不基于 4.3BSD-Reno
  
**文献**：Demetriou C G. NetBSD 0.8 Installation Notes (19 Apr 1993)；Demetriou C G. NetBSD 1.0 Release Announcement (8 Nov 1994)［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］
