# 090.3.2 Solaris 2.4 的比较

  **要点**：1994 年 SunOS 5.4 (Solaris 2.4) 发布，基于 SVR4，支持 SPARC 与 x86，提供与企业 Unix 兼容的 ABI；与 4.4BSD-Lite 相比，Solaris 2.4 是商业 UNIX 的延续，BSD 与 SVR4 的分野在 1994 年已基本定型

**史观**：总纲第 4 条分离聚合是永恒规律：BSD 与 SVR4 的分离在 1994 年已定型，Solaris 与 4.4BSD-Lite 走向不同路径
  
**辨析**：Solaris 2.4 与 4.4BSD-Lite 的比较须考虑 “商业 UNIX 续命”（Solaris 2.4 基于 SVR4，经 Sun 商业销售渠道在 SPARC 工作站市场延续）与 “开源 BSD 兴起”（4.4BSD-Lite 经 FreeBSD 2.0、NetBSD 1.0 在 x86 服务器市场兴起）的张力——BSD 与 SVR4 的分野在 1994 年已定型，前者经开源许可证（BSD）扩散，后者经商业许可证（Sun、HP、IBM）续命，二者经许可证模式差异走向不同路径
