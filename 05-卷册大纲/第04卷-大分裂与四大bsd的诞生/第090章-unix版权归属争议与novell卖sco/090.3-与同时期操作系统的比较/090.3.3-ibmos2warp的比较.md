# 090.3.3 IBM OS/2 Warp 的比较

  **要点**：1994 年 IBM OS/2 Warp 3.0 发布，定位桌面与小型企业市场，提供 32 位抢占式多任务；与 4.4BSD-Lite 相比，OS/2 Warp 定位桌面市场，4.4BSD-Lite 定位服务器市场，两者市场定位不同但都面临 Windows 95 的竞争压力
