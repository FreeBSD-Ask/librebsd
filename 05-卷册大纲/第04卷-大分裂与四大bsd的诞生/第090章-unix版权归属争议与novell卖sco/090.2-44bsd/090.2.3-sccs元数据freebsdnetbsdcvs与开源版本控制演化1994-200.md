# 090.2.3 SCCS 元数据 → FreeBSD/NetBSD CVS 与开源版本控制演化（1994-2000）

  **要点**：CSRG **1980-1995 年** 期间使用 SCCS（Source Code Control System，**1972 年** Marc Rochkind 在 Bell Labs 开发）作为版本控制系统，SCCS 元数据记录 BSD 源码的逐次提交时间、作者、注释，是 BSD 演化史的一手数字证据；CSRG 解散后 McKusick CSRG Archive CD-ROM #4 含 “Final /usr/src including SCCS files”，是 CSRG SCCS 元数据的完整保存载体；FreeBSD 1.0（**1993.11**）与 NetBSD 0.8（**1993.4**）发布后引入 CVS（Concurrent Versions System，**1986 年** Dick Grune 发布，**1990 年代** 初期普及）作为版本控制系统——CVS 服务器托管 FreeBSD/NetBSD 源代码，committer 通过 CVS 提交补丁，社区通过 **cvsup** 工具（John Polstra **1994 年** 开发）同步本地源代码树；SCCS 元数据在三大 fork 项目中被 “淘汰” 为 CVS 版本控制系统，但 CSRG 原始 SCCS 元数据作为史料保存于 McKusick CD-ROM #4 与 Bancroft CU-551 全宗；FreeBSD CVS 仓库持续到 **2008 年** 迁移到 SVN（Subversion），**2020 年 12 月** src 仓库迁移到 Git；NetBSD CVS 仓库持续到 **2016 年** 迁移到 CVS 同步 Git 镜像；OpenBSD CVS 仓库持续到今（仍使用 CVS）；SCCS → CVS → SVN → Git 的演化路径反映开源项目版本控制系统的演化趋势。版本控制系统演化路径如下：

| 系统 | 起源时间 | 在 BSD 中的使用 | 后续演化 |
| -- | ------ | ------------- | ------ |
| SCCS | **1972 年** Bell Labs | CSRG **1980-1995** 使用 | 元数据保存于 McKusick CD-ROM #4 |
| CVS | **1986 年** Dick Grune | FreeBSD/NetBSD/OpenBSD 主仓 | FreeBSD 迁移至 SVN，OpenBSD 仍使用 |
| SVN | — | FreeBSD **2008 年** 迁移 | NetBSD/OpenBSD 未采用 |
| Git | — | FreeBSD **2020 年 12 月** 迁移 | NetBSD **2016 年** 同步 Git 镜像 |

**史料**：SCCS 元数据（CSRG Archive CD-ROM #4）；FreeBSD 1.0 CVS 仓库记录；NetBSD 0.8 CVS 仓库记录；**cvsup** 工具发布记录（1994，John Polstra）；FreeBSD 2008 年 SVN 迁移公告；FreeBSD 2020-2021 年 Git 迁移公告；NetBSD 2016 年 CVS-Git 同步公告；OpenBSD CVS 仓库档案；SCCS/CVS/SVN/Git 发布记录 ［A］

**史观**：专题语（不设总纲条号）——信息技术史考察（原挂第 19 条系自撰名目，删条号保留分析）——SCCS/CVS/SVN/Git 版本控制系统的演化是 1970-2000 年代信息技术演化的物质遗存；总纲第 3 条——不存在进步，只有权力再分配（原“终结中的延续”系伪名目，按族例改挂，存疑）——CSRG 原始 SCCS 元数据作为史料保存，是 “终结中的延续” 的典型

**辨析**：SCCS 在 CSRG 中作为版本控制系统的具体时间需核对——SCCS 1972 年在 Bell Labs 开发，CSRG 1980 年代起使用，须区分 “SCCS 在 Bell Labs 开发” 与 “CSRG 使用 SCCS”；CVS 在 FreeBSD/NetBSD 中作为版本控制系统的具体时间需核对——FreeBSD 1.0（1993.11）与 NetBSD 0.8（1993.4）发布时 CVS 已在使用；OpenBSD 持续使用 CVS 至今（2025）需核对——OpenBSD 仍使用 CVS 但部分镜像已同步至 Git，须区分 “主仓库” 与 “镜像”
