# 第 73 章 openbsd的de-raadt独裁治理模式

## 要点

- 独裁模式的辩证合图——独裁模式既是 OpenBSD 工程质量的保障（反批评层）也是新人进入的障碍（批评层与再批评层），二者并非非此即彼而是同一结构的两面；de Raadt 的独裁模式在 OpenBSD 的特定规模（核心开发者约数十人）与特定目标（安全至上）下具有工程合理性，但这一合理性不可推广至更大规模或更广泛社区——FreeBSD 与 Linux 的层级化治理结构在其各自规模下同样具有工程合理性
- 分叉争议的项目统摄史观审视从总纲第 13、19、21 条切入——其一，总纲第 13 条“法律与道德是利益分配”揭示分叉的“人际冲突”叙事实质是利益分配问题：de Raadt 被撤销 commit bit 表面是“难以合作”的道德判断，实质是 NetBSD 核心团队内部关于项目方向、贡献者权限、决策权分配的利益再分配，“道德问题本质上是利益问题”——将分叉简化为“人际冲突”遮蔽了 NetBSD 核心
