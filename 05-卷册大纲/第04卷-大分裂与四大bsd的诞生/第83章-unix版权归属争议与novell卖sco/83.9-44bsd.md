# 83.9 4.4BSD-Lite 时期的技术淘汰——4.4BSD 含 AT&T 代码 →4.4BSD-Lite 完全自由版本、CSRG 机构化开发 →CSRG 解散后三大 fork 继承、SCCS 元数据 →FreeBSD/NetBSD CVS 与开源版本控制演化（1994-1995）

## 83.9.1 4.4BSD 含 AT&T 代码 → 4.4BSD-Lite 完全自由版本（1993-1994）

  **要点**：据 McKusick 当事人一手记载，4.4BSD-Encumbered（含 AT&T 许可代码版本）与 4.4BSD-Lite 于 **1994 年 6 月** 同时发布（4.4BSD-Encumbered 需购买 AT&T UNIX 源代码许可证方可使用）；CSRG CD-ROM #3 标注有 “4.4” 目录，存在 **1993 年** 晚期测试版本的可能 [考据完成：2026-08-17 4.4BSD 于 1993 年已有测试版（CSRG CD-ROM #3 “4.4”目录），因 USL 诉讼推迟至 1994.6 正式发布]；USL v. BSDi 诉讼核心争议为 Net/2 中 6 个内核文件，**1994 年 1 月** 和解后删除 3 个 System V 共享内存/信号量相关文件、约 70 个文件添加 USL 版权声明（文件本身为伯克利代码且可自由再分发）；4.4BSD-Lite（**1994.6**）是不含争议代码的 “清白” 版本，Novell 承诺不起诉基于 4.4BSD-Lite 的组织或个人；4.4BSD-Lite2（**1995.6**）作为 CSRG 最后一个发布版本包含两年的 bug fix；4.4BSD-Encumbered 在 4.4BSD-Lite 发布后被 “淘汰”，是 BSD 从 “混合版权” 完全过渡到 “完全自由 BSD 许可证” 的关键节点；FreeBSD 2.0（**1994.11.22** 网络发布/**1994.12** CD-ROM）、NetBSD 1.0（**1994.10.26**）均以 4.4BSD-Lite 为代码基础重建；OpenBSD 于 **1995 年 10 月** 从 NetBSD 1.0 fork（间接基于 4.4BSD-Lite），第一个正式版本 OpenBSD 1.2 于 **1996 年 7 月** 发布
  
**史料**：McKusick M K. Twenty Years of Berkeley Unix [M]//Open Sources, 1999（当事人一手记载）；4.4BSD-Lite Release Notes（1994.6）；4.4BSD-Lite2 Release Notes（1995.6）；USL v. BSDi 和解协议（1994.1）；FreeBSD 2.0 Release Announcement（1994.11.22 Jordan Hubbard 原始公告）；NetBSD 1.0 Release Announcement（1994.10.26）；OpenBSD 项目起源记录；CSRG Archive CD-ROM #3 目录 ［A］；bsd_commits.duckdb 查询 L3.6.1 显示：1994 年（4.4BSD-Lite 发布年）含 license/copyright/patent/BSD 关键词的 commit 为 3,005 commits/62 位贡献者，1995 年（4.4BSD-Lite2 发布年、CSRG 解散年）升至 4,055 commits/95 位贡献者，1996 年（三大 fork 完成重建年）进一步升至 6,473 commits/149 位贡献者；1994-1996 年 license/copyright/patent/BSD 关键词 commit 量的持续增长反映 4.4BSD-Encumbered → 4.4BSD-Lite 完全自由版本迁移完成后，三大 fork 项目在各自代码库中持续进行许可证清理与版权声明标准化工作
  
**史观**：总纲第 13 条——法律与道德是利益分配（原“许可证”挂第 24 条系伪名目，按许可证决定演化路径论旨改挂，存疑）——BSD 许可证在 4.4BSD → 4.4BSD-Lite 演化中起决定性作用，4.4BSD-Lite 完全自由许可证使 BSD 消除法律风险；专题语（不设总纲条号）——技术选择的代价（原挂第 6 条系伪名目，删条号）——4.4BSD-Encumbered 的混合版权模式在诉讼后被放弃，4.4BSD-Lite 以法律洁净为目标
  
**辨析**：4.4BSD-Encumbered 与 4.4BSD-Lite 的关系需严格区分——前者需 AT&T 源代码许可证，后者完全自由；争议文件数量需准确：“32 个争议文件” 说法无一手来源支持，McKusick 明确记载仅 3 个文件被完全删除、约 70 个文件添加 USL 版权声明（仍可自由再分发）；“4.4BSD（1993.11）” 正式发布日期 [考据完成：2026-08-17 4.4BSD-Encumbered 与 4.4BSD-Lite 均于 1994.6 发布，“4.4BSD（1993.11）正式发布”表述不确]——McKusick 1999 明确记载 4.4BSD-Encumbered 与 Lite 同时于 1994 年 6 月发布；Novell-UC Berkeley 和解协议签署于 1994 年 1 月而非 1994 年 6 月，1994 年 6 月是 4.4BSD-Lite 发布时间；【考据审慎·关键词匹配可能误报】L3.6.1 的关键词匹配基于 message_subject LIKE ‘%license%’ OR ’%copyright%’ OR ‘%patent%’ OR ’%BSD%’，LIKE 默认大小写不敏感，可能将包含 “BSD” 一词但与许可证无关的 commit 误报为许可证相关 commit，1994-1996 年的 commit 量级须结合手动抽样核实关键词匹配精度；【考据审慎·commit 量不等于质量】L3.6.1 的 license/copyright 关键词 commit 量增长反映开发者对许可证议题的关注度但不等于许可证清理工作的实际完成度，部分 commit 可能仅是版权声明格式微调；【考据审慎·CVS-to-Git 迁移风险】BSD 4 大 src 仓库中 netbsd-src 与 openbsd-src 均为 CVS 主仓的 GitHub 镜像，CVS-to-Git 转换可能重写 message_subject 字段，1994-1996 年关键词 commit 量基线须与各项目官方档案交叉验证
  
**文献**：McKusick M K. Twenty Years of Berkeley Unix [M]//Open Sources, 1999；4.4BSD-Lite/Lite2 Release Notes；USL v. BSDi 和解协议 1994.1；FreeBSD 2.0/NetBSD 1.0 Release Announcements ［B］；本项目。bsd_commits.duckdb 数据分析报告：深层信息挖掘 [R/OL]. 2026.

## 83.9.2 CSRG 机构化开发 → CSRG 解散后三大 fork 继承（1995-1996）

  **要点**：CSRG 于 1976 年因 DARPA 合同由 Bob Fabry 正式成立〔原“1980 年 4 月”与 46.18 所记 1976 年相差四年，按 McKusick 一手记载统一为 1976，DARPA 1980 年代续约强化另计〕后作为伯克利 EECS 系下的研究小组机构化运作，**1980-1995 年** 期间发布 4.1a/b/c BSD、4.1BSD、4.2BSD、4.3BSD、4.3BSD-Tahoe、4.3BSD-Reno、Net/1（**1989.6**）、Net/2（**1991.6**）、4.4BSD-Alpha（**1992.8**）、4.4BSD-Encumbered（**1994.6**）、4.4BSD-Lite（**1994.6**）、4.4BSD-Lite2（**1995.6**）等 BSD 主线版本；**1995 年 6 月** Mike Karels 发出告别邮件 “Berkeley CSRG is now disbanded”，CSRG 使命完成后解散；CSRG 在 DARPA 资助结束（约 **1992-1993**）后通过 CSRG Incorporated 非营利组织发行 4.4BSD 套装的收入维持了最后两年的 bug fix 工作，并非单纯因 DARPA 终止资助而立即解散；CSRG 机构化开发模式在 **1995 年** 后被三大 fork 继承——FreeBSD Core Team（**1993** 起，集体治理）、NetBSD Core Team（**1993** 起，集体治理）、OpenBSD（Theo de Raadt（西奥·德·若特） **1995.10** 起，单人主导 + 社区审查）；CSRG 档案物理保存于伯克利 Bancroft 图书馆 CU-551 全宗（1974-2005，12.5 线性英尺），McKusick 个人整理 CSRG Archive CD-ROM 4 盘套装作为另一条史料保存路径。CSRG 机构化开发时期关键版本发布时间线如下：

| 时间 | 版本 | 意义 |
| -- | -- | -- |
| **1980.4** | CSRG 成立 | DARPA 合同启动 |
| **1989.6** | Net/1 | 首个自由再分发版本 |
| **1991.6** | Net/2 | 引发 USL 诉讼 |
| **1992.8** | 4.4BSD-Alpha | 4.4BSD 开发起点 |
| **1994.6** | 4.4BSD-Encumbered / 4.4BSD-Lite | 同时发布，Lite 为法律洁净版本 |
| **1995.6** | 4.4BSD-Lite2 | CSRG 最后版本，Karels 告别邮件 |

**史料**：McKusick M K. Twenty Years of Berkeley Unix [M]//Open Sources, 1999（当事人一手记载）；CSRG 年度报告；Mike Karels 1995 年 6 月告别邮件；Bancroft CU-551 全宗目录；McKusick CSRG Archive CD-ROM 4 盘套装；FreeBSD/NetBSD/OpenBSD 项目起源档案 ［B］

**史观**：总纲第 3 条——不存在进步，只有权力再分配（原“终结中的延续”系伪名目，按族例改挂，存疑）——CSRG 解散是 “终结”，但其代码遗产通过三大 fork 项目 “延续”，是 “终结中的延续” 的典型；总纲第 4 条——分离聚合是永恒规律（原挂第 11 条系条号错配，正名）——CSRG 机构化代码聚合体在解散后分离为三大 fork，分离是聚合的前提

**辨析**：CSRG 解散的直接原因需准确表述——McKusick 当事人记载明确说明是 4.4BSD-Lite/Encumbered 销售收入支持了最后两年的 bug fix 工作，直到 bug 报告和功能增强请求大幅减少后发布 Lite2 并自然解散，“DARPA 终止资助后立即解散” 表述不准确；Mike Karels 告别邮件的具体日期 [存疑脚注：2026-08-17 CSRG 解散与 Mike Karels 告别邮件的精确日期无公开一手史料，无法确证]，多数来源仅标注 1995 年 6 月

**文献**：McKusick M K. Twenty Years of Berkeley Unix [M]//Open Sources, 1999；Mike Karels 告别邮件；Bancroft CU-551 全宗；McKusick CD-ROM 套装 ［B］

## 83.9.3 SCCS 元数据 → FreeBSD/NetBSD CVS 与开源版本控制演化（1994-2000）

  **要点**：CSRG **1980-1995 年** 期间使用 SCCS（Source Code Control System，**1972 年** Marc Rochkind 在 Bell Labs 开发）作为版本控制系统，SCCS 元数据记录 BSD 源码的逐次提交时间、作者、注释，是 BSD 演化史的一手数字证据；CSRG 解散后 McKusick CSRG Archive CD-ROM #4 含 “Final /usr/src including SCCS files”，是 CSRG SCCS 元数据的完整保存载体；FreeBSD 1.0（**1993.11**）与 NetBSD 0.8（**1993.4**）发布后引入 CVS（Concurrent Versions System，**1986 年** Dick Grune 发布，**1990 年代** 初期普及）作为版本控制系统——CVS 服务器托管 FreeBSD/NetBSD 源代码，committer 通过 CVS 提交补丁，社区通过 **cvsup** 工具（John Polstra **1994 年** 开发）同步本地源代码树；SCCS 元数据在三大 fork 项目中被 “淘汰” 为 CVS 版本控制系统，但 CSRG 原始 SCCS 元数据作为史料保存于 McKusick CD-ROM #4 与 Bancroft CU-551 全宗；FreeBSD CVS 仓库持续到 **2008 年** 迁移到 SVN（Subversion），**2020 年 12 月** src 仓库迁移到 Git；NetBSD CVS 仓库持续到 **2016 年** 迁移到 CVS 同步 Git 镜像；OpenBSD CVS 仓库持续到今（仍使用 CVS）；SCCS → CVS → SVN → Git 的演化路径反映开源项目版本控制系统的演化趋势。版本控制系统演化路径如下：

| 系统 | 起源时间 | 在 BSD 中的使用 | 后续演化 |
| -- | ------ | ------------- | ------ |
| SCCS | **1972 年** Bell Labs | CSRG **1980-1995** 使用 | 元数据保存于 McKusick CD-ROM #4 |
| CVS | **1986 年** Dick Grune | FreeBSD/NetBSD/OpenBSD 主仓 | FreeBSD 迁移至 SVN，OpenBSD 仍使用 |
| SVN | — | FreeBSD **2008 年** 迁移 | NetBSD/OpenBSD 未采用 |
| Git | — | FreeBSD **2020 年 12 月** 迁移 | NetBSD **2016 年** 同步 Git 镜像 |

**史料**：SCCS 元数据（CSRG Archive CD-ROM #4）；FreeBSD 1.0 CVS 仓库记录；NetBSD 0.8 CVS 仓库记录；**cvsup** 工具发布记录（1994，John Polstra）；FreeBSD 2008 年 SVN 迁移公告；FreeBSD 2020-2021 年 Git 迁移公告；NetBSD 2016 年 CVS-Git 同步公告；OpenBSD CVS 仓库档案；SCCS/CVS/SVN/Git 发布记录 ［A］

**史观**：专题语（不设总纲条号）——信息技术史考察（原挂第 19 条系自撰名目，删条号保留分析）——SCCS/CVS/SVN/Git 版本控制系统的演化是 1970-2000 年代信息技术演化的物质遗存；总纲第 3 条——不存在进步，只有权力再分配（原“终结中的延续”系伪名目，按族例改挂，存疑）——CSRG 原始 SCCS 元数据作为史料保存，是 “终结中的延续” 的典型

**辨析**：SCCS 在 CSRG 中作为版本控制系统的具体时间需核对——SCCS 1972 年在 Bell Labs 开发，CSRG 1980 年代起使用，须区分 “SCCS 在 Bell Labs 开发” 与 “CSRG 使用 SCCS”；CVS 在 FreeBSD/NetBSD 中作为版本控制系统的具体时间需核对——FreeBSD 1.0（1993.11）与 NetBSD 0.8（1993.4）发布时 CVS 已在使用；OpenBSD 持续使用 CVS 至今（2025）需核对——OpenBSD 仍使用 CVS 但部分镜像已同步至 Git，须区分 “主仓库” 与 “镜像”

**文献**：SCCS/CVS/SVN/Git 文档；CSRG Archive CD-ROM #4；FreeBSD/NetBSD/OpenBSD CVS 仓库档案；**cvsup** 发布记录；FreeBSD SVN/Git 迁移公告 ［A］

## 83.9.4 4.4BSD-Lite → FreeBSD 2.0/NetBSD 1.0/OpenBSD 重建路径（1994-1996）

  **要点**：4.4BSD-Lite（1994.6）发布后 FreeBSD、NetBSD、OpenBSD 三大 fork 项目均以 4.4BSD-Lite 为代码基础重建——FreeBSD 2.0（1994.11.22 网络发布/1994.12 CD-ROM）基于 4.4BSD-Lite 重建，从 FreeBSD 1.x（基于 386BSD 0.1 + Net/2）迁移到 4.4BSD-Lite 完全自由基础，消除 USL 诉讼争议文件的法律风险；NetBSD 1.0（1994.10.26）基于 4.4BSD-Lite 重建，从 NetBSD 0.x 迁移到 4.4BSD-Lite 完全自由基础；OpenBSD 于 1995 年 10 月由 Theo de Raadt 从 NetBSD 1.0 fork，间接基于 4.4BSD-Lite，第一个正式版本 OpenBSD 1.2 于 1996 年 7 月发布；4.4BSD-Lite → 三大 fork 重建路径是 BSD 代码基础从 “Net/2 含争议代码” 到 “4.4BSD-Lite 完全自由代码” 的关键迁移；FreeBSD 2.0/NetBSD 1.0 的 4.4BSD-Lite 重建是 BSD 谱系从 “CSRG 主线” 到 “三大 fork 分支” 的关键转型，CSRG 1995 年解散后 BSD 主线代码演化权完全转移至三大 fork 项目
  
**史料**：4.4BSD-Lite Release Notes（1994.6）；FreeBSD 2.0 Release Announcement（1994.11.22 Jordan Hubbard 原始公告）；NetBSD 1.0 Release Announcement（1994.10.26）；OpenBSD 项目起源记录；USL v. BSDi 和解协议（1994.1）；McKusick 1999 Open Sources；CSRG 解散记录（1995.6） ［A］
  
**史观**：总纲第 13 条——法律与道德是利益分配（原“许可证”挂第 24 条系伪名目，按许可证决定演化路径论旨改挂，存疑）——4.4BSD-Lite 完全自由许可证是三大 fork 重建的法律基础，许可证模式决定了 BSD 代码的演化路径；总纲第 4 条——分离聚合是永恒规律（原挂第 11 条系条号错配，正名）——4.4BSD-Lite → 三大 fork 重建是 BSD 代码从 “CSRG 主线聚合” 分离为 “三大 fork 分支聚合”，分离是聚合的前提
  
**辨析**：FreeBSD 2.0/NetBSD 1.0/OpenBSD 的 4.4BSD-Lite 重建需区分 “基础迁移” 与 “完全重写”——三大 fork 在 4.4BSD-Lite 基础上保留各自特有代码（如 FreeBSD 特有的设备驱动、NetBSD 特有的多平台支持），并非 “完全重写”；需注意 NetBSD 1.0（1994.10.26）发布早于 FreeBSD 2.0（1994.11.22）约一个月；Novell-UC Berkeley 和解协议签署于 1994 年 1 月而非 1994 年 6 月
  
**文献**：4.4BSD-Lite Release Notes；FreeBSD 2.0/NetBSD 1.0 Release Announcements；OpenBSD 项目起源；McKusick 1999 Open Sources；USL v. BSDi 和解协议 1994.1 ［B］
