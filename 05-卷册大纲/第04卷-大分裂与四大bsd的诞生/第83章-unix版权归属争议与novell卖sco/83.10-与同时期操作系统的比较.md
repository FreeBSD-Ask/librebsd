# 83.10 与同时期操作系统的比较：1994 年同期 Windows NT 3.5、Solaris 2.4、IBM OS/2 Warp

## 83.10.1 Windows NT 3.5 的比较

  **要点**：**1994 年** Windows NT 3.5 发布，定位企业市场，支持 x86、MIPS、Alpha 多架构（PowerPC 支持自 NT 3.51 起），提供 Win32 API；与 4.4BSD-Lite 相比，NT 3.5 商业支持完善但开源程度为零，技术架构（微内核 vs 宏内核）与许可模式（专有 vs 开源）形成鲜明对比
  
**史料**：Windows NT 3.5 Release 1994 微软公告；Windows NT 内核架构文档；4.4BSD-Lite Release Notes［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档与公告〕
  
**史观**：专题语（不设总纲条号）——技术选择即政治选择：NT 的微内核架构与 4.4BSD-Lite 的宏内核架构反映不同的技术政治选择
  
**辨析**：NT 3.5 与 4.4BSD-Lite 的比较须区分 “市场份额”（NT 3.5 经微软企业销售渠道在商业市场胜出）与 “技术影响”（4.4BSD-Lite 经 FreeBSD 2.0 1994.11.22、NetBSD 1.0 1994.10.26、OpenBSD 1995.10 fork 在开源生态影响深远）；技术影响的多维评估经 bsd_commits.duckdb 三大 fork 首条 commit 时间（FreeBSD 1993-06-12、NetBSD 1993-03-21、OpenBSD 1995-10-18）可量化——4.4BSD-Lite 代码遗产持续至 2026 年，NT 3.5 已被 NT 4.0/2000/XP/Server 2003 等后续版本取代

## 83.10.2 Solaris 2.4 的比较

  **要点**：1994 年 SunOS 5.4 (Solaris 2.4) 发布，基于 SVR4，支持 SPARC 与 x86，提供与企业 Unix 兼容的 ABI；与 4.4BSD-Lite 相比，Solaris 2.4 是商业 UNIX 的延续，BSD 与 SVR4 的分野在 1994 年已基本定型
  
**史料**：Solaris 2.4 Release 1994 Sun 公告；SVR4 与 BSD 比较文档；4.4BSD-Lite Release Notes［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档与公告〕
  
**史观**：总纲第 4 条分离聚合是永恒规律：BSD 与 SVR4 的分离在 1994 年已定型，Solaris 与 4.4BSD-Lite 走向不同路径
  
**辨析**：Solaris 2.4 与 4.4BSD-Lite 的比较须考虑 “商业 UNIX 续命”（Solaris 2.4 基于 SVR4，经 Sun 商业销售渠道在 SPARC 工作站市场延续）与 “开源 BSD 兴起”（4.4BSD-Lite 经 FreeBSD 2.0、NetBSD 1.0 在 x86 服务器市场兴起）的张力——BSD 与 SVR4 的分野在 1994 年已定型，前者经开源许可证（BSD）扩散，后者经商业许可证（Sun、HP、IBM）续命，二者经许可证模式差异走向不同路径

## 83.10.3 IBM OS/2 Warp 的比较

  **要点**：1994 年 IBM OS/2 Warp 3.0 发布，定位桌面与小型企业市场，提供 32 位抢占式多任务；与 4.4BSD-Lite 相比，OS/2 Warp 定位桌面市场，4.4BSD-Lite 定位服务器市场，两者市场定位不同但都面临 Windows 95 的竞争压力
  
**史料**：OS/2 Warp 3.0 Release 1994 IBM 公告；OS/2 与 Windows 竞争史；4.4BSD-Lite Release Notes［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档/L5 二手研究〕
  
**史观**：专题语（不设总纲条号）——技术选择即政治选择：OS/2 与 4.4BSD-Lite 的不同技术选择反映不同的市场政治策略
  
**辨析**：OS/2 Warp 与 4.4BSD-Lite 的比较需考虑 “桌面 vs 服务器” 的市场定位差异；不得直接对比市场份额

## 83.10.4 比较的辨析

  **要点**：4.4BSD-Lite 与 Windows NT 3.5、Solaris 2.4、IBM OS/2 Warp 的比较辨析须区分 “技术架构”（微内核 vs 宏内核、SVR4 vs BSD、32 位抢占式多任务 vs 分时多任务）与 “市场定位”（企业 vs SPARC 工作站 vs 桌面 vs 服务器）——前者可技术对比，后者经各操作系统的发布档案与第三方市场份额统计（IDC、Gartner）场景化评估；单一维度的决定论（如仅以许可模式判断胜负）经 Windows NT 3.5 商业市场胜出但开源生态影响为零、4.4BSD-Lite 商业市场份额有限但开源生态影响深远的对照可证伪。1994 年同期操作系统对照如下：

| 操作系统 | 发布时间 | 技术架构 | 市场定位 | 许可模式 |
| ------ | ------ | ------ | ------ | ------ |
| 4.4BSD-Lite | **1994.6** | 宏内核 | 服务器 | BSD 开源 |
| Windows NT 3.5 | **1994 年** | 微内核 | 企业 | 专有 |
| Solaris 2.4 | **1994 年** | SVR4 | SPARC 工作站 | 专有 |
| IBM OS/2 Warp 3.0 | **1994 年** | 32 位抢占式多任务 | 桌面 | 专有 |

**史料**：四个操作系统的发布档案；技术架构文档；市场份额第三方统计［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档与公告〕

**史观**：0 信任原则（考据规则）：比较辨析须对照各操作系统的发布档案（Windows NT 3.5 1994 微软公告、Solaris 2.4 1994 Sun 公告、OS/2 Warp 3.0 1994 IBM 公告、4.4BSD-Lite Release Notes 1994.6）与第三方市场份额统计交叉验证，市场份额数据须采信 IDC、Gartner 等权威机构报告而非厂商自述

**辨析**：比较的解释力存在边界——部分学者过于强调单一维度（如许可模式），架构（微内核 vs 宏内核）、市场（企业 vs 桌面 vs 服务器）、生态（商业支持 vs 开源社区）多维因素须综合评估——Windows NT 3.5 在商业市场胜出但开源生态影响为零，4.4BSD-Lite 在商业市场份额有限但开源生态影响深远，二者经不同维度评估结论不同

### 史观映射

> Karels 的告别邮件发出去的那天，CSRG 不是终结了，而是散开了——代码、人、许可证，像一把沙子从指缝间漏下，每一粒都落在了不同的地方。4.4BSD-Lite 是这些沙粒中最干净的一把：不含 AT&T 代码，法律上无可争议，成为 FreeBSD、NetBSD、OpenBSD 三个项目共同的重建基础。CSRG 的解散不是历史的断裂，而是总纲第 4 条分离聚合是永恒规律的又一次展开：一个中心消失了，三个分支从它的遗产中各自生长。FreeBSD 基于 4.4BSD-Lite 的重建不是回归，而是聚合——旧代码在新手中获得了新的命运
