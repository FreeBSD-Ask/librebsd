# 69.6 de Raadt 与 Chuck Cranor 建立匿名 CVS（anoncvs）服务器——两人 1999 年合著论文称此举使用户得以“在调试与开发中扮演更积极的角色”（take a more active role）

## 69.6.1 匿名版本控制服务器的建立

  **要点**：de Raadt 与 Chuck Cranor 创建匿名 CVS（anoncvs）机制——据两人 1999 年 USENIX 论文自述，1995 年秋（Fall of 1995）OpenBSD 项目启动时决定以 CVS 管理源码树，为化解“开放协作环境与仅限特权开发者访问的私有仓库”之间的冲突而创建匿名 CVS，即互联网上第一个匿名 CVS 服务器（用于分发 OpenBSD）；服务器是 OpenBSD 早期开发的基础设施，允许用户匿名只读访问源码仓库［考据注：2026-09-11 联网核验留痕——USENIX FREENIX 1999 论文原文与 Chuck Cranor 个人主页一手核验；旧稿“1995 年初/1995 年中”两说不取］
  
**史料**：Cranor C D, de Raadt T. Opening the Source Repository with Anonymous CVS（USENIX FREENIX 1999 论文，usenix.org 存档，2026-09-11 核验，其中自述 1995 年秋创建匿名 CVS 并首次实现）；Chuck Cranor 个人主页（**chuck.cranor.org**，自述“hosted and helped create the first Anonymous CVS server on the Internet—the original anoncvs.openbsd.org, also known as eap.ccrc.wustl.edu”，2026-09-11 核验）；OpenBSD 官方 FAQ、OpenBSD CVS 历史早期记录（未取得具体页面著录） 〔L3 论文/L4 事后叙述〕
  
**史观**：总纲第 10 条——动手者创造历史：匿名 CVS 服务器由动手者设计、实现并托管，是 OpenBSD 开放协作文化的技术基础
  
**辨析**：服务器建立的具体时点：旧稿“部分资料称 1995 年初，部分称 1995 年中”两说均与一手史料冲突——Cranor 与 de Raadt 在 1999 年 USENIX 论文中自述 1995 年秋 OpenBSD 项目启动时创建匿名 CVS，与 OpenBSD 自 NetBSD 分出（1995 年 10 月）的章节时间线自洽，精确上线月份一手史料未载。　[存疑脚注] anoncvs 服务对公众开放的精确月份待考，须对照 openbsd.duckdb 早期 CVS 提交记录与邮件列表存档交叉验证
