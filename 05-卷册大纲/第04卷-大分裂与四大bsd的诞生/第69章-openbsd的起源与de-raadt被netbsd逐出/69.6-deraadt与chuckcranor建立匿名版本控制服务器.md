# 69.6 de Raadt 与 Chuck Cranor 建立匿名 CVS（anoncvs）服务器——两人 1999 年合著论文称此举使用户得以“在调试与开发中扮演更积极的角色”（take a more active role）

## 69.6.1 匿名 CVS（anoncvs）服务器的建立

## 69.6.4 服务器的意义

**要点**：匿名 CVS 的意义在于提供开放协作的基础设施——据两人 1999 年 USENIX 论文，它把 CVS 仓库中的修订、历史与分支信息公开，使用户得以匿名只读访问源码与历史，降低贡献门槛；OpenBSD 甚至随 CD-ROM 附带已检出的 CVS 树，便于用户直接上手；此机制长期影响 OpenBSD 开放协作文化的形成，其后被 FreeBSD、NetBSD、Mozilla、GNOME、Python 等项目采用

**史料**：Cranor C D, de Raadt T. Opening the Source Repository with Anonymous CVS（USENIX FREENIX 1999，2026-09-11 核验，论文第 5 节列出采用 anoncvs 的项目清单） 〔L3 论文〕

**史观**：总纲第 10 条——动手者创造历史：匿名 CVS 服务器是动手者建成的开放协作基础设施，开放协作文化由具体的动手者工程实践塑造

**辨析**：服务器对 OpenBSD 文化的具体影响在不同叙事中评估不一——部分视为决定性，部分视为辅助性。 [存疑脚注] 须对照社区发展史与后续项目采用情况（FreeBSD、NetBSD 等）核实
