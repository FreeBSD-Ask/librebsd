# 069.6.3 1.0 的太少太迟批评

  **要点**：**386BSD 1.0**（1994 年末/late 1994）发布时社区普遍批评 “too little, too late”——**FreeBSD 1.0** 已于 **1993 年 11 月** 公告、**12 月** 通过 Walnut Creek CDROM 发行并积累用户，**NetBSD 0.8** 已于 **1993 年 4 月** 发布且早已成熟；386BSD 1.0 失去历史窗口
  
**史料**：comp.unix.bsd 1994 年对 1.0 的评论、386BSD 1.0 release notes、FreeBSD Project 历史回顾、NetBSD Project 官方历史时间线［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］；freebsd.duckdb 查询 L1.4.1 显示：FreeBSD 在 386BSD 1.0 发布同期（1994 末）已完成 `release/1.1.0_cvs`（1994-05-01）、`release/1.1.5.1_cvs`（1994-07-01）、`release/2.0`（1994-11-22）三次 release tag，间隔分别为 181 天、61 天、144 天，反映 FreeBSD 以约 2-6 个月周期持续发布，与 386BSD 约 2 年无公开版本形成鲜明对比。FreeBSD release tag 时间线如下：

| Tag | 日期 | 距上次间隔 |
|---| -- | -------- |
| `release/1.1.0_cvs` | 1994-05-01 | 181 天 |
| `release/1.1.5.1_cvs` | 1994-07-01 | 61 天 |
| `release/2.0` | 1994-11-22 | 144 天 |

**史观**：经济周期：技术产品的市场窗口具有不可逆性

**辨析**：1.0 的具体发布日期需对照 Usenet 原始帖进一步核验（部分二手资料标注为 late 1994）；FreeBSD 1.0 发布于 1993 年 11 月公告、12 月 CD-ROM 发行，非泛泛的 “1993.12”；经[参考文献库]验证通过：FreeBSD Handbook 原文记载"st CD-ROM (and general net-wide) distribution was FreeBSD 1.0, released in December of [1993]"（reference_id=60, fact_id=658, confidence=0.9），印证 FreeBSD 1.0 首次 CD-ROM 发行于 1993 年 12 月；【0 信任原则·release tag 间隔局限】L1.4.1 查询的 release tag 间隔反映发布节奏但不等于开发节奏，部分 release tag（如 release/1.0.0_cvs）由 svn2git 迁移工具标注而非原作者，tagger_date 可能为 SVN 时代 commit 日期而非实际公告日期，须与 FreeBSD 1.0 Release Announcement（1993.11.1）交叉验证；【0 信任原则·tagger_name 验证】release/2.0 tag 由 Jordan K. Hubbard（乔丹·哈伯德） 本人标注，可信度高于 svn2git 标注的 tag
