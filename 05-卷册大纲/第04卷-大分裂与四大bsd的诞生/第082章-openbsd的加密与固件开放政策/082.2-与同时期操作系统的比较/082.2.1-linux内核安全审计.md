# 082.2.1 Linux 内核安全审计


**1995-1996 年** 同期操作系统安全路径对照如下：

| 操作系统 | 安全路径 | 目标定位 | 与 OpenBSD 对照 |
| ------ | ------ | ------ | ------------- |
| OpenBSD | 全代码审计 | 社区安全至上 | 基准 |
| Linux 内核 | 内核安全审计 | 开源社区 | 审计深度与 OpenBSD 存在差距 |
| Windows NT 4.0 | 商业安全模型 | 商业环境 | 强调商业环境安全 |
| Solaris 2.5 | 企业级安全机制 | 企业级 | 强调企业级安全 |

  **要点**：1995-1996 年 Linux 内核安全审计——Linux 在同期也开始关注内核安全，但审计深度与 OpenBSD 相比存在差距；Linux 安全审计路径与 OpenBSD 形成对照
