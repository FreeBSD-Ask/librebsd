# 70.7 1995 年 10 月 CVS 仓库初始导入与 1996 年 7 月 OpenBSD 1.2 首次发布

## 70.7.1 OpenBSD 项目的启动
  - 要点：OpenBSD 项目启动于 1995 年——基于 NetBSD 1.0 源码分叉，de Raadt 与早期开发者进行全代码审计与安全加固；1995 年 10 月 18 日完成 CVS 仓库初始导入，标志项目正式启动；开发过程强调代码质量与安全性
  - 史料：OpenBSD CVS 历史早期记录（1995.10.18 初始导入）、de Raadt 个人主页自述；openbsd.db 数据库证据——openbsd-src 仓库首条 commit 为 deraadt 1995-10-18T08:37:01Z “initial import of NetBSD tree”（commit_hash `df930be708d50e9715f173caa26ffe1b7599b157`），author_date 与 committer_date 完全一致，与大纲记载 1995 年 10 月 18 日 CVS 仓库初始导入完全吻合；OpenBSD src GitHub 镜像 1995-10 月共 30 个 commit，全部由 deraadt 提交，commit message 内容包括 “initial import of NetBSD tree”（首条）、“initial import of pica stuff (a few theo modifications already in here)”（第 2 条）、“mvme68k port by me. some parts by dale rahn.”（第 3 条）等，证实 fork 后立即进行多平台代码 import；deraadt（Theo de Raadt）在 netbsd-src 末次 commit 为 1994-12-17T23:12:41Z（commit_hash `699d2a37b0e3c0c6ff29ea0d407c3feeba5642b4`，subject “correct ie [1234] addreses”），与其被 NetBSD 核心团队撤销 commit bit 的时间吻合；deraadt 在 openbsd-src 首次 commit（1995-10-18T08:37:01Z）与 netbsd-src 末次 commit（1994-12-17T23:12:41Z）间隔约 304 天（约 10 个月），此期间为 Theo de Raadt 筹备 OpenBSD 项目的筹备阶段；deraadt 在 openbsd-src 共 27181 个 commit，末次 commit 为 2026-07-16T22:03:31Z，是 OpenBSD 项目最长持续贡献者 ［A］
  - 史观：总纲第 5 条——组织结构塑造技术路径：基于 NetBSD 分叉的开发路径决定 OpenBSD 的工程方向
  - 辨析：开发的具体起点时点已确认为 1995 年 10 月 18 日（CVS 初始导入时间），先前为筹备阶段；bsd_commits.db 验证结论——openbsd-src 首条 commit 的 author_date 与 committer_date 完全一致（均为 1995-10-18T08:37:01Z），且 commit message 明确为 “initial import of NetBSD tree”，与大纲记载的 “基于 NetBSD 1.0 源码分叉” 完全吻合，无任何日期偏差；deraadt 在 netbsd-src 的末次 commit（1994-12-17）与在 openbsd-src 的首次 commit（1995-10-18）间隔 304 天，此 10 个月空窗期与大纲记载的 “被撤销 commit bit 后筹备 OpenBSD” 叙事完全吻合；0 信任原则提示：OpenBSD 主仓为 CVS (anoncvs.openbsd.org)，GitHub 仓库为只读 git 镜像，可能滞后于主仓，1995 年 10 月的早期 commit 可能存在缺失；CVS-to-Git 转换可能引入日期偏差或作者归属错误，1995-1996 年间的 commit 时间戳须与 OpenBSD 官方公告、Theo de Raadt 个人声明、NetBSD 核心团队撤销权限公告等多源交叉验证；OpenBSD src GitHub 镜像无 tag 信息，OpenBSD 1.2/2.0 等版本发布时间须以 OpenBSD 官方公告为准

## 70.7.2 OpenBSD 1.2 的首次公开发布
  - 要点：**OpenBSD 1.2** 于 **1996 年 7 月** 发布——作为 OpenBSD 项目首个正式公开版本；发布标志 OpenBSD 作为独立 BSD 项目正式进入公众视野；**1996 年 10 月** 发布 **OpenBSD 2.0**，确立每 6 个月一个大版本的发布节奏。OpenBSD 早期版本发布时间线如下：

| 版本 | 发布日期 | 备注 |
| --- | --- | --- |
| OpenBSD 1.0/1.1 | 1995-1996 年内部 | 从未公开发布 |
| OpenBSD 1.2 | 1996-07 | 首次公开发布 |
| OpenBSD 2.0 | 1996-10 | 确立 6 个月发布节奏 |

- 史料：OpenBSD 1.2 发布声明（1996.7）、OpenBSD 2.0 发布声明（1996.10）、OpenBSD 官方 FAQ[考据完成：2026-07-28 经穷尽联网考据，上述史料清单为已知公开来源汇总，部分原始档案未公开数字化或须档案馆藏地现场核验，属史料缺口，须待原始档案公开后方可补充确证]；openbsd.db 查询 L1.1.1 显示：openbsd-src 1995 年仅 770 commits（占当年 4 大 BSD src 仓库总量 20,656 的 3.73%），反映 1995.10.18 fork 后至年底的启动阶段 commit 活跃度有限；1996 年 openbsd-src = 5,240 commits（占当年 4 大 BSD src 仓库总量 29,245 的 17.92%），较 1995 年增长约 6.8 倍，反映 OpenBSD 1.2 发布当年开发活跃度大幅提升，与 OpenBSD 1.2 首次公开发布（1996.7）的工程节奏吻合
- 史观：总纲第 2 条——分离与聚合：OpenBSD 1.2 的发布标志 BSD 阵营的新聚合
- 辨析：OpenBSD 1.0/1.1 为内部开发版本，从未公开发布；首个公开版本为 1.2（1996.7），此点常被误述为 1.0（1995.10）；【0 信任原则·commit 量不等于质量】L1.1.1 的 1995-1996 openbsd-src commit 量（770→5,240）反映开发活跃度但不等于代码质量，OpenBSD 1.2 的 “全代码审计” 质量须结合 commit message 主题词与安全公告记录综合判断；【0 信任原则·CVS-to-Git 迁移风险】openbsd-src 主仓为 CVS（anoncvs.openbsd.org），GitHub 为只读 git 镜像，CVS-to-Git 转换可能引入日期偏差或作者归属错误，1995-1996 年 commit 时间戳须与 OpenBSD 官方公告交叉验证；【0 信任原则·GitHub 镜像滞后】openbsd-src GitHub 镜像可能滞后于 CVS 主仓，1995-1996 年的早期 commit 可能存在缺失；【L1.4.1 release tag 信息缺失】bsd_commits.db 查询 L1.4.1 结果显示 openbsd-src GitHub 镜像无 OPENBSD_ 前缀的 release tag 条目，无法通过 tag 间隔验证 OpenBSD 1.0/1.1/1.2/2.0 发布节奏，OpenBSD 发布时间须以官方公告为准；【L7.1.1.openbsd-src 查询不存在】bsd_commits.db 数据分析报告《衍生项目与跨项目对比分析.md》中 L7.1.1 系列仅含 ghostbsd-src、hardenedbsd-src、trueos-src、pfsense-src 四个 FreeBSD 衍生项目的 merge commit 比例查询，无 openbsd-src 专用查询，OpenBSD 从 NetBSD fork 的分歧路径识别须通过 commit_hash 与 parent_hashes 的手动比对补全，不可凭空引用
- 文献：OpenBSD 1.2 发布声明；OpenBSD 官方 FAQ；OpenBSD 发布历史[考据完成：2026-07-28 经穷尽联网考据，上述文献清单为已知公开来源汇总，部分原始档案未公开数字化或须付费访问，属史料缺口，须待原始档案公开后方可补充确证]；本项目。bsd_commits.db 数据分析报告：宏观趋势统计 [R/OL]. 2026.
## 70.7.3 OpenBSD 1.2 的技术特性
  - 要点：OpenBSD 1.2 的技术特性包括全代码审计、密码学加固、安全默认配置——基于 NetBSD 1.0 但增加安全审计；特性奠定 OpenBSD 安全至上路径的基础
  - 史料：OpenBSD 1.2 发布声明、OpenBSD 1.2 源码、OpenBSD 官方 FAQ ［A］
  - 史观：总纲第 6 条——技术选择的代价：安全至上的工程选择带来性能与功能广度的牺牲
  - 辨析：技术特性的具体范围在不同叙事中略有差异——需对照源码与发布声明核实
  - 文献：OpenBSD 1.2 发布声明；OpenBSD 1.2 源码 ［A］
## 70.7.4 OpenBSD 1.2 的反响

  - 史料：BSD 与 Linux 邮件列表 1996.7-1996 年存档、开源社区访谈录 ［A］

  - 辨析：反响的具体分布在不同叙事中差异较大——部分资料称多数认可，部分称多数质疑；需对照邮件列表存档统计核实
