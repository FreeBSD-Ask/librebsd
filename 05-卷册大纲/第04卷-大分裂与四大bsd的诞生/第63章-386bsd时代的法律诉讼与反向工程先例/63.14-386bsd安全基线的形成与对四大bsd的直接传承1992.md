## 63.14.1 386BSD 安全基线的具体内容——4.3BSD-Reno 安全机制在 80386 平台的完整移植

  **要点**：**386BSD 0.0**（**1992-03-12**）与 **0.1**（**1992-07-14**）由 Bill Jolitz 与 Lynne Jolitz 夫妇完成，基于 4.3BSD-Reno 与 Networking Release 2（Net-2，1991），是 BSD UNIX 在 Intel 80386 个人计算机平台上的首次完整移植；386BSD 的安全基线本质上是 4.3BSD-Reno 安全机制在 80386 平台的移植，未引入新的安全机制——root/超级用户二元特权模型（继承自 Research UNIX v4）、文件权限 rwx 三段式结构（继承自 UNIX v4/v6）、setuid/setgid 机制（继承自 UNIX v6）、基于 DES 的 **crypt(3)** 密码散列（继承自 UNIX v7）、单文件 **`/etc/passwd`**（未引入 shadow password）、4.3BSD 网络栈远程漏洞面（sendmail DEBUG、fingerd 缓冲区溢出、**`~/.rhosts`** 信任链）；386BSD 未引入 securelevel（4.4BSD-Lite 才引入）、未引入 chroot 安全沙箱用途（chroot 在 4.4BSD-Lite 时期仍为构建隔离用途）、未引入 shadow password（System V 才有 **`/etc/shadow`**，BSD 延续单 **`/etc/passwd`** 直至 FreeBSD 4.x 才弥合）。386BSD 安全基线机制对照如下：

| 安全机制 | 来源 | 386BSD 引入 |
| ------ | -- | --------- |
| root/超级用户二元特权模型 | Research UNIX v4 | 继承 |
| 文件权限 rwx 三段式结构 | UNIX v4/v6 | 继承 |
| setuid/setgid 机制 | UNIX v6 | 继承 |
| **crypt(3)** DES 密码散列 | UNIX v7 | 继承 |
| 单 **`/etc/passwd`** | 4.3BSD-Reno | 继承 |
| 4.3BSD 网络栈远程漏洞面 | 4.3BSD-Reno | 继承 |
| securelevel | 4.4BSD-Lite | 未引入 |
| chroot 安全沙箱用途 | 4.4BSD-Lite | 未引入 |
| shadow password | System V | 未引入 |

**史料**：386BSD 0.0 与 0.1 源代码与 release notes（1992）；Bill Jolitz 与 Lynne Jolitz 在 Dr. Dobb's Journal 的 386BSD 移植系列文章（1991 年起）；CSRG 邮件列表存档（1991-1994）；Networking Release 2（Net-2）发布说明（1991） ［A］

**史观**：总纲第 4 条——分离聚合是永恒规律：386BSD 安全基线是 BSD 前安全史（1969-1992）与 BSD 后安全史（1992 年后四大 BSD CVE 漏洞史）之间的关键过渡，386BSD 将 BSD UNIX 安全基因从 VAX 与 Sun 工作站的学术场景带入个人计算机平台；硬件与软件辩证：Intel 80386 的 32 位地址空间与硬件 MMU 是 BSD PC 化的硬件前提，386BSD 安全机制在 80386 平台的移植是硬件发展推动软件演化的具体呈现（“硬件与软件辩证” 为本章专题语，未对应总纲 25 条单一条目，故不设条号）

**辨析**：386BSD 安全基线的具体内容须区分 “继承自 4.3BSD-Reno” 与 “386BSD 新引入”——386BSD 未引入任何新的安全机制，所有安全机制均继承自 4.3BSD-Reno；386BSD 未引入 securelevel 的考据基于 4.4BSD SMM: 16《On the Security of UNIX》中关于 securelevel 的描述（4.4BSD 引入）与 386BSD 0.0/0.1 源代码的对照，386BSD 源代码中未发现 securelevel 相关代码；386BSD 未引入 shadow password 的考据基于 386BSD 0.0/0.1 源代码中 `/etc/passwd` 格式与 System V `/etc/shadow` 的对照；【0 信任原则·当事人自述需交叉验证】Bill Jolitz 与 Lynne Jolitz 在 Dr. Dobb's Journal 的连载文章须与 386BSD 0.0/0.1 源代码、CSRG 邮件列表存档交叉验证

**文献**：386BSD 0.0/0.1 Release Notes (1992)；Jolitz W F, Jolitz L G. Porting UNIX to the 386 [J]. Dr. Dobb's Journal, 1991-1992；Networking Release 2 Release Notes (1991)；CSRG 邮件列表存档 (1991-1994) ［A］

## 63.14.2 386BSD 安全基线对 FreeBSD 1.0 与 NetBSD 0.8/0.9 的直接传承

  **要点**：386BSD 0.1 是 FreeBSD 1.0（1993-11-01）与 NetBSD 0.8/0.9（1993）的共同直接基线；FreeBSD 1.0 由 Nate Williams（内特·威廉姆斯）、Rod Grimes、Jordan Hubbard 等在 386BSD 0.1 补丁集基础上 fork 发布，NetBSD 0.8/0.9 由 Chris Demetriou、Theo de Raadt（西奥·德·若特）、Adam Glass（亚当·格拉斯）、Charles Hannum 等因对 386BSD 维护方向的不同意见 fork 发布；386BSD 的安全基线（root 模型、rwx 权限、setuid 机制、**crypt(3)** 散列、单 `/etc/passwd`、4.3BSD 网络栈远程漏洞面）通过 FreeBSD 1.0 与 NetBSD 0.8/0.9 直接传递给 FreeBSD 与 NetBSD，是 1992 年四大 BSD 分立时 FreeBSD 与 NetBSD 共同的安全起点；安全补丁的继承与分歧从此分别由 FreeBSD 与 NetBSD 社区独立维护
  
**史料**：FreeBSD 1.0 Release Announcement (1 Nov 1993)；NetBSD 0.8 Release Notes (1993.4)；`freebsd-hackers` 与 `netbsd` 邮件列表存档（1993-1994）；McKusick M K, Bostic K, Karels M J, Quarterman J S. The Design and Implementation of the 4.4BSD Operating System. Addison-Wesley, 1996；Salus P H. A Quarter Century of UNIX. Addison-Wesley, 1994 ［A］
  
**史观**：总纲第 4 条——分离聚合是永恒规律：386BSD 开发停滞直接催生 FreeBSD 与 NetBSD 两个独立社区，分离后产生新的聚合——安全补丁的继承与分歧从此分别由 FreeBSD 与 NetBSD 社区独立维护；BSD 反向影响线：386BSD 安全基线通过 FreeBSD 与 NetBSD 直接传承，是 BSD UNIX 安全基因在四大 BSD 分立后得以延续的直接史源（“BSD 反向影响线” 为本章专题语，未对应总纲 25 条单一条目，故不设条号）
  
**辨析**：386BSD 安全基线对 FreeBSD 与 NetBSD 的传承须区分 “代码继承” 与 “安全补丁维护”——前者通过 386BSD 0.1 源代码直接继承，后者在 fork 后分别由 FreeBSD 与 NetBSD 社区独立维护；FreeBSD 1.0 基于 “U.C. Berkeley‘s 4.3BSD-Lite (’Net/2') tape distribution”，非直接基于 “386BSD 0.1 + 4.3BSD-Reno”，须区分 “Net/2 基础” 与 “386BSD 0.1 补丁集基础”——FreeBSD 1.0 同时继承 Net/2 与 386BSD 0.1 补丁集，安全基线来自 Net/2（即 4.3BSD-Reno 网络栈）经 386BSD 0.1 移植至 80386 平台；NetBSD 0.8/0.9 虽基于 386BSD 部分代码但更早脱离 386BSD 单人维护模式，NetBSD 0.8 的 386BSD 0.1 import commit（cgd, 1993-03-21T09:45:37Z, `0d110d127c41d7aeb2b1bfdc71964c5a496eabf9`）早于 NetBSD 0.8 公告（1993-04-19）约 1 个月
  
**文献**：FreeBSD 1.0 Release Announcement (1 Nov 1993)；NetBSD 0.8 Release Notes (1993.4)；McKusick M K, Bostic K, Karels M J, Quarterman J S. The Design and Implementation of the 4.4BSD Operating System [M]. Reading, MA: Addison-Wesley, 1996. ISBN 0-201-54979-4；Salus P H. A Quarter Century of UNIX [M]. Reading, MA: Addison-Wesley, 1994. ## 63.14.3 386BSD 安全基线对 OpenBSD 1.0 的间接传承与被 4.4BSD-Lite 取代

  **要点**：386BSD 0.1 是 OpenBSD 1.0（1996-07，从 NetBSD 1.0 fork）的间接前身——OpenBSD 通过 NetBSD 1.0 间接继承 386BSD 安全基线，但 OpenBSD 1.0 的直接基线是 NetBSD 1.0（1994，基于 4.4BSD-Lite），而非 386BSD 0.1；1994 年 6 月 4.4BSD-Lite 发布后，FreeBSD 2.0（1995）与 NetBSD 1.0（1994）均 rebase 至 4.4BSD-Lite，386BSD 作为直接安全基线的地位被 4.4BSD-Lite 取代；4.4BSD-Lite 引入 securelevel 内核安全等级机制（level 0/1/2 分级约束 root 用户运行时特权），是 386BSD 安全基线未包含的新机制；OpenBSD 1996 年 fork 后的全代码审计工程可视为对 386BSD 安全基线缺陷（4.3BSD 网络栈远程漏洞面、单 `/etc/passwd` 无 shadow password）的激进回应
  
**史料**：OpenBSD 1.0 Release Notes (1996.7)；NetBSD 1.0 Release Notes (1994.10)；4.4BSD-Lite Release Notes (1994.6)；4.4BSD SMM: 16《On the Security of UNIX》；McKusick M K, Bostic K, Karels M J, Quarterman J S. The Design and Implementation of the 4.4BSD Operating System. Addison-Wesley, 1996 ［A］
  
**史观**：总纲第 5 条——偶然性改写历史：386BSD 开发停滞直接催生 FreeBSD 与 NetBSD，NetBSD 内部冲突又催生 OpenBSD，386BSD 安全基线通过这一偶然链条间接传递给 OpenBSD；形式与内容：4.4BSD-Lite 取代 386BSD 作为直接安全基线是 “形式（法律洁净的 4.4BSD-Lite）压倒内容（386BSD 安全基线的延续）” 的转折（“形式与内容” 为本章专题语，未对应总纲 25 条单一条目，故不设条号）
  
**辨析**：386BSD 安全基线对 OpenBSD 的传承须区分 “直接继承” 与 “间接继承”——OpenBSD 1.0 通过 NetBSD 1.0 fork 间接继承 386BSD 安全基线，但 OpenBSD 1.0 的直接基线是 NetBSD 1.0（基于 4.4BSD-Lite），而非 386BSD 0.1；386BSD 作为直接安全基线的地位被 4.4BSD-Lite 取代的考据基于 FreeBSD 2.0（1995）与 NetBSD 1.0（1994）均 rebase 至 4.4BSD-Lite 的事实，386BSD 0.2（1993，通行著录系 1993 年经 Dr. Dobb's Journal 渠道发布，1994 说未见于通行文献）在 Bill Jolitz 主导下发布，但此时 FreeBSD 与 NetBSD 已独立发展，386BSD 本身的安全影响力急剧下降；【0 信任原则·当事人自述需交叉验证】Theo de Raadt 关于 OpenBSD 创建动机的个人自述须与 NetBSD 邮件列表存档（1994.12）交叉验证
  
**文献**：OpenBSD 1.0 Release Notes (1996.7)；NetBSD 1.0 Release Notes (1994.10)；4.4BSD-Lite Release Notes (1994.6)；4.4BSD SMM: 16《On the Security of UNIX》；McKusick M K, Bostic K, Karels M J, Quarterman J S. The Design and Implementation of the 4.4BSD Operating System [M]. Reading, MA: Addison-Wesley, 1996. ISBN 0-201-54979-4 ［A］
