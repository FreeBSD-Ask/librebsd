# 82.3 CSRG 解散——1995 年 6 月 Mike Karels 的告别邮件

## 81.3.1 解散的语境

  **要点**：CSRG **1995.6** 解散的背景是多方面的——CSRG 自 **1980 年 4 月** 因 DARPA 合同由 Bob Fabry 正式成立，**1992-1994 年** USL v. BSDi 诉讼期间 CSRG 核心成员（Keith Bostic（基思·博斯蒂克）、Kirk McKusick）发起 CSRG Incorporated 非营利组织，通过 4.4BSD-Lite/4.4BSD-Encumbered 发行所得支持 CSRG 最后两年（**1994-1995**）的 bug fix 与完善工作；4.4BSD-Lite2（**1995.6**）发布后，CSRG 认为 BSD 系统已达到稳定可发布状态、bug 报告和功能增强请求大幅减少，使命完成后自然解散；解散标志 BSD 与大学学术研究的传统终结。CSRG 解散时间线如下：

| 时间 | 事件 |
| -- | -- |
| **1980 年 4 月** | CSRG 由 Bob Fabry 因 DARPA 合同正式成立 | | |
| **1980-1992 年** | DARPA 资助 CSRG 进行 BSD 开发 | | |
| **1992-1994 年** | USL v. BSDi 诉讼期间，CSRG Incorporated 成立 | | |
| **1994.6** | 4.4BSD-Lite 发布（法律洁净版本） | | |
| **1994-1995 年** | CSRG 通过发行收入维持最后两年 bug fix | | |
| **1995.6** | 4.4BSD-Lite2 发布，Mike Karels 发布告别邮件，CSRG 解散 | | |

**史料**：McKusick M K. Twenty Years of Berkeley Unix [M]//Open Sources, 1999（当事人一手记载）；4.4BSD-Lite/4.4BSD-Lite2 Release Notes 1994.6/1995.6；Mike Karels 告别邮件 1995.6；DARPA CSRG 资助记录 1980-1992 ［B］

**史观**：商业与社区的张力：CSRG 在 DARPA 资助结束后通过自有发行收入维持至使命完成，而非单纯 “经费枯竭被迫解散”

**辨析**：解散的原因在不同叙事中差异较大——部分叙事简单归因于 “DARPA 资助终止”，但 McKusick 当事人记载明确说明 4.4BSD-Lite/Encumbered 销售收入支持了最后两年的 bug fix 工作，直到 bug 报告和功能增强请求大幅减少后发布 Lite2 并自然解散；“经费枯竭被迫解散” 表述不准确

**文献**：McKusick M K. Twenty Years of Berkeley Unix [M]//Open Sources, 1999；4.4BSD-Lite2 Release Notes 1995.6；Mike Karels 告别邮件 ［B］

## 81.3.2 Karels 的告别邮件

  **要点**：**1995.6** Mike Karels 发布告别邮件，宣布 CSRG 解散与 4.4BSD-Lite2 作为最终版本；告别邮件回顾 BSD 开发历史（自 **1974 年** Ken Thompson 带回 UNIX 起约 21 年，自 **1980 年** CSRG 正式成立起约 15 年）、感谢贡献者、说明 4.4BSD-Lite2 的内容；邮件标志 CSRG 时代的终结

> Berkeley CSRG is now disbanded.
>
> ——Mike Karels，**1995 年 6 月** 告别邮件，宣布 CSRG 解散与 4.4BSD-Lite2 作为最终版本，回顾 BSD 开发历史并感谢贡献者

**史料**：Mike Karels 告别邮件 1995.6 原文；4.4BSD-Lite2 Release Notes 1995.6；CSRG 历史档案；McKusick 1999 Open Sources ［B］

**史观**：社区文化即技术资产：告别邮件作为社区文化遗产承载 CSRG 约 15 年的技术与文化记忆（CSRG 正式成立于 1980.4）

**辨析**：告别邮件的内容在不同叙事中差异较小，但需区分 “BSD 开发历史（1974/1976 起）” 与 “CSRG 组织历史（1980.4 正式成立起）”——前者约 21 年，后者约 15 年；“1976-1995 共 19 年” 表述不准确；邮件具体日期 据 Hennessy (1984) 一手文献印证消解^doubt-resolved-339：此处事实待多源交叉验证 ］，多数来源仅标注 1995 年 6 月，无精确日期

**文献**：Mike Karels 告别邮件原文；4.4BSD-Lite2 Release Notes 1995.6；McKusick M K. Twenty Years of Berkeley Unix [M]//Open Sources, 1999 ［B］

## 81.3.3 解散的形式主义分析

  **要点**：CSRG 解散的形式主义分析显示——解散是 “形式（大学研究组织）与内容（BSD 技术传承）分离” 的典型，CSRG 作为大学研究小组的组织形式因使命完成而自然终结；但 BSD 技术内容（4.4BSD-Lite2）通过社区项目（FreeBSD、NetBSD、OpenBSD）以新的组织形式延续
  
**史料**：McKusick 1999 Open Sources；CSRG 解散公告；FreeBSD/NetBSD/OpenBSD 早期项目档案 ［B］
  
**史观**：形式与内容：解散的形式（大学组织消亡）与内容（技术传承）分离，内容通过新形式（社区项目）延续
  
**辨析**：形式主义分析的边界——部分学者认为解散标志着 BSD 时代的终结，部分认为 BSD 通过社区项目延续；须区分 “CSRG 大学研究组织消亡”（1995.6 Karels 告别邮件 "Berkeley CSRG is now disbanded"）与 “BSD 技术通过社区延续”（FreeBSD/NetBSD/OpenBSD 三大 fork 继承 4.4BSD-Lite2 代码）两个层面；解散原因并非单纯 “DARPA 资助终止”——McKusick 1999 当事人记载明确说明 4.4BSD-Lite/Encumbered 销售收入支持了最后两年的 bug fix 工作
  
**文献**：McKusick 1999 Open Sources；BSD 项目传承研究 ［B］

## 81.3.4 解散的史料辨析

  **要点**：解散的史料辨析须区分 “组织解散” 与 “技术终结”——前者有据可循（CSRG **1995.6** Mike Karels 告别邮件 "Berkeley CSRG is now disbanded"），后者经三大 fork 项目继承 4.4BSD-Lite2 代码延续（FreeBSD 2.0 **1994.11.22**、NetBSD 1.0 **1994.10.26**、OpenBSD **1995.10** fork）；组织与技术的平衡经 CSRG 解散（组织终结）与三大 fork 持续至 **2026 年**（技术延续）的对照可量化

**辨析**：解散的史料价值在 “组织解散” 维度有据可循（CSRG 1995.6 Karels 告别邮件），但在 “技术终结” 维度经 FreeBSD/NetBSD/OpenBSD 三大 fork 持续至 2026 年的客观事实可证伪——BSD 技术通过社区项目长期延续，组织解散与技术终结非同一维度
