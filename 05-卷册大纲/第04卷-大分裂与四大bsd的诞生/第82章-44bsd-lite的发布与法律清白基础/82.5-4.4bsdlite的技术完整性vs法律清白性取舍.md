# 82.5 4.4BSD-Lite 的技术完整性与法律清白性取舍

## 82.5.1 被移除三文件的技术影响

**要点**：和解协议要求移除信号处理、printcap、tty 三文件虽仅占极少代码行数，但影响了打印机配置与串行终端支持。

**史料**：USL v. BSDi 和解附件； 4.4BSD-Lite RELNOTES ［A］

**史观**：总纲第 13 条——法律与道德是利益分配〔订正注：原挂“总纲第 12 条——法律妥协的技术代价”系伪标签，权威表第 12 条为“科学是形式主义”，本节论旨“以法律清白性换取技术完整性的取舍”恰合第 13 条“法律与道德是利益分配”，依核查报告重挂〕。

**辨析**：本目遵循 0 信任原则，三文件的“技术影响”判定须以 4.4BSD-Lite RELNOTES 与被移除文件的实际功能为据——信号处理、printcap、tty 三文件对应信号处理、打印机配置、串行终端支持三条用户态路径，其移除使 4.4BSD-Lite 相对 4.4BSD 形成功能性缺口，而非单纯的代码行数减少；【0 信任原则】三文件的“技术影响”程度须以 RELNOTES 一手记载核验，不得仅凭“极少代码行数”即推断“影响轻微”——功能路径的缺失与代码体量无线性关系；【存疑判定依据】USL v. BSDi 和解附件原文未公开数字化，三文件的具体清单与功能范围须待原始和解附件公开后方可确证

**文献**：和解协议； 4.4BSD-Lite 文档 ［A］

**要点**：

- 据 McKusick 回忆，DARPA 二期大合同将网络任务拆分为二：BBN 承担 TCP/IP 协议实现，伯克利负责设计 socket、connect、accept 等编程接口并最终集成 BBN 代码后随 BSD 发布；Bill Joy 迅速搭好接口框架后，直接向 BBN 主管 TCP/IP 开发的 Rob Gurwitz 索取尚未定型的原型代码先行嵌入，双方约定并行迭代，这一快节奏集成方式为日后伯克利代码取代 BBN 代码的争端埋下伏笔。（BSDTalk EP170，[905-1045]，L1）
- McKusick 以亲历者身份还原早期网络栈的性能工程细节：rlogin 与 rcp 起源于 Joy 在 VAX 750 之间测试网络的需要，因 FTP 与 Telnet 尚未编写而临时造出，未含协议号等正式设计却流传后世；为定位性能瓶颈，团队将原本用户态的 gprof 移植入内核；Joy 将 BBN 的 TCP 状态机实现重构为巨型 switch 语句，使 RCP 吞吐从约 56 至 60 kb/s 提升到可饱和 3 Mb/s 以太网，进一步受限的仅为早期以太网控制器本身。（BSDTalk EP170，[1090-1294]，L1）
- 4.2 于 1983 年 8 月发布约千份拷贝后，BBN 因其 TCP/IP 未获采用而向 DARPA 施压；McKusick 口述 DARPA 代表以“我们说了算”强令伯克利改用 BBN 代码，引发 Mike Karels 强烈反弹。McKusick 提出折中的 bake-off 方案：编译开关方案因无法互操作被 DARPA 否决后，由双方均可接受的第三方 Mike Muuss（Ballistics Research Laboratory）主持盲测；结果吞吐测试伯克利胜出，随机丢包场景 BBN 代码先发领先但随即崩溃重启、伯克利代码反超，结论为继续随 BSD 发布修正版 TCP 代码，4.3 遂于 1986 年 6 月面世。（BSDTalk EP170，[1767-2300]，L1）
- McKusick 描述了从 Net1 到 Net2 的去 AT&T 化进程：1986 年秋加入的 Keith Bostic 以完成 2.11BSD 的 PDP-11 移植为入职条件，此前 PC 网卡厂商因 AT&T 源码许可证涨至约 25 万美元而无力购买完整发行版，促使 CSRG 剥离 TCP/IP 及相关工具以伯克利新许可证发布 Networking Release 1，磁带售价 1000 美元售出约千份而同一代码可从 UUNet 免费下载，付费者实际购买的是律师签署的法律确权；随后 Bostic 在 USENIX 会议张贴重写清单征集 cat、ls、tr 等工具的社区重写，tr 家族重写报告迫使团队逐行分离内核中伯克利与 AT&T 成分，经律师确认后发布 Networking Release 2，半年后 BSDI 补齐缺失文件开始销售。（BSDTalk EP170，[2347-2818]，L1）
- 关于诉讼年代，McKusick 口述 BSDI 以 1-800-ITS-UNIX 电话号码与“比 AT&T 源码价便宜 99%”的广告激怒 AT&T 而被起诉；BSDI 以仅六个文件出自己手抗辩并获法官认同，AT&T 遂转而起诉加州大学；McKusick 出任专家证人并由此开启其专家证人生涯；最终以和解收场——承认 Networking Release 2 含有少量侵权成分但程度轻微，重新发布剥离 AT&T 代码的 4.4BSD Lite 与需 AT&T 许可证的完整版 4.4BSD 双轨并行；Bill Jolitz 拒绝迁移致其发行版衰落，FreeBSD 与 NetBSD 完成繁重基线迁移，CSRG 以 Lite 许可收入完成 Lite2 修复后离开校园，伯克利发布史就此终结。（BSDTalk EP170，[2819-3047]，L1）
- 主持人梳理 BSD 起源脉络：贝尔实验室以极低成本向大学与企业发放 Unix 源码，伯克利在旧版 Unix 上叠加功能，套接字网络层为其标志性贡献；AT&T 进入操作系统市场后限制传播，迫使伯克利剥离并重写非自有代码，最终形成独立于 AT&T 源码的 BSD 系统且因商标只能称 BSD。其中口述以 BSD light 指称与 AT&T 真正分离的版本，历史上 Net/2 与 4.4BSD-Lite 是两个不同发布物，前者为 UC Berkeley 与 USL 和解前的分离版，后者为和解后 CSRG 发布的清白版，口述术语不精确处应以 CSRG 发布文档与和解协议核对。[考据脚注] 口述术语混淆风险。　[考据脚注] 主持人以 BSD light 笼统指称分离版本，Net/2 与 4.4BSD-Lite 的区分需以一手发布文档核证。（BSDTalk EP1，[74.16-162.80]，L2）
- 主持人对 2005 年三大 BSD 作横向定位：FreeBSD 最流行、以 i386 与 64 位 SPARC 为主要平台；NetBSD 以五十余种架构居可移植性之首，其代码甚至运行于其办公网络的 Savin 复印机；OpenBSD 分叉自 NetBSD，以密码学、安全与路由见长但维护架构较少。他并对 BSD 安全名声附加限定：BSD 目标较小、自动化攻击脚本少，属安全模糊性收益，对有能力的定向攻击者该优势无效，这构成对 OpenBSD 安全叙事的清醒保留。（BSDTalk EP1，[386.06-636.32]，L1）
- 主持人列举 BSD 的使用图景：Apple 借采用 BSD 工具使其成为最流行的桌面 Unix；Yahoo 以 FreeBSD 驱动大部分前后端 Web 服务器；Hotmail 被微软收购前全站运行 FreeBSD。他谨慎处理 Hotmail 迁移 Windows 过渡困难的传闻，表述为任何该规模迁移皆困难；该传闻长期流传但缺乏微软工程资料佐证，引用须交叉核证。[存疑脚注] 系主持人二手转述的市场传闻。　[存疑脚注] Hotmail 迁移困难之说为社区传闻，主持人自述为 I believe 层面，需与微软迁移工程资料交叉核证。（BSDTalk EP1，[320.64-381.00]，L2）
- 视频将 UNIX 的诞生置于 Multics 的失败阴影之下：贝尔实验室、MIT 与 GE 三方合作的 Multics 是为 GE 645 大型机设计、引入动态链接、多处理器支持与层次文件系统等重要特性的早期分时系统，但在贝尔实验室管理层终止全部操作系统研发后，Ken Thompson 与 Dennis Ritchie 转而借助实验室一台闲置的 DEC PDP-7 延续其系统构想，其后又以向 AT&T 专利局交付文字处理程序为交换条件获得全新 PDP-11；Dennis Ritchie 发明 C 语言并以之重写 UNIX 主体，使系统具备可移植性，UNIX 及其源代码由此得以授权给 AT&T 以外的机构使用。（YouTube EPY0ixYwLd9Pg，[84.4-254.47]，L2）
- 1970 年代中期 UNIX 进入加州大学伯克利分校 CSRG，研究生 Bill Joy 将该校的附加软件汇编成发行版，1978 年发布 1BSD、其后 2BSD 相继问世；DEC VAX 小型机带来虚拟内存等现代硬件特性而 AT&T 提供的 UNIX 版本未加利用，CSRG 学生遂重写内核核心以充分利用新硬件；视频将 TCP/IP 进入 4 系列 BSD 定位为现代互联网史上的重大里程碑，称伯克利网络栈曾被包括 Windows 在内的几乎所有现代操作系统采用，Tim Berners-Lee 在 CERN 创造万维网时所用的 NeXT 计算机运行的亦是这一网络栈。（YouTube EPY0ixYwLd9Pg，[268.08-374.23]，L2）
- 随着 BSD 日趋自成一体，因使用 BSD 须持有价格逐年攀升的 AT&T 许可证，伯克利发起移除专有代码的运动，先后发布可依宽松许可自由分发的 Net/1 与更完整的 Net/2；Net/2 成为向 Intel 386 架构移植的基础，同时衍生出 Jolitz 夫妇自 1989 年开始的自由开源 386BSD 与 BSDi 销售的专有 BSD/386，后者以 1-800-ITS-UNIX 的订购电话招徕客户，却引来持有 UNIX 名称版权的 AT&T Unix System Laboratories 注意并于 1991 年提起诉讼，BSD 系合法性因此受质疑，客观上为 Linux 争取了发展窗口；1994 年和解的条件是发布移除少量争议文件的 4.4BSD-Lite，已归 Novell 所有的 USL 亦须为 UNIX 中源自 BSD 的文件附加伯克利版权声明，基于 Lite 的衍生系统自此在法律上归于清白，视频称其结果近乎双赢。（YouTube EPY0ixYwLd9Pg，[376.15-548.55]，L2）
- 386BSD 因免费开源且可运行于廉价个人计算机而流行，但补丁散布于早期网络的各 Usenet 服务器难以检索，Terry Lambert 创建的非官方 patchkit 日后膨胀至难以维护；补丁协调人 Nate Williams、Rod Grimes 与 Jordan Hubbard 计划取 386BSD 快照、套用全部相关补丁并清理代码后以独立版本发布，因 Bill Jolitz 撤回支持而受阻，遂更名 FreeBSD 继续推进，Walnut Creek CD-ROM 公司为其提供高速互联网接入与光盘发行渠道，1993 年 FreeBSD 正式问世，并在诉讼结束后迁移至 4.4BSD-Lite 基座；其后 FreeBSD 先后进入 Sony PlayStation 3 与 4 主机、Netflix 内容分发网络与 Yahoo 服务器，一度支撑互联网多数 Web 服务器后被 Linux 超越。（YouTube EPY0ixYwLd9Pg，[568.08-800.39]，L2）

**史料**：

- 该期提及的一手史料包括：DARPA 与伯克利的资助合同文本（含成果须以合理成本向公众提供的条款，75 万美元首期与数百万美元二期）；BBN 交付的 TCP/IP 原型代码及其在伯克利的集成过程；Mike Muuss 主持的 bake-off 测试报告（结论被有意藏于中段强制通读）；经加州信息自由法请求解封的 USL 诉讼判决文本；McKusick 本人在 USL 案及后续 Sun 相关诉讼中担任专家证人的经历。（BSDTalk EP170，[293-311]，L1）
- 主持人自述 2005 年底的个人运维生态：以 FreeBSD 做测试机、以 OpenBSD 在生产环境运行 Web 服务器，并称曾在 VMware 社区虚拟机页面上传 OpenBSD 虚拟机镜像，供 Windows 与 Linux 用户零成本试用 BSD；其开播动机为当时缺乏讨论 BSD 的音频节目，自认并非主要 BSD 开发者。该期本身构成 2005 年底 BSD 用户生态与传播渠道（VMware Player 免费虚拟化试用路径）的一手口述。（BSDTalk EP1，[575.98-797.82]，L1）
- 该期呈现的一手与准一手史料线索包括：贝尔实验室闲置 DEC PDP-7 的实物史事与 AT&T 专利局购置 PDP-11 换取文字处理程序的设备交易；1978 年 1BSD 发行；进入 4 系列 BSD 的 TCP/IP 实现与被 Windows、NeXT 等采用的伯克利网络栈；Net/1、Net/2 自由分发版本；386BSD 与 BSDi 的 BSD/386 及 1-800-ITS-UNIX 订购渠道；1994 年和解与 4.4BSD-Lite 发布、UNIX 中 BSD 源文件附加伯克利版权声明之安排；Usenet 上的 386BSD 补丁散布与非官方 patchkit；1993 年 FreeBSD 首发与 Walnut Creek CD-ROM 发行渠道。（YouTube EPY0ixYwLd9Pg，[167.12-725.03]，L2）

**史观**：

- 总纲5 没有必然性，只有偶然性：这期口述显示 BSD 技术走向多次系于偶然：bake-off 的第三方人选恰为双方都熟识的 Mike Muuss，测试科目设计与报告结论藏匿位置皆出其个人之手；BSDI 一个营销电话号码与广告文案的偶然选择直接引爆 AT&T 诉讼；和解能否达成又与 Novell 收购 USL 的时点相纠缠。技术史的关键节点常由具体的个人际遇与偶然条件触发，而非可推导的必然规律。（BSDTalk EP170，[2144-2300]，L1）
- 总纲4 分离聚合是永恒规律：主持人叙述 OpenBSD 分叉自 NetBSD 缘于开发者冲突、DragonFly BSD 分叉自 FreeBSD：BSD 谱系以分离与聚合的循环展开，分离既是治理冲突的结果，也成为生态定位分化（可移植、安全、流行度）的方式。（BSDTalk EP1，[449.47-465.62]，L2）
- 总纲13 法律与道德是利益分配：主持人把 GPL 与 BSD 许可证之争归结为对自由的定义分歧——GPL 以版权机制强制回馈社区，BSD 许可证允许商业封闭但不要求回馈——并拒绝裁决孰更自由，视之为利益分配方式的分野而非道德高下。（BSDTalk EP1，[248.96-319.38]，L2）
- 总纲4 分离聚合是永恒规律：全片叙事呈现分离与聚合的循环：UNIX 自 Multics 废墟中分离而出，BSD 经 Net/1、Net/2 与 4.4BSD-Lite 逐级剥离 AT&T 代码，FreeBSD 又自 386BSD 分离，NetBSD、OpenBSD 相继分立；与此同时伯克利网络栈被几乎所有现代操作系统吸收，各分支项目延续同一传统，分离之后在各处再聚合，BSD 系统的生命力恰由不断分离而非单一谱系所维系。（YouTube EPY0ixYwLd9Pg，[905.11-909.99]，L2）
- 总纲5 没有必然性，只有偶然性：视频将 UNIX 的诞生归结为具体偶然条件与需求的凑合而非必然进程：管理层终止项目、PDP-7 恰好闲置、专利局恰需文字处理器，诸条件先后相遇方使系统在无人支持的环境中存活并繁荣，结尾以“如凤凰自 Multics 灰烬中重生”作喻，实际上否定了技术演进的必然性叙事。（YouTube EPY0ixYwLd9Pg，[878.399-890.949]，L2）

**辨析**：

- McKusick 坦承 Net1 的法律依据并非明文：团队向校方律师出示的政府合同条款只笼统要求成果以合理成本向公众提供，其原话承认条款“并非真的那样写，但我们说服了律师”，说明伯克利许可证的诞生包含对合同条款的扩张解释成分，史书引用该条款作为开源发行法律基础时须作限定，不能径直表述为合同明文义务。　[存疑脚注] 政府合同条款原文与律师沟通过程仅有当事人单方口述，无合同文本佐证，引用时须标注存疑（BSDTalk EP170，[2594-2616]，L1）
- 主持人称 Darwin 不使用 FreeBSD 内核而使用另一微内核；XNU 实为 Mach 微内核与 BSD 组件的混合内核，该表述反映 2005 年大众话语对微内核标签的通行用法，与内核混合架构的实际不符。[存疑脚注] 主持人非内核开发者，系转述层面口误风险，需以 Apple XNU 源码与 Darwin 文档核证。　[存疑脚注] 主持人对 Darwin 内核的描述与 XNU 混合架构事实不符，属口述简化。（BSDTalk EP1，[213.90-226.24]，L4）
- 主持人承认 SunOS 原本基于 BSD 代码、后转 Solaris，但判断仍存活的 SunOS 数量属印象式陈述，无 deployment 数据支撑；引用该期作为 SunOS 存量证据时须另寻统计来源。[存疑脚注] 单一来源印象推断。　[存疑脚注] SunOS 存量流行度为主持人印象，无量化依据。（BSDTalk EP1，[182.06-197.72]，L4）
- 多处表述须回核原始音视频与一手史料：其一，视频称 Multics 始于 1956 年，与通行考据的项目 1964 年启动不符，或系将 GE 与 MIT 更早的分时探索并入叙述；其二，转写在 CSRG 学生为 VAX 重写核心处呈现为今日所称 FreeBSD 诞生，按编年此处应为 3BSD，FreeBSD 之名至 1993 年方出现，属口述或转写之误；其三，视频称另一群体在 FreeBSD 项目开始前基于 386BSD 启动 NetBSD，与通行考据的 NetBSD 于 1993 年基于 Net/2 启动之说存在出入；其四，转写存在重复损伤与记音失真，CSRG 解散年份、FreeBSD 2.0 发布年份等数字缺失，Lynne Jolitz、Terry Lambert 等人名记音失真，引用相关细节前须交叉核证。　[存疑脚注] Multics 1956 年说、CSRG 重写处误称 FreeBSD、NetBSD 起源与启动基础表述，及转写数字缺失与人名记音失真，均须以原始视频与一手史料复核后方可引用（YouTube EPY0ixYwLd9Pg，[106.079-737.75]，L5）
