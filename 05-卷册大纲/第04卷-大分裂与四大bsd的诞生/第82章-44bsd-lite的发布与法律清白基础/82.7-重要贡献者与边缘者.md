## 82.7.1 CSRG 末期的无名成员

  **要点**：CSRG 末期（1992-1995）的无名成员包括——参与 4.4BSD 最后开发的实习生、贡献补丁的研究生、协助测试的 Berkeley 学生；这些成员在 Release Notes 中可能未被完整记录，但他们的贡献支撑了 4.4BSD-Lite 的发布
  
**史料**：4.4BSD-Lite Release Notes 贡献者名单；CSRG 内部邮件存档；Berkeley CS 系学生记录 ［A］
  
**史观**：边缘者贡献：CSRG 末期的无名成员作为边缘者，其贡献常被主流叙事忽视
  
**辨析**：无名成员的具体身份与贡献在不同叙事中差异较大——部分成员可能仅贡献少量补丁但被忽视；须对照 CSRG Archive CD-ROM #4 SCCS 元数据（McKusick 个人整理，含 Final /usr/src including SCCS files）核实，SCCS 元数据记录 BSD 源码逐次提交时间、作者、注释，是 CSRG 末期无名成员贡献识别的一手数字证据

## 82.7.2 成员的贡献内容

  **要点**：无名成员的贡献内容包括——补丁编写、bug 修复、测试反馈、文档校对；这些贡献虽小但累积支撑了 4.4BSD-Lite 的发布；具体贡献者与贡献内容须从 CSRG Archive CD-ROM #4 SCCS 元数据与 CSRG 邮件列表贡献记录中识别
  
**史料**：4.4BSD-Lite 源码 commit 日志；CSRG 邮件列表贡献记录；测试反馈邮件 ［A］
  
**史观**：边缘者贡献：无名成员的具体贡献内容须从 CSRG Archive CD-ROM #4 SCCS 元数据与 CSRG 邮件列表贡献记录主动挖掘——主流叙事（Release Notes 贡献者名单、McKusick 1999 当事人记载）仅记录核心成员，边缘者贡献须依赖原始数字档案而非二手归纳
  
**辨析**：贡献内容的具体性经 CSRG Archive CD-ROM #4 SCCS 元数据与 4.4BSD-Lite 源码 commit 日志对照核实——部分贡献在 Release Notes 中未被记录，须通过 SCCS 元数据识别 commit 作者、提交时间、注释内容以重建完整贡献链

## 82.7.3 被遗忘的贡献者辨析

  **要点**：被遗忘的贡献者辨析须识别两类——“技术贡献被低估”（如补丁作者、测试者，其工作可经 SCCS 元数据与 commit 日志量化）与 “非技术贡献被忽视”（如组织协调者、外部联络者，其工作须从 CSRG 邮件列表贡献记录与 Berkeley CS 系档案中挖掘）；两类贡献者的史料都须从 CSRG Archive CD-ROM #4 与 Bancroft CU-551 全宗主动挖掘
  
**史料**：CSRG 邮件列表贡献记录；4.4BSD-Lite 源码 commit 日志；Berkeley CS 系档案 ［A］
  
**史观**：边缘者贡献：被遗忘的贡献者作为边缘者，其贡献须从 CSRG Archive CD-ROM #4 SCCS 元数据（技术贡献量化）与 CSRG 邮件列表贡献记录、Bancroft CU-551 全宗（非技术贡献挖掘）主动识别——主流叙事仅记录 Core Team 核心成员（McKusick、Karels、Bostic），边缘者贡献须依赖原始数字档案与机构档案
  
**辨析**：被遗忘的标准需明确——“被主流叙事忽视” 不等同于 “贡献低”，需区分贡献规模与叙事曝光度

## 82.7.4 边缘贡献者的史料辨析

  **要点**：边缘贡献者的史料辨析须交叉验证三类来源——技术贡献（补丁、测试）经 CSRG Archive CD-ROM #4 SCCS 元数据量化，组织贡献（协调、联络）经 CSRG 邮件列表贡献记录识别，文化贡献（文档、培训）经 Berkeley CS 系档案与 Bancroft CU-551 全宗挖掘；不得仅依赖 commit 日志评估贡献
  
**史料**：CSRG 邮件列表贡献记录；4.4BSD-Lite 源码 commit 日志；Berkeley CS 系档案 ［A］
  
**史观**：0 信任原则：边缘贡献者史料须交叉验证三类来源（SCCS 元数据、CSRG 邮件列表、Berkeley CS 系档案），不得仅依赖单一来源——SCCS 元数据仅记录技术贡献，邮件列表仅记录组织贡献，机构档案仅记录文化贡献，三类来源互补方能还原边缘者全貌
  
**辨析**：边缘贡献者的史料价值在不同维度表现不同——技术贡献经 SCCS 元数据量化（commit 数、补丁行数），组织与文化贡献经邮件列表与机构档案定性分析，量化与定性方法的边界须明确——“贡献规模” 与 “叙事曝光度” 非同一维度，前者经原始数字档案可量化，后者经主流叙事（McKusick 1999、Release Notes 贡献者名单）可对比
