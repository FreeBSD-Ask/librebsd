# 070.3.3 商业 UNIX 工作站 → 386BSD PC 民主化路径（1992-1994）

  **要点**：1980-1990 年代初期 BSD 主要通过商业 UNIX 工作站路径分发——SunOS（1983 起，基于 4.1BSD/4.2BSD）运行于 Sun 工作站（价格 10000-50000 美元），DEC ULTRIX（1987 起，基于 4.2BSD/4.3BSD）运行于 VAX 工作站（价格 30000-200000 美元），HP-UX、IBM AIX 等商业 UNIX 均限于工作站与中小型机，BSD 代码本身通过 AT&T UNIX 源代码许可证分发，价格 200000-400000 美元，BSD 长限期于学术机构与商业工作站用户；386BSD 0.1（1992.7）发布后通过 Internet 免费下载与 Walnut Creek CDROM 商业发行（1992 年起，价格 39 美元），使 BSD 可运行于普通 Intel 80386 PC（价格 2000-5000 美元），是 BSD “PC 民主化” 路径的起点；386BSD PC 民主化路径后被 FreeBSD 1.0（1993.11，Walnut Creek CDROM 商业发行）、NetBSD 0.8（1993.4，Internet 免费下载）、Linux 0.12（1992.1，Internet 免费下载）等继承与扩展，1990 年代后期 PC 服务器（基于 Intel x86）逐步替代商业 UNIX 工作站成为互联网服务器主流硬件；商业 UNIX 工作站路径在 386BSD 后被 “淘汰” 为 PC 民主化路径，但 Sun/DEC/HP/IBM 等商业 UNIX 工作站在 1990 年代仍保留学术与商业市场，须区分 “PC 民主化路径兴起” 与 “商业 UNIX 工作站完全消失”
  
**史料**：SunOS/ULTRIX/HP-UX/IBM AIX 商业发行记录；AT&T UNIX 源代码许可证价格表（1984-1987）；386BSD 0.1 Release Notes（1992.7）；Walnut Creek CDROM 档案；FreeBSD 1.0 Release Notes（1993.11）；NetBSD 0.8 Release Notes（1993.4）；Linux 0.12 Release Notes（1992.1） ［A］
  
**史观**：第 13 条法律与道德是利益分配（存疑）——386BSD PC 民主化路径是 BSD 从 “商业 UNIX 工作站精英” 到 “PC 大众” 的经济民主化，硬件价格从 50000 美元降至 2000 美元推动 BSD 普及；第 4 条分离聚合是永恒规律（存疑）——386BSD PC 民主化路径后被 Linux 继承与扩展，是 BSD 反向影响开源运动的具体呈现
  
**辨析**：商业 UNIX 工作站被 “淘汰” 指 BSD 主流分发路径迁移，Sun/DEC/HP/IBM 等商业 UNIX 工作站在 1990 年代仍保留市场，须区分 “BSD 主流分发路径迁移” 与 “商业 UNIX 工作站完全消失”；386BSD PC 民主化与 Linux PC 民主化的关系需谨慎判断——两者几乎同时选择 PC 平台，但 386BSD 因 USL 诉讼错失时间窗口，Linux 在 1992-1994 年快速发展；Walnut Creek CDROM 商业发行的具体销售数据须考据
