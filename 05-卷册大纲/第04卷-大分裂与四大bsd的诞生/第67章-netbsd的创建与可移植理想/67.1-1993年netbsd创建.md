# 67.1 1993 年 NetBSD 创建——Demetriou/de Raadt/Glass/Hannum 四人组

## 67.1.1 创建的历史语境

  **要点**：1993 年 3 月 21 日 NetBSD 项目创建 [考据脚注：经 netbsd.duckdb 数据库确认，NetBSD 项目实际起步以 cgd（Chris Demetriou）1993-03-21T09:45:37Z“initial import of 386bsd-0.1 sources”（commit_hash 0d110d127c41d7aeb2b1bfdc71964c5a496eabf9）为标志，该日期在 NetBSD 官方历史页无明确记载，但数据库一手证据已确认。第三轮查证：此日期已通过 netbsd.duckdb 交叉验证，确认为 1993 年 3 月 21 日。]，背景是 386BSD 补丁质量混乱与维护者无法及时整合补丁的挫败感；Chris Demetriou、Theo de Raadt（西奥·德·若特）、Adam Glass（亚当·格拉斯）、Charles M. Hannum（查尔斯·汉纳姆） 四人从 386BSD 0.1 分叉，最初聚焦于质量与架构独立性（architecture independence），“可移植性至上”理念随项目发展逐步确立
  
**史料**：Chris Demetriou 1993 年 4 月 19 日 NetBSD 0.8 发布公告（comp.os.386bsd.announce）、NetBSD Project 官方历史页、NetBSD 早期邮件列表存档；netbsd.duckdb 数据库证据——netbsd-src 仓库首条 commit 为 srcmastr 1992-07-13T16:18:24Z“initial empty check-in”（commit_hash `e81d63576b2e46ab90da7d75fa155ea57ee4d32e`），但此为仓库初始化脚本 commit，非 NetBSD 项目实际成立时间；NetBSD 项目实际起步以 cgd（Chris Demetriou）1993-03-21T09:45:37Z“initial import of 386bsd-0.1 sources”（commit_hash `0d110d127c41d7aeb2b1bfdc71964c5a496eabf9`）为标志，证实 1993-03-21 CVS 仓库建立日期的存疑脚注成立；deraadt（Theo de Raadt）在 netbsd-src 首次 commit 为 1993-04-02T12:24:21Z，与四人组发起 NetBSD 项目的时间吻合；netbsd.duckdb 查询 L1.1.1 显示：1993 年 netbsd-src = 14,507 commits（占当年 4 大 BSD src 仓库总量 15,375 的 94.35%），反映 NetBSD 项目创建当年的开发活跃度远超同期 freebsd-src（868 commits, 5.65%），1994 年 netbsd-src = 17,726 commits（80.78%）、freebsd-src = 4,217 commits（19.22%），1995 年 netbsd-src = 12,163 commits（58.88%）、freebsd-src = 7,723 commits（37.39%）、openbsd-src = 770 commits（3.73%），反映 NetBSD 在 1993-1995 年为 BSD 阵营 commit 量最大的项目 ［A］
  
**史观**：总纲第 4 条——分离聚合是永恒规律：NetBSD 是从 386BSD 分离聚合的第二个 BSD 项目
  
**辨析**：源码仓库建立日期 1993 年 3 月 21 日经 netbsd.duckdb 数据库确认（cgd 1993-03-21T09:45:37Z“initial import of 386bsd-0.1 sources”），该存疑已解除；首次公开版本（NetBSD 0.8）发布于 1993 年 4 月 19/20 日（公告日 19 日，FTP 开放日 20 日）；FreeBSD 项目分叉时间晚于 NetBSD（FreeBSD 1.0 网络公告为 1993 年 11 月 1 日），两者为同期并行分叉关系而非先后派生；netbsd.duckdb 验证结论——netbsd-src 中 cgd 1993-03-21T09:45:37Z 的“initial import of 386bsd-0.1 sources”commit 证实 1993-03-21 为 NetBSD 项目代码起步日期；0 信任原则提示：netbsd-src 的 GitHub 镜像可能滞后于主仓（CVS/Mercurial），1992-07-13 的 srcmastr“initial empty check-in”是 NetBSD CVS 仓库转换为 Git 时保留的初始化 commit，时间戳可能由 CVS-to-Git 转换脚本生成，须与 NetBSD 邮件列表公告交叉验证；【0 信任原则·commit 量不等于质量】L1.1.1 commit 量反映开发活跃度但不等于代码质量，1993 年 netbsd-src 14,507 commits 须结合 commit 规模（additions/deletions）与 message 质量综合判断；【0 信任原则·GitHub 镜像滞后】netbsd-src 为 GitHub 镜像，commit 量可能滞后于主仓（CVS），1993-1995 年 commit 基线须以 NetBSD 官方档案为准；【0 信任原则·CVS-to-Git 迁移风险】NetBSD CVS-to-Git 转换可能重写 author 字段或 commit_date，1993-1995 年贡献者身份与时间戳须与 NetBSD 邮件列表签名交叉验证

## 67.1.4 创建的工程基础

  **要点**：NetBSD 0.8 基于 386BSD 0.1 + 0.2.2 patch kit，集成了 Berkeley Networking Release 2 (Net/2) 中 386BSD 缺失的程序；NetBSD 1.0 于 1994 年迁移至 4.4BSD-Lite 代码基础 [考据脚注：4.4BSD-Lite 于 1994 年 6 月发布，经 McKusick 1999 一手叙述、CSRG Release Notes 与多源交叉一致确认。]；MI/MD（Machine-Independent/Machine-Dependent）分层架构在后续版本中逐步完善，0.8 仅支持 i386 单平台但架构设计为多平台移植预留了空间
  
**史料**：Demetriou 0.8 原始公告（明确记载"based heavily on 386BSD 0.1, patched with the 0.2.2 patch kit“，”integrated many programs from UCB's second BSD Networking Software Release“）、NetBSD 1.0 Release Announcement（明确记载”based on 4.4BSD Lite and Berkeley Networking Release 2 sources"）、NetBSD 源码树 ［A］
  
**史观**：总纲第 15 条——文化即形式主义：MI/MD 分层是 BSD 工程传统在多平台场景的形式主义化〔存疑：挂条待主理人审定〕
  
**辨析**：MI/MD 架构并非在 0.8 时即完整建立——0.8 仅支持 i386 单平台，多平台支持与完整 MI/MD 分层在 0.9、1.0 及后续版本中逐步完善；4.4BSD-Lite 基础是 1.0 版本（1994.10）才引入的，0.8（1993.4）不基于 4.4BSD-Lite 也不基于 4.3BSD-Reno
  
**文献**：Demetriou C G. NetBSD 0.8 Installation Notes (19 Apr 1993)；Demetriou C G. NetBSD 1.0 Release Announcement (8 Nov 1994)［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］
