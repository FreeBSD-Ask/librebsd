# 67.2 移植到一切平台的工程目标——"of course it runs NetBSD"的口号起源

## 66.2.1 可移植理想的工程目标
  - 要点：NetBSD 的工程目标是“运行在一切硬件上”，强调 MI/MD 分层使移植成本最小化；这一目标成为 NetBSD 的核心差异化定位
  - 史料：NetBSD Project 早期宣言、netbsd-users 邮件列表讨论 ［A］
  - 史观：总纲第 17 条——软件工程：可移植性作为工程哲学是 BSD 工程传统的延伸
  - 辨析：“运行在一切硬件上”是工程理想还是宣传口号需对照实际移植数量核验
  - 文献：NetBSD Project Goals；NetBSD Developer Documentation[考据完成：2026-07-28 经穷尽联网考据，上述文献清单为已知公开来源汇总，部分原始档案未公开数字化或须付费访问，属史料缺口，须待原始档案公开后方可补充确证]
## 66.2.2 口号起源的考证
  - 要点："of course it runs NetBSD"口号的确切起源在 NetBSD 社区内部存在不同叙事；一种说法是 1990 年代末社区自嘲式玩笑，另一说法是 NetBSD 网站正式口号
  - 史料：NetBSD 邮件列表口号讨论、archive.org NetBSD.org 历史快照 ［A］
  - 史观：总纲第 22 条——开源运动：口号是开源社区身份认同的形式主义化
  - 辨析：口号的最早出现时间需对照邮件列表原始帖核验；经[邮件列表库]核查：netbsd 库检索"of course it runs"未命中该口号原文（0 条精确匹配，检索所得多为 2008-2015 年技术帖与 advocacy 帖），口号最早出现时间两库无法验证（覆盖范围：NetBSD 邮件列表 1994-）
  - 文献：NetBSD.org archive.org 快照；netbsd-users 邮件列表 ［A］
## 66.2.3 口号的文化意义
  - 要点：口号体现 NetBSD 社区的自嘲式精英主义——既承认 NetBSD 跑在所有硬件上的工程事实，也表达对“主流市场”的不屑；口号成为 NetBSD 社区身份认同的核心符号
  - 史料：netbsd-users 邮件列表讨论、BSD 会议口号引用频率 ［A］
  - 史观：总纲第 14 条——哲学思潮：自嘲式精英主义是 NetBSD 社区的哲学气质
  - 辨析：口号文化意义的解读需对照社区内部讨论核验，避免事后归因
  - 文献：netbsd-users 邮件列表档案；BSDCan/EuroBSDCon 会议记录 ［A］
## 66.2.4 可移植理想的实践
  - 要点：**NetBSD 1.0**（**1994-10-26** tag，**1994-11-08** 公告）发布时提供二进制版本的硬件平台共 5 个：amiga、i386、mac68k（some m68k-based Macintoshes）、pc532、sparc（SPARCstation sun4c）；HP9000/300（hp300）的二进制版本"expected, but not yet ready"尚未就绪，源码树中还包含 DECstations、部分 Sun 3 型号、部分 VAXen 的支持代码但不够成熟无法提供完整二进制分发；MI/MD 架构使新平台移植成本相对较低。NetBSD 1.0 二进制平台支持情况如下：

| 平台 | 二进制版本状态 | 备注 |
| --- | --- | --- |
| amiga | 已就绪 | m68k |
| i386 | 已就绪 | ISA/EISA，386/486 |
| mac68k | 已就绪 | 部分 m68k Macintosh |
| pc532 | 已就绪 | NS32032 |
| sparc | 已就绪 | SPARCstation sun4c |
| hp300 | 未就绪 | "expected, but not yet ready" |

- 史料：Demetriou 1.0 原始公告（8 Nov 1994）明确列出可用二进制平台、hp300 状态、源码树中其他平台状态；NetBSD 官方发布页 ［A］
- 史观：总纲第 7 条——硬件与软件辩证：MI/MD 分层是软件对硬件多元性的辩证回应
- 辨析：1.0 正式二进制发布平台确认为 5 个架构（amiga、i386、mac68k、pc532、sparc），hp300 在源码中已有支持但二进制版尚未准备好；“6 个平台”说法包含了未就绪的 hp300；12/14/21 等数字为后续版本或混淆了平台与架构的计数
- 文献：Demetriou C G. NetBSD 1.0 Release Announcement (8 Nov 1994, comp.os.386bsd.announce)；NetBSD Formal Releases 历史页[考据完成：2026-07-28 经穷尽联网考据，上述文献清单为已知公开来源汇总，部分原始档案未公开数字化或须付费访问，属史料缺口，须待原始档案公开后方可补充确证]
