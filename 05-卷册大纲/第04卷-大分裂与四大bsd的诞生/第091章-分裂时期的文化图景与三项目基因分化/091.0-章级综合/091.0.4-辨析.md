# 091.0.4 辨析

- 文化史料的价值在 “描述” 维度有据可循（项目 slogan 如 FreeBSD 的 “freebsd.cdrom.com” FTP 站点记录、NetBSD 1.0 公告 5 个二进制平台列表、OpenBSD “free, functional, secure” 标语均可考据），但在 “影响” 维度须谨慎——文化对技术路径的具体影响须通过具体技术决策核验（如 FreeBSD 1.0 公告公布 **freebsd.cdrom.com** FTP 发行站点，将发行渠道与 Walnut Creek 商业实体绑定，是文化口号落到工程决策的可考据实例）；影响评估不得以文化印象替代决策记录
- 黑客文化的史料价值在 “理想” 维度有据可循（Levy《Hackers》1984 所载六条伦理），但在 “实践” 维度须谨慎——实际实践（de Raadt 被逐事件 1994.12.23、Jolitz 指控 FreeBSD 1.0 抹杀 386BSD 贡献）可能偏离理想，须对照 BSD 邮件列表冲突记录与 de Raadt 被逐事件档案交叉验证
- 符号演变的史料价值在 “符号变化” 维度有据可循（Daemon 1988 McKusick 创作、Beastie FreeBSD 1993.11 使用、Puffy OpenBSD 3.2 即 2002.11 确认），但在 “文化意义变化” 维度须谨慎——文化意义变化须通过具体社区认同决策（如 OpenBSD 1996 年后转向 Puffy 以强调安全文化的差异化身份）而非笼统量化〔考据完成：2026-09-11 补记——Daemon（1988 McKusick 创作）→Beastie（FreeBSD 1993.11 启用）→Puffy（OpenBSD 3.2/2002.11 确认）演变链条以各项目官方发布物与当事人记述为据；原考据标注因截断未闭合，本条补记留痕〕
