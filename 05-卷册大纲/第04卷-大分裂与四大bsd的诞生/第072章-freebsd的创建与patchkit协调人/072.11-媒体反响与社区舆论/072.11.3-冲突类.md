### 冲突类-1

- **新闻标题（中英）**：Berkeley Software Design, Inc.（BSDi）成立与 BSD/OS 商业化
- **新闻来源**：多源转引 + 1991 年 BSDi 成立〔存疑脚注：成立年份学界有 1991（当年开始运营）与 1992（BSD/386 发布）两说，与 USL 诉讼时序相关，待一手档案确证〕 + 创始团队〔存疑脚注：两份名单口径不一——通行“公司由 Rick Adams 与 CSRG 成员 Keith Bostic、Kirk McKusick、Mike Karels、Bill Jolitz、Donn Seeley 创办，Jolitz/Seeley/Trent Hein 为首批雇员”；另有“Seeley、Karels、Jolitz、Hein 离开加州大学创办”说；Bostic 与 McKusick 是否创始股东待 SEC 文件或当事人自述确证，本条两处名单暂按原文保留〕；原始新闻源待补（回源 SEC S-1 或 BSDi 官方档案）
- **新闻摘要**：1991 年，一群 BSD 开发者（Donn Seeley、Mike Karels、Bill Jolitz、Trent Hein 等）离开加州大学伯克利分校，创办 Berkeley Software Design, Inc.（BSDi，后改名 BSDi）〔存疑脚注：另有口径记载公司由 Rick Adams 与 Keith Bostic、Kirk McKusick、Mike Karels、Bill Jolitz、Donn Seeley 等 CSRG 成员创办，Seeley/Jolitz/Hein 时为 UUNET 雇员并成为 BSDi 首批雇员；两种口径并存，待一手来源统一〕。BSDi 是第一家在便宜常见的 Intel 平台上提供全功能商业 BSD UNIX 的厂商，产品名为 BSD/386（后改名 BSD/OS），售价约 995 美元。BSDi 的成立与 FreeBSD 项目同期，二者形成商业版与自由版的互补关系，但 BSDi 很快陷入与 USL 的诉讼（1992 年提起），该诉讼直接影响了 FreeBSD 1.0 的法律地位。
- **与本章主题的关联说明**：本章 FreeBSD 的诞生不能脱离 BSDi 商业化与 USL 诉讼的大背景，BSDi 同期成立为 FreeBSD 提供了商业参照系，USL 诉讼则直接构成 FreeBSD 1.0 发布后的法律威胁。BSDi 的商业化为后续 FreeBSD 1.1.5.1 紧急发布与 FreeBSD 2.0 基于 4.4BSD-Lite 重写埋下伏笔。
