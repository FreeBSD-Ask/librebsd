# 79.12 文化挪用的遮蔽本质——项目统摄史观审视

## 79.12.1 遮蔽的三重机制——技术遮蔽（来源淡化）、记忆遮蔽（记忆抹除）、话语遮蔽（话语重塑）
  - 要点：文化挪用的遮蔽本质表现为三重机制——来源淡化（技术传承的源头标注被剥离，Linux 端主流叙事通过 man page 与培训教材的内部一致性建构“Linux 原生”叙事，使 BSD 端一手作者在“商品”层面被市场自然遗忘）、记忆抹除（贡献者与原始语境在主流叙事中缺席，GPL 重写将 BSD 许可证项目边缘化为“permissive 但不严肃”，重写版以“现代 Linux 默认工具”形式化为商品）、话语重塑（以“开源通用遗产”包装具体的项目出身，基金会化、商业化、商标认证、供应商化四个机制把 BSD 端“开放治理加学术共享加社区维护”的核心要素封装为“可销售、可估值、可并购的开源软件商品”）；三重机制非依次发生而是同时运作，在 sudo、BIND、jail → Docker、sendmail → Sendmail Inc、MAC → SELinux 等案例中均可见三重机制的叠加；本节明确表述：Linux 社区的文化挪用现象是对开源文化的遮蔽，使 BSD 谱系在开源主流叙事中边缘化
  - 史料：原材料/研究/linux 文化挪用/模式总结.md 的 4 种模式归纳；BSD 案例 1（sudo：Coggeshall 与 Spencer 在 LPI 认证、Red Hat RHCSA 教材中被“Todd C. Miller（托德·C·米勒） 1994”取代）、BSD 案例 23（BIND：Terry 等 4 人在 BIND 9 官方文档中被“ISC 与 Red Hat”取代）、BSD 案例 7（jail → Docker：PHK 1999 设计在 Docker 主流叙事中被“Solomon Hykes 2013 Docker 创新”取代）、BSD 案例 22（sendmail → Sendmail Inc → Proofpoint：Allman 1983 BSD 起源在 Postfix 商业产品文档中完全消失）、BSD 案例 59（MAC → SELinux/AppArmor：TrustedBSD 学术传统被弱化为“早期的尝试”） ［A］
  - 史观：总纲第 15 条——文化即形式主义：BSD 端的“ports 文化”“rc.d 文化”“man 文化”在 Linux 端“形式主义化”过程中被遮蔽与重构——"ports"被更名为"package manager"、"init script"被更名为"unit"、"man"被竞争为“man 与 GNU info”，传统在更名与重构中被遮蔽；“知音难觅”同样适用于技术社区——Coggeshall 与 Spencer、Terry 等 4 人、Watson 与 Anderson 等一手作者姓名在 Linux 端主流叙事中几近缺席
  - 辨析：三重机制的“同时运作”非“依次发生”——在 BSD 案例 7（jail → Docker → OCI）中，来源淡化（PHK 1999 设计被“Solomon Hykes 2013 Docker 创新”叙事取代）、记忆抹除（Docker 重写为 libcontainer 与 runc，原作者被替换为重写者）、话语重塑（OCI 2015-12-08 加入 Linux Foundation 托管，以“开源通用遗产”包装具体的项目出身）三重机制在同一案例中同时运作而非依次发生；三重机制的“叠加效应”使 BSD 端的“先验存在”在“商品化”过程中被系统性遮蔽，这一遮蔽不是“自然遗忘”而是“形式主义权力运作”的产物；【0 信任原则】三重机制的“同时运作”须经一手档案的多维度交叉验证——man page 与培训教材的“内部一致性”（来源淡化）、GPL 重写与代码血缘比对（记忆抹除）、基金会章程与商业公司档案（话语重塑）须三类来源交叉验证
  - 文献：原材料/研究/linux 文化挪用/模式总结.md；BSD 案例 1、23、7、22、59 案例文件；一手 man page 与培训教材档案；GPL 许可证原文；Linux Foundation 与 BSD Foundation 章程 ［A］
## 79.12.2 遮蔽不等于盗窃——形式主义权力运作的辨析
  - 要点：文化挪用的遮蔽本质须与道德意义上的“盗窃”明确区分——遮蔽是形式主义的权力运作，指 Linux 端主流叙事通过 man page、官方文档、培训教材、社区话语等渠道，将 BSD 端的一手作者、起源日期、概念先验地位系统性隐去的形式主义过程；“盗窃”是道德判断，预设了“财产权”的明确边界与“窃取”的主观恶意；BSD 许可证本身允许自由使用、修改、再分发，Linux 端使用 BSD 代码在法律层面不构成“盗窃”；但法律层面的“允许使用”不等于叙事层面的“归属公正”——BSD 许可证的“自由散逸”哲学承认人类的有限性，不以强制形式限制自由，但 Linux 端主流叙事的“形式主义化”反向剥夺了 BSD 端的“历史记忆与归属权”，构成对“人”（一手作者）的遮蔽
  - 史料：BSD 许可证原文（BSD 3-Clause 1990）；GPL v2 许可证原文（1991）；原材料/研究/linux 文化挪用/案例-许可证.md（许可证案例 1：GPL 兼容性问题的 BSD 视角——1988-1990 BSD 早期 18 条 advertising clause 形式许可证，1999-07-22 三大 BSD 项目联合去除 advertising clause，1999-09 FSF 正式声明 BSD 二条款与三条款与 GPL v2 兼容）；BSD 案例 20（BSD 二条款 → MIT 许可证借鉴）、BSD 案例 21（BSD 三条款 → Apache 2.0 归属条款） ［A］
  - 史观：总纲第 13 条——法律与道德是利益分配：BSD 与 GPL 兼容性问题、BSD → MIT 借鉴、BSD → Apache 2.0 借鉴等“法律与道德”叙事本质上是“利益分配”问题——FSF 与 Stallman 在 2000s 多场公开演讲中将 BSD 描述为"less free than GPL"，建构“GPL 是严格 free software，BSD 是 permissive”的阵营对立叙事，这一“道德问题”本质上是 FSF 阵营对 BSD 阵营的“利益分配”问题；总纲第 11 条——商品是形式主义：法律层面的“允许使用”（BSD 许可证散逸效应）与叙事层面的“归属公正”（文化挪用的遮蔽）非同一维度——前者是法律结构，后者是形式主义权力运作
  - 辨析：遮蔽不等于盗窃的辨析须区分三个维度——法律维度（BSD 许可证允许自由使用，Linux 端使用 BSD 代码不构成“盗窃”）、道德维度（“盗窃”预设“财产权”明确边界与“窃取”主观恶意，BSD 许可证的“自由散逸”哲学不以强制形式限制自由，“盗窃”概念不适用）、叙事维度（Linux 端主流叙事的“形式主义化”反向剥夺了 BSD 端的“历史记忆与归属权”，构成对“人”的遮蔽，这一遮蔽是形式主义权力运作而非道德意义上的“盗窃”）；本节不使用“Linux 是掠夺者”“Linux 盗窃 BSD”等道德判断性表述，以考据证据呈现文化挪用的遮蔽现象；【0 信任原则】“遮蔽不等于盗窃”的辨析须以 BSD 许可证原文与 GPL v2 许可证原文交叉验证，不得仅凭道德直觉即断定“盗窃”
  - 文献：BSD 许可证原文；GPL v2 许可证原文；原材料/研究/linux 文化挪用/案例-许可证.md；BSD 案例 20、21 案例文件 ［A］
## 79.12.3 史观映射——总纲第 3、5、11、15、19、21、22、23 条
  - 要点：文化挪用的遮蔽本质在项目统摄史观 25 条总纲中可作 8 条主线映射——总纲第 3 条（不存在进步，只有权力再分配）：Linux 端“apt 优于 ports”“systemd 优于 rc.d”“eBPF 优于 BPF”等“进步叙事”本质上是“权力再分配”，技术演进不是从低级到高级的进步，而是形式主义的诡异曲线；总纲第 5 条（没有必然性，只有偶然性）：Linux 端“Todd C. Miller 1994 发明 sudo”“Docker 2013 创新容器”“GPL 必然取代 BSD”等叙事将偶然性必然化，是“君权神授”式合法性建构；总纲第 11 条（商品是形式主义）：4 种挪用模式本质上是 BSD 端技术经“形式主义化”后封装为“开源软件商品”的权力运作，“劣币驱逐良币”在技术归属维度的体现；总纲第 15 条（文化即形式主义）：BSD 端的“ports 文化”“rc.d 文化”“man 文化”在 Linux 端“形式主义化”过程中被遮蔽与重构，传统在更名与重构中被遮蔽；总纲第 19 条（解释学循环是历史认识的根本条件）：“什么被记录、什么被遗忘”本身就是权力行使——Coggeshall 与 Spencer、Terry 等 4 人、Watson 与 Anderson 等一手作者在 Linux 端主流叙事中被“遗忘”，这一“遗忘”不是“自然遗忘”而是“权力与知识共谋”的产物；总纲第 21 条（革命与改革是历史方法论的分歧）：Linux 靠革命（systemd 重构、Docker 重命名、eBPF 扩展），BSD 靠改革（rc.d 渐进演化、jail 渐进扩展、BPF 渐进扩展），“改革的困难远高于革命”，“破山中贼易，破心中贼难”——Linux 端革命的“心中贼”（建构 Linux 原生叙事）远比“山中贼”（具体技术重写）难以破除；总纲第 22 条（知识注定过时）：技术史写作本身可能固化遮蔽——主流技术叙事一旦以 man page、培训教材、认证体系的“内部一致性”形成，便固化了 BSD 端“先验存在”被遮蔽的状态，但数字档案与考据工作将持续证明这一“知识”注定过时；总纲第 23 条（一切历史写作都是基于哲学设定的历史小说）：Linux 端主流叙事建构的“Todd C. Miller 1994 发明 sudo”“Solomon Hykes 2013 Docker 创新容器”等叙事本质上是“基于哲学设定的历史小说”
  - 史料：原材料/哲学/项目统摄史观/第 25 章.md 总纲原文；原材料/研究/linux 文化挪用/史学映射.md 的 25 条总纲映射；BSD 案例 1（sudo）、5（ports）、7（jail）、13（rc.d）、24（BPF → eBPF）案例文件 ［A］
  - 史观：总纲第 3 条——不存在进步，只有权力再分配：Linux 端“进步叙事”本质上是“权力再分配”，思想亦不随技术进步——BSD 端“社区与商业隔离”哲学不因 Linux Foundation 2007 治理模式出现而“过时”；总纲第 5 条——没有必然性，只有偶然性：每一个关键人物（Coggeshall 与 Spencer、PHK、Watson 与 Anderson）、每一次 fork、每一个技术决定，都是不可替代的偶然，“替代品的无限性不能否定事物的独特价值”；总纲第 11 条——商品是形式主义：4 种挪用模式本质上是“劣币驱逐良币”在技术归属维度的体现；总纲第 15 条——文化即形式主义：传统在形式主义化过程中被遮蔽与重构；总纲第 19 条——解释学循环是历史认识的根本条件：前理解的差异使 BSD 与 Linux 两端的分歧不可避免，“什么被记录、什么被遗忘”本身就是权力行使；总纲第 21 条——革命与改革是历史方法论的分歧：Linux 靠革命，BSD 靠改革，“改革的困难远高于革命”；总纲第 22 条——知识注定过时：技术史写作本身可能固化遮蔽，Linux 端主流叙事建构的“Linux 原生”知识看似稳固，但数字档案与考据工作将持续证明其“注定过时”；总纲第 23 条——一切历史写作都是基于哲学设定的历史小说：史家以为自己在书写历史，但历史人物可能正在藉着史家书写他们自己的故事
  - 辨析：8 条总纲的映射遵循“非穷尽性、非排他性、非客观性”原则——非穷尽性指每条总纲仅列举核心候选案例，79 项案例中多数可作多条总纲的候选；非排他性指同一案例可同时映射多条总纲（如 BSD 案例 1 sudo 同时映射总纲第 1、5、11、22 条）；非客观性指本映射基于项目统摄史观，不宣称“客观真实”；【0 信任原则】总纲第 19 条的“权力与知识共谋”须经具体案例的“什么被记录、什么被遗忘”考据——Coggeshall 与 Spencer 1980 sudo 起源被“遗忘”（Linux man **sudo(8)** 不回溯 4.1BSD 起源）、Terry 等 4 人 1984 BIND 起源被“遗忘”（BIND 9 官方文档不点明 4 人姓名）、Watson 与 Anderson 2012 Capsicum 起源被“遗忘”（Linux man **landlock(7)** 不点明二人姓名），这一“遗忘”须经一手档案与主流叙事的比对交叉验证
  - 文献：原材料/哲学/项目统摄史观/第 25 章.md；原材料/研究/linux 文化挪用/史学映射.md；BSD 案例 1、5、7、13、24 案例文件 ［A］
## 79.12.4 自反——本书书写本身亦是形式主义化的建构
  - 要点：本节的考据本身亦是形式主义化的非存在——史家通过一手档案“重构”Coggeshall 与 Spencer 1980 sudo、PHK 1999 jail、Terry 等 4 人 1984 BIND 等历史，但这一重构本身就是当下主体的形式主义建构，不宣称呈现“真实的 BSD 历史”；本节的“文化挪用”概念本身亦是项目统摄史观视角下的“形式主义化”建构，不同史观（如马克思主义史观、自由主义史观、后现代主义史观）下的结论可能不同；总纲第 7 条——理论必须自反：本书承认自身的形式主义性质，以自反姿态打开裂缝，“理论字数越多越不值钱”——本节不追求“穷尽所有案例”或“穷尽所有总纲映射”，而是以自反姿态打开裂缝，使被遮蔽的 BSD 端先验存在暴露于历史审视之下
  - 史料：原材料/哲学/项目统摄史观/第 25 章.md 总纲第 2 条（历史是形式主义化的非存在）、第 7 条（理论必须自反）、第 23 条（一切历史写作都是基于哲学设定的历史小说）、第 25 条（逻辑是形式主义而非世界本身的结构）；原材料/研究/linux 文化挪用/史学映射.md 的“映射的局限性说明”章节（非穷尽性、非排他性、非客观性、时效性、考据边界、哲学边界六条局限） ［A］
  - 史观：总纲第 2 条——历史是形式主义化的非存在：本书所写皆是当下主体的重构，从不宣称呈现历史本身；总纲第 7 条——理论必须自反：本书承认自身的形式主义性质，以自反姿态打开裂缝；总纲第 23 条——一切历史写作都是基于哲学设定的历史小说：史家以为自己在书写历史，但历史人物可能正在藉着史家书写他们自己的故事，“一切都是重复，一切都是古代史”；总纲第 25 条——逻辑是形式主义而非世界本身的结构：自反性不是逻辑悖论，而是对逻辑本身局限性的揭示
  - 辨析：自反的辨析须区分“考据的有限性”与“考据的无效性”——考据的有限性指本节的“证明 BSD 端先验存在”本身亦是形式主义化的非存在，不宣称“客观真实”；考据的无效性指因考据有限即否定考据价值，这是错误的——考据虽有限但通过一手档案的交叉验证仍可使被遮蔽的“BSD 存在”重新生成于历史叙事之中；本节的自反不追求“消除形式主义”，而是“以自反姿态打开裂缝”——使被遮蔽的 BSD 端先验存在暴露于历史审视之下，这一“暴露”本身也是一次循环，与古代史中“史家重写”无本质区别（总纲第 1 条：一切真历史都是古代史）；【0 信任原则】自反不等于自我否定——本节的考据遵循 0 信任原则与三次复查流程，所有事实以一手档案为交叉锚，自反是承认考据的哲学边界而非否定考据的史学价值
