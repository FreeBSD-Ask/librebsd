# 第 84 章 分裂时期的文化图景与三项目基因分化

## 要点

- 文化图景的史料辨析需区分 “文化描述” 与 “文化影响”——前者可考据（项目 slogan、邮件列表风格），后者需谨慎评估（文化对技术路径的具体影响）；辨析需平衡描述与影响
- 黑客文化的史料辨析需区分 “文化理想” 与 “实际实践”——前者是 Levy《Hackers》所载的理想化伦理，后者是 BSD 社区的实际实践（含冲突、权力斗争、个人恩怨）；辨析需剥离理想与实践
- BSD 符号演变的史料辨析需区分 “符号变化” 与 “文化意义变化”——前者可考据（Daemon 到 Puffy 的演变），后者需谨慎评估（文化意义的具体变化）；辨析需平衡符号与文化意义
