# 080.2.2 PF/OpenSSH 的不对称共享

  **要点**：OpenBSD 开发的 pf 与 OpenSSH 被 FreeBSD、NetBSD 等项目广泛采用——但 OpenBSD 从 FreeBSD/NetBSD 反向采用较少；不对称共享反映 BSD 阵营的工程贡献不平衡。PF/OpenSSH 不对称共享时间线如下：

| 事件 | 日期 | 备注 |
| -- | -- | -- |
| OpenSSH 导入 OpenBSD 源码树 | **1999-09-26** | Aaron Campbell、Bob Beck、Dug Song、Markus Friedl（马库斯·弗里德尔）、Niels Provos（尼尔斯·普罗沃斯）、Theo de Raadt（西奥·德·若特） 基于 Tatu Ylönen 的 SSH 1.2.12 分叉 |
| OpenSSH 随 OpenBSD 2.6 首次发布 | **1999-12-01** | OpenBSD src GitHub 镜像无 tag 信息，发布日期须以 openbsd.org 官方页面为准 |
| PF 导入 OpenBSD 源码树 | **2001-06-24** | Daniel Hartmeier（丹尼尔·哈特迈尔） 与 Henning Brauer（亨宁·布劳尔） 编写，因 Darren Reed（达伦·里德） 的 IPFilter 许可证变更为非自由 |
| PF 随 OpenBSD 3.0 首次发布 | **2001-12-01** | 语法大部分与 ipf 兼容 |
| deraadt 在 openbsd-src 累计 commit | 1995-10-18 至 2026-07-16 | **27,181** 个 commit，与 FreeBSD 核心贡献者 Jordan K. Hubbard（7,101 个 commit，1993-06-18 至 2004-11-14）相比，OpenBSD 项目高度依赖单一核心贡献者 |

反映 OpenBSD 通过高质量安全工具（OpenSSH/PF）向外辐射影响力的工程模式

**史料**：FreeBSD/NetBSD 主线合并 PF/OpenSSH 记录、OpenBSD 主线合并 FreeBSD/NetBSD 代码记录；openbsd.duckdb 数据库证据（2026-07-21 复核）：OpenSSH 于 1999-09-26 导入 OpenBSD 源码树，随 OpenBSD 2.6 首次发布（OpenBSD src GitHub 镜像无 tag 信息，发布日期须以 openbsd.org 官方页面为准）；PF 于 2001-06-24 导入 OpenBSD 源码树，随 OpenBSD 3.0 首次发布；deraadt 在 openbsd-src 累计 27,181 个 commit（1995-10-18 至 2026-07-16），与 FreeBSD 核心贡献者 Jordan K. Hubbard（7,101 个 commit，1993-06-18 至 2004-11-14）相比，OpenBSD 项目高度依赖单一核心贡献者，反映 OpenBSD 通过高质量安全工具（OpenSSH/PF）向外辐射影响力的工程模式 ［A］

**史观**：边缘者贡献：OpenBSD 作为边缘项目通过 PF/OpenSSH 等贡献影响整个 BSD 阵营

**辨析**：不对称共享的具体数据在不同叙事中略有差异——需对照主线合并记录核实；bsd_commits.duckdb 的 OpenBSD src GitHub 镜像可能滞后于 CVS 主仓（anoncvs.openbsd.org），且无 tag 信息，PF/OpenSSH 的具体发布版本日期须与 OpenBSD 官方 release 页面交叉验证

**文献**：FreeBSD/NetBSD 主线合并记录；OpenBSD 主线合并记录；OpenBSD src 首条 commit `df930be708d50e9715f173caa26ffe1b7599b157`（deraadt, 1995-10-18T08:37:01Z, “initial import of NetBSD tree”）；deraadt 在 openbsd-src 贡献者记录（27,181 commits, 1995-2026） ［A］
