# 080.1.1 de Raadt 独裁模式的形成

  **要点**：OpenBSD 长期由 Theo de Raadt 个人主导——无 Core Team 选举、无 Foundation 董事会干预，所有重大决策由 de Raadt 最终拍板；模式形成于 **1995-2000 年** 间，与 OpenBSD 创建背景密切相关。独裁模式形成期 openbsd-src commit 量数据如下：

| 年份 | commit 量 | 备注 |
| -- | ------- | -- |
| 1995 | 770 | OpenBSD CVS 仓库初始导入年（10 月 18 日） |
| 1996 | 5,240 | OpenBSD 1.2/2.0 发布年，较 1995 年增长约 6.8 倍 |
| 1997 | 6,888 | 稳定平台期 |
| 1998 | 5,207 | 稳定平台期 |
| 1999 | 6,547 | 首个 hackathon（6 月 Calgary）、OpenSSH 导入（9 月 26 日） |
| 2000 | 7,265 | 稳定平台期 |
| **累计** | **32,117** | **6 年合计** |

反映 de Raadt 独裁模式形成期 OpenBSD 项目开发活跃度持续稳定增长，**1996 年**（OpenBSD 1.2/2.0 发布年）较 **1995 年** 增长约 6.8 倍后进入 5,000-7,000 commits/年的稳定平台

**史料**：OpenBSD 官方 FAQ、de Raadt 个人主页自述、OpenBSD CVS 历史全量［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］；openbsd.duckdb 查询 L1.1.1 显示：openbsd-src 1995-2000 年 commit 量分别为 770（1995）、5,240（1996）、6,888（1997）、5,207（1998）、6,547（1999）、7,265（2000），6 年累计 32,117 commits，反映 de Raadt 独裁模式形成期 OpenBSD 项目开发活跃度持续稳定增长，1996 年（OpenBSD 1.2/2.0 发布年）较 1995 年增长约 6.8 倍后进入 5,000-7,000 commits/年的稳定平台

**史观**：组织结构塑造技术路径：de Raadt 独裁模式决定 OpenBSD 的工程方向

**辨析**：独裁模式的形成过程在不同叙事中差异较大——部分视为主动选择，部分视为被动形成；需对照 OpenBSD 早期邮件列表核实；【0 信任原则·commit 量不等于质量】L1.1.1 的 1995-2000 openbsd-src commit 量（770→5,240→6,888→5,207→6,547→7,265）反映开发活跃度但不等于代码质量，de Raadt 独裁模式的质量评估须结合 commit message 主题词与安全公告记录综合判断；【0 信任原则·CVS-to-Git 迁移风险】openbsd-src 主仓为 CVS（anoncvs.openbsd.org），GitHub 为只读 git 镜像，CVS-to-Git 转换可能引入日期偏差或作者归属错误，1995-2000 年 commit 量基线须与 OpenBSD 官方档案交叉验证；【0 信任原则·GitHub 镜像滞后】openbsd-src GitHub 镜像可能滞后于 CVS 主仓，1995-2000 年 commit 量的精度须以官方档案为准；【L3.1.1.audit 查询不存在】openbsd.duckdb 数据分析报告《深层信息挖掘.md》中 L3.1.1 系列仅含 MFC/Fix/Add/Refactor/Document/Linux/Import/Update 8 个关键词查询，无独立 ‘audit’ 关键词查询，OpenBSD 全代码审计文化形成（1996 年夏天起，OpenBSD security.html 明确记载 “We have been auditing since the summer of 1996”）的量化识别须通过手动检索 openbsd-src commit message 中 ‘audit’ 关键词补全，不可凭空引用 L3.1.1.audit 查询结果
