# 078.5.3 NIS（YP）的逐步退役

  **要点**：NIS（Network Information Service，原 Yellow Pages，因商标争议改名）由 Sun Microsystems **1985 年** 发布，1990 年代在 UNIX 环境中广泛用于集中式用户与主机管理；OpenBSD 因 NIS 的明文传输、无认证、广播查询等安全缺陷，自 2.0（**1996 年 10 月**）起将 **ypserv(8)** 默认禁用，但保留 NIS 客户端支持以便与既有环境互操作；OpenBSD 4.0（**2006 年 11 月**）将 NIS 服务端组件从 base system 完全移除，仅保留客户端；OpenBSD 6.0（**2016 年 9 月**）进一步移除 NIS 客户端支持，使 OpenBSD 完全不再支持 NIS——NIS 的位置由 LDAP（slapd 等）取代，但 LDAP 在 OpenBSD base 中不提供，需通过 ports 安装。NIS 退役时间线如下：

| 事件 | 版本/日期 | 备注 |
| -- | ------- | -- |
| NIS 服务端默认禁用 | OpenBSD 2.0（1996-10） | 保留客户端支持 |
| NIS 服务端从 base 移除 | OpenBSD 4.0（2006-11） | 仅保留客户端 |
| NIS 客户端从 base 移除 | OpenBSD 6.0（2016-09） | 完全不再支持 NIS |

**史料**：OpenBSD 2.0 Release Notes (1996.10) NIS 默认禁用条目、OpenBSD 4.0 Release Notes (2006.11) NIS 服务端移除条目、OpenBSD 6.0 Release Notes (2016.9) NIS 客户端移除条目、Sun 1985 NIS（Yellow Pages）原始文档 ［A］

**史观**：总纲第 13 条——法律与道德是利益分配〔存疑：对位待主理人审定〕：NIS 的逐步退役体现 OpenBSD 对历史遗留协议的安全优先淘汰策略；总纲第 4 条——分离与聚合：NIS 退役后其功能由 LDAP 与 Kerberos 等分散聚合

**辨析**：NIS 退役的精确版本在不同来源中说法不一——OpenBSD 4.0 移除服务端，6.0 移除客户端，分两阶段；LDAP 是否真正 “取代” NIS 在企业环境中需考据
