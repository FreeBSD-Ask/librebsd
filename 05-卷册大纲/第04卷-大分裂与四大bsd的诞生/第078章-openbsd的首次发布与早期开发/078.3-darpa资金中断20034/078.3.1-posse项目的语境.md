# 078.3.1 POSSE 项目的语境

  **要点**：POSSE（Portable Open Source Security Enterprise）项目由 DARPA 资助——总资助 **2,125,000 美元**，其中约 **100 万** 分配给 OpenBSD；项目背景涉及 9/11 后美国政府对开源安全的关注。POSSE 项目资金时间线如下：

| 事件 | 时间 | 备注 |
| -- | -- | -- |
| DARPA POSSE 项目启动 | 2002-2003 年 | 9/11 后政府关注开源安全 |
| 总资助 | 2,125,000 美元 | 其中约 100 万给 OpenBSD |
| 《环球邮报》采访 | 2003-04 | de Raadt 反战言论 |
| DARPA 资金中断通知 | 2003-04 | OpenBSD 失去政府资金 |

**史料**：DARPA POSSE 项目公告（2002-2003）、OpenBSD 官方关于 POSSE 的声明、de Raadt 关于 POSSE 的公开邮件［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］

**史观**：总纲第 13 条——法律与道德是利益分配：POSSE 项目是 OpenBSD 接受政府资金的关键尝试，资助与撤资皆是利益分配的安排

**辨析**：POSSE 项目的具体资助金额在不同叙事中略有差异——部分资料称 2,125,000 美元，部分称其他数字；需对照 DARPA 公告核实
