# 078.6.4 Windows 95（1995）/ Windows NT 3.51（1995）

  **要点**：Microsoft Windows 95（1995.8）是面向消费者的 16/32 位混合桌面系统，NT 3.51（1995.5）是面向服务器的 32 位微内核架构；二者均为闭源商业系统，无公开源代码安全审计，其安全模型（用户权限、NT 的 ACL）与 OpenBSD 的 “默认拒绝/权限分离” 哲学迥异。OpenBSD 的开源审计模式在闭源 Windows 世界无对应物。
  
**史料**：Microsoft Windows 95 / NT 3.51 发布文档（1995）［A］；NT 安全架构白皮书 ［B］
  
**史观**：总纲第 4 条——分离聚合是永恒规律：闭源商业系统的 “黑盒安全” 与 OpenBSD 的 “公开审计安全” 由共同的安全工程需求分离后各自聚合，形成根本方法论对立，这一对立延续至今。
  
**辨析**：Windows NT 的 ACL 模型与 OpenBSD 的 permission separation 目标相似（最小权限）但实现路径不同（闭源 vs 开源审计）；将 Windows 简单视为 “不安全” 忽视了 NT 的企业安全设计。
  
**文献**：Microsoft. Windows NT 3.51 Resource Kit [Z]. 1995；Custer H. Inside Windows NT [M]. 1993. ［B］
