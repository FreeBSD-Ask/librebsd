# 087.2.3 重写即归属模式典型案例

  **要点**：重写即归属模式指 Linux 或 FSF 端对 BSD 或 UNIX 端既有工具进行实质性重写（通常采用 GPL 许可证）后，主流叙事将原作者替换为重写者，原作者姓名、机构、公告日期等关键归属信息被抹去或退居次要位置；本目选取 BSD 案例 11（BSD Make → GNU Make）、BSD 案例 15（FFS → ext2/ext3/ext4）、BSD 案例 22（sendmail → Postfix）、BSD 案例 17（patch → GNU patch）4 项典型案例
  
**史料**：BSD 案例 11——Stuart Feldman 1976 在 Bell Labs 设计 Make，Adam de Boor 1986-1987 编写 pmake（BSD Make），Richard Stallman 与 Roland McGrath 1988 起为 FSF 重写 GNU Make，1993 GNU Make 3.0 公开，Feldman 1976 起源与 pmake 1986 扩展在 GNU Make 官方手册中被弱化为“早期 Make 历史”；BSD 案例 15——Marshall Kirk McKusick（马歇尔·柯克·麦库西克） 1983-08 随 4.2BSD 设计并发布 FFS（cylinder group、block size 4K、rotation optimization），1984 SOSP 论文权威学术公开，Rémy Card 1993-01 提交 ext2 至 Linux 0.99.x，Stephen Tweedie 1999-11 引入 ext3 journal，Theodore Ts'o 2006-10 ext4 experimental、2008-10-24 Linux 2.6.28 ext4 stable，FFS cylinder group 哲学在 Linux Foundation 培训中被淡化为“类似设计”；BSD 案例 22——Eric Allman（埃里克·奥尔曼） 1979 在 UCB 编写 delivermail 随 BSD 4.0 释出，1983 sendmail 1.0 随 4.1cBSD 释出，1996 年约 80% 公网邮件服务器运行 sendmail，Postfix 1997 Wietse Venema 在 IBM T.J. Watson Research Center 编写、1998-12-14 首次发布，qmail 1995-12 Daniel J. Bernstein 起编写、1.03 1998-06-15 final，Eric Allman 1983 BSD 起源在 Postfix 与 qmail 官方文档中不被点明；BSD 案例 17——Larry Wall 1984 起编写 patch 工具，1985-05-08 mod.sources 公告 patch 1.3（<wall@sdcrdcf.UUCP>），FSF 1990 年代初 fork 出 GNU patch，Wall 1985-05-08 公告日期与 <wall@sdcrdcf.UUCP> 在 Linux 端主流叙事中几近消失，构成“无更名的事实更名”——代码同名但归属被替换 ［A］
  
**史观**：同 79.11.1 总述，总纲第 11 条——商品是形式主义：重写即归属是 BSD 端技术经 GPL 重写后封装为“开源软件商品”的典型权力运作；总纲第 22 条——知识注定过时，重写者建构的“Linux 原生”叙事终将被代码血缘考据证伪
  
**辨析**：重写即归属模式的考据须警惕“工程量大即原创性强”的简化陷阱——重写者在重写过程中确实投入大量工程量，但“工程量大”不等于“原创性强”，须以重写 commit 中的“代码血缘”（关键函数签名、blame 历史、SCCS 或 CVS 起点）作交叉验证；4 项案例的“代码血缘”均有据可循——GNU Make 的变量扩展与模式规则承袭 Feldman 1976 Make 与 pmake 1986 扩展、ext4 的 cylinder group 哲学承袭 McKusick 1983 FFS、Postfix 的 mail queue 与 MTA 架构承袭 Allman 1983 sendmail、GNU patch 的 context diff 与 unified diff 逻辑承袭 Wall 1985 patch；【0 信任原则】重写版的“重新设计”自我定位须经代码血缘比对验证，不得仅凭重写者自述即采信
  
**文献**：BSD 案例 11、15、22、17 案例文件；Feldman 1976 Make 论文；McKusick 1984 SOSP FFS 论文；Allman 1983 sendmail 4.1cBSD 发布记录；Wall 1985-05-08 mod.sources patch 1.3 公告 ［A］
