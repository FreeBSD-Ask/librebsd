# 087.2.6 平行演化与扩展超越（混合形态 E）

  **要点**：平行演化与扩展超越是 4 种模式的混合形态——平行演化指同一时期两个生态独立开发功能相似的工具，但设计理念相互借鉴，最终 Linux 版本因市场或生态优势成为事实标准，BSD 平行方案被边缘化；扩展超越指 Linux 端在 BSD 原创基础上进行重大工程扩展，扩展部分的巨大成功反向建构“Linux 原创”叙事，BSD 原始贡献被弱化为“灵感来源”或“历史脚注”；本目选取 BSD 案例 24（BPF → eBPF）、BSD 案例 36（PF → nftables）、BSD 案例 31（syslog → rsyslog）3 项典型案例
  
**史料**：BSD 案例 24——Steven McCanne 与 Van Jacobson（LBL）1992 至 1993 设计 BPF，论文《The BSD Packet Filter: A New Architecture for User-level Packet Capture》发表于 USENIX Winter 1993（1993-01），随 4.4BSD 1994-06 集成进 BSD 内核，Alexei Starovoitov 与 Daniel Borkmann 2014 年起将 BPF 扩展为 eBPF，从“数据包过滤虚拟机”扩展为支持网络、跟踪、安全、性能分析的通用内核虚拟机（Linux 3.18 2014-12 雏形、Linux 4.1 2015-06 成熟），eBPF 在虚拟机核心设计（累加器、寄存器、指令集、辅助函数调用约定）上承袭自经典 BPF 1993，但在 CNCF 与 eBPF Foundation 营销材料中常被描述为“Linux 内核革命性技术”，McCanne 与 Van Jacobson 1993 原创被弱化为“BPF 起源于 BSD”；BSD 案例 36——Daniel Hartmeier（丹尼尔·哈特迈尔） 主导 OpenBSD 团队 2001 年开发 PF，随 OpenBSD 3.0 2001-12-01 首次公开发布，Rusty Russell 与 Harald Welte 团队 2000 至 2001 开发 netfilter 与 iptables（Linux 2.4 2001-01 稳定），比 PF 早 11 个月，属于平行演化，Patrick McHardy 与 Pablo Neira Ayuso 团队 2014 年发布 nftables（Linux 3.13 2014-01-19），引入“sets”（类似 PF tables）、“chains in tables”（类似 PF anchors），netfilter 核心开发者 Pablo Neira Ayuso 在多个场合承认 PF 的设计对 nftables 的启发，但 nftables 官方文档将 nftables 建构为“iptables 的下一代演进”，PF 作为平行方案的影响被最小化；BSD 案例 31——Eric Allman 1980 至 1983 年在 CSRG 为 sendmail 设计 syslog，随 4.2BSD 1983-08 首次公开发布（库接口）、4.3BSD 1986-06 包含完整 syslogd 守护进程，RFC 3164 2001-08 明确记载"originally developed in the 1980s by Eric Allman for the sendmail project"，Rainer Gerhards 2004 年从 sysklogd fork 出 rsyslog，增加 TCP 与 TLS 传输、RELP 可靠传输、Kafka 与 Elasticsearch 输出、结构化日志、过滤规则等，成为 RHEL 与 CentOS 与 Ubuntu 默认 syslog 实现，rsyslog 官方文档将自身描述为“rocket-fast system for log processing”，对 sysklogd 起源与 BSD syslog 根源仅以简短“based on sysklogd”带过 ［A］
  
**史观**：同 79.11.1 总述，总纲第 17 条——证明世界先于解释和改造世界：平行演化案例仍须先“证明 BSD 端的先验存在”；总纲第 22 条——知识注定过时，Linux 端“扩展超越”建构的“Linux 原创”叙事注定过时
  
**辨析**：平行演化与扩展超越的考据须区分“核心设计承袭”与“工程实现扩展”——扩展规模大不等于原创性强，须以虚拟机核心设计、辅助函数签名、API 兼容性等具体血缘作交叉锚；3 项案例的“核心设计承袭”均有据可循——eBPF 在累加器、寄存器、指令集、辅助函数调用约定上承袭 BPF 1993、nftables 在 sets 与 chains 设计上承袭 PF 2001（Pablo Neira Ayuso 本人承认）、rsyslog 在 facility 与 severity 双层分类与 **syslog(3)** API 上承袭 BSD syslog 1983；【0 信任原则】“平行演化”与“扩展超越”的区分须经设计理念比对与时序比对交叉验证——iptables 2001-01 比 PF 2001-12 早 11 个月属平行演化，eBPF 2014 比 BPF 1993 晚 21 年属扩展超越，二者非同一形态
  
**文献**：BSD 案例 24、36、31 案例文件；McCanne 与 Van Jacobson 1993 USENIX BPF 论文；4.4BSD 1994-06 集成记录；OpenBSD 3.0 2001-12-01 PF 发布记录；Linux 2.4 2001-01 netfilter/iptables 发布记录；Linux 3.13 2014-01-19 nftables 发布记录；RFC 3164 2001-08；4.2BSD 1983-08 syslog 发布记录 ［A］
