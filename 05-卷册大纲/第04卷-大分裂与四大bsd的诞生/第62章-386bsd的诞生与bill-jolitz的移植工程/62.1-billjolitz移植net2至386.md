# 62.1 Bill Jolitz 移植 Net/2 至 386

## 61.1.1 Jolitz 的技术语境

  **要点**：Bill Jolitz 1980 年代在伯克利参与 2.8BSD 与 2.9BSD 开发，后在 Symmetric Computer Systems 工作期间向伯克利贡献代码；1989 年开始将 BSD 移植到 386 平台，当 CSRG 裁定其 386 移植工作为 “大学专有” 后，Jolitz 基于 Net/2 的自由代码从头重写；1991 年曾短暂任职于 UUNET（后分拆出 BSDi），但因方向分歧很快离开；Lynne Jolitz 作为共同开发者与 Bill 协作，夫妇二人共同撰写 Dr. Dobb's Journal 17 部分连载与两卷《Operating System Source Code Secrets》书籍，形成内核 + 文档/写作的协作组合。技术能力横跨 BSD 内核与 PC 硬件平台是后续 386BSD 移植的工程基础
  
**史料**：Jolitz 夫妇 Dr. Dobb's Journal 1991.1-1992.7 连载《Porting UNIX to the 386》（共 17 部分）、386BSD 0.0 Release Notes (1992.3)、386BSD 0.1 Release Notes (1992.7.14)、Rachel Chalmers "The unknown hackers" Salon 2000.5.17 专访、comp.unix.bsd 早期 Usenet 帖 ［B］
  
**史观**：边缘者贡献：Jolitz 以独立开发者身份承担了 BSD 在 386 平台上的早期移植，当大学主张其工作的所有权后从头重写，体现了边缘者突破制度约束的创造力
  
**辨析**：Jolitz 在 CSRG 的具体头衔存在不同叙事——部分资料称其为 “研究工程师”，另一部分称其为 “外协贡献者”，386BSD 0.0 Release Notes 仅称其为 William F. Jolitz，未提 CSRG 正式头衔；Jolitz 是否为 BSDi 联合创始人说法不一——部分中文来源称其为 BSDi 联合创始人（与 Donn Seeley、Mike Karels、Trent Hein 共同创办），但一手资料显示其仅短暂任职于 UUNET 后因方向分歧离开，BSDi 的 BSD/386（后称 BSD/OS）使用 Jolitz 贡献给伯克利的代码但为独立商业产品，需对照多源核实
  
**文献**：Jolitz, W. F. & Jolitz, L. G. "Porting UNIX to the 386" DDJ 1991.1-1992.7 连载（共 17 部分）；386BSD 0.0 Release Notes (1-7 March 1992)；386BSD 0.1 Release Notes (14 July 1992, Bastille Day)；Chalmers, R. "The unknown hackers" Salon, 17 May 2000；McKusick, M. K. et al. "Design and Implementation of the 4.4BSD Operating System" (Addison-Wesley 1996) ISBN 0-201-54979-4；Salus, P. H. "A Quarter Century of UNIX" (Addison-Wesley 1994) ISBN 978-0-201-54777-1；Jolitz, W. F. & Jolitz, L. G. "Operating System Source Code Secrets Vol 1: The Basic Kernel" (Peer-to-Peer Communications 1996) ISBN 1-57398-026-9 ［A］

## 61.1.2 Net/2 至 386 移植的技术挑战

  **要点**：Net/2（1991.6）以源码形式发布但不含完整可启动系统，Jolitz 最初为 CSRG 做的 386 移植被大学主张为 “专有” 后，基于 Net/2 的自由代码从头重写，补齐 386 内核缺失组件——pmap（虚拟内存子系统）、陷阱处理、控制台驱动、磁盘驱动、文件系统引导扇区等；386 处理器的分段与分页机制、保护模式切换、中断向量布局都需重新实现；Jolitz 重写的关键组件包括全新的虚拟内存实现，而非简单沿用 Net/2 中的 VM 代码
  
**史料**：Net/2 Release Notes（1991.6）、Jolitz DDJ 连载 1991.1-1992.7 各期（含 "Missing Pieces I and II", May-June 1992）、386BSD 0.0/0.1 源码树、Jolitz "Operating System Source Code Secrets Vol 2: Virtual Memory" (2000) ［A］
  
**史观**：硬件与软件辩证：386 硬件能力（32 位、分页、保护模式）的释放需要与之匹配的内核代码改写；Jolitz 重写 VM 的决定体现了从头设计而非修补的工程哲学
  
**辨析**：Net/2 是否包含可启动内核存在叙事分歧——CSRG 官方称 Net/2 “非完整系统”，Jolitz 在 DDJ 连载 "Missing Pieces" 系列中明确列出需补齐的关键缺失组件；关于 VM 重写——Jolitz 在其著作中声称 386BSD 包含全新内核设计，而非简单移植 Net/2 代码，需对照源码核验 VM 实现的原创性
  
**文献**：CSRG "4.3BSD-Net/2 Release Notes" (June 1991)；Jolitz, W. F. & Jolitz, L. G. "Porting UNIX to the 386" DDJ 1991.1-1992.7 连载；Jolitz "Missing Pieces I and II" DDJ, May-June 1992；McKusick, M. K. "Twenty Years of Berkeley Unix" in Open Sources (O'Reilly 1999)；Jolitz, W. F. & Jolitz, L. G. "Operating System Source Code Secrets Vol 2: Virtual Memory" (Peer-to-Peer Communications 2000) ISBN 1-57398-027-7 ［A］

## 61.1.3 移植完成的时间线

  **要点**：1989 年 Jolitz 开始 386 移植实验；**1992-03-12** 发布 **386BSD 0.0**（首个公开版本，由 Dr. Dobb's Journal 配套发行）；**1992-07-14**（Bastille Day/法国国庆日）发布 **386BSD 0.1**，因 AT&T 诉讼于 **1992 年 8 月** 暂停公开更新；**1994 年末（late 1994）** 发布 **386BSD 1.0** 时已远落后于 FreeBSD/NetBSD；**不存在 386BSD 0.2 公开版本**——社区补丁包积累期间无 Jolitz 官方版本发布。386BSD 版本发布时间线如下：

| 版本 | 发布日期 | 备注 |
| -- | ------ | -- |
| 386BSD 0.0 | 1992-03-12 | 首个公开版本，DDJ 配套发行 | | |
| 386BSD 0.1 | 1992-07-14 | Bastille Day，因 USL 诉讼后暂停公开更新 | | |
| 386BSD 1.0 | 1994 年末 | 远落后于 FreeBSD/NetBSD | | |

**史料**：386BSD 0.0 Release Notes (1-7 March 1992)、386BSD 0.1 Release Notes (14 July 1992)、comp.unix.bsd Usenet 原始公告（386BSD 0.0 发布于 12 March 1992）、NetBSD Project 官方历史时间线、FreeBSD Handbook "A Brief History of FreeBSD"；freebsd.db 间接证据——netbsd-src 中 cgd 1993-03-21T09:45:37Z 提交 "initial import of 386bsd-0.1 sources"（commit_hash `0d110d127c41d7aeb2b1bfdc71964c5a496eabf9`），证明 386BSD 0.1 至迟在 1993-03-21 已被 NetBSD 项目作为基线 import，与 1992-07-14 Release Notes 日期一致；freebsd-src 中 Rodney W. Grimes（罗德尼·W·格赖姆斯） 1993-06-20T13:41:45Z 提交 "Initial import of 386BSD 0.1 othersrc/etc"（commit_hash `1bf9d5d9518e789360439c1db3d568b113caf60d`），印证 FreeBSD 项目亦以 386BSD 0.1 为 fork 基线 ［A］

**史观**：偶然性改写历史：Jolitz 在 1992 年中后期的停滞是一个具体的人的具体决定，但这一停滞直接催生了 FreeBSD 与 NetBSD 的 fork；不存在的 0.2 版本成为社区补丁包与 fork 叙事的误解来源

**辨析**：**386BSD 0.0 发布日期经一手 Usenet 公告确认为 1992 年 3 月 12 日**，而非先前误传的 1991 年 7 月或 1992 年 2 月；**经 NetBSD 官方时间线、FreeBSD 官方历史、386BSD 0.0/0.1 Release Notes 三方交叉验证，确认不存在 386BSD 0.2 公开版本**——"0.2" 可能是对社区 patchkit 累积版本的误称，或源于非正式的内部测试版本；386BSD 1.0 发布于 1994 年末（late 1994），晚于 NetBSD 0.8（1993 年 4 月）与 FreeBSD 1.0（1993 年 11 月公告/12 月 CD-ROM）；freebsd.db 验证结论——386BSD 0.1 作为 FreeBSD 与 NetBSD 共同基线，在 netbsd-src 与 freebsd-src 早期 commit 中均有显式 import 记录，commit message 中明确提及 "386bsd-0.1 sources" 与 "Initial import of 386BSD 0.1 othersrc/etc"，与 Release Notes 日期相互印证；0 信任原则提示：386BSD 0.0/0.1 本身无独立 git 仓库（Bill Jolitz 1990 年代早期使用单一 tarball 分发），数据库中的 import commit 是下游项目对 386BSD 源码的二次 import，时间晚于原始发布日期约 9-12 个月，须与一手 Release Notes 与 Usenet 公告交叉验证

## 61.1.4 移植工作的工程意义

  **要点**：386BSD 是首个能在普通 PC 上运行的免费 32 位 BSD 系统，证明 BSD 内核可在 commodity x86 硬件上稳定运行；其 MI/MD 分层设计为后续 FreeBSD/NetBSD 的多平台架构奠定了基础；Net/2 + 386BSD 的组合为 USL 诉讼后 BSD 重建提供了法律清白的代码基础
  
**史料**：386BSD 0.1 源码树、Jolitz DDJ 连载代码清单、FreeBSD 1.0 源码与 386BSD 的对照分析、USL v. BSDi 判决书 ［A］
  
**史观**：软件工程：Jolitz 的工作是将学术 BSD 内核工程化至 PC 平台的实践，体现了 “实践先于理论” 的工程传统
  
**辨析**：386BSD 与 FreeBSD 1.0 代码共享比例存在不同估计——FreeBSD Project 倾向强调自身独立性，Jolitz 夫妇则强调 FreeBSD 大量继承 386BSD 代码，需对照源码 diff 独立核验
  
**文献**：Jolitz DDJ 连载；FreeBSD Project 官方历史文档；Marshall Kirk McKusick（马歇尔·柯克·麦库西克） "Design and Implementation of 4.4BSD" (Addison-Wesley 1996) ［B］
