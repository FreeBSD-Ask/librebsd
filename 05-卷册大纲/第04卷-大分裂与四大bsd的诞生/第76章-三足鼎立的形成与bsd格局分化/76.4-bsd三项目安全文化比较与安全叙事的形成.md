# BSD 三项目安全文化比较——安全叙事的形成

## BSD.1 OpenBSD 的‘安全优先’叙事构建与学术检验

**要点**：OpenBSD 以代码审计与安全默认配置为核心差异化叙事（de Raadt, DEF CON 5, 1997）。但 2019 年调查显示 OpenBSD 基础安装的 CVE 密度与 FreeBSD 无统计显著差异。

**史料**：de Raadt DEF CON 1997; ACM CCS 2019 安全比较 ［A］

**史观**：总纲第 14 条——叙事建构与技术现实。

**文献**：de Raadt 1997; CCS 2019 ［A］

史学含义：BSD 的历史中，Linux 的崛起、FreeBSD 的边缘化、OpenBSD 的安全转向、DragonFly 的 fork，皆非必然。不写"若没有某某也会有另一个人做同样的事"，因为世界上没有必然性只有偶然性。每一个关键节点都是不可替代的偶然。

以食品安全为例：人们永远无法得到真正的认识。你既不能说科学证明其在某量无毒害就真的无毒害，也不能证明它真的有毒害。用科学说服人本身就不科学——因为科学本身就是非充分决定性的，本身的正确性是得不到保证的。且你能得到的所有科学解释，正因为它是科学解释，所以它必定也是错误的。这并非反智，而是对科学边界的清醒认识。好坏是对于人来说的，所谓"剂量决定论"也是无意义的——零剂量不是更安全吗？
