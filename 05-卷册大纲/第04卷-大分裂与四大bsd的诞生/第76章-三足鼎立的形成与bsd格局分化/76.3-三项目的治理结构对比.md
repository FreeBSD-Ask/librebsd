# 76.3 三项目的治理结构对比——Core Team 选举制、NetBSD Foundation 董事会制、OpenBSD 个体主导制

## 76.3.1 FreeBSD Core Team 选举制

  **要点**：FreeBSD 采用 Core Team 选举制——Core Team 由 committer 选举产生，承担技术决策；选举制是 FreeBSD 治理结构的核心特征
  
**史料**：FreeBSD Core Team 选举规则、Core Team 历年选举记录、FreeBSD Foundation 关于治理的声明 ［A］
  
**史观**：总纲第 8 条——本体论上各方平等：Core Team 选举制是 BSD 项目治理结构的典型形态之一，与董事会制、个体主导制在治理形态上平等并存
  
**辨析**：选举制的具体程序在不同时期存在差异——需对照选举规则历年版本核实
  
**文献**：FreeBSD Core Team 选举规则；历年选举记录 ［A］

## 76.3.2 NetBSD Foundation 董事会制

  **要点**：NetBSD 采用 Foundation 董事会制——董事会由成员选举产生，承担法律与资金决策；董事会制是 NetBSD 治理结构的核心特征
  
**史料**：NetBSD Foundation By-Laws、董事会历年选举记录、Foundation 关于治理的声明 ［A］
  
**史观**：总纲第 8 条——本体论上各方平等：Foundation 董事会制是 BSD 项目治理结构的另一典型形态，承担法律与资金维度的组织化决策
  
**辨析**：董事会制的具体程序在不同时期存在差异——需对照 By-Laws 历年版本核实
  
**文献**：NetBSD Foundation By-Laws；董事会选举记录 ［A］

## 76.3.3 OpenBSD 个体主导制

  **要点**：OpenBSD 采用个体主导制——de Raadt 作为项目创始人承担最终决策权，无 Core Team 选举、无 Foundation 董事会干预；个体主导制是 OpenBSD 治理结构的核心特征
  
**史料**：OpenBSD 官方 FAQ、de Raadt 关于治理的公开声明、OpenBSD Foundation 注册文件［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档与公告〕
  
**史观**：总纲第 8 条——本体论上各方平等：个体主导制是 BSD 项目治理结构的又一形态，个体最终决策权不构成治理形态的优劣判据
  
**辨析**：个体主导制的具体边界在不同叙事中略有差异——需对照 OpenBSD 官方声明核实

## 76.3.4 三种治理结构的对比

  **要点**：FreeBSD Core Team 选举制、NetBSD Foundation 董事会制、OpenBSD 个体主导制——三种治理结构各有优劣，影响项目工程方向与社区文化；对比反映 BSD 阵营治理结构的多样性。三种治理结构对照如下：

| 项目 | 治理结构 | 决策主体 | 核心特征 |
| -- | ------ | ------ | ------ |
| FreeBSD | Core Team 选举制 | Core Team（由 committer 选举产生） | 技术决策民主化 |
| NetBSD | Foundation 董事会制 | 董事会（由成员选举产生） | 法律与资金决策组织化 |
| OpenBSD | 个体主导制 | de Raadt 个人 | 无 Core Team 选举、无 Foundation 董事会干预〔存疑：negative 表述以 OpenBSD 官方文档逐年核验〕 |

**1995-1997 年** 三项目邮箱占比演化（openbsd.duckdb L3.3.3 查询）如下：

| 年份 | @freebsd.org | @netbsd.org | @openbsd.org |
| -- | ---------- | --------- | ---------- |
| 1995 | 55,825（88.91%） | 6,189（9.86%） | 770（1.23%） |
| 1996 | 57,470（80.93%） | 8,077（11.37%） | 5,466（7.70%） |
| 1997 | 71,840（76.40%） | 13,728（14.60%） | 7,748（8.24%） |

三年窗口（1995-1997）内 @freebsd.org 占比自 88.91% 缓降至 76.40%，@netbsd.org 自 9.86% 升至 14.60%，@openbsd.org 自 1.23% 升至 8.24%（数据陈述止于此；治理结构与团队规模的关联推断移入要点段辨析）

**史观**：总纲第 4 条——分离聚合是永恒规律：三项目自同一 BSD 谱系分离后各自形成选举制、董事会制、个体主导制的治理结构，治理差异反塑各自的工程方向与社区文化

**辨析**：三种治理结构的优劣评估在不同叙事中差异较大——需对照多方公开声明核实；【0 信任原则·author 字段可伪造】L3.3.3 的项目邮箱占比基于 author_email 字段，git 的 author 字段可由提交者任意填写，分析贡献者归属时须与 committer 字段交叉验证；【0 信任原则·项目邮箱不代表项目成员身份】@freebsd.org/@openbsd.org/@netbsd.org 邮箱可能为非提交者持有（如邮件列表订阅者），项目邮箱占比仅为核心团队规模的近似指标，不可等同于正式成员数；【0 信任原则·CVS-to-Git 迁移风险】netbsd-src 与 openbsd-src 均为 CVS 主仓的 GitHub 镜像，CVS-to-Git 转换可能重写 author_email 字段，1995-1997 年项目邮箱占比的精度须与官方档案交叉验证
