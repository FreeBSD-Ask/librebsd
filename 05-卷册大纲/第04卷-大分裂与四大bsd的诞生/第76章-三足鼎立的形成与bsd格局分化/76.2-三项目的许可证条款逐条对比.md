## 75.2.4 三项目许可证选择的对比

  **要点**：FreeBSD、NetBSD、OpenBSD 三项目在许可证选择上存在差异——FreeBSD 早期使用 4 条款后改为 2 条款，NetBSD 使用 2 条款，OpenBSD 使用 ISC 许可证；对比反映三项目对许可证简洁化的不同追求。三项目许可证选择对照如下：

| 项目 | 早期许可证 | 当前许可证 | 简洁化程度 |
| -- | -------- | -------- | -------- |
| FreeBSD | BSD 4 条款 | BSD 2 条款 | 中等 | | |
| NetBSD | BSD 2 条款 | BSD 2 条款 | 中等 | | |
| OpenBSD | — | ISC 许可证 | 最高 | | |

BSD 许可证条款演化对照如下：

| 许可证 | 条款数 | 包含内容 | 移除条款 |
| ---- | ---- | ------ | ------ |
| BSD 4 条款 | 4 | 版权声明、许可证声明、免责声明、广告条款 | — | | |
| BSD 3 条款 | 3 | 版权声明、许可证声明、免责声明 | 移除广告条款 | | |
| BSD 2 条款 | 2 | 版权声明、免责声明 | 移除“不得用于推广”条款 | | |
| ISC 许可证 | — | 简化的开源许可证 | 进一步简化 | | |
