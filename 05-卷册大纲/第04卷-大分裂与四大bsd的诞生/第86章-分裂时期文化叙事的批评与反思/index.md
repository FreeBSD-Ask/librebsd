## 要点

- 边缘贡献者的史料辨析须对照三类史料交叉验证——技术贡献（补丁、本地化）经 bsd_commits.db commit 数统计、文化贡献（翻译、培训）经 BSD 本地化项目档案、组织贡献（大会、联络）经 BSD 大会与社区组织档案；不得仅依赖代码提交记录评估贡献
- **1992-1996 年** 基础科学与计算机科学发展——复杂度理论实用化（近似算法、随机算法）、信息论与数据压缩（zlib/gzip）、Web 技术的数学基础（HTML、HTTP、URL）；基础科学与 CS 进步塑造 BSD 互联网基础设施

- 计算机科学发展——Web 技术 HTTP/HTML（Berners-Lee **1991**）、Linux 与开源运动的理论基础、文件系统理论（FFS 软更新、LFS 日志结构）、网络安全的系统化；CS 进步塑造 BSD 技术基础
- 与 BSD 的关联——FreeBSD 作为互联网服务器面临 SSL/PKI 部署需求，BSD 社区需集成 SSL（OpenSSL 前身 SSLeay）；OpenBSD 2.0（**1996**）开始集成 SSH 与 SSL
