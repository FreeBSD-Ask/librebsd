# 85.6 分裂时期的地缘政治语境——冷战结束后全球化加速对 BSD 传播的推动，互联网商业化浪潮（1993-1996 年）对 BSD 社区地理扩张的塑造，USL 诉讼期间 BSD 在美国的法律不确定性对其地理传播的抑制，1994 年和解后 4.4BSD-Lite 发布对 BSD 全球地理扩散的解放性效应

## 85.6.1 冷战结束与全球化

  **要点**：**1991 年** 冷战结束对 BSD 传播的推动——全球化加速使 BSD 代码跨越国界扩散，前苏联与东欧开发者加入 BSD 社区，亚洲（特别是日本）成为 BSD 重要地理区域；冷战结束的地缘政治背景塑造 BSD 全球扩散

**史观**：总纲第 13 条——法律与道德是利益分配〔存疑：对位待主理人审定〕：冷战结束作为地缘政治结构变化，直接塑造 BSD 全球扩散
  
**辨析**：冷战结束对 BSD 的影响兼有全球化与互联网扩散两个归因——1991 年苏联解体后前苏联与东欧开发者通过 Internet 接入 BSD 社区（如俄罗斯 FreeBSD 用户组 1990 年代中期建立），但 Internet 扩散本身亦受冷战结束推动（NSFNET 1991 年解除商业限制）；两个归因相互交织而非独立，BSD 全球扩散是地缘政治变化与互联网基础设施扩张的复合结果 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］

## 85.6.2 互联网商业化浪潮

  **要点**：**1993-1996 年** 互联网商业化浪潮对 BSD 社区地理扩张的塑造——NSFNET **1995 年** 商业化、Web 兴起、ISP 普及使 BSD 代码通过互联网全球扩散；BSD 在 Web 服务器（Apache 早期基于 FreeBSD）、ISP 基础设施中的广泛应用反映互联网商业化的塑造
  
**史料**：NSFNET 商业化档案；Apache 早期平台统计；ISP 基础设施 BSD 使用记录［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档与公告〕
  
**史观**：总纲第 15 条——文化即形式主义〔存疑：对位待主理人审定〕：互联网商业化通过商业需求推动 BSD 全球扩散，但亦带来商业-社区张力，Walnut Creek CDROM 等商业实体在 BSD 社区中产生隐形中心化（商业发行渠道的权威）；“假开源” 等不自反的形式主义化社区姿态须警惕，BSD 商业化与社区理想之间的张力须自反地审视而非简单二元对立
  
**辨析**：互联网商业化的影响兼有技术优势与时机两个归因——FreeBSD 在 Web 服务器市场（Apache 早期版本 1995 年起在 FreeBSD 上广泛部署）与 ISP 基础设施中的优势源于 4.4BSD TCP/IP 协议栈的成熟度（技术优势），但 BSD 阵营恰逢 1993-1995 年互联网商业化浪潮（NSFNET 1995 年商业化、Web 兴起）亦是关键时机；技术优势与时机不可单独归因 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］

## 85.6.3 法律不确定性对地理的抑制

  **要点**：USL 诉讼期间（**1992-1994**）BSD 在美国的法律不确定性对地理传播的抑制——美国商业用户与开发者因规避风险转向 Linux 或其他系统，BSD 在美国的扩散受限；但 BSD 通过欧洲与亚洲的扩散部分弥补美国市场的损失
  
**史料**：USL v. BSDi 诉讼档案；美国 BSD 商业用户转向记录；欧洲与亚洲 BSD 扩散档案［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档与公告〕
  
**史观**：总纲第 13 条——法律与道德是利益分配〔存疑：对位待主理人审定〕：法律不确定性作为法律结构直接抑制 BSD 地理扩散
  
**辨析**：法律不确定性对美国市场的影响在 1992-1994 年诉讼期间确实存在——部分美国商业用户与开发者转向 Linux 规避风险（如某些 ISP 在 1993-1994 年选择 Linux 而非 FreeBSD 作为服务器平台），但 BSD 通过欧洲与亚洲（特别是日本）的扩散部分弥补美国市场的损失；美国市场受限的具体程度缺乏精确统计，1992-1994 年 BSD 与 Linux 市场份额对比数据不存在 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］

## 85.6.4 4.4BSD-Lite 的解放性效应

  **要点**：**1994 年** 和解后 4.4BSD-Lite 发布对 BSD 全球地理扩散的解放性影响——法律洁净使 BSD 代码可自由全球分发，欧洲、亚洲、南美的 BSD 社区快速扩张；4.4BSD-Lite 成为 FreeBSD 2.0 与 NetBSD 1.0 的法律基础，推动 BSD 全球扩散
  
**史料**：4.4BSD-Lite Release Notes **1994.6**；FreeBSD 2.0 与 NetBSD 1.0 全球扩散档案；欧洲与亚洲 BSD 社区扩张记录［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档与公告〕
  
**史观**：总纲第 13 条——法律与道德是利益分配〔存疑：对位待主理人审定〕：4.4BSD-Lite 的法律洁净作为法律结构变化，解放 BSD 全球扩散
  
**辨析**：4.4BSD-Lite 的解放性影响在 **1994.6** 发布后立即显现——FreeBSD 2.0（**1994.11.22**）与 NetBSD 1.0（**1994.10.26**）均于 4.4BSD-Lite 发布后 5 个月内完成重建并发布，证明法律洁净解除了 BSD 阵营的开发束缚；欧洲与亚洲 BSD 社区在 1994-1996 年快速扩张（如日本 BSD 用户会活动记录、欧洲 BSD Verein 成立），但全球扩散的具体速度与规模缺乏精确统计 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］

分时思想出现于 1950 年代末：1959 年 Strachey 与 McCarthy 各自提出 time-sharing。1961 年 11 月，Fernando Corbató 与 Robert Daley 等在 MIT 建成并演示 Compatible Time-Sharing System（CTSS），成为首个可运行的分时系统，1963 年发展为稳定大规模系统；其后 CTSS 在 ARPA 支持下演进为 Project MAC（1963 年上线）。1965 年 CMOS 分时设计更上层楼，MIT Project MAC、贝尔电话实验室与通用电气联合启动 Multics（由 Corbató 领导），引入分页、分段存储与树状文件系统；贝尔实验室 1969 年退出，1970 年 GE 计算机业务转售 Honeywell 将其商业化，1985 年被取消。1990 年 Corbató 因在 CTSS 与 Multics 上的开创性工作获 ACM 图灵奖。
