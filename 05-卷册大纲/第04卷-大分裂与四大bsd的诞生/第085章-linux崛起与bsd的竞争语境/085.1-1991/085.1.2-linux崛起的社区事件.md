# 085.1.2 Linux 崛起的社区事件

  **要点**：Linux 崛起的社区事件包括 comp.os.linux 创建（**1992 年初**〔1991 年末为倡议与投票期，创建年暂存疑待 Google Groups 存档核验〕）、Linux Journal 创刊（**1994**）、Linux 商业发行版出现（**1994-1995**）等——社区事件推动 Linux 用户基数与商业资源汇聚。Linux 崛起关键社区事件时间线如下：

| 事件 | 时间 | 影响 |
| -- | -- | -- |
| comp.os.linux 创建 | **1992 年初**〔存疑：1991 年末为倡议投票期〕 | Linux 早期用户交流平台 |
| SLS 发行版 | **1992** | 首个 Linux 商业发行版 |
| Yggdrasil 发行版 | **1992** | 早期商业发行版 |
| Linux Journal 创刊 | **1994** | Linux 媒体曝光渠道 |
| RedHat 发行版 | **1994** | 后续商业模式奠基 |
| Caldera 公司创立 | **1994-10**（首个发行版 CND 1995 发布） | 商业化载体 |

**史料**：comp.os.linux Usenet 存档、Linux Journal 历年文章、Linux 商业发行版发布声明 ［A］

**史观**：总纲第 15 条——文化即形式主义（原“社区文化即技术资产”系伪名目，按文化论旨改挂，存疑）：社区事件是 Linux 崛起的文化资产

**辨析**：社区事件的具体影响经 comp.os.linux Usenet 存档、Linux Journal 历年文章与 Linux 商业发行版发布声明对照核实——comp.os.linux 1991 年创建为 Linux 早期用户提供交流平台，Linux Journal 1994 年创刊为 Linux 媒体曝光提供渠道，Linux 商业发行版（SLS 1992、Yggdrasil 1992、RedHat 1994、Caldera 公司 1994-10 创立、CND 1995 发布）先后为 Linux 商业化提供载体

**文献**：comp.os.linux Usenet 存档；Linux Journal 历年文章 ［A］
