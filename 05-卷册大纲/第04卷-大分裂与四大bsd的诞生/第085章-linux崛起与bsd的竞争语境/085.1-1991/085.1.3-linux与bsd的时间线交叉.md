# 085.1.3 Linux 与 BSD 的时间线交叉

  **要点**：Linux 与 BSD 时间线交叉——**1991 年** Linux 0.01 与 386BSD 同期发布，**1993 年** Linux 1.0 与 FreeBSD 1.0/NetBSD 0.8 同期，**1994-1995 年** USL 诉讼期间 Linux 趁机扩张；交叉时点决定后续竞争力格局。1991-1996 年 Linux 与 BSD 时间线交叉节点对照如下：

| 年份 | Linux 节点 | BSD 节点 | 交叉意义 |
| -- | -------- | ------ | ------ |
| **1991** | Linux 0.01（**1991.9**） | 386BSD 0.0（**1992.2**） | Linux 早约 5 个月 |
| **1993** | Linux 0.99 系列迭代 | FreeBSD 1.0（**1993.11.1**）、NetBSD 0.8（**1993.4**） | BSD 在 USL 诉讼期间仍发布 |
| **1994** | Linux 1.0（**1994.3**） | 4.4BSD-Lite（**1994.6**）、FreeBSD 2.0（**1994.11.22**） | Linux 早于 FreeBSD 2.0 约 8 个月 |
| **1995** | Linux 1.2 系列扩张 | OpenBSD 创建（**1995.10.18**） | OpenBSD 起步阶段规模远小于前两者 |
| **1996** | Linux 2.0（**1996.6**） | 三足鼎立格局正式形成 | Linux 正值 BSD 完成 4.4BSD-Lite 迁移后约 2 年 |

**史料**：Linux 与 BSD 项目发布历史、USL v. BSDi 诉讼时间线、Salus “A Quarter Century of UNIX” (1994)；netbsd.duckdb 数据库证据（2026-07-21 复核）：FreeBSD 1.0 release tag `release/1.0.0_cvs` 标注 1993-11-01（commit_hash `8503f4f13f77abf7adc8f7e329c6f9c1d52b6a20`，tagger svn2git 迁移工具），与大纲记载 FreeBSD 1.0（1993.11）一致，早于 Linux 1.0（1994.3）约 4 个月；FreeBSD src 首条 commit 1993-06-12T14:49:13Z（Rodney W. Grimes（罗德尼·W·格赖姆斯）, “Initial import, 0.1 + pk 0.2.4-B1”, commit_hash `9002c02abc587664acb357c6879d8ca08664dd0b`），NetBSD src 首条 commit 1992-07-13T16:18:24Z（srcmastr, “initial empty check-in”, 仅为仓库初始化，实际 386BSD 0.1 源码导入为 cgd 1993-03-21T09:45:37Z）；FreeBSD 1993 年 868 个 commit、1994 年 4,217 个 commit，NetBSD 1993 年 14,507 个 commit、1994 年 17,726 个 commit，反映 BSD 阵营在 USL 诉讼期间（1992-1994）仍保持高强度开发 ［A］；〔存疑：L1.1.2 跨仓份额查询原挂 netbsd.duckdb 系错挂（该库仅 netbsd 两仓），数据本体系分库汇总口径，实际来源库名待归口〕 显示：1993 年 4 大 BSD src 仓库 commit 量相对比例为 netbsd-src = 14,507 commits（94.35%）、freebsd-src = 868 commits（5.65%），openbsd-src 尚未 fork（1995.10 才创建）；1994 年比例为 netbsd-src = 17,726 commits（80.78%）、freebsd-src = 4,217 commits（19.22%），FreeBSD 份额增长约 3.4 倍；1995 年比例为 netbsd-src = 12,163 commits（58.88%）、freebsd-src = 7,723 commits（37.39%）、openbsd-src = 770 commits（3.73%），三足鼎立格局初步显现；1996 年比例为 netbsd-src = 16,057 commits（54.91%）、freebsd-src = 7,948 commits（27.18%）、openbsd-src = 5,240 commits（17.92%），OpenBSD 份额增长约 4.8 倍，三足鼎立格局正式形成

**史观**：总纲第 5 条——没有必然性，只有偶然性（原“偶然性改写历史”挂第 9 条系条号名目错配，按权威表改挂第 5 条）：时间线交叉的偶然节点决定 BSD 阵营竞争力格局

**辨析**：交叉时点的具体影响经 Linux 与 BSD 项目发布历史、USL v. BSDi 诉讼时间线与 Salus《A Quarter Century of UNIX》(1994) 多方原始文档核实；netbsd.duckdb 中 FreeBSD 1.0.0 release tag 由 svn2git 迁移工具标注（1993-11-01），非 Jordan K. Hubbard（乔丹·哈伯德） 本人标注（与 FreeBSD 2.0 tag 由 Jordan K. Hubbard 本人标注不同），可能存在 SVN-to-Git 迁移过程中的日期偏差，经 FreeBSD 1.0 Release Announcement（1993.11.1 FTP / 1993.12 CD-ROM）交叉验证后采信 1993.11.1 为 FTP 发布日期；【0 信任原则·commit 量不等于质量】L1.1.2 的 BSD src 比例反映开发活跃度分布但不等于项目质量，1993-1994 年 NetBSD commit 占比超 80% 反映 NetBSD 早期开发活跃但不应直接等同于 NetBSD 质量或市场份额高于 FreeBSD；【0 信任原则·CVS-to-Git 迁移风险】netbsd-src 与 openbsd-src 均为 CVS 主仓的 GitHub 镜像，CVS-to-Git 转换可能重写 author 字段或 commit_date，1993-1996 年 commit 量比例须与各项目官方档案交叉验证；【0 信任原则·GitHub 镜像滞后】netbsd-src 与 openbsd-src 的 GitHub 镜像可能滞后于 CVS 主仓，1993-1996 年 commit 量比例的精度须以官方档案为准
