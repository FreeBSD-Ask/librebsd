# 第 74 章 openbsd的邮件列表与社区文化

## 要点

- OpenBSD 反向工程引发伦理争议——部分观点视为合法逆向，部分视为侵犯知识产权；de Raadt 长期批评闭源固件，主张源码必须开放；争议反映开源社区对闭源固件的不同立场
- OpenBSD 邮件列表与 Linux 内核邮件列表（LKML）在言辞文化上存在对照——两者均以 “言辞激烈” 著称，但 OpenBSD 更强调精英主义，LKML 更强调技术辩论；对照反映两个项目的社区文化差异
- OpenBSD hackathon 长期运行形成 “元老网络”——多次参与 hackathon 的核心开发者形成非正式决策圈，影响项目长期方向；元老网络是 OpenBSD 治理结构的非正式层面
- OpenBSD Foundation 董事会与 de Raadt 核心圈子存在人员重叠——部分核心开发者同时担任董事会成员；重叠既是协调优势也是治理隐患
- OpenBSD 基金会（2007 年成立）在 2007-2014 年间未公开财务报告，2014 年 Theo de Raadt（西奥·德·若特） 澄清后改善。2014 年电费断供暴露了小型开源项目财务管理的系统脆弱性。
