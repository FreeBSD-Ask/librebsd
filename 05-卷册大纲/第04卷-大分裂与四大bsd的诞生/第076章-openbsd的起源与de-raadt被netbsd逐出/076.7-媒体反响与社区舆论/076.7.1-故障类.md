# 076.7.1 故障类


> 本子节汇总与本章主题相关的新闻报道与社区舆论，按“故障类 / 冲突类 / 里程碑事件类”三类组织。所有新闻条目遵循 0 信任原则，须与官方史料交叉验证后方可采信。

### 新闻条目 1

- **新闻标题（中英）**：OpenBSD 2.0 Changelog — Changes made between birth and OpenBSD 2.0（OpenBSD 2.0 变更日志 —— 自诞生至 OpenBSD 2.0 的变更）
- **新闻来源**：OpenBSD Project 官方网站 + OpenBSD 项目维护者集体署名 + 持续维护至 2026 年 + **<https://www.openbsd.org/plus20.html>** + 访问日期 2026-07-27
- **新闻摘要**：OpenBSD 2.0 变更日志“Changes made between birth and OpenBSD 2.0”段落记载了 OpenBSD 自 1995-10 源码导入至 1996-10 发布 2.0 期间累计的工程变更，重点条目包括："We have completed security reviews of almost all userland programs and libraries except for the gnu stuff“、”Almost a hundred more security fixes, including /tmp races because of strncpy“、”Another kerberos security fix“、”deal with the SYN bomb problem (denial of service attack)“、”secure multicast tools against possible security problems“、”sendmail gecos hole fixed“、”generic protection against the bind() takeover problem“、”randomized port allocation in bind(), bindresvport(), and rresvport() -- security via unpredictability“、”The most secure rdist support anywhere“、”Numerous more security policy and implementation improvements (OpenBSD defaults to installing in a very secure mode)“、”Protection from the udp spamming and ftp bounce attacks“、”Say goodbye to dump, restore, and mt security holes: They are no longer setuid“。变更日志同时记载工程整合条目：”FreeBSD's adduser(8) command“、”FreeBSD pipe() system call; quite a bit faster“、”FreeBSD malloc() that uses mmap() and is able to free unused memory“、”The FreeBSD ports subsystem was integrated and is usable by you!"。
- **与本章主题的关联说明**：本章叙事须呈现 OpenBSD“安全至上”定位的工程实践证据，OpenBSD 2.0 变更日志是 OpenBSD 项目对自诞生至 2.0 期间工程变更最完整的一手官方史料，明确记载“几乎完成所有用户态程序与库的安全审计（除 GNU 部分）”、“近一百项安全修正”、“SYN bomb 拒绝服务攻击处理”、“bind() 接管问题的通用防护”、“随机化端口分配”等安全工程实践，构成本章“安全至上起源”叙事的工程层证据。变更日志同时记载与 FreeBSD 的工程整合，构成本章衔接第083章“三足鼎立”叙事中 BSD 家族内部技术交流的线索。
- **与官方史料的交叉验证结论**：该页面为 OpenBSD 项目官方史料，所述“完成几乎所有用户态程序与库的安全审计”与 OpenBSD security.html（故障类条目 2）所述“We have been auditing since the summer of 1996”形成工程实践与时间点双重印证。所述“近一百项安全修正”为工程量化证据，可与 openbsd.duckdb openbsd-src 仓库 1995-1996 年 commit 记录交叉验证。

### 新闻条目 2

- **新闻标题（中英）**：OpenBSD Security（OpenBSD 安全）
- **新闻来源**：OpenBSD Project 官方网站 + OpenBSD 项目维护者集体署名 + 持续维护至 2026 年 + **<https://www.openbsd.org/security.html>** + 访问日期 2026-07-27
- **新闻摘要**：OpenBSD 安全页面明确记载：“We have been auditing since the summer of 1996”。页面同时提供 OpenBSD 2.0 起所有版本的 errata 安全公告链接（2.0 至 7.9），并说明 OpenBSD 的安全审计哲学："OpenBSD is widely known for its strict security. The OpenBSD project maintains a number of policies and practices that should result in a very secure system"。页面同时说明漏洞报告流程与 CVE 处理机制。
- **与本章主题的关联说明**：本章叙事须呈现 OpenBSD“安全至上”定位的起源时点，OpenBSD 安全页面明确记载“自 1996 年夏开始审计”，与 OpenBSD FAQ 历史章节所述 1996-07 发布 OpenBSD 1.2、1996-10 发布 OpenBSD 2.0 的时间线衔接，构成本章“安全审计起源时点”叙事的关键时间锚点。
- **与官方史料的交叉验证结论**：该页面为 OpenBSD 项目官方史料，所述“自 1996 年夏开始审计”与 OpenBSD 2.0 变更日志（故障类条目 1）所述“完成几乎所有用户态程序与库的安全审计”形成时序印证——1996 年夏启动审计，至 1996-10 发布 2.0 时已“完成几乎所有用户态程序与库的安全审计”。所述“OpenBSD 2.0 起所有版本的 errata 安全公告链接”为后续章节衔接第224章“OpenBSD 安全文化的奠基”叙事提供线索。
