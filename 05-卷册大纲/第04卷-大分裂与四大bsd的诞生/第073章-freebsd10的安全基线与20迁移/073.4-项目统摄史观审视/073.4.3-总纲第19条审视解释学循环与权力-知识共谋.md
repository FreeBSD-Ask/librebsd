# 073.4.3 总纲第 19 条审视：解释学循环与权力-知识共谋

  **要点**：FreeBSD 从 386BSD patchkit fork 争议是解释学循环的典型呈现——双方叙事都基于各自的前理解。Jolitz 夫妇的前理解是 “386BSD 是我们的创造物，fork 是窃取”；FreeBSD fork 群体的前理解是 “386BSD 已停滞，fork 是自救”。前理解的差异使分歧不可避免——即便双方面对同一组事实（补丁积压、版本停滞、BSD 许可证允许代码继承、commit `9002c02abc587664acb357c6879d8ca08664dd0b` subject “Initial import, 0.1 + pk 0.2.4-B1”），得出的叙事截然不同。权力与知识在历史书写中共谋——FreeBSD Project 作为后续成功的项目，其 “被迫 fork” 叙事通过官方网站、FAQ、Handbook 等渠道持续传播，成为主流版本；Jolitz 夫妇的 “虚构” 反控通过 386BSD.org 与 Salon 专访传播，但因 386BSD 项目本身的边缘化而影响力有限。什么被记录、什么被遗忘本身就是权力行使——FreeBSD 阵营的史料（freebsd-src 仓库 commit 历史、邮件列表、Handbook）被系统性保存与传播，且通过 Walnut Creek CDROM 商业发行渠道获得额外传播力；Jolitz 夫妇的史料（386BSD.org、个人文章、Salon 专访）则散落各处需 archive.org 检索。商业资源的不对等进一步加剧了叙事权力的不对等——FreeBSD Project 通过 Walnut Creek CDROM 获得 CD-ROM 发行渠道（售价 39.95 美元）与开发机器、高速互联网接入，使其叙事得以通过商业渠道持续放大，而 386BSD 缺乏类似商业支撑，Jolitz 夫妇的叙事传播力受限。史家在此须自反——本节审视本身亦建基于史家的前理解，承认自身无法跳出解释学循环，只能呈现循环的结构而非 “客观真相”。项目史观总纲第 2 条 “历史是形式主义化的非存在” 在此具体化——FreeBSD 诞生的 “真历史” 已不可完全重建，本章所写皆是当下主体的重构，与第026章 25.16.3 审视共同呈现 386BSD patchkit fork 争议的完整解释学循环结构
  
**史料**：综合 26.1-26.13 各节史料，重点参照 FreeBSD Project 官方历史文档与 386BSD.org archive.org 快照的叙事差异、freebsd.duckdb freebsd-src 仓库首条 commit ［A］
  
**史观**：解释学循环是历史认识的根本条件；历史是形式主义化的非存在；理论必须自反：本章承认自身的形式主义性质，以自反姿态打开裂缝
  
**辨析**：解释学循环审视不等于 “各方叙事等价”——须区分 “叙事权力不对等”（FreeBSD 叙事传播力远超 Jolitz 夫妇叙事，且商业资源加剧此不对等）与 “叙事真理性”（双方叙事都需多源交叉验证，不能因传播力强弱判定真伪）；权力-知识共谋的揭示本身亦是史家的形式主义化重构，须自反；本节审视不引入新事实，仅呈现史观层面的解释学循环结构；与第 25 章 25.16.3 审视的呼应——两章审视共同呈现 fork 争议的完整解释学循环，避免单章偏颇。考据过程留痕——【查证来源】项目史观总纲第 19 条原文 “解释学循环是历史认识的根本条件。前理解的差异使分歧不可避免。权力与知识在历史书写中共谋——什么被记录、什么被遗忘，本身就是权力行使” 经 据原文第 25 章 第 23 行 Read 一手核验；项目史观总纲第 2 条原文 “历史是形式主义化的非存在。本书所写皆是当下主体的重构，从不宣称呈现历史本身。人类文明历史发展就是形式主义发展史” 经第 6 行 Read 一手核验；项目史观总纲第 7 条原文 “理论必须自反。本书承认自身的形式主义性质，以自反姿态打开裂缝。理论字数越多越不值钱” 经第 11 行 Read 一手核验；freebsd.duckdb freebsd-src 仓库首条 commit（commit_hash `9002c02abc587664acb357c6879d8ca08664dd0b`，author = Rodney W.
