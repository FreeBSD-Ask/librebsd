- **新闻摘要**：Rachel Chalmers 在 Salon 长篇专访中记载 386BSD 与 Linux 的关系："Not many Linux-come-latelies know this, but Linux was actually the second open-source Unix-based operating system for personal computers to be distributed over the Internet.
