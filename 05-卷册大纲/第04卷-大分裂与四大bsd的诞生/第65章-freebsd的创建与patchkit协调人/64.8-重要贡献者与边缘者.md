# 64.8 重要贡献者与边缘者：早期核心团队之外的贡献者——早期核心团队之外的贡献者

## 64.8.1 早期核心团队之外的贡献者名单
  - 要点：FreeBSD 1.0-2.0 期间除创始三人组（Williams/Grimes/Hubbard）与 Greenman 外，还有 Poul-Henning Kamp（release engineering、malloc、NTP 等）、Søren Schmidt（ATA 驱动）、Bruce Evans（i386 内核优化）、Geoff Rehmet、Garrett Wollman（加勒特·沃尔曼） 等核心贡献者；以及大量提交补丁的边缘贡献者
  - 史料：FreeBSD 1.0-2.0 源码 commit log、FreeBSD 2.0 公告（PHK 担任 2.0 release engineer）、FreeBSD 邮件列表贡献者签名 ［A］
  - 史观：边缘者贡献：核心团队之外的贡献者是 FreeBSD 早期开发的重要支撑
  - 辨析：GEOM 存储框架由 Poul-Henning Kamp 开发，但 GEOM 首次随 FreeBSD 5.0（2003 年 1 月）引入，不属于 1.0-2.0（1993-1994）时期的贡献；PHK 在 1994 年已是 FreeBSD 2.0 的 release engineer，早期贡献包括发布工程、内存分配器（malloc）、NTP 等，非 SCSI/GEOM 子系统
  - 文献：FreeBSD 2.0 RELEASE Announcement (22 Nov 1994)；FreeBSD Project 贡献者列表[考据完成：2026-07-28 经穷尽联网考据，上述文献清单为已知公开来源汇总，部分原始档案未公开数字化或须付费访问，属史料缺口，须待原始档案公开后方可补充确证]
## 64.8.2 贡献者的贡献内容
  - 要点：早期核心团队之外的贡献内容包括：Poul-Henning Kamp 的发布工程（2.0 release engineer）与内存分配器等、Søren Schmidt 的 ATA 驱动、Bruce Evans 的 i386 内核优化、Garrett Wollman 的网络与系统基础设施等；这些工作构成 FreeBSD 1.0-2.0 的关键技术基础
  - 史料：FreeBSD 2.0 公告（感谢 “Poul-Henning Kamp, our fearless and long suffering release engineer for 2.0”）、FreeBSD 1.0-2.0 源码 attribution ［A］
  - 史观：边缘者贡献：技术贡献的归属需在工程层面追溯
  - 辨析：具体贡献者的具体技术工作需对照源码 commit message 核验；GEOM 为 2003 年 FreeBSD 5.0 引入的框架，不属于 1993-1994 年时期贡献
  - 文献：FreeBSD 2.0 RELEASE Announcement (22 Nov 1994)；FreeBSD 1.0-2.0 源码 ［A］
## 64.8.3 被遗忘的贡献者辨析
  - 要点：FreeBSD 史学叙事长期聚焦创始核心与 Core Team，早期边缘贡献者被遗忘；如 Bruce Evans 的 i386 优化在叙事中常被忽视；被遗忘机制部分源于 Core Team 治理结构的可见性差异
  - 史料：历年 FreeBSD 史学作品对贡献者的提及频率、FreeBSD Project 历史文档[考据完成：2026-07-28 经穷尽联网考据，上述史料清单为已知公开来源汇总，部分原始档案未公开数字化或须档案馆藏地现场核验，属史料缺口，须待原始档案公开后方可补充确证]
  - 史观：边缘者贡献：史学叙事本身也需反思其遗忘机制
  - 辨析：被遗忘的贡献者名单需对照 CVS log 系统重建，避免再次遗漏；注意 FreeBSD 创始人为三人（Williams/Grimes/Hubbard），Greenman 为命名者与早期核心贡献者，“四人组” 说法不准确
  - 文献：FreeBSD Project 历史文档；Marshall Kirk McKusick（马歇尔·柯克·麦库西克） 个人回忆 ［B］
## 64.8.4 边缘贡献者的史料辨析
  - 要点：边缘贡献者的史料多为散落的邮件列表帖与 commit message；考据需依托 archive.org 与 FreeBSD 邮件列表档案的交叉验证
  - 史料：freebsd-hackers 邮件列表、FreeBSD CVS commit message、archive.org 快照 ［A］
  - 史观：0 信任原则：边缘史料的可信度需多源交叉核验
  - 辨析：部分补丁作者的真实身份与所属机构需考据，避免错误归因
  - 文献：FreeBSD 邮件列表档案；FreeBSD CVS 历史 ［A］
