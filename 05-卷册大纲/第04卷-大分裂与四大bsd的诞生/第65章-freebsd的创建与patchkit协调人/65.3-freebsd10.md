# 65.3 FreeBSD 1.0

## 65.3.1 FreeBSD 1.0 的开发

**要点**：1993.6-11 期间创始团队与早期贡献者集中开发 FreeBSD 1.0；以 4.3BSD Net/2 为基础合并社区补丁、修复内核 bug、完善用户空间工具；Jordan Hubbard 联系 Walnut Creek CDROM 同步准备光盘发行
  
**史料**：FreeBSD 1.0 源码树、FreeBSD Handbook 官方历史、Walnut Creek CDROM 合作档案；freebsd.duckdb 查询 L1.1.1 显示：1993 年 freebsd-src = 868 commits（占当年 4 大 BSD src 仓库总量 15,375 的 5.65%），反映 FreeBSD 1.0 开发期（1993.6-11）的 commit 活跃度；freebsd.duckdb 查询 L1.2.1 显示：1993 年 4 大 BSD src 仓库新增贡献者 72 人（1992 年仅 3 人），反映 fork 后社区扩张效应 ［A］
  
**史观**：软件工程：FreeBSD 1.0 开发是 BSD 工程传统的延续与工程化
  
**辨析**：FreeBSD Handbook 明确记载 “Jordan contacted Walnut Creek CDROM”——是 Jordan Hubbard 而非 David Greenman（大卫·格林曼） 联系了 Walnut Creek CDROM；【0 信任原则·commit 量不等于质量】commit 量仅反映开发活跃度，FreeBSD 1.0 开发期（1993.6-11）的 868 commits 须结合 commit 规模（additions/deletions）与 message 质量综合判断；【0 信任原则·SVN-to-Git 迁移风险】FreeBSD 2020 年 SVN-to-Git 迁移可能引入 commit_date 偏差，1993 年 commit 时间戳须与邮件列表公告交叉验证；【0 信任原则·GitHub 镜像滞后】L1.2.1 新贡献者数指 4 大 BSD src 仓库合计新增（含 NetBSD/OpenBSD/DragonFly），需结合 freebsd-src 仓库自身新增数据交叉验证
  
**文献**：FreeBSD Handbook “A Brief History of FreeBSD”；FreeBSD 1.0 RELEASE Announcement (1993.11.1)；本项目。**bsd_commits.duckdb** 数据分析报告：宏观趋势统计 [R/OL]. 2026. ［B］

## 65.3.2 FreeBSD 1.0 的发布

**要点**：1993.11.1 Jordan Hubbard 在 comp.os.386bsd.announce 发布 FreeBSD 1.0-RELEASE FTP 公告（FTP 站点 freebsd.cdrom.com），1993.12 Walnut Creek CDROM 发行 CD-ROM 版本
  
**史料**：FreeBSD 1.0 原始公告（Date: 1 Nov 1993 16:12:20 -0800, Newsgroups: comp.os.386bsd.announce）、Walnut Creek CDROM 销售记录 ［A］
  
**史观**：信息技术：FTP + CD-ROM 双渠道发布是 1990 年代初开源项目的典型模式
  
**辨析**：FreeBSD Handbook 记载 1.0 发布于 “December of 1993”（指 CD-ROM 广泛分发），原始 FTP 公告日期为 1993 年 11 月 1 日；公告发布于 comp.os.386bsd.announce，comp.unix.bsd.freebsd 新闻组当时尚未创建
  
**文献**：FreeBSD 1.0 RELEASE Announcement (1 Nov 1993)；FreeBSD Handbook “A Brief History of FreeBSD” ［B］

## 65.3.3 FreeBSD 1.0 的技术特性

**要点**：FreeBSD 1.0 基于 4.3BSD Net/2 + 386BSD 组件 + FSF 组件，支持 386/486 处理器、ISA 总线、SCSI/IDE 磁盘；引入 GCC、XFree86、TCP/IP 网络栈；Ports 软件包管理系统在 1.0 中是否存在 [考据完成：2026-08-17 FreeBSD 1.0（1993.11）不含 Ports；pkg_install 工具 1993-08-26 已提交，Ports 框架由 Jordan Hubbard 于 1994-08-21 首次提交]，由后续版本引入
  
**史料**：FreeBSD 1.0 原始公告、FreeBSD 1.0 Release Notes、FreeBSD Handbook 官方历史 ［A］
  
**史观**：硬件与软件辩证：FreeBSD 1.0 的硬件支持范围决定了其早期用户群
  
**辨析**：原始公告提及的特性包括动态缓冲区缓存、Linux 声音驱动（Gravis UltraSound/SoundBlaster）、Mitsumi CDROM 接口、更新的安装软盘、更安全的 ISA 设备探测、syscons 对 XFree86 2.0 的高级支持；~~原 “4.3BSD-Reno” 说法错误~~（Handbook 明确为 Net/2）；FreeBSD 1.0 不含 Ports，Ports 框架由 Jordan Hubbard 于 1994-08-21 首次提交，属后续版本引入（考据完成：2026-08-17）
  
**文献**：FreeBSD 1.0 RELEASE Announcement (1 Nov 1993)；FreeBSD Handbook “A Brief History of FreeBSD” ［B］

## 65.3.4 FreeBSD 1.0 的反响

**要点**：FreeBSD 1.0 发布后在 comp.os.386bsd Usenet 社区获得积极反响，被视为 386BSD 的 “活跃继承者”；Walnut Creek CDROM 光盘发行确认 FreeBSD 商业可行性
**史料**：comp.os.386bsd.announce 1993.11 Usenet 反馈、FreeBSD 1.0 公告中对 Walnut Creek CDROM 的致谢（“continuing (and, up to now, profitless) support”）［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L2 即时通讯/L3 官方文档〕
  
**史观**：企业研究双重性：Walnut Creek CDROM 的商业支持是 FreeBSD 早期成功的关键
  
**辨析**：用户反响的具体规模需对照 Usenet 帖量与 CD-ROM 销量核验；公告明确感谢 Walnut Creek CDROM 当时 “尚无盈利” 的支持
