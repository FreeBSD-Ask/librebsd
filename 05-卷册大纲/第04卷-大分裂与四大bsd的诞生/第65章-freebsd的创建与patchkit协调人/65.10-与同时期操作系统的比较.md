- 26.5.3 开发资源的提供
  **要点**：Walnut Creek CDROM 为 FreeBSD 提供的互联网接入在 1993-1995 年是稀缺资源（多数开发者仅能通过拨号或校园网访问互联网）；开发机器用于 FTP 镜像（freebsd.cdrom.com）、CVS 仓库、邮件列表托管
  
**史料**：freebsd-hackers 邮件列表 1994-1995 年关于资源使用的讨论、FreeBSD 1.0 公告中 FTP 站点 freebsd.cdrom.com ［A］
  
**史观**：总纲第 20 条历史地理塑造思想土壤——物理带宽与服务器资源的获取是 1990 年代初开源项目生存的关键
  
**辨析**：Walnut Creek 提供的服务器具体规格与带宽速率需对照 1994 年邮件列表核验；FreeBSD 1.0 公告中 FTP 站点为 freebsd.cdrom.com，证实 Walnut Creek 从一开始就托管 FTP 分发
  
**文献**：FreeBSD 1.0/2.0 RELEASE Announcement；FreeBSD Handbook “A Brief History of FreeBSD” ［B］

- 65.10.1 Slackware 1.0 的比较
  **要点**：**Slackware 1.0**（**1993.7**）由 Patrick Volkerding 创建，是早期最流行的 Linux 发行版；与 **FreeBSD 1.0** 同期发布但定位不同——Slackware 跟随 Linux 内核，FreeBSD 跟随 BSD 内核；Slackware 软件包管理简单（pkgtools），而 FreeBSD 1993 年时尚无 Ports 体系——当年 8 月仅有 package install Makefile 雏形，现代 port make macros 框架至 1994 年 8 月 21 日方建立（考据据 Slackware 官方公告存档 ref2519，即 Volkerding 1993-07-16 原始公告 **slackware.com/announce/1.0.php**；原引 Wikipedia 系禁引来源，仅作考据留痕，正文已改引官方主源）
  
**史料**：Slackware 1.0 release notes、comp.os.linux.announce 1993 帖、Patrick Volkerding 个人回忆  
**史观**：总纲第 4 条分离聚合是永恒规律——Linux 与 BSD 在 1993 年的同期分化
  
**辨析**：**Slackware 1.0** 的确切发布日期（一般认为是 **1993-07-17**）与 **FreeBSD 1.0**（**1993-11-01**）的时间差约 3.5 个月
  
**文献**：Slackware 1.0 Release Notes (1993.7)；Patrick Volkerding 个人回忆
- 65.10.2 Debian 0.01 的比较
  **要点**：**Debian 0.01**（**1993-09-15**）由 Ian Murdock 创建，定位为 “GNU/Linux 发行版”；与 FreeBSD 1.0 同期但更加强调 GNU 哲学与社区治理；Debian 的 dpkg 软件包管理与 FreeBSD Ports 路径不同
  
**史料**：Debian 0.01 release notes、debian-devel 早期邮件、Ian Murdock 个人回忆  
**史观**：总纲第 21 条革命与改革是历史方法论的分歧——Debian 的 GNU 哲学与 FreeBSD 的 BSD 哲学在 1993 年同期分化
  
**辨析**：**Debian 0.01** 发布于 **1993 年 9 月 15 日**，与 **FreeBSD 1.0**（**1993-11-01**）间隔约 1.5 个月
  
**文献**：Debian Project 历史；Ian Murdock 个人回忆
- 65.10.3 NetBSD 0.8 的比较
  **要点**：**NetBSD 0.8**（**1993.4**）由 Demetriou/de Raadt/Glass/Hannum 创建，定位为 “可移植性至上”；比 **FreeBSD 1.0** 早约 7 个月发布，路线不同——FreeBSD 专注 x86，NetBSD 主张跨平台
  
**史料**：NetBSD 0.8 release notes、NetBSD 创建公告 1993.3、netbsd-users 邮件列表 ［A］
  
**史观**：总纲第 4 条分离聚合是永恒规律——FreeBSD 与 NetBSD 在 1993 年的同期 fork 是 386BSD 分裂的两个分支
  
**辨析**：**NetBSD 0.8** 发布时间已确认为 **1993 年 4 月 20 日**，早于 **FreeBSD 1.0**（**1993 年 11 月**）约 7 个月，与 NetBSD 官方发布记录一致
  
**文献**：NetBSD 0.8 Release Notes (1993.4)；FreeBSD 1.0 Release Notes (1993.11)；NetBSD 官方历史页面
- 65.10.4 386BSD 1.0 的比较
  **要点**：386BSD 1.0（1994）发布时已远落后于 FreeBSD 1.0 与 NetBSD 0.8；386BSD 1.0 延续 Jolitz 夫妇单一维护者模式，社区规模与开发节奏均不及 fork 后的两个项目
  
**史料**：386BSD 1.0 release notes、comp.os.386bsd 1994 年讨论  
**史观**：总纲第 2 条历史是形式主义化的非存在——386BSD 1.0 的滞后是单一维护者组织形式主义化的必然产物
  
**辨析**：386BSD 1.0 与 FreeBSD 1.0 的技术对比需对照源码 diff 独立核验
  
**文献**：386BSD 1.0 Release Notes (1994)；FreeBSD 1.0 Release Notes (1993.11)
