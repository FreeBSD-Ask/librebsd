# 65.1 1993 年初 FreeBSD 创建——Williams/Grimes/Hubbard 三位 patchkit 协调人发起，Greenman 命名

## 64.1.1 创建的历史语境
  - 要点：1993 年初 386BSD patchkit 维护者群体与 Jolitz 夫妇的分歧加剧，patchkit 已积累大量未合并代码；patchkit 最后三位协调人 Nate Williams（内特·威廉姆斯）、Rod Grimes、Jordan Hubbard 决定从 patchkit fork 一个独立项目以绕开 386BSD 维护瓶颈；David Greenman（大卫·格林曼） 为项目命名 "FreeBSD" 并成为早期核心贡献者
  - 史料：FreeBSD Handbook "A Brief History of FreeBSD"（Jordan Hubbard 亲撰）、comp.os.386bsd.announce Usenet 早期帖、FreeBSD 1.0 原始公告（1993.11.1）；freebsd.db 数据库证据——freebsd-src 仓库首条 commit 为 Rodney W.   - 史观：分离与聚合：fork 是分离聚合律的具体呈现，patchkit 群体从 386BSD 分离后聚合为 FreeBSD

## 64.1.2 创始团队的构成与分工
  - 要点：Nate Williams、Rod Grimes、Jordan Hubbard 三位 Unofficial 386BSD Patchkit 最后协调人发起项目；David Greenman 创造了 "FreeBSD" 名称并成为内核核心贡献者；Jordan Hubbard 负责对外协调与发行联络；Rod Grimes 负责系统构建；Nate Williams 负责内核与驱动；David Greenman 负责内核架构；后加入 Poul-Henning Kamp（波尔-亨宁·坎普） 等早期贡献者
  - 史料：FreeBSD Handbook 官方历史（Jordan Hubbard 亲撰）、FreeBSD 1.0 原始公告、FreeBSD 邮件列表早期签名 ［A］
  - 史观：组织结构塑造技术路径：三人创始+Greenman 命名的早期核心模式奠定了 FreeBSD Core Team 治理的早期结构
  - 辨析：FreeBSD Handbook 明确记载创始人为三位 patchkit 协调人（Williams/Grimes/Hubbard），Greenman 为命名者与早期核心贡献者但非初始协调人；具体分工需对照 commit 记录核验
  - 文献：FreeBSD Handbook "A Brief History of FreeBSD"；FreeBSD 1.0 RELEASE Announcement (1993.11.1) ［B］
## 64.1.3 创建的具体时间线
  - 要点：1993 年初项目启动，早期工作名称为 "386BSD 0.5" 或 "386BSD Interim"；**1993-06-19** 被广泛纪念为 FreeBSD 名称确立日（FreeBSD Day）；**1993-11-01** Jordan Hubbard 在 comp.os.386bsd.announce 发布 FreeBSD 1.0-RELEASE FTP 公告；**1993.12** FreeBSD 1.0 CD-ROM 由 Walnut Creek CDROM 发行。FreeBSD 早期时间线如下：

| 事件 | 日期 | 备注 |
| --- | --- | --- |
| 项目启动 | 1993 年初 | 早期工作名 "386BSD 0.5"/"386BSD Interim" |
| 首条 import commit | 1993-06-12 | Rodney W. Grimes，fork 公告前 7 天 |
| Jordan Hubbard 首 commit | 1993-06-18 | 早于 FreeBSD Day 1 天 |
| FreeBSD Day | 1993-06-19 | FreeBSD 名称确立日 |
| FreeBSD 1.0 FTP 公告 | 1993-11-01 | comp.os.386bsd.announce |
| FreeBSD 1.0 CD-ROM | 1993-12 | Walnut Creek CDROM 发行 |

- 史料：FreeBSD 1.0 原始公告（Date: 1 Nov 1993 16:12:20 -0800）、FreeBSD Handbook 官方历史、Walnut Creek CDROM 合作记录；bsd_commits.db 查询 L1.1.1 显示：netbsd-src 最早 commit 为 1993-06-18（与 Jordan Hubbard 首 commit 同日），netbsd-src 总 commit 数 773,683（统计结论 C-04，SQL 查询 `SELECT COUNT(*) FROM commits WHERE repo_name='netbsd-src'`），反映 1993 年 6 月是 BSD 阵营 fork 的高峰月——FreeBSD 与 NetBSD 几乎同步启动 commit 历史；bsd_commits.db 推断性统计 C-18 显示：Theo de Raadt（西奥·德·若特） 于 1994-12 离开 NetBSD fork OpenBSD，其前后 6 个月 NetBSD commit 量配对样本 Wilcoxon 符号秩检验结果为 W = 10、p = 0.9165、效应量 r = 0.043，不拒绝 H0（即 Theo fork 对 NetBSD commit 量无统计显著影响），Python 脚本 `scipy.stats.wilcoxon`，反映 1994-12 的 fork 事件在短期 commit 量层面未造成显著冲击；changelog.db 统计结论 C-51 显示：entries 总数 670 条（SQL 查询 `SELECT COUNT(*) FROM entries`），集中于 2026-07-16 至 2026-07-26 共 11 天，反映本项目编纂期的密集变更记录，为 FreeBSD 诞生叙事的史料核查提供可追溯的变更日志支撑
- 史观：偶然性改写历史：fork 时机选择直接决定了 FreeBSD 在 Linux 1.0（1994.3）前的时间窗口；统计结论印证项目史观总纲第 25 章分离聚合是永恒规律——1993 年 6 月 FreeBSD 与 NetBSD 同步启动 commit 历史（C-04 netbsd-src 1993-06-18 最早 commit），1994 年 12 月 Theo fork 进一步分裂（C-18 Wilcoxon 不拒绝 H0 表明 fork 短期影响有限），BSD 阵营在分离-聚合-再分离的辩证运动中形成多极格局；第 2 条实践先于理论——commit 量数据先于史观判断，统计结论为史观提供量化参照而非相反
- 辨析：FreeBSD Handbook 记载 1.0 于 "December of 1993" 发布（指 CD-ROM 广泛分发），而网络公告/FTP 发布日期为 1993 年 11 月 1 日，两种说法均正确但指代不同发布渠道；公告发布于 comp.os.386bsd.announce（comp.unix.bsd.freebsd 新闻组当时尚未创建）；【0 信任原则·统计显著 ≠ 实际显著】C-18 Wilcoxon p = 0.9165 不拒绝 H0 仅表明 Theo fork 前后 6 个月 NetBSD commit 量无统计显著差异，不等于 fork 事件对 NetBSD 社区、技术方向、贡献者士气无实际影响——长期影响（如 OpenBSD 成为安全领域独立分支）超出 Wilcoxon 检验的 6 个月窗口；【0 信任原则·效应量与样本量】C-18 效应量 r = 0.043 为极小效应，配对样本数 N = 6 月份对，统计功效较低，不拒绝 H0 可能存在第二类错误风险；【0 信任原则·多重比较风险】C-04 netbsd-src commit 量与 C-18 Wilcoxon 检验跨章引用时存在多重比较风险，须按 Bonferroni 或 Benjamini-Hochberg 校正后解读；【0 信任原则·CVS-to-Git 迁移风险】netbsd-src 为 CVS 主仓的 GitHub 镜像，CVS-to-Git 转换可能重写 commit_date 字段，1993-06-18 最早 commit 时间戳须与 NetBSD 官方档案交叉验证；【0 信任原则·changelog 时间窗口局限】C-51 changelog.db 670 条集中于 11 天，反映的是本项目编纂期的变更记录而非 1993 年 FreeBSD 诞生当时的变更日志，须严格区分编纂期变更与历史事件本身
- 文献：FreeBSD Handbook "A Brief History of FreeBSD"；FreeBSD 1.0 RELEASE Announcement (1 Nov 1993)；本项目。netbsd.db 数据分析报告：描述性统计与推断性统计 [R/OL]. 2026.（统计结论 C-04 netbsd-src 总 commit 数 773,683，SQL 查询 `SELECT COUNT(*) FROM commits WHERE repo_name='netbsd-src'`；统计结论 C-18 Theo fork NetBSD 1994-12 Wilcoxon W = 10 p = 0.9165 r = 0.043，Python 脚本 `scipy.stats.wilcoxon`）；本项目。changelog.db 数据分析报告：描述性统计 [R/OL]. 2026.（统计结论 C-51 entries 总数 670，SQL 查询 `SELECT COUNT(*) FROM entries`） ［B］
## 64.1.4 创建的工程基础
  - 要点：FreeBSD 1.0 基于 U.C. Berkeley 4.3BSD-Lite（"Net/2"）磁带，同时包含大量 386BSD 组件与自由软件基金会（FSF）提供的组件（GCC 等）；MI/MD 架构延续 BSD 设计；引入 GCC、BSD make、C shell 等用户空间工具
  - 史料：FreeBSD Handbook 官方历史、FreeBSD 1.0 源码树、FreeBSD 1.0 Release Notes ［A］
  - 史观：软件工程：FreeBSD 1.0 的工程基础是 BSD 工程传统的延续
  - 辨析：FreeBSD Handbook 原文明确记载 1.0 "based on the 4.3BSD-Lite ('Net/2') tape from U.C. Berkeley, with many components also provided by 386BSD and the Free Software Foundation"；~~原 "4.3BSD-Reno" 说法错误~~，Net/2 与 4.3BSD-Reno 是 CSRG 不同的发布物
  - 文献：FreeBSD Handbook "A Brief History of FreeBSD"；FreeBSD 1.0 源码树 ［A］
