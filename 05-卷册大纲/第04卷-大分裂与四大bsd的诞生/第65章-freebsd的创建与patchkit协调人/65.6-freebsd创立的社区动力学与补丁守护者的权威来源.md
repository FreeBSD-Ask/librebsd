# 65.6 FreeBSD 创立的社区动力学——补丁守护者的权威来源

## 65.6.1 patchkit 协调人的合法性与权力基础

**要点**：Jordan Hubbard、Rod Grimes、David Greenman（大卫·格林曼） 等的权力基础来自技术贡献积累而非正式选举——他们维护的 386BSD patchkit 被社区广泛采用，构成事实上的‘官方’补丁集。

**史料**：FreeBSD 早期邮件列表（1993）; Hubbard 等访谈 ［A］

**史观**：第 10 条动手者创造历史（存疑）——非正式权力结构的形成。

**辨析**：社区分裂的叙事需要区分“建设性分叉”和“破坏性分裂”——前者是开源生态的正常现象（如 OpenBSD 从 NetBSD 分叉后独立发展），后者是社区治理失败的结果。分裂事件的历史记录往往由胜出方书写，分裂方的视角和贡献可能被系统性低估。
**文献**：FreeBSD 邮件存档 ［A］

**要点**：

- Julian Elischer 一手自述其 BSD 起点：1990 年入职 TRW，在基于 VME 总线 68030 的图像处理服务器群上运行 BSD 4.3；公司为降级到 x86 工作站而采用 Mach 系统——即 CMU 将其微内核研究成果嫁接 BSD 4.3 之上、保留原文件系统与网络栈的产物；x86 与 68030 的大小端差异令他迅速领教网络栈中字节序转换函数存在的理由。因 Mach 无 SCSI 支持，他为 Mach 编写了 SCSI 子系统，随后将其移植入 386BSD，该代码成为 FreeBSD SCSI 子系统的基础，后由 Justin Gibbs 等人重写；他声称其残留文件与署名至今仍存于 FreeBSD、NetBSD 与 OpenBSD 之中。（BSDTalk EP165，[508.86-588.84]，L1）
- 386BSD patchkit 时期的协作形态由当事人还原：Bill Jolitz 与 Lynn Jolitz 因家庭危机淡出后，开发者群体自行维护官方补丁集，无版本控制工具，参与者复制源码树制作 diff 汇入补丁集；Julian 在 TRW 金融系统的外部网络上架设服务器，向所有愿意工作的人开放账号。1993 年他返澳期间 Jordan Hubbard 等人分叉出 FreeBSD，他将其定性为组织性争论而非技术争论；NetBSD 更早分叉、性质偏技术，诉求是获得 CVS 树与更好的支持结构。Jolitz 夫妇最终因家庭变故（他提及 Bill 父亲去世等）彻底退出，FreeBSD 从此自立。（BSDTalk EP165，[359.28-477.40]，L1）
- Whistle Communications（1996 至 1999）是其总结的“以 BSD 解决问题、开发成果回流 FreeBSD”模式的典型：小企业一体机被当事人称为盒装 IT 部门，公司被 IBM 收购后产品线遭整体关停，当事人形容为花费约 1.2 亿美元买下再关掉的怪异决策；该时期回流 FreeBSD 的成果包括以合同委托 McKusick 移植的 soft updates、Divert Sockets、NetGraph 子系统与 AppleTalk 栈。对“BSD 许可证纵容企业只取不予”的担忧，他以跨公司经验给出系统性反驳：回馈即由社区维护、代码保鲜，NetGraph 首次提交仅约 12 个模块、如今 50 至 60 个模块大多出自他人之手，回馈即省钱；竞争对手若已自行实现同类功能，将己方代码回馈入主线会抬高对手门槛，拖延三年则可能错失窗口——对手正解决同一问题，谁先回馈谁的定义成为事实标准，故总有理由尽快回馈。（BSDTalk EP165，[884.96-1081.76]，L1）
- TRW 分部管理层强推 COTS（商用现货）路线的教训由当事人痛陈：以改用 Windows NT 与 Sun 服务器、把工程师从百人裁至五十人为诱饵的论证，被其斥为似是而非——采用 COTS 即接受所有公司共有的 COTS 局限，公司从能做出差异化产品的 vendor 沦为 me-too vendor。此前自研系统曾以 15.5K 巨型帧穿过作局部总线用的以太网、专用驱动将包直接写入内存缓冲馈入磁盘、几乎无 CPU 干预，一台 68030 即可打满六七条以太网；自造成本 1.5 万美元售 7 万美元，而改用 Sun 方案后需三倍硬件，24 万美元的 Sun 设备以 18 万美元亏本竞标。管理层的省钱承诺从未兑现。（BSDTalk EP165，[1223.02-1367.42]，L1）

- 该期呈现的一手与准一手史料线索包括：贝尔实验室闲置 DEC PDP-7 的实物史事与 AT&T 专利局购置 PDP-11 换取文字处理程序的设备交易；1978 年 1BSD 发行；进入 4 系列 BSD 的 TCP/IP 实现与被 Windows、NeXT 等采用的伯克利网络栈；Net/1、Net/2 自由分发版本；386BSD 与 BSDi 的 BSD/386 及 1-800-ITS-UNIX 订购渠道；1994 年和解与 4.4BSD-Lite 发布、UNIX 中 BSD 源文件附加伯克利版权声明之安排；Usenet 上的 386BSD 补丁散布与非官方 patchkit；1993 年 FreeBSD 首发与 Walnut Creek CD-ROM 发行渠道。（YouTube EPY0ixYwLd9Pg，[155.8-723.9]，L2）

**史观**：

- 总纲9 经验优先：当事人反复以工程师经验对抗管理层的抽象成本论证：COTS 转型的纸上省钱方案在他看来完全站不住脚，因为真实性能、可维护性与差异化能力只存在于一线动手者的实践 knowledge 之中；TRW 由领先者沦为跟随者的过程，正是管理层以公式化推理覆盖工程经验的后果。技术决策的正当性来自动手者的经验，而非报表上的论证。（BSDTalk EP165，[1265.06-1292.04]，L1）
- 总纲4 分离聚合是永恒规律：386BSD 补丁社区先后分立为 NetBSD 与 FreeBSD 两支，说明早期 BSD 谱系并非按预定计划展开，而是补丁协调权威周期性缺位下的社群自组织：当唯一的发布者长期消失，社区以分离的方式重新聚合，各自另立门户延续伯克利遗产。（Software Engineering Daily EP1914，[364.0-476.0]，L2）
- 总纲5 没有必然性，只有偶然性：Baldwin 以亲历者视角强调，决定 BSD 与 Linux 竞争格局的转折完全发生在技术领域之外：单个开发者无法控制的商业与法律事件，加上偶然与运气，左右了操作系统的命运；技术史的走向并不由代码优劣必然决定，法律环境的扰动足以重塑整个生态的归属。（Software Engineering Daily EP1914，[548.0-650.0]，L2）
- 总纲4 分离聚合是永恒规律：全片叙事呈现分离与聚合的循环：UNIX 自 Multics 废墟中分离而出，BSD 经 Net/1、Net/2 与 4.4BSD-Lite 逐级剥离 AT&T 代码，FreeBSD 又自 386BSD 分离，NetBSD、OpenBSD 相继分立；与此同时伯克利网络栈被几乎所有现代操作系统吸收，各分支项目延续同一传统，分离之后在各处再聚合，BSD 系统的生命力恰由不断分离而非单一谱系所维系。（YouTube EPY0ixYwLd9Pg，[903.3-908.5]，L2）
- 总纲5 没有必然性，只有偶然性：视频将 UNIX 的诞生归结为具体偶然条件与需求的凑合而非必然进程：管理层终止项目、PDP-7 恰好闲置、专利局恰需文字处理器，诸条件先后相遇方使系统在无人支持的环境中存活并繁荣，结尾以“如凤凰自 Multics 灰烬中重生”作喻，实际上否定了技术演进的必然性叙事。（YouTube EPY0ixYwLd9Pg，[878.1-890.2]，L2）

**辨析**：

- 转写音译误植须按上下文考订：Mark 应为 Mach（微内核嫁接 BSD 4.3 的 CMU 系统，对应 Mach 2.5 形态）、E-Melon 应为 CMU、Scuzzy system 即 SCSI 子系统的诨名、Jollitz 应为 Jolitz、McCusick 应为 McKusick、Freeride 6BSD 与 previous D 等均应为 FreeBSD、VSD 为 BSD；自称“QWERTY member”不可考，按其自述语境仅为“始终在场的老资格长期开发者”。IBM 收购 Whistle 的 1.2 亿美元金额系当事人单方回忆，Vycor 后续买家转写不清，均待外部文献核验。[存疑脚注] 涉及金额、人名拼写与公司归属的细节仅有一手口述孤证。　[存疑脚注] Mach、CMU 为按上下文考订；1.2 亿美元收购金额与 Vycor 买家名无法自转写内证确证，需以新闻报道与公司档案复核。（BSDTalk EP165，[249.52-277.48]，L4）
- Baldwin 将诉讼表述为 AT&T 与 UC Berkeley 之间的冲突，而通行档案记载的诉讼主体是 USL 于 1992 年起诉 BSDi 与伯克利加州大学董事会，1994 年和解；口述回忆与档案记载在诉讼主体与命名上存在出入，引用时应以起诉书与和解协议等一手档案为准。　[考据脚注] 诉讼主体的 AT&T 表述为 Baldwin 事后回忆，需与 41.1 所载 USL 起诉书档案交叉核对（Software Engineering Daily EP1914，[548.0-650.0]，L2）
- 多处表述须回核原始音视频与一手史料：其一，视频称 Multics 始于 1956 年，与通行考据的项目 1964 年启动不符，或系将 GE 与 MIT 更早的分时探索并入叙述；其二，转写在 CSRG 学生为 VAX 重写核心处呈现为今日所称 FreeBSD 诞生，按编年此处应为 3BSD，FreeBSD 之名至 1993 年方出现，属口述或转写之误；其三，视频称另一群体在 FreeBSD 项目开始前基于 386BSD 启动 NetBSD，与通行考据的 NetBSD 于 1993 年基于 Net/2 启动之说存在出入；其四，新转写记音失真处仍在：Terry Lambert 误记为 Terry Land、1-800-ITS-UNIX 误记为 100 H Unix、4.4BSD-Lite 误记为 4.4 BERT-like、FreeBSD 误记为 FreeBSD 或 FBSD 或 FreeBESD，引用相关细节前须交叉核证；旧转写所记 CSRG 解散年份与 FreeBSD 2.0 发布年份之缺失，新转写已分别给出 1995 年解散与 1994 年 11 月发布，Lynne Jolitz 人名亦记音正确，该两项存疑判断随之作废。　[存疑脚注] Multics 1956 年说、CSRG 重写处误称 FreeBSD、NetBSD 起源与启动基础表述，及转写专名与人名记音失真，均须以原始视频与一手史料复核后方可引用（YouTube EPY0ixYwLd9Pg，[104.2-771.5]，L5）〔订正：时间戳重锚至 [104.2-771.5]；原「CSRG 解散年份、FreeBSD 2.0 发布年份等数字缺失」据新转写作废（新转写 548.5-561.7 作 1995 年解散、759.1-764.9 作 1994 年 11 月发布）；原「Lynne Jolitz 记音失真」据新转写作废（462.8-475.0 作 Lynne Jolitz）；改列新转写仍存之失真 Terry Land、100 H Unix、4.4 BERT-like、FreeBSD 与 FreeBESD〕
