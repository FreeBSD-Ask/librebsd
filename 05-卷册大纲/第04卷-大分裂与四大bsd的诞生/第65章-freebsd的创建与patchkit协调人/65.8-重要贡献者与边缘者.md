## 65.8.1 早期核心团队之外的贡献者名单

  **要点**：FreeBSD 1.0-2.0 期间除创始三人组（Williams/Grimes/Hubbard）与 Greenman 外，还有 Poul-Henning Kamp（release engineering、malloc、NTP 等）、Søren Schmidt（ATA 驱动，贡献期主要在 4.x 时代，晚于 1.0-2.0 窗口）、Bruce Evans（i386 内核优化，1991 年起活跃）、Geoff Rehmet、Garrett Wollman（加勒特·沃尔曼）等核心贡献者；以及大量提交补丁的边缘贡献者
  
**史料**：FreeBSD 1.0-2.0 源码 commit log、FreeBSD 2.0 公告（PHK 担任 2.0 release engineer）、FreeBSD 邮件列表贡献者签名 ［A］
  
**史观**：总纲第 10 条——动手者创造历史：核心团队之外的贡献者是 FreeBSD 早期开发的重要支撑，大量提交补丁的边缘贡献者以动手实践共同创造了 FreeBSD 的早期历史
  
**辨析**：GEOM 存储框架由 Poul-Henning Kamp 开发，但 GEOM 首次随 FreeBSD 5.0（2003 年 1 月）引入，不属于 1.0-2.0（1993-1994）时期的贡献；PHK 在 1994 年已是 FreeBSD 2.0 的 release engineer，早期贡献包括发布工程、内存分配器（malloc）、NTP 等，非 SCSI/GEOM 子系统
  
**文献**：FreeBSD 2.0 RELEASE Announcement (22 Nov 1994)；FreeBSD Project 贡献者列表［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］

## 65.8.2 贡献者的贡献内容

  **要点**：早期核心团队之外的贡献内容包括：Poul-Henning Kamp 的发布工程（2.0 release engineer）与内存分配器等、Søren Schmidt 的 ATA 驱动（其 **ata(4)** 驱动首现于 FreeBSD 4.0，属 1.0-2.0 之后的贡献）、Bruce Evans 的 i386 内核优化（Evans 自 1991 年起活跃，386BSD 0.1 即列贡献者，FreeBSD 共同创始人）、Garrett Wollman 的网络与系统基础设施等；这些工作构成 FreeBSD 1.0-2.0 前后的关键技术基础
  
**史料**：FreeBSD 2.0 公告（感谢 “Poul-Henning Kamp, our fearless and long suffering release engineer for 2.0”）、FreeBSD 1.0-2.0 源码 attribution ［A］
  
**史观**：总纲第 10 条——动手者创造历史：技术贡献的归属需在工程层面追溯，历史由动手写代码、修驱动、做发布的贡献者创造，归属考据即是对创造者历史的确认
  
**辨析**：具体贡献者的具体技术工作需对照源码 commit message 核验；GEOM 为 2003 年 FreeBSD 5.0 引入的框架，不属于 1993-1994 年时期贡献；Søren Schmidt 的 ata(4) 驱动经 FreeBSD 官方手册核证首现于 FreeBSD 4.0，其贡献时期为 1.0-2.0 之后而非 1993-1994 年窗口之内
  
**文献**：FreeBSD 2.0 RELEASE Announcement (22 Nov 1994)；FreeBSD 1.0-2.0 源码 ［A］

## 65.8.3 被遗忘的贡献者辨析

  **要点**：FreeBSD 史学叙事长期聚焦创始核心与 Core Team，早期边缘贡献者被遗忘；如 Bruce Evans 的 i386 优化在叙事中常被忽视；被遗忘机制部分源于 Core Team 治理结构的可见性差异
  
**史料**：历年 FreeBSD 史学作品对贡献者的提及频率、FreeBSD Project 历史文档［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档/L5 二手研究〕
  
**史观**：总纲第 10 条——动手者创造历史：史学叙事本身也需反思其遗忘机制，正是边缘贡献者的动手实践构成了 FreeBSD 早期开发的历史本体，叙事对动手者的取舍即是历史书写的权力再分配
  
**辨析**：被遗忘的贡献者名单需对照 CVS log 系统重建，避免再次遗漏；注意 FreeBSD 创始人为三人（Williams/Grimes/Hubbard），Greenman 为命名者与早期核心贡献者，“四人组”说法不准确
  
**文献**：FreeBSD Project 历史文档；Marshall Kirk McKusick（马歇尔·柯克·麦库西克） 个人回忆 ［B］
