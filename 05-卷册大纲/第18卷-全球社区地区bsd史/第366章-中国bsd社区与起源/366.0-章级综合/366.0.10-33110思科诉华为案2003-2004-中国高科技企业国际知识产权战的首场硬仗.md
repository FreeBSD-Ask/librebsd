# 366.0.10 331.10 思科诉华为案（2003-2004）——中国高科技企业国际知识产权战的首场硬仗与开源语境

- 史观：总纲第 13 条——法律与道德是利益分配：思科诉华为是中国高科技企业首次直面美国软件版权诉讼，该案经由法律程序重新划定软件利益的合法边界——其确立的“复制证据链”标准（源码字符串比对、命令行界面/手册逐字比对）对中国企业软件研发的“干净房”（clean-room）合规意识具有启蒙意义；对 BSD 史而言，该案同期（2003）恰逢 SCO v. IBM 诉讼爆发（本卷 294.3），中国网络设备企业与 UNIX/开源代码的合规问题被同时置于国际法律聚光灯下
- 史观：总纲第 5 条——没有必然性，只有偶然性：华为案以和解收场的偶然性——3Com 合资（市场制衡）、独立专家审核（技术中立化）、双方保密和解（声誉保全）三重偶然叠加使案件未走向终局判决；与 USL v. BSDi（1994 和解，本卷 40-42 章）一样，软件版权大案以“保密和解”收场成为常态——和解条款保密使“谁对谁错”的史实认定长期悬置，这正是史学考据必须面对的“被遮蔽史实”（对照本卷 62.11 的 Groklaw 解封先例）
- 史观：总纲第 15 条——文化即形式主义：华为案与自主可控叙事的关系——国际知识产权诉讼压力（思科案）与开源生态参与（Linux 基金会）看似相反，实则共同塑造中国科技政策“以我为主、开放兼容”的叙事框架，自主可控话语本身即一种文化形式主义的建构——BSD 许可证的宽松性（本卷 282 章）使中国 BSD 系部署（麒麟曾基于 FreeBSD）在法律上无复制风险，成为自主可控叙事的可选技术底座
- 辨析：须辨析思科诉华为与 BSD 史的直接关联并避免过度关联——华为并非 BSD 企业（其 VRP 系统基于自研 + 开源组件），该案核心是 IOS 专有代码复制指控，不涉及 BSD 代码；但该案与中国 BSD 社区语境相关：(1) 华为是中国最早深度参与开源（含 BSD 系组件如 OpenBSD 的 pf 等）的企业之一；(2) 该案推动中国企业对“开源代码合规使用”的法律意识（许可证义务、代码溯源）；(3) 2003-2004 年中国软件产业知识产权争议（华为案、中科红旗等）构成中国开源/自主可控叙事（本卷 331.7 麒麟、331.9 信创）的时代背景。同时须以 0 信任原则对待双方叙事——思科 2012 博客披露的专家报告摘录（“Huawei misappropriated this code”“electronically copied”）系思科单方发布，华为对此未回应（丁耘 2012 年表述为“未发现侵权”），专家报告全文保密，第三方无法独立核验，考据结论应表述为“中立方专家报告认定存在代码复制，但全文未公开、双方叙事对立”，而非采信任何单方；该案对 BSD 史的意义是“语境性”的（中国科技法律环境、开源合规意识、自主可控叙事），而非“直接性”的（无 BSD 代码争议），中国 BSD 社区与华为案的关联应表述为“同期法律语境下的制度环境共享”，而非因果 ［A］
