# 343.3 印度尼西亚的 BSD 采用

117.3 **印度尼西亚的 BSD 采用**———印度尼西亚 BSD 采用以雅加达与万隆为中心，印度尼西亚大学（UI）与万隆理工学院（ITB）开设 BSD 相关课程，印度尼西亚 BSD 社区通过在线社区（如 Kaskus、Telegram）组织活动
