# 343.2 马来西亚的 BSD 社区与教育

117.2 **马来西亚的 BSD 社区与教育**———马来西亚 BSD 社区以吉隆坡与槟城为中心，马来西亚多媒体大学（MMU）与马来西亚理科大学（USM）开设 BSD 相关课程，马来西亚 BSD 社区规模较小但持续活跃
