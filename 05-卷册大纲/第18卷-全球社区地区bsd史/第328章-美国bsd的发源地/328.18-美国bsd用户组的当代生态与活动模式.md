# 美国 BSD 用户组的当代生态

## 美国.1 美国活跃 BSD 用户组

**要点**：BABUG（SF 湾）、NYC*BUG、ChicagoBUG、Seattle BUG、Phoenix BUG。COVID 后混合模式，核心议题延伸至 DevOps、云原生、嵌入式 BSD。
**史料**：BSD User Group 列表（bsd.org）; Meetup 数据 ［B］
**史观**：总纲第 15 条——用户组是最基层社会基础设施。
**辨析**：美国 BSD 用户组的数量与活跃度远低于 Linux 用户组（UG 总数约 1:10），反映了 BSD 在北美市场的结构性弱势。但 BSD 用户组的平均技术深度高于 Linux 用户组——BSD 用户组更倾向于讨论内核、网络栈、安全等底层议题，而非桌面应用。COVID-19 后混合模式增加了国际参与者的接入，但也降低了面对面技术交流的深度。用户组数据来源以 Meetup 和官方登记为准，未登记的线下小团体可能被遗漏。
**文献**：bsd.org; Meetup 数据 ［B］

**要点**：

- Brian Callahan 自 2013 年成为 OpenBSD 开发者，在 Rensselaer Polytechnic Institute 任教，并已向 OpenBSD 移植约四五十个编译器与解释器。（BSD Now EP422，[82.26-112.86]，L1）
- 他在信息安全课程中让学生登录其托管的 OpenBSD 机器，讲授 strlcpy、pledge 与 unveil 等机制，并以现代二进制利用课程反向印证这些安全设计的价值。（BSD Now EP422，[1152.74-1504.02]，L1）
- NYC*BUG 是纽约 BSD 用户组，约于 2003 至 2004 年成立，自称最古老的 BSD 用户组之一，疫情后成功转为线上活动。（BSD Now EP422，[2083.8-2321.72]，L1）
- Michael W. Lucas 自述 Absolute FreeBSD 第三版（2018 年）因 FreeBSD 十年间特性大幅增长，删去 sendmail 与 Web 服务器配置等旧内容，新增 GEOM、ZFS、Poudriere、blacklistd 等主题；第二版基于 FreeBSD 7，第三版对应 FreeBSD 11 至 12 前后的变化。（BSD Now EP267，[1212.72-1245.12]，L1）
- Lucas 回忆第一本 Absolute FreeBSD 缘起于 No Starch 出版社 Bill Pollock 的约稿；此前他在 O’Reilly 撰写 BSD 专栏（Big Scary Daemons），将自学 disk label 与 slices 等主题的文章整理成书，属于自学者向技术写作的转化。（BSD Now EP267，[1900.86-1993.50]，L1）
- 访谈提出 BSD 在 1980 年代被宣告死亡后仍由一群狂热者延续；激进的新事物往往由一两人发起，如 Matt Dillon 与 DragonFly、Theo de Raadt 与 OpenBSD、Peter Wemm 将 FreeBSD 从 CVS 迁往 Subversion，并由此获得 AMD64 支持。（BSD Now EP267，[1667.54-1888.12]，L1）
- 2014 年 4 月 Heartbleed 漏洞披露后，OpenBSD 团队导入 OpenSSL 1.0.1g 并启动 fork：彻底禁用引发漏洞的 heartbeat 扩展，删除约五点五万行针对 VMS、Windows 等平台的移植代码与过时 DES 加密支持，并将内核常规格式（KNF）统一应用于整个代码库以改善可维护性；主持人预期约一年内会出现可移植版本，使其 fork 可用于 FreeBSD 等其他系统。（BSD Now EP33，[849.5-1160.12]，L2）
- Heartbleed 的披露过程与产业响应暴露了协同流程的脆弱性：按 oss-security 邮件列表整理的时间线，原定负责任披露、各发行版周三同步就绪，实际却于周一提前混乱曝光；Akamai 曾声称其把私钥隔离在独立内存区的补丁使自身免疫，事后承认补丁无效并为客户重签证书；pfSense 随即发布含修复的 2.1.2 版本；另据报道有情报机构可能自 2011 年起利用该漏洞。　[存疑脚注] NSA 自 2011 年利用 Heartbleed 一说仅为主持人转述的媒体传闻，本期未提供证据，须另行核证（BSD Now EP33，[760.88-849.5]，L2）
- Jim Brown 一手回忆 BSD 认证工作的起源：2005 年 10 月纽约市 BSD 用户组例会后的晚餐讨论注意到 Linux Professional Institute 认证正当流行而 BSD 社区没有对应机制，数人当场发起倡议，随后在新泽西注册为非营利组织；2006 年该组织完成首次全球工作任务分析调查，以一线 BSD 系统管理员日常任务的频率与重要性为依据形成 BSDA 考试目标文档，2008 年在洛杉矶 SCALE 大会举行首次考试，形式为 100 题、90 分钟的选择题，覆盖 DragonFly BSD、FreeBSD、NetBSD 与 OpenBSD 四个服务器领域主流分支。（BSD Now EP33，[1572.6-1836.58]，L1）
- 面向高阶从业者的 BSD Professional 认证自 2009 年起开发，兼顾笔试与实操两种考核：实操环节采用装有定制 PC-BSD 系统的专用 USB 工作站，考生按任务单完成服务搭建后由自动化脚本评分，只考察能否提供目标服务而不限定所用软件；计划于 2014 年 BSDCan 在渥太华开放测试考试，需约一百名考生成绩供心理测量分析划定及格线，正式发布预计不早于 2015 年。（BSD Now EP33，[2145.2-2354.6]，L1）
- 认证组将全球可负担性列为初始目标：BSDA 纸笔考试定价 75 美元，转入商业考试中心后为 150 美元，会议现场仍维持 75 美元；续证按五年周期设计并配教育学分体系；组织期望最终获得 ANSI 17024 人员认证认可，理由是该认可可打开美国政府采购市场并取得国际互认，SANS 等机构已循此路径获得认证。（BSD Now EP33，[2533.84-2809.64]，L1）
- OpenBSD 基金会宣布达成 2014 年 15 万美元的筹款目标，较 2013 年约 3 万美元的规模大幅增长；主持人指出该资金保障了在全球几乎所有系统上使用的 OpenSSH 的持续维护，并认为捐款人数本身是社区活跃度的信号，建议小额分散捐助多个 BSD 项目以同时传递资金与活跃度信号。（BSD Now EP33，[3484.72-3588.68]，L2）
- PC-BSD 10.1 的周报显示其桌面化工程持续推进：修复 PBI 运行时稳定性问题并缩短加载时间，在控制面板中试验可将系统、软件包与安全更新统一处理的 Update Center 作为未来唯一更新机制，并从 Linux 移植了自适应预读守护进程 preload，使其跨重启记住常用应用并预热缓存以加快登录与桌面启动。（BSD Now EP33，[3596.68-3684.36]，L1）
- 受访者在 ShmooCon 2006 演讲中把网络安全监控数据划分为告警、统计、会话与全内容四类，主张以 Bamm Visscher 主导开发的开源接口 Sguil 整合四类数据；他批评当时流行的 Snort 告警界面 ACID 与 BASE 无法满足严肃入侵检测需求，同台者 David Bianco 又演示了不依赖任何签名、仅凭会话数据发现 Windows WMF 漏洞利用活动的检测路径。（BSDTalk EP13，[528.07-656.97]，L1）
- 受访者回忆其 FreeBSD 使用史：1999 年获赠 FreeBSD 3.2 安装光盘，2000 年前后在得克萨斯州圣安东尼奥的空军计算机应急响应组任上尉期间，因同僚看重 FreeBSD 网络栈的稳固而促成部队以此构建传感器；2001 年初退役进入托管安全服务行业后，所在公司选定 FreeBSD 4.2 作为传感器平台，此后他创办 Tao Security，所有自建传感器仍全部基于 FreeBSD。（BSDTalk EP13，[1208.39-1310.62]，L1）
- 截至 2006 年初，美国国防部已规定 2008 年起骨干网强制采用 IPv6；受访者以审读 O’Reilly《IPv6 Network Administration》与 Apress《Running IPv6》两本专著并在 FreeBSD 上动手实验为基础，判断 128 位源与目的地址使抓包分析的可读性显著恶化；同时指出 BSD 阵营的蓝牙安全扫描工具远少于 Linux，已有社区成员尝试将相关工具移植入 FreeBSD ports。（BSDTalk EP13，[840.37-938.92]，L1）

**史观**：

- 总纲10 动手者创造历史：Callahan 以持续移植编译器、教学与组织用户组的具体劳动扩展 OpenBSD 生态，体现动手者的长期积累。（BSD Now EP422，[384.1-735.94]，L1）
- 总纲10 动手者创造历史：Lucas 认为少数关键人物把想法真正做出来，其余人让开道路，ZFS 进入 FreeBSD、DragonFly 与 OpenBSD 的分叉皆由此路径产生。（BSD Now EP267，[1779.18-1812.04]，L1）
- 总纲22 知识注定过时：BSD 更新速度快于出版业愿意出新书的速度，技术图书在出版之日即开始过时，写作只能追赶版本。（BSD Now EP267，[1414.10-1437.22]，L1）
- 总纲15 文化即形式主义：OpenBSD 用户几乎购买市场上每一本 OpenBSD 产品，这一购买文化使小众图书市场得以成立，属于社区文化作为形式主义包装的体现。（BSD Now EP267，[1522.62-1597.60]，L1）
- 总纲15 文化即形式主义：主持人在复盘 heartbeat 扩展进入 OpenSSL 与 IETF 的过程时指出：Hacker News 用户考据 IETF 邮件列表档案发现提案当年即有反对声音，但标准化结果并不取决于技术逻辑，而取决于邮件列表的参与结构——推动者必然积极发言，认为不必需者通常无意长期参与辩论，因此可疑特性容易通过；技术标准由此是被参与文化塑造的形式产物。（BSD Now EP33，[876.82-922.22]，L2）
- 总纲3 不存在进步，只有权力再分配：OpenBSD 对 OpenSSL 的 fork、大规模删码与全库格式重整，不宜单纯叙述为技术进步：其实质是把加密库的维护权、审计权与规范制定权从既有上游及其缺陷追踪机制收回，重新分配给一个坚持自身工程标准的社区；Heartbleed 事件只是这种权力再分配的触发契机。（BSD Now EP33，[980.74-1160.12]，L2）
- 总纲13 法律与道德是利益分配：BSD 认证组追求 ANSI 17024 认可的动因揭示了认证制度的利益本质：认证并非单纯的能力证明，而是把技术能力转化为制度资本、进而进入美国政府市场与国际互认体系的准入机制；五年续期与教育学分等规范化要求，均服务于这一利益分配格局。（BSD Now EP33，[2665.68-2809.64]，L1）
- 总纲10 动手者创造历史：受访者自称并非 BSD 权威而只是长期用户，其技术评论的依据是先在 FreeBSD 上亲手编译与试用工具、再把经过记录进博客以备自查；这种以动手实验与经验记录为发言资格的做法，凸显了系统生态的实际演进由一线使用者的实践积累而非权威论断推动。（BSDTalk EP13，[717.47-781.39]，L1）
- 总纲5 没有必然性，只有偶然性：Port Request 网站的诞生并非任何机构的规划产物：受访者把一系列个人化偶然条件——厌恶书签、依赖 Freshports 监视列表、发现某工具没有 port 时的不便——命名为至高懒惰，再将构想带到 NYCBUG 聚会，成员 Michael 当场动手实现并进入内测；基础设施工具由此从具体个人的省力需求中偶然生长出来。（BSDTalk EP13，[964.07-1155.61]，L1）
