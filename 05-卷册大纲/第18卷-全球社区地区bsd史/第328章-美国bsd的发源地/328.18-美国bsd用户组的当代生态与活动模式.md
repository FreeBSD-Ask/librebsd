# 美国 BSD 用户组的当代生态

## 美国.1 美国活跃 BSD 用户组

**要点**：BABUG（SF 湾）、NYC*BUG、ChicagoBUG、Seattle BUG、Phoenix BUG。COVID 后混合模式，核心议题延伸至 DevOps、云原生、嵌入式 BSD。
**史料**：BSD User Group 列表（bsd.org）; Meetup 数据 ［B］
**史观**：总纲第 15 条——用户组是最基层社会基础设施。
**辨析**：美国 BSD 用户组的数量与活跃度远低于 Linux 用户组（UG 总数约 1:10），反映了 BSD 在北美市场的结构性弱势。但 BSD 用户组的平均技术深度高于 Linux 用户组——BSD 用户组更倾向于讨论内核、网络栈、安全等底层议题，而非桌面应用。COVID-19 后混合模式增加了国际参与者的接入，但也降低了面对面技术交流的深度。用户组数据来源以 Meetup 和官方登记为准，未登记的线下小团体可能被遗漏。
**文献**：bsd.org; Meetup 数据 ［B］
