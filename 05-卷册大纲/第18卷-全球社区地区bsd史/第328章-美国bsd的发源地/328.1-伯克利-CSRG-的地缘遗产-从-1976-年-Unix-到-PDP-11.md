## 327.1.3 伯克利在 BSD 中的地缘地位辨析

  **要点**：伯克利作为 BSD 诞生地享有地缘中心地位，但 CSRG 解散后地位下降，社区全球化
  **史料**：BSD 社区地理分布变迁、Core Team 成员地理记录 ［A］；openbsd.db 查询 L3.3.1 显示：FreeBSD 23 仓库 commit 时区分布以 -08:00（美国太平洋时区，含伯克利/加州）与 -05:00（美国东部时区）为主，-07:00 时区（美国山地时区，含犹他/亚利桑那等）累计 788,356 commit 占比显著，反映美国本土时区（-08:00/-07:00/-06:00/-05:00）合计占 commit 总量主体；openbsd.db 查询 L3.3.2 显示：commit 作者邮箱 TLD 分布以 .org（开源组织）、.com（商业公司）、.edu（教育机构，含 berkeley.edu 等）三大类为主，.edu TLD 反映美国大学在 BSD commit 中的持续贡献
  **史观**：地缘中心的延续与解构；统计结论印证：统计结论 [L3.3.1] 时区分布 -07:00 占 788,356 commit 与统计结论 [L3.3.2] TLD 分布 org/com/edu 三大类共同印证美国本土作为 BSD 地缘中心的量化基础——美国时区（UTC-8 至 UTC-5）合计 commit 占比与 .edu TLD 持续活跃反映伯克利 CSRG 解散后地缘中心从 “单一机构（伯克利）” 向 “美国多机构网络” 扩散但未脱离美国本土，与 141.1.3 节所述 “地缘中心延续与解构” 在数据层面互证；bsd_commits.db L3.3.1/L3.3.2 查询覆盖 freebsd-src 等 23 仓库 commit author_email 时区推断（基于 commit 时间戳偏移）
  **辨析**：伯克利地位的下降是否完全需考据；其他地缘中心的崛起需分析；【0 信任原则·时区推断局限】L3.3.1 时区分布基于 commit 时间戳的 UTC 偏移推断作者所在地，但 commit 时间戳可能因服务器时区设置、开发者跨时区出差、自动化提交（CI/CD bot）等因素偏离作者实际所在地，时区数据仅为地理分布的近似指标；【0 信任原则·TLD 不等于国籍】L3.3.2 TLD 分布中 .com 与 .org 为全球通用 TLD，非美国专属，.edu 虽主要美国大学使用但亦含少数非美国机构，TLD 数据须与 author_email 域名归属交叉验证；【统计显著 ≠ 实际显著】美国本土 commit 占比高不直接等同于 “美国社区健康度最高”，须结合人口基数、互联网普及率、英语语言优势等结构性变量综合判断；详见描述性统计.md L3.3.1/L3.3.2 节与考据记录 20260727_第十二卷-统计学整合.md
  **文献**：Core Team Roster；BSD 社区地理分布研究 ［A］；openbsd.db 查询 L3.3.1（commit 时区分布，23 仓库）、L3.3.2（commit 作者邮箱 TLD 分布，23 仓库），见 `原材料/研究/bsd仓库分析/数据分析/深层信息挖掘.md` §L3.3.1、§L3.3.2
