**要点**：

- vBSDCon 2019 由 Dan Langille 组织，在弗吉尼亚州 Reston 的 Hyatt Regency 举办，Verisign 为主赞助商，议程涵盖 FreeBSD hackathon、正式会议、开发者峰会与慈善拍卖。（BSD Now EP315，[70.72-221.6]，L1）
- John Baldwin 的演讲回顾 BSD 自 1990 年代 sendfile 以来的内核 TLS 演进，并说明如何将加密会话密钥经 setsockopt 交给内核、再卸载到 Chelsio T6 网卡，同时处理链路聚合下的会话密钥交接。（BSD Now EP315，[828.32-1029.72]，L2）
- 反馈环节解释 FreeBSD 与 OpenBSD 的 PF 已因 VNET/vimage 支持与多核性能改造而大幅分叉，重新移植 OpenBSD 新版 PF 会丧失 FreeBSD 侧特性，因此长期未跟进。（BSD Now EP315，[4269.98-4411.6]，L1）
- 该期转述 Ars Technica 的 Unix 50 年回顾：1969 年 3 月 Multics 被叫停后，Thompson、Ritchie 与 Canaday 在闲置 PDP-7 上先设计文件管理器、再写汇编器与内核，形成 Unix 雏形。（BSD Now EP315，[2395.38-2999.32]，L2）
- 本期教程演示 SSH 链式连接：先以 ProxyCommand 指定经堡垒主机（bastion host）逐跳登录内网机器，再把主机别名、登录用户、密钥文件与跳板参数沉淀进 .ssh/config，使一条短命令即可完成多跳；HostKeyAlias 可将同一服务器的多个 known_hosts 条目合并为一以消除指纹误报；配置支持 host1/host2/host3 形式的递归串联与 Host * 通配默认跳板，且对 rsync、scp 等一切基于 SSH 的工具透明生效。（BSD Now EP42，[4676.64-5026.70]，L2）
- Sean Webb（彼时尚非 FreeBSD committer）推进 FreeBSD 的 PIE 支持以实现 ASLR：常规 ELF 可执行文件向内核声明固定加载地址，而以 PIE 编译者可被加载至任意地址，随机化由此可行；基础系统应用尚未默认以 PIE 编译，需在 make.conf 或 src.conf 置 WITH_PIE=yes 重编，i386、amd64、sparc64 与 arm 等架构均在支持计划内；该工作现处 11-CURRENT、尚未回移 10，项目即将发布测试征召，需要开发者清理代码风格、审查并给出 sign-off 以确认不破坏既有负载。（BSD Now EP42，[76.36-215.26]，L2）

**史料**：

- Paul Vixie 在 vBSDCon 2019 的 DNS over HTTPS 主题演讲，演示以 passive DNS 与 IPFW divert socket 识别 DoH 端点。（BSD Now EP315，[621.76-729.64]，L2）
- Ars Technica 的 Unix 50 年报道，含 Multics 会议、PDP-7 迁移、口述代码转磁带等细节。（BSD Now EP315，[2385.06-3015.04]，L2）
- ZFS 核心开发者 Matt Ahrens（转写误作 Matt Aarons）撰写的 ZFS StripeWidth 技术文章经主持人转述进入本节目：以图解与 Google 表格解析 RAID Z 按块分配和条带宽度对空间效率的影响，并给出 Delphix 生产库以 LZ4 压缩获得约 2 至 3 倍压缩比、读盘量减少三倍即读取时间节省三倍的量化经验；这是研究 ZFS 块分配设计的一手当事人文献，亦回应了社区常见教程中关校验以求提速的误传。（BSD Now EP42，[380.36-408.46]，L2）
- BSDCan 2014 参会行记留存本届议程一手记录：Luigi Rizzo 报告 Open vSwitch 与 NetMap 及软件定义网络，兼论 Linux 内核代码向 FreeBSD 的移植与 NetLink 套接字；Patrick Kelsey 介绍 libuinet，将 FreeBSD TCP/IP 栈整体迁入用户态以便无需反复重编内核即可测试修改，并与 NetMap 结合提速；PJD（Paweł Jakub Dawidek，转写仅作缩写）报告 Capsicum 与 Casper；主持人 Allan Jude 补述会后汉莎航班上约六十名 BSD 开发者同机、一位撞见即一位 committer 的“巴士系数”轶事，构成会议社区史的生动一手场景。（BSD Now EP42，[3436.30-3572.08]，L2）
- Devious shell provider 当任管理员 Bryce Chittister 的当事人自述：2010 年服务上线不久后以普通用户身份加入，创始人皆为 OpenBSD 爱好者，硬件、托管与带宽均由创始人捐赠，管理员全为志愿者（历任十一人、在任四人，含此前受访的 Brian Callahan）；现有唯一 shell 服务器与独立 DNS，用户 5684 账户、累计申请 16811 人、拒收率高，运行 OpenBSD 5.4 i386（2 GB 内存、四核 Xeon），因 5.5 升级需长时间停机而暂缓；治理依赖 login.conf 分类限额与监控后台进程的 bgkd 脚本、OSSEC 入侵检测加人工审阅申请与日志，奉行先处置后解释的运维哲学。（BSD Now EP42，[1438.14-1707.66]，L1）

**史观**：

- 总纲5 没有必然性，只有偶然性：Unix 诞生源于 Multics 被叫停与一台被遗忘的 PDP-7 被 Thompson 找到，是具体偶然条件而非必然演进。（BSD Now EP315，[2627.36-2670.72]，L2）
- 总纲10 动手者创造历史：Thompson 用三周分别写汇编器、编辑器与内核，且文件管理器先于内核成形，体现动手者而非宏大规划的创造路径。（BSD Now EP315，[2939.36-2981.86]，L2）
- 总纲4 分离聚合是永恒规律：PF 从 OpenBSD 移植到 FreeBSD 后因 vimage 与多核改造分叉，双方代码不再对齐，呈现分离聚合的循环。（BSD Now EP315，[4269.98-4411.6]，L1）
- 总纲22 知识注定过时：针对观众“生产服务器是否应移除编译器”之问，主持人指出该做法源自主机独占、用户别无他机的旧时代安全惯例，在任何人可随手起虚拟机编译再回拷二进制的当下已无任何安全收益，securelevel 提升与文件不可变标志等内核级约束才是有效防线，并以 Varnish 内置编译器处理配置语言为反例佐证；同段还呼应 Michael W. Lucas 在 FreeBSD hackers 邮件列表引发约五百封邮件的 gpart 与 fdisk、disklabel 之辨——安全教条与工具惯性皆随运行环境变迁而失效，具体知识注定过时，唯环境条件决定其效力。（BSD Now EP42，[4409.24-4471.84]，L2）
- 总纲5 没有必然性，只有偶然性：Bryce 以亲历者身份断言 shell 服务已无利可图：这一行当的黄金年代系于拨号上网、IRC bouncer 需求与 Hotmail、Gmail 尚不提供 IMAP 等偶然技术条件——用户需要一台永远在线、带固定上游带宽的机器；宽带普及与免费邮箱补齐能力后市场随之消亡，仅剩十余年前的少数大厂仍在运营（Brian Callahan 亦供职于其中之一）；BSD shell 服务的兴衰并非 BSD 本身的命运，而是外部通信条件偶然组合的函数，历史进程不可化约为项目内因。（BSD Now EP42，[2630.30-2712.26]，L1）
