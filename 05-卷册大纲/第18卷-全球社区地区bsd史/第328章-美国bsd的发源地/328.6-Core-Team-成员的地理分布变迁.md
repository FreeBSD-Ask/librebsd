## 328.6.1 早期美国主体到国际化演变

**史料**：Core Team 历届名单、成员地理记录、选举公告 ［A］；bsd_commits.db 查询 L3.3.1 显示：4 大 BSD src 仓库 + freebsd-doc/freebsd-ports 等 22 仓库合计 committer_date 时区偏移分布中，美国本土四时区 -05:00/-06:00/-07:00/-08:00 合计 1,378,470 commit（占前 30 时区合计约 45.6%）、贡献者 32,868 人（占前 30 时区合计约 41.8%），其中 -07:00（Mountain，含丹佛—博尔德一带，与 FreeBSD Foundation 注册地科罗拉多州 Boulder 重合）788,356 commit / 17,719 贡献者居全球时区之首，-08:00（Pacific，含硅谷、洛杉矶、西雅图）381,184 commit / 11,405 贡献者，-05:00（Eastern，含波士顿、纽约、华盛顿）144,926 commit / 8,901 贡献者，-06:00（Central，含芝加哥、奥斯汀）64,004 commit / 4,843 贡献者，-10:00（Hawaii）3,861 commit / 355 贡献者、-09:00（Alaska）291 commit / 7 贡献者；bsd_commits.db 查询 L3.3.2 显示：author_email TLD 分布中美国主导的 .com 域 1,041,011 commit / 31,783 unique emails（commit 量仅次于 .org 的 5,719,829），.edu 域（美国高校）8,425 commit / 340 unique emails（含伯克利、CMU、MIT、斯坦福等 BSD 教学重镇），.gov 域（美国联邦政府）41,303 commit / 42 unique emails（含 NSA、NASA、DARPA 等机构），.net 域 56,605 commit / 1,315 unique emails（部分为美国 ISP）
**史观**：地缘集中到分散的演变
**辨析**：国际化的具体时间节点需考据；各区域成员比例需统计；【0 信任原则·地理识别局限】author_email 域名不等于实际地理位置，.com 与 .org 等通用 TLD 为全球使用，不能简单等同于美国贡献者；时区偏移不等于居住地，远程办公、VPN、移民、海外美国公民、旅美外籍开发者等因素使时区—地理位置映射须慎重；【0 信任原则·committer_date 异常】L3.3.1 基于 committer_date 提取时区偏移，但 GitHub 镜像仓库的 committer_date 可能被重写为同步时间，分析时须改用 author_date 复核；【0 信任原则·author 字段可伪造】L3.3.2 基于 author_email 统计，git 的 author 字段可由提交者任意填写，且 .edu 邮箱可能被非在校人员长期保留，数据须与 committer 字段交叉验证
**文献**：Core Team Roster History；Core Team Election Records ［A］；openbsd.db 查询 L3.3.1（committer_date 时区偏移分布前 30，22 仓库合计，30 行结果）、L3.3.2（author_email 域名 TLD 分布，22 仓库合计，16 行结果），见 `原材料/研究/bsd仓库分析/数据分析/深层信息挖掘.md` §L3.3.1、§L3.3.2
