# 370.8.2 城市与偏远地区的 BSD 技术鸿沟

  **要点**：加拿大城市（多伦多、温哥华、蒙特利尔、渥太华）与偏远地区（育空、西北地区、努纳武特、纽芬兰乡村）之间存在显著的 BSD 技术鸿沟，偏远地区的 BSD 用户面临网络基础设施不足、技术支持匮乏、社区活动无法参与等障碍
  **史料**：加拿大偏远地区 BSD 使用调查、加拿大互联网基础设施统计、偏远地区 BSD 用户访谈 ［B］
  **史观**：总纲第 20 条——加拿大城市与偏远地区的技术鸿沟是 “历史地理塑造思想土壤” 的体现
  **辨析**：偏远地区 BSD 用户的具体人数需统计；技术鸿沟对 BSD 在加拿大扩散的影响需评估
