# 370.0.1 要点

- 加拿大多伦多大学、滑铁卢大学、不列颠哥伦比亚大学（UBC）、麦吉尔大学等高校在 1980 年代拥有活跃的 UNIX 计算机科学研究传统，多伦多大学的 CSRG 相关研究（与伯克利 CSRG 有学术联系）为加拿大 BSD 社区奠定了技术土壤。滑铁卢大学的计算机科学系在 1980 年代使用 4.2BSD/4.3BSD 作为教学与研究平台。
- 加拿大早期 ISP（如 iSTAR Internet、Internet Direct、Sympatico）在 1990 年代中期使用 FreeBSD 作为骨干服务器，加拿大互联网的早期基础设施（特别是 .ca 域名注册机构 CIRA 的早期系统）部分运行 FreeBSD。加拿大 ISP 系统管理员群体是 BSD 在加拿大最早的用户群体。
- BSDCan 于 2004 年首届在渥太华大学举办，由 Dan Langille 组织，渥太华被选为举办地部分原因在于其地理位置（加拿大首都，距多伦多、蒙特利尔、美国东北部 BSD 社区均较近）。BSDCan 的渥太华地缘选择使加拿大成为北美 BSD 会议文化的重要节点。
- 加拿大 BSD 早期部署记录与高校档案是评估加拿大 BSD 社区起源的关键史料，需交叉验证 ISP 技术文档与高校课程记录
- BSDCan 2004 年首届于渥太华大学举办，由 Dan Langille 组织，此后每年在渥太华举办（2020-2021 年因 COVID-19 转为线上），成为北美 BSD 社区仅次于 EuroBSDCon 的第二大年度会议。BSDCan 的会议文化以非正式、技术导向、社区友好著称，包括传统的 “BSDCan Pub Night” 与 “BSDCan 5K Run” 等社交活动
