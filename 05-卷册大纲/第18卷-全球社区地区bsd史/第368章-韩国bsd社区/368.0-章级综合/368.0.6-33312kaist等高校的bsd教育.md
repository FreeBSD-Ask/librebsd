# 368.0.6 333.1.2 KAIST 等高校的 BSD 教育

- 要点：KAIST（韩国科学技术院）、首尔大学、浦项工科大学（POSTECH）、延世大学、高丽大学等高校在 1990 年代开设 UNIX/BSD 相关课程，KAIST 的系统架构实验室（System Architecture Lab）在 BSD 内核研究方面做出了贡献。韩国高校的 BSD 课程培养了一批后续成为 FreeBSD/NetBSD committer 的韩国工程师。
- 辨析：各高校 BSD 课程的开设年代与名录需考据；KAIST 系统架构实验室的贡献细节需分析
