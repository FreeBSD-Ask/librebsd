# 368.1.3 韩国 BSD 用户组的早期活动

  **要点**：韩国 BSD 用户组（Korea BSD Users Group，한국 BSD 사용자 그룹）1990 年代末成立，早期通过 Daum Cafe、Naver Cafe 等韩国在线社区平台组织活动，邮件列表（freebsd-users-kr）与 IRC 频道（#freebsd-kr）是主要交流渠道。韩国 BSD 用户组与日本 BSD 用户组（JBUG）有频繁交流。
  **史料**：韩国 BSD 用户组 Daum Cafe Archive、freebsd-users-kr 邮件列表、早期活动记录 ［A］
  **史观**：总纲第 22 条——韩国 BSD 用户组是 BSD 社区在韩国本土化的组织载体
  **辨析**：韩国 BSD 用户组的确切成立日期需考据；Daum/Naver Cafe 的活跃度需评估
  **文献**：freebsd-users-kr Mailing List Archive；韩国 BSD 用户组 Daum Cafe 记录 ［A］
