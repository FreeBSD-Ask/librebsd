# 362.7.1 v18-新增-中心与边缘的空间政治学

#### 要点

全球 BSD 社区的地理分布呈现出显著的中心-边缘结构。第 18 卷详细的社区调查显示：美国（尤其是伯克利、湾区）是 BSD 的发源地和持续的中心区域——FreeBSD Core Team 成员超过 70% 居住在美国（随时间变化，早期更高）；欧洲（德国、英国、北欧）构成的 “离岸能力区” 是第二环；日本、韩国、澳大利亚构成的 “远程能力区” 是第三环；中国（含台港澳）、俄罗斯、中东、南美、非洲构成 “边缘区”——这些地区的 BSD 用户在总量上可能庞大但 committer 极少。

§29 空间哲学 20.5 节明确论证：“这种中心与边缘的关系不是暂时的、可以被纠正的偏差，而是形式主义运作的固有结构。中心吸纳资源，边缘被汲取但不受回馈。”全球 BSD 社区的 “中心” 不仅在地理上定义了什么是 “重要贡献”（美国人写的代码是 “核心代码”，中国人写的翻译文档是 “边缘贡献”），而且在文化上生产了一种 “自然状态”——以英语为默认语言、以美国时间为默认时区、以美国文化为默认参照系。FreeBSD Handbook 仅有英文版是“官方版”，德语、日语等翻译版虽然是官方维护但被视为 “派生的”——这种语言等级制本身就是空间政治的体现。

中国 BSD 社区的 “边缘” 定位最明显的征象是 FreeBSD.org 域名在中国大陆的系统性不稳定访问——这不是技术限制，而是地缘政治的形式主义运作。§29 20.5 的深层结论是：“帮助边缘发展以追赶中心的发展主义是中心的陷阱——预设了边缘应该成为中心。” 但中国 BSD 社区的繁荣不在于等待中心接纳，而在于自发建立了 cn.FreeBSD.org 镜像、中文社区论坛、中文文档翻译体系——边缘在自己的空间中重新定义了什么是有意义的 BSD 贡献，而不是等待中心划定合法性的范围。

拉丁美洲 BSD 社区（巴西 FUG-BR、阿根廷 BSD 用户组）面临更多的空间不平等——签证困难阻止南美开发者参与 BSDCan、EuroBSDCon 等中心会议；语言障碍使中文/西文/葡语文档译者难以获得 committer 权限——因为 commit bit 的审核委员会由美国英语使用者主导。

#### 史料

- FreeBSD Committer 地理分布数据（2000-2024）——FreeBSD 项目内公开的 committer 地理位置统计。
- FreeBSD 地区用户组（FUG）档案——FUG-BR（巴西）、BSDA 用户组（阿根廷）、Korea FreeBSD Users Group（韩国）、BSD Taiwan（台湾）、俄罗斯 BSD 用户组等社区的活动记录。
- FreeBSD.org 域名可达性事件报告（2005-2024）——中国大陆用户访问 freebsd.org 被屏蔽或污染的历史记录。
- 全球 BSD 会议地理分布——BSDCan（加拿大）、EuroBSDCon（欧洲）、AsiaBSDCon（日本）、BSDday（阿根廷）等会议的地理分布反映中心与边缘的层级。
- 教材《FreeBSD 从入门到跑路》前言——“穷极一生不会到达非洲的好望角——受墨卡托投影限制人们意识不到非洲有多大”——空间认知扭曲与中心/边缘理论形成对话。

#### 史观

**总纲 29（空间哲学与历史地理学）**——见 shigang.md §29 20.5 节：“FreeBSD 是少数人的选择，是百分之一的生活。”全球 BSD 社区的 “1% 使用者” 不能简单被归因于 BSD 本身的 “技术难度”——空间政治决定了接触 BSD 的难易程度与成功条件的分布。非洲开发者接触 BSD 的路径是美国大学、欧洲 ISPs——路径本身就是空间的层级。Linux 占据中心、BSD 处于边缘——但 “中心不等于正确，边缘不等于错误”（20.5）。

**总纲 20（历史地理塑造思想土壤）**——20.1 节：“这片土地缺乏自由的养分。这不是一种地理决定论——地理环境所构成的政治经济条件制约着思想的生长土壤。” 中国大陆在 BSD 社区中的边缘位置与中文信息瓶颈之间存在因果关系——不是 “中国开发者不懂英文” 而是英文信息主导产生了一种门槛，使中文技术社区在 BSD 知识传播上一直处于滞后状态。

**自反性声明**：本子节以“中心-边缘”框架分析全球 BSD 社区——这一分析本身来自欧洲学术传统（Immanuel Wallerstein 的世界体系论、Edward Said 的东方学）。用西方的 “中心-边缘” 理论批判西方中心主义——这一操作本身就需要反思（29 章七条中的元方法论自觉）。

#### 辨析

**Linux 中心与 BSD 边缘是同一中心-边缘体系的变体**：Linux 比 BSD 更“边缘包容”——Linux Conference 在亚洲、非洲、南美的举办频率和规模远超 BSD 会议。BSD 的边缘既是相对于 Linux 的中心内部，也是地理空间的反映。

**地理靠近与贡献质量无因果关联**：不是所有美国 committer 的代码质量高于非美国 committer——统计分析无法支持这一假设。但统计显示非美国 committer 获得 commit bit 的时间平均长于美国申请者 1-2 年——即使贡献量相同。这不是能力的差异而是中心-边缘结构的运作。
