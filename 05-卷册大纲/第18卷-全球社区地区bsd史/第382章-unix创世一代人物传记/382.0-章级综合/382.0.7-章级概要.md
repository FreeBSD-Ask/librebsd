# 382.0.7 章级概要

**要点**：本章为 UNIX 创世一代与 BSD 谱系核心人物传记总览——贝尔实验室一代（Thompson、Ritchie、Kernighan、McIlroy 等）、伯克利 CSRG 一代（Joy、McKusick、Karels、Bostic 等）与三大 BSD 项目创始一代（de Raadt、Hubbard、Demetriou、Hannum 等）的生平、贡献与谱系传承；章内人物档案 28 位，生卒与身份已逐条对照项目人物基准核验相符（含 McKusick 在世、Karels 2024-06-02 逝世两条核心修正）。

**史料**：项目人物基准库；官方纪念文与讣告；访谈与会议视频记录；`03-原始史料库/06-考据记录/` 人物传记考据文档（20260808_mckusick传记考据、20260808_karels逝世考据、20260808_全书人物传记研究） ［A］

**史观**：总纲第 10 条——动手者创造历史：UNIX 与 BSD 的历史由动手者书写，人物档案的逐位考据即对动手者群体的正名；总纲第 22 条——知识注定过时：人物在世状态等事实随时间推移必然过时，须按 0 信任原则持续核验更新。

**辨析**：在世人物的名誉纪律与生卒事实的时效性核验须区分处理；1995 年驱逐事件等争议性叙事平衡呈现而不裁决；人物入选本章的谱系关联性须以可查证来源为据（如库兹韦尔条目的入选依据待考，见下方 DB_POINTS 块整改留痕）。
