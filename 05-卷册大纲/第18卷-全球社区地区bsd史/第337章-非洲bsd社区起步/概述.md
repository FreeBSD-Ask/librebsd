# 第 337 章 非洲：待开垦的土地——南非技术社区、ISP 与金融业的 BSD 部署

> 本子章由原第 149 章拆分而来（2026-07 拆分前编号），承载 337.1-337.8 节。

## 本章摘要

本章考察非洲大陆 BSD 部署与社区建设的起步脉络：南非 ISP（Internet Solutions、Afrihost、Mweb 等）与企业、金融业（Standard Bank、Absa、FNB 等）的 BSD 部署构成非洲 BSD 应用的主要载体。开罗大学、拉各斯大学、内罗毕大学等高校的 BSD 课程尝试、低带宽环境下的源码分发与镜像策略、FOSSFA 等开源教育倡议，勾勒非洲 BSD 知识传播的制度条件。非洲开发者参与国际 BSD 社区的稀缺性及其经济、教育与签证等结构性原因，以及技术人才外流对本土社区的效应，构成本章辨析的重点。
