# 337.5 非洲开发者贡献的稀缺性与结构性原因——非洲开发者参与国际 BSD 社区的稀缺性、经济条件与教育资源的限制、签证困难对国际会议参与的限制

## 337.5.1 经济与教育资源限制的具体表现

  **要点**：非洲开发者参与国际 BSD 社区的稀缺性主要源于经济条件与教育资源的限制；具体表现包括：互联网接入不稳定、电力供应中断、计算机设备匮乏、英语/技术教育不足；具体数据须通过非洲开发者调查与社区档案核查

  **史观**：硬件与软件的辩证关系，物质条件限制塑造非洲开发者贡献的稀缺性
  **辨析**：限制因素的具体数据须通过权威统计核查——世界银行、国际电信联盟等；“稀缺性” 须量化——非洲 committer 比例

## 337.5.2 贡献稀缺性的长期趋势

  **要点**：1990 年代至 2010 年代非洲开发者贡献稀缺性持续存在；2010 年代后随非洲科技创业生态发展略有改善，但 BSD 社区贡献仍极少；趋势须通过 committer 地理分布统计验证
  **史料**：BSD committer 地理分布统计、非洲科技创业生态报告、非洲开发者调查 ［A］
  **史观**：技术路线的分化与并行演化，非洲开发者贡献稀缺性的持续反映结构性限制
  **辨析**：科技创业生态 “发展” 的判断须具体化——各国差异显著；BSD 与 Linux 在非洲开发者贡献的对比须量化
  **文献**：BSD committer 地理分布统计；非洲科技创业生态报告；非洲开发者调查报告 ［A］

## 337.5.3 非洲与南美开发者贡献比较

  **要点**：南美开发者对 BSD 社区的贡献规模显著大于非洲，主要因南美有更完善的互联网基础设施与教育体系；差异还源于南美葡萄牙语/西班牙语社区与英语社区的桥梁作用较强；比较须控制经济发展水平与教育投入变量
  **史料**：非洲与南美 BSD committer 统计、非洲与南美互联网基础设施对比、非洲与南美教育体系对比 ［A］
  **史观**：边缘者的贡献被中心叙事遮蔽，非洲开发者的双重边缘化反映 BSD 全球叙事不平等
  **辨析**：南美 “贡献规模较大” 的判断须量化——committer 数量、提交次数；语言桥梁作用的影响须具体分析
  **文献**：非洲与南美 BSD committer 统计；非洲与南美互联网基础设施对比研究；非洲与南美教育体系对比研究 ［A］

**要点**：

- Mohammed Farrag 为 ArabBSD 项目管理者，三年前开始 FreeBSD 研究、一年前进入 FreeBSD 社区贡献；ArabBSD 的目标是提升阿拉伯世界对 BSD 系统尤其 FreeBSD 的认知，把当地分散于调度、文件系统等方向的操作系统编程兴趣统一到 FreeBSD 这一环境中，并通过阿拉伯语教程与活跃邮件列表引导人们进入开源社区。（BSDTalk EP207，[57.28-136.16]，L1）
- 项目已在埃及一所大型大学提供免费互动课程，学员普遍无 UNIX 背景，故从 UNIX 入门与基础命令教起；受访者坦言当地对开源社区信任不足是推广的主要障碍，课程使命正是以此路径把人引入 FreeBSD 社区。（BSDTalk EP207，[131.16-291.40]，L1）
- FreeBSD Handbook 阿拉伯语翻译已完成约五章，项目计划两个月内完成全书；该翻译在归属上属 FreeBSD 文档项目，但尚未提交，拟集齐章节后统一提交；教程已上传至 FreeBSD 社区与 ArabBSD 网站；man 页翻译与网站阿语化列入后续计划；志愿者多以 OpenOffice 撰写再转换为 XML 等网页格式。（BSDTalk EP207，[211.48-424.90]，L1）
- 命令行的阿拉伯语化在短期内不可行：shell 仅有英文，且阿拉伯世界计算机科学教育以英语进行，学生习惯并偏好英文 shell；更现实的替代路径是提供 GNOME、KDE 等图形桌面环境；受访者正与 PC-BSD 团队接触，商讨提供默认阿拉伯语的 FreeBSD 桌面发行形态，Linux 阵营的 ArabEyes 项目被引为参照。（BSDTalk EP207，[699.08-827.16]，L1）
- 项目现阶段专注服务阿拉伯语使用者，非阿拉伯语者的参与机制暂不开放，虽有来自中国、法国的志愿者，多语种扩展被置于远期；项目原计划三个月内在阿拉伯世界举办全球性 BSD 活动，拟邀请 Robert Watson、Warner Losh、Dru Lavigne 等，因组织与赞助问题推迟。（BSDTalk EP207，[477.58-516.94]，L1）
- 阿拉伯世界尚无本地 FreeBSD 用户组，沟通完全依赖邮件列表；长期计划是在各国各城市建立本地小组，使成员能够面对面交流协作。（BSDTalk EP207，[638.32-699.08]，L1）
- 受访者向美国、欧洲与亚洲的 FreeBSD 社区发出呼吁：阿拉伯世界有优秀的开发者，但缺乏可供其发展并施展技能的环境，国际社区若提供环境与设施，这些技能即可投入 FreeBSD 开发。（BSDTalk EP207，[831.16-875.56]，L1）

**史料**：

- Mohammed Farrag 关于 ArabBSD 项目目标、埃及大学免费互动课程、Handbook 阿语翻译进度约五章的当事人一手口述；关于拟办阿拉伯世界全球 BSD 活动并拟邀 Robert Watson、Warner Losh、Dru Lavigne 的计划陈述。（BSDTalk EP207，[57.28-516.94]，L1）
- ArabBSD 与 PC-BSD 团队就阿拉伯语默认桌面进行的接触商谈；Linux 阵营 ArabEyes 阿拉伯化项目作为参照系被提及，可与 ArabEyes 与 PC-BSD 官方记录交叉核对。（BSDTalk EP207，[784.96-827.16]，L1）

**史观**：

- 总纲4 分离聚合是永恒规律：ArabBSD 试图把分散于调度、文件系统等方向的个人编程兴趣重新聚合到 FreeBSD 单一环境之中，是技术社群中分离力量经由组织化工作再趋聚合的一次自觉实践。（BSDTalk EP207，[531.26-557.12]，L1）
- 总纲20 历史地理塑造思想土壤：阿拉伯世界以英语为计算机科学教学语言、阿语文档长期缺位、对开源社区信任不足，这三重条件共同构成 BSD 在该地区传播的思想土壤与阻力，说明技术采纳路径深受地理与语言环境的塑形。（BSDTalk EP207，[265.48-315.28]，L1）
- 总纲8 本体论上各方平等：受访者强调阿拉伯开发者不是 BSD 的被动消费者而是潜在的对等贡献者，呼吁国际社区为其提供平等的发展环境，其立足点正是各方在本体论上的平等地位。（BSDTalk EP207，[831.16-875.56]，L1）
