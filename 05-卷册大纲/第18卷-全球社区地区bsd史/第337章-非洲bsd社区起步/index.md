# 第337章 非洲bsd社区起步

## 要点

- 南非 ISP（Internet Solutions、Afrihost、Mweb 等）自 1990 年代起部署 FreeBSD 用于网络服务；南非金融领域（Standard Bank、Absa、FNB 等）在核心交易系统中使用 BSD；部署的具体规模与时间节点须通过企业档案与 ISP 工程师访谈核查
- 南非 BSD 社区以 ZA FreeBSD User Group 为核心，1990 年代末至 2000 年代中期较活跃，2010 年代后随云计算主流化而式微；演变须通过邮件列表活跃度统计验证
- 南非与以色列 BSD 社区均起步于 1990 年代，但以色列因 Check Point 等安全公司与军方 8200 部队的技术传统形成更成熟的 BSD 生态；南非 BSD 社区规模较小且更依赖 ISP 与金融领域；比较须控制经济发展水平与教育体系变量
- 南非 BSD 史料以邮件列表、企业档案、技术媒体报道为主，缺乏系统性的学术研究；企业档案须警惕商业秘密限制；媒体报道须警惕政治立场与商业利益
- 埃及开罗大学、尼日利亚拉各斯大学、肯尼亚内罗毕大学、加纳大学等高校在 1990 年代至 2000 年代曾有零星 BSD 课程与社团；课程多由个人教师推动，缺乏制度化保障；具体课程内容与时间须通过大学课程档案核查

## 史观

- 部署反映企业对稳定性的实用主义选择；统计结论印证：统计结论 [L3.3.1] 时区分布非洲主要时区 +02:00 426,606 commit / 16,727 贡献者与 +03:00 74,576 / 3,977 均与欧洲/俄罗斯共用无法单独区分非洲贡献者与统计结论 [L3.3.2] TLD 分布非洲 ccTLD（.za/.ng/.ke/.eg/.ma/.tn 等）
- 总纲第 20 条——历史地理塑造思想土壤，非洲大学 BSD 课程的零星性反映当地教育土壤对 BSD 传播的限制
  - 辨析：BSD 课程的实际存在须通过大学课程档案核实——警惕 “传说中” 的课程；课程内容须具体化，不能仅凭教师自述
  - 文献：开罗大学/拉各斯大学/内罗毕大学/加纳大学计算机科学系档案；教师个人页面；学生回忆录 ［B］
