# 第337章 非洲bsd社区起步

## 要点

- 南非 ISP（Internet Solutions、Afrihost、Mweb 等）自 1990 年代起部署 FreeBSD 用于网络服务；南非金融 sector（Standard Bank、Absa、FNB 等）在核心交易系统中使用 BSD；部署的具体规模与时间节点须通过企业档案与 ISP 工程师访谈核查
- 南非 BSD 社区以 ZA FreeBSD User Group 为核心，1990 年代末至 2000 年代中期较活跃，2010 年代后随云计算主流化而式微；演变须通过邮件列表活跃度统计验证
- 南非与以色列 BSD 社区均起步于 1990 年代，但以色列因 Check Point 等安全公司与军方 8200 部队的技术传统形成更成熟的 BSD 生态；南非 BSD 社区规模较小且更依赖 ISP 与金融 sector；比较须控制经济发展水平与教育体系变量
- 南非 BSD 史料以邮件列表、企业档案、技术媒体报道为主，缺乏系统性的学术研究；企业档案须警惕商业秘密限制；媒体报道须警惕政治立场与商业利益
- 埃及开罗大学、尼日利亚拉各斯大学、肯尼亚内罗毕大学、加纳大学等高校在 1990 年代至 2000 年代曾有零星 BSD 课程与社团；课程多由个人教师推动，缺乏制度化保障；具体课程内容与时间须通过大学课程档案核查
