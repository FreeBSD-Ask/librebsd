# 337.3 低带宽环境下的源码分发与镜像策略——非洲低带宽环境下的源码 CD-ROM 分发历史、镜像站建立的困难、与非洲学术网络（如 UbuntuNet Alliance、WACREN、ASREN）的合作

## 337.3.1 CD-ROM 分发与镜像站建设

  **要点**：1990 年代至 2000 年代初非洲因低带宽环境主要依赖 CD-ROM 分发 BSD 源码；镜像站建设困难，主要依赖南非与埃及；与非洲学术网络（UbuntuNet Alliance 2005 年下半年由 5 个东非与南非 NREN 成立、2006-08-24 在荷兰阿姆斯特丹正式注册；WACREN 2006 年由 AAU 在阿克拉孵化、后在加纳注册；ASREN 2010-12-15 在开罗召开成立会议、2011-06-03 在德国杜塞尔多夫正式注册）的合作有限；具体 CD-ROM 分发量须通过社区档案核查
  **史料**：CD-ROM 分发记录、镜像站建设档案、UbuntuNet Alliance/WACREN/ASREN 合作文件［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］〔L3 官方文档与公告〕
  **史观**：总纲第 7 条——硬件与软件的辩证关系，低带宽环境塑造非洲 BSD 分发的独特模式
  **辨析**：UbuntuNet Alliance 2005 年下半年由 5 个 NREN（MAREN/Malawi、MoRENet/Mozambique、KENET/Kenya、RwEdNet/Rwanda、TENET/South Africa）成立已由 NITRD 2010 报告与 TANDEM 报告交叉印证；WACREN 2006 年孵化（AfNOG 2006、阿克拉 AAU 2006-11 会议）已由 TANDEM 报告确证；ASREN 2010-12-15 开罗成立会议与 2011-06-03 杜塞尔多夫注册已由 asren.net 官方与 aroqa.org 2010-12-15 报道交叉印证；CD-ROM 分发的实际规模须量化

## 337.3.2 分发策略从 CD-ROM 到网络的演变

  **要点**：2000 年代中期后随非洲互联网基础设施改善，BSD 源码分发从 CD-ROM 转向网络；但非洲镜像站仍稀少，多数依赖欧美镜像；演变须通过镜像站统计数据验证
  **史料**：非洲镜像站统计数据、非洲互联网基础设施发展报告、BSD 源码分发记录 ［A］
  **史观**：总纲第 6 条——技术路线的分化与并行演化，分发策略的演变反映非洲互联网基础设施的渐进改善
  **辨析**：非洲 “互联网基础设施改善” 的判断须具体化——各国差异显著；镜像站稀少的原因须具体分析
  **文献**：非洲镜像站统计数据；非洲互联网基础设施发展报告；BSD 源码分发档案 ［A］

## 337.3.3 非洲与南美分发策略比较

  **要点**：南美因经济条件较好与互联网基础设施较完善，CD-ROM 分发时期较短，网络分发较早普及；非洲 CD-ROM 分发时期较长，网络分发滞后；比较须控制经济发展水平与互联网普及率变量
  **史料**：非洲与南美 CD-ROM 分发记录、非洲与南美镜像站统计数据、非洲与南美互联网基础设施对比［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］〔L3 官方文档与公告/L5 二手研究〕

  **辨析**：南美 “较早普及” 的判断须具体化——南美各国差异显著；非洲 “滞后” 的原因须具体分析

**要点**：

- NSRC 是自 1980 年代后期即以某种形式存在的非营利组织，由 Randy Bush 约从其车库起步，宗旨是把互联网连接带到未曾到达之地；最早连接南非等非洲学术机构（先经早期拨号网络、后转 UUCP），其后获 NSF 与卡内基基金会等资助，从自行建设连接转向协助需要联网的人群；由少数国家的个人扩展至全球咨询支持（蒙古、不丹、尼泊尔、中美洲、巴拿马等），现聚焦于已存在的商业、科研与 NGO 网络，教授网络技术成熟化与面向客户的互联网服务建设，因为互联网边缘地带的连接与实际服务仍相当薄弱。（BSDTalk EP56，[59.04-176.46]，L1）
- PACNOG（太平洋岛国网络运营者组）创立于访谈前一年的首届工作坊，仿照 NANOG、AFNOG 等网络运营者组模式；太平洋岛屿面临独特难题——大量基本互不相连的岛屿，且有些岛屿之间永远不会铺设电缆；工作坊与 Cisco 及 PITA（太平洋岛国电信协会，ITU 地区努力的延伸）合作举办，首届在斐济、最近一届在萨摩亚；课程面向骨干网而非小型局域网：网络侧教 IGP 内部路由、BGP 多归属与对等负载均衡、经 APNIC 获取提供商无关地址，服务侧（他讲授部分）教可扩展邮件系统、RADIUS/AAA 认证与安全的 webmail 部署等高于默认水平的服务建设。（BSDTalk EP56，[183.66-425.46]，L1）
- 选用 FreeBSD 作教学平台的理由有四：其一，NSRC 创始人 Randy Bush 是早期 BSD 黑客；其二，增量升级配合 cvsup 与 ports 能让多机保持同步，把经昂贵链路传输的数据量压到最低——发展中地区卫星链路可达每兆比特每月 5,000 美元，发行版大版本更新动辄 4GB DVD ISO 会实质抬高 ISP 运营成本；其三，GEOM 架构成熟，从无镜像磁盘迁移到镜像磁盘极为简单，对低预算建 ISP 很重要；其四，ports 可在短时间内为 FreeBSD 本地化全部软件包，显著提高工作坊效率——FreeBSD 4 与 Linux 2.0-2.2、Red Hat 4-5 时代尚需训练学员从官方仓库手工编译安装。（BSDTalk EP56，[427.7-601.04]，L1）
- 教学法上刻意选择学员稍感陌生的工具：学员多具深厚 Linux 经验（十年前非洲则以 Solaris 背景居多），若在 Linux 上授课，许多人可凭既有惯性完成练习而不加批判性思考；Jaeggli 以自己 1993 年从 Solaris 转 Linux 所经历的陡峭学习曲线为经验依据，并称已观察到学员在实际中部署 FreeBSD 的转化。（BSDTalk EP56，[603.48-704.64]，L1）
- 工程取舍：工作坊主要使用 Cisco 路由器，而他在 Oregon Route Views 项目中用运行 BGP 的 PC 从全球路由器（经 BGP multihop 或置于交换点）收集完整路由表；但在接口多样、备件资金有限的地区，DS3 及以上接口与 V.35 串口等硬件尚未充分商品化，使其倾向采购可获支持的商业路由器；对无物理接触条件的远程主机他偏好 FreeBSD，因 cvsup、make buildworld、降至单用户重装的路径远比 Fedora 跨版本升级（仅靠串口控制台与远程网络）优雅，Route Views 主机分布于四大洲、损坏时无法飞赴抢修。（BSDTalk EP56，[716.82-912.12]，L1）

**史料**：

- 该期提供 NSRC 与互联网扩展史的一手口述：Randy Bush 车库创业与 NSRC 早期非洲连接（拨号网络转 UUCP）、NSF 与卡内基基金会的资助转向、首届与第二届 PACNOG（斐济、萨摩亚）的组织细节、Route Views 以 PC 路由器采集全球 BGP 全表的运作方式，以及发展中地区卫星链路每兆比特每月 5,000 美元的资费实证。（BSDTalk EP56，[59.04-176.46]，L1）

**史观**：

- 总纲20 历史地理塑造思想土壤：地理与经济条件直接塑造技术选择：卫星链路资费与岛屿地理使“增量升级、低传输量、磁盘镜像”成为 FreeBSD 被选为教学与部署平台的决定性理由，技术采纳并非单纯由功能优劣决定，而由带宽、资金与运维距离等物质条件共同规定。（BSDTalk EP56，[427.7-522.62]，L1）
