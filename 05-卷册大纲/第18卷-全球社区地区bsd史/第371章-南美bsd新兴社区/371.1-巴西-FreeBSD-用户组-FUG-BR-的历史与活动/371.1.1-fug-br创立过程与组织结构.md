# 371.1.1 FUG-BR 创立过程与组织结构

  **要点**：FUG-BR（FreeBSD User Group - Brasil）1995 年由 Edson Brandi 创立（其本人在 freebsd-translators 邮件列表 2019-12-27 自介中明确），为巴西最早且最具影响力的 FreeBSD 用户组；组织结构以邮件列表与论坛为核心，无固定主席，采用协调人轮换制；具体创立过程须经 FUG-BR 邮件列表存档与参与者口述访谈核查
