# 371.11.1 FreeBSD 商标在南美的注册情况

  **要点**：FreeBSD 商标在南美各国（巴西、阿根廷、智利、哥伦比亚等）的注册情况须经各国商标注册数据库核查；BSD Daemon 图像的版权由 Marshall Kirk McKusick（马歇尔·柯克·麦库西克） 持有，南美开源社区在衍生产品中使用须经授权；南美 BSD 衍生产品的商标使用须考据
  **史料**：巴西专利商标局（INPI）商标数据库、阿根廷商标数据库、智利商标数据库 ［A］
  **史观**：法律结构对技术创新的制约与解放，商标与版权的法律框架塑造 BSD 衍生产品的商业化路径
  **辨析**：商标注册号与注册日期须经原始数据库核查；BSD Daemon 图像授权的具体条款须查原始授权书
  **文献**：巴西 INPI 商标检索；阿根廷商标检索；智利商标检索 ［A］
