# 380.0.2 要点

- 印度理工学院（IIT）各校区（IIT Bombay、IIT Delhi、IIT Kanpur、IIT Madras、IIT Kharagpur 等）在 1990 年代开设 UNIX/BSD 相关课程，IIT Bombay 的计算机科学与工程系在 4.3BSD/4.4BSD 研究方面有传统。印度高校的 BSD 教育培养了一批后续成为全球 BSD 贡献者的印度工程师
- 印度 IT 产业巨头（Infosys、Tata Consultancy Services、Wipro、HCL Technologies）在 1990-2000 年代的早期基础设施中使用 FreeBSD 作为服务器操作系统。印度 IT 产业的外包业务（为美国企业提供 IT 服务）推动了 FreeBSD 在印度企业中的采用
- 印度互联网早期（ERNET，Education and Research Network，1986 年启动；VSNL，1995 年提供公共互联网接入）使用 FreeBSD 作为网络服务器。印度互联网的早期发展受政府主导（ERNET 由印度政府电子部资助），BSD 在印度学术网络中的部署是 BSD 在南亚最早的采用之一
- 印度 BSD 早期采用记录是评估印度 BSD 社区起源的关键史料，但部分记录分散且不完整
- 印度 BSD 用户组在 2000 年代形成，以班加罗尔（印度硅谷）、孟买、德里、海德拉巴、钦奈等 IT 中心为主要聚集地。Bangalore BSD Users Group（BBUG）是印度最大的 BSD 用户组，受益于班加罗尔作为印度 IT 产业中心的地位
