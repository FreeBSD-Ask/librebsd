# 380.8.1 印度多语言 BSD 用户的挑战


122.8 **多元群体贡献**———南亚 BSD 社区中不同语言、宗教、种姓、职业背景的贡献者群体——印度多语言 BSD 用户、巴基斯坦与孟加拉国的 BSD 用户、海外南亚裔 BSD 贡献者——的多元贡献模式

  **要点**：印度多语言环境（印地语、泰米尔语、泰卢固语、孟加拉语等 22 种官方语言）对 BSD 技术文档的本地化构成巨大挑战，印度 BSD 用户主要使用英语技术资料，但英语能力在印度分布不均，非英语背景的 BSD 用户面临语言障碍
