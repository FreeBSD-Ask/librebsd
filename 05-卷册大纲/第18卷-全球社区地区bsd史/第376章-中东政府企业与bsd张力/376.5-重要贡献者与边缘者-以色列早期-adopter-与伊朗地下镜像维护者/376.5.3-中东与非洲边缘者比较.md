# 376.5.3 中东与非洲边缘者比较

  **要点**：中东 BSD 边缘者多因个人兴趣与产业传统维持长期贡献，非洲边缘者多因经济压力与人才外流转向其他领域；差异主要源于两地 IT 产业结构的差异；比较须控制经济水平与就业市场变量
