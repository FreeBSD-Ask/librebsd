# 376.6.2 中东 OS 生态的演变趋势

  **要点**：1990 年代末至 2000 年代中期中东 OS 生态以 Linux 为主，BSD 边缘化；2010 年代后云计算与容器化使中东 OS 生态同质化，BSD 与 Linux 的本地差异缩小；趋势须通过历届中东技术会议议题统计验证
