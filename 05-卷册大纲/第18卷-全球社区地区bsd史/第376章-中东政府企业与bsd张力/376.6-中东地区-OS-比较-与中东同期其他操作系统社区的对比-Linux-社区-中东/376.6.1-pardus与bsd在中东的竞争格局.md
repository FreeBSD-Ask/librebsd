# 376.6.1 Pardus 与 BSD 在中东的竞争格局

  **要点**：Pardus（土耳其本土 Linux 发行版，2003 年由 TÜBİTAK 启动规划，TÜBİTAK UEKAE 开发，2005-02-04 发布首个 Live CD 1.0，2005-12-27 发布首个可硬盘安装的 Pardus 1.0，gonullu.pardus.org.tr 官方与 OSOR 案例研究交叉印证）在中东形成一定影响，对 BSD 在土耳其的地位构成竞争；BSD 在中东仅以色列等小规模群体维持；竞争格局的形成与 Pardus 的政府支持直接相关
  **史料**：Pardus 项目档案、TÜBİTAK 官方文件、Israel FreeBSD User Group 邮件列表、OSOR 案例研究、gonullu.pardus.org.tr Pardus 官方历史 ［A］
  **史观**：企业研究投入的双重性，Pardus 的政府支持塑造其在土耳其的竞争优势
  **辨析**：Pardus 2003 年由 TÜBİTAK 启动规划已由 OSOR 与 TÜBİTAK 官方档案交叉验证；Pardus 首个 Live CD 1.0（2005-02-04）与首个可安装版本 1.0（2005-12-27）的两个里程碑已由 gonullu.pardus.org.tr 与 turkipedia 交叉验证；Pardus 与 BSD 在中东的占比须量化
