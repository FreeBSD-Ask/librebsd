# 330.16 欧洲政府、企业与 BSD 项目之间的内部张力——**欧盟 Framework Programme 与 Horizon 2020/Europe 资助项目** 的官僚主义与项目交付压力：申请流程复杂、报告要求繁琐、部分开发者拒绝参与受欧盟资助的项目，认为 “官僚主义扼杀技术创造力”

  **要点**：欧盟 Framework Programme 与 Horizon 2020/Europe 资助项目的官僚主义与项目交付压力引发部分开发者抵触，认为 “官僚主义扼杀技术创造力”；申请流程复杂、报告要求繁琐是主要张力来源

## 330.16.2 张力的演变与效应

  **要点**：2000 年代后随欧盟资助规模扩大，官僚主义批评增多；部分开发者拒绝参与受欧盟资助的项目，转向 Foundation 直接资助或企业赞助
  **史料**：开发者邮件列表讨论、Foundation 资助记录、企业赞助公告 ［A］
  **史观**：总纲第 4 条——分离是新的聚合的开始，欧盟资助的官僚主义推动开发者转向其他资助模式
  **辨析**：演变的因果关系需谨慎表述；拒绝参与的具体人数需评估
  **文献**：开发者邮件列表讨论；Foundation 资助记录；企业赞助公告 ［A］
