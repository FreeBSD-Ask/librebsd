# 第 330 章 欧洲法律实体与基金会合作

## 要点

- 注册文件分散在美国 IRS、欧洲各国政府公报、基金会档案中，须交叉验证；部分早期文件未数字化
- 商标档案分散在 EUIPO、美国 USPTO、各国商标局中，须交叉验证；部分早期商标档案未数字化
- 筹款记录分散在 Foundation 年度报告、企业公告、邮件列表中，须交叉验证；部分匿名捐赠的具体金额未公开
- 提交者记录分散在 commit log、邮件列表、Foundation 档案中，须交叉验证；部分自动退休的 committer 名单未公开
- 矛盾记录分散在邮件列表、IRC 日志、个人博客中，须交叉验证；非英语记录的代表性不足
