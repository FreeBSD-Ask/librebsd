# 第 340 章 中东bsd法律与开源政策

## 要点

- 中东 BSD 法律史料以法律文本、企业合规档案、法律评论为主，缺乏系统性的学术研究；法律文本以 WIPO Lex 官方条目为一手基准（以色列《版权法》IL027、沙特《版权法》SA001、阿联酋 AE060 等，340.10）；法律文本须警惕修订频繁；企业合规档案须警惕商业秘密限制
- 中东 BSD 商标史料以商标局档案、FreeBSD Foundation 政策文件、社区记录为主，缺乏系统性的学术研究；注册记录集中于以色列、阿联酋、沙特等经济较发达国家（340.11）；商标局档案须警惕完整性不足；社区记录须警惕代表性偏差
- 中东捐赠史料以 FreeBSD Foundation 年度报告、企业档案、社区筹款记录为主，缺乏系统性的学术研究；捐赠记录较少，主要来自以色列 Check Point 等安全公司与海湾电信公司（340.12）；年度报告须警惕分类标准变化；企业档案须警惕商业秘密限制
- 中东 committer 史料以 FreeBSD 源代码库 commit 历史、Core Team 公告、committer 个人页面为主，缺乏系统性的学术研究；中东 committer 总数极少，伊朗 committer 因国际制裁而受限（340.13）；commit 历史须警惕归属错误；个人页面须警惕自利偏差
- 中东社区矛盾史料以邮件列表、社区论坛、口述史为主，缺乏系统性的学术研究；以色列 BSD 社区与阿拉伯语社区长期无正式合作，Arabeyes 项目最后编辑于 2017-01-19 后趋于停滞（340.14）；邮件列表须警惕代表性偏差——仅反映活跃成员观点；口述史须警惕记忆偏差与政治立场

## 史观

- 总纲第 13 条——法律与道德是利益分配：中东各国版权法、商标法与数据保护法对 BSD 部署的规制，反映不同法域间产业利益的分配格局（340.10）
- 总纲第 19 条——解释学循环是历史认识的根本条件：法律文本与社区史料的辨析须在文本与解释之间往复，并交代编纂者的选择（340.10、340.14）
- 总纲第 20 条——历史地理塑造思想土壤：地缘政治格局塑造中东 BSD 社区的合作与隔阂（340.14）
- 总纲第 8 条——本体论上各方平等：以色列 BSD 社区与阿拉伯语 BSD 社区在本体论上地位相等，差异是历史语境的不同而非本体等级（340.14）
- 总纲第 9 条——经验优先：法律事实以 WIPO Lex 与各国官方公报等一手文本为准，社区事实以邮件列表存档与 commit 历史等一手记录为准（340.10、340.13）

## 辨析

- 考据过程留痕——中东社区矛盾史料以 Israel FreeBSD User Group 邮件列表、Arabeyes 项目档案（<https://www.arabeyes.org/> 与 <https://gitlab.com/arabeyes/arabeyes>）、社区论坛历史讨论、口述史为主，缺乏系统性的学术研究（学术数据库检索未定位到专门的“以色列 BSD 社区与阿拉伯语 BSD 社区关系”研究文献）；邮件列表仅反映活跃成员观点，Arabeyes 项目最后编辑于 2017-01-19、2017-02-21 迁移 GitLab 后趋于停滞；口述史须与邮件列表、commit 记录交叉验证并标注政治立场（详见 340.14.4）
- commit 归属的准确性须评估——author_email 代理指标无法识别使用通用域名的中东贡献者，ccTLD 统计多归入 other 类（340.14.1）；个人页面的自利偏差须警惕（340.13.4）
- 年度报告的分类标准须明确——FreeBSD Foundation 年度报告的地区分类变化影响中东捐赠统计口径（340.12.4）；企业档案受商业秘密限制，捐赠金额须以原始年度报告核查（340.12.1）
- 商标局档案的完整性须评估——FreeBSD 商标在中东仅以色列、阿联酋、沙特等国有零星注册记录，数字化程度不足（340.11.1）；社区记录的代表性须量化（340.11.4）
- 法律文本的版本须明确——如阿联酋 Federal Decree-Law No. 38 of 2021 须区分 2021-09-20 颁布与 2022-01-02 生效（340.10.2）；企业合规档案多不公开，可获得的方得作为事实陈述依据（340.10.4）
