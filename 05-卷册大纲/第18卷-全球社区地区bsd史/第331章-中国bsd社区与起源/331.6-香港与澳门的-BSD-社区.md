# 331.6 香港与澳门的 BSD 社区

## 331.6.1 香港 BSD 社区的起源

  **要点**：香港 BSD 社区起源于 1990 年代，受英国殖民时期 Unix 传统影响；香港大学、香港中文大学、香港科技大学是 BSD 早期采用与教学的重要基地；香港作为国际金融中心，BSD 在金融 IT 基础设施中有部署记录

  **辨析**：香港 BSD 社区的确切起源时间须考据；金融 IT 中 BSD 部署的具体规模需评估

## 331.6.2 香港 BSD 用户组与活动

  **要点**：香港开源社区中有 BSD 用户群体；Hong Kong Open Source Conference 等活动中偶有 BSD 议题；香港 BSD 社区因国际化程度高，与欧美 BSD 社区有直接交流渠道
  **史料**：香港开源社区活动记录、BSD 相关演讲档案、社区成员访谈 ［B］

  **辨析**：香港 BSD 用户群体的具体规模须考据；与欧美社区交流的深度需评估
  **文献**：香港开源社区活动记录；BSD 演讲档案；社区成员访谈 ［B］

## 331.6.3 澳门 BSD 社区概况

  **要点**：澳门 BSD 社区规模较小，主要依托澳门大学等高校的计算机科学教育；澳门 BSD 使用集中在学术研究与小型企业服务器部署；澳门 BSD 社区与香港 BSD 社区有地理邻近性带来的交流
  **史料**：澳门大学课程记录、社区成员访谈 ［B］
  **史观**：总纲第 10 条——边缘者的贡献被中心叙事遮蔽，澳门 BSD 社区因规模极小最容易被忽略
  **辨析**：澳门 BSD 使用的具体数据须考据；澳门与香港 BSD 社区的交流程度需评估

## 331.6.4 港澳 BSD 社区与大陆 BSD 社区的互动

  **要点**：港澳 BSD 社区与大陆 BSD 社区在简体/繁体中文翻译项目上有协作；港澳因语言与法律体系差异，BSD 社区与大陆存在不同的发展路径；港澳回归后与大陆 BSD 社区的技术交流有所增加

  **辨析**：三地社区互动的具体案例须考据；法律体系差异对 BSD 使用的影响需评估
