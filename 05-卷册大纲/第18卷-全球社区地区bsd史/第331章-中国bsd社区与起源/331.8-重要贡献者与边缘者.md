# 331.8 重要贡献者与边缘者

## 331.8.1 各代中文社区维护者

  **要点**：CNFUG、FreeBSD China、ChinaFreeBSD、BSDCN 等各代中文社区维护者长期承担社区组织、文档翻译、新人培养工作；每一代社区组织者的退场都带走大量隐性的历史经验
  **史料**：各代社区档案、翻译项目存档、个人贡献者回忆 ［A］
  **史观**：边缘者的贡献被中心叙事遮蔽，中文社区维护者的长期贡献容易被忽略
  **辨析**：贡献者名单须逐项考据；翻译项目的完整性需评估
  **文献**：各代社区档案；翻译项目存档；个人贡献者回忆 ［A］

## 331.8.2 中文 Handbook 与 FAQ 翻译者

  **要点**：中文 Handbook 与 FAQ 翻译项目的长期贡献者是中国 BSD 社区的重要边缘力量；翻译工作从早期零星翻译发展为系统化翻译，但翻译者名单与贡献量缺乏系统记录
  **史料**：翻译项目 SVN/Git 提交日志、邮件列表讨论、社区成员访谈 ［A］
  **史观**：边缘者的贡献被中心叙事遮蔽，翻译者的贡献长期被代码贡献叙事遮蔽
  **辨析**：翻译贡献者的完整名单须考据；翻译质量与贡献量的评估标准需明确
  **文献**：翻译项目 SVN/Git 提交日志；邮件列表讨论；社区成员访谈 ［A］

## 331.8.3 被遗忘的中国早期 committer 与文档贡献者

  **要点**：1990 年代至 2000 年代中国早期 committer 的贡献记录分散在 commit log 与邮件列表中；部分 committer 因自动退休条款淡出社区，其贡献被后续叙事遮蔽
  **史料**：FreeBSD commit log、邮件列表存档、社区成员访谈 ［A］；bsd_commits.duckdb 查询 L3.3.1 显示：22 仓库合计 committer_date 时区偏移分布中，+08:00（中国标准时，含中国大陆、香港、台湾、新加坡、马来西亚部分）115,307 commit / 3,406 贡献者，是亚洲最大时区之一；bsd_commits.duckdb 查询 L3.3.2 显示：author_email TLD 分布中 .cn 域 9,650 commit / 591 unique emails（中国大陆 ccTLD），未单独列出的 .hk（香港）、.tw（台湾）归入 other 类；bsd_commits.duckdb 查询 L1.2.1 显示：FreeBSD 23 仓库合计每年新增贡献者数从 1993 年 72 人增至 2000 年 181 人，2005 年首次突破千人（1,563 人），2017 年达 2,215 人，反映中国大陆贡献者随互联网普及在 2010 年代后逐步进入主流社区
  **史观**：总纲第 4 条——分离是新的聚合的开始，早期贡献者的边缘化伴随社区代际更替；统计结论印证：统计结论 [L3.3.1] 时区分布 +08:00 中国标准时 115,307 commit / 3,406 贡献者作为亚洲最大时区之一与统计结论 [L3.3.2] TLD 分布 .cn 9,650 commit / 591 unique emails 共同印证中国大陆作为亚洲 BSD 社区新兴力量的量化基础，与 143.8.3 节所述“早期贡献者的边缘化伴随社区代际更替”在数据层面互证——+08:00 时区 commit 量与 .cn TLD 邮箱数显著但早期贡献者叙事被后续代际更替遮蔽，反映总纲第 4 条分离聚合命题的量化印证；freebsd.duckdb L3.3.1/L3.3.2 查询覆盖 freebsd-src 等 22 仓库 commit author_email 时区推断与 TLD 提取
  **辨析**：早期 committer 的具体名单须查 commit log；“被遗忘”现象的普遍性需评估；【0 信任原则·地理识别局限】author_email TLD 不等于实际地理位置，.cn 邮箱可由旅华外籍人员使用，且中国大陆、香港、台湾共用 +08:00 时区，时区偏移不等于居住地，远程办公、VPN（中国大陆开发者因网络限制可能使用境外 VPN 提交，导致时区偏移显示为境外时区）、移民等因素使时区—地理位置映射须慎重；【0 信任原则·committer_date 异常】L3.3.1 基于 committer_date 提取时区偏移，但 GitHub 镜像仓库的 committer_date 可能被重写为同步时间，分析时须改用 author_date 复核；【0 信任原则·author 字段可伪造】L3.3.2 基于 author_email 统计，git 的 author 字段可由提交者任意填写，且部分中国大陆贡献者使用 .com 邮箱（如 Gmail）或 .org 邮箱提交，未计入 .cn 域，.cn 数据仅为下限，实际中国大陆贡献者数量须结合 commit message 中的中文姓名与地理位置声明交叉验证；【统计显著 ≠ 实际显著】+08:00 时区 commit 量与 .cn TLD 占比高不直接等同于“中国社区贡献度最高”，须结合 GFW 网络限制、英语语言壁垒、内需市场体量等结构性变量综合判断；详见描述性统计.md L3.3.1/L3.3.2 节与考据记录 20260727_第十二卷-统计学整合.md
  **文献**：FreeBSD commit log；邮件列表存档；社区成员访谈 ［A］；openbsd.duckdb 查询 L3.3.1（committer_date 时区偏移分布前 30，22 仓库合计，30 行结果）、L3.3.2（author_email 域名 TLD 分布，22 仓库合计，16 行结果）、L1.2.1（每年新增贡献者数演化，1993-2026，38 行结果），见 `原材料/研究/bsd仓库分析/数据分析/深层信息挖掘.md` §L3.3.1、§L3.3.2，`原材料/研究/bsd仓库分析/数据分析/宏观趋势统计.md` §L1.2.1

## 331.8.4 台湾与香港繁体中文翻译者

  **要点**：台湾与香港繁体中文翻译者是独特群体，其翻译工作与简体中文翻译项目并行但独立发展；繁体中文 FreeBSD Handbook 的翻译质量与持续性在中文 BSD 社区中具有重要地位
  **史料**：繁体中文翻译项目存档、社区成员访谈 ［A］
  **史观**：总纲第 10 条——边缘者与中心者的对比体现结构性不平等，繁体中文翻译者的贡献在简体中文主导叙事中被边缘化
  **辨析**：繁体中文翻译者的具体名单须考据；翻译项目与简体中文翻译的协作关系需评估
  **文献**：繁体中文翻译项目存档；社区成员访谈 ［A］

  **辨析**：教学推广者的具体名单须考据；推广效果的量化的评估需谨慎
  **文献**：高校课程记录；社区培训活动档案；社区成员访谈 ［B］
