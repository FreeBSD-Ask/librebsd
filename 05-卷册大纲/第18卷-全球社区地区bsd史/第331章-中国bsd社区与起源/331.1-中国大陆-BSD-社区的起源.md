# 331.1 中国大陆 BSD 社区的起源

## 331.1.1 CNFUG 的创建与早期活动

  **要点**：CNFUG（China FreeBSD User Group）是中国大陆最早的 BSD 用户组织之一，定期发布《CNFUG 期刊》共 18 期，技术论坛活跃；2006 年存档停更，标志着第一代中文 BSD 社区的阶段性终结
  **史料**：CNFUG 期刊存档、论坛快照、社区成员回忆 ［A］
  **史观**：边缘者的贡献被中心叙事遮蔽，中文社区的早期贡献容易被忽略
  **辨析**：CNFUG 期刊共 18 期的数量须查存档；2006 年停更的具体原因需考据
  **文献**：CNFUG 期刊存档；论坛快照；社区成员回忆 ［A］

## 331.1.2 FreeBSD China（freebsdchina.org）的创建

  **要点**：FreeBSD China（freebsdchina.org）约 2003 年起活跃，曾是中国大陆最主要的 FreeBSD 交流平台；论坛与 wiki 社区并重，承载了第一代中文 BSD 用户的技术交流
  **史料**：FreeBSD China 网站快照、论坛存档、社区成员回忆 ［A］
  **史观**：边缘者的贡献被中心叙事遮蔽，中文社区平台的早期贡献容易被忽略
  **辨析**：2003 年创建时间须查网站快照；“最主要”地位的判定需评估
  **文献**：FreeBSD China 网站快照；论坛存档；社区成员回忆 ［A］
