# 336.7 南美 ISP 与电信公司的 BSD 部署——巴西 Telefonica/Vivo、Embratel、Argentine Telecom、Chilean Entel 等电信公司的 BSD 部署历史

## 336.7.1 Telefonica/Embratel 等电信 BSD 部署

  **要点**：巴西 Telefonica/Vivo、Embratel、Argentine Telecom、Chilean Entel 等南美电信公司在 1990-2000 年代广泛部署 FreeBSD 作为网络服务器与路由器平台；具体部署规模须经公司技术档案与招聘信息核查
  **史料**：南美电信公司技术档案、招聘信息、FUG-BR 邮件列表 ［A］

  **辨析**：电信公司 BSD 部署的具体规模须经公司技术档案核查；“广泛部署” 的量化标准须明确
  **文献**：南美电信公司技术档案；FUG-BR 邮件列表；招聘信息档案 ［A］

## 336.7.3 南美 ISP 部署回馈不足分析

  **要点**：南美 ISP 对 BSD 的部署规模较大但回馈不足；回馈不足与南美企业研发投入有限、语言壁垒、社区文化差异相关；分析须警惕 “南美更自私” 的预设偏差
  **史料**：FreeBSD SVN/Git 提交日志、FUG-BR 邮件列表 ［A］
  **史观**：总纲第 9 条——企业研究投入的双重性，回馈不足是 BSD 商业化史的普遍现象，地域差异在程度而非性质
  **辨析**：回馈不足的量化标准须明确；“自私” 的判定须考据
  **文献**：FreeBSD SVN/Git 仓库；FUG-BR 邮件列表 ［A］
