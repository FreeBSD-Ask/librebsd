## 336.20.1 Linux 与 BSD 在南美的竞争格局

  **要点**：Linux 在南美通过 Debian-BR、Ubuntu-BR 等本地化社区形成压倒性优势；BSD 在南美仅 FUG-BR 等小规模群体维持；竞争格局的形成与南美各国政府的自由软件政策倾向直接相关，卢拉政府 2003 年政策对 GPL 阵营的倾斜是关键节点
  **史料**：Debian-BR 邮件列表、Ubuntu-BR 社区档案、FUG-BR 邮件列表、巴西政府自由软件政策文件 ［A］
  **史观**：总纲第 9 条——企业研究投入的双重性，政策倾向塑造 BSD 在南美的弱势地位
  **辨析**：Linux 在南美占优的原因是多方面的——许可证契合政策、社区组织能力、企业投入，不能简单归因于单一因素；FUG-BR 的实际规模与活跃度须通过邮件列表量化
  **文献**：Debian-BR 项目档案；Ubuntu-BR 社区页面；FUG-BR 邮件列表存档；巴西卢拉政府自由软件政策档案 ［A］

## 336.20.3 南美与东亚 OS 生态比较

  **要点**：东亚（日本、韩国、中国）BSD 社区规模与影响力显著大于南美，主要因东亚有更完善的大学体系与产业基础；南美 BSD 社区长期依附欧美，缺乏独立组织；比较须控制经济发展水平与互联网普及率变量
  **史料**：Japan FreeBSD Users Group、韩国 BSD 用户组、中国 FreeBSD 用户组档案、FUG-BR 档案［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］〔L3 官方文档与公告〕
  **史观**：总纲第 10 条——边缘者的贡献被中心叙事遮蔽，南美 BSD 社区在全球叙事中被双重边缘化
  **辨析**：东亚与南美的差异不能简单归因于 “文化” 或 “经济”，须具体分析各国历史路径；日本与南美的 BSD 社区存在移民纽带，须考据
  **文献**：日本 FreeBSD 用户组档案；韩国与中国 BSD 用户组档案；FUG-BR 档案；日本巴西移民史资料［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］

### 史观映射

> 南美不是 BSD 版图的边缘，而是 “百分之一的选择” 最纯粹的试验场——当 Linux 成为拉美开源的主流叙事，选择 BSD 的人便成了少数中的少数，他们的选择不是基于市场份额的理性计算，而是基于技术判断与社区认同的信仰式决断。从边缘聚合为新兴力量的过程印证了分离聚合律：巴西 FUG-BR、阿根廷 FreeBSD 社区、智利与哥伦比亚的技术小组，每一处都是碎片化存在中的微聚合。技术生态的本体论平等在此遭遇了最残酷的现实检验——BSD 的代码不预设任何地区的优越地位，但基础设施的匮乏、经济的动荡与政治的不稳定使 “平等” 在安第斯山脉与亚马逊雨林之间沦为最苍白的哲学承诺。然而南美社区的核心始终是那些踏实做事的工程师，他们以最朴素的方式证明：动手者不需要中心，只需要一台连得上网的机器
