## 336.2.2 西语 BSD 社区的演进与衰落演变

  **要点**：西语 BSD 社区演变分三阶段——1999-2005 年的建立期、2006-2015 年的稳定期、2016 年后的衰落期；衰落与 Linux 兴起、社交媒体冲击、社区老龄化同步

  **辨析**：三阶段划分须经邮件列表量化分析核查；2016 年后的衰落是否单纯因 Linux 兴起需辨析

## 336.2.3 三国 BSD 社区比较分析

  **要点**：阿根廷、智利、哥伦比亚三国 BSD 社区存在差异；阿根廷因学术传统较强而 BSD 教学应用较多；智利因电信业发达而 ISP 部署较多；哥伦比亚因经济波动而社区规模较小；比较须警惕 “阿根廷最发达” 的预设偏差
