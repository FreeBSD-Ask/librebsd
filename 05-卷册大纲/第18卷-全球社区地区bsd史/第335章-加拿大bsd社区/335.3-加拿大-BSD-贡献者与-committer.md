# 335.3 加拿大 BSD 贡献者与 committer

147.3 **加拿大 BSD 贡献者与 committer**———加拿大 BSD 贡献者与 committer 包括 Dan Langille（BSDCan 创始人、FreeBSD ports 贡献者）、Michael W. Lucas（BSD 作家）、Gordon Tetlow（FreeBSD Core Team 成员）、加拿大 NetBSD 与 OpenBSD 贡献者

## 334.3.1 加拿大 BSD committer 群体概览

  **要点**：加拿大 BSD committer 群体涵盖 FreeBSD、NetBSD、OpenBSD 三大项目，代表性人物包括 Dan Langille（BSDCan 创始人，FreeBSD ports 贡献者，Bacula 与 FreshPorts 创始人）、Gordon Tetlow（FreeBSD Core Team 成员，安全团队）、Michael W. Lucas（著名 BSD 作家，著有《Absolute FreeBSD》《Absolute OpenBSD》等）、加拿大 NetBSD 与 OpenBSD 贡献者
  **史料**：FreeBSD committer 名单、NetBSD developer 名单、OpenBSD contributor 名单、committer 个人主页 ［A］；openbsd.db 查询 L3.3.1 显示：22 仓库合计 committer_date 时区偏移分布中，加拿大与美东共用 -05:00（多伦多、渥太华、蒙特利尔）144,926 commit / 8,901 贡献者、-06:00（温尼伯）64,004 / 4,843、-07:00（卡尔加里、埃德蒙顿）788,356 / 17,719、-08:00（温哥华）381,184 / 11,405、-09:00（育空）291 / 7，因加拿大全部时区与美国共用，时区数据无法单独区分加拿大贡献者；openbsd.db 查询 L3.3.2 显示：author_email TLD 分布中 .ca 域 2,395 commit / 144 unique emails（加拿大 ccTLD），在 ccTLD 中位列 .de/.uk/.fr/.cn/.ru/.jp 之后
  **史观**：总纲第 10 条——加拿大 BSD committer 是“动手者创造历史”的跨国体现；统计结论印证：统计结论 [L3.3.1] 时区分布加拿大全部时区与美国共用（-05:00 多伦多/渥太华/蒙特利尔 144,926 commit / 8,901 贡献者、-06:00 温尼伯 64,004 / 4,843、-07:00 卡尔加里/埃德蒙顿 788,356 / 17,719、-08:00 温哥华 381,184 / 11,405、-09:00 育空 291 / 7）无法单独区分加拿大贡献者与统计结论 [L3.3.2] TLD 分布 .ca 2,395 commit / 144 unique emails 在 ccTLD 中位列 .de/.uk/.fr/.cn/.ru/.jp 之后共同印证加拿大 BSD 社区在量化指标中被美国叙事遮蔽的边缘性，与 147.3.1 节所述“加拿大 BSD committer 动手者创造历史的跨国体现”在数据层面形成“地理相邻但统计独立”的张力——加拿大 BSD committer 群体涵盖 FreeBSD/NetBSD/OpenBSD 三大项目代表性人物但 .ca ccTLD 邮箱在 22 仓库中占比偏低且时区数据无法与美国区分，反映总纲第 10 条边缘者批评的量化印证；freebsd.db L3.3.1/L3.3.2 查询覆盖 freebsd-src 等 22 仓库 commit author_email 时区推断与 TLD 提取
  **辨析**：加拿大 committer 的具体人数需统计；各 BSD 项目中的分布比例需分析；【0 信任原则·地理识别局限】author_email TLD 不等于实际地理位置，.ca 邮箱可由旅加外籍人员使用，且加拿大全部时区与美国共用，时区偏移无法区分加美两国贡献者，远程办公、VPN、移民等因素使时区—地理位置映射须慎重；【0 信任原则·committer_date 异常】L3.3.1 基于 committer_date 提取时区偏移，但 GitHub 镜像仓库的 committer_date 可能被重写为同步时间，分析时须改用 author_date 复核；【0 信任原则·author 字段可伪造】L3.3.2 基于 author_email 统计，.ca 域数据仅为下限，部分加拿大贡献者使用 .com 邮箱（如 Gmail）或公司邮箱提交，未计入 .ca 域
  **文献**：FreeBSD Committers List；NetBSD Developers List；OpenBSD Contributors List ［A］；openbsd.db 查询 L3.3.1（committer_date 时区偏移分布前 30，22 仓库合计，30 行结果）、L3.3.2（author_email 域名 TLD 分布，22 仓库合计，16 行结果），见 `原材料/研究/bsd仓库分析/数据分析/深层信息挖掘.md` §L3.3.1、§L3.3.2

## 334.3.2 Dan Langille 与 BSDCan 的贡献

  **要点**：Dan Langille 是 BSDCan 的创始人，自 2004 年起持续组织 BSDCan 会议，同时是 FreeBSD ports 的贡献者（Bacula 备份软件 ports、FreshPorts 网站）。Dan Langille 的贡献体现了加拿大 BSD 社区的 “动手者” 精神——通过组织会议与维护 ports 双管齐下推动 BSD 发展
  **史料**：Dan Langille 个人主页、BSDCan 组织记录、FreeBSD ports commit log、FreshPorts 网站 ［A］
  **史观**：总纲第 10 条——Dan Langille 是加拿大 BSD 社区 “动手者” 的典型代表
  **辨析**：Dan Langille 的 ports 贡献量需统计；BSDCan 的组织工作对加拿大 BSD 社区的影响需评估
  **文献**：FreeBSD ports commit log；BSDCan 组织记录 ［A］

## 334.3.3 Michael W. Lucas 的 BSD 写作贡献

  **要点**：Michael W. Lucas 是 BSD 社区最著名的技术作家之一，著有《Absolute FreeBSD》（第 1 版 2007 年，第 3 版 2018 年）、《Absolute OpenBSD》（第 1 版 2003 年，第 2 版 2013 年）、《FreeBSD Mastery》系列等十余本 BSD 相关书籍。Lucas 的书籍是英语 BSD 社区最畅销的技术出版物之一，其写作风格以幽默与实用著称
