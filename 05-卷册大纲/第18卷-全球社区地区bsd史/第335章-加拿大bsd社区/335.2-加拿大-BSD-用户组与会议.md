# 335.2 加拿大 BSD 用户组与会议

147.2 **加拿大 BSD 用户组与会议**———BSDCan（2004 年首届于渥太华大学）是加拿大 BSD 社区的核心会议，Toronto BSD Users Group（TBUG）、Vancouver BSD Users Group 等地方用户组活跃

## 334.2.1 BSDCan 的会议文化

  **要点**：BSDCan 2004 年首届于渥太华大学举办，由 Dan Langille 组织，此后每年在渥太华举办（2020-2021 年因 COVID-19 转为线上），成为北美 BSD 社区仅次于 EuroBSDCon 的第二大年度会议。BSDCan 的会议文化以非正式、技术导向、社区友好著称，包括传统的 "BSDCan Pub Night" 与 "BSDCan 5K Run" 等社交活动
  **史料**：BSDCan 2004-2025 届议程与论文集、Dan Langille 组织记录、参会者统计 ［B］

## 334.2.2 Toronto BSD Users Group（TBUG）

  **要点**：Toronto BSD Users Group（TBUG）是加拿大最大的 BSD 用户组之一，定期在多伦多市中心举办技术讲座与安装会。TBUG 的成员涵盖多伦多大学、约克大学的学生与多伦多地区 IT 企业工程师，TBUG 与 BSDCan 组织团队有密切合作
  **史料**：TBUG 活动记录、TBUG 邮件列表、TBUG 技术讲座议程 ［A］
