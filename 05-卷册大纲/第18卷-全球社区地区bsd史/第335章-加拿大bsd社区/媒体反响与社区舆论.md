## 里程碑事件类

### 新闻条目 1

- **新闻标题（中英）**：Common Criteria Portal / 通用准则门户
- **新闻来源**：Common Criteria 官方门户 + URL `<https://www.commoncriteriaportal.org/index.cfm`>
- **新闻摘要**：Common Criteria（CC）是 IT 产品安全评估的国际标准框架，安全属性证书由多个证书授权方案（Certificate Authorizing Schemes）签发，证书被所有 CCRA（Common Criteria Recognition Arrangement）签署方认可。
- **与本章主题的关联说明**：这是 Common Criteria 官方门户，是本章 “J 类 ISO/IEC 官方文档” 与 “CC 框架定义” 小节的核心一手史料。
- **与官方史料的交叉验证结论**：门户由 Common Criteria 体系官方维护，CCRA 签署方列表与 ISO/IEC 15408 标准一致。

### 新闻条目 2

- **新闻标题（中英）**：Common Criteria (ISO/IEC 15408) | Secure-by-Design Handbook / 通用准则（ISO/IEC 15408）| 安全设计手册
- **新闻来源**：Secure-by-Design Handbook + URL `<https://www.securebydesignhandbook.com/docs/standards/global/common-criteria-overview`>
- **新闻摘要**：Common Criteria（CC）是评估与认证 IT 产品安全的全球认可框架，正式标准化为 ISO/IEC 15408 系列，配套评估方法论为 ISO/IEC 18045（CC Part 1 § 1）。
- **与本章主题的关联说明**：这是第三方对 CC 框架的系统性解读，明确 ISO/IEC 15408 与 ISO/IEC 18045 的标准编号关系，是本章 “CC 标准体系” 小节的辅助史料。
- **与官方史料的交叉验证结论**：ISO/IEC 15408 与 ISO/IEC 18045 编号与 ISO 官方目录一致，CC Part 1/2/3 结构与官方门户一致。

### 新闻条目 3

- **新闻标题（中英）**：ISO/IEC 15408 Common Criteria for IT security explained / ISO/IEC 15408 IT 安全通用准则解析
- **新闻来源**：cyber-regulation.com + URL `<https://cyber-regulation.com/article/isoiec-15408-common-criteria-for-it-security-explained`>
- **新闻摘要**：Common Criteria 自 1999 年起标准化为 ISO/IEC 15408，源自美国 TCSEC（Trusted Computer System Evaluation Criteria）、欧洲 ITSEC、加拿大 CTCPEC 的融合。认证路径从定义安全目标到测试实验室评估，资源密集。
- **与本章主题的关联说明**：这是 CC 历史源流的二手梳理，揭示 CC 与早期 TCSEC 的谱系关系，TCSEC 是 BSD 早期安全评估（如 1985 年 DoD 橙皮）的基础，是本章 “CC 历史源流” 小节的辅助史料。
- **与官方史料的交叉验证结论**：CC 源自 TCSEC/ITSEC/CTCPEC 融合的事实与 ISO/IEC 15408 历史记录一致，1999 年标准化时点与 ISO 官方记录一致。

### 新闻条目 4

- **新闻标题（中英）**：Common Criteria (ISO/IEC 15408): IT security eval / 通用准则（ISO/IEC 15408）：IT 安全评估
- **新闻来源**：spilma.com + URL `<https://www.spilma.com/en/guides/common-criteria-iso-15408`>
- **新闻摘要**：CC 全称 Common Criteria for Information Technology Security Evaluation，自 1999 年标准化为 ISO/IEC 15408，配套方法论 ISO/IEC 18045（Common Evaluation Methodology, CEM），为 IT 产品安全评估提供国际框架。
- **与本章主题的关联说明**：这是 CC 框架的第三方解读，明确 CEM（ISO/IEC 18045）作为配套方法论，是本章 “CC 评估方法论” 小节的辅助史料。
- **与官方史料的交叉验证结论**：ISO/IEC 18045 编号与 ISO 官方目录一致，CC 与 CEM 的配套关系与官方门户一致。

所谓"物质"的定义，是列宁抄的普列汉诺夫和恩格斯，而普列汉诺夫和恩格斯又是抄的费尔巴哈。后来这个东西被写进了课本，名曰"物质是不依赖于人的意识并能为人的意识所反映的客观实在"。从哲学史来看，唯物唯心两派从来没有进行过真正的对抗，不像中国哲学史存在儒道之争。所谓唯物唯心对抗是日丹诺夫编的，流传至今。"历史唯物主义"这个词马克思本人根本没说过，恩格斯也没有说过，是普列汉诺夫编的。恩格斯只说过"唯物主义历史观"。
