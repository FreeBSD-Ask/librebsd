# 333.3 韩国 BSD 贡献者与 committer

109.3 **韩国 BSD 贡献者与 committer**———韩国 BSD 贡献者与 committer 包括 Hye-Shik Chang（FreeBSD ports 与 Python 贡献者）、Jung-uk Kim（FreeBSD Java 与 ACPI 贡献者）、Sevan Janiyan（FreeBSD 文档贡献者）、韩国 NetBSD 与 OpenBSD 贡献者

## 332.3.1 韩国 BSD committer 群体概览

  **要点**：韩国 BSD committer 群体涵盖 FreeBSD、NetBSD 项目，代表性人物包括 Hye-Shik Chang（perky，FreeBSD ports 贡献者，Python 相关 ports 维护者）、Jung-uk Kim（jkim，FreeBSD Java 与 ACPI 子系统贡献者，Oracle Java 移植者）、Sevan Janiyan（FreeBSD 文档与网站贡献者）等。韩国 committer 的人数在亚洲 BSD 社区中仅次于日本。
  **史料**：FreeBSD committer 名单、NetBSD developer 名单、committer 个人主页 ［A］；openbsd.db 查询 L3.3.1 显示：22 仓库合计 committer_date 时区偏移分布中，+09:00（韩国标准时，与日本共用）38,272 commit / 3,046 贡献者，韩国与日本共享该时区，须结合 author_email 与姓名辨识区分；openbsd.db 查询 L3.3.2 显示：author_email TLD 分布中 .kr 域未单独列出，归入 other 类（other 类合计 1,277,384 commit / 4,252 unique emails），表明韩国 ccTLD 邮箱在 22 仓库中占比未进入前 15
  **史观**：总纲第 10 条——韩国 BSD committer 是“动手者创造历史”的跨国体现；统计结论印证：统计结论 [L3.3.1] 时区分布 +09:00 与日本共用 38,272 commit / 3,046 贡献者无法单独区分韩国贡献者与统计结论 [L3.3.2] TLD 分布 .kr 域未单独列出归入 other 类（other 类合计 1,277,384 commit / 4,252 unique emails）共同印证韩国 BSD 社区在量化指标中的边缘性，与 145.3.1 节所述“韩国 BSD committer 动手者创造历史的跨国体现”在数据层面形成“叙事丰富但量化稀疏”的张力——韩国 BSD committer 群体涵盖 FreeBSD/NetBSD 项目代表性人物但 .kr ccTLD 邮箱在 22 仓库中占比未进入前 15，反映总纲第 10 条边缘者批评的量化印证；freebsd.db L3.3.1/L3.3.2 查询覆盖 freebsd-src 等 22 仓库 commit author_email 时区推断与 TLD 提取
  **辨析**：韩国 committer 的具体人数需统计；各 BSD 项目中的分布比例需分析；【0 信任原则·地理识别局限】author_email TLD 不等于实际地理位置，.kr 邮箱未单独统计意味着韩国贡献者数量被低估，且 +09:00 时区同时覆盖日本与韩国，时区偏移不等于居住地，远程办公、VPN、移民等因素使时区—地理位置映射须慎重；【0 信任原则·committer_date 异常】L3.3.1 基于 committer_date 提取时区偏移，但 GitHub 镜像仓库的 committer_date 可能被重写为同步时间，分析时须改用 author_date 复核；【0 信任原则·author 字段可伪造】L3.3.2 基于 author_email 统计，.kr 域未单独列出可能因韩国贡献者多使用 .com 邮箱（如 Gmail、Naver 邮箱的 .com 域）或公司邮箱提交，数据须结合 commit message 中的韩国姓名与地理位置声明交叉验证；【统计显著 ≠ 实际显著】.kr TLD 未进入前 15 不直接等同于“韩国社区贡献度低”，须结合韩国 IT 产业体量、英语语言能力、Naver/Mail.ru 等本土邮箱服务流行度等结构性变量综合判断；详见描述性统计.md L3.3.1/L3.3.2 节与考据记录 20260727_第十二卷-统计学整合.md
  **文献**：FreeBSD Committers List；committer 个人主页 ［A］；openbsd.db 查询 L3.3.1（committer_date 时区偏移分布前 30，22 仓库合计，30 行结果）、L3.3.2（author_email 域名 TLD 分布，22 仓库合计，16 行结果），见 `原材料/研究/bsd仓库分析/数据分析/深层信息挖掘.md` §L3.3.1、§L3.3.2

## 332.3.2 Hye-Shik Chang 与 Jung-uk Kim 的贡献

  **要点**：Hye-Shik Chang（perky）是 FreeBSD ports 中 Python 相关 ports 的主要维护者，长期负责 FreeBSD 的 Python 软件包基础设施。Jung-uk Kim（jkim）是 FreeBSD Java 项目（FreeBSD Java Porting Team）的核心成员，负责 Oracle Java 在 FreeBSD 上的移植，同时是 FreeBSD ACPI 子系统的重要贡献者
  **史料**：Hye-Shik Chang 的个人主页与 commit log、Jung-uk Kim 的 commit log 与 Java 移植文档、FreeBSD ports 记录 ［A］
  **史观**：总纲第 10 条——Hye-Shik Chang 与 Jung-uk Kim 是韩国 “动手者” 对 FreeBSD 的关键贡献
  **辨析**：Python ports 与 Java 移植的具体贡献量需统计；两人在 FreeBSD 社区中的地位需分析
  **文献**：FreeBSD ports commit log；FreeBSD Java Porting Project 文档 ［A］

## 332.3.3 韩国 NetBSD 与 OpenBSD 贡献者
