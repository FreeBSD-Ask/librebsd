# 333.8 多元群体贡献

109.8 **多元群体贡献**———韩国 BSD 社区中不同年龄层、性别、职业背景的贡献者群体——学生、系统管理员、企业工程师、学术研究者、海外韩国人 BSD 贡献者——的多元贡献模式

## 332.8.1 学生与学术界的 BSD 贡献

  **要点**：韩国大学生（特别是 KAIST、POSTECH、首尔大学的学生）通过学术研究项目与 BSD 安装会参与 BSD 社区，韩国编程之夏（编程之夏）参与者在 BSD 项目中贡献了代码。韩国学术界在 BSD 网络栈、文件系统、安全研究方面有研究成果
  **史料**：KAIST/POSTECH 学生 BSD 研究记录、编程之夏 韩国参与者记录、韩国学术 BSD 论文 ［B］
  **史观**：总纲第 10 条——韩国学生是 BSD 社区 “动手者” 的新生力量
  **辨析**：学生贡献的具体项目与代码量需统计；编程之夏 参与者的后续贡献持续性需评估
  **文献**：编程之夏 FreeBSD 项目韩国参与者记录；韩国学术 BSD 论文 ［B］

## 332.8.2 系统管理员与 ISP 工程师的 BSD 实践

  **要点**：韩国 ISP 系统管理员与网络工程师是 BSD 在韩国最活跃的实践者群体，他们通过日常运维积累了丰富的 BSD 经验，韩国互联网的高速发展（1990 年代末 -2000 年代）为 BSD 在 ISP 领域的应用提供了广阔空间
  **史料**：韩国 ISP 系统管理员访谈、BSD 会议演讲记录、邮件列表讨论 ［A］
  **史观**：总纲第 10 条——韩国 ISP 工程师是 BSD 在韩国 “动手者” 的中坚力量
  **辨析**：系统管理员贡献的具体内容需考据；ISP 工程师的 BSD 使用规模需统计
  **文献**：韩国 ISP 工程师访谈；BSD 会议演讲记录 ［B］

## 332.8.3 海外韩国人 BSD 贡献者

  **要点**：部分韩国 BSD 贡献者居住于海外（如美国、日本），他们通过跨国网络参与韩国 BSD 社区与全球 BSD 社区。海外韩国人 BSD 贡献者在韩国 BSD 社区与全球 BSD 社区之间扮演了桥梁角色
  **史料**：海外韩国人 BSD 贡献者访谈、跨国社区参与记录、BSD 会议演讲者名单 ［B］
  **史观**：总纲第 10 条——海外韩国人 BSD 贡献者是 “动手者” 跨国网络的体现
  **辨析**：海外韩国人贡献者的具体人数需统计；跨国贡献的具体内容需分析
  **文献**：海外韩国人 BSD 贡献者访谈；BSD 会议演讲者名单 ［B］

辩证双方的地位如果不同，则必然是形式主义，或者说会自己往对面滑。因为二者本来就是一个东西。你如果承认可以转化，那么怎么说一方地位不同？存在逻辑问题。你最多只能说双方在一刻，地位不同。从结构本身看，必然是相同的。所谓辩证唯物主义的根本问题在于不承认双方的地位均等——它把一刻的不均等划成了本体论的。一刻哲学的历史跨度也可以很长，但本体论角度，相等。真正的辩证法在中国古代就有了，黑格尔还是没学到位。

所谓"物质"的定义，是列宁抄的普列汉诺夫和恩格斯，而普列汉诺夫和恩格斯又是抄的费尔巴哈。后来这个东西被写进了课本，名曰"物质是不依赖于人的意识并能为人的意识所反映的客观实在"。从哲学史来看，唯物唯心两派从来没有进行过真正的对抗，不像中国哲学史存在儒道之争。所谓唯物唯心对抗是日丹诺夫编的，流传至今。"历史唯物主义"这个词马克思本人根本没说过，恩格斯也没有说过，是普列汉诺夫编的。恩格斯只说过"唯物主义历史观"。

随着哲学学习的深入，会发现中国哲学的重要性。很多现实生活中真正重要的东西，只有在中国哲学中才有深入的讨论，以及能提供一种慰藉。西方哲学虽然也会讨论希望、幸福，但从来不考虑如何实现，只是一种形式主义——他们不去讨论现实的合理性，只重视逻辑上的合理性。纯粹研究哲学的学院哲学家很难有任何成就，真正的哲学家往往有其他领域的贡献作为支撑。
