# 373.3.1 非洲企业捐赠的具体记录

  **要点**：非洲企业与机构对 FreeBSD Foundation 的捐赠记录较少，主要来自南非 ISP 与金融 sector；捐赠的具体金额与时间须通过 FreeBSD Foundation 年度报告与企业档案核查
  **史料**：FreeBSD Foundation 年度报告、非洲企业捐赠档案、社区筹款记录 ［B］
  **史观**：企业研究投入的双重性，非洲企业捐赠的稀少反映 BSD 在非洲产业中的弱势
  **辨析**：捐赠的具体金额须通过 FreeBSD Foundation 原始年度报告核查；“较少” 的判断须量化——与其他地区对比
  **文献**：FreeBSD Foundation 年度报告；非洲企业捐赠档案；社区筹款记录 ［B］
