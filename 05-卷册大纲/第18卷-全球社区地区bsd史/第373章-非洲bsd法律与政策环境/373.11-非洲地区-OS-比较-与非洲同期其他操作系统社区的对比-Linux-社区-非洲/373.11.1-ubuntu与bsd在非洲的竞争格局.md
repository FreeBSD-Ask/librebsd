# 373.11.1 Ubuntu 与 BSD 在非洲的竞争格局

  **要点**：Ubuntu Linux 由 Canonical Ltd. 于 2004 年 3 月创办（2004 年 10 月 20 日发布 Ubuntu 4.10 “Warty Warthog”），创办人为南非企业家 Mark Shuttleworth（ubuntu.com 官方与 billionaires.africa 2026-06-03 报道交叉印证）；Ubuntu 在非洲形成压倒性优势，主要因 Ubuntu 的非洲渊源（命名源自南非 Nguni 语哲学概念 “humanity to others”）与本地化投入；BSD 在非洲仅南非等小规模群体维持；竞争格局的形成与 Ubuntu 的非洲渊源直接相关
  **史料**：Ubuntu 公司史（ubuntu.com）、Mark Shuttleworth 个人档案（billionaires.africa 2026-06-03 报道）、ZA FreeBSD User Group 邮件列表 ［A］
  **史观**：企业研究投入的双重性，Ubuntu 的非洲渊源塑造其在非洲的压倒性优势
  **辨析**：Canonical 2004 年 3 月成立已由 ubuntu.com 官方与 billionaires.africa 报道交叉印证；Ubuntu 4.10 于 2004-10-20 发布（ubuntu.com 官方）；Mark Shuttleworth 南非身份已由 billionaires.africa 与 iniafrica.com 2025-11-25 报道印证（出生于 1973 年，Thawte 创始人，1999 年以 5.75 亿美元出售给 VeriSign，2002 年 4 月 25 日成为首位太空游非洲人）；BSD 与 Ubuntu 在非洲的占比须量化
  **文献**：Ubuntu 公司档案（ubuntu.com）；Mark Shuttleworth 个人页面（billionaires.africa 2026-06-03）；ZA FreeBSD User Group 邮件列表存档 ［A］
