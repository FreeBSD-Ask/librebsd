# 第339章 中东bsd技术绿洲以色列

## 要点

- Check Point（1993 年 6 月 5 日由 Gil Shwed、Marius Nacht、Shlomo Kramer 在以色列拉马特甘创立，portersfiveforce.com、Check Point 官方多源交叉验证）的 FireWall-1（1994 年发布）初期目标平台为 SunOS 4.1.4 与 Solaris 2.3，SunOS 4.x 基于 BSD 4.3 派生，故 FireWall-1 与 BSD 派生平台关系密切；以色列军方 8200 部队等技术单位对 BSD 有使用；以色列 ISP（Bezeq、Cellcom、Partner 等）部署 BSD 用于网络服务；Check Point 与军方的具体 BSD 使用须通过企业档案与工程师访谈核查
- 以色列 BSD 社区以 Israel FreeBSD User Group 为核心，1990 年代末至 2000 年代中期较活跃；2010 年代后随云计算主流化而式微，但因 Check Point 等安全公司的存在仍保持一定活力；演变须通过邮件列表活跃度统计验证
- 以色列与南非 BSD 社区均起步于 1990 年代，但以色列因 Check Point 等安全公司与军方技术传统形成更成熟的 BSD 生态；南非 BSD 社区规模较小且更依赖 ISP 与金融 sector；比较须控制经济发展水平与教育体系变量
- 以色列 BSD 史料以邮件列表、企业档案、技术媒体报道为主，缺乏系统性的学术研究；企业档案须警惕商业秘密限制；军方资料须警惕国家安全限制
- 阿联酋 Etisalat 与 du、沙特 STC 与 Mobily、卡塔尔 Ooredoo、科威特 Zain 与 Ooredoo、巴林 Batelco、阿曼 Omantel 等海湾电信公司在 1990 年代至 2000 年代曾广泛部署 FreeBSD 用于网络服务；BSD 部署的具体规模与时间须通过企业档案与工程师访谈核查

## 339.1.2 以色列 BSD 社区从萌芽到成熟的演变

- 要点：以色列 BSD 社区以 Israel FreeBSD User Group 为核心，1990 年代末至 2000 年代中期较活跃；2010 年代后随云计算主流化而式微，但因 Check Point 等安全公司的存在仍保持一定活力；演变须通过邮件列表活跃度统计验证

- 辨析：Check Point 1993 年 6 月 5 日成立时间已由 portersfiveforce.com、Check Point 自家 2018-12-19 25 周年纪念文章交叉验证；FireWall-1 1994 年发布及 SunOS 4.1.4/Solaris 2.3 初始支持已由 firewall.cx Shlomo Kramer 自述与 Check Point 官方技术文档交叉验证

## 339.2.2 海湾 BSD 部署从起步到扩展的演变

- 要点：1990 年代海湾 BSD 部署起步，主要因 FreeBSD 的网络性能优势；2000 年代随海湾互联网基础设施扩展 BSD 部署扩大；2010 年代后随 Linux 网络性能改善与云计算主流化，BSD 角色弱化；演变须通过电信部署统计验证
- 史料：海湾电信 BSD 部署统计、海湾互联网基础设施发展报告、BSD 与 Linux 性能对比研究［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］
- 史观：总纲第 3 条——不存在进步，只有权力再分配，海湾电信公司对 BSD 的实用主义选择及其后 BSD 角色的弱化是部署份额的再分配
- 辨析：各电信公司的具体 BSD 部署时间须通过企业档案核查；BSD 与 Linux 在海湾电信部署中的占比须量化
- 文献：海湾电信公司企业档案；海湾电信行业报告；工程师访谈记录 ［B］

## 339.3.2 BSD 教学从零星尝试到边缘化的演变

- 要点：中东大学 BSD 教学多在 2000 年代中期后边缘化，主要原因包括教师退休或外流、Linux 主流化、教育资源转向；演变须通过课程档案与教师访谈验证
- 史料：中东大学课程档案、教师访谈、中东教育政策文件 ［B］
- 史观：总纲第 3 条——不存在进步，只有权力再分配，BSD 教学的边缘化与 Linux 在中东教育中的主流化是教育阵地的再分配
- 辨析：边缘化的原因须具体分析——教师退休或外流、Linux 主流化、教育资源转向的相对作用须甄别

## 339.5.2 伊朗 BSD 社区在制裁下的生存演变

- 要点：伊朗 BSD 社区在国际制裁下通过地下网络获取软件与文档；2010 年代后随制裁加剧，伊朗 BSD 社区进一步孤立；演变须通过社区档案与开发者访谈验证
- 史料：伊朗技术社区邮件列表、开发者访谈、地下软件分发记录 ［A］
- 史观：总纲第 13 条——法律与道德是利益分配，国际制裁作为法律框架的利益分配工具塑造伊朗 BSD 社区的独特生存模式
- 辨析：地下网络的实际情况因安全限制难以完全核查；开发者访谈须警惕记忆偏差与政治立场
- 文献：伊朗技术社区邮件列表、开发者访谈、地下软件分发记录 ［A］

## 339.6.2 地缘政治效应从局部到全局的演变

- 要点：1990 年代地缘政治对 BSD 社区影响局部，主要因 BSD 社区规模小；2000 年代后随美国制裁加剧与全球反恐战争，地缘政治影响扩展；2010 年代后随美中技术竞争加剧，地缘政治影响全球化；演变须通过制裁清单变化与社区档案验证
- 史料：EAR 修订历史、OFAC 制裁名单变化、FreeBSD Foundation 公告、社区邮件列表 ［A］
- 史观：总纲第 20 条——历史地理塑造思想土壤，地缘政治环境从局部到全局的演变塑造中东 BSD 社区的生存境况
- 文献：Israel FreeBSD User Group 邮件列表存档；Saudi Arabian Unix Users Group 档案；Iran Unix User Group 档案 ［A］

- 要点：阿拉伯之春（2010-2012 年）对中东技术社区造成冲击，部分社区成员因政治动荡外流；技术社区在政治动荡中既遭遇破坏也获得新的组织机会；演变须通过社区档案与开发者访谈验证

- 辨析：阿拉伯之春的起止时间（2010-2012 年）须通过历史档案核查；“破坏”与“机会”的具体表现须通过社区档案与开发者访谈具体化
