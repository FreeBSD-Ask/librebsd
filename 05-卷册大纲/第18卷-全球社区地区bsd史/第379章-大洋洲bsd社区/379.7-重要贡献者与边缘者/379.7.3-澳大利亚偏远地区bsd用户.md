# 379.7.3 澳大利亚偏远地区 BSD 用户

**要点**：澳大利亚城市（悉尼、墨尔本、布里斯班、珀斯）与偏远地区（北领地、塔斯马尼亚、西澳乡村）之间存在显著的 BSD 技术鸿沟，偏远地区的 BSD 用户面临网络基础设施不足、技术支持匮乏、社区活动无法参与等障碍

**史料**：澳大利亚偏远地区 BSD 使用调查、澳大利亚互联网基础设施统计、偏远地区 BSD 用户访谈 ［B］

**史观**：总纲第 20 条——澳大利亚城市与偏远地区的技术鸿沟是 “历史地理塑造思想土壤” 的体现

**辨析**：偏远地区 BSD 用户的具体人数需统计；技术鸿沟对 BSD 在澳大利亚扩散的影响需评估
