  **史料**：ITWeb 历史文章（itweb.africa 2021-03-01 官方文章）、BSDCan 会议报道、Juniper/NetApp 南非部署档案、iniafrica.com 2025-11-25 ［C］

## 338.16.2 公众认知从空白到偏见的演变

  **要点**：1990 年代非洲公众对 BSD 普遍空白，将其与 Linux 混淆；2000 年代后随 Ubuntu 在非洲主流化，BSD 被部分公众视为 “过时的西方技术”；演变须通过历届 Idlelo 公众调查与媒体报道分析
  **史料**：Idlelo 历届公众调查、非洲技术媒体报道、BSD 与 Linux 用户论坛讨论 ［C］
  **史观**：技术路线的分化与并行演化，公众认知的演变反映 Ubuntu 在非洲的主流化
  **辨析**：“空白” 与 “偏见” 的判断标准须明确；Ubuntu 主流化对 BSD 公众认知的影响须量化
  **文献**：Idlelo 公众调查档案；非洲技术媒体存档；BSD 与 Linux 用户论坛历史讨论 ［A］

## 338.16.3 非洲与南美公众认知比较

  **要点**：南美公众对 BSD 的认知较非洲相对准确，主要因南美有更长的 UNIX 传统与更完善的技术教育；非洲公众认知的偏差与非洲 UNIX 传统的薄弱直接相关；比较须控制教育体系与媒体生态变量
  **史料**：非洲与南美技术媒体对 BSD 的报道、非洲与南美技术教育课程对比 ［C］
  **史观**：边缘者的贡献被中心叙事遮蔽，非洲公众认知的偏差是 BSD 全球叙事边缘化的体现
  **辨析**：南美 “相对准确” 的判断须具体化——南美各国公众认知差异显著；非洲 “UNIX 传统薄弱” 的判断须通过大学课程与产业历史验证
  **文献**：非洲与南美技术媒体存档；非洲与南美大学计算机科学课程档案 ［A］

## 338.16.4 非洲公众认知史料辨析

  **要点**：非洲公众认知史料以媒体报道、论坛讨论、口述史为主，缺乏系统调查；口述史须警惕记忆偏差与事后合理化；媒体报道须警惕政治立场与商业利益
  **史料**：Idlelo 公众调查、非洲技术媒体报道、BSD 与 Linux 用户论坛讨论、口述史 ［C］

  **辨析**：口述史的代表性须评估——是否仅反映活跃社区成员的观点；媒体报道的覆盖率须量化
  **文献**：Idlelo 公众调查档案；非洲技术媒体存档；BSD 与 Linux 用户论坛历史讨论；口述史记录 ［A］
