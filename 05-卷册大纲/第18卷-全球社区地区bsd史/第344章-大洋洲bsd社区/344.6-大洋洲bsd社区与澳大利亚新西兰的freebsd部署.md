# 344.6 大洋洲 BSD 社区与 FreeBSD 部署

## 344.6.1 BSD 在澳大利亚学术网络与 CSIRO 中的部署

**要点**：Sydney 大学（1976 年起）与 CSIRO 在多代平台中使用 BSD。新西兰 Wellington BSD User Group 虽小但技术深度高。

**史料**：Sydney 大学 BSD 记录（TUHS）; CSIRO 技术报告 ［B］

**史观**：总纲第 15 条——学术传统对技术路线的锁定效应。
**辨析**：大洋洲 BSD 的独特之处在于其学术血脉的连续性——Sydney 大学从 1976 年至今的 BSD 使用跨越了近半个世纪，是全球最长的 BSD 学术部署血统之一。但这种连续性也带来了“锁定效应”——BSD 在澳大利亚学术网络中的存在更多是历史惯性而非主动选择。CSIRO 的 BSD 部署因机构重组而缺乏完整的公开记录，使研究者在重建技术谱系时面临碎片化证据的挑战。新西兰 Wellington BSD User Group 的“小而深”模式与加拿大 BSDCan 的“会议驱动”模式形成对比——大洋洲 BSD 社区更接近欧洲的“深度优先”而非北美的“广度优先”模式。Peter Jeremy 等大洋洲 BSD 开发者的贡献在国际社区中可见，但大洋洲本地的 BSD 叙事仍以学术部署为主，缺乏独立的社区故事线。
**文献**：TUHS 存档； CSIRO 报告 ［B］
