# 第344章 大洋洲bsd社区

## 要点

- 澳大利亚悉尼大学、墨尔本大学、新南威尔士大学（UNSW）、莫纳什大学、澳大利亚国立大学（ANU）等高校在 1980 年代拥有活跃的 UNIX 计算机科学研究传统，UNSW 的计算机科学与工程学院在 4.3BSD/4.4BSD 研究方面有传统，澳大利亚学术网络（AARNet）的早期发展中使用 BSD 系统
- 澳大利亚早期 ISP（如 OzEmail、Telstra BigPond、OptusNet、iiNet）在 1990 年代中期使用 FreeBSD 作为骨干服务器。澳大利亚互联网的早期发展（以 AARNet 1989 年启动为起点，1990 年代中期商业化）中 FreeBSD 扮演了重要角色
- 澳大利亚 BSD 贡献者包括 Peter Wemm（FreeBSD Core Team 成员，长期负责 FreeBSD 的 Perforce 版本管理与集群基础设施）、Bruce Evans（FreeBSD 早期贡献者，i386 架构核心开发者）、以及多位澳大利亚籍 FreeBSD/NetBSD committer。澳大利亚 BSD 贡献者在大洋洲 BSD 社区中占据主导地位
- 澳大利亚 BSD 早期部署记录是评估澳大利亚 BSD 社区起源的关键史料，澳大利亚作为英语国家，其 BSD 记录在大洋洲保存最为完整
- Sydney BSD Users Group（SBUG）是澳大利亚最大的 BSD 用户组之一，以悉尼为中心，定期举办技术讲座与安装会。SBUG 受益于悉尼作为澳大利亚最大城市与 IT 中心的地位，成员涵盖悉尼大学、UNSW 的学生与悉尼 IT 企业工程师
