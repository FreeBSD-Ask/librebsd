# 344.4 新西兰的 BSD 采用

118.4 **新西兰的 BSD 采用**———新西兰 BSD 采用以奥克兰与惠灵顿为中心，新西兰 ISP（如 Xtra、Vodafone NZ）在早期使用 FreeBSD，新西兰 BSD 社区规模较小但持续活跃
