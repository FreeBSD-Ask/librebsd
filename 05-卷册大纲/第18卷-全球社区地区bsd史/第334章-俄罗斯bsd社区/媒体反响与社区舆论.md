## 里程碑事件类

### 新闻条目 1

- **新闻标题（中英）**：Cryptographic Module Validation Program - Certificate #4282 / 加密模块验证程序——证书 #4282
- **新闻来源**：NIST CSRC 官方 CMVP + URL `<https://csrc.nist.gov/projects/cryptographic-module-validation-program/certificate/4282`>
- **新闻摘要**：OpenSSL FIPS Provider（证书编号 #4282）通过 NIST CMVP 验证，为 C 语言应用提供加密功能 API。该证书对应 OpenSSL 3.0 FIPS 模块。
- **与本章主题的关联说明**：这是 FreeBSD 通过 OpenSSL 间接获得 FIPS 140 验证的关键证书，是本章 “BSD FIPS 140 验证路径” 小节的核心一手史料，揭示 FreeBSD 通过用户态加密库而非内核模块实现 FIPS 合规的模式。
- **与官方史料的交叉验证结论**：证书位于 `csrc.nist.gov` 官方 CMVP 数据库，证书编号 #4282 与 OpenSSL 官方文档（`docs.openssl.org/master/fips/`）一致。

- **新闻来源**：FreeBSD 官方源码 + GitHub 镜像 `<https://github.com/Atlantic-OS/FreeBSD-src/blob/main/crypto/openssl/README-FIPS.md`> + 官方 cgit `<https://cgit.freebsd.org/src/plain/crypto/openssl/README-FIPS.md`>
- **新闻摘要**：FreeBSD 源码树中 OpenSSL FIPS 模块说明文档，指出加密模块须经复杂 FIPS 140 验证流程后方可称 “FIPS validated”，无法对每个 OpenSSL 小版本进行验证。如需 FIPS 验证模块，必须仅使用具有有效 FIPS 证书的 OpenSSL 版本生成 FIPS provider。
- **与本章主题的关联说明**：这是 FreeBSD 源码树中对 FIPS 140 验证的官方说明，反映 FreeBSD 项目对 FIPS 合规的严谨态度，是本章 “K 类 BSD 官方反映” 与 “FreeBSD FIPS 实施细节” 小节的核心一手史料。
- **与官方史料的交叉验证结论**：文档位于 FreeBSD 官方 cgit（`cgit.freebsd.org`）与 GitHub 镜像，与 OpenSSL 上游 README-FIPS.md 内容一致。
