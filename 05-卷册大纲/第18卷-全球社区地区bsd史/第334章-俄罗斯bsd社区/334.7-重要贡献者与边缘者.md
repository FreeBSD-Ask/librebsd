# 334.7 重要贡献者与边缘者

## 334.7.1 俄语社区核心维护者

  **要点**：俄语社区核心贡献者包括 **FreeBSD.org.ru** 俄语镜像站维护者、俄语 FreeBSD Documentation Project 长期贡献者、被遗忘的 DemOS 时代俄罗斯 Unix 先驱；具体名单须经提交日志与社区档案核查
  **史料**：FreeBSD SVN/Git 提交日志、**FreeBSD.org.ru** 镜像站历史、**Russian FreeBSD Documentation Project** 提交记录 ［A］
  **史观**：边缘者的贡献被中心叙事遮蔽，俄语社区贡献者须从提交日志与档案中重建
  **辨析**：贡献者名单是否完整须经多方档案交叉验证；“核心”与“边缘”的判定标准须明确
  **文献**：FreeBSD SVN/Git 仓库；**FreeBSD.org.ru** 镜像站档案；**Russian FreeBSD Documentation Project** 仓库 ［A］

## 334.7.2 被遗忘的 DemOS 时代先驱

  **要点**：DemOS 时代的俄罗斯 Unix 先驱是 BSD 历史中被严重遮蔽的群体；1990 年代苏联解体后这批先驱在资源匮乏的环境中引入并推广 BSD，其贡献长期被英语中心叙事忽略
  **史料**：DemOS 项目档案、参与者口述访谈、俄语技术媒体 ［B］
  **史观**：边缘者的贡献被中心叙事遮蔽，DemOS 时代先驱的贡献须从俄语档案中重建
  **辨析**：DemOS 先驱的具体名单须考据；口述访谈中当事人的记忆偏差须警惕
  **文献**：DemOS 项目档案；参与者口述访谈；俄语技术媒体 ［B］

## 334.7.3 俄罗斯 committer 的个人贡献

  **要点**：俄罗斯 committer 在 FreeBSD 主线中长期有重要贡献，尤其在性能优化与安全方向；早期 committer 因苏联数学教育传统而在算法与系统优化领域贡献突出
  **史料**：FreeBSD SVN/Git 提交日志、**freebsd-hackers** 邮件列表 ［A］
  **史观**：边缘者的贡献被中心叙事遮蔽，俄罗斯 committer 的个人贡献须从提交日志中重建
  **辨析**：个人贡献的判定须经提交日志量化分析；“苏联数学教育传统”与贡献领域的关系须谨慎表述
  **文献**：FreeBSD SVN/Git 仓库；**freebsd-hackers** 邮件列表 ［A］

## 334.7.4 俄语翻译者与文档贡献者

  **要点**：**Russian FreeBSD Documentation Project** 的长期翻译者将 FreeBSD Handbook 与 FAQ 系统化翻译为俄语；翻译者的贡献长期被代码贡献叙事遮蔽
  **史料**：**Russian FreeBSD Documentation Project** 提交记录、**freebsd-russian** 邮件列表 ［A］
  **史观**：边缘者的贡献被中心叙事遮蔽，翻译者的贡献长期被代码贡献叙事遮蔽
  **辨析**：翻译贡献者的完整名单须考据；翻译质量的评估标准需明确
  **文献**：**Russian FreeBSD Documentation Project** 仓库；**freebsd-russian** 邮件列表 ［A］

## 334.7.5 俄罗斯企业捐赠记录

  **要点**：Yandex、Mail.ru 等俄罗斯企业对 FreeBSD Foundation 的捐赠记录须经 Foundation 年度报告核查；俄罗斯企业捐赠规模因 2022 年制裁后大幅下降
  **史料**：FreeBSD Foundation 年度报告、Yandex 与 Mail.ru 企业档案 ［B］
  **史观**：总纲第 11 条——商品是形式主义，俄罗斯企业捐赠与社区贡献的关系须经量化分析
  **辨析**：捐赠金额的具体数据须经 Foundation 年度报告核查；2022 年制裁后的下降幅度须考据
  **文献**：FreeBSD Foundation 年度报告；Yandex 与 Mail.ru 企业档案 ［B］

## 334.7.6 贡献者记录的史料辨析

  **要点**：贡献者记录的史料来源包括 FreeBSD 官方名单、SVN/Git 提交日志、邮件列表、社区论坛、口述访谈；个人身份信息受隐私保护，部分记录已脱敏；俄罗斯早期贡献者的口述史尚未系统整理，存在遗失风险
  **史料**：FreeBSD 官方提交者名单、SVN/Git 提交日志、邮件列表存档、社区论坛历史数据、参与者口述访谈 ［A］
  **史观**：总纲第 10 条——动手者创造历史，贡献者记录的系统化保存是 BSD 社区史研究的基础
  **辨析**：脱敏记录的还原须经当事人同意；口述访谈中当事人的记忆偏差须警惕；早期贡献者的口述史整理须尽快推进
  **文献**：FreeBSD SVN/Git 仓库；**freebsd-committers** 邮件列表；**Habr** 历史存档 ［A］
