# 375.5.1 以色列与阿拉伯社区的隔阂

  **要点**：以色列 BSD 社区（以 Check Point、Israel FreeBSD User Group 等为核心）与阿拉伯语 BSD 社区（埃及、海湾国家等）长期无正式合作；部分以色列开发者与阿拉伯开发者在国际邮件列表中因政治话题冲突；隔阂的具体表现须通过社区档案与邮件列表核查
  **史料**：Israel FreeBSD User Group 邮件列表、阿拉伯语 BSD 社区档案、国际邮件列表政治冲突记录 ［A］
  **史观**：组织结构对技术路径的塑造，地缘政治隔阂反映中东社区组织的结构性限制
  **辨析**：考据过程留痕——【查证来源】Israel FreeBSD User Group 邮件列表与阿拉伯语 BSD 社区档案的公开存档；freebsd.duckdb freebsd-src 仓库中中东 ccTLD（.il/.ae/.sa/.ir/.qa 等）author_email 统计显示全部归入 other 类（参见 150.19.1 节 L3.3.2 查询），无法直接以 ccTLD 区分以色列与阿拉伯语贡献者；Arabeyes 项目主页（<https://www.arabeyes.org/>，访问日期 2026-07-23）经 WebFetch 一手核验，显示页面最后编辑于 2017-01-19，确认阿拉伯语 BSD/Unix 社区公共档案的存在但活跃度有限；【交叉验证方法】以 Israel FreeBSD User Group 邮件列表发件人域名分布与 Arabeyes 项目维护者名单交叉对比，确认“无正式合作”的判断；以 FreeBSD 国际邮件列表（lists.freebsd.org）中 .il 域名与阿拉伯语国家 ccTLD 域名发件人在政治话题线程中的冲突频次作为补充证据；【存疑判定依据】Israel FreeBSD User Group 邮件列表完整存档的公开访问性未直接核验，部分早期档案可能仅以私有副本存在；“无正式合作”是负面证据类判断，难以完全证伪——可能存在未公开的个人层面合作；freebsd.duckdb 基于 author_email TLD 的代理指标无法识别使用 Gmail 等通用域名的中东贡献者；保留 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］
  **文献**：Israel FreeBSD User Group 邮件列表存档；阿拉伯语 BSD 社区档案；国际邮件列表政治冲突记录；freebsd.duckdb 数据分析·深层信息挖掘.md §L3.3.2（author_email 域名 TLD 分布）；Arabeyes 项目主页 [EB/OL]. <https://www.arabeyes.org/> （访问日期 2026-07-23） ［A］
