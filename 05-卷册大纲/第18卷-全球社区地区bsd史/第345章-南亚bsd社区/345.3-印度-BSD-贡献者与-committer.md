# 345.3 印度 BSD 贡献者与 committer

122.3 **印度 BSD 贡献者与 committer**———印度 BSD 贡献者与 committer 包括 Deb Goodkin（FreeBSD Foundation 执行董事）、印度裔 FreeBSD committer（如部分 FreeBSD ports 维护者）、印度 NetBSD 贡献者

## 344.3.1 印度 BSD committer 群体概览

  **要点**：印度 BSD committer 群体涵盖 FreeBSD、NetBSD 项目，代表性人物包括 Deb Goodkin（FreeBSD Foundation 执行董事，2010 年代起任职，推动 Foundation 筹款与治理改革）、印度裔 FreeBSD committer（如部分 ports 维护者与文档贡献者）。印度 BSD committer 的人数在亚洲 BSD 社区中少于日本、韩国
  **史料**：FreeBSD committer 名单、NetBSD developer 名单、committer 个人主页 ［A］；openbsd.db 查询 L3.3.2 显示：23 仓库合计 author_email 域名 TLD 分布中 .in（印度 ccTLD）仅 625 commit / 59 贡献者，远低于 .jp（6,471/205）、.cn（9,650/591）、.au（10,866/150），且 .pk（巴基斯坦）、.lk（斯里兰卡）、.np（尼泊尔）、.bd（孟加拉国）等南亚其他 ccTLD 全部归入 other 类（未单独列出），反映南亚 BSD 贡献者在 author_email 域名维度的极度稀缺
  **史观**：总纲第 10 条——印度 BSD committer 是 “动手者创造历史” 的跨国体现
  **辨析**：印度 committer 的具体人数需统计；印度裔 committer 中居住于印度本土的比例需区分；【0 信任原则·地理识别局限·author_email 域名不等于实际地理位置】L3.3.2 基于 author_email 域名 TLD 统计，.in 仅统计邮箱后缀为 .in 的贡献者，大量印度本土贡献者使用 .com（Gmail 等）、.org、.edu（IIT 等高校）邮箱，其实际地理位置无法通过 author_email 域名识别，故 .in 625/59 严重低估印度本土实际贡献者数量；【0 信任原则·海外印度裔归因局限】Deb Goodkin 等海外印度裔 BSD 贡献者使用美国 .com/.org 邮箱，其贡献被归入 .com/.org 而非 .in，无法反映印度裔整体贡献；【0 信任原则·南亚其他 ccTLD 归入 other】.pk/.lk/.np/.bd 等南亚其他 ccTLD 因贡献者数量过少被归入 other 类，无法单独统计，反映南亚 BSD 社区在 author_email 域名维度的数据严重缺失
  **文献**：FreeBSD Committers List；NetBSD Developers List ［A］；openbsd.db 查询 L3.3.2（author_email 域名 TLD 分布，16 行结果），见 `原材料/研究/bsd仓库分析/数据分析/深层信息挖掘.md` §L3.3.2

## 344.3.2 Deb Goodkin 与 FreeBSD Foundation

  **要点**：Deb Goodkin 是 FreeBSD Foundation 的执行董事，自 2010 年代起领导 Foundation 的筹款、治理、社区外联工作。Deb Goodkin 在推动 FreeBSD Foundation 从科罗拉多州博尔德注册的 501(c)(3) 组织发展为全球 BSD 筹款与治理核心机构方面发挥了关键作用
  **史料**：Deb Goodkin 个人主页、FreeBSD Foundation 年报、Foundation 治理记录 ［B］
  **史观**：总纲第 10 条——Deb Goodkin 是印度裔 BSD 社区 “动手者” 的典型代表
  **辨析**：Deb Goodkin 的具体任职时间需考据；Foundation 治理改革的具体内容需分析
  **文献**：FreeBSD Foundation 年报；Deb Goodkin 个人主页 ［B］

## 344.3.3 印度 NetBSD 与 OpenBSD 贡献者

  **要点**：印度在 NetBSD 项目中有少量贡献者（如部分 NetBSD 内核驱动开发者），在 OpenBSD 项目中印度贡献者极为稀少。印度 BSD 贡献者的分布以 FreeBSD 为主体，NetBSD 与 OpenBSD 在印度的社区规模极小
  **史料**：NetBSD developer 名单、OpenBSD contributor 名单、印度 BSD 社区贡献者统计[考据完成：2026-07-28 经穷尽联网考据，上述史料清单为已知公开来源汇总，部分原始档案未公开数字化或须档案馆藏地现场核验，属史料缺口，须待原始档案公开后方可补充确证]〔L3 官方文档与公告/L5 二手研究〕
  **史观**：总纲第 8 条——印度 BSD 贡献者分布的不均衡反映了各 BSD 项目在印度的接受度差异
  **辨析**：NetBSD/OpenBSD 在印度的低接受度原因需分析；是否与印度 IT 产业特点有关需考据
