# 345.1 印度的 BSD 采用：从 IIT 到 IT 产业

122.1 **印度的 BSD 采用：从 IIT 到 IT 产业**———印度 BSD 的采用始于 1990 年代 IIT（印度理工学院）各校区的 UNIX 研究传统，印度 IT 产业（Infosys、TCS、Wipro 等）在早期基础设施建设中使用 FreeBSD，印度互联网早期（ERNET、VSNL）有 FreeBSD 部署
