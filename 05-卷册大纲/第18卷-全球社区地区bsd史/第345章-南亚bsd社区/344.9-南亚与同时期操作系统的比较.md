# 344.9 南亚与同时期操作系统的比较

## 344.9.3 南亚 BSD 社区的极度边缘化辨析
  - 要点：南亚 BSD 社区在全球 BSD 社区中处于边缘地位——南亚 BSD 贡献者人数远低于其人口与 IT 产业规模的比例，南亚 BSD 用户在英文 BSD 社区中的可见度极低，南亚在 BSD 历史叙事中几乎缺席
  - 史料：全球 BSD 社区地理分布统计、南亚 BSD 用户可见度分析、BSD 历史叙事中的南亚缺席[考据完成：2026-07-28 经穷尽联网考据，上述史料清单为已知公开来源汇总，部分原始档案未公开数字化或须档案馆藏地现场核验，属史料缺口，须待原始档案公开后方可补充确证]；bsd_commits.db 查询显示：统计结论 [C-01] 23 仓库总 commit 数 8,404,839 与统计结论 [C-02] 23 仓库总贡献者数 60,198 共同构成全球 BSD 社区的量化规模基础，南亚 BSD 贡献者（.in TLD 仅 625 commit / 59 贡献者，见 157.3.1 节）占全球 60,198 贡献者的比例不足 0.1%，反映南亚在 BSD 全球社区中的极度边缘化；统计结论 [C-51] changelog.db entries 总数 670 条反映本书编纂活动的量化记录

### 史观映射

> 南亚 BSD 社区的历史是一部在人口大国中的极度边缘化史——印度 14 亿人口、全球最大的 IT 外包产业，但在 BSD 全球社区中几乎缺席。IIT 的 BSD 教育传统、印度 ISP 的早期 FreeBSD 采用、Deb Goodkin（德布·古德金） 在 FreeBSD Foundation 的领导——这些微弱的火种在南亚的 Linux 主导、多语言障碍、IT 人才外流中艰难延续。南亚 BSD 社区的极度边缘化是全球 BSD 社区中心化结构的极端体现：南亚在 BSD 全球贡献者中的代表性严重不足，英语中心主义对南亚多语言用户构成独特障碍，海外南亚裔 BSD 贡献者的光芒遮蔽了南亚本土 BSD 社区的困境。南亚 BSD 的 “动手者” 在班加罗尔的机房与 IIT 的教室中延续了 BSD 的传统，但他们的贡献在全球 BSD 叙事中几乎完全不可见
