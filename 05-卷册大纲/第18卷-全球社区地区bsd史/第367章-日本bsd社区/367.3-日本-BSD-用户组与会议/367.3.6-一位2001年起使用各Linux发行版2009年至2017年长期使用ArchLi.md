# 367.3.6 一位2001年起使用各Linux发行版2009年至2017年长期使用ArchLi

- 一位 2001 年起使用各 Linux 发行版、2009 年至 2017 年长期使用 Arch Linux 的用户因 systemd 的推行方式与发行版组织哲学（进程日益不透明、共同开发的应用集合被机制耦合）决意脱离 Linux，先在朋友推荐下于 FreeBSD 11 服务器运行 Postgres、RabbitMQ、nginx 与 JVM 进程约三个月，再因笔记本芯片组驱动缺口选中承接 PC-BSD 血统、基于 FreeBSD 12-CURRENT 并集成最新驱动的 TrueOS；八个月体验中其留下的理由是 OpenRC 熟悉且有完善文档（本人两小时写出 Postgres 10 脚本）、ZFS boot environments 的回滚能力（由此确信 ZFS 价值）、base 系统与应用分离的文件系统布局（认为做 “怪异之事” 的是 Linux 发行版一方）、Handbook 文档质量与 Telegram/Discourse 社区的友好（核心开发者常驻）；同时坦承 Netflix、Google Hangouts 与 Electron 应用不可用系上游而非 TrueOS 之过，并称迁移带来哲学转变——在 BSD 许可证与 GPL 之间更认同前者，因其 “更实用”。（YouTube EP_6gNefiY6hU，[2515.8-2972.7]，L1）[订正：原“2009 年后长期使用 Arch Linux”→“2009 年至 2017 年长期使用 Arch Linux”，字幕明确 until twenty seventeen；原“OpenRC 的可文档化”→“OpenRC 熟悉且有完善文档”，字幕原文为 the init system that is familiar and well documented，原译方向反了；时间戳原 [2516.53-2969.63]→[2515.8-2972.7]，Linux 发行版使用史段自 2515.8 起、BSD 许可证更实用结论止于 2972.7，原终点截入该段中部]
