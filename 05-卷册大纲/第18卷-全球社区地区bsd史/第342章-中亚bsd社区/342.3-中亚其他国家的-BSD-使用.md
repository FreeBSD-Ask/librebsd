# 342.3 中亚其他国家的 BSD 使用

115.3 **中亚其他国家的 BSD 使用**———吉尔吉斯斯坦、塔吉克斯坦、土库曼斯坦的 BSD 使用情况极为稀少，受到互联网基础设施落后、IT 人才外流、俄语/英语技术资料获取困难等因素制约
