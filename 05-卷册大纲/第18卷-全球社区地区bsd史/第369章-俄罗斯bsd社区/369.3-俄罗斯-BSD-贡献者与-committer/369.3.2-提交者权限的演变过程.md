# 369.3.2 提交者权限的演变过程

  **要点**：俄罗斯 committer 权限演变分三阶段——1995-2005 年的零星授予期、2006-2015 年的稳定增长期、2016 年后的多元化期；2022 年制裁后俄罗斯 committer 权限是否受影响须经 FreeBSD Core Team 公开声明核查
  **史料**：FreeBSD 提交者历史名单、SVN/Git 提交日志统计、FreeBSD Core Team 公开声明 ［A］
  **史观**：技术路线的分化与并行演化，俄罗斯 committer 增长节奏与社区发展节奏不同步
  **辨析**：三阶段划分须经提交日志量化分析核查；2022 年制裁对俄罗斯 committer 的影响须考据
  **文献**：FreeBSD SVN/Git 仓库；FreeBSD Core Team 选举档案与公开声明；freebsd-committers 邮件列表 ［A］
