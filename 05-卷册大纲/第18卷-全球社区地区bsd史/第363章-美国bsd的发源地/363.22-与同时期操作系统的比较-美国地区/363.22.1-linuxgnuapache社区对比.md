# 363.22.1 Linux/GNU/Apache 社区对比


与美国同期其他操作系统社区的对比——Linux 社区（Linus Torvalds 2003 年移居美国后 Linux Foundation 在美国注册运营、Red Hat/Canonical/IBM 等美国企业主导）、GNU 项目（FSF 1985 年于波士顿成立，GPL 法律框架在美国成型）、Apache 社区（ASF 1999 年于特拉华州注册）、Python 社区（PSF 2001 年于特拉华州注册）、Node.js 社区（OpenJS Foundation 2019 年注册）、Rust 社区（Rust Foundation 2021 年于美国注册）——美国作为全球开源社区法律实体的主要注册地的地缘优势与税务驱动的深层结构

**要点**：Linux（Linux Foundation 2007 美国注册，由 OSDL 与 Free Standards Group 于 2007-01-22 合并成立）[修正脚注]、GNU（FSF 1985 波士顿）、Apache（ASF 1999 特拉华）等社区均在美国注册

| 社区 | 基金会 | 注册时间 | 注册地 | 法律地位 |
| -- | ---- | ------ | ---- | ------ |
| Linux | Linux Foundation | 2007 | 美国 | 501(c)(6) 商业联盟 |
| GNU | FSF | 1985 | 波士顿 | 501(c)(3) 公益慈善 |
| Apache | ASF | 1999 | 特拉华 | 501(c)(3) 公益慈善 |
| Python | PSF | 2001 | 特拉华 | 501(c)(3) 公益慈善 |
| Node.js | OpenJS Foundation | 2019 | 美国 | 501(c)(6) 商业联盟 |
| Rust | Rust Foundation | 2021 | 美国 | 501(c)(6) 商业联盟 |
| FreeBSD | FreeBSD Foundation | 2000-03-19 | 科罗拉多州 Boulder | 501(c)(3) 公益慈善 |
