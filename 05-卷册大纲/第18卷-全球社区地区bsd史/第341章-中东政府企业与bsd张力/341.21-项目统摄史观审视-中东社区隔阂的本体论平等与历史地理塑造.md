# 341.21 项目统摄史观审视：中东社区隔阂的本体论平等与历史地理塑造

- 341.21 项目统摄史观审视：中东社区隔阂的本体论平等与历史地理塑造
  **要点**：从项目史观总纲审视，中东 BSD 社区隔阂的批评、反批评与再批评各方（以色列 BSD 社区、阿拉伯语 BSD 社区、Iran FreeBSD User Group、Turkey LKD、地缘政治约束论者、技术社区碎片化批评者、文化隔阂合理化论者、合作改革倡导者）在本体论上地位相等——其一，偶然性视角（总纲第 5 条“没有必然性，只有偶然性”）：以色列 BSD 社区与阿拉伯语社区的隔阂是偶然性事件的具体显现——1948 年以色列建国后的地缘政治对立、2001 年 Arabeyes 项目的成立、2010-2012 年阿拉伯之春、2017 年 1 月 19 日 Arabeyes 项目最后编辑、2017 年 2 月 21 日 Arabeyes 迁移至 GitLab、2020 年《亚伯拉罕协议》后以色列与阿联酋、巴林关系正常化等皆是偶然性事件——若 1948 年以色列未建国、若 2001 年 Arabeyes 项目未成立、若 2017 年 Arabeyes 未停止更新、若 2020 年《亚伯拉罕协议》未签署，中东 BSD 社区隔阂的具体形态将根本不同；Israel FreeBSD User Group 与 Arabeyes 项目的兴衰对照（前者持续活跃，后者 2017 年后停滞）亦是偶然性事件塑造社区生态的具体显现，而非中东 BSD 社区发展的必然规律；其二，本体论平等视角（总纲第 8 条“本体论上各方平等”）：以色列 BSD 社区与阿拉伯语 BSD 社区、Check Point 与 Arabeyes、希伯来语技术文档与阿拉伯语技术文档、犹太-世俗文化与伊斯兰文化在本体论上地位相等，各方皆是 BSD 谱系在中东地理内的一刻状态——Check Point 的工程文化与 Arabeyes 的本地化工作各自在其生态内合理，差异是地理与历史语境的不同而非本体等级的高下；Israel FreeBSD User Group 的活跃与 Arabeyes 项目的停滞各自在其资源条件下合理，差异是志愿者供给与社区结构的不同而非本体等级的高下；地缘政治约束论者与技术社区碎片化批评者在本体论上地位相等，二者皆是中东 BSD 社区发展实践的一刻状态；其三，解释学循环与权力知识共谋视角（总纲第 19 条“解释学循环是历史认识的根本条件”）：中东社区隔阂的历史认识受前理解差异制约——反批评者以“地缘政治约束”为前理解，再批评者以“碎片化代价”为前理解，以色列 BSD 社区成员以“技术能力优先”为前理解，阿拉伯语 BSD 社区成员以“语言资源不对称”为前理解，外部观察者以“开源普世主义”为前理解，五者难以通约；权力与知识在 FreeBSD 中东社区隔阂的历史书写中共谋——以色列 BSD 社区叙事（如 Israel FreeBSD User Group 邮件列表、Check Point 公司史）与阿拉伯语 BSD 社区叙事（如 Arabeyes 项目档案、阿拉伯语技术社区论坛）在“什么被记录、什么被遗忘”上本身就是权力行使，本节（341.15-341.20 辩证链诸节〔旧号 341.14.1-341.14.4、341.14a、341.14b、341.14c〕、341.21）的辩证链补足与项目统摄史观审视即是试图打破单一叙事的权力垄断，使以色列 BSD 社区阵营与阿拉伯语 BSD 社区阵营的论点对称呈现；解释学循环亦适用于本审视自身——项目统摄史观审视嵌入项目统摄史观的前理解，须自觉呈现这一前理解而非伪装中立，合图（辩证链合图层，旧号 341.14c）不是辩证链的终结而是阶段性综合，随中东地缘政治演化（如《亚伯拉罕协议》后以色列与海湾国家关系变化）与 Arabeyes 项目状态变化须重新展开；其四，法律与道德是利益分配视角（总纲第 13 条“法律与道德是利益分配”）：中东 BSD 社区隔阂的法律与道德层面本质上是利益分配问题——其一，地缘政治约束下的法律利益分配：美国出口管制条例（EAR）与 OFAC 制裁清单将伊朗、叙利亚等国开发者排除在 FreeBSD Foundation 的合规贡献渠道之外，这一法律安排名义上是“国家安全”的道德要求，实质上是美国国家利益分配机制的形式主义化——受制裁国家开发者的技术参与权被剥夺，而以色列开发者因以色列与美国同盟关系享有完全的参与权，地缘政治约束下的法律利益分配直接塑造了 Israel FreeBSD User Group 与 Arabeyes 项目（特别是伊朗 FreeBSD 社区）的活跃度对照；其二，社区治理的道德形式主义：反批评者以“地缘政治约束”为前理解将隔阂合理化，再批评者以“碎片化代价”为前理解质疑合理化——二者的分歧本质上是“规避法律风险的利益”与“合作收益的利益”之间的分配冲突，道德话语（“社区准则”“技术能力优先”）是利益分配的形式主义化显现；其三，本地化资源的利益分配：希伯来语技术文档在以色列高校（Technion、TAU、HUJI）与 Israel FreeBSD User Group 内部积累，阿拉伯语技术文档依赖 Arabeyes 项目（2001 年成立，2017 年后停滞）的翻译工作——二者的资源分配差异反映以色列与阿拉伯语国家在 IT 产业基础、教育体系、志愿者供给等利益分配结构上的不对称，Arabeyes 项目的停滞是阿拉伯语本地化资源分配不足的具体显现，而非阿拉伯语社区“不重视本地化”的道德判断；其四，Check Point 的工程文化与 8200 部队的联系是以色列军事工业复合体利益分配结构的产物——8200 部队培养的工程文化进入 Check Point 等商业公司，形成“军事训练—商业就业—开源贡献”的循环，这一利益分配结构在阿拉伯语国家因军事工业基础差异无对应模式，Check Point 1993 年在以色列创立（具体日期“6 月 5 日”与地点“拉马特甘”未在 Check Point 官方页面一手核验，须以 SEC 上市文件或早期公司档案核验）是以色列军事工业复合体利益分配结构的具体显现

### 史观映射

> 中东的 BSD 社区揭示了一种哲学维度的极限情境——当技术社区在战乱、制裁与宗教管制的夹缝中求存时，技术本身便被赋予了准信仰的属性：服务器的不宕机不只是运维指标，而是一种存在确证；代码的提交不只是版本控制，而是对荒诞环境的微小抵抗。地缘政治塑造了中东技术社区的独特形态——以色列的 BSD 社区在军事工业复合体中萌芽，伊朗的 BSD 用户在制裁下通过地下网络获取软件，海湾国家的 BSD 部署在石油财富与宗教律法的双重约束中寻找空间。“世上没有真正的净土，唯有靠自己的努力”——这句净土与信仰的命题在中东获得了最字面化的诠释：BSD 许可证的宽松性使其成为少数不受制裁严格限制的开源选择，但这不是因为许可证的设计者预见到了地缘政治的困局，而是因为“自由”的形式主义化在法律层面恰好留下了缝隙。中东社区对“自由软件”的前理解因而是双重的——既承载着西方自由主义的话语，又叠加着本土对“自由”的宗教与政治理解
