# 341.19 重要贡献者与边缘者：以色列早期 adopter 与伊朗地下镜像维护者

## 341.19.1 以色列早期 adopter 与伊朗镜像维护者

  **要点**：以色列早期 adopter（Check Point 工程师、Israel FreeBSD User Group 维护者等）维持了中东最大 BSD 社区的运作；伊朗地下镜像维护者在制裁下通过地下网络分发 BSD 源码与文档；贡献的具体内容须通过社区档案与个人访谈核查
  **史料**：Israel FreeBSD User Group 邮件列表存档、Check Point 企业档案、伊朗地下镜像维护者访谈 ［A］；**openbsd.duckdb**（原 **bsd_commits.db** 数据集拆分库）查询 L3.3.2 显示：author_email TLD 分布中中东 ccTLD（.il 以色列/.ae 阿联酋/.sa 沙特/.ir 伊朗/.qa 卡塔尔 等）均未单独列出，全部归入 other 类（other 类合计 1,277,384 commit / 4,252 unique emails），表明中东 ccTLD 邮箱在 22 仓库中占比极低，与中东作为 BSD 技术绿洲但仍属边缘的定位相符
  **史观**：总纲第 10 条——边缘者的贡献被中心叙事遮蔽，以色列早期 adopter 与伊朗地下镜像维护者的工作在 BSD 全球叙事中长期被忽视；统计结论印证：统计结论 [L3.3.1] 时区分布中东主要时区 +03:00 74,576 commit / 3,977 贡献者（与俄罗斯莫斯科、东非共用）与 +04:00 与俄罗斯萨马拉共用无法单独区分中东贡献者，与统计结论 [L3.3.2] TLD 分布中东 ccTLD（.il/.ae/.sa/.ir/.qa 等）全部归入 other 类（other 类合计 1,277,384 commit / 4,252 unique emails）共同印证中东作为 BSD 技术绿洲但仍属量化边缘地带的张力，与本节（341.19.1）要点所述“以色列早期 adopter 与伊朗地下镜像维护者的工作在 BSD 全球叙事中长期被忽视”在数据层面形成“叙事存在但量化缺失”的张力——中东 BSD 社区以 Check Point、Israel FreeBSD User Group 等机构存在但中东 ccTLD 邮箱在 22 仓库中占比极低，反映总纲第 10 条边缘者批评的量化印证；**freebsd.duckdb**（原 **bsd_commits.db** 数据集拆分库，原数据集覆盖 freebsd-src 等 22 仓库）L3.3.1/L3.3.2 查询：commit author_email 时区推断与 TLD 提取
  **辨析**：以色列早期 adopter 名单须通过 Israel FreeBSD User Group 邮件列表核实；伊朗地下镜像维护者的实际情况因安全限制难以完全核查；【0 信任原则·地理识别局限】author_email TLD 不等于实际地理位置，中东 ccTLD 全部归入 other 类意味着中东贡献者数据严重缺失，且中东时区 +03:00 与欧洲、俄罗斯共用，+04:00 与俄罗斯萨马拉共用，时区偏移无法区分中东与欧洲/俄罗斯贡献者，时区偏移不等于居住地，远程办公、VPN、移民等因素使时区—地理位置映射须慎重；【0 信任原则·author 字段可伪造】L3.3.2 基于 author_email 统计，中东 ccTLD 数据缺失可能因中东贡献者多使用 .com 邮箱（如 Gmail）或公司邮箱（如 @checkpoint.com）提交，未计入中东 ccTLD；【0 信任原则·committer_date 异常】L3.3.1 基于 committer_date 提取时区偏移，但 GitHub 镜像仓库的 committer_date 可能被重写为同步时间，分析时须改用 author_date 复核；【统计显著 ≠ 实际显著】中东 ccTLD 全部归入 other 类不直接等同于“中东社区贡献度低”，须结合 Check Point 等以色列安全公司技术产出、伊朗地下镜像维护者地下分发网络等地缘政治结构性变量综合判断，统计显著性与实际显著性须区分；详见 **03-原始史料库/01-代码仓库史料/01-数据库本体/统计分析/数据库大纲交叉对照表/05-第三节-L系列抽样对照表.md** L3.3.1/L3.3.2 对照条目；考据记录 20260727_第十二卷-统计学整合.md 已按源文件清理规则入库 **03-原始史料库/original_sources.duckdb**
  **文献**：Israel FreeBSD User Group 邮件列表存档；Check Point 企业档案；伊朗地下镜像维护者访谈记录 ［A］；**openbsd.duckdb**（原 **bsd_commits.db** 数据集拆分库）查询 L3.3.2（author_email 域名 TLD 分布，22 仓库合计，16 行结果），见 **03-原始史料库/01-代码仓库史料/01-数据库本体/统计分析/数据库大纲交叉对照表/05-第三节-L系列抽样对照表.md**（原报告深层信息挖掘.md 已随旧工作区清理移除，L3.3.2 对照条目见该表）

## 341.19.2 贡献者从活跃到边缘的演变

  **要点**：中东 BSD 贡献者多从学生时代或工程师生涯活跃，后因就业压力、地缘政治限制、人才外流等转向其他领域；Israel FreeBSD User Group 活跃度在 2000 年代中期达峰后下滑；演变须通过邮件列表活跃度统计验证
  **史料**：Israel FreeBSD User Group 邮件列表活跃度统计、贡献者个人访谈、中东 IT 就业市场数据 ［A］
  **史观**：总纲第 10 条——边缘者的贡献被中心叙事遮蔽，贡献者的边缘化反映 BSD 在中东产业中的弱势
  **辨析**：贡献者边缘化的原因须具体分析——就业压力、地缘政治限制、人才外流等；“活跃度下滑”须量化
  **文献**：Israel FreeBSD User Group 邮件列表存档；贡献者访谈；中东 IT 就业市场报告 ［A］
