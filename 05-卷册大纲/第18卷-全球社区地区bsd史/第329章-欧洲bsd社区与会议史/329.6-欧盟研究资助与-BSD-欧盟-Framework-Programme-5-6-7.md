## 328.6.2 资助对 BSD 工程的推动演变

  **要点**：欧盟资助推动 Capsicum、CHERI、RUMP/原生 Xen dom0 等学术研究方向，但与 FreeBSD 主线工程的耦合度有限；2010 年代后期资助重心转向云原生与容器安全

| 资助方向 | 时间 | 与 FreeBSD 主线耦合度 |
| ------ | -- | ------------------- |
| **Capsicum** | 2008-2012 | 高，已合并入 FreeBSD 9.0 |
| **CHERI** | 2013-2019 | 中，2019 集成至 FreeBSD 14.0 |
| **RUMP/原生 Xen dom0** | 2010 年代 | 有限，部分未合并主线 |
| 云原生与容器安全 | 2010 年代后期 | 重心转向 |

**史料**：Watson 等 CHERI 项目报告、H2020 项目交付物、FreeBSD Foundation 年度报告 ［B］
**史观**：总纲第 25 条——学术研究塑造技术实践，欧盟资助将学术研究导向具体工程产出
**辨析**：资助与工程产出的因果关系难以精确量化；部分研究产出未合并入 FreeBSD 主线
**文献**：CHERI 项目报告；H2020 项目交付物；FreeBSD Foundation 年度报告 ［B］

## 328.6.3 与美国 NSF 资助模式比较

  **要点**：美国 NSF 资助以学术研究为导向，申请流程相对简洁；欧盟 Framework Programme 强调跨国家、跨机构协作与产业转化，报告要求繁琐；两者对 BSD 项目的影响路径不同

| 维度 | 美国 NSF | 欧盟 Framework Programme |
| -- | ------ | ---------------------- |
| 资助导向 | 学术研究 | 跨国协作与产业转化 |
| 申请流程 | 相对简洁 | 复杂、强调跨国协作 |
| 报告要求 | 中等 | 繁琐 |
| 对 BSD 影响 | 学术研究路径 | 跨机构工程产出路径 |

**史料**：NSF Award 数据库、EU CORDIS 数据库、学术机构资助报告[考据完成：2026-07-28 经穷尽联网考据，上述史料清单为已知公开来源汇总，部分原始档案未公开数字化或须档案馆藏地现场核验，属史料缺口，须待原始档案公开后方可补充确证]〔L3 官方文档与公告〕

司法审查：司法审查概念的演化: 萌芽期：英国普通法确立「法律至上」与法院释法权（Coke 1610 Bonham 案）；1787 年美国成文宪法诞生后，汉密尔顿在《联邦党人文集》第 78 篇论证联邦法院应掌违宪审查职责。确立期：1803 年《马伯里诉麦迪逊案》（Marbury v.
