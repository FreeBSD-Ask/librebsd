## 文献增补（基于参考文献数据库）

### 观点

- 王志强等指出开源许可证以法律形式规范开源软件的使用、复制、修改和分发行为，不同许可证在原作品及衍生作品是否须按原许可证发布、是否须公开源代码、是否授予专利权等方面有不同规定——此观点与本章 326.9 节“欧洲法律框架对 BSD 许可证的效应”中欧盟 Software Directive 91/250/EEC 与开源许可证可执行性判例法的讨论形成法律视角的对照。（王志强等， 2022）
- Tymoshchuk 等将 FreeBSD 列为网络安全训练模拟环境的操作系统选项之一，与 Parrot Security OS、Ubuntu Linux、Oracle Linux 等并列，反映 FreeBSD 在欧洲学术与工程交汇语境下的实际部署地位——此观点呼应本章 326.4 节“欧洲 ISP 与学术机构部署”中欧洲学术网络部署 FreeBSD 的历史叙事。（Tymoshchuk 等， 2024）

### 不同观点

- 王志强等侧重从法律合规视角分析开源许可证（强调许可证条款的约束力与违规案例的法律后果），而 Tymoshchuk 等侧重从技术实用视角看待 FreeBSD（作为安全训练平台的工具属性），两者对 BSD 在欧洲的角色呈现法律合规与技术实用两种不可通约的视角——此分歧映射本章 326.8 节“欧洲对自由软件概念的理解”中 FSFE 与 GNU/FSF 美国本部在“Open Source”与“Free Software”话语权重上的理念分歧。（单一文献支撑，需后续交叉验证）

### 说明

- 王志强等说明经 Black Duck KnowledgeBase 统计，已存在的相关许可证超过 2600 份，但经 OSI 批准的仅 121 份；2020 年 2 月中国木兰宽松许可证 v2 正式获 OSI 认证为“国际类别开源许可证”——此量化数据为本章 326.8 节“欧洲对自由软件概念的理解”中欧洲对“Open Source”与“Free Software”话语权重偏好的讨论提供了全球许可证生态的背景参照。（王志强等， 2022）
- Tymoshchuk 等说明该网络安全训练系统使用 Xen 与 KVM 等开源 hypervisor 部署虚拟机，支持 packet filtering、VPN、load balancing 与 Snort 等安全配置——此技术说明为本章 326.3 节“丹麦 Poul-Henning Kamp（波尔-亨宁·坎普）（phk）的核心贡献”中 phk 基于 FreeBSD 开发 Varnish HTTP Accelerator 的欧洲 BSD 工程传统提供了当代延续的技术脉络。（Tymoshchuk 等， 2024）

### 批评

- 王志强等批评开源许可证违规案例中存在未按双重许可执行的情况——以 MySQL 为例，其免费版基于 GPL 许可证发布，但接收者若既不按 GPL 分发也不购买商业授权而将作品基于其他许可证分发，则属于禁止行为——此类违规案例对本章 326.10 节“欧洲 BSD 相关诉讼与争议”中 Patrick McHardy 2016-2017 年针对德国企业的 GPL 许可证诉讼潮具有直接的警示意义。（王志强等， 2022）

### 褒奖

- 王志强等肯定开源运动打破了传统软件开发的封闭模式，开源许可证以法律形式保护开源软件知识产权不受侵害并规范开发者对开源软件的使用——此褒奖呼应本章 326.7 节“欧洲各国 BSD 用户组”中德国 GUUG（1984 年成立）、荷兰 NLnet Foundation（1989 年成立，1997 年获荷兰邮政彩票 5000 万荷兰盾资助）等欧洲开源社区长期推动自由软件制度化的历史努力。（王志强等， 2022）
