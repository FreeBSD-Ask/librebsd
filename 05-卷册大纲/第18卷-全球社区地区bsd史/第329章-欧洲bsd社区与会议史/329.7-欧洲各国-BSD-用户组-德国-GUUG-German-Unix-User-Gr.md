## 328.7.2 用户组的演变与消长

  **要点**：1990 年代用户组以本地会议、邮件列表为主，2000 年代后随互联网普及逐渐式微，部分用户组转型为综合性开源社区或合并入 Linux 用户组；东欧用户组在 1989 年后随政治转型兴起
  **史料**：用户组会议记录、邮件列表存档、社区成员访谈 ［A］
  **史观**：总纲第 4 条——分离是新的聚合的开始，用户组的消亡常伴随社区形态的转型
  **辨析**：用户组 “消亡” 的判定标准需明确——是停止活动还是合并入其他组织；东欧用户组兴起与政治转型的因果关系需谨慎表述
  **文献**：用户组邮件列表存档；社区成员访谈；EuroBSDCon 历届会议记录 ［A］

## 328.7.3 与 Linux 用户组的比较

  **要点**：欧洲 Linux 用户组（如德国 LinuxTag 1996 年首届、法国 Solution Linux 1999 年首届）规模普遍大于 BSD 用户组，商业赞助更充裕；BSD 用户组更注重技术深度与学术传统

| 维度 | 欧洲 Linux 用户组 | 欧洲 BSD 用户组 |
| -- | --------------- | ------------- |
| 规模 | 较大 | 较小 |
| 商业赞助 | 充裕 | 有限 |
| 技术焦点 | 商业实用主义 | 技术深度与学术传统 |
| 代表会议 | 德国 LinuxTag（1996 首届）、法国 Solution Linux（1999 首届） | EuroBSDCon（2001 首届） |
