# 332.2 KAME 项目：IPv6 与 IPsec 的 BSD 实现（1998-2006）

108.2 **KAME 项目：IPv6 与 IPsec 的 BSD 实现（1998-2006）**———KAME 项目 1998 年由 Keio University 的 Jun-ichiro itojun Hagino 等人发起，由日本总务省（MIC）下属的通信综合研究所（CRL）与 WIDE 项目资助，在 FreeBSD/NetBSD/OpenBSD 上实现 IPv6 与 IPsec 协议栈，2006 年完成使命终止

## 331.2.1 KAME 项目的发起与组织

  **要点**：KAME 项目 1998 年由 Jun-ichiro itojun Hagino（Keio 大学）、Shoichi Sakane（Yokogawa Electric）、Yoshinobu Inoue（Toshiba）等人发起，得到日本通信综合研究所（CRL）与 WIDE 项目资助，是日本学术界对 BSD 最具影响力的贡献。KAME 名字取自 "KAME"（龟），象征 “龟虽慢但稳”，与 IPv6 的长期部署目标相呼应。
  **史料**：KAME 项目官网 Archive、Itojun Hagino 个人主页、CRL 资助记录、WIDE 项目文档[考据完成：2026-07-28 经穷尽联网考据，上述史料清单为已知公开来源汇总，部分原始档案未公开数字化或须档案馆藏地现场核验，属史料缺口，须待原始档案公开后方可补充确证]〔L3 官方文档与公告/L4 事后叙述〕
  **史观**：总纲第 10 条——日本学术界的 “动手者” 通过 KAME 项目塑造了 IPv6 的全球部署路径

## 331.2.2 IPv6 协议栈的 BSD 实现

  **要点**：KAME 项目在 FreeBSD、NetBSD、OpenBSD 上实现了完整的 IPv6 协议栈，包括邻居发现协议（NDP）、地址自动配置（SLAAC）、IPv6 over IPv4 隧道、多播侦听器发现（MLD）等。KAME 的 IPv6 代码于 2002-2004 年逐步合并入 FreeBSD src tree（FreeBSD 4.0 起），KAME 的 IPv6 栈成为 Linux 以外最成熟的 IPv6 实现之一。
  **史料**：KAME IPv6 源代码（FreeBSD src tree）、KAME 发布公告、IETF IPv6 相关 RFC 实现记录 ［A］
  **史观**：总纲第 12 条——KAME 的 IPv6 实现将日本学术研究转化为全球技术标准的具体执行
  **辨析**：KAME 代码合并入 FreeBSD 的具体时间节点需考据；KAME 与 Linux USAGI 项目的关系需分析
  **文献**：KAME IPv6 Source Code (FreeBSD src)；IETF RFC 2460/4861/4862 实现记录 ［A］

## 331.2.3 IPsec 实现与安全贡献

  **要点**：KAME 项目同时实现了 IPsec 协议栈（AH 与 ESP），包括 IKE 密钥管理协议（racoon 守护进程），KAME 的 IPsec 实现于 2000 年代初期被 FreeBSD/NetBSD/OpenBSD 广泛采用，racoon 成为 BSD 系统 IPsec 的标准 IKE 实现直至 2010 年代被 strongSwan 替代
  **史料**：KAME IPsec 源代码、racoon 守护进程文档、FreeBSD IPsec 手册页 ［A］
  **史观**：总纲第 12 条——KAME 的 IPsec 实现是日本安全研究对全球 BSD 社区的直接贡献
  **辨析**：racoon 的考据记录需区分 KAME 原版与后续维护版本；IKEv1 与 IKEv2 的过渡时间需考据
  **文献**：KAME IPsec Source Code；racoon(8) Manual Page ［A］
