# 332.5 日本企业的 BSD 部署

108.5 **日本企业的 BSD 部署**———IIJ（Internet Initiative Japan）1992 年起大量使用 FreeBSD 作为骨干路由器与邮件服务器、NTT（日本电信电话）的部分服务器、Yahoo! Japan 的早期基础设施、Sony 的 BSD 使用（PlayStation 操作系统）、任天堂的 BSD 使用（Nintendo Switch 部分网络服务）

## 331.5.1 IIJ 与日本 ISP 的 BSD 部署

  **要点**：IIJ（Internet Initiative Japan）1992 年成立，由 Jun Murai 教授（WIDE 项目创始人）创立，早期骨干路由器与邮件服务器大量使用 FreeBSD。IIJ 的技术团队（如 Kenjiro Cho 等人）对 FreeBSD 网络栈（特别是 ALTQ 流量整形）进行了深度定制，部分代码回馈入 FreeBSD 内核
  **史料**：IIJ 技术文档、Kenjiro Cho 的 ALTQ 论文与代码、IIJ 系统架构记录 ［A］
  **史观**：总纲第 10 条——IIJ 是日本企业 “动手” 参与 BSD 内核开发的标杆
  **辨析**：IIJ 使用 FreeBSD 的具体规模与时间范围需考据；ALTQ 代码的回馈比例需分析
  **文献**：IIJ 技术报告（1992-2010）；Kenjiro Cho, ALTQ 论文（USENIX 1999） ［B］

## 331.5.2 Sony 与任天堂的 BSD 使用

  **要点**：Sony PlayStation 3/4/5 操作系统基于 FreeBSD 内核（CellOS 与 Orbis OS），Sony 自 2006 年 PS3 起即使用 FreeBSD 作为游戏机操作系统基础。任天堂 Nintendo Switch 的部分网络服务（如 NPLN）运行于 FreeBSD 服务器，任天堂 2017 年向 FreeBSD Foundation 做出捐赠
  **史料**：Sony PS3/PS4/PS5 系统文档、FreeBSD Foundation 捐赠记录、任天堂技术访谈 ［B］
  **史观**：总纲第 11 条——日本游戏机产业对 BSD 的商业采用是形式主义市场选择
  **辨析**：Sony PlayStation 各版本 BSD 内核的具体定制程度需考据；任天堂 BSD 部署的规模需评估

## 331.5.3 Yahoo! Japan 与大型企业的 BSD 采用

  **要点**：Yahoo! Japan 的早期基础设施（2000 年代）曾使用 FreeBSD 作为 Web 服务器与缓存服务器，NTT 的部分内部服务器运行 FreeBSD。日本大型企业（如日立、东芝、NEC）的嵌入式系统与网络设备中也存在 BSD 衍生系统的部署
  **史料**：Yahoo! Japan 技术博客、NTT 技术报告、日立/东芝/NEC 嵌入式系统文档 ［C］
  **史观**：总纲第 11 条——日本大型企业的 BSD 采用是技术市场形式主义运作的缩影
  **辨析**：各企业 BSD 部署的具体规模与时间线需考据；嵌入式系统 BSD 衍生版本的具体信息需分析
  **文献**：Yahoo! Japan 技术博客（2000-2010）；NTT 技术报告 ［C］
