## 故障类

### 新闻条目 1

- **新闻标题（中英）**：SP 800-218, Secure Software Development Framework (SSDF) Version 1.1 / SP 800-218 安全软件开发框架（SSDF）1.1 版
- **新闻来源**：NIST CSRC 官方 + 发布日期 2022-02 + 作者 Murugiah Souppaya（NIST）、Karen Scarfone（Scarfone Cybersecurity）、Donna Dodson + URL <https://csrc.nist.gov/pubs/sp/800/218/final> + DOI <https://doi.org/10.6028/NIST.SP.800-218> + PDF <https://nvlpubs.nist.gov/nistpubs/SpecialPublications/NIST.SP.800-218.pdf>
- **新闻摘要**：NIST SP 800-218 SSDF 1.1 版最终发布，定义一组高级安全软件开发实践，可集成至各 SDLC 实现。SSDF 源自 2020-04 NIST CSWP 13 白皮书，正式版取代白皮书。背景为 US Executive Order 14028《Improving the Nation's Cybersecurity》（2021-05-12 签署）。文档目标：减少已发布软件漏洞数量、缓解未检测漏洞利用影响、解决漏洞根本原因以防止复发。
- **与本章主题的关联说明**：这是 SSDF 官方权威定义文档，是本章 “J 类 NIST 官方文档” 与 “SSDF 框架定义” 小节的核心一手史料，为 BSD 项目 SSDF 合规提供标准参照。
- **与官方史料的交叉验证结论**：文档位于 `csrc.nist.gov` 官方域，DOI 注册完整，与 Executive Order 14028 关联明确。文档历史显示 2021-09-30 公开草案、2022-02-03 最终版，时间线清晰。

### 新闻条目 2

- **新闻标题（中英）**：FreeBSD Foundation Cyber Resilience Act Readiness Project - Security and Vulnerability Handling Workstream / FreeBSD Foundation CRA 就绪项目——安全与漏洞处理工作流
- **新闻来源**：FreeBSD Foundation 官方项目页面 + URL <https://freebsdfoundation.org/project/cyber-resilience-act-readiness/>
- **新闻摘要**：FreeBSD Foundation CRA 就绪项目的 “Security and Vulnerability Handling” 工作流，Foundation 工作人员与 FreeBSD 项目利益相关方（Core、Secteam、Ports Secteam）及下游厂商协作，发展 CRA 责任的共享理解、检视潜在场景、确定适当协作响应。该工作流亦更新政策、公开立场与文档，并考虑更广泛开源生态的新兴良好实践。
- **与本章主题的关联说明**：这是 FreeBSD Foundation 将 SSDF 类实践纳入 CRA 就绪工程的具体工作流，反映 BSD 项目对 SSDF 理念的事实遵循，是本章 “K 类 FreeBSD Foundation 官方反映” 与 “BSD SSDF 实施路径” 小节的关键史料。
- **与官方史料的交叉验证结论**：项目页面位于 `freebsdfoundation.org` 官方域，工作流描述与 NIST SP 800-218 SSDF 的 “PO.1（Define Security Requirements）”、“PO.2（Implement Roles and Responsibilities）”、“PS.1（Protect Code from Tampering）” 等实践可对应。

### 新闻条目 3

- **新闻标题（中英）**：FreeBSD Alpha Omega Project / FreeBSD Alpha Omega 项目
- **新闻来源**：FreeBSD Foundation 官方网站 + URL <https://freebsdfoundation.org/> + 关联 <https://alpha-omega.dev/>
- **新闻摘要**：FreeBSD Foundation 启动 Alpha Omega 项目，目标减少 FreeBSD 源代码中可利用漏洞数量，由 Alpha Omega 项目（Linux Foundation 旗下 OpenSSF 资助）资助。2024 年起 Foundation 另获 25 万美元专项拨款设立 Security Engineer in Residence 职位，应对 AI 生成漏洞报告。
- **与本章主题的关联说明**：这是 FreeBSD Foundation 对 SSDF “RV（Respond to Vulnerabilities）” 实践组的工程响应，与 SSDF “减少已发布软件漏洞数量” 目标一致，是本章 “BSD 安全工程投入” 小节的关键史料。
- **与官方史料的交叉验证结论**：Alpha Omega 项目官方站点 `alpha-omega.dev` 确认该项目由 OpenSSF 资助，OpenSSF 是 Linux Foundation 旗下组织，与 NIST SSDF 的 EO 14028 背景一致。
