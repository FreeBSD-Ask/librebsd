### 新闻条目 1

- **新闻标题（中英）**：SP 800-218, Secure Software Development Framework (SSDF) Version 1.1 / SP 800-218 安全软件开发框架（SSDF）1.1 版
- **新闻来源**：NIST CSRC 官方 + 发布日期 2022-02 + 作者 Murugiah Souppaya（NIST）、Karen Scarfone（Scarfone Cybersecurity）、Donna Dodson + URL `<https://csrc.nist.gov/pubs/sp/800/218/final`> + DOI `<https://doi.org/10.6028/NIST.SP.800-218`> + PDF `<https://nvlpubs.nist.gov/nistpubs/SpecialPublications/NIST.SP.800-218.pdf`>
- **新闻摘要**：NIST SP 800-218 SSDF 1.1 版最终发布，定义一组高级安全软件开发实践，可集成至各 SDLC 实现。SSDF 源自 2020-04 NIST CSWP 13 白皮书，正式版取代白皮书。背景为 US Executive Order 14028《Improving the Nation's Cybersecurity》（2021-05-12 签署）。文档目标：减少已发布软件漏洞数量、缓解未检测漏洞利用影响、解决漏洞根本原因以防止复发。
- **与本章主题的关联说明**：这是 SSDF 官方权威定义文档，是本章 “J 类 NIST 官方文档” 与 “SSDF 框架定义” 小节的核心一手史料，为 BSD 项目 SSDF 合规提供标准参照。
- **与官方史料的交叉验证结论**：文档位于 `csrc.nist.gov` 官方域，DOI 注册完整，与 Executive Order 14028 关联明确。文档历史显示 2021-09-30 公开草案、2022-02-03 最终版，时间线清晰。
