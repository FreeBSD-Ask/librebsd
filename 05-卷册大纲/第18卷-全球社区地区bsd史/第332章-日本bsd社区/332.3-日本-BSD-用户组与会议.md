# 332.3 日本 BSD 用户组与会议

108.3 **日本 BSD 用户组与会议**———日本 FreeBSD 用户组（JBUG）1990 年代成立，BSD 会议包括 AsiaBSDCon（首届 2004 年于台北，2007 年届在东京）[修正脚注]与 BSD 关西会议，日本 BSD 用户组的邮件列表与 IRC 频道是社区交流的核心渠道

## 332.3.1 JBUG 的用户组历史

  **要点**：日本 BSD 用户组（JBUG，Japan BSD Users Group）1990 年代末成立，由 IIJ 与 WIDE 项目的系统管理员发起，早期东京、大阪、名古屋等城市均有本地用户组。JBUG 的邮件列表（freebsd-users-jp）与 IRC 频道（#bsd-jp）是日本 BSD 用户交流的核心渠道。
  **史料**：JBUG 邮件列表 Archive、freebsd-users-jp 档案、JBUG 早期活动记录 ［A］
  **史观**：总纲第 22 条——日本 BSD 用户组是 BSD 社区去中心化组织结构的重要体现
  **辨析**：JBUG 的确切成立日期需考据；东京/大阪/名古屋各地用户组的活跃时间需分析
  **文献**：freebsd-users-jp Mailing List Archive；JBUG 活动记录 ［A］

## 332.3.3 BSD 关西会议与地方活动

  **要点**：BSD 关西会议（Kansai BSD Conference）是日本关西地区（大阪/京都/神户）的 BSD 社区会议，与 AsiaBSDCon 互补，规模较小但更聚焦本地社区。此外日本各地不定期举办 BSD 安装会（Install Fest）与黑客松（Hackathon）。
  **史料**：BSD 关西会议议程、地方活动记录、社区博客 ［C］
  **史观**：总纲第 22 条——地方会议是 BSD 社区去中心化凝聚力的体现
  **辨析**：BSD 关西会议的首届日期需考据；地方活动的持续性需评估
  **文献**：Kansai BSD Conference Archives；日本 BSD 社区博客 ［B］

**要点**：

- AsiaBSDCon 2018 在东京举行，前两日为 FreeBSD Developer Summit 与 BeehiveCon（含 NetBSD Summit 和 OpenBSD VMM 更新），后两日为论文演讲；bhyve 相关论文在第二天占满专题时段，议题覆盖 bhyve 的 SmartOS zones 移植、ARMv7/v8、挂起恢复与虚拟中断控制器，另有 FreeBSD VPC 与保存恢复（朝向热迁移的第一步）。（BSD Now EP237，[0.0-997.0]，L1）
- FreeBSD 11.1 stable 合入针对 Meltdown 与 Spectre V2 的缓解：Meltdown 采用 PTI 分离内核与用户页表，Spectre V2 采用依赖微码更新的 IBRS；可通过 vm.pmap.pti 与 hw.ibrs_active 等 sysctl 查看与切换，retpoline 编译器方案仍在评估中。（BSD Now EP237，[1008.2-1502.9]，L2）
- OpenBSD 宣布 syspatch 开始为两个受支持版本（6.1 与 6.2）同时提供二进制补丁，使 6.2 在 6.3 发布后仍可通过 syspatch 获得 Meltdown 缓解，并特别感谢 Robert 与 Antoine Jacoutot 的工作。（BSD Now EP237，[3566.9-3641.5]，L2）
- MidnightBSD 创始人 Lucas Holt 在访谈中说明该桌面导向系统是 FreeBSD 的 fork 而非发行版，拥有自有包管理器 mPort（tar LZMA 包加 SQLite3 清单与索引），启动卷使用 UFS2 并支持 ZFS，提供 2.6.16 内核的 Linux 仿真，计划保留 i386 支持至 1.0 版本。（BSD Now EP237，[1701.7-2136.1]，L2）
- 一篇八个月使用 TrueOS 的报告记述作者因对 Linux 发行版的 systemd 组织方式失望而转向 FreeBSD/TrueOS，赞赏 OpenRC、ZFS 启动环境回滚与手册质量，并由此偏好 BSD 许可证；其未能使用的软件为 Netflix、Google Hangouts 与 Electron 类应用。（BSD Now EP237，[2373.5-2995.7]，L2）
- AsiaBSDCon 2008 定于 2008 年 3 月 27 日至 30 日（周四至周日）在东京举行，延续首届格式：前两日教程、后两日正文会议；由上届单轨道改为双轨道，日程更宽松；会址比上届更靠近市中心与公共交通。（BSDTalk EP134，[132.83-195.19]，L1）
- 征稿流程：call for papers 已发布，2007 年 12 月 1 日截稿，程序委员会评审后于 12 月 24 日发出录用通知——被戏称为给作者的圣诞礼物，督促其写完承诺的论文。（BSDTalk EP134，[94.03-127.55]，L1）
- 上届 AsiaBSDCon 成绩：近 200 名参会者、四天会期、录用 13 场报告并设多场教程；第二届组织时向赞助者解释项目身份与诉求更为容易。（BSDTalk EP134，[273.03-290.47]，L1）
- 并行开发者峰会安排：上届在教程时段并行举办 FreeBSD 开发者会议，本届将继续；欢迎其他 BSD 项目组织类似峰会，因亚洲开发者多在 AsiaBSDCon 期间聚齐，是难得的面对面协作时机。（BSDTalk EP134，[216.67-238.27]，L1）
- 赞助与资金政策：Google、FreeBSD Foundation 等上年主要赞助方已承诺继续赞助（另一机构名转写不可辨），仍面向亚洲内外征集新赞助者；上届确立的政策是赞助款项最大部分用于把人带到会场——机票、酒店与签证，目标是让尽可能多的开发者与讲者同时同地聚集。（BSDTalk EP134，[251.77-331.44]，L1）
- 注册费与汇率观察：上年约 80 美元（约 60 欧元），本届以日元定价；日元走弱使欧洲参会者赴日成本更低。（BSDTalk EP134，[363.55-401.76]，L1）
- 旅行配套：与 JTB 合作，会议网站将链接其套餐，从东京数小时游到京都数日游或温泉之旅；上届曾组织日本传统文化之旅但报名者少，本届改为按需联系安排。（BSDTalk EP134，[410.35-483.07]，L1）
- 组织基础设施：会议官网设 announce 邮件列表供订阅；组织人手已足，需要的志愿者工作是扩散公告与广告；Neville-Neil 公布电子邮箱征集企业赞助。（BSDTalk EP134，[490.03-530.59]，L1）

- 总纲8 本体论上各方平等：AsiaBSDCon 的节目委员会与志愿组织者包括 George Neville-Neil、Hidetoshi Shimokawa、Masanobu Saito 等动手者，会议同时容纳 FreeBSD、NetBSD、OpenBSD、DragonFly 与 illumos 议题，体现本体论上各方平等的社区呈现。（BSD Now EP237，[948.5-997.0]，L1）

- 总纲20 历史地理塑造思想土壤：会议形态深嵌日本地理与文化土壤：会址向市中心与公共交通收敛、依托 JTB 的旅行体系、温泉与传统文化行程作为社区交往的延伸——地理与旅行文化塑造了亚洲 BSD 社区的聚散方式。（BSDTalk EP134，[174.08-483.07]，L1）
