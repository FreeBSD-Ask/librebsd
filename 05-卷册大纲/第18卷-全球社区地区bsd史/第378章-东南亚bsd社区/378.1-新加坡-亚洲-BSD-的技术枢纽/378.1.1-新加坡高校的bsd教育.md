# 378.1.1 新加坡高校的 BSD 教育


117.1 **新加坡：亚洲 BSD 的技术枢纽**———新加坡 BSD 社区的起源可追溯至 1990 年代新加坡国立大学（NUS）与南洋理工大学（NTU）的 UNIX 研究传统，新加坡作为亚洲互联网枢纽的地位推动了 BSD 在新加坡 ISP 与数据中心中的广泛采用

  **要点**：新加坡国立大学（NUS）与南洋理工大学（NTU）在 1990 年代开设 UNIX/BSD 相关课程，NUS 计算机学院（School of Computing）在 BSD 网络栈与操作系统研究方面有传统。新加坡高校的 BSD 教育培养了一批新加坡 BSD 贡献者，新加坡学生通过 编程之夏 参与 BSD 项目
