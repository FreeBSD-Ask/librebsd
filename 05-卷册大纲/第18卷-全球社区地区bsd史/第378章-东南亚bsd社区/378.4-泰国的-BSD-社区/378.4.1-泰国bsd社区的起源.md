# 378.4.1 泰国 BSD 社区的起源


117.4 **泰国的 BSD 社区**———泰国 BSD 社区以曼谷为中心，泰国朱拉隆功大学与泰国农业大学开设 BSD 相关课程，泰国 BSD 社区与泰国 Linux 社区（TLF）有交叉参与

  **要点**：泰国 BSD 社区以曼谷为中心，泰国互联网早期（1990 年代，以 Internet Thailand 为代表的 ISP）使用 FreeBSD 作为网络服务器。泰国 BSD 用户组的形成受到泰国开源社区（Thai Linux Working Group）的影响，泰国 BSD 社区规模较小但持续活跃
