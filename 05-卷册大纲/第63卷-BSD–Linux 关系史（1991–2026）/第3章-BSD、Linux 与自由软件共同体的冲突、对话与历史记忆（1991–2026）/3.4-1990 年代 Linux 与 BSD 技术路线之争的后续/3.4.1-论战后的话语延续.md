# 3.4.1 论战后的话语延续

<!-- MAIL_INSIGHT: 199508280806.KAA26470@bonnie.tcd-dresden.de -->
**观点**：1995 年 8 月 28 日，Jörg Wunsch 在 freebsd-chat 转贴 Terry Lambert 的一篇跨自由 Unix 系统比较，并评论“对那些还没看到的人来说，这终于是一篇技术上有趣的（各自由 Unix 系统之间的）比较”——以“终于”二字点出此前 Linux vs BSD 论战大多空洞无物。
**邮件来源**：Jörg Wunsch，freebsd-chat，1995 年，Message-ID: `199508280806.KAA26470@bonnie.tcd-dresden.de`
**史学意义**：资深开发者对论战质量的厌倦与对技术性比较的欢迎，说明 79.9.1 所批评的决定论站队叙事在 1995 年即已引发阵营内部的反感——对空洞比较的批评并非后世史学家的追溯建构，而是论战参与者的当下反应。

**观点**：1993年1月，John Bass 声称 USL 诉讼“实为 BSDI 与 Jolitz 抄袭 UNIX 的拙劣尝试，不要把他们塑造成民间英雄”，引发 Hellmuth Michaelis 以“ENOUGH!”为题回帖抗议此类言论毒化讨论。
**邮件来源**：Hellmuth Michaelis（转述 John Bass 指控并反驳），comp.unix.bsd，1993-01-21，Message-ID: `1630@hcshh.hcs.de`
**史学意义**：诉讼期间社区内部围绕“盗用 vs 创新”的对立叙事当时即已正面交锋，话语权斗争是诉讼史的内在组成部分。
