# 103.3.1 OS 级虚拟化的概念起源

  **要点**：OS 级虚拟化概念（多实例共享内核）可追溯至 1979 年 chroot，但 Jails（2000）首次实现生产级安全隔离，Solaris Zones（2004）、OpenVZ（2005）、LXC（2008）、Docker（2013）均晚于 Jails
  
**史料**：容器技术史论文、Jails/Zones/LXC/Docker 文档、phk BSDCon 演讲 ［A］
  
**史观**：总纲第 5 条——没有必然性，只有偶然性，Jails 概念早于市场认可
  
**辨析**：OS 级虚拟化的 “首创” 归属存在争议，chroot 是早期形式
  
**文献**：容器技术史论文；Jails/Zones/LXC/Docker 文档 ［B］
