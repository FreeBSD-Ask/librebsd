# 103.1.3 Jails 的设计动机

  **要点**：phk 的设计动机是 “让 root 不那么全能”，通过 **jail(2)** 限制 root 权限 (如禁止修改网络配置、禁止加载内核模块)，使 jailed 进程即使被攻破也无法影响主机
  
**史料**：jail(2) 手册页、phk 的 BSDCon 论文、sys/kern/kern_jail.c 注释 ［A］
  
**史观**：总纲第 2 条——实践先于理论，Jails 源于 “chroot 不够用” 的实践痛点
  
**辨析**：Jails 的安全模型是否 “完全” 安全存在争议，后续发现多个逃逸漏洞
  
**文献**：jail(2) 手册页；Kamp 论文；安全审计报告 ［A］
