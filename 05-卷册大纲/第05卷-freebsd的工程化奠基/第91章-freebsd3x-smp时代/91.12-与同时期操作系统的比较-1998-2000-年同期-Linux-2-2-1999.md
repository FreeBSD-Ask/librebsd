# 91.12 **与同时期操作系统的比较**：1998-2000 年同期 Linux 2.2（1999.1，SMP 支持大幅改进，引入 spinlock 优化，但仍保留大内核锁 BKL，调度器仍为 O(n)）、Windows 2000（2000.2，NT 5.0，微内核混合架构，调度器优先级驱动 32 级，NTFS 日志文件系统，Active Directory 域目录服务）、Solaris 8（2000.2，SVR4，完全抢占式内核，细粒度锁，Solaris Threads/UltraSPARC 多线程优化，UFS Logging + VxFS 可选，ZFS 尚未出现）——FreeBSD 3.x 的技术路线分化：①SMP 架构——FreeBSD 3.x 仍依赖 Giant Lock 粗粒度锁，Linux 2.2 也保留 BKL 但已开始细粒度化，Solaris 8 已实现完全抢占式内核与细粒度锁，FreeBSD 在 SMP 成熟度上明显落后于 Solaris、略落后于 Linux

## 90.12.1 Linux 2.2 与 FreeBSD 3.x

  **要点**：Linux 2.2(1999.1) 引入 spinlock 优化改进 SMP，但仍保留 BKL；FreeBSD 3.x 依赖 Giant Lock，二者 SMP 成熟度相近，Linux 在驱动支持上领先，FreeBSD 在网络栈稳定性上领先

  1998-2000 年同期操作系统 SMP 能力对照：

  | 操作系统 | 发布日期 | SMP 锁模型 | 调度器 | 文件系统一致性 |
| ------ | ------ | -------- | ---- | ------------ |
| FreeBSD 3.x | 1998-10 | Giant Lock（粗粒度） | O(n) | soft updates | | |
| Linux 2.2 | 1999-01 | BKL + spinlock 优化 | O(n) | ext2（无日志） | | |
| Solaris 8 | 2000-02 | 完全抢占式、细粒度锁 | 抢占式 | UFS Logging + VxFS | | |
| Windows 2000 | 2000-02 | 微内核混合架构 | 32 级优先级 | NTFS 日志 | | |

## 90.12.2 Windows 2000 与 Solaris 8
