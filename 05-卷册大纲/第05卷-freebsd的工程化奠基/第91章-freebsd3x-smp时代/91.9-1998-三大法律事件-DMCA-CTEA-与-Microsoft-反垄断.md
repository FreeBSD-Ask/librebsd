# 91.9 1998 三大法律事件：DMCA、CTEA 与 Microsoft 反垄断——1998.10.28 DMCA（Pub.L. 105-304，112 Stat. 2860）由克林顿总统签署生效，实施 WIPO 版权条约与 WIPO 表演人与录音制品条约（1996.12.20 日内瓦缔结），含五编：第一编 §1201 反规避条款与版权管理信息保护、第二编 §512 OSP 安全港与通知-移除机制、第三编计算机维修豁免、第四编综合条款、第五编船舶外观设计保护

## 91.9.1 DMCA 立法语境与 WIPO 条约实施

  **要点**：DMCA(1998.10.28, Pub.L. 105-304) 实施 WIPO 版权条约 (1996.12.20)，§1201 反规避条款禁止绕过技术保护措施，§512 OSP 安全港为在线服务提供商提供免责，深刻影响开源逆向工程与密码学研究
  
**史料**：DMCA 全文 (Pub.L. 105-304)、WIPO 版权条约文本、House Judiciary Committee 报告 ［A］
  
**史观**：法律结构，DMCA 的法律结构塑造了开源软件的逆向工程边界
  
**辨析**：DMCA §1201 是否禁止开源逆向工程存在法律解释争议，需查判例
  
**文献**：DMCA 全文；WIPO 条约；House 报告；Lessig《Free Culture》(2004) [考据脚注：Lessig《Free Culture》经 Lawrence Lessig（劳伦斯·莱斯格） 个人网站（lessig.org）与多源书评确认出版于 2004 年（Penguin Press），为自由文化运动经典著作。]

## 91.9.2 Sonny Bono CTEA 与版权期限延长至 70 年

  **要点**：Sonny Bono CTEA(1998.10.27, Pub.L. 105-298) 将美国版权期限从作者终身加 50 年延长至 70 年，保护 Disney 等公司早期作品进入公共领域，2003 年 Eldred v. Ashcroft 维持合宪
  
**史料**：CTEA 全文 (Pub.L. 105-298)、Eldred v. Ashcroft 判决 (537 U.S. 186)、Lessig 的 Eldred 诉案文档 [考据脚注：Lawrence Lessig 为 Eldred v. Ashcroft（537 U.S. 186, 2003）首席律师，其诉案文档经 lessig.org 与最高法院判决书交叉验证确证。] 〔L3 官方文档〕
  
**史观**：法律结构，CTEA 的法律结构延长了版权垄断期
  
**辨析**：CTEA 是否 “违宪” 存在法律争议，最高法院 7-2 维持
  
**文献**：CTEA 全文；Eldred 判决；Lessig《Free Culture》 [考据脚注：同上，Lessig《Free Culture》（Penguin Press, 2004）经多源交叉验证确证。]；**补充引用（自重复块合并）**：CTEA 全文（mat_id 15032）；Eldred v. Ashcroft（mat_id 12434）［C］

## 91.9.3 US v. Microsoft 1998 起诉与 76 天庭审

  **要点**：US v. Microsoft(1998.5.18 起诉) 由 DOJ 联合 20 州提起，Judge Jackson 主持 76 天庭审 (1998.10.19-1999.6.24)，1999.11.5 事实认定书认定 Microsoft 垄断，2000.4.3 裁定违法垄断，2000.6.7 拆分令
  
**史料**：US v. Microsoft 判决书 (84 F. Supp. 2d 9, 87 F. Supp. 2d 30)、庭审记录、DOJ 新闻稿 ［A］
  
**史观**：国家政策，反垄断政策影响操作系统市场竞争
  
**辨析**：拆分令被上诉法院撤销，最终采行为约束，影响程度存在争议
  
**文献**：US v. Microsoft 判决书；DOJ 文档；Lessig《The Future of Ideas》(2001) ［A］；**补充引用（自重复块合并）**：Complaint（mat_id 15027）；84 F. Supp. 2d 9（mat_id 15028）；87 F. Supp. 2d 30（mat_id 15029）；253 F.3d 34（mat_id 15030）；Final Judgment（mat_id 15031）；DOJ 监督记录；Econ 评审报告（Page 等）［C］

## 91.9.4 Microsoft 公司史与浏览器战争

  **要点**：Microsoft 在 1995-2001 年浏览器战争中通过 IE 绑定 Windows 击败 Netscape，反垄断诉讼后 IE 市场份额持续上升至 95%(2004)，开源浏览器 (如 Firefox 2004) 的兴起部分源于对 Microsoft 垄断的反应
  
**史料**：Microsoft 公司年报、IE 市场份额统计、Netscape 开源 Mozilla(1998) 文档 ［B］
  
**史观**：开源运动，Microsoft 垄断催生了 Mozilla 开源运动
  
**辨析**：浏览器战争的胜负是否 “完全” 归因于绑定存在争议
  
**文献**：Microsoft 年报；IE 市场份额统计；Mozilla 开源文档 ［B］
