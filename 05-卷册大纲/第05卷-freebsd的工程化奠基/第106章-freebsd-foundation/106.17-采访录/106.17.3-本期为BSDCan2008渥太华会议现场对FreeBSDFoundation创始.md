# 106.17.3 本期为BSDCan2008渥太华会议现场对FreeBSDFoundation创始

- 本期为 BSDCan 2008 渥太华会议现场对 FreeBSD Foundation 创始人 Justin Gibbs 的一手口述访谈，保留基金会 2000 年创立过程、2004 年首名带薪员工、2007 年厂商捐赠扩张、Sun Java 再分发协议与 Flash 授权尝试、Cisco 万兆集群与 NetApp filer 捐赠等可核查线索；可对照基金会网站公开财务与年报交叉验证。（BSDTalk EP149，[26.44-67.56]，L1）
- Deb Goodkin 关于 2005 至 2006 年受聘过程（经 HR 好友介绍、顾问试用转正、首位专职员工身份）、基金会三大职能与法律实体角色的当事人一手口述。（BSDTalk EP211，[134.24-432.46]，L1）
- 2011 年募款 42.8 万美元、807 笔个人捐赠、2012 年 50 万目标等运营数字口述；与 Sun 的 Java 许可、PCI-SIG 规范获取、NDA 机制的法律实务口述；大项目清单与已资助项目（auditd、IPv6 性能分析）的口述，可与基金会官网财务与新闻记录交叉核对。（BSDTalk EP211，[385.14-1189.12]，L1）
- 本演讲录音构成一手史料：FreeBSD Foundation 项目开发总监 Ed Maste 与董事 George Neville-Neil 于 vBSDCon（2015 年 11 月发布）的联合演讲；演讲中指认的公开材料包括基金会网站上的完整财务报表、参照系 ACM Queue 杂志，及现场展示的 X230 与 Mac 的 suspend/resume 对比等实物例证。（BSDTalk EP259，[98.30-146.90]，L1）
- 本期为 EMC 实验室管理员 Glen R. J. Neff 的口述访谈（bsdtalk093，2007-01-15），其中对 FreeBSD Foundation 职能的陈述尤为详尽：基金会以捐款与 Sun 达成许可协议，得以分发稳定的 Diablo Java VM 二进制，终结 FreeBSD 上须经 Linux 模拟 bootstrap、过程痛苦且产物不稳定的 JDK 构建史；基金会正筹资与 Adobe 合作提供 FreeBSD 原生 Shockwave Flash 插件（既有 Linux 包装器不稳定、常致浏览器崩溃）；基金会资助 BSD 会议并为散居各地开发者提供差旅补助以促成两三天的面对面磋商；其资助的 NetPerf Cluster（位于加拿大）为高端硬件环境，FreeBSD 6.x 网络栈的大量改进、jemalloc 的测试与大量 ZFS 开发均在此完成；基金会并赞助虚拟网络栈的开发。 [存疑脚注] 转写将 NetPerf Cluster 的托管方记作 Cintex，疑为 Sentex 之失真；gated port 的细节亦受转写噪声影响，待核。（BSDTalk EP93，[1495.9-1810.48]，L1）

**史观**：

- 总纲13 法律与道德是利益分配：Gibbs 解释 IRS 非营利法规关注捐赠集中度：若单一企业巨头注入巨款并接管基金会方向，基金会将沦为非营利门面，因此特定时期须专门动员个人小额捐赠以维持比例——法律与税收制度直接塑造了基金会的行为形态，免税资质与合规约束本质上是利益分配的制度装置。（BSDTalk EP149，[509.02-542.26]，L1）
- 总纲10 动手者创造历史：基金会董事会全员为亲手参与 FreeBSD 开发的工程师，资助取舍经由社区调研与月会表决决定，而非职业经理人的商业逻辑，治理形态由动手者的经验直接运作。（BSDTalk EP211，[669.52-746.72]，L1）
- 总纲13 法律与道德是利益分配：志愿者群体本身不具备法人地位，许可签署、NDA、诉讼风险均须由基金会这一法律实体承担，法人形式成为开源协作得以在现行法律秩序中运转的分配装置。（BSDTalk EP211，[340.82-427.90]，L1）
- 总纲5 没有必然性，只有偶然性：基金会首位专职雇员的产生源于 Justin Gibbs 向其公司 HR 好友求助这一私人友谊链条，基金会职业化的起点是一次偶然的人际引荐，而非制度设计的必然产物。（BSDTalk EP211，[158.52-172.80]，L1）
- 总纲17 证明世界先于解释和改造世界：大项目新模式先雇人写出规格、框架与真实预算并公开，再据此募资与雇人，把承诺建立在可执行、可核验的文件之上，而非口号式愿景，体现以可证明的先行事实组织协作的理念。（BSDTalk EP211，[1038.09-1097.84]，L1）
- 总纲11 商品是形式主义：FreeBSD 项目本身是不具法人资格的个人集合，商标、NDA、捐赠基金这些法律形式外壳使集体行动成为可能——基金会的价值不在直接写代码，而在于以法人形式把分散的个体劳动组织为可持续的项目基础设施。（BSDTalk EP259，[841.02-893.42]，L1）
- 总纲3 不存在进步，只有权力再分配：FreeBSD 路由基础设施的命运曲线揭示技术角色的流转机制：其表现越好、越有效地服务测试与开发，项目获得资金越多；资金增长带来 Cisco Catalyst 4000 乃至 6500 的部署，硬件三层路由最终取代了自己扶持起来的 FreeBSD 路由层。技术角色的更替并非单纯的技术优劣裁决，而是随组织预算结构与权力层级的再分配而流转。（BSDTalk EP93，[734.88-805.4]，L1）

**辨析**：

- 2007 年厂商捐赠分水岭的规模、未公开采用 FreeBSD 的厂商名单与 Flash 授权谈判进度均为受访者单方陈述，本期未提供文件证据，需以基金会年报、捐赠公示及 Sun Java 协议文本交叉验证；Gibbs 对基金会低开销的判断亦属自评。 [存疑脚注] 厂商捐赠规模与 Flash 授权进展为单一来源自述，需对照基金会公开财务文件复核。（BSDTalk EP149，[187.62-319.54]，L1）
- 转写中的 co-verity license 无法确证所指许可名称，引用前须以基金会法律记录核对；受访者当场未给出运营预算总额，仅有募款与支出目标数字，具体财务须以基金会年度报告为准；大项目清单为 2012 年初计划，实际执行进度须事后核对；转写讹误：ENX 应为 NCR 或 IBM 存储语境之外的待考缩写、audit ghosty demon 应为 auditd、free VSD 应为 FreeBSD。 [存疑脚注] co-verity license 一词转写不明；ENX 一词所指公司无法确证；全部数字均为单方口述，须与基金会年报核对。（BSDTalk EP211，[405.10-415.62]，L4）
- 转写专名讹误密集：Ed Mast 应为 Ed Maste、Yankun 应为 Jan Koum、Syntex 疑为 Sentex、Jim Morrow 疑为 Jim Maurer、SemiHap 疑为 Semihalf、NetVisd 应为 NetBSD、“Robert Barron's”应指 robber barons（强盗大亨）、Iselons 疑为 Isilons、“Women in Courage”疑为 Grace Hopper Celebration 相关表述，引用前须核对原始音频；另外演讲录音分段时间戳非单调，不影响语义完整性。 [存疑脚注] 上述专名校正均系语境推断，须经原始音频确证后方可引用。（BSDTalk EP259，[2045.56-2055.16]，L5）
- 受访者对 Linux 与 BSD 的比较观：BSD 项目是完整操作系统，而 Linux 只是内核——用户态工具与配置方式随发行版而异、内核日益去中心化、发行版彼此竞争，他视 Linux 为碎片化的努力；虽自称“工具至上者”，仍偏爱 FreeBSD，理由是可阅读源码、文档为各操作系统之最佳、支持网络发达（IRC、新闻组、邮件列表，且能直接联系驱动开发者协作修 bug）。其入坑契机是拨号时代以三美元购得的 FreeBSD 3.0 光盘，亲身体验印证了朋友所言 BSD 驱动质量优于 Linux 的判断。（BSDTalk EP93，[1345.66-1492.3]，L1）
