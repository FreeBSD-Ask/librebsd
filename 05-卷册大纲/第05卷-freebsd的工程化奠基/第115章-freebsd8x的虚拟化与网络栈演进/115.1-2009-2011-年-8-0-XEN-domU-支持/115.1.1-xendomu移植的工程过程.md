# 115.1.1 XEN domU 移植的工程过程

  **要点**：FreeBSD 8.0（2009.11）引入 XEN domU（半虚拟化客户端）支持，由 Doug Rabson（道格·拉布森） 等完成移植；移植包括修改内核启动、驱动适配（xenbus、xennet）、Grant Table 支持

**史料**：FreeBSD 8.0 Release Notes、commit log、freebsd-xen 邮件 ［A］；**freebsd.duckdb** 查询 L1.1.1 显示：freebsd-src 8.x 时期（2009-2011）年度 commit 量在宏观趋势统计报告中被截断未显示（L1.1.1 共 572 行仅显示前 30 行），须直接查询 **freebsd.duckdb** 获取完整数据；可从 L1.3.2 文件操作数据间接反映开发活跃度——freebsd-src 2009 年 files_modified = 86,650、2010 年 100,575（8.1 发布年，files_deleted = 84,724 为 2005-2009 年最高值，反映 8.x 大规模代码重构）、2011 年 92,851，8.x 时期文件修改数持续高位反映网络与虚拟化改造的工程规模；**freebsd.duckdb** 查询 L2.2.1.sys_net 显示：freebsd-src sys/net/ 子系统年度 commit 量在 8.x 时期——2009 年 4,340 条（files_touched = 657）、2010 年 4,023 条（files_touched = 693）、2011 年 2,981 条（files_touched = 707），2009-2010 年 sys/net commit 量保持高位反映 VNET 网络栈虚拟化与 XEN domU 网络驱动开发的叠加效应，2011 年下降反映 8.x 稳定后网络子系统开发节奏放缓；**freebsd.duckdb** 查询 L2.3.1.vimage 显示：中观模式挖掘报告中 L2.3.1 特性查询仅覆盖 ZFS/Capsicum/bhyve/Clang/ARM64/RISC-V 六项，无 vimage 专项查询，vimage/VNET 引入到稳定周期的 commit 时间序列须直接查询 **freebsd.duckdb** 获取（建议查询条件：commit message 含“vimage”或“vnet”关键词，或 file_path 含“sys/net/vnet”路径） ［A］
  
**史观**：总纲第 4 条——分离聚合是永恒规律：XEN domU 移植使 BSD 谱系迁移至 hypervisor 客户机新载体，跨平台传统在离开旧宿主、汇入新生态的分离-聚合运动中延续
  
**辨析**：移植完整度，需查支持的 XEN 版本与功能；0 信任原则适用说明：L1.1.1 年度 commit 量基于 author_date 聚合，报告截断导致 2009-2011 年 freebsd-src 数据不可直接获取，L1.3.2 文件修改数为替代指标不等于 commit 量；L2.2.1.sys_net 基于 sys/net% 路径匹配，可能漏掉重命名后的文件（VNET 相关代码在 sys/net/vnet/ 目录下应被匹配，但若部分代码移至 sys/netpfil/ 则可能漏匹配）；L2.3.1.vimage 查询在中观模式挖掘报告中缺失，须直接查询 **freebsd.duckdb** 验证 vimage/VNET 引入周期；sys/net commit 量保持高位不等于 VNET 贡献（可能包含其他网络子系统改进），须结合 file_path 过滤 vnet 相关 commit 交叉验证
