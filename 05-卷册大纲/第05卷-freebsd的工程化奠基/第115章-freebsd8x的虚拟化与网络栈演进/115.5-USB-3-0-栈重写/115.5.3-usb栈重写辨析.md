# 115.5.3 USB 栈重写辨析

  **要点**：USB 栈重写辨析：(1) 是否过度工程；(2) 与 Linux USB 栈比较；(3) 兼容性问题
  
**史料**：邮件、博客 ［C］
  
**史观**：0 信任原则（方法论表述，不设总纲条号）：与 Linux 的比较结论须经独立测试
  
**辨析**：与 Linux 比较，需独立测试——PODCAST_REVIEW 块载 Selasky 实测：新栈以变长 IO 向量对照 Linux pumping 方案，另支持控制传输分段（Linux 亦无）；独立测试须同硬件同负载
  
**文献**：freebsd-usb mailing list USB stack discussions (2009-2011)；freebsd-current mailing list USB feedback (2009)；LWN.net FreeBSD USB stack (2009) ［A］
