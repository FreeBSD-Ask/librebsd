**要点**：

- 节目报道 USENIX ATC 2018 论文将 FreeBSD ULE 调度器移植到 Linux，与原生 CFS 在相同条件下对比，结论是无总体赢家，平均性能差约 1.5% 且通常偏向更简单的 ULE。（BSD Now EP256，[251.16-487.12]，L2）
- 论文发现 ULE 可能对同类线程产生饥饿，但具体负载差异显著：SiMark 在 ULE 上慢约 36%，ApacheBench 快约 40%，差异源于抢占策略与 Java 系统线程被当作交互线程的优先级处理。（BSD Now EP256，[811.68-1248.64]，L2）
- PS4 5.05 BPF double-free 内核漏洞利用文指出 PS4 内核约 600 个系统调用中约 500 个来自 FreeBSD，Sony 在后续固件中移除 BPF 写权限并阻止非特权进程访问，漏洞根因是 BPF 过滤器设置路径缺少锁保护。（BSD Now EP256，[3124.60-3674.92]，L2）

**史料**：
