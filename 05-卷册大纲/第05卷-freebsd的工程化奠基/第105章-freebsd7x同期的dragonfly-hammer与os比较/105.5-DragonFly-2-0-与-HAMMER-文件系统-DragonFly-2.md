## 105.5.1 DragonFly 2.0 与 HAMMER

  **要点**：DragonFly BSD 2.0（2008.7.20）引入 HAMMER 文件系统，由 Matt Dillon 单人开发；HAMMER 采用 B-tree 写时复制设计，支持可配置历史保留、即时快照、崩溃即时恢复（无需 **fsck(8)**）、近实时镜像

## 105.5.2 vkernel 虚拟内核

  **要点**：DragonFly BSD 引入 vkernel（虚拟内核）机制，允许在用户空间运行内核实例，用于调试与虚拟化；vkernel 是 Dillon 的独创设计，体现 DragonFly BSD 的实验精神

## 105.5.3 DragonFly 1:1 线程与 FreeBSD libthr 殊途同归

  **要点**：DragonFly BSD 选择 1:1 线程模型（与 FreeBSD libthr 一致），放弃了 FreeBSD 5.x 的 KSE M: N 模型；两条路径殊途同归，证明 1:1 是工程上的更优选择
  
**史料**：DragonFly BSD commit log、FreeBSD libthr 文档 ［A］
  
**史观**：总纲第 7 条——BSD 与 UNIX 谱系的连续性
  
**辨析**：1:1 是否真优于 M: N，需查基准测试
  
**文献**：DragonFly BSD commit log (1:1 thread model)；Dillon, M. DragonFly 1:1 LWKT design notes (2008)；FreeBSD libthr documentation (man.freebsd.org) ［A］
