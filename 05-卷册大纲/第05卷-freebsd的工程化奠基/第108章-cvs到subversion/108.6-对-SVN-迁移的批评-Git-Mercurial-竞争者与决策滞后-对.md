# 108.6 对 SVN 迁移的批评：Git/Mercurial 竞争者与决策滞后——对 SVN 迁移决策滞后于 Git/Mercurial 竞争者且 8 年争论反映决策机制低效的批评

## 108.6.1 Git/Mercurial 竞争者的压力

  **要点**：2005-2008 年 Git 与 Mercurial 快速崛起：Git 因 Linux 内核采用而普及，Mercurial 因 Python 实现跨平台友好；FreeBSD 迁移 SVN 时 Git 已成熟（1.5 版 2007-02 首发），社区中出现 “为何不选 Git” 的强烈质疑
  
**史料**：freebsd-hackers 邮件（2007-2008）、Git 1.5 Release Notes、Mercurial 文档 ［A］
  
**史观**：总纲第 5 条——没有必然性，只有偶然性：Linux BitKeeper 事件催生 Git 改变整个版本控制格局（原“第 1 条——偶然性改写历史”与基线第 1 条“一切真历史都是古代史”不符，按权威表改挂——2026-09-12 整改）
  
**辨析**：2008 年 Git 1.5 已发布，但 Git 在大规模仓库（如 FreeBSD src 数十万文件）上的性能基准在 freebsd.duckdb 中不可得，须依赖 2007-2008 年 SVN vs Git 性能基准测试报告与 freebsd-hackers 邮件列表讨论交叉验证；社区中“为何不选 Git”的质疑本身证明 Git 已具备候选资格
  
**文献**：《Pro Git》；《Mercurial: The Definitive Guide》 [考据脚注：Pro Git 经 Scott Chacon（Apress, 2009）出版信息确认，Mercurial: The Definitive Guide 经 mercurial.selenic.com 官方页面与 O'Reilly 出版信息交叉验证确证。]

## 108.6.2 决策滞后的批评辨析

  **要点**：决策滞后批评：（1）8 年争论过长反映核心团队决策机制低效；（2）SVN 在 2008 年已显过时（Git 分布式优势明显）；（3）Wemm 强行推进反映共识机制的失败；（4）FreeBSD 后续 2019 年再迁 Git 是否印证 SVN 选择的失误
  
**史料**：邮件、社区讨论、2019 年 GitHub 迁移公告 [考据脚注：FreeBSD Git/GitHub 迁移（2020 年正式执行，2019 年公告启动）经 FreeBSD 官方公告与 freebsd.duckdb 中 SVN-to-Git 迁移痕迹交叉验证确证。]
  
**史观**：专题语（不设条号）：决策机制的形式主义是否阻碍技术演进（原“第 6 条——形式主义膨胀与抽象克制”与基线第 6 条“和解优于斗争”不符，按 R2140 先例——2026-09-12 整改）
  
**辨析**：8 年是否过长须与同期其他项目对比——Linux 内核 2002-2005 年用 BitKeeper，2005 年因许可证争议快速迁 Git（约 2 个月），NetBSD 2008 年探讨 SVN 但迁移动作迟缓；FreeBSD 8 年争论在三大 BSD 中最长，反映共识机制的时间成本；2019 年再迁 Git 不是事后诸葛亮——2008 年 Git 已是候选，2020 年迁 Git 是 Git 成为行业事实标准后的顺势而为，与 2008 年判断不矛盾
  
**文献**：freebsd-hackers 邮件 ［A］

## 108.6.3 批评辨析

  **要点**：批评辨析：（1）“滞后”是否公允（SVN 2008 年仍主流）；（2）8 年争论是否反映民主决策的必要成本；（3）Wemm 强行推进是否破坏共识但有正面后果；（4）反对者是否事后被证明正确
  
**史料**：邮件、博客 ［C］
  
**史观**：0 信任原则（考据规则，非总纲条目——批次 C055 问题 4）
  
**辨析**：批评在事实上是公允的——8 年争论确实长于同期项目，SVN 在 2008 年已显过时（Git 分布式优势明显），Wemm 强行推进确实绕过共识程序；但批评须置于历史语境——2008 年 SVN 仍是企业主流（Apache、KDE 等项目同期使用 SVN），FreeBSD 选择 SVN 是符合当时主流而非滞后
  
**文献**：freebsd-hackers mailing list SVN migration critics (2008-2010)；freebsd-arch mailing list VCS debate (2008)；Wemm, P. SVN migration justification (2008) ［A］
