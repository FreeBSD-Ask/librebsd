# 108.3 社区开发模式变化——CVS 时代的补丁文化与 SVN 时代的中央仓库文化

## 107.3.1 CVS 时代的补丁文化

  **要点**：CVS 时代 FreeBSD 社区采用补丁文化：开发者通过 diff/patch 提交补丁，由 committer 审核提交；补丁文化强调社区参与，边缘者可通过补丁贡献
  
**史料**：freebsd-hackers 邮件、补丁提交记录 ［A］
  
**史观**：总纲第 13 条——边缘者的作用，补丁文化允许边缘者参与
  
**辨析**：补丁文化与中央仓库文化无绝对优劣但有不同后果——补丁文化降低参与门槛但增加 committer 审核负担，中央仓库文化提升提交效率但提高边缘者参与门槛；bsd_commits.db contributors 表显示 freebsd-src 仓库 commit 数量在 2008 年前后未发生突变（月度 commit 数 644-1430 区间波动），说明模式变化对总提交量的影响有限，但对贡献者结构的影响须依赖邮件列表讨论交叉验证
  
**文献**：freebsd-hackers mailing list patch culture (2000-2008)；freebsd-committers mailing list commit statistics；McKusick, M. K. FreeBSD committer model in Open Sources (O'Reilly, 1999) ［A］

## 107.3.2 SVN 时代的中央仓库文化

  **要点**：SVN 时代 FreeBSD 社区转向中央仓库文化：committer 直接提交，分支管理更规范；但边缘者参与门槛提高，补丁提交减少
  
**史料**：commit log、邮件 ［A］
  
**史观**：总纲第 14 条——话语权与边缘者，中央仓库文化可能削弱边缘者参与
  
**辨析**：文化变化影响在 bsd_commits.db 中可通过 contributors 表首末活动时间间接验证——2008 年后新进入 committer 的首条 commit 时间分布须依赖 contributors 表逐人核查，但 “边缘者参与门槛提高” 的主观感受在 commit 中不可见，须依赖 freebsd-hackers 邮件列表与 freebsd-advocacy 讨论交叉验证
  
**文献**：freebsd-hackers mailing list SVN commit culture (2008-2010)；freebsd-committers mailing list；FreeBSD Committer's Guide (freebsd.org) ［A］

## 107.3.3 开发模式变化辨析

  **要点**：开发模式变化辨析：(1) 补丁文化是否更民主；(2) 中央仓库是否更高效；(3) 边缘者参与是否减少
  
**史料**：邮件、commit log ［A］
  
**史观**：总纲第 4 条——0 信任原则
  
**辨析**：模式无绝对优劣但有后果——补丁文化强调社区参与但效率受限于 committer 审核带宽，中央仓库文化强调提交效率但边缘者参与门槛提高；bsd_commits.db 数据显示 freebsd-src 仓库月度 commit 数在 2008 年前后未发生突变，说明模式变化对总提交量影响有限
  
**文献**：freebsd-hackers mailing list patch vs commit culture (2008-2010)；freebsd-arch mailing list development model (2009)；FreeBSD Committer's Guide ［A］

## 107.3.4 模式变化史料辨析

  **要点**：模式变化史料疑点：(1) 变化的时间线；(2) 关键推动者；(3) 是否有社区讨论影响变化
  
**史料**：邮件、commit log ［A］
  
**史观**：总纲第 4 条——0 信任原则
  
**辨析**：变化原因在 bsd_commits.db 中无直接 commit 证据——SVN 迁移作为模式变化的触发器是技术驱动的，但文化变化的深层原因（committer 群体代际更替、企业受薪开发者比重上升）须依赖邮件列表讨论与 Foundation 年度报告交叉验证
  
**文献**：freebsd-hackers mailing list 2000-2008 VCS migration discussions；freebsd-arch mailing list VCS selection threads；FreeBSD Committer's Guide ［A］
