# 第 107 章 CVS 到 Subversion

### 核心内容

### 史观映射

> 从 CVS 到 SVN 的迁移花了八年争论——不是因为技术难，而是因为选择版本控制工具就是在选择如何记忆开发史。CVS 的每一次提交、每一个分支、每一句日志都是开发记忆的载体，迁移意味着这些记忆要从一条无法重渡的河流搬到另一条——水还是那些水，但河床换了。而当 SVN 本身在 Git 面前也开始过时时，讽刺就完成了：用来对抗遗忘的工具，自己也会被遗忘
