# 第 108 章 CVS 到 Subversion

## 核心内容

FreeBSD 的版本控制历史为：CVS 使用期 1993 至 2012 年，Subversion 随后分批接管各仓库——`src/` 于 2008-05-31、`doc/www` 于 2012-05-19、`ports` 于 2012-07-14（Ed Maste（埃德·马斯特）, 2018）。

Anonymous CVS 由 Charles D. Cranor 与 Theo de Raadt（西奥·德·若特） 于 1995 年秋创建 OpenBSD 时设计，其机制是让匿名互联网用户在不危及安全的前提下访问源码库，将开放源码推进为开放源码库（Charles D. Cranor & Theo de Raadt）。

关于 FreeBSD 迁移到 Subversion 的时间存在口径矛盾：McKusick 称经辩论后于 2000 年迁到 Subversion（Marshall Kirk McKusick（马歇尔·柯克·麦库西克）, 2018），而 Ed Maste 的版本控制历史显示 `src/` 仓库直到 2008-05-31 才迁至 Subversion（Ed Maste, 2018），二者相差八年，可能分别指向迁移决策与首个仓库迁移完成两个节点。

### 辨析（2026-08-14 双库核查）

- “Anonymous CVS 由 Charles D. Cranor 与 Theo de Raadt 于 1995 年秋创建 OpenBSD 时设计”经参考文献库验证通过（来源：reference_id=171《Opening The Source Repository With Anonymous CVS》，Charles D. Cranor & Theo de Raadt；reference_id=172 anoncvs-slides，1995）。
- “`src/` 仓库迁至 Subversion”经参考文献库验证：FreeBSD Handbook 记载“In June 2008, the Project switched to using SVN (Subversion)”（reference_id=60，fact_id=793），与 Ed Maste 所记 2008-05-31 一致（5 月末至 6 月初）。
- McKusick 所称“2000 年迁 Subversion”两库无法验证，保留口径矛盾辨析（原文已注明二者可能分别指向迁移决策与首个仓库迁移完成两个节点）。

### 史观映射

> 从 CVS 到 SVN 的迁移花了八年争论——不是因为技术难，而是因为选择版本控制工具就是在选择如何记忆开发史。CVS 的每一次提交、每一个分支、每一句日志都是开发记忆的载体，迁移意味着这些记忆要从一条无法重渡的河流搬到另一条——水还是那些水，但河床换了。而当 SVN 本身在 Git 面前也开始过时时，讽刺就完成了：用来对抗遗忘的工具，自己也会被遗忘
