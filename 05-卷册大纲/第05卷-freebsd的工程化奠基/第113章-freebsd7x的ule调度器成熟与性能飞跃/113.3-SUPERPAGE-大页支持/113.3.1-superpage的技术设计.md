# 113.3.1 SUPERPAGE 的技术设计

  **要点**：SUPERPAGE（大页支持）由 Alan Cox（非 Linux 的 Alan Cox）等设计，允许使用 2MB/4MB 大页替代 4KB 小页，减少 TLB miss；7.0 引入
  
**史料**：FreeBSD 7.0 Release Notes、SUPERPAGE 论文（Cox et al.） ［B］
  
**史观**：简洁与复杂的辩证，大页增加复杂度但减少 TLB miss
  
**辨析**：大页是否真提升性能，需查基准测试
  
**文献**：Cox, A. et al. “Practical Transparent Superpage Support for FreeBSD” (FreeBSD Project, 2007)；FreeBSD 7.0 Release Notes；Navarro, J. et al. "Practical, Transparent Operating System Support for Superpages"ACM SIGOPS 2002 ［B］
