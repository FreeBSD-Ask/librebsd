# 114.1.3 DragonFly 1:1 线程与 FreeBSD libthr 殊途同归

  **要点**：DragonFly BSD 选择 1:1 线程模型（与 FreeBSD libthr 一致），放弃了 FreeBSD 5.x 的 KSE M: N 模型；两条路径殊途同归，证明 1:1 是工程上的更优选择
  
**史料**：DragonFly BSD commit log、FreeBSD libthr 文档 ［A］
  
**史观**：BSD 与 UNIX 谱系的连续性
  
**辨析**：1:1 是否真优于 M: N，需查基准测试
  
**文献**：DragonFly BSD commit log (1:1 thread model)；Dillon, M. DragonFly 1:1 LWKT design notes (2008)；FreeBSD libthr documentation (man.freebsd.org) ［A］
