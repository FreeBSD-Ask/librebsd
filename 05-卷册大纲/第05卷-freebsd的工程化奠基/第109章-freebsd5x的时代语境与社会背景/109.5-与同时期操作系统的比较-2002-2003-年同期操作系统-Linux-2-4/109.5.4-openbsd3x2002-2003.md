# 109.5.4 OpenBSD 3.x（2002-2003）

  **要点**：OpenBSD 3.0-3.3（2002-2003）持续强化安全（如 W^X 雏形、特权分离），对 SMP 关注较少，保持单处理器为主的简洁设计；与 FreeBSD 5.x 的 SMP 重心形成对照——OpenBSD 宁可牺牲多核扩展性也要维持安全与简洁。
  
**史料**：OpenBSD 3.x 发布说明（2002-2003）［A］
  
**史观**：总纲第 8 条——本体论上各方平等：OpenBSD 的 “安全/简洁优先” 与 FreeBSD 5.x 的 “可扩展性优先” 是 BSD 家族内部的目标分叉，两种工程优先级在本体论上地位相等（原挂“总纲第 6 条——技术路线分化”，按权威表改挂——2026-09-12 整改）。
  
**辨析**：OpenBSD 在 2002-2003 未全力投入 SMP 并非技术落后，而是工程优先级选择；其单处理器安全模型反而降低了攻击面。
  
**文献**：OpenBSD Project. OpenBSD 3.x Release Notes [Z]. 2002-2003. ［A］
