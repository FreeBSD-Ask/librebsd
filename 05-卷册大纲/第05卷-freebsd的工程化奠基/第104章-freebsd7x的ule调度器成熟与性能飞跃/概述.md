# 第 104 章 FreeBSD 7.x 的 ULE 调度器成熟与性能飞跃

> 本子章由原第 45 章拆分而来，承载 104.1-104.4 节。

## 核心内容

ULE 是 Jeff Roberson 于 2003 年在 BSDCon 提出的 FreeBSD 现代调度器，其论文开篇即指出既有线程调度器已不适应项目变化后的优先级与硬件目标（Jeff Roberson, 2003）。

FreeBSD 原调度器源自 4.3BSD 调度器，在小负载下交互性能优异，但不支持多 CPU 的处理器亲和性，且核心调度算法随进程数呈 O(n) 复杂度，无法充分利用多处理器（Jeff Roberson, 2003）。

ULE 交互式调度器具备处理器亲和性，并由内核依据交互性评分动态设置优先级，与 4BSD 共享调度器基于多级反馈队列的运行行为调节相区分（Marshall Kirk McKusick（马歇尔·柯克·麦库西克）, 2020）。

FreeBSD 原调度器无法区分不同能力的 CPU，而这对对称多线程（SMT）很重要，构成 ULE 重写的动机之一（Jeff Roberson, 2003）。
