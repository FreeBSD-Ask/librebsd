# 111.9.3 分配器路线的辨析

**要点**：分配器路线辨析：（1）per-thread arena（Linux）；（2）per-CPU arena（jemalloc）；（3）slab 分配器（Solaris libumem）；（4）LFH（Windows）。

**史料**：Evans BSDCan 2006 论文（arena 设计与性能数据）、Ghemawat TCMalloc 技术报告（Google, 2004）、Berger 等 Hoard 论文（ACM SIGPLAN Notices 35(11), 2000）［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档〕

**史观**：总纲第 4 条——分离聚合是永恒规律：四条分配器路线由同一“分配器难题”分化而来，又各自在其生态内聚合成形

**辨析**：四条路线的优劣依负载而异——多线程服务器负载利好 per-CPU arena（jemalloc），低内存与单线程场景差距缩小；路线比较必须绑定负载类型，不存在普适优劣。

Hoard: A Scalable Memory Allocator for Multithreaded Applications[J]. ACM SIGPLAN Notices, 2000, 35(11)；Gloger W. ptmalloc2[Z]. 2006 ［B］
