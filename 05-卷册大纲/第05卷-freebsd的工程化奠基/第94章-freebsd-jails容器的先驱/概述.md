## 文献增补（基于参考文献数据库）

### 观点

- Shirk 在 vBSDCon 2017 演讲《The State of Network Security Tools on BSD》中将 jails 列为 BSD 安全工具生态的核心组件，与 Snort、Suricata 等网络安全监控工具并列，认为 jails 体现了 BSD 安全哲学的工程化呈现 (Shirk, 2017)。

### 说明

- Shirk 在演讲中梳理 BSD 安全工具现状时说明，jails 与 **BPF**、PF 等工具协同构成 BSD 安全栈，是网络监控与隔离基础设施的关键一环；演讲同时指出 FreeBSD 3.0 于 1998 年引入 SMP 支持、4.x 仍依赖 Giant Lock、5.0 于 2003 年发布等版本脉络，为 jails 在 4.x 时期诞生的工程语境提供旁证 (Shirk, 2017)。

### 辨析（2026-08-14 双库核查）

- “Jails 由 Poul-Henning Kamp（波尔-亨宁·坎普） 开发”经邮件列表库验证通过（来源：freebsd 列表 1999-05-04 Poul-Henning Kamp《Re: Jail - any success?》、1999-03-26 PHK《Re: "JAIL" code headed for -current》）。
- 章节索引 93.1 记“2000 年 phk”：经邮件列表库验证，jail 代码于 1999 年 1 月即进入 -current（1999-01-29 Eivind Eklund《Re: "JAIL" code headed for -current》），FreeBSD 4.0 于 2000 年 3 月发布，PHK 为开发者，年份归属一致。
- Shirk 所述“FreeBSD 3.0 于 1998 年引入 SMP、5.0 于 2003 年发布”为演讲旁证，两库无法直接验证该版本脉络，保留原述。

### 批评

- Zhang 等在《MEBS: Uncovering Memory Life-Cycle Bugs in Operating System Kernels》中通过基于 **LLVM** 的跨过程全局调用图与特征化源识别方法，对 FreeBSD 与 Linux 内核进行内存生命周期 bug 检测，实验暴露 100 余个新 bug 并分配 12 个 CVE，揭示 jails 隔离层之下的内核内存分配—解引用—释放链存在安全缺陷，jails 作为容器隔离机制并不能消除内核本体的内存生命周期风险 (Zhang 等, 2021)。
