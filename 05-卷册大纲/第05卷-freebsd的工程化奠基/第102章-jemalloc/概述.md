# 第 102 章 jemalloc

## 核心内容

jemalloc 是 Jason Evans 于 2006 年为 FreeBSD 设计的可扩展并发内存分配器，其直接动因是 FreeBSD 自第 5 版起持续推进多处理器（SMP）扩展，使 C 库的 `malloc(3)` 成为多线程应用在多处理器系统上的性能瓶颈（Jason Evans, 2006）。

jemalloc 的前任是 Poul-Henning Kamp（波尔-亨宁·坎普） 于 1998 年实现的 phkmalloc，长期被认为是可用分配器中的最佳之一（Jason Evans, 2006）。

jemalloc 的核心算法创新是采用多个 arena 分配内存，并以比哈希更可靠的轮转（round-robin）机制为线程分配 arena，避免了伪随机哈希导致 arena 负载不均的问题（Jason Evans, 2006）。

关于 jemalloc 成为 FreeBSD 默认分配器的时间存在口径分歧：Deb Goodkin（德布·古德金） 的 FreeBSD 时间线称 2005 年 jemalloc 即开始作为 FreeBSD 的 libc 分配器使用（Deb Goodkin, 2019），而章节索引 102.3 记为 FreeBSD 7.0（2008 年）默认，二者分别指向“开始采用”与“成为默认”两个不同节点。

### 史观映射

> 总纲第 3 条——不存在进步只有权力再分配：jemalloc 是 BSD 代码散逸的教科书案例——Jason Evans 写出的 arena 分配器被 Facebook 和 Mozilla 拿走，BSDL 允许他们这样做，也允许他们不回馈。但更深的散逸不在代码，在话语：Evans 自己承认 jemalloc 在 Linux 上相对 glibc ptmalloc 的优势“不足以构成替换理由”，Linux 社区评论者普遍认为“除非系统分配器真的糟透了，否则没理由换”——一个技术优秀的分配器，就这样被“够用就行”的保守态度挡在了 glibc 的墙外
