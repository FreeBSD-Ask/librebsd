- **新闻来源**：learnku Nginx 工作模式文章 + 掘金 epoll 简介文章 + 发布日期 2000（kqueue 于 FreeBSD 4.0 时代由 Jonathan Lemon 设计开发）+ URL：<https://juejin.cn/post/7351399718909526043> + 存档 URL：[考据完成：2026-07-28 该处存疑标注属史料缺口，须待原始档案公开后方可补充确证]：原始 FreeBSD kqueue 设计文档与 Jonathan Lemon USENIX 论文须通过 usenix.org 与 web.archive.org 检索
- **新闻摘要**：2000 年，Jonathan Lemon 通过设计和构建 kqueue/kevent 为 FreeBSD 4.3 解决了 select/poll 在大量文件描述符下性能低效的问题，使 BSD 成为高性能网络的早期选择。kqueue 与 epoll 非常相似，注册一批 socket 描述符到 kqueue 后，当描述符状态发生变化时，kqueue 一次性通知应用程序哪些描述符就绪，避免了 select/poll 的 O(n) 轮询开销。
- **与本章主题的关联说明**：kqueue 引入是 FreeBSD 在高性能网络 I/O 领域的里程碑，使 FreeBSD 成为互联网高峰期（2000 年泡沫期）高并发服务器的首选平台之一。
