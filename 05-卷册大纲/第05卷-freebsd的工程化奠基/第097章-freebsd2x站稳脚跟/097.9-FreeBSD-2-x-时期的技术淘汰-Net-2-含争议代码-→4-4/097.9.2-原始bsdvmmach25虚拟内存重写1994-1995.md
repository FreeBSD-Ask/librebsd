# 097.9.2 原始 BSD VM → Mach 2.5 虚拟内存重写（1994-1995）

  **要点**：FreeBSD 1.x 沿用 4.3BSD-Net/2 的原始 BSD 虚拟内存子系统，缺少现代共享内存、mmap 高效实现、demand paging 优化；FreeBSD 2.0-RELEASE（1994.11.22）以 Carnegie Mellon University Mach 2.5 虚拟内存系统为蓝本重写 VM 子系统，由 John Dyson 等主导；Mach 2.5 VM 引入基于页的内存管理、更高效的 fork/clone、改进的 swap 子系统；FreeBSD 2.0 公告中明确称：

  > featured a revamp of the original Carnegie Mellon University Mach virtual memory system, which was optimized for performance under high loads
  >
  > ——FreeBSD 2.0-RELEASE Announcement, 1994-11-22

  Mach VM 重写为后续 3.x、4.x 时期 SMP 与多线程支持奠定基础；同期 NetBSD 1.0 亦使用 Mach 2.5 VM，但实现路径不同
  
**史料**：FreeBSD 2.0-RELEASE Release Notes；John Dyson 在 freebsd-hackers 邮件列表 1994-1995 年关于 VM 重写的讨论；CMU Mach 2.5 设计文档；Richard Rashid（理查德·拉希德） 等 "Machine-Independent Virtual Memory Management for Paged Uniprocessor and Multiprocessor Architectures"（CMU-CS-88-1） ［A］
  
**史观**：技术选择的代价：FreeBSD 选择 Mach 2.5 VM 重写付出短期稳定性代价，但获得长期 SMP 与多线程扩展能力；总纲第 17 条——形式与内容：VM 子系统作为 “形式”（内存管理框架）改变 “内容”（应用程序可用的内存模型）
  
**辨析**：经 freebsd.duckdb `commits` 表验证（2026-07-22 查询），1994-1995 年间 freebsd-src 仓库存在 3 条严格 Mach 微内核相关 commit：(1) David Greenman（大卫·格林曼） 1994-10-15T13:33:09Z commit 976e77fc9c178ec1373d3e867d3d35d3005c64cd "1) Some of the counters in the vmmeter struct don't fit well into the Mach VM"，证明 Mach VM 概念在 2.0-RELEASE（1994.11.22）前后已存在；(2) Poul-Henning Kamp（波尔-亨宁·坎普） 1995-12-13T10:35:36Z commit c08c8adcf5230aeaf555f77eff6290285ab74192 "Remove MACH_KERNEL, ORIGINAL, and ZP_DEBUG, I should have done this before it was imported."；(3) Bruce Evans 1995-12-27T16:16:02Z commit f15351202fdaa20a5e0b07fb7272a9cd719b2bfe “Finished removing MACH_KERNEL stuff.”——1995 年 12 月的两条 commit 证明 MACH_KERNEL 宏在 FreeBSD 2.x 时期曾被使用，但于 1995 年末被系统性移除，反映 FreeBSD 早期确实引入了 Mach VM 概念但逐步去除了 Mach 微内核相关抽象，与 “FreeBSD 使用 Mach 2.5 的 VM 部分而非 microkernel 整体” 叙事方向一致；John Dyson 在 VM 子系统的角色经 freebsd.duckdb `commits` 表验证：Dyson（<dyson@FreeBSD.org>）在 1995-04 至 1995-11 期间提交 13 条 VM 相关 commit（如 1995-04-21 commit 7e15fd27577744fa48ca9fde818f113b7bd52927 " Fixed a problem in _vm_object_page_clean that could cause an infinite loop.“、1995-09-03 ” New subroutine vm_page_set_validclean for a vfs_bio improvement.“、1995-11-05 ” Greatly simplify the msync code."），证明 Dyson 确为 2.x 时期 VM 子系统的主要维护者；0 信任原则提示：Dyson 的 commit 集中在 1995 年（2.0-RELEASE 于 1994.11.22 发布后），可能反映 2.0 VM 重写后的持续优化而非 2.0 重写本身，2.0 VM 重写（1994.11.22 前）的具体主导者仍需对照 1994 年 commit log 与邮件列表核验；存疑部分解决：Mach VM 概念存在性已确认（MACH_KERNEL 宏于 1995-12 移除），John Dyson 角色（1995 年 VM 维护者）已确认，但 Mach 2.5 与 Mach 3.0 的版本区分在 commit message 中未明确，仍需对照 CMU Mach 设计文档与 FreeBSD 2.0 源码核验；FreeBSD 2.0 VM 与同期 NetBSD 1.0 VM 的具体差异需对照源码核验
