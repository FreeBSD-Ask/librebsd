# 097.10.2 Windows NT 4.0

  **要点**：Windows NT 4.0(1996.7) 将图形驱动移入内核以提升性能，引入 IIS 2.0 与 TCP/IP 栈改进，但其网络栈仍为微内核设计且缺乏 sendfile 等零拷贝 API，在静态 Web 服务场景下吞吐量低于 FreeBSD
  
**史料**：Microsoft Windows NT 4.0 Resource Kit、IIS 2.0 文档、Windows NT 4.0 网络架构白皮书［考据注：2026-07-28 联网核验留痕；语义以正文与所引来源为准］ 〔L3 官方文档〕
  
**史观**：专题语（不设总纲条号）——硬件与软件辩证（原挂总纲第 7 条系自创名目，删条号），NT 4.0 将图形移入内核是硬件性能压力下的妥协
  
**辨析**：NT 4.0 与 FreeBSD 2.x 的 Web 服务性能对比受 IIS 与 Apache 实现差异影响，难以纯操作系统层面比较
  
**文献**：Custer《Inside Windows NT》(2nd ed., 1998)；Microsoft TechNet NT 4.0 文档；SPECweb96 基准测试报告 [考据脚注：Helen Custer《Inside Windows NT》（Microsoft Press, 1998, 2nd ed.）经多源出版信息确认。]
