# 91.4 OpenSSH 默认集成——OpenBSD 代码回流 FreeBSD

## 91.4.1 OpenBSD 代码回流 FreeBSD
  - 要点：OpenSSH 由 OpenBSD 项目开发 (1999)，FreeBSD 在 4.0(2000) 后默认集成，体现 BSD 生态跨项目代码流动；OpenSSH 替代了早期 SSH Communications 商业版 SSH

## 91.4.2 默认集成的工程决策
  - 要点：FreeBSD 选择 OpenSSH 作为默认 SSH 服务，取代商业版 SSH Communications 的有限许可，决策基于安全与许可证考量；OpenSSH 的 BSD 许可证允许 FreeBSD 自由集成
  - 史料：freebsd-security 邮件列表讨论、Core Team 决策记录 ［A］
  - 史观：总纲第 24 条——许可证，OpenSSH 的 BSD 许可证促成集成
  - 辨析：是否存在 “反对” OpenSSH 集成的声音需查邮件列表
  - 文献：freebsd-security 邮件列表；Core Team 记录；OpenSSH LICENSE ［A］
## 91.4.3 安全生态的效应
  - 要点：OpenSSH 默认集成使 FreeBSD 成为安全远程管理的首选平台，SSH 普及推动了 telnet/rsh 的废弃，影响整个 UNIX 生态的安全实践
  - 史料：SSH 普及统计、BSDCon 安全演讲、freebsd-security 邮件列表 ［A］
  - 史观：总纲第 21 条——密码学，SSH 普及推动了密码学在系统管理的工程化
  - 辨析：SSH 普及是否 “完全” 归因于 OpenSSH 存在争议
