## 91.1.2 Jails 的技术架构
  - 要点：Jails 通过 **jail(2)** 系统调用扩展 **chroot(2)**，增加进程可见性隔离 (IP 地址绑定、hostname 隔离、超级权限限制)，每个 Jail 拥有独立文件系统视图与网络栈视图，是 OS 级虚拟化的早期实现
  - 史料：jail(2) 与 jail(8) 手册页、SVN 仓库 sys/kern/kern_jail.c 初始 commit、phk 的 Jails 设计文档 ［A］
  - 史观：总纲第 4 条——分离与聚合，Jails 将 chroot 的文件隔离与新的网络/进程隔离聚合
  - 辨析：Jails 是否 “真正的虚拟化” 存在争议，因内核共享未完全隔离
  - 文献：jail(2) 手册页；phk 的 Jails 文档；Kamp "Jails: Confining the Omnipotent Root"(BSDCon 2000) ［A］

## 91.1.4 4.0 史料辨析
  - 要点：4.0 史料保存较好，Release Notes 与 commit log 完整，但 phk 的 Jails 设计动机散落在邮件列表中
  - 史料：4.0 Release Notes、SVN commit log、freebsd-hackers 邮件列表 ［A］；bsd_commits.db 数据库交叉印证——统计结论 C-03 freebsd-src 仓库总 commit 数 444,203 条（`SELECT COUNT(*) FROM commits WHERE repo_name='freebsd-src'`），4.x 黄金时期（2000-2003）的 commit 分布为此累计量的中段，结合 37.1.1 节所引 L1.1.1 数据（2000 年 15,347 条、2001 年 18,105 条、2002 年 19,824 条、2003 年 15,654 条），4.x 时期 commit 量在 2002 年达峰值反映黄金时期工程活跃度的高位平台；统计结论 C-12 freebsd-src 变点检测 1999-08（Pettitt 与 BUISHAND 双检验一致 p < 0.001），距 2020-01 SVN-to-Git 迁移 245 个月，判定为非迁移伪变点，1999-08 距 4.0 发布（2000-03-14 公告 / 2000-03-20 tagger_date）仅 7 个月，变点反映 3.x 维护期向 4.x 黄金时期切换的工程节律结构性转变，为 4.0 的发布提供了 commit 时序上的前置背景；Python 脚本 `script/phase2_inferential.py` Task 6（Pettitt 自实现 + BUISHAND R 自实现），查询日期 2026-07-27 ［B］

## 91.1.5 Jails 工作的赞助与捐赠来源（SANE 2000 论文记载）
  - 要点：Kamp 与 Watson 合著的 Jails 论文（SANE 2000，荷兰马斯特里赫特）记载，jails 工作由 servetheweb.com 赞助并捐赠给 FreeBSD 项目，FreeBSD 4.0-RELEASE 是首个包含该代码的发布，后续工作由 Safeport Network Services 赞助（Kamp & Watson, 2000）——为 4.0 引入 jails 提供了一手史料，也说明 jails 的起源与商业托管服务（ISP 隔离需求）直接相关
  - 史料：Kamp & Watson. Jails: Confining the omnipotent root [C]. SANE 2000. references_fulltext ref 2689/499 ［A］
  - 史观：总纲第 13 条——法律与道德是利益分配，商业赞助与捐赠使 jails 以“商品”形式进入 FreeBSD 项目，体现 BSD 生态与商业的既有共构关系
  - 辨析：servetheweb.com 与 Safeport Network Services 的商业模式与 jails 设计的因果方向（是隔离需求催生赞助还是赞助催生需求）须对照 phk 个人陈述核验
  - 文献：Kamp & Watson. Jails: Confining the omnipotent root [C]//Proceedings of SANE 2000. Maastricht, 2000 ［A］
