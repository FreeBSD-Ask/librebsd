# 92.3 IPv6 与 KAME——4.x 时期的网络协议栈

## 91.3.1 IPv6 协议栈实现

  **要点**：FreeBSD 4.x 集成 KAME 项目的 IPv6 协议栈，KAME 由日本 WIDE 项目资助，1998 年启动，提供生产级 IPv6 实现包括邻居发现、无状态地址自动配置、IPv6 过渡机制 (6to4)
  
**史料**：KAME 项目档案、SVN 仓库 sys/netinet6/ commit、KAME 中间发布快照 ［A］
  
**史观**：总纲第 11 条——国家政策，KAME 由日本 WIDE 项目资助体现国家政策对技术的影响
  
**辨析**：KAME 代码进入 FreeBSD 的版本存在 4.0 与 4.1 争议，需查 commit log

## 91.3.2 IPsec 安全框架

  **要点**：FreeBSD 4.x 集成 KAME 的 IPsec 实现，支持 AH/ESP 协议、IKE 密钥交换、VPN 隧道；IPsec 是 IPv6 的强制组件但 IPv4 可选
  
**史料**：KAME IPsec 文档、SVN 仓库 sys/netipsec/ commit、setkey(8) 手册页 ［A］
  
**史观**：总纲第 21 条——密码学，IPsec 是密码学在网络安全上的工程实现
  
**辨析**：KAME IPsec 与 Linux FreeS/WAN 的优劣比较存在争议
  
**文献**：KAME 文档；RFC 4301-4309；setkey(8) 手册页 ［A］

## 91.3.3 网络安全的工程意义

  **要点**：IPv6/IPsec 集成使 FreeBSD 成为早期 IPv6 部署的首选平台，支撑了日本 WIDE 项目与亚太 IPv6 试点，也为 6bone 实验网络提供了稳定实现
