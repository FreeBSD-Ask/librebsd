## 95.8.5 跨项目采用实证：PostgreSQL 13 以 kqueue 替代 poll（2020）

  **要点**：Thomas Munro 在 BSDCan 2020 报告，PostgreSQL 13 以 **kqueue(2)** 替代 **poll(2)** 进行多路复用等待，大幅降低高核数、多活动连接系统的系统时间，类似于 Linux 上采用 **epoll(2)** 的改进（Munro, 2020）——补充 95.8.1 节“PostgreSQL 8.x 后端连接池”之后的新采用案例，显示 kqueue 在 2020 年代仍作为 FreeBSD 上主流数据库的事件通知接口持续生效
  
**史料**：Munro. PostgreSQL on FreeBSD [C]. BSDCan 2020. references_fulltext ref 717 ［A］
  
**史观**：总纲第 25 条——终结与延续，kqueue 从 FreeBSD 内核原语延续为跨项目采用的基础设施
  
**辨析**：Munro 同时为 PostgreSQL 与 FreeBSD 开发者（<tmunro@postgresql.org> 与 <tmunro@freebsd.org>），该采用属个人驱动还是社区共识须对照 PostgreSQL 13 release notes 核验；其报告中“大幅降低系统时间”为特定负载（hw.ncpu=88）下的观测，不得泛化为普遍结论
  
**文献**：Munro. PostgreSQL on FreeBSD: Some news, observations and speculation [C]//BSDCan 2020. Ottawa, 2020 ［A］
