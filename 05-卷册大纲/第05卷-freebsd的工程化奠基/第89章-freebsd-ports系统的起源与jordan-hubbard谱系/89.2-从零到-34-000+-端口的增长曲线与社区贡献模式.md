# 88.2 从零到 34,000+ 端口的增长曲线与社区贡献模式

## 88.2.1 Port 增长曲线
  - 要点：Port 数量从 1994 年的约 100 个增长至 2010 年的 24,000 余个，2024 年突破 34,000 个，增长曲线呈指数型，1998-2002 年互联网泡沫期增速最快 (年增 30%-50%)，2005 年后增速放缓但仍保持年增 5%-10%

## 88.2.2 社区贡献模式
  - 要点：Ports 社区贡献模式以 maintainer 制度为核心，每个 port 由 1-3 名 maintainer 维护，无 maintainer 的 port 由 ports-secteam 集体维护，新 port 通过 submit PR 提交，committer 评审后导入，形成约 500 名活跃 maintainer 与 100 名 committer 的贡献金字塔
  - 史料：freebsd-ports 邮件列表、GNATS/Bugzilla PR 数据库、Maintainers Guide 各版本、Ports Committer 指南 ［A］
  - 史观：总纲第 23 条——社区治理，Ports 的 maintainer 制度是分布式治理的早期实验
  - 辨析：maintainer 数量的精确统计困难，因部分 maintainer 使用团队邮箱 (如 <ports@FreeBSD.org>)
  - 文献：FreeBSD Porter's Handbook；Maintainer's Guide；freebsd-ports 邮件列表 FAQ ［A］
## 88.2.3 增长模式的辨析
  - 要点：Ports 指数增长背后存在质量问题，部分 port 因 upstream 消失或缺乏维护而 broken，2005 年引入 expire-ok 机制自动清理长期 broken 的 port，反映“增长 vs 质量”的张力
  - 史料：freebsd-ports 邮件列表关于 broken port 清理的讨论、Ports Quarterly Report 中 broken 统计、expire-ok 机制 commit log ［A］
  - 史观：总纲第 3 条——形式主义膨胀，Port 数量的形式主义增长可能掩盖质量衰退
  - 辨析：broken port 的定义标准在不同时期不同，1998 年与 2008 年的 broken 判定阈值存在差异
  - 文献：Ports Quarterly Report；freebsd-ports 邮件列表；expire-ok 机制文档 ［A］
## 88.2.4 增长史料辨析
  - 要点：Port 增长曲线的史料保存较好，但早期 (1994-1996) 的精确数量因 CVS 仓库迁移存在统计偏差，需以 freshports.org 的重建数据为准
  - 史料：freshports.org 数据库、SVN 仓库 ports/ 目录统计、freebsd-ports-announce 里程碑公告 ［A］
  - 史观：总纲第 17 条——软件工程，Port 数量统计的准确性依赖版本控制元数据的完整保存
  - 辨析：freshports.org 的数据可能存在重复 port 或别名 port 的统计问题
  - 文献：FreshPorts 数据库说明；freebsd-ports 邮件列表；Ports 统计方法论文档 ［A］
## 88.2.5 ports 仓库版本控制系统迁移时间线与 port 数量统计口径
  - 要点：FreeBSD 官方文献记载，ports 树创建于 1994 年，以 CVS 跟踪至 2012 年 7 月 15 日 Subversion 接管，2021 年 4 月 6 日又从 Subversion 迁移至 Git（Mingrone, 2022）；2022 年初 ports 仓库已包含超过 40,000 个 port 与 28 年历史（Mingrone, 2022）——与本子节 88.2.1“2024 年突破 34,000 个”的既有统计存在显著口径差异，提示 port 计数随统计方式（是否含 broken/deprecated、是否按活跃维护过滤）波动
  - 史料：Mingrone. Contributing to FreeBSD Ports with Git. FreeBSD Journal, 2022 (Jan/Feb). references_fulltext ref 1004 ［A］
  - 史观：总纲第 17 条——软件工程，版本控制迁移（CVS→SVN→Git）影响 port 数量统计的可复现性
  - 辨析：40,000+（2022）与 34,000+（2024）两组数字可能分别对应“仓库中全部 port 条目数”与“可构建/活跃 port 数”，须在正文中明确标注口径，避免引用冲突；Mingrone 所载 SVN 接管日期（2012-07-15）与本卷 87.8 节 ports 仓库迁移首 commit 日期（2012-07-14）相差一日，须以 SVN 转换日志为准交叉核验
  - 文献：Mingrone. Contributing to FreeBSD Ports with Git [J]. FreeBSD Journal, 2022(1): 12-18 ［A］
