# 88.1 Jordan Hubbard 的 port make macros 谱系

## 88.1.1 port make macros 的起源
  - 要点：Jordan Hubbard 1994 年 8 月的 port make macros 是 Ports 系统的雏形，最初仅是一组 Makefile 宏用于简化 fetch/extract/patch/build/install 流程，后演化为 bsd.port.mk 框架；起源动机是 Hubbard 在 FreeBSD 1.x 时期手动编译 200 余个软件的疲劳
  - 史料：Hubbard 1994.8.21 freebsd-hackers 邮件、SVN 仓库 ports/Mk/bsd.port.mk r1 commit、Hubbard 在 BSDCon 1998 的 Ports 演讲；bsd_commits.db freebsd-ports 仓库 tags 表最早 release tag 为 release/2.0.5a（tagger_date = 1995-05-29T13:46:40Z）与 release/2.0.5（tagger_date = 1995-05-29T13:46:42Z），证明 Ports 系统在 FreeBSD 2.0.5 时期已作为独立仓库与 src 同步发布 ［A］
  - 史观：总纲第 2 条——实践先于理论，Ports 起源于手动编译的实践疲劳而非软件包管理理论
  - 辨析：Hubbard 是否参考了同期 NetBSD pkgsrc(1997) 存在时序问题，pkgsrc 比 FreeBSD Ports 晚约 3 年，但两者是否独立演化需考据；bsd_commits.db freebsd-ports 仓库现存 114 个 release tag，最早为 1995-05-29，与 FreeBSD 2.0.5 同期发布，印证 Ports 自 2.0.5 起即作为官方分发组件
  - 文献：Hubbard"The FreeBSD Ports System"(BSDCon 1998)；FreeBSD Porter's Handbook 历史章节；Lehey《The Complete FreeBSD》Ports 章节；release/2.0.5a. freebsd-ports 仓库 tag [DB/OL]. 1995-05-29T13:46:40Z. tag: release/2.0.5a ［A］
## 88.1.2 从早期结构到框架演化
  - 要点：Ports 从 1994 年的简单 Makefile 宏演化为 1998 年的 bsd.port.mk 框架，期间引入 MASTER_SITES、WRKSRC、PLIST、pkg-message 等约定，distfiles 与 packages 目录分离，category 体系从 12 个扩展至 60 余个
  - 史料：SVN 仓库 ports/Mk/bsd.port.mk commit 历史、freebsd-ports 邮件列表 1995-1998 年讨论、Ports 目录树快照 ［A］
  - 史观：总纲第 5 条——组织结构塑造技术路径，bsd.port.mk 的变量约定决定了后续 20 年 Ports 的演化方向
  - 辨析：MASTER_SITES 的多镜像机制引入时间存在 1996 与 1997 两种说法，需查 bsd.port.mk commit log
  - 文献：FreeBSD Porter's Handbook 各版本；bsd.port.mk 历史变更日志；Hubbard 在 BSDCon 的 Ports 演讲 ［B］
## 88.1.3 谱系的版本演进
  - 要点：bsd.port.mk 从 1.0(1994) 经历 2.0(1996 引入 PLIST)、3.0(1998 引入 OPTIONS)、4.0(2002 引入 USE_AUTOTOOLS) 等大版本演化，每次大版本引入新的变量约定与构建阶段，向后兼容通过 .if 分支维持

  bsd.port.mk 大版本演化（社区约定编号）：

  | 版本 | 年份 | 关键引入 | 向后兼容 |
  | --- | --- | --- | --- |
  | 1.0 | 1994 | 基础 fetch/extract/patch/build/install | —— |
  | 2.0 | 1996 | PLIST、MASTER_SITES 多镜像 | `.if` 分支 |
  | 3.0 | 1998 | OPTIONS 编译期选项 | `.if` 分支 |
  | 4.0 | 2002 | USE_AUTOTOOLS、USE_GNOME | `.if` 分支 |

  - 史料：SVN 仓库 ports/Mk/bsd.port.mk 版本标签、bsd.port.mk 变更日志、Ports 升级指南 ［A］
  - 史观：总纲第 25 条——终结与延续，bsd.port.mk 的演化是“终结旧约定、延续旧 port”的辩证过程
  - 辨析：bsd.port.mk 的版本号从未被官方编号，所谓 1.0/2.0/3.0 是社区约定，需以功能引入为分界
  - 文献：bsd.port.mk 变更日志；Ports 升级指南各版本；freebsd-ports 邮件列表讨论 ［A］
## 88.1.4 谱系史料辨析
  - 要点：bsd.port.mk 的演化史料保存于 SVN commit log，但早期 commit message 较简略，部分功能引入的具体时间需对照 freebsd-ports 邮件列表
