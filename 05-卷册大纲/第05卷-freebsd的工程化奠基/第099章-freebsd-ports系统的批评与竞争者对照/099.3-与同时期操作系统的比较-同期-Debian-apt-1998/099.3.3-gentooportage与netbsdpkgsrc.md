# 099.3.3 Gentoo Portage 与 NetBSD pkgsrc

  **要点**：Gentoo Portage(2002) 由 Daniel Robbins 设计，直接借鉴 FreeBSD Ports 的源码编译理念，用 Python 重写 bsd.port.mk 等价物；NetBSD pkgsrc(1997) 由 Alistair Crooks 与 Hubert Feyrer（胡贝特·费雷尔） 设计，与 FreeBSD Ports 同源但独立演化，支持多平台

  4 大 ports 树年度 commit 量对比（dragonfly.duckdb 查询 L4.4.1）：

**史料**：Gentoo Portage 设计文档、pkgsrc 源码、freebsd-ports 邮件列表关于 Portage 借鉴的讨论 ［A］；freebsd.duckdb 查询 L4.4.1 显示：4 大 ports 树（freebsd-ports/openbsd-ports/netbsd-pkgsrc/dragonfly-dports）年度 commit 量对比——freebsd-ports 1996 年 2,551 条、2000 年 12,096 条、2005 年 24,598 条；netbsd-pkgsrc 1997 年 657 条（首次出现）、2000 年 17,609 条（超越 freebsd-ports 同年 12,096 条）、2002 年 34,811 条、2004 年 83,373 条（峰值）、2005 年 73,069 条；openbsd-ports 1997 年 186 条、2000 年 458 条、2010 年 786 条；dragonfly-dports 2012 年才出现（16,516 条），第四卷时间窗口（1996-2010）内不存在，netbsd-pkgsrc 在 2000 年后 commit 量持续超越 freebsd-ports 反映 pkgsrc 多平台可移植策略带来的仓库规模扩张
  
**史观**：总纲第 4 条——分离与聚合，Ports 理念分离至 Gentoo 与 NetBSD 后各自聚合演化
  
**辨析**：Portage 是否“抄袭”Ports 存在争议，Robbins 公开承认借鉴但社区有不同声音；【0 信任原则·commit 量不等于质量】L4.4.1 中 netbsd-pkgsrc 的 commit 量超越 freebsd-ports 不等于 pkgsrc 生态优于 FreeBSD Ports，因 pkgsrc 支持多平台导致每个平台的 port 独立维护，commit 量存在重复计数，须结合独立 port 数量（非 commit 量）交叉验证
