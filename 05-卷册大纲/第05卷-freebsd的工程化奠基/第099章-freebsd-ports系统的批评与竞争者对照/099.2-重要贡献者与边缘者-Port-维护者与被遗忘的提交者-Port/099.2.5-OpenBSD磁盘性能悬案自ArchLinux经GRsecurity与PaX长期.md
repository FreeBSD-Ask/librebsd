# 099.2.5 OpenBSD磁盘性能悬案自ArchLinux经GRsecurity与PaX长期

- OpenBSD 磁盘性能悬案：自 Arch Linux（经 GRsecurity 与 PaX 长期加固）转向 OpenBSD 5.5 stable 的听众报告 SSD 上 iostat 峰值仅约 180MB/s，而 Linux 全盘 AES-256 加密可达 350MB/s；主持人指出 OpenBSD 出于安全考量以 Giant Lock 将多核操作强制于单锁之下、多核性能受限，同时提醒 Linux 数字可能包含不安全的写缓存，并强调 FFS/UFS 本身并不慢，建议核对 CPU 占用；该问题当期未获最终解释，留待 OpenBSD 社区反馈。 [存疑脚注] 性能差异成因仅为主持人基于 Giant Lock 架构的推断，当期无实测结论（BSD Now EP41，[3094.68-3315.54]，L2）
