# 93.11 重要贡献者与边缘者——被忽视的 committer 谱系

## 92.11.1 被忽视的 committer 谱系

  **要点**：4.x 时期约 200 名 committer 中，约 60% 在社区记忆中被忽视，他们的贡献散落在 commit log 中，包括驱动维护、文档撰写、bug 修复
  
**史料**：SVN commit log、Core Team 名单、freebsd-committers 邮件列表 ［A］
  
**史观**：总纲第 10 条——边缘者贡献，被忽视的 committer 是 4.x 稳定的基础设施
  
**辨析**：被忽视的程度需统计 commit 量与社区认知
  
**文献**：commit log；Core Team 名单；邮件列表 ［A］

## 92.11.2 边缘贡献者辨析

  **要点**：4.x 时期边缘贡献者包括测试反馈者、文档翻译者、PR 提交者，他们通过 send-pr 与邮件列表参与但未获 commit 权限
  
**史料**：GNATS PR 数据库、freebsd-doc 邮件列表、翻译团队记录 ［A］
  
**史观**：总纲第 10 条——边缘者贡献，边缘贡献者的劳动是 4.x 质量的基础
  
**辨析**：边缘贡献者的贡献难以量化
  
**文献**：PR 数据库；邮件列表；翻译团队记录 ［A］

## 92.11.3 贡献者与版本的关系

  **要点**：4.x 系列的每个版本 (4.0-4.11) 涉及不同贡献者群体，部分贡献者横跨多版本，部分仅参与单版本，贡献者与版本的关系需从 commit log 重建
  
**史料**：SVN commit log、Release Notes、Core Team 记录 ［A］
  
**史观**：总纲第 25 条——终结与延续，贡献者与版本的关系体现延续性
  
**辨析**：贡献者归属需对照 commit log
  
**文献**：commit log；Release Notes；Core Team 记录 ［A］

## 92.11.4 边缘者史料辨析

  **要点**：4.x 边缘贡献者史料保存较差，仅 commit log 与 PR 数据库可查，部分 PR 在迁移时丢失
  
**史料**：SVN commit log、GNATS/Bugzilla 数据库、邮件列表 ［A］
  
**史观**：总纲第 17 条——软件工程，边缘贡献者史料是开源史学挑战
  
**辨析**：部分贡献者使用化名
  
**文献**：commit log；PR 数据库；邮件列表 ［A］
