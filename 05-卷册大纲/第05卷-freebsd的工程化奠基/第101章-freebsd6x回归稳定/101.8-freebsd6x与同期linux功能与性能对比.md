# 101.8 FreeBSD 6.x 与同期 Linux 功能与性能对比

## 101.8.1 6.x vs Linux 2.6 I/O 路径对比

**要点**：6.x 引入 DEVFS 重写、CAM 层改进与 UFS2 SUJ。标准 I/O 基准测试中同步写入负载表现出色，但异步 I/O 与内存映射 I/O 落后于 Linux 2.6。

**史料**：FreeBSD 6.x 基准测试（2006）; Phoronix 2006-2007 ［A］

**史观**：总纲第 8 条——性能比较是技术路线的实证检验。

**辨析**：跨项目功能比较存在方法论陷阱——同一功能在不同项目中的实现时间、成熟度和目标用户群不同，直接的功能矩阵对比可能掩盖设计哲学的差异。性能基准测试受硬件平台、编译器版本和工作负载选择影响，不同来源的基准数据常有矛盾。比较时应区分“功能有无”和“实现质量”两个维度。
**文献**：基准测试； Phoronix ［A］
