## 101.2.1 取代 KSE M: N 的决策

  **要点**：6.x 决定用 libthr 1:1 线程模型取代失败的 KSE M: N；决策由 David Xu 等主导，理由是 1:1 实现简单、性能可接受、与 Linux NPTL 一致

  KSE M: N 与 libthr 1:1 线程模型对照：

  | 特性 | KSE M: N（5.x） | libthr 1:1（6.x+） |
| -- | ------------- | ---------------- |
| 模型 | M 个用户线程映射 N 个内核线程 | 每个用户线程对应一个内核线程 |
| 设计者 | Daniel Eischen、Julian Elischer | David Xu |
| 用户态调度器 | 需要 | 不需要 |
| 内核线程数 | 可控（少于用户线程） | 等于用户线程 |
| 实现复杂度 | 高 | 低 |
| 性能 | 理论优势，实际不佳 | 可接受 |
| 与 Linux NPTL 一致 | 否 | 是 |
| 生命周期 | 5.3 默认 → 7.0 被取代 | 6.0 默认至今 |
