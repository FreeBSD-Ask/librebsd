# 102.1 2004 年 OpenBSD 的 PF 移植到 FreeBSD

## 102.1.1 PF 的 OpenBSD 源起
  - 要点：PF（Packet Filter）由 Daniel Hartmeier（丹尼尔·哈特迈尔） 与 OpenBSD 团队于 2001 年开发，替代因许可证争议被移除的 IPFilter；PF 采用规则集优化（skip steps）与状态保持（stateful inspection）设计，首版随 OpenBSD 3.0（2001.12）发布
  - 史料：Hartmeier 的 openbsd-misc 2001 邮件、OpenBSD 3.0 Release Notes、**pf.conf(5)** 手册页原始版本 ［A］；bsd_commits.db 查询 L2.3.1.pf 显示：中观模式挖掘报告中 L2.3.1 特性查询仅覆盖 ZFS/Capsicum/bhyve/Clang/ARM64/RISC-V 六项，无 pf 专项查询，PF 引入到稳定周期的 commit 时间序列须直接查询 bsd_commits.db 获取（建议查询条件：commit message 含 "pf" 或 "packet filter" 关键词，或 file_path 含 "sys/netpfil/pf" 路径）；bsd_commits.db 查询 L2.4.1.pf 显示：L2.4.1.Import from 查询使用关键词 "Import from" 匹配 message_subject/message_body，但 PF 导入 commit 的 message_subject 为 "Import pf from OpenBSD 3.5 (OPENBSD_3_5_BASE)"（commit_hash = 32b30983561ed562aa495d8e124488ab94b332aa），"Import pf from" 不含连续 "Import from" 子串，故 L2.4.1 查询未命中 PF 导入 commit，反映关键词匹配查询的局限性；bsd_commits.db 查询 L2.2.1.sys_net 显示：freebsd-src sys/net/ 子系统年度 commit 量在 PF 移植前后呈波动——2004 年（PF 导入年）4,764 条（files_touched = 674）、2005 年（PF 集成后开发活跃期）5,598 条（files_touched = 694）、2006 年 3,185 条、2007 年 3,336 条、2008 年 6,334 条（files_touched = 775，可能与 8.0 网络栈改进相关），2005 年 commit 量较 2004 年增长 17.5% 反映 PF 集成后网络子系统开发活跃度提升 ［A］
  - 史观：总纲第 1 条——偶然性改写历史，IPFilter 许可证争议催生 PF 这一全新防火墙
  - 辨析：PF 是否完全由 Hartmeier 一人开发，需查 commit log 确认其他 OpenBSD 开发者的贡献；0 信任原则适用说明：L2.3.1.pf 查询在中观模式挖掘报告中缺失，须直接查询 netbsd.db 验证 PF 引入周期；L2.4.1.Import from 查询使用 "Import from" 关键词未命中 PF 导入 commit（message_subject 为 "Import pf from"），反映关键词匹配查询的漏命中风险，须结合 commit_hash 直接验证；L2.2.1.sys_net 基于 sys/net% 路径匹配，可能漏掉重命名后的文件（如 sys/netpfil/ 目录在 PF 重构后可能被移出 sys/net/ 匹配范围）；sys/net commit 量增长不等于 PF 贡献（可能包含其他网络子系统改进），须结合 file_path 过滤 pf 相关 commit 交叉验证
  - 文献：Hartmeier "OpenBSD Packet Filter"（ONLamp 2002）；**pf.conf(5)** 手册页 ［A］；freebsd.db L2.3.1.pf 查询结果（中观模式挖掘报告缺失，须直接查询）[DB/OL]；freebsd.db L2.4.1.Import from 查询结果（PF 导入 commit 未命中，关键词匹配局限）[DB/OL]；freebsd.db L2.2.1.sys_net 查询结果（freebsd-src sys/net/ 年度 commit 量 2004-2010）[DB/OL] ［A］
## 102.1.2 移植的工程过程
  - 要点：FreeBSD 于 2004 年（5.3 RELEASE，2004.11.4，release/5.3.0 tagger_date = 2004-11-04T19:12:42Z，tagger = Ken Smith）首次将 PF 作为可选防火墙引入，由 Pyun YongHyeon、Max Laier 等完成移植；PF 导入 commit 为 2004-06-16T23:03:14Z（commit_hash = 32b30983561ed562aa495d8e124488ab94b332aa，committer = Max Laier，message_subject = "Import pf from OpenBSD 3.5 (OPENBSD_3_5_BASE)"），早于 5.3-RELEASE 约 4.5 个月，属 5-CURRENT 开发周期；移植包括内核钩子、用户态 pfctl 工具与 ALTQ 流量整形框架

  PF 导入 commit message：

  > Import pf from OpenBSD 3.5 (OPENBSD_3_5_BASE)
  >
  > ——Max Laier, commit `32b30983561ed562aa495d8e124488ab94b332aa`, 2004-06-16T23:03:14Z

  - 史料：FreeBSD 5.3 Release Notes、freebsd-pf 邮件列表、commit log；freebsd.db freebsd-src 仓库 commits 表 PF 导入 commit 为 2004-06-16T23:03:14Z（commit_hash = 32b30983561ed562aa495d8e124488ab94b332aa，committer = Max Laier，message_subject = "Import pf from OpenBSD 3.5 (OPENBSD_3_5_BASE)"）；freebsd.db freebsd-src 仓库 tags 表 release/5.3.0 的 tagger_date = 2004-11-04T19:12:42Z（target_commit_hash = f8d4987d7271c1003cce92715022709505f995c7） ［A］
  - 史观：总纲第 7 条——BSD 与 UNIX 谱系的连续性，PF 跨 BSD 项目流动体现谱系共享
  - 辨析：经 bsd_commits.db commits 表验证，PF 导入 commit 为 2004-06-16T23:03:14Z（早于 5.3-RELEASE 约 4.5 个月，属 5-CURRENT 开发周期）；经 bsd_commits.db tags 表验证，5.3-RELEASE 的 tagger_date 为 2004-11-04T19:12:42Z（非旧叙事 2004.11.6，误差 2 天，可能为公告日期与 tag 日期差异）；移植的具体时间线（5.3 引入 vs 6.1 默认推荐），需查 commit log 与 Release Notes 交叉验证；PF 移植源自 OpenBSD 3.5（OPENBSD_3_5_BASE）

## 102.1.3 跨项目流动的辨析
  - 要点：PF 从 OpenBSD 流入 FreeBSD/NetBSD/DragonFly BSD，体现 BSD 生态的代码共享性；但各 BSD 对 PF 的维护投入不同，FreeBSD 增加了 SMP 扩展与 VNET 支持，导致功能分化
  - 史料：各 BSD 的 PF 源码分支、commit log ［A］
  - 史观：总纲第 14 条——话语权与边缘者，跨项目流动是否削弱 OpenBSD 话语权
  - 辨析：跨项目流动是否真削弱 OpenBSD 话语权，需独立判断；FreeBSD 的修改是否回流 OpenBSD
