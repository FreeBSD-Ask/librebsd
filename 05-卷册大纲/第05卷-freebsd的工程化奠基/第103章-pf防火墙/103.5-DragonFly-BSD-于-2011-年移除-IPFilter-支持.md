# 103.5 DragonFly BSD 于 2011 年移除 IPFilter 支持

## 103.5.1 DragonFly BSD 移除决策

**要点**：DragonFly BSD（Matt Dillon）于 2011 年移除 IPFilter 支持，理由是 IPFilter 维护停滞且许可证历史问题；DragonFly BSD 转向 PF 作为默认防火墙

**史料**：DragonFly BSD commit log、邮件列表 ［A］

**史观**：总纲第 7 条——BSD 与 UNIX 谱系的连续性，DragonFly BSD 从 IPF 转 PF 体现谱系内部的技术选择

**辨析**：移除决策是否合理，需查 IPFilter 当时的维护状态

**文献**：DragonFly BSD commit log ［A］

## 103.5.2 移除的工程效应

**要点**：移除 IPFilter 后，DragonFly BSD 用户需迁移至 PF 或 ipfw；移除简化了内核维护但增加了用户迁移成本
