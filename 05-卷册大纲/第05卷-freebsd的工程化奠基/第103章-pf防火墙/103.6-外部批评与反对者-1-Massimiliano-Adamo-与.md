# 103.6 外部批评与反对者 ：(1) Massimiliano Adamo 与 Mauro Tablo（USENIX ; login: 2005）——论文《Linux vs. OpenBSD: A packet filter performance test》（usenix.org/system/files/login/articles/947-adamo.pdf）通过对 Linux iptables 与 OpenBSD PF 的防火墙性能测试得出结论 "iptables filters packets more quickly than PF, with only one exception (in our testing): if the transport-layer protocol of the transit packet, say, UDP, differs from the specified transport-protocol type of a sequence of rules—‘protocol type’ set to ‘TCP’in this example—PF ignores those rules and confronts the packet only with the rest of the set, acting more efficiently than Linux, which confronts the packet with all the rules in the set"——即 iptables 在大多数场景下过滤速度快于 PF，仅在一个例外场景下 PF 因协议类型不匹配跳过规则而更优

## 103.6.1 Adamo 与 Tablo 的性能测试

**要点**：Massimiliano Adamo 与 Mauro Tablo 在 USENIX ; login: 2005 发表论文，测试 Linux iptables 与 OpenBSD PF 的性能，结论是 iptables 在大多数场景下过滤速度快于 PF，仅在一个例外场景下 PF 因协议类型不匹配跳过规则而更优

## 103.6.2 Linux nftables 自建路线

**要点**：Linux netfilter 社区选择自建 nftables（2014 发布，Patrick McHardy 主导）而非移植 PF，理由是 PF 的 OpenBSD 内核耦合度不适合 Linux；nftables 采用虚拟机字节码设计，提供更灵活的规则表达

**史料**：nftables 文档、netfilter 邮件列表 ［A］

**史观**：总纲第 14 条——话语权与边缘者，Linux 自建 nftables 是对 PF 路线的工程否定

**辨析**：自建理由是否充分，需独立判断；nftables 是否真比 PF 优越
