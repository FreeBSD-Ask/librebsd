# 102.6 外部批评与反对者 **：(1)** Massimiliano Adamo 与 Mauro Tablo（USENIX ; login: 2005）——论文《Linux vs. OpenBSD: A packet filter performance test》（usenix.org/system/files/login/articles/947-adamo.pdf）通过对 Linux iptables 与 OpenBSD PF 的防火墙性能测试得出结论 "iptables filters packets more quickly than PF, with only one exception (in our testing): if the transport-layer protocol of the transit packet, say, UDP, differs from the specified transport-protocol type of a sequence of rules—‘protocol type’ set to 'TCP'in this example—PF ignores those rules and confronts the packet only with the rest of the set, acting more efficiently than Linux, which confronts the packet with all the rules in the set"——即 iptables 在大多数场景下过滤速度快于 PF，仅在一个例外场景下 PF 因协议类型不匹配跳过规则而更优

## 102.6.1 Adamo 与 Tablo 的性能测试
  - 要点：Massimiliano Adamo 与 Mauro Tablo 在 USENIX ; login: 2005 发表论文，测试 Linux iptables 与 OpenBSD PF 的性能，结论是 iptables 在大多数场景下过滤速度快于 PF，仅在一个例外场景下 PF 因协议类型不匹配跳过规则而更优
  - 史料：Adamo & Tablo "Linux vs. OpenBSD: A packet filter performance test"（USENIX ; login: 2005） ［B］
  - 史观：总纲第 4 条——0 信任原则，对性能测试的方法论与数据交叉验证
  - 辨析：测试方法是否公平，需查测试环境（硬件、规则集、流量模式）；样本是否具有代表性
  - 文献：Adamo & Tablo 论文（USENIX ; login: 2005） ［B］
## 102.6.2 Linux nftables 自建路线
  - 要点：Linux netfilter 社区选择自建 nftables（2014 发布，Patrick McHardy 主导）而非移植 PF，理由是 PF 的 OpenBSD 内核耦合度不适合 Linux；nftables 采用虚拟机字节码设计，提供更灵活的规则表达
  - 史料：nftables 文档、netfilter 邮件列表 ［A］
  - 史观：总纲第 14 条——话语权与边缘者，Linux 自建 nftables 是对 PF 路线的工程否定
  - 辨析：自建理由是否充分，需独立判断；nftables 是否真比 PF 优越
  - 文献：nftables 文档；netfilter 邮件[考据完成：2026-07-28 经穷尽联网考据，上述文献清单为已知公开来源汇总，部分原始档案未公开数字化或须付费访问，属史料缺口，须待原始档案公开后方可补充确证]
## 102.6.3 批评的形式主义分析
  - 要点：批评形式主义分析：(1) 性能测试是否全面（仅测规则过滤速度，未测状态保持、NAT 等）；(2) 自建是否合理（not invented here 综合征）；(3) 批评是否促进 PF 改进
  - 史料：论文、nftables 文档 ［B］
  - 史观：总纲第 6 条——形式主义膨胀与抽象克制
  - 辨析：批评效果，需查 PF 是否因批评而改进性能
  - 文献：论文；nftables 文档 ［B］
## 102.6.4 批评的史料辨析
  - 要点：批评史料疑点：(1) 测试环境是否一致（OpenBSD 与 Linux 内核版本、硬件）；(2) nftables 自建决策过程是否有公开讨论；(3) PF 社区对批评的回应
  - 史料：论文、邮件 ［B］
  - 史观：总纲第 4 条——0 信任原则
  - 辨析：PF 社区回应，需查 OpenBSD/FreeBSD 邮件
- 文献：freebsd-hackers mailing list archives；FreeBSD Quarterly Status Reports；The FreeBSD Foundation Annual Reports ［A］
