# 103.2 ipfw vs IPF vs PF 之争——三者的设计哲学差异

## 103.2.1 三者的设计哲学差异

**要点**：ipfw（FreeBSD 原生，1994，Ugen J.S. Antsilevich 设计〔设计者归属待一手 commit 核〕）采用规则序号 + 状态表设计；IPFilter（Darren Reed（达伦·里德），1995）采用 NAT + 状态保持设计；PF（OpenBSD，2001）采用规则集优化（skip steps）+ALTQ 集成设计；三者哲学各异，ipfw 重简洁、IPF 重跨平台、PF 重规则优化

  ipfw、IPFilter 与 PF 设计哲学对照：

  | 特性 | ipfw | IPFilter | PF |
| -- | -- | ------ |--|
| 引入年份 | 1994 | 1995 | 2001 |
| 设计者 | Ugen J.S. Antsilevich | Darren Reed | Daniel Hartmeier（丹尼尔·哈特迈尔） |
| 起源项目 | FreeBSD | 跨平台 | OpenBSD |
| 规则模型 | 规则序号 + 状态表 | NAT + 状态保持 | 规则集优化（skip steps） |
| 流量整形 | dummynet | —— | ALTQ 集成 |
| 许可证 | BSD | 争议（2001 年致 OpenBSD 移除，Darren Reed 后重授权双许可） | ISC/BSD |
| FreeBSD 状态 | 保留（原生） | 保留至今（5.3 引入 PF；IPFilter 移除系 OpenBSD 2001 年事件） | 5.3 引入 |

**史料**：**ipfw(8)**、**ipf(5)**、**pf.conf(5)** 手册页 ［A］
