# 117.3.3 开发模式变化辨析

  **要点**：开发模式变化辨析：(1) 补丁文化是否更民主；(2) 中央仓库是否更高效；(3) 边缘者参与是否减少
  
**史料**：邮件、commit log ［A］
  
**史观**：0 信任原则
  
**辨析**：模式无绝对优劣但有后果——补丁文化强调社区参与但效率受限于 committer 审核带宽，中央仓库文化强调提交效率但边缘者参与门槛提高；freebsd.duckdb 数据显示 freebsd-src 仓库月度 commit 数在 2008 年前后未发生突变，说明模式变化对总提交量影响有限
  
**文献**：freebsd-hackers mailing list patch vs commit culture (2008-2010)；freebsd-arch mailing list development model (2009)；FreeBSD Committer's Guide ［A］
