# 117.5.1 迁移决策中的技术论证与社区说服

**要点**：Peter Wemm（彼得·韦姆） 等 2007-2008 年主导迁移方案。技术核心是 SVN 的原子提交与分支效率，反对来自习惯 CVS 的老 committer 与主张直跳 Git 的激进派。

**史料**：Wemm 迁移方案（2008）; 开发者峰会纪要 ［A］

**史观**：总纲第 5 条——技术迁移中的代际张力。

**辨析**：版本控制系统迁移是技术决策与社区政治的复合事件——CVS 到 SVN 的迁移不仅是技术升级，更涉及开发流程、权限模型和贡献者习惯的变革。迁移过程中的争议（如是否应直接迁移到分布式 VCS）反映了 BSD 社区对技术变革的保守态度，这种保守性既是稳定性的保障也是创新的阻力。
**文献**：Wemm 2008; 峰会纪要 ［A］
