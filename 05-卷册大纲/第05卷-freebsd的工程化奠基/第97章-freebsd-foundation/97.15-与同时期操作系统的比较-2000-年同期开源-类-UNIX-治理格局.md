# 97.15 与同时期操作系统的比较：2000 年同期开源/类 UNIX 治理格局——Linux 2.4、NetBSD 1.5、OpenBSD 2.8、Windows 2000、Darwin——FreeBSD Foundation 成立时的治理坐标

## 97.15.1 Linux 2.4 与社区治理（2000）

  **要点**：2000 年 Linux 处于 2.2/2.4 开发期（2.4 于 2001.1 发布），由 Torvalds 个人把关（“仁慈的终身独裁者”），资金与协调由 1999 年成立的 OSDL（Open Source Development Labs）等机构逐步介入；与 FreeBSD Foundation（2000 成立）相比，Linux 当时尚无统一基金会，治理高度依赖个人权威与企业赞助（Red Hat 等）。
  
**史料**：Linux 2.4 开发时间线（2000-2001）；OSDL 成立公告（1999）［B］；Torvalds 邮件列表 ［B］
  
**史观**：总纲第 22 条——开源运动：FreeBSD Foundation 的成立是 BSD 世界对 “开源项目需要制度化治理与法律实体” 的回应，与 Linux 的 OSDL 路径殊途同归。
  
**辨析**：Foundation 模式并非 “更好”——Linux 凭借个人威望与企业资本同样成功；两种治理（基金会 vs 企业 + 个人）各适应不同社区结构。
  
**文献**：OSDL. Open Source Development Labs Announcement [Z]. 1999；Torvalds L. Linux 2.4 ChangeLog [EB/OL]. ［B］

## 97.15.2 NetBSD 1.5（2000）与治理

  **要点**：NetBSD 1.5（2000.12）延续 “极致可移植” 路线，治理由 NetBSD 核心团队（core）负责，无独立基金会；与 FreeBSD Foundation 相比，NetBSD 依赖核心团队志愿治理与少量赞助，制度化法律/资金实体出现较晚。
  
**史料**：NetBSD 1.5 发布说明（2000）；NetBSD 核心团队治理文档 ［B］
  
**史观**：总纲第 7 条——BSD 谱系：三大 BSD 在 2000 年治理模式各异（FreeBSD 有基金会、NetBSD/OpenBSD 靠核心团队），反映 BSD 家族 “去中心化、各自探索” 的特征。
  
**辨析**：无基金会不等于 “治理弱”——NetBSD 的核心团队模式运转良好；基金会是治理工具之一而非必需。
  
**文献**：NetBSD Project. NetBSD 1.5 Release Notes [Z]. 2000. ［B］

## 97.15.3 OpenBSD 2.8（2000）与治理

  **要点**：OpenBSD 2.8（2000.12）由 Theo de Raadt（西奥·德·若特） 强领导，项目依赖个人信誉与捐赠，长期无独立基金会（OpenBSD Foundation 迟至 2007 年才成立）；其资金模式（捐款、CD 销售）与 FreeBSD Foundation 的 “企业赞助 + 捐赠” 形成对照。
  
**史料**：OpenBSD 2.8 发布说明（2000）；de Raadt 关于资金模式的公开陈述 ［C］
  
**史观**：总纲第 22 条——开源运动：OpenBSD 的 “极简、个人驱动” 资金模式与 FreeBSD Foundation 的 “制度化” 模式代表开源项目可持续性的两种实验。
  
**辨析**：OpenBSD 长期以微薄预算维持高质量安全产出，说明资金规模与产出质量非线性相关；其模式不可简单复制。
  
**文献**：OpenBSD Project. OpenBSD 2.8 Release Notes [Z]. 2000；de Raadt T. OpenBSD Funding [EB/OL].［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］

## 97.15.4 Windows 2000（2000）与 Darwin（2000）

  **要点**：Windows 2000（2000.2）是微软面向服务器的 NT 5.0，由企业全职团队开发，无社区治理；同年 Apple 开放 Darwin（Mac OS X 的 BSD 基础，2000.6 开源）并采用 Apple Public Source License，是 BSD 代码进入商业公司的另一治理样本。二者与 FreeBSD Foundation 的 “社区基金会” 模式根本不同——均为公司主导。
  
**史料**：Microsoft Windows 2000 发布（2000.2）；Apple Darwin 开源公告（2000.6）［A］
  
**史观**：总纲第 22 条——开源运动：Darwin 的 APSL 与 FreeBSD Foundation 的 BSD 许可生态共同体现 “企业以 BSD 许可证吸收社区代码” 的模式，与 GPL 项目治理不同。
  
**辨析**：Darwin 开源不意味 Apple 接受社区治理——Apple 保留最终控制权，与 FreeBSD Foundation 的社区自治本质不同。
  
**文献**：Apple. Darwin Open Source License [Z]. 2000；Microsoft. Windows 2000 Resource Kit [Z]. 2000. ［A］

## 97.15.5 同期 BSD 与开源治理全景（2000）

  **要点**：2000 年前后，开源/类 UNIX 项目的治理呈现光谱：个人威望驱动（Linux/Torvalds、OpenBSD/de Raadt）、核心团队志愿（NetBSD）、社区基金会（FreeBSD Foundation 2000）、企业主导（Windows、Darwin）。FreeBSD Foundation 的成立使 FreeBSD 成为首个拥有独立法律与资金实体的主要 BSD 项目，为后续 11.x/12.x 的持续发展奠定制度基础。

  2000 年开源/类 UNIX 治理格局对照：

  | 项目 | 治理模式 | 法律实体 | 资金来源 | 领导模式 |
| -- | ------ | ------ | ------ | ------ |
| FreeBSD | 社区基金会 | FreeBSD Foundation（2000） | 企业赞助 + 捐赠 | Core Team + Foundation |
| Linux | 个人威望 + 企业 | OSDL（1999） | 企业赞助 | Torvalds 个人把关 |
| NetBSD | 核心团队志愿 | 无独立基金会 | 少量赞助 | Core Team 集体 |
| OpenBSD | 个人信誉驱动 | 无（OpenBSD Foundation 2007） | 捐赠 + CD 销售 | de Raadt 强领导 |
| Windows 2000 | 企业主导 | Microsoft | 企业全职 | 微软内部团队 |
| Darwin | 企业主导 | Apple | Apple 全职 | Apple 控制 |

**史料**：各项目 2000 年治理结构公开资料 ［B］
  
**史观**：开源运动：Foundation 模式是 BSD 项目走向制度化、法律化与可持续化的关键一步，影响此后十余年的 FreeBSD 发展。
  
**辨析**：不应神化基金会——FreeBSD 的成功仍依赖核心开发者与社区；基金会是赋能工具而非替代。
  
**文献**：FreeBSD Foundation. Annual Reports (2000-)[EB/OL]. ［B］
