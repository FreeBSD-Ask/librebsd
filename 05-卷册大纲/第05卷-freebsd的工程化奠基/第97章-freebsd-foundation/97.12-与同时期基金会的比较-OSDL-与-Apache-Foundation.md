# 96.12 与同时期基金会的比较——OSDL 与 Apache Foundation

## 96.12.1 OSDL 与 Apache Foundation
  - 要点：OSDL(Open Source Development Labs, 2000) 与 Apache Software Foundation(1999) 是同期开源基金会，二者治理路径不同：OSDL 以企业成员为主，Apache 以个人成员为主；FreeBSD Foundation 选择个人主导路径
  - 史料：OSDL 历史文档、Apache Foundation By-Laws、Linux Foundation 历史 (2007 OSDL+FSG 合并) ［A］
  - 史观：总纲第 7 条——BSD 与 UNIX 谱系的连续性，Apache 路径与 BSD 路径相似
  - 辨析：FreeBSD Foundation 选择是否真受 Apache 影响，需查早期邮件
  - 文献：Apache Foundation By-Laws；OSDL 文档 ［A］
## 96.12.2 Eclipse Foundation 的治理
  - 要点：Eclipse Foundation(2004) 采用企业成员主导的治理结构，与 FreeBSD Foundation 个人主导形成对比；Eclipse 模式在商业推广上更成功
  - 史料：Eclipse Foundation By-Laws、Eclipse 历史页 ［A］
  - 史观：总纲第 9 条——简洁与复杂的辩证，企业主导与个人主导的权衡
  - 辨析：Eclipse 模式是否真在商业推广上更成功，需查市场份额
