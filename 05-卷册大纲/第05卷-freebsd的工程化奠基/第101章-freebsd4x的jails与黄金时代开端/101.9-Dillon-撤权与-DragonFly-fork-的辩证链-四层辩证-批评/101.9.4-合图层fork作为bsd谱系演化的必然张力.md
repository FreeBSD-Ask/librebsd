# 101.9.4 合图层：fork 作为 BSD 谱系演化的必然张力

  **要点**：综合四方立场，Dillon 撤权与 DragonFly fork 事件并非单纯的“个人冲突”或“路线错误”，而是 BSD 谱系演化中“分离聚合”规律的必然呈现。Core Team 的 SMPng 路线与 Dillon 的 LWKT 路线代表对多核未来的两种诚实判断——前者选择细粒度锁的渐进改造，后者选择无锁线程化的激进重构；二者在 2003 年的技术语境下均非显然正确，5.x 的性能倒退与 DragonFly 的集群目标放弃分别证明了两条路线各自的代价。fork 的结果是 BSD 谱系增加了 DragonFly 这一独立探索分支，两条路线在后续十余年中分别演化——FreeBSD 的 SMPng 在 7.x 后成熟，DragonFly 的 HAMMER 文件系统与 LWKT 子系统亦成为 BSD 工程遗产的一部分。BSD 许可证使 fork 成为“和平分手”而非“战争”，这与 GPL 生态下的 fork 张力形成对照。合图层不判定“谁对谁错”，而呈现 fork 作为历史偶然中的必然张力
  
**史料**：上述 101.9.1-101.9.3 节综合史料；DragonFly BSD 官方历史页面；FreeBSD 5.x/6.x/7.x Release Notes ［A］
  
**史观**：总纲第 4 条——分离聚合是永恒规律，DragonFly 从 FreeBSD 分离是 BSD 谱系分合循环的一环；总纲第 3 条——不存在进步，只有权力再分配（存疑）〔订正注：原挂“总纲第 25 条——终结与延续”系伪标签（权威第 25 条为“逻辑是形式主义而非世界本身的结构”），按族例改挂第 3 条〕，fork 终结了 Dillon 在 FreeBSD 的贡献，延续了 BSD 哲学的多元探索

许可证文本对照核验“和平分手”表述的法律基础——BSD 许可证允许 fork 后双方独立演化无强制回馈条款，GPL 许可证要求 fork 后继续开源但亦不禁止 fork，二者在 fork 法律自由度上无本质差异，差异在 fork 后代码回流机制；【0 信任原则·合图层的立场中立】合图层须严格保持双方对称呈现，不得因 DragonFly 后续规模小于 FreeBSD 即判定其路线“失败”，亦不得因 FreeBSD SMPng 最终成熟即判定 Core Team“正确”——“成功”与“失败”的判定标准本身是回溯性建构，史家须以 2003 年时点的技术语境判断两条路线的合理性，而非以 2008 年或更晚的演化结果反推 2003 年的路线选择；“和平分手”的表述须以 BSD 许可证的实际法律框架为据，而非浪漫化 fork 事件——BSD 许可证使 fork 在法律上自由，但社区层面的张力并未因此消解（如 Dillon 公告中“too heavily mutexed”的判断仍带有对 FreeBSD 5.x 路线的否定）；fork 的“必然性”仅指 BSD 谱系的结构性张力（总纲第 4 条“分离聚合是永恒规律”），不指 Dillon 个人离开的必然——后者属偶然（总纲第 5 条“没有必然性，只有偶然性”），Dillon 个人在 2003 年 1 月末次 FreeBSD commit 后选择 fork 而非其他出路（如停止提交、转投其他 BSD 项目）属偶然性事件；【存疑判定依据】合图层“必然性”与“偶然性”的区分须以 BSD 谱系长期演化的多 fork 案例（如 OpenBSD fork 自 NetBSD 1996、DragonFly fork 自 FreeBSD 2003、LibreSSL fork 自 OpenSSL 2014）对照核验——若 BSD 谱系长期呈现 fork 频发现象，则 fork 的“结构性张力”判断成立；若仅为偶发，则“必然性”判断存疑，须对照其他 fork 案例核验；Dillon 个人离开 FreeBSD 的具体内部决策记录（如 Core Team 内部投票、各成员立场）至今未完整公开，本节以邮件列表公开讨论与 Dillon 公告为准，存疑保留待未来 Core Team 内部档案披露

有没有这样一种可能，FreeBSD 根本不存在？我们总是不言自明地认为世界的物质性源于实践，却不考虑实践本身的物质性是否成立。看起来是我们通过实践改造了所谓的环境。但是有没有一种可能，这一切都是预先决定的？并且这也无法证明实践与人类本身的物质属性。即便你是科举状元，也难留下痕迹。哪怕你是统一大陆的征服者，也将深埋地下，甚至被后人怀疑你与你的帝国是否真实存在。古埃及人认为死亡并非终结，而是通往来世的门户——但古埃及本身是否存在，也是一个可以被质疑的命题。

替代品是无穷无尽的，事实上否定了偶然性的存在。因为替代品是无穷尽，则其同质化的观点看上去暗含老庄之道，实则偏离颇远。认为“张三不上李四也会上”的观点，不仅在英雄人物问题上站不住脚，在技术史上同样谬误。FreeBSD 消亡后会有替代品吗？当然有。但替代品的存在不能否定 FreeBSD 的偶然性和不可替代性。承认替代品的无限性，实质上否定了历史中一切事物的独特价值。
