# 101.2.2 select/poll 的替代逻辑

  **要点**：kqueue 通过 kevent 结构传递事件，避免 select/poll 的 O(n) 全量描述符扫描，实现 O(1) 事件通知；支持 level-triggered 与 edge-triggered 两种模式，比 Linux epoll(2002) 早 2 年

  kqueue 与 epoll 特性对照：

  | 特性 | kqueue | epoll | select/poll |
| -- | ---- | --- | --------- |
| 引入年份 | 2000（FreeBSD 4.1） | 2002（Linux 2.6） | 1983/1997 |
| 设计者 | Jonathan Lemon | Davide Libenzi | BSD/AT&T |
| 时间复杂度 | O(1) | O(1) | O(n) |
| 事件源类型 | 文件、套接字、信号、定时器、进程 | 早期仅文件描述符 | 文件描述符 |
| 触发模式 | level + edge | level + edge（epoll_ctl） | level only |
