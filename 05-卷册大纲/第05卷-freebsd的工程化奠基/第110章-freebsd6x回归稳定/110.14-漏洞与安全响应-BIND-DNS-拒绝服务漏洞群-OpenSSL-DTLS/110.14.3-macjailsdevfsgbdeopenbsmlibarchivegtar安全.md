# 110.14.3 MAC/Jails/devfs/gbde/OpenBSM/libarchive/gtar 安全修复合并叙述——6.x 时期 base system 安全加固

  **要点**：6.x 版本周期内 22 条 security fix commit（无 CVE 编号）覆盖 MAC 框架、Jails、devfs、gbde、OpenBSM、libarchive、gtar 等多个 base system 组件。MAC 框架方面，Christian S.J. Peron 于 2006-01-24 提交 `ca1e983adfa8d07f70fecd2e0b512d5467458afc`（“MFC the security.mac.biba.interfaces_equal sysctl variable”），将 MAC/biba 策略的 interfaces_equal sysctl 从 HEAD 回溯至 RELENG_6，扩展 MAC/biba 对网络接口的等价处理。Jails 方面，Maxim Konovalov 于 2006-05-17 提交 `faf72da5bb5e08c4b48c96259e983856ef86235f`，文档化 `security.jail.jailed` 与 `security.jail.list` sysctl；Simon L. B. Nielsen 于 2006-05-28 提交 `6ad01cde4efac3de004a6e49195f0f42358fc50b`，撤销先前 devfs jail mount 的 MFC——commit_subject 明确 "mounting devfs without a devfs ruleset inside a jail is a very bad idea security wise"，反映 6.x 时期对 jail 内 devfs 暴露面的安全收紧。gbde 方面，Colin Percival 于 2006-02-14 提交 `a5e9d3ad0cdaaa2eb16b52cefe47a865c619bf84`，为 **gbde(8)** 增加 key file 支持，减少对 passphrase 的单一依赖。OpenBSM 方面，Robert Watson 于 2006-09-02 提交 `1181d11733c8593f30e6d62e57edb2b4cd25a849`，将 OpenBSM 1.0 alpha 10 从 HEAD MFC 至 RELENG_6，commit_subject 强调 "OpenBSM is the user space portion of the TrustedBSD audit subsystem"，是 6.x 时期 TrustedBSD 审计子系统稳定化的关键节点。libarchive 与 gtar 方面，Tim Kientzle 于 2007-08-25 提交 `cb43e1fdfee1d975ace60eecc3370a1a7e4cd833`，用 libarchive 的新安全检查替代 **tar(1)** 内的旧实现；John Baldwin（约翰·鲍德温） 于 2007-11-29 提交 `7d396c5f9cab1f0aa7d16ea25fb06cd59b3df775`，修复 gtar 目录遍历漏洞

**史观**：总纲第 13 条——法律与道德是利益分配〔映射存疑，待主理人审定〕：base system 组件的安全加固是长期工程，单条 commit 的影响分摊于整个用户群；总纲第 15 条——文化即形式主义〔映射存疑，待主理人审定〕：6.x 时期 MFC 流程的规范化使 security fix 能快速从 HEAD 同步至稳定分支
  
**辨析**：22 条 security fix commit 的 commit_subject 均含 “security” 或 “Security:” 标签，但部分 commit（如 `7d396c5f9cab1f0aa7d16ea25fb06cd59b3df775` 的 gtar 目录遍历）可能涉及未公开 CVE，需对照 NVD 数据库核验是否漏标；devfs jail mount revert 的 `6ad01cde4efac3de004a6e49195f0f42358fc50b` 是罕见的 “撤销 MFC” 操作，反映 6.x 时期 jail 安全策略的迭代式收紧——先在 HEAD 引入 devfs 自动挂载以方便 jail 用户，发现安全隐患后立即在稳定分支撤销；OpenBSM 1.0 alpha 10 的 MFC 时点（2006-09-02）与 TrustedBSD 审计子系统的稳定化时间线需对照 TrustedBSD 项目页面核验；security fix commit 中有 7 条由 Bruce A. Mah 提交〔计数以本文件所列 7 个 hash 与 101.14.4 口径统一，待库复核〕（`2ca173bc23a6314a826b7d1cff7c9b336d9898e1`、`7ce45f14d7f375cda5a174fac88b8d9f2adb8e3c`、`cd6816b327e46010dd80ff77780ac321a53e2c68`、`617b61be5e53964702a4f950960d8588c6a0655b`、`86cdf41115202a207fefaa9c93270bf0187bf95a`、`86b4a269faf203846cafe693446a02d5da3d6af8`、`20f6de38f93bc5dc6a2c4d3b3c2f1398ced2b218`），多为 security advisory 文档维护与 URL 规范化，非代码漏洞修复，应区别对待
