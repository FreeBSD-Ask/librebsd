# 110.12.3 GBDE → GELI 磁盘加密框架（6.0，2005.11.3）

  **要点**：FreeBSD 5.x 时期由 Poul-Henning Kamp（波尔-亨宁·坎普） 设计 GBDE（GEOM-Based Disk Encryption），作为 GEOM 框架的一个 class 提供 4KB 扇区级磁盘加密；GBDE 设计简单但加密能力有限——使用固定密钥、缺少密钥衍生函数（KDF）、不支持多密码、加密元数据简单；FreeBSD 6.0-RELEASE（2005.11.3，release/6.0.0 tagger_date = 2005-11-03T00:35:26Z，tagger = cvs2svn）引入 **geli(8)** 与 **geli(4)**，由 Pawel Jakub Dawidek 设计；GELI 首次 commit 于 2005-07-27T21:43:37Z（commit_hash = c58794debd2bfe8cfe8b69483080d0e7b3fcb3ed，committer = Pawel Jakub Dawidek，message_subject = "Add GEOM_ELI class which provides GEOM providers encryption. For features list and usage see manual page: geli(8)."），早于 6.0-RELEASE 约 3 个月，属 6-CURRENT 开发周期；GELI 同样基于 GEOM 框架，但引入 AES-XTS/AES-CBC 加密、PBKDF2 密钥衍生、密钥文件与密码组合认证、加密元数据冗余、引导时加密根文件系统支持；GELI 在功能与安全性上全面优于 GBDE，成为 6.x 时期默认磁盘加密方案；GBDE 在 6.x 时期保留但被标记为 deprecated；7.0 起社区强烈推荐使用 GELI 替代 GBDE
  
**史料**：FreeBSD 6.0-RELEASE Release Notes；Pawel Jakub Dawidek 在 freebsd-geom 邮件列表 2005 年关于 GELI 设计的讨论；man **geli(8)** 与 **geli(4)** 历次版本；Poul-Henning Kamp GBDE 设计文档（phk.freebsd.dk）；freebsd.duckdb freebsd-src 仓库 commits 表 GELI 首次 commit 为 2005-07-27T21:43:37Z（commit_hash = c58794debd2bfe8cfe8b69483080d0e7b3fcb3ed，author = Pawel Jakub Dawidek）；freebsd.duckdb freebsd-src 仓库 tags 表 release/6.0.0 的 tagger_date = 2005-11-03T00:35:26Z（target_commit_hash = 3d215489fe03c6c5cecc3b5ed9ea39118e6ce379） ［A］
  
**史观**：总纲第 10 条——动手者创造历史：Pawel Jakub Dawidek 作为相对边缘的贡献者，GELI 设计影响后续 FreeBSD 全盘加密生态；总纲第 3 条——不存在进步，只有权力再分配〔映射存疑，待主理人审定〕：GELI 引入付出向后兼容性代价（GBDE 加密卷需转换），但获得更强安全性
