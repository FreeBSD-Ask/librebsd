# 110.7.3 FreeBSD 6.x SMPng 与 DragonFly token 路线对比

  **要点**：FreeBSD 6.x 继续 SMPng 细粒度锁路线，DragonFly 采用 token(类似读写锁) 路线；DragonFly token 抢占开销小但并发性弱，SMPng 锁开销大但并发性强
