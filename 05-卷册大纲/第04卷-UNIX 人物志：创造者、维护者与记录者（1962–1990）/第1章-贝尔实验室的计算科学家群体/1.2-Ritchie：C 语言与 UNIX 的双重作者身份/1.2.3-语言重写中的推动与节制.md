# 1.2.3 语言重写中的推动与节制

<!-- DOC_MINE: ref203#3 -->
**学术记载**（证据等级：L4，来源：`historical_claims.duckdb.claim.CL-RM-495856`；2026-11-16 V04 补证批 b002）

Thompson 记：UNIX 内核约 10,000 行 C 与约 1,000 行汇编；汇编中约 200 行为效率而留（本可用 C 写），约 800 行承担 C 无法实现的硬件功能；内核仅占泛称“UNIX 操作系统”全部代码的 5% 至 10%。引文出处：THOMPSON K. UNIX Implementation[J]. Bell System Technical Journal, 1978, 57(6): 1931-1946.；引文按 L4 纪律：以上为当事人一手记载，属过程性证据，具体结论仍须回核原文与同期一手材料，不得单独引为定论。
