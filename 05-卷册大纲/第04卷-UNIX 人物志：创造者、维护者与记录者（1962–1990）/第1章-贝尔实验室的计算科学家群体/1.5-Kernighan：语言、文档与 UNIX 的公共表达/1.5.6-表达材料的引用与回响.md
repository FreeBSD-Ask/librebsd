# 1.5.6 表达材料的引用与回响

**同时代报道**（证据等级：L4，来源：`historical_claims.duckdb.claim.CL-RM-496585`；2026-11-17 V04 补证批 b014）

Scherrer（STUG 协调人）亲述：1976 年 Kernighan 与 Plauger 的《Software Tools》连磁带成为畅销，诱使 LBNL 研究者扩充并广为散布，移植到从 Cray 到微机等多种机器，催生 Software Tools Users Group。引文出处：SCHERRER D K. Software Tools Users Group[J]. UNIX World (USER SPOTLIGHT).；引文按 L4 纪律：以上为当事人一手记载，属过程性证据，具体结论仍须回核原文与同期一手材料，不得单独引为定论。
