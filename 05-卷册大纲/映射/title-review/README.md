## verdict 取值

| 值 | 判义 |
| -- | ---- |
| 确证 | 题内事实断言获一手（A 级）或独立二手（B 级）支撑 |
| 形态 | 无外部事实断言的体例题（分工、编目、叙事分层类），离线＋目录核查过 |
| 有误 | 断言与一手相悖或年代/题域错置；`issue` 给证据，`suggested_title` 给改法 |
| 存疑 | 查无一手或被反爬阻断（不编造）；`issue` 说明已查何处 |
| 合规 | 题面质量 PASS：完整、符合 T/C/S 判据、风格与既有标题一致；事实层沿用 2026-10-30 批准取证＋定向抽查（组二三四质量批 2026-11-02 增设，ykla 改判） |
