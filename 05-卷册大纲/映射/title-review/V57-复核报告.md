## 四、本批升确证要点（15 条，2026-11-02 补证）

- **XigmaNAS 来历**（3.1.3）：wiki“History of the name”整段逐字——“Originally called ‘FreeNAS’ when development began in 2005…the project changed its name to ‘NAS4Free’ in 2011…In 2018, we were awarded our final, legally registered name, ‘XigmaNAS.’”
- **m0n0wall 嵌入约束**（4.1.2）：Wayback 2011 快照逐字 “a complete, embedded firewall software package”＋“based on a bare-bones version of FreeBSD”。
- **共同成分留存**（4.1.3）：pfSense 官方 README 逐字 “pfSense started in 2004 as a fork of the m0n0wall Project (which ended 2015/02/15)”＋m0n0wall “The entire system configuration is stored in one single XML text file”。
- **许可选择**（4.1.5）：opnsense/core README 逐字 “OPNsense is and will always be available under the 2-Clause BSD license”；Deciso 发布稿 “under the 2-clause BSD license”；pfSense 官方仓 License: Apache License 2.0（构成对照）。
- **可扩展性取向**（4.2.2）：Deciso 发布稿 “extend its features, or even create a fork and build upon the same codebase”＋fork 史页 framework／MVC 句。
- **商业版界线**（4.2.3）：releases 页 Community Edition／Business Edition 分立两节（版本列 15.1—26.7／19.1—26.10）。
- **插件分置**（4.2.4）：plugins 仓库 README 逐字 “The plugins collection offers users and developers a way to quickly build additions…available to everyone through the firmware GUI pages”。
- **命名与周期**（4.2.5／4.3.2／4.3.4）：roadmap 页逐字 “We use a 6 months major release cycle with firm release dates.”＋“The OPNsense Roadmap version naming system consists of year.month”；releases 页首版 15.1 “Ascending Albatross”。
