# 小节标题设计·风格规范（2026-10-29 立）

> **性质**：本文件是《小节建制与题名规则》在“标题设计”作业面的执行手册，只写“怎么写、怎么写得好”；阈值与禁令以该规则 §二–§七 为准，本文件不重复判据正文。
> **适用对象**：`05-卷册大纲/映射/title-design/V{NN}.tsv`、`title-evidence/V{NN}.tsv`、`title-design/approvals.tsv`、`title-design/approved/V{NN}.title.ok`、`title-design/exceptions/V{NN}.tsv`。
> **真值方向**：`映射/title-design/` 是全书小节标题的唯一真值；`outline.txt` 第四级行与树内 `.md` 只在卷级批准后由落盘器生成，**不得反向手改**。
> **零态**：本文件立时 0 标题、0 批准、0 例外；台账 schema 先行，内容随 3A.4 起逐卷填入。

## 一、作业目标

1. 每节设计 **2–12 个论题**（中位 5–7），每个论题对应一个小节、一个标题。
2. **名字先于史料**：标题表冻结并通过卷级批准后，才研读旧树候选块；禁止由存量史料反推结构。
3. 同一节的小节题**构成该节的论证骨架**：合起来覆盖节题所指范围，分开各有独立论题，互不重复。
4. 标题服务于读者定位：只看目录即知本节论证什么，不必读正文。

## 二、句式模板库

以下六族是“论题名词短语”（T1）的落地写法，可组合，不得滑向动词短语或摘要句。

**甲 机制／过程族**：`X 的形成`｜`X 的确立`｜`X 的扩散`｜`X 的衰退`｜`X 的再起`｜`X 的分化`

**乙 结构／构成族**：`X 的构成`｜`X 的三层结构`｜`X 与 Y 的分界`｜`X 的内外分层`｜`X 的边界重划`

**丙 关系／比较族**：`X 与 Y`｜`X 对 Y 的影响`｜`X 在 Y 中的位置`｜`X 之于 Y`｜`X 与 Y 的错位`

**丁 事件／节点族**：`X 事件`（须补对象）｜`X 的转折`｜`X 的临界点`｜`X 之后的重组`（禁以日期起首）

**戊 制度／组织族**：`X 的治理结构`｜`X 的许可安排`｜`X 的决策链`｜`X 的代表制`｜`X 的章程与惯例`

**己 技术／器物族**：`X 的实现路径`｜`X 的接口约定`｜`X 的兼容层`｜`X 的移植策略`｜`X 的物质基础`

反例（不得成题）：

- 动词短语裸题：`讨论 X`｜`分析 X 的成因`｜`介绍 X`
- 日期起首：`1975 年 X`｜`1993 年 4 月 X`
- 纯版本号与行号：`2.6.19-rc2`｜`邮件 1741585`｜`PR 112729`
- 工序状态词：`未判定`｜`待定`｜`杂项`｜`空模板件`
- 摘要句式：`关于 X 的若干问题`｜`X 研究综述`

## 三、术语表

**项目术语（题名内一律照写）**

| 概念 | 题名写法 | 禁用写法 |
| ---- | ----- | ----- |
| FreeBSD 的软件包系统 | Port（单数）｜Ports 树｜Ports Collection | 端口（用于 ports 系统语境） |
| 网络端口 | 网络端口｜端口（仅在网络语境） | — |
| 操作系统内核 | 内核 | 核心（作为 kernel 译名） |
| 发行版 | 发行版 | 分发版 |
| 代码分支 | 分支 | 支线 |
| 版本控制提交 | 提交 | 签入 |
| 快照 | 快照 | 镜像（作 snapshot 译名） |
| 接口 | 接口 | 界面（作 interface 译名） |
| 许可 | 许可｜许可证 | 授权协议（作 license 译名） |
| 治理 | 治理 | 管理（作 governance 译名） |
| 共同体 | 共同体 | 社区（除专名“社区”外） |

**专名（题名内保留英文原形）**：BSD｜FreeBSD｜NetBSD｜OpenBSD｜DragonFly BSD｜macOS｜UNIX｜POSIX｜ANSI｜IEEE｜USENIX｜CSRG｜UCB｜AT&T｜X11｜NFS｜TCP/IP｜SPARC｜VAX｜PDP-11

**人名**：以 `10-交叉索引` 人物索引与术语表为准，禁自译；同一人物在全书只用一种译名。首见可用“中文名（英文名）”，题名内不并置。

**缩写**：题名内不展开（`TCP/IP` 不写“传输控制协议／网际协议”）；正文首次出现时展开。

## 四、年代与数字

1. 年代只在**必要**时入题（分期本身是论题时）；置题末，全角括号，区间用连接号 U+2013：`（1993–2026）`。
2. 题名内不重复年份串；节题已有年代者，小节题不再括注。
3. 单年用四位数字，不写“年”于题首：`X 的转向（1996）`；跨世纪区间全写：`（1969–1989）`。
4. 版本号与标识符不拆：`FreeBSD 9.1`｜`if_bridge`｜`2.6.19-rc2`（作为限定语可，独立成题不可）。
5. 中英、中数之间各一个半角空格；数字与单位间保留半角：`16 KB`｜`4.4BSD`。

## 五、长度与标点

1. 长度：8–30 字为常态，硬上限 40 字（T6）；超者拟题缩短，全题入正文 H1 或台账 `note`。
2. **同节平行下限**：同一节内各题字数极差 ≤14 字（机读判据 D3 的阈值来源）。
3. 句读全角（，；：！？）；题名内**禁用逗号串联多分句**，需要分层用冒号（`主标题：副题`），冒号全角。
4. 引号：弯引号 “”‘’；禁直角引号与 ASCII 直引号。
5. 路径非法字符全角化：`/`→`／`、`:`→`：`、`*`→`＊`、`?`→`？`、`"`→`＂`、`<`→`＜`、`>`→`＞`、竖线→`｜`。
6. 禁双空格、禁行首尾空格、禁 AI 不可见字符（Cf／Zs 除 U+0020）。

## 六、同节平行与同章协调

1. **同节平行**：同一节内各题属同一模板族、同一粒度层级。不出现“甲案的背景”与“乙案”混排，不出现“X 的机制”与“Y 简介”同列。
2. **同章协调**：相邻节的题名不重复同一中心语（如两节都叫“……的形成”，须有一节改为“……的确立”或“……的扩散”）。
3. **跨节去重**：同一论题不得在两个节下各设一个小节；确需分述者，一主一从，从者题末标 `（另见 X）` 并在设计卡说明分工。
4. **上下位一致**：小节题必须是所属节题的下位论题；不得与节题平级，不得越级（S2）。

## 七、四源矩阵与证据表

每条标题由四类来源合成，不得由单一来源决定：

| 源 | 项目载体 | 在台账里的记法 |
| -- | ---- | ----- |
| 史料 | 旧树 37,484 子节、ROW_MINE 块、`historical_claims.duckdb`、`03-原始史料库`、`04-现代研究文献` | `sources` 含 `史料`；`evidence` 记 source_id／块数／同类率 |
| 联网 | 官方页（ACM／IEEE／USENIX／项目站）、标准号、机构页 | `sources` 含 `联网`；`evidence` 记 URL、层级 A／B／C、访问日、引文 |
| 目录分析 | `outline.txt` 卷章节目录、`@@` 注、同章前后节、`targets.tsv` | `sources` 含 `目录`；`evidence` 记节题原文与归属判断 |
| 规则 | 《小节建制与题名规则》T1–T7／C1–C6／S1–S4、本规范术语表、人物索引、史观映射 | `sources` 含 `规则`；`evidence` 记所据条款号 |

**覆盖要求**：每条 ≥2 源；专名题、标准号题、年代题 ≥3 源；**单源题不得批准**，一律进例外报告。

**冲突裁决顺序**：体例与术语 → 规则；层级与归属 → 目录分析；史实、年代、专名 → 联网一手（与史料一手冲突者标〔存疑〕）；论题与内容边界 → 史料。

**缺源披露**：缺史料标 `corpus_gap`；缺联网标 `[未获一手确证]`；缺目录分析标 `outline_gap`；缺规则标 `rule_gap`；四者全缺不得立题。

## 八、台账 schema

### 8.1 `title-design/V{NN}.tsv`（标题表，每卷一件）

制表符分隔，首行表头，十列：

| # | 列名 | 取值与约束 |
| - | ---- | ---- |
| 1 | `subsection_id` | `V{NN}.{C}.{S}.{s}`（V 两位、C 不补零、S 不补零、s 为节内序号）；全卷唯一 |
| 2 | `vol` | 两位卷号，与 `subsection_id` 第一段一致 |
| 3 | `chapter` | 章号（整数，不补零） |
| 4 | `section` | 节号（整数，不补零） |
| 5 | `title` | 题名；须过 T1–T7／C1–C6／S1–S4 |
| 6 | `thesis` | 论题一句话（本小节论证什么），不得为空 |
| 7 | `order` | 节内序号，1..n 连续，无洞无重 |
| 8 | `source_count` | 整数 2–4，与 `sources` 集合大小相等 |
| 9 | `sources` | 四源标记，分号分隔，取值集 {史料,联网,目录,规则} |
| 10 | `status` | `draft`／`final`／`approved` |

### 8.2 `title-evidence/V{NN}.tsv`（证据表）

八列：`subsection_id`｜`query`｜`url`｜`source_type`｜`tier`｜`accessed`｜`quote`｜`conflict`

- `source_type` ∈ {史料, 联网, 目录, 规则}
- `tier` ∈ {A, B, C}（A 官方一手／B 二手或厂商文档／C 聚合站，仅作线索）
- `accessed`：`YYYY-MM-DD`
- `conflict` ∈ {none, noted}
- 每条标题至少一行；四源各有其行

### 8.3 `title-design/approvals.tsv`（批准记录，全局唯一）

七列：`kind`｜`vol`｜`title_count`｜`ledger_sha256`｜`approved_by`｜`approved_at`｜`note`

- `kind` ∈ {title, landing}；本线只写 `title`
- `ledger_sha256`＝批准时该卷 `title-design/V{NN}.tsv` 的 SHA-256
- 只追加，不修改；改题须新增一行并废前一行（`note` 记 `superseded by …`）

### 8.4 `title-design/approved/V{NN}.title.ok`（批准标记）

纯文本键值，UTF-8 无 BOM、LF：

```text
kind=title
vol=V01
title_count=8
ledger_sha256=<64 位十六进制>
approved_by=ykla
approved_at=2026-10-30
```

台账变动即 hash 不符，门禁 H 组判 FAIL，须重批。

### 8.5 `title-design/exceptions/V{NN}.tsv`（例外台账）

五列：`subsection_id`｜`kind`｜`reason`｜`proposal`｜`status`

- `kind` ∈ {single_source, cannot_name, propose_section, propose_chapter, propose_volume, corpus_gap}
- `status` ∈ {open, accepted, rejected}
- 例外不阻断该卷其余标题批准，但 `open` 项须在呈审报告中单列

## 九、作业顺序（每卷一次）

1. **读目录**：卷题、章题、节题、`@@` 注、同章前后节 → 列论题候选。
2. **四源取证**：按 §七 填 `title-evidence`；史料源先只做“有无与边界”判读，不读块内容细节。
3. **拟题**：按 §二 模板族成题，过 §五 长度与标点。
4. **自检**：跑 `audit_title_consistency.py --check`，清零 B／C／D／E／F／G 组。
5. **例外判定**：无法归纳、建议独立、单源、缺源者进 `exceptions`。
6. **升格裁定**：P1–P3 提案单独成段，先呈 ykla 裁定；升格未裁不得定稿。
7. **定稿与呈审**：`status=final` → 呈 ykla → 批准后写 `approvals.tsv` 行与 `approved/V{NN}.title.ok`。
8. **空骨架**：无史料小节按规则 §六 建 `.md`（H1＋YAML 全字段），不写正文。

## 十、禁止事项

- 不由存量史料反推小节结构（J0）。
- 不以单一来源定题；单源题不得批准。
- 不以“档案节”名义突破每节 12 小节上限（J7）。
- 不手改 `outline.txt`／`index.html`；一切走装配器与合并器。
- 不先斩后奏升格；未获批不得改节层。
- 台账任何增删改题即失效重批；不得“先批后改”。
- 不建旁路副本；留痕唯一靠 Git。

## 十一、去 AI 味与风格一致（2026-10-30 ykla 令）

> 令文：“标题风格应一致，去 AI 味的同时保持学术性。”机判落在第三十九件 C8 组（C8a／C8b／C8c 硬拦，C8i 披露）。

1. **禁 AI 高频空转词入题**（C8a 硬拦）：赋能、抓手、闭环、颗粒度、锚点、景深、温差、样态。
2. **同卷结尾二字簇 ≤3**（C8b 硬拦）：同卷多题共用同一收尾词是公式化排比的典型 AI 味；超限者优先改写收尾，落实义名词。
3. **单题“的”字 ≤2**（C8c 硬拦）：三层“的”字偏正连缀是 AI 句法指纹；拟题以并列或动宾结构化解。
4. **AI 腔临界词披露**（C8i 不拦）：图景、维度、对位、坐标、版图、生态、张力、轨迹、格局、画像——对象层研究（如史学辨析章以“叙事”为研究对象）合法，人工复核裁量。
5. **正形**：收尾落实义名词（制度、工程、清单、交接、源流）；同节同族同粒度（S3）不变；学术性靠具体史事对象与可考细节保证，不靠抽象大词。
