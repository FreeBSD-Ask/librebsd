## 三、题面—thesis 预核（0 信任）

一手锚＝DragonFly 官方 1.0 公告（Matthew Dillon 署名，2004-07-12，dragonflybsd.org mailarchive/kernel/2004-07/msg00143.html）：原文“One year after starting the project as a fork off the FreeBSD-4.x tree… our 1.0 release!”、“replaced nearly all of the core threading, process, interrupt, and network infrastructure with DragonFly native subsystems… MP-friendly slab allocator, a Light Weight Kernel Threading (LWKT) system that is separate from the dynamic userland scheduler, a fine-grained system timer abstraction… a fully integrated light weight messaging system, and a core IPI messaging system”、“retain 4.x's vaunted stability… UP and MP friendly”、“start removing the BGL… threading the VFS subsystem (the network subsystem is already threaded as of 1.0)”。

1. **4.7.2**：thesis“发行体系自建，独立过程约两年”——官方公告载 1.0 发布于起步后“one year”（2003 年中起步→2004-07 首发），“约两年”无一手支撑；题拟为“发行自建而独立过程耗时”，不写死年数，缺口随填充批核。
2. **4.3.1**：thesis“分叉取四版后期代码基，时点在 2003 年年中”——公告“fork off the FreeBSD-4.x tree”＋1.0 公告 2004-07＝起步约 2003 年中，与 thesis 一致；题以“二〇〇三年中自四版另立代码基”承载可考两端。
3. **4.2.3／4.4.x**：thesis“单系统映像构想／集群透明化目标后来调整”——一手公告载 LWKT、IPI、集群消息传递为设计核心，未见“目标调整”的逐字证据；题保留“列为长远目标”“并置而非取代”等可考判断，限定语随填充批核。thesis 字段一律不动。
