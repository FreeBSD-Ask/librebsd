## 五、本卷要点与风险

**要点**

- 本卷骨架按“作品形成→作品传播→作品生命周期”推进：第 1 章立传统的机构与许可基底，第 2—11 章逐作品分章（编辑器、shell、终端库、网络、邮件、DNS、管理工具、OpenSSH、OpenBSD 作品群），第 12—13 章处理工具链与独立化，第 14 章回到方法论。凡涉年代处，均以一手发布说明或官方文档页为锚，不以概括语立题。
- 一手材料以 `docs-archive.freebsd.org/44doc` 的 USD／PSD 原文档为骨干：vi 与 ex 的原始论文（Joy／Horton）、C shell 引言（Joy）、Mail Reference Manual（Shoens）、IPC 教程（Sechrest）四件同时是史料与题面依据，作品史因此落在文本层而非转述层。
- 版本与守护进程类题目一律落在 man 页可核的行为句上（如 nc“错误走标准错误”、tmux“会话可分离重连”、cron“每分钟轮询”），避免“作品影响”一类无锚断言。
- 13 章的独立化线以旧树 `066.8.1`／`066.2.1` 的逐字要点为据（BDB 1.85 随 4.4BSD、PostgreSQL 1986 立项、MySQL 维护 BSD 支持），并区分“自研库／移植库／客户端库”三层。

**风险与存疑**

1. **1.0 类年代不入题**：outline 注已声明 1BSD 1977／1978 两说并存、vi 首次公开 2BSD 1978—1979 与 3BSD 1979 两说并存；本卷题面一律不写具体年份，论题亦不裁断，只在 2.2 用旧树要点陈“两说并陈”。
2. **BIND 全球占有率九成**：仅见旧树 `062.3.4` 记载，未获一手统计确证，题面不写数字，7.5.5 论题以“同库使用面极广”表述；`historical_claims.duckdb` BIND 相关 615 条中未见占有率一手源，已在报告披露。
3. **OpenSSH 起点两处**：旧树 `225.1.1` 记 OpenBSD 树 1999-09-26 导入、1999-10-01 标记 OpenSSH-1.0；claim 库另记 openssh.com 独立仓库最早 commit 为 1999-10-27（Damien Miller）。两者属不同库，9.2 题面只写“初始导入的提交记录”，不并时点。
4. **6 条题仅两源**：`V60.5.1.5`、`V60.9.3.1`（部分）、`V60.14.1.x` 等 6 条题面为纯中文抽象题，按规则 ≥2 源成立；若复核要求 3 源，可整条补一条武汉（联网）证据，不影响题面。
5. **B 级材料比例**：23 行 B 级中，faqs.org《Csh Programming Considered Harmful》为当事人长文（作者 tchrist），按 B 级计入但论题只取“批评以长文形态流传”，不作技术裁断；Oracle Berkeley DB 文档页为厂商站，只用于“产品化后文档分层”一类论题。
6. **未获一手确证的题目清单**：无。80 个 URL 均为当日实抓，引文逐字；`mysql`／`redis` 官方页两次抓取失败（4xx／超时），故 13.7、13.8 改以旧树要点与 Valkey 官方页立题，未编造任何引文。
