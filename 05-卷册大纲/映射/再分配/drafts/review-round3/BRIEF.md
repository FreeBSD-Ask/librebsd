# 第三轮逐条复核判据（每路必读）

## 0. 你的角色与权限

你是**独立复核者**，不是作者。只做判定与拟题，**不得修改仓库内任何既有文件**；唯一允许写入的是你在任务中指定的那一个 `lane-NN-review.tsv`。

## 1. 背景

`05-卷册大纲/目录/data/outline.txt` 是本项目的唯一大纲真值，语法：

- `# 第N卷  卷题`
- `>` 卷导言
- `## 第 N 章 章题`
- `- M.N 节题@@〔注〕`

`05-卷册大纲/映射/mapping.tsv` 记录旧树 37,484 个来源条目到新节点的映射，字段含 `source_id`、`source_title`、`target_id`、`status`、`review_state`。你要复核的每个对象，其“内容”只能由映射到它的来源条目标题来判断，**不得凭想象**。

## 2. 题名规范（既有 3,900 条节题的统计口径）

1. **语言**：中文为主。允许专名保留拉丁字母（`FreeBSD`、`NetBSD`、`OpenBSD`、`pkgsrc`、`ZFS`、`pledge`、`-mm`、`time_t` 等）；**不得出现机器拼接串**，如 `netbsd1416的成熟期19992002`、`gcc421`、`linux2 0 2 2`。
2. **拉丁词元**：0 词约 34%，1—2 词约 50%，3 词以上仅 14% 且几乎全为专名并列（如 `CAM、SCSI、ATA、NVMe`）。**超过 2 个非专名词元即视为异常**。
3. **数字**：只用三类——年份（`1996`）、年份区间（`2006—2025`，破折号用 `—`）、版本号（`2.0`、`4.2BSD`、`5.x`）。**孤立三位以上数字串**（`19731979`、`100`）一律违规。
4. **禁用**：`谱系`（全库禁用词）；直角引号（U+300C／U+300D／U+300E／U+300F）；英文直引号（U+0022／U+0027，中文正文用 `“”‘’`）；`主义`作主题词冒充证据。
5. **结构**：可用冒号分层（约 28%），冒号后为限定或副题；括号只用于年份、版本、别名；不得以句号、逗号、顿号、分号、问号、感叹号收尾。
6. **长度**：中位约 20 字。超过 40 字须有充分理由；硬上限 50 字（英文单词按 1 字计）。
7. **实质对象**：题名的核心名词必须能在来源条目标题中找到对应。**保留原题全部实质对象**，只改格式；不得擅自换主题（例如把“语言的保守主义”改成“静态 PIE 实现”）。
8. **章内唯一**：同一章内不得有两节题名实质重复（如两节都叫“与同时期操作系统的比较”而不加限定）。

## 3. 判定口径

对每个对象给出四项：

| 字段 | 取值 | 含义 |
|---|---|---|
| `format` | PASS／FAIL | 是否违反第 2 节任一条（违反即 FAIL，并在 `issues` 写具体条款） |
| `fit` | PASS／WARN／FAIL | 题名与来源条目内容是否相符。FAIL＝主题错、系统错、断代错；WARN＝只覆盖部分来源或限定不足 |
| `dup` | PASS／WARN | 与同章其他节题是否实质重复 |
| `verdict` | PASS／WARN／FAIL | 三项中最差者 |

`fit=FAIL` 或 `format=FAIL` 时，必须在 `proposed_title` 给出**保留原实质对象**的改题建议；否则 `proposed_title` 留空。

## 4. 输出格式

写入指定的 `lane-NN-review.tsv`，UTF-8 无 BOM、LF、制表符分隔，首行为表头，列固定为：

```
object_id	kind	format	fit	dup	verdict	issues	proposed_title	evidence_note
```

- `issues`：分号分隔的具体问题，例如 `格式:数字串19992002;格式:机器连写`。
- `proposed_title`：仅 FAIL 时填；否则留空。
- `evidence_note`：一句话说明依据的来源条目（写 `source_id` 或题名片段）。

对象数必须与输入 `lane-NN.tsv` 完全一致，不得漏行、不得多行。

## 5. 纪律

- 不编造来源条目。找不到证据就在 `evidence_note` 写 `未取得`，并把 `fit` 标 `WARN`，**不得标 PASS**。
- 不因“看起来像”就判定相符；按 `source_title` 的实际字面判断。
- 中文标点用全角；引号用 `“”`。
