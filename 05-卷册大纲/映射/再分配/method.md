# 全量再分配方法（Task 3／4／5，阶段 A）

> 本文件是 `pipeline/p02_recheck.py`／`p03_aggregate.py`／`p04_registry.py` 的方法说明。
> 所有阈值、权重、候选规则均在此文档化，脚本按此实现；改动阈值须同步本节并重跑二跑校验。
> 输入只读：`mapping.tsv`、`targets.tsv`、`目录/data/outline.txt`、旧树 `旧大纲-20261023/`、
> `缺口族分析/12-chapter-level-targets.tsv`；输出只写 `映射/再分配/`（含 `pipeline/`、`checkpoints/`）
> 与 `script/_reassign_20261026/`。`/script` 由 `.gitignore` 覆盖，故管线与 checkpoint 的入库副本
> 放在 `再分配/` 下，Task 1／2 的基线件仍留在 `script/_reassign_20261026/`。

## 1. 重审口径

- **重审＝逐行复核 `target_id` 与 `status`**，保留既有 `review_a/b/c` 三趟证据；只有改判才写新证据与理由；
  **不重跑三趟原文判定**，也不读取正文内容（唯一例外见 §7 的两条章级待复核行）。
- 旧 `target_id` 有两种写法：`S-00xxxx`（已是 `targets.tsv` 节点）与 `Vxx-y.z`（旧卷号＋节号）。
  后者按 `(vol_no, ch_no, sec_no)` 映射到 `targets.tsv` 的 sec 节点，`ch_no` 取节号首段
  （如 `V13-4.4.2` → `(13, 4, 4.2)`）。两条章级写法 `V12-3`／`V19-1` 无法映射，转入 §7。
- `status` 不写 `CONFIRMED`；本批不生成 `layout.tsv`。

## 2. 题面规范化与分词（`reassign_lib.py`）

1. **去编号前缀**：切掉题首的 `001.2.1`、`6.` 类前缀与空白。
2. **污染截断**：老树部分行的题面字段被正文样板串污染，遇到 `当事人自述`、`二手转述`、
   `证据等级`、`引用时按`、`以上为邮件` 即截断，保留污染前的题面；截断后为空者记为“题面污染”。
3. **去标点空格**得规范化题面（用于近重复比对与主题名）。
4. **分词**：中英数混排先按“CJK 连续段／ASCII 连续段”切分（`2003年40Jails` → `2003`／`年`／
   `40`／`jails`）；CJK 段取**二元组**，ASCII 词长度 ≥2；命中停用词则丢弃；**首字或末字为虚词
   （的了与和及之在为者以对而从被于其并或由等各本该所把就便是不很最更又再可要会能）的二元组
   丢弃**——此类多为跨词边界碎片（“的加”“者与”“链与”）。
5. **共词数**（门禁用）：题面中互不重叠的连续二元组段计 1 词，**同一词重复出现不重复计**；
   ASCII 词各计 1（“数据库”的 `数据`／`据库` 两段重叠，计 1 词；“pkgng pkgng”计 1 词）。

## 3. 候选节集合（上限 50）

按下列顺序取候选，去重后不超过 50 个：

1. 当前 `target_id` 对应节；
2. 同旧节的“高分既有落点”（同节内 `EXISTING_SECTION` 且 `MED/HIGH` 行最多的节）；
3. 同旧章的高分既有落点；
4. 同一旧卷高分落点最多的前 3 个新卷内的全部节；
5. 与题面共享 ≥1 token 的节（按共享 token 数降序、节点号升序）。

token → 节 的倒排索引中，**文档频率 > 300 的 token 不参与候选索引**（仍参与打分），
避免 `unix`／`freebsd` 类泛词把候选池撑爆。

## 4. 证据分（0–1，三位小数）

```
score = weightedJaccard(题面 token, 节链 token) + 0.15(同旧节高分落点) + 0.10(领域词)   → 截断到 [0,1]
```

- **节链 token**：节题权重 1.0、父章题 0.4、卷题 0.2，同名取最大权重；
  `weightedJaccard = Σmin(题面权重, 节链权重) / Σmax(...)`。
- **同旧节高分落点 +0.15**：候选即 §3 第 2 项所指节点时加。
- **领域词 +0.10**：题面与节链（节题＋章题＋卷题）同命中 `reassign_lib.DOMAIN_TERMS` 某词时加。
- **校准 C1（加分前置共词）**：加分项仅在该候选与题面**至少 1 个共词**时生效。理由：首轮实测中
  “同节落点 +0.15”把零题面证据行推入 0.12–0.18 带，聚合输入被抽空。

## 5. 判定规则（整改后口径）

**EXISTING_SECTION 必须同时满足四项**：①题面与目标节链 **共词 ≥2**；②其中 **≥1 个为题面专属词**
（该 token 在全部 37,484 题面中的文档频率 <100，泛词 `linux`／`内核`／`治理` 不算）；
③分 ≥0.18；④目标卷在该旧卷允许集内（§10）。任一不满足则不得判 `EXISTING_SECTION`（复核 F-3／F-4）。

| 情形 | 处置 | reason |
|---|---|---|
| 有原 `target`，共词 ≥2 且当前分 ≥0.18 | `EXISTING_SECTION`（confirm，沿用三趟证据） | `existing_confirm` |
| 有原 `target`，最佳候选共词 ≥2 且分 ≥0.30 且高出当前 ≥0.10 | `EXISTING_SECTION`（reassign） | `reassign_stronger` |
| 有原 `target`，不满足上述 | `AGGREGATE_CANDIDATE`（零交集 `zero_overlap`／弱交集 `weak_overlap`） | 同左 |
| 无 `target`，最佳候选共词 ≥2 且分 ≥0.18 | `EXISTING_SECTION`（新落节；冲突时取最高分） | `existing_new`／`conflict_resolved` |
| 无 `target`，共词 ≥2 且 0.12 ≤ 分 < 0.18 | `REVIEW`（**仅中间态**，最终转聚合） | `weak_band` |
| 无 `target`，其余 | `AGGREGATE_CANDIDATE` | `zero_overlap`／`weak_overlap` |

- **校准 C3（章级综合层不新落）**：旧节号为 `x.0`（每章“章级综合”层）且无 `target` 者一律
  `AGGREGATE_CANDIDATE`（`meta_layer`），不新落任何节。
- `proposed_target` 只取 `targets.tsv` 的 **sec 节点**或空值。
- `REVIEW` 只作 `stage3_disposition` 中间态：`p04` 一律把它并入所属聚合簇并落枚举内取值，
  最终表 `REVIEW` 恒为 0（复核 F-1）。

## 6. 行级去重

- **SHA-256 组**：同组代表件优先（非空件 > 有 `target_id` > `source_id` 最小），其余标 `DUPLICATE`
  并记代表件 `source_id`（`sha_duplicate`）。**实测 37,484 组各 1 行，本批无重复件**。
- **近重复题面**（规范化题面相同、SHA 不同，829 组）：题面显著（长度 ≥6、非样板题面、组 ≤17 行）者，
  **组内若有 ≥MED 高置信落点，整组归该锚点的目标**（`near_dup_anchor`）；**无锚点则转主题聚合**
  （`near_dup_no_anchor`）；一律**不判 `DUPLICATE`**。其余样板／污染题面或 >17 行组随行判定。
  明细见 `dedupe-near-groups.tsv`。

## 9. 主题聚合（`p03_aggregate.py`）

- **输入行**：`AGGREGATE_CANDIDATE` 与 `REVIEW`（后者为中间态，随簇收口）。
- **簇锚**：`(旧卷, 旧章, 旧节, 内容类型)`。理由：实测题面多为长句、几乎互不重复，按题面 token
  直接分簇会碎成单行；同一旧节的多行残留本属同一旧主题，旧节是可靠的主题锚。
- **内容类型**（按规范化题面判）：`编纂元数据`（要点／史料／史观／辨析／文献／清单／索引／摘要／
  实录／辑录／摘编／年表／大事记／纪事／编年等）、`题面污染`（题面被样板串截断为空）、`正文`。
- **主题名**：旧节目录名去编号、去括号注、连字符转空格、保留数字间小数点、**不截断**。
- **父节门槛（复核 F-4）**：只计 **语料 df < 100 的专属词**，须
  ①**≥2 个专属词共词**，且 ②“分 ≥0.05 ／ 共词 ≥3 ／ 领域词同命中”之一（强度守卫）；
  并做**项目名一致性守卫**（题面含 freebsd／netbsd／openbsd／dragonfly／linux／… 时，
  候选节链须含同一项目名）。同旧节既有落点**不再单独**作为父节证据。
- **裁定**：
  - 编纂元数据／章级综合层／题面污染 → `UNMAPPED_KEEP`（`meta_layer`／`title_polluted`）；
  - `正文` 且 <5 行 → `UNMAPPED_KEEP`（`cluster_lt5`）；
  - ≥5 行且有合格父节 → **小节**（`cluster_parent_ge2`，节下映射桶）；
  - ≥20 行且无合格父节 → **节**（`cluster_ge20_no_parent`）；宿主章取“该旧章高分既有落点最多的
    新章（限旧卷高分落点前 3 新卷）”，无此证据则退 `UNMAPPED_KEEP`（`no_legal_parent`）；
  - 5–19 行且无合格父节 → `UNMAPPED_KEEP`（`no_legal_parent`）。
- 不以“其他”兜底；同义主题按题名合并；簇内行数、证据 `source_id`、父节与宿主均落表。

  （`4.0 Jails` → `4 0 Jails`）。前者无主题判据，一律留旧树；后者由 `formal_title_candidate`
  给候选，批准前须人工确认正式题名。
- 既有 `mapping.tsv` 含上一批粗分配（整卷落单节，低置信）；本方法只把 `MED/HIGH` 既有落点
  作结构证据，避免把粗分配当父节或宿主证据。
- 题面打分只覆盖题面，不读正文；零交集行一律不判 `EXISTING_SECTION`，改入聚合或留旧树。
