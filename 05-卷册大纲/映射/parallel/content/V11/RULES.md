## 四、处置阶梯（J4，逐块择一）

| 处置 | 含义 | 何时用 |
| --- | --- | --- |
| `归入` | 进入对应论题小节 | 默认；块主题与该题 thesis 同类 |
| `辑存` | 多个低价值块合并为一件，不逐块设小节 | 同一件内 ≥2 块均低价值且同质；reason 写“辑存组：<组名>” |
| `移出` | 确属他卷／他节论题 | reason 须写建议宿主（如 `V12-3.1`） |
| `挂账` | 该小节容量已满（≤12 块），或暂无法定位 | reason 写“容量已满”或“待定位” |
| `删除` | 仅限零内容块（空块、纯签名、退订启事） | reason 写“零内容：<类型>”，并给 bytes 与 sha256 |

**容量规则**：同一 `subsection_id` 收到超过 12 块时，第 13 块起一律 `挂账`，reason 写“容量已满（第 N 块）”。
**同类率**：同一小节的 `归入` 块须主题同类（J1 ≥80%）；发现异质块，改为 `移出`或 `挂账`，不得靠凑数达标。

## 五、输出

写一个 TSV：`05-卷册大纲/映射/parallel/content/V11/part<K>.tsv`。

- 编码 UTF-8 无 BOM；换行 LF；分隔符**制表符**；首行表头固定如下 **5 列**，顺序不得变：

```
rowmine_id	subsection_id	title	action	reason
```

| 列 | 取值 |
| --- | --- |
| `rowmine_id` | 逐字抄台账的 `rowmine_id` |
| `subsection_id` | 本卷 204 题之一（如 `V11.1.1.1`）；`挂账`／`移出`／`删除`／`辑存` 时写目标节（如 `V11-2.5`）或空 |
| `title` | 与 `subsection_id` 对应的题名（逐字抄 `titles.tsv`）；空处置写 `—` |
| `action` | `归入`／`辑存`／`移出`／`挂账`／`删除`／`未处理` 六者之一 |
| `reason` | ≤60 字，写判据：同类点、容量、他卷宿主、零内容类型 |

**行数守恒**：你负责的分片共 N 块，输出必须**恰好 N 行数据**（表头另计），每块出现且仅出现一次。这是硬验收判据。
