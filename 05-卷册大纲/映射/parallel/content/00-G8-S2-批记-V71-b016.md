## 二、取证要点

1. **2.1.1 基底与功能层分离**：`OneFS is built on a BSD-based UNIX operating system foundation. It supports both Linux/UNIX and Windows semantics natively…`（底座）＋`OneFS combines the three layers…into one unified software layer`（功能层合并）。合并发生在基础之上，**底座未被替换**。
2. **2.1.2 两厂商来源**：Isilon／PowerScale 侧 `From OneFS 8.2 onwards, the underlying operating system version is FreeBSD 11.`（原装对齐）；NetApp 侧 `ONTAP leverages a highly customized derivative of the FreeBSD operating system for some tasks.`（高度定制派生、仅部分任务）。来源相近、形态不同。
3. **2.1.3 选型动因**：Dell `because it is a mature and proven operating system, and the open-source community can be leveraged for innovation`（工程可用性）＋NetApp `needed a licensing model…without worrying about potential software licensing issues`（许可模型）。双动因互证。

## 三、复核分层（三份清单）

- 分层判定：含版本号（OneFS 8.2／FreeBSD 11）但为厂商自述的版本对齐陈述，按常规题三份清单。
- 清单 1：6/6 引文与出处对应（12 条候选全部先做命中校验，取 6 条）。
- 清单 2：6/6 对抓取文本空白归一逐字命中（onefs_ih／netapp_kb／netapp_cs）。
- 清单 3：NetApp 的 `for some tasks` 限定保留，不写“ONTAP 即 FreeBSD”；Dell 的选型理由未提许可，故许可侧由 NetApp 案例承担，不把 Dell 语句读作许可论据。
