## 二、取证要点

1. **3.3.1 前端集群**：`we added a FreeBSD box to our cluster of Web servers. Not only did it out-perform the rest of our machines, but it was more stable.`（集群先存在，FreeBSD 是加进去的一台）＋`over 50 servers running various versions of 2.1 STABLE`（生产全部迁移后的规模）。
2. **3.3.2 门户规模**：`over 180 days of uptime on a machine serving over 4 million HTTP requests per day`（单机）＋`deployed on nearly 100K machines`（配置管理覆盖）。**三者主体不同**：服务器数、单机吞吐、配置管理覆盖，不合并。
3. **3.3.3 商业证明**：`it was the stability, performance, and access to the sourcode that sold us`（选型所因，原文拼写 `sourcode` 照录）＋`Yahoo! *is* largely a BSD shop.`（2005 年仍在用的延续证据）。

## 三、复核分层（三份清单）

- 分层判定：含数量与吞吐，按“量化口径题”三份清单。
- 清单 1／2：6/6 引文与出处对应、6/6 逐字命中。
- 清单 3：**不写“Yahoo 有十万台 FreeBSD 服务器”**——`nearly 100K machines` 的主语是配置管理系统；五十余台是 2.1 STABLE 时期；日 400／1200 万次是单机吞吐。三者分列。
