## 二、取证要点

1. **2.2.3 版本对齐**：`From OneFS 8.2 onwards, the underlying operating system version is FreeBSD 11.`（并列陈述）＋`from version 6.0 in 2004 to version 14.0 today, FreeBSD has remained a constant and up-to-date component in NetApp.`（逐版沿革）。落块写“须以版本记录核对，不以推断代替”，**不画通用对应表**。
2. **2.3.2 WAFL 并置**：`Data ONTAP GX was created as a combination of the WAFL® file system and SpinFS running in a FreeBSD environment.`（组合来源）＋`the clean separation of the operating system from the file system allows for focused innovation within the file system itself`（分离维持两套维护线）。
3. **2.3.5 fork 与主线**：`now it tracks closer to the current release (also known as “tracking head” within the FreeBSD Community)`（跟随幅度可调）＋`Limit private customizations to business critical IP and upstream-first everything else.`（选择性合并边界）。
