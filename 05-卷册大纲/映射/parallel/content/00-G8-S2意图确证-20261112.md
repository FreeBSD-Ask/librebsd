## ⑤ 手段自由度

- 联网：HTTP 直取（curl，UA 常规）＋WebFetch／exa 兜底；抓取不受 robots 限制（项目既定口径）。
- 证据卡：`04-现代研究文献/01-参考文献总目/99-考据新增/<年>_<作者>_<slug>.md`，含 URL、抓取时点、sha256；`format='web'`、`status='kaoju_new'`、`source_tier` 必填。
- 写库：duckdb==2.0.0；`claimdb_guard` 两库 PASS → 专项备份槽 → waterlock `--db/--tag/--max-claim-id/--count` → 写四表 → `release --rows/--distinct`。
- 块体：一律由引擎 `script/_v11_supp.py` 按 JSON spec 生成，禁手工拼串；D2 锚 `ref<ID>#url`。
- 检索记录：每卷 `映射/parallel/content/V{NN}/s2-联网检索记录.tsv`，逐题一行。
