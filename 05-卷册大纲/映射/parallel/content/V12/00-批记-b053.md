## 二、判读要点

1. **4.5.1 硬件与抱负匹配**：McKusick 记 VAX-11/780 新宣布即满足要求且预算内可得（L4）＋TUHS 32V 页记 32V 提供 V7 环境却未用 VAX 虚存（L3，匹配的历史阶段）。
2. **4.5.2 大内存设计空间**：McKusick 记缺虚存使进程地址空间受物理内存限制（新 VAX 初始 1 MB）（L4）＋TUHS 3BSD 页记 3BSD 首加虚存、页面置换与按需分页（L3，设计空间具体化）。
3. **4.5.3 机型演进推动**：McKusick 记 1979-12 Joy 发出近一百份 3BSD——首个 Berkeley VAX 发行（L4，版本对齐）＋TUHS 32V 页记 32V 为商业 Unix 与 BSD 变体共同祖先（L3，谱系对齐）。
4. **4.5.4 厂商配合与机型获取**：McKusick 记 VAX-11/780 新宣布且预算内可得（L4，采购条件；与 4.5.1A 同句第二宿主）＋Kahn 回忆 DEC（Sam Fuller、Gordon Bell 等）对研究机构十分配合（L4，**语境为 CNRI 初创资助，非 Berkeley 购机**，旁证限定）。
5. **4.5.5 能力约束反向塑造**：McKusick 记 VAX 缺 reference bits 使 Babaoglu 的工作集分页实现复杂化（L4）＋TUHS 32V 页记 32V 未用虚存仅换入换出（L3，形态受实现选择约束）。
6. **4.5.6 因果分寸**：McKusick 用 fulfilled the requirements 描述匹配（L4，非“推动”）＋TUHS 用 first … to run 描述首发（L3，断言语须与允许语并置）。
