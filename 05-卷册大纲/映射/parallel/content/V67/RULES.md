| 处置 | 何时用 |
| --- | --- |
| 归入 | 块主题与该题 thesis 同类（默认；旧节已定址） |
| 辑存 | 同件低价值同质块合组 |
| 移出 | 属他卷论题（如 USENIX 早期 UNIX 技术史→V01-10；Linux 治理→V65） |
| 挂账 | 单题容量满（≤12）或暂无法定位 |
| 删除 | 零内容块（仅抬头无正文） |

**同类率** J1 ≥80%；不硬塞、不凑数；`reason` ≤60 字。
