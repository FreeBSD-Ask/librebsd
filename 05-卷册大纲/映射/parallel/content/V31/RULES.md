## 一、你在做什么

料域（34 个旧树节，见 `parts.tsv`）抽出的 817 个机器块是**语料**，不是小节。
逐块判读，判定它归入 204 个已批论题中的哪一个；不能归入者按 §四 阶梯处置。

**禁止由史料反推结构**（J0）：204 题已由标题线批准并落纲，只做归属，不改题、不增题、不并题、不拆分节。
**抽样披露**：料域节块总量 122,040，入批 817（每节按题面相似度降序取前 cap）；
低于阈值的块不在本批，不构成本批处置对象（例外报告披露）。

## 三、三十四章节边界（归属硬边界）

### 第 1 章　BSD 内核结构、调度与进程间通信
- 1.1 内核结构三段演化（PDP-11→4.2BSD→4.4BSD-Lite2）：收内核整体结构、monolithic 组织、子系统划分；不收单一子系统内部算法细节。
- 1.2 调度与时间片：收调度器、优先级、重调度节奏；不收 SMP 并行化（属后 1995 专题卷）。
- 1.3 管道与 IPC：收管道承袭、共享内存、信号与 IPC 机制；不收 socket（7.1）。

### 第 2 章　FFS 与 UFS（1974–1995）
- 2.1 FFS 柱面组与布局；2.2 UFS 命名与形态；2.3 soft updates（至 1995）；2.4 fsck 与磁盘可靠性。不收 ZFS／日志文件系统（属后 1995 卷）、不收 FreeBSD 存储栈现代演化。

### 第 3 章　虚拟内存与地址空间
- 3.1 VAX 虚存与 BSD；3.2 分页／交换／置换；3.3 mmap 与共享内存；3.4 虚存对象抽象。不收 Mach VM 移植后的 FreeBSD 时代（属 V05–V08 料域）。

### 第 4 章　工具链与移植
- 4.1 Berkeley Pascal 与系统软件教育；4.2 GCC 进入 BSD；4.3 KNF 与 style(9)。不收 C 语言诞生（属 V01）、不收 GCC 自身演化史（属 GNU 卷）。

### 第 5 章　隔离与包过滤（至 1995）
- 5.1 ipfw 与 IPFilter；5.2 chroot；5.3 隔离机制的边界。不收 pf（OpenBSD 3.x，属 V10 料域）、jails（属 FreeBSD 卷）。

### 第 6 章　终端、编辑器与 Shell
- 6.1 ed/ex/vi；6.2 vi 模态设计；6.3 termcap；6.4 curses；6.5 Job Control；6.6 C Shell。不收 emacs／GNU 对抗（属 V16）、不收后世编辑器谱系。

### 第 7 章　网络栈：Berkeley TCP／IP（1974–1995）
- 7.1 sockets 接口；7.2 BBN 与 Berkeley TCP／IP 两线；7.3 栈重写与代码归属（1988–1991）；7.4 路由／子网／网关；7.5 Tahoe 与 Reno 拥塞控制；7.6 BSD TCP／IP 的被参照。不收 IPv6／KAME（属 FreeBSD 网络卷）、不收网际网基础设施社会史（V08 后段）。

### 第 8 章　服务层
- 8.1 sendmail；8.2 BIND 与 DNS；8.3 inetd；8.4 Web 服务器（至 1995）；8.5 Ingres／POSTGRES／Berkeley DB。不收 MySQL／PostgreSQL 后世生态（属 V08 后段）、不收 opensmtpd（属 V10）。

**歧义裁决顺序**：①块主对象属于哪一类（内核／FS／VM／工具链／隔离／终端编辑／网络栈／服务）；②该对象在 34 节中的唯一归属；③仍歧义看时代与场合（哪个邮件列表、哪年、哪个发行版），取最贴近一节；④无法归属按 §四 处置并写明，不得硬塞。

## 四、处置阶梯（逐块择一）

| 处置 | 含义 | 何时用 |
| --- | --- | --- |
| `归入` | 进入对应论题小节 | 默认；块主题与该题 thesis 同类 |
| `辑存` | 多个低价值块合并为一件，不逐块设小节 | 同一件内 ≥2 块均低价值且同质；reason 写“辑存组：<组名>” |
| `移出` | 确属他卷／他节论题 | reason 写建议宿主（如 `V05-2.1`、`V10-3.2`、`V16-2.3`） |
| `挂账` | 该小节容量已满（≤12 块），或暂无法定位 | reason 写“容量已满（第 N 块）”或“待定位：<理由>” |
| `删除` | 仅限零内容块（空块、纯签名、退订启事） | reason 写“零内容：<类型>”，并抄 bytes 与 sha256 前 12 位 |

**容量规则**：同一 `subsection_id` 收到超过 12 块时，第 13 块起一律 `挂账`，reason 写“容量已满（第 N 块）”。
**同类率**：同一小节的 `归入` 块须主题同类（J1 ≥80%）；发现异质块，改 `移出` 或 `挂账`，不得靠凑数达标。

## 五、输出

主会话逐片写 `05-卷册大纲/映射/parallel/content/V31/part<K>.tsv`（K=1..4）。

- UTF-8 无 BOM；LF；制表符分隔；首行表头固定 5 列：`rowmine_id	subsection_id	title	action	reason`
- `rowmine_id` 逐字抄块档；`subsection_id`＝204 题之一；`title` 逐字抄 `titles.tsv`；空处置写 `—`。
- `action` 五者之一；`reason` ≤60 字，只写判据。
- **行数守恒**：该片块数 N，输出恰好 N 行数据，每块出现且仅出现一次。

其余六列由 `_vol_merge.py V31 --parts 4` 机器补全；落 `design/V31-C1.tsv`（P1）／`V31-C2.tsv`（P2–P4）。

## 六、硬约束

1. 只写 `part<K>.tsv` 与本卷 design 三件；不碰 outline、不建 `.md`（落盘由 `_vol_build_md.py`）。
2. 不撰写正文；`reason` 只写判据。
3. 不新拟题名；`title` 只能逐字抄 `titles.tsv`。
4. 禁直角引号；禁制表符以外的不可见字符。
5. 只判主题归属，不判结论真伪。
