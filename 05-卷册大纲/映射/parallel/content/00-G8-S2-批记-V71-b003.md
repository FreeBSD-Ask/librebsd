## 二、取证要点

1. **1.4.5 披露惯例**：ADC/ADM 13.1 与 13.0《Third Party Notices for FreeBSD-based Products》标题自署 FreeBSD-based；开篇“may include third party software components… This list was generated using third party software as of the date listed. This list may change… and may not be complete; it is provided “As-Is.””；13.0 正文条目体例为“组件＋版本＋版权行＋许可证”（如 Apache HTTP Server 2.4.39 标 Apache License 2.0）。
2. **1.5.2 驱动接缝**：BLX 14.1 架构页“full-fledged TCP/IP stack… bypassing the TCP/IP stack of the Linux kernel… interacts directly with the Linux kernel driver”；FreeBSD 基金会 2024 秋季峰会提纲列 2.2.5／4.4／4.9／6.3／8.4／11.4 六节点。
3. **1.5.4 内核约束**：13.1-37.232 FIPS 发行说明 NSPLAT-26973“The kernel clock and timer events in FreeBSD 11.4 is made similar to that of the FreeBSD 8.4 to achieve stability in the NetScaler VPX platform.”；15.1 迁移文档前置“must be running NetScaler 14.1 build 56.x or later… standard FreeBSD bundle first”。
