## 四、处置阶梯与容量规则

1. **自动类**（`_triage.py` 预分，直接写固定裁决）：
   `DEEP_ANALYSIS: sacred_sources` → 归入仅当题面即史学方法论（9.4／10.4／13.3），否则 `移出`（建议宿主＝史观卷）；
   `concept_history` → 归入概念考订题（9.2／9.3），否则 `移出`；
   ≤260B 空块 → `删除`（无正文）。
2. **真人料阶梯**：`归入`（论点答该题 thesis）→ `辑存`（相关但答别题且别题已满/属本卷他节）→
   `移出`（属他卷，记建议宿主）→ `挂账`（相关但题面无对应、暂无宿主）→ `删除`（重复/无内容）。
3. **单题容量 ≤12 块**（合并器超限自动降挂账）；同件同题连续块优先取首块。
4. **料域陷阱（本卷特有）**：
   - 016.4／012.1 主体是**技术本体**（C 用法、1978 生态条目）——按“谈文献则归、谈技术则移”逐块裁，预期移出占绝对多数，不得整片降格为空骨架后放弃逐块落行；
   - 012.5／012.6／010.7 的“元论述”块（谈方法、谈叙事、谈考订）才是本卷目标块，技术性结论块移出 V06／V08；
   - 354.1 为 BSD 俚语考据（主体属 V17+ 治理卷），仅词源考据块可归 9.2；
   - 030.5（bill joy）与 395.19（LKML）属人物／他卷叙事，预期全部移出（V09/V10/V20）；
   - 394.2／409.1／006.2 等小料域逐块精读，优先归入 12.x／13.3。
5. **0 块节的处理**：54 节中 6.2／7.1—7.4／8.1—8.3／10.1 等节预期 0 块或极少块——
   这是文献元卷的料域实况（旧树机器块几乎不谈“文献本身”），按空骨架落盘并在
   例外报告按节披露，**不得**为凑数把技术块顶入题面。
