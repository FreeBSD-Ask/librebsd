## 四、处置阶梯＋容量规则

1. 自动类（脚本已剔）：`DB_REF`／`DB_POINTS`／卷内重复 ≥5 的 `DEEP_ANALYSIS` 模板 → 删除，不写 dec。
2. 零内容块（正文 < 60 字，切块器已剔）与判读期发现的空壳块 → `删除`，写明理由。
3. 与题面意合的 ROW_MINE／MAIL_INSIGHT／“要点”实质块 → `归入`（sid 逐字取自 `titles.tsv`），单题 ≤12，超限由合并器降 `挂账`。
4. 实质块但宿主在他卷：A/UX 与 Mac OS 7 运维 → `移出`（V35 商业 UNIX 系）；
   泛技术流水 → `移出`（V49）；许可证条款细读 → `移出`（V59）；史学通论 → `移出`（V75）；
   别的 BSD 项目自述 → `移出`（对应项目卷）。reason 须写建议宿主卷号。
5. 同题面但证据力弱 → 原则上 `归入`（filled／skeleton 由落盘器定），不轻判挂账。
6. `X.0` 章级综合与 `N.N` 节同事实重复时：**先 `X.0` 后 `N.N`**，重复块降 `挂账`，不双计。
