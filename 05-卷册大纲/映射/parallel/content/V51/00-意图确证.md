## 五、手段自由度

- **锁定**：子代理 0 路；outline 第四级行的唯一写者＝`merge_subsections.py`；
  含反引号／`$` 与中文的落盘一律走 Write 工具写脚本再执行（禁 `python -c` 内联）；
  提交必带显式 pathspec，且 add 与 commit 同窗（他线并发在工作区，禁 `git add -A`）；
  共享文件（outline.txt／targets.tsv／SUMMARY／index.html／theme／keywords）写入→门禁→提交
  须在同一紧凑窗口内完成，避免与他线落盘交叠。
- **自选**：各卷料域切片的划分与片数、判读顺序、reason 措辞、块文本的通读深度
  （只读块摘要，不联网补证；判读只依据块内文本与 thesis）、临时脚本命名。
