# 3.3.2 断裂处的技术标记

<!-- MAIL_INSIGHT: 3855bd$sae@quagga.ru.ac.za -->
**观点**：1994年10月，FreeBSD 核心团队成员 Geoff Rehmet 说明：4.4BSD-Lite 磁带只有部分代码可直接编译，内核因“那场愚蠢的 USL 诉讼”缺件，FreeBSD 2.0 的开发实质是把 4.4-Lite 引导为完整操作系统——折入 FreeBSD 1.x 功能并补齐 BIND、FLEX 与全部 GNU 工具。
**邮件来源**：Geoff Rehmet（FreeBSD core team），comp.unix.bsd，1994-10-20，Message-ID: `3855bd$sae@quagga.ru.ac.za`
**史学意义**：当事人精确刻画了从 4.4BSD-Lite 法律清白基底到 FreeBSD 2.0 可用系统的“重建工程”规模。
