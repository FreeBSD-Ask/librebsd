# 7.6.4 过滤规则的表述语汇

<!-- ROW_MINE: port-vax.messages.459729 -->
**当事人自述**（证据等级：L4，来源：`historical_claims.duckdb.claim.CL-RM-013248`；2026-09-06 大库战线行级遍历考据采纳）

2019 年 2 月 10 日，Maciej W. Rozycki 把 VAX 浮点异常修复的讨论推向格式史层面：他主张测试禁用与 XFAIL 是异构浮点目标的正当出路，并以 PS2 的 Emotion Engine R5900 MIPS 核（同样非 IEEE-754、无 NaN/Inf/异常）为旁证；自述当年移植 GCJ 与 GNU Classpath 时因 Java 标准明确要求 IEEE-754 而遭遇的困境；进而断言 denormals 的缺失才是 VAX 浮点格式输掉战争的根本原因，援引 Kahan 访谈佐证，并论及 GCC 软浮点互链须在 CALLS 语义下增设转换 thunks。这封信是 VAX 浮点败因论的一手陈述，把操作系统侧的修复议题接入格式演化史与上游生态判断。以上为当事人自述，属 L4 级证据，败因归断与历史回忆均属当事人立场，Kahan 文献与 Java 规范须独立核对。
