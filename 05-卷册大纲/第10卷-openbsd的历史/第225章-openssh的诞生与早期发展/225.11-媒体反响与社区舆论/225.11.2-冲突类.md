# 225.11.2 冲突类

### 新闻条目 1

- **新闻标题（中英）**：OpenSSH 1.2.2 随 OpenBSD 2.6 发布（OpenSSH 1.2.2 shipped with OpenBSD 2.6）
- **新闻来源**：OpenSSH 官方项目历史（openssh.com/history.html）+ 1999-12-01 + URL: <https://www.openssh.com/history.html>；OpenBSD 2.6 发行说明 <https://www.openbsd.org/26.html>
- **新闻摘要**：OpenSSH 项目历史官方叙述：1999 年 OpenBSD 开发者发现 Björn Grönvall 的 OSSH（基于 Tatu Ylönen 的 ssh 1.2.12 最后自由版本）后，决定在 OpenBSD 2.6 发布前两个月内 fork OSSH 并进行快速安全审计。初始 import 于 1999-09-26 完成，发布时部分源文件 RCS 修订号已达 1.34 至 1.66。团队分工：Theo de Raadt（移除非可移植代码以简化源码）、Niels Provos（前往加拿大移除加密与 GPL 组件以实现完全自由可重用）、Markus Friedl（替换 SSH 1.3 协议为 SSH 1.5、后添加 SSH 2 与 SFTP）、Bob Beck（处理 Makefile 与 OpenSSL 无 RSA 专利算法编译）、Aaron Campbell（改进文档）、Dug Song（Kerberos IV 认证）。OpenSSH 1.2.2 于 1999-12-01 随 OpenBSD 2.6 发布，移除所有专利组件，支持 skey 一次性口令认证。OpenBSD 2.6 因 RSA 专利未到期，CD 中 libssl/libcrypto 共享库缺失 RSA，安装时用户可通过 FTP/HTTP 替换。
- **与本章主题的关联说明**：本章叙述 OpenSSH（1999-2026），1999-12-01 OpenSSH 1.2.2 首次随 OpenBSD 2.6 发布是本章 “OpenSSH 诞生” 叙事的核心时间锚点。
- **与官方史料的交叉验证结论**：openssh.com/history.html 项目官方叙述与 OpenBSD 2.6 发行说明（openbsd.org/26.html）一致；与 OpenBSD 2.6 changelog 中 OpenSSH 1.2.2 条目互证；与 CVSweb 中 src/usr.bin/ssh/LICENCE 文件（cvsweb.openbsd.org/src/usr.bin/ssh/LICENCE）的许可证组合互证。一致采纳。

### 新闻条目 2

- **新闻标题（中英）**：Compiling OpenSSH No Longer Requires Linking in OpenSSL（编译 OpenSSH 不再需要链接 OpenSSL）
- **新闻来源**：undeadly.org + pitrh（Peter Hessler）署名 + 2014-04-30 + URL: <https://undeadly.org/cgi?action=article;sid=20140430045723> + 存档 URL: 待补
- **新闻摘要**：undeadly.org 2014-04-30 报道 Markus Friedl（markus@）于 2014-04-29 提交 commit（<https://marc.info/?l=openbsd-cvs&m=139879453001957>），使编译时链接 OpenSSL 变为可选（make OPENSSL = no）。禁用 OpenSSL 后，算法集合缩减为 curve25519、aes-ctr、chacha、ed25519。undeadly.org 评论中 phessler（Peter Hessler）确认链接 LibreSSL 是当前默认；markus（Markus Friedl）补充说明 OpenSSL 与 LibreSSL 在 OpenSSH 视角下已有相同的 API 与特性。这一变更发生在 Heartbleed（CVE-2014-0160，2014-04-07）披露后约三周、LibreSSL fork（2014-04-23）后一周，使 OpenSSH 可以独立于 OpenSSL/LibreSSL 构建最小化加密套件，对嵌入式场景特别有价值。Slashdot 同日报道（it.slashdot.org/story/14/04/30/1822209）转载。
- **与本章主题的关联说明**：本章叙述 OpenSSH（1999-2026），2014-04-29 OpenSSH 编译可选 OpenSSL 是本章 “OpenSSH 工程独立性” 叙事的核心节点，体现 OpenSSH 在 Heartbleed 后对加密库依赖的解耦。
- **与官方史料的交叉验证结论**：undeadly.org 报道与 Markus Friedl 的 openbsd-cvs 邮件列表 commit 原文（<https://marc.info/?l=openbsd-cvs&m=139879453001957>）完全一致；与 Slashdot 2014-04-30 报道形成媒体反映链；与 OpenSSH 6.7→6.8 changelog 中 “Support --without-openssl at configure time” 条目互证。一致采纳。
