# 212.3.4 要点OpenSSH199910原始公告与CVScommitlog是研究OpenS

**要点**：OpenSSH 1999.10 原始公告与 CVS commit log 是研究 OpenSSH 诞生的核心史料；公告由 de Raadt 发布至 OpenBSD 邮件列表与 comp.security.ssh Usenet；commit log 反映早期开发节奏与贡献者

**史料**：OpenBSD 1999.10 OpenSSH 发布公告；OpenSSH CVS commit log；comp.security.ssh Usenet 存档 ［A］

**史观**：总纲第 9 条——经验优先：公告与 commit log 需考据——部分早期邮件在存档迁移中可能丢失

**辨析**：OpenSSH 1.0 的具体发布日期存在 1999.10.1 与 1999.10.5 两种说法——需对照 OpenBSD 官方公告核验【代码级证据·openbsd.duckdb openbsd-src 仓库】commit `bf74e864c129cdd07c9ebd41a8db719c7c8b49d8`（committer_date `1999-10-01T18:58:56Z`，author `deraadt`，message_subject “OpenSSH-1.0”）证实 1999-10-01 为 OpenSSH 1.0 的 commit 日期，“1999.10.5 说法”无代码级证据支持；OpenSSH 官方历史页面 <https://www.openssh.com/history.html> 显示 OpenSSH 1.2.2 于 1999 年 12 月随 OpenBSD 2.6 发布，OpenSSH 1.0 早于 1.2.2，时序与 1999-10-01 commit 日期吻合经 [邮件列表库] 验证通过（来源：openbsd-announce 1999-12-01 Louis Bertrand “OpenBSD 2.6 Press Release” 确认 OpenBSD 2.6 为首个集成 SSH 协议的操作系统；openbsd-tech 2015-12-02 Tobias Ulmer “ARM as: add .inst support” 明确提及 “No GPLv3 license was violated” 证实 OpenBSD 对 GPLv3 的敏感态度）。
