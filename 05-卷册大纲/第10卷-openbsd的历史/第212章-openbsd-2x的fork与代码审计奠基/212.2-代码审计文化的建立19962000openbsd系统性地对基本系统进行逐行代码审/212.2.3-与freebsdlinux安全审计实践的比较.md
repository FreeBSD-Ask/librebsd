# 212.2.3 与 FreeBSD/Linux 安全审计实践的比较

**要点**：FreeBSD 1990 年代后期建立 Security Officer 制度但未系统性代码审计；Linux 1990 年代缺乏系统性审计，依赖用户与厂商报告；OpenBSD 是 1990 年代唯一系统性代码审计的 Unix 系统；OpenBSD 审计成果通过 cross-BSD 协调反馈至 FreeBSD/NetBSD

**史料**：FreeBSD Security Advisories 1996-2000；Linux Security Audit 项目文档；cross-BSD 安全协调邮件列表 ［A］

**史观**：总纲第 15 条——文化即形式主义：OpenBSD 的“审计文化”将安全规范凝结为可复用的工程形式（advisory、errata、commit 记录规范），与 FreeBSD/Linux 的“反应式安全”构成两种不同的文化资产形态

**辨析**：OpenBSD 与 FreeBSD/Linux 安全实践的“严格程度”对比缺乏权威评估——需对照实际漏洞修复时序核验；OpenBSD 审计成果被其他项目移植的具体数量需考据

**文献**：FreeBSD Security Advisories；Linux Security Audit 项目；cross-BSD 协调邮件列表 ［A］
