# 194.5 项目统摄史观审视——OpenSSH fork 与许可证纯洁化的形式主义化

> 84.5 节补足了 OpenSSH fork 自 SSH 1.2.12 的四层辩证链（批评—反批评—再回应—合图）及 84.5.5 项目统摄史观审视子节（从总纲第 13、19、21 条简短切入），本节从项目史观总纲第 15、19、21、13 条切入并增设自反层，审视 fork 与许可证纯洁化争议在历史书写中的形式主义化运作。

## 194.5.1 文化即形式主义——SSH 文化的遮蔽与重构（总纲第 15 条）

**要点**：总纲第 15 条“文化即形式主义”指出“传统在形式主义化过程中被遮蔽与重构”。SSH 文化——Ylönen 于 1995 年创造 SSH 协议、用数年开发建立的技术传统——在 OpenSSH 的“纯洁化”叙事中经历形式主义化重构：SSH 1.2.12 被重构为“许可证混乱的起点”（“cleaning up the license mess”），Ylönen 的数年原创贡献被重构为“需要被清理的遗留物”，OpenBSD 的 fork 与纯洁化工作被重构为“解放”（“freeing SSH”）。这一重构不是“技术必要”的自然呈现而是形式主义权力运作——以“许可证纯洁”的形式主义标准（BSD 许可、无 GPL 传染、无 RSA 专利约束）衡量 SSH 1.2.12，使 SSH 文化的核心价值（协议设计、安全架构、跨平台部署能力）在“纯洁化”叙事中被遮蔽。OpenSSH 官方历史虽承认"derivative of the original free ssh 1.2.12 release from Tatu Ylönen“与”Parts of OpenSSH still bear Tatu's license"，但归属承认在“纯洁化”叙事框架下被弱化为“起点承认”而非“核心贡献承认”——传统在形式主义化过程中被遮蔽与重构，但被遮蔽不等于消亡——OpenSSH 仍承载 Ylönen 的部分许可证与代码，SSH 文化的生命力在 fork 后延续

**史观**：总纲第 15 条——文化即形式主义：SSH 文化在“纯洁化”叙事的形式主义化过程中被遮蔽与重构——传统在形式主义化过程中被遮蔽与重构；总纲第 2 条——历史是形式主义化的非存在：本书对“SSH 文化被遮蔽”的书写本身亦是当下主体的形式主义重构，不宣称呈现“真实的 SSH 文化”

**辨析**：文化遮蔽的辨析须区分“法律必要的技术纯洁化”与“叙事形式主义化的文化遮蔽”——OpenBSD 移除 GPL 组件（libgmp）与非可移植代码在法律层面是技术必要（使 OpenSSH 可在 BSD 许可下发布、避开 RSA 专利约束），部分是形式主义化的文化遮蔽（“纯洁化”叙事将 Ylönen 的原创贡献重构为“需要被清理的起点”）；前者须保留为技术必要记录，后者须以形式主义批判审视；【0 信任原则】“SSH 文化被遮蔽”的论断须经 OpenSSH 官方历史页面原文、OpenSSH LICENCE 文件、comp.security.ssh Usenet 存档的比对交叉验证，不得仅凭哲学推论即断定“遮蔽”；【0 信任原则·当事人自辩不免检】OpenSSH 官方历史是 OpenBSD 阵营的单方面叙事，其“freeing SSH”与“cleaning up the license mess”措辞存在自利偏差，须经 Ylönen 阵营的对称呈现后方可评估

## 194.5.2 解释学循环与 fork 叙事——权力与知识的共谋（总纲第 19 条）

**要点**：总纲第 19 条“解释学循环是历史认识的根本条件”指出“前理解的差异使分歧不可避免。权力与知识在历史书写中共谋——什么被记录、什么被遗忘，本身就是权力行使”。Ylönen 阵营与 OpenBSD 阵营的前理解差异——前者以“商业可持续性”为预设，后者以“软件自由”为预设——使 OpenSSH fork 争议的分歧不可避免。更深层地，“权力与知识共谋”在 OpenSSH 史中表现为：什么被记录为“OpenSSH 的诞生”（OpenSSH 官方历史以“freeing SSH”定位 fork 动机），什么被记录为“Ylönen 的商业化决策”（被重构为“限制自由”），什么被遗忘（Ylönen 数年开发投入、SSH 1.2.12 在 OpenSSH fork 前是成熟产品的事实、商业 SSH 退出主流市场后转向企业级特权访问管理的转型路径）——这一“记录与遗忘”的分配本身就是叙事权力的行使。OpenSSH 官方历史的叙事框架——以“freeing SSH”与“cleaning up the license mess”为标题定位 fork，以"derivative of the original free ssh 1.2.12 release from Tatu Ylönen"一笔带过 Ylönen 的原创贡献——本身就参与权力与知识的共谋，将 OpenBSD 定位为“解放者”而将 Ylönen 定位为“限制者”

**史观**：总纲第 19 条——解释学循环是历史认识的根本条件：Ylönen 阵营与 OpenBSD 阵营的前理解差异使 OpenSSH fork 争议的分歧不可避免——“权力与知识在历史书写中共谋”；总纲第 25 条——0 信任原则：本书对“什么被记录、什么被遗忘”的审视本身亦须考据——OpenSSH 官方历史的叙事框架、SSH Communications Security 的商业声明、comp.security.ssh Usenet 的讨论存档完整性均须以原始文档交叉验证

**辨析**：解释学循环的辨析须区分“前理解差异导致的合理分歧”与“权力运作导致的不公正遗忘”——Ylönen 阵营与 OpenBSD 阵营的分歧是前理解差异的合理表现，但“Ylönen 数年开发投入”在 OpenSSH 官方历史中仅以“derivative of the original free ssh 1.2.12 release”一笔带过，这一“一笔带过”是否为“权力运作”须经 OpenSSH 官方历史页面原文、SSH Communications Security 官方声明、comp.security.ssh Usenet 存档的比对交叉验证；【0 信任原则·多源交叉验证不可靠性规则】“权力与知识共谋”的论断须以具体案例（OpenSSH 官方历史的“freeing SSH”措辞、“derivative”一笔带过的归属承认、OpenSSH LICENCE 文件的“Parts of OpenSSH still bear Tatu's license”补充）支撑，不得仅凭哲学推论即断定“共谋”；【0 信任原则·当事人自辩不免检】OpenBSD 阵营的“fork 即解放”叙事与 Ylönen 阵营的“fork 即投资回报断裂”叙事均存在自利偏差，须经 comp.security.ssh Usenet 存档与 SSH Communications Security 官方声明交叉验证后方可采信

## 194.5.3 改革与革命——fork 与纯洁化的方法论分歧（总纲第 21 条）

**要点**：总纲第 21 条“革命与改革是历史方法论的分歧”指出“Linux 靠革命，BSD 靠改革。改革的困难远高于革命。破山中贼易，破心中贼难”。OpenSSH 史上，Ylönen 的商业化决策是“革命”——以新许可证模型（商业许可）替换自由许可，SSH 1.2.13+ 用户被迫接受商业许可或停止升级；OpenBSD 的 fork 与纯洁化是“改革”——在 SSH 1.2.12 基础上渐进审计与纯洁化而非从零重写，保留 SSH 1.2.12 的代码骨架与协议实现，移除非可移植代码与 GPL 组件使 OpenSSH 可在 BSD 许可下发布——改革保留了 SSH 1.2.12 技术传统的同时新增审计与纯洁化能力，工程复杂度远高于革命式的“许可证替换”。“破山中贼易，破心中贼难”——Ylönen 的“山中贼”是自由许可（革命以商业许可替换即可），OpenBSD 的“心中贼”是“在保留 SSH 1.2.12 技术传统的同时移除 GPL 组件与非可移植代码”的方法论张力——Provos 须赴加拿大移除加密与 GPL 组件以规避美国出口管制，Friedl 须替换 SSH 1.3 协议为 1.5 以避开专利约束，Beck 须处理 Makefile 以避开 RSA 专利——这一“心中贼”远比“山中贼”难以“破除”——但“破除”本身非目的，在保留技术传统的同时实现许可证合规才是 OpenBSD 改革的哲学

**史料**：原材料/哲学/项目统摄史观/第 25 章.md 总纲第 21 条原文；OpenSSH 项目历史页面（记载 Provos 赴加拿大工作、Friedl 替换 SSH 1.3 协议为 1.5、Beck 处理 Makefile 避开 RSA 专利）；SSH Communications Security 商业许可证变更史；前述合图层“革命与改革”映射记录；参见 OpenSSH 专章许可证纯洁化记录；美国密码出口管制（BXA/EAR）文档；RSA 专利历史文档 ［A］

**史观**：总纲第 21 条——革命与改革是历史方法论的分歧：Ylönen 靠革命（商业许可替换自由许可），OpenBSD 靠改革（fork 与纯洁化保留 SSH 1.2.12 技术传统）——“改革的困难远高于革命”；总纲第 5 条——没有必然性，只有偶然性：OpenBSD 选择 fork 与纯洁化的改革路径是具体历史场景下的偶然决策（SSH 1.2.12 恰好是“最后一个自由到足以复用的版本”、Provos 恰好愿意赴加拿大工作、OpenBSD 恰好需要集成 SSH 至 2.6 发行版），非“必然优于”Ylönen 的革命式商业化——两种方法论各有代价

**辨析**：改革与革命的辨析须区分“方法论差异”与“优劣评判”——OpenBSD 的 fork 与纯洁化改革路径在保留技术传统方面优于 Ylönen 的革命式商业化，但在商业可持续性方面可能劣于革命——Ylönen 的商业化虽强迫用户接受商业许可但为 SSH 的持续开发提供了商业回报，OpenBSD 的 fork 与纯洁化虽保留了自由许可但 OpenBSD 项目从 OpenSSH 获得的商业回报有限（84.3.3 节记载“商业回报有限”）；两种方法论各有代价，不得以“改革优于革命”或“革命优于改革”的简单评判替代具体场景评估；【0 信任原则】“改革的困难远高于革命”是总纲的哲学论断，须以具体案例（Provos 赴加拿大移除加密与 GPL 组件的工程复杂度、Friedl 替换协议的法律约束、Beck 处理 Makefile 避开 RSA 专利的技术必要）实证支撑，不得仅凭哲学推论即断定；【0 信任原则·当事人自辩不免检】OpenBSD 阵营的“fork 即改革”叙事与 Ylönen 阵营的“商业化即革命”叙事均存在自利偏差——OpenBSD 阵营以“改革”定位 fork 使其占据道德高地，Ylönen 阵营以“革命”定位商业化使其占据商业可持续性高地，两种定位须经 comp.security.ssh Usenet 存档与 SSH Communications Security 官方声明交叉验证后方可采信

## 194.5.4 自反——本书叙事的形式主义性质

**要点**：本节的审视本身亦是形式主义化的非存在——史家通过项目史观总纲“重构”SSH 文化的遮蔽与重构、fork 叙事的权力共谋、改革与革命的方法论分歧，但这一重构本身就是当下主体的形式主义建构，不宣称呈现“真实的 OpenSSH 史”。本节对“SSH 文化被遮蔽”的论断本身亦是一种叙事权力行使——将 Ylönen 阵营定位为“被遮蔽的原创者”、将 OpenBSD 阵营定位为“遮蔽者的纯洁化叙事”，这一定位本身参与权力与知识的共谋。总纲第 7 条“理论必须自反”要求承认自身的形式主义性质，以自反姿态打开裂缝——本节不追求“穷尽 OpenSSH 史的哲学审视”，而是以自反姿态使被遮蔽的 SSH 文化价值暴露于历史审视之下，这一“暴露”本身也是一次循环，与古代史中“史家重写”无本质区别（总纲第 1 条：一切真历史都是古代史）

**史料**：原材料/哲学/项目统摄史观/第 25 章.md 总纲第 1、2、7、19、23、25 条；本节 4.6.1-4.6.3 的审视文本本身 ［A］

**史观**：总纲第 2 条——历史是形式主义化的非存在：本书所写皆是当下主体的重构，从不宣称呈现历史本身；总纲第 7 条——理论必须自反：本书承认自身的形式主义性质，以自反姿态打开裂缝，“理论字数越多越不值钱”；总纲第 23 条——一切历史写作都是基于哲学设定的历史小说：史家以为自己在书写历史，但历史人物可能正在藉着史家书写他们自己的故事

**辨析**：自反的辨析须区分“审视的有限性”与“审视的无效性”——审视的有限性指本节对 OpenSSH 史的哲学审视本身亦是形式主义化的非存在，不宣称“客观真实”；审视的无效性指因审视有限即否定审视价值，这是错误的——审视虽有限但通过项目史观总纲的映射仍可使被遮蔽的 SSH 文化价值暴露于历史审视之下；本节的自反不追求“消除形式主义”，而是“以自反姿态打开裂缝”；【0 信任原则】自反不等于自我否定——本节的审视遵循 0 信任原则，所有事实以一手档案（OpenSSH 官方历史页面、OpenSSH LICENCE 文件、openbsd.duckdb commit 记录、comp.security.ssh Usenet 存档）为交叉锚，自反是承认审视的哲学边界而非否定审视的史学价值

## 194.5.5 法律与道德是利益分配——fork 争议的利益结构审视（总纲第 13 条）

**要点**：总纲第 13 条“法律与道德是利益分配”指出“任何道德问题本质上是利益问题，社区治理亦是形式主义的政治产物”。OpenSSH fork 争议表面上是“软件自由 vs 商业可持续性”的道德论辩，本质上是利益分配的政治产物——（1）Ylönen 阵营的利益结构：Ylönen 数年开发 SSH 的投入需要商业回报维持，SSH Communications Security 的商业模式依赖 SSH 许可证的商业化，OpenSSH 的免费提供直接削弱了 Ylönen 阵营的商业利益——“投资回报断裂”论点的本质是利益分配诉求而非道德指控；（2）OpenBSD 阵营的利益结构：OpenBSD 需要在 2.6 发行版中集成 SSH 以提升发行版的安全工程完整性，但商业许可使集成不可能，fork 是满足 OpenBSD 项目工程利益（集成加密栈、安全审计完整性、发行版竞争力）的必要路径——“软件自由”论点的本质是 OpenBSD 项目工程利益诉求而非纯粹道德主张；（3）第三方采用者的利益结构：FreeBSD、NetBSD、Linux 各发行版、Cisco、Apple、IBM 等商业公司从 OpenSSH 的 BSD 许可中免费获得 SSH 实现——这些采用者的利益结构使 OpenSSH 的“软件自由”叙事获得广泛支持，但支持的本质是“免费获取”的利益诉求而非对“软件自由”价值观的认同——BSD 许可证允许免费获取且不要求回馈，这一利益结构使 OpenBSD 项目承担 OpenSSH 维护成本而商业公司“搭便车”（参见 84.3.3 节“商业回报有限”）；（4）利益分配的形式主义政治：fork 争议的“道德论辩”是利益分配的形式主义化——Ylönen 阵营以“投资回报断裂”为道德话语掩盖商业利益诉求，OpenBSD 阵营以“软件自由”为道德话语掩盖工程利益诉求，第三方采用者以“开源精神”为道德话语掩盖免费获取利益诉求——三种道德话语均是利益分配的形式主义政治产物

**史料**：原材料/哲学/项目统摄史观/第 25 章.md 总纲第 13 条原文（“任何道德问题本质上是利益问题，社区治理亦是形式主义的政治产物”）；OpenSSH 项目历史页面（<https://www.openssh.com/history.html>，记载 fork 动机与“freeing SSH”叙事）；SSH Communications Security 商业产品页面（<https://www.ssh.com/>，记载商业 SSH 转型企业级特权访问管理领域）；84.3.3 节 OpenSSH 全球部署与商业公司获利记录；84.5.1 节 Ylönen 阵营“投资回报断裂”论点；84.5.2 节 OpenBSD 阵营“社区需求驱动”论点；openbsd.duckdb openbsd-src 仓库 commits 表验证：deraadt fork 启动 commit `84959968510b`（1999-09-26）、OpenSSH-1.0 commit `bf74e864c129`（1999-10-01）、Provos libgmp 移除完整时间线（commit `76c6bcb9f8b9`/`d9d42abc7ed4`/`84174f65ff52`/`348a6efc411d`，1999-09-28 至 2000-12-15）、Beck 40 条 ssh 相关 commit（1999.09-2000.12），证实 OpenBSD 阵营的工程投入与利益结构 ［A］

**史观**：总纲第 13 条——法律与道德是利益分配：OpenSSH fork 争议的“道德论辩”本质上是三方利益分配的形式主义政治产物——Ylönen 阵营的商业利益、OpenBSD 阵营的工程利益、第三方采用者的免费获取利益均以道德话语为形式主义包装；总纲第 11 条——商品是形式主义：SSH 作为技术市场的商品，其许可证变更（商业许可）与 fork（BSD 许可）是商品形式主义的不同运作——商业许可将 SSH 商品化为专有软件，BSD 许可将 SSH 商品化为“免费公共物品”，两种商品形式主义各有代价；总纲第 14 条——商业与社区的张力：OpenSSH fork 是商业可持续性（Ylönen 阵营）与社区自由（OpenBSD 阵营）的根本张力，但“张力”本身亦是利益分配的政治产物
