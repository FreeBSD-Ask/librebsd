# 194.9 OpenBSD 从 4.4BSD-Lite2 继承的 audio(4)（跨 BSD/UNIX/macOS 扩展）

## 193.11.1 audio(4) 的继承与 sndio 协同

**要点**：OpenBSD 自 fork 自 NetBSD 1.0（**1996 年 10 月**）起继承 **audio(4)** 框架，实现路径与 NetBSD audio(4) 在 fork 时刻同源。man page 见 **man.openbsd.org/audio.4**。OpenBSD 在 2.x 时期对 audio(4) 进行了安全审计，特别是在 sndio(7) 音频服务器引入后，audio(4) 与 sndio 协同提供安全的音频访问路径。

**史料**：OpenBSD 2.0 Release Notes；**audio(4)** man page（man.openbsd.org/audio.4）；OpenBSD src 仓库 **sys/dev/audio.c** 源码；OpenBSD. *sndio(7) Documentation*. openbsd.org。〔L1 代码/构建产物/L3 官方文档与公告〕

**史观**：总纲第 1 条——源头时刻：OpenBSD fork 时“冻结”了 audio(4) 的 NetBSD 实现；总纲第 2 条——分离与聚合：OpenBSD 从 NetBSD 分离时聚合了 audio(4) 框架；总纲第 6 条——技术选择的代价：OpenBSD 选择保留 audio(4) 并与 sndio 协同，付出维护复杂度代价，但获得安全的音频访问路径；总纲第 10 条——边缘者贡献：audio(4) 的最初设计者被遮蔽，sndio 的设计者 Alexandre Ratchov 在 OpenBSD 社区获得署名；总纲第 17 条——形式与内容：audio(4) 与 sndio 共同构成“形式”（设备接口+用户态服务器），覆盖了音频访问的“内容”；自反性声明：本释读不预设“OpenBSD 中心论”——audio(4) 在 NetBSD、FreeBSD、DragonFly BSD 均有保留，sndio 是 OpenBSD 独有扩展。

**辨析**：OpenBSD audio(4) 与 NetBSD audio(4) 在 fork 时刻同源，分叉发生在 OpenBSD 4.x（2006）后的安全审计与 sndio 引入；与 Linux ALSA 无代码共享；macOS CoreAudio 是 Apple 自研，与 BSD 谱系无源码关系。

**文献**：OpenBSD Project. *OpenBSD 2.0 Release Notes*[EB/OL]. (1996-10-18). <https://www.openbsd.org/>; OpenBSD Project. *audio(4) Manual Page*[EB/OL]. <https://man.openbsd.org/audio.4>; OpenBSD Project. *sndio(7) Documentation*[EB/OL]. <https://www.openbsd.org/>.
