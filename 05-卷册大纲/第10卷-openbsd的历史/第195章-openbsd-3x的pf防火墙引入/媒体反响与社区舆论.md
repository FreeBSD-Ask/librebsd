# 第 195 章 OpenBSD 3.x 的 pf 防火墙引入——媒体反响与社区舆论

> 本子节汇总与本章主题相关的新闻报道与社区舆论，按“批评类 / 里程碑事件类”两类组织（导语原称七类，其余五类待回填）。所有新闻条目对应总纲第 9 条“经验优先”的交叉验证要求，须与官方史料交叉验证后方可采信。

## 批评类

### 新闻条目 1

- **新闻标题（中英）**：DARPA Funding Pulled（DARPA 撤资事件）+ The Continued DARPA Funding Story + The Emerging DARPA Reasoning（系列报道三篇）
- **新闻来源**：undeadly.org + 多位社区编辑 + 2003-04-17 / 2003-04-21 / 2003-04-22 + URL: <https://undeadly.org/cgi?action=article;sid=20030417181810> + <https://undeadly.org/cgi?action=article;sid=20030421190834> + <https://undeadly.org/cgi?action=article;sid=20030422123107> + 存档 URL: 待补
- **新闻摘要**：2003 年 4 月，DARPA（美国国防高级研究计划局）突然撤回了对 OpenBSD 项目 POSSE 项目的资助（约 50 万美元），正值 OpenBSD c2k3 hackathon 期间。后续报道揭示撤资原因与 Theo de Raadt（西奥·德·若特） 2003 年 3 月公开反对伊拉克战争立场直接相关，DARPA 在政治压力下撤资。该事件是 OpenBSD 历史上最重大的资金断裂危机，直接导致项目依靠社区捐款存活。
- **与本章主题的关联说明**：本章叙述 OpenBSD 3.x 时期（2001-2004），DARPA 撤资事件发生在 OpenBSD 3.3 发布前夕，是本章 “OpenBSD 资金困境与社区韧性” 叙事的核心事件。
- **与官方史料的交叉验证结论**：undeadly.org 三篇报道与 OpenBSD 项目 <misc@openbsd.org> 邮件列表存档（2003-04 主题）一致；Theo de Raadt 本人在邮件列表中确认 DARPA 撤资；事件日期 2003-04-17 与 OpenBSD 3.3 CVS tag 时间 2003-04-04 仅相隔 13 天；与 OpenBSD 3.3 release（2003-05-01）时间线吻合。一致采纳。

### 新闻条目 2

- **新闻标题（中英）**：MicroBSD violates OpenBSD copyright（MicroBSD 侵犯 OpenBSD 版权）
- **新闻来源**：undeadly.org + 编辑署名 + 2003-02-21 + URL: <https://undeadly.org/cgi?action=article;sid=20030221011931> + 存档 URL: 待补
- **新闻摘要**：undeadly.org 报道 MicroBSD 项目（一个基于 OpenBSD 的衍生发行版）违反 OpenBSD 版权条款，未按 BSD 许可证要求保留原始版权声明。OpenBSD 社区对此事件进行公开批评，最终 MicroBSD 项目停止侵权并修正版权声明。该事件是 OpenBSD 严格执行 BSD 许可证条款的典型案例。
- **与本章主题的关联说明**：本章叙述 OpenBSD 3.x 时期（2001-2004），MicroBSD 版权争议是 OpenBSD 严格许可证执行路线的标志性事件，是本章 “OpenBSD 许可证纯洁化” 叙事的重要史料。
- **与官方史料的交叉验证结论**：undeadly.org 报道与 OpenBSD <misc@openbsd.org> 邮件列表 2003-02 主题一致；MicroBSD 项目最终修正版权声明的事实与 OpenBSD 严格 BSD 许可证执行路线一致。一致采纳。

## 里程碑事件类

### 新闻条目 1

- **新闻标题（中英）**：More Security: WxorX（更多安全：W^X 引入）
- **新闻来源**：undeadly.org + 编辑署名 + 2003-01-26 + URL: <https://undeadly.org/cgi?action=article;sid=20030126143902> + 存档 URL: 待补
- **新闻摘要**：undeadly.org 报道 OpenBSD -current 引入 W^X（Write XOR Execute）数据执行保护机制，标记内存页要么可写要么可执行但不能同时具备。W^X 是 OpenBSD 3.3（2003-05）首次正式引入的硬件辅助数据执行保护，对应 x86 NX bit、UltraSPARC 等 CPU 特性，是 OpenBSD 安全文化的里程碑式技术。
- **与本章主题的关联说明**：本章叙述 OpenBSD 3.x 时期（2001-2004），W^X 引入是 OpenBSD 3.3 的核心技术里程碑，是本章 “OpenBSD 安全技术创新” 叙事的关键节点。
- **与官方史料的交叉验证结论**：undeadly.org 报道与 OpenBSD 3.3 changelog（plus33.html）一致；W^X 引入时间 2003-01 与 OpenBSD 3.3 release 2003-05 时序吻合；与 OpenBSD 官方 security.html 关于 W^X 的描述一致。一致采纳。

### 新闻条目 2

- **新闻标题（中英）**：OpenBSD 3.0 Changelog（OpenBSD 3.0 官方变更日志）
- **新闻来源**：OpenBSD 项目官方 + plus30.html + 无署名作者（OpenBSD 项目维护）+ 持续更新 + URL: <https://www.openbsd.org/plus30.html> + 存档 URL: 待补
- **新闻摘要**：OpenBSD 3.0（2001-12-01 发布）官方变更日志列出 2.9 至 3.0 期间的全部重要变更，涵盖 pf 防火墙改进（block IP options、address translation、state searching 修复）、sendmail 8.12.1 升级、FM radio 驱动支持、RAIDFrame 改进、IPv6 包过滤等。OpenBSD 3.0 是 OpenBSD 引入 pf 防火墙（替代 ipfilter）的关键版本。
- **与本章主题的关联说明**：本章叙述 OpenBSD 3.x 时期（2001-2004），OpenBSD 3.0 引入 pf 防火墙是本章 “OpenBSD 网络安全栈演进” 叙事的核心节点。
- **与官方史料的交叉验证结论**：plus30.html 为 OpenBSD 官方 changelog，与 OpenBSD release 时间线一致；pf 引入时点 2001-12 与 OpenBSD 3.0 release 时间一致；与 Daniel Hartmeier（pf 作者）的 BSDCan 演讲内容一致。一致采纳。

### 新闻条目 3

- **新闻标题（中英）**：OpenBSD Gets Harder to Crack（OpenBSD 变得更难破解）
- **新闻来源**：undeadly.org + 编辑署名 + 2003-06-04 + URL: <https://undeadly.org/cgi?action=article;sid=20030604081356> + 存档 URL: 待补
- **新闻摘要**：undeadly.org 引用外部媒体对 OpenBSD 3.3 安全加固的报道，涵盖 W^X、ProPolice 栈保护等多层防御机制（ASLR 系 OpenBSD 3.4-3.8 渐次引入，非 3.3 特性）。该报道反映了 OpenBSD 3.3 时期外界媒体对 OpenBSD 安全路线的肯定性评价。
- **与本章主题的关联说明**：本章叙述 OpenBSD 3.x 时期（2001-2004），OpenBSD 3.3 是该时期安全技术集大成的版本，该报道是本章 “OpenBSD 安全文化外溢效应” 叙事的代表性媒体反响。
- **与官方史料的交叉验证结论**：undeadly.org 报道与 OpenBSD 3.3 changelog（plus33.html）一致；ProPolice 栈保护与 OpenBSD 3.3 -current 5 月引入 propolice kernel（2003-05-13 undeadly.org 报道）互证。一致采纳。

### 新闻条目 4

- **新闻标题（中英）**：Absolute OpenBSD Released...（Absolute OpenBSD 书籍出版）
- **新闻来源**：undeadly.org + 编辑署名 + 2003-06-12 + URL: <https://undeadly.org/cgi?action=article;sid=20030612000200> + 存档 URL: 待补
- **新闻摘要**：undeadly.org 报道 Michael W. Lucas 所著《Absolute OpenBSD》一书正式出版，该书是 OpenBSD 第一本英文权威教材，由 No Starch Press 出版。该书系统介绍 OpenBSD 安装、配置、管理、安全实践，成为 OpenBSD 文献史上的标志性著作，对 OpenBSD 在英语世界的传播起到重要作用。
- **与本章主题的关联说明**：本章叙述 OpenBSD 3.x 时期（2001-2004），2003 年《Absolute OpenBSD》出版是 OpenBSD 走出纯极客圈、进入系统化文献传播阶段的标志，是本章 “OpenBSD 文化传播” 叙事的重要节点。
- **与官方史料的交叉验证结论**：undeadly.org 报道与 OpenBSD 官方 books.html 一致；Michael W. Lucas 后续在 BSDNow 播客多次确认该书 2003 年出版；与 No Starch Press 官方书目一致。一致采纳。
