# 202.5 重要贡献者与边缘者：OpenBSD 7.x 时期的核心团队——Theo de Raadt（创始人）、Bob Beck（LibreSSL）、Markus Friedl（马库斯·弗里德尔）（OpenSSH）、Ingo Schwarze（英戈·施瓦茨）（mandoc）、Anton Lindqvist（网络栈）等

## 202.5.1 de Raadt 的持续主导

**要点**：2013-2026 年间 de Raadt 持续主导 OpenBSD——所有重大架构决策、release engineering、社区治理均由其参与；de Raadt 主导 pledge/unveil/LibreSSL/RETGUARD 等关键特性；其主导模式是 OpenBSD 一致性的根本保障

**史料**：de Raadt 在 misc@、tech@ 的发言（<https://marc.info/?l=openbsd-misc>，tech@ 列表见 <https://marc.info/?l=openbsd-tech>）；OpenBSD CVS commit log 中 de Raadt 的 commit（<https://cvsweb.openbsd.org/>）；OpenBSD hackathons 记录 ［A］

**史观**：总纲第 10 条——边缘者贡献：de Raadt 作为 OpenBSD 的创始人兼 BDFL，长期在 “安全至上” 路线不被主流市场理解中坚持——2020-2026 年间容器化与 AI 浪潮中 OpenBSD 仍坚持 pledge/unveil 与代码审计路线，是边缘者坚守自身哲学的典型

**辨析**：de Raadt 的具体工作量以 **openbsd.duckdb** openbsd-src 仓库 author_name ='deraadt' 的 commit 统计为准——其 commit 涵盖内核、用户态、文档等多个领域；de Raadt 的主导模式为 “重大决策亲自参与 + 日常维护放权给领域负责人”——pledge/unveil 由 de Raadt 亲自设计，mandoc 由 Schwarze 维护、OpenSSH 由 Friedl 维护

**文献**：OpenBSD CVS 仓库 [EB/OL]. <https://cvsweb.openbsd.org/>；de Raadt 邮件列表发言 [EB/OL]. <https://marc.info/?l=openbsd-misc>；OpenBSD hackathons 记录 ［A］

**要点**：Bob Beck 在 2014 年 Heartbleed 后主导 LibreSSL fork 与持续维护；Markus Friedl 持续维护 OpenSSH 协议实现与安全特性；两人的贡献让 OpenBSD 在 TLS 与 SSH 基础设施领域占据独特地位

**史料**：OpenBSD CVS commit log 中 Beck 的 LibreSSL commit、Friedl 的 OpenSSH commit（<https://cvsweb.openbsd.org/>）；misc@、tech@ 邮件列表中两人的发言；LibreSSL/OpenSSH 项目文档 ［A］

**史观**：总纲第 10 条——边缘者贡献：Beck 与 Friedl 分别守护 TLS 与 SSH 两大互联网基础协议的 OpenBSD 实现——LibreSSL 从 OpenSSL fork 后由 Beck 持续维护，OpenSSH 从 SSH Communications Security fork 后由 Friedl 持续维护，二者的维护工作是 “边缘者守护全球基础设施” 的典型
