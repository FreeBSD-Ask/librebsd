# 214.2.1 W^X 的设计与效应


**OpenBSD 3.x 安全特性引入时间线**：

| 版本 | 发布日期 | 安全特性 | 主导开发者 |
| --- | --- | --- | --- |
| 3.0 | 2001-12-01 | pf 防火墙 | Daniel Hartmeier（丹尼尔·哈特迈尔） |
| 3.1 | 2002-05-19 | W^X（Write XOR Execute） | Niels Provos（尼尔斯·普罗沃斯） |
| 3.3 | 2003-05-01 | stack protector（ProPolice/SSP） | Hiroaki Etoh |
| 3.4 | 2003-11-01 | 权限分离（privilege separation） | Niels Provos |
| 3.6 | 2004-11-01 | swap encryption | OpenBSD 团队 |

**要点**：OpenBSD 3.1（2002.5）引入 W^X（Write XOR Execute）内存保护机制，由 Niels Provos 主导；W^X 利用 i386 与 amd64 的 NX bit 等硬件特性，使栈与堆内存不可执行；W^X 是 OpenBSD 对缓冲区溢出攻击的根本性防御，后被 Linux/FreeBSD/NetBSD 效仿

**史料**：OpenBSD 3.1 Release Notes W^X 部分；Provos W^X 设计文档；CVS commit log ［A］

**史观**：边缘者贡献：OpenBSD 作为边缘项目率先引入 W^X，影响整个 Unix 安全实践

**辨析**：OpenBSD W^X 与 Linux/FreeBSD 类似机制（如 PaX、OpenBSD exec shield）的关系需考据——PaX 项目更早但未集成至 Linux 主线；i386 不支持 NX bit 的硬件（如 Pentium III）的兼容性需考据
