# 211.1.3 yplib/ypcat → ypldap 替换（NIS → LDAP）

**要点**：NIS（Network Information Service，原 Yellow Pages）是 Sun Microsystems 1980 年代设计的网络目录服务，OpenBSD 早期通过 **yplib(3)**、**ypcat(1)**、**ypmatch(1)** 等工具支持；NIS 因安全设计缺陷（无认证、明文传输）逐步被 LDAP 取代；openbsd.duckdb 显示 ypldap 首次 commit 为 2008-06-26 pyr commit f624240892b9 "ypldap -- Intended to be a drop-in replacement for ypserv, gluing in a LDAP directory a..."（4.4 周期，2008.11 release），2008-10-14 deraadt commit 33b8cba20fd2 “enable ypldap. serious development needs it to be enabled.” 在 4.5 周期正式启用——原大纲称 “5.x 时期成熟” 系误记，ypldap 在 4.4-4.5 周期（2008-2009）已引入并启用；ypldap 作为 NIS 与 LDAP 的桥接，让 NIS 客户端可查询 LDAP 目录

**史料**：openbsd.duckdb openbsd-src 仓库 commit f624240892b9（2008-06-26 pyr “ypldap -- Intended to be a drop-in replacement for ypserv”）、commit 33b8cba20fd2（2008-10-14 deraadt “enable ypldap”）；Sun NIS 文档；OpenBSD **ypldap(8)** 手册页（<https://man.openbsd.org/ypldap.8>） ［A］

**史观**：专题——网络目录服务的 NIS → LDAP 迁移（不设总纲条号）：NIS 作为 1980 年代的网络目录信息技术被 LDAP 聚合替代——ypldap 的引入是 OpenBSD 对网络目录服务从 NIS 向 LDAP 迁移趋势的响应，但 OpenBSD 选择桥接（ypldap）而非直接取代（删除 ypserv）的渐进路径

**辨析**：ypldap 在 OpenBSD 中的引入版本以 openbsd.duckdb commit log 为准——2008-06-26 pyr@ 首次引入（4.4 周期），2008-10-14 deraadt@ 启用（4.5 周期），原大纲称 “4.5 或更早” 与 “5.x 时期成熟” 均不准确；ypldap 与传统 ypserv 的关系以 **ypldap(8)** 手册页为准——ypldap 模拟 ypserv 协议让 NIS 客户端透明查询 LDAP，二者并存而非替代；NIS 在 OpenBSD 中的实际部署规模无权威统计 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］
