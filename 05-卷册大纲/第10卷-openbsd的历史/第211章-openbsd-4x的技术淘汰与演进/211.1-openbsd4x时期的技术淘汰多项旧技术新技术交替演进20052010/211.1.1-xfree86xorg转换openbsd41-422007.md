# 211.1.1 XFree86 → X.org 转换（OpenBSD 4.1-4.2，2007）


**OpenBSD 4.x 时期技术淘汰时间线**：

| 旧技术 | 新技术 | 关键 commit | 引入版本 | 淘汰动因 |
| --- | --- | --- | --- | --- |
| XFree86 4.4.0 | X.org + xenocara | `8462c87f5bf9`（2005-05-04 jaredy）、`fcb4a8a3b89b`（2007-03-26 matthieu） | 4.1（2007.5） | XFree86 4.4.0 许可证加入广告条款 |
| gcc 4.x（默认） | pcc 探索失败 → clang/LLVM | 邮件列表讨论（2007-2008） | 5.7（2015.5）切换至 clang | gcc GPLv3 许可证争议与代码质量 |
| yplib/ypcat（NIS） | ypldap（LDAP 桥接） | `f624240892b9`（2008-06-26 pyr）、`33b8cba20fd2`（2008-10-14 deraadt） | 4.4-4.5（2008-2009） | NIS 安全设计缺陷 |
| svnd（Blowfish） | softraid（AES-XTS） | `f18dcc9c26b1`（2007-11-27 tedu）、`79cdc9424edb`（2008-06-14 hshoexer） | 4.2-4.4（2007-2008） | AES-XTS 取代 Blowfish |
| Kerberos IV（krb4） | Kerberos V（Heimdal 0.7.2） | `ed832e58feb0`（2005-10-05 biorn “Remove kerberos4 services”）、`10e361c8b7f1`（2005-12-16 todd “rm kerberosIV remnant”）、`ad528311addf`（2006-04-14 biorn “Import of heimdal-0.7.2”）、`2bb5d18aad7b`（2006-04-14 biorn “Merge of heimdal 0.7.2”） | 3.8-4.0（2005-2006） | Kerberos IV 协议过时，Heimdal 0.7.2 提供 Kerberos V 完整实现 |

**注**：原 jianyi.md 7s 条目建议补“IPFilter→pf 完成”一行，但经 openbsd.duckdb openbsd-src 仓库查询，2005-2010 年间 `sys/netinet/ipf*`、`sbin/ipf*` 等文件路径下无任何 commit（`ipf` 关键字搜索结果均为 `ipforward_rt`、`ip_mib`、`per-ipf mbuf cluster` 等误匹配），证实 IPFilter 代码在 4.x 时期之前（即 3.x 时期 pf fork 后）已从 openbsd-src 仓库移除，“IPFilter→pf 完成”不属于 4.x 时期技术淘汰项，故本表不列入。原建议中“hebibmd”系“heimdal”拼写之误，OpenBSD 4.x 时期的 Kerberos 演进为 Kerberos IV → Kerberos V（Heimdal 实现），heimdal 0.7.2 于 4.0 周期（2006.11 release）导入。Release Notes 详见 **<https://www.openbsd.org/40.html>**。

**要点**：XFree86 项目因 2004 年 1 月 XFree86 4.4.0 许可证变更（加入类似 “广告条款” 的限制性条款）引发社区分裂，X.Org 基金会 fork 形成 X.org 服务器；openbsd.duckdb 显示 OpenBSD 在 4.x 时期完成从 XFree86 到 X.org 的转换——2005-05-04 jaredy commit 8462c87f5bf9 “change XFree86 -> X.Org” 标识手册页转换，2007-03-26 matthieu commit fcb4a8a3b89b "Switch X build instructions to xenocara. ok deraadt@ jmc@ mbalmer@" 标识 xenocara 构建框架首次引入（4.1 周期）；xenocara 是 OpenBSD 对 X.org 的定制构建框架，整合 X server、驱动、字体等组件；原大纲称 “为后续 xenocara 重组（6.0）奠定基础” 系误记——xenocara 于 4.1（2007.5）引入，非 6.0（2015.10）

**史料**：openbsd.duckdb openbsd-src 仓库 commit 8462c87f5bf9（2005-05-04 jaredy “change XFree86 -> X.Org”）、commit fcb4a8a3b89b（2007-03-26 matthieu “Switch X build instructions to xenocara”）；XFree86 4.4.0 LICENSE 文件变更；X.Org 基金会成立公告；OpenBSD 4.1 Release Notes X11 部分 ［A］

**史观**：总纲第 13 条——法律与道德是利益分配：XFree86 4.4.0 许可证变更（加入广告条款）催生 X.org fork，OpenBSD 通过 xenocara 聚合 X.org 完成替代——这一路径是 OpenBSD 许可证纯洁性哲学的实践，OpenBSD 拒绝接受含广告条款的 XFree86 4.4.0，选择 fork 后的 X.org

**辨析**：OpenBSD 从 XFree86 切换到 X.org 的具体版本以 commit log 与 Release Notes 交叉确认——2005-05-04 jaredy commit 标识手册页转换，2007-03-26 matthieu commit 标识 xenocara 构建框架引入，二者间隔约 2 年，反映 X.org 切换是渐进过程；XFree86 4.4.0 许可证变更的具体条款以原始 LICENSE 文件为准——新增条款要求所有文档与广告材料中提及 XFree86 项目
