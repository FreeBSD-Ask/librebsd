# 211.5.4 要点OpenBSD4x时期的本地漏洞与网络栈漏洞分散于pf规则拷贝X11转发Ap

**要点**：OpenBSD 4.x 时期的本地漏洞与网络栈漏洞分散于 pf 规则拷贝、X11 转发、Apache 跨站脚本等组件——CVE-2008-1483 为 X11 转发连接劫持漏洞，markus 于 2008-04-02 通过回退 commit 1.183 修复（commit `39ff0b053b9574ba427fa40f29afcc8ceea31f3d`），技术机制类型为信息泄露，无 CVSS v3 评分；CVE-2006-5752 为 Apache **mod_status** 跨站脚本，martynas 于 2007-08-08 修复（commit `12bf86315208ef652ace74cdad4aa9a19432fe10`）；CVE-2007-3304 为 Apache 拒绝服务，martynas 于 2007-08-09 修复（commit `451b3c8ea42aa461fe38ce7c4e0ee3543af373d1`）；CVE-2007-5000 与 CVE-2007-6388 为 Apache **mod_status** 跨站脚本，martynas 于 2008-01-12 修复（commit `13c83fe772f120c766e2ec5ecb0cd47972b82798`）；CVE-2011-2748 与 CVE-2011-2749 为选项处理栈存储清零缺陷，krw 于 2011-11-12 修复（commit `a720dd5f942df2aad6cede205026b44e8662b680`）；此外 claudio 于 2010-12-15 修复 pf 规则从用户态拷贝至内核时的指针验证缺陷（commit `04523091a16553628956e63cc3d1b31f792bdfe6`，无 CVE），rpointel 于 2011-10-11 更新 Digest 模块至 1.17 含安全修复（commit `7469d825cf6e71597105f4ae22285dfac06ebcb6`，无 CVE）；pf 规则拷贝漏洞的修复体现了 “发现漏洞—快速修复—加固重构” 循环——claudio 不仅修补具体缺陷，还审查了所有从用户态拷贝至内核的结构体指针验证逻辑。
