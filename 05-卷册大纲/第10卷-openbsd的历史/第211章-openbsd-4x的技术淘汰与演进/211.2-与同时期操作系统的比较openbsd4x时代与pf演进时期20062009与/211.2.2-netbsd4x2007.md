# 211.2.2 NetBSD 4.x（2007）

**要点**：NetBSD 在 OpenBSD 4.x 同期为 4.0/4.0.x（2007.12 release），以 NPF（后引入）前的 ipf/PF 支持与多平台见长；NetBSD 4.x 也移植 pf，但 OpenBSD 4.x 是 pf 的创新与维护中心

**史料**：NetBSD 4.x Release Notes（<https://www.netbsd.org/releases/formal-4.0.html>）；NetBSD 4.x 防火墙支持文档；OpenBSD 4.x pf ［B］

**史观**：总纲第 13 条——法律与道德是利益分配：NetBSD 与 OpenBSD 同期共享 pf 代码，是 BSD 家族内代码自由流动的体现——NetBSD 选择移植 pf 与 ipf 并存以适配其多平台导向，OpenBSD 选择 pf 独占以适配其安全优先导向

**辨析**：NetBSD 4.x 的防火墙生态以 NetBSD 文档为准——NetBSD 4.x 支持 ipf（IPFilter，Darren Reed（达伦·里德） 维护）与 pf，二者并存；NPF（NetBSD Packet Filter）由 Mindaugas Rasiukevicius 在 NetBSD 6.0（2012）引入，不在 4.x 时期

**文献**：NetBSD 4.x Release Notes [EB/OL]. <https://www.netbsd.org/releases/formal-4.0.html>；NetBSD pf 指南；OpenBSD pf 指南 [EB/OL]. <https://www.openbsd.org/faq/pf/> ［B］
