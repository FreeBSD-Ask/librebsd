### 新闻条目 1

- **新闻标题（中英）**：Bitrig 1.0 发布——OpenBSD fork 走向现代化（Welcome to Bitrig 1.0!）
- **新闻来源**：bitrig.org 项目官方首页 + 2014-11 + URL: <https://www.bitrig.org/>
- **新闻摘要**：bitrig.org 官方首页宣布 Bitrig 1.0 发布。Bitrig 是 free、fast、secure 的 Unix-like 开源操作系统，fork 自 OpenBSD，目标是比 OpenBSD 更 “现代化”（modern）。Bitrig 1.0 提供当前硬件平台支持，源代码以宽松许可证（permissive license）发布于 GitHub（github.com/bitrig/bitrig）。项目通过开发者自筹资金维持，接受法定货币与 Bitcoin 捐赠（1M8eE7vFxcjCgqFvxKnSvRoBvx3RwJVWiR）。Bitrig 的 roadmap、FAQ、UPDATING 等文档均托管于 GitHub wiki。Bitrig 后续 discontinued，但其作为 OpenBSD 生态中少数尝试 fork 的项目具有史学意义。
- **与本章主题的关联说明**：本章叙述 OpenBSD 衍生发行版（1996-2026），Bitrig 是 OpenBSD 生态中 2013-2014 年间最具影响力的 fork 尝试，本章 “OpenBSD fork 实验” 叙事的核心节点。
- **与官方史料的交叉验证结论**：bitrig.org 官方首页与 GitHub 仓库（github.com/bitrig/bitrig）一致；与维基百科 “Bitrig” 条目（仅作线索，不作采信来源）描述的 “OpenBSD fork，discontinued” 状态一致；与 undeadly.org 2014-2015 档案中 OpenBSD 社区对 Bitrig 的讨论形成时序链。一致采纳。
