# 205.1 OpenSSH 的诞生（1999.9-10）


- 要点：deraadt 于 1999-09-26 commit 84959968510b 将 ssh 代码初始导入 OpenBSD 源码树，fork 路径为 SSH 1.2.12（Tatu Ylönen 最后一个自由许可版本）→ OSSH（Björn Grönvall 维护的 fork）→ OpenSSH（OpenBSD 团队 fork OSSH）；deraadt 于 1999-10-01 commit bf74e864c129 标记“OpenSSH-1.0”，markus 于 1999-10-14 commit 33fe18e4e13b 修复 ssh-agent 竞争条件，provos 于 1999-10-17 commit 086f047a5407 添加 OpenSSH 文档；fork 动机是 SSH Communications Security 1999 年将 SSH 1.2.13+ 转为商业许可证（1.2.12 为最后一个 BSD 许可版本），OpenBSD 需要一个自由许可的 SSH 实现；OpenSSH 1.0 于 1999-12-01 随 OpenBSD 2.6 发布；统计结论印证——openbsd.db openbsd-src 仓库总 commit 数 245,904（统计结论 C-05），OpenSSH 相关 commit 占其中一部分，反映 OpenSSH 自 1999-09-26 fork 起在 OpenBSD 工程节奏中的持续演进
- 史料：openbsd.db openbsd-src 仓库 commit 84959968510b（1999-09-26 deraadt 初始导入）、commit bf74e864c129（1999-10-01 deraadt“OpenSSH-1.0”）、commit 33fe18e4e13b（1999-10-14 markus ssh-agent 竞争条件修复）、commit 086f047a5407（1999-10-17 provos 文档添加）；OpenSSH 项目历史页面（<https://www.openssh.com/history.html，记载> SSH 1.2.12 → OSSH → OpenSSH fork 路径）；OpenBSD 2.6 Release Notes（<https://www.openbsd.org/26.html）>；SSH Communications Security 1999 许可证变更声明
- 史观：总纲第 1 条——偶然性改写历史：Tatu Ylönen 1999 年将 SSH 1.2.13+ 转为商业许可证的决策偶然催生 OpenSSH——若无此许可证变更，OpenBSD 无需 fork，OpenSSH 项目可能永不存在，全球 SSH 生态将沿另一路径演进；总纲第 12 条——法律结构：SSH 1.2.12 的 BSD 许可证与 1.2.13+ 的商业许可证之间的法律结构断裂是 fork 的直接原因——OpenBSD 团队选择了最后一个自由许可版本 1.2.12 经 OSSH 作为 fork 起点，这一选择完全由许可证结构驱动；统计结论印证——C-05 openbsd-src 总 commit 数 245,904 以工程节奏的统计刻画印证“分离聚合是永恒规律”（总纲第 4 条），OpenSSH fork 是分离事件，后续 OpenSSH 在 openbsd-src 仓库中的持续 commit 反映聚合后的工程演进
- 辨析：fork 日期在不同叙事中存在差异——部分来源称“1999 年 9 月（随 OpenBSD 2.6 于 1999-12-01 正式发布）”（以 OpenSSH-1.0 commit 日期 1999-10-01 为准），部分称“1999 年 9 月”（以初始导入 commit 84959968510b 日期 1999-09-26 为准）；经 openbsd.db 核查，初始导入为 1999-09-26（deraadt），OpenSSH-1.0 标记为 1999-10-01（deraadt），两个日期均为 fork 过程的组成部分；fork 路径经 OpenSSH 官方历史页面核实为 SSH 1.2.12 → OSSH（Björn Grönvall）→ OpenSSH（OpenBSD），非直接 fork 自 SSH 1.2.12——OSSH 是 Grönvall 维护的 SSH 1.2.12 自由许可 fork，OpenBSD 在 OSSH 基础上创建 OpenSSH；openbsd.db 查询 L2.3.1.openssh 在中观模式挖掘报告中不存在（报告仅含 L2.3.1.ZFS、L2.3.1.Capsicum、L2.3.1.bhyve、L2.3.1.Clang、L2.3.1.ARM64、L2.3.1.RISC-V 等 FreeBSD 特性查询，未覆盖 OpenBSD OpenSSH 子系统），OpenSSH 相关子系统级 commit 数据须以 openbsd.db 直接查询 file_path 维度（如 usr.bin/ssh/、lib/libcrypto/）补全；**统计局限性标注**——C-05 openbsd-src 总 commit 数 245,904 包含 OpenSSH 与非 OpenSSH 相关 commit，OpenSSH 在其中占比须以 file_path 含“ssh”或 message_subject 含“ssh/openssh”为筛选条件通过 openbsd.db commit_files 表 JOIN 方可确认，不得仅凭 commit 总量推断 OpenSSH 在 OpenBSD 工程中的占比；0 信任原则适用：统计显著 ≠ 实际显著，commit 总量仅反映工程活跃度，不等于 OpenSSH 的代码质量或安全等级
