# 196.4 **与同时期操作系统的比较**：1996-2004 年同期 NetBSD 1.2-1.6（可移植性至上）、FreeBSD 2.x-4.x（x86 性能与稳定性）、Linux 2.0-2.6（内核成熟与商业爆发）、Solaris 2.x-9（企业 Unix）——OpenBSD 以“安全至上与代码审计”为差异化定位

## 195.4.1 NetBSD 可移植性与 OpenBSD 安全的分野

**要点**：NetBSD 1996-2004 年间专注跨平台移植（支持 30+ 平台），OpenBSD 专注安全审计；两项目从 NetBSD 1.1 fork 出发，至 2004 年在工程哲学上完全分化；NetBSD 与 OpenBSD 的分野反映 BSD 哲学的两条路径——“广度”与“深度”

**史料**：NetBSD 1.2-1.6 Release Notes；OpenBSD 1.0-3.6 Release Notes；两项目 CVS 源码对照 ［A］

**史观**：总纲第 7 条——技术选择即政治选择：NetBSD 选择“可移植性”，OpenBSD 选择“安全”——选择即政治

**辨析**：两项目的“广度”与“深度”对比缺乏权威评估——需对照实际功能对比核验；两项目代码共享比例在 1996-2004 年间的下降曲线需考据

**文献**：NetBSD/OpenBSD Release Notes；CVS 源码对照 ［A］

## 195.4.2 FreeBSD x86 性能的对照

**要点**：FreeBSD 1996-2004 年间专注 x86 性能与稳定性，引入 SMPng（5.x 时代）、softdep、ULE 调度器雏形；FreeBSD x86 性能领先于 OpenBSD，但 OpenBSD 安全特性领先；FreeBSD 与 OpenBSD 在用户群上分化——FreeBSD 服务于 ISP/CDN，OpenBSD 服务于安全敏感场景
