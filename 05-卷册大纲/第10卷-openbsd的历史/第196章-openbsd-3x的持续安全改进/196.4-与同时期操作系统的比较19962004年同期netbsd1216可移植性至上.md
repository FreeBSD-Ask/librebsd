# 196.4 与同时期操作系统的比较：1996-2004 年同期 NetBSD 1.2-1.6（可移植性至上）、FreeBSD 2.x-4.x（x86 性能与稳定性）、Linux 2.0-2.6（内核成熟与商业爆发）、Solaris 2.x-9（企业 Unix）——OpenBSD 以“安全至上与代码审计”为差异化定位

## 196.4.1 NetBSD 可移植性与 OpenBSD 安全的分野

**要点**：NetBSD 1996-2004 年间专注跨平台移植（支持 30+ 平台），OpenBSD 专注安全审计；两项目从 NetBSD 1.1 fork 出发，至 2004 年在工程哲学上完全分化；NetBSD 与 OpenBSD 的分野反映 BSD 哲学的两条路径——“广度”与“深度”

**史料**：NetBSD 1.2-1.6 Release Notes；OpenBSD 1.0-3.6 Release Notes；两项目 CVS 源码对照 ［A］

**史观**：总纲第 21 条——革命与改革是历史方法论的分歧：NetBSD 选择“可移植性”、OpenBSD 选择“安全”，是同一 BSD 传统内部两条改进路径的方法论分歧——一方以渐进移植扩展自由软件的疆域，一方以激进审计重铸既有代码；两种路径无对错之分，却塑造了此后十年 BSD 阵营的分化格局。

**辨析**：两项目的“广度”与“深度”对比缺乏权威评估——需对照实际功能对比核验；两项目代码共享比例在 1996-2004 年间的下降曲线需考据

**文献**：NetBSD/OpenBSD Release Notes；CVS 源码对照 ［A］

## 196.4.2 FreeBSD x86 性能的对照

**要点**：FreeBSD 1996-2004 年间专注 x86 性能与稳定性，引入 SMPng（5.x 时代）、softdep、ULE 调度器雏形；FreeBSD x86 性能领先于 OpenBSD，但 OpenBSD 安全特性领先；FreeBSD 与 OpenBSD 在用户群上分化——FreeBSD 服务于 ISP/CDN，OpenBSD 服务于安全敏感场景

**史料**：FreeBSD 2.x-4.x Release Notes；OpenBSD Release Notes；BSD 基准测试对比〔L3 官方文档与公告/L5 二手研究〕

**史观**：总纲第 8 条——本体论上各方平等：FreeBSD 以 x86 性能见长、OpenBSD 以安全审计立身，两种工程取向在存在论上并无高下——性能与安全是不同部署场景下的不同“善”，比较框架本身即预设了评价者的立场。

**辨析**：FreeBSD 与 OpenBSD 的“性能差距”在不同硬件与负载上差异较大——需对照基准测试核验；两项目的用户群分化缺乏权威统计

**文献**：FreeBSD/OpenBSD Release Notes；BSD 基准测试对比

## 196.4.3 Linux 商业爆发对 OpenBSD 的挤压

**要点**：Linux 1996-2004 年间凭借 Red Hat（1995）、SuSE、Caldera 等商业发行版与 1999 年 IPO 热潮爆发；Linux 商业爆发挤压 BSD 整体市场，OpenBSD 因安全定位受冲击相对较小但用户基数仍小；Linux 在 2.4（2001）与 2.6（2003）内核成熟后进一步主导服务器市场

**史料**：Linux 商业发行版历史；Red Hat/SuSE IPO 资料；Linux 2.4/2.6 changelog〔L3 官方文档与公告/L5 二手研究〕

**史观**：总纲第 3 条——不存在进步，只有权力再分配：Linux 的商业爆发并非单纯的“技术进步”胜出，而是服务器市场权力从专有 Unix 与 BSD 阵营向 Linux 商业生态的再分配——Red Hat 于 **1999 年 8 月 11 日**在纳斯达克上市（发行价 14 美元，首日收于 52.06 美元，验证方法：Nutanica “Red Hat initial public offering” 词条与多源财经档案互证），资本市场为这一再分配提供了注脚；OpenBSD 因定位边缘而少受波及，恰说明再分配中亦有未被触及的角落。

**辨析**：Linux 商业爆发对 OpenBSD 的具体冲击规模缺乏权威统计——需对照市场份额数据核验；OpenBSD 在安全敏感场景（如防火墙、VPN）的部署是否被 Linux 商业发行版侵蚀需考据

**文献**：Linux 商业发行版历史；市场份额报告

## 196.4.4 各项目发布数据与市场份额考据

**要点**：1996-2004 年间市场份额数据——Linux 服务器市场占有率从约 5% 升至约 20%，FreeBSD 约 2%-3%，NetBSD 不足 0.5%，OpenBSD 不足 0.5%；Solaris 从约 30% 降至约 15%；BSD 整体被 Linux 挤压但 OpenBSD 在安全场景保持存在

**史料**：Netcraft Web Server Survey 1996-2004；IDC 服务器操作系统市场报告〔L5 二手研究〕

**史观**：总纲第 7 条——理论必须自反：本节引用的每一份市场份额统计（Netcraft 的 Web 服务器签名、IDC 的出货口径）都是特定测量方法的建构物——理论必须自反地承认：说“OpenBSD 不足 0.5%”之前，须先审视测量工具能否看见 OpenBSD 的典型部署（防火墙、VPN 网关等不经 Web 签名暴露的形态）。

**辨析**：OpenBSD 在防火墙场景的部署（如 pfSense 早期基于 m0n0wall）未被服务器市场报告统计；市场份额数据在不同调查中差异较大

**文献**：Netcraft Web Server Survey 1996-2004；IDC 服务器操作系统市场报告
