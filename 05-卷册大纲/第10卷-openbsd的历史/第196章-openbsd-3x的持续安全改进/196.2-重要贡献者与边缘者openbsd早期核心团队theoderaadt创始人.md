# 196.2 重要贡献者与边缘者：OpenBSD 早期核心团队——Theo de Raadt（创始人）、Niels Provos（W^X 与 privilege separation）、Angelos Keromytis（IPsec 与 cryptography）、Daniel Hartmeier（pf 设计）、Bob Beck（OpenSSH）等

## 195.2.1 de Raadt 的创始贡献

**要点**：Theo de Raadt 作为 OpenBSD 创始人主导项目从 1996 年 fork 至 2004 年间的所有关键决策；贡献包括代码审计文化建立、加密集成、OpenSSH fork、pf fork、W^X 引入等；de Raadt 的"benign dictator"治理风格塑造 OpenBSD 工程哲学

**史料**：de Raadt 个人网站；OpenBSD CVS commit log 中 theo 的提交；OpenBSD 邮件列表帖 ［A］

**史观**：总纲第 1 条——偶然性改写历史：de Raadt 作为创始人通过具体决定塑造 OpenBSD 走向

**辨析**：de Raadt 的具体贡献在 commit log 中可能被高估——部分大型 commit 由多人协作，但 theo 署名；de Raadt 的"benign dictator"风格在不同参与者叙事中存在差异

**文献**：de Raadt 个人网站；OpenBSD CVS 仓库；OpenBSD 邮件列表 ［A］

## 195.2.2 Provos/Keromytis 的安全贡献

**要点**：Niels Provos 贡献 W^X、privilege separation、systrace 等安全特性；Angelos Keromytis 贡献 IPsec、加密框架（**crypto(9)**）等；两人作为希腊/德国裔边缘者贡献 OpenBSD 安全核心

**史料**：OpenBSD CVS commit log 中 provos 与 angelos 的提交；Provos 学术论文；Keromytis IPsec 文档 ［A］

**史观**：总纲第 10 条——边缘者贡献：Provos 与 Keromytis 作为边缘者贡献 OpenBSD 安全核心

**辨析**：Provos 与 Keromytis 的具体贡献划分需对照 CVS commit log 核验；两人后来离开 OpenBSD 核心团队的具体时间需考据

**文献**：OpenBSD CVS 仓库；Provos/Keromytis 学术论文 ［B］

## 195.2.3 Hartmeier/Beck 的 pf 与 OpenSSH 贡献

**要点**：Daniel Hartmeier 设计并实现 pf，是 pf 项目核心；Bob Beck 主导 OpenSSH fork 与早期开发；两人作为独立贡献者推动 OpenBSD 在防火墙与 SSH 领域的全球影响

**史料**：OpenBSD CVS commit log 中 dhartmei 与 beck 的提交；Hartmeier 个人 pf 历史文章；Beck OpenSSH 演讲 ［A］

**史观**：总纲第 10 条——边缘者贡献：Hartmeier 与 Beck 作为边缘者贡献 pf 与 OpenSSH

**辨析**：Hartmeier 与 Beck 的具体贡献划分需对照 CVS commit log 核验；Beck 在 OpenSSH 项目的具体角色需考据

## 195.2.4 贡献者 commit 记录与邮件考据

**要点**：1996-2004 年间 OpenBSD 主要贡献者的 commit 记录与邮件列表讨论是研究社区动态的核心史料；除 de Raadt、Provos、Keromytis、Hartmeier、Beck 外，还包括 Todd C. Miller（托德·C·米勒）、Deraadt、Markus Friedl（马库斯·弗里德尔）、Jason Ishmael 等；考据需对照 CVS commit log 与邮件列表署名

**史料**：OpenBSD CVS commit log 完整记录；misc@/tech@openbsd.org 邮件列表存档；BSDCan/AsiaBSDCon 演讲视频 ［A］

**史观**：总纲第 25 条——0 信任原则：贡献者 commit 记录需考据——部分 commit 在迁移至 Git 后丢失元数据

**辨析**：主要贡献者的具体 commit 数量在不同统计工具中差异较大；邮件列表署名与 CVS author 字段可能不完全对应【代码级证据·openbsd.db openbsd-src 仓库】author_name 维度 commit 计数（全仓库，非 3.x 时期限定）：provos（Niels Provos）834、angelos（Angelos Keromytis）1659、dhartmei（Daniel Hartmeier）591、beck（Bob Beck）1569、cedric 210、daniel 107；Hartmeier 的全仓库计数 591 与 7.1.4 节 pf 相关 commit 计数 747 的差异源于统计口径不同——7.1.4 节为 commit_files 表 file_path 命中 pf 路径的聚合，本处为 commits 表 author_name 全仓库聚合；Provos 学术主页 <https://www.citi.umich.edu/u/provos/>、Keromytis 哥伦比亚大学主页 <https://www.cs.columbia.edu/~angelos/>、Hartmeier 个人站点 <https://www.benzedrine.ch/>、Beck OpenBSD events 页面 <https://www.openbsd.org/events.html> 为各自贡献史料补遗 URL
