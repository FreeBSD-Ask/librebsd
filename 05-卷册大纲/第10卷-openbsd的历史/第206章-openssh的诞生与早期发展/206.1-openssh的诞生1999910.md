# 206.1 OpenSSH 的诞生（1999.9-10）

**要点**：deraadt 于 1999-09-26 commit 84959968510b 将 ssh 代码初始导入 OpenBSD 源码树，fork 路径为 SSH 1.2.12（Tatu Ylönen 最后一个自由许可版本）→ OSSH（Björn Grönvall 维护的 fork）→ OpenSSH（OpenBSD 团队 fork OSSH）；deraadt 于 1999-10-01 commit bf74e864c129 标记“OpenSSH-1.0”，markus 于 1999-10-14 commit 33fe18e4e13b 修复 ssh-agent 竞争条件，provos 于 1999-10-17 commit 086f047a5407 添加 OpenSSH 文档；fork 动机是 SSH Communications Security 1999 年将 SSH 1.2.13+ 转为商业许可证（1.2.12 为最后一个 BSD 许可版本），OpenBSD 需要一个自由许可的 SSH 实现；OpenSSH 1.0 于 1999-12-01 随 OpenBSD 2.6 发布；统计结论印证——openbsd.duckdb openbsd-src 仓库总 commit 数 245,904（统计结论 C-05，快照生成时点未标注；2026-09-12 实测 openbsd-src 已为 246,535 条，差 631 系约一周量级漂移），OpenSSH 相关 commit 占其中一部分，反映 OpenSSH 自 1999-09-26 fork 起在 OpenBSD 工程节奏中的持续演进

**史料**：openbsd.duckdb openbsd-src 仓库 commit 84959968510b（1999-09-26 deraadt 初始导入）、commit bf74e864c129（1999-10-01 deraadt“OpenSSH-1.0”）、commit 33fe18e4e13b（1999-10-14 markus ssh-agent 竞争条件修复）、commit 086f047a5407（1999-10-17 provos 文档添加）；OpenSSH 项目历史页面（<https://www.openssh.com/history.html>，记载 SSH 1.2.12 → OSSH → OpenSSH fork 路径）；OpenBSD 2.6 Release Notes（<https://www.openbsd.org/26.html>）；SSH Communications Security 1999 许可证变更声明〔L1 代码/构建产物/L3 官方文档与公告〕

**史观**：总纲第 5 条——没有必然性，只有偶然性：Tatu Ylönen 1999 年将 SSH 1.2.13+ 转为商业许可证的决策偶然催生 OpenSSH——若无此许可证变更，OpenBSD 无需 fork，OpenSSH 项目可能永不存在，全球 SSH 生态将沿另一路径演进；总纲第 13 条——法律与道德是利益分配：SSH 1.2.12 的 BSD 许可证与 1.2.13+ 的商业许可证之间的法律结构断裂是 fork 的直接原因——OpenBSD 团队选择了最后一个自由许可版本 1.2.12 经 OSSH 作为 fork 起点，这一选择完全由许可证结构驱动；统计结论印证——C-05 openbsd-src 总 commit 数 245,904 以工程节奏的统计刻画印证“分离聚合是永恒规律”（总纲第 4 条），OpenSSH fork 是分离事件，后续 OpenSSH 在 openbsd-src 仓库中的持续 commit 反映聚合后的工程演进

**辨析**：fork 日期在不同叙事中存在差异——部分来源称“1999 年 9 月（随 OpenBSD 2.6 于 1999-12-01 正式发布）”（以 OpenSSH-1.0 commit 日期 1999-10-01 为准），部分称“1999 年 9 月”（以初始导入 commit 84959968510b 日期 1999-09-26 为准）；经 openbsd.duckdb 核查，初始导入为 1999-09-26（deraadt），OpenSSH-1.0 标记为 1999-10-01（deraadt），两个日期均为 fork 过程的组成部分；fork 路径经 OpenSSH 官方历史页面核实为 SSH 1.2.12 → OSSH（Björn Grönvall）→ OpenSSH（OpenBSD），非直接 fork 自 SSH 1.2.12——OSSH 是 Grönvall 维护的 SSH 1.2.12 自由许可 fork，OpenBSD 在 OSSH 基础上创建 OpenSSH；openbsd.duckdb 查询 L2.3.1.openssh 在中观模式挖掘报告中不存在（报告仅含 L2.3.1.ZFS、L2.3.1.Capsicum、L2.3.1.bhyve、L2.3.1.Clang、L2.3.1.ARM64、L2.3.1.RISC-V 等 FreeBSD 特性查询，未覆盖 OpenBSD OpenSSH 子系统），OpenSSH 相关子系统级 commit 数据须以 openbsd.duckdb 直接查询 file_path 维度（如 usr.bin/ssh/、lib/libcrypto/）补全；**统计局限性标注**——C-05 openbsd-src 总 commit 数 245,904（统计快照，生成时点未标注；2026-09-12 实测 openbsd-src 已为 246,535 条，差 631 系约一周量级漂移）包含 OpenSSH 与非 OpenSSH 相关 commit，OpenSSH 在其中占比须以 file_path 含“ssh”或 message_subject 含“ssh/openssh”为筛选条件通过 openbsd.duckdb commit_files 表 JOIN 方可确认，不得仅凭 commit 总量推断 OpenSSH 在 OpenBSD 工程中的占比；0 信任原则适用：统计显著 ≠ 实际显著，commit 总量仅反映工程活跃度，不等于 OpenSSH 的代码质量或安全等级经 [邮件列表库] 验证通过（来源：openbsd-announce 1999-12-01 Louis Bertrand “OpenBSD 2.6 Press Release” 确认 OpenSSH 随 OpenBSD 2.6 于 1999-12-01 发布；openbsd-misc 1999-10-12 Markus Friedl “ssh” 确认 Friedl 主导 OpenSSH 开发；openbsd-www 1999-11-18 Richard Wong “OpenSSH Media Coverage page” 确认 Slashdot 报道；openbsd-announce 1999-12-03 Theo de Raadt “2.6 sslUSA security problem” 确认 RSA 专利问题）。

**要点**：

- OpenCon 是全球唯一专门面向 OpenBSD 的会议，2007 年在威尼斯机场附近酒店举行（与上年同址）；本届首次增设周五教程日，设 packet filter、OpenBSD ports 与 OpenBSD 可用 VPN 技术三场教程，讲者多为 OpenBSD 开发者；周六周日为多主题演讲马拉松。（BSDTalk EP133，[52.34-104.13]，L1）
- 会议日程与发布节奏耦合：OpenBSD 4.2 定于 2007 年 11 月 1 日发布，OpenCon 于 12 月首个周末举行，届时与会者多已用上 4.2，现场可购 CD-ROM，讲者可将 4.2 新特性纳入演讲；发布切分在会前数月已完成，开发已转入 -current，因而演讲更多面向更新的事物。（BSDTalk EP133，[132.66-179.11]，L1）
- 预告的技术演讲包括：瑞士 OpenBSD 开发者 Claudio Jeker 讲 OSPF6 守护进程（IPv6 的 OSPF 路由协议），以及关于 OpenBSD 4.2 缓冲区缓存改进的演讲等。（BSDTalk EP133，[179.58-217.60]，L1）
- 社区庆典与经济安排：周六晚举办 OpenSSH 八周年生日派对（OpenSSH 生于 1999 年 10 月，2007 年满八岁），周五晚设酒吧非正式聚会以促进与会者与开发者交流构想；会议与教程全免费、无入场费，成本由组织者承担，午餐需自购、派对收少量费用；会议不做录像录音，理由是人们应当亲临现场。（BSDTalk EP133，[226.47-315.13]，L1）
- Balmer 在 OpenCon 之外的工作是组织 OpenBSD 开发者会议（hackathon）：属非公开、仅受邀的内部活动，且趋势是越办越小规模，如上年葡萄牙的 hackathon；此类活动公开可见度低。（BSDTalk EP133，[315.13-344.45]，L1）
- 规模与国际化：注册开放的首个周末已有来自 11 个国家的 28 人报名；上年参会者超过 130 人，甚至有来自黎巴嫩者；Balmer 感叹 BSD 社区已成长到足以支撑专门的国际会议。（BSDTalk EP133，[357.94-384.05]，L1）
- 主持人的 UNIX 起点约在 1996 年：先在 DOS 分区上运行 Minix（记忆最深的是随附的 Asteroids 游戏），继而被赠予 O'Reilly《Running Linux》随书 CD-ROM——内含 Red Hat Linux 2.1 的源码与安装文档，安装过程费力，最终跑起 X 图形环境时令他极为兴奋；更早在大学时代（1980 年代末至 1990 年代初）所用系统已记忆模糊，只记得用 finger 查看其他大学的朋友是否在线、以基础 talk 工具交谈。（BSDTalk EP60，[75.2-156.0]，L1）
- 其可查的最早 BSD 兴趣记录是 1999 年 11 月 3 日发往 FAQ@openbsd.org 的提问邮件，获 OpenBSD 开发者 Eric Jackson（monkey.org）清晰友好的回复，这份回复被他视为鼓励自己继续钻研 BSD 的关键；最早的 OpenBSD 实物为 1999 年 12 月 1 日发布的 2.6 CD 组与原装贴纸；同期他也研究过 FreeBSD（留有 2000 年 2 月的 4.0-RC2 CD），却不记得为何未续用，OpenBSD 反而留存下来。（BSDTalk EP60，[156.0-334.48]，L1）
- OpenBSD 2.6 CD 是一段加密法制史的物证：该版为首个随版附带 OpenSSH 的发行版本；CD 插页仍印有“因专利或其他限制，SSH 与 PGP 等包不能置于 CD-ROM”的旧表述（主持人推测为转用 OpenSSH 后的残留语言），而基于 OpenSSL 的 libssl 与 libcrypto（供 SSH、HTTPD、ISAKMPD 使用）确因专利授权限制不在 CD 上、须另行下载；与 2006 年的美国环境对照，加密管制的松紧变化一目了然。（BSDTalk EP60，[227.28-293.36]，L1）
- 当下的 OpenBSD 使用：公司 Web 服务器运行 OpenBSD，用于托管带内容管理系统的基本站点且要求相当安全；他看中 OpenBSD 的 chroot 特性——Apache 默认已置于 chroot 监牢，几乎无需额外工作即可运行；chroot 对不愿被改造的不兼容应用确会带来额外问题，但整体运行良好。（BSDTalk EP60，[356.66-401.94]，L1）
- spamd 灰名单实战：近期在 OpenBSD 4 上以网桥方式部署 spamd 灰名单（无须改动既有配置），置于公司 Exchange Server 2003 之前——原先内置过滤加 Outlook 的组合占用大量带宽与算力而效果平平；灰名单一周内效果显著，且未遇到邮件列表或外发服务器池从不同 IP 重新入队等常见顾虑；他预告将邀请 spamd 相关开发者上节目。（BSDTalk EP60，[401.94-467.3]，L1）
- 无障碍议题呼吁：主持人公开征集有视觉或其他障碍的 BSD 用户，指出屏幕阅读器、外接盲文终端等无障碍特性在 BSD 生态中少受讨论；他提及 YASR（yet another screen reader）曾可在 FreeBSD 上编译，联系项目后获复“应能编译但未做过测试”；其关切理由包括同事正在使用屏幕阅读器、任何人都可能因事故临时需要无障碍能力、政府合同常对此有硬性要求，以及语音输入输出对未来车载计算等场景的价值。（BSDTalk EP60，[471.0-597.76]，L1）

**史观**：

- 总纲20 历史地理塑造思想土壤：OpenCon 的地理组织——威尼斯会场、11 国乃至黎巴嫩的参会者流动——显示欧洲城市节点与会议空间如何承载并塑造 BSD 社区的交流形态，社区思想的生长与其地理聚点不可分。（BSDTalk EP133，[59.18-72.61]，L1）
