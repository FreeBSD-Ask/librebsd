# 206.2 OpenSSH 的许可证纯洁化

**要点**：OpenSSH fork OSSH 后的首要工作是去除 SSH 1.2.12 中的受限组件——Theo de Raadt（西奥·德·若特） 移除非可移植代码以简化源码便于安全审计，Niels Provos（尼尔斯·普罗沃斯） 通过赴加拿大实地工作移除受美国密码出口管制约束的加密组件与 GPL 组件（libgmp 受 GPL 约束），Markus Friedl（马库斯·弗里德尔） 将 SSH 1.3 协议代码替换为 SSH 1.5 协议实现（兼容 ssh 1.2.27 系列，因众多 Windows SSH 客户端仅支持 SSH 1.5），Bob Beck 处理 Makefile 使 OpenBSD 2.6 附带的 libssl/libcrypto 不含受 RSA 专利约束的算法（RSA 专利至 2000-09 方过期，CD 出货时不含 RSA，安装时用户可通过 FTP/HTTP 替换）；纯洁化工作在 OpenSSH 1.2.2 随 OpenBSD 2.6 发布（1999-12-01）前完成

**史料**：OpenSSH 项目历史页面（<https://www.openssh.com/history.html>，记载 de Raadt 移除非可移植代码、Provos 赴加拿大移除加密与 GPL 组件、Friedl 替换 SSH 1.3 为 1.5、Beck 处理 Makefile 避免 RSA 专利）；OpenSSH LICENCE 文件（<https://cvsweb.openbsd.org/src/usr.bin/ssh/LICENCE>，记载各组件许可证组合）；OpenBSD 2.6 Release Notes（<https://www.openbsd.org/26.html>）；RSA 专利过期日期（2000-09-20）

**史观**：总纲第 12 条——法律结构：许可证纯洁化是法律结构对技术实现的直接塑造——Provos 必须赴加拿大移除加密组件是美国密码出口管制法律的直接后果，Beck 必须处理 Makefile 避开 RSA 算法是美国专利法的直接后果，Friedl 替换 SSH 1.3 为 1.5 是为兼容仅支持 1.5 的 Windows 客户端而进行的协议层法律规避——三项工作均由法律结构驱动而非纯技术考量；总纲第 8 条——社区文化即技术资产：de Raadt 移除非可移植代码以“简化源码便于安全审计”是 OpenBSD 审计文化的具体显现——代码可读性被预设为安全性的前提

**辨析**：纯洁化工作的具体范围经 OpenSSH 官方历史页面确认涵盖四项——de Raadt 的非可移植代码移除、Provos 的加密与 GPL 组件移除、Friedl 的 SSH 1.3→1.5 协议替换、Beck 的 RSA 专利规避 Makefile；纯洁化完成时间节点为 OpenSSH 1.2.2 随 OpenBSD 2.6 发布日 1999-12-01，因 1.2.2 是首个随 OpenBSD 正式发布的版本；OSSH（Björn Grönvall 维护的 fork）仅支持 SSH 1.3 协议，OpenSSH fork 后 Friedl 增加 SSH 1.5 支持时保留了 1.3 支持，非完全替换

**OpenSSH 许可证纯洁化工作分工**：

| 负责人 | 工作内容 | 法律驱动 |
| --- | --- | --- |
| Theo de Raadt | 移除非可移植代码（OS/2、VMS、Windows 9x 等） | 简化源码便于审计 |
| Niels Provos | 赴加拿大移除加密组件与 GPL 组件（libgmp） | 美国密码出口管制 + GPL 约束 |
| Markus Friedl | 替换 SSH 1.3 协议为 SSH 1.5 | 兼容仅支持 1.5 的 Windows 客户端 |
| Bob Beck | 处理 Makefile 避开 RSA 算法 | RSA 专利至 2000-09 方过期 |
