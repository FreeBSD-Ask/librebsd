# 206.3 OpenSSH 成为 BSD/Linux 默认 SSH 实现

**要点**：OpenSSH 1.2.2 随 OpenBSD 2.6 于 1999-12-01 发布，成为 OpenBSD 默认 SSH 实现；FreeBSD 于 2000-02-24 由 Mark Murray commit 511b41d2a18c 首次 vendor import OpenSSH 入 -CURRENT，2000-02-27 Kris Kennaway commit 0990cf946f28 提升 __FreeBSD_version，2000-03-13 Kris Kennaway commit 636e8b707b47 将 RSAREF 检测 MFC 至 4-STABLE，使 FreeBSD 4.0（2000-03-14 发布）首次包含 OpenSSH，2000-09-07 Jordan K. Hubbard（乔丹·哈伯德） commit 94e00feef2e1 将“sshd enabled by default”MFC 至 4-STABLE，FreeBSD 4.1.1（2000-11）起 sshd 默认启用；NetBSD 于 2000-07-25 由 thorpej 添加 usr.bin/ssh 构建框架（commit 8f6bf0e26409，注明“SSH 实现尚未进入 NetBSD 源码树”），2000-09-28 thorpej commit 88df7b2c9ccb"Import NetBSD Secure Shell. This is based on OpenSSH, but modified somewhat"将 OpenSSH 引入 NetBSD 源码树，NetBSD 1.5（2000-11）包含 OpenSSH；portable OpenSSH 由 Damien Miller（达米安·米勒）、Philip Hands 等在 OpenSSH 1.2.2 发布后立即开始移植至 Linux 与其他 Unix 系统，OpenBSD 团队有意将核心开发与可移植开发分离以保持核心代码简洁

**史观**：总纲第 10 条——边缘者贡献：OpenBSD 作为边缘项目通过 OpenSSH 贡献至整个互联网生态——2000 年 2 月至 9 月间 FreeBSD、NetBSD 相继采纳 OpenSSH，OpenBSD 审计文化产出的 SSH 实现从单一项目扩散至三大 BSD；总纲第 2 条——分离与聚合：OpenSSH 从 SSH Communications Security 的闭源实现分离后聚合入 OpenBSD 源码树，再从 OpenBSD 聚合入 FreeBSD、NetBSD 与各 Linux 发行版——两次聚合均以 BSD 许可证为法律基础；总纲第 7 条——技术选择即政治选择：OpenBSD 团队有意将核心开发与 portable 开发分离（"compare the number of lines of code between the baseline and portable versions"）是工程政治选择——以核心代码简洁性为预设，宁可维护两套代码也不让可移植性包袱污染核心

**辨析**：FreeBSD 4.0（2000-03-14）包含 OpenSSH 但 sshd 未默认启用——vendor import 在 2000-02-24，MFC 至 4-STABLE 在 2000-03-13，但“sshd enabled by default”MFC 在 2000-09-07（commit 94e00feef2e1），故 FreeBSD 4.0 用户需手动启用 sshd，FreeBSD 4.1.1（2000-11）起 sshd 默认启用；NetBSD 1.5（2000-11）采纳 OpenSSH 的时间与 thorpej 2000-09-28 import 一致，但 NetBSD 将其命名为“NetBSD Secure Shell”并注明“based on OpenSSH, but modified somewhat”，表明 NetBSD 对 OpenSSH 进行了本地修改而非直接 vendor import；portable OpenSSH 的维护团队（Damien Miller、Philip Hands 等）与 OpenBSD 主线团队（de Raadt、Friedl、Provos 等）存在人员交叉但开发分支独立——portable 版本在核心版本基础上增加可移植性胶水代码，OpenBSD 团队官方历史页面明确记载这一分离决策；freebsd.duckdb 查询 L2.2.1.openssh 在中观模式挖掘报告中不存在（报告仅含 freebsd-src 仓库的 sys/kern、sys/net 等子系统查询，未覆盖 openbsd-src 或 freebsd-src 仓库的 usr.bin/ssh 子系统），OpenSSH 相关子系统级 commit 数据须以 freebsd.duckdb 直接查询 file_path 维度（如 usr.bin/ssh/、crypto/openssh/）补全
