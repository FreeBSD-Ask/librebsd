# 207.6 项目统摄史观审视扩展：从总纲第 13、19、21 条看 OpenSSH 内部代码替换争议

**要点**：本节从项目史观总纲第 13 条（法律与道德是利益分配）、第 19 条（解释学循环是历史认识的根本条件）、第 21 条（革命与改革是历史方法论的分歧）切入，审视 207.2-207.5 节的四层辩证；总纲第 13 条揭示三项纯洁化工作（Provos 移除 libgmp、Friedl 替换 SSH 1.3 为 1.5、Beck 处理 Makefile 避免 RSA 专利）均由法律结构驱动——GPL 约束、美国密码出口管制、RSA 专利是三项法律结构，“纯洁化”叙事将法律结构驱动的工程决策包装为道德选择，“许可证纯洁化”的道德话语遮蔽了法律驱动的利益分配本质；总纲第 19 条揭示四层辩证中的解释学循环——OpenBSD 阵营以“许可证纯洁化优先”为前理解使其反批评在自身框架内自洽但无法跳出框架评估叙事一致性，批评方以“功能完整性/叙事一致性/用户责任”为前理解使其批评在自身框架内成立但无法理解 OpenBSD 的许可证审计逻辑，前理解的差异使分歧不可避免，权力与知识在历史书写中共谋（OpenSSH 官方历史页面由 OpenBSD 团队书写，自然倾向于许可证纯洁化叙事）；总纲第 21 条揭示三项纯洁化工作是革命路线（一次性移除 libgmp、替换协议、规避专利）而非改革路线（渐进替换、延后发布、与专利方协商），与 SSH Communications Security 的渐进改良路线（保留商业许可证、逐步收紧功能）形成历史方法论分歧——革命路线的“破山中贼易”（一次性移除 GPL 与专利组件）与改革路线的“破心中贼难”（让商业 SSH 用户接受 BSD 许可证开源实现）在 1999-2017 年间各自呈现，最终在 OpenSSH 成为事实标准时达成和解

**史观**：总纲第 13 条——法律与道德是利益分配：三项纯洁化工作均由法律结构驱动而非纯技术考量——Provos 移除 libgmp 是 GPL 约束的直接后果，Beck 处理 Makefile 是美国专利法的直接后果，Friedl 替换 SSH 1.3 为 1.5 虽含兼容性考量但其发生的语境是许可证纯洁化工作（fork 的首要动机是 SSH 1.2.13+ 转为商业许可证），“纯洁化”叙事将法律结构驱动的工程决策包装为道德选择——de Raadt 的“简化源码便于安全审计”叙事本身即是法律驱动的工程决策在话语层面的道德化，文化（审计传统）被重构为工程（代码可读性）的话语；总纲第 19 条——解释学循环是历史认识的根本条件：四层辩证中的每一方都站在自身前理解中——OpenBSD 阵营以“许可证纯洁化优先”为前理解，批评方以“功能完整性/叙事一致性/用户责任”为前理解，前理解的差异使 207.4 节再回应不可避免，权力与知识在历史书写中共谋——OpenSSH 官方历史页面由 OpenBSD 团队书写，自然倾向于许可证纯洁化叙事（原文“freeing SSH, cleaning up the license mess”），Provos 赴加拿大的个人成本在历史页面中被简略为“road trips to Canada”一笔带过，Friedl 替换协议的动机被表述为兼容性扩展而非纯洁化让步，Beck 处理 Makefile 的用户合规负担被“Luckily this kind of hackery is no longer needed”的轻松语调淡化——什么被记录（OpenBSD 团队的工程成就）、什么被遗忘（Provos 个人成本、用户合规负担、OpenSSL 早期稳定性风险）本身就是权力行使；总纲第 21 条——革命与改革是历史方法论的分歧：三项纯洁化工作是革命路线（一次性移除 libgmp、替换协议、规避专利）而非改革路线（渐进替换、延后发布、与专利方协商），与 SSH Communications Security 的渐进改良路线形成历史方法论分歧——革命路线的“破山中贼易”（一次性移除 GPL 与专利组件）与改革路线的“破心中贼难”（让商业 SSH 用户接受 BSD 许可证开源实现）在 1999-2017 年间各自呈现，最终在 OpenSSH 成为事实标准时达成和解；但须注意总纲第 21 条原文“Linux 靠革命，BSD 靠改革”在 OpenSSH 案例中的张力——OpenSSH 的纯洁化工作是革命路线，而 SSH Communications Security 的渐进改良是改革路线，这与总纲第 21 条的“BSD 靠改革”表述存在表面矛盾，这一矛盾揭示总纲第 21 条的“革命 vs 改革”框架在具体案例中的复杂性——同一项目内部可能同时存在革命成分（一次性移除）与改革成分（保留 SSH 1.3 支持渐进迁移），二者并非完全对立而是同一过程的不同侧面
