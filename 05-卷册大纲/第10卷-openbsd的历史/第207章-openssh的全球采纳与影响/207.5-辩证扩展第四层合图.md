# 207.5 辩证扩展第四层：合图

**要点**：四层辩证在 OpenSSH 长期演进中达成合图——Provos 移除 libgmp 以 OpenSSL libcrypto 替代在长期被证明是正确的选择，OpenSSL 后续成为全球加密事实标准（尽管 2003 年与 2014 年 Heartbleed 等漏洞表明 OpenSSL 自身存在稳定性问题，但 libgmp 因 GPL 约束无法保留在 BSD 许可证的 OpenSSH 中，移除是修复 GPL 违规的法律必要而非可选的工程选择）；Friedl 替换 SSH 1.3 为 1.5 同时保留 1.3 支持在长期被证明是兼容性扩展的正确决策，SSH 1.3 与 1.5 双协议支持持续至 2017 年 OpenSSH 7.6 完全删除 SSH1 协议（commit `6c99a5ed578d`，2017-04-30 djm），期间为全球用户提供了平滑的协议迁移窗口；Beck 处理 Makefile 避免 RSA 专利在 RSA 专利过期（2000-09-20）后即不再需要（官方历史页面原文“Luckily this kind of hackery is no longer needed”），OpenBSD 2.7（2000-06-15）发布时仍在专利过期前但 OpenBSD 2.8（2000-12-01）发布时已可合法包含 RSA，FTP/HTTP 替换机制的存续期仅约 1 年；合图并非“OpenBSD 全胜”——Provos 个人赴加拿大的成本、OpenSSL 早期稳定性风险、用户安装时替换 RSA 的合规负担均为真实代价，但这些代价在 OpenSSH 成为事实标准后被行业消化；三项纯洁化工作均由法律结构驱动（GPL 约束、美国密码出口管制、RSA 专利），印证了 92.12 节史观字段引用的总纲第 13 条——法律与道德是利益分配——“纯洁化”叙事的本质是法律结构驱动的工程决策在话语层面的合理化

**史观**：总纲第 6 条——和解优于斗争：合图不是“OpenBSD 胜利”而是各方立场在长期演进中的和解——OpenBSD 阵营的许可证纯洁化论点被 libgmp GPL 违规修复与 OpenSSL 成为事实标准部分验证，批评方的工程公平与叙事一致性关切被 Provos 个人成本与 OpenSSL 早期稳定性风险部分验证，商业 SSH 厂商的市场份额虽被 OpenBSD 取代但其企业级 PAM 领域仍存；总纲第 4 条——分离聚合是永恒规律：OpenSSH 从 SSH 1.2.12 分离后聚合入 OpenBSD 源码树，再从 OpenBSD 聚合入 FreeBSD、NetBSD、Linux 各发行版——分离与聚合的循环是 OpenSSH 全球扩散的根本结构；总纲第 13 条——法律与道德是利益分配：三项纯洁化工作均由法律结构驱动，“纯洁化”叙事将法律结构驱动的工程决策包装为道德选择，合图揭示这一包装在长期被行业消化但并未消除其法律驱动的本质
