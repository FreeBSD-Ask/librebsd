# 203.3 OpenBSD 1.0/1.1/1.2 的早期发布历程（1996）


- 要点：OpenBSD 1.0/1.1 为内部/预发布版本，无公开 ISO 发布，仅在 CVS 仓库中存在版本标记——OpenBSD Jumpstart（<https://www.openbsdjumpstart.org/）称“第一个> OpenBSD release 1.1/CVS 出现于 1995 年 10 月 18 日 “，该日期实为 fork 启动日（即 CVS 仓库最早 commit 时间），非 1.1 正式发布日；OpenBSD 1.2 于 1996 年 7 月发布，是首个公开发行的版本（bsd_commits.db openbsd-src 仓库 commit d8c59f67b872ee4d18dce483743f4096c202ff56，1996-07-16T22:57:02Z deraadt ” 1.2 ”，为版本号标记 commit）；OpenBSD 1.0/1.1/1.2 均以 NetBSD 1.0 为基础，附加加密代码（如 SSH、SSL）
- 史料：OpenBSD 1.0/1.1/1.2 Release Notes（<https://www.openbsd.org/plus.html，plus.html> 页面仅从 2.0 起有独立 changelog 页面，1.x 无独立页面）；bsd_commits.db openbsd-src 仓库 commit d8c59f67b872ee4d18dce483743f4096c202ff56（1996-07-16T22:57:02Z deraadt “1.2”）；OpenBSD Jumpstart 项目介绍（<https://www.openbsdjumpstart.org/，记载“第一个> OpenBSD release 1.1/CVS 出现于 1995 年 10 月 18 日 ”）；OpenBSD CVS 仓库（<https://cvsweb.openbsd.org/）>
- 史观：总纲第 2 条——分离与聚合：OpenBSD 从 NetBSD 1.0 分离后聚合加密代码（SSH、SSL），分离是法律结构驱动的（de Raadt 被 NetBSD 逐出），聚合是技术取向驱动的（安全至上定位需要加密组件）；总纲第 5 条——组织结构塑造技术路径：OpenBSD 1.0/1.1 作为内部版本无公开 ISO 发布，是 de Raadt BDFL 模式下的决策——宁可延后公开发布也要确保代码质量，与 NetBSD 1.0（1994-10）公开发布的策略不同
- 辨析：OpenBSD 1.0/1.1 的具体发布日期在数据库中无直接证据——bsd_commits.db openbsd-src 仓库 tags 表为空（tag_count = 0），无 release tag；1996 年 1-7 月 commit 计数显示 1996-05（607 commits）与 1996-07（404 commits）为活跃期，与 1.2 发布时间吻合；OpenBSD Jumpstart 所称 “1.1/CVS 出现于 1995.10.18” 经 bsd_commits.db 核查为 fork 启动日（CVS 仓库最早 commit 时间），非 1.1 正式发布日——1.1 实为内部版本号 [考据完成：2026-07-28 初次考据，2026-07-30 三次复查（**openbsd.db** openbsd-src 仓库 `message_subject` 含 “1.0” “1.1” 关键词查询经 `script\jianyi_7ai_openbsd_1x_release.py` 执行，仅 1996-07-16T22:57:02Z deraadt “1.2” 一条版本号 commit 匹配，1.0/1.1 无匹配；WebFetch OpenBSD 官方 changelog **plus.html** 证实版本切换链接从 2.0 起，1.0/1.1 无 changelog 页面；WebFetch marc.info **openbsd-announce** 邮件列表存档搜索接口返回空结果，存档为交互式动态接口 WebFetch 不可达）进一步证实该存疑标注属史料缺口，须待 **openbsd-announce** 邮件列表 1996 年存档或其他原始档案公开后方可补充确证]；OpenBSD 1.2 为首个公开发行的版本，发布时间经 bsd_commits.db commit d8c59f67b872ee4d18dce483743f4096c202ff56（1996-07-16 “1.2”）确认为 1996 年 7 月
