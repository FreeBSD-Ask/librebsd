## 冲突类

### 新闻条目 1

- **新闻标题（中英）**：OpenBSD 7.2 Released（OpenBSD 7.2 发布）+ Further memory protections committed to -current + Next steps toward mimmutable, from deraadt@
- **新闻来源**：undeadly.org + 编辑署名 + 2022-10-20 / 2022-10-08 / 2022-11-20 + URL: <https://undeadly.org/cgi?action=article;sid=20221020184115> + <https://undeadly.org/cgi?action=article;sid=20221008100649> + <https://undeadly.org/cgi?action=article;sid=20221120115616> + 存档 URL: 待补
- **新闻摘要**：undeadly.org 系列报道 OpenBSD 7.2 于 2022-10-20 正式发布，同时 2022-10-08 报道进一步内存保护已提交至 -current，2022-11-20 Theo de Raadt（西奥·德·若特）（deraadt@）发布 mimmutable 下一步计划。mimmutable 是 OpenBSD 7.x 时期引入的不可变用户态映射机制，通过将关键内存页标记为不可变，阻断攻击者通过修改已映射内存页注入代码的路径，是 pledge(2)/unveil(2) 之后 OpenBSD 沙箱体系的下一级支柱。
- **与本章主题的关联说明**：本章叙述 OpenBSD 7.x 时期，7.2 发布与 mimmutable 引入是本章 “OpenBSD 7.x 内存保护演进” 叙事的核心节点，延续 OpenBSD 自 W^X、KARL、RETGUARD 以来的主动安全路线。
- **与官方史料的交叉验证结论**：undeadly.org 报道与 OpenBSD 7.2 changelog（plus72.html）一致；mimmutable 工作与 Theo de Raadt 2022-11-20 邮件列表说明互证；与 2022-09-02 "OpenBSD may soon gain further memory protections: immutable userland mappings" 报道形成时序链。一致采纳。

### 新闻条目 2

- **新闻标题（中英）**：Parallel IP forwarding activated（并行 IP 转发激活）+ Testing parallel forwarding
- **新闻来源**：undeadly.org + 编辑署名 + 2022-05-04 / 2022-03-19 + URL: <https://undeadly.org/cgi?action=article;sid=20220504061418> + <https://undeadly.org/cgi?action=article;sid=20220319123157> + 存档 URL: 待补
- **新闻摘要**：undeadly.org 报道 OpenBSD 在 2022-03-19 呼叫测试并行转发，随后 2022-05-04 正式激活并行 IP 转发。这是 OpenBSD 网络栈去大锁（NET_LOCK）工作的延续，使 IP 转发路径可在多核并行执行，显著提升多核路由器/防火墙场景吞吐量。该工作由 Martin Pieuchot（马丁·皮厄肖） 在 d2k17 hackathon 起持续推进，至 7.1 时期正式落地。
- **与本章主题的关联说明**：本章叙述 OpenBSD 7.x 时期，并行 IP 转发激活是本章 “OpenBSD 7.x 网络栈现代化” 叙事的核心节点，延续 6.x 时期网络栈去大锁工作。
- **与官方史料的交叉验证结论**：undeadly.org 报道与 OpenBSD source-changes@ 邮件列表 2022-03 / 2022-05 网络栈 commit 一致；与 d2k17 hackathon 报告 Martin Pieuchot on moving the network stack out of the big lock（2017-06-29）形成历史时序链；与 OpenBSD 7.2 changelog 中并行转发条目互证。一致采纳。
