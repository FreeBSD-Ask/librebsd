# 197.5 重要贡献者与边缘者：OpenBSD 5.x 时期的核心团队——Theo de Raadt（创始人）、Henning Brauer（pf 维护）、Markus Friedl（马库斯·弗里德尔）（OpenSSH）、Bob Beck（OpenSSH/ OpenSSL）、Reyk Flöter（relayd/ldapd）等

## 197.5.1 de Raadt 的持续主导

**要点**：de Raadt 作为 OpenBSD 创始人，2005-2012 年间持续主导项目——所有重大架构决策、release engineering、社区治理均由其参与；de Raadt 的贡献涵盖内核、驱动、用户态工具与社区文化；openbsd.duckdb 显示 deraadt 自 1995 年 fork 起持续提交至 2024 年，是 OpenBSD 仓库中 commit 数量最多的贡献者之一

**史料**：openbsd.duckdb openbsd-src 仓库 deraadt commit 记录（首末 commit 时间与 commit 数量）；de Raadt 在 misc@、tech@ 的发言（<https://marc.info/?l=openbsd-misc>、<https://marc.info/?l=openbsd-tech>）；OpenBSD hackathons 记录（<https://www.openbsd.org/hackathons.html>）［A］

**史观**：总纲第 10 条——边缘者贡献：de Raadt 作为 OpenBSD 的“动手者”——1995 年被 NetBSD 核心团队要求停止参与后 fork 创建 OpenBSD，从被边缘化到主导项目，其经历是“边缘者突破制度约束”的典型

**辨析**：de Raadt 的具体工作量以 openbsd.duckdb openbsd-src 仓库 deraadt commit 记录为准——deraadt 的 commit 涵盖内核、驱动、用户态工具等多个领域，但部分技术细节由领域负责人主导（如 pf 由 Brauer 维护）；commit log 反映的实际工作量以 commit hash 与 file_path 交叉验证为准

**文献**：openbsd.duckdb openbsd-src 仓库 deraadt commit；de Raadt 邮件列表发言 [EB/OL]. <https://marc.info/?l=openbsd-misc>；OpenBSD hackathons 记录 [EB/OL]. <https://www.openbsd.org/hackathons.html> ［A］

## 197.5.2 Brauer/Friedl 的 pf 与 OpenSSH 贡献

**要点**：Henning Brauer 是 pf 防火墙的核心维护者，主导 pf 4.x-5.x 时期的语法演进与性能改进；Markus Friedl 是 OpenSSH 的核心维护者，主导 OpenSSH 协议实现与安全特性；两者作为非显性贡献者，长期在 OpenBSD 社区贡献关键基础设施

**史料**：openbsd.duckdb openbsd-src 仓库 Brauer 的 pf 相关 commit（以 sys/net/pf/ 路径下 henning 的 commit 为索引）、Friedl 的 OpenSSH 相关 commit（以 usr.bin/ssh/ 路径下 markus 的 commit 为索引）；misc@、tech@ 邮件列表中两人的发言（<https://marc.info/?l=openbsd-tech>）［A］

**史观**：边缘者贡献：Brauer 与 Friedl 是长期深耕单一子系统的边缘者——Brauer 守护 pf 防火墙（OpenBSD 网络安全的核心组件），Friedl 守护 OpenSSH（全球 SSH 基础设施的核心实现），二者的贡献虽不显性但构成了 OpenBSD 对外影响力的技术基石

**辨析**：Brauer 与 Friedl 的具体贡献边界以 openbsd.duckdb openbsd-src 仓库 commit_files 表中 sys/net/pf/ 与 usr.bin/ssh/ 路径下的 commit 归属为准——部分 patch 由多人协作但仅一人 commit，commit_files 表可定位实际代码变更者

**文献**：openbsd.duckdb openbsd-src 仓库 Brauer pf commit、Friedl OpenSSH commit；OpenSSH 项目历史文档 [EB/OL]. <https://www.openssh.com/>；pf 设计文档（<https://www.openbsd.org/faq/pf/>）

## 197.5.3 Beck/Flöter 的安全与网络贡献

**要点**：Bob Beck 是 OpenSSH 与 OpenSSL（后 LibreSSL）的长期贡献者，在 Heartbleed 后协调 LibreSSL fork（openbsd.duckdb 显示 beck 自 2014-04-14 起参与 OpenSSL 代码清理，commit af0b15b8442f 之前由 djm 提交 Heartbleed fix）；Reyk Flöter 是 relayd、snmpd、iked 等 OpenBSD 守护进程的开发者（relayd 由其与 Pierre-Yves Ritschard 于 2004-2006 年间开发，2006 年随 OpenBSD 4.1 发布；iked 即 OpenIKED 亦由其启动）；两人的贡献让 OpenBSD 在网络与安全领域占据独特地位

**史料**：openbsd.duckdb openbsd-src 仓库 Beck 的 OpenSSH/LibreSSL 相关 commit（2014-04-14 起 beck 移除 OpenSSL 引擎、2014-05-29 beck 定义 LIBRESSL_INTERNAL）、Flöter 的 relayd/snmpd/iked 相关 commit；misc@、tech@ 邮件列表中两人的发言（<https://marc.info/?l=openbsd-tech>）［A］

**史观**：边缘者贡献：Beck 与 Flöter 作为非显性贡献者——Beck 在 Heartbleed 后协调 LibreSSL fork（对外沟通与 dead code 清理），Flöter 开发 relayd、snmpd、iked 等网络服务，二者的贡献虽不如 de Raadt 显性但构成了 OpenBSD 安全与网络基础设施的关键组件

**辨析**：Flöter 的姓名拼写以 OpenBSD 官方 committer 名单为准——OpenBSD CVS 与 commit log 中使用“reyk”作为用户名，全名拼写为 Reyk Flöter；Beck 在 LibreSSL fork 中的角色以 openbsd.duckdb openbsd-src 仓库 2014-04 至 2014-07 的 commit 为准——beck 是 fork 的主要协调者（移除引擎、定义 LIBRESSL_INTERNAL），jsing 是 libressl 库初始代码的提交者（2014-07-12 commit b6553af36068“Initial version of libressl”）；需辨明的是，CARP 协议由 Ryan McBride 主设计（Michael Shalayeff、Marco Pfatschbacher、Markus Friedl 协助，见 OpenBSD FAQ 6.11 与 carp(4) 版权行“Copyright (c) 2003, Ryan McBride”），ldapd(8) 由 Martin Hedenfalk 编写（见 OpenBSD innovations 页 2010-05-31 入树记录），二者均非 Flöter 的工作——Flöter 的代表性成果是 relayd（与 Pierre-Yves Ritschard 共同开发）、snmpd、hostapd 与 OpenIKED（iked，2010-06-03 入树，验证方法：cvsweb.openbsd.org www/innovations.html 各条目入树日期与维护人记录）

**文献**：openbsd.duckdb openbsd-src 仓库 Beck、Flöter commit；LibreSSL 项目历史文档 [EB/OL]. <https://www.libressl.org/>；relayd 设计文档（<https://man.openbsd.org/relayd>）
