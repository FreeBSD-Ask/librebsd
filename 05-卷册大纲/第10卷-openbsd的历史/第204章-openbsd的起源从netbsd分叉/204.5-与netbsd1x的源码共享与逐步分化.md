# 203.5 与 NetBSD 1.x 的源码共享与逐步分化


- 要点：OpenBSD fork 自 NetBSD 1.0，早期代码与 NetBSD 共享比例较高，至 2.x 系列逐步分化；OpenBSD 2.0（1996-10）后逐步引入 strlcpy/strlcat（1998-07-01 millert commit 1dc0268a4106，见第 91 章考据）、arc4random 等 OpenBSD 专有 API，源码共享比例持续下降；两个项目的分化路径是 “安全审计” 与 “可移植性” 两条 BSD 哲学方向的具体显现——OpenBSD 投入工程资源逐行审计基本系统源码，NetBSD 投入工程资源移植至更多硬件平台
- 史料：OpenBSD 1.x 与 NetBSD 1.x Release Notes（<https://www.openbsd.org/plus.html>、https://www.netbsd.org/releases/formal.html）；两项目 CVS 源码对照（<https://cvsweb.openbsd.org/>、https://cvsweb.netbsd.org/）；bsd_commits.db openbsd-src 仓库 commit 1dc0268a4106（1998-07-01 millert "add strlcpy/strlcat"，lib/libc/string/strlcpy.c 与 strlcat.c 首次引入）〔L1 代码/构建产物/L3 官方文档与公告〕
- 史观：总纲第 7 条——技术选择即政治选择：OpenBSD 选择 “安全至上”（投入工程资源逐行审计基本系统源码），NetBSD 选择 “可移植至上”（投入工程资源移植至更多硬件平台），二者的技术选择是各自社区对 BSD 哲学不同面向的政治选择——前者以 “代码可审计为可信来源” 为预设，后者以 “运行于一切硬件为自由之基” 为预设；总纲第 2 条——分离与聚合：OpenBSD 从 NetBSD 1.0 分离后逐步聚合自有的安全 API（strlcpy/strlcat、arc4random），这些 API 后续又从 OpenBSD 分离并聚合入 FreeBSD、NetBSD、glibc 等其他系统——分离与聚合的方向随时间反转，OpenBSD 从 NetBSD 的接收者变为向 NetBSD 的贡献者
- 辨析：代码共享比例 “约 90%” 在不同叙事中存在差异——该数字为早期二手资料的概括性估计，精确比例须以 OpenBSD 1.x 与 NetBSD 1.x 源码 diff 为准 [考据完成：2026-07-28 代码共享比例的精确数字无单一权威来源，“约 90%” 为社区共识性估计；2026-07-30 三次复查经 **openbsd.db** openbsd-src 仓库与 **netbsd.db** netbsd-src 仓库 1995-10-18 至 1997-12-31 期间 commit_files 表 file_path 集合交集统计（经 `script\jianyi_vol7_query_filepath_intersection.py` 执行），openbsd-src 仓库同期触及 file_path 数 29,549、netbsd-src 仓库同期触及 file_path 数 23,408、交集 file_path 数 15,043、并集 file_path 数 37,914、Jaccard 相似系数 39.68%、openbsd-src 中与 netbsd-src 共享的 file_path 比例 50.91%、netbsd-src 中与 openbsd-src 共享的 file_path 比例 64.26%——此比例反映两仓库在 1995-10-18 至 1997-12-31 期间被 commit 触及的 file_path 集合交集，而非 fork 初期（1995-10-18）源码树的完整共享比例，“约 90%” 的社区共识性估计指 fork 初期 OpenBSD 源码树与 NetBSD 1.0 源码树的共享比例，二者含义不同；file_path 集合交集统计的局限：仅统计被 commit 触及的文件，未触及的文件不在集合中，且 file_path 路径相同不等于文件内容相同，须以源码 tarball diff 核验完整共享比例]；OpenBSD fork 自 NetBSD 1.0 而非 1.1——bsd_commits.db 显示 openbsd-src 仓库最早 commit 为 1995-10-18 "initial import of NetBSD tree"，NetBSD 1.0 发布于 1994-10，NetBSD 1.1 发布于 1995-11，fork 时间在 NetBSD 1.1 发布前，故 fork 基础为 NetBSD 1.0
