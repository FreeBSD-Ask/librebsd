# 204.8 de Raadt 行动性再回应层（再批评层）——OpenBSD 1.0/1.1/1.2 早期版本时间线与卡尔加里据点运作

**要点**：de Raadt 对撤权事件未在 netbsd-users 或 current-users 公开列表发布回应声明，而是以 “行动性再回应” 方式于 1995 年 10 月 18 日从加拿大卡尔加里 fork NetBSD 1.0 源码创建 OpenBSD 项目。本章对 OpenBSD 1.0/1.1/1.2 早期版本时间线进行考据——openbsd.duckdb openbsd-src 仓库最早 commit 为 1995-10-18T08:37:01Z（commit `df930be708d50e9715f173caa26ffe1b7599b157`，author = deraadt，message = “initial import of NetBSD tree”），此为 fork 实际启动日；当日 deraadt 在 openbsd-src 连续提交 10+ 条 commit（10:39、10:42、10:52、10:54、10:58、11:03、11:05、12:19、12:22 等），可视为 OpenBSD 仓库正式启动的代码级证据；OpenBSD 1.0/1.1 为内部/预发布版本，无公开 ISO 发布，仅在 CVS 仓库中存在版本标记——OpenBSD Jumpstart 所称 “1.1/CVS 出现于 1995.10.18” 实为 fork 启动日而非 1.1 正式发布日；OpenBSD 1.2 于 1996 年 7 月发布，是首个公开发行的版本（openbsd.duckdb openbsd-src 仓库 commit `d8c59f67b872ee4d18dce483743f4096c202ff56`，1996-07-16T22:57:02Z deraadt “1.2”，为版本号标记 commit）。卡尔加里据点运作方面，openbsd.duckdb openbsd-src 仓库 1995-10 至 1996-12 期间 commit 统计显示早期核心贡献者为：deraadt（2787 commits，1995-10-18 起）、niklas（676 commits，1995-11-28 起）、tholo（492 commits，1995-12-14 起）、mickey（399 commits，1996-02-17 起）、downsj（378 commits，1996-06-08 起）、millert（303 commits，1996-07-13 起）——deraadt 个人贡献占同期总量约 42%，远超第二名 niklas 的 676 commits，这一 commit 分布是 BDFL 模式的量化显现。de Raadt 在 1996-07 OpenBSD 1.2 发布后逐步通过 <misc@openbsd.org> 邮件列表与公开采访阐述 fork 动因，但从未直接反驳 Adam Glass（亚当·格拉斯）通知邮件的具体措辞——这一 “以行动替代辩论” 的回应方式本身是 BDFL 治理风格的显现

**史观**：总纲第 5 条——偶然性改写历史：de Raadt 末次 netbsd-src commit 1994-12-17T23:12:41Z 至 openbsd-src 首 commit 1995-10-18T08:37:01Z 间隔约 10 个月，这 10 个月为 fork 筹备期——若无 Adam Glass 1994-12-23 通知邮件撤销访问权限，de Raadt 无动机筹备 fork，OpenBSD 项目可能永不存在，BSD 生态的安全审计路径将以另一面貌演进；总纲第 10 条——边缘者贡献：OpenBSD 早期团队从 NetBSD 分离后以卡尔加里住所为据点，是典型的边缘项目运作模式——无企业赞助、无基金会支持，依靠 CD 分发收入与志愿者贡献维持运转，但这一边缘团队后续产出的 OpenSSH、strlcpy/strlcat、LibreSSL 等成果贡献至整个 Unix 生态；总纲第 8 条——本体论平等：de Raadt 在 OpenBSD 中采用的 BDFL 模式与 NetBSD Core Team 的委员会模式在本体论上平等——前者通过单一领导者意志避免组织内耗，后者通过组织程序解决人事冲突，二者各有其代价与收益，无优劣之分

**辨析**：考据过程留痕——【查证来源】OpenBSD fork 启动时间经 openbsd.duckdb openbsd-src 仓库 commits 表最早 commit 1995-10-18T08:37:01Z（commit `df930be708d50e9715f173caa26ffe1b7599b157`）一手核验，message = “initial import of NetBSD tree” 证实 fork 基础为 NetBSD 源码树；当日连续 10+ 条 commit 序列（10:39-12:22）可视为仓库正式启动的代码级证据；OpenBSD 1.2 发布时间经 openbsd.duckdb openbsd-src 仓库 commit `d8c59f67b872ee4d18dce483743f4096c202ff56`（1996-07-16T22:57:02Z deraadt “1.2”）核验，为版本号标记 commit；【交叉验证方法】openbsd.duckdb commit 时间线（一手）与 OpenBSD Jumpstart 项目介绍（二手）交叉验证——Jumpstart 所称 “1.1/CVS 出现于 1995.10.18” 经 openbsd.duckdb 核查为 fork 启动日（CVS 仓库最早 commit 时间），非 1.1 正式发布日，1.1 实为内部版本号；openbsd.duckdb 显示 OpenBSD 1.0/1.1 在数据库中无独立 release tag（tags 表为空，tag_count = 0），1996 年 1-7 月 commit 计数显示 1996-05（607 commits）与 1996-07（404 commits）为活跃期，与 1.2 发布时间吻合；【存疑判定依据】OpenBSD 1.0/1.1 的确切发布日期在官方页面与数据库中均无直接证据——openbsd.duckdb openbsd-src 仓库 tags 表为空（tag_count = 0），无 release tag；OpenBSD 官方 plus.html 页面仅从 2.0 起有独立 changelog 页面，1.x 无独立页面；此处采信 “1.0/1.1 为内部版本、1.2 为首个公开发布版本” 的叙事，存疑保留至 OpenBSD 1.x 时期 core 开发者公开回忆录或内部档案公开之日；de Raadt 未直接反驳 Adam Glass 通知邮件的具体措辞这一事实，可能源于 “以行动替代辩论” 的 BDFL 风格，亦可能源于对程序性发声的不屑回应，二者在史料中无法区分，存疑保留
