# 204.4 早期开发团队与卡尔加里据点

**要点**：OpenBSD 早期开发以 de Raadt 在加拿大卡尔加里的住所为据点，项目通过 <misc@openbsd.org> 邮件列表与 CD 分发维持运转；openbsd.duckdb openbsd-src 仓库 1995-10 至 1996-12 期间 commit 统计显示早期核心贡献者为：deraadt（2787 commits，1995-10-18 起）、niklas（676 commits，1995-11-28 起）、tholo（492 commits，1995-12-14 起）、mickey（399 commits，1996-02-17 起）、downsj（378 commits，1996-06-08 起）、millert（303 commits，1996-07-13 起）、pefo（154 commits，1996-05-01 起）、etheisen（152 commits，1996-01-22 起）、briggs（134 commits，1995-12-16 起）、chuck（117 commits，1995-11-07 起）；Niels Provos（密歇根大学，后主导 OpenSSH 开发）与 Angelos Keromytis（宾夕法尼亚大学，IPSec/PhotoID 开发者）在 fork 后陆续加入

**史料**：openbsd.duckdb openbsd-src 仓库 1995-10 至 1996-12 期间 author_name 与 commit 计数统计；OpenBSD 早期邮件列表存档（<misc@openbsd.org> <https://marc.info/?laccopenbsd-misc>、<tech@openbsd.org> <https://marc.info/?laccopenbsd-tech>）；OpenBSD CVS 仓库中早期贡献者记录（<https://cvsweb.openbsd.org/>）

**史观**：总纲第 5 条——组织结构塑造技术路径：de Raadt 单方面主导的 BDFL 治理结构自 fork 之初即确立——openbsd.duckdb 显示 1995-10 至 1996-12 期间 deraadt 个人贡献 2787 commits（占同期总量约 42%），远超第二名 niklas 的 676 commits，这一 commit 分布是 BDFL 模式的量化显现——单一领导者的技术决策无需经过委员会审批即可直接入树；总纲第 10 条——边缘者贡献：OpenBSD 早期团队从 NetBSD 分离后以卡尔加里住所为据点，是典型的边缘项目运作模式——无企业赞助、无基金会支持，依靠 CD 分发收入与志愿者贡献维持运转，但这一边缘团队后续产出的 OpenSSH、strlcpy/strlcat、LibreSSL 等成果贡献至整个 Unix 生态

**辨析**：早期核心贡献者的完整名单以 openbsd.duckdb author_name 统计为准——deraadt、niklas、tholo、mickey、downsj、millert、pefo、etheisen、briggs、chuck 为 commit 数前 10 的贡献者；卡尔加里据点在项目早期运作中的角色为 de Raadt 住所兼开发据点，部分核心开发者（如 Provos）赴卡尔加里实地参与开发（Provos 1999 年赴加拿大移除 OpenSSH 中受美国密码出口管制约束的加密组件，见第 92 章）；Provos 与 Keromytis 的加入时间在 openbsd.duckdb 中以 author_name 检索——provos 首次 commit 为 1999 年（OpenSSH 时期），keromytis 首次 commit 亦在后期，二人非 1995-1996 时期的核心贡献者，但在 IPSec 与 OpenSSH 开发中贡献关键
