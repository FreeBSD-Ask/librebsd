# 204.3 OpenBSD 1.0/1.1/1.2 的早期发布历程（1996）

**要点**：OpenBSD 1.0/1.1 为内部/预发布版本，无公开 ISO 发布，仅在 CVS 仓库中存在版本标记——OpenBSD Jumpstart（<https://www.openbsdjumpstart.org/>）称“第一个 OpenBSD release 1.1/CVS 出现于 1995 年 10 月 18 日”，该日期实为 fork 启动日（即 CVS 仓库最早 commit 时间），非 1.1 正式发布日；OpenBSD 1.2 于 1996 年 7 月发布，是首个公开发行的版本（openbsd.duckdb openbsd-src 仓库 commit d8c59f67b872ee4d18dce483743f4096c202ff56，1996-07-16T22:57:02Z deraadt “1.2”，为版本号标记 commit）；OpenBSD 1.0/1.1/1.2 均以 NetBSD 1.0 为基础，附加加密代码（如原始 SSH 与 SSLeay）

**史料**：OpenBSD 1.0/1.1/1.2 Release Notes（<https://www.openbsd.org/plus.html>，plus.html 页面仅从 2.0 起有独立 changelog 页面，1.x 无独立页面）；openbsd.duckdb openbsd-src 仓库 commit d8c59f67b872ee4d18dce483743f4096c202ff56（1996-07-16T22:57:02Z deraadt “1.2”）；OpenBSD Jumpstart 项目介绍（<https://www.openbsdjumpstart.org/>，记载“第一个 OpenBSD release 1.1/CVS 出现于 1995 年 10 月 18 日 ”）；OpenBSD CVS 仓库（<https://cvsweb.openbsd.org/>）〔L1 代码/构建产物/L3 官方文档与公告〕

**史观**：总纲第 2 条——分离与聚合：OpenBSD 从 NetBSD 1.0 分离后聚合加密代码（原始 SSH 与 SSLeay），分离是法律结构驱动的（de Raadt 被 NetBSD 逐出），聚合是技术取向驱动的（安全至上定位需要加密组件）；总纲第 5 条——组织结构塑造技术路径：OpenBSD 1.0/1.1 作为内部版本无公开 ISO 发布，是 de Raadt BDFL 模式下的决策——宁可延后公开发布也要确保代码质量，与 NetBSD 1.0（1994-10）公开发布的策略不同

**辨析**：OpenBSD 1.0/1.1 的具体发布日期在数据库中无直接证据——openbsd.duckdb openbsd-src 仓库 tags 表为空（tag_count = 0），无 release tag；1996 年 1-7 月 commit 计数显示 1996-05（607 commits）与 1996-07（404 commits）为活跃期，与 1.2 发布时间吻合；OpenBSD Jumpstart 所称 “1.1/CVS 出现于 1995.10.18” 经 openbsd.duckdb 核查为 fork 启动日（CVS 仓库最早 commit 时间），非 1.1 正式发布日——1.1 实为内部版本号 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］；OpenBSD 1.2 为首个公开发行的版本，发布时间经 openbsd.duckdb commit d8c59f67b872ee4d18dce483743f4096c202ff56（1996-07-16 “1.2”）确认为 1996 年 7 月；〔存疑：1.2 是否属严格意义的官方发行版存在口径张力——公开档案中一种口径以 2.0（1996-10）为首个 official release，认为 1.2 仅为沿用 NetBSD 版本序列的开发版标记；本章采“首个公开发行”表述并以 commit `d8c59f67b872ee4d18dce483743f4096c202ff56` 为版本标记依据，官方发行定性存疑保留〕；1.x 时期附加的加密组件为原始 SSH（1995 年外部实现，非 1999 年的 OpenSSH）与 SSLeay（SSL 协议的早期实现库），OpenSSH 直至 2.6（1999-12）才首发
