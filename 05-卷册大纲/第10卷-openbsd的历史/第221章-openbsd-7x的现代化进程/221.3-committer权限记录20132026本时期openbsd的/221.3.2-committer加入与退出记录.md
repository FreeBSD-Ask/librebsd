# 221.3.2 committer 加入与退出记录

**要点**：2013-2026 年间 OpenBSD committer 数量缓慢增长——新加入者多为 hackathons 参与者与持续贡献者；此时期加入的关键 committer 包括 Schwarze（mandoc）、Lindqvist（网络栈）等；老 committer 退出多因个人原因或精力转移

**史料**：OpenBSD committer 名单变更记录；CVS commit log 反映的活跃度（<https://cvsweb.openbsd.org/>）；邮件列表中 committer 加入公告 ［A］

**史观**：边缘者贡献：新加入 committer 多从边缘贡献者成长而来——Schwarze 在成为 committer 前长期以外部贡献者身份提交 mandoc 补丁，Lindqvist 在成为 committer 前长期以外部贡献者身份提交网络栈补丁，二者的成长路径是 “边缘者 → 核心者” 的典型

**辨析**：committer 的具体加入与退出时间以 CVS access log 与邮件列表公告为准——OpenBSD CVS 仓库的 access log 记录了 committer 权限变更，邮件列表中偶有加入公告；个别 committer 退出的具体原因在邮件列表中有时公开有时不公开

**文献**：OpenBSD committer 名单；CVS commit log [EB/OL]. <https://cvsweb.openbsd.org/>；OpenBSD 邮件列表档案 [EB/OL]. <https://marc.info/?laccopenbsd-misc> ［A］
