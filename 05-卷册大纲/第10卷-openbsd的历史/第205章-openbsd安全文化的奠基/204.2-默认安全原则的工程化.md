# 204.2 “默认安全” 原则的工程化

- 要点：OpenBSD “默认安全”（secure by default）原则体现在默认关闭非必要服务（如默认不启用 telnetd、ftpd）、默认启用加密（如 SSH 默认开启）、默认最小权限等多方面；该原则自 1996 年 fork 之初即确立；防火墙方面，ipf（Darren Reed（达伦·里德） 的 IP Filter）自 OpenBSD fork 前即存在于 NetBSD 代码库中（openbsd.db 显示 openbsd-src 仓库 1996-01-07 dm commit b6126525eb2a “from <beurton@fnet.fr>: Darren Reed's IP filter” 为 ipf 初始导入），OpenBSD 继承 ipf 至 2.9 版本，2001-06-24 kjell commit 148b55c022b1 “Initial import of pf, an all-new ipf-compatable packet filter” 引入 pf 替代 ipf（因 Darren Reed 修改 ipf 许可证引发争议），pf 随 OpenBSD 3.0（2001-12-01）首次发布；默认配置变更通过 Release Notes 详细记录
- 史料：openbsd.db openbsd-src 仓库 commit b6126525eb2a（1996-01-07 dm “from <beurton@fnet.fr>: Darren Reed's IP filter”，ipf 初始导入）、commit 148b55c022b1（2001-06-24 kjell “Initial import of pf, an all-new ipf-compatable packet filter”，pf 替代 ipf）；OpenBSD Release Notes 各版本默认配置变更记录（<https://www.openbsd.org/plus.html>）；OpenBSD **afterboot(8)** 手册页（<https://man.openbsd.org/afterboot.8>）

**OpenBSD/FreeBSD/Linux 同期默认安全配置对比（1996-2001）**：

| 默认项 | OpenBSD | FreeBSD 4.0（2000-03） | Linux（Debian/RHEL，2000） |
| --- | --- | --- | --- |
| sshd | 默认开启（自 2.6 起） | 4.0 含但未默认启用，4.1.1（2000-11）起默认 | 发行版各异，多数未默认 |
| telnetd | 默认关闭 | 默认附带 | 发行版各异 |
| ftpd | 默认关闭 | 默认附带 | 发行版各异 |

- 史观：总纲第 8 条——社区文化即技术资产：默认安全原则的工程化体现为具体的默认配置决策——默认关闭 telnetd/ftpd、默认开启 sshd、默认最小权限，每一项决策均通过 Release Notes 公开记录，使 “默认安全” 从口号物化为可审计的配置清单；总纲第 7 条——技术选择即政治选择：OpenBSD 以 pf 替代 ipf 的决策是政治选择——Darren Reed 修改 ipf 许可证条款后，OpenBSD 选择从头编写 pf 而非接受新许可证，以 “许可证纯洁性” 为预设宁可投入工程资源重写也不妥协
- 辨析：ipf 与 pf 的替代关系——ipf 自 1996 年 fork 前即存在于 NetBSD 代码库，OpenBSD 继承使用至 2.9（2001-05）；2001 年 Darren Reed 修改 ipf 许可证引发争议，OpenBSD 于 2001-06-24 引入 pf（commit 148b55c022b1）作为 ipf 兼容替代品，pf 随 OpenBSD 3.0（2001-12-01）首次发布；部分二手资料将 pf 引入时间误记为 2.4（1998），经 openbsd.db 核查 pf 首次 commit 为 2001-06-24；默认安全原则与同期 FreeBSD/Linux 的差异——FreeBSD 4.0（2000-03）默认启用 sshd 但仍默认附带 telnetd，Linux 各发行版默认配置因发行版而异（Debian 默认不启用任何网络服务，Red Hat 默认启用部分服务），OpenBSD 是同期默认关闭最多非必要服务的 Unix 系统
