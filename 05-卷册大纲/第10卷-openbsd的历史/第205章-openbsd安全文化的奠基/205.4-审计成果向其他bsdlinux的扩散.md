# 205.4 审计成果向其他 BSD/Linux 的扩散

**要点**：OpenBSD 审计成果通过 cross-BSD 协调（vendor branch 同步）反馈至 FreeBSD/NetBSD，部分修复被 Linux 发行版移植；OpenBSD 提出的 **strlcpy(3)**/**strlcat(3)**（1998-07-01 millert commit 1dc0268a4106 “add strlcpy/strlcat, safe and sensible string copy/append”，非 1996 年）、**arc4random(3)** 等 API 被 FreeBSD、NetBSD 与 Linux glibc 等采纳；strlcpy/strlcat 的设计目标是替代不安全的 **strncpy(3)**/**strncat(3)**，通过返回值始终为目标缓冲区大小（而非实际复制的字节数）使调用者能检测截断

**史料**：openbsd.duckdb openbsd-src 仓库 commit 1dc0268a4106（1998-07-01 millert “add strlcpy/strlcat, safe and sensible string copy/append”，lib/libc/string/strlcpy.c 与 strlcat.c 首次引入）；FreeBSD/NetBSD Security Advisories 中引用 OpenBSD 的记录（<https://www.freebsd.org/security/advisories/>、<https://www.netbsd.org/support/security/）；**strlcpy(3)>** 手册页（<https://man.openbsd.org/strlcpy.3>）；Linux Security Audit 项目文档（<https://www.linux.org.au/lsec/>）〔L1 代码/构建产物/L3 官方文档与公告〕

**史观**：总纲第 10 条——边缘者贡献：OpenBSD 作为边缘项目产出的 strlcpy/strlcat API 被 FreeBSD、NetBSD、Linux glibc、macOS libc 等主流系统采纳，是边缘者贡献至整个 Unix 生态的典型案例——一个由 millert 于 1998-07-01 在 OpenBSD 中编写的字符串处理函数，最终成为跨系统共享的安全 API 标准；总纲第 2 条——分离与聚合：审计成果从 OpenBSD 分离并向外聚合——strlcpy/strlcat 从 OpenBSD lib/libc/string/ 分离后聚合入 FreeBSD lib/libc/string/、NetBSD lib/libc/string/、glibc string/，每次聚合均通过 vendor branch 同步机制完成

**辨析**：strlcpy/strlcat 引入时间——openbsd.duckdb 显示 millert 于 1998-07-01 commit 1dc0268a4106 引入 strlcpy.c/strlcat.c/strlcpy.3，部分二手资料误记为 1996 年，实际引入时间为 1998-07-01；strlcpy/strlcat 被 glibc 采纳的过程曲折——glibc 维护者 Ulrich Drepper 长期拒绝引入 strlcpy（认为其鼓励截断而非确保缓冲区足够大），直至 2019 年 glibc 2.30 方引入；cross-BSD 协调机制通过 vendor branch 同步运作——OpenBSD 修复的安全漏洞通过 FreeBSD/NetBSD 的 vendor branch 导入对应版本，各系统的 Security Advisory 通常标注 “based on OpenBSD fix”

**文献**：FreeBSD Security Advisories [EB/OL]. <https://www.freebsd.org/security/advisories/>；NetBSD Security Advisories [EB/OL]. <https://www.netbsd.org/support/security/>；OpenBSD **strlcpy(3)** 手册页 [EB/OL]. <https://man.openbsd.org/strlcpy.3>；OpenBSD commit 1dc0268a4106 [G/OL]. <https://github.com/openbsd/src/commit/1dc0268a4106>；Linux Security Audit Project [EB/OL]. <https://www.linux.org.au/lsec/> ［A］
