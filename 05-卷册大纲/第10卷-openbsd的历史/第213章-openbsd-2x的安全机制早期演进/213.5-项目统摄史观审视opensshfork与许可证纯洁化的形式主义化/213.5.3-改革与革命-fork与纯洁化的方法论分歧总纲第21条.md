# 213.5.3 改革与革命——fork 与纯洁化的方法论分歧（总纲第 21 条）

**要点**：总纲第 21 条“革命与改革是历史方法论的分歧”指出“Linux 靠革命，BSD 靠改革。改革的困难远高于革命。破山中贼易，破心中贼难”。OpenSSH 史上，Ylönen 的商业化决策是“革命”——以新许可证模型（商业许可）替换自由许可，SSH 1.2.13+ 用户被迫接受商业许可或停止升级；OpenBSD 的 fork 与纯洁化是“改革”——在 SSH 1.2.12 基础上渐进审计与纯洁化而非从零重写，保留 SSH 1.2.12 的代码骨架与协议实现，移除非可移植代码与 GPL 组件使 OpenSSH 可在 BSD 许可下发布——改革保留了 SSH 1.2.12 技术传统的同时新增审计与纯洁化能力，工程复杂度远高于革命式的“许可证替换”。“破山中贼易，破心中贼难”——Ylönen 的“山中贼”是自由许可（革命以商业许可替换即可），OpenBSD 的“心中贼”是“在保留 SSH 1.2.12 技术传统的同时移除 GPL 组件与非可移植代码”的方法论张力——Provos 须赴加拿大移除加密与 GPL 组件以规避美国出口管制，Friedl 须替换 SSH 1.3 协议为 1.5 以避开专利约束，Beck 须处理 Makefile 以避开 RSA 专利——这一“心中贼”远比“山中贼”难以“破除”——但“破除”本身非目的，在保留技术传统的同时实现许可证合规才是 OpenBSD 改革的哲学

**史观**：总纲第 21 条——革命与改革是历史方法论的分歧：Ylönen 靠革命（商业许可替换自由许可），OpenBSD 靠改革（fork 与纯洁化保留 SSH 1.2.12 技术传统）——“改革的困难远高于革命”；总纲第 5 条——没有必然性，只有偶然性：OpenBSD 选择 fork 与纯洁化的改革路径是具体历史场景下的偶然决策（SSH 1.2.12 恰好是“最后一个自由到足以复用的版本”、Provos 恰好愿意赴加拿大工作、OpenBSD 恰好需要集成 SSH 至 2.6 发行版），非“必然优于”Ylönen 的革命式商业化——两种方法论各有代价

**辨析**：改革与革命的辨析须区分“方法论差异”与“优劣评判”——OpenBSD 的 fork 与纯洁化改革路径在保留技术传统方面优于 Ylönen 的革命式商业化，但在商业可持续性方面可能劣于革命——Ylönen 的商业化虽强迫用户接受商业许可但为 SSH 的持续开发提供了商业回报，OpenBSD 的 fork 与纯洁化虽保留了自由许可但 OpenBSD 项目从 OpenSSH 获得的商业回报有限（091.3.3 节记载“商业回报有限”）；两种方法论各有代价，不得以“改革优于革命”或“革命优于改革”的简单评判替代具体场景评估；【0 信任原则】“改革的困难远高于革命”是总纲的哲学论断，须以具体案例（Provos 赴加拿大移除加密与 GPL 组件的工程复杂度、Friedl 替换协议的法律约束、Beck 处理 Makefile 避开 RSA 专利的技术必要）实证支撑，不得仅凭哲学推论即断定；【0 信任原则·当事人自辩不免检】OpenBSD 阵营的“fork 即改革”叙事与 Ylönen 阵营的“商业化即革命”叙事均存在自利偏差——OpenBSD 阵营以“改革”定位 fork 使其占据道德高地，Ylönen 阵营以“革命”定位商业化使其占据商业可持续性高地，两种定位须经 comp.security.ssh Usenet 存档与 SSH Communications Security 官方声明交叉验证后方可采信
