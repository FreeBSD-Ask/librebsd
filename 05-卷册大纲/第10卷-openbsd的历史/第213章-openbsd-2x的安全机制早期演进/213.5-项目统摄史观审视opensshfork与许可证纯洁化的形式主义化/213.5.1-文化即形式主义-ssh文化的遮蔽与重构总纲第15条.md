# 213.5.1 文化即形式主义——SSH 文化的遮蔽与重构（总纲第 15 条）


> 84.5 节补足了 OpenSSH fork 自 SSH 1.2.12 的四层辩证链（批评—反批评—再回应—合图）及 84.5.5 项目统摄史观审视子节（从总纲第 13、19、21 条简短切入），本节从项目史观总纲第 15、19、21、13 条切入并增设自反层，审视 fork 与许可证纯洁化争议在历史书写中的形式主义化运作。

**要点**：总纲第 15 条“文化即形式主义”指出“传统在形式主义化过程中被遮蔽与重构”。SSH 文化——Ylönen 于 1995 年创造 SSH 协议、用数年开发建立的技术传统——在 OpenSSH 的“纯洁化”叙事中经历形式主义化重构：SSH 1.2.12 被重构为“许可证混乱的起点”（“cleaning up the license mess”），Ylönen 的数年原创贡献被重构为“需要被清理的遗留物”，OpenBSD 的 fork 与纯洁化工作被重构为“解放”（“freeing SSH”）。这一重构不是“技术必要”的自然呈现而是形式主义权力运作——以“许可证纯洁”的形式主义标准（BSD 许可、无 GPL 传染、无 RSA 专利约束）衡量 SSH 1.2.12，使 SSH 文化的核心价值（协议设计、安全架构、跨平台部署能力）在“纯洁化”叙事中被遮蔽。OpenSSH 官方历史虽承认"derivative of the original free ssh 1.2.12 release from Tatu Ylönen“与”Parts of OpenSSH still bear Tatu's license"，但归属承认在“纯洁化”叙事框架下被弱化为“起点承认”而非“核心贡献承认”——传统在形式主义化过程中被遮蔽与重构，但被遮蔽不等于消亡——OpenSSH 仍承载 Ylönen 的部分许可证与代码，SSH 文化的生命力在 fork 后延续

**史料**：原材料/哲学/项目统摄史观/第 25 章.md 总纲第 15 条原文；OpenSSH 项目历史页面（<https://www.openssh.com/history.html>，记载“freeing SSH”、“cleaning up the license mess”、"derivative of the original free ssh 1.2.12 release from Tatu Ylönen“、”Parts of OpenSSH still bear Tatu's license"）；OpenSSH LICENCE 文件（<https://cvsweb.openbsd.org/src/usr.bin/ssh/LICENCE>）；84.5.3 节再回应与许可证纯洁化争议深化记录 ［A］

**史观**：总纲第 15 条——文化即形式主义：SSH 文化在“纯洁化”叙事的形式主义化过程中被遮蔽与重构——传统在形式主义化过程中被遮蔽与重构；总纲第 2 条——历史是形式主义化的非存在：本书对“SSH 文化被遮蔽”的书写本身亦是当下主体的形式主义重构，不宣称呈现“真实的 SSH 文化”

**辨析**：文化遮蔽的辨析须区分“法律必要的技术纯洁化”与“叙事形式主义化的文化遮蔽”——OpenBSD 移除 GPL 组件（libgmp）与非可移植代码在法律层面是技术必要（使 OpenSSH 可在 BSD 许可下发布、避开 RSA 专利约束），部分是形式主义化的文化遮蔽（“纯洁化”叙事将 Ylönen 的原创贡献重构为“需要被清理的起点”）；前者须保留为技术必要记录，后者须以形式主义批判审视；【0 信任原则】“SSH 文化被遮蔽”的论断须经 OpenSSH 官方历史页面原文、OpenSSH LICENCE 文件、comp.security.ssh Usenet 存档的比对交叉验证，不得仅凭哲学推论即断定“遮蔽”；【0 信任原则·当事人自辩不免检】OpenSSH 官方历史是 OpenBSD 阵营的单方面叙事，其“freeing SSH”与“cleaning up the license mess”措辞存在自利偏差，须经 Ylönen 阵营的对称呈现后方可评估
