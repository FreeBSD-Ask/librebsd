# 209.4 多元群体贡献


- 要点：OpenBSD 生态多元群体贡献包括 de Raadt 本人（南非裔加拿大人，1968 年生于比勒陀利亚，1977 年随家移居加拿大）、Niels Provos（德国，OpenSSH 主导开发者，bsd_commits.db openbsd-src 仓库 provos 贡献者记录）、Jun-ichiro itojun Hagino（日本，IPv6 贡献者，2007-10-29 逝世，openbsd.db openbsd-src 仓库最后 commit 为 2007-08-03 commit `44be632afd37` “curly brace issues...”）、Damien Miller（澳大利亚，OpenSSH portable 维护者）、Bob Beck（加拿大，LibreSSL；bsd_commits.db openbsd-src 仓库 beck commit 8b23add8c74b 2018-07-13 引入 unveil）；OpenBSD 社区具有显著的跨国特征，贡献者来自北美、欧洲、亚洲、大洋洲
- 史料：OpenBSD CVS/Git commit log 中贡献者地理分布（<https://cvsweb.openbsd.org/、https://github.com/openbsd）；OpenBSD> 邮件列表中贡献者互动记录（<https://marc.info/?l=openbsd-misc）；bsd_commits.db> openbsd-src 仓库 contributors 表中的 provos、itojun、djm、beck 等贡献者活动时间；**【2026-07-30 itojun 逝世一手纪念页面考据·7au 条目】**undeadly.org 2007-10-30 纪念文章（**<https://undeadly.org/cgi?action=article&sid=20071030220114>**）原文载 “Jun-ichiro ‘itojun’ Itoh Hagino passed away on October 29, 2007 at the age of 37”，并载葬仪时间地点（2007-11-06 守夜、2007-11-07 葬礼，东京临海斎場）；itojun 个人站点 **<http://www.itojun.org/>**；BSDTalk 115 采访（**<http://bsdtalk.blogspot.com/2007/06/bsdtalk115-jun-ichiro-itojun-itoh.html>**）；bsd_commits.db openbsd-src 仓库 itojun 最后 commit 为 2007-08-03 commit `44be632afd37` “curly brace issues...”（逝世前约 3 个月）
- 史观：总纲第 10 条——边缘者贡献：OpenBSD 作为边缘项目的多元群体贡献——多位核心开发者来自非美国地区，与 Linux 内核早期以美国/欧洲为中心的贡献者分布有显著差异；总纲第 8 条——社区文化即技术资产：跨国贡献者群体使 OpenBSD 文化不限于北美工程传统，融入日本工程美学（itojun 的 IPv6 实现）、德国密码学严谨（Provos 的 OpenSSH 加密设计）等多元文化元素
- 辨析：多元群体贡献的发掘基于 commit log 与邮件列表记录——de Raadt 1968 年生于南非比勒陀利亚，1977 年随家移居加拿大，其反战立场（2003-04 伊拉克战争公开言论导致 DARPA 撤销 OpenBSD 项目约 230 万 USD 资助）对项目资金结构产生长期影响；DARPA 撤资的具体时间点是 2003-04-21 前后（DARPA 项目经理 Jan Cargnelli 通知 University of Calgary 的 POSSE 计划负责人），具体金额 230 万 USD 涵盖原定的 2003-2008 年 5 年资助；de Raadt 本人在 misc@ 邮件列表 2003-04 的相关发言须逐份核对
