# 209.3 OpenBSD 的发行文化与 CD/海报传统


- 要点：OpenBSD 自 2.0（1997-06-01 发布）起保持每年 5 月与 11 月 6 个月固定发布周期传统——OpenBSD 7.9（2026-05-19 发布）是第 60 个 release，从未出现因外部事件推迟发布的情况（OpenBSD 各版本发布日期均见 <https://www.openbsd.org/> 各版本页面）；CD 封面艺术（每版由不同艺术家创作，如 3.4 的 Puffy Hood 由 Tyson Ads 创作）与 release song（发布歌曲，3.4 为“The Legend of Puffy Hood”）构成独特的发行文化；该传统自 2.x 系列延续至 7.x 系列
- 史料：OpenBSD 各版本 CD 封面艺术与 release song 存档（<https://www.openbsd.org/lyrics.html）；OpenBSD> Release Notes（<https://www.openbsd.org/plus.html）；OpenBSD> 邮件列表中关于发行传统的讨论（<https://marc.info/?l=openbsd-misc）；OpenBSD> 3.4 Release Page（<https://www.openbsd.org/34.html，明确发布日期> Nov 1, 2003）
- 史观：总纲第 8 条——社区文化即技术资产：发行文化是 OpenBSD 社区文化资产——CD 封面艺术与 release song 将工程发布升格为文化仪式，使每次 release 成为社区认同的强化节点；总纲第 5 条——组织结构塑造技术路径：6 个月固定发布周期塑造 OpenBSD 的开发节奏——所有功能须在 cutoff 日期前合入，否则顺延至下个 release
- 辨析：原叙事中“2003 年因 Iraq War 推迟 3.4 发布”的说法与官方记录不符——OpenBSD 3.4 于 2003-11-01 按期发布（<https://www.openbsd.org/34.html），与> Iraq War（2003-03-20 开始）无推迟关系；DARPA 撤资事件发生于 2003-04，亦未影响 3.4 发布；6 个月发布周期自 OpenBSD 2.0（1997-06-01）起确立，至 2026-05-19 的 7.9 共 60 个 release，时间间隔稳定
