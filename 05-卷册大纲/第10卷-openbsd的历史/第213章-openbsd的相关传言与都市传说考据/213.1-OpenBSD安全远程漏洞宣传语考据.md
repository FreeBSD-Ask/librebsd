# 213.1 OpenBSD 安全远程漏洞宣传语考据——“Only one remote hole” 的传播与争议

**要点**：OpenBSD 安全宣传语的演化史是开源项目自我品牌化（branding）的典型案例——其措辞变化与实际的漏洞事件精确对应：（1）“Five years without a remote hole in the default install!”（约 1997-2002 年），声称默认安装五年无远程漏洞，这一宣称基于 OpenBSD 项目的安全审计实践——代码逐行审计、最小化默认服务、安全优先的设计哲学；（2）2002 年 6 月，Internet Security Systems 的 Mark Dowd 在 OpenSSH 的 challenge-response 认证代码中发现了漏洞（CVE 编号缺失于早期记录中），该漏洞允许攻击者远程获取 root 权限，因 OpenSSH 在当时已广泛用于多数操作系统，影响远超 OpenBSD 本身。宣传语随之调整为“One remote hole in the default install, in nearly 6 years!”——承认“一个远程漏洞”的事实，但维持“近六年”的时间尺度；（3）2007 年 3 月 13 日，Core Security Technologies 的 Alfredo Ortega 披露了另一个网络相关远程漏洞，宣传语再次更新为"Only two remote holes in the default install, in a heck of a long time!"——此版本至今（2026 年）仍然是官网的口号。
这一宣传语的批评者指出：（a）OpenBSD 的默认安装中开启的服务极少（几乎无网络侦听端口），因此“默认安装无远程漏洞”是一个相对较低的安全门槛；（b）ports 树中包含未经审计的第三方软件，用户安装或配置不当即可引入安全风险——但 OpenBSD 官方立场认为该宣传语明确限定于“默认安装”，在此限制下该宣称是准确的。Debian/Ubuntu 等 Linux 发行版的默认安装同样极少有远程漏洞（因其默认不启用远程服务），但 OpenBSD 独有的安全审计文化——逐行代码审计、strlcpy/strlcat 等安全 API 替换、W^X 内存保护、pledge/unveil 沙箱——使得“默认安装”的安全基础比多数 Linux 发行版更为坚实。2017 年 DEF CON 上 Ilja van Sprundel 的演讲“Are all BSDs created equally?”虽然指出"Bugs are still easy to find in those kernels, even in OpenBSD“，但仍承认 OpenBSD 是三 BSD 中安全的”clear winner“。2019 年匿名研究者”Stein“在 CCC 的演讲”A systematic evaluation of OpenBSD's mitigations"则提出了更尖锐的批评——认为 OpenBSD 的诸多缓解措施“充其量无用且基于纯粹的运气与迷信”，建议更加理性的方法。

**史料**：OpenBSD 官网安全声明（openbsd.org/security.html，含宣传语的历史版本）。Mark Dowd 漏洞公告——见 Internet Security Systems 2002-06 的安全公告、OpenBSD errata 公告 2002-06-26（openssh challenge-response vulnerability，remote root exploit）。Alfredo Ortega 漏洞公告——Core Security Technologies 2007-03-13 公告。Ilja van Sprundel, “Are all BSDs created equally? — A survey of BSD kernel vulnerabilities”, DEF CON 25 / 34C3（2017-12），定性为“OpenBSD 是三 BSD 中安全的 clear winner”但发现内核漏洞仍易找到。Stein (anonymous), “A systematic evaluation of OpenBSD's mitigations”, 36C3 (2019)，批评 OpenBSD 的缓解措施“useless at best and based on pure luck and superstition”，倡导更理性的缓解设计。〔禁引来源·仅作线索·须与一手史料交叉验证·不得直接采信〕（宣传语演化、OpenSSH 漏洞细节与批评意见的综合叙述以 OpenBSD 官网安全声明 openbsd.org/security.html 为准）。［A］

**史观**：总纲第 7 条“安全即自由的保障”——OpenBSD 的“默认安装安全”哲学与 BSD 许可证的“自由分发”之间是一体两面：宽松的许可证使 OpenBSD 的代码（包括其安全改进）可被任何人自由使用与镜像，而严格的安全审计则确保这份“自由”不被漏洞所背叛。总纲第 3 条“没有绝对的善或恶的形式主义”——“Only two remote holes” 的宣传语本身就是形式主义化的品牌建构：它将十年仅两个漏洞叙述为“优异”，但批评者指出这一数字部分源于“默认安装几乎不侦听网络”——即形式主义条件的选择决定了叙事的结论。项目统摄史观的自反性要求是：在呈现 OpenBSD 的安全成就时须同时对宣传语的“形式主义前提”保持自觉。
