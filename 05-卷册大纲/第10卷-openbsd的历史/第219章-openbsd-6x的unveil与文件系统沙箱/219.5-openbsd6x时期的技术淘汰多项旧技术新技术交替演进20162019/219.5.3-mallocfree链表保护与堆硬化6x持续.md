# 219.5.3 malloc → free 链表保护与堆硬化（6.x 持续）

**要点**：OpenBSD 4.0（2006-11 发布）引入 Otto Moerbeek（奥托·穆尔贝克） 设计的 malloc 替代实现，加入随机化、guard page、free 后填充等安全特性；OpenBSD 6.x 时期（2016-2019）持续改进 malloc 安全——free 链表指针保护、堆元数据随机化、use-after-free 检测；这些改进让堆溢出与 use-after-free 攻击更难利用；可视为“朴素 malloc→ 安全硬化 malloc”的持续演进

**史料**：OpenBSD 4.0/4.4 Release Notes malloc 部分（<https://www.openbsd.org/40.html>、<https://www.openbsd.org/44.html>）；OpenBSD 6.x Release Notes malloc 改进部分（<https://www.openbsd.org/plus.html>）；Otto Moerbeek 邮件列表帖（<https://marc.info/?laccopenbsd-tech>）；openbsd.duckdb openbsd-src 仓库 malloc 相关 commit

**史观**：总纲第 10 条——动手者创造历史：Moerbeek 动手改进 malloc 安全特性——malloc 替代实现被 OpenBSD 4.0 采用并成为堆安全的核心机制，但 Moerbeek 的名字鲜为公众所知
