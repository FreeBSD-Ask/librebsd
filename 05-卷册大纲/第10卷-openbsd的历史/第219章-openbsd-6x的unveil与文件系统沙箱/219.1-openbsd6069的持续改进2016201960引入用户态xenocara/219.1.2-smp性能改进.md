# 219.1.2 SMP 性能改进

**要点**：OpenBSD 6.1（2017-04 发布）改进 SMP 性能——细粒度锁扩展、网络栈多队列优化；6.4 进一步改进调度器；SMP 性能改进让 OpenBSD 在多核网络设备部署中表现提升，但仍不及 FreeBSD SMPng 与 Linux——OpenBSD 6.x 仍保留 big-lock 模型作为安全简化手段

**史料**：OpenBSD 6.1/6.4 Release Notes SMP 部分（<https://www.openbsd.org/61.html>、<https://www.openbsd.org/64.html>）；tech@ 邮件列表 SMP 讨论（<https://marc.info/?laccopenbsd-tech>）；openbsd.duckdb openbsd-src 仓库 SMP 相关 commit

**史观**：总纲第 9 条——经验优先：SMP 性能改进是 OpenBSD 对 big-lock 模型的渐进改进——在不放弃 big-lock 安全简化的前提下，通过细粒度锁扩展与网络栈多队列优化提升多核性能，这一路径是“安全优先于性能”哲学下的工程折中

**辨析**：SMP 性能改进的具体数字以同硬件同负载的 Phoronix 等基准测试为准——OpenBSD 6.1 相比 6.0 在网络吞吐场景有 10-20% 提升，但仍落后 FreeBSD/Linux 20-50%；big-lock 模型的具体改进幅度以 OpenBSD Release Notes kernel 部分为准
