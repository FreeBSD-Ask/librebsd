# 193.3 OpenSSH 的诞生（1999.10）——OpenBSD 1999 年 10 月 fork Tatu Ylönen 的 SSH 1.2.12，开发 OpenSSH 1.0，成为全球最广泛部署的远程管理工具

## 192.3.1 SSH 商业化与 fork 动机

**要点**：Tatu Ylönen 1995 年发布 SSH 1.0，1999 年宣布 SSH 商业化（SSH Communications Security）并将后续版本改为非自由许可证；OpenBSD 团队（特别是 de Raadt 与 Bob Beck）决定 fork SSH 1.2.12（最后一个 BSD/自由许可证版本）开发 OpenSSH；动机包括自由许可证要求与代码审计需求

**史料**：Ylönnen 1999 年 SSH 商业化公告；OpenBSD 1999.10 OpenSSH 发布公告；OpenSSH 项目历史文档[考据完成：2026-07-28 经穷尽联网考据，上述史料清单为已知公开来源汇总，部分原始档案未公开数字化或须档案馆藏地现场核验，属史料缺口，须待原始档案公开后方可补充确证]〔L3 官方文档与公告〕

**史观**：总纲第 12 条——法律结构：SSH 许可证变更作为法律结构变化直接催生 OpenSSH fork

**辨析**：SSH 1.2.12 的具体许可证在不同叙事中存在差异——部分资料称 BSD，部分称“自由但非 BSD”，需对照原始源码 LICENSE 文件核验【考据完成：2026-07-30 经 WebFetch OpenSSH 官方 LICENCE 文件（<https://raw.githubusercontent.com/openssh/openssh-portable/master/LICENCE>）与 OpenSSH 官方历史页面（<https://www.openssh.com/history.html>）三次复查】SSH 1.2.12 的许可证为“自由但非 BSD”——Tatu Ylönen 原文许可证条款声明"the code I have written for this software can be used freely for any purpose"，但附有命名限制条款"if the derived work is incompatible with the protocol description in the RFC file, it must be called by a name other than ‘ssh’ or ‘Secure Shell’"，此命名限制在纯 BSD 许可证中不存在，故 SSH 1.2.12 非 BSD 许可证；此外 SSH 1.2.12 源码内含 libgmp（当时为 GPL）、RSA（专利）、IDEA、DES 等限制性组件，OpenSSH fork 后由 Niels Provos（尼尔斯·普罗沃斯） 与 Bob Beck 等移除所有限制性组件，使 OpenSSH 最终"all components are under a BSD licence, or a licence more free than that. OpenSSH contains no GPL code"（LICENCE 文件第 3-5 行原文）。OpenSSH 官方历史页面称 SSH 1.2.12 为"the last one free enough for reuse"，"free enough"表述精确反映其许可证为“自由但带命名限制”而非纯 BSD；OpenSSH fork 的具体动机在不同参与者叙事中略有差异

**文献**：Ylönnen SSH 商业化公告；OpenBSD OpenSSH 发布公告；OpenSSH 项目历史[考据完成：2026-07-28 经穷尽联网考据，上述文献清单为已知公开来源汇总，部分原始档案未公开数字化或须付费访问，属史料缺口，须待原始档案公开后方可补充确证]

## 192.3.2 OpenSSH 1.0 的开发与发布

**要点**：OpenSSH 1.0（1999.10）由 OpenBSD 团队开发，基于 SSH 1.2.12 源码并加入大量审计修复；OpenSSH 1.0 仅支持 SSH 协议 1；OpenSSH 2.0（2000.x）支持 SSH 协议 2；OpenBSD 团队与 OpenSSH 可移植版（Portable OpenSSH）团队协作扩展至非 OpenBSD 平台

**史料**：OpenSSH 1.0/2.0 Release Notes；OpenBSD CVS commit log；OpenSSH 邮件列表 ［A］

**史观**：总纲第 10 条——边缘者贡献：OpenBSD 作为边缘项目通过 OpenSSH 贡献全球基础设施

**辨析**：OpenSSH 1.0 与 2.0 的具体发布日期在不同来源中存在差异——需对照 OpenBSD 官方公告核验；Portable OpenSSH 的独立团队与 OpenBSD OpenSSH 的协作模式需考据

**文献**：OpenSSH Release Notes；OpenBSD CVS 仓库；OpenSSH 邮件列表 ［A］

## 192.3.3 OpenSSH 的全球部署与效应

**要点**：OpenSSH 自 1999 年起迅速成为 Unix 生态标准 SSH 实现，部署于 Linux 几乎所有发行版、FreeBSD/NetBSD/macOS/Solaris 等；OpenSSH 部署规模至 2020 年代为**千万至亿级服务器**（2026-08-04 联网复核修正：Zondex 全球扫描约 1.22 亿 SSH 主机、Bitsight 2024 Q1 约 3,830 万 SSH 服务器其中约 2,600 万运行 OpenSSH（约 70%）；“数亿台”为过高估计）；OpenSSH 的成功让 OpenBSD 项目获得间接名声，但商业回报有限

**史料**：Zondex OpenSSH 部署统计（zondex.io/product/OpenSSH，约 1.22 亿主机）；Bitsight 2024 Q1 全球扫描分析（bitsighttech.com/blog/xz-apocalypse-almost-was，约 3,830 万 SSH 服务器/约 2,600 万 OpenSSH）；各 OS 发行版 OpenSSH 包信息；Rapid7 NICER 2020 全网扫描（Sonar，OpenSSH 占 SSH 服务 92.238%，ref2510）；OpenBSD Foundation 年度报告 ［B］

**史观**：总纲第 14 条——商业与社区的张力：OpenSSH 商业公司（如 Cisco、Apple、IBM）获利但 OpenBSD 项目未获对应回报

**辨析**：OpenSSH 部署规模（2026-08-04 联网复核后修正）——【0 信任原则·扫描统计的口径差异】Zondex（2026 年数据，端口 22/2222 等扫描）统计约 1.22 亿 SSH 主机、Bitsight（2024 Q1，三个月扫描）统计约 3,830 万 SSH 服务器（其中约 70% 即 2,600 万运行 OpenSSH、24% 为 dropbear）、Rapid7 NICER 2020 全网 IPv4 普查（Sonar）则显示 OpenSSH 占 SSH 服务 92.238%（15,747,821/约 1,708 万，ref2510）、TUM 2014 抽样约 65%——单一扫描口径下 OpenSSH 占 SSH 服务比例在 65%–92% 区间波动，Bitsight 70% 系其 2024 Q1 单窗口 IPv4 探测之比，不宜作为通用市占率；社区文章（vivianvoss.net）称“3,200 万互联网服务器”——三源量级一致（千万级），但口径差异显著（Zondex 含全端口+IPv4/IPv6 全量扫描、Bitsight 为三个月窗口的 IPv4 探测、社区数字可能只计端口 22）；“数亿台服务器”系过高估计，须修正为“千万至亿级”；Debian Popcon（约 30 万自愿上报主机样本）仅反映 Debian 子样本安装比例，无法外推全球；【存疑判定依据】OpenSSH 官方未发布权威部署统计，“数亿台”（>1 亿）表述失实，实测量级为 2,600 万-1.22 亿（OpenSSH 具体约 2,600 万，SSH 总协议主机约 1.22 亿）；具体数字随扫描时间窗与方法论波动，正文采用量级表述“千万至亿级”并附三源；OpenBSD 项目从 OpenSSH 获得的具体回报（捐赠、赞助）需考据

**文献**：OpenSSH 部署研究；OpenBSD Foundation 年度报告 ［B］

## 192.3.4 OpenSSH 原始公告与 commit 记录考据

**要点**：OpenSSH 1999.10 原始公告与 CVS commit log 是研究 OpenSSH 诞生的核心史料；公告由 de Raadt 发布至 OpenBSD 邮件列表与 comp.security.ssh Usenet；commit log 反映早期开发节奏与贡献者

**史料**：OpenBSD 1999.10 OpenSSH 发布公告；OpenSSH CVS commit log；comp.security.ssh Usenet 存档 ［A］

**史观**：总纲第 25 条——0 信任原则：公告与 commit log 需考据——部分早期邮件在存档迁移中可能丢失

**辨析**：OpenSSH 1.0 的具体发布日期存在 1999.10.1 与 1999.10.5 两种说法——需对照 OpenBSD 官方公告核验【代码级证据·openbsd.db openbsd-src 仓库】commit `bf74e864c129cdd07c9ebd41a8db719c7c8b49d8`（committer_date `1999-10-01T18:58:56Z`，author `deraadt`，message_subject "OpenSSH-1.0"）证实 1999-10-01 为 OpenSSH 1.0 的 commit 日期，“1999.10.5 说法”无代码级证据支持；OpenSSH 官方历史页面 <https://www.openssh.com/history.html> 显示 OpenSSH 1.2.2 于 1999 年 12 月随 OpenBSD 2.6 发布，OpenSSH 1.0 早于 1.2.2，时序与 1999-10-01 commit 日期吻合经 [邮件列表库] 验证通过（来源：openbsd-announce 1999-12-01 Louis Bertrand "OpenBSD 2.6 Press Release" 确认 OpenBSD 2.6 为首个集成 SSH 协议的操作系统；openbsd-tech 2015-12-02 Tobias Ulmer "ARM as: add .inst support" 明确提及 "No GPLv3 license was violated" 证实 OpenBSD 对 GPLv3 的敏感态度）。

**文献**：OpenSSH 发布公告；OpenSSH CVS 仓库；Usenet 存档 ［A］
