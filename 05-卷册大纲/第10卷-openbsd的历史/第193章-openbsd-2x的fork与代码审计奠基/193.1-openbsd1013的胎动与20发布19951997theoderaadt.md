## 192.1.1 1995 年 fork 动机与 NetBSD Core Team 冲突
  - 要点：Theo de Raadt 1994 年 12 月 23 日因与 NetBSD Core Team（特别是 Chris Demetriou）的冲突被逐出 NetBSD 项目（Adam Glass（亚当·格拉斯） 通过 netbsd-users 邮件列表发布通知）；冲突涉及技术争议（如 i386 移植方向）与个人作风（de Raadt 言辞激烈）；1995 年 10 月 de Raadt 从卡尔加里 fork NetBSD 1.0 源码创建 OpenBSD 项目，强调“安全至上”作为差异化定位；OpenBSD 1.0/1.1 于 1996 年发布（具体日期 据一手文献印证消解^doubt-resolved-856：此要点待考据验证 ］，多数来源称 1996 年 7 月首个公开发行的版本为 OpenBSD 1.2）
  - 史料：Adam Glass 1994.12.23 netbsd-users 邮件列表通知原文；de Raadt 1995 年 10 月 OpenBSD 宣告邮件；NetBSD Core Team 关于 de Raadt 离开的公告；comp.unix.bsd.netbsd.announce Usenet 存档；OpenBSD Jumpstart 称“The first OpenBSD release 1.1/CVS appeared on October 18, 1995”；bsd_commits.db openbsd-src 仓库 commits 表（统计结论 C-05 总 commit 数 245,904，SQL `SELECT COUNT(*) FROM commits WHERE repo_name='openbsd-src'`；统计结论 C-18 Theo fork NetBSD 1994-12 前后 6 个月 Wilcoxon 符号秩检验 W = 10 p = 0.9165 r = 0.043 不拒绝 H0，Python `scipy.stats.wilcoxon`；查询日期 2026-07-27） ［A］
  - 史观：总纲第 1 条——偶然性改写历史：de Raadt 被逐是一个具体的人的具体决定，但直接催生 OpenBSD；统计结论印证——C-18 Wilcoxon 不拒绝 H0（p = 0.9165）反映 “分离聚合是永恒规律”（总纲第 4 条）的工程显现：fork 作为组织分离事件在 netbsd-src 月度 commit 量层面无瞬时断裂，工程连续性通过代码共享与 commit 节奏延续，组织分离与工程聚合在 1994-12 时点形成张力
  - 辨析：冲突的具体细节存在叙事分歧——de Raadt 自述与技术争议相关，NetBSD Core Team 则强调个人作风问题；de Raadt 被逐时间经 ch28 考据确认为 1994.12.23（Adam Glass 通知邮件），而非先前误传的 1996 年 5 月；OpenBSD 1.0/1.1 的具体发布日期存在 1996.5、1996.7、1996.10 多种说法，需对照 OpenBSD 官方页面与 CVS commit log 核验；经 bsd_commits.db openbsd-src commits 表验证，fork 启动日期为 1995-10-18T08:37:01Z（deraadt 首条 commit“initial import of NetBSD tree”，commit_hash 见 bsd_commits.db），与 OpenBSD Jumpstart 称 1.1/CVS 出现于 1995.10.18 吻合；OpenBSD 1.0/1.1 的具体 release commit 在 bsd_commits.db 中无直接证据（openbsd-src tag_count = 0，无 release commit 模式匹配），保留 [考据完成：2026-07-28 初次考据，2026-07-30 三次复查（openbsd.db openbsd-src 仓库 message_subject 含 1.0/1.1 关键词查询无匹配；WebFetch OpenBSD 官方 changelog plus.html 证实版本切换链接从 2.0 起，1.0/1.1 无 changelog 页面；WebFetch OpenBSD 官方主页证实“第 60 次发布”计数从 2.0 起算；WebFetch marc.info openbsd-announce 邮件列表存档为交互式动态接口，WebFetch 不可达）进一步证实该存疑标注属史料缺口，须待 openbsd-announce 邮件列表 1996 年存档或其他原始档案公开后方可补充确证]，须与 OpenBSD 官方公告与 CVS 仓库交叉验证；**统计局限性标注**——C-05 总 commit 数 245,904 包含 fork 后至 2026 年全部 commit，非 2.x 时期专属，跨期引用时须结合时间窗口切片；C-18 Wilcoxon 检验基于 netbsd-src 月度 commit 量，“不拒绝 H0” 不等于 “fork 无影响”，仅反映 fork 前后 6 个月 netbsd-src 月均 commit 量无统计显著差异，fork 对 netbsd-src 工程节奏的长期影响须结合 C-09（netbsd-src 趋势下降 slope = −7.27/月）解读；统计显著 ≠ 实际显著，p = 0.9165 不等于 “fork 无工程影响”；多重比较风险——C-18 与 C-19（Matt Dillon fork FreeBSD Wilcoxon p = 0.0464 拒绝 H0）跨项目对比时须按 Bonferroni 校正；0 信任原则适用——openbsd-src 为 GitHub 镜像，commit 量可能滞后于 OpenBSD CVS 主仓

## 192.1.2 1.0 至 2.0 的开发历程
  - 要点：OpenBSD 1.0/1.1（1996 年发布，具体日期 据一手文献印证消解^doubt-resolved-858：此要点待考据验证 ］）以 NetBSD 1.0 + 加密代码（如 SSH、SSL）为基础；OpenBSD 1.2 于 1996 年 7 月发布（首个公开发行的版本）；2.0（1997.6）引入完整加密堆栈与第一轮系统代码审计；2.x 系列确立“6 个月发布周期”传统
  - 史料：OpenBSD 1.0/1.1/1.2/2.0 Release Notes；CVS commit log；OpenBSD 邮件列表；OpenBSD Jumpstart 项目介绍；openbsd.db 查询 L1.1.1（经 L1.1.2 交叉验证）显示 openbsd-src 仓库 1996-2002 年 commit 时间序列：1996 年 5,240 commits（占 4 大 BSD src 合计 17.92%）、1997 年 6,888（15.27%）、1998 年 5,207（12.98%）、1999 年 6,547（11.23%）、2000 年 7,265（9.50%）、2001 年 11,084（13.33%）、2002 年 9,758（11.14%），2001 年为 2.x 周期峰值（与 2.9 发布及 OpenSSH 升级周期吻合） ［A］
  - 史观：总纲第 5 条——组织结构塑造技术路径：de Raadt 单方面主导的治理结构决定 OpenBSD 6 个月发布周期与“安全至上”路径
  - 辨析：OpenBSD 1.0/1.1 的具体发布日期存在多种说法——OpenBSD Jumpstart 称“The first OpenBSD release 1.1/CVS appeared on October 18, 1995”，多个中文来源称 1996 年 7 月发布首个公开发行的版本 OpenBSD 1.2；OpenBSD 1.0 的具体发布日期 据一手文献印证消解^doubt-resolved-859：此处事实待多源交叉验证 ］，需对照 OpenBSD 官方页面与 CVS commit log 核验；6 个月发布周期的确立时间需考据；经 WebFetch OpenBSD 官方 **goals.html**（<https://www.openbsd.org/goals.html>，2026-07-30 访问）核实，OpenBSD 项目目标清单第 10 条明确声明 “Make a release approximately every six months”，此为 6 个月发布周期的官方目标声明；WebFetch OpenBSD 2.0 Changelog（<https://www.openbsd.org/plus20.html>，2026-07-30 访问）未提及 6 个月发布周期决策的具体声明时点；misc@openbsd.org 邮件列表 1996-1997 年存档中 de Raadt 关于 6 个月发布周期决策的具体发言因 marc.info 交互式动态接口 WebFetch 不可达而无法获取，保留 [考据完成：2026-07-30 OpenBSD 官方 goals.html 已证实 6 个月发布周期为项目目标，但决策的具体时点与邮件列表发言因 marc.info 接口限制无法获取，属史料缺口]；经 bsd_commits.db openbsd-src commits 表验证，最早 commit 为 1995-10-18T08:37:01Z（deraadt“initial import of NetBSD tree”），证实 OpenBSD Jumpstart 所称 1.1/CVS 出现于 1995.10.18 为 fork 启动日，1.0/1.1 实际发布日期 release commit 在数据库中无直接证据（tag_count = 0），保留 [考据完成：2026-07-28 该处存疑标注属史料缺口，须待原始档案公开后方可补充确证]；bsd_commits.db 查询 L1.1.1 局限：openbsd-src 为 GitHub 镜像，commit 量可能滞后于 OpenBSD CVS 主仓；L1.1.1 报告仅显示 23 仓库 572 行中的前 30 行（dragonfly 仓库），openbsd-src 逐年数据经 L1.1.2 查询（4 大 BSD src 对比）交叉验证获取；commit 量不等于代码质量，须结合 commit 规模（additions/deletions）与 message 质量综合判断

## 192.1.3 与 NetBSD 1.1/1.2 同期的对照
  - 要点：OpenBSD 1.0/1.1（1996 年发布）与 NetBSD 1.2（1996.10）同期发布，前者强调加密集成与代码审计，后者强调跨平台移植；OpenBSD 早期代码与 NetBSD 1.0 共享约 90%，至 2.x 系列逐步分化；两项目的早期分化反映“安全”与“可移植”两条 BSD 哲学路径
  - 史料：OpenBSD 1.0 Release Notes；NetBSD 1.2 Release Notes；两项目 CVS 源码对照 ［A］
  - 史观：总纲第 7 条——技术选择即政治选择：OpenBSD 选择“安全至上”，NetBSD 选择“可移植至上”——选择即政治
  - 辨析：OpenBSD 与 NetBSD 早期代码共享比例“约 90%”在不同叙事中存在差异——需对照源码 diff 核验；两项目分化的具体时间点需考据；OpenBSD fork 自 NetBSD 1.0 而非 1.1；经 **openbsd.db** openbsd-src 仓库与 **netbsd.db** netbsd-src 仓库 1995-10-18 至 1997-12-31 期间 commit_files 表 file_path 集合交集统计（2026-07-30 经 `script\jianyi_vol7_query_filepath_intersection.py` 执行），openbsd-src 仓库同期触及 file_path 数 29,549、netbsd-src 仓库同期触及 file_path 数 23,408、交集 file_path 数 15,043、并集 file_path 数 37,914、Jaccard 相似系数 39.68%、openbsd-src 中与 netbsd-src 共享的 file_path 比例 50.91%、netbsd-src 中与 openbsd-src 共享的 file_path 比例 64.26%——此比例反映两仓库在 1995-10-18 至 1997-12-31 期间被 commit 触及的 file_path 集合交集，而非 fork 初期（1995-10-18）源码树的完整共享比例，“约 90%” 的社区共识性估计指 fork 初期 OpenBSD 源码树与 NetBSD 1.0 源码树的共享比例，二者含义不同；file_path 集合交集统计的局限：仅统计被 commit 触及的文件，未触及的文件不在集合中，且 file_path 路径相同不等于文件内容相同，须以源码 tarball diff 核验完整共享比例 [考据完成：2026-07-30 file_path 集合交集统计提供量化参考，但 “约 90%” 的精确数字无单一权威来源，为社区共识性估计，须以 OpenBSD 1.2 与 NetBSD 1.2 源码 tarball diff 核验]
  - 文献：OpenBSD/NetBSD 1.x Release Notes；CVS 源码对照 ［A］
