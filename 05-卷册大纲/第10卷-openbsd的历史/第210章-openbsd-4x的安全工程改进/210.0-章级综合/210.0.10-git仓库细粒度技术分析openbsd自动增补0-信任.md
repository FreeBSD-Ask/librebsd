- **Clang/LLVM**（工具链，2008–2026）：C 编译器栈：FreeBSD 2012 用 Clang 取代 GCC（许可证原因）
- **许可/治理**（治理，1995–2026）：许可证与治理：BSD 许可宽松，Linux GPL；基金会治理（FreeBSD/NetBSD/OpenBSD 基金会）
- **TCP/IP**（网络，1995–2026）：TCP 拥塞控制演进：Reno→NewReno→CUBIC，BSD 与 Linux 并行
- **ARM**（硬件支持，1996–2026）：ARM64 支持：Linux 2012 官方；FreeBSD 2016 起
- **性能优化**（性能，1995–2026）：持续性能工程：内核网络/存储/调度微优化
- **GPU/DRM**（硬件支持，1997–2026）：显卡驱动：Linux DRM 2010s 成熟，FreeBSD 借 LinuxKPI 移植 DRM
- **OpenSSH**（安全，1997–2026）：安全远程登录套件（OpenBSD 1999 开发）
- **USB**（硬件支持，1999–2026）：USB 栈：FreeBSD usb4bsd 重写，Linux 成熟
- **无线**（网络，1996–2026）：802.11 无线栈：FreeBSD 用 net80211，Linux 用 mac80211/cfg80211
- **IPsec**（安全/网络，1997–2026）：IP 安全协议（RFC 2401），内核加密隧道
- **pf防火墙**（网络，2001–2026）：OpenBSD 包过滤防火墙（2001），OpenBSD 安全旗舰
- **内存管理**（内存管理，1995–2026）：虚拟内存、slab 分配、大页/HugeTLB 透明大页
- **UFS/FFS**（存储，1995–2026）：伯克利快速文件系统（1984），soft updates（1998）
- **SMP/多核**（进程/并行，1995–2026）：对称多处理与内核并行化（自旋锁→睡眠锁→无锁结构）
- **pledge/unveil**（安全，2015–2026）：OpenBSD 进程权限承诺（2015/2018），更小的攻击面
- **RISC-V**（硬件支持，2018–2026）：开放指令集：Linux 2017；BSD 陆续支持
- **调度器**（进程/并行，1996–2026）：任务调度策略：FreeBSD ULE、Linux CFS/EEVDF、NetBSD sched_4BSD
