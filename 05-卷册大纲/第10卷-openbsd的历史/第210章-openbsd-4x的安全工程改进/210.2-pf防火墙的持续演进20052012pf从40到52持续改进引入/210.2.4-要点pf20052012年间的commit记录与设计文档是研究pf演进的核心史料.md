# 210.2.4 要点pf20052012年间的commit记录与设计文档是研究pf演进的核心史料

**要点**：pf 2005-2012 年间的 commit 记录与设计文档是研究 pf 演进的核心史料；openbsd.duckdb openbsd-src 仓库显示 2005-2010 年间 pf 相关 commit 主要贡献者为 claudio@（198 条，ospfd/route 协议与 pf 集成）、henning@（169 条，ospfd 与 pf 接口组匹配）、mcbride@（52 条，pf 核心维护）；pf 的原始作者 Daniel Hartmeier（丹尼尔·哈特迈尔） 在 2001 年首次引入 pf（commit 2001-06-24 sys/net/pf.c 首次引入），但 4.x 时期 Hartmeier 已不活跃于 pf 主维护

**史料**：openbsd.duckdb openbsd-src 仓库 2005-2010 pf 相关 commit 贡献者统计（claudio 198、henning 169、mcbride 52、deraadt 50、reyk 41）；openbsd.duckdb openbsd-src 仓库 sys/net/pf.c 首次引入 commit（2001-06-24）；OpenBSD **pf.conf(5)** 手册页历次版本（<https://man.openbsd.org/pf.conf.5>）；OpenBSD 邮件列表档案（<https://marc.info/?laccopenbsd-tech>） ［A］

**史观**：总纲第 25 条——0 信任原则：pf 演进考据须以 commit log 的 file_path 维度交叉筛选——仅凭 message_subject 含 “pf” 关键字可能遗漏未标注 “pf” 但实际修改 pf 代码的 commit（如 claudio@ 的 ospfd 与 pf 集成 commit），openbsd.duckdb commit_files 表中 sys/net/pf*.c 路径下的 commit 是权威索引

**辨析**：pf 演进的具体里程碑以 Release Notes 与 commit log 交叉验证为准——Release Notes 记录用户可见的 pf 语法变更（如 4.1 的 interface groups），commit log 记录具体代码变更；OpenBSD 仓库无 release tag，pf 各特性的引入版本须以 Release Notes 与 commit log 的 author_date 交叉确认；freebsd.duckdb 查询 L2.2.1.sys_net_pf 在中观模式挖掘报告中不存在（报告仅含 freebsd-src 仓库的 sys/kern、sys/net 等子系统查询，未覆盖 openbsd-src 仓库的 sys/net/pf 子系统），pf 相关子系统级 commit 数据须以 openbsd.duckdb 直接查询 file_path 维度（如 sys/net/pf*.c、sbin/pfctl/）补全

**文献**：openbsd.duckdb openbsd-src 仓库 pf 相关 commit；OpenBSD **pf.conf(5)** 手册页 [EB/OL]. <https://man.openbsd.org/pf.conf.5>；OpenBSD Release Notes [EB/OL]. <https://www.openbsd.org/plus.html>；openbsd.duckdb 查询 L2.2.1.sys_net_pf（来源：原材料/研究/bsd 仓库分析/数据分析/中观模式挖掘.md §L2.2.1，数据缺口） ［A］
