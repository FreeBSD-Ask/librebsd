# 207.2 LibreSSL 的开发历程与技术路线


- 要点：LibreSSL fork 后第一周即删除约 70,000 行 OpenSSL 代码（包括旧平台支持、FIPS 模块、OS/2、VMS 等代码）；LibreSSL 2.0（2014-07-11）首次随 OpenBSD 5.6（2014-11-01）发布——bsd_commits.db 显示 jsing 于 2014-07-12 commit b6553af36068 引入 lib/libressl/，与 2.0 发布时间一致；LibreSSL 2.1.4（2014-11）发布 portable 版本支持 Linux；LibreSSL 强调简洁性、安全性，移除 SSLeay 兼容层、弃用部分旧 API
- 史料：LibreSSL Release Notes（<https://www.libressl.org/releases.html>）；OpenBSD CVS/Git commit log 中 LibreSSL 相关记录（<https://github.com/openbsd/src/tree/master/lib/libressl>）；LibreSSL 邮件列表存档（<https://marc.info/?l=libressl>）；bsd_commits.db openbsd-src commit b6553af36068（2014-07-12 LibreSSL 首次引入）
- 史观：总纲第 8 条——社区文化即技术资产：LibreSSL 的代码清理文化继承自 OpenBSD 审计文化——删除 70,000 行代码是“激进移除不安全代码”哲学的具体显现，与 OpenBSD 1996 年起审计文化一脉相承；总纲第 7 条——技术选择即政治选择：LibreSSL 选择“简洁优先”而非“兼容优先”是其政治选择——以“减少攻击面”为预设，宁可不兼容旧 API 也要降低代码复杂度
- 辨析：LibreSSL 与 OpenSSL 的兼容性策略在 2014-2018 年间有所变化——2014-2015 年采取激进删除策略（移除 SSLeay 兼容层），2016 年后因 portable 版本在 Linux 发行版中遭遇兼容性问题而部分回退；LibreSSL 的采用率相对 OpenSSL 较低——OpenBSD 自 5.6（2014-11）起默认使用 LibreSSL；FreeBSD 基础系统从未将 LibreSSL 作为默认加密库（经 bsd_commits.db 查询 freebsd-src 仓库无 lib/libressl 路径文件引入记录，FreeBSD 14.0-RELEASE 官方公告 <https://www.freebsd.org/releases/14.0R/announce/> 明确载明 OpenSSL 3.0.12 为基础系统加密库），LibreSSL 仅作为 ports/packages 可选；Alpine Linux 3.5.0（2016-12）曾切换至 LibreSSL，3.9（2019-01）因 LibreSSL 缺少部分 API 切回 OpenSSL；macOS 自 10.11 El Capitan（2015-09）起附带 LibreSSL 但同时保留 OpenSSL；Debian/Ubuntu/RHEL 全程默认使用 OpenSSL；2024 年统计 OpenBSD 是唯一默认使用 LibreSSL 的主流操作系统，Linux 桌面发行版 LibreSSL 占比不足 1%；bsd_commits.db 查询 L2.3.1.libressl 在中观模式挖掘报告中不存在（报告仅含 L2.3.1.ZFS、L2.3.1.Capsicum、L2.3.1.bhyve、L2.3.1.Clang、L2.3.1.ARM64、L2.3.1.RISC-V 等 FreeBSD 特性查询，未覆盖 OpenBSD LibreSSL 子系统），LibreSSL 相关子系统级 commit 数据须以 bsd_commits.db 直接查询 file_path 维度（如 lib/libressl/、lib/libssl/）补全
- 文献：LibreSSL Release Notes [EB/OL]. <https://www.libressl.org/releases.html>；LibreSSL 仓库 [EB/OL]. <https://github.com/libressl-portable/portable>；OpenBSD 5.6 Release Notes [EB/OL]. <https://www.openbsd.org/56.html>；LibreSSL 邮件列表 [EB/OL]. <https://marc.info/?l=libressl>；bsd_commits.db 查询 L2.3.1.libressl（来源：原材料/研究/bsd 仓库分析/数据分析/中观模式挖掘.md §L2.3.1，数据缺口） ［A］

**LibreSSL 各系统采用情况对比**：

| 系统 | 默认加密库 | LibreSSL 状态 | 备注 |
| --- | --- | --- | --- |
| OpenBSD | LibreSSL（自 5.6 起） | 默认 | 唯一默认使用 LibreSSL 的主流 OS |
| FreeBSD | OpenSSL 3.0.12（14.0 起） | ports 可选 | 基础系统从未引入 lib/libressl/ |
| macOS | LibreSSL（自 10.11 起）+ OpenSSL 并存 | 附带但非唯一 | 10.11 El Capitan（2015-09）起 |
| Alpine Linux | OpenSSL（3.9 起） | 曾切换后切回 | 3.5.0（2016-12）切换至 LibreSSL，3.9（2019-01）切回 |
| Debian/Ubuntu/RHEL | OpenSSL | 未采用 | 全程默认 OpenSSL |
