# 212.2 与 Linux 安全模块（SELinux/AppArmor）的对照

**要点**：SELinux 由 NSA 主导开发，2000 年 12 月首次发布（基于 Flask 架构与 Type Enforcement），2003 年合入 Linux 2.6 内核主线，依赖 Linux Security Modules（LSM）框架；AppArmor 由 Immunix 公司开发（1998 起），2006 年随 SUSE Linux Enterprise 10 集成；两者均采用 “策略可配置的强制访问控制” 路线，OpenBSD pledge（OpenBSD 5.9，2015-10-18）与 unveil（OpenBSD 6.4，2018-10-15）采用 “白名单沙箱默认” 路线——SELinux 策略语言复杂（RHEL 默认策略含约 4000+ 类型），OpenBSD pledge 仅约 30 个 promise 关键字（如 “stdio”、“rpath”、“wpath”、“inet”、“dns”）

**史料**：NSA SELinux 项目历史与发布声明（<https://www.nsa.gov/what-we-do/research/selinux/>）；AppArmor 项目白皮书与 SUSE 集成记录（<https://apparmor.net/>）；Linux Kernel 2.6.0 changelog 中 LSM 集成条目（<https://kernelnewbies.org/LinuxChanges>）；OpenBSD pledge(2)/unveil(2) 手册页（<https://man.openbsd.org/pledge.2>）；de Raadt 关于 pledge 设计的 misc@ 邮件列表发言（<https://marc.info/?laccopenbsd-misc>）；openbsd.duckdb openbsd-src 仓库 commit df174574d401（2015-10-09 tame→pledge）；openbsd.duckdb 查询 L7.3.1（4 大 BSD src 合计 vs Linux kernel commit 量与贡献者对比）显示：2005 年 BSD 60,533 commits/658 contributors vs Linux 16,697/1,464（linux_to_bsd_ratio = 0.28）；2008 年 BSD 48,242/690 vs Linux 48,825/2,746（ratio = 1.01，Linux commit 量首次超越 BSD 合计）；2020 年 BSD 36,392/574 vs Linux 90,911/4,864（ratio = 2.50），Linux commit 量自 2008 年起持续超越 BSD 四大 src 合计

**史观**：总纲第 7 条——技术选择即政治选择：SELinux 的 NSA 政府背景与 OpenBSD 的社区背景是两种不同政治选择——前者以 “政府主导安全合规” 为预设，后者以 “社区代码审计为预设”；总纲第 12 条——法律结构：LSM 框架作为 Linux 内核结构性约束塑造安全模块生态，所有 Linux 安全模块须遵循 LSM hook 接口，OpenBSD 的 pledge 不依赖此类框架而直接内建于 syscall 路径

**辨析**：SELinux 与 pledge/unveil 的功能并非完全等价——SELinux 提供内核级 MAC 策略（约 4000+ 类型、用户/角色/类型三元组），pledge 提供进程级 syscall 沙箱（约 30 个 promise 关键字、不区分用户角色），技术层级与粒度均不同；SELinux 在 RHEL 默认 enforcing 模式，但 Red Hat 官方文档（<https://access.redhat.com/documentation/en-us/red_hat_enterprise_linux/>）记录多数用户因配置复杂将其设为 permissive 或 disabled；OpenBSD pledge 自 5.9 起被/usr.bin/下大量程序默认启用，无管理员可关闭选项；openbsd.duckdb 查询 L7.3.1 局限：Linux kernel commit 量级远大于 BSD 项目，对比时须使用归一化指标（人均 commit、增长率、子系统比例），不可直接比较绝对值；linux-kernel 仓库仅含 Linus 主仓，不含子系统仓库（如 netdev、drm 等独立仓库），实际 Linux 内核开发活跃度高于 L7.3.1 数据所示；openbsd-src 为 GitHub 镜像，commit 量可能滞后于 OpenBSD CVS 主仓
