# 212.4 与 macOS/Darwin 安全机制的对照

**要点**：macOS 基于 Darwin（含 BSD 用户空间，自 Mac OS X 10.0 起源自 FreeBSD 4.x 用户空间与 Mach 3.0 内核混合）；macOS 通过 Sandbox（10.5 Leopard 2007 引入 Seatbelt sandbox，基于 TrustedBSD MAC Framework）、System Integrity Protection（SIP，2015 OS X 10.11 El Capitan 引入，保护系统目录与进程）、Gatekeeper（2012 Mountain Lion 10.8 引入，强制代码签名验证）等机制提供安全；OpenBSD pledge（OpenBSD 5.9，2015-10-18）与 unveil（OpenBSD 6.4，2018-10-15）走 “进程级白名单” 路线——macOS 路线依赖商业闭源决策与硬件级隔离（如 Apple Silicon Pointer Authentication Codes, PAC 自 A12 2018 起强制），OpenBSD 路线依赖纯软件审计与开源可验证

**史料**：Apple Platform Security 白皮书（<https://support.apple.com/guide/security/welcome/web>，年度更新）；Darwin 开源代码（Apple 公开 XNU 内核源码 <https://opensource.apple.com/projects/xnu/>）；OpenBSD pledge/unveil 文档（<https://man.openbsd.org/pledge.2>）；OS X 10.11 SIP 技术文档；Apple Silicon 安全架构白皮书；openbsd.duckdb openbsd-src commit 8b23add8c74b（2018-07-13 unveil 引入）

**史观**：总纲第 7 条——技术选择即政治选择：商业闭源安全（Apple 决策主导，SIP 与 Gatekeeper 均为闭源实现）与开源审计安全（OpenBSD 社区审计，pledge/unveil 源码完全可审计）是两种不同政治选择；总纲第 12 条——法律结构：macOS 闭源决策作为商业约束塑造安全模型——SIP 限制 root 权限但 root 权限的具体边界由 Apple 单方面决定，OpenBSD pledge 的权限边界由程序源码公开声明

**辨析**：macOS SIP 与 OpenBSD pledge/unveil 的技术层级不同——SIP 保护系统级完整性（限制 root 写入 /usr、/bin、/sbin 等系统目录），pledge 限制进程级 syscall（程序运行时声明所需 promise 类别），unveil 限制进程级文件路径访问；macOS 的 BSD 用户空间渊源与安全机制的关系是独立演进——Darwin 用户空间源自 FreeBSD 4.x（2001 年 Mac OS X 10.0 发布时），但 SIP/Gatekeeper/Sandbox 均为 Apple 自研，未从 FreeBSD 主线合并；Apple Silicon PAC（2018 A12 起）是硬件级控制流完整性保护，OpenBSD 至 7.6（2024-10）仅在 arm64 平台提供部分 PAC 支持

**文献**：Apple Platform Security 白皮书 [EB/OL]. <https://support.apple.com/guide/security/welcome/web>；Darwin/XNU 开源代码 [EB/OL]. <https://opensource.apple.com/projects/xnu/>；OpenBSD pledge(2) 手册页 [EB/OL]. <https://man.openbsd.org/pledge.2>；OpenBSD unveil(2) 手册页 [EB/OL]. <https://man.openbsd.org/unveil.2> ［A］

**macOS 安全机制演进与 OpenBSD 对应**：

| macOS 机制 | 引入版本 | 时间 | 技术层级 | OpenBSD 对应 |
| --- | --- | --- | --- | --- |
| Sandbox（Seatbelt） | 10.5 Leopard | 2007 | 基于 TrustedBSD MAC Framework | pledge（5.9，2015） |
| Gatekeeper | 10.8 Mountain Lion | 2012 | 代码签名验证 | 无对应 |
| SIP | 10.11 El Capitan | 2015 | 系统目录保护 | 无对应（root 权限边界由程序源码声明） |
| Apple Silicon PAC | A12 起 | 2018 | 硬件级控制流完整性 | OpenBSD 7.6（2024-10）arm64 部分支持 |
