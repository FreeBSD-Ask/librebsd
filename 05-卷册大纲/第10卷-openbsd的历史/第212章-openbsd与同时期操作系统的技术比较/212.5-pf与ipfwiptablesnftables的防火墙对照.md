# 211.5 pf 与 IPFW/iptables/nftables 的防火墙对照


- 要点：OpenBSD pf 由 Daniel Hartmeier（丹尼尔·哈特迈尔） 主导开发，2001 年随 OpenBSD 3.0（2001-12-01 发布）引入——openbsd.db openbsd-src 仓库 commit 148b55c022b1（2001-06-24 kjell 引入 sys/net/pf.c 与 sys/net/pfvar.h）证实代码引入时间早于 3.0 发布约 5 个月；pf 替代因许可证问题被移除的 ipf（deraadt 于 2001-05-30 commit 345de70aec27 删除 sbin/ipf/）；pf 强调状态跟踪（stateful inspection）与简洁语法（如 `pass in on $ext_if proto tcp to any port 22`）；FreeBSD IPFW 由 Ugen J.S. Antsilevich 等维护，自 FreeBSD 2.0 起作为默认防火墙，强调性能与可配置性；Linux iptables（2001 年随 Linux 2.4）后继 nftables（2014 年随 Linux 3.13，统一替代 iptables/ip6tables/arptables/ebtables）；pf 于 2003 年随 FreeBSD 5.3 移植——freebsd.db freebsd-src 仓库记录 Daniel Hartmeier 本人 2004-05-02 至 2007-11-21 期间向 FreeBSD 提交 20 条 commit；NetBSD 自 4.0（2007-12）起集成 pf；OpenBSD 主页声称 pf 是 "the most copied firewall in the world"
- 史料：Daniel Hartmeier 个人 pf 历史文章（<https://www.benzedrine.ch/pf.html>）；OpenBSD 3.0 Release Notes（<https://www.openbsd.org/30.html>）；FreeBSD IPFW 手册页 **ipfw(8)** 与 FreeBSD 5.3 Release Notes pf 移植记录；Linux nftables 项目主页（<https://www.netfilter.org/projects/nftables/>）与 man pages；openbsd.db openbsd-src commit 148b55c022b1（pf.c 首次引入）与 345de70aec27（ipf 删除）；openbsd.db contributors 表 <dhartmei@openbsd.org>（591 commits, 2001-06-24 至 2007-12-02）与 <dhartmei@FreeBSD.org>（20 commits, 2004-05-02 至 2007-11-21）〔L1 代码/构建产物/L3 官方文档与公告/L4 事后叙述〕
- 史观：总纲第 7 条——技术选择即政治选择：三种防火墙设计是三种不同政治选择——pf 简洁优先（约 30 个规则关键字）、IPFW 性能优先（早期 ipfw 1.x 不含状态跟踪直至 IPFW2）、iptables/nftables 灵活优先（nftables 提供 Turing-complete 规则语言）；总纲第 2 条——分离与聚合：pf 从 OpenBSD 分离并向 FreeBSD/NetBSD 聚合，是 BSD 间的代码流动——Hartmeier 本人在 2004-2007 年间向 FreeBSD 主线提交 pf 移植与维护 commit
- 辨析：三者性能对比缺乏权威基准——多数公开基准（Phoronix、Calomel.org）存在配置不等价问题（如未对齐规则数量、状态表大小、conntrack 模块）；FreeBSD 默认仍提供 IPFW/IPF/pf 三选项（编译时选择），NetBSD 自 7.0（2015-10）起 NPF 取代 pf 作为默认防火墙（<https://man.netbsd.org/npf.7>）
- 文献：Daniel Hartmeier pf 历史 [EB/OL]. <https://www.benzedrine.ch/pf.html>；OpenBSD 3.0 Release Notes [EB/OL]. <https://www.openbsd.org/30.html>；FreeBSD IPFW 手册页 **ipfw(8)** [EB/OL]. <https://www.freebsd.org/cgi/man.cgi?ipfw(8)>；Linux nftables 项目 [EB/OL]. <https://www.netfilter.org/projects/nftables/>；NetBSD NPF 手册页 **npf(7)** [EB/OL]. <https://man.netbsd.org/npf.7> ［A］

| 维度 | OpenBSD pf | FreeBSD IPFW | Linux iptables/nftables |
| --- | --- | --- | --- |
| 引入版本 | OpenBSD 3.0（2001-12-01） | FreeBSD 2.0 | iptables Linux 2.4（2001）/nftables 3.13（2014） |

| 跨项目扩散 | FreeBSD 5.3、NetBSD 4.0 移植 | FreeBSD 自家 | Linux 自家 |

| 默认启用 | OpenBSD 默认启用 pf | FreeBSD 默认不启用（须编译时选择 IPFW/IPF/pf 之一） | Linux 默认不启用（须发行版配置） |
| 设计哲学 | 简洁 + 安全默认 + 状态跟踪优先 | 性能 + 可配置性 + 灵活动作 | 灵活 + 统一框架（nftables 统一 iptables/ip6tables/arptables/ebtables） |
