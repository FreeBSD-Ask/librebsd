# 212.1 与 FreeBSD 安全模型的对照

**要点**：OpenBSD 采用 “默认安全 + 代码审计” 模型，FreeBSD 采用 “Security Officer + MAC Framework” 模型；FreeBSD 通过 TrustedBSD 项目（2000-2003 年由 Robert Watson、Poul-Henning Kamp（波尔-亨宁·坎普） 等推动）引入 MAC、Jails（1999 年由 Poul-Henning Kamp 创建）、Capabilities 等机制；OpenBSD 通过 pledge（OpenBSD 5.9，2015-10-18 发布；deraadt 于 2015-10-09 commit df174574d401 将 tame 改名为 pledge）与 unveil（OpenBSD 6.4，2018-10-15 发布；beck 于 2018-07-13 commit 8b23add8c74b 引入）走 “沙箱化默认” 路线，FreeBSD MAC 走 “策略可配置” 路线——前者将权限白名单内建于程序代码，后者将策略外置为可加载模块；统计结论印证——资料数据库.duckdb doubt_flag 字段卡方检验（统计结论 C-28）显示第七卷存疑率 2.89%（vol-7），12 卷间存疑率分布差异显著（χ² = 229.62 df = 11 p = 5.09e-43 Cramer's V = 0.127 小效应量），反映第七卷 OpenBSD 安全路线叙事的考据存疑率处于全书 12 卷中游偏下水平，与本卷核心叙事围绕 “代码审计” 与 “安全默认” 两条主线（与 FreeBSD MAC Framework 路线对照）的史料基础相一致

**史料**：OpenBSD Security Advisories（<https://www.openbsd.org/security.html>）与 FreeBSD Security Advisories（<https://www.freebsd.org/security/advisories/>）；TrustedBSD 项目文档（<https://docs.freebsd.org/en/books/arch-handbook/mac/>）；OpenBSD pledge(2) 手册页（<https://man.openbsd.org/pledge.2>）；OpenBSD unveil(2) 手册页（<https://man.openbsd.org/unveil.2>）；openbsd.duckdb openbsd-src 仓库 commit df174574d401 与 8b23add8c74b；资料数据库.duckdb doubt_flag 字段卡方检验（统计结论 C-28：χ² = 229.62 df = 11 p = 5.09e-43 Cramer's V = 0.127 小效应量，Python `scipy.stats.chi2_contingency` 实现，查询日期 2026-07-27），vol-7 存疑率 2.89% 为 12 卷中游偏下水平（vol-9 存疑率 0.00% 最低，vol-10 存疑率 21.33% 最高）〔L1 代码/构建产物/L3 官方文档与公告〕

**史观**：总纲第 7 条——技术选择即政治选择：pledge/unveil 的 “白名单内建” 路线对应 “开发者须为每程序声明最小权限” 的预设，MAC Framework 的 “策略可配置” 路线对应 “管理员可后置配置策略” 的预设——此两种预设分别对应 OpenBSD 社区 “开发者责任前置” 与 FreeBSD 社区 “管理员灵活后置” 两种治理取向；总纲第 8 条——社区文化即技术资产；统计结论印证——C-28 各卷 doubt_flag 卡方检验以存疑率差异的统计刻画印证 “分离聚合是永恒规律”（总纲第 4 条），第七卷存疑率 2.89% 反映 OpenBSD 安全路线叙事的史料考据存疑点处于卷间中游偏下水平——与 FreeBSD MAC Framework 路线对照的本卷叙事，其存疑率既未像 vol-9（0.00%）因史料稀疏而无存疑标注，也未像 vol-10（21.33%）因 BSD 衍生操作系统史料分散而存疑密集，反映 OpenBSD 安全路线叙事的史料基础相对集中且可查

**辨析**：OpenBSD 与 FreeBSD 安全模型严格程度的对比缺乏权威评估；pledge/unveil 与 MAC Framework 的技术层级不同——pledge 是进程级 syscall 沙箱（用户态调用 pledge(2) 后内核拒绝非白名单 syscall），MAC Framework 是内核级策略框架（管理员加载模块如 mac_biba、mac_mls 后内核在 syscall 路径上调用策略检查），二者并非完全等价；OpenBSD 5.9（2015-10-18）首次提供 pledge，FreeBSD 5.0（2003-01-19）首次提供 MAC Framework，时间差约 12 年；**统计局限性标注**——C-28 卡方检验的 Cramer's V = 0.127 属小效应量，统计显著（p = 5.09e-43）但实际效应量较小，反映 12 卷间存疑率分布差异虽统计显著但实际差异幅度有限；C-28 检验基于资料数据库.duckdb doubt_flag 字段，受字段填充率影响（doubt_flag 覆盖率 11.08%，1,582 条），vol-7 存疑率 2.89% 是基于本卷已标记 doubt_flag 的 materials 条目数与卷内 materials 总数的比值，不得以全卷 materials 数量推断存疑绝对数；0 信任原则适用：统计显著 ≠ 实际显著，Cramer's V = 0.127 的小效应量须结合卷间存疑率的实际数值差异（vol-9 0.00% 至 vol-10 21.33%）综合判断，多重比较风险——12 卷间两两比较的 Bonferroni 校正后部分差异可能不再显著
