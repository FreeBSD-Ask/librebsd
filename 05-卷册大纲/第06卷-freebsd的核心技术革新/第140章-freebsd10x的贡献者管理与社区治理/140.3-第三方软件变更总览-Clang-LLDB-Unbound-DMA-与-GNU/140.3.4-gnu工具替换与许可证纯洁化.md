# 140.3.4 GNU 工具替换与许可证纯洁化

**要点**：10.0 时期完成或推进的 GNU 工具替换包括：**make(1)** → **bmake(1)**（来自 NetBSD）、**patch(1)** →BSD patch、**sort(1)** →BSD sort、**ar(1)**/**ranlib(1)** → 基于 libarchive 的 BSD 版本、**bc(1)**/**dc(1)** →BSD 版本、**cpio(1)** → 基于 libarchive 的 BSD 版本、yacc→byacc、lex→flex 2.5.37。这是许可证纯洁化工程的关键阶段——每一项 GNU 工具替换都使用 BSD 许可的实现，消除 GPL 许可证对 base system 的约束。详细分析见 59.7.4〔待核实节号〕 节与第063章。

**史观**：许可证：GNU 工具替换的核心动力是 GPLv3 许可证担忧，但替换后的 BSD 工具在代码可读性、可维护性、许可证兼容性上的收益也是真实的

**辨析**：GNU 工具替换不是 10.0 一次性完成的事件，而是持续多年的逐点清除工程——部分工具（如 groff→mandoc、texinfo 等）在更晚版本才完成替换或移除
