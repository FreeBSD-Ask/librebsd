# 140.3.2 BIND→Unbound 与 BIND 移除

**要点**：FreeBSD 10.0-RELEASE 将 ISC BIND 从 base system 移除，以 NLnet Labs 的 Unbound（递归 DNS 解析器，BSD 许可证）+ LDNS（DNS 解析库）组合替代作为本地缓存 DNS 解析器。BIND 自 4.3BSD Tahoe（1988）起即为 BSD 系统的标准 DNS 服务器，移除原因包括：安全漏洞历史（Dan Kaminsky 2008 DNS 缓存投毒漏洞等）、代码体量庞大维护负担重、Unbound 作为模块化递归解析器更轻量且攻击面更小。随 BIND 移除的还有 nslookup 与 dig 工具——base 中改为提供 **host(1)** 与 **drill(1)**（来自 LDNS）。详细分析见 59.7.1〔待核实节号〕 与 59.7.2〔待核实节号〕 节。

**史观**：总纲第 24 条——许可证与安全：BIND 移除是安全债务清算与许可证纯洁化的共同结果

**辨析**：Unbound 仅替代 BIND 的 “本地递归解析器” 功能，不替代 BIND 的 “权威 DNS 服务器” 功能，base 中不再包含权威 DNS 服务器软件
