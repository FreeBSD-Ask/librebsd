# 140.4.1 Linux 3.x-4.x 与容器革命

**要点**：FreeBSD 10.x 时期（2014-2017）对应 Linux 内核 3.13-4.10 版本时期，这一时期是 Linux 生态容器技术爆发期：Docker 1.0 于 2014 年 6 月发布，Kubernetes 1.0 于 2015 年 7 月发布，容器化彻底改变了软件部署方式。Linux 内核同期主要特性：cgroups v2、namespaces 改进、overlayfs、eBPF 萌芽、KDBUS 争议（最终未合并主线）、Live Patching（kpatch/kgraft）、Btrfs/ZFS on Linux 成熟度提升、Wayland 桌面生态开始替代 Xorg。FreeBSD 10.x 在容器/云原生领域显著落后于 Linux——**jail(8)** 虽成熟但缺乏 Docker 生态支持，bhyve 是 KVM 竞品但无 Docker/Moby 集成，Linux 二进制兼容层在 10.3 才支持 64 位但无法运行 Docker。Linux 发行版方面：Ubuntu 14.04 LTS/16.04 LTS、RHEL/CentOS 7、Debian 8/9 主导服务器市场，systemd 成为大多数主流发行版初始化系统（引发长期争议）。

**史料**：Linux kernel release notes 3.13-4.10、Docker/Kubernetes 1.0 发布公告、Phoronix/LWN.net 同期技术报道。 ［C］

**史观**：总纲第 4 条——分离聚合是永恒规律：容器革命是 Linux 在 2010 年代进一步扩大服务器市场优势的关键转折点，FreeBSD 虽有 jail（容器概念的先驱，2000 年 3 月随 FreeBSD 4.0 发布，1999 年进入开发主线）和 ZFS 等优秀技术，但未抓住容器生态爆发的机遇，这与 FreeBSD 社区保守文化、企业投入规模、许可证生态差异等多重因素相关。

**辨析**：不应简单说 “FreeBSD 没有容器技术”——jail 是容器技术的先驱且在 10.x 时期持续改进（10.3 `jail -l` 干净环境标志、VIMAGE/VNET 虽未稳定但在发展），但 jail 没有 Docker 这样的用户友好工具链和镜像生态，这在 “开发者体验” 竞争中是致命差距；bhyve 作为 hypervisor 与 KVM 技术路线不同（bhyve 更简洁更聚焦），但缺乏 libvirt/virt-manager 生态配套。
