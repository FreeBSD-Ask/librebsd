# 140.4.2 Windows Server 与 Microsoft 转型

**要点**：FreeBSD 10.x 时期对应 Microsoft 从 Ballmer 时代向 Nadella 时代转型：Windows Server 2012 R2（2013）、Windows Server 2016（2016）、Windows 10（2015）发布。Microsoft 此时期最大变化是对开源态度的根本转变——2014 年 Satya Nadella 任 CEO 后提出 “Microsoft loves Linux”，2014-2016 年逐步：开源 .NET Core、与 FreeBSD 合作 Hyper-V 驱动、在 Azure 上支持 Linux/FreeBSD、收购 Xamarin、加入 Linux Foundation、推出 WSL（Windows Subsystem for Linux，2016 年 beta）。FreeBSD 10.3 镜像于 2016 年进入 Azure Marketplace，是 Microsoft 与 FreeBSD 合作的标志性成果。

**史观**：总纲第 13 条——法律与道德是利益分配：Microsoft 从开源敌人到开源参与者的转型是 2010 年代科技行业最大事件之一，FreeBSD 是这一转型的早期受益者——Hyper-V 驱动与 Azure 镜像使 FreeBSD 在 Microsoft 云生态中获得一席之地。这也证明了 BSD 许可证对商业公司的友好性——Microsoft 可以自由使用 FreeBSD 代码而不必像 GPL 代码那样考虑许可证义务。

**辨析**：Microsoft 支持 FreeBSD on Azure 是实用主义决策——Azure 市场有客户需要运行 FreeBSD（如 NetApp 存储设备、iXsystems TrueNAS、Netflix CDN 组件），Microsoft 提供官方镜像以满足客户需求而非出于 “热爱开源” 的意识形态转变。
