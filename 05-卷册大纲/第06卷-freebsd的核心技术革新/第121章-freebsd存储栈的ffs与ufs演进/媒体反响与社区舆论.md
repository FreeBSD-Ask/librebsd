## 冲突类

### 新闻条目 1

- **新闻标题（中英）**：UFS 与 ZFS 文件系统在 FreeBSD 9.0 上的性能对比（UFS vs. ZFS File-System Performance On FreeBSD 9.0）
- **新闻来源**：Phoronix + Michael Larabel + 2011-12-12 + <https://www.phoronix.com/news/MTAyNjg> + <https://web.archive.org/web/2011/https://www.phoronix.com/news/MTAyNjg>
- **新闻摘要**：2011 年 12 月 Phoronix 发布 UFS 与 ZFS 在 FreeBSD 9.0 上的性能对比测试。UFS（Unix File System）是 FreeBSD 传统文件系统，经过 Berkeley FFS 与 Soft Updates 演进而来。测试显示 UFS 在单磁盘场景下仍有竞争力，但 ZFS 在数据完整性、快照、压缩方面优势明显。这一对比反映了 FreeBSD 存储栈在 2010s 初 UFS 与 ZFS 并存的格局。
- **与本章主题的关联说明**：本章记述 FreeBSD 存储栈中 UFS/FFS 等 非 ZFS 部分的演进，Phoronix 2011 年对比测试是 UFS 在 ZFS 兴起后仍作为生产文件系统的关键性能参照。
- **与官方史料的交叉验证结论**：FreeBSD 9.0-RELEASE 发行说明列出 UFS 与 ZFS 均为基本系统文件系统；Phoronix 测试为独立第三方，技术细节与 FreeBSD 手册一致。

## 里程碑事件类

### 新闻条目 1

- **新闻标题（中英）**：FreeBSD 弃用 BIND 与 GNU AR（FreeBSD Drops BIND, GNU AR From Base System）
- **新闻来源**：Phoronix + Michael Larabel + 2013-10-08 + <https://www.phoronix.com/news/MTQ3OTg> + <https://web.archive.org/web/2013/https://www.phoronix.com/news/MTQ3OTg>
- **新闻摘要**：2013 年 10 月 FreeBSD 10.0-CURRENT 弃用 BIND（DNS 服务器）与 GNU AR（归档工具）从基本系统。这一决策反映了 FreeBSD 10.x 周期“瘦身基本系统”的工程方向，将维护负担转移到 Ports 系统。虽然主题为 BIND 与 GNU AR，但同期 FreeBSD 存储栈也在精简老旧组件。
- **与本章主题的关联说明**：本章记述 FreeBSD 存储栈在 10.x 周期的现代化，基本系统精简是存储栈演进的工程背景。
- **与官方史料的交叉验证结论**：FreeBSD 10.0-RELEASE 发行说明与 Phoronix 报道交叉验证，弃用项一致。

### 新闻条目 2

- **新闻标题（中英）**：FreeBSD 9.2 带来 ZFS TRIM、ZFS LZ4、更新的 DTrace（FreeBSD 9.2 Brings ZFS TRIM, ZFS LZ4, Updated DTrace）
- **新闻来源**：Phoronix + Michael Larabel + 2013-09-30 + <https://www.phoronix.com/news/MTQ3MzU> + <https://web.archive.org/web/2013/https://www.phoronix.com/news/MTQ3MzU>
- **新闻摘要**：2013 年 9 月 FreeBSD 9.2-RELEASE 发布，包含 ZFS TRIM（SSD trim 支持）与 LZ4 压缩算法。虽然这些是 ZFS 改进，但同期 FreeBSD UFS 也获得了 TRIM 支持改进，反映存储栈整体向 SSD 时代适配的方向。
- **与本章主题的关联说明**：本章记述 FreeBSD 存储栈向 SSD 与现代存储介质的适配，TRIM 支持是 UFS 与 ZFS 共同的演进方向。
- **与官方史料的交叉验证结论**：FreeBSD 9.2-RELEASE 发行说明与 Phoronix 报道交叉验证，TRIM 与 LZ4 改进项一致。
