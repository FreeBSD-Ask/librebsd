# 126.4.1 Corbet 的“DTrace envy”话语框架

**要点**：LWN.net 编辑 Jonathan Corbet 于 2007 年 8 月 7 日发表《On DTrace envy》（lwn.net/Articles/244536/），勾勒了 Linux 社区面对 DTrace 时的复杂话语框架：“DTrace 支持者常说 SystemTap 不过是 DTrace 的劣质仿制品，SystemTap 支持者则反驳它是独立开发、自有其价值”；Corbet 分析了 Linux 追踪领域的现状——kprobes、SystemTap 等工具在可用性和安全性上与 DTrace 存在差距，但 CDDL 许可证使 DTrace 无法进入 Linux 主线；该文奠定了此后十年 Linux 社区讨论 DTrace 时的“羡慕但不愿承认”的话语基调

**史料**：Jonathan Corbet 2007-08-07《On DTrace envy》原文（lwn.net/Articles/244536/）；LWN.net DTrace/SystemTap/eBPF 相关报道时间线（2005-2020 年） ［C］

**史观**：总纲第 23 条——社区治理：Corbet 的文章是技术新闻话语塑造社区认知的经典案例——“DTrace envy”这一短语精准捕捉了 Linux 社区面对 DTrace 时的复杂情感（羡慕技术优势 + 排斥因许可证 + 维护 NIH 自尊），这一框架影响了此后多年对 DTrace/Linux 追踪问题的讨论方式

**辨析**：Corbet 作为 LWN 编辑，其立场相对平衡——他既承认 DTrace 的技术优势，也理解 Linux 社区的许可证立场和发展独立工具的必要性；“envy”一词在文中不是贬义，而是对社区心理的准确描述；该文发表于 eBPF 诞生之前（2007 年 vs 2014 年），彼时 SystemTap 是 Linux 追踪的主要希望
