# 123.5 CAM ATA 重写与 USB 栈完成——内核 I/O 子系统现代化

## 123.5.1 Alexander Motin 的 CAM ATA 重写

**要点**：Alexander Motin（mav@）主导的 CAM（Common Access Method）层 ATA 重写在 9.0-RELEASE 中基本完成，将 ATA/SATA 驱动从旧的独立 **ata(4)** 子系统移入 CAM 框架，统一了 SCSI 与 ATA 的 I/O 路径；新框架原生支持 AHCI（Advanced Host Controller Interface），为 SATA 硬盘提供了更好的性能与热插拔支持；旧 **ata(4)** 驱动在 9.x 中仍可用但被标记为废弃，10.x 之后逐步移除；**graid(8)** GEOM RAID 类取代旧的 **ataraid(4)** BIOS 软 RAID 支持

**史料**：Alexander Motin 在 freebsd-arch 邮件列表的 CAM ATA 设计提案、svn commit log（CAM ATA 相关提交序列）、FreeBSD 9.0 Release Notes、**ata(4)** vs **cam(4)** 对比文档 ［A］

**史观**：总纲第 17 条——软件工程：CAM ATA 重写是 FreeBSD 内核存储栈 20 年来最大的架构调整之一——它消除了 SCSI 与 ATA 两条平行 I/O 路径的代码重复，使 SATA SSD、SAS HBA、硬件 RAID 控制器等设备共享同一 CAM 层基础设施；Motin 作为 iXsystems 员工在 ZFS/存储领域的持续贡献，体现了商业公司对 FreeBSD 核心基础设施的重要投入

**辨析**：CAM ATA 迁移在 9.0 时期并非完全无痛——部分旧 ATA 控制器在新栈中存在兼容性问题，用户需在 loader.conf 中切换回旧 **ata(4)** 驱动；但到 9.1/9.2 时期大部分兼容性问题已解决

**文献**：FreeBSD 9.0-RELEASE Release Notes（Storage Drivers 章节）；Motin A. CAM ATA: Integration of ATA into CAM Layer [C]//EuroBSDCon 2011. London, 2011；**ahci(4)**、**cam(4)**、**ata(4)** man pages

## 123.5.2 Hans Petter Selasky 与 USB 栈重写完成（usbus2）

**要点**：Hans Petter Selasky（hps@）主导的新 USB 栈（项目名 usbus2）在 8.0 时期引入但标记为实验性，在 9.0-RELEASE 中完全替换旧 **usb(4)** 栈；9.0 同时新增 USB 3.0（XHCI）支持默认启用（r223098）；新 USB 栈设计更清晰，修复了大量旧栈的死锁与性能问题，支持 USB packet filter（类似 BPF 的 USB 抓包框架）和 **usbdump(8)** 工具；USB 栈重写历时多年，是 FreeBSD 内核子系统重写的成功范例

**史料**：Hans Petter Selasky 关于 USB 栈重写的系列论文与演讲、svn commit log、FreeBSD 8.x/9.0 Release Notes、**usbdump(8)** man page；**freebsd.duckdb** `commits` 表 `freebsd-src` 仓库数据库验证——XHCI 驱动首次完整引入 commit 为 `1354026034bcac3abf55b01e0a427be249283d95`，author = Hans Petter Selasky，author_date = 2010-10-03T08:12:17Z，committer_date = 2010-10-03T08:12:17Z，subject = "Commit initial version of new XHCI driver which was written from scratch. This driver adds support for USB3.0 devices. The XHCI interface is also backwards compatible to USB2.0 and USB1.0 and will evntually replace the OHCI/UHCI and EHCI drivers."；此 2010-10-03 的 commit 时间点早于 FreeBSD 9.0-RELEASE（2012-01-12）约 15 个月，反映 XHCI 驱动在 9.0 开发周期早期即已进入 -CURRENT 分支；数据库另显示 Selasky 在 2010-10-03 至 2010-10-04 期间密集提交 XHCI 相关 commit（`963169b4af5d...` 2010-10-04 全 USB 3.0 host/device 模式支持、`0acf6a648a99...` 2010-10-04 将 XHCI 链接入默认内核构建），随后在 2010-10 至 2011-11 期间持续提交 XHCI 改进 commit（如 `c1338c65d63b...` 2011-01-13 64 字节上下文支持、`82d3f0ce92ec...` 2011-04-03 MFC 至 stable/8 分支、`ff11fd7fa7db...` 2011-07-22 早期接管代码、`3d09c7b32726...` 2011-10-26 挂起恢复修复、`96ef942084e7...` 2011-11-15 重置时间调整），反映 XHCI 驱动在合入后经历了约 13 个月的密集稳定化工作才随 FreeBSD 9.0-RELEASE 正式发布；原大纲所述 r223098（9.0 USB 3.0 支持默认启用）与数据库 commit 时间线一致——XHCI 主线合入在 2010-10-03，9.0-RELEASE 在 2012-01-12，r223098 应为 9.0 开发周期内将 XHCI 设为默认启用的 SVN revision；0 信任原则提示：此时期 FreeBSD 仍处于 SVN 时代，commit hash 经 2020 年 SVN-to-Git 迁移重算，author_date 由迁移脚本根据原始 SVN commit 元数据回填，可信度较高但非原始 Git 时代记录 ［A］

**史观**：总纲第 17 条——软件工程：USB 栈重写体现了 FreeBSD “重写而非修补” 的工程勇气——旧 USB 栈因 NetBSD 起源且历经多人修补，到 2000 年代中期已成为维护噩梦；Selasky 从零设计新栈，历经两个大版本周期（8.0 引入实验，9.0 默认替换）完成过渡，这种 “并行存在、渐进替换” 的模式是 FreeBSD 处理大型基础组件替换的典型方式

**辨析**：USB 3.0 支持在 9.0 中的覆盖范围需要精确——主要支持 XHCI 主机控制器，但部分早期 USB 3.0 设备可能存在兼容性问题；完整 USB 3.0 外设支持在 9.x/10.x 持续改进；数据库证据精确化了 XHCI 时间线：驱动代码首次合入为 2010-10-03（早于 9.0-RELEASE 约 15 个月），9.0-RELEASE 时已积累约 15 个月的稳定化工作，与原大纲 “USB 栈重写历时多年” 的判断一致

## 123.5.3 9.1 CTL（CAM Target Layer）与 virtio 半虚拟化

**要点**：9.1-RELEASE 引入 CTL（CAM Target Layer）——一个磁盘和处理器设备仿真子系统，为 FreeBSD 提供 SCSI target 模式支持（可作为存储服务器导出磁盘给其他 initiator）；9.2-RELEASE 将 **virtio(4)** 半虚拟化驱动加入 amd64 和 i386 的 GENERIC 内核配置，为 bhyve 和 KVM  guest 提供高性能半虚拟化 I/O；9.1 同时新增内核 AVX FPU 扩展支持

**史料**：FreeBSD 9.1/9.2-RELEASE Announcement 与 Release Notes、**ctl(4)**/**ctld(8)** man pages、**virtio(4)** man page ［B］

**史观**：总纲第 6 条——技术路线分化：CTL 使 FreeBSD 具备企业级存储 target 能力（与 Linux LIO、SCST 对标），virtio 驱动加入 GENERIC 则是为 bhyve（10.0 正式引入）做的基础设施准备——这两项特性共同表明 9.x 是 FreeBSD 虚拟化与存储能力的蓄力期

**辨析**：**ctl(4)** 在 9.1 中作为框架提供，但用户态管理工具 **ctld(8)** 和完整配置体系在 10.0 及后续版本完善；virtio 驱动虽在 9.2 GENERIC 中，但 bhyve 本身 10.0 才正式发布，9.x 时期 virtio 主要用于 Linux/KVM  guest 环境

**文献**：FreeBSD 9.1-RELEASE Announcement [Z]. 2012-12-30；FreeBSD 9.2-RELEASE Announcement [Z]. 2013-09-30；**ctl(4)**、**ctld(8)**、**virtio(4)** man pages ［B］
