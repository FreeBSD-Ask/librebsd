# 142.1.4 要点11x时期虚拟化平台驱动持续改进VMware方面vmx4VMXNET3网络驱

**要点**：11.x 时期虚拟化平台驱动持续改进：VMware 方面——**vmx(4)** VMXNET3 网络驱动在 10.0 从 OpenBSD 移植后 11.x 持续改进性能与稳定性；**vmblock(4)**/**vmmouse(4)**/**vmhgfs(4)** 等 VMware guest 驱动持续更新；VMware SVGA 图形驱动配合 Xorg 可实现自适应分辨率。Xen 方面——DomU（客户机）支持在 10.x 已稳定，11.x 持续优化；Dom0（控制域/宿主机）支持持续改进但 11.x 仍不建议生产使用（Dom0 生产就绪在更晚版本）；Xen PVHVM 半虚拟化驱动在 GENERIC 内核中默认启用。Hyper-V 方面——11.1 加入 Generation 2 虚拟机支持是里程碑式改进（Gen2 使用 UEFI 引导、SCSI 启动、合成设备，性能远优于 Gen1）。云平台方面：Amazon EC2 获得 **ena(4)** 增强网络驱动（11.1）；Azure 正式进入 Marketplace（11.1）；Google Compute Engine 镜像持续提供；Vagrant 官方镜像持续更新。

**史料**：FreeBSD 11.x Release Notes Virtualization/Hardware/Network Drivers 章节、vmx(4)/ena(4)/hv_netvsc(4) 等驱动手册页、Hyper-V Gen2 支持提交记录。 ［A］
