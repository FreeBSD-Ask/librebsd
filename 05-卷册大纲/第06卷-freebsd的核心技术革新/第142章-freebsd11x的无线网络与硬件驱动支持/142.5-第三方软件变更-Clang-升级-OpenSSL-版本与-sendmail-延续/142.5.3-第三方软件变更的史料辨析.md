# 142.5.3 第三方软件变更的史料辨析

**要点**：11.x 时期第三方软件变更的特点是“稳定升级、无激进取代”——Clang 持续升级但无新的编译器迁移，OpenSSL 保持 1.0.2 系列、sendmail 保持默认地位、GCC 继续保留用于非 x86 架构。与 10.0 的“集中换代”和 12.0/13.0 的“GCC 移除”相比，11.x 是三个版本周期中的“稳定期”——10.0 引入新工具链，11.x 稳定使用，12.0/13.0 完成旧工具链的移除。这种“引入-稳定-移除”三阶段模式是 FreeBSD 工程管理的典型节奏。

**史料**：FreeBSD 10.x/11.x/12.x/13.x Release Notes 对比［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档〕

**史观**：总纲第 25 条——终结与延续：11.x 作为“稳定期”的工程价值在于——它让用户有充足时间从 10.0 的“集中换代”中恢复，在生产环境中验证 Clang/LLVM/Unbound/pkg/bsdinstall 等新组件的稳定性，为 12.0/13.0 的旧组件移除创造条件

**辨析**：不应将 11.x 的“无重大第三方软件变更”视为“缺乏创新”——11.x 时期 FreeBSD 在 arm64 支持、bhyve 成熟、UEFI 完善、网络栈优化（Netflix 驱动）、虚拟化支持等方面有大量创新，只是这些创新不直接涉及第三方软件的替换
