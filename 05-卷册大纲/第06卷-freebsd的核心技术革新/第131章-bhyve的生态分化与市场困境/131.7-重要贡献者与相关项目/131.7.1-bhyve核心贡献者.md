# 131.7.1 bhyve 核心贡献者

**要点**：bhyve 的核心贡献者按贡献时间与程度排序为：Neel Natu（尼尔·纳图）（nneul@）——bhyve 初始设计者与主要作者，NetApp 员工，在 NetApp 工作期间开发了 bhyve 内核 vmm 模块与初始用户态代码；Peter Grehan（彼得·格雷汉）（grehan@）——bhyve 长期主要维护者，FreeBSD Foundation 董事会成员，负责将 bhyve 导入 FreeBSD、持续功能开发、UEFI/Windows 支持、社区协调；John Baldwin（约翰·鲍德温）（jhb@）——FreeBSD src committer，负责 AMD SVM（AMD-V）支持、PCI 直通、x2APIC 等重要功能；Mihai Carabaș——bhyve ARM64 移植主要作者；此外还有众多社区贡献者提供 bug 修复、驱动、文档与管理工具

**史料**：FreeBSD src commit log 统计（各作者提交数量与模块分布）；BSDCan/AsiaBSDCon/EuroBSDCon 会议论文作者署名；bhyve 源码版权头 ［A］

**史观**：总纲第 10 条——边缘者贡献与核心维护者的关键作用：bhyve 展示了开源项目中 “创始开发者” 与 “维护者” 角色分离的典型模式——Neel Natu 完成了初始架构设计与核心实现，Peter Grehan 则承担了长达十余年的维护、扩展、社区建设工作；大型基础设施项目的长期成功更多依赖持续维护者的坚持而非初始设计者的天才

**辨析**：bhyve 贡献者的归属需要注意：Neel Natu 在 NetApp 的工作背景意味着 bhyve 的初始开发得到了 NetApp 的商业支持，这是 bhyve 能以高质量代码起步的重要原因，并非纯粹的业余时间项目；与 KVM 由初创公司 Qumranet（后被 Red Hat 收购）的 Avi Kivity 开发类似，bhyve 也是商业公司资助开源项目的案例；原文提到的 “Qing Huang” 经多方检索未在 bhyve 主要贡献者中找到可靠记录，标注为 ［ 存疑脚注：此处事实待多源交叉验证 ］；bhyve 没有获得 FreeBSD Foundation 大规模专项资助，主要依靠维护者个人精力与商业公司（NetApp、iXsystems、Joyent）的零散贡献
