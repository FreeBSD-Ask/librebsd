# 124.2.1 要点ZFS在各平台的早期移植者1PawelDawidekpjd@FreeBSDZ

**要点**：ZFS 在各平台的早期移植者：（1）Pawel Dawidek（pjd@）——FreeBSD ZFS 移植的核心开发者，波兰开发者，FreeBSD committer，2006-2007 年完成 ZFS 到 FreeBSD 的移植，包括 Solaris API 兼容层（solaris/ directory），commit r177621（2008 年 3 月）是关键里程碑；（2）Brian Behlendorf（布莱恩·贝伦多夫）——ZFS on Linux（ZoL）创始人，2008 年启动 Linux 移植，LLNL（Lawrence Livermore National Laboratory）雇员，其工作使 ZFS 在 Linux 上可用，ZoL 后来成为 OpenZFS 2.0 的基础代码库；（3）illumos 社区——2010 年 Oracle 关闭 OpenSolaris 后，Garrett D'Amore（加勒特·达莫尔） 等人发起 illumos fork，维护 OpenSolaris 代码继续发展，成为 ZFS 上游的重要来源；（4）Matt Ahrens——ZFS 联合设计者，Bonwick 离开 Sun/Oracle 后 Ahrens 成为 OpenZFS 社区技术领袖之一，Delphix 公司雇员，持续贡献 ZFS 代码至今；（5）其他重要移植者：Adam Leventhal（Delphix）、George Wilson（Delphix/Oracle）、Andriy Gapon（FreeBSD ZFS 维护者）、Martin Matuska（FreeBSD ZFS，后加入 OpenZFS 协调）

**史观**：终结与延续：ZFS 的延续不是由 Sun/Oracle 决定的，而是由一群分散在不同公司和社区的开发者共同维系的——Dawidek 在波兰、Behlendorf 在 LLNL、Ahrens 在 Delphix、illumos 社区独立 fork，这些 “边缘者” 的努力使得 ZFS 在 Oracle 闭源后得以延续和发展

**辨析**：ZFS 移植的历史常被简化为 “Pawel Dawidek 移植到 FreeBSD”，但实际上早期 ZFS 移植是多人协作：Dawidek 是核心人物，但罗伯特·N. M. 沃森（Robert Watson）、Kip Macy 等人也参与了早期工作；ZoL 早期并非 “官方” 移植，而是 Behlendorf 的个人/LLNL 项目，直到 2010 年代中期才获得广泛认可
