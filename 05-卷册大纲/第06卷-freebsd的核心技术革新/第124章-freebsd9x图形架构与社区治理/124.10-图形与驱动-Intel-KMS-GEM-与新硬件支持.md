# 124.10 图形与驱动——Intel KMS/GEM 与新硬件支持

## 124.10.1 9.1 Intel GPU GEM/KMS 驱动

**要点**：9.1-RELEASE 新增 Intel GPU 驱动支持 GEM（Graphics Execution Manager）与 KMS（Kernel Mode Setting），这是 FreeBSD 图形栈现代化的重要一步；KMS 将显示模式设置从用户态 X 服务器移入内核，支持更快的 VT 切换、更稳定的图形性能和 suspend/resume；Radeon KMS 支持在 9.x 尚未完成，10.x 之后才引入

**史料**：FreeBSD 9.1-RELEASE Release Notes、Konrad Witaszczyk（Intel KMS 移植主要开发者）commit log ［A］

**史观**：总纲第 10 条——边缘者贡献：FreeBSD 图形驱动开发长期依赖少数志愿者（如 Konstantin Belousov（康斯坦丁·别洛乌索夫）、Konrad Witaszczyk 等）从 Linux 移植 DRM/KMS 代码，是项目中资源相对匮乏但需求广泛的领域；图形栈的延迟成熟是 FreeBSD 桌面体验落后于 Linux 的重要原因

**辨析**：9.1 Intel KMS 仅支持较旧的 Intel GPU（Ironlake/Sandy Bridge 时期），Ivy Bridge 及更新 GPU 支持在后续版本添加；Radeon/NVIDIA KMS 在 9.x 不可用

**文献**：FreeBSD 9.1-RELEASE Release Notes（Graphics Drivers 章节）；**drm(4)**、**i915kms(4)** man pages（9.1 版本） ［B］

## 124.10.2 网络驱动更新

**要点**：9.x 系列新增大量网卡驱动：9.0 新增 **bxe(4)**（Broadcom NetXtreme II 10GbE）、**cxgbe(4)**（Chelsio T4 10Gb/1Gb）、**vte(4)**（RDC R6040）、**vxge(4)**（Neterion X3100 10GbE）；**em(4)** 更新至 7.3.2、**igb(4)** 至 2.2.5、**ixgbe(4)** 至 2.3.8，新增 Intel I350 支持；9.1 新增 **oce(4)**（Emulex OneConnect 10GbE）、**sfxge(4)**（Solarflare SFC9000）、**hpt27xx(4)**（HighPoint RocketRAID 27xx SAS 6Gb/s）

**史料**：FreeBSD 9.0/9.1 Release Notes、各驱动 man pages ［B］

**史观**：总纲第 17 条——软件工程：10GbE 网卡驱动的密集引入反映了 2010-2012 年万兆以太网从数据中心向企业普及的趋势；Chelsio、Solarflare、Emulex 等高端网卡厂商主动提交或赞助 FreeBSD 驱动，体现了 FreeBSD 在服务器和网络设备市场的重要地位

**辨析**：9.x 时期 WiFi 驱动（尤其是 802.11n/**ath(4)**）持续改进但 802.11ac 支持尚不存在；USB WiFi 适配器支持在新 USB 栈下重写

**文献**：FreeBSD 9.0/9.1-RELEASE Release Notes（Network Drivers 章节）；各网卡驱动 man pages ［B］

**要点**：

- Baptiste 与原 X11 团队为 Xorg 1.18.4 升级及配套新 Intel/ATI DDX 驱动发起测试征集，以匹配内核侧新 DRM 驱动；录制时点在 FreeBSD 11 上装此补丁暂不能期待新增 GPU 支持，因为其依赖尚未合入的内核部件，需配合 DRM Next 分支与更新的 ports 分支使用。（BSD Now EP179，[289.34-351.2]，L2）
