# 138.3.4 10.2 时期的 ports 与 pkg 生态

**要点**：10.2 时期 **pkg(8)** 已成熟至 1.5.x 系列，pkg 1.3.8 在 10.1 中引入，10.2 时期 pkg 1.4/1.5 带来性能改进与 bug 修复。pkg 升级初期的兼容性问题（如 1.x 系列早期版本升级故障、jail 循环等）在 10.2 时期已大幅减少。Ports Collection 在 10.x 时期引入 pkg 子版本化支持，**portsnap(8)** 持续作为 ports 树分发工具，同时支持 svn 检出。CentOS 6 Linux 兼容层 ports（emulators/linux-c6）在 10.2 成熟，允许运行 Linux 二进制程序；CentOS 7 支持在 10.3 引入。

**史料**：FreeBSD 10.2-RELEASE Release Notes、pkg(8) 发行历史、ports/CHANGES 文件。［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L1 代码；L3 官方文档〕

**史观**：专题语（不设总纲条号）——基础设施软件的成熟节奏：**pkg(8)** 从 pkgng 原型到生产级软件包管理器的成熟过程经历了约 3 年（2012-2015），10.0-10.2 是迁移阵痛期，10.3 之后进入稳定期。这种 “M 次小版本迭代达到稳定” 是大型基础设施软件的常态。

**辨析**：原文件提到 “pkg 1.10.1 升级后整个 pkg 环境无法使用、从 1.x 升级到 2.10 时大量包被意外安装、jail 环境中 pkg 命令陷入无限循环”——这些问题发生在 pkg 1.x 早期版本（约 2014-2015 年），属迁移期真实问题但多数在 10.2 时期已修复；pkg 2.x 系列实际是在更晚版本中出现，10.x 携带的是 pkg 1.x 系列。

**文献**：FreeBSD 10.2-RELEASE Release Notes [Z]. 2015；Daroussin B, Drewery B. pkg: The FreeBSD Package Manager [C]//AsiaBSDCon 2014. Tokyo, 2014.
