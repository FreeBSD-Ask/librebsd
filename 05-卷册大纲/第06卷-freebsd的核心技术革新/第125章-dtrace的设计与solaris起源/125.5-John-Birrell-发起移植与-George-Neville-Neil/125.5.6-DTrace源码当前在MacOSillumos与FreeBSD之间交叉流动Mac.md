# 125.5.6 DTrace源码当前在MacOSillumos与FreeBSD之间交叉流动Mac

- DTrace 源码当前在 Mac OS、illumos 与 FreeBSD 之间交叉流动：Mac OS 自 FreeBSD 拉取并亦自 illumos 取用，FreeBSD 则回馈补丁，另有 Linux 移植与 Windows 移植设想，但无任何项目可充任唯一权威上游，多数人仍以 illumos 为参照。为此演讲人提出 OpenDTrace：设立 GitHub 组织、沿用 Jonathan Anderson 此前采用的 RFC 变更流程，先以数月把 FreeBSD 专属改动归位、达成跨系统功能对等，并着手为 DTrace 的数据结构与运行时格式撰写正式规格——规格化既便利扩展者理解设计意图，也为因 CDDL 许可证障碍而拒绝使用该代码的第三方提供净室重实现的依据。[订正：原“沿用 illumos 社区的 RFC 变更流程”→新转写证实 RFC 流程系 Jonathan Anderson 此前所用（新转写作 Joint and Sun）；原“Mac OS 主要自 illumos 拉取，FreeBSD 向 illumos 回馈补丁”→新转写实为“macOS pulls things from us and I think they also get stuff from Illumos. We send patches back”，即 Mac OS 亦自 FreeBSD 取用]（YouTube EPj_TVpq8S2Io，[2165.2-2380.7]，L1）
