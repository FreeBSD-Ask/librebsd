# 135.5.1 2012 年安全团队交接

**要点**：Simon L. B. Nielsen 卸任 Security Officer（2004-2012），交接暴露单点故障风险——大部分安全公告知识未被文档化。

**史料**：安全团队 2012 年度报告 ［A］

**史观**：总纲第 1 条——知识管理的制度化。

**辨析**：

**辨析**：安全事件的公开披露与修复时间线存在选择性记录——项目倾向披露已修复的漏洞而淡化未修复的零日漏洞。安全审计的外部独立验证不足，大部分安全声明依赖项目自述。不同 BSD 项目间的安全实践比较需注意威胁模型的差异——面向服务器的 OpenBSD 与面向嵌入式 NetBSD 的安全需求不可直接对比。
**文献**：安全团队报告 ［A］
