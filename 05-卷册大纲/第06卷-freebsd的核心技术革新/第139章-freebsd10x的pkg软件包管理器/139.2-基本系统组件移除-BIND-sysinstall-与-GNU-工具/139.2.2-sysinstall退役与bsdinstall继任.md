# 139.2.2 sysinstall 退役与 bsdinstall 继任

**要点**：**sysinstall(8)**——FreeBSD 自 2.0 起使用的安装程序——在 FreeBSD 10.0 正式从 base 移除（r225937）。sysinstall 由 Jordan Hubbard 等人在 1990 年代开发，采用 TUI（文本用户界面）与 ad-hoc 配置文件，是 1990 年代 Unix 安装程序的典型代表，但代码架构僵化难以扩展（如无法支持 ZFS 引导、UEFI、GELI 加密等新特性）。sysinstall 由 **bsdinstall(8)** 完全替代，bsdinstall 是重写的模块化安装程序，采用 shell 脚本与 C 工具组合架构，设计更灵活可扩展。与 sysinstall 一同移除的还有其依赖的辅助库与工具：libdisk、libftpio、sade（磁盘分区编辑器）。**bsdconfig(8)** 作为系统配置工具（TUI）提供 sysinstall 中 post-install 配置功能的继任。bsdinstall 在 10.0 已支持 ZFS Root-on-ZFS 自动安装（BIOS 模式，r256361），10.3 加入 UEFI 模式 Root-on-ZFS 自动安装支持。

**史料**：FreeBSD 10.0 Release Notes（sysinstall removed, replaced by bsdinstall, r225937）、bsdinstall(8)/bsdconfig(8) 手册页、Nathan Whitehorn（nwhitehorn@）bsdinstall 设计文档与提交记录。 ［A］

**史观**：软件工程：sysinstall 服役近 20 年（1994-2014），是 FreeBSD 历史上最长寿的基础设施组件之一。其退役体现了软件架构生命周期规律——当旧架构无法通过渐进修改适应新需求（ZFS、UEFI、GELI）时，完全重写成为唯一选择。bsdinstall 的模块化设计（shell 脚本驱动、可扩展分区后端）使其能适应 10.x 之后多年的新硬件与新文件系统需求。

**辨析**：**sade(8)** 虽随 sysinstall 移除，但 bsdconfig 提供了部分磁盘配置功能；10.0 中 bsdinstall 仍缺少部分 sysinstall 功能（如详细的软件包选择界面），这些功能在后续版本逐步补全；部分老用户因怀旧或习惯继续偏好 sysinstall 界面，但 sysinstall 在 10.x 后不再可用。
