# 127.1.1 Capsicum 论文的核心技术贡献

**要点**：Capsicum 由剑桥大学计算机实验室 罗伯特·N. M. 沃森 团队与 Google 合作设计，核心论文“Capsicum: Practical Capabilities for UNIX”于 2010 年 8 月在第 19 届 USENIX Security Symposium（华盛顿特区）发表；作者为 罗伯特·N. M. 沃森（剑桥）、Jonathan Anderson（剑桥）、Ben Laurie（Google）、Kris Kennaway（Google/FreeBSD committer）；论文提出三大核心 OS 原语：能力文件描述符（capabilities，带细粒度权限位的文件描述符）、能力模式（capability mode，通过 **cap_enter(2)** 系统调用进入的单向沙箱态，进程丧失对全局命名空间的访问权）、进程描述符（process descriptors，以文件描述符替代 PID 的能力中心进程管理）；论文原型基于 FreeBSD 8.x 开发，同步完成了 tcpdump、dhclient、gzip、OpenSSH 以及 Chromium 浏览器的沙箱改造演示

**史观**：项目统摄史观〔订正注：原“总纲第 1 条”伪标签去条号，权威总纲 1 为“一切真历史都是古代史”〕：Capsicum 论文是 UNIX 安全模型的“源头时刻”——Watson 团队在 2008-2010 年间选择了一条与当时主流沙箱方案完全不同的路径：不引入新的内核策略层（如 SELinux/AppArmor 式的 MAC 标签），不改造用户态全局权限模型（如 POSIX capabilities 式的 root 权限分割），而是复用 UNIX 已存在五十年的文件描述符抽象，将其改造为能力句柄；这一“在旧抽象中植入新安全语义”的设计决策与 BSD 一贯的渐进式工程哲学一致

**辨析**：论文第四作者名字存在长期讹误——原文及诸多中文资料写为“Kenneally”，经论文 PDF 与 USENIX 官方议程交叉验证应为 Kris Kennaway（FreeBSD 长期 committer，后任职 Google）；Pawel Jakub Dawidek 常被误认为 Capsicum 论文作者——Dawidek 是 FreeBSD 侧 Capsicum 后续实现与 casperd 的核心开发者，但并非 2010 年 USENIX Security 论文作者；Capsicum 设计思想溯源可至 Henry Levy《Capability-Based Computer Systems》（1984）中系统化的 PSOS、KeyKOS、CAP computer 等能力系统，但论文本身对这些前驱的引用集中在 related work 节而非设计主体；[考据完成：2026-08-15 复核查] 参考文献库验证通过：people 模式检索“Watson”命中 reference_id=206《Capsicum: Practical Capabilities for UNIX》（USENIX Security 2010，Watson/Anderson/Laurie/Kennaway，context "Capsicum: practical capabilities for UNIX Robert N. M. Watson University of Cambridge"），与论文作者、机构、年份一致
