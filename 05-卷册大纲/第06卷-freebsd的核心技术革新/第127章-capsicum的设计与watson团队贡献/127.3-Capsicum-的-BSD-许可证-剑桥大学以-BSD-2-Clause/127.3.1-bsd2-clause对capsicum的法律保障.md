# 127.3.1 BSD 2-Clause 对 Capsicum 的法律保障

**要点**：Capsicum 代码以 BSD 2-Clause License（Simplified BSD License / FreeBSD License）发布，由剑桥大学计算机实验室持有版权；BSD 2-Clause 许可证授权条款为：允许源代码和二进制形式的再分发与使用，无论是否修改，条件是保留版权声明和许可声明，不使用作者/机构名字背书衍生产品；这一许可证选择使 Capsicum 代码可直接合入 FreeBSD 基本系统（FreeBSD 本身即以 BSD 2-Clause/3-Clause 类许可证发布），不存在任何许可证兼容性障碍；Capsicum 内核代码与用户态库代码均放置在 FreeBSD src 树的常规位置（sys/kern/sys_capability.c、lib/libcapsicum/ 等），非 contrib/ 目录下的外部代码（与 CDDL 许可的 ZFS/DTrace 放置在 cddl/ 目录不同），这表明 Capsicum 被视为 FreeBSD 原生组件而非第三方导入

**史观**：总纲第 13 条——法律与道德是利益分配：BSD 许可证选择是学术研究成果向工业界转化的关键法律决策——剑桥大学作为学术机构选择 BSD 2-Clause 而非 GPL 或 LGPL，使得 Capsicum 能被 FreeBSD、DragonFly BSD、Google（capsicum-linux）等各方自由采纳，包括用于商业产品；这与 CHERI 指令集规范同样采用 BSD 风格许可证的决策一致（参见 081.6 节），体现了安全基础设施研究中“开放规范促进采纳”的治理哲学

**辨析**：Capsicum 版权持有者需精确表述——核心代码由剑桥大学计算机实验室开发并持有版权，Pawel Jakub Dawidek 的后续工程工作以 FreeBSD Foundation 资助形式贡献，其代码版权归 FreeBSD Foundation 或其本人持有；“BSD 许可证”说法需区分 BSD 2-Clause 与 BSD 3-Clause——Capsicum 使用的是更宽松的 BSD 2-Clause（无“不得用于宣传背书”的第 3 条款，但 FreeBSD 项目整体使用 BSD 2-Clause 和 BSD 3-Clause 的混合，二者均为 GPL 兼容）
