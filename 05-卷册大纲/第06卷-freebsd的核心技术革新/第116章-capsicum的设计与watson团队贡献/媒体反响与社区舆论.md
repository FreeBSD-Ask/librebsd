- **与本章主题的关联说明**：本章记述 Capsicum 概念在 2010-2018 年的扩展应用，CloudABI 是 Capsicum 从 FreeBSD 内核框架向跨平台云运行时演化的关键节点。

### 新闻条目 3

- **新闻标题（中英）**：Landlock 第 11 次修订，用于无特权但强大的安全沙箱（Landlock Revved An 11th Time For Unprivileged Yet Powerful Security Sandboxes）
- **新闻来源**：Phoronix + Michael Larabel + 2019-10-30 + <https://www.phoronix.com/news/Landlock-11-Linux-LSM> + <https://web.archive.org/web/2019/https://www.phoronix.com/news/Landlock-11-Linux-LSM>
- **新闻摘要**：2019 年 10 月 Linux 内核 Landlock LSM 第 11 次修订发布，目标是无特权安全沙箱。Landlock 的设计明确参考了 FreeBSD Capsicum 的“能力（capability）”模型，但以 Linux 内核兼容方式实现。这一动向印证了 Capsicum 设计对操作系统安全范式的长期影响。
- **与本章主题的关联说明**：本章记述 Capsicum 设计对后续操作系统安全框架的影响，Landlock 是 Capsicum 概念在 Linux 侧的演化产物。
- **与官方史料的交叉验证结论**：Landlock 论文（Vincent Dary 等）与 Linux 内核邮件列表可交叉验证；Capsicum 论文（Watson 等，USENIX Security 2010）是 Landlock 设计的明确参考文献。

### 新闻条目 4

- **新闻标题（中英）**：Landlock 落地 Linux 5.13，用于无特权应用沙箱（“Landlock”Lands In Linux 5.13 For Unprivileged Application Sandboxing）
- **新闻来源**：Phoronix + Michael Larabel + 2021-05-02 + <https://www.phoronix.com/news/Linux-5.13-Landlock-Lands> + <https://web.archive.org/web/2021/https://www.phoronix.com/news/Linux-5.13-Landlock-Lands>
- **新闻摘要**：2021 年 5 月 Linux 5.13 正式合并 Landlock LSM，提供无特权应用沙箱能力。Landlock 的合并标志着 Capsicum 概念（2010 年 FreeBSD 首创）在 Linux 侧的正式落地，距 FreeBSD 9.0 集成 Capsicum 已 11 年。
- **与本章主题的关联说明**：本章记述 Capsicum 设计的长期影响，2021 年 Landlock 在 Linux 落地是 Capsicum 概念跨平台扩散的关键节点。
- **与官方史料的交叉验证结论**：Linux 5.13 发行说明与 Landlock 代码合并 commit 可交叉验证；Phoronix 报道与 Linux 内核官方史料一致。
