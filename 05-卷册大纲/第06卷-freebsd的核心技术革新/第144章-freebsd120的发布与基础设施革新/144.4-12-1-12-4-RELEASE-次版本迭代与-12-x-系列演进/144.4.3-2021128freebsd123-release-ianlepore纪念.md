# 144.4.3 2021.12.8 FreeBSD 12.3-RELEASE——Ian Lepore 纪念

**要点**：FreeBSD 12.3-RELEASE 于 2021 年 12 月 8 日正式发布（release/12.3.0 tag 于 2021 年 12 月 3 日创建，公告日期为 12 月 8 日，二者相差 5 日），stable/12 第四个版本。核心更新：网络驱动更新、用户态工具改进、内核 bug 修复、第三方软件更新。12.3 献词页献给 Ian Lepore（ian@）——他是 FreeBSD ARM 移植的核心开发者之一，对 ARM/嵌入式平台支持做出了不可磨灭的贡献，于 2021 年去世。架构列表恢复 armv7：amd64、i386、powerpc、powerpc64、sparc64、armv6、armv7、aarch64 共 8 种；powerpcspe 仍未列入。AWS arm64 AMI 可用 SSM Parameter Store 查找。12.3 EOL 为 2023 年 3 月 31 日。Release Team 与 12.2 基本相同，Tom Rhodes（trhodes@）因 Release Notes 工作获特别感谢。WireGuard 争议事件（2020 年 12 月 -2021 年 3 月，Jason Donenfeld/Netgate 代码导入争议）发生在 13.0 周期而非 12.x 周期，但对整个社区治理产生了深远影响。

**史料**：FreeBSD 12.3-RELEASE Announcement（2021-12-08，明确献词给 Ian Lepore、架构列表）、FreeBSD 12.3-RELEASE Release Notes、Ian Lepore commit 历史与纪念帖；**freebsd.duckdb** `tags` 表 `freebsd-src` 仓库 release tag 数据库验证——`release/12.3.0` tagger_date = 2021-12-03T20:03:04-05:00，tagger_name = Glen Barber，target_commit_hash = `70cb68e7a00ac0310a2d0ca428c1d5018e6d39e1`，target_commit_date = 2021-12-01T19:08:38-05:00，tag_type = annotated，tag_message =“Tag release/12.3.0”，与公开声明日期 2021-12-08 相差 5 日（即 tag 创建后约 5 日才正式发布，符合 FreeBSD 发布工程“tag 先行、公告随后”的标准节奏）；target_commit_date = 2021-12-01T19:08:38-05:00 早于 tagger_date 约 2 日，反映 tag 指向的 commit 与 tag 创建之间存在 Git 操作延迟（注意 12.3 已是 Git 时代发布的版本，时区标记为 -05:00 EST） ［A］

**史观**：总纲第 10 条——边缘者贡献：Ian Lepore 代表了嵌入式/ARM 平台的“边缘架构”贡献者群体。与 amd64 由多家公司赞助开发不同，ARM 支持长期依赖少数核心开发者（Andrew Turner、Ian Lepore、Oleksandr Tymoshenko 等）的志愿贡献与 FreeBSD Foundation 部分赞助。Lepore 的去世是 FreeBSD ARM 社区的重大损失。

**辨析**：12.3 主要是维护版本而非新功能版本——这符合 .3/.4 版本在 FreeBSD 发布周期中的定位：早期点版本引入新特性，后期点版本聚焦稳定性与安全修复。WireGuard 争议虽主要在 13.0 周期，但间接影响了 12.x 的 backport 决策——争议期间 12.x 未合入有争议的 WireGuard 代码。**数据库验证结论**：`release/12.3.0` tagger_date = 2021-12-03T20:03:04-05:00（EST 时区）早于公开声明日期 2021-12-08 共 5 日，与 12.x 系列其他版本对比处于正常范围（12.0 偏差 4 日、12.1 偏差 0 日、12.2 偏差 16 日、12.4 偏差 0 日）；原文件标注“FreeBSD 12.3-RELEASE 于 2021 年 12 月 7 日发布”——经数据库验证，2021-12-03 为 release tag 创建日期，正式公告日期为 2021-12-08，二者相差 5 日，原文件标注的 12 月 7 日既非 tag 日期也非公告日期，可能是早期文档记录错误或时区差异所致；0 信任原则提示：12.3 已是 Git 时代发布的版本（2020 年 12 月 SVN-to-Git 迁移后），tagger_date 为 Git 原生元数据，可信度极高；时区 -05:00 反映 tagger Glen Barber 当时所在 EST 时区
