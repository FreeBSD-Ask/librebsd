# 144.4.1 2019.11.4 FreeBSD 12.1-RELEASE——BearSSL 导入与 Kurt Lidl 纪念

**要点**：FreeBSD 12.1-RELEASE 于 2019 年 11 月 4 日发布，是 stable/12 第二个版本。核心更新：Clang/LLVM/LLD/LLDB/compiler-rt/libc++ 全套升级至 8.0.1；OpenSSL 更新至 1.1.1d；BearSSL（轻量级 TLS 库，BSD 许可）导入 base 系统用于验证和安全相关功能；默认 PAGER 改为 **less(1)** 等用户态改进延续至正式版。12.1 献词页献给 Kurt Lidl——他是 FreeBSD 项目长期贡献者，在 PPP、网络子系统等领域有重要贡献。Release Team 名单中 Remko Lodder 不再担任 Security Officer Deputy（仅 Ed Maste（埃德·马斯特） 留任 Deputy）。赞助企业新增 Rubicon Communications（Netgate/pfSense）。12.1 支持 amd64、i386、powerpc、powerpc64、powerpcspe、sparc64、armv6、armv7、aarch64 共九种架构（与 12.0 相同），AWS 首次提供 arm64 AMI 镜像。12.1 EOL 为 2021 年 1 月 31 日。

**史料**：FreeBSD 12.1-RELEASE Announcement（2019-11-04，明确 Clang 8.0.1、BearSSL 导入、献词给 Kurt Lidl、AWS arm64 AMI）、FreeBSD 12.1-RELEASE Release Notes；**freebsd.duckdb** `tags` 表 `freebsd-src` 仓库 release tag 数据库验证——`release/12.1.0` tagger_date = 2019-11-04T18:34:29Z，tagger_name = Glen Barber（格伦·巴伯），target_commit_hash = `cc807f9e55c25fe811f7db5d1540455ff2bf8716`，target_commit_date = 2019-11-01T00:00:17Z，tag_type = annotated，tag_message =“Tag releng/12.1@r354233 as release/12.1.0 (12.1-RELEASE).”，与公开声明日期 2019-11-04 同日（即 tag 创建当日即正式发布，是 12.x 系列中 tag 与公告日期最接近的版本之一，反映 12.1 发布过程顺畅未发生镜像重建等问题）；target_commit_date = 2019-11-01T00:00:17Z 早于 tagger_date 约 3 日，反映 tag 指向的 commit 与 tag 创建之间存在 SVN 操作延迟 ［A］

**史观**：终结与延续：BearSSL 导入 base 系统是 FreeBSD 对 TLS 生态多样化的探索——BearSSL 由 Thomas Pornin 开发，以代码简洁、内存安全、可审计性著称，与 OpenSSL 的庞大代码库形成对比。虽然 BearSSL 在 FreeBSD 中主要用于有限的内部场景而非替代 OpenSSL，但它的引入体现了 FreeBSD 不依赖单一 TLS 实现的风险分散策略。

**辨析**：BearSSL 导入 base 并不意味着它替代 OpenSSL——OpenSSL 仍是默认 TLS 库，BearSSL 主要用于特定安全敏感组件（如 veriexec 签名验证等场景）；12.1 中 Linux 兼容层仍以 CentOS 7（linux-c7）ports 为主，Ubuntu 兼容层（linux-ubuntu）在更晚版本引入。**数据库验证结论**：`release/12.1.0` tagger_date = 2019-11-04T18:34:29Z 与公开声明日期 2019-11-04 完全一致（同日），是 12.x 系列中偏差最小的版本（对比 12.0 偏差 4 日、12.2 偏差 16 日、12.3 偏差 5 日、12.4 偏差 0 日），反映 12.1 发布过程顺畅；0 信任原则提示：12.1 在 SVN 时代发布（2020 年 SVN-to-Git 迁移前），tagger_date 由迁移脚本根据原始 SVN 元数据回填，可信度较高；target_commit_date 与 tagger_date 之间存在 3 日差，可能反映 SVN 时代 committer_date 与 tagger_date 由不同人员在不同时间执行
