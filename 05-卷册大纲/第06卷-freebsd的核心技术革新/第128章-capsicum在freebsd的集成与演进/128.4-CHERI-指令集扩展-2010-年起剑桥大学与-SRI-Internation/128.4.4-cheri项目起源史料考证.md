**要点**：

- Brooks Davis 自述 CHERI 是剑桥大学与 SRI International 开发的能力硬件扩展，以不可伪造的 capability 替代裸指针，为分配空间附加边界与标签，从而在架构层阻断缓冲区溢出，并抑制大部分时序内存安全漏洞。（BSD Now EP486，[402.5-532.2]，L1）[订正：原 [419.69-546.33]，2026-09-30 SenseAudio 重转核对]
- Morello 是由 UKRI“Digital Security by Design”计划与 ARM 共同出资的全尺寸原型芯片，在 ARM N1（Amazon Graviton 所用核型）上加入 CHERI，从架构到 tape out 仅用一年，制造成本逾一亿英镑；其目标之一是打破软件界不愿面向不存在硬件编程、硬件界不愿制造无人使用硬件的僵局。（BSD Now EP486，[581.9-781.9]，L1）[订正：原 [583.47-774.5]，2026-09-30 SenseAudio 重转核对]
- Brooks Davis 称 FreeBSD 是首个面向或在 Morello 上开发的操作系统；团队十年前从 64 位 MIPS 起步将 FreeBSD 移植为 CheriBSD，此后并行开展 RISC-V 与 ARM 端口，并自动化了 FreeBSD 兼容层创建，使新增系统调用时只需正确标注即可判断是否需要兼容函数。（BSD Now EP486，[802.1-999.9]，L1）[订正：原 “Brooks Davis 称 CheriBSD 是首个在 Morello 上开发的操作系统；团队十年前从 64 位 MIPS 起步将 FreeBSD 移植为 CheriBSD，此后并行开展 RISC-V 与 ARM 端口，并自动化了 FreeBSD 兼容层创建，使新增系统调用时只需正确标注即可判断是否需要兼容函数。（BSD Now EP486，[821.15-999.65]，L1）”，2026-09-30 SenseAudio 重转核对]
- Olivier Cochard-Labbé 自述 2005 年为搭建家用 NAS 修补 m0n0wall 防火墙时偶然发现其底层并非 Linux 而是 FreeBSD，遂将防火墙配置替换为 Samba 配置，由此创建 FreeNAS；FreeNAS 最初只是面向家庭文件共享的 PHP Web 界面加 gvinum RAID 方案。（BSD Now EP486，[1219.7-1502.3]，L1）[订正：原 [1225.45-1346.59]，2026-10-01 SenseAudio 重转核对]

- Brooks Davis 在亚洲 BSDCon 受访时自述，CHERI 项目为支持自研研究处理器而维护 FreeBSD 的分支（转写误作 CherryBSD），在 MIPS64 指令集基础上增加 ISA 扩展以实现空间内存安全，并辅以时间内存安全框架；在改动最深的纯能力模式下缓冲区溢出被消解，越界将触发硬件异常而非任意行为，编译后的 SSH 理论上不应再有缓冲区溢出；项目由 DARPA 资助、至受访时已进行约五年，因既有 MIPS32 FPGA 设计而选择 MIPS64，并向 RISC-V 与标记内存方向延展。（BSD Now EP139，[1436.4-1546.5]，L1）[订正：原 [1444.10-1541.46]，2026-09-30 SenseAudio 重转核对]
