# 131.6 社区治理、Core Team 与重要贡献者

## 131.6.1 2014/2016/2018 Core Team 选举

**要点**：FreeBSD Core Team（核心团队）是项目的最高治理机构，由活跃 committer 每两年选举产生。11.x 时期跨越三次 Core Team 选举：①2014 年选举——产生 2014-2016 届 Core Team；②2016 年选举——2016 年 5-6 月举行，产生 2016-2018 届 Core Team；③2018 年选举——2018 年举行，产生 2018-2020 届 Core Team。Core Team 职责包括：committer 权限的授予与撤销、项目方向决策、争端解决、与 FreeBSD Foundation 协调、新 Core Team 选举组织。2016/2018 届 Core Team 成员包括 George V. Neville-Neil（主席）、Benedict Reuschling（秘书）、Ed Maste（埃德·马斯特）、Gleb Smirnoff、John Baldwin（约翰·鲍德温）、Konstantin Belousov（康斯坦丁·别洛乌索夫）、Kris Moore（克里斯·摩尔）、Philip Paeps（菲利普·佩普斯）、Sean Chittenden 等（不同届次有变动）。11.x 时期没有公开的大规模 committer 权限撤销事件，社区治理相对平稳。

**史料**：FreeBSD Core Team 选举公告（freebsd-announce 邮件列表）、Core Team 页面各届成员名单、core-secretary 邮件列表归档。 ［A］

**史观**：社区治理（专题语，不设总纲条号；原挂“总纲第 23 条——社区治理”系伪标签，权威第 23 条为“一切历史写作都是基于哲学设定的历史小说”，依 2026-09-14 核查报告去条号留论旨）：FreeBSD Core Team 是“开发者自治”模式的典型——由活跃开发者选举产生核心团队，核心团队对开发者负责，没有单一企业或个人能控制项目。这种治理模式与 Linux 的“仁慈独裁者”（林纳斯·托瓦兹（Linus Torvalds）长期拥有最终决策权）模式形成对比。两年一次的定期选举保证了核心团队的新陈代谢。

**辨析**：2014-2018 年间 Core Team 没有公开撤销 committer 权限的案例——这一时期社区治理相对和谐，未发生像 2000 年代初（core 辞职风波）或 2020 年代初（WireGuard 争议）那样的重大治理冲突。committer 权限变动多为自然退役（committer 因个人原因申请退位）而非强制撤销。

**文献**：FreeBSD Core Team Election Announcements [Z]. freebsd-announce mailing list, 2014/2016/2018；FreeBSD Core Team page [EB/OL]. freebsd.org/internal/. ［A］

## 131.6.2 Security Officer 交接与安全团队

**要点**：FreeBSD Security Team 负责安全漏洞响应、安全公告发布、安全补丁维护。Colin Percival（cperciva@）自 2004 年起担任 Security Officer 长达约十年，是 FreeBSD 安全响应体系的建立者，卸任后保留 Security Officer Emeritus（荣誉安全官）称号。10.x-11.x 早期 Security Officer 为 Dag-Erling Smørgrav（des@）与 Xin Li（delphij@）。11.2-RELEASE（2018.6）Release Team 名单标志着正式交接：Xin Li 转为 Security Officer Emeritus，Gordon Tetlow（戈登·泰特洛）（gordon@）接任 Security Officer，Ed Maste（emaste@）任 Security Officer Deputy。Gordon Tetlow 长期参与 FreeBSD 安全工作与 portmgr 团队工作，其接任保证了安全团队的连续性。Security Team 其他成员包括 Remko Lodder（Security Team Liaison）、Gleb Smirnoff 等。安全团队的职责包括接收安全漏洞报告、评估严重性、协调补丁开发、发布 FreeBSD Security Advisory（SA）与 Errata Notice（EN）。

**史料**：FreeBSD 11.0-11.4 RELEASE Announcements 中 Release Team 名单（Security Officer 职务变化）、FreeBSD Security Team 页面历史、Colin Percival 关于 FreeBSD Security Officer 工作的文章。［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档；L5 二手研究〕

**史观**：社区治理（专题语，不设总纲条号；原挂“总纲第 23 条——社区治理”系伪标签，权威第 23 条为“一切历史写作都是基于哲学设定的历史小说”，依 2026-09-14 核查报告去条号留论旨）：安全团队的平稳交接是 FreeBSD 项目成熟度的体现——安全漏洞响应能力直接关系到操作系统的可信度，交接过程不能出现空档。Security Officer Emeritus 制度使经验丰富的前安全官能够继续以顾问身份参与，Dag-Erling Smørgrav、Xin Li、Colin Percival 等 Emeritus 成员在 11.x 时期仍参与安全问题处理。

**辨析**：Colin Percival 正式卸任 Security Officer 实际发生在 2010 年代初早于 11.x 时期，但他作为 Security Officer Emeritus 持续参与安全工作，11.2 Announcement 仍特别感谢他协助解决 EC2 问题——他的贡献贯穿 11.x 始终。Gordon Tetlow 在 11.2 正式接任 Security Officer 前已参与安全团队工作多年，属于内部晋升而非外部空降。

## 131.6.3 FreeBSD Foundation 资助项目

**要点**：FreeBSD Foundation（FreeBSD 基金会）在 11.x 时期持续加大项目资助力度，赞助了多项关键基础设施开发。11.x 时期获得基金会赞助的项目包括但不限于：①arm64/AArch64 移植与成熟化（Andrew Turner 等持续获得赞助）；②UEFI 引导完善与 UEFI Secure Boot 支持（**uefisign(8)**、**efivar(8)**、**efibootmgr(8)** 等工具开发）；③ **vt(4)** Newcons 控制台性能优化（r271128 等明确标注赞助）；④ **fstyp(8)**、**ar(1)** 安全改进、**ar(1)** 默认确定性模式等用户空间工具开发（多个 commit 标注 Sponsored by The FreeBSD Foundation）；⑤bhyve 虚拟化改进；⑥ELF Tool Chain 项目替换 GNU binutils 工具链；⑦FreeBSD 安全改进与 Capsicum 推广；⑧ 持续的开发者峰会（BSDCan、AsiaBSDCon、EuroBSDCon、vBSDCon）资助；⑨ 文档改进与市场营销。基金会资金主要来自企业捐赠（NetApp、Juniper、iXsystems、Netflix、Dell EMC、Microsoft、Google、Amazon 等）与个人捐赠。

**史料**：FreeBSD Foundation 2016-2020 年度报告（年报详细列出年度资助项目清单与赞助金额）、svn commit 记录中“Sponsored by The FreeBSD Foundation”标注、FreeBSD Quarterly Status Reports Foundation 章节。 ［A］

**史观**：开源运动（专题语，不设总纲条号；原挂“总纲第 22 条——开源运动”系伪标签，权威第 22 条为“知识注定过时”，依 2026-09-14 核查报告去条号留论旨）：FreeBSD Foundation 从早期的“法律庇护与会议组织”角色转变为 2010 年代后“直接赞助开发”的角色，是 FreeBSD 工程能力的重要放大器。与 Linux 基金会相比，FreeBSD Foundation 资金规模较小但使用集中，能够直接资助关键架构（如 arm64）与基础设施（如 UEFI）开发，这是 11.x 时期 FreeBSD 能够持续进步的重要资金保障。

**辨析**：FreeBSD Foundation 资助的项目占 FreeBSD 总开发量的比例虽远不及企业贡献者（Netflix、Juniper、Intel、Dell、Microsoft 等公司雇员直接贡献大量代码），但基金会赞助填补了“商业公司不愿投入但项目必需”的基础设施缺口，如非热门架构移植、安全工具链改进、文档工作等。

**文献**：FreeBSD Foundation Annual Reports 2016-2020 [R]. freebsdfoundation.org；svn commit log sponsorship markers [Z]. ［A］
