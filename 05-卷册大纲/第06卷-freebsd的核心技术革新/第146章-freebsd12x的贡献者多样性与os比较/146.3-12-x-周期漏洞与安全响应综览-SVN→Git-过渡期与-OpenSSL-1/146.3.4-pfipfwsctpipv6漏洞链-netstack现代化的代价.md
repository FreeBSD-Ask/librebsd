# 146.3.4 pf/ipfw/SCTP/IPv6 漏洞链——netstack 现代化的代价

**要点**：12.x 周期内 FreeBSD 网络子系统共发布 **15 个 SA**（正文列举与下表合计一致），是同期 SA 数量最多的子系统集群——pf 2 个（**SA-19:05.pf** IPv6 分片重组 panic、**SA-19:06.pf** ICMP/ICMP6 包过滤绕过，CVE-2019-5597/5598，Kristof Provost 修复，commit `6f4909de5fef`、`64af73aadea5`）、ipfw 1 个（**SA-20:10.ipfw** mbuf 处理漏洞，CVE-2019-15874 与 CVE-2019-5614，commit `c4ea09589c68`）、SCTP 2 个（**SA-20:14.sctp** SCTP-AUTH 共享密钥更新检查不足 CVE-2019-15878、**SA-20:25.sctp** SCTP 套接字 use-after-free CVE-2020-7463，commit `411de40890ab`）、IPv6 系列 3 个（**SA-20:20.ipv6** 套接字选项竞争 CVE-2020-7457、**SA-20:24.ipv6** Hop-by-Hop 选项 use-after-free CVE-2020-7462、**SA-20:31.icmp6** ICMPv6 错误消息 use-after-free CVE-2020-7469，commit `1f6a45d684ff`）、TCP SYN cache 1 个（**SA-20:04.tcp** IPv6 SYN cache 内核信息泄露 CVE-2020-7451，commit `986219318e60`）、ICMPv6/MLDv2 1 个（**SA-19:19.mldv2** 越界内存访问 CVE-2019-5608，commit `559bc7e1f903`）、bsnmp 1 个（**SA-19:20.bsnmp** ASN.1 消息长度验证不足 CVE-2019-5610）、rtsold 1 个（**SA-20:32.rtsold** 多处缓冲区溢出 CVE-2020-25577，commit `f2fb8af15522`，Mark Johnston（马克·约翰斯顿） 修复）、IPsec 1 个（**SA-20:02.ipsec** 反重放窗口检查缺失 CVE-2019-5613）、dhclient 1 个（**SA-20:26.dhclient** 堆溢出 CVE-2020-7461）、libresolv 相关 1 个（**SA-21:01.fsdisclosure** 文件系统信息泄露）；这一漏洞群反映 12.x 周期 netstack 现代化（VNET 默认启用、pf in jail、iflib 框架推广）带来的攻击面扩张

**史料**：**freebsd.duckdb** `commits` 表 `freebsd-src` 仓库 netstack CVE commit 查询：`SELECT commit_hash, author_date, author_name, message_subject FROM commits WHERE repo_name='freebsd-src' AND author_date>='2018-12-01' AND author_date<'2021-04-01' AND (message_subject LIKE '%pf%' OR message_subject LIKE '%ipfw%' OR message_subject LIKE '%SCTP%' OR message_subject LIKE '%icmp6%' OR message_subject LIKE '%ipv6%' OR message_subject LIKE '%rtsold%' OR message_subject LIKE '%ipsec%' OR message_subject LIKE '%dhclient%' OR message_subject LIKE '%bsnmp%') AND message_body LIKE '%CVE-%' ORDER BY author_date ASC`；FreeBSD-SA-19:05.pf、SA-19:06.pf、SA-19:19.mldv2、SA-19:20.bsnmp、SA-20:02.ipsec、SA-20:04.tcp、SA-20:10.ipfw、SA-20:14.sctp、SA-20:20.ipv6、SA-20:24.ipv6、SA-20:25.sctp、SA-20:26.dhclient、SA-20:31.icmp6、SA-20:32.rtsold PGP 签名公告；Kristof Provost pf 测试 commit `15426769bbe2`、`0fc80e44f600`（CVE-2019-5597/5598 回归测试）；Mark Johnston rtsold 修复 commit `e937464e2b89` ［A］

**史观**：总纲第 9 条——经验优先：12.x 周期 netstack 漏洞群密集爆发，是“网络栈现代化代价”的典型样本——12.0 默认启用 VIMAGE/VNET 使每个 jail 拥有独立网络栈，pf 可在 jail 中独立运行，iflib 框架推广使大量网卡驱动迁移到新框架；这些现代化改进提升了功能与性能，但同时也使网络栈代码路径大幅扩展——VNET 引入 per-instance 网络状态后，原本“全局唯一”的网络数据结构变为“per-vnet”，每个 vnet 实例的状态隔离边界成为新攻击面；pf in jail 使攻击者可通过 jail 内操作触发 pf 内核代码路径；SCTP 协议在 12.x 仍为 base 系统组件（13.x 起考虑移除），其复杂的状态机是漏洞高发区；**与 14.x 周期对比**：14.x 周期 netstack SA 显著减少（约 4-5 个），反映 12.x 周期 netstack 现代化引入的攻击面已在 12.x 末期与 13.x 周期被逐步清理

**辨析**：**需精确说明 pf 漏洞的攻防语义**：CVE-2019-5597（IPv6 分片重组 panic）是 DoS 漏洞——恶意 IPv6 分片可使内核 panic，但不泄露数据；CVE-2019-5598（ICMP/ICMP6 包过滤绕过）是过滤绕过——pf 规则集可能被绕过但非内核 panic；两者性质不同但同属 pf 协议解析漏洞；**SCTP 漏洞的特殊性**：CVE-2019-15878（SCTP-AUTH 共享密钥更新）与 CVE-2020-7463（SCTP 套接字 use-after-free）都涉及 SCTP 协议复杂状态机——SCTP 在 FreeBSD base 中长期保留但实际部署极少，是“协议保留但缺乏充分测试”的典型技术债务；**rtsold 漏洞的 KAME 遗产**：CVE-2020-25577 是 rtsold（路由器广告守护进程）的缓冲区溢出，rtsold 源自 KAME 项目（1998-2010 年 IPv6 实现项目），是 FreeBSD base 中长期未充分审计的 KAME 遗留代码——这一点与 14.x 周期 SA-25:12.rtsold（CVE-2025-14558）形成跨周期连续性，反映 KAME 遗留代码的长期维护负担；**dhclient 堆溢出**：CVE-2020-7461 影响 dhclient 处理恶意 DHCP 响应，理论上可被恶意 DHCP 服务器利用实现 RCE，是 12.x 周期少数“潜在 RCE”漏洞之一
