## 里程碑事件类

### 新闻条目 1

- **新闻标题（中英）**：FreeBSD 9.0 发布，搭载 DTrace、Clang、ZFS 更新（FreeBSD 9.0 Arrives w/ DTrace, Clang, ZFS Updates）
- **新闻来源**：Phoronix + Michael Larabel + 2012-01-12 + <https://www.phoronix.com/news/MTA0MjA> + <https://web.archive.org/web/2012/https://www.phoronix.com/news/MTA0MjA>
- **新闻摘要**：2012 年 1 月 FreeBSD 9.0-RELEASE 正式发布，搭载 DTrace 动态追踪框架作为基础系统组件。Phoronix 报道指出 DTrace 是 FreeBSD 9.0 的关键新特性之一，与 Clang 编译器、ZFS 文件系统更新并列。DTrace 移植工作源自 2008 年的 Sun CDDL 协议 DTrace 代码整合，经过多年稳定性打磨后正式进入基础系统。
- **与本章主题的关联说明**：本章记述 FreeBSD 集成 DTrace 的工程史，2008 年是 DTrace 代码首次进入 FreeBSD 8.0-CURRENT 的关键年份，2012 年 9.0-RELEASE 是其正式纳入基础系统里程碑。Phoronix 报道连接了 2008 年移植起点与 2012 年正式发布节点。
- **与官方史料的交叉验证结论**：FreeBSD 9.0-RELEASE 发行说明（2012-01-12）明确列出 DTrace 为新特性；FreeBSD 8.0-CURRENT 邮件列表（2008 年）可交叉验证 DTrace 移植补丁的合并。Phoronix 报道与 FreeBSD 官方发行说明一致。

### 新闻条目 2

- **新闻标题（中英）**：FreeBSD 9.2 带来 ZFS TRIM、ZFS LZ4、更新的 DTrace（FreeBSD 9.2 Brings ZFS TRIM, ZFS LZ4, Updated DTrace）
- **新闻来源**：Phoronix + Michael Larabel + 2013-09-30 + <https://www.phoronix.com/news/MTQ3MzU> + <https://web.archive.org/web/2013/https://www.phoronix.com/news/MTQ3MzU>
- **新闻摘要**：2013 年 9 月 FreeBSD 9.2-RELEASE 发布，包含 DTrace 的更新改进（包括对用户态探针的增强）。Phoronix 报道将 DTrace 更新与 ZFS TRIM、LZ4 压缩并列为本版三大存储与可观测性改进。DTrace 在 FreeBSD 9.x 系列持续打磨，为后续在生产环境的应用奠定基础。
- **与本章主题的关联说明**：本章记述 DTrace 在 FreeBSD 中的演进，9.2-RELEASE 是 DTrace 从初始集成（2008）到生产可用（2013）的成熟度里程碑。
- **与官方史料的交叉验证结论**：FreeBSD 9.2-RELEASE 发行说明（2013-09-30）明确列出 DTrace 更新；Phoronix 报道与 FreeBSD 官方发行说明一致。

### 新闻条目 3

- **新闻标题（中英）**：OpenSolaris 2009.06 发布（OpenSolaris 2009.06 Released）
- **新闻来源**：Phoronix + Michael Larabel + 2009-06-01 + <https://www.phoronix.com/review/opensolaris_200906> + <https://web.archive.org/web/2009/https://www.phoronix.com/review/opensolaris_200906>
- **新闻摘要**：2009 年 6 月 OpenSolaris 2009.06 发布，包含 DTrace 的多项改进（包括对 Java 与 Python 的 USDT 探针支持）。这一版本是 FreeBSD DTrace 移植上游同步的关键参照点——FreeBSD DTrace 代码定期从 OpenSolaris 上游同步，2009.06 的改进在后续 FreeBSD 版本中陆续合并。
- **与本章主题的关联说明**：本章记述 FreeBSD DTrace 移植与上游 OpenSolaris 的同步关系，OpenSolaris 2009.06 是 2008 年 FreeBSD 集成 DTrace 后的上游演进参照。
- **与官方史料的交叉验证结论**：OpenSolaris 2009.06 发行说明由 Sun 官方发布；Phoronix 评测为独立第三方，技术细节与 Sun 官方文档一致。

### 新闻条目 4

- **新闻标题（中英）**：Joyent 开源 SmartOS，将 KVM 移植到 Solaris（Joyent Open-Sources SmartOS, Ports KVM To Solaris）
- **新闻来源**：Phoronix + Michael Larabel + 2011-08-15 + <https://www.phoronix.com/news/OTc5Ng> + <https://web.archive.org/web/2011/https://www.phoronix.com/news/OTc5Ng>
- **新闻摘要**：2011 年 8 月 Joyent 开源 SmartOS，基于 illumos（OpenSolaris 后续分支），搭载 DTrace 与 ZFS。SmartOS 的发布强化了 DTrace 在生产环境的可见度，间接促进 FreeBSD 社区对 DTrace 生产应用的兴趣。Joyent 团队后续也成为 FreeBSD DTrace 改进的贡献者之一。
- **与本章主题的关联说明**：本章记述 DTrace 在 BSD/Solaris 生态中的传播，SmartOS 作为 illumos 侧的 DTrace 载体与 FreeBSD 形成互补，共同推动 DTrace 在开源操作系统圈的普及。
- **与官方史料的交叉验证结论**：Joyent 官方 SmartOS 发布公告与 Phoronix 报道一致；SmartOS 代码库可在 GitHub 验证 DTrace 实现。
