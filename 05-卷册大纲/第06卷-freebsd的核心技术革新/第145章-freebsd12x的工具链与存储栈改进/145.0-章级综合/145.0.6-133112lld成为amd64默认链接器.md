# 145.0.6 133.11.2 LLD 成为 amd64 默认链接器

- 要点：FreeBSD 12.0-RELEASE 将 LLD（LLVM Linker）设为 amd64 架构的默认系统链接器，替代 GNU ld（来自 GNU binutils）。LLD 是 LLVM 项目的子项目，由 Rui Ueyama 等开发
