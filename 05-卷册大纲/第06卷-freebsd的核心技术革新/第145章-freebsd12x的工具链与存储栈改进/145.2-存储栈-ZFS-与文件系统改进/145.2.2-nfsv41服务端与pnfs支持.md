# 145.2.2 NFSv4.1 服务端与 pNFS 支持

**要点**：FreeBSD 12.0 的 NFSv4.1 服务器实现更新，包含 pNFS（Parallel NFS）服务器支持（"The NFS version 4.1 server has been updated to include pNFS server support"）。pNFS 允许 NFSv4.1 服务器向客户端提供数据服务器（data server）集群布局，客户端可并行访问多个数据服务器进行 I/O，显著提高大规模存储环境的吞吐量。NFSv4.1/pNFS 服务端主要由 Rick Macklem（rmacklem@）长期开发与维护。NFS 客户端方面，12.x 持续改进 NFSv4 兼容性、支持 Amazon EFS（Elastic File System）等云 NFS 服务。

**史料**：FreeBSD 12.0-RELEASE Announcement（NFSv4.1 pNFS 服务器）、**nfsd(8)**/**nfsv4(4)** 手册页、Rick Macklem NFS 相关提交与邮件列表讨论。 ［A］

**史观**：总纲第 15 条——文化即形式主义〔存疑：映射待主理人审定〕：NFSv4.1/pNFS 是企业级存储协议的重要演进，FreeBSD 对其支持使其在 NAS（网络附加存储）领域保持竞争力。相比 Linux NFS 实现，FreeBSD NFS 服务器以代码简洁、稳定性高著称，被部分商业 NAS 厂商（如 iXsystems TrueNAS）采用。

**辨析**：pNFS 在 12.0 为初始支持状态，实际部署需要精心配置元数据服务器（MDS）与数据服务器（DS），在 12.x 时期主要用于特定企业场景；大多数 FreeBSD NFS 部署仍使用 NFSv3 或 NFSv4.0。
