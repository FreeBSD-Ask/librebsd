# 7.3.3 桌面支持的改进

**要点**：OpenBSD 7.2（2022-10）改进桌面支持——包括 Wayland 实验性支持、图形驱动改进、音频子系统改进；7.4 进一步改进 GNOME/KDE 兼容性；桌面支持改进让 OpenBSD 在桌面用户中获得关注

**史料**：OpenBSD 7.2/7.4 Release Notes 桌面部分；tech@ 邮件列表桌面讨论；CVS commit log ［A］

**史观**：总纲第 7 条——技术选择即政治选择：OpenBSD 投入工程资源改进桌面支持是针对用户需求的政治选择——以 “安全系统亦须可用作日常桌面” 为预设，将资源分配给 Wayland/图形/音频子系统而非仅专注于服务器场景

**辨析**：Wayland 支持的具体进度在 OpenBSD 7.2 Release Notes 与 tech@ 邮件列表中有记录——7.2 引入实验性 Wayland compositor 支持（基于 sway/portable），后续版本持续完善；桌面用户的实际规模无权威统计 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］；**【2026-07-30 DistroWatch 方法论一手核验·7ab 条目】** 经 WebFetch DistroWatch 官方 Page Hit Ranking 方法论页面（**<https://distrowatch.com/dwres.php?resource=popularity>**）一手核验，DistroWatch 官方明确声明："The DistroWatch Page Hit Ranking statistics are a light-hearted way of measuring interest in Linux distributions and other free operating systems among the visitors of this website. **They correlate neither to usage nor to quality and should not be used to measure the market share of distributions.** They simply show the number of times a distribution page on DistroWatch was accessed each day, nothing more.“ 计数规则为 ”Only one hit per IP address per day is counted"（每个 IP 每日仅计一次），且自 2004-05 起因计数器被滥用而切换至内部计数器。这一官方声明证实 DistroWatch Page Hit Ranking 的方法论限制：（1）仅统计 DistroWatch 网站访问者对 OpenBSD 页面的点击，不统计实际部署；（2）每个 IP 每日仅计一次，无法反映多用户/多机部署；（3）DistroWatch 访问者群体本身是 Linux/BSD 发行版爱好者，不代表全量操作系统用户群体。OpenBSD 在 DistroWatch 的具体 HPD（hits per day）数据因 DistroWatch 页面以动态表格呈现，WebFetch 仅返回方法论声明文本，未返回具体 HPD 数值——但 DistroWatch 官方方法论声明已足够佐证“DistroWatch 排名仅反映关注度不反映实际部署”的判断，OpenBSD 在 DistroWatch 的具体排名数字作为参考性数据须待 DistroWatch 完整动态页面可解析后补全。
