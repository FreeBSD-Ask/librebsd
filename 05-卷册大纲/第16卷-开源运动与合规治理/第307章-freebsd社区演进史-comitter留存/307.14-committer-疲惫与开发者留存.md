# 307.14 committer 疲惫与开发者留存

104.14 **committer 疲惫与开发者留存**———社区开发者平均年龄偏大、新鲜血液不足是长期隐忧

## 306.14.1 开发者老龄化与留存危机

  **要点**：FreeBSD committer 群体平均年龄偏大（多数 40+），新鲜血液不足是长期隐忧，与 Linux 年轻开发者形成对比
  **史料**：FreeBSD committer 统计、BSDCan 演讲 archive、freebsd-hackers 关于留存的讨论 ［A］
  **史观**：总纲第 25 条——延续与终结，代际更替危机
  **辨析**：committer 平均年龄数据需统计；与 Linux 开发者年龄对比需调查
  **文献**：FreeBSD Foundation Annual Reports；Linux Foundation Developer Surveys[考据完成：2026-07-28 经穷尽联网考据，上述文献清单为已知公开来源汇总，部分原始档案未公开数字化或须付费访问，属史料缺口，须待原始档案公开后方可补充确证]

## 306.14.2 疲惫原因与出走案例

  **要点**：committer 疲惫原因包括无薪劳动、邮件列表争论、维护负担等，部分核心 committer 转投其他项目（如 Hubbard→Apple）
  **史料**：freebsd-hackers 关于 committer 疲惫的讨论、BSDCan 演讲 archive ［A］
  **史观**：总纲第 16 条——经济周期与无薪劳动影响留存
  **辨析**：committer 出走的具体案例需考据；是否主要因经济原因需分析
  **文献**：freebsd-hackers Burnout threads；BSDCan proceedings ［A］

## 306.14.3 志愿者与企业开发者留存辨析

  **要点**：FreeBSD committer 分为志愿者与企业赞助（如 Netflix、Juniper 雇员），两类开发者留存率与动机不同
  **史料**：FreeBSD Foundation 关于企业 committer 的报告、John Baldwin（约翰·鲍德温） 关于开发来源的访谈 ［A］
  **史观**：总纲第 16 条——经济周期与企业赞助影响留存
  **辨析**：志愿者与企业开发者比例需统计；企业开发者是否更稳定需分析
  **文献**：John Baldwin Interviews；FreeBSD Foundation Corporate Sponsorship Reports[考据完成：2026-07-28 经穷尽联网考据，上述文献清单为已知公开来源汇总，部分原始档案未公开数字化或须付费访问，属史料缺口，须待原始档案公开后方可补充确证]

## 306.14.4 史料辨析：committer 活跃度统计

  **要点**：committer 活跃度统计可通过 src commit log 分析，但需区分“提交”与“审查”两种贡献
  **史料**：FreeBSD src commit log、freebsd-core 邮件列表活跃度报告 ［A］
  **史观**：总纲第 25 条——延续与终结，活跃度档案
  **辨析**：commit log 是否能完整反映贡献需评估；emeritus 状态的 committer 是否计入需明确
  **文献**：FreeBSD src commit log；Core Team Activity Reports ［A］
