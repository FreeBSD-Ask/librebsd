# 307.20 邮件列表、IRC 与 Discord 文化中的派系与排外

104.20 **邮件列表、IRC 与 Discord 文化中的派系与排外**———freebsd-hackers、freebsd-current、freebsd-advocacy、freebsd-multimedia、freebsd-net、freebsd-scsi、freebsd-ports 等数十个邮件列表长期存在“老男孩俱乐部”（old boys' club）现象，1990 年代末至 2010 年代初新人提问常遭 RTFM 嘲讽与“先翻手册再来”的回应，部分核心 committer 在列表中“一言堂”风格令新贡献者退缩

## 306.20.1 邮件列表排外现象

  **要点**：freebsd-hackers 等邮件列表长期存在“老男孩俱乐部”现象，新人提问遭 RTFM 嘲讽，部分核心 committer“一言堂”风格令新贡献者退缩
  **史料**：freebsd-hackers 邮件列表存档、新人贡献者口述历史 ［A］
  **史观**：总纲第 22 条——社区文化与包容性的辩证关系
  **辨析**：排外现象的具体案例需考据；是否为 FreeBSD 独有需对比其他社区
  **文献**：freebsd-hackers Archive；社区贡献者访谈 ［A］
