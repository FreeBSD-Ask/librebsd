# 341.7.1 科学工具选择中的权力运作

  **要点**：科学工具的选择不是中性的——当 CERN 选择 FreeBSD 处理粒子对撞数据、当生物信息学家在 BSD 许可证下发布算法，权力与知识的共谋便在每一次 “选择” 中悄然运作；这些选择源于质朴的实践需求：经验优先，不是哲学优先；具体选择须通过科学家访谈与项目档案核查
  **史料**：CERN/ESO 等机构选择 BSD 的决策档案、科学家访谈、科学哲学研究 ［B］
  **史观**：总纲第 3 条——形式主义膨胀的起点，科学工具的选择即形式主义化的非存在的展开
  **辨析**：“权力运作” 的判断须通过具体案例验证——不能简单套用福柯理论；“经验优先” 的判断须通过科学家访谈验证
  **文献**：CERN/ESO 等机构决策档案；科学家访谈记录；科学哲学研究文献 ［B］
