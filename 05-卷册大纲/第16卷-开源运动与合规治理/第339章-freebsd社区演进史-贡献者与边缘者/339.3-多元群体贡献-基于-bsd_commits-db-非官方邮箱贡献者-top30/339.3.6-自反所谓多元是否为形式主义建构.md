# 339.3.6 自反：所谓“多元”是否为形式主义建构

  **要点**：本章对“多元群体贡献”的专章书写本身须自反——在贡献发生的当下，贡献者并不以“少数族裔”“女性”“儿童”“不同信仰者”等标签自我定位，标签是史家事后对提交记录的形式主义化归类；将一群本以“开发者/维护者”身份协作的人重新切分为六类“多元群体”，既是为纠正“英雄叙事”偏差的努力，也可能在强调“差异”的同时反而固化了差异本身。FreeBSD 的贡献史首先是技术协作史，六类标签只是对其全球性与异质性的事后描述，而非贡献者的自我认同。
  **史料**：本章相关各节考据结果；相关章节边缘者贡献论述；第十二卷各区域社区史。［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］〔L3 官方文档与公告〕
  **史观**：总纲第 22 条——自反性：史书对“多元”的书写是一种形式主义化建构，须在呈现差异的同时警惕建构本身。
  **辨析**：本书对六类群体的书写以“可考据者书之、不可考据者缺之”为铁律，绝不臆造；信息缺口声明（女性/儿童/信仰三类）恰是 0 信任原则的体现，而非叙事失败。
