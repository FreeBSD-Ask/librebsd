## 要点

- CERN 等高能物理实验室在 1990 年代曾部署 FreeBSD 用于数据处理；费米实验室、SLAC 等物理研究机构也有 BSD 使用记录；BSD 在天文数据处理中（ESO/NASA 等天文台）扮演一定角色；具体部署须通过实验室档案核查
- 1990 年代 BSD 在物理计算中扮演重要角色，主要因 FreeBSD 的稳定性与网络性能；2000 年代后随 Linux 在科学计算中主流化，BSD 角色弱化；演变须通过实验室部署统计验证
- Linux 在物理计算中逐渐取代 BSD，主要因 Linux 有更完善的商业支持（Red Hat 等）与更广泛的社区；BSD 在物理计算中的优势（稳定性、网络性能）逐渐被 Linux 追平；比较须控制商业支持与社区规模变量
- BSD 物理计算史料以实验室档案、技术报告、科学家访谈为主，缺乏系统性的学术研究；实验室档案须警惕商业秘密限制；科学家访谈须警惕记忆偏差
- BLAST、HMMER、BWA 等生物信息学工具在 BSD 上有运行历史；人类基因组计划时期（1990-2003 年）的 BSD 服务器部署有限；BSD 与开放生物信息基金会的合作须通过基金会档案核查
