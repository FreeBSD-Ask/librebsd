# 338.3.1 非 committer 补丁提交流程


104.16 **非 committer 贡献者挫折**———FreeBSD 使用 Bugzilla PR 系统接收外部补丁，非 committer 需通过 PR 提交补丁由 committer 审查后提交，但 FreeBSD 没有类似 LKML 那样的公开高流量补丁讨论论坛，内部讨论在需要 committer 权限的邮件列表上进行

  **要点**：非 committer 通过 Bugzilla PR 提交补丁，由 committer 审查后合并，无类似 LKML 的高流量公开补丁讨论论坛，内部讨论在需要 committer 权限的邮件列表上进行
  **史料**：FreeBSD Bugzilla PR 系统存档、freebsd-hackers 邮件列表存档 ［A］
  **史观**：总纲第 10 条——边缘者（非 committer）贡献路径塑造项目
  **辨析**：Bugzilla PR 是否能完整反映外部贡献需评估；与 LKML 模式的可对比性需考据
  **文献**：FreeBSD Bugzilla PR Archive；freebsd-hackers 邮件列表 ［A］
