# 338.5.1 基金会预算与 Linux 基金会对比


104.18 **基金会资金不足**———与 Linux 背后的 RedHat/Canonical 相比，FreeBSD 基金会资金与商业支持严重不足

  **要点**：FreeBSD Foundation 年预算约数百万美元，Linux Foundation 年预算达数亿美元，差距悬殊
  **史料**：FreeBSD Foundation 年报、Linux Foundation 年报、双方 990 表对比 ［B］
  **史观**：总纲第 16 条——经济周期与资金规模影响项目能力
  **辨析**：预算口径需统一（含会员费/赞助/捐赠）；Linux Foundation 包含多项目需区分
