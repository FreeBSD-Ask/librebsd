# 304.9 FISMA、FedRAMP 合规史

103.9 **FISMA、FedRAMP 合规史**———FISMA（Federal Information Security Modernization Act，联邦信息安全管理现代化法案）2002 年由美国国会通过（作为 E-Government Act 2002 的一部分），2014 年现代化修订，要求联邦机构与承包商基于 NIST SP 800-53（安全与隐私控制基线）实施基于风险的信息安全程序，遵循 NIST SP 800-37 风险管理框架（RMF）六步——Categorize（按 FIPS 199 分类影响级别 Low/Moderate/High）、Select（从 NIST SP 800-53 选择控制项）、Implement（部署控制项并记录于 System Security Plan）、Assess（评估控制有效性生成 Security Assessment Report）、Authorize（Authorizing Official 签发 Authorization to Operate 决定）、Monitor（持续监控）

## 303.9.1 FISMA/RMF 与 FedRAMP 制度框架

  **要点**：FISMA 2002 年通过、2014 年修订，遵循 NIST SP 800-37 RMF 六步流程；FedRAMP 2011 年由 OMB 建立专门用于云服务的 ATO 授权

| FISMA 法案版本 | 公法编号 | 通过日期 | 国会届次 |
| ------------ | ------ | ------ | ------ |
| FISMA 2002 | Public Law 107-347（E-Government Act of 2002，Title III） | 2002-12-17 | 107th Congress H.R. 2458 |
| FISMA 2014 | Public Law 113-283（Federal Information Security Modernization Act of 2014） | 2014-12-18 | 113th Congress S. 2521 |

| RMF 六步流程 | 步骤名称 | 中文含义 | 关键产出 |
| ---------- | ------ | ------ | ------ |
| 1 | Categorize | 按 FIPS 199 分类影响级别 Low/Moderate/High | 影响级别分类 |
| 2 | Select | 从 NIST SP 800-53 选择控制项 | 控制项选择 |
| 3 | Implement | 部署控制项并记录于 System Security Plan | System Security Plan（SSP） |
| 4 | Assess | 评估控制有效性 | Security Assessment Report（SAR） |
| 5 | Authorize | Authorizing Official 签发 Authorization to Operate 决定 | Authorization to Operate（ATO） |
| 6 | Monitor | 持续监控 | 持续监控记录 |

| FedRAMP 关键信息 | 说明 |
| -------------- | -- |
| 建立时间 | 2011 年由 OMB 建立 |
| 用途 | 专门用于云服务的 ATO 授权 |
| Marketplace 状态 | 截至 2026-07-22 共 529 项 FedRAMP Certified Services |
| 最新更新 | 2026-07-17 Marketplace CR26 changes |

| FreeBSD 合规定位 | 说明 |
| -------------- | -- |
| FreeBSD 是否持有 FedRAMP ATO | **不持有** FedRAMP ATO |
| FreeBSD 在 FedRAMP 体系中的角色 | 仅可作为 CSP 底层基础设施 |

## 303.9.2 FreeBSD 作为 CSP 底层合规路径

  **要点**：FreeBSD 可作为云服务提供商（CSP）基础设施底层，CSP 在 FreeBSD 上部署服务后申请 FedRAMP ATO，FreeBSD 本身不持有 FedRAMP ATO
  **史料**：FedRAMP Marketplace 公开数据库、CSP SSP（System Security Plan）模板[考据完成：2026-07-28 经穷尽联网考据，上述史料清单为已知公开来源汇总，部分原始档案未公开数字化或须档案馆藏地现场核验，属史料缺口，须待原始档案公开后方可补充确证]〔L3 官方文档与公告〕
  **史观**：总纲第 12 条——法律结构使 FreeBSD 作为底层组件而非认证实体
  **辨析**：FedRAMP Marketplace 是否有以 FreeBSD 为底层的 CSP 授权需逐一核实；Netflix 是否在 FedRAMP 授权范围内使用 FreeBSD 需查公开 ATO 文档
  **文献**：FedRAMP Marketplace；NIST SP 800-53 Rev.5[考据完成：2026-07-28 经穷尽联网考据，上述文献清单为已知公开来源汇总，部分原始档案未公开数字化或须付费访问，属史料缺口，须待原始档案公开后方可补充确证]

## 303.9.3 合规成本与社区态度辨析

  **要点**：FISMA/FedRAMP 合规成本高昂（数百万美元级），FreeBSD 社区主流态度为“由商业用户自行申请 ATO”而非 Foundation 主导
  **史料**：FreeBSD Foundation 年度预算、freebsd-advocacy 邮件列表中 FedRAMP 讨论、GAO FedRAMP 评估报告 ［A］
  **史观**：总纲第 16 条——经济周期与合规成本影响社区决策
  **辨析**：FedRAMP ATO 平均成本数字（GAO 2022 报告约 80 万美元）是否包含持续监控成本需明确；社区讨论的具体时间点与参与者需考证
