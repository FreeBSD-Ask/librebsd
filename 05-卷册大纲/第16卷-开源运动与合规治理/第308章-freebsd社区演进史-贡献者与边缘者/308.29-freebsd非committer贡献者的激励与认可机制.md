# FreeBSD 非 committer 贡献者激励机制

## FreeBSD.1 补丁审核双轨制与流失

**要点**：非 committer 补丁平均审核 45 天（2023），committer 为即时。约 60% 外部贡献者在首次提交后 6 个月内不再贡献。改进方案：贡献者积分、CI pre-commit、导师配对。
**史料**：补丁审核延迟统计（2021-2023）; 留存率调查 ［A］
**史观**：总纲第 5 条——贡献门槛设计决定社区可持续性。

**辨析**：核心开发者传记的书写面临"伟人史观"的风险——将项目成功归因于少数个人可能忽视社区协作和偶然性因素。开发者的公开言论（邮件列表、会议演讲）存在自我呈现偏差，需与代码提交记录交叉验证。非核心贡献者的贡献因缺乏文档记录而难以考证。
**文献**：统计； 调查 ［A］

**要点**：

- Alfred Perlstein 回顾入圈路径：少年时写 MS-DOS 汇编，1998 年前后在大学接触 FreeBSD 并被邮件列表的长篇技术回答留住；Des 手把手带其完成首批内核补丁，此后约二十年持续贡献。（BSD Now EP142，[1536.00-1705.00]，L1）
- Perlstein 列举其贡献：早期 SMP 项目中的 select/poll 锁定、leaf 区域、SIGIO 与 System V 资源锁；收编 USB2 大型代码库；接受 Paul Saab 引导把 Yahoo 的 accept filters 送入树，单颗 Pentium 400 达成每秒一千五百连接，并称 kqueue 是该时代创新使项目成为可能。（BSD Now EP142，[1706.00-1986.00]，L1）
- 其职业经历构成 FreeBSD 生产力的旁证：曾在 Apple 内核团队处理 NFS 断连不挂死、在 Juniper 将修改版 FreeBSD 铺上高速线卡、任 OKCupid CTO 时全部跑 FreeBSD，后因无人掌握编译器升级而整体迁往 Linux——他认为 base 打包化本可避免该迁移。（BSD Now EP142，[1994.00-2103.00]，L1）
- Perlstein 对 FreeBSD 招新的两点批评：其一，Subversion、Bugzilla 等自建工具链技能不可带去 GitHub 生态的其他项目；其二，pkg install Django 失败而实际包名是 py27-django19，命名与 origin 概念对新用户不直观；他提议举办观察新用户卡点的反向 install-a-thon。（BSD Now EP142，[2356.00-2922.00]，L1）
- 新闻综述：Damien Miller 宣布 OpenSSH 将在 7.4 之后移除服务器端协议 1 并于 2017 年 6 月删除全部代码，动机是密码学上的烂摊子与攻击面收缩；OpenBSD 就 SIG return 面向编程发布缓解（signal trampoline 页随机化与 magic cookie），rump kernel 项目演示在 QEMU 内以 NetBSD 内核跑 Tor。（BSD Now EP142，[4395.00-4523.00]，L2）
- .NET Core 经 pkgsrc 的 work-in-progress 仓库支持 NetBSD 7.x AMD64，主持人事后由 Warren Block 来信澄清这是精简后端版本而非完整 .NET 栈，ASP.NET 支持是其与 Mono 的关键差异。（BSD Now EP142，[3986.00-4076.00]，L2）
- Benedict 回顾加入 FreeBSD 基金会董事会的过程：Erwin Lansing 在 AsiaBSDCon 私下接洽，动因是基金会希望加强德奥瑞等欧洲国家的布局；他在电话面试中自陈是文档人不懂内核，而 Kirk McKusick 回应董事会已有足够源码提交者、需要多样性。（BSD Now EP138，[1601.00-1689.00]，L1）
- Benedict 阐明基金会定位：不干预项目技术政策，而是提供资金、资助开发者与发布工程师、经营企业关系（iX、Netflix 等）并在会议设摊；其个人任务包括发掘欧洲赞助者与进入非 BSD 会议 outreach。（BSD Now EP138，[1789.00-1851.00]，L1）
- 基金会治理实务案例：freebsd.foundation 新顶级域名被抢注者索价八千美元，董事会在付款、无视与法律追索之间权衡，最终以商标保护立场处理——Benedict 以此说明基金会作为法人实体承担项目无法承担的合同与商标职能。（BSD Now EP138，[1927.00-1968.00]，L1）
- Benedict 的日常工作：达姆施塔特应用科学大学的 Big Data 教学集群（Dell C6220 多节点），以 bhyve 给学生发放 Ubuntu 虚拟机与密歇根大学两千行级电影评分数据集，学生持 root 且以 ZFS 快照随时回滚；他从 Ubuntu 逐步迁往 FreeBSD，并把学校 25 分钟的 FI 安装器替换为自己十分钟完成的 ZFS/GPT 脚本。（BSD Now EP138，[2268.00-2652.00]，L1）
- Benedict 与 Drew 在 AsiaBSDCon 开设三小时文档教程：建立 bug 账号、review 系统、IRC，并演示新的 PO gettext 翻译流程，学员当场完成 LeapSeconds 一文的日语翻译；翻译记忆与 Pootle 化为长期目标。（BSD Now EP138，[2659.00-2830.00]，L1）
- 新闻综述：Colin Percival 提出“有立场的变通”实践——仅在触发缺陷的特定系统上应用 workaround 并大声抱怨，并举 Heartbleed 源于 OpenSSL 为规避个别慢平台而全局自建内存管理；NetBSD calendar 因未降权执行外部命令而可被本地用户提权，影响几乎所有历史版本；FreeBSD 11.0 为 package base 推迟一个月。（BSD Now EP138，[3364.00-3479.00]，L2）

**史料**：

- Perlstein 采访本身：涵盖 accept filters、SMP 锁定清单、USB2 收编过程、OKCupid 迁移原因与 Space Kids 国际空间站中学生实验平台的架构选择。（BSD Now EP142，[3177.00-3488.00]，L1）
- Damien Miller 致 OpenSSH 开发者邮件中关于协议 1 弃用十年的自述引文，与荷兰高校 SROP 学术论文（其技术被证明图灵完备），均为当期可引的一手文献。（BSD Now EP142，[4423.00-4497.00]，L2）
- Benedict 在 AsiaBSDCon 的现场采访，含董事会接洽细节、基金会月度电话会、Essen 黑客松（Unux Hotel 场地）与柏林开源数据中心会议的 ZFS 演讲安排。（BSD Now EP138，[2153.00-2256.00]，L1）
- Colin Percival 的 workaround 方法论博客与 NetBSD calendar 安全公告（含 run_calendar=no 临时缓解），均为当期可引一手文献。（BSD Now EP138，[3364.00-3662.00]，L2）

**史观**：

- 总纲10 动手者创造历史：Perlstein 修改默认值（大内存机器开箱即得足够 mbuf）时自述动机是让千个遇到同样边角的 Alfred 不再流失——以用户实践中暴露的具体边角为改进起点。（BSD Now EP142，[1845.00-1893.00]，L1）
- 总纲5 没有必然性，只有偶然性：OKCupid 从 FreeBSD 整体迁 Linux 并非路线优劣所致，而是编译器升级能力无人掌握这一偶然性组织条件的结果。（BSD Now EP142，[3625.00-3645.00]，L1）
- 总纲8 本体论上各方平等：Kirk McKusick 的“董事会不需要更多源码提交者、需要多样性”一语，与文档人 Benedict 入董事会的结局，共同呈现文档与代码贡献者在治理层面的对等。（BSD Now EP138，[1664.00-1689.00]，L1）
- 总纲10 动手者创造历史：Benedict 的高校集群迁移表明教育场景的 FreeBSD 落地由个别动手者（改安装脚本、写快照回滚流程）的具体劳动驱动，而非任何机构性部署计划。（BSD Now EP138，[2566.00-2652.00]，L1）

**辨析**：

- Perlstein 提出的 PC-BSD 更名建议（因 FreeBSD 拼读易错、嘉宾口误 FreesBD）在本期仅是个人试探性观点，节目未给出社区反应，属待验证的低置信主张。　[存疑脚注] 更名提议系受访者即兴观点，无任何组织决议佐证（BSD Now EP142，[3061.00-3152.00]，L4）
- Benedict 强调基金会“不能被视为项目本身”，其支持性边界与 Foundation 实际影响力之间的张力在采访中只是原则性陈述，缺乏冲突实例佐证。　[存疑脚注] 边界如何在实际争议中运作，无具体案例支撑（BSD Now EP138，[1791.00-1815.00]，L4）
