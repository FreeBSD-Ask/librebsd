# 308.31 与同时期操作系统的比较

1993-2026 年同期 Linux 社区（Linus Torvalds 维持独裁模式，LKML 公开高流量补丁讨论，Linux Foundation 2010 年成立形成完整商业闭环）、OpenBSD 社区（Theo de Raadt（西奥·德·若特） 独裁，无 Core Team 选举，无 CoC，小规模精英模式）、NetBSD 社区（Core Team 选举但规模更小）、Apache 社区（Apache Software Foundation 1999 年成立，成熟的 meritocracy 治理）、Python 社区（PEP 流程，BDFL 模式，2018 年 Guido van Rossum（吉多·范罗苏姆） 卸任后转向指导委员会）——FreeBSD 的“Core Team 共识 + Foundation 商业托管”双轨治理模式在开源世界介于 Linux 独裁与 Apache meritocracy 之间
