**要点**：

- 阿伯丁大学的 Tom Jones 在 FOSDEM 间隙受访：少年时代借图书馆的《Learn Unix in 24 Days》自学 shell，试遍各 Linux 发行版后在学生时代接触 OpenBSD 与 FreeBSD，直至为移植 NewCWV TCP 拥塞控制算法而重投 FreeBSD 并将其设为工作机；其参与的欧盟地平线 2020 项目 NEAT 旨在为四十年未变的 socket API 重造单一接口，基于 libuv 事件循环以 neat flow 抽象提供协议选择、回退与切换，其与苹果方案同名的选择器在 IPv4、IPv6、SCTP 与 TCP 之间依网络路径可用性自动裁决，命中 SCTP 即获多宿主与多路径能力——Firefox 移植演示中多宿主主机借 CMT 将下载提速一倍，代码与支撑论文实时公开于 GitHub，项目自述移植越多、暴露的缺陷越多、库越好。（BSD Now EP183，[1288.92-1818.70]，L1）[订正：原 [1288.92-1688.48]，2026-09-30 SenseAudio 重转核对]
- 另一则考据还原 Unix 退格的内核机制：按下退格键并非删除字符，而是由内核 tty 行律在简单情形下输出退格、空格、再退格的三步序列完成视觉抹除；麻烦随制表符而至——内核须按每八列的硬编码制表位推算当前列并回退相应格数，经 Ctrl-V 引用输入的控制字符须作为整体成对擦除，多字节宽字符更令部分内核（如 Illumos 的 ldterm 模块）须专门绕行；FreeBSD 还独有对空格的单次退格优化，作者以重定向至 /dev/null 的裸终端让读者亲见这套久远代码的运行轨迹。（BSD Now EP183，[2597.09-2830.78]，L2）
- Wayland 相关端口已合入 FreeBSD 主线 ports 树并被归入 graphics 类目，标志 Wayland 首度以用户可及形态登陆 FreeBSD：前提是内核侧具备可用的 DRM（建议 TrueOS 最新包或 Matt Macy 的分支以支持现代 Intel GPU，NVIDIA 则依赖 modesetting），且现有桌面环境尚无开箱支持，Lumina 窗口管理器与登录管理器被列为优先移植目标；转引推动者的推文截图：其 MacBook Pro 的 Intel GPU 上经 XWayland 以 Weston 运行 Firefox 播放 1080p 60fps 视频而 CPU 占用未满——主持人视之为其整个职业 Unix 生涯以来最大的桌面变局。 [存疑脚注] Wayland 主要推动者转写为“Hannes Lundberg”，疑为 Johannes Lundberg，须以 ports 提交记录核证；DRM 与 GPU 兼容性细节为主播转述。（BSD Now EP183，[2839.12-3019.60]，L2）

**史观**：

- 总纲22 知识注定过时：Tom Jones 对 socket API 的判词是本期最具断代意味的陈述：这套接口“迄今表现良好”，却未给新协议留出前进通道，网络基础设施老化僵滞，应用被锁在四十年前的抽象之内——NEAT 项目的全部工程雄心，本质上是为一套注定过时的知识续写下一版本；接口的依然可用与无法前进并存，正是知识过时性在日常工程中的形态。（BSD Now EP183，[1393.78-1414.60]，L1）
