# 334.6.3 macOS UNIX 认证与代码血缘悖论

  **要点**：Apple macOS 自 10.5 Leopard 起通过 UNIX 03 认证，但其底层 Darwin 部分代码源自 FreeBSD，形成“FreeBSD 代码通过 macOS 获得 UNIX 03 认证而 FreeBSD 本身未认证”的血缘悖论

| 维度 | macOS | FreeBSD |
| -- | --- | ----- |
| UNIX 03 认证 | 自 10.5 Leopard 起通过 | 从未申请认证 |
| 底层代码 | Darwin 部分代码源自 FreeBSD | 源代码上游 |
| 血缘关系 | 部分代码源自 FreeBSD | 代码被 macOS 通过 Darwin 继承 |
| 认证状态悖论 | FreeBSD 代码通过 macOS 获得 UNIX 03 认证 | FreeBSD 本身未认证 |

| macOS 版本 | UNIX 03 认证状态 |
| -------- | -------------- |
| 10.5 Leopard | 起通过 UNIX 03 认证 |
| 10.6-14 Sonoma | 需逐一核实认证状态 |

**史料**：Apple macOS UNIX 03 认证证书、Darwin 源码开源档案、Apple OS X 10.5 release notes ［A］
**史观**：总纲第 12 条——法律结构使商标持有与代码血缘分离
**辨析**：Darwin 中 FreeBSD 代码的具体比例与版本需查 Apple 公开源码；macOS UNIX 03 认证的具体版本（10.5 Leopard 至 14 Sonoma）需逐一核实
