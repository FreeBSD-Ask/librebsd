**要点**：

- 节目介绍在 DragonFly BSD 上以 LUKS 兼容加密层对磁盘加密后搭建 HAMMER 主从文件系统，展示 HAMMER 作为可跨多台机器的分布式文件系统的特性，并提示 LUKS 提供的安全性与同步复制取舍。（BSD Now EP251，[66.84-354.00]，L2）
- Intel FPU 推测执行漏洞被确认：OpenBSD 的 Philip Guenther 于 7 月 5 日提交从惰性切换到主动切换的变更，Colin Percival 根据 Theo de Raadt 演讲披露的信息约五小时写出概念验证并通知 Intel，促使 Intel 提前公布；FreeBSD 2015 年 3 月的邮件列表曾有人建议为性能做同样变更。（BSD Now EP251，[3176.16-3380.00]，L1）
- BSDCan 2018 复盘记录 Ben O'Rice 的 systemd 悲剧主题演讲，他主张不应仅因批评就否定 systemd 的合理意图，BSD 社区可吸收其优点而不必照搬；并记录 Kirk McKusick 的 FreeBSD 治理演进演讲，回顾核心团队每两年改选、从 Jordan 时代到 Watson 时代再到当代的交替。（BSD Now EP251，[831.08-2315.32]，L1）
- 节目考据多个 Unix 命令名词源：awk 取自 Aho、Weinberger、Kernighan 姓氏首字母；grep 源自 ed 的 g/re/p（全局正则表达式打印）；cat 是 concatenate 的缩写；GECOS 字段源自 Honeywell 的 General Electric Comprehensive Operating Supervisor；rc 可追溯至 1965 年 MIT CTSS 的 runcom。（BSD Now EP251，[3944.18-4195.44]，L2）
- TrueOS 宣布把重点转向核心操作系统，Project Trident 接管图形化 FreeBSD 桌面开发；Ken Moore（Lumina 开发者）、JT 等桌面团队成员转入 Trident，TrueOS 核心由 iXsystems 付费开发者继续维护，并以 JSON 清单系统方便他人基于 TrueOS 构建发行版。（BSD Now EP250，[88.90-271.86]，L1）
- BSDCan 2018 开发者峰会复盘记录：Deb Goodkin 介绍基金会工作，Core 团队汇报两年工作，Mariusz Strobl 介绍发布工程并讨论代码冻结策略，峰会还列出 FreeBSD 12 待完成特性并逐项指派责任人，讨论 OpenZFS 上游从 Solaris 仓库转向从各实现择优合入的趋势。（BSD Now EP250，[873.26-2534.62]，L1）
- LLVM 的 LLD 成为 FreeBSD AMD64 默认链接器：Ed Maste 约三年前开设 LLVM 元缺陷跟踪阻碍、约一年半前以 3 万包 exp-run 试编译，历经一年半修复 LLD 与 ports 后达成；特殊感谢 Antoine 反复跑 exp-run 与 Krion 排查 ports 失败并标记 LLD unsafe。（BSD Now EP250，[4500.88-4658.16]，L1）
- HardenedBSD 宣布推进在美国设立 501(c)(3) 非营利组织的计划，已确定六名董事会成员（含 Shawn Webb 等），以使其后的捐赠可获税收抵扣。（BSD Now EP250，[2640.70-2885.64]，L2）
- Hubbard 以当事人身份界定 NextBSD 的性质：它不是又一个分叉，而是一间验证异步服务架构的“实验室”（3553.34-3556.26），先把 launchd、libdispatch、Mach IPC、notifyd 等技术在独立环境打磨成熟，再择机回灌 FreeBSD 主线；他明确不愿重演 DragonFly BSD 式的长期分流，认为现有 BSD 数量已经够多，若其他项目能从 NextBSD 摘取成果反而是造福生态（4573.44-4602.40）。（BSD Now EP113，[3553.34-3565.18]，L1）
- 新闻段记录 OpenBSD 5.8 于项目二十周年当日（10 月 18 日）发布（1008.96-1020.05）：冻结时名为 tame 的权限约束 API 首次随版附送，且“已被更名为 pledge”（1105.34-1107.96）；sudo 移出基本系统、由更精简的 doas 承担提权；file 命令重写并引入沙箱与特权分离；LibreSSL 的 OpenSSL 命令行移除 SSLv3 支持。主持人据此把 5.8 读作 OpenBSD 以年度发布节奏持续收紧默认信任边界的一个节点。（BSD Now EP113，[1008.96-1174.68]，L2）

- 总纲5 没有必然性，只有偶然性：FreeBSD 早在 2015 年就有改为主动 FPU 切换的建议，因担心引入难以诊断的缺陷而未实施，最终由漏洞披露这一外部偶然事件促成变更。（BSD Now EP251，[3287.60-3368.70]，L1）
- 总纲15 文化即形式主义：awk、grep、rc、GECOS 等命令名是历史语境在工具命名上的沉积，命名本身成为 Unix 文化的形式化载体。（BSD Now EP251，[3944.18-4195.44]，L2）
- 总纲4 分离聚合是永恒规律：TrueOS 与 Project Trident 的拆分把商业核心与社区桌面分离为两个实体，呈现组织随功能需要而分离聚合的规律。（BSD Now EP250，[193.26-271.86]，L1）
- 总纲13 法律与道德是利益分配：LLD 替代 GNU ld 成为默认链接器，其驱动力之一是许可证纯洁化与工具链自主，体现法律许可作为利益分配机制对工程选型的塑造。（BSD Now EP250，[4653.80-4658.16]，L1）
- 总纲6 和解优于斗争：Hubbard 提出社区管理至少与技术管理同等重要、有时更为优先的论断——“社区管理这一环更重要，否则项目没有未来；代码是不会有的，剩下的只是弃置软件”（6902.92-6948.02）；他以乐队因无法就艺术方向达成一致而解散作比，指出开源项目同样会在人际失谐中分裂或停滞（6964.42-7010.14）。这一判断把项目存续的因果链从代码生产逆转到共同体的维系，与其强调友善招募、团队对话优先于路线争吵的立场一以贯之。（BSD Now EP113，[6902.92-6948.02]，L1）
