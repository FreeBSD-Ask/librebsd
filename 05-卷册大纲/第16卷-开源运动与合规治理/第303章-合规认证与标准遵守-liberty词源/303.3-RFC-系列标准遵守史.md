# 303.3 RFC 系列标准遵守史

303.3 **RFC 系列标准遵守史**——IETF RFC（Request for Comments）系列规范是互联网核心协议的权威标准，FreeBSD 网络栈自 4.2BSD（1983 年）继承而来长期作为互联网协议参考实现

## 303.3.1 FreeBSD 网络栈与 RFC 实现

  **要点**：FreeBSD 网络栈源自 4.2BSD，长期作为 TCP/IP 协议族参考实现，对 RFC 793（TCP）、RFC 768（UDP）、RFC 791（IP）、RFC 2460（IPv6）等核心 RFC 实现稳健

| RFC 编号 | 发布时间 | 作者 | 标题 | 替代关系 |
| ------ | ------ | -- | -- | ------ |
| RFC 1 | 1969-04-07 | Steve Crocker（UCLA） | Host Software | - |
| RFC 791 | 1981-09 | USC/Information Sciences Institute | Internet Protocol | - |
| RFC 793 | 1981-09 | USC/Information Sciences Institute | Transmission Control Protocol | - |
| RFC 2460 | 1998-12 | S. Deering（Cisco）、R. Hinden（Nokia） | Internet Protocol, Version 6 (IPv6) Specification | obsoletes 1883 |
| RFC 8200 | 2017-07 | S. Deering（Retired）、R. Hinden（Check Point Software） | Internet Protocol, Version 6 (IPv6) Specification | obsoletes 2460，STD 86 |
| RFC 5321 | 2008-10 | J. Klensin | Simple Mail Transfer Protocol | obsoletes 2821，updates 1123 |

| 错误标注 | 正确 RFC | 正确内容 |
| ------ | ------ | ------ |
| ~~RFC 7541 标注为“HTTP/2 Push”~~ | RFC 7541 | 实为“HPACK: Header Compression for HTTP/2”，HTTP/2 Server Push 是 RFC 7540（HTTP/2 规范）的特性，已由 RFC 9113（2022-06）替代 |
| ~~RFC 9000 标注为“HTTP/3”~~ | RFC 9000 | 实为“QUIC: A UDP-Based Multiplexed and Secure Transport”（2021-05, J. Iyengar Fastly, M. Thomson Mozilla），HTTP/3 对应 RFC 9114 |

## 303.3.3 TLS/SSL 与防火墙 RFC 合规辨析

  **要点**：FreeBSD 通过 OpenSSL/LibreSSL ports 提供 TLS/SSL 实现，防火墙方面 pf（OpenBSD 移植）、ipfw、ipfilter 各自实现 RFC 1918/2979 等私有地址与过滤规范

| 防火墙 | 来源 | 实现 RFC | FreeBSD 集成方式 |
| ---- | -- | ------ | -------------- |
| pf | OpenBSD 移植 | RFC 1918/2979 等私有地址与过滤规范 | 移植自 OpenBSD |
| ipfw | FreeBSD 原生 | RFC 1918/2979 等私有地址与过滤规范 | FreeBSD 原生 |
| ipfilter | 第三方 | RFC 1918/2979 等私有地址与过滤规范 | 第三方集成 |

| TLS/SSL 实现 | 来源 | TLS 1.3（RFC 8446）支持 |
| ---------- | -- | --------------------- |
| OpenSSL | ports | 需区分 base OpenSSL 与 ports 版本 |
| LibreSSL | ports | 需区分 base 与 ports 版本 |

**史料**：OpenSSL commit 历史、FreeBSD **src/sbin/pfctl** 与 **sbin/ipfw** 源码、RFC 1918/5246/8446 文本 ［A］
**史观**：总纲第 6 条——技术路线分化导致三种防火墙并存
**辨析**：pf 从 OpenBSD 移植到 FreeBSD 的版本对应关系需对照；TLS 1.3（RFC 8446）在 FreeBSD base 中的支持需区分 base OpenSSL 与 ports 版本
**文献**：OpenSSL TLS 1.3 实现文档；OpenBSD pf FAQ；FreeBSD Handbook Chapter 30 Firewalls ［B］
