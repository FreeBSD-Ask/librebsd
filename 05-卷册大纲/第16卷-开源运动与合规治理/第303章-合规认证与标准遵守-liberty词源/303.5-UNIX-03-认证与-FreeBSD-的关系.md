# 303.5 UNIX 03 认证与 FreeBSD 的关系

103.5 **UNIX 03 认证与 FreeBSD 的关系**———UNIX 是 The Open Group 持有的注册商标与认证标志，使用 UNIX 名称须通过 Single UNIX Specification（SUS）认证并签订 Open Brand Trademark License Agreement（TMLA）

## 303.5.1 UNIX 商标与 SUS 认证体系

  **要点**：UNIX 商标由 The Open Group 持有，通过 Single UNIX Specification（SUS）认证并签订 TMLA 协议后方可使用 UNIX 名称，认证需通过 VSX4/VSX5 等测试套件

| 商标持有方 | 转移时间 | 备注 |
| -------- | ------ | -- |
| Novell | - | 早期持有 UNIX 商标 |
| X/Open | - | 中期持有 |
| The Open Group | 现行 | 现行持有人与 SUS 认证主管机构 |

| SUS 版本 | 对应 POSIX | 备注 |
| ------ | -------- | -- |
| SUS v3 | POSIX.1-2001 | Single UNIX Specification v3 |
| SUS v4 | POSIX.1-2008 | Base Specifications Issue 7 |
| SUS v5 | POSIX.1-2024 | Base Specifications Issue 8 |

| 认证要素 | 说明 |
| ------ | -- |
| 商标持有人 | The Open Group |
| 认证协议 | Open Brand Trademark License Agreement（TMLA） |
| 测试套件 | VSX4、VSX5、VSTH、VSU5、VSRT |
| Base Specifications Issue 7, 2018 Edition | 同时为 IEEE Std 1003.1-2017 与 The Open Group Technical Standard |

**史料**：The Open Group UNIX Brand Requirements、VSX5 测试套件文档、SUS v4 规范（The Open Group 官网 pubs.opengroup.org 2026-07-22 直接访问确认 UNIX 商标归 The Open Group 所有，Base Specifications Issue 7, 2018 Edition 同时为 IEEE Std 1003.1-2017 与 The Open Group Technical Standard，由 The Open Group 与 IEEE 联合发布）［A］
**史观**：总纲第 24 条——许可证与商标直接决定 UNIX 名称使用权
**辨析**：UNIX 商标所有权从 Novell 到 X/Open 到 The Open Group 的转移链条需精确考证；SUS v3/v4/v5 与 POSIX.1-2001/2008/2024 的对应关系需对照；联网核查结论：The Open Group 官方页面确认其为 UNIX 商标持有人与 SUS 认证主管机构，POSIX.1-2017 同时性声明（同时为 IEEE Std 1003.1-2017 与 The Open Group Technical Standard Base Specifications Issue 7）由 The Open Group 官方页面直接确认；The Open Group UNIX Brand 认证具体费用表未在公开页面直接列出，需查 The Open Group 商业认证入口 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］，详见考据记录 20260722_compliance-standards-fact-check.md

## 303.5.2 未申请认证的工程与财务原因

  **要点**：FreeBSD 从未申请 UNIX 03 认证，主因为认证费用高昂（约 10 万美元起）与持续维护成本，且 FreeBSD Foundation 预算有限
  **史料**：The Open Group 认证费用表、FreeBSD Foundation 年度预算报告、freebsd-advocacy 邮件列表中 UNIX 03 认证讨论 ［A］
  **史观**：总纲第 16 条——经济周期与资金约束决定合规策略
  **辨析**：10 万美元数字源自社区讨论，The Open Group 官方费用表是否公开需核实；认证成本中初始费 vs 年度维护费的比例需区分
  **文献**：The Open Group fee schedule（部分公开）；FreeBSD Foundation Annual Reports 2005-2024［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］

## 303.5.3 macOS UNIX 认证与代码血缘悖论

  **要点**：Apple macOS 自 10.5 Leopard 起通过 UNIX 03 认证，但其底层 Darwin 部分代码源自 FreeBSD，形成“FreeBSD 代码通过 macOS 获得 UNIX 03 认证而 FreeBSD 本身未认证”的血缘悖论

| 维度 | macOS | FreeBSD |
| -- | --- | ----- |
| UNIX 03 认证 | 自 10.5 Leopard 起通过 | 从未申请认证 |
| 底层代码 | Darwin 部分代码源自 FreeBSD | 源代码上游 |
| 血缘关系 | 部分代码源自 FreeBSD | 代码被 macOS 通过 Darwin 继承 |
| 认证状态悖论 | FreeBSD 代码通过 macOS 获得 UNIX 03 认证 | FreeBSD 本身未认证 |

| macOS 版本 | UNIX 03 认证状态 |
| -------- | -------------- |
| 10.5 Leopard | 起通过 UNIX 03 认证 |
| 10.6-14 Sonoma | 需逐一核实认证状态 |

**史料**：Apple macOS UNIX 03 认证证书、Darwin 源码开源档案、Apple OS X 10.5 release notes ［A］
**史观**：总纲第 12 条——法律结构使商标持有与代码血缘分离
**辨析**：Darwin 中 FreeBSD 代码的具体比例与版本需查 Apple 公开源码；macOS UNIX 03 认证的具体版本（10.5 Leopard 至 14 Sonoma）需逐一核实
