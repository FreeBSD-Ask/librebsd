# 333.2.2 Windows 的闭源与逐步开源路径

  **要点**：Microsoft Windows 的开源路径：(1) Windows 长期闭源；(2) Microsoft 2014 年起在 Satya Nadella 主导下转向 “Microsoft 爱开源”；(3) 2016 年收购 Xamarin；(4) 2018 年收购 GitHub（75 亿美元）；(5) 2018 年加入 OSI；(6) 开源 .NET Core、VS Code 等；Windows 内核仍闭源
  **史料**：Microsoft 2014 公告、2018 GitHub 收购公告、Nadella 访谈 ［B］
  **史观**：偶然性改写历史，Nadella 上任偶然改变 Microsoft 立场
  **辨析**：Microsoft 是否真诚开源，需独立判断；GitHub 收购是否影响开源
  **文献**：Microsoft 官方博客；Nadella《Hit Refresh》 ［C］
