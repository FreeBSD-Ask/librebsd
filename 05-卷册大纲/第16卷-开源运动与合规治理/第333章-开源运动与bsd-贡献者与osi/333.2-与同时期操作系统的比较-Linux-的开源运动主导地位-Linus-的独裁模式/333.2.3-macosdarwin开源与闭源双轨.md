# 333.2.3 macOS Darwin 开源与闭源双轨

  **要点**：Apple macOS 的 Darwin 开源与闭源双轨：(1) Darwin 0.1（1999 年）开源，2000 年起定期发布；(2) Darwin 内核基于 FreeBSD 与 Mach 3.0；(3) macOS 上层（Aqua、Cocoa）闭源；(4) iOS 同样基于 Darwin 但更封闭；(5) Apple 2017 年后基本停止更新 Darwin 公开源代码
