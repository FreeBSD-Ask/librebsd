# 331.0.8 300.3.2 开源定义的十项标准与 BSD 许可证

- 要点：开源定义（OSD）十项标准由 Perens 基于 Debian 自由软件指南（DFSG）改写，1998 年由 OSI 采纳；OSD 包括自由再分发、源代码开放、派生作品、作者源代码完整性、无歧视、许可证传播、许可证不得特定于产品、不得限制其他软件、技术中立；BSD 许可证（两条款与三条款）作为 OSD 认证的原型许可证
