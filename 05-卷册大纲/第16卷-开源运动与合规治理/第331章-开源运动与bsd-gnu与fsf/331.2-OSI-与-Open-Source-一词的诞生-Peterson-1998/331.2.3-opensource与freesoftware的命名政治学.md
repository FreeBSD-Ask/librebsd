# 331.2.3 Open Source 与 Free Software 的命名政治学

  **要点**：命名政治学：(1) “Open Source” 去除 “free” 歧义与 Stallman 政治色彩，便于企业接受；(2) “Free Software” 强调道德立场，拒绝商业中立；(3) 1998 年后开源运动分裂为 “实用派”（OSI）与 “道德派”（FSF）；(4) BSD 社区介于两者之间，因 BSDL 早于两者

  **史观**：话语权与边缘者，命名政治学决定话语权归属
  **辨析**：命名确实改变了运动性质——“Open Source” 去除 “free” 歧义与 Stallman 政治色彩后，企业（Netscape、IBM、Sun）得以在不接受 Stallman 道德立场的前提下参与开源；1998 年后 OSI 的 “实用派” 与 FSF 的 “道德派” 分裂为两个独立运动，BSD 社区介于两者之间但因 BSDL 早于两者而未被任何一方完全收纳
