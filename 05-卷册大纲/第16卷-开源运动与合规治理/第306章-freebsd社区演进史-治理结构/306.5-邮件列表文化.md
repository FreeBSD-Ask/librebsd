## 306.6.1 CVS/SVN/Git 技术迁移过程

  **要点**：FreeBSD src 仓库 2008 年 5 月 31 日从 CVS 迁移至 SVN（首个 SVN commit 为 r179447），doc 仓库 2012 年 5 月 19 日迁移至 SVN，ports 仓库 2012 年 7 月 14 日迁移至 SVN（首个 commit r300894），2013 年 2 月 28 日 ports CVS 访问正式关闭；2020 年 12 月 22 日 src.git 创建，2020 年 12 月 doc 迁移至 Git，2021 年 4 月 6 日 ports 仓库迁移至 Git 完成

| 仓库 | CVS→SVN 时间 | SVN 首个 commit | CVS 访问关闭 | SVN→Git 时间 |
| -- | ---------- | ------------- | ---------- | ---------- |
| src | 2008-05-31 | r179447 | - | 2020-12-22（src.git 创建） |
| doc | 2012-05-19 | - | - | 2020-12 |
| ports | 2012-07-14 | r300894 | 2013-02-28 | 2021-04-06 |

**史料**：FreeBSD Committer's Guide Subversion Primer 章节、FreeBSD Quarterly Status Reports 2020-2021、FreeBSD Git Working Group 报告 ［A］
**史观**：总纲第 19 条——信息技术工具演进驱动协作模式变迁
**辨析**：2008 年 src 迁移的具体决策时间需查 freebsd-hackers；2020 年 Git 迁移使用 cgit 作为 Web 界面
**文献**：FreeBSD Committer's Guide Subversion Primer；FreeBSD Git Migration Documentation ［A］
