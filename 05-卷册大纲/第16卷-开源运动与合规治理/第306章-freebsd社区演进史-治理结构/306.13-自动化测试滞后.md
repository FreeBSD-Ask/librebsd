## 306.13.1 测试基础设施缺失状况

  **要点**：FreeBSD 直到 2017 年才引入 CI/CD（Jenkins）系统，先前主要依赖手动测试与 release engineering 团队的安装测试

| 时间 | 测试基础设施状态 | 关键节点 |
| -- | -------------- | ------ |
| 2017 前 | 主要依赖手动测试与 release engineering 脚本 | 无 CI/CD 系统 |
| 2017 后 | 引入 Jenkins CI | CI/CD 系统建立 |
| 后续 | 引入 kyua 测试框架、GitHub Actions | 测试基础设施逐步完善 |

  **要点**：测试基础设施滞后导致开发者信心不足，部分补丁因无测试覆盖而拒绝合并，影响开发效率
  **史料**：freebsd-hackers 关于测试债务的讨论、FreeBSD Foundation 2018-2020 年报中的测试项目 ［A］
