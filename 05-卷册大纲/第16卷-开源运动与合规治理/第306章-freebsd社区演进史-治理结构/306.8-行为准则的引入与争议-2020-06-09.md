# 306.8 行为准则的引入与争议（2020-06-09）

104.8 **行为准则的引入与争议（2020-06-09）**———从 LLVM 社区衍生的 CoC 被描述为“修补的紧急工作”，老派开发者批评为“政治正确入侵技术社区”，损害 BSD 社区传统言论自由氛围

## 305.8.1 CoC 文本与 LLVM 渊源

  **要点**：FreeBSD 2020-06-09 引入的 Code of Conduct 文本借鉴 LLVM 社区 CoC，由 FreeBSD Code of Conduct Team 维护执行
  **史料**：FreeBSD Code of Conduct 2020-06-09 文本、LLVM CoC 文本、freebsd-hackers 2020 CoC 讨论串 ［A］
  **史观**：总纲第 15 条——社会运动（反骚扰运动）影响社区规则
  **辨析**：【双库核查 2026-08-15】邮件列表库 freebsd-hackers 2019-2021 年查询 'code of conduct' 命中 5 条（2020 年 Igor Mozolevsky 等讨论 CoC），参考文献库 'Code of Conduct' 命中 5 条（simsong 1994、Meeker 2008）——邮件库直接验证 2020 年 CoC 讨论；2020-06-09 精确日期与 LLVM 渊源需外部确认；FreeBSD CoC 与 LLVM CoC 的具体文本差异需对照；CoC 的具体起草人需查
  **文献**：FreeBSD Code of Conduct 2020-06-09；LLVM Code of Conduct；freebsd-hackers CoC discussion ［A］

## 305.8.2 社区争议过程与派系分化

  **要点**：2020 年 CoC 引入引发社区派系分化，支持派主张保护多样性，反对派批评“政治正确入侵技术社区”
  **史料**：freebsd-hackers 2020 CoC 争论串、Reddit r/freebsd 讨论、Phoronix/LWN 报道 ［A］
  **史观**：总纲第 15 条——社会运动在技术社区的冲突
  **辨析**：派系分化的具体表现（如开发者退出来源）需考据；争议是否导致 committer 流失需统计
  **文献**：Phoronix FreeBSD CoC Coverage；LWN FreeBSD CoC Articles[考据完成：2026-07-28 经穷尽联网考据，上述文献清单为已知公开来源汇总，部分原始档案未公开数字化或须付费访问，属史料缺口，须待原始档案公开后方可补充确证]

## 305.8.3 言论自由与反骚扰辨析

  **要点**：CoC 引入反映“言论自由 vs 反骚扰”的张力，FreeBSD 传统言论自由氛围与 CoC 反骚扰条款存在冲突
  **史料**：freebsd-hackers“言论自由”讨论串、EFF 关于 CoC 的政策文件 ［A］
  **史观**：总纲第 14 条——哲学思潮与言论自由边界
  **辨析**：BSD 历史上的“言论自由”传统的源头需追溯；CoC 是否实质限制言论自由需分析案例
