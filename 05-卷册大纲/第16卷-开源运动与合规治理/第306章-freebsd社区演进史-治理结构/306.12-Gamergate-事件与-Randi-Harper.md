**要点**：

- FreeBSD 发布新版行为准则，核心团队成员 Benno Rice 在访谈中说明：首个准则是在 gamergate 相关风波后的应激产物，新准则以 geek feminism 反骚扰政策为底本，采取报告驱动而非禁止模式，由 conduct@freebsd.org 的五人审查团队受理，重大处分须上报 core 团队并允许上诉。（BSD Now EP234，[1021.5-2144.3]，L1）
- Benno Rice 自述曾任职 Isilon（Dell EMC），后加入 iXsystems；其当前工作包括为 FreeBSD 安装镜像实现 hybrid boot，使单个镜像可同时作为 CD 与 USB 启动，方案源自对 GRUB hybrid boot 的反向工程。（BSD Now EP234，[2153.4-2241.3]，L1）
- iocage 教程演示其作为 jail 命令的替代管理 FreeBSD jail：激活后拉取 FreeBSD 11.1 镜像、创建带 IP 的 jail、经 loopback 接口与 PF NAT 联网，并可在 jail 内安装 Apache 或以前端 jail 反代到多个后端 jail。（BSD Now EP234，[525.3-757.7]，L2）
- Landon Fuller 自 2015 年起受 FreeBSD Foundation 赞助改进 Broadcom Wi-Fi 支持，2016 年初提交 BHND 驱动家族以统一 SSB 与 BCMA 总线接口，并完成将 BWN 软 MAC 驱动移植到 BHND、初步支持 BCM43224 与 BCM43225。（BSD Now EP234，[3511.3-3899.5]，L2）
- Lib Hijack 文章展示利用 FreeBSD 默认开启的非特权 ptrace 创建匿名内存映射、注入代码并劫持 PLT/GOT，称其绕过 wrapper 式 Capsicum，建议默认关闭 security.bsd.unprivileged_proc_debug 并实现 pax noexec。（BSD Now EP234，[2529.5-2872.4]，L2）

**史料**：

- 一手史料：FreeBSD 新版行为准则文本；Benno Rice 访谈自述；Landon Fuller 的 Broadcom Wi-Fi 工作博客；iocage 教程；Lib Hijack 在 soldierx.com 的文章。（BSD Now EP234，[525.3-3899.5]，L2）

**史观**：

- 总纲6 和解优于斗争：新版行为准则以报告驱动而非禁令的方式为多元背景参与者提供安全空间，把不同群体的共存置于社区治理核心，体现和解优于对抗的社区伦理。（BSD Now EP234，[1410.9-1449.2]，L1）
- 总纲10 动手者创造历史：Landon Fuller 多年默默推进 BHND 驱动并使其覆盖消费级 Broadcom 设备，Benno Rice 以反向工程实现 hybrid boot，均为动手者在系统基础设施上的真实积累。（BSD Now EP234，[3511.3-3899.5]，L2）
