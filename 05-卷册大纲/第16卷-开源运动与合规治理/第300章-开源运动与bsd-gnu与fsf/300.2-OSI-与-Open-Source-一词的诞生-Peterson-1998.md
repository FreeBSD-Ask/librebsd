# 300.2 OSI 与 Open Source 一词的诞生——Peterson 1998 年的提议

## 300.2.1 Peterson 1998 年提出 Open Source 一词

## 300.2.3 Open Source 与 Free Software 的命名政治学

  **要点**：命名政治学：(1) “Open Source” 去除 “free” 歧义与 Stallman 政治色彩，便于企业接受；(2) “Free Software” 强调道德立场，拒绝商业中立；(3) 1998 年后开源运动分裂为 “实用派”（OSI）与 “道德派”（FSF）；(4) BSD 社区介于两者之间，因 BSDL 早于两者
  **史料**：Raymond 文章、Stallman 批评 Open Source 的文章［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］〔L4 事后叙述〕
  **史观**：总纲第 14 条——话语权与边缘者，命名政治学决定话语权归属
  **辨析**：命名确实改变了运动性质——“Open Source” 去除 “free” 歧义与 Stallman 政治色彩后，企业（Netscape、IBM、Sun）得以在不接受 Stallman 道德立场的前提下参与开源；1998 年后 OSI 的 “实用派” 与 FSF 的 “道德派” 分裂为两个独立运动，BSD 社区介于两者之间但因 BSDL 早于两者而未被任何一方完全收纳

## 300.2.4 Open Source 一词对 BSD 社区的冲击

  **要点**：Open Source 一词对 BSD 社区的冲击：(1) BSD 长期 “已开源” 但不在新话语中；(2) BSD 社区被动接受 Open Source 标签；(3) BSD 在新话语中被 Linux 抢占焦点；(4) BSD 社区未主动参与命名政治学，导致话语权丧失
