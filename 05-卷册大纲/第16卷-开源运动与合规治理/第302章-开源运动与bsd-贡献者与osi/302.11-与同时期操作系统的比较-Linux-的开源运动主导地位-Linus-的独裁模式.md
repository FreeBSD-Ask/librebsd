# 302.11 与同时期操作系统的比较：Linux 的开源运动主导地位（Linus 的独裁模式、Linux Foundation 的治理）、Windows 的闭源与逐步开源（Microsoft 2018 年收购 GitHub）、macOS 的 Darwin 开源与闭源内核双轨——BSD 在开源运动中以 “被沉默的元老” 身份存在

## 302.11.1 Linux 的开源运动主导地位

  **要点**：Linux 在开源运动中的主导地位：(1) Linus Torvalds 的 “独裁” 模式（最终决策权）成为开源运动典型；(2) Linux Foundation（2007 年由 OSDL 与 FSG 合并）是最大开源基金会，预算数亿美元；(3) Linux 是 OSI 与 Open Source 运动的旗舰项目；(4) Linux 在企业、云、移动（Android）三大市场主导
  **史料**：Linux Foundation 年报、Linus 自传《Just for Fun》、市场研究报告 ［B］
  **史观**：总纲第 14 条——话语权与边缘者，Linux 话语权压倒 BSD
  **辨析**：Linux 主导是否因技术优势还是商业与话语权，需独立判断
  **文献**：Linux Foundation 年报；Torvalds《Just for Fun》 ［B］

## 302.11.2 Windows 的闭源与逐步开源路径

  **要点**：Microsoft Windows 的开源路径：(1) Windows 长期闭源；(2) Microsoft 2014 年起在 Satya Nadella 主导下转向 “Microsoft 爱开源”；(3) 2016 年收购 Xamarin；(4) 2018 年收购 GitHub（75 亿美元）；(5) 2018 年加入 OSI；(6) 开源 .NET Core、VS Code 等；Windows 内核仍闭源
  **史料**：Microsoft 2014 公告、2018 GitHub 收购公告、Nadella 访谈 ［B］
  **史观**：总纲第 1 条——偶然性改写历史，Nadella 上任偶然改变 Microsoft 立场
  **辨析**：Microsoft 是否真诚开源，需独立判断；GitHub 收购是否影响开源
  **文献**：Microsoft 官方博客；Nadella《Hit Refresh》 ［C］

## 302.11.3 macOS Darwin 开源与闭源双轨

  **要点**：Apple macOS 的 Darwin 开源与闭源双轨：(1) Darwin 0.1（1999 年）开源，2000 年起定期发布；(2) Darwin 内核基于 FreeBSD 与 Mach 3.0；(3) macOS 上层（Aqua、Cocoa）闭源；(4) iOS 同样基于 Darwin 但更封闭；(5) Apple 2017 年后基本停止更新 Darwin 公开源代码
  **史料**：Apple Darwin 源代码页、Apple 开发者文档 ［A］
  **史观**：总纲第 13 条——边缘者的作用，BSD 作为 Darwin 基础被边缘化
  **辨析**：Apple 是否利用 BSD 代码不回馈，需独立判断；Apple 与 FreeBSD 关系

## 302.11.4 BSD 作为被沉默的元老的辨析

  **要点**：BSD 作为 “被沉默的元老” 的辨析：(1) BSD 早于 Linux 16 年开源但话语权丧失；(2) BSD 是 macOS/iOS、PlayStation、Juniper 等的基础但被忽视；(3) Linux 在话语权上压倒 BSD；(4) BSD 社区未主动争夺话语权
  **史料**：邮件、社区讨论；freebsd.duckdb freebsd-src 仓库首条 commit 为 1993-06-12T14:49:13Z Rodney W.
