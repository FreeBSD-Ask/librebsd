# 301.8 Apache 软件基金会 BSD 许可证下的治理模式

## Apache.1 ASF ‘Apache Way’ 治理哲学

**要点**：ASF 的 meritocracy→PMC→Board 三层结构，与 BSD 的 committer→Core Team→Foundation 存在深层同构性。
**史料**：ASF 治理文档； Jagielski 2008 ［A］
**史观**：总纲第 5 条——许可证类型与治理结构的协变。

**辨析**：加密出口管制对 BSD 代码分发的影响程度在不同来源中存在争议——部分开发者认为管制是 BSD 安全特性滞后的主要原因，但也有观点认为 BSD 社区自身的安全审计文化不足才是更根本的因素。出口管制的法律文本与执行实践之间存在差距，实际影响需结合具体时间段和代码模块分析。
**文献**：ASF 文档； Jagielski 2008 ［A］
