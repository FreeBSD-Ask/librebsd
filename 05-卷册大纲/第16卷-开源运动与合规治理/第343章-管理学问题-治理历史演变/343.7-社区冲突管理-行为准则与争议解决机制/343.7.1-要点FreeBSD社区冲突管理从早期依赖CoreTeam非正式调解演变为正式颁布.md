# 343.7.1 要点FreeBSD社区冲突管理从早期依赖CoreTeam非正式调解演变为正式颁布

**要点**：FreeBSD 社区冲突管理从早期依赖 Core Team 非正式调解，演变为正式颁布 Code of Conduct（行为准则）并设立 CoC 团队；经 2026-07-22 联网核查 FreeBSD 官方 Code of Conduct 页面（<https://www.freebsd.org/internal/code-of-conduct/> ），Publication date 为 2020-06-09（原大纲称 “2018 年正式颁布” 为误，官方页面标注发布日期为 2020-06-09）；争议解决机制包括邮件列表举报、CoC 团队调查、Core Team 最终裁决；行为准则颁布前后曾引发社区关于 “言论自由 vs 社区包容” 的激烈辩论，部分成员因反对行为准则离场；行为准则历经多次修订，2020 年代后执行趋于稳定

**史料**：FreeBSD Code of Conduct 官方页面（<https://www.freebsd.org/internal/code-of-conduct/> ，访问日期 2026-07-22，Publication date: 2020-06-09）、freebsd-hackers 关于 CoC 的讨论、Core Team 关于冲突处理的公告 ［A］

**史观**：总纲第 22 条——社区治理，行为准则是社区规模扩张后非正式调解失效的形式主义化应对

**辨析**：Code of Conduct 发布日期经联网核查确认为 2020-06-09（非原大纲的 2018 年）；CoC 团队的组成与权限需以 CoC 文档原文为准；因 CoC 离场的成员案例需逐一核查，避免事后叙事扭曲

**文献**：FreeBSD Project. Code of Conduct [Z/OL]. 2020-06-09. <https://www.freebsd.org/internal/code-of-conduct/> （访问日期 2026-07-22）；Tourani, P., Adams, B., & Serebrenik, A. (2017). *Code of Conduct in Open Source Projects*. IEEE SANER 2017, pp. 24-33; Nafus, D. (2012). *“Patches don't have gender”: What Is Not Open in Open Source Software*. New Media & Society, 14(4), 669-683. ［A］
