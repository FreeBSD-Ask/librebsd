Jiri Slaby 在 ath5k GPLv2 许可补丁讨论中提出："This mess has been occurring in the kernel for years. The DRM graphics drivers are used in both BSD and Linux. It is quite easy to contribute something to this code via LKML and think you are doing it under the GPL. Doesn't a patch against the kernel have to be GPL? When these patches get pulled back into BSD and distributed with it, did BSD get infected with the GPL? AFAIK this has never been legally sorted out."——即 BSD/GPL 双许可下的法律感染问题在内核中长期存在。Alan Cox 反驳：“I'm not aware anyone has felt it needed "sorting out". Its not exactly complicated. BSD non advertising is compatible with GPL The GPL says: "when you distribute the same sections as part of a whole which is a work based on the Program, the distribution of the whole must be on the terms of this License, " The BSD license doesn't conflict with that… All a bit irrelevant anyway as Ath5K code (not the .h file) say: * Alternatively, this software may be distributed under the terms of the GNU General Public License ("GPL") version 2 as published by the Free Software Foundation. So Jiri is choosing to distribute it under the GPL, and with his changes GPL only. So whats the problem ?”——即 BSD 非广告条款与 GPL 兼容，且 ath5k 代码本身已明文允许 GPL v2。此为 BSD/GPL 双许可治理难题在内核中的集中记录。
