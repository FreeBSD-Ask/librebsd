# 312.5 文档与代码的管理不平衡——贡献者激励的结构性缺陷

## 312.5.1 doc committer 二等公民化与代码中心主义

**要点**：FreeBSD 文档贡献者（doc committer）与源码贡献者（src committer）在社区声望、决策参与、会议邀请上存在结构性差异，doc committer 常被视为 “二等公民”；此差异导致文档项目招募困难，与相关章节 “文档项目事实搁置” 互为因果；贡献者激励结构重代码轻文档，反映 BSD 文化 “代码中心主义”；doc committer 在 Core Team 选举中的参与度长期低于 src committer，加剧了文档贡献者在治理中的边缘化

**史料**：freebsd-doc 邮件列表、Core Team 选举中 doc committer 参与记录、BSDCan/EuroBSDCon 演讲邀请统计［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］

**史观**：总纲第 14 条——社区与文明历史哲学，文档与代码的等级化是社区权力结构的微观体现

**辨析**：“二等公民” 是主观感受还是结构性事实需分别考据；不同 BSD 项目（FreeBSD/NetBSD/OpenBSD/DragonFly BSD）的文档贡献者地位需分别考察，避免普世化；Core Team 中是否有 doc committer 出身成员需核实
