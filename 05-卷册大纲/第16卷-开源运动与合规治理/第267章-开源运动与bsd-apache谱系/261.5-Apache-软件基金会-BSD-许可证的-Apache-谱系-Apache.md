## 300.5.4 Apache 项目生态与 BSD 系统的交织
  - 要点：Apache 项目生态与 BSD 系统的交织：(1) Apache HTTP Server 长期是 FreeBSD 默认 Web 服务器；(2) Yahoo! 早期 FreeBSD + Apache 是典型组合；(3) FreeBSD Ports 中 Apache 项目占重要位置；(4) Apache 项目大量在 BSD 系统上开发与测试
  - 史料：FreeBSD Ports、Apache 邮件；bsd_commits.db freebsd-ports 仓库 1997 年起即有 Apache 相关 commit：1997-08-16 Andreas Klemm commit `f48f4dcfd107`（“libRSAglue.a is needed to build apache-ssl port. Added it to the post-install target in ports Makefile. Updated PLIST”）证明 1997 年 8 月 FreeBSD ports 已含 apache-ssl 端口；1997-08-25 Andrey A. Chernov commit `c9a02a1c285c`（“Do not replace Apache md5 with FreeBSD one, it cause support problems and gains almost nothing”）与 `7ec41b024f2d`（同主题 PR 4380）反映早期 Apache 与 FreeBSD 集成的工程问题——FreeBSD 开发者曾尝试用 FreeBSD md5 替换 Apache md5 但被驳回，反映 Apache 在 FreeBSD ports 中的独立性 ［A］
  - 史观：总纲第 13 条——边缘者的作用，BSD 系统作为 Apache 开发平台
  - 辨析：freebsd.db freebsd-ports 仓库 1997 年的 Apache commit 显示二者交织的起始时间早于 Apache 软件基金会 1999 年成立，证明 FreeBSD ports 是 Apache HTTP Server 早期分发与维护的重要平台之一；交织是双向但不对称的——FreeBSD ports 为 Apache 提供分发渠道与平台适配修复，Apache 项目本身则未特别针对 FreeBSD 优化；0 信任原则适用说明：commit message 中的 “PR 4380” 为 FreeBSD GNATS 问题跟踪系统编号，须与 GNATS 数据库交叉验证；1997 年的 commit 经历 CVS-to-SVN（2008）与 SVN-to-Git（2020）两次迁移，commit_hash 已重算，但 committer_date 与 author 信息应保持一致
