- 【Linux社区】Greg KH 在审阅 Danilo Krummrich 提交的 devres 抽象补丁时，注意到所有新 Rust 文件缺少版权声明。Greg 表示自己支持不加版权声明的做法，但指出与他共事的公司法务人员对没有版权行的文件持强烈反对态度，建议 Danilo 去确认公司要求，否则未来可能面临严厉谈话。这反映了 Rust for Linux 项目中关于是否需要版权声明的 GPL 实践争议，涉及版权归属与公司法律要求之间的张力，也体现了开源项目中个人偏好与企业法务需求的平衡问题。 `

<!-- ROW_MINE: lkml.messages.5130606 -->`
- 【Linux社区】2014 年 FreeBSD 工程师 Nathan Whitehorn 反对 Rickard Strandqvist 删除 ps3_repository_write_highmem_info 的补丁，转述 Geoff Levand“These ps3_repository_write_highmem routines are also the only documentation the freeBSD port has as to how the highmem info is (should be) saved in the repository”，并自陈“we really need this for FreeBSD since that port uses the repository directly instead of FDT”，坐实 Linux 内核 PS3 子系统的代码成为 FreeBSD PowerPC 移植的隐性文档 `

<!-- ROW_MINE: lkml.messages.6136583 -->`
