- 【Linux社区】讨论一个提议在 Linux 中添加 O_EMPTY_PATH 标志的补丁。该标志允许 openat 与 open 系统调用在路径为空字符串时打开由文件描述符引用的文件，补丁说明称该设计与 FreeBSD 的 O_EMPTY_PATH 标志非常相似，其用途是避免为这类操作开放对 /proc 的访问，以便像 samba 容器这样的场景能在无竞态条件下重开文件以改变标志位。David Laight 对此提出质疑，追问该标志究竟做什么，并认为两种实现方式都存在安全问题，因为仅测试文件 inode 的写权限不足以验证程序实际能否以写方式打开该文件，程序还需要目录搜索权限，因此提议的做法无法完整覆盖权限检查。该条目记录了一个 Linux 系统调用标志设计阶段直接对标 FreeBSD 同类标志，属于 API 层面的跨内核谱系证据，但讨论本身未涉及 BSD 许可或移植问题。 `
