- 【Linux社区】Michael Kerrisk 在 linux-fsdevel 报告 write() 等系统调用的文件偏移更新与 I/O 执行并非原子，构成对 POSIX 要求的明确违反，并以多核 BSD 系统作为对照正确实现。原文：“When I run this on a multi-CPU BSD systems, I get the expected result” 该条为 Linux 与 BSD 行为差异的对照证据。`<!-- ROW_MINE: linux-fsdevel.messages.508949 -->`
- 【Linux社区】在 LogFS take two 补丁讨论中，Albert Cahalan 引用 BSD 提供的非特权不可变位特性，认为仅此位即足以防止应用覆盖自身配置文件并建议引入该特性；Jörn Engel 回应称此功能加入相对容易。原文：“BSD offers an unprivileged immutable bit as well” 引语指向 BSD 文件系统接口语义进入 Linux VFS 特性讨论。`<!-- ROW_MINE: linux-fsdevel.messages.509098 -->`
- 【Linux社区】Evgeniy Dushistov 提交 ufs2 more correct work with time 补丁，修正 Linux ufs 驱动中 UFS2 inode 时间字段的读取与更新，将 atime、ctime、mtime 改为按 ui_atime 与 ui_atimensec 两个字段分别换算。原文：“This patch corrects work with time in UFS2 case.” 原文：“inode->i_atime.tv_sec = fs64_to_cpu(sb, ufs2_inode->ui_atime);”`<!-- ROW_MINE: linux-fsdevel.messages.509303 -->`
- 【Linux社区】Michael Kerrisk 在 flock() 与 NFS 锁定讨论中提议为 flock(2) 手册页补写 NOTES 段，说明该实现产生经典 BSD 语义，并附注现代 BSD 上两把锁会相互作用。原文：“This yields classical BSD semantics” 原文：“Note, however, that on some modern BSDs, flock() and fcntl(2) locks do interact with one another.”`<!-- ROW_MINE: linux-fsdevel.messages.510093 -->`
- 【Linux社区】Al Viro 向 Linus Torvalds 说明 /dev/stdin 在 Linux 与 BSD 系系统上语义不同，主张不切换为 BSD 语义以免破坏用户空间。原文：“new opened file for the same object (Linux behaviour) vs. new descriptor” 原文：“on Linux opening /dev/stdin gives you a descriptor with independent current IO position” 正文进一步指出 BSD VFS 的 magic-open 处理是缺陷区域。`<!-- ROW_MINE: linux-fsdevel.messages.510310 -->`
- 【Linux社区】David Howells 在 xstat 提案讨论中主张采纳 st_btime 字段，理由是与 BSD stat 接口兼容，Samba 可经 autoconf 自动识别并利用。原文：“st_btime, however, would be compatible with BSD's stat, and Samba would just use it by way of autoconf magic” 兼容性成为该扩展字段进入 Linux 文件统计接口的关键论据。`<!-- ROW_MINE: linux-fsdevel.messages.510395 -->`
- 【Linux社区】Theodore Ts'o 在 ext2 二次探测标记疑问的讨论中指出，Orlov 目录块分配算法最早实现于 BSD FFS，其后由 Al Viro 引入 ext2。原文：“Orlov algorithm was originally implemented in the BSD FFS, and was then imported into ext2 by Al Viro.” 该条为 BSD 文件系统算法进入 Linux 内核的直接证据。`<!-- ROW_MINE: linux-fsdevel.messages.510911 -->`
- 【Linux社区】Alejandro Colomar 在 mount_setattr.2 手册页讨论 man 页转义序列格式，援引 mandoc 维护者 Ingo Schwarze 持相反偏好。原文：“Ingo Schwarze, OpenBSD committer and mandoc(1) maintainer” 该行明确标注其 OpenBSD committer 身份，其格式偏好被列为需权衡的第三方意见。`<!-- ROW_MINE: linux-fsdevel.messages.510999 -->`

- 【Linux社区】Jan Kara 重发修复补丁系列，解决 BSD 进程记账向冻结文件系统写入时产生的死锁，并说明上次拉取请求中未见该系列。原文：“fix a deadlock when BSD process accounting is logging into a filesystem that is frozen” 补丁直接修复 Linux 对 BSD 记账功能的支持故障。`<!-- ROW_MINE: linux-fsdevel.messages.511116 -->`
