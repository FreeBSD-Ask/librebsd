# 5.7.3 创始人的实证立场

<!-- ROW_MINE: lkml.messages.1672577 -->`
- 【Linux社区】2003 年 Kris Kennaway 以 FreeBSD 工程师身份在 LKML 发出 NFS 协议分歧告警，指出 Linux 2.6.0-test7 的 lockd/xdr.h 把 NLM cookie 固化为 8 字节，而“FreeBSD 5.x's rpc.lockd uses a 16 byte cookie, and therefore FreeBSD 5.x NFS clients cannot interoperate with Linux when NFS locking is enabled”，并援引 freebsd.org PR kern/56461 作证，主张修 Linux 才是合规方向，是 NFS 协议在 Linux 与 BSD 家系间的典型不兼容证据 `

<!-- ROW_MINE: lkml.messages.6457462 -->`
- 【Linux社区】2020 年 2 月 FreeBSD 贡献者 Emmanuel Vadot（manu@freebsd.org）向 lkml 发出 [PATCH 0/2] Dual licence some files in GPL-2.0 and MIT，直击 GPL-2.0-only 授权对 BSD 系发行版的排他壁垒，原话“Those files are a problem with BSDs as we cannot include them”，主张与 drm_client.c 主要贡献者 Noralf Trønnes、Thomas Zimmermann 及 drm_format_helper.c 贡献者 Gerd Hoffmann 协商，将两个文件从纯 GPL-2.0 改为 GPL-2.0 与 MIT 双许可，是 BSD 生态对抗 GPL exclusivism 的典型案例 `

<!-- ROW_MINE: lkml.messages.2545074 -->`
- 【Linux社区】2017-02-28 FreeBSD 贡献者 Emmanuel Vadot（manu@freebsd.org）在 Priit Laes 的 [PATCH 1/4] clk: sunxi-ng: Add clocks and reset indices for sun7i-a20 SoC 串中直接要求双许可：“Do you mind dual licence those header under GPL/MIT like the others? We currently dont use those directly in FreeBSD but we should (and will soon) and we can't if they are only GPL”，并请求补 HDMI 定义（非 HDMI1）以贴合 FreeBSD DTS。BSD 阵营推动 Linux dt-bindings 从纯 GPL 改为 GPL/MIT 双许可以打破 GPL exclusivism 的典型案例，与 205.2 收录的 Vadot 2017-12 RK3328 GPL/X11、2020-02 drm/client GPL/MIT 双许可构成同一工程师的连续 BSD/GPL 双许可行动链。 `

<!-- ROW_MINE: lkml.messages.3827779 -->`
- 【Linux社区】2023 年 10 月 OpenBSD 创始人 Theo de Raadt 在 mseal() RFC PATCH v1 讨论中直接介入：“mseal() is a clone of mimmutable(2), but with an extremely over-complicated API based upon dubious arguments. I designed mimmutable(2) [1] in OpenBSD, it took about a year to get all the components working correctly. There were many intermediate API during development, but in the end the API is simply: int mimmutable(void *addr, size_t len)”“Very simple semantics. The only case where the immutable marker is ignored is during address space teardown as a result of process termination”，Jeff Xu 随即就 mimmutable 是否覆盖 mlock/madvice 场景发问，是 OpenBSD 作者以 API 设计权威身份反向审视 Linux mseal 语义的一手证据 `

<!-- ROW_MINE: lkml.messages.2077327 -->`
