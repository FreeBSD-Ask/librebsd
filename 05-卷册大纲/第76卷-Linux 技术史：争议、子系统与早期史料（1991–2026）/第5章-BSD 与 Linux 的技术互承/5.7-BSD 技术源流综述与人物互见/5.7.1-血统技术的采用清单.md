# 5.7.1 血统技术的采用清单

<!-- ROW_MINE: lkml.messages.1625369 -->`
- 【Linux社区】2003年12月 Matthew Wilcox(willy@debian.org) 在“Re: partially encrypted filesystem”串中 复述 Acorn RISCiX 压缩页技术，指出其为“4.3BSD based”并以之论证 Linux page cache 需支持更大 chunk，是 BSD 血统技术经验被 Linux 内核作者直接借用的例证 `

<!-- ROW_MINE: lkml.messages.1724762 -->`
- 【Linux社区】2004年9月 Jan Blunck(j.blunck@tu-harburg.de) 在“Re: [PATCH 1/3] copyfile: generic_sendpage”串中 说明自己的 union-mount 内核实现以 McKusick 论文为设计蓝本，“The focus is on the basic functionality explained by McKusick”，是 BSD 血统文件系统技术被 Linux VFS 层直接借用的例证 `

<!-- ROW_MINE: fb-1045290 -->`
- 【Linux社区】2011年12月 O. Hartmann(ohartman@zedat.fu-berlin.de) 在“Benchmark (Phoronix): FreeBSD 9.0-RC2 vs. Oracle Linux 6.1 Server”串中转述 Stefan Esser 关于 BSD 血统技术反向流入 Linux 内核的断言 many concepts were implemented in Linux based on BSD examples，是 FreeBSD 用户就 BSD 生态相对 Linux 定位的经典讨论 `

<!-- ROW_MINE: lkml.messages.2634315 -->`
- 【Linux社区】2021年9月 Mark Kettenis（kettenis@openbsd.org）在“[PATCH v5 3/4] dt-bindings: pci: Add DT bindings for apple,pcie”串中提交 apple,pcie 设备树绑定并采用“SPDX-License-Identifier: (GPL-2.0-only OR BSD-2-Clause)”双许可，是 OpenBSD 开发者把 BSD-2-Clause 作为一等公民带进 Linux DT 绑定、实现 BSD 技术血统正式纳入 Linux 内核文档体系的许可治理张力案例 

<!-- ROW_MINE: lkml.messages.3762579 -->`
- 【Linux社区】2024年5月14日 Theo de Raadt（deraadt@openbsd.org）在“Re: [PATCH v10 0/5] Introduce mseal”串中论证 Linux mprotect 与 munmap 部分变更语义的攻击面“The return values of mprotect and munmap are very rarely checked”，是 BSD 维护者从系统调用语义可靠性角度指认 Linux 独特风险的深度剖析 

<!-- ROW_MINE: lkml.messages.7490131 -->`
- 【Linux社区】2020年6月 Jung-uk Kim(jkim@freebsd.org) 在“Re: [PATCH] ACPICA: fix UBSAN warning using __builtin_offsetof”串中 从 FreeBSD 视角建议 ACPI 头采用平台特定的 offsetof 定义，指出“I think we should let platform-specific acfoo.h decide what to do here”，是 FreeBSD 维护者在共享 ACPICA 头中捍卫非 Linux 平台（含 BSD）与 Linux 内核共存的跨平台接口治理例证
