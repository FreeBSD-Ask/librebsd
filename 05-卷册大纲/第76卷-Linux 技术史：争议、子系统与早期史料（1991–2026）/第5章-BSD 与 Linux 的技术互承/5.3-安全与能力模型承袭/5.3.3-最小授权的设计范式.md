# 5.3.3 最小授权的设计范式

<!-- ROW_MINE: fb-1102840 -->`
- 【Linux社区】2000年5月 Thomas David Rivers(rivers@dignus.com) 在“Re: db 1.85 --> 2.x or 3.x?”串中 用 Linux 内核+FreeBSD 命令行组合追问 BSD 商业授权边界“a product came together that was the Linux kernel with the FreeBSD command set”，是 BSD 授权条款被放到 Linux 内核组合情境下检验、Sleepycat 商业授权的 BSD/Linux 参照记录 `

<!-- ROW_MINE: lkml.messages.5773726 -->`
- 【Linux社区】2013年4月 Adrian Chadd(adrian@freebsd.org) 在“Re: Version number policy!”串中 呼应开放固件规则草案“for the community, for BSD / Linux”的共同适用目标并以共享库版本兼容模型回应，是 BSD 与 Linux 在 802.11 开放固件治理上的协作实例 

<!-- ROW_MINE: freebsd-hackers.messages.1312494 -->`
- 【Linux社区】1996年8月 Ollivier Robert(ollivier.robert@eurocontrol.fr) 在“List of OpenBSD changes”串中 转发Theo de Raadt列出的OpenBSD吸收FreeBSD成果清单，“The FreeBSD ports subsystem was integrated and is usable by you!”是 BSD分支间(FreeBSD到OpenBSD)技术双向流动的例证 `

<!-- ROW_MINE: freebsd-hackers.messages.1316818 -->`
- 【Linux社区】1995年 Jordan K. Hubbard（jkh@violet.berkeley.edu）在 freebsd-hackers 的“ISPs and other commercial interests”串中提出由 ISP 联合开发驱动并以不受限版权授权的思路，属 FreeBSD 对 GPL 替代激励路径的早期探索；原始邮件不在本库，所涉原文引句已删除，待日后取得 freebsd-hackers 原帖后再行补证。`

<!-- ROW_MINE: linux-fsdevel.messages.626206 -->`
- 【Linux社区】2016年 Pavan Teja 在“Advantages of kdbus with enhanced capabilities feature”中提议把 Linux capabilities 作为 kdbus 连接的主令牌以放宽访问策略——与 Capsicum 的最小权限令牌哲学直接呼应，是 BSD 安全思想在 Linux 话题里的横向借用。 `
