# 5.3.1 提权约束的机制源头

<!-- ROW_MINE: lkml.messages.2107675 -->`
- 【Linux社区】2003 年 Andries Brouwer 回应 Matti Aarnio 对 O_DIRECT 行为的疑问，Aarnio 指出“Unlike Linux, FreeBSD (where this flag originates, apparently) does not require that read()/write() happens from page aligned memory areas”，明确把 O_DIRECT 追溯到 FreeBSD 源流；Brouwer 以 Linux man page 原文对照“Transfer sizes, and the alignment of user buffer and file offset must all be multiples of the logical block size”，坐实 Linux 采纳 BSD 接口后本地化的语义收紧 `

<!-- ROW_MINE: lkml.messages.6424401 -->`
- 【Linux社区】2024年5月Bagas Sanjaya转发Bugzilla用户Elvis的218813请求，主张Linux内核增加类似FreeBSD dev.uart.0.pps_mode=1（loader.conf tunable）的开关，允许在RJ45 COM口CTS引脚#8接收PPS信号（GPS Stratum 0场景），直接引用man.freebsd.org/cgi/man.cgi?query=uart作为先例，附not1337/pps-stuff内核补丁hack佐证，是FreeBSD tunable机制被援引向Linux内核提需求的一手邮件。 

<!-- ROW_MINE: lkml.messages.1998312 -->`
- 【Linux社区】2014年4月 Alexey Dobriyan (adobriyan@gmail.com) 在“Re: + lib-stringc-strlcpy-might-read-too-far.patch added to -mm tree”串中要求 Linux 内核 strlcpy 与 OpenBSD 参考实现对齐：“it is better to not diverge from master code”，是 Linux 内核开发者以 OpenBSD 实现为规范源头的 BSD 谱系证据 `

<!-- ROW_MINE: lkml.messages.3569904 -->`
- 【Linux社区】2023年12月14日 Theo de Raadt（deraadt@openbsd.org）在“Re: [RFC PATCH v3 11/11] mseal:add documentation”串中解释 OpenBSD 默认不可变映射机制“The OpenBSD kernel makes those regions immutable BY DEFAULT”，是 BSD 技术为 Linux mseal 提案提供设计源头的关键证据

- 【Linux社区】2024年 obiwac (obiwac@freebsd.org) 在“Re: Questions about best practices w.r.t. writing a kernel module port which modified LinuxKPI (BATMAN)”串中询问 FreeBSD 政策“the kernel module for batman can't be shipped with FreeBSD as it's GPL”，是 BSD 维护者在 LinuxKPI 移植 Linux 内核模块时直面 GPL 传染性约束的实证 `
