- 【Linux社区】讨论 IPv6 UDP 绑定语义时，面对“为何保留这一反直觉行为”的提问，Eric Dumazet 答以 “Because the BSD api has no other choice”，并从 connect() 无法替应用挑选源地址出发否决改仿 Solaris 的提议，体现 BSD API 兼容性对内核行为路径的塑造。`<!-- ROW_MINE: netdev.messages.8056243 -->`

- 【Linux社区】讨论 TCP Vegas 能否设为默认时，Stephen Hemminger 称 “If Vegas proves to be as reliable in Linux as BSD” 便可能成为默认，Andi Kleen 附议并称其了解的各 BSD 在 TCP 拥塞算法上远比 Linux 保守，BSD 的可靠性被用作内核决策参照。`<!-- ROW_MINE: netdev.messages.8056595 -->`
- 【Linux社区】讨论是否向应用上报 qdisc 丢包时，David Miller 以 BSD 等协议栈均不这样做为由，担心默认上报会破坏应用兼容，原句 “potential to break applications, because BSD and other stacks do not” 显示 BSD 行为成为其保留意见的依据，但他未直接否决补丁。`<!-- ROW_MINE: netdev.messages.8056635 -->`
