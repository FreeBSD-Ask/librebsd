- 【Linux社区】2001 年 Jan Harkes 就 UML 跨平台构建问题回复 Alan Cox：Ryan Cumming 称 FreeBSD 原生 gcc 未定义 __linux__，Harkes 指出真正障碍是“the same coda.h header is also used as part of the FreeBSD kernel to build a Coda kernel module”，Linux 与 FreeBSD 内核的 include/typedef 要求不同，同一份 coda.h 无法识别自身归属，故主张在 arch/uml/Makefile 加入 -D__linux__ 作为跨平台共享源码的通用方案，并列举所有为多平台开发的驱动和文件系统都可能受影响，是 BSD 与 Linux 共享头文件的直接证据 `
