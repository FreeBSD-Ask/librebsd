- 【Linux社区】2006 年 11 月 Evgeniy Polyakov 在 kevent 补丁串中直面 Pavel Machek 质疑，援引 FreeBSD kqueue 与 Linux kevent 对照：“Briefly saying, FreeBSD kqueue behaves like Linux epoll, sometimes better (with small request rate), sometimes worse (with 3k simultaneous connections rate), and the latter was shown to behave worse than kevent”，并反问既然不可能拥有相同的 API 为何还要使用 BSD 子系统，是 BSD kqueue 与独立设计的 Linux kevent 之争的公开技术辩论 

<!-- ROW_MINE: lkml.messages.1600897 -->`
- 【Linux社区】2019年3月25日，Aaro Koskinen（aaro.koskinen@iki.fi）在 [BISECTED, REGRESSION] Broken networking on MIPS/OCTEON EdgeRouter Lite 线程中，就 Andrew Lunn 对 cavium-pip ethernet 驱动 rx-delay/tx-delay DT 属性（值范围 1-31，硬件映射因芯片而异）缺少规范文档的批评回复 these are likely used only in-tree. Vendor GPL bundles provide some more documentation for this setting, as does the FreeBSD source tree 并附 freebsd/github cvmx-asxx-defs.h#L911 链接；他承认即便如此改名为 rx-delay-ps 仍难，因为取值过粗且不可靠，并补充默认值在 CN50XX 芯片上是 16、其他芯片是 24。此为 Linux 内核 OCTEON 设备树绑定文档缺口由 FreeBSD 内核提供的 Cavium OCTEON SDK 头文件填补的一手 BSD→Linux 文档承袭证据。 `

<!-- ROW_MINE: lkml.messages.2050343 -->`
- 【Linux社区】2000年12月Tigran Aivazian在test12-pre6补丁串中转述Alexander Viro“They are not Linux-specific (check where they came from), so I would rather check 4.4BSD and SuSv2”的原话，并展开一个具体的 API 语义分歧：4.4BSD（FreeBSD 4.2-release）对已加 immutable 属性（schg/uchg）的文件调 truncate(2) 返回 EPERM，而当时 Linux 的 truncate(2) 未做相同检查，因此“if we want to return the same as FreeBSD then we either need to: a) change vfs_permission() ... or b) we need to move that explicit check in do_sys_truncate() above the call to permission()”。这是 Linux truncate(2) 与 4.4BSD/FreeBSD 语义分歧在 LKML 上被明确记录并讨论修复路径的案例，反映 Linux VFS 权限层对 BSD immutable 文件语义的移植缺口。
