# 5.2.3 netmap 的 FreeBSD 渊源

<!-- ROW_MINE: lkml.messages.2050123 -->`
- 【Linux社区】2001 年 2 月 Jocelyn Mayer（Netgem）在 LKML“FA-311 / Natsemi 2.4.1 问题”线程中指出“the natsemi chip (in fact DP83815) is quite the same as SiS900 one”，附 OpenBSD 驱动代码附件，请求“someone who knows something about OpenBSD driver could merge the driver into Linux, I think it would be a real great deal”。这是 OpenBSD 网络驱动被 LKML 用户直接提议移植到 Linux 内核的一手邮件。 `

<!-- ROW_MINE: fb-2656044 -->`
- 【Linux社区】2010年1月 PseudoCylon(moonlightakkiy@yahoo.ca) 在“Calling for testers if_run rt3572 support”串中披露 webcamd userland program becomes GPL'ed due to the V4L USB drivers which are GPL licensed，是 BSD 用户态因链接 Linux 血统 GPL V4L 驱动而被迫整体转 GPL 的最直接技术证据 `

<!-- ROW_MINE: fb-6308 -->`
- 【Linux社区】2002年1月 Kjell Wooding(kjell@tash.pintday.org) 在“Re: UVM, UBC, and PF criticisms in comp.unix.solaris”串中列出 OpenBSD 未采纳 iptables 的四条理由，包括 GPL 许可不好以及 BSD 与 Linux IP 栈几乎没有共同点，为 BSD 防火墙谱系独立性的官方辩护 `

<!-- ROW_MINE: ob-150099 -->`
- 【Linux社区】2008年7月 Travers Buda(traversbuda@gmail.com) 在“Re: atheros - just curious, ot”串中引述 Reyk Floeter 称 ath9k 不会存在若没有 OpenBSD ar5k 驱动先被 Atheros 改写为 ISC 引入 Linux ath5k 并让 Luis Rodriguez 得到 Atheros 工作，是 BSD 血统网络技术反向输入 Linux 内核的关键证据 `

<!-- ROW_MINE: lkml.messages.3743437 -->`
- 【Linux社区】2024年5月14日 Theo de Raadt（deraadt@openbsd.org）在“Re: [PATCH v10 0/5] Introduce mseal”串中回应 Matthew Wilcox“this version of mseal() is OpenBSD's mimmutable() with a basically unused extra 'flags' argument”的判断并以“Yes, it is close enough”确认 Linux mseal 直接源自 OpenBSD mimmutable，是 BSD 技术被 Linux 采纳的直接证据 

<!-- ROW_MINE: lkml.messages.5905773 -->`
- 【Linux社区】2017年10月 Adrian Chadd(adrian@freebsd.org) 在“Re: [PATCH] ath10k: fix core PCI suspend when WoWLAN is supported but disabled”串中 以 FreeBSD 移植经验背书 ath10k 补丁“I did this on my in progress ath10k port to freebsd”，是 FreeBSD 移植 Linux ath10k 驱动反哺 Linux 主树的证据 

<!-- ROW_MINE: lkml.messages.7761792 -->`
- 【Linux社区】2021年5月 Mark Kettenis(kettenis@openbsd.org) 在 [PATCH 2/2] arm64: apple: Add pinctrl nodes 串中为 Apple Silicon Mac (t8103) 添加 pinctrl 与 GPIO 节点，是 OpenBSD 开发者把 OpenBSD 长期积累的 Apple Silicon 硬件逆向工作系统性移植进 Linux DTS 的谱系迁移案例 

<!-- ROW_MINE: linux-fsdevel.messages.697975 -->`
- 【Linux社区】2026年 Ali Ahmet Memis(ali@iusegentoo.com) 在“[PATCH 05/10] ufs: honour on-disk immutable and append-only flags”中 提交补丁把 BSD chflags 映射到 Linux S_IMMUTABLE/S_APPEND，“ui_flags holds the BSD chflags of the inode”是 BSD 权限位跨 OS 失效的直接证据。 `

<!-- ROW_MINE: linux-fsdevel.messages.642048 -->`
- 【Linux社区】2007年6月 Evgeniy Dushistov(dushistov@mail.ru) 在“[PATCH]: ufs: restore back support of openstep”中 提交 UFS 目录 chunk 大小参数化补丁，“common UFSes (BSD and Solaris UFS)”是 Linux UFS 驱动必须兼容 BSD 磁盘变体的直接证据。 `

<!-- ROW_MINE: netdev.messages.8341775 -->`
- 【Linux社区】2013年4月 Stephen Hemminger 在“[RFC 2/2] ixgbe: netmap support”中 将 netmap 支持直接移植进 Intel ixgbe 驱动，“originally developed on FreeBSD”是 BSD 网络技术被 Linux 驱动采纳的直接证据 `

<!-- ROW_MINE: netdev.messages.8208102 -->`
- 【Linux社区】2013年3月 Stephen Hemminger 在“[RFC 1/2] netmap: infrastructure (in staging)”中 将 Luigi Rizzo 源自 FreeBSD 的 netmap 框架移植进 Linux staging，“all the BSD ugliness”是 BSD 网络技术进入 Linux 网络栈时被显式承认的技术来源 `
