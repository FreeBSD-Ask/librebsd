# 2.6.6 二分定位的方法源流

<!-- ROW_MINE: lkml.messages.1730146 -->`
- 【Linux社区】2013-07-23 Linux NFSv4 客户端维护者 Trond Myklebust（NetApp）在 3.11-rc2 回归串中，就 Rydberg 反馈的 NFSv4 建文件失败确认根因：Rydberg 二分定位到 Trond 的提交 b4a2cf76“NFSv4: Fix a regression against the FreeBSD server”——“Linux client is allowed by the NFSv4 spec to send 3 word bitmaps as part of an OPEN request. However, this causes the current FreeBSD server to return NFS4ERR_ATTRNOTSUPP errors”，遂让 Linux 客户端改用 2 word bitmap。Linux NFSv4 为兼容 FreeBSD 服务端改协议的证据，与 205.1 收录的 Kris Kennaway 2003 NFSv4 NLM cookie 事件构成双向兼容连续谱。
