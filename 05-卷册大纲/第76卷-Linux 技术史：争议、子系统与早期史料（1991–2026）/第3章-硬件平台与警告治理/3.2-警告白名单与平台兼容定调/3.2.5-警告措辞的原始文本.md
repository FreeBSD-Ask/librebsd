# 3.2.5 警告措辞的原始文本

<!-- ROW_MINE: lkml.messages.6945141 -->`
- 【Linux社区】2019 年 9 月 Ahmed Darwish 在 lkml getrandom() WARN/getrandom2 补丁串中回复 Andy Lutomirski，后者援引 FreeBSD getrandom() 行为“Similarly, FreeBSD has getrandom()”（附 freebsd.org man.cgi getrandom(2) 链接）并指出“if we make getrandom(..., 0) warn, then we have a situation where the correct (if regrettable) way to use the function on FreeBSD causes a warning on Linux”，建议仅加 GRND_INSECURE 与 GRND_SECURE_BLOCKING；Darwish 确认该方案已在随后提交的 V5 落地，是 BSD 系统调用语义影响 Linux rand 子系统 API 设计的一手证据。
