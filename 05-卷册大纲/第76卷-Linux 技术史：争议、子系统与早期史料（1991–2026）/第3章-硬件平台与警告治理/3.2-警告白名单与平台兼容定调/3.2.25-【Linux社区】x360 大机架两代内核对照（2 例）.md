# 3.2.25 【Linux社区】x360 大机架两代内核对照（2 例）

**要点（判定表逐字）**：Eric Malkowski报告IBM x360四Xeon上2.2.21 SMP中断全然不发生：ASSIGN_IRQ_VECTOR回绕到52、MP-BIOS bug 8254未连IO-APIC、ExtINT失败改BP IRQ成功、IO APIC 14为51项版本0x11，2.4则一切正常；M. Ghaeini报告IBM x360 2.4.18 SMP 6GB双Xeon panic：MP-BIOS bug: 8254 timer not connected to IO-APIC、io-apic加timer doesn't work提示须扰mingo，EBDA与意外IO-APIC警告同现
