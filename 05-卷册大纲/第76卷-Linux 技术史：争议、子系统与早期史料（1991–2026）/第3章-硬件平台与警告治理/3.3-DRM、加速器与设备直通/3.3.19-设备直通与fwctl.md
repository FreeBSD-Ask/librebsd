# 3.3.19 设备直通与fwctl

- **要点**：认同fwctl短期限于CXL Feature等安全命令，但坚持BMC场景须能经同一接口放开高破坏性命令，隧道命令须核对目标设备命令效果日志，权限模型仍是缺口。认同媒体设备BSP驱动曾把用户态物理地址直送DMA引擎的乱象，承认服务器与嵌入式消费级硬件安全文化差异大，对后者同等信任持保留态度。将争论拆为三题：跨子系统NAK权限属维护者峰会，厂商开放性教育曾靠LF现已乏力，开放驱动标准之辩宜由Plumbers承办。主张以“政治”而非“哲学”定性直通分歧，背后是市场控制、竞争与厂商锁定议题，因而更难公开讨论；并追问Leon对维护者信任论的适用范围。指Ricardo的相机营销功能例证误导，厂商可任意闭源用户态，关键在内核UAPI；两人一致认同UAPI功能须有开源对应实现。
