# 151.1.1 Security Team 核心成员与贡献

**要点**：FreeBSD Security Team 由 Security Officer 领导，是负责接收安全漏洞报告、协调修复、发布安全公告的专门志愿者团队；核心安全基础设施贡献者包括：罗伯特·N. M. 沃森（Robert Watson）——TrustedBSD 项目创始人，MAC 框架、OpenBSM、Capsicum、OpenPAM 等核心安全机制的主要设计者和实现者，剑桥大学教授；Poul-Henning Kamp（波尔-亨宁·坎普）——**jail(8)**、**gbde(8)**、**malloc(3)**（phkmalloc）、MD5crypt 等的作者，FreeBSD 架构师；Pawel Jakub Dawidek——**geli(8)**、Capsicum 工程化、**casperd(8)**、HAST、ZFS 工具等的作者；Colin Percival——Security Officer（2005-2012）、**freebsd-update(8)**、**portsnap(8)**、scrypt、Tarsnap 作者；Mark R. V. Murray——**random(4)** CSPRNG（Yarrow/Fortuna）实现、OpenPAM 等；Dag-Erling Smørgrav、Simon L. Nielsen、Gordon Tetlow（戈登·泰特洛）、Ed Maste（埃德·马斯特） 等——历任或现任 Security Team 成员 [存疑精确任期]

**史料**：FreeBSD Security Team 官方页面 freebsd.org/security/（列有现任成员）；Colin Percival 个人网站 daemonology.net；罗伯特·N. M. 沃森 剑桥大学主页和 TrustedBSD 项目页面；Poul-Henning Kamp 个人网站 phk.freebsd.dk；Pawel Dawidek 演讲和博客；FreeBSD 开发者页面 freebsd.org/developers/ ［A］

**史观**：总纲第 10 条——动手者创造历史：安全子系统是 FreeBSD 中最依赖少数核心开发者的领域之一——少数人贡献了 FreeBSD 安全基础设施的绝大部分；这种 “少数英雄” 模式在开源安全领域很常见（如 OpenBSD 的 Theo de Raadt（西奥·德·若特）、OpenSSL 的 Steve Henson 等），但也带来 “公交车因子（bus factor）” 风险；FreeBSD Foundation 通过资助安全相关开发（如 Capsicum 工程化、CHERI 审计、安全工具改进）在一定程度上缓解了这一风险

**辨析**：“Security Team 成员就是所有 src committer”——不是，Security Team 是专门处理安全事件、协调安全公告的特定团队，成员有明确列表；“所有安全相关代码变更都需要 Security Team 批准”——不是，普通 src committer 可以修改安全相关代码，但安全公告和高危漏洞补丁由 Security Team 协调；历任 Security Team 的精确任期因早期记录不完整而部分存疑
