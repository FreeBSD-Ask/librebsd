# 149.8 FreeBSD 13.x 安全特性与 Mitigation 机制

## 149.8.1 13.x 安全缓解：CET、KASAN、SafeStack

**要点**：13.x 引入 CET 影子栈、W^X、KASAN、SafeStack。FreeBSD 倾向‘硬缓解’（hardware-assisted），OpenBSD 倾向‘软隔离’（API 收缩）。

**史料**：13.x 安全文档； OpenBSD 安全路线 ［A］

**史观**：总纲第 8 条——安全路线是价值观外部化。

**辨析**：

**辨析**：安全事件的公开披露与修复时间线存在选择性记录——项目倾向披露已修复的漏洞而淡化未修复的零日漏洞。安全审计的外部独立验证不足，大部分安全声明依赖项目自述。不同 BSD 项目间的安全实践比较需注意威胁模型的差异——面向服务器的 OpenBSD 与面向嵌入式 NetBSD 的安全需求不可直接对比。
**文献**：13.x 文档； OpenBSD 安全文档 ［A］
