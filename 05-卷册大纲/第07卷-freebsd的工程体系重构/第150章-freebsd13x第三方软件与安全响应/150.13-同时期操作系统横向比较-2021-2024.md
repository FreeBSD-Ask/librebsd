# 150.13 同时期操作系统横向比较（2021-2024）

## 150.13.1 Linux 5.10-6.x LTS 与 FreeBSD 13.x 比较

**史观**：总纲第 6 条——技术路线分化：到 2020 年代，Linux 已成为绝对主导的通用操作系统内核，但 FreeBSD 在特定场景（如 Netflix CDN、pfSense/OPNsense 防火墙、TrueNAS 存储、嵌入式网络设备）仍保持优势，这是 30 年技术路线分化的结果

**辨析**：“Linux 比 FreeBSD 功能多/性能好/支持硬件多”是一个笼统的说法，需要看具体场景——在网络转发性能、ZFS 集成、内核 API 稳定性、许可证纯净度等方面 FreeBSD 有自身优势；反之 Linux 在新硬件支持、容器生态、eBPF 可编程性等方面优势明显

## 150.13.2 Windows 11/Server 2022、macOS 11-14 与 BSD 谱系

**要点**：同期闭源/混合源操作系统：(1) **Windows 11（2021-10）** 和 **Windows Server 2022（2021-08）**：Windows Server 2022 改进了容器、安全、存储功能，但与 FreeBSD 技术关联较小；WSL2（Windows Subsystem for Linux）在 Windows 11 中成熟，但微软官方未支持 FreeBSD 作为 WSL 发行版（社区有非官方移植）；(2) **macOS 11 Big Sur（2020-11）** 至 **macOS 14 Sonoma（2023-09）**：macOS 是 BSD 谱系中商业上最成功的操作系统，基于 XNU 内核（部分代码源自 FreeBSD）；macOS 11 是 Apple Silicon（M 系列芯片）转型的开端，aarch64 架构成为 macOS 主流；macOS 与 FreeBSD 共享用户态工具、部分 POSIX API 实现，但内核架构差异显著

**史料**：Windows Server 2022 官方文档；Apple macOS 版本历史；XNU 内核源码（opensource.apple.com） ［A］

**史观**：总纲第 7 条——BSD 与 UNIX 谱系的连续性：macOS 证明了 BSD 技术在消费级和专业级市场的商业成功——Apple 通过 NeXTSTEP 继承 BSD 传统，将其转化为数十亿用户使用的操作系统；这是 BSD 技术“隐藏在成功产品背后”的典型案例

**辨析**：macOS 是 BSD 谱系成员但不是“FreeBSD 变体”——XNU 内核是 Mach 和 BSD 的混合，用户态部分源自 FreeBSD 但大量组件是 Apple 专有；macOS 开源部分（XNU、部分用户态）与 FreeBSD 代码共享随着时间推移逐渐减少

**文献**：Apple Inc. *macOS Release Notes*. apple.com; Apple Inc. *XNU Source Code*. opensource.apple.com; Microsoft. *Windows Server 2022 Documentation*. microsoft.com. ［A］

## 150.13.3 OpenBSD 6.9-7.5、NetBSD 9.x-10.x、DragonFly 6.x 同期比较

**要点**：其他 BSD 系统同期情况：(1) **OpenBSD**：6.9（2021-05）至 7.5（2024-04），持续聚焦安全和代码简洁性：**pledge(2)**/**unveil(2)** 持续改进、signify 签名工具、WireGuard 原生支持（OpenBSD 的 **wg(4)** 实现质量高、争议少）、持续的硬件支持改进；OpenBSD 在 WireGuard 集成上比 FreeBSD 顺利，因其代码审查流程极其严格；(2) **NetBSD**：9.x（2022）至 10.0（2024-03），持续改进可移植性和性能，支持更多架构，Xen 虚拟化改进，WiFi 驱动改进；NetBSD 10.0 是重要版本，带来显著性能改进；(3) **DragonFly BSD**：6.0（2021）至 6.4（2024），HAMMER2 文件系统持续完善，性能优化，虚拟化改进；HAMMER2 是 DragonFly 独创的文件系统，与 FreeBSD 的 ZFS/UFS 形成对比

**史料**：OpenBSD 6.9-7.5 Release Notes；NetBSD 9.x/10.0 Release Notes；DragonFly BSD 6.x Release Notes；各 BSD 项目官网［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档〕

**史观**：总纲第 6 条——技术路线分化：四大 BSD（FreeBSD/OpenBSD/NetBSD/DragonFly）各自有明确的定位和特色：FreeBSD 追求通用性、高性能、生产就绪；OpenBSD 追求安全、简洁、代码正确；NetBSD 追求可移植性、设计质量；DragonFly 追求 SMP 性能、HAMMER2 存储；这种分化不是“分裂”而是生态多样性

**辨析**：OpenBSD 的 WireGuard 集成之所以没有发生类似 FreeBSD 的争议，是因为 OpenBSD 的 WireGuard 驱动（**wg(4)**）由 Donenfeld 本人和 OpenBSD 开发者 Matt Dunwoodie 直接合作开发，代码质量从一开始就有保证，且经过 OpenBSD 极其严格的代码审查

## 150.13.4 同期 OS 比较辨析

**要点**：2021-2024 年是操作系统生态相对稳定的时期：Linux 在服务器、云计算领域占据主导；Windows 在桌面和企业服务器保持份额；macOS 在创意专业和消费高端市场成功；四大 BSD 在各自细分领域持续发展；这一时期没有出现颠覆性的新操作系统，但各系统都在持续演进；FreeBSD 13.x 的定位是“工程成熟期”——不再追求大量新功能，而是把已有功能做扎实、工具链统一、治理成熟、为未来版本（14.x/15.x）奠定基础

**史料**：各操作系统市场份额统计（需注意此类统计通常低估 BSD 部署量，因为 BSD 常作为嵌入式设备固件不被识别）；各项目发布公告；技术媒体年度回顾［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］ 〔L3 官方文档；L4 事后叙述；L5 二手研究〕

**史观**：总纲第 25 条——终结与延续：13.x 是 FreeBSD“30 年历史”承前启后的阶段——它完成了从 12.x 开始的现代化（去 GNU 化、Git 迁移、ARM64 Tier-1），同时为 14.x（OpenSSL 3.0、dma 默认、进一步现代化）奠定基础；“成熟”不是终点，而是下一轮创新的起点

**辨析**：市场份额数据对 BSD 参考价值有限——BSD 大量部署在嵌入式设备、防火墙、存储设备中，不被典型的操作系统统计捕获；TrueNAS（基于 FreeBSD）是部署量最大的开源存储系统，pfSense/OPNsense（基于 FreeBSD）是部署量最大的开源防火墙之一
