# 150.1.7 演示者在全新安装的FreeBSD系统上依次创建并销毁单盘stripe与双盘mir

- 演示者在全新安装的 FreeBSD 系统上依次创建并销毁单盘 stripe 与双盘 mirror 存储池，明确指出 stripe 无冗余、单盘故障即数据尽失，而 RAIDZ2 与 RAIDZ3 分别需要至少三块与四块磁盘，故双盘环境只能止步于 mirror，双盘建 RAIDZ1 未被拒绝而是实际表现为 stripe（降级）。（YouTube EP2ON_yeNfO7Y，[321.2-508.3]，L1）[订正：系统对不满足冗余条件的配置会直接拒绝或降级→双盘建 RAIDZ1 未被拒绝而是实际表现为 stripe（降级）]
- 通过 zfs 与 zpool 两个工具的分工演示数据集级属性：新建数据集开启 gzip 压缩后写入约 994 MB 的 ISO 镜像实际占用约 979 MB，演示者强调压缩收益取决于压缩级别，仅在处理大型数据集时才显著，区分了存储池管理与文件系统属性两条命令线。（YouTube EP2ON_yeNfO7Y，[244.3-289.3]，L1）[订正：压缩收益取决于数据类型与压缩级别→压缩收益取决于压缩级别（转写仅言 compression level 与大数据集，未提及数据类型），内容复核]
- 演示以 zfs create 携带加密属性创建 AES-256-GCM 加密数据集，重启后数据集默认未挂载、需手动重挂载且加密状态保持不变，并通过 zfs get all 导出全部属性核验加密算法与挂载状态，展示了 FreeBSD 上 ZFS 原生加密的完整生命周期。（YouTube EP2ON_yeNfO7Y，[514.9-666.0]，L1）
