# 167.2.3 项目官方核心与基金会治理

**要点**：FreeBSD 核心提交者（@freebsd.org）构成持续投入的主干，FreeBSD Foundation（约 2000 年成立，501(c)(3)）提供法律、资金与招聘托管，使贡献者群体从“纯志愿者”扩展为“核心 + 基金会 + 企业 + 志愿者”的多元结构（参见第106章 FreeBSD Foundation）。

**史料**：freebsd.duckdb 项目官方邮箱（@freebsd.org）提交量 282,291 次（口径冲突见 154.14.1 存疑脚注），为主体；FreeBSD Foundation 年报与赞助者名单（参见第106章 FreeBSD Foundation）［A/B］ 〔L1 代码/构建产物；L3 官方文档与公告〕

**史观**：总纲第 13 条——法律与道德是利益分配：BSD 许可证与基金会治理共同放大多元群体贡献。

**辨析**：@freebsd.org 提交量高不意味着贡献者单一——其中既有受雇于企业的 committer，也有独立志愿者；邮箱域无法区分二者，须结合雇佣关系公开资料判断。

**文献**：freebsd.duckdb（freebsd-src contributors 表）［A］；FreeBSD Foundation 官方站点（<https://www.freebsdfoundation.org/>）［B］
