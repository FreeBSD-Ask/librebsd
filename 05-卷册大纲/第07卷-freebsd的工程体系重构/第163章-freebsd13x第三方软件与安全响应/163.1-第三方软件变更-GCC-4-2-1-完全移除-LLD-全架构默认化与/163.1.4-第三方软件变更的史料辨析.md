# 163.1.4 第三方软件变更的史料辨析

**要点**：13.0 是 FreeBSD 许可证纯洁化工程的“竣工”版本——GCC 4.2.1 完全移除、LLD 全架构默认、GNU binutils 移除，三项变更共同标志着 FreeBSD base 彻底摆脱了对 GPL（v2/v3）许可组件的依赖。这一工程自 2007 年 GPLv3 发布启动，历时 14 年，涉及编译器、链接器、汇编器、调试器、文本工具、构建系统、DNS 解析器、软件包管理器等数十个组件的替换。13.0 的第三方软件变更体现了“终结”多于“开始”——旧工具链的移除多于新工具链的引入，这是 12.0/13.0 作为“移除期”的特征。

**史料**：FreeBSD 10.x/11.x/12.x/13.x Release Notes 对比 〔L3 官方文档〕

**史观**：总纲第 4 条——分离聚合是永恒规律：13.0 的 GCC/ld/binutils 移除是“终结”，但 LLVM 工具链（Clang/LLD/LLDB/libc++/libc++abi/compiler-rt）的全面接管是“延续”——FreeBSD 从一个“依赖 GPL 工具链的项目”转变为一个“拥有完整 BSD 许可工具链的项目”，这是 CSRG 解散后 FreeBSD 社区在工具链自主性上取得的最大成就

**辨析**：许可证纯洁化的“成功”不等于“所有 GPL 软件都从 FreeBSD 生态消失”——ports 中仍有大量 GPL 许可的软件（如 GCC、GIMP、GNU Emacs 等），但 base system 作为操作系统的核心，完全由 BSD 许可/兼容许可的代码组成，这确保了 FreeBSD 核心的许可证自由性
