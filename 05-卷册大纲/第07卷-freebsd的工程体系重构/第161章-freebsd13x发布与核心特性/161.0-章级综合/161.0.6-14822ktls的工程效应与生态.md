# 161.0.6 148.2.2 KTLS 的工程效应与生态

- 要点：KTLS 的引入对 FreeBSD 网络栈有深远工程影响：(1) 推动内核加密框架（OPCF，Open Crypto Framework）重构，支持异步加密操作；(2) 促进 **sendfile(2)** 与 KTLS 协同实现内核态加密零拷贝发送，Netflix 的规模化内容分发即是此路径的生产应用
