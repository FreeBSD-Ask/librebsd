# 6.5.1 K&R 教科书的规范地位

<!-- MAIL_INSIGHT: houxt.181 -->
**观点**：1982 年 2 月，Bill Stewart 在 comp.unix.wizards 列出一批 C 语言文档，指出 Dennis Ritchie 的《The C Programming Language—Reference Manual》是 K&R 著作的节选、已更新到 1980 年 9 月，另列 Bjarne Stroustrup 的《Extensions of the C Language Type Concept》等，并给出 Ritchie（2C517）与 Stroustrup（2C324）在 Murray Hill 的办公室号。
**邮件来源**：Bill Stewart，comp.unix.wizards，1982，Message-ID: `houxt.181`
**史学意义**：这条帖文记录了 K&R 手册在成书后的持续修订轨迹与 C 语言标准化前夜的文献生态，证明 C 的传播与规范在 1980 年代初已在学术与工业社区间以文本形式流动。
