# 6.6.5 标准落地的时间跨度

<!-- MAIL_INSIGHT: 7870@alice.UUCP -->
**观点**：1988 年 5 月，Dennis Ritchie 在 comp.std.c 亲自解释为何《The C Programming Language》第二版先于 ANSI C 标准出版：既为纪念第一版面世十周年，也因去年夏天 X3J11 接近尾声，与出版商讨论后认为不值得等待。
**邮件来源**：Dennis Ritchie（dmr），comp.std.c，1988-05-15，Message-ID: `7870@alice.UUCP`
**史学意义**：这是 C 标准化关键时刻的作者本人一手陈述，说明 K&R 二版与 ANSI C 的时间差是出版决策而非标准冲突。
