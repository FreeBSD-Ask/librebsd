# 012.11.1 PWB/UNIX 1.0 的运维安全实践——rsh、SCCS、RJE 账号管理

**要点**：PWB/UNIX（Programmer's WorkBench）1.0 由 Rudd Canaday、Mike Lesk、Dick Haight 等人于 1973 年主导发布，将 Research UNIX 的极简安全模型扩展为适合百人至千人规模多用户运维的安全实践；引入 **rsh**（restricted shell，受限 shell）将普通用户命令执行限制在白名单内、SCCS（Source Code Control System）提供源代码版本控制与审计追踪、RJE（远程作业录入）账号管理允许批量作业以独立账号运行与交互用户隔离；PWB/UNIX 经历 1.0（1973 年）、1.1（1974 年）、1.2（1977 年）、1.3（1979 年）等多版本演化，是 UNIX 商用分支首次将安全机制从“权限判定”扩展到“行为约束与审计追踪”

**史料**：PWB/UNIX 1.0-1.2 用户手册与技术报告（贝尔实验室内部文档，须查互联网档案馆存档与贝尔实验室历史文档馆藏）；Salus 1994 编年史关于 PWB/UNIX 1.0（1973 年）的描述；`research!unix`/`unix-wizards` 邮件列表存档；freebsd.duckdb 数据库交叉印证——`SELECT * FROM commits WHERE repo_name='freebsd-src' AND (message_subject LIKE '%PWB%' OR message_subject LIKE '%rsh%' OR message_subject LIKE '%SCCS%')` 未返回 PWB/UNIX 1.0 直接相关 commit（预期内，PWB/UNIX 源代码未直接进入 FreeBSD 主线），但 FreeBSD Ports 中 `sccs` 软件包与 `rsh` 命令的存在可视为 PWB 运维安全实践的间接回流

**史观**：企业研究双重性：PWB/UNIX 既是贝尔实验室内部大规模运维的工程产物，又因 1956 年同意令无法直接商业化，其安全实践通过 System V 进入商用市场；软件工程：rsh、SCCS、RJE 账号管理为后世 **rbash**、**jail(8)** shell 限制、RCS/CVS/SVN/Git、**at(1)**/**cron(8)**/systemd 服务的史源

**辨析**：PWB/UNIX 1.0 的发布年份（1973 年）经 Salus 1994 编年史与 Bell Labs 内部技术报告两方独立来源交叉印证；rsh 作为受限 shell 的设计动机（专利部门、开发部门、生产支持部门的多信任级别需求）需考据；PWB/UNIX 1.0-1.3 各版本的具体差异需逐版本考据；与本章 11.9（UNIX 早期技术淘汰史：SCCS、PWB 与 shell 演化的起点）互补——11.9 聚焦 PWB 作为工具集的演化（该内容拆分前记作旧 008.9.2），本节聚焦 PWB 的运维安全实践
