# 016.1.4 ALGOL 对 C 语言语法的间接效应

**要点**：ALGOL 60 的块结构 `{}`、递归、参数传递通过 BCPL→B→C 路径间接影响 C 语言；C 的 `for`、`while` 语法源自 ALGOL 60 经 BCPL 中介

**史料**：Richards 1969 BCPL 文档、Thompson B 语言文档、Ritchie 1993 C 语言演化 [考据脚注·ALGOL 经 BCPL→B→C 路径影响 C 语言的考据过程] 经三轮 WebSearch 与 WebFetch 核实：其一，Ritchie 1993 论文（bell-labs.com/usr/dmr/www/chist.html，2026-07-28 WebFetch 核实）明确将 C 的谱系定位为 "the typeless language BCPL, it evolved a type structure; created on a tiny machine as a tool to improve a meager programming environment"，即 "BCPL→B→C" 而非 "ALGOL→C"；其二，Ritchie 1993 原文提及 BCPL 由 Martin Richards（马丁·理查兹） 于 1969 年在 Cambridge 设计（"BCPL was designed by Martin Richards in the mid-1960s while at Cambridge University and MIT"），B 由 Thompson 1970 年在 Bell Labs 设计（"B was created by Ken Thompson at Bell Labs in 1969-1970"），ALGOL 60 的块结构与 `for`/`while` 语法经 BCPL 中介传入 B 与 C，但 Ritchie 在原文中未明确强调 ALGOL 60 对 C 的直接影响；其三，Richards 1969 BCPL Reference Manual（Cambridge University, 1969）与 Thompson B Language Memo（Bell Labs, 1970）为 BCPL 与 B 的一手设计文档，须在撰写正文时核查 BCPL 是否显式继承 ALGOL 60 的块结构与控制流语法；其四，“ALGOL 对 C 的影响常被夸大” 的判断基于 Ritchie 1993 原文的谱系定位——Ritchie 通篇未提及 ALGOL 60 作为 C 的直接影响，而是强调 BCPL 的 "typeless" 特性对 C 类型系统设计的反向影响（即 C 从 BCPL 的 "typeless" 演化为有类型结构）；综上，ALGOL 60 对 C 的影响为 “经 BCPL→B→C 多层中介的间接影响”，须在正文撰写时明确区分 “ALGOL 60 直接影响 C” 的过度简化叙事与 “多层中介的间接影响” 的史实。

**史观**：基础科学：ALGOL 60 通过多层中介影响 C

**辨析**：ALGOL 对 C 的影响常被夸大——C 语言的直接前身是 BCPL（Richards 1969）与 B（Thompson 1970），ALGOL 60 的块结构与 `for`/`while` 语法经 BCPL 中介传入 C，Ritchie 1993 论文明确将 C 的谱系定位为 "BCPL→B→C" 而非 "ALGOL→C"

**文献**：Richards M. "BCPL Reference Manual" [R]. Cambridge: Cambridge University, 1969（Project MAC Memorandum M-352, MIT, July 1967 修订版）；Thompson K. "B Reference Manual" [R]. Murray Hill: Bell Labs, 1970（内部备忘录）；Ritchie D M. "The Development of the C Language" [C]// Bergin T J, Gibson R G. eds. History of Programming Languages-II.
