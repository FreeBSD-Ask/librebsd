# 016.4.2 PCC：Portable C Compiler 与早期 BSD

**要点**：Stephen C. Johnson 于 1970 年代后期在 Bell Labs 开发 PCC（Portable C Compiler），作为 V7 UNIX（1979）的 C 编译器；PCC 是第一个可移植的 C 编译器，取代了原有的 Ritchie C 编译器；1BSD（1978）至 4.3BSD（1986）均使用 PCC 作为系统 C 编译器；PCC 代码量小、可移植性强，适合早期 BSD 在多种硬件平台（VAX、PDP-11、Tahoe 等）上的移植需求；Steve Johnson 基于 PCC 开发了 **lint(1)** 静态分析工具——原始文档日期为 1978 年 7 月 26 日（V7/usr/doc/lint 中 "July 26, 1978"），随后作为 V7 UNIX Programmer's Manual 第七版第 2B 卷的一部分于 1979 年 1 月正式发布；PCC 的开发与采用发生于 1975-1979 年间，此时期 C 语言、Pascal、Modula 等系统编程语言与编译器生态形成多线分化
