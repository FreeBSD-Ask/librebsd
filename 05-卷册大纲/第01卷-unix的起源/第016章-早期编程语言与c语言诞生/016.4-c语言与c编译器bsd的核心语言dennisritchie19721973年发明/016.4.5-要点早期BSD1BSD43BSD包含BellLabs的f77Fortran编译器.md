# 016.4.5 要点早期BSD1BSD43BSD包含BellLabs的f77Fortran编译器

**要点**：早期 BSD（1BSD-4.3BSD）包含 Bell Labs 的 f77 Fortran 编译器（与 PCC 配套），为科学计算用户提供 Fortran 77 支持；f2c（Fortran to C 转换器）由 Bell Labs、AT&T 与民间开发者于 1990 年代初开发，可将 Fortran 77 源码转换为 C 代码后用 GCC 编译；GCC 的 g77（GNU Fortran 77）前端自 1990 年代中期进入 FreeBSD Ports 与基本系统，FreeBSD 9.0 基本系统 GCC 4.2.1 仍包含 f77/（即 g77）目录；gfortran 作为 GCC 4.0（2005）引入的新 Fortran 95/2003/2008 前端取代 g77，但未进入 FreeBSD 基本系统（用户需通过 Ports 安装 lang/gcc）；Clang/LLVM 目前无原生 Fortran 前端，Flang（基于 LLVM 的 Fortran 编译器）正在开发中

**史料**：FreeBSD SVN base/release/9.0.0/gnu/usr.bin/cc/f77/ 目录、f2c 官方文档、GCC g77/gfortran Release Notes、FreeBSD Porter's Handbook、freebsd.duckdb 数据库交叉验证——`SELECT DISTINCT cf.file_path, c.author_date, c.message_subject FROM commits c JOIN commit_files cf ON c.commit_hash=cf.commit_hash AND c.repo_name=cf.repo_name WHERE c.repo_name='freebsd-src' AND c.author_date BETWEEN '1993-01-01' AND '1995-12-31' AND (cf.file_path LIKE '%fortran%' OR cf.file_path LIKE '%f77%' OR cf.file_path LIKE '%f2c%') ORDER BY cf.file_path LIMIT 30` 返回 30+ 条 1994-1995 年记录：(1) 1994-01-12 commit aaed6788e756 L Jonas Olsson "Added -o option to rename C output file. This only works when Fortran input is from a file, not stdin."；(2) 1994-05-01 FreeBSD 1.1 RELEASE commit a16f65c7d117 含 `gnu/usr.bin/cc/cc/f77.script`、`include/f2c.h`、`lib/libF77/Makefile`、`lib/libF77/README`、`lib/libF77/Version.c`、`lib/libF77/abort_.c`、`lib/libF77/c_abs.c`、`lib/libF77/c_cos.c`、`lib/libF77/c_div.c`、`lib/libF77/c_exp.c` 等——证实 FreeBSD 1.1 起基本系统已含完整 f77/f2c/libF77 工具链；(3) 1994-07-01 FreeBSD 1.1.5.1 commit 5e0e9b99dc3f 含 `gnu/usr.bin/cc25/usr.bin.f77/Makefile`、`gnu/usr.bin/cc25/usr.bin.f77/f77.script`；(4) 1994-10-25 commit 1f967df0a48e L Jonas Olsson "Added FORTRAN rule"；(5) 1994-10-26 commit a5a29f816ec1 L Jonas Olsson "Install f2c.h for FORTRAN support. Obtained from: netlib.att.com"；(6) 1997-09-15 commit f37c3d0edb12 Jordan K. **史观**：总纲第 2 条与第 22 条——实践先于理论与开源运动：Fortran 支持从 Bell Labs 原生工具到 GNU 工具链再到 LLVM 生态的演进

**辨析**：FreeBSD 基本系统中 Fortran 支持的终止时间——FreeBSD 10.0 移除 GCC 后基本系统不再包含 Fortran 编译器，用户需通过 Ports 安装 lang/gcc（含 gfortran）；f2c 曾长期在 Ports 中提供（lang/f2c）；[考据脚注] FreeBSD 1.1（1994-05-01）起基本系统已含 f77/f2c/libF77 完整工具链一事经 freebsd.duckdb 交叉印证——commit a16f65c7d117（"Release FreeBSD 1.1"，1994-05-01）含 `gnu/usr.bin/cc/cc/f77.script`、`include/f2c.h`、`lib/libF77/` 系列文件
