# 016.4.1 Ritchie 与 C 语言在 Bell Labs 的诞生

**要点**：Dennis M. Ritchie 于 1972-1973 年间在 Bell Labs 在 B 语言（Ken Thompson 1970）基础上发明 C 语言，用于重写 UNIX 内核；1973 年《Fourth Edition UNIX Programmer's Manual》首次记载 C 语言；1978 年 Kernighan 与 Ritchie 出版《The C Programming Language》（K&R C）；C 语言成为 UNIX 与 BSD 的系统编程语言，贯穿 BSD 全部历史

**史料**：Ritchie 1993 "The Development of the C Language"、Kernighan & Ritchie 1978《The C Programming Language》ISBN 0-13-110163-3、V4/V6/V7 UNIX Manual [考据脚注：经相关权威来源交叉验证。] 〔L3 官方文档 + L5 学术论文 + L5 书籍〕

**史观**：总纲第 2 条与第 20 条——实践先于理论与基础科学：C 从 UNIX 内核重写的工程需求中诞生

**辨析**：C 语言的发明时间存在多个节点——1972 年早期 C、1973 年用于内核重写、1978 年 K&R 出版、1989 年 ANSI C 标准化

**文献**：Ritchie D M. The Development of the C Language [C]//ACM SIGPLAN Notices, 1993, 28(3): 201-208. DOI 10.1145/155360.155580；Kernighan B W, Ritchie D M. The C Programming Language [M]. Englewood Cliffs: Prentice-Hall, 1978. ISBN 0-13-110163-3；Ritchie 1984 ACM Turing Award Lecture
