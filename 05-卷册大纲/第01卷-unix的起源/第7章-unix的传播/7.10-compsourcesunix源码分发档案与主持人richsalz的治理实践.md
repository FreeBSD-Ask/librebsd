# 7.10 comp.sources.unix：Unix 源码分发档案与主持人 Rich Salz 的治理实践

7.10 **comp.sources.unix：Unix 源码分发档案与主持人 Rich Salz 的治理实践**——1990 年代前后 Unix/BSD 工具与源码经由 Usenet  moderated 新闻组分发的制度形态。

## 7.10.1 新闻组的投稿与归档制度

  **要点**：comp.sources.unix 为**有主持人（moderated）**的源码发行新闻组，1988-1990 年由 **Rich Salz**（rsalz@bbn.com、后为 rsalz@uunet.uu.net）主持。每篇发布件带三段机读元数据：`Posting-number`（形如 `Volume 21, Issue 28`，帖题前缀 `v21i028`）、`Archive-name`、`Submitted-by`。**多段源码以 shar（shell archive）分包投递**，帖题标 `PartNN/MM`，其中 Part01（或独立帖）承载说明文字，其余各段为纯代码续传。卷首另发 `vNNINFk` 导言帖（投稿方式、档案站点、已发布源清单）。

  **制度特征**：源码以**共享而非专有**为默认预期——主持人在 v17INF4 明示**放弃其作为主持人对该“合辑”的隐含版权**，并在 1990 年的政策帖中称读者可自由取用与再分发代码，乃至复制档案转售亦无妨。

## 7.10.2 档案所承载的软件谱系

  **要点**：该档案是 BSD/Linux 生态诸多基础工具的首发或主要分发渠道。实测第 17-21 卷（1988-1990）收录者包括 **Perl 3.0**（Larry Wall，首度以 GNU 版权条款分发）、**flex**（Vern Paxson）、**nn**（Kim F. Storm，新闻阅读器）、**C News**（Henry Spencer 等，重写 Usenet 传输与过期部分）、**ash**（Kenneth Almquist，System V shell 重实现，可运行于 4.2/4.3BSD 与 System V）、**Elm 2.2**、**mush 6.4**、**SC 6.1**、**indent**、**screen**、**pax**、**zoo**、**GNU grep**、**cproto**、**gperf**、**COPS**、**Deliver**、**psroff**、**fbm**、**DES 例程**（声明不受美国出口管制）等。

  **意义**：本节为“源码如何抵达使用者”这一传播环节的实证材料，与 7.3 大学许可证条款、7.4 1956 年同意令共同构成 Unix 分发的制度链条。

**史料**：comp.sources.unix 第 17-21 卷发布件（pk 135311-137987，含 `Posting-number`/`Archive-name`/`Submitted-by` 元数据与主持人方括号编者按）；主持人 Rich Salz 的 v17INF2-v17INF4、v18INF1-v18INF2、v19INF1-v19INF4、v20INF1-v20INF2 导言与政策帖；相关软件的 README 与 man page。 ［A］

**史观**：待核定——本节系 2026-09-15 依“行级挖掘缺节补建”程序新立，史观归属待主理人核定，不预设总纲条目以免伪标签。

**辨析**：① 本节建制依据为 list34（sources.unix）挖掘过程中反复出现的宿主缺位——此前其内容被迫就近安放于 143.9（工具链组件替换）、124.10（图形与驱动）等**时代与技术域双重错位**的节；② 本卷为“unix 的传播”，与档案的传播属性相符，但须注意该档案跨越 BSD/System V/Linux 诸系，不应单归于 BSD；③ 各卷期与软件名的对应关系以发布件元数据为准，软件后续演化不在本节范围。

**文献**：comp.sources.unix 档案镜像（uunet、wuarchive 等）的索引帖；Rich Salz 关于新闻组管理的说明帖。 ［B］
