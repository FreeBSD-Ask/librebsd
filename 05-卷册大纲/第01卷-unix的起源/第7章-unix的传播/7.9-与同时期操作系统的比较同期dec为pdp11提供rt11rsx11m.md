# 7.9 **与同时期操作系统的比较**：同期 DEC 为 PDP-11 提供 RT-11、RSX-11M 的商业闭源路径

## 6.9.1 DEC 为 PDP-11 提供 RT-11 的商业闭源路径

**要点**：DEC 1973 年为 PDP-11 发布 RT-11（Real-Time 11），单用户实时操作系统，目标为实验室数据采集与小型系统；RT-11 以二进制形式分发，源代码不公开，与 UNIX 学术源代码分发形成对照

**史料**：DEC RT-11 Software Handbook (1973)、DECUS Proceedings 1973-1978、DEC 官方时间线 (archive.computerhistory.org) ［B］

**史观**：总纲第 4 条——分离聚合是永恒规律。项目史观总纲第 25 章载 “UNIX 与 BSD、BSD 各分支之间的分合循环，是历史的根本结构”——DEC 商业闭源（RT-11 二进制分发）与 UNIX 学术开源（源代码分发）是 1970 年代 PDP-11 平台上的分离聚合，两路径在本体论上地位相等（总纲第 8 条 “本体论上各方平等”），事后被归约为 “商业 vs 学术” 的对立叙事是 5.3 节 “记忆将许多偶然性认识为一种必然性” 的形式主义建构

**辨析**：[考据脚注] RT-11 首次实现可追溯至 1970 年，正式发布日期在不同来源中存在微小差异——DEC 官方时间线 (archive.computerhistory.org) 与 Gordon Bell 个人站点均记为 July 1973，部分二手文献记为 June 1973；以 DEC 官方时间线为权威来源采 July 1973；RT-11 是否为完全闭源——DEC 向 DECUS 用户提供部分技术文档，但源代码仍不公开

**文献**：DEC RT-11 Reference Manual (1973)；DEC 官方时间线 (archive.computerhistory.org/resources/text/DEC/dec.digital_(DEC)_timeline_1957-1997)；Gordon Bell Digital Timeline (gordonbell.azurewebsites.net/digital/timeline/16-bit.htm)；DECUS Proceedings 1973-1978 [考据脚注：DEC RT-11（1973）为 PDP-11 单用户操作系统等核心事实经 DEC 时间线与 Computer History Museum 档案交叉验证确证。]

## 6.9.2 RSX-11M 的商业闭源路径

**要点**：DEC 1974 年发布 RSX-11M（Resource Sharing Executive 11M），多用户多任务操作系统，目标为 PDP-11 中型系统；RSX-11M 设计强调实时性与多用户，但以二进制分发；RSX-11M 后续演化为 RSX-11M-PLUS 与 Micro/RSX [考据脚注]

**史料**：DEC RSX-11M System Reference Manual (1974)、DEC PDP-11 Software Handbook、DEC 官方时间线 (archive.computerhistory.org) ［B］

**史观**：总纲第 4 条——分离聚合是永恒规律。项目史观总纲第 25 章载 “分离聚合是永恒规律”——RSX-11M 与 UNIX 同期同硬件但哲学不同即分离聚合的具体呈现，二者在本体论上地位相等（总纲第 8 条），事后 “哲学完全不同” 的对照叙事是事后建构而非 1974 年时的本体论差异

**辨析**：[考据脚注] RSX-11M 的发布年份经 DEC 官方时间线 (archive.computerhistory.org) 与 Gordon Bell 个人站点 (gordonbell.azurewebsites.net/digital/timeline/16-bit.htm) 两方独立来源交叉印证为 1974 年；注意区分 RSX-11 家族与 RSX-11M——RSX-11D（家族首个版本）于 1972 年 5 月发布，但 RSX-11M 为 1974 年发布的不同子版本；早期部分二手文献误将 RSX-11D 的 1972 年发布时间归于 RSX-11M，已修正

**文献**：DEC RSX-11M Reference Manual (1974)；DEC 官方时间线 (archive.computerhistory.org/resources/text/DEC/dec.digital_(DEC)_timeline_1957-1997)；Gordon Bell Digital Timeline (gordonbell.azurewebsites.net/digital/timeline/16-bit.htm)；Martin, J. (1976) "Programming Real-Time Computer Systems" 对 RSX 的描述 [考据脚注：DEC RSX-11M（1974）为 PDP-11 多用户操作系统等核心事实经 DEC 时间线与 Computer History Museum 档案交叉验证确证。]

## 6.9.3 UNIX 学术分发与商业闭源的路线分化

**要点**：1970 年代 PDP-11 上存在三条操作系统路线——UNIX 学术开源、RT-11/RSX-11M 商业闭源、DEC 自家 TOPS-10（PDP-10）的混合模式；路线分化反映 1970 年代计算机产业的商业模式多元性。1970 年代 PDP-11 操作系统路线分化：

| 操作系统 | 厂商 | 发布年份 | 分发模式 | 目标场景 |
| ------ | -- | ------ | ------ | ------ |
| UNIX | Bell Labs | 1973（V4） | 学术源代码分发 | 学术研究、教学 | | |
| RT-11 | DEC | 1973 年 7 月 | 商业二进制闭源 | 实验室数据采集、小型系统 | | |
| RSX-11M | DEC | 1974 | 商业二进制闭源 | PDP-11 中型系统多用户多任务 | | |
| TOPS-10 | DEC | 1970 名称启用（源自 1964 年 PDP-6 Monitor） | 混合模式（许可证+DECUS 文档） | PDP-10 分时系统 | | |

**史料**：DEC PDP-11 软件产品目录 1973-1978、Ceruzzi 2003 [考据脚注：UNIX 与 DEC 商业闭源路径的对比经 Ceruzzi 2003 与 DEC 产品目录交叉验证确证。] 〔L3 官方文档 + L5 书籍〕

**史观**：总纲第 4 条与第 9 条——分离聚合是永恒规律与经验优先。项目史观总纲第 25 章载 “分离聚合是永恒规律”——UNIX 学术开源、RT-11/RSX-11M 商业闭源、TOPS-10 混合模式三路径并存即分离聚合的多元呈现；总纲第 9 条 “经验优先” 提示 “产业成熟” 判断本身是事后建构，须回到 1970 年代当事人的具体经验（DEC 客户对实时性的需求、Bell Labs 对学术扩散的容忍、DECUS 与 USENIX 各自的运作机制）而非笼统归因

**辨析**：路线分化是否为必然——1970 年代法律环境（IBM unbundle、AT&T 同意令）与市场需求共同塑造

**文献**：Ceruzzi, P. (2003) "A History of Modern Computing"；Campbell-Kelly & Aspray 1996 [考据脚注：UNIX 开源路径与 DEC 商业闭源路径的对比经 Ceruzzi 2003 与 Campbell-Kelly & Aspray 1996 交叉验证确证。]

## 6.9.4 路线分化对后续操作系统生态的效应

**要点**：商业闭源路径（RT-11/RSX-11M）后续演化为 VAX/VMS（1977）与 Windows NT（1993）；学术开源路径（UNIX）后续演化为 BSD（1977）与 Linux（1991）；两条路径在 1990 年代后形成操作系统生态的根本分野
