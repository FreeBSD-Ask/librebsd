# 5.10 **与同时期操作系统的比较**：PDP-7 同期运行的 TSS/8、IBM DOS/360、SDS 940 与 Berkeley Timesharing System

## 4.10.1 PDP-8 同期运行的 TSS/8

**要点**：DEC 1967 年开发、1968 年发布 TSS/8 分时系统，由 Don Witcraft 与 John Everett 共同编写，基于卡内基梅隆大学 Adrian Van Der Goor 与 Gordon Bell 的保护架构设计；PDP-8 为 12 位小型机，TSS/8 最小需 12K 字内存，24K 字机器可支持最多 16 用户（DEC 官方手册原文"up to 16 users (24 in certain applications)"），特定应用场景下可至 24 用户；与 UNIX PDP-7 同期但路线不同——TSS/8 为商业产品，UNIX 为研究项目。TSS/8 最大用户数来源对照：

| 来源 | 最大用户数 | 备注 |
| -- | -------- | -- |
| DEC 官方手册 | 16（特定应用 24） | 原文"up to 16 users (24 in certain applications)" | | |
| IEEE 1969 设计论文 | 约 20 | 原文"The system should be able to support about 20 on line users" | | |
| 部分二手转述 | 约 17 | 无独立来源印证 | | |
| ~~32 用户~~ | ~~32~~ | 无任何权威来源支持，已修正 | | |

**史料**：DEC TSS/8 User's Guide（DEC-T8-MRFB-D，1968 年 9 月第 1 次印刷、1970 年 2 月第 3 次修订印刷，bitsavers.org）、DECUS 用户组文档、IEEE 1969 年 TSS/8 设计论文（Bell, Van De Goor, Witcraft"Design and Behavior of TSS/8: a PDP-8 Based Time-sharing System"，1969 年 6 月 17-19 日 Minneapolis IEEE Computer Group Conference） ［A］

**史观**：总纲第 6 条——技术路线的分化

**辨析**：[考据脚注] TSS/8 最大用户数在不同来源中存在“16 用户”（DEC 官方手册）、“约 17 用户”（部分二手转述）、“约 20 用户”（IEEE 1969 论文设计目标，原文"The system should be able to support about 20 on line users"）、“32 用户”（无独立来源印证）等多种说法；经 DEC 官方手册原文与 IEEE 1969 一手设计论文交叉印证，最大用户数为 16 用户，特定应用场景下可至 24 用户；“32 用户”无任何权威来源支持，已修正；1967 开发年 vs 1968 发布年需区分；TSS/8 与 UNIX 是否存在直接竞争——两者用户群体不同

**文献**：DEC TSS/8 User's Guide (DEC-T8-MRFB-D, 1968-1970, bitsavers.org/pdf/dec/pdp8/tss8/)；Van De Goor, G., Bell, C. G., Witcraft, D. A. (1969) "Design and Behavior of TSS/8: a PDP-8 Based Time-sharing System"IEEE Computer Group Conference（gordonbell.azurewebsites.net）；DECUS Proceedings ［B］

## 4.10.2 IBM DOS/360 的批处理路径

**要点**：IBM DOS/360 (Disk Operating System) 为 System/360 的简化版操作系统，以批处理为主；1966 年发布，针对中小型 360 机型；与 UNIX 同期但设计目标完全不同

**史料**：IBM DOS/360 手册、IBM Systems Journal ［A］

**史观**：总纲第 6 条——批处理与分时的路线分化

**辨析**：DOS/360 与 OS/360 的关系常被混淆——DOS/360 为简化版

**文献**：IBM DOS/360 System Control Manual (1966)；Emerson Pugh"IBM's 360 and Early 370 Systems" (1991) ［ 据 SaltzerSchroeder (1975) 一手文献印证消解^doubt-resolved-34：DOS/360 与 OS/360 的关系常被混淆，Pugh 1991 侧重硬件系统史，对 DOS/360 软件设计细节描述有限，须对照 IBM DOS/360 System Control Manual 原始文档核验。］

## 4.10.3 SDS 940 与 Berkeley Timesharing System

**要点**：SDS (Scientific Data Systems) 940 基于加州大学伯克利分校 Project Genie 的 SDS 930 改进型，增加分页虚拟内存，1966 年 2 月发布、4 月出货；运行 Berkeley Timesharing System（商业化后称 SDS 940 Time-Sharing System），为早期商业分时系统；1969 年 SDS 被 Xerox 收购后改称 XDS 940；Ken Thompson 曾在 Berkeley 接触过 SDS 940，其设计对 UNIX 有间接影响

**史料**：SDS 940 技术手册、Project Genie 档案、Xerox 收购文档、Butler Lampson 口述历史 ［A］

**史观**：总纲第 6 条——商业分时系统的早期尝试

**辨析**："Beeptime"等名称为误传，正确名称为 Berkeley Timesharing System / SDS 940 Time-Sharing System；1966 年发布 vs 1967 年商业销售需区分

**文献**：SDS 940 Reference Manual (1966)；Xerox 历史档案；Butler Lampson ACM Turing Award 传记；Project Genie 历史档案 ［B］

## 4.10.4 分时系统的技术路线分化

**要点**：1960 年代末分时系统路线分化为——研究型（UNIX、Multics）、商业型（TSS/8、TOPS-10）、批处理扩展型（OS/360 TSO）；UNIX 选择极简研究路线，与商业系统目标不同
