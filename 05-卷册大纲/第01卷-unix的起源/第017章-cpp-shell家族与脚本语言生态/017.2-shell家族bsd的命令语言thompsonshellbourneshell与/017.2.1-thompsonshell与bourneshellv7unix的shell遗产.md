# 017.2.1 Thompson shell 与 Bourne shell：V7 UNIX 的 shell 遗产

**要点**：Ken Thompson 于 1971 年为 First Edition UNIX 编写 Thompson shell（sh），是 UNIX 第一个命令解释器；Stephen Bourne 于 1977-1979 年间在 Bell Labs 为 V7 UNIX（1979）编写 Bourne shell，取代 Thompson shell 成为 AT&T UNIX 默认 shell；Bourne shell 引入了 shell 脚本编程的核心特性：变量、控制结构、函数、here-document 等；早期 BSD（1BSD/2BSD，1978-1979）基于 V6/V7 UNIX，自然继承了 Thompson shell 与 Bourne shell

**史料**：V6 UNIX Manual、V7 UNIX Manual、Bourne S R. An Introduction to the UNIX Shell [J]. Bell System Technical Journal, 1978, 57(6, Part 2): 2797-2822；Mashey J R. The UNIX Shell [J]. Bell System Technical Journal, 1978, 57(6, Part 2): 2823-2838 ［B］

**史观**：实践先于理论：shell 从交互式命令解释需求中演进

**辨析**：Thompson shell 与 Bourne shell 的关系——Bourne shell 并非 Thompson shell 的超集，而是重写；早期 BSD 同时包含 sh（Bourne shell）与新开发的 csh

**文献**：Bourne S R. An Introduction to the UNIX Shell [J]. Bell System Technical Journal, 1978, 57(6): 2797-2822；V7 UNIX Programmer's Manual (1979)；Mashey J R. The UNIX Shell [J]. BSTJ 1978, 57(6): 2823-2838 ［B］
