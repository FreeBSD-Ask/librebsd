# 018.4.1 Java 移植的无名工程师

**要点**：FreeBSD OpenJDK 移植由 Greg Lewis、Kurt Miller 等社区工程师长期推动，2000 年代起持续维护 OpenJDK 6/7/8/11/17 的 FreeBSD 移植；他们的工作长期被主流叙事遮蔽

**史料**：FreeBSD OpenJDK Port 维护记录、freebsd-java 邮件列表 ［A］

**史观**：总纲第 10 条——动手者创造历史。项目史观总纲第 14 章 14.2 节载 “真正的问题不在于技术发展的程度，而在于是否动手”——Greg Lewis、Kurt Miller 等社区工程师长期维护 FreeBSD OpenJDK 移植即 “动手者” 的主体性在场；其工作 “处于主流叙事边缘” 非因其社会阶层 “边缘”，而是因事后叙事偏向 Core Team 与大幅 commit 的核心开发者（参第 14 章 “史学含义” “史家应记录那些默默做事的老实人，而非只写那些站在台前的大佬”）；14.5 节 “文档与代码的本体平等” 提示 Ports MAINTAINER 字段、freebsd-java 邮件讨论与 OpenJDK 代码本身在本体论上地位相等

**辨析**：贡献者名单以 Ports MAINTAINER 字段与 freebsd-java 邮件列表提交记录交叉核对——Greg Lewis、Kurt Miller 为长期 MAINTAINER，同期贡献者尚有 Jonathan Chen、Bill Fumerola 等，名单不完整因部分早期贡献者已无活跃邮件记录

**文献**：FreeBSD Ports Tree (java/openjdk*)；freebsd-java 邮件存档；提交日志 ［A］
