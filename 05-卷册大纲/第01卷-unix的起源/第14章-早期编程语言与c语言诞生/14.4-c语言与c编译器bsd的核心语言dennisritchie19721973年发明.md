## 14.4.1 Ritchie 与 C 语言在 Bell Labs 的诞生
- 要点：Dennis M. Ritchie 于 1972-1973 年间在 Bell Labs 在 B 语言（Ken Thompson 1970）基础上发明 C 语言，用于重写 UNIX 内核；1973 年《Fourth Edition UNIX Programmer's Manual》首次记载 C 语言；1978 年 Kernighan 与 Ritchie 出版《The C Programming Language》（K&R C）；C 语言成为 UNIX 与 BSD 的系统编程语言，贯穿 BSD 全部历史
- 史料：Ritchie 1993 “The Development of the C Language”、Kernighan & Ritchie 1978《The C Programming Language》ISBN 0-13-110163-3、V4/V6/V7 UNIX Manual [考据脚注：经相关权威来源交叉验证。]
- 史观：总纲第 2 条与第 20 条——实践先于理论与基础科学：C 从 UNIX 内核重写的工程需求中诞生
- 辨析：C 语言的发明时间存在多个节点——1972 年早期 C、1973 年用于内核重写、1978 年 K&R 出版、1989 年 ANSI C 标准化

## 14.4.2 PCC：Portable C Compiler 与早期 BSD

## 14.4.3 GCC 进入 FreeBSD：GNU 工具链的接管
- 要点：Richard Stallman 于 1987 年 3 月 22 日发布 GCC 0.9（第一个 beta 版本），随后于 1987 年 5 月 23 日正式发布 GCC 1.0（GNU C Compiler）；386BSD（1992）与早期 FreeBSD（1.0/2.0，1993-1994）已采用 GCC 作为系统编译器，PCC 逐步退役；FreeBSD 基础系统长期使用 GCC 2.7.2.3 → GCC 2.95 → GCC 3.x → GCC 4.2.1 的演进路径；FreeBSD 9.0（2012 年 1 月）仍以 GCC 4.2.1 为默认编译器，同时默认安装 Clang 3.0 作为可选；GCC 采用 GPLv2+ 许可证，为后续许可证争议埋下伏笔。**FreeBSD 基础系统 C 编译器演进**：

| 时间节点 | FreeBSD 版本 | 默认编译器 | 备注 |

| 1987-05-23 | — | GCC 1.0 发布 | GCC 首个正式版本 |

## 14.4.4 Clang/LLVM 的崛起与 FreeBSD 编译器切换
- 要点：LLVM 项目由 Chris Lattner 于 2000 年在伊利诺伊大学发起，Clang C/C++/Objective-C 编译器前端于 2007 年首次开源；FreeBSD 社区自 2009 年起推进 Clang 适配，Brooks Davis、David Chisnall、Dimitry Andric、Ed Schouten、Roman Divacky 等为核心贡献者；FreeBSD 9.0（2012 年 1 月）默认安装 Clang 3.0 但默认编译器仍为 GCC 4.2.1，WITH_CLANG_IS_CC 选项可切换；FreeBSD 10.0（2014 年 1 月）i386/amd64/arm 等平台正式以 Clang/LLVM 3.3 为默认系统编译器，GCC 4.2.1 不再默认构建（仅 pc98 等少数平台保留）；切换动机包括 BSD 许可证友好（BSD vs GPL）、编译速度更快、错误诊断更友好、模块化架构适合 IDE 集成；GCC 4.2.1 最终从 FreeBSD 基础系统完全移除为 FreeBSD 12/13 时期

## 14.4.5 Fortran 编译器在 BSD 中的演进：f77→f2c→g77→gfortran
- 要点：早期 BSD（1BSD-4.3BSD）包含 Bell Labs 的 f77 Fortran 编译器（与 PCC 配套），为科学计算用户提供 Fortran 77 支持；f2c（Fortran to C 转换器）由 Bell Labs、AT&T 与民间开发者于 1990 年代初开发，可将 Fortran 77 源码转换为 C 代码后用 GCC 编译；GCC 的 g77（GNU Fortran 77）前端自 1990 年代中期进入 FreeBSD Ports 与基础系统，FreeBSD 9.0 基础系统 GCC 4.2.1 仍包含 f77/（即 g77）目录；gfortran 作为 GCC 4.0（2005）引入的新 Fortran 95/2003/2008 前端取代 g77，但未进入 FreeBSD 基础系统（用户需通过 Ports 安装 lang/gcc）；Clang/LLVM 目前无原生 Fortran 前端，Flang（基于 LLVM 的 Fortran 编译器）正在开发中
- 史料：FreeBSD SVN base/release/9.0.0/gnu/usr.bin/cc/f77/ 目录、f2c 官方文档、GCC g77/gfortran Release Notes、FreeBSD Porter's Handbook、freebsd.db 数据库交叉验证——`SELECT DISTINCT cf.file_path, c.author_date, c.message_subject FROM commits c JOIN commit_files cf ON c.commit_hash=cf.commit_hash AND c.repo_name=cf.repo_name WHERE c.repo_name='freebsd-src' AND c.author_date BETWEEN '1993-01-01' AND '1995-12-31' AND (cf.file_path LIKE '%fortran%' OR cf.file_path LIKE '%f77%' OR cf.file_path LIKE '%f2c%') ORDER BY cf.file_path LIMIT 30` 返回 30+ 条 1994-1995 年记录：(1) 1994-01-12 commit aaed6788e756 L Jonas Olsson “Added -o option to rename C output file. This only works when Fortran input is from a file, not stdin.”；(2) 1994-05-01 FreeBSD 1.1 RELEASE commit a16f65c7d117 含 `gnu/usr.bin/cc/cc/f77.script`、`include/f2c.h`、`lib/libF77/Makefile`、`lib/libF77/README`、`lib/libF77/Version.c`、`lib/libF77/abort_.c`、`lib/libF77/c_abs.c`、`lib/libF77/c_cos.c`、`lib/libF77/c_div.c`、`lib/libF77/c_exp.c` 等——证实 FreeBSD 1.1 起基础系统已含完整 f77/f2c/libF77 工具链；(3) 1994-07-01 FreeBSD 1.1.5.1 commit 5e0e9b99dc3f 含 `gnu/usr.bin/cc25/usr.bin.f77/Makefile`、`gnu/usr.bin/cc25/usr.bin.f77/f77.script`；(4) 1994-10-25 commit 1f967df0a48e L Jonas Olsson “Added FORTRAN rule”；(5) 1994-10-26 commit a5a29f816ec1 L Jonas Olsson “Install f2c.h for FORTRAN support. Obtained from: netlib.att.com”；(6) 1997-09-15 commit f37c3d0edb12 Jordan K. Hubbard “MFC: a number of trivial cosmetic updates and a fairly large update of f2c”；(7) 1997-09-15 commit 5a5c688432b1 Jordan K. Hubbard “MFC: In honor of fortran programmers everywhere. :)”；`SELECT commit_hash, author_date, author_name, message_subject FROM commits WHERE repo_name='freebsd-src' AND (message_subject LIKE '%FORTRAN%' OR message_subject LIKE '%Backus%') ORDER BY author_date ASC LIMIT 10` 返回 10 条记录，证实 FORTRAN 在 FreeBSD 基础系统持续存在至 1998 年 ［A］
- 史观：总纲第 2 条与第 22 条——实践先于理论与开源运动：Fortran 支持从 Bell Labs 原生工具到 GNU 工具链再到 LLVM 生态的演进
- 辨析：FreeBSD 基础系统中 Fortran 支持的终止时间——FreeBSD 10.0 移除 GCC 后基础系统不再包含 Fortran 编译器，用户需通过 Ports 安装 lang/gcc（含 gfortran）；f2c 曾长期在 Ports 中提供（lang/f2c）；[考据脚注] FreeBSD 1.1（1994-05-01）起基础系统已含 f77/f2c/libF77 完整工具链一事经 freebsd.db 交叉印证——commit a16f65c7d117（“Release FreeBSD 1.1”，1994-05-01）含 `gnu/usr.bin/cc/cc/f77.script`、`include/f2c.h`、`lib/libF77/` 系列文件
