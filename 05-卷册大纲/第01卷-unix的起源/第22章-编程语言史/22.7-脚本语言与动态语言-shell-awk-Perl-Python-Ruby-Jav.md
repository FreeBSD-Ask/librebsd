# 22.7 脚本语言与动态语言——shell、awk、Perl、Python、Ruby、JavaScript（1977-2026）

## 要点

1977 年，Stephen Bourne（Bell Labs）发布 Bourne shell（sh），首个广泛使用的 UNIX shell；Bourne shell 的核心特性：变量、控制结构（if/for/while/case）、函数、管道与重定向、通配符扩展（globbing）；1979 年 Version 7 UNIX 发布 sh，成为 UNIX 标准 shell。
1977 年，Alfred Aho、Peter Weinberger、Brian Kernighan（Bell Labs）发布 awk（命名取自三人姓氏首字母），专为文本处理与报表生成设计；awk 的核心特性：模式-动作（pattern-action）语法、正则表达式、字段与记录（$0 全行、\$1 第一字段等）、关联数组；awk 后被 POSIX 标准化（POSIX awk），GNU awk（gawk, 1986）与 mawk（Michael Brennan, 1989）为广泛使用的实现。
1987 年，Larry Wall 发布 Perl 1.0，融合 awk、sed、sh、C 的特性，专为文本处理与系统管理设计；Perl 5（1994）引入对象、模块、引用等特性，Perl 6（2015，改名 Raku）为重新设计版本但未能广泛传播；Perl 在 1990 年代是 Web CGI 编程的主要语言，后随 PHP、Python、Ruby 的兴起而衰落；2026 年 7 月现状：Perl 5.40 为最新版本，主要用于遗留系统管理与文本处理。
1991 年，Guido van Rossum（吉多·范罗苏姆） 发布 Python 0.9.0，灵感来源于 ABC 语言与 C；Python 的核心特性：清晰的语法（强制缩进）、动态类型、垃圾回收、丰富的标准库、模块化；Python 2.0（2000）、Python 3.0（2008，不兼容 Python 2）、Python 3.12（2023）持续演化；Python 在 2010 年代后成为数据科学、机器学习、Web 开发（Django、Flask）、系统管理（Ansible）等领域的主要语言；2026 年 7 月现状：Python 3.13 为最新版本。
1995 年，Yukihiro Matsumoto（松本行弘）发布 Ruby 0.95，融合 Perl 的实用性、Smalltalk 的纯面向对象、Python 的可读性；Ruby on Rails（2004，David Heinemeier Hansson）框架使 Ruby 在 Web 开发领域流行；2026 年 7 月现状：Ruby 3.3 为最新版本。
1995 年，Brendan Eich（布兰登·艾奇）（Netscape）在 10 天内实现 JavaScript 1.0（最初名为 Mocha，后改名 LiveScript，1995 年 12 月改名 JavaScript）；JavaScript 的核心特性：动态类型、原型继承、函数是一等公民、闭包；JavaScript 在浏览器中运行，成为 Web 开发的主要语言；Node.js（2009，Ryan Dahl）使 JavaScript 可用于服务器端，React（2013，Facebook）、Vue（2014，尤雨溪）、Angular（2016，Google）等前端框架使 JavaScript 成为全栈语言；2026 年 7 月现状：ECMAScript 2024（ES15）为最新标准，JavaScript 与 TypeScript（Microsoft, 2012）共同主导 Web 开发。

#### 史观

本子节史观映射覆盖以下 5 条相关总纲，皆已回溯到 29 章原文核验：

**总纲 4（分离聚合是永恒规律）**——见 据原文第 4 章 4.1 节：

> “分离聚合是世界发展的规律。分久必合，合久必分，具有必然性。”

脚本语言的演化呈现分离聚合——shell、awk、Perl 从分离（各自针对不同场景）到部分聚合（Perl 融合 shell/awk/sed 特性），Python、Ruby 从分离（不同设计哲学）到部分聚合（二者均支持面向对象、函数式编程），JavaScript 从浏览器分离到服务器端聚合（Node.js）——这一系列分离聚合并非线性进步，而是不同形式主义的循环呈现。

**总纲 3（不存在进步，只有权力再分配）**——见 据原文第 3 章 3.2 节：

> “所谓进步只不过是权力再分配，把演讲台上的人割一茬，换他来一个样。”

Python 在 2010 年代后取代 Perl 成为数据科学主要语言，并非 “Python 优于 Perl” 的进步，而是商业资本的权力再分配——Google（TensorFlow, 2015）、Facebook（PyTorch, 2016）等公司将机器学习框架的资源从 Perl/Java 重新分配至 Python；JavaScript 成为全栈语言，是 Netscape（1995 浏览器）、Google（2008 V8 引擎）、Microsoft（2016 TypeScript）等公司将 Web 开发的资源重新分配至 JavaScript 生态。

**总纲 5（没有必然性，只有偶然性）**——见 据原文第 5 章 5.2 节：

> “将英雄人物的出现必然化是一种机械的错误，没有认识到偶然性和自由的意义。”

若 Guido van Rossum 未在 1989 年圣诞节假期开始 Python 开发，若 Yukihiro Matsumoto 未在 1993 年决定创建 “比 Perl 更强大、比 Python 更面向对象” 的语言，若 Brendan Eich 未在 1995 年 5 月被 Netscape 雇佣并在 10 天内实现 JavaScript，脚本语言史会完全不同。所谓 “Python/Ruby/JavaScript 必然流行” 的叙事是史家的事后重构。

**总纲 10（动手者创造历史）**——见 据原文第 14 章 14.1-14.2 节：

> “这个世界不是靠什么精英也不是靠什么人民更不是靠什么其他人运转的，而是我们这些老实人，才让世界运转了起来。”

Stephen Bourne 亲自实现 Bourne shell，Aho/Weinberger/Kernighan 亲自实现 awk，Larry Wall 亲自实现 Perl，Guido van Rossum 亲自实现 Python，Yukihiro Matsumoto 亲自实现 Ruby，Brendan Eich 亲自实现 JavaScript——这些是动手者的实践，而非 “Bell Labs 决定” 或 “Netscape 决定” 等组织决策的产物。

**总纲 2（历史是形式主义化的非存在）**——见 据原文第 2 章 2.5 节：

#### 辨析

**Bourne shell 与 C shell 关系辨析**：Bourne shell（sh, 1977）与 C shell（csh, 1978，Bill Joy）同期诞生，C shell 语法类似 C 语言，但 Bourne shell 因 POSIX 标准化而成为主流；csh/tcsh 在 BSD 系统中仍保留。本子节采用 “Bourne shell（POSIX 标准化）为主流，C shell（csh/tcsh）在 BSD 系统中保留” 的限定性表述。

**Perl 6 与 Raku 辨析**：Perl 6（2015 发布）为 Perl 5 的重新设计版本，但因语法不兼容与开发周期过长（2000-2015，15 年）未能广泛传播；2020 年 Perl 6 改名 Raku，与 Perl 5 彻底分离。本子节采用 “Perl 6（2015）改名 Raku（2020），与 Perl 5 彻底分离” 的限定性表述。

**Python 2 与 Python 3 不兼容辨析**：Python 3.0（2008）不兼容 Python 2，导致 Python 2 与 Python 3 长期共存（约 10 年过渡期）；Python 2 于 2020 年 1 月 1 日正式 EOL（End of Life）。本子节采用 “Python 3.0（2008）不兼容 Python 2，Python 2 于 2020 年 EOL” 的限定性表述。

**JavaScript 与 ECMAScript 关系辨析**：JavaScript 是 Netscape 对 ECMAScript 标准的实现（含扩展），ECMAScript 是标准（由 ECMA TC39 维护）；日常使用中 JavaScript 与 ECMAScript 常互换使用。本子节采用 “JavaScript 是 ECMAScript 标准的实现（含 Netscape/Mozilla 扩展），二者常互换使用” 的限定性表述。
