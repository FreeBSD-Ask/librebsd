# 003.10.2 游戏的技术实现与硬件约束

**要点**：PDP-7 标准配置内存为 4K 字（每字 18 位，约合 9KB），无内存管理单元；Thompson 用汇编实现游戏，包括星系模拟、飞船控制、着陆物理；硬件约束逼迫极简设计。PDP-7 关键规格：

| 规格 | 数值 |
| -- | -- |
| 字长 | 18 位 |
| 标准内存 | 4K 字（约 9KB） |
| 最大可扩展内存 | 32K 字（约 72KB） |
| 内存管理单元 | 无 |
| 内存周期 | 2.75 微秒 |
| 首次出货 | 1964 年 12 月 |
| 总产量 | 120 台 |

**史料**：PDP-7 技术手册、Thompson 早期代码存档、DEC 官方规格说明、DEC PDP-7 1964 年产品手册（archive.computerhistory.org 存档） ［A］

**史观**：总纲第 7 条——硬件约束塑造软件形态，极简资源催生极简设计哲学

**辨析**：4K 字为标准配置，DEC 1964 年 PDP-7 产品手册明确“ECONOMICAL MEMORY EXPANSION up to 32,768 words”即最高可扩展至 32K 字（约 72KB）（先前叙事称“最高可扩展至 64K 字（约 144KB）”有误：经 archive.computerhistory.org 1964 年 PDP-7 产品手册、soemtron.uk PDP-7 选项列表、bitsaversvm01“Architectural Evolution in DEC's 18b Computers”by Bob Supnik 三项独立来源交叉印证，PDP-7 最大寻址空间为 32K 字而非 64K 字；64K 字为后续 PDP-15 的能力，非 PDP-7）；Bell Labs 所用 PDP-7 具体配置存在不同说法；游戏代码是否保留至今存在疑问

**文献**：DEC PDP-7 Handbook (1965)；DEC PDP-7 1964 年产品手册（Computer History Museum 存档 archive.computerhistory.org/resources/access/text/2024/06/102776306-05-0001-acc.pdf）；soemtron.uk PDP-7 选项列表；Bob Supnik“Architectural Evolution in DEC's 18b Computers” (2002, bitsaversvm01)；Thompson 早期代码（部分见于 Unix Heritage Society 存档） ［A］
