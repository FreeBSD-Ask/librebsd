- Hubbard 以 X Consortium 源码树拆分为先例论证 FreeBSD 基本系统打包化的必要性：他承认自己当年斥 X.org 组件化为异端，如今承认“X.org 的拆分者事后被证明完全正确”（5946.28-5949.92），并断言“FreeBSD 面前也有类似的演化在等着”（5977.42-5984.02）；其设想是以 JSON 之类可读格式定义 base 内容、按角色生成发行镜像，把 sendmail、Perl 等历史包袱移出 base。此论把“base 的定义”与“如何为特定用途构建”分离，直指单体源码树与现代化打包体制之间的结构性矛盾。（BSD Now EP113，[5946.28-5988.30]，L1）
- 主持人转述 Ted Unangst 对可复现构建的限定：它不防 Shellshock 类代码级漏洞，也无法对抗 trusting trust 式编译器后门——若编译器全域被攻陷，可复现性只会忠实复现后门；其结论是可复现构建是工具箱中的一件工具而非安全终点，这对 Debian 主导的可复现构建热构成边界辨析。（BSD Now EP107，[4014.74-4277.72]，L2）

- Olivier 关于 OpenBSD 缺乏多队列驱动与多线程网络栈的论断，仅基于其在 OpenBSD 5.x 时期的测试，属 2014 年时点判断；OpenBSD 网络栈此后的并行化进程不在本期证据之内，不宜外推为对该项目后续状态的结论。 [存疑脚注] 时点性技术判断，需与 OpenBSD 后续版本演进核对（BSD Now EP60，[1640.26-1680.98]，L4）
