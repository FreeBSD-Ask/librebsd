**要点**：

- PC-BSD 发布 1.0 的第二候选版：本质是将 FreeBSD 6.0 打包为单 CD 的桌面导向系统，预装 KDE 3.5，全程图形化安装并默认创建普通用户与自动登录，明确面向家用场景。其区别于普通 FreeBSD 加 KDE 之处在于自研包管理器：以单个文件夹容纳应用的程序、库与配置，以双击式安装器交付并请求 root 密码安装，库彼此隔离以避免依赖冲突；当事人梳理此应用包理念的前史为 Acorn 的 RISC OS 与 NeXT，经 Apple 的 Darwin 推广。批评者指其制造冗余膨胀，当事人认为在单用户桌面系统上代价可接受；系统另提供在线更新，免除传统 make world 升级流程；因 1.0 正式版未至，当事人认为此时难作定评。（BSDTalk EP8，[55.22-316.42]，L1）
- 当事人盘点五项免费 BSD shell 账户服务：GNUK（转写亦作 gnooc）与 metawire.org 基于 OpenBSD，arbornet.org 基于 FreeBSD，freeshell.org 基于 NetBSD，此类社区服务多在低配硬件上勉强维持；另有惠普的 HP Test Drive 提供 FreeBSD、NetBSD、Tru64 UNIX、OpenVMS 与 Linux 的 shell，硬件规模远超社区服务（含 16 CPU 系统、GB 级内存），其 NetBSD 已是 3.0 版。当事人注册 GNUK.org 实测获当天技术支持响应，账户按使用年限与捐赠硬件分级、可申请提升配额；并警告挂 IRC 机器人、拒绝服务攻击、骚扰等滥用会毁掉此类免费服务。（BSDTalk EP8，[389.20-605.24]，L1）
- 对 HP Test Drive 以 Telnet 接入一事，当事人批评 OpenSSH 作为 BSD 许可的安全 Telnet 替代品早已人人可用，Telnet 继续被使用不可原谅；并推测 HP 或有意以不安全协议劝阻用户将测试机当重要系统使用。（BSDTalk EP8，[559.26-605.24]，L1）
- OpenBSD 发行传统：自 3.0 版起每版附带一首发布歌曲，当事人以其中一首作为本期节目开场音乐。（BSDTalk EP8，[42.72-51.34]，L1）

**史料**：

- PC-BSD 1.0 RC2 的一手试用记录（安装流程、KDE 3.5 环境、bundle 式包管理器、卸载系统与在线更新），为桌面 BSD 早期形态的直接证词；另含 2006 年 1 月免费 BSD shell 账户服务名录及其底层系统、硬件规模与滥用生态的口述记录，以及 OpenBSD 发行歌传统（自 3.0 起）的口述。（BSDTalk EP8，[42.72-479.56]，L1）

**史观**：

- 总纲15 文化即形式主义：OpenBSD 每版附发行歌的做法，把版本发布这一纯技术事件转化为可感知的文化仪式：例行发布程序被赋予音乐形式而成为社区文化产品，显示技术社群如何以仪式性形式维系自我认同与传播节奏。（BSDTalk EP8，[42.72-51.34]，L1）
