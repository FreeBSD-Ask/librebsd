# 261.1 GhostBSD 与 FreeBSD 桌面化（2009-2026）

## 261.1.1 FreeBSD 上的桌面集成
  - 要点：GhostBSD（2009 起）以 FreeBSD 为基底，提供 MATE 桌面与图形安装器，降低 FreeBSD 桌面使用门槛；其存在反映社区对 “开箱即用 BSD 桌面” 的长期需求。
  - **ghostbsd-src 仓库 commit 量与 merge 比例演变表（L7.1.1.ghostbsd-src）**：

| 年份 | total_commits | merge_commits | merge 比例 |
| --- | --- | --- | --- |
| 2015 | 25,675 | 543 | 2.1% |
| 2017 | 20,562 | 601 | 2.9% |
| 2019 | 20,740 | 538 | 2.6% |
| 2022 | 14,032 | 151 | 1.1% |

- 史料：GhostBSD 项目档案、FreeBSD 桌面文档（福利局/ Ports 中的桌面环境）；bsd_commits.db 查询 L7.1.1.ghostbsd-src 显示：ghostbsd-src 仓库因 fork 自 FreeBSD 故继承上游 1993 年起的 commit 历史，2015 年 total_commits = 25,675（merge_commits = 543, 2.1%）、2017 年 20,562（601, 2.9%）、2019 年 20,740（538, 2.6%）、2022 年 14,032（151, 1.1%），commit 量在 2015-2016 年达峰后呈缓慢下降趋势，merge commit 比例长期维持在 1-3% 反映 GhostBSD 与上游 FreeBSD 的同步节奏；bsd_commits.db 查询 L1.1.1（ghostbsd-src 仓库 2012-2026 年每年 commit 量时间序列）[考据完成：2026-07-28 经穷尽联网考据，上述史料清单为已知公开来源汇总，部分原始档案未公开数字化或须档案馆藏地现场核验，属史料缺口，须待原始档案公开后方可补充确证]
- 史观：总纲第 25 条——终结中的延续，桌面 BSD 是 FreeBSD 在消费端的延伸尝试；统计结论印证：C-54（ghostbsd-src ~ pfsense-src Spearman rho = 0.9355 p = 9.154e-184）反映 GhostBSD 与 pfSense 虽产品形态迥异（桌面 vs 防火墙），但 commit 时间序列呈强正相关，体现 BSD 衍生项目同步跟随 FreeBSD 上游的工程节奏同源性，0 信任原则适用：强相关不等于因果，可能由共同的上游 FreeBSD 同步行为驱动
- 辨析：GhostBSD 版本对应的 FreeBSD 基底须以项目 Release Notes 核实；openbsd.db 查询 L7.1.1.ghostbsd-src 的 commit 量须警惕 fork 分歧识别局限——ghostbsd-src 仓库 1993 年起的 commit 是 fork 自 FreeBSD 继承的上游历史，非 GhostBSD 项目本地 commit，识别 GhostBSD 本地特有 commit 须通过 merge commit 与 parent_hashes 交叉验证，不可仅凭时间戳；2022 年 merge commit 比例降至 1.1% 可能反映 GhostBSD 2023 年转向直接派生 FreeBSD 13.x 后同步节奏的变化，须与 Eric Turgeon 公告交叉验证[双库验证 2026-08-15] GhostBSD 经邮件列表库（2014 年 FreeBSD Quarterly Status Report 提及 Eric Turgeon 为 GhostBSD 贡献者）与参考文献库（FOSSY 2023 FreeBSD Workshop 提及 GhostBSD）确认；Eric Turgeon 与 GhostBSD 的关联在双库中有记录
