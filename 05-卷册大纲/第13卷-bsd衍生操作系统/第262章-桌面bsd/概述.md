# 第 261 章 桌面 BSD：GhostBSD、MidnightBSD、NomadBSD、helloSystem

### 核心内容

本章论述面向桌面用户的 BSD 衍生系统：GhostBSD（FreeBSD + MATE/GTK）、MidnightBSD（独立桌面 BSD，基于 FreeBSD 分支）、NomadBSD（Live 桌面 BSD）、helloSystem（macOS 风格 FreeBSD 桌面）。这些是 BSD 许可证在消费桌面上的持续尝试，反映 BSD 在桌面生态的结构性弱势。
