## 260.1.1 基于 FreeBSD 的 NAS 系统
  - 要点：FreeNAS（2005）以 FreeBSD 为基底，提供基于 Web 的 NAS 管理，利用 FreeBSD 的 ZFS（later）、Samba、ZFS 集成能力；其成功证明 BSD 在存储设备上的可行性。

- FreeNAS（Free Network Attached Storage）定位为轻量定制 FreeBSD 发行版：刻录 CD 引导后快速安装裸 FreeBSD 6.0，并以源自 m0n0wall 项目的 Web 界面管理磁盘挂载、软 RAID、格式化与 Samba、NFS、FTP 共享，亦支持 USB 引导。作者动机是市面上没有免费的 NAS 服务器；其原为 m0n0wall 长期用户且不懂 FreeBSD，因 m0n0wall 开发者指南易读易懂而决定照此做一个存储版。对 BSD 许可证可能被他人拿走而不回馈的顾虑，作者表示毫不在意：项目起初只为自用，用户可任意处置，这样做反而更好。（BSDTalk EP11，[461.60-667.44]，L1）
- 作者选择 FreeBSD 作为 NAS 基座的理由：稳定性高、系统足迹小、安全问题极少，且市面已有大量基于 FreeBSD 的设备，顺势而为。作者的个人环境：主力开发与编译工作站为 FreeBSD，另有一台 Windows 机与一台改造为媒体播放机的 Xbox；FreeNAS 是其编程起点，边做边学 PHP 并借项目认识 FreeBSD。（BSDTalk EP11，[675.50-762.58]，L1）
- 局限与生态观察：FreeBSD 对 NTFS 的支持很差（可读 Linux ext2 但 NTFS 弱）；FreeNAS 当时尚无用户认证，文件对任何能访问者开放，只应部署于可信网络，认证功能在开发中。作者尝试把 FreeBSD 装上日常工作笔记本时认为安装器不够易用——小项目与服务器场景尚可，桌面扩展不行；主持人因此推荐桌面导向、安装器易用的 PC-BSD。节目收尾主持人提醒：当前版本不宜直接暴露于互联网。（BSDTalk EP11，[567.92-948.42]，L1）
