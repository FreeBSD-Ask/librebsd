# 259.1 FreeNAS 的 FreeBSD 根基（2005-2011）

## 259.1.1 基于 FreeBSD 的 NAS 系统
  - 要点：FreeNAS（2005）以 FreeBSD 为基底，提供基于 Web 的 NAS 管理，利用 FreeBSD 的 ZFS（later）、Samba、ZFS 集成能力；其成功证明 BSD 在存储设备上的可行性。
  - **truenas-middleware 仓库 FreeNAS 早期社区规模演变表（L7.6.1）**：

| 年份 | commit_count | contributor_count | ixsystems_contributors |
| --- | --- | --- | --- |
| 2010 | 373 | 5 | 1 |
| 2011 | 3,195 | 8 | 3 |
| 2012 | 2,993 | 7 | 3 |

- 史料：FreeNAS 项目档案（iXsystems）、Olivier Cochard-Labbé 公开访谈、FreeBSD ZFS 集成史（参见相关章节 ZFS 部分）；openbsd.db 查询 L7.6.1 显示：truenas-middleware 仓库 2010 年 commit_count = 373、contributor_count = 5、ixsystems_contributors = 1，2011 年 commit_count = 3,195、contributor_count = 8、ixsystems_contributors = 3，2012 年 commit_count = 2,993、contributor_count = 7、ixsystems_contributors = 3，反映 FreeNAS/TrueNAS 早期社区规模小且 iXsystems 员工占比有限的状况 ［B］
- 史观：总纲第 2 条——实践先于理论，FreeNAS 直接在 FreeBSD 上构建而非自研内核；统计结论印证：C-54（truenas-middleware 仓库 commit 量趋势）反映 FreeNAS 早期（2010-2012）社区规模小且 iXsystems 员工占比有限（2010 年 ixsystems_contributors = 1/5），体现 BSD 衍生项目 “个人发起 → 企业接手” 的典型演化路径，0 信任原则适用：ixsystems_contributors 字段仅基于邮箱域名识别，员工用个人邮箱提交会导致低估
- 辨析：FreeNAS 各版本对应的 FreeBSD 基底版本须以 Release Notes 核实；openbsd.db 查询 L7.6.1 的 ixsystems_contributors 字段仅基于邮箱域名（@ixsystems.com、@truenas.com）识别，员工可能用个人邮箱（如@gmail.com）提交，识别存在低估，须与 iXsystems 员工名册、commit message 中的 Signed-off-by 行交叉验证[双库验证 2026-08-15] FreeNAS 基于 FreeBSD 经参考文献库（BSDCan 2007 Olivier Cochard-Labbé FreeNAS 演讲）确认；iXsystems 与 TrueNAS 的关联经参考文献库（vBSDCon 2017 iXsystems 相关论文）确认
- 文献：FreeNAS/TrueNAS 官方文档；iXsystems 公司史；bsd_commits.db 查询 L7.6.1（truenas-middleware 仓库 commit 量趋势与 iXsystems 员工占比，2005-2026）；原材料/研究/bsd 仓库分析/数据分析/衍生项目与跨项目对比分析.md §L7.6。 ［B］
