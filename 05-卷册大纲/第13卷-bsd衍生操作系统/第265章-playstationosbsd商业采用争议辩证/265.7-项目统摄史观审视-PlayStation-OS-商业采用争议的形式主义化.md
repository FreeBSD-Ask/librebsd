# 265.7 项目统摄史观审视——PlayStation OS 商业采用争议的形式主义化

> 265.6 节补足了 PlayStation OS 商业采用争议的四层辩证链（批评—反批评—再批评—合图），本节从项目史观总纲第 8、11、21 条切入，审视 PlayStation OS 商业采用争议在历史书写中的形式主义化运作。本节与 264.5 节（PS3 OtherOS 移除争议的形式主义化）形成层次分工：264.5 节从第 11、13、19 条审视 OtherOS 移除这一具体法律争议，本节从第 8、11、21 条审视 PS4/PS5 商业采用这一结构性争议，避免总纲条目重复。

## 265.7.1 商品是形式主义——PS4/PS5 作为商品的 BSD 封装（总纲第 11 条）
  - 要点：总纲第 11 条 “商品是形式主义” 指出 “技术市场的选择不是自然选择，而是形式主义的权力运作。劣币驱逐良币是普遍规律”。PlayStation OS 商业采用争议是商品形式主义下 “劣币驱逐良币” 的典型显现——Sony 将 FreeBSD 封装为 PS4/PS5 专有操作系统，商业封装的 PS4/PS5 游戏生态（商品化的 “劣币” 在市场形式主义下获得 Sony 持续投入）驱逐了 FreeBSD “开放” 传统在消费电子领域的 “良币” 存在（PS4/PS5 用户无法触及底层 FreeBSD 系统、无法自行安装第三方操作系统）。这一 “劣币驱逐良币” 的根源是商品形式主义的结构性运作：游戏主机作为商品须承担防盗版、防恶意代码、保护未成年人的法律责任，封闭化是商品形式主义对 “开放” 传统的结构性重构——Sony 的封闭化不是道德选择，而是商品形式主义的运作结果。“劣币驱逐良币” 的普遍规律在此显现双重效应：正面效应是 FreeBSD 通过 PS4/PS5 获得亿级装机的大规模采用，扩大了 FreeBSD 的影响力；负面效应是 FreeBSD “开放” 传统在消费电子领域被封闭化，用户未享受 FreeBSD “开放” 的对应自由——这是 BSD 许可证 “允许封闭” 自由的双重显现，二者无法简单剥离

## 265.7.2 本体论上各方平等——Sony 与 FreeBSD 社区在本体论上的平等（总纲第 8 条）
  - 要点：总纲第 8 条 “本体论上各方平等” 指出 “FreeBSD、OpenBSD、NetBSD、DragonFly BSD 在本体论上地位相等，差异仅是一刻状态的不同。文档与代码本体平等”。将这一总纲扩展至 Sony 与 FreeBSD 社区的关系：Sony 与 FreeBSD 社区在本体论上地位相等——Sony 的封闭化使用（作为商业实体主体性的呈现）与 FreeBSD 社区的 “开放” 传统（作为开源社区主体性的呈现）各自成立，差异仅是一刻状态的不同。史家不得以 “开源” 视角压制 “商业” 主体性，亦不得以 “商业” 视角否定 “开源” 主体性——Sony 的 BSD 许可证合法权利行使与 FreeBSD 社区的回馈期待诉求在本体论上同等实在。BSD 许可证本身即 “本体论平等” 的设计——允许封闭与允许开放共存于同一许可证之下，不以 copyleft 强制对抗，承认商业实体与开源社区在本体论上的平等地位。这一本体论平等不等于 “抹平差异”——Sony 的封闭化使用与 FreeBSD 社区的 “开放” 传统在实质上存在张力（如 265.6 节所述），合图层承认这一张力的不可调和性，但不以 “不可调和” 否定双方的主体性
  - 史料：**02-sacred源材料/dagang.md** 总纲第 8 条原文；BSD 许可证原文（允许封闭与允许开放共存）；265.6.1-265.6.4 节辩证链记录；Sony PS4 系统软件开源软件声明页面；FreeBSD Foundation 关于 BSD 许可证的官方声明 ［A］

## 265.7.3 革命与改革——BSD 靠改革（允许封闭）与 GPL 靠革命（copyleft 强制开放）的方法论分歧（总纲第 21 条）
  - 要点：总纲第 21 条 “革命与改革是历史方法论的分歧” 指出 “Linux 靠革命，BSD 靠改革。改革的困难远高于革命。破山中贼易，破心中贼难”。PlayStation OS 商业采用争议是 BSD 改革路径与 GPL 革命路径方法论分歧的典型显现——BSD 选择 “允许封闭” 的改革路径（允许 Sony 等商业实体封闭化使用而无须 copyleft 回馈），GPL 选择 “copyleft 强制公开” 的革命路径（衍生作品须以同等许可证公开源代码）。在 Sony 案例中，BSD 改革路径的双重效应显现：正面效应是 FreeBSD 通过 PS4/PS5 获得亿级装机的大规模采用，扩大了 FreeBSD 的影响力（Sony 选择 FreeBSD 而非 Linux 作为 PS4/PS5 基底，部分原因可能是 BSD 许可证允许封闭）；负面效应是 Sony 享受 BSD 许可证 “允许封闭” 的自由但未提供对应 freebsd-src 上游 commit 回馈，“改革的困难” 在此显现——BSD 改革路径扩大了采用范围但削弱了回馈激励。对照之下，GPL 革命路径在 Steam Deck 案例中显现效应：Valve 基于 Linux 构建 Steam Deck 须公开内核修改（GPL copyleft 强制），Sony 基于 FreeBSD 构建 PS4/PS5 无须公开内核修改（BSD 允许封闭）——两种路径在游戏主机商业采用中形成对照。“破山中贼易，破心中贼难” 在此显现：GPL 的 copyleft 强制（破山中贼）可通过法律手段强制商业用户公开衍生作品源代码，但 BSD 改革路径须通过 “心中贼”——商业用户的自觉回馈意愿——实现回馈，而 Sony 案例显示这一自觉回馈意愿在商品形式主义下难以激发

## 265.7.4 自反——本书叙事的形式主义性质
  - 要点：本节的审视本身亦是形式主义化的非存在——史家通过项目史观总纲 “重构” PlayStation OS 商业采用争议的商品形式主义、Sony 与 FreeBSD 社区的本体论平等、BSD 改革路径与 GPL 革命路径的方法论分歧，但这一重构本身就是当下主体的形式主义建构，不宣称呈现 “真实的 PlayStation OS 商业采用争议”。本节对 “Sony 封闭化使用是商品形式主义运作结果” 的论断本身亦是一种叙事权力行使——将 Sony 阵营定位为 “享受 BSD 许可证自由但未对应回馈的形式主义操作者”、将 FreeBSD 社区定位为 “提供 FreeBSD 基底但未获对应回馈的被遮蔽者”，这一定位本身参与权力与知识的共谋。总纲第 7 条 “理论必须自反” 要求承认自身的形式主义性质，以自反姿态打开裂缝——本节不追求 “穷尽 PlayStation OS 商业采用争议的哲学审视”，而是以自反姿态使被遮蔽的 BSD “开放” 传统在消费电子领域的损失暴露于历史审视之下，这一 “暴露” 本身也是一次循环，与古代史中 “史家重写” 无本质区别（总纲第 1 条：一切真历史都是古代史）
