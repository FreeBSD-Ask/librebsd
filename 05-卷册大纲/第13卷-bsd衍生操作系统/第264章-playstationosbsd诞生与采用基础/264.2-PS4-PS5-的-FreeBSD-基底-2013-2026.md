# 264.2 PS4/PS5 的 FreeBSD 基底（2013-2026）

## 263.2.1 Orbis/Prospero OS 的 FreeBSD 9 基础
  - 要点：PS4（2013）的 Orbis OS 基于 FreeBSD 9，PS5（2020）的 Prospero OS 延续 FreeBSD 基底并适配 AMD APU；Sony 与 FreeBSD 社区保持代码交流（如 GPU 驱动、网络栈修复回馈）。
  - 史料：Sony 工程演讲（BSDCan 等）、PS4/PS5 系统文档、FreeBSD 中与 Sony/PlayStation 相关 commit（bsd_commits.db）。 ［A］
  - 史观：总纲第 25 条——终结中的延续，FreeBSD 在主机世代间延续；统计结论印证：C-54（跨数据库关联分析 Task 28）显示 BSD 衍生 fork 项目 commit 时间序列呈强正相关（ghostbsd-src ~ pfsense-src rho = 0.9355），而 PlayStation OS 作为商业闭源 fork 其 commit 不在公开仓库 Spearman 相关矩阵中，反映商业闭源 fork 与社区开源 fork 在工程可观测性上的结构性差异——PS3/PS4/PS5 跨越三个主机世代的 FreeBSD 延续无法通过 commit 时间序列统计分析验证，须以 Sony 工程演讲与系统文档交叉印证，0 信任原则适用：Orbis/Prospero 的 FreeBSD 版本号须以 Sony 披露核实，未公开细节已考据完成（详见辨析字段），不得以统计分析推断闭源产品的版本同步节奏
  - 辨析：Orbis/Prospero 的 FreeBSD 版本号[考据完成：2026-07-28 经穷尽联网考据，PS4 Orbis OS 基于 FreeBSD 9.0 系列经多个二手来源（gamersky.com 2013-06、3dmgame.com 2013-06、CSDN 技术博客）广泛报道，CTurt 等 PS4 越狱开发者亦确认 FreeBSD 9.0 内核基础，但 Sony 官方从未发布正式声明确认具体 FreeBSD 版本号，PS5 Prospero OS 的 FreeBSD 版本号更未公开披露（推测基于 FreeBSD 12 或更新版本但无一手证据），保留为史料缺口]。
  - 文献：Sony 工程存档；bsd_commits.db。 ［A］

## 263.2.3 外部贡献者
  - 要点：Sony 工程师（含日本籍与非英美成员）向 FreeBSD 回馈驱动/网络补丁，构成企业 →BSD 的代码流动案例。
  - 史料：FreeBSD 与 Sony 相关 commit（freebsd.db）、Sony 工程演讲；freebsd.db 查询 L7.2.1 显示：衍生项目贡献者在 freebsd-src 的回馈 commit 前 30 名（≥5 次）中，未出现 @sony.com 邮箱域名的贡献者，反映 Sony 员工向 freebsd-src 上游直接回馈 commit 量未达前 30 名阈值（即 <5 次）或 Sony 员工未使用企业邮箱提交；与 iXsystems 员工合计回馈约 715 次、LLNL <behlendorf1@llnl.gov> 单人 2,603 次形成对比，Sony 对 freebsd-src 上游的直接回馈显著低于 OpenZFS 跨公司协作格局中的 iXsystems/LLNL/Delphix ［A］
  - 史观：总纲第 10 条。
  - 辨析：具体贡献者须以 commit 记录核实；freebsd.db 查询 L7.2.1 的 “未出现 @sony.com 邮箱贡献者” 不等于 Sony 零回馈——Sony 工程师可能使用 @freebsd.org 邮箱（被查询排除条件过滤）、个人邮箱或 @playstation.com 等子域名提交，且 PlayStation OS 作为专有产品其内部 fork 不公开，Sony 可能通过内部维护而非直接推送 freebsd-src 上游，须与 Sony 工程演讲、BSDCan 演讲存档、FreeBSD 提交权限记录交叉验证
  - 文献：freebsd.db 查询 L7.2.1（衍生项目贡献者在 freebsd-src 的回馈 commit，≥5 次，前 30 名）；原材料/研究/bsd 仓库分析/数据分析/衍生项目与跨项目对比分析.md §L7.2；Sony 工程存档。 ［A］
