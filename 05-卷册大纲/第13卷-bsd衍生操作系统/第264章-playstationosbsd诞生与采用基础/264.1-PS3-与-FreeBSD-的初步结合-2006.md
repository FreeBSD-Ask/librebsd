# 264.1 PS3 与 FreeBSD 的初步结合（2006）

## 264.1.1 Cell 时代 GameOS 的 BSD 组件
  - 要点：PS3（2006）的 GameOS 在 Linux 早期支持撤回后，底层含 FreeBSD 派生组件，Sony 工程师在 BSD 会议（如 BSDCan）披露 PlayStation 对 FreeBSD 的使用；具体组件范围须以 Sony 工程演讲核实。
  - **PlayStation 主机 BSD 基底世代对照表**：

| 主机世代 | 发布年份 | OS 名称 | FreeBSD 基底 |
| --- | --- | --- | --- |
| PS3 | 2006 | GameOS | FreeBSD 派生组件 |
| PS4 | 2013 | Orbis OS | FreeBSD 9 |
| PS5 | 2020 | Prospero OS | 延续 FreeBSD 基底（适配 AMD APU） |

- **商业实体 commit 占比时间序列表（L3.2.1，含 Sony @sony.com）**：

| 年份 | commercial_commits | total | 占比 |
| --- | --- | --- | --- |
| 2017 | 2,841 | 344,697 | 0.824% |
| 2018 | 3,887 | 336,461 | 1.155% |
| 2020 | 3,820 | 303,425 | 1.260% |

- 史料：Sony 工程师 BSDCan/相关会议演讲、PS3 系统文档（一手来源优先）；freebsd.db 查询 L3.2.1 显示：Sony（@sony.com 邮箱域名）商业 commit 在全 23 仓库汇总的 commercial_commits 中与其他 11 个商业实体合并统计，2017 年 commercial_commits = 2,841/total = 344,697（0.824%）、2018 年 3,887/336,461（1.155%）、2020 年 3,820/303,425（1.260%），Sony 单一实体占比须按邮箱域名细分查询；freebsd.db 查询 L3.2.2 显示：商业实体 commit 量按仓库分布中 freebsd-src 仓库 907 commits（含 Sony 等多实体合计），未单独列出 sony.com 占比[考据完成：2026-07-28 经穷尽联网考据，上述史料清单为已知公开来源汇总，部分原始档案未公开数字化或须档案馆藏地现场核验，属史料缺口，须待原始档案公开后方可补充确证]
- 史观：总纲第 2 条——实践先于理论，主机 OS 直接采用 FreeBSD 组件；统计结论印证：C-54（跨数据库关联分析 Task 28 多元 Spearman 相关矩阵显示 fork 项目 ghostbsd-src ~ pfsense-src rho = 0.9355 强相关）反映 BSD 衍生 fork 项目 commit 时间序列存在工程节奏同源性，而 Sony 作为商业实体其 @sony.com 邮箱在 L7.2.1 freebsd-src 前 30 名回馈贡献者中未出现，且 L3.2.1 商业实体 commit 占比不足 1.3%（2020 年 3,820/303,425），反映 PlayStation OS 作为专有闭源产品其 FreeBSD 回馈模式与社区 fork 项目结构性不同——fork 项目通过公开仓库同步上游，Sony 通过内部 fork 维护且不公开 commit，0 信任原则适用：L7.2.1 的邮箱域名识别存在局限，Sony 工程师可能使用 @freebsd.org 邮箱（被查询排除条件过滤）、个人邮箱或 @playstation.com 等子域名提交，commit 量不等于 PlayStation OS 对 FreeBSD 的依赖程度
- 辨析：PS3 的 “FreeBSD 成分” 范围与 Linux 支持撤回的关系须厘清[考据完成：2026-07-28 经穷尽联网考据，PS3 的 FreeBSD 成分范围与 Linux 支持撤回的精确关系 Sony 未官方公开披露，多个二手来源（gamersky.com、3dmgame.com、CSDN）记载 PS4 Orbis OS 基于 FreeBSD 9.0 但 PS3 时期的 FreeBSD 成分细节未公开，保留为史料缺口]；openbsd.db 查询 L3.2.1 与 L3.2.2 的 Sony 占比须警惕邮箱域名识别不精确——Sony 工程师可能用个人邮箱或 @playstation.com 等子域名提交，且 PlayStation OS 作为专有产品其内部 fork 不公开，commit 量不等于 Sony 对 FreeBSD 上游的依赖程度，须与 Sony 工程演讲、BSDCan 演讲存档交叉验证[双库验证 2026-08-15] PlayStation 使用 FreeBSD 经参考文献库（FOSDEM 2020 "FreeBSD Around the World"、linux.conf.au 2020 "FreeBSD, The Other Unix-Like OS"）确认；PS3 2006 年、PS4 2013 年、PS5 2020 年发布年份在参考文献库（FreeBSD Foundation timeline）中可确认；PS3 GameOS 含 FreeBSD 派生组件的具体范围在双库中无法验证 [存疑脚注]
- 文献：Sony 工程演讲存档（BSD 会议）；PS3 架构文档；openbsd.db 查询 L3.2.1（商业实体 commit 占比随时间变化，含 Sony @sony.com）；openbsd.db 查询 L3.2.2（商业实体 commit 量按仓库分布）；原材料/研究/bsd 仓库分析/数据分析/深层信息挖掘.md §L3.2.1、§L3.2.2。 ［A］
