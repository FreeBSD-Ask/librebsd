# 259.1 BSD 许可证的扩散机制（1988-1999）

- **要点**：BSD 许可证（1988 年 UCB 文本、1999 年 7 月删除广告条款后余 3 条款，2 条款版系后续社区简化）允许代码在保留版权声明前提下用于专有产品，使 BSD 成为网络设备与嵌入式系统的首选基底；此机制是 BSD 谱系扩散的法律根源。
- **BSD 许可证演变与谱系扩散机制表**：

| 年份 | BSD 许可证文本 | 关键变化 | 谱系扩散意义 |
| --- | --- | --- | --- |
| 1988 | UCB 文本 | 含广告条款 | — |
| 1999 | 3 条款文本 | 官方废止广告条款（1999-07-22） | 进一步降低专有再分发门槛 |

- 史料：BSD 许可证原始文本（1988/1999）、UC Berkeley REGENTS 声明、自由软件许可证比较文献；**bsd-derivatives.duckdb** 查询 L1.1.1 显示：7 个衍生仓库（ghostbsd-src、hardenedbsd-src、midnightbsd-mports、midnightbsd-src、opnsense-core、pfsense-src、truenas-middleware）年度 commit 量时间序列共 150 个年度数据点，各仓覆盖自 1985、1993、2006、2014 年起至 2026 年不等；2006 年（MidnightBSD）与 2014 年（OPNsense、pfSense）新仓库数据点的出现可印证 2005 年后社区扩张信号，原表述“2020 年前后 trueos-src 骤降”未获当前库支持（存疑：trueos-src 不在 bsd-derivatives.duckdb 现存 7 仓之列，该骤降信号待考）［A］
- 史观：总纲第 13 条——法律与道德是利益分配：许可证直接决定代码扩散形态；统计结论印证：C-54（跨仓库 Spearman 相关分析 ghostbsd-src ~ pfsense-src rho = 0.9355 p = 9.154e-184）反映 BSD 衍生项目在 commit 时间序列上存在强正相关，体现 BSD 许可证扩散下衍生谱系的工程节奏同源性——多个 fork 项目同步跟随 FreeBSD 上游的发布周期与安全公告节奏，0 信任原则适用：Spearman 秩相关仅反映时间序列共动性，不等于因果关联，且强相关可能由共同的上游 FreeBSD 同步行为驱动而非 fork 间的直接工程影响［存疑脚注：rho = 0.9355、p = 9.154e-184 的显著性量级与年度序列样本规模（约 33 年）不匹配，待复核统计口径］
- 辨析：BSD 许可与 GPL 的“扩散哲学”差异（最大化再使用 vs 最大化自由回馈）须客观论述，避免价值优劣判断；**bsd-derivatives.duckdb** 查询 L1.1.1 的 commit 量仅反映开发活跃度，须结合 commit 规模（additions/deletions）与 message 质量综合判断，且 GitHub 镜像仓库 commit 量可能滞后于主仓，衍生项目时间序列的“分化”判断须与各项目公告、邮件列表交叉验证
- 文献：BSD 许可证文本；相关许可证哲学文献；**bsd-derivatives.duckdb** 查询 L1.1.1（7 个 BSD 衍生项目 1993-2026 年每年 commit 量时间序列；2026-09-11 整改：所涉 7 仓库实存于 bsd-derivatives.duckdb，原“freebsd.duckdb”归属按库实况校正）；**research_notes.duckdb** 宏观趋势统计记录（原“原材料/研究/bsd 仓库分析/数据分析/宏观趋势统计.md”路径已失效，2026-09-11 整改改指）。［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］
