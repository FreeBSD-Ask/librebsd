# 259.3 与同时期操作系统的比较

- 要点：对比 Linux 衍生谱系（Android、各发行版）与 BSD 衍生谱系，二者扩散机制（GPL vs BSD 许可）与产品形态（开源生态 vs 嵌入专有）根本不同。
- 史料：各 OS 许可证与产品文献。［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］〔L3 官方文档与公告〕
- 史观：总纲第 6 条。
- 辨析：BSD 衍生谱系（JunOS/PlayStation/TrueNAS/pfSense 等嵌入式专有产品为主）与 Linux 衍生谱系（Android/Ubuntu/RHEL 等开源生态为主）在三维度存在根本差异——(1) 扩散机制：BSD 许可证允许闭源使用不要求回馈，厂商可基于 FreeBSD 构建专有产品而不公开改动（如 JunOS、PlayStation OS、NetScaler）；GPL 强制开源衍生作品，厂商基于 Linux 构建产品须公开源码（如 Android 基于 Linux 内核须开源 kernel 改动，但允许厂商在用户态保留专有）；(2) 产品形态：BSD 衍生以嵌入式专有产品为主（路由器、游戏主机、存储设备、ADC），开源发行版为辅（FreeNAS/TrueNAS、pfSense/OPNsense、GhostBSD 等桌面/服务器发行版）；Linux 衍生以开源发行版为主（Android、Ubuntu、RHEL、Debian），嵌入式专有产品为辅（多为厂商定制内核 + 用户态专有）；(3) 商业生态：BSD 衍生由厂商主导（Juniper、Sony、iXsystems、Netgate、Deciso），社区发行版依赖商业公司工程投入；Linux 衍生由发行版主导（Red Hat、Canonical、SUSE），厂商通过发行版间接影响上游；两谱系的差异根源在许可证哲学——BSD “宽松自由” 允许商业封闭，GPL “强制自由” 要求开源回馈，差异不构成 BSD 或 Linux 任一方的 “优势” 或 “劣势”，而是不同形式主义选择的历史呈现。
