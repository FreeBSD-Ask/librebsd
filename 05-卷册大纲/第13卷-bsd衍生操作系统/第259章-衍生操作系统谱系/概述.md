# 第 258 章 衍生操作系统的谱系：BSD 许可证的扩散力

### 核心内容

本章为第十卷总览章，论述 BSD 许可证（宽松、允许专有再分发）如何将 BSD 代码扩散至庞大的衍生操作系统谱系——从网络设备（JunOS）、游戏主机（PlayStation OS）、存储系统（TrueNAS/Isilon/NetApp）、防火墙（pfSense/OPNsense）、内容网络（Netflix Open Connect）到桌面 BSD（GhostBSD/PC-BSD）。谱系的核心驱动力是 BSD 许可的 “可嵌入专有产品” 特性，区别于 GPL 的 copyleft。
