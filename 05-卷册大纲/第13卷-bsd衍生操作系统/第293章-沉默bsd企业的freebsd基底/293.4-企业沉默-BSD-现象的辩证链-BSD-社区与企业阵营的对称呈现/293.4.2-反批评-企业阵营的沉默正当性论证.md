# 293.4.2 反批评——企业阵营的沉默正当性论证

  - 要点：企业阵营的沉默正当性论证沿四条线索展开——（1）BSD 总纲第 13 条——法律与道德是利益分配（原“许可证”系伪名目，按许可证利益论旨重挂）的法律权利行使：BSD 总纲第 13 条——法律与道德是利益分配（原“许可证”系伪名目，按许可证利益论旨重挂）明确允许闭源使用而不要求回馈，企业以 FreeBSD 为基础设施构建商业产品是 BSD 总纲第 13 条——法律与道德是利益分配（原“许可证”系伪名目，按许可证利益论旨重挂）法律权利的合法行使，非道德义务的违反——BSD 总纲第 13 条——法律与道德是利益分配（原“许可证”系伪名目，按许可证利益论旨重挂）的“允许不回馈”是 Berkeley CSRG 与 FreeBSD 项目自觉选择的结果，企业行使这一权利是 BSD 哲学“宽松自由”的具体显现，非“结构性利用”；（2）商业竞争与信息披露的合理性：企业在竞争性市场中须保护商业机密与技术细节，WhatsApp 不公开 FreeBSD 调优细节、NetApp 不公开 ONTAP 与 BSD 网络栈的具体关系、Citrix 不公开 NetScaler 与 FreeBSD 的代码改动，是商业竞争驱动的合理信息披露策略——“沉默”不等于“遮蔽”，而是商业机密保护的必要措施；（3）内部 fork 维护的工程合理性：企业基于 FreeBSD 构建商业产品时通常维护内部 fork 而非直接推送上游——NetApp ONTAP 的 BSD 网络栈经 NetApp 内部长期定制已与 FreeBSD 上游差异显著，Isilon OneFS 的 FreeBSD 基底经 Isilon 内部长期演进已形成独立分支，直接推送上游可能涉及商业机密披露与工程成本，“内部 fork 维护”是工程合理性而非“不回馈”；（4）间接回馈的存在：企业虽不直接推送 freebsd-src 上游 commit，但通过 FreeBSD Foundation 赞助、工程会议参与、员工个人贡献（使用 @freebsd.org 或个人邮箱）等方式间接回馈——WhatsApp 工程师在 Erlang Factory 等会议分享 FreeBSD 调优经验，NetApp 与 Isilon 工程师参与 FreeBSD Foundation 技术咨询，这些间接回馈虽不体现在 freebsd.duckdb L7.2.1 的前 30 名贡献者统计中，但构成企业对 FreeBSD 生态的实际贡献
