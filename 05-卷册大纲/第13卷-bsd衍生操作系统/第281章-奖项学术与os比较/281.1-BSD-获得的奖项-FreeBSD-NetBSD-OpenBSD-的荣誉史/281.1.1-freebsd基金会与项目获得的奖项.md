# 281.1.1 FreeBSD 基金会与项目获得的奖项

  - 要点：FreeBSD 基金会与 FreeBSD 项目历年获得的奖项与资助包括——2007 年与 2012 年，iXsystems 出品的 **FreeNAS** 两次获 InfoWorld Bossie Award（2007 年最佳开源 NAS 服务器、2012 年最佳开源数据中心与云软件；Bossie 系产品奖，授予 FreeNAS 而非组织）；2024 年 8 月 26 日 FreeBSD Foundation 获得 Sovereign Tech Fund 资助 **€686,400**（经 2026-07-22 联网核查 FreeBSD Foundation 官方博客 <https://freebsdfoundation.org/blog/sovereign-tech-fund-to-invest-e686400-in-freebsd-infrastructure-modernization/> ，由德国 BMWK 资助、SPRIND 托管，专项用于 5 个关键项目：Zero Trust Builds、CI/CD Automation、Reduce Technical Debt、Security Controls、SBOM Improvements）。FreeBSD 项目的奖项多来自开源社区与企业奖项，缺乏与 ACM 颁发的 Grace Murray Hopper Award（授予个人）等同等级别的学术奖项。
  - **FreeBSD 基金会与项目历年奖项时间线表**：

| 年份 | 奖项/资助 | 颁发机构 |
| --- | --- | --- |
| 2007/2012 | InfoWorld Bossie Award（**FreeNAS**：2007 最佳开源 NAS 服务器；2012 最佳开源数据中心与云软件） | InfoWorld（产品奖，授予 FreeNAS） |
| 2024-08-26 | Sovereign Tech Fund 资助 €686,400 | 德国 BMWK 资助、SPRIND 托管 |

- **Sovereign Tech Fund 2024 年 FreeBSD 资助五个关键项目表**：

| 项目 | 内容 |
| --- | --- |
| Zero Trust Builds | 零信任构建 |
| CI/CD Automation | CI/CD 自动化 |
| Reduce Technical Debt | 减少技术债务 |
| Security Controls | 安全控制 |
| SBOM Improvements | SBOM 改进 |
