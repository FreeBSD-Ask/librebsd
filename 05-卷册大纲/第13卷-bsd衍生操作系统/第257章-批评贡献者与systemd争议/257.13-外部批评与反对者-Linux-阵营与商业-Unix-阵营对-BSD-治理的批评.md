# 257.13 外部批评与反对者——Linux 阵营与商业 Unix 阵营对 BSD 治理的批评

## 257.13.1 Linux 阵营对 BSD 治理的批评
  - 要点：Linux 阵营对 BSD 治理的批评主要包括——其一，BSD Core Team 选举制效率低下（决策缓慢，如 CVS→SVN→Git 迁移迟缓）；其二，BSD 社区小团体化严重，外部贡献者难获认可；其三，BSD 许可证允许商业零回馈，使 BSD 成为“大公司的免费午餐”；其四，BSD 在桌面市场失败，反映 BSD 工程哲学不适合现代桌面需求。这些批评在 LKML、Reddit r/linux、Hacker News 等平台反复出现，构成 Linux 阵营对 BSD 的长期话语压力。

## 257.13.2 商业 Unix 阵营对 BSD 治理的批评
  - 要点：商业 Unix 阵营（Oracle/Solaris、IBM/AIX、HP/HP-UX）对 BSD 治理的批评主要包括——其一，BSD 缺乏形式认证（UNIX 03/FIPS 140/Common Criteria），不适合企业合规需求；其二，BSD 商业支持薄弱（无与 Red Hat 同等级别的企业级支持）；其三，BSD 发布周期不稳定（FreeBSD 大版本间隔 2 年）。这些批评反映商业 Unix 阵营试图通过合规认证与企业支持门槛将 BSD 排除在企业市场之外的话语策略。

## 257.13.3 BSD 社区对 Linux 阵营的反向批评
