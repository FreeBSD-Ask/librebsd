# 257.13 外部批评与反对者——Linux 阵营与商业 Unix 阵营对 BSD 治理的批评

## 257.13.1 Linux 阵营对 BSD 治理的批评

## 257.13.2 商业 Unix 阵营对 BSD 治理的批评

- 要点：商业 Unix 阵营（Oracle/Solaris、IBM/AIX、HP/HP-UX）对 BSD 治理的批评主要包括——其一，BSD 缺乏形式认证（UNIX 03/FIPS 140/Common Criteria），不适合企业合规需求；其二，BSD 商业支持薄弱（无与 Red Hat 同等级别的企业级支持）；其三，BSD 发布周期不稳定（FreeBSD 大版本间隔 2 年）。这些批评反映商业 Unix 阵营试图通过合规认证与企业支持门槛将 BSD 排除在企业市场之外的话语策略。

| 2 | BSD 商业支持薄弱 | 无与 Red Hat 同等级别的企业级支持 |

## 257.13.4 学术界对 BSD/Linux 治理的批评

## 257.13.5 外部批评的史观辨析：BSD/Linux 话语权争夺的形式主义

- 要点：BSD/Linux 话语权争夺是开源运动内部的阵营对立，其形式主义呈现——BSD 阵营与 Linux 阵营各自以对方为“他者”建构自身认同，BSD 阵营以“许可证哲学纯粹性”建构认同，Linux 阵营以“市场份额与商业成功”建构认同。话语权争夺的形式主义化使双方均难以客观评价对方——BSD 阵营低估 Linux 的工程效率，Linux 阵营低估 BSD 的哲学价值。形式主义批评的史观辨析须保留双方的实质内容，同时警惕话语权运作的形式主义化。
- **BSD/Linux 阵营认同建构与互相低估对照表**：

| 阵营 | 认同建构基础 | 对对方的低估 |
| --- | --- | --- |
| BSD 阵营 | 许可证哲学纯粹性 | 低估 Linux 的工程效率 |
| Linux 阵营 | 市场份额与商业成功 | 低估 BSD 的哲学价值 |

**史观**：总纲第 2 条——历史是形式主义化的非存在，BSD/Linux 对立作为形式主义操作，其“对立”在实质内容上常呈现非存在；总纲第 3 条——不存在进步，只有权力再分配，话语权争夺是权力运作的具体呈现

**辨析**：“对立”的话语建构须与双方实际存在的技术协作事实（如共同参与 POSIX 标准化、BSD 许可代码可并入 GPL 项目）对照检验；“用户文章”仅作话语样本留存，不作为可引证据，其论断须按 0 信任原则逐条考据后方可采用
