**史观**：

- 总纲4 分离聚合是永恒规律：Holt 解释为何不把改动回馈既有 BSD：立意之时 FreeBSD 的重心在服务器，正向 Sun 的 Niagara 平台推广 ports，终端用户不受重视；USB 设备拔出时机不当即致内核 panic 之类的易用性缺陷长期无人修补。MidnightBSD 与同期 PC-BSD、DesktopBSD 的涌现，是桌面需求在服务器导向的主项目中无处安放后向外分离的动作，分离之后 FreeBSD 才在 PC-BSD 带动下重新关注桌面。（BSDTalk EP126，[437.90-497.54]，L1）
- 总纲13 法律与道德是利益分配：Holt 的许可证立场直接塑造技术选型：自称个人偏好 BSD 许可证甚于其他一切，GNUstep 生态及流行图形库普遍采用 GPL 是其心中遗憾，因而考虑采用大部分代码为 BSD 许可的 Étoilé 桌面项目（基于 GNUstep 添加窗口管理器、外观近似 Mac OS X）作为默认环境——许可证的利益分配考量被置于图形环境的功能与美学之前。（BSDTalk EP126，[624.54-667.54]，L1）
- 总纲10 动手者创造历史：White 的叙述显示，商业移植的达成关键不在公司市场判断而在动手者：BSD 社区成员在 Wine 上游默默改进 BSD 专属代码，把移植成本从数周工程压缩为一个下午的编译，动手者的劳动改变了商业决策的成本结构，偶然的礼貌请求随之成为触发条件。（BSDTalk EP148，[849.36-915.44]，L1）
- 总纲4 分离聚合是永恒规律：bsdforums.org 的失效与管理员失联引发社群脱离旧载体、重组为 DaemonForums 的过程，显示 BSD 社区的交流载体并非稳态结构：旧的社区形式僵死后，人群分离并在新形式下重新聚合，社区存续依靠的是这种分离与聚合的循环而非某个固定平台。（BSDTalk EP155，[66.20-93.76]，L1）
- 总纲8 本体论上各方平等：他把自由与开源软件的意义归结为免于单一选择的支配：不仅体现在自由软件与专有软件之间的选择，也体现在各自由项目之间的选择；BSD 内部各项目哲学各异、各有所长，他希望这种多样性长存。用户依自身思维方式挑选系统，多样性本身构成生态价值。（BSDTalk EP158，[1020.98-1086.42]，L1）
- 总纲9 经验优先：受访者的全部论据来自自身长期操作经验而非厂商宣传：以视障者的实际使用流程（SSH、串口、屏幕阅读器）检验系统设计的实际可及性，正是把当事人一手经验置于判断中心的路径。（BSDTalk EP220，[509.34-543.22]，L1）
- 总纲10 动手者创造历史：家用防火墙这类长期运转的基础设施由普通动手者搭建：受访者以一台将被淘汰的旧 Athlon 主机承担全家封包路由与过滤，并在 VMware 宿主内以 OpenBSD 虚机做单盒防火墙实验；这类沉默的实践者及其技艺传承（从 Linux iptables 到 PF）构成基础设施史的真实底层。（BSDTalk EP220，[1030.56-1069.10]，L1）
- 总纲10 动手者创造历史：该软件的存续不取决于原公司的商业计划，而由论坛版主、志愿编译者与无薪酬维护者推动：项目没有支持团队，社区自任支持角色，“我们就是支持”；开源后的服务压力最初以注册门槛与论坛互助消化，呈现动手者而非决策者续写软件史的样本。（BSDTalk EP262，[866.56-891.92]，L1）
- 总纲13 法律与道德是利益分配：许可证与商业模式始终是利益分配的界面而非抽象信条：Fabio 以“不得出售”为开源让渡前提；早期 Linux 版免费但无支持、Mac 与 Windows 版收费约 175 美元；项目网站又以注册下载缓解 Reddit 曝光后的服务器冲击，Tex 自认此举“有点反 BSD 许可证”——开源实践在许可纯度与运营现实之间反复讨价还价。（BSDTalk EP262，[696.06-744.84]，L1）
- 总纲4 分离聚合是永恒规律：对 Linux 与 BSD 生态分化：受访者以 distrowatch 观察为据，估计 Linux 发行版达两三百至五百之谱，而 BSD 仅约十个且各自特化；他不同意 Eric Raymond 所谓 BSD 分叉更微妙的说法，认为分叉难易的落差正是 Linux 生态爆炸式扩张而 BSD 保持少数特化路线的结构性原因——分立与聚合的不同节奏塑造了两个阵营的形态。（BSDTalk EP43，[759.90-786.02]，L1）
- 总纲13 法律与道德是利益分配：许可与保护的政治经济学：项目早期用 GPL 后改 BSD，并改造四条款广告条款为宽松形态——交付所含本项目源码、或径以电邮告知作者使用事实即视为履约；其理据是不强令商业方公开自身代码，同时相信维护分叉的开销本身足以诱导回馈，回馈出于利益计算而非法律强制；他进一步主张源码防不住窃取——程序之智在算法而非原码，交出代码即已交出秘密，唯一防线是专利，而软件专利制度为最琐碎显然之物授权、窒息创新、只惠及拥有庞大法务预算的大公司。（BSDTalk EP44，[936.10-1074.88]，L1）
