# 280.3.4 NetBSD ABI 政策与 DragonFly BSD ABI 政策

  - 要点：NetBSD ABI 政策介于 FreeBSD 与 OpenBSD 之间——大版本内 ABI 稳定，跨大版本 ABI 不保证稳定，与 FreeBSD 类似；NetBSD 的特色是同架构跨版本的用户态二进制兼容与跨硬件平台的源码级可移植，这是 NetBSD 可移植性哲学的体现。DragonFly BSD ABI 政策由 Matt Dillon 个人主导，每个版本可破坏 ABI，与 OpenBSD 类似；DragonFly BSD 的 HAMMER 文件系统 ABI 在 HAMMER1→HAMMER2 转换时彻底改变，用户须迁移数据。
  - **NetBSD 与 DragonFly BSD ABI 政策对照表**：

| 项目 | 大版本内 ABI | 跨大版本 ABI | 特色 |
| --- | --- | --- | --- |
| NetBSD | 稳定 | 不保证稳定 | 同架构跨版本二进制兼容，跨平台源码级可移植（可移植性哲学） |
| DragonFly BSD | 每版本可破坏 | 每版本可破坏 | HAMMER1→HAMMER2 转换时彻底改变，用户须迁移数据 |
