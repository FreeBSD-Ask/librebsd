# 280.3.1 Linux 内核 ABI 稳定承诺：用户空间永不破坏

  - 要点：Linux 内核长期承诺“用户空间 ABI 永不破坏”（we don't break userspace），即新内核版本必须能运行为旧内核编译的用户空间程序。这一承诺由 Linus Torvalds 个人坚持，成为 Linux 内核开发的核心原则之一。Linux 内核 ABI 稳定承诺的工程后果是——旧用户空间程序可在新内核上运行（向后兼容），但内核内部 API 可以频繁变化（内核模块须针对每个内核版本重新编译）。这一承诺使 Linux 在企业市场具有强竞争力——企业可升级内核而不必重新编译所有用户空间程序。
  - **Linus Torvalds“we don't break userspace”原则引文**：

> We don't break userspace.
>
> ——Linus Torvalds，LKML 多次发言

- **Linux 内核 ABI 稳定承诺工程后果表**：

| 维度 | 内容 |
| --- | --- |
| 用户空间 ABI | 跨版本稳定（向后兼容） |
| 内核内部 API | 频繁变化（内核模块须重新编译） |
| 企业市场竞争力 | 强（升级内核不必重新编译用户空间） |
| 技术债务 | 累积（旧 ABI 不能移除） |
