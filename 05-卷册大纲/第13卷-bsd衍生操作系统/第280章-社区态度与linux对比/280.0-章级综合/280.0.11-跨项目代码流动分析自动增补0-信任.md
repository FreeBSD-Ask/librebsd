> 来源：各 git 仓库库 `commit_files` 表的 DISTINCT `file_path` 集合。
> 方法：多库 ATTACH + SQL `INTERSECT` 计算项目间共享路径；“重叠率”以较小库路径总数为分母；
> 子系统移植以关键字（zfs/openssh/llvm/clang/dtrace/pf/hammer/geom/capsicum）匹配 DISTINCT 路径计数。
> 局限：仅按路径字面匹配，未做内容哈希；不同项目的路径命名惯例差异会低估真实代码流动（如 ZFS 在 illumos 与 FreeBSD 路径不同）。
