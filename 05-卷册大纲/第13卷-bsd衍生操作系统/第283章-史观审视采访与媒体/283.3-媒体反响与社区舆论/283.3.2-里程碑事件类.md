# 283.3.2 里程碑事件类

### 新闻条目 1

- **新闻标题（中英）**：PC-BSD 8.0 Released For A Polished, Friendlier FreeBSD Desktop（PC-BSD 8.0 发布：打磨更友好的 FreeBSD 桌面）
- **新闻来源**：Phoronix + Michael Larabel + 2010-02-23 + <https://www.phoronix.com/review/pcbsd_8> + 存档 <https://web.archive.org/web/2010/https://www.phoronix.com/review/pcbsd_8>
- **新闻摘要**：PC-BSD 8.0（代号 Hubble Edition）基于 FreeBSD 8.0-RELEASE-P2，于 2010-02-22 发布，引入新版图形化 SysInstaller、LiveDVD 模式、NVIDIA x86_64 专有驱动的 3D 加速支持，默认搭载 KDE 4.3.5 桌面环境。Phoronix 评测认为其安装过程顺利、桌面体验良好。
- **与本章主题的关联说明**：PC-BSD 8.0 是 iXsystems 收购后首批重大版本之一，体现了该项目 “图形化桌面 FreeBSD” 的核心定位，对应本章 PC-BSD 黄金期叙事。
- **与官方史料的交叉验证结论**：Phoronix 报道的发布日期 2010-02-22 与 PC-BSD 官方公告一致；KDE 4.3.5、FreeBSD 8.0-RELEASE-P2 等版本号与 PC-BSD 官方发行说明吻合。媒体报道与官方史料一致。

### 新闻条目 2

- **新闻标题（中英）**：PC-BSD-Renamed TrueOS To Use LibreSSL, Linux DRM 4.7 Compatibility（改名后的 TrueOS 将采用 LibreSSL 与 Linux DRM 4.7 兼容层）
- **新闻来源**：Phoronix + Michael Larabel + 2016-09-01 + <https://www.phoronix.com/news/TrueOS-LibreSSL-DRM-4.7> + 存档 <https://web.archive.org/web/2016/https://www.phoronix.com/news/TrueOS-LibreSSL-DRM-4.7>
- **新闻摘要**：改名后的 TrueOS 宣布采用 OpenBSD 的 LibreSSL 替换 OpenSSL，并引入 Linux DRM 4.7 兼容层以改善图形驱动支持。这一技术栈调整体现 TrueOS 在改名的同时强化安全与图形能力的双重方向。
- **与本章主题的关联说明**：技术细节补充改名事件，说明 TrueOS 改名不仅是市场行为，也是技术路线调整。
- **与官方史料的交叉验证结论**：LibreSSL 与 DRM 4.7 兼容层在 TrueOS 17.12 发行说明中得到印证，与官方史料一致。

### 新闻条目 3

- **新闻标题（中英）**：It's Official But Sad: TrueOS Is Over As Once The Best Desktop BSD OS（不幸正式宣告：曾经最佳桌面 BSD 的 TrueOS 终结）
- **新闻来源**：Phoronix + Michael Larabel + 2020-03-28 + <https://www.phoronix.com/news/No-More-TrueOS> + 存档 <https://web.archive.org/web/2020/https://www.phoronix.com/news/No-More-TrueOS>
- **新闻摘要**：iXsystems 工程副总裁 Kris Moore（克里斯·摩尔） 在官方论坛确认 TrueOS 已无活跃开发，最后提交为 2020-01 初；Moore 表示过去 2-3 年 TrueOS 已沦为 iX 员工的 “个人激情项目”，团队全力转向 TrueNAS CORE/Enterprise，加之社区需求不足，故项目实质性终结。文章回顾 TrueOS/PC-BSD 自 2006 年以来作为最佳 BSD 桌面体验的历史地位。
- **与本章主题的关联说明**：本章关键终点——TrueOS 终止开发——的核心英文媒体报道，与官方论坛声明交叉验证。
- **与官方史料的交叉验证结论**：Phoronix 引用 iXsystems 社区论坛 Kris Moore 的两段原话（post-574390 与 post-574498），与官方史料一致。文中提及 TrueNAS 12.0 CORE 与 FreeNAS 合并事项亦与官方公告相符。

### 新闻条目 4

- **新闻标题（中英）**：Project Trident Switching From TrueOS/FreeBSD Distribution To Basing On Void Linux（Project Trident 从 TrueOS/FreeBSD 切换至基于 Void Linux）
- **新闻来源**：Phoronix + Michael Larabel + 2019-10-15 + <https://www.phoronix.com/news/Project-Trident-Void-Linux> + 存档 <https://web.archive.org/web/2019/https://www.phoronix.com/news/Project-Trident-Void-Linux>
- **新闻摘要**：Project Trident 宣布放弃 FreeBSD/TrueOS 基础，改以 Void Linux 作为新基础。这是 TrueOS 生态崩塌的早期信号，反映 FreeBSD 桌面分支在硬件兼容、驱动支持方面的长期困境。
- **与本章主题的关联说明**：TrueOS 桌面遗产的接续者 Project Trident 转向 Linux，是 TrueOS 终结叙事的前奏。
- **与官方史料的交叉验证结论**：与 project-trident.org 官方博客公告一致。

### 新闻条目 5

- **新闻标题（中英）**：Void-Linux-Powered Project Trident To Cease Operations（基于 Void Linux 的 Project Trident 终止运营）
- **新闻来源**：Phoronix + Michael Larabel + 2021-10-30 + <https://www.phoronix.com/news/Project-Trident-No-More> + 存档 <https://web.archive.org/web/2021/https://www.phoronix.com/news/Project-Trident-No-More>

- **与本章主题的关联说明**：本章 PC-BSD/TrueOS 桌面谱系的最终尾声，对应章节尾部叙事。
- **与官方史料的交叉验证结论**：与 Project Trident 官方公告一致。
