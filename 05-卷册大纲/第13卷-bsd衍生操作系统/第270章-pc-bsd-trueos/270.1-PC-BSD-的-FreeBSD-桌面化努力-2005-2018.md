# 270.1 PC-BSD 的 FreeBSD 桌面化努力（2005-2018）

## 269.1.1 开箱即用桌面 BSD 的尝试
  - 要点：PC-BSD（2005）由 Kris Moore（克里斯·摩尔） 发起，提供图形安装器、PBI 软件包系统、预配置桌面，目标是 “开箱即用 FreeBSD 桌面”；其存在反映社区对消费桌面的长期诉求。
  - **trueos-src 仓库 commit 量时间序列表（L1.1.1，2006-2017）**：

| 年份 | total_commits | merge_commits | merge 比例 |
| --- | --- | --- | --- |
| 2006 | 11,119 | 87 | 0.8% |
| 2010 | 9,695 | 112 | 1.2% |
| 2015 | 14,515 | 254 | 1.7% |
| 2016 | 18,601 | 393 | 2.1%（峰值） |
| 2017 | 10,724 | 287 | 2.7% |

- 史料：PC-BSD 项目档案、Kris Moore 公开资料、FreeBSD 桌面文档；freebsd.db 查询 L1.1.1 显示：trueos-src 仓库 2005-2020 年每年 commit 量时间序列，2006 年 total_commits = 11,119（merge_commits = 87, 0.8%）、2010 年 9,695（112, 1.2%）、2015 年 14,515（254, 1.7%）、2016 年 18,601（393, 2.1%，峰值）、2017 年 10,724（287, 2.7%），commit 量在 2016 年达峰后呈下降趋势，merge commit 比例从 2006 年 0.8% 上升至 2017 年 2.7% 反映 PC-BSD→TrueOS 转型期间与上游 FreeBSD 同步节奏的变化[考据完成：2026-07-28 经穷尽联网考据，上述史料清单为已知公开来源汇总，部分原始档案未公开数字化或须档案馆藏地现场核验，属史料缺口，须待原始档案公开后方可补充确证]
- 史观：总纲第 2 条——实践先于理论，直接构建而非等待上游；统计结论印证：C-54（trueos-src 仓库 commit 量趋势 L1.1.1）显示 trueos-src 2006 年 total_commits = 11,119 → 2016 年 18,601（峰值）→ 2020 年 154，commit 量在 2016 年达峰后骤降，反映 PC-BSD 10.x 高峰期至 TrueOS 转型的工程节奏变化，0 信任原则适用：commit 量仅反映开发活跃度，须结合 commit 规模（additions/deletions）与 message 质量综合判断，且 GitHub 镜像仓库 commit 量可能滞后于主仓
- 辨析：PC-BSD 各版本对应 FreeBSD 基底须以项目 Release Notes 核实；freebsd.db 查询 L1.1.1 的 commit 量仅反映开发活跃度，须结合 commit 规模（additions/deletions）与 message 质量综合判断，且 GitHub 镜像仓库 commit 量可能滞后于主仓，trueos-src 仓库 2016 年的 commit 量峰值须与 PC-BSD 10.x 发布记录、iXsystems 商业投入说明交叉验证[双库验证 2026-08-15] PC-BSD 由 Kris Moore 于 2005 年发起经邮件列表库（freebsd 2008 年 "Printable PC-BSD labels?" 讨论、2021 年 Quarterly Status Report 提及 Kris Moore）与参考文献库确认；PC-BSD 2017 年 8 月更名为 TrueOS 的精确月份在双库中无法直接验证 [存疑脚注]
- 文献：PC-BSD 官方文档；freebsd.db 查询 L1.1.1（trueos-src 仓库 2005-2020 年每年 commit 量时间序列）；原材料/研究/bsd 仓库分析/数据分析/宏观趋势统计.md §L1.1.1。 ［B］
