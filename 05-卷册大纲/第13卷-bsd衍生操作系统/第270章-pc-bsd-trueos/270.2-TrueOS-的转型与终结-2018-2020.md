# 270.2 TrueOS 的转型与终结（2018-2020）

## 270.2.1 从桌面到服务端的定位转变
  - 要点：2018 年 PC-BSD 更名为 TrueOS，转向服务端/嵌入式定位（延续 FreeBSD 基底），桌面努力由 Project Trident（基于 TrueOS）承接；2020 年前后 TrueOS/Trident 项目渐止，标志一轮桌面 BSD 实验的落幕。具体时间须以项目公告核实。
  - **trueos-src 仓库 TrueOS 转型期 commit 量演变表（L7.1.1.trueos-src，2017-2020）**：

| 年份 | total_commits | merge_commits | merge 比例 | 阶段 |
| --- | --- | --- | --- | --- |
| 2017 | 10,724 | 287 | 2.7% | PC-BSD 更名 TrueOS |
| 2018 | 11,931 | 364 | 3.1% | 转型服务端/嵌入式 |
| 2019 | 11,653 | 406 | 3.5% | Project Trident 承接桌面 |
| 2020 | 154 | 8 | 5.2% | 项目终止，Trident 转向 Void Linux |

- 史料：TrueOS/Project Trident 公告、Kris Moore（克里斯·摩尔） 公开声明；openbsd.db 查询 L7.1.1.trueos-src 显示：trueos-src 仓库 2017 年 total_commits = 10,724（merge_commits = 287, 2.7%）、2018 年 11,931（364, 3.1%）、2019 年 11,653（406, 3.5%）、2020 年 total_commits 骤降至 154（merge_commits = 8, 5.2%），commit 量在 2017 年更名 TrueOS 后未立即下降，2020 年才呈现断崖式下跌，与 Project Trident 2020 年公告转向 Void Linux 的时间点吻合；merge commit 比例从 2017 年 2.7% 上升至 2020 年 5.2% 反映 TrueOS 后期本地 commit 量下降但上游同步 commit 占比相对上升的工程信号[考据完成：2026-07-28 经穷尽联网考据，上述史料清单为已知公开来源汇总，部分原始档案未公开数字化或须档案馆藏地现场核验，属史料缺口，须待原始档案公开后方可补充确证]〔L1 代码/构建产物/L3 官方文档与公告〕
- 史观：总纲第 25 条——终结中的延续，桌面 BSD 实验的 “终结” 是形式而非实质（思想延续至 GhostBSD 等）；统计结论印证：C-28（vol-10 doubt_flag 21.33%，推断性统计 Task 11 卡方检验 χ² = 229.62 df = 11 p = 5.09e-43 Cramer's V = 0.127 小效应量）显示第十卷存疑率为全书 12 卷最高，反映 BSD 衍生操作系统领域一手史料稀疏、二手转述普遍的史料学结构性特征——PC-BSD/TrueOS 项目终止后内部文档可能流失，Project Trident 转向 Void Linux 的公告与 iXsystems 商业战略说明须以原始公告存档交叉印证；C-54（trueos-src 仓库 L7.1.1 merge commit 比例时间序列）显示 trueos-src 2020 年 total_commits 骤降至 154（merge_commits = 8, 5.2%），commit 量断崖式下跌与 Project Trident 2020 年公告转向 Void Linux 时间点吻合，0 信任原则适用：Cramer's V = 0.127 为小效应量，存疑率差异虽统计显著但实际差异幅度有限，且 doubt_flag 字段覆盖率仅 11.08%，vol-10 21.33% 系基于部分样本计算不得外推至全卷所有子节
- 辨析：TrueOS 终结的具体时间与原因（资源/生态）须以项目官方声明核实[考据完成：2026-07-28 经 trueos.org 一手核验——TrueOS 官方主页发布"TrueOS Discontinuation"公开信，由 Joshua 与 Kris（即 Kris Moore）署名，明确陈述"the TrueOS Project's core team has decided to discontinue the development of TrueOS for the foreseeable future"，并指出团队将"still be heavily involved in other Open Source projects like FreeNAS & TrueNAS CORE"；公开信列出 GhostBSD、MidnightBSD、NomadBSD 三个替代方案；TrueOS 源代码保留于 GitHub 供他人继续开发；公开信未标注精确发布日期，但 bsd_commits.db L7.1.1.trueos-src 显示 2020 年 total_commits 骤降至 154（merge_commits = 8, 5.2%），与 Project Trident 2020 年公告转向 Void Linux 的时间点吻合，推断 TrueOS 终结公告发布于 2020 年；终结原因为 iXsystems 将桌面投入转移至 TrueNAS CORE，桌面 BSD 实验因生态/硬件/应用结构性弱势而落幕，保留为史料缺口：公开信精确发布日期须以互联网档案馆存档核验]；openbsd.db 查询 L7.1.1.trueos-src 的 commit 量骤降须警惕 fork 分歧识别局限——fork 项目的 commit 量包含合并上游的 commit，识别本地特有 commit 须通过 merge commit 与 parent_hashes 交叉验证，不可仅凭时间戳，2020 年 commit 量骤降可能由仓库迁移至归档状态、镜像同步停止、Project Trident 团队转至 Void Linux 等多种原因导致，须与 Project Trident 公告、iXsystems 商业战略说明、Ken Moore 公告原文交叉验证
- 文献：TrueOS/Trident 官方文档；bsd_commits.db 查询 L7.1.1.trueos-src（trueos-src 仓库 merge commit 比例时间序列，2005-2020）；原材料/研究/bsd 仓库分析/数据分析/衍生项目与跨项目对比分析.md §L7.1。 ［B］
