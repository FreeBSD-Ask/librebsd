# 第 256 章 奖项学术与os比较

## 要点

- FreeBSD 基金会与 FreeBSD 项目历年获得的奖项包括——2005 年 OSCON 开源奖项（Open Source Award）；2014 年 iXsystems 与 FreeBSD Foundation 获得的 InfoWorld Bossie Awards（最佳开源存储与服务器）；2019 年 FreeBSD Foundation 获得 Sovereign Tech Fund 资助
- NetBSD 项目获得的奖项包括——2006 年 NetBSD 3.0 获得 OSNews 评选的最佳开源操作系统提名；2010 年 NetBSD 5.1 获得 Slashdot 评选的最佳服务器操作系统提名；NetBSD 的可移植性纪录（运行于 50+ 硬件平台）曾获吉尼斯世界纪录认证。NetBSD 项目的奖项相对较少，反映其在主流市场的边缘地位。
- OpenBSD 项目获得的奖项包括——2004 年 OpenSSH 获得 USENIX STUG Award（Software Tools User Group Award）；OpenBSD 的安全审计方法论多次被信息安全社区表彰；OpenSSH 作为全球 SSH 事实标准，间接为 OpenBSD 项目带来声誉。OpenBSD 项目的奖项相对较少，Theo de Raadt（西奥·德·若特） 个人
- CSRG 时期 BSD 获得的奖项（1980-1990 年代学术与工业界的若干提名与共享声誉）在 BSD 整体奖项谱系中具有承前启后的位置——承前于 CSRG 作为伯克利学术研究小组在系统研究社区的学术声誉，启后于 CSRG 解散后 FreeBSD/NetBSD/OpenBSD 各项目独立发展后的现代奖项谱系。CSRG 时期奖项的形式主义辨析须注意——奖项作为学术与工业界的认可形式，其“认可”在
- BSD 奖项的辨析须避免两种极端——其一，以奖项数量判断项目价值（Linux 奖项多于 BSD 故 Linux 优于 BSD），其二，以反奖项姿态否定奖项价值（OpenBSD 反奖项故奖项无意义）。奖项作为形式主义操作，其“认可”在实质内容上既有真实成分（FreeBSD 获 Sovereign Tech Fund 资助反映其工程价值），也有形式主义成分（奖项的颁发常受政治与商业影响）。BSD 奖项
