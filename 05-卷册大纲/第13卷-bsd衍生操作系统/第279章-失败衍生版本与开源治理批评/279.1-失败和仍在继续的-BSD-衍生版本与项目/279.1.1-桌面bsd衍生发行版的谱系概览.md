# 279.1.1 桌面 BSD 衍生发行版的谱系概览

  - 要点：自 2000 年代起，以 FreeBSD/NetBSD/OpenBSD 为底座构建“开箱即用桌面 BSD”的尝试形成一条清晰的衍生发行版谱系——PC-BSD（**2005** 年由 **iXsystems** 推出，**2017** 年更名为 **TrueOS**，**2018** 年转向 TrueOS Core 后停摆）、DesktopBSD（**2006** 年由 **Peter Hofer** 与 **Oliver Fromme** 等奥地利开发者发起，基于 FreeBSD 5.x/6.x，**2010** 年前后停滞）、FreeSBIE（**2004** 年意大利佛罗伦萨开源社区开发的 LiveCD BSD，基于 FreeBSD 5.x，**2007** 年后停止更新）、Frenzy（俄罗斯开发的 FreeBSD LiveCD，主要面向系统管理员应急修复，**2012** 年后停滞）、OliveBSD（基于 OpenBSD 的 LiveCD，**2005** 年发布后即停摆）、GhostBSD（**2010** 年由 **Eric Turgeon** 发起，基于 FreeBSD，**2020** 年后转向 TrueOS BASE 并在 **2023** 年转向 FreeBSD 13.x 直接派生，仍在挣扎维持）、MidnightBSD（**2007** 年由 **Philip Charles** 等开发者发起，基于 FreeBSD 6.x，定位桌面与小众服务器，至今仍在缓慢更新）、DragonFly BSD（**2003** 年 **Matt Dillon** fork FreeBSD 4.x，定位 SMP 与 HAMMER 文件系统，**2026** 年仍在维持但社区规模极小）。此谱系反映桌面 BSD 长期未能形成与 Ubuntu/Fedora/openSUSE 同等竞争力的桌面发行版生态，但其挣扎史本身是 BSD 哲学在桌面维度反复试错的真实记录。
  - **桌面 BSD 衍生发行版谱系表**：

- 史料：Distrowatch 各 BSD 衍生发行版页面历史快照；PC-BSD 1.0 至 TrueOS 18.x 发布公告档案；DesktopBSD 项目网站互联网档案馆存档；FreeSBIE SourceForge 项目档案；GhostBSD 官方公告与 Eric Turgeon 邮件列表发言；MidnightBSD 项目档案与 Philip Charles 邮件；DragonFly BSD announce 邮件列表；`bsd_commits.duckdb` 查询 `L7.1.1.trueos-src` 显示：`trueos-src` 仓库 2006-2020 年每年 commit 量与 merge commit 比例时间序列，2019 年 `total_commits=11,653`（`merge_commits=406`，`non_merge_commits=11,247`），2020 年 `total_commits` 骤降至 154（`merge_commits=8`，`non_merge_commits=146`），commit 量在一年内下降约 98.7%，与 Project Trident 2020 年转向 Void Linux 的公告时间吻合 ［A］
- 史观：总纲第 11 条——分离与聚合，BSD 衍生发行版反复从 FreeBSD/NetBSD/OpenBSD 分离又试图聚合桌面生态，分离与聚合的循环呈现“形式主义化的非存在”；BSD 反向影响线，桌面 BSD 的反复失败反映 BSD 反向影响在桌面维度的断裂
- 辨析：各衍生发行版的发起时间、初始基线版本、停摆时间须以原始公告与邮件列表交叉核验，Distrowatch 的“年份”信息常被二手资料沿用但可能不准；“失败”的判断须区分“项目停止开发”与“项目转方向”（如 PC-BSD 改名 TrueOS 后转向，并非完全停摆），须避免简化叙事；GhostBSD 2023 年转向直接派生 FreeBSD 13.x 的决策须考据 Eric Turgeon 公告原文，避免误读为“放弃 TrueOS”；freebsd.duckdb 查询 L7.1.1.trueos-src 的 commit 量骤降仅反映仓库活动度，commit 量不等于项目质量，且 trueos-src 仓库 2020 年后的低活动可能源于镜像同步滞后或归档迁移，须与 Project Trident 公告、iXsystems 商业战略说明等多源交叉验证[双库验证 2026-08-15] PC-BSD 存在与活动经邮件列表库（freebsd 2008 年 “Printable PC-BSD labels?” 讨论）与参考文献库（BSDCan 2007 FreeNAS slides，vBSDCon 2017 iXsystems 相关论文）交叉印证；DesktopBSD 与 FreeSBIE 在双库中均无命中记录，发起人信息须以项目原始档案交叉验证 [存疑脚注]
