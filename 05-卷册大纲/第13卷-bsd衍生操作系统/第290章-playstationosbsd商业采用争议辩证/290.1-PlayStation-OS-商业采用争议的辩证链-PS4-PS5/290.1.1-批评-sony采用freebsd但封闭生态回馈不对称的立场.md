# 290.1.1 批评——Sony 采用 FreeBSD 但封闭生态、回馈不对称的立场


> 126.4 节已补足 PS3 OtherOS 移除争议（2010-2018）的四层辩证链，本节补足更广泛的 PlayStation OS 商业采用争议——Sony 采用 FreeBSD 作为 PS4/PS5 操作系统基底但维持封闭生态、Sony 对 FreeBSD 上游回馈程度不足、BSD 许可证允许 Sony 封闭化使用与 GPL 项目商业采用模式形成对比——的四层辩证链（批评—反批评—再批评—合图），确保 BSD/Linux 阵营与 Sony 阵营论点对称呈现。本节与 126.4 节的 OtherOS 移除争议形成层次分工：126.4 节聚焦 “已交付功能的撤回” 这一具体法律争议，本节聚焦 “采用 BSD 但封闭化使用与回馈不对称” 这一结构性争议。

  - 要点：从 BSD 社区与开源批评者视角，Sony 的 FreeBSD 商业采用存在三重结构性张力——（1）封闭生态与 BSD 许可证的 “开放” 预期落差：PS4（2013）的 Orbis OS 基于 FreeBSD 9.0、PS5（2020）的 Prospero OS 延续 FreeBSD 基底（FreeBSD Handbook 官方页面记载 “两个 PlayStation 3 和 PlayStation 4 游戏机运行在修改版的 FreeBSD 之上”），但 Sony 将 FreeBSD 封装为专有游戏主机操作系统，PS4/PS5 用户无法触及底层 FreeBSD 系统、无法自行安装第三方操作系统、无法运行未经 Sony 数字签名认证的代码——Sony 享受 BSD 许可证 “允许封闭使用” 的自由，但用户未享受 FreeBSD “开放” 的对应自由，“开放-封闭” 张力在 PS4/PS5 上比 PS3 OtherOS 时期更彻底（PS3 至少曾允许 OtherOS，PS4/PS5 自始即封闭）；（2）回馈不对称的代码级证据：freebsd.duckdb 查询显示，Sony 工程师（@sony.com、@am.sony.com、@jp.sony.com、@sonycom.com、@sonymobile.com、@sm.sony.co.jp、@hq.scei.sony.co.jp 等邮箱域名）在所统计的全部 BSD/Linux 仓库中共提交 1014 次 commit，但全部 1014 次均位于 linux-kernel 仓库，freebsd-src 仓库中未发现任何 @sony.com 或 @playstation 邮箱域名的 commit——Sony 工程师对 Linux 上游有持续回馈（如 @sonycom.com 的 Geert Uytterhoeven 197 次、@am.sony.com 的 Geoff Levand 152 次、@sonymobile.com 的 Bjorn Andersson 126 次、@sony.com 的 Frank Rowand 119 次、@sony.com 的 Yuezhang Mo 82 次均在 linux-kernel），但对 FreeBSD 上游的直接 commit 回馈为零（或未使用企业邮箱提交，无法在邮箱域名层面识别）；FreeBSD 对 PS3 的支持由 FreeBSD committer Nathan Whitehorn <nwhitehorn@FreeBSD.org> 于 2011-01-06 提交（commit `03479763b279`，"Import support for the Sony Playstation 3 using the OtherOS feature available on firmwares 3.15 and earlier."），PS4 DualShock 控制器驱动 ps4dshock 的触摸板修复由 FreeBSD committer Vladimir Kondratyev <wulf@FreeBSD.org> 于 2021-08-16 提交（commit `bb5eb85e5c01`，“ps4dshock(4): Fix touchpad width in HID report descriptor”）——PS3/PS4 的 FreeBSD 适配工作由 FreeBSD 社区完成，而非 Sony 工程师回馈；（3）BSD 许可证与 GPL 商业采用模式的对比：BSD 许可证允许 Sony 封闭化使用 FreeBSD 而无须公开 PS4/PS5 内核修改，与 GPL 许可证 “衍生作品须公开源代码” 的 copyleft 要求形成对比——若 Sony 基于 Linux 构建 PS4/PS5（如 Steam Deck 基于 Linux），则 Sony 须公开内核修改；Sony 选择 FreeBSD 而非 Linux 作为 PS4/PS5 基底，可论证其部分动机是规避 GPL 的 copyleft 义务，享受 BSD 许可证 “允许封闭” 的自由而无须对应回馈
  - **PlayStation OS 商业采用争议三重张力表**：

- 史观：总纲第 11 条——商品是形式主义：Sony 将 FreeBSD 封装为 PS4/PS5 专有操作系统是商品形式主义下 “劣币驱逐良币” 的显现——商业封装的 PS4/PS5 游戏生态获得 Sony 持续投入，FreeBSD “开放” 的传统在消费电子领域被商品形式主义运作封闭化；总纲第 8 条——本体论上各方平等：Sony 与 FreeBSD 社区在本体论上地位相等，但 Sony 的商业影响力使其封闭化使用获得高可见度，FreeBSD 社区的 “开放” 传统在 PS4/PS5 上被遮蔽
