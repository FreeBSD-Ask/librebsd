# 282.1.4 学术界对 BSD/Linux 治理的批评

- 要点：学术界对 BSD/Linux 治理的批评相对中立——开源治理研究文献（如 O'Mahony 2007、Kelty 2008）对 BSD 与 Linux 治理模式均有批评，认为两者均存在小团体化、绩优主义形式主义、外部贡献者排斥等问题。学术批评的价值在于超越阵营立场，对开源治理的根本问题进行结构性分析。
- **学术界对 BSD/Linux 治理的结构性问题分析表**：

| 结构性问题 | BSD 表现 | Linux 表现 | 学术文献 |
| --- | --- | --- | --- |
| 小团体化 | BSD Core Team 内圈 | Linux maintainer 体系 | O'Mahony 2007、Kelty 2008 |
| 绩优主义形式主义 | FreeBSD Core Team 选举门槛 | Linux maintainer 任命权 | Kelty 2008《Two Bits》 |
| 外部贡献者排斥 | BSD 各项目审查周期长 | Linux 层级 maintainer 筛选 | O'Mahony 2007 |
