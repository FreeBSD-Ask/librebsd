# 3.3.1 HAMMER 1.0 的设计与实现

**要点**：DragonFly 2.0（**2008-07-21**）发布 HAMMER 1.0 文件系统——Dillon 设计的 B-tree 写时复制文件系统，支持快照、历史记录、增量备份；HAMMER 1.0 是 DragonFly 默认文件系统，替代 UFS；HAMMER 设计哲学是 “轻量级写时复制”，避免 ZFS 的内存消耗与复杂度。dragonfly.duckdb dragonfly-src 仓库 `sys/vfs/hammer*` 路径 commit 演化显示 HAMMER 1.0 的工程实现集中爆发于 2008 年：

    | 年份 | 关联文件变更行数 | 文件数 | 阶段 |
    |---|---|---|---|
    | 2007 | 181 | 21 | 设计阶段 |
    | 2008 | 1,213 | 32 | HAMMER 1.0 随 2.0-RELEASE 发布（工程爆发） |
    | 2009 | 282 | 29 | 进入维护期 |
    同期 bus factor 显示 HAMMER 1.0 发布期社区短暂扩大但 bus factor 仍极低：
    | 年份 | top10 commit 占比 | 贡献者总数 |
    |---|---|---|
    | 2007 | 97.09% | 23 |
    | 2008 | 91.56% | 36（2.x 时代最高） |
    | 2009 | 86.93% | 36 |
