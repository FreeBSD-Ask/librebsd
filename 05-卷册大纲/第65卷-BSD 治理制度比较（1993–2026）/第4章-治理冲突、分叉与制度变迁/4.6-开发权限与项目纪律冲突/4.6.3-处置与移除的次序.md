**Mauro GitHub 源流论**：“该怪互联网基础设施不允许编辑已发邮件（八十年代 X.400 就允许）；CoC 无任何说 TAB 会处置 Developer A 的内容——唯一会被罚的是维护者；此 CoC 为 Github 而生——作者与维护者都有全权编辑/删除帖子、GitHub 背后有公司需要防诉讼、防止非法帖子的是项目所有者；用于邮件行不通（无法删除已发帖）、Bugzilla/Trac 不行（无人能编辑）、Mediawiki 不完全行（历史可见）；用此 CoC 要么修它、要么工作流改成只用 Github 类系统”。
