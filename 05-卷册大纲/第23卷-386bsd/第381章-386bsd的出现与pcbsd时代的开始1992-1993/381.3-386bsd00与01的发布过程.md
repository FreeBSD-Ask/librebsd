# 381.3 386BSD 0.0 与 0.1 的发布过程

## 381.3.1 版本时间线与发布口径

  **要点**：386BSD 0.0 于 1992 年 3 月首次公开发布（386BSD 0.0 Release Notes 落款期 1992 年 3 月 1-7 日；comp.unix.bsd Usenet 公告日 1992-03-12；另有 1992-03-17 说与 1992 年 2 月说并存，两说并陈勿单取）；0.0 基于 Net/2 自由部分加自写缺失代码，经 Dr. Dobb's Journal 配套渠道传播；0.1 于 1992-07-14（巴士底日）发布，可用性显著提高并含“Tiny 386BSD”安装器；0.1 发布后自其 FTP 服务器获得 250,000 次下载（1992 年拨号上网时代的天文数字）；0.1 之后官方更新停滞，无 0.2 系列的 Jolitz 官方公开版本（0.2 之辨见辨析）；版本时间线如下：
  
| 版本 | 发布时间 | 备注 |
| -- | ------ | -- |
| 386BSD 0.0 | 1992-03（公告 1992-03-12；另有 03-17／2 月说） | 首个公开版本，DDJ 配套传播 |
| 386BSD 0.1 | 1992-07-14 | 巴士底日发布，250,000 次 FTP 下载 |
| patchkit 0.2.2～0.2.4 | 1993 | 社区非官方补丁集（非 Jolitz 官方版本） |
| 386BSD 1.0 | 1994 年末 | DDJ CD-ROM 独家发行，全新内核设计 |
| 386BSD 2.0 | 2016-08-05 | Ben Jolitz 于 GitHub 更新 |

**史观**：
- 总纲第 5 条——没有必然性，只有偶然性：0.1 的发布日期（巴士底日）与传播峰值皆为偶然叠加，250,000 次下载不由任何计划保证
- 总纲第 9 条——经验优先：下载量是可核的传播证据，优于任何“广受欢迎”的概括表述
- 总纲第 19 条——解释学循环：公告日（03-12）与文档落款期（3 月 1-7 日）两重时间口径互相校准，不互相取代
- 总纲第 4 条——分离聚合是永恒规律：0.1 作为 FreeBSD 与 NetBSD 共同的 import 基线，是“一次发布、两支聚合”的物质证据
- 总纲第 23 条——一切历史写作都是基于哲学设定的历史小说：本节版本表是编纂者的秩序化重构，非 1992 年当事人自我意识中的版本史
  
**辨析**：0.0 发布日期三说并存——1992-03-12（Usenet 公告与多数条目 infobox）、1992-03-17（gunkies 等）、1992 年 2 月（目录页复核标注两说之一），并陈勿单取；0.2 版本之有无——gunkies 称存在 ISO-9660 与 Rock Ridge 更新版“0.2”（见 DrDobbs July 1993），而既有磁盘考据（第 62 章 62.1.3）经 NetBSD 官方时间线、FreeBSD 官方历史与 Release Notes 三方交叉确认不存在公开 0.2，“0.2”可能为 patchkit 累积版误称，两说并存待源码与 DDJ 原刊复核；下游 import commit（1993-03／1993-06）晚于原始发布约 8-11 个月，为二次 import，不得作为发布日证据
