# 3.11.1 按分支全量存档的署名消息头

<!-- DOC_MINE: ref10664#1 -->
**官方文档**（证据等级：L3，来源：`historical_claims.duckdb.claim.CL-C`；supp-V75-b032 2026-11-20）

FreeBSD Committer's Guide 记载：FreeBSD 有数百名活跃开发者与横跨数十年历史的数十万条提交；每条提交可在消息尾部附一行或多行结构化元数据行（关键词或短语＋冒号＋制表符＋补充信息），署名等元数据以字段行形式随提交持续留存。 引文出处：FreeBSD Project. FreeBSD Committer's Guide[EB/OL].
