# 1.1.4 标准符合性作为类 UNIX 判据

<!-- ROW_MINE: fb-2637035 -->`
- 【Linux社区】2002年2月 Michael Lucas(mwlucas@blackhelicopters.org) 在“Re: valgrind”串中反驳称许可证并非绝对阻碍，指出“GPL'd code can swallow BSDL'd code”的非对称性作为BSD与GPL互操作的经典判据 `

<!-- ROW_MINE: ob-150099 -->`
- 【Linux社区】2008年7月 Travers Buda(traversbuda@gmail.com) 在“Re: atheros - just curious, ot”串中引述 Reyk Floeter 称 ath9k 不会存在若没有 OpenBSD ar5k 驱动先被 Atheros 改写为 ISC 引入 Linux ath5k 并让 Luis Rodriguez 得到 Atheros 工作，是 BSD 血统网络技术反向输入 Linux 内核的关键证据 `

<!-- ROW_MINE: lkml.messages.3662146 -->`
- 【Linux社区】2024年3月14日 John Baldwin（jhb@freebsd.org）在“Re: [PATCH 1/1] x86/elf: Add a new .note section containing Xfeatures information to x86 core files”串中讨论 FreeBSD XSAVE core dump 与 Linux NT_X86_XSTATE 的兼容，指出“FreeBSD dumps an XSAVE register set note that matches the same layout of NT_X86_XSTATE used by Linux”，是 BSD 血统工具与 Linux ABI 互操作的关键见证 

<!-- ROW_MINE: lkml.messages.3816028 -->`
- 【Linux社区】2024年1月20日 Theo de Raadt(deraadt@openbsd.org) 在 Re: [RFC PATCH v3 11/11] mseal:add documentation 串中 论证 EPERM 优于语义已被占用的 EACCES，主张内存映射控制操作采用无歧义的 EPERM 以促成 BSD 与 Linux 对齐，是 BSD 维护者主导 Linux errno 语义最终收敛的关键决策节点 

<!-- ROW_MINE: freebsd-hackers.messages.2614907 -->`
- 【Linux社区】1999年 Doug (Doug@gorean.org) 在“Re: GNU GLOBAL”串中强烈反对 Shigio Yamaguchi 的转向“It means that it will be released under GPL instead of BSD license”并断言“The GNU license interferes with the goals of the FreeBSD project”，是 BSD 社区在软件许可证战线上公开发难 GPL 意识形态的关键檄文 `

<!-- ROW_MINE: linux-fsdevel.messages.538754 -->`
