# 2.7.3 CVS 的集中式协作模型

<!-- DOC_MINE: ref10679#url -->
**官方文档**（证据等级：L3，来源：`historical_claims.duckdb.claim.CL-RM-495471`；2026-11-15 V34 联网补证批 b002）

存储仍是一个文件：CVS 把某文件所有版本存在单个文件里，只保存版本间的差异——集中式的“一个库”由此成立。引文出处：Cederqvist P, et al. CVS—Concurrent Versions System v1.11.23: 1.1 What is CVS?[EB/OL].
