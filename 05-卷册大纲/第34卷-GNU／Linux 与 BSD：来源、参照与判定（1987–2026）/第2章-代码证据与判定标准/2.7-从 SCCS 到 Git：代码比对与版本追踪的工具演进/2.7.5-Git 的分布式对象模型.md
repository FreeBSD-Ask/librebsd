# 2.7.5 Git 的分布式对象模型

<!-- DOC_MINE: ref10675#url -->
**官方文档**（证据等级：L3，来源：`historical_claims.duckdb.claim.CL-RM-495467`；2026-11-15 V34 联网补证批 b001）

模型的起点是拒绝增量：Git 不把数据存成“基线＋改动”，而是存成缩影文件系统的一系列快照——线性版本观在此被换掉。引文出处：Chacon S, Straub B. Pro Git: What is Git?[EB/OL]. 2nd ed. [2026-11-15]. https://git-scm.com/book/en/v2/Getting-Started-What-is-Git%3F.；引文按 L3 纪律：以上为公开文献记载（官方文档或同时代报道），非当事人直接证词，具体结论仍须回核原文与同期一手材料，不应单独引为定论。
