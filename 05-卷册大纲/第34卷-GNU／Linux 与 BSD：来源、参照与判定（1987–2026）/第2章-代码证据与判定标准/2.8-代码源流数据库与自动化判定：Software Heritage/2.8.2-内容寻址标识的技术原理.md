# 2.8.2 内容寻址标识的技术原理

<!-- ROW_MINE: fb-1041097 -->`
- 【Linux社区】2010年10月 Daniel Gerzo(danger@freebsd.org) 在“FreeBSD Status Report July - September, 2010”中汇报 V4L support in the Linux emulator has been merged to 8-STABLE，是 FreeBSD 系统持续承接 Linux V4L 用户态技术的技术公告 `

<!-- ROW_MINE: ksummit.messages.943 -->`
- 【Linux社区】2018年9月 Mauro Carvalho Chehab(mchehab+samsung@kernel.org) 在“[MAINTAINER SUMMIT] EXPORT_SYMBOL_GPL”串中讨论 media 子系统“GPL compatible modules”策略，是 EXPORT_SYMBOL_GPL 与 BSD 派生许可共存的技术落点 `

<!-- ROW_MINE: netdev.messages.8208102 -->`
- 【Linux社区】2013年3月 Stephen Hemminger 在“[RFC 1/2] netmap: infrastructure (in staging)”中 将 Luigi Rizzo 源自 FreeBSD 的 netmap 框架移植进 Linux staging，“all the BSD ugliness”是 BSD 网络技术进入 Linux 网络栈时被显式承认的技术来源 `
