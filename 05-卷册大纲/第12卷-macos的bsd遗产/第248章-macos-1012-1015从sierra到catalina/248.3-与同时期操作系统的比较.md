# 248.3 与同时期操作系统的比较

## 248.3.1 macOS 10.12-10.15 对比 FreeBSD 11/12、Linux 4.x、Windows 10

**要点**：**2016-2019 年** macOS 10.12-10.15 对比 **FreeBSD 11.x**（**2016 年 10 月 10 日** 发布）/**12.x**（**2018 年 12 月 11 日** 发布）、**Linux 4.x**（2016-2019 年）、**Windows 10**（2015-2019 年），其 APFS 与 64 位纯净化在文件系统与架构演进上各有侧重。FreeBSD 11.x/12.x 引入 ZFS 作为原生文件系统（自 FreeBSD 5.3 起），与 macOS 的 APFS 截然不同——APFS 是 Apple 自研（闭源），ZFS 是开源（CDDL 许可证）。Linux 4.x 的 ext4/btrfs/xfs 文件系统生态多元，与 macOS 的 APFS 单一文件系统策略截然不同。Windows 10 的 NTFS 继承自 Windows NT 3.1（1993 年），至 2019 年仍是默认文件系统，未引入新文件系统。

  | 操作系统 | 发布时间 | 文件系统 | 架构演进 | 安全模型 |
  | --- | --- | --- | --- | --- |
  | **macOS 10.12-10.15** | 2016-2019 | **APFS**（自研、闭源） | 64 位纯净化（Catalina 移除 32 位） | SIP + Gatekeeper |
  | **FreeBSD 11.x/12.x** | 2016-10-10 / 2018-12-11 | **ZFS**（开源、CDDL） | 多架构支持 | **jail(8)** + TrustedBSD MAC |
  | **Linux 4.x** | 2016-2019 | ext4/btrfs/xfs（多元生态） | 多架构支持 | SELinux + AppArmor |
  | **Windows 10** | 2015-2019 | NTFS（继承自 NT 3.1，1993 年） | x86/x64 only | UAC + Windows Defender |

  > macOS 选择自研 APFS、FreeBSD 选择 ZFS、Linux 选择 ext4/btrfs 多元生态、Windows 10 选择 NTFS——四者共享 POSIX/Unix 哲学的根基但发展出不同的文件系统主体性。
**史料**：FreeBSD Project. FreeBSD 11.0/12.0 Release Notes [EB/OL]. (2016-10-10, 2018-12-11). <https://www.freebsd.org/releases/>；Linux Kernel Archives. Linux 4.0-4.20 Release Notes [EB/OL]. (2015-2019). <https://www.kernel.org/>；Microsoft. Windows 10 File Systems Documentation [EB/OL]. <https://docs.microsoft.com/en-us/windows-server/storage/file-systems/>。〔L3 官方文档与公告〕

**史观**：总纲第 6 条——主体性与和解。macOS、FreeBSD、Linux、Windows 10 在文件系统选择上是“主体性”的显现——此即项目史观总纲第六章的具体呈现：macOS 选择自研 APFS，FreeBSD 选择 ZFS，Linux 选择 ext4/btrfs 多元生态，Windows 10 选择 NTFS——四者共享 POSIX/Unix 哲学的根基但发展出不同的文件系统主体性。q.md“好望角与塔式起重机”在此显现：四者的文件系统选择是“塔式起重机”式的渐进分化（在 VFS 抽象层上各自选择不同实现），而非“好望角”式的根本转向。

**辨析**：APFS 与 ZFS 的设计哲学差异须客观论述——APFS 针对固态存储优化（SSD/NVMe），ZFS 针对池化存储优化（storage pool）；APFS 是闭源，ZFS 是开源（CDDL）。此差异不意味着优劣，而是不同的设计目标。采信“APFS 与 ZFS 是不同设计目标的文件系统，非优劣关系”的判断。

(2015-2019). <https://www.kernel.org/>; Microsoft. Windows 10 File Systems Documentation [EB/OL]. <https://docs.microsoft.com/en-us/windows-server/storage/file-systems/>.
