- **新闻摘要**：Asahi Linux 项目由 Hector Martin（marcan）于 2021 年 1 月启动，目标是逆向工程 Apple Silicon Mac 的启动协议与硬件接口，将 Linux 原生移植至 M1 Mac。Asahi Linux 是首个在 Apple Silicon Mac 上原生运行的 Linux 发行版。项目通过逆向 m1n1 引导加载器与 U-Boot 移植，逐步攻克 Apple Silicon 的设备树、GPU 驱动、显示驱动、网络驱动、电源管理。Asahi Linux 的工作间接影响 BSD 项目：逆向所得的 Apple Silicon 硬件文档（如 AIC 中断控制器、ASC 协处理器、SMC 系统管理控制器）为 BSD 移植提供参考。2022-03 Asahi Linux Alpha 发布，2025-12 支持 Linux Kernel 6.18，覆盖 M1/M2/M3 系列。Asahi Linux 的成果使 BSD 社区重新评估 Apple Silicon 原生支持的可能性。

- **新闻摘要**：Apple 于 WWDC 2020 宣布 Mac 从 Intel x86-64 转换至自研 Apple Silicon（ARM64 架构）。这一转换对 BSD 生态系统产生深远影响：Darwin/macOS 本身基于 BSD 用户态与 Mach 内核，Apple Silicon 使 Darwin 转向 ARM64 架构；BSD 项目（FreeBSD、NetBSD、OpenBSD）需评估 Apple Silicon Mac 的原生支持可能性；Apple Silicon Mac 上的虚拟化技术允许 BSD 在虚拟机中运行。Apple Silicon 转换的核心挑战是 Apple 未公开 Apple Silicon Mac 的启动协议、设备树、固件接口，使第三方操作系统原生引导困难。Apple Silicon 转换预计两年完成（实际 2023-06 Mac Pro M2 Ultra 发布后完成）。
- **与本章主题的关联说明**：本条目（Apple Silicon 转换宣布，2020-06-22）属 2020-2024 年 Apple Silicon 时代事件，超出本章 2016-2019 时段；与本章主题仅存在远期延伸关联，非本章时段内媒体舆论。条目移至对应章节涉跨文件迁移，已登记 DEFERRED 待主代理处置。
