# 245.1 GCD 与 libdispatch 的 BSD 集成（2009）

## 245.1.1 libdispatch 的开放核心与 Apache 2.0 许可证

**要点**：**Mac OS X 10.6 Snow Leopard** 于 **2009 年 8 月 28 日** 发布，引入 **Grand Central Dispatch（GCD）**——基于 **libdispatch** 库的并发抽象，将任务调度抽象为队列（serial queue、concurrent queue），开发者通过 `dispatch_async`、`dispatch_sync` 等 API 提交任务至队列，由 libdispatch 内部调度至线程池执行。libdispatch 于 **2009 年 9 月 10 日** 以 **Apache 2.0 许可证** 开源（非 Apple 自家的 APSL 2.0），此许可证选择使 FreeBSD、NetBSD 等 BSD 系统可无障碍移植——Apache 2.0 与 BSD 许可证兼容，无 APSL 的 “通报义务” 与 “终止权” 条款。libdispatch 开源后，FreeBSD、NetBSD、Linux（通过 libdispatch-portable 项目）均启动移植工作。

  | libdispatch 要素 | 内容 |
  | --- | --- |
  | 发布日期 | 2009-08-28（随 Snow Leopard） |
  | 开源日期 | 2009-09-10 |
  | 开源许可证 | Apache 2.0（非 APSL 2.0） |
  | 许可证兼容性 | 与 BSD 兼容，无 “通报义务” |
  | 主要 API | `dispatch_async`、`dispatch_sync` |
  | 队列类型 | serial queue、concurrent queue |

  | 许可证对比 | 通报义务 | 终止权 | 与 BSD 兼容 | 适用代码 |
  | --- | --- | --- | --- | --- |
  | **APSL 2.0** | 有 | 有 | 部分兼容 | Darwin 核心代码 |
  | **Apache 2.0** | 无 | 无 | 完全兼容 | libdispatch |

  > Apple 选择以 Apache 2.0（而非 APSL）开源 libdispatch，使 FreeBSD 可无障碍移植——同一 Apple 的代码，APSL 许可的部分难以回馈 FreeBSD，Apache 2.0 许可的部分可无障碍移植。

**史观**：总纲第 13 条——法律与道德是利益分配。Apple 选择以 Apache 2.0（而非 APSL）开源 libdispatch，使 FreeBSD 可无障碍移植——此即 q.md “自由的张力” 的具体显现：APSL 的 “有限消极自由” 使 Darwin 代码难以被 FreeBSD 直接回馈，而 Apache 2.0 的 “完全消极自由” 使 libdispatch 的双向流动成为可能。许可证选择直接决定代码能否双向流动——同一 Apple 的代码，APSL 许可的部分难以回馈 FreeBSD，Apache 2.0 许可的部分可无障碍移植。

**辨析**：[2026-08-15 双库核查] Snow Leopard GCD/libdispatch 引入（2009 年）经参考文献库 “Mac OS X 10.6 Snow Leopard - libdispatch/GCD debut”（Apple Inc., 2009）记录印证；libdispatch 以 Apache 2.0 开源经参考文献库 Swift corelibs-libdispatch 记录印证。原辨析：GCD 是用户空间库而非内核机制——GCD 的 “并发” 通过 BSD 层的 `pthread` 与 Mach 的线程抽象协作实现，但 GCD 本身在用户态运行。GCD 通过 `pthread_create` 创建线程池，通过 Mach 的 `thread_set_exception_ports` 等接口处理异常，但 GCD 的调度逻辑在用户空间。避免 “GCD 是内核机制” 的误解——采信 “GCD 是用户空间库，依赖 BSD 层的 pthread 与 Mach 线程抽象” 的判断。【统计结论 C-03 C-41 整合】统计结论 [C-03] freebsd-src 总 commit 数 444,203 条（系 2026-07-22 统计档案值，2026-09 复核现库为 445,203 条），作为 Darwin 用户态源头参照——Snow Leopard 时期（2009）Darwin 的 BSD 用户空间同步 FreeBSD 7.x/8.x 级别，freebsd-src 的 commit 积累反映此期 FreeBSD 端的工程活跃度；统计结论 [C-41] references 表总数 16,867 条——Snow Leopard 时期的 BSD 谱系学术文献在 references 表中有对应积累。0 信任原则提示：freebsd-src 的 444,203 条 commit 反映 FreeBSD 端工程活跃度，不直接等同于 Darwin 端的代码吸收量；Darwin 仓库不在 darwin.duckdb 中，Snow Leopard 时期 BSD 层具体状态须以 Darwin 源码仓库 xnu-1504 系列为准。
