# 250.3 流动的边界与误解

## 250.3.1 “macOS 基于 FreeBSD” 叙事的修正
  - 要点：“macOS 基于 FreeBSD” 的简化叙事须经架构事实修正——Darwin 内核为 XNU（**Mach 3.0 微内核** + BSD 宏内核子系统 + I/O Kit），FreeBSD 为传统单内核（monolithic kernel），二者架构根本不同。代码流动是部分、双向、随版本变化的，非整体派生。freebsd.db 查询 3 显示，freebsd-src 仓库中 author_email 含 apple.com 的 commit 仅 **6 条**（**2021-2024 年**），来自 2 位贡献者（**Cosimo Cecchi** 3 条、**Yann Kerherve** 3 条），而 Apple 从 FreeBSD 吸收的代码涉及 libc、网络栈、用户态工具等核心子系统——此数据差异即 “不对称流动” 的量化证据。

  | 内核架构对比 | Darwin（macOS） | FreeBSD |
  | --- | --- | --- |
  | 内核类型 | XNU 混合内核 | 传统单内核 |
  | 微内核 | **Mach 3.0** | 无 |
  | BSD 子系统 | 宏内核子系统 | 整体 BSD |
  | 驱动框架 | I/O Kit | 内核内驱动 |
  | 代码同步方式 | 部分双向，随版本变化 | 部分双向，随版本变化 |

  | darwin.db 查询 3 结果（apple.com 邮箱） | 内容 |
  | --- | --- |
  | 时间范围 | 2021-2024 年 |
  | commit 总数 | 6 条 |
  | 贡献者数 | 2 位 |
  | **Cosimo Cecchi** | 3 条 |
  | **Yann Kerherve** | 3 条 |

  ~~macOS 基于 FreeBSD~~，事实上 Darwin 内核为 XNU（Mach 3.0 + BSD 子系统 + I/O Kit），与 FreeBSD 单内核架构根本不同——代码流动是部分、双向、随版本变化的，非整体派生。
  - 史料：darwin.db 查询 2 与查询 3 结果（apple.com 邮箱贡献者 2 位、6 条 commit）；XNU 架构文档（<https://github.com/apple-oss-distributions/xnu>）；FreeBSD 架构文档（<https://docs.freebsd.org/en/books/architecture-handbook/>）。
  - 史观：总纲第 1 条——形式主义即真实存在。“macOS 基于 FreeBSD” 作为形式主义化的误置获得了真实的传播力，但其 “非存在”（与架构事实不符）是事实——此即项目史观总纲第一章的显现：简化叙事作为形式主义化的非存在，其影响力反而超过真实的架构描述。
  - 辨析：避免两种极端——既非 “完全基于 FreeBSD” 亦非 “与 FreeBSD 无关”。freebsd.db 查询 6 显示，freebsd-src 中 MFC 相关且含 Apple/Darwin 的 commit 有 30 条，多为 Apple 硬件支持（Apple HFS 分区、Apple Mac codec ID、Apple Kauai ATA 控制器、Apple PowerMac SMP 支持），由 Nathan Whitehorn、Alexander Motin 等 FreeBSD committer 提交——此即 FreeBSD 对 Apple 硬件的支持性回馈，与 Darwin 对 FreeBSD 用户态代码的吸收是不同方向的流动。
  - 文献：Apple Inc. XNU Source Code [EB/OL]. <https://github.com/apple-oss-distributions/xnu>; FreeBSD Project. FreeBSD Architecture Handbook [EB/OL]. <https://docs.freebsd.org/en/books/architecture-handbook/>.

## 250.3.2 代码流动的量化分析
  - 要点：freebsd.db 数据库查询揭示 macOS 与 FreeBSD 代码流动的量化图景——FreeBSD→Darwin 方向的代码吸收涉及 libc、网络栈、VFS、用户态工具等核心子系统（具体 commit 数量因 Darwin 源码不在数据库中而无法直接统计）；Darwin→FreeBSD 方向的回馈以 Apple 开发者工具补丁（**Pedro F. Giffuni** 6 条 commit）、xlocale API（**David Chisnall（戴维·奇斯纳尔）** 1 条 commit）、版权与许可证同步（**Robert Watson** 2 条 commit）为主，总计约 **15 条 commit**（查询 1 结果）。**Jordan Hubbard** 在 freebsd-src 的 commit 记录为 **7,101 条**（**1993-06-18** 至 **2004-11-14**），其在 **2001 年** 加入 Apple 后仍有少量提交——此即 “人才流动” 与 “代码流动” 的交叉点。

  | darwin.db 量化查询 | 结果 |
  | --- | --- |
  | FreeBSD→Darwin 方向 | 无法直接统计（Darwin 仓库不在数据库中） |
  | Darwin→FreeBSD 方向 | 约 15 条 commit（查询 1） |
  | **Pedro F. Giffuni** | 6 条 commit（Apple 开发者工具补丁） |
  | **David Chisnall** | 1 条 commit（xlocale API 移植） |
  | **Robert Watson** | 2 条 commit（版权与许可证同步） |
  | **Jordan Hubbard** | 7,101 条 commit（1993-06-18 至 2004-11-14） |

  > freebsd.db 不含 Darwin 仓库，故 FreeBSD→Darwin 方向的代码吸收无法从数据库直接统计，只能从 Darwin 源码仓库的 CREDITS 文件与 commit 历史间接推断——此局限在辨析中明确标注，不强行给出无法验证的数字。
  - 史料：darwin.db 全部 6 项查询结果（见 script/vol9_ch118_apple_darwin_commits.py 输出）；Jordan Hubbard 的 7,101 条 commit 记录（查询 5）。
  - 史观：总纲第 10 条——边缘者贡献。代码流动的关键人物中，Robert Watson（同时为 FreeBSD 核心开发者与 Apple 顾问）与 David Chisnall（FreeBSD committer，同时参与 Darwin libc++ 开发）是 “边缘者”——他们横跨 FreeBSD 与 Apple 两个社区，其贡献在两个社区的 “计分板” 上都不完整。此即 q.md “局外人姿态” 在代码流动中的显现。
  - 辨析：[2026-08-15 双库核查] Jordan Hubbard 2001 年加入 Apple 经参考文献库 "hubbard-macosx_from_the_server_room_to_your_pocket-slides"（2008 LISA）中 "Why I came to Apple (in 2001)" 印证；Robert Watson FreeBSD 核心开发者身份经参考文献库 people 模式多条记录（TrustedBSD MAC Framework 2003 等）印证。原辨析：代码流动的量化分析存在数据库覆盖盲区——freebsd.db 不含 Darwin/macOS 仓库（仅含 freebsd-src/doc/ports、netbsd-src、openbsd-src、dragonfly-src），故 FreeBSD→Darwin 方向的代码吸收无法从数据库直接统计，只能从 Darwin 源码仓库的 CREDITS 文件与 commit 历史间接推断。此局限在辨析中明确标注，不强行给出无法验证的数字。
  - 文献：darwin.db 查询结果汇总 [EB/OL]. script/vol9_ch118_apple_darwin_commits.py, 2026-07-22.
