# 251.1 Apple 从 FreeBSD 吸收的代码（2000-2026）

## 251.1.1 用户空间与网络栈的同步

**要点**：Darwin 的 libc、TCP/IP 栈、文件系统工具在 **2000-2003 年** 间直接同步 FreeBSD 3.x/4.x 代码，后续以 “接口对齐” 方式维持兼容而非逐行同步。**Robert Watson**（FreeBSD 核心开发者，同时期为 Apple 顾问）于 **2001 年 8 月 29 日** 在 freebsd-src 仓库提交 commit “Reduce gratuitous whitespace difference from Darwin”（commit 查询经 freebsd.duckdb 验证），**2008 年 7 月 31 日** 提交 "Further synchronization of copyrights, licenses, white space, etc from Apple"——这两条 commit 证明 FreeBSD 与 Darwin 的代码同步是双向的，而非 Apple 单方面从 FreeBSD 获取。**David Chisnall（戴维·奇斯纳尔）** 于 **2011 年 11 月 20 日** 在 freebsd-src 提交 “Implement xlocale APIs from Darwin, mainly for use by libc++”，此即 FreeBSD 从 Darwin 反向吸收 xlocale API 的代码级证据【2026-07-30 联网核查：穷尽检索 GitHub `github.com/freebsd/freebsd-src` commits 搜索（需登录）与 freebsd.duckdb 数据库，Robert Watson 2001-08-29 commit、David Chisnall 2011-11-20 commit、Robert Watson 2008-07-31 commit 三条 commit 的完整 40 字符 SHA-1 hash 均无法从公开 GitHub 搜索直接获取；freebsd-src 仓库历史经 git 迁移后部分早期 commit 元数据缺失，freebsd.duckdb 数据库仅记录 message_subject 与 author_date 而非完整 hash。依据 0 信任原则 + 严禁臆造约束，本子节不予著录三条 commit 的完整 SHA-1 hash，待后续以 GitHub API 或 freebsd-src 仓库 git log 命令行核验后补全——详 `03-原始史料库/06-考据记录/20260730_jianyi缺口补全考据.md` §9x】
