# 251.1 Apple 从 FreeBSD 吸收的代码（2000-2026）

## 251.1.1 用户空间与网络栈的同步

**要点**：Darwin 的 libc、TCP/IP 栈、文件系统工具在 **2000-2003 年** 间直接同步 FreeBSD 3.x/4.x 代码，后续以 “接口对齐” 方式维持兼容而非逐行同步。**Robert Watson**（FreeBSD 核心开发者，同时期为 Apple 顾问）于 **2001 年 8 月 29 日** 在 freebsd-src 仓库提交 commit "Reduce gratuitous whitespace difference from Darwin"（commit 查询经 freebsd.db 验证），**2008 年 7 月 31 日** 提交 "Further synchronization of copyrights, licenses, white space, etc from Apple"——这两条 commit 证明 FreeBSD 与 Darwin 的代码同步是双向的，而非 Apple 单方面从 FreeBSD 获取。**David Chisnall（戴维·奇斯纳尔）** 于 **2011 年 11 月 20 日** 在 freebsd-src 提交 "Implement xlocale APIs from Darwin, mainly for use by libc++"，此即 FreeBSD 从 Darwin 反向吸收 xlocale API 的代码级证据【2026-07-30 联网核查：穷尽检索 GitHub `github.com/freebsd/freebsd-src` commits 搜索（需登录）与 freebsd.db 数据库，Robert Watson 2001-08-29 commit、David Chisnall 2011-11-20 commit、Robert Watson 2008-07-31 commit 三条 commit 的完整 40 字符 SHA-1 hash 均无法从公开 GitHub 搜索直接获取；freebsd-src 仓库历史经 git 迁移后部分早期 commit 元数据缺失，freebsd.db 数据库仅记录 message_subject 与 author_date 而非完整 hash。依据 0 信任原则 + 严禁臆造约束，本子节不予著录三条 commit 的完整 SHA-1 hash，待后续以 GitHub API 或 freebsd-src 仓库 git log 命令行核验后补全——详 `03-原始史料库/06-考据记录/20260730_jianyi缺口补全考据.md` §9x】

**史料**：freebsd.db 查询结果（freebsd-src 仓库，message_subject 含 "From Apple"/"From Darwin"，15 条 commit，查询条件见 script/vol9_ch118_apple_darwin_commits.py 查询 1）；Darwin 源码仓库 opensource.apple.com；Amit Singh（阿米特·辛格）《Mac OS X Internals: A Systems Approach》（Addison-Wesley, 2006, ISBN 0-321-36645-0）。〔L1 代码/构建产物/L5 二手研究〕

**史观**：总纲第 25 条——终结中的延续。CSRG 于 1995 年解散后，BSD 代码未终结而是以 “分离聚合” 方式在 FreeBSD、Darwin 等分支中延续——此即项目史观总纲第四章 “循环与否定” 的具体显现：BSD 代码从 Berkeley→FreeBSD→Darwin 的流动非线性进化而是循环往复，同一代码在两端各自演化后部分重新同步。

**辨析**：[2026-08-15 双库核查] Darwin→FreeBSD 代码流动经邮件列表库 2003-07-18 "MSDOSFS patch of dirty flag (Darwin Import)" 邮件（Jun Su）印证；Apple 工程师参与 FreeBSD 社区经邮件列表库 2000-01-21 Conrad Minshall（<conrad@apple.com>）邮件印证。原：“代码同步”（逐行复制）与 “接口对齐”（独立实现同接口）的比例随版本变化——早期（2000-2003）Darwin 直接同步 FreeBSD 4.x 代码（逐行复制比例高），后期（2005 年后）以接口对齐为主（逐行复制减少）。此判断基于 Robert Watson 2001-2008 年间 commit 的 message_subject 分析：2001 年 commit 标题为 "Reduce gratuitous whitespace difference"（消除差异），2008 年为 "Further synchronization of copyrights, licenses"（同步版权与许可证），二者性质不同——前者是代码级同步，后者是元数据级同步。【统计结论 C-41 C-42 C-43 整合】统计结论 [C-41] references 表总数 16,867 条；统计结论 [C-42] references 表年份提取率 44.42%（7,493/16,867）；统计结论 [C-43] Price 指数 7.34%（近 5 年参考文献占比）——Price 指数 7.34% 反映本书史料积累偏向早期经典，macOS 与 FreeBSD 代码双向流动的早期关键 commit（如 Robert Watson 2001-2008 年的同步 commit、David Chisnall 2011 年的 xlocale API 反向移植 commit）即落入此 “早期经典” 区间；0 信任原则提示：统计显著 ≠ 实际显著，references 表文献数量与 Price 指数反映学术关注度与史料积累偏向，不直接等同于代码双向流动的工程影响；Darwin 仓库不在 freebsd.db 中，本时期双向流动的代码级证据须以 freebsd-src 仓库中的 Apple/Darwin 相关 commit 与 Darwin 源码仓库 opensource.apple.com 双源印证（数据局限性继承自描述性统计.md 数据局限性总述）。

**要点**：

- FreeBSD 11.2 于 2018 年 6 月 27 日发布，带来 ZFS 压缩发送/接收与设备移除、面向 Intel 集成显卡的 DRM Next Kmod、OpenSSH 7.5p1 与 OpenSSL 1.0.2o 更新、LLVM 6 工具链，以及 Chelsio、Mellanox、Intel IXL 等大量网卡驱动更新。（BSD Now EP252，[63.24-246.32]，L2）
- Robert Watson 在 2008 年的帖子中指出 XNU 并非微内核，但其源码树含约 2100 万行显式标记为 BSD 的代码（主要来自 FreeBSD 并经大量修改）、约 1600 万行 Mach 代码，另有 IOKit 设备驱动与 libkern 等 Apple 自有代码，从而反驳 macOS 只是带 Apple 图形界面的 FreeBSD 这一说法。（BSD Now EP252，[3217.08-3380.68]，L1）
- Dave 的 BSDCan 2018 报告记录 Ben O'Rice 的 systemd 悲剧主题演讲与 Kirk McKusick 的 FreeBSD 治理演进演讲，后者回顾从 Jordan、Phk、Rod Grimes 时代到 Watson 时代的核心团队更替，并讨论 committer 年龄结构与社区新鲜血液。（BSD Now EP252，[2747.78-3215.62]，L1）

- 一手史料：FreeBSD 11.2 发布公告与发行说明；Robert Watson 2008 年致 FreeBSD advocacy 邮件列表的帖子；Dave 的 BSDCan 2018 参会报告（邮件）。（BSD Now EP252，[63.24-3394.24]，L2）
