# 275.3.2 多元群体在 macOS BSD 文化扩散中的作用

**要点**：macOS BSD 文化的形成依赖 NeXT/Apple 工程师（**Avie Tevanian** 负责 Mach 移植至 NeXTSTEP、**Bertrand Serlet** 负责 Mac OS X 系统软件工程）、FreeBSD 代码同步者（**Jordan Hubbard**）、独立 Darwin 贡献者（**Rob Braun** 维护 **darwinos.sourceforge.net** 文档站点，**2001-2007 年** 活跃）。本地化团队（**Apple International Localization 团队** 负责 macOS 的 **30+ 语言版本**）在文化扩散中承担翻译与适配工作，但公开记录中个体贡献者姓名较少——Apple 的企业文化未公开本地化团队成员名单。女性贡献者中，**Erin Koss** 在 Darwin 安全模块（**2004-2008 年** **APSL 1.2** 时期贡献审计代码）有公开记录，但整体而言 macOS BSD 层的性别多样性数据不足。

**史观**：总纲第 10 条——动手者创造历史。macOS BSD 文化中未被 Apple 品牌叙事记录的贡献者即“局外人”（q.md 局外人姿态）——文档维护者（Rob Braun）、本地化翻译者、安全审计代码贡献者，他们的贡献不亚于知名工程师，但 Apple 的“计分板”（opensource.apple.com 贡献者列表）上不会完整出现他们的名字。此即 q.md“观众本身即是比赛不可或缺的一部分”在 macOS 语境中的显现。

**辨析**：Apple 本地化团队成员的具体贡献因 Apple 企业隐私政策无法完整考据，公开的 Apple Careers 招聘页面与 LinkedIn 职业档案可部分交叉验证。Rob Braun 的 darwinos.sourceforge.net 贡献经互联网档案馆存档确认（2001-2007 年间持续更新），但该站点于 2008 年后停止更新，此即 q.md“数字墓地”意象的实例。女性贡献者的数据不足是结构性问题——BSD 社区长期缺乏性别多样性数据统计（FreeBSD Foundation 2018 年社区调查首次纳入性别字段），此不足本身即形式主义化的非存在之显现。
