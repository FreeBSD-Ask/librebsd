# 261.6.3 商业产业新闻类

### 新闻条目 1

- **新闻标题（中英）**：Mac OS X 10.6 Snow Leopard: the Ars Technica review / Mac OS X 10.6 Snow Leopard：Ars Technica 评论
- **新闻来源**：Ars Technica + John Siracusa + 2009-09-01 + <https://arstechnica.com/gadgets/2009/08/mac-os-x-10-6/> + <https://web.archive.org/web/2009*/arstechnica.com/apple/reviews/2009/08/mac-os-x-10-6.ars>
- **新闻摘要**：John Siracusa 的 Snow Leopard 长篇评论以 “No new features” 为开篇标语，详细分析 Snow Leopard 不同于以往版本（如 Tiger 150+ 新功能、Leopard 300+ 新功能）的市场定位——重点在底层重构与性能优化而非可见新功能。文章覆盖 Mac OS X 自 2001 年以来从 12 个月发布周期到 18 个月周期的演进，以及 Apple 公布 Snow Leopard 弃 PowerPC 支持转向纯 Intel 的策略转变。
- **与本章主题的关联说明**：本章关注 10.6 Snow Leopard（2009-08-28）、10.7 Lion（2011-07-20）、10.8 Mountain Lion（2012-07-25）三版本演进。Siracusa 的评论揭示了 Apple 从 “功能堆叠” 到 “底层优化” 的策略转折，奠定后续 Lion 与 Mountain Lion 的工程基础。
- **与官方史料的交叉验证结论**：与 Apple 2009-06-08 WWDC 主题演讲公布的 Snow Leopard 定价 29 美元一致；与 Apple 2009-08-28 Snow Leopard 发布新闻稿一致；与 Apple 开发者文档记录的弃 PowerPC 支持一致。
