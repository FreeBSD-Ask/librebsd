# 238.2 WebObjects 与 BSD 服务器传统（1995-1997）

## 238.2.1 WebObjects 应用服务器对 BSD 网络栈的依托

**要点**：**NeXT** 于 **1995 年 12 月** 发布 **WebObjects 1.0**——基于 **Objective-C** 的应用服务器，依托 NeXTSTEP 的 BSD 网络栈提供 HTTP 服务。WebObjects 是 NeXT 退出硬件业务后（**1993 年** 退出）转向软件与服务器市场的核心产品，是 BSD 在 Web 应用服务器领域的早期商业实践。WebObjects 1.0 的架构基于 NeXTSTEP 的 **Foundation 框架**（Objective-C 对象模型）与 BSD socket 网络栈——其 HTTP 服务通过 BSD socket 实现，请求处理通过 Foundation 的 **Distributed Objects** 机制分发。WebObjects 后随 Apple 收购（**1996 年 12 月** 宣布、**1997 年 2 月** 完成）并入 Apple，并最终转向 Java 实现（2000 年代后，**WebObjects 5.0** 转向纯 Java）。WebObjects 与 BSD 的直接关系在 Apple 收购后逐渐弱化——Apple 时期的 WebObjects 运行于 Mac OS X Server 的 Darwin BSD 层之上，但其核心架构从 Objective-C 转向 Java 后，与 NeXTSTEP 的 BSD 代码无直接继承关系。

  | WebObjects 版本 | 发布年 | 实现语言 | 与 BSD 代码关系 |
  | --- | --- | --- | --- |
  | WebObjects 1.0 | 1995 | Objective-C | 直接依托 BSD socket |
  | WebObjects 3.x | 1997 | Objective-C | 直接依托 BSD socket |
  | WebObjects 4.x | 1999-2000 | Objective-C + Java 部分 | 弱化 |
  | WebObjects 5.0 | 2001 | 纯 Java | 无直接继承 |

**史观**：总纲第 9 条——企业研究投入的双重性。WebObjects 体现 NeXT 将 BSD 网络能力商品化——此即项目史观总纲第九章的具体显现：NeXT 退出硬件业务后，将 NeXTSTEP 的 BSD 网络栈转化为 Web 应用服务器产品（WebObjects），此商品化是 NeXT 转向软件与服务市场的核心策略。q.md “道与术的辩证” 在此显现：WebObjects 的 BSD socket 依托是 “术”（工程实现），NeXT 的软件与服务转型是 “道”（商业战略哲学），二者并行但分属不同层面。q.md “记忆的不可重渡” 在此显现：WebObjects 从 Objective-C 转向 Java 后，其与 NeXTSTEP BSD 代码的直接继承关系终结，Apple 对 WebObjects 的再诠释改变了其原始 NeXT 形态。

**辨析**：WebObjects 1.0 的发布月份——以 NeXT Developer Documentation 为准，标注为 1995 年 12 月，标注 [脚注：经穷尽联网考据，NeXT Developer Documentation 与 NeXT 企业产品文档均仅标注月份（1995 年 12 月），未给出具体发布日，NeXT 内部发布记录未公开数字化，故具体发布日保留为史料缺口]。WebObjects 与 BSD 的直接关系——WebObjects 1.0 期（1995-1997）直接依托 NeXTSTEP 的 BSD socket 网络栈，Apple 收购后 WebObjects 运行于 Darwin BSD 层之上但核心架构从 Objective-C 转向 Java。采信 “WebObjects 1.0 期与 BSD 有直接代码关系，Apple 收购后关系逐渐弱化，Java 转向后无直接代码继承” 的判断。WebObjects 转向 Java 的时间——WebObjects 5.0（2001 年发布）转向纯 Java，先前 WebObjects 4.x（1999-2000 年）部分使用 Java。【0 信任原则·XNU 快照发布局限】darwin.duckdb 查询 L7.5.1 数据无法反映 WebObjects 1.0 时期 BSD socket 接口的具体调用路径，XNU 快照仅显示文件级 commit 聚合，无 WebObjects 相关 commit 标记。
