- **新闻摘要**：OpenDarwin 项目于 2006-07-25 宣布关停。OpenDarwin 于 2002-04 由 Apple 工程师 Jordan Hubbard（FreeBSD 联合创始人）与 Apple Darwin 团队主导创立，目标是构建基于 Apple Darwin 开源代码的社区操作系统。Apple 自 1999 年起将 Darwin 操作系统以 **Apple Public Source License（APSL）**逐版开源（官方公告 1999-03-16，随 Mac OS X Server 1.0 发布），OpenDarwin 项目作为社区协作平台，承接 Apple Darwin 开源代码并允许外部开发者参与改进。OpenDarwin 关停公告称，“由于 Apple 与开源社区之间的协作模式未达预期，且 Apple 内部对 Darwin 开源策略调整，OpenDarwin 项目无法继续维持活跃开发”，项目宣布正式关停。OpenDarwin 关停后，社区分裂为两个方向：一是 PureDarwin 社区项目（继续基于 Darwin 开源代码构建可用系统），二是 Apple 内部继续维护 macOS 闭源路线，Darwin 开源代码更新逐渐减少。OpenDarwin 关停标志着 Apple 对 Darwin 完全开源路线的实质性放弃，仅保留部分 Darwin 代码（如 XNU 内核）的开源发布。
- **与本章主题的关联说明**：OpenDarwin 是 Apple 将 BSD 层遗产（Darwin/XNU）开放给社区的关键平台，其 2006 年关停直接标示 Apple 开源策略收缩，为“macOS 的 BSD 层技术哲学”提供反向坐标。
- **与官方史料的交叉验证结论**：关停日期 2006-07-25 与创立信息（2002-04，Jordan Hubbard 与 Apple Darwin 团队）经互联网档案馆公告回放与 Hubbard 官方履历互证成立；公告引语的逐字核对回源待办。

### 新闻条目 3

- **新闻标题（中英）**：Fedora Asahi Remix Released / Fedora Asahi Remix 发布
- **新闻来源**：Asahi Linux 官方网站 + 2023-08 + <https://asahilinux.org/fedora> + 存档：<https://web.archive.org/web/2023/https://asahilinux.org/fedora>
- **新闻摘要**：Asahi Linux 项目与 Fedora Project 合作，于 2023-08 在 Flock 大会上正式发布 Fedora Asahi Remix 39，作为 Apple Silicon Mac 上 “最 polished 的 Linux 体验”。Fedora Asahi Remix 基于 Fedora Linux 39（后续 2024 年发布 40 版本），支持 M1 与 M2 系列 MacBook、Mac mini、Mac Pro、Mac Studio 与 iMac 设备。Fedora Asahi Remix 默认采用 KDE Plasma 桌面（后续 40 版本升至 KDE Plasma 6.0），亦提供 GNOME 与 Minimal/Server 镜像。Fedora Asahi Remix 提供 100% Wayland 体验，并搭载全球首个通过 Khronos 认证的 Apple Silicon OpenGL 4.6、OpenGL ES 3.2、OpenCL 3.0 与 Vulkan 1.4 实现，支持开放式图形标准而非依赖 Apple Metal 专有 API。Fedora Asahi Remix 内置 PipeWire + WirePlumber DSP 音频方案，针对 8 种以上机型单独测量与校准，配合自研 Bankstown 低音增强与 Smart Amp 安全实现，提供 “Linux 笔记本最佳音频体验”。Asahi Linux 项目由 Hector Martin（marcan）于 2021 年发起，通过 Patreon 众筹启动开发，目标是为 Apple Silicon Mac 提供 Linux 移植。Asahi Linux 对 BSD 生态的影响在于：Apple Silicon Mac 上 Linux 可原生运行，但 FreeBSD 等 BSD 系统在 Apple Silicon 上的支持仍滞后，Asahi Linux 的逆向工程工作（M1 GPU 驱动、Apple Virtualization Framework 兼容性等）部分被 BSD 社区参考，但 BSD 端 Apple Silicon 移植进度远落后于 Linux。
- **与本章主题的关联说明**：Apple Silicon 上 Linux 生态的成熟度构成 BSD 移植滞后的参照系，其逆向成果是 BSD 端移植的外部依赖，服务本章“同时期比较”维度。
- **与官方史料的交叉验证结论**：发布时点 2023-08（Flock 大会）、Fedora 39 基线、KDE Plasma 默认与 Khronos 认证（OpenGL 4.6/ES 3.2/OpenCL 3.0/Vulkan 1.4）与 asahilinux.org/fedora 官方页面一致；认证细节以 Khronos 官方公告回源为准。

- **新闻来源**：社区报道 + 2015 + 原始链接失效，互联网档案馆存档：<https://web.archive.org/web/2015/http://www.nextbsd.org/> + 交叉验证：头条报道 + 2024 + <http://m.toutiao.com/group/7665341867344527899/>
- **新闻摘要**：NextBSD 项目最初由 FreeBSD 联合创始人 Jordan Hubbard 于 2015 年发起。Jordan Hubbard 曾是 FreeBSD 创立者之一，后任 Apple 公司 Darwin 项目负责人。NextBSD 计划将 Apple Darwin 操作系统的部分组件移植到 FreeBSD 上，反向借鉴 Darwin 的设计思想（如 launchd、dispatch 队列、Mach 端口等）以增强 FreeBSD 的现代系统能力。NextBSD 与 OpenDarwin/PureDarwin 的方向相反：OpenDarwin/PureDarwin 试图构建独立可用的 Darwin 系统，NextBSD 则试图将 Darwin 部件移植入 FreeBSD。NextBSD 项目发布后社区反响有限，后续开发进度缓慢，至 2020 年代项目实际停止维护。NextBSD 反映了 BSD 与 macOS 之间双向技术流动的历史：早期 BSD 影响 macOS（FreeBSD 用户态、BSD 网络栈等），后期 macOS 部分设计反向启发 BSD（NextBSD 借鉴 Darwin 部件）。Jordan Hubbard 在 FreeBSD 与 Apple 之间的双重身份，是 BSD-macOS 衍生关系的关键人物节点。
- **与本章主题的关联说明**：NextBSD 是 BSD 与 macOS 双向技术流动（Darwin 部件回流 FreeBSD）的直接案例，与本章“macOS 的 BSD 层”主题正反互证。
- **与官方史料的交叉验证结论**：发起人 Jordan Hubbard 与移植组件（launchd、dispatch 队列、Mach 端口）同其 FreeBSD/Apple 履历互证成立；“2015 年发起”与 nextbsd.org 存档一致；“2020 年代停止维护”为社区观察性陈述，尚无官方声明佐证，采信时保留单源标注。
