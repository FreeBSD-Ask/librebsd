# 249.4 与同时期操作系统的比较

**要点**：macOS 11-15（2020-2024）Apple Silicon 时期的 BSD 层与同时期操作系统比较——macOS 11 Big Sur 于 2020-11-12 发布，与 M1 芯片及首批 Apple Silicon Mac（MacBook Air、13 英寸 MacBook Pro、Mac mini）同期推出，开启 macOS 11.x 时代；此后 Monterey（2021-10-25）、Ventura（2022 年 WWDC 发布）、Sonoma（2023-09-26）、Sequoia（2024-09-16）保持每年一版节奏，XNU（Mach + BSD 混合内核）及其 BSD 用户态构成闭源商业系统的 Unix 基座。同期 Windows 11 于 2021-10-05 正式推送（NT 混合内核、闭源）；FreeBSD 13.0（2021-04-13）与 FreeBSD 14.0（2023-11-20，amd64/arm64 支持至 1024 核、OpenZFS 2.2、默认 TCP 拥塞控制改为 CUBIC）延续 BSD 单内核开源路线；Linux 保持 GPL 授权单内核路线。四方在内核架构（混合/单内核）、授权模式（闭源/开放核心/全开源）与硬件策略（Apple 纵向整合/开放硬件生态）上形成对照。

**辨析**：比较的三重陷阱——①内核架构对照（XNU 混合、NT 混合、Linux/FreeBSD 单内核）不应读作“BSD 层更纯即更先进”的进步叙事，Apple Silicon 时期 macOS 的纵向整合（自研芯片+闭源系统）恰说明架构选择由商业与工程条件塑造；②开源程度光谱：FreeBSD/Linux 全栈开源、Windows 闭源、macOS 闭源但 Darwin/XNU 以 APSL 定期公开源码，比较时须区分“内核开源”与“系统开源”；③与 FreeBSD 的血缘：macOS 的 BSD 用户态与 FreeBSD 同源于 CSRG 传统，但双方自 2000 年代起各自独立演进、代码层面互不依赖，Apple 与 FreeBSD 的双向代码流动争议另见第 251 章专论
