# 247.2 Mavericks 至 El Capitan 的沙盒与系统完整性（2013-2015）

## 247.2.1 沙盒机制与 BSD 权限模型改造

**要点**：**OS X 10.9 Mavericks** 于 **2013 年 10 月 22 日** 发布（首次免费升级，不再收费），引入 **App Nap**（能效机制，后台应用降低 CPU 使用）、**Tags**（文件标签）、**iCloud Keychain**。**Darwin 13.x** 同步 FreeBSD 9.x/10.x 级别用户空间——FreeBSD 10.0 于 **2014 年 1 月 14 日** 发布（默认使用 **Clang** 替代 GCC）。**OS X 10.10 Yosemite** 于 **2014 年 10 月 16 日** 发布，引入 **Continuity**（Handoff、电话接力、SMS 转发）、Today View、Spotlight 增强。**Darwin 14.x** 同步 FreeBSD 10.x 级别用户空间。**OS X 10.11 El Capitan** 于 **2015 年 9 月 30 日** 发布，引入 **System Integrity Protection（SIP/Rootless）**——限制即使 root 用户对系统目录（`/usr`、`/bin`、`/sbin`、`/System`）的写权限，此为 BSD 传统 root 权限模型的重大改造。SIP 通过 BSD 层的 **TrustedBSD MAC**（Mandatory Access Control）框架实现——Apple 基于 TrustedBSD MAC 框架（FreeBSD 5.0 引入）扩展了 SIP 的策略。

  | OS X 版本 | 发布日期 | Darwin 版本 | BSD 同步 | 主要功能引入 |
  | --- | --- | --- | --- | --- |
  | **10.9 Mavericks** | 2013-10-22 | Darwin 13.x | FreeBSD 9.x/10.x | App Nap、Tags、iCloud Keychain（免费升级） |
  | **10.10 Yosemite** | 2014-10-16 | Darwin 14.x | FreeBSD 10.x | Continuity、Today View |
  | **10.11 El Capitan** | 2015-09-30 | Darwin 15.x | FreeBSD 10.x | **SIP/Rootless** |

  | SIP 限制的系统目录 | root 写权限 | 实现机制 |
  | --- | --- | --- |
  | `/usr` | 受限 | TrustedBSD MAC 框架 |
  | `/bin` | 受限 | TrustedBSD MAC 框架 |
  | `/sbin` | 受限 | TrustedBSD MAC 框架 |
  | `/System` | 受限 | TrustedBSD MAC 框架 |

  ~~Apple SIP 基于 FreeBSD **jail(8)** 实现~~，事实上 Apple SIP 基于 TrustedBSD MAC 框架扩展，未使用 **jail(8)**——SIP 是系统级权限限制（限制 root 对系统目录写权限），**jail(8)** 是进程级容器隔离。

OS X 10.11 El Capitan Release Notes [EB/OL]. (2015-09-30). Apple Developer（SIP 章节）；Apple Inc. Apple Platform Security Guide [EB/OL]. (2015). Apple Security Documentation（SIP 与 TrustedBSD MAC 框架）；FreeBSD Project. FreeBSD 10.0 Release Notes [EB/OL]. (2014-01-14). <https://www.freebsd.org/releases/>（Clang 默认编译器）；Darwin 源码仓库 opensource.apple.com（`bsd/security/` 目录含 SIP 实现代码）。

**史观**：总纲第 25 条——终结中的延续。root 无限权限的“终结”（SIP 限制 root）是 BSD 传统的重大转向——此即项目史观总纲第二十五章的具体呈现：BSD 自 1978 年 Berkeley 时期即确立的“root 拥有无限权限”模型，在 2015 年被 Apple 的 SIP 改造为“root 拥有受限权限”模型。q.md“记忆的不可重渡”在此显现：BSD 的“root 无限权限”记忆不可重渡，但 BSD 层的权限模型在 SIP 之后以新的形式延续——root 仍是特殊用户，但其权限被 MAC 框架约束。

**辨析**：SIP 与 FreeBSD **jail(8)**/TrustedBSD MAC 的关系须厘清——**jail(8)** 是 FreeBSD 4.0（2000 年 3 月 14 日发布）引入的容器化机制，将进程隔离在子环境中；TrustedBSD MAC 是 FreeBSD 5.0（2003 年 1 月 19 日发布）引入的强制访问控制框架，允许定义细粒度权限策略。Apple 的 SIP 基于 TrustedBSD MAC 框架扩展，但未使用 **jail(8)**——SIP 是系统级的权限限制（限制 root 对系统目录的写权限），**jail(8)** 是进程级的容器隔离。采信“Apple SIP 基于 TrustedBSD MAC 框架扩展，未使用 **jail(8)**”的判断。【2026-07-30 联网核查：SIP 引入后 BSD `root` 用户权限受限的具体技术细节（如 `root` 无法修改 `/usr`、`/bin`、`/sbin`、`/System` 目录的 MAC 策略配置、`restricted` 文件标志机制等）穷尽联网检索 Apple Platform Security Guide 与 Apple Developer 文档未获完整技术规格；社区对 SIP 限制 BSD 哲学“工具由小而精的组合完成大任务”的争议（如 Hacker News、freebsd-hackers 邮件列表中 2015-2016 年间的讨论）未检索到系统性争议文献。依据 0 信任原则 + 严禁臆造约束，本子节不予著录 SIP MAC 策略配置细节与社区争议具体文献，待后续核查 Apple Platform Security Guide 完整版本或 Internet Archive 存档后补全——详 `03-原始史料库/06-考据记录/20260730_jianyi缺口补全考据.md` §9p】

## 247.2.2 外部贡献者与 David Chisnall（戴维·奇斯纳尔） 的 xlocale 移植

**要点**：此期 Darwin 同步吸收 FreeBSD 网络栈与安全相关补丁，独立开发者经 APSL 2.0 流程贡献。freebsd.duckdb 查询显示，**David Chisnall** 于 **2011 年 11 月 20 日** 在 freebsd-src 仓库提交“Implement xlocale APIs from Darwin, mainly for use by libc++”——此 commit 将 Darwin 的 **xlocale API**（扩展 locale 支持，支持 UTF-8 与多字节字符）移植至 FreeBSD，是 Darwin→FreeBSD 代码流动的典型实例。David Chisnall 是 FreeBSD committer，同时参与 Darwin libc++ 开发，是横跨 FreeBSD 与 Apple 两个社区的“桥梁人物”。此期 Apple 开发者工具补丁移植由 **Pedro F. Giffuni** 在 **2012-2014 年** 间进行（6 条 commit，从 Apple 的 llvm-gcc 项目与开发者工具向 FreeBSD GCC 移植补丁）。

  | 贡献者 | 关键 commit | 日期 | 方向 | 说明 |
  | --- | --- | --- | --- | --- |
  | **David Chisnall** | “Implement xlocale APIs from Darwin, mainly for use by libc++” | 2011-11-20 | Darwin→FreeBSD | xlocale API 反向移植 |
  | **Pedro F. Giffuni** | Apple 开发者工具补丁（6 条 commit） | 2012-2014 | Apple→FreeBSD | llvm-gcc 与开发者工具移植 |

  > David Chisnall 的 xlocale 移植是 Darwin→FreeBSD 的代码流动，Apple 未直接从此次移植中获益，但 FreeBSD 的 xlocale 实现与 Darwin 保持接口兼容，间接促进了跨平台应用开发。
**史料**：darwin.duckdb 查询 1 结果（David Chisnall 2011-11-20 xlocale 移植 commit；Pedro F. Giffuni 2012-2014 年 6 条 Apple 开发者工具补丁）；Apple Open Source. Darwin Source Releases [EB/OL]. <https://opensource.apple.com/releases/>（xnu-3248 系列对应 10.11 El Capitan）。〔L1 代码/构建产物〕

**史观**：总纲第 10 条——边缘者贡献被中心叙事遮蔽。David Chisnall 与 Pedro F. Giffuni 是 Darwin 与 FreeBSD 代码流动中的“边缘者”——他们的贡献不属于 FreeBSD 或 Apple 任一方的“主线叙事”，而是横跨两个社区的桥梁贡献。此即 q.md“局外人姿态”在代码流动中的具体显现。

**辨析**：David Chisnall 的 xlocale 移植是否“回馈”了 Apple——xlocale API 源自 Darwin，David Chisnall 将其移植至 FreeBSD，此为 Darwin→FreeBSD 的代码流动（非 FreeBSD→Darwin）。Apple 未直接从此次移植中获益，但 FreeBSD 的 xlocale 实现与 Darwin 保持接口兼容，间接促进了跨平台应用开发。采信“David Chisnall 的 xlocale 移植是 Darwin→FreeBSD 流动，Apple 未直接获益但间接促进跨平台兼容”的判断。
