# 247.5 项目统摄史观审视

本节从项目史观总纲第 5、8、11、19 条切入，审视 David Chisnall（戴维·奇斯纳尔） 与 Pedro F. Giffuni 作为 Apple-FreeBSD 桥梁贡献者的哲学意涵。

**总纲第 5 条——没有必然性，只有偶然性**。David Chisnall 与 Pedro F. Giffuni 作为 2011-2015 年间 Apple 与 FreeBSD 之间仅有的两位桥梁贡献者，其出现是偶然的而非必然的。Chisnall 之所以成为桥梁，源于其同时参与 FreeBSD committer 工作与 Darwin libc++ 开发的双重身份——此双重身份是其个人学术与工程经历的特殊产物，而非 Apple 或 FreeBSD 任一方的制度安排。Giffuni 之所以成为桥梁，源于其对 Apple 开发者工具向 FreeBSD GCC 移植的个人兴趣——此兴趣是其个人选择而非社区委派。项目史观总纲第五章“没有必然性，只有偶然性”在此显现：桥梁贡献者的出现不可被预测，亦不可被制度化为“Apple-FreeBSD 桥梁计划”。替代品的无限性不能否定事物的独特价值——若 Chisnall 或 Giffuni 中的任一位因个人原因未参与此期工作，桥梁贡献可能更为稀疏甚至归零，此即“每一个关键人物都是不可替代的偶然”在代码流动中的具体显现。史家须承认：桥梁贡献的稀疏不是制度失败，而是偶然性在 2011-2015 年间的具体显现；任何要求“制度化桥梁”的呼吁，皆忽视了偶然性是历史根本动力这一哲学事实。

**总纲第 8 条——本体论上各方平等**。Apple 作为商业实体与 FreeBSD 作为非营利社区，在本体论上地位相等——差异仅是一刻状态的不同。David Chisnall 与 Pedro F. Giffuni 的桥梁贡献，揭示了本体论平等在代码流动中的具体显现：Chisnall 的 xlocale 移植是 Darwin→FreeBSD 方向，Giffuni 的工具补丁是 Apple→FreeBSD 方向，二者皆是“代码”作为本体的流动，不因 Apple 的商业属性或 FreeBSD 的非营利属性而有本体论上的高下。项目史观总纲第八章“本体论上各方平等”在此显现：macOS 与 FreeBSD 在本体论上地位相等，差异仅是商品化程度的不同——macOS 是 BSD 代码的商品化形态，FreeBSD 是 BSD 代码的非商品化形态，二者同源于 BSD 代码本体。史家不应将 Apple 描绘为“剥削者”或 FreeBSD 描绘为“受害者”——此等叙事预设了本体论上的不平等，违反第 8 条。桥梁贡献稀疏的事实须被承认，但其哲学意涵是“本体论平等下的形式主义分叉”，而非“本体论不平等下的剥削关系”。

**总纲第 11 条——商品是形式主义**。David Chisnall 与 Pedro F. Giffuni 的桥梁贡献稀疏，本质是同一 BSD 代码在“商品化”与“非商品化”两端的分流。Apple 将 BSD 代码吸收进 Darwin，再以 macOS 商业发行的形式商品化——此即项目史观总纲第八章所述“商品本身是一种形式主义，不是人们在追求商品，而是商品在召唤人们”。macOS 作为商品获得了市场主导权，FreeBSD 作为非商品在桌面市场被边缘化，此非技术优劣的反映而是“劣币驱逐良币”的显现——“占据主流的未必是设计最优的，而往往是营销最成功的、时机最恰当的”。BSD 许可证“允许不回馈”的设计，在商品形式主义下演化为商业公司可汲取非营利社区代码而无需对等回馈的结构性通道——Chisnall 与 Giffuni 的桥梁贡献虽存在，但其稀疏性正是此结构性通道的具体显现。然而，项目统摄史观不预设此“稀疏”为恶——BSDL 的选择承认人类的有限性，“允许不回馈”是消极自由的底线，其代价是“桥梁稀疏”。史家的职责不是裁决 Apple 是否“应该”派遣更多员工回馈 FreeBSD，而是揭示商品形式主义下权力运作的真实结构——桥梁贡献稀疏是此结构的必然结果，而非偶然失误。

**总纲第 19 条——解释学循环是历史认识的根本条件**。David Chisnall 与 Pedro F. Giffuni 桥梁贡献的叙事本身陷入解释学循环——Apple 阵营与 BSD 阵营对“同一组 commit”的前理解截然不同。Apple 阵营的前理解是“许可证即契约，桥梁稀疏是契约的必然结果”，BSD 阵营的前理解是“许可证允许不等于社区利益所宜，桥梁稀疏是利益分配失衡”。此即项目史观总纲第十九章所述“我们往往预设了读者与作者享有相同的前理解与前意识，因此随着讨论深入，分歧只会越来越多”。更深层的是权力与知识的共谋——“什么是重要的历史事件，什么被记录，什么被遗忘，什么被视为错误，什么被视为进步，这些判断背后都有权力的运作”。freebsd.duckdb 记录了 freebsd-src 中 Chisnall 与 Giffuni 的 commit，但未记录 Apple 在 Darwin 仓库中可能接受的 FreeBSD 提交者的 pull request——什么被记录、什么不被记录，本身即权力行使。Chisnall 与 Giffuni 作为桥梁贡献者的高可见度（因其 commit 在 freebsd-src 中可查），与 Apple 员工在 Darwin 仓库中的低可见度（因 Darwin 仓库不在 freebsd.duckdb 中）形成对比——此即“权力与知识在历史书写中共谋”在桥梁贡献叙事中的显现。史家须自反地承认：本节对“桥梁稀疏”的书写本身亦是形式主义化的非存在，前理解的差异使分歧不可避免，唯有坦承此局限方能打开裂缝。
