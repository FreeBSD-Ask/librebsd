# 263.5.2 里程碑事件类

### 新闻条目 1

- **新闻标题（中英）**：Brief Thoughts and Observations Regarding Today's WWDC 2016 Keynote / 关于今日 WWDC 2016 主题演讲的简要思考与观察
- **新闻来源**：Daring Fireball + John Gruber + 2016-06-13 + <https://daringfireball.net/2016/06/thoughts_and_observations_wwdc_2016> + <https://web.archive.org/web/2016*/daringfireball.net/2016/06/thoughts_and_observations_wwdc_2016/>
- **新闻摘要**：John Gruber 在 WWDC 2016 主题演讲当日撰文，正式确认 Apple 将 Mac OS X 重命名为 macOS。Gruber 评论称喜欢名称变更，但作为记得经典 Mac 操作系统时代叫 “Mac OS” 的人，对不带空格的 “macOS” 拼写感到不习惯——彼时 “MacOS” 被视作拼写错误。Gruber 同时评述 macOS Sierra 的 Continuity 功能（Auto-Unlock 与 Universal Clipboard）以及 iOS 10 的实用改进。
- **与本章主题的关联说明**：本章核心关注 macOS 10.12-10.15（Sierra 2016-09-20、High Sierra 2017-09-25、Mojave 2018-09-24、Catalina 2019-10-07）四版本演进，重点是 Mac OS X 改名为 macOS。Gruber 的报道是 Mac OS X → macOS 改名事件的关键一手记录，揭示命名变更对长期 Mac 用户的拼写习惯冲击。
- **与官方史料的交叉验证结论**：与 Apple 2016-06-13 WWDC 2016 主题演讲公告 macOS 10.12 Sierra 一致；与 Apple 公布的 macOS 名称采用小写 “m” 一致。Gruber 引述的 “10 亿 Apple 设备” 数据与 Apple 2016 年初公布的活跃设备数一致。

### 新闻条目 2

- **新闻标题（中英）**：The iPhones 8 / iPhone 8 系列
- **新闻来源**：Daring Fireball + John Gruber + 2017-09-19 + <https://daringfireball.net/2017/09/the_iphones_8> + <https://web.archive.org/web/2017*/daringfireball.net/2017/09/the_iphones_8/>
- **新闻摘要**：John Gruber 在 iPhone 8 与 iPhone X 发布会后的评述。同时期 Apple 发布 macOS 10.13 High Sierra（2017-09-25），引入 APFS（Apple File System）作为默认文件系统，从 HFS+ 转向 30 年来首次重大文件系统变更。
- **与本章主题的关联说明**：本章关注 macOS 10.13 High Sierra 2017-09-25 发布。High Sierra 是首个采用 APFS 作为默认文件系统的 macOS 版本，与 iPhone 8 系列同时期发布。
- **与官方史料的交叉验证结论**：与 Apple 2017-06-05 WWDC 主题演讲公告 High Sierra 一致；与 Apple 2017-09-25 High Sierra 发布新闻稿一致；与 Apple Developer 文档记录的 APFS 1.0 在 High Sierra 成为默认一致。

### 新闻条目 3

- **新闻标题（中英）**：The Talk Show Live From WWDC 2019, With Craig Federighi and Greg Joswiak / 2019 WWDC 现场访谈：Craig Federighi 与 Greg Joswiak
- **新闻来源**：Daring Fireball + John Gruber + 2019-06-05 + <https://daringfireball.net/2019/06/the_talk_show_live_from_wwdc_2019> + <https://web.archive.org/web/2019*/daringfireball.net/2019/06/the_talk_show_live_from_wwdc_2019/>
- **新闻摘要**：John Gruber 在 WWDC 2019 主题演讲当晚主持 The Talk Show 播客现场直播，邀请 Apple 软件工程高级副总裁 Craig Federighi 与全球营销副总裁 Greg Joswiak 作为嘉宾。该播客覆盖 WWDC 2019 公告的 macOS 10.15 Catalina（弃 iTunes 转 Apple Music/TV/Podcasts 三应用、Sidecar、Voice Control 等新功能）、iOS 13、iPadOS 13、watchOS 6 等公告。Catalina 是首个完全弃 32 位应用支持的 macOS 主版本。
- **与本章主题的关联说明**：本章关注 macOS 10.15 Catalina 2019-10-07 发布。Catalina 弃 32 位应用是 macOS 历史最大兼容性转折之一，与本章 BSD 用户态生态叙事高度契合。
- **与官方史料的交叉验证结论**：与 Apple 2019-06-03 WWDC 主题演讲公告 Catalina 一致；与 Apple 2019-10-07 Catalina 发布新闻稿一致；与 Apple Developer 文档记录的弃 32 位应用支持一致。
