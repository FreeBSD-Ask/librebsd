# 260.0.7 章级概要

**要点**：本章追溯 BSD 进入 NeXT 的起源——1985 年 Jobs 创立 NeXT 后选择 Mach 2.5 内核与 BSD 4.3 子系统的双层架构（Mach 提供虚拟内存与调度，BSD 提供 UNIX 用户环境），NeXTSTEP 0.9–3.3 的 BSD 子系统随 4.3BSD 到 4.4BSD Lite 演进；Objective-C/AppKit 与 BSD 底层的共生使 NeXTSTEP 成为工作站时代最具工程完整性的 BSD 衍生系统，其遗产经 OpenStep 规范与 1996-12 Apple 收购流入 macOS。

**史料**：Jobs 1985 Playboy 访谈、1995 CRN 访谈、1997 WWDC 演讲（与 Isaacson 传记、1996-12 Apple 收购公告多源互证）；Tevanian 1988 博士论文与 1993 USENIX 论文；Rashid 等 1986 Mach 论文与 CMU-CS-94-146 最终报告；NeXTSTEP 0.9–3.3 设计文档与 release notes；Hubbard 2001-2002 由 FreeBSD 转入 Apple 的招聘公告与 bsdtalk 访谈 ［A］

**史观**：总纲第 4 条——分离聚合是永恒规律：BSD 从伯克利学术谱系经 NeXT 商业化再聚合入 macOS，是代码与人员的多轮分离聚合；总纲第 10 条——动手者创造历史：NeXTSTEP 的 BSD 子系统质量由 Tevanian 等动手者的移植工程决定，而非仅由 Jobs 的产品愿景。

**辨析**：“BSD 走进 NeXT”须区分两条技术线——Mach（卡内基梅隆学术线）与 BSD 4.3（伯克利用户环境线）在 NeXT 的整合并非简单移植；Jobs 个人的叙事权重须与 Tevanian、Bertrand Serlet 等工程师的实际工程贡献平衡；NeXTSTEP 与 macOS 的连续性叙事（Cocoa/AppKit 谱系）不宜反推为 1988 年即有明确设计意图。

**文献**：见文末文献节（Mach 论文、Tevanian 论文、NeXTSTEP release notes、OpenStep 白皮书、Isaacson 传记） ［A］
