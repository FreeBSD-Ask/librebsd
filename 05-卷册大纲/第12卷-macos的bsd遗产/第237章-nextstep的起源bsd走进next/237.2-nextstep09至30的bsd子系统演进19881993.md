# 237.2 NeXTSTEP 0.9 至 3.0 的 BSD 子系统演进（1988-1993）

## 237.2.1 NeXTSTEP 发布线与 BSD 版本对应

**要点**：NeXT Cube 于 **1988 年 10 月 12 日** 在旧金山 Davies Symphony Hall 发布，预装 **NeXTSTEP 0.8**（预览版；0.9 同为 1988 年但非精确落于该发布日）[考据完成：2026-08-04 史实：1988-10-12 发布亮相的是 0.8 预览版，0.9 同为 1988 年但非精确落于该日；存疑 id 1727]；**NeXTSTEP 1.0** 于 **1989 年 9 月 18 日** 正式发布；**NeXTSTEP 2.0** 于 1990 年发布；**NeXTSTEP 3.0** 于 1992 年发布。各版本的 BSD 子系统演进：0.9-1.0 基于 **4.3BSD-Tahoe**（1988 年 6 月发布）用户空间，2.0 升级至 **4.3BSD-Reno**（1990 年发布），3.0 部分吸收 **4.4BSD-Alpha**（1992 年）。其 libc、网络栈、文件系统（UFS）均源自 4.3BSD，并引入 BSD 的 `vfork`、`mmap` 等系统调用接口。Mach 版本：0.9-1.0 使用 **Mach 2.0**，2.0 升级至 **Mach 2.5**（单内核式 Mach + BSD 在同一地址空间），3.0 预览 **Mach 3.0**（真正的微内核架构，BSD 作为用户态服务器）。

  | NeXTSTEP 版本 | 发布日期 | BSD 版本 | Mach 版本 |
  | --- | --- | --- | --- |
  | 0.9（预览版） | 1988-10-12 | 4.3BSD-Tahoe | Mach 2.0 |
  | 1.0 | 1989-09-18 | 4.3BSD-Tahoe | Mach 2.0 |
  | 2.0 | 1990 | 4.3BSD-Reno | Mach 2.5（collocated） |
  | 3.0 | 1992 | 4.4BSD-Alpha | Mach 3.0（预览） |
**史料**：NeXT Computer Inc. NeXTSTEP Reference, Release 0.9 [Z]. NeXT, 1988; NeXT Computer Inc. NeXTSTEP Reference, Release 1.0 [Z]. NeXT, 1989; NeXTSTEP Release Notes 各版本（Stanford University Library, NeXT Inc. Records, M1412, 1985-1996）; CSRG. 4.3BSD-Tahoe Release Notes [Z]. Berkeley: CSRG, 1988。darwin.duckdb 查询 L7.5.1 显示：XNU bsd/vfs/vfs_subr.c（85 commits，2003-08-08 至 2026-06-17）与 bsd/kern/kern_exec.c（83 commits）等 BSD 子系统文件在 XNU 公开源码快照中持续维护，可间接印证 NeXTSTEP 2.0/3.0 时期承袭 4.3BSD-Reno/4.4BSD-Alpha 的 VFS 与 exec 子系统未在后续 Darwin 谱系中废弃。〔L1 代码/构建产物/L3 官方文档与公告〕

**史观**：总纲第 6 条——主体性与和解。NeXTSTEP 的 BSD 层与 SunOS、FreeBSD 同期演进但选择了 Mach 混合内核路线——此即项目史观总纲第六章 “主体性与和解” 的显现：NeXTSTEP 与其他 Unix 系统共享 BSD 根基但发展出不同的主体性（微内核 + 宏内核混合 vs 纯宏内核），既不对立也不可和解，而是 “分离聚合” 的循环。

**辨析**：NeXTSTEP 的 Mach 2.5（单内核式 Mach + BSD 在同一地址空间）与后续 Mach 3.0（微内核，BSD 作为用户态服务器）的架构差异直接影响 later Darwin/XNU 的设计——XNU 至 2024 年仍使用 Mach 3.0 的 “collocated” 模式（Mach 与 BSD 在同一地址空间而非真正的用户态服务器），此设计选择可追溯至 NeXTSTEP 2.0 的 Mach 2.5 架构。NeXTSTEP 各版本的 BSD 版本对应经 Stanford University Library NeXT Inc. Records 档案与 CSRG Release Notes 交叉验证。【0 信任原则·XNU 快照发布局限】darwin.duckdb 查询 L7.5.1 数据仅覆盖 XNU 公开源码快照（2003-08-08 起），无法直接印证 1988-1993 年 NeXTSTEP 0.9-3.0 时期 BSD 版本对应关系；bsd/ 目录文件 last_commit 至 2026-06-17 显示其持续维护，但维护者身份与 NeXT 时期的对应无法从 commit 历史直接追溯。
