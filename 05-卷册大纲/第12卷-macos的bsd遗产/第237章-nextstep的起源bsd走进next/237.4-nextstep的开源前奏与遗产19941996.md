# 237.4 NeXTSTEP 的开源前奏与遗产（1994-1996）

## 237.4.1 OpenStep 规范与 BSD 层抽象

**要点**：**1994 年** **NeXT** 与 **Sun Microsystems** 联合发布 **OpenStep 规范**（Yellow Box/Cocoa 前身），将 NeXTSTEP 的上层 API（**Foundation Kit**、**Application Kit**）抽象为跨平台标准。OpenStep 规范独立于底层操作系统——可在 Solaris、Windows NT、NeXTSTEP 上实现，但底层 BSD 实现仍保留。OpenStep 规范发布后，**NeXTSTEP 3.3**（1995 年发布）成为最后一个以 “NeXTSTEP” 命名的版本，后续版本改名为 **OPENSTEP for Mach**（1996 年）与 **OPENSTEP for Solaris/Windows**。OpenStep 为后续 Darwin 的开放核心埋下伏笔——OpenStep 的规范开放使 Apple 在 1997 年收购 NeXT 后能将 API 层独立于操作系统层授权。

  | OpenStep 实现版本 | 目标平台 | 发布年 | 底层 BSD |
  | --- | --- | --- | --- |
  | OPENSTEP for Mach | NeXT 硬件 | 1996 | 4.3BSD-Reno/4.4BSD-Alpha |
  | OPENSTEP for Solaris | Sun SPARC | 1996 | SunOS 5.x（SVR4 派生） |
  | OPENSTEP for Windows NT | x86 | 1996 | NT 内核（非 BSD） |
  | Yellow Box（后 Cocoa） | Mac OS X | 2000 | Darwin（FreeBSD 派生） |

  > NeXT 与 Sun 于 1994 年联合发布的 OpenStep 规范明确将 API 与底层操作系统解耦，此即 OpenStep specification 所称 “独立于操作系统的面向对象应用框架”。
**史料**：NeXT Computer Inc. & Sun Microsystems Inc. OpenStep Specification [Z]. 1994（NeXT/Sun 联合发布，规范文档存档于 Stanford University Library NeXT Inc. Records）; NeXT Computer Inc. OPENSTEP for Mach Release Notes [Z]. 1996。darwin.duckdb 查询 L7.5.1 显示：XNU bsd/ 目录前 30 文件 commit 历史中，bsd/net/dlil.c（83 commits，2003-08-08 至 2026-06-17）等网络接口层文件持续维护，OpenStep 规范独立于底层操作系统的设计原则在 later Darwin/XNU 的 BSD 网络栈独立演化中得到延续。〔L1 代码/构建产物/L3 官方文档与公告〕

**史观**：总纲第 13 条——法律与道德是利益分配。OpenStep 的规范开放为 later Darwin 开源奠定法律基础——此即 q.md “自由的张力” 的显现：OpenStep 以规范形式（API 定义）开放，但实现仍由 NeXT 控制，此即 “有限消极自由” 的早期形态——API 是 “自由的”（任何人可实现），实现是 “受控的”（NeXT 决定实现细节）。

**辨析**：OpenStep 与 later Apple 的 Cocoa 命名混淆须厘清——Cocoa 即 OpenStep 的 Apple 实现（1997 年 Apple 收购 NeXT 后将 OpenStep API 更名为 Cocoa，2000 年 Mac OS X DP4 首次使用此名称），二者 API 兼容但实现独立。OpenStep 规范本身在 1996 年后由 NeXT/Sun 维护，Apple 收购 NeXT 后未继续维护 OpenStep 商标，但 Cocoa 至 2024 年仍保持 OpenStep API 兼容性。【0 信任原则·XNU 快照发布局限】darwin.duckdb 查询 L7.5.1 数据与 OpenStep 规范（1994 年）的关联仅能通过 BSD 网络栈的持续维护间接印证，XNU 快照无法直接反映 1994-1996 年 OpenStep 规范对 BSD 层抽象的原始影响。

**文献**：NeXT & Sun. OpenStep Specification [Z]. 1994; NeXT Computer Inc. OPENSTEP for Mach Release Notes [Z]. 1996; Apple Computer Inc. Cocoa Application Fundamentals [Z]. Apple Developer Documentation, 2000; darwin.duckdb 查询 L7.5.1 结果 [EB/OL]. 衍生项目与跨项目对比分析.md §L7.5, 2026-07-22.

## 237.4.2 NeXTSTEP 的 WebObjects 与 BSD 服务器角色

**要点**：**NeXT** 发布 **WebObjects 1.0**（基于 NeXTSTEP 的 Objective-C Web 应用服务器框架；发布月份卷内矛盾——本章记 1996-03，第 237.2 节记 1995-12，待 NeXT 原始发布说明确证）[考据完成：2026-08-04 WebObjects 1.0 发布月卷内矛盾（236.4.2=1996-03 vs 237.2=1995-12），穷尽检索未获确证；存疑 id 1726]，使 NeXTSTEP 不仅作为桌面操作系统，还承担 Web 服务器角色。WebObjects 是早期大型商业网站（如 Dell 在线商店、Disney 在线服务）的服务器框架，其底层依赖 NeXTSTEP 的 BSD 网络栈与文件系统。WebObjects 的商业化成功是 Apple **1996 年 12 月 20 日** 收购 NeXT（收购价 4.29 亿美元）的重要估值因素之一。

  | WebObjects 版本 | 发布时间 | 许可证 | 商业用途案例 |

  | WebObjects 3.x | 1997 | 专有商业 | BBC 新闻网站 |
  | WebObjects 4.5 | 1999 | 专有商业 | Apple Store 在线零售 |
  | WebObjects 5.x | 2001 | Java 重写 | Apple Store、iTunes Store |

## 237.4.3 外部贡献者

**要点**：NeXT 工程团队含多位 BSD/Mach 背景工程师——**Avie Tevanian**（CMU Mach 核心开发者，1988 年加入 NeXT，后任 NeXT/Apple 软件工程副总裁）、**Richard Rashid（理查德·拉希德）**（CMU Mach 项目主持人，后任 Microsoft Research 副总裁，未直接加入 NeXT 但其 Mach 研究是 NeXTSTEP 的技术上游）、**Bob Scheifler**（MIT X Window System 开发者，为 NeXTSTEP 的 Display PostScript 提供参考）。CMU Mach 项目（**1985-1994 年**，DARPA 资助）的持续贡献构成 NeXTSTEP 的技术上游——Mach 论文（Accetta 等 1986）是 NeXTSTEP 内核设计的直接学术来源。

**史观**：总纲第 10 条——动手者创造历史。CMU Mach 项目的研究者（包括 Richard Rashid、Avie Tevanian、Brian Bershad、David Golub 等）虽非 “商业 BSD” 贡献者，但在谱系上属于 BSD 学术传统——Mach 基于 4.3BSD 代码构建，其研究者是 BSD 谱系中的 “学术边缘者”。此即 q.md “局外人姿态” 的显现：CMU 研究者不直接参与 BSD 商业生态，但其 Mach 研究通过 NeXTSTEP 进入商业操作系统。

**辨析**：CMU Mach 项目与 CSRG（Berkeley BSD）的关系须厘清——Mach 基于 4.2BSD/4.3BSD 代码构建（Mach 的 BSD 服务组件直接来自 CSRG），但 Mach 项目本身是 DARPA 资助的独立研究项目，非 CSRG 的子项目。此关系使 Mach 既属 BSD 学术传统，又有独立的研究谱系。NeXT 选择 Mach 而非直接使用 CSRG 的 BSD 宏内核，是技术路线选择——微内核架构适配 NeXT 的多线程需求。【0 信任原则·XNU 快照发布局限】darwin.duckdb 查询 L7.5.1 数据无法反映 CMU Mach 项目研究者的个人贡献归属，XNU 快照仅记录文件级 commit 数量，不区分作者；CMU Mach 与 CSRG 的关系须以 CMU 档案与 CSRG Release Notes 为准。
