#### 采访 1：史蒂夫·乔布斯（Steven Paul Jobs）

**字段 2 采访摘要**

乔布斯在 WWDC 2006 主题演讲中预览 Mac OS X 10.5 Leopard 的核心特性——Time Machine 备份（基于 BSD 文件系统的硬链接与目录树快照）、Boot Camp（Intel Mac 双启动，涉及 BSD 引导分区管理），以及 Leopard BSD 子系统向 FreeBSD 6.x 的同步更新。乔布斯亦宣布 Leopard 将是首个完整支持 64 位应用的 Mac OS X 版本。

**字段 3 考据脚注**

本则来自 Apple WWDC 2006 主题演讲录像，Apple Developer 官方存档。乔布斯关于 Leopard BSD 子系统同步 FreeBSD 6.x 的陈述，经 Apple 2007-10-26 Leopard 发布新闻稿与 openbsd.duckdb 查询 L7.5.1 交叉验证。自利偏差审查：乔布斯作为 Apple 首席执行官，其陈述带有 Apple 官方立场。完整考据过程见 [20260724_jobs-wwdc-2006-keynote.md](../../../原材料/研究/考据记录/20260724_jobs-wwdc-2006-keynote.md)。

**字段 5 史观映射**

- 总纲 10“动手者创造历史”：乔布斯在 WWDC 2006 预览 Leopard 的 BSD 子系统更新，展现了“动手者”如何将 FreeBSD 相关记录（详情见存疑库）无论什么时候街道总是需要人去扫”，乔布斯亲自预览 Time Machine、Boot Camp 与 Leopard 64 位支持是“动手去做”的实践。但需自反地看待：乔布斯作为 Apple 首席执行官的商业立场（字段 3 已审查）使其对 Leopard 技术进步的陈述带有 Apple 官方立场，“动手者”不可等同于“商业领袖”——乔布斯既是产品演示者也是 Apple 利益相关者，此辩证性需保留。

- 总纲 4“分离聚合是永恒规律”：Leopard BSD 子系统同步 FreeBSD 6.x 是分离聚合的显现——FreeBSD 6.x 的改进分离至 Darwin，构成 Apple-FreeBSD 代码分合循环的又一节点。据第 25 章总纲 4 原文“UNIX 与 BSD、BSD 各分支之间的分合循环，是历史的根本结构”，Leopard 的 BSD 子系统更新非乔布斯个人创造，而是 BSD 分合循环在 Apple 商业语境中的具体显现。
- 总纲 8“本体论上各方平等”：Apple 与 FreeBSD 社区在 Time Machine 硬链接机制上本体平等——Apple 工程师基于 BSD 文件系统的硬链接实现 Time Machine，FreeBSD 社区提供上游文件系统代码，二者在本体论上无主次之分。据第 25 章总纲 8 原文“FreeBSD、OpenBSD、NetBSD、DragonFly BSD 在本体论上地位相等，差异仅是一刻状态的不同。文档与代码本体平等”，Apple 与 FreeBSD 社区在 Time Machine 实现中的关系亦应作此本体论平等的看待——不可因 Apple 的商业体量而将 Apple 视为“Time Machine 主导”、FreeBSD 社区视为“文件系统附属”。
- 总纲 3“不存在进步，只有权力再分配”：Leopard 的完整 64 位应用支持不是“进步”，而是权力再分配。据第 25 章总纲 3 原文“技术演进不是从低级到高级的进步，而是形式主义的诡异曲线。思想亦不随技术进步”，Leopard 的 64 位完整支持并非“BSD 的进步”，而是 64 位计算在桌面 Unix 中的形式主义化呈现——但需注意项目统摄史观批评的是“进步史观”这一形式主义，而非否定 Leopard 的 64 位工程成就本身。
- 总纲 22“知识注定过时”：Leopard 的 64 位应用支持与 Time Machine 硬链接机制至 2024 年已大幅演化。据第 25 章总纲 22 原文“今天书写的技术史，可能在出版之日就已过时。技术债务是历史遗产”，2007 年 Leopard 的 64 位完整支持至 2024 年已过时（Apple Silicon 时代有新的 64 位 ABI），Time Machine 的硬链接机制亦被 APFS 快照取代——过时的是知识的特定形式主义化形态，而非 64 位计算或备份机制本身。
- 总纲 23“一切历史写作都是基于哲学设定的历史小说”：乔布斯在 WWDC 2006 的陈述并非客观历史，而是其藉由公开演讲书写自身产品故事的姿态。据第 27 章 27.2 节原文“任何理论都只能是形式主义，包括此理论本身”，乔布斯的自述带有自利偏差（字段 3 已审查），史家须以自反姿态打开裂缝——本采访录的写作本身也是形式主义化的非存在，不可呈现为“对 WWDC 2006 的客观正确记录”。
