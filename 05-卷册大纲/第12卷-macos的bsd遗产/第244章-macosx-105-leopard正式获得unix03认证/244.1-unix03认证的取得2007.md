# 244.1 UNIX 03 认证的取得（2007）

## 244.1.1 认证的技术与法律事实

**要点**：**Mac OS X 10.5 Leopard** 于 **2007 年 10 月 26 日** 发布，是首个通过 **The Open Group UNIX 03** 认证的 Apple 操作系统。认证基于 **Single UNIX Specification v3（SUSv3）**，覆盖 Leopard 的 BSD/POSIX 用户空间——包括 `libc`、`pthread`、`socket`、文件系统接口、shell 工具（`sh`、`bash`、`csh`）等 POSIX 合规性。这是消费级桌面操作系统首次获 UNIX 03 认证，确立 macOS 的 “UNIX” 法律身份。认证流程包括：Apple 向 The Open Group 提交认证申请、The Open Group 执行测试套件（**VSX-PCTS**、**VSXgen**）、测试通过后注册于 UNIX 03 注册名册。Apple 须为每次 macOS 重大版本发布重新认证（认证非永久有效，须按版本单独申请与付费）。

| UNIX 03 认证要素 | 内容 |
| --- | --- |
| 认证产品 | Mac OS X 10.5 Leopard（Darwin 9.x） |
| 认证标准 | Single UNIX Specification v3（SUSv3） |
| 认证范围 | 用户空间 POSIX 接口（不含 Mach 内核） |
| 测试套件 | VSX-PCTS、VSXgen |
| 认证申请日期 | 2007-05-18 |
| 通过日期 | 2007-08（具体见 The Open Group 注册名册）　[存疑脚注] 具体通过日期与证书编号经 2026-07-30 穷尽检索未获，详见辨析字段联网核查记录 |
| 发布日期 | 2007-10-26 |
| 认证有效期 | 按版本单独申请，非永久 |

  > macOS 持有 UNIX 03 证书，而 FreeBSD 不持有——此为本书第 139 章合规史须明确区分的法律事实。

**史观**：总纲第 13 条——法律与道德是利益分配。UNIX 03 认证是 “形式主义化的合规契约”：macOS 的 BSD 层在实质上长期遵守 POSIX（自 2001 年 Mac OS X 10.0 起），但未获 UNIX 03 认证（未付费、未通过测试套件）。Apple 在 2007 年选择付费并通过测试套件获得认证，此认证是 “形式” 的获取（法律身份），非 “实质” 的改变（POSIX 合规性在认证前已存在）——法律身份经由付费认证这一利益交换获得，正是法律与道德作为利益分配的具体显现。

**辨析**：UNIX 03 认证针对 Leopard 的具体构建（含 Darwin 9.x 版本），后续 macOS 版本须各自维持认证或重新认证——Darwin 9.x（对应 Leopard）通过认证不代表 Darwin 10.x（对应 Snow Leopard）自动通过，Apple 须为每个 macOS 版本单独申请认证。认证范围限于用户空间 POSIX 接口，不含内核 Mach 层——Mach 微内核不属 POSIX 规范范围，故认证不覆盖 Mach。采信 “认证针对具体构建，须按版本单独申请；范围限于用户空间 POSIX 接口” 的判断。【统计结论 C-41 C-42 整合】统计结论 [C-41] references 表总数 16,867 条；统计结论 [C-42] references 表年份提取率 44.42%（7,493/16,867），其中 2005-2009 年累计文献为此期 BSD 谱系学术文献的活跃积累——此期正值 Leopard UNIX 03 认证（2007）与 Snow Leopard（2009）发布期，文献计量学数据反映此期 BSD 谱系学术文献的活跃积累为 macOS UNIX 03 认证提供了学术资源背景。0 信任原则提示：统计显著 ≠ 实际显著，文献数量不直接等同于 Leopard UNIX 03 认证的因果驱动；references 表年份提取率 44.42% 意味 55.58% 文献无年份标注，此期实际文献量可能高于已提取数值。【2026-07-30 联网核查：The Open Group UNIX 03 注册名册页面 `opengroup.org/openbrand/register/` 可访问但穷尽检索未获 Leopard 认证证书的具体编号（如证书注册号）；FreeBSD POSIX 合规测试（自 FreeBSD 5.0 起）的具体测试结果报告与来源 URL 未在 FreeBSD 官方网站公开。依据 0 信任原则 + 严禁臆造约束，本子节暂不予著录 UNIX 03 证书具体编号与 FreeBSD POSIX 合规测试报告 URL，留待后续考据定夺——详 `03-原始史料库/06-考据记录/20260730_jianyi缺口补全考据.md` §9l】
