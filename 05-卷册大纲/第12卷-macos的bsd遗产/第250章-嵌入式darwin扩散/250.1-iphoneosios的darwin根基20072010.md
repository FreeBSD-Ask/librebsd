# 250.1 iPhone OS/iOS 的 Darwin 根基（2007-2010）

## 250.1.1 iPhone OS 1.0 的 XNU 与 BSD 裁剪

**要点**：Apple 于 **2007 年 1 月 9 日** 在 Macworld San Francisco 公布 iPhone 与 iPhone OS 1.0，**2007 年 6 月** 在美国上市（4GB 版 499 美元、8GB 版 599 美元，独家合作运营商 Cingular，后并入 AT&T）。iPhone OS 1.0 的内核即 XNU（与 Mac OS X 10.4 Tiger 同期），包含 **Mach 3.0 微内核**、**BSD 宏内核子系统** 与 **I/O Kit 驱动框架**——此架构直接承袭自 NeXTSTEP 与 Mac OS X，无独立设计的移动内核。BSD 用户空间为移动设备裁剪：移除多用户登录（`init`、`getty` 桌面服务）、X Window 等桌面组件，强化沙盒与代码签名机制（iPhone OS 1.0 即要求所有应用经 Apple 签名方可执行，此为 Darwin 谱系中首个强制应用签名的版本）。iPhone OS 2.0（**2008 年 7 月 11 日** 随 iPhone 3G 与 App Store 同步发布）引入 SDK 与第三方应用沙盒，BSD 层的 `sandbox_init`、`sandbox_*` 系统调用为应用隔离提供底层支持。

  | iPhone OS 节点 | 日期 | 事件 |
  | --- | --- | --- |
  | Macworld 公布 | 2007-01-09 | iPhone 与 iPhone OS 1.0 |
  | 美国上市 | 2007-06 | 4GB 499 美元、8GB 599 美元 |
  | iPhone OS 2.0 发布 | 2008-07-11 | iPhone 3G + App Store + SDK |

  | iPhone OS 1.0 XNU 组成 | 来源 |
  | --- | --- |
  | **Mach 3.0 微内核** | CMU（1985 年）经 NeXTSTEP 传至 Mac OS X |
  | **BSD 宏内核子系统** | FreeBSD 4.4-Lite + NeXTSTEP BSD 代码（经 Mac OS X 传递） |
  | **I/O Kit 驱动框架** | Apple 自研（基于 Embedded C++） |

  > iPhone OS 的 BSD 层是桌面 Darwin 的裁剪而非新设计——Apple 直接复用 Mac OS X 已验证的 XNU/BSD 架构，未为移动设备从零设计内核。

**史观**：总纲第 2 条——实践先于理论。iPhone OS 的 BSD 层是桌面 Darwin 的裁剪而非新设计，此即项目史观总纲第二章 “历史认识论” 中 “经验优先” 的显现——Apple 直接复用 Mac OS X 已验证的 XNU/BSD 架构，未为移动设备从零设计内核。q.md “道与术的辩证” 在此显现：iPhone OS 的 BSD 层是 “术”（工程复用），Apple 的 “革命性手机” 品牌叙事将其追认为 “道”（重新定义移动计算），但底层是 Darwin/BSD 的工程延续。

**辨析**：iPhone OS 1.0 是否“基于 BSD”须明确——iPhone OS 内核为 XNU（Mach + BSD 子系统），BSD 子系统源自 FreeBSD 4.4-Lite 与 NeXTSTEP 的 BSD 代码（经 Mac OS X 传递），非直接派生自 FreeBSD 6.x（2007 年同期版本）。iPhone OS 1.0 的 BSD 用户空间工具（如 `bash`、`vi`）存在但默认不向用户暴露，须通过非官方越狱方可访问——此即“BSD 层存在但隐藏”的工程选择。Apple 未公开 iPhone OS 1.0 的完整 BSD 子系统版本对应关系，故具体版本号标注 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］。【统计结论 C-41 整合】统计结论 [C-41] references 表总数 16,867 条——iOS/iPadOS/watchOS/tvOS/visionOS 时期（2007-2024）的 BSD 谱系学术文献在 references 表中有对应积累，其中 2005-2024 年累计文献覆盖此期嵌入式 Darwin 扩散全过程；0 信任原则提示：references 表文献数量反映学术关注度，不直接等同于嵌入式 Darwin 扩散的工程影响；iOS/watchOS/tvOS/visionOS 源码不在 darwin.duckdb 中，本时期无直接 Darwin commit 数据可查（数据局限性继承自描述性统计.md 数据局限性总述），仅 macOS 端 Darwin 部分开源可作参照。

## 250.1.2 iOS 4 至 iOS 7 的 BSD 层演进（2010-2013）

**要点**：iPhone OS 于 **2010 年 6 月 21 日** 随 iOS 4.0（iPhone OS 4）更名，iOS 之名正式启用。**iOS 4** 引入多任务（伪多任务，限定 API 后台执行）、FaceTime（基于 SIP 协议，底层 BSD socket）；**iOS 5**（**2011 年 10 月 12 日** 发布）引入 iCloud 与通知中心，底层 BSD socket 与推送通知服务集成；**iOS 6**（**2012 年 9 月 19 日** 发布）移除 Google Maps 改用 Apple Maps，BSD 层的网络栈承担新的地图数据加载；**iOS 7**（**2013 年 9 月 18 日** 发布）全面重设计用户界面，底层 XNU 升级至支持 64 位 ARMv8（随 iPhone 5s A7 芯片首发），此为 Darwin 在移动端的首次 64 位迁移。BSD 层的 `mmap`、`mprotect` 等系统调用为 64 位地址空间管理提供支持。

  | iOS 版本 | 发布日期 | 主要功能 | BSD 层关联 |
  | --- | --- | --- | --- |
  | **iOS 4** | 2010-06-21 | 多任务（伪）、FaceTime | BSD socket（SIP 协议） |
  | **iOS 5** | 2011-10-12 | iCloud、通知中心 | BSD socket + 推送通知 |
  | **iOS 6** | 2012-09-19 | Apple Maps | BSD 网络栈（地图数据加载） |
  | **iOS 7** | 2013-09-18 | 64 位 ARMv8 支持（iPhone 5s A7） | `mmap`/`mprotect` 64 位地址空间 |

  > iOS 4 的 “多任务” 是 API 限制的伪多任务（仅音频、VoIP、定位等特定 API 可后台执行），非 BSD 进程调度的完整多任务——BSD 层的 `fork`、`exec`、`sched_*` 系统调用本身支持完整多任务，iOS 在其上施加了策略限制。

Apple Press Release；Apple Inc. iPhone 5s Technical Specifications [EB/OL]. (2013-09-10). Apple Press Release（A7 芯片与 ARMv8 64 位架构）；Darwin 源码仓库 opensource.apple.com（xnu-2422 系列对应 iOS 7 时期）。〔L1 代码/构建产物/L3 官方文档与公告〕

**史观**：总纲第 25 条——终结中的延续。BSD 核心在移动端延续——iPhone OS 至 iOS 7 的 6 年间，BSD 层未因移动设备资源受限而消失，反而随 64 位迁移扩展其能力。此即项目史观总纲第二十五章的显现：BSD 代码的 “终结”（被 Apple 品牌化）反而成为其在移动端的 “延续” 起点。q.md “数字墓地” 在此显现：iOS 的 BSD 层对普通用户完全不可见，但通过越狱或开发者工具可访问——BSD 层成为 “沉默的数字墓地”，存在但不被言说。

**辨析**：iOS 的多任务实现与桌面 BSD 的多任务实现存在根本差异——iOS 4 的 “多任务” 是 API 限制的伪多任务（仅音频、VoIP、定位等特定 API 可后台执行），非 BSD 进程调度的完整多任务。此差异是 Apple 的工程选择（省电与安全），非 BSD 层的技术限制——BSD 层的 `fork`、`exec`、`sched_*` 系统调用本身支持完整多任务，iOS 在其上施加了策略限制。此判断基于 iOS 4 SDK 文档对后台执行 API 的明确限制描述。

**文献**：Apple Inc. iOS 4 Software Update [EB/OL]. (2010-06-21). Apple Press Release; Apple Inc. iOS Application Programming Guide [Z]. Apple Developer Documentation, 2010-2013; Apple Inc. iPhone 5s Technical Specifications [EB/OL]. (2013-09-10). Apple Press Release.
