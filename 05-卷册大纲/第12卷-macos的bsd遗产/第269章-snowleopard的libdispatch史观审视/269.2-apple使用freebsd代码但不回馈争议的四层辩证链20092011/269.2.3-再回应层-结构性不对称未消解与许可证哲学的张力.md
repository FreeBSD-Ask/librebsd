# 269.2.3 再回应层——结构性不对称未消解与许可证哲学的张力

**要点**：再回应层承认反批评层的合理性（BSD 许可证契约的合法性、APSL 2.0 的自由软件资格、Darwin 源码公开、libdispatch Apache 2.0 开源均属事实），但指出结构性不对称并未因此消解——批判方的核心论点不是“Apple 违反 BSD 许可证”，而是“BSD 许可证允许的结构性不对称在 Apple 案例中具体显现为 FreeBSD 项目长期处于代码流出方而非流入方”。**Free Software Foundation** 在 APSL 2.0 评估中明言"only part of Mac OS X is being released under the APSL. Even though the fatal flaws of the APSL were fixed, and even if the practical problems were addressed, that does no good for the other parts of Mac OS X whose source code is not being released at all"——此即 FSF 对 Apple 商业模式整体封闭性的再回应，承认 APSL 2.0 的改进但不延伸至 Mac OS X 整体。再回应层指出，反批评层所强调的“Apple 实质性回馈”在规模上不足以消解结构性不对称：Darwin 源码公开是 APSL 2.0 强制要求（非 Apple 主动选择），libdispatch 的 Apache 2.0 开源是单个库的选择性让步（非整体商业模式开放），Jordan Hubbard 在 Apple 期间对 FreeBSD 主线的具体贡献须以 freebsd.duckdb 一手数据核验而非以“人才流动”叙事替代［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］。再回应层进一步指出，**Jordan Hubbard 2001 年从 FreeBSD 社区转至 Apple** 本身即是结构性不对称的显现——FreeBSD 失去了一位核心开发者，Apple 获得了一位 Darwin 项目负责人，人才流动方向与代码流动方向一致（FreeBSD→Apple），反向流动（Apple→FreeBSD 主线 commit）稀少。
