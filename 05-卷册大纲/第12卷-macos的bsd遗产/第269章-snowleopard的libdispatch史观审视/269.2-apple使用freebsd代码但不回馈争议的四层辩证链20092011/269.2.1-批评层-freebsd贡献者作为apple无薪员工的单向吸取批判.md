# 269.2.1 批评层——FreeBSD 贡献者作为 Apple“无薪员工”的单向吸取批判

**要点**：Mac OS X 10.6 Snow Leopard 时代（2009-2011）正值 BSD 社区对 Apple 使用 FreeBSD 代码但不回馈的批评集中爆发期。批判方以 FreeBSD 内核开发者 **John Baldwin（约翰·鲍德温）** 与 **Marshall Kirk McKusick（马歇尔·柯克·麦库西克）**（4.3BSD 与 4.4BD 开发者，深度参与 FreeBSD）的公开访谈为主要论据，指出 Apple 长期从 FreeBSD 用户空间吸收代码（如 `libc`、网络栈、`pf` 防火墙、用户空间工具）而仅以 APSL 2.0 选择性发布 Darwin 源代码，且发布位置（**opensource.apple.com** 的 Darwin 仓库与 xnu-1504 系列源码包）独立于 FreeBSD 仓库之外，未通过 FreeBSD 项目的提交审核流程。**John Baldwin** 在 FreeBSD 13.0 发布（2021 年 3 月）的回顾性访谈中明言“相较于 Netflix 等，同样是 FreeBSD 受益者，Apple 为上游做贡献的积极性也不足（因为 BSDL，贡献上游这事就全凭自觉了）”——此判断回溯性地适用于 Snow Leopard 时代。批判方进一步援引“FreeBSD 的贡献者常常被调侃为 Apple 公司的无薪员工”这一长期叙事，指出 Apple 在 Darwin/xnu 中将 FreeBSD 用户空间代码 fork 后独立演化，与 FreeBSD 主线长期脱节。freebsd.duckdb 一手数据印证此批判：freebsd-src 仓库 2009-2011 年间 commit author_email 包含 `@apple.com` 域名的 commit 数量稀少［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］——此即“Apple 工程师未直接向 FreeBSD 主线提交代码”的代码级证据。批判方亦指出，Apple 通过支付版税获得 UNIX 03 认证（The Open Group 注册），但版税流向 The Open Group 而非 FreeBSD 项目，FreeBSD 项目本身未持有 UNIX 03 认证——此即“Apple 从 FreeBSD 代码受益但 FreeBSD 项目未获直接经济回馈”的结构性证据。
