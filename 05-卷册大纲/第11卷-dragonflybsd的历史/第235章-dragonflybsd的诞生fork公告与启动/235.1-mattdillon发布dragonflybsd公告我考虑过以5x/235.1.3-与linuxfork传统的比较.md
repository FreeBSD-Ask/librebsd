# 235.1.3 与 Linux fork 传统的比较

**要点**：DragonFly 是继 1993 年 NetBSD fork 自 386BSD、1995 年 OpenBSD fork 自 NetBSD 之后，BSD 传统的第三次重大内核 fork。Linux 内核虽存在发行版 fork（如 Android 的 Linux 内核分支），但 Linux 内核主线在 Linus Torvalds 治理下从未出现成功分裂为独立内核项目的 fork——Linux 内核 fork 尝试（如 2004 年 Cohorts、2010 年 Linux-libre 移除非自由固件）均未成为独立内核项目。BSD 许可证允许 fork 后无须回馈，GPL 强制回馈，许可证差异是 fork 频率差异的结构性因素之一。BSD 家族三次重大内核 fork 对照如下：

    | fork 事件 | 时间 | 源项目 | fork 后项目 | 首 commit（dragonfly.duckdb 验证） |
    |---|---|---|---|---|
    | NetBSD fork | 1993-04 | 386BSD 0.1 | NetBSD | （386BSD 基线，无独立 commit 数据库记录） |
    | OpenBSD fork | 1995-10-18 | NetBSD 1.0 | OpenBSD | openbsd-src deraadt 首 commit = 1995-10-18T08:37:01Z |
    | DragonFly fork | 2003-06-17 | FreeBSD 4.8-RELEASE | DragonFly BSD | dragonfly-src 首 commit = `984263bcb83a`（2003-06-17T02:57:24Z） |
**史料**：NetBSD 1993.4 fork 公告（Charles Hannum 等 1993.4.8 发布）；OpenBSD 1995.10 fork 公告（Theo de Raadt（西奥·德·若特） 1995.10.18 首 commit in openbsd-src，commit 数据库验证）；Linux 内核 fork 尝试记录（Linux-libre 2010、Cohorts 2004）；openbsd.duckdb openbsd-src 仓库 commits 表 deraadt 首 commit = 1995-10-18T08:37:01Z〔L2 即时通讯记录/L3 官方文档与公告〕

**史观**：总纲第 4 条——分离与聚合：BSD 家族在 1993-2003 年间产生 3 次内核 fork（NetBSD 1993、OpenBSD 1995、DragonFly 2003），Linux 内核同期无成功 fork——BSD 反复分裂、Linux 内核聚合的格局在 1993 年即已奠定，BSD 许可证的宽松性与 GPL 的 copyleft 约束是 fork 频率差异的法律基础

**辨析**：Android 的 Linux 内核分支在法律上是 fork（Android Source Project 维护独立内核分支），但 Android 内核未脱离 Linux 主线社区，定期 rebase 至主线，未成为独立内核项目；DragonFly 则是完全独立的内核项目，与 FreeBSD 主线无 rebase 关系——“成功 fork” 的判定标准须以 “是否成为独立内核项目” 为准；Android 内核 rebase 机制须经 Android Source Project 官方文档核验 [存疑脚注：Android 内核定期 rebase 至 Linux 主线的具体机制与频率须经 Android Source Project 官方文档核验，本轮考据未联网核验]。0 信任原则应用维度：author 字段可伪造（fork 判定标准涉及社区言论属当事人立场，须与 openbsd.duckdb commit 量数据交叉验证）、tagger_date 与实际发布日期可能偏差（OpenBSD fork 首 commit 1995-10-18T08:37:01Z 须经 openbsd.duckdb openbsd-src 仓库核验）、关键词匹配局限（fork 关键词搜索可能遗漏以 “split” “branch” 等同义词为关键词的讨论）。考据留痕至 `03-原始史料库/06-考据记录/20260730_jianyi缺口补全考据.md` 8ao 节
