**字段 2 采访摘要**

DragonFly BSD features 页面陈述项目的“主要特性清单”，包括 KERNEL、EXTREME SCALING、HAMMER 文件系统、NULLFS、TMPFS、DM_TARGET_CRYPT/TCPLAY、SWAPCACHE、VARIANT SYMLINKS、PROCESS CHECKPOINTING、DNTPD、DMA 等。KERNEL 段落陈述 LWKT 调度器与 User Thread Scheduler 的双层抽象：LWKT 用于内核调度所有可执行实体，User Thread Scheduler 为每个 CPU 选择一个用户线程并经 LWKT 调度；二者皆为 per-CPU，但 User Thread Scheduler 从公共可运行进程列表中选择。features 页面是 DragonFly BSD 项目对自身技术路线的官方自我陈述。

**字段 3 考据脚注**

本则 features 页面经联网抓取核实，页面顶部列出 11 项主要特性，KERNEL 段落详述 LWKT 与 User Thread Scheduler 的双层调度抽象。features 页面与 history 页面（**<https://www.dragonflybsd.org/history/>**）共同构成 DragonFly BSD 项目的官方自我陈述。dragonfly.duckdb dragonfly-src 仓库中 LWKT 关键词 commit 2013 年 20 条、2014 年 5 条，反映 LWKT 在 3.x 时期已进入“成熟维护”阶段，features 页面对 LWKT 的陈述是对其历史地位的官方确认。自利偏差审查：features 页面属项目自述，对 LWKT 优势的陈述须以 FreeBSD ULE 调度器文档与第三方 benchmark 加以对照，不得仅凭 features 页面采信“LWKT 优于细粒度锁”的论断。完整考据过程〔存疑：原引 原材料/研究/考据记录/ 下考据文件全库不存在，待补录〕见 20260723_announcements-dragonfly.md 与 20260724_dragonfly-official-features-page.md。

**字段 5 史观映射**

- 总纲 8“本体论上各方平等”——项目史观总纲第 25 章原文“FreeBSD、OpenBSD、NetBSD、DragonFly BSD 在本体论上地位相等，差异仅是一刻状态的不同”。features 页面对 LWKT 路线与 ULE 路线不作“谁对谁错”的道德判断，仅陈述“不同的方向”，与项目统摄史观的本体论平等立场相契。须注意项目统摄史观批评的对象是“以市场占有率或社区规模判定项目价值”的形式主义评判，而主张各技术路线在本体论上地位相等——LWKT 即使在用户基数上远逊于 ULE，其作为调度器设计的本体论地位并不因此降低。
- 总纲 2“历史是形式主义化的非存在”——项目史观总纲第 25 章原文“本书所写皆是当下主体的重构，从不宣称呈现历史本身。人类文明历史发展就是形式主义发展史”。LWKT 的双层调度抽象是“轻量级同步”哲学从理论到工程的形式主义化，features 页面是对这一形式主义化的官方确认。须注意项目统摄史观批评的对象是“将形式主义视为历史本身”的实在论误读，而主张形式主义是人类文明全部——features 页面作为形式主义产物并不因此失真，它就是 DragonFly 技术路线历史本身的样子。
- 总纲 20“历史地理塑造思想土壤”——项目史观总纲第 25 章原文“土地与自由的养分、农耕文明与工商业文明、中心与边缘，皆是形式主义的空间呈现”。features 页面将 DragonFly 的技术特性置于 FreeBSD 4.8 fork 的历史地理土壤中，“major modifications have been made to nearly the entire DragonFly kernel with regard to the original FreeBSD-4.8 fork”一句明示项目的工程起点。须注意项目统摄史观批评的对象是“将地理视为决定性因素”的地理决定论，而主张地理是形式主义的空间呈现之一——DragonFly 自 FreeBSD 4.8 fork 出发，是“中心与边缘”空间呈现的典型：从 FreeBSD 中心组织边缘化为 DragonFly 个人项目。
