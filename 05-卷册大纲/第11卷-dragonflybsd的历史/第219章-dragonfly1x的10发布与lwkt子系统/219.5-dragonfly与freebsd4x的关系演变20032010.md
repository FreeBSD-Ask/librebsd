# 219.5 DragonFly 与 FreeBSD 4.x 的关系演变（2003-2010）——DragonFly 早期 fork 自 FreeBSD 4.x，但随时间推移共享代码越来越少，最终几乎完全独立

## 219.5.1 早期共享代码的范围

**要点**：DragonFly fork 自 FreeBSD 4.8（2003 年），早期共享代码范围包括 VFS 层、网络栈、用户态工具、驱动框架等，Dillon 在 fork 初期尽量保持与 FreeBSD 4.x 的兼容以便回迁改动

**史料**：DragonFly fork 公告；FreeBSD 4.8 release notes；早期 DragonFly commit log 中来自 FreeBSD 4.x 的 MFC 记录；dragonfly.duckdb 查询 L2.4.1.Import from 显示：dragonfly-src 2003 年有 1 条 import commit（“Initial import from FreeBSD RELENG_4”），即 fork 时的初始代码导入；2004 年有 1 条 import commit（“Import from NetBSD: pgrep and pkill utilities”），反映 DragonFly fork 后不仅从 FreeBSD 继承代码，还从 NetBSD 引入用户态工具，体现 BSD 阵营内部的跨项目代码流动 ［A］

**史观**：总纲第 4 条——分离与聚合：DragonFly fork 是分离聚合律的典型——分离之初仍保留大量共享代码，聚合的惯性使二者无法立即完全独立

**辨析**：早期共享代码的精确范围需考据——并非所有 4.x 代码都被继承，Dillon 已在 fork 时进行选择性裁剪；【0 信任原则·关键词匹配局限】L2.4.1 查询以 “Import from” 为关键词，可能遗漏不含此关键词的实际代码导入 commit（如 “MFC from FreeBSD” 或 “Sync with FreeBSD”），实际跨项目代码流动量可能高于统计值

**文献**：DragonFly fork 公告（2003 年 7 月）；FreeBSD 4.8 release notes；DragonFly 早期 commit log；中观模式挖掘.md §L2.4.1.Import from ［A］

## 219.5.2 共享代码的逐渐减少

**要点**：随着 DragonFly 引入 LWKT、token、HAMMER 等自有创新，与 FreeBSD 4.x 的代码差异逐渐扩大；FreeBSD 4.x 在 2007 年 EOL 后，DragonFly 失去上游同步源，共享代码进一步减少

**史料**：DragonFly 各版本 release notes 中关于代码差异的说明；FreeBSD 4.x EOL 公告；DragonFly 邮件列表关于代码差异的讨论 ［A］

**史观**：总纲第 4 条——分离与聚合：共享代码减少是分离律的延续——一旦技术路线分化，代码共享的基础逐渐消失

**辨析**：共享代码减少的速度与时间点需考据——并非线性过程，某些子系统（如驱动）共享时间较长，核心子系统（如调度器）几乎立即分化

**文献**：DragonFly release notes 历年版本；FreeBSD 4.x EOL 公告（2007 年）；DragonFly 邮件列表档案 ［A］

## 219.5.3 与 OpenBSD-NetBSD 分裂后关系的比较

**要点**：OpenBSD 1995 年从 NetBSD fork 后，二者长期保持完全独立的代码库与社区；DragonFly 与 FreeBSD 4.x 的关系演变与之类似，但 DragonFly fork 起点更高（继承自成熟的 4.x），初期共享代码更多

**史料**：OpenBSD fork 历史（1995 年 de Raadt 从 NetBSD fork 公告与邮件列表记录）；NetBSD 与 OpenBSD 早期共享代码记录（netbsd-src 与 openbsd-src 仓库 commit 历史）；DragonFly 与 FreeBSD 4.x 共享代码记录（dragonfly-src 首 commit `984263bcb83a` “Initial import from FreeBSD RELENG_4” 2003-06-17）；dragonfly.duckdb dragonfly-src/netbsd-src/openbsd-src 仓库 commits 表与 commit_files 表（路径 `d:\librebsd\03-原始史料库\01-代码仓库史料\01-数据库本体\`）；DragonFly BSD 邮件列表存档（**<https://www.dragonflybsd.org/mailinglists/**）；DragonFly> BSD Release Notes（**<https://www.dragonflybsd.org/releases/**）；Dillon> fork 公告（**<https://lists.freebsd.org/pipermail/freebsd-current/2003-July/006889.html**）；HAMMER> 设计 PDF（**<https://www.dragonflybsd.org/hammer/hammer.pdf**）[三角验证：openbsd.duckdb> + 邮件列表 + Release Notes] ［A］

**史观**：总纲第 4 条——分离与聚合：BSD 阵营内部的多次 fork（386BSD→FreeBSD/NetBSD、NetBSD→OpenBSD、FreeBSD→DragonFly）都是分离聚合律的体现

**辨析**：每次 fork 的分离速度不同——OpenBSD-NetBSD 因 de Raadt 与 NetBSD Core 的个人冲突而迅速完全分离，DragonFly-FreeBSD 因 Dillon 仍保留部分合作而缓慢分离

**文献**：OpenBSD fork 历史；NetBSD 邮件列表档案；DragonFly 邮件列表档案 ［A］
