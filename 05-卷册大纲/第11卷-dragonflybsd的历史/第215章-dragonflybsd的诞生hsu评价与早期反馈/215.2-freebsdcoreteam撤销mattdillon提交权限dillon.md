# 215.2 FreeBSD Core Team 撤销 Matt Dillon 提交权限——Dillon 1998 年起活跃于 FreeBSD 提交（freebsd-src 首 commit 1998-08-26），技术实力过硬但不擅团队合作

## 215.2.1 撤权决策与程序依据

**要点**：FreeBSD Core Team 依据《Committer's Big List of Rules》（freebsd.org/internal/developers.html）中关于行为规范的条款撤销 Dillon 的提交权限。撤权决定经 Core Team 表决通过，但具体投票记录未在 freebsd.org/administration/ 公开。freebsd.duckdb 显示 Dillon 在 freebsd-src 首 commit 为 1998-08-26（contributors 表核验），末次 commit 为 2003-01-28T18:44:40Z——表明撤权前 Dillon 已实质性停止贡献 4.5 个月

**史料**：《FreeBSD Committer's Big List of Rules》文本（freebsd.org/internal/developers.html）；Core Team 2003 年决议（freebsd.org/administration/，部分公开）；freebsd-hackers 2003 年公告邮件；freebsd.duckdb freebsd-src 仓库 contributors 表 Matt Dillon（<dillon@freebsd.org> 或 <dillon@apollo.backplane.com>，first_commit_date = 1998-08-26，last_commit_date = 2003-01-28T18:44:40Z）

**史观**：总纲第 3 条——不存在进步，只有权力再分配：撤权是社区治理的终极手段——Core Team 依据《Committer's Big List of Rules》撤权，反映 FreeBSD 治理依赖正式规则文本而非个人权威；对比 DragonFly 的 Dillon 个人主导模式（无正式规则文本、无 Core Team 表决），两种治理结构在 “撤权” 机制上截然不同

**辨析**：撤权的具体程序合规性——freebsd.duckdb 不记录权限变动，须以 freebsd-hackers 邮件列表 Core Team 公告为准 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］；**撤权精确日期勘误（2026-08-04）**：Greg Lehey 日记记载撤权发生于 **2003-02-03**（Dillon 在 freebsd-src 末次 commit 为 2003-01-28，二者吻合，佐证撤权前 Dillon 已实质性停止提交约 4.5 个月）；原大纲“2003 年中（存疑）”表述据此订正为 2003-02-03 [考据完成：2026-08-04 Greg Lehey 日记 + freebsd.duckdb contributors 表双源确认]；Dillon 本人对此有不同叙述，dragonfly.kernel 邮件列表 2003-2006 年间多次提及撤权程序不透明，但 Core Team 成员未公开回应

**文献**：FreeBSD. Committer's Big List of Rules [EB/OL]. freebsd.org/internal/developers.html；FreeBSD Core Team. 2003 决议 [EB/OL]. freebsd.org/administration/；freebsd.duckdb freebsd-src 仓库 contributors 表（Dillon 1998-08-26 至 2003-01-28） ［A］

## 215.2.2 撤权后 Dillon 的回应与后续

**要点**：Dillon 对撤权决定公开表示不满，2003-07-16 在 freebsd-current 邮件列表发布 fork 公告。dragonfly.duckdb 提供撤权与 fork 因果关系的时间线——2003-01-28 末次 commit（实质性停止贡献）→ 2003 年中撤权决议（具体日期［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］）→ 2003-06-17 dragonfly-src 首 commit `984263bcb83a`（fork 准备期开始）→ 2003-07-16 fork 公告。撤权直接催生 DragonFly 项目

**史料**：Dillon 2003.7.16 fork 公告邮件（lists.freebsd.org/pipermail/freebsd-current/2003-July/006889.html）；freebsd-hackers 中 Dillon 的回应邮件；dragonfly.duckdb dragonfly-src 仓库 commits 表首 commit = 2003-06-17T02:57:24Z（commit_hash = 984263bcb83a, message_subject = “Initial import from FreeBSD RELENG_4”）

**史观**：总纲第 5 条——没有必然性，只有偶然性：撤权这一偶然事件直接催生 DragonFly——freebsd.duckdb 时间线显示 Dillon 在 freebsd-src 末次 commit（2003-01-28）至 fork 公告（2003-07-16）间 5.5 个月的 “沉默期”，期间 fork 已在酝酿（2003-06-17 dragonfly-src 首 commit 早于公开公告 29 天）；撤权是 fork 的直接导火索，但 fork 准备在撤权后即开始

**辨析**：撤权与 fork 的因果关系——dragonfly.duckdb 显示 dragonfly-src 首 commit（2003-06-17）早于 fork 公告（2003-07-16）29 天，证明 fork 准备在公告前已开始；但 2003-01-28 至 2003-06-17 间 4.5 个月 Dillon 在 freebsd-src 与 dragonfly-src 均无 commit，反映 fork 准备期实际开始于撤权后约 4.5 个月，撤权与 fork 准备之间存在准备间隔

**文献**：Dillon M. Annoucning DragonFly BSD! [EB/OL]. 2003-07-16. lists.freebsd.org/pipermail/freebsd-current/2003-July/006889.html；dragonfly.duckdb dragonfly-src 仓库 commits 表（首 commit 2003-06-17）；FreeBSD Core Team. 2003 声明 [EB/OL] ［A］

## 215.2.3 与同期其他撤权案例的比较

**要点**：BSD 项目中最著名的撤权先例为 1994 年 12 月 Theo de Raadt（西奥·德·若特） 被 NetBSD Core Team 撤权。netbsd.duckdb 提供两者的精确时间对照——de Raadt 在 netbsd-src 末次 commit = 1994-12-17T23:12:41Z（早于 1994.12.23 Adam Glass（亚当·格拉斯） 通知 6 天），在 openbsd-src 首 commit = 1995-10-18T08:37:01Z（fork 后 10 个月方首 commit）；Dillon 在 freebsd-src 末次 commit = 2003-01-28T18:44:40Z，在 dragonfly-src 首 commit = 2003-06-17T02:57:24Z（fork 后 5 个月即首 commit）。两者均为个人主导型开发者被集体治理结构撤权，但 de Raadt 撤权涉及公开人际冲突（Adam Glass 通知、Charles Hannum 站队），Dillon 撤权未见 Core Team 成员公开表态。两次撤权案例对照如下：

    | 维度 | de Raadt（NetBSD → OpenBSD） | Dillon（FreeBSD → DragonFly） |
    |---|---|---|
    | 末次源项目 commit | 1994-12-17T23:12:41Z | 2003-01-28T18:44:40Z |
    | 撤权通知 | 1994-12-23 Adam Glass 通知 | 2003 年中（具体日期 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］） |
    | fork 后项目首 commit | 1995-10-18T08:37:01Z | 2003-06-17T02:57:24Z |
    | 准备期间隔 | 10 个月 | 5 个月 |
    | 撤权涉及公开人际冲突 | 是（Adam Glass、Charles Hannum 站队） | 否（Core Team 成员未公开表态） |
    | fork 后细分市场 | 安全细分市场（pledge/unveil/LibreSSL） | 未建立明确细分市场 |
**史料**：de Raadt 1994.12 撤权邮件（Adam Glass 1994.12.23 通知）；NetBSD Core Team 1994.12 声明；netbsd.duckdb commits 表 deraadt netbsd-src 末次 commit = 1994-12-17T23:12:41Z（commit_hash = 699d2a37b0e3c0c6ff29ea0d407c3feeba5642b4）；openbsd.duckdb commits 表 deraadt openbsd-src 首 commit = 1995-10-18T08:37:01Z；Dillon 2003 撤权邮件

**史观**：总纲第 4 条——分离与聚合：撤权导致分离，分离产生新项目——de Raadt 与 Dillon 均在撤权后 fork 新项目，但 fork 准备期差异显著（de Raadt 10 个月、Dillon 5 个月），反映两人技术准备状态与项目酝酿程度的不同；netbsd.duckdb 显示 de Raadt 在 netbsd-src 末次 commit 至 openbsd-src 首 commit 间隔 10 个月，Dillon 间隔 5 个月

**辨析**：两个案例的可比性须考虑 NetBSD 与 FreeBSD 治理文化差异——NetBSD Core Team 1994 年撤权涉及多名成员公开站队（Adam Glass、Charles Hannum），FreeBSD Core Team 2003 年撤权未见成员公开表态；bsd_commits.duckdb 不记录 Core Team 内部讨论，治理文化差异须以邮件列表公开记录为准

**文献**：de Raadt T. 1994.12 声明 [EB/OL]；NetBSD Core Team. 1994.12 决议 [EB/OL]；netbsd.duckdb commits 表（deraadt netbsd-src 末次 1994-12-17、openbsd-src 首 1995-10-18；Dillon freebsd-src 末次 2003-01-28、dragonfly-src 首 2003-06-17） ［A］

## 215.2.4 Core Team 决议原文与邮件考据

**要点**：Core Team 撤权决议的原文存于 freebsd-hackers 邮件列表 2003 年归档，但完整投票记录未在 freebsd.org/administration/ 公开。Dillon 的回应邮件在 freebsd-current 与 freebsd-hackers 均有存档。dragonfly.duckdb 不记录邮件内容，但 commit message 中 Dillon 的表述可作治理决策的非正式史料

**史料**：freebsd-hackers 2003 年邮件归档（lists.freebsd.org/pipermail/freebsd-hackers/2003/）；Core Team 内部决议（部分公开于 freebsd.org/administration/）；Dillon 回应邮件（lists.freebsd.org/pipermail/freebsd-current/2003-July/006889.html）；dragonfly.duckdb dragonfly-src 仓库 commits 表 Dillon commit message（2003-2006 年）

**史观**：总纲第 13 条——法律与道德是利益分配：社区治理的 “法律” 即规则文本——《Committer's Big List of Rules》作为 FreeBSD 治理的法律基础，其撤权条款的程序合规性是决议有效性的关键；bsd_commits.duckdb 不记录程序合规性，须以 freebsd-hackers 邮件列表与 freebsd.org/administration/ 公开记录为准

**辨析**：决议的完整文本是否已公开——freebsd.org/administration/ 公开 Core Team 决议摘要但未公开完整投票记录，Dillon 在 dragonfly.kernel 邮件列表称程序不透明；正式撰写时须以 freebsd-hackers 邮件列表原始公告与 Core Team 公开声明交叉核对 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］

**文献**：freebsd-hackers 2003 年归档 [EB/OL]；FreeBSD Core Team. 公开声明 [EB/OL]. freebsd.org/administration/；dragonfly.duckdb dragonfly-src 仓库 commits 表（Dillon commit message） ［A］
