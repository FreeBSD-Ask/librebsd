# 242.2.2 SMP 可扩展性改进

**要点**：DragonFly 2.6（2010 年发布）引入 SMP 可扩展性改进，主要在 LWKT 与 token 机制基础上进一步优化多核扩展性，宣称部分场景下线性扩展性优于 FreeBSD 8.x

**史料**：DragonFly 2.6 release notes；SMP 性能 benchmark 邮件；kernel@ 与 users@ 邮件列表讨论；dragonfly.duckdb 查询 L1.1.1 显示：dragonfly-src 2010 年 commit 量 3,081 条，反映 2.6 发布年开发强度 ［A］

**史观**：硬件演进的推动〔订正注：原挂“总纲第 7 条——硬件与软件辩证”系伪标签——权威第 7 条为“理论必须自反”，本条论旨（硬件普及推动工程投入）不在权威条目内，按处方去条号留论旨〕：多核硬件普及推动 DragonFly 在 SMP 可扩展性上的持续投入

**辨析**：benchmark 方法的争议——测试场景选择、硬件配置、测量指标的不同会导致结论差异，需对照独立第三方测试结果；【0 信任原则·commit 量不等于质量】2010 年 commit 量 3,081 条含 SMP 可扩展性改进的 LWKT/token 优化 commit，性能声称须结合独立 benchmark 核验
