# 239.3.1 Linux 内核独裁模式与 fork 失败

**要点**：Linux 内核在 Linus Torvalds 的独裁治理下自 1991 年起 35 年间无成功 fork——主要 fork 尝试包括 GNU Linux-libre（移除非自由固件，1984 哲学差异）、Android AOSP（Google 主导，2005 起，使用 Linux 内核但用户态独立）、linux-next（Stephen Rothwell 维护，集成测试分支非 fork）。Linux 的“不分裂”部分归因于 GPL copyleft 强制回馈（企业贡献回流上游）与 Torvalds 个人权威（“don't break userspace”原则 33 年维持）

**史料**：Linux 内核 fork 尝试记录（kernelnewbies.org/LinuxVersions）；Torvalds 关于 fork 的公开声明（lkml.org 邮件列表存档）；freebsd.duckdb freebsd-src 仓库 tags 表（FreeBSD 5.x-15.x release 序列对照 DragonFly v1.x-v6.4.x）

**史观**：总纲第 3 条——不存在进步只有权力再分配：独裁模式与 fork 倾向的关系——Linux 35 年无成功 fork vs BSD 1996-2003 年间 2 次重大 fork（OpenBSD/DragonFly），差异的原因包括：①GPL copyleft 强制回馈使企业贡献回流 Linux 上游，BSDL 允许企业 fork 后不回馈；②Linux Foundation 2007 年注册提供法律实体支撑，DragonFly 无 Foundation；③Torvalds 33 年单一领导 vs FreeBSD Core Team 9 届换届造成的路线连续性差异

**辨析**：Linux“无成功 fork”是否忽略 Android AOSP——AOSP 使用 Linux 内核但用户态独立，内核层面未 fork，严格意义不属于 Linux 内核 fork；GNU Linux-libre 移除非自由固件但未分化技术路线，属于意识形态分支而非技术 fork；“成功 fork”的判定标准须明确（社区规模、技术分化、独立治理），不得模糊表述。具体争议点：①版本号误载——AOSP 起始年份有 2005 年与 2008 年两种说法（Open Handset Alliance 2007-11 发布 Android SDK 0.1 预览版，2008-09-23 Android 1.0 SDK Release），bsd_commits.duckdb 无 AOSP 仓库 commit 记录，须经 Android Source Project 官方文档核验；②日期差异——Linux-libre 2010 年首发布（由 Alexandre Oliva 维护，FSF Latin America 推广），与 1984 哲学差异表述属意识形态分支而非技术 fork，须以 fsfla.org 邮件列表存档核验；③人物归属分歧——Linux 内核“独裁”治理归因于 Torvalds 个人权威还是 GPL copyleft 法律结构，社区言论属当事人立场，须与 Linux Foundation 治理章程交叉验证 〔存疑：AOSP 起始年份与 Linux-libre 首发布日期未经联网复核〕。0 信任原则应用维度：author 字段可伪造（Linux fork 尝试记录的社区言论属当事人立场，须与 lkml.org 邮件列表存档 committer 字段交叉验证）、tagger_date 与实际发布日期可能偏差（Linux-libre 2010 首发布 tagger 须经 bsd_commits.duckdb 或 fsfla.org 核验，AOSP 早期 tagger_date 须经 Android Source Project 官方 tag 核验）、关键词匹配局限（fork 关键词搜索可能遗漏以 “split” “branch” “divergence” 等同义词为关键词的 lkml.org 邮件讨论，须以邮件列表原文核验）。考据留痕至 `03-原始史料库/06-考据记录/20260730_jianyi缺口补全考据.md` 8av 节
