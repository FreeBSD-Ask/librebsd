# 239.3.4 各项目公开数据与统计考据

**要点**：dragonfly.duckdb 提供 DragonFly/FreeBSD/NetBSD/OpenBSD 四仓库同口径 commits/contributors/tags 表统计（dragonfly-src/freebsd-src/netbsd-src/openbsd-src），是跨项目比较的可靠数据来源。Linux 内核与 illumos 不在 openbsd.duckdb 范围内，须以各自官方仓库（git.kernel.org、github.com/illumos/illumos-gate）核验。各项目统计口径差异主要在 commit 定义（Linux 一次 commit 可能涉及数百文件、BSD 一次 commit 通常涉及数十文件）与分支策略（Linux 主线 vs BSD current/stable 分支）

**史料**：freebsd.duckdb dragonfly-src/freebsd-src/netbsd-src/openbsd-src 仓库 commits/contributors/tags 表（同口径统计对照）；Linux 内核仓库（git.kernel.org）；illumos 仓库（github.com/illumos/illumos-gate）；各项目 Foundation 年报〔L1 代码/构建产物/L3 官方文档与公告〕

**史观**：专题语：统计数据是工程实践的量化史料——illumos-gate.duckdb 提供的同口径统计数据是 BSD 四项目比较的可靠史料来源，对比 Linux/illumos 须考虑仓库差异；统计数据反映项目规模、活跃度、贡献者集中度等工程实践维度

**辨析**：跨项目统计比较的方法论须谨慎——illumos-gate.duckdb 四仓库同口径统计避免苹果与橘子比较，但 Linux/illumos 比较须考虑 commit 定义差异；Foundation 年报数据反映财务状况但非技术活跃度，二者不得混用；illumos-gate.duckdb 不提供下载量、用户数等数据，正式撰写时须以各项目官方统计（如 FreeBSD Foundation 年报下载量、OpenBSD CD 销售量 ［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］）补充
