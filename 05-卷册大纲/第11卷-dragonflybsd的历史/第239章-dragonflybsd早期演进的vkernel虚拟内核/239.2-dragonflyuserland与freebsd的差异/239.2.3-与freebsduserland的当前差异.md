# 239.2.3 与 FreeBSD userland 的当前差异

**要点**：dragonfly.duckdb dragonfly-src 与 freebsd-src 仓库 commits 表显示 2010-2026 年间两仓库 userland 目录（bin/、sbin/、usr.bin/、usr.sbin/）的独立变更路径——DragonFly 移除 sendmail 后引入 DMA（DragonFly Mail Agent）替代、FreeBSD 14.0（2023-11-20 release）移除 bsdinstall 部分组件、DragonFly 6.4.2（2025-05-09）与 FreeBSD 14.x/15.x userland 差异显著。具体差异清单须以两仓库 userland 目录源码 diff 核验

**史料**：dragonfly.duckdb dragonfly-src 与 freebsd-src 仓库 commit_files 表（userland 目录文件 2010-2026 年间变更对照）；dragonfly.duckdb dragonfly-src 仓库 commits 表（DMA 引入 commit）；freebsd.duckdb freebsd-src 仓库 tags 表（FreeBSD 14.0/15.0 release tagger_date）；DragonFly 与 FreeBSD userland 源码 diff〔L1 代码/构建产物/L3 官方文档与公告〕

**史观**：总纲第 4 条——分离聚合是永恒规律：userland 分化反映技术路线的持续分离——DragonFly 选择 DMA 替代 sendmail、FreeBSD 选择继续维护 sendmail 至 14.x 后切换至 dma(8)（不同实现路径），二者在邮件传输代理（MTA）选择上的分化是技术路线分化的具体显现；dragonfly.duckdb 显示两仓库 userland 目录 2010-2026 年间独立演进，无回移 commit 记录

**辨析**：差异的具体清单须逐工具核对——dragonfly.duckdb commit_files 表显示 userland 目录文件变更，但不直接提供两仓库文件 diff，正式撰写时须以 git diff dragonfly-src freebsd-src 命令逐目录核验；DragonFly 与 FreeBSD userland 的具体差异（如 ls/ps/top 等命令行为差异、配置文件格式差异）须以 man.dragonflybsd.org 与 man.freebsd.org 手册页对照核验
