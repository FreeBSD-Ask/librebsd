# 236.2.2 撤权后 Dillon 的回应与后续

**要点**：Dillon 对撤权决定公开表示不满，2003-07-16 在 freebsd-current 邮件列表发布 fork 公告。dragonfly.duckdb 提供撤权与 fork 因果关系的时间线——2003-01-28 末次 commit（实质性停止贡献）→ 2003 年中撤权决议（具体日期［考据注：2026-07-28 联网考据留痕，模板句式已按考据审慎原则精简（WO-004）；语义以正文与所引来源为准］）→ 2003-06-17 dragonfly-src 首 commit `984263bcb83a`（fork 准备期开始）→ 2003-07-16 fork 公告。撤权直接催生 DragonFly 项目

**史料**：Dillon 2003.7.16 fork 公告邮件（lists.freebsd.org/pipermail/freebsd-current/2003-July/006889.html）；freebsd-hackers 中 Dillon 的回应邮件；dragonfly.duckdb dragonfly-src 仓库 commits 表首 commit = 2003-06-17T02:57:24Z（commit_hash = 984263bcb83a, message_subject = “Initial import from FreeBSD RELENG_4”）

**史观**：总纲第 5 条——没有必然性，只有偶然性：撤权这一偶然事件直接催生 DragonFly——freebsd.duckdb 时间线显示 Dillon 在 freebsd-src 末次 commit（2003-01-28）至 fork 公告（2003-07-16）间 5.5 个月的 “沉默期”，期间 fork 已在酝酿（2003-06-17 dragonfly-src 首 commit 早于公开公告 29 天）；撤权是 fork 的直接导火索，但 fork 准备在撤权后即开始

**辨析**：撤权与 fork 的因果关系——dragonfly.duckdb 显示 dragonfly-src 首 commit（2003-06-17）早于 fork 公告（2003-07-16）29 天，证明 fork 准备在公告前已开始；但 2003-01-28 至 2003-06-17 间 4.5 个月 Dillon 在 freebsd-src 与 dragonfly-src 均无 commit，反映 fork 准备期实际开始于撤权后约 4.5 个月，撤权与 fork 准备之间存在准备间隔
