## 236.1.1 fork 周年纪念传统：2003 年从 FreeBSD 4.8 fork 的事件纪念与身份认同建构

**要点**：2003 年 6 月 Matthew Dillon（马修·狄龙） 在 FreeBSD 4.8-STABLE 基础上 fork 出 DragonFly BSD，fork 公告发布于 freebsd-current 邮件列表（<http://lists.freebsd.org/pipermail/freebsd-current/2003-July/006889.html>），项目最初命名 TortoiseBSD 后定名 DragonFly BSD（灵感来自蜻蜓照片，dragonflybsd.org/history/ 展示原始照片）；fork 核心技术动因是 Dillon 与 FreeBSD 核心团队对 FreeBSD 5.x SMP 策略的分歧——Dillon 反对细粒度锁方向，提倡 token 同步机制与消息传递架构；fork 公告明确将项目定位为“FreeBSD 4.x 系列的逻辑延续”；DragonFly BSD 持续发展至 6.4.2（截至 2025-10-03），项目每年在历史页面与社区中纪念 fork 事件，fork 周年是 DragonFly BSD 身份认同的根基；统计结论印证——资料数据库.duckdb doubt_flag 字段卡方检验（统计结论 C-28）显示第八卷存疑率 vol-8（与 vol-1 至 vol-7、vol-9 至 vol-12 同列），12 卷间存疑率分布差异显著（χ² = 229.62 df = 11 p = 5.09e-43 Cramer's V = 0.127 小效应量），反映第八卷 DragonFly BSD fork 与习俗叙事的考据存疑率处于全书 12 卷中游水平

**史料**：DragonFly BSD History 页面（<https://www.dragonflybsd.org/history/>，访问 2026-07-27，原文"DragonFly BSD was forked from FreeBSD 4.8 in June of 2003, by Matthew Dillon. **史观**：总纲第 4 条——分离聚合是永恒规律，DragonFly BSD 从 FreeBSD 4.8 fork 是 BSD 历史中分离聚合律的具体显现，fork 后的 DragonFly 与 FreeBSD 形成两个独立演化的本体；总纲第 5 条——没有必然性，只有偶然性，2003 年 fork 是 Dillon 与 FreeBSD 核心团队分歧累积的偶然结果，而非 BSD 演化的必然路径，替代方案（如 Dillon 留在 FreeBSD 推动 token 机制）的可能性不能被先验排除；总纲第 7 条——理论必须自反，本子节作为 fork 周年纪念传统的考据叙事，自身亦嵌入“fork 即身份建构”的前理解，须自觉呈现这一前理解；总纲第 21 条——革命与改革是历史方法论的分歧，Dillon 选择 fork（革命）而非留在 FreeBSD 推动改革，是 BSD 历史中革命与改革张力的具体显现，与 FreeBSD 5.x 内部改革路线形成对照；总纲第 23 条——一切历史写作都是基于哲学设定的历史小说，“fork 周年是 DragonFly BSD 身份认同的根基”等文化意义叙事是史家基于当下史料的形式主义建构

## 236.1.2 Matt Dillon 邮件长文传统：设计文档邮件长文与架构叙事的工程文化

**要点**：Matthew Dillon 自 2003 年 fork 起即在 DragonFly BSD 邮件列表（lists.dragonflybsd.org）持续发布长篇设计文档邮件，涵盖 kernel 子系统重写、token 同步机制、SMP 扩展、HAMMER/HAMMER2 文件系统设计等议题；这种“邮件长文”风格是 Dillon 的个人标志，将设计决策完整记录于邮件存档；Dillon 风格更偏架构叙事（讨论设计哲学与多版方案演化），与 Linux LKML 的 patch 中心文化、OpenBSD <tech@openbsd.org> 的简洁风格形成三重对照；截至 2026-07-27 Dillon 持续在 DragonFly BSD 邮件列表主导架构讨论，邮件长文是 DragonFly BSD 设计决策的核心载体，将 BSD 传统的“设计文档公开”推至极致

**史料**：DragonFly BSD 邮件列表（<https://lists.dragonflybsd.org/>，访问 2026-07-27）；2003-07 fork 公告邮件（<http://lists.freebsd.org/pipermail/freebsd-current/2003-July/006889.html>，引用自 DragonFly BSD history 页）；dragonfly.duckdb dragonflybsd-src 仓库 Dillon 邮箱 commit 序列（提交者 <dillon@dragonflybsd.org>，须以仓库实际历史核验） ［A］
