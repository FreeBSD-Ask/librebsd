# 251.1.3 与 FreeBSD 12.x 技术进展的比较

**要点**：bsd_commits.duckdb 显示 2017-2021 年间四仓库 commit 量对照如下：

    | 年份 | freebsd-src | dragonfly-src | 比值 |
    |---|---|---|---|
    | 2017 | 16157 | 1888 | 8.6 倍 |
    | 2018 | 14985 | 1709 | 8.8 倍 |
    | 2019 | 14273 | 1962 | 7.3 倍 |
    | 2020 | 14203 | 1585 | 9.0 倍 |
    | 2021 | 18043 | 946 | 19.1 倍 |
    FreeBSD 12.x（2018-2021）引入对 64-bit ARM 的 Tier-1 支持、改进 bhyve、改进无线网络栈等；DragonFly 5.0/5.2 在 AMD64 与 NVMe 改进上有局部进展，但 dragonfly.duckdb 显示 commit 量仅为 FreeBSD 同期约 11.7%-13.8%，整体生态与硬件支持仍落后
**史料**：dragonfly.duckdb 查询 L1.1.1 显示：dragonfly-src 2017 年 commit 量 1,888 条，2018 年 1,709 条，2019 年 1,962 条，2020 年 1,585 条，2021 年 946 条（5.x 时代整体下降趋势，2021 年跌破 1,000 条）；FreeBSD 12.x release notes；DragonFly 5.0/5.2 release notes

**史观**：总纲第 4 条——分离聚合是永恒规律〔订正：原挂“总纲第 6 条——技术路线分化”系伪标签，权威第 6 条为“和解优于斗争”，依核查报告按分化论旨改挂第 4 条〕：dragonfly.duckdb 数据显示 FreeBSD 与 DragonFly 在硬件支持广度上的分化持续加深——FreeBSD 2017-2021 年间年均 commit 量约 15532 条，DragonFly 同期年均约 1618 条，FreeBSD 是 DragonFly 的 9.6 倍

**辨析**：技术比较须结合项目目标——dragonfly.duckdb 显示 commit 量差距显著，但 FreeBSD 追求主流服务器市场（Tier-1 ARM64、bhyve、Kunai 调度器），DragonFly 追求轻量级内核哲学（LWKT/HAMMER/vkernel），无简单优劣关系；FreeBSD 12.x 的 64-bit ARM Tier-1 支持为其进入 ARM 服务器市场奠定基础，DragonFly 5.x 同期专注 x86-64，未进入 ARM 市场；【0 信任原则·commit 量不等于质量】dragonfly-src 2021 年 commit 量 946 条为 5.x 时代谷值，但 v6.0.0（2021-05-07）仍发布 SMP 与 LWKT 改进，反映 commit 量下降不等于开发停滞 [存疑脚注：FreeBSD 12.x ARM64 Tier-1 分级须以 FreeBSD 官方平台文档核验，本轮考据未联网核验]。0 信任原则应用维度：author 字段可伪造（FreeBSD 与 DragonFly commit 量比较须以各自仓库 committer 字段交叉验证）、tagger_date 与实际发布日期可能偏差（v5.0.0-v6.0.0 tagger 均为 Sherrill，须与 Release Notes 互参）、关键词匹配局限（commit 量比较含不同类型 commit，须以 commit_files 表细分核验）。考据留痕至 `03-原始史料库/06-考据记录/20260730_jianyi缺口补全考据.md` 8af 节
