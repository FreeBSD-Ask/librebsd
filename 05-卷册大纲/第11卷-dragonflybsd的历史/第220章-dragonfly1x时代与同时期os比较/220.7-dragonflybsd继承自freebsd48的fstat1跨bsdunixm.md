# 220.7 DragonFly BSD 继承自 FreeBSD 4.8 的 fstat(1)（跨 BSD/UNIX/macOS 扩展）

## 220.7.1 fstat 的 fork 时刻定格与 kvm(3) 路径保留

**要点**：DragonFly BSD 自 fork 自 FreeBSD 4.8（**2003-06-20**）起继承 **fstat(1)** 命令，源码位于 **sbin/fstat/** 目录——此实现未跟随 FreeBSD 5.0 后的 kvm(3) 重构，保留了 4.x 时代的实现路径。**fstat(1)** 在 DragonFly BSD 中保留至今，与 FreeBSD fstat 在 fork 时刻完全同源。

**史料**：DragonFly BSD src 仓库 **sbin/fstat/**；**fstat(1)** man page（man.dragonflybsd.org）；DragonFly BSD 1.0 Release Notes；Dillon, M. (2003). *DragonFly BSD Design Goals*.〔L1 代码/构建产物/L3 官方文档与公告〕

**史观**：总纲第 1 条——源头时刻：DragonFly BSD fork 时“冻结”了 fstat 的 4.x 实现；总纲第 2 条——分离与聚合：DragonFly BSD 从 FreeBSD 分离时聚合了 fstat 命令；技术选择的代价：DragonFly BSD 选择保留 4.x fstat 而非跟随 FreeBSD 5.0 kvm(3) 重构，付出代码路径分叉代价，但获得实现稳定性；总纲第 10 条——边缘者贡献：fstat 的最初设计者被遮蔽，Dillon 的 fork 决策是边缘者贡献的显现；总纲第 17 条——形式与内容：fstat 作为“形式”（文件描述符列表）保留了 4.4BSD-Lite2 的“内容”；自反性声明：本释读不预设“DragonFly BSD 中心论”——fstat 在 NetBSD、OpenBSD、FreeBSD 均有保留或演化。

**辨析**：DragonFly BSD fstat 与 FreeBSD 5.0+ fstat 在 fork 时刻同源，分叉发生在 FreeBSD 5.0 kvm(3) 重构后；与 Linux lsof 无代码共享。

**文献**：DragonFly BSD Project. *DragonFly BSD 1.0 Release Notes*[EB/OL]. (2005-07-24). <https://www.dragonflybsd.org/>; DragonFly BSD Project. *fstat(1) Manual Page*[EB/OL]. <https://man.dragonflybsd.org/>.
