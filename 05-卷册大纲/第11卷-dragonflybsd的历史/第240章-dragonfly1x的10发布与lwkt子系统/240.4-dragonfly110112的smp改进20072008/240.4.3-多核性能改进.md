# 240.4.3 多核性能改进

**要点**：DragonFly 1.12（2008.4）改进多核性能——token 机制优化、LWKT 调度器扩展；改进让 DragonFly 在 4-8 核基准测试中表现提升；改进仍基于 LWKT 消息传递与 token 同步路径

**史料**：DragonFly 1.12 Release Notes SMP 部分；DragonFly 邮件列表 SMP 讨论；CVS commit log ［A］

**史观**：软件工程：多核性能改进是 LWKT 与 token 工程哲学的持续实践

**辨析**：多核性能改进的具体数字在不同基准测试中差异较大——需对照同硬件同负载核验

**文献**：DragonFly Release Notes；DragonFly 邮件列表档案；CVS commit log ［A］
