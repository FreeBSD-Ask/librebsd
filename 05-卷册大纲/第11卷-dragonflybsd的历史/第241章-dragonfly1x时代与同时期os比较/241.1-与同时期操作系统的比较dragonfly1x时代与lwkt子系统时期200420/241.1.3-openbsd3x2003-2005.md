# 241.1.3 OpenBSD 3.x（2003-2005）

**要点**：OpenBSD 在 DragonFly 1.x 同期为 3.x（2003-2005），以安全审计与稳定著称，SMP 支持有限；与 DragonFly 1.x 的 LWKT 并发实验对照——OpenBSD 3.x 专注安全而非并发创新，DragonFly 1.x 押注 LWKT。

**史料**：OpenBSD 3.x 发布说明（含 3.4-4.3 Release Notes，Big Lock 简化保守路径）；DragonFly 1.x 史料；dragonfly.duckdb dragonfly-src 仓库 commits 表与 commit_files 表（路径 `03-原始史料库/01-代码仓库史料/05-DragonFlyBSD/db/duckdb/〔原引 01-数据库本体 路径断链，订正〕`）；DragonFly BSD 邮件列表存档（<https://www.dragonflybsd.org/mailinglists/>）；**DragonFly> BSD Release Notes（<https://www.dragonflybsd.org/releases/>）；**Dillon> fork 公告（<https://lists.freebsd.org/pipermail/freebsd-current/2003-July/006889.html>）；**HAMMER> 设计 PDF（<https://www.dragonflybsd.org/hammer/hammer.pdf>）**[三角验证：dragonfly.duckdb> + 邮件列表 + Release Notes 三类来源互参] ［B］

**史观**：总纲第 4 条——分离聚合是永恒规律：OpenBSD 与 DragonFly 同期演进，安全 vs 并发实验目标分化。

**辨析**：OpenBSD 3.x 的 SMP 保守，DragonFly 1.x 的 LWKT 前瞻，体现家族路线多元。具体争议点：1) OpenBSD 3.x SMP “保守” 的判定须以 OpenBSD 官方 Release Notes 与设计文档核验，部分二手来源将 “Big Lock 简化” 简化为 “无 SMP 创新” 属误读 [存疑脚注：OpenBSD 3.x SMP 保守路径的具体实现细节待以 OpenBSD 官方文档核验]；2) DragonFly 1.x “前瞻” 判定须警惕目的论叙事——LWKT 路径后续未获主流采纳，“前瞻” 不等于 “成功”。0 信任原则应用维度：author 字段可伪造、tagger_date 与实际发布日期可能偏差、“保守 vs 前瞻” 的价值判断须以项目目标（安全 vs 并发）而非统一标准衡量。考据记录归档至 `d:\librebsd\03-原始史料库\06-考据记录\20260730_jianyi缺口补全考据.md` 8k 节。
