# 233.7 DragonFly BSD 学术研究统计结论印证

**要点**：**统计结论 C-41**——文献计量学分析.md Task 22 显示本项目 `references` 表共收录 **16,867** 条参考文献，其中 DragonFly BSD 主题占比极低（dragonflybsd.org 域名在 materials 表 Top 50 来源域名中排名第 24 位，仅 2 条记录，占 0.7937%）；**统计结论 C-42**——同一报告显示 references 表年份提取率 **44.42%**（7,493/16,867），反映本项目参考文献的时序元数据完整性不足，DragonFly BSD 主题文献因总量稀少在此提取率限制下可分析样本更少；**统计结论 E-18**——外部基准-Academic-CVE.md 第 1.2.1 节显示 arXiv 官方 API 查询 `all:DragonFlyBSD` 仅 **1** 篇预印本（Kudrjavets et al., 2022，同时涉及四个 BSD 项目）；**统计结论 E-19**——同一报告显示 dblp 官方 API 查询 `q=DragonFly BSD` 返回 **0** 篇正式发表文献，DragonFly BSD 是四大 BSD 中唯一在 dblp 无正式发表文献的项目。四项统计结论交叉印证 DragonFly BSD 在学术界与本项目参考文献库中的双重边缘地位。

**史料**：**统计结论 C-41**——文献计量学分析.md Task 22 显示 references 表总数 16,867 条；**统计结论 C-42**——同一报告显示 references 表年份提取率 44.42%（7,493/16,867）；**统计结论 E-18**——外部基准-Academic-CVE.md 第 1.2.1 节显示 arXiv `all:DragonFlyBSD` 查询返回 1 篇预印本（Kudrjavets et al., 2022, `arxiv.org/abs/2206.05616`）；**统计结论 E-19**——同一报告显示 dblp `q=DragonFly BSD` 查询返回 0 篇正式发表文献（对比 FreeBSD 74 篇、OpenBSD 20 篇、NetBSD 15 篇、Linux 2802 篇）［ 查证来源：arXiv 官方 API（`export.arxiv.org/api/query`）与 dblp 官方 API（`dblp.org/search/publ/api`）经三次独立查询交叉验证；交叉验证方法：arXiv API 三关键词并行查询 + dblp 扩展关键词交叉验证 + dblp 年度分布全量拉取，三次查询关键词、URL 列表、WebFetch 获取页面已写入外部基准-Academic-CVE.md 第 1.1 节；存疑判定依据：IEEE Xplore 与 ACM DL 无公开 API，搜索结果页动态渲染，无法通过 WebFetch 直接获取精确总数，故定量主源以 arXiv 与 dblp 为准；Google Scholar 与 Semantic Scholar 在 2026-07-27 时点触发反机器人验证或限流（HTTP 429），无法交叉验证 ］〔L5 二手研究〕

**史观**：第 14 章边缘者贡献：DragonFly BSD 在学术界与本项目参考文献库中的双重边缘地位是 “边缘者贡献被主流叙事吞没” 的具体显现——dblp 0 篇正式发表文献意味着 DragonFly BSD 的技术演进未进入计算机科学正式学术文献体系，对比 FreeBSD 74 篇、OpenBSD 20 篇、NetBSD 15 篇，DragonFly BSD 是四大 BSD 中唯一在 dblp 无正式发表文献的项目；总纲第 10 条——动手者创造历史：DragonFly BSD 的技术演进主要通过 Dillon 个人设计文档（HAMMER/HAMMER2 设计文档）、邮件列表存档与 BSD 主题专业会议演讲记录传承，而非同行评审学术论文，这一文献分布形态反映 “动手者” 与 “言说者” 的分化——Dillon 作为动手者直接以 commit 与设计文档推进技术演进，而非以学术论文阐释技术决策

**辨析**：【统计显著 ≠ 实际显著·E-18/E-19 局限】arXiv 1 篇与 dblp 0 篇的统计结果反映 DragonFly BSD 在主流学术文献库中的覆盖稀薄，但 “学术文献稀薄” 不等于 “技术价值低”——DragonFly 的 LWKT 消息传递架构、HAMMER/HAMMER2 写时复制文件系统、vkernel 用户态虚拟化在 BSD 阵营中具有不可替代性，学术文献稀薄可能反映学术界的关注偏差而非技术本身的缺陷；【数据库覆盖局限】arXiv 主要收录 CS/物理/数学预印本，BSD 操作系统研究多在会议正式发表而非预印本；dblp 仅收录计算机科学领域正式发表的期刊与会议论文，不收录预印本、学位论文、技术报告、博客文章——故 arXiv 1 篇与 dblp 0 篇的组合仍可能遗漏 DragonFly BSD 相关的学位论文、技术报告与 BSD 主题专业会议演讲（如 AsiaBSDCon、USENIX BSD Track、NYCBSDCon 等非 dblp 索引会议）；【样本量极小】E-18 arXiv 仅 1 篇预印本且同时涉及四个 BSD 项目（非 DragonFly BSD 专题），样本量过小不支持统计推断；【C-41/C-42 references 表的局限】references 表 16,867 条文献中 DragonFly BSD 主题占比极低（dragonflybsd.org 域名仅 2 条记录），但 references 表的文献收录本身存在选择性偏差（本项目编纂团队的文献检索策略决定收录范围），不得以 references 表占比推演 DragonFly BSD 在全局学术文献中的实际占比；【多重比较风险】C-41/C-42 与 E-18/E-19 同源本项目 references 表与外部学术数据库，但统计结论相互独立，多重比较风险较低
