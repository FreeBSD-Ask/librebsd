# 354.2.5 /usr/src/、/usr/obj/、/usr/local/、/usr/pkg/ 目录传统：BSD hier(7) 目录层次与工程纪律

  **要点**：/usr/src/ 自 4.2BSD（1983 年）起为源码目录；/usr/obj/ 为构建产物目录；/usr/local/ 为本地安装目录自 4.4BSD 标准化；/usr/pkg/ 为 NetBSD pkgsrc 默认安装前缀；BSD 目录层次（hier(7)）严格定义各目录用途——/usr/src/ 为系统源码（内核与基本系统）、/usr/obj/ 为构建 /usr/src/ 的中间产物（make obj 后产生）、/usr/local/ 为本地编译软件安装前缀（FreeBSD ports 默认前缀）、/usr/pkg/ 为 NetBSD pkgsrc 默认前缀（避免与 /usr/local 冲突）、/usr/ports/ 为 FreeBSD ports 树；所有 BSD 系统遵循 hier(7) 标准；DragonFly BSD 使用 /usr/local/（DPorts 基于 FreeBSD ports），NetBSD 使用 /usr/pkg/；清晰的目录层次是 BSD 工程纪律的体现，使系统构建可重复、可维护
  **史料**：FreeBSD hier(7) man page（<https://man.freebsd.org/cgi/man.cgi?query=hier&sektion=7>，访问 2026-07-27）；NetBSD hier(7) man page（<https://man.netbsd.org/hier.7>，访问 2026-07-27）；OpenBSD hier(7) man page（<https://man.openbsd.org/hier.7>，访问 2026-07-27）；NetBSD pkgsrc 文档说明 /usr/pkg/ 默认前缀（<https://www.netbsd.org/docs/software/packages.html>，访问 2026-07-27） ［A］
  **史观**：总纲第 9 条——经验优先，hier(7) 目录层次是工程实践的具体沉淀，每个目录（/usr/src/、/usr/obj/、/usr/local/、/usr/pkg/）皆源于实际构建与安装需求；总纲第 4 条——分离聚合是永恒规律，BSD 目录层次从 4.2BSD 与 4.4BSD 聚合至四大 BSD 分支，是分离聚合律的具体显现；总纲第 7 条——理论必须自反，本子节作为 BSD 目录层次传统的考据叙事，自身亦嵌入 “清晰即工程善” 的前理解，须自觉呈现这一前理解；总纲第 8 条——本体论上各方平等，/usr/local/（FreeBSD ports）与 /usr/pkg/（NetBSD pkgsrc）在本体论上地位相等，差异仅是一刻状态的不同；总纲第 23 条——一切历史写作都是基于哲学设定的历史小说，“清晰的目录层次是 BSD 工程纪律的体现” 等文化意义叙事是史家基于当下史料的形式主义建构
  **辨析**：考据过程留痕——【查证来源】FreeBSD hier(7) man page 经 man.freebsd.org 一手核验；NetBSD hier(7) man page 经 man.netbsd.org/hier.7 一手核验；OpenBSD hier(7) man page 经 man.openbsd.org/hier.7 一手核验；NetBSD pkgsrc 文档经 netbsd.org/docs/software/packages.html 一手核验，确认 /usr/pkg/ 默认前缀；【交叉验证方法】各目录的演化时点（/usr/src/ 4.2BSD 1983、/usr/local/ 4.4BSD 标准化、/usr/pkg/ NetBSD pkgsrc 默认）须以各 BSD 版本 hier(7) man page 与 release notes 互证；FreeBSD ports 与 NetBSD pkgsrc 的目录前缀差异须以 Porter's Handbook 与 pkgsrc 文档互证；【0 信任原则·“/usr/src/ 自 4.2BSD 1983 年起为源码目录”】“/usr/src/ 自 4.2BSD（1983 年）起为源码目录” 的考据须以 4.2BSD 源码或 hier(7) man page 核验，本考据以既有学术文献为间接依据；【0 信任原则·“/usr/local/ 自 4.4BSD 标准化”】“/usr/local/ 为本地安装目录自 4.4BSD 标准化” 的考据须以 4.4BSD hier(7) man page 核验，本考据以既有学术文献为间接依据；【0 信任原则·“/usr/pkg/ 为 NetBSD pkgsrc 默认前缀”】NetBSD pkgsrc 默认前缀为 /usr/pkg/ 的考据以 NetBSD 官方文档为依据，但 pkgsrc 在非 NetBSD 平台的默认前缀可能不同（如 /usr/local/pkgsrc 或 /opt/pkgsrc），须以 pkgsrc 文档核验；【与同类 UNIX/BSD 习俗对比】Linux FHS（Filesystem Hierarchy Standard）与 BSD hier(7) 在多数目录上一致，但 /usr/pkg/ 为 NetBSD 独有；/usr/obj/ 在 Linux 较少使用；illumos 与 Solaris 有类似但不完全相同的目录传统；【自反性声明】本子节作为 BSD 目录层次传统的考据叙事，自身嵌入 “清晰即工程善” 的前理解，实际 hier(7) 标准的执行情况（如各 BSD 项目的实际目录结构差异、与现代容器化与系统更新的兼容性）须以多源交叉验证逼近史实
