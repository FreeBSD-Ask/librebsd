# 4.1.1 Pascal 系统的移植工程

<!-- MAIL_INSIGHT: ucbvax.4061 -->
**观点**：1981年 comp.unix.wizards 有人询问是否存在复用 Portable C Compiler 代码生成器的 Pascal 实现，反映 Pascal 与 C 编译基础设施在 UNIX 上的同源关系。
**邮件来源**：Schauble（MIT-Multics），comp.unix.wizards，1981年9月，Message-ID: `ucbvax.4061`
**史学意义**：提示 pcc 不仅是 C 的编译后端，也成为其他语言移植的公共基础设施，是理解 BSD 语言移植无名工程的线索。
<!-- /MAIL_INSIGHT -->

<!-- MAIL_INSIGHT: ucbvax.3005 -->
**观点**：1981年 Mark Horton 指出 Berkeley Pascal 中的 mark 与 release 是非标准 hack，仅存在于 P 系列编译器中，逊于标准 dispose。
**邮件来源**：Mark Horton（cbosgd!mark），comp.unix.wizards，1981年9月，Message-ID: `ucbvax.3005`
**史学意义**：反映 Berkeley Pascal 的实用主义取舍，也为 Wirth 学派“结构化理想”在 BSD 现实中被折中提供了注脚。
