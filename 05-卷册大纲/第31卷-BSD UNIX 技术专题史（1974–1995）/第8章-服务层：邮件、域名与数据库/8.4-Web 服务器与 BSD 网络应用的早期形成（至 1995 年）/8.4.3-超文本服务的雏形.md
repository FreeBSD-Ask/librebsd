# 8.4.3 超文本服务的雏形

<!-- MAIL_INSIGHT: 2ldqjk$sc2@bigfoot.wustl.edu -->
**观点**：1994 年 3 月，华盛顿大学的 G. H. Chinoy 回复南非用户提问，介绍 NCSA Mosaic 是 “World Wide Web 浏览器”，并确认这类程序可以在 NetBSD 或 FreeBSD 平台上运行。
**邮件来源**：G. H. Chinoy，comp.unix.bsd，1994 年 3 月，Message-ID: `2ldqjk$sc2@bigfoot.wustl.edu`
**史学意义**：跨国问答把“能否在 NetBSD/FreeBSD 上跑 Mosaic”当作常识性问题处理，说明自由 BSD 分支在万维网普及之初即被默认纳入浏览器可用平台之列。
