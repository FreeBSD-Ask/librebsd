## 二、缺失清单（现状 → 应为 → 依据 → 建议节题）

1. **现状**：稿件若把 OpenBSD 参与 GSoC 的系年写成 2011 或更早/更晚。
   **应为**：OpenBSD 项目方以“The OpenBSD Foundation”法人身份首次、且主要一次于 **2014 年**参与，**5 个名额／5 名学生**；2010–2013 无 OpenBSD 组织入选记录；2015 年基金会官网另记 5 名学生（跨段，交 A3）。
   **依据**：OpenBSD Foundation activities 页；undeadly systembsd 学生自述；OpenNet 2014 名单。
   **建议节题**：《2014：OpenBSD Foundation 首次踏入 GSoC 与 systembsd 的来历》。

2. **现状**：稿件若把 illumos 参与写成“2011 年一现”。
   **应为**：**2011 首参与（2 学生）→ 2012 组织在列（项目级未确证）→ 2013 未获确证 → 2014 组织在列但 0 项目**。
   **依据**：Google 官方博客（2011）；OpenNet 2012 名单；iCHAIT gist 2014（illumos＝0）。
   **建议节题**：《illumos 的 GSoC：一年高光与随后的沉寂》。

3. **现状**：稿件若把 2014 写成“BSD 全家福”。
   **应为**：2014 是 BSD 系落差年——**NetBSD 与 DragonFly 双双落选**，仅 FreeBSD／OpenBSD Foundation／illumos 在列，且 illumos 零项目。
   **依据**：NetBSD 官方 soc-projects 参与年表（2005–2013、2016–，无 2014/2015）；OpenNet 2014 名单；DragonFly 2013 后无 2014 记录。
   **建议节题**：《2014：BSD 阵营在 GSoC 的收缩》。

4. **现状**：稿件若缺少 NetBSD 计年。
   **应为**：NetBSD 连续参与 **2005–2013**，**2014–2015 中断**，**2016 复归**。
   **依据**：NetBSD 官方贡献页 https://www.netbsd.mirror.si/contrib/soc-projects.html 所列年份。
   **建议节题**：《NetBSD 的十年连线与 2014 断裂》。

5. **现状**：稿件若缺 DragonFly 计年。
   **应为**：DragonFly **2008–2013** 连续参与（其自称 2013 为第 6 次），**2014 起落选**。
   **依据**：DragonFly ikiwiki 声明；各年 Digest；OpenNet 2014。
   **建议节题**：《DragonFly：小项目的大夏天及其退场》。

## 三、存疑清单（续任务书 §六 C 清单，从 ⑮ 起；与既有 ①–⑭ 不重号）

> 既有 ①–⑭ 中与本段重叠者：⑩（FreeBSD 2014 项目数 16 vs 14）、⑪（illumos 2013 未获确证）、⑫（OpenBSD 2010–2013 未参与属否定性断言）、⑬（FreeBSD 2011 项目数 17 源自论坛）、⑭（DragonFly 2012“6 名额”为 digest 口径）。以下 ⑮–⑳ 为本段**新增**未编号存疑。

- **⑮ illumos 2012 项目／学生明细未获一手**：仅确证“组织在列”（依据为 OpenNet 聚合站 2012 名单，附 illumos 官方 ideas 页链接存目），项目数、学生名、导师均缺。检索路径：Google 官方博客（仅组织总数）、OpenNet 2012 名单、illumos 旧 wiki（Wayback 无有效快照）、illumos 邮件列表。建议以 Melange 2012 归档 org/projects 列表（浏览器执行 JS）补。
- **⑯ illumos 2014“组织在列但 0 项目”缺 Melange 一手计数**：现依据为个人整理 gist（C 级）＋ OpenNet 名单，二者均非 Melange 原始 org/project 计数；且 2014 组织列表归档为 JS 渲染，raw HTML 不含名单。须以 Wayback 快照＋浏览器渲染后取 DOM 复核。
- **⑰ DragonFly 参与起点 2008 的证据强度弱于终点**：2010 官方页仅称“participated in the GSoC program for 2010”，并指向 2008／2009 页，但本次未取得 2008／2009 页原文；“2008–2013”区间起点属推定。建议补 dragonflybsd.org 2008／2009 SoC 页。
- **⑱ NetBSD 2010 项目数 6 与 2011 项目数 9 未与 Melange 原始名单去重**：2010 名单含“Kristaps Dzonsons”等，2011 名单亦含同名（如 Efstathios Kamperis、Vyacheslav Matyushin、Zoltan Arnold Nagy 跨年重复），“项目数”是否等同“学生数”“名额数”需以 Melange 口径校准。
- **⑲ OpenBSD Foundation 2014 除 systembsd 外其余 4 项无逐条一手**：官方 activities 页仅给“5 participating students”总数；gist 列出两条 ideas（DHCP／配置解析重写；Systemd utility replacements），其余 3 项学生／导师／产出未获确证。
