### 制度转折点清单（供 S2 建节）

1. **2005 首创**：动机官方原话＝"helping students find work related to their academic pursuits during their school holidays"；**"防止暑期技能退化"未获一手确证**。来源 S15。
2. **2009**：引入 Melange（半 CMS 半工作流）；因避免导师资源摊薄主动缩减约 100 学生；预算约 US$5,000,000。**"2009 伞形组织模式起点"未获确证**（2005 起即有集成型组织，如 Google 自身）。来源 S16。
3. **2012**：1,212 学生/180 组织，**非规模高点**（学生峰值 2017=1,318；组织峰值 2018=206）。来源 S1。
4. **2016**：Stephanie Taylor 接任（2010–2015 为 Carol Smith）——二手一致＋官方 2017 起署名佐证。来源 S14。
5. **2017**：津贴改 **PPP** 计算，base US$6,000、区间 US$2,400–6,600（二手转引官方 FAQ，建议以当年 stipends 页最终确证）。来源 S1、二手 FAQ。
6. **2022**：**向 18+ 所有新手开放**；新增 175/350h；项目期 10–22 周。来源 S7、S8。
7. **2023**：术语改 **contributors**（stats 2023 行首现，2022 仍称 students）；资格表述改"students and beginners"；同一人最多 2 次。来源 S1、S10。
8. **2024**：二十周年；疑增设 ~90h 小档（启用年未获确证）。来源 S11＋材料线索。
9. **2026**：官方 stipends 页首次完整列明 Small/Medium/Large 分档与 PPP 区间。来源 S3。

### 七.1 S3 抓取方式规范（四类站点＋可复用命令）

> 依据：本机 2026-10-02 实测。**临时脚本置 `script/`**；固定脚本须入 `00-编纂规则与格式规范/01-规则/脚本与命令/` 并被规则引用（任务书 §四.6）。

**类 1｜服务端渲染（普通 HTTP 即得全文，非 JS）**
域：`developers.google.com`（含 `/gsoc/resources/stats`、`/gsoc/help/student-stipends`、`/gsoc/timeline`、`/gsoc/faq`、`/open-source/gsoc/*`）。
**实测**：stats 页 `curl` 直取 75,480 B，含 2005–2023 全表（`410`、`1,318`、`966` 等均命中）。**无需浏览器**。
```bash
curl -sSL -A "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/124.0 Safari/537.36" \
  -H "Accept-Language: en-US,en;q=0.9" \
  -o out.html "https://developers.google.com/open-source/gsoc/resources/stats"
# 自检：命中即非JS，空/仅标题即被JS门禁
grep -c "1,318" out.html && grep -o "<script" out.html | wc -l
```

**类 2｜JS/SPA（须浏览器渲染后取 DOM）**
域：`summerofcode.withgoogle.com` 全系（`/`、`/archive`、`/rules`、`/programs/...`、`/programs/2026/organizations`、`/projects/...`）。
**实测**：`WebFetch` 直接取仅得标题"Google Summer of Code"，须渲染。
```bash
# 方案A：playwright（Python）
python - <<'PY'
from playwright.sync_api import sync_playwright
with sync_playwright() as p:
    b = p.chromium.launch()
    pg = b.new_page()
    pg.goto("https://summerofcode.withgoogle.com/archive", wait_until="networkidle")
    open("archive_rendered.html","w",encoding="utf-8").write(pg.content())
    b.close()
PY
# 方案B：agent-browser CLI（AI 友好，取渲染后 DOM/快照）
# 方案C：npx playwright screenshot --wait-for-timeout 8000 --full-page <url> out.png
```
入库须记录抓取方式（浏览器渲染），并建议同时抓 Wayback 快照（见类 3）。

**类 3｜原站已失效（须 Wayback CDX API 定向取快照）**
域：`code.google.com/soc`、`socghop.appspot.com`（Melange 2009+）、`google-melange.com`。Google Code 2016 关站，原链失效。
```bash
# ① 列快照（CDX）
curl -s "http://web.archive.org/cdx/search/cdx?url=socghop.appspot.com/org/list/public/google/gsoc2009&output=json&limit=20"
# ② 取最近快照原文（id_ 后缀取原始未改写）
curl -sSL -o gsoc2009_orgs.html "https://web.archive.org/web/2009id_/http://socghop.appspot.com/org/list/public/google/gsoc2009"
```
**注意**：本机 2026-10-02 调用 archive.org `/wayback/available` **返回 HTTP 429 限流**，未获快照确认。S3 须**限速重试**（间隔数十秒），或用 CDX API 代替 available API。2009 三 BSD 组织可另由各自官网页互证（A1 已办）。

**类 4｜Anubis PoW 反爬（须浏览器执行挑战）**
域：`wiki.freebsd.org`。
`curl` 会停在"Making sure you're not a bot"挑战页，须由能执行 JS/工作量证明的浏览器（playwright / agent-browser）等待挑战通过后再取 DOM。
