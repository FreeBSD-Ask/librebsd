## 第 1 项：ch18.2 2017 libbe／bectl 项目学生姓名

- **判定：证伪（原注错）**。学生为 **Kyle Kneitinger**，导师 **Allan Jude**；原注作“Yuri Pankov”系误。
- 一手依据：
  1. bectl(8) manual（FreeBSD 手册页，HISTORY 节）逐字：“bectl and libbe(3) were written by **Kyle Kneitinger (kneitinger)** as a 2017 Google Summer of Code project, with **Allan Jude (allanjude)** as mentor.”——https://www.freebsd.org/cgi/man.cgi?manpath=FreeBSD+14.0-current&query=bectl （2026-10-02）。
  2. FreeBSD Wiki 2017 项目页（recall 快照）“A New ZFS Boot Environment Management Library & Tool For FreeBSD”：“Student: **KyleKneitinger** (kneitinger@)／Mentor: **AllanJude** (allanjude@)，A Summer of Code 2017 Project”——https://wiki.freebsd.org/action/recall/NewZfsBootEnvMgmtLibAndTool?rev=3 （2026-10-02）。
  3. FreeBSD Foundation《BSDCam 2017 Trip Report: Kyle Kneitinger》（该学生本人行程报告，佐证其为当年 GSoC 学生）——https://freebsdfoundation.org?p=5632/ （2026-10-02）。
- 备查：libbe(3) manual 亦载“libbe and its corresponding command, bectl(8), were written as a 2017 Google Summer of Code project with Allan Jude serving as a mentor.”
- **写作处置**：18.2 节题保留；注文学生名改为 Kyle Kneitinger，并注“原注作 Yuri Pankov 系误”。

## 第 2 项：ch17.4 2020 年 Capsicum GSoC 项目

- **判定：确证**。2020 年 FreeBSD 的 Capsicum GSoC 项目为 **Capsicumization of the base system**（学生 **Shubh Gupta**）；**cap_netdb 非 2020 年 GSoC 项目**。
- 一手依据：
  1. FreeBSD soc-status 邮件列表周报标题与正文：“[GSoC '20 weekly update] **Capsicumization of the base system**”，作者 Shubh Gupta 署名 shubh@freebsd.org；正文“This project aims at capsicumizing some of the base system applications”（沙箱化 traceroute6／fsck_ffs 等），项目页 https://wiki.freebsd.org/SummerOfCode2020Projects/CapsicumizationOfTheBaseSystem ——https://lists.freebsd.org/pipermail/soc-status/2020-June/001224.html 、/2020-July/001240.html （2026-10-02）。
  2. cap_netdb 系另一线工作：libcasper 服务由 **Ryan Moeller**（freqlabs）实现，评审 D24832 创建于 **2020-05-13**、abandoned 于 2020-10-25、最终提交于 **2021-06**（rG94dc57159532“libcasper: Create a minimal cap_netdb service”）；man 页 AUTHORS：“The cap_netdb service was implemented by Ryan Moeller”——https://reviews.freebsd.org/D24832 、https://reviews.freebsd.org/differential/diff/82662 、https://man.freebsd.org/cgi/man.cgi?query=cap_netdb （2026-10-02）。
- **cap_netdb 系年**：评审起 2020-05、提交 2021-06，与 GSoC 2020（Shubh Gupta base system 沙箱化）不属同一项目；cap_netdb 为 libcasper 服务扩展，非 GSoC 学生项目。
- **写作处置**：17.4 节题改为“2020：基本系统的 Capsicum 沙箱化（Shubh Gupta）”，cap_netdb 系年入注文另核。
