## 三、行为兼容与原生语义验证（三探针，全绿）

| 探针 | 结果 |
| ---- | ---- |
| 行为序列（`_dlg_behavior_probe`） | 与改造前基线逐项一致：开→open=1；二次点击不关；面板开启时背景**程序化**点击仍生效（badge note-open）；Esc 关 |
| 原生语义（`_dlg_native_probe`） | 四面板 tag=DIALOG／`:modal`=true／.open 同步／无 .scrim／role=dialog×4；Esc 四面板全关（.open 由 close 事件同步）；点 dialog 本体关、点 .box 不关 |
| 焦点归还（`_dlg_focus_probe` 真实用户流） | 图谱／时间线／修订 ESC 后焦点**原生归还触发按钮**（BUTTON#optGraphBtn／optTl／optRev）；检索面板落 BODY 系**既有行为**（打开后工具条收起致触发按钮 display:none、focus 空操作——与基线一致，登记不改） |

**前置判定探针**：`_dlg_inert_probe`——Chromium 中 `showModal` 背景 inert **不拦截程序化** `.click()`／`dispatchEvent`（仅挡真实交互）→ 三套回归全程依赖的程序化点击兼容无虞。
**虚惊排除**：`page.click('#optSearch')` 超时系工具条默认收起态（⚙ 展开后按钮可见）之既有设计，非本批引入；`_dlg_vis_probe` 证实 display:none 来自 `.opt-tools > button:not(.opt-tools-toggle)`。
