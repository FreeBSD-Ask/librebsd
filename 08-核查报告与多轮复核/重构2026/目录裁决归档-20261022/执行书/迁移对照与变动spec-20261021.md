## 1. 背景与问题

2026-10-21 22:25，`05-新大纲` 就地改名为 `05-卷册大纲`，原 74 卷旧树删除。由此产生三类问题：

1. **结构不同**：项目目录为 74 卷／521 章／3,691 节；新树为 24 卷／449 章／37,486 小节。卷号、章号、节号三套编号均不可直接对应。
2. **引用失效**：项目目录的〔溯源〕〔分工·迁移〕注保留旧树磁盘路径，共 39 处、去重 29 条，现行精确可解析数为 0。
3. **工具过期**：`refresh_diff_table.py` 与 `probe_diff_counts.py` 仍按“旧树＋新树”双路径编写，新树路径已不存在，比较表无法再自动重算。

比较表在这一时点之前生成，是旧树被删除后**唯一留存的章级对照台账**。表中“旧”指已删除的 74 卷源树，“新”指现行 24 卷树；章对应以“新卷序号＋章 slug”配对，旧卷号不参与配对键。本 spec 以该表为章级基线，以留痕索引为节级基线。

本 spec 只解决“如何对照、如何改指、如何登记后续变动”，不解决“两棵树谁对谁错”。二者不同是既定事实，对照的目的是可追溯，不是求同。

## 2. 目的与非目标

### 2.1 目的

- 建立项目目录与新树之间的**卷级、章级、节级**三级对照，每条对照有证据、有状态、有唯一结论。
- 把 29 条失效引用逐条改指或登记豁免，使引用面悬空归零。
- 以比较表的字节、锚、件数为对账基线，使迁移前后的规模变化可解释。
- 建立变动登记制度，使后续任何卷章增删、改名、移并、重编号都能在同一批次内同步对照表。
- 为迁移提供可复核的前置条件：映射齐备、裁定留痕、影子装配通过。

### 2.2 非目标

- 不追求 74 卷与 24 卷的结构等价，不设“必须一一对应”的判据。
- 不修改新树正文、目录名、留痕索引。
- 不把项目目录改成 24 卷，也不把新树改成 74 卷。
- 不以卷号、章号算术平移代替题名与证据匹配。
- 不在本阶段改动注文的史料判断与正文语义。
- 不重算比较表的旧树侧：旧树已删除，旧侧数字冻结为基线。

## 5. 对照卷章检查

### 5.1 三级对照模型

| 层级 | 对象 | 匹配单位 | 首选证据 | 允许关系 |
|---|---|---|---|---|
| 卷级 | 项目卷 ↔ 新卷 | 章题集合重合率 | 比较表逐卷汇总 | 一对一、一对多、多对一、未匹配 |
| 章级 | 项目章 ↔ 新章 | 规范化章题 | 比较表逐章明细 | 一对一、一对多、多对一、未匹配、歧义 |
| 节级 | 项目节 ↔ 新节目录 | 旧节号或规范化节题 | 留痕索引 | 一对一、一对多、未匹配、歧义 |

卷级不设强制映射：一个新卷可聚合多个项目卷，一个项目卷也可分属多个新卷。卷级对照只用于定位章级搜索范围，不作为结论。

### 5.2 匹配优先序

1. **比较表章级配对**：逐章明细已给出新章号、章题、旧件数、旧字节、旧锚；按此确定章级对应。
2. **留痕索引**：`本章节索引原样留痕.md` 中 `[旧节号 题名](../新节目录/)` 行，确定节级对应。
3. **规范化题名全等**：章题、节题去编号与标点后全等。
4. **规范化题名包含**：一方为另一方的连续子串，且长度差不超过 8 字。
5. **内容证据**：章级综合正文、文件名中的旧编号、正文首段的自述编号。
6. **人工裁定**：以上均不能判定者，登记歧义或未匹配，不得默认。

章级与节级冲突时，以更具体层级为准：节级证据可推翻章级候选，反之不得。冲突本身须登记。

### 5.3 规范化规则

对章题、节题、目录名统一执行：

1. 去章号前缀 `第\d+章-`、节号前缀 `\d+\.\d+-`。
2. 全角转半角；英文转小写。
3. 删除空白、下划线、连字符（`-`、`–`、`—`）、中点、逗号、句号、冒号、分号、括号、方括号、书名号、斜杠。
4. 统一 `＋` 与 `+`、`／` 与 `/`。
5. 仅保留汉字、拉丁字母、数字。
6. 规范化结果作为匹配键；原文保留在对照表中，不得以规范化文本回写目录。

比较表的章题已按此口径小写化，可直接作为键；项目侧须同口径归一后再匹配。

### 5.4 匹配状态机

| 状态 | 含义 | 处置 |
|---|---|---|
| M1 | 一对一确定 | 直接入映射 |
| M2 | 一对多（项目一章对应新树多章） | 入映射，登记拆分依据 |
| M3 | 多对一（项目多章并入新树一章） | 入映射，登记合并依据 |
| M4 | 未匹配 | 入未匹配清单，人工裁定 |
| M5 | 歧义（多个同分候选） | 入歧义清单，人工裁定，禁自动择一 |

任何 M4／M5 不得静默归入 M1；裁定结论须写明证据与责任人。

### 5.5 判据与阈值

| 判据 | 阈值 | 说明 |
|---|---:|---|
| 内容章配对率（M1＋M2＋M3） | ≥ 95% | 分母＝449−48 结构章＝401；比较表实测 390／401＝97.3% |
| 结构章登记率 | 100% | 48 章卷总览／卷末述评全部单列，不计入配对率 |
| 新章未配对登记率 | 100% | 卷20 的 11 章全部登记为 C3 新增 |
| 项目章反向覆盖率 | ≥ 75% | 521 个项目章中至少 390 章可在比较表找到承接；余者登记 |
| 节级可判定率 | ≥ 90% | 留痕索引覆盖 166 章／916 节，余按题名匹配 |
| 歧义静默数 | 0 | 每条 M5 必须有裁定记录 |
| 未匹配静默数 | 0 | 每条 M4 必须有处置结论 |

未达阈值时，迁移不得进入 S3；只能继续补证或缩范围。

### 5.6 输出物

统一写入 `执行临时区/迁移对照/`，全部 UTF-8 无 BOM、LF：

| 文件 | 内容 |
|---|---|
| `map_vol.jsonl` | 项目卷、候选新卷、章题重合率、字节与锚合计、状态、证据 |
| `map_ch.jsonl` | 项目卷章、新卷章、匹配类型、规范化键、比较表旧件数／旧字节／旧锚 |
| `map_ch_rev.jsonl` | 新章到项目章的逆向索引，供未配对章核对 |
| `map_sec.jsonl` | 项目卷章节、旧磁盘路径、新节目录、匹配类型、证据 |
| `unmatched.md` | M4／M5 清单，逐条列候选与待裁点；含 59 条未配对章与项目侧反向未覆盖章 |
| `decision_log.md` | 人工裁定记录，含日期、对象、结论、依据、复核 |
| `对照总表.md` | 由上述 JSONL 渲染的人读表，供审阅 |

JSONL 为唯一机器真值，Markdown 表为派生件；二者不一致时以 JSONL 为准并立即重渲染。

### 5.7 比较表对账

比较表是旧树删除后的冻结基线，对账分两侧：

1. **旧侧冻结**：3,273 件、336,943,812 字节、486,027 锚，不再重算；任何引用旧侧数字的文档须注明“比较表快照”。
2. **新侧重算**：按现行 24 卷树重算 24 卷、449 章、37,486 小节、348,022,031 字节、507,880 锚；与表不一致时，逐条登记为 C9 变动，不得直接改表。
3. **逐章对账**：迁移后每章的旧件数、旧字节、旧锚以表为准；新侧字节与锚重算；字节差须能由件头、空行、H1、结构章解释，锚差须逐章说明来源。
4. **未配对章**：48 结构章单列；卷20 的 11 章登记为 C3 新增；其余未配对为 0。
5. **卷20 特例**：旧件 0、新小节 5,596、新字节 9,268,701、新锚 21,770，整卷新增，不计入字节差的“移植漂移”，单列为新增开销。

对账结果写入 `执行临时区/迁移对照/recon_diff_table.md`，每卷一行，差异非零须有解释。

## 6. 引用改指检查

### 6.1 扫描面

| 载体 | 是否改 | 说明 |
|---|---|---|
| `执行临时区/outline.work.txt` | 是 | 唯一正文改动面 |
| `data/outline.txt` | 否（随正式替换整体更新） | 底本只读 |
| `08-核查报告与多轮复核/重构2026/index.html` | 否（由装配器重装） | 禁止手改 |
| `执行书/*.md` | 仅登记，不改路径 | 历史文档保留原貌 |
| `script/*.py` | 是（工具路径） | 仅改常量，不改逻辑 |

### 6.2 路径语法

引用形制为 `05-卷册大纲/<卷目录>/<章目录>/<节文件>.md` 或 `05-卷册大纲/<卷目录>/<章目录>/`。扫描时须处理：

- 路径被空格、`＋`、`；`、`〕` 截断；
- 同一注文含两条路径以 `＋` 连接；
- HTML 转义残留（`<\/code>`、`&amp;`）；
- 章号写作 `第 356 章`（含空格）与 `第356章` 两种形态。

截断或碎片路径不参与自动改指，列入人工清单。

### 6.3 改指规则

1. **章级路径**：旧章题经比较表 `map_ch.jsonl` 定位新章目录；比较表无承接着按留痕索引或题名匹配。
2. **节级路径**：优先用留痕索引；无索引时在新章目录内按节题规范化匹配。
3. **文件级路径**：改指到新节目录，文件名保留旧文件名作为“旧树文件名”括注，或改为新节目录内实际 `.md`；二者择一须全批统一。
4. **卷末书目述评**：旧章级 `卷末书目述评.md` 改指新树对应 `卷末书目述评` 章目录。
5. **聚合路径**（`…185.5…＋第187章/187.7…`）：拆为两条独立路径，各自映射。
6. **无法映射**：按 6.4 处置，不得保留旧路径假装有效。

### 6.4 不可映射的四类处置

| 类型 | 处置 | 登记 |
|---|---|---|
| 新树确无对应内容 | 改注文为文字出处（去磁盘路径），保留史料说明 | 豁免表 |
| 新树有内容但题名不同 | 人工裁定后改指，附题名差异说明 | 裁定表 |
| 路径本身截断或碎片 | 补全原路径后重判；不能补全则删路径留文字 | 裁定表 |
| 旧路径属历史层叙述 | 保留原文，加“旧树路径（已废）”限定语 | 豁免表 |

豁免表须含：引用行号、旧路径、豁免理由、批准日期。豁免不得批量授予。

### 6.5 禁止事项

- 禁止按卷号或章号算术平移（旧 273 不等于新 273）。
- 禁止全库正则批量替换路径。
- 禁止改动注文的史料判断、时间、人物、因果表述。
- 禁止把“旧树路径”改写为“新树路径”却不改文件名中的旧节号，造成新旧混写。

## 7. 后续变动管理

### 7.1 变动类型

| 代号 | 类型 | 示例 |
|---|---|---|
| C1 | 卷题改名 | 卷题时段或主体调整 |
| C2 | 章题改名 | 去版本号、去计数概括式 |
| C3 | 新增章 | 章末顺延；卷20 的 11 章即此类 |

| C9 | 新树侧变动 | 新树增删章、改目录名；比较表新侧数字变化 |

### 7.2 变动登记字段

每条变动一行，写入 `执行书/变动登记.jsonl`：

| 字段 | 必填 | 说明 |
|---|---|---|

### 7.3 同步义务

- 任何 C1–C9 变动，须在同一批次内更新 `map_vol/ch/sec.jsonl` 与 `对照总表.md`；未更新者视为批次未完成。
- 变动涉及引用面者，须同时更新 `ref_map` 并重跑引用解析。
- 新树侧变动（C9）须在下一批次前重扫留痕索引与比较表新侧数字，防止映射过期。

### 7.4 冻结与指纹

每个迁移阶段开始前，对以下对象记 SHA-256 与规模：

- `执行临时区/outline.work.txt`
- `data/outline.txt`
- `08-核查报告与多轮复核/重构2026/index.html`
- `05-卷册大纲` 的卷／章／节目录清单与 `SUMMARY.md`
- `执行书/前后差异细粒度比较表-20261021.md`

指纹写入 `执行临时区/迁移对照/baseline.json`。阶段间指纹变化须有对应变动登记，否则暂停。

### 7.5 回滚

项目在 git 管理下，数据库由系统轮替，md 文件不另设备份。回滚以提交为单位，禁止对 `D:/librebsd` 做手工覆盖式回滚；正式替换前须有可回退的提交点。
