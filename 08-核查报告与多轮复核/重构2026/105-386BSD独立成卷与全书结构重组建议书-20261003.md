## 一、386BSD 的历史分水岭地位（联网核证摘要）

| 事实 | 证据 |
| ---- | ---- |
| **第一个可在 PC 上运行的完全自由 UNIX** | 1992-03-12 发布 0.0；同年 7 月 0.1 获 250,000 次 FTP 下载 |
| **直接催生 FreeBSD 与 NetBSD** | Patchkit 维护者 1993 年分叉创立 FreeBSD；另一群用户创立 NetBSD |
| **所有现代 BSD 的共同祖先** | FreeBSD/NetBSD/OpenBSD/DragonFly 均溯源至 386BSD |
| **技术革新** | 角色安全、环形缓冲、自序配置、模块化内核设计 |
| **Dr. Dobb's Journal 17 篇连载** | 1991-01 起 Lynne/William Jolitz 撰写，使移植过程对一代系统程序员可及 |
| **USL 诉讼非当事方** | 386BSD/Jolitz/Dr. Dobb's 从未成为诉讼当事方，从未受限 |
| **386BSD 1.0 CD-ROM 畅销三年** | 1994–1997 Dr. Dobb's Journal CD-ROM 畅销榜 |
| **开源运动的分水岭** | 此前 UNIX 仅限工作站/小型机；此后 PC 用户可自由获取完整 BSD 系统 |
| **386BSD 2.0** | 2016-08 Ben Jolitz 更新（GitHub），"self-healing components" |

**分水岭意义**：386BSD 标志着 BSD 从**学术机构的特权产物**转变为**任何拥有 386 PC 的普通人都可以运行、修改和分发的自由操作系统**——这是开源运动史上的结构性转折点，值得独立成卷。
