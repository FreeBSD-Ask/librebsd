## 二、总体消解方案（机制）

### 2.1 执行方案三选一

- **方案 A（推荐）——章级书目注（概要式＋折叠清单）**：删除 22 行卷级占位；在每个承接章 `</ul>` 之后插入一个 `<details class="ch-biblio">` 折叠块——summary 概要行（源文件＋承接簇＋条目量级），右上角 `*` 切换符，展开后列出该章承接的全部条目（含 ref id），**默认收起**。CSS 新增 `.ch-biblio` 系（样式沿用现 `.vol-biblio` 弱化色），原生 `<details>` 无需 JS。占位句所担的“入口”职能由章注承接，真正落到章、节。章注设置遵循**“有则设、无则不设”**（2026-09-06 ykla 裁决）：有实测可承内容才设；无源章不设注、不留痕。完整标记与交互规格见 2.5。
- 方案 B——卷级映射注：占位行原位替换为一行具体映射注（源文件＋承接章列表），章级不动。改动最小，但未满足“合入对应章、节”。
- 方案 C——全文分发：911 KB 文献条目按章拆写进 HTML。预计页面膨胀至 4 MB 以上，目录预览可读性骤降，且与“回写正式大纲时按 11-参考文献重定义 标准 9 拆分”的既有流程重复。**不推荐。**

### 2.2 内容分发五原则（方案 A 适用）

1. **争议节 → 按主题对应章**：每条“争议一/二/三”归入其主题所属新章（见第三节逐卷映射）；跨卷争议主体归一、余卷留分工注（沿用 index.html 现行“与第 N 卷 N.N 分工”注释体例）。
2. **文献清单条目 → 双轨锚定**：带“关联建议”字段者，按其旧章号经 `19-新旧章号映射表.md`（注意其映射到 Version A 19卷313章 已废弃，须经 355 章磁盘实况二次校正）换算为新章；无字段者按内容亲缘分配，无法判读者列入“待人工判读”清单，禁止脚本猜测。

### 2.5 章注交互规格（v3，2026-09-06 ykla 裁决：概要式标题＋`*` 展开全量清单，默认收起）

**结构**：原生 `<details>` 折叠块（零 JS——index.html 为自包含单文件，不引入外部脚本）。

```html
<details class="ch-biblio">
  <summary>
    <span class="ch-biblio-title">本章书目述评：旧09卷《netbsd的历史》卷末书目述评——争议一/二/三 ＋ 文献清单一手/二手/口述史簇（约 34 条）</span>

    <ul class="ch-biblio-list">
      <li>ref 2761｜GE 信息系统事业部. GE-645 System Manual. 1966.〔旧01·临时放置批次〕</li>
      <!-- 该章承接的全部条目：ref id ＋ GB/T 7714 著录 ＋ 原簇名；条目多时全部列出，仅存于折叠体内 -->
    </ul>
  </div>
</details>
```

**要点**：

1. **概要式标题**：summary 行一句话——`本章书目述评：旧N卷《卷名》卷末书目述评——〈承接簇名〉（约 N 条）`；不逐条著录、不贴长引文。
2. **全量清单入折叠体**：条目无论多少，全部收进 `<ul class="ch-biblio-list">`（每条：ref id｜著录｜原簇名），点开后完整列出。
3. **`*` 切换符在标题最右上方**：summary 为 flex 布局，`*` 右对齐置顶；点击 summary 任意处切换；**默认收起**（`<details>` 不带 `open` 属性）。
4. **CSS 追加**（复用现 `.vol-biblio` 弱化色变量）：

```css

.ch-biblio summary::-webkit-details-marker { display: none; }

.ch-biblio-list { margin: 4px 0 0; padding-left: 18px; }
```
