## 四、本次新发现（96 号文未载）

1. **Mercurial 在现行目录零落点**（claim 15、磁盘 1 路径）。
   - 事实依据：NetBSD 主仓为 Mercurial（`hg.NetBSD.org`），而其 GitHub 为镜像——这一“主仓≠Git”的差异在版本控制迁移叙事中具独立价值。
   - 建议：**并入卷 41 第 8 章 8.1 节内**，不单设节。
2. **Phabricator“退役”未获证实**——`reviews.freebsd.org` 官方实例**仍在运行**，`wiki.freebsd.org/Phabricator` 仍述其用途。**任何“Phabricator 已被 X 取代”的写法在本次联网核验下不成立**，须先取一手公告方可写。
3. **`Subversion` 字面零计数的解释**——卷 41 第 8 章已有专节“8.1 FreeBSD CVS 至 SVN 至 Git 的档案迁移”，采用“SVN”写法。**这提示一条通用教训：主题词字面零命中不等于内容缺位，须同时按同义写法检索**（本次即避免了一次误报）。
