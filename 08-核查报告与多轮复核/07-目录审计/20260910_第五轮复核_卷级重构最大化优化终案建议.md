## 一、顶层诊断：27 卷骨架的三处结构性缺陷

逐卷通读后确认，27 卷骨架在**章级**已高度自洽（前四轮成果），但**卷级**存在三处由“历次拆分叠加”造成的结构性问题：

| 缺陷 | 现状（实测） | 根因 |
| --- | --- | --- |
| **D1 同一主题双卷并存、职责重叠** | 卷21“许可证与法律”（6 章）与卷22“许可证政治、合规与法律谱系”（15 章）同为“许可证/法律”主题，卷21 ch1–4（学术起源/条款演化/GPL 对照/许可证谱系）与卷22 ch4/ch5/ch10（OSI/许可证政治/其他 OS 许可证比较）实质重叠 | 47 号文 E-4b 从原卷19 拆成两卷，拆分后职责未彻底厘清 |
| **D2 “元卷”职责纠缠、体量失衡** | 卷26“分离聚合六十年”15 章**过载**（ch1–6 总结＋ch9 史料得失＋ch10 人物对照＋ch11–15 口述史/符号/计量/记忆方法论/自反）；卷27“史学史”仅 5 章**过薄**（4 正文＋1 述评） | 47 号文 E-5（卷26 扩容收束）＋E-1（卷27 史学史独立）两次决策叠加 |

## 二、P0 必改：卷21＋卷22 合并 ★★★★★

### 论据

卷21（6 章）与卷22（15 章）是 47 号文 E-4b 从原卷19“许可证与法律”拆出的**同一主题双卷**，拆分本意是“本体线（卷21）vs 政治法律线（卷22）”，但实测二者边界未厘清：

- 卷21 ch3“GPL 的对照：copyleft”与卷22 ch5“许可证政治：BSD 与 GPL 的路线之争”同域；
- 卷21 ch4“LGPL/Apache/MIT 谱系”与卷22 ch10“BSD 之外的操作系统许可证比较”同域；
- 卷22 ch4“OSI、开源定义与 BSD 许可证的位置”与卷21 ch1“BSD 许可证的学术起源”同域。

### 操作

卷21＋卷22 合并为**单卷“BSD 许可证、法律与合规”（约 19 章）**，去重 2 组（GPL 对照、许可证谱系各并 1 节）。

**新卷章序（暂定）**：学术起源 → 条款演化 → GPL 对照 → 许可证谱系 → 自由不对称与闭源 → 自由概念史 → AT&T/Novell/SCO 版权链 → USL 法律后效 → 商标与标准 → OSI 与开源定义 → 许可证政治 → 合规认证 → 出口管制 → 云时代适应 → 代际差异 → 其他 OS 比较 → Apache 谱系 → 供应链安全 → 商业策略 → 利益分配总结 → 卷末述评。

### 结果

卷数 27 → **26**；章数 232 → **230**（并 2 节）；节数 1515 → **1513**。

**风险**：**中**。触及 E-4b 拆分成界（两项归位成果合一），但合并方向即 E-4b 之前的原状，语义自洽。须主理人明示。

## 三、P1 应改（3 项）

### P1-1｜卷24 撤销，内容三分流 ★★★★

**论据**：卷24“代码谱系与移植”5 章中，ch1/2/3 属“BSD–Linux 代码关系”（与卷23 自由软件卷同域），ch4“被忽略的贡献者”（翻译者/镜像管理员，与卷19 传播载体卷重叠），ch5“桌面 BSD 被忽略”（与卷16 沉默基石卷的“被忽略”主题同域）。卷名“代码谱系与移植”已不能覆盖后两章。

**操作**（三分流）：
- ch1/2/3 → **卷23**（改题“自由软件、开源运动与 BSD–Linux 谱系”，9→12 章）；
- ch4“被忽略的贡献者”→ **卷19**（传播载体与公众记忆，6→7 章，与 ch1 翻译史、ch2 镜像站天然同域）；
- ch5“桌面 BSD”→ **卷16**（沉默的基石，12→13 章，与“被忽略/被隐形”主题同域）。

**结果**：卷24 撤销；卷数 26 → **25**（在 P0 基础上）；章数、节数不变（纯迁移）。

**风险**：**中高**。卷24 是 47 号文保留的独立卷名（非拆分产物），撤销须主理人明示；三分流的三个宿主卷均需改卷题涵盖。

### P1-2｜卷26/27 职责重组 ★★★★

**论据**：卷26（总结卷）ch11–15 五章（口述史/符号记忆/数字计量/记忆方法论/自反性）实为“史学方法”，与卷27“史学史”职责重叠；卷27 仅 5 章过薄。

**操作**：
- 卷26 保留 ch1–10（分离聚合史实＋分期＋史料得失＋人物对照），15→10 章，改题“BSD 分离聚合的六十年”不变；
- 卷27 吸收 ch11–15，5→10 章，改题“**BSD 史学史与方法**”：声名分配 → 讲述三十年 → 被记住者名录 → 缺席 → 口述史与记忆媒介 → 符号记忆 → 数字记忆计量 → 记忆史方法论 → 自反性 → 卷末述评。

**结果**：卷数不变（25）；卷26 15→10 章、卷27 5→10 章，职责清晰（卷26＝史实总结，卷27＝史学元卷）。

**风险**：**高**。触及 E-1（卷27 独立）＋E-5（ch11/13/14 归位卷26）两项成果；但方向是“把史学方法归回史学元卷”，逻辑更自洽。**须主理人明示**。

### P1-3｜卷3“UNIX 文化与哲学”偏薄补强（轻）

**论据**：卷3 仅 3 章（软件工程/哲学与文化/Plan9），为全书最薄的非编年卷；卷1 ch8“Research Unix 暮年：V8–V10”与卷3 的“UNIX 文化”有承接关系。

**建议**：采**乙**（不动），仅登记——卷3 偏薄但主题独立，强行补强收益低。
