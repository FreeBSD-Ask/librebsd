# DragonFly BSD — donations（dragonflybsd.org/donations/）

donations DragonFly is not yet incorporated as a non-profit, meaning no tax benefit is available for donating time or goods to the project. However, developers can still use your contributed hardware and you can make non-tax-deductible donations through PayPal. Donating money You can use the donate-button to make a non-tax-deductible donation through PayPal, or send to paypal@dragonflybsd.org. Matthew Dillon manages the account separately, and all money goes to DragonFly hardware or code bounties . We list donors here but we don't link back; this is not for advertising. Sponsoring projects We have a separate page for code bounties . Welcome to sponsor the projects there and/or create new code bounties. Hardware Donations For hardware donation. please contact the requestor directly (and CC: donations at dragonflybsd.org). You and the donating/receiving party must independently resolve any delivery issues. The DragonFly BSD Project is not responsible for any transactions. Some tips on sending donated equipment through the mail: International mailing usually requires some sort of customs declaration. Declare the equipment is used, and is to an individual, not to a business. Value is probably less than <$50USD. Add www.dragonflybsd.org as a reference for the customs officer. Repeat that information in a letter inside the packaging, in case it is opened or damaged.
