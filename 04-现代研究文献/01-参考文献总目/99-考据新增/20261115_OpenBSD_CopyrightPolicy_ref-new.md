- **source_url**：https://www.openbsd.org/policy.html
- **quote（逐字，四处）**：
  1. OpenBSD strives to provide code that can be freely used, copied, modified, and distributed by anyone and for any purpose.
  2. OpenBSD can exist as it does today because of the example set by the Computer Systems Research Group at Berkeley and the battles which they and others fought to create a Unix source distribution un-encumbered by proprietary code and commercial licensing.
  3. A license can only be considered fully permissive if it allows use by anyone for all the future without giving up any of their rights.
  4. source code published under version 2 of the Apache license is subject to additional restrictions and cannot be included into OpenBSD.
- **考据注**：四句分工——第 1 句是政策目标（V32.4.5.1 适用范围），第 2 句把政策的正当性接到伯克利 CSRG 的“去 encumbrance”斗争（与 3.3.1 呼应，但此处是**政策文本自述**，不是诉讼史），第 3 句给“完全宽松”的判准（V32.4.5.2 取舍标准），第 4 句是 Apache 2.0 被拒的政策表述。**注意**：第 2 句原文作 “un-encumbered”（带连字符），与 3.3.1 手册转述里的 “unencumbered” 拼法不同，两处各自照录，不统一。页内另有 GPL 段（“The GNU Public License and licenses modeled on it impose the restriction that source code must be distributed or made available…”），本批未取，留给 4.5.5 宽严尺度对照
- **本批落点**：V32.4.5.1 第 1、2 块；V32.4.5.2 第 1、2 块
