1. [1.2.4 用，两句连跨段（规范化后连续）] The rsh utility executes command on host. The rsh utility copies its standard input to the remote command, the standard output of the remote command to its standard output, and the standard error of the remote command to its standard error.

2. [备用（后续批），照录] Authorization is determined as in rlogin(1).

3. [HISTORY 节照录（卡内出典）] The rsh command appeared in 4.2BSD.

4. [备用，照录] If no command is specified, you will be logged in on the remote host using rlogin(1).
