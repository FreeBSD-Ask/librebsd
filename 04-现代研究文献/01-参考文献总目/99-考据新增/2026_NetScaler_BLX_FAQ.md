## 二、逐字引文（英文，未翻译）

BLX 的形态定义：

> NetScaler BLX is a bare metal software version of NetScaler that runs as a native application on the Linux host.

三种软件形态的分野：

> NetScaler BLX, CPX, and VPX are software form factors of NetScaler.

> NetScaler VPX™ is a virtual appliance and must run on a hypervisor installed on the server. NetScaler CPX is a containerized version of NetScaler, which must run in a container. NetScaler BLX is a software package that runs natively on Linux systems.

## 三、考据说明

- “native application／runs natively on Linux systems”是 1.4.3“BLX 以 Linux 原生进程交付”的直接表述。
