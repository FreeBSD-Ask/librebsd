## 二、逐字引文（英文，未翻译）

系列层与形成者的关系：

> The series is the descriptive level that is connected to the archival creator - the person or organization who created and/or maintained the records.

案卷单元与文件项的从属关系：

> File units are always contained by series, while items can be contained by either series or file units.

## 三、考据说明

1. 该页把目录结构讲成四层：record group／collection → series → file unit → item，并指明**系列层是与形成者（creator）挂接的层级**——这解释了为何检索记录必须写到系列，否则无法回到机构。
2. 从属规则明确：file unit 必属系列，item 可属系列或 file unit。留痕时若把 item 直接挂到全宗，即违反目录自身结构，日后无法复现检索路径。
3. 与 GIL 17 的引用要素（六层）互为表里：GIL 17 讲“引用要写什么”，本页讲“目录里这些层是什么关系”。
4. 禁引核查：`.gov` 官方站，`banned_source=0`；属系统说明，不作史实证据。
