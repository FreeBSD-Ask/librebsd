# Google LLC v. Oracle America, Inc.（593 U.S. 1, 2021）引用卡

- **案件名**：Google LLC v. Oracle America, Inc.
- **法院**：美国联邦最高法院（Supreme Court of the United States）
- **案号**：No. 18-956（S. Ct.）
- **判决日**：2021-04-05
- **引文**：593 U.S. 1 (2021)
- **涉及许可证/版权问题**：Java API 声明代码的版权性；合理使用（fair use）；API 互操作性与开源生态边界
- **核心裁判观点**：最高法院以 6-2 多数认定 Google 复制 Oracle 的 Java SE API（约 11,500 行声明代码，为 Android 重实现）构成合理使用——Breyer 大法官主笔：API 声明代码的复制具转换性（为不同计算环境的互操作）、所复制部分仅占 API 整体极小比例、市场损害有限；**本案对开源生态意义重大**：若 API 不可合理使用，则兼容实现（如 OpenJDK、BSD 系对 POSIX API 的实现）将面临版权风险；本案与 BSD 史关联——BSD 系对 POSIX/Unix API 的兼容实现逻辑与本案合理使用论证同构（详见 148.10 节 Google v. Oracle 终审判决与 API 版权 Fair Use 的判例）
