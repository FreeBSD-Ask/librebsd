Contact justin@dragonflybsd.org if you want to be added to this page, or add your own entry if you are comfortable doing so. pkg(8) Configuration To use any mirror in this list for packages, check /usr/local/etc/pkg/repos/df-latest.conf , and change the enabled option from no to yes for the mirror you want to use. Also disable the default Avalon repo by changing its enabled from yes to no , since pkg(8) will use the first enabled site found in that file. If the mirror you want to use does not exist in that config file, you can add it using the information on this page. Copy df-latest.conf from df-latest.conf.sample in the same directory if it does not exist. The Project is also running the following AUTO mirror: AUTO: { url : https://pkg.dragonflybsd.org/pkg/${ABI}/LATEST mirror_type : HTTP enabled : yes } It's powered by mirrorselect and will return the preferred mirrors "near" the client/user. See also https://pkg.dragonflybsd.org/mirrors to check the available backend mirrors and their status.
