## 正文摘录（逐字）

"calls two system functions: Write File or Device (Interrupt 21h Function 40h) and End Program (Interrupt 21h Function 4Ch)."

## 提要

微软 1991 年《MS-DOS 程序员参考》以中断 21h 的函数号描述系统调用（如功能 40h 写文件或设备、功能 4Ch 结束程序）——应用经统一的软件中断入口请求操作系统服务，硬件差异由该入口之后收束。该句承 4.6.3 的“中断调用收束硬件差异”。
