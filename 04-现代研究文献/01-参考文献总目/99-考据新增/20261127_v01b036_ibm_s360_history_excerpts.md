## 正文摘录（逐字）

"The System/360 replaced all five of IBM’s existing computer product lines with one strictly compatible family, using a new architecture that pioneered the 8-bit byte still in use on computers today."

"The new line would replace all existing IBM computer products and cost USD 5 billion over four years."

"Before the System/360, anyone buying a new computer system had to scrap their existing programs and start from scratch. There were no commercial software companies, and software was customized (or custom written) for each new machine. The System/360 changed that dynamic overnight by separating software from hardware."

## 提要

IBM 官方遗产页记：System/360 以单一严格兼容的机族取代 IBM 既有五条计算机产品线，并开 8 位字节架构之先；新线将取代全部现有产品、四年耗资 50 亿美元；此前每买新机都要废弃旧程序重写，商业软件公司尚不存在，软件按机定制，System/360 以软硬件分离改变此局。三条分别承 3.2.3 的五线合一的兼容策略、3.2.4 的最大单笔投入与 3.2.5 的软件独立化。
