1. [1.6.2 用] Some of these flaws exist because hosts rely on IP source address for authentication; the Berkeley ‘‘r-utilities’’[3] are a notable example.

2. [备用（后续批可用），照录] Many of the intrusions described above succeed only because the target host uses the IP source address for authentication, and assumes it to be genuine. Unfortunately, there are sufficiently many ways to spoof this address that such techniques are all but worthless.

3. [备用，照录] Some protocols (i.e., Berkeley’s rlogin and rsh) permit ordinary users to extend trust to remote host/user combinations. In that case, individual users, rather than an entire system, may be targeted by source routing attacks.
