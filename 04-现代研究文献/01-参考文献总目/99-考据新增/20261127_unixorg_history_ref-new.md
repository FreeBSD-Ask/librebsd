## 正文摘录（逐字）

> 1982System III AT&T's UNIX System Group (USG) release System III, the first public release outside Bell Laboratories.

> 1983System V AT&T announces UNIX System V, the first supported release. Installed base 45,000.

> 1984SVR2 System V Release 2 introduced. At this time there are 100,000 UNIX installations around the world.

> 1987SVR3 System V Release 3 including STREAMS, TLI, RFS.

> 19844.2BSD University of California at Berkeley releases 4.2BSD, includes TCP/IP, new signals and much more.

> 1980Xenix Microsoft introduces Xenix. 32V and 4BSD introduced.
