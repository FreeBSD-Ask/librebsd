1. [1.2.3 用] The user entry should contain the user name of the user as whom the server should run. This allows for servers to be given less permission than root.

2. [备用（后续批可用于入口集题），照录] It then listens for connections on certain internet sockets. When a connection is found on one of its sockets, it decides what service the socket corresponds to, and invokes a program to service the request.

3. [备用，照录] Essentially, inetd allows running one daemon to invoke several others, reducing load on the system.
