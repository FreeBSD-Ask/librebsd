# DragonFly BSD — Mailing Lists（官方邮件列表页）

## 抓取正文（节选，空白已归一）

```
mailing lists and an IRC channel for discussion. IRC channel For more immediate communication, DragonFly users and developers are often available via IRC on #dragonflybsd, on EFNet. Mailing lists DragonFly uses Mailman to manage all mailing lists. To subscribe, unsubscribe, or change your settings for a subscribed email address, visit lists.dragonflybsd.org/mailman/listinfo . The bugs@ and submit@ lists are tied into the bug tracker at bugs.dragonflybsd.org . Subscribers to these lists will receive all output, but to post to those lists, you need to have an account. The sign-up process is moderated so an administrator will have to activate your account before it can be used. If you need assistance please contact Antonio Huete, Matthew Dillon, Sascha Wildner or Justin Sherrill directly or in #dragonflybsd in EFNet. A mailing list subscription is not necessary to post a bug report when you access the bugs database via bugs.dragonflybsd.org . You will be appropriately CCd via your bugs database registration. By web archive lists.dragonflybsd.org (official, all groups) leaf.dragonflybsd.org/mailarchive/ (old official, all groups) marc.info (all groups except hammer and test, in BSD section) Gmane.org (all groups except docs, hammer and test) DragonFly BSD / Mailing Lists & IRC
```
