## Code Analysis of the Linux Wireless Team's ath5k Driver（SFLC 官方审查）

- **ref id**: 2516
- **类型**: 一手/法律审查报告（primary）
- **状态**: verified
- **作者**: Software Freedom Law Center（软件自由法律中心）
- **发布**: softwarefreedom.org，2007
- **语言**: en
- **URL**: https://softwarefreedom.org/badge/resources/2007/ath5k-code-analysis.html
- **用途**: 大纲第68章 68.4、第191章 191.4——2007 年 ath5k 驱动 GPL 许可争议的**官方法律审查**依据；替换原 en.wikipedia-on-ipfs.org 的 Theo de Raadt 条目。
- **关键事实**: Linux ath5k 源自 OpenBSD ar5k（ISC 许可）；2007-06 起 Jiri Slaby/Kossifidis 等基于 madwifi 开发；SFLC 审查结论——ar5k 派生代码的全部版权持有者同意按 ISC 许可授权，使改进可回馈 OpenBSD；含 GPL 分支难以回馈。
