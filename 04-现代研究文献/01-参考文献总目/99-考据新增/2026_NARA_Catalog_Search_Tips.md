## 二、逐字引文（英文，未翻译）

检索范围：

> The National Archives Catalog allows you to search all of the catalog records and authority files.

著录层级：

> The Level of Description search allows you to limit your search to archival descriptions at a particular archival level such as Record Group, Collection, Series, File Unit, or Item.

记录组号检索：

> The Record Group Number search allows you to search for archival descriptions belonging to a particular Record Group. It will search for the description of a particular Record Group, as well as any Series, File Units, and Items that fall under that Record Group.

## 三、考据说明

1. 该页把 NARA 的著录层级写实为五级：Record Group／Collection／Series／File Unit／Item；中文可对应记录组／集合（全宗级）／系列／案卷／件。V11 题面所称“馆藏、全宗与件三级”是叙述上的简化，严格检索口径为五级。
2. 目录对公众开放检索（无需凭证），与 DTIC 的分层授权入口形成对照——这是“检索入口开放情况”的直接证据。
3. 按记录组号检索会连带返回其下系列、案卷与件，说明“全宗号”是向下展开的入口，而非终点。
4. 禁引核查：`.gov` 官方站，`banned_source=0`。
