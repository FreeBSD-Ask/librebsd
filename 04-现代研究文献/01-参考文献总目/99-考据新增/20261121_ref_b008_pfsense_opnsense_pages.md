- **FAQ 句二（V57.4.2.5 A 块）**：pfSense Plus (and TNSR) software release numbering is consistent with the Linux Networking Foundation FD.io project approach - where releases are numbered with a year.month.patch convention. pfSense CE software release numbering is consistent with the FreeBSD approach - where releases are numbered with a major.minor.patch convention.
- **release-schedule 句（V57.4.2.5 B 块）**：pfSense Plus software typically targets 3 releases per year, but the schedule varies based on complexity of development for a given release. Releases for pfSense® CE software are made when they are ready.
