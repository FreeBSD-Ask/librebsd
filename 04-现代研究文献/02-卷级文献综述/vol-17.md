## ① 卷主题与章节范围

本卷覆盖 **1970-2024 年政治制度与社区治理**：技术-政治交叉背景（美国政治制度史、总统时代、三权分立、科技政策）、BSD 社区治理哲学（daemon 词源与名称溯源、社区政治学、治理模式对照），以及 BSD 所嵌入的政治经济环境（DARPA 资助、Bayh-Dole、EAR 出口管制）（14 章，ch313-326）。本卷主题为"**自由的制度环境**"——软件自由无法脱离政治制度与治理结构的土壤。

## ② 现有研究综述

**素材基础**：T1 素材 3 条（极稀疏）——但存疑 32 条（高密度）覆盖政治制度考据。

- **档案文献**：DTIC ADA611780（国防技术信息中心）、FreeBSD Journal 2016.09-10、VAX 系统配置手册（1981）——技术-制度档案。
- **存疑富矿**：32 条 doubts 分两块：①**美国政治制度**（拜杜法案 1980 vs 1992 误记 id 1615/1618、DARPA 资助 CSRG 金额 id 1619、EAR 密码软件管制 id 1620、Trump v. United States 2024 判决 id 1627/1629、选举团/最高法院政治化/国会-总统权力失衡 id 1622-1625）；②**BSD 社区治理**（daemon 词源 id 1642、社区哲学）。

**中文研究现状**：中文对"美国政治制度 + 开源社区"交叉的中文系统论述极少——本卷以 BSD 史视角切入政治-技术交叉，填补空白。

## ④ 研究缺口

1. **技术-政治交叉的系统化**：总统政策（特朗普 1.0/2.0、拜登）对开源/BSD 项目的具体影响（id 1616）——需政策-项目因果梳理。
2. **DARPA 资助口径**：CSRG 受资助金额的官方档案口径（id 1619 已辨析为 1700 万级）——待 DARPA 原始合同档案。
3. **治理哲学提炼**：daemon 词源（已核验）→ BSD 社区"低调治理"哲学的文本化——需从社区文献提炼。
4. **辩证史观的呈现**：id 1632 明示"线性进步"史观局限——综述须采用项目统摄史观（革命 vs 改革方法论）。

## ⑤ 与本书"软件自由"主线的关系

本卷是"**自由的制度环境**"：BSD 诞生于 DARPA/国防资助的土壤（第 2 卷承续），其"自由"始终与政治制度博弈——Bayh-Dole 改变了大学技术转移规则、EAR 管制密码软件、总统政策左右科技生态。同时，BSD 社区自身的治理（daemon 象征、低调哲学、精英共识）是"自由如何自我组织"的微观样本。与第 16 卷（组织化）构成"外部制度-内部治理"的双层结构。
